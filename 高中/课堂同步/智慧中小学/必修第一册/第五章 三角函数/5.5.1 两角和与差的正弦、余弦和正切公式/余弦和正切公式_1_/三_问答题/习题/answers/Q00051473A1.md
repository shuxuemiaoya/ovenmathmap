> > [!success]- **【答案】** 详见解析

> > [!note]- **【解析】**
> > 【正确答案】 $\because \frac{3}{4}\pi +\beta -\left(\frac{\pi}{4} -\alpha\right) = \frac{\pi}{2} +\alpha +\beta ,\quad \therefore sin(\alpha +\beta) = sin\Bigl [\left(\frac{3}{4}\pi +\beta\right) - \left(\frac{\pi}{4} -\alpha\right) - \frac{\pi}{2}\Bigr ] = cos$ $\left[\left(\frac{3}{4}\pi +\beta\right) - \left(\frac{\pi}{4} -\alpha\right)\right] = -cos\left(\frac{3}{4}\pi +\beta\right)cos\left(\frac{\pi}{4} -\alpha\right) - sin\left(\frac{3}{4}\pi +\beta\right)sin\left(\frac{\pi}{4} -\alpha\right),$ $\because \frac{\pi}{4} <  \alpha <  \frac{3}{4}\pi ,\quad \therefore -\frac{\pi}{2} < \frac{\pi}{4} - \alpha <  0,\quad \therefore sin\left(\frac{\pi}{4} -\alpha\right) = -\frac{4}{5},\quad \frac{\pi}{2} <  \beta <  \frac{3}{4}\pi ,\quad \because \frac{5\pi}{4} <  \frac{3}{4}\pi +\beta <  \frac{3}{2}\pi ,\quad \therefore cos$ $\left(\frac{3}{4}\pi +\beta\right) = -\frac{5}{13},\quad \therefore sin(\alpha +\beta) = \frac{5}{13}\times \frac{3}{5} -\left(-\frac{12}{13}\right)\times \left(-\frac{4}{5}\right) = \frac{15}{65} -\frac{48}{65} = -\frac{33}{65}$
