> [!faq]- 《简单的三角变换（2）》答案与解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【解析】**
> > 【正确答案】
> > （1） $\frac{\sin7^{\circ}+\sin8^{\circ}\cdot\cos15^{\circ}}{\cos7^{\circ}-\sin8^{\circ}\cdot\sin15^{\circ}}=\frac{\sin(15^{\circ}-8^{\circ})+\sin8^{\circ}\cdot\cos15^{\circ}}{\cos(15^{\circ}-8^{\circ})-\sin8^{\circ}\cdot\sin15^{\circ}}=\frac{\sin15^{\circ}\cos8^{\circ}}{\cos15^{\circ}\cos8^{\circ}}=\tan(45^{\circ}-30^{\circ})=$ $\frac{tan45^{\circ}-tan30^{\circ}}{1+tan45^{\circ}tan30^{\circ}}=\frac{1-\frac{\sqrt{3}}{3}}{1+1\times\frac{\sqrt{3}}{3}}=2-\sqrt{3}$
> >
> > $$
> > \begin{array}{l}
> > (2) 4 \cos 7 0 ^ {\circ} + \tan 2 0 ^ {\circ} = \frac {4 \cos 7 0 ^ {\circ} \cos 2 0 ^ {\circ} + \sin 2 0 ^ {\circ}}{\cos 2 0 ^ {\circ}} = \frac {2 \sin 4 0 ^ {\circ} + \sin 2 0 ^ {\circ}}{\cos 2 0 ^ {\circ}} = \frac {2 \cos 5 0 ^ {\circ} + \sin (5 0 ^ {\circ} - 3 0 ^ {\circ})}{\cos 2 0 ^ {\circ}} = \frac {\frac {\sqrt {3}}{2} \sin 5 0 ^ {\circ} + \frac {3}{2} \cos 5 0 ^ {\circ}}{\cos 2 0 ^ {\circ}} \\ = \frac {\sqrt {3} \sin (5 0 ^ {\circ} + 6 0 ^ {\circ})}{\cos 2 0 ^ {\circ}} = \sqrt {3} \end{array}
> > $$
