> [!faq]- 《同角三角函数的基本关系应用》答案与解析
>
> > [!success]- **【答案】** (1)
>
> > [!note]- **【解析】**
> > ∴ $1 + 2\cos x \sin x = \frac{1}{25}$ 即 $\cos x \sin x = -\frac{12}{25}$
> >
> > $\because \cos x \sin x < 0$ 且 $-\pi < x < 0, \therefore x$ 为第四象限角.
> >
> > (2)【问答题】 $\because (sinx - cosx)^{2} = 1 - 2cosx\sin x = \frac{49}{25},$
> >
> > $\therefore \sin x - \cos x = \pm \frac{7}{5}$
> >
> > ∵x为第四象限角，sinx<0，cosx>0
> >
> > $\therefore \sin x - \cos x < 0, \therefore \sin x - \cos x = -\frac{7}{5},$ 联立 $\cos x + \sin x = \frac{1}{5}$ 得： $\left\{ \begin{array}{l} \sin x = -\frac{3}{5} \\ \cos x = \frac{4}{5} \end{array} \right.$
> >
> > $$
> > \therefore \tan x = \frac {\sin x}{\cos x} = - \frac {3}{4}.
> > $$
