> [!faq]- 《单调性》答案与解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【解析】**
> > 证明：函数 $f(x) = x^3 + x$ 在 $R$ 上是增函数.
> >
> > 【正确答案】设 $x_{1}$ ， $x_{2}$ 是R上的两个任意实数，且 $x_{1} < x_{2}$ ，则 $f(x_{1}) - f(x_{2}) = (x_{1}^{3} + x_{1}) - (x_{2}^{3} + x_{2})$ $= (x_1^3 -x_2^3) + (x_1 - x_2) = (x_1 - x_2)(x_1^2 +x_1x_2 + x_2^2) + (x_1 - x_2) = (x_1 - x_2)(x_1^2 +x_1x_2 + x_2^2 +l)$ $= (x_{1} - x_{2})\left[\left(x_{1} + \frac{x_{2}}{2}\right)^{2} + \frac{3}{4} x_{2}^{2} + 1\right],\quad \because x_{1} <   x_{2},\quad \therefore x_{1} - x_{2} <   0$ 而 $\left(x_{1} + \frac{x_{2}}{2}\right)^{2} + \frac{3}{4} x_{2}^{2} + l > 0,\quad \therefore f(x_{1}) - f(x_{2})$
> >
> > 即 $f(x_{1})<f(x_{2})$ . $\therefore f(x)=x^{3}+x$ 在R上是增函数.
