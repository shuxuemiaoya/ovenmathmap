> > [!note]- **【解析】**
> > (2)【问答题】综上所述，当a<-1时，原不等式的解集为 $\left\{x\mid x<-\frac{l}{a}或x>1\right\}$ ;
> >
> > 当 $a = -1$ 时，原不等式的解集为 $\{x\mid x\neq 1\}$
> >
> > 当 -1 < a < 0 时，原不等式的解集为 $\{x \mid x < 1 \text{ 或 } x > -\frac{1}{a}\}$ ;
> >
> > 当 $a = 0$ 时，原不等式的解集为 $\{x|x < 1\}$
> >
> > 当 $a > 0$ 时，原不等式的解集为 $\left\{x\right| - \frac{l}{a} < x < 1\}$ .
