> [!faq]- 《一元函数的导数及其应用小结（2）》答案与解析
>
> > [!success]- **【答案】** $\frac{\pi}{3}$
>
> > [!note]- **【解析】**
> > 种植区的面积为 $S_{1}=\frac{1}{2}AF\cdot AE\cdot\theta=\frac{1}{2}\theta,$
> >
> > 正方形面积为 $S = AD^{2} = \cos^{2}\angle DAF = \frac{l + \cos 2\angle DAF}{2} = \frac{l + \sin\theta}{2}$
> >
> > 设年总收入为 $W(\theta)$ 万元，则
> >
> > $$
> > W (\theta) = 1 0 S _ {I} + 2 0 S _ {I I} + 2 0 S _ {I I I} = 1 0 S _ {I} + 2 0 (S - S _ {I}) = 5 \theta + 2 0 \left(\frac {1 + \sin \theta}{2} - \frac {1}{2} \theta\right) = 1 0 + 1 0 \sin \theta - 5 \theta ,
> > $$
> >
> > 其中 $\frac{\pi}{4} < \theta < \frac{\pi}{2}$ ，求导可得 $W'(\theta) = 10\cos \theta - 5$ 。
> >
> > 当 $\frac{\pi}{4} < \theta \leqslant \frac{\pi}{3}$ 时， $W'(\theta) > 0$ ， $W(\theta)$ 递增；当 $\frac{\pi}{3} < \theta < \frac{\pi}{2}$ 时， $W'(\theta) < 0$ ， $W(\theta)$ 递增.  
> > 所以当 $\theta = \frac{\pi}{3}$ 时， $W(\theta)$ 取得最大值，此时年总收入最大.
