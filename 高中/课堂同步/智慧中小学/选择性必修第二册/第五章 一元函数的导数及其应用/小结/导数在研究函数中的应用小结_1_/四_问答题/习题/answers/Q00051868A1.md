> [!faq]- 《导数在研究函数中的应用小结（1）》答案与解析
>
> > [!success]- **【答案】** 先证： $\ln x > \frac{2(x - 1)}{x + 1}(x > 1)$ ， $\ln x < \frac{2(x - 1)}{x + 1}(0 < x < 1)$
>
> > [!note]- **【解析】**
> > 不妨设 $0 < x_{1} < \frac{1}{a} < x_{2}$
> >
> > $$
> > \frac {x _ {2}}{\frac {1}{a}} = a x _ {2} > 1 \Rightarrow \ln (a x _ {2}) > \frac {2 (a x _ {2} - 1)}{a x _ {2} + 1} \Leftrightarrow a ^ {2} x _ {2} ^ {2} + (a l n a - a) x _ {2} + l n a + 2 > 0 \tag {①}
> > $$
> >
> > $$
> > \frac {x _ {I}}{\frac {I}{a}} = a x _ {I} <   1 \Rightarrow l n (a x _ {I}) <   \frac {2 (a x _ {I} - 1)}{a x _ {I} + 1} \Leftrightarrow a ^ {2} x _ {I} ^ {2} + (a l n a - a) x _ {I} + l n a + 2 <   0 \tag {②}
> > $$
> > - **①**：-②: $a^{2}(x_{2}^{2}-x_{1}^{2})+(a\ln a-a)(x_{2}-x_{1})>0$ 则 $x_{1}+x_{2}>\frac{1-\ln a}{a}$
