13.【复合题】为研究患肺癌与是否吸烟有关，做了一次相关调查，其中部分数据丢失，但可以确定的是不吸烟人数与吸烟人数相同，吸烟患肺癌人数占吸烟总人数的 $\frac{4}{5}$

；不吸烟的人数中，患肺癌与不患肺癌的比为 1:4.

(1)【问答题】若吸烟不患肺癌的有4人，现从患肺癌的人中用分层抽样的方法抽取5人，再从这5人中随机抽取2人进行调查，求这两人都是吸烟患肺癌的概率；

(2)【问答题】在
（1）的前提条件下，能不能在犯错误概率不超过 0.001

的前提下，认为患肺癌与吸烟有关？

附： $\chi^2 = \frac{n(ad - bc)^2}{(a + b)(c + d)(a + c)(b + d)}$

其中 $n = a + b + c + d$
