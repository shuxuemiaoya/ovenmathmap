19. (17分)已知函数$f$($x$)*=*$\frac{x + b}{1 + x^{2}}$为奇函数*.*
(1)求$b$的值;
(2)证明:函数$f$($x$)在区间(1,*+∞*)内单调递减;
(3)解关于$x$的不等式$f$(1*+*2$x^{2}$)*+f*(*-x*^2^*+*2*x-*4)*\>*0*.*
(1)解:因为函数$f$($x$)*=*$\frac{x + b}{1 + x^{2}}$为定义在*$R$*上的奇函数,所以$f$(0)*=b=*0*.*
(2)证明:由(1)可得$f$($x$)*=*$\frac{x}{1 + x^{2}}$,下面证明函数$f$($x$)在区间(1,*+∞*)内单调递减*.*
设任意$x_{1}$,$x_{2}$∈(1,*+∞*),且$x_{2}$*\>x*~1~,
则有$f$($x_{1}$)*-f*($x_{2}$)*=*$\frac{x_{1}}{1 + x_{1}^{2}} - \frac{x_{2}}{1 + x_{2}^{2}}$
*=*$\frac{x_{1} + x_{1}\text{·}x_{2}^{2}\text{-}x_{2}\text{-}x_{2}\text{·}x_{1}^{2}}{\text{(}1 + x_{1}^{2}\text{)(}1 + x_{2}^{2}\text{)}}$
*=*$\frac{\text{(}x_{1}\text{-}x_{2}\text{)(}1\text{-}x_{1}x_{2}\text{)}}{\text{(}1 + x_{1}^{2}\text{)(}1 + x_{2}^{2}\text{)}}$*.*
根据$x_{2}$*\>x*~1~*\>*1,可得1*+*$x_{1}^{2}$*\>*0,1*+*$x_{2}^{2}$*\>*0,$x_{1}$*-x*~2~*\<*0,1*-x*~1~$x_{2}$*\<*0,
即$\frac{\text{(}x_{1}\text{-}x_{2}\text{)(}1\text{-}x_{1}x_{2}\text{)}}{\text{(}1 + x_{1}^{2}\text{)(}1 + x_{2}^{2}\text{)}}$*\>*0,
即$f$($x_{1}$)*\>f*($x_{2}$),故函数$f$($x$)在区间(1,*+∞*)内单调递减*.*
(3)解:由不等式$f$(1*+*2$x^{2}$)*+f*(*-x*^2^*+*2*x-*4)*\>*0,
且$f$($x$)为奇函数,
可得$f$(1*+*2$x^{2}$)*\>-f*(*-x*^2^*+*2*x-*4)*=f*($x^{2}$*-*2*x+*4)*.*
由函数$f$($x$)在区间(1,*+∞*)内单调递减,可得1*+*2$x^{2}$*\<x*^2^*-*2*x+*4,
