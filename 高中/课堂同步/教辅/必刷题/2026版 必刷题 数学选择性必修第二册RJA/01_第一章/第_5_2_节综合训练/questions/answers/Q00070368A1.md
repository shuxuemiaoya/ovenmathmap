> [!faq]- 答案与解析
>
> > [!success]- **【答案】** $2^{n + 1} - \frac{1}{2} n - \frac{3}{2}$
>
> > [!note]- **【解析】**
> > 由 $(2 - a_{n + 1})$ · $(4 + a_{n}) = 8$ ，可得 $2a_{n} - 4a_{n + 1} = a_{n}a_{n + 1}$ ，所以 $\frac{1}{a_{n + 1}} = \frac{2}{a_n} +\frac{1}{2}$ ，即 $\frac{1}{a_{n + 1}} +\frac{1}{2} =$ $2\left(\frac{1}{a_n} +\frac{1}{2}\right),$ 令 $b_{n} = \frac{1}{a_{n}} +\frac{1}{2}$ 得 $b_{n + 1} = 2b_{n}$ ，即 $\frac{b_{n + 1}}{b_n} = 2,$ 因为 $b_0 = \frac{1}{a_0} +\frac{1}{2} = 1$ ，所以 $b_{n} = 2^{n}$ ，即 $\frac{1}{a_n} = 2^n -\frac{1}{2},$ 所以 $\sum_{i = 0}^{n}\frac{1}{a_i} = (2^0 +2^1 +\dots +2^n) - \frac{1}{2}(n+$ $1) = \frac{1\times(1 - 2^{n + 1})}{1 - 2} -\frac{1}{2} (n + 1) = 2^{n + 1}-$ $\frac{1}{2} n - \frac{3}{2}.$
