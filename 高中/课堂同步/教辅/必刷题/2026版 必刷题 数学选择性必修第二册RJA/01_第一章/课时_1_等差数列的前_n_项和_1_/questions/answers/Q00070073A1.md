> > [!note]- **【解析】**
> > 数列 $\{a_{n}\}$ 中，由 $\frac{a_{n+1}-a_{n}}{a_{n}}=\frac{a_{n+2}-a_{n+1}}{a_{n+2}}$ ，得 $\frac{1}{a_{n+2}}+\frac{1}{a_{n}}=\frac{2}{a_{n+1}}$ ，则数列 $\left\{\frac{1}{a_{n}}\right\}$ 是首项为 $\frac{1}{a_{1}}=1$ 的等差数列，设其公差为 $d$ ，则 $\frac{1}{a_{n}}=1+(n-1)d$ ，即 $a_{n}=\frac{1}{dn+1-d}$ .
> >
> > 于是 $a_{n}a_{n + 1} = \frac{1}{dn + 1 - d}\cdot \frac{1}{dn + 1} = \frac{1}{d}$ $\left(\frac{1}{dn + 1 - d} -\frac{1}{dn + 1}\right),\sum_{i = 1}^{n}a_{i}a_{i + 1} = \frac{1}{d}$ $\left(1 - \frac{1}{dn + 1}\right) = \frac{n}{dn + 1},$ 由 $a_1a_2 + a_2a_3 + \dots +a_6a_7 = 3,$ 得 $\frac{6}{6d + 1} =$ 3,解得 $d = \frac{1}{6}$ ，因此 $a_{n} = \frac{6}{n + 5}$ 所以 $a_{2025} = \frac{6}{2025 + 5} = \frac{3}{1015}.$
