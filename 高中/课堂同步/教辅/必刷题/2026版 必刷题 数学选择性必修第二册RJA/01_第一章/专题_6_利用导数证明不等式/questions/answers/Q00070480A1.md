> [!faq]- 答案与解析
>
> > [!success]- **【答案】** D
>
> > [!note]- **【解析】**
> > D 【解析】对命题①: 因为 $e^{x} \geqslant x + 1$ ，所以 $e^{x-1} \geqslant (x - 1) + 1 = x$ 恒成立，则当 x > 0 时， $\ln e^{x-1} \geqslant \ln x$ ，即 $x - 1 \geqslant \ln x$ ，则 $x \geqslant \ln x + 1$ ，
> > 所以 $e^{x-1} \geqslant x \geqslant \ln x + 1$ 在 $(0, +\infty)$ 上恒成立，且当 x = 1 时两个等号均成立，所以①正确；
> > 对命题②: 因为 $e^{x} \geqslant x + 1$ ，所以 $e^{x-a} \geqslant x-a+1$ ，两边同乘 $e^{a}$ 得 $e^{x} \geqslant e^{a}(x-a+1)$ ，且当 x = a 时等号成立，所以②正确；
> > 对命题③: 设 $f(x)=\cos x+\frac{1}{2}x^{2}-1$ ，则 $f'(x)=-\sin x+x,$ 设 $h(x)=-\sin x+x,$ 则 $h'(x)=-\cos x+1 \geqslant 0$ 恒成立且不恒为0，
> > 所以 $h(x) = -\sin x + x$ 在 $(-∞, +∞)$ 上单调递增，又 $h(0) = 0,$ 所以当 x < 0 时， $h(x) < 0$ ，当 x > 0 时， $h(x) > 0,$ 所以 $f(x)$ 在 $(-∞, 0)$ 上单调递减，在 $(0, +∞)$ 上单调递增，且 $f(0)=0,$ 所以 $f(x) \geqslant 0$ 恒成立，即 $\forall x \in R,$ $\cos x \geqslant 1 - \frac{1}{2}x^{2}$ ，且当 x = 0 时等号成立，所以③正确；
> > 对命题④: 因为 $e^{x} \geqslant x + 1$ ，所以当 x > 0 时， $e^{x+\ln x} \geqslant x+\ln x+1$ ，即 $xe^{x} \geqslant x+\ln x+1$ ，且当 $x+\ln x=0$ 时等号成立，所以④正确，
> >
> > 故选 **D**.
