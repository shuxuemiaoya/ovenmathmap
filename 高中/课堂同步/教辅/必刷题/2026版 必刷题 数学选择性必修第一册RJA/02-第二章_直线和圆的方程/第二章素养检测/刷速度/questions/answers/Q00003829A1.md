> [!faq]- 必刷题解析
> **【解析】**
> 【解】(1)设圆 C 的半径为 r.
若选条件①, 圆 C 与直线 $3x + 4y + 17 = 0$ 相切,
则圆心 C 到直线 $3x + 4y + 17 = 0$ 的距离是圆 C 的半径, 即 $r = \frac{|-6+4+17|}{5} = 3$ , 所以圆 C 的方程为 $(x+2)^{2} + (y-1)^{2} = 9$ .
若选条件②, 圆 C 与圆 $M: (x-2)^{2} + (y-4)^{2} = 4$ 相外切, 圆 M 的圆心为 (2,4), 半径为 2,
所以 $r+2=\sqrt{(2+2)^{2}+(4-1)^{2}}=5$ , 所以 $r = 3$ ，所以圆 $C$ 的方程为 $(x + 2)^{2} + (y - 1)^{2} = 9.$ 若选条件③，圆 $C$ 经过直线 $3x + y + 2 = 0$ 与直线 $x - 3y + 14 = 0$ 的交点，由 $\left\{ \begin{array}{l}3x + y + 2 = 0,\\ x - 3y + 14 = 0, \end{array} \right.$ 得 $\left\{ \begin{array}{l}x = -2,\\ y = 4, \end{array} \right.$ 所以 $r = 4 - 1 = 3,$ 所以圆 $C$ 的方程为 $(x + 2)^{2} + (y - 1)^{2} = 9.$ (2)圆 $N:(x - m)^{2} + y^{2} = m^{2}(m > 0)$ 的圆心为 $(m,0)$ ，半径为 $m$ 两个圆有公共弦，则 $|m - 3| <   |CN| <   m + 3$ ，即 $|m - 3| <   \sqrt{(m + 2)^2 + 1} < m + 3$ ，解得 $m > \frac{2}{5}$ 由 $\left\{ \begin{array}{l}(x + 2)^2 +(y - 1)^2 = 9,\\ (x - m)^2 +y^2 = m^2 \end{array} \right.$ 得，两圆公共弦所在直线的方程为 $(m + 2)x-$ $y - 2 = 0$ 又两圆的公共弦长为2，则圆心 $C$ 到公共弦所在直线的距离 $d = \frac{| - 2m - 4 - 1 - 2|}{\sqrt{(m + 2)^2 + 1}} = \frac{|2m + 7|}{\sqrt{m^2 + 4m + 5}}$ ，且 $2\sqrt{9 - d^2} = 2$ ，解得 $m = \frac{\sqrt{10} - 1}{2}$ 或 $m = \frac{-\sqrt{10} - 1}{2},$ 又 $m > \frac{2}{5}$ ，所以 $m = \frac{\sqrt{10} - 1}{2}$ .经检验符合题意.
故存在实数 $m = \frac{\sqrt{10} - 1}{2}$ ，使得圆 $N$ 与圆 $C$ 公共弦的长度为2.
