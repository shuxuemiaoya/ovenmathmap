> [!faq]- 必刷题解析
> **【解析】**
> 1 【解析】设点 $P_{1}, P_{2}$ 的坐标分别为 $(x_{1}, y_{1})$ ， $(x_{2}, y_{2})$ ，则 $d_{1} = \frac{Ax_{1} + By_{1} + C}{\sqrt{A^{2} + B^{2}}}$ ， $d_{2} = \frac{Ax_{2} + By_{2} + C}{\sqrt{A^{2} + B^{2}}}$ 。若 $d_{1} - d_{2} = 0$ ，则 $d_{1} = d_{2}$ ，即 $\frac{Ax_{1} + By_{1} + C}{\sqrt{A^{2} + B^{2}}} = \frac{Ax_{2} + By_{2} + C}{\sqrt{A^{2} + B^{2}}}$ ，所以 $Ax_{1} + By_{1} + C = Ax_{2} + By_{2} + C$ 。若 $d_{1} = d_{2} = 0$ ，即 $Ax_{1} + By_{1} + C = Ax_{2} + By_{2} + C = 0$ ，则点 $P_{1}, P_{2}$ 都在直线 l 上，此时直线 $P_{1}P_{2}$ 与直线 l 重合，故①②③均为假命题。当 $d_{1}d_{2} < 0$ 时， $P_{1}, P_{2}$ 在直线 l 的两侧，则直线 $P_{1}P_{2}$ 与直线 l 相交，故④为真命题。故真命题的个数为 1。
