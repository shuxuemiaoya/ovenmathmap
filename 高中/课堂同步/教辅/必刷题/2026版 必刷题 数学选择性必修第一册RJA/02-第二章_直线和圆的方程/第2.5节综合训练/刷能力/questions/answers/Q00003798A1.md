> [!faq]- 必刷题解析
> **【答案】** C
>
> **【解析】**
> 圆 $x^{2} + y^{2} = 3$ 的圆心为 $O_{1}(0,0)$ ，半径 $r_1 = \sqrt{3}$ 圆 $x^{2} + y^{2} - 2x - 2y - m = 0$ 可化为 $(x-$ $1)^{2} + (y - 1)^{2} = m + 2,$ 则 $m > - 2$ ，圆心为 $O_{2}(1,1)$ ，半径 $r_2 =$ $\sqrt{m + 2}$ ，则 $|O_1O_2| = \sqrt{1 + 1} = \sqrt{2}$ 由题意可知两圆相交，所以 $|\sqrt{m + 2} -\sqrt{3}| <   \sqrt{2} <  \sqrt{m + 2} +\sqrt{3},$ ①两圆方程作差可得 $2x + 2y + m - 3 = 0$ ，即公共弦所在直线的方程为 $2x+$ $2y + m - 3 = 0$ 令 $x = 0$ ，则 $y = \frac{3 - m}{2}$ ，令 $y = 0$ ，则 $x = \frac{3 - m}{2}$ 所以该直线与两坐标轴围成的三角形面积为 $\frac{1}{2}\times \left|\frac{3 - m}{2}\right|\times \left|\frac{3 - m}{2}\right| = 2,$ 解得 $m = -1$ 或7，经检验 $m = -1$ 或 $m=$ 7满足①，即 $m = -1$ 或 $m = 7.$
>
> 故选 **C**.
