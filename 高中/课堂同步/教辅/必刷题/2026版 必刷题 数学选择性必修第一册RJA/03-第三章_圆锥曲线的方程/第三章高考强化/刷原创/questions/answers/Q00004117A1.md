> [!faq]- 必刷题解析
> **【解析】**
> 【解】(1)因为 $C:3x^{2}-y^{2}=m^{2}$ , 所以其焦点 $F_{1}\left(-\frac{2\sqrt{3}}{3}m,0\right),F_{2}\left(\frac{2\sqrt{3}}{3}m,0\right)$ , 渐近线方程为 $y=\pm\sqrt{3}x$ . 因为焦点到渐近线的距离为 3 , 所以 $\frac{\left|\sqrt{3}\cdot\frac{2\sqrt{3}}{3}m\right|}{\sqrt{1+3}}=3$ , 解得 $m=3$ (负值舍去). 则双曲线 $C$ 的方程为 $\frac{x^{2}}{3}-\frac{y^{2}}{9}=1$ .
(2) 设 $A(x_{1},y_{1}),B(x_{2},y_{2})(x_{1}x_{2}\neq0)$ , 由题意可知直线 $l$ 的斜率存在且不为 0 , 则可设直线 $l$ 的方程为 $y=kx+$ $\rightarrow$ 敢黑板: 若直线 $l$ 的斜率不存在, 则点 $A,B$ 关于 $x$ 轴对称, 则 $k_{1}k_{2}<0$ , 与已知矛盾 $t(k\neq\pm\sqrt{3})$ .
联立 $\begin{cases} y=kx+t, \\ \frac{x^{2}}{3}-\frac{y^{2}}{9}=1 \Rightarrow (k^{2}-3)x^{2}+2ktx+ \\ t^{2}+9=0, \text{则 } \Delta>0, \text{即 } t^{2}+9-3k^{2}>0, \text{①} \\ x_{1}+x_{2}=-\frac{2kt}{k^{2}-3}, x_{1}x_{2}=\frac{9+t^{2}}{k^{2}-3}. \end{cases}$ 因为直线 $l$ 与 $C$ 的一支交于 $A,B$ 两个不同的点, 所以 $x_{1}x_{2}>0$ , 所以 $k^{2}>3$ .
由 $k_{1}k_{2}=\frac{1}{3}=\frac{y_{1}y_{2}}{x_{1}x_{2}}$ ,
得 $y_{1}y_{2}=\frac{1}{3}x_{1}x_{2}=\frac{9+t^{2}}{3(k^{2}-3)}$ . $k_{1}k_{2}=\frac{1}{3}=\frac{(kx_{1}+t)(kx_{2}+t)}{x_{1}x_{2}}=k^{2}+$ $\frac{k t(x_ {1}+ x_ {2})+ t ^ {2}}{x _ {1} x _ {2}}=k ^ { 2 } + \frac { ( k ^ { 2 } - 3 ) t ^ { 2 } - 2 k ^ { 2 } t ^ { 2 } } { 9 + t ^ { 2 } }$ , 则 $t ^ { 2 } = \frac { 2 7 } { 1 0 } k ^ { 2 } - \frac { 9 } { 1 0 }$ . ②
因为点 $O$ 到直线 $l$ 的距离 $d=\frac{|t|}{\sqrt {1+k ^ { 2 }}}=$ $\sqrt {\frac { 27 } { 10 } k ^ { 2 } - \frac { 9 } { 10 }} = \sqrt {\frac { 27 } { 10 } - \frac { 36 } { 10 } \times \frac { 1 } { 1 + k ^ { 2 } }}.$ 将②代入①, 结合 $k ^ { 2 } > 3$ , 得 $3<k ^ { 2 }<$ 27, 则 $d \in \left( \frac { 3 \sqrt {5 } } { 5 }, \frac { 3 \sqrt {14 } } { 7 } \right)$ .
