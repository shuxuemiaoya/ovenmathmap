> **【解析】**
> （1）【解】由题意可知， $c = 1,2b = 2$ $\therefore b = 1,\therefore a^2 = b^2 +c^2 = 2,$ ∴椭圆 $C$ 的方程为 $\frac{x^2}{2} +y^2 = 1.$ （2）【证明】设直线 $l$ 的方程为 $y = k(x - 1)(k\neq 0),A(x_1,y_1),B(x_2,y_2)$ 联立 $\left\{ \begin{array}{ll}\frac{x^2}{2} +y^2 = 1, & \text{消去} y\text{得}(2k^2 +$ \\ x^2 -4k^2 x + 2k^2 -2 = 0, $\Delta = 8(k^2 +1) > 0,$ 则 $x_{1} + x_{2} = \frac{4k^{2}}{2k^{2} + 1},$ ∵ $M$ 为线段 $AB$ 的中点，\\ $\therefore x_M = \frac{x_1 + x_2}{2} = \frac{2k^2}{2k^2 + 1},y_M = k(x_M - 1) =$ $\frac{-k}{2k^2 + 1},$
$\therefore k_{OM} = \frac{y_M}{x_M} = -\frac{1}{2k},$ $\therefore k_{OM}\cdot k = -\frac{1}{2k}\times k = -\frac{1}{2}$ 即为定值. (3)【解】若四边形 $OAPB$ 为平行四边形，则 $\overrightarrow{OA} +\overrightarrow{OB} = \overrightarrow{OP},$ $\therefore x_{P} = x_{1} + x_{2} = \frac{4k^{2}}{2k^{2} + 1},$ $y_{P} = y_{1} + y_{2} = k(x_{1} + x_{2}) - 2k = \frac{-2k}{2k^{2} + 1}.$ $\because$ 点 $P$ 在椭圆上， $\therefore \left(\frac{4k^2}{2k^2 + 1}\right)^2 +2\times$ $\left(\frac{-2k}{2k^2 + 1}\right)^2 = 2$ ，解得 $k^2 = \frac{1}{2},$ 即 $k = \pm \frac{\sqrt{2}}{2}$ 故当四边形 $OAPB$ 为平行四边形时，直线 $l$ 的斜率 $k = \pm \frac{\sqrt{2}}{2}$
