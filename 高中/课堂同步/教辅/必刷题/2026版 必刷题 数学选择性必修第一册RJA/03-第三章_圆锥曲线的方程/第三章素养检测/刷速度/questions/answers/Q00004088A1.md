> [!faq]- 必刷题解析
> **【解析】**
> 4 【解析】若直线 $AB$ 与 $x$ 轴重合，则该直线与抛物线 $y^{2} = 8x$ 只有一个交点，不符合题意，设直线 $AB$ 的方程为 $x = ty + m (m \neq 0)$ ，故黑板：当 $m = 0$ 时， $A, B$ 中有一点与点 $M$ 重合，因此 $m \neq 0$ 联立 $\left\{ \begin{array}{l} x = ty + m, \\ y^{2} = 8x, \end{array} \right.$ 消去 $x$ 得 $y^{2} - 8ty - 8m = 0, \Delta = (-8t)^{2} + 4 \times 8m = 64t^{2} + 32m > 0,$ 设 $A(x_{1}, y_{1}), B(x_{2}, y_{2})$ ，则 $y_{1} + y_{2} = 8t, y_{1}y_{2} = -8m,$ $\frac{1}{|AM|^2} = \frac{1}{(x_1 - m)^2 + y_1^2} = \frac{1}{(t^2 + 1)y_1^2}$ ，同理可得 $\frac{1}{|BM|^2} = \frac{1}{(t^2 + 1)y_2^2}$ ，所以 $\frac{1}{|AM|^2} + \frac{1}{|BM|^2} = \frac{1}{t^2 + 1}\cdot \left(\frac{1}{y_1^2} + \frac{1}{y_2^2}\right) = \frac{1}{t^2 + 1}\cdot \frac{(y_1 + y_2)^2 - 2y_1y_2}{(y_1y_2)^2} = \frac{64t^2 + 16m}{64m^2t^2 + 64m^2}$ ，因为 $\frac{1}{|AM|^2} + \frac{1}{|BM|^2}$ 为定值，所以 $\frac{64}{64m^2} = \frac{16m}{64m^2}$ ，解得 $m = 4$ ，满足 $\Delta > 0$ ，故 $m = 4$ 。
