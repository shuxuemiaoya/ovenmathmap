> **【解析】**
> 2 【解析】设弦 $AC$ 所在直线与 $x$ 轴正方向的夹角为 $\theta$ ，则 $|AC| = \frac{2ab^2}{a^2 - c^2\cos^2\theta}, |BD| = \frac{2ab^2}{a^2 - c^2\sin^2\theta}$ ，∴ 四边形 $ABCD$ 的面积 $S = \frac{2a^2b^4}{a^4 - a^2c^2 + c^4\cos^2\theta\sin^2\theta} \leqslant \frac{2a^2b^4}{a^4 - a^2c^2} = \frac{2b^4}{b^2} = 2b^2 = \frac{25}{2}, \therefore b^2 = \frac{25}{4};$ $S = \frac{2a^2b^4}{a^4 - a^2c^2 + c^4\cos^2\theta\sin^2\theta} \geqslant \frac{2a^2b^4}{a^4 - a^2c^2 + \frac{1}{4}c^4} = \frac{2b^4}{b^2 + \frac{1}{4} \cdot \frac{c^4}{a^2}} = \frac{2b^2}{1 + \frac{1}{4} \cdot \frac{c^4}{a^2b^2}} = 8, \therefore \frac{c^4}{a^2b^2} = \frac{9}{4}, \therefore a = 5,$ \$\therefore \frac{a}{b} = 2.\$
>

> **📚 二级结论**
> 在椭圆 $\frac{x^2}{a^2} +\frac{y^2}{b^2} = 1(a > b>$ 0)中，点 $P$ 为椭圆上一点.如图，设 $\angle PF_1F_2 = \alpha$ ，则 $|PF_{1}| =$ $\frac{b^2}{a - c\cos\alpha},|MF_1| = \frac{b^2}{a + c\cos\alpha},$ $\frac{1}{|PF_1|} +\frac{1}{|MF_1|} = \frac{2a}{b^2},$ $|MP| = \frac{2ab^2}{a^2 - c^2\cos^2\alpha}.$

证明：
在 $\triangle PF_{1}F_{2}$ 中，根据余弦定理，有 $|PF_{2}|^{2}=|PF_{1}|^{2}+|F_{1}F_{2}|^{2}-2|PF_{1}|\cdot|F_{1}F_{2}|\cdot\cos\alpha,$ 由椭圆定义 $|PF_{1}|+|PF_{2}|=2a$ 得 $(2a-|PF_{1}|)^{2}=|PF_{1}|^{2}+4c^{2}-4ccos\alpha\cdot|PF_{1}|,$ 整理得 $|PF_{1}|=\frac{b^{2}}{a-c\cos\alpha}.$ 在 $\triangle MF_{1}F_{2}$ 中， $|MF_{2}|^{2}=|MF_{1}|^{2}+$ $|F_{1}F_{2}|^{2}-2|MF_{1}|\cdot|F_{1}F_{2}|\cdot\cos(\pi-\alpha)=(2a-|MF_{1}|)^{2},$ 整理得 $|MF_{1}|=\frac{b^{2}}{a+c\cos\alpha}.$
所以 $\frac{1}{|PF_1|} +\frac{1}{|MF_1|} = \frac{2a}{b^2},$ $|MP| = |MF_1| + |PF_1| = \frac{2ab^2}{a^2 - c^2\cos^2\alpha}.$
