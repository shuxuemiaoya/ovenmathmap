> [!faq]- 必刷题解析
> **【答案】** A
>
> **【解析】**
> 由题易知 $AD, AB, AP$ 两两垂直，如图，以 $A$ 为坐标原点， $AD, AB, AP$ 所在直线分别为 $x, y, z$ 轴建立空间直角坐标系。由二面角 $Q - PD - A$ 的大小为 $30^\circ$ ，可知 $Q$ 的轨迹是过点 $D$ 的一条直线，又 $Q$ 是四边形 $ABCD$ 内部一点（包括边界），则 $Q$ 的轨迹是过点 $D$ 的一条线段，设点 $Q$ 的轨迹与 $y$ 轴的交点坐标为 $G(0, b, 0) (b > 0)$ 。由题意可知 $A(0, 0, 0), D(2, 0, 0), P(0, 0, 1)$ ，所以 $\overrightarrow{DP} = (-2, 0, 1)$ ， $\overrightarrow{DG} = (-2, b, 0), \overrightarrow{AD} = (2, 0, 0)$ ，易知平面 $APD$ 的一个法向量为 $\pmb{n}_1 = (0, 1, 0)$ 。设平面 $PDG$ 的法向量为 $\pmb{n}_2 = (x_2, y_2, z_2)$ ，则 $\left\{ \begin{array}{l} \pmb{n}_2 \cdot \overrightarrow{DP} = 0, \\ \pmb{n}_2 \cdot \overrightarrow{DG} = 0, \end{array} \right.$ 即 $\left\{ \begin{array}{l} -2x_2 + z_2 = 0, \\ -2x_2 + by_2 = 0, \end{array} \right.$ 令 $z_2 = 2$ ，得 $x_2 = 1, y_2 = \frac{2}{b}$ ，所以 $\pmb{n}_2 = \left(1, \frac{2}{b}, 2\right)$ 是平面 $PDG$ 的一个法向量，则二面角 $G - PD - A$ 的平面角的余弦值为 $|\cos \langle \pmb{n}_1, \pmb{n}_2 \rangle| = |\pmb{n}_1 \cdot \pmb{n}_2| / |\pmb{n}_1| |\pmb{n}_2| = \frac{\left|\frac{2}{b}\right|}{\sqrt{5 + \frac{4}{b^2}}} = \frac{\sqrt{3}}{2}$ ，解得 $b = \frac{2\sqrt{15}}{15}$ 或 $b = -\frac{2\sqrt{15}}{15}$ （舍去）。因为点 $Q$ 在线段 $DG$ 上运动，所以 $\triangle ADQ$ 面积的最大值是 $\frac{2\sqrt{15}}{15}$ 。
