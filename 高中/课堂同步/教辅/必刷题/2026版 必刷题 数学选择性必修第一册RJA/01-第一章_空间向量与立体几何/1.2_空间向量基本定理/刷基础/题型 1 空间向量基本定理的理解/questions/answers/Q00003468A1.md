> [!faq]- 必刷题解析
> **【答案】** C
>
> **【解析】**
> 对于 A, 若 x, y, z 不全为 0, 则 a, b, c 共面, 与题意矛盾, 故 A 正确; 点悟: 成为基底的三个向量必不共面
对于 B, a, b, c 是空间的一个基底, 则 a, b, c 两两共面, 但 a, b, c 不共面, 故 B 正确; 对于 C, 由题知 a, b, c 不共面, 则不存在实数 x, y, 使得 $a = xb + yc$ , 故 C 错误; 对于 D, 若 $a + b, b - c, c + 2a$ 共面, 则有 $a + b = k(b - c) + \lambda(c + 2a) (k, \lambda \in \mathbb{R})$ , 即 $\left\{\begin{aligned}&2\lambda=1,\\&k=1,\quad\text{无解},\\&\lambda-k=0,\end{aligned}\right.$ 故 $a + b, b - c, c + 2a$ 不共面, 一定能构成空间的一个基底, 故 D 正确.
>
> 故选 **C**.
