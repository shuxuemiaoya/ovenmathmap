> [!faq]- 答案与解析
>
> > [!success]- **【答案】** AD
>
> > [!note]- **【解析】**
> > 对于 A, 当 t = -1 时, 直线 l: y = -x - 2, 而圆 C 的方程 $x^{2} + y^{2} + 4x - 4 = 0$ 可化为 $(x + 2)^{2} + y^{2} = 8$ , 可知圆心 C(-2, 0), 此时点 C(-2, 0) 在直线 y = -x - 2 上, 所以圆 C 关于直线 l 对称, 故 A 正确; 对于 B, 当 t = 1 时, 直线 l: y = x - 2, 此时圆心 C 到直线 l 的距离为 $\frac{|-2 - 2|}{\sqrt{2}} =$
> >
> > $2\sqrt{2}$ ，由于圆 C 的半径 $r=2\sqrt{2}$ ，所以直线 l 与圆 C 相切，只有一个公共点，故 B 错误；
> > 对于 C, 要使得直线 l 与圆 C 没有交点，则圆心 C 到直线 l 的距离 $\frac{|-2t-2|}{\sqrt{t^{2}+1}} > 2\sqrt{2}$ ，整理得 $(t-1)^{2}<0$ ，此时不等式 $(t-1)^{2}<0$ 无实数解，所以不存在 $t \in R$ ，使得直线 l 与圆 C 没有交点，故 C 错误；
> > 对于 D, 由直线 l 被圆 C 截得的弦长为 $\frac{4\sqrt{30}}{5}$ ，圆心 C 到直线 l 的距离为 $\frac{|-2t-2|}{\sqrt{t^{2}+1}}$ 得 $2\sqrt{(2\sqrt{2})^{2}-\left(\frac{|-2t-2|}{\sqrt{t^{2}+1}}\right)^{2}}=\frac{4\sqrt{30}}{5}$ 化简得 $t^{2}+10t+1=0$ ，解得 $t=-5\pm2\sqrt{6}$ ，故 D 正确. 故选 AD.
