> [!faq]- 答案与解析
>
> > [!success]- **【答案】** 见解析
>
> > [!note]- **【解析】**
> > 因为 $A(1,0,0),B(0,1,0),C(0,0,1)$ 所以 $\overrightarrow{CA} = (1,0, - 1),\overrightarrow{CB} = (0,1, - 1)$ 设平面ABC的法向量为 $\pmb {n} = (a,b,c)$ 则 $\left\{ \begin{array}{l}\overrightarrow{CA}\cdot \pmb {n} = 0,\\ \overrightarrow{CB}\cdot \pmb {n} = 0, \end{array} \right.$ 即 $\left\{ \begin{array}{l}a - c = 0,\\ b - c = 0, \end{array} \right.$ 令 $c = 1$ ，可得 $a = 1,b = 1$ ，即平面ABC的一个法向量 $\pmb {n} = (1,1,1)$ .因为点 $D(x,y,z)\in$ 平面ABC，所以 $\pmb {n}\perp \overrightarrow{CD}$ ，可知 $\overrightarrow{CD} = (x,y,$ $z - 1)$ ，可得 $\pmb {n}\cdot \overrightarrow{CD} = x + y + z - 1 = 0$ ，即 $x+$ $y + z = 1$ 故点 $D$ 的坐标满足 $x + y + z = 1$ 即可，可取 $\left(\frac{1}{2},\frac{1}{2},0\right)$ （本题答案不唯一）.
