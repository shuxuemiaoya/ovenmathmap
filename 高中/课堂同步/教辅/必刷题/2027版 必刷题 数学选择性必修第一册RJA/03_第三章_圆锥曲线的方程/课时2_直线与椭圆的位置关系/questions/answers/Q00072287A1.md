> [!faq]- 答案与解析
>
> > [!success]- **【答案】** B
>
> > [!note]- **【解析】**
> > 设椭圆 C 的长、短半轴长分别为 a, b，由椭圆 C 的离心率为 $\frac{\sqrt{2}}{2}$ ，得 $\frac{\sqrt{a^{2}-b^{2}}}{a}=\frac{\sqrt{2}}{2}$ ，则 $a=\sqrt{2}b$ ，由椭圆 C 的面积为 $4\sqrt{2}\pi$ ，得 $ab\pi=4\sqrt{2}\pi$ ，则 $ab=4\sqrt{2}$ ，因此 $a=2\sqrt{2}$ ，b=2，而椭圆 C 的焦点在 y 轴上，所以椭圆 C 的方程为 $\frac{x^{2}}{4}+\frac{y^{2}}{8}=1$ 。故选 B.
