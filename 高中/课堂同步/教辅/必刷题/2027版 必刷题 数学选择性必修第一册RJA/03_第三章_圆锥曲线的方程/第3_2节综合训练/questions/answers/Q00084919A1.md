>
> > [!success]- **【答案】** D

> > [!note]- **【解析】**
> > D 【解析】∵ 双曲线 $C: \frac{x^{2}}{a^{2}} - \frac{y^{2}}{b^{2}} = 1 (a > 0, b > 0)$ 的一条渐近线方程是 $y = \sqrt{2}x, \therefore \frac{b}{a} = \sqrt{2}$ ，即 $b = \sqrt{2}a$ 。∵ 左焦点 $F(-\sqrt{3}, 0), \therefore c = \sqrt{3}, \therefore c^{2} = a^{2} + b^{2} = 3a^{2} = 3, \therefore a^{2} = 1, b^{2} = 2, \therefore$ 双曲线 C 的方程为 $x^{2} - \frac{y^{2}}{2} = 1$ 。易知直线 l 的方程为 $y = 2(x + \sqrt{3})$ ，设 $A(x_{1}, y_{1})$ ， $B(x_{2}, y_{2})$ ，由 $\left\{\begin{aligned} y &= 2(x + \sqrt{3}), \\ x^{2} - \frac{y^{2}}{2} &= 1 \end{aligned}\right.$ 消去 y 可得 $x^{2} + 4\sqrt{3}x + 7 = 0$ ，则 $\Delta = (4\sqrt{3})^{2} - 4 \times 7 = 20 > 0, \therefore x_{1} + x_{2} = -4\sqrt{3}, x_{1}x_{2} = 7,$ ∴ $|AB| = \sqrt{1 + k^{2}} \times \sqrt{(x_{1} + x_{2})^{2} - 4x_{1}x_{2}} =$ ▶ 散 黑板：弦长公式 $|AB| = \sqrt{1 + k^{2}}$ $|x_{1} - x_{2}| = \sqrt{1 + k^{2}}\sqrt{(x_{1} + x_{2})^{2} - 4x_{1}x_{2}}, k$ 为直线 AB 的斜率， $x_{1}, x_{2}$ 为交点的横坐标 $\sqrt{1 + 4} \times \sqrt{48 - 28} = 10$ 。
> >
> > 故选 **D**。
