> [!faq]- 答案与解析
>
> > [!success]- **【答案】** 见解析
>
> > [!note]- **【解析】**
> > (1)设直线 $AB: x - 2 = m(y - 1)$ ， $A(x_1, y_1)$ ， $B(x_2, y_2)$ ，联立 $\left\{ \begin{array}{l} x = my - m + 2, \\ y^2 = 4x \end{array} \right.$ 得 $y^2 - 4my + 4m - 8 = 0$ ， $\Delta_1 > 0$ ，所以 $y_1 + y_2 = 4m = 2$ ，解得 $m = \frac{1}{2}$ ，所以直线 $l_1$ 的斜率 $k_1 = 2$ ，直线 $l_2$ 的斜率 $k_2 = -\frac{1}{2}$ ，所以直线 $l_1, l_2$ 的斜率之和 $k_1 + k_2 = \frac{3}{2}$ .
> >
> > (2)由(1)可得 $y_1 + y_2 = 2, y_1y_2 = -6$ ，则 $|AB| = \sqrt{(m^2 + 1)(y_1 - y_2)^2} = \sqrt{\left(\frac{1}{2}\right)^2 + 1} \cdot \sqrt{(y_1 + y_2)^2 - 4y_1y_2} = \sqrt{35}$ ，由(1)可得直线 $CD: x = -2y + 4$ ，设 $C(x_3, y_3), D(x_4, y_4)$ ，联立 $\left\{ \begin{array}{l} x = -2y + 4, \\ y^2 = 4x \end{array} \right.$ 得 $y^2 + 8y - 16 = 0$ ， $\Delta_2 > 0$ ，所以 $y_3 + y_4 = -8, y_3y_4 = -16$ ，可得 $|CD| = \sqrt{[1 + (-2)^2](y_3 - y_4)^2} = \sqrt{5[(y_3 + y_4)^2 - 4y_3y_4]} = 8\sqrt{10}$ ，故 $\frac{|CD|}{|AB|} = \frac{8\sqrt{14}}{7}$ .
