>
> > [!success]- **【答案】** BCD
>
> > [!note]- **【解析】**
> > 对于 A, 抛物线在点 A 处的切线方程为 $x_{1}x = 2(y + y_{1})$ ，斜率为 $\frac{x_{1}}{2}$ ，∴ 直线 l 的方程为 $y = \frac{x_{1}}{2}(x - x_{2}) + y_{2}$ ，代入 $x^{2} = 4y$ 中，并化简得 $x^{2} - 2x_{1}x + 2x_{1}x_{2} - 4y_{2} = 0$ ，该方程的解为 $x_{2}, x_{3}$ ，由根与系数的关系可知 $x_{2} + x_{3} = 2x_{1}$ ，A 选项错误。
> > 对于 B，设 $E(0, y_{0})$ ，代入 $y = \frac{x_{1}}{2}(x - x_{2}) + y_{2}$ 可解得 $y_{0} = -\frac{x_{1}x_{2}}{2} + y_{2}$ ，∵ $k_{AB} = \frac{y_{2} - y_{1}}{x_{2} - x_{1}} = \frac{\frac{x_{2}^{2}}{4} - \frac{x_{1}^{2}}{4}}{x_{2} - x_{1}} = \frac{x_{2} + x_{1}}{4}$ ，∴ 直线 AB 的方程为 $y - \frac{x_{1}^{2}}{4} = \frac{x_{2} + x_{1}}{4}(x - x_{1})$ ，化简得 $4y - (x_{1} + x_{2})x + x_{1}x_{2} = 0$ ，直线 AB 过点 $F(0, 1)$ ，∴ $x_{1}x_{2} = -4$ ，∴ $y_{0} = 2 + y_{2}$ ，又∵ $|FB| = y_{2} + 1 = y_{0} - 2 + 1 = y_{0} - 1$ ， $|FE| = y_{0} - 1$ ，∴ $|FB| = |FE|$ ，B 选项正确.
> > 对于 C，直线 l 的方程可化为 $y=\frac{x_{1}x}{2}+2+y_{2}=\frac{x_{1}x}{2}+2+\frac{x_{2}^{2}}{4}=\frac{x_{1}x}{2}+2+\frac{4}{x_{1}^{2}}$ ，即 $x_{1}x-2y+4+\frac{8}{x_{1}^{2}}=0$ ，则 $|BD|=\sqrt{1+\left(\frac{x_{1}}{2}\right)^{2}}|x_{2}-x_{3}|$ ，由点到直线的距离公式可得点 A 到直线 l 的距离 $d=\frac{|x_{1}^{2}-2y_{1}+4+\frac{8}{x_{1}^{2}}|}{\sqrt{x_{1}^{2}+4}}$ $\therefore \triangle ABD$ 的面积 $S = \frac{1}{2}\sqrt{1 + \left(\frac{x_1}{2}\right)^2}\cdot$ $|x_{2} - x_{3}|\cdot \frac{\left|x_{1}^{2} - 2y_{1} + 4 + \frac{8}{x_{1}^{2}}\right|}{\sqrt{x_{1}^{2} + 4}}$ $= \frac{1}{4}|x_{2} - x_{3}|\cdot \left|2y_{1} + 4 + \frac{2}{y_{1}}\right|$ $= |x_{1} - x_{2}|\cdot \left|y_{1} + 2 + \frac{1}{y_{1}}\right|$ $= \left|x_1 + \frac{4}{x_1}\right|\cdot \left|y_1 + 2 + \frac{1}{y_1}\right|$
