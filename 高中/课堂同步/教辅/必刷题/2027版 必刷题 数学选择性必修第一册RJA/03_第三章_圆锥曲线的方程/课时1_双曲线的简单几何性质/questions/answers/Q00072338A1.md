> > 设弦 AC 所在直线与 x 轴正方向的夹角为 $\theta$ ，则 $|AC| = \frac{2ab^{2}}{a^{2} - c^{2}\cos^{2}\theta}, |BD| = \frac{2ab^{2}}{a^{2} - c^{2}\sin^{2}\theta}, \therefore$ 四边形 ABCD 的面积 $S = \frac{2a^{2}b^{4}}{a^{4} - a^{2}c^{2} + c^{4}\cos^{2}\theta\sin^{2}\theta} \leqslant \frac{2a^{2}b^{4}}{a^{4} - a^{2}c^{2}} = \frac{2b^{4}}{b^{2}} = 2b^{2} = \frac{25}{2}, \therefore b^{2} = \frac{25}{4};$ $S = \frac{2a^{2}b^{4}}{a^{4} - a^{2}c^{2} + c^{4}\cos^{2}\theta\sin^{2}\theta} \geqslant \frac{2a^{2}b^{4}}{a^{4} - a^{2}c^{2} + \frac{1}{4}c^{4}} = \frac{2b^{4}}{b^{2} + \frac{1}{4} \cdot \frac{c^{4}}{a^{2}}} = \frac{2b^{2}}{1 + \frac{1}{4} \cdot \frac{c^{4}}{a^{2}b^{2}}} = 8, \therefore \frac{c^{4}}{a^{2}b^{2}} = \frac{9}{4}, \therefore a = 5, \therefore \frac{a}{b} = 2.$ 二级结论 在椭圆 $\frac{x^{2}}{a^{2}} + \frac{y^{2}}{b^{2}} = 1 (a > b > 0)$ 中，点 P 为椭圆上一点.
