-\overrightarrow{AA_1},$ 而 $\overrightarrow{A_1N} = x\overrightarrow{CA} +y\overrightarrow{C_1B_1} +z\overrightarrow{AA_1},$ 则 $x = -\frac{1}{2},y = \frac{1}{2},z = -1,$ 所以 $x + y + z = -\frac{1}{2} +\frac{1}{2} -1 = -1.$ (2)设 $\overrightarrow{C_1M} = \lambda \overrightarrow{C_1B_1} (\lambda \in [0,1])$ ，则 $\overrightarrow{AM} = \overrightarrow{AA_1} +\overrightarrow{A_1C_1} +\overrightarrow{C_1M} = \overrightarrow{CC_1} -\overrightarrow{CA}+$ $\lambda \overrightarrow{CB}$ .由题意可设 $|\overrightarrow{CA}| = |\overrightarrow{CB}| =$ $|\overrightarrow{CC_1}| = 1,$ 因为 $CC_{1}\bot$ 平面 $ABC,CA\subset$ 平面 $ABC,CB\subset$ 平面 $ABC$ ，所以 $CC_{1}\bot$ $CA,CC_{1}\bot CB.$ 又 $\langle \overrightarrow{CA},\overrightarrow{CB}\rangle = 120^{\circ},\langle \overrightarrow{CA},\overrightarrow{CC_1}\rangle =$ $\langle \overrightarrow{CB},\overrightarrow{CC_1}\rangle = 90^{\circ}$ ，则 $\overrightarrow{CA}\cdot \overrightarrow{CB} =$ $-\frac{1}{2},\overrightarrow{CA}\cdot \overrightarrow{CC_1} = \overrightarrow{CB}\cdot \overrightarrow{CC_1} = 0.$ 由(1)知 $\overrightarrow{A_1N} = -\frac{1}{2}\overrightarrow{CA} +\frac{1}{2}\overrightarrow{CB} -\overrightarrow{CC_1},$ 因为 $AM\bot A_{1}N$ ，所以 $\overrightarrow{AM}\cdot \overrightarrow{A_1N} = 0,$ 即 $(\overrightarrow{CC_1} -\overrightarrow{CA} +\lambda \overrightarrow{CB})\cdot (-\frac{1}{2}\overrightarrow{CA}+$ $\frac{1}{2}\overrightarrow{CB} -\overrightarrow{CC_1}) = 0,$ 所以 $-\frac{1}{2}\overrightarrow{CC_1}\cdot \overrightarrow{CA} +\frac{1}{2}\overrightarrow{CC_1}\cdot \overrightarrow{CB}-$ $\overline{CC_1^2} +\frac{1}{2}\overrightarrow{CA^2} -\frac{1}{2}\overrightarrow{CA}\cdot \overrightarrow{CB} +\overline{CC_1}\cdot$ $\overrightarrow{CA} -\frac{1}{2}\lambda \overrightarrow{CA}\cdot \overrightarrow{CB} +\frac{1}{2}\lambda \overrightarrow{CB^2} -\lambda \overrightarrow{CB}\cdot$ $\overline{CC_1} = 0.$ 所以 $0 + 0 - 1 + \frac{1}{2} +\frac{1}{4} +0-$ $\left(\frac{1}{2}\lambda\right)\cdot \left(-\frac{1}{2}\right) + \frac{1}{2}\lambda -0 = 0,$ 即 $\frac{3}{4}\lambda = \frac{1}{4},$ 解得 $\lambda = \frac{1}{3},$ 所以
