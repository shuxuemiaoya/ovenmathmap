> [!faq]- 答案与解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【解析】**
> > 【解】(1)由题可知， $\overrightarrow{BC} = (-2, -1, 2)$ 。由 $c // \overrightarrow{BC}$ 可设 $c = k\overrightarrow{BC}(k \in \mathbf{R})$ ，则 $c = (-2k, -k, 2k)$ 。因为 $|c| = 3$ ，所以 $(-2k)^2 + (-k)^2 + (2k)^2 = 3^2$ ，解得 $k = \pm 1$ ，所以 $c = (-2, -1, 2)$ 或 $c = (2, 1, -2)$ 。（2）因为 $A(-2, 0, 2), B(-1, 1, 2)$ ， $C(-3, 0, 4), a = \overrightarrow{AB}, b = \overrightarrow{AC}$ ，所以 $a = (1, 1, 0), b = (-1, 0, 2)$ ，则 $\cos \langle a, b \rangle = \frac{a \cdot b}{|a||b|} = \frac{-1}{\sqrt{2} \times \sqrt{5}} = -\frac{\sqrt{10}}{10}$ 。（3）因为 $ka + b = (k - 1, k, 2), ka - 2b = (k + 2, k, -4)$ ，又 $ka + b$ 与 $ka - 2b$ 垂直，所以 $(ka + b) \cdot (ka - 2b) = (k - 1)(k + 2) + k^2 - 8 = 0$ ，解得 $k = -\frac{5}{2}$ 或 $k = 2$ 。
