> > C 【解析】∵ $\overrightarrow{PG} = \overrightarrow{PA} + \overrightarrow{AG} = \overrightarrow{PA} + \frac{2}{3} \times \frac{1}{2} (\overrightarrow{AB} + \overrightarrow{AC}) = \overrightarrow{PA} + \frac{1}{3} (\overrightarrow{AP} + \overrightarrow{PB} + \overrightarrow{AP} + \overrightarrow{PC}) = \frac{1}{3} \overrightarrow{PA} + \frac{1}{3} \overrightarrow{PB} + \frac{1}{3} \overrightarrow{PC},$ ∴ $\overrightarrow{PM} = \frac{1}{2} \overrightarrow{PG} = \frac{1}{6} (\overrightarrow{PA} + \overrightarrow{PB} + \overrightarrow{PC}).$ ∵ $\overrightarrow{PD} = \lambda \overrightarrow{PA}, \overrightarrow{PE} = \mu \overrightarrow{PB}, \overrightarrow{PF} = \frac{1}{2} \overrightarrow{PC},$ ∴ $\overrightarrow{PM} = \frac{1}{6\lambda} \overrightarrow{PD} + \frac{1}{6\mu} \overrightarrow{PE} + \frac{1}{3} \overrightarrow{PF}.$ ∵ M, D, E, F 四点共面，且点 P 在平面 DEF 外，∴ $\frac{1}{6\lambda} + \frac{1}{6\mu} + \frac{1}{3} = 1$ ，即 $\frac{1}{\lambda} + \frac{1}{\mu} = 4.$ ∵ $\lambda + \mu = \frac{1}{4} (\lambda + \mu) \left( \frac{1}{\lambda} + \frac{1}{\mu} \right) = \frac{1}{4} (2 + \frac{\mu}{\lambda} + \frac{\lambda}{\mu}) \geqslant 1$ ，当且仅当 $\lambda = \mu = \frac{1}{2}$ 时，等号成立，∴ $\lambda + \mu$ 的最小值为 1。
