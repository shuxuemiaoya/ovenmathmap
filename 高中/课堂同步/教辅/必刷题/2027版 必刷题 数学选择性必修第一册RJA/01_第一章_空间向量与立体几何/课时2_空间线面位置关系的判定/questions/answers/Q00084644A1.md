> [!faq]- 答案与解析
>
> > [!success]- **【答案】** B
>
> > [!note]- **【解析】**
> > 因为 $e_1, e_2, e_3$ 为空间内三个不共面的向量，所以 $\{e_1, e_2, e_3\}$ 可以作为空间的一个基底，又平面 $\alpha$ 和平面 $\beta$ 的法向量分别为 $a = e_1 + \lambda e_2 + 3e_3$ 和 $b = -e_1 + 2e_2 + \mu e_3$ 且 $\alpha // \beta$ 所以 $a // b$ ，则 $a = tb (t \in \mathbf{R})$ ，即 $\rightarrow$ 故黑板：由面面平行得到两法向量平行是解题关键 $e_1 + \lambda e_2 + 3e_3 = t (-e_1 + 2e_2 + \mu e_3)$ ，所以 $\left\{ \begin{array}{l} -t = 1, \\ 2t = \lambda, \\ t\mu = 3, \end{array} \right.$ 解得 $\left\{ \begin{array}{l} t = -1, \\ \lambda = -2, \\ \mu = -3, \end{array} \right.$ 所以 $\lambda + \mu = -5.$ 故选 B.
