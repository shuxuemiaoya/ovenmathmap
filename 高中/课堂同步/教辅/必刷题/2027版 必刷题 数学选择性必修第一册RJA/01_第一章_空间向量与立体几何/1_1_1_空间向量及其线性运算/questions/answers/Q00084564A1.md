> [!faq]- 答案与解析
>
> > [!success]- **【答案】** D
>
> > [!note]- **【解析】**
> > D 【解析】由 $\overrightarrow{AC} = \overrightarrow{OC} - \overrightarrow{OA}$ ，得 $\overrightarrow{OA} = 2m\overrightarrow{OB} + n\overrightarrow{OD} + k\overrightarrow{OC} - k\overrightarrow{OA}$ ，则 $(k+1) \cdot \overrightarrow{OA} = 2m\overrightarrow{OB} + n\overrightarrow{OD} + k\overrightarrow{OC}$ ，显然 $k \neq -1$ ，否则 $\overrightarrow{OC} = 2m\overrightarrow{OB} + n\overrightarrow{OD}$ ，即点 O, B, C, D 共面，矛盾，因此 $\overrightarrow{OA} = \frac{2m}{k+1}\overrightarrow{OB} + \frac{n}{k+1}\overrightarrow{OD} + \frac{k}{k+1}\overrightarrow{OC}$ 。由共面向量
> >
> > 敲黑板：注意公式特点：各向量的起点是平面 ABCD 外一点 O
> >
> > 定理的推论，得 $\frac{2m}{k+1} + \frac{n}{k+1} + \frac{k}{k+1} = 1$ ，所以 $2m + n = 1$ 。故选 D。
> >
> > 二级结论 如果点 A, B, C 不共线，且点 O 不在平面 ABC 内，那么对空间中任意一点 P，存在唯一的有序实数组 $(x, y, z)$ ，使得 $\overrightarrow{OP} = x\overrightarrow{OA} + y\overrightarrow{OB} + z\overrightarrow{OC}$ ，其中 $x + y + z = 1 \Leftrightarrow P, A, B, C$ 四点共面。
