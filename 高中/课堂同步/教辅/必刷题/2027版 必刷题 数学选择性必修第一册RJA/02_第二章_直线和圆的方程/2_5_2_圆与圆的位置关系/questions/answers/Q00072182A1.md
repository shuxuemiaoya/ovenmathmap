> [!faq]- 答案与解析
>
> > [!success]- **【答案】** B
>
> > [!note]- **【解析】**
> > B 【解析】圆 $C:(x+2)^{2}+(y-1)^{2}=1$ 的圆心 $C(-2,1)$ ，半径 r=1，将点 A 的坐标代入圆 C 的方程等号的左端，得 $1^{2}+(-3)^{2}=10>1$ ，则点 A 在圆 C 外。当 l 的斜率不存在时，直线 l 的方程为避坑：不要遗漏斜率不存在的情况 x=-1，点 C 到直线 x=-1 的距离为 1，满足题意；当 l 的斜率存在时，设 l 的方程为 $y=k(x+1)-2$ ，由直线 l 与圆 C 相切，得 $\frac{|-k-3|}{\sqrt{k^{2}+1}}=1$ ，解得 $k=-\frac{4}{3}$ ，则 l 的方程为 $y=-\frac{4}{3}(x+1)-2$ ，即 $4x+3y+10=0$ ，所以直线 l 的方程为 $x+1=0$ 或 $4x+3y+10=0$ 。故选 B.
> >
> > 归纳总结 过圆上一点作切线,可通过该点坐标与圆的方程直接写出切线方程,或利用圆心与切点连线垂直于切线求切线的斜率.过圆外一点作切线,通常设直线的点斜式方程,利用圆心到直线的距离等于半径解出切线的斜率,此时需讨论斜率不存在的情况是否满足题意,并注意切线方程通常有两解.
