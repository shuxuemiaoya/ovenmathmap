> [!faq]- 答案与解析
>
> > [!success]- **【答案】** B
>
> > [!note]- **【解析】**
> > 已知圆 $C_1: x^2 + y^2 - 2x = 0$ ，即 $(x - 1)^2 + y^2 = 1$ ，则圆心 $C_1(1, 0)$ ，半径 $r_1 = 1$ ；圆 $C_2: x^2 + y^2 + mx - 4y + n = 0$ ，即 $\left(x + \frac{m}{2}\right)^2 + (y - 2)^2 = \frac{m^2}{4} - n + 4$ ，则 $\frac{m^2}{4} - n + 4 > 0$ ①，圆心 $C_2\left(-\frac{m}{2}, 2\right)$ ，半径 $r_2 = \sqrt{\frac{m^2}{4} - n + 4}$ 。由题意可知两圆相交，所以 $\left|\sqrt{\frac{m^2}{4} - n + 4} - 1\right| < \sqrt{\left(-\frac{m}{2} - 1\right)^2 + 4} < \sqrt{\frac{m^2}{4} - n + 4} + 1$ ②。两圆方程作差可得 $(m + 2)x - 4y + n = 0$ ，即公共弦所在直线的方程为 $(m + 2)x - 4y + n = 0$ 。因为圆 $C_2$ 平分圆 $C_1$ 的周长，所以公共弦所在直线过点
> >
> > $C_{1}(1,0)$ ，故 $m+2+n=0$ ，即 $m+n=-2$ ，经检验，满足①②。故选 B.
