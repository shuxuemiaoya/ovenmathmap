> [!faq]- 答案与解析
>
> > [!success]- **【答案】** C
>
> > [!note]- **【解析】**
> > C 【解析】设 $P(x, y)$ ，则 $(x-1)^{2} + (y+1)^{2} = 16$ ，圆 C 的圆心为 $(1, -1)$ ，半径为 4。因为 $PA \perp PB$ ，所以 P 在以 AB 为直径的圆上（不包括 A, B 两点），圆心为 $(-2, 3)$ ，半径为 $\frac{|AB|}{2} = \sqrt{2}$ ，
> >
> > 敲黑板：圆的直径所对的圆周角是 $90^{\circ}$ ，反之也成立
> >
> > 即 $(x+2)^{2} + (y-3)^{2} = 2$ 。因为 $|4 - \sqrt{2}| < \sqrt{(-2-1)^{2} + (3+1)^{2}} = 5 < 4 + \sqrt{2}$ ，所以 $\text{圆}(x-1)^{2} + (y+1)^{2} = 16$ 与圆 $(x+2)^{2} + (y-3)^{2} = 2$ 相交，所以点 P 的个数为 2。
> >
> > 故选 **C**.
