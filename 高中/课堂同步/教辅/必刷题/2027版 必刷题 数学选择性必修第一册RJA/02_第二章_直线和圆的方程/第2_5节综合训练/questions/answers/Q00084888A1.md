>
> > [!success]- **【答案】** A
>
> > [!note]- **【解析】**
> > A 【解析】由圆 $C: x^{2} + y^{2} - 6y = 0$ ，得 $C: x^{2} + (y - 3)^{2} = 9$ ，所以圆 C 的圆心的坐标为 $(0, 3)$ ，半径 r = 3，所以圆心 C 到直线 $l: x - y + 6 = 0$ 的距离 $d = \frac{|0 - 3 + 6|}{\sqrt{1^{2} + (-1)^{2}}} = \frac{3\sqrt{2}}{2}$ ，所以直线 l 与圆 C 相交的弦长 $|AB| = 2\sqrt{r^{2} - d^{2}} = 2\sqrt{9 - \left(\frac{3\sqrt{2}}{2}\right)^{2}} = 3\sqrt{2}$ 。
> >
> > 故选 **A**.
