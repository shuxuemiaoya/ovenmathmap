> [!faq]- 答案与解析
>
> > [!success]- **【答案】** C
>
> > [!note]- **【解析】**
> > 因为直线 $mx + ny = 2$ 与圆 $C: x^{2} + y^{2} = 4$ 没有公共点，所以直线 $mx + ny = 2$ 与圆 $C: x^{2} + y^{2} = 4$ 相离，所以圆心 $(0, 0)$ 到直线 $mx + ny = 2$ 的距离 $d_{1} = \frac{|-2|}{\sqrt{m^{2} + n^{2}}} > 2$ ，即 $m^{2} + n^{2} < 1$ ，则圆心 $(0, 0)$ 到直线 $nx + my = 4$ 的距离 $d_{2} = \frac{|-4|}{\sqrt{n^{2} + m^{2}}} > 2$ ，所以直线 $nx + my = 4$ 与圆 $C: x^{2} + y^{2} = 4$ 相离。故选 C.
