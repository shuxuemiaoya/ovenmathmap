> [!faq]- 答案与解析
>
> > [!success]- **【答案】** ACD
>
> > [!note]- **【解析】**
> > ACD 【解析】因为 $\frac{|PM|}{|PN|} = \frac{1}{2}$ ，所以 $\frac{\sqrt{(x-1)^{2}+(y-0)^{2}}}{\sqrt{(x-4)^{2}+(y-0)^{2}}} = \frac{1}{2} \Leftrightarrow$ $\frac{(x-1)^{2}+(y-0)^{2}}{(x-4)^{2}+(y-0)^{2}} = \frac{1}{4} \Leftrightarrow$ $\frac{x^{2}-2x+1+y^{2}}{x^{2}-8x+16+y^{2}} = \frac{1}{4}$ ，化简得到 $x^{2} + y^{2} = 4$ ，点 P 的轨迹方程为 $x^{2} + y^{2} = 4$ ，选项 A 正确. $x^{2} + y^{2} - 6y + 10 = x^{2} + (y - 3)^{2} + 1$ ，其几何意义为点 P 到定点 $(0,3)$ 距离的平方加 1，因为点 P 在圆 O: $x^{2} + y^{2} = 4$ 上，圆心为 O(0,0)，半径 $r_{1} = 2$ ，点 $(0,3)$ 到圆心 O 的距离为 d = 3，则点 $(0,3)$ 与圆 O 上一点的最大距离为 $d + r_{1} = 5$ ，所以 $x^{2} + y^{2} - 6y + 10$ 的最大值为 $5^{2} + 1 = 26$ ，选项 B 错误.
> >
> > 圆 C: $(x - 3)^{2} + (y - 3)^{2} = 4$ ，圆心为 C(3,3)，半径 $r_{2} = 2$ ，圆 O 与圆 C 的圆心距为 $|OC| = \sqrt{(3 - 0)^{2} + (3 - 0)^{2}} = 3\sqrt{2}$ ，则 $|PQ|$ 的最小值为 $|OC| - r_{1} - r_{2} = 3\sqrt{2} - 2 - 2 = 3\sqrt{2} - 4$ ; $|PQ|$ 的最大值为 $|OC| + r_{1} + r_{2} = 3\sqrt{2} + 2 + 2 = 3\sqrt{2} + 4$ ，所以 $|PQ|$ 的取值范围是 $[3\sqrt{2} - 4, 3\sqrt{2} + 4]$ ，C 正确.
> >
> > 当 $\angle EPF = 90^{\circ}$ 时，四边形 PECF 为正方形，此时 $|PC| = 2\sqrt{2}$ ，因为点 P 到 C(3,3) 的最小距离为 $|OC| - r_{1} = 3\sqrt{2} - 2 < 2\sqrt{2}$ ，最大距离为 $|OC| + r_{1} = 3\sqrt{2} + 2 > 2\sqrt{2}$ ，则存在点 P，使得 $\angle EPF = 90^{\circ}$ ，D 正确。
> >
> > 故选 **ACD**.
