> > $\sqrt{2}$ 【解析】已知两条直线 $a_1x + b_1y + 1 = 0$ 和 $a_2x + b_2y - 1 = 0$ 都经过点 $A(1,1)$ ，则 $a_1 + b_1 + 1 = 0,a_2 + b_2 - 1 =$ 多种解法 在直线 $l: x + 2y + 3 = 0$ 上取一点 $A(-3, 0)$ ，点 $A(-3, 0)$ 关于直线 $x + y = 0$ 对称的点为 $B(0, 3)$ 。直线 $x + 2y + 3 = 0$ 与直线 $x + y = 0$ 的交点为 $C(3, -3)$ ，所以直线 $l'$ 的方程即为直线 BC 的方程，为 $\frac{y + 3}{3 + 3} = \frac{x - 3}{0 - 3}$ ，化简得 $2x + y - 3 = 0$ 。故选 A.
> >
> > 二级结论 与直线 $Ax + By + C = 0$ 关于 $x$ 轴对称的直线的方程为 $Ax - By + C = 0$ ；与直线 $Ax + By + C = 0$ 关于 $y$ 轴对称的直线的方程为 $-Ax + By + C = 0$ ；与直线 $Ax + By + C = 0$ 关于直线 $y = x$ 对称的直线的方程为 $Ay + Bx + C = 0$ ；与直线 $Ax + By + C = 0$ 关于直线 $y = -x$ 对称的直线的方程为 $-Ay - Bx + C = 0$ 。
> >
> > 规律方法 求直线 $l_{1}: A_{1}x + B_{1}y + C_{1} = 0$ 关于直线 $l_{2}: A_{2}x + B_{2}y + C_{2} = 0 (l_{1}$ 与 $l_{2}$ 相交)对称的直线 $l_{3}$ 的方程
> >
> > 方法一：在已知直线 $l_{1}$ 上任取一点（不为交点），然后得到关于 $l_{2}$ 的对称点，再结合 $l_{1}$ 与 $l_{2}$ 的交点求解 $l_{3}$ 的方程。
> >
> > 方法二：设已知直线 $l_{1}$ 上一点 $P$ 的坐标，点 $P$ 关于 $l_{2}$ 的对称点为 $(x, y)$ ，用 $x, y$ 表示点 $P$ 的坐标，再代入 $l_{1}$ 的方程求出 $l_{3}$ 的方程。

> > 专题3 与直线有关的最值问题
> > 0,两式相减得 $a_{1}-a_{2}+b_{1}-b_{2}+2=0$ ,即 $b_{1}-b_{2}=-2-(a_{1}-a_{2})$ . 则 $|P_{1}P_{2}|=\sqrt{(a_{1}-a_{2})^{2}+(b_{1}-b_{2})^{2}}=\sqrt{2(a_{1}-a_{2}+1)^{2}+2}\geqslant\sqrt{2}$ ，即两点 $P_{1},P_{2}$ 间的最短距离为 $\sqrt{2}$ .
> > 多种解法 因为两条直线 $a_{1}x+b_{1}y+1=0$ 和 $a_{2}x+b_{2}y-1=0$ 都经过点 A(1,1)，所以 $a_{1}+b_{1}+1=0,a_{2}+b_{2}-1=0$ ，所以 $P_{1}(a_{1},b_{1}),P_{2}(a_{2},b_{2})$ 分别在直线 $x+y+1=0,x+y-1=0$ 上，所以两点 $P_{1}(a_{1},b_{1}),P_{2}(a_{2},b_{2})$ 间的最短距离为两平行直线间的距离，即 $|P_{1}P_{2}|_{\min}=\frac{|1+1|}{\sqrt{2}}=\sqrt{2}.$
