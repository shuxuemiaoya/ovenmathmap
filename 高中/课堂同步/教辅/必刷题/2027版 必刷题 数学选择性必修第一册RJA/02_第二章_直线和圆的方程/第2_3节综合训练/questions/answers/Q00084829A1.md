>
> > [!success]- **【答案】** 1
>
> > [!note]- **【解析】**
> > 由题意可得 $|AB| = \sqrt{\left(x + \frac{1}{x} - 1\right)^2 + \left(x - \frac{1}{x} - 0\right)^2} = \sqrt{\left(x + \frac{1}{x} - 1\right)^2 + \left(x - \frac{1}{x}\right)^2} = \sqrt{x^2 + 2 + \frac{1}{x^2} - 2x - \frac{2}{x} + 1 + x^2 - 2 + \frac{1}{x^2}} = \sqrt{2x^2 + \frac{2}{x^2} - 2x - \frac{2}{x} + 1} = \sqrt{2\left(x + \frac{1}{x}\right)^2 - 2\left(x + \frac{1}{x}\right) - 3},$ 令 $t = x + \frac{1}{x}$ ，由于 $x \geqslant 1$ ，函数 $t = x + \frac{1}{x}$ 在 $[1, +\infty)$ 上单调递增，故 $t = x + \frac{1}{x} \geqslant 1 + \frac{1}{1} = 2$ ，则 $\sqrt{2\left(x + \frac{1}{x}\right)^2 - 2\left(x + \frac{1}{x}\right) - 3} = \sqrt{2t^2 - 2t - 3} = \sqrt{2\left(t - \frac{1}{2}\right)^2 - \frac{7}{2}},$ 由于 $t \geqslant 2, y = 2\left(t - \frac{1}{2}\right)^2 - \frac{7}{2}$ 在 $[2, +\infty)$ 上单调递增，故 $2\left(t - \frac{1}{2}\right)^2 - \frac{7}{2} \geqslant 2\left(2 - \frac{1}{2}\right)^2 - \frac{7}{2} = 1,$ 即 $\sqrt{2\left(t - \frac{1}{2}\right)^2 - \frac{7}{2}}$ 的最小值为 1，当且仅当 $t = 2$ ，即 $x = 1$ 时取等号，故动点 $A\left(x + \frac{1}{x}, x - \frac{1}{x}\right)$ 与点 $B(1,0)$ 的距离的最小值是 1.
