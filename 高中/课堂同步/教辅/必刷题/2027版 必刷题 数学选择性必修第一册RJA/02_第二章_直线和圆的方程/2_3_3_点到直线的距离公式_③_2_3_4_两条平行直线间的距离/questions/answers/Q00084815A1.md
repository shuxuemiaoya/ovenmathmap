> [!faq]- 答案与解析
>
> > [!success]- **【答案】** B
>
> > [!note]- **【解析】**
> > ∵ 直线 $l_{1}: 5x - 12y + 4 = 0$ ，即 $10x - 24y + 8 = 0, \therefore$ 斜率 $k_{1} = \frac{5}{12}$ .
> >
> > ∵ 直线 $l_{2}: 10x - 24y - 5 = 0, \therefore$ 斜率 $k_{2} = \frac{10}{24} = \frac{5}{12}, \therefore k_{1} = k_{2} = \frac{5}{12}$ ，显然两直线不重合，∴ $l_{1} // l_{2}$ . 则 $|PQ|$ 的最小值即为两平行直线间的距离，由两平行直线间的距离公式可得直线 $l_{1}$ 与 $l_{2}$ 之间的距离 $d = \frac{|8 - (-5)|}{\sqrt{10^{2} + (-24)^{2}}} = \frac{13}{26} = \frac{1}{2}$ ，即 $|PQ|$ 的最小值为 $\frac{1}{2}$ . 故选 B.
