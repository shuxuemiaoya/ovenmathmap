> [!faq]- 答案与解析
>
> > [!success]- **【答案】** C
>
> > [!note]- **【解析】**
> > C 【解析】由题意知 $ab \neq 0$ ，则直线 l 的方程为 $\frac{x}{a} + \frac{y}{b} = 1$ ，则 $\frac{4}{a} + \frac{-3}{b} = 1$ ①，又 $\log_{a} b = 2, \therefore b = a^{2}$ ②.
> > 由①②解得 a = 3, b = 9 或 a = 1, b = 1.
> > 又由 $\log_{a} b = 2$ 知 a > 0, $a \neq 1$ , b > 0，则 a = 3, b = 9，则直线 l 的斜率为 $-\frac{b}{a} = -3$ .
> >
> > 故选 **C**.
