> [!faq]- 答案与解析
>
> > [!success]- **【答案】** AC
>
> > [!note]- **【解析】**
> > AC 【解析】当 a = -2 时， $F(x) = x^{-2}$ ，定义域为 $\{x \mid x \neq 0\}$ ，关于原点对称，且 $F(-x) = (-x)^{-2} = x^{-2} = F(x)$ ，所以 $F(x) = x^{-2}$ 为偶函数，故 A 符合；
> > 当 a = 1 时， $F(x) = x$ ，定义域为 R，且 $F(x) = x$ 为奇函数，故 B 不符合；
> > 当 a=4 时， $F(x)=x^{4}$ ，定义域为 R，且 $F(-x)=(-x)^{4}=x^{4}=F(x)$ 所以 $F(x)=x^{4}$ 为偶函数，故 C 符合；
> >
> > 当 $a = \frac{1}{2}$ 时， $F(x) = x^{\frac{1}{2}} = \sqrt{x}$ ，定义域为 $[0, +\infty)$ ，不关于原点对称，所以 $F(x) = x^{\frac{1}{2}}$ 为非奇非偶函数，故D不符合故选AC.
> >
> > 易错警示 $F(x)=x^{\frac{1}{2}}=\sqrt{x}$ 虽然指数部分分母为偶数,但是其定义域为 $[0,+\infty)$ ,所以 $F(x)=x^{\frac{1}{2}}$ 为非奇非偶函数.
