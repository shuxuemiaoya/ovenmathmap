> [!faq]- 答案与解析
>
> > [!success]- **【答案】** $\frac{\sqrt{10}}{10}$
>
> > [!note]- **【解析】**
> > $f(x) = 2\sin x + \cos x = \sqrt{5}\sin (x + \alpha)$ ，其中 $\cos \alpha = \frac{2}{\sqrt{5}}, \sin \alpha = \frac{1}{\sqrt{5}}$ ， $\alpha$ 为锐角。 $\because$ 当 $x = \theta$ 时，函数 $f(x)$ 取得最小值， $\therefore \sqrt{5}\sin (\theta + \alpha) = -\sqrt{5}$ ，即 $\sin (\theta + \alpha) = -1$ ， $\therefore \cos (\theta + \alpha) = 0$ 。
> > 故可令 $\theta + \alpha = -\frac{\pi}{2}$ ，即 $\theta = -\frac{\pi}{2} - \alpha$ ，
> > 故 $\cos \left( \theta + \frac{\pi}{4} \right) = \cos \left( -\frac{\pi}{4} - \alpha \right) = \cos (\alpha +$ $\frac{\pi}{4}) = \frac{\sqrt{2}}{2}\cos \alpha -\frac{\sqrt{2}}{2}\sin \alpha = \frac{\sqrt{2}}{2}\times \left(\frac{2}{\sqrt{5}} -\right.$ $\frac{1}{\sqrt{5}})\equiv \frac{\sqrt{10}}{10}.$ 10. $\frac{5\sqrt{3}}{11}$ 【解析】 $\because \frac{\pi}{2} <  \alpha <  \pi ,0 <   \beta <  \frac{\pi}{2},$ $\therefore \frac{\pi}{4} <  \alpha -\frac{\beta}{2} <  \pi , - \frac{\pi}{4} <  \frac{\alpha}{2} - \beta <  \frac{\pi}{2},$ $\therefore \sin \left(\alpha -\frac{\beta}{2}\right) = \sqrt{1 - \cos^2\left(\alpha -\frac{\beta}{2}\right)} = \frac{\sqrt{21}}{7},$ $\cos \left(\frac{\alpha}{2} -\beta\right) = \sqrt{1 - \sin^2\left(\frac{\alpha}{2} -\beta\right)} = \frac{\sqrt{3}}{2},$ $\therefore \cos \frac{\alpha + \beta}{2} = \cos \left[\left(\alpha -\frac{\beta}{2}\right) - \left(\frac{\alpha}{2} -\beta\right)\right]$ $= \cos \left(\alpha -\frac{\beta}{2}\right)\cos \left(\frac{\alpha}{2} -\beta\right) + \sin \left(\alpha -\right.$ $\frac{\beta}{2})\sin \left(\frac{\alpha}{2} -\beta\right)$ $= -\frac{2\sqrt{7}}{7}\times \frac{\sqrt{3}}{2} +\frac{\sqrt{21}}{7}\times \frac{1}{2} = -\frac{\sqrt{21}}{14}.$ $\therefore \alpha \in \left(\frac{\pi}{2},\pi\right),\beta \in \left(0,\frac{\pi}{2}\right),$ $\frac{\pi}{4} <  \frac{\alpha + \beta}{2} <  \frac{3\pi}{4},$ $\therefore \sin \frac{\alpha + \beta}{2} = \sqrt{1 - \cos^2\frac{\alpha + \beta}{2}} = \frac{5\sqrt{7}}{14},$ $\therefore \tan \frac{\alpha + \beta}{2} = \frac{\sin\frac{\alpha + \beta}{2}}{\cos\frac{\alpha + \beta}{2}} = -\frac{5\sqrt{3}}{3},$ $\therefore \tan (\alpha +\beta) = \frac{2\tan\frac{\alpha + \beta}{2}}{1 - \tan^2\frac{\alpha + \beta}{2}} = \frac{5\sqrt{3}}{11}.$
