> [!faq]- 答案与解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【解析】**
> > 【解】(1) 将 $\sin \alpha + \cos \alpha = -\frac{\sqrt{5}}{5}$ 两边平方得, $1 + 2\sin \alpha \cos \alpha = \frac{1}{5}$ ,
> >
> > [254]
> >
> > 所以 $2\sin \alpha \cos \alpha = -\frac{4}{5} < 0.$ 因为 $\alpha \in (0,\pi)$ ，所以 $\sin \alpha > 0, \cos \alpha < 0$ ，所以 $\sin \alpha - \cos \alpha = \sqrt{(\sin \alpha - \cos \alpha)^2} = \sqrt{1 - 2\sin \alpha \cos \alpha} = \frac{3\sqrt{5}}{5}$ ，所以 $\sin \alpha \cos \alpha + \cos 2\alpha = \sin \alpha \cos \alpha + \cos^2\alpha - \sin^2\alpha = \sin \alpha \cos \alpha + (\cos \alpha + \sin \alpha) \cdot (\cos \alpha - \sin \alpha) = -\frac{2}{5} + (-\frac{\sqrt{5}}{5}) \times (-\frac{3\sqrt{5}}{5}) = \frac{1}{5}$ . (2)由 $\left\{ \begin{array}{l} \sin \alpha + \cos \alpha = -\frac{\sqrt{5}}{5}, \\ \sin \alpha - \cos \alpha = \frac{3\sqrt{5}}{5}, \end{array} \right.$ 解得 $\left\{ \begin{array}{l} \sin \alpha = \frac{\sqrt{5}}{5}, \\ \cos \alpha = -\frac{2\sqrt{5}}{5}, \end{array} \right.$ 所以 $\tan \alpha = \frac{\sin \alpha}{\cos \alpha} = -\frac{1}{2}$ ，所以 $\tan (2\alpha + \beta) = \tan (\alpha + \alpha + \beta) = \frac{\tan \alpha + \tan (\alpha + \beta)}{1 - \tan \alpha\tan (\alpha + \beta)} = \frac{-\frac{1}{2} - \frac{1}{3}}{1 - (-\frac{1}{2}) \times (-\frac{1}{3})} = -1.$
