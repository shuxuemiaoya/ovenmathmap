> [!faq]- 答案与解析
>
> > [!success]- **【答案】** BC
>
> > [!note]- **【解析】**
> > BC 【解析】在 $\triangle ABC$ 中, $A + B + C = \pi$ , 所以 $A + B = \pi - C$ . 对于 A, $\sin C + \sin (A + B) = \sin C + \sin (\pi - C) = \sin C + \sin C = 2\sin C$ , 不是常数, 故 A 错误; 对于 B, $\cos (A + B) + \cos C = \cos (\pi - C) + \cos C = -\cos C + \cos C = 0$ , 是常数, 故 B 正确; 对于 C, $\tan \frac{A + B}{2} \tan \frac{C}{2} = \tan \frac{\pi - C}{2} \tan \frac{C}{2} =$ $\tan \left(\frac{\pi}{2} -\frac{C}{2}\right)\tan \frac{C}{2} = \frac{1}{\tan\frac{C}{2}}\tan \frac{C}{2} = 1$ ，是常数，故C正确；对于D, $\cos \frac{A + B}{2}$ $\cos \frac{C}{2} = \cos \frac{\pi - C}{2}\cos \frac{C}{2} = \cos \left(\frac{\pi}{2} -\frac{C}{2}\right)$ $\cos \frac{C}{2} = \sin \frac{C}{2}\cos \frac{C}{2} = \frac{1}{2}\sin C,$ 不是常数，故D错误.
> >
> > 故选 **BC**.
