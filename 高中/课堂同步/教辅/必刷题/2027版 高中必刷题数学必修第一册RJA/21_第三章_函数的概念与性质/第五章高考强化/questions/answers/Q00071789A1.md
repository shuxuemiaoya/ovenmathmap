> [!faq]- 答案与解析
>
> > [!success]- **【答案】** ACD
>
> > [!note]- **【解析】**
> > ACD 【解析】对 A 选项: a > 0, b > 0, 且 $a + b = 4$ , 故 $a^{2} + b^{2} = (a + b)^{2} - 2ab = 4^{2} - 2ab \geqslant 16 - 2\left(\frac{a + b}{2}\right)^{2} = 8$ , 当且仅当 a = b = 2 时等号成立, 即 $a^{2} + b^{2} \geqslant 8$ , 故 A 正确; 对 B 选项: a > 0, b > 0, 且 $a + b = 4$ , 故 $\log_{2}a + \log_{2}b = \log_{2}(ab) \leqslant \log_{2}\left(\frac{a + b}{2}\right)^{2} = \log_{2}4 = 2$ , 当且仅当 a = b = 2 时等号成立, 即 $\log_{2}a + \log_{2}b \leqslant 2$ , 故 B 错误; 对 C 选项: a > 0, b > 0, 且 $a + b = 4$ , 故 $2^{a} + 2^{b} \geqslant 2\sqrt{2^{a} \cdot 2^{b}} = 2\sqrt{2^{a+b}} = 2\sqrt{2^{4}} = 8$ , 当且仅当 a = b = 2 时等号成立, 即 $2^{a} + 2^{b} \geqslant 8$ , 故 C 正确; 对 D 选项: a > 0, b > 0, 且 $a + b = 4$ , 故 $(\sqrt{a + 1} + \sqrt{b + 3})^{2} = a + 1 + b + 3 +$ 点悟: 求两个根式相加减形式的式子的最值, 一般可先将其平方, 然后利用基本不等式去掉根号 $2\sqrt{(a+1)(b+3)} \leqslant a + b + 4 + 2 \times \frac{a + 1 + b + 3}{2} = 4 + 4 + 2 \times \frac{4 + 4}{2} = 16$ , 当且仅当 $a + 1 = b + 3$ , 且 $a + b = 4$ , 即 a = 3, b = 1 时等号成立, 即 $\sqrt{a+1} + \sqrt{b+3} \leqslant 4$ , 故 D 正确.
> >
> > 故选 **ACD**.
