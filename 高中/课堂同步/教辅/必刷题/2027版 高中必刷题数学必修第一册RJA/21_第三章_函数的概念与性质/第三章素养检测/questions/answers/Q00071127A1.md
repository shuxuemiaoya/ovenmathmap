> [!faq]- 答案与解析
>
> > [!success]- **【答案】** D
>
> > [!note]- **【解析】**
> > D 【解析】对于 A, $y=\frac{1}{x+1}$ 的定义域为 $\{x|x\neq-1\}$ ，不关于原点对称，所以不是奇函数，故 A 不符合题意；
> > 对于 B，记 $y=f(x)=x^{2}$ ，定义域为 R，且 $f(-x)=(-x)^{2}=x^{2}=f(x)$ ，则 $f(x)$ 是偶函数，不是奇函数，故 B 不符合题意；
> > 对于 C，记 $y=g(x)=|x|$ ，定义域为 R，且 $g(-x)=|-x|=|x|=g(x)$ ，则 $g(x)$ 是偶函数，不是奇函数，故 C 不符合题意；
> > 对于 D, 记 $y = h(x) = \begin{cases} x^2, & x \geqslant 0, \\ -x^2, & x < 0, \end{cases}$ ，定义域为 R，当 x > 0 时，-x < 0，则 $h(-x) = -(-x)^{2} = -x^{2} = -h(x)$ ，当 x < 0 时，-x > 0，则 $h(-x) = (-x)^{2} = x^{2} = -h(x)$ ，当 x = 0 时， $h(0) = 0$ ，则 $h(x)$ 是奇函数，当 $x \geqslant 0$ 时， $h(x)$ 单调递增，又 $h(x)$ 在 R 上的图象连续，所以 $h(x)$ 在 R 上为增函数，故 D 符合题意。
> >
> > 故选 **D**.
