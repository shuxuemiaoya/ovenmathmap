> [!faq]- 答案与解析
>
> > [!success]- **【答案】** $\frac{\pi}{3}$
>
> > [!note]- **【解析】**
> > 因为 $\sin (\pi -\alpha) = \frac{4\sqrt{3}}{7}$ 所以 $\sin \alpha = \frac{4\sqrt{3}}{7}.$ 因为 $0 <   \alpha <  \frac{\pi}{2}$ ，所以 $\cos \alpha = \sqrt{1 - \sin^2\alpha} = \frac{1}{7}.$ 因为 $\cos (\alpha -\beta) = \frac{13}{14}$ ，且 $0 <   \beta <  \alpha <  \frac{\pi}{2},$ 所以 $0 <   \alpha -\beta <  \frac{\pi}{2},$ 所以 $\sin (\alpha -\beta) = \sqrt{1 - \cos^2(\alpha -\beta)} = \frac{3\sqrt{3}}{14}.$ 所以 $\cos \beta = \cos [\alpha -(\alpha -\beta)] =$ $\cos \alpha \cos (\alpha -\beta) + \sin \alpha \sin (\alpha -\beta) = \frac{1}{7}\times$ $\frac{13}{14} +\frac{4\sqrt{3}}{7}\times \frac{3\sqrt{3}}{14} = \frac{1}{2}.$ 因为 $0 <   \beta <  \frac{\pi}{2}$ ，所以 $\beta = \frac{\pi}{3}$ 易错警示本题容易忽视角的限制条件 $0 <   \beta <  \alpha <  \frac{\pi}{2}$ 导致函数值的符号错误
