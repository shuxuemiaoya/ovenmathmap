> > [!note]- **【解析】**
> > 5 三角恒等变换 $\frac{3\sqrt{10}}{10}, \sin \alpha = \sqrt{1 - \left(\frac{\sqrt{5}}{5}\right)^2} = \frac{2\sqrt{5}}{5},$ 坑：先判断角的范围再求三角函数值不易产生增根 $\therefore \cos \beta = \cos [\alpha - (\alpha - \beta)] = \cos \alpha \cos (\alpha - \beta) + \sin \alpha \sin (\alpha - \beta) = \frac{\sqrt{5}}{5} \times \frac{3\sqrt{10}}{10} + \frac{2\sqrt{5}}{5} \times \frac{\sqrt{10}}{10} = \frac{\sqrt{2}}{2}$ . 故选 A.
> >
> > 归纳总结 三角函数求值的两种类型
> > (1) 给角求值: 正确选用公式, 把非特殊角的三角函数转化为特殊角的三角函数.
> > (2) 给值求值: 关键是找出已知式与待求式之间的联系及函数的差异. 常见解题思路: ①适当变换已知式, 求得另外函数式的值, 以备应用;
> > - **②**：变换待求式, 便于将已知式求得的函数值代入, 从而达到解题的目的.
> > 常见的角的变换: $\alpha = (\alpha + \beta) - \beta, 2\alpha = (\alpha + \beta) + (\alpha - \beta), 2\alpha - \beta = \alpha + (\alpha - \beta), \beta = \frac{\alpha + \beta}{2} - \frac{\alpha - \beta}{2}, \left(\frac{3\pi}{4} + \beta\right) - \left(\frac{\pi}{4} - \alpha\right) = \frac{\pi}{2} + (\alpha + \beta), \left(\alpha + \frac{\pi}{4}\right) + \left(\beta - \frac{\pi}{4}\right) = \alpha + \beta.$ 只要对题设条件与所求式中涉及的角进行仔细的观察, 往往会发现角之间的关系.
> > 要特别注意角的范围确定的三角函数的正负, 否则可能会产生增根.
> >
> > 最大值为1，
> > 即当x=0时， $y=f(\sin x)$ 取得最大值，最大值为1.
> > (2) 函数 $f(x)=2x^{2}-4x+1$ 图象的对称轴为直线 x=1，且开口向上，
> > ∵ $0 \leqslant x \leqslant 3$ ，则当 x=1 时， $f(x)$ 取最小值，且最小值为 $f(1)=2 \times 1^{2}-4 \times 1+1=-1$ ，当 x=3 时， $f(x)$ 取最大值，且最大值为 $f(3)=2 \times 3^{2}-4 \times 3+1=18-12+1=7$ ，
> > ∴ 当 $0 \leqslant x \leqslant 3$ 时， $f(x)$ 的值域为 [-1,7].
> > ∵ $M=\{y|y=f(x),0\leqslant x\leqslant3\},\therefore M=[-1,7].$ ∵ 当 $0 < x < \pi$ 时， $-\frac{\pi}{6} < x - \frac{\pi}{6} < \frac{5\pi}{6}, \therefore -\frac{1}{2} < \sin\left(x-\frac{\pi}{6}\right) \leqslant 1,$ ∵ A>0, ∴ $-\frac{1}{2}A<A\sin\left(x-\frac{\pi}{6}\right) \leqslant A,$ ∴ 当 $0 < x < \pi$ 时， $-\frac{1}{2}A < g(x) \leqslant A.$ ∵ $N = \{ y | y = g(x), 0 < x < \pi \}$ ,
> > ∴ $N = \left\{ y \mid -\frac{1}{2}A < y \leqslant A \right\}.$ ∵ $M \cup N = N, \therefore M \subseteq N,$ $\left\{\begin{aligned}-\frac{1}{2}A<-1,\\A\geqslant7,\end{aligned}\right.$ $\therefore\left\{\begin{aligned}A>2,\\A\geqslant7,\end{aligned}\right.$ $\therefore A\geqslant7,$ ∴ 实数 A 的取值范围为 $[7, +\infty)$ .
