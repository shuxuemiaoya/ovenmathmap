> [!faq]- 答案与解析
>
> > [!success]- **【答案】** $\frac{7\sqrt{65}}{65}$
>
> > [!note]- **【解析】**
> > ∵ $\alpha$ 为钝角, $\beta$ 为锐角, $\sin\alpha=\frac{4}{5},\sin\beta=\frac{12}{13},$ ∴ $\cos\alpha=-\frac{3}{5},\cos\beta=\frac{5}{13},$
> >
> > $\therefore \cos (\alpha - \beta) = \cos \alpha \cos \beta + \sin \alpha \sin \beta = -\frac{3}{5} \times \frac{5}{13} + \frac{4}{5} \times \frac{12}{13} = \frac{33}{65}$ .
> >
> > 又: $\frac{\pi}{2} < \alpha < \pi, 0 < \beta < \frac{\pi}{2}$ , $\therefore 0 < \alpha - \beta < \pi, \therefore 0 < \frac{\alpha - \beta}{2} < \frac{\pi}{2}$ . $\therefore \cos \frac{\alpha - \beta}{2} = \sqrt{\frac{1 + \cos (\alpha - \beta)}{2}} = \sqrt{\frac{1 + \frac{33}{65}}{2}} = \frac{7\sqrt{65}}{65}$ .
> >
> > 易错警示 易求错 $\frac{\alpha - \beta}{2}$ 的范围, 导致求 $\cos \frac{\alpha - \beta}{2}$ 的值时产生增解或错解.
> >
