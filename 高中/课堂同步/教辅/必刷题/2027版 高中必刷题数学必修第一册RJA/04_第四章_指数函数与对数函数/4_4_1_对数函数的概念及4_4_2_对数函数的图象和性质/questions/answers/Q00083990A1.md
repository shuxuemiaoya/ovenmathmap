> [!faq]- 答案与解析
>
> > [!success]- **【答案】** C
>
> > [!note]- **【解析】**
> > C 【解析】因为当 x<0 时， $f(x)=x^{2}+(4a-3)x+3a$ ，二次函数 $y=x^{2}+(4a-3)x+3a$ 的图象开口向上，所以要使函数 $f(x)$ 是单调函数，则函数 $f(x)$ 在 $(-∞,0)$ 上单调递减，则函数 $f(x)$ 在 R 上单调递减，则有 $\left\{\begin{aligned}-\frac{4a-3}{2}&\geqslant0,\\0<a<1,\\3a&\geqslant2,\end{aligned}\right.$ 解得 $\frac{2}{3}&\leqslant a\leqslant\frac{3}{4},$ 故选 C.
> >
> > 易错警示 分段函数单调性的一致性，
> > 要求端点值的大小关系也是一致的. 若
> > 分段函数在定义域上单调递减, 则 $\left\{\begin{array}{l}\text { 每一段函数在对应定义范围内单调 } \\ \text { 递减, } \\ \text { 定义域分界点处左边函数值 } \geqslant \text { 右边 } \\ \text { 函数值; }\end{array}\right.$ 若分段函数在定义域上单调递增, 则 $\left\{\begin{array}{l}\text { 每一段函数在对应定义范围内单调递增, } \\ \text { 定义域分界点处左边函数值 } \leqslant \text { 右边 } \\ \text { 函数值. }\end{array}\right.$ 列不等式时还要注意不等号能否取到,
> > 可以假设能取到等号处的值, 若满足要
> > 求则可取等号, 不满足要求不可以取
> > 等号.
