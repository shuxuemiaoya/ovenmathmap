> [!faq]- 答案与解析
>
> > [!success]- **【答案】** BCD
>
> > [!note]- **【解析】**
> > BCD 【解析】对于 A, 原式 = $(1 - \lg 2) \cdot (1 + \lg 2) + (\lg 2)^{2} + \frac{\lg 9}{\lg 2} \cdot \frac{\lg 8}{\lg 3} + 3 = 1 + \frac{2 \lg 3}{\lg 2} \cdot \frac{3 \lg 2}{\lg 3} + 3 = 1 + 6 + 3 = 10$ , A 选项错误;
> > 对于 B, $8^{\frac{2}{3}} \times 3^{1 - \log_{3}2} = (2^{3})^{\frac{2}{3}} \times \frac{3}{3^{\log_{3}2}} = 2^{2} \times$ $\frac{3}{2} = 6, \mathrm{B}$ 选项正确；
> > 对于C，若 $\lg 3 = m, \lg 2 = n$ ，则 $\log_518 = \frac{\lg 18}{\lg 5} = \frac{\lg 2 + \lg 9}{1 - \lg 2} = \frac{\lg 2 + 2\lg 3}{1 - \lg 2} = \frac{2m + n}{1 - n},$ C选项正确；
> > 对于D，若 $a^{\frac{1}{2}} + a^{-\frac{1}{2}} = 2$ ，则 $(a^{\frac{1}{2}} + a^{-\frac{1}{2}})^2 = a + a^{-1} + 2a^{\frac{1}{2}} \times a^{-\frac{1}{2}} = a + a^{-1} + 2 = 4$ ，所以 $a + a^{-1} = 2,\mathrm{D}$ 选项正确.
> >
> > 名师点拨 对于对数的乘法,尤其是不同底对数的乘法,最好的方法就是将所有对数换成同底对数的商,这样能很好地化简式子.
