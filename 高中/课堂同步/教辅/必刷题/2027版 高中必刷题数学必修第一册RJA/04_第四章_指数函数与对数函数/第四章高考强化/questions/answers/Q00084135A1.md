> [!faq]- 答案与解析
>
> > [!success]- **【答案】** ABD
>
> > [!note]- **【解析】**
> > ABD【解析】由 $a > 0, b > 0, a + b = 1$ ，得 $\frac{a^2 + b^2}{2} \geqslant \left(\frac{a + b}{2}\right)^2 = \frac{1}{4}$ ，即 $a^2 + b^2 \geqslant \frac{1}{2}$ ，当且仅当 $a = b = \frac{1}{2}$ 时取等号，故A正确；由 $a > 0, b > 0, a + b = 1$ ，得 $a - b = 2a - 1 > -1$ ，故 $2^{a - b} > \frac{1}{2}$ ，故B正确； $\log_2 a + \log_2 b = \log_2 (ab) \leqslant \log_2 \left(\frac{a + b}{2}\right)^2 = \log_2 \left(\frac{1}{2}\right)^2 = -2$ ，当且仅当 $a = b = \frac{1}{2}$ 时，等号成立，故C错误； $(\sqrt{a} + \sqrt{b})^2 = a + b + 2\sqrt{ab} = 1 + 2\sqrt{ab} \leqslant 1 + a + b = 2$ ，得 $\sqrt{a} + \sqrt{b} \leqslant \sqrt{2}$ ，当且仅当 $a = b = \frac{1}{2}$ 时，等号成立，故D正确。
