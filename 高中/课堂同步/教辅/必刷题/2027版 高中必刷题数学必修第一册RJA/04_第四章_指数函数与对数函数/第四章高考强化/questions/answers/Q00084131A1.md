> > [!note]- **【解析】**
> > 由 $x_{1}$ 为 $f(x) = \mathrm{e}^{x} + 3x - 2$ 的零点，得 $\mathrm{e}^{\mathrm{x}_1} + 3\mathrm{x}_1 = 2$ 又由 $x_{2}$ 为 $g(x) = \ln x^3 + x - 2 = 3\ln x + x - 2$ 的零点，得 $3\ln x_2 + x_2 = 2$ ，即 $\mathrm{e}^{\ln x_2} + 3\ln x_2 = 2$ 故点 $(x_{1},2)$ 与点 $(\ln x_2,2)$ 为曲线 $h(x) = \mathrm{e}^{x} + 3x$ 与直线 $y = 2$ 的交点因为函数 $h(x) = \mathrm{e}^{x} + 3x$ 在 $\mathbf{R}$ 上单调递增，从而曲线 $h(x) = \mathrm{e}^{x} + 3x$ 与直线 $y = 2$ 只有一个交点所以 $x_{1} = \ln x_{2}$ ，即 $\mathrm{e}^{\mathrm{x}_1} = x_2 > 0$
