> [!faq]- 答案与解析
>
> > [!success]- **【答案】** ABD
>
> > [!note]- **【解析】**
> > ABD 【解析】设 $3^{x} = 4^{y} = 12^{z} = t, t > 1$ ，则 $x = \log_{3}t, y = \log_{4}t, z = \log_{12}t,$ 点击黑板：指对互化
> >
> > 所以 $\frac{1}{x} + \frac{1}{y} = \frac{1}{\log_3t} + \frac{1}{\log_4t} = \log_t 3 + \log_t 4 = \log_t 12 = \frac{1}{z}$ ，A 正确.
> >
> > 因为 $\frac{6z}{3x} = \frac{2\log_{12}t}{\log_3t} = \frac{2\log_t 3}{\log_t 12} = \log_{12}9 < 1$ ，所以 $6z < 3x$ 。
> >
> > 因为 $\frac{3x}{4y} = \frac{3\log_3t}{4\log_4t} = \frac{3\log_t 4}{4\log_t 3} = \frac{\log_t 64}{\log_t 81} = \log_{81}64 < 1$ ，所以 $3x < 4y$ ，所以 $6z < 3x < 4y$ ，B 正确.
> >
> > 因为 $x + y - 4z = \log_3 t + \log_4 t - 4\log_{12} t = \frac{1}{\log_t 3} + \frac{1}{\log_t 4} - \frac{4}{\log_t 12} = \frac{\log_t 3 + \log_t 4}{\log_t 3\log_t 4} - \frac{4}{\log_t 3 + \log_t 4} = \frac{(\log_t 3 - \log_t 4)^2}{\log_t 3\log_t 4(\log_t 3 + \log_t 4)} > 0$ ，所以 $x + y > 4z$ ，D 正确.
> >
> > 因为 $\frac{1}{z} = \frac{1}{x} + \frac{1}{y} = \frac{x + y}{xy}$ ，所以 $\frac{xy}{z} = x + y > 4z$ ，所以 $xy > 4z^2$ ，C 错误。
> >
> > 故选 **ABD**。
