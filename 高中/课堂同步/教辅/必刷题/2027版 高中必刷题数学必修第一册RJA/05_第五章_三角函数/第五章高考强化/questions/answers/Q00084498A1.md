> [!faq]- 答案与解析
>
> > [!success]- **【答案】** 3 $\left[-\frac{5\pi}{6} + 2k\pi, \frac{\pi}{6} + 2k\pi\right] (k \in \mathbb{Z})$
>
> > [!note]- **【解析】**
> > 由辅助角公式，得 $f(x) = A\cos x + \sqrt{3}\sin x = \sqrt{A^2 + 3}\sin (x + \varphi)$ ，其中角 $\varphi$ 满足$\sin \varphi = \frac{A}{\sqrt{A^2 + 3}},\cos \varphi = \frac{\sqrt{3}}{\sqrt{A^2 + 3}}$ 故由 $f(x)$ 图象的一条对称轴为直线 $x = \frac{\pi}{6}$ ，知 $f\left(\frac{\pi}{6}\right) = \pm \sqrt{A^2 + 3}$ 即 $\frac{\sqrt{3}}{2} A + \frac{\sqrt{3}}{2} = \pm \sqrt{A^2 + 3}$ 即 $\frac{3}{4} (A + 1)^2 = A^2 +3$ ，整理得 $A^2 -6A + 9 = 0$ 解得 $A = 3.$ 于是 $f(x)$ 的解析式可以为 $f(x) = 2\sqrt{3}\sin \left(x+\right.$ $\frac{\pi}{3}$ ，故由 $-\frac{\pi}{2} +2k\pi \leqslant x + \frac{\pi}{3}\leqslant \frac{\pi}{2} +2k\pi ,$ $k\in \mathbf{Z},$ 解得 $-\frac{5\pi}{6} +2k\pi \leqslant x\leqslant \frac{\pi}{6} +2k\pi ,$ $k\in \mathbf{Z},$ 所以函数 $f(x)$ 的单调递增区间为 $\left[-\frac{5\pi}{6} +2k\pi ,\frac{\pi}{6} +2k\pi \right](k\in \mathbf{Z}).$
