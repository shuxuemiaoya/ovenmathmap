> [!faq]- 答案与解析
>
> > [!success]- **【答案】** B
>
> > [!note]- **【解析】**
> > B 【解析】 $\sin^{4}x+\cos^{4}x=(\sin^{2}x+\cos^{2}x)^{2}-2\sin^{2}x\cos^{2}x=1-2\sin^{2}x\cos^{2}x,$ 又 $\sin^{4}x + \cos^{4}x = \frac{1}{2}$ ,
> > 所以 $1 - 2 \sin^{2} x \cos^{2} x = \frac{1}{2}$ ,
> > 所以 $\sin^{2}x\cos^{2}x=\frac{1}{4},$ 又 $x \in \left(-\frac{\pi}{2}, 0\right)$ ，所以 $\sin x < 0, \cos x > 0,$ $\sin x \cos x < 0, \sin x - \cos x < 0,$ 所以 $\sin x \cos x = -\frac{1}{2},$ 故 $\sin x - \cos x = -\sqrt{(\sin x - \cos x)^{2}} = -\sqrt{1 - 2 \sin x \cos x} = -\sqrt{1 - 2 \times \left(-\frac{1}{2}\right)} = -\sqrt{2}.$
> >
> > 故选 **B**.
