> > [!note]- **【解析】**
> > BCD 【解析】因为 $A+B=\pi-C$ ,
> > 所以 $\sin(A+B)=\sin(\pi-C)=\sin C$ ，故 A 错误； $\cos(A+B)=\cos(\pi-C)=-\cos C$ ，故 B 正确； $\tan(A+B)=\tan(\pi-C)=-\tan C\left(C\neq\frac{\pi}{2}\right)$ 故 C 正确；
> > 因为 $B+C=\pi-A$ 所以 $\sin\frac{B+C}{2}=\sin\frac{\pi-A}{2}=\sin\left(\frac{\pi}{2}-\frac{A}{2}\right)=\cos\frac{A}{2}$ ，故 D 正确.
> > 故选 BCD.

> > $= \frac{|1 + \sin x| - |1 - \sin x|}{|\cos x|} = \frac{2\sin x}{-\cos x} = -2\tan x,$ 所以 $f(x) = -2\tan x.$ (2)因为 $1 - \sin x > 0,1 + \sin x > 0$ ，结合(1)知 $f(x) = \frac{2\sin x}{|\cos x|}$ ，而 $f(x) = 1$ ，则 $\frac{\sin x}{|\cos x|} =$ $\frac{1}{2}$ ，所以 $\sin x > 0,x$ 是第一象限角或第二象限角.当 $\cos x > 0$ ，即 $x$ 是第一象限角时， $\tan x =$ $\frac{1}{2},\sin x(\sin x + \cos x) = \frac{\sin^2x + \sin x\cos x}{\sin^2x + \cos^2x} =$ $\frac{\tan^2x + \tan x}{\tan^2x + 1} = \frac{\left(\frac{1}{2}\right)^2 + \frac{1}{2}}{\left(\frac{1}{2}\right)^2 + 1} = \frac{3}{5};$ 当 $\cos x <   0$ ，即 $x$ 是第二象限角时， $\tan x =$ $-\frac{1}{2},\sin x(\sin x + \cos x) = \frac{\sin^2x + \sin x\cos x}{\sin^2x + \cos^2x} =$ $\frac{\tan^2x + \tan x}{\tan^2x + 1} = \frac{\left(-\frac{1}{2}\right)^2 - \frac{1}{2}}{\left(-\frac{1}{2}\right)^2 + 1} = -\frac{1}{5}.$ 综上， $\sin x(\sin x + \cos x)$ 的值为 $\frac{3}{5}$ 或- $\frac{1}{5}$
