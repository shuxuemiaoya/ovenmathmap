> > [!note]- **【解析】**
> > B 【解析】因为 $-\frac{3\pi}{4} < \alpha < \frac{\pi}{2}$ , 所以 $-\frac{\pi}{2} <$ $\alpha + \frac{\pi}{4} < \frac{3\pi}{4},$ 又 $\sin \left(\frac{\pi}{4} + \alpha\right) = -\frac{2\sqrt{6}}{5} < 0,$ 则 $-\frac{\pi}{2} < \alpha + \frac{\pi}{4} < 0,$ 所以 $\cos \left(\frac{\pi}{4} + \alpha\right) = \sqrt{1 - \sin^2\left(\frac{\pi}{4} + \alpha\right)} = \sqrt{1 - \frac{24}{25}} = \frac{1}{5},$ 则 $\sin \left(\frac{\pi}{4} - \alpha\right) = \cos \left[\frac{\pi}{2} - \left(\frac{\pi}{4} - \alpha\right)\right] = \cos \left(\frac{\pi}{4} + \alpha\right) = \frac{1}{5}.$
