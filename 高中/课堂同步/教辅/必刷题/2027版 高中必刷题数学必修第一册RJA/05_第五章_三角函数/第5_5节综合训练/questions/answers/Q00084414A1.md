> [!faq]- 答案与解析
>
> > [!success]- **【答案】** $\frac{\sqrt{3}}{2}$
>
> > [!note]- **【解析】**
> > 将 $\sin x + \sin y = \frac{\sqrt{2}}{2}, \cos x + \cos y = \frac{\sqrt{6}}{2}$ 同时平方后求和得 $(\sin x + \sin y)^2 + (\cos x + \cos y)^2 = 2$ ，化简得 $\cos (x - y) = 0$ . 又 $(\sin x + \sin y) \cdot (\cos x + \cos y) = \frac{1}{2} \sin 2x + \frac{1}{2} \sin 2y + \sin (x + y) = \frac{\sqrt{3}}{2}$ ，则 $\frac{1}{2} \sin [(x + y) + (x - y)] + \frac{1}{2} \sin [(x + y) - (x - y)] + \sin (x + y) = \frac{\sqrt{3}}{2}$ ，即 $\frac{\sqrt{3}}{2} = \sin (x + y) \cos (x - y) + \sin (x + y)$ ，所以 $\sin (x + y) = \frac{\sqrt{3}}{2}$ .
