> [!faq]- 答案与解析
>
> > [!success]- **【答案】** D
>
> > [!note]- **【解析】**
> > \(\frac{(4k + 1)\pi}{8} k\in \mathbb{Z}\) 【解析】\$\because \{\sin \theta, \sin 2\theta, \sin 3\theta\} = \{\cos \theta, \cos 2\theta, \cos 3\theta\}, \therefore \sin \theta + \sin 2\theta + \sin 3\theta = \cos \theta + \cos 2\theta + \cos 3\theta,\)
> >
> > 由和差化积公式可得，
> >
> > \(\sin \theta + \sin 3\theta = 2\sin \frac{\theta + 3\theta}{2} \cos \frac{\theta - 3\theta}{2} = 2\sin 2\theta \cos (-\theta) = 2\sin 2\theta \cos \theta,\)
> >
> > \(\cos \theta + \cos 3\theta = 2\cos \frac{\theta + 3\theta}{2} \cos \frac{\theta - 3\theta}{2} = 2\cos 2\theta \cos (-\theta) = 2\cos 2\theta \cos \theta,\)
> >
> > \$\therefore \sin \theta + \sin 2\theta + \sin 3\theta = 2\sin 2\theta \cos \theta + \sin 2\theta = \sin 2\theta (2\cos \theta + 1),\)
> >
> > \$\cos \theta + \cos 2\theta + \cos 3\theta = 2\cos 2\theta \cos \theta + \cos 2\theta = \cos 2\theta (2\cos \theta + 1),\)
> >
> > \$\therefore \sin 2\theta (2\cos \theta + 1) = \cos 2\theta (2\cos \theta + 1),\)
> >
> > \$\therefore \sin 2\theta = \cos 2\theta\) 或 \(\cos \theta = -\frac{1}{2}\)
> >
> > 当 \(\cos \theta = -\frac{1}{2}\) 时，\( \theta = \frac{2\pi}{3} + 2k\pi, k \in \mathbb{Z}\) 或
> > \(\theta = \frac{4\pi}{3} + 2k\pi, k \in \mathbb{Z},\)
> >
> > 此时 \(\cos \theta = \cos 2\theta = -\frac{1}{2}\)，不满足集合元
> >
> > ## 专题5 三角恒等变换
> >
> > $\cos 56^{\circ}\sin 45^{\circ} = \sin (56^{\circ} - 45^{\circ}) = \sin 11^{\circ},$ $c = \frac{1 - \tan^{2}39^{\circ}}{1 + \tan^{2}39^{\circ}} = \frac{\frac{\cos^{2}39^{\circ} - \sin^{2}39^{\circ}}{\cos^{2}39^{\circ}}}{\frac{\cos^{2}39^{\circ} + \sin^{2}39^{\circ}}{\cos^{2}39^{\circ}}} =$ $\cos^2 39^\circ -\sin^2 39^\circ = \cos 78^\circ = \sin 12^\circ ,$ $\because \sin 11^{\circ} <   \sin 12^{\circ} <   \sin 13^{\circ},\therefore a > c > b.$ 故选D.
> >
> > 素的互异性,故舍去;
> > 当 $\sin 2\theta = \cos 2\theta$ 时, $2\theta = \frac{\pi}{4} + k\pi, k \in Z,$ ∴ $\theta=\frac{\pi}{8}+\frac{k\pi}{2}, k \in Z,$ 满足题意，
> > ∴ $\theta=\frac{(4k+1)\pi}{8}, k \in Z.$
