> [!faq]- 答案与解析
>
> > [!success]- **【答案】** C
>
> > [!note]- **【解析】**
> > C 【解析】易知 $\frac{1}{a + b} +\frac{4}{b + c} = \frac{1}{2}\left[(a + b) + (b + c)\right]\cdot \left(\frac{1}{a + b} +\frac{4}{b + c}\right) = \frac{1}{2}\left[1 + \frac{b + c}{a + b} +\right.$ $\frac{4(a + b)}{b + c} +4]\geqslant \frac{1}{2}\left[5 + 2\sqrt{\frac{b + c}{a + b}\cdot\frac{4(a + b)}{b + c}}\right] =$ $\frac{9}{2}$ 当且仅当 $\left\{ \begin{array}{l}b + c = 2(a + b),\\ a + 2b + c = 2, \end{array} \right.$ 即 $\left\{ \begin{array}{l}a + b = \frac{2}{3},\\ b + c = \frac{4}{3} \end{array} \right.$ 时取等号，则 $\frac{1}{a + b} +\frac{4}{b + c}$ 的最小值为 $\frac{9}{2}$
> >
> > 故选 **C**.
