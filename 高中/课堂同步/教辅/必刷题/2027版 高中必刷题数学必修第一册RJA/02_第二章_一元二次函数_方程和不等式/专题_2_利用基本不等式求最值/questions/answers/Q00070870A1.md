> [!faq]- 答案与解析
>
> > [!success]- **【答案】** B
>
> > [!note]- **【解析】**
> > B 【解析】 $a+2b-2ab=0\Rightarrow\frac{1}{a}+\frac{1}{2b}=1$ ,
> > 则 $8a + b = \left(\frac{1}{a} + \frac{1}{2b}\right)(8a + b) = \frac{17}{2} + \left(\frac{b}{a} + \frac{4a}{b}\right) \geqslant \frac{17}{2} + 2\sqrt{\frac{b}{a} \cdot \frac{4a}{b}} = \frac{25}{2}$ ,
> > 当且仅当 $\frac{b}{a}=\frac{4a}{b}$ ，即 $a=\frac{5}{4},b=\frac{5}{2}$ 时取等号，则 $8a+b$ 的最小值为 $\frac{25}{2}$ . 故选B.
> >
> > 多种解法 $a + 2b - 2ab = 0 \Rightarrow a = \frac{2b}{2b - 1}$ （ $b > \frac{1}{2}$ ），则 $8a + b = \frac{16b}{2b - 1} + b = \frac{8(2b - 1) + 8}{2b - 1} + b = 8 + \frac{8}{2b - 1} + \frac{2b - 1}{2} + \frac{1}{2} \geqslant \frac{17}{2} + 2\sqrt{\frac{8}{2b - 1} \cdot \frac{2b - 1}{2}} = \frac{17}{2} + 4 = \frac{25}{2}$ ，当且仅当 $\frac{8}{2b - 1} = \frac{2b - 1}{2}$ ，即 $a = \frac{5}{4}, b = \frac{5}{2}$ 时取等号.
