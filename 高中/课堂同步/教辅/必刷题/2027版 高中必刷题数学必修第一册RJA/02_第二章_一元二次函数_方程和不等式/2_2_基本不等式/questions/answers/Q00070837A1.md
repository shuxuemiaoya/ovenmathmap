> [!faq]- 答案与解析
>
> > [!success]- **【答案】** B
>
> > [!note]- **【解析】**
> > B【解析】设该超市每月销售该商品所获得利润为 $L$ 元， $\because$ 每件利润为 $(x - 10)$ 元，每月的销售量为 $100y$ 件， $\therefore L = 100y(x - 10) = 100\left(\frac{20}{x - 20} +2\right)(x-$ $20 + 10),20 <   x <   50.$ 令 $t = x - 20$ ，则 $0 <   t <   30$ $\therefore L = 100\left(\frac{20}{t} +2\right)(t + 10) = 200\left(\frac{100}{t} +t+\right.$ $20)\geqslant 200\left(2\sqrt{\frac{100}{t}\cdot t} +20\right) = 200\times 40 =$ 8000,当且仅当 $\frac{100}{t} = t$ ，即 $t = 10$ ，即 $x = 30$ 时取等号.
> > ∴该超市每月销售该商品所获得利润的最小值为8000元.
> >
> > 故选 **B**.
