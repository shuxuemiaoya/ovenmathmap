> [!faq]- 答案与解析
>
> > [!success]- **【答案】** C
>
> > [!note]- **【解析】**
> > C 【解析】设两直角边的长度分别为 $a, b, a > 0, b > 0$ ，则 $ab = 4$ ，铁支架框的周长 $l = a + b + \sqrt{a^2 + b^2} \geqslant 2\sqrt{ab} + \sqrt{2ab} = 4 + 2\sqrt{2} \approx 6.828$ ，当且仅当 $a = b = 2$ 时取等号。→地坑：题中所给条件为“够用”。意思是比6.828只能多不能少
> >
> > 故选 **C**.
