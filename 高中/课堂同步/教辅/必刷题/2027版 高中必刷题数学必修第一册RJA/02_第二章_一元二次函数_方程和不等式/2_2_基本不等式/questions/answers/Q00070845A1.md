> > [!note]- **【解析】**
> > 【证明】(1)由 $a, b, c$ 均为正实数，且 $a + b + c = 2$ 得 $\frac{1}{a} + \frac{1}{b} + \frac{1}{c} = \frac{1}{2}\left(\frac{1}{a} + \frac{1}{b} + \frac{1}{c}\right)(a + b + c) = \frac{1}{2}\left(1 + \frac{b}{a} + \frac{c}{a} + \frac{a}{b} + 1 + \frac{c}{b} + \frac{a}{c} + \frac{b}{c} + 1\right) = \frac{1}{2}\left(\frac{b}{a} + \frac{a}{b} + \frac{c}{a} + \frac{a}{c} + \frac{c}{b} + \frac{b}{c} + 3\right) \geqslant \frac{1}{2}\left(2\sqrt{\frac{b}{a} \cdot \frac{a}{b}} + 2\sqrt{\frac{c}{a} \cdot \frac{a}{c}} + 2\sqrt{\frac{c}{b} \cdot \frac{b}{c}} + 3\right) = \frac{9}{2},$ 当且仅当 $\frac{b}{a} = \frac{a}{b}, \frac{c}{a} = \frac{a}{c}, \frac{c}{b} = \frac{b}{c}$ ，即 $a = b = c = \frac{2}{3}$ 时等号成立，故 $\frac{1}{a} + \frac{1}{b} + \frac{1}{c} \geqslant \frac{9}{2}$ . (2)由 $a, b, c$ 均为正实数，且 $abc = 1$
> >
> > 得 $\frac{1}{a^2} +\frac{1}{b^2}\geqslant 2\sqrt{\frac{1}{a^2}\cdot\frac{1}{b^2}} = \frac{2}{ab} = 2c$ ，当且仅当 $\frac{1}{a^2} = \frac{1}{b^2}$ 即 $a = b$ 时等号成立； $\frac{1}{b^2} +\frac{1}{c^2}\geqslant 2\sqrt{\frac{1}{b^2}\cdot\frac{1}{c^2}} = \frac{2}{bc} = 2a$ ，当且仅当 $\frac{1}{b^2} = \frac{1}{c^2}$ 即 $b = c$ 时等号成立； $\frac{1}{a^2} +\frac{1}{c^2}\geqslant 2\sqrt{\frac{1}{a^2}\cdot\frac{1}{c^2}} = \frac{2}{ac} = 2b$ ，当且仅当 $\frac{1}{a^2} = \frac{1}{c^2}$ 即 $a = c$ 时等号成立.所以 $\frac{1}{a^2} +\frac{1}{b^2} +\frac{1}{b^2} +\frac{1}{c^2} +\frac{1}{a^2} +\frac{1}{c^2}\geqslant 2c + 2b+$ $2a$ ，即 $\frac{1}{a^2} +\frac{1}{b^2} +\frac{1}{c^2}\geqslant a + b + c,$ 当且仅当 $a = b = c = 1$ 时等号成立.(3）由 $x,y,z$ 均为正实数，且 $\frac{1}{x} +\frac{4}{y}+$ $\frac{9}{z} = 1,$ 得 $x + y + z = (x + y + z)\left(\frac{1}{x} +\frac{4}{y} +\frac{9}{z}\right)$ $= 1 + \frac{4x}{y} +\frac{9x}{z} +\frac{y}{x} +4 + \frac{9y}{z} +\frac{z}{x} +\frac{4z}{y} +9$ $= 14 + \frac{4x}{y} +\frac{y}{x} +\frac{9x}{z} +\frac{z}{x} +\frac{9y}{z} +\frac{4z}{y}$ $\geqslant 14 + 2\sqrt{\frac{4x}{y}\cdot\frac{y}{x}} +2\sqrt{\frac{9x}{z}\cdot\frac{z}{x}} +$ $2\sqrt{\frac{9y}{z}\cdot\frac{4z}{y}} = 36,$ 当且仅当 $\frac{4x}{y} = \frac{y}{x},\frac{9x}{z} = \frac{z}{x},\frac{9y}{z} = \frac{4z}{y}$ 即 $x = 6,y = 12,z = 18$ 时等号成立，故 $x + y+$ $z\geqslant 36.$
