> [!faq]- 答案与解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【解析】**
> > 【解】(1)设矩形花园的另一条边长为 $y\mathrm{m}$ ，因为矩形花园的总面积为 $120\mathrm{m}^2$ ，所以 $xy = 120$ ，可得 $y = \frac{120}{x}$ 。又 $y > 3, x > 3$ ，则 $3 < x < 40$ 。又因为阴影部分是宽度为 $1\mathrm{m}$ 的小路，所以 $2a + 3 = y = \frac{120}{x}$ ，即 $a = \frac{60}{x} - \frac{3}{2}$ ，即 $a = \frac{60}{x} - \frac{3}{2} (3 < x < 40)$ 。（2）由（1）知， $a = \frac{60}{x} - \frac{3}{2} (3 < x < 40)$ ，则 $S = (x - 2)a + (x - 3)a = (2x - 5)a = (2x - 5)\cdot \left(\frac{60}{x} -\frac{3}{2}\right) = \frac{255}{2} -\left(3x + \frac{300}{x}\right) \leqslant \frac{255}{2} -2\sqrt{3x\cdot\frac{300}{x}} = \frac{135}{2}$ ，
> >
> > 当且仅当 $3x = \frac{300}{x}$ 即 $x = 10$ 时，等号成立.所以当 $x = 10$ 时，才能使鲜花种植的总面积最大，最大面积为 $\frac{135}{2}\mathrm{m}^2$
