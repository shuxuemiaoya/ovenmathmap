> > [!note]- **【解析】**
> > 因为 $(a + b)(a + 2b) + 2a + 3b = 3$ ，所以 $(a + b + 1)(a + 2b + 1) = 4.$ 又 $a \geqslant -1, b$ 为正实数，所以 $a + b + 1 > 0, a + 2b + 1 > 0,$ 故 $3a + 4b + 3 = (a + 2b + 1) + 2(a + b + 1) \geqslant 2\sqrt{(a + 2b + 1) \cdot 2(a + b + 1)} = 2\sqrt{2 \times 4} = 4\sqrt{2},$ 当且仅当 $a + 2b + 1 = 2(a + b + 1)$ ，即 $a = -1, b = \sqrt{2}$ 时等号成立.故 $3a + 4b$ 的最小值为 $4\sqrt{2} - 3.$
