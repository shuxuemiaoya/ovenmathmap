> [!faq]- 答案与解析
>
> > [!success]- **【答案】** AB
>
> > [!note]- **【解析】**
> > AB【解析】因为 $a > b > 0$ ，所以 $\frac{1}{ab} >0$ ，所以 $a\cdot \frac{1}{ab} >b\cdot \frac{1}{ab}$ 即 $\frac{1}{a} <\frac{1}{b}$ 故A正确；
> >
> > $x = -2$ 时不成立，故该情况不满足题意.
> > - **②**：若方程 $x^{2} + ax + 2 = 0$ 不存在实数解，则 $x^{2} + ax + 2 > 0$ 恒成立，此时 $\Delta = a^2 -8 <   0$ ，解得 $-2\sqrt{2} <  a <   2\sqrt{2}$ ，则原不等式等价于 $x^{2}+$ $ax + 2\geqslant x + 1$ 且 $x^{2} + ax + 2\geqslant -x - 1.$ 当 $x^{2} + ax + 2\geqslant x + 1$ 时，有 $x^{2} + (a - 1)x+$ $1\geqslant 0,$ $\therefore \Delta_1 = (a - 1)^2 -4\leqslant 0,$ $\therefore -1\leqslant a <   2\sqrt{2};$ 当 $x^{2} + ax + 2\geqslant -x - 1$ 时，有 $x^{2} + (a + 1)x+$ $3\geqslant 0,$ $\therefore \Delta_2 = (a + 1)^2 -12\leqslant 0,$ $\therefore -2\sqrt{2} < a\leqslant 2\sqrt{3} -1.$ 综上所述，所求实数 $a$ 的取值范围为 $\{a| - 1\leqslant a\leqslant 2\sqrt{3} -1\}$
> >
> > 因为 $a > b > 0$ ，所以 $ab > b^2$ ，故B正确；
> > 取 $c = 0$ ，则 $ac^2 = bc^2$ ，故C错误；
> > 取 $a = \frac{1}{2} >b = \frac{1}{3}$ ，则 $a^2 -a = \left(\frac{1}{2}\right)^2 -\frac{1}{2} =$ $-\frac{1}{4} <  \left(\frac{1}{3}\right)^2 -\frac{1}{3} = -\frac{2}{9} = b^2 -b$ ，故D错误.
> >
> > 故选 **AB**.
