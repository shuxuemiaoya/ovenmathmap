> [!faq]- 答案与解析
>
> > [!success]- **【答案】** B
>
> > [!note]- **【解析】**
> > B 【解析】① $a^5 + b^5 - (a^3b^2 + a^2b^3) = a^3(a^2 - b^2) + b^3(b^2 - a^2) = (a^2 - b^2)(a^3 - b^3) = (a - b)^2(a + b)(a^2 + ab + b^2) > 0$ 不恒成立；
> > - **②**：$(a^2 + b^2) - 2(a - b - 1) = a^2 - 2a + b^2 + 2b + 2 = (a - 1)^2 + (b + 1)^2 \geqslant 0$ 恒成立；
> > - **③**：当 $a = 1, b = -1$ 时， $\frac{a}{b} + \frac{b}{a} = -2$ ，故 $\frac{a}{b} + \frac{b}{a} > 2$ 不恒成立。
> >
> > 故选 **B**.
