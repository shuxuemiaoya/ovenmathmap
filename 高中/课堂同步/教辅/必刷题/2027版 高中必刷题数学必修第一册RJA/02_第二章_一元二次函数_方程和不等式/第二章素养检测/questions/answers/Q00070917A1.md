> [!faq]- 答案与解析
>
> > [!success]- **【答案】** B
>
> > [!note]- **【解析】**
> > B【解析】由条件可得 $2x^{2} + y^{2} = 4 - z^{2}\Rightarrow$ $2x^{2} + y^{2} = (2 + z)(2 - z)$ 所以 $0 <   z <   2$ ，则 $2 + z = \frac{2x^2 + y^2}{2 - z},$ 所以 $\frac{z + 2}{xyz} = \frac{\frac{2x^2 + y^2}{2 - z}}{xyz} = \frac{2x^2 + y^2}{(2 - z)xyz}\geqslant$ $\frac{2\sqrt{2x^2y^2}}{(2 - z)xyz} = \frac{2\sqrt{2}xy}{(2 - z)xyz} = \frac{2\sqrt{2}}{(2 - z)z}\geqslant$ $\frac{2\sqrt{2}}{\left[\frac{(2 - z) + z}{2}\right]^2} = 2\sqrt{2},$ 当且仅当 $\sqrt{2} x = y$ ，且 $2 - z = z$ ，即 $x = \frac{\sqrt{3}}{2},y =$ $\frac{\sqrt{6}}{2},z = 1$ 时等号成立.
> >
> > 故选 **B**.
