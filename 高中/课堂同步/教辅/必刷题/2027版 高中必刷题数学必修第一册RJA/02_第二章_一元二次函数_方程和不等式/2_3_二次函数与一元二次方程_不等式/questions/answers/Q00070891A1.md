> > [!success]- **【答案】** C
>
> > [!note]- **【解析】**
> > C 【解析】当 k=0 时, 原不等式变为 $1 \geqslant 0$ , 显然对一切实数 x 都成立;
> > 当 $k \neq 0$ 时，由 $\left\{\begin{aligned}k>0,\\ \Delta=k^{2}-4k\leqslant0,\end{aligned}\right.$ 解得 $0<k\leqslant4$ . 综上，实数 k 的取值范围是 $\{k|0\leqslant k\leqslant4\}$ . 故选 C.
> >
> > 链接教材 这道题目是教材第 58 页复习参考题 2 第 6 题的变式, 基本的解题思路是对 k 分类讨论, 利用一元二次不等式的解集与判别式的关系求解.
> >
> > ## 规律方法 一元二次型不等式恒成立
> >
> > 的解题方法
> > (1) 不等式 $ax^{2} + bx + c > 0$ 对任意实数 x 恒成立等价于 $\left\{\begin{aligned}a &= b = 0, \\ c &= 0\end{aligned}\right.$ 或 $\left\{\begin{aligned}a &= 0, \\ b &= -4ac < 0.\end{aligned}\right.$ (2) 不等式 $ax^{2} + bx + c < 0$ 对任意实数 x 恒成立等价于 $\left\{\begin{aligned}a &= b = 0, \\ c &= 0\end{aligned}\right.$ 或 $\left\{\begin{aligned}a &= 0, \\ b &= -4ac < 0.\end{aligned}\right.$ 题中若明确说是一元二次不等式，则 $a\neq0$ ; 若未明确说是一元二次不等式，则要考虑 a=0 的情况.
