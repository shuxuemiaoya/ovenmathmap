> [!faq]- 答案与解析
>
> > [!success]- **【答案】** $\{x \mid x \geqslant 3 \text{ 或 } x \leqslant 1 \text{ 或 } x = 2\}$
>
> > [!note]- **【解析】**
> > 原不等式可化为 $\left\{ \begin{array}{l} x - 2 \neq 0, \\ (x - 1)(x - 3) \geqslant 0 \end{array} \right.$ 或 $x - 2 = 0$ , 解得 $x \geqslant 3$ 或 $x \leqslant 1$ 或 $x = 2$ . 所以原不等式的解集为 $\{x \mid x \geqslant 3 \text{ 或 } x \leqslant 1 \text{ 或 } x = 2\}$ . 易错警示 易错解为 $(x - 2)^2(x - 1)(x - 3) \geqslant 0$ , 因为 $(x - 2)^2 \geqslant 0$ , 所以 $(x - 1)(x - 3) \geqslant 0$ , 所以 $x \geqslant 3$ 或 $x \leqslant 1$ . 故原不等式的解集为 $\{x \mid x \geqslant 3 \text{ 或 } x \leqslant 1\}$ . 错误的原因是随意消项, 事实上, 当 $(x - 2)^2 = 0$ 时, 原不等式亦成立.
