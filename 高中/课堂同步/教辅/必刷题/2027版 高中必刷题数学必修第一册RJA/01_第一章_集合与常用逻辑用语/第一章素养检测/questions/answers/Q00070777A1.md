> > [!note]- **【解析】**
> > A 【解析】因为 $M = \{x \mid 0 \leqslant x \leqslant 2\}$ ， $N = \{x \mid 1 \leqslant x \leqslant 3\}$ ，所以 $M \cup N = \{x \mid 0 \leqslant x \leqslant 3\}$ ，所以题图中阴影部分所表示的集合为 $\complement_{R}(M \cup N) = \{x \mid x < 0 \text{ 或 } x > 3\}$ 。
> >
> > 故选 **A**.
