> > [!note]- **【解析】**
> > 【解】(1)由题可得 $B = \{x\mid x^2 -5x + 6 =$ $0\} = \{2,3\}$ ，由 $A = B$ 可得2,3是方程 $x^{2} - ax + a^{2} - 19 =$ 0的两根，则有 $\left\{ \begin{array}{l}2 + 3 = a,\\ 2\times 3 = a^2 -19, \end{array} \right.$ 解得 $a = 5.$ (2) $B = \{2,3\}$ ， $C = \{x\mid x^2 -2x - 3 = 0\} =$ $\{-1,3\}$ 因为 $A\cap B\neq \emptyset$ 且 $A\cap C = \emptyset$ ，所以 $2\in A$ 且 $3\notin A,$ 则有 $4 - 2a + a^2 -19 = 0$ ，化简得 $a^2 -2a-$ $15 = 0$ ，解得 $a = 5$ 或 $a = -3.$ 当 $a = 5$ 时， $A = \{2,3\}$ ，则 $A\cap C\neq \emptyset$ ，不符合题意；当 $a = -3$ 时， $A = \{-5,2\}$ ，则 $A\cap B = \{2\}$ 且 $A\cap C = \emptyset$ ，故 $a = -3$ 符合题意综上，实数 $a$ 的值为-3.
