> [!faq]- 答案与解析
>
> > [!success]- **【答案】** AC
>
> > [!note]- **【解析】**
> > AC 【解析】对于 A, $0 \in \{x \mid x^{2} = 0\} = \{0\}$ ，故 A 正确；对于 B，因为 $\{1\}$ ，N 表示集合，所以 $\{1\} \subseteq N$ ，故 B 错误；对于 C，由 $\{2, 1\} = \{x \mid x^{2} - 3x + 2 = 0\} = \{x \mid (x - 1) \cdot (x - 2) = 0\} = \{1, 2\}$ ，故 C 正确；对于 D，根据集合与集合间的关系， $\{x \mid x < 0\} \subseteq \{x \mid x < 1\}$ ，故 D 错误。故选 AC。
> >
> > 易错警示 (1) 元素与集合的关系为属于、不属于；集合与集合的关系为包含、不包含.
> > (2) 集合相等也是集合包含关系的一种情况.
> > (3) 空集和 $\{0\}$ 并不相等.
> >
