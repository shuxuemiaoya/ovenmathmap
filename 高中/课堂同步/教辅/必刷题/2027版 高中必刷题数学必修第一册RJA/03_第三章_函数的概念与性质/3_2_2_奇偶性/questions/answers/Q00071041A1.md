> [!faq]- 答案与解析
>
> > [!success]- **【答案】** B
>
> > [!note]- **【解析】**
> > B 【解析】由 $f(x) = x^3 - ax^2 + b$ 为奇函数，得 $f(-x) = -f(x)$ ，即 $-x^3 - a(-x)^2 + b = -(x^3 - ax^2 + b)$ ，整理得 $ax^2 - b = 0$ 对任意的 $x \in \mathbb{R}$ 成立， $\therefore a = 0, b = 0$ ，即 $f(x) = x^3 - ax^2 + b$ 为奇函数等价于 $a = b = 0$ ， $\therefore "a = 0"$ 是“函数 $f(x) = x^3 - ax^2 + b$ 为奇函数”的必要不充分条件。
> >
> > 故选 **B**.
