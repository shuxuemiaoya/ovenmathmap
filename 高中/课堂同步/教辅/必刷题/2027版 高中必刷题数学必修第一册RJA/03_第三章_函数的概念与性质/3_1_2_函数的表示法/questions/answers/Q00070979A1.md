> [!faq]- 答案与解析
>
> > [!success]- **【答案】** $\left[\frac{1}{3},1\right]$
>
> > [!note]- **【解析】**
> > 函数 $f(x)$ 的值域是 [-1,3]，当 c<x<3 时， $f(x)=\frac{1}{x}$ ，得 c>0，
> > →点悟：若 c<0，则 $f(x)$ 值域的左端点必为负无穷大
> > 则 $f(x) \in \left(\frac{1}{3}, \frac{1}{c}\right), \frac{1}{c} \leqslant 3$ ，可得 $c \geqslant \frac{1}{3}$ .
> > 当 $-3 \leqslant x \leqslant c$ 时， $f(x) = x^{2} + 2x = (x + 1)^{2} - 1$ ，而 $f(x)_{\min} = f(-1) = -1$ ，且 $f(-3) = 3$ ，因此 $f(c) = c^{2} + 2c \leqslant 3$ ，又 c > 0，解得 $0 < c \leqslant 1$ 。综上， $\frac{1}{3} \leqslant c \leqslant 1$ ，所以实数 c 的取值范围是 $\left[\frac{1}{3},1\right]$
