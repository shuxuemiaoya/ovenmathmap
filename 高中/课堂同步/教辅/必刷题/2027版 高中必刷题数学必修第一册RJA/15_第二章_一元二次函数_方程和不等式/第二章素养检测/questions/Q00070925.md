16. (本小题满分 15 分) [广东惠州 2026 高一期中] 根据题意, 求解下列问题:
(1) 已知 x > 0, y > 0, 且满足 $x + 8y = xy$ , 求 $x + 2y$ 的最小值;
(2) 已知 x > 1, 求 $y = \frac{x^{2} + 3x}{x - 1}$ 的最小值;
(3) 已知 a > 0, b > 0, c > 0, $a + b + c = 1$ , 求 $a^{2} + b^{2} + c^{2} + 4ab + \frac{7}{2}bc + \frac{7}{2}ac$ 的最大值.
