> [!faq]- 答案与解析
>
> > [!success]- **【答案】** D
>
> > [!note]- **【解析】**
> > D 【解析】因为两个正实数 $x, y$ 满足 $x + y = 1$ , 所以 $\frac{1}{x} + \frac{1}{y} = (x + y)\left(\frac{1}{x} + \frac{1}{y}\right) = 2 + \frac{y}{x} + [170]$
> >
> > 作关于 $x$ 的二次函数，则 $x^{2} + 2(ay + 1)x + (3y^{2} + 6y + 4) > 0$ 恒成立的条件是判别式 $\Delta_x = 4(ay + 1)^2 -4(3y^2 +6y + 4) <   0$ ，即 $(a^2 -$ $3)y^{2} + 2(a - 3)y - 3 <   0$ ，若 $a^2 -3 = 0$ ，则 $a = \pm \sqrt{3}$ ，此时 $a - 3\neq 0$ ，故要使该不等式对任意 $y\in \mathbf{R}$ 恒成立，则必须满足(1)二次项系数 $a^2 -3 <   0$ ，解得 $-\sqrt{3} < a <   \sqrt{3};$ (2)判别式 $\Delta_y = 4(a - 3)^2 -4(a^2 -3)(-3) <   0,$ 即 $2a^{2} - 3a <   0,$ 解得 $0 <   a <   \frac{3}{2}$ 综上，实数 $a$ 的取值范围为 $\left\{a\mid 0 <   a <   \frac{3}{2}\right\}$
