> **【解析】**
> $\frac{4\sqrt{3}-3}{10}$ 【解析】由 $\sin A = \frac{3}{5}, \cos B = -\frac{1}{2} < 0$ ，得 $B$ 为钝角， $A, C$ 为锐角，故 $\cos A = \frac{4}{5}, \sin B = \frac{\sqrt{3}}{2}$ . 故 $\sin C = \sin (A + B) = \sin A \cos B + \cos A \sin B = \sin (A + B)$ 点悟： $\sin C = \sin [\pi - (A + B)] = \sin (A + B)$ $\frac{3}{5} \times \left(-\frac{1}{2}\right) + \frac{4}{5} \times \frac{\sqrt{3}}{2} = \frac{4\sqrt{3} - 3}{10}$ .
