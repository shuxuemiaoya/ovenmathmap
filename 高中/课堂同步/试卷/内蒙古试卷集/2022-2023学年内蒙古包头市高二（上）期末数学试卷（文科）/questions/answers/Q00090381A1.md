> [!faq]- 2022-2023学年内蒙古包头市高二（上）期末数学试卷（文科）解析
>
> > [!success]- **【答案】** C
>
> > [!note]- **【解析】**
> > 对于 $A, \because \frac{x^2}{2} - \frac{y^2}{3} = 1, \therefore a = \sqrt{2}, b = \sqrt{3}, c = \sqrt{3 + 2} = \sqrt{5}$ ,
> >
> > $\therefore e = \frac{c}{a} = \frac{\sqrt{5}}{\sqrt{2}} = \frac{\sqrt{10}}{2},\therefore A_{\text{错误}};$
> >
> > 对于 $B, \because x^{2} - \frac{y^{2}}{4} = 1, \therefore a = 1, b = 2, c = \sqrt{1 + 4} = \sqrt{5}$
> >
> > $\therefore e = \frac{c}{a} = \sqrt{5},\therefore B$ 错误；
> >
> > 对于 $C$ ， $\because \frac{y^2}{4} -x^2 = 1$ ， $\therefore a = 2$ ， $b = 1$ ， $c = \sqrt{4 + 1} = \sqrt{5}$
> >
> > $\therefore e = \frac{c}{a} = \frac{\sqrt{5}}{2},\therefore C$ 正确；
> >
> > 对于 $D$ ， $\because \frac{y^2}{3} -\frac{x^2}{2} = 1$ ， $\therefore a = \sqrt{3}$ ， $b = \sqrt{2}$ ， $c = \sqrt{5}$
> >
> > $\therefore e = \frac{c}{a} = \frac{\sqrt{5}}{\sqrt{3}} = \frac{\sqrt{15}}{3},\therefore D$ 错误，
> >
> > 故选：C.
