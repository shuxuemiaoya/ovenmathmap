> [!faq]- 2024-2025学年内蒙古包头九中外国语学校高二（下）期中数学试卷解析
>
> > [!success]- **【答案】** C
>
> > [!note]- **【解析】**
> > $$
> > a = - \frac {\ln 4}{4} = \frac {1}{4} \ln \frac {1}{4} = \frac {1}{2} \ln \frac {1}{2}, c = - \frac {1}{e} = \frac {1}{e} \ln \frac {1}{e}
> > $$
> >
> > 设函数 $f(x) = x \ln x, x \in (0, +\infty), f'(x) = \ln x + 1$
> >
> > 当 $x\in(0,\frac{1}{e})$ 时， $f^{\prime}(x)<0$ ，当 $x\in(\frac{1}{e},+\infty)$ 时， $f^{\prime}(x)>0$
> >
> > 所以函数 $f(x)$ 在 $(0, \frac{1}{e})$ 上单调递减，在 $(\frac{1}{e}, +\infty)$ 上单调递增，
> >
> > 又 $\frac{1}{e} < \frac{1}{2} < \frac{2}{3}$ ，所以 $f\left(\frac{1}{e}\right) < f\left(\frac{1}{2}\right) < f\left(\frac{2}{3}\right)$ ，所以 $c < a < b$
> >
> > 故选：C.
