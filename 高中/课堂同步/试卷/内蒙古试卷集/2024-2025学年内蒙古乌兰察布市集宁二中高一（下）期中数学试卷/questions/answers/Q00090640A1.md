> [!faq]- 2024-2025学年内蒙古乌兰察布市集宁二中高一（下）期中数学试卷解析
>
> > [!success]- **【答案】** ABD
>
> > [!note]- **【解析】**
> > 对于A，因为在 $\triangle ABC$ 中， $A\in(0,\pi)$ ， $B\in(0,\pi)$ ，
> >
> > 所以当 $\sin A = \sin B$ 时， $A = B$ ，故 $\triangle ABC$ 为等腰三角形，故 $A$ 正确；
> >
> > 对于 $B$ ，由正弦定理 $\frac{a}{\sin A} = \frac{b}{\sin B} = \frac{c}{\sin C} = 2R$ ，得 $b = 2R\sin B$ ， $c = 2R\sin C$ $a = 2R\sin A$
> >
> > 所以 $\frac{a + b + c}{\sin A + \sin B + \sin C} = 2R$ ，可得 $\frac{a}{\sin A} = \frac{a + b + c}{\sin A + \sin B + \sin C}$ ，故 $B$ 正确；
> >
> > 对于 $C$ ，由余弦定理得cos $C = \frac{a^2 + b^2 - c^2}{2ab} < 0$
> >
> > 在 $\triangle ABC$ 中，可得 $C\in \left(\frac{\pi}{2},\pi\right)$ ，所以 $\triangle ABC$ 是钝角三角形，故 $C$ 错误；
> >
> > 对于 $D$ ， $S_{\triangle ABC} = \frac{1}{2} bc\sin A = \frac{\sqrt{3}}{2}$ ，故 $D$ 正确.
> >
> > 故选：ABD.
