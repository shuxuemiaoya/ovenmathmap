> [!faq]- 2024-2025学年内蒙古乌兰察布市集宁二中高一（下）期中数学试卷解析
>
> > [!success]- **【答案】** B
>
> > [!note]- **【解析】**
> > ∵ $A = \{x \mid -1 < x < 1\}$ , $B = \{x \mid 0 \leqslant x \leqslant 2\}$ ,
> > ∴ $A \cup B = \{x \mid -1 < x < 1\} \cup \{x \mid 0 \leqslant x \leqslant 2\} = \{x \mid -1 < x \leqslant 2\}$ .
> > 故选：B.
