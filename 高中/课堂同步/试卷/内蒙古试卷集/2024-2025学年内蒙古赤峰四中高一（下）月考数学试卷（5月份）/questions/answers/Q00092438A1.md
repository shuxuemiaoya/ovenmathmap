> [!faq]- 2024-2025学年内蒙古赤峰四中高一（下）月考数学试卷（5月份）解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【解析】**
> > 详见解析
> >
> > （1）根据题意可知， $\cos C + (\cos B - \sqrt{3}\sin B)\cos A = 0$
> >
> > $$
> > \therefore - \cos (A + B) + \cos B \cos A - \sqrt {3} \sin B \cos A = 0
> > $$
> >
> > $$
> > - \cos A \cos B + \sin A \sin B + \cos B \cos A - \sqrt {3} \sin B \cos A = 0
> > $$
> >
> > $$
> > \sin A \sin B - \sqrt {3} \sin B \cos A = 0
> > $$
> >
> > $$
> > \because \sin B > 0, \therefore \sin A = \sqrt {3} \cos A
> > $$
> >
> > $$
> > \cos A \neq 0, \therefore \tan A = \sqrt {3}
> > $$
> >
> > $$
> > \because 0 <   A <   \frac {\pi}{2}, \therefore A = \frac {\pi}{3};
> > $$
> >
> > (2)根据正弦定理， $\frac{a}{\sin A} = \frac{b}{\sin B} = \frac{c}{\sin C} = \frac{2\sqrt{3}}{\frac{\sqrt{3}}{2}} = 4$
> >
> > $$
> > | b + c = 4 \sin B + 4 \sin C = 4 \sin B + 4 \sin (A + B) = 4 \sin B + 2 \sin B + 2 \sqrt {3} \cos B
> > $$
> >
> > $$
> > = 6 \sin B + 2 \sqrt {3} \cos B = 4 \sqrt {3} \sin \left(B + \frac {\pi}{6}\right),
> > $$
> >
> > $\frac{\pi}{6} < B < \frac{\pi}{2}$ ，所以 $b + c$ 的取值范围为 $(6, 4\sqrt{3}]$ .
