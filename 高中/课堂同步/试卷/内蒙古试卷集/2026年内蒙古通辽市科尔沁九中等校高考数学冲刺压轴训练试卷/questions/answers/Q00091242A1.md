> [!faq]- 2026年内蒙古通辽市科尔沁九中等校高考数学冲刺压轴训练试卷解析
>
> > [!success]- **【答案】** 1； $\frac{3}{2}$
>
> > [!note]- **【解析】**
> > 由 $f(x) = a\cos \omega x + \sin \omega x$ ，且 $f(0) = 1$ ，得 $f(0) = a\cos 0 + \sin 0 = a = 1$ 则 $f(x) = \cos \omega x + \sin \omega x = \sqrt{2} sin(\omega x + \frac{\pi}{4})(\omega >0)$ 所以 $f(\frac{\pi}{2\omega}) = cos\frac{\pi}{2} +sin\frac{\pi}{2} = 1$ 可得 $\frac{\omega\pi}{3} +\frac{\pi}{4} = \frac{\pi}{4} +2k\pi$ 或 $\frac{\omega\pi}{3} +\frac{\pi}{4} = \frac{3\pi}{4} +2k\pi ,(k\in Z)$ 即 $\omega = 6m$ 或 $\omega = \frac{3}{2} +6m,(m\in Z)$ 又 $f(x)$ 在 $(\frac{\pi}{6},\frac{\pi}{2})$ 上单调递减，代入函数 $f(x) = \sqrt{2} sin(\omega x + \frac{\pi}{4})$ 可得 $(\frac{\omega\pi}{6} +\frac{\pi}{4},\frac{\omega\pi}{2} +\frac{\pi}{4})\subseteq (\frac{\pi}{2} +2k\pi ,\frac{3\pi}{2} +2k\pi),(k\in Z)$ 转化为： $\left\{ \begin{array}{ll}\frac{\omega\pi}{6} +\frac{\pi}{4}\geqslant \frac{\pi}{2} +2k\pi \\ \frac{\omega\pi}{2} +\frac{\pi}{4}\leqslant \frac{3\pi}{2} +2k\pi \end{array} \right.$ 解得： $\frac{3}{2} +12k\leqslant \omega \leqslant \frac{5}{2} +4k,(k\in Z),$
> >
> > 又 $\omega = 6m$ 或 $\omega = \frac{3}{2} + 6m$ ， $(m \in Z)$
> >
> > 所以当k=0时， $\omega=\frac{3}{2}$ 满足题意.
> >
> > 故答案为：1； $\frac{3}{2}$ .
