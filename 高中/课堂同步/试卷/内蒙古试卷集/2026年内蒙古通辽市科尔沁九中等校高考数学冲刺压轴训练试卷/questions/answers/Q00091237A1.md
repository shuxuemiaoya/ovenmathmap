> [!faq]- 2026年内蒙古通辽市科尔沁九中等校高考数学冲刺压轴训练试卷解析
>
> > [!success]- **【答案】** AB
>
> > [!note]- **【解析】**
> > 对于A，因为经验回归方程为 $\hat{y}=0.14x-0.33$ ，斜率为0.14>0，
> >
> > 所以 $\pmb{y}$ 随着 $\pmb{x}$ 的增大而增大，即 $\pmb{y}$ 与 $\pmb{x}$ 正相关，故 $\pmb{A}$ 正确；
> >
> > 对于 $B$ ，由题意可知， $\bar{y} = \frac{0.1 + 0.2 + 0.4 + 0.5}{4} = 0.3$
> >
> > 因为经验回归方程 $\hat{y} = 0.14x - 0.33$ 过样本中心点 $(\bar{x},\bar{y})$
> >
> > 所以 $0.3 = 0.14\bar{x} - 0.33$ ，解得 $\bar{x} = 4.5$
> >
> > 所以 $\bar{x} = \frac{3 + 4 + 5 + m}{4} = 4.5$ ，解得 $m = 6$ ，故 $B$ 正确；
> >
> > 对于 $C$ ，当 $\pmb{x} = 3$ 时，预测值 $\hat{\pmb{y}} = 0.14\times 3 - 0.33 = 0.09$ ，实际值为0.1，
> >
> > 所以残差 $= 0.1 - 0.09 = 0.01 \neq -0.01$ ，故 $C$ 错误；
> >
> > 对于D，经验回归方程为 $\hat{y}=0.14x-0.33$ ，斜率为0.14>0，
> >
> > 所以样本的相关系数r>0，故D错误.
> >
> > 故选：AB.
