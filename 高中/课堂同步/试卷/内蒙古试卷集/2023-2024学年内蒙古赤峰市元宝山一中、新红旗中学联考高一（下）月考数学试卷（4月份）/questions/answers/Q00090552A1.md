> [!faq]- 2023-2024学年内蒙古赤峰市元宝山一中、新红旗中学联考高一（下）月考数学试卷（4月份）解析
>
> > [!success]- **【答案】** C
>
> > [!note]- **【解析】**
> > 由题意得， $\left\{ \begin{array}{l} 1 - 2cosx \geq 0 \\ sinx - \frac{\sqrt{2}}{2} > 0 \\ 0 \leq x \leq 2\pi \end{array} \right.$ ，解得 $\left\{ \begin{array}{l} \frac{\pi}{3} \leq x \leq \frac{5\pi}{3} \\ \frac{\pi}{4} < x < \frac{3\pi}{4} \end{array} \right.$
> >
> > 所以 $\frac{\pi}{3} \leq x < \frac{3\pi}{4}$ ，即函数定义域为 $[\frac{\pi}{3}, \frac{3\pi}{4})$ 。
> >
> > 故选：C.
