> [!faq]- 2023-2024学年内蒙古师大附属二中高一（下）期中数学试卷解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【解析】**
> > 详见解析
> >
> > ( I ) $\alpha$ , $\beta$ 为锐角, $\sin\alpha=\frac{\sqrt{2}}{10}$ , $\tan(\alpha+\beta)=\frac{1}{2}$ ,
> >
> > 所以 $\cos \alpha = \frac{7\sqrt{2}}{10}$ ， $\tan \alpha = \frac{\sin\alpha}{\cos\alpha} = \frac{1}{7}$
> >
> > $$
> > \tan \beta = \tan (\alpha + \beta - \alpha) = \frac {\tan (\alpha + \beta) - \tan \alpha}{1 + \tan (\alpha + \beta) \tan \alpha} = \frac {\frac {1}{2} - \frac {1}{7}}{1 + \frac {1}{2} \times \frac {1}{7}} = \frac {1}{3}.
> > $$
> >
> > $(\Pi)\tan (\alpha +2\beta) = \tan (\alpha +\beta +\beta) = \frac{\tan(\alpha + \beta) + \tan\beta}{1 - \tan(\alpha + \beta)\tan\beta} = \frac{\frac{1}{2} + \frac{1}{3}}{1 - \frac{1}{2}\times\frac{1}{3}} = 1,$
> >
> > 因为 $\tan \alpha < 1, \tan \beta < 1$ ，且 $\alpha, \beta$ 为锐角，
> >
> > 所以 $0 < \alpha < \frac{\pi}{4}, 0 < \beta < \frac{\pi}{4}, 0 < \alpha + 2\beta < \frac{3\pi}{4}$
> >
> > 所以 $\alpha + 2\beta = \frac{\pi}{4}$ .
