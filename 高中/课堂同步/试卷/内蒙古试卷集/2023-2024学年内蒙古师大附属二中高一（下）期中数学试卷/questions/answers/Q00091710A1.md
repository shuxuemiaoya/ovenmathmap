> [!faq]- 2023-2024学年内蒙古师大附属二中高一（下）期中数学试卷解析
>
> > [!success]- **【答案】** ABD
>
> > [!note]- **【解析】**
> > 对于 $A, (1 + \tan 28^{\circ})(1 + \tan 17^{\circ}) = [1 + \tan (45^{\circ} - 17^{\circ})](1 + \tan 17^{\circ})$ $= (1 + \frac{tan45^{\circ} - tan17^{\circ}}{1 + tan45^{\circ}tan17^{\circ}})(1 + tan17^{\circ}) = (1 + \frac{1 - tan17^{\circ}}{1 + tan17^{\circ}})(1 + tan17^{\circ}) = 1 + \tan 17^{\circ}$ $+1 - \tan 17^{\circ} = 2$ ，故 $A$ 正确；
> >
> > 对于 $B$ ， $\cos \frac{\pi}{9}\cos \frac{2\pi}{9}\cos \frac{4\pi}{9} = \frac{\sin\frac{\pi}{9}\cos\frac{\pi}{9}\cos\frac{2}{9}\pi\cos\frac{4}{9}\pi}{\sin\frac{\pi}{9}} = \frac{\frac{1}{2}\sin\frac{2}{9}\pi\cos\frac{2}{9}\pi\cos\frac{4}{9}\pi}{\sin\frac{\pi}{9}}$
> >
> > $= \frac{\frac{1}{2} \times \frac{1}{2} \sin\frac{4}{9} \pi \cos\frac{4}{9} \pi}{\sin\frac{\pi}{9}} = \frac{\frac{1}{4} \times \frac{1}{2} \sin\frac{8}{9} \pi}{\sin\frac{\pi}{9}} = \frac{\frac{1}{8} \sin(\pi - \frac{\pi}{9})}{\sin\frac{\pi}{9}} = \frac{1}{8}$ ，故 $B$ 正确；
> >
> > 对于 $C$ ， $y = 3\sin \theta -4\cos \theta = 5\sin (\theta -\varphi)$ ，其中 $\cos \varphi = \frac{3}{5}$ ， $sin\varphi = \frac{4}{5}$
> >
> > 当 $\theta -\varphi = \frac{\pi}{2} +2k\pi ,k\in Z$ ，即 $\theta = \varphi +\frac{\pi}{2} +2k\pi$ 时， $y = 3\sin \theta -4\cos \theta$ 取得最大值，
> >
> > 此时 $sin\theta = sin(\varphi + \frac{\pi}{2} + 2k\pi) = cos\varphi = \frac{3}{5}$ ，故 $C$ 错误；
> >
> > $$
> > D, \because \overrightarrow {a} \cdot \overrightarrow {b} = \sqrt {2} c o s \theta + \sqrt {2} s i n \theta = 2 s i n (\theta + \frac {\pi}{4}) = \frac {3 \sqrt {2}}{5},
> > $$
> >
> > $$
> > \therefore \sin (\theta + \frac {\pi}{4}) = \frac {3 \sqrt {2}}{1 0}, \therefore \sin 2 \theta = - \cos (\frac {\pi}{2} + 2 \theta)
> > $$
> >
> > $= -cos2(\theta +\frac{\pi}{4}) = 2sin^{2}(\theta +\frac{\pi}{4}) - 1 = 2\times (\frac{3\sqrt{2}}{10})^{2} - 1 = -\frac{16}{25}$ ，故 $D$ 正确
> >
