> [!faq]- 2024-2025学年内蒙古包头市高二（下）期末数学试卷解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【解析】**
> > 详见解析
> >
> > (1)因为 $f(x)=\cos(x-\varphi)$ 为奇函数，所以 $\varphi=\frac{\pi}{2}+k\pi(k\in Z)$ ，又 $\varphi\in[0,\pi)$ ，所以 $\varphi=\frac{\pi}{2}$ ；
> > (2)由(1)得 $f(x)=cos(x-\frac{\pi}{2})=sinx$ 所以 $g(x)=sinx\cdot sin(x-\frac{\pi}{3})=sinx\cdot(\frac{1}{2}sinx-\frac{\sqrt{3}}{2}cosx)$ $=\frac{1}{2}\sin^{2}x-\frac{\sqrt{3}}{2}\sin x\cdot cos x=\frac{1}{2}\cdot\frac{1-cos2x}{2}-\frac{\sqrt{3}}{4}\sin2x$ $=\frac{1}{4}-(\frac{1}{4}\cos2x+\frac{\sqrt{3}}{4}\sin2x)=\frac{1}{4}-\frac{1}{2}\sin(2x+\frac{\pi}{6})$ 令 $2x+\frac{\pi}{6}=k\pi(k\in Z)$ ，得 $x=-\frac{\pi}{12}+\frac{k\pi}{2}$ 则 $g(x)$ 的对称中心是 $(- \frac {\pi } { 1 2 } + \frac { k \pi } { 2 } , \frac { 1 } { 4 } ) ( k \in Z )$ 因为 $-1 \leqslant sin(2x + \frac {\pi }{ 6}) \leqslant 1$ ，所以 $-\frac{1}{2} \leqslant -\frac{1}{2} sin(2x + \frac {\pi }{ 6}) \leqslant \frac{1}{2}$ 即 $-\frac{1}{4}\leqslant\frac{1}{4}-\frac{1}{2}\sin(2x+\frac{\pi}{6})\leqslant\frac{3}{4}$ ，故 $g(x)$ 的值域是 $[- \frac {1}{4},\frac {3}{4}]$ .
