> [!faq]- 2024-2025学年内蒙古包头市高二（下）期末数学试卷解析
>
> > [!success]- **【答案】** BC
>
> > [!note]- **【解析】**
> > 对于 $A, \because \{a_n\}$ 是等差数列， $\therefore S_7 = \frac{7(a_1 + a_7)}{2} = \frac{7(a_2 + a_6)}{2} = 42$
> >
> > $\therefore a_{2} + a_{6} = 12$ ，又 $a_2 = 4$ ， $\therefore a_6 = 8$ ，故 $A$ 错误；
> >
> > 对于 $B$ ，设等差数列 $\{a_{n}\}$ 的公差为 $d$ ，由 $A$ 知 $a_6 = 8$ ，则 $a_6 - a_2 = 4d = 4$
> >
> > $$
> > \therefore d = 1, \therefore a _ {n} = a _ {2} + (n - 2) d = n + 2
> > $$
> >
> > $\therefore a_{n} + n = 2n + 2$ ，故数列 $\{a_n + n\}$ 为递增数列，故 $B$ 正确；
> >
> > 对于 $C$ ，由 $a_{n} = n + 2$ ，则 $S_{n} = \frac{n(3 + n + 2)}{2} = \frac{1}{2} n^{2} + \frac{5}{2} n$ ，故 $C$ 正确；
> >
> > 对于 $D, \because \frac{1}{a_n a_{n+1}} = \frac{1}{(n + 2)(n + 3)} = \frac{1}{n + 2} - \frac{1}{n + 3}$ ,
> >
> > $$
> > \therefore \{\frac {1}{a _ {n} a _ {n + 1}} \}
> > $$
> >
> > $$
> > (\frac {1}{3} - \frac {1}{4}) + (\frac {1}{4} - \frac {1}{5}) + (\frac {1}{5} - \frac {1}{6}) + (\frac {1}{6} - \frac {1}{7}) = \frac {1}{3} - \frac {1}{7} = \frac {4}{2 1}
> > $$
> >
> > 故选：BC.
