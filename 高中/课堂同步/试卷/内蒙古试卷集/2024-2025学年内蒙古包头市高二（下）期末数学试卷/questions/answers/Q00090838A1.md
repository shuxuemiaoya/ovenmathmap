> [!faq]- 2024-2025学年内蒙古包头市高二（下）期末数学试卷解析
>
> > [!success]- **【答案】** 108
>
> > [!note]- **【解析】**
> > 由题意， $f^{\prime}(x)=(x-c)^{2}+2x(x-c)=(x-c)(3x-c)$ ，
> > ∵ $f(x)$ 在 x = -1 处有极小值，∴ $f'(-1)=0$ 即 $(-1-c)(-3-c)=0$ ，解得 c=-1 或 c=-3，
> > 若 c=-1，则 $f'(x)=(x+1)(3x+1)$ 当 x<-1 或 $x > -\frac{1}{3}$ 时， $f'(x)>0$ 当 $-1 < x < -\frac{1}{3}$ 时， $f'(x)<0$ ∴ f(x) 在 $(-∞, -1)$ 和 $(- \frac{1}{3}, +∞)$ 上单调递增，在 $(-1, -\frac{1}{3})$ 上单调递减，
> > ∴ f(x) 在 x = -1 处取极大值，不符合题意；
> > 若 c = -3，则 $f'(x) = (x + 3)(3x + 3)$ 当 x < -3 或 x > -1 时， $f'(x)>0$ 当 -3 < x < -1 时， $f'(x)<0$ ∴ f(x) 在 $(-∞,-3)$ 和 $(-1,+∞)$ 上单调递增，在 $(-3,-1)$ 上单调递减，
> > ∴ f(x) 在 x = -1 处取极小值，符合题意，
> > ∴ $f(x)=x(x+3)^{2}$ ，则 $f(3)=3\times(3+3)^{2}=108.$ 故答案为：108.
