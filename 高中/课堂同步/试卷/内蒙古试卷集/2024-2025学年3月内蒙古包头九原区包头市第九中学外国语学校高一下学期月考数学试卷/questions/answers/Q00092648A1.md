> [!faq]- 2024-2025学年3月内蒙古包头九原区包头市第九中学外国语学校高一下学期月考数学试卷解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【分析】**
> > (1) 根据同角三角函数之间的基本关系计算可得 $\sin (\alpha - \beta) = -\frac{2\sqrt{5}}{5}, \sin 2\alpha = \frac{3\sqrt{10}}{10}$ ，再由两角差的余弦公式计算可得结果.
>
> > [!note]- **【解析】**
> > 详见解析
> >
> > (1) 由 $0 < \alpha < \beta < \frac{\pi}{2}$ ，得 $-\frac{\pi}{2} < \alpha - \beta < 0$ ，又 $\cos (\alpha - \beta) = \frac{\sqrt{5}}{5}$ ，所以 $\sin (\alpha - \beta) = -\sqrt{1 - \cos^2 (\alpha - \beta)} = -\frac{2\sqrt{5}}{5}$ ，因为 $\cos 2\alpha = \frac{\sqrt{10}}{10} > 0$ ，且 $\alpha, \beta$ 均为锐角，则 $0 < 2\alpha < \frac{\pi}{2}, 0 < \alpha < \frac{\pi}{4}$ ，所以 $\sin 2\alpha = \sqrt{1 - \cos^2 2\alpha} = \frac{3\sqrt{10}}{10}$ ，所以 $\cos (\alpha + \beta) = \cos [2\alpha - (\alpha - \beta)] = \cos 2\alpha \cos (\alpha - \beta) + \sin 2\alpha \sin (\alpha - \beta)$ $= \frac{\sqrt{10}}{10} \times \frac{\sqrt{5}}{5} - \frac{3\sqrt{10}}{10} \times \frac{2\sqrt{5}}{5} = -\frac{\sqrt{2}}{2}$ ，综上 $\alpha + \beta = \frac{3\pi}{4}$ ，而 $0 < \alpha < \frac{\pi}{4}$ ，则 $0 < \alpha + \beta < \frac{3\pi}{4}$ ，显然有矛盾，所以 $\alpha + \beta$ 不存在。
> >
> > (2) 由 $\alpha \in \left(0, \frac{\pi}{2}\right)$ ，则 $\frac{\pi}{3} < \alpha + \frac{\pi}{3} < \frac{5\pi}{6}$ ，又 $\cos \left(\alpha + \frac{\pi}{3}\right) = -\frac{\sqrt{6}}{3}$ ，则
> >
> > $$
> > \sin \left(\alpha + \frac {\pi}{3}\right) = \frac {\sqrt {3}}{3}.
> > $$
> >
> > 而
> >
> > $$
> > \begin{array}{r l} & {\sin \alpha = \sin \left[ \left(\alpha + \frac {\pi}{3}\right) - \frac {\pi}{3} \right] = \sin \left(\alpha + \frac {\pi}{3}\right) \cos \frac {\pi}{3} - \cos \left(\alpha + \frac {\pi}{3}\right) \sin \frac {\pi}{3}} \\ & {= \frac {\sqrt {3}}{3} \times \frac {1}{2} - (- \frac {\sqrt {6}}{3}) \times \frac {\sqrt {3}}{2} = \frac {\sqrt {3} + 3 \sqrt {2}}{6}.} \end{array}
> > $$
