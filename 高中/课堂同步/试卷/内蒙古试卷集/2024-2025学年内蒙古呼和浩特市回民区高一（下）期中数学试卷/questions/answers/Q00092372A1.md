> [!faq]- 2024-2025学年内蒙古呼和浩特市回民区高一（下）期中数学试卷解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【解析】**
> > 详见解析
> >
> > (1) 由题意可得 $f(\alpha) = \frac{\sin\alpha(-\cos\alpha)\sin\alpha}{(-\sin\alpha)(-\sin\alpha)} = -\cos\alpha$ ;
> >
> > (2)若 $\alpha = -\frac{20\pi}{3}$ 则 $f(\alpha) = -cos(-\frac{20\pi}{3}) = -cos(-\frac{20\pi}{3} + 8\pi) = -cos(\frac{\pi}{3} + \pi) = cos\frac{\pi}{3} = \frac{1}{2}$ ;
> >
> > (3)因为 $\cos(\alpha-\frac{\pi}{2})=cos(\frac{\pi}{2}-\alpha)=-\frac{3}{5}$ ，所以 $\sin\alpha=-\frac{3}{5}$ ，
> >
> > 又 $\alpha$ 为第三象限角，所以 $cos\alpha = -\sqrt{1 - sin^2\alpha} = -\sqrt{1 - \left(-\frac{3}{5}\right)^2} = -\frac{4}{5}$
> >
> > 所以
> >
> > $$
> > f (\alpha + \frac {\pi}{3}) = - c o s (\alpha + \frac {\pi}{3}) = s i n \alpha s i n \frac {\pi}{3} - c o s \alpha c o s \frac {\pi}{3} = - \frac {3}{5} \times \frac {\sqrt {3}}{2} + \frac {4}{5} \times \frac {1}{2} = \frac {4 - 3 \sqrt {3}}{1 0}.
> > $$
