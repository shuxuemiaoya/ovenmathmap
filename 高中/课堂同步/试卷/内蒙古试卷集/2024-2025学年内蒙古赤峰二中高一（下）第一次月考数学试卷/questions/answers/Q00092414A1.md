> [!faq]- 2024-2025学年内蒙古赤峰二中高一（下）第一次月考数学试卷解析
>
> > [!success]- **【答案】** A
>
> > [!note]- **【解析】**
> > 因为 $\frac{\pi}{4} \leq \alpha \leq \pi$ ，则 $\frac{\pi}{2} \leq 2\alpha \leq 2\pi$ ，因为 $sin2\alpha = \frac{4}{5}$ ，则 $\frac{\pi}{2} \leq 2\alpha \leq \pi$ ，可得 $\frac{\pi}{4} \leq \alpha \leq \frac{\pi}{2}$
> >
> > 因为 $\pi \leq \beta \leq \frac{3\pi}{2}$ ，则 $\frac{\pi}{2} \leq \beta - \alpha \leq \frac{5\pi}{4}, \frac{5\pi}{4} \leq \alpha + \beta \leq 2\pi$
> >
> > 所以， $cos2\alpha = -\sqrt{1 - sin^2 2\alpha} = -\frac{3}{5}$ ， $sin(\alpha + \beta) = -\sqrt{1 - cos^2 (\alpha + \beta)} = -\frac{7\sqrt{2}}{10}$ ，所以，
> >
> > $$
> > \sin (\beta - \alpha) = \sin [ (\alpha + \beta) - 2 \alpha ] = \sin (\alpha + \beta) \cos 2 \alpha - \cos (\alpha + \beta) \sin 2 \alpha = - \frac {7 \sqrt {2}}{1 0} \times (- \frac {3}{5})
> > $$
> >
> > $$
> > - \left(- \frac {\sqrt {2}}{1 0}\right) \times \frac {4}{5} = \frac {\sqrt {2}}{2}
> > $$
> >
> > 所以， $\beta -\alpha = \frac{3\pi}{4}.$
> >
> > 故选：A.
