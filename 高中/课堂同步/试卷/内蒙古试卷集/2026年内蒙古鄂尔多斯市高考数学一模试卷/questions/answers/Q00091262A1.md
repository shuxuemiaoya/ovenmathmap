> [!faq]- 2026年内蒙古鄂尔多斯市高考数学一模试卷解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【解析】**
> > 详见解析
> >
> > (1)已知 $\{a_{n}\}$ 是等差数列，且 $a_1 + a_3 = 6$
> >
> > 由等差中项性质得： $a_1 + a_3 = 2a_2 = 6$ ，得 $a_2 = 3$
> >
> > 又 $a_{1}a_{2}=3$ ，所以 $a_{1}=1$ ，则公差 $d=a_{2}-a_{1}=2$ ，
> >
> > 所以 $a_{n}=a_{1}+(n-1)d=2n-1$ ;
> >
> > $$
> > 2 b _ {n} ^ {2} - b _ {n} b _ {n + 1} + 2 b _ {n} - b _ {n + 1} = 2 b _ {n} (b _ {n} + 1) - b _ {n + 1} (b _ {n} + 1) = (2 b _ {n} - b _ {n + 1}) (b _ {n} + 1) = 0
> > $$
> >
> > 且数列 $\{b_n\}$ 各项为正数，所以 $b_{n} + 1\neq 0$ ，故 $b_{n + 1} = 2b_{n}$
> >
> > 即数列 $\{b_n\}$ 是首项 $b_{1} = 2$ 、公比 $q = 2$ 的等比数列，
> >
> > 则 $b_{n}=2\cdot2^{n-1}=2^{n}$ ;
> >
> > (2)由 $c_{n}=\left\{\begin{aligned}&b_{n},&n\text{为奇数}\\ &\frac{1}{a_{n-1}\cdot a_{n+1}},&n\text{为偶数}\end{aligned}\right.$
> >
> > 设奇数项和为 $S_{n}$ ，设偶数项和为 $F_{n}$
> >
> > $$
> > \left| T _ {2 n} = \left(c _ {1} + c _ {3} + \dots + c _ {2 n - 1}\right) + \left(c _ {2} + c _ {4} + \dots + c _ {2 n}\right) = S _ {n} + F _ {n} \right.
> > $$
> >
> > $n$ 为奇数时 $c_{n} = b_{n} = 2^{n}$ ，奇数项为 $b_{1}, b_{3}, \ldots, b_{2n - 1}$ ，是首项为2、公比为4的等比数列，
> >
> > 故 $S_{n} = \frac{2(4^{n} - 1)}{4 - 1} = \frac{2(4^{n} - 1)}{3}$
> >
> > $\pmb{n}$ 为偶数时，设 $\pmb{n} = 2\pmb{k}(\pmb{k}\in N)$ ，则
> >
> > $$
> > c _ {2 k} = \frac {1}{a _ {2 k - 1} a _ {2 k + 1}} = \frac {1}{(4 k - 3) (4 k + 1)} = \frac {1}{4} \left(\frac {1}{4 k - 3} - \frac {1}{4 k + 1}\right),
> > $$
> >
> > 可得 $F_{n}=\frac{1}{4}\left[(1-\frac{1}{5})+\left(\frac{1}{5}-\frac{1}{9}\right)+\cdots+\left(\frac{1}{4n-3}-\frac{1}{4n+1}\right)\right]=\frac{1}{4}(1-\frac{1}{4n+1})=\frac{n}{4n+1}.$ 综上可得： $T_{2n}=S_{n}+F_{n}=\frac{2(4^{n}-1)}{3}+\frac{n}{4n+1}.$
