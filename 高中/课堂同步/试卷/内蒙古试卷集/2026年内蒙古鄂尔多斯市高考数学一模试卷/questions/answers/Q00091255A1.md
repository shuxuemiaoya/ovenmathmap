> [!faq]- 2026年内蒙古鄂尔多斯市高考数学一模试卷解析
>
> > [!success]- **【答案】** D
>
> > [!note]- **【解析】**
> > 因为 $sin^2\frac{A + B}{2} = \frac{1 - cos(A + B)}{2} = \frac{1 - cos(\pi - C)}{2} = \frac{1 + cosC}{2}$
> >
> > 所以 $b - 2a + 4a \cdot \frac{1 + \cos C}{2} = 0$ ，整理得 $b + 2a\cos C = 0$
> >
> > 得 $\sin B + 2\sin A\cos C = 0$
> >
> > 若 $C = \frac{\pi}{2}$ ，则 $\sin B = 0\Rightarrow B = 0$ ， $\pi$ ，不满足题意，故 $C\neq \frac{\pi}{2}$
> >
> > 又 $\sin B = \sin (A + C) = \sin A\cos C + \cos A\sin C$
> >
> > 所以 $\sin B + 2\sin A\cos C = \sin A\cos C + \cos A\sin C + 2\sin A\cos C = 0$ 整理得 $\tan C = -3\tan A$
> >
> > $$
> > \tan B = \tan [ \pi - (A + C) ] = - \tan (A + C) = - \frac {\tan A + \tan C}{1 - \tan A \tan C}
> > $$
> >
> > $$
> > = - \frac {\tan A - 3 \tan A}{1 + 3 \tan^ {2} A} = \frac {2}{\frac {1}{\tan A} + 3 \tan A},
> > $$
> >
> > 易知，若 $\tan A < 0$ ，则 $\tan B < 0$ ，不合题意；
> >
> > 当 $\tan A > 0$ 时， $\tan B = \frac{2}{\frac{1}{\tan A} + 3\tan A} \leqslant \frac{2}{2\sqrt{3}} = \frac{\sqrt{3}}{3}$ ，
> >
> > 当且仅当 $\tan A=\frac{\sqrt{3}}{3}$ ，即 $A=\frac{\pi}{6}$ 时，等号成立.
> > 故选：D
