> [!faq]- 2024-2025学年内蒙古赤峰实验中学高一（下）期中数学试卷解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【解析】**
> > 详见解析
> >
> > (1)因为向量 $\overrightarrow{a} = (\cos 3x, \sin 3x)$ , $\overrightarrow{b} = (-\sin (x + \frac{\pi}{6}), \cos (x + \frac{\pi}{6}))$ , 令 $f(x) = \overrightarrow{a} \cdot \overrightarrow{b}$ ,
> >
> > $$
> > f (x) = - \cos 3 x \sin \left(x + \frac {\pi}{6}\right) + \sin 3 x \cos \left(x + \frac {\pi}{6}\right) = \sin \left[ 3 x - \left(x + \frac {\pi}{6}\right) \right] = \sin \left(2 x - \frac {\pi}{6}\right),
> > $$
> >
> > 可得函数的最小正周期 $T=\frac{2\pi}{2}=\pi$ ，
> >
> > 令 $-\frac{\pi}{2} + 2k\pi \leqslant 2x - \frac{\pi}{6} \leqslant \frac{\pi}{2} + 2k\pi, k \in Z$ ，解得 $-\frac{\pi}{6} + k\pi \leqslant x \leqslant \frac{\pi}{3} + k\pi, k \in Z$
> >
> > 所以函数 $f(x)$ 的最小正周期为 $\pi$ ；函数的单调递增期间为 $\left[-\frac{\pi}{6}+k\pi,\frac{\pi}{3}+k\pi\right]$ ， $k\in Z$ ；
> >
> > (2)当 $x\in[-\frac{\pi}{6},\frac{\pi}{2}]$ 时，可得 $2x-\frac{\pi}{6}\in[-\frac{\pi}{2},\frac{5\pi}{6}]$ ，
> >
> > 当 $2x - \frac{\pi}{6} \in [\frac{\pi}{6}, \frac{5\pi}{6}]$ ，且 $2x - \frac{\pi}{6} \neq \frac{\pi}{2}$ 时， $f(x) = m$ 有两个不等的两个根，
> >
> > 且 $2x_{1}-\frac{\pi}{6}+(2x_{2}-\frac{\pi}{6})=\frac{\pi}{2}$ ，可得 $x_{1}+x_{2}=\frac{5\pi}{12}$ ，
> >
> > 所以 $m\in\left[\frac{1}{2},1\right)$ ，且两根之和为 $\frac{5\pi}{12}$ ；
> >
> > (3)在锐角三角形 $ABC$ 中，因为 $\pmb{f}(A) = 1$ ，即 $\sin (2A - \frac{\pi}{6}) = 1$ ，即 $2A - \frac{\pi}{6} = \frac{\pi}{2}$
> >
> > 可得 $A = \frac{\pi}{3}$
> >
> > 可得 $\left\{ \begin{array}{l} 0 < B < \frac{\pi}{2} \\ 0 < C = \frac{2\pi}{3} - B < \frac{\pi}{2} \end{array} \right.$ ，可得 $\frac{\pi}{6} < B < \frac{\pi}{2}$
> >
> > 又因为a=2，
> >
> > 由正弦定理可得 $\frac{b}{\sin B} = \frac{c}{\sin C} = \frac{a}{\sin A} = \frac{2}{\frac{\sqrt{3}}{2}} = \frac{4}{\sqrt{3}}$
> >
> > 所以 $b=\frac{4}{\sqrt{3}}\sin B$ , $c=\frac{4}{\sqrt{3}}\sin C$ ,
> >
> > 所以 $\triangle ABC$ 的周长为 $a + b + c = 2 + \frac{4}{\sqrt{3}} (\sin B + \sin C) = 2 + \frac{4}{\sqrt{3}} [\sin B + \sin (\frac{\pi}{3} + B)]$
> >
> > $$
> > = 2 + \frac {4}{\sqrt {3}} (\frac {\sqrt {3}}{2} \cos B + \frac {3}{2} \sin B) = 2 + 4 \sin (B + \frac {\pi}{6})
> > $$
> >
> > 因为 $B+\frac{\pi}{6}\in\left(\frac{\pi}{3},\frac{2\pi}{3}\right)$ ，所以 $\sin(B+\frac{\pi}{6})\in\left(\frac{\sqrt{3}}{2},1\right]$
> >
> > 所以该三角形的周长为 $(2+2\sqrt{3},6]$ .
