>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【解析】**
> > 详见解析
> >
> > （1）由函数 $f(x) = 2\sin (\omega x + \varphi)$ 的部分图象知， $\frac{1}{4} T = \frac{2\pi}{3} -\frac{\pi}{6} = \frac{\pi}{2}$ ，解 $T = 2\pi$ ，所以 $\omega = 1$ 又 $f(\frac{\pi}{6}) = 2\sin (\frac{\pi}{6} +\varphi) = 2$ ，所以 $\sin (\frac{\pi}{6} +\varphi) = 1$ ， $\frac{\pi}{6} +\varphi = \frac{\pi}{2} +2k\pi ,k\in Z$ ；解得 $\varphi = \frac{\pi}{3} +2k\pi ,k\in Z$ 因为 $0 <   \varphi <  \pi$ ，所以 $\varphi = \frac{\pi}{3}$ ，所以 $f(x) = 2\sin (x + \frac{\pi}{3})$ 将 $f(x)$ 图象上的每个点的横坐标变为原来的 $\frac{1}{2}$ （纵坐标不变)，得 $y = f(2x) = 2\sin (2x + \frac{\pi}{3})$ 再将所得图象向右平移 $\frac{\pi}{4}$ 个单位长度，得 $y = 2\sin [2(x - \frac{\pi}{4}) + \frac{\pi}{3}] = 2\sin (2x - \frac{\pi}{6})$ 向下平移1个单位长度，得 $y = 2\sin (2x - \frac{\pi}{6}) - 1$ ，所以 $g(x) = 2\sin (2x - \frac{\pi}{6}) - 1$ (2)因为 $\alpha$ ， $\beta$ 均为锐角， $f(\alpha -\frac{\pi}{3}) = \frac{8}{5}$ ，所以 $2\sin (\alpha -\frac{\pi}{3} +\frac{\pi}{3}) = \frac{8}{5},\sin \alpha = \frac{4}{5},$ $\cos \alpha = \sqrt{1 - sin^2\alpha} = \frac{3}{5},$ 由 $0 <   \alpha <  \frac{\pi}{2},0 <   \beta <  \frac{\pi}{2}$ ，所以 $-\frac{\pi}{2} <  \alpha -\beta <  \frac{\pi}{2}$ ，由 $sin (\alpha -\beta) = -\frac{12}{13}$ ，得
> >
> > $$
> > \cos (\alpha - \beta) = \sqrt {1 - s i n ^ {2} (\alpha - \beta)} = \frac {5}{1 3},
> > $$
> >
> > 所以 $\sin (2\alpha -\beta) = \sin \alpha \cos (\alpha -\beta) + \cos \alpha \sin (\alpha -\beta) = \frac{4}{5}\times \frac{5}{13} +\frac{3}{5}\times (-\frac{12}{13}) = -\frac{16}{65}.$
