> [!faq]- 2024-2025学年内蒙古赤峰实验中学高一（下）期中数学试卷解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【解析】**
> > 详见解析
> >
> > (1)因为 $a^{2}+b^{2}-c^{2}=\sqrt{2}ab$ ，
> >
> > 所以由余弦定理得 $\cos C = \frac{a^2 + b^2 - c^2}{2ab} = \frac{\sqrt{2}ab}{2ab} = \frac{\sqrt{2}}{2}$ ，结合 $C$ 为三角形的内角，可得 $C = \frac{\pi}{4}$ 因为 $\sin C = \sqrt{2}\cos B = \frac{\sqrt{2}}{2}$ ，所以 $\cos B = \frac{1}{2}$ ，结合 $B \in (0, \pi)$ ，得 $B = \frac{\pi}{3}$ ；  
> > (2)由(1)可知 $A = \pi - B - C = \frac{5\pi}{12}$ ，设△ABC的外接圆半径为 $R$ ，由正弦定理得 $b = 2R\sin B = \sqrt{3}R$ ， $c = 2R\sin C = \sqrt{2}R$ ，由 $S_{\triangle ABC} = \frac{1}{2} bc\sin A = 3 + \sqrt{3}$ ，得 $\frac{1}{2} \cdot \sqrt{3}R \cdot \sqrt{2}R \cdot \sin \frac{5\pi}{12} = 3 + \sqrt{3}$ ，即 $\frac{\sqrt{6}R^2}{2} \cdot \frac{\sqrt{6} + \sqrt{2}}{4} = 3 + \sqrt{3}$ ，解得 $R^2 = 4$ ，所以 $R = 2$ （舍负），可得 $c = \sqrt{2}R = 2\sqrt{2}$ .
