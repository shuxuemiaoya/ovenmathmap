> [!faq]- 2022-2023学年内蒙古呼和浩特二中高一（下）期末数学试卷解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【解析】**
> > 详见解析
> >
> > （1）由已知及正弦定理，得 $\frac{a - b}{c} = \frac{a - c}{a + b}$ 即 $(a - b)(a + b) = c(a - c)$ 即 $a^2 -b^2 = ac - c^2$ 即 $a^2 +c^2 -b^2 = ac.$
> >
> > 由余弦定理，得 $cosB = \frac{a^2 + c^2 - b^2}{2ac} = \frac{1}{2}$
> >
> > 因为 $B \in (0^{\circ}, 180^{\circ})$ ,
> >
> > 所以 $B=60^{\circ}$ .
> >
> > (2)因为 $A + C = 120^{\circ}$ ， $c = 2$ ，由正弦定理，得
> >
> > $$
> > a = \frac {c \sin A}{\sin C} = \frac {2 \sin (1 2 0 ^ {\circ} - C)}{\sin C} = \frac {\sqrt {3} \cos C + \sin C}{\sin C} = \frac {\sqrt {3}}{\tan C} + 1.
> > $$
> >
> > 所以 $S = \frac{1}{2} acsin B = asin60^{\circ} = \frac{\sqrt{3}}{2} (\frac{\sqrt{3}}{tanC} +1).$
> >
> > 因为 $\triangle ABC$ 为锐角三角形，则 $30^{\circ} < C < 90^{\circ}$ ，从而 $\tan C \in \left(\frac{\sqrt{3}}{3}, +\infty\right)$ ，
> >
> > 所以 $S\in(\frac{\sqrt{3}}{2},2\sqrt{3}).$
