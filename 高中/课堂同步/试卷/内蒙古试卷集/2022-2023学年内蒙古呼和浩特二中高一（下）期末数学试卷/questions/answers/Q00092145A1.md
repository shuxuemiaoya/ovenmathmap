> [!faq]- 2022-2023学年内蒙古呼和浩特二中高一（下）期末数学试卷解析
>
> > [!success]- **【答案】** A
>
> > [!note]- **【解析】**
> > 对于 $A$ ，因为 $\sin^2 A + \sin^2 B < \sin^2 C$ ，所以 $a^2 + b^2 < c^2$ ， $\cos C = \frac{a^2 + b^2 - c^2}{2ab} < 0$ ， $C$ 为钝角， $\triangle ABC$ 是钝角三角形，选项 $A$ 正确；
> >
> > 对于 $B$ ，由 $a = 8$ ， $c = 10$ ， $B = 60^{\circ}$ ，利用余弦定理得$b^{2}=a^{2}+c^{2}-2ac\cos B=64+100-2\times8\times10\times\cos60^{\circ}=84$ ，解得 $b=2\sqrt{21}$ ，所以符合条件的△ABC有1个，选项B错误；
> >
> > $$
> > a \cos B = \sqrt {3}
> > $$
> >
> > $\frac{asinB}{acosB} = \frac{3}{\sqrt{3}}$ ，解得 $\tan B = \sqrt{3}$ ，又 $B\in (0,\pi)$ ，所以 $B = \frac{\pi}{3}$ ，选项 $C$ 错误；
> >
> > $$
> > a \sin B = b \sin A = 3
> > $$
> >
> > 对于 $D$ ，斜三角形 $ABC$ 中， $A + B + C = \pi$ ， $A + B = \pi -C$ ，所以
> >
> > $\tan (A + B) = \tan (\pi - C) = -\tan C$ ，即 $\tan (A + B) = \frac{\tan A + \tan B}{1 - \tan A\tan B}$ ，
> >
> > $$
> > - \tan C (1 - \tan A \tan B) = \tan A + \tan B
> > $$
> >
> > $$
> > \tan A + \tan B + \tan C = \tan A \tan B \tan C
