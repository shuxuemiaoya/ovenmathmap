> [!faq]- 2023-2024学年内蒙古乌海一中高一（下）期中数学试卷解析
>
> > [!success]- **【答案】** 四
>
> > [!note]- **【解析】**
> > 由 $e^{i\theta}=\cos\theta+i\sin\theta$
> >
> > $$
> > { } ^ { 3 } z = \frac { e ^ { \frac { \pi } { 4 } i } } { e ^ { \frac { \pi } { 2 } i } } = \frac { c o s \frac { \pi } { 4 } + i s i n \frac { \pi } { 4 } } { c o s \frac { \pi } { 2 } + i s i n \frac { \pi } { 2 } } = \frac { \frac { \sqrt { 2 } } { 2 } + \frac { \sqrt { 2 } } { 2 } i } { i } = \frac { \frac { \sqrt { 2 } } { 2 } i + \frac { \sqrt { 2 } } { 2 } i ^ { 2 } } { - 1 } = \frac { \sqrt { 2 } } { 2 } - \frac { \sqrt { 2 } } { 2 } i .
> > $$
> >
> > 则复数 $z = \frac{e^{\frac{\pi}{4}i}}{e^{\frac{\pi}{2}i}}$ 在复平面内对应的点才坐标为 $\left(\frac{\sqrt{2}}{2}, -\frac{\sqrt{2}}{2}\right)$ ，在第四象限.
