> [!faq]- 2023-2024学年内蒙古乌海一中高一（下）期中数学试卷解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【解析】**
> > 详见解析
> >
> > (1) $\triangle ABC$ 中， $\sin B - 2\sqrt{3}\cos^2\frac{A + C}{2} = 0$
> >
> > 所以 $sinB - 2\sqrt{3} sin^2 \frac{B}{2} = 0$
> >
> > 故 $sinB = 2\sqrt{3} sin^2 \frac{B}{2}$ ，即 $2sin\frac{B}{2} cos\frac{B}{2} = 2\sqrt{3} sin^2 \frac{B}{2}$
> >
> > 由于 $0 < B < \pi$ ，得 $\sin \frac{B}{2} > 0$
> >
> > 所以 $cos\frac{B}{2}=\sqrt{3}sin\frac{B}{2}$
> >
> > 即 $tan\frac{B}{2}=\frac{\sqrt{3}}{3}$ ，
> >
> > 又 $0 < B < \pi$ ，故 $0 < \frac{B}{2} < \frac{\pi}{2}$
> >
> > 所以 $\frac{B}{2} = \frac{\pi}{6}$ ，解得 $B = \frac{\pi}{3}$
> >
> > (2)由题设及(1)知 $\triangle ABC$ 的面积 $S_{\triangle ABC} = \frac{\sqrt{3}}{4} a$
> >
> > 由正弦定理得 $a = \frac{csinA}{sinC} = \frac{csin(120^{\circ} - C)}{sinC}$
> >
> > $\begin{aligned} & = \frac{c(sin120^{\circ}\cos C - \cos 120^{\circ}\sin C)}{\sin C}\\ & = \frac{\frac{\sqrt{3}}{2}\cos C + \frac{1}{2}\sin C}{\sin C}\\ & = \frac{\sqrt{3}}{2\tan C} +\frac{1}{2}, \end{aligned}$
> >
> > 由于 $\triangle ABC$ 为锐角三角形，故 $0 < A < \frac{\pi}{2}$ ， $0 < C < \frac{\pi}{2}$ ，
> >
> > 由(1)知 $A+C=\frac{2\pi}{3}$ ，所以 $\frac{\pi}{6}<C<\frac{\pi}{2}$ ，
> >
> > 所以 $\tan C > \frac{\sqrt{3}}{3}$ ，所以 $0 < \frac{1}{\tan C} < \sqrt{3}$ ，
> >
> > 所以 $0 < \frac{\sqrt{3}}{2\tan C} < \frac{3}{2}$ ，所以 $\frac{1}{2} < \frac{\sqrt{3}}{2\tan C} +\frac{1}{2} < 2$
> >
> > 故 $\frac{1}{2} < a < 2$ ，从而 $\frac{\sqrt{3}}{8} < S_{\triangle ABC} < \frac{\sqrt{3}}{2}$
> >
> > 则 $\triangle ABC$ 面积的取值范围是 $(\frac{\sqrt{3}}{8}, \frac{\sqrt{3}}{2})$ .
