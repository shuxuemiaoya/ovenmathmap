> [!faq]- 2024-2025学年内蒙古呼和浩特二中高一（下）期中数学试卷解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【解析】**
> > 详见解析
> >
> > (1)因为 $c \cdot \sin A = \sqrt{3}a \cdot \cos C$
> >
> > 所以 $\sin C\sin A=\sqrt{3}\sin A\cos C$
> >
> > 又因为 $\sin A > 0$
> >
> > 可得 $\sin C = \sqrt{3}\cos C$ ，可得 $tanC = \sqrt{3}$
> >
> > 而C为三角形内角，
> >
> > 所以 $C = \frac{\pi}{3}$
> >
> > (2)由于 $\sin C + \sin (B - A) = 5\sin 2A$
> >
> > 所以 $\sin (B + A) + \sin (B - A) = 5\sin 2A$
> >
> > 所以 $2\sin B\cos A = 5\sin 2A = 10\sin A\cos A$
> >
> > 所以 $\cos A = 0$ 或 $\sin B = 5\sin A$
> >
> > 若 $\cos A = 0$ ，而 $A$ 为三角形内角，可得 $A = \frac{\pi}{2}$ ，可得 $c = \frac{\sqrt{3}a}{2}$
> >
> > 可得 $a = \frac{2}{\sqrt{3}} c = \frac{2}{\sqrt{3}} \times \sqrt{21} = 2\sqrt{7}$ ，此时可得 $B = \frac{\pi}{6}$ ， $b = a \sin B = 2\sqrt{7} \times \frac{1}{2} = \sqrt{7}$ ；
> >
> > 若 $\sin B = 5\sin A$ ，则 $b = 5a$ ，由 $c^2 = a^2 + b^2 - 2ab\cos C$ ，可得 $21 = 26a^2 - 5a^2 = 21a^2$
> >
> > 可得 $a = 1, b = 5$
> >
> > 综上， $a = 2\sqrt{7}$ ， $b = \sqrt{7}$ 或 $a = 1$ ， $b = 5$
