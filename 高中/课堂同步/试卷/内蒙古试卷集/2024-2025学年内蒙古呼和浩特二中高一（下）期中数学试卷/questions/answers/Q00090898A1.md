> [!faq]- 2024-2025学年内蒙古呼和浩特二中高一（下）期中数学试卷解析
>
> > [!success]- **【答案】** ACD
>
> > [!note]- **【解析】**
> > A选项，由正弦定理可知 $\sin A > \sin B \Leftrightarrow a > b \Leftrightarrow A > B$ ，
> >
> > 因为 $0 < B < A < \pi$ ，且余弦函数 $y = \cos x$ 在 $(0, \pi)$ 上单调递减，故 $\cos A < \cos B$
> >
> > 所以在 $\triangle ABC$ 中， $\sin A > \sin B$ 是 $\cos A < \cos B$ 的充要条件， $A$ 选项对；
> >
> > $B$ 选项，因为 $a\cos A = b\cos B$ ，即 $a\bullet \frac{b^2 + c^2 - a^2}{2bc} = b\bullet \frac{a^2 + c^2 - b^2}{2ac}$
> >
> > 整理可得 $(a^2 - b^2)(a^2 + b^2 - c^2) = 0$ ，可得 $a = b$ 或 $a^2 + b^2 = c^2$
> >
> > 所以， $\triangle ABC$ 为等腰三角形或直角三角形， $B$ 选项错；
> >
> > C选项，在锐角△ABC中，A为锐角，则 $B+C>\frac{\pi}{2}$ ，可得 $B>\frac{\pi}{2}-C$ ，
> >
> > 因为 $B$ 、 $C\in \left(0,\frac{\pi}{2}\right)$ ，所以 $0 <   \frac{\pi}{2} -C <   B <   \frac{\pi}{2}$
> >
> > 因为正弦函数 $y = \sin x$ 在 $(0, \frac{\pi}{2})$ 上为增函数，所以 $\sin (\frac{\pi}{2} - C) < \sin B$ ，即 $\sin B > \cos C$ ， $C$ 选项对；
> >
> > $D$ 选项，因为 $a^2 + b^2 = ab\cos C + \sqrt{3} absinC = 2absin(C + \frac{\pi}{6})$
> >
> > 由基本不等式可得 $a^2 + b^2 = 2ab\sin \left(C + \frac{\pi}{6}\right) \geq 2ab$ ，可得 $sin \left(C + \frac{\pi}{6}\right) \geq 1$
> >
> > 又因为 $\sin(C+\frac{\pi}{6})\leq1$ ，所以 $\sin(C+\frac{\pi}{6})=1$ ，
> >
> > 因为 $0 < C < \pi$ ，所以 $\frac{\pi}{6} < C + \frac{\pi}{6} < \frac{7\pi}{6}$ ，则 $C + \frac{\pi}{6} = \frac{\pi}{2}$ ，所以 $C = \frac{\pi}{3}$
> >
> > 此时 $a^2 + b^2 = 2ab\sin \left(C + \frac{\pi}{6}\right) = 2ab\sin \frac{\pi}{2} = 2ab$ ，即 $(a - b)^2 = 0$ ，所以 $a = b$
> >
> > 所以 $\triangle ABC$ 为等边三角形， $D$ 选项对.
> >
> > 故选：ACD.
