> [!faq]- 2024-2025学年内蒙古包头昆都仑区包头市第六中学高一下学期期中数学试卷解析
>
> > [!success]- **【答案】** ①②
>
> > [!note]- **【分析】**
> > 根据空间中线线、线面、面面的位置关系一一判断即可.
>
> > [!note]- **【解析】**
> > ① $a / / b$ ， $b / / c$ ，由平行公理得出 $a / / c$ ，故①正确；
> >
> > ② $\alpha // \beta, \beta // \gamma$ ，由面面平行的性质得出 $\alpha // \gamma$ ，故②正确；
> >
> > ③ $a//b,\ a// \alpha\Rightarrow b// \alpha$ 或 $b\subset\alpha$ ，故③错误；
> >
> > ④ $a//\alpha,\alpha//\beta\Rightarrow a//\beta$ 或 $a\subset\beta$ ，故④错误.
> >
> > 故答案为：①②.
