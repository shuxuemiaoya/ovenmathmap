> [!faq]- 2024-2025学年内蒙古赤峰二中高一（下）第二次月考数学试卷解析
>
> > [!success]- **【答案】** B
>
> > [!note]- **【解析】**
> > 因为 $1 + i$ 是关于 $\pmb{x}$ 的方程 $x^{2} + ax + b = 0(a, b \in R)$ 的一个解，
> >
> > 所以1 - i是关于x的方程 $x^{2} + ax + b = 0 (a, b \in R)$ 的另一个解，
> >
> > 由韦达定理可得， $\left\{ \begin{array}{l}(1 + i) + (1 - i) = -a\\ (1 + i)(1 - i) = b \end{array} \right.$
> >
> > 解得 $\left\{\begin{aligned}a&=-2\\ b&=2\end{aligned}\right.$
> >
> > 所以 $a^{2}+b^{2}=4+4=8.$
> >
> > 故选：B.
