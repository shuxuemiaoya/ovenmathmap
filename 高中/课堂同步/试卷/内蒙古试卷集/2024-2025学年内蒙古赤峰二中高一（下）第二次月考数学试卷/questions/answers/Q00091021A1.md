> [!faq]- 2024-2025学年内蒙古赤峰二中高一（下）第二次月考数学试卷解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【解析】**
> > 详见解析
> >
> > (1) $(b - c)\sin B = b\sin (A - C)$ ，所以 $(b - c)\sin B = b$ ( $\sin A\cos C - \cos A\sin C$ )
> >
> > $$
> > b ^ {2} - b c = a b \cos C - b c \cos A = \frac {a ^ {2} + b ^ {2} - c ^ {2}}{2} - \frac {b ^ {2} + c ^ {2} - a ^ {2}}{2} = a ^ {2} - c ^ {2}
> > $$
> >
> > 又 $a^{2}=b^{2}+c^{2}-2bc\cos A$ ，所以 $\cos A=\frac{1}{2}$
> >
> > 因为 $A\in(0,\pi)$ ，所以 $A=\frac{\pi}{3}$ .
> >
> > (2) $b=(\sqrt{3}-1)c$ ，所以 $sinB=(\sqrt{3}-1)sinC$ ，
> >
> > 所以 $\sin(A+C)=\sin(C+\frac{\pi}{3})=(\sqrt{3}-1)\sin C$ ,
> >
> > 即 $\frac{1}{2}\sin C + \frac{\sqrt{3}}{2}\cos C = (\sqrt{3} - 1)\sin C$ ，所以 $\tan C = 2 + \sqrt{3}$ ，则 $C = 75^{\circ}$ .
> >
> > (3)由(1)可知 $S=\frac{1}{2}bcsinA=\frac{\sqrt{3}}{4}bc$ ， $a^{2}=b^{2}+c^{2}-bc.$
> >
> > $$
> > \frac {a ^ {2} + b ^ {2} + c ^ {2}}{S} = \frac {4 \sqrt {3}}{3} \cdot \frac {a ^ {2} + b ^ {2} + c ^ {2}}{b c} = \frac {4 \sqrt {3}}{3} \cdot \frac {2 b ^ {2} + 2 c ^ {2} - b c}{b c} = \frac {8 \sqrt {3}}{3} (\frac {b}{c} + \frac {c}{b}) - \frac {4 \sqrt {3}}{3}
> > $$
> >
> > 因为 $\triangle ABC$ 锐角三角形，所以 $\left\{ \begin{array}{l}0 < C < \frac{\pi}{2}\\ 0 < \frac{2\pi}{3} -C < \frac{\pi}{2} \end{array} \right.$ ，整理得 $\frac{\pi}{6} < C < \frac{\pi}{2}$
> >
> > 因为 $\frac{b}{c} = \frac{\sin B}{\sin C} = \frac{\sin(A + C)}{\sin C} = \frac{\sin A\cos C + \cos A\sin C}{\sin C} = \frac{\sqrt{3}}{2\tan C} +\frac{1}{2}$ ，所以 $\frac{1}{2} <  \frac{b}{c} <  2.$
> >
> > 令 $\frac{b}{c}=t$ ，则函数 $y=t+\frac{1}{t}$ 在 $(\frac{1}{2},1)$ 上单调递减，在 $(1,2)$ 上单调递增，所以 $y\in[2,\frac{5}{2})$ ，即 $\frac{b}{c}+\frac{c}{b}\in[2,\frac{5}{2})$ 故 $\frac{a^{2}+b^{2}+c^{2}}{S}$ 的取值范围为 $[4\sqrt{3},\frac{16\sqrt{3}}{3})$ .
