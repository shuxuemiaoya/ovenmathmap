> [!faq]- 2024-2025学年内蒙古包头九中高二（上）期中数学试卷解析
>
> > [!success]- **【答案】** AB
>
> > [!note]- **【解析】**
> > 设点 $P$ 坐标为 $(m, n)$ ，若存在过点 $P$ 的无数对互相垂直的直线 $l_{1}$ 和 $l_{2}$
> >
> > 则一定有无数对直线 $l_{1}$ 和 $l_{2}$ 的斜率存在，且它们的斜率之积等于-1.
> >
> > 设直线 $l_{1}$ 、 $l_{2}$ 的方程分别为 $y - n = k(x - m)$ ， $y - n = -\frac{1}{k} (x - m)$ ，即： $kx - y + n - km = 0$ ， $x + ky - kn - m = 0$
> >
> > 因为两圆半径相等，且直线 $l_{1}$ 被圆 $C_1$ 截得的弦长等于直线 $l_{2}$ 被圆 $C_2$ 截得的弦长，
> >
> > 所以 $C_1(-3,1)$ 到直线 $l_{1}$ 的距离等于 $C_2(4,5)$ 到直线 $l_{2}$ 的距离，即 $\frac{|-3k - 4 + n - km|}{\sqrt{k^2 + 1}} = \frac{|4 + 5k - kn - m|}{\sqrt{1 + k^2}}$ ，化简得 $(2 - m - n)k = m - n - 3$ 或 $(m - n + 8)k = m + n - 5$ ，因为关于 $k$ 的方程有无穷多个解，所以 $\left\{ \begin{array}{l}2 - m - n = 0\\ m - n - 3 = 0 \end{array} \right.$ 或 $\left\{ \begin{array}{l}m - n + 8 = 0\\ m + n - 5 = 0 \end{array} \right.$ ，解得 $\left\{ \begin{array}{l}m = \frac{5}{2}\\ n = -\frac{1}{2} \end{array} \right.$ 或 $\left\{ \begin{array}{l}m = -\frac{3}{2}\\ n = \frac{13}{2} \end{array} \right.$ 即满足条件的点 $P$ 坐标为 $(\frac{5}{2}, - \frac{1}{2})$ 或 $(- \frac{3}{2},\frac{13}{2})$ 故选： $AB$
> >
> > 故选：AB.
