> [!faq]- 2022-2023学年内蒙古包头高一下学期期末数学试卷解析
>
> > [!success]- **【答案】** 详见解析 (2)乙出发 $\frac{2}{3}$ 分钟后，乙在缆车上与甲的最短距离为 $40\sqrt{5}\mathrm{m}$
>
> > [!note]- **【分析】**
> > (1) 由 $\sin B = \sin (A + C) = \frac{56}{65}$ ，结合正弦定理，即可求解；
>
> > [!note]- **【解析】**
> > (1) 由 $\sin A = \frac{3}{5}, \sin C = \frac{5}{13}$
> >
> > 得 $\cos A = \frac{4}{5},\cos C = \frac{12}{13}$ ，又 $A + B + C = \pi$
> >
> > 可得
> >
> > $$
> > \sin B = \sin (A + C) = \sin A \cos C + \cos A \sin C = \frac {3}{5} \times \frac {1 2}{1 3} + \frac {4}{5} \times \frac {5}{1 3} = \frac {5 6}{6 5}
> > $$
> >
> > 由正弦定理 $\frac{AB}{\sin C} = \frac{AC}{\sin B}$ ，得 $AB = \frac{2520}{\frac{56}{65}} \times \frac{5}{13} = 1125(\mathrm{m})$
> >
> > 所以索道AB的长度为1125（m）.
> >
> > (2) 设乙出发 $t\left(0 < t \leq \frac{45}{4}\right)$ 分钟时，甲、乙之间的距离为 $h$ ，由余弦定理，可得
> >
> > $$
> > h ^ {2} = (1 0 0 t) ^ {2} + 5 0 ^ {2} (t + 2) ^ {2} - 2 \times 1 0 0 t \times 5 0 (t + 2) \times \frac {4}{5} = 5 0 ^ {2} \left(\frac {9}{5} t ^ {2} - \frac {1 2}{5} t + 4\right)
> > $$
> >
> > 当 $t = \frac{2}{3}$ 时， $h^2$ 取最小值．此时， $h$ 的最小值为 $40\sqrt{5}(\mathbf{m})$
> >
> > 所以，乙出发 $\frac{2}{3}$ 分钟后，乙在缆车上与甲的最短距离为 $40 \sqrt{5} \mathrm{~m}$ .
