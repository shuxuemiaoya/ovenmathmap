> [!faq]- 2023-2024学年4月内蒙古包头昆都仑区包钢第九中学高一下学期月考数学试卷解析
>
> > [!success]- **【答案】** B
>
> > [!note]- **【分析】**
> > 利用正弦定理及三角恒等变换化简求出角即可得解.
>
> > [!note]- **【解析】**
> > 因为 $2\cos^{2}\frac{A}{2}=\frac{b+c}{b}$ ,
> >
> > 所以 $1 + \cos A = 1 + \frac{c}{b}$ ，即 $\cos A = \frac{c}{b}$ ，即 $\cos A = \frac{\sin C}{\sin B}$
> >
> > 所以 $\cos A\sin B = \sin C$
> >
> > 在 $\triangle ABC$ 中， $A + B + C = \pi$
> >
> > 所以 $\sin C = \sin (A + B)$
> >
> > 所 以
> >
> > $\cos A \sin B = \sin (A + B) = \sin A \cos B + \cos A \sin B,$
> >
> > 所以 $\sin A\cos B = 0$
> >
> > 因为 $0 < A < \pi$ ，所以 $\sin A \neq 0$ ，则 $\cos B = 0$
> >
> > 所以 $B=\frac{\pi}{2}$ ，所以△ABC为直角三角形，
> >
> > 故选：B.
