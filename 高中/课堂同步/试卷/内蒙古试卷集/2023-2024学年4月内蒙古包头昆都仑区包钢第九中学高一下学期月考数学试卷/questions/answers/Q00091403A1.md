> [!faq]- 2023-2024学年4月内蒙古包头昆都仑区包钢第九中学高一下学期月考数学试卷解析
>
> > [!success]- **【答案】** $\frac{\sqrt{7}}{14}$
>
> > [!note]- **【分析】**
> > 根据余弦定理求得c，进而求得 $\cos B$ .
>
> > [!note]- **【解析】**
> > 由余弦定理， $a^2 = b^2 +c^2 -2bc\cos A = b^2 +c^2 -bc,$
> >
> > 因为 $b - c = 1, a = \sqrt{7}$ ，所以 $c^2 + (c + 1)^2 - c(c + 1) = 7$
> >
> > 即 $c^2 + c - 6 = 0$ ，解得 $c = 2$ 或 $c = -3$ （舍），
> >
> > 所以 $b = 3, c = 2, \cos B = \frac{a^2 + c^2 - b^2}{2ac} = \frac{7 + 4 - 9}{2 \times \sqrt{7} \times 2} = \frac{\sqrt{7}}{14}$ .
> >
> > 故答案为： $\frac{\sqrt{7}}{14}$
