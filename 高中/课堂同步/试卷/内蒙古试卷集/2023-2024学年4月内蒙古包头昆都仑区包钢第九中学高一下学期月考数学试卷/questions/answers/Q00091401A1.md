> [!faq]- 2023-2024学年4月内蒙古包头昆都仑区包钢第九中学高一下学期月考数学试卷解析
>
> > [!success]- **【答案】** AB
>
> > [!note]- **【解析】**
> > A项：设△ABC的内角A、B、C所对的边分别为a、b、c，
> > 因为 $\sin A:\sin B:\sin C=2:3:\sqrt{7}$ ，所以由正弦定理可得
> >
> > $a:b:c = 2:3:\sqrt{7}$ ，设 $a = 2t$ ， $b = 3t$ ， $c = \sqrt{7} t(t > 0)$ ，因为
> >
> > $S_{\triangle ABC} = 6\sqrt{3}$ ，所以 $6\sqrt{3} = \sqrt{\frac{1}{4}\left[7t^2\times 4t^2 - \left(\frac{7t^2 + 4t^2 - 9t^2}{2}\right)^2\right]}$
> >
> > 解得 $t = 2$ ，则 $a = 4$ ， $b = 6$ ， $c = 2\sqrt{7}$ ，故△ABC的周长为 $10 + 2\sqrt{7}$ ，A正确；
> >
> > B项：因为 $\cos C = \frac{a^2 + b^2 - c^2}{2ab} = \frac{16 + 36 - 28}{2\times 4\times 6} = \frac{1}{2},$
> >
> > 所以 $C = \frac{\pi}{3}$ ， $A + B = \pi -\frac{\pi}{3} = \frac{2\pi}{3} = 2C$ ，故B正确；
> >
> > C项：因为 $C=\frac{\pi}{3}$ ，所以 $\sin C=\frac{\sqrt{3}}{2}$ ，由正弦定理得
> >
> > $2R = \frac{c}{\sin C} = \frac{2\sqrt{7}}{\sqrt{3}} = \frac{4\sqrt{21}}{3}, R = \frac{2\sqrt{21}}{3}, C$ 错误；
> >
> > D项：由余弦定理得 $\cos B = \frac{a^2 + c^2 - b^2}{2ac} = \frac{16 + 28 - 36}{2\times 4\times 2\sqrt{7}} = \frac{\sqrt{7}}{14}$ ，在
> >
> > $\triangle BCD$ 中 $BC = 4$ ， $BD = \sqrt{7}$ ，由余弦定理得
> >
> > $\cos B = \frac{16 + 7 - CD^2}{2\times 4\times\sqrt{7}} = \frac{\sqrt{7}}{14}$ ，解得 $CD = \sqrt{19}$ ，D错误.
> >
> > 故选：AB.
