> [!faq]- 2022-2023学年内蒙古呼和浩特市新城区土默特中学高一（下）开学数学试卷解析
>
> > [!success]- **【答案】** BD
>
> > [!note]- **【解析】**
> > $A$ ：当 $\frac{a}{b} < 0$ 时， $\frac{b}{a} +\frac{a}{b} = -[(-\frac{b}{a}) + (-\frac{a}{b})]\leq -2\sqrt{(-\frac{b}{a})\bullet(-\frac{a}{b})} = -2$ ，当且仅当 $a = b$ 时取
> >
> > 等号，故A错误，
> >
> > $B$ ：解不等式 $\frac{2x - 1}{3x + 1} < 0$ 可得： $-\frac{1}{3} < x < \frac{1}{2}$ ，所以不等式的解集为 $\{x\mid -\frac{1}{3} < x < \frac{1}{2}\}$ ，故 $B$ 正确，
> >
> > $C$ ：解方程 $x^{2} - 3x - 4 = 0$ 可得： $x = 4$ 或-1，所以函数的零点为4或-1，故 $C$ 错误，
> >
> > $D$ ：函数 $f(x) = \frac{x^4 - 1}{x^2 + 1} = x^2 - 1, x \in R$ ，函数 $g(x) = x^2 - 1, x \in R$ ，所以函数 $f(x)$ 与 $g(x)$ 为同一函数，故 $D$ 正确，
> >
> > 故选：BD.
