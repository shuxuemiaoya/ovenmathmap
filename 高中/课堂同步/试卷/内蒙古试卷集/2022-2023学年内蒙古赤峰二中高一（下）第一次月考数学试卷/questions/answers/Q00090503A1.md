> [!faq]- 2022-2023学年内蒙古赤峰二中高一（下）第一次月考数学试卷解析
>
> > [!success]- **【答案】** (1,2)
>
> > [!note]- **【解析】**
> > 由正弦定理和正弦二倍角公式可得
> >
> > $2\sin C\sin (B - A) = 2\sin A\sin A\cos B + \sin B\sin 2A = 2\sin A\sin A\cos B + 2\sin B\sin$ $A\cos A = 2\sin A(\sin A\cos B + \sin B\cos A) = 2\sin A\sin (A + B)$
> >
> > 因为 $0 < C < \frac{\pi}{2}$ , $\pi - C = A + B$ , 所以 $\sin (\pi - C) = \sin (A + B) = \sin C \neq 0$ ,
> >
> > 可得 $\sin (B - A) = \sin A$
> >
> > 因为 $0 < A < \frac{\pi}{2}$ , $0 < B < \frac{\pi}{2}$ , 所以 $-\frac{\pi}{2} < B - A < \frac{\pi}{2}$ ,
> >
> > 所以 $B=2A$ , $C=\pi-3A$
> >
> > $$
> > 0 <   B = 2 A <   \frac {\pi}{2}, 0 <   C = \pi - 3 A <   \frac {\pi}{2} \text {可得} \frac {\pi}{6} <   A <   \frac {\pi}{4}
> > $$
> >
> > 所以 $\frac{\sqrt{2}}{2} <  cosA <   \frac{\sqrt{3}}{2}$ ， $\frac{1}{2} <  cos^2 A <   \frac{3}{4}$
> >
> > 由正弦定理得
> >
> > $$
> > \begin{array}{l} \frac {c}{a} = \frac {\sin C}{\sin A} = \frac {\sin 3 A}{\sin A} = \frac {\sin (2 A + A)}{\sin A} = \frac {\sin 2 A \cos A + \cos 2 A \sin A}{\sin A} = 2 \cos^ {2} A + \cos 2 A \\ = 4 \cos^ {2} A - 1 \in (1, 2) \end{array}
> > $$
> >
> > 故答案为：(1,2).
