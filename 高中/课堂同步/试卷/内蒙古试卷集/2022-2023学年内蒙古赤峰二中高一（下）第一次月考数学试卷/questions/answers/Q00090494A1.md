> [!faq]- 2022-2023学年内蒙古赤峰二中高一（下）第一次月考数学试卷解析
>
> > [!success]- **【答案】** D
>
> > [!note]- **【解析】**
> > 因为 $b\cos C + c\sin B = a$
> >
> > 所以由正弦定理可得 $\sin B\cos C + \sin C\sin B = \sin A$
> >
> > $$
> > \sin A = \sin (B + C) = \sin B \cos C + \cos B \sin C
> > $$
> >
> > 所以 $\sin B\cos C + \sin C\sin B = \sin B\cos C + \cos B\sin C$ ，即 $\sin C\sin B = \cos B\sin C$ 又 $C$ 为三角形内角， $\sin C\neq 0$
> >
> > 所以 $\sin B = \cos B$ ，即 $\tan B = 1$
> >
> > 因为 $B \in (0, \pi)$ ,
> >
> > 所以 $B=\frac{\pi}{4}$ ，
> >
> > 因为 $b = 6$ ，由正弦定理可得 $\frac{a}{\sin A} = \frac{b}{\sin B} = \frac{6}{\frac{\sqrt{2}}{2}} = 6\sqrt{2}$
> >
> > $$
> > \frac {a + 2 b}{\sin A + 2 \sin B} = \frac {6 \sqrt {2} \sin A + 2 \times 6 \sqrt {2} \sin B}{\sin A + 2 \sin B} = 6 \sqrt {2}.
> > $$
> >
> > 故选：D.
