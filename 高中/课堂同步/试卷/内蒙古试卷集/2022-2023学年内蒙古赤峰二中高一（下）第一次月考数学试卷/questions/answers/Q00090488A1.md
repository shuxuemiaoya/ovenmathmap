> [!faq]- 2022-2023学年内蒙古赤峰二中高一（下）第一次月考数学试卷解析
>
> > [!success]- **【答案】** C
>
> > [!note]- **【解析】**
> > 由 $x^{2} - x > 0$ ，解得 $x <   0$ 或 $x > 1$ ，即 $A = \{x\mid x <   0$ 或 $x > 1\}$
> >
> > 由 $|x|>1$ ，解得x>1或x<-1，即 $B=\{x\mid x<-1$ 或 $x>1\}$ .
> >
> > 则 $A \cup B = \{x \mid x < 0 \text{或} x > 1\}$ ，故选项 $A$ 错误； $A \cap B = \{x \mid x < -1 \text{或} x > 1\}$ ，故选项 $B$ 错误；
> >
> > 根据集合间的包含关系，可知 $B \subseteq A$ ，故选项C正确，选项D错误.
> >
> > 故选：C.
