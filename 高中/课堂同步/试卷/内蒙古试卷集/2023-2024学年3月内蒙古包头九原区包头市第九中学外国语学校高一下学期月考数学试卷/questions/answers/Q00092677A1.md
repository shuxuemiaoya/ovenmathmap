> [!faq]- 2023-2024学年3月内蒙古包头九原区包头市第九中学外国语学校高一下学期月考数学试卷解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【分析】**
> > （1）先将函数 $f(x)$ 化简为 $y = A\sin (\omega x + \varphi) + k$ 的形式，再根据正弦函数的单调性求解单调区间；
>
> > [!note]- **【解析】**
> > 详见解析
> >
> > （1） $f(x) = \sqrt{3} - 2\sqrt{3}\sin^2 x + (\sin x + \cos x)^2 = \sqrt{3}(1 - 2\sin^2 x) + (\sin^2 x + 2\sin x\cos x + \cos^2 x) = \sqrt{3}\cos 2x + \sin 2x + 1 = 2\sin \left(2x + \frac{\pi}{3}\right) + 1.$ 由 $2k\pi + \frac{\pi}{2} \leq 2x + \frac{\pi}{3} \leq 2k\pi + \frac{3\pi}{2}, k \in \mathbb{Z}$ ，解得 $k\pi + \frac{\pi}{12} \leq x \leq k\pi + \frac{7\pi}{12}, k \in \mathbb{Z}$ ，
> >
> > 所以 $f(x)$ 的单调递减区间是 $[k\pi + \frac{\pi}{12}, k\pi + \frac{7\pi}{12}]$ , $k \in Z$ .
> >
> > (2) 已知 $f\left(\frac{\alpha}{2}\right)=2\sin\left(\alpha+\frac{\pi}{3}\right)+1=\frac{3}{2}$ ，则
> >
> > $2\sin(\alpha+\frac{\pi}{3})=\frac{3}{2}-1=\frac{1}{2}$ ，所以 $\sin(\alpha+\frac{\pi}{3})=\frac{1}{4}$ .
> >
> > 因为 $\alpha \in (\frac{\pi}{6},\frac{2\pi}{3})$ ，所以 $\alpha +\frac{\pi}{3}\in (\frac{\pi}{2},\pi)$
> >
> > 所以 $\cos (\alpha +\frac{\pi}{3}) = -\sqrt{1 - \sin^2(\alpha + \frac{\pi}{3})} = -\sqrt{1 - \left(\frac{1}{4}\right)^2} = -\frac{\sqrt{15}}{4}.$ 所以 $\cos \alpha = \cos \left(\left(\alpha +\frac{\pi}{3}\right) - \frac{\pi}{3}\right)$ $= \cos \left(\alpha +\frac{\pi}{3}\right)\cos \frac{\pi}{3} +\sin \left(\alpha +\frac{\pi}{3}\right)\sin \frac{\pi}{3}$ $= -\frac{\sqrt{15}}{4}\times \frac{1}{2} +\frac{1}{4}\times \frac{\sqrt{3}}{2} = \frac{\sqrt{3} - \sqrt{15}}{8}.$
