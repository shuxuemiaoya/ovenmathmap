> [!faq]- 2023-2024学年3月内蒙古包头九原区包头市第九中学外国语学校高一下学期月考数学试卷解析
>
> > [!success]- **【答案】** ABC
>
> > [!note]- **【分析】**
> > 由角的定义求解可判断A；由圆的性质及角的定义求解可判断B；由三角函数定义求解可判断C；由中点坐标公式及三角函数定义，结合角的变换、两角和与差的余弦公式求解可判断D.
>
> > [!note]- **【解析】**
> > 对于A：因为 $\angle A O x = \alpha, \angle B O x = \beta, 0 < \alpha < \beta < \frac{\pi}{2}$ ，所以 $\angle A O B = \beta - \alpha$ ，正确；  
> > 对于B：依题意M为线段AB的中点，则 $OM \perp AB$ ，则 $\angle A O M = \frac{\beta - \alpha}{2}$ ，又 $|OA| = 1$ ，所以 $|OM| = |OA| \cos \angle A O M = \cos \frac{\beta - \alpha}{2}$ ，正确；  
> > 对于C：M为线段AB的中点，射线OM与单位圆交于点C，则C为 $\widehat{AB}$ 的中点，所以 $\angle C O x = \alpha + \frac{\beta - \alpha}{2} = \frac{\alpha + \beta}{2}$ ，又 $|OC| = 1$ ，所以点C的坐标为 $\left( \cos \frac{\alpha + \beta}{2}, \sin \frac{\alpha + \beta}{2} \right)$ ，正确；  
> > 对于D： $x_M = \frac{1}{2}(x_A + x_B) = \frac{1}{2} (\cos \alpha + \cos \beta) = \frac{1}{2} \left[ \cos \left( \frac{\alpha + \beta}{2} + \frac{\alpha - \beta}{2} \right) + \cos \left( \frac{\alpha + \beta}{2} - \frac{\alpha - \beta}{2} \right) \right]$ $= \frac{1}{2} \left[ \cos \frac{\alpha + \beta}{2} \cos \frac{\alpha - \beta}{2} - \sin \frac{\alpha + \beta}{2} \sin \frac{\alpha - \beta}{2} + \cos \frac{\alpha + \beta}{2} \cos \frac{\alpha - \beta}{2} + \sin \frac{\alpha + \beta}{2} \sin \frac{\alpha - \beta}{2} \right]$ $= \frac{1}{2} \cdot 2 \cos \frac{\alpha + \beta}{2} \cos \frac{\alpha - \beta}{2} = \cos \frac{\alpha + \beta}{2} \cos \frac{\alpha - \beta}{2}$ ， $y_M = \frac{1}{2}(y_A + y_B) = \frac{1}{2} (\sin \alpha + \sin \beta) = \frac{1}{2} \left[ \sin \left( \frac{\alpha + \beta}{2} + \frac{\alpha - \beta}{2} \right) + \sin \left( \frac{\alpha + \beta}{2} - \frac{\alpha - \beta}{2} \right) \right]$ $= \frac{1}{2} \left[ \sin \frac{\alpha + \beta}{2} \cos \frac{\alpha - \beta}{2} + \cos \frac{\alpha + \beta}{2} \sin \frac{\alpha - \beta}{2} + \sin \frac{\alpha + \beta}{2} \cos \frac{\alpha - \beta}{2} - \cos \frac{\alpha + \beta}{2} \sin \frac{\alpha - \beta}{2} \right]$ $= \frac{1}{2} \cdot 2 \sin \frac{\alpha + \beta}{2} \cos \frac{\alpha - \beta}{2} = \sin \frac{\alpha + \beta}{2} \cos \frac{\alpha - \beta}{2}$ ，所以点M的坐标为 $\left( \cos \frac{\alpha + \beta}{2} \cos \frac{\beta - \alpha}{2}, \sin \frac{\alpha + \beta}{2} \cos \frac{\beta - \alpha}{2} \right)$ ，错误。故选：ABC
