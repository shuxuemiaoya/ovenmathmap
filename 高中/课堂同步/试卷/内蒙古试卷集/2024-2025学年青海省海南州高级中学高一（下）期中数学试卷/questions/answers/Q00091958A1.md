> [!faq]- 2024-2025学年青海省海南州高级中学高一（下）期中数学试卷解析
>
> > [!success]- **【答案】** B
>
> > [!note]- **【解析】**
> > $A:y = f(x) = x\sin x,f(-x) = -x\sin (-x) = x\sin x = f(x)$ ，故 $A$ 不符合题意； $B:f(x) = x + \sin x,f(-x) = -x - \sin x = -f(x)$ ，为奇函数，故 $B$ 符合题意； $C:f(x) = \frac{\sin x}{x},f(-x) = \frac{\sin(-x)}{-x} = \frac{\sin x}{x} = f(x)$ 为偶函数，不符合题意； $D:y = f(x) = \frac{x}{\sin x}$ ，则 $f(-x) = \frac{-x}{\sin(-x)} = \frac{x}{\sin x} = f(x)$ 为偶函数，不符合题意.故选： $B$
