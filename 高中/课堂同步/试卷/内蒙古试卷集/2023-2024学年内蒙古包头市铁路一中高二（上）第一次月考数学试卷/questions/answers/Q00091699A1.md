> [!faq]- 2023-2024学年内蒙古包头市铁路一中高二（上）第一次月考数学试卷解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【解析】**
> > 详见解析
> >
> > （I）由题意得 $e=\frac{c}{a}=\frac{\sqrt{3}}{2}$ ，所以 $c=\frac{\sqrt{3}a}{2}$ ， $b^{2}=a^{2}-c^{2}=\frac{1}{4}a^{2}$ ①，
> >
> > 又点 $(1, \frac{\sqrt{3}}{2})$ 在 $E$ 上，所以 $\frac{1^2}{a^2} + \frac{\frac{3}{4}}{b^2} = 1$ ②，联立①②，解得 $a = 2, b = 1$
> >
> > 所以椭圆 $E$ 的标准方程为 $\frac{x^2}{4} + y^2 = 1$ .
> >
> > （Ⅱ）设 $A$ ， $B$ 的坐标为 $(x_{1},y_{1}),(x_{2},y_{2})$ ，依题意得，  
> > 联立方程组 $\left\{ \begin{array}{l}\frac{x^2}{4} +y^2 = 1\\ y = kx + 2 \end{array} \right.$ 消去 $y$ ，得 $(1 + 4k^{2})x^{2} + 16kx + 12 = 0.\Delta = (16k)^{2} - 48(1 + 4k^{2}) > 0, k^{2} > \frac{3}{4}, x_{1} + x_{2} = \frac{-16k}{1 + 4k^{2}}$ ， $x_{1}x_{2} = \frac{12}{1 + 4k^{2}}$ $\overrightarrow{OA}\cdot \overrightarrow{OB} -x_1x_2 + y_1y_2 = x_1x_2 + (kx_1 + 2)(kx_2 + 2) = (1 + k^2)x_1x_2 + 2k(x_1 + x_2) + 4$ $= (1 + k^2)\cdot \frac{12}{1 + 4k^2} +2k\cdot \frac{-16k}{1 + 4k^2} +4 = \frac{12 - 20k^2}{1 + 4k^2} +4$ $\because \overrightarrow{OA}\cdot \overrightarrow{OB} = 2,\therefore \frac{12 - 20k^2}{1 + 4k^2} +4 = 2,k^2 = \frac{7}{6} >\frac{3}{4},$ 所以， $k = \pm \frac{\sqrt{42}}{6}$
