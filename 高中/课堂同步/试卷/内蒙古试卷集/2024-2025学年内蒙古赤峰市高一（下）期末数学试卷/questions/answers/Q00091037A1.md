> [!faq]- 2024-2025学年内蒙古赤峰市高一（下）期末数学试卷解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【解析】**
> > 详见解析
> >
> > $$
> > f (x) = \sqrt {3} (1 + \cos x) + \frac {1}{2} \sin x + \frac {\sqrt {3}}{2} \cos x + \frac {1}{2} \sin x - \frac {\sqrt {3}}{2} \cos x - \sqrt {3}
> > $$
> >
> > $$
> > = \sqrt {3} c o s x + s i n x = 2 (\frac {1}{2} s i n x + \frac {\sqrt {3}}{2} c o s x) = 2 s i n (x + \frac {\pi}{3})
> > $$
> >
> > 令 $2k\pi - \frac{\pi}{2} \leq x + \frac{\pi}{3} \leq 2k\pi + \frac{\pi}{2}, k \in Z$ ，解得 $2k\pi - \frac{5\pi}{6} \leq x \leq 2k\pi + \frac{\pi}{6}, k \in Z$
> >
> > 所以 $f(x)$ 单调递增区间为 $\left[2k\pi - \frac{5\pi}{6}, 2k\pi + \frac{\pi}{6}\right]$ ， $k \in Z$ .
> >
> > (2)令 $t=x+\frac{\pi}{3}$ ， $t\in R$ ，当 $\sin t\geqslant0$ 时， $2k\pi\leqslant t\leqslant2k\pi+\pi$ ， $k\in Z$ ，所以 $f(x) \geqslant 0$ 时， $2k\pi \leq x + \frac{\pi}{3} \leq 2k\pi + \pi, k \in Z$ ，解得 $2k\pi - \frac{\pi}{3} \leq x \leq 2k\pi + \frac{2\pi}{3}, k \in Z$ ，综上所述，使 $f(x) \geqslant 0$ 成立的 $x$ 的取值集合为 $\{x \mid 2k\pi - \frac{\pi}{3} \leq x \leq 2k\pi + \frac{2\pi}{3}, k \in Z\}$ .
