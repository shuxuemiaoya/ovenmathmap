> [!faq]- 2024-2025学年内蒙古赤峰市高一（下）期末数学试卷解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【解析】**
> > 详见解析
> >
> > （1）函数 $f(x) = \log_a(2 - x) + \log_a(x + 1)$ 有意义，则 $\left\{ \begin{array}{l}2 - x > 0\\ x + 1 > 0 \end{array} \right.$ ，解得 $-1 <   x <   2$ 此时 $f(x) = \log_a[(2 - x)(x + 1)] = \log_a(-x^2 +x + 2)$ ，令 $t = -x^{2} + x + 2$ 函数 $t = -x^{2} + x + 2$ 在 $(-1,\frac{1}{2})$ 上单调递增，在 $(\frac{1}{2},2)$ 上单调递减，而当 $a > 1$ 时，函数 $y = \log_a t$ 在 $(0, + \infty)$ 上单调递增，所以函数 $f(x)$ 的单调递减区间是 $(\frac{1}{2},2)$ (2)由（1）得，当 $a > 1$ 时，函数 $f(x)$ 在 $[\frac{1}{2},\frac{7}{4} ]$ 上单调递减， $f(x)_{max} = f(\frac{1}{2}) = log_a\frac{9}{4}$ 依题意， $\log_a\frac{9}{4}\leqslant 2$ ，等价于 $\log_a\frac{9}{4}\leqslant \log_a a^2$ ，即 $a^2\geqslant \frac{9}{4}$ ，解得 $a\geqslant \frac{3}{2}$ 当 $0 <   a <   1$ 时，函数 $f(x)$ 在 $[\frac{1}{2},\frac{7}{4} ]$ 上单调递增， $f(x)_{max} = f(\frac{7}{4}) = log_a\frac{11}{16}$ 依题意， $\log_a\frac{11}{16}\leqslant 2$ ，等价于 $\log_a\frac{11}{16}\leqslant \log_a a^2$ ，即 $0 <   a^2 <  \frac{11}{16}$ ，解得 $0 <   a\leqslant \frac{\sqrt{11}}{4}$ 所以 $a$ 的取值范围是 $(0,\frac{\sqrt{11}}{4} ]\cup [\frac{3}{2}, + \infty).$
