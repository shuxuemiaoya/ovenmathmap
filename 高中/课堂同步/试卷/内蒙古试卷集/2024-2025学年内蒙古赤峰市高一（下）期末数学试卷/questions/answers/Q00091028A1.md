> > [!note]- **【解析】**
> > 因为 $c = b(1 + 2\cos A)$
> >
> > 由正弦定理得 $\sin C = \sin B(1 + 2\cos A) = \sin B + 2\cos A\sin B$
> >
> > 所以 $\sin A\cos B - \cos A\sin B = \sin (A - B) = \sin B$
> >
> > 则 $A - B = B$ ， $A = 2B$ 或 $A - B = \pi -B$ ， $A = \pi ($ 舍），
> >
> > 所以 $A = 2B = \frac{\pi}{3}, C = \frac{\pi}{2}$
> >
> > $$
> > | c = \frac {a}{\sin A} = \frac {1}{\sin \frac {\pi}{3}} = \frac {2 \sqrt {3}}{3}, b = c \sin B = \frac {2 \sqrt {3}}{3} \sin \frac {\pi}{6} = \frac {\sqrt {3}}{3},
> > $$
> >
> > $$
> > C _ {\triangle A B C} = a + b + c = 1 + \sqrt {3}.
> > $$
> >
> > 故选：A.
