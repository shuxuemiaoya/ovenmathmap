>
> > [!success]- **【答案】** A
>
> > [!note]- **【解析】**
> > ∵在△ABC中， $\frac{\sin A}{a}=\frac{\cos B}{b}=\frac{\cos C}{c}$ ，
> > 则由正弦定理可得： $\frac{\sin A}{\sin A}=\frac{\cos B}{\sin B}=\frac{\cos C}{\sin C}$ 即 $\sin B = \cos B, \sin C = \cos C,$ ∴B = C = 45°,
> > ∴A = 90°
> > 故△ABC为等腰直角三角形，
> >
> > 故选A.
