> [!faq]- 2018-2019学年内蒙古包头昆都仑区包头市第九中学高一下学期期中数学试卷解析
>
> > [!success]- **【答案】** 详见解析 (2) $\frac{7\sqrt{3}}{3}$
>
> > [!note]- **【解析】**
> > （1）在 $\triangle ABC$ 中，由正弦定理可知， $2\sin A \cdot \sin B = \sqrt{3}\sin B,$ $\therefore \sin A = \frac{\sqrt{3}}{2},$ $\therefore A = \frac{\pi}{3}$ 或 $\frac{2}{3}\pi$ （舍去）.
> >
> > (2) 由余弦定理可得，
> >
> > $\cos A = \frac{b^2 + c^2 - a^2}{2bc} = \frac{1}{2},$ $\therefore b^{2} + c^{2} - a^{2} = bc,$ 即 $(b + c)^{2} - 2bc - a^{2} = bc,$ 解得 $bc = \frac{28}{3},$ $\therefore$ 面积 $S = \frac{1}{2} bc\cdot \sin A = \frac{7\sqrt{3}}{3}.$
