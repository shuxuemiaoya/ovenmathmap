> [!faq]- 2018-2019学年内蒙古包头昆都仑区包头市第九中学高一下学期期中数学试卷解析
>
> > [!success]- **【答案】** 详见解析 (2) $T_{n} = \frac{n}{6n + 9}$
>
> > [!note]- **【解析】**
> > （1） $S_{4} = \frac{4(a_{1} + a_{4})}{2} = 24,$ $\therefore a_1 + a_4 = 12,$ 又 $a_1a_4 = 27$ ， $d > 0$ $\therefore a_{1} = 3,a_{4} = 9,$ $\therefore 9 = 3 + 3d$ ，解得 $d = 2$ $\therefore a_n = 2n + 1.$ (2） $b_{n} = \frac{1}{a_{n}a_{n + 1}} = \frac{1}{(2n + 1)(2n + 3)}$ $= \frac{1}{2}\left(\frac{1}{2n + 1} -\frac{1}{2n + 3}\right),$ $T_{n} = \frac{1}{2}\left[\left(\frac{1}{3} -\frac{1}{5}\right) + \left(\frac{1}{5} -\frac{1}{7}\right) + \dots +\left(\frac{1}{2n + 1} -\frac{1}{2n + 3}\right)\right]$ $= \frac{1}{2}\left(\frac{1}{3} -\frac{1}{2n + 3}\right) = \frac{n}{6n + 9}.$
