> [!faq]- 2024-2025学年4月内蒙古包头昆都仑区包钢第一中学高一下学期月考数学试卷解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【解析】**
> > 详见解析
> >
> > （1）因为 $\cos \left(\alpha -\frac{\pi}{4}\right) = \frac{1}{3}$ ，所以 $\frac{\sqrt{2}}{2}\cos \alpha +\frac{\sqrt{2}}{2}\sin \alpha = \frac{1}{3}$ ，即 $\cos \alpha +\sin \alpha = \frac{\sqrt{2}}{3},$ 平方得 $\cos^2\alpha +\sin^2\alpha +2\sin \alpha \cos \alpha = \frac{2}{9}$ ，所以 $\sin 2\alpha = 2\sin \alpha \cos \alpha = \frac{2}{9} -1 = -\frac{7}{9},$
> >
> > $(\cos \alpha - \sin \alpha)^2 = \cos^2 \alpha + \sin^2 \alpha - 2\cos \alpha \sin \alpha = 1 - \left(-\frac{7}{9}\right) = \frac{16}{9}$ 又 $\frac{\pi}{2} < \alpha < \pi$ ，所以 $\sin \alpha > 0, \cos \alpha < 0$ ，则 $\cos \alpha - \sin \alpha < 0$ ，所以 $\cos \alpha - \sin \alpha = -\frac{4}{3}$ ，
> >
> > 故
> >
> > $$
> > \cos 2 \alpha = \cos^ {2} \alpha - \sin^ {2} \alpha = (\cos \alpha + \sin \alpha) (\cos \alpha - \sin \alpha) = \frac {\sqrt {2}}{3} \times \left(- \frac {4}{3}\right) = - \frac {4 \sqrt {2}}{9}
> > $$
> >
> > (2) 因为 $0 < \beta < \frac{\pi}{2} < \alpha < \pi$ ，所以 $\frac{\pi}{2} < \alpha + \beta < \frac{3\pi}{2}$ ，
> >
> > 由于 $\sin (\alpha +\beta) = \frac{4}{5}$ ，所以
> >
> > $$
> > \cos (\alpha + \beta) = - \sqrt {1 - \sin^ {2} (\alpha + \beta)} = - \frac {3}{5},
> > $$
> >
> > 由 $\frac{\pi}{2} < \alpha < \pi$ 知： $\frac{\pi}{4} < \alpha -\frac{\pi}{4} < \frac{3\pi}{4}$ ，因为cos（ $\alpha -\frac{\pi}{4}$ ） $= \frac{1}{3}$
> >
> > 则 $\sin \left(\alpha -\frac{\pi}{4}\right) = \sqrt{1 - \cos^2\left(\alpha -\frac{\pi}{4}\right)} = \frac{2\sqrt{2}}{3},$
> >
> > 所以
> >
> > $$
> > \sin \left(\beta + \frac {\pi}{4}\right) = \sin \left[ (\beta + \alpha) - \left(\alpha - \frac {\pi}{4}\right) \right] = \sin (\beta + \alpha) \cos \left(\alpha - \frac {\pi}{4}\right) - \cos (\beta + \alpha) \sin \left(\alpha - \frac {\pi}{4}\right)
> > $$
> >
> > $$
> > = \frac {4}{5} \times \frac {1}{3} - \left(- \frac {3}{5}\right) \times \frac {2 \sqrt {2}}{3} = \frac {4 + 6 \sqrt {2}}{1 5}.
> > $$
