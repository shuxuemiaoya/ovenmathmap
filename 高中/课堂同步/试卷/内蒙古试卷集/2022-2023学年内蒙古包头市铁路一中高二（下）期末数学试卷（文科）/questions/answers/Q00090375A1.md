> [!faq]- 2022-2023学年内蒙古包头市铁路一中高二（下）期末数学试卷（文科）解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【解析】**
> > 详见解析
> >
> > (1)由题意， $\sum_{i = 1}^{5}x_iy_i = 1410$ ， $\sum_{i = 1}^{5}x_i^2 = 55$ 又 $\overline{x} = \frac{1 + 2 + 3 + 4 + 5}{5} = 3$ ， $\overline{y} = \frac{120 + 105 + 100 + 95 + 80}{5} = 100$ 则 $\hat{b} = \frac{\sum_{i=1}^{5} x_i y_i - 5\overline{x}\overline{y}}{\sum_{i=1}^{5} x_i^2 - 5\overline{x}^2} = \frac{1410 - 1500}{55 - 45} = -9$
> >
> > 故 $\hat{a} = 100 + 3 \times 9 = 127$
> >
> > 故 $\hat{y} = -9x + 27$
> >
> > 所以预测该运动品牌公司6月份获得“运动达人”称号的员工数为 $-9 \times 6 + 127 = 73$ 人；
> >
> > (2)由题意，m=20，n=40，
> >
> > 所以 $K^2 = \frac{140\times(1200 - 800)^2}{80\times60\times100\times40}\approx 1.167 <   3.841$
> >
> > 故没有95%的把握认为获得“运动达人”称号与性别有关.
