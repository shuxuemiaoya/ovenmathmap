> [!faq]- 2024-2025学年内蒙古乌海一中高一（下）期中数学试卷解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【解析】**
> > 详见解析
> >
> > (1) 因为 $S_{1}-S_{2}+S_{3}=\frac{\sqrt{6}}{3}ac$ ,
> >
> > 所以 $\frac{\sqrt{3}}{4} a^2 -\frac{\sqrt{3}}{4} b^2 +\frac{\sqrt{3}}{4} c^2 = \frac{\sqrt{6}}{3} ac$
> >
> > 即 $a^{2}-b^{2}+c^{2}=\frac{4\sqrt{2}}{3}ac$ ，
> >
> > 由 $2accosB = a^{2} - b^{2} + c^{2} = \frac{4\sqrt{2}}{3} ac$
> >
> > 所以 $\cos B=\frac{2\sqrt{2}}{3}$ .
> >
> > (2)由外接圆面积为 $\frac{9\pi}{4}$ 得半径 $r = \frac{3}{2}$ ，
> >
> > 由（1） $\cos B=\frac{2\sqrt{2}}{3}$ ，所以 $\sin B=\frac{1}{3}$ ，
> >
> > 由正弦定理得 $\frac{b}{\sin B} = 2r = 3$ ，解得 $b = 1$
> >
> > 由余弦定理得 $1 = a^2 + c^2 - 2ac\cos B$ ，即 $1 = a^2 + c^2 - \frac{4\sqrt{2}}{3} ac \geq 2ac - \frac{4\sqrt{2}}{3} ac$ ，当且仅当 $a = c$ 时等号成立，
> >
> > 化简得 $ac \leq \frac{9 + 6\sqrt{2}}{2}$
> >
> > 所以 $ac$ 的最大值为 $\frac{9 + 6\sqrt{2}}{2}$ .
> >
> > (3)因为 $BD$ 是 $\triangle ABC$ 的角平分线，则 $\angle ABC = 2\angle ABD = 2\angle CBD$
> >
> > 所以 $\triangle ABC$ 的面积
> >
> > $$
> > S = \frac {1}{2} a c \sin \angle A B C = \frac {1}{2} \times \frac {3 \sqrt {2}}{4} \times \frac {1}{3} = \frac {1}{2} a \bullet B D \sin \angle A B D + \frac {1}{2} c \bullet B D \sin \angle C B D
> > $$
> >
> > 所以 $\frac{1}{2} (a + c)\bullet \frac{2\sqrt{3}}{3}\bullet sin\frac{\angle ABC}{2} = \frac{\sqrt{2}}{8}$ ，则 $a + c = \frac{\sqrt{6}}{8sin\frac{\angle ABC}{2}}$
> >
> > 由 $cos\angle ABC=\frac{2\sqrt{2}}{3}$ ，所以 $2sin^{2}\frac{\angle ABC}{2}=1-\frac{2\sqrt{2}}{3}$
> >
> > 解得 $sin\frac{\angle ABC}{2}=\frac{\sqrt{2}-1}{\sqrt{6}}$
> >
> > 综上， $a + c = \frac{3 + 3\sqrt{2}}{4}.$
