> [!faq]- 2024-2025学年内蒙古乌海一中高一（下）期中数学试卷解析
>
> > [!success]- **【答案】** D
>
> > [!note]- **【解析】**
> > 因为 $(2a - c)\cos B = a - b\cos C$
> >
> > 所以
> >
> > $$
> > 2 \sin A \cos B - \sin C \cos B = \sin A - \sin B \cos C = \sin (B + C) - \sin B \cos C = \sin C \cos B
> > $$
> >
> > 即 $2\sin A\cos B = 2\sin C\cos B$
> >
> > 所以 $\cos B(\sin A - \sin C) = 0$
> >
> > 所以 $\cos B = 0$ 或 $\sin A = \sin C$
> >
> > 所以 $B=90^{\circ}$ 或A=C.
> >
> > 故选：D.
