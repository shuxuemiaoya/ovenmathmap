> [!faq]- 2018-2019学年内蒙古包头青山区包头市北重三中高一下学期期中数学试卷解析
>
> > [!success]- **【答案】** 详见解析 (2) $\frac{24}{25}$
>
> > [!note]- **【解析】**
> > （1） $f(x)=\sin^{2}\frac{x}{2}+\sqrt{3}\sin\frac{x}{2}\cos\left(\pi+\frac{x}{2}\right)$ $=\sin^{2}\frac{1}{2}x-\sqrt{3}\sin\frac{1}{2}x\times\cos\frac{1}{2}x$
> >
> > $= \frac{1 - \cos x}{2} -\frac{\sqrt{3}}{2}\sin x = \frac{1}{2} -\sin \left(x + \frac{\pi}{6}\right),$ $\because -\frac{1}{3}\pi \leqslant x\leqslant \frac{1}{2}\pi ,$ $\therefore -\frac{\pi}{6}\leqslant x + \frac{\pi}{6}\leqslant \frac{2\pi}{3}.$ $\therefore -\frac{1}{2}\leqslant \sin \left(x + \frac{\pi}{6}\right)\leqslant 1.$ $\therefore$ 函数的值域为 $\left[-\frac{1}{2},1\right].$ (2） $\because f(x) = -\frac{1}{10},$ $\therefore \sin \left(x + \frac{\pi}{6}\right) = \frac{3}{5}.$ $\therefore \cos \left(x + \frac{\pi}{6}\right) = \pm \frac{4}{5}.$ 又 $0 <   x <   \frac{1}{2}\pi ,$ $\therefore \frac{\pi}{6} <  x + \frac{\pi}{6} <  \frac{2\pi}{3}.$ $\because \frac{3}{5} <  \frac{\sqrt{3}}{2},$ $\therefore \frac{\pi}{6} <  x + \frac{\pi}{6} <  \frac{\pi}{2},$ 或 $\frac{2\pi}{3} <  x + \frac{\pi}{6} <  \pi$ （舍）. $\therefore \cos \left(x + \frac{\pi}{6}\right) = \frac{4}{5}.$ $\therefore \sin \left(2x + \frac{\pi}{3}\right) = 2\sin \left(x + \frac{\pi}{6}\right)\cos \left(x + \frac{\pi}{6}\right) = \frac{24}{25}.$
