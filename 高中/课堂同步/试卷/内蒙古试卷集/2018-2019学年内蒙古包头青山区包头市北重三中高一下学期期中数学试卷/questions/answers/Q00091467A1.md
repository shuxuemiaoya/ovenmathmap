> [!faq]- 2018-2019学年内蒙古包头青山区包头市北重三中高一下学期期中数学试卷解析
>
> > [!success]- **【答案】** A
>
> > [!note]- **【解析】**
> > 由题设知 $a_{n}=2n-1$ ，
> >
> > $\because \{b_{n}\}$ 是以1为首项，2为公比的等比数列，
> >
> > $$
> > \therefore b _ {n} = 2 ^ {n - 1}, \therefore T _ {n} = c _ {1} + c _ {2} + \dots + c _ {n} = a _ {b _ {1}} + a _ {b _ {2}} + \dots + a _ {b _ {n}}
> > $$
> >
> > $= a_{1} + a_{2} + \dots +a_{2^{n - 1}} = (2\times 1 - 1) + (2\times 2 - 1) + (2\times 4 - 1) + \dots +(2\times 2^{n - 1} - 1)$ $= 2(1 + 2 + 4 + \dots +2^{n - 1}) - n = 2\times \frac{1 - 2^n}{1 - 2} -n = 2^{n + 1} - n - 2,$ $\because T_n <   2019,$ $\therefore 2^{n + 1} - n - 2 <   2019,$ $\therefore n\leqslant 9$ ，则 $n$ 的最大值为9.  
> > 故选A.
