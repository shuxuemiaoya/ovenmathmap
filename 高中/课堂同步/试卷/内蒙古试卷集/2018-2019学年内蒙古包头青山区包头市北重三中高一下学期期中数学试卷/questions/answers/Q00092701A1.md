> [!faq]- 2018-2019学年内蒙古包头青山区包头市北重三中高一下学期期中数学试卷解析
>
> > [!success]- **【答案】** 详见解析 (2) $6 + 2\sqrt{6}$
>
> > [!note]- **【解析】**
> > （1）由 $(2a-c)\cdot\cos B=b\cos C$ 及正弦定理可得： $(2\sin A-\sin C)\cdot\cos B=\sin B\cos C$ $2\sin A\cos B=\sin C\cdot\cos B+\sin B\cos C$ $2\sin A\cos B=\sin(B+C)$ $2\sin A\cos B=\sin A$ ∵在△ABC中， $\sin A\neq0$ ∴ $\cos B=\frac{1}{2}$ 且 $B\in(0,\pi)$ ,
> >
> > $\therefore B = \frac{\pi}{3}.$ (2) $S_{\triangle ABC} = \frac{1}{2} ac \cdot \sin B = \sqrt{3},$ 得 $ac = 4$ ，又 $a + c = 6$ 由余弦定理得 $b^{2} = a^{2} + c^{2} - 2ac \cdot \cos B = (a + c)^{2} - 2ac - 2ac \cdot \cos B = 1,$ $\therefore b^2 = 6^2 -2\times 4 - 2\times 4\times \frac{1}{2} = 24,$ $\therefore b = 2\sqrt{6},$ $\therefore \triangle ABC$ 的周长为 $a + b + c = 6 + 2\sqrt{6}.$
