> [!faq]- 2017-2018学年内蒙古包头高一下学期期末数学试卷解析
>
> > [!success]- **【答案】** ④⑤
>
> > [!note]- **【解析】**
> > ①如果a，b是两条直线，且a//b，那么a平行于经过b的任何平面，不正确，可能a，b在一个平面内；
> >
> > ②如果直线a和平面 $\alpha$ 满足 $a//\alpha$ ，那么直线a与平面 $\alpha$ 内的任何直线平行，不正确，可能a与平面 $\alpha$ 内的直线异面；
> >
> > ③如果直线 $a, b$ 和平面 $\alpha$ 满足 $a / / \alpha, b / / \alpha$ , 那么 $a / / b$ , 不正确, $a, b$ 可能相交或异面;
> >
> > ④如果直线a，b和平面 $\alpha$ 满足 $a//b$ ， $a//\alpha$ ， $b\not\subset\alpha$ ，过a与 $\alpha$ 相交的平面与 $\alpha$ 交于直线c，可得 $a//c$ ，即有 $b//c$ ，那么 $b//\alpha$ ，正确；
> >
> > ⑤如果平面 $\alpha, \beta, \gamma$ 满足 $\alpha // \gamma, \beta // \gamma$ , 由面面平行的传递性可得 $\alpha // \beta$ , 故正确.
> >
> > 故答案为：④⑤.
