> [!faq]- 2017-2018学年内蒙古包头高一下学期期末数学试卷解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【解析】**
> > 详见解析
> >
> > 联立 $\left\{ \begin{array}{l} x - y + 1 = 0 \\ 2x + y + 2 = 0 \end{array} \right.$ ，解得 $\left\{ \begin{array}{l} x = -1 \\ y = 0 \end{array} \right.$ ，可得正方形的中心为 $M(-1,0)$ 设正方形相邻两边的方程为： $x + 3y + m = 0 (m \neq -2)$ ， $3x - y + n = 0$
> >
> > 由正方形的性质可得： $\frac{|-1+m|}{\sqrt{10}}=\frac{|-1-2|}{\sqrt{10}}=\frac{|-3+n|}{\sqrt{10}}$ ，解得m=4，
> > n = 0 或 6.
> > ∴ 正方形其他三边所在直线的方程为： $x + 3y + 4 = 0, 3x - y = 0,$ $3x - y + 6 = 0.$
