> [!faq]- 2024-2025学年内蒙古鄂尔多斯市西四旗高一（下）期末数学试卷解析
>
> > [!success]- **【答案】** C
>
> > [!note]- **【解析】**
> > (1) $\triangle ABC$ 中，角 $A < B$ ：
> >
> > 若 $0 < A < B \leqslant \frac{\pi}{2}$ ，根据 $y = \sin x$ 在 $(0, \frac{\pi}{2}]$ 上单调递增得到 $\sin A < \sin B$ ；
> >
> > 若 $0 < A < \frac{\pi}{2}$ , $\frac{\pi}{2} < B < \pi$ , $\because 0 < A + B < \pi$ , $\therefore 0 < A < \pi - B < \frac{\pi}{2}$ , 所以
> >
> > $$
> > \sin A <   \sin (\pi - B) = \sin B
> > $$
> >
> > ∴角A<B能得到sin A<sin B;
> >
> > 即 $A < B$ 能得到 $\sin A < \sin B$ ;
> >
> > $\therefore$ 角 $A < B$ 是 $\sin A < \sin B$ 的充分条件；
> >
> > (2)若 $\sin A < \sin B$ :
> >
> > $A, B \in (0, \frac{\pi}{2}]$ 时， $y = \sin x$ 在 $(0, \frac{\pi}{2}]$ 上单调递增，所以由 $\sin A < \sin B$ ，得到 $A < B$ ；
> >
> > $A\in (0,\frac{\pi}{2}),B\in (\frac{\pi}{2},\pi)$ 时，显然满足 $A <   B$
> >
> > 即 $\sin A < \sin B$ 能得到 $A < B$ ;
> >
> > $\therefore A < B$ 是 $\sin A < \sin B$ 的必要条件；
> >
> > 综合(1)
> > (2)得角A<B，是 $\sin A<\sin B$ 的充要条件.
> >
> > 故选：C.
