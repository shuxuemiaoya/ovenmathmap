> [!faq]- 2017-2018学年3月内蒙古包头青山区包头市北重三中高一下学期理科月考数学试卷解析
>
> > [!success]- **【答案】** 详见解析 (2) $\frac{1}{2} \leqslant b < 1$
>
> > [!note]- **【解析】**
> > （1）由已知得 $-\cos (A + B) + \cos A\cos B - \sqrt{3}\sin A\cos B = 0,$ 即有 $\sin A\sin B - \sqrt{3}\sin A\cos B = 0,$ 因为 $\sin A\neq 0$ ，所以 $\sin B - \sqrt{3}\cos B = 0,$ 又 $\cos B\neq 0$ ，所以 $\tan B = \sqrt{3},$ 又 $0 <   B <   \pi$ ，所以 $B = \frac{\pi}{3}.$ （2）由余弦定理，有 $b^{2} = a^{2} + c^{2} - 2ac\cos B.$ 因为 $a + c = 1$ ， $\cos B = \frac{1}{2},$ 有 $b^2 = 3(a - \frac{1}{2})^2 +\frac{1}{4}.$ 又 $0 <   a <   1$ ，于是有 $\frac{1}{4}\leqslant b^2 <  1,$ 即有 $\frac{1}{2}\leqslant b <   1.$
