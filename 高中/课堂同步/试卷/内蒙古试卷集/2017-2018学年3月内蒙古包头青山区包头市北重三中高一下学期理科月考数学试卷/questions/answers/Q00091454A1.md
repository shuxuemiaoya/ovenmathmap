> [!faq]- 2017-2018学年3月内蒙古包头青山区包头市北重三中高一下学期理科月考数学试卷解析
>
> > [!success]- **【答案】** 详见解析 (2) 2
>
> > [!note]- **【解析】**
> > （1）在 $\triangle ABC$ 中， $\sin B = \frac{\sqrt{10}}{10}, A = \frac{3\pi}{4}$ ， $\therefore \cos B = \frac{3\sqrt{10}}{10}, \sin A = \frac{\sqrt{2}}{2}, \cos A = -\frac{\sqrt{2}}{2}, \therefore \sin C = \sin (A + B) = \frac{\sqrt{2}}{2} \times \frac{3\sqrt{10}}{10} - \frac{\sqrt{2}}{2} \times \frac{\sqrt{10}}{10} = \frac{2\sqrt{20}}{20} = \frac{\sqrt{5}}{5}, \therefore \frac{b}{c} = \frac{\sin B}{\sin C} = \frac{\sqrt{10}}{10} \times \frac{5}{\sqrt{5}} = \frac{\sqrt{2}}{2}.$
> >
> > (2) $\because D$ 为 $BC$ 中点， $\therefore 2\overrightarrow{AD} = \overrightarrow{AB} + \overrightarrow{AC}, 4\overrightarrow{AD}^2 = \overrightarrow{AB}^2 + 2\overrightarrow{AB} \cdot \overrightarrow{AC} + \overrightarrow{AC}^2,$ 即 $4 = c^2 + b^2 + 2bc \cdot \left(-\frac{\sqrt{2}}{2}\right)$ ，化简得 $4 = b^2 + c^2 - \sqrt{2}bc^{①}$ ，由（1）知 $\frac{b}{c} = \frac{\sqrt{2}}{2}^{②}$ ，联立①②解得 $b = 2, c = 2\sqrt{2}$ ，
> >
> > $$
> > \therefore S _ {\triangle A B C} = \frac {1}{2} b c \sin A = 2.
> > $$
