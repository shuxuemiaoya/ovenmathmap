> [!faq]- 2024-2025学年内蒙古包头高一下学期期中数学试卷（景泰高级解析
>
> > [!success]- **【答案】** 详见解析 (2) $a + b + c = 2 + 2\sqrt{2}$
>
> > [!note]- **【解析】**
> > （1）由 $b=\sqrt{2}a\sin\left(C+\frac{\pi}{4}\right)$ 得 $\sin B=\sqrt{2}\sin A\sin\left(C+\frac{\pi}{4}\right)$ ，
> > 因为 $\sin B = \sin (A + C) = \sin A \cos C + \cos A \sin C,$ $\sqrt{2}\sin\left(C+\frac{\pi}{4}\right)=\sin C+\cos C,$ 所以 $\sin A\cos C + \cos A\sin C = \sin A (\sin C + \cos C),$ 即 $\cos A\sin C = \sin A\sin C,$ 所以 $\tan A = 1,$ 所以 $A = \frac{\pi}{4}.$
> >
> > (2) 因为三角形的面积为 $\sqrt{2}$ ,
> >
> > 所以 $\frac{1}{2} bc\sin A = \sqrt{2}$ ，所以 $bc = 4$
> >
> > $$
> > a ^ {2} = b ^ {2} + c ^ {2} - 2 b c \cos A \text {, 即} b ^ {2} + c ^ {2} = 1 + 4 \sqrt {2},
> > $$
> >
> > $$
> > (b + c) ^ {2} = b ^ {2} + c ^ {2} + 2 b c = 9 + 4 \sqrt {2} = (1 + 2 \sqrt {2}) ^ {2}
> > $$
> >
> > 故 $b+c=1+2\sqrt{2}$ ,
> >
> > 所以三角形的周长为 $a + b + c = 2 + 2\sqrt{2}$ .
