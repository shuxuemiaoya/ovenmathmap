> [!faq]- 2024-2025学年内蒙古包头六中高二（下）月考数学试卷（6月份）解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【解析】**
> > 详见解析
> >
> > (1)证明：因为数列 $\{a_{n}\}$ 的通项公式为 $a_{n} = n^{2} + 1$ ，设 $b_{n} = a_{n + 1} - a_{n}$
> >
> > 所以 $a_{n + 1} - a_n = (n + 1)^2 + 1 - (n^2 + 1) = 2n + 1$
> >
> > $$
> > \text { 设 } b _ {n} = a _ {n + 1} - a _ {n} = 2 n + 1
> > $$
> >
> > $$
> > \left| b _ {n + 1} - b _ {n} = 2 (n + 1) + 1 - (2 n + 1) = 2 \right.
> > $$
> >
> > 所以数列 $\{a_{n}\}$ 是二阶等差数列；
> >
> > (2)证明： $S_{n}=1^{2}+2^{2}+3^{2}+\cdots+n^{2}=1\times1+2\times2+3\times3+\ldots+n\times n$
> >
> > $$
> > = 1 \times (2 - 1) + 2 \times (3 - 1) + 3 \times (4 - 1) + \dots + n \times (n + 1 - 1)
> > $$
> >
> > $$
> > = 1 \times 2 + 2 \times 3 + 3 \times 4 + \dots + n \times (n + 1) - (1 + 2 + 3 + \dots + n)
> > $$
> >
> > $$
> > = 1 \times 2 + 2 \times 3 + 3 \times 4 + \dots + n \times (n + 1) - n (n + 1),
> > $$
> >
> > 因为 $n \times (n + 1) = \frac{1}{3} [n(n + 1)(n + 2) - (n - 1)n(n + 1)]$
> >
> > $$
> > \begin{array}{l} 1 \times 2 + 2 \times 3 + 3 \times 4 + \dots + n \times (n + 1) = \frac {1}{3} [ n (n + 1) (n + 2) - 0 ], \\ S _ {n} = \frac {n (n + 1) (n + 2)}{3} - \frac {n (n + 1)}{2} = \frac {n (n + 1) (2 n + 1)}{6}, \end{array}
> > $$
> >
> > 即证得结论成立；
> >
> > (3)计算 $\{a_{n}\}$ 的各阶等差数列，1，2，8，22，47，86，…，得 $\{b_{n}\} : 1, 6, 14, 25, 39, \ldots; \{c_{n}\} : 5, 8, 11, 14, \ldots; \{d_{n}\} : 3, 3, 3, \ldots,$
> >
> > $\{a_{n}\}$ 是一个三阶等差数列，所以 $\{d_n\}$ 是一个常数列， $c_{n} = c_{1} + 3(n - 1) = 3n + 2$
> >
> > 因为 $b_{n+1}-b_{n}=3n+2,n=1,2,\ldots,$
> >
> > 所以
> >
> > $$
> > \begin{array}{l} {b _ {n} - b _ {1} = (b _ {n} - b _ {n - 1}) + \ldots + (b _ {2} - b _ {1}) = \sum_ {k = 1} ^ {n - 1} (3 k + 2) = \frac {3 n (n - 1)}{2} + 2 (n - 1)} \\ {= \frac {(3 n + 4) (n - 1)}{2}} \\ {\text {所以} b _ {n} = \frac {3}{2} n ^ {2} + \frac {1}{2} n - 1,} \end{array}
> > $$
> >
> > $$
> > a _ {n} - a _ {1} = \sum_ {k = 1} ^ {n - 1} \left(\frac {3}{2} k ^ {2} + \frac {1}{2} k - 1\right) = \frac {(n - 1) n (2 n - 1)}{4} + \frac {n (n - 1)}{4} - (n - 1)
> > $$
> >
> > 解得 $a_{n}=\frac{1}{2}n^{3}-\frac{1}{2}n^{2}-n+2.$
