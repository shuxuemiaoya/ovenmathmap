> [!faq]- 2020-2021学年4月内蒙古包头青山区包头市第四中学高一下学期月考数学试卷解析
>
> > [!success]- **【答案】** C
>
> > [!note]- **【解析】**
> > 解：因为锐角 $\triangle ABC$ 中，若 $C = 2B$ ， $A + B + C = 180^{\circ}$ ，所以
> >
> > $$
> > A = 1 8 0 ^ {\circ} - 3 B
> > $$
> >
> > $\therefore \left\{ \begin{array}{l}0^{\circ} <   2B <   90^{\circ}\\ 0^{\circ} <   B <   90^{\circ}\\ 0^{\circ} <   180^{\circ} - 3B <   90^{\circ} \end{array} \right.$ $\therefore 30^{\circ} <   B <   45^{\circ}$ 由正弦定理可得， $\frac{c}{b} = \frac{\sin C}{\sin B} = \frac{\sin 2B}{\sin B}$ $= \frac{2\sin B\cos B}{\sin B} = 2\cos B,$ $\because \frac{\sqrt{2}}{2} <  \cos B <   \frac{\sqrt{3}}{2},$ $\therefore \sqrt{2} <  \frac{c}{b} <  \sqrt{3}$ ，即 $\frac{c}{b}\in (\sqrt{2},\sqrt{3})$ 因此正确答案为： $C$
