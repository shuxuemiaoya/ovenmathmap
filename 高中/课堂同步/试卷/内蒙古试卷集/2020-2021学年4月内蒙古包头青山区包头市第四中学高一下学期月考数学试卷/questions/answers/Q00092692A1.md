> [!faq]- 2020-2021学年4月内蒙古包头青山区包头市第四中学高一下学期月考数学试卷解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【分析】**
> > (1)先对已知利用正弦定理化简即得 $A=\frac{2\pi}{3}$ .
> > (2)先利用余弦定理求bc=4，再求三角形ABC的面积.
>
> > [!note]- **【解析】**
> > 详见解析
> >
> > （1）∵2acosC = 2b + c，由正弦定理可知
> >
> > $$
> > 2 \sin A \cos C = 2 \sin B + \sin C ①
> > $$
> >
> > $$
> > \sin B = \sin (A + C) = \sin A \cos C + \cos A \sin C ②.
> > $$
> >
> > $$
> > 2 \cos A \sin C + \sin C = 0
> > $$
> >
> > $$
> > \cos A = - \frac {1}{2}
> > $$
> >
> > $$
> > \sin C \neq 0
> > $$
> >
> > $$
> > 0 <   A <   \pi
> > $$
> >
> > (2) 由余弦定理 $a^{2}=b^{2}+c^{2}-2bc\cdot cosA$ ，得
> >
> > $$
> > A = \frac {2 \pi}{3}
> > $$
> >
> > $$
> > (2 \sqrt {3}) ^ {2} = (b + c) ^ {2} - 2 b c - 2 b c \cdot \cos \frac {2 \pi}{3},
> > $$
> >
> > 即： $12 = 16 - 2bc - 2bc\cdot \left(-\frac{1}{2}\right),\therefore bc = 4.$
> >
> > 故得： $S_{\triangle ABC} = \frac{1}{2} bc\sin A = \frac{1}{2}\times 4\times \frac{\sqrt{3}}{2} = \sqrt{3}.$
> >
> > 【点睛】本题主要考查正弦定理余弦定理解三角形，考查三角形面积的计算，意在考查学生对这些知识的掌握水平和分析推理能力.
