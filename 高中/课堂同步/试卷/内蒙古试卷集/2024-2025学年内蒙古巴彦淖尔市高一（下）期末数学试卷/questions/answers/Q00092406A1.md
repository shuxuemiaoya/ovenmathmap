> [!faq]- 2024-2025学年内蒙古巴彦淖尔市高一（下）期末数学试卷解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【解析】**
> > 详见解析
> >
> > （1）证明：因为 $a\sin (B - C) = b\sin C\cos A$ ，  
> > 所以 $a\sin B\cos C - a\cos B\sin C = b\sin C\cos A$ 由正弦定理得： $ab\cos C - ac\cos B = bc\cos A$ 由余弦定理得： $ab\bullet \frac{a^2 + b^2 - c^2}{2ab} -ac\bullet \frac{a^2 + c^2 - b^2}{2ac} = bc\bullet \frac{b^2 + c^2 - a^2}{2bc}$ 所以 $\frac{a^2 + b^2 - c^2}{2} -\frac{a^2 + c^2 - b^2}{2} = \frac{b^2 + c^2 - a^2}{2}$ 即 $a^2 +b^2 -c^2 -(a^2 +c^2 -b^2) = b^2 +c^2 -a^2$ ，所以 $a^2 +b^2 = 3c^2$
> >
> > (2)因为 $a^{2}+b^{2}=3c^{2}$
> >
> > 所以由余弦定理得： $cosC = \frac{a^2 + b^2 - c^2}{2ab} = \frac{3c^2 - c^2}{2ab} = \frac{2c^2}{2ab}\geq \frac{2c^2}{a^2 + b^2} = \frac{2c^2}{3c^2} = \frac{2}{3}$
> >
> > 又因为 $C\in(0,\pi)$ ，所以 $\frac{2}{3}\leq\cos C<1$ ，
> >
> > 所以 $\cos C$ 的取值范围是： $\left[\frac{2}{3},1\right)$ ;
> >
> > (3)由（2）得 $\frac{2}{3} \leq \cos C < 1$ ，所以 $\sin C = \sqrt{1 - \cos^2 C} \leq \frac{\sqrt{5}}{3}$ ，
> >
> > 设△ABC的外接圆半径为R，
> >
> > 所以由正弦定理得： $R = \frac{c}{2sinC} = \frac{2\sqrt{5}}{2sinC} = \frac{\sqrt{5}}{sinC}\geq \frac{\sqrt{5}}{\frac{\sqrt{5}}{3}} = 3$
> >
> > 所以 $\triangle ABC$ 外接圆面积的最小值为 $\pi R^2 = \pi \times 3^2 = 9\pi$ .
