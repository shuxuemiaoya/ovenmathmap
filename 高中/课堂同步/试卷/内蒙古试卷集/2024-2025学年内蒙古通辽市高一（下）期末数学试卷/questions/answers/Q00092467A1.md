> [!faq]- 2024-2025学年内蒙古通辽市高一（下）期末数学试卷解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【解析】**
> > 详见解析
> >
> > (1) 因为 $\overrightarrow{m} = (sinC, cosC)$ , $\overrightarrow{n} = (2sinA - \sqrt{3}cosB, -\sqrt{3}sinB)$ , 且 $\overrightarrow{m} \perp \overrightarrow{n}$ ,
> >
> > $$
> > \overrightarrow {m} \bullet \overrightarrow {n} = \sin C \bullet (2 \sin A - \sqrt {3} \cos B) + \cos C \bullet (- \sqrt {3} \sin B) = 0
> > $$
> >
> > 所以 $2\sin A\sin C - \sqrt{3}\sin C\cos B - \sqrt{3}\cos C\sin B = 0$
> >
> > 所以 $2\sin A\sin C - \sqrt{3} (\sin C\cos B + \cos C\sin B) = 0$
> >
> > 所以 $2\sin A\sin C - \sqrt{3}\sin (B + C) = 0$
> >
> > 所以 $2sinAsinC - \sqrt{3} sinA = 0$ ，所以 $sinA(2sinC - \sqrt{3}) = 0$
> >
> > 因为 $0 < A < \pi$ ，所以 $\sin A \neq 0$ ，所以 $2\sin C - \sqrt{3} = 0$
> >
> > 所以 $\sin C = \frac{\sqrt{3}}{2}$ ，因为 $0 < C < \frac{\pi}{2}$ ，所以 $C = \frac{\pi}{3}$ ；
> >
> > (2)在 $\triangle ABC$ 中，由余弦定理可得 $c^2 = b^2 + a^2 - 2ba\cos C$
> >
> > 又因为 $C = \frac{\pi}{3}$ ， $c = \sqrt{3}$ ，所以 $3 = b^2 +a^2 -ba = (a + b)^2 -3ab\geq (a + b)^2 -3\bullet \frac{(a + b)^2}{4}$
> >
> > 所以 $12 \geqslant (a + b)^{2}$ ，所以 $a + b \leq 2\sqrt{3}$ ，当且仅当 $a = b = \sqrt{3}$ 时取等号，
> >
> > 所以 $\triangle ABC$ 的周长的最大值为 $3\sqrt{3}$ .
