> [!faq]- 2022-2023学年内蒙古赤峰市松山区赤峰红旗中学高一（下）期末数学试卷解析
>
> > [!success]- **【答案】** $(- \infty ,2]$
>
> > [!note]- **【解析】**
> > 由 $c - b = 2b\cos A$ ，结合正弦定理可得 $\sin C - \sin B = 2\sin B\cos A$ 则 $\sin (A + B) - \sin B = 2\sin B\cos A$ ，得 $\sin A\cos B - \cos A\sin B = \sin B$ 所以 $\sin (A - B) = \sin B$ 因为 $0 < A < \frac{\pi}{2}, 0 < B < \frac{\pi}{2}, -\frac{\pi}{2} < A - B < \frac{\pi}{2}$ 所以 $A - B = B$ ，则 $A = 2B$ 所以不等式 $2t\sin A - \cos (C - B) < 3$ 恒成立，即 $2t < \frac{cos(C - B) + 3}{sinA}$ 恒成立，则 $2t < [\frac{cos(C - B) + 3}{sinA}]_{min}$ 因为 $C - B = \pi - A - B - B = \pi - 4B$ 因为 $C - B = \pi - A - B - B = \pi - 4B$ $\frac{cos(C - B) + 3}{sinA} = \frac{cos(\pi - 4B) + 3}{sin2B} = \frac{3 - cos4B}{sin2B} = \frac{2 + 2sin^22B}{sin2B}$ $= \frac{2}{\sin 2B} + 2\sin 2B$
> >
> > 因为三角形为锐角三角形，所以 $\left\{ \begin{array}{l}0 < 2B < \frac{\pi}{2}\\ 0 < B < \frac{\pi}{2}\\ 0 < \pi -3B < \frac{\pi}{2} \end{array} \right.$ ，解得： $\frac{\pi}{6} <  B <   \frac{\pi}{4}$ 则 $\frac{\sqrt{3}}{2} <  sin2B <   1$ 设 $y = \frac{2}{x} +2x$ ，函数在区间 $x\in (\frac{\sqrt{3}}{2},1)$ 单调递减，所以函数的值域为 $(4,\frac{7\sqrt{3}}{3})$ 即 $4 <   \frac{2}{sin2B} +2sin2B <   \frac{7\sqrt{3}}{3}$ ，则 $\frac{cos(C - B) + 3}{sinA}\in (4,\frac{7\sqrt{3}}{3})$ 所以 $2t\leqslant 4$ ，得 $t\leqslant 2.$ 故答案为： $(- \infty ,2]$
