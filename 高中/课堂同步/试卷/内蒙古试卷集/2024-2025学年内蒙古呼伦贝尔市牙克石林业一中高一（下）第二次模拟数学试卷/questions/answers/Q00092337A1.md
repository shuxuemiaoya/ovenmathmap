> [!faq]- 2024-2025学年内蒙古呼伦贝尔市牙克石林业一中高一（下）第二次模拟数学试卷解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【解析】**
> > 详见解析
> >
> > (1) 在 $\triangle ABC$ 中， $\angle ACB = \pi - \frac{2\pi}{3} - \frac{\pi}{12} = \frac{\pi}{4}$ ，
> >
> > 由正弦定理 $\frac{BC}{\sin\angle BAC} = \frac{AB}{\sin\angle ACB}$ ， $AB = \frac{100\sqrt{6}}{3} m$ ， $\angle BAC = \frac{2\pi}{3}$ 得 $BC = \frac{AB\sin\angle BAC}{\sin\angle ACB} = 100m$
> >
> > (2)在 $\triangle BCD$ 中，由余弦定理
> >
> > $BC^{2} = BD^{2} + CD^{2} - 2BD\bullet CDcos\frac{\pi}{3} = BD^{2} + CD^{2} - BD\bullet CD,$
> >
> > $$
> > \text {得} 1 0 0 0 0 + 3 B D \bullet C D = (B D + C D) ^ {2} \leqslant 1 0 0 0 0 + 3 \times \frac {(B D + C D) ^ {2}}{4},
> > $$
> >
> > 即 $BD + CD \leqslant 200m$
> >
> > 当且仅当 $BD = CD = 100m$ 时，等号成立，
> >
> > 故这两段网箱获得的最高经济总收益为 $200 \times 30 = 6000$ 元.
