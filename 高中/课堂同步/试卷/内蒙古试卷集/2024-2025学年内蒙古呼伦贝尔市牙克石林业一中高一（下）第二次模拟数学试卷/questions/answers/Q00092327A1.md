> [!faq]- 2024-2025学年内蒙古呼伦贝尔市牙克石林业一中高一（下）第二次模拟数学试卷解析
>
> > [!success]- **【答案】** C
>
> > [!note]- **【解析】**
> > 在 $\triangle ABC$ 中，由已知等式整理得： $\frac{a^2 + b^2 - c^2}{2ab} = \frac{1}{2tanC}$ ，即 $\cos C = \frac{\cos C}{2sinC}$
> >
> > $\because \cos C \neq 0, \therefore \sin C = \frac{1}{2}$
> >
> > ∵ C 为 △ABC 内角，
> >
> > $\therefore C = \frac{\pi}{6}$ 或 $\frac{5\pi}{6}$
> >
> > 故选：C.
