> [!faq]- 2023-2024学年内蒙古名校联盟高一（下）期中数学试卷解析
>
> > [!success]- **【答案】** B
>
> > [!note]- **【解析】**
> > $\sin A \cos C = \sin B + \cos A$
> >
> > 则 $-\cos A = \sin B - \sin A\cos C = \sin (A + C) - \sin A\cos C = \sin C\cos A$
> >
> > 所以 $(\sin C + 1)\cos A = 0$ ，解得 $\sin C = -1$ （舍去）或 $\cos A = 0$
> >
> > $$
> > \boldsymbol {A} \in (0, \pi)
> > $$
> >
> > 则 $A=\frac{\pi}{2}.$
> >
> > 故选：B.
