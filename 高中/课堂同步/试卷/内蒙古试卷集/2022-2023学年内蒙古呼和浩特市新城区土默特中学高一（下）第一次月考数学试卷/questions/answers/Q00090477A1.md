> [!faq]- 2022-2023学年内蒙古呼和浩特市新城区土默特中学高一（下）第一次月考数学试卷解析
>
> > [!success]- **【答案】** BCD
>
> > [!note]- **【解析】**
> > 对于 $A$ ，因为 $a:b:c = 2:2:3$ ，则cos $A = \frac{b^2 + c^2 - a^2}{2bc} = \frac{4 + 9 - 4}{2\times 2\times 3} = \frac{3}{4}\neq \frac{\sqrt{2}}{2}$
> >
> > 所以 $A \neq 45^{\circ}$ ，故A错误；
> >
> > 对于 $B$ ，若 $A:B:C = 1:2:3$ ，又 $A + B + C = \pi$ ，则 $A = \frac{\pi}{6}$ ， $B = \frac{\pi}{3}$ ， $C = \frac{\pi}{2}$
> >
> > 则 $a:b:c = sinA:sinB:sinC = \frac{1}{2}:\frac{\sqrt{3}}{2}:1 = 1:\sqrt{3}:2$ ，故 $B$ 正确；
> >
> > 对于 $C$ ，若 $\pmb{A} > \pmb{B}$ ，则 $\pmb{a} > \pmb{b}$
> >
> > 由正弦定理可得 $2R\sin A > 2R\sin B$ （ $R$ 为 $\triangle ABC$ 的外接圆半径），
> >
> > 所以 $\sin A > \sin B$ ，故 $C$ 正确；
> >
> > 对于 $D$ ，由正弦定理得 $\frac{3}{\frac{1}{2}} = \frac{4}{\sin B}$ ，所以 $\sin B = \frac{2}{3}$ ，由 $b > a$ 得 $B > A$
> >
> > 所以B为锐角或钝角，有两解，故D正确.
> >
> > 故选：BCD.
