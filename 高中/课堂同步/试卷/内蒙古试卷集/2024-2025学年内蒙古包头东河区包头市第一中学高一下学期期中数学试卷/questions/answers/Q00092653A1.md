> [!faq]- 2024-2025学年内蒙古包头东河区包头市第一中学高一下学期期中数学试卷解析
>
> > [!success]- **【答案】** 详见解析 (2) $\left(\sqrt{3}, 2\sqrt{3}\right]$ (3) 存在点 $P(0,2)$
>
> > [!note]- **【解析】**
> > （1）
> >
> > $$
> > h (x) = - 2 \sin \left(x - \frac {\pi}{6}\right) = - 2 \left(\frac {\sqrt {3}}{2} \sin x - \frac {1}{2} \cos x\right) = - \sqrt {3} \sin x + \cos x
> > $$
> >
> > ，所以函数 $h(x)$ 的相伴向量 $\overrightarrow{OM} = (-\sqrt{3}, 1)$ .
> >
> > (2) 由题知 $f(x) = \frac{\sqrt{3}}{2}\sin x - \frac{1}{2}\cos x = \sin \left(x - \frac{\pi}{6}\right)$ ，由 $f(2B) = 1$ ，得 $\sin \left(2B - \frac{\pi}{6}\right) = 1$ 。又 $2B - \frac{\pi}{6} \in \left(-\frac{\pi}{6}, \frac{11\pi}{6}\right)$ ，即 $2B - \frac{\pi}{6} = \frac{\pi}{2}$ ，所以 $B = \frac{\pi}{3}$ 。又 $b = \sqrt{3}$ ，由正弦定理 $\frac{a}{\sin A} = \frac{b}{\sin B} = \frac{c}{\sin C}$ ，得 $a = 2\sin A, c = 2\sin C$ ，即 $a + c = 2\sin A + 2\sin C = 2\sin A + 2\sin \left(\frac{2\pi}{3} - A\right) = 2\sqrt{3}\cos \left(A - \frac{\pi}{3}\right)$ 。因为 $0 < A < \frac{2\pi}{3}$ ，所以 $-\frac{\pi}{3} < A - \frac{\pi}{3} < \frac{\pi}{3}$ ，所以 $2\sqrt{3}\cos \left(A - \frac{\pi}{3}\right) \in (\sqrt{3}, 2\sqrt{3}]$ ，即 $a + c$ 的取值范围为 $(\sqrt{3}, 2\sqrt{3}]$ 。
> >
> > (3) 由（2）知 $f(x) = \sin \left(x - \frac{\pi}{6}\right)$ ，所以 $\varphi(x) = 2f\left(\frac{x}{2} + \frac{2\pi}{3}\right) = 2\sin \left[\left(\frac{x}{2} + \frac{2\pi}{3}\right) - \frac{\pi}{6}\right] = 2\sin \left(\frac{x}{2} + \frac{\pi}{2}\right) = 2\cos \frac{x}{2}$ ，设 $P(x, 2\cos \frac{x}{2})$ ，因为 $D(-2, 3), E(2, 6)$ ，所以 $\overrightarrow{DP} = (x + 2, 2\cos \frac{x}{2} - 3), \overrightarrow{EP} = (x - 2, 2\cos \frac{x}{2} - 6)$ ，又因为 $\overrightarrow{DP} \perp \overrightarrow{EP}$ ，所以 $\overrightarrow{DP} \cdot \overrightarrow{EP} = 0$ ，所以 $(x + 2)(x - 2) + (2\cos \frac{x}{2} - 3)(2\cos \frac{x}{2} - 6) = 0$ ，即 $x^2 - 4 + 4\cos^2\frac{x}{2} - 18\cos\frac{x}{2} + 18 = 0$ ，所以 $(2\cos\frac{x}{2} - \frac{9}{2})^2 = \frac{25}{4} - x^2$ 。因为 $-2 \leq 2\cos\frac{x}{2} \leq 2$ ，所以 $-\frac{13}{2} \leq 2\cos\frac{x}{2} - \frac{9}{2} \leq -\frac{5}{2}$ ，所以 $\frac{25}{4} \leq (2\cos\frac{x}{2} - \frac{9}{2})^2 \leq \frac{169}{4}$ ，又因为 $\frac{25}{4} - x^2 \leq \frac{25}{4}$ ，所以当且仅当 $x = 0$ 时， $(2\cos\frac{x}{2} - \frac{9}{2})^2$ 和 $\frac{25}{4} - x^2$ 同时等于 $\frac{25}{4}$ ，所以在 $y = f(x)$ 图像上存在点 $P(0, 2)$ ，使得 $\overrightarrow{DP} \perp \overrightarrow{EP}$ 。
