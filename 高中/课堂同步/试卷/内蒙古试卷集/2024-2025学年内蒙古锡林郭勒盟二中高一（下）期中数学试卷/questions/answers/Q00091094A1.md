> [!faq]- 2024-2025学年内蒙古锡林郭勒盟二中高一（下）期中数学试卷解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【解析】**
> > 详见解析
> >
> > （1）因为 $2\cos A(c\cos B + b\cos C) = a$ ，由正弦定理得： $2\cos A(\sin C\cos B + \sin B\cos C) = \sin A$ 即 $2\cos A\sin (B + C) = 2\cos A\sin A = \sin A$
> >
> > 由于 $\sin A \neq 0$ ，所以 $\cos A = \frac{1}{2}$ ，又 $A \in (0, \pi)$ ，
> >
> > 所以 $A=\frac{\pi}{3}$ .
> >
> > (2)因为 $A=\frac{\pi}{3}$ ，a=3，
> >
> > 由正弦定理得： $2R = \frac{a}{\sin A} = \frac{3}{\frac{\sqrt{3}}{2}} = 2\sqrt{3}$
> >
> > 则 $a + b + c = 2\sqrt{3} \sin B + 2\sqrt{3} \sin C + 3 = 3 + 2\sqrt{3} \sin B + 2\sqrt{3} \sin (\frac{2\pi}{3} - B)$ $= 3 + 2\sqrt{3} \sin B + 2\sqrt{3} \sin \frac{2\pi}{3} \cos B - 2\sqrt{3} \cos \frac{2\pi}{3} \sin B$ $= 3 + 2\sqrt{3} \sin B + 3 \cos B + \sqrt{3} \sin B = 3 + 3\sqrt{3} \sin B + 3 \cos B$ $= 3 + 6(\frac{\sqrt{3}}{2} \sin B + \frac{1}{2} \cos B) = 3 + 6 \sin (B + \frac{\pi}{6})$
> >
> > 因为 $0 < B < \frac{2\pi}{3}$
> >
> > 故 $\frac{\pi}{6} < B + \frac{\pi}{6} < \frac{5\pi}{6}$ ，所以 $3 + 6sin(B + \frac{\pi}{6}) \in (6, 9]$ .
> >
> > 故 $\triangle ABC$ 的周长的取值范围为：(6,9].
