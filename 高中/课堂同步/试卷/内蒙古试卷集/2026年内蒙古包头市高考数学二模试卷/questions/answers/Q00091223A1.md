> [!faq]- 2026年内蒙古包头市高考数学二模试卷解析
>
> > [!success]- **【答案】** $-\frac{\sqrt{3}}{3}$
>
> > [!note]- **【解析】**
> > 因为 $a^2, b^2, 2c^2$ 成等差数列，所以 $a^2 + 2c^2 = 2b^2$
> >
> > $$
> > | \cos C = \frac {a ^ {2} + b ^ {2} - c ^ {2}}{2 a b} = \frac {3 (b ^ {2} - c ^ {2})}{2 a b}, \cos B = \frac {a ^ {2} + c ^ {2} - b ^ {2}}{2 a c} = \frac {b ^ {2} - c ^ {2}}{2 a c},
> > $$
> >
> > 所以 $\frac{cosC}{cosB} = \frac{\frac{3(b^2 - c^2)}{2ab}}{\frac{b^2 - c^2}{2ac}} = \frac{3c}{b} = \frac{3sinC}{sinB}$
> >
> > 即 $\tan B = 3\tan C$ ，且 $\tan C > 0$
> >
> > $$
> > \tan (C - B) = \frac {\tan C - \tan B}{1 + \tan B \tan C} = - \frac {2 \tan C}{1 + 3 \tan^ {2} C} = - \frac {2}{\frac {1}{\tan C} + 3 \tan C} \geqslant - \frac {2}{2 \sqrt {3}} = - \frac {\sqrt {3}}{3}
> > $$
> >
> > 当且仅当 $\tan C=\frac{\sqrt{3}}{3}$ 时，等号成立，
> >
> > 即 $\tan(C-B)$ 的最小值为 $-\frac{\sqrt{3}}{3}$ .
> >
> > 故答案为： $-\frac{\sqrt{3}}{3}$ .
