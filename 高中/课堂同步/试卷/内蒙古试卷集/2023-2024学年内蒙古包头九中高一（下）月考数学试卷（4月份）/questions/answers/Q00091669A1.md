> [!faq]- 2023-2024学年内蒙古包头九中高一（下）月考数学试卷（4月份）解析
>
> > [!success]- **【答案】** 1
>
> > [!note]- **【解析】**
> > 由题意得， $\overrightarrow{a} -\overrightarrow{b} = (-1 - m,2),\because (\overrightarrow{a} -\overrightarrow{b})\perp \overrightarrow{b},$
> >
> > $\therefore m(-1 - m) + 2 = 0$ ，解得 $m = -2$ （舍去）或 $m = 1$
> >
> > 故答案为：1.
> >
> >
> > 2、 $A = \frac{\pi}{3}$ ， $a = \sqrt{7}$ ， $b - c = 1$
> >
> > 由余弦定理， $a^2 = b^2 +c^2 -2bc\cos A = b^2 +c^2 -bc$
> >
> > 因为 $b - c = 1$ ， $a = \sqrt{7}$ ，所以 $c^2 +(c + 1)^2 -c(c + 1) = 7$
> >
> > 即 $c^{2}+c-6=0$ ，解得c=2或 $c=-3$ （舍），
> >
> > 所以 $b = 3, c = 2, \cos B = \frac{a^2 + c^2 - b^2}{2ac} = \frac{7 + 4 - 9}{2 \times \sqrt{7} \times 2} = \frac{\sqrt{7}}{14}$ .
> >
> > 故答案为： $\frac{\sqrt{7}}{14}$
