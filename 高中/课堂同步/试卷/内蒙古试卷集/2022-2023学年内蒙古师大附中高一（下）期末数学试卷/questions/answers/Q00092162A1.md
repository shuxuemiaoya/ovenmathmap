> [!faq]- 2022-2023学年内蒙古师大附中高一（下）期末数学试卷解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【解析】**
> > 详见解析
> >
> > (1) 在 $\triangle ADC$ 中， $\because \angle ADC = \frac{\pi}{3}$ ， $\therefore$ 由余弦定理得 $AC = \sqrt{16 + 4 - 2 \cdot 4 \cdot 2 \cdot \frac{1}{2}} = 2\sqrt{3}$ ，
> >
> > $\therefore AC^{2} + AD^{2} = 12 + 4 = 16 = DC^{2}$ （或由正弦定理得： $\frac{2\sqrt{3}}{\sin\angle ADC} = \frac{2}{\sin\angle ACD})$
> >
> > $\therefore \angle D A C = \frac{\pi}{2}, \angle A C D = \frac{\pi}{6},$ $\because \triangle A B C$ 为等边三角形， $\therefore B C = 2 \sqrt {3}, \angle A C B = \frac{\pi}{3},$ $\therefore \angle D C B = \frac{\pi}{6} + \frac{\pi}{3} = \frac{\pi}{2},$ $\therefore S_{\triangle B C D} = \frac{1}{2} \times 4 \times 2 \sqrt {3} = 4 \sqrt {3};$ (2)不妨设 $\angle A D C = \theta, \angle A C D = \alpha, \theta, \alpha \in (0, \pi),$ $\therefore$ 在△BCD中， $S_{\triangle BCD} = \frac{1}{2} \cdot D C \cdot B C \cdot s i n (\alpha + \frac{\pi}{3}) = B C \cdot (s i n \alpha + \sqrt {3} c o s \alpha)$ ，  
> > 在△ACD中，由余弦定理得 $A C^2 = 2 0 - 1 6 \cos \theta$ $\because 4 = A C^2 + 1 6 - 8 A C \cdot c o s \alpha \Rightarrow c o s \alpha = \frac {A C^2 + 1 2}{8 A C},$ $\therefore c o s \alpha = \frac {4 - 2 c o s \theta}{A C},$ 在△ACD中，由正弦定理得 $\frac {A C}{s i n \theta} = \frac {2}{s i n \alpha} \Rightarrow s i n \alpha = \frac {2 s i n \theta}{A C},$ $\therefore S_{\triangle BCD} = B C \cdot (\frac {2 s i n \theta}{A C} + \sqrt {3} \frac {4 - 2 c o s \theta}{A C}) = 2 s i n \theta - 2 \sqrt {3} c o s \theta + 4 \sqrt {3} = 4 s i n (\theta - \frac {\pi}{3})$ $+4\sqrt {3}\leq 4 + 4\sqrt {3}$ 当且仅当 $\theta -\frac{\pi}{3} = \frac{\pi}{2}\Rightarrow \theta = \frac{5\pi}{6}$ 时，等号成立， $\therefore S_{\triangle BCD}$ 面积最大为 $4 + 4\sqrt {3}$ .
