> [!faq]- 2023-2024学年内蒙古包头高一下学期期末数学试卷解析
>
> > [!success]- **【答案】** $\frac{24}{25}$
>
> > [!note]- **【分析】**
> > 根据C=2B，由正弦定理得到 $2b\cos B=c$ ，再由8b=5c，得到 $\cos B=\frac{4}{5}$ ，然后由二倍角公式求解.
>
> > [!note]- **【解析】**
> > 因为C=2B,
> >
> > 所以由正弦定理得： $\frac{b}{\sin B} = \frac{c}{\sin C} = \frac{c}{\sin 2B} = \frac{c}{2\sin B\cos B},$
> >
> > 即 $2b\cos B=c,$
> >
> > 因为8b=5c，所以2bcosB= $\frac{8}{5}$ b,
> >
> > 即 $\cos B = \frac{4}{5}$ ，所以 $\sin B = \sqrt{1 - \cos^2 B} = \sqrt{1 - \frac{16}{25}} = \frac{3}{5}$
> >
> > 所以 $\sin C = \sin 2B = 2\sin B\cos B = 2\times \frac{3}{5}\times \frac{4}{5} = \frac{24}{25},$
> >
> > 故答案为： $\frac{24}{25}$
