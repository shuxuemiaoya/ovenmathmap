> [!faq]- 2022-2023学年内蒙古赤峰二中高一（下）第二次月考数学试卷解析
>
> > [!success]- **【答案】** D
>
> > [!note]- **【解析】**
> > $$
> > \triangle B C D \text {中}, \angle B C D = 1 5 ^ {\circ}, \angle C B D = 3 0 ^ {\circ}, C D = 1 0 \sqrt {2} m
> > $$
> >
> > 由正弦定理 $\frac{CD}{\sin\angle CBD} = \frac{CB}{\sin\angle CDB}$ ，可得 $\frac{10\sqrt{2}}{\sin 30^{\circ}} = \frac{CB}{\sin(180^{\circ} - 15^{\circ} - 30^{\circ})}$
> >
> > 可得 $CB = 20\sqrt{2} \times \frac{\sqrt{2}}{2} = 20$
> >
> > 在 $Rt\triangle ABC$ 中， $\angle ACB = 45^{\circ}$
> >
> > 所以塔高AB = BC = 20m.
> >
> > 故选：D.
