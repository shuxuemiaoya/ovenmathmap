> [!faq]- 2024-2025学年内蒙古乌兰察布市集宁二中高一（下）期末数学试卷解析
>
> > [!success]- **【答案】** BCD
>
> > [!note]- **【解析】**
> > 对于 $A$ ，因为 $a = 2$ ， $c = 1$ ，根据三角形的三边关系得边 $\pmb{b}$ 的范围为 $1 < b < 3$ ，所以 $\pmb{b}$ 可能小于2，故 $A$ 错误；
> >
> > 对于 $B$ ，因为 $\pmb{a} = 2$ ， $c = 1$ ，所以根据正弦定理
> >
> > $\frac{a}{sinA} = \frac{c}{sinC} \Rightarrow \frac{2}{sinA} = \frac{1}{sinC} \Rightarrow sinA = 2\sin C$ ，故 $B$ 正确；
> >
> > 对于 $C$ ，当 $B = 60^{\circ}$ 时，由余弦定理得 $b^{2} = a^{2} + c^{2} - 2ac\cos B = 2^{2} + 1^{2} - 2\times 2\times 1\times \frac{1}{2} = 3$
> >
> > 此时 $a^2 = 4$ ， $b^{2} + c^{2} = 3 + 1 = 4$ ，满足勾股定理，所以 $\triangle ABC$ 为直角三角形，故 $C$ 正确；
> >
> > 对于 $D$ ，当 $B = 150^{\circ}$ 时，因为 $\pmb {a} = 2$ ， $\pmb {c} = 1$ ，所以
> >
> > $S = \frac{1}{2} \bullet a \bullet c \bullet \sin B = \frac{1}{2} \bullet 2 \bullet 1 \bullet \sin 150^{\circ} = \frac{1}{2}$ ，故 $D$ 正确.
> >
> > 故选：BCD.
