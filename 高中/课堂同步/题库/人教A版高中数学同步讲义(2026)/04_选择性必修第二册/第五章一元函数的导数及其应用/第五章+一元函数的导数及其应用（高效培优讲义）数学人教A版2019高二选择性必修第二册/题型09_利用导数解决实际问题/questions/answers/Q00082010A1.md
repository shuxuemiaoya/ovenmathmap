> [!faq]- 《第五章+一元函数的导数及其应用（高效培优讲义）数学人教A版2019高二选择性必修第二册》官方解析
>
> > [!success]- **【答案】** (1) $y=\frac{1000}{v}\left(a+\frac{1}{200}v^{3}\right)=1000\left(\frac{a}{v}+\frac{1}{200}v^{2}\right),v\in(0,120]$ (2) 答案见解析
>
> > [!note]- **【分析】**
> > （1）求出汽车从甲地匀速行驶到乙地所用时间，根据汽车每小时的运输成本可变部分和固定部分组
> >
> > 成，可求得全程运输成本以及函数的定义域；
> >
> > (2) 求导讨论单调性即可·
>
> > [!note]- **【解析】**
> > （1）由题意得，每小时运输成本为 $\left(a+\frac{1}{200}v^{3}\right)$ ，全程行驶时间为 $\frac{1000}{v}$ 小时，所以
> >
> > $$
> > y = \frac {1 0 0 0}{v} \left(a + \frac {1}{2 0 0} v ^ {3}\right) = 1 0 0 0 \left(\frac {a}{v} + \frac {1}{2 0 0} v ^ {2}\right), v \in (0, 1 2 0 ]
> > $$
> >
> > $$
> > y ^ {\prime} (v) = 1 0 0 0 \left(- \frac {a}{v ^ {2}} + \frac {v}{1 0 0}\right) = 1 0 0 0 \left(\frac {v ^ {3} - 1 0 0 a}{1 0 0 v ^ {2}}\right) \tag {2}
> > $$
> >
> > 当 $\sqrt[3]{100a} < 120, 0 < a < 17280$ 时，当 $v = \sqrt[3]{100a}$ 时， $y' = 0$ ，
> >
> > 当 $0 < v < \sqrt[3]{100a}$ 时， $y' < 0$ ，y 单调递减，
> >
> > 当 $\sqrt[3]{100a} < v < 120$ 时， $y' > 0, y$ 单调递增，
> >
> > 所以当 $v = \sqrt[3]{100a}$ 时，y 最小；
> >
> > 当 $\sqrt[3]{100a}$ 120, $a$ 17280时， $y' \leq 0$ ， $y$ 单调递减，当 $v = 120$ 时， $y$ 最小；
> >
> > 综上：当 $0 < a < 17280$ 时，应该以 $\sqrt[3]{100a}$ 千米/小时行驶；
> >
> > 当 $a = 17280$ 时，应该以 $120$ 千米/小时行驶
> >
> > ## 方法技巧
> >
> > 函数的优化问题即实际问题中的最值问题，其一般解题步骤为：
> >
> > 一设，设出自变量、因变量；
> >
> > 二列，列出函数关系式，并写出定义域；
> >
> > 三解，解出函数的最值，一般常用导数求解；
> >
> > 四答，回答实际问题.
