> [!faq]- 《第五章+一元函数的导数及其应用（高效培优讲义）数学人教A版2019高二选择性必修第二册》官方解析
>
> > [!success]- **【答案】** A
>
> > [!note]- **【分析】**
> > 根据函数极值点的定义，由导函数及韦达定理计算参数 $a$ 范围，可直接判定 $\mathsf{A}$ ；对于 $\mathsf{B}$ 项，消元转
> >
> > 化为单变量，构造函数判定其单调性求最值即可；对于 $C$ 项，利用韦达定理消元转化计算即可；对于 $D$ 项，
> >
> > 化简比值代数式，将问题化为判定两点斜率问题，结合对数函数的图象即可判定
>
> > [!note]- **【解析】**
> > 由题意知 $f(x)=\ln x-ax+\frac{a}{x}(x>0)$ ，则 $f'(x)=\frac{1}{x}-a-\frac{a}{x^{2}}=\frac{-ax^{2}+x-a}{x^{2}}$
> >
> > 由于 $f(x)=\ln x-ax+\frac{a}{x}$ 有两个不同的极值点 $x_{1},x_{2}$
> >
> > 即 $ax^2 - x + a = 0$ 有2个正数根 $x_1, x_2$ ，则 $x_1 + x_2 = \frac{1}{a}, x_1 x_2 = 1$
> >
> > 故需满足 $\left\{ \begin{array}{ll}\Delta = 1 - 4a^{2} > 0\\ \frac{1}{2a} >0\\ a > 0 \end{array} \right.$ ，解得 $0 <   a <   \frac{1}{2}$
> >
> > 对于 A， $x_{1} + x_{2} = \frac{1}{a} > 2$ ，A 错误；
> >
> > 对于 B， $\frac{x_{1}+x_{2}}{2}=\frac{1}{2a}$ ，故 $f\left(\frac{x_{1}+x_{2}}{2}\right)=f\left(\frac{1}{2a}\right)=-\ln2a-\frac{1}{2}+2a^{2}$
> >
> > $$
> > g (a) = - \ln 2 a - \frac {1}{2} + 2 a ^ {2}, 0 <   a <   \frac {1}{2} \text {, 则} g ^ {\prime} (a) = - \frac {1}{a} + 4 a = \frac {4 a ^ {2} - 1}{a} <   0
> > $$
> >
> > 即 $g(a) = -\ln 2a - \frac{1}{2} + 2a^2$ 在 $\left(0, \frac{1}{2}\right)$ 上单调递减，故 $g(a) > g\left(\frac{1}{2}\right) = 0$
> >
> > 即 $f\left(\frac{x_{1}+x_{3}}{2}\right)>0$ ，B 正确；
> >
> > 对于 C， $f(x_{1}) + f(x_{2}) = \ln x_{1} - ax_{1} + \frac{a}{x_{1}} + \ln x_{2} - ax_{2} + \frac{a}{x_{2}} = \ln (x_{1}x_{2}) - a(x_{1} + x_{2}) + \frac{a(x_{1} + x_{2})}{x_{1}x_{2}} = \ln 1 - a \times \frac{1}{a} + 1 = 0$ ，C
> >
> > 正确；
> >
> > 对于 D， $\frac{f(x_{1})-f(x_{2})}{x_{1}-x_{2}}=\frac{\ln x_{1}-\ln x_{2}+a(x_{2}-x_{1})+\frac{a(x_{2}-x_{1})}{x_{1}x_{2}}}{x_{1}-x_{2}}=\frac{\ln x_{1}-\ln x_{2}}{x_{1}-x_{2}}-2a,\frac{\ln x_{1}-\ln x_{2}}{x_{1}-x_{2}}$ 可看作曲线 $y=\ln x$ 上两
> >
> > 点 $\left(x_{1},\ln x_{1}\right)$ ， $\left(x_{2},\ln x_{2}\right)$ 连线的斜率，
> >
> > 由于 $x_{1} + x_{2} = \frac{1}{a} > 2, x_{1}x_{2} = 1$ ，故不妨设 $x_{1} < 1, x_{2} > 1$ ，
> >
> > 由于 $y = \ln x, y' = \frac{1}{x}$ ，则曲线 $y = \ln x$ 在 x = 1 处的切线斜率为 1，
> >
> > 由于 $x_{1} < 1, x_{2} > 1$ ，故 $\left(x_{1}, \ln x_{1}\right), \left(x_{2}, \ln x_{2}\right)$ 连线的斜率小于 1，即 $\frac{\ln x_{1} - \ln x_{2}}{x_{1} - x_{2}} < 1$
> >
> > 所以 $\frac{\ln x_{1}-\ln x_{2}}{x_{1}-x_{2}}-2a<1-2a$ ，即 $\frac{f(x_{1})-f(x_{2})}{x_{1}-x_{2}}<1-2a$ ，D 正确。
> >
> > 故选 **A**.
