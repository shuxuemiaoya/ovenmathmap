> [!faq]- 《第五章+一元函数的导数及其应用（高效培优讲义）数学人教A版2019高二选择性必修第二册》官方解析
>
> > [!success]- **【答案】** (1) $y=\frac{4}{\pi^{2}}x-\frac{4}{\pi}+1$ (2)① $\{0,1\}$ ; ②证明见解析
>
> > [!note]- **【分析】**
> > （1）求导，进而可求 $f\left(\frac{\pi}{2}\right)$ ， $f'\left(\frac{\pi}{2}\right)$ ，结合导数的几何意义求切线方程；
> >
> > (2) ① 分析可知方程 $x \sin x = a$ 有两个解 $x_{1}, x_{2}$ ，构造 $h(x) = x \sin x$ ，利用导数分析其单调性，结合单调性分
> >
> > 析求解即可；②由 $h(x)$ 的单调性可知： $0 < x_1 < c < x_2 < \pi$ 。分 $\pi - c < x_1$ 和 $x_1 \leq \pi - c$ 两种情况，结合 $h(x)$ 的单
> >
> > 调性分析证明·
>
> > [!note]- **【解析】**
> > （1）当 $a = 1$ 时，则 $f(x) = \sin x - \frac{1}{x}$ ， $x \in (0, \pi)$ ，且 $f'(x) = \cos x + \frac{1}{x^2}$
> >
> > 可得 $f\left(\frac{\pi}{2}\right) = 1 - \frac{2}{\pi}, f'\left(\frac{\pi}{2}\right) = \frac{4}{\pi^2}$ ，即切点坐标为 $\left(\frac{\pi}{2}, 1 - \frac{2}{\pi}\right)$ ，切线斜率 $k = \frac{4}{\pi^2}$
> >
> > 所以所求切线方程为 $y - \left(1 - \frac{2}{\pi}\right) = \frac{4}{\pi^2}\left(x - \frac{\pi}{2}\right)$ ，即 $y = \frac{4}{\pi^2} x - \frac{4}{\pi} + 1$
> >
> > (2) ①函数 $f(x)$ 有两个零点 $x_{1}, x_{2}$ ，即方程 $x \sin x = a$ 有两个解 $x_{1}, x_{2}$ ，
> >
> > $h(x)=x\sin x$ ，则 $h'(x)=\sin x+x\cos x$
> >
> > 设 $h'(x)$ 的导函数为 $h''(x)$ ，则 $h''(x)=2\cos x-x\sin x$
> >
> > 当 $x \in \left(0, \frac{\pi}{2}\right]$ 时，则 $\cos x = 0, \sin x > 0$ ，可得 $h'(x) > 0$ ；
> >
> > 当 $x\in \left(\frac{\pi}{2},\pi\right)$ 时，则 $\cos x <   0,\sin x > 0$ ，可得 $h^{\prime \prime}(x) <   0$
> >
> > 可知 $h^{\prime}(x)$ 在 $\left(\frac{\pi}{2},\pi\right)$ 内单调递减，且 $h^{\prime}\left(\frac{\pi}{2}\right) > 0$ ， $h^{\prime}\left(\frac{2\pi}{3}\right) = \frac{\sqrt{3}}{2} -\frac{\pi}{3} < 0$
> >
> > 则存在 $c \in \left(\frac{\pi}{2}, \frac{2\pi}{3}\right)$ ，使得 $h'(c) = \sin c + c \cos c = 0$
> >
> > 当 $x\in \left(\frac{\pi}{2},c\right)$ 时， $h^{\prime}(x) > 0$ ， $x\in (c,\pi)$ 时， $h^{\prime}(x) < 0$
> >
> > 综上所述：当 $x \in (0, c)$ 时， $h'(x) > 0$ ， $x \in (c, \pi)$ 时， $h'(x) < 0$
> >
> > 可知 $h(x)$ 在 $(0,c)$ 内单调递增，在 $(c,\pi)$ 内单调递减，
> >
> > 则 $h(x)_{\max}=h(c)=c\sin c=\frac{c^{2}}{\sqrt{c^{2}+1}}$
> >
> > 构建 $g(x) = \frac{x^2}{\sqrt{x^2 + 1}}$ ， $x \in \left(\frac{\pi}{2}, \frac{2\pi}{3}\right)$
> >
> > 因为 $g(x)=\frac{x^{2}}{\sqrt{x^{2}+1}}=\sqrt{x^{2}+1}-\frac{1}{\sqrt{x^{2}+1}}$ ，可知 $g(x)$ 在 $\left(\frac{\pi}{2},\frac{2\pi}{3}\right)$ 上单调递增，
> >
> > 又因为 $\pi^2 < 10$ ，则 $g(c) < g\left(\frac{2\pi}{3}\right) = \frac{\left(\frac{2\pi}{3}\right)^2}{\sqrt{\left(\frac{2\pi}{3}\right)^2 + 1}} < \frac{\frac{40}{9}}{\sqrt{\frac{40}{9} + 1}} = \frac{40}{21} < 2$
> >
> > 且当 $h(0) = h(\pi) = 0$ ， $h\left(\frac{\pi}{2}\right) = \frac{\pi}{2} > 1$ ，所以 $[a]$ 的取值范围为 $\{0,1\}$ ；
> > - **②**：由 $h(x)$ 的单调性可知： $0 < x_{1} < c < x_{2} < \pi$
> >
> > 若 $\pi - c < x_{1}$ ，则 $\pi - x_{1} < c < x_{2}$ ，有 $x_{1} + x_{2} > \pi$ 成立；
> >
> > 若 $x_{1} \leq \pi - c$ ，则 $h(\pi - x_{1}) = (\pi - x_{1})\sin (\pi - x_{1}) = \pi \sin x_{1} - x_{1}\sin x_{1} = \pi \sin x_{1} - a$
> >
> > 因为 $h(x_{1})=h(x_{2})=a$ ，则 $h(\pi-x_{1})=(\pi-x_{1})\sin(\pi-x_{1})=\pi\sin x_{1}-a=\frac{\pi a}{x_{1}}-a$
> >
> > 因为 $c > \frac{\pi}{2}$ ，则 $\pi - c < \frac{\pi}{2}$ ，可得 $x_{1} < \frac{\pi}{2}$
> >
> > $$
> > h \left(\pi - x _ {1}\right) = \left(\pi - x _ {1}\right) \sin \left(\pi - x _ {1}\right) = \pi \sin x _ {1} - a = \frac {\pi a}{x _ {1}} - a > \frac {\pi a}{\frac {\pi}{2}} - a = a = h \left(x _ {2}\right) \text {则}
> > $$
> >
> > 因为 $\pi - x_{1}$ c, $x_{2} > c$ , 且 $h(x)$ 在 $(c, \pi)$ 单调递减，
> >
> > 所以 $\pi - x_{1} < x_{2}$ ，即 $x_{1} + x_{2} > \pi$ ；
> >
> > 综上所述： $x_{1}+x_{2}>\pi$
> >
> > ## 方法技巧
> >
> > 证明不等式的过程中常使用构造法，利用函数单调性、极值、最值加以证明．常见的构造方法有：
> >
> > (1)直接构造法：证明不等式 $f(x) > g(x)(f(x) < g(x))$ 转化为证明 $f(x) - g(x) > 0(f(x) - g(x) < 0)$ ，进而构造辅助函数
> >
> > $$
> > h (x) = f (x) - g (x);
> > $$
> >
> > (2)适当放缩构造法：一是根据已知条件适当放缩，二是利用常见的放缩结论，如①对数形式： $x \geq 1 + \ln x (x > 0)$ ，当且仅当 x = 1 时，等号成立.
> > - **②**：指数形式： $\mathrm{e}^{x}\geq x+1\ (x\in\mathbb{R})$ ，当且仅当x=0时，等号成立。进一步可得到一组不等式链： $\mathrm{e}^{x}>x+1>x>1+\ln x\ (x>0$ ，且 $x\neq1$ ）.
> >
> > (3)构造“形似”函数：稍作变形再构造，对原不等式同解变形，如移项、通分、取对数，把不等式转化为左、
> >
> > 右两边是相同结构的式子的形式，根据“相同结构”构造辅助函数；
> >
> > (4)构造双函数：若直接构造函数求导难以判断符号，导函数零点也不易求得，因此函数单调性与极值点都不
> >
> > 易获得，则可构造函数 $f(x)$ 和 $g(x)$ ，利用其最值求解。在证明过程中，等价转化是关键，此处 $f(x)_{\min} > g(x)_{\max}$
> >
> > 恒成立．从而 $f(x)>g(x)$ ，但此处 $f(x)$ 与 $g(x)$ 取到最值的条件不是同一个“x的值”．
