> [!faq]- 《第五章+一元函数的导数及其应用（高效培优讲义）数学人教A版2019高二选择性必修第二册》官方解析
>
> > [!success]- **【答案】** ABD
>
> > [!note]- **【分析】**
> > 将 $\tan C = \frac{1 - \sin A}{\cos A}$ 切化弦，整理得到 $\sin B = \cos C$ ，从而得到 $B = \frac{\pi}{2} - C$ ， $B = \frac{\pi}{2} + C$ ，当 $B = \frac{\pi}{2} - C$ 计算出角 A，代入已知 $a = b \cos A$ ，得到 a = 0，产生矛盾，从而得到 $B = \frac{\pi}{2} + C$ ；由 $B = \frac{\pi}{2} + C$ ，计算出 $A = \frac{\pi}{2} - 2C$ ，利用 A > 0 求出 $0 < C < \frac{\pi}{4}$ ，由 $\sin B = \cos C$ 和 $\sin A = \sin B \cos A$ 得到 $\tan A = \cos C$ ，代入 $A = \frac{\pi}{2} - 2C$ 整理后得到 $2 \sin^{3} C - 2 \sin^{2} C - 2 \sin C + 1 = 0$ ，将此式子放缩后得到 $2 \sin^{3} C - 2 \sin^{2} C - 2 \sin C + 1 < 2 \sin^{3} C - \sin^{2} C - 2 \sin C + 1$ ，即 $0 < \sin^{2} C (2 \sin C - 1) - (2 \sin C - 1)$ ，整理后得到 $\sin C < \frac{1}{2}$ ，从而得到 C 的范围；由 $a = 2 R \sin A$ 和 $A = \frac{\pi}{2} - 2C$ 得到 $a = 2 R \cos 2C$ ，由 $c = 2 R \sin C$ 和 $0 < C < \frac{\pi}{6}$ 得到 $0 < \sin C < \frac{1}{2}$ 和 $\frac{1}{2} < \cos 2C < 1$ ，从而得到 a > c；设 $\sin C = t$ ，则 $2 \sin^{3} C - 2 \sin^{2} C - 2 \sin C + 1 = 0$ ，转化为 $2 t^{3} - 2 t^{2} - 2 t + 1 = 0$ 且 $0 < t < \frac{1}{2}$ ，设 $f(t) = 2 t^{3} - 2 t^{2} - 2 t + 1$ ，利用导数法得到 $f(t)$ 在 $(0, \frac{1}{2})$ 内是减函数，利用二分法思想得到 $f(t)$ 的零点在 $(\frac{2}{5}, \frac{1}{2})$ 内，即 $\frac{2}{5} < \sin C < \frac{1}{2}$ ，求出 $\tan C$ 的范围，得到 $\tan C > \frac{2}{5}$ ，由 $B = \frac{\pi}{2} + C$ 得到 $\sin B = \cos C$ ，由正弦定理得到 $\frac{c}{b} = \tan C$ ，从而得到 $c > \frac{2}{5} b$ 。
>
> > [!note]- **【解析】**
> > ∵ $\tan C = \frac{1 - \sin A}{\cos A}$ ，∴ $\frac{\sin C}{\cos C} = \frac{1 - \sin A}{\cos A}$ ，
> >
> > $$
> > \therefore \sin C \cos A = \cos C - \sin A \cos C
> > $$
> >
> > $$
> > \therefore \sin C \cos A + \sin A \cos C = \cos C, \quad \therefore \sin (C + A) = \cos C,
> > $$
> >
> > $\therefore \sin (\pi - B) = \cos C, \therefore \sin B = \cos C, \therefore B = \frac{\pi}{2} - C \text{或} B = \frac{\pi}{2} + C,$
> >
> > $$
> > B = \frac {\pi}{2} - C \quad \because A = \pi - B - C = \pi - \left(\frac {\pi}{2} - C\right) - C = \frac {\pi}{2},
> > $$
> >
> > 代入已知 $a = b\cos A$ ，得到 $a = 0$ ，这是不可能的，则 $B = \frac{\pi}{2} - C$ 舍去，
> >
> > $\therefore B=\frac{\pi}{2}+C$ ，故选项 $^{A}$ 正确；
> >
> > $$
> > \because B = \frac {\pi}{2} + C \quad \therefore A = \pi - B - C = \pi - \left(\frac {\pi}{2} + C\right) - C = \frac {\pi}{2} - 2 C
> > $$
> >
> > $$
> > \because A > 0, \therefore \frac {\pi}{2} - 2 C > 0, \therefore 0 <   C <   \frac {\pi}{4},
> > $$
> >
> > $$
> > \because \sin B = \cos C, \quad \sin A = \sin B \cos A, \quad \therefore \sin A = \cos C \cos A, \quad \therefore \tan A = \cos C
> > $$
> >
> > $$
> > \because A = \frac {\pi}{2} - 2 C ^ {\prime} \therefore \tan \left(\frac {\pi}{2} - 2 C\right) = \cos C ^ {\prime} \therefore \frac {\sin \left(\frac {\pi}{2} - 2 C\right)}{\cos \left(\frac {\pi}{2} - 2 C\right)} = \cos C ^ {\prime},
> > $$
> >
> > $$
> > \therefore \frac {\cos 2 C}{\sin 2 C} = \cos C, \therefore \cos 2 C = \sin 2 C \cos C, \therefore 1 - 2 \sin^ {2} C = 2 \sin C \cos^ {2} C,
> > $$
> >
> > $$
> > \therefore 1 - 2 \sin^ {2} C = 2 \sin C (1 - \sin^ {2} C) \quad \therefore 2 \sin^ {3} C - 2 \sin^ {2} C - 2 \sin C + 1 = 0
> > $$
> >
> > $$
> > \because \sin^ {2} C > 0 \quad , \therefore 2 \sin^ {2} C > \sin^ {2} C \quad , \therefore - 2 \sin^ {2} C <   - \sin^ {2} C
> > $$
> >
> > $$
> > \therefore 2 \sin^ {3} C - 2 \sin^ {2} C - 2 \sin C + 1 <   2 \sin^ {3} C - \sin^ {2} C - 2 \sin C + 1
> > $$
> >
> > $$
> > \therefore 0 <   \sin^ {2} C (2 \sin C - 1) - (2 \sin C - 1) \quad \therefore 0 <   (\sin^ {2} C - 1) (2 \sin C - 1)
> > $$
> >
> > $$
> > \therefore \sin^ {2} C - 1 <   0, \therefore 2 \sin C - 1 <   0, \therefore \sin C <   \frac {1}{2}, \therefore 0 <   C <   \frac {\pi}{6},
> > $$
> >
> > 故选项 B 正确；
> >
> > $$
> > \because a = 2 R \sin A, A = \frac {\pi}{2} - 2 C, \therefore a = 2 R \sin \left(\frac {\pi}{2} - 2 C\right) = 2 R \cos 2 C,
> > $$
> >
> > $\because c = 2R\sin C$ ， $\because 0 <   C <   \frac{\pi}{6}$
> >
> > $$
> > \because 0 <   \sin C <   \frac {1}{2}, \therefore 0 <   2 C <   \frac {\pi}{3}, \therefore \frac {1}{2} <   \cos 2 C <   1
> > $$
> >
> > $\therefore a > c$ ，故选项 $^{C}$ 错误；
> >
> > 设 $\sin C = t$ ，∵ $0 < C < \frac{\pi}{6}$ ， $0 < t < \frac{1}{2}$ ，
> >
> > $$
> > \because 2 \sin^ {3} C - 2 \sin^ {2} C - 2 \sin C + 1 = 0, \therefore 2 t ^ {3} - 2 t ^ {2} - 2 t + 1 = 0, \quad 0 <   t <   \frac {1}{2},
> > $$
> >
> > 设 $f(t)=2t^{3}-2t^{2}-2t+1$
> >
> > $$
> > \because f ^ {\prime} (t) = 6 t ^ {2} - 4 t - 2 = 2 (3 t ^ {2} - 2 t - 1) = 2 (3 t + 1) (t - 1) <   0
> > $$
> >
> > $\therefore f(t) = 2t^{3} - 2t^{2} - 2t + 1$ 在 $(0, \frac{1}{2})$ 内是减函数，
> >
> > $$
> > \because f (0) = 1 > 0, f \left(\frac {1}{2}\right) = \frac {1}{4} - \frac {1}{2} - 1 + 1 = - \frac {1}{4} <   0,
> > $$
> >
> > $\therefore f(t) = 2t^3 - 2t^2 - 2t + 1$ 在 $(0, \frac{1}{2})$ 内有唯一的零点，
> >
> > 利用二分法思想，∵ $f(0.4) = 2 \times 0.4^3 - 2 \times 0.4^2 - 2 \times 0.4 + 1 = 0.008 > 0$
> >
> > $\therefore f(t) = 2t^3 - 2t^2 - 2t + 1$ 的零点在 $(\frac{2}{5}, \frac{1}{2})$ 内，
> >
> > $$
> > \therefore \frac {2}{5} <   \sin C <   \frac {1}{2}, \therefore \frac {4}{2 5} <   \sin^ {2} C <   \frac {1}{4}, \therefore \frac {4}{2 5} <   \frac {\sin^ {2} C}{\sin^ {2} C + \cos^ {2} C} <   \frac {1}{4},
> > $$
> >
> > $$
> > \therefore \frac {4}{2 5} <   \frac {\tan^ {2} C}{\tan^ {2} C + 1} <   \frac {1}{4} \quad \therefore \frac {2}{\sqrt {2 1}} <   \tan C <   \frac {1}{\sqrt {3}}
> > $$
> >
> > $$
> > \because \frac {2}{\sqrt {2 1}} > \frac {2}{5} \quad , \therefore \tan C > \frac {2}{5}
> > $$
> >
> > $$
> > \because B = \frac {\pi}{2} + C, \therefore \sin B = \cos C, \therefore \frac {c}{b} = \frac {\sin C}{\sin B} = \frac {\sin C}{\cos C} = \tan C,
> > $$
> >
> > $\therefore\frac{c}{b}>\frac{2}{5}$ ，故选项D正确.
> >
> > 故选 **ABD**.
