> [!faq]- 《第五章+一元函数的导数及其应用（高效培优讲义）数学人教A版2019高二选择性必修第二册》官方解析
>
> > [!success]- **【答案】** ACD
>
> > [!note]- **【分析】**
> > 由给定等式同构变形，借助函数 $h(t)=\ln t+t$ 单调性判断 A；利用导数，结合不等式 $\ln(x+1)\mathfrak{L}x$ 推理判
> >
> > 断 $^{B}$ ；利用不等式 $\ln x \leq x - 1$ 及 $x + y > 0$ 确定曲线位置判断 C；构造关于 x 的函数 $\varphi(x) = \ln(x + y) - 2x - 3y$ ，借助
> >
> > 此函数有零点，再利用导数求解判断 D.
>
> > [!note]- **【解析】**
> > 依题意， $\ln(x+y)-x-2y=e^{2x+3y}\Leftrightarrow\ln(x+y)+x+y=2x+3y+e^{2x+3y}=\ln e^{2x+3y}+e^{2x+3y}$
> >
> > 对于 $\mathsf{A}$ ，令函数 $h(t) = \ln t + t$ ，函数 $h(t)$ 在 $(0, +\infty)$ 上单调递增，而 $h(x + y) = h(\mathrm{e}^{2x + 3y})$
> >
> > 则 $x + y = \mathrm{e}^{2x + 3y}$ ， $\ln (x + y) = 2x + 3y$ ，A正确；
> >
> > 令函数 $g(x)=\ln(x+1)-x$ ，求导得 $g'(x)=\frac{1}{x+1}-1=\frac{-x}{x+1}$
> >
> > 当 -1 < x < 0 时， $g'(x) > 0$ ，当 x > 0 时， $g'(x) < 0$
> >
> > 函数 $g(x)$ 在 $(-1,0)$ 上递增，在 $(0,+\infty)$ 上递减， $g(x)\leq g(0)=0$
> >
> > 因此 $\ln(x+1)$ £ x， $\ln x \leq x-1$ ，
> >
> > 对于 B，当 x=1 时， $\ln(1+y)=2+3y$ ，而 $\ln(1+y)\leq y$ ，则 $2+3y\leq y$ ，解得 $y\leq-1$ ，
> >
> > 与 $1 + y > 0$ 矛盾，因此 $x \neq 1$ ，B错误；
> >
> > 对于 C，由 $2x + 3y = \ln(x + y) \leq x + y - 1$ ，得 $x + 2y \leq -1$
> >
> > 即曲线 C 上的点位于直线 $x + 2y = -1$ 的下方；
> >
> > 由 $x + y > 0$ ，得曲线 $C$ 上的点位于直线 $x + y = 0$ 的上方，曲线 $C$ 全部位于第四象限，C正确；
> >
> > 对于 D，曲线 $C:\ln(x+y)=2x+3y$ 上的点满足方程 $\ln(x+y)-2x-3y=0$
> >
> > 令 $\varphi (x) = \ln (x + y) - 2x - 3y$ ，则方程 $\varphi (x) = 0$ 有解， $\varphi^{\prime}(x) = \frac{1}{x + y} -2 = \frac{1 - 2(x + y)}{x + y}\big(x > - y\big)$
> >
> > 由 $\varphi'(x)>0$ ，得 $x<\frac{1}{2}-y$ ；由 $\varphi'(x)<0$ ，得 $x>\frac{1}{2}-y$
> >
> > $\varphi (x)$ 在 $(-y,\frac{1}{2} -y)$ 上递增，在 $(\frac{1}{2} -y, + \infty)$ 上递减，
> >
> > $\varphi(x)_{\max}=\varphi(\frac{1}{2}-y)=\ln(\frac{1}{2}-y+y)-2(\frac{1}{2}-y)-3y=-y-1-\ln2\quad0$ ，解得 $y\leq-1-\ln2$ ，
> >
> > 当 $x$ 从大于 $-y$ 的方向趋近于 $-y$ 时， $\varphi(x) \to -\infty$ ，当 $x \to +\infty$ 时， $\varphi(x) \to -\infty$ ，
> >
> > 因此 $\varphi(x)=0$ 必有解，D 正确.
> >
> > 故选 **ACD**
