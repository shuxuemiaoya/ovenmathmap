> [!faq]- 《第五章+一元函数的导数及其应用（高效培优讲义）数学人教A版2019高二选择性必修第二册》官方解析
>
> > [!success]- **【答案】** A
>
> > [!note]- **【分析】**
> > 先根据函数的零点只有一个列式，再构造函数 $g(x) = x^{2} - \ln (x + 1) - \ln (a - x)$ ，根据导函数得出函数
> >
> > 单调性得出最小值即可计算求出参数范围 $-1 < x_0 < \frac{\sqrt{3} - 1}{2}$ ，再构造 $\varphi(x) = x^2 + \ln\left(\frac{1}{(x+1)^2} - \frac{2x}{1+x}\right)$ ，结合导函
> >
> > 数单调性及零点个数计算求参·
>
> > [!note]- **【解析】**
> > 函数 $f(x)$ 在 $(-1, a)$ 上有且只有一个零点等价于方程 $\mathrm{e}^{x^2} + (x + 1)(x - a) = 0$ 在 $(-1, a)$ 上有且只有一个实
> >
> > 数根，
> >
> > 即 $x^{2}=\ln(x+1)+\ln(a-x)$ 在 $(-1,a)$ 上有且只有一个实数根.
> >
> > 令 $g(x)=x^{2}-\ln(x+1)-\ln(a-x)$ ，则 $g'(x)=2x-\frac{1}{x+1}-\frac{1}{x-a}$ ，
> >
> > 函数 $g'(x)$ 单调递增，当 $x \to -1$ 时， $g'(x) \to -\infty$ ，当 $x \to a$ 时， $g'(x) \to +\infty$ ，
> >
> > 所以存在 $x_0 \in (-1, a)$ ，使得 $g'(x_0) = 2x_0 - \frac{1}{x_0 + 1} - \frac{1}{x_0 - a} = 0$ ，则 $\frac{1}{a - x_0} = \frac{1}{x_0 + 1} - 2x_0$
> >
> > 当 $-1 < x < x_{0}$ 时， $g'(x) < 0$ ，此时函数 $g(x)$ 单调递减，
> >
> > 当 $x_{0}<x<a$ 时， $g'(x)>0$ ，此时函数 $g(x)$ 单调递增，
> >
> > 所以 $g(x)_{\min}=g(x_{0})=x_{0}^{2}-\ln(1+x_{0})-\ln(a-x_{0})=0$
> >
> > 由 $\left\{ \begin{array}{l} \frac{1}{a - x_0} = \frac{1}{x_0 + 1} - 2x_0 > 0 \\ x_0 > -1 \end{array} \right.$ ，解得 $-1 < x_0 < \frac{\sqrt{3} - 1}{2}$ ，
> >
> > 所以 $x_0^2 -\ln (1 + x_0) + \ln \left(\frac{1}{a - x_0}\right) = x_0^2 -\ln (1 + x_0) + \ln \left(\frac{1}{x_0 + 1} -2x_0\right) = x_0^2 +\ln \left(\frac{1}{(x_0 + 1)^2} -\frac{2x_0}{1 + x_0}\right) = 0$
> >
> > 令 $\varphi(x)=x^{2}+\ln\left(\frac{1}{(x+1)^{2}}-\frac{2x}{1+x}\right)$ ，其中 $-1<x<\frac{\sqrt{3}-1}{2}$ ，
> >
> > $$
> > \varphi^ {\prime} (x) = 2 x + \frac {(x + 1) ^ {2}}{1 - 2 x ^ {2} - 2 x} \times \left[ - \frac {2 (x + 2)}{(x + 1) ^ {3}} \right] = 2 x + \frac {2 (x + 2)}{(2 x ^ {2} + 2 x - 1) (x + 1)} = \frac {4 x ^ {4} + 8 x ^ {3} + 2 x ^ {2} + 4}{(2 x ^ {2} + 2 x - 1) (x + 1)} =
> > $$
> >
> > $$
> > \frac {4 x ^ {2} (x + 1) ^ {2} + 2 (2 - x ^ {2})}{(2 x ^ {2} + 2 x - 1) (x + 1)}.
> > $$
> >
> > 因为 $-1 < x < \frac{\sqrt{3} - 1}{2}$ ，所以 $2x^{2} + 2x - 1\langle 0, x + 1\rangle 0, 2 - x^{2} > 0$ ，所以 $\varphi'(x) < 0$
> >
> > 所以函数 $\varphi(x)$ 在 $\left(-1, \frac{\sqrt{3} - 1}{2}\right)$ 上单调递减，且 $\varphi(0) = 0$ ，所以 $x_0 = 0$ ，
> >
> > 所以 $\frac{1}{a - 0} = \frac{1}{0 + 1} -2\times 0$ ，解得 $a = 1$
> >
> > 故选 **A**.
