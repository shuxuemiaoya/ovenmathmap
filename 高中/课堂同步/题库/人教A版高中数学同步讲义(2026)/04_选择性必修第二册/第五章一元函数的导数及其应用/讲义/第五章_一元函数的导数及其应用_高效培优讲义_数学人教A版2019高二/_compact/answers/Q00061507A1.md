> [!faq]- 《第五章_一元函数的导数及其应用_高效培优讲义_数学人教A版2019高二》官方解析
>
> > [!success]- **【答案】** ABD
>
> > [!note]- **【分析】**
> > 对函数 $f(x)$ 求导得出 $f'(x) < 0$ 的解集，可判断 $^{A}$ 正确，代入计算出 $f(x + 1) + 1$ 的解析式，再由奇函
> >
> > 数定义可判断 $^{B}$ 正确，设切点为 $(a,f(a))$ ，构造方程并根据方程解的个数判断出切弦条数，可得 $^{C}$ 错误，令
> >
> > $h(x)=f(x+a)-f(x)$ ，再根据二次函数最值解不等式即可判断D正确.
>
> > [!note]- **【解析】**
> > 对于 A，易知 $f'(x)=3x^{2}-6x=3x(x-2)$ ，令 $f'(x)<0$ ，解得 0<x<2
> >
> > 因此可知 $f(x)$ 在 $(0,2)$ 上单调递减，即 $\mathsf{A}$ 正确，
> >
> > 对于 B，令函数 $y = g(x) = f(x + 1) + 1 = (x + 1)^{3} - 3(x + 1)^{2} + 1 + 1 = x^{3} - 3x$
> >
> > 显然满足 $g(-x) = -g(x)$ ，因此可得 $y = f(x + 1) + 1$ 是奇函数，即 $\mathbf{B}$ 正确；
> >
> > 对于 $C$ ，设切点为 $\left(a,f(a)\right)$
> >
> > 则切线斜率为 $k = f'(a) = 3a^2 - 6a$ ，可知切线方程为 $y - f(a) = k(x - a)$ ，
> >
> > 代入点 $(0,1)$ 可得 $1 - f(a) = -ak$ ，即 $3a^{2} - a^{3} = -a(3a^{2} - 6a)$ ，解得 $a = 0$ 或 $a = \frac{3}{2}$
> >
> > 因此过点 $(0,1)$ 可作曲线 $y = f(x)$ 的两条切线，即 $C$ 错误；
> >
> > 对于D，令 $h(x) = f(x + a) - f(x)$ ，可得 $h(x) = 3ax^{2} + (3a^{2} - 6a)x + a^{3} - 3a^{2}$
> >
> > 由二次函数性质可得其最小值为 $h\left(\frac{2-a}{2}\right)=\frac{a^{3}-12a}{4}$ ，
> >
> > 当 $a = 2\sqrt{3}$ 时，易知 $h\left(\frac{2 - a}{2}\right) = \frac{a^3 - 12a}{4} = 0$ ，因此 $f(x + a) = f(x)$ 恒成立，即D正确
> >
> > 故选 **ABD**
