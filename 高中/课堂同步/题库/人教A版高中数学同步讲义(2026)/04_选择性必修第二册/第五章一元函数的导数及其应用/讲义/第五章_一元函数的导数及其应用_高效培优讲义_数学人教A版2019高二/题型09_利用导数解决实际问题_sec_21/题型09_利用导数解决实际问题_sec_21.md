## 题型09 利用导数解决实际问题

【典例1】某农村合作社为了提高蔬菜产量，增加农民收入，计划建造一批蔬菜大棚·经过调研得知，初期需

投入固定成本 $20$ 万元，除此之外，建造 $x$ 个蔬菜大棚需另投入成本 $D(x)$ 万元，且

$D(x)=\left\{\begin{aligned}x^{2}+10x(0<x\leq10,x\in\mathrm{N}),\\ 40x+\frac{1440}{x}-380(x>10,x\in\mathrm{N}),\end{aligned}\right.$ 初步估计每个蔬菜大棚未来能带来30万元的收入·

(1)求蔬菜大棚带来的利润 $L(x)$ （万元）关于大棚个数 $x$ 的函数关系式；

(2)建造多少个蔬菜大棚时，带来的利润最大?并求最大利润.

【答案】(1) $L(x)=\left\{\begin{aligned}&-x^{2}+20x-20(0<x\leq10,x\in\mathbb{N}),\\ &360-\left(10x+\frac{1440}{x}\right)(x>10,x\in\mathbb{N}).\end{aligned}\right.$

(2)12个，120万元

【分析】（1）利润等于销售额减去投入成本及固定成本，分段计算整理即可；

(2) 分别计算分段函数的最值，比较得出函数最值.

【详解】（1）根据题意得

当 $0 < x \leq 10$ 时， $L(x) = 30x - x^2 - 10x - 20 = -x^2 + 20x - 20$

当 x > 10 时， $L(x) = 30x - 40x - \frac{1440}{x} + 380 - 20 = -10x - \frac{1440}{x} + 360$

所以 $L(x)=\left\{\begin{aligned}-x^{2}+20x-20(0<x\leq10,x\in\mathbb{N}),\\360-\left(10x+\frac{1440}{x}\right)(x>10,x\in\mathbb{N}).\end{aligned}\right.$

(2) 当 $0 < x \leq 10$ 时， $L(x) = -x^{2} + 20x - 20 = -(x - 10)^{2} + 80$

$L(x)_{\text{在}}(0,10]$ 内单调递增，所以当 x=10 时， $L(x)_{\text{的最大值为 }80}$

当 $x > 10$ 时， $L(x) = 360 - \left(10x + \frac{1440}{x}\right)$

因为 $10x + \frac{1440}{x}$ $2\sqrt{10x\times\frac{1440}{x}} = 240$ ，当且仅当 $10x = \frac{1440}{x}$

即 x=12 时，等号成立，

所以 $L(x) \leq 360 - 240 = 120$

因为 $120 > 80$ ，所以当 $x = 12$ 时， $L(x)$ 的最大值为 $120$ ，

所以建造 12 个生态农场获得的利润最大，最大利润为 120 万元·

【典例2】甲、乙两地相距 $1000$ 千米，汽车从甲地匀速驶向乙地，速度不得超过 $120$ 千米/小时．已知汽车每

小时的运输成本（以元为单位）由可变部分和固定部分组成：可变部分与速度 $v$ （千米/小时）的立方成正比，

比例系数为 $\frac{1}{200}$ ，固定部分为 $a (a > 0)$ 。

(1)把全部运输成本 $y$ 元表示为速度 $v$ （千米/小时）的函数，并指出这个函数的定义域；

(2)为了使全部运输成本最小，汽车应以多大速度行驶？

【答案】(1) $y=\frac{1000}{v}\left(a+\frac{1}{200}v^{3}\right)=1000\left(\frac{a}{v}+\frac{1}{200}v^{2}\right),v\in(0,120]$

(2) 答案见解析

【分析】（1）求出汽车从甲地匀速行驶到乙地所用时间，根据汽车每小时的运输成本可变部分和固定部分组

成，可求得全程运输成本以及函数的定义域；

(2) 求导讨论单调性即可·

【详解】（1）由题意得，每小时运输成本为 $\left(a+\frac{1}{200}v^{3}\right)$ ，全程行驶时间为 $\frac{1000}{v}$ 小时，所以

$$
y = \frac {1 0 0 0}{v} \left(a + \frac {1}{2 0 0} v ^ {3}\right) = 1 0 0 0 \left(\frac {a}{v} + \frac {1}{2 0 0} v ^ {2}\right), v \in (0, 1 2 0 ]
$$

$$
y ^ {\prime} (v) = 1 0 0 0 \left(- \frac {a}{v ^ {2}} + \frac {v}{1 0 0}\right) = 1 0 0 0 \left(\frac {v ^ {3} - 1 0 0 a}{1 0 0 v ^ {2}}\right) \tag {2}
$$

当 $\sqrt[3]{100a} < 120, 0 < a < 17280$ 时，当 $v = \sqrt[3]{100a}$ 时， $y' = 0$ ，

当 $0 < v < \sqrt[3]{100a}$ 时， $y' < 0$ ，y 单调递减，

当 $\sqrt[3]{100a} < v < 120$ 时， $y' > 0, y$ 单调递增，

所以当 $v = \sqrt[3]{100a}$ 时，y 最小；

当 $\sqrt[3]{100a}$ 120, $a$ 17280时， $y' \leq 0$ ， $y$ 单调递减，当 $v = 120$ 时， $y$ 最小；

综上：当 $0 < a < 17280$ 时，应该以 $\sqrt[3]{100a}$ 千米/小时行驶；

当 $a = 17280$ 时，应该以 $120$ 千米/小时行驶

## 方法技巧

函数的优化问题即实际问题中的最值问题，其一般解题步骤为：

一设，设出自变量、因变量；

二列，列出函数关系式，并写出定义域；

三解，解出函数的最值，一般常用导数求解；

四答，回答实际问题.
