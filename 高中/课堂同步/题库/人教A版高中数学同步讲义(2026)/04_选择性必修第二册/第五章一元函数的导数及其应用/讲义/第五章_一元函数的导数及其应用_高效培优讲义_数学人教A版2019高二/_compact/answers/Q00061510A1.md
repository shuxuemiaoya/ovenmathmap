> [!faq]- 《第五章_一元函数的导数及其应用_高效培优讲义_数学人教A版2019高二》官方解析
>
> > [!success]- **【答案】** (1)证明见解析 (2)① $\left[\frac{1}{2}, +\infty\right)$ ; ② $\left(-\infty, -\frac{1}{\mathrm{e}^3}\right)$
>
> > [!note]- **【分析】**
> > （1）根据函数对称性定义验证 $f(x) + f(-x) = 2$ 即可证明；
> >
> > (2) ①由题可得 $f'(x) = 0$ 恒成立，分离参数转化为最值问题解决；
> >
> > ②根据题意可得 $h(x) = f(x) - 1$ 为奇函数，且为增函数，可将问题转化为 $m < x\mathrm{e}^x + 2\mathrm{e}^x$ 对 $x \in [-4, 2]$ 恒成立，构
> >
> > 造函数 $p(x) = x\mathrm{e}^{x} + 2\mathrm{e}^{x} = (x + 2)\mathrm{e}^{x}$ ，利用导数求出最值即可求解
>
> > [!note]- **【解析】**
> > （1）因为 $f(x) + f(-x) = \frac{2}{\mathrm{e}^x + 1} + ax + \frac{2}{\mathrm{e}^{-x} + 1} - ax = \frac{2}{\mathrm{e}^x + 1} + \frac{2\mathrm{e}^x}{\mathrm{e}^x + 1} = \frac{2(\mathrm{e}^x + 1)}{\mathrm{e}^x + 1} = 2$ ，
> >
> > 所以曲线 $y = f(x)$ 关于点 $(0,1)$ 对称.
> >
> > (2) ①因为 $f(x)$ 为增函数，所以 $f'(x) = a - \frac{2\mathrm{e}^x}{(\mathrm{e}^x + 1)^2} \quad 0$ 对于 $x \in \mathbb{R}$ 恒成立，
> >
> > 即 $a \frac{2\mathrm{e}^x}{(\mathrm{e}^x + 1)^2}$ 对于 $x \in \mathbb{R}$ 恒成立，
> >
> > 因为 $\frac{2\mathrm{e}^x}{(\mathrm{e}^x + 1)^2} = \frac{2}{\mathrm{e}^x + \frac{1}{\mathrm{e}^x} + 2}\leq \frac{2}{2\sqrt{\mathrm{e}^x\cdot\frac{1}{\mathrm{e}^x}} + 2} = \frac{1}{2}$ 当且仅当 $x = 0$ 时等号成立，
> >
> > 则 $\frac{2\mathrm{e}^x}{\left(\mathrm{e}^x + 1\right)^2}$ 的最大值为 $\frac{1}{2}$ ，
> >
> > 所以 $a \quad \frac{1}{2}$ ，即 a 的取值范围是 $\left[\frac{1}{2}, +\infty\right)$ .
> > - **②**：由（1）知，曲线 $y = f(x)$ 关于点(0,1)对称，所以 $h(x) = f(x) - 1$ 为奇函数，
> >
> > 由 $f\left(-x\mathrm{e}^{x}\right) + f\left(m - 2\mathrm{e}^{x}\right) < 2$ ， $x \in [-4,2]$ ，得 $f\left(-x\mathrm{e}^{x}\right) - 1 + f\left(m - 2\mathrm{e}^{x}\right) - 1 < 0$
> >
> > 则 $h\left(-x\mathrm{e}^{x}\right) + h\left(m - 2\mathrm{e}^{x}\right) < 0$ ，即 $h\left(m - 2\mathrm{e}^{x}\right) < -h\left(-x\mathrm{e}^{x}\right) = h\left(x\mathrm{e}^{x}\right)$
> >
> > 因为 $f(x)$ 为增函数，所以 $h(x) = f(x) - 1$ 为增函数，则 $m - 2\mathrm{e}^x < x\mathrm{e}^x$
> >
> > 即 $m < x\mathrm{e}^{x} + 2\mathrm{e}^{x}$ 对 $x \in [-4, 2]$ 恒成立，
> >
> > 设函数 $p(x) = x\mathrm{e}^{x} + 2\mathrm{e}^{x} = (x + 2)\mathrm{e}^{x}$ ， $x \in [-4, 2]$ ，则 $p'(x) = (x + 3)\mathrm{e}^{x}$ ，
> >
> > <!-- source-part:2 pages:51-100 -->
> >
> > 当 $x \in [-4, -3)$ 时， $p'(x) < 0$ ，则 $p(x)$ 在 $[-4, -3)$ 上单调递减，
> >
> > 当 $x\in (-3,2]$ 时， $p'(x) > 0$ ，则 $p(x)$ 在 $(-3,2]$ 上单调递增，
> >
> > 故 $m < p(x)_{\min} = p(-3) = -\frac{1}{e^{3}}$
> >
> > 所以 $m$ 的取值范围为 $\left(-\infty, -\frac{1}{\mathrm{e}^3}\right)$ .
