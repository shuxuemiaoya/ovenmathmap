## 知识点 02 函数的最值

1.函数的最大值与最小值定理

若函数 $y = f(x)$ 在闭区间 $[a, b]$ 上连续，则 $f(x)$ 在 $[a, b]$ 上必有最大值和最小值；在开区间 $(a, b)$ 内连续的函数

$f(x)$ 不一定有最大值与最小值．如 $f(x) = \frac{1}{x} (x > 0)$

2. 求函数最值的的基本步骤：

若函数 $y = f(x)$ 在闭区间 $[a, b]$ 有定义，在开区间 $(a, b)$ 内有导数，则求函数 $y = f(x)$ 在 $[a, b]$ 上的最大值和最

小值的步骤如下：

(1) 求函数 $f(x)$ 在 $(a,b)$ 内的导数 $f'(x)$ ;

(2) 求方程 $f'(x)=0$ 在 $(a,b)$ 内的根；

(3) 求在 $(a, b)$ 内使 $f'(x) = 0$ 的所有点的函数值和 $f(x)$ 在闭区间端点处的函数值 $f(a)$ ， $f(b)$ ；

（4）比较上面所求的值，其中最大者为函数 $y = f(x)$ 在闭区间 $[a, b]$ 上的最大值，最小者为函数 $y = f(x)$ 在

闭区间 $[a,b]$ 上的最小值.

【即学即练】

1. 已知函数 $f(x) = \ln x + \frac{a}{x} - a$ .

(1)当 $a = \frac{1}{2}$ 时，求曲线 $y = f(x)$ 在点 $\left(1, f(1)\right)$ 处的切线方程；

(2)若函数 $f(x)$ 有极小值，且 $f(x)$ 的极小值小于 $1 - a^2$ ，求实数 $a$ 的取值范围。

【答案】(1) $x - 2y - 1 = 0$

(2) $(0,1)$

【分析】（1）根据题意计算 $f(1)$ 和 $f'(1)$ ，得切线方程为 $y - f(1) = f'(1)(x - 1)$ ；

(2) 先求导得 $f'(x) = \frac{x - a}{x^2}$ ，分 $a > 0$ 和 $a \leq 0$ 讨论，求出极小值 $f(x)_{\text{极小值}} = f(a) = \ln a + 1 - a$ ，再由

$\ln a + 1 - a < 1 - a^2$ 整理有 $a^2 + \ln a - a < 0$ ，构造新函数 $g(a) = a^2 + \ln a - a (a > 0)$ ，利用导数求解 $g(a) < 0$ 即可.

【详解】（1）当 $a = \frac{1}{2}$ 时， $f(x) = \ln x + \frac{1}{2x} - \frac{1}{2}$ ，则 $f'(x) = \frac{1}{x} - \frac{1}{2x^2}$ ，所以 $f'(1) = \frac{1}{2}$ ，

因为 $f(1) = 0$ ，所以 $f(x)$ 在 $x = 1$ 处的切线方程为 $x - 2y - 1 = 0$

(2) 因为 $f(x)=\ln x+\frac{a}{x}-a$ ，其中 x>0，

则 $f^{\prime}(x) = \frac{1}{x} -\frac{a}{x^{2}} = \frac{x - a}{x^{2}}$

①当 $a \leq 0$ 时， $f'(x) > 0$ 恒成立，此时函数 $f(x)$ 在 $(0, +\infty)$ 上单调递增，无极小值，

②当 $a > 0$ 时，令 $f^{\prime}(x) = 0$ ，可得 $x = a$ ，列表如下：

<table><tr><td>x</td><td>(0,a)</td><td>a</td><td>(a,+∞)</td></tr><tr><td>f&#x27;(x)</td><td>-</td><td>0</td><td>+</td></tr><tr><td>f(x)</td><td>递减</td><td>极小值</td><td>递增</td></tr></table>

所以 $f(x)_{\text{极小值}} = f(a) = \ln a + 1 - a$

由题意可得 $\ln a + 1 - a < 1 - a^2$ ，即 $a^2 +\ln a - a <   0$

令 $g(a) = a^2 + \ln a - a (a > 0)$ ，则 $g(1) = 0$

因为 $g'(a)=2a+\frac{1}{a}-1$ $2\sqrt{2}-1>0$ ，当 $2a=\frac{1}{a}\Rightarrow a=\frac{\sqrt{2}}{2}$ 等号成立，

所以函数 $g(a)$ 在 $(0, +\infty)$ 单调递增，

所以由 $g(a) < g(1) = 0$ ，得 0 < a < 1，

所以实数 $a$ 的取值范围是 $(0,1)$

2. 已知函数 $f(x) = \frac{3}{2} x^2 - 6ax + b\ln x + 2a^2 \quad (a, b \in R)$

(1)若 $f(x)$ 的图象在点 $(1, f(1))$ 处的切线方程为 $4x - 2y - 1 = 0$ ，求 $a$ 与 $b$ 的值；

(2)若 $f(x)$ 在 $x = 1$ 处有极值 $-\frac{5}{2}$ ，求 $a$ 与 $b$ 的值.

【答案】(1) $a = 0$ ， $b = -1$ 或 $a = 3$ ， $b = 17$

$a = 2, b = 9$ (2)

【分析】（1）由函数解析式求导，利用导数求得切线斜率，由函数解析式求得切点，根据切线方程，建立方

程组，可得答案；

（2）由函数解析式求导，根据极值与导数的关系，结合函数解析式，建立方程组，可得答案.

【详解】（1）因为 $f(x)=\frac{3}{2}x^{2}-6ax+b\ln x+2a^{2}$ ，所以 $f'(x)=3x-6a+\frac{b}{x}$

所以 $f(1)=\frac{3}{2}-6a+2a^{2}$ ， $f'(1)=3-6a+b$ ，

因为切线方程为 $4x - 2y - 1 = 0$

所以 $\left\{\begin{aligned}f(1)&=\frac{3}{2}-6a+2a^{2}=\frac{3}{2}\\ f'(1)&=3-6a+b=2\end{aligned}\right.$ ，解得 $\left\{\begin{aligned}a&=0\\ b&=-1\end{aligned}\right.$ 或 $\left\{\begin{aligned}a&=3\\ b&=17\end{aligned}\right.$

所以 a = 0, b = -1 或 a = 3, b = 17.

(2) $\therefore$ 函数 $f(x)$ 在 $x = 1$ 处有极值 $-\frac{5}{2}$

$\therefore f^{\prime}(1) = 3 - 6a + b = 0$ 且 $f(1) = \frac{3}{2} -6a + 2a^2 = -\frac{5}{2}$ 解得 $a = 1, b = 3$ 或 $a = 2, b = 9$ 当 $a = 1, b = 3$ 时， $f^{\prime}(x) = 3x - 6 + \frac{3}{x} = \frac{3(x - 1)^2}{x} = 0$ 恒成立，此时函数无极值点，当 $a = 2, b = 9$ 时 $f^{\prime}(x) = 3x - 12 + \frac{9}{x} = \frac{3(x - 1)(x - 3)}{x}$ ，此时1是极值点，满足题意，所以 $a = 2, b = 9$ 。
