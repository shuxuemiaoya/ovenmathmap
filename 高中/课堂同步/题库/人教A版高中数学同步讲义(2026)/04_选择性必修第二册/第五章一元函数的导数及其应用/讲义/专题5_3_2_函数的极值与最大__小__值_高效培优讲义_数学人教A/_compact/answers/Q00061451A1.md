> [!faq]- 《专题5_3_2_函数的极值与最大__小__值_高效培优讲义_数学人教A》官方解析
>
> > [!success]- **【答案】** (1)函数 $f(x)$ 在 $(-∞, a-1)$ 上单调递减，在 $(a-1, +∞)$ 单调递增 (2) $a \leq 2$ (3)证明见解析
>
> > [!note]- **【分析】**
> > （1）求导，判断导数正负得解；
> >
> > (2) 设 $g(x) = f(x) + x + a = (x - a)e^x + x + a$ ，求导得 $g'(x) = (x + 1 - a)e^x + 1$ ，令 $h(x) = g'(x)$ ，分 $a \leq 2$ 和
> >
> > $a > 2$ 讨论，验证 $g(x) = 0$
> >
> > (3) 由 (2)，当 $a = 2$ 时， $g(x) = (x - 2)e^x + x + 2 \quad 0$ ，令 $x = \frac{2}{k + 1} (k \in \mathbb{N}^*)$ ，可得
> >
> > $\left(\frac{2}{k + 1} -2\right)\mathrm{e}^{\frac{2}{k + 1}} + \frac{2}{k + 1} +2 > 0$ ，得 $\frac{2}{k + 1} <  \ln \frac{k + 2}{k}\big(k\in \mathbf{N}^{*}\big)$ ，求和得证.
>
> > [!note]- **【解析】**
> > （1）由 $f'(x)=(x+1-a)e^{x}$
> >
> > 令 $f^{\prime}(x) < 0$ ，得 $x\in (-\infty ,a - 1)$
> >
> > 令 $f'(x)>0$ ，得 $x\in(a-1,+\infty)$
> >
> > 所以 $f(x)$ 在 $(-∞, a-1)$ 上单调递减，在 $(a-1, +∞)$ 单调递增.
> >
> > (2) 设 $g(x)=f(x)+x+a=(x-a)\mathrm{e}^{x}+x+a,\quad g(0)=0$
> >
> > 则 $g'(x)=(x+1-a)e^{x}+1$ ， $g'(0)=2-a$ ，令 $h(x)=g'(x)$ ，
> > - **①**：当 $2 - a$ 0即 $a\leq 2$ 时，令 $h^{\prime}(x) = (x + 2 - a)\mathrm{e}^{x}$ 0，故 $g^{\prime}(x)$ 在 $(0, + \infty)$ 上单调递增，
> >
> > 故 $g^{\prime}(x)\quad g^{\prime}(0) = 2 - a\quad 0$ ，所以 $g(x)$ 在 $(0, + \infty)$ 上单调递增，故 $g(x)\quad g(0) = 0$ ，符合题意；
> > - **②**：当 $2 - a < 0$ 即 $a > 2$ 时，当 $x \in (0, a - 2)$ 时， $h'(x) < 0$ ，即 $g'(x)$ 单调递减，
> >
> > 故 $g^{\prime}(x) < g^{\prime}(0) < 0$ ， $g(x)$ 单调递减，故 $g(x) < g(0) = 0$ ，不符合题意；
> >
> > 综上， $a \leq 2$ .
> >
> > (3) 由 (2)，当 $a = 2$ 时， $g(x) = (x - 2)e^x + x + 2 \quad 0$ ，当且仅当 $x = 0$ 时，等号成立，
> >
> > 令 $x = \frac{2}{k + 1}\left(k\in \mathbf{N}^{*}\right)$ ，则 $\left(\frac{2}{k + 1} -2\right)\mathrm{e}^{\frac{2}{k + 1}} + \frac{2}{k + 1} +2 > 0$
> >
> > 整理得 $\frac{2}{k+1}<\ln\frac{k+2}{k}\left(k\in\mathbb{N}^{*}\right)$ ，
> >
> > 所以 $\sum_{k=1}^{n}\frac{2}{k+1}<\sum_{k=1}^{n}\ln\frac{k+2}{k}=\ln\frac{3}{1}+\ln\frac{4}{2}+\ln\frac{5}{3}+\cdots+\ln\frac{n+2}{n}$
> >
> > $$
> > \text { 即 } \frac {1 + \frac {2}{3} + \cdots + \frac {2}{n + 1}}{2} <   \ln \left(\frac {n ^ {2} + 3 n + 2}{2}\right).
> > $$
