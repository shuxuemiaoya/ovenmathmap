> [!faq]- 《专题5_3_2_函数的极值与最大__小__值_高效培优讲义_数学人教A》官方解析
>
> > [!success]- **【答案】** BCD
>
> > [!note]- **【分析】**
> > 对于 A，根据函数式，通过计算得 $f(-4-x)=f(x)$ 可判断 B 正确；
> >
> > 对于 B，利用导数得函数的单调性结合函数的对称性求得 $f(x)_{\min} = \frac{e^{2}}{4} > 1$ 可判断 A 不正确；
> >
> > 对于 C，先求得 $f(x-2)=\frac{\mathrm{e}^{|x|}}{x^{2}}=\left\{\begin{aligned}&\frac{\mathrm{e}^{x}}{x^{2}},x>0\\&\frac{\mathrm{e}^{-x}}{x^{2}},x<0\end{aligned}\right.$ ，再求导，得 $f^{\prime}(x-2)=\left\{\begin{aligned}&-\mathrm{e}^{-x}(x+2),x<0\\&\frac{\mathrm{e}^{x}(x-2)}{x^{3}},x>0\end{aligned}\right.$ ，经验证得到
> >
> > $f^{\prime}(-x-2)=-f^{\prime}(x-2)$ ，可判断 C 正确；
> >
> > 对于 D，令 $t = f(x)$ ，由 $f(x)_{\min} = \frac{e^{2}}{4}$ ，确定 $f(t) = e^{2}$ ， $t \in \left[\frac{e^{2}}{4}, +\infty\right)$ 方程的只有一个根 $t_{0}$ ，且由 $f(x)$ 在
> >
> > $(0, +\infty)$ 上的单调性得， $t_0 > 2$ ，再由方程 $f(x) = t_0 > \frac{\mathrm{e}^2}{4}$ 有4个不相等的实数根得到方程 $f(f(x)) = \mathrm{e}^2$ 有4个不
> >
> > 相等的实数根，判断 D 正确.
>
> > [!note]- **【解析】**
> > 对于 B，由 $f(-4-x)=\frac{\mathrm{e}^{|-4-x+2|}}{(-4-x+2)^{2}}=\frac{\mathrm{e}^{|-2-x|}}{(-2-x)^{2}}=\frac{\mathrm{e}^{|2+x|}}{(2+x)^{2}}=f(x)$ 得， $f(-4-x)-f(x)=0$ ，故 B 正
> >
> > 确；
> >
> > 对于 A， $f(x)=\frac{\mathrm{e}^{|x+2|}}{(x+2)^{2}}$ ，定义域为 $\left\{x\mid x\neq-2\right\}$ .
> >
> > 当 $x > -2$ 时， $f(x) = \frac{\mathrm{e}^{x + 2}}{(x + 2)^2}$ ， $f'(x) = \frac{x\mathrm{e}^{x + 2}}{(x + 2)^3}$ ，
> >
> > 令 $f'(x)>0$ ，得 x>0 ；令 $f'(x)<0$ ，得 -2<x<0 ；
> >
> > 所以 $f(x)$ 在 $(-2,0)$ 上单调递减，在 $(0,+\infty)$ 上单调递增.
> >
> > 由 B 知 $f(-4-x)=f(x)$ ， $f(x)=\frac{\mathrm{e}^{|x+2|}}{(x+2)^{2}}$ 的图象关于 x=-2 对称，
> >
> > 所以 $f(x)$ 在 $(-4,-2)$ 上单调递增，在 $(-∞,-4)$ 上单调递减.
> >
> > $f(x)_{\min}=f(0)=f(-4)=\frac{e^{2}}{4}$ . 故 A 不正确；
> >
> > 对于 C， $f(x-2)=\frac{\mathrm{e}^{|x|}}{x^{2}}=\left\{\begin{aligned}&\frac{\mathrm{e}^{x}}{x^{2}},x>0\\&\frac{\mathrm{e}^{-x}}{x^{2}},x<0\end{aligned}\right.$
> >
> > 当 x > 0 时， $f(x - 2) = \frac{\mathrm{e}^{x}}{x^{2}}, f'(x - 2) = \frac{(x - 2)\mathrm{e}^{x}}{x^{3}}$
> >
> > 当 x < 0 时， $f(x - 2) = \frac{\mathrm{e}^{-x}}{x^{2}}$ ， $f'(x - 2) = \frac{-\mathrm{e}^{-x}(x + 2)}{x^{3}}$
> >
> > 所以， $f^{\prime}(x - 2) = \left\{ \begin{array}{l} \frac{-\mathrm{e}^{-x}(x + 2)}{x^{3}}, x < 0 \\ \frac{\mathrm{e}^{x}(x - 2)}{x^{3}}, x > 0 \end{array} \right.$
> >
> > 当 $x > 0$ 时， $-x < 0$ ， $f'(-x - 2) = \frac{-\mathrm{e}^{-(x)}(-x + 2)}{(-x)^3} = \frac{-\mathrm{e}^x(x - 2)}{-x^3} = -\frac{\mathrm{e}^x(x - 2)}{x^3} = -f'(x - 2)$ ;
> >
> > 当 $x < 0$ 时， $-x > 0$ ， $f'(-x - 2) = \frac{(-x - 2)e^{-x}}{(-x)^3} = \frac{-(x + 2)e^{-x}}{-x^3} = \frac{(x + 2)e^{-x}}{x^3} = -f'(x - 2)$
> >
> > 所以 $f^{\prime}(x - 2)$ 是奇函数，图象关于原点对称·故C正确；
> >
> > 对于D，由A知， $f(x)$ 的图象关于 $x = -2$ 对称，
> >
> > $f(x)$ 在 $(- \infty, -4)$ 上单调递减，在 $(-4, -2)$ 上单调递增，在 $(-2, 0)$ 上单调递减，在 $(0, +\infty)$ 上单调递增，且
> >
> > $$
> > f (x) _ {\min} = f (0) = f (- 4) = \frac {\mathrm{e} ^ {2}}{4}
> > $$
> >
> > 令 $t = f(x)$ ，则 $t\in \left[\frac{\mathrm{e}^2}{4}, + \infty\right)$ ，由 $f(f(x)) = \mathrm{e}^2$ ，得 $f(t) = \mathrm{e}^2$ ， $t\in \left[\frac{\mathrm{e}^2}{4}, + \infty\right)$
> >
> > 根据 $f(x)$ 的对称性和单调性知，方程 $f(t) = \mathrm{e}^2$ ， $t \in \left[\frac{\mathrm{e}^2}{4}, +\infty\right)$ 只有一个实数根且 $t_0$
> >
> > 由 $f(x)$ 在 $(0, +\infty)$ 上单调递增， $f(2) = \frac{\mathrm{e}^4}{16} < \mathrm{e}^2 = f(t_0)$ ，所以 $t_0 > 2$
> >
> > 而方程 $f(x)=t_{0}>\frac{\mathrm{e}^{2}}{4}$ 有 4 个不相等的实数根.
> >
> > 所以方程 $f(f(x)) = \mathrm{e}^2$ 有4个不相等的实数根.故D正确
> >
> > 故选 **BCD**.
