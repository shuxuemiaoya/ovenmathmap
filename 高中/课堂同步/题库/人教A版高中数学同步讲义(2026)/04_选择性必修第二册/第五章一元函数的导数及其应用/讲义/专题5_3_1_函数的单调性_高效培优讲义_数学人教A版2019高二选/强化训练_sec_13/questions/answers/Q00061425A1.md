> [!faq]- 《专题5_3_1_函数的单调性_高效培优讲义_数学人教A版2019高二选》官方解析
>
> > [!success]- **【答案】** $^{(1)}$ 分类讨论，答案见解析· (2) $\left[\frac{25}{8}, +\infty\right)$
>
> > [!note]- **【分析】**
> > （1）先确定函数的定义域，接着对函数进行求导，令 $f'(x) = 0$ ，得到临界点 $x = 2$ 和 $x = a$ ，最后根
> >
> > 据 $a$ 与0、2的大小关系，分 $a \leq 0, 0 < a \left\langle 2, a = 2, a \right\rangle 2$ 四种情况讨论 $f'(x)$ 在不同区间的符号，从而确定 $f(x)$ 的
> >
> > 单调性·
> >
> > (2) 根据 $\frac{f(x_2) - f(x_1)}{x_2 - x_1} > 3 - a$ ，构造函数 $g(x) = f(x) + (a - 3)x$ ，由条件得出 $g(x)$ 在 $(0, +\infty)$ 上单调递增，
> >
> > 所以 $g'(x)$ 在 $(0,+\infty)$ 上恒成立，变形得到 2a x(5-x) 在 $(0,+\infty)$ 上恒成立，最后求 $h(x)=-x^{2}+5x$ 的最大
> >
> > 值即可得到 $a$ 的取值范围.
>
> > [!note]- **【解析】**
> > （1） $f(x)$ 的定义域为 $(0, +\infty)$ ， $f'(x) = \frac{2a}{x} + x - (a + 2) = \frac{(x - a)(x - 2)}{x}$
> >
> > 若 $f'(x)=0$ ，则 $(x-a)(x-2)=0$
> > - **①**：若 $a \leq 0$ ，当 $x > 2$ 时， $f'(x) > 0$ ；当 $0 < x < 2$ 时， $f'(x) < 0$
> >
> > 所以 $f(x)$ 在 $(0,2)$ 上单调递减，在 $(2,+\infty)$ 上单调递增；
> > - **②**：若 $0 < a < 2$ ，当 $x > 2$ 或 $0 < x < a$ 时， $f'(x) > 0$ ；当 $a < x < 2$ 时， $f'(x) < 0$
> >
> > 所以 $f(x)$ 在 $(0,a)$ 上单调递增，在 $(a,2)$ 上单调递减，在 $(2,+\infty)$ 上单调递增；
> > - **③**：若 $a = 2, f'(x) = \frac{(x - 2)^2}{x} = 0$ ，当且仅当 $x = 2$ 时取等号，此时 $f(x)$ 在 $(0, +\infty)$ 上单调递增；
> > - **④**：若 a > 2 ，当 x > a 或 0 < x < 2 时， $f'(x) > 0$ ；当 2 < x < a 时， $f'(x) < 0$
> >
> > 所以 $f(x)$ 在 $(0,2)$ 上单调递增，在 $(2,a)$ 上单调递减，在 $(a, +\infty)$ 上单调递增.
> >
> > 综上所述，当 $a \leq 0$ 时， $f(x)$ 在 $(0, 2)$ 上单调递减，在 $(2, +\infty)$ 上单调递增；
> >
> > 当 $0 < a < 2$ 时， $f(x)$ 在 $(0, a)$ 上单调递增，在 $(a, 2)$ 上单调递减，在 $(2, +\infty)$ 上单调递增；
> >
> > 当 $a = 2$ 时， $f(x)$ 在 $(0, +\infty)$ 上单调递增；
> >
> > 当 $a > 2$ 时， $f(x)$ 在 $(0, 2)$ 上单调递增，在 $(2, a)$ 上单调递减，在 $(a, +\infty)$ 上单调递增.
> >
> > (2) 不妨设 $x_{1} < x_{2}$ ，则 $\frac{f(x_2) - f(x_1)}{x_2 - x_1} > 3 - a \Leftrightarrow f(x_2) - f(x_1) > (3 - a)(x_2 - x_1)$
> >
> > $$
> > \Leftrightarrow f \left(x _ {2}\right) + (a - 3) x _ {2} > f \left(x _ {1}\right) + (a - 3) x _ {1}
> > $$
> >
> > 设 $g(x) = f(x) + (a - 3)x = 2a\ln x + \frac{1}{2} x^2 -5x$ ，则 $g(x_{2}) > g(x_{1})$
> >
> > 所以 $g(x)$ 在 $(0, +\infty)$ 上单调递增，所以 $g'(x) = \frac{2a}{x} + x - 5 \quad 0$ 对 $\forall x \in (0, +\infty)$ 恒成立，
> >
> > 所以 $2a \quad x(5-x)$ 对 $\forall x\in(0,+\infty)$ 恒成立，
> >
> > 又 $x(5 - x) = -x^2 + 5x = -\left(x - \frac{5}{2}\right)^2 + \frac{25}{4}$ ，所以当 $x = \frac{5}{2}$ 时， $x(5 - x)$ 取最大值 $\frac{25}{4}$ ，
> >
> > 所以 $2a \frac{25}{4}$ ，解得 $a \frac{25}{8}$ ，即 $a$ 的取值范围为 $\left[\frac{25}{8}, +\infty\right)$
