> [!faq]- 《第五章+一元函数的导数及其应用（高效培优单元测试·提升卷）数学人教A版2019高二选择性必修第二册》官方解析
>
> > [!success]- **【答案】** -1
>
> > [!note]- **【解析】**
> > 由 $f(x) = x^3 + 2ax^2 + a^2x + 1$ ，得 $f'(x) = 3x^2 + 4ax + a^2$
> >
> > 函数 $f(x) = x^{3} + 2ax^{2} + a^{2}x + 1$ 在 $x = 1$ 处有极小值，所以 $f^{\prime}(1) = 3 + 4a + a^{2} = 0$
> >
> > 解得 a = -1 或 a = -3 ，
> >
> > 当 a = -1 时， $f'(x) = 3x^{2} - 4x + 1 = (3x - 1)(x - 1)$ ，
> >
> > 当 $\frac{1}{3} < x < 1$ 时， $f'(x) < 0$ ，所以 $f(x)$ 在 $\left(\frac{1}{3}, 1\right)$ 上单调递减，
> >
> > 当 $x > 1$ 时， $f'(x) > 0$ ，所以 $f(x)$ 在 $(1, +\infty)$ 上单调递增，
> >
> > 所以 $f(1)$ 是 $f(x)$ 的极小值，符合题意.
> >
> > 当 $a = -3$ 时， $f'(x) = 3(x^2 - 4x + 3) = 3(x - 1)(x - 3)$
> >
> > 当 $x < 1$ 时， $f'(x) > 0$ ，所以 $f(x)$ 在 $(- \infty, 1)$ 上单调递增，
> >
> > 当 $1 < x < 3$ 时， $f'(x) < 0$ ，所以 $f(x)$ 在 $(1,3)$ 上单调递减，
> >
> > 所以 $f(1)$ 是 $f(x)$ 的极大值，不符合题意.
> >
> > 综上所述，实数 a 的值为 -1.
> >
> > 故答案为：-1·
