> [!faq]- 《专题5.3.1+函数的单调性（高效培优讲义）数学人教A版2019高二选择性必修第二册》官方解析
>
> > [!success]- **【答案】** A. 存在 $a, b$ 使得 $f(x)$ 为奇函数 B．存在 a，b 使得 $f(x)$ 为偶函数 C. 当 $a = 2, b = 1$ 时， $f(x)$ 在 $x \in \left[-1, -\frac{1}{3}\right]$ 上单调递减 D．过曲线 $y = f(x)$ 上一点 $P_{1}(x_{1}, y_{1})$ 作曲线的切线与 $y = f(x)$ 交于 $P_{2}(x_{2}, y_{2})$ ，必有 $x_{2} + 2x_{1} = 1$
>
> > [!note]- **【分析】**
> > 通过奇偶性定义推导 $^{A}$ 、 $^{B}$ 的成立条件，利用导数及二次函数性质分析 $^{C}$ 的单调性，取特殊值验证 $^{D}$
> >
> > 的结论·
>
> > [!note]- **【解析】**
> > 选项A，若 $f(x)$ 为奇函数，则对任意 $x$ ，有 $f(-x) = -f(x)$
> >
> > 代入 $f(x) = x^3 + ax^2 + b\sin x$ ，得 $(-x)^3 + a(-x)^2 + b\sin (-x) = -\left(x^3 + ax^2 + b\sin x\right)$
> >
> > 化简为 $-x^{3} + ax^{2} - b\sin x = -x^{3} - ax^{2} - b\sin x$ ，两边消去 $-x^{3} - b\sin x$
> >
> > 得 $ax^{2}=-ax^{2}$ ，即 $2ax^{2}=0$ 。
> >
> > 该式对任意 $x$ 成立，仅当 $a = 0$ ， $b$ 可为任意实数，故存在 $a, b$ 使 $f(x)$ 为奇函数， $\mathsf{A}$ 正确。
> >
> > 选项 B，若 $f(x)$ 为偶函数，则对任意 x，有 $f(-x)=f(x)$
> >
> > 代入得 $(-x)^{3} + a(-x)^{2} + b\sin (-x) = x^{3} + ax^{2} + b\sin x$
> >
> > 化简为 $-x^{3} + ax^{2} - b\sin x = x^{3} + ax^{2} + b\sin x$ ，两边消去 $ax^{2}$ ，
> >
> > 得 $-x^{3} - b\sin x = x^{3} + b\sin x$ ，即 $2x^{3} + 2b\sin x = 0$ ，此方程不恒成立，B错误
> >
> > 选项 C，当 a=2，b=1 时， $f(x)=x^{3}+2x^{2}+\sin x$ ， $f'(x)=3x^{2}+4x+\cos x$ .
> >
> > 令 $g(x) = 3x^{2} + 4x$ ，其对称轴为 $x = -\frac{2}{3}$ ，在区间 $\left[-1, -\frac{1}{3}\right]$ 内， $g(-1) = 3 - 4 = -1$
> >
> > $$
> > g \left(- \frac {2}{3}\right) = 3 \times \frac {4}{9} + 4 \times \left(- \frac {2}{3}\right) = \frac {4}{3} - \frac {8}{3} = - \frac {4}{3}, g \left(- \frac {1}{3}\right) = 3 \times \frac {1}{9} + 4 \times \left(- \frac {1}{3}\right) = \frac {1}{3} - \frac {4}{3} = - 1
> > $$
> >
> > 故 $g(x)\in \left[-\frac{4}{3}, - 1\right]$ ，又 $x\in \left[-1, - \frac{1}{3}\right]$ 时， $\cos x\leq \frac{1}{3} <  1$
> >
> > 因此 $f^{\prime}(x) = g(x) + \cos x < -1 + 1 = 0$ 恒成立， $f(x)$ 在该区间单调递减，C正确.
> >
> > 选项 D，取 a = 0，b = 0，则 $f(x) = x^{3}$ ， $f'(x) = 3x^{2}$ ，设 $x_{1} = 1$ ，
> >
> > 在点 $P_{1}(1,1)$ 处， $f^{\prime}(1) = 3 \times 1^{2} = 3$
> >
> > 切线方程为 $y-1=3(x-1)$ ，即 y=3x-2。
> >
> > 联立切线与 $f(x)$ 方程，由 $\left\{\begin{aligned}y&=3x-2\\ y&=x^{3}\end{aligned}\right.$ 消去y得 $x^{3}=3x-2$ ，即 $x^{3}-3x+2=0$ ，
> >
> > 因式分解为 $(x - 1)^2 (x + 2) = 0$ ，解得 $x = 1$ （与 $x_{1}$ 相同）或 $x = -2$ ，故 $x_{2} = -2$
> >
> > 此时 $x_{2} + 2x_{1} = -2 + 2 \times 1 = 0 \neq 1$ ，故D错误.
> >
> > 故选 **AC**
