> [!faq]- 《专题5.2+导数的运算（高效培优讲义）数学人教A版2019高二选择性必修第二册》官方解析
>
> > [!success]- **【答案】** C
>
> > [!note]- **【分析】**
> > 根据给定条件，利用偶函数的定义及复合函数求导得出轴对称和中心对称，进而求出周期求解判断
> >
> > 各选项·
>
> > [!note]- **【解析】**
> > 对于 $\mathsf{A}$ ，由函数 $f(x)$ 的定义域为 $\mathbf{R}$ ，函数 $f(2x + 2)$ 为偶函数，得 $f(2x + 2) = f(-2x + 2)$
> >
> > 即 $f(x + 2) = f(-x + 2)$ ，因此函数 $f(x)$ 的图象关于 $x = 2$ 轴对称，A 正确；
> >
> > 对于 B，由函数 $g(x-1)$ 为偶函数，得 $g(-x-1)=g(x-1)$ ，由 $g(x)$ 是函数 $f(x)$ 的导函数，
> >
> > 得 $f^{\prime}(-x - 1) - f^{\prime}(x - 1) = 0$ 即 $[f(-x - 1) + f(x - 1)]' = 0$ 则 $f(-x - 1) + f(x - 1) = 2C$
> >
> > $C = f(-1)$ ，因此函数 $f(x)$ 的图象关于 $(-1, C)$ ，即 $(-1, f(-1))$ 中心对称， $^{B}$ 正确；
> >
> > 对于 C，由选项 A 得 $f(x+4)=f(-x)$ ，由选项 B 得 $f(x-2)+f(-x)=2C$ ，
> >
> > 则 $f(x + 4) = -f(x - 2) + 2C$ ，即 $f(x + 6) = -f(x) + 2C$ ，因此 $f(x + 12) = -f(x + 6) + 2C$
> >
> > $= -[ - f(x) + 2C ] + 2C = f ( x )$ ，即函数 $f(x)$ 是周期为 $^{12}$ 的周期函数，又 $f^{\prime}(x + 12) = f^{\prime}(x)$
> >
> > 即 $g(x + 12) = g(x)$ ，函数 $g(x)$ 是周期为 $^{12}$ 的周期函数，则 $f(16) = f(4) = f(0)$
> >
> > 又 $f(-2) + f(0) = 2f(-1) = 2f(5) = -2$ ，于是 $f(0) = -2 - f(-2) = -2 - 1 = -3$
> >
> > 由 $f(x + 2) = f(-x + 2)$ 得 $g(x + 2) = -g(-x + 2)$ 则 $\pmb {g}(2) = 0$ ， $g(26) = g(2) = 0$
> >
> > 因此 $g(26)+f(16)=g(2)+f(0)=-3$ ，C 错误；
> >
> > 对于 D，当 $14 \leq x \leq 17$ 时， $-1 \leq 16 - x \leq 2$ ， $f(x) = f(x - 12) = f[4 - (x - 12)]$ $= f(16 - x) = e^{17 - x} - 1$ ，D 正确.
> >
> > 故选 **C**
