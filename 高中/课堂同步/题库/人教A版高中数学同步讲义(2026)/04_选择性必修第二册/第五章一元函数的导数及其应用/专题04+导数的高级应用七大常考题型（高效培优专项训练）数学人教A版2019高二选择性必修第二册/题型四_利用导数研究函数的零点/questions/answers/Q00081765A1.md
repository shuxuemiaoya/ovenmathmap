> [!faq]- 《专题04+导数的高级应用七大常考题型（高效培优专项训练）数学人教A版2019高二选择性必修第二册》官方解析
>
> > [!success]- **【答案】** B
>
> > [!note]- **【分析】**
> > 利用导数研究 $f(x)$ 的单调性，由此列不等式组求得k的取值范围·
>
> > [!note]- **【解析】**
> > 函数 $f(x) = x\ln x - x + k$ 的定义域是 $(0, + \infty)$
> >
> > $f^{\prime}(x) = \ln x$
> >
> > 当 $0 < x < 1$ 时， $f'(x) < 0$ ，当 $x > 1$ 时， $f'(x) > 0$
> >
> > 所以 $f(x)$ 在区间 $(0,1)$ 上单调递减，在区间 $(1,+\infty)$ 上单调递增，
> >
> > 因为 $x \to 0, f(x) \to k, x \to +\infty, f(x) \to +\infty$ ，且 $f(1) = k - 1$
> >
> > 所以要使函数 $f(x) = x \ln x - x + k$ 存在两个不同的零点，
> >
> > 则需 $\left\{ \begin{array}{l} k > 0 \\ k - 1 < 0 \end{array} \right.$ ，解得 $0 < k < 1$
> >
> > 故选 **B**
