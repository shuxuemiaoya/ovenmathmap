> > 40. 函数 $f(x) = \log_2(2^x + 1) + \log_2(2^{-x} + 1)$ 的大致图像为（）
> >
> > 【答案】
> >
> > D
> > ![](../../../images/questions/4c14515bf49dd36fc292f7b524ca032687cfcd5aefccfb0937fe1fffcf99e9ec.jpg)
> >
> > ![](../../../images/questions/830498530344745f8611d377bef295441d34c53766bac9030aa46757b7e3a7d9.jpg)
> >
> > C
> > ![](../../../images/questions/fa339a338ca7180e10e74cc702033e4a3a3d74597d4d983e5db57d88c431d94a.jpg)
> >
> > ![](../../../images/questions/cae94554cbe3f582fcb068f7164ee1cce198ddb723a457dc9fa2b4d6d0c8374f.jpg)
> >
> > 【答案】B
> >
> > 【分析】结合函数的奇偶性以及导数求得正确答案·
> >
> > 【详解】 $f(x)$ 的定义域为 R， $f(-x)=\log_{2}(2^{-x}+1)+\log_{2}(2^{x}+1)=f(x)$ ， $f(x)$ 为偶函数· $f'(x)=\frac{2^x}{2^x+1}-\frac{2^{-x}}{2^{-x}+1}=\frac{2^x}{2^x+1}-\frac{1}{2^x+1}=1-\frac{2}{2^x+1}$
> >
> > 当 $x > 0$ 时 $2^{x} + 1 > 2,0 <   \frac{1}{2^{x} + 1} <  \frac{1}{2}, - 1 <   \frac{-2}{2^{x} + 1} <  0,0 <   1 - \frac{2}{2^{x} + 1} <  1$
> >
> > 即 $f^{\prime}(x)\in (0,1)$ ，且 $f^{\prime}(x) = 1 - \frac{2}{2^{x} + 1}$ 在 $(0, + \infty)$ 上递增，
> >
> > 也即 $f(x)$ 在区间 $(0,+\infty)$ ，导数为正数且越来越大， $f'(x)$ 增加越来越快，但 $f'(x)<1$ ，
> > 所以 ACD 选项错误，B 选项正确·
> >
> > 故选：B

> > 41. 函数 $y = \frac{\mathrm{e}^x(x - 2)}{x - 1}$ 的图象大致是（）

> >
> > A
> > ![](../../../images/questions/3d27a12f480ce8b30d284b6fc7b442c8db5b7fa5761cc53861f3ab4e8c39a836.jpg)
> >
> > B
> > ![](../../../images/questions/3c903556eb57dc42b275e450c5a563671ffcddffb58b0d7cb89c7723f7aa99ec.jpg)
> >
> > C
> > ![](../../../images/questions/ba5a6231af9e43aa95c4c3731aaf31ce795d25b4eab45ed9549070592e009db8.jpg)

> > ![](../../../images/questions/7b3e3627bbab7f12f5247c6234ed8983cdd7a87176fc4d318bd112e97d2bf08e.jpg)
> >
> > 【答案】C
> >
> > 【分析】根据函数符号，单调性即可判断·
> >
> > 【详解】对于 $f(x) = \frac{\mathrm{e}^x(x - 2)}{x - 1}$ ，当 $x < 0$ 时， $f(x) > 0$ ，故B错误；
> >
> > $f^{\prime}(x) = \frac{x^{2} - 3x + 3}{(x - 1)^{2}}\mathrm{e}^{x} = \frac{\left(x - \frac{3}{2}\right)^{2} + \frac{3}{4}}{(x - 1)^{2}}\mathrm{e}^{x}$ ，显然在定义域内 $f^{\prime}(x) > 0$
> >
> > 即在 $(-∞,1)$ 和 $(1,+∞)$ 都是增函数，C 正确，AD 错误；
> >
> > 故选：C.
