> [!faq]- 《专题04+导数的高级应用七大常考题型（高效培优专项训练）数学人教A版2019高二选择性必修第二册》官方解析
>
> > [!success]- **【答案】** (1) $a = -1, b = -1$ (2) $\left(-1,\frac{5}{27}\right)$
>
> > [!note]- **【分析】**
> > （1）求导，利用 $f^{\prime}\left(-\frac{1}{3}\right)=0$ 、 $f^{\prime}(1)=0$ 求出a，b的值，再进行检验；
> > (2) 结合函数的单调性和极值情况，只需满足 $f\left(-\frac{1}{3}\right)>0, f(1)<0$ ，解之即得
>
> > [!note]- **【解析】**
> > （1）由题意得 $f'(x)=3x^{2}+2ax+b$
> >
> > 由函数 在 $x = -\frac{1}{3}$ 及 处取得极值，得 $\left\{ \begin{array}{l} f' \left( -\frac{1}{3} \right) = \frac{1}{3} - \frac{2a}{3} + b = 0, \\ f'(1) = 3 + 2a + b = 0, \end{array} \right.$
> >
> > 解得 $\left\{\begin{aligned}a&=-1\\ b&=-1\end{aligned}\right.$ ，此时 $f(x)=x^{3}-x^{2}-x-c$ ， $f'(x)=3x^{2}-2x-1$ ，
> >
> > 则 $f'(x) > 0$ 得 $x < -\frac{1}{3}$ 或 $x > 1$ ; $f'(x) < 0$ 得 $-\frac{1}{3} < x < 1$ ,
> >
> > 则 $f(x)$ 在 $\left(-\infty, -\frac{1}{3}\right)$ 和 $(1, +\infty)$ 上单调递增，在 $\left(-\frac{1}{3}, 1\right)$ 上单调递减，
> >
> > 则 $x = -\frac{1}{3}$ 和 $x = 1$ 分别为 $f(x)$ 的极大值点和极小值点
> >
> > 故 $a = -1, b = -1$ .
> >
> > (2) 由 (1) 可知， $f(x)$ 在 $x = -\frac{1}{3}$ 处取得极大值，在 $x = 1$ 处取得极小值.
> >
> > 又 有三个不同的实根，所以 $\left\{ \begin{array}{l} f\left(-\frac{1}{3}\right) = -\frac{1}{27} - \frac{1}{9} + \frac{1}{3} - c > 0, \\ f(1) = -1 - c < 0, \end{array} \right.$
> >
> > 解得 $-1 < c < \frac{5}{27}$ ，所以实数 $c$ 的取值范围是 $\left(-1, \frac{5}{27}\right)$
