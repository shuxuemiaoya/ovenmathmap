> [!faq]- 《专题03+利用导数研究函数最值五大常考题型（高效培优专项训练）数学人教A版2019高二选择性必修第二册》官方解析
>
> > [!success]- **【答案】** B
>
> > [!note]- **【分析】**
> > 根据极值点的定义得到 $a = 4$ ，然后用导数研究原函数的单调性判断即可.
>
> > [!note]- **【解析】**
> > 由 $f(x)=(x-1)^{2}(x-a)$ ，所以 $f'(x)=(x-1)(3x-2a-1)$ ，
> >
> > 由题可知： $f'(3)=(3-1)(3\times3-2a-1)=0\Rightarrow a=4$
> >
> > 当 a=4 时， $f'(x)=(x-1)(3x-9)$
> >
> > 令 $f'(x) < 0$ ，则 1 < x < 3；令 $f'(x) > 0$ ，则 x < 1 或 x > 3。
> >
> > 所以函数 $f(x)$ 在 $(-∞,1),(3,+∞)$ 单调递增，在 $(1,3)$ 单调递减.
> >
> > 对A，所以 $f(x)$ 在 $x = 3$ 处取得极小值， $a = 4$ ，错误；
> >
> > 对 B， $f(1)=0, f(3)=-4$ ，所以 $-4<f(x)<0$ ，正确；
> >
> > 对 C，当 0 < x < 1 时， $0 < x^{2} < x < 1$ ，所以 $f(x) > f(x^{2})$ 错误；
> >
> > 对 D，x=1 是函数 $f(x)$ 的极大值点，错误；
> >
> > 故选 **B**
