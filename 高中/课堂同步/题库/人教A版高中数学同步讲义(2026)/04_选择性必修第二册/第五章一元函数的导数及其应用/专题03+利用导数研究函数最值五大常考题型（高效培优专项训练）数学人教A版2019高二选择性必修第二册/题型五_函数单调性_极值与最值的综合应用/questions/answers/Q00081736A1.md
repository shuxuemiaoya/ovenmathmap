> [!faq]- 《专题03+利用导数研究函数最值五大常考题型（高效培优专项训练）数学人教A版2019高二选择性必修第二册》官方解析
>
> > [!success]- **【答案】** A
>
> > [!note]- **【分析】**
> > 原题等价于函数 $y = a + 2 \ln x$ 的图象与函数 $y = x^{2} + 2$ 的图象有交点，即方程 $a + 2 \ln x = x^{2} + 2$ 有解，即 $a = x^{2} + 2 - 2 \ln x$ 有解，令 $f(x) = x^{2} + 2 - 2 \ln x$ ，利用导数法求出函数的值域，即可求得答案
>
> > [!note]- **【解析】**
> > 函数 $y = -x^{2} - 2$ 的图象与函数 $y = x^{2} + 2$ 的图象关于原点对称，
> >
> > 若函数 $y = a + 2 \ln x \left( x \in \left[ \frac{1}{\mathrm{e}}, \mathrm{e} \right] \right)$ 的图象上存在点 P，
> >
> > 函数 $y = -x^{2} - 2$ 的图象上存在点 Q，且 P, Q 关于原点对称，
> >
> > 则函数 $y = a + 2 \ln x \left( x \in \left[ \frac{1}{\mathrm{e}}, \mathrm{e} \right] \right)$ 的图象与函数 $y = x^{2} + 2$ 的图象有交点，
> >
> > 即方程 $a + 2 \ln x = x^{2} + 2 \left( x \in \left[ \frac{1}{\mathrm{e}}, \mathrm{e} \right] \right)$ 有解，即 $a = x^{2} + 2 - 2 \ln x \left( x \in \left[ \frac{1}{\mathrm{e}}, \mathrm{e} \right] \right)$ 有解，
> >
> > 令 $f(x) = x^{2} + 2 - 2 \ln x$ ，则 $f'(x) = \frac{2(x^{2} - 1)}{x}$ ，当 $x \in \left[ \frac{1}{\mathrm{e}}, 1 \right)$ 时， $f'(x) < 0$ ，
> >
> > 当 $x \in (1, e]$ 时， $f'(x) > 0$ ，故当 x = 1 时， $f(x)$ 取最小值 3，
> >
> > 由 $f\left(\frac{1}{\mathrm{e}}\right) = \frac{1}{\mathrm{e}^{2}} + 4$ ， $f(\mathrm{e}) = \mathrm{e}^{2}$ ，故当 x = e 时， $f(x)$ 取最大值 $e^{2}$ ，故 $a \in [3, e^{2}]$ ，
> >
> > 故选：A.
> >
> > 47. 函数 $f(x) = \frac{\ln x}{x}$ 在区间[2,3]上的最小值是（）
> >
> > 【答案】
> > A. $\frac{\ln 2}{2}$ B. $\frac{1}{e}$ C. $\frac{\ln 3}{3}$ D.0
> >
> > 【答案】A
> >
> > 【分析】对函数 $f(x) = \frac{\ln x}{x}$ 求导，判断函数单调性，结合所给区间，即得函数最小值.
> > 【详解】由 $f(x) = \frac{\ln x}{x}$ 求导得 $f'(x) = \frac{1 - \ln x}{x^2}$ ， $x \in [2,3]$ ，
> >
> > 则当 $2 < x < \mathrm{e}$ 时， $f'(x) > 0$ ， $f(x)$ 单调递增；当 $\mathrm{e} < x < 3$ 时， $f'(x) < 0$ ， $f(x)$ 单调递减。
> >
> > 故当 $x = \mathrm{e}$ 时， $f(x)_{\max} = f(\mathrm{e}) = \frac{1}{\mathrm{e}}$
> >
> > 又 $f(2) = \frac{\ln 2}{2}, f(3) = \frac{\ln 3}{3}$ , 由 $f(2) - f(3) = \frac{\ln 2}{2} - \frac{\ln 3}{3} = \frac{3\ln 2 - 2\ln 3}{6} = \frac{\ln 8 - \ln 9}{6} < 0$ ，可得 $f(2) < f(3)$ ，故 $f(x)_{\min} = f(2) = \frac{\ln 2}{2}$ .
> >
> > 故选 **A**.
