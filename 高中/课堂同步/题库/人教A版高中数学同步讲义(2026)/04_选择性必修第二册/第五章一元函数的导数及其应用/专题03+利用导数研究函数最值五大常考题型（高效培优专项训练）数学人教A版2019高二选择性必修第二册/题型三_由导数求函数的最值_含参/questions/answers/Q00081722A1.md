> [!faq]- 《专题03+利用导数研究函数最值五大常考题型（高效培优专项训练）数学人教A版2019高二选择性必修第二册》官方解析
>
> > [!success]- **【答案】** (1) $a = 3$ ， $b = 4$ (2)答案见解析
>
> > [!note]- **【分析】**
> > （1）求出函数的导函数，依题意可得 $f'(1) = 6$ 且 $f(1) = 8$ ，即可求出 $a, b$ 的值；
> >
> > (2) 分 $a = 0$ 、 $a \leq -12$ 、 $-12 < a < 0$ 三种情况讨论，分别说明函数的单调性，即可求出函数的最大值.
>
> > [!note]- **【解析】**
> > （1）因为 $f(x) = x^3 + ax + b$ ，所以 $f'(x) = 3x^2 + a$
> >
> > 所以 $f'(1)=3+a=6$ ，所以 a=3，
> >
> > 又 $f(1)=1+a+b=8$ ，所以 b=4，
> >
> > 综上所述 $a = 3$ ， $b = 4$ ：
> >
> > (2) 因为 $f'(x)=3x^{2}+a$
> >
> > (i) 当 $a = 0$ 时， $f'(x) = 0$ 恒成立，
> >
> > 所以函数 $f(x)$ 在 $[0,2]$ 上单调递增，
> >
> > 所以 $f(x)_{\max} = f(2) = 2a + b + 8$ ;
> >
> > (ii) 当 $a < 0$ 时，由 $f'(x) = 3x^2 + a = 0$ ，解得 $x = \sqrt{-\frac{a}{3}}$ 或 $x = -\sqrt{-\frac{a}{3}}$
> >
> > 当 $x > \sqrt{-\frac{a}{3}}$ 或 $x < -\sqrt{-\frac{a}{3}}$ 时， $f'(x) > 0$ ，则 $f(x)$ 在 $\left(\sqrt{-\frac{a}{3}}, +\infty\right)$ 和 $\left(-\infty, -\sqrt{-\frac{a}{3}}\right)$ 上单调递增，
> >
> > 当 $-\sqrt{-\frac{a}{3}} < x < \sqrt{-\frac{a}{3}}$ 时， $f'(x) < 0$ ，则 $f(x)$ 在 $\left(-\sqrt{-\frac{a}{3}}, \sqrt{-\frac{a}{3}}\right)$ 上单调递减；
> > - **①**：当 $\sqrt{-\frac{a}{3}}$ 2时，即 $a \leq -12$ ，所以函数 $f(x)$ 在 $[0,2]$ 上单调递减，
> >
> > 所以 $f(x)_{\max}=f(0)=b$ ;
> > - **②**：当 $\sqrt{-\frac{a}{3}} < 2$ 时，即 $-12 < a < 0$ ，函数 $f(x)$ 在 $\left(0, \sqrt{-\frac{a}{3}}\right)$ 上单调递减，在 $\left(\sqrt{-\frac{a}{3}}, 2\right)$ 上单调递增，
> >
> > 又 $f(0) = b$ ， $f(2) = 2a + b + 8$ ，则 $f(2) - f(0) = 2a + 8$
> >
> > 所以当-4<a<0时， $f(2)>f(0)$ ，当-12<a<-4时， $f(2)<f(0)$ ，
> >
> > 当 a = -4 时， $f(2) = f(0)$ ，
> >
> > 所以 $f(x)_{\max} = \max \left\{f(2), f(0)\right\} = \begin{cases} b, -12 < a \leq -4 \\ 2a + b + 8, -4 < a < 0 \end{cases}$
> >
> > 综上所述，当 $a > -4$ 时， $f(x)_{\max} = 2a + b + 8$ ；当 $a \leq -4$ 时， $f(x)_{\max} = b$ 。
