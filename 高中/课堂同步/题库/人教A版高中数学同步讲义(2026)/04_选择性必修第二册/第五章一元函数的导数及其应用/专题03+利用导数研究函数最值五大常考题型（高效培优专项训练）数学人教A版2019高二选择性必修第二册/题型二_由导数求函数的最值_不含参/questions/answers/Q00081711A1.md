> [!faq]- 《专题03+利用导数研究函数最值五大常考题型（高效培优专项训练）数学人教A版2019高二选择性必修第二册》官方解析
>
> > [!success]- **【答案】** (1) $a = 2, b = -3$ (2)最大值为 10，最小值为 2，
>
> > [!note]- **【分析】**
> > （1）求导，即可根据函数值以及导数值列方程求解，
> >
> > (2) 根据函数的单调性，求解极值以及端点处函数值，即可作答.
>
> > [!note]- **【解析】**
> > （1） $f'(x)=3ax^{2}+2b$
> >
> > 故 $f(-1) = -a - 2b + 6 = 10$ 且 $f^{\prime}(-1) = 3a + 2b = 0$ ，解得 $a = 2, b = -3$
> >
> > 则 $f^{\prime}(x) = 6x^{2} - 6 = 6(x + 1)(x - 1)$
> >
> > 令 $f'(x)=0$ ，则 $x=\pm1$ ，
> >
> > 当 $x < -1$ 时， $f'(x) > 0$ ，当 $-1 < x < 1$ 时， $f'(x) < 0$ ，当 $x > 1$ 时， $f'(x) > 0$
> >
> > 故 $f(x)$ 在 $(- \infty, -1)$ 上单调递增，在 $(-1, 1)$ 上单调递减，在 $(1, +\infty)$ 上单调递增，
> >
> > 故 $f(x)$ 在x=-1处取到极大值，故a=2,b=-3满足题意，
> >
> > (2) 由 (1) 知： $f(x)$ 在 $(-2, -1)$ 和 $(1, 2)$ 单调递增，在 $(-1, 1)$ 单调递减，
> > 且 $f(x)_{\text{极大值}} = f(-1) = 10, f(x)_{\text{极小值}} = f(1) = 2, f(-2) = -16 + 12 + 6 = 2, f(2) = 16 - 12 + 6 = 10,$
> >
> > 故最大值为 10，最小值为 2.

> > 19. 函数 $f(x) = \sqrt{\mathrm{e}^{2x} + x^2} + \sqrt{2}|x|$ 的最小值为（ ）A.1 B.2 C.e D. $\mathbf{e}^2$
> >
> > 【答案】A
> >
> > 【分析】先对函数解析式进行变形因为 $f(x) = \sqrt{x^2 + (\mathrm{e}^x)^2} + \sqrt{x^2 + x^2}$ ，把求 $f(x)$ 的最小值转化为求点 $P(0,0)$ 到 $A(x,\mathrm{e}^x)$ 与 $B(x,x)$ 的距离之和的最小值，计算 $|AB| = |\mathrm{e}^x - x| = \mathrm{e}^x - x$ ，令 $g(x) = \mathrm{e}^x - x$ ，利用导数求得 $g(x)$ 的单调性和最小值，再根据 $f(x) = |PA| + |PB| \quad |AB| = 1$ ，求得答案。
> >
> > 【详解】因为 $f(x)=\sqrt{\mathrm{e}^{2x}+x^{2}}+\sqrt{2}|x|=\sqrt{x^{2}+\left(\mathrm{e}^{x}\right)^{2}}+\sqrt{x^{2}+x^{2}}$
> >
> > 故求 $f(x)$ 的最小值转化为求点 $P(0,0)$ 到 $A(x,\mathrm{e}^{x})$ 与 $B(x,x)$ 的距离之和的最小值，
> >
> > 又 $\left|AB\right|=\left|e^{x}-x\right|=e^{x}-x$ ，令 $g(x)=e^{x}-x$
> >
> > 则 $g^{\prime}(x) = \mathrm{e}^{x} - 1$ ，则 $g(x)$ 在 $(- \infty, 0)$ 单调递减，在 $(0, +\infty)$ 单调递增，故 $g(x) g(0) = 1$ 所以 $f(x) = |PA| + |PB| \quad |AB| \quad 1$ ，易知两个不等号均在 $x = 0$ 时取等号，故 $f(x)$ 的最小值为1.
> >
> > 故选 **A**.
