> [!faq]- 《专题02_利用导数研究函数的单调性六大常考题型_高效培优专项训练_数学》官方解析
>
> > [!success]- **【答案】** BCD
>
> > [!note]- **【分析】**
> > 构造函数 $g(x) = \frac{\mathrm{e}^x}{x^2}$ 应用导函数得出函数单调性得出值域判断A，B，根据 $x_{1}, x_{2}, x_{3}$ 成等差数列，结合指数运算律及对数运算律判断C，D.
>
> > [!note]- **【解析】**
> > 对 A、B: 令 $f(x)=\mathrm{e}^{x}-ax^{2}=0$ 则 $a=\frac{\mathrm{e}^{x}}{x^{2}}$
> >
> > 设 $g(x) = \frac{\mathrm{e}^x}{x^2}$ ，则 $g'(x) = \frac{\mathrm{e}^x(x - 2)}{x^3}$
> >
> > 故当 $x \in (-\infty, 0) \cup (2, +\infty)$ 时， $g'(x) > 0$ ，当 $x \in (0, 2)$ 时， $g'(x) < 0$
> >
> > 故 $g(x)$ 在 $(- \infty, 0), (2, +\infty)$ 上单调递增，在 $(0, 2)$ 上单调递减，
> >
> > 又 $x \to -\infty$ 时， $g(x) \to 0, x \to 0$ 时， $g(x) \to +\infty, x \to +\infty$ 时， $g(x) \to +\infty$
> >
> > 且 $g(2) = \frac{\mathrm{e}^2}{4}$ ，故 $x_{1} < 0 < x_{2} < 2 < x_{3}$ ，且 $a > \frac{\mathrm{e}^2}{4}$ ，故A错误、B正确；
> >
> > 对 C、D：由题意可得 $\frac{e^{x_{1}}}{x_{1}^{2}}=\frac{e^{x_{2}}}{x_{2}^{2}}=\frac{e^{x_{3}}}{x_{3}^{2}}$ ，所以 $\frac{e^{x_{1}}\times e^{x_{3}}}{x_{1}^{2}x_{3}^{2}}=\frac{e^{x_{1}+x_{3}}}{x_{1}^{2}x_{3}^{2}}=\frac{e^{2x_{2}}}{x_{2}^{4}}$ ，
> >
> > 由于 $x_{1}, x_{2}, x_{3}$ 成等差数列，则 $x_{1} + x_{3} = 2x_{2}$ ，故 $e^{x_{1} + x_{3}} = e^{2x_{2}}$ ，
> >
> > 则 $x_{1}^{2}x_{3}^{2} = x_{2}^{4}$ ，所以 $-x_{1}x_{3} = x_{2}^{2}$ ，故 $-x_{1},x_{2},x_{3}$ 成等比数列，故C正确；
> >
> > 则 $-x_{1}x_{3} = x_{2}^{2} = \left(\frac{x_{1} + x_{3}}{2}\right)^{2}$ ，化简有 $x_{1}^{2} + x_{3}^{2} + 6x_{1}x_{3} = 0$ ，则 $\frac{x_3^2}{x_1^2} +\frac{6x_3}{x_1} +1 = 0$
> >
> > 解得 $\frac{x_3}{x_1} = -3 - 2\sqrt{2}$ 或 $\frac{x_3}{x_1} = -3 + 2\sqrt{2}$
> >
> > 又 $\frac{x_3^2}{x_1^2} = \mathrm{e}^{x_3 - x_1}$ ，则 $x_{3} - x_{1} = 2\ln \left(-\frac{x_{3}}{x_{1}}\right) > 0$ ，故 $-\frac{x_3}{x_1} >1$
> >
> > 则 $\frac{x_3}{x_1} < -1$ ，又 $-3 + 2\sqrt{2} > -3 + 2 = -1$ 故舍去，
> >
> > 故 $\frac{x_3}{x_1} = -3 - 2\sqrt{2}$ ，又 $3 + 2\sqrt{2} = (1 + \sqrt{2})^2$
> >
> > 所以 $x_{3} - x_{1} = 2\ln \left(-\frac{x_{3}}{x_{1}}\right) = 2\ln \left(1 + \sqrt{2}\right)^{2} = 4\ln \left(1 + \sqrt{2}\right)$ ，故D正确.
> >
> > 故选 **BCD**.
