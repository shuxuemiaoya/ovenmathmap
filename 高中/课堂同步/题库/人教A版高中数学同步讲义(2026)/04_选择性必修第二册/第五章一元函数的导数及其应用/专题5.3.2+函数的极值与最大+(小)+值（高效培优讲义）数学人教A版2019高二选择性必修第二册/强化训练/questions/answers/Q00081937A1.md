> [!faq]- 《专题5.3.2+函数的极值与最大+(小)+值（高效培优讲义）数学人教A版2019高二选择性必修第二册》官方解析
>
> > [!success]- **【答案】** ABD
>
> > [!note]- **【分析】**
> > 根据导数的运算法则，结合极值点、零点、导数的性质逐一判断即可.
>
> > [!note]- **【解析】**
> > $f(x)=\frac{1}{3}x^{3}-\frac{1}{2}x^{2}-2x\Rightarrow f'(x)=x^{2}-x-2=(x+1)(x-2)$
> >
> > A：因为 $f^{\prime}(-1) = (-1 + 1)(-1 - 2) = 0$ ，所以 A 正确；
> >
> > B：因为当 x > 2 时， $f'(x) > 0, f(x)$ 单调递增，
> >
> > 当 $-1 < x < 2$ 时， $f'(x) < 0, f(x)$ 单调递减，且 $f'(2) = 0$
> >
> > 所以 $x = 2$ 是函数 $f(x)$ 的极值点，因此B正确；
> >
> > C: $f(x) = \frac{1}{3} x^3 - \frac{1}{2} x^2 - 2x = \frac{1}{6} x(2x^2 - 3x - 12) = 0 \Rightarrow x = 0$ ，或 $2x^2 - 3x - 12 = 0$ ，
> >
> > 由 $2x^{2} - 3x - 12 = 0 \Rightarrow x = \frac{3 \pm \sqrt{105}}{4}$ ，因此 $f(x)$ 有且仅有三个零点，所以 C 不正确；
> >
> > D：当 $2 < x < 3$ 时， $f'(x) > 0, f(x)$ 单调递增，
> >
> > 当 -1 < x < 2 时， $f'(x) < 0, f(x)$ 单调递减，
> >
> > 当 -3 < x < -1 时， $f'(x) > 0, f(x)$ 单调递增，
> >
> > 因为 $f(2) = -\frac{10}{3}, f(-3) = -\frac{15}{2}$ ，所以 $f(x)$ 在 $[-3, 3]$ 上的最小值为 $-\frac{15}{2}$ ，因此 D 正确，
> >
> > 故选 **ABD**
