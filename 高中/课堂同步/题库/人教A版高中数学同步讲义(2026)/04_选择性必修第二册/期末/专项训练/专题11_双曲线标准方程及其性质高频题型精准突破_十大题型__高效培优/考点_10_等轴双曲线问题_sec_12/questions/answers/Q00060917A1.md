> [!faq]- 《专题11_双曲线标准方程及其性质高频题型精准突破_十大题型__高效培优》官方解析
>
> > [!success]- **【答案】** $\frac{8}{3}$
>
> > [!note]- **【分析】**
> > 可知 $x, y$ 轴为曲线 $C_1$ 的渐近线，进而可得 $e_1 = \sqrt{2}$ ，设 $P(x, y), F_1\left(-\frac{\sqrt{6}}{3}, -\frac{\sqrt{6}}{3}\right), F_2\left(\frac{\sqrt{6}}{3}, \frac{\sqrt{6}}{3}\right)$ ，根据题意
> >
> > 整理可得 $\left|PF_{1}\right|+\left|PF_{2}\right|=2\sqrt{2}$ ，结合椭圆定义可得a,c以及 $e_{2}$ ，即可得结果·
>
> > [!note]- **【解析】**
> > 对于曲线 $C_1: y = \frac{1}{x}$ ，则 $x, y$ 轴为其渐近线，即渐近线相互垂直，
> >
> > 可知该双曲线为等轴双曲线，可得 $e_1 = \sqrt{2}$
> >
> > 对于曲线 $C_{2}$ ，设曲线 $C_{2}$ 上的点 $P(x,y)$ ，
> >
> > 由于将 $(y, x)$ 代入 $x^{2} - xy + y^{2} = 1$ 中，方程不变，故曲线 $C_{2}$ 关于 $y = x$ 对称，
> >
> > 由于将 $(-y, -x)$ 代入 $x^{2} - xy + y^{2} = 1$ 中，方程不变，故曲线 $C_2$ 关于 $y = -x$ 对称，
> >
> > 由此令 $x = \frac{\sqrt{2}}{2} (x' - y'), y = \frac{\sqrt{2}}{2} (x' + y')$ ，代入到 $x^2 - xy + y^2 = 1$ 中，
> >
> > 可得 $\frac{(x')^{2}}{2}+\frac{(y')^{2}}{\frac{2}{3}}=1$ ，该椭圆焦点为 $\left(\pm\frac{2\sqrt{3}}{3},0\right)$ ，
> >
> > 由于曲线： $x^{2} - xy + y^{2} = 1$ 是椭圆可按 $x = \frac{\sqrt{2}}{2} (x' - y')$ ， $y = \frac{\sqrt{2}}{2} (x' + y')$ 变换得到 $\frac{(x')^2}{2} +\frac{(y')^2}{\frac{2}{3}} = 1$ 故按此变换，由 $\left(\pm \frac{2\sqrt{3}}{3},0\right)$ ，可取 $F_{1}\left(-\frac{\sqrt{6}}{3}, - \frac{\sqrt{6}}{3}\right),F_{2}\left(\frac{\sqrt{6}}{3},\frac{\sqrt{6}}{3}\right)$ 可得 $(x + y)^2 -1 = 3xy\leqslant 3\left(\frac{x + y}{2}\right)^2$ ，解得 $-2\leqslant x + y\leqslant 2$ 当且仅当 $x = y = -1$ 时， $x + y = -2$ ，当且仅当 $x = y = 1$ 时， $x + y = 2$ 又因为 $\left|PF_1\right| = \sqrt{\left(x + \frac{\sqrt{6}}{3}\right)^2 + \left(y + \frac{\sqrt{6}}{3}\right)^2} = \sqrt{x^2 + y^2 + \frac{2\sqrt{6}}{3}x + \frac{2\sqrt{6}}{3}y + \frac{4}{3}}$ $= \sqrt{x^2 + y^2 + \frac{2\sqrt{6}}{3}x + \frac{2\sqrt{6}}{3}y - \frac{2}{3}(x^2 -xy + y^2) + 2}$ $= \sqrt{\frac{1}{3}(x + y)^2 + \frac{2\sqrt{6}}{3}(x + y) + 2} = \sqrt{\left[\frac{\sqrt{3}}{3}(x + y) + \sqrt{2}\right]^2} = \frac{\sqrt{3}}{3}(x + y) + \sqrt{2}$ ， $|PF_2| = \sqrt{\left(x - \frac{\sqrt{6}}{3}\right)^2 + \left(y - \frac{\sqrt{6}}{3}\right)^2} = \sqrt{x^2 + y^2 - \frac{2\sqrt{6}}{3}x - \frac{2\sqrt{6}}{3}y + \frac{4}{3}}$ $= \sqrt{x^2 + y^2 - \frac{2\sqrt{6}}{3}x - \frac{2\sqrt{6}}{3}y - \frac{2}{3}(x^2 -xy + y^2) + 2}$ $= \sqrt{\frac{1}{3}(x + y)^2 - \frac{2\sqrt{6}}{3}(x + y) + 2} = \sqrt{\left[\sqrt{2} - \frac{\sqrt{3}}{3}(x + y)\right]^2} = \sqrt{2} -\frac{\sqrt{3}}{3}(x + y)$ 则 $|PF_1| + |PF_2| = \sqrt{2} +\frac{\sqrt{3}}{3} (x + y) + \sqrt{2} -\frac{\sqrt{3}}{3} (x + y) = 2\sqrt{2}$ 可知曲线 $C_2$ 是以 $F_{1},F_{2}$ 为焦点的椭圆，则 $a = \sqrt{2},c = |OF_1| = \frac{2\sqrt{3}}{3}$ ，可得 $e_2 = \frac{c}{a} = \frac{\sqrt{6}}{3}$ 所以 $e_1^2 +e_2^2 = 2 + \frac{2}{3} = \frac{8}{3}$ 故答案为： $\frac{8}{3}$
