> [!faq]- 《专题03_空间向量及其运算的坐标表示高频题型精准突破_五大题型__高效》官方解析
>
> > [!success]- **【答案】** C
>
> > [!note]- **【分析】**
> > 根据空间向量的共面定理的推论，可判定 $^{A}$ 错误；由a与b的夹角为钝角，得到 $a\cdot b<0$ 且a与b不共线，结合数量积的运算和共线定理，可判定 $^{B}$ 错误；根据向量的共面定理和基底的概念，可判定 $^{C}$ 正确；根据向量的共线定理，以及充分、必要条件的判定方法，可判定 $^{D}$ 错误。
>
> > [!note]- **【解析】**
> > 对于 A，若 P, A, B, C 四点共面，则存在实数 x, y, z 使得 $OP = xOA + yOB + zOC$
> >
> > 且满足 $x + y + z = 1$ ，又由 $\overline{OP} = 2\overline{OA} -\overline{OB} +\overline{OC}$ 中， $2 + (-1) + 1 = 2\neq 1$
> >
> > 所以 P, A, B, C 四点不共面，所以 $^{A}$ 错误；
> >
> > 对于 B，向量 $a = (1, t, 2)$ ， $b = (-2, 1, 8t)$
> >
> > 若 $a$ 与 $b$ 的夹角为钝角，可得 $a \cdot b < 0$ 且 $a$ 与 $b$ 不共线，
> >
> > 由 $a \cdot b = -2 + t + 16t < 0$ ，解得 $t < \frac{2}{17}$ ，
> >
> > 设 $a = \lambda b$ ，可得 $\left\{ \begin{array}{l}1 = -2\lambda \\ t = \lambda \\ 2 = 8\lambda t \end{array} \right.$ ，解得 $t = -\frac{1}{2},\lambda = -\frac{1}{2}$
> >
> > 所以 $a$ 与 $b$ 的夹角为钝角时，实数 $t$ 的取值范围为 $(- \infty, -\frac{1}{2}) \cup (-\frac{1}{2}, \frac{2}{17})$ ，所以 $B$ 不正确；
> >
> > 对于 $C$ ，假设 $\{a + b,b + c,c + a\}$ 不能作为一个空间基底，即 $a + b,b + c,c + a$ 共面，
> >
> > 则存在实数 $x, y$ 使得 $a + b = x(b + c) + y(c + a)$ ，即 $a + b = ya + xb + (x + y)c$ ，
> >
> > 因为 $\left\{a,b,c\right\}$ 为空间向量的一组基底，可得 $\left\{\begin{aligned}y&=1\\ x&=1\\ x+y&=0\end{aligned}\right.$ ，此时方程组无解，
> > 所以 $a+b, b+c, c+a$ 不共面，所以 $\left\{a+b, b+c, c+a\right\}$ 能作为一个空间基底，所以 C 正确；
> > 对于 D，若 $a \neq 0, b = 0$ ，此时 a // b，但不存在实数 $\lambda$ ，使得 $a = \lambda b$ ，即必要性不成立；
> > 反之：若 $\exists \lambda \in R$ ，使得 $a = \lambda b$ ，则 $a // b$ ，即充分性成立，
> > 所以 $\exists \lambda \in R$ ，使得 $a = \lambda b$ ， $a // b$ 的充分不必要条件，所以 D 错误。
> >
> > 故选 **C**.
