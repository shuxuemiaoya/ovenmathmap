22. 下列命题中，正确的是（ ）
A．对空间任意一点 O 和不共线的三点 A, B, C，若 $OP = 2OA - OB + OC$ ，则，P, A, B, C 四点共面；
B．已知向量 $a = (1, t, 2)$ ， $b = (-2, 1, 8t)$ ，若 a 与 b 的夹角为钝角，则实数 t 的取值范围为 $\left(-\infty, \frac{2}{17}\right)$ ；
C．若 $\left\{a, b, c\right\}$ 为空间向量的一组基底，则 $\left\{a + b, b + c, c + a\right\}$ 构成空间向量的一组基底；
D．已知空间向量 a，b，“a//b”的充要条件是“ $\exists\lambda\in R$ ，使得 $a=\lambda b$ ”.
