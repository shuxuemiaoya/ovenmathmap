> [!faq]- 《专题02_空间向量基本定理高频题型精准突破_三大题型__高效培优期末专》官方解析
>
> > [!success]- **【答案】** CD
>
> > [!note]- **【分析】**
> > 举反例排除 $AB$ ；对 $C$ ，根据空间向量共面的条件判定；对 $D$ ，根据能成为基底的条件判定。
>
> > [!note]- **【解析】**
> > 对 $^{A}$ ，因为向量a、b同向时， $\left|a\right|+\left|b\right|\neq\left|a-b\right|$ ，即必要性不成立，故 $^{A}$ 错误；
> >
> > 对 $^{B}$ ，当 $a \neq 0$ ，b = 0 时，满足 $a // b$ ，但不存在实数 $\lambda$ ，使得 $a = \lambda b$ ，故 $^{B}$ 错误；
> >
> > 对 $C$ ，由于 $\overline{OP} = 2\overline{OA} -4\overline{OB} +3\overline{OC}$ ，得 $\overline{PB} = \frac{1}{2}\overline{PA} +\frac{3}{4}\overline{PC}$
> >
> > 若 $PA,PC$ 共线，则 $PA,PC,PB$ 三向量共线，故A,B,C三点共线，与已知矛盾，
> >
> > 故 $PA,PC$ 不共线，由向量共面的充要条件知 $PB,PA,PC$ 共面，
> >
> > 而 $PB, PA, PC$ 过同一点 $P$ ，所以 $P, A, B, C$ 四点共面，故 $C$ 正确；
> >
> > 对 $\mathsf{D}$ ，若 $\{a,b,c\}$ 为空间的一个基底，则 $a$ ， $b$ ， $c$ 不共面，
> >
> > 假设 $a + b, b + 2c, c + 3a$ 共面，设 $a + b = x(b + 2c) + y(c + 3a)$
> >
> > 所以 $\left\{ \begin{array}{ll}1 = 3y\\ 1 = x\\ 0 = 2x + y \end{array} \right.$ ，无解，故 不共面，
> >
> > 则 $\{a + b, b + 2c, c + 3a\}$ 构成空间的另一个基底，故 $^{\mathrm{D}}$ 正确
> >
> > 故选 **CD**.
