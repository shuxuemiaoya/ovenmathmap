> [!faq]- 《专题02_空间向量基本定理高频题型精准突破_三大题型__高效培优期末专》官方解析
>
> > [!success]- **【答案】** $\frac{5}{2} (a + b) + \frac{1}{2} (a - b) + c$
>
> > [!note]- **【分析】**
> > 设 $p = 3a + 2b + c = x(a + b) + y(a - b) + zc$ ，然后解方程组即可·
>
> > [!note]- **【解析】**
> > 设 $p = 3a + 2b + c = x(a + b) + y(a - b) + zc$
> >
> > 即有 $3a + 2b + c = (x + y)a + (x - y)b + zc$
> >
> > 因为 $\left\{ \begin{array}{lll} \mathrm{r} & \mathrm{r} & \mathrm{r} \\ a, b, c \end{array} \right\}$ 是空间的一个单位正交基底，
> >
> > 所以有 $\left\{ \begin{array}{l}x + y = 3\\ x - y = 2\Rightarrow \\ z = 1 \end{array} \right.$ $\left\{ \begin{array}{l}x = \frac{5}{2}\\ y = \frac{1}{2}\\ z = 1 \end{array} \right.$
> >
> > 所以 $\vec{p}=\frac{5}{2}(a+b)+\frac{1}{2}(a-b)+c$
> >
> > 故答案为： $\frac{5}{2} (a + b) + \frac{1}{2} (a - b) + c$
