> [!faq]- 《专题02_空间向量基本定理高频题型精准突破_三大题型__高效培优期末专》官方解析
>
> > [!success]- **【答案】** D
>
> > [!note]- **【分析】**
> > 根据空间向量的线性运算及空间向量基本定理即可求解·
>
> > [!note]- **【解析】**
> > 因为点 $E, F$ 分别为 $PB, PD$ 的中点，所以 $\overline{AE} = \frac{1}{2}\left(\overline{AP} + \overline{AB}\right), \overline{AF} = \frac{1}{2}\left(\overline{AP} + \overline{AD}\right)$ ，所以 $\overline{AP} + \overline{AB} = 2AE, \overline{AP} + \overline{AD} = 2AF$ ，因为 $\overline{PG} = \frac{1}{2}GC$ ，所以 $\overline{AG} - \overline{AP} = \frac{1}{2}\left(\overline{AC} - \overline{AG}\right) = \frac{1}{2}\left(\overline{AB} + \overline{AD} - \overline{AG}\right)$ ，所以 $\overline{AG} = \frac{2}{3}AP + \frac{1}{3}AB + \frac{1}{3}AD = \frac{1}{3}\left(\overline{AP} + \overline{AB}\right) + \frac{1}{3}\left(\overline{AP} + \overline{AD}\right) = \frac{2}{3}AE + \frac{2}{3}AF$ ，又 $\overline{AG} = xAE + yAF$ ，则 $x = y = \frac{2}{3}$ ，所以 $x + y = \frac{4}{3}$ .
> >
> > 故选 **D**.
