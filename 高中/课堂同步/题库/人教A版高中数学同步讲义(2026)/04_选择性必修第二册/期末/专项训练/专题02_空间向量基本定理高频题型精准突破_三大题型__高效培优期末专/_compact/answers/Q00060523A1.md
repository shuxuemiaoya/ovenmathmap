> [!faq]- 《专题02_空间向量基本定理高频题型精准突破_三大题型__高效培优期末专》官方解析
>
> > [!success]- **【答案】** C ##
>
> > [!note]- **【分析】**
> > 要判断向量是否共面，需依据向量共面定理：三个向量共面的充要条件是其中一个向量可由另外两个不共线向量线性表示，用此定理一一进行检验即可判断·
>
> > [!note]- **【解析】**
> > $\because \{a,b,c\}$ 构成空间的一个基底， $\therefore a,b,c$ 不共面.
> >
> > 选项 A：因 $b=\frac{1}{2}(b+c)+\frac{1}{2}(b-c)$ ，则 $b+c, b, b-c$ 三个向量共面；
> >
> > 选项 B：因 $\vec{a}=\frac{1}{2}(a+\vec{b})+\frac{1}{2}(a-b)$ ，则 $a,a+b,a-b$ 三个向量共面；
> >
> > 选项C：假设 $a + b, a - b, c$ 共面，则存在 $x, y \in \mathbb{R}$ ，使得 $c = x(a + b) + y(a - b) = (x + y)a + (x - y)b$
> >
> > 这与 $a, b, c$ 不共面相矛盾，故假设不成立，即 $a + b, a - b, c$ 不共面；
> >
> > 选项 D：因 $a + b + c = (a + b) + c$ ，则 $a + b + c, (a + b), c$ 三个向量共面。
> >
> > 故选 **C**.
