> [!faq]- 《专题06_直线方程高频题型精准突破_六大题型__高效培优期末专项训练_》官方解析
>
> > [!success]- **【答案】** BD
>
> > [!note]- **【分析】**
> > 把直线方程化成斜截式，可判断 $^{A}$ 的真假；根据平行直线的判断方法判断 $^{B}$ 的真假；根据垂直之线的判断方法判断 $^{C}$ 的真假；设 $P(x,y)$ ，平移得Q点坐标，代入直线l的方程验证可判断 $^{D}$ 的真假。
>
> > [!note]- **【解析】**
> > 对 $^{A}$ ：由 $x+2y+c=0\Rightarrow y=-\frac{1}{2}x-\frac{c}{2}$ ，为直线l的斜截式方程，故 $^{A}$ 错误；
> >
> > 对 ${}^{\mathrm{B}}$ ：因为 $\frac{1}{1} = \frac{2}{2} \neq \frac{0}{c}$ ，所以直线 $x + 2y + c = 0 (c \neq 0)$ 与 $x + 2y = 0$ 平行，故 ${}^{\mathrm{B}}$ 正确；
> >
> > 对 C：因为 $1 \times 2 + 2 \times 1 \neq 0$ ，所以直线 $x + 2y + c = 0 (c \neq 0)$ 与 $2x + y - 1 = 0$ 不垂直，故 C 错误；
> >
> > 对 D：设 $P(x,y)$ ，则 $x+2y+c=0$ ，将点 P 向右平移 2 个单位长度，再向下平移 1 个单位长度得点 Q
> >
> > $\left(x + 2, y - 1\right)$ ，因为 $(x + 2) + 2(y - 1) + c = x + 2y + c = 0$ ，所以点 $Q$ 仍在直线 $l$ 上，故 $^{\mathrm{D}}$ 正确。
> >
> > 故选 **BD**
