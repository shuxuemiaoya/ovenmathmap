> [!faq]- 《专题06_直线方程高频题型精准突破_六大题型__高效培优期末专项训练_》官方解析
>
> > [!success]- **【答案】** CD
>
> > [!note]- **【分析】**
> > A化为斜截式判断；B特殊值 $a = 0, bc > 0$ 判断即可；C化为 $2x + y + 4 + \lambda (x - 2y - 3) = 0$ ，即可确定定点；D将参数 $a = 0$ 代入直线方程即可判断·
>
> > [!note]- **【解析】**
> > A：将直线化为斜截式，有 $y = -\frac{\sqrt{3}}{3} x + 1$ ，即直线斜率为 $-\frac{\sqrt{3}}{3}$ ，错；
> >
> > B：当 $a = 0, bc > 0$ 时，直线为 $y = -\frac{c}{b} < 0$ 也过第三象限，错；
> >
> > C: $(2 + \lambda)x + (1 - 2\lambda)y + 4 - 3\lambda = 2x + y + 4 + \lambda (x - 2y - 3) = 0$
> >
> > 令 $\left\{ \begin{array}{l} 2x + y + 4 = 0 \\ x - 2y - 3 = 0 \end{array} \right. \Rightarrow \left\{ \begin{array}{l} x = -1 \\ y = -2 \end{array} \right.$ ，即直线过定点 $(-1, -2)$ ，对；
> >
> > D：由题设 $3x + ay = 2 \Rightarrow x = \frac{2}{3}$ ， $ax + 3y + 1 = 0 \Rightarrow y = -\frac{1}{3}$ ，显然两线垂直，对
> >
> > 故选：CD
> >
> > 46. 直线 $l_{1}: x + (m + 1)y - 2m - 2 = 0$ 与直线 $l_{2}: (m + 1)x - y - 2m - 2 = 0$ 相交于点 $P$ ，对任意实数 $m$ ，直线 $l_{1}, l_{2}$ 分别恒过定点 $A, B$ ，则 $|PA| + |PB|$ 的最大值为（）A.2 B. $2\sqrt{2}$ C. $4\sqrt{2}$ D.4
> >
> > 【答案】D
> >
> > 【分析】求得 $A(0,2)$ 、 $B(2,0)$ ，再根据两直线的位置关系的判断可得 $l_{1} \perp l_{2}$ ，即有 $PA \perp PB$ ，从而得 $PA \perp PB$ ，再结合基本不等式求解即可。
> >
> > 【详解】解：因为 $l_{1}: x + (m + 1)y - 2m - 2 = 0$ ，即 $x + y - 2 + m(y - 2) = 0$
> >
> > 由 $\left\{ \begin{array}{l}x + y - 2 = 0\\ y - 2 = 0 \end{array} \right.$ ，解得 $\left\{ \begin{array}{ll}x = 0\\ y = 2 \end{array} \right.$ ，所以直线 $l_{1}$ 过定点 $A(0,2)$
> >
> > 同理可得直线 $l_{2}$ 过定点 $B(2,0)$ ;
> >
> > 又因为 $1 \times (m + 1) + (-1) \times (m + 1) = 0$ ，所以 $l_{1} \perp l_{2}$
> >
> > 即有 $PA \perp PB$ ，所以 $|PA|^2 + |PB|^2 = |AB|^2 = 8$
> >
> > 所以 $|PA| + |PB| \leq \sqrt{2(|PA|^2 + |PB|^2)} = 4$
> >
> > 当且仅当 $\left|PA\right|=\left|PB\right|=2$ 时，取等号.
> >
> > 所以 $|PA| + |PB|$ 的最大值为 4.
> >
> > 故选 **D**.
