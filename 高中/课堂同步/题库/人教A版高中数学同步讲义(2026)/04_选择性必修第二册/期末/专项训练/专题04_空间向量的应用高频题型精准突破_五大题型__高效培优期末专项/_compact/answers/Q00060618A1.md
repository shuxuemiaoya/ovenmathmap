> [!faq]- 《专题04_空间向量的应用高频题型精准突破_五大题型__高效培优期末专项》官方解析
>
> > [!success]- **【答案】** BCD
>
> > [!note]- **【分析】**
> > 选项 A，求平面 ABC 法向量 n，验证 $AD \cdot n$ 是否为 0 判断四点是否共面即可；选项 B，求 AB 和 CD 方向向量，假设共面列方程组，根据有无解判断是否共面即可；选项 C，设 $AF = \lambda AB$ 得 F 坐标表达式，利用 EF 和 EG 共线列方程求 $\lambda$ 确定 F 坐标即可；选项 D，由 EF 和 EG 共线求出 $\mu$ ，根据 $CG = \mu CD$ 确定 G 坐标即可。
>
> > [!note]- **【解析】**
> > 选项 A， $AB = (1,2,3) - (1,1,1) = (0,1,2)$
> >
> > $$
> > \stackrel {\sqcup \sqcup \sqcup} {A C} = (1, 0, 1) - (1, 1, 1) = (0, - 1, 0), \quad \stackrel {\sqcup \sqcup \sqcup} {A D} = (2, 1, 1) - (1, 1, 1) = (1, 0, 0)
> > $$
> >
> > 设平面 ABC 的法向量 $n = (x, y, z)$ ，则 $\left\{\begin{aligned} &n \cdot AB = y + 2z = 0 \\ &n \cdot AC = -y = 0\end{aligned}\right.$
> >
> > 解得 $y = 0$ ， $z = 0$ ， $x$ 为不为0的实数，
> >
> > 不妨取 $n=(1,0,0)$ ，因为 $AD\cdot n=(1,0,0)\cdot(1,0,0)=1\neq0$
> >
> > 所以 A, B, C, D 四点不共面，选项 A 错误；
> >
> > 选项 B，直线 AB 的方向向量 $\overline{AB} = (0,1,2)$
> >
> > 直线 $CD$ 的方向向量 $\overline{CD} = (2,1,1) - (1,0,1) = (1,1,0)$
> >
> > 假设直线 $AB$ 与直线 $CD$ 共面，则存在实数 $m, n$ ，使得 $\overline{CD} = m\overline{AB} + n\overline{AC}$
> >
> > 即 $(1,1,0) = m(0,1,2) + n(0, - 1,0) = (0,m - n,2m)$ ，此方程无解，
> >
> > 所以直线 AB 与直线 CD 是异面直线，选项 B 正确；
> >
> > 选项 $^{C}$ ，因为 F 在直线 AB 上，设 $AF = \lambda AB$ ， $AB = (0,1,2)$ ， $A(1,1,1)$
> >
> > 则 $F$ 点坐标为 $\left(1,1 + \lambda ,1 + 2\lambda\right)$ ，又有 $E(2,1,0)$
> >
> > 则 $EF = (1, 1 + \lambda, 1 + 2\lambda) - (2, 1, 0) = (-1, \lambda, 1 + 2\lambda)$
> >
> > 因为 G 在直线 CD 上，设 $CG = \mu CD$ ， $CD = (1, 1, 0)$ ， $C(1, 0, 1)$ ，
> >
> > 则 $G$ 点坐标为 $(1 + \mu, \mu, 1)$ ，则 $EG = (1 + \mu, \mu, 1) - (2, 1, 0) = (\mu - 1, \mu - 1, 1)$
> >
> > 因为 $\frac{\mu\mu}{EF}$ 和 $\frac{\mu\mu}{EG}$ 共线，则 $\frac{-1}{\mu - 1} = \frac{\lambda}{\mu - 1} = \frac{1 + 2\lambda}{1}$ ，解得 $\lambda = -1$ ，
> >
> > 此时点 F 坐标为 $(1,1-1,1-2)=(1,0,-1)$ ，选项 C 正确；
> >
> > 选项D， $\frac{-1}{\mu - 1} = \frac{\lambda}{\mu - 1} = \frac{1 + 2\lambda}{1}$ ，解得 $\lambda = -1$ ， $\mu = 2$
> >
> > 此时点 G 坐标为 $(1+2,2,1)=(3,2,1)$ ，选项 D 正确；
> >
> > 故选 **BCD**.
