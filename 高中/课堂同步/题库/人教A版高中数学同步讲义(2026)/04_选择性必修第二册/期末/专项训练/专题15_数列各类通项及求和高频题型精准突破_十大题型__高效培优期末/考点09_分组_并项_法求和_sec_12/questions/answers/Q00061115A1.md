> [!faq]- 《专题15_数列各类通项及求和高频题型精准突破_十大题型__高效培优期末》官方解析
>
> > [!success]- **【答案】** (1) $a_{n} = n$ (2) $T_{2n}=n^{2}+\frac{n}{4(n+1)}$
>
> > [!note]- **【分析】**
> > （1）先根据等差数列的通项公式求出 $S_{n}$ ，再利用 $a_{n}$ 与 $S_{n}$ 的关系求解即可；
> >
> > (2) 利用分组求和，其中奇数部分利用等差数列的前 $n$ 项和公式，偶数部分利用裂项相消求解即可。
>
> > [!note]- **【解析】**
> > （1）因为 $a_1 = S_1 = 1$ ， $S_3 = 6$ ，设等差数列 $\left\{\frac{S_n}{n}\right\}$ 的公差为 $d$ ，则 $\frac{S_3}{3} = 1 + 2d = 2$ ，解得 $d = \frac{1}{2}$ 所以 $\frac{S_n}{n} = 1 + \frac{1}{2}(n - 1) = \frac{n + 1}{2}$ ，即 $S_n = \frac{n^2 + n}{2}$ ，
> >
> > 当 $n$ 2时， $a_{n} = S_{n} - S_{n - 1} = n$ ，当 $n = 1$ 时， $a_{1} = 1$ 成立，故 $a_{n} = n$
> >
> > (2) 由题意可得 $T_{2n} = b_{1} + b_{2} + b_{3} + \dots + b_{2n}$
> >
> > $= (b_{1} + b_{3} + \ldots + b_{2n - 1}) + (b_{2} + b_{4} + \ldots + b_{2n})$ $= [1 + 3 + \ldots + (2n - 1)] + \left[\frac{1}{2 \times 4} + \frac{1}{4 \times 6} + \ldots + \frac{1}{2n \times 2(n + 1)}\right]$ $= \frac{n[1 + (2n - 1)]}{2} + \frac{1}{4}\left[\frac{1}{1 \times 2} + \frac{1}{2 \times 3} + \ldots + \frac{1}{n \times (n + 1)}\right]$ $= n^2 + \frac{1}{4}\left(1 - \frac{1}{2} + \frac{1}{2} - \frac{1}{3} + \ldots + \frac{1}{n} - \frac{1}{n + 1}\right)$ $= n^2 + \frac{n}{4(n + 1)}.$
