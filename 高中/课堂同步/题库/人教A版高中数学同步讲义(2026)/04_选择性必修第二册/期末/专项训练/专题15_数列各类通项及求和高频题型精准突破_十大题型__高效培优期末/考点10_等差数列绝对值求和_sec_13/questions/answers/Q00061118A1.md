> [!faq]- 《专题15_数列各类通项及求和高频题型精准突破_十大题型__高效培优期末》官方解析
>
> > [!success]- **【答案】** (1) $a_{n}=2^{n-1}$ <!-- source-part:2 pages:51-56 --> (2)见解析
>
> > [!note]- **【分析】**
> > （1）由条件可知， $2(a_{2}+1)=a_{1}+a_{3}+1$ ，再代入等比数列通项公式，即可求解；
> >
> > (2) 若选①，利用裂项相消法求和；若选②，结合绝对值里面的正负，分情况求和；若选③，利用等差和等比数列求和公式，即可求解.
>
> > [!note]- **【解析】**
> > （1）设数列 $\{a_{n}\}$ 的公比为 $q$ ，
> >
> > 由条件可知， $2(a_{2}+1)=a_{1}+a_{3}+1$ ，
> >
> > 即 $2(q + 1) = 2 + q^2$ ，得 $q = 2$ 或 $q = 0$ （舍），
> >
> > 所以 $a_{n} = 2^{n - 1}$
> >
> > (2) 若选①， $\log_{2}a_{n+1}=n,\quad\log_{2}a_{n+2}=n+1$
> >
> > 所以 $b_{n} = \frac{1}{\log_{2}a_{n + 1}\cdot\log_{2}a_{n + 2}} = \frac{1}{n(n + 1)} = \frac{1}{n} -\frac{1}{n + 1}$
> >
> > 则 $T_{n} = \left(1 - \frac{1}{2}\right) + \left(\frac{1}{2} -\frac{1}{3}\right) + \left(\frac{1}{3} -\frac{1}{4}\right) + \ldots +\left(\frac{1}{n} -\frac{1}{n + 1}\right) = 1 - \frac{1}{n + 1};$
> >
> > 若选②， $b_{n}=\left|\log_{2}a_{n}-3\right|=\left|n-4\right|$
> >
> > 数列 $\{n - 4\}$ 是前 $n$ 项和是 $S_{n} = \frac{n(-3 + n - 4)}{2} = \frac{n(n - 7)}{2}$
> >
> > 当 $n \leq 4$ 时，数列 $\{n - 4\}$ 的每一项都是非正数，所以 $T_{n} = -S_{n} = \frac{n(7 - n)}{2}$
> >
> > 当 $n$ 5时，数列 $\{n - 4\}$ 的每一项都是正数，
> >
> > 所以 $T_{n} = S_{n} - S_{4} - S_{4} = S_{n} - 2S_{4} = \frac{n^{2} - 7n + 24}{2}$
> >
> > 所以 $T_{n}=\left\{\begin{aligned}&\frac{n(7-n)}{2},n\leq4\\&\frac{n^{2}-7n+24}{2},n\quad5\end{aligned}\right.$ ;
> >
> > 如选择③，则 $b_{n}=n+a_{n}=n+2^{n-1}$
> >
> > 数列 $\{n\}$ 的前 $n$ 项和为 $\frac{n(1 + n)}{2}$ ，数列 $\{a_{n}\}$ 的前 $n$ 项和为 $\frac{1 - 2^n}{1 - 2} = 2^n - 1$ ，
> >
> > 则 $T_{n} = \frac{n(1 + n)}{2} + 2^{n} - 1$ .
