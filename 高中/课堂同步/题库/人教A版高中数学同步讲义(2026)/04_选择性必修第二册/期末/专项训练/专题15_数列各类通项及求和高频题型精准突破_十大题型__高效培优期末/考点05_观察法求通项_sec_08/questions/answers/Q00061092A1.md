> [!faq]- 《专题15_数列各类通项及求和高频题型精准突破_十大题型__高效培优期末》官方解析
>
> > [!success]- **【答案】** ABC
>
> > [!note]- **【分析】**
> > 利用数列的定义可判断 $^{A}$ 选项；利用观察法求出数列通项公式可判断 $^{B}$ 选项；利用常数列的定义可判断 $^{C}$ 选项；利用数列的单调性和无穷数列的定义可判断 $^{D}$ 选项.
>
> > [!note]- **【解析】**
> > 对于 $^{A}$ 选项，数列是按一定顺序排成的一列数，即数列1，3，5，7与7，5，3，1是两个数列，故 $^{A}$ 错误；
> >
> > 对于 B 选项，数列 0，1，2，3，L 的通项公式是 $a_{n}=n-1$ ，故 B 错误；
> >
> > 对于 $^{C}$ 选项，-1，1，-1，1，L是摆动数列，故 $^{C}$ 错误；
> >
> > 对于 $^{D}$ 选项，1，2， $2^{2}$ ， $2^{3}$ ，L是递增数列，也是无穷数列，故 $^{D}$ 正确·
> >
> > 故选：ABC.

> > 26. 南宋数学家杨辉在《详解九章算法商功》一书中记载的三角垛、方垛、刍甍垛等的求和都与高阶等差数列有关，如图是一个三角垛，最顶层有 $^{1}$ 个小球，第二层有 $^{3}$ 个小球，第三层有 $^{6}$ 个小球，第四层有 $^{10}$ 个小球……设第n层有 $a_{n}$ 个小球，则 $\frac{1}{a_{1}}+\frac{1}{a_{2}}+\frac{1}{a_{3}}+\ldots+\frac{1}{a_{2025}}$ 的值为（）
> >
> > ![](../../../images/questions/part-001/0162d2d05d71a5faaf6f6bcf96058c1aa5c93a309d53d68f858fb6b03e92231d.jpg)
> >
> > A. $\frac{2024}{2025}$ B. $\frac{2023}{1012}$ C. $\frac{2025}{2026}$ D. $\frac{2025}{1013}$
> >
> > 【答案】D
> >
> > 【分析】由已知条件分析得到数列 $\left\{a_{n}\right\}$ 的通项公式，并利用等差数列前 $n$ 项和公式化简，进而求得数列 $\left\{\frac{1}{a_n}\right\}$ 的通项公式·再利用裂项相消求和法求得结果·
> > 【详解】由题意可得， $a_1 = 1, a_2 = 3 = 1 + 2, a_3 = 6 = 1 + 2 + 3, a_4 = 10 = 1 + 2 + 3 + 4$ ，……
> > 所以， $a_n = 1 + 2 + 3 + \dots + n = \frac{n(n + 1)}{2}$ .
> > 所以， $\frac{1}{a_n} = \frac{2}{n(n + 1)} = 2\left(\frac{1}{n} - \frac{1}{n + 1}\right)$ 所以， $\frac{1}{a_1} + \frac{1}{a_2} + \frac{1}{a_3} + \dots + \frac{1}{a_{2025}} = 2\left(1 - \frac{1}{2}\right) + 2\left(\frac{1}{2} - \frac{1}{3}\right) + 2\left(\frac{1}{3} - \frac{1}{4}\right) + \dots + 2\left(\frac{1}{2025} - \frac{1}{2026}\right)$ $= 2\left(1 - \frac{1}{2} + \frac{1}{2} - \frac{1}{3} + \frac{1}{3} - \frac{1}{4} + \dots + \frac{1}{2025} - \frac{1}{2026}\right) = 2\left(1 - \frac{1}{2026}\right) = \frac{2025}{1013}$ 故选：D
> >
> > 27. “杨辉三角”是中国古代重要的数学成就，如图是由“杨辉三角”拓展而成的三角形数阵，从第三行起，每一行的第三个数 $1, \frac{1}{3}, \frac{1}{6}, \frac{1}{10}, L$ ，构成数列 $\{a_n\}$ ，其前 $n$ 项和为 $S_n$ ，则 $S_{31} = (\quad)$ A. $\frac{31}{16}$ B. $\frac{39}{20}$ C. $\frac{31}{32}$ D. $\frac{39}{40}$
> >
> > 【答案】A
> >
> > 【分析】根据数列 $\{a_{n}\}$ 的前4项，归纳出数列的通项公式，再利用裂项相消法求出前 $n$ 项和，即可求解·【详解】根据题意可知， $a_{1} = 1 = \frac{2}{1 \times 2}$ ， $a_{2} = \frac{1}{3} = \frac{2}{2 \times 3}$ ， $a_{3} = \frac{1}{6} = \frac{2}{3 \times 4}$ ， $a_{4} = \frac{1}{10} = \frac{2}{4 \times 5}$ ，L
> >
> > 以此类推， $a_{n} = \frac{2}{n(n + 1)} = 2\left(\frac{1}{n} -\frac{1}{n + 1}\right)$
> >
> > 所以其前 $n$ 项和 $S_{n} = 2\left(1 - \frac{1}{2} +\frac{1}{2} -\frac{1}{3} +\frac{1}{3} -\frac{1}{4} +\dots +\frac{1}{n} -\frac{1}{n + 1}\right) = 2\left(1 - \frac{1}{n + 1}\right) = \frac{2n}{n + 1}$
> >
> > 所以 $S_{31}=\frac{2\times31}{31+1}=\frac{62}{32}=\frac{31}{16}$ .
> >
> > 故选 **A**.
