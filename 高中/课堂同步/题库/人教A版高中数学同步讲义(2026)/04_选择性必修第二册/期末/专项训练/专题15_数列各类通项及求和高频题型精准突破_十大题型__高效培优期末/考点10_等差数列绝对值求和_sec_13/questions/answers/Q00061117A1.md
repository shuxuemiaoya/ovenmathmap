> [!faq]- 《专题15_数列各类通项及求和高频题型精准突破_十大题型__高效培优期末》官方解析
>
> > [!success]- **【答案】** (1) $a_{n}=2n-6$ (2) $T_{n}=\begin{cases}-n^{2}+5n,n<3\\n^{2}-5n+12,n\end{cases}$ 3
>
> > [!note]- **【分析】**
> > （1）借助 $a_{n}$ 与 $S_{n}$ 的关系，结合等差数列定义计算即可得；
> >
> > (2) 分 n < 3 与 n 3 进行讨论即可得.
>
> > [!note]- **【解析】**
> > （1）当 $n = 2$ 时， $a_{1} = S_{2} - a_{2} = 2^{2} - 7 \times 2 + 6 = -4$
> >
> > 当 $n$ 2时， $S_{n - 1} = S_n - a_n = n^2 -7n + 6,S_n = S_{n + 1} - a_{n + 1} = n^2 -5n$
> >
> > 两式相减得 $a_{n} = S_{n} - S_{n - 1} = (n^{2} - 5n) - (n^{2} - 7n + 6) = 2n - 6$
> >
> > 经检验，当 n=1 时， $a_{1}=-4$ ，符合上式，所以 $a_{n}=2n-6$ ；
> >
> > (2) 设数列 $\left\{\left|a_{n}\right|\right\}$ 的前 n 项和为 $T_{n}$
> >
> > 由 $a_{n} = 2n - 6$ ，则当 $n < 3$ 时， $a_{n} < 0$ ， $\left|a_{n}\right| = 6 - 2n$
> >
> > 此时 $T_{n} = \frac{n(6 - 2 + 6 - 2n)}{2} = -n^{2} + 5n$
> >
> > 当 n 3 时， $a_{n}$ $0, S_{n} = a_{n} + n^{2} - 7n + 6 = 2n - 6 + n^{2} - 7n + 6 = n(n - 5)$
> >
> > 所以 $T_{n}=\left|a_{1}\right|+\left|a_{2}\right|+a_{3}+\cdots+a_{n}=S_{n}-2\left(a_{1}+a_{2}\right)=n^{2}-5n+12$
> >
> > 综上所述，数列 $\left\{\left|a_n\right|\right\}$ 的前 $n$ 项和 $T_{n} = \left\{ \begin{array}{ll} - n^{2} + 5n, & n < 3\\ n^{2} - 5n + 12,n & 3 \end{array} \right.$
