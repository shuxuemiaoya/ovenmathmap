> [!faq]- 《专题14_等比数列高频题型精准突破_十大题型__高效培优期末专项训练_》官方解析
>
> > [!success]- **【答案】** D
>
> > [!note]- **【分析】**
> > 利用韦达定理求出 $a_1, a_5$ 的可能值，利用等比数列的性质求出 $a_3$ ，分情况讨论求出 $a_2$ 的可能值进而求出 $a_2 + a_3$ ：
>
> > [!note]- **【解析】**
> > ∵ $a_{1}, a_{5}$ 是方程 $x^{2} - 34x + 64 = 0$ 的两根，
> >
> > 由韦达定理得 $\left\{ \begin{array}{l}a_{1} + a_{5} = 34\\ a_{1}\cdot a_{5} = 64 \end{array} \right.$ ，解得 $\left\{ \begin{array}{ll}a_1 = 2\\ a_5 = 32 \end{array} \right.$ 或 $\left\{ \begin{array}{ll}a_1 = 32\\ a_5 = 2 \end{array} \right.$
> >
> > $\therefore \left\{a_{n}\right\}$ 是正项等比数列，设公比为 $q$ ，则 $q > 0$
> >
> > $\therefore a_{1}a_{5} = a_{3}^{2} = 64$ ，解得 $a_3 = 8$
> >
> > 若 $\left\{ \begin{array}{l}a_{1} = 2\\ a_{5} = 32 \end{array} \right.$ ，则 $q^4 = \frac{a_5}{a_1} = 16$ ，解得 $q = 2$ ， $a_2 = a_1q = 2\times 2 = 4$
> >
> > $\therefore a_{2} + a_{3} = 4 + 8 = 12$
> >
> > 若 $\left\{ \begin{array}{l} a_{1} = 32 \\ a_{5} = 2 \end{array} \right.$ ，则 $q^{4} = \frac{a_{5}}{a_{1}} = \frac{2}{32} = \frac{1}{16}$ ，解得 $q = \frac{1}{2}$ ， $a_{2} = a_{1}q = 32 \times \frac{1}{2} = 16$ ， $\therefore a_{2} + a_{3} = 16 + 8 = 24$ 。
> >
> > 综上， $a_{2}+a_{3}$ 的值为 24 或 12，故 D 正确。
> >
> > 故选：D.

> > 20. 等差数列 $\{a_{n}\}$ 的首项为 1，公差不为 0。若 $a_{2}, a_{3}, a_{6}$ 成等比数列，则 $\{a_{n}\}$ 前 6 项的和为（）
> > A.-24 B.-3 C.-9 D.8
> >
> > 【答案】A
> >
> > 【分析】设等差数列 $\{a_{n}\}$ 的公差为 $d$ ，由 $a_2, a_3, a_6$ 成等比数列，得 $a_3^2 = a_2a_6$ ，进而解得 $d$ ，利用等差数列前 $n$ 项和公式即可求解：
> >
> > 【详解】设等差数列 $\{a_{n}\}$ 的公差为 $d$ ，所以 $a_2 = 1 + d, a_3 = 1 + 2d, a_6 = 1 + 5d$
> >
> > 由 $a_2, a_3, a_6$ 成等比数列，所以 $a_3^2 = a_2a_6$ ，所以 $\left(1 + 2d\right)^2 = (1 + d)(1 + 5d)$
> >
> > 即 $d^{2}+2d=0$ ，解得 d=-2 或 0 （舍去），
> >
> > 所以 $a_{n} = 1 + (n - 1)\times (-2) = -2n + 3$
> >
> > 所以 $S_{6} = \frac{6\times\left(a_{1} + a_{6}\right)}{2} = 3\times(1 - 9) = -24$
> >
> > 故选 **A**.
