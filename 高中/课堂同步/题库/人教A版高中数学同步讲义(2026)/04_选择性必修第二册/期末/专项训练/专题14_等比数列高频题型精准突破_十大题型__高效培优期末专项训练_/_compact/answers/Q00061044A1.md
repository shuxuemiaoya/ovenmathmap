> [!faq]- 《专题14_等比数列高频题型精准突破_十大题型__高效培优期末专项训练_》官方解析
>
> > [!success]- **【答案】** (1)证明见解析， $a_{n}=3^{n}+n$ (2) $\frac{3^{n+1}-3+n^{2}+n}{2}$
>
> > [!note]- **【分析】**
> > （1）由题意推得 $a_{n + 1} - (n + 1) = 3(a_n - n)$ ，可得 $\{b_n\}$ 为等比数列，进而求得 $\{a_n\}$ 的通项公式；（2）利用分组求和法，结合等差数列与等比数列的前 $n$ 项和公式即可求解。
>
> > [!note]- **【解析】**
> > （1）由 $a_1 = 4$ ，又 $b_{n} = a_{n} - n$ ，所以 $b_{1} = a_{1} - 1 = 3$
> >
> > 因为 $a_{n+1}=3a_{n}-2n+1, n\in N_{+}$ ，所以 $a_{n+1}-n-1=3a_{n}-3n$ ，
> >
> > 所以 $a_{n + 1} - (n + 1) = 3(a_n - n)$ ，因 $b_{n} = a_{n} - n$ .则 $\frac{b_{n + 1}}{b_n} = 3$
> >
> > 所以数列 $\{b_n\}$ 是首项为 $3$ ，公比为 $3$ 的等比数列，
> >
> > 可得 $b_{n}=3\times3^{n-1}=3^{n},a_{n}=b_{n}+n=3^{n}+n$
> >
> > (2) 由 (1) 知 $a_{n} = 3^{n} + n$ ，记数列 $\{a_{n}\}$ 的前 $n$ 项和为 $S_{n}$ ， $S_{n} = a_{1} + a_{2} + a_{3} + \dots + a_{n}$ $= 3^{1} + 1 + 3^{2} + 2 + \dots + 3^{n} + n$ $= (3^{1} + 3^{2} + \dots + 3^{n}) + (1 + 2 + \dots + n)$ $= \frac{3(1 - 3^{n})}{1 - 3} + \frac{n(n + 1)}{2} = \frac{3^{n+1} - 3 + n^{2} + n}{2}$ .
