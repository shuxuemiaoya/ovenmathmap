> [!faq]- 《专题14_等比数列高频题型精准突破_十大题型__高效培优期末专项训练_》官方解析
>
> > [!success]- **【答案】** AD
>
> > [!note]- **【分析】**
> > 利用等差、等比数列的定义判断各项的正误即可·
>
> > [!note]- **【解析】**
> > 若 $\left\{a_{n}\right\},\left\{b_{n}\right\}$ 的公差分别为u,v，
> >
> > $\left(a_{n + 1} + b_{n + 1}\right) - \left(a_n + b_n\right) = \left(a_{n + 1} - a_n\right) + \left(b_{n + 1} - b_n\right) = u + v$ 为定值，即 $\{a_n + b_n\}$ 为等差数列， $\left(a_{n + 1}b_{n + 1}\right) - \left(a_nb_n\right) = \left(a_n + u\right)\left(b_n + v\right) + a_nb_n = ub_n + va_n + uv$ 不一定为定值，即 $\{a_n\cdot b_n\}$ 不是等差数列，A对，C错，若 $\{a_n\},\{b_n\}$ 的公比分别为 $c,d$ ， $a_{n}\neq 0,b_{n}\neq 0$ ， $\frac{a_{n + 1} + b_{n + 1}}{a_n + b_n} = \frac{ca_n + db_n}{a_n + b_n}$ ，不一定为定值，即 $\{a_n + b_n\}$ 不是等比数列， $\frac{a_{n + 1}b_{n + 1}}{a_nb_n} = \frac{cda_nb_n}{a_nb_n} = cd$ 为定值，即 $\{a_n\cdot b_n\}$ 为等比数列，B错，D对·
> >
> > 故选 **AD**
