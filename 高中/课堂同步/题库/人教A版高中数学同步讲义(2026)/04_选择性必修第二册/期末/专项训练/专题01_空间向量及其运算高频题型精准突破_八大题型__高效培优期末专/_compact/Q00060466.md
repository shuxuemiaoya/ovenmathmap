11. 下列说法中正确的是（ ）
A. $\left|a\right|-\left|b\right|=\left|a+b\right|$ 是 a,b 共线的充分不必要条件
B. 若 $\overline{AB}, \overline{CD}$ 共线，则 AB // CD
C. A, B, C 三点不共线，对空间中任意一点 O，若 $\overline{OP} = \frac{3}{4} \overline{OA} + \frac{1}{8} \overline{OB} + \frac{1}{8} \overline{OC}$ ，则 P, A, B, C 四点共面
D. 若 P, A, B, C 为空间四点，且有 $\overline{PA} = \lambda \overline{PB} + \mu \overline{PC}$ （ $\overline{PB}, \overline{PC}$ 不共线），则 $\lambda + \mu = 1$ 是 A, B, C 三点共线的充要条件
