> [!faq]- 《专题13_等差数列高频题型精准突破_十大题型__高效培优期末专项训练_》官方解析
>
> > [!success]- **【答案】** (1) $a_{n}=n$ (2)7
>
> > [!note]- **【分析】**
> > （1）由等差中项法可判断数列 $\{a_{n}\}$ 是等差数列，再结合 $S_{3} = 6$ 可求公差，最后利用等差数列的通项公式即可；
> >
> > (2)
> > 解法一：先求出 $\frac{1}{b_{n+1}} - \frac{1}{b_n} = 13\left(\frac{1}{n} - \frac{1}{n+1}\right)$ ，再利用累加法求出 $b_n = \frac{n}{2n-13}$ ，最后结合 $b_n + b_{13-n} = 1$ 即可
> >
> > 求出；
> >
> > 解法二：构造数列 $\left\{\frac{1}{b_n} +\frac{13}{n}\right\}$ ，其为各项是 $\frac{1}{b_1} +13 = 2$ 的常数列，求出 $b_{n} = \frac{n}{2n - 13}$ ，其余同法一
>
> > [!note]- **【解析】**
> > （1）因 $S_{n + 2} - S_n = a_{n + 1} + a_{n + 2} = 3a_{n + 1} - a_n\left(n\in \mathbf{N}^*\right)$ ，则 $a_{n + 2} - a_{n + 1} = a_{n + 1} - a_n\left(n\in \mathbf{N}^*\right)$
> >
> > 所以数列 $\{a_{n}\}$ 是首项为 $a_1 = 1$ 的等差数列，
> >
> > 由于 $S_{3} = 3a_{2} = 6$ ，得 $a_2 = 2$ ，则公差为 $a_2 - a_1 = 1$ ，所以 $a_{n} = 1 + n - 1 = n$
> >
> > 则 $\{a_{n}\}$ 的通项公式为 $a_{n} = n$
> >
> > (2)
> > 解法一：由 (1) 知， $a_{n}=n$ ，故 $\frac{1}{b_{n+1}}-\frac{1}{b_{n}}=\frac{13}{n(n+1)}=13\left(\frac{1}{n}-\frac{1}{n+1}\right)$ ，
> >
> > 所以，当 $n$ 2时， $\frac{1}{b_n} -\frac{1}{b_1} = \frac{1}{b_n} -\frac{1}{b_{n - 1}} +\frac{1}{b_{n - 1}} -\frac{1}{b_{n - 2}} +\dots +\frac{1}{b_2} -\frac{1}{b_1} = 13\left(1 - \frac{1}{n}\right)$
> >
> > 又因为 $b_{1} = -\frac{1}{11}$ ，代入化简可得 $b_{n} = \frac{n}{2n - 13}$ （ $n$ 2， $n\in \mathbf{N}^{*}$ ）.
> >
> > 因为 $b_{1} = -\frac{1}{11}$ 也符合上式，所以 $b_{n} = \frac{n}{2n - 13}\left(n\in \mathbf{N}^{*}\right)$
> >
> > 注意到 $b_{n} + b_{13 - n} = \frac{n}{2n - 13} +\frac{13 - n}{2(13 - n) - 13} = 1$
> >
> > 所以 $\left\{b_{n}\right\}$ 的前 13 项和为 $\left(b_{1}+b_{12}\right)+\left(b_{2}+b_{11}\right)+\cdots+\left(b_{6}+b_{7}\right)+b_{13}=6+b_{13}=6+1=7$
> >
> > 解法二：由（1）知， $a_{n} = n$ ，故 $\frac{1}{b_{n + 1}} -\frac{1}{b_n} = \frac{13}{n(n + 1)} = 13\left(\frac{1}{n} -\frac{1}{n + 1}\right)$
> >
> > 即 $\frac{1}{b_{n + 1}} +\frac{13}{n + 1} = \frac{1}{b_n} +\frac{13}{n}$
> >
> > 又因为 $b_{1} = -\frac{1}{11}$ ，所以数列 $\left\{\frac{1}{b_n} +\frac{13}{n}\right\}$ 是各项为 $\frac{1}{b_1} +13 = 2$ 的常数列，即 $\frac{1}{b_n} +\frac{13}{n} = 2$
> >
> > 所以 $b_{n} = \frac{n}{2n - 13}\left(n\in \mathbf{N}^{*}\right)$
> >
> > 注意到 $b_{n} + b_{13 - n} = \frac{n}{2n - 13} +\frac{13 - n}{2(13 - n) - 13} = 1$
> >
> > 所以 $\left\{b_{n}\right\}$ 的前 13 项和为 $\left(b_{1}+b_{12}\right)+\left(b_{2}+b_{11}\right)+\cdots+\left(b_{6}+b_{7}\right)+b_{13}=6+b_{13}=6+1=7$
