> [!faq]- 《专题08_圆的两类高频题型精准突破_九大题型__高效培优期末专项训练_》官方解析
>
> > [!success]- **【答案】** (1) $x+2y-3=0$ ； (2) $x^{2}+y^{2}-6x-16=0$
>
> > [!note]- **【分析】**
> > （1）求出 $AB$ 中点的坐标与直线 $AB$ 的斜率，然后根据垂直平分线的性质算出 $AB$ 的垂直平分线的方程；
> >
> > (2) 设出 $\mathrm{VABC}$ 的外接圆的一般式方程，根据 $A$ 、 $B$ 、 $C$ 的坐标求出 $D$ 、 $E$ 、 $F$ ，即可得到 $\mathrm{VABC}$ 的外接圆的方程。
>
> > [!note]- **【解析】**
> > （1）根据题意，可得 $k_{AB} = \frac{0 - 4}{-2 - 0} = 2$ ，所以 $AB$ 的垂直平分线的斜率 $k = \frac{-1}{k_{AB}} = -\frac{1}{2}$
> >
> > 结合 $AB$ 的中点为 $(-1,2)$ ，可得 $AB$ 的垂直平分线方程为 $y - 2 = -\frac{1}{2}(x + 1)$ ，即 $x + 2y - 3 = 0$ ；
> >
> > (2) 设 VABC 的外接圆的方程为 $x^{2} + y^{2} + Dx + Ey + F = 0 (D^{2} + E^{2} - 4F > 0)$
> >
> > 根据题意，可得 $\left\{ \begin{array}{l}0 + 16 + 4E + F = 0\\ 4 + 0 - 2D + F = 0\\ 64 + 0 + 8D + F = 0 \end{array} \right.$ ，解得 $\left\{ \begin{array}{l}D = -6\\ E = 0\\ F = -16 \end{array} \right.,$
> >
> > 所以VABC的外接圆的方程为 $x^{2} + y^{2} - 6x - 16 = 0.$
