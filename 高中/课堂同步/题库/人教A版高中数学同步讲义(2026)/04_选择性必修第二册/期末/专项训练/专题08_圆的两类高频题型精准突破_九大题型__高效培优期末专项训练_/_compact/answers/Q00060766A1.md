> [!faq]- 《专题08_圆的两类高频题型精准突破_九大题型__高效培优期末专项训练_》官方解析
>
> > [!success]- **【答案】** （1） $\left(-\frac{8}{5},\frac{6}{5}\right)$ ；（2） $x^{2}+y^{2}-(5m+3)x-(15m+4)y=0$ ， $(0,0)$ 和 $\left(\frac{3}{2},-\frac{1}{2}\right)$
>
> > [!note]- **【解析】**
> > (1)设点 $C(x,y)$ ，利用两点之间距离公式和 $^{C}$ 点在线段 $^{OA}$ 上得出关系式： $\sqrt{(x+4)^{2}+(y-3)^{2}}=3$ $y=-\frac{3}{4}x$ 联立求解即可得出点 $^{C}$ 的坐标； $-4 \leq x \leq 0$
> >
> > (2)由题意求出 $D$ 点坐标 $\left(5m + 3,0\right)$ ，设 $\Delta OCD$ 外接圆的一般方程为 $x^{2} + y^{2} + Dx + Ey + F = 0$ 由三点坐标得出关系式 $\left\{ \begin{array}{l} F = 0 \\ \left(5m + 3\right)^{2} + (5m + 3)D + F = 0 \\ 25m^{2} - 4mD + 3mE + F = 0 \end{array} \right.$ ，
> >
> > 联立解得圆的方程 $x^{2} + y^{2} - (5m + 3)x - (15m + 4)y = 0$ ，将圆的方程转化为
> >
> > $\left(x^{2}+y^{2}-3x-4y\right)-5m(x+3y)=0$ ，令 $\left\{\begin{aligned}x^{2}+y^{2}-3x-4y=0\\ x+3y=0\end{aligned}\right.$ 求解即可得出圆过定点的坐标.
> >
> > 【详解】解：（1）设点 $C(x,y)$ ，当 $\left|BD\right| = 3$ 时， $\left|AC\right| = 3$ ，则 $\sqrt{(x + 4)^2 + (y - 3)^2} = 3$
> >
> > 由 $^{C}$ 点在线段 $^{OA}$ 上则有，且，则联立 $\left\{\begin{aligned}\sqrt{(x+4)^{2}+(y-3)^{2}}&=3\\ y&=-\frac{3}{4}x\\ -4&\leq x\leq0\end{aligned}\right.$
> >
> > 解得 $x = -\frac{8}{5}$ ， $y = \frac{6}{5}$ ，则点 C 的坐标为 $\left(-\frac{8}{5}, \frac{6}{5}\right)$ .
> >
> > (2) 由点 C 的坐标为 $(-4m, 3m)(0 < m \leq 1)$ ，可得 $\left|AC\right| = \sqrt{\left(4m - 4\right)^{2} + \left(3m - 3\right)^{2}} = 5\left|m - 1\right| = 5 - 5m$ $\left|OD\right|=8-\left(5-5m\right)=5m+3$ ，可得点D的坐标为 $(5m+3,0)$ ，
> > 设点 $\Delta OCD$ 的外接圆的方程为 $x^{2}+y^{2}+Dx+Ey+F=0$ ，
> >
> > 代入点 、 、 的坐标可得 $\left\{ \begin{array}{l} F = 0 \\ (5m + 3)^2 + (5m + 3)D + F = 0 \\ 25m^2 - 4mD + 3mE + F = 0 \end{array} \right.$ ，解得 $\left\{ \begin{array}{l} D = -5m - 3 \\ E = -15m - 4 \\ F = 0 \end{array} \right.$ ，
> >
> > 可得 $\Delta OCD$ 的外接圆的一般方程为 $x^{2} + y^{2} - (5m + 3)x - (15m + 4)y = 0$
> >
> > 可化为 $\left(x^{2} + y^{2} - 3x - 4y\right) - 5m(x + 3y) = 0$
> >
> > 令 $\left\{ \begin{array}{l}x^{2} + y^{2} - 3x - 4y = 0\\ x + 3y = 0 \end{array} \right.$ ，解得 $\left\{ \begin{array}{l}x = 0\\ y = 0 \end{array} \right.$ 或 $\left\{ \begin{array}{l}x = \frac{3}{2}\\ y = -\frac{1}{2} \end{array} \right.$
> >
> > 故 $\Delta OCD$ 的外接圆所过定点的坐标为 $(0,0)$ 和 $\left(\frac{3}{2}, -\frac{1}{2}\right)$ .
