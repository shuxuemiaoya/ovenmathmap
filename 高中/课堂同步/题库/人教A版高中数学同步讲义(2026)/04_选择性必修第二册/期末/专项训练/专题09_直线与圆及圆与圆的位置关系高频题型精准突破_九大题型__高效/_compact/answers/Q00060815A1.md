> [!faq]- 《专题09_直线与圆及圆与圆的位置关系高频题型精准突破_九大题型__高效》官方解析
>
> > [!success]- **【答案】** C
>
> > [!note]- **【分析】**
> > 先设出点 P 的坐标，根据 $\left|PO\right|^{2}+\left|PA\right|^{2}=20$ 得出点 P 的轨迹方程，再根据圆与圆的位置关系求出实数 a 的取值范围.
>
> > [!note]- **【解析】**
> > 设点 $P(x,y)$ ，因为 O 为坐标原点 $(0,0)$ ， $A(0,2)$ ，且 $\left|PO\right|^{2}+\left|PA\right|^{2}=20$ 。
> >
> > 根据两点间距离公式，则 $\left|PO\right|^2 = x^2 +y^2$ ， $\left|PA\right|^2 = x^2 +(y - 2)^2.$
> >
> > 所以 $x^{2} + y^{2} + x^{2} + (y - 2)^{2} = 20$ ，展开整理可得： $x^{2} + (y - 1)^{2} = 9$ 所以点 $P$ 的轨迹是以 $Q(0,1)$ 为圆心， $r = 3$ 为半径的圆·
> > 已知圆 $(x - a)^2 + (y - a + 4)^2 = 1$ ，其圆心为 $M(a, a - 4)$ ，半径 $R = 1$ ·
> > 因为圆 $(x - a)^2 + (y - a + 4)^2 = 1$ 上存在点 $P$ 满足条件，所以两圆有公共点·
> > 根据两圆位置关系，两圆的圆心距 $d = \sqrt{(a - 0)^2 + [(a - 4) - 1]^2} = \sqrt{a^2 + (a - 5)^2}$ ．
> > 两圆有公共点，则 $|r - R| \leq d \leq r + R$ ，即 $|3 - 1| \leq \sqrt{a^2 + (a - 5)^2} \leq 3 + 1$ ．
> > 对于 $2 \leq \sqrt{a^2 + (a - 5)^2}$ ，两边平方得 $4 \leq a^2 + (a - 5)^2$ ，展开整理得， $2a^2 - 10a + 21\quad 0$ ，因为 $\Delta = (-10)^2 - 4 \times 2 \times 21 = -68 < 0$ ，函数图象开口向上，所以 $2a^2 - 10a + 21\quad 0$ 恒成立·
> > 对于 $\sqrt{a^2 + (a - 5)^2} \leq 3 + 1$ ，两边平方得 $a^2 + (a - 5)^2 \leq 16$ ，即 $2a^2 - 10a + 9 \leq 0$ ，
> > 解得 $\frac{5 - \sqrt{7}}{2} \leq a \leq \frac{5 + \sqrt{7}}{2}$ ．
> > 综上可得实数 $a$ 的取值范围为 $\left[\frac{5 - \sqrt{7}}{2}, \frac{5 + \sqrt{7}}{2}\right]$ ．
> >
> > 故选 **C**.
