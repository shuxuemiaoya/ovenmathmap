> [!faq]- 《专题09_直线与圆及圆与圆的位置关系高频题型精准突破_九大题型__高效》官方解析
>
> > [!success]- **【答案】** BCD
>
> > [!note]- **【分析】**
> > 利用圆与圆的位置关系可判断 $^{A}$ 选项；当a=6时，判断出两圆相交，将两圆方程作差可得相交弦所在直线的方程，可判断 $^{B}$ 选项；利用圆的几何性质可判断 $^{C}$ 选项；利用平面向量的运算性质可计算得出 $\left|C_{1}P\right|=\sqrt{2}$ ，可得出点P的轨迹方程为 $(x-3)^{2}+(y+2)^{2}=2$ ，由此得出 $x-y+b=0$ 与圆 $(x-3)^{2}+(y+2)^{2}=2$ 有公共点，利用直线与圆的位置关系求出b的范围，可判断 $^{D}$ 选项.
>
> > [!note]- **【解析】**
> > 圆 $C_{1}$ 的圆心为 $C_{1}(3,-2)$ ，半径为 $r_{1}=1$
> >
> > 圆 $C_2$ 的标准方程为 $\left(x - 7\right)^2 +\left(y + a\right)^2 = 36$ ，圆心为 $C_2(7, - a)$ ，半径为 $r_2 = 6\cdot$
> >
> > 对于 $\mathsf{A}$ 选项，若圆 $C_1$ 与圆 $C_2$ 内切，则 $\left|C_1C_2\right| = \left|r_2 - r_1\right| = 5$
> >
> > 即 $\left|C_{1}C_{2}\right|=\sqrt{(3-7)^{2}+\left(-2+a\right)^{2}}=5$ ，解得 a=-1 或 5，A 错；
> >
> > 对于 $\mathsf{B}$ 选项，当 $a = 6$ 时，圆 $C_2$ 的圆心为 $C_2(7, - 6)$
> >
> > 则 $\left|C_1C_2\right| = \sqrt{(3 - 7)^2 + (-2 + 6)^2} = 4\sqrt{2}$ ，此时 $\left|r_2 - r_1\right| <   \left|C_1C_2\right| <   r_1 + r_2$ ，则圆 $C_1$ 与圆 $C_2$ 相交，
> >
> > 圆 $C_{1}$ 的一般方程为 $x^{2} + y^{2} - 6x + 4y + 12 = 0$
> >
> > 圆 $C_2$ 的一般方程为 $x^{2} + y^{2} - 14x + 12y + 49 = 0$
> >
> > 将两圆方程作差并化简得 $8x - 8y - 37 = 0$
> >
> > 即两圆公共弦所在直线的方程为 8x - 8y - 37 = 0 ，B 对；
> >
> > 对于 C 选项，因为 $\left(0-3\right)^{2}+\left(0+2\right)^{2}=13>1$ ，即原点 O 在圆 $C_{1}$ 外，所以 $m^{2}+n^{2}=\left|OP\right|^{2}$
> >
> > 由圆的几何性质可得 $\left|OP\right|_{\max}=\left|OC_{1}\right|+1=\sqrt{3^{2}+\left(-2\right)^{2}}+1=\sqrt{13}+1$
> >
> > 故 $m^{2}+n^{2}$ 的最大值为 $(\sqrt{13}+1)^{2}=14+2\sqrt{13}$ ，C对；
> >
> > 对于 D 选项，由题意可知 $\left|\overline{C_{1}M}\right|=\left|\overline{C_{1}N}\right|=1$
> >
> > 因为 $NM = C_1M - C_1N$ ， $C_1M + C_1N = C_1P$
> >
> > $$
> > \left| C _ {1} P \right| ^ {2} + \left| N M \right| ^ {2} = \left(C _ {1} M + C _ {1} N\right) ^ {2} + \left(C _ {1} M - C _ {1} N\right) ^ {2} = 2 \left(\left| C _ {1} M \right| ^ {2} + \left| C _ {1} N \right| ^ {2}\right) = 4
> > $$
> >
> > 因为 $\left|\overline{NM}\right|=\sqrt{2}$ ，故 $\left|\overline{C_{1}P}\right|=\sqrt{2}$ ，故点 P 的轨迹方程为 $(x-3)^{2}+(y+2)^{2}=2$ ，
> >
> > 圆 $(x - 3)^2 +(y + 2)^2 = 2$ 的圆心为 $C_1(3, - 2)$ ，半径为 $r = \sqrt{2}$
> >
> > 由题意可知，直线 $x - y + b = 0$ 与圆 $(x - 3)^2 +(y + 2)^2 = 2$ 有公共点，
> >
> > 则 $\frac{|3 + 2 + b|}{\sqrt{2}} = \frac{|b + 5|}{\sqrt{2}} \leq \sqrt{2}$ ，即 $|b + 5| \leq 2$ ，解得 $-7 \leq b \leq -3$ ， $D$ 对·
> >
> > 故选 **BCD**.
