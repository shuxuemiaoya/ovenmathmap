> [!faq]- 《专题07 直线交点坐标与各种距离高频题型精准突破（九大题型）（高效培优期末专项训练）》官方解析
>
> > [!success]- **【答案】** A. $\sqrt{2}$ B. $\sqrt{3}$ C. 2 D. $\sqrt{5}$
>
> > [!note]- **【分析】**
> > 令 $a = \left|x_{1} - x_{2}\right|, b = \left|y_{1} - y_{2}\right|$ ，根据题意可化为二次函数，即可求出结果
>
> > [!note]- **【解析】**
> > 根据题意，直角距离 $d(A, B) = |x_1 - x_2| + |y_1 - y_2| = 2$
> >
> > 令 $a = \left|x_{1} - x_{2}\right|, b = \left|y_{1} - y_{2}\right|$ ，则 $a + b = 2$ ， $a, b = 0$
> >
> > 线段 $AB$ 长度 $L = \sqrt{\left(x_{1} - x_{2}\right)^{2} + \left(y_{1} - y_{2}\right)^{2}} = \sqrt{a^{2} + b^{2}}$ ，由 $a + b = 2$ ，得 $b = 2 - a$ ，代入得： $L = \sqrt{a^2 + (2 - a)^2} = \sqrt{2a^2 - 4a + 4} = \sqrt{2(a - 1)^2 + 2}$
> >
> > 当 $a = 1$ 时， $L$ 取最小值为 $\sqrt{2}$ ，此时 $a = b = 1$ ，即 $\left|x_{1} - x_{2}\right| = 1, \left|y_{1} - y_{2}\right| = 1$ ，满足条件。
> >
> > 故选 **A**
