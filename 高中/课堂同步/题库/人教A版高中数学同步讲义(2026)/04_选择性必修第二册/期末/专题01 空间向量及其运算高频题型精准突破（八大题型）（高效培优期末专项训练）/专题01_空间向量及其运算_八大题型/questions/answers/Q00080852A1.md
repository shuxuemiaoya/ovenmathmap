> [!faq]- 《专题01 空间向量及其运算高频题型精准突破（八大题型）（高效培优期末专项训练）》官方解析
>
> > [!success]- **【答案】** B
>
> > [!note]- **【分析】**
> > 利用向量的加减法则，将 $\overline{EF}$ 逐步转化为已知向量 $a$ 、 $b$ 、 $c$ 的线性组合
>
> > [!note]- **【解析】**
> > ∵ E 是 CD 的中点，∴ $\overline{EC} = \frac{1}{2} \overline{DC}$ ，又 $\overline{AF} = \frac{2}{3} \overline{AB}$
> >
> > $$
> > \therefore E F = E C + C F = \frac {1}{2} D C + C A + A F = \frac {1}{2} (D A + A C) + C A + A F = \frac {1}{2} (D A + A C) + C A + \frac {2}{3} A B
> > $$
> >
> > $$
> > \underset {A D = a} {\text {   }} \underset {A B = b, A C = c} {\text {   }} \text {   } \therefore \underset {E F} {\text {   }} = \frac {1}{2} \left(\underset {D A + A C} {\text {   }} + \underset {C A} {\text {   }} + \frac {2}{3} \underset {A B} {\text {   }} = \frac {1}{2} (- a + c) + (- c) + \frac {2}{3} b = - \frac {1}{2} a + \frac {2}{3} b - \frac {1}{2} c\right)
> > $$
> >
> > 故选 **B**·
