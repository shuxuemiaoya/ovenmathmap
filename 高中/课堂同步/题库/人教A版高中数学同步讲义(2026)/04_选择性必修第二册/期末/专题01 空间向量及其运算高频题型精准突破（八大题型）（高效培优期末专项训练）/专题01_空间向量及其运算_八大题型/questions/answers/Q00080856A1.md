> [!faq]- 《专题01 空间向量及其运算高频题型精准突破（八大题型）（高效培优期末专项训练）》官方解析
>
> > [!success]- **【答案】** A. $\left|a\right|-\left|b\right|=\left|a+b\right|$ 是 a,b 共线的充分不必要条件 B. 若 $\overline{AB}, \overline{CD}$ 共线，则 AB // CD C. A, B, C 三点不共线，对空间中任意一点 O，若 $\overline{OP} = \frac{3}{4} \overline{OA} + \frac{1}{8} \overline{OB} + \frac{1}{8} \overline{OC}$ ，则 P, A, B, C 四点共面 D. 若 P, A, B, C 为空间四点，且有 $\overline{PA} = \lambda \overline{PB} + \mu \overline{PC}$ （ $\overline{PB}, \overline{PC}$ 不共线），则 $\lambda + \mu = 1$ 是 A, B, C 三点共线的充要条件
>
> > [!note]- **【分析】**
> > 由向量数量积运算律及共线判定，结合充分必要性定义判断 $^{A}$ ，利用AB,CD共线，则直线AB，
> > CD 可能重合判断 $^{B}$ ，利用四点共面的结论判断 $^{C}$ ，由向量线性运算及共线判定，结合充分必要性定义判断D.
>
> > [!note]- **【解析】**
> > 对于 A：由 $\left(\left|a\right|-\left|b\right|\right)^{2}=\left|a+b\right|^{2}\Rightarrow2\left|a\right|\left|b\right|=2a\cdot b\Rightarrow\cos a,b=1$
> >
> > 此时 a，b 共线，充分性成立，
> >
> > 若 $a$ ， $b$ 同向共线，且 $\left|a\right| <   \left|b\right|$ ，则 $\left|a\right| - \left|b\right| <   0$ ，显然 $\left|a\right| - \left|b\right| = \left|a + b\right|$ 不成立，
> >
> > 必要性不成立，
> >
> > 所以“ $\left|a\right|-\left|b\right|=\left|a+b\right|$ ”是“a,b共线”的充分不必要条件，故 $^{A}$ 正确；
> >
> > 对于 B：若 $\overline{AB, CD}$ 共线，则直线 AB，CD 可能重合，故 B 错误；
> >
> > 对于C：由 $\frac{3}{4} +\frac{1}{8} +\frac{1}{8} = 1$ ，且 $OP = \frac{3}{4} OA + \frac{1}{8} OB + \frac{1}{8} OC$
> >
> > 根据空间向量共面的推论知 $P, A, B, C$ 四点共面，故 $\mathbb{C}$ 正确；对于 $\mathbb{D}: \overline{PA} = \overline{\lambda PB} + \overline{\mu PC}$ （ $\overline{PB}, \overline{PC}$ 不共线），若 $\lambda + \mu = 1$ 则 $\overline{PA} = \lambda \overline{PB} + (1 - \lambda)\overline{PC} = \overline{PC} + \lambda (\overline{PB} - \overline{PC})$ ，所以 $\overline{PA} - \overline{PC} = \lambda (\overline{PB} - \overline{PC})$
> >
> > 即 $\overline{CA} = \lambda \overline{CB}$ ，所以 A, B, C 三点共线，反之也成立，
> >
> > 所以 $\lambda + \mu = 1$ 是 A, B, C 三点共线的充要条件，（本选项也可用三点共线的推论）故 D 正确。
> >
> > 故选 **ACD**
