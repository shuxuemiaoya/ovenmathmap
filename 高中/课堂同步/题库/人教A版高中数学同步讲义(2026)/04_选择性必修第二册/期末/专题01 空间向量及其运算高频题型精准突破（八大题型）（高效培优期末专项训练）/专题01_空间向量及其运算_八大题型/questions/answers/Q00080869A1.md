> [!faq]- 《专题01 空间向量及其运算高频题型精准突破（八大题型）（高效培优期末专项训练）》官方解析
>
> > [!success]- **【答案】** A. $a - b + c$ , $b + c$ , a - c B. $a + b$ , $c + 2b$ , 2a - c C. $2a - b$ , $2c + b$ , $a + c$ D. $a + b$ , $2a + b + c$ , c - b
>
> > [!note]- **【分析】**
> > 根据空间向量基底的判定，即向量组是否共面，若不共面则构成空间的一组基底·
>
> > [!note]- **【解析】**
> > 设 $a - b + c = x(b + c) + y(a - c)$ ，即 $a - b + c = xb + ya + (x - y)c$ ，∴ $\left\{\begin{aligned}y &= 1 \\ x &= -1 \\ x &= -y = 1\end{aligned}\right.$ ，此方程组无解，
> >
> > ∴ $a - b + c$ ， $b + c$ ，a - c 不共面，可构成基底，∴ A 正确.
> >
> > 设 $a + b = x(2b + c) + y(2a - c)$ ，即 $a + b = 2xb + 2ya + (x - y)c$ ， $\therefore \left\{\begin{aligned}&2y=1\\ &2x=1\\ &x-y=0\end{aligned}\right. \Rightarrow\left\{\begin{aligned}x=\frac{1}{2}\\ &y=\frac{1}{2}\end{aligned}\right.$ ，此方程组有解，
> >
> > ∴ $a + b$ ， $c + 2b$ ，2a - c 共面，不可构成基底，∴ B 错误
> >
> > 设 $2a - b = x(b + 2c) + y(a + c)$ ，即 $2a - b = xb + ya + (2x + y)c$ ， $\therefore \left\{\begin{aligned}y &= 2 \\ x &= -1 \\ 2x &= y = 0\end{aligned}\right. \Rightarrow \left\{\begin{aligned}x &= -1 \\ y &= 2\end{aligned}\right.$ ，此方程组有解，
> >
> > ∴ 2a - b ， $2c + b$ ， a + c 共面，不可构成基底，∴ C 错误
> >
> > 设 $a + b = x(2a + b + c) + y(c - b)$ ，即 $a + b = 2xa + (x - y)b + (x + y)c$ ，∴ $\left\{\begin{aligned}x + y &= 0 \\ 2x &= 1 \\ x - y &= 1\end{aligned}\right.$ ，此方程组有解，$a+b$ ， $2a+b+c$ ，c-b 共面，不可构成基底，∴D错误
> >
> > 故选 **A**·
