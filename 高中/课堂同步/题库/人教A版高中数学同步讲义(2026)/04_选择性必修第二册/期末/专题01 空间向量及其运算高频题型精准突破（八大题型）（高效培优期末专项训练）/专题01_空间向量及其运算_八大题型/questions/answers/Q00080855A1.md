> [!faq]- 《专题01 空间向量及其运算高频题型精准突破（八大题型）（高效培优期末专项训练）》官方解析
>
> > [!success]- **【答案】** A. 将空间中所有的单位向量平移到同一个点为起点，则它们的终点构成一个圆 B. 若空间向量 a, b 满足 $\left|a\right|=\left|b\right|$ ，则 a=b 或 a=-b； C. 若空间向量 a, b, c 满足 a = b, b = c，则 a = c； D. 若空间向量 m, n, p 满足 m // n, n // p，则 m // p。
>
> > [!note]- **【分析】**
> > 根据单位向量的性质可判断 $^{A}$ 的正误，根据相等向量的定义可判断 $^{BC}$ 的正误，根据零向量的性质可判断 $^{D}$ 的正误·
>
> > [!note]- **【解析】**
> > 对于 $A$ ，根据空间向量的定义，空间中所有的单位向量平移到同一个点为起点，
> >
> > 则它们的终点构成一个球面，所以 $^{A}$ 错误；
> >
> > 对于 B，若空间向量 a，b 满足 $\left|a\right|=\left|b\right|$
> >
> > 但由于它们的方向不一定相同或相反，故 $a, b$ 不一定相等或相反，所以 ${}^{\mathrm{B}}$ 错误；
> >
> > 对于 $C$ ，根据向量相等的定义可得 $a = c$ ，所以 $C$ 正确；
> >
> > 对于 $^{D}$ ，向量的平行不具有传递性，比如当n为零向量时，零向量与任何向量都平行，则 $m,p$ 不一定平行，所以 $^{D}$ 错误。
> >
> > 故选 **C**.
