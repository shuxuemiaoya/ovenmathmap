> [!faq]- 《专题01 空间向量及其运算高频题型精准突破（八大题型）（高效培优期末专项训练）》官方解析
>
> > [!success]- **【答案】** B
>
> > [!note]- **【分析】**
> > 根据共面向量定理一一计算判断即可·
>
> > [!note]- **【解析】**
> > 对 $^{A}$ ，假设 $a = x(a + b) + y(a - c)$ ，即 $a = (x + y)a + xb - yc$ ，
> > 则 $\left\{\begin{aligned}x+y&=1\\ x&=0\\ -y&=0\end{aligned}\right.$ ，显然无实数解，则与向量不共面，故 $^{A}$ 错误；
> >
> > 对 B，因为 $b + c = (a + b) - (a - c)$ ，所以 $a + b, a - c, b + c$ 共面，故 B 正确；
> > 对 C，假设 $b-c=m(a+b)+n(a-c)$ ，即 $b-c=(m+n)a+mb-nc$ ，
> >
> > 则 $\left\{ \begin{array}{l}m + n = 0\\ m = 1\\ -n = -1 \end{array} \right.$ ，显然无实数解，则与向量不共面，故C错误；
> >
> > 对 $\mathsf{D}$ ，假设 $a + b + c = s(a + b) + t(a - c)$ ，即 $a + b + c = (s + t)a + sb - tc$ ，则 $\left\{ \begin{array}{ll}s + t = 1\\ s = 1\\ -t = 1 \end{array} \right.$ ，显然无实数解，则与向量不共面，故 $\mathsf{D}$ 错误；
> >
> > 故选 **B**.
