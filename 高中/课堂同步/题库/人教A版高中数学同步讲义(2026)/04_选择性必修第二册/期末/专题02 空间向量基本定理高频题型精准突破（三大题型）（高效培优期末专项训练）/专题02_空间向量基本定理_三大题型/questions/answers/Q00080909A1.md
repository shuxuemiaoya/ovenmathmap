> [!faq]- 《专题02 空间向量基本定理高频题型精准突破（三大题型）（高效培优期末专项训练）》官方解析
>
> > [!success]- **【答案】** A．若空间中的 O, A, B, C，满足 OC = 1/3 OA + 2/3 OB，则 A, B, C 三点共线 B．空间中三个向量 a, b, c，若 a 与 b 不共线，则 a, b, c 不共面 C．对空间任意一点 O 和不共线的三点 A, B, C，若 OP = 2OA + 2022OB - 2023OC，则 P, A, B, C 四点共面 D．{a, b, c} 是空间的一组基底，若 m = a + b, n = a - b，则 {m, n, c} 能为空间的一组基底
>
> > [!note]- **【分析】**
> > 化简得 AC = 2/3 AB，可判定 A 正确；结合 a = (0, 0, 1), b = (1, 1, 0), c = (1, 1, 1)，可判定 B 错误；化简得 CP = 2CA + 2022CB，可判定 C 正确；设 c = xm + yn，得到 c = (x + y)a + (x - y)b，得到 a, b, c 与 {a, b, c} 是空间的一组基底矛盾，可判定 D 正确。
>
> > [!note]- **【解析】**
> > 对于 A，由 OC = 1/3 OA + 2/3 OB，可得 OC - OA = 2/3 OB - 2/3 OA，即 AC = 2/3 AB，
> > 所以 A, B, C 三点共线，所以 A 正确；
> > 对于 B，例如：向量 a = (0, 0, 1), b = (1, 1, 0)，可得向量 a, b 不共线，
> > 若 c = (1, 1, 1)，则 c = a + b，此时向量 a, b, c 共面，所以 B 不正确；
> > 对于 C，由 OP = 2OA + 2022OB - 2023OC，可得 OP - OC = 2OA + 2022OB - 2024OC，
> > 则 CP = 2(OA - OC) + 2022(OB - OC) = 2CA + 2022CB
> >
> > 所以 P, A, B, C 四点共面，所以 C 正确；
> >
> > 对于 D，若向量 m, n, c 共面，则存在实数 x, y，使得 $c = xm + yn$ ，
> >
> > 因为 $m = a + b, n = a - b$ ，可得 $c = x(a + b) + y(a - b) = (x + y)a + (x - y)b$
> >
> > 则向量 $a, b, c$ 共面，这与 $\{a, b, c\}$ 是空间的一组基底矛盾，
> >
> > 所以 $\{m, n, c\}$ 可以构成一个空间基底，所以 $^D$ 正确.
> >
> > 故选 **ACD**.
