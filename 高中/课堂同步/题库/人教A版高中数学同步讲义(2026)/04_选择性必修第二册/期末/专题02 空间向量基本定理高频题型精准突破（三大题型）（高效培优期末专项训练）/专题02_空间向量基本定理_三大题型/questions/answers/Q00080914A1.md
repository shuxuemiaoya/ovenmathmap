> [!faq]- 《专题02 空间向量基本定理高频题型精准突破（三大题型）（高效培优期末专项训练）》官方解析
>
> > [!success]- **【答案】** C
>
> > [!note]- **【分析】**
> > 逐一判断选项中的向量是否与 $m,n$ 共面即可，如果不共面就符合题意·
>
> > [!note]- **【解析】**
> > 由题意知，a, b, c 不共面，对于选项 A， $a=\frac{1}{2}[(a+b)+(a-b)]=\frac{1}{2}m+\frac{1}{2}n$ ，故 $a,m,n$ 共面，排除 A；
> >
> > 对于选项 B， $b=\frac{1}{2}[(a+b)-(a-b)]=\frac{1}{2}m-\frac{1}{2}n$ ，故 b, m, n 共面，排除 B；
> >
> > 对于选项 D，由选项 A 得， $2a = m + n$ ，故 2a, m, n 共面，排除 D。
> >
> > 对于 C， $\forall x,y\in R$ ，向量 $xm+yn=(x+y)a+(x-y)b$ ，而 c 不与 a,b 共面，故 C 正确.
> >
> > 故选 **C**.
