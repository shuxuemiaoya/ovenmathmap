> [!faq]- 《专题02 空间向量基本定理高频题型精准突破（三大题型）（高效培优期末专项训练）》官方解析
>
> > [!success]- **【答案】** A. $\{a + c, a - b, b + c\}$ B. $\{c, a + b, a - b\}$ C. $\{a, a + b, -5b\}$ D. $\{\overrightarrow{a + b}, \overrightarrow{a + b + c}, \frac{1}{3}c\}$
>
> > [!note]- **【分析】**
> > 通过证明 $^{ACD}$ 选项中的三个向量共面，判断它们错误，利用反证法证明 $^{B}$ 选项中的三个向量不共面，判断 $^{B}$ 正确·
>
> > [!note]- **【解析】**
> > 对于 A，因为 $a+c-(a-b)=b+c$ ，所以 $a+c, a-b, b+c$ 共面，
> > 所以 $\left\{a+c,a-b,b+c\right\}$ 不能构成基底，
> > 对于 C，因为 $-5b = 5a - 5(a + b)$ 所以 $a, a + b, -5b$ 共面，所以 $\left\{a, a + b, -5b\right\}$ 不能构成基底，C 错误；
> > 对于 D， $\frac{1}{3}c=\frac{1}{3}(a+b+c)-\frac{1}{3}(a+b)$ 所以 $a+b, a+b+c, \frac{1}{3}c$ 共面，所以 $\left\{a+b, a+b+c, \frac{1}{3}c\right\}$ 不能构成基底，D 错误，
> > 对于 B，若 $c, a + b, a - b$ 共面，
> > 则可设 $c = x(a + b) + y(a - b)$ ，故 $c = (x + y)a + (x - y)b$ 故 a, b, c 共面，与条件矛盾，
> > 所以 c, a + b, a - b 不共面，即 $\left\{c, a + b, a - b\right\}$ 能构成基底，B 正确；
> >
> > 故选 **B**.
