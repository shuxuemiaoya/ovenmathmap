> [!faq]- 《专题02 空间向量基本定理高频题型精准突破（三大题型）（高效培优期末专项训练）》官方解析
>
> > [!success]- **【答案】** C
>
> > [!note]- **【分析】**
> > 由题意得到 $\sqcup_{e_1,e_2,e_3}$ 共面，再由共面定理得到关于 的方程组 $\left\{ \begin{array}{l} 2x + 2y = 1 \\ ax + 4y = 1 \\ x + by = 0 \end{array} \right.$ 有解，逐一检验各选项
> >
> > 即可求解·
>
> > [!note]- **【解析】**
> > 若 $e_1, e_2, e_3$ 不能构成空间向量的一组基底，
> >
> > 则 $e_1, e_2, e_3$ 共面，则 $\exists x, y \in \mathbb{R}$ ，使得 $e_1 = xe_2 + ye_3$
> >
> > 即 $(1,1,0)=x(2,a,1)+y(2,4,b)=(2x+2y,ax+4y,x+by)$
> >
> > 则关于 的方程组 $\left\{\begin{aligned}&2x+2y=1\\ &ax+4y=1\\ &x+by=0\end{aligned}\right.$ 有解，
> >
> > 当时，方程组为 $\left\{ \begin{array}{l} 2x + 2y = 1 \\ \sqrt{3} x + 4y = 1 \\ x = 0 \end{array} \right.$ ，无解，故A错误；
> >
> > 当时，方程组为 $\left\{ \begin{array}{l}2x + 2y = 1\\ 4x + 4y = 1\\ x + \sqrt{2} y = 0 \end{array} \right.$ ，无解，故B错误；
> > 当时，方程组为 $\left\{ \begin{array}{l}2x + 2y = 1\\ 3x + 4y = 1\Rightarrow \left\{ \begin{array}{l}x = 1\\ y = -\frac{1}{2} \end{array} \right.,\text{故}^{\mathrm{C}}\text{正确；}\right.$ 当时，方程组为 $\left\{ \begin{array}{l}2x + 2y = 1\\ 3x + 4y = 1\\ x + y = 0 \end{array} \right.$ ，无解，故D错误；
> >
> > 故选 **C**
