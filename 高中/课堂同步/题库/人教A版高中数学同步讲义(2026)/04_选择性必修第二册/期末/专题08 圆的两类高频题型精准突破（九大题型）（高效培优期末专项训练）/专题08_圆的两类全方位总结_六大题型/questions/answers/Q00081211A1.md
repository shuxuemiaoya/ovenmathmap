> [!faq]- 《专题08 圆的两类高频题型精准突破（九大题型）（高效培优期末专项训练）》官方解析
>
> > [!success]- **【答案】** （Ⅰ） $x^{2}+y^{2}+2x-1=0$ ；（Ⅱ） $(0,1),(-2,1)$
>
> > [!note]- **【解析】**
> > （Ⅰ）设圆 C 的方程为 $x^{2} + y^{2} + Dx + Ey + F = 0$ ，令 y = 0 得 $x^{2} + Dx + F = 0$ ，与
> >
> > $f(x) = x^{2} + 2x + b = 0$ 是同一方程，可求得 $D,F$
> >
> > 再令 x=0 得 $y^{2}+Ey+F=0$ ，因为方程 $f(x)=x^{2}+2x+b=0$ 有一根为 b，代入可得 E，再将 b=-1 代入即可.
> >
> > (Ⅱ) 根据由 (Ⅰ) 圆 C 的方程为 $x^{2} + y^{2} + 2x + (-b - 1)y + b = 0$ ，转化为：
> >
> > $x^{2} + y^{2} + 2x - y - (y - 1)b = 0$ ，令 $\left\{ \begin{array}{l} x^2 + y^2 + 2x - y = 0 \\ y - 1 = 0 \end{array} \right.$ 求解
> >
> > 【详解】（Ⅰ）设圆 C 的方程为 $x^{2} + y^{2} + Dx + Ey + F = 0$
> >
> > 令 y=0 得 $x^{2}+Dx+F=0$ ，与 $f(x)=x^{2}+2x+b=0$ 是同一方程，
> >
> > 所以 $D = 2, F = b$
> >
> > 令 x=0 得 $y^{2}+Ey+F=0$ ，方程 $f(x)=x^{2}+2x+b=0$ 有一根为 b，
> >
> > 所以 $E = -b - 1$
> >
> > 所以圆 C 的方程为 $x^{2} + y^{2} + 2x + (-b - 1)y + b = 0$
> >
> > 当 $b = -1$ 时，圆 $\mathbb{C}$ 的方程为 $x^{2} + y^{2} + 2x - 1 = 0$
> >
> > (Ⅱ) 由 (Ⅰ) 知，圆 C 的方程为 $x^{2} + y^{2} + 2x + (-b - 1)y + b = 0$
> >
> > 转化为： $x^{2} + y^{2} + 2x - y - (y - 1)b = 0$
> >
> > 令 $\left\{ \begin{array}{l}x^{2} + y^{2} + 2x - y = 0\\ y - 1 = 0 \end{array} \right.$
> >
> > 解得 $\left\{\begin{aligned}x&=0\\ y&=1\end{aligned}\right.$ 或 $\left\{\begin{aligned}x&=-2\\ y&=1\end{aligned}\right.$
> >
> > 故圆 C 经过定点 $(0,1)$ , $(-2,1)$ .
