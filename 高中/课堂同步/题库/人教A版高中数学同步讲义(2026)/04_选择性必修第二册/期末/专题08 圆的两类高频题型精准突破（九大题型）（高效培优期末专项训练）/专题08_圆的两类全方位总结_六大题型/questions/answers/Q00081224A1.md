> [!faq]- 《专题08 圆的两类高频题型精准突破（九大题型）（高效培优期末专项训练）》官方解析
>
> > [!success]- **【答案】** (1) $x^{2}+\left(y-5\right)^{2}=9$ (2) $\left[82 - 6\sqrt{73}, 82 + 6\sqrt{73}\right]$ (3) $[5,35]$
>
> > [!note]- **【分析】**
> > （1）设圆心为 $C(0,b)(b > 0)$ ，根据条件建立方程为 $\frac{|0 - 9b|}{\sqrt{12^2 + 9^2}} = 3$ ，求出 $b$ ，即可求解；
> >
> > (2) 将问题转化成 $M(x,y)$ 与 $P(-3,-3)$ 距离的平方，再利用圆的性质，即可求解；
> >
> > (3) 利用圆的参数方程， $x = 3\cos\theta, y = 5 + 3\sin\theta$ ，结合条件，利用辅助角公式得
> >
> > $3x + 4y = 15\sin(\theta + \varphi) + 20$ ，即可求解.
>
> > [!note]- **【解析】**
> > （1）设圆心为 $C(0,b)(b > 0)$ ，由题有 $\frac{|0 - 9b|}{\sqrt{12^2 + 9^2}} = 3$ ，解得 $b = 5$
> >
> > 所以圆 C 的标准方程为 $x^{2} + (y - 5)^{2} = 9$ .
> >
> > (2) 因为 $(x+3)^{2}+(y+3)^{2}$ 表示 $M(x,y)$ 与 $P(-3,-3)$ 距离的平方，
> >
> > 由（1）知 $C(0,5)$ ，则 $\left|CP\right| = \sqrt{3^2 + (5 + 3)^2} = \sqrt{73}$
> >
> > 所以 $\sqrt{73}-3\leq\left|MP\right|\leq\sqrt{73}+3$ ，则 $82-6\sqrt{73}\leq\left|MP\right|^{2}\leq82+6\sqrt{73}$
> >
> > 所以 $(x+3)^{2}+(y+3)^{2}$ 的取值范围为 $\left[82-6\sqrt{73},82+6\sqrt{73}\right]$ .
> >
> > (3) 令 $x = 3\cos \theta, y = 5 + 3\sin \theta$
> >
> > 则 $3x + 4y = 9\cos \theta +12\sin \theta +20 = 15\sin (\theta +\varphi) + 20$ ，其中 $\tan \varphi = \frac{3}{4}$
> >
> > 所以 $5 \leq 3x + 4y \leq 35$ .
