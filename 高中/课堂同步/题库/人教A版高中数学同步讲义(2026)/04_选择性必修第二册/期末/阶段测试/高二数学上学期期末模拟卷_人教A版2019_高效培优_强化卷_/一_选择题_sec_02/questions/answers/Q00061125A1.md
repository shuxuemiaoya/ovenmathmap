> [!faq]- 《高二数学上学期期末模拟卷_人教A版2019_高效培优_强化卷_》官方解析
>
> > [!success]- **【答案】** A
>
> > [!note]- **【解析】**
> > 圆 $C_1: x^2 + y^2 = a$ ，圆心为 $C_1(0,0)$ ，半径 $r_1 = \sqrt{a}$
> >
> > 圆 $C_2: x^2 + y^2 + bx + cy - 1 = 0$ 的标准方程为 $\left(x + \frac{b}{2}\right)^2 + \left(y + \frac{c}{2}\right)^2 = \frac{b^2}{4} + \frac{c^2}{4} + 1$
> >
> > 圆心为 $C_2\left(-\frac{b}{2}, - \frac{c}{2}\right)$ ，半径 $r_2 = \sqrt{\frac{b^2}{4} + \frac{c^2}{4} + 1}$
> >
> > 由题可知 $C_{1}(0,0)$ 与 $C_{2}\left(-\frac{b}{2},-\frac{c}{2}\right)$ 关于直线 $x+y-2=0$ 对称，
> >
> > 所以 $\left\{\begin{aligned}-\frac{b}{2}+\frac{-c}{2}-2=0\\-\frac{c}{2}-0\\-\frac{b}{2}-0\end{aligned}\right.$ 解得，b=c=-4
> >
> > 又 $r_1 = r_2$ ，所以 $a = \frac{4^2}{4} +\frac{4^2}{4} +1 = 9$ 故 $a + b + c = 1$
> >
> > 故选 **A**.
