> > 10. 数列 $\left\{a_{n}\right\}$ 满足 $a_{1}=1,\quad a_{n+1}=2a_{n}+n-1,\quad n\in N_{+}$ ，则下列说法正确的有（）
> > A. 数列 $\left\{a_{n}+n\right\}$ 是等比数列
> > B. $a_{n}=2^{n}-n$ C. 数列 $\left\{a_{n}\right\}$ 的前 n 项和 $S_{n}=2^{n+1}-\frac{n^{2}+n-4}{2}$ D. 数列 $\left\{a_{n}\right\}$ 是递增数列
> >
> > 【答案】ABD
> >
> > 【详解】因为 $a_{n + 1} = 2a_{n} + n - 1$ ，所以 $a_{n + 1} + (n + 1) = 2a_{n} + 2n = 2(a_{n} + n)$
> >
> > 因为 $a_1 = 1$ ，所以 $a_1 + 1 = 2$
> >
> > 所以数列 $\{a_{n} + n\}$ 是首项和公比都为2的等比数列，故A正确；
> >
> > 则 $a_{n} + n = 2^{n}$ ，所以 $a_{n} = 2^{n} - n$ ，故B正确；
> >
> > 因为 $a_{n}=2^{n}-n$ ，所以 $S_{n}=a_{1}+a_{2}+\cdots+a_{n}=2^{1}-1+2^{2}-2+\cdots+2^{n}-n$
> >
> > $=2^{1}+2^{2}+\cdots+2^{n}-(1+2+\cdots+n)=2^{n+1}-2-\frac{(n+1)n}{2}=2^{n+1}-\frac{n^{2}+n+4}{2}$ ，故C错误；
> >
> > 因为 $a_{n + 1} = 2a_{n} + n - 1$ ，所以 $a_{n + 1} - a_n = a_n + n - 1 = 2^n -1$
> >
> > 因为 $n \in \mathbf{N}_{+}$ ，所以 $2^{n} - 1 > 0$ ，所以 $a_{n+1} > a_{n}$ ，即数列 $\left\{a_{n}\right\}$ 是递增数列，故D正确。
> >
> > 故选 **ABD**.
