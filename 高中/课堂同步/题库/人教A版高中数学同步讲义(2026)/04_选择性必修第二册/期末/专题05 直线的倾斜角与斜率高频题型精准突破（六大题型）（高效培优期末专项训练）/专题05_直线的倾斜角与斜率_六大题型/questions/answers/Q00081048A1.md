> [!faq]- 《专题05 直线的倾斜角与斜率高频题型精准突破（六大题型）（高效培优期末专项训练）》官方解析
>
> > [!success]- **【答案】** ![](../../../images/questions/494e01a4033c5bd8450db210276303a3578c4ea0c09e287bd15493237a990604.jpg) A. $k_{1} < k_{3} < k_{2}$ B. $k_{3} < k_{2} < k_{1}$ C. $\alpha_{1} < \alpha_{3} < \alpha_{2}$ D. $\alpha_{3} < \alpha_{2} < \alpha_{1}$
>
> > [!note]- **【分析】**
> > 根据直线斜率与倾斜角定义，依图象分别判断各选项即可·
>
> > [!note]- **【解析】**
> > 由图可知 $0 < \alpha_{3} < \alpha_{2} < \frac{\pi}{2} < \alpha_{1}$
> >
> > 则 $k_{1} < 0 < k_{3} < k_{2}$
> >
> > 故选 **AD**
