> [!faq]- 《专题05 直线的倾斜角与斜率高频题型精准突破（六大题型）（高效培优期末专项训练）》官方解析
>
> > [!success]- **【答案】** ![](../../../images/questions/ad920fd86492deea9db34a59dac603ba8c23935f7ae3f618d2b0bcafec8cb471.jpg) A. $k_{3} < k_{2} < k_{1}$ B. $k_{3} < k_{1} < k_{2}$ C. $k_{1} < k_{2} < k_{3}$ D. $k_{1} < k_{3} < k_{2}$
>
> > [!note]- **【分析】**
> > 利用倾斜角的大小，结合正切函数的单调性可作出判断·
>
> > [!note]- **【解析】**
> > 设直线 $l_{1}$ ， $l_{2}$ ， $l_{3}$ 的倾斜角分别为 $\alpha_{1}$ ， $\alpha_{2}$ ， $\alpha_{3}$
> >
> > ![](../../../images/questions/4dfde92316f484d962ea031c5600538422662cbef522e76ca129f4d0fc0f0383.jpg)
> >
> > 则根据图象可得： $0 < \alpha_{3} < \alpha_{2} < \frac{\pi}{2} < \alpha_{1}$
> >
> > 再由正切函数的单调性可知： $\tan \alpha_{1} < 0 < \tan \alpha_{3} < \tan \alpha_{2}$
> >
> > 即有 $k_{1} < k_{3} < k_{2}$
> >
> > 故选：D.
