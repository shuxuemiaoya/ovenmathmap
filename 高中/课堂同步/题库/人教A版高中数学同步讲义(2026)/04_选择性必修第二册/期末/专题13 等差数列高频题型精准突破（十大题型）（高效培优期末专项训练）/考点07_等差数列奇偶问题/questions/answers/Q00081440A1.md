> [!faq]- 《专题13 等差数列高频题型精准突破（十大题型）（高效培优期末专项训练）》官方解析
>
> > [!success]- **【答案】** A
>
> > [!note]- **【分析】**
> > 根据等差数列的求和公式，结合等差数列的性质，即可求解·
>
> > [!note]- **【解析】**
> > 等差数列 $\{a_{n}\}$ 共 $2n + 1$ 项，其中奇数项有 $n + 1$ 项，偶数项有 $n$ 项，
> >
> > 奇数项和为 $a_1 + a_3 + \mathsf{L} + a_{2n + 1} = \frac{(n + 1)(a_1 + a_{2n + 1})}{2} = 220$ ①，
> >
> > 偶数项和为 $a_2 + a_4 + L + a_{2n} = \frac{n(a_2 + a_{2n})}{2} = 200$ ②
> >
> > 因为 $a_1 + a_{2n+1} = a_2 + a_{2n}$ ，所以①÷②，得 $\frac{n+1}{n} = \frac{11}{10}$ ，则 $n = 10$ 。
> >
> > 故选：A.
> >
> > 38. 等差数列 $\{a_{n}\}$ 共 $2n + 1$ 项，且奇数项和为 $^{165}$ ，偶数项和为 $^{150}$ ，则 $n =$ \_\_\_\_.
> >
> > 【答案】 $^{10}$
> >
> > 【分析】结合等差数列前 $n$ 项和公式，利用奇数项和偶数项的和列式求解即可·
> >
> > 【详解】等差数列 $\{a_{n}\}$ 共 $2n + 1$ 项，其中奇数项有 $n + 1$ 个，偶数项有 $n$ 个，
> >
> > 设等差数列 $\{a_{n}\}$ 的公差为 $d$ ，
> >
> > 奇数项和 $a_{1} + a_{3} + \cdots + a_{2n+1} = (n+1)a_{1} + \frac{(n+1)n}{2} \cdot 2d = (n+1)(a_{1} + nd) = 165$ ①，
> >
> > 偶数项和 $a_2 + a_4 + \dots + a_{2n} = n(a_1 + d) + \frac{n(n - 1)}{2} \cdot 2d = n(a_1 + nd) = 150$ ②，
> >
> > 由①-②，得 $a_{1}+nd=15$ ，代入②式，可得 $n\times15=150$ ，解得n=10。
> >
> > 故答案为：10
