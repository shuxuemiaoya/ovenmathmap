> [!faq]- 《专题13 等差数列高频题型精准突破（十大题型）（高效培优期末专项训练）》官方解析
>
> > [!success]- **【答案】** 56
>
> > [!note]- **【分析】**
> > 只需根据等差数列前 n 项和性质求得 $a_{15}, a_{16}$ 的值，再结合等差数列性质即可求解.
>
> > [!note]- **【解析】**
> > 当 $n$ 为偶数时，由题意可知 $S_{\text{奇}} = \frac{a_1 + a_{n-1}}{2} \times \frac{n}{2}, S_{\text{偶}} = \frac{a_2 + a_n}{2} \times \frac{n}{2}$
> >
> > 所以 $S_{偶}-S_{奇}=\frac{n}{2}d=-4n=360-480=-120$ ，所以 n=30，
> >
> > 此时 $S_{奇}=\frac{a_{1}+a_{29}}{2}\times15=15a_{15}=480$ ，解得 $a_{15}=32$ ，
> >
> > $S_{偶}=\frac{a_{2}+a_{30}}{2}\times15=15a_{16}=360$ ，解得 $a_{16}=24$ ，
> >
> > 则 $a_1 + a_{30} = a_{15} + a_{16} = 32 + 24 = 56$
> >
> > 故答案为：56.

> > 42. 如果 n 项有穷数列 $\left\{a_{n}\right\}$ 满足 $a_{1}=a_{n}$ ， $a_{2}=a_{n-1}$ ，…， $a_{n}=a_{1}$ ，即 $a_{i}=a_{n-i+1}(i=1,2,\cdots,n)$ ，则称有穷数列 $\left\{a_{n}\right\}$ 为“对称数列”·设数列 $\left\{c_{n}\right\}$ 是项数为 2k-1（ $k\in N^{*}$ ，且 k-2）的“对称数列”，且满足 $\left|c_{n+1}-c_{n}\right|=2$ ，记 $S_{n}$ 为数列 $\left\{c_{n}\right\}$ 的前 n 项和·若 $c_{1}$ ， $c_{2}$ ，…， $c_{k}$ 构成单调递增数列，且 $c_{k}=2023$ ，则当 $S_{2k-1}$ 取得最大值时，k= \_\_\_\_.
> >
> > 【答案】1012
> >
> > 【分析】根据对称数列的定义可得数列为等差数列，然后分组求和，根据二次函数的性质来求解
> >
> > 【详解】由题设知 $c_{1}, c_{2}, \cdots, c_{k}$ 构成公差为 2 的等差数列， $c_{k}, c_{k+1}, \cdots, c_{2k-1}$ 构成公差为 -2 的等差数列，
> >
> > $$
> > S _ {2 k - 1} = c _ {1} + c _ {2} + \dots + c _ {k} + c _ {k + 1} + \dots + c _ {2 k - 1} = 2 \left(c _ {k} + c _ {k + 1} + \dots + c _ {2 k - 1}\right) - c _ {k}
> > $$
> >
> > $$
> > = 2 \left[ 2 0 2 3 k + \frac {k (k - 1)}{2} \times (- 2) \right] - 2 0 2 3 = - 2 k ^ {2} + 4 0 4 8 k - 2 0 2 3,
> > $$
> >
> > 所以当 $k = -\frac{4048}{-4} = 1012$ 时， $S_{2k-1}$ 取得最大值.
> >
> > 故答案为：1012.
