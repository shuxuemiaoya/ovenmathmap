> [!faq]- 《专题14 等比数列高频题型精准突破（十大题型）（高效培优期末专项训练）》官方解析
>
> > [!success]- **【答案】** (1) $\frac{341}{256}$ (2) $a_{n}=\frac{1}{15}\times2^{n-1}$ 或 $a_{n}=-\frac{1}{5}\times(-2)^{n-1}$ (3)50
>
> > [!note]- **【分析】**
> > （1）应用等比数列前 $n$ 项和公式，代入基本量 $a_1, q$ 运算即可；
> >
> > (2) 应用等比数列前 n 项和公式建立方程组求解基本量 $a_{1}, q$ ，再由通项公式可得；
> >
> > （3）由等比数列的定义可得 $a_{n} = 2a_{n + 1}$ ，化奇数项和为偶数项和，整体求解 $a_2 + a_4 + \mathrm{L} + a_{100}$ 可得
>
> > [!note]- **【解析】**
> > （1）由已知 $q \neq 1$
> >
> > 则 $S_{10} = \frac{a_1(1 - q^{10})}{1 - q} = \frac{2\times\left[1 - \left(-\frac{1}{2}\right)^{10}\right]}{1 - \left(-\frac{1}{2}\right)}$ $= \frac{4}{3}\times \left(1 - \frac{1}{1024}\right) = \frac{341}{256}$
> >
> > (2) 若 $q = 1$ ，则 $S_{8} = 2S_{4}$ ，不符合题意， $\therefore q \neq 1$ $\therefore S_{4} = \frac{a_{1}(1 - q^{4})}{1 - q} = 1$ ，且 $S_{8} = \frac{a_{1}(1 - q^{8})}{1 - q} = 17$ ，
> > 两式相除得 $\frac{1 - q^{8}}{1 - q^{4}} = 17 = 1 + q^{4}$ ，
> > 解得 $q = 2$ 或 $q = -2$ 。
> > 当 $q = 2$ 时， $a_{1} = \frac{1}{15}$ ；当 $q = -2$ 时， $a_{1} = -\frac{1}{5}$ ， $\therefore a_{n} = \frac{1}{15} \times 2^{n-1}$ 或 $a_{n} = -\frac{1}{5} \times (-2)^{n-1}$ ；
> > (3) $\because q = \frac{1}{2}$ ，则 $\frac{1}{2} a_{n} = a_{n+1}$ ，即 $a_{n} = 2a_{n+1}$ ， $\therefore a_{1} = 2a_{2}, a_{3} = 2a_{4}, \cdots, a_{99} = 2a_{100}$ ， $S_{100} = a_{1} + a_{2} + a_{3} + a_{4} + \cdots + a_{99} + a_{100}$ $= 2(a_{2} + a_{4} + \cdots + a_{100}) + a_{2} + a_{4} + \cdots + a_{100}$ $= 3(a_{2} + a_{4} + \cdots + a_{100}) = 150$ ， $\therefore a_{2} + a_{4} + a_{6} + \cdots + a_{100} = 50$ 。
