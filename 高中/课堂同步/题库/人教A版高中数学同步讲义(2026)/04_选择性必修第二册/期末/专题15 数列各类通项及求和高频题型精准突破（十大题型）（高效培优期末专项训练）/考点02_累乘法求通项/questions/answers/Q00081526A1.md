> [!faq]- 《专题15 数列各类通项及求和高频题型精准突破（十大题型）（高效培优期末专项训练）》官方解析
>
> > [!success]- **【答案】** ABD
>
> > [!note]- **【分析】**
> > 利用给定条件求解数列单调性判断 $^{A}$ ，利用累乘法求出数列通项公式判断 $^{B}$ ，利用等差数列求和公式结合给定条件判断 $^{C}$ ，利用裂项相消法求和判断 $^{D}$ 即可·
>
> > [!note]- **【解析】**
> > 由题意得 $\frac{a_{n + 1}}{a_n} = 1 + \frac{1}{n}\left(n\in \mathbf{N}^*\right)$ ，且 $a_1 = 1$
> >
> > 可知 $\frac{a_{n + 1}}{a_n} = 1 + \frac{1}{n} >1$ ，则 $\{a_n\}$ 为正项递增数列，
> >
> > 得到 $a_{2n+1}-a_{2n}>0$ ，即 $a_{2n}<a_{2n+1}$ ，故 A 正确；
> >
> > 由 $\frac{a_{n + 1}}{a_n} = 1 + \frac{1}{n} = \frac{n + 1}{n}$ ，则 $n - 2$ 时，$a_{n} = \frac{a_{n}}{a_{n - 1}}\cdot \frac{a_{n - 1}}{a_{n - 2}}\cdot \dots \cdot \frac{a_{2}}{a_{1}}\cdot a_{1} = \frac{n}{n - 1}\cdot \frac{n - 1}{n - 2}\cdot \dots \cdot \frac{2}{1}\cdot 1 = n$
> >
> > 又 $a_1 = 1$ 符合上式，故 $a_{n} = n$
> >
> > 当 $n$ 2时， $a_{n-1} + a_{n+1} = n - 1 + n + 1 = 2n = 2a_n$ ，故B正确；
> >
> > 由等差数列求和公式得 $S_{n} = \frac{n(n + 1)}{2}$ ，则 $\frac{S_n}{n} = \frac{n + 1}{2}$ ，故C错误；
> >
> > 而 $\frac{1}{S_n} = \frac{2}{n(n + 1)} = 2\left(\frac{1}{n} -\frac{1}{n + 1}\right)$
> >
> > 故数列 $\left\{\frac{1}{S_{n}}\right\}$ 的前n项和为 $\frac{1}{S_{1}}+\frac{1}{S_{2}}+\cdots+\frac{1}{S_{n}}$
> >
> > $= 2\left(1 - \frac{1}{2} +\frac{1}{2} -\frac{1}{3} +\dots +\frac{1}{n} -\frac{1}{n + 1}\right) = 2\left(1 - \frac{1}{n + 1}\right) = \frac{2n}{n + 1}$ ，故D正确.
> >
> > 故选 **ABD**
