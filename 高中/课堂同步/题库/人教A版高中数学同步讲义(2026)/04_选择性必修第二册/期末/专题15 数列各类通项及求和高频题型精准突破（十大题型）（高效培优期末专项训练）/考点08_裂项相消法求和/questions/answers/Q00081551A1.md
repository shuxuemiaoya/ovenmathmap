> [!faq]- 《专题15 数列各类通项及求和高频题型精准突破（十大题型）（高效培优期末专项训练）》官方解析
>
> > [!success]- **【答案】** (1) $a_{n}=2n+1$ (2) $T_{n} = \frac{2n}{2n + 3}$
>
> > [!note]- **【分析】**
> > （1）设出等差数列的公差 $d$ 后，根据题目所给条件列出方程即可求出 $d$ ，进而得解；（2）利用裂项相消法求和即可·
>
> > [!note]- **【解析】**
> > （1）设等差数列 $\{a_{n}\}$ 的公差为 $d$ ，
> >
> > 则由 $S_{3}=a_{1}+a_{2}+a_{3}=a_{4}+6$ ，可得 $3a_{2}=a_{2}+2d+6$ ，
> >
> > 因 $a_{2} = 5$ ，代入解得 $d = 2$ ，则 $a_1 = a_2 - d = 3$
> >
> > 因此 $a_{n} = a_{1} + (n - 1)d = 3 + 2(n - 1) = 2n + 1.$
> >
> > (2) 由 $b_{n} = \frac{6}{a_{n} a_{n+1}} = \frac{6}{(2n + 1)(2n + 3)} = 3\left(\frac{1}{2n + 1} - \frac{1}{2n + 3}\right)$ ，
> >
> > $$
> > T _ {n} = b _ {1} + b _ {2} + b _ {3} + \dots + b _ {n} = 3 \left(\frac {1}{3} - \frac {1}{5} + \frac {1}{5} - \frac {1}{7} + \frac {1}{7} - \frac {1}{9} + \dots + \frac {1}{2 n + 1} - \frac {1}{2 n + 3}\right)
> > $$
> >
> > $$
> > = 3 \left(\frac {1}{3} - \frac {1}{2 n + 3}\right) = 1 - \frac {3}{2 n + 3} = \frac {2 n}{2 n + 3}.
> > $$
