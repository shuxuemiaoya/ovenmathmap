> [!faq]- 《专题15 数列各类通项及求和高频题型精准突破（十大题型）（高效培优期末专项训练）》官方解析
>
> > [!success]- **【答案】** 2027
>
> > [!note]- **【分析】**
> > 先根据等差数列定义得出等差数列通项，再结合累加法计算得出所以 $a_{n} = n(n + 1)(n\in \mathbf{N}_{+})$ ，结合函数新定义计算求和·
>
> > [!note]- **【解析】**
> > 因为 $a_{n + 2} - 2a_{n + 1} + a_n = 2$ ，所以 $\left(a_{n + 2} - a_{n + 1}\right) - \left(a_{n + 1} - a_n\right) = 2.$
> >
> > 因为 $a_1 = 2$ ， $a_2 = 6$ ，所以 $a_2 - a_1 = 4$ ，所以数列 $\{a_{n + 1} - a_n\}$ 是首项为4，公差为2的等差数列，故 $a_{n + 1} - a_n = 4 + 2(n - 1) = 2n + 2$
> >
> > 由累加法可知当 $n = 2$ 时， $\left(a_{n} - a_{n-1}\right) + \left(a_{n-1} - a_{n-2}\right) + \cdots + \left(a_{2} - a_{1}\right) = \frac{(n-1)(4+2n)}{2} = (n+2)(n-1)$ ，
> >
> > 所以 $a_{n} = (n + 2)(n - 1) + a_{1} = n(n + 1)(n - 2)$ ，又 $a_{1} = 2$ 也符合该式，所以 $a_{n} = n(n + 1)(n \in \mathbf{N}_{+})$
> >
> > 所以 $\frac{(n + 1)^2}{a_n} = \frac{(n + 1)^2}{n(n + 1)} = \frac{n + 1}{n} = 1 + \frac{1}{n}$
> >
> > 当 $n = 1$ 时， $b_{1} = \left[1 + \frac{1}{1}\right] = 2$
> >
> > 当 $n$ 2时， $1 < 1 + \frac{1}{n} \leq \frac{3}{2}$ ，此时 $b_{n} = \left[1 + \frac{1}{n}\right] = 1$
> >
> > 所以 $\left\{b_{n}\right\}$ 的前 2026 项和为 $b_{1}+b_{2}+\cdots+b_{2026}=2+1+1+\cdots+1=2+1\times2025=2027$
> >
> > 故答案为：2027.
