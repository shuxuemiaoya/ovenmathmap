> [!faq]- 《高二数学上学期期末模拟卷（选择性必修第一册 选择性必修第二册数列，高效培优·提升卷）》官方解析
>
> > [!success]- **【答案】** A. $a_n = \frac{n + 2}{3}$ B. $S_n = \frac{1}{3} a_n$ C. $a_{100} = 5050$ D. $\frac{1}{a_1} + \frac{1}{a_2} + \cdots + \frac{1}{a_{10}} = \frac{21}{11}$
>
> > [!note]- **【解析】**
> > 因 $\left\{\frac{S_n}{a_n}\right\} = \frac{1}{3}$ $\frac{S_n}{a_n} = \frac{S_1}{a_1} +\frac{1}{3}\big(n - 1\big) = \frac{n + 2}{3}$ 是公差为的等差数列，则
> >
> > 则 $3S_{n} = (n + 2)a_{n}$ ， $3S_{n + 1} = (n + 3)a_{n + 1}$ ，两式相减，得 $3a_{n + 1} = (n + 3)a_{n + 1} - (n + 2)a_{n}$ 即 $na_{n + 1} = (n + 2)a_{n}$ ，可得 $\frac{a_{n + 1}}{n + 2} = \frac{a_n}{n}$ ，因 $n\in \mathbb{N}^*$ ，可得 $\frac{a_{n + 1}}{(n + 1)(n + 2)} = \frac{a_n}{n(n + 1)}$ 故得 $\left\{\frac{a_n}{n(n + 1)}\right\}$ 为常数列，从而 $\frac{a_n}{n(n + 1)} = \frac{a_1}{2} = \frac{1}{2}$ ，即得 $a_{n} = \frac{n(n + 1)}{2}$ 故A错误；对于C，由上文求得的通项公式可知， $a_{100} = \frac{100\times 101}{2} = 5050$ ，故C正确；对于B,由上分析， $3S_{n} = (n + 2)a_{n}$ 即 $S_{n} = \frac{n + 2}{3} a_{n}$ ，故B错误；对于D，因 $a_{n} = \frac{n(n + 1)}{2}$ ，则 $\frac{1}{a_n} = \frac{2}{n(n + 1)} = 2(\frac{1}{n} -\frac{1}{n + 1})$ 则 $\frac{1}{a_1} +\frac{1}{a_2} +\dots +\frac{1}{a_{10}} = 2[(1 - \frac{1}{2}) + (\frac{1}{2} -\frac{1}{3}) + \dots +(\frac{1}{10} -\frac{1}{11})] = 2(1 - \frac{1}{11}) = \frac{20}{11}$ ，故D错误
> >
> > 故选 **C**.
