> [!faq]- 《第四章 数列（高效培优单元测试·提升卷）数学人教A版高二选择性必修第二册》官方解析
>
> > [!success]- **【答案】** ①③④
>
> > [!note]- **【解析】**
> > 由题意设数列 $\{a_{n}\}$ 的公差为 $d(d\neq 0)$ ，首项为 $a_1$ ，数列 $\{b_n\}$ 的公比为 $q(q\neq 1)$ ，首项为 $b_{1}$ ，则 $a_{n} = a_{1} + (n - 1)d,b_{n} = b_{1}\cdot q^{n - 1}$
> > - **对于①**：令 $c_{n} = a_{n} + b_{n} = a_{1} + (n - 1)d + b_{1}\cdot q^{n - 1}$ ，假设 $\{c_n\}$ 是等比数列，则 $\frac{c_{n + 1}}{c_n}$ 为常数，
> >
> > $$
> > \underline {{c _ {n + 1}}}
> > $$
> >
> > 而 $\frac{c_{n+1}}{c_{n}}=\frac{a_{1}+nd+b_{1}q^{n}}{a_{1}+(n-1)d+b_{1}q^{n-1}}$ 与 n 有关不为常数，故矛盾，故①正确；
> > - **对于②**：设 $a_{n} = 2n - 1, b_{n} = -\left(\frac{1}{2}\right)^{n - 1}$ ，满足题意，则 $a_{n} \cdot b_{n} = (1 - 2n)\left(\frac{1}{2}\right)^{n - 1}$ ，
> >
> > 由 $a_1b_1 = -1, a_2b_2 = -\frac{3}{2}, a_2b_2 < a_1b_1$ ，所以数列 $\{a_n \cdot b_n\}$ 不是递增数列，故②错误；
> > - **对于③**：假设 $b_{n}, b_{n+1}, b_{n+2}$ 为等差数列，所以 $2b_{n+1} = b_{n} + b_{n+2}$ ，即 $2b_{1}q^{n} = b_{1}q^{n-1} + b_{1}q^{n+1}$
> >
> > 所以 $2q = 1 + q^{2}$ ，解得 q = 1 与 $q \neq 1$ 矛盾，故③正确；
> > - **对于④**：$a_{n}=\sqrt{2}+\sqrt{3}n$ ，则 $a_{p}=\sqrt{2}+\sqrt{3}p,a_{q}=\sqrt{2}+\sqrt{3}q,a_{r}=\sqrt{2}+\sqrt{3}r\left(p<q<r,p,q,r\in\mathbb{N}^{*}\right)$
> >
> > 若 $a_{p}, a_{q}, a_{r}$ 能构成等比数列，则 $a_{q}^{2} = a_{p}a_{r}$ ，即 $\left(\sqrt{2} + \sqrt{3} q\right)^{2} = \left(\sqrt{2} + \sqrt{3} p\right)\left(\sqrt{2} + \sqrt{3} r\right)$ ，
> >
> > 化简整理得 $3q^{2} + 2\sqrt{6}q = 3pr + \sqrt{6}(p + r) \Rightarrow \left\{\begin{aligned} q^{2} &= pr \\ 2q &= p + r \end{aligned}\right. \Rightarrow p = q = r$ 矛盾，故④正确；
> >
> > 故选：①③④·
