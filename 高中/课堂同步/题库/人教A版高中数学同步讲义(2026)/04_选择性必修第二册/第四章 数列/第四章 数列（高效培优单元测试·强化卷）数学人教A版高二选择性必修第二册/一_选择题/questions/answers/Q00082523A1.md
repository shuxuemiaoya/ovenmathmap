> [!faq]- 《第四章 数列（高效培优单元测试·强化卷）数学人教A版高二选择性必修第二册》官方解析
>
> > [!success]- **【答案】** $\frac{1}{8}, \frac{3}{8}, \frac{5}{8}, \frac{7}{8}$ ，依此类推，设 $S_{n}$ 为 $\{a_{n}\}$ 的前 $n$ 项和，则（）A. $a_{15} = \frac{15}{16}$ B. $S_{15} - S_{7} = 4$ C．有且仅有一个正整数 m，使得 $a_{m} + a_{m+1} = \frac{31}{32}$ D．存在无数个正整数 n，使得 $S_{n} = \frac{n}{2}$
>
> > [!note]- **【解析】**
> > A选项：易知接下来的8项为 $\frac{1}{16},\frac{3}{16},\frac{5}{16},\frac{7}{16},\frac{9}{16},\frac{11}{16},\frac{13}{16},\frac{15}{16}$ ，所以 $a_{15} = \frac{15}{16}$ ，故A正确：
> >
> > $S_{15}-S_{7}=\frac{1+3+\cdots+15}{16}=4$ B选项：，故B正确；
> >
> > $^{C}$ 选项：设分母为 $2^{k}$ 的为第k组，
> >
> > 情形一： $a_{m}, a_{m + 1}$ 在不同组，设 $a_{m}$ 为第 $k$ 组最后一个数，则 $a_{m} = \frac{2^{k} - 1}{2^{k}}$
> >
> > $a_{m + 1}$ 为第 $k + 1$ 组第一个数，则 $a_{m + 1} = \frac{1}{2^{k + 1}}$ ，所以 $a_{m} + a_{m + 1} = \frac{2^{k} - 1}{2^{k}} +\frac{1}{2^{k + 1}} = \frac{31}{32}$
> >
> > 解得 k = 4 ，即 m = 15 .
> >
> > 情形二： $a_{m}, a_{m+1}$ 为第 $k$ 组第 $i$ 和第 $i+1$ 个，则 $a_{m} + a_{m+1} = \frac{2i - 1 + 2i + 1}{2^k} = \frac{4i}{2^k} = \frac{i}{2^{k-2}} = \frac{31}{32}$ ，
> >
> > 取 i=31, k=7 ，即 $m=1+2+4+8+16+32+31=94$ 符合题意，故 C 错误；
> >
> > D 选项：因为 $S_{2^{n + 1} - 1} - S_{2^n -1} = \frac{1 + 3 + \cdots + 2^{n + 1} - 1}{2^{n + 1}} = 2^n$ 所以 $S_{2^{n}-1}=S_{1}+S_{3}-S_{1}+\cdots+S_{2^{n}-1}-S_{2^{n-1}-1}=\frac{1}{2}+1+\cdots+2^{n-1}=\frac{\frac{1}{2}\left(1-2^{n}\right)}{1-2}=\frac{1}{2}\left(2^{n}-1\right)$
> >
> > 因此存在无数个正整数 $n$ ，使得 $S_{n} = \frac{n}{2}$ ，故D正确；
> >
> > 故选 **ABD**.
