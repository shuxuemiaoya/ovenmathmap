> [!faq]- 《专题02 等差数列八大常考题型（高效培优专项训练）数学人教A版高二选择性必修第二册》官方解析
>
> > [!success]- **【答案】** (1)证明见解析； (2) $S_{2n} = -\frac{3n}{12n + 8}$ .
>
> > [!note]- **【分析】**
> > （1）根据题意得到 $\frac{T_n}{T_{n - 1}} = a_n$ ，由 $\frac{1}{a_n} = 1 - \frac{3}{T_n}$ ，化简得到 $T_{n} - T_{n - 1} = 3$ ，求得 $T_{1} = 4$ ，结合等差数列的定义推理得证·
> >
> > (2) 由 (1) 可得 $T_{n} = 3n + 1$ ，得到 $b_{n} = (-1)^{n} \cdot \left(\frac{1}{3n + 1} + \frac{1}{3n + 4}\right)$ ，结合裂项法，即可求解
>
> > [!note]- **【解析】**
> > （1）依题意， $T_{n}=a_{1}a_{2}L\quad a_{n}$ ，当n=2时，得 $T_{n-1}=a_{1}a_{2}\cdots a_{n-1}$ ，则 $\frac{T_{n}}{T_{n-1}}=a_{n}$
> >
> > 由 $\frac{1}{a_n} = 1 - \frac{3}{T_n}$ ，得 $\frac{T_{n - 1}}{T_n} = 1 - \frac{3}{T_n}$ ，则 $T_{n - 1} = T_n - 3$ ，即 $T_{n} - T_{n - 1} = 3$
> >
> > 当 $n = 1$ 时， $T_{1} = a_{1}$ ，于是 $\frac{1}{T_1} = 1 - \frac{3}{T_1}$ ，解得 $T_{1} = 4$ ，
> >
> > 所以数列 $\{T_n\}$ 是以4为首项，3为公差的等差数列
> >
> > (2) 由 (1) 得 $T_{n} = 4 + (n - 1) \cdot 3 = 3n + 1$
> >
> > $$
> > b _ {n} = (- 1) ^ {n} \cdot \frac {6 n + 5}{T _ {n} \cdot T _ {n + 1}} = (- 1) ^ {n} \cdot \frac {(3 n + 1) + (3 n + 4)}{(3 n + 1) (3 n + 4)} = (- 1) ^ {n} \cdot \left(\frac {1}{3 n + 1} + \frac {1}{3 n + 4}\right)
> > $$
> >
> > $$
> > S _ {2 n} = - \left(\frac {1}{4} + \frac {1}{7}\right) + \left(\frac {1}{7} + \frac {1}{1 0}\right) - \left(\frac {1}{1 0} + \frac {1}{1 3}\right) + \dots - \left(\frac {1}{6 n - 2} + \frac {1}{6 n + 1}\right) + \left(\frac {1}{6 n + 1} + \frac {1}{6 n + 4}\right)
> > $$
> >
> > $$
> > = - \frac {1}{4} + \frac {1}{6 n + 4} = - \frac {6 n}{4 (6 n + 4)} = - \frac {3 n}{1 2 n + 8}.
> > $$
