> [!faq]- 《专题02 等差数列八大常考题型（高效培优专项训练）数学人教A版高二选择性必修第二册》官方解析
>
> > [!success]- **【答案】** (1) $a_{1}=41$ ， $a_{2}=13$ . (2)证明见解析 (3)27.
>
> > [!note]- **【分析】**
> > （1）由 $a_{3}=6$ 得 $a_{2}=13$ ，再得 $a_{1}=41$ ；
> >
> > (2) 由 $na_{n} = (n + 2)a_{n + 1} + 2$ 进行凑配即可证明.
> >
> > (3) 由 (2) 可得 $a_{n} = 84\left(\frac{1}{n} - \frac{1}{n + 1}\right) - 1$ ，再进行求和得 $S_{n} = 84\left(1 - \frac{1}{n + 1}\right) - n$ ，再解不等式可得
>
> > [!note]- **【解析】**
> > （1）由题意得 $2a_{2} = 4a_{3} + 2$ ， $a_1 = 3a_2 + 2$ ，算得 $a_2 = 13$ ， $a_1 = 41$
> >
> > (2) 由 $na_{n}=(n+2)a_{n+1}+2$
> >
> > $$
> > \text {   得   } n (n + 1) a _ {n} = (n + 1) (n + 2) a _ {n + 1} + 2 (n + 1),
> > $$
> >
> > $$
> > n (n + 1) a _ {n} + n ^ {2} = (n + 1) (n + 2) a _ {n + 1} + 2 (n + 1) + n ^ {2}
> > $$
> >
> > $$
> > n (n + 1) a _ {n} + n ^ {2} = (n + 1) (n + 2) a _ {n + 1} + (n + 1) ^ {2} + 1
> > $$
> >
> > $$
> > \text {记} b _ {n} = n (n + 1) a _ {n} + n ^ {2}, \text {则} b _ {n + 1} = (n + 1) (n + 2) a _ {n + 1} + (n + 1) ^ {2}
> > $$
> >
> > 得 $b_{n+1} - b_n = -1$ ， $b_1 = 2a_1 + 1 = 83$ ，所以数列 $\{b_n\}$ 是首项为 83，公差为 -1 的等差数列。故 $\left\{n(n+1)a_n + n^2\right\}$ 是等差数列。
> >
> > (3) 由 (2) 得 $b_n = 83 - (n-1) = 84 - n$ ，即 $n(n+1)a_n + n^2 = 84 - n$
> >
> > $$
> > a _ {n} = \frac {8 4 - n - n ^ {2}}{n ^ {2} + n} = \frac {8 4}{n ^ {2} + n} - 1 = 8 4 \left(\frac {1}{n} - \frac {1}{n + 1}\right) - 1
> > $$
> >
> > 所以 $a_{1} = 84\left(\frac{1}{1} -\frac{1}{2}\right) - 1$ ， $a_2 = 84\left(\frac{1}{2} -\frac{1}{3}\right) - 1$ ， $a_{3} = 84\left(\frac{1}{3} -\frac{1}{4}\right) - 1$ ， $\mathbb{L}$ ， $a_{n} = 84\left(\frac{1}{n} -\frac{1}{n + 1}\right) - 1$
> >
> > 所以 $S_{n}=84[(1-\frac{1}{2})+(\frac{1}{2}-\frac{1}{3})+\cdots+(\frac{1}{n}-\frac{1}{n+1})]-n$ ，即 $S_{n}=84\left(1-\frac{1}{n+1}\right)-n$
> >
> > 因此 $S_{n} = 84\left(1 - \frac{1}{n + 1}\right) - n\leq 2n$
> >
> > 解得 n 27，故使 $S_{n} \leq 2n$ 的最小正整数 n 的值为 27.
