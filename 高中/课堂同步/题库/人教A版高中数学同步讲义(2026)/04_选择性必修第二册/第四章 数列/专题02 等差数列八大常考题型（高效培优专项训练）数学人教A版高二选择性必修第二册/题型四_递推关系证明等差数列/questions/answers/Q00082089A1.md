> [!faq]- 《专题02 等差数列八大常考题型（高效培优专项训练）数学人教A版高二选择性必修第二册》官方解析
>
> > [!success]- **【答案】** (1)证明见解析； (2) $T_{2n}=-\frac{2n}{4n+1}$ .
>
> > [!note]- **【分析】**
> > （ $^{1}$ ）由已知条件，变形给定等式，再利用等差数列的定义推理得证·
> >
> > (2) 由 (1) 求出 $a_{n}$ 及 $b_{n}$ ，再利用裂项相消求和法及并项求和法求出 $T_{2n}$ .
>
> > [!note]- **【解析】**
> > （1）由 $\{a_{n}\}$ 是各项都为正数的递增数列，得 $a_{n + 1} > a_n$ $a_1 = 1$
> >
> > 而 $(a_{n + 1} + a_n - 1)^2 = 4a_{n + 1}a_n$ ，则 $a_{n + 1} + a_n - 1 = 2\sqrt{a_{n + 1}a_n}$ ，整理得 $(\sqrt{a_{n + 1}} -\sqrt{a_n})^2 = 1$
> >
> > 因此 $\sqrt{a_{n + 1}} -\sqrt{a_n} = 1$ ，所以数列 $\{\sqrt{a_n}\}$ 是等差数列
> >
> > (2) 由 (1) 知 $\sqrt{a_n} = \sqrt{a_1} + (n - 1) \times 1 = n$ ， $a_n = n^2$
> >
> > 则 $b_{n} = (-1)^{n}\frac{\sqrt{4a_{n}}}{4a_{n} - 1} = (-1)^{n}\frac{2n}{4n^{2} - 1} = (-1)^{n}\cdot \frac{1}{2} (\frac{1}{2n - 1} +\frac{1}{2n + 1})$
> >
> > $$
> > b _ {2 n - 1} + b _ {2 n} = - \frac {1}{2} \left(\frac {1}{4 n - 3} + \frac {1}{4 n - 1}\right) + \frac {1}{2} \left(\frac {1}{4 n - 1} + \frac {1}{4 n + 1}\right) = \frac {1}{2} \left(\frac {1}{4 n + 1} - \frac {1}{4 n - 3}\right)
> > $$
> >
> > $$
> > T _ {2 n} = \left(b _ {1} + b _ {2}\right) + \left(b _ {3} + b _ {4}\right) + \dots + \left(b _ {2 n - 1} + b _ {2 n}\right) = \frac {1}{2} \left[ \left(\frac {1}{5} - 1\right) + \left(\frac {1}{9} - \frac {1}{5}\right) + \dots + \left(\frac {1}{4 n + 1} - \frac {1}{4 n - 3}\right) \right]
> > $$
> >
> > $$
> > = \frac {1}{2} \left(\frac {1}{4 n + 1} - 1\right) = - \frac {2 n}{4 n + 1}.
> > $$
