> [!faq]- 《专题02 等差数列八大常考题型（高效培优专项训练）数学人教A版高二选择性必修第二册》官方解析
>
> > [!success]- **【答案】** C
>
> > [!note]- **【分析】**
> > 利用等差数列性质得 $S_{2n-1} = (2n - 1)a_n, T_{2n-1} = (2n - 1)b_n$ ，由 $\frac{a_n}{b_n} \leq \frac{1}{3}$ 即可求解
>
> > [!note]- **【解析】**
> > 由 $\frac{S_n}{T_n} = \frac{n}{2n + 3}$ ，得 $\frac{S_{2n - 1}}{T_{2n - 1}} = \frac{2n - 1}{2(2n - 1) + 3} = \frac{2n - 1}{4n + 1}$
> >
> > 又 $\frac{S_{2n - 1}}{T_{2n - 1}} = \frac{\frac{(2n - 1)(a_1 + a_{2n - 1})}{2}}{\frac{(2n - 1)(b_1 + b_{2n - 1})}{2}} = \frac{(2n - 1)a_n}{(2n - 1)b_n} = \frac{a_n}{b_n}$ ，所以 $\frac{2n - 1}{4n + 1}\leq \frac{1}{3}$
> >
> > 整理得 $6n - 3 \leq 4n + 1$ ，所以 $n \leq 2$ ，故符合条件的 $n$ 可取 $1, 2$ ，
> >
> > 故选 **C**
