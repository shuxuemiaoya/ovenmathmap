> [!faq]- 《第四章_数列_高效培优单元测试_提升卷_数学人教A版高二选择性必修第二》官方解析
>
> > [!success]- **【答案】** B
>
> > [!note]- **【解析】**
> > 由题意 $S_{n} = 2a_{n} - 2n$ ，所以 $S_{1} = a_{1} = 2a_{1} - 2$ ，解得 $a_1 = 2$ ，而 $a_{n} = S_{n} - S_{n - 1} = 2a_{n} - 2n - \left[2a_{n - 1} - 2(n - 1)\right] = 2a_{n} - 2a_{n - 1} - 2,(n - 2)$ ，从而 $a_{n} = 2a_{n - 1} + 2,(n - 2)$ ，所以 $a_{n} + 2 = 2(a_{n - 1} + 2),(n - 2)$ ，所以 $\{a_n + 2\}$ 是以 $a_1 + 2 = 4$ 为首项、 $^2$ 为公比的等比数列，所以 $a_{n} + 2 = 4\times 2^{n - 1}$ ，解得 $a_{n} = 2^{n + 1} - 2$ ，所以 $b_{n} = (n - \lambda)\log_{2}(a_{n} + 2) = (n - \lambda)(n + 1) = n^{2} + (1 - \lambda)n - \lambda$ ，若数列 $\{b_n\}$ 是递增数列，则当且仅当 $b_{n + 1} > b_n$ 恒成立，所以 $b_{n + 1} - b_n = (n + 1)^2 + (1 - \lambda)(n + 1) - \lambda - [n^2 + (1 - \lambda)n - \lambda] = 2n + 1 + 1 - \lambda = 2n + 2 - \lambda >0$ 恒成立，所以 $\lambda < 2n + 2$ 恒成立，所以 $\lambda < (2n + 2)_{\min} = 4$ ，所以实数 $\lambda$ 的取值范围是 $(- \infty ,4)$
> >
> > 故选：B.
