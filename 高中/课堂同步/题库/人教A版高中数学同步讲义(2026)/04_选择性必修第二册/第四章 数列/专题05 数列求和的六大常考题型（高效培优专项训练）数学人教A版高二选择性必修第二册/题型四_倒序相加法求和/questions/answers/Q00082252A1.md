> [!faq]- 《专题05 数列求和的六大常考题型（高效培优专项训练）数学人教A版高二选择性必修第二册》官方解析
>
> > [!success]- **【答案】** A. 2024 B. 4048 C. 3036 D. 2025
>
> > [!note]- **【分析】**
> > 由 $f(x)$ 表达式及 $a_{n}=\frac{n}{2025}$ 得到 $f(a_{1})+f(a_{2})+\cdots+f(a_{2024})=\sum_{n=1}^{2024}\frac{n}{2025}+\pi\sum_{n=1}^{2024}\sin\left(\frac{n}{2025}-\frac{1}{2}\right)+\sum_{n=1}^{2024}\frac{3}{2}$ ，
> > 利用等差数列求和公式及倒序相加求和可求得结果.
>
> > [!note]- **【解析】**
> > ∵ $f(x)=x+\pi\sin\left(x-\frac{1}{2}\right)+\frac{3}{2}$ ， $a_{n}=\frac{n}{2025}$ ∴ $f(a_{n}) = \frac{n}{2025} + \pi \sin \left( \frac{n}{2025} - \frac{1}{2} \right) + \frac{3}{2}$ 则 $f(a_{1}) + f(a_{2}) + \cdots + f(a_{2024}) = \sum_{n=1}^{2024} \frac{n}{2025} + \pi \sum_{n=1}^{2024} \sin \left( \frac{n}{2025} - \frac{1}{2} \right) + \sum_{n=1}^{2024} \frac{3}{2}$ .
> >
> > $$
> > \text {因为} \sin \left(\frac {n}{2 0 2 5} - \frac {1}{2}\right) + \sin \left(\frac {2 0 2 5 - n}{2 0 2 5} - \frac {1}{2}\right) = \sin \left(\frac {n}{2 0 2 5} - \frac {1}{2}\right) + \sin \left(1 - \frac {n}{2 0 2 5} - \frac {1}{2}\right)
> > $$
> >
> > $$
> > = \sin \left(\frac {n}{2 0 2 5} - \frac {1}{2}\right) + \sin \left(\frac {1}{2} - \frac {n}{2 0 2 5}\right) = \sin \left(\frac {n}{2 0 2 5} - \frac {1}{2}\right) - \sin \left(\frac {n}{2 0 2 5} - \frac {1}{2}\right) = 0
> > $$
> >
> > 令 $n=1,2,3,\cdots,2024$ ，得
> >
> > $$
> > \sin \left(\frac {1}{2 0 2 5} - \frac {1}{2}\right) + \sin \left(\frac {2 0 2 4}{2 0 2 5} - \frac {1}{2}\right) = 0;
> > $$
> >
> > $$
> > \sin \left(\frac {2}{2 0 2 5} - \frac {1}{2}\right) + \sin \left(\frac {2 0 2 3}{2 0 2 5} - \frac {1}{2}\right) = 0;
> > $$
> >
> > $$
> > \sin \left(\frac {3}{2 0 2 5} - \frac {1}{2}\right) + \sin \left(\frac {2 0 2 2}{2 0 2 5} - \frac {1}{2}\right) = 0;
> > $$
> >
> > $$
> > \pi \sum_ {n = 1} ^ {2 0 2 4} \sin \left(\frac {n}{2 0 2 5} - \frac {1}{2}\right) = 1 0 1 2 \pi \times 0 = 0.
> > $$
> >
> > 又 $\sum_{n=1}^{2024}\frac{n}{2025} +\sum_{n=1}^{2024}\frac{3}{2} = \frac{1}{2025}\times \frac{(1 + 2024)\times 2024}{2} +\frac{3}{2}\times 2024 = 4048.$
> >
> > 故 $f(a_{1})+f(a_{2})+\cdots+f(a_{2024})=4048.$
> >
> > 故选 **B**
