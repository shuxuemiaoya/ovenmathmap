> [!faq]- 《专题05 数列求和的六大常考题型（高效培优专项训练）数学人教A版高二选择性必修第二册》官方解析
>
> > [!success]- **【答案】** (1) $a_{n}=n,S_{n}=\frac{n(n+1)}{2}$ ; (2)证明见解析; (3) $\left[-\frac{256}{1053},\frac{1024}{4131}\right]$ .
>
> > [!note]- **【分析】**
> > 升次作差得 $a_{n + 1} - a_n = 1$ ，再利用等差数列通项公式和求和公式即可得到答案；
> >
> > （2）化简得 $\frac{1}{b_n} = 3\left[\frac{1}{n(n + 1)} -\frac{1}{(n + 1)(n + 2)}\right]$ ，再利用裂项求和法即可证明；
> >
> > （3）利用错位相减法得 $T_{n} = -\frac{3}{16} - \frac{4n + 1}{16} (-3)^{n + 1}$ ，再分奇偶数讨论并分离参数，最后根据作商法即可求出答案.
>
> > [!note]- **【解析】**
> > （1）∵ $2S_{n}=a_{n}^{2}+a_{n}(n\in\mathbf{N}^{*})$ ，①，
> >
> > $$
> > \therefore 2 S _ {n + 1} = a _ {n + 1} ^ {2} + a _ {n + 1} \left(n \in \mathbf {N} ^ {*}\right), \tag {②}
> > $$
> >
> > 由② - ①得 $2a_{n+1} = a_{n+1}^2 - a_n^2 + a_{n+1} - a_n\left(n \in \mathbf{N}^*\right)$ ,
> >
> > 即 $a_{n + 1} + a_n = a_{n + 1}^2 -a_n^2 = (a_{n + 1} + a_n)\cdot (a_{n + 1} - a_n)$
> >
> > 又 $a_{n} > 0, \therefore a_{n + 1} - a_{n} = 1$
> >
> > 又 $2a_{1} = a_{1}^{2} + a_{1}$ ，解得 $a_1 = 1$ 或0（舍），
> >
> > $$
> > a _ {n} = 1 + (n - 1) \times 1 = n, 2 S _ {n} = a _ {n} ^ {2} + a _ {n} = n ^ {2} + n \Rightarrow S _ {n} = \frac {n (n + 1)}{2}
> > $$
> >
> > (2) 由 (1) 可知 $b_{n} = \frac{n + 2}{3} S_{n} = \frac{n(n + 1)(n + 2)}{6}$ ，则
> >
> > $$
> > \frac {1}{b _ {n}} = \frac {6}{n (n + 1) (n + 2)} = 3 \left[ \frac {1}{n (n + 1)} - \frac {1}{(n + 1) (n + 2)} \right]
> > $$
> >
> > 于是有： $\frac{1}{b_{1}}+\frac{1}{b_{2}}+\cdots+\frac{1}{b_{n}}=3\left[\frac{1}{1\times2}-\frac{1}{2\times3}+\frac{1}{2\times3}-\frac{1}{3\times4}+\cdots+\frac{1}{n(n+1)}-\frac{1}{(n+1)(n+2)}\right]$
> >
> > $$
> > = 3 \left[ \frac {1}{2} - \frac {1}{(n + 1) (n + 2)} \right] <   3 \times \frac {1}{2} = \frac {3}{2}.
> > $$
> >
> > (3) 由 (1) 可知： $c_{n}=a_{n}\cdot3^{a_{n}}\cdot\cos(a_{n}\pi)=n\cdot3^{n}\cdot\cos(n\pi)=n\cdot(-3)^{n}$
> >
> > $$
> > T _ {n} = (- 3) ^ {1} + 2 \cdot (- 3) ^ {2} + 3 \cdot (- 3) ^ {3} + \dots + n \cdot (- 3) ^ {n} (1)
> > $$
> >
> > $$
> > - 3 T _ {n} = (- 3) ^ {2} + 2 \cdot (- 3) ^ {3} + 3 \cdot (- 3) ^ {4} + \dots + (n - 1) \cdot (- 3) ^ {n} + n (- 3) ^ {n + 1} \tag {②}
> > $$
> >
> > $$
> > 4 T _ {n} = (- 3) ^ {1} + (- 3) ^ {2} + (- 3) ^ {3} + (- 3) ^ {4} + \dots + (- 3) ^ {n} - n (- 3) ^ {n + 1}
> > $$
> >
> > $$
> > = \frac {- 3 [ 1 - (- 3) ^ {n} ]}{1 - (- 3)} - n (- 3) ^ {n + 1} = - \frac {3}{4} - \frac {4 n + 1}{4} (- 3) ^ {n + 1},
> > $$
> >
> > $$
> > \therefore T _ {n} = - \frac {3}{1 6} - \frac {4 n + 1}{1 6} (- 3) ^ {n + 1}
> > $$
> >
> > $\therefore \lambda (16T_{n} + 3) = -\lambda (4n + 1)(-3)^{n + 1}\leq 4^{n + 1}$
> >
> > 当 $n$ 为奇数时， $-\lambda \leq \frac{4^{n + 1}}{(4n + 1)3^{n + 1}}$
> >
> > 当 $n$ 为偶数时， $\lambda \leq \frac{4^{n+1}}{(4n+1)3^{n+1}}$
> >
> > 令 $f(n) = \frac{4^{n + 1}}{(4n + 1)3^{n + 1}} = \frac{\left(\frac{4}{3}\right)^{n + 1}}{4n + 1}$ ，则 $\frac{f(n + 2)}{f(n)} = \frac{\left(\frac{4}{3}\right)^2(4n + 1)}{4n + 9} = \frac{64n + 16}{36n + 81}$
> >
> > 由 $\frac{f(n+2)}{f(n)}=\frac{\left(\frac{4}{3}\right)^{2}(4n+1)}{4n+9}=\frac{64n+16}{36n+81}$ 1，得 n $\frac{65}{28}=2\frac{9}{28}$
> >
> > 当 n 为奇数时，则有 $f(1) > f(3) < f(5) < f(7) < \cdots$
> >
> > 则 $-\lambda \leq f(3), \therefore \lambda - f(3) = -\frac{1}{13} \times \left(\frac{4}{3}\right)^4 = -\frac{256}{1053}$ ;
> >
> > 当 n 为偶数时， $f(2) > f(4) < f(6) < f(8) \cdots$
> >
> > 则 $\lambda \leq f(4) = \frac{1}{17} \times \left(\frac{4}{3}\right)^{5} = \frac{1024}{4131}$ ，
> >
> > 综上：实数 $\lambda$ 的取值范围为 $\left[-\frac{256}{1053}, \frac{1024}{4131}\right]$
