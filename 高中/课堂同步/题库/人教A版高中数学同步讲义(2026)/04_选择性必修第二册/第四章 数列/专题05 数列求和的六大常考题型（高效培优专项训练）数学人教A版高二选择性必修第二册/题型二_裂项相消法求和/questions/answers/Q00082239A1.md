> [!faq]- 《专题05 数列求和的六大常考题型（高效培优专项训练）数学人教A版高二选择性必修第二册》官方解析
>
> > [!success]- **【答案】** (1) $\alpha = -\frac{1}{2}(2)b_n = -\frac{1}{2(n + 1)}$ (3)证明见解析
>
> > [!note]- **【分析】**
> > （1）由递推式求得 $a_2, a_3$ ，进而由题意得到关于 $\alpha$ 的方程，再检验得到的 $\alpha$ 的值；
> >
> > (2) 利用构造法证得 $\left\{\frac{1}{b_{n}}\right\}$ 为等差数列，从而得解；
> >
> > (3) 利用 (2) 中结论求得 $a_{n}$ , 再利用分组求和法与裂项求和法即可得证.
>
> > [!note]- **【解析】**
> > （1）由题知数列 $\left\{\frac{1}{b_n}\right\}$ 是等差数列，则 $\frac{2}{b_2} = \frac{1}{b_1} +\frac{1}{b_3}$
> >
> > $$
> > \because a _ {1} = \frac {1}{4}, (1 - a _ {n}) a _ {n + 1} = \frac {1}{4}, \therefore a _ {2} = \frac {1}{3}, a _ {3} = \frac {3}{8}
> > $$
> >
> > 由 $b_{n} = a_{n} + \alpha$ 可得： $b_{1} = \frac{1}{4} +\alpha$ ， $b_{2} = \frac{1}{3} +\alpha$ ， $b_{3} = \frac{3}{8} +\alpha$
> >
> > $\therefore \frac{2}{\frac{1}{3} + \alpha} = \frac{1}{\frac{1}{4} + \alpha} + \frac{1}{\frac{3}{8} + \alpha}$ ，解得： $\alpha = -\frac{1}{2}$
> >
> > (2) 由 (1) 知： $b_{1} = -\frac{1}{4}$ ， $b_{2} = -\frac{1}{6}$ ， $b_{3} = -\frac{1}{8}$ ，
> >
> > 则等差数列 $\left\{\frac{1}{b_n}\right\}$ 公差为 $d = \frac{1}{b_2} -\frac{1}{b_1} = -6 - (-4) = -2$
> >
> > 数列 $\left\{\frac{1}{b_n}\right\}$ 是以为首项，为公差的等差数列，
> >
> > $\therefore \frac{1}{b_n} = -4 + (n - 1)(-2) = -2(n + 1)$
> >
> > $\therefore b_{n} = -\frac{1}{2(n + 1)}$
> >
> > (3) 证明：由（1）、（2）知 $a_{n} = b_{n} + \frac{1}{2} = \frac{n}{2(n + 1)}$
> >
> > $$
> > \therefore \frac {a _ {n + 1}}{a _ {n}} = \frac {\frac {n + 1}{2 (n + 2)}}{\frac {n}{2 (n + 1)}} = \frac {(n + 1) ^ {2}}{n (n + 2)} = 1 + \frac {1}{n (n + 2)} = 1 + \frac {1}{2} \left(\frac {1}{n} - \frac {1}{n + 2}\right)
> > $$
> >
> > $$
> > \therefore \frac {a _ {2}}{a _ {1}} + \frac {a _ {3}}{a _ {2}} + \dots + \frac {a _ {n + 1}}{a _ {n}} = n + \frac {1}{2} \left(1 - \frac {1}{3} + \frac {1}{2} - \frac {1}{4} + \frac {1}{3} - \frac {1}{5} + \dots + \frac {1}{n - 1} - \frac {1}{n + 1} + \frac {1}{n} - \frac {1}{n + 2}\right)
> > $$
> >
> > $$
> > = n + \frac {1}{2} \left(1 + \frac {1}{2} - \frac {1}{n + 1} - \frac {1}{n + 2}\right) = n + \frac {3}{4} - \frac {1}{2} \left(\frac {1}{n + 1} + \frac {1}{n + 2}\right),
> > $$
> >
> > $$
> > \because n \in \mathrm{N} ^ {*}, \therefore n + \frac {3}{4} - \frac {1}{2} \left(\frac {1}{n + 1} + \frac {1}{n + 2}\right) <   n + \frac {3}{4}, \therefore \frac {a _ {2}}{a _ {1}} + \frac {a _ {3}}{a _ {2}} + \dots + \frac {a _ {n - 1}}{a _ {n}} <   n + \frac {3}{4}.
> > $$
