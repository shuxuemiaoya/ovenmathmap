> [!faq]- 《专题05 数列求和的六大常考题型（高效培优专项训练）数学人教A版高二选择性必修第二册》官方解析
>
> > [!success]- **【答案】** (1) $a_{n}=2n-1^{(2)}T_{n}=\frac{1}{3}-\frac{1}{4}\left(\frac{1}{(2n+1)}+\frac{1}{(2n+3)}\right)$
>
> > [!note]- **【分析】**
> > （1）根据已知条件求出 $a_1 = 1$ ，再通过 $S_{n}$ 与 $S_{n - 1}$ 的关系推出数列 $\{a_n\}$ ，进而求出其通项公式.
> > （2）将数列 $\{b_n\}$ 裂项，根据裂项相消法求其前 $n$ 项和.
>
> > [!note]- **【解析】**
> > （1）当 $n = 1$ 时， $\sqrt{a_1} = \frac{1}{2}\left(a_1 + 1\right)$ ，解得 $a_1 = 1$
> >
> > 当 $n$ 2时， $S_{n} = \frac{1}{4}\big(a_{n} + 1\big)^{2}$ ， $S_{n - 1} = \frac{1}{4}\big(a_{n - 1} + 1\big)^{2}$ .
> >
> > 两式相减得: $S_{n} - S_{n - 1} = \frac{1}{4}\left[\left(a_{n} + 1\right)^{2} - \left(a_{n - 1} + 1\right)^{2}\right] = \frac{1}{4}\left[a_{n}^{2} - a_{n - 1}^{2} + 2\left(a_{n} - a_{n - 1}\right)\right].$
> >
> > 整理得到: $4a_{n} = a_{n}^{2} - a_{n-1}^{2} + 2(a_{n} - a_{n-1}), a_{n}^{2} - a_{n-1}^{2} - 2(a_{n} + a_{n-1}) = 0, (a_{n} + a_{n-1})(a_{n} - a_{n-1} - 2) = 0$ .
> >
> > $$
> > \because a _ {n} > 0, \therefore a _ {n} - a _ {n - 1} = 2
> > $$
> >
> > ∴数列 $\left\{a_{n}\right\}$ 是首项为1，公差为2的等差数列.
> >
> > $$
> > \therefore a _ {n} = 2 n - 1
> > $$
> >
> > (2) 由 (1) 得 $b_{n} = \frac{1}{(2n - 1)(2n + 3)} = \frac{1}{4}\left(\frac{1}{2n - 1} - \frac{1}{2n + 3}\right)$ .
> >
> > $$
> > T _ {n} = \frac {1}{4} \left[ \left(1 - \frac {1}{5}\right) + \left(\frac {1}{3} - \frac {1}{7}\right) + \left(\frac {1}{5} - \frac {1}{9}\right) + \dots + \left(\frac {1}{2 n - 3} - \frac {1}{2 n + 1}\right) + \left(\frac {1}{2 n - 1} - \frac {1}{2 n + 3}\right) \right]
> > $$
> >
> > $$
> > = \frac {1}{4} \left[ 1 + \frac {1}{3} - \frac {1}{2 n + 1} - \frac {1}{2 n + 3} \right] = \frac {1}{3} - \frac {1}{4} \left(\frac {1}{2 n + 1} + \frac {1}{2 n + 3}\right)
> > $$
> >
> > 16. 等比数列 $\{a_{n}\}$ 中， $a_{2} = 16, S_{3} = 56$ ，且数列 $\{a_{n}\}$ 单调递增.
> >
> > (1)求数列 $\{a_{n}\}$ 的通项公式；
> >
> > (2)设 $b_{n}=\log_{2}a_{n}$ ，求数列 $\left\{\frac{1}{b_{n}\cdot b_{n+1}}\right\}$ 的前n项和 $T_{n}$ .
> >
> > 【答案】(1) $a_{n}=2^{n+2}\left(n\in\mathrm{N}^{*}\right)(2)T_{n}=\frac{n}{3n+9}\left(n\in\mathrm{N}^{*}\right)$
> >
> > 【分析】（1）利用等比数列的定义与性质列方程计算即可；
> >
> > (2) 利用裂项相消法求和即可.
> >
> > 【详解】（1）设等比数列 $\{a_{n}\}$ 的公比为 $q$ ，
> >
> > 由题意得 $S_{3} = a_{1} + a_{2} + a_{3} = \frac{16}{q} + 16 + 16q = 56$ ，解得 $q = 2$ 或 $\frac{1}{2}$ ，
> >
> > 因为 $\{a_{n}\}$ 单调递增，所以 $q = 2$
> >
> > 所以 $\left\{a_{n}\right\}$ 的通项公式为 $a_{n}=a_{2}\cdot q^{n-2}=2^{n+2}$
> >
> > 即 $a_{n}=2^{n+2}\left(n\in\mathbf{N}^{*}\right)$ ;
> >
> > (2) 因为 $b_{n} = \log_{2} a_{n}$ ，所以 $b_{n} = n + 2$ ，
> >
> > 记 $c_{n} = \frac{1}{b_{n}\cdot b_{n + 1}}$ ，则 $c_{n} = \frac{1}{(n + 3)\cdot(n + 2)} = \frac{1}{n + 2} -\frac{1}{n + 3}$
> >
> > 所以 $T_{n}=c_{1}+c_{2}+c_{3}+\ldots+c_{n}=\frac{1}{3}-\frac{1}{4}+\frac{1}{4}-\frac{1}{5}+\frac{1}{5}-\frac{1}{6}+\ldots+\frac{1}{n+2}-\frac{1}{n+3}$
> >
> > $$
> > T _ {n} = c _ {1} + c _ {2} + c _ {3} + \dots + c _ {n} = \frac {1}{3} - \frac {1}{n + 3} = \frac {n}{3 n + 9}
> > $$
> >
> > 综上所述 $T_{n} = \frac{n}{3n + 9}\Big(n\in \mathbf{N}^{*}\Big).$
