> [!faq]- 《专题05 数列求和的六大常考题型（高效培优专项训练）数学人教A版高二选择性必修第二册》官方解析
>
> > [!success]- **【答案】** (1) $k = -1, b = 0$ ， $a_n = 2^n + n$ (2) $S_{n} = \frac{4^{n + 1} + 2}{3} +(n - 1)2^{n + 1}$
>
> > [!note]- **【分析】**
> > （1）设数列公比为，进而待定系数得 $\left\{ \begin{array}{l} q = 2, \\ k = -1, \\ b = 0 \end{array} \right.$ 再根据等比数列的通项公式求解即可得 $\left\{ a_n \right\}$ 的通项公式；
> >
> > (2) 结合 (1) 得 $b_{n} = 4^{n} + n \cdot 2^{n}$ ，再根据分组求和与错位相减法求解即可.
>
> > [!note]- **【解析】**
> > （1）解：因为数列 $\{a_{n} + kn + b\}$ 为等比数列（ $k, b$ 为常数），设公比为 $q$ ，
> >
> > 所以，当 $n$ 2时， $a_{n} + kn + b = q\left[a_{n - 1} + k(n - 1) + b\right]$ ，即 $a_{n} = qa_{n - 1} + (qk - k)n - qk + qb - b$
> >
> > 因为， $n$ 2时， $a_{n} = 2a_{n - 1} - n + 2$
> >
> > 所以 $\left\{\begin{aligned}q&=2,\\ qk-k&=-1,\\ -qk+qb-b&=2\end{aligned}\right.$ ，解得 $\left\{\begin{aligned}q&=2,\\ k&=-1,\\ b&=0\end{aligned}\right.$
> >
> > 所以 $a_{n}-n=2\left[a_{n-1}-(n-1)\right]$ ，n 2，
> >
> > 又 $a_{1} = 3$ ， $a_1 - 1 = 2$
> >
> > 所以 $\{a_{n} - n\}$ 是等比数列，公比为2，首项为2，
> >
> > 所以 $a_{n} - n = 2 \times 2^{n - 1} = 2^{n}$ ，即 $a_{n} = 2^{n} + n$
> >
> > (2) 解：由 (1) 知 $b_{n}=a_{n}^{2}-na_{n}=\left(2^{n}+n\right)\cdot2^{n}=4^{n}+n\cdot2^{n}$
> >
> > 令 $\left\{n\cdot2^{n}\right\}$ 的前n项和为 $T_{n}$ ，
> >
> > 则 $T_{n}=1\times2+2\times2^{2}+3\times2^{3}+\cdots+(n-1)\cdot2^{n-1}+n\cdot2^{n}$
> >
> > $2T_{n}=1\times2^{2}+2\times2^{3}+3\times2^{4}+\cdots+(n-1)\cdot2^{n}+n\cdot2^{n+1}$
> >
> > 两式相减得： $-T_{n}=2+2^{2}+2^{3}+2^{4}+\cdots+2^{n}-n\cdot2^{n+1}=\frac{2(1-2^{n})}{1-2}-n\cdot2^{n+1}=2^{n+1}-2-n\cdot2^{n+1}=(1-n)2^{n+1}-2$
> >
> > 所以 $T_{n} = (n - 1)2^{n + 1} + 2$
> >
> > 所以数列 $\{b_n\}$ 的前 $n$ 项和 $S_{n} = \frac{4(1 - 4^{n})}{1 - 4} + (n - 1)\cdot 2^{n + 1} + 2 = \frac{4^{n + 1} - 4}{3} + (n - 1)\cdot 2^{n + 1} + 2 = \frac{4^{n + 1} + 2}{3} + (n - 1)\cdot 2^{n + 1}$ .
