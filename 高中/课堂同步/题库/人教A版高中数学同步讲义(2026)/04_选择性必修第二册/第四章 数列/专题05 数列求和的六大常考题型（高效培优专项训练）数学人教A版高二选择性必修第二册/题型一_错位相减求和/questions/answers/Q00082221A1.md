> [!faq]- 《专题05 数列求和的六大常考题型（高效培优专项训练）数学人教A版高二选择性必修第二册》官方解析
>
> > [!success]- **【答案】** (1) $a_{n}=n$ (2) $(n - 1)\cdot 2^{n + 1} + 2$ (3)证明见解析
>
> > [!note]- **【分析】**
> > （1）由 $2S_{n} = a_{n}^{2} + n$ 得 $2S_{n + 1} = a_{n + 1}^{2} + n + 1$ ，两式相减，根据 $a_{n}$ 与 $S_{n}$ 的关系构造关于 $a_{n + 1},a_n$ 的关系，结合已知条件即可求出 $\{a_n\}$ 为等差数列，根据等差数列的通项公式即可求得答案；
> >
> > (2) 利用错位相减法即可求解；
> >
> > (3) 当 $n = 2$ 时，利用 $\frac{1}{a_n S_n} = \frac{2}{n^2 (n + 1)} < \frac{2}{n(n - 1)(n + 1)} = \frac{1}{n(n - 1)} - \frac{1}{n(n + 1)}$ ，放缩后再裂项相消即可得证.
>
> > [!note]- **【解析】**
> > （1）∵ $2S_{n}=a_{n}^{2}+n$ ，∴ $2S_{n+1}=a_{n+1}^{2}+n+1$ ，
> >
> > 两式相减得 $2a_{n+1}=a_{n+1}^{2}-a_{n}^{2}+1$
> >
> > 即 $\left(a_{n + 1} - 1\right)^2 -a_n^2 = 0$ ，即 $(a_{n + 1} - a_n - 1)(a_{n + 1} + a_n - 1) = 0$
> >
> > 当 $n = 1$ 时，有 $2a_{1} = a_{1}^{2} + 1$ ，解得 $a_1 = 1$
> >
> > 又: 数列 $\{a_{n}\}$ 单调递增，故 $a_{n+1} + a_{n} - 1 > 1 > 0$
> >
> > 故只能有 $a_{n+1}-a_{n}=1$
> >
> > 由等差数列的定义可知 $\{a_{n}\}$ 是首项和公差均为1的等差数列，故 $a_{n} = n$
> >
> > (2) $a_{n}\cdot a_{2^{n}} = n\cdot 2^{n}$
> >
> > 记数列 $\{a_{n} \cdot a_{2^{n}}\}$ 前 n 项和为 $T_{n}$
> >
> > 则 $T_{n} = 1 \times 2^{1} + 2 \times 2^{2} \cdots + n \times 2^{n}$
> >
> > 则 $2T_{n}=1\times2^{2}+2\times2^{3}\cdots+(n-1)\times2^{n}+n\times2^{n+1}$
> >
> > 两式相减，得 $T_{n}=n\times2^{n+1}-\left(2^{1}+\cdots+2^{n}\right)=n\times2^{n+1}-\frac{2\left(1-2^{n}\right)}{1-2}=\left(n-1\right)\cdot2^{n+1}+2$
> >
> > (3) 由题， $S_{n}=\frac{a_{n}^{2}+n}{2}=\frac{n^{2}+n}{2}$ ，
> >
> > 当 $n = 1$ 时， $\frac{1}{a_1\cdot S_1} = 1 <   \frac{3}{2}$ ，不等式成立；
> >
> > 当 $n - 2$ 时， $\frac{1}{a_nS_n} = \frac{2}{n(n^2 + n)} = \frac{2}{n^2(n + 1)} < \frac{2}{n(n - 1)(n + 1)} = \frac{1}{n(n - 1)} - \frac{1}{n(n + 1)}$ 故 $\frac{1}{a_1S_1} + \frac{1}{a_2S_2} + \dots + \frac{1}{a_nS_n} < 1 + \frac{1}{2 \times 1} - \frac{1}{2 \times 3} + \frac{1}{3 \times 2} - \frac{1}{3 \times 4} + \dots + \frac{1}{n(n - 1)} - \frac{1}{n(n + 1)}$ ， $= 1 + \frac{1}{2 \times 1} - \frac{1}{n(n + 1)} < \frac{3}{2}$
> >
> > 综上所述，原不等式得证。
