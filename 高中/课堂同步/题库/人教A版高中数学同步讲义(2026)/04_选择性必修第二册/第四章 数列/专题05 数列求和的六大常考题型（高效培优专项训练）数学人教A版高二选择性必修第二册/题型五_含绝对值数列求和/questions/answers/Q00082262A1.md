> [!faq]- 《专题05 数列求和的六大常考题型（高效培优专项训练）数学人教A版高二选择性必修第二册》官方解析
>
> > [!success]- **【答案】** (1) $a_{n} = 2n - 6(n\in \mathbb{N}^{*})$ . (2) $T_{n} = \left\{ \begin{array}{ll}n(5 - n),n < 3,\\ n^{2} - 5n + 12,n & 3, \end{array} \right.$ $n\in \mathbb{N}^*$
>
> > [!note]- **【分析】**
> > （1）首先利用数列 $a_{n}$ 与 $S_{n}$ 的关系式，转化为数列 $\{a_n\}$ 的递推关系式，再通过构造求数列的通项公式；
> >
> > （2）由（1）可知 $a_{n} = 2n - 6\left(n\in \mathbb{N}^{*}\right)$ ，分 $n < 3$ 和 $n$ 3两段，集合数列 $\{a_n\}$ 的特征，和数列的前 $n$ 项和，分别求数列 $\{|a_n|\}$ 的和.
>
> > [!note]- **【解析】**
> > （1）由 $2S_{n} = n(a_{n} - 4) = na_{n} - 4n$ 可得 $2S_{n + 1} = (n + 1)a_{n + 1} - 4(n + 1)$ ，两式相减，得 $2a_{n + 1} = (n + 1)a_{n + 1} - na_{n} - 4$ ，即 $(n - 1)a_{n + 1} = na_n + 4$ 当 $n = 1$ 时， $2a_{1} = a_{1} - 4$ ，则 $a_1 = -4$ 当 $n = 2$ 时， $\frac{a_{n + 1}}{n} = \frac{a_n}{n - 1} +\frac{4}{n(n - 1)} = \frac{a_n}{n - 1} +\frac{4}{n - 1} -\frac{4}{n}$ ，即 $\frac{a_{n + 1} + 4}{n} = \frac{a_n + 4}{n - 1}$
> >
> > 于是由递推关系得 $\frac{a_{n}+4}{n-1}=a_{2}+4=2$ ，得 $a_{n}=2n-6(n-2)$ ，
> > 而 $a_{1}=-4=2\times1-6$ ，满足上式，
> > 故数列 $\left\{a_{n}\right\}$ 的通项公式为 $a_{n}=2n-6\left(n\in\mathbb{N}^{*}\right)$ .
> > (2) 由 $a_{n}=2n-6$ 得，
> > 当 n<3 时， $a_{n}<0$ ，则 $\left|a_{n}\right|=6-2n$ 所以 $T_{n}=\frac{n(6-2+6-2n)}{2}=n(5-n)$ ;
> > 当 n 3 时， $a_{n}$ 0，注意到 $S_{n}=\frac{n}{2}(a_{n}-4)=n(n-5)$ ，
> > 故 $T_{n}=\left|a_{1}\right|+\left|a_{2}\right|+a_{3}+\cdots+a_{n}=S_{n}-2\left(a_{1}+a_{2}\right)=n^{2}-5n+12$ 综上， $T_{n}=\left\{\begin{aligned}&n(5-n),&n<3,\\ &n^{2}-5n+12,n&3,\end{aligned}\right.$ $n\in N^{*}$
