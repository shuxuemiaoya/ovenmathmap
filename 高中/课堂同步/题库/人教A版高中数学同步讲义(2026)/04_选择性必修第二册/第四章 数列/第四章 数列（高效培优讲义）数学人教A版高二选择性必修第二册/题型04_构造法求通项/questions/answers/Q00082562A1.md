> [!faq]- 《第四章 数列（高效培优讲义）数学人教A版高二选择性必修第二册》官方解析
>
> > [!success]- **【答案】** A
>
> > [!note]- **【解析】**
> > 由条件可得 $\frac{1}{a_{n + 1}} = \frac{1}{a_n} +\frac{1}{2}$ ，则 $\frac{1}{a_n} = \frac{1}{2} n + \frac{1}{2}$ ，进而可求出数列 $\{a_n\}$ 的通项公式，令 $a_{n} = \frac{2}{101}$ ，求出 $n$ 值
> >
> > 即可·
> >
> > 【详解】解：由 $a_{n + 1} = \frac{2a_n}{a_n + 2}\big(n\in N^*\big)$ ，得 $\frac{1}{a_{n + 1}} = \frac{a_n + 2}{2a_n} = \frac{1}{a_n} +\frac{1}{2}$
> >
> > $$
> > \frac {1}{a _ {n}} = \frac {1}{a _ {1}} + \frac {1}{2} (n - 1) = 1 + \frac {1}{2} (n - 1) = \frac {1}{2} n + \frac {1}{2}
> > $$
> >
> > $$
> > \therefore a _ {n} = \frac {2}{n + 1}
> > $$
> >
> > $$
> > a _ {n} = \frac {2}{n + 1} = \frac {2}{1 0 1}, \text {得} n = 1 0 0.
> > $$
> >
> > 故选：A.
> >
> > ## 方法技巧
> >
> > (1)形如 $a_{n + 1} = pa_n + f(n)(p\neq 1)$ 型的递推式：
> > - **①**：待定系数法： $a_{n+1}=pa_{n}+q$ （其中p,q均为常数， $(pq(p-1)\neq0)$ ）
> >
> > 解法：把原递推公式转化为： $a_{n + 1} - t = p(a_n - t)$ ，其中 $t = \frac{q}{1 - p}$ ，再利用换元法转化为等比数列求解.
> > - **②**：待定系数法： $a_{n + 1} = pa_n + q^n$ （其中 $p,q$ 均为常数， $(pq(p - 1)(q - 1)\neq 0)$ ）.（或 $a_{n + 1} = pa_n + rq^n$ 其中
> >
> > $p,q,r$ 均为常数）.
> >
> > 解法：在原递推公式两边同除以 $q^{n + 1}$ ，得： $\frac{a_{n + 1}}{q^{n + 1}} = \frac{p}{q}\cdot \frac{a_n}{q^n} +\frac{1}{q}$ ，令 $b_{n} = \frac{a_{n}}{q^{n}}$ ，得： $b_{n + 1} = \frac{p}{q} b_n + \frac{1}{q}$ ，再按第
> >

> > - **①**：种情况求解.
> > - **③**：待定系数法： $a_{n+1}=pa_{n}+an+b\ (p\neq1,0,\ a\neq0)$
> >
> > 解法：一般利用待定系数法构造等比数列，即令 $a_{n + 1} + x(n + 1) + y = p(a_n + xn + y)$ ，与已知递推式比较，
> >
> > 解出 $x, y$ ，从而转化为 $\left\{a_n + xn + y\right\}$ 是公比为 $p$ 的等比数列.
> > - **④**：待定系数法： $a_{n+1}=pa_{n}+an^{2}+bn+c(p\neq0,1,a\neq0)$
> >
> > 解法：一般利用待定系数法构造等比数列，即令 $a_{n + 1} + x(n + 1)^2 +y(n + 1) + z = p(a_n + xn^2 +yn + z)$ ，与已
> >
> > 知递推式比较，解出 $x, y$ ，从而转化为 $\left\{a_n + x n^2 + y n + z\right\}$ 是公比为 $p$ 的等比数列.
> >
> > (2)形如 $a_{n + 2} = pa_{n + 1} + qa_n$ 型的递推式：
> >
> > 用待定系数法，化为特殊数列 $\{a_{n} - a_{n - 1}\}$ 的形式求解．方法为：设 $a_{n + 2} - ka_{n + 1} = h(a_{n + 1} - ka_n)$ ，比较系数得
> >
> > $h + k = p, - hk = q$ ，可解得 $h, k$ ，于是 $\{a_{n+1} - ka_n\}$ 是公比为 $h$ 的等比数列，这样就化归为 $a_{n+1} = pa_n + q$ 型.
