> [!faq]- 《第四章 数列（高效培优讲义）数学人教A版高二选择性必修第二册》官方解析
>
> > [!success]- **【答案】** (1) $a_{n}=2n-6$ (2) 5
>
> > [!note]- **【分析】**
> > （ $^{1}$ ）设出公差后，借助等差数列求和公式与基本量计算即可得；
> >
> > (2) 借助等差数列求和公式与作差法计算即可得.
>
> > [!note]- **【解析】**
> > （1）设等差数列 $\left\{a_{n}\right\}$ 的公差为 $d$ ，由 $a_3 = S_5$ ，有 $a_1 + 2d = 5a_1 + 10d$ ，即 $a_1 = -2d$ ，由 $a_2a_4 = S_4$ ，有 $(a_1 + d)(a_1 + 3d) = 4a_1 + 6d$ ，将 $a_1 = -2d$ 代入得 $d^2 = 2d$ ，
> >
> > 则 $d = 2$ 或 $d = 0$ ，又数列 $\left\{a_{n}\right\}$ 的公差不为0
> >
> > 故 $d = 2$ ，则 $a_1 = -2d = -4$
> >
> > 故数列 $\left\{a_{n}\right\}$ 的通项公式 $a_{n}=-4+2(n-1)=2n-6$ ;
> >
> > (2) $S_{n} - a_{n} = \frac{(-4 + 2n - 6)\cdot n}{2} - (2n - 6) = n^{2} - 7n + 6 = (n - 1)(n - 6) <   0$
> >
> > 则 $1 < n < 6$ ，又 $n \in \mathbf{N}^*$ ，故使 $S_n < a_n$ 成立的 $n$ 的最大值为 5.
