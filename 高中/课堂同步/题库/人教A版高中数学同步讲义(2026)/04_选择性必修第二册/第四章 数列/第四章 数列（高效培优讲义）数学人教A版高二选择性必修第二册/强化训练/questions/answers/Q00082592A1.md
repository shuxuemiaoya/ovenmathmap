> [!faq]- 《第四章 数列（高效培优讲义）数学人教A版高二选择性必修第二册》官方解析
>
> > [!success]- **【答案】** (1) $a_{n} = 2n + 1, b_{n} = 2n - 1$ (2) $\frac{n}{2n+1}$
>
> > [!note]- **【分析】**
> > （ $^{1}$ ）根据题中条件，即可求解公差，进而根据等差通项公式即可求解，
> >
> > (2) 利用裂项相消法求和即可得解·
>
> > [!note]- **【解析】**
> > （1）由题意可得 $a_{2} = b_{2} + 2 = 5, b_{1} = a_{1} - 2 = 1$
> >
> > 则 $\{a_{n}\}$ 的首项为 $3$ 、公差为 $2$ ， $\{b_{n}\}$ 的首项为 $1$ 、公差为 $2$ ：
> >
> > 故 $a_{n} = 3 + 2(n - 1) = 2n + 1, b_{n} = 1 + 2(n - 1) = 2n - 1$
> >
> > (2) 由 (1) 得 $a_{n}b_{n} = (2n + 1)(2n - 1)$ .
> >
> > $$
> > \frac {1}{a _ {n} b _ {n}} = \frac {1}{(2 n - 1) (2 n + 1)} = \frac {1}{2} \left(\frac {1}{2 n - 1} - \frac {1}{2 n + 1}\right)
> > $$
> >
> > $$
> > S _ {n} = \frac {1}{2} \left[ \left(1 - \frac {1}{3}\right) + \left(\frac {1}{3} - \frac {1}{5}\right) + \dots + \left(\frac {1}{2 n - 1} - \frac {1}{2 n + 1}\right) \right] = \frac {1}{2} \left(1 - \frac {1}{2 n + 1}\right) = \frac {n}{2 n + 1}
> > $$
