> [!faq]- 《专题4_4_数学归纳法_高效培优讲义_数学人教A版高二选择性必修第二册》官方解析
>
> > [!success]- **【答案】** ①②④
>
> > [!note]- **【分析】**
> > 利用作差法可判断①；利用数学归纳法可判断②④；利用特例法可判断③
>
> > [!note]- **【解析】**
> > - **对于①**：，根据题意得 $a_{2}=a_{1}+a_{1}^{2}=a_{1}(1+a_{1})$ ， $a_{3}=a_{2}+\frac{a_{2}^{2}}{4}=a_{1}(1+a_{1})+\frac{a_{1}^{2}(1+a_{1})^{2}}{4}$
> >
> > 所以 $S_{1} + S_{3} - 2S_{2} = 2a_{1} + a_{2} + a_{3} - 2(a_{1} + a_{2}) = a_{3} - a_{2} = \frac{a_{2}^{2}}{4} > 0$ ，故 $2S_{2} < S_{1} + S_{3}$ ，①对；
> > - **对于②**：，因为 $a_1 \leq 1 \cdot a_1$ ，对任意的 $k \in \mathbf{N}^*$ ，猜想 $a_k \leq ka_1$ ，
> >
> > 则当 $n = k + 1$ 时， $a_{k + 1} = a_k + \frac{a_k^2}{k^2} \leq ka_1 + a_1^2 < ka_1 + a_1 = (k + 1)a_1$
> >
> > 这说明当 $n = k + 1$ 时， $a_{k + 1} \leq (k + 1)a_1$ ，猜想成立，故对任意的 $n \in \mathbf{N}^*$ ， $a_n \leq na_1$ ，②对；
> > - **对于③**：，若 $a_1 = \frac{1}{2}$ ，则 $a_2 = a_1 + a_1^2 = \frac{1}{2} + \frac{1}{4} = \frac{3}{4}$ ，此时， $a_2 = \frac{3}{4} < 2 - 1$ ，故③错；
> > - **对于④**：，因为 $a_1 = \frac{1}{2}$ ，则 $a_2 = \frac{3}{4}$ ， $a_3 = a_2 + \frac{a_2^2}{4} = \frac{3}{4} + \frac{9}{64} = \frac{57}{64} < \frac{6}{5} = \frac{3 \times (3 - 1)}{3 + 2}$
> >
> > 假设当 $n = k(k - 3)$ 时，猜想成立，即 $a_{k} < \frac{3(k - 1)}{k + 2}$
> >
> > 则当 $n = k + 1$ 时， $a_{k + 1} = a_k + \frac{a_k^2}{k^2} < \frac{3(k - 1)}{k + 2} + \frac{9(k - 1)^2}{k^2(k + 2)^2}$ ，
> >
> > 接下来比较 $\frac{9(k - 1)^2}{k^2(k + 2)^2}$ 与 $\frac{9}{(k + 2)(k + 3)}$ 的大小，
> >
> > 因为 $\frac{9(k - 1)^2}{k^2(k + 2)^2} -\frac{9}{(k + 2)(k + 3)} = \frac{9(k - 1)^2(k + 3) - 9k^2(k + 2)}{k^2(k + 2)^2(k + 3)}$
> >
> > $$
> > = \frac {9 (3 - 5 k - k ^ {2})}{k ^ {2} (k + 2) ^ {2} (k + 3)} <   0
> > $$
> >
> > 故 $\frac{9(k-1)^{2}}{k^{2}(k+2)^{2}}<\frac{9}{(k+2)(k+3)}$ ，
> >
> > 因此 $a_{k + 1} = a_k + \frac{a_k^2}{k^2} < \frac{3(k - 1)}{k + 2} +\frac{9(k - 1)^2}{k^2(k + 2)^2} < \frac{3(k - 1)}{k + 2} +\frac{9}{(k + 2)(k + 3)}$
> >
> > $$
> > = \frac {3 (k - 1) (k + 3) + 9}{(k + 2) (k + 3)} = \frac {3 k (k + 2)}{(k + 2) (k + 3)} = \frac {3 k}{k + 3}
> > $$
> >
> > 故当 $n = k + 1$ 时，猜想也成立，故当 $n = 3$ 时， $a_{n} < \frac{3(n - 1)}{n + 2}$ ，④对
> >
> > 故答案为：①②④
