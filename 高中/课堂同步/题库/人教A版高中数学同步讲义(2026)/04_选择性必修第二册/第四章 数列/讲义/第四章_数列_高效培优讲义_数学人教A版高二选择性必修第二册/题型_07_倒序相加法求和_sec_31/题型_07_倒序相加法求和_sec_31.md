## 题型 07 倒序相加法求和

【典例1】已知正数数列 $\left\{a_{n}\right\}$ 是公比不等于1的等比数列，且 $a_{1}a_{2025}=1$ ，试用推导等差数列前n项和的方法
探求：若 $f(x)=\frac{4}{1+x^{2}}$ ，则 $f(a_{1})+f(a_{2})+\cdots+f(a_{2025})=$ \_\_\_\_.

【答案】4050

【分析】根据 $a_1a_{2025} = 1$ 可得 $a_{n}a_{2026 - n} = 1, n \in \mathbb{N}^{*}, n \leq 2025$ ，结合函数得到当 $x \neq 0$ 时， $f(x) + f\left(\frac{1}{x}\right) = 4$ ，进而

结合倒序相加法求解即可·

【详解】正数数列 $\left\{a_{n}\right\}$ 是公比不等于 1 的等比数列， $a_{1}a_{2025}=1$

则 $a_{n}a_{2026 - n} = 1,n\in \mathbf{N}^{*},n\leq 2025$

由 $f(x) = \frac{4}{1 + x^2}$ ，当 $x \neq 0$ 时， $f(x) + f\left(\frac{1}{x}\right) = \frac{4}{1 + x^2} + \frac{4}{1 + \left(\frac{1}{x}\right)^2} = \frac{4}{1 + x^2} + \frac{4x^2}{1 + x^2} = 4$ ，

于是 $f(a_{n}) + f(a_{2026-n}) = f(a_{n}) + f\left(\frac{1}{a_{n}}\right) = 4$

$$
\text {令} T _ {2 0 2 5} = f \left(a _ {1}\right) + f \left(a _ {2}\right) + \dots + f \left(a _ {2 0 2 5}\right)
$$

则 $T_{2025}=f\left(a_{2025}\right)+f\left(a_{2024}\right)+\cdots+f\left(a_{1}\right)$

因此 $2T_{2025}=\left[f\left(a_{1}\right)+f\left(a_{2025}\right)\right]+\left[f\left(a_{2}\right)+f\left(a_{2024}\right)\right]+\cdots+\left[f\left(a_{2025}\right)+f\left(a_{1}\right)\right]=4\times2025$

所以 $T_{2025}=4050$ .

故答案为：4050.

【典例2】已知 $f(x) + f(1 - x) = 2, a_{n} = f(0) + f\left(\frac{1}{n}\right) + \ldots + f\left(\frac{n - 1}{n}\right) + f(1), (n \in \mathbb{N}^{*})$ ，则数列 $\{a_{n}\}$ 的通项公式为（ ）A. $a_{n} = n - 1$ B. $a_{n} = n$ C. $a_{n} = n + 1$ D. $a_{n} = n^{2}$

【答案】C

【分析】利用倒序相加法即可求解

【详解】因 $f(x) + f(1 - x) = 2$

且 $a_{n}=f(0)+f\left(\frac{1}{n}\right)+\ldots+f\left(\frac{n-1}{n}\right)+f(1),$ ①

则 $a_{n} = f(1) + f\left(\frac{n - 1}{n}\right) + \ldots +f\left(\frac{1}{n}\right) + f(0)$ ，②

由① $^{+}$ ②可得： $2a_{n}=\left[f(0)+f(1)\right]+\left[f\left(\frac{1}{n}\right)+f\left(\frac{n-1}{n}\right)\right]+\ldots+\left[f(1)+f(0)\right]=2(n+1)$

故 $a_{n} = n + 1$

故选：C.

## 方法技巧

如果一个数列 $\{a_{n}\}$ ，与首末项等距的两项之和等于首末两项之和，可采用把正着写与倒着写的两个和式相加，就得到一个常数列的和，这一求和方法称为倒序相加法，等差数列前 $n$ 项和公式的推导便使用了此法。用倒序相加法解题的关键，就是要能够找出首项和末项之间的关系，因为有时这种关系比较隐蔽。
