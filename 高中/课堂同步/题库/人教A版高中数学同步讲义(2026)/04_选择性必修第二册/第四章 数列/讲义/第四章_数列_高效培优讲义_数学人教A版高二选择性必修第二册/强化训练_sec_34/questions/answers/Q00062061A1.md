> [!faq]- 《第四章_数列_高效培优讲义_数学人教A版高二选择性必修第二册》官方解析
>
> > [!success]- **【答案】** A
>
> > [!note]- **【分析】**
> > 根据条件，利用等差、等比数列的性质得 $a + b = x + y, cd = xy$ ，从而有 $\frac{(a + b)^2}{2cd} = \frac{(x + y)^2}{2xy}$ ，再利用
> >
> > 基本不等式，即可求解·
>
> > [!note]- **【解析】**
> > ∵ x, a, b, y 成等差数列，x, c, d, y 成等比数列，
> >
> > 所以 $a + b = x + y, cd = xy$ ，且 $x > 0, y > 0$ ，则 $\frac{(a + b)^2}{2cd} = \frac{(x + y)^2}{2xy}$ $\frac{(2\sqrt{xy})^2}{2xy} = 2$
> >
> > 当且仅当 x = y 时取等号，
> >
> > 故选 **A**.
