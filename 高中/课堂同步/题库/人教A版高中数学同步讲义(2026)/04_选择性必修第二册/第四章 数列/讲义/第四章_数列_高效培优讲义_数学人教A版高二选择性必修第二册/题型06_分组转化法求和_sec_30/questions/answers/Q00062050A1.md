> [!faq]- 《第四章_数列_高效培优讲义_数学人教A版高二选择性必修第二册》官方解析
>
> > [!success]- **【答案】** (1) $a_{n}=n+1,\quad b_{n}=3^{n}$ ; (2) $S_{n} = \frac{n^{2} + 3n - 3 + 3^{n + 1}}{2}$ .
>
> > [!note]- **【分析】**
> > （1）利用等差数列性质求出公差，进而求出通项公式；直接求出等比数列通项公式·
> >
> > (2) 利用分组求和法及等差数列、等比数列前 n 项和求解.
>
> > [!note]- **【解析】**
> > （1）在等差数列 $\left\{a_{n}\right\}$ 中， $a_{5} = \frac{a_{2} + a_{8}}{2} = 6$ ，则公差 $d = \frac{a_{5} - a_{3}}{5 - 3} = 1$ ， $a_{n} = a_{3} + (n - 3)d = n + 1$ ；
> >
> > 在等比数列 $\{b_n\}$ 中， $b_2 = 9$ ，公比 $q = 3$ ，则 $b_n = b_2 q^{n-2} = 9 \times 3^{n-2} = 3^n$
> >
> > 所以数列 $\left\{a_{n}\right\}$ 和 $\left\{b_{n}\right\}$ 的通项公式分别为 $a_{n}=n+1,\quad b_{n}=3^{n}$
> >
> > (2) 由 (1) 得 $c_{n} = n + 1 + 3^{n}$
> >
> > 所以数列 $\left\{c_{n}\right\}$ 的前 n 项和 $S_{n}=\left[2+3+4+\cdots+(n+1)\right]+\left(3+3^{2}+3^{3}+\cdots+3^{n}\right)$
> >
> > $$
> > = \frac {n [ 2 + (n + 1) ]}{2} + \frac {3 (1 - 3 ^ {n})}{1 - 3} = \frac {n ^ {2} + 3 n - 3 + 3 ^ {n + 1}}{2}.
> > $$
