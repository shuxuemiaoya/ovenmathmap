## 题型06 等比数列的奇数项与偶数项和

【典例1】已知无穷等比数列 $\{a_{n}\}$ 首项为 $a$ ，公比为 $r$ ，无穷等比数列 $\{b_n\}$ 首项为 $b$ ，公比为 $s\cdot$

(1)若 $\left|r\right|<1$ 且 $\left|s\right|<1$ ，求：数列 $\{a_{n}\}$ 所有奇数项的和与数列 $\{b_{n}\}$ 所有偶数项的和；

(2)若数列 $\{a_{n}\}$ 满足 $a_{n} = -3a_{n + 1}$ ，且 $\sum_{i = 1}^{+\infty}a_{2i} = \frac{9}{2}$ 求： $a$ 的值；

(3)请直接写出： $\lim_{n\to\infty}\frac{a_{n}}{b_{n}}$

【答案】(1) $\frac{a}{1-r^{2}}$ ; $\frac{bs}{1-s^{2}}$

(2) $a = -12$

$$
\lim _ {n \rightarrow \infty} \frac {a _ {n}}{b _ {n}} = \left\{\begin{array}{c}0 0 <   r <   s\\0, s <   r <   0\\\text {不存在}, r s <   0\\+ \infty , r > s > 0, a b > 0\\+ \infty , r <   s \langle 0, a b \rangle 0\\- \infty , r > s > 0, a b <   0\\- \infty , r <   s <   0, a b <   0\\\frac {a}{b}, r = s\end{array}. \right. \tag {3}
$$

【分析】（1）由题意可知数列 $\{a_{n}\}$ 所有奇数项仍成等比数列，数列 $\{b_{n}\}$ 所有偶数项也成等比数列，根据等比

数列的前项和公式表示出数列 $\{a_{n}\}$ 前 $n$ 个奇数项的和与数列 $\{b_{n}\}$ 前 $n$ 个偶数项的和，并分别求出当 $n\to +\infty$ 时

它们的值，即为数列 $\{a_{n}\}$ 所有奇数项的和与数列 $\{b_{n}\}$ 所有偶数项的和；

(2) 根据所给递推公式求得数列 $\{a_{n}\}$ 的公比，代入 $\sum_{i=1}^{+\infty} a_{2i} = \frac{9}{2}$ ，可求得 $a_{1}$ 的值；

(3) 分类讨论 r, s 的取值情况，可得到 $\lim_{n\to\infty}\frac{a_{n}}{b_{n}}$

【详解】（1）等比数列 $\{a_n\}$ 首项为 $a$ ，公比为 $r$ ，若 $|r| < 1$

数列 $\{a_{n}\}$ 前 $n$ 个奇数项的和为 $a_1 + a_3 + a_5 + \dots\dots + a_{2n - 1} = \frac{a\left[1 - \left(r^2\right)^n\right]}{1 - r^2}$

若 $\left|r\right|<1$ ，则由 $r\neq0$ ，得 $0<r^{2}<1$ ，所以当 $n\to+\infty$ 时， $\left(r^{2}\right)^{n}\to0$ 。

所以数列 $\{a_{n}\}$ 所有奇数项的和为 $\frac{a}{1-r^{2}}$

等比数列 $\{b_{n}\}$ 首项为 b，公比为 $s \cdot |s| < 1$

所以数列 $\{b_n\}$ 前 $n$ 个偶数项的和为 $b_{2} + b_{4} + b_{6} + \dots\dots +b_{2n} = \frac{b_2[1 - (s^2)^n]}{1 - s^2}$

若 $|s|<1$ ，则由 $s\neq0$ ，得 $0<s^{2}<1$ ，所以当 $n\to+\infty$ 时， $(s^{2})^{n}\to0$

所以数列 $\{b_{n}\}$ 所有偶数项的和为 $\frac{bs}{1-s^{2}}$

(2) 若数列 $\left\{a_{n}\right\}$ 满足 $a_{n} = -3a_{n+1}$ ，则 $r = -\frac{1}{3}$ .

由 $\sum_{i=1}^{+\infty} a_{2i} = \frac{9}{2}$ ，得 $\lim_{n \to +\infty} \frac{\left(-\frac{1}{3}a\right)\left[1 - \left(-\frac{1}{3}\right)^{2n}\right]}{1 - \left(-\frac{1}{3}\right)^2} = -\frac{3a}{8} = \frac{9}{2}$ ，解得 $a = -12$

(3) 由题可知 $a_{n} = ar^{n - 1}$ , $b_{n} = bs^{n - 1}$ .

所以 $\lim_{n\to \infty}\frac{a_n}{b_n} = \left\{ \begin{array}{c}0 0 < r < s\\ 0,s < r < 0\\ \text{不存在，} rs < 0\\ +\infty ,r > s > 0 ,ab > 0\\ +\infty ,r < s\langle 0 ,ab\rangle 0\\ -\infty ,r > s > 0 ,ab < 0\\ -\infty ,r < s < 0 ,ab < 0\\ \frac{a}{b} ,r = s \end{array} \right.$

## 方法技巧

等比数列 $\{a_{n}\}$ 中，若项数为 $2n$ ，则 $\frac{S_{\text{偶}}}{S_{\text{奇}}} = q$ ；若项数为 $2n + 1$ ，则 $\frac{S_{\text{奇}} - a_1}{S_{\text{偶}}} = q$
