> [!faq]- 《专题4_2_2_等差数列前n项和公式_高效培优讲义_数学人教A版高二选》官方解析
>
> > [!success]- **【答案】** CD
>
> > [!note]- **【分析】**
> > 由等差数列定义、通项公式、及求和公式逐项判断即可·
>
> > [!note]- **【解析】**
> > 对于 $\mathsf{A}$ ：因为 $\left\{a_{n}\right\}$ 是等差数列，所以 $a_{n}$ 是关于 $n$ 的一次函数， $\mathsf{A}$ 错；
> >
> > 对于 B：当公差 $d_{1}=0$ 时， $S_{n}=na_{1}$ 不是关于 n 的二次函数，故 B 错；
> >
> > 对于 $\mathbb{C}$ ：因为 $\left(a_{n + 1} + b_{n + 1}\right) - \left(a_n + b_n\right) = \left(a_{n + 1} - a_n\right) + \left(b_{n + 1} - b_n\right) = d_1 + d_2$
> >
> > 且 $d_{1} + d_{2}$ 为常数，所以数列 $\left\{a_{n} + b_{n}\right\}$ 是等差数列，C对；
> >
> > 对于 D：因为数列 $\left\{a_{n}b_{n}\right\}$ 是等差数列，所以 $2a_{2}b_{2}=a_{1}b_{1}+a_{3}b_{3}$
> >
> > 所以 $2(a_{1}+d_{1})(b_{1}+d_{2})=a_{1}b_{1}+(a_{1}+2d_{1})(b_{1}+2d_{2})$
> >
> > 即 $2\left(a_{1}b_{1} + a_{1}d_{2} + b_{1}d_{1} + d_{1}d_{2}\right) = a_{1}b_{1} + \left(a_{1}b_{1} + 2a_{1}d_{2} + 2b_{1}d_{1} + 4d_{1}d_{2}\right)$
> >
> > 化简得 $d_{1}d_{2}=0$ ，D 对。
> >
> > 故选：CD

> > 5. 等差数列 $\left\{a_{n}\right\}$ 的前 $n$ 项和为 $S_{n}$ ， $a_{2} + a_{4} = 20$ ， $S_{10} = S_{15}$ ，则下列说法正确的是（）A. $a_{8} = 6$ B. $a_{n} = -n + 13$ C. 当 $n = 12$ 或 $13$ 时， $S_{n}$ 取得最大值 D. 若 $b_{n} = a_{n}\cos n\pi$ 。则数列 $\left\{b_{n}\right\}$ 的前 $36$ 项和 $T_{36} = -18$
> >
> > 【答案】BCD
> >
> > 【分析】利用等差数列的性质求得 $a_{8}$ 判断 $^{A}$ ；求出通项公式可判断 $^{B}$ ；由通项公式可得各项的符号判断 $^{C}$ ；利
> >
> > 用并项求和法可得 $T_{36}$ 判断D.
> >
> > 【详解】在等差数列 $\left\{a_{n}\right\}$ 中，有 $a_{2}+a_{4}=2a_{3}=20$ ，所以 $a_{3}=10$
> >
> > 又因为 $S_{10} = S_{15}$ ，可得 $a_{15} + a_{14} + a_{13} + a_{12} + a_{11} = 0$ ，所以 $5a_{13} = 0$ ，所以 $a_{13} = 0$
> >
> > 所以 $a_{3} + a_{13} = 0 + 10 = 10$ ，所以 $2a_{8} = 10$ ，所以 $a_{8} = 5$ ，故 A 不正确；
> >
> > 所以等差数列 $\{a_{n}\}$ 的公差 $d = \frac{a_{13} - a_3}{13 - 3} = -1$
> >
> > 所以等差数列 $\left\{a_{n}\right\}$ 的通项公式为 $a_{n} = 10 + (n - 3)\times (-1) = 13 - n$ ，故B正确.
> >
> > 当 $1 \leq n \leq 12$ 时， $a_{n} > 0$ ；当n = 13时， $a_{n} = 0$ ；
> >
> > 当 $n = 14$ 时， $a_{n} < 0$ ，故当 $n = 12$ 或 $^{13}$ 时， $S_{n}$ 取得最大值，故 $\mathbb{C}$ 正确，
> >
> > 因为 $a_{n} = 13 - n$ ， $b_{n} = a_{n}\cos n\pi$ ，所以 $b_{n} = (-1)^{n}(13 - n)$
> >
> > 则 $T_{36} = -12 + 11 - 10 + 9 + \cdots + 22 - 23 = (-1) \times 18 = -18$ ，故 D 正确。
> >
> > 故选 **BCD**.
