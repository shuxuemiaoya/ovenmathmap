> [!faq]- 《专题4_2_1_等差数列的概念_高效培优讲义_数学人教A版高二选择性必》官方解析
>
> > [!success]- **【答案】** A
>
> > [!note]- **【分析】**
> > 由等差中项知 $c = 2b - a$ ，则可得到甲能推乙，当 $c$ 为整数时，易得 $a = 1, b = \frac{3}{2}, c = 2$ 符合条件，但 $b$
> >
> > 不是整数，故乙不能推甲，继而可解·
>
> > [!note]- **【解析】**
> > 由正数 a, b, c 满足 b 为 a 和 c 的等差中项，所以 $a + c = 2b$ ，
> >
> > 若 a, b 为整数，则 c = 2b - a 为整数，故甲能推乙；
> >
> > 若 $c$ 为整数，例 $a = 1, b = \frac{3}{2}, c = 2$ 符合 $b$ 为 $a$ 和 $c$ 的等差中项，但 $b$ 不是整数，故乙不能推甲，所以甲是乙的充分条件但不是必要条件·
> >
> > 故选 **A**.
