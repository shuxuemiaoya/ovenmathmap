> [!faq]- 《专题4.3.1 等比数列的概念（高效培优讲义）数学人教A版高二选择性必修第二册》官方解析
>
> > [!success]- **【答案】** (1) $a_{3}=4$ , $a_{4}=8$ , $a_{5}=16$ , $a_{n}=2^{n-1}$ (2)证明见解析
>
> > [!note]- **【分析】**
> > （1）先根据递推公式得出 $a_3, a_4, a_5$ ，再计算得出等比的通项公式；
> >
> > (2) 结合已知应用递推公式,根据等比数列定义证明等比数列.
>
> > [!note]- **【解析】**
> > （1）由 $2a_{n} = a_{n + 2} - a_{n + 1}$ 得 $a_3 = 2a_1 + a_2 = 4, a_4 = 2a_2 + a_3 = 8, a_5 = 2a_3 + a_4 = 16$
> >
> > 结合 $a_1 = 1, a_2 = 2$ 可猜想数列 $\{a_n\}$ 的通项公式为 $a_n = 2^{n-1}$
> >
> > (2) 因为 $a_{n+2} = 2a_n + a_{n+1}, a_1 = 1, a_2 = 2$
> >
> > 所以 $\left\{a_{n}\right\}$ 为正项递增数列，所以 $a_{n+1} + a_{n} \neq 0$
> >
> > 所以 $\frac{a_{n + 2} + a_{n + 1}}{a_{n + 1} + a_n} = \frac{2a_n + a_{n + 1} + a_{n + 1}}{a_{n + 1} + a_n} = 2$
> >
> > 故数列 $\left\{a_{n + 1} + a_n\right\}$ 是等比数列.
