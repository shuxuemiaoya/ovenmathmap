> [!faq]- 《专题4.3.1 等比数列的概念（高效培优讲义）数学人教A版高二选择性必修第二册》官方解析
>
> > [!success]- **【答案】** ACD
>
> > [!note]- **【分析】**
> > A 选项，利用 $a_4 = a_1q^3$ 求出公比；B 选项，求出 $a_3, a_5$ ，相加得到答案；C 选项， $\left|a_n\right| = 4^{n-1}$ ，从而得到 $\frac{\left|a_{n+1}\right|}{\left|a_n\right|} = 4$ ；D 选项， $a_n a_{n+2} = 2^{4n}$ ，得到 $\frac{a_{n+1} a_{n+3}}{a_n a_{n+2}} = 16$ ，D 正确。
>
> > [!note]- **【解析】**
> > A选项，设公比为q，由 $a_{4}=a_{1}q^{3}$ 得 $64=-q^{3}$ ，解得q=-4，A正确；
> >
> > B 选项，因为 $a_{1} = -1, q = -4$ ，所以 $a_{3} + a_{5} = -1 \times (-4)^{2} + (-1) \times (-4)^{4} = -272$ ，B 错误；
> >
> > C 选项，因为 $a_1 = -1, q = -4$ ，所以 $a_n = -(-4)^{n-1}$ ，则 $\left|a_n\right| = \left|(-1)^{n-1} \cdot 4^{n-1}\right| = 4^{n-1}$
> >
> > 故 $\frac{\left|a_{n + 1}\right|}{\left|a_n\right|} = 4$ ， $\left\{\left|a_n\right|\right\}$ 为等比数列，C正确；
> >
> > D 选项，因为 $a_{n} = -(-4)^{n-1}$ ，所以 $a_{n}a_{n+2} = -(-4)^{n-1} \times \left[-(-4)^{n+1}\right] = (-4)^{2n} = 2^{4n}$
> >
> > 所以 $\frac{a_{n + 1}a_{n + 3}}{a_na_{n + 2}} = \frac{2^{4(n + 1)}}{2^{4n}} = 16$ ，所以数列 $\{a_n a_{n + 2}\}$ 的公比为 $^{16}$ ，D正确.
> >
> > 故选 **ACD**
