> [!faq]- 《专题4.3.1 等比数列的概念（高效培优讲义）数学人教A版高二选择性必修第二册》官方解析
>
> > [!success]- **【答案】** $2^{n} + n$
>
> > [!note]- **【分析】**
> > 法一：设 $b_{n} = a_{n + 1} - 2a_{n}$ 、 $t_n = b_n + n - 1$ ，结合递推关系得到 $t_{n + 1} + 2t_n = 0$ ，再根据已知得 $t_n = 0$ ，进一
> >
> > 步有 $a_{n + 1} - (n + 1) = 2(a_n - n)$ ，利用等比数列的定义写出通项公式；法二：由递推关系得
> >
> > $a_{n+2}-(n+2)=4(a_{n}-n)$ ，讨论 n 的奇偶性写出通项公式即可.
>
> > [!note]- **【解析】**
> > 法一：因为 $a_{n + 2} - 4a_{n} = -3n + 2$ ，所以 $a_{n + 2} - 2a_{n + 1} + 2(a_{n + 1} - 2a_n) = -3n + 2.$
> >
> > 设 $b_{n} = a_{n + 1} - 2a_{n}$ ，则 $b_{n + 1} + 2b_{n} = -3n + 2$ ，所以 $\left(b_{n + 1} + n\right) + 2\left(b_n + n - 1\right) = 0$ ：
> >
> > 设 $t_n = b_n + n - 1$ ，则 $t_{n + 1} + 2t_n = 0$
> >
> > 因为 $a_1 = 3$ ， $a_2 = 6$ ，所以 $b_{1} = a_{2} - 2a_{1} = 0$ ， $t_1 = b_1 + 1 - 1 = 0$
> >
> > 所以 $t_{n}=0$ ，即 $b_{n}+n-1=0$ ，即 $a_{n+1}-2a_{n}+n-1=0$ ，所以 $a_{n+1}-(n+1)=2(a_{n}-n)$ .
> >
> > 因为 $a_1 - 1 = 3 - 1 = 2$ ，所以数列 $\{a_n - n\}$ 是首项为 $^2$ ，公比为 $^2$ 的等比数列，
> >
> > 所以 $a_{n}-n=2^{n}$ ， $a_{n}=2^{n}+n$ 。
> >
> > 法二：因为 $a_{n + 2} - 4a_n = -3n + 2$ ，所以 $a_{n + 2} - (n + 2) = 4(a_n - n)$
> >
> > 由 $a_1 = 3$ ， $a_2 = 6$ ，得 $a_1 - 1 = 2$ ， $a_2 - 2 = 4$
> >
> > 所以数列 $\{a_{n} - n\}$ 的奇数项是首项为 $2$ ，公比为 $4$ 的等比数列，偶数项是首项为 $4$ ，公比为 $4$ 的等比数列，当 $n$ 为奇数时， $a_{n} - n = 2 \times 4^{\frac{n-1}{2}} = 2^{n}$ ，即 $a_{n} = 2^{n} + n$ ；
> >
> > 当 n 为偶数时， $a_{n}-n=4\times4^{\frac{n}{2}-1}=2^{n}$ ，即 $a_{n}=2^{n}+n\cdot$
> >
> > 综上， $a_{n} = 2^{n} + n$
> >
> > 故答案为： $2^{n} + n$
> >
> > ## 方法技巧
> >
> > ## 一般地，如果一个数列从第二项起，每一项与它的前一项的比等于同一个常数，那么这个数列就叫做等比数
> >
> > 列．这个常数叫做等比数列的公比；公比通常用字母 $q$ 表示（ $q \neq 0$ ），即： $\frac{a_{n+1}}{a_n} = q (q \neq 0)$
