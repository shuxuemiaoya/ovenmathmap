> [!faq]- 《专题4.2.1 等差数列的概念（高效培优讲义）数学人教A版高二选择性必修第二册》官方解析
>
> > [!success]- **【答案】** ACD
>
> > [!note]- **【分析】**
> > 根据已知关系式可推导出 $a_{n + 1} - a_n = 2n + 2$ 是等差数列，即可判断 $\mathsf{A}$ ；根据已知结论可求出数列 $\left\{a_n\right\}$
> >
> > 的通项公式，即可判断 $^{B}$ ；根据高阶等差数列的定义，结合已知结论，可分别计算并判断 $^{C}$ 、 $^{D}$ .
>
> > [!note]- **【解析】**
> > 对于 A，因为 $a_{n+1} + a_{n-1} = 2(a_n + 1)(n - 2)$ ，所以 $(a_{n+1} - a_n) - (a_n - a_{n-1}) = 2(n - 2)$ ，所以数列 $\{a_{n+1} - a_n\}$
> >
> > 是首项为 $a_{2} - a_{1} = 4$ ，公差为 $^{2}$ 的等差数列，所以 $a_{n + 1} - a_n = 2n + 2$ ，所以数列 $\{a_n\}$ 为二阶等差数列，故A正
> >
> > 确；
> >
> > 对于 B, 因为 $a_{n} = (a_{n} - a_{n-1}) + (a_{n-1} - a_{n-2}) + \cdots + (a_{2} - a_{1}) + a_{1} = 2n + (2n - 2) + \cdots + 4 + 2$
> >
> > 所以 $a_{n}=\frac{(2+2n)n}{2}=n^{2}+n$ ，故 B 不正确；
> >
> > 对于 C，因为 $a_{n+1}^{2}-a_{n}^{2}=(n+1)^{2}(n+2)^{2}-n^{2}(n+1)^{2}=4(n+1)^{3}$ ，所以
> >
> > $\left(a_{n + 1}^{2} - a_{n}^{2}\right) - \left(a_{n}^{2} - a_{n - 1}^{2}\right) = 4(n + 1)^{3} - 4n^{3} = 4(3n^{2} + 3n + 1)$ ，令 $c_{n} = 4(3n^{2} + 3n + 1)$ ，则 $c_{n + 1} - c_n = 24n + 24$ ，所以数
> >
> > 列 $\{c_n\}$ 是二阶等差数列，数列 $\{a_{n + 1}^2 - a_n^2\}$ 为三阶等差数列，故 $C$ 正确；
> >
> > 因为 $a_{n + 1} + a_n = (n + 1)(n + 2) + n(n + 1) = 2(n + 1)^2$ ，所以 $\left(a_{n + 1} + a_n\right) - \left(a_n + a_{n - 1}\right) = 2(n + 1)^2 -2n^2 = 4n + 2$ ，所以数
> >
> > 列 $\left\{a_{n + 1} + a_n\right\}$ 为二阶等差数列，故D正确·
> >
> > 故选 **ACD**.
