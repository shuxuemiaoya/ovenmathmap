> [!faq]- 《专题01 数列概念的六大常考题型（高效培优专项训练）数学人教A版高二选择性必修第一册》官方解析
>
> > [!success]- **【答案】** D
>
> > [!note]- **【分析】**
> > 由递推公式，写出数列前几项，得到数列的周期，可求 $m$ 可能的值·
>
> > [!note]- **【解析】**
> > 数列 $\{a_{n}\}$ 的递推公式为 $a_{n + 1} = \frac{1 + a_n}{1 - a_n}$ ，由 $a_1 = 2$ ，则有 $a_2 = \frac{1 + a_1}{1 - a_1} = -3, a_3 = \frac{1 + a_2}{1 - a_2} = -\frac{1}{2}, a_4 = \frac{1 + a_3}{1 - a_3} = \frac{1}{3}, a_5 = \frac{1 + a_4}{1 - a_4} = 2$ ， $a_5 = a_1$ ，则 $\{a_n\}$ 是以 $^4$ 为周期的周期数列， $a_m = \frac{1}{3}$ ，有 $a_m = a_4$ ， $2024 = 4 \times 505 + 4$ ，故 $m$ 的值可能为 $^{2024}$ 。故选：D.
> >
> > 47. 数列 $\{a_{n}\}$ 满足 $a_{n + 1} = \frac{2a_n - 1}{4a_n + 2}$ ，且 $a_1 = 1$ ，则数列 $\{a_{n}\}$ 的前 $^{2024}$ 项的和 $S_{2024} = (\quad)$ A. $-\frac{253}{6}$ B. $-\frac{253}{8}$ C. $-\frac{1771}{6}$ D. $-\frac{1771}{8}$
> >
> > 【答案】C
> > 【分析】根据题意可知数列 $\{a_{n}\}$ 是以 $^4$ 为周期的周期数列，结合周期性运算求解·
> > 【详解】因为 $a_{n + 1} = \frac{2a_n - 1}{4a_n + 2}$ ，且 $a_1 = 1$
> >
> > 令 $n = 1$ ，可得 $a_{2} = \frac{2a_{1} - 1}{4a_{1} + 2} = \frac{1}{6}$ ；令 $n = 2$ ，可得 $a_{3} = \frac{2a_{2} - 1}{4a_{2} + 2} = -\frac{1}{4}$
> >
> > 令 $n = 3$ ，可得 $a_4 = \frac{2a_3 - 1}{4a_3 + 2} = -\frac{3}{2}$ ；令 $n = 4$ ，可得 $a_5 = \frac{2a_4 - 1}{4a_4 + 2} = 1$
> >
> > 可知数列 $\{a_{n}\}$ 是以 $^4$ 为周期的周期数列，
> >
> > 则 $a_1 + a_2 + a_3 + a_4 = 1 + \frac{1}{6} -\frac{1}{4} -\frac{3}{2} = -\frac{7}{12}$ ，且 $2024 = 4\times 506$
> >
> > 所以 $S_{2024}=506\times\left(-\frac{7}{12}\right)=-\frac{1771}{6}$ .
> >
> > 故选：C.
> >
> > 48. 数列 $\{a_{n}\}$ 满足 $a_{n+1} = 1 - \frac{1}{a_n}, a_1 = 2$ ，则 $a_{2024} =$ \_\_\_\_.
> >
> > 【答案】 $\frac{1}{2} / 0.5$
> >
> > 【分析】根据递推式得到数列的周期，应用周期性求对应项·
> >
> > 【详解】由题设 $a_1 = 2, a_2 = \frac{1}{2}, a_3 = -1, a_4 = 2, \ldots$
> >
> > 所以 $\left\{a_{n}\right\}$ 是周期为 3 的数列，则 $a_{2024}=a_{3\times674+2}=a_{2}=\frac{1}{2}$ .
> >
> > 故答案为： $\frac{1}{2}$
