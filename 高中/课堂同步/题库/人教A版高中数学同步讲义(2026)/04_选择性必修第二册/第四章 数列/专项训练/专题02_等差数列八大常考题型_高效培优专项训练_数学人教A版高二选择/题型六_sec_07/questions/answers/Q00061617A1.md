> [!faq]- 《专题02_等差数列八大常考题型_高效培优专项训练_数学人教A版高二选择》官方解析
>
> > [!success]- **【答案】** C
>
> > [!note]- **【分析】**
> > 由等差数列的性质可得 $\frac{S_{2n - 1}}{T_{2n - 1}} = \frac{\frac{1}{2}\big(a_1 + a_{2n - 1}\big)(2n - 1)}{\frac{1}{2}\big(b_1 + b_{2n - 1}\big)(2n - 1)} = \frac{a_n}{b_n}$ ，要使 $\frac{a_n}{b_n}$ 为整数，即 $\frac{8}{n + 1}$ 为整数，计算即可求解·
>
> > [!note]- **【解析】**
> > 由等差数列的性质可得 $\frac{S_{2n - 1}}{T_{2n - 1}} = \frac{\frac{1}{2}\big(a_1 + a_{2n - 1}\big)(2n - 1)}{\frac{1}{2}\big(b_1 + b_{2n - 1}\big)(2n - 1)} = \frac{a_n}{b_n} ,$ 因为 $\frac{S_n}{T_n} = \frac{6n + 2}{n + 3}$ ，所以 $\frac{a_n}{b_n} = \frac{6(2n - 1) + 2}{(2n - 1) + 3} = \frac{12n - 4}{2n + 2} = 6 - \frac{8}{n + 1} ,$ 因为 $n\in \mathbb{N}^*$ ，要使 $\frac{a_n}{b_n}$ 为整数，即 $\frac{8}{n + 1}$ 为整数，所以 $n = 1,3,7$ ，共3个，
> > 即使得 $\frac{a_n}{b_n}$ 为整数的正整数 $n$ 的个数是3·
> >
> > 故选 **C**
