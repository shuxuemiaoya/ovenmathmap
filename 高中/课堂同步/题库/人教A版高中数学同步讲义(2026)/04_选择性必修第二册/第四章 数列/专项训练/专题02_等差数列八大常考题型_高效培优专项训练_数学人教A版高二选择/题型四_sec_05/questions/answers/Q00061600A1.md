> [!faq]- 《专题02_等差数列八大常考题型_高效培优专项训练_数学人教A版高二选择》官方解析
>
> > [!success]- **【答案】** ABD
>
> > [!note]- **【分析】**
> > 根据 $a_{n} = n^{2} - 8n = (n - 4)^{2} - 16$ ，写出相关项并确定最小项判断A、B、C，再应用等差数列的定义判断D.
>
> > [!note]- **【解析】**
> > $a_{n} = n^{2} - 8n = (n - 4)^{2} - 16$
> >
> > 对于 $\mathsf{A}$ ， $a_1 = a_7 = -7, a_3 = a_5 = -15$ ，则 $a_1 + a_3 = a_5 + a_7$ ，故 $\mathsf{A}$ 正确；
> >
> > 对于 $\mathsf{B}$ ，当 $n = 4$ 时， $\left\{a_n\right\}$ 中的最小项为 $a_4 = -16$ ，故 $\mathsf{B}$ 正确；
> >
> > 对于 $C$ ，由上计算得 $a_3 = a_5 = -15$ ，显然从第三项起， $\{a_n\}$ 的每一项不一定大于它的前一项，故 $C$ 错误；
> >
> > 对于 D，由 $a_{n+2}-a_{n}=(n+2)^{2}-8(n+2)-n^{2}+8n=4n-12$
> >
> > 显然 $(a_{n + 3} - a_{n + 1}) - (a_{n + 2} - a_n) = [4(n + 1) - 12] - (4n - 12) = 4$
> >
> > 所以 $\left\{a_{n + 2} - a_n\right\}$ 是公差为 $^4$ 的等差数列，故D正确
> >
> > 故选 **ABD**.
