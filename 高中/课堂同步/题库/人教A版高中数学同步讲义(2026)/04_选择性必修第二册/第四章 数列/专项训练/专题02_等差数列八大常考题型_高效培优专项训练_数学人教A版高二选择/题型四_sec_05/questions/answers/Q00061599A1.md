> [!faq]- 《专题02_等差数列八大常考题型_高效培优专项训练_数学人教A版高二选择》官方解析
>
> > [!success]- **【答案】** B
>
> > [!note]- **【分析】**
> > 根据题意，化简得到 $a_{n + 1} = \frac{5a_n - 1}{a_n + 3}$ ，求得 $a_{n + 1} - 1 = \frac{4a_n - 4}{a_n + 3}$ ，得到 $\frac{1}{a_{n + 1} - 1} -\frac{1}{a_n - 1} = \frac{1}{4}$ ，可得判定A正确；由等差数列的通项公式，求得 $a_{n} = \frac{2n - 7}{2n - 15}$ ，结合 $a_7 <   0$ 且 $a_1 > 0$ ，可判定B错误；由通项公式，得到数列 $\{a_n\}$ 取值的正负，可判定C正确；求得 $T_{n}$ 的表达式，得到 $n = 4$ 或 $n = 6$ 时， $T_{n} <   0$ 且 $T_{4} = T_{6}$ ，当
> >
> > $n = 1,2,3,5,7$ 或 $n$ 8时， $T_{n} > 0$ ，进而可判定D正确.
>
> > [!note]- **【解析】**
> > 由数列 $\{a_{n}\}$ 满足 $a_{n + 1}a_n = 5a_n - 3a_{n + 1} - 1$ ，可得 $a_{n + 1} = \frac{5a_n - 1}{a_n + 3}$ ，则 $a_{n + 1} - 1 = \frac{4a_n - 4}{a_n + 3}$
> >
> > 可得 $\frac{1}{a_{n + 1} - 1} = \frac{a_n + 3}{4a_n - 4} = \frac{1}{a_n - 1} +\frac{1}{4}$ ，即 $\frac{1}{a_{n + 1} - 1} -\frac{1}{a_n - 1} = \frac{1}{4}$
> >
> > 因为 $a_1 = \frac{5}{13}$ ，可得 $\frac{1}{a_1 - 1} = -\frac{13}{8}$
> >
> > 所以数列 $\left\{\frac{1}{a_n - 1}\right\}$ 是首项为 $-\frac{13}{8}$ ，公差为 $\frac{1}{4}$ 的等差数列，所以 $A$ 正确；
> >
> > 由等差数列的通项公式，可得 $\frac{1}{a_n - 1} = -\frac{13}{8} + (n - 1) \times \frac{1}{4} = \frac{2n - 15}{8}$ ，
> >
> > 所以 $a_{n} = \frac{2n - 7}{2n - 15}$ ，因为 $a_7 = -7$ ，而 $a_1 = \frac{5}{13} >0$
> >
> > 所以 $a_{7}$ 不是数列 $\{a_n\}$ 的最大项，所以 $\mathsf{B}$ 错误；
> >
> > 当 $1 \leq n \leq 3$ 时， $a_{n} > 0$ ；当 $4 \leq n \leq 7$ 时， $a_{n} < 0$ ；当 $n = 8$ 时， $a_{n} > 0$
> >
> > 可得 $S_{n}$ 在 $n = 7$ 时取得最小值，所以 $\mathbb{C}$ 正确；
> >
> > 由 $T_{n}=a_{1}a_{2}a_{3}\cdots a_{n-2}a_{n-1}a_{n}=\frac{-5}{-13}\times\frac{-3}{-11}\times\frac{-1}{-9}\times\cdots\times\frac{2n-11}{2n-19}\times\frac{2n-9}{2n-17}\times\frac{2n-7}{2n-15}$ $=\frac{(2n-13)(2n-11)(2n-9)(2n-7)}{13\times11\times9\times7}$
> >
> > 当 n=4 或 n=6 时， $T_{n}<0$ 且 $T_{4}=T_{6}$ ，此时取得最小值；
> > 当 $n=1,2,3,5,7$ 或 $n\quad8,n\in N^{*}$ 时， $T_{n}>0$ ，且无最大值，所以 D 正确。
> >
> > 故选 **B**.
