> [!faq]- 《专题02_等差数列八大常考题型_高效培优专项训练_数学人教A版高二选择》官方解析
>
> > [!success]- **【答案】** $\left(\frac{3}{2023},\frac{5}{2022}\right]$
>
> > [!note]- **【分析】**
> > 设 $f(1) = a$ ，令 $y = 1$ 得到 $f(x + 1) = f(x) + a + 2$ ，通过等差数列的通项公式求出 $f(x)$ ，再根据 $\left\{ \begin{array}{l} f(2023) > 4047 \\ f(2022) \leq 4047 \end{array} \right.$ 列不等式求解即可·
>
> > [!note]- **【解析】**
> > 设 $f(1) = a$
> >
> > 令 $y = 1$ 得 $f(x + 1) = f(x) + f(1) + 2 = f(x) + a + 2$
> >
> > 所以当 $x$ 为正整数时，由等差数列的通项公式，
> >
> > 得 $f(x) = a + (a + 2)(x - 1) = (a + 2)x - 2$
> >
> > 由题意知 $\left\{\begin{aligned}f(2023)&=2023(a+2)-2>4047\\ f(2022)&=2022(a+2)-2\leq4047\end{aligned}\right.$
> >
> > 解得 $\frac{3}{2023} < a \leq \frac{5}{2022}$
> >
> > 故答案为： $\left(\frac{3}{2023},\frac{5}{2022}\right]$

> > 20. 数列 $\{a_{n}\}$ 满足 $a_1 = -21, a_2 = -12, a_{n+1} + a_{n-1} = 2a_n - 2(n - 2), S_n$ 是 $\{a_{n}\}$ 的前 $n$ 项和，则下列说法正确的是（）A. $\left\{\frac{a_n}{n-8}\right\}$ 是等差数列B. $a_{n} = -n^{2} + 12n + 32$ C. $a_{6}$ 是数列 $\{a_{n}\}$ 的最大项D. 对于两个正整数 $m, n (n > m), S_{n} - S_{m}$ 的最大值为 10
> >
> > 【答案】ACD
> >
> > 【分析】根据等差数列的定义及通项公式，利用累加法及二次函数的性质，结合 $a_{n}$ 与 $S_{n}$ 的关系即可求解·【详解】A选项，由 $a_{n + 1} + a_{n - 1} = 2a_{n} - 2$ ，整理得 $a_{n + 1} - a_n - (a_n - a_{n - 1}) = -2$
> >
> > 故 $\{a_{n} - a_{n - 1}\}$ 是公差为-2的等差数列，首项 $a_2 - a_1 = 9$
> >
> > 故 $a_{n} - a_{n - 1} = 13 - 2n(n\quad 2)$
> >
> > 由此可得 $a_{n-1}-a_{n-2}=15-2n,\cdots,a_{3}-a_{2}=7,a_{2}-a_{1}=9$
> >
> > 累加得， $a_{n}=-n^{2}+12n-32=(n-8)(4-n)$
> >
> > 由此可得， $\frac{a_n}{n - 8} = 4 - n$
> >
> > 当 $n = 1$ 时， $\frac{a_1}{1 - 8} = 4 - 1$ ，解得 $a_1 = -21\cdot$ 此式满足 $a_1$
> >
> > 故 $\frac{a_{n + 1}}{n + 1 - 8} -\frac{a_n}{n - 8} = 4 - (n + 1) - 4 + n = -1$
> >
> > $\therefore \left\{\frac{a_n}{n - 8}\right\}$ 是等差数列，故 $\mathsf{A}$ 正确；
> >
> > BC 选项，因为 $a_{n} = -n^{2} + 12n - 32 = (n - 8)(4 - n) = -(n - 6)^{2} + 4$
> >
> > 故当 $n = 6$ 时， $a_{n} = -(n - 6)^{2} + 4$ 取得最大值， $a_{6}$ 是数列 $\{a_n\}$ 的最大项，故B不正确，C正确；
> >
> > D 选项，对于两个正整数 $m, n (n > m)$ ， $S_{n} - S_{m} = a_{m+1} + a_{m+2} + \ldots + a_{n}$
> >
> > 由 $a_1 < a_2 < a_3 < a_4 = 0 < a_5 < a_6 > a_7 > a_8 = 0 > a_9 > a_{10} > a_{11}>$
> >
> > 故 $S_{n} - S_{m} = 3 + 4 + 3 = 10$ 时， $S_{n} - S_{m}$ 取得最大值，最大值为 $10$ ，故D正确·
> >
> > 故选 **ACD**.
