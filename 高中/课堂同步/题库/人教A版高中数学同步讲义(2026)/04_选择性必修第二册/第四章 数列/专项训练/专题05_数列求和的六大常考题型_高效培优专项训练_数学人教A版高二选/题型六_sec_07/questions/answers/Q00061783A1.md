> [!faq]- 《专题05_数列求和的六大常考题型_高效培优专项训练_数学人教A版高二选》官方解析
>
> > [!success]- **【答案】** (1) $a_{n}=2n-1,b_{n}=2^{n-1}$ (2)证明见解析(3) $T_{2n}=\frac{(6n-2)4^{n+1}+8}{9}$
>
> > [!note]- **【分析】**
> > （1）利用等差等比数列的通项公式进行基本量运算即可得解；
> >
> > (2) 由等比数列的性质及通项与前 $n$ 项和的关系结合分析法即可得证；
> >
> > (3) 由并项求和可得 $T_{2n} = \sum_{k=1}^{n} 2k \cdot 4^k$ ，再结合错位相减法可得解.
>
> > [!note]- **【解析】**
> > （1）设 $\{a_{n}\}$ 公差为 $d$ ， $\{b_n\}$ 公比为 $q$ ，则 $a_{n} = 1 + (n - 1)d, b_{n} = q^{n - 1}$
> >
> > 由 $a_2 - b_2 = a_3 - b_3 = 1$ 可得 $\left\{ \begin{array}{l} 1 + d - q = 1 \\ 1 + 2d - q^2 = 1 \end{array} \right. \Rightarrow d = q = 2$ （ $d = q = 0$ 舍去），所以 $a_n = 2n - 1, b_n = 2^{n-1}$ ；
> >
> > (2) 因为 $b_{n+1} = 2b_n \neq 0$ ，所以要证 $(S_{n+1} + a_{n+1})b_n = S_{n+1}b_{n+1} - S_nb_n$
> >
> > 即证 $(S_{n + 1} + a_{n + 1})b_{n} = S_{n + 1}\cdot 2b_{n} - S_{n}b_{n}$ ，即证 $S_{n + 1} + a_{n + 1} = 2S_{n + 1} - S_n$
> >
> > 即证 $a_{n+1}=S_{n+1}-S_{n}$
> >
> > 而 $a_{n + 1} = S_{n + 1} - S_n$ 显然成立，所以 $(S_{n + 1} + a_{n + 1})b_n = S_{n + 1}\cdot b_{n + 1} - S_n\cdot b_n$
> >
> > (3) 因为 $c_{2n-1} + c_{2n} = \left[a_{2n} - (-1)^{2n-1}a_{2n-1}\right]b_{2n-1} + \left[a_{2n+1} - (-1)^{2n}a_{2n}\right]b_{2n}$
> >
> > $$
> > = (4 n - 1 + 4 n - 3) \times 2 ^ {2 n - 2} + [ 4 n + 1 - (4 n - 1) ] \times 2 ^ {2 n - 1} = 2 n \cdot 4 ^ {n}
> > $$
> >
> > 所以 $T_{2n} = \sum_{k=1}^{n}\left\{\left[a_{2k} - (-1)^{2k-1}a_{2k-1}\right]b_{2k-1} + \left[a_{2k+1} - (-1)^{2k}a_{2k}\right]b_{2k}\right\} = \sum_{k=1}^{n}2k\cdot 4^k$
> >
> > 所以 $T_{2n}=2\times4+4\times4^{2}+6\times4^{3}+\cdots+2n\times4^{n}$
> >
> > 则 $4T_{2n}=2\times4^{2}+4\times4^{3}+6\times4^{4}+\cdots+2n\times4^{n+1}$
> >
> > 作差得 $-3T_{2n}=2\left(4+4^{2}+4^{3}+4^{4}+\cdots+4^{n}\right)-2n\cdot4^{n+1}=\frac{2\times4(1-4^{n})}{1-4}-2n\times4^{n+1}$
> >
> > $$
> > = \frac {(2 - 6 n) 4 ^ {n + 1} - 8}{3}
> > $$
> >
> > 所以 $T_{2n}=\frac{(6n-2)4^{n+1}+8}{9}$ ，
