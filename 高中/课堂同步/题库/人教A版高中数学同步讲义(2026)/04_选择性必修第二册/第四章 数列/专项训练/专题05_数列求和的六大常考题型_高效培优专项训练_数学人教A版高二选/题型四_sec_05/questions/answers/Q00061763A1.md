> [!faq]- 《专题05_数列求和的六大常考题型_高效培优专项训练_数学人教A版高二选》官方解析
>
> > [!success]- **【答案】** (1)证明见解析， $a_{n} = 2n - 1$ (2)证明见解析
>
> > [!note]- **【分析】**
> > （1）计算 $f(x) + f(1 - x)$ 为定值2，用倒序相加法求得 $\left\{a_{n}\right\}$ 通项公式；
> >
> > (2) 由 (1) 得到 $a_{n}$ , 裂项相消求和得 $T_{n}$ , 进而结合单调性证明不等式即可.
>
> > [!note]- **【解析】**
> > （1）由题意得 $f(x) + f(1 - x) = \lg \frac{20 - 10x}{1 + x} + \lg \frac{10 + 10x}{2 - x}$
> >
> > $$
> > = \lg (\frac {2 0 - 1 0 x}{1 + x} \times \frac {1 0 + 1 0 x}{2 - x}) = \lg 1 0 0 = 2
> > $$
> >
> > 则 $a_{n}=f\left(\frac{1}{2n}\right)+f\left(\frac{2}{2n}\right)+f\left(\frac{3}{2n}\right)+\cdots+f\left(\frac{2n-1}{2n}\right)$
> >
> > 得到 $a_{n}=f\left(\frac{2n-1}{2n}\right)+f\left(\frac{2n-2}{2n}\right)+f\left(\frac{2n-3}{2n}\right)+\cdots+f\left(\frac{1}{2n}\right)$
> >
> > 两式相加得 $2a_{n}=2(2n-1)$ ，即 $a_{n}=2n-1$ 。
> >
> > (2) 由题意得 $\frac{1}{a_n a_{n+1}} = \frac{1}{(2n-1)(2n+1)} = \frac{1}{2} \left( \frac{1}{2n-1} - \frac{1}{2n+1} \right)$ ,
> >
> > $$
> > T _ {n} = \frac {1}{2} \times \left(1 - \frac {1}{3} + \frac {1}{3} - \frac {1}{5} + \frac {1}{5} - \frac {1}{7} + \dots + \frac {1}{2 n - 1} - \frac {1}{2 n + 1}\right) = \frac {n}{2 n + 1} = \frac {1}{2 + \frac {1}{n}},
> > $$
> >
> > 而 $T_{1} = \frac{1}{2\times 1 + 1} = \frac{1}{3}$ ，而 $\frac{n}{2n + 1} = \frac{1}{2}\times \left(1 - \frac{1}{2n + 1}\right)$ ，可得当 $n\to +\infty$ 时， $\frac{n}{2n + 1}\rightarrow \frac{1}{2}$
> >
> > 令 $f(n) = \frac{1}{2 + \frac{1}{n}}$ ，因为反比例函数 $y = \frac{1}{n}$ 在 $[1, +\infty)$ 上单调递减，
> >
> > 所以 $_{f(n)}$ 在 $[1,+\infty)$ 上单调递增，即 $T_{n}$ 在 $[1,+\infty)$ 上单调递增，故 $\frac{1}{3} \leq T_{n} < \frac{1}{2}$ 得证.
> >
> > 33．德国大数学家高斯，被誉为数学界的王子，在其年幼时，对 $1+2+3+L+100$ 的求和运算中，提出了倒序相加法的原理，该原理基于所给数据前后对应项的和呈现一定的规律性，因此，此方法也称之为高斯算法．现有函数 $f(x)=\frac{2x}{3k+6078}$ （k>0），则 $f(1)+f(2)+f(3)+\cdots+f(k+2025)$ 等于（）A. $\frac{k+2025}{3}$ B. $\frac{2k+6078}{3}$ C. $\frac{2k+6078}{6}$ D. $\frac{k+2025}{6}$
> >
> > 【答案】A
> >
> > 【分析】先确定 $f(x) + f(m - x) = \frac{2}{3}$ ，再利用倒序相加法求和即可.
> >
> > 【详解】由题意得 $f(x) = \frac{2x}{3k + 6078}$ ，设 $m = k + 2026$ ，
> >
> > $$
> > f (x) + f (m - x) = \frac {2 x}{3 m} + \frac {2 (m - x)}{3 m} = \frac {2 x}{3 m} + \frac {2 m - 2 x}{3 m} = \frac {2}{3}
> > $$
> >
> > $$
> > S = f (1) + f (2) + f (3) + \dots + f (k + 2 0 2 5)
> > $$
> >
> > 倒序得 $S = f(k + 2025) + f(k + 2024) + \cdots + f(2) + f(1)$
> >
> > 两式相加得到 $2S = (k + 2025) \times \frac{2}{3} = \frac{2(k + 2025)}{3}$ ，解得 $S = \frac{k + 2025}{3}$ ，故只有A正确.
> >
> > 故选 **A**
