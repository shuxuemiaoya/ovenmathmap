> [!faq]- 《专题05_数列求和的六大常考题型_高效培优专项训练_数学人教A版高二选》官方解析
>
> > [!success]- **【答案】** (1) $a_{n}=3n-1$ (2) $T_{2n}=\frac{(18n+7)n}{2(3n+1)}$
>
> > [!note]- **【分析】**
> > （1）由 $S_{n + 1} - S_n = a_{n + 1}$ 化简条件可得数列 $\{a_n\}$ 是公差为3的等差数列，利用等差数列通项公式求解即可.
> >
> > (2) 利用分组求和裂项相消求和即可.
>
> > [!note]- **【解析】**
> > （1）由已知， $S_{n+1}-S_{n}=a_{n}+3$ ，即 $a_{n+1}=a_{n}+3$ ，即 $a_{n+1}-a_{n}=3$ ，所以数列 $\left\{a_{n}\right\}$ 是公差为3的等差数列
> >
> > 因为 $S_{5} = \frac{a_{1} + a_{5}}{2}\times 5 = 5a_{3} = 40$ ，则 $a_3 = 8$
> >
> > 因为 $a_{n} - a_{3} = (n - 3)d$ ，所以 $\{a_n\}$ 的通项公式是 $a_{n} = 8 + 3(n - 3) = 3n - 1$
> >
> > (2) 因为 $a_{n+1} - a_n = 3$ ，则 $\sum_{k=1}^{2n} (-1)^k a_k = (a_2 - a_1) + (a_4 - a_3) + \cdots + (a_{2n} - a_{2n-1}) = 3n$
> >
> > 因为 $\frac{1}{a_{n}a_{n+1}}=\frac{1}{3}\left(\frac{1}{a_{n}}-\frac{1}{a_{n+1}}\right)$ ，则 $\sum_{k=1}^{2n}\frac{1}{a_{k}a_{k+1}}=\frac{1}{3}\left[\left(\frac{1}{a_{1}}-\frac{1}{a_{2}}\right)+\left(\frac{1}{a_{2}}-\frac{1}{a_{3}}\right)+\cdots+\left(\frac{1}{a_{2n}}-\frac{1}{a_{2n+1}}\right)\right]=\frac{1}{3}\left(\frac{1}{a_{1}}-\frac{1}{a_{2n+1}}\right)$
> >
> > $$
> > = \frac {1}{3} \left(\frac {1}{2} - \frac {1}{6 n + 2}\right) = \frac {1}{6} \left(1 - \frac {1}{3 n + 1}\right) = \frac {n}{2 (3 n + 1)}
> > $$
> >
> > 所以 $T_{2n}=3n+\frac{n}{2(3n+1)}=\frac{(18n+7)n}{2(3n+1)}$ .
