> [!faq]- 《专题05_数列求和的六大常考题型_高效培优专项训练_数学人教A版高二选》官方解析
>
> > [!success]- **【答案】** (1)证明见解析； (2) $S_{n} = (n - 1)2^{n + 1} - n + 2$
>
> > [!note]- **【分析】**
> > （1）由条件可得 $\frac{a_{n + 1} + 1}{2^{n + 1}} -\frac{a_n + 1}{2^n} = 1$ ，根据等差数列定义证明结论；
> >
> > (2) 由 (1) 可得 $a_{n} = n \cdot 2^{n} - 1$ ，所以 $S_{n} = 2^{1} + 2 \cdot 2^{2} + \dots + n \cdot 2^{n} - n$ ，设 $T_{n} = 2^{1} + 2 \cdot 2^{2} + \dots + n \cdot 2^{n}$ ，利用错位相减法求 $T_{n}$ ，由此可得结论。
>
> > [!note]- **【解析】**
> > （1）因为 $a_{n + 1} = 2a_{n} + 2^{n + 1} + 1$
> >
> > 所以 $a_{n + 1} + 1 = 2a_n + 2 + 2^{n + 1}$
> >
> > 所以 $\frac{a_{n + 1} + 1}{2^{n + 1}} = \frac{2a_n + 2}{2^{n + 1}} +1$ ，即 $\frac{a_{n + 1} + 1}{2^{n + 1}} -\frac{a_n + 1}{2^n} = 1$
> >
> > 又 $a_1 = 1$ ，故 $\frac{a_1 + 1}{2} = 1$
> >
> > 所以数列 $\left\{\frac{a_n + 1}{2^n}\right\}$ 为首项为 $1$ ，公差为 $1$ 的等差数列，
> >
> > (2) 由 (1) $\frac{a_n + 1}{2^n} = 1 + (n - 1) = n$
> >
> > 所以 $a_{n}=n\cdot2^{n}-1$
> >
> > 所以 $S_{n}=a_{1}+a_{2}+\cdots+a_{n}=2^{1}-1+2\cdot2^{2}-1+\cdots+n\cdot2^{n}-1$
> >
> > 所以 $S_{n}=2^{1}+2\cdot2^{2}+\cdots+n\cdot2^{n}-n$
> >
> > 设 $T_{n}=2^{1}+2\cdot2^{2}+\cdots+n\cdot2^{n}$
> >
> > 所以 $2T_{n}=1\cdot2^{2}+2\cdot2^{3}+\cdots+n\cdot2^{n+1}$
> >
> > 所以 $T_{n} = -2 - 2^{2} - 2^{3} - \cdots - 2^{n} + n \cdot 2^{n+1}$
> >
> > $$
> > T _ {n} = n \cdot 2 ^ {n + 1} - (2 + 2 ^ {2} + 2 ^ {3} + \dots + 2 ^ {n}) = n \cdot 2 ^ {n + 1} - \frac {2 (1 - 2 ^ {n})}{1 - 2} = n \cdot 2 ^ {n + 1} + 2 - 2 ^ {n + 1} = (n - 1) 2 ^ {n + 1} + 2
> > $$
> >
> > 所以 $S_{n}=(n-1)2^{n+1}-n+2$
