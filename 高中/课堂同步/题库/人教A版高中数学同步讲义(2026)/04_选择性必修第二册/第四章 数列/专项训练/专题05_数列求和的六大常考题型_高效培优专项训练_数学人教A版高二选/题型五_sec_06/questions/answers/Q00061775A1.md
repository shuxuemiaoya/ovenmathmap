> [!faq]- 《专题05_数列求和的六大常考题型_高效培优专项训练_数学人教A版高二选》官方解析
>
> > [!success]- **【答案】** ACD
>
> > [!note]- **【分析】**
> > A 选项，设出公差，根据条件得到方程，求出公差，进而求出首项；B 选项，表示出 $S_{n}=n^{2}-10n=(n-5)^{2}-25$ ，求出 n=5 时， $S_{n}$ 取得最小值，B 错误；C 选项，求出 $\frac{S_{n}}{n}=n-10$ ，故 $\frac{S_{n+1}}{n+1}-\frac{S_{n}}{n}=1>0$ ，C 正确；D 选项，求出通项公式，当 $n\leq5$ 时， $a_{n}<0$ ，当 n=6 时， $a_{n}>0$ ，从而利用
> >
> > $\left(S_{10} - S_5\right) - S_5$ 求出 $\left\{\left|a_n\right|\right\}$ 的前10项和.
>
> > [!note]- **【解析】**
> > A选项，设 $\{a_{n}\}$ 的公差为 $d$ ，则 $a_5 + a_7 = a_2 + 3d + a_3 + 4d = a_2 + a_3 + 7d$
> >
> > 即 $2 = -12 + 7d$ ，解得 $d = 2$
> >
> > 故 $a_{2} + a_{3} = a_{1} + 2 + a_{1} + 4 = 2a_{1} + 6 = -12$ ，所以 $a_1 = -9$ ，A正确；
> >
> > B 选项， $S_{n} = -9n + \frac{n(n-1)}{2} \times 2 = n^{2} - 10n = (n-5)^{2} - 25$
> >
> > 当 $n = 5$ 时， $S_{n}$ 取得最小值，B错误；
> >
> > C 选项， $\frac{S_{n}}{n}=\frac{n^{2}-10n}{n}=n-10$ ，故 $\frac{S_{n+1}}{n+1}-\frac{S_{n}}{n}=n-9-(n-10)=1>0$ ，
> >
> > 所以 $\left\{\frac{S_n}{n}\right\}$ 为递增数列，C正确；
> >
> > D选项， $a_{n} = -9 + 2(n - 1) = 2n - 11$
> >
> > 当 $n \leq 5$ 时， $a_{n} < 0$ ，当 $n = 6$ 时， $a_{n} > 0$
> >
> > $\left|\left|a_n\right|\right|$ 的前10项和为 $\left(S_{10} - S_5\right) - S_5 = S_{10} - 2S_5 = 10^2 - 10\times 10 - 2\times \left(5^2 -10\times 5\right) = 50$ ，D正确.
> >
> > 故选 **ACD**
