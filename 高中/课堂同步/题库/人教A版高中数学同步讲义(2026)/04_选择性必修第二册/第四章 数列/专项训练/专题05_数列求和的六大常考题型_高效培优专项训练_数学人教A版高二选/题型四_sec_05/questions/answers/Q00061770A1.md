> [!faq]- 《专题05_数列求和的六大常考题型_高效培优专项训练_数学人教A版高二选》官方解析
>
> > [!success]- **【答案】** D
>
> > [!note]- **【分析】**
> > 由等比数列的性质可得 $a_1a_{2026} = a_2a_{2025} = \ldots = a_{1013}a_{1014}$ ，再计算 $f(x) + f\left(\frac{1}{x}\right) = 2$ ，再利用倒序相加
> >
> > 计算结果.
>
> > [!note]- **【解析】**
> > 因 $a_1a_{2026} = 1$ ，数列 $\{a_n\}$ 是等比数列，有 $a_1a_{2026} = a_2a_{2025} = \dots = a_{1013}a_{1014} = 1$
> >
> > 因为 $f(x) = \frac{2}{1 + x^2}$ ，所以 $f(x) + f\left(\frac{1}{x}\right) = \frac{2}{1 + x^2} + \frac{2}{1 + \frac{1}{x^2}} = \frac{2(1 + x^2)}{1 + x^2} = 2$
> >
> > 故有 $f(a_{1}) + f(a_{2026}) = f(a_{2}) + f(a_{2025}) = \dots\dots = f(a_{1013}) + f(a_{1014}) = 2$ 设 $S = f(a_{1}) + f(a_{2}) + \dots +f(a_{2026})$ ，则 $S = f(a_{2026}) + f(a_{2025}) + \dots +f(a_{1})$ ，则 $2S = 2026[f(a_1) + f(a_{2026})] = 2026\times 2 = 4052$ ，则 $S = f(a_{1}) + f(a_{2}) + \dots +f(a_{2026}) = 2026.$
> >
> > 故选 **D**.
