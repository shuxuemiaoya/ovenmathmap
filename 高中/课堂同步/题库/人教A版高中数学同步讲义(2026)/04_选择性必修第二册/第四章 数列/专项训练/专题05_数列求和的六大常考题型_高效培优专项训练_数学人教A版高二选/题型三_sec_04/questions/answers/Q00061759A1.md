> [!faq]- 《专题05_数列求和的六大常考题型_高效培优专项训练_数学人教A版高二选》官方解析
>
> > [!success]- **【答案】** (1)证明见解析 (2) $S_{n} = \frac{3 + (2n - 1)\cdot 3^{n + 1}}{4} -n^{2}$
>
> > [!note]- **【分析】**
> > （1）将递推公式配凑成 $a_{n + 1} + (n + 1) = 3(a_n + n)$ ，即可；
> >
> > (2) 由 (1) 求得 $b_{n} = n \cdot 3^{n} - (2n - 1)$ ，由分组求和、错位相减法求和即可.
>
> > [!note]- **【解析】**
> > （1）证明：由 $a_{n+1}=3a_{n}+2n-1$ ，
> >
> > 得 $a_{n + 1} + (n + 1) = 3(a_n + n)$ ， $n\in \mathbf{N}^*$ ，且 $a_1 + 1 = 3\neq 0$
> >
> > 所以数列 $\{a_{n} + n\}$ 是首项为3，公比为3的等比数列，
> >
> > (2) 由 (1) 知数列 $\{a_{n} + n\}$ 是首项为 3，公比为 3 的等比数列，
> >
> > 所以 $a_{n} + n = 3 \times 3^{n-1} = 3^{n}$
> >
> > 故 $b_{n} = na_{n} + (n - 1)^{2} = n(a_{n} + n) - (2n - 1) = n\cdot 3^{n} - (2n - 1)$
> >
> > 所以 $S_{n}=\left(1\times3^{1}-1\right)+\left(2\times3^{2}-3\right)+\left(3\times3^{3}-5\right)+\cdots+\left[n\cdot3^{n}-(2n-1)\right]$
> >
> > $$
> > = \left(1 \times 3 ^ {1} + 2 \times 3 ^ {2} + 3 \times 3 ^ {3} + \dots + n \cdot 3 ^ {n}\right) - [ 1 + 3 + 5 + \dots + (2 n - 1) ]
> > $$
> >
> > 设 $T_{n}=1\times3^{1}+2\times3^{2}+3\times3^{3}+\cdots+n\cdot3^{n}$ ①
> >
> > 所以 $3T_{n}=1\times3^{2}+2\times3^{3}+\cdots+(n-1)\cdot3^{n}+n\cdot3^{n+1}$ ②
> > - **①**：- ②得： $-2T_{n}=3+3^{2}+3^{3}++\cdots+3^{n}-n\cdot3^{n+1}=\frac{3-3^{n}\cdot3}{1-3}-n\cdot3^{n+1}=-\frac{3}{2}-\frac{2n-1}{2}\cdot3^{n+1}$
> >
> > 所以 $T_{n}=\frac{3+(2n-1)\cdot3^{n+1}}{4}$ ，又 $1+3+5+\cdots+(2n-1)=\frac{n[1+(2n-1)]}{2}=n^{2}$ ，
> >
> > 所以 $S_{n}=\frac{3+(2n-1)\cdot3^{n+1}}{4}-n^{2}$
