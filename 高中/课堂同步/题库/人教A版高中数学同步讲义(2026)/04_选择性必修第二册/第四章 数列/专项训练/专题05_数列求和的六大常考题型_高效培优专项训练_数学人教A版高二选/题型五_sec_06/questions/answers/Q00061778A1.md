> [!faq]- 《专题05_数列求和的六大常考题型_高效培优专项训练_数学人教A版高二选》官方解析
>
> > [!success]- **【答案】** (1) $a_{n}=11-2n$ ; (2) $T_{n}=\begin{cases}10n-n^{2},n\leq5\\n^{2}-10n+50,n\quad6\end{cases}$ ; (3) $R_{n}=\frac{n}{2n+1}$ .
>
> > [!note]- **【分析】**
> > （1）将题干式子变形得 $S_{n}=na_{n}+n^{2}-n$ ，利用 $a_{n}$ 与 $S_{n}$ 的关系化简可得 $a_{n}=a_{n-1}-2$ ，根据等差数
> >
> > 列通项公式计算即可；
> >
> > (2) 求得 $\left\{b_{n}\right\}$ 的通项公式，分类讨论求和即可；
> >
> > （3）由题意得 $c_{n} = \frac{1}{(2n - 1)(2n + 1)} = \frac{1}{2}\left(\frac{1}{2n - 1} -\frac{1}{2n + 1}\right)$ ，利用裂项相消求和即可.
>
> > [!note]- **【解析】**
> > （1） $\frac{S_{n}}{n}-a_{n}=n-1$ ，得 $S_{n}=na_{n}+n^{2}-n$ ，
> >
> > 当 n 2 时，有 $S_{n-1} = (n-1)a_{n-1} + (n-1)^{2} - (n-1)$
> >
> > 得 $a_{n} = S_{n} - S_{n - 1} = na_{n} + n^{2} - n - \left[\left(n - 1\right)a_{n - 1} + \left(n - 1\right)^{2} - \left(n - 1\right)\right]$
> >
> > 化简可得 $(n-1)a_{n}=(n-1)a_{n-1}-2(n-1)$ ，
> >
> > 因为 n 2，所以 $(n-1) \neq 0$ ，所以 $a_{n} = a_{n-1} - 2$ ，
> >
> > 所以数列 $\{a_{n}\}$ 是以 $a_1 = 9$ 为首项， $d = -2$ 为公差的等差数列，
> >
> > 所以 $a_{n} = 11 - 2n$
> >
> > (2) 由 (1) 可得 $b_{n} = \begin{cases} 11 - 2n, & n \leq 5 \\ 2n - 11, & n = 6 \end{cases}$ ,
> >
> > 当 $n \leq 5$ 时， $T_{n} = \frac{n(9 + 11 - 2n)}{2} = 10n - n^{2}$ ，
> >
> > 当 $n$ 6时， $T_{n} = \frac{n(-9 + 2n - 11)}{2} + 2T_{5} = n^{2} - 10n + 50$
> >
> > 综上， $T_{n}=\left\{\begin{aligned}&10n-n^{2},n\leq5\\ &n^{2}-10n+50,n&6\end{aligned}\right.$
> >
> > (3) 由 (1) 可得 $c_{n} = \frac{1}{(2n - 1)(2n + 1)} = \frac{1}{2}\left(\frac{1}{2n - 1} - \frac{1}{2n + 1}\right)$ ,
> >
> > $$
> > R _ {n} = c _ {1} + c _ {2} + c _ {3} + \dots + c _ {n} = \frac {1}{2} \left(1 - \frac {1}{3} + \frac {1}{3} - \frac {1}{5} + \frac {1}{5} - \frac {1}{7} + \dots + \frac {1}{2 n - 1} - \frac {1}{2 n + 1}\right) = \frac {n}{2 n + 1}.
> > $$
