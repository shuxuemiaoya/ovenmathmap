> [!faq]- 《专题03_等比数列七大常考题型_高效培优专项训练_数学人教A版高二选择》官方解析
>
> > [!success]- **【答案】** C
>
> > [!note]- **【分析】**
> > 利用等比数列的性质求解即可·
>
> > [!note]- **【解析】**
> > 设等比数列 $\{a_{n}\}$ 的公比为 $q$
> >
> > 则 $a_5 + a_6 + a_7 + a_8 = q^3(a_2 + a_3 + a_4 + a_5)$
> >
> > 即 $243q^{3} = 72$ ，解得 $q = \frac{2}{3}$
> >
> > 所以 $a_7 + a_8 + a_9 + a_{10} = q^2(a_5 + a_6 + a_7 + a_8) = \left(\frac{2}{3}\right)^2\times 72 = 32$
> >
> > 故选 **C**.
