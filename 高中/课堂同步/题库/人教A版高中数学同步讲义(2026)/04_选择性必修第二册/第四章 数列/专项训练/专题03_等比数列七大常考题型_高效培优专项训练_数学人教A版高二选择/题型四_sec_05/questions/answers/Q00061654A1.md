> [!faq]- 《专题03_等比数列七大常考题型_高效培优专项训练_数学人教A版高二选择》官方解析
>
> > [!success]- **【答案】** AD
>
> > [!note]- **【分析】**
> > 根据已知条件求得等比数列 $\{a_{n}\}$ 的首项和公比，得到其通项公式、前 $n$ 项和与前 $n$ 项积，然后逐项判断即可·
>
> > [!note]- **【解析】**
> > 设等比数列 $\left\{a_{n}\right\}$ 的公比为 $q,q\neq0$
> >
> > 由题可知： $\left\{ \begin{array}{l}a_{1} + a_{1}q + a_{1}q^{2} = \frac{13}{3}\\ a_{1}\cdot a_{1}q\cdot a_{1}q^{2} = 1 \end{array} \right.$
> >
> > 化简得： $(3q - 1)(q - 3) = 0$ ，解得 $q = \frac{1}{3}$ 或 $q = 3\cdot$
> >
> > 所以 $\left\{\begin{aligned}a_{1}&=3\\ q&=\frac{1}{3}\end{aligned}\right.$ 或 $\left\{\begin{aligned}a_{1}&=\frac{1}{3}\\ q&=3\end{aligned}\right.$
> >
> > 选项 A： $a_{2}=a_{1}q=1$ ，所以选项 A 正确；
> >
> > 选项 B：当 $\left\{\begin{aligned}a_{1}&=3\\ q&=\frac{1}{3}\end{aligned}\right.$ 时，数列 $\left\{a_{n}\right\}$ 为递减数列；
> >
> > 当 $\left\{ \begin{array}{l}a_{1} = \frac{1}{3}\\ q = 3 \end{array} \right.$ 时，数列 $\left\{a_n\right\}$ 为递增数列，所以选项B错误；
> >
> > 选项 C：若 $a_{1}<a_{4}$ ，则 $q^{3}>1$ ，所以 q>1，
> >
> > 所以 $\left\{ \begin{array}{l}a_{1} = \frac{1}{3}\\ q = 3 \end{array} \right., a_{n} = \frac{1}{3}\times 3^{n - 1} = 3^{n - 2}\cdot$
> >
> > 所以 $Tn = 3^{-1} \times 3^{0} \times 3^{1} \times \ldots \times 3^{n-2} = 3^{\frac{n(n-3)}{2}}$
> >
> > 当 $n = 1$ 或 $n = 2$ 时， $T_{n}$ 取得最小值，最小值为 $\frac{1}{3} \cdot$ 所以选项C错误；
> >
> > 选项 D：若 $a_{1} > a_{4}$ ，则 $q^{3} < 1$ ，所以 q < 1
> >
> > 所以 $\left\{ \begin{array}{l}a_{1} = 3\\ q = \frac{1}{3} \end{array} \right.$ ， $a_{n} = 3\times \left(\frac{1}{3}\right)^{n - 1} = 3^{2 - n}\cdot$
> >
> > 所以 $S_{n}=\frac{a_{1}-a_{n}q}{1-q}=\frac{9-3^{2-n}}{2}$ .
> >
> > 因为 $n \in \mathbb{N}^*$ ，所以 $0 < 3^{2 - n} \leq 3$ ，所以 $3 \leq S_n < \frac{9}{2}$ ，所以选项 D 正确。
> >
> > 故选 **AD**.
