> [!faq]- 《专题04_求数列通项公式八大常考题型_高效培优专项训练_数学人教A版高》官方解析
>
> > [!success]- **【答案】** $\frac{2n + 1}{2n}$
>
> > [!note]- **【分析】**
> > 先把条件化成 $a_{1} + 2a_{2} + 3a_{3} + \cdots + na_{n} = \frac{n(n+2)}{2}$ 这样的形式，再利用 $a_{n}$ 与 $S_{n}$ 的关系，作差即可得到答案.
>
> > [!note]- **【解析】**
> > 由 $\frac{n}{a_1 + 2a_2 + 3a_3 + \cdots + na_n} = \frac{2}{n + 2}$ ，得 $a_1 + 2a_2 + 3a_3 + \cdots + na_n = \frac{n(n + 2)}{2}(1)$
> >
> > 当 $n$ 2时， $a_{1} + 2a_{2} + 3a_{3} + \dots + (n - 1)a_{n - 1} = \frac{(n - 1)(n + 1)}{2}(2)$ ，
> >
> > 由(1)-(2)得 $na_{n}=\frac{2n+1}{2}$ ，所以 $a_{n}=\frac{2n+1}{2n}$ ，
> >
> > 又 $n = 1$ 时，由（1）得 $a_1 = \frac{3}{2}$ ，也满足上式
> >
> > 所以 $a_{n}=\frac{2n+1}{2n}$ .
> >
> > 故答案为： $\frac{2n+1}{2n}$
