> [!faq]- 《专题04_求数列通项公式八大常考题型_高效培优专项训练_数学人教A版高》官方解析
>
> > [!success]- **【答案】** B
>
> > [!note]- **【分析】**
> > 由数列的递推式可得 $a_{n} - 2n = 2a_{n - 1} + 4 - 4n = 2[a_{n - 1} - 2(n - 1)]$ ，求得 $a_{n} = 2n$ ，再由等差数列的求和公式和定义，即可得到 $b_{n} = n + 1$ ，再利用放缩法，结合数列的裂项相消求和和不等式的性质，即可得解．
>
> > [!note]- **【解析】**
> > 解：因为 $a_1 = 2$ ， $a_n + 2n = 2a_{n-1} + 4(n..2, n \in N^*)$
> >
> > 可得 $a_{n} - 2n = 2a_{n - 1} + 4 - 4n = 2[a_{n - 1} - 2(n - 1)]$
> >
> > 由 $a_1 - 2 = 0$ ，可得 $a_{n} - 2n = 0$ ，即 $a_{n} = 2n$
> >
> > $$
> > S _ {n} = \frac {1}{2} n (2 + 2 n) = n (n + 1)
> > $$
> >
> > 则 $b_{n} = \frac{S_{n}}{n} = n + 1$
> >
> > 所以 $\frac{1}{b_n^2} = \frac{1}{(n + 1)^2} = \frac{1}{n^2 + 2n + 1} < \frac{1}{n^2 + 2n + \frac{3}{4}} = 4 \cdot \frac{1}{(2n + 1)(2n + 3)} = 2\left(\frac{1}{2n + 1} - \frac{1}{2n + 3}\right)$
> >
> > 可得 $\frac{1}{b_1^2} +\frac{1}{b_2^2} +\dots +\frac{1}{b_n^2} < 2\left[\left(\frac{1}{3} -\frac{1}{5}\right) + \left(\frac{1}{5} -\frac{1}{7}\right) + \left(\frac{1}{7} -\frac{1}{9}\right) + \dots +\left(\frac{1}{2n + 1} -\frac{1}{2n + 3}\right)\right] = 2\left(\frac{1}{3} -\frac{1}{2n + 3}\right) <   \frac{2}{3}$
> >
> > 又 $\frac{1}{b_{1}^{2}}+\frac{1}{b_{2}^{2}}+\cdots+\frac{1}{b_{6}^{2}}>\frac{1}{2}$ ， $\frac{1}{b_{1}^{2}}+\frac{1}{b_{2}^{2}}+\cdots+\frac{1}{b_{n}^{2}}<\frac{7}{10}$ 恒成立。
> >
> > 故选 **B**.
