> [!faq]- 《专题04_求数列通项公式八大常考题型_高效培优专项训练_数学人教A版高》官方解析
>
> > [!success]- **【答案】** $6n^{2} + 11n$
>
> > [!note]- **【分析】**
> > 由 $a_{n + 1} = 3a_n - 4n$ 可化为 $a_{n + 1} - \left[2(n + 1) + 1\right] = 3\left[a_n - (2n + 1)\right]$ ，由 $a_1 = 3$ ，可得 $a_1 - 3 = 0$ ，可求得 $a_n$ ，再将 $\{b_n\}$ 的通项展开裂项，利用裂项求和方法计算即得：
>
> > [!note]- **【解析】**
> > 因 $a_{n + 1} = 3a_{n} - 4n$ ，设 $a_{n + 1} + x(n + 1) + y = 3(a_n + xn + y)$ ①，展开整理得： $a_{n + 1} = 3a_{n} + 2xn + 2y - x$
> >
> > 对照 $a_{n + 1} = 3a_n - 4n$ ，可得： $\left\{ \begin{array}{ll}2x = -4\\ 2y - x = 0 \end{array} \right.$ ，解得 $x = -2,y = -1$
> >
> > 故①式为： $a_{n+1}-[2(n+1)+1]=3[a_{n}-(2n+1)]$
> >
> > 因 $n = 1$ 时， $a_{1} - 3 = 0$ ，即数列 $\{a_{n} - (2n + 1)\}$ 为常数列，故 $a_{n} = 2n + 1$
> >
> > $$
> > b _ {n} = \frac {4 n ^ {2} + 8 n + 5}{a _ {n} a _ {n + 1}} = \frac {4 n ^ {2} + 8 n + 5}{(2 n + 1) (2 n + 3)} = 1 + \frac {1}{2 n + 1} - \frac {1}{2 n + 3}
> > $$
> >
> > $\therefore$ 数列 $\{b_n\}$ 的前 $n$ 项和为： $S_{n} = n + \left(\frac{1}{3} -\frac{1}{5}\right) + \left(\frac{1}{5} -\frac{1}{7}\right) + \ldots +\left(\frac{1}{2n + 1} -\frac{1}{2n + 3}\right) = n + \frac{1}{3} -\frac{1}{2n + 3} = n\left(1 + \frac{2}{6n + 9}\right)$ ， $\therefore (6n + 9)S_n = n(6n + 9) + 2n = 6n^2 +11n$
> >
> > 故答案为： $6n^{2} + 11n$
