> [!faq]- 《专题04_求数列通项公式八大常考题型_高效培优专项训练_数学人教A版高》官方解析
>
> > [!success]- **【答案】** B
>
> > [!note]- **【分析】**
> > 利用放缩法进行放缩即可求解.
>
> > [!note]- **【解析】**
> > $S=1+\frac{1}{\sqrt{2}}+\frac{1}{\sqrt{3}}+\cdots+\frac{1}{\sqrt{1000000}}$ $=1+2\times\frac{1}{\sqrt{2}+\sqrt{2}}+2\frac{1}{\sqrt{3}+\sqrt{3}}+\cdots+2\times\frac{1}{\sqrt{1000000}+\sqrt{1000000}}$ $<1+2\times\left(\frac{1}{\sqrt{2}+1}+\frac{1}{\sqrt{3}+\sqrt{2}}+\cdots+\frac{1}{\sqrt{1000000}+\sqrt{999999}}\right)$ $=1+2\times\left(\sqrt{2}-1+\sqrt{3}-\sqrt{2}+\cdots+\sqrt{1000000}-\sqrt{999999}\right)$ $=1+2'\left(\sqrt{1000000}-1\right)=1+2'999=1999$ 又 $S=1+\frac{1}{\sqrt{2}}+\frac{1}{\sqrt{3}}+\cdots+\frac{1}{\sqrt{1000000}}$ $=1+2\times\frac{1}{\sqrt{2}+\sqrt{2}}+2\frac{1}{\sqrt{3}+\sqrt{3}}+\cdots+2\times\frac{1}{\sqrt {1000000}+\sqrt {1000000}}$ $>1+2\times\left(\frac{1}{\sqrt{3}+\sqrt{2}}+\frac{1}{\sqrt{4}+\sqrt{3}}+\cdots+\frac{1}{\sqrt {1000001}+\sqrt {1000000}}\right)$ $=1+2\times\left(\sqrt{3}-\sqrt{2}+\sqrt{4}-\sqrt{3}+\cdots+\sqrt {1000001}-\sqrt {1000000}\right)$ $=1+2'\left(\sqrt { 1 0 0 0 0 0 1 } - \sqrt { 2 }\right)>1+2'\left(\sqrt { 1 0 0 0 0 0 0 } - \sqrt { 2 }\right)=2 0 0 1-2 \sqrt { 2 }>2 0 0 1-3=1 9 98$
> >
> > 所以 $1998 < S < 1999$ ，则S的整数部分为1998，
> >
> > 故选 **B**.
