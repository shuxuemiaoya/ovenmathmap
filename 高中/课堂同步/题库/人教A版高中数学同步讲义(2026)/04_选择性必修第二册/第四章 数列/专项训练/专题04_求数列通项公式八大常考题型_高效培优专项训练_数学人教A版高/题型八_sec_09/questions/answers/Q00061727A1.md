> [!faq]- 《专题04_求数列通项公式八大常考题型_高效培优专项训练_数学人教A版高》官方解析
>
> > [!success]- **【答案】** (1)证明见解析 (2) $a_{n} = n \times 2^{n - 1}$ (3) $S_{n} = 2^{n}(n - 1) + 1$
>
> > [!note]- **【分析】**
> > （1）将 $S_{n + 2} = 5S_{n + 1} - 8S_n + 4S_{n - 1}$ 变为 $S_{n + 2} - S_{n + 1} = 4(S_{n + 1} - S_n) - 4(S_n - S_{n - 1})$ ，则 $a_{n + 2} = 4a_{n + 1} - 4a_n$
> >
> > 整理得 $a_{n + 2} - 2a_{n + 1} = 2(a_{n + 1} - 2a_n)$ ，利用等比数列的概念证明即可
> >
> > (2) 根据等比数列通项公式求得 $a_{n+1} - 2a_n = 2^n$ ，变形为 $\frac{a_{n+1}}{2^{n+1}} - \frac{a_n}{2^n} = \frac{1}{2}$ ，然后根据等差数列的定义及通项公式求解即可·
> >
> > (3) 利用错位相减法求和即可·
>
> > [!note]- **【解析】**
> > （1）当n 2时， $S_{n+2}=5S_{n+1}-8S_{n}+4S_{n-1}$ 即 $S_{n + 2} - S_{n + 1} = 4(S_{n + 1} - S_n) - 4(S_n - S_{n - 1})$ ，
> > 则 $a_{n + 2} = 4a_{n + 1} - 4a_n$ ，而 $a_1 = 1, a_2 = 4, a_3 = 12$ ，则 $a_3 = 4a_2 - 4a_1$ 于是 $\forall n \in \mathbb{N}^*$ 时， $a_{n + 2} = 4a_{n + 1} - 4a_n$ ，整理得 $a_{n + 2} - 2a_{n + 1} = 2(a_{n + 1} - 2a_n)$ 又 $a_2 - 2a_1 = 2 \neq 0$ 所以数列 $\{a_{n + 1} - 2a_n\}$ 是首项和公比都是 $^2$ 的等比数列．
> > （2）由（1）知，数列 $\{a_{n + 1} - 2a_n\}$ 是首项和公比都是 $^2$ 的等比数列，则 $a_{n + 1} - 2a_n = 2^n$ ，因此 $\frac{a_{n + 1}}{2^{n + 1}} - \frac{a_n}{2^n} = \frac{1}{2}$ 所以数列 $\left\{\frac{a_n}{2^n}\right\}$ 是首项为 $\frac{1}{2}$ ，公差为 $\frac{1}{2}$ 的等差数列， $\frac{a_n}{2^n} = \frac{1}{2} + \frac{1}{2}(n - 1) = \frac{1}{2}n$ 所以数列 $\{a_n\}$ 的通项公式 $a_n = n \times 2^{n - 1}$ （3）由（2）知， $S_n = 1 \times 2^0 + 2 \times 2^1 + 3 \times 2^2 + L + n \times 2^{n - 1}$ $2S_n = 1 \times 2^1 + 2 \times 2^2 + L + (n - 1) \times 2^{n - 1} + n \times 2^n$ 两式相减得， $-S_n = 1 + 2^1 + 2^2 + \dots + 2^{n - 1} - n \times 2^n = \frac{1 - 2^n}{1 - 2} - n \times 2^n = -1 + (1 - n) \times 2^n$ 则 $S_n = 2^n (n - 1) + 1$
