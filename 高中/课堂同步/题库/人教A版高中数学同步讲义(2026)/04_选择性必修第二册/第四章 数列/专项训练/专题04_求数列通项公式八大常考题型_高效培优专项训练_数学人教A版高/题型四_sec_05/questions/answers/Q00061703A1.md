> [!faq]- 《专题04_求数列通项公式八大常考题型_高效培优专项训练_数学人教A版高》官方解析
>
> > [!success]- **【答案】** (1) $a_{n}=4n+2$ ； (2) $T_{n}=\frac{n}{12(2n+3)}$ .
>
> > [!note]- **【分析】**
> > （1）利用 $a_{n}, S_{n}$ 关系求通项公式即可；
> >
> > (2) 应用裂项相消法求 $T_{n}$ .
>
> > [!note]- **【解析】**
> > （1）由 $S_{n} = a_{n} + 2n^{2} - 2$ ，得 $S_{n + 1} = a_{n + 1} + 2(n + 1)^{2} - 2 = a_{n + 1} + 2n^{2} + 4n$
> >
> > 两式相减得 $a_{n+1}=a_{n+1}-a_{n}+4n+2$ ，则 $a_{n}=4n+2$ ；
> >
> > (2) 由 (1) 可知 $b_{n} = \frac{1}{a_{n}} = \frac{1}{4n + 2}$ ，则 $b_{n}b_{n + 1} = \frac{1}{(4n + 2)(4n + 6)} = \frac{1}{8}\left(\frac{1}{2n + 1} -\frac{1}{2n + 3}\right)$
> >
> > $$
> > T _ {n} = b _ {1} b _ {2} + b _ {2} b _ {3} + \dots + b _ {n} b _ {n + 1} = \frac {1}{8} \left[ \left(\frac {1}{3} - \frac {1}{5}\right) + \left(\frac {1}{5} - \frac {1}{7}\right) + \dots + \left(\frac {1}{2 n + 1} - \frac {1}{2 n + 3}\right) \right]
> > $$
> >
> > $$
> > = \frac {1}{8} \left(\frac {1}{3} - \frac {1}{2 n + 3}\right) = \frac {n}{1 2 (2 n + 3)}.
> > $$
