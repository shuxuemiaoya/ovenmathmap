> [!faq]- 《专题04_求数列通项公式八大常考题型_高效培优专项训练_数学人教A版高》官方解析
>
> > [!success]- **【答案】** ACD
>
> > [!note]- **【分析】**
> > 由 $a_{n}$ 和 $S_{n}$ 的关系可得 $a_{n} = 2a_{n - 1} + 2^{n}$ ，进而可得 $a_{n} = (n + 1)\cdot 2^{n}$ ，将 $a_{n}$ 代入 $S_{n}$ 可得 $S_{n} = n\cdot 2^{n + 1}$ ，计算可判断ABC，求得 $\left|\frac{a_n}{2^{n - 1}} -13\right| = |2n - 11|$ ，分 $n\leq 5$ 和 $n = 6$ 求解即可判断D.
>
> > [!note]- **【解析】**
> > 已知数列 $\{a_{n}\}$ 的前 $n$ 项和为 $S_{n}$ ，且满足 $S_{n} = 2a_{n} - 2^{n + 1}$
> >
> > $n = 1$ 时， $S_{1} = 2a_{1} - 2^{1 + 1}$ ， $a_1 = 4$
> >
> > n 2 时， $S_{n-1}=2a_{n-1}-2^{n}$
> >
> > 由 $a_{n} = S_{n} - S_{n - 1}$ 得 $a_{n} = 2a_{n} - 2^{n + 1} - \left(2a_{n - 1} - 2^{n}\right)$
> >
> > 化简得 $a_{n} = 2a_{n - 1} + 2^{n}$
> >
> > 两边同除以 $2^{n}$ ，得 $\frac{a_n}{2^n} = \frac{a_{n - 1}}{2^{n - 1}} +1$
> >
> > 因此，数列 $\left\{\frac{a_n}{2^n}\right\}$ 是首项为 $\frac{a_1}{2^1} = 2$ ，公差为 $^1$ 的等差数列，
> >
> > 所以 $\frac{a_n}{2^n} = 2 + (n - 1) \times 1 = n + 1$ ，即 $a_n = (n + 1) \cdot 2^n$ ，
> >
> > 代入 $S_{n} = 2a_{n} - 2^{n + 1}$ 得 $S_{n} = (n + 1)\cdot 2^{n + 1} - 2^{n + 1} = n\cdot 2^{n + 1}$
> >
> > 对于 A : $a_{5}=6\times2^{5}=192$ ，故 A 正确；
> >
> > 对于 B : $S_{6}=6\times2^{7}=768\neq780$ ，故 B 错误；
> >
> > 对于 C : $\frac{S_{n}}{a_{n}}=\frac{n\cdot2^{n+1}}{(n+1)\cdot2^{n}}=\frac{2n}{n+1}$ ，故 C 正确；
> >
> > 对于 D：数列 $\left\{\left|\frac{a_{n}}{2^{n-1}}-13\right|\right\}$ 中 $\frac{a_{n}}{2^{n-1}}=\frac{(n+1)\cdot2^{n}}{2^{n-1}}=2(n+1)$ ，所以 $\left|\frac{a_{n}}{2^{n-1}}-13\right|=\left|2n-11\right|$
> >
> > 令 $\left|2n-11\right|=0$ ，得n=5.5，则前n项和需分 $n\leq5$ 和n 6讨论：
> >
> > 当 $n \leq 5$ 时， $\left|2n - 11\right| = 11 - 2n$ ，则前5项和为 $\sum_{k=1}^{5}\left(11 - 2k\right) = 9 + 7 + 5 + 3 + 1 = 25$
> >
> > 当 $n$ 6时， $\left|2n - 11\right| = 2n - 11$ ，则前20项和为：
> >
> > $25+\sum_{k=6}^{20}(2k-11)=25+1+3+\cdots29=25+\frac{15\times(1+29)}{2}=250$ ，故D正确.
> >
> > 故选 **ACD**
