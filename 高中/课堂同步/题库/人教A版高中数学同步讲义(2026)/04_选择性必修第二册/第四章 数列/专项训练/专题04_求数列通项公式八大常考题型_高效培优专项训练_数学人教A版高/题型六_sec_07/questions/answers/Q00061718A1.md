>
> > [!success]- **【答案】** (1) $a_{n}=\frac{n(n-1)}{2}+1(2)$ $a_{n}=2^{n}-1(3)$ $a_{n}=n\cdot2^{n-1}(4)$ $a_{n}=3^{n}-2^{n}(5)$ $a_{n}=\frac{7}{4}\cdot3^{n-1}-\frac{n}{2}-\frac{1}{4}$ $$ a _ {n} = \frac {5}{4} \cdot 3 ^ {n} - 2 ^ {n} - \frac {n}{2} - \frac {1}{4} (7) a _ {n} = n \cdot 2 ^ {n - 1} + 2 ^ {n} - n - 1 (8) a _ {n} = 7 \cdot 3 ^ {n - 1} - n \cdot 2 ^ {n} - 2 ^ {n + 1} (9) a _ {n} = n (n - 1) \cdot 2 ^ {n - 2} + 2 ^ {n - 1} $$ $$ a _ {n} = 8 \cdot 3 ^ {n - 1} - 2 ^ {n + 1} - n \cdot 2 ^ {n} - 1 (1 1) a _ {n} = n (n - 1) \cdot 2 ^ {n - 2} + 2 ^ {n} - 1 (1 2) a _ {n} = \frac {1 1}{4} \cdot 3 ^ {n} - (n + 2) 2 ^ {n} - \frac {n}{2} - \frac {3}{4} $$ $$ a _ {n} = n \left(3 ^ {n} - 2 ^ {n}\right) (1 4) a _ {n} = - \frac {3}{4} (- 1) ^ {n} + \frac {n}{2} - \frac {1}{4} (1 5) a _ {n} = - \frac {1}{3} (- 1) ^ {n} + \frac {1}{3} \cdot 2 ^ {n} \tag {3} $$
>
> > [!note]- **【分析】**
> > 根据已知条件应用累加法计算或构造等差数列或构造等比数列求解通项公式:
>
> > [!note]- **【解析】**
> > （1） $a_{n+1}=a_{n}+An+B$ 型.
> >
> > 递推累加，等差数列求和：
> >
> > $$
> > a _ {2} - a _ {1} = 1
> > $$
> >
> > $$
> > a _ {3} - a _ {2} = 2
> > $$
> >
> > $$
> > a _ {4} - a _ {3} = 3
> > $$
> >
> > L
> >
> > $$
> > a _ {n} - a _ {n - 1} = n - 1
> > $$
> >
> > 上述 $n - 1$ 个式子累加得 $a_{n} - a_{1} = \frac{(n - 1)n}{2}$ ，即 $a_{n} = 1 + \frac{(n - 1)n}{2}$
> >
> > (2) $a_{n+1}=a_{n}+q^{n}$ 型.
> >
> > 递推累加，等比数列求和：
> >
> > $$
> > a _ {2} - a _ {1} = 2 ^ {1}
> > $$
> >
> > $$
> > a _ {3} - a _ {2} = 2 ^ {2}
> > $$
> >
> > $$
> > a _ {4} - a _ {3} = 2 ^ {3}
> > $$
> >
> > $$
> > a _ {n} - a _ {n - 1} = 2 ^ {n - 1}
> > $$
> >
> > 上述 n-1 个式子累加得 $a_{n}-a_{1}=2^{n}-2$ ，即 $a_{n}=2^{n}-1$ 。
> >
> > (3) $a_{n + 1} = qa_n + q^n (q = p)$ 型.
> >
> > 同除 $q^n$ 转化为等差数列： $\frac{a_{n + 1}}{q^n} = \frac{a_n}{q^{n - 1}} +1$ ，令 $b_{n} = \frac{a_{n}}{q^{n - 1}}$ ，则 $b_{n + 1} = b_n + 1$ ，转化为等差数列.
> >
> > $$
> > 2 ^ {n}
> > $$
> >
> > 由 $a_{n + 1} = 2a_{n} + 2^{n}$ 得 $\frac{a_{n + 1}}{2^n} = \frac{a_n}{2^{n - 1}} +1$
> >
> > 令 $b_{n}=\frac{a_{n}}{2^{n-1}}$ ，则 $b_{n+1}=b_{n}+1$ ， $b_{1}=1$ ，
> >
> > 得 $b_{n}=n$ ，即 $\frac{a_{n}}{2^{n-1}}=n$ ， $a_{n}=n\cdot2^{n-1}$
> >
> > $$
> > (4) a _ {n + 1} = q a _ {n} + p ^ {n} (q \neq p) \text {型}
> > $$
> >
> > 直接待定系数： $a_{n + 1} + Ap^{n + 1} = q(a_n + Ap^n)(q\neq p)$
> >
> > 本小题中， $a_{n + 1} + 2^{n + 1} = 3(a_n + 2^n)$
> >
> > 令 $b_{n}=a_{n}+2^{n}$
> >
> > 则 $b_{n + 1} = 3b_{n}$ ， $b_{1} = 3$
> >
> > 得 $b_{n}=3^{n}$ ，即 $a_{n}+2^{n}=3^{n}$ ，即 $a_{n}=3^{n}-2^{n}$
> >
> > (5) $a_{n + 1} = qa_n + An + B(q\neq 1)$ 型.
> >
> > 直接待定系数： $a_{n + 1} + \alpha (n + 1) + \beta = q(a_n + \alpha n + \beta)(q\neq 1)$
> >
> > 其中 $\alpha = \frac{A}{q - 1}$ ， $\beta = \frac{B}{q - 1} +\frac{A}{(q - 1)^2}$
> >
> > 本小题中，由 $a_{n + 1} = 3a_n + n$ ，得 $a_{n + 1} + \frac{1}{2} (n + 1) + \frac{1}{4} = 3\left(a_n + \frac{1}{2} n + \frac{1}{4}\right)$
> >
> > 令 $b_{n}=a_{n}+\frac{1}{2}n+\frac{1}{4}$ ，则 $b_{1}=\frac{7}{4}$ ， $b_{n+1}=3b_{n}$ ，
> >
> > 得 $b_{n}=\frac{7}{4}\times3^{n-1}$ ，即 $a_{n}+\frac{1}{2}n+\frac{1}{4}=\frac{7}{4}\times3^{n-1}$ ，
> >
> > 故 $a_{n} = \frac{7}{4}\cdot 3^{n - 1} - \frac{n}{2} -\frac{1}{4}$
> >
> > ## 直接待定系数时必须是完整的关于 $n$ 的一次函数.
> >
> > (6) $a_{n + 1} = qa_n + p^n +An + B$ 型.
> >
> > 直接待定系数： $a_{n + 1} + \alpha (n + 1) + \beta +\gamma p^{n + 1} = q\left(a_n + \alpha n + \beta +\gamma p^n\right)(q\neq 1)$
> >
> > 其中 $\alpha=\frac{A}{q-1}$ ， $\beta=\frac{B}{q-1}+\frac{A}{(q-1)^{2}}$ ， $\gamma=\frac{1}{q-p}$
> >
> > 本小题中，由 $a_{n+1}=3a_{n}+2^{n}+n$
> >
> > 得 $a_{n + 1} + \frac{1}{2} (n + 1) + \frac{1}{4} +2^{n + 1} = 3\left(a_n + \frac{n}{2} +\frac{1}{4} +2^n\right)$
> >
> > 同（5）方法可得 $a_{n} = \frac{5}{4}\cdot 3^{n} - 2^{n} - \frac{n}{2} -\frac{1}{4}$
> >
> > (7) $a_{n + 1} = qa_n + q^n +An + B$ 型.
> >
> > 先待定系数配制掉多项式部分 $An + B$ ，再同除 $p^n$ 转化为等差数列.
> >
> > $a_{n + 1} + \alpha (n + 1) + \beta = p(a_n + \alpha n + \beta) + p^n$
> >
> > $\frac{a_{n + 1} + \alpha(n + 1) + \beta}{p^n} = \frac{a_n + \alpha n + \beta}{p^{n - 1}} +1$ ，令 $b_{n} = \frac{a_{n} + \alpha n + \beta}{p^{n - 1}}$ ，则 $b_{n + 1} = b_n + 1$ ，转化为等差数列.
> >
> > 本小题中，由 $a_{n + 1} = 2a_{n} + 2^{n} + n$
> >
> > 得 $a_{n + 1} + (n + 1) + 1 = 2(a_n + n + 1) + 2^n$
> >
> > 同除 $2^{n}$ 得 $\frac{a_{n + 1} + (n + 1) + 1}{2^n} = \frac{a_n + n + 1}{2^{n - 1}} +1$
> >
> > 同（3）方法可得 $\frac{a_n + n + 1}{2^{n - 1}} = n + 2$
> >
> > 故 $a_{n} = n\cdot 2^{n - 1} + 2^{n} - n - 1$
> >
> > (8) $a_{n + 1} = qa_n + n \cdot p^n$ 型.
> >
> > 先同除 $p^n$ 转化为等差数列，再待定系数转化为等比数列.
> >
> > $\frac{a_{n + 1}}{p^n} = \frac{q}{p}\cdot \frac{a_n}{p^{n - 1}} +n$
> >
> > 令 $b_{n}=\frac{a_{n}}{p^{n-1}}$ ，则 $b_{n+1}=\frac{q}{p}\cdot b_{n}+n$ ，
> >
> > $b_{n + 1} + \alpha (n + 1) + \beta = \frac{q}{p}\big(b_n + \alpha n + \beta\big)$
> >
> > 再令 $c_{n} = b_{n} + \alpha n + \beta$ ，则 $c_{n + 1} = \frac{q}{p}\cdot b_n$ ．以下步骤略.
> >
> > 本小题中，由 $a_{n + 1} = 3a_n + n\cdot 2^n$ 得 $\frac{a_{n + 1}}{2^{n + 1}} = \frac{3}{2}\cdot \frac{a_n}{2^n} +\frac{n}{2}$
> >
> > $$
> > \frac {a _ {n + 1}}{2 ^ {n + 1}} + (n + 1) + 2 = \frac {3}{2} \left(\frac {a _ {n}}{2 ^ {n}} + n + 2\right)
> > $$
> >
> > 可得 $\frac{a_n}{2^n} + n + 2 = \frac{7}{2}\left(\frac{3}{2}\right)^{n - 1}$
> >
> > 故 $a_{n} = 7\cdot 3^{n - 1} - n\cdot 2^{n} - 2^{n + 1}$
> >
> > 变式：
> >
> > $$
> > a _ {n + 1} + [ A (n + 1) + B ] \cdot 2 ^ {n + 1} = 3 \left[ a _ {n} + (A n + B) \cdot 2 ^ {n} \right]
> > $$
> >
> > 本小题中， $a_{n + 1} + [(n + 1) + 2]\cdot 2^{n + 1} = 3\left[a_n + (n + 2)\cdot 2^n\right]$
> >
> > $a_{n} + (n + 2)\cdot 2^{n} = 7\cdot 3^{n - 1}$
> >
> > 故 $a_{n} = 7\cdot 3^{n - 1} - n\cdot 2^{n} - 2^{n + 1}$
> >
> > (9) 先同除 $2^{n}$ 转化为 (1) 类求解.
> >
> > 由 $a_{n + 1} = 2a_{n} + n\cdot 2^{n}$ 得 $\frac{a_{n + 1}}{2^n} = \frac{a_n}{2^{n - 1}} +n$
> >
> > 再令 $b_{n} = \frac{a_{n}}{2^{n - 1}}$ ，得 $b_{n + 1} = b_n + n$ 。最终得 $a_{n} = n(n - 1) \cdot 2^{n - 2} + 2^{n - 1}$ 。
> >
> > (10) $a_{n + 1} = qa_n + An\cdot p^n +B$ 型
> >
> > 先待定系数转化为 $(8)$ 类求解：
> >
> > $$
> > a _ {n + 1} + \alpha = q (a _ {n} + \alpha) + A n p ^ {n}
> > $$
> >
> > $$
> > \frac {a _ {n + 1} + \alpha}{p ^ {n + 1}} = \frac {q}{p} \cdot \frac {a _ {n} + \alpha}{p ^ {n}} + \frac {A n}{p},
> > $$
> >
> > 令 $b_{n}=\frac{a_{n}+\alpha}{p^{n}}$ ，则 $b_{n+1}=\frac{q}{p}\cdot b_{n}+\frac{An}{p}$ ，
> >
> > $$
> > b _ {n + 1} + \alpha (n + 1) + \beta = \frac {q}{p} \left(b _ {n} + \alpha n + \beta\right).
> > $$
> >
> > 或直接待定系数转化为等比数列：
> >
> > $$
> > a _ {n + 1} + [ \alpha (n + 1) + \beta ] p ^ {n + 1} + \gamma = p \left[ a _ {n} + (\alpha n + \beta) p ^ {n} + \gamma \right].
> > $$
> >
> > 本小题中，直接待定系数得 $a_{n + 1} + [(n + 1) + 2]\cdot 2^{n + 1} + 1 = 3\left[a_n + (n + 2)\cdot 2^n +1\right]$
> >
> > 得 $a_{n} + (n + 2)\cdot 2^{n} + 1 = 8\cdot 3^{n - 1}$
> >
> > 故 $a_{n} = 8\cdot 3^{n - 1} - (n + 2)\cdot 2^{n} - 1 = 8\cdot 3^{n - 1} - 2^{n + 1} - n\cdot 2^{n} - 1$
> >
> > (11) 先待定系数转化为 (9) 类求解.
> >
> > 由题意得 $a_{n + 1} + 1 = 2(a_n + 1) + n\cdot 2^n$
> >
> > 令 $b_{n}=a_{n}+1$ ，则 $b_{n+1}=2b_{n}+n\cdot2^{n}$ 。最终得 $a_{n}=n(n-1)\cdot2^{n-2}+2^{n}-1$
> >
> > (12) $a_{n + 1} = qa_n + An\cdot p^n +Bn + C$ 型.
> >
> > 直接待定系数求解：
> >
> > $$
> > a _ {n + 1} + [ \alpha (n + 1) + \beta ] p ^ {n + 1} + \gamma (n + 1) + \varphi = p \left[ a _ {n} + (\alpha n + \beta) p ^ {n} + \gamma n + \varphi \right].
> > $$
> >
> > 本小题中， $a_{n + 1} + \frac{n + 1}{2} +\frac{3}{4} +(n + 3)\cdot 2^{n + 1} = 3\left(a_n + \frac{n}{2} +\frac{3}{4}\right) + (n + 2)\cdot 2^n$
> >
> > 最终得 $a_{n} = \frac{11}{4}\cdot 3^{n} - (n + 2)\cdot 2^{n} - \frac{n}{2} -\frac{3}{4}$
> >
> > (13) $a_{n + 1} = 3\left(\frac{n + 1}{n}\right)a_n + n\cdot 2^n +2^n$
> >
> > $$
> > \frac {a _ {n + 1}}{n + 1} + 2 ^ {n + 1} = 3 \left(\frac {a _ {n}}{n} + 2 ^ {n}\right)
> > $$
> >
> > 最终得 $a_{n} = n\left(3^{n} - 2^{n}\right)$
> >
> > (14) 由 $a_{n+1} + a_n = n$ 得 $a_{n+1} = -a_n + n$
> >
> > $a_{n + 1} - \frac{n + 1}{2} +\frac{1}{4} = -\left(a_n - \frac{n}{2} +\frac{1}{4}\right)$
> >
> > 最终得 $a_{n} = -\frac{3}{4}\cdot (-1)^{n} + \frac{n}{2} -\frac{1}{4}$
> >
> > (15) 由 $a_{n+1} + a_n = 2^n$ 得 $a_{n+1} = -a_n + 2^n$
> >
> > $a_{n + 1} - \frac{1}{3}\cdot 2^{n + 1} = -\left(a_n - \frac{1}{3}\cdot 2^n\right)$
> >
> > 最终得 $a_{n} = -\frac{1}{3}\cdot (-1)^{n} + \frac{1}{3}\cdot 2^{n}$
