> [!faq]- 《专题4.4 数学归纳法（高效培优讲义）数学人教A版高二选择性必修第二册》官方解析
>
> > [!success]- **【答案】** $a_{n} = \sqrt{n} -\sqrt{n - 1}$ ，证明见解析
>
> > [!note]- **【分析】**
> > 利用 $S_{n} = \frac{1}{2}\left(a_{n} + \frac{1}{a_{n}}\right)$ 求 $\{a_n\}$ 前4项的值，并猜想通项公式，利用数学归纳法证明即可.
>
> > [!note]- **【解析】**
> > 当 $n = 1$ 时， $S_{1} = a_{1} = \frac{a_{1}^{2} + 1}{2a_{1}}$ ，解得 $a_{1} = 1$ ；
> >
> > $S_{2} = a_{1} + a_{2} = \frac{a_{2}^{2} + 1}{2a_{2}}$ ，解得 $a_2 = \sqrt{2} -1$ ，同理得 $a_3 = \sqrt{3} -\sqrt{2}$ ， $a_4 = \sqrt{4} -\sqrt{3}$ ，L
> >
> > 猜想 $a_{n} = \sqrt{n} -\sqrt{n - 1}$ ，以下用数学归纳法加以证明.
> >
> > (i) 当 $n = 1$ 时， $a_1 = 1$ ，等式成立；
> >
> > (ii) 假设当 $n = k$ 时， $a_{k} = \sqrt{k} - \sqrt{k - 1}$ 成立，
> >
> > 当 $n = k + 1$ 时， $S_{k+1} = S_k + a_{k+1}$
> >
> > 即 $\frac{a_{k + 1}^2 + 1}{2a_{k + 1}} = \frac{a_k^2 + 1}{2a_k} + a_{k + 1} = \frac{\left(\sqrt{k} - \sqrt{k - 1}\right)^2 + 1}{2\left(\sqrt{k} - \sqrt{k - 1}\right)} + a_{k + 1} = \sqrt{k} + a_{k + 1}$
> >
> > 去分母并整理得 $a_{k + 1}^2 +2\sqrt{k} a_{k + 1} - 1 = 0$ ，解得 $a_{k + 1} = \pm \sqrt{k + 1} -\sqrt{k}$
> >
> > 故 $a_{k + 1} = \sqrt{k + 1} -\sqrt{k}$ （负值舍去），则 $n = k + 1$ 时等式成立.
> >
> > 由（i）（ii）知对任意 $n\in \mathbf{N}^*$ ， $a_{n} = \sqrt{n} -\sqrt{n - 1}$ 成立.
> >
> > ## 方法技巧
> >
> > 即先验证使结论有意义的最小的正整数 $n_0$ ，如果当 $n = n_0$ 时，命题成立，再假设当 $n = k$ （ $k \in N^*$
> >
> > $k\quad n_{0}$ ）时，命题成立．（这时命题是否成立不是确定的），根据这个假设，如能推出当 $n = k + 1$ 时，命题也
> >
> > 成立，那么就可以递推出对所有不小于 $n_0$ 的正整数 $n_0 + 1$ ， $n_0 + 2$ ，…，命题都成立.
