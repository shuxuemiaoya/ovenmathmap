> [!faq]- 《专题04 求数列通项公式八大常考题型（高效培优专项训练）数学人教A版高二选择性必修第二册》官方解析
>
> > [!success]- **【答案】** $a_{n} = 3^{n - 1} - 2^{n - 1} + 1$
>
> > [!note]- **【分析】**
> > 由已知可得 $a_{n + 2} - 1 = 5(a_{n + 1} - 1) - 6(a_n - 1)$ ，令 $b_{n} = a_{n} - 1$ ，可得 $b_{n + 2} - 2b_{n + 1} = 3(b_{n + 1} - 2b_n)$ ，从而得数列 $\{b_{n + 1} - 2b_n\}$ 是等比数列，求得 $b_{n + 1} = 2b_{n} + 3^{n - 1}$ ，即有 $\frac{b_{n + 1}}{3^{n + 1}} = \frac{2}{3}\cdot \frac{b_n}{3^n} +\frac{1}{9}$ ，即可得 $\{\frac{b_n}{3^n} -\frac{1}{3}\}$ 是等比数列，求出其首项和公比，可得 $b_{n} = 3^{n - 1} - 2^{n - 1}$ ，即可得 $a_{n}$ ：
>
> > [!note]- **【解析】**
> > 解：因为 $a_{n+2}=5a_{n+1}-6a_{n}+2$
> >
> > 所以 $a_{n+2}-1=5\left(a_{n+1}-1\right)-6\left(a_{n}-1\right)$
> >
> > 令 $b_{n}=a_{n}-1$
> >
> > 则 $b_{1} = 0, b_{2} = 1, b_{n + 2} = 5b_{n + 1} - 6b_{n}$
> >
> > 所以 $b_{n + 2} - 2b_{n + 1} = 3b_{n + 1} - 6b_n = 3(b_{n + 1} - 2b_n)$
> >
> > 所以数列 $\{b_{n + 1} - 2b_n\}$ 是等比数列，首项为 $b_{2} - 2b_{1} = 1$ ，公比为3，
> >
> > 所以 $b_{n + 1} - 2b_n = 3^{n - 1}$
> >
> > 所以 $b_{n+1}=2b_{n}+3^{n-1}$
> >
> > 所以 $b_{n+1}=2b_{n}+3^{n-1}$ ， $\frac{b_{n+1}}{3^{n+1}}=\frac{2}{3}\cdot\frac{b_{n}}{3^{n}}+\frac{1}{9}$ ，
> >
> > 所以 $\frac{b_{n + 1}}{3^{n + 1}} -\frac{1}{3} = \frac{2}{3}\left(\frac{b_n}{3^n} -\frac{1}{3}\right)$
> >
> > 所以数列 $\{\frac{b_n}{3^n} -\frac{1}{3}\}$ 是等比数列，首项为 $\frac{b_1}{3} -\frac{1}{3} = -\frac{1}{3}$ ，公比为 $\frac{2}{3}$
> >
> > 所以 $\frac{b_n}{3^n} -\frac{1}{3} = -\frac{1}{3}\cdot (\frac{2}{3})^{n - 1}$
> >
> > 所以 $b_{n} = 3^{n}\left[-\frac{1}{3}\cdot \left(\frac{2}{3}\right)^{n - 1} + \frac{1}{3}\right] = 3^{n - 1} - 2^{n - 1}$
> >
> > 即 $a_{n} - 1 = 3^{n - 1} - 2^{n - 1}$
> >
> > 所以 $a_{n} = 3^{n - 1} - 2^{n - 1} + 1$
