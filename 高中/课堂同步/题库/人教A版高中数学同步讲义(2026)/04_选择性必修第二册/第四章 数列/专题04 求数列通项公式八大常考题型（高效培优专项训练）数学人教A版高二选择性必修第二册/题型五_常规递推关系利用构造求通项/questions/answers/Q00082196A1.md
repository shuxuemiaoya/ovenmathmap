> [!faq]- 《专题04 求数列通项公式八大常考题型（高效培优专项训练）数学人教A版高二选择性必修第二册》官方解析
>
> > [!success]- **【答案】** $\frac{1}{3}$
>
> > [!note]- **【分析】**
> > 先由已知递推关系变形后得到数列 $\left\{a_{n} + a_{1} + n\right\}$ 是首项为 $2a_{1} + 1$ ，公比为 $^2$ 的等比数列，再代入 $a_{10} = 843$ 后计算可得·
>
> > [!note]- **【解析】**
> > 由已知得 $a_{n+1} + a_1 + n + 1 = 2(a_n + a_1 + n)$ ，
> >
> > 又 $a_1 + a_1 + 1 = 2a_1 + 1$ ，所以数列 $\{a_n + a_1 + n\}$ 是首项为 $2a_{1} + 1$ ，公比为 $^2$ 的等比数列，
> >
> > 则 $a_{n} + a_{1} + n = (2a_{1} + 1)2^{n - 1}$
> >
> > 所以 $a_{10} + a_{1} + 10 = (2a_{1} + 1)2^{9}$ ，又 $a_{10} = 843$ ，解得 $a_{1} = \frac{1}{3}$ .
> >
> > 故答案为： $\frac{1}{3}$

> > 34．无穷数列 $\left\{a_{n}\right\}$ 满足 $a_{1}=1$ ， $3a_{n+1}+a_{n}=4$ ，则数列 $\left\{a_{n}-3\right\}$ 的所有项和S= \_\_\_\_.

> > 【答案】 $-\infty$
> >
> > 【分析】根据递推公式 $3a_{n + 1} + a_n = 4$ ，得到 $3(a_{n + 1} - 1) = -(a_n - 1)$ ，结合 $a_1 = 1$ 即可求出数列 $\{a_n\}$ 的各项值，进而得到数列 $\{a_n - 3\}$ 的各项值，由此即可求数列 $\{a_n - 3\}$ 的所有项和S·
> >
> > 【详解】因为 $3a_{n + 1} + a_n = 4$ ，所以有： $3(a_{n + 1} - 1) = -(a_n - 1)$
> >
> > 因为 $a_1 = 1$ ，由此可得 $a_{n} = 1$ ，所以 $a_{n} - 3 = 1 - 3 = -2$
> >
> > 所以数列 $\{a_{n} - 3\}$ 为各项均为-2的无穷数列，
