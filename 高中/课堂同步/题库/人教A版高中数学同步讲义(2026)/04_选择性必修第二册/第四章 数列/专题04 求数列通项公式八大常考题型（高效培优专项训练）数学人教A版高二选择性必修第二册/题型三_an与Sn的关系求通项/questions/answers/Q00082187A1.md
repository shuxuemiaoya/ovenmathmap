> [!faq]- 《专题04 求数列通项公式八大常考题型（高效培优专项训练）数学人教A版高二选择性必修第二册》官方解析
>
> > [!success]- **【答案】** $a_{n} = \frac{4}{n(n + 1)}$
>
> > [!note]- **【分析】**
> > 利用 $a_{n} = S_{n} - S_{n - 1}(n - 2)$ 将已知条件 $S_{n} = n^{2}a_{n}$ 进行转化，得到 $S_{n}$ 与 $S_{n - 1}$ 的关系式，再通过变形得到 $\frac{S_n}{S_{n - 1}}$ 的表达式，然后利用累乘法求出 $S_{n}$ 的表达式，最后根据 $a_{n} = S_{n} - S_{n - 1}(n - 2)$ 求出数列 $\{a_n\}$ 的通项公
> >
> > 式，并且要单独验证 n=1 时的情况·
>
> > [!note]- **【解析】**
> > 由 $S_{n} = n^{2}a_{n}$ ，当 $n - 2$ 时， $a_{n} = S_{n} - S_{n - 1}$ ，得 $S_{n} = n^{2}(S_{n} - S_{n - 1})$ ，化简得： $n^2 S_{n - 1} = (n^2 -1)S_n\Rightarrow \frac{S_n}{S_{n - 1}} = \frac{n^2}{n^2 - 1} = \frac{n^2}{(n - 1)(n + 1)}$ ，当 $n - 2$ 时， $\frac{S_n}{S_{n - 1}}\cdot \frac{S_{n - 1}}{S_{n - 2}}\dots \frac{S_2}{S_1} = \frac{n^2}{(n - 1)(n + 1)}\cdot \frac{(n - 1)^2}{(n - 2)n}\dots \frac{2^2}{1\times 3}\Rightarrow \frac{S_n}{S_1} = \frac{2n}{n + 1}$ 因为 $a_1 = 2$ ，所以 $S_{1} = a_{1} = 2$ ，那么 $S_{n} = \frac{4n}{n + 1}$ 当 $n - 2$ ， $a_{n} = S_{n} - S_{n - 1} = \frac{4n}{n + 1} -\frac{4(n - 1)}{n} = \frac{4}{n(n + 1)}$ 当 $n = 1$ 时， $a_1 = 2$ ， $a_{n} = \frac{4}{n(n + 1)}$ 满足，数列 $\{a_n\}$ 的通项为 $a_{n} = \frac{4}{n(n + 1)}.$
