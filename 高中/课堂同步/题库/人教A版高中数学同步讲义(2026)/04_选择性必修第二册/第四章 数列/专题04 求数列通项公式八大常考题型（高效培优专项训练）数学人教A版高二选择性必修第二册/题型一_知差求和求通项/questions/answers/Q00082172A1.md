> [!faq]- 《专题04 求数列通项公式八大常考题型（高效培优专项训练）数学人教A版高二选择性必修第二册》官方解析
>
> > [!success]- **【答案】** $\ln 15 + 1$
>
> > [!note]- **【分析】**
> > 整理数列的递推公式，利用累加法求得其通项公式 $a_{n} = \ln n + 1$ ，再赋值计算即得
>
> > [!note]- **【解析】**
> > 因为 $a_{n + 1} = a_n + \ln (1 + \frac{1}{n})$ ，所以 $a_{n + 1} - a_n = \ln (1 + \frac{1}{n}) = \ln (n + 1) - \ln n$
> >
> > 所以 $n$ 2时， $a_{n} - a_{n-1} = \ln n - \ln (n - 1)$
> >
> > 则 $a_{n}=a_{n}-a_{n-1}+a_{n-1}-a_{n-2}+\cdots+a_{3}-a_{2}+a_{2}-a_{1}+a_{1}$
> >
> > $$
> > = \ln n - \ln (n - 1) + \ln (n - 1) - \ln (n - 2) + \dots + \ln 3 - \ln 2 + \ln 2 - \ln 1 + 1 = \ln n + 1
> > $$
> >
> > 故 $a_{15}=\ln15+1$ .
> >
> > 故答案为： $\ln15+1$
