> [!faq]- 《专题04 求数列通项公式八大常考题型（高效培优专项训练）数学人教A版高二选择性必修第二册》官方解析
>
> > [!success]- **【答案】** (1) $a_{n}=3^{n}-2^{n}$ (2) $S_{n} = \frac{(2n - 1)\cdot 3^{n + 1} + 3}{4}$
>
> > [!note]- **【分析】**
> > （1）先根据题干构造出 $\{a_{n} + 2^{n}\}$ 是以3为首项，3为公比的等比数列，进而求出数列 $\{a_{n}\}$ 的通项公式；
> >
> > (2) 由 (1) 可知数列 $\{n(a_n + 2^n)\}$ 的通项公式为等差乘等比，利用错位相减求出前 $n$ 项和即可·
>
> > [!note]- **【解析】**
> > （1）由于 $a_{n + 1} = 3a_{n} + 2^{n}$ ，则 $a_{n + 1} + 2^{n + 1} = 3a_{n} + 2^{n} + 2^{n + 1}$
> >
> > 化简得 $a_{n + 1} + 2^{n + 1} = 3(a_n + 2^n)$
> >
> > 又 $a_1 + 2 = 3$ ，则 $\left\{a_n + 2^n\right\}$ 是以3为首项，3为公比的等比数列，
> >
> > 得 $a_{n} + 2^{n} = 3^{n}$ ，所以 $a_{n} = 3^{n} - 2^{n}$
> >
> > (2) 由(1)得， $a_{n}=3^{n}-2^{n}$ ，则 $n(a_{n}+2^{n})=n\cdot3^{n}$ ，则
> >
> > $S_{n} = 1 \cdot 3^{1} + 2 \cdot 3^{2} + 3 \cdot 3^{3} + \cdots + n \cdot 3^{n}$ ，①
> >
> > $3S_{n} = 1 \cdot 3^{2} + 2 \cdot 3^{3} + 3 \cdot 3^{4} + L + n \cdot 3^{n+1}$ ，②
> > - **①**：-②，得
> >
> > $-2S_{n}=3^{1}+3^{2}+3^{3}+\cdots+3^{n}-n\cdot3^{n+1}$ $-2S_{n}=\frac{3(1-3^{n})}{1-3}-n\cdot3^{n+1}$ $-2S_{n}=\frac{3-3^{n+1}}{-2}-n\cdot3^{n+1}$ $-2S_{n}=\frac{3^{n+1}-3}{2}-n\cdot3^{n+1}$ $-2S_{n}=\left(\frac{1}{2}-n\right)\cdot3^{n+1}-\frac{3}{2}$ 化简后得 $S_{n}=\frac{(2n-1)\cdot3^{n+1}+3}{4}$
