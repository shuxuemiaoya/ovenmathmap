> [!faq]- 《专题04 求数列通项公式八大常考题型（高效培优专项训练）数学人教A版高二选择性必修第二册》官方解析
>
> > [!success]- **【答案】** C
>
> > [!note]- **【分析】**
> > 根据 $S_{n}$ 与 $a_{n}$ 的关系可得 $\frac{a_{n + 1}}{a_n} = \frac{n}{n + 2}$ ，利用累乘法计算得出 $a_{n}$ 即可求解
>
> > [!note]- **【解析】**
> > 易得 $S_{n + 1} = (n + 1)^2 a_{n + 1}$ ，故 $S_{n + 1} - S_n = (n + 1)^2 a_{n + 1} - n^2 a_n$
> >
> > 化简得 $\left(n^2 + 2n\right)a_{n+1} = n^2a_n$ ，即 $\left(n + 2\right)a_{n+1} = na_n$
> >
> > 由 $a_1 = 1$ 知 $a_{n}\neq 0$ ，故 $\frac{a_{n + 1}}{a_n} = \frac{n}{n + 2}$
> >
> > 累乘可得 $\frac{a_{n+1}}{a_{n}}\cdots\cdots\frac{a_{2}}{a_{1}}=\frac{n}{n+2}\cdots\times\frac{2}{4}\times\frac{1}{3}$
> >
> > 即 $a_{n + 1} = \frac{2a_1}{(n + 1)(n + 2)} = \frac{2}{(n + 1)(n + 2)}$ ，故 $a_{n} = \frac{2}{n(n + 1)} (n - 2)$
> >
> > 当 $n = 1$ 时，也符合上式，故 $S_{n} = n^{2}a_{n} = \frac{2n}{n + 1}$ ，故 $S_{30} = \frac{60}{31}$
> >
> > 故选 **C**.
