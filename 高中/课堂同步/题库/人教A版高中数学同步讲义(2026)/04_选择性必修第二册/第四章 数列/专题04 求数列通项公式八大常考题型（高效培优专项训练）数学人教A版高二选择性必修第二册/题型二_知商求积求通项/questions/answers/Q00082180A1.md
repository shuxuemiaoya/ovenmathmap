> [!faq]- 《专题04 求数列通项公式八大常考题型（高效培优专项训练）数学人教A版高二选择性必修第二册》官方解析
>
> > [!success]- **【答案】** ABD
>
> > [!note]- **【分析】**
> > 先利用累乘法求出数列 $\{a_{n}\}$ 的通项公式，作差判断A，根据数列的增减性判断B，利用 $n^3 < a_n < (n + 1)^3$ 判断C，利用数学归纳法，假设数列 $\{a_{n}\}$ 的前 $n$ 项和 $S_{n} = \frac{n(n + 1)(n + 2)(n + 3)}{4}$ 成立判断D.【详解】由题意可得 $a_{n}\neq 0$ ， $\frac{a_{n + 1}}{a_n} = \frac{n + 3}{n}$
>
> > [!note]- **【解析】**
> > 所以当 $n$ 2时， $\frac{a_n}{a_{n-1}} = \frac{n + 2}{n - 1}, \ldots, \frac{a_3}{a_2} = \frac{5}{2}, \frac{a_2}{a_1} = \frac{4}{1}$
> > 以上 $n - 1$ 个式子左右两边分别相乘得 $\frac{a_n}{a_{n - 1}}\times \ldots \times \frac{a_3}{a_2}\times \frac{a_2}{a_1} = \frac{n + 2}{n - 1}\times \ldots \times \frac{5}{2}\times \frac{4}{1}$
> > 即 $\frac{a_n}{a_1} = \frac{(n + 2)!}{3!\times(n - 1)!} = \frac{(n + 2)(n + 1)n}{6}$ ，将 $a_1 = 6$ 代入解得 $a_{n} = n(n + 1)(n + 2)$
> > 当 $n = 1$ 时满足 $a_1 = 6$ ，所以数列 $\{a_n\}$ 的通项公式为 $a_{n} = n(n + 1)(n + 2)$
> > 因为 $f(n)=n(n+2)-(n+1)^{2}=-1<0$ 对 $\forall n\in N^{*}$ 恒成立，
> > 所以 $n(n + 1)(n + 2) = a_{n} < (n + 1)^{3}$ 对 $\forall n\in \mathbb{N}^*$ 恒成立，A说法正确；
> > 易知数列 $\left\{a_{n}\right\}$ 是递增数列，且 $a_{11} = 1716$ ， $a_{12} = 2184$ ，所以 $\forall n \in \mathbb{N}^{*}$ ， $a_{n} \neq 2025$ ，B说法正确；
> > 因为 $n^3 < a_n < (n + 1)^3$ ，所以不存在 $n \in \mathbb{N}^*$ 使得 $a_n$ 为完全立方数， $^\mathrm{C}$ 说法错误；
> > 下证 $\forall n\in \mathbf{N}^*$ ，数列 $\{a_n\}$ 的前 $n$ 项和 $S_{n} = \frac{n(n + 1)(n + 2)(n + 3)}{4}$
> > 当 $n = 1$ 时， $S_{1} = \frac{1 \times 2 \times 3 \times 4}{4} = 6$ 成立，
> > 假设当 $n = k$ 时， $S_{k} = \frac{k(k + 1)(k + 2)(k + 3)}{4}$ 成立，
> > 则当 $n = k + 1$ 时，
> > $S_{k} + a_{k + 1} = \frac{k(k + 1)(k + 2)(k + 3)}{4} +(k + 1)(k + 2)(k + 3) = \frac{(k + 1)(k + 2)(k + 3)(k + 4)}{4} = S_{k + 1}$ 成立
> > 所以 $\forall n\in \mathbb{N}^*$ ，数列 $\{a_{n}\}$ 的前 $n$ 项和 $S_{n} = \frac{n(n + 1)(n + 2)(n + 3)}{4}$ ，D说法正确；
> >
> > 故选 **ABD**
