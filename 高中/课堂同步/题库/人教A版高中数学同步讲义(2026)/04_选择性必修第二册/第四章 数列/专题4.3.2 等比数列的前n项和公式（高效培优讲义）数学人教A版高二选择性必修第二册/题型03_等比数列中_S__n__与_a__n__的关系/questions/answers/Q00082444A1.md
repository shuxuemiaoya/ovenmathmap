> [!faq]- 《专题4.3.2 等比数列的前n项和公式（高效培优讲义）数学人教A版高二选择性必修第二册》官方解析
>
> > [!success]- **【答案】** (1) $a_{n}=2^{2n-1},n\in N^{*},S_{n}=\frac{2}{3}(4^{n}-1)$ (2) $T_{n}=\frac{n}{2n+1}$
>
> > [!note]- **【分析】**
> > （1）利用退位相减法可求通项（注意检验首项），利用公式法可求 $S_{n}$ ；
> >
> > (2) 利用裂项相消法即可求和·
>
> > [!note]- **【解析】**
> > （1）由 $\frac{a_1}{2} +\frac{a_2}{4} +\frac{a_3}{8} +\dots +\frac{a_n}{2^n} = 2^n -1$
> >
> > 当 $n = 1$ 时， $\frac{a_1}{2} = 2 - 1 = 1\Rightarrow a_1 = 2$
> >
> > 当 n 2 时，可得 $\frac{a_{1}}{2} + \frac{a_{2}}{4} + \frac{a_{3}}{8} + \cdots + \frac{a_{n-1}}{2^{n-1}} = 2^{n-1} - 1$
> >
> > 两式相减得： $\frac{a_n}{2^n} = 2^n -1 - (2^{n - 1} - 1) = 2^{n - 1}$ ，所以有 $a_{n} = 2^{2n - 1}$ ， $a_1 = 2$ 也符合上式，
> >
> > 所以 $a_{n} = 2^{2n - 1}, n \in \mathbb{N}^{*}$ ，而 $\frac{a_n}{a_{n - 1}} = 4$ ，故 $\{a_n\}$ 是首项为 $2$ ，公比 $4$ 的等比数列，
> >
> > 故 $S_{n} = \frac{2(1 - 4^{n})}{1 - 4} = \frac{2}{3}(4^{n} - 1)$
> >
> > (2) 当 n=1 时，有 $b_{1}=\frac{1}{\log_{2}a_{1}\cdot\log_{2}a_{2}}=\frac{1}{\log_{2}2\cdot\log_{2}2^{3}}=\frac{1}{1\times3}$
> >
> > 当 $n$ 2时，有 $b_{n} = \frac{1}{\log_{2}a_{n}\cdot\log_{2}a_{n + 1}} = \frac{1}{\log_{2}2^{2n - 1}\cdot\log_{2}2^{2n + 1}} = \frac{1}{(2n - 1)(2n + 1)}$
> >
> > 所以有 $T_{n}=b_{1}+b_{2}+b_{3}+\cdots+b_{n}=\frac{1}{1\times3}+\frac{1}{3\times5}+\frac{1}{5\times7}+\cdots+\frac{1}{(2n-1)(2n+1)}$
> >
> > $$
> > = \frac {1}{2} \left(\frac {1}{1} - \frac {1}{3} + \frac {1}{3} - \frac {1}{5} + \frac {1}{5} - \frac {1}{7} + \dots + \frac {1}{2 n - 1} - \frac {1}{2 n + 1}\right) = \frac {1}{2} \left(1 - \frac {1}{2 n + 1}\right) = \frac {n}{2 n + 1}
> > $$
