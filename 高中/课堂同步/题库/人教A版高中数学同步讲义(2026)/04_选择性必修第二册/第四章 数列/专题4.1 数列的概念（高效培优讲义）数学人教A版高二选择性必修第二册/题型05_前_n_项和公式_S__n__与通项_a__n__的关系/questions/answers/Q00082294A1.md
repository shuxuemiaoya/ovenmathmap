> [!faq]- 《专题4.1 数列的概念（高效培优讲义）数学人教A版高二选择性必修第二册》官方解析
>
> > [!success]- **【答案】** B
>
> > [!note]- **【分析】**
> > 令 $n = 1$ 可得 $a_{1}$ 的值，当 $n\in \mathbb{N}^*$ 时，由 $2S_{n} = (n + 1)a_{n}$ 得出 $2S_{n + 1} = (n + 2)a_{n + 1}$ ，两式作差可推导出数列 $\left\{\frac{a_n}{n}\right\}$ 为常数列，求出数列 $\{a_n\}$ 的通项公式，即可得解· 【详解】因为 $S_{n}$ 为正项数列 $\{a_n\}$ 的前 $n$ 项和，且 $a_1S_n = (n + 1)a_n$ ，令 $n = 1$ 可得 $a_1 = 2$ ，故 $2S_{n} = (n + 1)a_{n}$
>
> > [!note]- **【解析】**
> > 当 $n\in \mathbf{N}^*$ 时， $2S_{n + 1} = (n + 2)a_{n + 1}$
> > 两式相减得到 $2a_{n + 1} = (n + 2)a_{n + 1} - (n + 1)a_n$ ，即 $na_{n + 1} = (n + 1)a_n$ ，故 $\frac{a_{n + 1}}{n + 1} = \frac{a_n}{n}$
> > 于是 $\left\{\frac{a_{n}}{n}\right\}$ 为常数列，故 $\frac{a_{n}}{n}=\frac{a_{1}}{1}=2$ ，故 $a_{n}=2n$ ，故 $a_{10}=20$ 。
> > 故选：B.
> > ## 方法技巧
> > 已知 $S_{n}$ 求出 $a_{n}$ 依据的是 $S_{n}$ 的定义： $S_{n} = a_{1} + a_{2} + \ldots + a_{n}$ ，分段求解，然后检验结果能否统一形式，能就写成一个，否则只能写成分段函数的形式。
