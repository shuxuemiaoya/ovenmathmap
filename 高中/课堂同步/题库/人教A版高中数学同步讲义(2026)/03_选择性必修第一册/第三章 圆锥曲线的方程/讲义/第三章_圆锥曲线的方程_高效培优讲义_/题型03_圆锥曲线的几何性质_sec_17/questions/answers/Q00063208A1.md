> [!faq]- 《第三章_圆锥曲线的方程_高效培优讲义_》官方解析
>
> > [!success]- **【答案】** (1) $x^{2}-\frac{y^{2}}{2}=1,\sqrt{3}$ (2) $\sqrt{2}$ (3) $m = \pm \sqrt{2}$
>
> > [!note]- **【解析】**
> > （1）因为双曲线 C 与 $\frac{y^{2}}{4}-\frac{x^{2}}{2}=1$ 有相同的渐近线，
> >
> > 所以可设双曲线 $C$ 的方程为 $\frac{x^2}{2} -\frac{y^2}{4} = \lambda$
> >
> > 将 $M(\sqrt{2}, -\sqrt{2})$ 代入，得 $\frac{2}{2} - \frac{2}{4} = \lambda$ ，得 $\lambda = \frac{1}{2}$ ，
> >
> > 故双曲线 $C$ 的方程为 $x^{2} - \frac{y^{2}}{2} = 1$ ，所以 $a = 1, b = \sqrt{2}, c = \sqrt{3}$ ，故离心率 $e = \sqrt{3}$
> >
> > (2) 由 (1) 可知， $C$ 的焦点为 $(\pm \sqrt{3}, 0)$ ，渐近线方程为 $y = \pm \sqrt{2} x$
> >
> > 故 $C$ 的焦点到其渐近线的距离 $d = \frac{|\pm\sqrt{2} \times \sqrt{3}|}{\sqrt{1 + (\sqrt{2})^2}} = \sqrt{2}$
> >
> > (3) 联立直线 $AB$ 与双曲线 $C$ 的方程，得 $\left\{ \begin{array}{l} x^{2} - \frac{y^{2}}{2} = 1, \\ y = x + m, \end{array} \right.$
> >
> > 整理得 $x^{2} - 2mx - m^{2} - 2 = 0$ ， $\Delta = 8m^2 +8 > 0$
> >
> > 设 $A(x_{1},y_{1}),B(x_{2},y_{2})$ ，则 $AB$ 的中点坐标为 $\left(\frac{x_1 + x_2}{2},\frac{y_1 + y_2}{2}\right)$
> >
> > 由根与系数的关系得， $x_{1} + x_{2} = 2m,y_{1} + y_{2} = (x_{1} + m) + (x_{2} + m) = (x_{1} + x_{2}) + 2m = 4m$
> >
> > 所以 $AB$ 的中点坐标为 $(m, 2m)$
> >
> > 又点 $(m,2m)$ 在圆 $x^{2} + y^{2} = 10$ 上，所以 $m^2 +4m^2 = 10$ ，所以 $m = \pm \sqrt{2}$
