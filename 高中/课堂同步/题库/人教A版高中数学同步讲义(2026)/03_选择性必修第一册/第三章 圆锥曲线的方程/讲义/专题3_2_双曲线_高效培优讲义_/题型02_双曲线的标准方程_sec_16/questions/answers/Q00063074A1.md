> [!faq]- 《专题3_2_双曲线_高效培优讲义_》官方解析
>
> > [!success]- **【答案】** $y^{2}-\frac{x^{2}}{3}=1$
>
> > [!note]- **【解析】**
> > 由复数 $z$ 满足 $\left|z + 2\mathrm{i}\right| - \left|z - 2\mathrm{i}\right| = \pm 2$ ，可得 $\left|\left|z + 2\mathrm{i}\right| - \left|z - 2\mathrm{i}\right|\right| = 2$
> >
> > 根据复数的几何意义，方程表示复数 $z$ 对应的点 $Z$ 到点 $(0, -2)$ 和 $(0, 2)$ 间的距离之差的绝对值为定值2，
> >
> > 由双曲线的定义，可得复数 $z$ 所对应轨迹为以 $(0, -2)$ 和 $(0, 2)$ 为焦点的双曲线
> >
> > 且 $2a = 2, 2c = 4$ ，可得 $a = 1, c = 2$ ，则 $b = \sqrt{c^2 - a^2} = \sqrt{3}$
> >
> > 所以复数 z 所对应的点的轨迹方程为 $y^{2}-\frac{x^{2}}{3}=1$
> >
> > 故答案为： $y^{2}-\frac{x^{2}}{3}=1$
