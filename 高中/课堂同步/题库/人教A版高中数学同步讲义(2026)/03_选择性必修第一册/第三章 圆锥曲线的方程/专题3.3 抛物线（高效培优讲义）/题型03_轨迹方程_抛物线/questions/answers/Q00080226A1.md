> [!faq]- 《专题3.3 抛物线（高效培优讲义）》官方解析
>
> > [!success]- **【答案】** $\left\{\begin{aligned}(x-1)^{2}+y^{2}&=\frac{9}{4},x\leq\frac{1}{2}\\ y^{2}&=3-2x,x>\frac{1}{2}\end{aligned}\right.$
>
> > [!note]- **【解析】**
> > 延长 $AP$ 到 $D$ 使 $\left|AP\right| = \left|DP\right|$ ，由 $\left|PB\right| = \left|PC\right|$ ，得四边形 $DCAB$ 为平行四边形，又 $BC \perp AD$ ，则 $\neg DCAB$ 为菱形，过 $D$ 作 $DF \perp x$ 轴，垂足为 $F$ ，直线 $DF: x = -1$ ，则 $\left|OF\right| = \left|OA\right| = 1$ ，又 $\left|CD\right| = \left|CA\right|$ ， $CD \perp DF$ ，于是 $C$ 的轨迹为抛物线： $y^2 = 4x$ ，① $Q$ 在 $y^2 = 4x$ 内部，过 $Q$ 作 $QN \perp y$ 轴交 $x = -1$ 于点 $N$ ，而 $CD \perp y$ 轴， $|CD| = |CA|$ ， $|QA|$ 为定值，则当 $Q, C, D$ 共线时， $\left|CA\right| + \left|AQ\right| + \left|QC\right|$ 有最小值 $|QA| + |QD| = 3$ 设 $Q(x, y)$ ， $\sqrt{(x - 1)^2 + y^2} + |x + 1| = 3$ ，而 $y^2 < 4x$ ，整理得 $y^2 = 3 - 2x (x > \frac{1}{2})$ ；
> >
> > ![](../../../images/questions/part-001/2a4b4d58f9dfa6741315975ee5148fe3a9895230295e7e6dff5e05b077387abd.jpg)
> > - **②**：$Q$ 在 $y^{2} = 4x$ 及外部，当 $Q, C, A$ 共线时， $\left|CA\right| + \left|AQ\right| + \left|QC\right|$ 有最小值3，即 $2\left|QA\right| = 3$
> >
> > 设 $Q(x,y)$ ，则 $\sqrt{(x - 1)^2 + y^2} = \frac{3}{2}$ ，而 $y^{2}$ 4x，整理得 $(x - 1)^{2} + y^{2} = \frac{9}{4} (x\leq \frac{1}{2})$
> >
> > 所以曲线 的方程为： $\left\{ \begin{array}{l} (x - 1)^2 + y^2 = \frac{9}{4}, x \leqslant \frac{1}{2} \\ y^2 = 3 - 2x, x > \frac{1}{2} \end{array} \right.$
> >
> > 故答案为： $\left\{ \begin{array}{l}(x - 1)^2 +y^2 = \frac{9}{4},x\leq \frac{1}{2}\\ y^2 = 3 - 2x,x > \frac{1}{2} \end{array} \right.$
> >
> > ## 方法技巧
> >
> > 求轨迹问题的两种方法
> >
> > (1)直接法：按照动点适合条件直接代入求方程.
> >
> > (2)定义法：若动点满足某种曲线定义，可按待定系数法列方程(组)求解曲线方程.
