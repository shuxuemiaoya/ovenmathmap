> [!faq]- 《专题3.1 椭圆（高效培优讲义）》官方解析
>
> > [!success]- **【答案】** (1) $\frac{x^{2}}{25}+\frac{y^{2}}{16}=1$ (2) $\frac{16\sqrt{3}}{3}$
>
> > [!note]- **【解析】**
> > （1）因为椭圆的焦距为 $2c = 6$ ，得 $c = 3$
> >
> > 又 $2a = \left|PF_{1}\right| + \left|PF_{2}\right| = 10$ ，则 $a = 5$ ，得 $b^{2} = a^{2} - c^{2} = 25 - 9 = 16$
> >
> > 因此，椭圆的标准方程为 $\frac{x^{2}}{25}+\frac{y^{2}}{16}=1$
> >
> > (2) 因为点 P 是椭圆 $\frac{x^{2}}{25} + \frac{y^{2}}{16} = 1$ 上的一点，则有 $\left|PF_{1}\right| + \left|PF_{2}\right| = 2a = 10$
> >
> > 可得 $\left|PF_{1}\right|^{2}+\left|PF_{2}\right|^{2}+2\left|PF_{1}\right|\cdot\left|PF_{2}\right|=100$ ，①
> >
> > 又由 $\angle F_{1}PF_{2} = \frac{\pi}{3}$ 结合余弦定理，得 $\left|PF_1\right|^2 +\left|PF_2\right|^2 -2\left|PF_1\right|\left|PF_2\right|\cos \frac{\pi}{3} = \left|PF_1\right|^2 +\left|PF_2\right|^2 -\left|PF_1\right|\left|PF_2\right| = \left|F_1F_2\right|^2 = 36$ ②
> > - **①**：\_②可得 $3\left|PF_{1}\right|\cdot \left|PF_{2}\right| = 64$ ，即 $\left|PF_1\right|\cdot \left|PF_2\right| = \frac{64}{3}$
> >
> > 则 $\triangle F_{1}PF_{2}$ 的面积 $S_{\triangle PF_1F_2} = \frac{1}{2}\left|PF_1\right|\cdot \left|PF_2\right|\sin \frac{\pi}{3} = \frac{1}{2}\times \frac{64}{3}\times \frac{\sqrt{3}}{2} = \frac{16\sqrt{3}}{3}.$
