> [!faq]- 《专题3.1 椭圆（高效培优讲义）》官方解析
>
> > [!success]- **【答案】** BC
>
> > [!note]- **【解析】**
> > 对于椭圆 $E \frac{x^{2}}{25} + \frac{y^{2}}{9} = 1$ ，a = 5, b = 3, c = 4，故椭圆长轴长为 2a = 10，A 错误；
> >
> > 椭圆离心率为 $e=\frac{c}{a}=\frac{4}{5}$ ，B 正确；
> >
> > 点 $P(x_0, y_0)$ 是椭圆 $E$ 上的一个动点，则 $a - c \leq |PF_1| \leq a + c$ ，即 $1 \leq |PF_1| \leq 9$ ， $C$ 正确；
> >
> > 由 $PF_{1} \cdot PF_{2} = 0$ 可知 $P$ 点位于以 $F_{1}F_{2}$ 为直径的圆上， $F_{1}(-4,0), F_{2}(4,0)$
> >
> > 则该圆方程为 $x^{2} + y^{2} = 16$ ，联立 $\frac{x^2}{25} +\frac{y^2}{9} = 1$ ，解得 $x = \pm \frac{5\sqrt{7}}{4},y = \pm \frac{9}{4}$
> >
> > 则 $P\left(\frac{5\sqrt{7}}{4}, \frac{9}{4}\right)$ 或 $P\left(\frac{5\sqrt{7}}{4}, -\frac{9}{4}\right)$ 或 $P\left(-\frac{5\sqrt{7}}{4}, \frac{9}{4}\right)$ 或 $P\left(-\frac{5\sqrt{7}}{4}, -\frac{9}{4}\right)$ ，故满足题意的点 $P$ 有 $^{4}$ 个， $^{D}$ 错误，
> >
> > 故选 **BC**
