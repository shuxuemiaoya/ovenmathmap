> [!faq]- 《第三章 圆锥曲线的方程（高效培优单元测试·提升卷）》官方解析
>
> > [!success]- **【答案】** $\frac{(\sqrt{5} - 1)\pi b^2}{2}$
>
> > [!note]- **【解析】**
> > 若 $e = \frac{c}{a} = \frac{\sqrt{5} - 1}{2}$ ，设 $c = (\sqrt{5} - 1)k$ ， $a = 2k$ ，则 $b^2 = a^2 - c^2 = (2\sqrt{5} - 2)k^2$ ，所以 $b^2 = ac$ ，
> >
> > 由等面积公式，以及椭圆的对称性可知，菱形 $ADBE$ 的内切圆的半径 $r = \frac{ab}{\sqrt{a^2 + b^2}}$
> >
> > 则其内切圆的面积 $S = \pi r^{2} = \frac{\pi a^{2} b^{2}}{a^{2} + b^{2}} = \frac{\pi a^{2} \cdot ac}{a^{2} + ac} = \frac{\pi a^{2} c}{a + c} = \frac{\pi ac}{1 + e} = \frac{2\pi b^{2}}{\sqrt{5} + 1} = \frac{(\sqrt{5} - 1)\pi b^{2}}{2}$ .
> >
> > 故答案为： $\frac{(\sqrt{5} - 1)\pi b^2}{2}$
