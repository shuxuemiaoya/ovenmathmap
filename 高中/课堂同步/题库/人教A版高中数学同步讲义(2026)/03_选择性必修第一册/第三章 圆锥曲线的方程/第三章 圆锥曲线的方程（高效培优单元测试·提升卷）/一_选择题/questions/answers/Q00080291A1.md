> [!faq]- 《第三章 圆锥曲线的方程（高效培优单元测试·提升卷）》官方解析
>
> > [!success]- **【答案】** B
>
> > [!note]- **【解析】**
> > 由已知，设 $\left|AF_{1}\right|\quad\left|BF_{1}\right|$ ，
> >
> > 则 $\left|AF_1\right| - \left|AF_2\right| = 2a,\left|BF_1\right| - \left|BF_2\right| = 2a$
> >
> > 两式相加得 $\left|AF_{1}\right|+\left|BF_{1}\right|-\left(\left|AF_{2}\right|+\left|BF_{2}\right|\right)=4a$
> >
> > 又 $\left|AF_2\right| + \left|BF_2\right| = \left|AB\right|$ ，所以 $\left|AF_1\right| + \left|BF_1\right| - \left|AB\right| = 4a$
> >
> > 又 $\left|AF_1\right| + \left|BF_1\right| = 3\left|F_1F_2\right| = 6c$ ，所以 $\left|AB\right| = 6c - 4a$
> >
> > 当 $AB \perp x$ 轴时 $\left|AB\right|$ 最小，此时 $\left|AB\right| = \frac{2b^2}{a}$
> >
> > 所以 $\frac{2b^2}{a} \leq 6c - 4a$ ，又 $b^2 = c^2 - a^2$
> >
> > 则 $\frac{2(c^2 - a^2)}{a} \leq 6c - 4a$ ，整理的 $2c^2 - 6ac + 2a^2 \leq 0$ ，
> >
> > 又 $e = \frac{c}{a}$ ，两边除以 $a^2$ 得 $2e^{2} - 6e + 2\leq 0$ ，解得 $\frac{3 - \sqrt{5}}{2}\leq e\leq \frac{3 + \sqrt{5}}{2}$
> >
> > 又双曲线的离心率 $e > 1$ ，所以双曲线的离心率取值范围是 $\left(1, \frac{3 + \sqrt{5}}{2}\right)$
> >
> > 故选：B.
