> [!faq]- 《专题01空间向量及其运算的四大常考题型_高效培优专项训练_》官方解析
>
> > [!success]- **【答案】** B
>
> > [!note]- **【分析】**
> > 用向量 $AB, AD, AA_{1}$ 作空间向量的一组基底分别表示 $AC_{1}$ 和 $CE$ ，由数量积为 $0$ 可得垂直·
>
> > [!note]- **【解析】**
> > 由题意，用向量 $AB, AD, AA_{1}$ 作空间向量的一组基底
> >
> > 则 $AC_{1}=AB+AD+AA_{1}, CE=CC_{1}+C_{1}E=AA_{1}-\frac{1}{2}(AB+AD)$
> >
> > 设正方体的棱长为 $^{1}$ ，于是：
> >
> > $$
> > A C _ {1} \cdot C E = (A B + A D + A A _ {1}) \cdot (A A _ {1} - \frac {1}{2} (A B + A D)) = 0 - \frac {1}{2} + 0 + 0 - 0 - \frac {1}{2} + 1 - 0 - 0 = 0 \text {故} A C _ {1} \perp C E
> > $$
> >
> > $$
> > A C _ {1}
> > $$
> >
> > 与 $CE$ 垂直
> >
> > 故选 **B**
