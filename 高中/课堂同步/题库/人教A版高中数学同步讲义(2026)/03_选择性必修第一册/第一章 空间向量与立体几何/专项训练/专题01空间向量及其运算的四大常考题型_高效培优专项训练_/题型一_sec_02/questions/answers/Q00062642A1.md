> [!faq]- 《专题01空间向量及其运算的四大常考题型_高效培优专项训练_》官方解析
>
> > [!success]- **【答案】** C
>
> > [!note]- **【分析】**
> > 根据空间向量的加减运算法则和相反向量的概念判断即可
>
> > [!note]- **【解析】**
> > $OA = -OC_{1}, OB = -OD_{1}, OC = -OA_{1}, OD = -OB_{1}$ 所以 $OA - OD = -OC_{1} + OB_{1} = OB_{1} - OC_{1}$ ，故 A 错误； $OB - OC = -OD_{1} + OA_{1} = OA_{1} - OD_{1}$ ，故 B 错误； $OA + OB + OC + OD = -OC_{1} - OD_{1} - OA_{1} - OB_{1} = -\left(OA_{1} + OB_{1} + OC_{1} + OD_{1}\right)$ ，故 C 正确； $OA_{1}-OA=-OC+OC_{1}=OC_{1}-OC$ ，故 D 错误·
> >
> > 故选 **C**
