> [!faq]- 《第一章_空间向量与立体几何_高效培优讲义_》官方解析
>
> > [!success]- **【答案】** C
>
> > [!note]- **【解析】**
> > A选项，设 $p = xa + yb$
> >
> > 即 $\left(1,0,1\right) = (x, - x,2x) + (0,y, - y) = (x, - x + y,2x - y)$
> >
> > 所以 $\left\{\begin{aligned}-x+y=0\\ x=1\\ 2x-y=1\end{aligned}\right.$ ，解得 $x=1,y=1,\quad p=a+b$
> >
> > 此时 $\left\{a,b,p\right\}$ 不能构成基底.
> >
> > B 选项， $q=(1,-2,3)=a-b$ ，此时 $\left\{a,b,q\right\}$ 不能构成基底.
> >
> > C 选项，设 $r = xa + yb$
> >
> > 即 $\left(1,1,1\right) = (x, - x + y,2x - y)$
> >
> > $\left\{ \begin{array}{l} -x + y = 1 \\ x = 1 \\ 2x - y = 1 \end{array} \right.$ ，此方程组无解，故此时 $\{a, b, r\}$ 能构成基底.
> >
> > D 选项， $s = (2, -1, 3) = 2a + b$ ，此时 $\left\{a, b, s\right\}$ 不能构成基底.
> >
> > 故选 **C**
