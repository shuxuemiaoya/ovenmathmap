## 题型02 空间共线向量定理

【典例1】在下列命题中：

①若向量 $a, b$ 共线，则向量 $a, b$ 所在的直线平行；

②若向量a,b所在的直线为异面直线，则向量a,b一定不共面；

③若三个向量 $a, b, c$ 两两共面，则向量 $a, b, c$ 共面；

④已知空间的三个向量 $a, b, c$ ，则对于空间的任意一个向量 $p$ 总存在实数 $x, y, z$ 使得 $p = xa + yb + zc$ 其中正确命题的个数是（ ）A.0 B.1 C.2 D.3

【答案】A

【详解】对于①，若向量a,b共线，则向量a,b所在的直线平行，也可能共线，故①错误；

对于②，由于向量可以平移，两个向量一定共面，故②错误；

对于③，任意两个向量自然是两两共面，三个向量则不一定共面，例如空间直角坐标系 $x, y, z$ 轴所在的向量

两两共面，但是显然 $x, y, z$ 轴不共面，故③错误；

对于④，若 $a, b$ 共线时，显然 $a, b, c$ 共面，于是 $xa + yb + zc$ 只能表示和 $a, b, c$ 共面的向量，对于空间中的任意向量 $\pmb{p}$ 则不一定成立，故④错误.

于是四个选项都是错的.

故选：A

【典例2】已知 $e_1, e_2, e_3$ 不共面，若 $AB = e_1 + 2e_2 - e_3$ ， $BC = \lambda e_1 + \mu e_2 + e_3$ ，且 $A, B, C$ 三点共线，则 $\lambda + \mu = (\quad)$ A. -3    B. 1    C. 2    D. 3

【答案】A

【详解】因为 A, B, C 三点共线，

所以 $AB = mBC$

即 $e_1 + 2e_2 - e_3 = m\lambda e_1 + m\mu e_2 + me_3$

所以 $\left\{ \begin{array}{l}m\lambda = 1\\ m\mu = 2\\ m = -1 \end{array} \right.$ ，解得 $\left\{ \begin{array}{l}\lambda = -1\\ \mu = -2 \end{array} \right.$

所以 $\lambda + \mu = -3$

故选：A

## 方法技巧

利用共线向量定理可以判定两直线平行、证明三点共线．证平行时，先从直线上取有向线段来表示两个向量，
然后利用向量的线性运算证明向量共线，进而可以得到线线平行，此为证明平行问题的一种重要方法；证明
三点共线问题时，通常不用图形。直接利用向量的线性运算，但一定要注意所表示的向量必须有一个公共点。
