> [!faq]- 《专题1_3_空间向量及其运算的坐标表示_高效培优讲义_》官方解析
>
> > [!success]- **【答案】** AC
>
> > [!note]- **【分析】**
> > 易求得对称点可判断 A；当 a, b 反向时可判断 B；由 $\frac{1}{4} + \frac{1}{2} + \frac{1}{4} = 1$ ，可得四点共面判断 C；设
> >
> > $a + b = p(a + b + c) + qc$ ，可得 $\left\{ \begin{array}{l}p = 1\\ p + q = 0 \end{array} \right.$ ，进而可得 $a + b,a + b + c,c$ 共面，判断D.
>
> > [!note]- **【解析】**
> > 对于 $^{A}$ ，点 $P(1,-1,2)$ 关于xOy平面对称的点的坐标是 $(1,-1,-2)$ ， $^{A}$ 正确；
> >
> > 对于 B，当 a, b 反向时， $a \cdot b = |a| \cdot |b| \cos \pi < 0$ ，此时向量的夹角为 $\pi$ ，不是钝角，B 错误；
> >
> > 对于 $^{C}$ ，由于对空间中任一点O，有 $\frac{\square\square\square\square}{OM}=\frac{1}{4}OA+\frac{1}{2}OB+\frac{1}{4}OC,\quad\frac{1}{4}+\frac{1}{2}+\frac{1}{4}=1$ ，而 $M,A,B,C$ 四点共面， $^{C}$ 正
> >
> > 确；
> >
> > D 选项，设 $a + b = p(a + b + c) + qc$ ，即 $a + b = pa + pb + (p + q)c$ ，故 $\left\{ \begin{array}{l} p = 1 \\ p + q = 0 \end{array} \right.$ ，
> >
> > 解得 $\left\{ \begin{array}{l} p = 1 \\ q = -1 \end{array} \right.$ ，故 $a + b, a + b + c, c$ 共面，不能构成空间的一个基底，故 ${}^{\mathrm{D}}$ 错误
> >
> > 故选 **AC**.
