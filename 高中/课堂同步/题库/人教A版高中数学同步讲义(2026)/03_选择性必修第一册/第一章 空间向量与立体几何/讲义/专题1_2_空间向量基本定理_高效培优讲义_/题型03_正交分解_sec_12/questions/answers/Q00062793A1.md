> [!faq]- 《专题1_2_空间向量基本定理_高效培优讲义_》官方解析
>
> > [!success]- **【答案】** C
>
> > [!note]- **【分析】**
> > 结合基底的概念，根据空间向量基本定理逐项判断即可·
>
> > [!note]- **【解析】**
> > 向量 $a, b, c$ 是不共面的三个向量，
> >
> > 对于 A， $3a = 2(a - b) + (a + 2b)$ ，则向量 $3a, a - b, a + 2b$ 共面，A 不能构成空间基底；
> >
> > 对于 B， $2b=(b-2a)+(b+2a)$ ，则向量 $2b, b-2a, b+2a$ 共面，B 不能构成空间基底；
> >
> > 对于 D， $2c=(a+c)-(a-c)$ ，则向量 $c, a+c, a-c$ 共面，D 不能构成空间基底；
> >
> > 对于 $C$ ，假定向量 $a,2b,b - c$ 共面，则存在不全为 $0$ 的实数 $\lambda_1,\lambda_2$
> >
> > 使得 $a = 2\lambda_{1}b + \lambda_{2}(b - c)$ ，
> >
> > 整理得 $a - (2\lambda_{1} + \lambda_{2})b + \lambda_{2}c = 0$ ，而向量 $a,b,c$ 不共面，
> >
> > 则有 $\left\{ \begin{array}{l} 1 = 0 \\ 2\lambda_{1} + \lambda_{2} = 0 \\ \lambda_{2} = 0 \end{array} \right.$ ，显然不成立，
> >
> > 所以向量 a,2b,b-c 不共面，能构成空间的一个基底， $^{C}$ 能构成空间基底。
> >
> > 故选 **C**
