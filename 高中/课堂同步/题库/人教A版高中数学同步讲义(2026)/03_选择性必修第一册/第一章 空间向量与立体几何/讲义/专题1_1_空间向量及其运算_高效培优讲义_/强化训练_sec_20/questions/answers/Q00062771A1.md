> [!faq]- 《专题1_1_空间向量及其运算_高效培优讲义_》官方解析
>
> > [!success]- **【答案】** $^{(1)}$ 证明见解析 $^{(2)}$ $\frac{\sqrt{6}}{6}$
>
> > [!note]- **【分析】**
> > （1）根据空间向量的线性运算易得 $\frac{AE}{2}\frac{1}{2}DB+\frac{1}{2}DC-DA$ ， $BC=DC-DB$ ，进而结合空间向量的
> >
> > 数量积计算即可；
> >
> > (2) 利用空间向量的数量积的定义求解即可.
>
> > [!note]- **【解析】**
> > （1）证明：由题意，因为
> >
> > $$
> > A E = D E - D A = \frac {1}{2} (D B + D C) - D A \quad \begin{array}{c c c} \square & \square & \square \\ \square & \square & \square \\ B C = D C - D B \end{array}
> > $$
> >
> > 所以 $AE \cdot BC = \left( \frac{1}{2} DB + \frac{1}{2} DC - DA \right) \cdot (DC - DB)$
> >
> > $$
> > = \frac {1}{2} D B \cdot D C - \frac {1}{2} D B \cdot D B + \frac {1}{2} D C \cdot D C - \frac {1}{2} D C \cdot D B - D A \cdot D C + D A \cdot D B = 0 - 2 + 2 - 0 - 0 + 0 = 0,
> > $$
> >
> > 所以 $AE \perp BC$ ，即 $AE \perp BC$ 。
> >
> > $(2) \text{由 } (1) \text{ 知，} AE = \frac{1}{2} DB + \frac{1}{2} DC - DA$
> >
> > $$
> > A E \cdot D C = \left(\frac {1}{2} D B + \frac {1}{2} D C - D A\right) \cdot D C = \frac {1}{2} D B \cdot D C + \frac {1}{2} D C \cdot D C - D A \cdot D C = 0 + 2 - 0 = 2
> > $$
> >
> > $$
> > \text { 又 } \mid A E \mid = \sqrt {(\sqrt {2}) ^ {2} + 2 ^ {2}} = \sqrt {6}
> > $$
> >
> > 所以 $\cos\langle AE, DC\rangle = \frac{AE \cdot DC}{|AE||DC|} = \frac{2}{\sqrt{6} \times 2} = \frac{\sqrt{6}}{6}$
> >
> > 即直线 AE 与 DC 所成角的余弦值为 $\frac{\sqrt{6}}{6}$ .
