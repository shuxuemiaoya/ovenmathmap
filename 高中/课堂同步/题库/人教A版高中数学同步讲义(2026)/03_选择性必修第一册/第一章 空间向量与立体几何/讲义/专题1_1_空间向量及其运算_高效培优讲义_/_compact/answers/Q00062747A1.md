> [!faq]- 《专题1_1_空间向量及其运算_高效培优讲义_》官方解析
>
> > [!success]- **【答案】** C
>
> > [!note]- **【分析】**
> > 根据空间向量的加减运算法则和相反向量的概念判断即可
>
> > [!note]- **【解析】**
> > $OA = -OC_{1}, OB = -OD_{1}, OC = -OA_{1}, OD = -OB_{1}$
> >
> > 所以 $OA - OD = -OC_{1} + OB_{1} = OB_{1} - OC_{1}$ ，故 A 错误；
> >
> > $OB - OC = -OD_{1} + OA_{1} = OA_{1} - OD_{1}$ ，故B错误；
> >
> > $OA + OB + OC + OD = -OC_1 - OD_1 - OA_1 - OB_1 = -\left(OA_1 + OB_1 + OC_1 + OD_1\right)$ ，故C正确；
> >
> > $\overline{OA}_{1}-\overline{OA}=-\overline{OC}+\overline{OC}_{1}=\overline{OC}_{1}-\overline{OC}$ ，故D错误·
> >
> > 故选 **C**
