> [!faq]- 《专题1.3 空间向量及其运算的坐标表示（高效培优讲义）》官方解析
>
> > [!success]- **【答案】** 2 $\sqrt{21} / 21^{\frac{1}{2}}$
>
> > [!note]- **【分析】**
> > 利用向量数量积的坐标运算即可求 x；利用向量坐标的加法和数乘运算计算 $2a + b$ 的坐标，即可求
> >
> > 得 x ，再计算 $a + b$ 的坐标，最后利用求模公式即可·
>
> > [!note]- **【解析】**
> > 若 $a \perp b$ ，则 $a \cdot b = -2 + x = 0$ ，解得 $x = 2$ ；
> >
> > 因 $a = (-2,0,1), b = (1,2,x)$ ，则 $2a + b = (-4,0,2) + (1,2,x) = (-3,2,2 + x)$ ，
> >
> > 则 $2a + b = (-3, 2, 2 + x) = (-3, 2, 5)$ ，则 $2 + x = 5$ ，解得 $x = 3$ ，则 $b = (1, 2, 3)$
> >
> > 所以 $a + b = (-1,2,4)$ ，于是 $\left|\vec{a} +b\right| = \sqrt{(-1)^2 + 2^2 + 4^2} = \sqrt{21}$
> >
> > 故答案为：2； $\sqrt{21}$
