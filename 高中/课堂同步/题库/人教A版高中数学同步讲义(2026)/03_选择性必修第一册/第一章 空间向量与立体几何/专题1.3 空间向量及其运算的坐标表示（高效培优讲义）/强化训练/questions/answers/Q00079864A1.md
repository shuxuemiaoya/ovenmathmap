> [!faq]- 《专题1.3 空间向量及其运算的坐标表示（高效培优讲义）》官方解析
>
> > [!success]- **【答案】** A. -18 B. 18 C. 20 D. -20
>
> > [!note]- **【分析】**
> > 根据已知由空间向量的坐标运算求得 $\left(2a + b\right)\cdot c = -10$ ，根据数量积的运算律结合 $a\cdot c = 5$ ，即可
> >
> > 得 $b\cdot c$ 的值.
>
> > [!note]- **【解析】**
> > 由已知， $\left(2a + b\right)\cdot c = 0 + 10 - 20 = -10$
> >
> > 所以 $\left(2a + b\right)\cdot c = 2a\cdot c + b\cdot c = -10$
> >
> > 又 $a \cdot c = 5$ ，所以 $b \cdot c = -20$ .
> >
> > 故选 **D**.
