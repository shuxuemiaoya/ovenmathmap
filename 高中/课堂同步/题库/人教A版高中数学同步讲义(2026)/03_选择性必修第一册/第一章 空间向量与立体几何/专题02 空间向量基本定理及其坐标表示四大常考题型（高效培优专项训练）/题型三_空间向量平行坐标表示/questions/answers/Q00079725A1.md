> [!faq]- 《专题02 空间向量基本定理及其坐标表示四大常考题型（高效培优专项训练）》官方解析
>
> > [!success]- **【答案】** (1) $k=\frac{7}{5}$ (2) $c=(2,1,-2)$ 或 $c=(-2,-1,2)$
>
> > [!note]- **【分析】**
> > （1）求出向量 $a$ 、 $b$ 的坐标，进而求出向量 $a - kb$ 的坐标，由题意可得出 $\left(a - kb\right)\cdot b = 0$ ，结合空
> >
> > 间向量数量积的坐标运算可得出关于 $k$ 的等式，解之即可；
> >
> > (2) 设 $c = \lambda BC$ ，其中 $\lambda \in R$ ，求出 $\left|BC\right|$ 的值，利用向量模的性质求出 $\lambda$ 的值，即可得出向量 c 的坐标.
>
> > [!note]- **【解析】**
> > （1）由题意可得 $a = AB = (-1, -1, 5)$ ， $b = AC = (1, 0, 3)$
> >
> > 所以， $a - kb = (-1, - 1,5) - (k,0,3k) = (-1 - k, - 1,5 - 3k)$
> >
> > 因为向量 $a - kb$ 与 $b$ 互相垂直，则 $(a - kb) \cdot b = -1 - k + 3(5 - 3k) = 14 - 10k = 0$ ，解得 $k = \frac{7}{5}$ .
> >
> > (2) 由题意可得 $\overline{BC} = (2, 1, -2)$ ，则 $\left|\overline{BC}\right| = \sqrt{2^{2} + 1^{2} + (-2)^{2}} = 3$
> >
> > 因为 $c$ 与 $\overline{BC}$ 共线，设 $c = \lambda \overline{BC}$ ，其中 $\lambda \in \mathbb{R}$ ，则 $\left|c\right| = \left|\lambda \overline{BC}\right| = \left|\lambda\right| \cdot \left|\overline{BC}\right| = 3\left|\lambda\right| = 3$ ，解得 $\lambda = \pm 1$ ，
> >
> > 当 $\lambda=1$ 时， $c=\overline{BC}=(2,1,-2)$ ；当 $\lambda=-1$ 时， $c=-\overline{BC}=(-2,-1,2)$ .
> >
> > 综上所述， $c=(2,1,-2)$ 或 $c=(-2,-1,2)$ .

> > 29. 知向量 $a = (1, 1, 0)$ , $b = (-1, 0, 2)$
> >
> > (1)若 $\left(a + kb\right) / / (2a + b)$ ，求实数 $k$ ；
> >
> > (2)若向量 $a + kb$ 与 $2a + b$ 所成角为锐角，求实数 $k$ 的范围.
> >
> > 【答案】(1) $k = \frac{1}{2}$
> >
> > (2) $k > -1$ 且 $k \neq \frac{1}{2}$
> >
> > 【分析】（1）先求出 $a + kb = (1 - k, 1, 2k)$ ， $2a + b = (1, 2, 2)$ ，根据向量共线得到方程，求出 $k = \frac{1}{2}$ ；
> >
> > (2) 由题意得到 $\left(a + kb\right)\cdot \left(2a + b\right) > 0$ ，且 $a + kb$ 与 $2a + b$ 不同向共线，从而得到不等式，求出答案：
> >
> > 【详解】（1）因为 $a = (1,1,0)$ ， $b = (-1,0,2)$
> >
> > 所以 $a + kb = (1 - k, 1, 2k)$ ， $2a + b = (1, 2, 2)$
> >
> > 因为 $\left(a + kb\right) / / \left(2a + b\right)$ ，所以 $\frac{1 - k}{1} = \frac{1}{2} = \frac{2k}{2}$ ，解得： $k = \frac{1}{2}$ ；
> >
> > (2) 因为向量 $a + kb$ 与 $2a + b$ 所成角为锐角，
> >
> > 所以 $(a+kb)\cdot(2a+b)>0$ ，且 $a+kb$ 与 $2a+b$ 不同向共线，
> >
> > 由（1）知， $a + kb = (1 - k,1,2k)$ ， $2a + b = (1,2,2)$
> >
> > 故 $\left\{\begin{aligned}1-k+2+4k&>0\\ k&\neq\frac{1}{2}\end{aligned}\right.$
> >
> > 解得 $k > -1$ 且 $k \neq \frac{1}{2}$ ，即 $k$ 的取值范围为 $k > -1$ 且 $k \neq \frac{1}{2}$ .
