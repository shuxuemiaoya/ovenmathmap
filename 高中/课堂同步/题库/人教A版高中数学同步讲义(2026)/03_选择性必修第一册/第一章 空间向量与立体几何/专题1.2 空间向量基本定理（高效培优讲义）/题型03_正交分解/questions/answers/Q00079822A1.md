> [!faq]- 《专题1.2 空间向量基本定理（高效培优讲义）》官方解析
>
> > [!success]- **【答案】** BCD
>
> > [!note]- **【分析】**
> > 将向量想象为正方体三条相邻的棱可判断 $^{A}$ ；根据基底的性质判断 $^{B}$ ；由纵坐标都为 $^{0}$ 的向量都与平
> >
> > 面 xOz 平行判断 C；假设 $c, a + b, a - b$ 共面推得 a, b, c 也共面判断 D.
>
> > [!note]- **【解析】**
> > A：根据题设，以正方体三条相邻的棱为例，易知 $a / / c$ 不成立，错；
> >
> > B：根据基底的性质，a,b,c都是非零向量，对；
> >
> > C：纵坐标都为 $0$ 的向量都与平面 $xOz$ 平行或在其内，即它们都共面，对；
> >
> > D：若 $c, a + b, a - b$ 共面，则 $c = \lambda(a + b) + \mu(a - b) = (\lambda + \mu)a + (\lambda - \mu)b$
> >
> > 所以 $a, b, c$ 也共面，与题设矛盾，故 $\{c, a + b, a - b\}$ 也是空间的一个基底，对
> >
> > 故选 **BCD**
