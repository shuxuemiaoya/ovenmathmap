> [!faq]- 《专题1.4 空间向量的应用（高效培优讲义）》官方解析
>
> > [!success]- **【答案】** BCD
>
> > [!note]- **【分析】**
> > 选项A，求平面ABC法向量n，验证 $AD \cdot n$ 是否为0判断四点是否共面即可；选项B，求AB和CD方向向量，假设共面列方程组，根据有无解判断是否共面即可；选项C，设 $AF = \lambda AB$ 得F坐标表达式，利用和共线列方程求 $\lambda$ 确定F坐标即可；选项D，由EF和EG共线求出，根据 $CG = \mu CD$ 确定G坐标
> >
> > 即可·
>
> > [!note]- **【解析】**
> > 选项A， $AB = (1,2,3) - (1,1,1) = (0,1,2)$
> >
> > $$
> > \stackrel {\mathrm{uuu}} {A C} = (1, 0, 1) - (1, 1, 1) = (0, - 1, 0) \quad \stackrel {\mathrm{uuu}} {A D} = (2, 1, 1) - (1, 1, 1) = (1, 0, 0)
> > $$
> >
> > 设平面 ABC 的法向量 $n = (x, y, z)$ ，则 $\left\{\begin{aligned}n \cdot AB & = y + 2z = 0 \\ \rightarrow & \text{回回} \\ n \cdot AC & = -y = 0\end{aligned}\right.$
> >
> > 解得 y = 0 ， z = 0 ， x 为不为 0 的实数，
> >
> > 不妨取 $n = (1,0,0)$ ，因为 $AD\cdot n = (1,0,0)\cdot (1,0,0) = 1\neq 0$
> >
> > 所以 A, B, C, D 四点不共面，选项 A 错误；
> >
> > 选项 B，直线 AB 的方向向量 $\overline{AB} = (0,1,2)$
> >
> > 直线 $CD$ 的方向向量 $\overline{CD} = (2,1,1) - (1,0,1) = (1,1,0)$
> >
> > 假设直线 $AB$ 与直线 $CD$ 共面，则存在实数 $m, n$ ，使得 $CD = mAB + nAC$
> >
> > 即 $(1,1,0) = m(0,1,2) + n(0, - 1,0) = (0,m - n,2m)$ ，此方程无解，
> >
> > 所以直线 AB 与直线 CD 是异面直线，选项 B 正确；
> >
> > 选项 C，因为 F 在直线 AB 上，设 $\overline{AF} = \lambda \overline{AB}$ ， $\overline{AB} = (0,1,2)$ ， $A(1,1,1)$
> >
> > 则 F 点坐标为 $(1,1+\lambda,1+2\lambda)$ ，又有 $E(2,1,0)$
> >
> > 则 $EF = (1, 1 + \lambda, 1 + 2\lambda) - (2, 1, 0) = (-1, \lambda, 1 + 2\lambda)$
> >
> > 因为 $G$ 在直线 $CD$ 上，设 $\overline{CG} = \mu \overline{CD}$ ， $\overline{CD} = (1,1,0)$ ， $C(1,0,1)$
> >
> > 则 $G$ 点坐标为 $\left(1 + \mu ,\mu ,1\right)$ ，则 $EG = (1 + \mu ,\mu ,1) - (2,1,0) = (\mu -1,\mu -1,1)$
> >
> > 因为 $\overline{EF}$ 和 $\overline{EG}$ 共线，则 $\frac{-1}{\mu-1} = \frac{\lambda}{\mu-1} = \frac{1 + 2\lambda}{1}$ ，解得 $\lambda = -1$ ，
> >
> > 此时点 $F$ 坐标为 $(1,1 - 1,1 - 2) = (1,0, - 1)$ ，选项C正确；
> >
> > 选项D， $\frac{-1}{\mu - 1} = \frac{\lambda}{\mu - 1} = \frac{1 + 2\lambda}{1}$ ，解得 $\lambda = -1$ ， $\mu = 2$
> >
> > 此时点 G 坐标为 $(1+2,2,1)=(3,2,1)$ ，选项 D 正确；
> >
> > 故选：BCD.
> >
> > ## 方法技巧
> >
> > (1) 线线平行设直线 $l_{1}, l_{2}$ 的方向向量分别是 $a, b$ ，则要证明 $l_{1} / / l_{2}$ ，只需证明 $a / / b$ ，即 $a = kb (k \in \mathbf{R})$
> >
> > (2) 线面平行
> >
> > 线面平行的判定方法一般有三种：
> > - **①**：设直线 $l$ 的方向向量是 $a$ ，平面 $\alpha$ 的向量是 $u$ ，则要证明 $l / / \alpha$ ，只需证明 $a \perp u$ ，即 $a \cdot u = 0$ ：
> > - **②**：根据线面平行的判定定理：要证明一条直线和一个平面平行，可以在平面内找一个向量与已知直线的方向
> >
> > 向量是共线向量.
> > - **③**：根据共面向量定理可知，要证明一条直线和一个平面平行，只要证明这条直线的方向向量能够用平面内两
> >
> > 个不共线向量线性表示即可.
> >
> > (3) 面面平行
> > - **①**：由面面平行的判定定理，要证明面面平行，只要转化为相应的线面平行、线线平行即可。
> > - **②**：若能求出平面 $\alpha$ ， $\beta$ 的法向量 $u, v$ ，则要证明 $\alpha // \beta$ ，只需证明 $u // v$ 。
