> [!faq]- 《专题1.1 空间向量及其运算（高效培优讲义）》官方解析
>
> > [!success]- **【答案】** B
>
> > [!note]- **【分析】**
> > 根据空间向量线性运算法则得到 $\frac{uur}{PM} = \frac{4}{7} \frac{uur}{PA} + \frac{t}{14} \frac{uur}{PB} + \frac{5}{14} \frac{uur}{PC}$ ，再由空间共面定理的推论得到方程，
> >
> > 解得即可·
>
> > [!note]- **【解析】**
> > 因为 $9PM = 8PA + tPB + 5MC = 8PA + tPB + 5\left(PC - PM\right)$
> >
> > 所以 $\frac{\mathrm{uuu}}{14PM} = 8PA + tPB + 5PC$ ，即 $PM = \frac{4}{7} PA + \frac{t}{14} PB + \frac{5}{14} PC$
> >
> > 又点 M 是平面 ABC 内一点，所以 $\frac{4}{7} + \frac{t}{14} + \frac{5}{14} = 1$ ，解得 t = 1。故选：B
> >
> > ## 方法技巧
> >
> > ## 1. 解决向量共面的策略
> >
> > (1)若已知点 $P$ 在平面 $ABC$ 内，则有 $\mathrm{AP} = x\mathrm{AB} + y\mathrm{AC}$ 或 $\mathrm{OP} = x\mathrm{OA} + y\mathrm{OB} + z\mathrm{OC}(x + y + z = 1)$ ，然后利用指定向量表示出已知向量，用待定系数法求出参数。
> >
> > (2)证明三个向量共面(或四点共面)，需利用共面向量定理，证明过程中要灵活进行向量的分解与合成，将其中一个向量用另外两个向量来表示。
> >
> > 2. 证明空间四点 $P, M, A, B$ 共面的等价结论
> >
> > (1) $\mathrm{MP} = x\mathrm{MA} + y\mathrm{MB}$ ; (2) 对空间任一点 $O$ , $\mathrm{OP} = \mathrm{OM} + x\mathrm{MA} + y\mathrm{MB}$ ;
> >
> > (3)对空间任一点 O，OP = xOA + yOB + zOM $(x + y + z = 1)$ ；(4)PM∥AB（或PA∥MB或PB∥AM）.
