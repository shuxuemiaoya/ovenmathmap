> [!faq]- 《专题1.1 空间向量及其运算（高效培优讲义）》官方解析
>
> > [!success]- **【答案】** D
>
> > [!note]- **【解析】**
> > 如果 $a = (2,2,2), b = (-2, -2, -2)$ ，则 $\frac{a}{|a|} = (1, 1, 1), \frac{b}{|b|} = (-1, -1, -1)$ ， $\frac{a}{|a|} = \frac{b}{|b|}$ 不成立，故A错误，如果 $a = (2, 2, 0), b = (1, 1, 0)$ ，则 $a = 2b$ ，故 $a, b$ 平行，但 $\frac{a_1}{b_1} = \frac{a_2}{b_2} = \frac{a_3}{b_3}$ 不成立，因为 $\frac{a_3}{b_3}$ 无意义，故B错误。对于C， $a + kb = 0$ 不成立，因为 $a + kb$ 是向量，而0是实数，故C错误。
> >
> > 对于 $^{D}$ ，由向量共线定理可得：
> >
> > 向量 $a = (a_{1}, a_{2}, a_{3})$ 与非零向量 $b = (b_{1}, b_{2}, b_{3})$ 平行等价于存在实数 $k$ ，使 $a = kb$
> >
> > 故 $^{D}$ 成立，
> >
> > 故选 **D**.
