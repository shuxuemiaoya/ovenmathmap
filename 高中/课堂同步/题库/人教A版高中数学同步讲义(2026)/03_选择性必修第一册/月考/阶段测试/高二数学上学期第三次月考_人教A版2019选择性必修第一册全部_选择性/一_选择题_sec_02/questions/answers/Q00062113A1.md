> [!faq]- 《高二数学上学期第三次月考_人教A版2019选择性必修第一册全部_选择性》官方解析
>
> > [!success]- **【答案】** AD
>
> > [!note]- **【解析】**
> > 对于 A：由 $mx - y - 2m + 3 = 0$ 有 $m(x - 2) - y + 3 = 0$ ，令 x - 2 = 0 有 $-y + 3 = 0$ ，
> > 所以 $\left\{\begin{aligned}x=2\\ y=3\end{aligned}\right.$ ，所以直线 l 过定点 $(2,3)$ ，故 A 正确；
> > 对于 B：点 $(2,3)$ 在圆 C 内，圆 C 的圆心为 $C(4,5)$ ，当 $|AB|$ 取得最小值时，直线 l 与过点 $C(4,5)$ 和 $(2,3)$ 的
> >
> > 直线垂直，
> >
> > 所以 $m \cdot \frac{5 - 3}{4 - 2} = -1$ ，解得 $m = -1$ ，故B错误；
> >
> > 对于 C：当 $\angle ACB$ 最小时，此时 $\left|AB\right|$ 最小，当 $\left|AB\right|$ 最小时，直线 l 与过点 $C(4,5)$ 和 $(2,3)$ 的直线垂直，
> > 则 $\frac{\left|AB\right|}{2}=\sqrt{12-\left(4-2\right)^{2}-\left(5-3\right)^{2}}=2\Rightarrow\left|AB\right|=4$ ，由余弦定理有 $\cos\angle ACB=\frac{BC^{2}+AC^{2}-AB^{2}}{2BC\cdot AC}=\frac{1}{3}$ ，故 C 错误；
> >
> > 对于 D： $AB \cdot AC = |AB| |AC| \cos AB, AC = \frac{|AB|^2}{2} \leq \frac{(4\sqrt{3})^2}{2} = 24$ ，即的最大值为 24，故 D 正确，
> >
> > 故选 **AD**.
