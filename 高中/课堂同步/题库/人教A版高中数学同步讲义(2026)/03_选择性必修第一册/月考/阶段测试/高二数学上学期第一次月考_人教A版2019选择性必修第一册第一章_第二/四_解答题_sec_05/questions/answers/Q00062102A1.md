> [!faq]- 《高二数学上学期第一次月考_人教A版2019选择性必修第一册第一章_第二》官方解析
>
> > [!success]- **【答案】** (1) $c=(-2,-1,2)$ 或 $c=(2,1,-2)$ (2) $-\frac{\sqrt{10}}{10}$ (3) $k = 2$ 或 $k = -\frac{5}{2}$
>
> > [!note]- **【解析】**
> > （1）由题可知， $BC=(-2,-1,2)$
> >
> > 由 $c / / BC$ ，得 $c = kBC$ ，设 $c = (-2k, - k, 2k)$
> >
> > 因为 $\left| c \right| = 3$ ，
> >
> > 所以 $(-2k)^{2} + (-k)^{2} + (2k)^{2} = 3^{2}$ ，解得 $k = \pm 1$
> >
> > 所以 $c = (-2, -1, 2)$ 或 $c = (2, 1, -2)$
> >
> > (2) 因为 $A(-2,0,2)$ 、 $B(-1,1,2)$ 、 $C(-3,0,4)$ ， $a = AB$ ， $b = AC$ ，
> >
> > 所以 $a = (1,1,0)$ ， $b = (-1,0,2)$
> >
> > 则 $\cos < a, b > = \frac{a \cdot b}{|a| \cdot |b|} = \frac{-1}{\sqrt{2} \times \sqrt{5}} = -\frac{\sqrt{10}}{10}$ .
> >
> > (3) 因为 $ka + b = (k - 1, k, 2)$ ， $ka - 2b = (k + 2, k, -4)$
> >
> > 又 $ka + b$ 与 $ka - 2b$ 垂直，
> >
> > 所以 $\left(ka + b\right)\cdot \left(ka - 2b\right) = (k - 1)(k + 2) + k^2 -8 = 0$
> >
> > 解得 $k = -\frac{5}{2}$ 或 $k = 2$
