> [!faq]- 《专题2.3 直线的交点坐标与距离公式（高效培优讲义）》官方解析
>
> > [!success]- **【答案】** $\frac{9\sqrt{13}}{13}/\frac{9}{13}\sqrt{13}$
>
> > [!note]- **【分析】**
> > 根据给定条件，利用点到直线的距离公式，结合不等式的性质求出最小值·
>
> > [!note]- **【解析】**
> > 点 $A(-1,1), B(2,1), C(0,4)$ 到直线 $ax + by + c = 0$ 的距离分别为 $d_{1} = \frac{|-a + b + c|}{\sqrt{a^{2} + b^{2}}}$
> >
> > $d_{2}=\frac{|2a+b+c|}{\sqrt{a^{2}+b^{2}}},d_{3}=\frac{|4b+c|}{\sqrt{a^{2}+b^{2}}}$ ，则距离之和为 $d=d_{1}+d_{2}+d_{3}$ ，
> >
> > $d \quad d_{1}$ ，当且仅当 $d_{2}=d_{3}=0$ ，即 $\left\{\begin{aligned}&2a+b+c=0\\ &4b+c=0\end{aligned}\right.$ 时取等号，此时 $\left\{\begin{aligned}&a=\frac{3}{2}b\\ &c=-4b\end{aligned}\right.$ ， $d_{1}=\frac{9}{\sqrt{13}}$ ；
> >
> > $d\quad d_{2}$ ，当且仅当 $d_{1} = d_{3} = 0$ ，即 $\left\{ \begin{array}{l} - a + b + c = 0 \\ 4b + c = 0 \end{array} \right.$ 时取等号，此时 $\left\{ \begin{array}{l}a = -3b\\ c = -4b \end{array} \right.$ ， $d_{2} = \frac{9}{\sqrt{10}}$
> >
> > $d\quad d_{3}$ ，当且仅当 $d_{1} = d_{2} = 0$ ，即 $\left\{ \begin{array}{l} - a + b + c = 0\\ 2a + b + c = 0 \end{array} \right.$ 时取等号，此时 $\left\{ \begin{array}{ll}a = 0\\ c = -b \end{array} \right.,d_3 = 3$
> >
> > 而 $d_{1} < d_{2} < d_{3}$ ，因此 $d_{\mathrm{min}} = d_1 = \frac{9\sqrt{13}}{13}$ ，所以所求最小值为 $\frac{9\sqrt{13}}{13}$
> >
> > 故答案为： $\frac{9\sqrt{13}}{13}$
> >
> > ## 方法技巧
> >
> > 点 $P(x_0,y_0)$ 到直线 $Ax + By + C = 0$ 的距离为 $d = \frac{|Ax_0 + By_0 + C|}{\sqrt{A^2 + B^2}}$
