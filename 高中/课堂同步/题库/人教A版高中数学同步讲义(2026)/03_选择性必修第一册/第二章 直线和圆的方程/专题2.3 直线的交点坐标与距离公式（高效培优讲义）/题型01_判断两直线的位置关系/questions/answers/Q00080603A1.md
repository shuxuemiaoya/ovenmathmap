> [!faq]- 《专题2.3 直线的交点坐标与距离公式（高效培优讲义）》官方解析
>
> > [!success]- **【答案】** BD
>
> > [!note]- **【分析】**
> > 举出反例判断 $^{A}$ ；联立 $\left\{\begin{aligned}A_{1}x+B_{1}y+C_{1}&=0\\ A_{2}x+B_{2}y+C_{2}&=0\end{aligned}\right.$ ，结合 $A_{1}B_{2}-A_{2}B_{1}$ 是否为 $^{0}$ ，讨论方程组解的情况，判断
> >
> > 直线的位置关系，判断 B,C ，讨论 $B_{1}B_{2}$ 是否为 0 ，结合 $A_{1}A_{2} + B_{1}B_{2} = 0$ 可判断两直线是否垂直，判断 D.
>
> > [!note]- **【解析】**
> > 对于 A， $C_{1} \neq C_{2}$ 时，若 $A_{1}A_{2} \neq 0, B_{1} = B_{2} = 0$ ，且 $\frac{C_{1}}{A_{1}} = \frac{C_{2}}{A_{2}}$ 时，
> >
> > 两直线 $l_{1}$ ： $x = -\frac{C_{1}}{A_{1}}$ ， $l_{2}$ ： $x = -\frac{C_{2}}{A_{2}}$ 重合，A 错误；
> >
> > 对于 $^{B}$ ，联立 $\left\{\begin{aligned}A_{1}x+B_{1}y+C_{1}&=0\\ A_{2}x+B_{2}y+C_{2}&=0\end{aligned}\right.$ ，可得 $(A_{1}B_{2}-A_{2}B_{1})x=B_{1}C_{2}-B_{2}C_{1}$
> >
> > 当 $A_{1}B_{2} - A_{2}B_{1}\neq 0$ 时， $x = \frac{B_1C_2 - B_2C_1}{A_1B_2 - A_2B_1}$ ，此时方程组有唯一一组解，
> >
> > 故直线 $l_{1}$ 与 $l_{2}$ 相交，B正确；
> >
> > 对于 $^{C}$ ， $A_{1}B_{2}-A_{2}B_{1}=0$ 时，若 $B_{1}C_{2}-B_{2}C_{1}\neq0$ ，则 $\left\{\begin{aligned}A_{1}x+B_{1}y+C_{1}&=0\\ A_{2}x+B_{2}y+C_{2}&=0\end{aligned}\right.$ 无解，
> >
> > 此时 $l_{1}//l_{2}$ ;
> >
> > 若 $B_{1}C_{2} - B_{2}C_{1} = 0$ ，则 $\left\{ \begin{array}{l}A_1x + B_1y + C_1 = 0\\ A_2x + B_2y + C_2 = 0 \end{array} \right.$ 有无数多组解，
> >
> > 此时 $l_{1}, l_{2}$ 重合，故C错误；
> >
> > 对于D，若 $B_{1}B_{2}\neq 0$ ，则由 $A_{1}A_{2} + B_{1}B_{2} = 0$ 可得 $(- \frac{A_1}{B_1})\cdot (-\frac{A_2}{B_2}) = -1$
> >
> > 即两直线斜率之积等于-1，故 $l_{1}\perp l_{2}$ ；
> >
> > 若 $B_{1} = 0(B_{2} = 0)$ ，则可得 $A_{2} = 0(A_{1} = 0)$ ，此时满足 $A_{1}A_{2} + B_{1}B_{2} = 0$
> >
> > 直线 $l_{1}$ ： $A_{1}x + C_{1} = 0(B_{1}y + C_{1} = 0)$ ， $l_{2}$ ： $B_{2}y + C_{2} = 0(A_{2}x + C_{2} = 0)$ ，
> >
> > 此时 $l_{1}\perp l_{2}$ ，
> >
> > 故当 $A_{1}A_{2} + B_{1}B_{2} = 0$ 时， $l_{1} \perp l_{2}$ ，D 正确，
> >
> > 故选 **BD**
