> [!faq]- 《专题2.5 直线与圆、圆与圆的位置关系（高效培优讲义）》官方解析
>
> > [!success]- **【答案】** ABD
>
> > [!note]- **【解析】**
> > 因为 $\odot C_{1}$ : $x^{2} + y^{2} - 2x + 10y - 24 = 0 \Rightarrow (x - 1)^{2} + (y + 5)^{2} = 50$ ，所以 $C_{1}(1, -5)$ ， $r_{1} = 5\sqrt{2}$
> >
> > $$
> > \odot C _ {2}: x ^ {2} + y ^ {2} + 2 x + 2 y - 8 = 0 \Rightarrow (x + 1) ^ {2} + (y + 1) ^ {2} = 1 0 \text {, 所以} C _ {2} (- 1, - 1), r _ {2} = \sqrt {1 0}
> > $$
> >
> > 所以 $\left|C_{1}C_{2}\right|=\sqrt{4+16}=2\sqrt{5}$
> >
> > 对 A 选项：因为 $5\sqrt{2}-\sqrt{10}<2\sqrt{5}<5\sqrt{2}+\sqrt{10}$ ，即 $r_{1}-r_{2}<\left|C_{1}C_{2}\right|<r_{1}+r_{2}$ ，所以两圆相交，有两个公共点，故 A
> >
> > 正确；
> >
> > 对 B 选项：由 $\left(x^{2}+y^{2}+2x+2y-8\right)-\left(x^{2}+y^{2}-2x+10y-24\right)=4x-8y+16$
> >
> > 所以两圆的公共弦所在直线方程为 $4x - 8y + 16 = 0$ 即 $x - 2y + 4 = 0$ ，故B正确；
> >
> > 对 $C$ 选项： $C_2$ 到直线 $x - 2y + 4 = 0$ 的距离为： $\frac{|-1 + 2 + 4|}{\sqrt{1^2 + (-2)^2}} = \sqrt{5}$ ，所以两圆的公共弦长度为：
> >
> > $2\sqrt{\left(\sqrt{10}\right)^{2}-\left(\sqrt{5}\right)^{2}}=2\sqrt{5}$ ，故C错误；
> >
> > 对 D 选项：设所求圆的方程为： $\left(x^{2}+y^{2}+2x+2y-8\right)+\lambda\left(x^{2}+y^{2}-2x+10y-24\right)=0$ ( $\lambda\neq-1$ )
> >
> > 整理得： $(1 + \lambda)x^{2} + (1 + \lambda)y^{2} + (2 - 2\lambda)x + (2 + 10\lambda)y - (8 + 24\lambda) = 0.$
> >
> > 因为圆心在直线 $x + y = 0$ 上，所以 $2 - 2\lambda + 2 + 10\lambda = 0 \Rightarrow \lambda = -\frac{1}{2}$ .
> >
> > 所以所求圆的方程为： $\frac{1}{2} x^2 +\frac{1}{2} y^2 +3x - 3y + 4 = 0$ 即 $x^{2} + y^{2} + 6x - 6y + 8 = 0$
> >
> > 配方得： $(x + 3)^2 +(y - 3)^2 = 10$ 故D正确
> >
> > 故选 **ABD**
