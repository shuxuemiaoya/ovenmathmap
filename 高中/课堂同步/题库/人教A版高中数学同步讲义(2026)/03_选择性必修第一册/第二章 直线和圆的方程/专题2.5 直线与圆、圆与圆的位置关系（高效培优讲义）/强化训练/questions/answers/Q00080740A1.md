> [!faq]- 《专题2.5 直线与圆、圆与圆的位置关系（高效培优讲义）》官方解析
>
> > [!success]- **【答案】** (1) $x = -1$ 或 $4x - 3y + 4 = 0$ (2) $\sqrt{74}$ (3)存在直线 l，使得向量 $\overline{OP} + \overline{OQ}$ 与 AC 共线，直线 l 的方程为 4x - 3y + 4 = 0
>
> > [!note]- **【解析】**
> > （1）（解法一）设弦 $PQ$ 的中点为M，
> > - **①**：当直线 l 的斜率不存在时，易知 x = -1 符合题意。
> > - **②**：当直线 l 的斜率存在时，设直线 l 的方程为 $y = k(x + 1)$ ，即 $kx - y + k = 0$
> >
> > $\because |PQ| = 2\sqrt{3}$ ， $\therefore |CM| = \sqrt{4 - 3} = 1$ ，则由 $|CM| = \frac{|-k + 3|}{\sqrt{k^2 + 1}} = 1$ ，解得 $k = \frac{4}{3}$
> >
> > 此时直线 $l$ 的方程为 $4x - 3y + 4 = 0$
> >
> > 故直线 l 的方程为 x = -1 或 $4x - 3y + 4 = 0$ ；
> >
> > （解法二）易知直线 l 的斜率不为零，设直线 l 方程为 x = my - 1
> >
> > $\because |PQ| = 2\sqrt{3}$ ， $\therefore |CM| = \sqrt{4 - 3} = 1$ ，则由 $\frac{|0 - 3m + 1|}{\sqrt{1^2 + m^2}} = 1$ ，解得 $m = 0$ 或 $m = \frac{3}{4}$
> >
> > 故直线 l 的方程为 x = -1 或 $4x - 3y + 4 = 0$ ；
> >
> > (2) (解法一) 由于 TG、TH 为圆 C 的两条切线，
> >
> > 所以 $S_{TGCH} = 2S_{\triangle TGC} = 2 \cdot \frac{1}{2} |TG| \cdot |CG| = 2 |TG|$
> >
> > 又 $|TG| = \sqrt{|CT|^2 - 2^2}$ ，而 $|CT|$ 的最小值为点 $C$ 到直线 $m$ 的距离 $d$ ，
> >
> > $d=\frac{\left|3\times3+6\right|}{\sqrt{10}}=\frac{15}{\sqrt{10}}$ 所以 $\left|TG\right|_{\min}=\frac{\sqrt{74}}{2}$
> >
> > 故四边形TGCH 面积的最小值为 $\sqrt{74}$ ；
> >
> > (解法二) (前两步同解法一)
> >
> > 设点 $T$ 的坐标为 $(x,y)$ ，则 $|TG| = \sqrt{x^2 + (y - 3)^2 - 4}$
> >
> > $$
> > \mid T G \mid = \sqrt {(3 y + 6) ^ {2} + (y - 3) ^ {2} - 4} = \sqrt {1 0 (y + \frac {3}{2}) ^ {2} + \frac {3 7}{2}}
> > $$
> >
> > 所以当 $y = -\frac{3}{2}$ 时， $|TG|_{\min} = \frac{\sqrt{74}}{2}$
> >
> > 故四边形TGCH面积的最小值为 $\sqrt{74}$ ；
> >
> > （3）易知直线 $l$ 的斜率不为零，设直线 $l$ 的方程为 $x = my - 1$ ， $P(x_1, y_1)$ 、 $Q(x_2, y_2)$
> >
> > 由 $\left\{\begin{aligned}x&=my-1\\ x^{2}&+(y-3)^{2}=4\end{aligned}\right.$ ，可得 $\left(m^{2}+1\right)y^{2}-\left(2m+6\right)y+6=0$ ，
> >
> > 可得 $\Delta = (2m + 6)^2 - 4(m^2 + 1) \times 6$
> >
> > 所以 $y_{1} + y_{2} = \frac{2m + 6}{m^{2} + 1}$ ，所以 $x_{1} + x_{2} = m\frac{2m + 6}{m^{2} + 1} -2 = \frac{6m - 2}{m^{2} + 1}$
> >
> > 则 $OP + OQ = (x_{1} + x_{2}, y_{1} + y_{2})$ ，所以 $OP + OQ = \left(\frac{6m - 2}{m^{2} + 1}, \frac{2m + 6}{m^{2} + 1}\right)$ .
> >
> > 又 $A(-1,0)$ ， $C(0,3)$ ，所以 $\overline{AC} = (1,3)$
> >
> > 若向量 $\overline{OP} + \overline{OQ}$ 与 $\overline{AC}$ 共线，则 $\frac{2m + 6}{m^{2} + 1} = 3 \times \frac{6m - 2}{m^{2} + 1}$
> >
> > 由 $\frac{2m + 6}{m^2 + 1} = 3 \times \frac{6m - 2}{m^2 + 1}$ ，可得 $2m + 6 = 18m - 6$ ，解得 $m = \frac{12}{16} = \frac{3}{4}$ ，
> >
> > 当 $m = \frac{3}{4}$ 时， $\Delta = \left(\frac{15}{2}\right)^2 - 4 \times \frac{25}{16} \times 6 > 0$
> >
> > 所以存在直线 l，使得向量 $OP + OQ$ 与 AC 共线，
> >
> > 直线 l 的方程为 $x=\frac{3}{4}y-1$ ，即 $4x-3y+4=0$ 。
