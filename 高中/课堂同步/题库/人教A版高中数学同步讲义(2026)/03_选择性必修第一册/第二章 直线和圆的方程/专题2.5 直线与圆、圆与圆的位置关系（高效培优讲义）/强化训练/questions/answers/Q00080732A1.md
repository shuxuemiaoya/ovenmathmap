> [!faq]- 《专题2.5 直线与圆、圆与圆的位置关系（高效培优讲义）》官方解析
>
> > [!success]- **【答案】** $[-1,1]$
>
> > [!note]- **【解析】**
> > 设 $P\left(x_0,y_0\right)$ ，则 $\left|PA\right| = \sqrt{\left(x_0 - 1\right)^2 + y_0^2},PT = \sqrt{\left(x_0 + 1\right)^2 + y_0^2 - 1} = \sqrt{x_0^2 + 2x_0 + y_0^2},$
> >
> > $$
> > \because | P A | = \sqrt {3} P | T |
> > $$
> >
> > $\therefore \sqrt{\left(x_{0} - 1\right)^{2} + y_{0}^{2}} = \sqrt{3}\cdot \sqrt{x_{0}^{2} + 2x_{0} + y_{0}^{2}}$ ，整理得， $2x_0^2 +8x_0 + 2y_0^2 -1 = 0$
> >
> > 即 $\left(x_0 + 2\right)^2 +y_0^2 = \frac{9}{2},\therefore$ 点 $P$ 在圆 $(x + 2)^{2} + y^{2} = \frac{9}{2}$ 上，
> >
> > 又点 P 在直线 $l: y = k(x - 1)$ 上，
> >
> > 故直线 $y = k(x - 1)$ 与圆 $(x + 2)^{2} + y^{2} = \frac{9}{2}$ 有交点，
> >
> > 即 $\frac{|-2k - k|}{\sqrt{k^2 + 1}} \leq \frac{3}{\sqrt{2}}$ ，则 $\frac{k^2}{k^2 + 1} \leq \frac{1}{2}$ ，解得 $-1 \leq k \leq 1$ 。
> >
> > 故答案为： $\left[-1,1\right]$ .
