> [!faq]- 《第二章_直线和圆的方程_高效培优讲义_》官方解析
>
> > [!success]- **【答案】** （1）证明见解析；（2） $x+2y+3=0$
>
> > [!note]- **【解析】**
> > （1）圆 $C_1:(x - 1)^2 +(y - 3)^2 = 11$ 的圆心 $C_1(1,3)$ ，半径 $r_1 = \sqrt{11}$
> >
> > 圆 $C_2:(x - 5)^2 +(y - 6)^2 = 16$ 的圆心 $C_2(5,6)$ ，半径 $r_2 = 4$
> >
> > 则 $|C_1C_2| = \sqrt{(5 - 1)^2 + (6 - 3)^2} = 5 \in (4 - \sqrt{11}, 4 + \sqrt{11})$ ，即 $r_2 - r_1 < |C_1C_2| < r_2 + r_1$
> >
> > 所以圆 $C_{1}$ 和圆 $C_{2}$ 相交.
> >
> > $$
> > \left\{ \begin{array}{l} 2 x - y + 3 = 0 \\ x + y + 3 = 0 \end{array} \right.
> > $$
> >
> > (2) 由 $\left\lfloor x + y + 3 = 0 \right.$ ，解得 x = -2, y = -1，即点 $P(-2, -1)$ ，
> >
> > 设直线 $m$ 上任意一点 $M(x,y)$ ，则点 $M$ 关于点 $P(-2, - 1)$ 对称的点为 $N(-4 - x, - 2 - y)$
> >
> > 依题意，点 $N(-4-x,-2-y)$ 在直线 $x+2y+5=0$ 上，得 $(-4-x)+2(-2-y)+5=0$
> >
> > 化简得： $x+2y+3=0$ ，所以直线m的方程为 $x+2y+3=0$ 。
