> [!faq]- 《第二章_直线和圆的方程_高效培优讲义_》官方解析
>
> > [!success]- **【答案】** D
>
> > [!note]- **【解析】**
> > 圆 $(x+2)^{2}+(y-1)^{2}=4$ 的圆心 $(-2,1)$ ，半径r=2，
> >
> > 由直线 $ax - by + 1 = 0$ 被圆 $x^{2} + y^{2} + 4x - 2y + 1 = 0$ 截得弦长为4，得直线 $ax - by + 1 = 0$ 过圆心，
> >
> > 因此 $2a + b = 1$ ，而 a > 0, b > 0，则 $a + b < 2a + b = 1$ ，AB 错误；
> >
> > 又 $1 = 2a + b$ $2\sqrt{2ab}$ ，即 $ab \leq \frac{1}{8}$ ，当且仅当 $b = 2a = \frac{1}{2}$ 时取等号，C错误；
> >
> > 又 $\frac{a + 2b}{ab} = \frac{1}{b} +\frac{2}{a} = (\frac{1}{b} +\frac{2}{a})(2a + b) = 5 + \frac{2a}{b} +\frac{2b}{a}$ $5 + 2\sqrt{\frac{2a}{b}\cdot\frac{2b}{a}} = 9$ ，当且仅当 $a = b = \frac{1}{3}$ 时取等号，D正确.
> >
> > 故选 **D**
