> [!faq]- 《专题2_3_直线的交点坐标与距离公式_高效培优讲义_》官方解析
>
> > [!success]- **【答案】** B
>
> > [!note]- **【分析】**
> > 根据题意，分 x = 0 与 x < 0 讨论，结合条件，列出不等式，即可得到结果。
>
> > [!note]- **【解析】**
> > 当 $x = 0$ 时，由 $-a|x| = -a + x$ 可得， $-ax = -a + x$ ，当 $a \neq -1$ 时，解得 $x = \frac{a}{a + 1}$ ；当 $x < 0$ 时，由 $-a|x| = -a + x$ 可得， $ax = -a + x$ ，由 $a < 0$ 可知，方程的解是 $x = -\frac{a}{a - 1}$ ，
> >
> > 又 $y = -a|x|$ 的图象与直线 $y = -a + x (a < 0)$ 有两个不同的交点，
> >
> > 所以 $\left\{ \begin{array}{ll} \frac{a}{a + 1} & 0 \\ -\frac{a}{a - 1} < 0 \end{array} \right.$ ，其中，解得；
> >
> > 综上所述，a<-1.
> >
> > 故选 **B**
