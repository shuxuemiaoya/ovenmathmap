> [!faq]- 《专题02 直线的交点坐标与距离公式 的四大常考题型（高效培优专项训练）》官方解析
>
> > [!success]- **【答案】** $^{3}$
>
> > [!note]- **【解析】**
> > 因为 $\sqrt{m^{2}+n^{2}}$ 表示点 P 到原点 $(0,0)$ 的距离，而点 P 在直线 $3x+4y+15=0$ 上，
> >
> > 所以 $\sqrt{m^{2}+n^{2}}$ 的最小值即为原点 $(0,0)$ 到直线 $3x+4y+15=0$ 的距离， $d=\frac{|3\times0+4\times0+15|}{\sqrt{3^{2}+4^{2}}}=3$ .
> >
> > 所以 $\sqrt{m^{2}+n^{2}}$ 的最小值为 3.
> >
> > 故答案为：3·
> >
> > 22．平面上有三点 $A(-1,1), B(2,1), C(0,4)$ 到直线 $ax + by + c = 0$ （a、b 不全为 0）距离之和的最小值为 \_\_\_\_
> >
> > 【答案】 $\frac{9\sqrt{13}}{13} / \frac{9}{13}\sqrt{13}$
> >
> > 【详解】点 $A(-1,1), B(2,1), C(0,4)$ 到直线 $ax + by + c = 0$ 的距离分别为 $d_{1} = \frac{|-a + b + c|}{\sqrt{a^{2} + b^{2}}}$ ，
> >
> > $d_{2}=\frac{|2a+b+c|}{\sqrt{a^{2}+b^{2}}},d_{3}=\frac{|4b+c|}{\sqrt{a^{2}+b^{2}}}$ ，则距离之和为 $d=d_{1}+d_{2}+d_{3}$ ，
> >
> > $d\quad d_{1}$ ，当且仅当 $d_{2} = d_{3} = 0$ ，即 $\left\{ \begin{array}{l}2a + b + c = 0\\ 4b + c = 0 \end{array} \right.$ 时取等号，此时 $\left\{ \begin{array}{l}a = \frac{3}{2} b\\ c = -4b \end{array} \right.,d_1 = \frac{9}{\sqrt{13}}$
> >
> > $d$ $d_{2}$ ，当且仅当 $d_{1} = d_{3} = 0$ ，即 $\left\{ \begin{array}{l} -a + b + c = 0\\ 4b + c = 0 \end{array} \right.$ 时取等号，此时 $\left\{ \begin{array}{ll}a = -3b\\ c = -4b \end{array} \right.,d_2 = \frac{9}{\sqrt{10}}$
> >
> > $d$ $d_{3}$ ，当且仅当 $d_{1} = d_{2} = 0$ ，即 $\left\{ \begin{array}{l} - a + b + c = 0 \\ 2a + b + c = 0 \end{array} \right.$ 时取等号，此时 $\left\{ \begin{array}{l} a = 0 \\ c = -b, d_{3} = 3 \end{array} \right.$
> >
> > 而 $d_{1} < d_{2} < d_{3}$ ，因此 $d_{\min} = d_{1} = \frac{9\sqrt{13}}{13}$ ，所以所求最小值为 $\frac{9\sqrt{13}}{13}$ 。
> >
> > 故答案为： $\frac{9\sqrt{13}}{13}$
