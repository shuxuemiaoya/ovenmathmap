> [!faq]- 《第二章 直线和圆的方程（高效培优讲义）》官方解析
>
> > [!success]- **【答案】** C
>
> > [!note]- **【解析】**
> > 圆 $C_1: \left(x + \frac{1}{2}\right)^2 + (y + 2)^2 = r^2$ 关于原点的对称圆为 $C_3: \left(x - \frac{1}{2}\right)^2 + (y - 2)^2 = r^2$ 则 $\left|C_2C_3\right| = \sqrt{\left(2 - \frac{1}{2}\right)^2 + (1 - 2)^2} = \frac{\sqrt{13}}{2}$ ，
> >
> > 由已知得 $C_{3}$ 与 $C_{2}$ 无公共点，所以 $\left|C_{2}C_{3}\right|>r+1$ 或 $\left|C_{2}C_{3}\right|<\left|r-1\right|$
> >
> > 所以 $\frac{\sqrt{13}}{2} > r + 1$ 或 $\frac{\sqrt{13}}{2} < |r - 1|$ ，解得： $r < \frac{\sqrt{13}}{2} - 1$ 或 $r > \frac{\sqrt{13}}{2} + 1$
> >
> > 又因为 $r > 0$ ，所以 $r\in \left(0,\frac{\sqrt{13}}{2} -1\right)\cup \left(\frac{\sqrt{13}}{2} +1, + \infty\right)$ ，故C正确.
> >
> > 故选 **C**.
