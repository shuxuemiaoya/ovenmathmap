> [!faq]- 《第二章 直线和圆的方程（高效培优讲义）》官方解析
>
> > [!success]- **【答案】** (1) $(x-1)^{2}+(y-2)^{2}=9$ ，x=-2或 $4x+3y+5=0$ ； (2) $a = 1$ 或 $a = -5$
>
> > [!note]- **【解析】**
> > （1）由圆心 C 在直线 $x - y + 1 = 0$ 上，设圆心 $C(m, m + 1)$ ，
> >
> > 由 $\left|AC\right| = \left|BC\right|$ ，得 $\sqrt{(m - 1)^2 + (m + 2)^2} = \sqrt{(m - 4)^2 + (m - 1)^2}$ ，解得 $m = 1$
> >
> > 因此圆心 $C(1,2)$ ，半径 $r = \sqrt{(1 - 4)^2 + (2 - 2)^2} = 3$
> >
> > 所以圆 $C$ 的标准方程为 $(x - 1)^2 + (y - 2)^2 = 9$
> >
> > 当切线斜率不存在时，圆心 C 到直线 x = -2 的距离为半径 3，则直线 x = -2 是符合题意的切线；
> >
> > 当切线斜率存在时，设切线方程为 $y - 1 = k(x + 2)$ ，即 $kx - y + 1 + 2k = 0$
> >
> > $\frac{|k - 2 + 1 + 2k|}{\sqrt{k^2 + 1}} = 3$ ，解得 $k = -\frac{4}{3}$ ，直线方程为 $4x + 3y + 5 = 0$
> >
> > 所以切线方程为 x = -2 或 $4x + 3y + 5 = 0$ .
> >
> > (2) 由 (1) 知，圆 C 的圆心 $C(1,2)$ ，半径 r = 3，
> >
> > 由 $\angle MCN = 120^{\circ}$ ，得圆心 $C$ 到直线 $\sqrt{3} x + y + a - \sqrt{3} = 0$ 的距离 $d = r\cos 60^{\circ} = \frac{3}{2}$
> >
> > 则 $d = \frac{|\sqrt{3} \times 1 + 2 + a - \sqrt{3}|}{\sqrt{(\sqrt{3})^2 + 1^2}} = \frac{3}{2}$ ，即 $\frac{|a + 2|}{2} = \frac{3}{2}$ ，则 $|a + 2| = 3$ ，解得 $a = 1$ 或 $a = -5$ ，
> >
> > 所以实数 a 的值为 a = 1 或 a = -5.
