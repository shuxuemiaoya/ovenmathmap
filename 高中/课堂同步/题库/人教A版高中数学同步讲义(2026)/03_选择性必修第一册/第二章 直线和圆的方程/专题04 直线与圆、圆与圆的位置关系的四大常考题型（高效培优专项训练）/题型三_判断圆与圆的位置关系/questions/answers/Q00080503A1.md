> [!faq]- 《专题04 直线与圆、圆与圆的位置关系的四大常考题型（高效培优专项训练）》官方解析
>
> > [!success]- **【答案】** ABD
>
> > [!note]- **【解析】**
> > 由圆 $O_{1}:x^{2} + y^{2} + 2x = 0$ ，可得圆 $O_{1}:(x + 1)^{2} + y^{2} = 1$ ，所以圆心 $O_{1}(-1,0)$ ，半径 $r_1 = 1$
> >
> > 由圆 $O_{2}:x^{2} + y^{2} - 2x - 2y - 2 = 0$ ，可得圆 $O_{2}:(x - 1)^{2} + (y - 1)^{2} = 4$
> >
> > 所以 $O_{2}(1,1)$ ，半径 $r_2 = 2$
> >
> > 所以两圆的圆心距为 $\left|O_{1}O_{2}\right|=\sqrt{4+1}=\sqrt{5}$ ，所以 $2-1<\left|O_{1}O_{2}\right|<2+1$ ，
> >
> > 所以两圆相交，所以两圆的公切线有 $^{2}$ 条，故 $^{A}$ 正确；
> >
> > 因为圆 $O_{1}:x^{2} + y^{2} + 2x = 0$ 与圆 $O_{2}:x^{2} + y^{2} - 2x - 2y - 2 = 0$
> >
> > 所以两圆的方程相减可得公共弦 AB 的方程： $4x + 2y + 2 = 0$ ，即 $2x + y + 1 = 0$ ，故 B 正确；
> >
> > 由 $2x + y + 1 = 0$ ，得 $y = -2x - 1$ ，代入圆 $O_{1}$ ，可得 $x^{2} + (-2x - 1)^{2} + 2x = 0$
> >
> > 整理得 $5x^{2} + 6x + 1 = 0$ ，解得 $x = -1$ 或 $x = -\frac{1}{5}$ ，所以 $(-1,1)$ ， $B\left(-\frac{1}{5}, - \frac{3}{5}\right)$
> >
> > 由两点到直线的距离相等，所以 $\frac{|-a - 1 + 1|}{\sqrt{a^2 + 1}} = \frac{\left| -\frac{1}{5} a + \frac{3}{5} + 1 \right|}{\sqrt{a^2 + 1}}$
> >
> > 解得 a = -2 或 $a = \frac{4}{3}$ ，故 C 错误；
> >
> > 由圆 $O_{2}$ 上恰有 $^{4}$ 个点到直线 $y = x + b$ 的距离等于 $^{1}$ ，则 $\frac{|1 - 1 + b|}{\sqrt{1 + 1}} < 1$ ，解得 $-\sqrt{2} < b < \sqrt{2}$ ，所以当 $b \in (-\sqrt{2}, \sqrt{2})$ 时，圆 $O_{2}$ 上恰有 $^{4}$ 个点到直线 $y = x + b$ 的距离等于 $^{1}$ ，故 $^{D}$ 正确·
> >
> > 故选 **ABD**.
