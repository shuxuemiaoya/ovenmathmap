> [!faq]- 《专题03_圆的方程的四大常考题型_高效培优专项训练_》官方解析
>
> > [!success]- **【答案】** （1） $a \neq -1$ ；（2）证明见解析；（3） $a = \frac{1}{4}$
>
> > [!note]- **【解析】**
> > 解：（1）当 $a = -1$ 时，方程为 $x + 2y = 0$ 表示一条直线.
> >
> > 当 $a \neq -1$ 时， $(1 + a)x^{2} + (1 + a)y^{2} - 4x + 8ay = 0$
> >
> > 整理得 $(x - \frac{2}{a + 1})^2 +(y + \frac{4a}{a + 1})^2 = \frac{4 + 16a^2}{(a + 1)^2}$
> >
> > 由于 $\frac{4 + 16a^2}{(1 + a)^2} >0$
> >
> > 所以 $a \neq -1$ 时方程表示圆．
> >
> > (2) 证明：方程变形为 $x^{2} + y^{2} - 4x + a(x^{2} + y^{2} + 8y) = 0$
> >
> > 由于 $a$ 取任何值，上式都成立，则有 $\left\{ \begin{array}{l}x^{2} + y^{2} - 4x = 0,\\ x^{2} + y^{2} + 8y = 0, \end{array} \right.$
> >
> > 解得 $\left\{\begin{aligned}x&=0,\\ y&=0\end{aligned}\right.$ 或 $\left\{\begin{aligned}x&=\frac{16}{5},\\ y&=-\frac{8}{5},\end{aligned}\right.$
> >
> > 所以曲线 $C$ 必过定点 $A(0,0)$ ， $B\left(\frac{16}{5}, - \frac{8}{5}\right)$
> >
> > 即无论 $a$ 为何值，曲线 $C$ 必过两定点·
> >
> > (3) 由 (2) 知曲线 $C$ 过定点 $A, B$ , 在这些圆中, 以 $AB$ 为直径的圆的面积最小 (其余不以 $AB$ 为直径的圆的直径大于 $AB$ 的长, 圆的面积也大),
> >
> > 从而以 $AB$ 为直径的圆的方程为 $\left(x - \frac{8}{5}\right)^2 +\left(y + \frac{4}{5}\right)^2 = \frac{16}{5}$
> >
> > 所以 $\left\{\begin{aligned}\frac{2}{1+a}&=\frac{8}{5}\\\frac{4a}{1+a}&=\frac{4}{5}\end{aligned}\right.$ ，解得 $\frac{4+16a^{2}}{(1+a)^{2}}=\frac{16}{5}$ $a=\frac{1}{4}$
