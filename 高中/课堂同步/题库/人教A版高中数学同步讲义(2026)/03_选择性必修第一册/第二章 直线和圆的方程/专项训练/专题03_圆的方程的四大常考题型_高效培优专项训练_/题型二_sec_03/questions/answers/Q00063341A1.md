> [!faq]- 《专题03_圆的方程的四大常考题型_高效培优专项训练_》官方解析
>
> > [!success]- **【答案】** A
>
> > [!note]- **【解析】**
> > 因为 $x^{2}+y^{2}-x-a=0$ 可化为 $\left(x-\frac{1}{2}\right)^{2}+y^{2}=a+\frac{1}{4}$ ，则 $a+\frac{1}{4}>0$ ，所以 $a>-\frac{1}{4}$ 。
> > 又点 $(1,1)$ 在圆 $x^{2}+y^{2}-x-a=0$ 的外部，所以 $1^{2}+1^{2}-1-a>0$ ，故a<1，
> > 综上， $-\frac{1}{4}<a<1$
> >
> > 故选：A.
> >
> > 28. 过圆 $x^{2} + y^{2} - x + y - 2 = 0$ 和 $x^{2} + y^{2} = 5$ 的交点，且圆心在直线 $3x + 4y - 1 = 0$ 上的圆的方程为（）A. $x^{2} + y^{2} + 2x - 2y - 11 = 0$ B. $x^{2} + y^{2} - 2x + 2y - 11 = 0$ C. $x^{2} + y^{2} - 2x - 2y - 11 = 0$ D. $x^{2} + y^{2} + 2x + 2y - 11 = 0$
> >
> > 【答案】A
> >
> > 【详解】由题意设所求圆的方程为 $x^{2} + y^{2} - x + y - 2 + \lambda (x^{2} + y^{2} - 5) = 0, (\lambda \neq -1)$ ，即 $x^{2} + y^{2} - \frac{1}{1 + \lambda} x + \frac{1}{1 + \lambda} y - \frac{2 + 5\lambda}{1 + \lambda} = 0$ ，圆心坐标为 $\left(\frac{1}{2(1 + \lambda)}, -\frac{1}{2(1 + \lambda)}\right)$ ，代入 $3x + 4y - 1 = 0$ 中，即 $\frac{3}{2(1 + \lambda)} - \frac{4}{2(1 + \lambda)} - 1 = 0$ ，解得 $\lambda = -\frac{3}{2}$ ，将 $\lambda = -\frac{3}{2}$ 代入 $x^{2} + y^{2} - \frac{1}{1 + \lambda} x + \frac{1}{1 + \lambda} y - \frac{2 + 5\lambda}{1 + \lambda} = 0$ 中，即 $x^{2} + y^{2} + 2x - 2y - 11 = 0$ 满足 $2^{2} + (-2)^{2} - 4(-11) > 0$ 故所求圆的方程为 $x^{2} + y^{2} + 2x - 2y - 11 = 0$
> >
> > 故选 **A**
