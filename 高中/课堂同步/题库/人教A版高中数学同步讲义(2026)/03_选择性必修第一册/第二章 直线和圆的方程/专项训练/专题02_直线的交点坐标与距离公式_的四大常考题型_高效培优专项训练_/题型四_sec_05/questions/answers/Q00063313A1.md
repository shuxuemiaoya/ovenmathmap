> [!faq]- 《专题02_直线的交点坐标与距离公式_的四大常考题型_高效培优专项训练_》官方解析
>
> > [!success]- **【答案】** B
>
> > [!note]- **【解析】**
> > $\sqrt{(m - p)^2 + (n - p - 1)^2}$ 表示两点 $A(m,n)$ 与 $B(p,p + 1)$ 之间的距离， $\sqrt{(m - q)^2 + (n - q - 3)^2}$ 表示两点 $A(m,n)$ 与 $C(q,q + 3)$ 之间的距离，又点 $B(p,p + 1)$ 是直线 $y = x + 1$ 上的动点，点 $C(q,q + 3)$ 是直线 $y = x + 3$ 上的动点，且直线 $y = x + 1$ 与直线 $y = x + 3$ 平行，所以 $|AB| + |AC|$ 的最小值即为直线 $y = x + 1$ 与直线 $y = x + 3$ 之间的距离，所以 $|AB| + |AC|$ 的最小值为 $\frac{|3 - 1|}{\sqrt{1 + 1}} = \sqrt{2}$ .
> >
> > 故选 **B**.
