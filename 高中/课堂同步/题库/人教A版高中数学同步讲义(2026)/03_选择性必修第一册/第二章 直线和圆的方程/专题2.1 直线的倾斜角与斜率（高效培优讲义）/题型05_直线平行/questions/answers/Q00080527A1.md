> [!faq]- 《专题2.1 直线的倾斜角与斜率（高效培优讲义）》官方解析
>
> > [!success]- **【答案】** D
>
> > [!note]- **【分析】**
> > 根据条件，结合点与直线的位置关系，转化为坐标运算，即可判断选项·
>
> > [!note]- **【解析】**
> > 对于（1），因为 $\lambda_{1} + \lambda_{2} = 0$
> >
> > 所以 $ax_{1} + by_{1} + c + ax_{2} + by_{2} + c = a(x_{1} + x_{2}) + b(y_{1} + y_{2}) + 2c$
> >
> > $= 2\left[a\left(\frac{x_1 + x_2}{2}\right) + b\left(\frac{y_1 + y_2}{2}\right) + c\right] = 0$ ，即 $a\left(\frac{x_1 + x_2}{2}\right) + b\left(\frac{y_1 + y_2}{2}\right) + c = 0$ ，所以（1）正确；
> >
> > 对于 $(2)$ ，当 $\lambda_{1}=\lambda_{2}=0$ 时，满足 $\lambda_{1}-\lambda_{2}=0$ ，
> >
> > 此时有 $ax_{1} + by_{1} + c = 0$ ， $ax_{2} + by_{2} + c = 0$
> >
> > 即 $M(x_{1},y_{1})$ ， $N(x_{2},y_{2})$ 均在直线 $l$ 上，所以（2）错误；
> >
> > 对于 $(3)$ ，由 $\lambda_{1} \cdot \lambda_{2} < 0$ ，得到 $(ax_{1} + by_{1} + c) \cdot (ax_{2} + by_{2} + c) < 0$ ，
> >
> > 由直线分平面区域的点满足“同侧同号，异侧异号”，知选项 D 正确；
> >
> > 故选：D
> >
> > ## 方法技巧
> >
> > 判定两条不重合的直线是否平行的依据是：当这两条直线均不与 $x$ 轴垂直时，只需看它们的斜率是否相等即
> >
> > 可，反过来，两条直线平行，则隐含着这两条直线的斜率相等（当这两条直线均不与 $x$ 轴垂直时）.
> >
> > 判定两条直线是否平行，只要研究两条直线的斜率是否相等即可，但是要注意斜率都不存在的情况，以及两
> >
> > 条直线是否重合.
