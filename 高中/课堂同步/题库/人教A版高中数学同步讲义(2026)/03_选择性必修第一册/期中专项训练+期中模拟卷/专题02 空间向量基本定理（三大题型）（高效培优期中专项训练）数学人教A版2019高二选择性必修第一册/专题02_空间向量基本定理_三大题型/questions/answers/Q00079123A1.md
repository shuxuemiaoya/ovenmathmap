> [!faq]- 《专题02 空间向量基本定理（三大题型）（高效培优期中专项训练）数学人教A版2019高二选择性必修第一册》官方解析
>
> > [!success]- **【答案】** D
>
> > [!note]- **【分析】**
> > 先根据向量在新基底下的坐标表示形式，结合原基底下的坐标，列出方程组，求解方程组即可得到新坐标·
>
> > [!note]- **【解析】**
> > 因为向量 $p$ 以 $\{a,b,c\}$ 为基底时的坐标为 $(1,2,3)$ ，所以 $p = a + 2b + 3c$
> >
> > 设 $p = x(a + b) + y(a - b) + 2zc = (x + y)a + (x - y)b + 2zc$
> >
> > 由空间向量基本定理可得 $\left\{ \begin{array}{l}x + y = 1\\ x - y = 2\\ 2z = 3 \end{array} \right.$ ，解得 $\left\{ \begin{array}{l}x = \frac{3}{2}\\ y = -\frac{1}{2}\\ z = \frac{3}{2} \end{array} \right.$
> >
> > 因此，向量 p 以 $\{a+b,a-b,2c\}$ 为基底时的坐标为 $\left(\frac{3}{2},-\frac{1}{2},\frac{3}{2}\right)$ .
> >
> > 故选 **D**
