> [!faq]- 《专题02 空间向量基本定理（三大题型）（高效培优期中专项训练）数学人教A版2019高二选择性必修第一册》官方解析
>
> > [!success]- **【答案】** A. $a, b, a + b$ B. $a, c, a - c$ C. $a + b, c, a - b$ D. $a + b + c, a + b, c$
>
> > [!note]- **【分析】**
> > 要判断一组向量能否构成空间的一个基底，即判断这组向量是否不共面，逐一分析各选项，找出不共面的向量组即可。
>
> > [!note]- **【解析】**
> > 对于 A，因为 $(a)+(b)=(a+b)$ ，
> >
> > 所以 a, b, $a + b$ 共面，不能构成空间的一个基底，故 A 错误；
> >
> > 对于 B，因为 $(a-c)=(a)+(-1)\cdot(c)$
> >
> > 所以 a, c, a - c 共面，不能构成空间的一个基底，故 B 错误；
> >
> > 对于 $\mathbb{C}$ ，假设 $a + b$ ， $c$ ， $a - b$ 共面，则存在实数 $\lambda, \mu$ ，使得 $(a + b) = \lambda(c) + \mu(a - b)$
> >
> > 由于 $\left\{a, b, c\right\}$ 为空间的一个基底，所以可得实数 $\lambda, \mu$ 的解为 $\left\{ \begin{array}{l} \mu = 1 \\ -\mu = 1 \\ \lambda = 0 \end{array} \right.$
> >
> > 但 $\mu = 1$ 与 $-\mu = 1$ 矛盾，假设不成立，即 $a + b, c, a - b$ 不共面，能构成空间的一个基底，故 $C$ 正确；
> >
> > 对于 D，因为 $\left(a+b+c\right)=\left(a+b\right)+\left(c\right)$ 所以 $a + b + c, a + b, c$ 共面，不能构成空间的一个基底。
> >
> > 故选 **C**.
