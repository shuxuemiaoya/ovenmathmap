> [!faq]- 《专题02 空间向量基本定理（三大题型）（高效培优期中专项训练）数学人教A版2019高二选择性必修第一册》官方解析
>
> > [!success]- **【答案】** BCD
>
> > [!note]- **【分析】**
> > 由基底的概念逐项判断即可·
>
> > [!note]- **【解析】**
> > 对于 A：因为 $a - b = 2a - (a + b)$ ，共面，不能构成基底；
> >
> > 对于 B：设 $a + b = \lambda(a - b) + \mu c$ ，所以 $\left\{\begin{aligned}\lambda &=1 \\ \lambda &=-1 \\ \mu &=0\end{aligned}\right.$ ，无解，
> >
> > 所以 $a+b, a-b, c$ 是不共面的向量，能构成空间的一个基底，故 B 正确；
> >
> > 对于 C：设 $a + b + c = m(b + a) + n(a - b)$ ，显然无解，所以能构成空间的一个基底，C 正确；
> >
> > 对于D：设 $a + b = m(b + c) + n(c + a)$ ，则 $a + b = na + mb + (m + n)c$
> >
> > 所以 $\left\{\begin{array}{l}n=1\\m=1\\m+n=0\end{array}\right.$ ，无解，
> >
> > 所以 $a+b, b+c, c+a$ 是不共面的向量，能构成空间的一个基底，故 D 正确；
> >
> > 故选 **BCD**
