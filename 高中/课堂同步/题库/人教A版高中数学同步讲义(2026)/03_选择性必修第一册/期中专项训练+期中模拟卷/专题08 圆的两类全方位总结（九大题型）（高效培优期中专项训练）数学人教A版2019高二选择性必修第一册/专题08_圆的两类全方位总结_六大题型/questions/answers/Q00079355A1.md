> [!faq]- 《专题08 圆的两类全方位总结（九大题型）（高效培优期中专项训练）数学人教A版2019高二选择性必修第一册》官方解析
>
> > [!success]- **【答案】** A. $(x + 1)^2 +y^2 = 4$ B. $x^{2} + (y - 2)^{2} = 4$ C. $(x + 2)^{2} + y^{2} = 4$ D. $(x - 2)^{2} + y^{2} = 4$
>
> > [!note]- **【分析】**
> > 设圆心坐标 $(a,0)$ ，得到 $(x-a)^{2}+y^{2}=a^{2}$ ，再由点 $(-1,\sqrt{3})$ 在圆上，代入即可求解.
>
> > [!note]- **【解析】**
> > 设圆心坐标为： $(a,0)$
> >
> > 由题意可知圆的标准方程为： $(x-a)^{2}+y^{2}=a^{2}$
> >
> > 由圆过点 $\left(-1, \sqrt{3}\right)$
> >
> > 所以 $\left(-1 - a\right)^2 + 3 = a^2$ ，解得： $a = -2$
> >
> > 所以圆的标准方程为 $(x + 2)^{2} + y^{2} = 4$
> >
> > 故选 **C**
