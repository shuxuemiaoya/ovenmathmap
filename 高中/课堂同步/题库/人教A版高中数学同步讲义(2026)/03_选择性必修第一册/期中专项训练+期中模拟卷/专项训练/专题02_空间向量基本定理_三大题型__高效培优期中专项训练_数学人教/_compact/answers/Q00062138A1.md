> [!faq]- 《专题02_空间向量基本定理_三大题型__高效培优期中专项训练_数学人教》官方解析
>
> > [!success]- **【答案】** A
>
> > [!note]- **【分析】**
> > 由向量 $a, b, c$ 不能构成基底，可得向量 $a, b, c$ 共面，根据平面向量基本定理，待定系数求解即可。【详解】因为 $\{a = e_1 + e_2, b = e_2 + e_3, c = e_1 + ie_3\}$ 不能构成空间的一个基底，
> >
> > 所以存在实数 $x$ 、 $y$ 使得 $c = xa + yb$
> >
> > 即 $e_1 + te_3 = x(e_1 + e_2) + y(e_2 + e_3)$
> >
> > 即 $e_1 + te_3 = xe_1 + (x + y)e_2 + ye_3$
> >
> > 因为 $\{e_1, e_2, e_3\}$ 是空间的一个基底，
> >
> > 则 $\left\{ \begin{array}{l}x = 1\\ x + y = 0\\ y = t \end{array} \right.$ ，解得 $\left\{ \begin{array}{l}x = 1\\ y = -1\\ t = -1 \end{array} \right.$
> >
> > 故选：A.
> >
> > 2. 如果向量组 $\{a, b, c\}$ 是空间中的一组基底向量，且 $m = a + c$ ，那么 $\{a, b, m\}$ 也是空间向量的一组基底向
> >
> > 量. ( )
> >
> > 【答案】正确
> >
> > 【分析】要判断 $\{a, b, m\}$ 是否为空间向量的一组基底，需根据空间向量基底的定义：空间中不共面的三个向量可作为一组基底，所以要判断 $a, b, m$ 是否共面。
>
> > [!note]- **【解析】**
> > ∵ 向量组 $\{a,b,c\}$ 是空间中的一组基底向量，∴ a,b,c 不共面，假设 a,b,m 共面，根据空间向量共面定理，若三个向量共面，则其中一个向量可由另外两个向量线性表示，即存在实数 $\lambda$ 和 $\mu$ ，使得 $m = \lambda a + \mu b$ ，将 $m = a + c$ 代入 $m = \lambda a + \mu b$ ，可得 $a + c = \lambda a + \mu b$ ，进一步变形为 $c = (\lambda - 1)a + \mu b$ ，但这与 a,b,c 不共面矛盾，所以假设不成立，即 a,b,m 不共面.
> >
> > 综上， $\left\{a,b,m\right\}$ 是空间向量的一组基底向量，所给命题正确.
