> [!faq]- 《专题11_双曲线标准方程及其性质全方位总结_十大题型__高效培优期中专》官方解析
>
> > [!success]- **【答案】** $x^{2} - \frac{y^{2}}{3} = 1, x \in (1, +\infty)$
>
> > [!note]- **【分析】**
> > 设圆 C 的半径为 r，根据题意可得 $\left|CA\right|=r+3,\left|CB\right|=r+1$ ，两式相减，再结合双曲线的定义即可得解.
>
> > [!note]- **【解析】**
> > 设圆 C 的半径为 r ，
> >
> > 圆 $A:(x + 2)^{2} + y^{2} = 9$ 的圆心 $A(-2,0)$ ，半径 $r_1 = 3$
> >
> > 圆 $B:(x - 2)^{2} + y^{2} = 1$ 的圆心 $B(2,0)$ ，半径 $r_2 = 1$
> >
> > 因为圆 $C$ 与圆 $A$ 、圆 $B$ 外切，
> >
> > 则 $\left|CA\right|=r+3,\left|CB\right|=r+1$
> >
> > 所以 $\left|CA\right|-\left|CB\right|=2<4=\left|AB\right|$
> >
> > 所以点 $C$ 的轨迹是以 $A, B$ 为焦点的双曲线的右支，
> >
> > 又 $2c = 4,2a = 2$ ，则 $c = 2,a = 1,b^{2} = c^{2} - a^{2} = 3$
> >
> > 所以其轨迹方程为 $x^{2} - \frac{y^{2}}{3} = 1, x \in (1, +\infty)$
> >
> > 故答案为： $x^{2} - \frac{y^{2}}{3} = 1, x \in (1, +\infty)$
