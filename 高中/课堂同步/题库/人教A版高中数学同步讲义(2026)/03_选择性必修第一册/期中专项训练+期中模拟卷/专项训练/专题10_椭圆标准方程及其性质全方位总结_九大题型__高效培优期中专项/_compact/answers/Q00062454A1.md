> [!faq]- 《专题10_椭圆标准方程及其性质全方位总结_九大题型__高效培优期中专项》官方解析
>
> > [!success]- **【答案】** A
>
> > [!note]- **【分析】**
> > 利用椭圆定义得到 $\left|PF_{1}\right|+\left|PF_{2}\right|=2a=4$ ，再利用余弦定理得到 $\left|PF_{1}\right|^{2}+\left|PF_{2}\right|^{2}-\left|PF_{1}\right|\left|PF_{2}\right|=2^{2}$ ，两者联立解出 $\left|PF_{1}\right|\left|PF_{2}\right|=4$ ，再利用三角形面积公式求出面积即可·
>
> > [!note]- **【解析】**
> > 由椭圆的标准方程 $C: \frac{x^2}{4} + \frac{y^2}{3} = 1$ ，可得 $a = 2, b = \sqrt{3}$ ，所以 $\left|PF_1\right| + \left|PF_2\right| = 2a = 4$ ，
> >
> > 又因为 $c^2 = a^2 - b^2 = 1 \Rightarrow c = 1$ ，即 $\left|F_1F_2\right| = 2c = 2$
> >
> > 因为 $\angle F_{1}PF_{2} = 60^{\circ}$
> >
> > 在 $\Delta F_{1}PF_{2}$ ，根据余弦定理可得 $\left|PF_1\right|^2 +\left|PF_2\right|^2 -2\left|PF_1\right|\left|PF_2\right|\cos 60^{\circ} = \left|F_{1}F_{2}\right|^{2}$
> >
> > 即 $\left|PF_1\right|^2 +\left|PF_2\right|^2 -\left|PF_1\right|\left|PF_2\right| = 2^2\Rightarrow \left|PF_1\right|^2 +\left|PF_2\right|^2 = 4 + \left|PF_1\right|\left|PF_2\right|$
> >
> > 又因为 $\left(\left|PF_1\right| + \left|PF_2\right|\right)^2 = 4^2\Rightarrow \left|PF_1\right|^2 +\left|PF_2\right|^2 +2\left|PF_1\right|\left|PF_2\right| = 16$ ，所以 $\left|PF_1\right|\left|PF_2\right| = 4$
> >
> > 所以 $S_{\triangle F_1PF_2} = \frac{1}{2}\left|PF_1\right|\left|PF_2\right|\sin \angle F_1PF_2 = \frac{1}{2}\times 4\times \frac{\sqrt{3}}{2} = \sqrt{3}$
> >
> > 故选 **A**
