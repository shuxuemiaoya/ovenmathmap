> [!faq]- 《专题03_空间向量及其运算的坐标表示_五大题型__高效培优期中专项训练》官方解析
>
> > [!success]- **【答案】** (1)10； (2) $2\sqrt{14}$ ; (3)-3.
>
> > [!note]- **【分析】**
> > （1）根据已知得 $b=(4,-1,0)$ ，应用向量数量积的坐标运算求结果；
> >
> > (2) 首先求得 $b - a = (2,1, - 2)$ ，再由向量平行的坐标表示列方程求参数值，最后应用向量减法、模的坐标运算求结果；
> >
> > (3) 应用向量加减的坐标运算求 $ka + b, a - 2b$ ，再由向量垂直的坐标表示列方程求参数值.
>
> > [!note]- **【解析】**
> > （1）由题设 $b = (6, -3, 2) - (2, -2, 2) = (4, -1, 0)$ ，所以 $a \cdot b = 2 \times 4 + (-2) \times (-1) + 2 \times 0 = 10$ ；
> >
> > (2) 由 (1) $b - a = (4, -1, 0) - (2, -2, 2) = (2, 1, -2)$ ，又 $c // (b - a)$
> >
> > 所以 $\frac{4}{2} = \frac{m}{1} = \frac{n}{-2}$ ，可得 $m = 2, n = -4$ ，即 $c = (4, 2, -4)$
> >
> > 所以 $c - a = (4,2, - 4) - (2, - 2,2) = (2,4, - 6)$ ，则 $\left|c - a\right| = \sqrt{4 + 16 + 36} = 2\sqrt{14}$
> >
> > $$
> > (3) \text {由} (1) k a + b = (2 k, - 2 k, 2 k) + (4, - 1, 0) = (2 k + 4, - 2 k - 1, 2 k)
> > $$
> >
> > $$
> > a - 2 b = (2, - 2, 2) - (8, - 2, 0) = (- 6, 0, 2)
> > $$
> >
> > 由 $\left(ka + b\right)\perp \left(a - 2b\right)$ ，则 $\left(ka + b\right)\cdot \left(a - 2b\right) = -6(2k + 4) + 0 + 4k = 0$
> >
> > 所以 $8k + 24 = 0$ ，则 k = -3。
