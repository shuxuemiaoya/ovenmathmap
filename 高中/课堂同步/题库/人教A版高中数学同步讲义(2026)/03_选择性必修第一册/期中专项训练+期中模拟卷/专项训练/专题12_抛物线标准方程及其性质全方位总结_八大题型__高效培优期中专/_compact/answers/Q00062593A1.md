> [!faq]- 《专题12_抛物线标准方程及其性质全方位总结_八大题型__高效培优期中专》官方解析
>
> > [!success]- **【答案】** (1) a = 2 ; (2)证明见解析，定点 $(-4,2)$
>
> > [!note]- **【分析】**
> > （1）利用题给条件列出关于 $a$ 的方程，解之即可求得 $a$ 的值；
> >
> > (2) 先设出直线 $l$ 的方程 $l: x = my + t$ ，并与抛物线方程联立，利用设而不求的方法求得 $m, t$ 的关系，进而
> >
> > 求得直线 l 过定点的坐标。
>
> > [!note]- **【解析】**
> > （1）因为点 $P(a,4)$ 在抛物线 $C$ 上，所以 $16 = 2pa$ ，即 $8 = pa$ 因为 $\triangle POF$ 的面积为4，所以 $\frac{1}{2} \times \frac{p}{2} \times 4 = 4$ ，解得 $p = 4$ ，所以 $a = 2$ （2）由（1）得 $C: y^2 = 8x$ ， $P(2,4)$ 当直线 $l$ 斜率为0时，不适合题意；当直线 $l$ 斜率不为0时，设直线 $l: x = my + t$ ，设 $A(x_1, y_1)$ ， $B(x_2, y_2)$ 由 $\left\{ \begin{array}{l} y^2 = 8x \\ x = my + t \end{array} \right.$ ，得 $y^2 - 8my - 8t = 0$ 则 $\Delta > 0 \Rightarrow 2m^2 + t > 0$ ， $y_1 + y_2 = 8m$ ， $y_1y_2 = -8t$ 因为直线 $PA$ ， $PB$ 的斜率之和为 $\frac{4}{3}$ 所以 $\frac{y_1 - 4}{x_1 - 2} + \frac{y_2 - 4}{x_2 - 2} = \frac{4}{3}$ ，即 $\frac{y_1 - 4}{y_1^2 - 2} + \frac{y_2 - 4}{y_2^2 - 2} = \frac{4}{3}$ 所以 $\frac{8}{y_1 + 4} + \frac{8}{y_2 + 4} = \frac{4}{3}$ ，所以 $\frac{1}{3} = \frac{2}{y_1 + 4} + \frac{2}{y_2 + 4} = \frac{2(y_1 + y_2 + 8)}{(y_1 + 4)(y_2 + 4)} = \frac{2(y_1 + y_2 + 8)}{y_1y_2 + 4(y_1 + y_2) + 16} = \frac{2(8m + 8)}{-8t + 4 \times 8m + 16}$ ，整理得 $m = -\frac{1}{2} t - 2$ 所以直线 $l: x = my + t = \left(-\frac{1}{2} t - 2\right)y + t = t\left(-\frac{1}{2} y + 1\right) - 2y$ ，令 $\left\{ \begin{array}{l} -\frac{1}{2} y + 1 = 0 \\ x + 2y = 0 \end{array} \right.$ ，解之得 $\left\{ \begin{array}{l} x = -4 \\ y = 2 \end{array} \right.$ ，所以直线 $l$ 过定点（-4,2）
