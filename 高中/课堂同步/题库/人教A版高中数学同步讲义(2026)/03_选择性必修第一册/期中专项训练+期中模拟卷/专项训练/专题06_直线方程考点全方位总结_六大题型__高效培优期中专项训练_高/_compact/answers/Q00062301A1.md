> [!faq]- 《专题06_直线方程考点全方位总结_六大题型__高效培优期中专项训练_高》官方解析
>
> > [!success]- **【答案】** BD
>
> > [!note]- **【分析】**
> > 求得直线 $AB$ 的方程，即点 $P(x,y)$ 满足 $y = -\frac{2}{3} x + 2(1 \leq x \leq 3)$ ，进而 $\frac{y}{x} = -\frac{2}{3} + \frac{2}{x}$ ，根据 $1 \leq x \leq 3$ 及反比例函数的单调性求得 $\frac{2}{3} \leq \frac{2}{x} \leq 2$ ，即可求解最值·
>
> > [!note]- **【解析】**
> > 因为直线 $AB$ 的斜率为 $k_{AB} = \frac{\frac{4}{3} - 0}{1 - 3} = -\frac{2}{3}$ ，
> >
> > 所以直线 $AB$ 的方程为 $y - 0 = -\frac{2}{3}(x - 3)$ ，即 $y = -\frac{2}{3} x + 2$ ，
> >
> > 即点 $P(x,y)$ 满足 $y = -\frac{2}{3} x + 2(1 \leq x \leq 3)$ ，所以 $\frac{y}{x} = \frac{-\frac{2}{3}x + 2}{x} = -\frac{2}{3} + \frac{2}{x}$ ，
> >
> > 因为 $1 \leq x \leq 3$ ，所以 $\frac{2}{3} \leq \frac{2}{x} \leq 2$ ，所以 $0 \leq \frac{y}{x} \leq \frac{4}{3}$ ，
> >
> > 即 $\frac{y}{x}$ 的最大值是 $\frac{4}{3}$ ， $\frac{y}{x}$ 的最小值是 0.
> >
> > 故选 **BD**
