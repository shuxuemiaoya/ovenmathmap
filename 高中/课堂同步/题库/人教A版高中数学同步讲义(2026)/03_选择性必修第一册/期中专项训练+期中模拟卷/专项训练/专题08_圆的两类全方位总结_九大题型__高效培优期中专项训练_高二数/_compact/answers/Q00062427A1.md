> [!faq]- 《专题08_圆的两类全方位总结_九大题型__高效培优期中专项训练_高二数》官方解析
>
> > [!success]- **【答案】** D
>
> > [!note]- **【分析】**
> > 根据给定条件，求出 $x+y$ 的取值范围，再结合式子特征推理求出a的范围·
>
> > [!note]- **【解析】**
> > 依题意， $2 = 2(x - 1)^{2} + 2(y - 2)^{2} = [(x - 1) + (y - 2)]^{2} + [(x - 1) - (y - 2)]^{2}$
> >
> > $[ ( x - 1 ) + ( y - 2 ) ] ^ { 2 } \ , \text { 当且仅当 } x - 1 = y - 2 = \frac { \sqrt { 2 } } { 2 } \ \text { 或 } x - 1 = y - 2 = - \frac { \sqrt { 2 } } { 2 } \ \text { 时取等号 } ,$ 因此 $|x + y - 3|\leq \sqrt{2}$ ，即 $3 - \sqrt{2}\leq x + y\leq 3 + \sqrt{2}$
> >
> > 则 $|x + y + a| + |1 - x - y| = |x + y + a| + x + y - 1$
> >
> > 要 $|x+y+a|+|1-x-y|$ 的取值与x,y无关，当且仅当 $x+y+a\leq0\Leftrightarrow-a\quad x+y$
> >
> > 此时 $|x + y + a| + |1 - x - y| = -(x + y + a) + a + y - 1 = -a - 1$
> >
> > 由 $-a$ $3 + \sqrt{2}$ ，得 $a \leq -3 - \sqrt{2}$ ，所以实数 $a$ 的取值范围是 $(- \infty, -\sqrt{2} - 3]$ .
> >
> > 故选 **D**
