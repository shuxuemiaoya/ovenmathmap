> [!faq]- 《专题08_圆的两类全方位总结_九大题型__高效培优期中专项训练_高二数》官方解析
>
> > [!success]- **【答案】** ABC
>
> > [!note]- **【分析】**
> > 求出直线的斜率及纵截距判断 $^{A}$ ；利用平行线间距离公式计算判断 $^{B}$ ；
> >
> > 求出圆心 C 关于已知直线的对称点求解判断 C；利用目标函数的几何意义计算判断 D.
>
> > [!note]- **【解析】**
> > 对于 $^{A}$ ，由AB>0且BC<0，得直线 $Ax+By+C=0$ 的斜率 $-\frac{A}{B}<0$ ，纵截距 $-\frac{C}{B}>0$ ，该直线不过第三象限， $^{A}$ 正确；
> >
> > 对于 B，直线 $l_{1}$ ：2x-4y+2=0 ，当 a=-4 时， $l_{1}//l_{2}$ ，它们的距离为 $\frac{|-2-2|}{\sqrt{2^{2}+4^{2}}}=\frac{2\sqrt{5}}{5}$ ，B 正确；
> >
> > 对于 $\mathbb{C}$ ，令圆 $C:(x + 1)^2 +(y - 1)^2 = 4$ 的圆心 $C(-1,1)$ 关于直线 $x - y - 1 = 0$ 的对称点为 $(m,n)$
> >
> > 则 $\left\{ \begin{array}{l} \frac{m - 1}{2} - \frac{n + 1}{2} - 1 = 0 \\ \frac{n - 1}{m + 1} = -1 \end{array} \right.$ ，解得 $m = 2, n = -2$
> >
> > 所求圆的方程为 $(x - 2)^{2} + (y + 2)^{2} = 4$ ，C正确；
> >
> > 对于 D，圆 $(x-2)^{2}+y^{2}=1$ 的圆心 $M(2,0)$ ，半径 1，令原点为 O，
> >
> > 则 $x^{2} + y^{2} = |OA|^{2} \leq (|OM| + 1)^{2} = 9$ ，当且仅当 O, M, A 三点共线时取等号，D 错误.
> >
> > 故选 **ABC**
