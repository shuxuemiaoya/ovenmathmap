> [!faq]- 《专题08_圆的两类全方位总结_九大题型__高效培优期中专项训练_高二数》官方解析
>
> > [!success]- **【答案】** (1) $x+2y+3=0$ 或 $x+2y-7=0$ (2) $\left(x - \frac{2}{5}\right)^2 +\left(y - \frac{19}{5}\right)^2 = 1$
>
> > [!note]- **【分析】**
> > （1）依题意该直线与直线 $l$ 平行，由平行直线间的距离公式列方程即可求解；
> >
> > (2) 利用“垂直”，“平分”即可求出圆心关于直线的对称点，进而可求对称圆方程.
>
> > [!note]- **【解析】**
> > （1）由题意可知该直线与直线 $l$ 平行，
> >
> > 所以设该直线方程为 $x + 2y + c = 0$
> >
> > 依题意 $\frac{|-2 - \phi}{\sqrt{1^2 + 2^2}} = \sqrt{5}$ ，解得 $c = 3$ 或 $c = -7$
> >
> > 故该直线方程为 $x + 2y + 3 = 0$ 或 $x + 2y - 7 = 0$ .
> >
> > (2) 圆 $C: (x + 2)^{2} + (y + 1)^{2} = 1$ 的圆心为 $C(-2, -1)$
> >
> > 设圆心 $C(-2, - 1)$ 关于直线 $l:x + 2y - 2 = 0$ 的对称点为 $D(m,n)$
> >
> > 则 $k_{CD} \cdot k_l = -1$ 且 $CD$ 的中点 $\left(\frac{m - 2}{2}, \frac{n - 1}{2}\right)$ 在直线 $l$ 上.
> >
> > $\therefore \left\{ \begin{array}{l} \frac{n + 1}{m + 2} \times \left(-\frac{1}{2}\right) = -1 \\ \frac{m - 2}{2} + 2 \times \frac{n - 1}{2} - 2 = 0 \end{array} \right.$ ，解得 $m = \frac{2}{5}, n = \frac{19}{5}$
> >
> > $$
> > \therefore D \left(\frac {2}{5}, \frac {1 9}{5}\right)
> > $$
> >
> > ∵ 圆 C 关于直线 l 的对称圆半径不变，
> >
> > 该对称圆方程为： $\left(x - \frac{2}{5}\right)^2 +\left(y - \frac{19}{5}\right)^2 = 1$
