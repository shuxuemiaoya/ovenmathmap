> [!faq]- 《专题05 直线的倾斜角与斜率（六大题型）（高效培优期中专项训练）数学人教A版2019高二选择性必修第一册》官方解析
>
> > [!success]- **【答案】** ![](../../../images/questions/f4c1853037ad75a8beb3521f65d98f6bb6eab6b7eceac11fa8db79daa30977e1.jpg) A. $k_{4} < k_{3} < k_{2} < k_{1}$ B. $k_{4} < k_{3} < k_{1} < k_{2}$ C. $k_{3} < k_{4} < k_{2} < k_{1}$ D. $k_{4} < k_{2} < k_{3} < k_{1}$
>
> > [!note]- **【分析】**
> > 根据斜率与倾斜角的关系即可判断·
>
> > [!note]- **【解析】**
> > 倾斜角为锐角时，斜率为正，倾斜角越大，倾斜程度越大，斜率越大；
> >
> > 倾斜角为钝角时，斜率为负，倾斜角越大，倾斜程度越小，斜率越大，
> >
> > 所以 $k_{4} < k_{3} < 0 < k_{2} < k_{1}$
> >
> > 故选 **A**.
