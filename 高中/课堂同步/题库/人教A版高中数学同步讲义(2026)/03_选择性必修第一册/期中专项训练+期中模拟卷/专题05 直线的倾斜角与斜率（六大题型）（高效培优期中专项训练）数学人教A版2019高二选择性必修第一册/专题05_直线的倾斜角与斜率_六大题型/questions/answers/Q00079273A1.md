> [!faq]- 《专题05 直线的倾斜角与斜率（六大题型）（高效培优期中专项训练）数学人教A版2019高二选择性必修第一册》官方解析
>
> > [!success]- **【答案】** A
>
> > [!note]- **【分析】**
> > 利用两直线平行关系，可得 $x, y$ 的系数成比例，再检验是否有重合情况，从而可作出判断。【详解】由直线 $l_{1}: x + (m - 1)y + 1 = 0$ 与直线 $l_{2}: mx + 2y + 2 = 0$ 平行可得： $1 \times 2 = (m - 1)m$ ，解得： $m = 2$ 或 $m = -1$ ，检验，当 $m = 2$ 时，直线 $l_{1}: x + y + 1 = 0$ 与直线 $l_{2}: x + y + 1 = 0$ 重合，故舍去；
> >
> > 当 $m = -1$ 时，直线 $l_{1}:x - 2y + 1 = 0$ 与直线 $l_{2}:x - 2y - 2 = 0$ 平行；
> >
> > 故选：A.
> >
> > 56. 直线 $l_{1}: ax + y - 1 = 0, l_{2}: (a - 2)x - ay + 1 = 0$ ，则 $a = -2$ 是 $l_{1} // l_{2}$ 的（）
> >
> > 【答案】
> > A．必要不充分条件 B．充分不必要条件
> > C．充要条件 D．既不充分也不必要条件
> >
> > 【答案】C
> >
> > 【分析】根据直线平行的判定求参数，结合充分、必要性定义判断条件间的关系·
>
> > [!note]- **【解析】**
> > 若 $l_{1} / / l_{2}$ ，则 $a^2 + a - 2 = (a + 2)(a - 1) = 0$ ，可得 $a = -2$ 或 $a = 1$ $a = -2$ 时， $l_{1}: 2x - y + 1 = 0, l_{2}: 2x - y - \frac{1}{2} = 0$ ，即两直线平行，符合； $a = 1$ 时， $l_{1}: x + y - 1 = 0, l_{2}: x + y - 1 = 0$ ，即两直线重合，不符。所以 $a = -2$ ，即 $a = -2$ 是 $l_{1} / / l_{2}$ 的充要条件。
> >
> > 故选 **C**
