> > [!note]- **【分析】**
> > 根据直线一般形式下的平行条件计算即可·

> > [!note]- **【解析】**
> > 因为 $l_{1} / / l_{2}$ ，所以 $a(a - 3) = 18$ ，解得 $a = 6$ 或 $a = -3$
> >
> > 当 a=6 时， $l_{1}:6x+3y-2=0, l_{2}:6x+3y+4=0$ ，满足 $l_{1}$ 与 $l_{2}$ 平行；
> >
> > 当 $a = -3$ 时， $l_{1} : -3x + 3y - 2 = 0, l_{2} : 6x - 6y + 4 = 0$ ，可判断此时 $l_{1}$ 与 $l_{2}$ 重合，舍去；
> >
> > 所以 a = 6 .
> >
> > 故选：A.

> > 58. 直线 $l_{1}: x + my - 1 = 0, l_{2}: (m - 2)x + 3y + 1 = 0$ ，则下列说法正确的是（）A. 若 $l_{1} // l_{2}$ ，则 $m = -1$ 或 $m = 3$ B. 若 $l_{1} // l_{2}$ ，则 $m = -1$
> >
> > C．若 $l_{1}\perp l_{2}$ ，则 $m=-\frac{1}{2}$ D．若 $l_{1}\perp l_{2}$ ，则 $m=\frac{1}{2}$
> >
> > 【答案】AD
> >
> > 【分析】应用直线平行、垂直的判定列方程求参数，注意验证即可得答案·
> >
> > 【详解】已知直线 $l_{1}: x + my - 1 = 0, l_{2}: (m - 2)x + 3y + 1 = 0$
> >
> > 若 $l_{1} / / l_{2}$ ，则 $1\times 3 - m(m - 2) = 0$ ，求得 $m = 3$ 或 $m = -1$
> >
> > 经检验 m=3 或 m=-1 都满足条件，故 A 正确，B 不正确。
> >
> > 若 $l_{1} \perp l_{2}$ ，则 $1 \times (m - 2) + m \times 3 = 0$ ，得 $m = \frac{1}{2}$ ，故 $\mathbb{C}$ 不正确， $\mathbb{D}$ 正确。
> >
> > 故选 **AD**
