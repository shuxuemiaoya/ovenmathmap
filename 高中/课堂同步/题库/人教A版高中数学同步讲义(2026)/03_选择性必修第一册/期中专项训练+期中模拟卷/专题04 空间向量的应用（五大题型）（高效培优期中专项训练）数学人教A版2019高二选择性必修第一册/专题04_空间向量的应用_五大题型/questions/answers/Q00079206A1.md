> [!faq]- 《专题04 空间向量的应用（五大题型）（高效培优期中专项训练）数学人教A版2019高二选择性必修第一册》官方解析
>
> > [!success]- **【答案】** A
>
> > [!note]- **【分析】**
> > 由空间线面位置关系及向量法逐个判断即可·
>
> > [!note]- **【解析】**
> > 设平面 $\alpha, \beta$ 的法向量分别为 $n_1, n_2$ ，直线 $m$ 的方向向量为 $m$ ，
> >
> > 对于 A：若 $\alpha \parallel \beta, m \parallel \alpha$ ，则 $m \parallel \beta$ 或 $m \subset \beta$ ，错误；
> >
> > 对于 B：若 $m \perp \alpha, m \perp \beta$ ，则 $m // n_{1}, m // n_{2}$ ，所以 $n_{1} // n_{2}$ ，所以 $\alpha // \beta$ ，正确；
> >
> > 对于 $C$ ：由 $\alpha // \beta, m \perp \alpha$ ，可得 $n_1 // n_2, m // n_2$ ，所以 $m // n_1$ ，所以 $m \perp \beta$ ，正确；
> >
> > 对于 $^{D}$ ：由 $m\perp\alpha,m\parallel\beta$ ，可得： $m//n_{1}$ ， $m\perp n_{2}$ ，所以 $n_{1}\perp n_{2}$ ，所以 $\alpha\perp\beta$ ，正确，
> >
> > 故选：A
