> [!faq]- 《专题06 直线方程考点全方位总结（六大题型）（高效培优期中专项训练）数学人教A版2019高二选择性必修第一册》官方解析
>
> > [!success]- **【答案】** C
>
> > [!note]- **【分析】**
> > 利用直线的方向向量即可求得斜率，再利用直线的点斜式方程求出结果
>
> > [!note]- **【解析】**
> > 由题意知直线 l 的方向向量是 $v = (1, 2)$ ，可得其斜率为 2，
> > 所以直线 l 的方程为 $y - 0 = 2(x - 1)$ ，即 2x - y - 2 = 0。
> >
> > 故选：C
> >
> > 3. 过点 $(3, -2)$ ，倾斜角为 $30^{\circ}$ 的直线方程为（ ）A. $y - 2 = \frac{\sqrt{3}}{3} (x + 3)$ B. $y + 2 = \frac{\sqrt{3}}{3} (x - 3)$ C. $y - 2 = \sqrt{3} (x + 3)$ D. $y + 2 = \sqrt{3} (x - 3)$
> >
> > 【答案】B
> >
> > 【分析】由直线的点斜式方程即可求解·
> >
> > 【详解】因为倾斜角为 $30^{\circ}$ ，所以 $k = \tan 30^{\circ} = \frac{\sqrt{3}}{3}$
> >
> > 由直线的点斜式方程得 $y + 2 = \frac{\sqrt{3}}{3}(x - 3)$ .
> >
> > 故选 **B**.
