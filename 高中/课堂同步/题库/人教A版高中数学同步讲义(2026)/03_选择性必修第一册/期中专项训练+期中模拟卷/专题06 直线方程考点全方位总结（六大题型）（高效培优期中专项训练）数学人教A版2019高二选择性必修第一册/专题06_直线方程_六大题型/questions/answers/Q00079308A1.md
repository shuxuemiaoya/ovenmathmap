> [!faq]- 《专题06 直线方程考点全方位总结（六大题型）（高效培优期中专项训练）数学人教A版2019高二选择性必修第一册》官方解析
>
> > [!success]- **【答案】** A．直线 $\sqrt{3}x + 3y - 3 = 0$ 的斜率为 $\frac{\sqrt{3}}{3}$ B．若直线 $ax + by + c = 0$ 经过第三象限，则 ab > 0, bc < 0 C．直线 $(2+\lambda)x+(1-2\lambda)y+4-3\lambda=0(\lambda\in\mathbf{R})$ 恒过定点 $(-1,-2)$ D．若 a = 0，则直线 $3x + ay = 2$ 与直线 $ax + 3y + 1 = 0$ 垂直
>
> > [!note]- **【分析】**
> > $^{A}$ 化为斜截式判断； $^{B}$ 特殊值a=0,bc>0 判断即可； $^{C}$ 化为 $2x+y+4+\lambda(x-2y-3)=0$ ，即可确定定点； $^{D}$ 将参数a=0代入直线方程即可判断.
>
> > [!note]- **【解析】**
> > A：将直线化为斜截式，有 $y = -\frac{\sqrt{3}}{3} x + 1$ ，即直线斜率为 $-\frac{\sqrt{3}}{3}$ ，错；
> >
> > B：当 $a = 0, bc > 0$ 时，直线为 $y = -\frac{c}{b} < 0$ 也过第三象限，错；
> >
> > C. $(2 + \lambda)x + (1 - 2\lambda)y + 4 - 3\lambda = 2x + y + 4 + \lambda (x - 2y - 3) = 0$
> >
> > 令 $\left\{ \begin{array}{l} 2x + y + 4 = 0 \\ x - 2y - 3 = 0 \end{array} \right. \Rightarrow \left\{ \begin{array}{l} x = -1 \\ y = -2 \end{array} \right.$ ，即直线过定点 $(-1, -2)$ ，对；
> >
> > D：由题设 $3x + ay = 2 \Rightarrow x = \frac{2}{3}$ ， $ax + 3y + 1 = 0 \Rightarrow y = -\frac{1}{3}$ ，显然两线垂直，对
> >
> > 故选 **CD**
