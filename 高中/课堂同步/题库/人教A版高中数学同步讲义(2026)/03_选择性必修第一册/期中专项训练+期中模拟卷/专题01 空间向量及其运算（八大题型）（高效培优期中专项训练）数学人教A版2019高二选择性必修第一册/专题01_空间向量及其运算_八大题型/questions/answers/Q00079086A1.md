> [!faq]- 《专题01 空间向量及其运算（八大题型）（高效培优期中专项训练）数学人教A版2019高二选择性必修第一册》官方解析
>
> > [!success]- **【答案】** $^{(1)}$ 证明见解析 (2)证明见解析
>
> > [!note]- **【分析】**
> > （1）方法一：利用回路法·通过两个不同“路径”表示 $\overline{EF}$ ，再利用相反向量的性质即可得证；
> > 方法二：由 $\frac{AE}{EB} = \frac{DF}{FC} = \lambda$ ，利用平面向量中的定比分点公式结合向量的减法即可得证·
> >
> > (2) 同理 (1) 得， $\overline{GI}=\frac{1}{2}\overline{AB}+\frac{1}{2}\overline{DC}$ ，然后结合空间向量的共面定理证明四点共面
>
> > [!note]- **【解析】**
> > （1）证法 $^{1}$ ：由 $\frac{AE}{EB}=\frac{DF}{FC}=\lambda$ 得， $AE=\lambda EB,\quad DF=\lambda FC$ ，
> >
> > $EA + \lambda EB = 0$ $DF + \lambda CF = 0$
> >
> > 因为 $EF = EA + AD + DF$ ①； $EF = EB + BC + CF$ ②，
> >
> > 由①+②×λ，得
> >
> > $\left(1 + \lambda\right)EF = EA + AD + DF + \lambda \left(EB + BC + CF\right) = \lambda BC + AD$ ,
> >
> > 所以 $EF=\frac{\lambda}{1+\lambda}BC+\frac{1}{1+\lambda}AD$
> >
> > 证法 $^{2}$ ：设 O 是平面内一点，
> >
> > $$
> > \frac {A E}{E B} = \frac {D F}{F C} = \lambda
> > $$
> >
> > 由平面向量中的定比分点公式可得 $\overrightarrow{OE} = \frac{\overrightarrow{OU} + \lambda\overrightarrow{OB}}{1 + \lambda}$ ， $\overrightarrow{OF} = \frac{\overrightarrow{OU} + \lambda\overrightarrow{OC}}{1 + \lambda}$ ，
> >
> > $$
> > \overrightarrow {E F} = \overrightarrow {O F} - \overrightarrow {O E} = \frac {\overrightarrow {O D} + \lambda \overrightarrow {O C}}{1 + \lambda} - \frac {\overrightarrow {O A} + \lambda \overrightarrow {O B}}{1 + \lambda} = \frac {\overrightarrow {O D} - \overrightarrow {O A} + \lambda (\overrightarrow {O C} - \overrightarrow {O B})}{1 + \lambda} = \frac {\overrightarrow {A D} + \lambda \overrightarrow {B C}}{1 + \lambda}
> > $$
> >
> > 即 $EF=\frac{\lambda}{1+\lambda}BC+\frac{1}{1+\lambda}AD$
> >
> > (2) 由 E, F 分别是 AB, CD 上的动点，设 $\overline{AB} = m\overline{AE}, \overline{DC} = n\overline{DF}$ ,
> >
> > 因为 $G$ ， $I$ 分别为 $AD$ ， $BC$ 的中点，即 $\frac{AG}{GD} = \frac{BI}{IC} = 1$
> >
> > 根据（1）的结论，得 $\vec{GI} = \frac{\vec{AB} + \vec{DC}}{2} = \frac{m}{2}\vec{AE} +\frac{n}{2}\vec{DF}.$
> >
> > 又因为 J, H 分别为 AF ， EF 的中点，
> >
> > 所以 $GJ=\frac{1}{2}DF$ ， $JH=\frac{1}{2}AE$
> >
> > $\square\square$ GI = $\frac{1}{2}$ $\square\square\square$ AB + $\frac{1}{2}$ $\square\square\square$ DC = $\frac{m}{2}$ $\square\square\square$ AE + $\frac{n}{2}$ $\square\square\square$ DF = mJH + nGJ
> >
> > 即直线 GI 在平面 GHJ 上，所以 G，H，I，J 四点共面。
