> [!faq]- 《专题01 空间向量及其运算（八大题型）（高效培优期中专项训练）数学人教A版2019高二选择性必修第一册》官方解析
>
> > [!success]- **【答案】** A. $|a| - |b| = |a + b|$ 是 $a$ ， $b$ 共线的充要条件 B. 若 $\overset{\cup\cup}{AB}$ ， $\overset{\cup\cup}{CD}$ 共线，则 $AB \parallel CD$ C．若 P, A, B, C 为空间四点，且有 $\overline{PA} = \lambda \overline{PB} + \mu \overline{PC}$ ，则 $\lambda + \mu = 1$ 是 A, B, C 三点共线的充要条件 D. A, B, C 三点不共线，对空间任意一点 O，若 $\overline{OP} = \frac{3}{4} \overline{OA} + \frac{1}{8} \overline{OB} + \frac{1}{8} \overline{OC}$ ，则 P, A, B, C 四点共面
>
> > [!note]- **【分析】**
> > 当 $a, b$ 反向时， $\left|\vec{a}\right| - \left|b\right| = \left|a + b\right|$ ，可得 $\mathbf{A}$ 错误；利用共线向量定义可知，当向量 $a, b$ 共线时，向量
> >
> > a,b 所在的直线不一定平行，即 B 错误；当 $\overline{PB},\overline{PC}$ 共线时，由共线向量定义知 $\lambda+\mu$ 不一定为 1，可知 C 错
> >
> > 误；由空间向量证明点共面可知 $^{D}$ 正确·
>
> > [!note]- **【解析】**
> > 对于 $\mathsf{A}$ ，当 $a,b$ 同向时， $\left|\vec{a}\right| - \left|b\right| = \left|a - b\right|$
> >
> > 当 $a, b$ 反向时， $\left|\vec{a}\right| - \left|b\right| = \left|a + b\right|$ ，故 $\mathsf{A}$ 错误；
> >
> > 对于 $^{B}$ ，若 $\overline{AB,CD}$ 共线，则 $AB//CD$ 或 A, B, C, D 四点共线，故 $^{B}$ 错误；
> >
> > 对于 $C$ ，若 $\overline{PB},\overline{PC}$ 共线时，则 $\overline{PA} = \lambda \overline{PB} +\mu \overline{PC}$ 可知 $A,B,C$ 三点共线， $\lambda +\mu$ 不一定为1，
> >
> > 比如 $\overline{PB}=2\overline{PC}$ ， $\overline{PA}=PB+2\overline{PC}=4\overline{PC}$ ，可得 A，B，C 三点共线，必要性不成立，故 C 错误；
> >
> > 对于 $^{D}$ ，因为 A, B, C 三点不共线，对空间任意一点 O，若 $\frac{\square\square\square}{OP} = \frac{3}{4}\frac{\square\square\square}{OA} + \frac{1}{8}\frac{\square\square\square}{OB} + \frac{1}{8}\frac{\square\square\square}{OC}$
> >
> > 因为 $\frac{3}{4} +\frac{1}{8} +\frac{1}{8} = 1$ ，所以可知 $P,A,B,C$ 四点共面，故D正确，
> >
> > 故选 **D**
