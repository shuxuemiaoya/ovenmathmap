> [!faq]- 《专题03 空间向量及其运算的坐标表示（五大题型）（高效培优期中专项训练）数学人教A版2019高二选择性必修第一册》官方解析
>
> > [!success]- **【答案】** A. 若 $A(-4, -3, 2)$ 与 $B(a, b, c)$ 关于平面 $yOz$ 对称，则 $a + b + c = 3$ B. 若 $AB = AC + AD$ ，则 $A, B, C, D$ 共面 C. 若 $PD = \frac{1}{6} PA + \frac{4}{3} PB - \frac{1}{6} PC$ ，则 $A, B, C, D$ 共面 D. 若 $A(0, 0, 2), B(1, 2, 0), C(2, m, n)$ 三点共线，则 $m + n = 2$
>
> > [!note]- **【分析】**
> > 利用对称求解判断 $^{A}$ ；利用共面向量定理及推论判断 $^{BC}$ ；利用向量共线求解判断 $^{D}$ .
>
> > [!note]- **【解析】**
> > 对于 $\mathsf{A}$ ，由 $A(-4, -3, 2)$ 与 $B(a, b, c)$ 关于平面 $yOz$ 对称，得 $a = 4, b = -3, c = 2$ ， $a + b + c = 3$ ， $\mathsf{A}$ 正确；
> >
> > 对于 B，由 $AB = AC + AD$ 及共面向量定理得 A, B, C, D 共面，B 正确；
> >
> > 对于 $C$ ， $\frac{1}{6} +\frac{4}{3} +(-\frac{1}{6})\neq 1$ ，则点 $A,B,C,D$ 不共面， $C$ 错误；
> >
> > 对于 D， $AB=(1,2,-2)$ ， $AC=(2,m,n-2)$ ，由点 A, B, C 共线，得 $AB // AC$
> >
> > 则 $\frac{2}{1} = \frac{m}{2} = \frac{n - 2}{-2}$ ，解得 $m = 4, n = -2$ ， $m + n = 2$ ，D正确·
> >
> > 故选 **C**
