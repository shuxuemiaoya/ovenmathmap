> [!faq]- 《专题07 直线交点坐标与各种距离全方位总结（九大题型）（高效培优期中专项训练）数学人教A版2019高二选择性必修第一册》官方解析
>
> > [!success]- **【答案】** (1)a=3； (2) 存在点 $P\left(\frac{1}{9}, \frac{37}{18}\right)$ .
>
> > [!note]- **【分析】**
> > （ $^{1}$ ）由两平行线间距离公式代入数据即可求解；
> >
> > (2) 由点在第一象限，结合点到线的距离公式列出等式求解即可·
>
> > [!note]- **【解析】**
> > （1）∵ $l_{2}:2x-y-\frac{1}{2}=0$ 与 间的距离为 $d = \frac{\left|a - \left(-\frac{1}{2}\right)\right|}{\sqrt{2^2 + (-1)^2}} = \frac{\left|a + \frac{1}{2}\right|}{\sqrt{5}} = \frac{7\sqrt{5}}{10}$ 即 $\left|a + \frac{1}{2}\right| = \frac{7}{2}$ ， $\because a > 0$ ， $\therefore a = 3$
> >
> > (2) 假设存在，设点 $P(x_{0}, y_{0})$
> >
> > 由条件 ② 知，点 P 在与 $l_{1}$ ， $l_{2}$ 平行的直线 $l^{\prime}2x - y + c = 0$ 上，
> >
> > 且 $\frac{|c - 3|}{\sqrt{5}} = \frac{1}{2}\frac{\left|c + \frac{1}{2}\right|}{\sqrt{5}}$
> >
> > $$
> > \therefore c = \frac {1 3}{2} \text {或} c = \frac {1 1}{6}
> > $$
> >
> > $\therefore 4x_{0} - 2y_{0} + 13 = 0$ 或 $12x_{0} - 6y_{0} + 11 = 0$
> >
> > 由条件 ③ 知， $\frac{\left|2x_{0}-y_{0}+3\right|}{\sqrt{5}}=\frac{\sqrt{2}}{\sqrt{5}}\frac{\left|x_{0}+y_{0}-1\right|}{\sqrt{2}}$
> >
> > $\therefore \left|2x_{0} - y_{0} + 3\right| = \left|x_{0} + y_{0} - 1\right|$ 即 $x_0 - 2y_0 + 4 = 0$ 或 $3x_0 + 2 = 0$
> >
> > 因为点 $P$ 在第一象限， $\therefore x_0 > 0, 3x_0 + 2 = 0$ （舍），
> >
> > $\therefore \left\{ \begin{array}{l}x_{0} - 2y_{0} + 4 = 0\\ 4x_{0} - 2y_{0} + 13 = 0 \end{array} \right.$ 或 $\left\{ \begin{array}{l}x_0 - 2y_0 + 4 = 0\\ 12x_0 - 6y_0 + 11 = 0 \end{array} \right.$
> >
> > 解得 $\left\{\begin{aligned}x_{0}&=-3\\ y_{0}&=\frac{1}{2}\end{aligned}\right.$ （舍）， $\left\{\begin{aligned}x_{0}&=\frac{1}{9}\\ y_{0}&=\frac{37}{18}\end{aligned}\right.$
> >
> > 所以存在点 $P\left(\frac{1}{9}, \frac{37}{18}\right)$ 同时满足①②③.
