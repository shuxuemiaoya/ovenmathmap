> [!faq]- 《专题07 直线交点坐标与各种距离全方位总结（九大题型）（高效培优期中专项训练）数学人教A版2019高二选择性必修第一册》官方解析
>
> > [!success]- **【答案】** $\left[\sqrt{3},\sqrt{5}\right]$
>
> > [!note]- **【分析】**
> > 设点 $P(x,y)$ ，由距离公式得到 $x^{2} + y^{2} + 1 = \sqrt{16 + 4x^{2}}$ ，则 $\left|OP\right| = \sqrt{\sqrt{16 + 4x^2} - 1}$ ，求出 $x^{2}$ 的取值范围，即可得解
>
> > [!note]- **【解析】**
> > 设点 $P(x,y)$ ，依题意可得 $\left[(x + 1)^2 +y^2\right]\cdot \left[(x - 1)^2 +y^2\right] = 16$
> >
> > 即 $\left[\left(x^{2} + y^{2} + 1\right) + 2x\right] \cdot \left[\left(x^{2} + y^{2} + 1\right) - 2x\right] = 16$
> >
> > 则 $x^{2} + y^{2} + 1 = \sqrt{16 + 4x^{2}}$
> >
> > 所以 $\left|OP\right|=\sqrt{x^{2}+y^{2}}=\sqrt{\sqrt{16+4x^{2}}-1}$
> >
> > 因为 $16 = \left[(x + 1)^2 + y^2\right] \cdot \left[(x - 1)^2 + y^2\right]$ （ $x - 1)^2(x + 1)^2 = (x^2 - 1)^2$ ，当且仅当 $y = 0$ 时取等号，
> >
> > 由 $\left(x^{2} - 1\right)^{2}\leq 16$ ，解得 $0\leq x^{2}\leq 5$ ，所以 $16\leq 16 + 4x^{2}\leq 36$ ，则 $4\leq \sqrt{16 + 4x^2}\leq 6$
> >
> > 所以 $\left|OP\right|=\sqrt{\sqrt{16+4x^{2}}-1}\in\left[\sqrt{3},\sqrt{5}\right]$ .
> >
> > 故答案为： $\left[\sqrt{3},\sqrt{5}\right]$
