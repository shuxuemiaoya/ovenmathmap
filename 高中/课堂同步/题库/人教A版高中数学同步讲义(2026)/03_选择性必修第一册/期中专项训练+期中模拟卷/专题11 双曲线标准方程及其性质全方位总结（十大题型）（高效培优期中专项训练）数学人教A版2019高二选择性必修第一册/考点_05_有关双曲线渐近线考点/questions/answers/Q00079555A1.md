> [!faq]- 《专题11 双曲线标准方程及其性质全方位总结（十大题型）（高效培优期中专项训练）数学人教A版2019高二选择性必修第一册》官方解析
>
> > [!success]- **【答案】** ABC
>
> > [!note]- **【分析】**
> > 分别将 $m = 4,3,2,1$ 代入 $C:(m - 2)x^{2} + (6 - m)y^{2} = (m - 2)(6 - m)$ ，得到不同的方程，再根据方程的特点，说明曲线类型即可判断·
>
> > [!note]- **【解析】**
> > 对于A，当 $m = 4$ 时，曲线 $C:2x^{2} + 2y^{2} = 4$ ，即 $x^{2} + y^{2} = 2$ ，所以曲线 $C$ 表示的是以原点为圆心，半径为 $\sqrt{2}$ 的圆，故A正确；
> > 对于B，当 $m = 3$ 时， $C:x^{2} + 3y^{2} = 3$ ，即 $\frac{x^2}{3} +y^2 = 1$ ，所以 $a = \sqrt{3},b = 1,c = \sqrt{2}$ ，所以 $e = \frac{c}{a} = \frac{\sqrt{2}}{\sqrt{3}} = \frac{\sqrt{6}}{3}$ 所以曲线 $C$ 表示离心率为 $\frac{\sqrt{6}}{3}$ 的椭圆，故B正确；
> >
> > 对于 C，当 m=2 时， $C:4y^{2}=0$ ，即 y=0，
> >
> > 所以曲线 C 表示 x 轴所在的直线，故 C 正确；
> >
> > 对于D，当 $m = 1$ 时， $C: - x^{2} + 5y^{2} = -5$ ，即 $\frac{x^2}{5} -y^2 = 1$
> >
> > 所以 $a = \sqrt{5}, b = 1$ ，所以曲线 $C$ 表示渐近线为 $y = \pm \frac{\sqrt{5}}{5} x$ 的双曲线，故 $\mathbb{D}$ 错误
> >
> > 故选 **ABC**.
