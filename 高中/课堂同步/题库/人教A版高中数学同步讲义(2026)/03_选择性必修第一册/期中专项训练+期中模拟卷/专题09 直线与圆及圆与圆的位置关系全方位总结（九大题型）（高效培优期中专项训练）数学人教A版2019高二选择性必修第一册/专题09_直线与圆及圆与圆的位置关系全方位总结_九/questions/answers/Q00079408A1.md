> [!faq]- 《专题09 直线与圆及圆与圆的位置关系全方位总结（九大题型）（高效培优期中专项训练）数学人教A版2019高二选择性必修第一册》官方解析
>
> > [!success]- **【答案】** $\sqrt{2} \leq b < 2$
>
> > [!note]- **【分析】**
> > 根据直线与圆相切时满足的关系，以及点到直线的距离公式，准确画出曲线方程所表示曲线形状解决问题·
>
> > [!note]- **【解析】**
> > 曲线 $x = -\sqrt{2 - y^{2}}$ 即 $x^{2} + y^{2} = 2(x \leq 0)$ ,
> >
> > ![](../../../images/questions/part-001/477f58a5b1964dfe2a6683174c37157849493ec6a151bc5973346b8d1cb48318.jpg)
> >
> > 如图所示，当即 $b = \sqrt{2}$ 时，直线 $y = x + b$ 与曲线 $x = -\sqrt{2 - y^2}$ 有两个公共点，
> >
> > 直线向左上移动，当直线 $y = x + b$ 与曲线 $x = -\sqrt{2 - y^2}$ 相切时，有一个公共点，
> >
> > 原点到直线 $y = x + b$ 的距离为半径，即 $\frac{|b|}{\sqrt{2}} = \sqrt{2}$ ，解得 $b = 2$
> >
> > 所以，当有两个公共点时 $\sqrt{2} \leq b < 2$
> >
> > 故答案为： $\sqrt{2} \leq b < 2$
