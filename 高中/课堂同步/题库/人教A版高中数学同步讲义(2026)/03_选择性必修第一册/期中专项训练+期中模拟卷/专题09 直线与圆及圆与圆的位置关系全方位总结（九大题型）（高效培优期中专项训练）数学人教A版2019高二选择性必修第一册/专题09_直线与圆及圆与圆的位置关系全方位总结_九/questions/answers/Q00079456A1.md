> [!faq]- 《专题09 直线与圆及圆与圆的位置关系全方位总结（九大题型）（高效培优期中专项训练）数学人教A版2019高二选择性必修第一册》官方解析
>
> > [!success]- **【答案】** ABC
>
> > [!note]- **【分析】**
> > 利用圆与圆相交可得出关于 r 的不等式组，解出 r 的取值范围，可判断 A 选项；
> >
> > 根据直线 $x = -1$ 与两圆都相切，求出 $r$ 的值，可判断 ${}^{\mathrm{B}}$ 选项；
> >
> > 求出两圆的公共弦所在直线的方程，分析可知，当公共弦过原点时，公共弦最长，求出 $r$ 的值，可判断 $\mathbb{C}$
> >
> > 选项；
> >
> > 根据公共弦方程求出 r 的值，可判断 D 选项·
>
> > [!note]- **【解析】**
> > 圆 O 的圆心为原点，半径为 1，圆 C 的圆心为 $C(3,4)$ ，半径为 r，
> >
> > 对于 $\mathsf{A}$ 选项，因为 $|OC| = \sqrt{3^2 + 4^2} = 5$
> >
> > 若两圆相交，则 $\left|r-1\right|<\left|OC\right|<r+1$ ，即 $\left|r-1\right|<5<r+1$ ，
> >
> > 因为 r > 0 ，解得 4 < r < 6 ，A 对；
> >
> > 对于 $^{B}$ 选项，原点到直线x=-1的距离为1，则直线x=-1与圆O相切，
> >
> > 若直线 x = -1 与圆 C 相切，则 $r = 3 + 1 = 4$ ，
> >
> > 即当 r=4 时，直线 x=-1 是两圆的公切线， $^{B}$ 对；
> >
> > 对于 C 选项，将两圆方程作差可得 $6x + 8y + r^{2} - 26 = 0$ ，
> >
> > 当直线 $6x + 8y + r^2 - 26 = 0$ 过原点时，即 $r^2 = 26$ 时，即当 $r = \sqrt{26} \in (4,6)$ 时，
> >
> > 两圆的相交弦的弦长取最大值 $^{2}$ ，且此时两圆的相交弦为圆O的一条直径， $^{c}$ 对；
> >
> > 对于 $\mathbf{D}$ 选项，若两圆的相交弦方程为 $3x + 4y - 11 = 0$
> >
> > 则有 $\frac{6}{3} = \frac{8}{4} = \frac{r^2 - 26}{-11}$ ，因为 $r > 0$ ，解得 $r = 2\notin (4,6)$ ，不合乎题意，D错.
> >
> > 故选 **ABC**.
