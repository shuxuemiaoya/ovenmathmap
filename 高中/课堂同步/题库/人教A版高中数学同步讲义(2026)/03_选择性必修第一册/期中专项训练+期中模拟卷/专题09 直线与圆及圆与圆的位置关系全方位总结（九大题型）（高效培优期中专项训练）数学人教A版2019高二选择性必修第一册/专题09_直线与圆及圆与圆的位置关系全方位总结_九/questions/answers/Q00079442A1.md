> [!faq]- 《专题09 直线与圆及圆与圆的位置关系全方位总结（九大题型）（高效培优期中专项训练）数学人教A版2019高二选择性必修第一册》官方解析
>
> > [!success]- **【答案】** (1) $(x-1)^{2}+(y+2)^{2}=5$ (2) $\sqrt{6}$
>
> > [!note]- **【分析】**
> > （1）设圆 C 的一般方程为 $x^{2} + y^{2} + Dx + Ey + F = 0$ ，将 A, B, O 三点代入得到方程组，求出 D, E, F，即可得到圆 C 的方程；
> >
> > (2) 先求出圆心 C 到直线 l 的距离 d，再利用勾股定理求出弦长 MN，即可求出 $\Delta CMN$ 的面积.
>
> > [!note]- **【解析】**
> > （1）设圆 $C$ 的一般方程为 $x^{2} + y^{2} + Dx + Ey + F = 0$
> >
> > 将三点代入上式可得， $\left\{ \begin{array}{l}F = 0,\\ 4 + 2D + F = 0,\\ 1 + 1 - D - E + F = 0. \end{array} \right.$
> >
> > 解得 $D = -2, E = 4, F = 0$
> >
> > 所以圆 C 的一般方程为 $x^{2} + y^{2} - 2x + 4y = 0$
> >
> > 将其化为标准方程为 $(x-1)^{2}+(y+2)^{2}=5$ ;
> >
> > (2) 由 (1) 可知，圆心 $C(1, -2)$ ，半径 $r = \sqrt{5}$ .
> >
> > 则圆心 $C$ 到直线 $l$ 的距离为 $d = \frac{|1 + 2 - 1|}{\sqrt{2}} = \sqrt{2}$
> >
> > 所以 $\left|MN\right|=2\sqrt{r^{2}-d^{2}}=2\sqrt{\left(\sqrt{5}\right)^{2}-\left(\sqrt{2}\right)^{2}}=2\sqrt{3}$
> >
> > 故 $\triangle CMN$ 的面积为 $S_{\triangle CMN} = \frac{1}{2}\big|M N\big|\cdot d = \frac{1}{2}\times 2\sqrt{3}\times \sqrt{2} = \sqrt{6}$
