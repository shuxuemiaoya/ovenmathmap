> [!faq]- 《专题09 直线与圆及圆与圆的位置关系全方位总结（九大题型）（高效培优期中专项训练）数学人教A版2019高二选择性必修第一册》官方解析
>
> > [!success]- **【答案】** $^{(1)}$ P(0,0)或 $P\left(-\frac{8}{5},\frac{4}{5}\right)$ (2) 存在， $(0,2)$ ， $\left(-\frac{4}{5},\frac{2}{5}\right)$
>
> > [!note]- **【分析】**
> > （1）设 $P(-2b, b)$ ，解方程 $\left|MP\right| = \sqrt{(0 + 2b)^2 + (2 - b)^2} = 2$ ，即得解；
> >
> > (2) 求出圆 N 方程： $(2x - y + 2)b + (x^{2} + y^{2} - 2y) = 0$ ，解方程 $\left\{\begin{aligned}&2x - y + 2 = 0\\ &x^{2} + y^{2} - 2y = 0\end{aligned}\right.$ 即得解.
>
> > [!note]- **【解析】**
> > （1）由题可知，圆 $M$ 的半径 $r = 1$ ，设 $P(-2b,b)$
> >
> > 因为 PA 是圆 M 的一条切线，所以 $\angle MAP = 90^{\circ}$ ，
> >
> > 四边形面积 $= r \times |PA| = \sqrt{3}$ ，于是 $|PA| = \sqrt{3}$
> >
> > 所以 $\left|MP\right|=\sqrt{\left(0+2b\right)^{2}+\left(2-b\right)^{2}}=\sqrt{\left|AM\right|^{2}+\left|AP\right|^{2}}=2$
> >
> > 解得 b=0 或 $b=\frac{4}{5}$
> >
> > 所以点 $P$ 的坐标为 $P(0,0)$ 或 $P\left(-\frac{8}{5}, \frac{4}{5}\right)$
> >
> > (2) 设 $P(-2b, b)$ ，因为 $\angle MAP = 90^{\circ}$ ，
> >
> > 所以经过 A、P、M 三点的圆 N 以 MP 为直径，
> >
> > 其方程为 $\left(x + b\right)^2 +\left(y - \frac{b + 2}{2}\right)^2 = \frac{4b^2 + (b - 2)^2}{4}$
> >
> > 即 $(2x - y + 2)b + (x^{2} + y^{2} - 2y) = 0$
> >
> > 由 $\left\{\begin{aligned}&2x-y+2=0\\ &x^{2}+y^{2}-2y=0\end{aligned}\right.$ ，解得 $\left\{\begin{aligned}&x=0\\ &y=2\end{aligned}\right.$ 或 $\left\{\begin{aligned}&x=-\frac{4}{5}\\ &y=\frac{2}{5}\end{aligned}\right.$
> >
> > 所以圆过定点 $(0,2)$ ， $\left(-\frac{4}{5},\frac{2}{5}\right)$
> >
