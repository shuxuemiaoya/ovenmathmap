> [!faq]- 《高一数学下学期第一次月考（人教A版必修第二册第六章平面向量~第七章复数，高效培优·提升卷）》官方解析
>
> > [!success]- **【答案】** A. A, B, D B. A, B, C C. B, C, D D. A, C, D
>
> > [!note]- **【解析】**
> > 若向量 $a, b$ 共线，则 $AB, BC, CD$ 共线，此时 $A, B, C, D$ 共线，
> >
> > 当向量 $a, b$ 不共线时，
> >
> > 对于 A 选项， $BD = BC + CD = -5a + 6b + 7a - 2b = 2a + 4b = 2AB$ ，所以 A, B, D 三点共线，A 正确；
> >
> > 对于 B 选项，设 $AB = \mu BC$ ，则 $a + 2b = \mu (-5a + 6b)$ ，即 $\left\{\begin{aligned}-5\mu &=1 \\ 6\mu &=2\end{aligned}\right.$ 无解，B 错误；
> >
> > 对于 C 选项，设 $BC = mCD$ ，则 $-5a + 6b = m(7a - 2b)$ ，即 $\left\{\begin{aligned}7m &= -5 \\ -2m &= 6\end{aligned}\right.$ ，无解，C 错误；
> >
> > 对于 D 选项， $AC = AB + BC = a + 2b - 5a + 6b = -4a + 8b$ ，设 $AC = nCD$ ，
> >
> > 即 $-4a + 8b = n(7a - 2b)$ ，即 $\left\{\begin{aligned}7n &= -4 \\ -2n &= 8\end{aligned}\right.$ ，无解，D 错误。
> >
> > 故选 **A**
