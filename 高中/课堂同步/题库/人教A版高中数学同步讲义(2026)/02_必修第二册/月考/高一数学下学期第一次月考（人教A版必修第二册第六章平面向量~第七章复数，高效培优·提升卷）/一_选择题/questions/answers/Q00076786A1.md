> [!faq]- 《高一数学下学期第一次月考（人教A版必修第二册第六章平面向量~第七章复数，高效培优·提升卷）》官方解析
>
> > [!success]- **【答案】** A. $z_{1}z_{2} = OZ_{1} \cdot OZ_{2}$ B. $(z_{1} + z_{2})^{2} = (OZ_{1} + OZ_{2})^{2}$ C. $|z_{1}| |z_{2}| = |OZ_{1}| |OZ_{2}|$ D. $|z_{1}z_{2}| = |OZ_{1} \cdot OZ_{2}|$
>
> > [!note]- **【解析】**
> > 设复数 $z_{1} = 1, z_{2} = \mathrm{i}$ ，则在复平面上对应的向量分别为 $OZ_{1} = (1,0), OZ_{2} = (0,1)$
> >
> > 所以 $z_{1}z_{2}=i, OZ_{1}\cdot OZ_{2}=0+0=0$ ，A 选项错误；
> >
> > 所以 $\left|z_{1}z_{2}\right|=\left|i\right|=1,\left|\overline{OZ_{1}}\cdot\overline{OZ_{2}}\right|=0$ ，D选项错误；
> >
> > 所以 $z_{1} + z_{2} = 1 + \mathrm{i},\overline{OZ}_{1} + \overline{OZ}_{2} = (1,1)$ ， $\left(z_1 + z_2\right)^2 = (1 + \mathrm{i})^2 = 2\mathrm{i},\left(\overline{OZ}_1 + \overline{OZ}_2\right)^2 = \left(\sqrt{1 + 1}\right)^2 = 2$ ，B选项错误；设复数 $z_{1} = a + b\mathrm{i},z_{2} = c + d\mathrm{i},a,b,c,d\in \mathbf{R}$ ，则在复平面上对应的向量分别为 $OZ_{1} = (a,b),OZ_{2} = (c,d)$ $|z_1||z_2| = \sqrt{a^2 + b^2}\times \sqrt{c^2 + d^2},\left|\overline{OZ}_1\right|\left|\overline{OZ}_2\right| = \sqrt{a^2 + b^2}\times \sqrt{c^2 + d^2}$ ，C选项正确；
> >
> > 故选 **C**.
