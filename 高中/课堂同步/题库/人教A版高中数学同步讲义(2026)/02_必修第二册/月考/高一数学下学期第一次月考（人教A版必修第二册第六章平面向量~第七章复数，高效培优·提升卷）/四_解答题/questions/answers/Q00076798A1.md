> [!faq]- 《高一数学下学期第一次月考（人教A版必修第二册第六章平面向量~第七章复数，高效培优·提升卷）》官方解析
>
> > [!success]- **【答案】** (1) $A=\frac{\pi}{3}$ (2) $\left(\frac{\sqrt{3}}{2},\sqrt{3}\right]$ (3) $\frac{3\sqrt{3}}{4}$
>
> > [!note]- **【解析】**
> > （1）选择条件①，因为 $A + C = \pi - B$
> >
> > 由正弦定理 $\frac{a}{\sin A} = \frac{b}{\sin B}$ ，得 $b = \frac{a\sin B}{\sin A}$ ，将 $b = \frac{a\sin B}{\sin A}$ 代入条件①，
> >
> > 则 $\frac{a\sin B}{\sin A}\sin \left(A + \frac{\pi}{3}\right) = a\sin (\pi -B)$
> >
> > 因 $a \neq 0$ ， $\sin (\pi - B) = \sin B$ ，约去 $a \sin B (\sin B \neq 0)$ ，得 $\frac{\sin \left(A + \frac{\pi}{3}\right)}{\sin A} = 1$ ，
> >
> > 展开 $\sin \left(A + \frac{\pi}{3}\right)$ ，即 $\frac{1}{2}\sin A + \frac{\sqrt{3}}{2}\cos A = \sin A$
> >
> > 移项得 $\frac{\sqrt{3}}{2}\cos A=\frac{1}{2}\sin A$ ，即 $\tan A=\sqrt{3}$ ，又 $A\in(0,\pi)$ ，所以 $A=\frac{\pi}{3}$ ；
> >
> > 选择条件②，根据题意可知， $\frac{2\cos A}{bc}=\frac{\cos B}{ab}+\frac{\cos C}{ac}$
> >
> > 等式两边同乘 $abc$ ，得 $2a\cos A = c\cos B + b\cos C$ ，由正弦定理，则 $2\sin A\cos A = \sin (B + C)$
> >
> > 因为 $B + C = \pi - A$ ， $\sin(B + C) = \sin A$ ，所以 $2\sin A\cos A = \sin A$ ，
> >
> > 因 $A \in (0, \pi)$ ， $\sin A \neq 0$ ，约去 $\sin A$ ，得 $2\cos A = 1$ ，故 $A = \frac{\pi}{3}$ ；
> >
> > 选择条件③，由余弦定理 $\cos B = \frac{a^{2} + c^{2} - b^{2}}{2ac}$
> >
> > 代入条件③，则 $2a\cdot\frac{a^{2}+c^{2}-b^{2}}{2ac}+b=2c\Rightarrow\frac{a^{2}+c^{2}-b^{2}}{c}+b=2c$ ，化简得： $a^{2}=b^{2}+c^{2}-bc$ ，
> >
> > 对比余弦定理 $a^2 = b^2 + c^2 - 2bc\cos A$ ，得 $2\cos A = 1$ ，即 $\cos A = \frac{1}{2}$ ，因为 $A \in (0, \pi)$ ，所以 $A = \frac{\pi}{3}$ ；
> >
> > (2) 由 $A = \frac{\pi}{3}$ ，得 $B + C = \frac{2\pi}{3}$ ，即 $C = \frac{2\pi}{3} - B$
> >
> > $$
> > \sin B + \sin C = \sin B + \sin \left(\frac {2 \pi}{3} - B\right) = \sin B + \frac {\sqrt {3}}{2} \cos B + \frac {1}{2} \sin B
> > $$
> >
> > $= \frac{3}{2}\sin B + \frac{\sqrt{3}}{2}\cos B = \sqrt{3}\sin B\left(B + \frac{\pi}{6}\right)$
> >
> > 因为 $B \in \left(0, \frac{2\pi}{3}\right)$ ，所以 $B + \frac{\pi}{6} \in \left(\frac{\pi}{6}, \frac{5\pi}{6}\right)$ ， $\sin \left(B + \frac{\pi}{6}\right) \in \left(\frac{1}{2}, 1\right]$ ，
> >
> > 故 $\sin B + \sin C$ 的取值范围是 $\left(\frac{\sqrt{3}}{2}, \sqrt{3}\right]$ ;
> >
> > (3) 设 BC 中点为 D， $AD = \frac{\sqrt{13}}{2}$ ，AB = c = 3，AC = b，
> >
> > 由向量关系 $\overline{AD}=\frac{1}{2}\left(\overline{AB}+\overline{AC}\right)$ ，平方得 $\left|\overline{AD}\right|^{2}=\frac{1}{4}\left(\left|\overline{AB}\right|^{2}+2\overline{AB}\cdot\overline{AC}+\left|\overline{AC}\right|^{2}\right)$
> >
> > 即 $\frac{13}{4} = \frac{1}{4}\left(9 + 2\cdot 3\cdot b\cdot \cos \frac{\pi}{3} +b^2\right)$ ，即 $13 = 9 + 3b + b^{2}\Longrightarrow b^{2} + 3b - 4 = 0$ ，解得 $b = 1$ （舍负）
> >
> > 面积 $S=\frac{1}{2}bc\sin A=\frac{1}{2}\times1\times3\times\frac{\sqrt{3}}{2}=\frac{3\sqrt{3}}{4}.$
