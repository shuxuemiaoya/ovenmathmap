> [!faq]- 《高一数学下学期第一次月考（人教A版必修第二册第六章平面向量~第七章复数，高效培优·提升卷）》官方解析
>
> > [!success]- **【答案】** (1) $\frac{5}{6}$ (2) $\frac{1}{6}$
>
> > [!note]- **【解析】**
> > （1） $AO = mAB + nAC$ ， $(m, m \in \mathbb{R})$ ，因为 $B, O, D$ 三点共线，所以 $AO = mAB + (1 - m)AD$ ，又因为 $AD = 3DC$ ，所以 $AD = \frac{3}{4}AC$ ，则 $AO = mAB + \frac{3 - 3m}{4}AC$ 同理，因为 $C, O, E$ 三点共线，所以 $AO = nAC + (1 - n)AE$ ，又因为 $AE = 2EB$ ，所以 $AE = \frac{2}{3}AB$ ，则 $AO = nAC + \frac{2 - 2n}{3}AB$ ，根据平面向量基本定理，可得 $\begin{cases} m = \frac{2 - 2n}{3} \\ \frac{3 - 3m}{4} = n \end{cases}$ ，解得 $\begin{cases} m = \frac{1}{3} \\ n = \frac{1}{2} \end{cases}$ ，所以 $m + n = \frac{1}{3} + \frac{1}{2} = \frac{5}{6}$ .
> >
> > (2) 延长 $AO$ 与 $BC$ 交于点 $F$ ，因为 $B, F, C$ 三点共线，所以 $\overline{AF} = t\overline{AB} + (1 - t)\overline{AC}$ ，又因为 $\overline{AO} = \frac{1}{3}\overline{AB} + \frac{1}{2}\overline{AC}$ ，且 $\overline{AF} // AO$ ，所以 $\overline{AO} = \lambda AF$ ，即 $\frac{1}{3}\overline{AB} + \frac{1}{2}\overline{AC} = \lambda \left[t\overline{AB} + (1 - t)\overline{AC}\right] = \lambda t\overline{AB} + \lambda (1 - t)\overline{AC}$ ，所以 $\left\{\begin{array}{l}\lambda t = \frac{1}{3}\\ \lambda (1 - t) = \frac{1}{2}\end{array}\right.$ ，解得 $\left\{\begin{array}{l}t = \frac{2}{5}\\ \lambda = \frac{5}{6}\end{array}\right.$ ，所以 $\overline{AO} = \frac{5}{6}\overline{AF}$ ，则 $\overline{OF} = \frac{1}{6}\overline{AF}$ 所以 $\frac{S'}{S} = \frac{1}{6}$ .
