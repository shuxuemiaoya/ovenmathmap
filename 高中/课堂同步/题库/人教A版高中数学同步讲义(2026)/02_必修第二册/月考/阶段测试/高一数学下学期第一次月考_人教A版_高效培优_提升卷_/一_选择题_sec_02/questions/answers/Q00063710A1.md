> [!faq]- 《高一数学下学期第一次月考_人教A版_高效培优_提升卷_》官方解析
>
> > [!success]- **【答案】** A. $2, \frac{1}{2}$ B. $-3, -\frac{1}{3}$ C. $2, -\frac{1}{2}$ D. $-3, \frac{1}{3}$
>
> > [!note]- **【解析】**
> > 因为 $A, B, C$ 三点共线，则存在实数 $\lambda$ ，使 $AB = \lambda AC$
> >
> > 即 $\lambda_1a + b = \lambda (a + \lambda_2b)$ ，即 $\lambda_{1}a + b = \lambda a + \lambda \lambda_{2}b$
> >
> > 所以 $(\lambda_{1} - \lambda)a + (1 - \lambda \lambda_{2})b = 0$
> >
> > 又向量 $a, b$ 不共线，所以 $\left\{ \begin{array}{l} \lambda_1 - \lambda = 0 \\ 1 - \lambda \lambda_2 = 0 \end{array} \right.$ ，解得 $\lambda_1 \lambda_2 = 1$
> >
> > 所以实数 $\lambda_{1}, \lambda_{2}$ 的值互为倒数.
> >
> > 故选 **AB**
