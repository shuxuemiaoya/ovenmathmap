> [!faq]- 《高一数学下学期第一次月考_人教A版_高效培优_提升卷_》官方解析
>
> > [!success]- **【答案】** (1)1 (2)0 (3) $\left[\sqrt{3} - 1, \sqrt{3} + 1\right]$
>
> > [!note]- **【解析】**
> > （1）因为单位向量a,b满足 $a\cdot b=\lambda$
> >
> > 则 $\left(\vec{a}-\lambda b\right)^{2}=a^{2}-2\lambda a\cdot b+\lambda^{2}b^{2}=1-2\lambda^{2}++\lambda^{2}=1-\lambda^{2}\leq1$
> >
> > 当且仅当 $\lambda = 0$ 时等号成立，
> >
> > 故当 $\lambda = 0$ 时， $\left|a - \lambda b\right|$ 取得最大值为 1；
> >
> > (2) $ka$ 在 $(a-2\lambda b)$ 上投影的数量为 $\frac{(ka)\cdot(a-2\lambda b)}{|a-2\lambda b|}=\frac{\overrightarrow{ka^{2}}-2k\lambda a\cdot b}{\sqrt{a^{2}-4\lambda a\cdot b+4\lambda^{2}b^{2}}}=\frac{k-2k\lambda^{2}}{\sqrt{1-4\lambda^{2}+4\lambda^{2}}}=k-2k\lambda^{2}=k$
> >
> > 又 k > 0 ，则得 $1 - \lambda^{2} = 1$ ，所以 $\lambda^{2} = 0$ ；
> >
> > (3) 设 $\left|c\right|=m$ 0 $\cos b, c=n\in[-1,1]$
> >
> > 则 $\left(c + b\right)\cdot \left(c + 2b\right) = c^2 +3b\cdot c + 2b^2 = m^2 +3mn + 2$
> >
> > $$
> > \left| \overrightarrow {c + b} \right| = \sqrt {m ^ {2} + 2 m n + 1} \left| c + 2 b \right| = \sqrt {m ^ {2} + 4 m n + 4}
> > $$
> >
> > 因 $c + b, c + 2b = \frac{\pi}{6}$
> >
> > 故 $\cos\left\langle c+b,c+2b\right\rangle=\frac{\left|m^{2}+3mn+2\right|}{\sqrt{m^{2}+2mn+1}\cdot\sqrt{m^{2}+4mn+4}}=\cos\frac{\pi}{6}=\frac{\sqrt{3}}{2}$
> >
> > 整理得 $12m^{2}n^{2} + 6mn(m^{2} + 2) + m^{4} + m^{2} + 4 = 0$
> >
> > 设函数 $f(n)=12m^{2}n^{2}+6m(m^{2}+2)n+m^{4}+m^{2}+4=0$
> >
> > 则 $f(n)$ 在区间 $[-1,1]$ 上存在零点，则 $\Delta = 36m^2(m^2 + 2)^2 - 48m^2(m^4 + m^2 + 4) = 0$
> >
> > 即 $12m^{2}\left(-m^{4} + 8m^{2} - 4\right) = 0$ ，解得 $4 - 2\sqrt{3}\leq m^2\leq 4 + 2\sqrt{3}$ ，即 $\sqrt{3} -1\leq m\leq \sqrt{3} +1$
> >
> > 又 $f(0) > 0$ ， $f\left(-\frac{m^2 + 2}{4m}\right) = f(x)_{\min} \leq 0$
> >
> > 且当 $\sqrt{3} - 1 \leq m \leq \sqrt{3} + 1$ 时， $-\frac{m^2 + 2}{4m} + 1 = \frac{-m^2 + 4m - 2}{4m} > 0$ ，即 $-1 < -\frac{m^2 + 2}{4m} < 0$
> >
> > 即 $f(n)$ 在区间 $[-1, 1]$ 上存在零点，所以 $|c|$ 的取值范围为 $\left[\sqrt{3} - 1, \sqrt{3} + 1\right]$ .
