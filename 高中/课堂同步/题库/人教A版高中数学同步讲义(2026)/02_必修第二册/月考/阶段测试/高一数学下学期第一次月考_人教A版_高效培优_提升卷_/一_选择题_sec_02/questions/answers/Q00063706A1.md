> [!faq]- 《高一数学下学期第一次月考_人教A版_高效培优_提升卷_》官方解析
>
> > [!success]- **【答案】** ① $AC - BD + CD + BA = 0$ ②若 $AB = CD$ ，则 A, B, C, D 四点构成平行四边形 ③若平面向量 $a$ 与平面向量 $b$ 相等，则向量 $a$ 与 $b$ 是始点与终点都相同的向量 ④向量 $a = (2,0)$ 与 $b = (1,1)$ 可以作为平面内所有向量的一组基底 ⑤若两非零向量 $\vec{a}$ ， $\vec{b}$ 满足 $|\vec{a}|=|\vec{b}|=|\vec{a}-\vec{b}|$ ，则 $\vec{a}$ 与 $\vec{a}+\vec{b}$ 的夹角是 $30^{\circ}$ A. 2个 B. 3个 C. 4个 D. 5个
>
> > [!note]- **【解析】**
> > 由已知得： $AC + CD + DB + BA = 0$ ，①对；
> >
> > 若 $AB = CD$ ，则 $A, B, C, D$ 四点可以构成平行四边形或者 $A, B, C, D$ 四点共线，故②错误，
> >
> > 若平面向量 $a$ 与平面向量 $b$ 相等，则始点相同时，终点必须相同，始点不同时终点也不相同，故③错误，
> >
> > 因为 $2 \times 1 \neq 0 \times 1$ ，故 $a$ 与 $b$ 不共线，可作为基底，故④正确，
> >
> > 设 $|\vec{a}| = |\vec{b}| = |\vec{a} -\vec{b}| = 1$
> >
> > 则 $|\vec{a} -\vec{b}|^2 = \vec{a}^2 +\vec{b}^2 -2\vec{a}\cdot \vec{b} = 2 - 2\vec{a}\cdot \vec{b} = 1\Rightarrow \vec{a}\cdot \vec{b} = \frac{1}{2}$
> >
> > 所以 $\left|\vec{a}+\vec{b}\right|^{2}=\vec{a}^{2}+\vec{b}^{2}+2\vec{a}\cdot\vec{b}=3\Rightarrow\left|\vec{a}+\vec{b}\right|=\sqrt{3}$ ，设 $\vec{a}$ 与 $\vec{a}+\vec{b}$ 的夹角为 $\alpha$ ，
> >
> > 则 $\cos\alpha=\frac{\overrightarrow{a}\cdot\left(a+b\right)}{\left|a\right|\left|a+b\right|}=\frac{\overrightarrow{a^{2}}+a\cdot b}{\left|a\right|\left|a+b\right|}=\frac{\frac{3}{2}}{\sqrt{3}}=\frac{\sqrt{3}}{2}$ ，即 $\alpha=30^{\circ}$ ，⑤正确.
> >
> > 故选：B
> >
> > 7. VABC 的三个内角 A, B, C 对应的三条边分别为 a, b, c，且 $a \sin \frac{A + C}{2} = b \sin A, D$ 为 AC 的中点， $BD = \frac{1}{2}$
> >
> > 则 $a - c$ 的取值范围为（ ）A. $(-1,1]$ B. $(-1,2]$ C. $(-1,2)$ D. $(-1,1)$
> >
> > 【答案】D
> >
> > 【详解】在VABC中，由 $a\sin\frac{A+C}{2}=b\sin A$ 及正弦定理，得 $\sin A\sin\frac{A+C}{2}=\sin B\sin A$ ，而 $\sin A>0$ ，则 $\sin(\frac{\pi}{2}-\frac{B}{2})=\sin B$ ，即 $\cos\frac{B}{2}=2\sin\frac{B}{2}\cos\frac{B}{2}$ ，
> >
> > 由 $0 < \frac{B}{2} < \frac{\pi}{2}$ ，得 $\cos \frac{B}{2} > 0$ ，因此 $\sin \frac{B}{2} = \frac{1}{2}$ ， $\frac{B}{2} = \frac{\pi}{6}$ ，则 $B = \frac{\pi}{3}$
> >
> > 由 $D$ 是 $AC$ 的中点，得 $2\overline{BD} = \overline{BC} +\overline{BA}$ ，两边平方得 $4\overline{BD}^2 = a^2 +c^2 +2ac\cos B$
> >
> > 而 $BD = \frac{1}{2}$ ，则 $1 = a^2 + c^2 + ac$ 2ac + ac = 3ac，当且仅当 $a = c$ 时取等号，
> >
> > 因此 $0 < ac \leq \frac{1}{3}$ ， $1 = (a - c)^2 + 3ac$ ， $0 \leq (a - c)^2 = 1 - 3ac < 1$ ，解得 $-1 < a - c < 1$ ，
> >
> > 所以 a-c 的取值范围为 $(-1,1)$ .
> >
> > 故选 **D**
