> [!faq]- 《高一数学下学期第一次月考_人教A版_高效培优_提升卷_》官方解析
>
> > [!success]- **【答案】** (1) $\frac{1}{3}$ (2) $\frac{2\sqrt{2}}{3}$ (3) $4\sqrt{3}+4$
>
> > [!note]- **【解析】**
> > （1）因为 $c\cos A + (a - 3b)\cos C = 0$
> >
> > 由正弦定理得 $\sin C \cos A + (\sin A - 3 \sin B) \cos C = 0$
> >
> > 则 $3\sin B\cos C = \sin C\cos A + \cos C\sin A = \sin (A + C) = \sin (\pi -B) = \sin B$
> >
> > 因为 $B \in (0, \pi)$ ，则 $\sin B > 0$
> >
> > 故 $\cos C = \frac{1}{3}$
> >
> > (2) $\because \cos C = \frac{1}{3}$ , 且 $C \in (0, \pi)$ ,
> >
> > $\sin C = \sqrt{1 - \cos^2 C} = \sqrt{1 - \left(\frac{1}{3}\right)^2} = \frac{2\sqrt{2}}{3}$
> >
> > $\because \frac{a}{\sin A} = \frac{c}{\sin C}, a = 3\sqrt{3}, c = 6\sqrt{2}$
> >
> > $$
> > \frac {3 \sqrt {3}}{\sin A} = \frac {6 \sqrt {2}}{\frac {2 \sqrt {2}}{3}} \text {, 解得} \sin A = \frac {\sqrt {3}}{3},
> > $$
> >
> > $$
> > \begin{array}{c} A <   C, A \in \left(0, \frac {\pi}{2}\right) \\ \therefore a <   c \quad , \therefore \end{array} ,
> > $$
> >
> > $$
> > \therefore \cos A = \sqrt {1 - \sin^ {2} A} = \sqrt {1 - \left(\frac {\sqrt {3}}{3}\right) ^ {2}} = \frac {\sqrt {6}}{3},
> > $$
> >
> > $$
> > \sin 2 A = 2 \sin A \cos A = 2 \times \frac {\sqrt {3}}{3} \times \frac {\sqrt {6}}{3} = \frac {2 \sqrt {2}}{3}.
> > $$
> >
> > $$
> > S _ {\triangle A B C} = \frac {1}{2} a b \sin C = \frac {1}{2} \times \frac {2 \sqrt {2}}{3} a b = 4 \sqrt {2}, \therefore a b = 1 2, \tag {3}
> > $$
> >
> > 由余弦定理得 $2ab \cos C = a^{2} + b^{2} - c^{2}$
> >
> > $$
> > (a + b) ^ {2} - c ^ {2} = a ^ {2} + b ^ {2} - c ^ {2} + 2 a b = 2 a b (\cos C + 1) = 2 \times 1 2 \times \left(\frac {1}{3} + 1\right) = 3 2
> > $$
> >
> > 又 $a + b = \sqrt{3} c$ ， $\therefore 3c^{2} - c^{2} = 32$ ，则 $c = 4$
> >
> > $$
> > \therefore a + b = \sqrt {3} c = 4 \sqrt {3}
> > $$
> >
> > 于是VABC的周长 $L=a+b+c=4\sqrt{3}+4$
