> [!faq]- 《高一数学下学期第三次月考卷（人教A版必修第二册第六章~第九章，高效培优）》官方解析
>
> > [!success]- **【答案】** A. 若 $m, n \subset \alpha, m // \beta, n // \beta$ ，则 $\alpha // \beta$ B. 若 $\alpha \cap \beta = l, m // \alpha, m // \beta$ ，则 $m // l$ C. 若 $m \perp \alpha, \alpha \perp \beta$ ，则 $m // \beta$ D. 若 $\alpha \perp \beta, \alpha \cap \beta = l, m \perp l$ ，则 $m \perp \alpha$
>
> > [!note]- **【解析】**
> > 对于A，面面平行的判定定理要求 $m, n$ 相交，若 $m \parallel n$ ，则 $\alpha, \beta$ 可能相交，故A错误；对于B，过 $m$ 作平面 $\gamma$ 交 $\alpha$ 于 $a$ ，则 $m \parallel a$ ，过 $m$ 作平面 $\delta$ 交 $\beta$ 于 $b$ ，则 $m \parallel b$ ，故 $b \parallel a$ ，又 $a$ 不在平面 $\beta$ 内，又 $b \subset$ 平面 $\beta$ ，所以 $a \parallel \beta$ ，而 $\alpha \cap \beta = l, a \subset \alpha$ ，故 $a \parallel l$ ，故 $m \parallel l$ ，故B正确；对于C，若 $m \perp \alpha, \alpha \perp \beta$ ，则 $m \subset \beta$ 或 $m \parallel \beta$ ，故 $C$ 错误；
> >
> > 对于 D，若 $\alpha \perp \beta, \alpha \cap \beta = l, m \perp l$ ，如果 $m \notin \beta$ 或 $m \subset \alpha$ ，则不能判断 $m \perp \alpha$ ，故 D 错误.
