> [!faq]- 《高一数学下学期第三次月考卷（人教A版必修第二册第六章~第九章，高效培优）》官方解析
>
> > [!success]- **【答案】** (1)证明见解析(2) $\frac{a}{c+2b}\in\left(\frac{\sqrt{3}}{4},\frac{\sqrt{2}}{3}\right)$
>
> > [!note]- **【解析】**
> > （1）在VABC中，因为 $\frac{\sin C}{\sin B} = \frac{\sin^2C - \sin^2B}{\sin^2A} + 1$ ，由正弦定理可得， $\frac{c}{b} = \frac{c^2 - b^2 + a^2}{a^2}$
> >
> > 由余弦定理知， $b^{2}=a^{2}+c^{2}-2ac\cos B$ ，则 $\frac{c}{b}=\frac{2ac\cos B}{a^{2}}$ ，
> >
> > 所以 $a = 2b\cos B$ ，即 $\sin A = 2\sin B\cos B$ ，所以 $\sin A = \sin 2B$
> >
> > 所以 A = 2B 或 $A + 2B = \pi$ .
> >
> > 若 $A + 2B = \pi$ ，因为 $A + B + C = \pi$ ，所以 $B = C$ ，与已知条件矛盾，不满足.
> >
> > 故 $A = 2B$
> >
> > (2) 当 $V_{ABC}$ 为锐角三角形时， $0 < A < \frac{\pi}{2}, 0 < B < \frac{\pi}{2}, 0 < C < \frac{\pi}{2}$
> >
> > 即： $0 < B < \frac{\pi}{2}, 0 < 2B < \frac{\pi}{2}, 0 < \pi - 3B < \frac{\pi}{2}$ ，所以 $B \in \left( \frac{\pi}{6}, \frac{\pi}{4} \right)$ .
> >
> > $$
> > \frac {a}{c + 2 b} = \frac {\sin A}{\sin C + 2 \sin B} = \frac {\sin 2 B}{\sin 3 B + 2 \sin B} = \frac {\sin 2 B}{\sin (2 B + B) + 2 \sin B} = \frac {\sin 2 B}{\sin 2 B \cos B + \cos 2 B \sin B + 2 \sin B}
> > $$
> >
> > $$
> > \begin{array}{l} = \frac {\sin 2 B}{2 \sin B \cos^ {2} B + (1 - 2 \sin^ {2} B) \sin B + 2 \sin B} = \frac {\sin 2 B}{2 \sin B (1 - \sin^ {2} B) + (1 - 2 \sin^ {2} B) \sin B + 2 \sin B} \\ = \frac {\sin 2 B}{2 \sin B - 2 \sin^ {3} B + \sin B - 2 \sin^ {3} B + 2 \sin B} = \frac {2 \sin B \cos B}{5 \sin B - 4 \sin^ {3} B} = \frac {2 \cos B}{5 - 4 \sin^ {2} B} \\ = \frac {2 \cos B}{1 + 4 \cos^ {2} B} = \frac {2}{4 \cos B + \frac {1}{\cos B}}. \end{array}
> > $$
> >
> > 令 $t = \cos B$ ， $B\in \left(\frac{\pi}{6},\frac{\pi}{4}\right)$ ，则 $t\in \left(\frac{\sqrt{2}}{2},\frac{\sqrt{3}}{2}\right)$
> >
> > 令 $y = 4t + \frac{1}{t} = 4\left(t + \frac{1}{4t}\right)$ ，由对勾函数性质可知 $y = 4t + \frac{1}{t}$ 在 $\left(\frac{1}{2}, + \infty\right)$ 上单调增，
> >
> > 所以 $4t + \frac{1}{t}\in \left(3\sqrt{2},\frac{8\sqrt{3}}{3}\right)$ ，则 $\frac{1}{4t + \frac{1}{t}}\in \left(\frac{\sqrt{3}}{8},\frac{1}{3\sqrt{2}}\right)$
> >
> > 所以 $\frac{2}{4t + \frac{1}{t}}\in \left(\frac{\sqrt{3}}{4},\frac{\sqrt{2}}{3}\right)$ ，即 $\frac{2}{4\cos B + \frac{1}{\cos B}}\in \left(\frac{\sqrt{3}}{4},\frac{\sqrt{2}}{3}\right)$
> >
> > 所以 $\frac{a}{c + 2b} \in \left( \frac{\sqrt{3}}{4}, \frac{\sqrt{2}}{3} \right)$
