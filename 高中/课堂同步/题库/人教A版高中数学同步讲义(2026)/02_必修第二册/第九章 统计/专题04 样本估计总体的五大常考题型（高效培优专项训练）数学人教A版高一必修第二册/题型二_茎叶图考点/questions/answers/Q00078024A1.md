>
> > [!note]- **【分析】**
> > 由茎叶图计算极差、中位数、平均数分别判断 ABC，由数据的集中程度判断 D.
>
> > [!note]- **【解析】**
> > 对于 A，甲、乙班数学成绩的极差分别为 93 - 51 = 42, 92 - 51 = 41，故 A 正确；
> >
> > 对于B，甲、乙班数学成绩的中位数分别为 $\frac{73 + 73}{2} = 73, \frac{67 + 72}{2} = 69.5$ ，故B正确；
> >
> > 对于C，甲班数学成绩的平均数为 $\frac{1}{10}\left(51 + 60 + 62 + 63 + 73 + 73 + 76 + 81 + 82 + 93\right) = 71.4$
> >
> > 乙班数学成绩的平均数为 $\frac{1}{10}\left(51 + 52 + 63 + 63 + 67 + 72 + 81 + 82 + 83 + 92\right) = 70.6$
> >
> > 故C错误；
> >
> > 对于D，从茎叶图可以看出，甲班的数学成绩比乙班的数学成绩较为集中，即甲班数学成绩的方差比乙班小，故D正确；
> >
> > 故选 **C**.
