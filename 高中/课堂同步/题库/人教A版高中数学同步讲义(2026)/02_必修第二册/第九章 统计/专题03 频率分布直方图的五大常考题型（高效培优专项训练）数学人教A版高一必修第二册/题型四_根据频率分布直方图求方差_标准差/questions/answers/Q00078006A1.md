> [!faq]- 《专题03 频率分布直方图的五大常考题型（高效培优专项训练）数学人教A版高一必修第二册》官方解析
>
> > [!success]- **【答案】** (1)0.30; (2)1.1136.
>
> > [!note]- **【分析】**
> > （1）根据给定的频率分布直方图，利用各小矩形面积和为1求出a值作答.
> >
> > (2) 求出 100 户居民月均用水量的平均数，再列式计算方差作答.
>
> > [!note]- **【解析】**
> > （1）由频率分布直方图知，数据在 $[0,0.5),[0.5,1),[1,1.5),[1.5,2),[2,2.5),[2.5,3),[3,3.5),[3.5,4),[4,4.5]$ 的频率依次0.04,0.08,0.5a,0.21,0.25,0.5a,0.06,0.04,0.02，
> > 则由 $0.04 + 0.08 + 0.5a + 0.21 + 0.25 + 0.5a + 0.06 + 0.04 + 0.02 = 1$ ，解得 a = 0.30，
> > 所以直方图中 a 的值为 0.30.
> >
> > (2) 由频率分布直方图得 100 户居民月均用水量的平均数为： $\overline{x}=0.04\times0.25+0.08\times0.75+0.15\times1.25+0.21\times1.75+0.25\times2.25+0.15\times2.75+0.06\times3.25$ $+0.04\times3.75+0.02\times4.25=2.03$
> >
> > 所以这 100 户居民月均用水量的方差为：
> >
> > $s^2 = 0.04[0.3 + (0.25 - 2.03)^2] + 0.08[0.3 + (0.75 - 2.03)^2] + 0.15[0.3 + (1.25 - 2.03)^2]$ $+0.21[0.3 + (1.75 - 2.03)^2] + 0.25[0.4 + (2.25 - 2.03)^2] + 0.15[0.4 + (2.75 - 2.03)^2]$ $+0.06[0.4 + (3.25 - 2.03)^2] + 0.04[0.4 + (3.75 - 2.03)^2] + 0.02[0.4 + (4.25 - 2.03)^2] = 1.1136.$
