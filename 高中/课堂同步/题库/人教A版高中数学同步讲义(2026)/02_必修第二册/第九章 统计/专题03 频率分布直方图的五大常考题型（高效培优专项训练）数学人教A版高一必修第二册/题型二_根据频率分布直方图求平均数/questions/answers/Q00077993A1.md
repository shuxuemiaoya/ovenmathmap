> [!faq]- 《专题03 频率分布直方图的五大常考题型（高效培优专项训练）数学人教A版高一必修第二册》官方解析
>
> > [!success]- **【答案】** (1)n=100,20(个). (2)189750（元）.
>
> > [!note]- **【分析】**
> > （1）由质量分布在区间 $[275,325)$ 内的黄桃有16个结合频率分布直方图列方程求解 $n$ ，然后由各组的频率和为1列方程可求出 $x$ ，从而可求出质量分布在区间 $[425,475)$ 内的黄桃个数；
> >
> > (2) 根据频率分布直方图求出该村黄桃的单个质量的平均数，从而可估算出该村黄桃的总质量，进而可求出该村黄桃的销售收入.
>
> > [!note]- **【解析】**
> > （1）因为质量分布在区间[275,325)内的黄桃有16个，
> >
> > 所以 $\frac{16}{n} \times \frac{1}{50} = 0.0032$ ，解得 $n = 100$
> >
> > $50 \times (0.0010 + 0.0032 + 0.0048 + 0.0060 + x + 0.0010) = 1$ ，解得 x = 0.0040
> >
> > 则质量分布在区间 $[425,475)$ 内的黄桃个数为 $50nx = 20$ （个）.
> >
> > (2) 该村黄桃的单个质量的平均数为
> >
> > $$
> > 2 5 0 \times 0. 0 5 + 3 0 0 \times 0. 1 6 + 3 5 0 \times 0. 2 4 + 4 0 0 \times 0. 3 + 4 5 0 \times 0. 2 + 5 0 0 \times 0. 0 5 = 3 7 9. 5 (\text {克})
> > $$
> >
> > 故该村黄桃的总质量大约为 $379.5 \times 100000 = 37950$ （千克），
> >
> > 故估计该村黄桃的销售收入为 $37950 \times 5 = 189750$ （元）
