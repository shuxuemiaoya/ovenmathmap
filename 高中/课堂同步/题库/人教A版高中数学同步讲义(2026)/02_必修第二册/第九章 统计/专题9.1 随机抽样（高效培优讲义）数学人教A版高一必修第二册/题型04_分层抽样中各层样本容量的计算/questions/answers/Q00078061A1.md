> [!faq]- 《专题9.1 随机抽样（高效培优讲义）数学人教A版高一必修第二册》官方解析
>
> > [!success]- **【答案】** (1)24 架； (2) (i) 不能，需要知道这三个等级战机具体的个体数量 X, Y, Z，或者抽取样本的数量 m, n, l，估计 式见解析；（ii）证明见解析·
>
> > [!note]- **【分析】**
> > （1）由题设得 $\frac{21}{7} = \frac{N}{8}$ 求参数，即可得；
> >
> > (2) (i) 根据题意需要知道这三个等级战机具体的个体数量 X, Y, Z，或者抽取样本的数量 m, n, l
> >
> > 进而写出公式；（ii）按比例在各层抽取的且各层抽取的样本量分别为 $a$ 、 $b$ 、 $c$ ，得 $\frac{a}{A} = \frac{b}{B} = \frac{c}{C} = \frac{a + b + c}{A + B + C}$
> >
> > 应用分层等比例性质即可证·
>
> > [!note]- **【解析】**
> > （1）因为可用 $\frac{x_{n}}{n}$ 估计 $\frac{N}{n+1}$ ，所以 $\frac{21}{7}=\frac{N}{8}$ ，得 N=24，故敌军每年生产战机 $^{24}$ 架·
> >
> > (2) (i) 不能估计敌军所有现役战机的平均飞行高度，
> >
> > 需要知道这三个等级战机具体的个体数量 X，Y，Z，或者抽取样本的数量 m，n，l，
> >
> > 估计式为 $\frac{X}{X + Y + Z}\overline{x} +\frac{Y}{X + Y + Z}\overline{y} +\frac{Z}{X + Y + Z}\overline{z}$ 或 $\frac{m}{m + n + l}\overline{x} +\frac{n}{m + n + l}\overline{y} +\frac{l}{m + n + l}\overline{z}$
> >
> > (ii) 因为样本是按比例在各层抽取的且各层抽取的样本量分别为 $a$ 、 $b$ 、 $c$ ，
> >
> > 所以 $\frac{a}{A} = \frac{b}{B} = \frac{c}{C}$ ，则 $\frac{a}{A} = \frac{b}{B} = \frac{c}{C} = \frac{a + b + c}{A + B + C}$
> >
> > 所以 $\frac{a}{a + b + c} = \frac{A}{A + B + C}$ ， $\frac{b}{a + b + c} = \frac{B}{A + B + C}$ ， $\frac{c}{a + b + c} = \frac{C}{A + B + C}$
> >
> > 又因为样本平均数为 $\frac{a\overline{x} + b\overline{y} + c\overline{z}}{a + b + c} = \frac{a}{a + b + c}\overline{x} +\frac{b}{a + b + c}\overline{y} +\frac{c}{a + b + c}\overline{z}$
> >
> > 所以 $\frac{A}{A + B + C}\overline{x} +\frac{B}{A + B + C}\overline{y} +\frac{C}{A + B + C}\overline{z} = \frac{a}{a + b + c}\overline{x} +\frac{b}{a + b + c}\overline{y} +\frac{c}{a + b + c}\overline{z}.$
