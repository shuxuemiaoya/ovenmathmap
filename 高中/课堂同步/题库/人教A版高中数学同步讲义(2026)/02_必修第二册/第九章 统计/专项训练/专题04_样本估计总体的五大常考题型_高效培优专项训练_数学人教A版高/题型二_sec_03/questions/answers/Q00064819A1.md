> [!faq]- 《专题04_样本估计总体的五大常考题型_高效培优专项训练_数学人教A版高》官方解析
>
> > [!success]- **【答案】** $\frac{9}{4} / 2.25$
>
> > [!note]- **【分析】**
> > 结合茎叶图，由条件求出 $x, y$ ，由此可得 $a + b = 4$ ，再由基本不等式求 $\frac{1}{a} + \frac{4}{b}$ 的最小值。
>
> > [!note]- **【解析】**
> > 因为甲班成绩的中位数为81，故 $x = 1$ 。
> >
> > 因为乙班成绩的平均数是86，所以 $\frac{1}{7}(76 + 80 + 82 + 80 + y + 91 + 93 + 96) = 86$ 解方程得 $y = 4$ 。
> >
> > 因为 $G^2 = xy$ ，所以 $G^2 = 4$ ，又 $G$ 为正实数，所以 $G = 2$ 。
> >
> > 因为 $2G = a + b$ ，且 $a, b$ 为正实数，所以 $a + b = 4$ ， $a > 0, b > 0$ ，
> >
> > 从而 $\frac{1}{a} + \frac{4}{b} = \frac{(a + b)}{4} \cdot \left(\frac{1}{a} + \frac{4}{b}\right) = \frac{1}{4}\left(5 + \frac{b}{a} + \frac{4a}{b}\right) - \frac{9}{4}$ ，当且仅当 $a = \frac{4}{3}, b = \frac{8}{3}$ 时等号成立，
> >
> > 所以 $\frac{1}{a} + \frac{4}{b}$ 的最小值为 $\frac{9}{4}$ ，
> >
> > 故答案为： $\frac{9}{4}$ 。
