> [!faq]- 《专题9.2 用样本估计总体（高效培优讲义）数学人教A版高一必修第二册》官方解析
>
> > [!success]- **【答案】** (1) x = 0.075, 21 (2) 正常值为 $16.3 \sim 24$ ，存在差异，原因见解析 (3)23.8 1.32
>
> > [!note]- **【分析】**
> > （1）利用频率之和等于 $^{1}$ 建立等式求出x，用最高矩形的底边中点的坐标作为众数的估计值；
> >
> > (2) 利用频率分布直方图求百分位数的步骤分别算出第 $^{5}$ 百分位数和第 $^{85}$ 百分位数，即可确定BMI值的正
> >
> > 常范围，再利用样本的随机性来解释存在的差异；
> >
> > (3) 求出总体的平均数后，利用分层方差的公式进行求解即可.
>
> > [!note]- **【解析】**
> > （ $^{1}$ ）由频率分布直方图面积和为 $^{1}$ 可得
> >
> > $$
> > (0. 0 1 + 0. 1 0 0 + 0. 1 1 5 + 0. 1 2 5 + x + 0. 0 5 0 + 0. 0 2 5) \times 2 = 1 \quad x = 0. 0 7 5 \text {, 解得}
> > $$
> >
> > 由频率分布直方图知，BMI值在区间[20,22)内的频率最大，故取这个区间的组中值 $\frac{20 + 22}{2} = 21$ 作为样本众
> >
> > 数的估计值，并据此估计该市高中男生BMI值的众数为 $^{21}$ ；
> >
> > (2) 设第 $^{5}$ 百分位数为 x，因为前两组的频率之和为 0.02 + 0.2 = 0.22，所以第 $^{5}$ 百分位数 x ∈ [16,18)，
> >
> > 由 $0.02 + (x - 16) \times 0.1 = 0.05$ ，解得 $x = 16.3$ ，故第5百分位数为16.3。
> >
> > 前五组的频率之和为 $0.02 + 0.2 + 0.23 + 0.25 + 0.15 = 0.85$ ，故第85百分位数为24.
> >
> > 所以估计该市高中男生BMI的正常值为 $16.3\sim 24$ ，与中国高中男生BMI的正常值存在差异，
> >
> > 存在差异的原因是：由样本的随机性引起的．中国高中男生 BMI 值的样本容量较大，样本选取更广泛，更全
> >
> > 面，更具有代表性，故中国高中男生BMI的正常值更准确。
> >
> > (3) 落入区间 $[22,24)$ 中学生有： $1000 \times 0.075 \times 2 = 150$ 人，
> >
> > 落入区间[24,26)中学生有： $1000\times 0.05\times 2 = 100$ 人
> >
> > 故落入区间[22,26)的BMI值的平均数为： $\overline{\mu} = \frac{150}{250}\times 23 + \frac{100}{250}\times 25 = 23.8$
> >
> > 方差为： $s^2 = \frac{150}{250}\left[(23 - 23.8)^2 +0.2\right] + \frac{100}{250}\left[(25 - 23.8)^2 +0.6\right] = 1.32$
