> [!faq]- 《第九章 统计（高效培优单元自测·提升卷）数学人教A版高一必修第二册》官方解析
>
> > [!success]- **【答案】** C
>
> > [!note]- **【分析】**
> > 根据平均值的性质求得平均数，然后利用方差的概念求解即可判断各项·
>
> > [!note]- **【解析】**
> > 由题意可知， $\frac{x_{1}+x_{2}+x_{3}+x_{4}+x_{5}+x_{6}+x_{7}+x_{8}}{8}=x_{8}$ 所以 $x_{1} + x_{2} + x_{3} + x_{4} + x_{5} + x_{6} + x_{7} = 7x_{8}$ ，则 $\frac{x_{1} + x_{2} + x_{3} + x_{4} + x_{5} + x_{6} + x_{7}}{7} = x_{8}$ 所以数据 $x_{1}, x_{2}, x_{3}, x_{4}, x_{5}, x_{6}, x_{7}$ 的平均数是 $x_{8}$ 又 $s_{1}^{2}=\frac{(x_{1}-x_{8})^{2}+(x_{2}-x_{8})^{2}+(x_{3}-x_{8})^{2}+(x_{4}-x_{8})^{2}+(x_{5}-x_{8})^{2}+(x_{6}-x_{8})^{2}+(x_{7}-x_{8})^{2}+(x_{8}-x_{8})^{2}}{8}=$ $\frac{(x_{1}-x_{8})^{2}+(x_{2}-x_{8})^{2}+(x_{3}-x_{8})^{2}+(x_{4}-x_{8})^{2}+(x_{5}-x_{8})^{2}+(x_{6}-x_{8})^{2}+(x_{7}-x_{8})^{2}}{8}$ $s_{2}^{2}=\frac{(x_{1}-x_{8})^{2}+(x_{2}-x_{8})^{2}+(x_{3}-x_{8})^{2}+(x_{4}-x_{8})^{2}+(x_{5}-x_{8})^{2}+(x_{6}-x_{8})^{2}+(x_{7}-x_{8})^{2}}{7}$
> >
> > $s_1^2$ 与 $s_2^2$ 的分子相同，比较分母，可知 $s_1^2 < s_2^2$
> >
> > 故选 **C**
