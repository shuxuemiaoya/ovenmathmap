> [!faq]- 《第八章 立体几何初步（高效培优讲义）》官方解析
>
> > [!success]- **【答案】** C
>
> > [!note]- **【分析】**
> > 应用线面位置关系，线面垂直性质定理判断 A，B，D，应用面面垂直的判定定理证明即可判定 C.
>
> > [!note]- **【解析】**
> > $m \perp n, m // \alpha, n // \beta$ ，可能 $\alpha // \beta$ ，A 错误；
> >
> > $m \perp n, \alpha \cap \beta = m, n \subset \alpha$ $\alpha, \beta$ , 可能相交不一定垂直， $^{B}$ 错误；
> >
> > $m // n, m \perp \alpha, n \perp \beta$ $\alpha // \beta$ ，所以， $^{D}$ 选项错误；
> >
> > $\because n \perp \beta, m // n, \therefore m \perp \beta.$ 又 $m \subset \alpha$ ，由面面垂直的判定定理，得 $\alpha \perp \beta$
> >
> > 故选 **C**.
