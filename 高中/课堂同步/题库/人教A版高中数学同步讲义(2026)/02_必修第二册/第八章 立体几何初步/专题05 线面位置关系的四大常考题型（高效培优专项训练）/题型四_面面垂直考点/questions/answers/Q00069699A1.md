> [!faq]- 《专题05 线面位置关系的四大常考题型（高效培优专项训练）》官方解析
>
> > [!success]- **【答案】** (1)证明过程见解析 (2)证明过程见解析
>
> > [!note]- **【分析】**
> > （1）根据中位线得到 $EF / / PC$ ，从而证明出线面平行；
> >
> > (2) 证明出四边形 $AGCE$ 为平行四边形，故 $EA // GC$ ，所以 $EA // \text{平面} PGC$ ，同理可得 $EF // \text{平面} PGC$
> >
> > 证明出面面平行，由面面平行的性质得到线线平行.
>
> > [!note]- **【解析】**
> > （1）因为 E, F 分别为线段 BC, PB 的中点，
> > 所以 EF // PC ，
> > 因为 $EF \not\subset$ 平面 PAC， $PC \subset$ 平面 PAC，所以 $EF \parallel$ 平面 PAC；
> > （2）因为四边形 ABCD 是平行四边形，
> > 所以 BC // AD 且 BC = AD ，
> > 点 E, G 分别为线段 BC, AD 的中点，
> > 故 EC // AG 且 EC = AG ，
> > 所以四边形 AGCE 为平行四边形，故 EA // GC ，
> > 因为 EA ∉ 平面 PGC，GC ⊂ 平面 PGC，所以 EA // 平面 PGC ，
> > 因为 EF // PC，EF ∉ 平面 PGC，PC ⊂ 平面 PGC，所以 EF // 平面 PGC ，
> > 又 EA ∩ EF = E，EA, EF ⊂ 平面 FEA ，
> > 所以平面 FEA // 平面 PGC ，
> > 因为 AE ∩ BD = N, CG ∩ BD = M，即平面 PBD ∩ 平面 PGC = PM ，
> > 平面 PBD ∩ 平面 FEA = FN ，
> > 所以 FN // PM 。
