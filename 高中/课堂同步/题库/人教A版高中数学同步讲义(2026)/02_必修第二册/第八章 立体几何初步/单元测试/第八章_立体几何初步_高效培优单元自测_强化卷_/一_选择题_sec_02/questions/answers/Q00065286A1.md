> [!faq]- 《第八章_立体几何初步_高效培优单元自测_强化卷_》官方解析
>
> > [!success]- **【答案】** A．底面半径为 $^{1}$ ，高为 $^{2}$ 的圆锥 B．底面半径为 $^{1}$ ，高为 $^{2}$ 的圆柱 C．上、下底面半径分别为 $\frac{1}{2}$ ， $\frac{3}{2}$ ，高为 $^2$ 的圆台 D．半径为 $^1$ 的球
>
> > [!note]- **【分析】**
> > 利用圆锥、圆柱、圆台和球体的体积和表面积公式逐一计算检验即得·
>
> > [!note]- **【解析】**
> > 对于 A，圆锥的体积为 $V_{1}=\frac{1}{3}\times\pi\times1^{2}\times2=\frac{2\pi}{3}$ ，表面积为 $S_{1}=\pi\times1^{2}+\pi\times1\times\sqrt{2^{2}+1^{2}}=(\sqrt{5}+1)\pi$
> >
> > 所以 $\frac{V_1}{S_1} = \frac{\frac{2\pi}{3}}{(\sqrt{5} + 1)\pi} = \frac{\sqrt{5} - 1}{6}$ ，故A错误；
> >
> > 对于 $\mathsf{B}$ ，圆柱的体积为 $V_{2} = \pi \times 1^{2}\times 2 = 2\pi$ ，表面积为 $S_{2} = 2\times \pi \times 1^{2} + 2\times \pi \times 1\times 2 = 6\pi$
> >
> > 所以 $\frac{V_{2}}{S_{2}}=\frac{2\pi}{6\pi}=\frac{1}{3}$ ，故 B 正确；
> >
> > 对于 $C$ ，圆台的体积为 $V_{3} = \frac{1}{3}\times 2\times [\pi \times (\frac{1}{2})^{2} + \pi \times (\frac{3}{2})^{2} + \sqrt{\pi\times(\frac{1}{2})^{2}\times\pi\times(\frac{3}{2})^{2}} ] = \frac{13\pi}{6}$
> >
> > 表面积为： $S_{3} = \pi \times (\frac{1}{2})^{2} + \pi \times (\frac{3}{2})^{2} + \pi \times (\frac{1}{2} +\frac{3}{2})\times \sqrt{2^{2} + (\frac{3}{2} -\frac{1}{2})^{2}} = (\frac{5}{2} +2\sqrt{5})\pi$
> >
> > 所以 $\frac{V_3}{S_3} = \frac{\frac{13\pi}{6}}{(\frac{5}{2} + 2\sqrt{5})\pi} = \frac{52\sqrt{5} - 65}{165}$ ，故C错误；
> >
> > 对于D，球的体积为： $V_{4} = \frac{4}{3}\times \pi \times 1^{3} = \frac{4\pi}{3}$ ，表面积为： $S_{4} = 4\times \pi \times 1^{2} = 4\pi$
> >
> > 所以 $\frac{V_{4}}{S_{4}}=\frac{\frac{4\pi}{3}}{4\pi}=\frac{1}{3}$ ，故 D 正确。
> >
> > 故选 **BD**.
