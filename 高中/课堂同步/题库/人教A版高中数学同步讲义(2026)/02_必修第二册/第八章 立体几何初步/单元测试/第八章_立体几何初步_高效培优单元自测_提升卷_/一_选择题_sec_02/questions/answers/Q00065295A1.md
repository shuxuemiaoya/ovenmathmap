> [!faq]- 《第八章_立体几何初步_高效培优单元自测_提升卷_》官方解析
>
> > [!success]- **【答案】** A. 若 $m \subset \alpha, n // \alpha$ ，则 $m // n$ B. 若 $\alpha // \gamma, \beta // \gamma$ ，则 $\alpha // \beta$ C. 若 $m \perp \beta, m \perp \gamma, \alpha \perp \beta$ ，则 $\alpha \perp \gamma$ D. 若 $m \perp \alpha, n // \beta, \alpha // \beta$ ，则 $m \perp n$
>
> > [!note]- **【分析】**
> > 利用线面平行性质可判断 $A$ ，利用平行传递性可判断 $B$ ，利用空间的垂直和平行位置关系可判断CD.
>
> > [!note]- **【解析】**
> > 由 $m \subset \alpha, n // \alpha$ ，可知 $m // n$ 或 m, n 是异面直线，故 A 错误；
> >
> > 若 $\alpha // \gamma, \beta // \gamma$ ，且 $\alpha, \beta, \gamma$ 是三个不同的平面，则 $\alpha // \beta$ ，故 $^B$ 正确；
> >
> > 由 $m \perp \beta, m \perp \gamma$ ，可得 $\beta // \gamma$ ，又因为 $\alpha \perp \beta$ ，所以 $\alpha \perp \gamma$ ，故 C 正确；
> >
> > 由 $m \perp \alpha, \alpha // \beta$ ，可得 $m \perp \beta$ ，再由 $n // \beta$ ，可得 $m \perp n$ ，故 D 正确；
> >
> > 故选 **A**.
