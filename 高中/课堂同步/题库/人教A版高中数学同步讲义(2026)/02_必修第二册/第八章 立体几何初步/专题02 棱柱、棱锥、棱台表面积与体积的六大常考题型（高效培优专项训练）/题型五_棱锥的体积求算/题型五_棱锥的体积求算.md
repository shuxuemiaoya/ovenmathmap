## 题型五：棱锥的体积求算

33. 将一个圆形纸片裁成两个扇形，再分别卷成甲、乙两个圆锥的侧面，甲、乙两个圆锥的侧面积分别为 $S_{\text{甲}}$ 和 $S_{\text{乙}}$ ，体积分别为 $V_{\text{甲}}$ 和 $V_{\text{乙}}$ ，若 $\frac{S_{\text{甲}}}{S_{\text{乙}}} = \frac{1}{2}$ ，则 $\frac{V_{\text{甲}}}{V_{\text{乙}}} =$ \_\_\_\_.

【答案】 $\frac{\sqrt{10}}{10}$

【分析】设母线长为 $l$ ，甲圆锥底面半径为 $r_1$ ，乙圆锥底面圆半径为 $r_2$ ，根据圆锥的侧面积公式可得 $r_2 = 2r_1$ 再结合圆心角之和可将 $r_1, r_2$ 分别用 $l$ 表示，再利用勾股定理分别求出两圆锥的高，再根据圆锥的体积公式即可得解.

【详解】设母线长为 l，甲圆锥底面半径为 $r_{1}$ ，乙圆锥底面圆半径为 $r_{2}$ ，

则 $\frac{S_{\text{甲}}}{S_{\text{乙}}} = \frac{\pi r_1l}{\pi r_2l} = \frac{r_1}{r_2} = \frac{1}{2}$ ，所以 $r_2 = 2r_1$

又 $\frac{2\pi r_1}{l} +\frac{2\pi r_2}{l} = 2\pi$ ，则 $\frac{r_1 + r_2}{l} = 1$ ，所以 $r_2 = \frac{2}{3} l,r_1 = \frac{1}{3} l$

所以甲圆锥的高 $h_1 = \sqrt{l^2 - \frac{1}{9}l^2} = \frac{2\sqrt{2}}{3} l$

乙圆锥的高 $h_2 = \sqrt{l^2 - \frac{4}{9} l^2} = \frac{\sqrt{5}}{3} l$

所以 $\frac{V_{\text{甲}}}{V_{\text{乙}}} = \frac{\frac{1}{3}\pi r_1^2h_1}{\frac{1}{3}\pi r_2^2h_2} = \frac{\frac{1}{9}l^2\times\frac{2\sqrt{2}}{3}l}{\frac{4}{9}l^2\times\frac{\sqrt{5}}{3}l} = \frac{\sqrt{10}}{10}$

故答案为： $\frac{\sqrt{10}}{10}$
