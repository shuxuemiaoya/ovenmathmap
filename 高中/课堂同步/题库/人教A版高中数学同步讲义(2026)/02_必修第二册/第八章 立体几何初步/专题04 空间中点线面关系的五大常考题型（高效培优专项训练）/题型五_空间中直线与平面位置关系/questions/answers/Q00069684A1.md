> [!faq]- 《专题04 空间中点线面关系的五大常考题型（高效培优专项训练）》官方解析
>
> > [!success]- **【答案】** A. 若 $a // c$ ，则 $b // c$ B. 若 $a // \alpha$ ，则 $b // \alpha$ C. 若 $a$ 与 $c$ 相交，则 $b$ 与 $c$ 相交 D. 若 $a$ 与 $\alpha$ 相交，则 $b$ 与 $\alpha$ 相交
>
> > [!note]- **【分析】**
> > 利用空间中线线与线面的位置关系逐一分析各选项的正误，可得出合适的选项.
>
> > [!note]- **【解析】**
> > 对 A：因为 $a \parallel b$ ， $a \parallel c$ ，则 $b \parallel c$ 。故 A 成立；
> >
> > 对 B：若 $a \parallel b$ ， $a \parallel \alpha$ ，则 $b \parallel \alpha$ 或 $b \subset \alpha$ 。故 B 错误；
> >
> > 对 C：若 $a // b$ ，a 与 c 相交，则 b 与 c 相交或 b 与 c 异面，故 C 错误；
> >
> > 对 D：若 $a // b$ ，a 与 $\alpha$ 相交，则 b 与 $\alpha$ 相交。故 D 成立。
> >
> > 故选 **AD**
