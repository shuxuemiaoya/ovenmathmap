> [!faq]- 《专题04 空间中点线面关系的五大常考题型（高效培优专项训练）》官方解析
>
> > [!success]- **【答案】** A. 若 $m // \alpha, m // n$ ，则 $n // \alpha$ ； B. 若 $m // \alpha, m^{\wedge} n$ ，则 $n \perp \alpha$ ； C. 若 $m \perp \alpha, n \perp \alpha$ ，则 $m // n$ ； D. 若 $m \perp \alpha, m \perp n$ ，则 $n // \alpha$ 。
>
> > [!note]- **【分析】**
> > 依次判断选项即可.
>
> > [!note]- **【解析】**
> > 对于 A 项，也可以 $n \subset \alpha$ ，故 A 错；
> >
> > 对于 B 项，也可以 $n // \alpha$ 或 $n \subset \alpha$ ，故 B 错；
> >
> > 对于 C 项，显然成立，故 C 正确；
> >
> > 对于 D 项，也可以 $n \subset \alpha$ ，故 D 错，
> >
> > 故选 **C**
