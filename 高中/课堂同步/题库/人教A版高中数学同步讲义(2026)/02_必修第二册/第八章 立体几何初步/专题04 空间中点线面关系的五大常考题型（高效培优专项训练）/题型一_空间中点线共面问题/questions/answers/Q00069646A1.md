> [!faq]- 《专题04 空间中点线面关系的五大常考题型（高效培优专项训练）》官方解析
>
> > [!success]- **【答案】** A. $AB$ 与 $AC$ 共线 B. $AB$ 与 $CD$ 共线 C. $A, B, C, D$ 四点不共面 D. $A, B, C, D$ 四点共面
>
> > [!note]- **【分析】**
> > 根据向量共线和四点共面的条件进行判断即可.
>
> > [!note]- **【解析】**
> > ∵ $AC \neq \lambda AB$ ，∴ AC，AB 不共线，故 A 错误；
> >
> > $\overline{CD}=\overline{AD}-\overline{AC}=\overline{e_{1}}-13\overline{e_{2}}$ ，则 $\overline{CD}\neq\lambda\overline{AB}$ ，即 $\overline{CD}$ 与 $\overline{AB}$ 不共线，故B错误；
> >
> > 若 $AD = xAB + yAC$ ，则 $3e_{1} - 5e_{2} = xe_{1} + xe_{2} + 2ye_{1} + 8ye_{2} = (x + 2y)e_{1} + (x + 8y)e_{2}$
> >
> > 则 $\left\{\begin{aligned}x+2y=3\\ x+8y=-5\end{aligned}\right.$ ，得 $\left\{\begin{aligned}x=\frac{17}{3}\\ y=-\frac{4}{3}\end{aligned}\right.$ ，即 $AD=\frac{17}{3}AB-\frac{4}{3}AC$ ，
> >
> > 则 A, B, C, D 四点共面，故 C 错误；D 正确；
> >
> > 故选 **D**.
