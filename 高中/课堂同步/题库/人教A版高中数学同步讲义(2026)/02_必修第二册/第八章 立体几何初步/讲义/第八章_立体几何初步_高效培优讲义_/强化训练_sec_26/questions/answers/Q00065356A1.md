> [!faq]- 《第八章_立体几何初步_高效培优讲义_》官方解析
>
> > [!success]- **【答案】** A. 若 $l // \alpha, m \subset \alpha$ ，则 $l // m$ B. 若 $l // \alpha, m \perp \alpha$ ，则 $l \perp m$ C. 若 $l \perp \alpha, m \perp \beta, l \perp m$ ，则 $\alpha // \beta$ D. 若 $l // \alpha, \alpha // \beta$ ，则 $l // \beta$
>
> > [!note]- **【分析】**
> > 由 $l / / \alpha, m \subset \alpha$ ，分析出 $l / / m$ 或 $l, m$ 异面，即可判断 $\mathsf{A}$ ；由 $l / / \alpha$ ，根据线面平行的性质定理可知，
> >
> > 在平面 $\alpha$ 内一定存在直线 $n$ ，使得 $l / / n$ ，又由 $m \perp \alpha$ ，可得 $m \perp n$ ，即可得 $l \perp m$ ，即可判断 $^{\mathrm{B}}$ ；由
> >
> > $l \perp \alpha, m \perp \beta, l \perp m$ ，分析出 $\alpha \perp \beta$ ，即可判断 C；由 $l // \alpha, \alpha // \beta$ ，分析出 $l // \beta$ 或 $l \subset \beta$ ，即可判断 D.
>
> > [!note]- **【解析】**
> > 对于 A，若 $l \parallel \alpha, m \subset \alpha$ ，则 $l \parallel m$ 或 l, m 异面，故 A 错误；
> >
> > 对于 B，若 $l // \alpha$ ，则由线面平行的性质定理可知，在平面 $\alpha$ 内一定存在直线 n，使得 $l // n$ 。
> >
> > 又因为 $m \perp \alpha$ ，所以 $m \perp n \cdot$ 因为 $l // n$ ，所以 $l \perp m$ ，故 B 正确；
> >
> > 对于 $C$ ，若 $l \perp \alpha, m \perp \beta, l \perp m$ ，则 $\alpha \perp \beta$ ，故 $C$ 错误；
> >
> > 对于 D，若 $l \parallel \alpha, \alpha \parallel \beta$ ，则 $l \parallel \beta$ 或 $l \subset \beta$ ，故 D 错误.
> >
> > 故选 **B**
