> [!faq]- 《专题8.4 空间点、直线、平面之间的位置关系（高效培优讲义）》官方解析
>
> > [!success]- **【答案】** (1)证明见解析 (2)证明见解析
>
> > [!note]- **【分析】**
> > （ $^{1}$ ）作出辅助线，利用平行的传递性证明 GE // BD ，进而可得四点共线；
> >
> > (2) 延长 $AF, BG$ ，设它们交于一点，由已知可得 $\triangle SFG \sim \triangle SAB$ ，则 $\frac{SF}{SA} = \frac{FG}{AB} = \frac{1}{2}$ ，同理可得 $\frac{QF}{QA} = \frac{EF}{AD} = \frac{1}{2}$
> >
> > 则 S 和 Q 是同一个点，所以 AF, BG, DE 三条直线交于一点.
>
> > [!note]- **【解析】**
> > （1）
> >
> > ![](../../../images/questions/part-001/dce7f43fac5e87999b578a1af0044cc7877dffc655d2096a75c6d7a3f8651971.jpg)
> >
> > 如图，取 AB, AD 的中点分别为 S, T，连接 GS, ET, ST，则 ST // BD，
> >
> > 因为四边形ABCD和四边形EFGH均为正方形， $AB = 2FG$ ，且 $AB / / FG$ ， $AD / / EF$
> >
> > 所以四边形 $FGSA, FETA$ 均为平行四边形，即 $GS // FA // ET$ ， $GS = FA = ET$
> >
> > 所以四边形GETS为平行四边形，所以GE//TS，所以GE//BD
> >
> > 所以 B, D, E, G 四点共面·
> >
> > (2)
> >
> > ![](../../../images/questions/part-001/b645bf4d69fcec70f95f41d5ce951814e4cc30360ba35fc0fe5f2449db1f03bf.jpg)
> >
> > 延长 AF, BG ，设它们交于一点 S ，
> >
> > 因为 $AB \parallel FG$ ，且 $AB = 2FG$ ，所以 $\triangle SFG \sim \triangle SAB$ ，则 $\frac{SF}{SA} = \frac{FG}{AB} = \frac{1}{2}$ ，
> > 同理，延长 $AF, DE$ ，设它们交于一点 $Q$ ，
> > 因为四边形 $ABCD$ 和四边形 $EFGH$ 均为正方形， $AB = 2FG$ ，则 $AD = 2EF$ ，又 $AD \parallel EF$ ，所以 $\triangle QEF \sim \triangle QAD$ ，则 $\frac{QF}{QA} = \frac{EF}{AD} = \frac{1}{2}$ ，因此 $S$ 和 $Q$ 是同一个点，所以 $AF, BG, DE$ 三条直线交于一点。
