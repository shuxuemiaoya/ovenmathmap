> [!faq]- 《专题6.4 平面向量的应用（高效培优讲义）》官方解析
>
> > [!success]- **【答案】** (1) $AD=\frac{6}{5}\sqrt{3}$ (2) $\sin B = \frac{\sqrt{7}}{4}, PB = \frac{8\sqrt{14}}{7}$ (3)证明见解析
>
> > [!note]- **【解析】**
> > （1）因为 p = q ，所以 AD 为角 A 的角平分线，
> >
> > 因为 $\angle A = 60^{\circ}$ ，所以 $\angle BAD = \angle CAD = 30^{\circ}$ ，
> >
> > 因为 $S_{\triangle ABC} = S_{\triangle ABD} + S_{\triangle ACD}$
> >
> > 所以 $\frac{1}{2} \times 2 \times 3 \times \frac{\sqrt{3}}{2} = \frac{1}{2} \times 3 \times AD \times \frac{1}{2} + \frac{1}{2} \times 2 \times AD \times \frac{1}{2}$
> >
> > 解得 $AD = \frac{6}{5}\sqrt{3}$ ;
> >
> > (2) 因为 $A + C = \pi - B$ ， $A - C = \frac{\pi}{2}$ ，
> >
> > 所以 $A=\frac{3\pi}{4}-\frac{B}{2}$ ， $C=\frac{\pi}{4}-\frac{B}{2}$ ，
> >
> > 因为 $a + c = 2b$ ，所以 $\sin A + \sin C = 2\sin B$ ，
> >
> > 可得 $\sin \left(\frac{3\pi}{4} -\frac{B}{2}\right) + \sin \left(\frac{\pi}{4} -\frac{B}{2}\right) = 2\sin B$
> >
> > 即 $\frac{\sqrt{2}}{2}\cos\frac{B}{2}+\frac{\sqrt{2}}{2}\sin\frac{B}{2}+\frac{\sqrt{2}}{2}\cos\frac{B}{2}-\frac{\sqrt{2}}{2}\sin\frac{B}{2}=2\sin B$
> >
> > 即 $\sqrt{2}\cos \frac{B}{2} = 4\sin \frac{B}{2}\cos \frac{B}{2}$ ，因为 $\cos \frac{B}{2}\neq 0$
> >
> > 所以 $\sin \frac{B}{2} = \frac{\sqrt{2}}{4}$
> >
> > 可得 $\cos B = 1 - 2 \times \frac{2}{16} = \frac{3}{4}$ ，所以 $\sin B = \sqrt{1 - \frac{9}{16}} = \frac{\sqrt{7}}{4}$ ，
> >
> > 在 $\triangle PEG$ 中， $EG = \sqrt{p^2 + r^2 - 2pr\times\cos(\pi - B)} = \sqrt{1 + 4 - 2\times 2\times 1\times\left(-\frac{3}{4}\right)} = 2\sqrt{2}$
> >
> > 所以 $PB=\frac{EG}{\sin(\pi-B)}=\frac{2\sqrt{2}}{\frac{\sqrt{7}}{4}}=\frac{8\sqrt{14}}{7}$ ;
> >
> > (3) 因为 $EF = \sqrt{p^{2} + q^{2} - 2pq\cos(\pi - A)} = \sqrt{p^{2} + q^{2} - 2pq\cos(B + C)}$
> >
> > $$
> > = \sqrt {p ^ {2} + q ^ {2} - 2 p q (\cos B \cos C - \sin B \sin C)}
> > $$
> >
> > $$
> > = \sqrt {p ^ {2} + q ^ {2} - 2 p q \cos B \cos C + 2 p q \sin B \sin C}
> > $$
> >
> > $$
> > = \sqrt {p ^ {2} (\sin^ {2} B + \cos^ {2} B) + q ^ {2} (\sin^ {2} C + \cos^ {2} C) - 2 p q \cos B \cos C + 2 p q \sin B \sin C}
> > $$
> >
> > $$
> > = \sqrt {(p \sin B + q \sin C) ^ {2} + (p \cos B - q \cos C) ^ {2}} \quad p \sin B + q \sin C
> > $$
> >
> > 所以 $PA=\frac{EF}{\sin(\pi-A)}$ $\frac{p\sin B+q\sin C}{\sin A}$
> >
> > 当且仅当 $p \cos B = q \cos C$ 时，等号成立，-
> >
> > 同理 $PB \frac{p\sin A + r\sin C}{\sin B}$ ，当且仅当 $p\cos A = r\cos C$ 时，等号成立，
> >
> > PC $\frac{r\sin B+q\sin A}{\sin C}$ ，当且仅当 $r\cos B=q\cos A$ 时，等号成立，
> >
> > $$
> > \text {所以} P A + P B + P C \quad \frac {p \sin B + q \sin C}{\sin A} + \frac {p \sin A + r \sin C}{\sin B} + \frac {r \sin B + q \sin A}{\sin C},
> > $$
> >
> > $$
> > \text { 因为 } \frac {p \sin B + q \sin C}{\sin A} + \frac {p \sin A + r \sin C}{\sin B} + \frac {r \sin B + q \sin A}{\sin C}
> > $$
> >
> > $$
> > = p \left(\frac {\sin B}{\sin A} + \frac {\sin A}{\sin B}\right) + q \left(\frac {\sin C}{\sin A} + \frac {\sin A}{\sin C}\right) + r \left(\frac {\sin C}{\sin B} + \frac {\sin B}{\sin C}\right) 2 p + 2 q + 2 c,
> > $$
> >
> > 当且仅当 $\sin A = \sin B = \sin C$ 时，等号成立，
> >
> > 所以 $PA + PB + PC$ $2(p + q + r)$
> >
> > 当且仅当 a=b=c 且 p=q=r 时，等号成立。
