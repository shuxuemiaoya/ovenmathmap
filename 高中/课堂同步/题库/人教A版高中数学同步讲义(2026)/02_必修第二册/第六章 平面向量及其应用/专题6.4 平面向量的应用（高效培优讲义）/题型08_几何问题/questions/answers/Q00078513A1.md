> [!faq]- 《专题6.4 平面向量的应用（高效培优讲义）》官方解析
>
> > [!success]- **【答案】** B
>
> > [!note]- **【解析】**
> > 根据题意，得
> >
> > $$
> > \angle D B C = 6 0 ^ {\circ}, \quad \angle C B A = 1 5 ^ {\circ}, \quad \angle D C B = \angle D C A = 9 0 ^ {\circ}, \quad \angle C A B = 3 0 ^ {\circ}, \quad A B = 6 0 0 \mathrm{m}
> > $$
> >
> > 设 $CD = h$ ，则 $CB = \frac{\sqrt{3}}{3} h$
> >
> > 在VABC中， $\angle ACB = 180^{\circ} - \angle CAB - \angle CBA = 180^{\circ} - 15^{\circ} - 30^{\circ} = 135^{\circ}$
> >
> > 由正弦定理，得 $\frac{AB}{\sin\angle ACB} = \frac{BC}{\sin\angle CAB}$ ，即 $\frac{600}{\sin 135^\circ} = \frac{BC}{\sin 30^\circ}$ ，解得 $BC = 300\sqrt{2}\mathrm{m}$
> >
> > 所以 $CD = \sqrt{3}BC = 300\sqrt{6}m$ .
> >
> > 故选 **B**.
