> [!faq]- 《专题6.4 平面向量的应用（高效培优讲义）》官方解析
>
> > [!success]- **【答案】** A．若 $a=9,\quad b=10,\quad A=\frac{\pi}{3}$ ，则符合条件的三角形有两个 B．若 $\frac{a^{2}}{\tan A}=\frac{b^{2}}{\tan B}$ ，则VABC为等腰或直角三角形 C．若 $S_{\triangle ABC}=b^{2}\sin B$ ，则 $\cos B$ 的最小值为 $\frac{4}{5}$ D．若 $A=\frac{\pi}{3}, BC=\sqrt{3}, BC$ 边上的高为1，则符合条件的三角形有两个
>
> > [!note]- **【解析】**
> > 对于 A, $b \sin A = 10 \times \frac{\sqrt{3}}{2} = 5\sqrt{3}$ ，由于 $5\sqrt{3} < a < b$ ，故三角形有两个解，故 A 正确，
> >
> > 对于 B，由 $\frac{a^{2}}{\tan A} = \frac{b^{2}}{\tan B}$ 可得 $\frac{\sin^{2}A}{\tan A} = \frac{\sin^{2}B}{\tan B}$ ，进而 $\sin 2A = \sin 2B$ ，结合 $2A, 2B \in (0, 2\pi)$ ，
> >
> > 故 $2A = 2B$ 或 $2A + 2B = \pi$ ，即 $A = B$ 或 $A + B = \frac{\pi}{2}$
> >
> > 故三角形为等腰三角形或者直角三角形，故 B 正确，
> >
> > 对于 C, $S_{\triangle ABC} = b^{2} \sin B = \frac{1}{2} ac \sin B \Rightarrow ac = 2b^{2}$ ,
> >
> > 故 $\cos B = \frac{a^2 + c^2 - b^2}{2ac}$ $\frac{2ac - b^2}{2ac} = 1 - \frac{1}{4}\frac{2b^2}{ac} = \frac{3}{4}$ ，当且仅当 $a = c$ 时等号成立，故C错误，
> >
> > 对于 D, 由 $A = \frac{\pi}{3}$ ， $BC = \sqrt{3}$ ，BC 边上的高为 1 可得：
> >
> > $S_{\triangle ABC} = \frac{1}{2} BC \times 1 = \frac{1}{2} bc \sin A \Rightarrow \frac{1}{2} \times \sqrt{3} \times 1 = \frac{1}{2} bc \times \frac{\sqrt{3}}{2}$ ，故 $bc = 2$ ，
> >
> > 由余弦定理可得 $a^2 = b^2 + c^2 - 2bc\cos A$ ，故 $b^2 + c^2 = (b + c)^2 - 2bc = 5$ ，故 $b + c = 3$
> >
> > 联立 $bc = 2$ 可得 $b = 1, c = 2$ 或 $b = 2, c = 1$ ，故符合条件的三角形有两个，故D正确，
> >
> > 故选 **ABD**
