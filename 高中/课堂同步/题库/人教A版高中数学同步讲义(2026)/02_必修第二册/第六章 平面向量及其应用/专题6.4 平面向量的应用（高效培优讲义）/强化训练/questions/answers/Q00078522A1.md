> [!faq]- 《专题6.4 平面向量的应用（高效培优讲义）》官方解析
>
> > [!success]- **【答案】** (1) $A=\frac{\pi}{3}$ (2) $a = \sqrt{3}$
>
> > [!note]- **【解析】**
> > （1）因为 $\sqrt{3} a\sin B = 2b\cos^2\frac{A}{2}$ 结合正弦定理可得， $\sqrt{3}\sin A\sin B = 2\sin B\cos^2\frac{A}{2}$
> >
> > 因为 $B \in (0, \pi)$ ，所以 $\sin B \neq 0$ ，所以 $\sqrt{3} \sin A = 2 \cos^2 \frac{A}{2}$ ，则 $2\sqrt{3} \sin \frac{A}{2} \cos \frac{A}{2} = 2 \cos^2 \frac{A}{2}$ ，
> >
> > 因为 $A \in (0, \pi)$ ，所以 $\frac{A}{2} \in \left(0, \frac{\pi}{2}\right)$ ，则 $\cos \frac{A}{2} \neq 0$ ，得 $\tan \frac{A}{2} = \frac{\sqrt{3}}{3}$ ，则 $A = \frac{\pi}{3}$ ；
> >
> > (2) 因为 $AE$ 是 $\angle BAC$ 的角平分线，且 $S_{\triangle BAC} = S_{\triangle BAE} + S_{\triangle EAC}$ ， $A = \frac{\pi}{3}$ ， $AE = \frac{2\sqrt{3}}{3}$ ，
> >
> > 所以 $\frac{1}{2} bc\cdot \sin A = \frac{1}{2}\cdot b\cdot \sin \frac{A}{2}\cdot AE + \frac{1}{2}\cdot c\cdot \sin \frac{A}{2}\cdot AE$ ，得 $bc = \frac{2}{3}(b + c)$
> >
> > 在 $\triangle ACD$ 中利用余弦定理得 $\cos \angle ADC = \frac{\left(\frac{a}{2}\right)^2 + AD^2 - b^2}{a \cdot AD}$
> >
> > 在 $\triangle ABD$ 中利用余弦定理得 $\cos \angle ADB = \frac{\left(\frac{a}{2}\right)^2 + AD^2 - c^2}{a \cdot AD}$
> >
> > 因为 $\cos \angle ADC + \cos \angle ADB = 0$ ， $AD = \frac{\sqrt{7}}{2}$ ，所以 $\frac{a^2}{2} +\frac{7}{2} = b^2 +c^2$
> >
> > 则在 $\triangle ACB$ 中利用余弦定理得 $\frac{1}{2} = \cos A = \frac{b^2 + c^2 - a^2}{2bc} = \frac{\frac{a^2}{2} + \frac{7}{2} - a^2}{2bc}$ ，得 $7 - a^2 = 2bc$
> >
> > 因为 $bc = \frac{2}{3}(b + c)$ ，所以 $b^{2}c^{2} = \frac{4}{9}\left(b^{2} + c^{2} + 2bc\right)$
> >
> > 所以 $\left(7 - a^2\right)^2 = \frac{16}{9}\left(\frac{a^2}{2} +\frac{7}{2} +7 - a^2\right)$ ，解得 $9a^{4} - 118a^{2} + 273 = 0$ ，解得 $a = \sqrt{3}$ 或 $\frac{\sqrt{91}}{3}$
> >
> > 又 $7 - a^{2} = 2bc > 0$ ，解得 $a < \sqrt{7} < 3 < \frac{\sqrt{91}}{3}$ ，于是 $a = \sqrt{3}$
> >
> > 9. 锐角三角形VABC的内角A,B,C的对边分别为a,b,c，已知 $2\cos A(c\cos B+b\cos C)=a$
> >
> > (1)求 $A$
> >
> > (2)若 $a = 3$ ，求VABC的周长的取值范围.
> >
> > 【答案】(1) $\frac{\pi}{3}$
> >
> > (2) $(3\sqrt{3}+3,9]$
> >
> > 【详解】（1）解：因为 $2\cos A(c\cos B + b\cos C) = a$
> >
> > 由正弦定理得 $2 \cos A (\sin C \cos B + \sin B \cos C) = \sin A$
> >
> > 又因为 $B + C = \pi - A$ ，所以 $\sin C \cos B + \sin B \cos C = \sin (B + C) = \sin A$
> >
> > 所以 $2 \cos A \sin A = \sin A$
> >
> > 因为 VABC 为锐角三角形，可得 $A \in (0, \frac{\pi}{2})$ ，所以 $\sin A > 0$ ，
> >
> > 所以 $\cos A = \frac{1}{2}$ ，可得 $A = \frac{\pi}{3}$ .
> >
> > (2) 解：设 VABC 外接圆的半径为 r，
> >
> > 由（1）知 $A = \frac{\pi}{3}$ ，因为 $a = 3$ ，可得 $2r = \frac{a}{\sin A} = 2\sqrt{3}$
> >
> > 所以 $b = 2\sqrt{3} \sin B, c = 2\sqrt{3} \sin C$
> >
> > $$
> > b + c = 2 \sqrt {3} (\sin B + \sin C) = 2 \sqrt {3} [ \sin B + \sin \left(\frac {2 \pi}{3} - B\right) ] = 2 \sqrt {3} [ \sin B + \left(\frac {\sqrt {3}}{2} \cos B + \frac {1}{2} \sin B\right) ]
> > $$
> >
> > $$
> > = 2 \sqrt {3} \cdot \left(\frac {3}{2} \sin B + \frac {\sqrt {3}}{2} \cos B\right) = 6 \sin \left(B + \frac {\pi}{6}\right)
> > $$
> >
> > 因为 为锐角三角形，可得 $\left\{ \begin{array}{l}0 < B < \frac{\pi}{2}\\ 0 < \frac{2\pi}{3} -B < \frac{\pi}{2} \end{array} \right.$ ，解得 $\frac{\pi}{6} <  B <   \frac{\pi}{2}$
> >
> > 可得 $B + \frac{\pi}{6} \in (\frac{\pi}{3}, \frac{2\pi}{3})$ ，所以 $\sin(B + \frac{\pi}{6}) \in (\frac{\sqrt{3}}{2}, 1]$ ，则 $6\sin(B + \frac{\pi}{6}) \in (3\sqrt{3}, 6]$
> >
> > 即 $b + c \in (3\sqrt{3}, 6]$ ，所以 $\mathrm{V}ABC$ 的周长 $a + b + c \in (3\sqrt{3} + 3, 9]$
> >
> > 所以VABC的周长的取值范围为 $(3\sqrt{3}+3,9]$ .
