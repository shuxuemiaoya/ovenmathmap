> [!faq]- 《专题6.4 平面向量的应用（高效培优讲义）》官方解析
>
> > [!success]- **【答案】** (1) $A=\frac{\pi}{3}$ $$ 2) \left(\frac {\sqrt {3}}{2}, \frac {3 \sqrt {3}}{4} \right] $$
>
> > [!note]- **【解析】**
> > （1）因为 $\cos C=\frac{a^{2}+b^{2}-c^{2}}{2ab}$ ，所以 $8\sin A\sin B\times\frac{a^{2}+b^{2}-c^{2}}{2ab}=a^{2}+b^{2}-c^{2}$
> >
> > 又VABC为锐角三角形，即 $a^2 + b^2 - c^2 > 0$ ，所以 $4\sin A\sin B = ab$
> >
> > 由正弦定理 $\frac{a}{\sin A} = \frac{b}{\sin B}$ ，所以 $\frac{ab}{\sin A\sin B} = \left(\frac{a}{\sin A}\right)^2 = 4$ ，因为 $a = \sqrt{3}$ ，所以 $\sin A = \frac{\sqrt{3}}{2}$
> >
> > 又因为 A 为锐角，所以 $A = \frac{\pi}{3}$ ;
> >
> > (2) 由正弦定理有 $\frac{a}{\sin A} = \frac{b}{\sin B} = \frac{c}{\sin C} = \frac{\sqrt{3}}{\sin \frac{\pi}{3}} = 2$ ，所以 $b = 2\sin B, c = 2\sin C$
> >
> > 所以VABC的面积 $S=\frac{1}{2}bc\cdot\sin A=\frac{\sqrt{3}}{4}\cdot2\sin B\cdot2\sin C=$
> >
> > $$
> > \sqrt {3} \cdot \sin B \cdot \sin \left(\frac {2 \pi}{3} - B\right) = \sqrt {3} \sin B \left(\frac {\sqrt {3}}{2} \cos B + \frac {1}{2} \sin B\right)
> > $$
> >
> > $$
> > = \frac {3}{2} \sin B \cos B + \frac {\sqrt {3}}{2} \sin^ {2} B = \frac {3}{4} \sin 2 B + \frac {\sqrt {3}}{2} \times \frac {1 - \cos 2 B}{2}
> > $$
> >
> > $$
> > = \frac {3}{4} \sin 2 B - \frac {\sqrt {3}}{4} \cos 2 B + \frac {\sqrt {3}}{4} = \frac {\sqrt {3}}{2} \sin \left(2 B - \frac {\pi}{6}\right) + \frac {\sqrt {3}}{4}
> > $$
> >
> > 因为是锐角，所以 $0 < B, C < \frac{\pi}{2}$ ，即 $\left\{\begin{aligned}0 &< B < \frac{\pi}{2},\\ 0 &< \frac{2\pi}{3} - B < \frac{\pi}{2},\end{aligned}\right.$ 解得 $\frac{\pi}{6} < B < \frac{\pi}{2}$
> >
> > 所以 $\frac{\pi}{6} < 2B - \frac{\pi}{6} < \frac{5\pi}{6}$ ，所以 $\frac{1}{2} < \sin \left(2B - \frac{\pi}{6}\right) \leq 1$ ，所以 $\frac{\sqrt{3}}{2} < S \leq \frac{3\sqrt{3}}{4}$
> >
> > 则 $\triangle ABC$ 的面积的取值范围为 $\left(\frac{\sqrt{3}}{2},\frac{3\sqrt{3}}{4}\right]$
