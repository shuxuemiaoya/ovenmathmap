> [!faq]- 《专题6.4 平面向量的应用（高效培优讲义）》官方解析
>
> > [!success]- **【答案】** (1) $C=\frac{\pi}{3}$ (2) $4\sqrt{3}$
>
> > [!note]- **【解析】**
> > （1）由余弦定理可得 $\cos C = \frac{a^{2} + b^{2} - c^{2}}{2ab}$ ，所以 $a^{2} + b^{2} - c^{2} = 2ab\cos C$ .
> >
> > 由三角形面积公式可知 $S = \frac{1}{2} ab\sin C$ 及 $4S = \sqrt{3}\left(a^2 + b^2 - c^2\right)$ ，可得 $2ab\sin C = 2\sqrt{3} ab\cos C$ ，即 $\sin C = \sqrt{3}\cos C$
> >
> > 因为 $\cos C \neq 0$ ，所以 $\tan C = \frac{\sin C}{\cos C} = \sqrt{3}$ . 又 $C \in (0, \pi)$ ，所以 $C = \frac{\pi}{3}$ .
> >
> > (2) 由 (1) 知 $C = \frac{\pi}{3}$ .
> >
> > 因为 $c = 4$ ，所以由余弦定理可得 $c^2 = a^2 + b^2 - 2ab\cos C = a^2 + b^2 - ab = 16$
> >
> > 由不等式可得 $a^2 + b^2$ 2ab，所以 $16 = a^2 + b^2 - ab$ 2ab - ab = ab，即 $ab \leq 16$
> >
> > 当且仅当 a = b 时等号成立，ab 有最大值为 16.
> >
> > 所以 $S = \frac{1}{2} ab\sin C = \frac{\sqrt{3}}{4} ab\leq \frac{\sqrt{3}}{4}\times 16 = 4\sqrt{3}$
> >
> > 所以 VABC 的面积的最大值为 $4\sqrt{3}$ .
