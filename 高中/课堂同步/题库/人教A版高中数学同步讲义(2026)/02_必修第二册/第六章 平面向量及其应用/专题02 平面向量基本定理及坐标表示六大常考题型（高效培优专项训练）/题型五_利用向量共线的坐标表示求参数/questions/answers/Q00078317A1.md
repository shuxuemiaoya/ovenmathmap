> [!faq]- 《专题02 平面向量基本定理及坐标表示六大常考题型（高效培优专项训练）》官方解析
>
> > [!success]- **【答案】** (1) $\left(\sqrt{2}+1,\sqrt{2}\right)$ (2) $1+\frac{\sqrt{3}}{4}$ (3) $\theta = \frac{\pi}{3}$
>
> > [!note]- **【解析】**
> > （1）由题意知 $OB = (2,0)$
> >
> > 当 $\theta=\frac{\pi}{4}$ 时， $OC=\left(2\cos\frac{\pi}{4},2\sin\frac{\pi}{4}\right)=\left(\sqrt{2},\sqrt{2}\right)$
> >
> > 则 $AC = OC - OA = (\sqrt{2}, \sqrt{2}) - (-1, 0) = (\sqrt{2} + 1, \sqrt{2})$
> >
> > 所以当 $\theta=\frac{\pi}{4}$ 时， $\underset{AC}{\longrightarrow}$ 的坐标为 $(\sqrt{2}+1,\sqrt{2})$
> >
> > (2) 由向量旋转可知 $\overline{OC} = (2\cos q, 2\sin q)$ ， $\overline{AC} = (2\cos\theta + 1, 2\sin\theta)$ ，
> >
> > 又 $\triangle ACP$ 为等边三角形，则 $AP$ 可看作由 $AC$ 绕点 $A$ 沿逆时针方向旋转 $\frac{\pi}{3}$ 得到的，
> >
> > $$
> > A P = \left(\left(2 \cos \theta + 1\right) \cos \frac {\pi}{3} - 2 \sin \theta \sin \frac {\pi}{3}, (2 \cos \theta + 1) \sin \frac {\pi}{3} + 2 \sin \theta \cos \frac {\pi}{3}\right)
> > $$
> >
> > $$
> > = \left(\cos \theta - \sqrt {3} \sin \theta + \frac {1}{2}, \sqrt {3} \cos \theta + \sin \theta + \frac {\sqrt {3}}{2}\right),
> > $$
> >
> > 所以 $OP = OA + AP = \left( \cos \theta - \sqrt{3} \sin \theta - \frac{1}{2}, \sqrt{3} \cos \theta + \sin \theta + \frac{\sqrt{3}}{2} \right)$ ,
> >
> > $$
> > S _ {\triangle A O P} = \frac {1}{2} | O A | | y _ {P} | = \frac {\sqrt {3}}{2} \cos \theta + \frac {1}{2} \sin \theta + \frac {\sqrt {3}}{4} = \sin \left(\theta + \frac {\pi}{3}\right) + \frac {\sqrt {3}}{4},
> > $$
> >
> > 因为 $\sin \left(\theta +\frac{\pi}{3}\right)\leq 1$ ，所以 $S_{\triangle AOP}\leq 1 + \frac{\sqrt{3}}{4}$
> >
> > 当且仅当 $\theta + \frac{\pi}{3} = \frac{\pi}{2}$ ，即 $\theta = \frac{\pi}{6}$ 时， $S_{\triangle AOP}$ 取得最大值 $1 + \frac{\sqrt{3}}{4}$
> >
> > (3) 若 $\overline{AQ} = \frac{1}{3} \overline{AC}$ ，则 $\overline{OQ} = \overline{OA} + \overline{AQ} = \overline{OA} + \frac{1}{3} \overline{AC} = \overline{OA} + \frac{1}{3} \left( \overline{OC} - \overline{OA} \right)$
> >
> > $$
> > = \frac {2}{3} O A + \frac {1}{3} O C = \frac {2}{3} (- 1, 0) + \frac {1}{3} (2 \cos \theta , 2 \sin \theta) = \left(\frac {2}{3} (\cos \theta - 1), \frac {2}{3} \sin \theta\right)
> > $$
> >
> > 由（2）知 $\overrightarrow{AP} = \left(\cos \theta -\sqrt{3}\sin \theta +\frac{1}{2},\sqrt{3}\cos \theta +\sin \theta +\frac{\sqrt{3}}{2}\right)$
> >
> > 所以 $OP = OA + AP = \left( \cos \theta - \sqrt{3} \sin \theta - \frac{1}{2}, \sqrt{3} \cos \theta + \sin \theta + \frac{\sqrt{3}}{2} \right)$ ,
> >
> > 由 $O, Q, P$ 三点共线可知
> >
> > $$
> > \left(\cos \theta - \sqrt {3} \sin \theta - \frac {1}{2}\right) \times \frac {2}{3} \sin \theta = \left(\sqrt {3} \cos \theta + \sin \theta + \frac {\sqrt {3}}{2}\right) \times \frac {2}{3} (\cos \theta - 1),
> > $$
> >
> > 化简整理得 $\sin \left(\theta +\frac{\pi}{3}\right) = \frac{\sqrt{3}}{2}$
> >
> > 因为 $0 < \theta < \frac{\pi}{2}$ ， $\frac{\pi}{3} < \theta + \frac{\pi}{3} < \frac{5\pi}{6}$ ，所以 $\theta + \frac{\pi}{3} = \frac{2\pi}{3}$ ，则 $\theta = \frac{\pi}{3}$
