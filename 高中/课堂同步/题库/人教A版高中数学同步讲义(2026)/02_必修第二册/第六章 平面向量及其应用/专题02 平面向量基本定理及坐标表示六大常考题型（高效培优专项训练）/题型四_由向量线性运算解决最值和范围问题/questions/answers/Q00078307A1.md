> [!faq]- 《专题02 平面向量基本定理及坐标表示六大常考题型（高效培优专项训练）》官方解析
>
> > [!success]- **【答案】** (1) $32AB-22AC$ ; (2) $\left(-1,-\frac{1}{4}\right)$ .
>
> > [!note]- **【解析】**
> > （1）由已知得： $AB = (1,3), AC = (2,4), AD = (-3,5), BD = (-4,2), CD = (-5,1)$
> >
> > 所以 $AD + BD + CD = (-3, 5) + (-4, 2) + (-5, 1) = (-12, 8)$ .
> >
> > 由题设，存在实数 m, n 使得 $AD + BD + CD = mAB + nAC$
> >
> > 则 $(-12,8) = m(1,3) + n(2,4)$ ，即 $(-12,8) = (m + 2n,3m + 4n)$
> >
> > 可得 $\left\{ \begin{array}{l} m + 2n = -12 \\ 3m + 4n = 8 \end{array} \right.$ ，解得 $\left\{ \begin{array}{l} m = 32 \\ n = -22 \end{array} \right.$ .
> >
> > 所以 $AD + BD + CD = 32AB - 22AC.$
> >
> > (2) 设 $P(x, y)$ ，则 $\overline{AP} = (x - 1, y + 2)$
> >
> > 又 $AP = AB + \lambda AC = (1,3) + \lambda (2,4) = (1 + 2\lambda ,3 + 4\lambda)$
> >
> > 则 $\left\{ \begin{array}{l}x - 1 = 1 + 2\lambda \\ y + 2 = 3 + 4\lambda \end{array} \right.$ ，即 $\left\{ \begin{array}{l}x = 2 + 2\lambda \\ y = 1 + 4\lambda \end{array} \right.$ ，又点 $P$ 在第四象限，
> >
> > 所以 $\left\{\begin{aligned}2+2\lambda&>0\\ 1+4\lambda&<0\end{aligned}\right.$ ，解得： $-1<\lambda<-\frac{1}{4}$ ，故 $\lambda$ 的范围是 $\left(-1,-\frac{1}{4}\right)$ .
