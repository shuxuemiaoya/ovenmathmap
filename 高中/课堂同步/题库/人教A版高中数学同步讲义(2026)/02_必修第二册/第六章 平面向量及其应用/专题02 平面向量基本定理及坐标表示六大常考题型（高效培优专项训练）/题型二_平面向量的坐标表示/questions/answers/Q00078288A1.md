> [!faq]- 《专题02 平面向量基本定理及坐标表示六大常考题型（高效培优专项训练）》官方解析
>
> > [!success]- **【答案】** C
>
> > [!note]- **【解析】**
> > 由题意 $A(0,0),B\left(m,\frac{m}{1 + m}\right)$ ， $\overrightarrow{OQ} = \lambda \overrightarrow{OA} +\left(1 - \lambda\right)\overrightarrow{OB} = \left((1 - \lambda)m,\frac{(1 - \lambda)m}{1 + m}\right)$
> >
> > $$
> > x = \lambda a + (1 - \lambda) b = (1 - \lambda) m, y = \frac {(1 - \lambda) m}{(1 - \lambda) m + 1};
> > $$
> >
> > $$
> > P Q = O Q - O P = \left(0, \frac {(1 - \lambda) m}{m + 1} - \frac {(1 - \lambda) m}{(1 - \lambda) m + 1}\right),
> > $$
> >
> > $$
> > \left| \stackrel {\square \square \square} {P Q} \right| = \left| \frac {(1 - \lambda) m}{m + 1} - \frac {(1 - \lambda) m}{(1 - \lambda) m + 1} \right|,
> > $$
> >
> > $$
> > \text { 令 } t = (1 - \lambda) m, \text { 则 } t \in [ 0, m ]
> > $$
> >
> > $$
> > \left| \stackrel {\square \square \square} {P Q} \right| = \left| \frac {t}{m + 1} - \frac {t}{t + 1} \right| = \left| \frac {t + 1}{m + 1} + \frac {1}{t + 1} - 1 - \frac {1}{m + 1} \right|
> > $$
> >
> > $$
> > \text {令} g (t) = \frac {t + 1}{m + 1} + \frac {1}{t + 1} - 1 - \frac {1}{m + 1}, t \in [ 0, m ],
> > $$
> >
> > 由于 $g(0) = g(m) = 0$ ，且 $g(t) = 2\sqrt{\frac{1}{m + 1}} - 1 - \frac{1}{m + 1}$ ，当且仅当 $t = \sqrt{m + 1} - 1$ 时取到最小值·
> >
> > 因为 $f(x)$ 的峰值为 $\frac{1}{4}$ ，即 $\left|PQ\right|=\left|g(t)\right|$ 的最大值为 $\frac{1}{4}$ ，
> >
> > 所以 $2\sqrt{\frac{1}{m+1}}-1-\frac{1}{m+1}=-\frac{1}{4}$ ，解得 m=3 或 $m=-\frac{5}{9}$ （舍）.
> >
> > 故选 **C**
