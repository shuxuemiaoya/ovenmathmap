> [!faq]- 《专题02 平面向量基本定理及坐标表示六大常考题型（高效培优专项训练）》官方解析
>
> > [!success]- **【答案】** A. $m^{2} + n^{2}$ 的最小值是 4 B. b 在 a 上投影向量为 $\left(\frac{2}{5}, \frac{1}{5}\right)$ C. $|c|$ 的范围 $(0, 2\sqrt{5})$ D. $\frac{1}{m}+\frac{2}{n}\quad2$
>
> > [!note]- **【解析】**
> > 由 $a = (2,1), b = (1, -1)$ ，得 $a - b = (1,2)$ ，而 $c = (m - 2, -n)$ ， $(a - b) // c$ ，则 $2(m - 2) + n = 0$ ，即 $2m + n = 4$ ，又 $m > 0, n > 0$ ，则 $0 < m < 2$ ，
> >
> > 对于 A， $m^{2}+n^{2}=m^{2}+(4-2m)^{2}=5m^{2}-16m+16=5(m-\frac{8}{5})^{2}+\frac{16}{5}\quad\frac{16}{5}$
> >
> > 当且仅当 $m=\frac{8}{5}$ 时取等号，A 错误；
> >
> > 对于 B， $a \cdot b = 1, |a| = \sqrt{5}$ ，b 在 a 上投影向量 $\frac{a \cdot b}{|a|^{2}} a = \frac{1}{5} a = \left(\frac{2}{5}, \frac{1}{5}\right)$ ，B 正确；
> >
> > 对于 C， $|c|=\sqrt{(m-2)^{2}+n^{2}}=\sqrt{5}|m-2|\in(0,2\sqrt{5})$ ，C 正确；
> >
> > 对于 D， $\frac{1}{m}+\frac{2}{n}=\frac{1}{4}(2m+n)(\frac{1}{m}+\frac{2}{n})=\frac{1}{4}(4+\frac{n}{m}+\frac{4m}{n})\quad\frac{1}{4}(4+2\sqrt{\frac{n}{m}\cdot\frac{4m}{n}})=2$
> >
> > 当且仅当 $\frac{n}{m} = \frac{4m}{n}$ ，即 $n = 2m = 2$ 时取等号，D正确·
> >
> > 故选 **BCD**
