> [!faq]- 《第六章_平面向量及其应用_高效培优单元自测_强化卷_》官方解析
>
> > [!success]- **【答案】** A. 不存在最小值 B. $\frac{7}{2}$ C. 4 D. $\frac{9}{2}$
>
> > [!note]- **【解析】**
> > 设 $OA = OB + BA$ ，因为 A 在线段 BC 上（不含 BC 端点），
> >
> > 所以由向量共线定理设 $BA = \lambda BC, (0 < \lambda < 1)$
> >
> > 所以 $OA = OB + BA = OB + \lambda BC = OB + \lambda (BO + OC) = (1 - \lambda)OB + \lambda OC$
> >
> > 由题意有 $OA = xOB + yOC$ ，所以 $x + y = (1 - \lambda) + \lambda = 1$ ，所以 $x + y + 1 = 2$
> >
> > 所以 $\frac{1}{x} +\frac{4}{y + 1} = \frac{1}{2}\Big(x + y + 1\Big)\left(\frac{1}{x} +\frac{4}{y + 1}\right) = \frac{1}{2}\left(1 + 4 + \frac{y + 1}{x} +\frac{4x}{y + 1}\right)\quad \frac{1}{2}\Big(5 + 2\sqrt{4}\Big) = \frac{9}{2}$
> >
> > 当且仅当 $\left\{\begin{aligned}\frac{y+1}{x}&=\frac{4x}{y+1}\\ x+y&=1\end{aligned}\right.$ ，即 $\left\{\begin{aligned}x&=\frac{2}{3}\\ y&=\frac{1}{3}\end{aligned}\right.$ 时，等号成立.
> >
> > 所以 $\frac{1}{x} + \frac{4}{y + 1}$ 的最小值为 $\frac{9}{2}$ .
> >
> > 故选 **D**.
