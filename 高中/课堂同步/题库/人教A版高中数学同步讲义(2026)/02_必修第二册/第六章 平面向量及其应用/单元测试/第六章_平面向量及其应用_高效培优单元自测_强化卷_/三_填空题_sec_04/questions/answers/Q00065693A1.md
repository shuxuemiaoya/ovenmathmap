> [!faq]- 《第六章_平面向量及其应用_高效培优单元自测_强化卷_》官方解析
>
> > [!success]- **【答案】** (1) $A = \frac{\pi}{3}$ (2)VABC 面积的最大值为 $3\sqrt{3}$ ，周长的最大值为 $6\sqrt{3}$
>
> > [!note]- **【解析】**
> > （1）依题意 $\frac{\sin^2B + \sin^2C}{\sin A} = \sin A + \frac{\sin B\sin C}{\sin A}$ 得， $\sin^2 B + \sin^2 C = \sin^2 A + \sin B\sin C$
> >
> > 由正弦定理，得 $b^{2}+c^{2}=a^{2}+bc$ ，所以 $\cos A=\frac{b^{2}+c^{2}-a^{2}}{2bc}=\frac{1}{2}$ ，
> >
> > 因为 $A \in (0, \pi)$ ，所以 $A = \frac{\pi}{3}$ .
> >
> > (2) 由 $a^2 = b^2 + c^2 - 2bc\cos A$ 得， $12 = b^2 + c^2 - bc$ ， $2bc - bc = bc$ ，即 $bc \leq 12$ ，
> >
> > 当且仅当 $b = c = 2\sqrt{3}$ 时，等号成立，
> >
> > 所以VABC的面积 $S=\frac{1}{2}bc\sin A=\frac{\sqrt{3}}{4}bc\leq3\sqrt{3}$
> >
> > 所以 VABC 面积的最大值为 $3\sqrt{3}$ .
> >
> > 12 = $b^{2} + c^{2} - bc = (b + c)^{2} - 3bc$ $(b + c)^{2} - \frac{3(b + c)^{2}}{4} = \frac{(b + c)^{2}}{4}$
> >
> > 所以 $b + c \leq 4\sqrt{3}$ ，当且仅当 $b = c = 2\sqrt{3}$ 时，等号成立，
> >
> > 故VABC的周长为 $a + b + c \leq 6\sqrt{3}$
> >
> > 故VABC周长的最大值为 $6\sqrt{3}$ .
