> [!faq]- 《第六章_平面向量及其应用_高效培优单元自测_强化卷_》官方解析
>
> > [!success]- **【答案】** A
>
> > [!note]- **【解析】**
> > 由已知及正弦定理得 $\sin A\cos C + \sqrt{3}\sin A\sin C = \sin B + \sin C$
> >
> > $$
> > \sin A \cos C + \sqrt {3} \sin A \sin C = \sin (A + C) + \sin C = \sin A \cos C + \cos A \sin C + \sin C
> > $$
> >
> > 所以 $\sqrt{3}\sin A\sin C = \cos A\sin C + \sin C$ ，因为 $\sin C\neq 0$
> >
> > 所以 $\sqrt{3}\sin A - \cos A = 1$ ，即 $\sin(A - 30^{\circ}) = \frac{1}{2}$ ，因为 $-30^{\circ} < A - 30^{\circ} < 150^{\circ}$ ，
> >
> > 所以 $A-30^{\circ}=30^{\circ}$ ，从而 $A=60^{\circ}$ ，
> >
> > 由余弦定理得 $a^2 = b^2 + c^2 - 2bc\cos A$ ，即 $25 = b^2 + c^2 - bc = (b + c)^2 - 3bc$ ，又 $3bc \leq 3\left(\frac{b + c}{2}\right)^2$ ， $\therefore (b + c)^2 - 3bc = \frac{1}{4}(b + c)^2$ ，即 $25 = \frac{1}{4}(b + c)^2$
> >
> > $\therefore b + c \leq 10$ ，当且仅当 $b = c = 5$ 时等号成立，从而 $a + b + c \leq 15$
> >
> > ∴VABC 的周长的最大值为 15.
> >
> > 故选 **A**.
