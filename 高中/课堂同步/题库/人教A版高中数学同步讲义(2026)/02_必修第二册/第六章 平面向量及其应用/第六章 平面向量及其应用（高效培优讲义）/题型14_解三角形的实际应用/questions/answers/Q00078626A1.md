> [!faq]- 《第六章 平面向量及其应用（高效培优讲义）》官方解析
>
> > [!success]- **【答案】** ②③④
>
> > [!note]- **【分析】**
> > 结合题目给出条件以及直角三角形的边角关系，可知 $MA, MC, NB, NC$ 均已确定，对于①②③，可先
> >
> > 根据余弦定理判断 $AB$ 是否确定，再根据勾股定理判断 $MN$ 是否确定；对于④，可直接根据余弦定理进行判
> >
> > 断·
>
> > [!note]- **【解析】**
> > 设 $AB = c, AC = b, BC = a, MA = h_1, NB = h_2, CM = m, CN = n, \angle MCA = \theta, \angle NCB = \alpha$
> >
> > 在 Rt△MAC 中，CM = m = $\frac{CA}{\cos\angle MCA} = \frac{b}{\cos\theta}$ ， $MA = h_{1} = CA \cdot \tan\theta = b \tan\theta$
> >
> > 同理可得 $CN = n = \frac{a}{\cos \alpha}, NB = h_{2} = a \tan \alpha$
> >
> > 由于 $a, b, \theta, \alpha$ 均为已知量，故 $m, n, h_1, h_2$ 均为定值.
> > - **对于①**：在 $\forall ABC$ 中，由余弦定理可得 $b^{2} = a^{2} + c^{2} - 2ac\cos \angle ABC$ ，且 $a,b,\cos \angle ABC$ 均为定值，故该方程为
> >
> > 关于 c 的一元二次方程，c 可能有两解·
> >
> > 例如，若 $a = \sqrt{3}, b = 1, \cos \angle ABC = \frac{\sqrt{3}}{2}$
> >
> > <!-- source-part:3 pages:101-118 -->
> >
> > 则可得 $c^2 + 3 - 1 = 2 \cdot \sqrt{3} \cdot c \cdot \frac{\sqrt{3}}{2}$ ，即 $c^2 - 3c + 2 = 0$ ，解得 $c = 1$ 或 2，
> >
> > 由勾股定理可得 $MN = \sqrt{AB^{2} + (NB - MA)^{2}} = \sqrt{c^{2} + (h_{2} - h_{1})^{2}}$ ，由于 $h_{1}, h_{2}$ 为定值，而 c 有两解，故 MN 也有两解，
> >
> > 故①错误；
> > - **对于②**：在VABC中，由余弦定理可得 $c^{2}=a^{2}+b^{2}-2ab\cos\angle ACB$ ，且 $a,b,\cos\angle ACB$ 均为定值，故c也为定
> >
> > 值，
> >
> > 又因为 $MN = \sqrt{c^{2} + (h_{2} - h_{1})^{2}}$ ，其中 $c, h_{1}, h_{2}$ 均为定值，故 MN 为定值，故②正确；
> > - **对于③**：在 $\forall ABC$ 中，由余弦定理可得 $a^{2}=b^{2}+c^{2}-2bc\cos\angle BAC$ ，整理得 $c^{2}-2bc\cos\angle BAC+b^{2}-a^{2}=0$ 且 $a,b,\cos\angle BAC$
> >
> > $a,b,\cos \angle BAC$ 均为定值，
> >
> > 故该方程为关于 $c$ 的一元二次方程·又 $\because 0 < b < a, \therefore b^2 - a^2 < 0$
> >
> > 故 $\Delta = 4b^{2}(\cos \angle BAC)^{2} - 4(b^{2} - a^{2}) > 0$ ，即 $c$ 有两解，设两解分别为 $c_{1}, c_{2}$
> >
> > 由韦达定理可知， $c_{1}c_{2} = b^{2} - a^{2} < 0$ ，即 $c_{1}, c_{2}$ 异号，因此该方程仅有1个正数解，即 $c$ 有唯一确定解，
> >
> > 又因为 $MN = \sqrt{c^{2} + (h_{2} - h_{1})^{2}}$ ，其中 $c, h_{1}, h_{2}$ 均为定值，故 MN 为定值，故③正确；
> > - **对于④**：在 $\triangle MCN$ 中，由余弦定理可知， $MN^{2} = m^{2} + n^{2} - 2mn\cos \angle MCN$ ，因为 $m, n, \cos \angle MCN$ 均为定值，
> >
> > 故 $MN$ 也为定值，故④正确，
> >
> > 故答案为：②③④·
