> [!faq]- 《第六章 平面向量及其应用（高效培优讲义）》官方解析
>
> > [!success]- **【答案】** (1) $A=\frac{\pi}{6}$ 或 $A=\frac{5\pi}{6}$ (2) $S_{\triangle ABC} \in \left(2\sqrt{3}, 2 + \sqrt{3}\right]$
>
> > [!note]- **【分析】**
> > （1）先利用三角恒等变换的有关公式结合三角形内角和定理，得到 $2\sin A\sin B = \sin B$ ，再根据
> >
> > $\sin A=\frac{1}{2}$ 求角 A.
> >
> > (2) 确定角 A 的值，根据正弦定理表示出边 b, c，利用三角形的面积公式，结合三角函数的性质，求 $\forall ABC$
> >
> > 的面积的取值范围.
>
> > [!note]- **【解析】**
> > （1）由
> >
> > $$
> > 2 \sin B - \cos C = \frac {\sin C}{\tan A} = \frac {\cos A \sin C}{\sin A}
> > $$
> >
> > 得 $2\sin A\sin B - \sin A\cos C = \cos A\sin C$
> >
> > 即 $2\sin A\sin B = \sin A\cos C + \cos A\sin C = \sin (A + C) = \sin B$ 又 $\sin B\neq 0$
> >
> > 所以 $\sin A = \frac{1}{2}$ ，又 $A\in (0,\pi)$ ，所以 $A = \frac{\pi}{6}$ 或 $A = \frac{5\pi}{6}$
> >
> > (2) 因为 $\forall ABC$ 为锐角三角形，所以 $A = \frac{\pi}{6}$ ，由正弦定理得， $\frac{a}{\sin A} = \frac{b}{\sin B} = \frac{c}{\sin C} = 4$
> >
> > 即 $b = 4\sin B, c = 4\sin C$
> >
> > $$
> > S _ {\triangle A B C} = \frac {1}{2} b c \sin A = 4 \sin B \sin C = 4 \sin B \sin \left(\frac {5}{6} \pi - B\right)
> > $$
> >
> > $$
> > = 4 \sin B \left(\frac {1}{2} \cos B + \frac {\sqrt {3}}{2} \sin B\right) = 2 \sin B \cos B + 2 \sqrt {3} \sin^ {2} B
> > $$
> >
> > $$
> > = \sin 2 B - \sqrt {3} \cos 2 B + \sqrt {3} = 2 \sin \left(2 B - \frac {\pi}{3}\right) + \sqrt {3}
> > $$
> >
> > 又 $\left\{ \begin{array}{l} 0 < B < \frac{\pi}{2} \\ 0 < C = \frac{5}{6}\pi - B < \frac{\pi}{2} \\ \frac{\pi}{3} < B < \frac{\pi}{2} \end{array} \right.$ ，解得
> >
> > 则 $\frac{\pi}{3} < 2B - \frac{\pi}{3} < \frac{2}{3}\pi$ ， $\frac{\sqrt{3}}{2} < \sin \left(2B - \frac{\pi}{3}\right) \leq 1$
> >
> > 所以 $S_{\triangle ABC} \in \left(2\sqrt{3}, 2 + \sqrt{3}\right]$
