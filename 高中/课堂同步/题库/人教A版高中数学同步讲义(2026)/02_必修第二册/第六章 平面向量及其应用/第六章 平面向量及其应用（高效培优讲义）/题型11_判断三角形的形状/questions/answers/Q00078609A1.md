> [!faq]- 《第六章 平面向量及其应用（高效培优讲义）》官方解析
>
> > [!success]- **【答案】** A. 若 $A > B$ ，则 $\cos A < \cos B$ B．若 C 为钝角，则 $\cos A > \sin B$ C．当 k > 1 时，若 $a:b:c = k : (k + 1) : (k + 2)$ ，且 $\forall ABC$ 是钝角三角形，则 1 < k < 2 D．若 $A=\frac{\pi}{6}, b=2, a=\frac{\sqrt{15}}{2}$ ，则满足条件的三角形有两个
>
> > [!note]- **【分析】**
> > 对 $^{A}$ ：利用三角形内角性质结合余弦函数单调性计算即可得；对 $^{B}$ ：借助三角形内角性质与诱导公
> >
> > 式计算即可得；对 $^{C}$ ：借助余弦定理的推论计算即可得；对 $^{D}$ ：借助余弦定理计算可得c有两解，即可得解·
>
> > [!note]- **【解析】**
> > 对 A：由题意可得 $A, B, C \in (0, \pi)$ ，又 $y = \cos x$ 在 $(0, \pi)$ 上单调递减，
> >
> > 若 A > B ，则 $\cos A < \cos B$ ，故 A 正确；
> >
> > 对 B：若 C 为钝角，则 $A + B = \pi - C < \frac{\pi}{2}$ ，故 $0 < A < \frac{\pi}{2} - B < \frac{\pi}{2}$
> >
> > $\cos A > \cos \left( \frac{\pi}{2} - B \right) = \sin B$ 故，故 $^B$ 正确；
> >
> > 对 C：由 k > 1，则 a < b < c，故 C > B > A
> >
> > 设 $a = kt$ ，则 $B = (k + 1)t$ ， $C = (k + 2)t$ ， $t > 0$
> >
> > 故 $\cos C = \frac{a^2 + b^2 - c^2}{2ab} = \frac{t^2\left[k^2 + (k + 1)^2 - (k + 2)^2\right]}{2ab} < 0$
> >
> > 即 $2k^{2} + 2k + 1 < k^{2} + 4k + 4$ ，化简得 $k^2 - 2k - 3 = (k - 3)(k + 1) < 0$
> >
> > 则 $-1 < k < 3$ ，又 $k > 1$ ，有 $k + k + 1 - (k + 2) = k - 1 > 0$ ，则 $1 < k < 3$ ，故 $^C$ 错误；
> >
> > 对 ${}^{\mathrm{D}}$ ：由余弦定理 $a^2 = b^2 +c^2 -2bc\cos A$ 可得 $\frac{15}{4} = 4 + c^2 -2\times 2c\cdot \frac{\sqrt{3}}{2}$
> >
> > 即 $c^2 - 2\sqrt{3} c + \frac{1}{4} = 0$ ，解得 $c = \frac{2\sqrt{3} \pm \sqrt{11}}{2}$
> >
> > 即 $c$ 有两解，故满足条件的三角形有两个，故 $\mathbf{D}$ 正确·
> >
> > 故选 **ABD**.
