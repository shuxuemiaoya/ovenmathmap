> [!faq]- 《第六章 平面向量及其应用（高效培优单元自测·强化卷）》官方解析
>
> > [!success]- **【答案】** C
>
> > [!note]- **【解析】**
> > 由 $\sin \frac{B + C}{5} = \frac{a\sin B}{b}$ 得， $\sin \frac{B + C}{5} = \sin A$
> >
> > 因为 $0 < C < \frac{\pi}{2}$ ， $0 < B < \frac{\pi}{2}$ ，所以 $0 < \frac{B + C}{5} < \frac{\pi}{5}$ 。而 $0 < A < \frac{\pi}{2}$ ，所以 $\frac{B + C}{5} = A$ ，即 $B + C = 5A$ ，因此 $6A = \pi$ ， $A = \frac{\pi}{6}$ 。由 $0 < B < \frac{\pi}{2}$ 和 $0 < \frac{5\pi}{6} - B < \frac{\pi}{2}$ 得到， $\frac{\pi}{3} < B < \frac{\pi}{2}$ ，因此 $\sin \frac{\pi}{3} < \sin B < \sin \frac{\pi}{2}$ ， $\frac{\sqrt{3}}{2} < \sin B < 1$ 。于是 $\frac{a}{b} = \frac{\sin A}{\sin B} = \frac{1}{2\sin B} \in \left(\frac{1}{2}, \frac{\sqrt{3}}{3}\right)$ 。
> >
> > 故选 **C**.
