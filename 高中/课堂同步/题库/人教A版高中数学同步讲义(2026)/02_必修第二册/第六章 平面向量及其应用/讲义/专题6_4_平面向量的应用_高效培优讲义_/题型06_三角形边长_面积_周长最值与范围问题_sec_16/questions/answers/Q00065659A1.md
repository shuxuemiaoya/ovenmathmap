> [!faq]- 《专题6_4_平面向量的应用_高效培优讲义_》官方解析
>
> > [!success]- **【答案】** (1) $A=\frac{\pi}{3}$ (2) $a = 2\sqrt{7}$ (3) $b + c \in (3, 2\sqrt{3}]$
>
> > [!note]- **【解析】**
> > （1）因为 $b \cos C + c \cos B = 2a \cos A$
> >
> > 由正弦定理得 $\sin B\cos C + \sin C\cos B = 2\sin A\cos A$ ，即 $\sin (B + C) = 2\sin A\cos A$
> >
> > 因为在 $\triangle ABC$ 中， $\sin (B + C) = \sin A > 0$ ，所以 $\cos A = \frac{1}{2}$ ，
> >
> > 又 $0 < A < \pi$ ，所以 $A = \frac{\pi}{3}$ .
> >
> > (2) 因为 $A = \frac{\pi}{3}$ ，b = 2， $S_{\triangle ABC} = 3\sqrt{3}$ ，所以 $\frac{1}{2}bc\sin A = 3\sqrt{3}$ ，解得 c = 6。
> >
> > 由余弦定理得 $a = \sqrt{b^2 + c^2 - 2bc\cos A} = \sqrt{4 + 36 - 2\times 2\times 6\times\frac{1}{2}} = 2\sqrt{7}$
> >
> > (3) 因为 $A = \frac{\pi}{3}$ ， $a = \sqrt{3}$ ，
> >
> > 结合正弦定理，得 $\frac{b}{\sin B} = \frac{c}{\sin C} = \frac{\sqrt{3}}{\sin \frac{\pi}{3}} = 2$ ，所以 $b = 2\sin B, c = 2\sin C$
> >
> > 在 $\triangle ABC$ 中， $\sin C = \sin(A + B) = \sin\left(B + \frac{\pi}{3}\right)$ ,
> >
> > 所以 $b + c = 2\sin B + 2\sin C = 2\sin B + 2\sin \left(B + \frac{\pi}{3}\right) = 2\sin B + 2\sin B\cos \frac{\pi}{3} + 2\cos B\sin \frac{\pi}{3}$
> >
> > $$
> > = 3 \sin B + \sqrt {3} \cos B = 2 \sqrt {3} \sin \left(B + \frac {\pi}{6}\right)
> > $$
> >
> > 因为 为锐角三角形，所以 $\left\{\begin{aligned}0&<B<\frac{\pi}{2}\\ 0&<C=\frac{2\pi}{3}-B<\frac{\pi}{2}\end{aligned}\right.$ ，所以 $\frac{\pi}{6}<B<\frac{\pi}{2}$ ，
> >
> > 则 $\frac{\pi}{3} < B + \frac{\pi}{6} < \frac{2\pi}{3}$ ，所以 $\sin \left(B + \frac{\pi}{6}\right) \in \left(\frac{\sqrt{3}}{2}, 1\right]$ ，
> >
> > 所以 $b + c \in (3, 2\sqrt{3}]$
