## 题型07 面积与周长求值问题

【典例1】已知 $a, b, c$ 分别为VABC三个内角 $A, B, C$ 的对边，且 $a \cos C + \sqrt{3} a \sin C - b - c = 0$ ，且 $a = 2$

(1)求 $A$

(2)若VABC的面积为 $\sqrt{3}$ ，求b,c

(3)求VABC周长的取值范围.

【答案】(1) $A=\frac{\pi}{3}$

(2) $b = c = 2$

(3) $(4,6]$

【小题1】由正弦定理得 $\sin A\cos C + \sqrt{3}\sin A\sin C - \sin B - \sin C = 0$

其中 $\sin B = \sin(A + C) = \sin A \cos C + \cos A \sin C$

故 $\sqrt{3}\sin A\sin C - \cos A\sin C - \sin C = 0$

因为 $C\in (0,\pi)$ ，所以 $\sin C\neq 0$ ，故 $\sqrt{3}\sin A - \cos A = 1$

即 $2\sin \left(A - \frac{\pi}{6}\right) = 1$ ，所以 $\sin \left(A - \frac{\pi}{6}\right) = \frac{1}{2}$

因为 $A \in (0, \pi)$ ，所以 $A - \frac{\pi}{6} \in \left(-\frac{\pi}{6}, \frac{5\pi}{6}\right)$

故 $A - \frac{\pi}{6} = \frac{\pi}{6}$ ，解得 $A = \frac{\pi}{3}$ ；

【小题2】由（1）知 $A=\frac{\pi}{3}$ ，则 $S=\frac{1}{2}bc\sin A=\frac{\sqrt{3}}{4}bc=\sqrt{3}$ ，所以 bc=4，

由余弦定理， $a^2 = b^2 + c^2 - 2bc\cos A$ ，又 $a = 2$

则 $4 = b^{2} + c^{2} - bc = (b + c)^{2} - 3bc = (b + c)^{2} - 12$

解得 $b+c=4$ ，所以b=c=2；

【小题3】（方法一）因为 $A = \frac{\pi}{3}, a = 2$ ，由正弦定理

得 $b=\frac{4\sqrt{3}}{3}\sin B,c=\frac{4\sqrt{3}}{3}\sin C$

$B + C = \pi - A = \frac{2\pi}{3}$ $C = \frac{2\pi}{3} - B$ 又因为，所以

所以 $b + c = \frac{4\sqrt{3}}{3}\sin B + \frac{4\sqrt{3}}{3}\sin\left(\frac{2\pi}{3} - B\right) = 2\cos B + 2\sqrt{3}\sin B = 4\sin\left(B + \frac{\pi}{6}\right)$

又因为 $B \in \left(0, \frac{2\pi}{3}\right)$ ，所以 $B + \frac{\pi}{6} \in \left(\frac{\pi}{6}, \frac{5\pi}{6}\right)$

所以 $\frac{1}{2}<\sin\left(B+\frac{\pi}{6}\right)\leq1$

所以 $2 < 4 \sin \left( B + \frac{\pi}{6} \right) \leq 4$

即 $2 < b + c \leq 4$ ，所以 $4 < a + b + c \leq 6$

所以三角形 ABC 的周长的取值范围 $(4,6]$ .

（方法二）因为 $A = \frac{\pi}{3}, a = 2$ ，由余弦定理 $a^2 = b^2 + c^2 - 2bc\cos A$ ，得 $4 = b^2 + c^2 - 2bc \cdot \frac{1}{2}$

即 $4 = (b + c)^2 - 3bc$ ，又 $bc \leq \left(\frac{b + c}{2}\right)^2$ ，当且仅当 $b = c$ 时等号成立.

所以 $4 = (b + c)^2 - 3bc$ $(b + c)^2 - 3\left(\frac{b + c}{2}\right)^2 = \frac{1}{4} (b + c)^2$ 即 $4\frac{1}{4} (b + c)^2$

所以 $b + c \leq 4$ ，又因为 $b + c > a$ ，所以 $2 < b + c \leq 4$ ，所以 $4 < a + b + c \leq 6$

所以三角形 ABC 的周长的取值范围为 $(4,6]$ .
