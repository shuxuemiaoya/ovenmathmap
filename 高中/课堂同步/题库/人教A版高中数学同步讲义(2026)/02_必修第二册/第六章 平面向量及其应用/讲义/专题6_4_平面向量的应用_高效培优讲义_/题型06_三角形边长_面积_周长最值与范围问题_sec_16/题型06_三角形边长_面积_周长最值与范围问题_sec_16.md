## 题型06 三角形边长、面积、周长最值与范围问题

【典例1】已知锐角三角形 $ABC$ 中，角 $A$ 、 $B$ 、 $C$ 的对边分别为 $a$ 、 $b$ 、 $c$ ，且满足 $\frac{\sin A}{\sin C} - 1 = \frac{\sin^2 A - \sin^2 C}{\sin^2 B}$

$A^{1}C$

(1)求证： $B = 2C$

(2)求 $\frac{1}{\cos C} +\frac{a}{b}$ 的取值范围；

(3)若 $a = 2$ ，求三角形 $ABC$ 面积的取值范围.

【答案】(1)证明见解析；

$$
\left(\frac {3 \sqrt {2}}{2}, \frac {4 \sqrt {3}}{3}\right)
$$

(3) $\left(\frac{\sqrt{3}}{2},2\right)$ .

【详解】（1）由 $\frac{\sin A}{\sin C} - 1 = \frac{\sin^2 A - \sin^2 C}{\sin^2 B}$ 及正弦定理可得 $\frac{a}{c} - 1 = \frac{a^2 - c^2}{b^2}$ ，即 $\frac{a - c}{c} = \frac{a^2 - c^2}{b^2}$

因为 $A^{1}$ C，则 $a \neq c$ ，所以 $\frac{1}{c} = \frac{a + c}{b^{2}}$ ，即 $b^{2} = c^{2} + ac$ ，

由余弦定理可得 $c^2 + ac = b^2 = a^2 + c^2 - 2ac\cos B$ ，所以 $ac = a^2 - 2ac\cos B$

所以 $c = a - 2c\cos B$ ，由正弦定理可得 $\sin C = \sin A - 2\cos B\sin C$

$$
= \sin (B + C) - 2 \cos B \sin C = \sin B \cos C + \cos B \sin C - 2 \cos B \sin C
$$

$$
= \sin B \cos C - \cos B \sin C = \sin (B - C)
$$

因为 $\mathrm{V}ABC$ 为锐角三角形，故 $0 < B < \frac{\pi}{2}$ ， $0 < C < \frac{\pi}{2}$ ，所以 $-\frac{\pi}{2} < B - C < \frac{\pi}{2}$ ，

又函数 $y = \sin x$ 在 $\left(-\frac{\pi}{2}, \frac{\pi}{2}\right)$ 上单调递增，且 $\sin C = \sin (B - C)$ ，故 $C = B - C$ ，即 $B = 2C$ .

(2) $\frac{1}{\cos C} + \frac{a}{b} = \frac{1}{\cos C} + \frac{\sin A}{\sin B} = \frac{1}{\cos C} + \frac{\sin(B + C)}{\sin B} = \frac{1}{\cos C} + \frac{\sin B \cos C + \cos B \sin C}{\sin B}$

$$
= \frac {1}{\cos C} + \frac {\sin 2 C \cos C + \cos 2 C \sin C}{\sin 2 C} = \frac {1}{\cos C} + \frac {2 \sin C \cos^ {2} C + \cos 2 C \sin C}{2 \sin C \cos C}
$$

$$
= \frac {1}{\cos C} + \cos C + \frac {2 \cos^ {2} C - 1}{2 \cos C} = 2 \cos C + \frac {1}{2 \cos C}
$$

因为 为锐角三角形，故 $\left\{ \begin{array}{l}0 < C < \frac{\pi}{2}\\ 0 < B = 2C < \frac{\pi}{2}\\ 0 < A = \pi -3C < \frac{\pi}{2} \end{array} \right.$ ，解得

又因为 $A = \pi - 3C \neq C$ ，可得 $C \neq \frac{\pi}{4}$ ，故角 $C$ 的取值范围是 $\left(\frac{\pi}{6}, \frac{\pi}{4}\right)$

所以 $\frac{\sqrt{2}}{2}<\cos C<\frac{\sqrt{3}}{2}$ ，故 $\sqrt{2}<2\cos C<\sqrt{3}$ ，

$$
t = 2 \cos C \in (\sqrt {2}, \sqrt {3}), f (t) = t + \frac {1}{t}
$$

任取 $t_1$ 、 $t_2 \in (\sqrt{2}, \sqrt{3})$ 且 $t_1 < t_2$

$$
f \left(t _ {1}\right) - f \left(t _ {2}\right) = \left(t _ {1} + \frac {1}{t _ {1}}\right) - \left(t _ {2} + \frac {1}{t _ {2}}\right) = \left(t _ {1} - t _ {2}\right) - \left(\frac {1}{t _ {2}} - \frac {1}{t _ {1}}\right) = \left(t _ {1} - t _ {2}\right) - \frac {t _ {1} - t _ {2}}{t _ {1} t _ {2}}
$$

$$
= \left(t _ {1} - t _ {2}\right) \left(1 - \frac {1}{t _ {1} t _ {2}}\right) = \frac {\left(t _ {1} - t _ {2}\right) \left(t _ {1} t _ {2} - 1\right)}{t _ {1} t _ {2}},
$$

因为 $\sqrt{2} < t_1 < t_2 < \sqrt{3}$ ，所以 $t_1 - t_2 < 0$ ，则 $t_1t_2 > 1$ ，所以 $f(t_1) - f(t_2) = \frac{(t_1 - t_2)(t_1t_2 - 1)}{t_1t_2} < 0$

所以函数 $f(t)$ 在 $(\sqrt{2},\sqrt{3})$ 上为增函数，故 $\frac{1}{\cos C} +\frac{a}{b} = 2\cos C + \frac{1}{2\cos C}\in \left(\frac{3\sqrt{2}}{2},\frac{4\sqrt{3}}{3}\right)$

故 $\frac{1}{\cos C}+\frac{a}{b}$ 的取值范围是 $\left(\frac{3\sqrt{2}}{2},\frac{4\sqrt{3}}{3}\right)$ .

（3）由正弦定理可得 $\frac{b}{\sin B} = \frac{c}{\sin C} = \frac{a}{\sin A} = \frac{2}{\sin A}$ ，所以 $b = \frac{2\sin B}{\sin A}$ ， $c = \frac{2\sin C}{\sin A}$

所以 $S_{\triangle ABC}=\frac{1}{2}bc\sin A=\frac{1}{2}\times\frac{2\sin B}{\sin A}\times\frac{2\sin C}{\sin A}\times\sin A=\frac{2\sin B\sin C}{\sin A}=\frac{2\sin 2C\sin C}{\sin(\pi-3C)}=\frac{2\sin 2C\sin C}{\sin(3C)}$

$$
= \frac {4 \sin^ {2} C \cos C}{\sin 2 C \cos C + \cos 2 C \sin C} = \frac {4 \sin^ {2} C \cos C}{4 \sin C \cos^ {2} C - \sin C} = \frac {4 \sin^ {2} C \cos C}{4 \sin C \cos^ {2} C - \sin C (\sin^ {2} C + \cos^ {2} C)} = \frac {4 \sin^ {2} C \cos C}{3 \sin C \cos^ {2} C - \sin^ {3} C}
$$

$$
= \frac {4 \sin C \cos C}{3 \cos^ {2} C - \sin^ {2} C} = \frac {4 \tan C}{3 - \tan^ {2} C} = \frac {4}{\frac {3}{\tan C} - \tan C},
$$

因为 $C\in \left(\frac{\pi}{6},\frac{\pi}{4}\right)$ ，所以 $\tan C\in \left(\frac{\sqrt{3}}{3},1\right)$

令 $x = \tan C\in \left(\frac{\sqrt{3}}{3},1\right)$ ，函数 $y = \frac{3}{x}$ 、 $y = -x$ 在 $\left(\frac{\sqrt{3}}{3},1\right)$ 上均为减函数，

故函数 $y = \frac{3}{x} - x$ 在 $\left(\frac{\sqrt{3}}{3}, 1\right)$ 上为减函数，所以 $y = \frac{3}{x} - x \in \left(2, \frac{8\sqrt{3}}{3}\right)$ ，即 $\frac{3}{\tan C} - \tan C \in \left(2, \frac{8\sqrt{3}}{3}\right)$

因此 $S_{\triangle ABC} = \frac{4}{\frac{3}{\tan C} - \tan C} \in \left( \frac{\sqrt{3}}{2}, 2 \right)$ ，即 VABC 面积的取值范围是 $\left( \frac{\sqrt{3}}{2}, 2 \right)$ .
