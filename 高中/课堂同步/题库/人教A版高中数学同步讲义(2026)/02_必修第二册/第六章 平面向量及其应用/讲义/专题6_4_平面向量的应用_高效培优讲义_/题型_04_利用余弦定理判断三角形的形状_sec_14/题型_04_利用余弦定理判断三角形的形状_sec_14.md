## 题型 04 利用余弦定理判断三角形的形状

【典例1】已知VABC的内角A，B，C的对边分别为a，b，c，以下判断正确的是（）

A．若 $\sin A > \sin B$ ，则 A > B

B．若 $\sin^{2}A + \sin^{2}B - \sin^{2}C < 0$ ，则 VABC 是钝角三角形

C．若 $a = \sqrt{5}$ ， $b = \sqrt{15}$ ， $A = 30^{\circ}$ ，则符合条件的VABC有两个

D．若 $a\cos A = b\cos B$ ，则 VABC 为等腰直角三角形

【答案】ABC

【详解】对 A，由 $\sin A > \sin B$ 和正弦定理可得 a > b，由大边对大角可知 A > B，正确；

对 B，由 $\sin^{2}A + \sin^{2}B - \sin^{2}C < 0$ 和正弦定理可得 $a^{2} + b^{2} - c^{2} < 0$

所以 $\cos C = \frac{a^{2} + b^{2} - c^{2}}{2ab} < 0$ ，又 $C \in (0, \pi)$ ，所以 $C \in \left( \frac{\pi}{2}, \pi \right)$ ，正确；

对 C，若 $a=\sqrt{5}$ ， $b=\sqrt{15}$ ， $A=30^{\circ}$ ，则 $b\sin A=\frac{\sqrt{15}}{2}<\frac{\sqrt{20}}{2}=\sqrt{5}<\sqrt{15}$

即 $b \sin A < a < b$ ，所以符合条件的 VABC 有两个，正确；

对D，若 $a\cos A = b\cos B$ ，则 $\sin A\cos A = \sin B\cos B$ ，即 $\sin 2A = \sin 2B$

因为 $2A, 2B \in (0, 2\pi), 2A + 2B \in (0, 2\pi)$ ，所以 $2A = 2B$ 或 $2A + 2B = \pi$

即 A = B 或 $A + B = \frac{\pi}{2}$ ，

当 $A + B = \frac{\pi}{2}$ 时， $C = \pi - (A + B) = \frac{\pi}{2}$ ，此时 $\mathrm{V}ABC$ 为直角三角形；

当 A = B 时，VABC 为等腰三角形.

所以 VABC 为直角三角形或等腰三角形，错误.

故选：ABC

## 方法技巧

1、利用三角形的边角关系判断三角形的形状时，需要从“统一”入手，即使用转化思想解决问题，一般有两条思考路线

（1）先化边为角，再进行三角恒等变换，求出三角之间的数量关系.

(2) 先化角为边，再进行代数恒等变换，求出三边之间的数量关系.

2、判断三角形的形状时，经常用到以下结论

(1) $\triangle ABC$ 为直角三角形 $\Leftrightarrow a^2 = b^2 + c^2$ 或 $c^2 = a^2 + b^2$ 或 $b^2 = a^2 + c^2$ .

(2) $\triangle ABC$ 为锐角三角形 $\Leftrightarrow a^2 + b^2 > c^2$ ，且 $b^2 + c^2 > a^2$ ，且 $c^2 + a^2 > b^2$ 。

(3) $\triangle ABC$ 为钝角三角形 $\Leftrightarrow a^2 + b^2 < c^2$ 或 $b^2 + c^2 < a^2$ 或 $c^2 + a^2 < b^2$ .

(4) 若 $\sin 2A = \sin 2B$ ，则 A = B 或 $A + B = \frac{\pi}{2}$ .
