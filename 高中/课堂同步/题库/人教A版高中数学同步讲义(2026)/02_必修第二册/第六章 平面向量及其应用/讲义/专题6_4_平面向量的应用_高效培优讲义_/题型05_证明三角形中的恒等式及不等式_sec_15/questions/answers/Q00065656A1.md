> [!faq]- 《专题6_4_平面向量的应用_高效培优讲义_》官方解析
>
> > [!success]- **【答案】** (1) $C=\frac{\pi}{3}$ (2)证明见解析 (3) $\sqrt{3}$
>
> > [!note]- **【解析】**
> > （1）由 $c^2 = a^2 + b^2 - 2ab\cos C$ ， $a = b$
> >
> > $a^2 + b^2 + c^2 = 4\sqrt{3} \times \frac{1}{2} ab \sin C = 2\sqrt{3} ab \sin C$ ，联立得 $\sqrt{3} \sin C + \cos C = 2$
> >
> > 则 $2\sin \left(C + \frac{\pi}{6}\right) = 2\Rightarrow \sin \left(C + \frac{\pi}{6}\right) = 1$ ，因为 $0 <   C <   \pi$ ， $\frac{\pi}{6} <  C + \frac{\pi}{6} <  \frac{7\pi}{6}$
> >
> > 所以 $C + \frac{\pi}{6} = \frac{\pi}{2}$ ，即 $C = \frac{\pi}{3}$ ;
> >
> > $$
> > a ^ {2} + b ^ {2} + c ^ {2} - 4 \sqrt {3} S = a ^ {2} + b ^ {2} + c ^ {2} - 2 \sqrt {3} a b \sin C = 2 (a ^ {2} + b ^ {2} - a b \cos C - \sqrt {3} a b \sin C) \tag {2}
> > $$
> >
> > $$
> > 2 (2 a b - a b \cos C - \sqrt {3} a b \sin C) = 2 a b (2 - \cos C - \sqrt {3} \sin C) = 4 a b [ 1 - \sin (C + \frac {\pi}{6}) ]
> > $$
> >
> > 当且仅当 a = b 时等号成立；
> >
> > 因为 $\sin\left(C+\frac{\pi}{6}\right)\leq1$ ，所以 $1-\sin\left(C+\frac{\pi}{6}\right)$ 0
> >
> > 此时 $C = \frac{\pi}{3}$ ，当且仅当VABC是等边三角形时等号成立
> >
> > 则 $a^2 + b^2 + c^2 - 4\sqrt{3} S$ 0，即 $a^2 + b^2 + c^2$ $4\sqrt{3} S$
> >
> > $$
> > \text {(3)} \text {因为} \frac {b}{a \sin C} + \frac {\cos B}{\sin B} = \frac {b \sin B + a \sin C \cos B}{a \sin C \sin B} = \frac {b ^ {2} + a c \cos B}{a b \sin C} = \frac {b ^ {2} + a c \times \frac {a ^ {2} + c ^ {2} - b ^ {2}}{2 a c}}{a b \sin C}
> > $$
> >
> > $$
> > \frac {b}{a \sin C} + \frac {\cos B}{\sin B} = \frac {a ^ {2} + c ^ {2} + b ^ {2}}{2 a b \sin C} \quad \frac {4 \sqrt {3} S}{2 a b \sin C} = \frac {2 \sqrt {3} a b \sin C}{2 a b \sin C} = \sqrt {3}
> > $$
> >
> > 当且仅当VABC是等边三角形时等号成立.
