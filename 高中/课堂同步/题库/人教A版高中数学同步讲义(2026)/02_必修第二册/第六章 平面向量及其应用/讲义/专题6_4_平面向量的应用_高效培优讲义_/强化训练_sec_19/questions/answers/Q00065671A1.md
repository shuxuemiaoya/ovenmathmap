> [!faq]- 《专题6_4_平面向量的应用_高效培优讲义_》官方解析
>
> > [!success]- **【答案】** 1.6（答案不唯一）
>
> > [!note]- **【解析】**
> > 在锐角VABC中， $A,B\in \left(0,\frac{\pi}{2}\right)$ ，则 $2B\in (0,\pi)$ ，又 $\cos A = \cos 2B$
> >
> > 所以 A = 2B ，
> >
> > 又 $\left\{ \begin{array}{ll}0 <   2B <   \frac{\pi}{2}\\ 0 <   B <   \frac{\pi}{2} \end{array} \right.$ ，所以，所以 $0 <   \pi -3B <   \frac{\pi}{2}$ $\frac{\pi}{6} <  B <   \frac{\pi}{4}$ $\frac{\sqrt{2}}{2} <  \cos B <   \frac{\sqrt{3}}{2}$
> >
> > 所以 $\frac{a}{b} = \frac{\sin A}{\sin B} = \frac{\sin 2B}{\sin B} = \frac{2\sin B\cos B}{\sin B} = 2\cos B\in \left(\sqrt{2},\sqrt{3}\right)$
> >
> > 故符合题意的值可取1.6.
> >
> > 故答案为：1.6（答案不唯一）
