> [!faq]- 《专题6_3_平面向量基本定理及坐标表示_高效培优讲义_》官方解析
>
> > [!success]- **【答案】** A
>
> > [!note]- **【解析】**
> > 由题设 $AC = -a + 13b, BD = a + 5b$
> >
> > $AB = a + 5b$ $BD = a + 5b$ $AB = BD$ $AB$ $BD$ 与有公共端点 $B$ ，所以 $A,B,D$ 三点共线，A对； $AB = a + 5b$ $BC = -2a + 8b$ ，不存在 $\lambda$ $AB = \lambda BC$ ，
> >
> > 所以 $\stackrel{\mathrm{UUU}}{AB}$ 与 $\stackrel{\mathrm{UUU}}{BC}$ 不共线，即 $A,B,C$ 三点不共线，B错； $\stackrel{\mathrm{UUU}}{BC} = -2a + 8b$ ， $\stackrel{\mathrm{UUU}}{CD} = 3(a - b)$ ，不存在 $\lambda$ ，使 $\stackrel{\mathrm{UUU}}{CD} = \lambda BC$
> >
> > 所以 $\overset{\cup}{B}C$ 与 $\overset{\cup}{C}D$ 不共线，即 B, C, D 三点不共线，C 错； $AC = -a + 13b$ ， $CD = 3(a - b)$ ，不存在 $\lambda$ ，使 $CD = \lambda AC$ ，所以 $\overset{\square\square}{AC}$ 与 $\overset{\square\square}{CD}$ 不共线，即 A, C, D 三点不共线，D 错；
> >
> > 故选 **A**
