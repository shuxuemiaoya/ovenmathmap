> [!faq]- 《专题6_2_平面向量的运算_高效培优讲义_》官方解析
>
> > [!success]- **【答案】** ACD
>
> > [!note]- **【解析】**
> > 由题设 $|a-b|=|c|=2$ ，A对，
> >
> > 由 $\left|a\right|=1,\left|b\right|=\sqrt{3},\quad(\vec{a}-b)^{2}=\vec{c}^{2}\Rightarrow a^{2}-2a\cdot b+b^{2}=\vec{c}^{2}\Rightarrow4-2a\cdot b=4\Rightarrow a\cdot b=0,$
> >
> > 所以 $(a + b)^2 = a^2 + 2a \cdot b + b^2 = 4$ ，则 $\left|a + b\right| = 2$ ，B 错，
> >
> > 由上知 $a \perp b$ 且 $a - b = c$ ， $\left|a\right| = 1$ ， $\left|b\right| = \sqrt{3}$ ， $\left|c\right| = 2$ ，如下图 $a = \overline{OA}, b = \overline{OB}, c = \overline{BA}$
> >
> > 显然三个向量构成一个直角三角形，且 $a, c = 60^{\circ}, b, c = 150^{\circ}$
> >
> > ![](../../../images/questions/a3f238acca70a9a654f4334b453fdbcd832c9868248aa8e6578a0f059a791e10.jpg)
> >
> > 所以 $a + b - c = OA + OB - BA = OB + OA + AB = 2OB = 2b$ ，D 对，
> >
> > 由 $\left|a + b + c\right|^2 = a^2 +b^2 +c^2 +2a\cdot b + 2a\cdot c + 2b\cdot c = 1 + 3 + 4 + 0 + 2 - 6 = 4$
> >
> > 所以 $\left|a+b+c\right|=2$ ，C 对.
> >
> > 故选 **ACD**
