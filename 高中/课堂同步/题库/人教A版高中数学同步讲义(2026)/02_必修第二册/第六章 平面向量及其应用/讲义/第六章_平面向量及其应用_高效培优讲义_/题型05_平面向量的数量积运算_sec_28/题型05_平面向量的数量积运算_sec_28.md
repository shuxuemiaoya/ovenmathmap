## 题型05 平面向量的数量积运算

【典例1】已知向量 $a = (1, -m)$ ， $b = (3m + 2, -1)$ ，且 $a \perp b$ ，则 $m = (\quad)$ A. -1 B. 3 C. $\frac{1}{3}$ D. $-\frac{1}{2}$

【答案】D

【分析】将垂直转化为数量积为零计算即可·

【详解】∵ $a \perp b$ ，∴ $a \cdot b = 3m + 2 + (-1) \times (-m) = 4m + 2 = 0$ ，
∴ $m = -\frac{1}{2}$ ,

故选：D

【典例2】 $a,b,c$ 起点重合， $\left|a\right| = 2\sqrt{3},\left|b\right| = 4, < a,b > = \frac{\pi}{6},(a - c)\cdot (b - c) = 0$ ，则 $|c|$ 的取值范围为【答案】 $\left[\sqrt{13} -1,\sqrt{13} +1\right]$

【分析】根据数量积公式，可得 $a \cdot b = 12$ ，根据求模公式，可得 $\left|a + b\right| = 2\sqrt{13}$ ，根据题意，化简可得

$\cos \left\langle \overrightarrow{c}, a + \overrightarrow{b} \right\rangle = \frac{\left|\overrightarrow{c}\right|^2 + 12}{2\sqrt{13}\left|\overrightarrow{c}\right|}$ ，根据 $-1 \leq \cos < c, a + b > \leq 1$ ，结合一元二次不等式的解法，即可得答案。

$\rightarrow\overrightarrow{a}\cdot b=\left|a\right|\cdot\left|b\right|\cos\left\langle a,b\right\rangle=2\sqrt{3}\times4\times\frac{\sqrt{3}}{2}=12$ 【详解】由题意

$\left|\vec{a} + b\right|^2 = \left|a\right|^2 +\left|b\right|^2 +2a\cdot b = 12 + 16 + 24 = 52$ ，则 $\left|a + b\right| = 2\sqrt{13}$

因为 $\left(a - c\right)\cdot \left(b - c\right) = 0$

所以 $a \cdot b - a \cdot c - b \cdot c + c^{2} = 0$

所以 $c^2 = |c|^2 = -12 + c \cdot (a + b) = -12 + |c| \cdot |a + b| \cos \langle c, a + b \rangle$

所以 $\cos\left\langle\vec{c},a+\vec{b}\right\rangle=\frac{\left|\vec{c}\right|^{2}+12}{2\sqrt{13}\left|\vec{c}\right|}$

因为 $-1 \leq \cos < c, a + b > \leq 1$ ，所以 $-1 \leq \frac{\left|c\right|^2 + 12}{2\sqrt{13}\left|c\right|} \leq 1$

整理得 $\left|c\right|^{2}-2\sqrt{13}\left|c\right|+12\leq0$ 且 $\left|c\right|^{2}+2\sqrt{13}\left|c\right|+12\quad0$ （恒成立），

解得 $\sqrt{13} - 1 \leq |c| \leq \sqrt{13} + 1$

故答案为： $\left[\sqrt{13} - 1, \sqrt{13} + 1\right]$

## 方法技巧

(1) 求平面向量的数量积是较为常规的题型，最重要的方法是紧扣数量积的定义找到解题思路。

(2) 平面向量数量积的几何意义及坐标表示，分别突出了它的几何特征和代数特征，因而平面向量数量积是

中学数学较多知识的交汇处，因此它的应用也就十分广泛。

(3) 平面向量的投影问题，是近几年的高考热点问题，应熟练掌握其公式：向量 $a$ 在向量 $b$ 方向上的投影为 $\frac{a \div b}{|b|}$ .

(4) 向量运算与整式运算的同与异（无坐标的向量运算）

同： $(a \pm b)^{2} = a^{2} \pm 2ab + b^{2}$ ; $\left|a \pm b\right| = \sqrt{a^{2} \pm 2ab + b^{2}}$ ; $a(b + c) = ab + ac$ 公式都可通用

异：整式： $a\cdot b = \pm |a|||b|$ ， $|a|$ 仅仅表示数；向量： $a\cdot b = \pm |a||b|\cos \theta$ （ $\theta$ 为 $a$ 与 $b$ 的夹角）

$\left|ma \pm nb\right| = \sqrt{m^2 \left|a\right|^2 \pm 2mn \left|a\right|\left|b\right|\cos\theta + n^2 \left|b\right|^2}$ ，使用范围广泛，通常是求模或者夹角。 $\left|m a\right| - \left|n b\right| \leq \left|m a \pm n b\right| \leq \left|m a\right| + \left|n b\right|$ ，通常是求 $\left|m a \pm n b\right|$ 最值的时候用。【变式1】已知向量 $a, b$ 满足 $\left|a\right| = 1, \left|2a - b\right| = 4$ ，且 $(a + 2b) \perp a$ ，则 $\left|b\right| = (\quad)$ A. $\sqrt{5}$ B. $\sqrt{10}$ C. 5 D. 10

【答案】B

【分析】利用向量的模长与数量积运算即可求解·

【详解】因为 $\left(a + 2b\right) \perp a$ ，所以 $\left(a + 2b\right) \cdot a = 0$

展开得 $a \cdot a + 2a \cdot b = 0$ ，又 $\left|a\right| = 1$ ，所以 $a \cdot b = -\frac{1}{2}$ 。

因为 $\left|2a-b\right|=4$ ，则 $\left|2a-b\right|^{2}=16$ ，所以 $4\left|\vec{a}\right|^{2}-4a\cdot b+\left|b\right|^{2}=16$

解得 $\left|b\right|=\sqrt{10}$ （负值舍去）.

故选：B
