> [!faq]- 《第六章_平面向量及其应用_高效培优讲义_》官方解析
>
> > [!success]- **【答案】** (1) $\frac{\pi}{3}$ (2) $\left(3\sqrt{3} + 3,9\right]$
>
> > [!note]- **【分析】**
> > （1）本题可先根据向量数量积的定义将 $AB\cdot AC + BA\cdot BC = 2c^2\cos B$ 展开，再结合正弦定理进行化简，
> >
> > 进而求出 $\angle ABC$
> >
> > (2) 本题可根据正弦定理将 $a, c$ 用角 $A, C$ 表示，再结合三角形内角和为 $\pi$ 以及锐角三角形的条件，求出周长
> >
> > 的范围即可·
>
> > [!note]- **【解析】**
> > （1）因为 $AB \cdot AC + BA \cdot BC = 2c^2\cos B$ ，所以 $bc\cos A + ac\cos B = 2c^2\cos B$
> >
> > 所以 $b\cos A + a\cos B = 2c\cos B$ ，由正弦定理得： $\sin B\cos A + \sin A\cos B = 2\sin C\cos B$
> >
> > 所以 $\sin (A + B) = 2\sin C\cos B$ ，又因为 $A + B = \pi -C$ ，所以 $\sin C = 2\sin C\cos B$
> >
> > 又因为 $C \in (0, \pi)$ ，所以 $\sin C > 0$ ，所以 $\cos B = \frac{1}{2}$ ，
> >
> > 又因为 $B \in (0, \pi)$ ，所以 $B = \frac{\pi}{3}$ ，即 $\angle ABC = \frac{\pi}{3}$ .
> >
> > (2) 由正弦定理得 $\frac{a}{\sin A} = \frac{c}{\sin C} = \frac{b}{\sin B} = \frac{3}{\frac{\sqrt{3}}{2}} = 2\sqrt{3}$ ，所以 $a = 2\sqrt{3}\sin A, c = 2\sqrt{3}\sin C$ ，
> >
> > 所以 $a + c = 2\sqrt{3} \sin A + 2\sqrt{3} \sin C = 2\sqrt{3} (\sin A + \sin C)$
> >
> > $$
> > \sin A + \sin C = \sin A + \sin (\pi - A - B) = \sin A + \sin \left(\frac {2 \pi}{3} - A\right) = \sqrt {3} \sin (A + \frac {\pi}{6})
> > $$
> >
> > 得 $a + c = 2\sqrt{3} (\sin A + \sin C) = 6\sin (A + \frac{\pi}{6})$
> >
> > 因为 为锐角三角形，即 $\left\{ \begin{array}{l}0 < A < \frac{\pi}{2}\\ 0 < C = \frac{2\pi}{3} -A <   \frac{\pi}{2} \end{array} \right.$
> >
> > 所以 $\frac{\pi}{6} < A < \frac{\pi}{2}, \frac{\pi}{3} < A + \frac{\pi}{6} < \frac{2\pi}{3}$
> >
> > 即 $\frac{\sqrt{3}}{2} < \sin \left(A + \frac{\pi}{6}\right) \leq 1$ ， $3\sqrt{3} < a + c \leq 6$
> >
> > 则 $3\sqrt{3} + 3 < a + b + c \leq 9$ ，所以 $\forall ABC$ 的周长的取值范围为 $\left(3\sqrt{3} + 3, 9\right]$ .
