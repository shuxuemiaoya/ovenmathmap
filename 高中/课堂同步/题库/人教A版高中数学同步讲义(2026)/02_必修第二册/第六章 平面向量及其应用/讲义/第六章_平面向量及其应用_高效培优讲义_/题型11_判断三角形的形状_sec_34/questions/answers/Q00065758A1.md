> [!faq]- 《第六章_平面向量及其应用_高效培优讲义_》官方解析
>
> > [!success]- **【答案】** A．若 $a^2 + b^2 > c^2$ ，则 $\forall ABC$ 为锐角三角形 B．若 $b\cos A=a\cos B$ ，则 $\forall ABC$ 为等腰三角形 C. 若 $A > B$ ，则 $\sin A > \sin B$ D．若 $\forall ABC$ 为锐角三角形，且 $\sin A = 2\sin B\sin C$ ，则 $\tan A\tan B\tan C$ 的最小值为8
>
> > [!note]- **【分析】**
> > A选项，C为锐角，但不确定A，B是否是锐角；B选项，由正弦定理和同角三角函数关系得到
> >
> > $\tan A = \tan B$ ，所以 $A = B$ ，B正确；C选项，由正弦定理和大角对大边得到C正确；D选项，变形得到
> >
> > $\tan A \tan B \tan C = \frac{2 \tan^2 B \tan^2 C}{\tan B \tan C - 1}$ ，令 $\tan B \tan C - 1 = u \in (0, +\infty)$ ，得到 $\tan A \tan B \tan C = 2u + \frac{2}{u} + 4$ ，由基本不
> >
> > 等式求出最小值·
>
> > [!note]- **【解析】**
> > A选项， $\cos C=\frac{a^{2}+b^{2}-c^{2}}{2ab}>0$ ，故C为锐角，但不确定A，B是否是锐角，A错误；
> >
> > B 选项， $b \cos A = a \cos B$ ，由正弦定理得 $\sin B \cos A = \sin A \cos B$
> >
> > 因为 $A, B \in (0, \pi)$ ，所以 $\sin A > 0, \sin B > 0$ ，故 $\tan A = \tan B$
> >
> > 所以 A = B ，B 正确；
> >
> > C 选项，A > B ，由大角对大边得 a > b ，由正弦定理得 $\frac{a}{\sin A} = \frac{b}{\sin B} > 0$
> >
> > 故 $\sin A > \sin B$ ，C 正确；
> >
> > D 选项， $\cos A = -\cos(B + C) = \sin B \sin C - \cos B \cos C$
> >
> > $\sin A = 2\sin B\sin C \Rightarrow \tan A = \frac{2\sin B\sin C}{\cos A} \Rightarrow \tan A = \frac{2\sin B\sin C}{\sin B\sin C - \cos B\cos C}$
> >
> > 故 $\tan A = \frac{2\tan B\tan C}{\tan B\tan C - 1}$
> >
> > 故 $\tan A\tan B\tan C = \frac{2\tan^2B\tan^2C}{\tan B\tan C - 1}$
> >
> > $\forall ABC$ 为锐角三角形，故 $\tan A = \frac{2\tan B\tan C}{\tan B\tan C - 1} >0$ ，所以 $\tan B\tan C - 1 > 0$
> >
> > 令 $\tan B \tan C - 1 = u \in (0, +\infty)$
> >
> > 则 $\tan A\tan B\tan C = \frac{2(u + 1)^2}{u} = 2u + \frac{2}{u} +4\quad 2\sqrt{2u\cdot\frac{2}{u}} +4 = 8$
> >
> > 当且仅当 $2u = \frac{2}{u}$ ，即 u = 2 时，等号成立，D 正确。
> >
> > 故选 **BCD**
