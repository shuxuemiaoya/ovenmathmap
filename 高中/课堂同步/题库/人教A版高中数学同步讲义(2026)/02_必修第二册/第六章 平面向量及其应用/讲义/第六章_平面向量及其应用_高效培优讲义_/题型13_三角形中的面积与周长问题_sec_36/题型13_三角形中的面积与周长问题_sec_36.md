## 题型13 三角形中的面积与周长问题

【典例1】锐角三角形 $\forall ABC$ 的内角 $A, B, C$ 的对边分别为 $a, b, c$ ，已知 $2\cos A(c\cos B + b\cos C) = a$

(1)求 $A$ ；

(2)若 $a = 3$ ，求 $\vee ABC$ 的周长的取值范围·

【答案】(1) $\frac{\pi}{3}$

(2) $(3\sqrt{3} + 3,9]$

【分析】（1）根据题意，由正弦定理和三角恒等变换的公式，化简得到 $2\cos A\sin A = \sin A$ ，求得 $\cos A = \frac{1}{2}$

即可求解；

(2) 设 $\forall ABC$ 外接圆的半径为 $r$ ，得到 $b = 2\sqrt{3} \sin B, c = 2\sqrt{3} \sin C$ ，得到 $b + c = 6 \sin \left( B + \frac{\pi}{6} \right)$ ，由 $\forall ABC$ 为锐角

三角形，求得 $\frac{\pi}{6} < B < \frac{\pi}{2}$ ，结合三角函数的性质，求得 $b + c$ 的范围，进而求得 $\forall ABC$ 的周长的取值范围·

【详解】（1）解：因为 $2\cos A(c\cos B + b\cos C) = a$

由正弦定理得 $2 \cos A (\sin C \cos B + \sin B \cos C) = \sin A$

又因为 $B + C = \pi - A$ ，所以 $\sin C \cos B + \sin B \cos C = \sin (B + C) = \sin A$

所以 $2 \cos A \sin A = \sin A$

因为 $\vee ABC$ 为锐角三角形，可得 $A \in (0, \frac{\pi}{2})$ ，所以 $\sin A > 0$ ，

所以 $\cos A = \frac{1}{2}$ ，可得 $A = \frac{\pi}{3}$ .

(2) 解：设 $\vee ABC$ 外接圆的半径为 r，

由（1）知 $A = \frac{\pi}{3}$ ，因为 $a = 3$ ，可得 $2r = \frac{a}{\sin A} = 2\sqrt{3}$

所以 $b = 2\sqrt{3} \sin B, c = 2\sqrt{3} \sin C$

$$
b + c = 2 \sqrt {3} (\sin B + \sin C) = 2 \sqrt {3} [ \sin B + \sin (\frac {2 \pi}{3} - B) ] = 2 \sqrt {3} [ \sin B + (\frac {\sqrt {3}}{2} \cos B + \frac {1}{2} \sin B) ]
$$

$$
= 2 \sqrt {3} \cdot (\frac {3}{2} \sin B + \frac {\sqrt {3}}{2} \cos B) = 6 \sin (B + \frac {\pi}{6})
$$

因为 为锐角三角形，可得 $\left\{ \begin{array}{l}0 < B < \frac{\pi}{2}\\ 0 < \frac{2\pi}{3} -B <   \frac{\pi}{2} \end{array} \right.$ ，解得 $\frac{\pi}{6} <  B <   \frac{\pi}{2}$

可得 $B + \frac{\pi}{6} \in (\frac{\pi}{3}, \frac{2\pi}{3})$ ，所以 $\sin(B + \frac{\pi}{6}) \in (\frac{\sqrt{3}}{2}, 1]$ ，则 $6\sin(B + \frac{\pi}{6}) \in (3\sqrt{3}, 6]$

即 $b + c \in (3\sqrt{3}, 6]$ ，所以 $\forall ABC$ 的周长 $a + b + c \in (3\sqrt{3} + 3, 9]$

所以 $\vee ABC$ 的周长的取值范围为 $(3\sqrt{3} + 3, 9]$ .

【典例2】已知 $\vee ABC$ 的内角 $A$ 、 $B$ 、 $C$ 的对边分别为 $a$ 、 $b$ 、 $c$ ，且 $b\cos \frac{C}{2} = c\sin B$

(1)求 $C$

(2)若 $\vee ABC$ 的面积为 $\sqrt{3}$ ，求 $c$ 的最小值。

【答案】(1) $C=\frac{\pi}{3}$

(2)2

【分析】（ $^{1}$ ）利用正弦定理将边化为角，结合三角恒等变换求角 C；

(2) 利用三角形面积公式和余弦定理结合基本不等式求 $c$ 的最小值.

【详解】（ $^{1}$ ）由已知及正弦定理得

$$
\sin B \cos \frac {C}{2} = \sin C \sin B
$$

由 $B\in (0,\pi)$ ，得 $\sin B\neq 0$ ，得 $\cos \frac{C}{2} = \sin C = 2\sin \frac{C}{2}\cos \frac{C}{2}$

由 $C\in (0,\pi)$ ，得 $\frac{C}{2}\in \left(0,\frac{\pi}{2}\right)$ ，得 $\cos \frac{C}{2}\neq 0$ ，得 $\sin \frac{C}{2} = \frac{1}{2}$

得 $\frac{C}{2}=\frac{\pi}{6}$ ，得 $C=\frac{\pi}{3}$ ；

(2) 由 $S_{\triangle ABC} = \frac{1}{2} ab \sin C = \frac{\sqrt{3}}{4} ab = \sqrt{3}$ ，得 $ab = 4$ ，

由余弦定理得 $c^2 = a^2 + b^2 - 2ab\cos C = a^2 + b^2 - ab$

因为 $a^2 + b^2 - ab \quad 2ab - ab = ab = 4$

当且仅当 a=b=2 时，等号成立，

所以 $c^{2}$ 4 ，得 c 2 。故 c 的最小值为 2 。
