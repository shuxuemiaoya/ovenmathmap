## 题型11 判断三角形的形状

【典例1】已知 $\forall ABC$ 的内角 $A, B, C$ 满足 $\frac{1 - \cos 2A}{\sin 2A} = \frac{1 - \sin B}{\cos B}$ ，则下列说法错误的是（）
A. $\sin (A + B) = \cos A$ B. $\forall ABC$ 是直角三角形
C. $a^2 + c^2 > b^2$ D. $\forall ABC$ 是钝角三角形

【答案】B

【分析】利用二倍角公式化简得 $\sin A\cos B = \cos A(1 - \sin B)$ ，又由三角恒等变换得 $\sin (A + B) = \cos A$ ，即可

判断 A，进而得 $2A + B = \frac{\pi}{2}$ ，结合 $A + B + C = \pi$ 即可判断 BD，再由余弦定理即可判断 C.

【详解】由题意有： $\frac{1-\cos2A}{\sin2A}=\frac{2\sin^{2}A}{2\sin A\cos A}=\frac{\sin A}{\cos A}=\frac{1-\sin B}{\cos B}$

所以 $\sin A\cos B = \cos A(1 - \sin B)$

所以 $\cos A = \sin A \cos B + \cos A \sin B = \sin(A + B)$ ，即 $\sin(A + B) = \cos A$ ，故 A 正确；

由 $\sin(A+B)=\cos A=\sin\left(\frac{\pi}{2}-A\right)$ ，所以 $A+B=\frac{\pi}{2}-A$ 或 $A+B=\pi-\left(\frac{\pi}{2}-A\right)$ ，而 $B\neq\frac{\pi}{2}$ ，即 $2A+B=\frac{\pi}{2}$

由 $2A = \frac{\pi}{2} - B > 0 \Rightarrow 0 < B < \frac{\pi}{2}$ ，又 $A + B = \frac{\pi}{2} - A > 0 \Rightarrow 0 < A < \frac{\pi}{2}$ ，

又因为 $A + B + C = \pi$ ，所以 $C - A = \frac{\pi}{2}$ ，即 $C = \frac{\pi}{2} + A > \frac{\pi}{2}$ ，所以 $\forall ABC$ 是钝角三角形，故 ${}^{\mathrm{D}}$ 正确， ${}^{\mathrm{B}}$ 错误；

又 $0 < B < \frac{\pi}{2}$ ，所以 $\cos B = \frac{a^2 + c^2 - b^2}{2ac} > 0 \Rightarrow a^2 + c^2 > b^2$ ，故 C 正确；

故选：B.

【典例2】 $\forall ABC$ 中，角 $A, B, C$ 的对边分别为 $a, b, c$ ，且 $(a \cos B + b \cos A) \cos C = 2a \cos^2 \frac{C}{2} - a$ ，则 $\forall ABC$ 为（）
A. 等腰三角形 B. 直角三角形 C. 等腰或直角三角形 D. 等腰直角三角形

【答案】C

## 方法技巧

特殊三角形的判定：

(1) 直角三角形

勾股定理： $a^2 + b^2 = c^2$

互余关系： $A + B = 90^{0}$ ， $\cos C = 0$ ， $\sin C = 1$ ；

(2) 等腰三角形

$$
a = b, A = B
$$

用余弦定理判定三角形的形状（最大角 $A$ 的余弦值的符号）

(1) 在 $\Delta ABC$ 中， $0^{0} < A < 90^{0} \Leftrightarrow \cos A = \frac{b^{2} + c^{2} - a^{2}}{2bc} > 0 \Leftrightarrow b^{2} + c^{2} > a^{2}$ ;

(2) 在 $\Delta ABC$ 中， $A = 90^{0} \Leftrightarrow \cos A = \frac{b^{2} + c^{2} - a^{2}}{2bc} = 0 \Leftrightarrow b^{2} + c^{2} = a^{2}$ ;

(3) 在 $\Delta ABC$ 中， $90^{0} < A \Leftrightarrow \cos A = \frac{b^{2} + c^{2} - a^{2}}{2bc} < 0 \Leftrightarrow b^{2} + c^{2} < a^{2}$ ;
