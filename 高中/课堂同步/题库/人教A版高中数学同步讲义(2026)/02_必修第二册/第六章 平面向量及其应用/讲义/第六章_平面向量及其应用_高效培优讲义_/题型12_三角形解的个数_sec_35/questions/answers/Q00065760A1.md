> [!faq]- 《第六章_平面向量及其应用_高效培优讲义_》官方解析
>
> > [!success]- **【答案】** A．若 $b\cos A = a\cos B$ ，则 $\forall ABC$ 为等腰三角形 B．若 $a^2 + b^2 > c^2$ ，则 $\forall ABC$ 为锐角三角形 C．在锐角三角形 $ABC$ 中，不等式 $\sin A > \cos B$ 恒成立 D．若 $B = \frac{\pi}{4}$ ， $a = 2$ ，且该三角形有两解，则 $b$ 的范围是 $(\sqrt{2}, 2)$
>
> > [!note]- **【分析】**
> > 对于 A，根据正弦定理边化角即可判断；对于 B，余弦定理可得 $\cos C > 0$ ，则角 C 为锐角，不能得到
> > VABC
> > 为锐角三角形；对于 C，应用正弦单调性判断；对于 D：由题意得到 a $\sin B < b < a$ 即可求解。
>
> > [!note]- **【解析】**
> > 对于 A，因为 $b \cos A = a \cos B$
> >
> > 所以由正弦定理得 $\sin B\cos A = \sin A\cos B,\therefore \sin (B - A) = 0$
> >
> > 又 A, B 为 $\triangle ABC$ 的内角， $\therefore B-A\in(-\pi,\pi)$ ，则 B-A=0，即 B=A，故 A 正确；
> >
> > 对于 ${}^{\mathrm{B}}$ ，由余弦定理可得 $\cos C = \frac{a^2 + b^2 - c^2}{2ab} >0$ ，则角 $C$ 为锐角，不能得到 $\triangle ABC$ 为锐角三角形，故 ${}^{\mathrm{B}}$ 错误；
> >
> > 对于 $C$ ，因为 $\forall ABC$ 是锐角三角形，所以 $0 < C < \frac{\pi}{2}$ ，所以 $\frac{\pi}{2} < \pi - C = A + B < \pi$
> >
> > 又 $A, B \in \left(0, \frac{\pi}{2}\right)$ ，所以 $0 < \frac{\pi}{2} - B < A < \frac{\pi}{2}$
> >
> > 又因为 $y = \sin x$ 在 $\left(0, \frac{\pi}{2}\right)$ 单调递增，所以 $\sin A > \sin \left(\frac{\pi}{2} - B\right) = \cos B$ ，C 正确；
> >
> > 对于 D，因为 $B=\frac{\pi}{4}$ ，a=2，且该三角形有两解，
> >
> > 所以 $a\sin B < b < a$ ，即 $\sqrt{2} < b < 2$ ，故 ${}^{\mathrm{D}}$ 正确。
> >
> > 故选 **ACD**
