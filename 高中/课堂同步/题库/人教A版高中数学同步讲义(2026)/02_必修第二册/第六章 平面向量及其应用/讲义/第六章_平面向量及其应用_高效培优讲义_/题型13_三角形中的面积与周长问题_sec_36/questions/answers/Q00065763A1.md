> [!faq]- 《第六章_平面向量及其应用_高效培优讲义_》官方解析
>
> > [!success]- **【答案】** (1) $A=\frac{2\pi}{3}$ (2) $4+2\sqrt{3}$
>
> > [!note]- **【分析】**
> > （1）由 $\sqrt{3} a\sin C = c(2 + \cos A)$ ，利用正弦定理得到 $\sqrt{3}\sin A = 2 + \cos A$ ，再利用辅助角法求解；
> >
> > (2) 由 $A = \frac{2\pi}{3}$ ，结合余弦定理得到 $12 = b^2 + c^2 + bc$ ，再利用基本不等式得到 $b + c \leq 4$ 求解。
>
> > [!note]- **【解析】**
> > （1）因为 $\sqrt{3} a\sin C = c(2 + \cos A)$
> >
> > 所以 $\sqrt{3}\sin A\sin C = \sin C(2 + \cos A)$
> >
> > 因为 $\sin C \neq 0$ ，所以 $\sqrt{3}\sin A = 2 + \cos A$ ，
> >
> > 即 $\sqrt{3}\sin A - \cos A = 2$ ，即 $2\sin \left(A - \frac{\pi}{6}\right) = 2$
> >
> > 所以 $\sin \left(A - \frac{\pi}{6}\right) = 1$
> >
> > 因为 $A \in (0, \pi)$ ，所以 $A - \frac{\pi}{6} = \frac{\pi}{2}$ ， $A = \frac{2\pi}{3}$ ；
> >
> > (2) 由余弦定理 $a^2 = b^2 + c^2 - 2bc\cos A$ 及 $A = \frac{2\pi}{3}$
> >
> > 得 $\left(2\sqrt{3}\right)^{2}=b^{2}+c^{2}+bc$ ，即 $12=b^{2}+c^{2}+bc$ ，
> >
> > 即 $12 = (b + c)^{2} - bc$ ，又 $bc \leq \left(\frac{b + c}{2}\right)^{2}$ ，即 $(b + c)^{2} - 12 \leq \left(\frac{b + c}{2}\right)^{2}$
> >
> > 所以 $\left(b+c\right)^{2}\leq16$ ，即 $b+c\leq4$ ，当且仅当 b=c=2 时，等号成立，
> >
> > 所以周长 $L = a + b + c \leq 2\sqrt{3} + 4$
> >
> > 所以周长最大值为 $4 + 2\sqrt{3}$
