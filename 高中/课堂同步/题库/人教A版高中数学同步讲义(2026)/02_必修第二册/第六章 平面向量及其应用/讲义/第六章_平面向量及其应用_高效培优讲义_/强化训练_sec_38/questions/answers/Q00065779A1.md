> [!faq]- 《第六章_平面向量及其应用_高效培优讲义_》官方解析
>
> > [!success]- **【答案】** (1) $\frac{\pi}{3}$ (2)答案见解析
>
> > [!note]- **【分析】**
> > （1）由正弦定理和三角形的内角和定理，求得 $\sin \frac{A}{2} = \frac{1}{2}$ ，进而求得 $A$ 的大小；
> >
> > 又因为 $\frac{A}{2}\in(0,\frac{\pi}{2})$ ，所以 $\frac{A}{2}=\frac{\pi}{6}$ ，可得 $A=\frac{\pi}{3}$
> >
> > (2) 分别选择条件①②③，结合题意，利用正弦定理、余弦定理和面积公式，即可求解·
>
> > [!note]- **【解析】**
> > （1）解：因为 $b\sin \frac{B + C}{2} = a\sin B$ ，由正弦定理得
> >
> > 因为 $B \in (0, \pi)$ ，且 $B + C = \pi - A$ ，
> >
> > 所以 $\sin B\neq 0$ ，得 $\sin \frac{B + C}{2} = \sin A$
> >
> > 因为 $\sin \frac{B + C}{2} = \sin \left(\frac{\pi}{2} -\frac{A}{2}\right) = \cos \frac{A}{2}$ ，即 $\cos \frac{A}{2} = \sin A$
> >
> > 则 $\cos \frac{A}{2} = 2\sin \frac{A}{2}\cos \frac{A}{2}$ ，又因为 $\frac{A}{2}\in (0,\frac{\pi}{2})$ ，可得 $\cos \frac{A}{2} >0$
> >
> > 所以 $\sin\frac{A}{2}=\frac{1}{2}$ ，可得 $\frac{A}{2}=\frac{\pi}{6}$ ，可得 $A=\frac{\pi}{3}$ .
> >
> > (2) 解：选择条件①： $b+c=8$ ，因为 $a=2\sqrt{7}$ 且 $A=\frac{\pi}{3}$
> >
> > 由余弦定理得 $a^{2}=b^{2}+c^{2}-2bc\cos A$
> >
> > 即 $(2\sqrt{7})^2 = b^2 + c^2 - bc = (b + c)^2 - 3bc$ ，解得 $bc = 12$
> >
> > 所以 b, c 为方程 $x^{2}-8x+12=0$ 的根，解得 x=2 或 x=6，
> >
> > 即 $b = 2, c = 6$ 或 $b = 6, c = 2$ ，所以三角形的元素不唯一，不符合题意
> >
> > 选择条件②： $\cos C = \frac{\sqrt{7}}{14}$ ，因为 $C\in (0,\pi)$ ，可得 $\sin C = \sqrt{1 - \cos^2C} = \frac{3\sqrt{21}}{14}$
> >
> > 由正弦定理 $\frac{a}{\sin A} = \frac{c}{\sin C}$ ，可得 $c = \frac{a \sin C}{\sin A} = \frac{2\sqrt{7} \times \frac{3\sqrt{21}}{14}}{\frac{\sqrt{3}}{2}} = 6$ ，
> >
> > 因为 $C \in (0, \pi)$ 且 $\cos C = \frac{\sqrt{7}}{14}$ ，所以 $C$ 为锐角且唯一，所以 $\forall ABC$ 存在且唯一，
> >
> > $$
> > \sin B = \sin (A + C) = \sin (\frac {\pi}{3} + C) = \sin \frac {\pi}{3} \cos C + \cos \frac {\pi}{3} \sin C = \frac {\sqrt {3}}{2} \times \frac {\sqrt {7}}{1 4} + \frac {1}{2} \times \frac {3 \sqrt {2 1}}{1 4} = \frac {\sqrt {2 1}}{7}
> > $$
> >
> > 由正弦定理可得 $b = \frac{a\sin B}{\sin A} = \frac{2\sqrt{7} \times \frac{\sqrt{21}}{7}}{\frac{\sqrt{3}}{2}} = 4$ ，所以 $S_{VABC} = \frac{1}{2} bc\sin A = 6\sqrt{3}$
> >
> > 可得 $\frac{1}{2} ah = 6\sqrt{3}$ ，即 $\frac{1}{2} \times 2\sqrt{7} \cdot h = 6\sqrt{3}$ ，解得 $h = \frac{6\sqrt{21}}{7}$ ，即 $BC$ 边上的高为 $\frac{6\sqrt{21}}{7}$
> >
> > 条件③： $b=4$ ，由正弦定理 $\frac{a}{\sin A}=\frac{b}{\sin B}$ ，可得 $\sin B=\frac{b\sin A}{a}=\frac{4\times\frac{\sqrt{3}}{2}}{2\sqrt{7}}=\frac{\sqrt{21}}{7}$ ，
> >
> > 因为 $a = 2\sqrt{7} > b = 4$ ，所以 A > B，
> >
> > 又因为 $A = \frac{\pi}{3}$ ，所以 $_B$ 为锐角，且唯一确定，所以 $\vee ABC$ 存在且唯一，
> >
> > 又由 $\cos B = \sqrt{1 - \sin^{2} B} = \frac{2\sqrt{7}}{7}$
> >
> > 因为 $C = \pi - (A + B) = \pi - (\frac{\pi}{3} + B) = \frac{2\pi}{3} - B$
> >
> > 所以 $\sin C = \sin\left(\frac{2\pi}{3} - B\right) = \sin\frac{2\pi}{3}\cos B - \cos\frac{2\pi}{3}\sin B = \frac{\sqrt{3}}{2} \cdot \frac{2\sqrt{7}}{7} - \left(-\frac{1}{2}\right) \cdot \frac{\sqrt{21}}{7} = \frac{3\sqrt{21}}{14}$
> >
> > 又由正弦定理得 $c=\frac{a\sin C}{\sin A}=\frac{2\sqrt{7}\times\frac{3\sqrt{21}}{14}}{\frac{\sqrt{3}}{2}}=6$ ，所以 $S_{\triangle ABC}=\frac{1}{2}ac\sin B=6\sqrt{3}$ ，
> >
> > 可得 $\frac{1}{2} ah = 6\sqrt{3}$ ，即 $\frac{1}{2} \times 2\sqrt{7} \cdot h = 6\sqrt{3}$ ，解得 $h = \frac{6\sqrt{21}}{7}$ ，即 $BC$ 边上的高为 $\frac{6\sqrt{21}}{7}$
