> [!faq]- 《第六章_平面向量及其应用_高效培优讲义_》官方解析
>
> > [!success]- **【答案】** (1) $B=\frac{\pi}{3}$ (2)3
>
> > [!note]- **【分析】**
> > （1）根据三角函数恒等变换得到 $\sin\left(B+\frac{\pi}{6}\right)=1$ ，从而求出 $B=\frac{\pi}{3}$ ;
> >
> > (2) 由余弦定理得 $a^2 + c^2 - ac = 12$ ，再根据 $\forall ABC$ 的面积得 $ac = 12$ ，进而有 $a^2 + c^2 = 24$ ，由中线向量形式
> >
> > $\overline{BD}=\frac{1}{2}\left(\overline{BA}+\overline{BC}\right)$ 得，利用数量积的运算律即可求解·
>
> > [!note]- **【解析】**
> > （1）因为 $\sqrt{3}\sin B - 2\sin^2\frac{B}{2} = 1$ ，可得 $\sqrt{3}\sin B - (1 - \cos B) = 1$
> >
> > 故 $\sqrt{3}\sin B + \cos B = 2$ ，故 $2\sin \left(B + \frac{\pi}{6}\right) = 2$ ，可得 $\sin \left(B + \frac{\pi}{6}\right) = 1$
> >
> > 因为 $B \in (0, \pi)$ ，所以 $B + \frac{\pi}{6} \in \left( \frac{\pi}{6}, \frac{7\pi}{6} \right)$ ，所以 $B + \frac{\pi}{6} = \frac{\pi}{2}$ ，则 $B = \frac{\pi}{3}$ 。
> >
> > (2) 在 $\forall ABC$ 中，由余弦定理得 $b^{2}=a^{2}+c^{2}-2ac\cos\frac{\pi}{3}$
> >
> > 又 $b = 2\sqrt{3}$ ，所以 $a^2 + c^2 - ac = 12$
> >
> > 又 $\vee ABC$ 的面积为 $3\sqrt{3}$ ，所以 $\frac{1}{2} ac\sin \frac{\pi}{3} = 3\sqrt{3}$
> >
> > 所以 ac = 12 ，所以 $a^{2} + c^{2} = 24$
> >
> > 因为 $D$ 为线段 $AC$ 的中点，所以 $\overline{BD} = \frac{1}{2}\left(\overline{BA} +\overline{BC}\right)$
> >
> > 所以 $\overline{BD}^2 = \frac{1}{4}\left(\overline{BA} +\overline{BC}\right)^2 = \frac{1}{4}\left(\overline{BA}^2 +2BA\cdot BC + \overline{BC}^2\right)$
> >
> > 则 $\left|BD\right|^2 = \frac{1}{4}\left(c^2 + 2c \cdot a \cos \frac{\pi}{3} + a^2\right) = \frac{1}{4}\left(c^2 + ac + a^2\right) = \frac{1}{4}(24 + 12) = 9$
> >
> > 所以 $|BD|=3$ .
