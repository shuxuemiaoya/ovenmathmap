## 题型10 正余弦定理的应用

【典例1】在 $\forall ABC$ 中，角 $A, B, C$ 所对的边分别为 $a, b, c$ ，已知 $m = (\sin A, -1), n = (1, \sqrt{3} \cos A)$ ，且 $m \perp n$ .

(1)求 $A$

(2) 若 $a = 2$ ，且 $\vee ABC$ 的面积为 $\sqrt{3}$ ，求 $\vee ABC$ 的周长.

【答案】(1) $A = \frac{\pi}{3}$

(2)6

【分析】（1）根据向量垂直得到 $\sin A = \sqrt{3}\cos A$ ，进而得到 $\tan A = \sqrt{3}$ ，结合 $A$ 的范围求解即可·

(2) 根据三角形面积公式求出 bc，结合余弦定理求出 $b+c$ ，进而求出周长·

【详解】（1）因为 $m \perp n$ ，所以 $m \cdot n = \sin A - \sqrt{3} \cos A = 0$ ，则 $\sin A = \sqrt{3} \cos A$

若 $\cos A = 0$ ，则 $\sin A = 0$ ，与 $\sin^2 A + \cos^2 A = 1$ 矛盾，所以 $\cos A \neq 0$

所以 $\tan A = \sqrt{3}$ ，又 $A \in (0, \pi)$ ，所以 $A = \frac{\pi}{3}$ .

(2) 由 (1) 知， $A=\frac{\pi}{3}$ . 由题意知 $S=\frac{1}{2}bc\sin A=\frac{1}{2}bc\sin\frac{\pi}{3}=\sqrt{3}$ ，则 bc=4

由余弦定理 $a^2 = b^2 + c^2 - 2bc\cos A$

则 $4 = (b + c)^2 - 2bc - 2bc\cos \frac{\pi}{3}$ ，即 $4 = (b + c)^2 - 3bc$ ，

解得 $b + c = 4$ ，则 $a + b + c = 6$ ：

故VABC的周长为6.

【典例2】在VABC中，内角A，B，C的对边分别为a，b，c·若 $a=4$ ， $A=\frac{\pi}{3}$ ， $\sin B+\sin C=\frac{3\sqrt{3}}{4}$ ，则
bc = ( )
A. $\frac{80}{3}$ B. 20 C. 16 D. $\frac{20}{3}$

【答案】D

【分析】根据正弦定理、余弦定理求解即可·

【详解】因为 $a = 4$ ， $A = \frac{\pi}{3}$ ，所以 $\frac{a}{\sin A} = \frac{4}{\sin\frac{\pi}{3}} = \frac{4}{\frac{\sqrt{3}}{2}} = \frac{8}{\sqrt{3}}.$

由正弦定理可知， $\frac{b}{\sin B} = \frac{c}{\sin C} = \frac{a}{\sin A} = \frac{8}{\sqrt{3}}$ ，所以 $\sin B = \frac{\sqrt{3}}{8} b$ ， $\sin C = \frac{\sqrt{3}}{8} c$

又 $\sin B + \sin C = \frac{3\sqrt{3}}{4}$ ，所以 $\frac{\sqrt{3}}{8} b + \frac{\sqrt{3}}{8} c = \frac{3\sqrt{3}}{4}$ ，所以 $b + c = 6\cdot$

由余弦定理知， $a^2 = b^2 +c^2 -2bc\cos A$ ，所以 $16 = b^{2} + c^{2} - 2bc\times \frac{1}{2}$ ，即 $16 = b^{2} + c^{2} - bc$

又 $b^{2} + c^{2} = (b + c)^{2} - 2bc = 6^{2} - 2bc = 36 - 2bc$

所以 $16 = 36 - 2bc - bc$ ，所以 $bc = \frac{20}{3}$ .

故选：D.

## 方法技巧

(1) 已知两角及一边求解三角形；

(2) 已知两边一对角；

大角求小角一解（锐）
小角求大角 - $\left\{\begin{aligned}& 两解 - \sin A < 1 ( 一锐角、一钝角 )\\& 一解 - \sin A = 1 ( 直角 )\\& 无解 - \sin A > 1\end{aligned}\right.$

(3) 两边一对角，求第三边.

(1)已知两边一夹角或两边及一对角，求第三边.

(2)已知三边求角或已知三边判断三角形的形状，先求最大角的余弦值，

若余弦值 $\left\{ \begin{array}{l} > 0, \text{则} \Delta ABC \text{为锐角三角形} \\ = 0, \text{则} \Delta ABC \text{为直角三角形}. \\ < 0, \text{则} \Delta ABC \text{为钝角三角形} \end{array} \right.$
