> [!faq]- 《第六章_平面向量及其应用_高效培优讲义_》官方解析
>
> > [!success]- **【答案】** C
>
> > [!note]- **【分析】**
> > 由题知， $a+b=(-1,1),a-b=(3,1)$ ，再根据向量坐标运算公式依次讨论各选项即可判断
>
> > [!note]- **【解析】**
> > 由 $a = (1,1), b = (-2,0)$ ，知 $a + b = (-1,1), a - b = (3,1)$
> >
> > 对于 A， $(a+b)\cdot a=-1+1=0$ ，故 $(a+b)\perp a$ ，正确；
> >
> > 对于 $^{B}$ ，向量b在a上的投影向量 $\frac{a\cdot b}{|a|^{2}}\vec{a}=\frac{-2}{2}(1,1)=(-1,-1)$ ，故正确
> >
> > 对于 C， $a + b = (-1, 1)$ ， $a - b = (3, 1)$ ，显然 $\left(a + b\right) // \left(a - b\right)$ 不成立，故错误；
> >
> > 对于 D， $\cos\left\langle\vec{a},\vec{b}\right\rangle=\frac{\vec{a}\cdot\vec{b}}{\left|\vec{a}\right|\left|\vec{b}\right|}=\frac{-2}{2\sqrt{2}}=-\frac{\sqrt{2}}{2}$ ，故向量 $_{a}$ 与 $_{b}$ 的夹角为 $\frac{3}{4}\pi$ ，正确.
> >
> > 故选 **C**
