## 题型03 向量共线的运用

【典例1】设 $a, b$ 是非零向量，则 $\left|\overline{a}\right| = \frac{b}{\left|b\right|}$ 是 $a = 2b$ 成立的（ ）A. 充要条件B. 充分不必要条件C. 必要不充分条件D. 既不充分也不必要条件

【答案】C

【分析】根据充分、必要条件，以及向量共线等知识确定正确答案

【详解】对于非零向量a,b，

若 $\frac{a}{|a|} = \frac{b}{|b|}$ ，则 $a,b$ 同向，不一定有 $a = 2b$

若 $a = 2b$ ，则 $a,b$ 同向，此时 $\frac{a}{|a|} = \frac{b}{|b|}$

所以 $\frac{a}{|a|} = \frac{b}{|b|}$ 是 $a = 2b$ 成立的必要不充分条件

故选：C

【典例2】(多选)关于非零向量 $a, b$ ，下列命题中正确的是（ ）A．若 $\left|a\right| = \left|b\right|$ ，则 $a = b$ B．若 $a = -b$ ，则 $a // b$ C．若 $\left|a\right| > \left|b\right|$ ，则 $a > b$ D．若 $a = b$ ， $b = c$ ，则 $a = c$

【答案】BD

【分析】根据相等向量、向量的定义逐一判断即可·

【详解】A：两个非零向量相等除了它们的模相等之外还要方向相同，故本选项命题不正确；

B：由 $a = -b$ ，可以得到非零向量 $a, b$ 的方向相反，所以 $a // b$ ，因此本选项命题正确；

C：两个向量不能比较大小，所以本选项命题不正确；

D：由向量相等的定义可以判断本选项命题正确，

故选：BD

## 方法技巧

要证明 A, B, C 三点共线，只需证明 $\stackrel{\cup\cup\cup}{AB}$ 与 $\stackrel{\cup\cup\cup}{BC}$ 共线，即证 $AB = \lambda \stackrel{\cup\cup\cup}{BC} (\lambda \in R)$ . 若已知 A, B, C 三点共线，则必有 $\stackrel{\cup\cup\cup}{AB}$ 与 $\stackrel{\cup\cup\cup}{BC}$ 共线，从而存在实数 $\lambda$ ，使得 $AB = \lambda \stackrel{\cup\cup\cup}{BC}$ .
