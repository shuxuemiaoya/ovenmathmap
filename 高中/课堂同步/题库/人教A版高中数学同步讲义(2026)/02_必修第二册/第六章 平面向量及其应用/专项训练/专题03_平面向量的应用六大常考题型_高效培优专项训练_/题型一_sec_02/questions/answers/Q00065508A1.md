> [!faq]- 《专题03_平面向量的应用六大常考题型_高效培优专项训练_》官方解析
>
> > [!success]- **【答案】** A．若 $a = 2\sqrt{3}, A = \frac{\pi}{3}$ ，则VABC的外接圆的面积为 $4\pi$ B．若 $a = 3, b = 4, A = \frac{\pi}{3}$ ，则满足条件的三角形有两个 C．若VABC为锐角三角形，则 $\sin A+\sin B>\cos A+\cos B$ D．若 B > C ，则 $\tan B > \tan C$
>
> > [!note]- **【解析】**
> > 因为 $a=2\sqrt{3}, A=\frac{\pi}{3}$ ，所以 $\frac{a}{\sin A}=\frac{2\sqrt{3}}{\frac{\sqrt{3}}{2}}=4=2R$ （为外接圆的半径），
> >
> > 所以 $R = 2$ ，故VABC的外接圆的面积为 $4\pi$ ，故A正确；
> >
> > 若 $a = 3, b = 4, A = \frac{\pi}{3}$ ，则 $a < b\sin A$ ，所以无解，故 ${}^{\mathrm{B}}$ 错误；
> >
> > 若 $\mathrm{V}ABC$ 为锐角三角形，则 $A + B > \frac{\pi}{2}$ ，所以 $A > \frac{\pi}{2} - B$
> >
> > 所以 $\sin A > \sin \left(\frac{\pi}{2} - B\right) = \cos B$ ，同理 $\sin B > \cos A$ ，
> >
> > 所以 $\sin A + \sin B > \cos A + \cos B$ ，故 C 正确；
> >
> > 若 B 为钝角，显然满足 B > C ，但 $\tan B < 0, \tan C > 0$ ，不满足 $\tan B > \tan C$ ，故 D 错误
> >
> > 故选 **AC**
