> [!faq]- 《专题03_平面向量的应用六大常考题型_高效培优专项训练_》官方解析
>
> > [!success]- **【答案】** A
>
> > [!note]- **【解析】**
> > 方法一 $\because \sin A = \frac{\sin C - \sin B}{\cos B - \cos C}$ ， $A + B + C = \pi$ ，
> >
> > $$
> > \therefore \sin A \cos B - \sin A \cos C = \sin (A + B) - \sin (A + C)
> > $$
> >
> > $$
> > \therefore \sin A \cos B - \sin A \cos C = \sin A \cos B + \cos A \sin B - \sin A \cos C - \cos A \sin C
> > $$
> >
> > $\therefore \cos A (\sin B - \sin C) = 0$ ， $\therefore \cos A = 0$ 或 $\sin B - \sin C = 0$
> >
> > 又由 $\sin A = \frac{\sin C - \sin B}{\cos B - \cos C}$ 可知， $\sin C - \sin B \neq 0$ ， $\therefore \cos A = 0$ ，
> >
> > $\therefore A = \frac{\pi}{2}$ ， $\therefore \triangle ABC$ 为直角三角形．故 $\mathsf{A}$ 正确·
> >
> > 方法二：记 $\triangle ABC$ 的内角 $A, B, C$ 所对的边分别为 $a, b, c$ ，由正弦定理、余弦定理及题设条件可得 $a = \frac{c - b}{\frac{a^2 + c^2 - b^2}{2ac} - \frac{a^2 + b^2 - c^2}{2ab}}$ ，且 $c - b \neq 0$
> >
> > 化简得 $(b - c)(b^{2} + c^{2} - a^{2}) = 0$ ， $\therefore b^{2} + c^{2} - a^{2} = 0$ ，即 $b^{2} + c^{2} = a^{2}$
> >
> > $\therefore\triangle ABC$ 为直角三角形·故 A 正确·
> >
> > 故选：A.
> >
> > 40. VABC 中，内角 A, B, C 所对的边分别是 a, b, c.
> >
> > (1)若 $a + b = 2c$ ，求 $\cos C$ 的最小值；
> >
> > (2)若 $\mathrm{V}ABC$ 的内切圆半径是 $r$ ，且 $r > \frac{1}{2} (a + b - c)$
> >
> > (i) 请判断三角形的形状并说明理由；
> >
> > (ii) 若 $\sin 2A + \sin 2B = t\sin 2C$ ，请写出两个函数 $f(t)$ 与 $g(t)$ ，对于一切满足条件的实数 $t$ ，使得
> >
> > $\cos A\cos B + f(t)\cos C = 0$ 且式子 $\frac{\cos 2A + \cos 2B + g(t)(\cos 2C + 1)}{1 + \cos 2A\cos 2B}$ 恒为定值；
> >
> > 【答案】(1) $\frac{1}{2}$
> >
> > (2) (i) 钝角三角形，理由见解析；(ii) $f(t)=\frac{1-t}{2}$ $g(t)=-\frac{(t-1)^{2}}{2}$
> >
> > 【详解】（1）由 $a + b = 2c$ 平方可得 $a^2 + 2ab + b^2 = 4c^2$
> >
> > $$
> > \text {又} \cos C = \frac {a ^ {2} + b ^ {2} - c ^ {2}}{2 a b} = \frac {a ^ {2} + b ^ {2} - \frac {a ^ {2} + b ^ {2} + 2 a b}{4}}{2 a b} = \frac {3 (a ^ {2} + b ^ {2})}{8 a b} - \frac {1}{4} \quad \frac {6 a b}{8 a b} - \frac {1}{4} = \frac {1}{2}
> > $$
> >
> > 故 $\cos C$ 的最小值为 $\frac{1}{2}$ ，当且仅当 $a = b$ 时，等号成立
> >
> > (2) (i) 由 $S = \frac{1}{2} rC$ 可知： $r = \frac{2S}{C} = \frac{ab\sin C}{a + b + c}$
> >
> > 那么不等式可化为： $r=\frac{2S}{C}=\frac{ab\sin C}{a+b+c}>\frac{1}{2}(a+b-c)$
> >
> > 即 $2ab\sin C > (a + b - c)(a + b + c)$
> >
> > 则 $2ab\sin C > a^2 +b^2 +2ab - c^2 = 2ab(\cos C + 1)$
> >
> > 即 $\sin C - \cos C > 1$ ，平方可得 $\sin^2 C - 2\sin C\cos C + \cos^2 C > 1$ ，化简得 $2\sin C\cos C < 0$
> >
> > 由于 $C \in (0, \pi)$ ，故 $\cos C < 0$ 即 $C$ 为钝角，所以 $VABC$ 为钝角三角形；
> >
> > (ii) 由 $\sin 2A + \sin 2B = t\sin 2C$ 可得：
> >
> > $$
> > \sin [ (A + B) + (A - B) ] + \sin [ (A + B) + (B - A) ] = t \sin 2 [ \pi - (A + B) ]
> > $$
> >
> > 展开有： $2\sin(A+B)\cos(A-B)=-2t\sin(A+B)\cos(A+B)$
> >
> > 即： $\cos (A - B) = -t\cos (A + B)$ 即 $(t + 1)\cos A\cos B = (t - 1)\sin A\sin B$
> >
> > 又由 $\cos A\cos B + f(t)\cos C = 0$
> >
> > 可得 $f(t)=\frac{\cos A\cos B}{-\cos C}=\frac{\cos A\cos B}{\cos(A+B)}=\frac{\cos A\cos B}{\cos A\cos B-\sin A\sin B}$
> >
> > 即 $f(t)=\frac{\cos A\cos B}{\cos A\cos B-\frac{t+1}{t-1}\cos A\cos B}=\frac{1}{1-\frac{t+1}{t-1}}=\frac{1-t}{2}$
> >
> > 又由 $\cos A\cos B + f(t)\cos C = 0$ 知 $2\cos A\cos B + (1 - t)\cos C = 0$
> >
> > 即 $2\cos A\cos B = (t - 1)\cos C$ ，平方可得： $4\cos^2 A\cos^2 B = (t - 1)^2\cos^2 C$
> >
> > $$
> > 4 \cdot \frac {1 + \cos 2 A}{2} \cdot \frac {1 + \cos 2 B}{2} = (t - 1) ^ {2} \frac {1 + \cos 2 C}{2}
> > $$
> >
> > $$
> > 1 + \cos 2 A + \cos 2 B + \cos 2 A \cos 2 B = (t - 1) ^ {2} \frac {1 + \cos 2 C}{2}
> > $$
> >
> > $$
> > \cos 2 A + \cos 2 B - (t - 1) ^ {2} \frac {1 + \cos 2 C}{2} = - (1 + \cos 2 A \cos 2 B)
> > $$
> >
> > 那么： $\frac{\cos 2A + \cos 2B - \frac{(t - 1)^2}{2}(1 + \cos 2C)}{1 + \cos 2A\cos 2B} = -1$
> >
> > 即 $g(t) = -\frac{(t - 1)^2}{2}$
