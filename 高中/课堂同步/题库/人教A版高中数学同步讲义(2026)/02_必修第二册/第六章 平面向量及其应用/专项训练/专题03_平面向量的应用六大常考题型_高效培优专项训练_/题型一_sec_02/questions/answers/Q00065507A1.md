> [!faq]- 《专题03_平面向量的应用六大常考题型_高效培优专项训练_》官方解析
>
> > [!success]- **【答案】** A. $\frac{1}{\tan A} + \frac{1}{\tan B} = 2$ B. $\tan A + \tan B$ 的最小值为 4 C. 若 $C = \frac{\pi}{4}$ ，则 $a^{2} + b^{2} = 2\sqrt{2}ab$ D. $\sqrt{2}-1\leq\frac{b}{a}\leq\sqrt{2}+1$
>
> > [!note]- **【解析】**
> > 由 $c = 2a\sin B$ ，则 $\sin C = 2\sin A\sin B$ ，故 $\frac{\sin C}{\sin A\sin B} = 2$ ，
> >
> > $$
> > \frac {1}{\tan A} + \frac {1}{\tan B} = \frac {\tan A + \tan B}{\tan A \tan B} = \frac {\sin A \cos B + \cos A \sin B}{\sin A \sin B} = \frac {\sin (A + B)}{\sin A \sin B} = \frac {\sin C}{\sin A \sin B} = 2, A.
> > $$
> >
> > $$
> > \tan A + \tan B = \frac {1}{2} (\tan A + \tan B) \left(\frac {1}{\tan A} + \frac {1}{\tan B}\right) = \frac {1}{2} \left(2 + \frac {\tan B}{\tan A} + \frac {\tan A}{\tan B}\right)
> > $$
> >
> > 又VABC不是直角三角形，则 $\tan A, \tan B$ 一正一负或同正，
> >
> > 若 $\tan A, \tan B$ 一正一负，显然 $\frac{\tan B}{\tan A} + \frac{\tan A}{\tan B} < 0$ ，此时 $\tan A + \tan B < 1$ ，最小值不为 $4$ ；
> >
> > 若 $\tan A, \tan B$ 同正，则 $\frac{\tan B}{\tan A} + \frac{\tan A}{\tan B} = 2\sqrt{\frac{\tan B}{\tan A} \cdot \frac{\tan A}{\tan B}} = 2$ ，故 $\tan A + \tan B = 2$ ，
> >
> > 当且仅当 $\tan A = \tan B = 1$ 时取等号，显然等号不能成立，故 $\tan A + \tan B > 2$
> >
> > 综上， $\tan A + \tan B$ 的最小值不为 $4$ ，B 错；
> >
> > 由 $c^{2}=a^{2}+b^{2}-2ab\cos C=a^{2}+b^{2}-\sqrt{2}ab$
> >
> > 而 $\frac{b}{\sin B} = \frac{c}{\sin C} = \sqrt{2} c$ ，即 $\sin B = \frac{b}{\sqrt{2}c}$ ，由 $c = 2a\sin B$ ，则 $c = \frac{2ab}{\sqrt{2}c} \Rightarrow c^2 = \sqrt{2} ab$
> >
> > 所以 $a^{2}+b^{2}-\sqrt{2}ab=\sqrt{2}ab\Rightarrow a^{2}+b^{2}=2\sqrt{2}ab$ ，C 对；
> >
> > 由 $c^{2}=a^{2}+b^{2}-2ab\cos C\Rightarrow a^{2}+b^{2}=c^{2}+2ab\cos C$
> >
> > 则 $\frac{a}{b} +\frac{b}{a} = \frac{a^2 + b^2}{ab} = \frac{c^2 + 2ab\cos C}{ab} = \frac{\sin^2C}{\sin A\sin B} +2\cos C = 2(\sin C + \cos C) = 2\sqrt{2}\sin (C + \frac{\pi}{4})$ ，且
> >
> > $$
> > C \in (0, \frac {\pi}{2}) \cup (\frac {\pi}{2}, \pi), \frac {b}{a} > 0
> > $$
> >
> > 所以 $2\sqrt{\frac{a}{b} \cdot \frac{b}{a}} = 2 \leq \frac{a}{b} + \frac{b}{a} \leq 2\sqrt{2}$ ，左侧等号在 $a = b$ 时取得，右侧等号在 $C = \frac{\pi}{4}$ 时取得，
> >
> > 若 $t = \frac{b}{a} > 0$ ，则 $2 \leq t + \frac{1}{t} \leq 2\sqrt{2}$ ，即 $t^2 - 2\sqrt{2}t + 1 \leq 0$ ，所以 $\sqrt{2} - 1 \leq t = \frac{b}{a} \leq \sqrt{2} + 1$ ，D 对.
> >
> > 故选 **ACD**
