> [!faq]- 《专题03_平面向量的应用六大常考题型_高效培优专项训练_》官方解析
>
> > [!success]- **【答案】** A. $a = 3, b = 4, c = 5$ ，有唯一解 B. $a = 2, b = 3, \angle A = 30^{\circ}$ ，无解 C. $a = 5, b = 3, \angle B = 120^{\circ}$ ，有两解 D. $a = 4, b = 5, \angle A = 45^{\circ}$ ，有唯一解
>
> > [!note]- **【解析】**
> > 对于 $^{A}$ ，因为 $a^{2}+b^{2}=c^{2}$ ，所以VABC是以a,b为直角边的直角三角形，故 $^{A}$ 正确；
> >
> > 对于 $^{B}$ ，若 $a=2, b=3$ ， $\angle A=30^{\circ}$ ，则 $\frac{\sin B}{3}=\frac{\frac{1}{2}}{2}$ ，解得 $1>\sin B=\frac{3}{4}>\frac{1}{2}=\sin A$ ，
> >
> > 所以有两个解，故 $^{B}$ 错误；
> >
> > 对于 $^{C}$ ，若 $a=5, b=3, \angle B=120^{\circ}$ ，则 $\frac{\sin A}{5}=\frac{\frac{\sqrt{3}}{2}}{3}$ ，解得 $\sin A=\frac{5\sqrt{3}}{6}=\frac{\sqrt{75}}{\sqrt{36}}>1$ ，所以无解，故 $^{C}$ 错误；
> >
> > 对于 D，若 $a = 4, b = 5, \angle A = 45^{\circ}$ ，则 $\frac{\sin B}{5} = \frac{\frac{\sqrt{2}}{2}}{4}$ ，解得 $1 > \sin B = \frac{5\sqrt{2}}{8} > \frac{\sqrt{2}}{2} = \sin A$ ，
> >
> > 所以有两个解，故 $^{D}$ 错误·
> >
> > 故选 **A**.
