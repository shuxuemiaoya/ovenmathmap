> [!faq]- 《专题03_平面向量的应用六大常考题型_高效培优专项训练_》官方解析
>
> > [!success]- **【答案】** 18 $\frac{5\sqrt{15}}{2}$
>
> > [!note]- **【解析】**
> > 在VABC中，由 $\sin A:\sin B:\sin C=2:3:4$ 及正弦定理，得a:b:c=2:3:4，
> >
> > 令 $a = 2t, b = 3t, c = 4t (t > 0)$ ，由余弦定理得 $\cos C = \frac{a^2 + b^2 - c^2}{2ab} = \frac{4t^2 + 9t^2 - 16t^2}{2 \cdot 2t \cdot 3t} = -\frac{1}{4}$
> > - **①**：$\sin C = \sqrt{1 - \cos^2 C} = \frac{\sqrt{15}}{4}$ ，由VABC面积为 $3\sqrt{15}$ ，得 $S_{\triangle ABC} = \frac{1}{2} ab\sin C = \frac{3\sqrt{15}}{4} t^2 = 3\sqrt{15}$
> >
> > 解得 t=2 ，所以 VABC 的周长 $a+b+c=9t=18$
> > - **②**：由①知 $S_{\triangle ABC} = \frac{3\sqrt{15}}{4} t^2$ ，而 $S_{\triangle ABC} = \frac{1}{2} (a + b + c)r = \frac{9t}{2} r$ ，则 $r = \frac{\sqrt{15}t}{6}$ ，
> >
> > 由正弦定理 $c = 2R\sin C$ ，得 $4t = 2\cdot 8\sqrt{15}\cdot \frac{\sqrt{15}}{4}$ ，解得 $t = 15$ ，所以 $r = \frac{5\sqrt{15}}{2}$
> >
> > 故答案为： $^{18}$ ； $\frac{5\sqrt{15}}{2}$
