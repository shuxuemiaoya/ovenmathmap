> [!faq]- 《专题03_平面向量的应用六大常考题型_高效培优专项训练_》官方解析
>
> > [!success]- **【答案】** AC
>
> > [!note]- **【解析】**
> > 对于 A，因为函数 $y = \cos x$ 在 $(0, \pi)$ 上单调递减，
> >
> > 在VABC中，因为 $A, B \in (0, \pi)$ ，且 $A > B$ ，所以 $\cos A < \cos B$ ，故 ${}^{\mathsf{A}}$ 正确；
> >
> > 对于 B，若 $A = 30^{\circ}, b = 5, a = 2$ ，则由正弦定理 $\frac{a}{\sin A} = \frac{b}{\sin B}$ 可得 $\frac{2}{\sin 30^{\circ}} = \frac{5}{\sin B}$ ，
> >
> > 解得 $\sin B = \frac{5}{4} > 1$ · 因为正弦函数的值域为 $[-1, 1]$ ，
> >
> > 所以不存在这样的角 B，即 VABC 无解，故 B 错误；
> >
> > 对于 $C$ ，因为 $a - c\cdot \cos B = a\cdot \cos C$
> >
> > 所以由正弦定理可得 $\sin A - \sin C \cdot \cos B = \sin A \cdot \cos C$
> >
> > 又因为 $\sin A = \sin [\pi - (B + C)] = \sin (B + C) = \sin B\cos C + \cos B\sin C$
> >
> > 所以可得 $\sin B\cos C = \sin A\cos C$ ，即 $(\sin B - \sin A)\cos C = 0$
> >
> > 即 $\sin B = \sin A$ 或 $\cos C = 0$
> >
> > 由 $\sin B = \sin A$ 可得 a = b ，即 VABC 为等腰三角形；
> >
> > 由 $\cos C = 0$ ， $C\in (0,\pi)$ ，可得 $C = \frac{\pi}{2}$ ，所以VABC为直角三角形
> >
> > 综上可知，VABC 为等腰三角形或直角三角形，故 $^{C}$ 正确；
> >
> > 对于 $^{D}$ ，若 $\cos A\cos B\cos C>0$ ，且 $A,B,C\in(0,\pi)$
> >
> > 可知 $\cos A > 0, \cos B > 0, \cos C > 0$ ，即 $A, B, C$ 都是锐角，
> >
> > 所以 VABC 是锐角三角形，故 D 错误.
> >
> > 故选 **AC**
