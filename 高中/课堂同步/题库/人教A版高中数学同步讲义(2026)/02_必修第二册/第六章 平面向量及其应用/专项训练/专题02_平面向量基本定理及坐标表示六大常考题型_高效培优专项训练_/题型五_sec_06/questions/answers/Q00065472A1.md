> [!faq]- 《专题02_平面向量基本定理及坐标表示六大常考题型_高效培优专项训练_》官方解析
>
> > [!success]- **【答案】** C
>
> > [!note]- **【解析】**
> > 因为 $a = (1,2), b = (4,3)$
> >
> > 所以 $3a - b = (-1, 3)$ ，又 $c = (k, 2)$ ，3a - b 与 c 共线，
> >
> > 所以 $(-1)\times 2 = 3\times k$
> >
> > 所以 $k = -\frac{2}{3}$ ，
> >
> > 故选 **C**.
