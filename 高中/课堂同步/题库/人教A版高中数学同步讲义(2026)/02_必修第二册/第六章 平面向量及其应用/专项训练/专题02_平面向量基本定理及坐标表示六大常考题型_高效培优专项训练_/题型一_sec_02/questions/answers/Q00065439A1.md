> [!faq]- 《专题02_平面向量基本定理及坐标表示六大常考题型_高效培优专项训练_》官方解析
>
> > [!success]- **【答案】** (1) $\overline{AO}=\frac{1}{3}\overline{AB}+\frac{1}{6}\overline{AC};\overline{EO}=-\frac{1}{3}\overline{AB}+\frac{1}{6}\overline{AC}$ (2) $\frac{3}{2}$
>
> > [!note]- **【解析】**
> > （1）由图和题设条件可得： $AO=\frac{1}{2}AP=\frac{1}{2}(AB+BP)=\frac{1}{2}AB+\frac{1}{2}\times\frac{1}{3}BC$
> >
> > $$
> > = \frac {1}{2} A B + \frac {1}{6} (A C - A B) = \frac {1}{3} A B + \frac {1}{6} A C
> > $$
> >
> > $$
> > E O = A O - A E = \frac {1}{3} A B + \frac {1}{6} A C - \frac {2}{3} A B = - \frac {1}{3} A B + \frac {1}{6} A C.
> > $$
> >
> > (2) 由图和 $\overline{PC} = 2\overline{BP}$ 可得： $\overline{AC} - \overline{AP} = 2(\overline{AP} - \overline{AB})$ ，即 $\frac{\overline{AP}}{3} = \frac{2}{3}\frac{\overline{AP}}{AB} + \frac{1}{3}\frac{\overline{AP}}{AC}$ （\*），
> >
> > 因 $AE = \lambda AB(0\leq \lambda \leq 1),AF = \mu AC(0\leq \mu \leq 1)$
> >
> > 当 $\lambda = 0$ 时，点 $E$ 与点 $A$ 重合，显然不合题意，同理 $\mu = 0$ 时，也不合题意·则 $0 < \lambda \leq 1, 0 < \mu \leq 1$
> >
> > 由（ $^{*}$ ）可得： $2AO=\frac{2}{3\lambda}AE+\frac{1}{3\mu}AF$ ，即 $AO=\frac{1}{3\lambda}AE+\frac{1}{6\mu}AF$ ，
> >
> > 因 $E, O, F$ 三点共线，故 $\frac{1}{3\lambda} + \frac{1}{6\mu} = 1$
> >
> > 又因 $2\lambda + \mu = (2\lambda + \mu)\left(\frac{1}{3\lambda} + \frac{1}{6\mu}\right) = \frac{5}{6} + \left(\frac{\lambda}{3\mu} + \frac{\mu}{3\lambda}\right) \quad \frac{5}{6} + 2 \times \frac{1}{3} = \frac{3}{2}$
> >
> > 当且仅当 $\frac{\lambda}{3\mu} = \frac{\mu}{3\lambda}$ 时，即 $\lambda = \mu = \frac{1}{2}$ 时，等号成立，
> >
> > 即 $\lambda = \mu = \frac{1}{2}$ 时， $2\lambda + \mu$ 的最小值为 $\frac{3}{2}$ .
