> [!faq]- 《专题02_平面向量基本定理及坐标表示六大常考题型_高效培优专项训练_》官方解析
>
> > [!success]- **【答案】** (1) $AP=\frac{2}{3}AB+\frac{1}{3}AC$ (2) $\frac{3}{8}$ (3) $\frac{1}{2}+\frac{\sqrt{2}}{3}$
>
> > [!note]- **【解析】**
> > （1）由图， $AP = AB + BP = AB + \frac{1}{3} BC = AB + \frac{1}{3}(AC - AB) = \frac{2}{3} AB + \frac{1}{3} AC.$
> >
> > (2) 因 E, O, F 三点共线，则存在 $t \in R$ ，使得 $AO = tAE + (1 - t)AF = \frac{1}{3}tAB + \frac{1}{2}(1 - t)AC$
> >
> > 又 $O$ 是线段 $AP$ 上一点，则存在 $m \in \mathbb{R}$ ，使得 $AP = mAO = \frac{1}{3}mtAB + \frac{1}{2}m(1 - t)AC$
> >
> > 由（1）已得 $\frac{\mathrm{u}_{\mathrm{u}}}{AP} = \frac{2}{3}\frac{\mathrm{u}_{\mathrm{u}}}{AB} +\frac{1}{3}\frac{\mathrm{u}_{\mathrm{u}}}{AC}$ ，故有 $\left\{ \begin{array}{l}\frac{1}{3} mt = \frac{2}{3}\\ \frac{1}{2} m(1 - t) = \frac{1}{3} \end{array} \right.$ ，解得： $\left\{ \begin{array}{ll}m = \frac{8}{3}\\ t = \frac{3}{4} \end{array} \right.$ ，即 $\frac{AO}{AP} = \frac{3}{8}\cdot$
> >
> > (3) 因 $AE = \lambda AB, AF = \mu AC$ ，且 E, O, F 三点共线，
> >
> > 则存在 $t \in \mathbb{R}$ ，使得 $AO = tAE + (1 - t)AF = \lambda tAB + \mu(1 - t)AC$
> >
> > 又因点 O 为线段 AP 的中点，则有 $\overline{AP} = 2\overline{AO} = 2\lambda t\overline{AB} + 2\mu(1-t)\overline{AC}$
> >
> > 与 $\frac{\mathrm{uum}}{AP} = \frac{2\mathrm{uum}}{3AB} +\frac{1\mathrm{uum}}{3AC}$ 对照可得： $\left\{ \begin{array}{ll}2\lambda t = \frac{2}{3}\\ 2\mu (1 - t) = \frac{1}{3} & t\end{array} \right.$ ，消去即得，即 $\frac{2}{\lambda} +\frac{1}{\mu} = 6$
> >
> > 故 $\lambda +\mu = \frac{1}{6} (\lambda +\mu)(\frac{2}{\lambda} +\frac{1}{\mu}) = \frac{1}{6} (3 + \frac{\lambda}{\mu} +\frac{2\mu}{\lambda})$ $\frac{1}{6} (3 + 2\sqrt{2})$
> >
> > 当且仅当 $\frac{\lambda}{\mu} = \frac{2\mu}{\lambda}$ 时，即当 $\lambda = \frac{2 + \sqrt{2}}{6},\mu = \frac{1 + \sqrt{2}}{6}$ 时， $\lambda +\mu$ 取得最小值为 $\frac{1}{2} +\frac{\sqrt{2}}{3}$
