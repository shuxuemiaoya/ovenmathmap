> [!faq]- 《专题01 平面向量的运算七大常考题型（高效培优专项训练）》官方解析
>
> > [!success]- **【答案】** (1)证明见解析 (2) $\lambda = \pm \frac{\sqrt{2}}{2}$ (3) $(-∞,-2-\sqrt{3})∪(-2+\sqrt{3},1)∪(1,+∞)$
>
> > [!note]- **【解析】**
> > （1）由 $BC = 4e_{1} + e_{2}, CD = 8e_{1} - 9e_{2}$ ，可得 $BD = 12e_{1} - 8e_{2}$
> >
> > 因 $AB = 3e_{1} - 2e_{2}$ ，则有 $BD = 4AB$
> >
> > 又 $BD$ 与 $AB$ 有公共点 $B$ ，故 $A$ 、 $B$ 、 $D$ 三点共线·
> >
> > (2) 依题意，设 $2\lambda e_{1} + e_{2} = t(e_{1} + \lambda e_{2})$ ，则得 $\left\{ \begin{array}{l} 2\lambda = t \\ t\lambda = 1 \end{array} \right.$ ，解得 $\lambda = \pm \frac{\sqrt{2}}{2}$
> >
> > 当 $\lambda = \frac{\sqrt{2}}{2}$ 时， $2\lambda e_1 + e_2 = \sqrt{2} e_1 + e_2$ ， $\vec{e}_1 + \lambda \vec{e}_2 = \vec{e}_1 + \frac{\sqrt{2}}{2} \vec{e}_2$
> >
> > 此时显然有 $2\lambda e_{1} + e_{2} = \sqrt{2}(e_{1} + \lambda e_{2})$ ，符合题意；
> >
> > 当 $\lambda = -\frac{\sqrt{2}}{2}$ 时， $2\lambda e_1 + e_2 = -\sqrt{2}e_1 + e_2$ ， $\vec{e}_1 + \lambda \vec{e}_2 = e_1 - \frac{\sqrt{2}}{2}\vec{e}_2$ ，
> >
> > 此时显然有 $2\lambda e_{1} + e_{2} = -\sqrt{2}(e_{1} + \lambda e_{2})$ ，符合题意·
> >
> > 故 $\lambda = \pm \frac{\sqrt{2}}{2}$ 时， $2\lambda e_{1} + e_{2}$ 和 $e_{1} + \lambda e_{2}$ 共线.
> >
> > (3) 因 $|\stackrel{\square}{e}_1| = |\stackrel{\square}{e}_2| = 1$ ， $\langle e_1, e_2 \rangle = \frac{\pi}{3}$ ，则 $e_1 \cdot e_2 = \cos \frac{\pi}{3} = \frac{1}{2}$ .
> >
> > 由题意，可得 $(e_1 + \lambda e_2) \cdot (\lambda e_1 + e_2) > 0$ 且 $e_1 + \lambda e_2$ 与 $\lambda e_1 + e_2$ 不共线，
> >
> > 由 $(e_1 + \lambda e_2) \cdot (\lambda e_1 + e_2) = \lambda e_1^2 + (\lambda^2 + 1)e_1 \cdot e_2 + \lambda e_2^2 > 0$ ，即 $\frac{1}{2}\lambda^2 + 2\lambda + \frac{1}{2} > 0$
> >
> > 故 $\lambda^{2}+4\lambda+1>0$ ，解得 $\lambda<-2-\sqrt{3}$ 或 $\lambda>-2+\sqrt{3}$ ；
> >
> > 又由 $\stackrel{\square}{e_1} + \lambda \stackrel{\square}{e_2}$ 与 $\lambda \stackrel{\square}{e_1} + \stackrel{\square}{e_2}$ 共线可得 $\stackrel{\square}{e_1} + \lambda \stackrel{\square}{e_2} = m(\lambda \stackrel{\square}{e_1} + \stackrel{\square}{e_2})$ ，即 $\left\{ \begin{array}{l}m\lambda = 1\\ m = \lambda \end{array} \right.$ ，解得 $\lambda = \pm 1$
> >
> > 故 $e_{1}+\lambda e_{2}$ 与 $\lambda e_{1}+e_{2}$ 不共线，即 $\lambda\neq\pm1\cdot$
> >
> > 综上， $\lambda$ 的取值范围为 $(- \infty, -2 - \sqrt{3}) \cup (-2 + \sqrt{3}, 1) \cup (1, +\infty)$ .
