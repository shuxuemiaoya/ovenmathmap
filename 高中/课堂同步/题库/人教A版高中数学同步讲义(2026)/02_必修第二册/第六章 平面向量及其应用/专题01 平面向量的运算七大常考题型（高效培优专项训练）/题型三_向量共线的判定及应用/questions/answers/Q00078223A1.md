> [!faq]- 《专题01 平面向量的运算七大常考题型（高效培优专项训练）》官方解析
>
> > [!success]- **【答案】** A. 若 $a // b$ ，则 a 与 b 方向相同或相反 B．若 $a \perp b$ ，则 $\left|a + b\right| = \left|a - b\right|$ C．“ $a = \lambda b (\lambda \in \mathbb{R})$ ”是 $a$ ， $b$ 共线”的充要条件 D．若两个单位向量互相平行，则这两个单位向量相等
>
> > [!note]- **【解析】**
> > 对于 A，当 a = 0 或 b = 0 时，有 a // b
> >
> > 但 a 与 b 方向相同或相反不一定成立，故 A 错误；
> >
> > 对于 $\mathsf{B}$ ，若 $a\perp b$ ，则 $a\cdot b = 0$
> >
> > 则 $\left|a+b\right|^{2}=\left|a-b\right|^{2}=\left|a\right|^{2}+\left|b\right|^{2}$ ，即 $\left|a+b\right|=\left|a-b\right|$ ，故B正确；
> >
> > 对于 C，由 $a = \lambda b (\lambda \in \mathbb{R})$ ，可得 a，b 共线，
> >
> > 若 $a \neq 0$ ， $b = 0$ ，则 $a // b$ ，但不存在实数 $\lambda$ ，使得 $a = \lambda b$ ，
> >
> > 故“ $a = \lambda b(\lambda \in \mathbf{R})$ ”是 $a$ ， $b$ 共线”的充分不必要条件，故C错误；
> >
> > 对于 D，两个单位向量互相平行，它们的方向可能相同也可能相反，
> >
> > 则这两个单位向量不一定相等，故 $^{D}$ 错误。
> >
> > 故选 **B**.
