> [!faq]- 《专题03 平面向量的应用六大常考题型（高效培优专项训练）》官方解析
>
> > [!success]- **【答案】** $^{(1)}$ 是，理由见解析 (2)选①③④， $\frac{1+\sqrt{3}}{2}$
>
> > [!note]- **【解析】**
> > （1）因为 $b \cos A - c > 0$ ，由正弦定理可得 $\sin B \cos A - \sin C > 0$ ，
> >
> > 在VABC中， $C = \pi -A - B$
> >
> > $\sin C = \sin (A + B) = \sin A\cos B + \cos A\sin B$
> >
> > 所以不等式整理为 $\sin A\cos B + \cos A\sin B <   \sin B\cos A$
> >
> > 即 $\sin A\cos B < 0$ ，因为 $A\in (0,\pi),\sin A > 0$
> >
> > 所以 $\cos B < 0$ ，所以 $B$ 为钝角；
> >
> > (2) 若满足①②，由 B 为钝角，则 A，C 为锐角，
> >
> > 及 $\sin A = \frac{\sqrt{2}}{2},\sin C = \frac{\sqrt{3}}{2}$ ，可得 $A = \frac{\pi}{4},C = \frac{\pi}{3}$
> >
> > 所以 $B = \frac{5}{12}\pi$ 不符合 $B$ 为钝角，故①②不同时成立，
> >
> > 所以③④两个条件必选，
> >
> > 由③④可知 $a > c$ ，所以 $A > C$ ，所以②不成立，因此选①③④：
> >
> > 由正弦定理可得 $\frac{a}{\sin A} = \frac{c}{\sin C}$
> >
> > 即 $\frac{2}{\frac{\sqrt{2}}{2}} = \frac{\sqrt{2}}{\sin C}$ ，所以 $\sin C = \frac{1}{2}$ ，又 $a > c$ ，所以 $A > C$ ，在三角形中， $\sin A = \frac{\sqrt{2}}{2}$
> >
> > 所以 $A=\frac{\pi}{4}$ 或 $A=\frac{3}{4}\pi$ ，而由（Ⅰ）可得 $A=\frac{\pi}{4}$ ，
> >
> > 所以可得 $C=\frac{\pi}{6}, B=\pi-A-C=\pi-\frac{\pi}{4}-\frac{\pi}{6}=\frac{7}{12}\pi$ ;
> >
> > 所以 $\sin B = \sin(\pi - A - C) = \sin(A + C) = \sin A \cos C + \cos A \sin C = \frac{\sqrt{2} + \sqrt{6}}{4}$ ;
> >
> > 所以 $S=\frac{1}{2}ac\sin B=\frac{1}{2}\times2\times\sqrt{2}\times\frac{\sqrt{2}+\sqrt{6}}{4}=\frac{1+\sqrt{3}}{2}$
