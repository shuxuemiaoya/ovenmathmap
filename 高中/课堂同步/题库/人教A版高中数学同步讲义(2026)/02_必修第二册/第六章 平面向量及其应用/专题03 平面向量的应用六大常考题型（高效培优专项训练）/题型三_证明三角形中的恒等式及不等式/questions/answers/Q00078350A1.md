> [!faq]- 《专题03 平面向量的应用六大常考题型（高效培优专项训练）》官方解析
>
> > [!success]- **【答案】** (1)证明见解析； (2) $\left(\frac{1}{2},1\right)$ .
>
> > [!note]- **【解析】**
> > （1） $a^2 + c^2 - b^2 = 2bc(1 + \cos A) \Rightarrow \frac{a^2 + c^2 - b^2}{2ac} = \frac{b}{a}(1 + \cos A)$
> >
> > $$
> > \Rightarrow \cos B = \frac {b}{a} (1 + \cos A) \Rightarrow a \cos B = b (1 + \cos A)
> > $$
> >
> > 根据正弦定理 $\frac{a}{\sin A} = \frac{b}{\sin B}$ ，由 $a\cos B = b(1 + \cos A)\Rightarrow$
> >
> > $$
> > \sin A \cos B = \sin B (1 + \cos A) \Rightarrow \sin A \cos B - \sin B \cos A = \sin B
> > $$
> >
> > 即 $\sin(A-B)=\sin B$
> >
> > ∵ $\triangle ABC$ 是锐角三角形，
> >
> > $\therefore A, B \in \left(0, \frac{\pi}{2}\right)$ , $\therefore A - B \in \left(-\frac{\pi}{2}, \frac{\pi}{2}\right)$ ,
> >
> > 因此有 $A - B = B \Rightarrow A = 2B$
> >
> > (2) VABC 是锐角三角形， $\therefore A, B, C \in \left(0, \frac{\pi}{2}\right)$ ，而 $C = \pi - A - B = \pi - 3B$ ，
> >
> > $$
> > \therefore \left\{ \begin{array}{l} 0 <   B <   \frac {\pi}{2}, \\ 0 <   2 B <   \frac {\pi}{2}, \quad \Rightarrow \frac {\pi}{6} <   B <   \frac {\pi}{4} \\ 0 <   \pi - 3 B <   \frac {\pi}{2} \end{array} \right.
> > $$
> >
> > 由正弦定理 $\frac{b}{\sin B} = \frac{c}{\sin C}$ ，得 $\frac{b}{c} = \frac{\sin B}{\sin C} = \frac{\sin B}{\sin 3B}$
> >
> > 则 $\sin3B=\sin(2B+B)=\sin2B\cos B+\cos2B\sin B=2\sin B\cos^{2}B+(1-2\sin^{2}B)\sin B$
> >
> > 而 $1 - \sin^2 B = \cos^2 B, \therefore \sin 3B = 3\sin B - 4\sin^3 B$
> >
> > 所以 $y=\frac{b}{c}=\frac{1}{3-4\sin^{2}B},\because B\in\left(\frac{\pi}{6},\frac{\pi}{4}\right),\therefore \sin B\in\left(\frac{1}{2},\frac{\sqrt{2}}{2}\right)$
> >
> > $\therefore y = \frac{b}{c} \in \left( \frac{1}{2}, 1 \right)$ 因此 $\frac{b}{c}$ 的取值范围为 $\left( \frac{1}{2}, 1 \right)$ .
