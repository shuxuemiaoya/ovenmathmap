> [!faq]- 《专题03 平面向量的应用六大常考题型（高效培优专项训练）》官方解析
>
> > [!success]- **【答案】** A. $\sin C = \frac{\sqrt{2}}{2}$ B. $\sin A = \cos B$ C. $\cos C = \frac{\sqrt{2}}{2}$ D. $\sin 2A = \sin 2B$
>
> > [!note]- **【解析】**
> > 因为 $A, B \in (0, \pi)$ ，可得 $4A \in (0, 4\pi), 4B \in (0, 4\pi)$ ，由 $\sin 4A = \sin 4B$ ，可得以下情况：①若 $4A = 4B$ ，即 $A = B$ ，这与 $\mathrm{VABC}$ 是非等腰三角形矛盾，不符合题意；
> > - **②**：若 $4A + 4B = \pi$ ，即 $A + B = \frac{\pi}{4}$ ，此时 $\sin C = \frac{\sqrt{2}}{2}$ ，所以 ${}^{\mathrm{A}}$ 正确；
> > - **③**：若 $4A = 4B \pm 2\pi$ ，若 $A = B + \frac{\pi}{2}$ ，则 $\sin A = \cos B$ ，所以 ${}^{\mathrm{B}}$ 正确，
> > 若 $A = B - \frac{\pi}{2}$ ，则 $\sin A = -\cos B$ ；
> > - **④**：若 $4A + 4B = 3\pi$ ，即 $A + B = \frac{3\pi}{4}$ ，此时 $\cos C = \frac{\sqrt{2}}{2}$ ，所以 ${}^{\mathrm{C}}$ 正确，
> > 由 $\sin 2A = \sin 2B$ ，可得 $2A = 2B$ ，即 $A = B$ ，不符合题意，
> > 或 $2A + 2B = \pi$ ，即 $A = \frac{\pi}{2} - B$ ，此时 $\sin 4A = -\sin 4B$ ，所以 ${}^{\mathrm{D}}$ 不正确。
> >
> > 故选 **ABC**.
