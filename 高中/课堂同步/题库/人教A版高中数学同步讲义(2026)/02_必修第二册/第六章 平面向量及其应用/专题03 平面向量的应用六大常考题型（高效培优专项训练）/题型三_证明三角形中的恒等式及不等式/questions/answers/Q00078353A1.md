> [!faq]- 《专题03 平面向量的应用六大常考题型（高效培优专项训练）》官方解析
>
> > [!success]- **【答案】** A. 若 $\mathrm{VABC}$ 为锐角三角形，则 $\sin A > \cos B$ B. 若 $A > B$ ，则 $\sin A > \sin B$ C. 若 $a \cos A = b \cos B$ ，则 $\mathrm{VABC}$ 一定是等腰三角形 D．若VABC为非直角三角形，则 $\tan A + \tan B + \tan C = \tan A\tan B\tan C$
>
> > [!note]- **【解析】**
> > 对于 A 中，若 $V_{ABC}$ 为锐角三角形，可得 $A + B > \frac{\pi}{2}$ 且 $A, B \in \left(0, \frac{\pi}{2}\right)$
> >
> > 可得 $A > \frac{\pi}{2} - B$ ，且 $\frac{\pi}{2} - B \in \left(0, \frac{\pi}{2}\right)$ ，根据正弦函数的单调性，可得 $\sin A > \sin \left(\frac{\pi}{2} - B\right)$ ，所以 $\sin A > \cos B$ ，
> >
> > 所以 A 正确；
> >
> > 对于 $B$ 中，在VABC中，由 $A > B$ 知 $a > b$ ，根据正弦定理可得 $\sin A > \sin B$ ，所以 $B$ 正确；
> >
> > 对于 $C$ 中，由正弦定理知 $a = 2R\sin A, b = 2R\sin B$ ，可得 $\sin 2A = \sin 2B$ ，故 $2A = 2B$ 或 $2A + 2B = \pi$
> >
> > VABC 是等腰三角形或直角三角形，所以 C 不正确；
> >
> > 对于 D 中，在 VABC 中，可得 $A + B + C = \pi$ ，则 $A + B = \pi - C$ ，
> >
> > 所以 $\tan(A+B)=\tan(\pi-C)$ ，即 $\frac{\tan A+\tan B}{1-\tan A\tan B}=-\tan C$ ，
> >
> > 可得 $\tan A + \tan B = -\tan C + \tan A\tan B\tan C$
> >
> > 则 $\tan A + \tan B + \tan C = \tan A\tan B\tan C$ ，所以 $D$ 正确
> >
> > 故选 **ABD**·
