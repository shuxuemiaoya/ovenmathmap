> [!faq]- 《专题03 平面向量的应用六大常考题型（高效培优专项训练）》官方解析
>
> > [!success]- **【答案】** (1) $\frac{\pi}{3}$ (2) $\left(3+\sqrt{3},3\sqrt{3}\right]$
>
> > [!note]- **【解析】**
> > （1）由面积公式得 $a^2 + 4\sqrt{3} \times \frac{1}{2} bc \sin A = (b + c)^2$ ，即 $a^2 = (b + c)^2 - 2\sqrt{3} bc \sin A$
> >
> > 由余弦定理得 $a^2 = b^2 + c^2 - 2bc\cos A$ ，所以 $\left(b + c\right)^2 - 2\sqrt{3} bc\sin A = b^2 + c^2 - 2bc\cos A$
> >
> > 则 $2bc - 2\sqrt{3} bc\sin A = -2bc\cos A$ ，所以 $\sqrt{3}\sin A - \cos A = 2\sin \left(A - \frac{\pi}{6}\right) = 1$ ，即 $\sin \left(A - \frac{\pi}{6}\right) = \frac{1}{2}$
> >
> > 因为 $A \in (0, \pi)$ ，则 $A - \frac{\pi}{6} \in \left(-\frac{\pi}{6}, \frac{5\pi}{6}\right)$ ，所以 $A - \frac{\pi}{6} = \frac{\pi}{6}$ ，即 $A = \frac{\pi}{3}$
> >
> > (2) 由正弦定理得 $\frac{a}{\sin A} = \frac{b}{\sin B} = \frac{c}{\sin C} = \frac{\sqrt{3}}{\frac{\sqrt{3}}{2}} = 2$ ，所以 $b = 2\sin B, c = 2\sin C$
> >
> > 所以 $b + c = 2 \sin B + 2 \sin C = 2 \sin B + 2 \sin \left( \frac{2\pi}{3} - B \right) = 2 \sin B + 2 \left( \frac{\sqrt{3}}{2} \cos B + \frac{1}{2} \sin B \right)$
> >
> > $$
> > = 3 \sin B + \sqrt {3} \cos B = 2 \sqrt {3} \sin \left(B + \frac {\pi}{6}\right)
> > $$
> >
> > 因为 VABC 为锐角三角形，
> >
> > 所以 $\left\{\begin{aligned}0<B<\frac{\pi}{2}\\ 0&C=C=\frac{2\pi}{3}-B<\frac{\pi}{2}\end{aligned}\right.$ ，解得 $\frac{\pi}{6}<B<\frac{\pi}{2}$ ，
> >
> > 所以 $\frac{\pi}{3} < B + \frac{\pi}{6} < \frac{2\pi}{3}$
> >
> > 所以 $\sin \left(B + \frac{\pi}{6}\right) \in \left(\frac{\sqrt{3}}{2}, 1\right]$ ，则 $b + c = 2\sqrt{3} \sin \left(B + \frac{\pi}{6}\right) \in \left(3, 2\sqrt{3}\right]$ ，
> >
> > 所以三角形VABC周长为 $a+b+c\in(3+\sqrt{3},3\sqrt{3}]$
