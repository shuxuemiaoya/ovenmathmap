> [!faq]- 《专题03 平面向量的应用六大常考题型（高效培优专项训练）》官方解析
>
> > [!success]- **【答案】** (1) $A = \frac{\pi}{4}$ (2) $(4,8)$
>
> > [!note]- **【解析】**
> > （1） $\left(c - \sqrt{2} b\right)\sin C = a\sin A - b\sin B$
> >
> > 故 $\left(c-\sqrt{2}b\right)c=a^{2}-b^{2}$ ，即 $b^{2}+c^{2}-a^{2}=\sqrt{2}bc$
> >
> > 故 $\cos A = \frac{b^{2} + c^{2} - a^{2}}{2bc} = \frac{\sqrt{2}}{2}$
> >
> > 且 $0 < A < \frac{\pi}{2}$ ，故 $A = \frac{\pi}{4}$ .
> >
> > (2) 由正弦定理 $\frac{b}{\sin B} = \frac{c}{\sin C}$ 得，
> >
> > $$
> > b = \frac {c \sin B}{\sin C} = \frac {4 \sin \left(\frac {3 \pi}{4} - C\right)}{\sin C} = \frac {2 \sqrt {2} (\cos C + \sin C)}{\sin C} = 2 \sqrt {2} \left(\frac {1}{\tan C} + 1\right),
> > $$
> >
> > 因为 VABC 是锐角三角形，
> >
> > 故 $0 < \frac{3\pi}{4} - C < \frac{\pi}{2}, 0 < C < \frac{\pi}{2}$ ，即 $\frac{\pi}{4} < C < \frac{\pi}{2}$
> >
> > 所以 $\tan C > 1$ ，故 $2\sqrt{2} < b = 2\sqrt{2}\left(\frac{1}{\tan C} + 1\right) < 4\sqrt{2}$
> >
> > 所以 $S_{\triangle ABC} = \frac{1}{2}bc \sin A = \sqrt{2}b \in (4,8)$
> >
> > 故VABC 面积的取值范围为 $(4,8)$ .
