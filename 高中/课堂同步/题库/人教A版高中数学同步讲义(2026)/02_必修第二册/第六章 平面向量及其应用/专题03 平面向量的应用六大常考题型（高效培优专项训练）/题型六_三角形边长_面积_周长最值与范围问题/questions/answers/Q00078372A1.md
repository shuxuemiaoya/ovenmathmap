> [!faq]- 《专题03 平面向量的应用六大常考题型（高效培优专项训练）》官方解析
>
> > [!success]- **【答案】** $\left(0, \frac{\sqrt{3}}{3}\right)$
>
> > [!note]- **【解析】**
> > 因为 $\frac{\sin A + \sin B}{\sin C} = \frac{b - c}{b - a}$ ，由正弦边角关系得 $\frac{a + b}{c} = \frac{b - c}{b - a}$ ，即 $b^{2} + c^{2} - a^{2} = bc$
> >
> > 由余弦定理，得 $\cos A = \frac{b^2 + c^2 - a^2}{2bc} = \frac{bc}{2bc} = \frac{1}{2}$ ，又 $A\in (0,\pi)$ ，所以 $A = \frac{\pi}{3}$
> >
> > 由正弦定理得 $\frac{b}{\sin B} = \frac{c}{\sin C} = \frac{a}{\sin A} = \frac{2}{\sin \frac{\pi}{3}} = \frac{4}{\sqrt{3}}$ ，所以 $b = \frac{4}{\sqrt{3}}\sin B$ ， $c = \frac{4}{\sqrt{3}}\sin C$ ，
> >
> > 由余弦定理，得 $4 = b^{2} + c^{2} - 2bc\cos \frac{\pi}{3} = (b + c)^{2} - 3bc$ ，所以 $bc = \frac{(b + c)^2 - 4}{3}$
> >
> > 利用等面积法可得 $S_{\triangle ABC} = \frac{1}{2}bc\sin A = \frac{1}{2}(a + b + c)r$ ，
> >
> > $$
> > r = \frac {b c \sin A}{a + b + c} = \frac {\sqrt {3}}{6} \frac {(b + c) ^ {2} - 4}{2 + b + c} = \frac {\sqrt {3}}{6} (b + c - 2)
> > $$
> >
> > $= \frac{\sqrt{3}}{6}\left(\frac{4}{\sqrt{3}}\sin B + \frac{4}{\sqrt{3}}\sin C - 2\right) = \frac{\sqrt{3}}{6}\left[\frac{4}{\sqrt{3}}\sin B + \frac{4}{\sqrt{3}}\sin \left(\frac{2}{3}\pi -B\right) - 2\right]$ $= \frac{2\sqrt{3}}{3}\sin \left(B + \frac{\pi}{6}\right) - \frac{\sqrt{3}}{3},$ $\because a\neq b,\therefore B\neq A = \frac{\pi}{3}$ ，故 $B\in \left(0,\frac{\pi}{3}\right)\cup \left(\frac{\pi}{3},\frac{2\pi}{3}\right)$ ，则 $B + \frac{\pi}{6}\in \left(\frac{\pi}{6},\frac{\pi}{2}\right)\cup \left(\frac{\pi}{2},\frac{5\pi}{6}\right),$ 所以 $\sin \left(B + \frac{\pi}{6}\right)\in \left(\frac{1}{2},1\right)$ ，故 $r\in \left(0,\frac{\sqrt{3}}{3}\right)$ 故答案为： $\left(0,\frac{\sqrt{3}}{3}\right)$
