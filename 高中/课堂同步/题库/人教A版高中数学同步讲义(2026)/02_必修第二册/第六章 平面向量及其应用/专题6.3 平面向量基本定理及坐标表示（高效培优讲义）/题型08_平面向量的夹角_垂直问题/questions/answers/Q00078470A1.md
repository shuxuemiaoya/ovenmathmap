> [!faq]- 《专题6.3 平面向量基本定理及坐标表示（高效培优讲义）》官方解析
>
> > [!success]- **【答案】** A. $\left|b\right|=\sqrt{2}$ B. 向量 $2a - b$ 与 $a - 2b$ 的夹角为 $\frac{\pi}{4}$ C. $\left(2a + b\right)_{I/I}\left(a + 2b\right)$ D．向量 a 在 b 方向上的投影向量的长度为 $\sqrt{2}$
>
> > [!note]- **【解析】**
> > 向量 $a = (1,2)$ ， $b = (m,1)(m < 0)$ ，则 $a + b = (1 + m,3)$
> >
> > ∵向量 b 满足 $b \cdot (a + b) = 3$ ，∴ $m(m + 1) + 3 = 3$ ，解得 m = -1 或 m = 0
> >
> > 又因为 m < 0 ，所以 m = -1 ，所以 $b = (-1, 1)$
> >
> > 对于 A， $\left|b\right|=\sqrt{(-1)^{2}+1^{2}}=\sqrt{2}$ ，故 A 正确；
> >
> > 对于 B， $2a - b = (3,3), a - 2b = (3,0)$
> >
> > $$
> > \left| 2 \vec {a} - b \right| = \sqrt {3 ^ {2} + 3 ^ {2}} = 3 \sqrt {2}, \left| a - 2 b \right| = \sqrt {3 ^ {2} + 0 ^ {2}} = 3 \quad (2 a - b) \cdot (a - 2 b) = 3 \times 3 + 3 \times 0 = 9
> > $$
> >
> > 向量 $2a - b$ 与 $a - 2b$ 的夹角为 $\theta$ ，则 $\cos \theta = \frac{9}{3\sqrt{2} \times 3} = \frac{\sqrt{2}}{2}$
> >
> > 因为 $\theta \in [0,\pi ]$ ，所以 $\theta = \frac{\pi}{4}$ ，故B正确；
> >
> > 对于 C， $2a + b = (1,5), a + 2b = (-1,4)$ ，由于 $1 \times 4 - (-1) \times 5 \neq 0$ ，所以 $2a + b, a + 2b$ 不平行，故 C 错误；
> >
> > 对于 D，向量在方向上的投影向量的长度为 $\frac{\left|a\cdot b\right|}{\left|b\right|}=\frac{1}{\sqrt{2}}=\frac{\sqrt{2}}{2}$ ，故 D 错误。
> >
> > 故选 **AB**.
