> [!faq]- 《专题6.3 平面向量基本定理及坐标表示（高效培优讲义）》官方解析
>
> > [!success]- **【答案】** (1) m = n = 1 ; (2) $k = -2$ .
>
> > [!note]- **【解析】**
> > （1）∵ $a = mb + nc$ ，即 $(1,3) = m(-1,2) + n(2,1)$
> >
> > $\therefore \left\{ \begin{array}{l} -m + 2n = 1 \\ 2m + n = 3 \end{array} \right.$ ，解得 $m = n = 1$ ：
> >
> > (2) $a + kc = (1 + 2k,3 + k)$ ， $2b - a = (-3,1)$
> >
> > $$
> > \because (a + k c) / / (2 b - a)
> > $$
> >
> > $\therefore 1 \times (1 + 2k) - [ -3(3 + k) ] = 0$ ，即 $-3(3 + k) = 1 + 2k$ ，解得 $k = -2$
