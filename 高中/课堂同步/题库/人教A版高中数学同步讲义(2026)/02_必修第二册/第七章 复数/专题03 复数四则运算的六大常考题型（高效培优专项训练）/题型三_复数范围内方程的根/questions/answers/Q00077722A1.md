> [!faq]- 《专题03 复数四则运算的六大常考题型（高效培优专项训练）》官方解析
>
> > [!success]- **【答案】** A. $z_1 = 2$ B. $z_2 + z_3 = -2$ C. $|z_2 - z_3| = 2\sqrt{3}$ D. $|z_1z_2 + z_2z_3| = 2$
>
> > [!note]- **【分析】**
> > 根据方程在复数上的根结合韦达定理求解复数根 $z_{1}$ ， $z_{2}$ ， $z_{3}$ ，逐项判断即可得结论.
>
> > [!note]- **【解析】**
> > 由方程 $z^3 = 8$ 可得 $z^3 - 8 = (z - 2)(z^2 + 2z + 4) = 0$
> >
> > 该方程的三个不相等的复数根分别为 $z_{1}$ ， $z_{2}$ ， $z_{3}$ ，其中 $z_{1} \in \mathbf{R}$
> >
> > 所以 $z_{1} = 2$ ， $z_{2}$ ， $z_{3}$ 是方程 $z^{2} + 2z + 4 = 0$ 在复数上的两根，
> >
> > 则 $z_{2} + z_{3} = -2, z_{2}z_{3} = 4$ ，故A，B正确；
> >
> > 设 $z_{2} = a + bi, z_{3} = c + di$ ，则可得 $\left\{ \begin{array}{l} z_{2} + z_{3} = (a + c) + (b + d) \mathrm{i} = -2 \\ z_{2}z_{3} = (ac - bd) + (bc + ad) \mathrm{i} = 4 \end{array} \right.$ ，
> >
> > 所以 $\left\{ \begin{array}{l}a + c = -2\\ b + d = 0\\ ac - bd = 4 \end{array} \right.$ 解得 或 $bc + ad = 0$ $a = c = -1,b = \sqrt{3},d = -\sqrt{3}$ $a = c = -1,b = -\sqrt{3},d = \sqrt{3}$
> >
> > 故 $z_{2}$ ， $z_{3}$ 两根为 $-1 + \sqrt{3}\mathrm{i}, - 1 - \sqrt{3}\mathrm{i}$
> >
> > 则 $\left|z_{2}-z_{3}\right|=\left|\left(-1+\sqrt{3}\mathrm{i}\right)-\left(-1-\sqrt{3}\mathrm{i}\right)\right|=\left|2\sqrt{3}\mathrm{i}\right|=2\sqrt{3}$ ，故C正确；
> >
> > $\left|z_{1}z_{2} + z_{2}z_{3}\right| = \left|2\left(-1\pm \sqrt{3}\mathrm{i}\right) + 4\right| = \left|2\pm 2\sqrt{3}\mathrm{i}\right| = \sqrt{2^{2} + (\pm 2\sqrt{3})^{2}} = 4$ ，故D不正确.
> >
> > 故选 **ABC**.
