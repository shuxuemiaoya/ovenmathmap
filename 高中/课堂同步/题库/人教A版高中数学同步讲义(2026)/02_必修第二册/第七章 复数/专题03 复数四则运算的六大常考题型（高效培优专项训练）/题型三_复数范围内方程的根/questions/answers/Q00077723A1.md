> [!faq]- 《专题03 复数四则运算的六大常考题型（高效培优专项训练）》官方解析
>
> > [!success]- **【答案】** ABC
>
> > [!note]- **【分析】**
> > 利用因式分解可求三个复数根，再逐项计算后可得正确的选项.
>
> > [!note]- **【解析】**
> > 因为 $z^3 = 8$ ，故 $(z - 2)(z^2 + 2z + 4) = 0$
> >
> > 故 $z = 2$ 或 $z^2 + 2z + 4 = 0$ ，故 $z = 2$ 或 $(z + 1)^2 = -3$
> >
> > 故 $z = 2$ 或 $z = -1 \pm \sqrt{3} \mathrm{i}$ ，而 $z_{1} \in \mathbf{R}$ ，故 $z_{1} = 2$ ，故A正确；
> >
> > 不妨设 $z_{2} = -1 + \sqrt{3}\mathrm{i}, z_{3} = -1 - \sqrt{3}\mathrm{i}$ ，则 $z_{2} + z_{3} = -2$ ，故B正确；
> >
> > $\left|z_{2}-z_{3}\right|=\left|2\sqrt{3}\mathrm{i}\right|=2\sqrt{3}$ ，故C正确；
> >
> > $\left|z_{1}z_{2} + z_{2}z_{3}\right| = \left|z_{2}\left(z_{1} + z_{3}\right)\right|$ ，而 $z_{2}(z_{1} + z_{3}) = (-1 + \sqrt{3}\mathrm{i})(1 - \sqrt{3}\mathrm{i}) = 2 + 2\sqrt{3}\mathrm{i}$
> >
> > 故 $\left|z_{1}z_{2}+z_{2}z_{3}\right|=\sqrt{4+12}=4$ ，故D错误.
> >
> > 故选 **ABC**.
