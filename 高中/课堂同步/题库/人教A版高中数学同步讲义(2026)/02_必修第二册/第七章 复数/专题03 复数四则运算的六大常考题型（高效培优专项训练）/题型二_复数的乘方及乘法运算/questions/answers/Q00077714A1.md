> [!faq]- 《专题03 复数四则运算的六大常考题型（高效培优专项训练）》官方解析
>
> > [!success]- **【答案】** C
>
> > [!note]- **【分析】**
> > 根据给定条件，利用复数的除法求出 z，再利用复数乘方及复数模的意义求得答案.
>
> > [!note]- **【解析】**
> > 依题意，复数 $z=\frac{(1-i)(1-i)}{(1+i)(1-i)}=\frac{-2i}{2}=-i$
> >
> > 所以 $|z^{2025} - z^{2026}| = |(-\mathrm{i})^{2025} - (-\mathrm{i})^{2026}| = |- \mathrm{i} - (-1)| = |1 - \mathrm{i}| = \sqrt{2}$
> >
> > 故选：C
> >
> > 15. 复数 $z = \frac{-5\mathrm{i}^{2026}}{\mathrm{i} - 2}$ 的虚部为（）A.-2 B.-1 C.-i D.i
> >
> > 【答案】B
> > 【分析】应用复数的乘方及除法运算化简，再应用虚部的定义求解.
> >
> > 【详解】 $z = \frac{-5\mathrm{i}^{2026}}{\mathrm{i} - 2} = \frac{-5\mathrm{i}^2}{-2 + \mathrm{i}} = \frac{5(-2 - \mathrm{i})}{(-2 + \mathrm{i})(-2 - \mathrm{i})} = \frac{5(-2 - \mathrm{i})}{4 - \mathrm{i}^2} = -2 - \mathrm{i}$
> >
> > 所以复数的虚部为 -1.
> >
> > 故选 **B**.
