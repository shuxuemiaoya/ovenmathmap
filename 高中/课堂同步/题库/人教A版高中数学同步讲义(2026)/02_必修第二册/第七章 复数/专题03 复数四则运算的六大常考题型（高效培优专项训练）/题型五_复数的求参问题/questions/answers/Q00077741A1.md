> [!faq]- 《专题03 复数四则运算的六大常考题型（高效培优专项训练）》官方解析
>
> > [!success]- **【答案】** B
>
> > [!note]- **【分析】**
> > 将 $1 + \mathrm{i}$ 代入方程中化简，利用复数相等的概念得出 $a = -2, b = 2$ 即可. 【详解】由题意可得， $\left(1 + \mathrm{i}\right)^2 + a(1 + \mathrm{i}) + b = 0$ ，化简整理得 $a + b + (2 + a)\mathrm{i} = 0$ 则 $a + b = 0, 2 + a = 0$ ，得 $a = -2, b = 2$ 则 $a^2 + b^2 = 4 + 4 = 8$
>
> > [!note]- **【解析】**
> >
> > 故选 **B**
