> [!faq]- 《专题03 复数四则运算的六大常考题型（高效培优专项训练）》官方解析
>
> > [!success]- **【答案】** (1) $z = 1 - \mathrm{i}$ (2) $\sqrt{2}$
>
> > [!note]- **【分析】**
> > （1）设 $z = m + n\mathrm{i}(m > 0, n < 0)$ ，根据复数除法运算和加减法运算化简，再根据复数的分类列出方程组，解之即可；
> >
> > （2）根据 $a \in \mathbb{R}$ ，可得等式左边化简后得复数虚部等于零，可得出 $m, n$ 关系，再根据复数的模的计算公式即可得解。
>
> > [!note]- **【解析】**
> > （1）设 $z = m + n\mathrm{i}(m > 0, n < 0)$
> >
> > 由 $z + \frac{2}{z} = a$ ，得 $m + n\mathrm{i} + \frac{2}{m + n\mathrm{i}} = a$
> >
> > 即 $m + n\mathrm{i} + \frac{2(m - n\mathrm{i})}{(m + n\mathrm{i})(m - n\mathrm{i})} = a$ ，整理得 $m + \frac{2m}{m^2 + n^2} +\left(n - \frac{2n}{m^2 + n^2}\right)\mathrm{i} = a$
> >
> > 因为 $a = 2$ ，即 $m + \frac{2m}{m^2 + n^2} +\left(n - \frac{2n}{m^2 + n^2}\right)\mathrm{i} = 2$
> >
> > 所以 $\left\{ \begin{array}{l} m + \frac{2m}{m^2 + n^2} = 2 \\ n - \frac{2n}{m^2 + n^2} = 0 \end{array} \right.$ ，解得 $\left\{ \begin{array}{l} m = 1 \\ n = -1 \end{array} \right.$ ，
> >
> > 所以 z = 1 - i ;
> >
> > (2) 由 (1) 结合 $a \in \mathbb{R}$ ,
> >
> > 可得 $n - \frac{2n}{m^2 + n^2} = 0$ ，所以 $m^2 + n^2 = 2$
> >
> > 所以 $|z| = \sqrt{m^2 + n^2} = \sqrt{2}$
