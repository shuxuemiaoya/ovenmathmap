> [!faq]- 《第七章 复数（高效培优讲义）》官方解析
>
> > [!success]- **【答案】** B
>
> > [!note]- **【分析】**
> > 根据题设有 $z = \mathrm{e}^{3\mathrm{i}} = \cos 3 + \mathrm{i}\sin 3$ ，结合对应三角函数值符号及复数的坐标表示确定点所在象限即可·
>
> > [!note]- **【解析】**
> > 由题设 $z = \mathrm{e}^{3\mathrm{i}} = \cos 3 + \mathrm{i}\sin 3$ ，而 $\frac{\pi}{2} < 3 < \pi$ ，则 $\cos 3 < 0 < \sin 3$
> >
> > 所以 $z = e^{3i}$ 对应点 $(\cos 3, \sin 3)$ 在第二象限.
> >
> > 故选 **B**
