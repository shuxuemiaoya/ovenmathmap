> [!faq]- 《第七章 复数（高效培优讲义）》官方解析
>
> > [!success]- **【答案】** 16
>
> > [!note]- **【分析】**
> > 利用棣莫弗定理可求出复数 $z$ ，继而可得 $z$ ，即可求得答案·
>
> > [!note]- **【解析】**
> > 由题意得 $z = (1 + \sqrt{3}\mathrm{i})^4 = \left[2\left(\frac{1}{2} +\frac{\sqrt{3}}{2}\mathrm{i}\right)\right]^4 = 16\left(\cos \frac{\pi}{3} +\mathrm{i}\sin \frac{\pi}{3}\right)^4$
> >
> > $$
> > = 1 6 \left[ \cos \left(4 \times \frac {\pi}{3}\right) + \mathrm{i} \sin \left(4 \times \frac {\pi}{3}\right) \right] = - 8 - 8 \sqrt {3} \mathrm{i}
> > $$
> >
> > 故 $\overline{z} = -8 + 8\sqrt{3}\mathrm{i}$ ， $\left|\overline{z}\right| = \sqrt{(-8)^2 + (8\sqrt{3})^2} = 16$
> >
> > 故答案为：16
> >
> > ## 方法技巧
> >
> > 一般地，任何一个复数 $z = a + bi$ 都可以表示成 $r(\cos \theta + i\sin \theta)$ 形式，其中 $r$ 是复数 $z$ 的模； $\theta$ 是以 $x$ 轴的非负半轴为始边，向量 $\overline{OZ}$ 所在射线（射线 $OZ$ ）为终边的角，叫做复数 $z = a + bi$ 的辐角。 $r(\cos \theta + i\sin \theta)$ 叫做复数 $z = a + bi$ 的三角表示式，简称三角形式。【变式1】已知 $i$ 为虚数单位。设 $\theta \in \left[0, \frac{\pi}{2}\right]$ ，复数 $z_0 = (3\sin \theta - \cos \theta) + (\sin \theta + \cos \theta)i$ 。
> >
> > (1)若 $z_0$ 的实部与虚部相等，求 $\theta$ 的大小；
> >
> > (2)已知 $p,q\in \mathbf{R},\theta = \frac{\pi}{2}$ ，若 $z_0$ 是方程 $x^{2} + px + q = 0$ 的一个虚根，求 $p$ 与 $q$ 的值.
> >
> > 【答案】(1) $\theta = \frac{\pi}{4}$
> >
> > (2) $p = -6, q = 10$
> >
> > 【分析】（ $^{1}$ ）由实部与虚部相等建立等量关系，结合角的范围计算可得结果；
> >
> > (2) 代入 $\theta = \frac{\pi}{2}$ 可得复数 $z_0$ ，将复数 $z_0$ 代入方程，根据方程建立新的复数的实部与虚部求解可得结果。
> >
> > 【详解】（1）若 $z_0 = (3\sin \theta -\cos \theta) + (\sin \theta +\cos \theta)\mathrm{i}$ 的实部与虚部相等，则
> >
> > $3\sin \theta -\cos \theta = \sin \theta +\cos \theta$ ，化简可得： $\sin \theta = \cos \theta$ ，即 $\tan \theta = 1$ ，
> >
> > $$
> > \therefore \theta = \frac {\pi}{4}
> > $$
> >
> > (2) $\because \theta = \frac{\pi}{2}, \therefore z_0 = 3 + \mathrm{i}$
> >
> > 代入方程可得： $\left(3 + \mathrm{i}\right)^2 +p\left(3 + \mathrm{i}\right) + q = 0$ ，即 $3p + q + 8 + (6 + p)\mathrm{i} = 0$
> >
> > 则 $\left\{ \begin{array}{l}3p + q + 8 = 0\\ 6 + p = 0 \end{array} \right.$ ，解得： $\left\{ \begin{array}{l}p = -6\\ q = 10 \end{array} \right.$
