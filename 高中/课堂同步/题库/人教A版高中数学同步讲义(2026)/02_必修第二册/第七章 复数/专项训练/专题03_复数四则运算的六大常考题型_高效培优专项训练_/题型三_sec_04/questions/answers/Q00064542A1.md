> [!faq]- 《专题03_复数四则运算的六大常考题型_高效培优专项训练_》官方解析
>
> > [!success]- **【答案】** A. $p = -2$ B. $q = 0$ C. 方程 $x^{2} + px + q = 0$ 可能只有 $z$ 这一个根 D. 设方程 $x^{2} + px + q = 0$ 的另一根为 $z_{1}$ ，则 $\left(\frac{z}{z_1}\right)^{2025} = \mathrm{i}$
>
> > [!note]- **【分析】**
> > 根据复数相等的概念解方程即可判断 AB，根据共轭复数也是对应的方程的根判断 CD.
>
> > [!note]- **【解析】**
> > 由于 $z = 1 + \mathrm{i}$ 是关于 $x$ 的方程 $x^{2} + px + q = 0$ 的根，
> >
> > 所以 $(1+\mathrm{i})^{2}+p(1+\mathrm{i})+q=0$ ，即 $p+q+(2+p)\mathrm{i}=0$
> >
> > 因为 $p, q \in \mathbf{R}$
> >
> > 所以 $\left\{ \begin{array}{l} p + q = 0 \\ 2 + p = 0 \end{array} \right.$ ，解得 $p = -2, q = 2$ ，故A正确，B错误；
> >
> > 所以关于 $x$ 的方程 $x^{2} - 2x + 2 = 0$
> >
> > 将 $\overline{z} = 1 - \mathrm{i}$ 代入上述方程得： $(1 - \mathrm{i})^2 -2(1 - \mathrm{i}) + 2 = 0$
> >
> > 即 $\bar{z}=1-i$ 也是关于 x 的方程 $x^{2}+px+q=0$ 的根，故 C 错误；
> >
> > 所以 $z_{1} = \overline{z} = 1 - \mathrm{i}$
> >
> > 则 $\left(\frac{z}{z_1}\right)^{2025} = \left(\frac{1 + \mathrm{i}}{1 - \mathrm{i}}\right)^{2025} = \left(\frac{(1 + \mathrm{i})^2}{(1 - \mathrm{i})(1 + \mathrm{i})}\right)^{2025} = \mathrm{i}^{2025} = \mathrm{i}^{4\times 506 + 1} = \mathrm{i}$ ，故D正确；
> >
> > 故选 **AD**
