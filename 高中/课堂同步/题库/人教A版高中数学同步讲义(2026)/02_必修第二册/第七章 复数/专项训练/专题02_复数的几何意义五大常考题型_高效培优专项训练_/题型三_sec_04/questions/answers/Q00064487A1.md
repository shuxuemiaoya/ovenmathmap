> [!faq]- 《专题02_复数的几何意义五大常考题型_高效培优专项训练_》官方解析
>
> > [!success]- **【答案】** A
>
> > [!note]- **【分析】**
> > 利用复数的除法将 $z = \frac{2 + m\mathrm{i}}{1 + \mathrm{i}} (m\in \mathbf{R})$ 整理为 $z = \frac{2 + m}{2} +\frac{-2 + m}{2}\mathrm{i}$ ，则 $_z$ 在复平面内对应的点为 $\left(\frac{2 + m}{2},\frac{-2 + m}{2}\right)$ ，故有 $\frac{2 + m}{2} = 3$ ，解出 $m$ 的值即可.
>
> > [!note]- **【解析】**
> > $\because z = \frac{2 + m\mathrm{i}}{1 + \mathrm{i}} = \frac{(2 + m\mathrm{i})(1 - \mathrm{i})}{(1 + \mathrm{i})(1 - \mathrm{i})} = \frac{2 - 2\mathrm{i} + m\mathrm{i} - m\mathrm{i}^2}{1 - \mathrm{i}^2} = \frac{2 - 2\mathrm{i} + m\mathrm{i} + m}{1 + 1}$ $= \frac{(2 + m) + (-2 + m)\mathrm{i}}{1 + 1} = \frac{(2 + m) + (-2 + m)\mathrm{i}}{2} = \frac{2 + m}{2} +\frac{-2 + m}{2}\mathrm{i},$
> >
> > $\therefore z = \frac{2 + m\mathrm{i}}{1 + \mathrm{i}} (m\in \mathbf{R})$ 在复平面内对应的点为 $\left(\frac{2 + m}{2},\frac{-2 + m}{2}\right)$
> >
> > $\because z=\frac{2+mi}{1+i}(m\in\mathbf{R})$ 在复平面内对应的点的横坐标为 3，
> >
> > $\therefore \frac{2 + m}{2} = 3, \therefore m = 4.$
> >
> > 故选 **A**.
