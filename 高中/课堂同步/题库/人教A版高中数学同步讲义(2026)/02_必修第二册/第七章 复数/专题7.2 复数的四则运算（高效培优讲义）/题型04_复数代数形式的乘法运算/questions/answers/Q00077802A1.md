> [!faq]- 《专题7.2 复数的四则运算（高效培优讲义）》官方解析
>
> > [!success]- **【答案】** (1) $z_{1}=1+i$ ， $z_{2}=1-i$ (2) $z_0 = -32 - 32\sqrt{3}\mathrm{i}$
>
> > [!note]- **【分析】**
> > （1）设 $z_{1}=a+bi$ ， $z_{2}=c+di$ ，根据题意列出方程组，求解即可；
> >
> > (2) 找出复数 z 在复平面内对应的点，再将其绕着原点逆时针旋转 $\frac{\pi}{3}$ 得到新的点的坐标，即可求出复数 $z_{0}$
>
> > [!note]- **【解析】**
> > （1）设 $z_{1} = a + bi$ ， $z_{2} = c + di$ ， $a,b,c,d\in \mathbb{R}$
> >
> > 则 $\left\{ \begin{array}{l} z_{1} + z_{2} = a + b\mathrm{i} + c + d\mathrm{i} = (a + c) + (b + d)\mathrm{i} = 2 \\ z_{1} \cdot z_{2} = (a + b\mathrm{i})(c + d\mathrm{i}) = (ac - bd) + (ad + bc)\mathrm{i} = 2 \end{array} \right.$
> >
> > 则 $\left\{ \begin{array}{l}a + c = ac - bd = 2\\ b + d = ad + bc = 0 \end{array} \right.$ ，得 $\left\{ \begin{array}{ll}a = c = 1\\ b = 1\\ d = -1 \end{array} \right.$ 或 $\left\{ \begin{array}{ll}a = c = 1\\ b = -1\\ d = 1 \end{array} \right.$
> >
> > 因 $z_{1}$ 的虚部比 $z_{2}$ 的虚部大，则 $a = c = 1, b = 1, d = -1$
> >
> > 则 $z_{1} = 1 + \mathrm{i}$ ， $z_{2} = 1 - \mathrm{i}$
> >
> > (2) $z = (z_{1} - z_{2})^{6} = [(1 + \mathrm{i}) - (1 - \mathrm{i})]^{6} = (2\mathrm{i})^{6} = -2^{6} = -64$ 则复数 z 在复平面内对应的点为 $(-64,0)$ ，
> > 将点 $(-64,0)$ 绕着原点逆时针旋转 $\frac{\pi}{3}$ ，得 $(-32,-32\sqrt{3})$ ，
> > 则将复数 z 逆时针旋转 $\frac{\pi}{3}$ 得到复数 $z_{0} = -32 - 32\sqrt{3}i$ .
