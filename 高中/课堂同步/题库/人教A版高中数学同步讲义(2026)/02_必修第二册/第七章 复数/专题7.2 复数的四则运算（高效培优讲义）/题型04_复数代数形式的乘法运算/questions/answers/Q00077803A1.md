> [!faq]- 《专题7.2 复数的四则运算（高效培优讲义）》官方解析
>
> > [!success]- **【答案】** C
>
> > [!note]- **【分析】**
> > 首先展开复数的乘积，利用实部为-1求出 $a$ 的值，再代入计算虚部、模、共轭复数和对应点的象限，
> >
> > 逐一验证选项即可·
>
> > [!note]- **【解析】**
> > 由 $z = (a - \mathrm{i})(3 + 2\mathrm{i}) = (3a + 2) + (2a - 3)\mathrm{i}$ 的实部为-1可得， $3a + 2 = -1$
> >
> > 解得 $a = -1$ ，则 $z = -1 - 5\mathrm{i}$
> >
> > 复数 $z = -1 - 5\mathrm{i}$ 的虚部为 $-5$ ，故A错误；
> >
> > 复数 z = -1 - 5i 的共轭复数 $\overline{z} = -1 + 5i$ ，故 B 错误；
> >
> > $\left|z\right| = \sqrt{\left(-1\right)^{2} + \left(-5\right)^{2}} = \sqrt{26}$ ，故 $C$ 正确；
> >
> > z 在复平面内对应的点为 $(-1, -5)$ ，在第三象限，故 D 错误
> >
> > 故选 **C**.
