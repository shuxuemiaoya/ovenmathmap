> [!faq]- 《专题7.2 复数的四则运算（高效培优讲义）》官方解析
>
> > [!success]- **【答案】** (1) $a = -2$ 或 $a = \frac{1}{2}$ (2)1 或 -1
>
> > [!note]- **【分析】**
> > （1）根据复数的乘法和虚数的概念进行求解即可·
> >
> > (2) 将复数 $z_{1}$ 代入方程中得到关于 a, m 的等式，然后可求得 a, m ，进而求出结果
>
> > [!note]- **【解析】**
> > （1）由题意知 $z_{1} \cdot z_{2} = (a + 2\mathrm{i})(2a + 3 + \mathrm{i}) = (2a + 3)a + a\mathrm{i} + (2a + 3)\times 2\mathrm{i} + 2\mathrm{i}^{2} = 2a^{2} + 3a - 2 + (5a + 6)\mathrm{i}$
> >
> > 又 $z_{1} \cdot z_{2}$ 为纯虚数，所以 $\left\{ \begin{array}{l} 2a^{2} + 3a - 2 = 0 \\ 5a + 6 \neq 0 \end{array} \right.$ ，解得 $a = -2$ 或 $a = \frac{1}{2}$ 。
> >
> > (2) 因为复数 $z_{1}$ 是关于 $x$ 的方程 $x^{2} + mx + 5 = 0 (m \in \mathbf{R})$ 的一个根，
> >
> > 所以 $\left(a+2\mathrm{i}\right)^{2}+m\left(a+2\mathrm{i}\right)+5=0$ ，整理得 $a^{2}+ma+1+\left(4a+2m\right)\mathrm{i}=0$
> >
> > 所以 $\left\{\begin{aligned}a^{2}+ma+1=0\\ 4a+2m=0\end{aligned}\right.$ ，解得 a=1, m=-2，或 a=-1, m=2，
> >
> > 所以 $m + a = -2 + 1 = -1$ ，或 $m + a = 2 + (-1) = 1$
