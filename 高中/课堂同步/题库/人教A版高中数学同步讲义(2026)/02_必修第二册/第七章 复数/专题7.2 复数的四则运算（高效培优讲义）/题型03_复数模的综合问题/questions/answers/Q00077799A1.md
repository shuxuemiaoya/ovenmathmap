> [!faq]- 《专题7.2 复数的四则运算（高效培优讲义）》官方解析
>
> > [!success]- **【答案】** A
>
> > [!note]- **【分析】**
> > （1）选择①，设 $z_{2}=a+bi$ ，由条件 $z_{2}\overline{z_{2}}=4$ 可得 $a^{2}+b^{2}=4$ ，由条件 $z_{2}$ 为实数，结合复数运算可得
> >
> > $\therefore a+b=0$ ，解方程可求结论；
> >
> > $$
> > \underline {{z _ {1}}}
> > $$
> >
> > 选择②，由 $z_{2}$ 为实数，结合复数运算可得 $\sin x + \cos x = 0$ ，解方程可得结论，
> >
> > 选择③，设 $z_{2} = a + bi$ ，由条件可得 $a^2 + b^2 = 4$ ，由条件 $z_{2}$ 为实数，结合复数运算可得 $\therefore a + b = 0$ ，解方程可
> >
> > $$
> > \underline {{z _ {1}}}
> > $$
> >
> > 求结论；
> >
> > (2) 选择①或③，设 $z_{2} = a + bi$ ，由条件可得 $a^{2} + b^{2} = 4$ ， $\therefore a - b = 0$ ，解方程求 $a, b$ 可得结论.
> >
> > 选择②，由条件可得 $\cos x - \sin x = 0$ ，解方程求 x 可得结论.
>
> > [!note]- **【解析】**
> > （1）选择条件①，设 $z_{2} = a + bi$ ， $\because z_{2}\overline{z_{2}} = 4$ ， $z_{2}\overline{z_{2}} = (a + bi)(a - bi) = a^{2} + b^{2} = 4$
> >
> > 又 $\because \frac{z_1}{z_2}$ 为实数， $\therefore \frac{1 - \mathrm{i}}{a + b\mathrm{i}} = \frac{(a - b) - (a + b)\mathrm{i}}{4}$ ， $\therefore a + b = 0$ ，即 $a = -b$ ， $\therefore a^2 + b^2 = (-b)^2 + b^2 = 4$ ，解得 $b = \sqrt{2}$
> >
> > 或 $b = -\sqrt{2}$
> >
> > 故 $z_{2} = \sqrt{2} -\sqrt{2}\mathrm{i}$ 或 $z_{2} = -\sqrt{2} +\sqrt{2}\mathrm{i}$
> >
> > 选择条件②，∵ $z_{1}=1-i$ ， $z_{2}=2\cos x+2i\sin x$ ， $\frac{z_{1}}{z_{2}}$ 为实数，
> >
> > $\therefore \frac{z_1}{z_2} = \frac{1 - \mathrm{i}}{2\cos x + 2i\sin x} = \frac{\cos x - \sin x - (\sin x + \cos x)\mathrm{i}}{2}$
> >
> > 即 $-\left(\sin x + \cos x\right) = 0$ ， $\sin x + \cos x = \sqrt{2}\sin \left(x + \frac{\pi}{4}\right) = 0$
> >
> > 则 $x + \frac{\pi}{4} = k\pi, k \in \mathbf{Z}$ ，解得 $x = k\pi - \frac{\pi}{4}$
> >
> > 当 $k$ 为偶数时， $z_{2} = 2\cos \left(-\frac{\pi}{4}\right) + 2i\sin \left(-\frac{\pi}{4}\right) = 2\times \frac{\sqrt{2}}{2} - 2\times \frac{\sqrt{2}}{2}\mathrm{i} = \sqrt{2} -\sqrt{2}\mathrm{i}$ ；
> >
> > 当 $k$ 为奇数时， $z_{2} = 2\cos \left(\frac{3\pi}{4}\right) + 2i\sin \left(\frac{3\pi}{4}\right) = 2\times \left(-\frac{\sqrt{2}}{2}\right) + 2\times \frac{\sqrt{2}}{2}\mathrm{i} = -\sqrt{2} +\sqrt{2}\mathrm{i}$
> >
> > 故 $z_{2} = \sqrt{2} -\sqrt{2}\mathrm{i}$ 或 $z_{2} = -\sqrt{2} +\sqrt{2}\mathrm{i}$
> >
> > 选择条件 ③， $\because \frac{z_1}{z_2}$ 为实数，∴设 $z_2 = kz_1(k \in \mathbf{R})$
> >
> > $\because \left|z_{2}\right| = 2$ 则 $\left|k\right|\cdot \sqrt{2} = 2$ ，解得 $k = \sqrt{2}$ 或 $k = -\sqrt{2}$
> >
> > 故 $z_{2} = \sqrt{2}(1 - \mathrm{i}) = \sqrt{2} -\sqrt{2}\mathrm{i}$ 或 $z_{2} = -\sqrt{2}(1 - \mathrm{i}) = -\sqrt{2} +\sqrt{2}\mathrm{i}$
> >
> > (2) 选择条件①、③，∵ $z_{1}=1-i$ ，∴ $Z_{1}(1,-1)$ ，
> >
> > 设 $z_{2}=a+bi$ ，则 $Z_{2}(a,b)$ ，
> >
> > 又∵ $\overline{OZ_{1}}\perp\overline{OZ_{2}}$ ，∴a-b=0，即a=b，
> >
> > 又∵ $\left|z_{2}\right|=2$ ，∴ $a^{2}+b^{2}=a^{2}+a^{2}=4$ ，
> >
> > 解得 $a = \sqrt{2}$ 或 $a = -\sqrt{2}$
> >
> > 故 $z_{2} = \sqrt{2} +\sqrt{2}\mathrm{i}$ 或 $z_{2} = -\sqrt{2} -\sqrt{2}\mathrm{i}$
> >
> > 选择条件②， $\because z_{1}=1-\mathrm{i}, \therefore Z_{1}(1,-1), z_{2}=2\cos x+2\mathrm{i}\sin x$
> >
> > $$
> > \therefore Z _ {2} (2 \cos x, 2 \sin x), \because O Z _ {1} \perp O Z _ {2} 1 \times 2 \cos x + (- 1) \times 2 \sin x = 0
> > $$
> >
> > ∵ $\cos x - \sin x = \sqrt{2} \cos \left( x + \frac{\pi}{4} \right) = 0$ 化简得 $\cos x - \sin x = 0$ ，又
> >
> > 则 $x + \frac{\pi}{4} = k\pi +\frac{\pi}{2},k\in \mathbf{Z}$ ，解得 $x = k\pi +\frac{\pi}{4}$
> >
> > 当 k 为偶数时， $z_{2}=2\cos\frac{\pi}{4}+2i\sin\frac{\pi}{4}=2\times\frac{\sqrt{2}}{2}+2\times\frac{\sqrt{2}}{2}i=\sqrt{2}+\sqrt{2}i$
> >
> > 当 $k$ 为奇数时， $z_{2} = 2\cos \left(\frac{5\pi}{4}\right) + 2\mathrm{i}\sin \left(\frac{5\pi}{4}\right) = 2\times \left(-\frac{\sqrt{2}}{2}\right) + 2\times \left(-\frac{\sqrt{2}}{2}\right)\mathrm{i} = -\sqrt{2} -\sqrt{2}\mathrm{i}$
> >
> > 故 $z_{2} = \sqrt{2} +\sqrt{2}\mathrm{i}$ 或 $z_{2} = -\sqrt{2} -\sqrt{2}\mathrm{i}$
