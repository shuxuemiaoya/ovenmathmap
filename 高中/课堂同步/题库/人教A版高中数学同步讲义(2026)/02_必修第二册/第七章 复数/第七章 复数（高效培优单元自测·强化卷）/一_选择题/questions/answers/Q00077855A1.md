> [!faq]- 《第七章 复数（高效培优单元自测·强化卷）》官方解析
>
> > [!success]- **【答案】** AC
>
> > [!note]- **【分析】**
> > 由已知计算出 $z = 1 - \mathrm{i}$ ，根据复数模的计算公式求解判断A，根据复数的概念判断B，根据复数的加法和乘法计算判断C，根据复数的几何意义判断D.
>
> > [!note]- **【解析】**
> > 因为 $\mathrm{i}\cdot z = 1 + \mathrm{i}$ ，所以 $z = \frac{1 + \mathrm{i}}{\mathrm{i}} = \frac{(1 + \mathrm{i})\cdot(-\mathrm{i})}{\mathrm{i}\cdot(-\mathrm{i})} = 1 - \mathrm{i}$
> >
> > 对于 A : $\left|z\right|=\sqrt{1^{2}+\left(-1\right)^{2}}=\sqrt{2}$ ，A 正确；
> >
> > 对于 B：因为复数 z = 1 - i，所以复数 z 的虚部为 -1，B 错误；
> >
> > 对于 C：因为 $z = 1 - i$ ，所以 $\overline{z} = 1 + i$ ，所以 $z + \overline{z} = (1 - i) + (1 + i) = 2$ ，
> >
> > 又 $z\cdot \overline{z} = (1 - \mathrm{i})(1 + \mathrm{i}) = 1 - \mathrm{i}^2 = 2$ ，所以 $z + \overline{z} = z\cdot \overline{z}$ ，C正确；
> >
> > 对于 $^{D}$ ：因为复数z=1-i，所以复数z在复平面内对应的点坐标为 $(1,-1)$ ，在第四象限， $^{D}$ 错误；
> >
> > 故选：AC.
> >
> > 10．任何一个复数 $z = a + b\mathrm{i}$ （其中 $a, b \in \mathbb{R}$ ）都可以表示成： $z = r(\cos \theta + \mathrm{i}\sin \theta)$ 的形式．法国数学家棣莫
> >
> > 弗发现： $z^n = \left[r(\cos \theta +\mathrm{i}\sin \theta)\right]^n = r^n (\cos n\theta +\mathrm{i}\sin n\theta)(n\in \mathbb{N}^*)$ ，我们称这个结论为棣莫弗定理．根据以上信
> >
> > 息，下列说法正确的是（ ）
> >
> > A. 当 $r=1,\theta=\frac{\pi}{3}$ 时， $\bar{z}=\frac{1}{2}-\frac{\sqrt{3}}{2}i$
> >
> > B. 若 $z = 1$ 或 $z = -\frac{1}{2} \pm \frac{\sqrt{3}}{2}\mathrm{i}$ ，则 $z^3 = 1$
> >
> > C. $\left(\frac{1}{2} -\frac{\sqrt{3}}{2}\mathrm{i}\right)^{2026} = \frac{1}{2} -\frac{\sqrt{3}}{2}\mathrm{i}$
> >
> > D. 当 $r = 1, \theta = \frac{\pi}{4}$ ，且 $n$ 为偶数时，复数 $z^n$ 为纯虚数
> >
> > 【答案】AB
> >
> > 【分析】根据棣莫弗定理，结合三角函数知识，及共轭复数，纯虚数的概念逐项验证可得答案·
> >
> > 【详解】选项A：当 $r = 1$ ， $\theta = \frac{\pi}{3}$ 时，由棣莫弗定理得， $z = \cos \frac{\pi}{3} +\mathrm{i}\sin \frac{\pi}{3} = \frac{1}{2} +\frac{\sqrt{3}}{2}\mathrm{i}$
> >
> > 所以 $\overline{z}=\frac{1}{2}-\frac{\sqrt{3}}{2}i$ ，所以选项 A 正确；
> >
> > 选项 B : z = 1 显然有 $z^{3} = 1$ ，由棣莫弗定理得， $\left(-\frac{1}{2} + \frac{\sqrt{3}}{2}\mathrm{i}\right)^{3} = \left(\cos\frac{2\pi}{3} + \mathrm{i}\sin\frac{2\pi}{3}\right)^{3} = \cos2\pi + \mathrm{i}\sin2\pi = 1$
> >
> > $\left(-\frac{1}{2} - \frac{\sqrt{3}}{2}\mathrm{i}\right)^3 = \left(\cos \frac{4\pi}{3} + \mathrm{i}\sin \frac{4\pi}{3}\right)^3 = \cos 4\pi + \mathrm{i}\sin 4\pi = 1$ ，所以选项B正确；
> >
> > 选项 C $\left(\frac{1}{2}-\frac{\sqrt{3}}{2}\mathrm{i}\right)^{2026}=\left(\cos\frac{5\pi}{3}+\mathrm{i}\sin\frac{5\pi}{3}\right)^{2026}=\cos\frac{10130\pi}{3}+\mathrm{i}\sin\frac{10130\pi}{3}$
> >
> > $= \cos \frac{2\pi}{3} + \mathrm{i}\sin \frac{2\pi}{3} = -\frac{1}{2} + \frac{\sqrt{3}}{2}\mathrm{i}$ ，所以选项C错误；
> >
> > 选项D：当 $r = 1, \theta = \frac{\pi}{4}$ 时，由棣莫弗定理得， $z^n = \left(\cos \frac{\pi}{4} + \mathrm{i}\sin \frac{\pi}{4}\right)^n = \cos \frac{n\pi}{4} + \mathrm{i}\sin \frac{n\pi}{4}$ ，
> >
> > 当 $n = 4$ 时， $z^4 = \cos \pi + \mathrm{i}\sin \pi = -1$ ，此时不为纯虚数，
> >
> > 所以当 n 为偶数时，复数 $z^{n}$ 不一定为纯虚数，所以选项 D 错误。
> >
> > 故选 **AB**
