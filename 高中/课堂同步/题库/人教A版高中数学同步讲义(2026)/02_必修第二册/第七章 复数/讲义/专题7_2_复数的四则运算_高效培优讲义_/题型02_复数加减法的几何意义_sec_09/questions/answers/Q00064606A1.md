> [!faq]- 《专题7_2_复数的四则运算_高效培优讲义_》官方解析
>
> > [!success]- **【答案】** B
>
> > [!note]- **【分析】**
> > 设复数 $z$ 在复平面内对应的点为 $Z$ ，由复数的几何意义可知点 $Z$ 的轨迹为 $x$ 轴，则问题转化为 $x$ 轴上
> >
> > 的动点 $Z$ 到定点 $(-1, -2)$ 距离的最小值，从而即可求解
>
> > [!note]- **【解析】**
> > 解：设复数 z 在复平面内对应的点为 Z，
> >
> > 因为复数 $z$ 满足 $\left|z + \mathrm{i}\right| = \left|z - \mathrm{i}\right|$ ，所以由复数的几何意义可知，点 $Z$ 到点 $(0, - 1)$ 和 $(0,1)$ 的距离相等，
> >
> > 所以在复平面内点 $Z$ 的轨迹为 $x$ 轴，
> >
> > 又 $\left|z+1+2i\right|$ 表示点Z到点 $(-1,-2)$ 的距离，
> >
> > 所以问题转化为 $x$ 轴上的动点 $Z$ 到定点 $(-1, -2)$ 距离的最小值，
> >
> > 所以 $\left|z+1+2i\right|$ 的最小值为 2，
> >
> > 故选：B.
> >
> > 题型03 复数模的综合问题
> >
> > 【典例1】设 $O$ 为坐标原点，已知向量 $\overline{OZ_1}$ ， $\overline{OZ_2}$ 分别对应复数 $z_1, z_2$ ，且 $z_1 = \frac{3}{a + 5} + (a^2 - 10)\mathrm{i}$ ， $z_2 = \frac{2}{1 - a} + (2a - 5)i$ （其中 $a \in \mathbb{R}$ ），若 $z_1 + z_2$ 可以与任意实数比较大小。
> >
> > (1)求向量 $Z_{1}Z_{2}$ 对应的复数；
> >
> > (2)设 $Z_{1}Z_{2}$ 中点为 $Z$ ，求 $\left|\overline{O} Z\right|$
> >
> > 【答案】(1) $-\frac{11}{8} + 2\mathrm{i}$
> >
> > (2) $\frac{5}{16}$
> >
> > 【分析】（1）先求出 $z_{1} + z_{2}$ 的表达式，根据 $z_{1} + z_{2}$ 为实数的条件求出a的值，进而得到 $z_{1}$ 和 $z_{2}$ ，再根据向量与
> >
> > 复数的对应关系求出向量 $Z_{1}Z_{2}$ 对应的复数；
> >
> > (2) 利用中点坐标公式求出 $Z_{1}Z_{2}$ 中点 $Z$ 对应的复数，最后根据复数的模的计算公式求出 $\left|\overline{OZ}\right|$
> >
> > 【详解】（1） $z_{1} + z_{2} = \left(\frac{3}{a + 5} +\frac{2}{1 - a}\right) + (a^{2} - 10 + 2a - 5)\mathrm{i} = \frac{a - 13}{a^{2} + 4a - 5} +(a^{2} + 2a - 15)\mathrm{i}$
> >
> > $\because z_{1}+z_{2}$ 可与任意实数比较大小， $\therefore z_{1}+z_{2}$ 为实数，
> >
> > $\therefore \left\{ \begin{array}{l} a^{2} + 4a - 5 \neq 0 \\ a^{2} + 2a - 15 = 0 \end{array} \right.$ 解得 $a = 3$ $\therefore z_{1} = \frac{3}{8} -\mathrm{i}$ ， $z_{2} = -1 + \mathrm{i}$
> >
> > ∴ 向量 $Z_{1}^{uuuu}Z_{2}$ 对应的复数为 $(-1+i)-\left(\frac{3}{8}-i\right)=-\frac{11}{8}+2i$
> >
> > (2) $Z_{1}Z_{2}$ 的中点 $Z$ 对应的复数为 $z = \frac{(-1 + \mathrm{i}) + \left(\frac{3}{8} -\mathrm{i}\right)}{2} = -\frac{5}{16},\therefore \left|\overrightarrow{OZ}\right| = \sqrt{\left(-\frac{5}{16}\right)^2 + 0^2} = \frac{5}{16}$
> >
> > ## 方法技巧
> >
> > $\left|z_{1} - z_{2}\right|$ 表示复平面内 $z_{1}$ ， $z_{2}$ 对应的两点间的距离。利用此性质，可把复数模的问题转化为复平面内两点间的距离问题，从而进行数形结合，把复数问题转化为几何图形问题求解。
