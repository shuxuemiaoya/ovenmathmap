> [!faq]- 《专题7_2_复数的四则运算_高效培优讲义_》官方解析
>
> > [!success]- **【答案】** (1)(3,4) (2)m=-6或 $^{4}$
>
> > [!note]- **【分析】**
> > （1）已知方程 $x^{2} + 2\sqrt{3} x + m = 0(m \in \mathbf{R})$ ，结合 $\operatorname{Im} x_{1} < \operatorname{Im} x_{2} < 1$ 讨论判别式的情况，得出关于 $m$ 的不
> >
> > 等式组求解·
> >
> > (2) 分 $\Delta 0$ 和 $\Delta < 0$ 两种情况讨论，当 $\Delta 0$ ，通过韦达定理得到 $x_{1} + x_{2} = -2\sqrt{3}$ ， $x_{1}x_{2} = m$ ，结合
> >
> > $\frac{1}{|x_1|} + \frac{1}{|x_2|} = 1$ 得到关于 $m$ 的方程求解；当 $\Delta < 0$ 时，两虚数根 $x_1$ 与 $x_2$ 是共轭虚数，根据 $\left|x_1\right| = \left|x_2\right|$ 求解
>
> > [!note]- **【解析】**
> > （1）已知 $x^{2} + 2\sqrt{3} x + m = 0(m\in \mathbf{R})$ ，则 $\Delta = (2\sqrt{3})^2 -4m = 12 - 4m$
> >
> > 若 $\Delta = 12 - 4m$ 0，根为实数，虚部为 $0$ ，不满足 $\mathrm{Im}x_{1} < \mathrm{Im}x_{2} < 1$
> >
> > 若 $\Delta = 12 - 4m < 0$ ，根为虚数，由求根公式得： $x = -\sqrt{3} \pm \sqrt{m - 3}\mathrm{i}$
> >
> > 由 $\operatorname{Im}x_1 < \operatorname{Im}x_2 < 1$ 可知， $\operatorname{Im}x_1 = -\sqrt{m - 3}$ ， $\operatorname{Im}x_2 = \sqrt{m - 3} < 1$ 。
> >
> > 所以 $\left\{\begin{aligned}12-4m&<0,\\ \sqrt{m-3}&<1\end{aligned}\right.\Rightarrow3<m<4$
> >
> > (2) i) 当 $\Delta \quad 0$ ，即 $m \leq 3$ 时，由韦达定理知： $x_{1} + x_{2} = -2\sqrt{3}$ ， $x_{1}x_{2} = m$ .
> >
> > 若 $m < 0$ ，两根异号， $\left|x_{1}\right| + \left|x_{2}\right| = \left|x_{1} - x_{2}\right| = \sqrt{\left(x_{1} + x_{2}\right)^{2} - 4x_{1}x_{2}} = \sqrt{12 - 4m}$
> >
> > 由 $\frac{1}{\left|x_{1}\right|}+\frac{1}{\left|x_{2}\right|}=\frac{\left|x_{1}\right|+\left|x_{2}\right|}{\left|x_{1}\right|\left|x_{2}\right|}=\frac{\left|x_{1}-x_{2}\right|}{\left|x_{1}x_{2}\right|}=\frac{\sqrt{12-4m}}{\left|m\right|}=1\Rightarrow12-4m=m^{2}\Rightarrow m=-6$ 或 m=2 (m<0，故舍去).
> >
> > 若 $0 \leq m \leq 3$ ，两根同号为负， $\left|x_{1}\right| + \left|x_{2}\right| = \left|x_{1} + x_{2}\right| = 2\sqrt{3}$
> >
> > 由 $\frac{1}{\left|x_{1}\right|}+\frac{1}{\left|x_{2}\right|}=\frac{\left|x_{1}\right|+\left|x_{2}\right|}{\left|x_{1}\right|\left|x_{2}\right|}=\frac{\left|x_{1}+x_{2}\right|}{\left|x_{1}x_{2}\right|}=\frac{2\sqrt{3}}{m}=1\Rightarrow m=2\sqrt{3}>3$ ，矛盾，舍去。
> >
> > ii）当 $\Delta < 0$ ，即 $m > 3$ 时， $x_{1}$ 与 $x_{2}$ 是共轭虚数，则 $\left|x_{2}\right| = \left|x_{1}\right|$ ，结合 $\frac{1}{\left|x_{1}\right|} + \frac{1}{\left|x_{2}\right|} = 1$ ，得 $\left|x_{1}\right| = 2$
> >
> > $\therefore 4 = \left|x_{1}\right|^{2} = x_{1}\overline{x_{1}} = x_{1}x_{2} = m$ 综上，m = -6 或 4.

> > 10．代数基本定理是数学中最重要的定理之一，其内容为：任何一元 $n(n \in \mathbf{N}^*)$ 次复系数多项式方程 $f(x) = 0$
> >
> > 至少有一个复数根·由代数基本定理可以得到：任何一元 $n(n \in \mathbf{N}^*)$ 次复系数多项式 $f(x)$ 在复数集中可以分解
> >
> > 为 $n$ 个一次因式的乘积·进而，一元 $n(n \in \mathbf{N}^*)$ 次复系数多项式方程有 $n$ 个复数根（重根按重数计）
> >
> > (1)在复数集 $\mathbf{C}$ 中解方程： $x^{4} + 2x^{3} - x = 2$
> >
> > (2)写出一个以 $-\frac{1}{2}, \frac{1}{3}, 1 + i, 2 - i$ 为根的一元六次实系数多项式方程；（不需要写证明过程）
> >
> > (3)已知一元十次实系数多项式 $f(x)$ 满足 $f(k)=\frac{1}{k+1}(k=0,1,2,\cdots,10)$ ，求 $f(11)$ 的值.
> >
> > 【答案】(1) $x_{1}=-2,\quad x_{2}=1,\quad x_{3}=\frac{-1+\sqrt{3}\mathrm{i}}{2},\quad x_{4}=\frac{-1-\sqrt{3}\mathrm{i}}{2}$
> >
> > (2) $6x^{6}-35x^{5}+83x^{4}-87x^{3}+27x^{2}+28x-10=0$ (答案不唯一)
> >
> > (3) $f(11)=\frac{1}{6}$
> >
> > 【分析】（1）将方程因式分解得 $(x+2)(x-1)(x^{2}+x+1)=0$ ，再利用一元二次方程求根公式进行求解即可·
> >
> > (2) 根据代数基本定理可写出满足条件的一元六次多项式方程，化简可得结果；
> >
> > （3）设 $g(x) = (x + 1)f(x) - 1$ ，分析 $g(x)$ 的根，根据代数基本定理表示出 $g(x)$ ，令 $x = -1$ 列方程求解 $a$ ，最后
> >
> > 【详解】（1）由题意得， $x^{4}+2x^{3}-x-2=x^{3}(x+2)-(x+2)=(x+2)(x^{3}-1)=0$
> >
> > 即 $(x + 2)(x - 1)(x^2 + x + 1) = 0$ ，解得 $x = -2$ 、 $1$ 或 $x = \frac{-1 \pm \sqrt{3}i}{2}$
> >
> > 所以方程 $x^4 + 2x^3 - x = 2$ 在复数集中的解为 $x_1 = -2, x_2 = 1, x_3 = \frac{-1 + \sqrt{3}i}{2}, x_4 = \frac{-1 - \sqrt{3}i}{2}$ .
> >
> > (2) 以 $-\frac{1}{2}, \frac{1}{3}, 1 + i, 2 - i$ 为根的一元六次实系数多项式为：
> >
> > $$
> > 6 \left(x + \frac {1}{2}\right) \left(x - \frac {1}{3}\right) [ x - (1 + \mathrm{i}) ] [ x - (1 - \mathrm{i}) ] [ x - (2 - \mathrm{i}) ] [ x - (2 + \mathrm{i}) ] = 0
> > $$
> >
> > 所以 $(2x+1)(3x-1)\left[(x-1)^{2}-\mathrm{i}^{2}\right]\left[(x-2)^{2}-\mathrm{i}^{2}\right]=0$
> >
> > 所以 $\left(2x + 1\right)\left(3x - 1\right)\left(x^{2} - 2x + 2\right)\left(x^{2} - 4x + 5\right) = 0$
> >
> > 所以 $6x^{6}-35x^{5}+83x^{4}-87x^{3}+27x^{2}+28x-10=0$
> >
> > 所以以 $-\frac{1}{2}, \frac{1}{3}, 1 + \mathrm{i}, 2 - \mathrm{i}$ 为根的一个一元六次实系数方程为：
> >
> > $$
> > 6 x ^ {6} - 3 5 x ^ {5} + 8 3 x ^ {4} - 8 7 x ^ {3} + 2 7 x ^ {2} + 2 8 x - 1 0 = 0
> > $$
> >
> > (3) 设 $g(x)=(x+1)f(x)-1$
> >
> > 因为 $f(x)$ 是一元十次实系数多项式，所以 $g(x)$ 是一元十一次实系数多项式，
> >
> > 因为 $f(k)=\frac{1}{k+1}(k=0,1,2,\cdots,10)$ ，所以 $g(k)=(k+1)f(k)-1=(k+1)\frac{1}{k+1}-1=0$
> >
> > 所以 $g(x)=0$ 有 11 个根 $0,1,2,\cdots,10$
> >
> > 根据代数基本定理，得 $g(x)=ax(x-1)(x-2)\cdots(x-10)$
> >
> > 即 $(x+1)f(x)-1=ax(x-1)(x-2)\cdots(x-10)$
> >
> > 令 x = -1 ，则 $(-1+1)f(-1)-1 = a \times (-1) \times [(-1)-1] \times [(-1)-2] \times \cdots \times [(-1)-10]$
> >
> > 所以 $-1 = -a \times (1 \times 2 \times \cdots \times 11)$ ，解得 $a = \frac{1}{1 \times 2 \times \cdots \times 11}$ .
> >
> > 令 x=11 ，得 $(11+1)f(11)-1=\frac{1}{1\times2\times\cdots\times11}\times11\times10\times\cdots\times1=1$
> >
> > 所以 $12f(11)-1=1$ ，解得 $f(11)=\frac{1}{6}$ .
