## 题型01 复数代数形式的加、减运算

【典例1】设复数 $z_{1}, z_{2}$ 满足 $\left|z_{1}\right| = \left|z_{2}\right| = 4$ ，且 $z_{1} + z_{2} = 2\sqrt{3} + 2\mathrm{i}$ ，则 $\left|z_{1} - z_{2}\right| = \underline{\quad}$ .

【答案】 $4 \sqrt{3}$

【分析】设 $z_{1} = a + bi, z_{2} = c + di$ ，根据题意列方程组即可计算 $\left|z_{1} - z_{2}\right|$ .

【详解】设 $z_{1} = a + bi, z_{2} = c + di$ ，所以 $z_{1} + z_{2} = (a + c) + (b + d)\mathrm{i} = 2\sqrt{3} +2\mathrm{i}$ ，由 $\left|z_1\right| = \left|z_2\right| = 4$

所以 $\left\{\begin{aligned}a+c&=2\sqrt{3}\\ b+d&=2\\ a^{2}+b^{2}&=16\\ c^{2}+d^{2}&=16\end{aligned}\right.\Rightarrow\left\{\begin{aligned}a^{2}+b^{2}+c^{2}+d^{2}&=32\\ 2ac+2bd&=-16\end{aligned}\right.$

因为 $z_{1} - z_{2} = (a - c) + (b - d)\mathrm{i}$

所以 $\left|z_1 - z_2\right| = \sqrt{(a - c)^2 + (b - d)^2} = \sqrt{a^2 + b^2 + c^2 + d^2 - 2ac - 2bd} = \sqrt{48} = 4\sqrt{3}$

故答案为： $4\sqrt{3}$

## 方法技巧

解决复数加减运算的思路

两个复数相加（减），就是把两个复数的实部相加（减），虚部相加（减）。复数的减法是加法的逆运算。当多个复数相加（减）时，可将这些复数的所有实部相加（减），所有虚部相加（减）。
