> [!faq]- 《专题7_2_复数的四则运算_高效培优讲义_》官方解析
>
> > [!success]- **【答案】** C
>
> > [!note]- **【分析】**
> > 用参数设出两个复数，根据复数模长的计算公式，用参数表示出所有模长，求出结果·
>
> > [!note]- **【解析】**
> > 设 $z_{1} = a + b\mathrm{i}$ ， $z_{2} = c + d\mathrm{i}$
> >
> > 因为 $\left|z_{1}\right|=\left|z_{2}\right|=\left|z_{1}-z_{2}\right|=1$ ，所以 $a^{2}+b^{2}=1, c^{2}+d^{2}=1, (a-c)^{2}+(b-d)^{2}=1$
> >
> > 由 $(a - c)^2 +(b - d)^2 = 1$ 可得 $a^2 -2ac + c^2 +b^2 -2bd + d^2 = 1$
> >
> > 带入解得 $2ac + 2bd = 1$ ，则 $\left|z_1 + z_2\right| = \sqrt{(a + c)^2 + (b + d)^2} = \sqrt{a^2 + 2ac + c^2 + b^2 + 2bd + d^2} = \sqrt{1 + 1 + 1} = \sqrt{3}$
> >
> > 故选 **C**.
