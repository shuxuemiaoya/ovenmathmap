> [!faq]- 《第七章_复数_高效培优讲义_》官方解析
>
> > [!success]- **【答案】** A. 若 $\left|z_{1}\right|=\left|z_{2}\right|$ ，则 $z_{1}=z_{2}$ B. $\left|z_{1}z_{2}\right|=\left|z_{1}\overline{z_{2}}\right|$ C. 若 $z_{1}$ 为虚数，则 $\frac{1}{z_{1}}$ 也为虚数 D. 若 $\left|z_{1}+\mathbf{i}\right|=1$ ，则 $\left|z_{1}\right|$ 的最大值为 $\sqrt{2}$
>
> > [!note]- **【分析】**
> > 特例法判断 $^{AD}$ ；根据复数的乘法运算与复数的模长公式判断 $^{B}$ ；根据复数的乘法运算，以及共轭复
> >
> > 数、虚数的定义判断 C.
>
> > [!note]- **【解析】**
> > 对于 A，因为令 $z_{1}=1$ ， $z_{2}=i$ ，则 $\left|z_{1}\right|=\left|z_{2}\right|$ ，但 $z_{1}\neq z_{2}$ ，所以 A 不正确；
> >
> > 对于 B，设 $z_{1}=a+bi$ ， $z_{2}=c+di(a,b,c,d\in\mathbb{R})$
> >
> > 则 $z_{1} \cdot z_{2} = (a + bi) \cdot (c + di) = (ac - bd) + (ad + bc)i$
> >
> > $$
> > z _ {1} \cdot \overline {{z _ {2}}} = (a + b \mathrm{i}) \cdot (c - d \mathrm{i}) = (a c + b d) + (b c - a d) \mathrm{i}
> > $$
> >
> > 所以 $\left|z_1\cdot z_2\right| = \sqrt{(ac - bd)^2 + (ad + bc)^2} = \sqrt{(ac)^2 + (bd)^2 + (ad)^2 + (bc)^2}$
> >
> > $\left|z_{1}\cdot \overline{z_{2}}\right| = \sqrt{(ac + bd)^{2} + (bc - ad)^{2}} = \sqrt{(ac)^{2} + (bd)^{2} + (ad)^{2} + (bc)^{2}}$ ，所以 $\left|z_1z_2\right| = \left|z_1\overline{z_2}\right|$ ，所以B正确；
> >
> > 对于 $C$ ，设 $z_{1} = a + b\mathrm{i}$ ， $(a,b\in \mathbb{R},b\neq 0)$ ，所以 $\frac{1}{z_1} = \frac{\overline{z_1}}{z_1\cdot\overline{z_1}} = \frac{a - bi}{a^2 + b^2} = \frac{a}{a^2 + b^2} -\frac{b}{a^2 + b^2}\mathrm{i}$ ，因为 $\frac{b}{a^2 + b^2}\neq 0$ ，所以
> >
> > $\frac{1}{z_{1}}$ 为虚数，所以 C 正确；
> >
> > 对于 D，当 $z_{1} = -2i$ 时，满足 $\left|z_{1} + i\right| = 1$ ，此时 $\left|z_{1}\right| = 2 > \sqrt{2}$ ，所以 D 不正确。
> >
> > 故选 **BC**.
