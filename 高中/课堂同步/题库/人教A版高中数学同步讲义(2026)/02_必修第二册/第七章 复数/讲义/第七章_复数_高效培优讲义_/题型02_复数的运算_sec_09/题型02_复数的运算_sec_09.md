## 题型02 复数的运算

【典例1】若 $z = \frac{1 + 3\mathrm{i}}{1 - \mathrm{i}}$ ，其中 $\mathbf{i}$ 是虚数单位，则 $z$ 的虚部为（）A.-2 B.-1 C.1 D.2

【答案】D

【分析】给复数的分子分母同乘分母的共轭复数进行化简，得到标准形式 $a + b\mathrm{i}$ 后，直接取 $b$ 作为虚部。【详解】 $z = \frac{1 + 3\mathrm{i}}{1 - \mathrm{i}} = \frac{(1 + 3\mathrm{i})(1 + \mathrm{i})}{(1 - \mathrm{i})(1 + \mathrm{i})} = \frac{-2 + 4\mathrm{i}}{2} = -1 + 2\mathrm{i}$ ，则 $z$ 的虚部为 $2$ 。

故选：D.

【典例2】若 $\frac{z}{1 + \mathrm{i}} = 1 - \mathrm{i}$ ，则 $|z| = (\quad)$ A.0 B. $\sqrt{2}$ C.2 D. $2\sqrt{2}$

【答案】C

【分析】首先化简得到 z = 2 ，再求 $\left|z\right|$ 即可·

【详解】因为 $\frac{z}{1 + \mathrm{i}} = 1 - \mathrm{i}$ ，则 $z = (1 + \mathrm{i})(1 - \mathrm{i}) = 2$ ，所以 $|z| = 2$

故选：C

## 方法技巧

设 $z_{1} = a + bi, z_{2} = c + di(a, b, c, d \in R)$ ，则
(1) $z_{1} \pm z_{2} = a \pm c + (b \pm d)i$ (2) $z_{1} \cdot z_{2} = ac - bd + (ad + bc)i$ $\frac{z_{1}}{z_{2}} = \frac{ac + bd}{c^{2} + d^{2}} + \frac{bc - ad}{c^{2} + d^{2}} i (z_{2} \neq 0)$ (3)
