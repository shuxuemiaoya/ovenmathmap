> [!faq]- 《专题7_1_复数的概念_高效培优讲义_》官方解析
>
> > [!success]- **【答案】** (1) x = -2 或 x = -1 (2) x = 3
>
> > [!note]- **【分析】**
> > （1）根据题意得到实部有意义、虚部为 $^{0}$ 即可；
> >
> > (2) 要求实部为 $^{0}$ 且虚部不为 $^{0}$ 即可，得到方程组，可得答案
>
> > [!note]- **【解析】**
> > $(1) \because z$ 为实数，
> >
> > $$
> > \therefore \left\{ \begin{array}{l} x ^ {2} - 2 x - 3 \quad 0 \\ x ^ {2} + 3 x + 2 = 0 \end{array} \right.
> > $$
> >
> > 解得 $x = -2$ 或 $x = -1$
> >
> > ∴ 当 z 为实数时，x = -2 或 x = -1；
> >
> > $^{2}$ ∵ z 为纯虚数，
> >
> > $$
> > \therefore \left\{ \begin{array}{l} x ^ {2} - 2 x - 3 = 0 \\ x ^ {2} + 3 x + 2 \neq 0 \end{array} \right.
> > $$
> >
> > 解得 x = 3 ，∴ 当 z 为纯虚数时，x = 3 .
> >
> > 9．著名数学家棣莫弗出生于法国，他提出了公式 $\left[r\left(\cos\theta+\mathrm{i}\sin\theta\right)\right]^{n}=r^{n}\left(\cos n\theta+\mathrm{i}\sin n\theta\right)$ ，其中 $r>0,n\in\mathbf{N}^{*}$ ·设
> >
> > 复数 $z = \sqrt{2}\left(\cos \frac{\pi}{4} +\mathrm{i}\sin \frac{\pi}{4}\right)$ ，若正整数 $n$ 满足 $\left|z^n\right|\leq 2025$ ，则 $n$ 最大值为（ ）A.10 B.11 C.20 D.21
> >
> > 【答案】D
> >
> > 【分析】利用题设定义得 $z^{n}=2^{\frac{n}{2}}\left(\cos\frac{n\pi}{4}+\mathrm{i}\sin\frac{n\pi}{4}\right)$ ，进而可得 $\left|z^{n}\right|=2^{\frac{n}{2}}$ ，结合条件，即可求解.
> >
> > 【详解】因为 $z = \sqrt{2}\left(\cos \frac{\pi}{4} +\mathrm{i}\sin \frac{\pi}{4}\right)$ ，则 $z^n = 2^{\frac{n}{2}}\left(\cos \frac{n\pi}{4} +\mathrm{i}\sin \frac{n\pi}{4}\right)$
> >
> > 又 $\left|\cos \frac{n\pi}{4} +\mathrm{i}\sin \frac{n\pi}{4}\right| = \sqrt{\cos^2{\frac{n\pi}{4}} + \sin^2{\frac{n\pi}{4}}} = 1$ ，所以 $\left|z^n\right| = 2^{\frac{n}{2}}$
> >
> > 由 $\left|z^{n}\right|\leq2025$ ，得到 $2^{\frac{n}{2}}\leq2025$ ，又 $2^{10}<2025<2^{11}$ ，且 $2^{10}\times\sqrt{2}=2^{\frac{21}{2}}<2025$ ，
> >
> > 则 $\frac{n}{2} \leq \frac{21}{2}$ ，所以 $n \leq 21$ ，
> >
> > 故选 **D**.
