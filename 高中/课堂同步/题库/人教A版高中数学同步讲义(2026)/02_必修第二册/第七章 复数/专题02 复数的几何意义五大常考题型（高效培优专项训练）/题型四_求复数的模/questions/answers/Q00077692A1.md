> [!faq]- 《专题02 复数的几何意义五大常考题型（高效培优专项训练）》官方解析
>
> > [!success]- **【答案】** C
>
> > [!note]- **【分析】**
> > 根据题意，转化为点 B 可以看作点 A 绕点 O 逆时针方向旋转 90 度而得到，设 B 点对应的复数为 $a + bi$ ，列出方程组，即可求解.
>
> > [!note]- **【解析】**
> > 由等腰直角三角形 AOB 的直角顶点 O 为坐标原点，点 A 和点 B 分别在第一象限和第二象限，则点 B 可以看作点 A 绕点 O 逆时针方向旋转 90 度而得到，
> >
> > 因为 A 点对应的复数为 $2 + i$ ，设 B 点对应的复数为 $a + bi$ ，其中 a < 0, b > 0，
> >
> > 则满足 $\left\{ \begin{array}{l} \sqrt{a^2 + b^2} = \sqrt{5} \\ 2a + b = 0 \end{array} \right.$ ，解得 $a = -1, b = 2$ ，所以点 $B$ 所对应的复数为 $-1 + 2i$
> >
> > 故选 **C**.
