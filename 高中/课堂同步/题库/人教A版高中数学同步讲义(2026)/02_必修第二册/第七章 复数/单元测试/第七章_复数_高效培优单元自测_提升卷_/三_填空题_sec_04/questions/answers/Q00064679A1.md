> [!faq]- 《第七章_复数_高效培优单元自测_提升卷_》官方解析
>
> > [!success]- **【答案】** (1) $-4^{(2)}\left(-\sqrt{2},\frac{1}{2}\right)$
>
> > [!note]- **【分析】**
> > （1）根据条件，利用复数的几何意义得 $z_{2} = -1 + 2\mathrm{i}$ ，再利用复数的运算，得到 $\left\{ \begin{array}{l} -a^2 -4a = 0\\ 2a^2 -2a\neq 0 \end{array} \right.$ ，即
> >
> > 可求解；
> >
> > (2) 利用复数的运算，结合条件有 $\left\{\begin{aligned}1-2a&>0\\ a^{2}&-2<0\end{aligned}\right.$ ，即可求解
>
> > [!note]- **【解析】**
> > （1）因为复数 $z_{2}$ 在复平面内对应的向量为 $\overline{OA} = (-1, 2)$ ，则 $z_{2} = -1 + 2\mathrm{i}$
> >
> > 又 $z_{1} = a^{2} + 2ai$ ，则 $z_{1}z_{2} = (a^{2} + 2ai)(-1 + 2i) = -a^{2} - 4a + (2a^{2} - 2a)\mathrm{i}$
> >
> > 由题有 $\left\{\begin{aligned}-a^{2}-4a&=0\\ 2a^{2}-2a&\neq0\end{aligned}\right.$ ，解得 a=-4，所以 a 的值为 -4。
> >
> > (2) 因为 $z_{1}i - z_{2} = (a^{2} + 2ai)i - (-1 + 2i) = 1 - 2a + (a^{2} - 2)i$
> >
> > 由题有 $\left\{\begin{aligned}1-2a&>0\\ a^{2}&-2<0\end{aligned}\right.$ ，解得 $-\sqrt{2}<a<\frac{1}{2}$ ，所以 a 的取值范围为 $\left(-\sqrt{2},\frac{1}{2}\right)$ .
