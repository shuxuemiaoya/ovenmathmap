> [!faq]- 《第七章_复数_高效培优单元自测_强化卷_》官方解析
>
> > [!success]- **【答案】** B
>
> > [!note]- **【分析】**
> > 根据相等复数建立关于 $a, b$ 的方程组，解之，结合复数的乘法运算计算即可·
>
> > [!note]- **【解析】**
> > 由条件得 $\left\{ \begin{array}{l}a + b = 1\\ b = -3 \end{array} \right.$ ，解得 $\left\{ \begin{array}{l}a = 4\\ b = -3 \end{array} \right.$
> >
> > 则 $(a + b\mathrm{i})^2 = (4 - 3\mathrm{i})^2 = 16 - 24\mathrm{i} - 9 = 7 - 24\mathrm{i}$
> >
> > 故选：B.

> > 7. 复数 $z = i - |i|$ (i 为虚数单位) 的共轭复数 $\overline{z}$ 在复平面上所对应点的坐标为 ( )
> >
> > 【答案】
> >
> > A. $(1, -1)$ B. $(-1, -1)$ C. $(-1, 1)$ D. $(1, 1)$
> >
> > 【答案】B
> >
> > 【分析】由题知 $z = -1 + i, z = -1 - i$ ，再根据复数的几何意义求解即可。
> >
> > 【详解】由题知 $z = i - |i| = -1 + i$ ， $\overline{z} = -1 - i$ ，
> >
> > 所以 $\overline{z}$ 在复平面上所对应点的坐标为 $(-1,-1)$
> >
> > 故选 **B**
