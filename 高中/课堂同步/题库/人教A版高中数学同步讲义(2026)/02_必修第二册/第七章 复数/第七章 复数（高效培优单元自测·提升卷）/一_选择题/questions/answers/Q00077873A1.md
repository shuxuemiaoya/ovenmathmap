> [!faq]- 《第七章 复数（高效培优单元自测·提升卷）》官方解析
>
> > [!success]- **【答案】** BC
>
> > [!note]- **【分析】**
> > 化简 $z_{1}z_{2}$ ，由纯虚数的定义可判断 $^{A}$ ；由相等复数和复数的模长可判断 $^{B}$ ；对于CD分别由复数的
> >
> > 几何意义求出轨迹方程，再由圆的性质求解即可·
>
> > [!note]- **【解析】**
> > 对于 $\mathsf{A}$ ，复数 $z_{1} = m + 2\mathrm{i},z_{2} = -3 - n\mathrm{i}(m,n\in \mathbb{R})$
> >
> > 则 $z_{1}z_{2}=(m+2\mathrm{i})(-3-n\mathrm{i})=-3m+2n-(mn+6)\mathrm{i}$
> >
> > 若 $z_{1}z_{2}$ 为纯虚数，则 $\left\{ \begin{array}{l} -3m + 2n = 0 \\ mn + 6 \neq 0 \end{array} \right.$ ，得 $3m = 2n$ ，故 $\mathsf{A}$ 错误；
> >
> > 对于 B，若 $z_{1} = z_{2}$ ，则 $\left\{\begin{aligned}m &=-3 \\ n &=-2\end{aligned}\right.$ ，所以 $z_{1} = -3 + 2i$ ，
> >
> > 所以 $\left|z_{1}\right|=\sqrt{\left(-3\right)^{2}+2^{2}}=\sqrt{13}$ ，故 B 正确；
> >
> > 对于 C， $z_{1} + z_{2} = (m - 3) + (2 - n)\mathrm{i}$
> >
> > 由 $\left|z_{1}+z_{2}\right|=2$ 可得： $(m-3)^{2}+(n-2)^{2}=4$
> >
> > 故点 $A(m,n)$ 在以 $C(3,2)$ 为圆心，2为半径的圆上，
> >
> > $\left|m + n\mathrm{i}\right| = \sqrt{m^2 + n^2}$ 表示圆上一点 $A(m,n)$ 到原点 $O(0,0)$ 的距离，
> >
> > 圆心 $C(3,2)$ 到原点 $O(0,0)$ 的距离为 $\sqrt{(3 - 0)^2 + (2 - 0)^2} = \sqrt{13}$
> >
> > 则 $\left|m+n\mathrm{i}\right|$ 的最大值为 $\left|CO\right|+r=\sqrt{13}+2$ ，故 C 正确；
> >
> > 对于 D，由 $\left|z_{1}+z_{2}\right|=\sqrt{2}$ 可得 $(m-3)^{2}+(n-2)^{2}=2$
> >
> > 故点 $A(m,n)$ 在以 $C(3,2)$ 为圆心， $\sqrt{2}$ 为半径的圆上，
> >
> > 设 $m = 3 + \sqrt{2} \cos \theta, n = 2 + \sqrt{2} \sin \theta, 0 \leq \theta \leq 2\pi$
> >
> > 所以 $m + n = 5 + \sqrt{2} \cos \theta + \sqrt{2} \sin \theta = 5 + 2 \sin \left( \theta + \frac{\pi}{4} \right) \in [3, 7]$
> >
> > 故 $D$ 错误·
