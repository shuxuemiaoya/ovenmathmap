> [!faq]- 《第七章 复数（高效培优单元自测·提升卷）》官方解析
>
> > [!success]- **【答案】** (1)2(2)1(3) $(-∞,2)$
>
> > [!note]- **【分析】**
> > （1）结合题意求出 $z_{2} = 1 + \mathrm{i}$ ，再利用共轭复数的定义得到 $\overline{z_2} = 1 - \mathrm{i}$ ，最后得到 $z_{2} + \overline{z_{2}}$ 即可·
> >
> > (2) 利用复数的减法得到 $z_{1}-z_{2}$ ，再结合复数的模长公式求解模长，最后利用完全平方式的性质求解最小
> >
> > 值即可·
> >
> > (3) 利用复数的乘法运算求出 $z_{1}z_{2}$ ，再结合题意建立不等式，求解参数范围即可·
>
> > [!note]- **【解析】**
> > （1）因为 $\mathrm{i}(1 - z_2) = 1$ ，所以 $1 - z_{2} = \frac{1}{\mathrm{i}} = -\mathrm{i}$
> >
> > 解得 $z_{2}=1+i$ ，则 $\overline{z_{2}}=1-i$ ，
> >
> > 故 $z_{2} + \overline{z_{2}} = (1 + \mathrm{i}) + (1 - \mathrm{i}) = 2.$
> >
> > (2) 因为 $z_{1} = 2 + a\mathrm{i}, z_{2} = 1 + \mathrm{i}$
> >
> > 所以 $z_{1}-z_{2}=(2+ai)-(1+i)=1+(a-1)i$
> >
> > 由复数的模长公式得 $\left|z_{1} - z_{2}\right| = \sqrt{1^{2} + (a - 1)^{2}}$
> >
> > 而 $(a - 1)^{2}$ 0，得到 $1^{2} + (a - 1)^{2}$ 1，即 $\sqrt{1^2 + (a - 1)^2}$ 1
> >
> > 故当 $a = 1$ 时，原式取得最小值1.
> >
> > (3) 因为 $z_{1} = 2 + a\mathrm{i}, z_{2} = 1 + \mathrm{i}$
> >
> > 所以 $z_{1}z_{2} = (2 + ai)(1 + i) = 2 + ai + 2i + ai^{2} = (2 - a) + (2 + a)i$
> >
> > 而 $z_{1}z_{2}$ 的实部大于0，则 $2 - a > 0$ ，解得 $a < 2$ ，
> >
> > 故 $a$ 的取值范围为 $(- \infty, 2)$
