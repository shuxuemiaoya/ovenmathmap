> [!faq]- 《专题01 平面向量的基本概念（高效培优期中专项训练）数学人教A版高一必修第二册》官方解析
>
> > [!success]- **【答案】** A．若a,b是共线的单位向量，则a=b B．若a=b，则 $\left|a\right|=\left|b\right|$ C．若 $a\neq b$ ，则a,b不是共线向量 D．若a//b，则一定存在实数 $\lambda$ ，使得 $a=\lambda b$
>
> > [!note]- **【解析】**
> > a,b 是共线的单位向量，则 a=b 或 a=-b，A 错误；
> >
> > 向量相等，即大小相等，方向相同， $^{B}$ 正确；
> >
> > 若 $a \neq b$ 也有可能 $a, b$ 长度不等，但方向相同或相反，即共线，C 错误；
> >
> > 若 $a / / b$ ，不一定存在实数 $\lambda$ ，使得 $a = \lambda b$ ，如 $a \neq 0$ 且 $b = 0$ 时，命题不成立，D 错误.
> >
> > 25. 给出下列命题正确的是（ ）A．若 $\left|a\right|=\left|b\right|$ ，则a=b B．若a=b，b=c，则a=c C．若 $\left|a\right|=\left|b\right|$ 且 $a//b$ ，则a=b D．若 $a//b$ ， $b//c$ ，则 $a//c$
> >
> > 【答案】B
> >
> > 【详解】对于 A，当 a 与 b 方向不同时，a = b 不成立，∴ A 错误，
> > 对于 B，若 a = b，b = c，则 a = c，∴ B 正确，
> > 对于 C，当 a 与 b 方向相反时，a = b 不成立，∴ C 错误，
> > 对于 D，当 b = 0 时，满足 a // b，b // c，但 a // c 不一定成立．所以 D 错误
> >
> > 故选 **B**．
