> [!faq]- 《专题02 平面向量的运算（高效培优期中专项训练）数学人教A版高一必修第二册》官方解析
>
> > [!success]- **【答案】** B
>
> > [!note]- **【解析】**
> > 由题意 $AB = OB - OA = b - a$ ， $DC = OC - OD = c - d$
> >
> > 因为四边形 ABCD 为平行四边形，
> >
> > 所以 $\overset{\square\square}{AB} = \overset{\square\square}{DC}$ ，即 b - a = c - d
> >
> > 整理得 $a - b + c - d = 0$
> >
> > 故选 **B**
