> [!faq]- 《专题22 解三角形精选压轴60题12类考点专练（高效培优期中专项训练）数学人教A版高一必修第二册_57404525》官方解析
>
> > [!success]- **【答案】** (1)证明见解析； (2) $\left(\frac{\sqrt{3}}{3},\frac{\sqrt{2}}{2}\right)$
>
> > [!note]- **【分析】**
> > （1）由正弦边角关系及和差角正弦公式得到 $\sin(A+C)=\sin(A-B)$ ，结合三角形内角性质即可
> >
> > 证结论；
> >
> > (2) 由题设得 $\frac{\pi}{6} < B < \frac{\pi}{4}$ , 应用正弦边角关系、倍角正弦公式有 $\frac{b}{a} = \frac{1}{2\cos B}$ , 即可求范围.
>
> > [!note]- **【解析】**
> > （1）由题设 $\left(\sin B+\sin C\right)\cos A=\sin A\left(\cos B-\cos C\right)$
> >
> > 所以 $\sin B \cos A + \sin C \cos A = \sin A \cos B - \sin A \cos C$
> >
> > 则 $\sin C\cos A + \sin A\cos C = \sin A\cos B - \sin B\cos A$ 即 $\sin (A + C) = \sin (A - B)$
> >
> > 又 $A + C = \pi - B$ ，则 $\sin (\pi - B) = \sin B = \sin (A - B)$ ，且 $A, B \in (0, \pi)$ ，
> >
> > 所以 $B = A - B \Rightarrow A = 2B$ ，得证.
> >
> > (2) 由题设 $\left\{ \begin{array}{l} 0 < A < \frac{\pi}{2} \\ 0 < B < \frac{\pi}{2} \\ \frac{\pi}{2} < A + B < \pi \end{array} \right.$ ，即 $\left\{ \begin{array}{l} 0 < 2B < \frac{\pi}{2} \\ 0 < B < \frac{\pi}{2} \\ \frac{\pi}{2} < 3B < \pi \end{array} \right.$ ，得
> >
> > 由 $\frac{b}{a}=\frac{\sin B}{\sin A}=\frac{\sin B}{\sin 2B}=\frac{1}{2\cos B}$ ，而 $\cos B\in(\frac{\sqrt{2}}{2},\frac{\sqrt{3}}{2})$ ，故 $\frac{b}{a}\in(\frac{\sqrt{3}}{3},\frac{\sqrt{2}}{2})$ .
