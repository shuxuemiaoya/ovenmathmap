> [!faq]- 《专题22 解三角形精选压轴60题12类考点专练（高效培优期中专项训练）数学人教A版高一必修第二册_57404525》官方解析
>
> > [!success]- **【答案】** A．已知平面向量 $a=\left(-2,3\right)$ ， $b=\left(1,\lambda\right)$ ，若 $_{a,b}$ 夹角为钝角，则实数 $\lambda$ 的取值范围是 $\lambda<\frac{2}{3}$ 。 B．已知 $|a|=1$ ， $|b|=2$ ，则 $b\cdot(a+2b)$ 的最小值为6。 C．若 $AB=\sqrt{3}$ ，AC=1， $B=30^{\circ}$ ，则 $\forall ABC$ 面积为 $\frac{\sqrt{3}}{2}$ 。 D．若 $\sin^{2}A+\sin^{2}B+\cos^{2}C<1$ ，则 $\forall ABC$ 为钝角三角形。
>
> > [!note]- **【分析】**
> > 对于选项 A，根据向量夹角为钝角的条件列出不等式求解；对于选项 B，利用向量数量积的运算
> >
> > 律和三角函数的性质求解；对于选项 C，根据正弦定理求出角 C，再分情况求出三角形面积；对于选项
> >
> > D，根据三角函数的平方关系和正弦定理判断三角形的形状.
>
> > [!note]- **【解析】**
> > 选项A， $a,b$ 夹角为钝角，则 $a\cdot b <   0$ 且 $a$ 与 $b$ 不共线，由 $a\cdot b = -2 + 3\lambda <  0$ ， $\therefore \lambda <  \frac{2}{3}$
> >
> > 若 a 与 b 共线，则 $-2\lambda - 3 = 0$ ，即 $\lambda = -\frac{3}{2}$ .
> >
> > 所以当 $a, b$ 夹角为钝角时，实数 $\lambda$ 的取值范围是 $\lambda < \frac{2}{3}$ 且 $\lambda \neq -\frac{3}{2}$ . 故 A 选项错误.
> >
> > 选项B， $b\cdot (a + 2b) = a\cdot b + 2b^2 = \left|a\right|\left|b\right|\cos \theta +2\left|b\right|^2 = 2\cos \theta +8$ ，当 $\cos \theta = -1$ 时， $b\cdot (a + 2b)_{\min} = 6$ ，B选项
> >
> > 正确.
> >
> > 选项 C，由题意 $c = \sqrt{3}, b = 1, B = 30^{\circ}$ ，由正弦定理 $\frac{b}{\sin B} = \frac{c}{\sin C}$ ，∴ $\sin C = \frac{\sqrt{3}}{2}$
> >
> > 又 $C \in (0^{\circ}, 180^{\circ})$ ，∴ $C = 60^{\circ}$ 或 $C = 120^{\circ}$ .
> >
> > 当 $C = 60^{\circ}$ 时， $A = 90^{\circ}$ ，此时 $S_{\triangle ABC} = \frac{1}{2} bc = \frac{\sqrt{3}}{2}$ .
> >
> > 当 $C = 120^{\circ}$ 时， $A = 30^{\circ}$ ，此时 $S_{\triangle ABC} = \frac{1}{2} bc \sin A = \frac{\sqrt{3}}{4}$ ，故 C 选项错误.
> >
> > 选项D， $\because \sin^2 A + \sin^2 B + \cos^2 C < 1$ ， $\therefore \sin^2 A + \sin^2 B < 1 - \cos^2 C = \sin^2 C$ ，由正弦定理可得： $a^2 +b^2 < c^2$
> >
> > 即 $a^2 + b^2 - c^2 < 0$
> >
> > 由余弦定理 $\cos C = \frac{a^{2} + b^{2} - c^{2}}{2ab} < 0$ ，又 $C \in (0, \pi)$ ，∴ C 为钝角，即 $\forall ABC$ 为钝角三角形，D 选项正确.
