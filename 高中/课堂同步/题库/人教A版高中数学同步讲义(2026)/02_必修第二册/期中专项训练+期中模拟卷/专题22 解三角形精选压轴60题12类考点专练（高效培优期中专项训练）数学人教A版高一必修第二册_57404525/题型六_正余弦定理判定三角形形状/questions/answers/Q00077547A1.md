> [!faq]- 《专题22 解三角形精选压轴60题12类考点专练（高效培优期中专项训练）数学人教A版高一必修第二册_57404525》官方解析
>
> > [!success]- **【答案】** C
>
> > [!note]- **【分析】**
> > 根据诱导公式和正弦定理化简为 $\sin A = 2\sin B\cos C$ ，再根据 $\sin A = \sin(B + C)$ ，结合两角和的
> >
> > 正弦公式化简，即可求解.
>
> > [!note]- **【解析】**
> > 由条件可知 $a = 2b \cos C$ ，即 $\sin A = 2 \sin B \cos C$ ，
> >
> > 因为 $\sin A = \sin (B + C) = \sin B\cos C + \cos B\sin C$
> >
> > 所以 $\sin B \cos C + \cos B \sin C = 2 \sin B \cos C$
> >
> > 整理为 $\cos B \sin C - \sin B \cos C = \sin (C - B) = 0$
> >
> > 所以 B = C ，
> >
> > 所以 VABC 是等腰三角形.
> >
> > 故选 **C**
