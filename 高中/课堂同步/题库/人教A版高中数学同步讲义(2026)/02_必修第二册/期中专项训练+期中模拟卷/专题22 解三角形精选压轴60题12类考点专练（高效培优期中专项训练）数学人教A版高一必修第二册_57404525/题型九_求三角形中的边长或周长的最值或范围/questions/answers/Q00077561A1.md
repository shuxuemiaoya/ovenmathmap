> [!faq]- 《专题22 解三角形精选压轴60题12类考点专练（高效培优期中专项训练）数学人教A版高一必修第二册_57404525》官方解析
>
> > [!success]- **【答案】** (1) $A=\frac{\pi}{3}$ (2) $\frac{\sqrt{3}}{4}$ (3) $\left(1+\sqrt{3},3\right]$
>
> > [!note]- **【分析】**
> > （1）先应用正弦定理化边为角，再应用两角和的正弦公式计算化简得出角 $A$ ；
> >
> > （2）先根据向量关系 $\overline{AD}=\frac{1}{2}\overline{AB}+\frac{1}{2}\overline{AC}$ ，左右两边平方后结合余弦定理得出bc=1，进而得出面积即可；
> >
> > (3) 应用正弦定理边角转化应用辅助角公式化简，再根据角的范围应用正弦函数的性质求解.
>
> > [!note]- **【解析】**
> > （1）由正弦定理可知 $\frac{\sin A}{\cos A} = \frac{2\sin B - \sin C}{\cos C}$ ，即 $\sin A\cos C = 2\sin B\cos A - \sin C\cos A$
> >
> > 所以 $\sin A\cos C + \sin C\cos A = \sin(A + C) = 2\sin B\cos A$
> >
> > 又 $A + B + C = \pi, \sin (A + C) = \sin (\pi - B) = \sin B$ ，所以 $\sin B = 2\sin B\cos A$
> >
> > 因为 $\sin B > 0$ ，所以 $\cos A = \frac{1}{2}$ ，因为 $A \in (0, \pi)$ ，所以 $A = \frac{\pi}{3}$ 。
> >
> > (2) 由 (1) 及余弦定理得 $a^2 = b^2 + c^2 - 2bc\cos A$ ，即 $1 = b^2 + c^2 - bc$ ，①
> >
> > 又因为 $\frac{\square\square\square}{AD}=\frac{1}{2}\frac{\square\square\square}{AB}+\frac{1}{2}\frac{\square\square\square}{AC}$ ，则 $\frac{\square\square\square}{AD}^{2}=\left(\frac{1}{2}\frac{\square\square\square}{AB}+\frac{1}{2}\frac{\square\square\square}{AC}\right)^{2}$
> >
> > 则 $AD^2 = \frac{1}{4} AB^2 +\frac{1}{4} AC^2 +\frac{1}{2} AB\cdot AC$ ，即 $\left(\frac{\sqrt{3}}{2}\right)^2 = \frac{1}{4} c^2 +\frac{1}{4} b^2 +\frac{1}{2} bc\cos \frac{\pi}{3}$
> >
> > 所以 $\frac{3}{4} = \frac{1}{4} b^2 +\frac{1}{4} c^2 +\frac{1}{4} bc$ ，②
> >
> > 由②×4-①得bc=1，
> >
> > 所以 $S_{\triangle ABC}=\frac{1}{2}bc\sin A=\frac{1}{2}\times1\times\frac{\sqrt{3}}{2}=\frac{\sqrt{3}}{4}$
> >
> > (3) 由 (1) 得 $A = \frac{\pi}{3}$ , 则 $B + C = \frac{2\pi}{3}$ , 即 $\sin C = \sin \left(\frac{2\pi}{3} - B\right) = \frac{\sqrt{3}}{2} \cos B + \frac{1}{2} \sin B$
> >
> > 由正弦定理可知 $b = \frac{a\sin B}{\sin A} = \frac{2}{\sqrt{3}}\sin B,c = \frac{a\sin C}{\sin A} = \frac{2}{\sqrt{3}}\sin C$
> >
> > 所以 $b + c = \frac{2}{\sqrt{3}} (\sin B + \sin C) = \frac{2}{\sqrt{3}} (\sin B + \frac{\sqrt{3}}{2} \cos B + \frac{1}{2} \sin B)$
> >
> > $$
> > = 2 \left(\frac {\sqrt {3}}{2} \sin B + \frac {1}{2} \cos B\right) = 2 \sin \left(B + \frac {\pi}{6}\right)
> > $$
> >
> > 因为 $\bigvee ABC$ 为锐角三角形，所以 $0 < B < \frac{\pi}{2}, 0 < \frac{2\pi}{3} - B < \frac{\pi}{2}$
> >
> > 即 $\frac{\pi}{6} < B < \frac{\pi}{2}, \frac{\pi}{3} < B + \frac{\pi}{6} < \frac{2\pi}{3}$ ，则 $\sin \left(B + \frac{\pi}{6}\right) \in \left(\frac{\sqrt{3}}{2}, 1\right]$ ，即 $2\sin \left(B + \frac{\pi}{6}\right) \in \left(\sqrt{3}, 2\right]$
> >
> > 则 $a + b + c \in (1 + \sqrt{3}, 3]$ ，故 $\forall ABC$ 的周长的取值范围为 $(1 + \sqrt{3}, 3]$
