> [!faq]- 《专题22 解三角形精选压轴60题12类考点专练（高效培优期中专项训练）数学人教A版高一必修第二册_57404525》官方解析
>
> > [!success]- **【答案】** (1) $B=\frac{\pi}{3}$ (2) $(0,3)$
>
> > [!note]- **【分析】**
> > （1）根据余弦定理，结合三角形面积公式，整理化简即可求得结果；
> >
> > (2) 根据正弦定理构造 $2a - c$ 关于 $A$ 的函数，结合三角形是锐角三角形，求得 $A$ 的范围，再求函数在对
> >
> > 应区间上的值域即可.
>
> > [!note]- **【解析】**
> > （1）因为 $\forall ABC$ 中，面积为 $S = \frac{\sqrt{3}}{4} (a^2 + c^2 - b^2)$
> >
> > 又 $S = \frac{1}{2} ac\sin B$ ， $2ac\cos B = a^2 +c^2 -b^2$ ，则 $\frac{\sqrt{3}}{4}\cdot 2ac\cos B = \frac{1}{2} ac\sin B$
> >
> > 所以 $\tan B = \sqrt{3}$ ，又 $B \in (0, \pi)$ ，所以 $B = \frac{\pi}{3}$ .
> >
> > (2) 若 $\vee ABC$ 为锐角三角形，由 (1) 知 $B = \frac{\pi}{3}$ ， $b = \sqrt{3}$ ，
> >
> > 由正弦定理得 $\frac{a}{\sin A} = \frac{c}{\sin C} = \frac{b}{\sin B} = 2$ ，所以 $2a - c = 4\sin A - 2\sin C$
> >
> > 因为 $A + C = \frac{2\pi}{3}$ ，
> >
> > 所以 $2a - c = 4\sin A - 2\sin C = 4\sin A - 2\sin\left(\frac{2\pi}{3} - A\right)$
> >
> > $= 4\sin A - 2(\sin \frac{2\pi}{3}\cos A - \cos \frac{2\pi}{3}\sin A) = 3\sin A - \sqrt{3}\cos A = 2\sqrt{3}\sin (A - \frac{\pi}{6})$
> >
> > 又 为锐角三角形，所以 $\left\{ \begin{array}{l}0 < A < \frac{\pi}{2}\\ 0 < C < \frac{\pi}{2} \end{array} \right.$ ，则， $\forall ABC$ $C = \frac{2\pi}{3} -A\quad \frac{\pi}{6} < A < \frac{\pi}{2}$
> >
> > 所以 $0 < A - \frac{\pi}{6} < \frac{\pi}{3}$ ，故 $0 < \sin(A - \frac{\pi}{6}) < \frac{\sqrt{3}}{2}$ ，
> >
> > 所以 0 < 2a - c < 3，即 $2a - c$ 取值范围是 $(0,3)$ .
