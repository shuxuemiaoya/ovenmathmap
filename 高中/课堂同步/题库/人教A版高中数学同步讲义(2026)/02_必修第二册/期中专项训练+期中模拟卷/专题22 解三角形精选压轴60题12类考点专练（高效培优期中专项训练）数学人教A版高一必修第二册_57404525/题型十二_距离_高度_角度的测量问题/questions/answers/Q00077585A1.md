> [!faq]- 《专题22 解三角形精选压轴60题12类考点专练（高效培优期中专项训练）数学人教A版高一必修第二册_57404525》官方解析
>
> > [!success]- **【答案】** $\left(0,\frac{8-4\sqrt{3}}{3}\right]$
>
> > [!note]- **【分析】**
> > 化简已知等式可得 $B=\frac{3\pi}{4}$ ，即得 $A+C=\frac{\pi}{4}$ ，设 $y=\sin2A\left(\tan^{2}C+\frac{1}{3}\right)$ ，并化简得
> >
> > $y=\frac{8}{3}-\left(\frac{4}{3}\cos^{2}C+\frac{1}{\cos^{2}C}\right)$ ，设 $t=\cos^{2}C$ ，于是 $y=\frac{8}{3}-\left(\frac{4}{3}t+\frac{1}{t}\right)$ ，再结合函数的单调性求函数的值的取值
> >
> > 范围，即可得答案.
>
> > [!note]- **【解析】**
> > 由 $\frac{a + \sqrt{2}c}{\cos A} +\frac{b}{\cos B} = 0$ ，即 $a\cos B + b\cos A + \sqrt{2} c\cos B = 0$
> >
> > 由正弦定理可得 $\sin A\cos B + \sin B\cos A + \sqrt{2}\sin C\cos B = 0$
> >
> > 即 $\sin (A + B) + \sqrt{2}\sin C\cos B = 0$ ，所以 $\sin C + \sqrt{2}\sin C\cos B = 0$
> >
> > 因为 $C \in (0, \pi), \sin C \neq 0$ ，故 $1 + \sqrt{2} \cos B = 0$ ，所以 $\cos B = -\frac{\sqrt{2}}{2}$
> >
> > 又 $B \in (0, \pi)$ ，故 $B = \frac{3\pi}{4}$ ，
> >
> > 从而 $A + C = \frac{\pi}{4}$ ，即 $A = \frac{\pi}{4} -C$ ，则 $\sin 2A = \sin \left(\frac{\pi}{2} -2C\right) = \cos 2C$
> >
> > 设 $y = \sin 2A\left(\tan^2 C + \frac{1}{3}\right)$
> >
> > $$
> > y = \cos 2 C \left(\tan^ {2} C + \frac {1}{3}\right) = \cos 2 C \left(\frac {\sin^ {2} C}{\cos^ {2} C} + \frac {1}{3}\right) = \frac {(2 \cos^ {2} C - 1) (3 - 2 \cos^ {2} C)}{3 \cos^ {2} C}
> > $$
> >
> > $$
> > = \frac {8}{3} - \left(\frac {4}{3} \cos^ {2} C + \frac {1}{\cos^ {2} C}\right)
> > $$
> >
> > 由 $A + C = \frac{\pi}{4}$ ， $A > 0$ ，得 $C\in \left(0,\frac{\pi}{4}\right)$
> >
> > 故设 $t = \cos^2 C$ ，则 $t\in \left(\frac{1}{2},1\right)$ ，于是 $y = \frac{8}{3} -\left(\frac{4}{3} t + \frac{1}{t}\right)$
> >
> > 根据双勾函数性质知：函数 $f(t) = \frac{4}{3} t + \frac{1}{t}$ 在 $\left(\frac{1}{2}, \frac{\sqrt{3}}{2}\right]$ 上单调递减，在 $\left[\frac{\sqrt{3}}{2}, 1\right)$ 上单调递增.
> >
> > 所以 $f(t)$ $f\left(\frac{\sqrt{3}}{2}\right)=\frac{4}{3}\cdot\frac{\sqrt{3}}{2}+\frac{1}{\frac{\sqrt{3}}{2}}=\frac{4\sqrt{3}}{3}$ ，当且仅当 $t=\frac{\sqrt{3}}{2}$ 时取等号。
> >
> > 而 $f\left(\frac{1}{2}\right) = \frac{4}{3} \times \frac{1}{2} + \frac{1}{\frac{1}{2}} = \frac{8}{3}, f(1) = \frac{4}{3} \times 1 + \frac{1}{1} = \frac{7}{3}$ ，即 $f(t) < \frac{8}{3}$ ，
> >
> > 故 $y = \frac{8}{3} - \left(\frac{4}{3} t + \frac{1}{t}\right)$ 的取值范围为 $\left(0, \frac{8 - 4\sqrt{3}}{3}\right]$ .
