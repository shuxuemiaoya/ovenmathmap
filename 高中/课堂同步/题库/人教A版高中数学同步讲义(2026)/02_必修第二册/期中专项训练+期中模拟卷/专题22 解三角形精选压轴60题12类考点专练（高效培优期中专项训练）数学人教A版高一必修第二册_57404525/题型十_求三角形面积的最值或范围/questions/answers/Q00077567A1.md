> [!faq]- 《专题22 解三角形精选压轴60题12类考点专练（高效培优期中专项训练）数学人教A版高一必修第二册_57404525》官方解析
>
> > [!success]- **【答案】** (1) $B=\frac{\pi}{2}$ (2) $\frac{1}{2}$
>
> > [!note]- **【分析】**
> > （1）由题意可列出方程组求出 $b=\frac{5}{3}c,a=\frac{4}{3}c$ ，即可得 $b^{2}=a^{2}+c^{2}$ ，即得答案；
> >
> > （2）法一，由已知条件等式结合余弦定理化简可得 $a = 1$ ，再由余弦定理结合基本不等式即可求得答案；
> >
> > 法二由已知条件等式结合正弦定理化简可得 $a = 1$ ，再由余弦定理结合基本不等式即可求得答案；
>
> > [!note]- **【解析】**
> > （1）因为 $\cos A = \frac{3}{5}, L = 3a$ ，所以 $\left\{ \begin{array}{l} \frac{b^2 + c^2 - a^2}{2bc} = \frac{3}{5} \\ a + b + c = 3a \end{array} \right.$
> >
> > 消去 $a$ 得 $(3b - 5c)(5b - 3c) = 0$ ，又因为 $b > c$ ，所以 $b = \frac{5}{3} c, a = \frac{4}{3} c$
> >
> > 所以 $b^{2} = a^{2} + c^{2}$ ，即 $B = \frac{\pi}{2}$
> >
> > (2) 法一：因为 $5\cos C = 5b - 3c$ ，所以 $5 \times \frac{a^2 + b^2 - c^2}{2ab} = 5b - 3c$
> >
> > 即 $\frac{a^2 + b^2 - c^2}{2ab} = b - \frac{3}{5} c$
> >
> > 又因为 $\cos A=\frac{b^{2}+c^{2}-a^{2}}{2bc}=\frac{3}{5}$ ，所以 $\frac{a^{2}+b^{2}-c^{2}}{2ab}=b-\frac{b^{2}+c^{2}-a^{2}}{2bc}c$
> >
> > 化简得 $\frac{a^2 + b^2 - c^2}{a} = a^2 + b^2 - c^2$
> >
> > 因为 $C \neq \frac{\pi}{2}$ ，即 $a^2 + b^2 - c^2 \neq 0$ ，所以 $a = 1$ 。
> >
> > 因为 $\cos A = \frac{b^{2} + c^{2} - 1}{2bc} = \frac{3}{5}$ ，所以 $\frac{6}{5}bc + 1 = b^{2} + c^{2}$ 2bc （当且仅当 $b = c = \frac{\sqrt{5}}{2}$ 时取等号），
> >
> > 所以 $bc \leq \frac{5}{4}$ ，由题意可知 $A$ 为锐角，且 $\cos A = \frac{3}{5}$ ，故 $\sin A = \frac{4}{5}$ ，
> >
> > 因此 $S = \frac{1}{2} bc\sin A = \frac{2}{5} bc\leq \frac{1}{2}$ ，即 $\mathrm{S}$ 的最大值为 $\frac{1}{2}$
> >
> > 法二：在 $\vee ABC$ 中，因为 $\cos A = \frac{3}{5}$ ，所以 $\sin A = \sqrt{1 - \cos^2 A} = \frac{4}{5}$ ，
> >
> > 由正弦定理得 $b = \frac{a\sin B}{\sin A} = \frac{5}{4} a\sin B, c = \frac{a\sin C}{\sin A} = \frac{5}{4} a\sin C$
> >
> > 因为 $5 \cos C = 5b - 3c$ ，所以 $4 \cos C = 5a \sin B - 3a \sin C$ ，
> >
> > $4\cos C = 5a\sin (A + C) - 3a\sin C = 5a\left(\frac{4}{5}\cos C + \frac{3}{5}\sin C\right) - 3a\sin C = 4a\cos C$ 即
> >
> > 又 $C \neq \frac{\pi}{2}$ ，所以 $a = 1$ 。
> >
> > 所以 $\cos A=\frac{b^{2}+c^{2}-1}{2bc}=\frac{3}{5}$ ，所以 $\frac{6}{5}bc+1=b^{2}+c^{2}$ 2bc （当且仅当 $b=c=\frac{\sqrt{5}}{2}$ 时取等号），
> >
> > 所以 $bc \leq \frac{5}{4}$ ，因此 $S = \frac{1}{2} bc \sin A = \frac{2}{5} bc \leq \frac{1}{2}$ ，即 $\mathrm{S}$ 的最大值为 $\frac{1}{2}$ 。
