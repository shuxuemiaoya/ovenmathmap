> [!faq]- 《专题22 解三角形精选压轴60题12类考点专练（高效培优期中专项训练）数学人教A版高一必修第二册_57404525》官方解析
>
> > [!success]- **【答案】** $$ B = \frac {\pi}{3} $$ B．若 b=4 且 VABC 有两个不同的解，则 $4<a<4\sqrt{2}$ C．若 $\sin C = \sqrt{2}\sin A$ ，则 b = a D．若 b=4 ，则 $\forall ABC$ 面积最大值为 $4+4\sqrt{2}$
>
> > [!note]- **【分析】**
> > 先由正弦定理及三角恒等变换求出 $B = \frac{\pi}{4}$ 判断A，应用解的个数列式计算求解判断B，应用正弦
> >
> > 定理及余弦定理计算判断 C，再结合面积公式计算判断 D 即可.
>
> > [!note]- **【解析】**
> > 因为 $\frac{\cos C}{\cos B} = \frac{\sqrt{2}a - c}{b}$ ，所以由正弦定理，得 $\sin B\cos C = \sqrt{2}\sin A\cos B - \sin C\cos B$
> >
> > 得 $\sin (B + C) = \sqrt{2}\sin A\cos B$ ，由 $\sin (B + C) = \sin A$ ，得 $\cos B = \frac{\sqrt{2}}{2}, B \in (0, \pi)$
> >
> > 对于A项， $B = \frac{\pi}{4}$ ，故A项错误；
> >
> > 对于 B 项，因为 $\bigvee ABC$ 有两解，则 $a\sin B < b < a$ ，得 $a\sin\frac{\pi}{4} < 4 < a$ ，得 $4 < a < 4\sqrt{2}$ ，故 B 项正确；
> >
> > 对于 C 项，由正弦定理得， $c=\sqrt{2}a$ ，由余弦定理得， $b^{2}=a^{2}+c^{2}-2ac\cos\frac{\pi}{4}$ ，得
> >
> > $$
> > b ^ {2} = a ^ {2} + 2 a ^ {2} - 2 \sqrt {2} a ^ {2} \times \frac {\sqrt {2}}{2} = a ^ {2}
> > $$
> >
> > 所以 b = a ，故 C 项正确；
> >
> > 对于 D 项，由余弦定理得， $b^{2}=a^{2}+c^{2}-2ac\cos\frac{\pi}{4}$ ，得 $16=a^{2}+c^{2}-\sqrt{2}ac$ $2ac-\sqrt{2}ac$
> >
> > $ac \leq \frac{16}{2 - \sqrt{2}} = 8(2 + \sqrt{2})$ ，a = c 等号成立时，
> >
> > 则VABC的面积为 $S = \frac{1}{2} ac\sin B = \frac{1}{2} ac\sin \frac{\pi}{4} = \frac{\sqrt{2}}{4} ac \leq \frac{\sqrt{2}}{4} \times 8(2 + \sqrt{2}) = 4 + 4\sqrt{2}$ ，故D项正确；
> >
> > 故选 **BCD**
