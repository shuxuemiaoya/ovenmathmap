> [!faq]- 《专题21 立体几何初步及复数精选压轴60题12类考点专练（高效培优期中专项训练）数学人教A版高一必修第二册_57404446》官方解析
>
> > [!success]- **【答案】** A．若 $\left|z\right| = 1$ ，则 $z = \pm 1$ 或 $z = \pm i$ B．若点 $Z$ 的坐标为 $(-3, 2)$ ，且 $z$ 是关于 $x$ 的方程 $x^2 + px + q = 0 (p, q \in \mathbb{R})$ 的一个根，则 $p + q = 19$ C．若 $z = \sqrt{3} - 2i$ ，则 $\overline{\overline{z}}$ 的虚部为 $-4\sqrt{3}$ D．若 $1 \leq |z - 2i| \leq \sqrt{2}$ ，则点 $Z$ 的集合所构成的图形的面积为 $\pi$
>
> > [!note]- **【分析】**
> > 举反例可判断 A；根据复数相等列出方程组可判断 B；由复数乘除法运算，共轭复数及虚部概念
> >
> > 可判断 C；利用复数的几何意义可判断 D．
>
> > [!note]- **【解析】**
> > 对于A，若 $z = \frac{1}{2} +\frac{\sqrt{3}}{2}\mathrm{i}$ ，则 $\left|z\right| = \sqrt{\left(\frac{1}{2}\right)^2 + \left(\frac{\sqrt{3}}{2}\right)^2} = 1$ ，故A错误；
> >
> > 对于 B，点 Z 的坐标为 $(-3,2)$ ，则 $z = -3 + 2i$ ，
> >
> > 因为 z 是关于 x 的方程 $x^{2} + px + q = 0 (p, q \in \mathbb{R})$ 的一个根，
> >
> > 所以 $\left(-3 + 2\mathrm{i}\right)^{2} + \left(-3 + 2\mathrm{i}\right)p + q = 0$
> >
> > 整理得 $5 + q - 3p + (2p - 12)\mathrm{i} = 0$ ，所以 $\left\{ \begin{array}{l}5 + q - 3p = 0\\ 2p - 12 = 0 \end{array} \right.$ ，解得 $\left\{ \begin{array}{l}p = 6\\ q = 13 \end{array} \right.$
> >
> > 所以 $p + q = 19$ ，故B正确；
> >
> > 对于 C，若 $z = \sqrt{3} - 2i$ ，则 $\frac{\overline{z}}{z} = \frac{\sqrt{3} + 2i}{\sqrt{3} - 2i} = \frac{\left(\sqrt{3} + 2i\right)^{2}}{\left(\sqrt{3} - 2i\right)\left(\sqrt{3} + 2i\right)} = \frac{-1 + 4\sqrt{3}i}{7} = -\frac{1}{7} + \frac{4\sqrt{3}i}{7}$
> >
> > $$
> > 4 \sqrt {3}
> > $$
> >
> > 所以 z 的虚部为 7，故 C 错误；
> >
> > 对于 D，因为 $1 \leq |z - 2i| \leq \sqrt{2}$ ，所以点 Z 的轨迹为圆心为 $(0, 2)$ ，半径分别为 1 和 $\sqrt{2}$ 围成的圆环，
> > 所以点 Z 的集合所构成的图形的面积为 $\pi \times \left(\sqrt{2}\right)^{2} - \pi \times 1^{2} = \pi$ ，故 D 正确。
