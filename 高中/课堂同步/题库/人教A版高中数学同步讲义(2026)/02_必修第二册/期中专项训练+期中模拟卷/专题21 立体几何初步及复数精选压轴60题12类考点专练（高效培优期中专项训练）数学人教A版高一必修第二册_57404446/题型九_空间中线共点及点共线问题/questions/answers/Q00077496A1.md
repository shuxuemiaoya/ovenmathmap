> > [!success]- **【答案】** (1)证明见解析 (2)证明见解析
>
> > [!note]- **【分析】**
> > （1）作出辅助线，利用平行的传递性证明 $GE // BD$ ，进而可得四点共线；
> >
> > (2) 延长 $AF, BG$ ，设它们交于一点，由已知可得 $\triangle SFG \sim \triangle SAB$ ，则 $\frac{SF}{SA} = \frac{FG}{AB} = \frac{1}{2}$ ，同理可得
> >
> > $\frac{QF}{QA} = \frac{EF}{AD} = \frac{1}{2}$ ，则 $S$ 和 $Q$ 是同一个点，所以 $AF, BG, DE$ 三条直线交于一点.
>
> > [!note]- **【解析】**
> > （1）
> >
> > ![](../../../images/questions/part-002/1456fd8445366c427fc60a398e26f94c444a556bff8b7e76e73089a5f841f195.jpg)
> >
> > 如图，取 AB, AD 的中点分别为 S, T，连接 GS, ET, ST，则 ST // BD，
> >
> > 因为四边形ABCD和四边形EFGH均为正方形， $AB = 2FG$ ，且 $AB / / FG$ ， $AD / / EF$
> >
> > 所以四边形 FGSA, FETA 均为平行四边形，即 GS // FA // ET ，GS = FA = ET ，
> >
> > 所以四边形 GETS 为平行四边形，所以 GE // TS，所以 GE // BD，
> >
> > 所以 B, D, E, G 四点共面.
> >
> > (2)
> >
> > ![](../../../images/questions/part-002/e0a11a1e565adeeaec7461d52beae0eee6b2ae871a236d21861f3c0168eb4bee.jpg)
> >
> > 延长 AF, BG ，设它们交于一点 S ，
> >
> > 因为 $AB \parallel FG$ ，且 $AB = 2FG$
> >
> > 所以 $\triangle SFG \sim \triangle SAB$ ，则 $\frac{SF}{SA} = \frac{FG}{AB} = \frac{1}{2}$ ，
> >
> > 同理，延长 AF, DE ，设它们交于一点 Q ，
> >
> > 因为四边形 $ABCD$ 和四边形 $EFGH$ 均为正方形， $AB = 2FG$
> >
> > 则 $AD = 2EF$ ，又 $AD / / EF$
> >
> > 所以 $\triangle QEF \sim \triangle QAD$ ，则 $\frac{QF}{QA} = \frac{EF}{AD} = \frac{1}{2}$
> >
> > 因此 S 和 Q 是同一个点，
> >
> > 所以 AF, BG, DE 三条直线交于一点.
