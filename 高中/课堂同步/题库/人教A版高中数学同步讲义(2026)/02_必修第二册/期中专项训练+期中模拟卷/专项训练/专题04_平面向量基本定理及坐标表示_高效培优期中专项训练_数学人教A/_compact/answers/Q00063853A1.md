> [!faq]- 《专题04_平面向量基本定理及坐标表示_高效培优期中专项训练_数学人教A》官方解析
>
> > [!success]- **【答案】** (1)证明见解析 (2) $t = \frac{1}{3}$
>
> > [!note]- **【解析】**
> > （1）因为 $AB = OB - OA = a + 2b - (a + b) = b$
> >
> > $$
> > A C = O C - O A = a + 3 b - (a + b) = 2 b
> > $$
> >
> > 所以 $AC = 2AB$ ，且直线 AB 与直线 AC 有公共点 A，
> >
> > 因此 A, B, C 三点共线·
> >
> > (2) 因为 a, b 不共线，所以向量 $\frac{1}{2}a - \frac{3}{2}b$ 为非零向量，
> >
> > 因为向量 $b - ta$ ， $\frac{1}{2} a - \frac{3}{2} b$ 共线，
> >
> > 所以存在实数 $\lambda$ ，使得 $b - ta = \lambda \left(\frac{1}{2} a - \frac{3}{2} b\right)$ ，即 $\left(t + \frac{1}{2}\lambda\right)\vec{a} = \left(\frac{3}{2}\lambda + 1\right)\vec{b}$
> >
> > 必有 $\left(t + \frac{1}{2}\lambda\right)a - \left(\frac{3}{2}\lambda + 1\right)b = 0$ ，由 $a$ ， $b$ 不共线，
> >
> > 所以 $\left\{ \begin{array}{ll}t + \frac{1}{2}\lambda = 0,\\ \frac{3}{2}\lambda +1 = 0, \end{array} \right.$ 解得 $t = \frac{1}{3}$
> >
> > 因此，当向量 $b-ta$ ， $\frac{1}{2}a-\frac{3}{2}b$ 共线时， $t=\frac{1}{3}$ .
