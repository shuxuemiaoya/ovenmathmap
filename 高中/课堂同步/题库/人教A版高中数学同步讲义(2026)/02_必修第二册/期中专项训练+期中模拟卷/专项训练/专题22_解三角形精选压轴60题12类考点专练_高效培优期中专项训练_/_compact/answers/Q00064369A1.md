> [!faq]- 《专题22_解三角形精选压轴60题12类考点专练_高效培优期中专项训练_》官方解析
>
> > [!success]- **【答案】** $\frac{3\sqrt{3}}{4}$ ，则 $a^{2}+c^{2}$ 的最小值为\_\_\_\_
>
> > [!note]- **【分析】**
> > 结合题设利用正弦定理及两角和的正弦公式化简可得 $B = \frac{\pi}{3}$ ，再结合 $\forall ABC$ 的面积为 $\frac{3\sqrt{3}}{4}$ 可得
> >
> > ac = 3，进而根据基本不等式求解即可.
>
> > [!note]- **【解析】**
> > 因为 $b\cos C + c\cos B = 2a\cos B$
> >
> > 所以，由正弦定理边化角得 $\sin B \cos C + \sin C \cos B = 2 \sin A \cos B$
> >
> > 因为 $\sin B\cos C + \sin C\cos B = \sin(B + C) = \sin(\pi - A) = \sin A$
> >
> > 所以 $2\sin A\cos B=\sin A$
> >
> > 因为 $A \in (0, \pi)$ , $\sin A \neq 0$ ，所以 $\cos B = \frac{1}{2}$ ，
> >
> > 因为 $B \in (0, \pi)$ ，所以 $B = \frac{\pi}{3}$ ，
> >
> > $$
> > 3 \sqrt {3}
> > $$
> >
> > 因为VABC的面积为4，
> >
> > 所以 $S_{\triangle ABC} = \frac{1}{2} ac \sin B = \frac{\sqrt{3}}{4} ac = \frac{3\sqrt{3}}{4}$ ，解得 ac = 3，
> >
> > 所以 $a^2 + c^2 = 2ac = 6$ ，当且仅当 $a = c = \sqrt{3}$ 时等号成立，
> >
> > 所以 $a^2 + c^2$ 的最小值为6
