> [!faq]- 《专题22_解三角形精选压轴60题12类考点专练_高效培优期中专项训练_》官方解析
>
> > [!success]- **【答案】** (1) $\frac{\pi}{2}$ (2) $2\sqrt{2}-3$ (3) $A = \frac{2\pi}{3}$ , $B = \frac{\pi}{6}$
>
> > [!note]- **【分析】**
> > （1）由 $\sin A = \cos B$ ，得到 $\cos \left(\frac{\pi}{2} -A\right) = \cos B$ ，进而求得 $A - B = \frac{\pi}{2}$
> >
> > （2）由正弦定理分别求得 $b = \tan B$ ， $c = \frac{\cos 2B}{\cos B}$ ，结合向量的数量积的运算公式和三角恒等变换，得到 $AB\cdot AC = 2\cos^2 B + \frac{1}{\cos^2 B} -3$ ，结合基本不等式，即可求解.
> >
> > (3) 因为 $\sin A = \frac{3}{2} \tan C$ ，得到 $\left(\cos A + \frac{1}{2}\right)\left(2\cos^2 A + 2\cos A - 3\right) = 0$ ，求得 $\cos A = -\frac{1}{2}$ 或 $\cos A = \frac{-1 \pm \sqrt{7}}{2}$
> >
> > 结合题意，即可求解.
>
> > [!note]- **【解析】**
> > （1）解：因为 $\sin A = \cos B$ ，所以 $\cos \left(\frac{\pi}{2} -A\right) = \cos B$
> >
> > 所以 $\frac{\pi}{2} - A = 2k\pi + B$ 或 $\frac{\pi}{2} - A = 2k\pi - B$ ， $k \in \mathbb{Z}$
> >
> > 因为 $\left\{\begin{aligned}0<A<\pi\\ 0<B<\pi\\ 0<A+B<\pi\end{aligned}\right.$ 且 $-\pi<A-B<\pi$ ，所以 $A+B=\frac{\pi}{2}$ 或 $A-B=\frac{\pi}{2}$ ，
> >
> > 由 $\vee ABC$ 为斜三角形知， $A + B = \frac{\pi}{2}$ （舍），所以 $A - B = \frac{\pi}{2}$
> >
> > (2) 解：由正弦定理： $\frac{b}{\sin B}=\frac{1}{\sin(B+\frac{\pi}{2})}=\frac{1}{\cos B}$ ，所以 $b=\tan B$ ，
> >
> > 又由 $\frac{c}{\sin C} = \frac{1}{\sin(B + \frac{\pi}{2})} = \frac{1}{\cos B}$ ，可得 $c = \frac{1}{\cos B}\cdot \sin C = \frac{1}{\cos B}\cdot \sin (\frac{\pi}{2} -2B) = \frac{\cos 2B}{\cos B}$
> >
> > 所以 $AB \cdot AC = bc \cos A = \tan B \cdot \frac{\cos 2B}{\cos B} \cdot \cos \left( B + \frac{\pi}{2} \right) = -\frac{\cos 2B \sin^{2} B}{\cos^{2} B}$
> >
> > $$
> > = - \frac {(2 \cos^ {2} B - 1) (1 - \cos^ {2} B)}{\cos^ {2} B} = \frac {2 \cos^ {4} B - 2 \cos^ {2} B + 1}{\cos^ {2} B}
> > $$
> >
> > $= 2\cos^2 B + \frac{1}{\cos^2 B} -3$ $2\sqrt{2} -3$ ，当且仅当 $\cos^2 B = \frac{\sqrt{2}}{2}$ 时，等号成立，
> >
> > 所以 $AB \cdot AC$ 的最小值为 $2\sqrt{2} - 3$ .
> >
> > (3) 解：因为 $\sin A = \frac{3}{2} \tan C$ ，所以 $\sin A = -\frac{3}{2} \tan (A + B) = -\frac{3}{2} \tan \left(2A - \frac{\pi}{2}\right) = \frac{3}{2 \tan 2A}$
> >
> > 所以 $2\sin A\sin 2A = 3\cos 2A$ ，所以 $4\sin^2 A\cos A = 3(2\cos^2 A - 1)$
> >
> > 即 $4\left(1 - \cos^2 A\right)\cos A = 3\left(2\cos^2 A - 1\right)$
> >
> > 整理得 $4\cos^{3}A + 6\cos^{2}A - 4\cos A - 3 = 0$
> >
> > 所以 $\left(\cos A + \frac{1}{2}\right)\left(2\cos^2 A + 2\cos A - 3\right) = 0$
> >
> > 所以 $\cos A = -\frac{1}{2}$ 或 $\cos A = \frac{-1 \pm \sqrt{7}}{2}$
> >
> > 因为 A 是钝角，所以 $\cos A = -\frac{1}{2}$ ，所以 $A = \frac{2\pi}{3}$ ，所以 $B = A = \frac{\pi}{2} = \frac{\pi}{6}$ 。
