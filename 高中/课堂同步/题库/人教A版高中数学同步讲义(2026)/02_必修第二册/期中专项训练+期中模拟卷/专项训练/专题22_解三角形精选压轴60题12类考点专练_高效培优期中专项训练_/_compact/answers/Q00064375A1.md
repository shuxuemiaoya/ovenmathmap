> [!faq]- 《专题22_解三角形精选压轴60题12类考点专练_高效培优期中专项训练_》官方解析
>
> > [!success]- **【答案】** BCD
>
> > [!note]- **【分析】**
> > 利用正弦定理、余弦定理边角互化逐项判断即可.
>
> > [!note]- **【解析】**
> > A，由余弦定理 $\cos C = \frac{a^{2} + b^{2} - c^{2}}{2ab} > 0$ 可得 C 为锐角，
> >
> > 但 A, B 角度不确定， $\forall ABC$ 可为钝角三角形或直角三角形，A 错误；
> >
> > B，由余弦定理 $\cos C = \frac{a^2 + b^2 - c^2}{2ab} < 0$ 可得到 $C$ 为钝角，故 $\forall ABC$ 一定是钝角三角形，B正确；
> >
> > C，因为 $\frac{a}{\cos A} = \frac{b}{\cos B} = \frac{c}{\cos C}$ ，由正弦定理可得 $\frac{\sin A}{\cos A} = \frac{\sin B}{\cos B} = \frac{\sin C}{\cos C}$ ，即 $\tan A = \tan B = \tan C$
> >
> > 又 A, B, C 均为 $\vee ABC$ 的内角，所以 A = B = C， $\vee ABC$ 一定为等边三角形，C 正确；
> >
> > D，因为 $a\cos B + b\cos A = a$ ，由正弦定理可得 $\sin A\cos B + \sin B\cos A = \sin A$ ，即 $\sin (A + B) = \sin A$
> >
> > 所以 $\sin(\pi-C)=\sin C=\sin A$ ，又 A,C 均为 $\forall ABC$ 的内角，所以 A=C ，即 $\forall ABC$ 一定为等腰三角形，D
> >
> > 正确；
> >
> > 故选 **BCD**
