> [!faq]- 《专题22_解三角形精选压轴60题12类考点专练_高效培优期中专项训练_》官方解析
>
> > [!success]- **【答案】** (1) $A=\frac{\pi}{3}$ ; (2) $\sqrt{3}$ ; (3) $S_{\triangle ABC} \in (2\sqrt{3}, 8\sqrt{3})$
>
> > [!note]- **【分析】**
> > （1）由正弦边角关系及和角正弦公式化简整理得 $\sin C = 2\sin C\cos A$ ，结合三角形内角性质求角
> >
> > 的大小；
> >
> > (2) 由余弦定理、基本不等式可得 $bc \leq 4$ ，再由 $AD = \frac{1}{2}(AB + AC)$ 及数量积的运算律求模长，即可得；
> >
> > (3) 由正弦定理及三角形面积公式、三角恒等变换可得 $S_{\triangle ABC} = \frac{6}{\tan B} + 2\sqrt{3}$ ，结合 $\frac{\pi}{6} < B < \frac{\pi}{2}$ 求范围.
>
> > [!note]- **【解析】**
> > （1）由题设及正弦边角关系知 $\sin A\cos B = (2\sin C - \sin B)\cos A$
> >
> > 所以 $\sin A\cos B + \sin B\cos A = \sin(A + B) = \sin C = 2\sin C\cos A$
> >
> > 由 $\sin C > 0$ ，则 $\cos A = \frac{1}{2}$ ，且 $0 < A < \pi$ ，可得 $A = \frac{\pi}{3}$
> >
> > (2) 由 (1) 及余弦定理有 $a^2 = b^2 + c^2 - 2bc \cos A \Rightarrow b^2 + c^2 - bc = 4$
> >
> > 所以 $b^{2} + c^{2} - bc = 4$ bc，当且仅当 $b = c = 2$ 时取等号，
> >
> > D 为 BC 边的中点，则 $AD = \frac{1}{2}(AB + AC)$ ，
> >
> > 所以 $|AD|=\frac{1}{2}\sqrt{(AB+AC)^{2}}=\frac{1}{2}\sqrt{AB^{2}+2AB\cdot AC+AC^{2}}=\frac{1}{2}\sqrt{c^{2}+2bc\cos A+b^{2}}$
> >
> > $$
> > = \frac {1}{2} \sqrt {c ^ {2} + b c + b ^ {2}} = \frac {1}{2} \sqrt {4 + 2 b c} \leq \sqrt {3}
> > $$
> >
> > 综上，AD 长的最大值 $\sqrt{3}$ ；
> >
> > (3) 由 $c = \frac{b\sin C}{\sin B} = \frac{4\sin C}{\sin B}$ , $S_{\triangle ABC} = \frac{1}{2} bc\sin A = \sqrt{3} c = \frac{4\sqrt{3}\sin C}{\sin B}$
> >
> > 由（1）易知 $C=\frac{2\pi}{3}-B$ ，则 $S_{\triangle ABC}=\frac{4\sqrt{3}\sin(\frac{2\pi}{3}-B)}{\sin B}=\frac{6\cos B+2\sqrt{3}\sin B}{\sin B}=\frac{6}{\tan B}+2\sqrt{3}$ ，
> >
> > 由 为锐角三角形，则 $\left\{ \begin{array}{l}0 < C = \frac{2\pi}{3} - B < \frac{\pi}{2}\\ 0 < B < \frac{\pi}{2} \end{array} \right.\Rightarrow \frac{\pi}{6} < B < \frac{\pi}{2}$ ，则 $\tan B > \frac{1}{\sqrt{3}}$
> >
> > 所以 $S_{\triangle ABC} \in (2\sqrt{3}, 8\sqrt{3})$
