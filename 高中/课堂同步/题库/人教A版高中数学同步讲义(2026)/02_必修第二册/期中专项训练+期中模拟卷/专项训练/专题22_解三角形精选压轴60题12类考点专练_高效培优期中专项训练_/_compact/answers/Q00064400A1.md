> [!faq]- 《专题22_解三角形精选压轴60题12类考点专练_高效培优期中专项训练_》官方解析
>
> > [!success]- **【答案】** (1) $A=\frac{\pi}{4}$ (2) $S_{\triangle ABC} = \frac{12}{5}$
>
> > [!note]- **【分析】**
> > （1）利用正弦定理边化角，结合三角恒等变换分析运算；
> >
> > (2) 利用正弦定理边化角，结合三角恒等变换化简得 $\sqrt{2}b + 2c = 4\sqrt{5}\sin(B + \varphi)$ ，进而分析最值，运算求
> >
> > 解即可.
>
> > [!note]- **【解析】**
> > （1）因为 $\frac{\sin B}{\sin A} +\sin (A - B) = \sin C$ ，即 $\sin B + \sin A\sin (A - B) = \sin A\sin C$
> >
> > 可得 $\sin B + \sin A\left(\sin A\cos B - \cos A\sin B\right) = \sin A\sin (A + B) = \sin A\left(\sin A\cos B + \cos A\sin B\right)$
> >
> > 整理得 $\sin B = 2\sin A\cos A\sin B = \sin 2A\sin B$
> >
> > 且 $B\in (0,\pi)$ ，则 $\sin B\neq 0$ ，可得 $\sin 2A = 1$
> >
> > 且 $A \in (0, \pi)$ ，则 $2A \in (0, \pi)$
> >
> > 所以 $2A=\frac{\pi}{2}$ ，解得 $A=\frac{\pi}{4}$ .
> >
> > (2) 由正弦定理可知: $\frac{a}{\sin A} = \frac{b}{\sin B} = \frac{c}{\sin C} = \frac{2}{\frac{\sqrt{2}}{2}} = 2\sqrt{2}$ , 则 $b = 2\sqrt{2} \sin B, c = 2\sqrt{2} \sin C$
> >
> > 可得 $\sqrt{2} b + 2c = 4\sin B + 4\sqrt{2}\sin C = 4\sin B + 4\sqrt{2}\sin \left(\frac{3\pi}{4} -B\right)$
> >
> > $$
> > = 4 \sin B + 4 \cos B + 4 \sin B = 8 \sin B + 4 \cos B = 4 \sqrt {5} \sin (B + \varphi)
> > $$
> >
> > 其中 $\sin \varphi = \frac{\sqrt{5}}{5},\cos \varphi = \frac{2\sqrt{5}}{5},\varphi \in \left(0,\frac{\pi}{2}\right)$
> >
> > 当 $B + \varphi = \frac{\pi}{2}$ 时， $\sqrt{2}b + 2c$ 取得最大值，
> >
> > 此时 $\sin B = \sin \left(\frac{\pi}{2} -\varphi\right) = \cos \varphi = \frac{\sqrt{5}}{5},\cos B = \cos \left(\frac{\pi}{2} -\varphi\right) = \sin \varphi = \frac{2\sqrt{5}}{5}$
> >
> > $$
> > \text {则} b = \frac {2 \sqrt {5}}{5} \times 2 \sqrt {2} = \frac {4 \sqrt {1 0}}{5}, \sin C = \sin \left(\frac {\pi}{4} + B\right) = \frac {\sqrt {2}}{2} (\sin B + \cos B) = \frac {3 \sqrt {1 0}}{1 0}
> > $$
> >
> > 所以 $S_{\triangle ABC} = \frac{1}{2} ab \sin C = \frac{1}{2} \times 2 \times \frac{4\sqrt{10}}{5} \times \frac{3\sqrt{10}}{10} = \frac{12}{5}$ .
