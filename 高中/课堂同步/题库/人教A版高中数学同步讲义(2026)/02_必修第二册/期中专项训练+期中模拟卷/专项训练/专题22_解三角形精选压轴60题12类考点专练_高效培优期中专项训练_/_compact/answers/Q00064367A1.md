> [!faq]- 《专题22_解三角形精选压轴60题12类考点专练_高效培优期中专项训练_》官方解析
>
> > [!success]- **【答案】** $-\frac{\sqrt{3}}{3}$
>
> > [!note]- **【分析】**
> > 由已知可得 $a^2 + 2c^2 = 2b^2$ ，结合余弦定理可得 $\frac{\cos C}{\cos B} = \frac{3\sin C}{\sin B}$ ，利用两角差的正切公式可得
> >
> > $\tan (C - B) = -\frac{2}{\frac{1}{\tan C} + 3\tan C}$ ，利用基本不等式可求最小值.
>
> > [!note]- **【解析】**
> > 因为 $a^{2}, b^{2}, 2c^{2}$ 成等差数列，即 $a^{2} + 2c^{2} = 2b^{2}$
> >
> > $$
> > \cos B = \frac {a ^ {2} + c ^ {2} - b ^ {2}}{2 a c} = \frac {b ^ {2} - c ^ {2}}{2 a c}, \cos C = \frac {a ^ {2} + b ^ {2} - c ^ {2}}{2 a b} = \frac {3 (b ^ {2} - c ^ {2})}{2 a b}
> > $$
> >
> > 所以 $\frac{\cos C}{\cos B} = \frac{\frac{3(b^2 - c^2)}{2ab}}{\frac{b^2 - c^2}{2ac}} = \frac{3c}{b} = \frac{3\sin C}{\sin B}$ 即，且 $\tan B = 3\tan C$ $\tan C > 0$
> >
> > $$
> > \tan (C - B) = \frac {\tan C - \tan B}{1 + \tan B \tan C} = - \frac {2 \tan C}{1 + 3 \tan^ {2} C} = - \frac {2}{\frac {1}{\tan C} + 3 \tan C} - \frac {2}{2 \sqrt {3}} = - \frac {\sqrt {3}}{3}
> > $$
> >
> > 当且仅当 $\tan C = \frac{\sqrt{3}}{3}$ 时，等号成立.
> >
> > 即 $\tan(C-B)$ 的最小值为 $-\frac{\sqrt{3}}{3}$
