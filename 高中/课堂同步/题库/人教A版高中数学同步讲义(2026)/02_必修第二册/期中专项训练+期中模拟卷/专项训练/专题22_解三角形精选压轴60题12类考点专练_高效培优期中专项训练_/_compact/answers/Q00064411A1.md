> [!faq]- 《专题22_解三角形精选压轴60题12类考点专练_高效培优期中专项训练_》官方解析
>
> > [!success]- **【答案】** A. 若 $\forall ABC$ 是直角三角形, 则 $\forall ABC$ 的内切圆面积为 $\pi$ B. 若 $\forall ABC$ 是钝角三角形, 则 $\forall ABC$ 的外接圆半径必为 $\frac{16\sqrt{15}}{15}$ C. 若 $\forall ABC$ 的一个内角是另一个内角的两倍, 则 $\forall ABC$ 的周长必为 15 D. 若 $\forall ABC$ 的周长为 $l$ , 则 $S_{\triangle ABC} = \frac{\sqrt{3}l}{36}\sqrt{l^2 - 36}$
>
> > [!note]- **【分析】**
> > 设三边为 $n, n + 1, n + 2$ ，根据勾股定理判断 A，根据余弦定理结合最大角的余弦值为负求出 $n$ 后判断 B，根据正弦定理结合三角变换分类讨论后求最小角的余弦值后可判断 C 的正误，根据面积公式结合余弦定理求出面积后可判断 D.
>
> > [!note]- **【解析】**
> > 设三边为 $n, n+1, n+2$ ，其中 n 为正整数.
> >
> > 对于A，若 $\forall ABC$ 是直角三角形，则 $n^2 + (n + 1)^2 = (n + 2)^2$
> >
> > 故 $n^{2}-2n-3=0$ ，故n=-1（舍）或n=3，
> >
> > 故直角三角形的三边分别为 $3,4,5$ ，故内切圆的半径为 $\frac{3 + 4 - 5}{2} = 1$
> >
> > 故内切圆的面积为 $\pi$ ，故 A 正确.
> >
> > 对于B，因为 $\forall ABC$ 是钝角三角形，则 $n^2 + (n + 1)^2 < (n + 2)^2$
> >
> > 故 $1 \leq n < 3$ ，故n = 1或n = 2，
> >
> > 若 n=1 ，因为 $1+2=3$ ，故三个整数 1,2,3 不是三角形三边，舍；
> >
> > 故 $n = 2$ ，故三边为 $2,3,4$ ，不妨设长为4的边所对的角为 $A$ ，
> >
> > 则 $\cos A = \frac{4 + 9 - 16}{2 \times 2 \times 3} = -\frac{1}{4}$ ，因为 A 为三角形内角，故 $\sin A = \frac{\sqrt{15}}{4}$
> >
> > 故外接圆半径为 $\frac{1}{2} \times \frac{4}{\sin A} = \frac{2}{\frac{\sqrt{15}}{4}} = \frac{8\sqrt{15}}{15}$ ，故B错误.
> >
> > 对于 C，不妨设 A, B, C 所对的边分别为 $n + 2, n + 1, n$
> >
> > 故 $\sin A + \sin C = 2\sin B$ 且 A > B > C
> >
> > 若 $A = 2C$ ，则 $\sin 2C + \sin C = 2\sin B = 2\sin (\pi -3C)$
> >
> > 故 $2\sin C\cos C + \sin C = 2\sin 3C = 2\sin 2C\cos C + 2\cos 2C\sin C$
> >
> > 所以 $2\sin C\cos C + \sin C = 4\sin C\cos^2 C + 2\cos 2C\sin C$ ，而 $\sin C > 0$
> >
> > $$
> > 2 \cos C + 1 = 4 \cos^ {2} C + 2 \cos 2 C = 8 \cos^ {2} C - 2
> > $$
> >
> > 整理得 $8\cos^2 C - 2\cos C - 3 = 0$ ，故 $\cos C = \frac{3}{4}$ 或 $\cos C = -\frac{1}{2}$
> >
> > 但 $C$ 为锐角，故 $\cos C = -\frac{1}{2}$ 不成立，
> >
> > 当 $\cos C = \frac{3}{4}$ 时，则有 $\cos C = \frac{(n + 1)^2 + (n + 2)^2 - n^2}{2\times(n + 1)(n + 2)} = \frac{n^2 + 6n + 5}{2\times(n + 1)(n + 2)} = \frac{3}{4}$
> >
> > 整理得 $n^{2}-3n-4=0$ ，故 n=-1 （舍）或 n=4 ，此时周长为 15 .
> >
> > 若 $B = 2C$ ，则同理可得 $\cos C = \frac{3}{4}$ ，由 $A = 2C$ 的分析仍然可得 $n = 4$ ，
> >
> > 此时三边分别为 $6,5,4$ ，因为 $\cos A = \frac{25 + 16 - 36}{2\times 5\times 4} = \frac{1}{8}$
> >
> > $$
> > \cos A = \cos (\pi - 3 C) = - \cos 3 C = \sin 2 C \sin C - \cos 2 C \cos C
> > $$
> >
> > $$
> > = 2 \sin^ {2} C \cos C - (2 \cos^ {2} C - 1) \cos C = 2 (1 - \cos^ {2} C) \cos C - 2 \cos^ {3} C + 2 \cos C
> > $$
> >
> > $$
> > = 3 \cos C - 4 \cos^ {3} C = \frac {9}{4} - \frac {2 7}{1 6} = \frac {9}{1 6},
> > $$
> >
> > 矛盾，故 B = 2C 不合题意.
> >
> > 若 A = 2B ，则 B 为锐角且 $\sin 2B + \sin 3B = 2\sin B$
> >
> > 同理可得 $4\cos^2 B + 2\cos B - 3 = 0$ ，故 $\cos B = \frac{-1 + \sqrt{13}}{4}$ （另一解为负，舍），
> >
> > 但 $\cos B=\frac{n^{2}+(n+2)^{2}-(n+1)^{2}}{2\times n(n+2)}=\frac{n^{2}+2n+3}{2\times n(n+2)}$ ，此时 $\cos B$ 为有理数，
> >
> > 矛盾，故 $A = 2B$ 也不合题意，
> >
> > 故 C 正确；
> >
> > 对于 D，如 C 所设，A, B, C 所对的边分别为 $n + 2, n + 1, n$
> >
> > 则 $S_{\triangle ABC} = \frac{1}{2}(n + 1)(n + 2)\sin C = \frac{1}{2}(n + 1)(n + 2)\sqrt{1 - \cos^2C}$
> >
> > $$
> > = \frac {1}{2} (n + 1) (n + 2) \sqrt {1 - \left[ \frac {(n + 1) ^ {2} + (n + 2) ^ {2} - n ^ {2}}{2 (n + 1) (n + 2)} \right] ^ {2}}
> > $$
> >
> > $$
> > = \frac {1}{4} \sqrt {4 [ (n + 1) (n + 2) ] ^ {2} - (n ^ {2} + 6 n + 5) ^ {2}}
> > $$
> >
> > $$
> > = \frac {1}{4} \sqrt {4 [ (n + 1) (n + 2) ] ^ {2} - [ (n + 1) (n + 5) ] ^ {2}}
> > $$
> >
> > 而 $n + n + 1 + n + 2 = l$ ，故 $n = \frac{l}{3} -1$
> >
> > 故 $S_{\triangle ABC} = \frac{1}{4}\sqrt{4\times\left[\frac{l}{3}\left(\frac{l}{3} + 1\right)\right]^2 - \left[\frac{l}{3}\left(\frac{l}{3} + 4\right)\right]^2} = \frac{\sqrt{3}l}{36}\sqrt{l^2 - 36}$
> >
> > 故 D 正确.
