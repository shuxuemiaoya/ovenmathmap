> [!faq]- 《专题22_解三角形精选压轴60题12类考点专练_高效培优期中专项训练_》官方解析
>
> > [!success]- **【答案】** D
>
> > [!note]- **【分析】**
> > 利用正弦定理和余弦定理，以及三角形的边、角的关系定理逐一判断即可.
>
> > [!note]- **【解析】**
> > 对于 A，由 $\frac{a}{\cos A} = \frac{b}{\cos B}$ 和正弦定理，可得 $\frac{\sin A}{\cos A} = \frac{\sin B}{\cos B}$ ，即 $\tan A = \tan B$ ，
> >
> > 因 $0 < A, B < \pi$ ， $0 < A + B < \pi$ ，故 $A = B$ ，同理可得 $B = C$
> >
> > 故可得VABC为等边三角形，即A正确；
> >
> > 对于B，由 $\left(a + b + c\right)\left(a + b - c\right) = 3ab$ 可得 $(a + b)^2 -c^2 = 3ab$ ，即 $a^2 +b^2 -c^2 = ab$
> >
> > 由余弦定理， $\cos C = \frac{a^2 + b^2 - c^2}{2ab} = \frac{1}{2}$ ，因 $0^{\circ} <   C <   180^{\circ}$ ，故 $\angle C = 60^{\circ}$ ，即B正确；
> >
> > 对于 C，因 c < b < a，则最小内角为角 C，
> >
> > 由余弦定理， $\cos C = \frac{a^2 + b^2 - c^2}{2ab} = \frac{49 + 48 - 13}{2 \times 7 \times 4\sqrt{3}} = \frac{\sqrt{3}}{2}$
> >
> > 因 $0^{\circ} < C < 180^{\circ}$ ，则 $C = 30^{\circ}$ ，故C正确；
> >
> > 对于 D，由正弦定理， $\sin B=\frac{b\sin A}{a}=\frac{4\sin60^{\circ}}{5}=\frac{2\sqrt{3}}{5}$
> >
> > 因为 b < a，则 $B < A = 60^{\circ}$ ，故角 B 只有一解。即 D 错误。
> >
> > 故选 **D**.
