> [!faq]- 《专题22_解三角形精选压轴60题12类考点专练_高效培优期中专项训练_》官方解析
>
> > [!success]- **【答案】** (1) $\frac{\sqrt{3}}{2}$ (2)12 (3) $(2\sqrt{3}, 3\sqrt{3}]$
>
> > [!note]- **【分析】**
> > （1）由射影定理直接可得所求角的余弦值，进而可得正弦值；
> >
> > (2) 先由余弦定理及基本不等式可得 $c \quad 4$ ，进而可得周长的最小值；
> >
> > (3) 将三角形的面积表示成关于角 $A$ 的三角函数，用函数的性质可得面积的取值范围.
>
> > [!note]- **【解析】**
> > （1）因为在三角形中，由射影定理 $a = c\cos B + b\cos C$ 代入 $a = c\cos B + \frac{1}{2} b$
> >
> > 得 $b \cos C = \frac{1}{2} b$ ，即 $\cos C = \frac{1}{2}$ ，因为 $0 < C < \pi$ ，所以 $\sin C = \sqrt{1 - \cos^{2} C} = \frac{\sqrt{3}}{2}$ .
> >
> > (2) 在三角形中，由 (1) 知 $\cos C = \frac{1}{2}$ ，
> >
> > 由余弦定理得 $c^2 = a^2 + b^2 - 2ab\cos C = a^2 + b^2 - ab = (a + b)^2 - 3ab = 64 - 3ab$
> >
> > 又因为 $a + b = 8$ ，由基本不等式 $ab \leq \left(\frac{a + b}{2}\right)^2 = 16$ ，当且仅当 $a = b = 4$ 时等号成立，
> >
> > 所以 $c^2 = 64 - 3ab$ $64 - 3\times 16 = 16$ ，即 $c$ 4，所以周长 $a + b + c = 8 + c$ $8 + 4 = 12$
> >
> > 因此 $\vee ABC$ 周长的最小值为12.
> >
> > （3）因为 $\forall ABC$ 是锐角三角形，由（1）知 $\cos C = \frac{1}{2}$ ，且 $0 < C < \pi$ ，得 $C = \frac{\pi}{3}$ ， $B = \frac{2\pi}{3} - A$ ，所以 $\left\{ \begin{array}{l} 0 < A < \frac{\pi}{2} \\ 0 < \frac{2\pi}{3} - A < \frac{\pi}{2} \\ \frac{\pi}{6} < A < \frac{\pi}{2} \end{array} \right.$ ，解得
> >
> > 又由正弦定理得 $\frac{a}{\sin A} = \frac{b}{\sin B} = \frac{c}{\sin C} = \frac{2\sqrt{3}}{\frac{\sqrt{3}}{2}} = 4$ ，所以 $a = 4\sin A, b = 4\sin B = 4\sin \left(\frac{2\pi}{3} - A\right)$
> >
> > $$
> > a b = 1 6 \sin A \sin \left(\frac {2 \pi}{3} - A\right) = 1 6 \sin A \left(\frac {\sqrt {3}}{2} \cos A + \frac {1}{2} \sin A\right) = 8 \sqrt {3} \sin A \cos A + 8 \sin^ {2} A
> > $$
> >
> > $$
> > = 4 \sqrt {3} \sin 2 A + 4 (1 - \cos 2 A) = 8 \left(\frac {\sqrt {3}}{2} \sin 2 A - \frac {1}{2} \cos 2 A\right) + 4 = 8 \sin \left(2 A - \frac {\pi}{6}\right) + 4,
> > $$
> >
> > 因为 $A \in \left( \frac{\pi}{6}, \frac{\pi}{2} \right)$ ，所以 $2A - \frac{\pi}{6} \in \left( \frac{\pi}{6}, \frac{5\pi}{6} \right)$ ， $\sin \left( 2A - \frac{\pi}{6} \right) \in (\frac{1}{2}, 1]$ ，因此 $ab \in (8, 12]$ .
> >
> > 所以 $\forall ABC$ 面积 $S = \frac{1}{2} ab\sin C = \frac{\sqrt{3}}{4} ab\in (2\sqrt{3},3\sqrt{3} ]$
