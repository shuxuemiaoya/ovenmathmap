> [!faq]- 《专题22_解三角形精选压轴60题12类考点专练_高效培优期中专项训练_》官方解析
>
> > [!success]- **【答案】** C
>
> > [!note]- **【分析】**
> > 根据直角三角形中的三角函数关系可用 $\angle POC$ 表示出 $BC, OB, OA, AB$ 的长度，知A和B正误；将 $\triangle OBC$ 面积和矩形ABCD面积表示成关于 $\alpha$ 的函数的形式，将问题转化为三角函数最值的求解问题，
> >
> > 知 C 和 D 正误.
>
> > [!note]- **【解析】**
> > 对于 A，当 $\angle POC = \frac{\pi}{6}$ 时， $BC = AD = OC \cdot \sin \angle POC = \frac{1}{2}$ ， $OB = OC \cdot \cos \angle POC = \frac{\sqrt{3}}{2}$
> >
> > 又 $OA = \frac{AD}{\tan \angle DOA} = \frac{\frac{1}{2}}{\sqrt{3}} = \frac{\sqrt{3}}{6}$ ，∴ AB = OB - OA = $\frac{\sqrt{3}}{2} - \frac{\sqrt{3}}{6} = \frac{\sqrt{3}}{3}$ ，
> >
> > ∴ 四边形 ABCD 不是正方形，A 错误；
> >
> > 对于 B，当 $\angle POC = \alpha$ 时， $AD = BC = OC \cdot \sin \angle POC = \sin \alpha$ ， $OB = OC \cdot \cos \angle POC = \cos \alpha$ ，
> >
> > $$
> > O A = \frac {A D}{\tan \angle D O A} = \frac {\sin \alpha}{\sqrt {3}} = \frac {\sqrt {3}}{3} \sin \alpha
> > $$
> >
> > $\therefore AB=OB-OA=\cos\alpha-\frac{\sqrt{3}}{3}\sin\alpha$ ，B错误；
> >
> > 对于 C，设 $\angle POC = \alpha \left(0 \leq \alpha \leq \frac{\pi}{3}\right)$
> >
> > 由 B 知： $OB = \cos\alpha$ ， $BC = \sin\alpha$ ， $\therefore S_{\triangle OBC} = \frac{1}{2}OB \cdot BC = \frac{1}{2}\cos\alpha \sin\alpha = \frac{1}{4}\sin 2\alpha$
> >
> > $$
> > \because 0 \leq \alpha \leq \frac {\pi}{3}, \therefore 0 \leq 2 \alpha \leq \frac {2 \pi}{3}
> > $$
> >
> > ∴ 当 $2\alpha = \frac{\pi}{2}$ ，即 $\alpha = \frac{\pi}{4}$ 时， $S_{\triangle OBC}$ 取得最大值 $\frac{1}{4}$ ，C 正确；
> >
> > 对于D，设 $\angle POC = \alpha \left(0\leq \alpha \leq \frac{\pi}{3}\right)$
> >
> > 由B知： $BC = \sin \alpha$ ， $AB = \cos \alpha -\frac{\sqrt{3}}{3}\sin \alpha$
> >
> > ∴ 矩形 ABCD 的面积 $S = AB \cdot BC = \cos \alpha \sin \alpha - \frac{\sqrt{3}}{3} \sin^{2} \alpha = \frac{1}{2} \sin 2\alpha - \frac{\sqrt{3}}{6} (1 - \cos 2\alpha)$
> >
> > $$
> > = \frac {1}{2} \sin 2 \alpha + \frac {\sqrt {3}}{6} \cos 2 \alpha - \frac {\sqrt {3}}{6} = \frac {\sqrt {3}}{3} \sin \left(2 \alpha + \frac {\pi}{6}\right) - \frac {\sqrt {3}}{6}
> > $$
> >
> > $$
> > \because 0 \leq \alpha \leq \frac {\pi}{3}, \therefore \frac {\pi}{6} \leq 2 \alpha + \frac {\pi}{6} \leq \frac {5 \pi}{6}
> > $$
> >
> > ∴ 当 $2\alpha + \frac{\pi}{6} = \frac{\pi}{2}$ ，即 $\alpha = \frac{\pi}{6}$ 时，矩形 ABCD 的面积 S 取得最大值 $\frac{\sqrt{3}}{6}$ ，D 错误.
> >
> > 故选 **C**.
