> [!faq]- 《专题22_解三角形精选压轴60题12类考点专练_高效培优期中专项训练_》官方解析
>
> > [!success]- **【答案】** (1) b = 5， $S_{\triangle ABC} = \frac{15\sqrt{7}}{4}$ ; (2)证明见解析.
>
> > [!note]- **【分析】**
> > （1）由正弦值得 $\cos C = \frac{3}{4}$ ，再应用余弦定理列方程求得 $b = 5$ ，最后应用三角形面积公式求面
> >
> > 积；
> >
> > （2）由（1）及二倍角余弦公式得 $\cos 2C = \frac{1}{8}$ ，再应用余弦定理求得 $\cos A = \frac{1}{8}$ ，结合三角形内角的性质即
> >
> > 可证.
>
> > [!note]- **【解析】**
> > （1）在 $\forall ABC$ 中 $b - c = 1 \Rightarrow b = c + 1 > c$ ，所以 $C$ 是锐角，.
> >
> > 由 $\sin C = \frac{\sqrt{7}}{4}$ ，可得 $\cos C = \frac{3}{4}$ ，而 $c^2 = a^2 + b^2 - 2ab\cos C$
> >
> > 所以 $c^2 = 36 + (c + 1)^2 - 9(c + 1)$
> >
> > 可得 c = 4 ，则 b = 5 ，
> >
> > 故 $S_{\triangle ABC} = \frac{1}{2} ab \sin C = \frac{1}{2} \times 6 \times 5 \times \frac{\sqrt{7}}{4} = \frac{15\sqrt{7}}{4}$ ;
> >
> > (2) 由 (1) 易知 $\cos C = \frac{3}{4}$ , 则 $\cos 2C = 2\cos^2 C - 1 = \frac{1}{8}$ ,
> >
> > 由（1）及余弦定理有 $\cos A = \frac{b^2 + c^2 - a^2}{2bc} = \frac{25 + 16 - 36}{2\times 5\times 4} = \frac{1}{8}$
> >
> > 所以 $\cos A = \cos 2C$ ，又 $A, C \in (0, \pi), A + C < \pi$ ，则 A = 2C。
