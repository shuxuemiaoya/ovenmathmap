> [!faq]- 《专题20_平面向量精选压轴60题12类考点专练_高效培优期中专项训练_》官方解析
>
> > [!success]- **【答案】** ACD
>
> > [!note]- **【解析】**
> > 对于A，由 $CO=2OB$ 得， $AO=\frac{2}{3}AB+\frac{1}{3}AC=\frac{2}{3}mAM+\frac{1}{3}nAN$
> >
> > 又 $M, O, N$ 共线，则 $\frac{2}{3} m + \frac{1}{3} n = 1$ ，所以 $2m + n = 3$ ，A 正确；
> >
> > 对于 B，由 $\frac{2m+n}{2}\leq\sqrt{\frac{4m^{2}+n^{2}}{2}}$ 得， $4m^{2}+n^{2}\quad\frac{(2m+n)^{2}}{2}=\frac{9}{2}$
> >
> > 当且仅当 $2m = n = \frac{3}{2}$ 时取等号，即 $4m^{2} + n^{2}$ 的最小值为 $\frac{9}{2}$ ，B错误；
> >
> > 对于 C， $\frac{1}{m}+\frac{3m}{n}=\frac{\frac{2}{3}m+\frac{1}{3}n}{m}+\frac{3m}{n}=\frac{2}{3}+\frac{n}{3m}+\frac{3m}{n}\quad\frac{2}{3}+2\sqrt{\frac{n}{3m}\cdot\frac{3m}{n}}=\frac{8}{3}$
> >
> > 当且仅当 $\frac{n}{3m} = \frac{3m}{n}$ ，即 $n = 3m = \frac{9}{5}$ 时取等号，
> >
> > 所以 $\frac{1}{m} +\frac{3m}{n}$ 的最小值为 $\frac{8}{3}$ ，C正确；
> >
> > 对于D，由 $2m + n = 3$ 得， $2(m + 2) + (n + 1) = 8$
> >
> > $$
> > \frac {1}{m + 2} + \frac {1}{n + 1} = \frac {1}{8} \left(\frac {1}{m + 2} + \frac {1}{n + 1}\right) [ 2 (m + 2) + (n + 1) ] = \frac {1}{8} \left[ 3 + \frac {n + 1}{m + 2} + \frac {2 (m + 2)}{n + 1} \right]
> > $$
> >
> > $$
> > \frac {1}{8} \left[ 3 + 2 \sqrt {\frac {n + 1}{m + 2} \cdot \frac {2 (m + 2)}{n + 1}} \right] = \frac {3 + 2 \sqrt {2}}{8}
> > $$
> >
> > 当且仅当 $\frac{n + 1}{m + 2} = \frac{2(m + 2)}{n + 1}$ ，即 $m = 6 - 4\sqrt{2}$ ， $n = 8\sqrt{2} - 9$ 时取等号，
> >
> > 所以 $\frac{1}{m + 2} +\frac{1}{n + 1}$ 的最小值为 $\frac{3 + 2\sqrt{2}}{8}$ ，D正确.
