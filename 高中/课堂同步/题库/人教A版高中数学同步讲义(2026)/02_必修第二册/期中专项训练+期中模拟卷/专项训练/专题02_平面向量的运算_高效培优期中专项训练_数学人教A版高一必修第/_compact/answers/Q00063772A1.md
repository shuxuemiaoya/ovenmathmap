> > [!note]- **【解析】**
> > 分析：根据向量 $\left|m+n\right|^{2}+\left|m-n\right|^{2}=2\left|m\right|^{2}+2\left|n\right|^{2}$ ，解得结果·详解：因为 $\left|m+n\right|^{2}+\left|m-n\right|^{2}=2\left|m\right|^{2}+2\left|n\right|^{2}$ ，所以 $\left|m+n\right|^{2}+17=8+18$ ，所以 $\left|m+n\right|^{2}=9,\left|m+n\right|=3,$
> >

> > ## 考点02向量减法的运算律
> >
> > 9. 化简：
> >
> > (1) $BA + OD - OA - BC$ ;
> >
> > (2) $6(3a-2b)+9(-2a+b)$ .
> >
> > 【答案】(1)CD
> >
> > (2)-3b
> >
> > 【详解】（1）解：由向量的线性运算法则，
> >
> > 可得 $BA + OD - OA - BC = (BA - BC) + (OD - OA) = CA + AD = CD$ .
> >
> > (2) 解：由向量的运算法则，可得 $6(3a-2b)+9(-2a+b)=(18a-12b)+(-18a+9b)=-3b$
> >
> > 10. 化简： $AB + CD - AD = (\quad)$ A. $CB$ B. $BC$ C. $DC$ D. $CD$
> >
> > 【答案】A
> >
> > 【详解】 $AB + CD - AD = AB - AD + CD = DB + CD = CB$
> >
> > 故选：A.
> >
> > 11. 化简下列各向量的表达式：
> >
> > (1) $AB + BC - AD$
> >
> > (2) $(AB-CD)-(AC-BD)$
> >
> > (3) $(AC + BO + OA) - (DC - DO - OB)$ ;
> >
> > 【答案】(1) $DC$ .
> >
> > (2)0.
> >
> > (3)0
> >
> > 【详解】（1） $AB + BC - AD = AC - AD = DC$
> >
> > (2) $(AB - CD) - (AC - BD) = AB - AC + BD - CD = CB + BD + DC$ $= CB + BC = CB - CB = 0.$
> >
> > $$
> > \left(^ {3}\right) \stackrel {{\text {   ③   }}} {{(A C + B O + O A)}} - \stackrel {{\text {   ③   }}} {{(D C - D O - O B)}} = \stackrel {{\text {   ③   }}} {{A C}} + \stackrel {{\text {   ③   }}} {{B A}} - \left(\stackrel {{\text {   ③   }}} {{O C}} - \stackrel {{\text {   ③   }}} {{O B}}\right)
> > $$
> >
> > $$
> > = B C - B C = 0.
> > $$
