> [!faq]- 《专题09_复数的四则运算_高效培优期中专项训练_数学人教A版高一必修第》官方解析
>
> > [!success]- **【答案】** A. 点 $B$ 一定在第四象限 B. 点 $C$ 可能在第三象限 C. $|z| = 2$ D. 若 $\angle BAC = \frac{\pi}{2}$ ，则 $\vee ABC$ 的面积为 $2\sqrt{3}$
>
> > [!note]- **【解析】**
> > 设 $z = a + bi(a, b \in \mathbf{R})$ ，则 $\overline{z} = a - bi, \frac{z^2}{2} = \frac{a^2 - b^2}{2} + abi$
> >
> > 所以 $A(a,b),B(a, - b),C\left(\frac{a^2 - b^2}{2},ab\right)$
> >
> > 对于 $^{A}$ ，由题意知点 A 在第一象限，则 a > 0, b > 0，所以点 B 一定在第四象限，故 $^{A}$ 正确；
> > 对于 $^{B}$ ，因为a>0,b>0，所以ab>0，点C不可能在第三象限，故 $^{B}$ 错误；
> > 对于 $^{C}$ ，因为原点 O 是 $\vee ABC$ 的外心，所以 $\left|z\right|=\left|\overline{z}\right|=\left|\frac{z^{2}}{2}\right|$ ，即 $\left|z\right|=\frac{\left|z\right|^{2}}{2}$ ，
> > 由题知 $|z|\neq0$ ，所以 $|z|=2$ ，故 $^{C}$ 正确；
> > 对于 $^{D}$ ，易知 AB 与 y 轴平行，若 $\angle BAC = \frac{\pi}{2}$ ，则 AC 与 x 轴平行，z 与 $\frac{z^{2}}{2}$ 的虚部相等，
> > 即 b = ab ，得 a = 1 ，
> > 又因为 $\left|z\right|=2$ ，所以 $b=\sqrt{3}$ 从而可得 $A(1,\sqrt{3}), B(1,-\sqrt{3}), C(-1,\sqrt{3}), |AB|=2\sqrt{3}, |AC|=2$ 所以 $S_{\triangle ABC}=\frac{1}{2}|AB|\times|AC|=2\sqrt{3}$ ，故 D 正确。
> >
> > 故选：ACD.
> >
> > 39. 欧拉公式 $e^{xi} = \cos x + i\sin x$ 是由瑞士著名数学家欧拉创立，该公式将指数函数的定义域扩大到复数集，建立了三角函数与指数函数的关联，在复变函数论里面占有非常重要的地位，被誉为数学中的天桥。依据欧拉公式，下列说法中正确的是（）
> >
> > 【答案】
> >
> > A. $e^{2i}$ 对应的点位于第二象限
> >
> > B. $e^{\pi i}$ 为纯虚数
> >
> > C. $\frac{e^{xi}}{\sqrt{3+i}}$ 的模长等于 $\frac{1}{4}$ D. $e^{\frac{\pi}{3}-i}$ 的共轭复数为 $\frac{1}{2}-\frac{\sqrt{3}}{2}i$
> >
> > 【答案】AD
> >
> > 【详解】对于 $^{A}$ 项：由题意可得： $e^{2i} = \cos 2 + i \sin 2$ ，则其对应的点为 $(\cos 2, \sin 2)$
> >
> > $\therefore 2\in\left(\frac{\pi}{2},\pi\right)$ ，则 $\cos2<0,\sin2>0$ ，
> >
> > $\therefore e^{2i}$ 对应的点位于第二象限，故 A 项正确；
> >
> > 对于 $^{B}$ 项：由题意可得： $e^{\pi i} = \cos \pi + i \sin \pi = -1$ 为实数，故 $^{B}$ 项错误；
> >
> > 对于 $C$ 项：方法 $^{1}$ ：由题意可得：
> >
> > $$
> > \frac {\mathrm{e} ^ {x \mathrm{i}}}{\sqrt {3} + \mathrm{i}} = \frac {(\cos x + \mathrm{i} \sin x) (\sqrt {3} - \mathrm{i})}{(\sqrt {3} + \mathrm{i}) (\sqrt {3} - \mathrm{i})} = \frac {(\sqrt {3} \cos x + \sin x) - (\cos x - \sqrt {3} \sin x) \mathrm{i}}{4} = \frac {1}{2} \sin \left(x + \frac {\pi}{3}\right) - \mathrm{i} \left[ \frac {1}{2} \cos \left(x + \frac {\pi}{3}\right) \right],
> > $$
> >
> > 则 $\left|\frac{\mathrm{e}^{xi}}{\sqrt{3} + i}\right| = \sqrt{\left[\frac{1}{2}\sin\left(x + \frac{\pi}{3}\right)\right]^2 + \left[-\frac{1}{2}\cos\left(x + \frac{\pi}{3}\right)\right]^2} = \sqrt{\frac{1}{4}\left[\sin^2\left(x + \frac{\pi}{3}\right) + \cos^2\left(x + \frac{\pi}{3}\right)\right]} = \frac{1}{2}$
> >
> > 方法2： $\left|\frac{e^{xi}}{\sqrt{3}+i}\right|=\left|\frac{\cos x+i\sin x}{\sqrt{3}+i}\right|=\frac{\sqrt{\cos^{2}x+\sin^{2}x}}{\sqrt{(\sqrt{3})^{2}+1^{2}}}=\frac{1}{2}$ ，故C项错误；
> >
> > 对于 D 项：由题意可得： $e^{\frac{\pi}{3}i} = \cos\frac{\pi}{3} + i\sin\frac{\pi}{3} = \frac{1}{2} + \frac{\sqrt{3}}{2}i$ ，
> >
> > 则 $\mathrm{e}^{\frac{\pi}{3}\mathrm{i}}$ 的共轭复数为 $\frac{1}{2} -\frac{\sqrt{3}}{2}\mathrm{i}$ ，故D项正确；
> >
> > 故选 **AD**.
