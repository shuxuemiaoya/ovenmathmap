> [!faq]- 《专题09_复数的四则运算_高效培优期中专项训练_数学人教A版高一必修第》官方解析
>
> > [!success]- **【答案】** ACD
>
> > [!note]- **【解析】**
> > 设 $z = a + bi(ab \neq 0, a, b \in \mathbb{R})$
> >
> > 选项 A：由 $z = |z|$ 即 $a + bi = \sqrt{a^{2} + b^{2}}$
> >
> > 所以 $b = 0, a = \sqrt{a^2 + b^2} = \sqrt{a^2}$
> >
> > 又 $ab \neq 0$ ，所以 $a > 0$ ，即 $z = a$ 为正实数，故 $\mathsf{A}$ 选项正确；
> >
> > 选项 B：由 $z^{2}=(a+bi)^{2}=a^{2}-b^{2}+2abi\in\mathbb{R}$
> >
> > 所以 $ab = 0$ ，即 $a, b$ 至少有一个为0，
> >
> > 若 $a = 0, b \neq 0$ 则不满足 $z \in \mathbf{R}$ ，故 $\mathsf{B}$ 选项不正确；
> >
> > 选项 C：若 $z^{2}+1=0$ ，即 $a^{2}-b^{2}+2abi+1=0$ ，
> >
> > 则 $\left\{ \begin{array}{l}ab = 0\\ a^2 -b^2 +1 = 0 \end{array} \right.$ 又 $ab\neq 0$
> >
> > 所以当 $a = 0, b \neq 0 \Rightarrow b = \pm 1$
> >
> > 当 $b = 0, a \neq 0 \Rightarrow a^2 + 1 = 0$ ，不满足题意，
> >
> > 所以 $a = 0, b = \pm 1$ ，则 $z = \pm i$ ，故 $C$ 选项正确；
> >
> > 选项D：由 $z + \overline{z} = 0$ ， $\overline{z} = a - bi(ab\neq 0,a,b\in \mathbb{R})$
> >
> > 即 $z + \overline{z} = (a + bi) + (a - bi) = 2a = 0$
> >
> > 所以 $a = 0, b \neq 0$ ，所以 $z$ 为纯虚数，故 $\mathbb{D}$ 选项正确；
> >
> > 故选 **ACD**.
