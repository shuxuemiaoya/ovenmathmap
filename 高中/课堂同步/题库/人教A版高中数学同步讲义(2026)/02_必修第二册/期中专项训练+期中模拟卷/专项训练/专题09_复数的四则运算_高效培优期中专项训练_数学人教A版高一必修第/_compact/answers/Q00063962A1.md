> > [!note]- **【解析】**
> > 由 $z_{1} = a + 2\mathrm{i},z_{2} = b - 3\mathrm{i}$ ，则 $z_{1} + z_{2} = (a + 2\mathrm{i}) + (b - 3\mathrm{i}) = (a + b) - \mathrm{i} = b\mathrm{i}$
> >
> > 所以 $\left\{ \begin{array}{l}a + b = 0\\ b = -1 \end{array} \right.$ ，解得 $a = 1,b = -1$ ，
> >
> > 所以 $a^{2023} + b^{2024} = 1^{2023} + (-1)^{2024} = 2$
> >
> > 故答案为：2.

> > 4. 复数 $z = m(m - 1) + (m - 1)\mathrm{i}$ .
> >
> > (1)实数 $m$ 取什么值时，复数 $z$ 是实数？纯虚数？
> >
> > (2)若 $z$ 在复平面内对应的点位于第四象限，求 $m$ 的取值范围.
> >
> > (3)若 $\left|z - m^2\right| < \sqrt{5}$ ，求 $m$ 的取值范围。
> >
> > 【答案】(1)答案见解析 (2) $(- \infty, 0)$ (3) $(-1, 2)$
> >
> > 【详解】（1）若复数 z 是实数，则 m-1=0，解得 m=1；
> >
> > 若复数 $z$ 是纯虚数，则 $\left\{ \begin{array}{l} m - 1 \neq 0 \\ m(m - 1) = 0 \end{array} \right.$ ，解得 $m = 0$
> >
> > (2) 因为 z 在复平面内对应的点为 $(m(m-1), m-1)$
> >
> > 由题意可得： $\left\{\begin{aligned}m(m-1)>0\\ m-1<0\end{aligned}\right.$ ，解得m<0
> >
> > 所以 $m$ 的取值范围为 $\left(-\infty,0\right)$
> >
> > (3) 因为 $z - m^{2} = m(m - 1) + (m - 1)\mathrm{i} - m^{2} = -m + (m - 1)\mathrm{i}$
> >
> > 由题意可得： $\left|z-m^{2}\right|^{2}=m^{2}+(m-1)^{2}<5$ ，解得-1<m<2
> >
> > 所以 $m$ 的取值范围为 $(-1, 2)$
