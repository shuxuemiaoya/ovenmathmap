> [!faq]- 《专题07_正弦定理_余弦定理_高效培优期中专项训练_数学人教A版高一必》官方解析
>
> > [!success]- **【答案】** (1) $\frac{2\pi}{3}$ (2)① $\frac{1}{2}$ ; ② $\left(\frac{1}{2},\frac{\sqrt{3}}{3}\right]$ .
>
> > [!note]- **【解析】**
> > （1）在 $\forall ABC$ 中， $c = 3,a^{2} = b^{2} + 3b + 9$
> >
> > 由余弦定理得 $\cos A = \frac{b^2 + c^2 - a^2}{2bc} = \frac{-3b - 9 + 9}{2\times 3b} = -\frac{1}{2}$ ，而 $A\in (0,\pi)$
> >
> > 所以 $A=\frac{2\pi}{3}$ .
> >
> > (2) ①由 $\overrightarrow{AD} = \lambda \left( \frac{\overrightarrow{AB}}{|AB|} + \frac{\overrightarrow{AC}}{|AC|} \right)$ ，得 $AD$ 是 $\angle BAC$ 的平分线，由（1）知， $A = \frac{2\pi}{3}$ ，得 $\angle BAD = \angle CAD = \frac{\pi}{3}$ ，在 $\vee ABC$ 中， $S_{\triangle ABC} = S_{\triangle ABD} + S_{\triangle ACD}$ ，即 $\frac{1}{2} bc \sin A = \frac{1}{2} c \cdot AD \cdot \sin \angle BAD + \frac{1}{2} b \cdot AD \cdot \sin \angle CAD$ ，则 $bc = 2(b + c)$ ，所以 $\frac{1}{b} + \frac{1}{c} = \frac{b + c}{bc} = \frac{1}{2}$ .
> > - **②**：在 $\triangle ABD$ 中，由正弦定理得 $\frac{BD}{\sin \angle BAD} = \frac{AD}{\sin B}$ ，则 $BD = \frac{AD \sin \angle BAD}{\sin B} = \frac{\sqrt{3}}{\sin B}$ ，在 $\triangle CAD$ 中，由正弦定理得 $CD = \frac{AD \sin \angle CAD}{\sin C} = \frac{\sqrt{3}}{\sin C}$ ，则 $\frac{1}{BD} + \frac{1}{CD} = \frac{1}{\frac{\sqrt{3}}{\sin B}} + \frac{1}{\frac{\sqrt{3}}{\sin C}} = \frac{\sqrt{3}}{3} (\sin B + \sin C)$ ，由 $A = \frac{2\pi}{3}$ ，得 $B + C = \frac{\pi}{3}$ ，因此 $\frac{1}{BD} + \frac{1}{CD} = \frac{\sqrt{3}}{3} [\sin B + \sin (\frac{\pi}{3} - B)] = \frac{\sqrt{3}}{3} (\frac{1}{2} \sin B + \frac{\sqrt{3}}{2} \cos B) = \frac{\sqrt{3}}{3} \sin (B + \frac{\pi}{3})$ ，由 $0 < B < \frac{\pi}{3}$ ，得 $B + \frac{\pi}{3} \in (\frac{\pi}{3}, \frac{2\pi}{3})$ ，则 $\frac{\sqrt{3}}{3} \sin (B + \frac{\pi}{3}) \in (\frac{1}{2}, \frac{\sqrt{3}}{3}]$ ，所以 $\frac{1}{BD} + \frac{1}{CD}$ 的取值范围为 $(\frac{1}{2}, \frac{\sqrt{3}}{3}]$ .
> >
