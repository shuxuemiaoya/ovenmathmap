> [!faq]- 《专题07_正弦定理_余弦定理_高效培优期中专项训练_数学人教A版高一必》官方解析
>
> > [!success]- **【答案】** (1)证明见解析 (2) $(3,\frac{10}{3})$
>
> > [!note]- **【解析】**
> > （1）因为 $m=(a+c,a)$ ， $n=(a-c,b)$ ，且 $m\perp n$ ，
> >
> > 所以 $m \cdot n = (a + c, a) \cdot (a - c, b) = a^2 - c^2 + ab = 0$
> >
> > 又由余弦定理， $c^2 = a^2 +b^2 -2ab\cos C$ ，得 $a^2 -c^2 = 2ab\cos C - b^2$
> >
> > 所以 $2ab \cos C - b^{2} + ab = 0$ ，即 $2a \cos C - b + a = 0$ ，
> >
> > 由正弦定理可得， $2\sin A\cos C-\sin B+\sin A=0$
> >
> > 在 $\triangle ABC$ 中， $\sin B = \sin (A + C) = \sin A\cos C + \cos A\sin C$ ，代入上式，
> >
> > $$
> > \sin A \cos C - \cos A \sin C = - \sin A = \sin (- A)
> > $$
> >
> > 即 $\sin(A-C)=\sin(-A)$ ，又因为 A, C 是锐角， $A-C\in\left(-\frac{\pi}{2},\frac{\pi}{2}\right),-A\in\left(-\frac{\pi}{2},0\right)$ 所以 A - C = -A ，即 C = 2A 。
> >
> > (2) 由 C = 2A 和正弦定理可得，
> >
> > $$
> > \begin{array}{l} \frac {b}{a} + \left(\frac {2 a}{c}\right) ^ {2} = \frac {\sin B}{\sin A} + \frac {4 \sin^ {2} A}{\sin^ {2} C} = \frac {\sin (\pi - 3 A)}{\sin A} + \frac {4 \sin^ {2} A}{\sin^ {2} 2 A} = \frac {\sin 3 A}{\sin A} + \frac {4 \sin^ {2} A}{4 \sin^ {2} A \cos^ {2} A} \\ = \frac {\sin A \cos 2 A + \cos A \sin 2 A}{\sin A} + \frac {1}{\cos^ {2} A} = \cos 2 A + 2 \cos^ {2} A + \frac {1}{\cos^ {2} A} \\ = 4 \cos^ {2} A + \frac {1}{\cos^ {2} A} - 1, \end{array}
> > $$
> >
> > 因为 $\triangle ABC$ 是锐角三角形，
> >
> > 所以 $\left\{ \begin{array}{ll}0 < A <   \frac{\pi}{2}\\ 0 <   B = \pi -3A <   \frac{\pi}{2}\\ 0 <   C = 2A <   \frac{\pi}{2} \end{array} \right.$ ，所以 $A\in (\frac{\pi}{6},\frac{\pi}{4})$
> >
> > 所以 $\cos A\in(\frac{\sqrt{2}}{2},\frac{\sqrt{3}}{2})$ ， $\cos^{2}A\in(\frac{1}{2},\frac{3}{4})$ ，令 $t=\cos^{2}A\in(\frac{1}{2},\frac{3}{4})$ ，
> >
> > 则 $4\cos^2 A + \frac{1}{\cos^2 A} - 1 = 4t + \frac{1}{t} - 1$
> >
> > 因为对勾函数 $y = 4t + \frac{1}{t} - 1$ 在 $t \in \left(\frac{1}{2}, \frac{3}{4}\right)$ 上单调递增，所以 $y \in \left(3, \frac{10}{3}\right)$ ，
> >
> > 所以 $\frac{b}{a}+\left(\frac{2a}{c}\right)^{2}$ 的取值范围是 $(3,\frac{10}{3})\cdot$
