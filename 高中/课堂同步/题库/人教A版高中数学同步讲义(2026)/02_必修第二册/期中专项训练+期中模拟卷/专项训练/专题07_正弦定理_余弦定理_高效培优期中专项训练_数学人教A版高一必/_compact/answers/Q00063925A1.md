> [!faq]- 《专题07_正弦定理_余弦定理_高效培优期中专项训练_数学人教A版高一必》官方解析
>
> > [!success]- **【答案】** ABC
>
> > [!note]- **【解析】**
> > 对于选项 $^{A}$ ，因为 $A > B \Leftrightarrow a > b \Leftrightarrow 2R\sin A > 2R\sin B \Leftrightarrow \sin A > \sin B$ ，所以 $^{A}$ 正确，
> > 对于选项 $^{B}$ ，在锐角 $\bigvee ABC$ 中， $A+B>\frac{\pi}{2}\Leftrightarrow\frac{\pi}{2}>A>\frac{\pi}{2}-B>0$ ，因为 $y=\sin x$ 在 $\left(0,\frac{\pi}{2}\right)$ 上单调递增，
> > 所以 $\sin A > \sin\left(\frac{\pi}{2} - B\right) = \cos B$ ，所以 $^{B}$ 正确，
> > 对于 $^{C}$ ，因为 $\frac{a}{\cos A} = \frac{b}{\cos B} = \frac{c}{\cos C}$ ，则 $\frac{\sin A}{\cos A} = \frac{\sin B}{\cos B} = \frac{\sin C}{\cos C}$ 即 $\tan A = \tan B = \tan C$ ，又 $A, B, C \in (0, \pi)$ ，则有 $\tan A = \tan B = \tan C > 0$ ，所以 $A, B, C \in \left(0, \frac{\pi}{2}\right)$ ，
> > 又 $y = \tan x$ 在区间 $\left(0, \frac{\pi}{2}\right)$ 上单调递增，所以 A = B = C，则 a = b = c，所以 $^{C}$ 正确，
> > 对于 $^{D}$ ，若 $A=30^{\circ}$ ，b=4，a=3，则 $\sin B=\frac{b\sin A}{a}=\frac{4\times\frac{1}{2}}{3}=\frac{2}{3}$
> >
> > 因为 $a < b$ ，所以 $A < B$ ，则 $B$ 为锐角或钝角，即 $\forall ABC$ 有两解，所以 ${}^{\mathrm{D}}$ 错误.
> >
> > 故选 **ABC**
