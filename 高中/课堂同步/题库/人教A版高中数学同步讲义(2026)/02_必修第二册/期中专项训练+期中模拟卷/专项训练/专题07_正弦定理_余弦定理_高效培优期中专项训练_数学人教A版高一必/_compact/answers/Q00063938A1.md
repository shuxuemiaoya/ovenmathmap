> [!faq]- 《专题07_正弦定理_余弦定理_高效培优期中专项训练_数学人教A版高一必》官方解析
>
> > [!success]- **【答案】** 等腰或直角三角形
>
> > [!note]- **【解析】**
> > 在 $\bigvee ABC$ 中，由 $\frac{a\sin A}{a^2 + c^2 - b^2} = \frac{b\sin B}{b^2 + c^2 - a^2}$ 及余弦定理，得 $\frac{a\sin A}{2ac\cos B} = \frac{b\sin B}{2bc\cos A}$ ，整理得 $\sin A\cos A = \sin B\cos B$ ，即 $\sin 2A = \sin 2B$
> >
> > 而 $0 < 2A < 2\pi, 0 < 2B < 2\pi, 0 < 2A + 2B < 2\pi$ ，因此 $2A = 2B$ 或 $2A + 2B = \pi$
> >
> > 所以 $A = B$ 或 $A + B = \frac{\pi}{2}$ ，即 $\vee ABC$ 为等腰三角形或直角三角形。
> >
> > 故答案为：等腰或直角三角形
