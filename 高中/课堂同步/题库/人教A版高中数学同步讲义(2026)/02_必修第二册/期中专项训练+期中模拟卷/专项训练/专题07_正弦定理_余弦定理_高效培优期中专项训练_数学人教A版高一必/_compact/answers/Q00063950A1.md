> [!faq]- 《专题07_正弦定理_余弦定理_高效培优期中专项训练_数学人教A版高一必》官方解析
>
> > [!success]- **【答案】** A. $\left[\frac{7}{25}, \frac{25}{7}\right)$ B. $\left(\frac{7}{25}, +\infty\right)$ C. $\left(\frac{7}{25}, \frac{25}{7}\right)$ D. $\left(\frac{24}{25}, +\infty\right)$
>
> > [!note]- **【解析】**
> > 在 $\triangle ABC$ 中，由余弦定理得 $a^2 = b^2 + c^2 - 2bc\cos A$ ，且 $\triangle ABC$ 的面积 $S = \frac{1}{2} bc\sin A$ ，由 $3S = a^2 - (b - c)^2$ ，得 $\frac{3}{2} bc\sin A = 2bc + a^2 - b^2 - c^2 = 2bc - 2bc\cos A$ ，化简得 $3\sin A + 4\cos A = 4$ ，又 $A \in \left(0, \frac{\pi}{2}\right)$ ， $\sin^2 A + \cos^2 A = 1$ ，联立解得 $\sin A = \frac{24}{25}$ ， $\cos A = \frac{7}{25}$ ，所以 $\frac{b}{c} = \frac{\sin B}{\sin C} = \frac{\sin(A + C)}{\sin C} = \frac{\sin A\cos C + \cos A\sin C}{\sin C} = \frac{24}{25\tan C} + \frac{7}{25}$ ， $\triangle ABC$ 为锐角三角形，有 $0 < C < \frac{\pi}{2}$ ， $B = \pi - A - C < \frac{\pi}{2}$ ，得 $\frac{\pi}{2} - A < C < \frac{\pi}{2}$ ，则有 $\tan C > \tan\left(\frac{\pi}{2} - A\right) = \frac{\cos A}{\sin A} = \frac{7}{24}$ ，可得 $\frac{1}{\tan C} \in \left(0, \frac{24}{7}\right)$ ，所以 $\frac{b}{c} \in \left(\frac{7}{25}, \frac{25}{7}\right)$ . 故选：C

> >
> > (1)若 $b^{2}-a^{2}+c^{2}-3c=0$ ，且边BC的中线AD长为 $\frac{\sqrt{19}}{2}$ ，求 $\vee ABC$ 的面积；
> >
> > (2)若 $\vee ABC$ 是锐角三角形，求 $\frac{a + b}{c}$ 的范围·
> > 【答案】(1) $\frac{3\sqrt{3}}{2}$ (2) $\left(\frac{\sqrt{3} + 1}{2}, 2 + \sqrt{3}\right)$
> >
> > 【详解】（1）解：在 $\forall ABC$ 中，因为 $2c - b = 2a\cos B$
> >
> > 由余弦定理可得 $2c - b = 2a \times \frac{a^2 + c^2 - b^2}{2ac}$ ，即 $2c^2 - bc = a^2 + c^2 - b^2$
> >
> > 整理得 $b^{2} + c^{2} - a^{2} = bc$ ，所以 $\cos A = \frac{b^2 + c^2 - a^2}{2bc} = \frac{bc}{2bc} = \frac{1}{2}$
> >
> > 因为 $0 < A < \pi$ ，所以 $A = \frac{\pi}{3}$ ，
> >
> > 又因为 $b^{2} - a^{2} + c^{2} - 3c = 0$
> >
> > 联立方程组 $\left\{ \begin{array}{l} b^{2} + c^{2} - a^{2} = bc \\ b^{2} - a^{2} + c^{2} - 3c = 0 \end{array} \right.$ ，解得 $3c = bc$ ，所以 $b = 3$ ，
> >
> > 因为 $AD$ 为 $BC$ 边中线，则 $\overline{AD} = \frac{1}{2}\left(\overline{AB} +\overline{AC}\right)$
> >
> > 所以 $AD^2 = \frac{1}{4}\left(AB^2 + 2AB \cdot AC + AC^2\right) = \frac{1}{4}\left[c^2 + 2 \cdot 3c \cdot \frac{1}{2} + 3^2\right] = \frac{19}{4}$ ，
> >
> > 可得 $c^{2}+3c-10=0$ ，解得c=2或c=-5（舍去），
> >
> > 所以 $\vee ABC$ 的面积为 $S = \frac{1}{2} bc\sin A = \frac{3\sqrt{3}}{2}$ .
> >
> > (2) 解：由正弦定理，可得 $\frac{a+b}{c}=\frac{\sin A+\sin B}{\sin C}=\frac{\sin\left(C+\frac{\pi}{3}\right)+\frac{\sqrt{3}}{2}}{\sin C}=\frac{\frac{1}{2}\sin C+\frac{\sqrt{3}}{2}\cos C+\frac{\sqrt{3}}{2}}{\sin C}=\frac{\frac{\sqrt{3}}{2}\cos C+\frac{\sqrt{3}}{2}}{\sin C}+\frac{1}{2}=\frac{\sqrt{3}}{2}\frac{2\cos^{2}\frac{C}{2}}{2\sin\frac{C}{2}\cos\frac{C}{2}}+\frac{1}{2}=\frac{\sqrt{3}}{2}\frac{1}{\tan\frac{C}{2}}+\frac{1}{2}.$
> >
> > 因为 是锐角三角形，则 $\left\{ \begin{array}{l}0 < C < \frac{\pi}{2}\\ 0 < \frac{2\pi}{3} -C < \frac{\pi}{2} \end{array} \right.$ ，可得 $C\in \left(\frac{\pi}{6},\frac{\pi}{2}\right)$ ，所以 $\frac{C}{2}\in \left(\frac{\pi}{12},\frac{\pi}{4}\right)$
> >
> > 因为 $\tan \frac{\pi}{12} = \tan \left(\frac{\pi}{3} -\frac{\pi}{4}\right) = 2 - \sqrt{3}$ ，所以 $\tan \frac{C}{2}\in (2 - \sqrt{3},1)$ ，则 $\frac{1}{\tan\frac{C}{2}}\in (1,2 + \sqrt{3})$
> >
> > 所以 $\frac{\sqrt{3}}{2}\frac{1}{\tan\frac{C}{2}} +\frac{1}{2}\in \left(\frac{\sqrt{3} + 1}{2},2 + \sqrt{3}\right)$ ，所以 $\frac{a + b}{c}\in \left(\frac{\sqrt{3} + 1}{2},2 + \sqrt{3}\right)\cdot$
