> [!faq]- 《专题07_正弦定理_余弦定理_高效培优期中专项训练_数学人教A版高一必》官方解析
>
> > [!success]- **【答案】** CD
>
> > [!note]- **【解析】**
> > 对于选项 $^{A}$ ：因为 b > c， $\sin C = \frac{c \sin B}{b} = \frac{2\sqrt{3}}{5}$ ，所以只有一解，故 $^{A}$ 错误；
> >
> > 对于选项 B：因为在三角形中， $A + B \in (0, \pi)$
> >
> > 故若 $\sin 2A = \sin 2B$ ，则 $2A = 2B$ 或 $2A + 2B = \pi$ ，可得 $A = B$ 或 $A + B = \frac{\pi}{2}$
> >
> > 所以 $\vee ABC$ 为等腰三角形或直角三角形，故 $^{\mathrm{B}}$ 错误，
> >
> > 对于选项 C：若 $\sin^{2}A + \sin^{2}B < \sin^{2}C$ ，由正弦定理得 $a^{2} + b^{2} < c^{2}$ ，
> >
> > 由余弦定理 $\cos C = \frac{a^2 + b^2 - c^2}{2ab} < 0$ ，且 $C \in (0, \pi)$ ，所以 $C$ 为钝角，即是钝角三角形，故 $C$ 正确；
> >
> > 对于选项 $^{D}$ ：若 A > B，则 a > b，由正弦定理可得 $\sin A > \sin B$ 成立·故 $^{D}$ 正确·
> >
> > 故选：CD.
