> [!faq]- 《专题21_立体几何初步及复数精选压轴60题12类考点专练_期中复习专项》官方解析
>
> > [!success]- **【答案】** (1) $a=\frac{4}{3}$ (2) $(-∞,-2)$ (3) $\pm 2\sqrt{6}$ 或 $\pm 4\sqrt{3}$
>
> > [!note]- **【分析】**
> > （1）利用复数乘法法则得到 $\left(3+2\mathrm{i}\right)\cdot\overline{z}=6+2a+\left(4-3a\right)\mathrm{i}$ ，根据 $\left(3+2\mathrm{i}\right)\cdot\overline{z}$ 是实数，可得方程，
> >
> > 可求出 $a$ ；
> >
> > (2) 利用复数除法法则化简，得到 $z_{1}$ 对应的点坐标，根据所在象限，得到不等式组，求出实数 $a$ 的取值
> >
> > 范围；
> >
> > (3) 分方程的两根为实数根与虚数根两种情况求解即可.
>
> > [!note]- **【解析】**
> > （1）由 $z = 2 + ai$ 可得 $\overline{z} = 2 - ai$
> >
> > 所以 $\left(3 + 2\mathrm{i}\right)\cdot \overline{z} = (3 + 2\mathrm{i})\cdot (2 - ai) = 6 - 3ai + 4i - 2ai^2 = 6 + 2a + (4 - 3a)\mathrm{i}$
> >
> > 若复数 $(3+2\mathrm{i})\cdot\overline{z}$ 是实数，可得4-3a=0，
> >
> > 解得 $a = \frac{4}{3}$
> >
> > (2) $z_{1}=\frac{z}{1-i}=\frac{2+ai}{1-i}=\frac{(2+ai)(1+i)}{(1-i)(1+i)}=\frac{2+2i+ai+ai^{2}}{1-i^{2}}=\frac{2-a+(2+a)i}{2}$
> >
> > $$
> > = \frac {2 - a}{2} + \frac {2 + a}{2} \mathrm{i}
> > $$
> >
> > 易知复数 $z_{1}$ 在复平面内所对应的点坐标为 $\left(\frac{2 - a}{2},\frac{2 + a}{2}\right)$
> >
> > 又复数 在复平面内所对应的点位于第四象限，可得 $\left\{ \begin{array}{l} \frac{2 - a}{2} > 0 \\ \frac{2 + a}{2} < 0 \end{array} \right.$
> >
> > 解得 $a < -2$
> >
> > 即实数 $a$ 的取值范围为 $(- \infty, -2)$
> >
> > （3）若方程的两根为实数根，则 $\left|x_{1} - x_{2}\right| = \sqrt{\left(x_{1} + x_{2}\right)^{2} - 4x_{1}x_{2}} = \sqrt{m^{2} - 36} = 2\sqrt{3}$
> >
> > 解得 $m = \pm 4\sqrt{3}$ ，
> >
> > 若方程的两根为虚数根，则设 $x_{1} = a + bi$ ， $x_{2} = a - bi, a, b \in \mathbb{R}$ ，可得 $\left|x_{1} - x_{2}\right| = \left|2b\right| = 2\sqrt{3}$
> >
> > 则 $x_{1} = a + \sqrt{3}\mathrm{i}$ ， $x_{2} = a - \sqrt{3}\mathrm{i}$ ， $x_{1}x_{2} = a^{2} + 3 = 9$ ，所以 $a^2 = 6$ ，所以 $a = \pm \sqrt{6}$
> >
> > 由韦达定理可得 $-m = x_{1} + x_{2} = \pm 2\sqrt{6}$ ，所以 $m = \pm 2\sqrt{6}$
> >
> > 此时 $\Delta = m^{2} - 36 < 0$ ，满足题意，
> >
> > 综上， $m=\pm2\sqrt{6}$ 或 $\pm4\sqrt{3}$
> >
