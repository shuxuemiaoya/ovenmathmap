> [!faq]- 《专题03 向量的数量积（高效培优期中专项训练）数学人教A版高一必修第二册》官方解析
>
> > [!success]- **【答案】** ①③
>
> > [!note]- **【解析】**
> > 由题意： $OA = x_{1}e_{1} + y_{1}e_{2}$ ， $OB = x_{2}e_{1} + y_{2}e_{2}$
> > - **对于①**：设 $M$ 为 $AB$ 中点，
> >
> > 所以 $OM = \frac{1}{2} \left( OA + OB \right) = \frac{1}{2} \left( x_{1} e_{1} + y_{1} e_{2} + x_{2} e_{1} + y_{2} e_{2} \right) = \frac{x_{1} + x_{2}}{2} e_{1} + \frac{y_{1} + y_{2}}{2} e_{2}$
> >
> > 所以线段 $AB$ 的中点 $M$ 的广义坐标为 $\left(\frac{x_1 + x_2}{2}, \frac{y_1 + y_2}{2}\right)$ ，故①正确；
> > - **对于②**：，因为 $AB = OB - OA = x_2e_1 + y_2e_2 - x_1e_1 - y_1e_2 = (x_2 - x_1)e_1 + (y_2 - y_1)e_2$
> >
> > 所以 $\left|AB\right| = \sqrt{\left[\left(x_{2} - x_{1}\right)e_{1} + \left(y_{2} - y_{1}\right)e_{2}\right]^{2}} = \sqrt{\left(x_{2} - x_{1}\right)^{2}e_{1}^{2} + 2\left(x_{2} - x_{1}\right)\left(y_{2} - y_{1}\right)e_{1} \cdot e_{2} + \left(y_{2} - y_{1}\right)^{2}e_{2}^{2}}$
> >
> > 当向量 $e_{1}$ ， $e_{2}$ 是相互垂直的单位向量时，
> >
> > A，B两点间的距离为 $\sqrt{\left(x_1 - x_2\right)^2 + \left(y_1 - y_2\right)^2}$ ，否则距离不为 $\sqrt{\left(x_1 - x_2\right)^2 + \left(y_1 - y_2\right)^2}$ ，②错误；
> > - **对于③**：向量 $\overline{OA}$ 平行于向量 $\overline{OB}$ ，即 $\overline{OA}=\lambda\overline{OB}$ ， $\lambda\in R$ ，
> >
> > 即 $x_{1}^{\sqcup}e_{1} + y_{1}^{\sqcup}e_{2} = \lambda \left(x_{2}^{\sqcup}e_{1} + y_{2}^{\sqcup}e_{2}\right)$
> >
> > 则 $x_{1}y_{2} = x_{2}y_{1}$ ，故③正确；
> > - **对于④**：向量OA垂直于向量OB
> >
> > 即 $OA \cdot OB = \left( x_{1} e_{1} + y_{1} e_{2} \right) \cdot \left( x_{2} e_{1} + y_{2} e_{2} \right) = 0$
> >
> > 则 $x_{1}x_{2}e_{1}^{\sqcup 2} + (x_{1}y_{2} + x_{2}y_{1})e_{1}\cdot e_{2} + y_{1}y_{2}e_{2}^{\sqcup 2} = 0$
> >
> > 化简可得 $x_{1}x_{2} + y_{1}y_{2} + (x_{1}y_{2} + x_{2}y_{1})\mathbf{e}_{1}\cdot \mathbf{e}_{2} = 0$
> >
> > 故④不一定成立；
> >
> > 故答案为：①③·
> >
