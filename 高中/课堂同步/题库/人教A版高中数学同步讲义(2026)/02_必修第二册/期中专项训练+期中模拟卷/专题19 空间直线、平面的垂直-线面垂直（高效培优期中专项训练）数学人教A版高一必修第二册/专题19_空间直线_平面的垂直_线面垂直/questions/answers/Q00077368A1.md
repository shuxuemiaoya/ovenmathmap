> [!faq]- 《专题19 空间直线、平面的垂直-线面垂直（高效培优期中专项训练）数学人教A版高一必修第二册》官方解析
>
> > [!success]- **【答案】** A. 若 $n // \alpha, m \perp n$ ，则 $m \perp \alpha$ B. 若 $m // n, m // \alpha$ ，则 $n // \alpha$ C. $m \perp \alpha, n \perp \beta, \alpha // \beta$ ，则 $m // n$ D. 若 $m, n$ 是异面直线，则 $m, n$ 在 $\alpha$ 内的射影为两条相交直线
>
> > [!note]- **【解析】**
> > 对于 A， $n // \alpha$ ， $m \perp n$ ，则 m 可能在 $\alpha$ 内，可能平行于 $\alpha$ ，也可能与 $\alpha$ 相交，A 错误；
> >
> > 对于 B， $m \parallel n$ ， $m \parallel \alpha$ ，则 n 可能在 $\alpha$ 内，可能平行于 $\alpha$ ，B 错误；
> >
> > 对于 C，由 $m \perp \alpha$ ， $\alpha // \beta$ ，得 $m \perp \beta$ ，而 $n \perp \beta$ ，因此 $m // n$ ，C 正确；
> >
> > 对于 $^{D}$ ，m，n 是异面直线，m，n 在 $\alpha$ 内的射影可能是两条平行直线，可能是两条相交直线，
> >
> > 也可能是一条直线和一个点， $^{D}$ 错误·
> >
> > 故选：C
> >
> > ## 考点 04 线面垂直证明线线垂直
