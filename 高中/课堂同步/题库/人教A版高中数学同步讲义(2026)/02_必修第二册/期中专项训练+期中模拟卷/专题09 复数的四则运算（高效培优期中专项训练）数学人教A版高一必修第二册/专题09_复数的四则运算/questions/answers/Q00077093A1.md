> [!faq]- 《专题09 复数的四则运算（高效培优期中专项训练）数学人教A版高一必修第二册》官方解析
>
> > [!success]- **【答案】** （1） $(x - 2\mathrm{i})(x + 2\mathrm{i})$ ；（2）-1；（3） $\left\{ \begin{array}{l}a = -2\\ b = -1 \end{array} \right.$ 或 $\left\{ \begin{array}{l}a = -4\\ b = 2 \end{array} \right.$
>
> > [!note]- **【解析】**
> > （1）因为 $i^{2} = -1$ ，所以 $x^{2} + 4 = x^{2} - (2i)^{2} = (x - 2i)(x + 2i)$ ;
> >
> > (2) $\left(\frac{1 - \mathrm{i}}{1 + \mathrm{i}}\right)^{18} = \left[\frac{(1 - \mathrm{i})^2}{(1 + \mathrm{i})(1 - \mathrm{i})}\right]^{18} = (-\mathrm{i})^{18} = \mathrm{i}^{18} = \mathrm{i}^2 = -1$
> >
> > (3) 因为 $z = 1 + i$ ，所以 $\bar{z} = 1 - i$ ，
> >
> > 所以 $a(1 + \mathrm{i}) + 2b(1 - \mathrm{i}) = [a + 2(1 + \mathrm{i})]^2$ ，即 $a + a\mathrm{i} + 2b - 2b\mathrm{i} = a^2 +4(1 + \mathrm{i})^2 +4a(1 + \mathrm{i})$ ，
> >
> > 所以 $a + 2b + (a - 2b)\mathrm{i} = a^2 +4a + (8 + 4a)\mathrm{i}$
> >
> > 所以 $\left\{\begin{aligned}a+2b=a^{2}+4a\\ a-2b=8+4a\end{aligned}\right.$ ，解得 $\left\{\begin{aligned}a=-2\\ b=-1\end{aligned}\right.$ 或 $\left\{\begin{aligned}a=-4\\ b=2\end{aligned}\right.$

> > 19. 多项式 $x^{2} + 2x + 4$ 在复数集中因式分解的结果是（）A. $\left(x + 1 + \sqrt{3}\mathrm{i}\right)\left(x + 1 - \sqrt{3}\mathrm{i}\right)$ B. $\left(x - 1 - \sqrt{3}\mathrm{i}\right)\left(x + 1 - \sqrt{3}\mathrm{i}\right)$ C. $\left(x - 1 - \sqrt{3}\mathrm{i}\right)\left(x - 1 + \sqrt{3}\mathrm{i}\right)$ D. $\left(x + 1 - \sqrt{3}\mathrm{i}\right)\left(x - 1 + \sqrt{3}\mathrm{i}\right)$
> >
> > 【答案】A
> >
> > 【详解】解：对于方程 $x^{2} + 2x + 4 = 0$ ，因为 $\Delta = 2^{2} - 4\times 4 = -12$
> >
> > 所以 $x^{2} + 2x + 4 = 0$ 有两个虚根，即 $x_{1} = \frac{-2 + \sqrt{12}\mathrm{i}}{2} = -1 + \sqrt{3}\mathrm{i}, x_{2} = \frac{-2 - \sqrt{12}\mathrm{i}}{2} = -1 - \sqrt{3}\mathrm{i}$
> >
> > 所以 $x^{2}+2x+4=\left(x+1+\sqrt{3}\mathrm{i}\right)\left(x+1-\sqrt{3}\mathrm{i}\right)$ ;
> >
> > 故选 **A**
