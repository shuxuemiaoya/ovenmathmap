> [!faq]- 《专题09 复数的四则运算（高效培优期中专项训练）数学人教A版高一必修第二册》官方解析
>
> > [!success]- **【答案】** A
>
> > [!note]- **【解析】**
> > 依题意， $z = \frac{5}{1 + 2\mathrm{i}} = \frac{5(1 - 2\mathrm{i})}{(1 + 2\mathrm{i})(1 - 2\mathrm{i})} = \frac{5(1 - 2\mathrm{i})}{5} = 1 - 2\mathrm{i}$
> >
> > 所以 $|z| = \sqrt{1^2 + (-2)^2} = \sqrt{5}$ .
> >
> > 故选：A
> >
> > ## 考点04 复数范围内分解因式
> >
> > 16. 我们把 $a_0 + a_1x + a_2x^2 + \cdots + a_nx^n = 0$ （其中 $a_n \neq 0, n \in \mathbb{N}^*$ ）称为一元 $n$ 次多项式方程·代数基本定理：任何一元 $n(n \in \mathbb{N}^*)$ 次复系数多项式方程（即 $a_0, a_1, a_2, \cdots, a_n$ 为实数）在复数集内至少有一个复数根；由此推得，任何一元 $n(n \in \mathbb{N}^*)$ 次复系数多项式方程在复数集内有且仅有 $n$ 个复数根（重根按重数计算）·那么我们由代数基本定理可知：任何一元 $n(n \in \mathbb{N}^*)$ 次复系数多项式在复数集内一定可以分解因式，转化为 $n$ 个一元一次多项式的积·即 $a_0 + a_1x + a_2x^2 + \cdots + a_nx^n = a_n(x - \alpha_1)^{k_1}(x - \alpha_2)^{k_2} \cdots (x - \alpha_m)^{k_m}$ ，其中 $k, m \in \mathbb{N}^*$ ， $k_1 + k_2 + \cdots + k_m = n, \alpha_1, \alpha_2, \cdots, \alpha_m$ 为方程 $a_0 + a_1x + a_2x^2 + \cdots + a_nx^n = 0$ 的根·进一步可以推出：在实系数范围内（即 $a_0, a_1, a_2, \cdots, a_n$ 为实数），方程 $a_0 + a_1x + a_2x^2 + \cdots + a_nx^n = 0$ 有实数根，则多项式 $a_0 + a_1x + a_2x^2 + \cdots + a_nx^n$ 必可分解因式·例如：观察可知， $x = 1$ 是方程 $x^3 - 1 = 0$ 的一个根，则 $(x - 1)$ 一定是多项式 $x^3 - 1$ 的一个因式，即 $x^3 - 1 = (x - 1)(ax^2 + bx + c)$ ，由待定系数法可知， $a = b = c = 1$ .
> >
> > (1)在复数集内解方程： $x^{3}+x-2=0$ ；
> >
> > (2) 设 $f(x) = a_0 + a_1x + a_2x^2 + a_3x^3$ ，其中 $a_0, a_1, a_2, a_3 \in \mathbf{R}^*$ ，且 $a_0 + a_1 + a_2 + a_3 = 1$ .
> >
> > (i) 分解因式： $x-\left(a_{0}+a_{1}x+a_{2}x^{2}+a_{3}x^{3}\right)$ ;
> >
> > (ii) 记点 $P\left(x_0, y_0\right)$ 是 $y = f(x)$ 的图象与直线 $y = x$ 在第一象限内离原点最近的交点·求证：当 $a_1 + 2a_2 + 3a_3 \leq 1$ 时， $x_0 = 1$ .
> >
> > 【答案】 $^{(1)}$ 、 $\frac{-1\pm\sqrt{7}i}{2}$
> >
> > (2) (i) $x - \left(a_{0} + a_{1}x + a_{2}x^{2} + a_{3}x^{3}\right) = -\left(x - 1\right)\left[a_{3}x^{2} + \left(a_{3} + a_{2}\right)x - a_{0}\right]$ ; (i) 证明见解析
> >
> > 【详解】（1）观察可知， $x = 1$ 是方程 $x^{3} + x - 2 = 0$ 的一个根，
> >
> > 则 $(x - 1)$ 一定是多项式 $x^{3} + x - 2$ 的一个因式，
> >
> > 即 $x^{3} + x - 2 = (x - 1)(ax^{2} + bx + c) = ax^{3} + (b - a)x^{2} + (c - b)x - c$
> >
> > 即有 $\left\{ \begin{array}{l}a = 1\\ b - a = 0\\ c - b = 1\\ -c = -2 \end{array} \right.$ ，解得 $\left\{ \begin{array}{l}a = 1\\ b = 1\\ c = 2 \end{array} \right.$
> >
> > 即 $x^{3} + x - 2 = (x - 1)(x^{2} + x + 2)$
> >
> > 令 $x^{2} + x + 2 = 0$ ，则 $x = \frac{-1\pm\sqrt{1 - 8}}{2} = \frac{-1\pm\sqrt{7}\mathrm{i}}{2}$
> >
> > 即该方程的根为：1、 $\frac{-1\pm\sqrt{7}i}{2}$ ；
> >
> > (2) (i) 观察可知， $x = 1$ 是方程 $x - \left(a_{0} + a_{1}x + a_{2}x^{2} + a_{3}x^{3}\right) = 0$ 的一个根，
> >
> > 则 $(x - 1)$ 一定是多项式 $x - \left(a_{0} + a_{1}x + a_{2}x^{2} + a_{3}x^{3}\right)$ 的一个因式，
> >
> > $$
> > x - \left(a _ {0} + a _ {1} x + a _ {2} x ^ {2} + a _ {3} x ^ {3}\right) = (x - 1) \left(a x ^ {2} + b x + c\right) = a x ^ {3} + (b - a) x ^ {2} + (c - b) x - c
> > $$
> >
> > 则有 $\left\{ \begin{array}{l} -a_{3} = a \\ -a_{2} = b - a \\ 1 - a_{1} = c - b \\ -a_{0} = -c \end{array} \right.$ ，即 $\left\{ \begin{array}{l} a = -a_{3} \\ b = -a_{3} - a_{2} \\ c = a_{0} \end{array} \right.$
> >
> > 即 $x - \left(a_{0} + a_{1}x + a_{2}x^{2} + a_{3}x^{3}\right) = -\left(x - 1\right)\left[a_{3}x^{2} + \left(a_{3} + a_{2}\right)x - a_{0}\right]$
> >
> > (ii) 令 $f(x) = x$ ，即 $x - \left(a_{0} + a_{1}x + a_{2}x^{2} + a_{3}x^{3}\right) = 0$
> >
> > 即 $\left(x - 1\right)\left[a_3x^2 +\left(a_3 + a_2\right)x - a_0\right] = 0$
> >
> > 设 $g(x) = a_3x^2 + (a_3 + a_2)x - a_0$ ，由 $a_0, a_1, a_2, a_3 \in \mathbf{R}^*$
> >
> > 有 $\Delta=\left(a_{3}+a_{2}\right)^{2}+4a_{3}a_{0}>0$ ，故函数 $g(x)$ 必有两个不同零点，
> >
> > 设 $g(x_{1}) = g(x_{2}) = 0$ ，且 $x_{1} < x_{2}$ ，则 $x_{1}x_{2} = -\frac{a_{0}}{a_{3}} < 0$ ，故 $x_{1} < 0 < x_{2}$
> >
> > 又 $g(1) = a_{3} + a_{3} + a_{2} - a_{0} = 2a_{3} + a_{2} + a_{1} + a_{2} + a_{3} - 1 = 3a_{3} + 2a_{2} + a_{1} - 1\leq 0$
> >
> > 故 $x_{2}$ 1，则方程 $f(x) = x$ 的根有1、 $X_{1}$ 、 $x_{2}$ ，且 $x_{1} < 0 < 1 \leq x_{2}$ ，
> >
> > 故 $y = f(x)$ 的图象与直线 $y = x$ 在第一象限内离原点最近的交点的横坐标为1，即 $x_0 = 1$ .
