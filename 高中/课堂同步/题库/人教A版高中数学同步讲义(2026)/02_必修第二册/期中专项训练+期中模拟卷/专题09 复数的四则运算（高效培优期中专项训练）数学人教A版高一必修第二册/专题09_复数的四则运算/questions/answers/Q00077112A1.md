> [!faq]- 《专题09 复数的四则运算（高效培优期中专项训练）数学人教A版高一必修第二册》官方解析
>
> > [!success]- **【答案】** A. 只有纯虚数根 B. 只有实数根 C. 有两个实数根，两个纯虚数根 D. 既没有实数根，也没有纯虚数根
>
> > [!note]- **【解析】**
> > 解：因为关于 $x$ 的方程 $f(x) = 0$ 有纯虚数根，不妨设为 $x = m\mathrm{i}(m \neq 0, m \in R)$ 所以 $a(m\mathrm{i})^2 + b\mathrm{mi} + c = 0$ ，即 $-am^2 + b\mathrm{mi} + c = 0$ ，所以 $bm = 0, c = am^2$ ，所以 $b = 0, a \neq 0$ ， $a, c$ 同号，所以 $f(x) = ax^2 + c, (a \neq 0, a, c \in \mathbb{R})$ ，所以 $f(f(x)) = a(ax^2 + c)^2 + c = a(a^2x^4 + 2acx^2 + c^2) + c = a^3x^4 + 2a^2cx^2 + ac^2 + c = 0$ ，令 $x^2 = t - 0$ ，所以 $a^3t^2 + 2a^2ct + ac^2 + c = 0$ ，即因为 $\Delta = 4a^4c^2 - 4a^4c^2 - 4a^3c = -4a^3c = -4a^2 \cdot ac < 0$ ，所以 $x^2 = \frac{-2a^2c \pm \mathrm{i}\sqrt{4a^3c}}{2a^3} = \frac{-c \pm \mathrm{i}\sqrt{a^3c}}{a} = -\frac{c}{a} \pm \frac{\sqrt{a^3c}}{a}\mathrm{i}$ ，所以 $x$ 不可能为纯虚数，也不可能为实数，所以关于 $x$ 的方程 $f(f(x)) = 0$ 既没有实数根，也没有纯虚数根
> >
> > 故选 **D**
