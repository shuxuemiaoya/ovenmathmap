> [!faq]- 《专题07 正弦定理、余弦定理（高效培优期中专项训练）数学人教A版高一必修第二册》官方解析
>
> > [!success]- **【答案】** (1) $\frac{2\pi}{3}$ 或 $\frac{\pi}{3}$ (2) $\left[\sqrt{3},2\sqrt{3}\right)$
>
> > [!note]- **【解析】**
> > （1）解：因为 $2a\sin C - \sqrt{3} c = 0$ ，由正弦定理得 $2\sin A\sin C - \sqrt{3}\sin C = 0$
> >
> > 又因为 $C\in (0,\pi)$ ，可得 $\sin C > 0$ ，所以 $\sin A = \frac{\sqrt{3}}{2}$
> >
> > 因为 $A \in (0, \pi)$ ，所以 $A = \frac{2\pi}{3}$ 或 $A = \frac{\pi}{3}$ ，
> >
> > (2) 解：因为 $a = 2\sqrt{3}$ 且 $a \leq b$ ，所以 $A = \frac{\pi}{3}$ ，
> >
> > 由正弦定理得 $\frac{a}{\sin A} = 4$ ，所以 $b = 4\sin B$ ， $c = 4\sin C = 4\sin \left(B + \frac{\pi}{3}\right)$
> >
> > 则 $b - \frac{1}{2} c = 4\sin B - 2\sin \left(B + \frac{\pi}{3}\right) = 3\sin B - \sqrt{3}\cos B = 2\sqrt{3}\sin \left(B - \frac{\pi}{6}\right)$
> >
> > 又由 $a \leq b$ ，可得 $\frac{\pi}{3} \leq B < \frac{2\pi}{3}$ ，所以 $\frac{\pi}{6} \leq B - \frac{\pi}{6} < \frac{\pi}{2}$ ，可得 $\sin \left(B - \frac{\pi}{6}\right) \in [\frac{1}{2}, 1)$
> >
> > 则 $2\sqrt{3}\sin \left(B - \frac{\pi}{6}\right)\in \left[\sqrt{3},2\sqrt{3}\right)$ ，所以即 $b - \frac{c}{2}$ 的取值范围 $\left[\sqrt{3},2\sqrt{3}\right)$
> >
