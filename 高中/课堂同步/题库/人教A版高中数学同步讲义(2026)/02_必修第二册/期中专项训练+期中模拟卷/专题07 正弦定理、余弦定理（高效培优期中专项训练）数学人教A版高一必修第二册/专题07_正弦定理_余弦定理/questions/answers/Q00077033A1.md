> [!faq]- 《专题07 正弦定理、余弦定理（高效培优期中专项训练）数学人教A版高一必修第二册》官方解析
>
> > [!success]- **【答案】** (1) $B = \frac{\pi}{3}$ (2) $3\sqrt{3}$ (3) $\left(1,\frac{3}{2}\right]$
>
> > [!note]- **【解析】**
> > （1）∵在VABC中， $\frac{c}{a}=\frac{\sin A+2\sin B\cos A}{2\sin A}$ :
> >
> > 结合正弦定理可得： $\frac{\sin C}{\sin A} = \frac{\sin A + 2\sin B\cos A}{2\sin A}$
> >
> > 由 $A \in (0, \pi)$ 得 $\sin A > 0$ ， $\therefore 2\sin C = \sin A + 2\sin B\cos A$
> >
> > $\therefore 2\sin (A + B) = \sin A + 2\sin B\cos A, \therefore 2\sin A\cos B = \sin A$
> >
> > $$
> > \therefore \sin A (2 \cos B - 1) = 0 (\sin A > 0)
> > $$
> >
> > $\therefore \cos B = \frac{1}{2}$ ，又 $B\in (0,\pi)$ ，所以 $B = \frac{\pi}{3}$
> >
> > (2) 若选①：由 $BD$ 平分 $\angle ABC$ 得： $S_{\triangle ABC} = S_{\triangle ABD} + S_{\triangle BCD}$ ，
> >
> > $\therefore \frac{1}{2} ac\sin \frac{\pi}{3} = \frac{1}{2}\times 3a\sin \frac{\pi}{6} +\frac{1}{2}\times 3c\sin \frac{\pi}{6}$ ，即 $ac = \sqrt{3}(a + c)$
> >
> > 在 $\vee ABC$ 中，由余弦定理得 $b^{2} = a^{2} + c^{2} - 2ac\cos \frac{\pi}{3}$ ，则 $a^2 + c^2 - ac = 12$ ，
> >
> > 联立 $\left\{ \begin{array}{l} ac = \sqrt{3}(a + c) \\ a^2 + c^2 - ac = 12 \end{array} \right.$ ，得 $(ac)^2 - 9ac = 36$ ，解得 $ac = 12$ ，
> >
> > $$
> > \therefore S _ {\triangle A B C} = \frac {1}{2} a c \sin B = \frac {1}{2} \times 1 2 \times \frac {\sqrt {3}}{2} = 3 \sqrt {3}
> > $$
> >
> > 若选②：由题设 $\overline{BD}=\frac{1}{2}\left(\overline{BA}+\overline{BC}\right)$ ，则 $\overline{BD}^{2}=\frac{1}{4}\left(\overline{BA}+\overline{BC}\right)^{2}=\frac{1}{4}\left(\overline{BA}^{2}+2\overline{BA}\cdot\overline{BC}+\overline{BC}^{2}\right)$
> >
> > 所以 $a^{2}+c^{2}+ac=36$
> >
> > 在VABC中，由余弦定理得 $b^{2}=a^{2}+c^{2}-2ac\cos\frac{\pi}{3}$ ，则 $a^{2}+c^{2}-ac=12$ ，
> >
> > 联立 $\left\{ \begin{array}{l}a^2 +c^2 +ac = 36\\ a^2 +c^2 -ac = 12 \end{array} \right.$ ，得 $ac = 12$
> >
> > $$
> > \therefore S _ {\triangle A B C} = \frac {1}{2} a c \sin B = \frac {1}{2} \times 1 2 \times \frac {\sqrt {3}}{2} = 3 \sqrt {3}
> > $$
> >
> > (3) 由正弦定理得 $2R = \frac{b}{\sin B} = \frac{\sqrt{3}}{\frac{\sqrt{3}}{2}} = 2$ ，
> >
> > 故 $ac = 4R^2\sin A\sin C = 4\sin A\sin C = 2[\cos (A - C) - \cos (A + C)] = 2\cos (A - (\pi -A - B)) - 2\cos (\pi -B)$ $= -2\cos \left(2A + \frac{\pi}{3}\right) + 1,$
> >
> > 由于 为锐角三角形，故 $\left\{ \begin{array}{l}0 < A < \frac{\pi}{2}\\ 0 < \frac{2\pi}{3} -A < \frac{\pi}{2} \end{array} \right.$ 故 $2A + \frac{\pi}{3}\in \left(\frac{2\pi}{3},\frac{4\pi}{3}\right)$
> >
> > 故当 $2A + \frac{\pi}{3} = \pi$ ，即 $A = \frac{\pi}{3}$ 时，此时 $ac = -2\cos \left(2A + \frac{\pi}{3}\right) + 1$ 取到最大值3，
> >
> > 当 $2A + \frac{\pi}{3} = \frac{2\pi}{3}$ 或 $\frac{4\pi}{3}$ ，即 $A = \frac{\pi}{6}$ 或 $\frac{\pi}{2}$ 时，此时 $-2\cos \left(2A + \frac{\pi}{3}\right) + 2 = 2$
> >
> > 因此 $2 < ac \leq 3$
> >
> > 故三角形的面积为 $S_{\triangle ABC} = \frac{1}{2} ac \sin B = \frac{\sqrt{3}}{4} ac$ ，
> >
> > 故边上的高为， $h = \frac{S_{\triangle ABC}}{\frac{1}{2}b} = \frac{1}{2} ac\in \left(1,\frac{3}{2}\right]$
