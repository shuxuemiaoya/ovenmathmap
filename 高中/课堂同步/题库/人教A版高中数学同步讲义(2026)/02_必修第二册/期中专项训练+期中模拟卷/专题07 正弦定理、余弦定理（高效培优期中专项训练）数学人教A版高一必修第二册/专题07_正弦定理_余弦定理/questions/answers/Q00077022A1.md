> [!faq]- 《专题07 正弦定理、余弦定理（高效培优期中专项训练）数学人教A版高一必修第二册》官方解析
>
> > [!success]- **【答案】** BC
>
> > [!note]- **【解析】**
> > 对 $^{A}$ ：由 $\left\{\begin{aligned}&b>a\\&b\sin A=\sqrt{3}\sin45^{\circ}=\frac{\sqrt{6}}{2}<\sqrt{2}\end{aligned}\right.$ ，所以有两解，故 $^{A}$ 错误；
> >
> > 对 B：由余弦定理： $c^{2}=a^{2}+b^{2}-2ab\cos C>a^{2}+b^{2}\Rightarrow\cos C<0$
> >
> > 所以 C 为钝角，即 $\forall ABC$ 为钝角三角形，故 B 正确；
> >
> > 对 $C$ ：因为三角形 $\vee ABC$ 为锐角三角形，
> >
> > 所以 $A + B > 90^{\circ} \Rightarrow 90^{\circ} - B < A < 90^{\circ} \Rightarrow \sin(90^{\circ} - B) < \sin A$
> >
> > 即 $\cos B < \sin A$ ，故 C 正确；
> >
> > 对 D：因为 $\frac{a}{\cos B} = \frac{b}{\cos A}$ ，由正弦定理得： $\frac{\sin A}{\cos B} = \frac{\sin B}{\cos A}$ ，
> >
> > 则 $\sin A\cos A = \sin B\cos B$ ，所以 $\sin 2A = \sin 2B$
> >
> > 所以 $2A = 2B$ 或 $2A + 2B = 180^{\circ}$ ，即 A = B 或 $A + B = 90^{\circ}$ ，
> >
> > 所以 $\forall ABC$ 为等腰或直角三角形，故 $^{\mathrm{D}}$ 错误.
> >
> > 故选 **BC**.
