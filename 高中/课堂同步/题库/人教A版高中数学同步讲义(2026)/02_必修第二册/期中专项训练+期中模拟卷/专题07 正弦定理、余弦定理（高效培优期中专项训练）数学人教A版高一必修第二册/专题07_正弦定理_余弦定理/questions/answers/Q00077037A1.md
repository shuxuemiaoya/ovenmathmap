> [!faq]- 《专题07 正弦定理、余弦定理（高效培优期中专项训练）数学人教A版高一必修第二册》官方解析
>
> > [!success]- **【答案】** (1) $-\frac{5}{16}$ (2)247.4 米 (3) $BD = 100\sqrt{5}$ 米， $AB = AD = 100\sqrt{5}$ 米， $C = \frac{\pi}{2}$
>
> > [!note]- **【解析】**
> > （1）由余弦定理得， $\cos \angle BCD = \frac{100^2 + 2000^2 - 250^2}{2 \times 100 \times 200} = -\frac{5}{16}$
> >
> > (2) $S_{\triangle BCD} = \frac{1}{2} BC \cdot CD \cdot \sin C = \frac{1}{2} \times 100 \times 200 \times \sin C = 9600$ ，解得 $\sin C = \frac{24}{25}$
> >
> > 又 C 为钝角，所以 $\cos C = \sqrt{1 - \sin^{2} C} = -\frac{7}{25}$
> >
> > 由余弦定理得， $BD=\sqrt{BC^{2}+CD^{2}-2BC\cdot CD\cdot\cos C}$
> >
> > $$
> > = \sqrt {1 0 0 ^ {2} + 2 0 0 ^ {2} - 2 \times 1 0 0 \times 2 0 0 \times \left(- \frac {7}{2 5}\right)} = 6 0 \sqrt {1 7} \approx 2 4 7. 4 \text {米}
> > $$
> >
> > (3) $S_{\triangle BCD} = \frac{1}{2} BC \cdot CD \cdot \sin C \leq \frac{1}{2} BC \cdot CD = 10000$ ，当且仅当 $C = \frac{\pi}{2}$ 时等号成立，
> >
> > 此时， $BD = \sqrt{100^2 + 200^2} = 100\sqrt{5}$
> >
> > 设 $\angle ABD = \alpha, \alpha \in \left(0, \frac{2\pi}{3}\right)$
> >
> > 在 $\triangle ABD$ 中，由正弦定理得， $\frac{AD}{\sin\alpha} = \frac{AB}{\sin\left(\frac{2\pi}{3} - \alpha\right)} = \frac{100\sqrt{5}}{\sin\frac{\pi}{3}} = \frac{200}{3}\sqrt{15}$
> >
> > $$
> > S _ {\triangle A B D} = \frac {1}{2} A D \cdot A B \cdot \sin A = \frac {1 0 0 0 0 0}{3} \sin \alpha \sin \left(\frac {2 \pi}{3} - \alpha\right)
> > $$
> >
> > $$
> > = \frac {5 0 0 0 0}{3} \left[ \frac {1}{2} + \cos \left(2 \alpha - \frac {2 \pi}{3}\right) \right] \leq \frac {5 0 0 0 0}{3} \times \left(\frac {1}{2} + 1\right) = 2 5 0 0 0
> > $$
> >
> > 当且仅当 $2a - \frac{2\pi}{3} = 0$ ，即 $\alpha = \frac{\pi}{3}$ 时等号成立，
> >
> > 此时 $AB = AD = 100\sqrt{5}$ ， $C = \frac{\pi}{2}$
> >
> > 所以应设计 $BD = 100\sqrt{5}$ 米， $AB = AD = 100\sqrt{5}$ 米， $C = \frac{\pi}{2}$
