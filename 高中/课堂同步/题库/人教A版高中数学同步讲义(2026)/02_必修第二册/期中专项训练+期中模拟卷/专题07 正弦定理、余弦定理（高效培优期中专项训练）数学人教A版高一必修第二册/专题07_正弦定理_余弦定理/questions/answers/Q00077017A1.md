> [!faq]- 《专题07 正弦定理、余弦定理（高效培优期中专项训练）数学人教A版高一必修第二册》官方解析
>
> > [!success]- **【答案】** (1) $B=\frac{\pi}{3}$ (2) $R = 2\sqrt{2}, c = 4$
>
> > [!note]- **【解析】**
> > （1）在 $\forall ABC$ 中，由 $\sin^2 A + \sin^2 B - \sin^2 C = \sqrt{2}\sin A\sin B$ 及正弦定理，得 $a^2 + b^2 - c^2 = \sqrt{2}ab$
> >
> > 由余弦定理得 $\cos C = \frac{a^2 + b^2 - c^2}{2ab} = \frac{\sqrt{2}ab}{2ab} = \frac{\sqrt{2}}{2}$ ，而 $0 < C < \pi$ ，解得 $C = \frac{\pi}{4}$ ，
> >
> > 由 $\cos B = \frac{\sqrt{2}}{2}\sin C$ ，得 $\cos B = \frac{1}{2}$ ，而 $0 < B < \pi$ ，所以 $B = \frac{\pi}{3}$ .
> >
> > (2) 由 (1) 得 $\sin A = \sin (B + C) = \sin B\cos C + \cos B\sin C = \frac{\sqrt{2}}{2} (\frac{\sqrt{3}}{2} +\frac{1}{2}) = \frac{\sqrt{6} + \sqrt{2}}{2}$
> >
> > 由正弦定理得 $b = 2R\sin B = \sqrt{3} R$ ， $c = 2R\sin C = \sqrt{2} R$
> >
> > 由 $S_{\triangle ABC} = \frac{1}{2} bc\sin A = 6 + 2\sqrt{3}$ ，得 $\frac{1}{2}\cdot \sqrt{3} R\cdot \sqrt{2} R\cdot \sin \frac{5\pi}{12} = 6 + 2\sqrt{3}$
> >
> > 即 $\frac{\sqrt{6}R^2}{2}\cdot \frac{\sqrt{6} + \sqrt{2}}{4} = 6 + 2\sqrt{3}$ ，所以 $R = 2\sqrt{2}$ ， $c = \sqrt{2} R = 4$
