> [!faq]- 《专题07 正弦定理、余弦定理（高效培优期中专项训练）数学人教A版高一必修第二册》官方解析
>
> > [!success]- **【答案】** A．若 $\forall ABC$ 为锐角三角形，则 $a,b,c$ 可以分别是3，4，6 B．若 $A = \frac{\pi}{6}$ ， $a = \sqrt{3}$ ，该三角形只有一解，则 $0 < b \leq \sqrt{3}$ C．若 $B=\frac{\pi}{3}$ ，b=2，则 $\vee ABC$ 面积的最大值为 $\sqrt{3}$ D．若 $\cos A - \cos B + \frac{a - b}{c} = 0$ ，则 $\bigvee ABC$ 为等腰三角形
>
> > [!note]- **【解析】**
> > 对于 A，易知 C 为最大角， $\cos C = \frac{a^{2} + b^{2} - c^{2}}{2ab} = \frac{9 + 16 - 36}{2 \times 3 \times 4} < 0$ ，即 $C > \frac{\pi}{2}$ ，则 VABC 不是锐角三
> >
> > 角形，A选项错误·
> >
> > 对于 $^{B}$ ，因为 $\bigvee ABC$ 只有一解，所以 $\sin B=1$ 或 $\left\{\begin{aligned}\sin B&<1\\ b&\leq a\end{aligned}\right.$ ，
> >
> > 当 $\sin B = 1$ 时，即 $\frac{b}{a}\sin A = \frac{b}{\sqrt{3}}\times \frac{1}{2} = 1$ ，解得 $b = 2\sqrt{3}$
> >
> > 当 $\left\{ \begin{array}{l} \sin B < 1 \\ b \leq a \end{array} \right.$ 即 $\left\{ \begin{array}{l} \sin B = \frac{b}{a} \sin A = \frac{b}{\sqrt{3}} \times \frac{1}{2} < 1 \\ b \leq \sqrt{3} \\ 0 < b \leq \sqrt{3} \end{array} \right.$ ，得
> >
> > 综上 $0 < b \leq \sqrt{3}$ 或 $b = 2\sqrt{3}$ ，B选项错误
> >
> > 对于 C，在 $\bigvee ABC$ 中，由正弦定理得， $S_{\triangle ABC} = \frac{1}{2} ac \sin B = \frac{1}{2} \cdot \frac{\sqrt{3}}{2} ac = \frac{\sqrt{3}}{4} ac$ ，
> >
> > 由余弦定理得， $\cos B=\frac{a^{2}+c^{2}-b^{2}}{2ac}=\frac{1}{2}$ ，即 $a^{2}+c^{2}-4=ac\quad2ac-4$ ，有 $ac\leq4$ ，
> >
> > 当且仅当 $a = c = 2$ 时等号成立，所以 $\left(S_{\triangle ABC}\right)_{\max} = \frac{\sqrt{3}}{4}\times 4 = \sqrt{3}$ ，C选项正确·
> >
> > 对于 $\mathrm{D}$ ， $\cos A - \cos B + \frac{a - b}{c} = 0$ ，在 $\bigvee ABC$ 中，由余弦定理可得， $\frac{b^2 + c^2 - a^2}{2bc} -\frac{a^2 + c^2 - b^2}{2ac} +\frac{a - b}{c} = 0$
> >
> > 等式两边同乘 $abc$ ，经整理得， $a^2 b - a^3 + b^3 - ab^2 + ac^2 - bc^2 = 0$
> >
> > 即 $a^2 (b - a) + b^2 (b - a) = c^2 (b - a)$ ，则有，
> > - **①**：b - a = 0 ，即 b = a ，所以 $\bigvee ABC$ 为等腰三角形；
> > - **②**：$b-a\neq0$ ，则 $a^{2}+b^{2}=c^{2}$ ，即VABC为直角三角形.
> >
> > 综上， $\forall ABC$ 为等腰三角形或直角三角形，所以， $D$ 选项错误
> >
> > 故选 **ABD**
