> [!faq]- 《专题07 正弦定理、余弦定理（高效培优期中专项训练）数学人教A版高一必修第二册》官方解析
>
> > [!success]- **【答案】** (1) $\sqrt{2} + 1$ (2)证明见解析 (3)最小值为 $\sqrt{2} + 1$ ，无最大值·
>
> > [!note]- **【解析】**
> > （1）由 $\vee ABC$ 为等腰直角三角形，设直角边长为 $a$ ，则斜边长为 $\sqrt{2} a$
> >
> > 所以 $\bigvee ABC$ 外接圆的半径为 $R = \frac{\sqrt{2}a}{2}$ ，且 $\bigvee ABC$ 的周长为 $l = 2a + \sqrt{2}a$ ，
> >
> > 则 $\frac{1}{2} a^2 = \frac{1}{2} (2a + \sqrt{2} a)r$ ，可得 $r = \frac{a}{2 + \sqrt{2}}$
> >
> > 所以 $f=\frac{R}{r}=\frac{\frac{\sqrt{2}a}{2}}{\frac{a}{2+\sqrt{2}}}=\sqrt{2}+1$ .
> >
> > (2) 由正弦定理 $\frac{a}{\sin A} = \frac{b}{\sin B} = \frac{c}{\sin C} = 2R$ ，即 $a = 2R\sin A, b = 2R\sin B, c = 2R\sin C$
> >
> > 又由 $\vee ABC$ 得面积为 $S = \frac{1}{2} ab\sin C = 2R^2\sin A\sin B\sin C$
> >
> > 且 $\forall ABC$ 的周长为 $l = 2R(\sin A + \sin B + \sin C)$
> >
> > 因为 $S = \frac{1}{2} lr$ ，可得 $2R^{2}\sin A\sin B\sin C = \frac{1}{2}\times 2R(\sin A + \sin B + \sin C)\cdot r$
> >
> > 即 $2R \sin A \sin B \sin C = (\sin A + \sin B + \sin C) \cdot r$
> >
> > 所以 $f=\frac{R}{r}=\frac{\sin A+\sin B+\sin C}{2\sin A\sin B\sin C}$ .
> >
> > （3）由 $\cos 2A + \cos 2B = 1 + \cos 2C$ ，可得 $2\cos \frac{2A + 2B}{2}\cos \frac{2A - 2B}{2} = 2\cos^2 C$
> >
> > 即 $\cos (A + B)\cos (A - B) = \cos^2 C$
> >
> > 因为 $A + B + C = \pi$ ，可得 $\cos(A + B) = -\cos C$ ，所以 $-\cos C \cos(A - B) = \cos^{2} C$ ，
> >
> > 即 $\cos C[\cos C + \cos (A - B)] = 0$ ，可得 $\cos C = 0$ 或 $\cos (A - B) = -\cos C$
> >
> > 当 $\cos (A - B) = -\cos C$ ，即 $\cos (A - B) = \cos (A + B)$
> >
> > 即 $\cos A\cos B + \sin A\sin B = \cos A\cos B - \sin A\sin B$ ，可得 $2\sin A\sin B = 0$
> >
> > 因为 $0 < A, B < \pi$ ，所以 $2\sin A\sin B > 0$ ，不符合题意（舍去），
> >
> > 所以 $\cos C = 0$ ，由 $0 < C < \pi$ ，可得 $C = \frac{\pi}{2}$ ，即 $\vee ABC$ 为直角三角形，
> >
> > 由（2）知 $f = \frac{R}{r} = \frac{\sin A + \sin B + 1}{2\sin A\sin B} = \frac{\sin A + \cos A + 1}{2\sin A\cos A}$ ，
> >
> > 设 $t = \sin A + \cos A = \sqrt{2}\sin (A + \frac{\pi}{4})$ ，则 $2\sin A\cos A = t^2 -1$
> >
> > 因为 $0 < A < \frac{\pi}{2}$ ，可得 $\frac{\pi}{4} < A + \frac{\pi}{4} < \frac{3\pi}{4}$ ，可得 $t \in (1, \sqrt{2}]$ ，所以 $g(t)=\frac{t+1}{t^{2}-1}=\frac{1}{t-1}$ 在区间 $(1,\sqrt{2}]$ 为单调递减函数，
> > 可得 $g(t)_{\min}=g(\sqrt{2})=\sqrt{2}+1$ ，且当 $t\to1$ 时， $g(t)\to+\infty$ ，
> > 所以 f 的最小值为 $g(t)_{\min} = \sqrt{2} + 1$ ，无最大值。
> >
