> > 29. 复数平面内表示复数 $z = (m^2 - 8m + 15) + (m^2 - 5m - 14)\mathrm{i}$ 的点分别满足下列条件：
> >
> > (1)位于第四象限；
> >
> > (2)位于第一象限或第三象限；
> >
> > (3)位于直线 $y = x$ 上．求实数 $m$ 的取值范围．
> >
> > 【答案】(1) $-2 < m < 3$ 或 $5 < m < 7$
> >
> > (2) $m < -2$ 或 $3 < m < 5$ 或 $m > 7$
> >
> > (3) $m=\frac{29}{3}$
> >
> > 【详解】（1）由题意，复数 $z$ 在复平面内对应的点为 $\left(m^2 - 8m + 15, m^2 - 5m - 14\right)$
> >
> > 当点位于第四象限时，则 $\left\{ \begin{array}{l} m^2 - 8m + 15 > 0 \\ m^2 - 5m - 14 < 0 \end{array} \right.$ ，即 $\left\{ \begin{array}{l} m > 5 \text{或} m < 3 \\ -2 < m < 7 \end{array} \right.$ ，
> >
> > 故-2<m<3或5<m<7；
> >
> > (2) 当点位于第一象限或第三象限时，
> >
> > 则 $\left(m^{2}-8m+15\right)\left(m^{2}-5m-14\right)>0$
> >
> > 即 $(m-3)(m-5)(m-7)(m+2)>0$
> >
> > 故 $m < -2$ 或 $3 < m < 5$ 或 $m > 7$
> >
> > （3）当点位于直线 $y = x$ 上，则 $m^2 - 8m + 15 = m^2 - 5m - 14$ ，解得 $m = \frac{29}{3}$

> > 30. 复数 $z = (m^2 - m - 2) + m(m + 1)\mathrm{i}$ .
> >
> > (1)若复数 z 是实数，求实数 m 的值；
> >
> > (2)若复数 $z$ 是纯虚数，求实数 $m$ 的值；
> >
> > (3)在复平面内，复数 $z$ 对应的点位于第三象限，求实数 $m$ 的取值范围·
> >
> > 【答案】(1) $m = 0$ 或 $m = -1$
> >
> > (2) $m = 2$
> >
> > (3) $(-1,0)$
> >
> > 【详解】（1）因为复数 $z$ 是实数，
> >
> > 所以 $m(m+1)=0$ ，
> >
> > 解得 m = 0 或 m = -1 ;
> >
> > (2) 因为复数 $z$ 是纯虚数
> >
> > 所以 $\left\{\begin{aligned}m^{2}-m-2&=0\\ m(m+1)&\neq0\end{aligned}\right.$
> >
> > 所以 $\left\{\begin{aligned}m&=2\text{或}m=-1\\ m&\neq0\text{且}m\neq-1\end{aligned}\right.$
> >
> > 解得 $m = 2$
> >
> > (3) 因为复数 z 对应的点位于第三象限，
> >
> > 所以 $\left\{ \begin{array}{l} m^2 - m - 2 < 0 \\ m(m + 1) < 0 \end{array} \right.$
> >
> > 所以 $\left\{ \begin{array}{l} -1 < m < 2 \\ -1 < m < 0 \end{array} \right.$
> >
> > 解得 m 的取值范围是 $(-1,0)$
