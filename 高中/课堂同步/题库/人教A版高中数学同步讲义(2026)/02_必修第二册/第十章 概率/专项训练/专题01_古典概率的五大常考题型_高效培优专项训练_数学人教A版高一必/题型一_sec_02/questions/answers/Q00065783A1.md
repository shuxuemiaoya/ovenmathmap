> [!faq]- 《专题01_古典概率的五大常考题型_高效培优专项训练_数学人教A版高一必》官方解析
>
> > [!success]- **【答案】** (1)答案见解析 (2)答案见解析
>
> > [!note]- **【分析】**
> > （1）通过不放回列举样本空间和满足随机事件的样本空间，即可求出相应概率；
> >
> > (2) 通过有放回列举样本空间和满足随机事件的样本空间，即可求出相应概率.
>
> > [!note]- **【解析】**
> > （1）若标签的选取是不放回的，则样本空间 $\Omega_{1}$ 为：
> >
> > $\Omega_{1} = \left\{\left(1,2\right)\left(1,3\right)\left(1,5\right)\left(2,1\right)\left(2,3\right)\left(2,5\right),\left(3,1\right)\left(3,2\right)\left(3,5\right)\left(5,1\right)\left(5,2\right)\left(5,3\right)\right\}$
> >
> > 共12种等可能情形，
> >
> > 满足 $m + n > 5$ 的有： $\left\{\left(1,5\right)\left(2,5\right)\left(3,5\right)\left(5,1\right)\left(5,2\right)\left(5,3\right)\right\}$ ，共6种情形，
> >
> > 所以满足 $m + n > 5$ 的概率为 $P_{1} = \frac{6}{12} = \frac{1}{2}$
> >
> > (2) 若标签的选取是有放回的，则样本空间 $\Omega_{2}$ 为：
> >
> > $\Omega_{2} = \left\{\left(11\right)(1,2)\left(1,3\right)\left(1,5\right)\left(2,1\right)\left(2,3\right)\left(2,5\right),\left(3,1\right)\left(3,2\right)\left(3,5\right)\left(5,1\right)\left(5,2\right)\left(5,3\right)\left(5,5\right)\right\}$
> >
> > 共 16 种等可能情形，
> >
> > 满足 $m < n$ 的有： $\left\{\left(1,2\right)\left(1,3\right)\left(1,5\right)\left(2,3\right)\left(2,5\right),\left(3,5\right)\right\}$ ，共6种情形，
> >
> > 所以满足 $m < n$ 的概率 $P_{2} = \frac{6}{16} = \frac{3}{8}$ .

> > 2．投掷两枚质地均匀的骰子，正面朝上的点数分别记为 m、n，则能使 mn $3m + n$ 成立的数对 $(m, n)$ 共有\_对.
> >
> > 【答案】12
> >

> > 3．掷一枚骰子，记事件 A=“出现奇数点”，事件 B=“出现 4 点或 5 点”，事件 C=“点数不超过 3”。写出事件 $A \cup B$ 所包含的样本点：\_\_\_\_，事件 $A \cap C$ 所包含的样本点：\_\_\_\_。
> >
> > 【答案】 1,3,4,5 1,3
> >
> > 【分析】先求出各个事件的样本点，再利用交事件和并事件的性质求解即可.
> > 【详解】由题得 $A = \{1, 3, 5\}$ ， $B = \{4, 5\}$ ， $C = \{1, 2, 3\}$ ，
> > 则 $A \cup B = \{1, 3, 4, 5\}$ ， $A \cap C = \{1, 3\}$ .
> > 故答案为：1,3,4,5；1,3
