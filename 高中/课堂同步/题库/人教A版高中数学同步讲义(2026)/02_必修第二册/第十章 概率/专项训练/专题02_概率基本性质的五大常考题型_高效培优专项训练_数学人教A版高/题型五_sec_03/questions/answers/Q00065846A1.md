> [!faq]- 《专题02_概率基本性质的五大常考题型_高效培优专项训练_数学人教A版高》官方解析
>
> > [!success]- **【答案】** (1) $\frac{1}{6}$ (2) $\frac{11}{72}$
>
> > [!note]- **【分析】**
> > （1）利用相互独立事件概率乘法公式，再结合互斥事件加法公式即可求解；
> >
> > (2) 先求甲乙两人分别没通过面试的概率，再利用对立事件，即可得到甲乙两人分别通过面试的概率，然后利用两人中仅有一人通过，结合两相互独立事件概率乘法公式即可求解.
>
> > [!note]- **【解析】**
> > （1）设 $A_{1}$ = “甲答对 3 道题目”， $A_{2}$ = “甲答对 2 道题目”
> >
> > $B_{1} =$ “乙答对3道题目”， $B_{2} =$ “乙答对2道题目”，根据独立事件的性质，可得，
> >
> > $P(A_{1}) = \frac{2}{3}\times \frac{2}{3}\times \frac{2}{3} = \frac{8}{27},\quad P(A_{2}) = 3\times \frac{2}{3}\times \frac{2}{3}\times \frac{1}{3} = \frac{4}{9},$
> >
> > $P(B_{1}) = \frac{1}{2}\times \frac{1}{2}\times \frac{1}{2} = \frac{1}{8},\quad P(B_{2}) = 3(\frac{1}{2})^{3} = \frac{3}{8},$
> >
> > 设 A 为 “甲、乙两人共答对 5 道题目”，
> >
> > 则 $A = (A_{1}B_{2})\cup (A_{2}B_{1})$ ，因为 $A_{1}B_{2}$ 与 $A_{2}B_{1}$ 互斥， $A_{1}$ 与 $B_{2}$ ， $A_{2}$ 与 $B_{1}$ 分别相互独立， $P(A) = P(A_1B_2) + P(A_2B_1)$ $= P(A_{1})P(B_{2}) + P(A_{2})P(B_{1}) = \frac{8}{27}\times \frac{3}{8} +\frac{4}{9}\times \frac{1}{8} = \frac{1}{6}$ 所以甲、乙两人共答对5道题目的概率 $\frac{1}{6}$ ：
> >
> > (2) $C =$ “甲通过面试”， $D =$ “乙通过面试”， $C$ 与 $D$ 相互独立， $P(C) = 1 - P(\overline{C}) = 1 - \frac{1}{3} \times \frac{1}{3} \times \frac{1}{3} = \frac{26}{27}$ ， $P(D) = 1 - P(\overline{D}) = 1 - \frac{1}{2} \times \frac{1}{2} \times \frac{1}{2} = \frac{7}{8}$ $E =$ “甲、乙两人只有一人通过面试”，则 $E = (C\overline{D}) \cup (\overline{C}D)$ ，因为 $C\overline{D}$ 与 $\overline{C}D$ 互斥， $C$ 与 $\overline{D}$ ， $\overline{C}$ 与 $D$ 分别相互独立， $P(E) = P(C\overline{D} \cup \overline{C}D) = P(C\overline{D}) + P(\overline{C}D) = P(C)P(\overline{D}) + P(\overline{C})P(D)$ $= \frac{26}{27} \times \frac{1}{8} + \frac{1}{27} \times \frac{7}{8} = \frac{11}{72}$ 所以甲、乙两人只有一人通过面试的概率 $\frac{11}{72}$
