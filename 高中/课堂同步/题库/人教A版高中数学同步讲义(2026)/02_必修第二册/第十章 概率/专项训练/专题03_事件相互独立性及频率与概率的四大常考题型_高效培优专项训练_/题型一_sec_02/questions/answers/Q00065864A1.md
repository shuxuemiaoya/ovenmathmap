> [!faq]- 《专题03_事件相互独立性及频率与概率的四大常考题型_高效培优专项训练_》官方解析
>
> > [!success]- **【答案】** A. $P(D)=\frac{1}{5}$ B. 事件A与事件C相互独立 C. 事件A与事件E相互独立 D. 事件A与事件B相互独立
>
> > [!note]- **【分析】**
> > 求出事件 A, B, C, D, E 的概率，再根据相互独立事件概率的关系依次判断每个选项得到答案。
>
> > [!note]- **【解析】**
> > 根据题意， $P(A)=\frac{2}{6}=\frac{1}{3}$ ， $P(B)=\frac{3}{6}\times\frac{3}{5}+\frac{3}{6}\times\frac{2}{5}=\frac{1}{2}$ ， $P(C)=\frac{1}{6}$ ， $P(E)=1-\frac{5}{6}\times\frac{5}{6}=\frac{11}{36}$ ，
> > 对于 A，由于是不放回的取球，则 $P(D)=\frac{3\times2}{6\times5}=\frac{1}{5}$ ，故 A 正确；
> > 对于 B，因为 $P(AC)=\frac{10}{180}=\frac{1}{18}=P(A)P(C)$ ，所以事件 A 与 C 相互独立，故 B 正确；
> > 对于 C，因为 $P(AE)=\frac{7}{36}\neq P(A)P(E)$ ，所以事件 A 与 E 不相互独立，故 C 错误；
> > 对于 D，因为 $P(AB)=\frac{5}{30}=\frac{1}{6}=P(A)P(B)$ ，所以事件 A 与 B 相互独立，故 D 正确.
> >
> > 故选：ABD.
> >
> > 20．连续抛掷一枚质地均匀的硬币 n 次，记录这 n 次实验的结果。设事件 M 表示“n 次实验结果中，既出现正面又出现反面”，事件 N 表示“n 次实验结果中，至多出现一次正面”，则下列结论正确的有（）。
> >
> > 【答案】
> > A．若 n=2，则 M 与 N 互斥
> > B．若 n=2，则 M 与 N 不相互独立
> > C．若 n=3，则 M 与 N 不互斥
> > D．若 n=3，则 M 与 N 相互独立
> >
> > 【答案】BCD
> >
> > 【分析】依次写出 n=2 和 n=3 时样本总空间、事件 M, N, MN 的样本空间，以及利用古典概型求出相应的概率 $P(M), P(N), P(MN)$ ，再结合互斥事件和独立事件定义分析即可得解.
> >
> > 【详解】记抛掷一枚硬币正面向上为 1，反面向上为 0，
> >
> > 则连续抛掷一枚硬币两次的样本空间为 $\Omega_{1}=\left\{11,10,01,00\right\}$
> >
> > 此时事件 $M$ 的样本空间为 $\{10,01\}$ ，事件 $N$ 的样本空间为 $\{10,01,00\}$ ，
> >
> > 积事件 MN 的样本空间为 $\{10,01\}$
> >
> > 所以事件 M, N 交集不空，不互斥，且 $P(M) = \frac{1}{2}$ , $P(N) = \frac{3}{4}$ , $P(MN) = \frac{1}{2}$
> >
> > 所以 $P(MN) \neq P(M)P(N)$ ，故 $M$ 与 $N$ 不相互独立，故A错误，B正确；
> >
> > 连续抛掷一枚硬币3次的样本空间为 $\Omega_{2} = \{111,110,101,011,100,010,001,000\}$ 共8个样本点，
> >
> > 此时事件 $M$ 的样本空间为 $\{110, 101, 011, 100, 010, 001\}$ 共6个样本点，
> >
> > 事件 N 的样本空间为 $\{100,010,001,000\}$ 共 4 个样本点，
> >
> > 积事件 MN 的样本空间为 $\{100,010,001\}$
> >
> > 所以事件 M, N 的交集不空，不互斥，且 $P(M) = \frac{3}{4}, P(N) = \frac{1}{2}, P(MN) = \frac{3}{8}$
> >
> > 所以 $P(MN) = P(M)P(N)$ ，故 $M$ 与 $N$ 相互独立，故CD正确；
> >
> > 故选 **BCD**
