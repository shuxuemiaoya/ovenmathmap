> [!faq]- 《专题10.3 频率与概率（高效培优讲义）数学人教A版高一必修第二册》官方解析
>
> > [!success]- **【答案】** (1)结论 A 正确，结论 B 错误； (2) $\frac{13}{32}$ (3) $s_1^2 = s_2^2$
>
> > [!note]- **【分析】**
> > （1）结合题干利用样本中选择足球的人数的比例，可以判断结论 $A$ ；根据容斥原理，可以判断结论 $B$ .
> >
> > (2) 利用全概率公式求解选择排球课的人数为 $^{2}$ 的概率即可；
> >
> > (3) 根据题意可知 $y_{1} = 1 - x_{1}, y_{2} = 1 - x_{2}, y_{3} = 1 - x_{3}, y_{4} = 1 - x_{4}$ ，结合方差的定义得到两者方差相等。
>
> > [!note]- **【解析】**
> > （1）由题意可知，选择足球课的频率为 $\frac{80}{180} = \frac{4}{9}$
> >
> > 则全校高一学生有选择足球课的意愿的人数为 $\frac{4}{9} \times 1800 = 800$ ，故结论 $A$ 正确；
> >
> > 设不选择排球的男生集合为 M ，不选择篮球的男生集合为 N ，
> >
> > 则集合 $M$ 和 $N$ 中的人数分别为 $\left|M\right| = 50$ ， $\left|N\right| = 75$ ，都不选择的人数为 $\left|M\cap N\right|$
> >
> > 根据 $\left|M\cap N\right|=\left|M\right|+\left|N\right|-\left|M\cup N\right|$ 且 $\left|M\cup N\right|\leq100$
> >
> > 可得 $\left|M\cap N\right|$ 50+75-100=25
> >
> > 所以都不选择的人数至少为 25 人，故结论 B 错误·
> >
> > (2) 由题意可知，男生选择排球课的概率为 $\frac{50}{100} = \frac{1}{2}$ ，女生选择排球课的概率为 $\frac{50}{80} = \frac{5}{8}$
> >
> > 假设 X 表示 $^{3}$ 人中选择排球课的人数，则选择排球课的人数恰为 $^{2}$ 的概率
> >
> > $$
> > P (X = 2) = \left(\frac {1}{2}\right) ^ {2} \times \left(1 - \frac {5}{8}\right) + 2 \times \left(\frac {1}{2}\right) \times \left(1 - \frac {1}{2}\right) \times \frac {5}{8} = \frac {1 3}{3 2}.
> > $$
> >
> > (3) 由题意知， $y_{1}=1-x_{1},y_{2}=1-x_{2},y_{3}=1-x_{3},y_{4}=1-x_{4}$
> >
> > 设男生选择和不选择这四个活动课的平均值分别为 $\overline{x},\overline{y}$
> >
> > $$
> > \text {则} \overline {{y}} = 1 0 0 \cdot \frac {1 - x _ {1} + 1 - x _ {2} + 1 - x _ {3} + 1 - x _ {4}}{4} = 1 0 0 - 1 0 0 \cdot \frac {x _ {1} + x _ {2} + x _ {3} + x _ {4}}{4} = 1 0 0 - \overline {{x}}
> > $$
> >
> > 根据方差定义可得
> >
> > $$
> > s _ {2} ^ {2} = \frac {\left[ 1 0 0 - 1 0 0 x _ {1} - (1 0 0 - \bar {x}) \right] ^ {2} + \left[ 1 0 0 - 1 0 0 x _ {2} - (1 0 0 - \bar {x}) \right] ^ {2} + \left[ 1 0 0 - 1 0 0 x _ {3} - (1 0 0 - \bar {x}) \right] ^ {2} + \left[ 1 0 0 - 1 0 0 x _ {4} - (1 0 0 - \bar {x}) \right] ^ {2}}{4}
> > $$
> >
> > $$
> > = \frac {\left(- 1 0 0 x _ {1} + \bar {x}\right) ^ {2} + \left(- 1 0 0 x _ {2} + \bar {x}\right) ^ {2} + \left(- 1 0 0 x _ {3} + \bar {x}\right) ^ {2} + \left(- 1 0 0 x _ {4} + \bar {x}\right) ^ {2}}{4}
> > $$
> >
> > $$
> > = \frac {\left(1 0 0 x _ {1} - \bar {x}\right) ^ {2} + \left(1 0 0 x _ {2} - \bar {x}\right) ^ {2} + \left(1 0 0 x _ {3} - \bar {x}\right) ^ {2} + \left(1 0 0 x _ {4} - \bar {x}\right) ^ {2}}{4} = s _ {1} ^ {2}
> > $$
> >
> > 所以 $s_{1}^{2}=s_{2}^{2}$ .
