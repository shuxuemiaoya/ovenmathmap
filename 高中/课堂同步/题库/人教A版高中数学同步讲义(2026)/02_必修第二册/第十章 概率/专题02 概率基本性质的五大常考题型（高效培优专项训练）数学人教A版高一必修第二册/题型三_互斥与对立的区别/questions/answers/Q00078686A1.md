> [!faq]- 《专题02 概率基本性质的五大常考题型（高效培优专项训练）数学人教A版高一必修第二册》官方解析
>
> > [!success]- **【答案】** A．互斥但非对立事件 B．对立事件 C．非互斥事件 D．以上都不对
>
> > [!note]- **【分析】**
> > 事件“甲向南”与事件“乙向南”不能同时发生，但能同时都不发生，结合互斥、对立事件的定义即可判断.
>
> > [!note]- **【解析】**
> > 因为甲、乙、丙、丁四个人从同一地点随机地向东、南、西、北四个方向前进，每个方向一人，所以事件“甲向南”与事件“乙向南”不能同时发生，但能同时都不发生，故事件“甲向南”与事件“乙向南”是互斥但非对立事件；
> >
> > 故选：A
> >
> > 22. 抛掷一枚质地均匀的骰子一次，事件 $A =$ “出现点数为奇数”，事件 $B =$ “出现点数为3”，事件 $C =$ “出现点数为3的倍数”，事件 $D =$ “出现点数为偶数”，则以下选项正确的是（）A.B与 $D$ 互斥B.A与 $D$ 互为对立事件C. $P(C) = \frac{1}{2}$ D. $P(AC) = P(B)$
> >
> > 【答案】ABD
> >
> > 【分析】写出 $A, B, C, D$ 以及样本空间所包含的基本事件，逐一判断各个选项即可.
> > 【详解】由题意 $A = \{1, 3, 5\}, B = \{3\}, C = \{3, 6\}, D = \{2, 4, 6\}$ ，样本空间为 $U = \{1, 2, 3, 4, 5, 6\}$ 对于 A， $B \cap D = \emptyset$ ，这意味着 $B, D$ 不可能同时发生，故 A 正确；
> > 对于 B， $A \cap D = \emptyset, A \cup D = U$ ，这意味着 $A, D$ 中有且仅有一个事情发生，故 B 正确；
> > 对于 C， $P(C) = \frac{2}{6} = \frac{1}{3}$ ，故 C 错误；
> > 对于 D，因为 $A \cap C = B = \{3\}$ ，所以 $P(AC) = P(B) = \frac{1}{6}$ ，故 D 正确。
> >
> > 故选 **ABD**.
