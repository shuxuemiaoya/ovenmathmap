> [!faq]- 《第十章_概率_高效培优单元自测_提升卷_数学人教A版高一必修第二册》官方解析
>
> > [!success]- **【答案】** A. 某小组有 $^{3}$ 名男生和 $^{2}$ 名女生，从中任选 $^{2}$ 名同学参加演讲比赛，“至少一名男生”和“全是女生”是对 立事件 B．抛掷一颗质地均匀的骰子一次，事件 $M =$ “向上点数或4”，事件 $N =$ “向上点数是奇数”则 $$ P (M + N) = \frac {2}{3} $$ C．数据 13, 27, 24, 12, 14, 30, 15, 17, 19, 23 的 70% 分位数是 23 D．数据 $x_{1}, x_{2}, \cdots, x_{20}$ 的平均数为 2，方差为 3，则数据 $3x_{1} + 5, 3x_{2} + 5, L, 3x_{20} + 5$ 的平均数为 11，方差为 27
>
> > [!note]- **【分析】**
> > 根据对立事件的定义即可求解 $^{A}$ ，根据古典概型概率公式求解 $^{B}$ ，将数据重新排列，即可根据百
> >
> > 分位数的计算公式求解 $C$ ，根据平均数以及方差的性质即可求解 $\mathbf{D}$ 即可.
>
> > [!note]- **【解析】**
> > 对于 $^{A}$ ，任选 $^{2}$ 名同学包含“两名男生”，“两名女生”以及“一男一女”，
> >
> > 则“至少一名男生”和“全是女生”是对立事件，故 $^{A}$ 正确，
> >
> > 对于 B，由题意得 $M = \{1, 4\}, N = \{1, 3, 5\}$
> >
> > $M \cup N = \{1, 3, 4, 5\}, P(M + N) = P(M \cup N) = \frac{2}{3}$ 得到，故 $^{\mathsf{B}}$ 正确，
> >
> > 对于 C，将数据从小到大排列为 12，13，14，15，17，19，23，24，27，30，
> >
> > 由于 $10 \times 70\% = 7$ ，故 $70\%$ 分位数为 $\frac{23 + 24}{2} = 23.5$ ，故 $C$ 错误，
> >
> > 对于 D，数据 $x_{1}, x_{2}, \cdots, x_{20}$ 的平均数为 2，方差为 3，
> >
> > 则数据 $3x_{1} + 5,3x_{2} + 5,\mathrm{L},3x_{20} + 5$ 的平均数为 $3\times 2 + 5 = 11$
> >
> > 方差为 $3^{2} \times 3 = 27$ ，故 D 正确·
> >
> > 故选 **ABD**
