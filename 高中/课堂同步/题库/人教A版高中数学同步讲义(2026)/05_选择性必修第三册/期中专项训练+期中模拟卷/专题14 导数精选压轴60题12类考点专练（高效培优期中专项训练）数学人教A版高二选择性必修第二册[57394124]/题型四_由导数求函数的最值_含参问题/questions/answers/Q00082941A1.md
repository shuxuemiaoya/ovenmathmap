> [!faq]- 《专题14 导数精选压轴60题12类考点专练（高效培优期中专项训练）数学人教A版高二选择性必修第二册[57394124]》官方解析
>
> > [!success]- **【答案】** $(0,e)$
>
> > [!note]- **【分析】**
> > 由题意，利用导数分别求出 $f(x)_{\max}, g(x)_{\min}$ ，得 $a \ln a - a + 1 < 1$ ，解不等式即可.
>
> > [!note]- **【解析】**
> > $f^{\prime}(x) = \frac{a}{x} -1 = \frac{-x + a}{x} (x > 0,a > 0)$
> >
> > 令 $f^{\prime}(x) > 0\Rightarrow 0 <   x <   a,f^{\prime}(x) <   0\Rightarrow x > a$
> >
> > 所以 $f(x)$ 在 $(0,a)$ 上单调递增，在 $(a,+\infty)$ 上单调递减，
> >
> > 所以 $f(x)_{\max}=f(a)=a\ln a-a+1$
> >
> > $$
> > g ^ {\prime} (x) = 1 - \frac {1}{x} = \frac {x - 1}{x} (x > 0)
> > $$
> >
> > $$
> > \text { 令 } g ^ {\prime} (x) <   0 \Rightarrow 0 <   x <   1, g ^ {\prime} (x) > 0 \Rightarrow x > 1,
> > $$
> >
> > 所以 $g(x)$ 在 $(0,1)$ 上单调递减，在 $(1,+\infty)$ 上单调递增，
> >
> > 所以 $g(x)_{\min}=g(1)=1$
> >
> > 又 $\forall x_{1}, x_{2} \in (0, +\infty), f(x_{1}) < g(x_{2})$ 恒成立，
> >
> > 所以 $f(x)_{\max} < g(x)_{\min}$ ，即 $a \ln a - a + 1 < 1$
> >
> > 由 a > 0 ，解得 0 < a < e ，
> >
> > 即 a 的取值范围为 $(0, e)$ .
> >
> > 故答案为：(0,e)
