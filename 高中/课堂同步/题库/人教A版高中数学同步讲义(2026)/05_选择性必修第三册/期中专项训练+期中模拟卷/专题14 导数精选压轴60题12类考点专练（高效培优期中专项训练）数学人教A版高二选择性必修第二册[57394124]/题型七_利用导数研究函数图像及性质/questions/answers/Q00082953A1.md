> [!faq]- 《专题14 导数精选压轴60题12类考点专练（高效培优期中专项训练）数学人教A版高二选择性必修第二册[57394124]》官方解析
>
> > [!success]- **【答案】** ACD
>
> > [!note]- **【分析】**
> > 先由奇函数排除B选项，再由 $x\in [0,\pi ]$ 时， $f(x)$ 0，可排除A选项，结合导数研究可得 $f(x)$
> >
> > 在 $\left(0, \frac{2\pi}{3}\right)$ 上单调递增，在 $\left(\frac{2\pi}{3}, \pi\right)$ 上单调递减，结合图像分析即可求解.
>
> > [!note]- **【解析】**
> > 由题意， $x\in [-\pi ,\pi ]$ 关于原点对称，又 $f(-x) = [1 - \cos (-x)]\sin (-x) = -(1 - \cos x)\sin x = -f(x)$ 为
> >
> > 奇函数，可排除 B 选项；
> >
> > 又 $x \in [0, \pi]$ 时， $1 - \cos x = 0, \sin x = 0$ 可得 $f(x) = (1 - \cos x) \sin x = 0$ ，可排除 A 选项，
> >
> > $$
> > \text {当} x \in [ 0, \pi ] _ {\text {时}}, f ^ {\prime} (x) = \sin^ {2} x + (1 - \cos x) \cos x = - 2 \cos^ {2} x + \cos x + 1 = (2 \cos x + 1) (- \cos x + 1),
> > $$
> >
> > 当 $x \in [0, \pi]$ 时， $-\cos x + 1 = 0$ ，所以当 $0 < x < \frac{2\pi}{3}$ 时， $f'(x) > 0$ ，当 $\frac{2\pi}{3} < x < \pi$ 时， $f'(x) < 0$
> >
> > 所以 $f(x)$ 在 $\left(0, \frac{2\pi}{3}\right)$ 上单调递增，在 $\left(\frac{2\pi}{3}, \pi\right)$ 上单调递减，结合图像分析D不对，C选项正确.
