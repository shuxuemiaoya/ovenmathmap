> [!faq]- 《专题14 导数精选压轴60题12类考点专练（高效培优期中专项训练）数学人教A版高二选择性必修第二册[57394124]》官方解析
>
> > [!success]- **【答案】** (1) $y = 2x$ (2)若 $a = \frac{1}{2}$ ，单调递增区间为 $(0, + \infty)$ ； 若 $a > \frac{1}{2}$ ，单调递增区间为 $\left(0, \frac{1}{2}\right)$ 和 $(a, +\infty)$ ，单调递减区间为 $\left(\frac{1}{2}, a\right)$ ; 若 $0 < a < \frac{1}{2}$ ，单调递增区间为 $(0, a)$ 和 $\left(\frac{1}{2}, +\infty\right)$ ，单调递减区间为 $\left(a, \frac{1}{2}\right)$
>
> > [!note]- **【分析】**
> > （1）利用切点和导数几何意义得到切线斜率，再利用直线的点斜式方程得到切线方程；
> >
> > (2) 分情况讨论导函数在定义域内不同区间的正负，进而确定函数的单调区间.
>
> > [!note]- **【解析】**
> > （1）当 $a = -1$ 时，函数为 $f(x) = -\ln x - (2 \cdot (-1) + 1)x + x^2 = -\ln x + x + x^2$ ，定义域为 $(0, +\infty)$
> >
> > 因为 $f(1) = -\ln 1 + 1 + 1 = 0 + 1 + 1 = 2$ ，所以切点为 $(1,2)$
> >
> > 求导得 $f'(x) = -\frac{1}{x} + 1 + 2x$
> >
> > 在 $x = 1$ 处， $f'(1) = -1 + 1 + 2 = 2$ ，即切线斜率为2。
> >
> > 切线方程为 $y-2=2(x-1)\Rightarrow y=2x$
> >
> > (2) 当 $a > 0$ 时，函数为 $f(x) = a \ln x - (2a + 1)x + x^2$ ， $x > 0$
> >
> > $f^{\prime}(x) = \frac{a}{x} - (2a + 1) + 2x = \frac{2x^{2} - (2a + 1)x + a}{x} = \frac{(2x - 1)(x - a)}{x}$
> >
> > 令 $f'(x)=0$ 可得 $x=\frac{1}{2}$ 或 x=a ，
> >
> > 当 $a = \frac{1}{2}$ 时， $f'(x) = 0$ 恒成立（仅 $x = \frac{1}{2}$ 处为零），因此 $f(x)$ 在 $(0, +\infty)$ 上单调递增。
> >
> > 当 $a > \frac{1}{2}$ 时， $f'(x) > 0$ 时 $x < \frac{1}{2}$ 或 $x > a$ ； $f'(x) < 0$ 时 $\frac{1}{2} < x < a$
> >
> > 因此 $f(x)$ 的单调递增区间为 $\left(0, \frac{1}{2}\right)$ 和 $(a, +\infty)$ ，单调递减区间为 $\left(\frac{1}{2}, a\right)$
> >
> > 当 $0 < a < \frac{1}{2}$ 时， $f'(x) > 0$ 时， $0 < x < a$ 或 $x > \frac{1}{2}$ ； $f'(x) < 0$ 时， $a < x < \frac{1}{2}$
> >
> > 因此 $f(x)$ 的单调递增区间为 $(0,a)$ 和 $\left(\frac{1}{2}, + \infty\right)$ ，单调递减区间为 $\left(a,\frac{1}{2}\right)$
> >
> > 综上，当 $a > 0$ 时，
> >
> > 若 $a = \frac{1}{2}$ ，单调递增区间为 $(0, +\infty)$ ；
> >
> > 若 $a > \frac{1}{2}$ ，单调递增区间为 $\left(0, \frac{1}{2}\right)$ 和 $(a, +\infty)$ ，单调递减区间为 $\left(\frac{1}{2}, a\right)$
> >
> > 若 $0 < a < \frac{1}{2}$ ，单调递增区间为 $(0, a)$ 和 $\left(\frac{1}{2}, +\infty\right)$ ，单调递减区间为 $\left(a, \frac{1}{2}\right)$
