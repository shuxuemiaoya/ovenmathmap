> [!faq]- 《专题14 导数精选压轴60题12类考点专练（高效培优期中专项训练）数学人教A版高二选择性必修第二册[57394124]》官方解析
>
> > [!success]- **【答案】** $\left(-\frac{1}{2\mathrm{e}},0\right)$
>
> > [!note]- **【分析】**
> > 根据导函数的几何意义分析可得 $4m = -x_{2}\left[\ln \left(2x_{2}\right) - 1\right]^{2}$ ，构建 $h(x) = -x\left[\ln (2x) - 1\right]^{2}$ ，利用导数
> >
> > 求单调性及最值.
>
> > [!note]- **【解析】**
> > 设公切线为 $l$ ， $P(x_{1},y_{1})$ 是 $l$ 与 $f(x) = \frac{m}{x}$ 的切点， $Q(x_{2},y_{2})$ 是 $l$ 与 $g(x) = \ln (2x)$ 的切点，
> >
> > $f^{\prime}(x) = \frac{-m}{x^{2}}$ ， $g^{\prime}(x) = \frac{1}{x}$ ，所以 $l$ 的方程为 $y - y_{1} = \frac{-m}{x_{1}^{2}}(x - x_{1})$
> >
> > 因为 $y_{1}=\frac{m}{x_{1}}$ ，整理得 $y=\frac{-m}{x_{1}^{2}}x+\frac{2m}{x_{1}}$
> >
> > 同理 $y - y_{2} = \frac{1}{x_{2}} (x - x_{2})$ ，因为 $y_{2} = \ln (2x_{2})$ ，整理得 $y = \frac{1}{x_2} x + \ln (2x_2) - 1$
> >
> > 依题意两条直线重合，可得 $\left\{ \begin{array}{l} -\frac{m}{x_1^2} = \frac{1}{x_2}\textcircled{1}\\  \frac{2m}{x_1} = \ln (2x_2) - 1\textcircled{2} \end{array} \right.$ ，两式相除得 $-\frac{1}{2x_1} = \frac{1}{x_2[\ln(2x_2) - 1]}$
> >
> > 所以 $x_{1} = -\frac{x_{2}\left[\ln(2x_{2}) - 1\right]}{2}$ ，代入①得 $4m = -x_{2}\left[\ln(2x_{2}) - 1\right]^{2}$
> >
> > 由题意此方程有三个不等实根，设 $h(x) = -x[\ln (2x) - 1]^2 (x > 0)$
> >
> > 即直线 $y = 4m$ 与曲线 $h(x)$ 有三个不同的交点，
> >
> > 因为 $h'(x)=\left[\ln(2x)+1\right]\cdot\left[1-\ln(2x)\right]$ ，令 $h'(x)=0$ ，则 $x=\frac{1}{2e}$ 或 $\frac{e}{2}$ 。
> >
> > 当 $0 < x < \frac{1}{2\mathrm{e}}$ 时， $h'(x) < 0, h(x)$ 在 $\left(0, \frac{1}{2\mathrm{e}}\right)$ 上单调递减；
> >
> > 当 $\frac{1}{2\mathrm{e}} < x < \frac{\mathrm{e}}{2}$ 时， $h'(x) > 0$ ， $h(x)$ 在 $\left(\frac{1}{2\mathrm{e}}, \frac{\mathrm{e}}{2}\right)$ 上单调递增；
> >
> > 当 $x > \frac{\mathrm{e}}{2}$ 时， $h'(x) < 0, h(x)$ 在 $\left(\frac{\mathrm{e}}{2}, +\infty\right)$ 上单调递减，
> >
> > 所以 $h(x)$ 有极小值为 $h\left(\frac{1}{2\mathrm{e}}\right) = -\frac{2}{\mathrm{e}}$ ，有极大值为 $h\left(\frac{\mathrm{e}}{2}\right) = 0$
> >
> > 当 $x$ 趋近于0时， $h(x)$ 趋近于0；当 $x$ 趋近于 $+\infty$ 时， $h(x)$ 趋近于 $-\infty$ ，
> >
> > 所以当 $-\frac{2}{e}<4m<0$ ，即 $-\frac{1}{2e}<m<0$ 时，
> >
> > 直线 $y = 4m$ 与曲线 $h(x)$ 有三个交点，故 $m$ 的取值范围为 $\left(-\frac{1}{2\mathrm{e}},0\right)$
