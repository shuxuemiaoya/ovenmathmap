> [!faq]- 《专题14 导数精选压轴60题12类考点专练（高效培优期中专项训练）数学人教A版高二选择性必修第二册[57394124]》官方解析
>
> > [!success]- **【答案】** (1) $\left[\frac{1}{2},+\infty\right)$ (2)1 (3) $\left\{m \mid m \leq \frac{3}{2} + \ln 2\right\}$
>
> > [!note]- **【分析】**
> > （1） $f(x)$ 在定义域内单调递增等价于 $f'(x) = 0$ 恒成立，分离参数转化为最值问题求解；
> >
> > (2) 由 $1 + \ln (x + 1) \leq b\mathrm{e}^x + \ln b$ ，构造同构函数 $g(t) = t + \ln t$ ，利用 $g(t)$ 的单调性求解；
> >
> > (3) 由极值点得双变量 $x_{1}, x_{2}$ 之间关系，将 $\frac{f(x_1)}{x_2}$ 通过变量代换转化为关于 $x_{1}$ 的函数，利用导数判断单调
> >
> > 性求其最值情况即可求解.
>
> > [!note]- **【解析】**
> > （1）由题 $f(x)$ 的定义域为 $(-1, +\infty)$ ， $f'(x) = 2x + \frac{a}{1 + x} \quad 0.2x + \frac{a}{1 + x} \quad 0$ 在 $(-1, +\infty)$ 恒成立，且 $f'(x) = 0$ 的解不连续，
> >
> > 则 $a\left[-2x(1 + x)\right]_{\max} = \left[-2\left(x + \frac{1}{2}\right)^2 + \frac{1}{2}\right]_{\max} = \frac{1}{2}$
> >
> > 所以 a 的取值范围是 $\left[\frac{1}{2}, +\infty\right)$ ;
> >
> > (2) 当 $a = 1$ 时，不等式可化为 $1 + \ln (x + 1) \leq b\mathrm{e}^x + \ln b$ ，变形为 $x + 1 + \ln (x + 1) \leq b e^x + \ln (b e^x)$
> >
> > 令 $g(t) = t + \ln t$ ，求导得 $g'(t) = 1 + \frac{1}{t} >0$ ，所以 $g(t) = t + \ln t$ 在 $(0, + \infty)$ 上是增函数，
> >
> > 故 $x + 1 + \ln (x + 1) \leq be^x + \ln (be^x)$ ，即 $g(x + 1) \leq g(be^x)$ ，即 $x + 1 \leq be^x$ ，
> >
> > 所以对任意 $x \in (-1, +\infty)$ ，不等式 $f(x) - x^2 + 2 \leq b \mathrm{e}^x + \ln b$ 恒成立，即 $\frac{x + 1}{\mathrm{e}^x} \leq b$ 对任意 $x \in (-1, +\infty)$ 恒成立，
> >
> > 令 $h(x) = \frac{x + 1}{\mathrm{e}^x}, x \in (-1, +\infty)$ ，则 $h'(x) = \frac{-x}{\mathrm{e}^x}, x \in (-1, +\infty)$
> >
> > 所以当 $x \in (-1,0)$ 时， $h'(x) > 0$ ，则 $h(x)$ 单调递增；
> >
> > 当 $x \in (0, +\infty)$ 时， $h'(x) < 0$ ，则 $h(x)$ 单调递减，
> >
> > 所以 $h_{\max}(x)=h(0)=1$ ，即满足不等式的实数 b 的取值范围为 b-1，
> >
> > 所以 $b$ 的最小值为1；
> >
> > (3) 因为 $f(x)$ 存在两个不同的极值点 $x_{1}, x_{2}, x_{1} < x_{2}$
> >
> > 所以由 $f'(x)=2x+\frac{a}{1+x}=\frac{2x^{2}+2x+a}{x+1}=0$ 可得 $x_{1}, x_{2}$ 是方程 $2x^{2}+2x+a=0$ 的两根，
> >
> > $\Delta=4-8a>0,x_{1}+x_{2}=-1,x_{1}x_{2}=\frac{a}{2},\quad-1<x_{1}<-\frac{1}{2},\quad-\frac{1}{2}<x_{2}<0$ 所以 $\Delta = 4 - 8a > 0, x_{1} + x_{2} = -1, x_{1}x_{2} = \frac{a}{2}$ ，且 $-1 < x_{1} < -\frac{1}{2}, -\frac{1}{2} < x_{2} < 0$
> >
> > 所以 $x_{1}x_{2}=\frac{a}{2}>0$ ，故 $0<a<\frac{1}{2}$ ，
> >
> > 又由 $f(x_{1}) < mx_{2}$ 可得 $m < \frac{f(x_{1})}{x_{2}}$
> >
> > $$
> > \text {而} \frac {f (x _ {1})}{x _ {2}} = \frac {x _ {1} ^ {2} - 1 + a \ln (1 + x _ {1})}{- 1 - x _ {1}} = 1 - x _ {1} + \frac {a \ln (1 + x _ {1})}{- 1 - x _ {1}} = 1 - x _ {1} + \frac {2 x _ {1} (- 1 - x _ {1}) \ln (1 + x _ {1})}{- 1 - x _ {1}} = 1 - x _ {1} + 2 x _ {1} \ln (1 + x _ {1})
> > $$
> >
> > $$
> > \varphi (x) = 1 - x + 2 x \ln (1 + x), x \in \left(- 1, - \frac {1}{2}\right)
> > $$
> >
> > $$
> > \varphi^ {\prime} (x) = - 1 + 2 \ln (1 + x) + \frac {2 x}{1 + x} = \frac {x - 1}{1 + x} + 2 \ln (1 + x) = 1 - \frac {2}{x + 1} + 2 \ln (1 + x),
> > $$
> >
> > $x\in \left(-1, - \frac{1}{2}\right)$ $x + 1\in \left(0,\frac{1}{2}\right)$ ，即 $\frac{2}{x + 1}\in (4, + \infty),\ln (x + 1) <   0$
> >
> > 则 $\varphi^{\prime}(x) = 1 - \frac{2}{x + 1} +2\ln (1 + x) <   0$ ，所以 $\varphi (x)$ 在区间 $\left(-1, - \frac{1}{2}\right)$ 上单调递减，
> >
> > 所以有 $\varphi (x) > \varphi \left(-\frac{1}{2}\right) = \frac{3}{2} -\ln \frac{1}{2} = \frac{3}{2} +\ln 2$ ，即 $\frac{f(x_1)}{x_2} >\frac{3}{2} +\ln 2$
> >
> > 所以实数 m 取值范围 $\left\{m \mid m \leq \frac{3}{2} + \ln 2\right\}$ .
