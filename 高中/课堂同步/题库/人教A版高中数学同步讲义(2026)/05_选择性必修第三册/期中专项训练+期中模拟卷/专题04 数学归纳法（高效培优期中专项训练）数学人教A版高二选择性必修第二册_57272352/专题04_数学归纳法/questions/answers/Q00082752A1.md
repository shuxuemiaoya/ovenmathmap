> [!faq]- 《专题04 数学归纳法（高效培优期中专项训练）数学人教A版高二选择性必修第二册_57272352》官方解析
>
> > [!success]- **【答案】** ①用数学归纳法证明 $2^{n} > n^{2}$ 时，正整数 $n$ 的第一个取值是1. ②用数学归纳法证明 $\frac{1}{n+1}+\frac{1}{n+2}+\frac{1}{n+3}+\cdots+\frac{1}{2n}\quad\frac{11}{24}(n\quad1,n\in\mathbb{N})$ ，由 $n=k$ 到 $n=k+1$ 时，不等式左边应添加的项是 $\frac{1}{2k+1}+\frac{1}{2k+2}$ . ③设 $f(x)$ 是定义在正整数集上的函数，且 $f(x)$ 满足：“当 $f(k) \quad k^2$ 成立时，总可推出 $f(k + 1) \quad (k + 1)^2$ 成立”，若 $f(7) < 49$ 成立，则当 $k = 8$ 时，均有 $f(k) < k^2$ 成立. ④对于不等式 $\sqrt{n^2 + n} < n + 1(n\in \mathbf{N}_+)$ ，用数学归纳法的证明过程如下： (1) 当 n=1 时，左边 $=\sqrt{1^{2}+1}$ ，右边 $=1+1$ ，不等式成立. (2) 假设当 $n = k$ （ $k - 1$ 且 $k \in \mathbf{N}_{+}$ ）时，不等式成立，即 $\sqrt{k^2 + k} < k + 1$ 那么当 $n = k + 1$ 时， $$ \sqrt {(k + 1) ^ {2} + (k + 1)} = \sqrt {k ^ {2} + 3 k + 2} < \sqrt {(k ^ {2} + 3 k + 2) + k + 2} = \sqrt {(k + 2) ^ {2}} = (k + 1) + 1 $$ 所以当 $n = k + 1$ 时，不等式成立· 综上 $\sqrt{n^2 + n} < n + 1(n\in \mathbf{N}_+)$ A.1 B.2 C.3 D.4
>
> > [!note]- **【解析】**
> > - **对于①**：，n=1 时， $2^{1}>1^{2}$ 成立，而 n=2 时， $2^{2}=2^{2}$ ，不满足题意，
> >
> > 根据数学归纳法证明的要求可知，正整数 $n$ 的第一个取值不是 $1$ ，故①错误；
> > - **对于②**：，当 $n = k$ 时，左边的代数式为 $\frac{1}{k + 1} +\frac{1}{k + 2} +\frac{1}{k + 3} +\dots +\frac{1}{2k}$
> >
> > 当 $n = k + 1$ 时，左边的代数式为 $\frac{1}{k + 1 + 1} +\frac{1}{k + 1 + 2} +\dots +\frac{1}{k + 1 + k} +\frac{1}{2k + 2}$
> >
> > 故用 $n = k + 1$ 时左边的代数式减去 $n = k$ 时左边的代数式的结果为：
> >
> > $\frac{1}{k + 1 + k} + \frac{1}{2k + 2} - \frac{1}{k + 1} = \frac{1}{2k + 1} - \frac{1}{2k + 2}$ ，故②错误；
> > - **对于③**：，由题意， $f(7)<49$ 无法推出 k 8 时，均有 $f(k)<k^{2}$ 成立，故③错误；
> > - **对于④**：，在 $n=k+1$ 时，没有用到n=k的假设结论，故④错误·
> >
> > 故选 **D**.
