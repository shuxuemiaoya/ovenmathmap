17. (15 分)

已知数列 $\left\{a_{n}\right\},\left\{b_{n}\right\}$ 满足：对任意的 $n=2, n \in N^{*}$ ，都有 $a_{1}b_{1} + a_{2}b_{2} + a_{3}b_{3} + \cdots + a_{n}b_{n} = a_{n-1}b_{n+1} + c$ （c 为常数），

则称数列 $\{a_{n}\},\{b_{n}\}$ 为“ $c-$ 友好数列”，特别地，当 $c=0$ 时，数列 $\{a_{n}\},\{b_{n}\}$ 为“极好数列”.

(1)若数列 $\{a_{n}\},\{b_{n}\}$ 的通项公式分别为 $a_{n} = 2n - 1,b_{n} = 2^{n - 1}$ ，求证：数列 $\{a_n\} ,\{b_n\}$ 为“3-友好数列”；

(2)若数列 $\{a_{n}\},\{b_{n}\}$ 为“极好数列”， $a_{n} = n + 1,a_{1} = b_{1},a_{3} = b_{2}$ ，求数列 $\{b_n\}$ 的通项公式 $b_{n}$

(3)已知正整数列 $\{a_{n}\},\{b_{n}\}$ 为“3- 友好数列”，数列 $\{b_{n}\}$ 为等比数列，且 $a_1 = b_1 = 1$ ，求证：数列 $\{a_n\}$ 为等差

数列.
