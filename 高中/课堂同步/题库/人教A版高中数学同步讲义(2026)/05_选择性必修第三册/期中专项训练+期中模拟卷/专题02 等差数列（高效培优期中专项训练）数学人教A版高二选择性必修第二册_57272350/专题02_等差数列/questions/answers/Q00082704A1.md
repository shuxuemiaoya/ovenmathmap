> [!faq]- 《专题02 等差数列（高效培优期中专项训练）数学人教A版高二选择性必修第二册_57272350》官方解析
>
> > [!success]- **【答案】** $\frac{29}{57}$
>
> > [!note]- **【解析】**
> > 由题意得 $b_{1} + b_{6} = b_{5} + b_{2}, b_{2} + b_{8} = 2b_{5}$
> >
> > 所以 $b_{1} + b_{6} + b_{8} = 3b_{5}$ ，又 $\frac{a_5}{b_5} = \frac{9a_5}{9b_5} = \frac{S_9}{T_9} = \frac{3\times 9 + 2}{2\times 9 + 1} = \frac{29}{19}$
> >
> > 所以 $\frac{a_5}{b_1 + b_6 + b_8} = \frac{a_5}{3b_5} = \frac{1}{3}\times \frac{a_5}{b_5} = \frac{1}{3}\times \frac{29}{19} = \frac{29}{57}$
> >
> > 故答案为： $\frac{29}{57}$

> > 19. 等差数列 $\{a_{n}\}$ ， $\{b_{n}\}$ 的前 $n$ 项和分别为 $S_{n}$ 与 $T_{n}$ ，且 $(5n + 4)T_{n} = (4n + 3)S_{n}$ ，则 $\frac{b_{9} + b_{7}}{a_{15}} =$ \_\_\_\_.
> > 【答案】 $\frac{126}{149}$
> >
> > 【详解】 $\therefore$ 数列 $\{a_{n}\}$ ， $\{b_{n}\}$ 均为等差数列， $\therefore \frac{b_{1} + b_{7}}{a_{15}} = \frac{2b_{8}}{a_{15}}$ 。
> >
> > $\because (5n + 4)T_{n} = (4n + 3)S_{n}, \therefore \frac{S_{n}}{T_{n}} = \frac{5n + 4}{4n + 3}$
> >
> > 根据等差数列 $\{c_n\}$ 前 $n$ 项和 $C_n = an^2 + bn$ ，可设 $S_{n} = 5\lambda n^{2} + 4\lambda n$
> >
> > $$
> > T _ {n} = 4 \lambda n ^ {2} + 3 \lambda n, \quad \lambda \neq 0.
> > $$
> >
> > 对于数列 $\{a_{n}\}$ ，当 $n = 1$ 时， $a_1 = 9\lambda$
> >
> > 当 $n$ 2时， $a_{n} = S_{n} - S_{n - 1} = (5\lambda n^{2} + 4\lambda n) - [5\lambda (n - 1)^{2} + 4\lambda (n - 1)] = 10\lambda n - \lambda$
> >
> > 显然当 $n = 1$ 时，也满足 $a_{n} = 10\lambda n - \lambda$ ，故 $a_{n} = 10\lambda n - \lambda = \lambda (10n - 1)$
> >
> > 同理可得 $b_{n} = \lambda (8n - 1)$
> >
> > 故 $\frac{b_9 + b_7}{a_{15}} = \frac{2b_8}{a_{15}} = \frac{2\lambda(8\times 8 - 1)}{\lambda(10\times 15 - 1)} = \frac{126}{149}$
> >
> > 故答案为： $\frac{126}{149}$
