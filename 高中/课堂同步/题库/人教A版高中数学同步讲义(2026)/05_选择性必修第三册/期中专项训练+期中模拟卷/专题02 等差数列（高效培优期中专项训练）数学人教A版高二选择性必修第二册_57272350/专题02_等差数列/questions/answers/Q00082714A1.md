> [!faq]- 《专题02 等差数列（高效培优期中专项训练）数学人教A版高二选择性必修第二册_57272350》官方解析
>
> > [!success]- **【答案】** C
>
> > [!note]- **【解析】**
> > 等差数列 $\{a_{n}\}$ 的前 $n$ 项和为 $S_{n}$ ，由 $S_{12} < S_{11}$ ，且 $S_{13} > S_{11}$
> >
> > 得 $a_{12} = S_{12} - S_{11} < 0, a_{12} + a_{13} = S_{13} - S_{11} > 0$ ，所以 $a_{13} > 0 > a_{12}$
> >
> > 则数列 $\{a_{n}\}$ 的公差 $d > 0$ ，所以数列 $\{a_{n}\}$ 是递增的等差数列，
> >
> > 且当 $n \leq 12$ 时， $a_{n} < 0$ ，当 $n = 13$ 时， $a_{n} > 0$
> >
> > 又 $S_{23} = \frac{23(a_1 + a_{23})}{2} = 23a_{12} < 0, S_{24} = \frac{24(a_1 + a_{24})}{2} = 12(a_{12} + a_{13}) > 0$
> >
> > 所以使 $S_{n} > 0$ 成立的最小的 n 为 24，
> >
> > 故选 **C**.
