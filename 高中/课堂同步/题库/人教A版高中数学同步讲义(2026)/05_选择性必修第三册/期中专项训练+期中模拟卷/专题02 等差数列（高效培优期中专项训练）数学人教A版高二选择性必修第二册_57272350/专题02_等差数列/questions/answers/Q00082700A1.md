> [!faq]- 《专题02 等差数列（高效培优期中专项训练）数学人教A版高二选择性必修第二册_57272350》官方解析
>
> > [!success]- **【答案】** (1) $a_{1}=-2$ ， $a_{2}=3$ ， $a_{3}=-4$ (2) $a_{n}=\left\{\begin{aligned}&n+1,n\text{为偶数}\\&-\left(n+1\right),n\text{为奇数}\end{aligned}\right.$ (3) $-\frac{1}{2}+\frac{1}{n+2}$
>
> > [!note]- **【解析】**
> > （1）由条件知 $a_1 = S_1 = -\frac{1 + 3}{2} = -2$
> >
> > $$
> > a _ {2} = S _ {2} - S _ {1} = \frac {2}{2} - (- 2) = 3, a _ {3} = S _ {3} - S _ {2} = - \frac {3 + 3}{2} - \frac {2}{2} = - 4.
> > $$
> >
> > (2) 当 n 为奇数且 n 3 时， $a_{n}=S_{n}-S_{n-1}=-\frac{n+3}{2}-\frac{n-1}{2}=-n-1$ ， $a_{1}$ 也符合，
> >
> > 所以当 n 为奇数时， $a_{n} = -n - 1$ ；
> >
> > 当 $n$ 为偶数时， $a_{n} = S_{n} - S_{n-1} = \frac{n}{2} - \left(-\frac{n-1+3}{2}\right) = n+1$ ；
> >
> > 所以数列 $a_{n} = \left\{ \begin{array}{l} n + 1, n \text{为偶数} \\ - (n + 1), n \text{为奇数} \end{array} \right.$
> >
> > （3）由题可知 $a_{n}a_{n + 1} = -(n + 1)(n + 2)$ ，所以 $\frac{1}{a_n a_{n + 1}} = -\frac{1}{(n + 1)(n + 2)} = -\left(\frac{1}{n + 1} -\frac{1}{n + 2}\right)$
> >
> > 所以数列 $\left\{\frac{1}{a_{n}a_{n+1}}\right\}$ 的前 n 项和为 $-\left(\frac{1}{2}-\frac{1}{3}+\frac{1}{3}-\frac{1}{4}+\frac{1}{4}-\frac{1}{5}+\cdots+\frac{1}{n+1}-\frac{1}{n+2}\right)=-\frac{1}{2}+\frac{1}{n+2}$
