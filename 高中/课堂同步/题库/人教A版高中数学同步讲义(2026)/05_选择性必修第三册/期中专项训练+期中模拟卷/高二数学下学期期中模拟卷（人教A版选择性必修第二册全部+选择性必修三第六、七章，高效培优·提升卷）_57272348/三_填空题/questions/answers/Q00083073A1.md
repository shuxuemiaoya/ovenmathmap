> [!faq]- 《高二数学下学期期中模拟卷（人教A版选择性必修第二册全部+选择性必修三第六、七章，高效培优·提升卷）_57272348》官方解析
>
> > [!success]- **【答案】** (1) $x - \mathrm{e}y - 4 = 0$ (2) $f(x)$ 在 $(1,+\infty)$ 上单调递增，在 $(-∞,1)$ 上单调递减； $g(x)$ 在 $(-∞,2)$ 上单调递增，在 $(2,+∞)$ 上单调递减。 (3)证明见解析
>
> > [!note]- **【解析】**
> > （1）由 $f(x) = -x\mathrm{e}^{1 - x}$ ，得 $f'(x) = -\mathrm{e}^{1 - x} - x \cdot \mathrm{e}^{1 - x} \cdot (-1) = (x - 1)\mathrm{e}^{1 - x}$ ，
> >
> > 因为 $f(2) = -2\mathrm{e}^{1 - 2} = -\frac{2}{\mathrm{e}}$ ， $f'(2) = (2 - 1)\mathrm{e}^{1 - 2} = \frac{1}{\mathrm{e}}$
> >
> > 所以曲线 $y = f(x)$ 在点 $(2, f(2))$ 处的切线方程为 $y - \left(-\frac{2}{\mathrm{e}}\right) = \frac{1}{\mathrm{e}}(x - 2)$ ，即 $x - \mathrm{e}y - 4 = 0$
> >
> > (2) 由 (1) 知 $f'(x) = (x - 1)e^{1 - x}$ ,
> >
> > 令 $f'(x)>0$ ，得x>1；令 $f'(x)<0$ ，得x<1。
> >
> > 所以 $f(x)$ 在 $(1,+\infty)$ 上单调递增，在 $(-∞,1)$ 上单调递减.
> >
> > 由 $g(x) = f'(x) = (x - 1)\mathrm{e}^{1 - x}$ ，得 $g'(x) = \mathrm{e}^{1 - x} + (x - 1)\cdot \mathrm{e}^{1 - x}\cdot (-1) = (2 - x)\cdot \mathrm{e}^{1 - x}$
> >
> > 令 $g'(x)>0$ ，得 x<2 ；令 $g'(x)<0$ ，得 x>2 。
> >
> > 所以 $g(x)$ 在 $(-∞,2)$ 上单调递增，在 $(2,+∞)$ 上单调递减.
> >
> > (3) 因为 0 < t < x ，所以 $x < x + t$
> > - **①**：当 $x$ 1时， $1 \leq x < x + t$ ，由（2）知 $f(x)$ 在 $(1, +\infty)$ 上单调递增，
> >
> > 所以 $f(x) < f(x + t)$
> >
> > 因为 t > 0 ，所以 $f(t) = -te^{1-t} < 0$ ，所以 $f(t) + f(x) < f(t + x)$
> > - **②**：当 0 < x < 1 时，令 $h(x) = f(t) + f(x) - f(x + t)$ ，
> >
> > 则 $h'(x)=f'(x)-f'(t+x)$ ，0<x<t+x<2
> >
> > 由（2）知 $g(x) = f'(x)$ 在 $(0,2)$ 上单调递增，所以 $f'(x) < f'(t + x)$ ，
> >
> > 所以 $h'(x) < 0$
> >
> > 所以 $h(x)$ 在 $[0,1)$ 上单调递减，所以 $h(x) < h(0) = f(0) = 0$
> >
> > 即当 $0 < x < 1$ 时， $f(t) + f(x) < f(t + x)$
> >
> > 综上，当 $0 < t < x$ 时， $f(t) + f(x) < f(t + x)$
