> > [!success]- **【答案】** A
>
> > [!note]- **【分析】**
> > 根据等差数列的求和公式，结合等差数列的性质，即可求解.
>
> > [!note]- **【解析】**
> > 设等差数列 $\left\{a_{n}\right\}$ 共 $2n+1$ 项，则其中奇数项有 $n+1$ 项，偶数项有 n 项，且各成等差数列.
> > 奇数项和为 $a_{1} + a_{3} + \cdots + a_{2n+1} = \frac{(n+1)(a_{1} + a_{2n+1})}{2} = 220$ ①
> >
> > 偶数项和为 $a_{2} + a_{4} + \cdots + a_{2n} = \frac{n(a_{2} + a_{2n})}{2} = 200$
> >
> > 因为 $a_{1} + a_{2n+1} = a_{2} + a_{2n} \neq 0$
> >
> > 所以 $\frac{n + 1}{n} = \frac{220}{200} = \frac{11}{10}$ ，解得 $n = 10$
> >
> > 所以 $2n + 1 = 21$ ，即等差数列 $\{a_n\}$ 的项数为21.
> >
> > 故选：A.
> >
> > 35. 数列 $\left\{a_{n}\right\}$ 中， $a_{1}=2$ ，对 $\forall m,n\in N^{*}$ ，有 $a_{m+n}=a_{m}+a_{n}$ ，若 $a_{k+1}+a_{k+2}+a_{k+3}+\cdots+a_{k+10}=270$ ，则 k=（）A.8 B.9 C.10 D.11
> >
> > 【答案】A
> >
> > 【分析】先根据 $a_{m + n} = a_m + a_n$ 求证 $\{a_n\}$ 为等差数列，再根据等差数列求和公式列等式求解即可.
> >
> > 【详解】令 m=1 ，可得 $a_{n+1}=a_{n}+a_{1}=a_{n}+2$
> >
> > 则 $\left\{a_{n}\right\}$ 是首项 $a_1 = 2$ ，公差 $d = 2$ 的等差数列，
> >
> > 通项公式为 $a_{n}=a_{1}+(n-1)d=2+2(n-1)=2n$
> >
> > $$
> > a _ {k + 1} + a _ {k + 2} + a _ {k + 3} + \dots + a _ {k + 1 0} = \frac {1 0 (a _ {k + 1} + a _ {k + 1 0})}{2} = 5 [ 2 (k + 1) + 2 (k + 1 0) ] = 2 0 k + 1 1 0 = 2 7 0
> > $$
> >
> > 解得 $k = 8$
