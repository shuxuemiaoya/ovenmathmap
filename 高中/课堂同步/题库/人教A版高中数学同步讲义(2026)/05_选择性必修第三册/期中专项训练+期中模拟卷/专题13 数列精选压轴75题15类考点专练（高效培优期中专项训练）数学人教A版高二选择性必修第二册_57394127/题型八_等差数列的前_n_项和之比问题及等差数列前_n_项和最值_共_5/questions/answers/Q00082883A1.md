> [!faq]- 《专题13 数列精选压轴75题15类考点专练（高效培优期中专项训练）数学人教A版高二选择性必修第二册_57394127》官方解析
>
> > [!success]- **【答案】** $\frac{21}{11}$ $\frac{25}{19}$
>
> > [!note]- **【分析】**
> > 根据等差数列求和公式结合等差数列下标和性质，将所求项的比转化为和的比，计算求解.
>
> > [!note]- **【解析】**
> > $\frac{a_2 + a_8}{b_3 + b_7} = \frac{a_1 + a_9}{b_1 + b_9} = \frac{\frac{9(a_1 + a_9)}{2}}{\frac{9(b_1 + b_9)}{2}} = \frac{S_9}{T_9} = \frac{2\times 9 + 3}{9 + 2} = \frac{21}{11}$
> >
> > 因为数列 $\{a_{n}\},\{b_{n}\}$ 是等差数列，所以 $S_{n},T_{n}$ 均是 $n$ 的二次式，且常数项均为0.
> >
> > 由 $\frac{S_n}{T_n} = \frac{2n + 3}{n + 2}$ ，可设 $S_{n} = kn(2n + 3), T_{n} = kn(n + 2)$ ，其中 $k$ 为常数.
> >
> > 所以 $\frac{S_{11}}{T_{17}}=\frac{k\times11\times(2\times11+3)}{k\times17\times(17+2)}=\frac{11\times25}{17\times19}$ 又 $\frac{S_{11}}{T_{17}} = \frac{\frac{11(a_1 + a_{11})}{2}}{\frac{17(b_1 + b_{17})}{2}} = \frac{11a_6}{17b_9}$ ，所以 $\frac{11a_6}{17b_9} = \frac{11\times 25}{17\times 19}$ 所以 $\frac{a_6}{b_9} = \frac{25}{19}$
