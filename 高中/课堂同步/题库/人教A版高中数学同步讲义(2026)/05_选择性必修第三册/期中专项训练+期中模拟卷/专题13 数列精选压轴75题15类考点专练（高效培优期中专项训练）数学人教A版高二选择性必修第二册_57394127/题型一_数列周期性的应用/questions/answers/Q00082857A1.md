> [!faq]- 《专题13 数列精选压轴75题15类考点专练（高效培优期中专项训练）数学人教A版高二选择性必修第二册_57394127》官方解析
>
> > [!success]- **【答案】** D
>
> > [!note]- **【解析】**
> > 依题意有 $a_1 = 1, a_2 = a_1 + 1 = 2, a_3 = -a_2 + 2 = 0, a_4 = a_3 + 1 = 1$ ， $a_5 = -a_4 + 2 = 1, a_6 = a_5 + 1 = 2, \cdots$ ，所以数列 $\{a_n\}$ 是周期为 4 的周期数列，且 $a_1 + a_2 + a_3 + a_4 = 1 + 2 + 0 + 1 = 4$ ，因为 $2026 \div 4 = 506 \cdots 2$ ，所以 $S_{2026} = a_1 + a_2 + \cdots + a_{2026} = 506 \times (a_1 + a_2 + a_3 + a_4) + a_1 + a_2 = 2027$ 。
