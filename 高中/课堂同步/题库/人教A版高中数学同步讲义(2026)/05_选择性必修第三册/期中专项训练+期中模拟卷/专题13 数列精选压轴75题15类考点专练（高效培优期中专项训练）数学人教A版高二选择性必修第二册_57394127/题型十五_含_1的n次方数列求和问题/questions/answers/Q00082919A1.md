> [!faq]- 《专题13 数列精选压轴75题15类考点专练（高效培优期中专项训练）数学人教A版高二选择性必修第二册_57394127》官方解析
>
> > [!success]- **【答案】** ACD
>
> > [!note]- **【分析】**
> > 利用等差数列的基本量运算求出首项与公差，进而求得其通项，再根据选项代值检验，利用等
> >
> > 差（比）数列的定义逐一判断即可.
>
> > [!note]- **【解析】**
> > 设等差数列 $\{a_{n}\}$ 的公差为 $d$ ，由题意可得 $\left\{ \begin{array}{l}a_1 + 3d = 7\\ 3a_1 + 3d = 9 \end{array} \right.$ ，解得 $\left\{ \begin{array}{l}a_1 = 1\\ d = 2 \end{array} \right.$ ，故 $a_{n} = 1 + (n - 1)\times 2 = 2n - 1$
> >
> > 对于 A，由通项易得 $a_{2}=3$ ，故 A 正确；
> >
> > 对于 B，因 $a_{2n}=2\times2n-1=4n-1$ ，而 $2a_{n}-1=2(2n-1)-1=4n-3$ ，即 $a_{2n}\neq2a_{n}-1$ ，故 B 错误；
> >
> > 对于C，因 $S_{n} = \frac{n(1 + 2n - 1)}{2} = n^{2}$ ，则 $\sqrt{S_n} = n$ ，由 $\sqrt{S_{n + 1}} -\sqrt{S_n} = n + 1 - n = 1$ ，可得数列 $\left\{\sqrt{S_n}\right\}$ 为等差数列，
> >
> > 故 C 正确；
> >
> > 对于 D，因 $S_{n}=n^{2}$ ，则 $S_{2^{n}}=(2^{n})^{2}=2^{2n}$ ，由 $\frac{S_{2^{n+1}}}{S_{2^{n}}}=\frac{2^{2(n+1)}}{2^{2n}}=4$ ，可得 $\left\{S_{2^{n}}\right\}$ 为等比数列，故 D 正确.
