> [!faq]- 《专题14_导数精选压轴60题12类考点专练_高效培优期中专项训练_数学》官方解析
>
> > [!success]- **【答案】** (1)最大值为 $e^{e}-1$ ，最小值为 -e，只有 1 个零点； (2) $a \leq 3\mathrm{e}$
>
> > [!note]- **【分析】**
> > （1）利用导数计算函数的单调性计算最值，再根据零点存在性定理确定零点个数即可；
> >
> > (2) 构造函数 $m(x)=f(x)-ag(x)$ ，将问题化为函数 $m(x)$ 定义域上单调递增，即 $m'(x)=0$ 恒成立，分
> >
> > 离参数，再利用导数研究函数的单调性、最值计算即可.
>
> > [!note]- **【解析】**
> > （1）易知 $h(x) = f(x) + g(x) = \mathrm{e}^{x} - \frac{2\mathrm{e}}{x} +\ln x(x > 0)$
> >
> > 则 $h^{\prime}(x) = \mathrm{e}^{x} + \frac{2\mathrm{e}}{x^{2}} +\frac{1}{x} >0$ 定义域上恒成立，
> >
> > 所以 $h(x)$ 在 $[1, \mathrm{e}]$ 上单调递增，则 $h(x) \leq h(\mathrm{e}) = \mathrm{e}^{\mathrm{e}} - 1, h(x) \quad h(1) = -\mathrm{e}$ ，
> >
> > 即最大值为 $\mathrm{e}^{\mathrm{e}} - 1$ ，最小值为 $-\mathrm{e}$
> >
> > 又 $-\mathrm{e} < 0 < \mathrm{e}^{\mathrm{e}} - 1$ ，根据零点存在定理和函数的单调性，则 $h(x)$ 在[1,e]上只有一个零点；
> >
> > (2) 设 $m(x)=f(x)-ag(x)$ ，则对于任意的 $0<x_{1}<x_{2}$ ，均有 $m(x_{1})<m(x_{2})$ ，
> >
> > 即 $m(x)$ 在 $(0,+\infty)$ 上单调递增，
> >
> > 所以 $m^{\prime}(x) = f^{\prime}(x) - ag^{\prime}(x) = \mathrm{e}^{x} + \frac{2\mathrm{e}}{x^{2}} -\frac{a}{x}$ 0在 $(0, + \infty)$ 上恒成立，
> >
> > 即 $a \leq x e^{x} + \frac{2e}{x}$ 在 $(0, +\infty)$ 上恒成立，
> >
> > 令 $n(x) = x\mathrm{e}^{x} + \frac{2\mathrm{e}}{x}(x > 0)$ ，则 $n'(x) = (x + 1)\mathrm{e}^x -\frac{2\mathrm{e}}{x^2}$
> >
> > 令 $u(x) = n'(x)$ ，则 $u'(x) = (x + 2)e^x + \frac{4e}{x^3} > 0$ ，即 $n'(x)$ 在 $(0, +\infty)$ 上单调递增，
> >
> > 又 $n'(1)=0$ ，则 $n(x)$ 在 $(0,1)$ 上单调递减，在 $(1,+\infty)$ 上单调递增，
> >
> > 所以 $n(x)$ $n(1)=3e$ ，故 $a \leq 3e$
