> [!faq]- 《专题14_导数精选压轴60题12类考点专练_高效培优期中专项训练_数学》官方解析
>
> > [!success]- **【答案】** (1) $y = -2$ (2) $a$ 的取值范围为 $\left(-\infty,0\right]$ ; 当 $-1 < a \leq 0$ 时， $f(x)$ 在定义域 $(0, +\infty)$ 内无零点； 当 $a = -1$ 时， $f(x)$ 在定义域 $(0, +\infty)$ 内存在唯一零点； 当 $a < -1$ 时， $f(x)$ 在定义域 $(0, +\infty)$ 内存在两个零点.
>
> > [!note]- **【分析】**
> > （1）分别求出切点坐标和切线斜率，写出切线方程即得；
> >
> > (2) 对函数求导，根据参数 $a$ 进行分类讨论导函数的正负，得出函数的单调区间，分 $-1 < a \leq 0$ ， $a = -1$
> >
> > 和 a < -1 三种情况讨论函数 $f(x)$ 的零点个数即可.
>
> > [!note]- **【解析】**
> > （1）当 $a = 1$ 时， $f(x) = \ln x + x^2 - 3x$ ， $f'(x) = \frac{1}{x} + 2x - 3$ ，故 $f(1) = -2$ ， $f'(1) = 0$ 。
> >
> > 从而所求切线经过点 $\left(1, -2\right)$ 且斜率为 $0$ ，故曲线 $y = f(x)$ 在点 $\left(1, f(1)\right)$ 处的切线方程为 $y = -2$
> >
> > (2) 由于 $f(x) = \ln x + ax^2 - (2a + 1)x$
> >
> > $$
> > f ^ {\prime} (x) = \frac {1}{x} + 2 a x - (2 a + 1) = \frac {2 a x ^ {2} - (2 a + 1) x + 1}{x} = \frac {(x - 1) (2 a x - 1)}{x}
> > $$
> >
> > 函数 $f(x)$ 在区间 $(0,1)$ 上单调递增，在区间 $(1, +\infty)$ 上单调递减，
> >
> > 所以 $x = 1$ 是 $f(x)$ 的极大值点，即 $f^{\prime}(1) = 0$ ，且在 $x = 1$ 左侧 $f^{\prime}(x) > 0$ ，右侧 $f^{\prime}(x) < 0$
> > - **①**：当 $a > \frac{1}{2}$ 时，有 $1 > \frac{1}{2a}$ ， $f'(x) = \frac{(x - 1)(2ax - 1)}{x} = \frac{2a}{x}(x - 1)\left(x - \frac{1}{2a}\right)$
> >
> > 从而当 $0 < x < \frac{1}{2a}$ 或 $x > 1$ 时 $f'(x) > 0$ ；当 $\frac{1}{2a} < x < 1$ 时 $f'(x) < 0$ .
> >
> > 故函数 $f(x)$ 在 $\left(0, \frac{1}{2a}\right]$ 和 $[1, +\infty)$ 上单调递增，在 $\left[\frac{1}{2a}, 1\right]$ 上单调递减，不符合条件
> > - **②**：当 $a = \frac{1}{2}$ 时， $f'(x) = \frac{(x - 1)^2}{x}$ ，从而对 $0 < x < 1$ 和 $x > 1$ 均有 $f'(x) > 0$
> >
> > 故 $f(x)$ 在 $(0,1]$ 和 $[1, +\infty)$ 上单调递增，从而在 $(0, +\infty)$ 上单调递增，不符合条件
> > - **③**：当 $0 < a < \frac{1}{2}$ 时，有 $1 < \frac{1}{2a}$ ， $f'(x) = \frac{(x - 1)(2ax - 1)}{x} = \frac{2a}{x}(x - 1)\left(x - \frac{1}{2a}\right)$
> >
> > 从而当 $0 < x < 1$ 或 $x > \frac{1}{2a}$ 时 $f'(x) > 0$ ；当 $1 < x < \frac{1}{2a}$ 时 $f'(x) < 0$ .
> >
> > 故函数 $f(x)$ 在 $(0,1]$ 和 $\left[\frac{1}{2a}, +\infty\right)$ 上单调递增，在 $\left[1, \frac{1}{2a}\right]$ 上单调递减，不符合条件
> > - **④**：当 $a \leq 0$ 时，对任意 x > 0 都有 2ax - 1 < 0 ，
> >
> > 从而当 $0 < x < 1$ 时 $f'(x) > 0$ ；当 x > 1 时 $f'(x) < 0$
> >
> > 故函数 $f(x)$ 在 $(0,1]$ 上单调递增，在 $[1, +\infty)$ 上单调递减，符合条件。
> >
> > 综上， $a$ 的取值范围为 $\left(-\infty ,0\right]$
> >
> > 所以 $f(x)_{\max}=f(1)=-a-1$
> >
> > 当 $f(1) < 0$ ，即 $-a - 1 < 0 \Rightarrow -1 < a \leq 0$ 时， $f(x)$ 在定义域 $(0, +\infty)$ 内无零点；
> >
> > 当 $f(1) = 0$ ，即 $a = -1$ 时， $f(x)$ 在 $x = 1$ 处取得零点，且是唯一零点；
> >
> > 当 $f(1) > 0$ ，即 $a < -1$ 时，
> >
> > 由于 $0 < \mathrm{e}^{a} < 1$ ， $f\left(\mathrm{e}^{a}\right) = \ln \mathrm{e}^{a} + a\left(\mathrm{e}^{a}\right)^{2} - (2a + 1) \cdot \mathrm{e}^{a} = a\left(\mathrm{e}^{a} - 1\right)^{2} - \mathrm{e}^{a} < 0$
> >
> > 根据零点存在性定理可得 $f(x)$ 在 $(0,1)$ 存在唯一零点；
> >
> > 由于 $f(2) = \ln 2 + 4a - 4a - 2 = \ln 2 - 2 < 0$ ，根据零点存在性定理可得 $f(x)$ 在 $(1, +\infty)$ 存在唯一零点；
> >
> > 所以 $a < -1$ 时， $f(x)$ 存在两个零点；
> >
> > 综上，当 $-1 < a \leq 0$ 时， $f(x)$ 在定义域 $(0, +\infty)$ 内无零点；
> >
> > 当 $a = -1$ 时， $f(x)$ 在定义域 $(0, +\infty)$ 内存在唯一零点；
> >
> > 当 $a < -1$ 时， $f(x)$ 在定义域 $(0, +\infty)$ 内存在两个零点.
