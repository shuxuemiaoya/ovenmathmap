> [!faq]- 《专题14_导数精选压轴60题12类考点专练_高效培优期中专项训练_数学》官方解析
>
> > [!success]- **【答案】** (1)单调递增区间为 $\left(0,\frac{1}{3}\right)$ ，单调递减区间为 $\left(\frac{1}{3},+\infty\right)$ (2) $\left[-1,0\right]$ (3)证明见解析
>
> > [!note]- **【分析】**
> > （1）求导后讨论导数正负即可得原函数单调性；
> >
> > (2) 利用函数性质可得 $a \leq 0$ ，再利用导数可得该函数单调性，即可得 $f(x) < f(1)$ ，解出即可得；
> >
> > $h(x)=f(x)+\frac{1}{2}(x-1)^{2}$ ，利用导数计算可得该函数单调性，从而可得该函数小于0恒成立。
> >
> > 即可得证.
>
> > [!note]- **【解析】**
> > （1）当 $a = 1$ 时，则 $g(x) = \ln x + x^2 - 3x - x^2 = \ln x - 3x$ 的定义域为 $(0, +\infty)$ ，
> >
> > 则 $g'(x)=\frac{1}{x}-3=\frac{1-3x}{x}$
> >
> > 令 $g\Phi(x)>0$ ，解得 $0<x<\frac{1}{3}$ ；令 $g\Phi(x)<0$ ，解得 $x>\frac{1}{3}$ ；
> >
> > 所以函数 $g(x)$ 的单调递增区间为 $\left(0, \frac{1}{3}\right)$ ，单调递减区间为 $\left(\frac{1}{3}, +\infty\right)$ ;
> >
> > (2) 因为 $f(x)=\ln x+ax^{2}-(2a+1)x$
> >
> > 若 $a > 0$ ，当 $x$ 趋近于 $+\infty$ 时， $f(x)$ 趋近于 $+\infty$ ，不合题意，所以 $a \leq 0$
> >
> > 因为 $f'(x)=\frac{1}{x}+2ax-(2a+1)=\frac{(2ax-1)(x-1)}{x}$
> >
> > 且 $x \in (1, +\infty)$ ，则 $x - 1 > 0$ ， $2ax - 1 < 0$ ，则 $f \Phi(x) < 0$
> >
> > 可知 $f(x)$ 在 $(1, +\infty)$ 内单调递减，则 $f(x) < f(1) = -a - 1$
> >
> > 可得 $-a-1\leq0$ ，解得 $-1\leq a\leq0$ ，所以实数 a 的取值范围为 $\left[-1,0\right]$
> >
> > (3) 令 $h(x)=f(x)+\frac{1}{2}(x-1)^{2}=\left(a+\frac{1}{2}\right)x^{2}-(2a+2)x+\ln x+\frac{1}{2}$
> >
> > 则 $h^{\prime}(x) = (2a + 1)x - (2a + 2) + \frac{1}{x} = \frac{(x - 1)[(2a + 1)x - 1]}{x}$
> >
> > 因为 $0 < x < 1$ ， $0 < a < \frac{1}{2}$ ，则 $x - 1 < 0$ ， $\frac{1}{2} < \frac{1}{2a + 1} < 1$
> >
> > 令 $h^{\prime}(x) > 0$ ，解得 $0 < x < \frac{1}{2a + 1}$ ；令 $h^{\prime}(x) < 0$ ，解得 $\frac{1}{2a + 1} < x < 1$
> >
> > 可知 $h(x)$ 在 $\left(0, \frac{1}{2a+1}\right)$ 内单调递增，在 $\left(\frac{1}{2a+1}, 1\right)$ 内单调递减，
> >
> > 则 $h(x)\leq h\left(\frac{1}{2a + 1}\right) = \frac{1}{2(2a + 1)} -\frac{2a + 2}{2a + 1} +\ln \frac{1}{2a + 1} +\frac{1}{2} = -\frac{1}{2(2a + 1)} +\ln \frac{1}{2a + 1} -\frac{1}{2}$
> >
> > 因为 $\frac{1}{2} < \frac{1}{2a + 1} < 1$ ，则 $\ln \frac{1}{2a + 1} < 0$
> >
> > 可得 $h\left(\frac{1}{2a + 1}\right) = -\frac{1}{2(2a + 1)} + \ln \frac{1}{2a + 1} - \frac{1}{2} < 0$
> >
> > 即 $h(x) < 0$ ，所以当 $0 < x < 1$ 时， $f(x) < -\frac{1}{2}(x - 1)^2$
> >
