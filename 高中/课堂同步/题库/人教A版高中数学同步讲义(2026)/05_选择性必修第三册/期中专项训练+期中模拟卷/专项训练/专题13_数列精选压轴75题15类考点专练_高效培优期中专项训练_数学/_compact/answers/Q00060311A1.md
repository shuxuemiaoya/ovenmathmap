> [!faq]- 《专题13_数列精选压轴75题15类考点专练_高效培优期中专项训练_数学》官方解析
>
> > [!success]- **【答案】** (1) $a_{n}=n+1$ (2) $m = 99$ 或102
>
> > [!note]- **【分析】**
> > （1）设出公差，利用等差数列通项公式和求和公式计算即可得解；
> >
> > (2) 结合并项求和法分奇偶讨论 $T_{n}$ ，再分奇偶计算即可得.
>
> > [!note]- **【解析】**
> > （1）设数列 $\{a_{n}\}$ 的公差为 $d$ ，则 $S_{5} = 5a_{1} + 10d = 4S_{2} = 8a_{1} + 4d$ ，即 $a_1 = 2d$
> >
> > 由 $a_{2n} = 2a_n - 1$ ，则 $a_2 = 2a_1 - 1 = a_1 + d = \frac{3}{2} a_1$ ，解得 $a_1 = 2$ ，则 $d = 1$
> >
> > 故 $a_{n} = 2 + (n - 1) = n + 1$
> >
> > (2) $b_{n}=\left(-1\right)^{n}a_{n}=\left(-1\right)^{n}(n+1)$ ，则 $T_{n}=-2+3-4+5-\cdots+\left(-1\right)^{n}(n+1)$
> >
> > 当 n 为奇数时， $T_{n} = -2 + 3 - 4 + 5 - \cdots - (n + 1) = -2 + (3 - 4) + \cdots + (n - n - 1) = -\frac{n + 3}{2}$
> >
> > 当 n 为偶数时， $T_{n} = -2 + 3 - 4 + 5 - \cdots + (n + 1) = (-2 + 3) + (-4 + 5) + \cdots + (-n + n + 1) = \frac{n}{2}$
> >
> > 由 $\left|T_{m}\right|=51$ ，则当m为奇数时，有 $\frac{m+3}{2}=51$ ，解得m=99，
> >
> > 当 m 为偶数时，有 $\frac{m}{2}=51$ ，解得 m=102，
> >
> > 综上可得，m = 99 或 102。
