> [!faq]- 《专题15_计数原理及随机变量及其分布精选压轴70题14类考点专练_期中》官方解析
>
> > [!success]- **【答案】** ABD
>
> > [!note]- **【解析】**
> > 对于 A：两点分布的方差公式为 $D(X)=p(1-p)$ （其中 p 为成功概率），
> >
> > 将其视为关于 $p$ 的二次函数 $f(p) = -p^2 + p$ ，开口向下，顶点在 $p = \frac{1}{2}$ 处，
> >
> > 此时方差最大值为 $\frac{1}{4}$ ，故A正确；
> >
> > 对于 B：设查得次品数为 X，则 X 服从超几何分布，
> >
> > 其中 $N = 10$ （产品总数）， $M = 3$ （次品数）， $n = 2$ （抽取的产品数），
> >
> > 根据超几何分布的均值公式 $E(X) = n \cdot \frac{M}{N}$ ，可得 $E(X) = 2 \times \frac{3}{10} = 0.6$ ，故B正确；
> >
> > 对于 C：根据独立性检验的统计量 $\chi^{2}$ 的计算公式为 $\chi^{2}=\frac{n(ad-bc)^{2}}{(a+b)(c+d)(a+c)(b+d)}$ （其中 $n=a+b+c+d$
> >
> > 为样本量），若所有数据扩大10倍，
> >
> > 则新数据为 $a' = 10a, b' = 10b, c' = 10c, d' = 10d, n' = 10n$
> >
> > 代入公式得： $\chi^{\prime 2} = \frac{10n\cdot(10a\cdot 10d - 10b\cdot 10c)^{2}}{(10a + 10b)(10c + 10d)(10a + 10c)(10b + 10d)} = 10\chi^{2}$
> >
> > 所以统计量的值变为原来的 10 倍，结论会改变，故 C 错误；
> >
> > 对于 D：已知 $\chi^{2}=8.612,\quad\chi^{2}_{0.001}=10.828$ ，因为 $\chi^{2}=8.612<\chi^{2}_{0.001}=10.828$
> >
> > 所以依据 $\alpha = 0.001$ 的独立性检验，可判断 X 与 Y 独立，故 D 正确.
