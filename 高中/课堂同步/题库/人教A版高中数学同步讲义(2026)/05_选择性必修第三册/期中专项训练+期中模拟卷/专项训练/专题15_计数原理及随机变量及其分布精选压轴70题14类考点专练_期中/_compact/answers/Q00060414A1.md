> [!faq]- 《专题15_计数原理及随机变量及其分布精选压轴70题14类考点专练_期中》官方解析
>
> > [!success]- **【答案】** BD
>
> > [!note]- **【解析】**
> > 对于 A，甲可以同时选打球和唱歌， $\therefore A_{1} \cap A_{2} \neq \varnothing$ ，故 $A_{1}$ 与 $A_{2}$ 不互斥，故 A 错误，
> >
> > 对于 B，先从 4 个项目中选择 2 个给其中一个人，有 $C_{4}^{2}$ 种选法，
> >
> > 再将这2个项目与另外两个项目全排列，分给甲、乙、丙3名学生，有 $\mathrm{A}_3^3$ 种排法，
> >
> > 根据分步乘法计数原理可得总的样本数为 $C_{4}^{2}A_{3}^{3}=36$ 种,
> >
> > 甲只选唱歌，此时从剩下3个项目给乙、丙，有 $C_{3}^{2}A_{2}^{2}=6$ 种；
> >
> > 甲只选唱歌和另外一个项目有 $C_{3}^{1}=3$ 种，此时从剩下2个项目给乙、丙，共有 $C_{3}^{1}A_{2}^{2}=6$ 种，故 $P(A_{2})=\frac{6+6}{36}=\frac{1}{3}$ ，故B正确，
> >
> > 对于 C，乙只选跳舞，此时从剩下 3 个项目给甲、丙，有 $C_{3}^{2}A_{2}^{2}=6$ 种；
> >
> > 乙选跳舞和另外一个项目有 $C_3^1 = 3$ 种，此时从剩下2个项目给甲、丙，有 $C_3^1 A_2^2 = 6$ 种，故 $P(A_{3}) = \frac{6 + 6}{36} = \frac{1}{3}$
> >
> > 甲选唱歌且乙选跳舞，此时有5种情况， $\therefore P(A_{2}A_{3}) = \frac{5}{36}$
> >
> > $\therefore P(A_3)P(A_2) = \frac{1}{9} \neq P(A_2A_3) = \frac{5}{36}$ ，故 $A_2$ 与 $A_3$ 不相互独立，故C错误，
> >
> > 对于 D， $P(A_{1}, A_{2}) = \frac{P(A_{3} \cap A_{2})}{P(A_{2})} = \frac{\frac{5}{36}}{\frac{12}{36}} = \frac{5}{12}$ ，故 D 正确.

> > 题型八 全概率公式的综合应用（共5小题）
> >
> > 36．英国数学家贝叶斯在概率论研究方面成就显著，根据贝叶斯定理，随机事件 $A, B$ 存在如下关系：
> >
> > $P(A \mid B) = \frac{P(A)P(B \mid A)}{P(B)}$ . 张同学每天的运动计划包括两种主要方式：室内健身和户外运动．张同学第一
> >
> > 天选择室内健身的概率为 $\frac{2}{3}$ ，选择户外运动的概率为 $\frac{1}{3}$ 。如果第一天选择室内健身，那么第二天继续选择室内健身的概率为 $\frac{1}{2}$ ；如果第一天选择户外运动，那么第二天选择室内健身的概率为 $\frac{2}{3}$ 。则张同学（ ）A．第二天去室内健身的概率为 $\frac{5}{9}$ B．第二天去户外运动的概率为 $\frac{2}{9}$ C．若第二天去了室内健身，则第一天去户外运动的概率为 $\frac{2}{5}$ D．若第二天去了户外运动，则第一天去室内健身的概率为 $\frac{3}{4}$
> >
> > 【答案】ACD
> >
> > 【详解】设 $A_{1}$ 表示张同学第一天选择室内健身， $A_{2}$ 表示张同学第二天选择室内健身，
> >
> > $B_{1}$ 表示张同学第一天选择户外运动， $B_{2}$ 表示张同学第二天选择户外运动.
> >
> > 则 $P(A_{1}) = \frac{2}{3}$ ， $P(B_{1}) = \frac{1}{3}$ ， $P(A_{2}|A_{1}) = \frac{1}{2}$ ， $P(A_{2}|B_{1}) = \frac{2}{3}$
> >
> > 因为 $P(A_{2}|A_{1})=\frac{P(A_{2})P(A_{1}|A_{2})}{P(A_{1})}=\frac{1}{2}$ ，所以 $P(A_{2})P(A_{1}|A_{2})=\frac{1}{2}\times\frac{2}{3}=\frac{1}{3}$ ，
> >
> > 因为 $P(A_{2}|B_{1}) = \frac{P(A_{2})P(B_{1}|A_{2})}{P(B_{1})} = \frac{2}{3}$ ，所以 $P(A_{2})P(B_{1}|A_{2}) = \frac{2}{3}\times \frac{1}{3} = \frac{2}{9}$
> >
> > 对于A， $P(A_{2}) = P(A_{2})P(A_{1}|A_{2}) + P(A_{2})P(B_{1}|A_{2}) = \frac{1}{3} +\frac{2}{9} = \frac{5}{9}$ ，故A正确；
> >
> > 对于B，因为 $P(B_{2}) = 1 - P(A_{2}) = 1 - \frac{5}{9} = \frac{4}{9}$ ，故B错误；
> >
> > 对于 C，因为 $P(B_{1}|A_{2})=\frac{\frac{2}{9}}{P(A_{2})}=\frac{\frac{2}{9}}{\frac{5}{9}}=\frac{2}{5}$ ，故 C 正确；
> >
> > 对于 D，因为 $P(A_{1}|B_{2})=\frac{P(A_{1})P(B_{2}|A_{1})}{P(B_{2})}=\frac{P(A_{1})\left[1-P(A_{2}|A_{1})\right]}{P(B_{2})}=\frac{\frac{2}{3}\times\left(1-\frac{1}{2}\right)}{\frac{4}{9}}=\frac{3}{4}$ ，故 D 正确.
