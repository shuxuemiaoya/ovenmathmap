> [!faq]- 《专题15_计数原理及随机变量及其分布精选压轴70题14类考点专练_期中》官方解析
>
> > [!success]- **【答案】** (1)-28160 $x^{2}$ (2)1
>
> > [!note]- **【分析】**
> > （1）由二项式系数和可得出关于 $n$ 的等式，解出 $n$ 的值，再利用二项展开式通项可求出展开式
> >
> > 中含 $x^{2}$ 的项.
> >
> > (2) 令 $x = 1$ 可得出 $a_0$ 的值，令 $x = 2$ 可得出 $a_0 + a_1 + a_2 + a_3 + \dots + a_{11}$ 的值，即可得出 $a_1 + a_2 + a_3 + \dots + a_{11}$ 的值
> >
> > 值.
>
> > [!note]- **【解析】**
> > （1）由题意得 $(x - 2)^n$ 的展开式的二项式系数和为 $2^{n} = 2048$ ，解得 $n = 11$ ：
> >
> > 展开式的通项公式为 $T_{r+1} = C_{11}^{r} x^{11-r} (-2)^{r} (r = 0, 1, 2, \cdots, 11)$ ,
> >
> > 令 $11 - r = 2$ ，解得 $r = 9$ ，代入通项公式得 $T_{10} = \mathrm{C}_{11}^{9}x^{2}(-2)^{9} = -512\times 55x^{2} = -28160x^{2}$
> >
> > (2) 因为 $(x-2)^{11}=a_{0}+a_{1}(x-1)+a_{2}(x-1)^{2}+\cdots+a_{11}(x-1)^{11}$
> >
> > 所以令 $x = 1$ ，得 $a_0 = (1 - 2)^{11} = -1$
> >
> > 令 x=2 ，得 $(2-2)^{11}=a_{0}+a_{1}+a_{2}+\cdots+a_{11}=0$
> >
> > 所以 $a_{1} + a_{2} + \cdots + a_{11} = 0 - a_{0} = 1$
