> [!faq]- 《专题15_计数原理及随机变量及其分布精选压轴70题14类考点专练_期中》官方解析
>
> > [!success]- **【答案】** BC
>
> > [!note]- **【分析】**
> > 根据方差的公式即可判断选项 A，根据回归方程即可判断 B，根据期望和方差的性质判断 C；根
> >
> > 据正态分布的对称性求解判断 D.
>
> > [!note]- **【解析】**
> > 对于 A，令数据 $x_{1}, x_{2}, \cdots, x_{n}$ 的平均数为 $\overline{x}$ ，
> >
> > 则由 $s^2 = \frac{1}{n}\sum_{i = 1}^{n}\left(x_i - \overline{x}\right)^2 = 0$ ，可得 $\sum_{i = 1}^{n}\left(x_i - \overline{x}\right)^2 = 0$
> >
> > 所以 $\left(x_{1}-\bar{x}\right)^{2}+\left(x_{2}-\bar{x}\right)^{2}+\cdots+\left(x_{n}-\bar{x}\right)^{2}=0$
> >
> > 所以 $x_{1}=x_{2}=\cdots=x_{n}=\overline{x}$ ，
> >
> > 即所有的 $x_{i}(i=1,2,3,\cdots,n)$ 都相等，A 正确；
> >
> > 对于 B，线性回归方程 $\hat{y}=2+0.5x$ 中，当变量 x 每增加一个单位时， $\hat{y}$ 平均增加 0.5 个单位，B 错误；
> >
> > 对于 C，由 $\eta = 3\xi - 2$ ，则 $E(\eta) = 3E(\xi) - 2$ ， $D(\eta) = 9D(\xi)$ ，C 错误.
> >
> > 对于 D，随机变量 X 服从正态分布 $N(3, \sigma^{2})$ ，则 $\mu = 3$ ，由 $P(X \leq 4) = 0.7$
> >
> > 得 $P(3 < X < 4) = P(X \leq 4) - P(X \leq 3) = 0.7 - 0.5 = 0.2$
> >
> > 则 $P(2 < X < 4) = 2P(3 < X < 4) = 2 \times 0.2 = 0.4$ ，D正确；
> >
> > 故选 **BC**
