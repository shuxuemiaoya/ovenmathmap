> [!faq]- 《专题12_正态分布_高效培优期中专项训练_数学人教A版高二选择性必修第》官方解析
>
> > [!success]- **【答案】** (1)2.3% (2)32740
>
> > [!note]- **【解析】**
> > （1）设学生的物理得分为随机变量 $X$ ，则 $X \sim N(60, 100)$ ，所以 $\mu = 60$ ， $\sigma = 10$ ，所以 $P(40 \leq X \leq 80) = P(\mu - 2\sigma \leq X \leq \mu + 2\sigma) = 95.4\%$ ， $P(X > 80) = \frac{1 - P(40 \leq X \leq 80)}{2} = 0.023$ ，
> >
> > 所以物理成绩优秀的人数占总人数的比例为 2.3% .
> >
> > （2）由题意，得 $P(\mu - \sigma \leq X \leq \mu + \sigma) = 0.683$ ， $P(\mu - 2\sigma \leq X \leq \mu + 2\sigma) = 0.954$ 即 $P(50 \leq X \leq 70) = 0.683$ ， $P(40 \leq X \leq 80) = 0.954$ 所以 $P(50 \leq X \leq 60) = \frac{1}{2} P(50 \leq X \leq 70) = 0.3415$ ， $P(60 < X \leq 80) = \frac{1}{2} P(40 \leq X \leq 80) = 0.477$ 所以 $P(50 \leq X \leq 80) = P(50 \leq X \leq 60) + P(60 < X \leq 80) = 0.3415 + 0.477 = 0.8185$ 又 $40000 \times 0.8185 = 32740$ 所以全市物理成绩在[50,80]内的学生人数估计为 $32740$
