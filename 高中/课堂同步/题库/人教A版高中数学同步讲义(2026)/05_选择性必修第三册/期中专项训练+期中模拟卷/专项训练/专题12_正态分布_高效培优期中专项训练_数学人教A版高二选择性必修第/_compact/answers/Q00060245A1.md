> [!faq]- 《专题12_正态分布_高效培优期中专项训练_数学人教A版高二选择性必修第》官方解析
>
> > [!success]- **【答案】** C
>
> > [!note]- **【解析】**
> > 由随机变量 X 服从正态分布 $X \sim N(4, \sigma^{2})$ ，其正态分布分布曲线的对称轴为直线 x = 4，
> > 则 $P(2 < X < 4) = P(4 < X < 6)$ 所以 $P(X > 6) + P(2 < X < 4) = m + n = \frac{1}{2}$ ，且 m > 0，n > 0，即 $2m + 2n = 1$ ，
> > 所以 $\frac{2}{m}+\frac{1}{n}=(2m+2n)\left(\frac{2}{m}+\frac{1}{n}\right)=\frac{4n}{m}+\frac{2m}{n}+6 \sqrt{\frac{4n}{m}\times\frac{2m}{n}}+6=4\sqrt{2}+6$ 当且仅当 $\frac{4n}{m}=\frac{2m}{n}$ ，即 $m=\sqrt{2}n=\frac{2-\sqrt{2}}{2}$ 时，取等号·
> >
> > 故选 **C**.
