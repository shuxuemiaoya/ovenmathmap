> [!faq]- 《专题12_正态分布_高效培优期中专项训练_数学人教A版高二选择性必修第》官方解析
>
> > [!success]- **【答案】** (1)1587 (2)0.0989
>
> > [!note]- **【解析】**
> > （1）已知本次模拟考试成绩都近似服从正态分布 $X \sim N(\mu, \sigma^2)$
> >
> > 由题意得 $\mu = 65 \cdot$ 因为 $\frac{228}{10000} = 0.0228$ ，又 $\frac{1 - P(\mu - 2\sigma \leq X \leq \mu + 2\sigma)}{2} \approx 0.0228$ .
> >
> > 即 $P(X > \mu + 2\sigma) \approx 0.0228$ ，所以 $\mu + 2\sigma = 87$ ，解得 $\sigma = 11 \cdot$
> >
> > 因为甲市学生 A 的成绩为 76 分，且 $76 = \mu + \sigma$ .
> >
> > 又 $\frac{1 - P(\mu - \sigma \leq X \leq \mu + \sigma)}{2} \approx 0.1587$ ，即 $P(X > \mu + \sigma) \approx 0.1587$ .
> >
> > 所以学生 A 在甲市的大致名次为 1587 名·
> >
> > (2) 在本次模拟考试的学生中，抽取1名化学成绩在 $\left[\mu - 3\sigma, \mu + 3\sigma\right]$ 之内的概率为 $0.9974 \cdot$
> >
> > 所以抽取1名化学成绩在 $\left(\mu-3\sigma,\mu+3\sigma\right)$ 之外的概率为0.0026·
> >
> > 所以随机变量 Y 服从二项分布，即 $Y \sim B(40, 0.0026)$
> >
> > 所以 $P(Y \quad 1) = 1 - P(Y = 0) = 1 - 0.9974^{40} \approx 0.0989$ .
> >
> > 27. 化学课上，老师带同学进行酸碱平衡测量实验，由于物质的量浓度差异，测量酸碱度 pH 值时会造成一定的误差，甲组的实验数据误差 X 和乙组的实验数据误差 Y 均符合正态分布，其中 $X \sim N(0.3, 0.0001)$ ， $Y \sim N(0.28, 0.0004)$ ，已知正态分布密度函数 $f(x) = \frac{1}{\sqrt{2\pi}\sigma} e^{-\frac{(x-\mu)^2}{2\sigma^2}}$ ，记 X 和 Y 所对应的正态分布密度函数分别为 $f_1(x), f_2(x)$ ，则（）
> >
> > A. $f_1(0.3) > f_2(0.28)$ B. 甲组的实验数据误差相对于乙组更集中
> >
> > C. $P(X < 0.28) + P(X \leq 0.32) = 1$ D. $P(Y < 0.31) < P(X < 0.31)$
> >
> > 【答案】ABC
> >
> > 【详解】对于 $A$ ， $B$ ，由正态分布密度函数曲线可知，数据的标准差越小，数据越集中在均值附近，峰值越大，反之，标准差越大，数据越分散，峰值越小，对于两个小组的误差，甲组的标准差 $\sigma_{1} = \sqrt{0.0001} = 0.01$ ，乙组的标准差 $\sigma_{2} = \sqrt{0.0004} = 0.02$ ，显然甲组的标准差更小，故峰值更大，数据误差相对乙组更集中，故 $A$ ， $B$ 正确；
> >
> > 对于 C, $P(X < 0.28) = P(X < \mu - 2\sigma_{1}) = P(X > \mu + 2\sigma_{1})$ ， $P(X \leq 0.32) = P(X \leq \mu + 2\sigma_{1})$
> >
> > $P(X<0.28)+P(X\leq0.32)=P(X>\mu+2\sigma_{1})+P(X\leq\mu+2\sigma_{1})=1$ ，故C正确；
> >
> > 对于 D， $P(Y < 0.31) = P\left(Y < \mu_{2} + \frac{3}{2}\sigma_{2}\right) > P\left(Y < \mu_{2} + \sigma_{2}\right) = \frac{1}{2} + \frac{1}{2}P\left(\mu_{2} - \sigma_{2} < Y < \mu_{2} + \sigma_{2}\right)$
> >
> > $$
> > P (X <   0. 3 1) = P (X <   \mu_ {1} + \sigma_ {1}) = \frac {1}{2} + \frac {1}{2} P (\mu_ {1} - \sigma_ {1} <   X <   \mu_ {1} + \sigma_ {1})
> > $$
> >
> > 而对于任何正态分布都有 $P\left(\mu_{1} - \sigma_{1} < X < \mu_{1} + \sigma_{1}\right) = P\left(\mu_{2} - \sigma_{2} < Y < \mu_{2} + \sigma_{2}\right)$
> >
> > 故 $P(Y<0.31)>P(X<0.31)$ ，故D错误.
> >
> > 故选 **ABC**.
