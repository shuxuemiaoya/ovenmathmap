> [!faq]- 《专题08_二项式定理_高效培优期中专项训练_数学人教A版高二选择性必修》官方解析
>
> > [!success]- **【答案】** ABD
>
> > [!note]- **【解析】**
> > 对于 A：由 $T_{k+1} = C_{7}^{k}(2x)^{k} = C_{7}^{k} \times 2^{k} x^{k}$ ，所以 $a_{2} = C_{7}^{2} \times 2^{2} = 84$ ，故 A 正确；
> > 对于 B：令 x = 0，得 $a_{0} = 1$ ，故 B 正确；
> > 对于 C：令 x = -1 有 $\left[1 + 2 \times (-1)\right]^{7} = a_{0} - a_{1} + a_{2} - a_{3} + a_{4} - a_{5} + a_{6} - a_{7} = -1$ 所以 $-a_{1} + a_{2} - a_{3} + a_{4} - a_{5} + a_{6} - a_{7} = -1 - a_{0} = -1 - 1 = -2$ ，故 C 错误；
> > 对于 D：对 $(1+2x)^{7}=a_{0}+a_{1}x+a_{2}x^{2}+a_{3}x^{3}+a_{4}x^{4}+a_{5}x^{5}+a_{6}x^{6}+a_{7}x^{7}$ 同时求导得 $a_{1}+2a_{2}x+3a_{3}x^{2}+4a_{4}x^{3}+5a_{5}x^{4}+6a_{6}x^{5}+7a_{7}x^{6}=14(1+2x)^{6}$ 令 x = -1 得 $a_{1}-2a_{2}+3a_{3}-4a_{4}+5a_{5}-6a_{6}+7a_{7}=14$ 同时乘-1得 $-a_{1}+2a_{2}-3a_{3}+4a_{4}-5a_{5}+6a_{6}-7a_{7}=-14$ ，故 D 正确.
> >
> > 故选 **ABD**.
