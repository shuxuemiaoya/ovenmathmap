> [!faq]- 《专题05_导数的概念及运算_高效培优期中专项训练_数学人教A版高二选择》官方解析
>
> > [!success]- **【答案】** (1) $y = 13x - 32$ (2) $y = 13x \quad (-2, -26)$
>
> > [!note]- **【解析】**
> > （1）由 $f(2)=2^{3}+2-16=-6$ ，得点 $(2,-6)$ 在曲线上，
> >
> > 求导得 $f^{\prime}(x) = 3x^{2} + 1$ ，则 $f^{\prime}(2) = 3\times 2^{2} + 1 = 13$
> >
> > 所以所求切线的方程为 $y + 6 = 13(x - 2)$ ，即 y = 13x - 32。
> >
> > (2) 设切点为 $\left(x_{0}, y_{0}\right)$ ，则切线 l 的斜率为 $f'\left(x_{0}\right)=3x_{0}^{2}+1$
> >
> > 切线 l 的方程为： $y = \left( 3x_{0}^{2} + 1 \right) \left( x - x_{0} \right) + x_{0}^{3} + x_{0} - 16$
> >
> > 由切线 $l$ 过点 $(0,0)$ ，得 $0 = (3x_0^2 + 1)(-x_0) + x_0^3 + x_0 - 16$ ，整理得 $x_0^3 = -8$
> >
> > 解得 $x_0 = -2$ ， $y_0 = (-2)^3 + (-2) - 16 = -26$ ，切线 $l$ 的斜率 $k = 3 \times (-2)^2 + 1 = 13$
> >
> > 所以切线 l 的方程为 y = 13x ，切点坐标为 $(-2, -26)$ .
