> [!faq]- 《专题02_等差数列_高效培优期中专项训练_数学人教A版高二选择性必修第》官方解析
>
> > [!success]- **【答案】** B
>
> > [!note]- **【解析】**
> > 因为等差数列 $\{a_{n}\},\{b_{n}\}$ 的前 $n$ 项和分别为 $A_{n}$ 和 $B_{n}$ , $\frac{A_n}{B_n} = \frac{3n + 75}{2n + 5}$
> >
> > 所以可设 $A_{n} = kn(3n + 75)$ （ $k\neq 0$ ）， $B_{n} = kn(2n + 5)$
> >
> > 所以 $n$ 2时， $a_{n} = A_{n} - A_{n-1} = kn(3n + 75) - k(n - 1)(3n + 72) = 6k(n + 12)$
> >
> > 又 $a_{1}=78k$ 满足上式，所以 $a_{n}=6k(n+12)$ （ $n\in N^{*}$ ）
> >
> > n 2时， $b_{n}=B_{n}-B_{n-1}=kn(2n+5)-k(n-1)(2n+3)=k(4n+3)$
> >
> > 又 $b_{1} = 7k$ 满足上式，所以 $b_{n} = k(4n + 3), n \in \mathbf{N}^{*}$
> >
> > 则 $\frac{a_{2n}}{b_n} = \frac{6k(2n + 12)}{k(4n + 3)} = \frac{12n + 72}{4n + 3} = 3 + \frac{63}{4n + 3}$
> >
> > 因为 $\frac{a_{2n}}{b_n} \in \mathbf{Z}$ ，所以 $4n + 3$ 是63的正因数，63的正因数有1，3，7，9，21，63，又 $n \in \mathbb{N}^*$ ，则 $4n + 3 = 7$ ，解得 $n = 1$ ； $4n + 3 = 63$ ，解得 $n = 15$ ，
> >
> > 所以 $n = 1$ ，15，即满足 $\frac{a_{2n}}{b_n}\in \mathbf{Z}$ 的正整数 $n$ 有2个.
> >
> > 故选 **B**.
