> [!faq]- 《专题02_等差数列_高效培优期中专项训练_数学人教A版高二选择性必修第》官方解析
>
> > [!success]- **【答案】** (1)证明见解析， $a_{n}=\sqrt{n}-\sqrt{n-1}$ (2)不存在，理由见解析
>
> > [!note]- **【解析】**
> > （1） $2S_{n}=a_{n}+\frac{1}{a_{n}}$ 中令n=1得： $2a_{1}=a_{1}+\frac{1}{a_{1}}$
> >
> > 故正项数列 $\{a_{n}\}$ 中， $a_{1}^{2} = 1$ ，即 $a_{1} = 1$
> >
> > 当 $n$ 2时， $a_{n} = S_{n} - S_{n-1}$ ，即 $2S_{n} = S_{n} - S_{n-1} + \frac{1}{S_{n} - S_{n-1}}$
> >
> > 整理得 $S_{n}^{2} - S_{n - 1}^{2} = 1$ ，又 $S_{1}^{2} = a_{1}^{2} = 1$
> >
> > 因此，数列 $\left\{S_n^2\right\}$ 是以 $1$ 为首项， $1$ 为公差的等差数列，
> >
> > 则 $S_{n}^{2} = n$ ，因为 $\{a_n\}$ 是正项数列，即 $S_{n} > 0$ ，所以 $S_{n} = \sqrt{n}$
> >
> > 当 n 2 时， $a_{n}=S_{n}-S_{n-1}=\sqrt{n}-\sqrt{n-1}$ ，又 $a_{1}=1$ 满足此式，
> >
> > 即 $\forall n\in N^{*}$ ，都有 $a_{n}=\sqrt{n}-\sqrt{n-1}$ ；
> >
> > (2) 不存在，理由如下：
> >
> > 由（1）中 $a_{n} = \sqrt{n} -\sqrt{n - 1}$ 可得： $\frac{1}{a_n} = \frac{1}{\sqrt{n} - \sqrt{n - 1}} = \sqrt{n} +\sqrt{n - 1}$
> >
> > 假设存在满足要求的连续三项 $a_{k}, a_{k+1}, a_{k+2}$ ，使得 $\frac{1}{a_k}, \frac{1}{a_{k+1}}, \frac{1}{a_{k+2}}$ 构成等差数列，
> >
> > 则 $2(\sqrt{k + 1} + \sqrt{k}) = (\sqrt{k} + \sqrt{k - 1}) + (\sqrt{k + 2} + \sqrt{k + 1})$ ，即 $\sqrt{k + 1} + \sqrt{k} = \sqrt{k - 1} + \sqrt{k + 2}$
> >
> > 两边平方，得 $k + 1 + k + 2\sqrt{k + 1}\sqrt{k} = k - 1 + k + 2 + 2\sqrt{k - 1}\sqrt{k + 2}$ ，即 $(k + 1)k = (k - 1)(k + 2)$
> >
> > 整理得： $k^{2} + k = k^{2} + k - 2$ ，即 $0 = -2$ ，显然不成立，因此假设是错误的，
> >
> > 所以数列 $\{a_{n}\}$ 中不存在使 $\frac{1}{a_k},\frac{1}{a_{k + 1}},\frac{1}{a_{k + 2}}$ 构成等差数列的连续三项
