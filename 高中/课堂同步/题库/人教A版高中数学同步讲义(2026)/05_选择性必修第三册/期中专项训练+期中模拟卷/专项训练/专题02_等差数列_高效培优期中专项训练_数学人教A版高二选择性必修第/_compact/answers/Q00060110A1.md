> [!faq]- 《专题02_等差数列_高效培优期中专项训练_数学人教A版高二选择性必修第》官方解析
>
> > [!success]- **【答案】** ABD
>
> > [!note]- **【解析】**
> > 在等差数列 $\{a_{n}\}$ 中，由为 $S_{13} > 0, S_{14} < 0$
> >
> > 可得 $S_{13} = \frac{13(a_1 + a_{13})}{2} = 13a_7 > 0, S_{14} = \frac{14(a_1 + a_{14})}{2} = \frac{14(a_7 + a_8)}{2} < 0$
> >
> > 所以 $a_7 > 0, a_7 + a_8 < 0$ ，可得 $a_7 > 0, a_8 < 0$
> >
> > 又由 $d = a_{8} - a_{7} < 0$ ，所以 $\mathsf{A}$ 正确， $\mathsf{B}$ 正确；
> >
> > 由 $\left|a_{7}\right|-\left|a_{8}\right|=a_{7}+a_{8}<0$ ，所以 $\left|a_{7}\right|<\left|a_{8}\right|$ ，所以C错误；
> >
> > 由 $a_7 > 0, a_8 < 0$ 且 $d < 0$ ，可得当 $1 \leq n \leq 7$ 时， $a_n > 0$ ；当 $n = 8$ 时， $a_n < 0$
> >
> > 所以，当 $n = 7$ 时， $S_{n}$ 取最大值，所以 ${}^{\mathrm{D}}$ 正确
> >
> > 故选 **ABD**.
