> [!faq]- 《专题02_等差数列_高效培优期中专项训练_数学人教A版高二选择性必修第》官方解析
>
> > [!success]- **【答案】** (1) $a_{n}=9-2n$ (2) $S_{n}=-n^{2}+8n$ ，n=4，最大值为16 (3)证明见解析
>
> > [!note]- **【解析】**
> > （1）设等差数列 $\{a_{n}\}$ 的公差为 $d$ ，由题意得：
> >
> > 所以 $S_{3}=3a_{1}+\frac{3\times2}{2}d=21+3d=15$ ，解得 d=-2，
> >
> > 所以 $a_{n}=7-2(n-1)=9-2n$ ;
> >
> > (2) 法一：由 $a_{n} = 9 - 2n > 0$ 得 $n < \frac{9}{2}$ ，又等差数列 $\left\{a_{n}\right\}$ 的公差 $d < 0$ ，
> >
> > 所以等差数列 $\{a_{n}\}$ 是递减数列，因为 $a_4 = 1 > 0, a_5 = -1 < 0$ ，所以等差数列 $\{a_{n}\}$ 前4和最大，
> >
> > 此时 $S_{4}=4a_{1}+\frac{4\times3d}{2}=28-12=16$ ;
> >
> > 法二：因为 $S_{n} = na_{1} + \frac{n(n - 1)d}{2} = -n^{2} + 8n = -(n - 4)^{2} + 16\quad 16$
> >
> > 所以当 n=4 时， $S_{n}$ 取到最大值 16.
> >
> > (3) $\frac{1}{b_1b_2} + \frac{1}{b_2b_3} + \dots + \frac{1}{b_nb_{n+1}} = \frac{1}{1 \times 2} + \frac{1}{2 \times 3} + \dots + \frac{1}{n(n+1)}$
> >
> > $$
> > = 1 - \frac {1}{2} + \frac {1}{2} - \frac {1}{3} + \dots + \frac {1}{n} - \frac {1}{n + 1} = 1 - \frac {1}{n + 1}
> > $$
> >
> > 因为 $n+1>0$ ，所以 $1-\frac{1}{n+1}<1$ ，即 $\frac{1}{b_{1}b_{2}}+\frac{1}{b_{2}b_{3}}+\frac{1}{b_{3}b_{4}}+\cdots+\frac{1}{b_{n}b_{n+1}}<1$ .
