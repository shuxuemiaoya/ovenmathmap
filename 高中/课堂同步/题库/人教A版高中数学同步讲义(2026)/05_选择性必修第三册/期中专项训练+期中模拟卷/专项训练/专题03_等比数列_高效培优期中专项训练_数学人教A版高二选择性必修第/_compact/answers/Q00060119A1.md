> [!faq]- 《专题03_等比数列_高效培优期中专项训练_数学人教A版高二选择性必修第》官方解析
>
> > [!success]- **【答案】** D
>
> > [!note]- **【解析】**
> > $a_{n + 1} = 2a_{n} + 2$ ，所以 $a_{n + 1} + 2 = 2(a_n + 2)$
> >
> > 所以 $\left\{a_{n}+2\right\}$ 是以 $a_{1}+2=4$ 为首项、2 为公比的等比数列，
> >
> > 所以 $a_{n} + 2 = 4 \times 2^{n-1}$
> >
> > 所以 $b_{n} = (n - \lambda)\log_{2}(a_{n} + 2) = (n - \lambda)(n + 1) = n^{2} + (1 - \lambda)n - \lambda$
> >
> > 若数列 $\{b_n\}$ 是递增数列，则 $b_{n + 1} > b_n$ 恒成立，
> >
> > 所以 $b_{n+1}-b_{n}=(n+1)^{2}+(1-\lambda)(n+1)-\lambda-\left[n^{2}+(1-\lambda)n-\lambda\right]$
> >
> > $= 2n + 1 + 1 - \lambda = 2n + 2 - \lambda >0$ 恒成立，
> >
> > 所以 $\lambda < 2n + 2$ 恒成立，所以 $\lambda < (2n + 2)_{\min} = 4$
> >
> > 所以实数 $\lambda$ 的取值范围是 $(-∞,4)$ .
> >
> > 故选：D.

> > 8. 数列 $\{a_{n}\}$ 满足 $a_{2} = 5, a_{n+1} = 2a_{n} - 1$ .
> >
> > (1)证明：数列 $\{a_{n} - 1\}$ 是等比数列；
> >
> > (2)若 $b_{n} = \frac{a_{n} - 1}{a_{n}a_{n + 1}}$ ，证明：数列 $\{b_n\}$ 的前 $n$ 项和 $S_{n} <   \frac{1}{3}$
> >
> > 【答案】(1)证明见解析
> >
> > (2)证明见解析
> >
> > 【详解】（1）由 $a_2 = 5, a_{n+1} = 2a_n - 1$ 可得 $5 = 2a_1 - 1$ ，解得 $a_1 = 3$ ，则 $a_1 - 1 = 2 \neq 0$ .
> >
> > 且 $a_{n + 1} - 1 = 2(a_n - 1)$ ，故 $\{a_n - 1\}$ 是以 $^2$ 为首项， $^2$ 为公比的等比数列，即得证·
> >
> > (2) 由 (1) $a_{n} - 1 = 2^{n}$ , 故 $a_{n} = 2^{n} + 1$ ,
> >
> > $b_{n} = \frac{a_{n} - 1}{a_{n}a_{n + 1}} = \frac{2^{n}}{(2^{n} + 1)(2^{n + 1} + 1)} = \frac{1}{2^{n} + 1} -\frac{1}{2^{n + 1} + 1}$
> >
> > $$
> > S _ {n} = \frac {1}{2 ^ {1} + 1} - \frac {1}{2 ^ {2} + 1} + \frac {1}{2 ^ {2} + 1} - \frac {1}{2 ^ {3} + 1} + \dots + \frac {1}{2 ^ {n} + 1} - \frac {1}{2 ^ {n + 1} + 1}
> > $$
> >
> > $= \frac{1}{3} -\frac{1}{2^{n + 1} + 1} <  \frac{1}{3}$ ，即得证.
