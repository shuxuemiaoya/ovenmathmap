> [!faq]- 《专题01_数列的概念_高效培优期中专项训练_数学人教A版高二选择性必修》官方解析
>
> > [!success]- **【答案】** (1) $a_{n}=2n-1,\quad b_{n}=2^{n}$ (2)5
>
> > [!note]- **【解析】**
> > （1）设等差数列 $\{a_{n}\}$ 的公差为 $d$ ，
> >
> > 当 $d = 0$ 时，则 $\frac{1}{a_1a_2} +\frac{1}{a_2a_3} +\dots +\frac{1}{a_{10}a_{11}} = \frac{10}{a_1^2} = \frac{10}{21}$ ，与 $a_1 = 1$ 矛盾，不合题意；
> >
> > 当 $d \neq 0$ 时， $\frac{1}{a_{1}a_{2}} + \frac{1}{a_{2}a_{3}} + \cdots + \frac{1}{a_{10}a_{11}} = \frac{1}{d} \left[ \left( \frac{1}{a_{1}} - \frac{1}{a_{2}} \right) + \left( \frac{1}{a_{2}} - \frac{1}{a_{3}} \right) + \cdots + \left( \frac{1}{a_{10}} - \frac{1}{a_{11}} \right) \right]$
> >
> > $$
> > = \frac {1}{d} \left(1 - \frac {1}{a _ {1 1}}\right) = \frac {1}{d} \left(1 - \frac {1}{1 + 1 0 d}\right) = \frac {1 0}{1 + 1 0 d} = \frac {1 0}{2 1}
> > $$
> >
> > 解得 d = 2 ，所以 $a_{n} = 1 + 2(n - 1) = 2n - 1$
> >
> > 即 $a_{n} = 2n - 1$
> >
> > 当 n=1 时， $b_{1}=S_{1}=2b_{1}-2$ ，得 $b_{1}=2$ ，
> >
> > 当 n 2 时， $S_{n}=2b_{n}-2$ ①，
> >
> > $S_{n - 1} = 2b_{n - 1} - 2$ $②$
> > - **①**：- ② 得 $b_n = 2b_n - 2b_{n-1}$ ，即 $b_n = 2b_{n-1}$ ，即 $\frac{b_n}{b_{n-1}} = 2$ ，
> >
> > 所以数列 $\{b_n\}$ 是以 $^2$ 为首项， $^2$ 为公比的等比数列，所以 $b_n = 2 \times 2^{n-1} = 2^n$ 即 $b_n = 2^n$ ；
> >
> > (2) $c_{n} = \frac{b_{n} - a_{n} - 3}{3^{n}} = \frac{2^{n} - 2n - 2}{3^{n}}$ ，则 $c_{n + 1} = \frac{2^{n + 1} - 2n - 4}{3^{n + 1}}$
> >
> > 所以 $c_{n + 1} - c_n = \frac{2^{n + 1} - 2n - 4}{3^{n + 1}} -\frac{2^n - 2n - 2}{3^n} = \frac{4n + 2 - 2^n}{3^{n + 1}}$
> >
> > 令 $f(n) = 4n + 2 - 2^n$ ，则 $f(n + 1) = 4n + 6 - 2^{n + 1}$
> >
> > $$
> > f (n + 1) - f (n) = 4 - 2 ^ {n}
> > $$
> >
> > 则 $f(1)\left\langle f(2)=f(3)\right\rangle f(4)>0>f(5)>\cdots,$
> >
> > 所以 $c_{n + 1} - c_n > 0$ ，得出 $1 \leq n \leq 4$
> >
> > 即 $c_{1} < c_{2} < c_{3} < c_{4} < c_{5}, c_{5} > c_{6} > \dots$
> >
> > 所以数列 $\{c_{n}\}$ 中， $c_{5}$ 最大，故 $n = 5$ .
