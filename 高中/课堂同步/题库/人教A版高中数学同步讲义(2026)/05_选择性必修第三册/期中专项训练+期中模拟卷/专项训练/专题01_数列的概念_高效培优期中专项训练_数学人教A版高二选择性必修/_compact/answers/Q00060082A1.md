> [!faq]- 《专题01_数列的概念_高效培优期中专项训练_数学人教A版高二选择性必修》官方解析
>
> > [!success]- **【答案】** 2 37
>
> > [!note]- **【解析】**
> > 由已知 $a_{a_1} = 3$ ，若 $a_1 = 1$ ，将有 $a_1 = 3$ ，矛盾；
> >
> > 若 $a_1 = k$ 3，则 $a_{k} = a_{a_{1}} = 3\leq a_{1}$ ，与 $\{a_n\}$ 单调性矛盾；故 $a_1 = 2$
> >
> > 由 $a_1 = 2$ ，有 $a_2 = a_{a_1} = 3, a_3 = a_{a_2} = 6$ ，所以 $a_6 = a_{a_3} = 9, a_9 = a_{a_6} = 18$
> >
> > 又 $a_3 < a_4 < a_5 < a_6$ ，则 $6 < a_4 < a_5 < 9$ ，所以 $a_4 = 7, a_5 = 8$
> >
> > 故 $a_{7} = a_{a_{4}} = 12, a_{12} = a_{a_{7}} = 21$
> >
> > 则由 $a_{9} < a_{10} < a_{11} < a_{12}$ ，即 $18 < a_{10} < a_{11} < 21$ ，知 $a_{10} = 19$ ，故 $a_{9} + a_{10} = 37$ .
> >
> > 故答案为：2；37
