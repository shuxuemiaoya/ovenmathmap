> [!faq]- 《高二数学下学期期中模拟卷_人教A版_高效培优_强化卷_》官方解析
>
> > [!success]- **【答案】** ACD
>
> > [!note]- **【解析】**
> > 依题意可知，点 $P(1, f(1))$ 为切点，代入 $3x + 3y - 4 = 0$ 可得，
> >
> > $f(1)=\frac{1}{3}$ ，又 $f(1)=\frac{1}{3}+a+b+1=\frac{1}{3}$ ，即 $a+b=-1$
> >
> > 又由 $f(x) = \frac{1}{3} x^3 + ax^2 + bx + 1$ ，得 $f'(x) = x^2 + 2ax + b$ .
> >
> > 依题可得 $f'(1) = -1$ ，代入上式，可得 $1 + 2a + b = -1$ ，即 $2a + b = -2$ ，
> >
> > 由 $\left\{ \begin{array}{l}a + b = -1\\ 2a + b = -2 \end{array} \right.$ ，解得 $\left\{ \begin{array}{ll}a = -1\\ b = 0 \end{array} \right.$ ，故A正确，B错误；
> >
> > 对于 C，由上分析可得 $f(x)=\frac{1}{3}x^{3}-x^{2}+1$ ，则 $f'(x)=x^{2}-2x$ ，
> >
> > 由 $f^{\prime}(x) > 0$ ，可得 $x <   0$ 或 $x > 2$ ；由 $f^{\prime}(x) <   0$ ，可得 $0 <   x <   2$
> >
> > 故 $f(x)$ 在 $(- \infty, 0), (2, +\infty)$ 上单调递增，在 $(0, 2)$ 上单调递减，
> >
> > 所以 $f(x)$ 的极大值为 $f(0) = 1$ ，因 $f(3) = \frac{1}{3} \times 3^3 - 3^2 + 1 = 1$
> >
> > 由题 $f(x)$ 在区间 $(m - 1, m + 5)$ 上有最大值，故有 $\left\{ \begin{array}{l} m - 1 < 0 \\ 0 < m + 5 \leq 3 \end{array} \right.$ ，
> >
> > 解得 $m \in (-5, -2]$ ，故C正确；
> >
> > 对于 D，因 $f(x)=\frac{1}{3}x^{3}-x^{2}+1$ ，则 $f'(x)=x^{2}-2x, f(x+2)=\frac{1}{3}(x+2)^{3}-(x+2)^{2}+1$ ，
> >
> > 于是 $f'(x + 2) = (x + 2)^2 - 2(x + 2) = x^2 + 2x = f'(-x)$ ，故D正确.
> >
> > 故选 **ACD**.
