> [!faq]- 《高二数学下学期期中模拟卷_人教A版_高效培优_强化卷_》官方解析
>
> > [!success]- **【答案】** (1)证明见解析 (2) $b_{n}=2^{n}$ (3)证明见解析
>
> > [!note]- **【解析】**
> > （1）因为数列 $\{a_{n}\},\{b_{n}\}$ 的通项公式分别为 $a_{n} = 2n - 1,b_{n} = 2^{n - 1}$
> >
> > 所以 $a_{1}b_{1}+a_{2}b_{2}+a_{3}b_{3}+\cdots+a_{n}b_{n}=1\cdot2^{0}+3\cdot2^{1}+5\cdot2^{2}+\cdots+(2n-1)\cdot2^{n-1}$
> >
> > 设 $S_{n}=1\cdot2^{0}+3\cdot2^{1}+5\cdot2^{2}+\cdots+(2n-1)\cdot2^{n-1}$
> >
> > 则 $2S_{n}=1\cdot2^{1}+3\cdot2^{2}+5\cdot2^{3}+\cdots+(2n-1)\cdot2^{n}$
> >
> > 两式相减，可得 $-S_{n}=1+2\cdot2^{1}+2\cdot2^{2}+\cdots+2\cdot2^{n-1}-(2n-1)\cdot2^{n}$
> >
> > $$
> > = 1 + 2 \cdot \frac {2 (1 - 2 ^ {n - 1})}{1 - 2} - (2 n - 1) \cdot 2 ^ {n} = - 3 - (2 n - 3) \cdot 2 ^ {n}
> > $$
> >
> > 所以 $S_{n}=(2n-3)\cdot2^{n}+3$
> >
> > 又 $a_{n - 1}b_{n + 1} + 3 = (2n - 3)\cdot 2^n +3$
> >
> > 所以对任意 $n$ $2, n \in \mathbf{N}^{*}$ ，都有 $a_{1}b_{1} + a_{2}b_{2} + a_{3}b_{3} + \cdots + a_{n}b_{n} = a_{n-1}b_{n+1} + 3$
> >
> > 所以 $\left\{a_{n}\right\},\left\{b_{n}\right\}$ 为“3- 友好数列”.
> >
> > (2) 因为 $a_{n}=n+1$ ，所以 $a_{1}=b_{1}=2$ ， $a_{3}=b_{2}=4$ ，c=0，
> >
> > 且 $a_{1}b_{1} + a_{2}b_{2} + a_{3}b_{3} + \cdots + a_{n}b_{n} = a_{n-1}b_{n+1}(n - 2)$
> >
> > 所以 $2b_{1} + 3b_{2} + 4b_{3} + \cdots + (n + 1)b_{n} = nb_{n+1}(n - 2)$ ，①
> >
> > 当 n 3 时， $2b_{1} + 3b_{2} + 4b_{3} + \cdots + nb_{n-1} = (n - 1)b_{n}$ ，②
> > - **①**：-②得 $2nb_{n}=nb_{n+1}$ ，即 $\frac{b_{n+1}}{b_{n}}=2(n-3)$
> >
> > 当 n=2 时，①可化为 $2b_{1}+3b_{2}=2b_{3}$ ，即 $2\times2+3\times4=2b_{3}, b_{3}=8$
> >
> > 所以 $\frac{b_3}{b_2} = 2, \frac{b_2}{b_1} = 2$ 成立，所以数列 $\{b_n\}$ 是首项为 2，公比为 2 的等比数列，
> >
> > 所以 $b_{n} = 2^{n}$
> >
> > (3) 因为数列 $\left\{a_{n}\right\},\left\{b_{n}\right\}$ 为“3- 友好数列”，
> >
> > 所以对任意的 n $2, n \in N^{*}$ ，都有 $a_{1}b_{1} + a_{2}b_{2} + a_{3}b_{3} + \cdots + a_{n}b_{n} = a_{n-1}b_{n+1} + 3$
> >
> > 设等比数列 $\left\{b_{n}\right\}$ 的公比为 $q,b_{1}=1$ ，则 $b_{n}=q^{n-1}$
> >
> > 当 $n = 2$ 时，可得 $1 + a_{2}q = q^{2} + 3$ ，即 $a_2 = \frac{2}{q} +q$
> >
> > 由 $a_2 \in \mathbf{N}^*$ 得 $q = 1$ 或 $q = 2$ .
> >
> > 当 q=1 时， $b_{n}=1, a_{2}=3$
> >
> > 当 n=3 时， $1+a_{2}+a_{3}=a_{2}+3$ ，则 $a_{3}=2$ 。
> >
> > 当 n=4 时， $1+a_{2}+a_{3}+a_{4}=a_{3}+3$ ，则 $a_{4}=-1$ 。
> >
> > 这与 $a_{n} \in \mathbf{N}^{*}$ 矛盾，所以 $q = 1$ 不符合题意.
> >
> > 当 $q = 2$ 时， $b_{n} = 2^{n - 1}, a_{2} = 3$
> >
> > 进而 n 2 时，恒有 $1 + 2a_{2} + 4a_{3} + \cdots + 2^{n-1}a_{n} = 2^{n}a_{n-1} + 3$ ，①
> >
> > 所以 n 3 时，恒有 $1 + 2a_{2} + 4a_{3} + \cdots + 2^{n-2}a_{n-1} = 2^{n-1}a_{n-2} + 3$ ，②
> > - **①**：-② 可得 $2a_{n-1}=a_{n-2}+a_{n}(n\quad3)$ .
> >
> > 故数列 $\left\{a_{n}\right\}$ 为等差数列.
