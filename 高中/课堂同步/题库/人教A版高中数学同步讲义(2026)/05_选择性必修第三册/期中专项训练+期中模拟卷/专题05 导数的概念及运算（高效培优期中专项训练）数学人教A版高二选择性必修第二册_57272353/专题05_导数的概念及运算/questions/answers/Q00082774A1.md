> [!faq]- 《专题05 导数的概念及运算（高效培优期中专项训练）数学人教A版高二选择性必修第二册_57272353》官方解析
>
> > [!success]- **【答案】** B
>
> > [!note]- **【解析】**
> > 设切点为 $A(x_{0}, y_{0})$
> >
> > 由已知可得 $y' = e^{x}(x + a + 1)$ .
> >
> > 根据导数的几何意义可知，
> >
> > 切线的斜率为 $k = y' = e^{x_{0}}(x_{0} + a + 1)$ .
> >
> > 代入切线方程为 $y - y_0 = k(x - x_0)$
> >
> > 整理可得 $y - (x_0 + a)\mathrm{e}^{x_0} = \mathrm{e}^{x_0}(x_0 + a + 1)(x - x_0)$
> >
> > 又切线经过原点，
> >
> > 所以有 $0 - (x_0 + a)\mathrm{e}^{x_0} = \mathrm{e}^{x_0}(x_0 + a + 1)(0 - x_0)$
> >
> > 整理可得 $x_0^2 + ax_0 - a = 0$
> >
> > 因为曲线 $y=(x+a)e^{x}$ 有两条过坐标原点的切线，
> >
> > 所以方程有两个不相等的实数解，
> >
> > 即有 $\Delta = a^{2} + 4a > 0$ ，解得 a < -4 或 a > 0。
> >
> > 故选 **B**.
