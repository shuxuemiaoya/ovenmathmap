> [!faq]- 《专题05 导数的概念及运算（高效培优期中专项训练）数学人教A版高二选择性必修第二册_57272353》官方解析
>
> > [!success]- **【答案】** A. $\left(x + \frac{1}{x}\right)' = 1 + \frac{1}{x^2}$ B. $\left[\ln (2x + 1)\right]' = \frac{1}{2x + 1}$ C. $\left(\frac{\mathrm{e}^x}{x}\right)' = \frac{\mathrm{e}^x(x + 1)}{x^2}$ D. $(x\sin x)' = \sin x + x\cos x$
>
> > [!note]- **【解析】**
> > $\left(x + \frac{1}{x}\right)' = x' + \left(\frac{1}{x}\right)' = 1 - \frac{1}{x^2}$ ，A不正确；
> >
> > $\left[\ln (2x + 1)\right]' = \frac{1}{2x + 1} \times (2x + 1)' = \frac{2}{2x + 1}$ ，B不正确；
> >
> > $\left(\frac{\mathrm{e}^{x}}{x}\right)^{\prime}=\frac{\left(\mathrm{e}^{x}\right)^{\prime}\cdot x-\mathrm{e}^{x}\cdot x^{\prime}}{x^{2}}=\frac{\mathrm{e}^{x}(x-1)}{x^{2}}$ ，C不正确；
> >
> > $\left(x\sin x\right)^{\prime}=x^{\prime}\sin x+x\left(\sin x\right)^{\prime}=\sin x+x\cos x$ ，D 正确.
> >
> > 故选 **D**
