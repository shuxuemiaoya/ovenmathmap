> [!faq]- 《专题15 计数原理及随机变量及其分布精选压轴70题14类考点专练（期中复习专项训练）数学人教A版高二选择性必修第三册_57394125》官方解析
>
> > [!success]- **【答案】** A. $a_{0}=64$ B. $a_{1}+a_{3}+a_{5}+a_{7}=2$ C. $a_{0} + a_{2} + a_{4} + a_{6} = 1$ D. $a_{1} + a_{2} + a_{3} + a_{4} + a_{5} + a_{7} = -51$
>
> > [!note]- **【分析】**
> > A选项，令 $x = 0$ 得， $a_0 = 64$ ；BC选项，令 $x = 1$ 和 $x = -1$ ，两式相加减，得到BC；D选项，写
> >
> > 出 $\left(x - 2\right)^6$ 展开式的通项公式，得到 $a_6 = -11$ ，结合ABC选项所求结论得到答案.
>
> > [!note]- **【解析】**
> > A选项， $(x+1)(x-2)^{6}=a_{0}+a_{1}x+a_{2}x^{2}+\cdots a_{6}x^{6}+a_{7}x^{7}$ 中，令x=0得，
> >
> > $(0+1)\times(0-2)^{6}=a_{0}$ ，故 $a_{0}=64$ ，A正确；
> >
> > BC 选项， $(x+1)(x-2)^{6}=a_{0}+a_{1}x+a_{2}x^{2}+\cdots a_{6}x^{6}+a_{7}x^{7}$ 中，令 x=1 得
> >
> > $$
> > a _ {0} + a _ {1} + a _ {2} + a _ {3} + \dots + a _ {6} + a _ {7} = (1 + 1) \times (1 - 2) ^ {6} = 2 \tag {①}
> > $$
> >
> > 令 x = -1 得 $a_{0} - a_{1} + a_{2} - a_{3} + \cdots + a_{6} - a_{7} = (-1 + 1) \times (-1 - 2)^{6} = 0$ ②，
> >
> > 式子①+②得 $2(a_{0} + a_{2} + a_{4} + a_{6}) = 2$ ，故 $a_0 + a_2 + a_4 + a_6 = 1$ ，C正确，
> >
> > 式子①-②得 $2(a_{1}+a_{3}+a_{5}+a_{7})=2$ ，故 $a_{1}+a_{3}+a_{5}+a_{7}=1$ ，B 错误；
> >
> > D 选项， $(x-2)^{6}$ 展开式的通项公式为 $T_{r+1}=C_{6}^{r}x^{6-r}(-2)^{r}$
> >
> > 则 $T_{1} = \mathrm{C}_{6}^{0}x^{6}\left(-2\right)^{0} = x^{6}, T_{2} = \mathrm{C}_{6}^{1}x^{5}\left(-2\right) = -12x^{5}$
> >
> > 所以 $a_{6}=1\times1+1\times(-12)=-11$
> >
> > 由①得 $a_{0} + a_{1} + a_{2} + a_{3} + \cdots + a_{6} + a_{7} = 2$ ，由 A 知， $a_{0} = 64$ ，
> >
> > 所以 $a_{1} + a_{2} + a_{3} + a_{4} + a_{5} + a_{7} = 2 - 64 - (-11) = -51$ ，D 正确.
> >
> > 故选 **ACD**
