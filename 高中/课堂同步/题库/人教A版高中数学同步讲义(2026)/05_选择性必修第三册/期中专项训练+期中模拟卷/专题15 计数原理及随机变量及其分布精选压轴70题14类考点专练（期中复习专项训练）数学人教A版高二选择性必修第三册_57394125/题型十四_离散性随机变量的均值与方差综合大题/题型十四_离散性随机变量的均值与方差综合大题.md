66. 随着 deepseek 等人工智能大模型的快速发展，某市文创体验馆推出了“AI 创意手作”的线下体验项目.

为优化运营策略，运营团队统计了过去100天的运营数据，以各客流量等级的日平均收入作为日收入，

整理成如下表格：

<table><tr><td>客流量等级</td><td>小客流(A)</td><td>中客流(B)</td><td>大客流(C)</td></tr><tr><td>天数</td><td>30</td><td>50</td><td>20</td></tr><tr><td>日收入(元)</td><td>4000</td><td>10000</td><td>22000</td></tr><tr><td>设备发生故障的概率</td><td>0.1</td><td>0.2</td><td>0.4</td></tr></table>

① 设备发生的故障又分为“轻微故障”和“严重故障”，其中设备发生轻微故障的概率为 $\frac{2}{3}$ ，发生严重故障的

$$
\begin{array}{c} \frac {2}{3} \end{array}
$$

概率为 $\frac{1}{3}$ ；②若设备无故障，当日收入不变，无维修费用支出；若设备发生轻微故障，当日收入不变，

但需支付维修费200元；若设备发生严重故障，当日收入减半，还需支付维修费1000元.已知每日客流量

等级相互独立，故障类型与客流量等级相互独立，用频率估计每日的客流量等级的概率.

(1)求该项目在将来某一日客流量等级为中客流且设备发生严重故障的概率；

(2)设该项目在将来某一日的运营总损失为 $X$ 元（运营总损失 $=$ 维修费 $+$ 收入损失），求 $X$ 的分布列和均

值.

【答案】(1) $\frac{1}{30}$

(2) $X$ 的分布列为

<table><tr><td>X</td><td>0</td><td>200</td><td>3000</td><td>6000</td><td>12000</td></tr><tr><td>P</td><td> $\frac{79}{100}$ </td><td> $\frac{7}{50}$ </td><td> $\frac{1}{100}$ </td><td> $\frac{1}{30}$ </td><td> $\frac{2}{75}$ </td></tr></table>

$E(X) = 578$

【分析】（1）根据独立事件的乘法公式直接计算即可；

(2) 根据当日设备没有发生故障、发生轻微故障、发生严重故障且为小客流、中客流、大客流等情况依

次讨论对应的取值及概率即可求解.

【详解】（1）由频率估计概率，根据表中数据，客流量等级为中客流（B）的概率为 $P(B) = \frac{50}{100} = \frac{1}{2}$

已知中客流设备发生故障的概率为 0.2，故障中发生严重故障的概率为 $\frac{1}{3}$ ，且各事件相互独立，

记该项目在将来某一日客流量等级为中客流且设备发生严重故障的概率为 p ，

则 $p=\frac{1}{2}\times0.2\times\frac{1}{3}=\frac{1}{30}$ .

(2) 该项目在将来某一日的运营总损失 $X$ 的可能取值为 0, 200, 3000, 6000, 12000,

客流量等级为小客流（A）的概率为 $P(A) = \frac{30}{100} = \frac{3}{10}$ ，客流量等级为大客流（C）的概率为 $P(C) = \frac{20}{100} = \frac{1}{5}$ ，

当日设备没有发生故障时，X = 0

$$
P (X = 0) = \frac {3}{1 0} \times (1 - 0. 1) + \frac {1}{2} \times (1 - 0. 2) + \frac {1}{5} \times (1 - 0. 4) = \frac {7 9}{1 0 0},
$$

当日设备发生轻微故障时，X = 200，

$$
P (X = 2 0 0) = \left(\frac {3}{1 0} \times 0. 1 + \frac {1}{2} \times 0. 2 + \frac {1}{5} \times 0. 4\right) \times \frac {2}{3} = \frac {7}{5 0}
$$

当日为小客流且发生严重故障时，X = 3000，

$$
P (X = 3 0 0 0) = \frac {3}{1 0} \times 0. 1 \times \frac {1}{3} = \frac {1}{1 0 0},
$$

当日为中客流且发生严重故障时，X = 6000，

$$
P (X = 6 0 0 0) = \frac {1}{2} \times 0. 2 \times \frac {1}{3} = \frac {1}{3 0},
$$

当日为大客流且发生严重故障时，X=12000

$$
P (X = 1 2 0 0 0) = \frac {1}{5} \times 0. 4 \times \frac {1}{3} = \frac {2}{7 5},
$$

所以 $X$ 的分布列为：

<table><tr><td>X</td><td>0</td><td>200</td><td>3000</td><td>6000</td><td>12000</td></tr><tr><td>P</td><td> $\frac{79}{100}$ </td><td> $\frac{7}{50}$ </td><td> $\frac{1}{100}$ </td><td> $\frac{1}{30}$ </td><td> $\frac{2}{75}$ </td></tr><tr><td></td><td></td><td></td><td></td><td></td><td></td></tr></table>

$$
E (X) = 0 \times \frac {7 9}{1 0 0} + 2 0 0 \times \frac {7}{5 0} + 3 0 0 0 \times \frac {1}{1 0 0} + 6 0 0 0 \times \frac {1}{3 0} + 1 2 0 0 0 \times \frac {2}{7 5} = 0 + 2 8 + 3 0 + 2 0 0 + 3 2 0 = 5 7 8
$$

67. 为了了解高一学生的体质状况，某校开展了一次体质测试，从中随机抽取40名女学生的立定跳远成

绩（单位：厘米）进行分析，得到如下频率分布表．

<table><tr><td>成绩区间</td><td>[160, 170)</td><td>[170, 180)</td><td>[180, 190)</td><td>[190, 200)</td><td>[200, 210)</td><td>[210, 220]</td></tr><tr><td>频率</td><td>0.10</td><td>0.15</td><td>0.20</td><td>0.25</td><td>0.20</td><td>0.10</td></tr></table>

(1)计算这40名女学生立定跳远成绩的众数、平均数的近似值（同一组中的数据用该组区间的中点值为代

表）；

(2)规定成绩在区间 $[210, 220]$ , $[200, 210)$ , $[190, 200)$ 分别为 $A, B, C$ 等级．用分层抽样的方法从成

绩在这三个等级的学生中抽取11人，再从11人中随机抽取3人进行示范．记示范学生中成绩 $A$ 等级的人

数为 $X$ ，求 $X$ 的分布列与 $E(X)$

【答案】(1)195 厘米，191 厘米

(2)分布列见解析， $\frac{6}{11}$

【分析】（1）根据众数、平均数的定义求解；

(2) 由分层抽样确定各等级人数，得 X 的所有可能取值为 0, 1, 2，计算出概率后得分布列.

【详解】（1）这六个区间中，频率最大为0.25，该区间为[190，200），则这40名学生立定跳远成绩的

众数的近似值为 195 厘米，

$$
\text {平均数} = 1 6 5 \times 0. 1 0 + 1 7 5 \times 0. 1 5 + 1 8 5 \times 0. 2 0 + 1 9 5 \times 0. 2 5 + 2 0 5 \times 0. 2 0 + 2 1 5 \times 0. 1 0 = 1 9 1
$$

所以这 40 名学生立定跳远成绩的平均数的近似值为 191 厘米.

(2) 由分层抽样，可知 $C$ 等级对应5人， $B$ 等级对应4人， $A$ 等级对应2人。

从 11 人中选 3 人，共 $C_{11}^{3}=165$ 种。

X 的所有可能取值为 0, 1, 2,

$$
P (X = 0) = \frac {\mathrm{C} _ {2} ^ {0} \mathrm{C} _ {9} ^ {3}}{\mathrm{C} _ {1 1} ^ {3}} = \frac {2 8}{5 5}, P (X = 1) = \frac {\mathrm{C} _ {2} ^ {1} \mathrm{C} _ {9} ^ {2}}{\mathrm{C} _ {1 1} ^ {3}} = \frac {2 4}{5 5}, P (X = 2) = \frac {\mathrm{C} _ {2} ^ {2} \mathrm{C} _ {9} ^ {1}}{\mathrm{C} _ {1 1} ^ {3}} = \frac {3}{5 5}
$$

则 $X$ 的分布列为

<table><tr><td>X</td><td>0</td><td>1</td><td>2</td></tr><tr><td>P</td><td> $\frac{28}{55}$ </td><td> $\frac{24}{55}$ </td><td> $\frac{3}{55}$ </td></tr></table>

$$
E (X) = 0 \times \frac {2 8}{5 5} + 1 \times \frac {2 4}{5 5} + 2 \times \frac {3}{5 5} = \frac {6}{1 1}
$$

68. 为落实《全民健身条例》，某区体育局对本区居民的健身场所选择偏好进行调研.数据显示，居民主

要选择商业健身场馆（如健身房、体育中心）和社区公共运动场（如小区健身点、街心公园）两类场所为

了解年龄因素是否影响健身场所的选择，研究人员将成年居民分为青壮年组（18岁且<40岁）和中老

年组（40岁），从该区随机抽取170名成年居民进行调查，得到如下不完整的 $2 \times 2$ 列联表：

<table><tr><td></td><td>青壮年</td><td>中老年</td><td>合计</td></tr><tr><td>商业健身场馆</td><td>60</td><td></td><td></td></tr><tr><td>社区公共运动场</td><td></td><td>50</td><td></td></tr><tr><td>合计</td><td>80</td><td></td><td>170</td></tr></table>

(1)请补充 $2 \times 2$ 列联表，并根据表中数据判断能否有 $95\%$ 的把握认为年龄与居民健身场所的选择有关；

(2)用分层抽样的方式从选择社区公共运动场的居民中抽取14个人，再从14个人中随机抽取7个人，用随

机变量 X 表示这 7 个人中中老年与青壮年人数之差的绝对值，求 X 的分布和数学期望.

参考公式及数据： $\chi^2 = \frac{n(ad - bc)^2}{(a + b)(c + d)(a + c)(b + d)}$ ，其中 $n = a + b + c + d$

<table><tr><td> $P(\chi^{2} \chi_{0})$ </td><td>0.1</td><td>0.05</td><td>0.025</td><td>0.01</td><td>0.005</td><td>0.001</td></tr><tr><td> $\chi_{0}$ </td><td>2.706</td><td>3.841</td><td>5.024</td><td>6.635</td><td>7.879</td><td>10.828</td></tr></table>

【答案】(1)列联表见解析，有95%的把握认为年龄与健身场所选择有关

(2) $X$ 的分布见解析，数学期望为 $\frac{439}{143}$ （或约3.07）

【分析】（1）先补全 $2 \times 2$ 列联表，再代入卡方独立性检验公式计算统计量，与 $95\%$ 置信度临界值比较，

判断年龄与健身场所选择是否有关联；

(2) 先按分层抽样确定抽取的青壮、中老年人数，再用超几何分布计算随机变量 $X$ 的各取值概率，列

出分布列并代入期望公式求数学期望.

【详解】（1）根据已知数据计算空缺值，得到完整 $2 \times 2$ 列联表如下：

<table><tr><td></td><td>青壮年</td><td>中老年</td><td>合计</td></tr><tr><td>商业健身场馆</td><td>60</td><td>40</td><td>100</td></tr><tr><td>社区公共运动场</td><td>20</td><td>50</td><td>70</td></tr><tr><td>合计</td><td>80</td><td>90</td><td>170</td></tr></table>

$\chi^{2} = \frac{170(60\times 50 - 40\times 20)^{2}}{100\times 70\times 80\times 90} = \frac{170\times(3000 - 800)^{2}}{50400000} = \frac{170\times 4840000}{50400000}\approx 16.33$ 因为 $16.33 > 3.841$

因此有 95% 的把握认为年龄与居民健身场所的选择有关.

(2) 选择社区公共运动场的居民共 70 人，其中青壮年 20 人、中老年 50 人，抽样比为 $\frac{14}{70} = \frac{1}{5}$

因此抽取的样本中青壮年人数： $20 \times \frac{1}{5} = 4$ ，中老年人数： $50 \times \frac{1}{5} = 10$

设抽取的7人中中老年人数为 $m$ ，则青壮年人数为 $7 - m$ ， $X = |m - (7 - m)| = |2m - 7|$

因为青壮年共 4 人，故 $7 - m \leq 4$ ，解得 m 3，又 $m \leq 7$ ，

因此 m=3,4,5,6,7 ，对应 X 的可能取值为 1,3,5,7 .

总情况数为 $C_{14}^{7}=3432$

$X = 1$ （对应 $m = 3$ 或 $m = 4$ ）时， $P(X = 1) = \frac{C_{10}^{3}C_{4}^{4} + C_{10}^{4}C_{4}^{3}}{C_{14}^{7}} = \frac{120 + 840}{3432} = \frac{960}{3432} = \frac{40}{143}$ ，

$X = 3$ （对应 $m = 5$ ）时， $P(X = 3) = \frac{C_{10}^{5}C_{4}^{2}}{C_{14}^{7}} = \frac{1512}{3432} = \frac{63}{143}$ ，

$X = 5$ （对应 $m = 6$ ）时， $P(X = 5) = \frac{C_{10}^{6}C_{4}^{1}}{C_{14}^{7}} = \frac{840}{3432} = \frac{35}{143}$ ，

$X = 7$ （对应 $m = 7$ ）时， $P(X = 7) = \frac{C_{10}^{7}C_{4}^{0}}{C_{14}^{7}} = \frac{120}{3432} = \frac{5}{143}$ ，

因此， $X$ 的分布列为：

<table><tr><td>X</td><td>1</td><td>3</td><td>5</td><td>7</td></tr><tr><td>P</td><td> $\frac{40}{143}$ </td><td> $\frac{63}{143}$ </td><td> $\frac{35}{143}$ </td><td> $\frac{5}{143}$ </td></tr></table>

所以 $E(X)=1\times\frac{40}{143}+3\times\frac{63}{143}+5\times\frac{35}{143}+7\times\frac{5}{143}=\frac{439}{143}\approx3.07$
