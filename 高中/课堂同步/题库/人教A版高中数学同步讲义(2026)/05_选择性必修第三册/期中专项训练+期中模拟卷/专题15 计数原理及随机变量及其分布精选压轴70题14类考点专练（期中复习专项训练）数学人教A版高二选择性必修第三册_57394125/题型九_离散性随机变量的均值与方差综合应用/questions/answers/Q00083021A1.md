> [!faq]- 《专题15 计数原理及随机变量及其分布精选压轴70题14类考点专练（期中复习专项训练）数学人教A版高二选择性必修第三册_57394125》官方解析
>
> > [!success]- **【答案】** 下列说法正确的是（一） A．在一个有限样本空间中，假设 $P(A)=P(B)=\frac{1}{3}$ ，且A与B相互独立，则 $P(A\cup B)=\frac{2}{3}$ B．已知随机变量 $\xi \sim B\left(4, \frac{1}{4}\right)$ ，则 $E(3\xi - 2) = 1$ C．根据分类变量 X 与 Y 的成对样本数据，计算得到 $\chi^{2}=9.850$ ，依据 $\alpha=0.01$ 的独立性检验 $\left(\chi_{0.01}^{2}=6.635\right)$ ，可判断 X 与 Y 独立 D．若随机变量 $X \sim N(5, \sigma^{2})$ ，且 $P(X - 3) = 4P(X - 7)$ ，则 $P(3 < X < 5) = \frac{3}{10}$
>
> > [!note]- **【分析】**
> > 对于 A：根据独立事件概率求法结合事件的运算求解；对于 B：根据二项分布的期望公式以及期
> >
> > 望的性质运算求解；对于 C：根据独立性检验思想分析判断；对于 D：根据正态分布的对称性运算求解.
>
> > [!note]- **【解析】**
> > 对于选项A：因为 $A$ 与 $B$ 相互独立，则 $P(AB) = P(A)P(B) = \frac{1}{9}$
> >
> > 所以 $P(A \cup B) = P(A) + P(B) - P(AB) = \frac{1}{3} + \frac{1}{3} - \frac{1}{9} = \frac{5}{9}$ ，故A错误；
> >
> > 对于选项B：因为随机变量 $\xi \sim B\left(4, \frac{1}{4}\right)$ ，则 $E(\xi) = 4 \times \frac{1}{4} = 1$
> >
> > 所以 $E(3\xi-2)=3E(\xi)-2=1$ ，故 B 正确；
> >
> > 对于选项 C：因为 $\chi^{2}=9.850>6.635=\chi_{0.01}^{2}$
> >
> > 根据依据 $\alpha = 0.01$ 的独立性检验原则，可知分类变量 X 与 Y 相关，不独立，故 C 错误；
> >
> > 对于选项 D：因为随机变量 $X \sim N(5, \sigma^{2})$ ，且 $\frac{3 + 7}{2} = 5$ ，
> >
> > $$
> > P (X \quad 3) = \frac {1}{2} + P (3 <   X <   5), P (X \quad 7) = \frac {1}{2} - P (5 <   X \leq 7) = \frac {1}{2} - P (3 <   X <   5)
> > $$
> >
> > 又因为 $P(X - 3) = 4P(X - 7)$ ，则 $\frac{1}{2} + P(3 < X < 5) = 4\left(\frac{1}{2} - P(3 < X < 5)\right)$
> >
> > 即 $5P(3 < X < 5) = \frac{3}{2}$ ，解得 $P(3 < X < 5) = \frac{3}{10}$ ，故D正确；
> >
> > 故选 **BD**.
