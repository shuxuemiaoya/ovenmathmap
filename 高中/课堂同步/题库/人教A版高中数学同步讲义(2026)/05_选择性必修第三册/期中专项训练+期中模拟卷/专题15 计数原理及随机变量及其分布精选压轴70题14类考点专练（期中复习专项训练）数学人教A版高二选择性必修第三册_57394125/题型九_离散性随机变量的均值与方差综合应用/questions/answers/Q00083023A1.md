> [!faq]- 《专题15 计数原理及随机变量及其分布精选压轴70题14类考点专练（期中复习专项训练）数学人教A版高二选择性必修第三册_57394125》官方解析
>
> > [!success]- **【答案】** A．已知随机变量 $X$ 服从二项分布 $B(n,p)$ ，若 $E(X) = 15$ ， $D(X) = 10$ ，则 $p = \frac{1}{3}$ B．已知随机变量 $X$ 服从正态分布 $N(1,\sigma^2)$ ，若 $P(X < 3) = 0.6$ ，则 $P(-1 < X < 1) = 0.2$ C．根据分类变量 $X$ 与 $Y$ 的成对样本数据，计算得到 $\chi^2 = 6.712$ ．依据 $\alpha = 0.01$ 的独立性检验 $\left(\chi_{0.01} = 6.635\right)$ ，可判断 $X$ 与 $Y$ 不独立 D．样本点 $(x_i, y_i)(i = 1,2,3,\dots)$ 的经验回归方程为 $\hat{y} = 3x + \hat{a}$ ，若样本点 $(m,3)$ 与 $(2,n)$ 的残差相等，则 $3m + n = 9$
>
> > [!note]- **【分析】**
> > 由二项分布的期望和方差公式可得 A；利用正态分布的对称性可判断 B；根据独立性检验零假设
> >
> > 为 $H_{0}$ ：X 与 Y 相互独立，由卡方值大于 6.635 得到 $H_{0}$ 不成立，即可判断 C；利用残差的计算可得 D.
>
> > [!note]- **【解析】**
> > 对于 A，已知随机变量 X 服从二项分布 $B(n,p)$ ，若 $E(X)=15$ ， $D(X)=10$
> >
> > 则 $np = 15, np(1 - p) = 10$ ，解得 $p = \frac{1}{3}$ ，故A正确；
> >
> > <!-- source-part:2 pages:51-100 -->
> >
> > 对于 B，随机变量 X 服从正态分布 $N(1, \sigma^{2})$ ，所以对称轴为 x = 1
> >
> > 则 $P(x < 1) = 0.5$ ，因为 $P(X < 3) = 0.6$ ，所以 $P(1 < X < 3) = 0.6 - 0.5 = 0.1$
> >
> > 所以 $P(-1 < X < 1) = P(1 < X < 3) = 0.1$ ，故B错误；
> >
> > 对于 C，零假设为 $H_{0}$ ：X 与 Y 相互独立，
> >
> > 由 $\chi^2 = 6.712 > 6.635 = \chi_{0.01}$
> >
> > 所以 X 与 Y 不相互独立，犯错误的概率不超过 0.01，故 C 正确；
> >
> > 对于 D，由题意可得样本点 $(m,3)$ 与 $(2,n)$ 的残差分别为 $3-(3m+\hat{a})$ 和 $n-(6+\hat{a})$ ，
> > 所以 $3-(3m+\hat{a})=n-(6+\hat{a})$ ，则 $3m+n=9$ ，故 D 正确.
> >
> > 故选 **ACD**.
