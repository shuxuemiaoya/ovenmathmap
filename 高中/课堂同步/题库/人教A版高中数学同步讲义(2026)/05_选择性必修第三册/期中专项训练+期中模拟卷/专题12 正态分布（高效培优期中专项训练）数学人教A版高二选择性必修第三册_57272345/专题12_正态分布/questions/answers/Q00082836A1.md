> [!faq]- 《专题12 正态分布（高效培优期中专项训练）数学人教A版高二选择性必修第三册_57272345》官方解析
>
> > [!success]- **【答案】** C
>
> > [!note]- **【解析】**
> > 设分数达到 $a$ 及以上的就是 $A$ 等级，分数达到 $b$ 但小于 $a$ 的就是 $B$ 等级，分数达到 $c$ 但小于 $b$ 的就是 $C$ 等级，根据题意，可得 $P(X \quad a) = 16\%$ ， $P(b \leq X < a) = 34\%$ ， $P(c \leq X < b) = 34\%$ ， $P(X \quad c) = P(X \quad a) + P(b \leq X < a) + P(c \leq X < b) = 84\%$ 因为 $P(X \quad \mu - \sigma) = P(X \quad 67) = P(X \quad 83) + P(67 \leq X < 83) = 0.5 + \frac{0.6826}{2} = 0.8413$ ，所以 $c = 67$ 故选：C.
> >
> > 5. 化学课上，老师带同学进行酸碱平衡测量实验，由于物质的量浓度差异，测量酸碱度 $pH$ 值时会造成一定的误差，甲小组进行的实验数据的误差 $X$ 和乙小组进行的实验数据的误差 $Y$ 均符合正态分布，其中 $X \sim N(0.3, 0.0001)$ ， $Y \sim N(0.28, 0.0004)$ ，已知正态分布密度函数 $f(x) = \frac{1}{\sigma \sqrt{2\pi}} \mathrm{e}^{-\frac{(x - \mu)^2}{2\sigma^2}}$ ，记 $X$ 和 $Y$ 所对应的正态分布密度函数分别为 $f_1(x)$ ， $f_2(x)$ ，则（）A. $f_1(0.3) > f_2(0.28)$ B. 乙小组的实验误差数据相对于甲小组更集中
> >
> > C $P(X <   0.28) + P(X\leq 0.32) = 1$
> >
> > D $P(X < 0.31) > P(Y < 0.31)$
> >
> > 【答案】AC
> >
> > 【详解】由正态分布密度函数曲线可知，数据的标准差越小，数据越集中在均值附近，峰值越大，反之，标准差越大，数据越分散，峰值越小·
> >
> > 对于两个小组的误差，甲组的标准差 $\sigma_{1} = \sqrt{0.0001} = 0.01$ ，乙组的标准差 $\sigma_{2} = \sqrt{0.0004} = 0.02$
> >
> > 显然甲组的标准差更小，故峰值更大，数据相对乙组更集中，故 $^{A}$ 正确， $^{B}$ 错误；
> >
> > $$
> > P (X <   0. 2 8) = P (X <   \mu - 2 \sigma_ {1}) = P (X > \mu + 2 \sigma_ {1}), P (X \leq 0. 3 2) = P (X \leq \mu + 2 \sigma_ {1}),
> > $$
> >
> > $$
> > P (X <   0. 2 8) + P (X \leq 0. 3 2) = P (X > \mu + 2 \sigma_ {1}) + P (X \leq \mu + 2 \sigma_ {1}) = 1, \text {故} C \text {正确};
> > $$
> >
> > $$
> > P (Y <   0. 3 1) = P \left(Y <   \mu + \frac {3}{2} \sigma_ {2}\right) > P \left(Y <   \mu + \sigma_ {2}\right) = \frac {1}{2} + \frac {1}{2} P \left(\mu - \sigma_ {2} <   Y <   \mu + \sigma_ {2}\right),
> > $$
> >
> > $$
> > P (X <   0. 3 1) = P (X <   \mu + \sigma_ {1}) = \frac {1}{2} + \frac {1}{2} P (\mu - \sigma_ {1} <   X <   \mu + \sigma_ {1}),
> > $$
> >
> > 而对于任何正态分布都有 $P(\mu - \sigma_{1} < X < \mu + \sigma_{1}) = P(\mu - \sigma_{2} < Y < \mu + \sigma_{2})$ ,
> >
> > 故 $P(Y < 0.31) > P(X < 0.31)$ ，故D错误·
> >
> > 故选：AC.
