> [!faq]- 《专题12 正态分布（高效培优期中专项训练）数学人教A版高二选择性必修第三册_57272345》官方解析
>
> > [!success]- **【答案】** A．若随机变量 $X \sim B(4, \frac{1}{3})$ ，则 $D(X) = \frac{4}{3}$ B．若随机变量 $X \sim 0 - 1$ ，且 $P(X = 0) = 3 - 4P(X = 1) = a$ ，则 $a = \frac{1}{3}$ C．若随机变量 $X \sim N(2, \sigma^2)$ ， $P(X > 1) = 0.68$ ，则 $P(2 \leq x < 3) = 0.18$ D．若事件 $A, B$ 满足 $0 < P(A)$ ， $P(B) < 1$ 且 $P(A\overline{B}) = P(A) \cdot [1 - P(B)]$ ，则 $A$ 与 $B$ 独立
>
> > [!note]- **【解析】**
> > 选项 $^{A}$ ：因为 $X \sim B(4, \frac{1}{3})$
> >
> > 所以 $D(X) = 4 \times \frac{1}{3} \times (1 - \frac{1}{3}) = \frac{8}{9}$
> >
> > 故 $^{A}$ 错误；
> >
> > 选项 B：因为随机变量 $X \sim 0 - 1$ 且 $P(X = 0) = 3 - 4P(X = 1) = a$
> >
> > 所以 $P(X=1)=\frac{3-a}{4}$ ，所以 $a+\frac{3-a}{4}=1\Rightarrow a=\frac{1}{3}$
> >
> > 故 $^{B}$ 选项正确；
> >
> > 选项 C：因为 $X \sim N(2, \sigma^{2}), P(X > 1) = 0.68$
> >
> > 所以 $P(2 \leq x < 3) = P(1 < x < 2) = P(x > 1) - P(x > 2) = 0.18$
> >
> > 故 $^{C}$ 选项正确；
> >
> > 选项 D：因为 $P(A\overline{B}) = P(A)\mathbb{I}[1 - P(B)] = P(A)P(\overline{B})$
> >
> > 所以 A 与 $\bar{B}$ 相互独立，则 A 与 ♦ ♦ 独立.
> >
> > 故选项 D 正确；
> >
> > 故选 **BCD**.
