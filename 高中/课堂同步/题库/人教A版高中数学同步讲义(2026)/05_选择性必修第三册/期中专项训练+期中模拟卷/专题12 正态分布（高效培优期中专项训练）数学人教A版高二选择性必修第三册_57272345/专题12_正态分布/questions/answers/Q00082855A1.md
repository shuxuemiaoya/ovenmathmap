> [!faq]- 《专题12 正态分布（高效培优期中专项训练）数学人教A版高二选择性必修第三册_57272345》官方解析
>
> > [!success]- **【答案】** (若 $X\sim N(\mu,\sigma^{2})$ ，则 $P(|X-\mu|<\sigma)=0.6827,P(|X-\mu|<2\sigma)=0.9545$ ， $P(|X-\mu|<3\sigma)=0.9973$ )
>
> > [!note]- **【解析】**
> > 技术改造前，易知 $\mu_{1} = 50, \sigma_{1} = 0.6$
> >
> > 则其优品率为 $P(49.4 < X < 50.6) = P(\mu_1 - \sigma_1 < X < \mu_1 + \sigma_1) = P(|X - \mu_1| < \sigma_1) = 0.6827$
> >
> > 技术改造后，其中 $\mu_{2} = 50, \sigma_{2} = 0.2$
> >
> > 则其优品率为 $P(49.4 < X < 50.6) = P(\mu_2 - 3\sigma_2 < X < \mu_2 + 3\sigma_2) = P(|X - \mu_1| < 3\sigma_2) = 0.9973$
> >
> > 所以优品率之差为 0.9973 - 0.6827 = 0.3146.
> >
> > 故答案为：0.3146
