> [!faq]- 《高二数学下学期第一次月考（人教A版选择性必修数列 导数，高效培优·提升卷）[56877320]》官方解析
>
> > [!success]- **【答案】** A. [1,3] B. [2,3] C. [1,4) D. [2,4)
>
> > [!note]- **【解析】**
> > 要使函数有意义，则 $\frac{x}{2 - x} > 0$ ，即 $\frac{x}{x - 2} < 0$
> >
> > 所以函数 $f(x)$ 的定义域为 $(0,2)$ ,
> >
> > 因为 $f(x_{1}) + f(x_{2}) - 2$ ，所以令 $g(x) = f(x) + 1$ ，则 $g(x_{1}) + g(x_{2}) = 0$
> >
> > 因为 $g(x)=f(x)+1=\ln\frac{x}{2-x}+\frac{1}{3}(x-1)^{3}-x+1$
> >
> > 所以 $g(2-x)=\ln\frac{2-x}{x}+\frac{1}{3}(1-x)^{3}+x-1=-g(x)$ ，所以 $g(x)+g(2-x)=0$ ，
> >
> > 所以 $g(x)$ 的图象关于 $(1,0)$ 对称.
> >
> > 对 $g(x)$ 求导得 $g'(x)=\frac{2-x}{x}\cdot\frac{2}{(2-x)^{2}}+(x-1)^{2}-1=\frac{2-x^{2}(2-x)^{2}}{x(2-x)}$
> >
> > 因为 0 < x < 2，所以 $0 < x(2 - x) = -x^{2} + 2x = -(x - 1)^{2} + 1 \leq 1$
> >
> > 所以 $2-x^{2}(2-x)^{2}=2-\left[x(2-x)\right]^{2}>0$ ，所以 $g'(x)>0$ ，所以 $g(x)$ 在 $(0,2)$ 上单调递增，
> >
> > 要使得 $f(x_{1}) + f(x_{2}) - 2$ ，则使 $g(x_{1}) + g(x_{2}) = 0$ ，即 $g(x_{1}) - g(x_{2}) = g(2 - x_{2})$
> >
> > 所以 $x_{1}$ $2 - x_{2}$ 且 $x_{1}, x_{2} \in (0, 2)$ ，所以 $2 \leq x_{1} + x_{2} < 4$ 。
> >
> > 故选：D.
