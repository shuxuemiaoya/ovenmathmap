> [!faq]- 《高二数学下学期第一次月考（人教A版选择性必修数列 导数，高效培优·强化卷）[56796613]》官方解析
>
> > [!success]- **【答案】** (1) $a_{n}=\left(\frac{3}{4}\right)^{n-1}-\frac{1}{5}$ ; $$ S _ {n} = \left\{ \begin{array}{l l} \frac {8 + 2 0 \times (\frac {3}{4}) ^ {n} + n - 4 0 \times (\frac {3}{4}) ^ {6}}{5}, n & 7 \\ \frac {2 0 - 2 0 \times (\frac {3}{4}) ^ {n} - n}{5}, n \leq 6 \end{array} ; \right. \tag {2} $$ (3)证明见解析.
>
> > [!note]- **【解析】**
> > （1）在数列 $\{a_{n}\}$ 中， $a_1 = \frac{4}{5}$ ， $4a_{n + 1} = 3a_{n} - \frac{1}{5}$ ，则 $a_{n + 1} = \frac{3}{4} a_n - \frac{1}{20}$
> >
> > 即 $a_{n + 1} + \frac{1}{5} = \frac{3}{4}(a_n + \frac{1}{5})$ ，而 $a_1 + \frac{1}{5} = 1$
> >
> > 因此数列 $\{a_{n} + \frac{1}{5}\}$ 是首项为1，公比为 $\frac{3}{4}$ 的等比数列， $a_{n} + \frac{1}{5} = (\frac{3}{4})^{n - 1}$ ，
> >
> > 所以 $\{a_{n}\}$ 的通项公式为 $a_{n} = (\frac{3}{4})^{n - 1} - \frac{1}{5}$ .
> >
> > (2) 由 (1) 得 $a_{n+1} - a_n = \left[\left(\frac{3}{4}\right)^n - \frac{1}{5}\right] - \left[\left(\frac{3}{4}\right)^{n-1} - \frac{1}{5}\right] = \left(\frac{3}{4}\right)^n - \left(\frac{3}{4}\right)^{n-1} = -\frac{1}{4} \cdot \left(\frac{3}{4}\right)^{n-1} < 0$
> >
> > 即 $a_{n + 1} < a_n$ ，则 $\{a_n\}$ 为单调递减数列，而 $a_6 = (\frac{3}{4})^5 -\frac{1}{5} = \frac{243}{1024} -\frac{1}{5} >0$
> >
> > $a_{7} = \left(\frac{3}{4}\right)^{6} - \frac{1}{5} = \frac{729}{4096} -\frac{1}{5} < 0$ ，即当 $n <   7$ 时， $a_{n} > 0$ ；当 $n$ 7时， $a_{n} <   0$
> >
> > 记 $\left\{a_{n}\right\}$ 的前项和为 $T_{n}$ ，则 $T_{n} = \frac{1 - (\frac{3}{4})^{n}}{1 - \frac{3}{4}} - \frac{1}{5} n = 4 - 4 \times (\frac{3}{4})^{n} - \frac{1}{5} n$
> >
> > 当 $n \leq 6$ 时， $S_{n} = T_{n} = \frac{20 - 20 \times (\frac{3}{4})^{n} - n}{5}$ ；
> >
> > 当 n 7 时， $S_{n}=a_{1}+a_{2}+\cdots+a_{6}-a_{7}-\cdots-a_{n}=2T_{6}-T_{n}$
> >
> > $$
> > = \frac {4 0 - 4 0 \times (\frac {3}{4}) ^ {6} - 1 2}{5} - \frac {2 0 - 2 0 \times (\frac {3}{4}) ^ {n} - n}{5} = \frac {8 + 2 0 \times (\frac {3}{4}) ^ {n} + n - 4 0 \times (\frac {3}{4}) ^ {6}}{5},
> > $$
> >
> > 所以数列 的前 项和 $S_{n} = \left\{ \begin{array}{l}8 + 20\times (\frac{3}{4})^{n} + n - 40\times (\frac{3}{4})^{6}\\ \hline 5, n\quad 7\\ \frac{20 - 20\times (\frac{3}{4})^{n} - n}{5}, n\leq 6 \end{array} \right.$
> >
> > (3) 当 $n$ 2 且 $n \in \mathbf{N}_{+}$ 时， $\frac{1}{n^2 - 2} = \frac{2}{(n^2 - 3) + (n^2 - 1)} < \frac{2}{(n - 1)(n + 1)} = \frac{1}{n - 1} - \frac{1}{n + 1}$
> >
> > 当 $n = 2$ 时， $1 + \frac{1}{2^2 - 2} = \frac{3}{2} < \frac{5}{2}$ ；当 $n = 3$ 时， $1 + \frac{1}{2^2 - 2} + \frac{1}{3^2 - 2} + \frac{1}{4^2 - 2} + \dots + \frac{1}{n^2 - 2}$
> >
> > $$
> > <   1 + \left(1 - \frac {1}{3}\right) + \left(\frac {1}{2} - \frac {1}{4}\right) + \left(\frac {1}{3} - \frac {1}{5}\right) + \left(\frac {1}{4} - \frac {1}{6}\right) + \dots + \left(\frac {1}{n - 2} - \frac {1}{n}\right) + \left(\frac {1}{n - 1} - \frac {1}{n + 1}\right)
> > $$
> >
> > $$
> > = 1 + 1 + \frac {1}{2} - \frac {1}{n} - \frac {1}{n + 1} = \frac {5}{2} - \frac {2 n + 1}{n (n + 1)} <   \frac {5}{2}
> > $$
> >
> > 所以 $1+\frac{1}{2^{2}-2}+\frac{1}{3^{2}-2}+\frac{1}{4^{2}-2}+\cdots+\frac{1}{n^{2}-2}<\frac{5}{2}$ ，n 2 且 $n\in N_{+}$
