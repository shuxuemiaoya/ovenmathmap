> [!faq]- 《高二数学下学期第一次月考（人教A版选择性必修数列 导数，高效培优·强化卷）[56796613]》官方解析
>
> > [!success]- **【答案】** A
>
> > [!note]- **【解析】**
> > 根据图象可知当 $x < -2$ 时， $g(x) = (x + 2)f'(x) > 0$ ，可得 $f'(x) < 0$ ；当 $-2 < x < 0$ 时， $g(x) = (x + 2)f'(x) < 0$ ，可得 $f'(x) < 0$ ；
> >
> > 结合 $f(x)$ 的图象是一条连续不断的曲线，可知 $x\in(-\infty,0)$ 时， $f(x)$ 单调递减；
> >
> > 当 $x = 0$ 时， $g(x) = (x + 2)f'(x) = 0$ ，仅当 $x = 0,2$ 时取等号，可得 $f'(x) = 0$
> >
> > 对于 AB， $x \in (-\infty, 0)$ 时， $f(x)$ 单调递减，当 $x \in (0, +\infty)$ 时， $f'(x) = 0$ ，此时 $f(x)$ 单调递增，
> >
> > 因此 $f(x)$ 的单调递减区间是 $(-\infty, 0), f(x)$ 的单调递增区间是 $(0, +\infty)$ ，即 A 正确，B 错误；
> >
> > 对于 C，易知当 0 < x < 2 时， $f'(x) > 0$ ，当 x > 2 时， $f'(x) > 0$
> >
> > 即在 x=2 处左右函数 $f(x)$ 的单调性不改变，因此 C 错误；
> >
> > 对于 D，因为 0 < x < 2 时， $g(x) = (x + 2)f'(x) > 0$ ，由 $x + 2 > 0$ ，可得 $f'(x) > 0$
> >
> > 因此 $f'(1)>0$ ，即 D 错误.
> >
> > 故选 **A**.
