> [!faq]- 《高二数学下学期第一次月考（人教A版选择性必修数列 导数，高效培优·强化卷）[56796613]》官方解析
>
> > [!success]- **【答案】** BCD
>
> > [!note]- **【解析】**
> > A选项，由函数 $f(x) = \frac{2}{3} x^3 - x^2 - 12x + \frac{49}{6}$ ，可得 $f'(x) = 2x^2 - 2x - 12 = 2(x - 3)(x + 2)$ ，
> >
> > 令 $f^{\prime}(x) > 0$ ，解得 $x < -2$ 或 $x > 3$ ；令 $f^{\prime}(x) < 0$ ，解得 $-2 < x < 3$
> >
> > 所以函数 $f(x)$ 在 $(-∞,-2)$ 上单调递增，在 $(-2,3)$ 上单调递减，在 $(3,+∞)$ 单调递增，
> >
> > 当 $x = -2$ 时， $f(x)$ 取得极大值，极大值为 $f(-2) = \frac{137}{6}$ ，所以极大值点为 $-2$ ，故A错误；
> >
> > B 选项，由 A 知，当 x=3 时， $f(x)$ 取得极小值，
> >
> > 极小值 $f(3) = 18 - 9 - 36 + \frac{49}{6} = -\frac{113}{6} < 0$ ，且当 $x \to -\infty$ 时， $f(x) \to -\infty$ ，
> >
> > 当 $x \to +\infty$ 时， $f(x) \to +\infty$ ， $f(-2) = \frac{137}{6} > 0$ ，所以函数 $f(x)$ 有3个零点，故B正确；
> >
> > C 选项，由 $f'(x)=2x^{2}-2x-12$ ，可得 $f''(x)=4x-2$
> >
> > 令 $f''(x)=0$ ，可得 $x=\frac{1}{2}$ ，又由 $f\left(\frac{1}{2}\right)=\frac{2}{3}\times\left(\frac{1}{2}\right)^{3}-\left(\frac{1}{2}\right)^{2}-12\times\frac{1}{2}+\frac{49}{6}=2$
> >
> > 所以点 $\left(\frac{1}{2},2\right)$ 是函数 $f(x)$ 的对称中心，故C正确；
> >
> > D 选项，因为 $\left(\frac{1}{2},2\right)$ 是函数 $f(x)$ 的对称中心，所以 $f(x)+f(1-x)=4$
> >
> > $$
> > S = f \left(\frac {1}{2 0 2 5}\right) + f \left(\frac {2}{2 0 2 5}\right) + f \left(\frac {3}{2 0 2 5}\right) + \dots + f \left(\frac {2 0 2 4}{2 0 2 5}\right)
> > $$
> >
> > $$
> > S = f \left(\frac {2 0 2 4}{2 0 2 5}\right) + f \left(\frac {2 0 2 3}{2 0 2 5}\right) + f \left(\frac {2 0 2 2}{2 0 2 5}\right) + \dots + f \left(\frac {1}{2 0 2 5}\right),
> > $$
> >
> > $$
> > 2 S = \left[ f \left(\frac {1}{2 0 2 5}\right) + f \left(\frac {2 0 2 4}{2 0 2 5}\right) \right] + f \left[ \left(\frac {2}{2 0 2 5}\right) + f \left(\frac {2 0 2 3}{2 0 2 5}\right) \right] + \left[ f \left(\frac {3}{2 0 2 5}\right) + f \left(\frac {2 0 2 2}{2 0 2 5}\right) \right]
> > $$
> >
> > $$
> > + \dots + \left[ f \left(\frac {2 0 2 4}{2 0 2 5}\right) + f \left(\frac {1}{2 0 2 5}\right) \right] = 4 \times 2 0 2 4
> > $$
> >
> > $$
> > \text {所以} S = 4 0 4 8 \text {, 即} f \left(\frac {1}{2 0 2 5}\right) + f \left(\frac {2}{2 0 2 5}\right) + f \left(\frac {3}{2 0 2 5}\right) + \dots f \left(\frac {2 0 2 4}{2 0 2 5}\right) = 4 0 4 8 \quad , \text {所以D正确.}
> > $$
> >
> > 故选 **BCD**.
