> [!faq]- 《专题02 两个计数原理综合应用的四大常考题型（高效培优专项训练）》官方解析
>
> > [!success]- **【答案】** 8
>
> > [!note]- **【分析】**
> > 由条件可得 $3 \leq c + f \leq 11$ ，根据 $100(a + d) + 10(b + e) + c + f = 705$ ，推出 $c + f = 5$ ，再证明 $b + e = 10$ ，由此确定 $a, b, c, d, e, f$ 的可能取值，再求结论。
>
> > [!note]- **【解析】**
> > 因为 $3 \leq c + f \leq 11$ ， $100(a + d) + 10(b + e) + c + f = 705$ ，
> >
> > 所以 $c + f = 5$ ，
> >
> > 所以 $\{c,f\}$ 为 $\{1,4\}$ 或 $\{2,3\}$ ;
> >
> > 所以 $100(a + d) + 10(b + e) = 700$ ，即 $10(a + d) + b + e = 70$
> >
> > 所以 $b + e$ 是 10 的倍数，又 $3 \leq b + e \leq 11$ ，所以 $b + e = 10$ ，
> >
> > 则 $\{b, e\} = \{4, 6\}$ ，因为 $c, b, e, f$ 互不相同，
> >
> > 所以 $\{c,f\}$ 不能是 $\{1,4\}$ ，只能是 $\{2,3\}$ ，
> >
> > 剩下的数字是1,5，所以 $\{a,d\}=\{1,5\}$ ，
> >
> > 所以满足条件的 $2 \times 3$ 方格表共有 $2 \times 2 \times 2 = 8$ 张.
> >
> > 故答案为：8·
