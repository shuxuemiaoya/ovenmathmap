> [!faq]- 《专题02 两个计数原理综合应用的四大常考题型（高效培优专项训练）》官方解析
>
> > [!success]- **【答案】** 420
>
> > [!note]- **【分析】**
> > 分使用五种染料、四种染料、三种染料求解，最后相加即可·
>
> > [!note]- **【解析】**
> > 五个顶点涂五种不同的颜色，有 $A_{5}^{5}=120$ （种）涂法；
> >
> > 五个顶点涂四种不同的颜色，其中 A, C 同色 B, D 不同色或 A, C 不同色 B, D 同色，有 $C_{2}^{1}A_{5}^{4}=240$ （种）涂法；
> > 五种顶点涂三种不同的颜色，其中 A, C 同色且 B, D 同色，有 $A_{5}^{3}=60$ （种）涂法。
> >
> > 综上，共有 $120 + 240 + 60 = 420$ （种）涂色方法·
> >
> > 故答案为：420
