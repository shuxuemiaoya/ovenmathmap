> [!faq]- 《专题6.2 排列与组合（高效培优讲义）》官方解析
>
> > [!success]- **【答案】** （1） $^{15}$ 种（2） $^{15}$ 种（3） $^{36}$ 种（4） $^{301}$ 种
>
> > [!note]- **【分析】**
> > （1）法一利用排列数的性质求解，法二利用隔板法求解即可·
> >
> > (2) 先将问题合理转化，再利用隔板法求解即可·
> >
> > (3) 法一对空盒子的个数进行分类讨论，再求和即可，法二利用隔板法求解即可·
> >
> > (4) 利用组合数的性质求解即可·
>
> > [!note]- **【解析】**
> > （1）法一：问题相当于先把 $^{7}$ 个相同的小球分成 $^{3}$ 堆，再分配到不同的盒子里·
> >
> > 把 7 个相同的小球分成 3 堆，有 4 种分法 $7 = 1 + 1 + 5, 7 = 1 + 2 + 4, 7 = 1 + 3 + 3, 7 = 2 + 2 + 3$ .
> >
> > 第一类，按照1,1,5来分，有 $\frac{\mathrm{A}_3^3}{2!} = 3$ 种方法；
> >
> > 第二类，按照1,2,4来分，有 $A_{3}^{3}=6$ 种方法；
> >
> > 第三类，按照 $1,3,3$ 来分，有 $\frac{\mathrm{A}_3^3}{2!} = 3$ 种方法：
> >
> > 第四类，按照2,2,3来分，有 $\frac{A_{3}^{3}}{2!}=3$ 种方法
> >
> > 综上，共有 $3 + 6 + 3 + 3 = 15$ 种方法·
> >
> > 法二：在 $^{7}$ 个相同的小球中间的 $^{6}$ 个空档里，
> >
> > 选择 $^{2}$ 个空档，插入 $^{2}$ 块隔板，共有 $C_{6}^{2}=15$ 种方法·
> >
> > (2) 可以先在每个盒子中放 $^{1}$ 个球，问题就变成将 $^{7}$ 个相同的小球放入 $^{3}$ 个不同的盒子，
> >
> > 每个盒子里至少放 $^{1}$ 个球，即将小球分为 $^{3}$ 堆，会产生 $^{2}$ 个空档，
> >
> > 选择 $^{2}$ 个空档，插入 $^{2}$ 块隔板，共有 $C_{6}^{2}=15$ 种方法.
> >
> > (3) 法一：空 $0$ 个盒子共有 $C_6^2 = 15$ 种，空 $1$ 个盒子共有 $C_3^1 C_6^1 = 18$ 种，
> >
> > 空 $^{2}$ 个盒子共有 $C_{3}^{2}=3$ 种，综上，共有 $15+18+3=36$ 种方法·
> >
> > 法二：先借 $^{3}$ 个相同的球，在每个盒子里先放入 $^{1}$ 个借来的球，
> >
> > 则问题就转化为把 $^{10}$ 个相同的小球放在 $^{3}$ 个不同的盒子里，要求每个盒子都不空，
> >
> > 即在 $10$ 个相同的小球中间的 $9$ 个空档里，
> >
> > 选择 $^{2}$ 个空档，插入 $^{2}$ 块隔板，共有 $C_{9}^{2}=36$ 种方法·
> >
> > （4）由题意得盒子相同，按照球的个数可以分为 $7 = 1 + 1 + 5, 7 = 1 + 2 + 4, 7 = 1 + 3 + 3, 7 = 2 + 2 + 3$ ，共4种，
> >
> > 第一类，按照1,1,5来分，有 $\frac{\mathrm{C}_7^1\mathrm{C}_6^1\mathrm{C}_5^5}{2!} = 21$ 种方法；
> >
> > 第二类，按照1,2,4来分，有 $C_{7}^{1}C_{6}^{2}C_{4}^{4}=105$ 种方法；
> >
> > 第三类，按照1,3,3来分，有 $\frac{C_7C_6C_3}{2!} = 70$ 种方法：
> >
> > $$
> > \frac {\mathrm{C} _ {7} ^ {1} \mathrm{C} _ {6} ^ {3} \mathrm{C} _ {3} ^ {3}}{2 !} = 7 0
> > $$
> >
> > 第四类，按照2,2,3来分，有 $\frac{\mathrm{C}_7^2\mathrm{C}_5^2\mathrm{C}_3^3}{2!} = 105$ 种方法
> >
> > 综上，共有 $21 + 105 + 70 + 105 = 301$ 种方法·
