> [!faq]- 《专题03 排列六大常考题型（高效培优专项训练）》官方解析
>
> > [!success]- **【答案】** (1)1； (2)证明见解析； (3) $\{8\}$ .
>
> > [!note]- **【分析】**
> > （1）（2）（3）应用排列数公式化简求值、证明恒等关系及解不等式；
>
> > [!note]- **【解析】**
> > （1） $\frac{2A_{8}^{5}+7A_{8}^{4}}{A_{8}^{8}-A_{9}^{5}}=\frac{2\times8\times7\times6\times5\times4+7\times8\times7\times6\times5}{8\times7\times6\times5\times4\times3\times2\times1-9\times8\times7\times6\times5}=\frac{8+7}{24-9}=1$
> >
> > (2) $\mathrm{A}_n^m = \frac{n!}{(n - m)!} = n\cdot \frac{(n - 1)!}{(n - m)!} = n\cdot \frac{(n - 1)!}{[ (n - 1) - (m - 1)]!} = n\mathrm{A}_{n - 1}^{m - 1}$ ， $(n\quad m\quad 2)$
> >
> > (3) 依题意，有 $\left\{ \begin{array}{l} 0 \leq x \leq 8 \\ 0 \leq x - 2 \leq 8 \end{array} \right.$ ，可得 $2 \leq x \leq 8$ 由 $\mathrm{A}_8^x < 6\mathrm{A}_8^{x - 2}$ ，得 $\frac{8!}{(8 - x)!} < 6\times \frac{8!}{(10 - x)!}$ ，即 $1 <   \frac{6}{(10 - x)(9 - x)}$ 整理得 $x^{2} - 19x + 84 <   0$ ，解得 $7 <   x <   12$ ，所以 $7 <   x\leq 8$ 又 $x\in \mathbf{N}^*$ ，得 $x = 8$ ，所以 $\mathrm{A}_8^x < 6\mathrm{A}_8^{x - 2}$ 的解集为 $\{8\}$
