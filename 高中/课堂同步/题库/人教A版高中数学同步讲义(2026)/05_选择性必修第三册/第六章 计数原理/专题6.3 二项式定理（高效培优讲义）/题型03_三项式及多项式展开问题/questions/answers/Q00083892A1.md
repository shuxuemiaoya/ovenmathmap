> [!faq]- 《专题6.3 二项式定理（高效培优讲义）》官方解析
>
> > [!success]- **【答案】** (2) $\left(x^{2} + x + 2\right)^{5}$ 的展开式中 $x^4$ 的系数为
>
> > [!note]- **【分析】**
> > （1）将目标式合理变形，再结合二项式定理和赋值法求解系数即可·
> >
> > (2) 法一将含有 $x^4$ 的项合理分为三种情况，再把三种情况的系数相加即可，法二将目标式合理变形后两次
> >
> > 使用二项式定理展开，得到 $\left(x^{2} + x + 2\right)^{5}$ 的展开式通项，再得到 $k\in [0,2]$ ，最后结合赋值法求解即可·
>
> > [!note]- **【解析】**
> > （1）由题意得 $(x-y)(x+2y)^{3}=x(x+2y)^{3}-y(x+2y)^{3}$
> >
> > 由二项式定理得 $\left(x + 2y\right)^3$ 的通项为 $T_{k + 1} = \mathrm{C}_3^k x^{3 - k}(2y)^k = \mathrm{C}_3^k 2^k x^{3 - k}y^k$
> >
> > 令 $k = 1$ ，则 $x(x + 2y)^3$ 中含 $x^{3}y$ 的项为 $6x^{3}y$
> >
> > 令 $k = 0$ ，则 $-y(x + 2y)^3$ 中含 $x^{3}y$ 的项为 $-x^{3}y$
> >
> > 故 $(x-y)(x+2y)^{3}$ 的展开式中 $x^{3}y$ 的系数为5.
> >
> > (2) 法一：欲求 $\left(x^{2}+x+2\right)^{5}$ 的展开式中含有 $x^{4}$ 的项，
> >
> > 则选法如下，当选两个 $x^{2}$ ，三个2时，系数为 $\mathrm{C}_5^2 2^3 = 80$
> >
> > 当选一个 $x^{2}$ ，两个 x，两个 2 时，系数为 $C_{5}^{1}C_{4}^{2}2^{2}=120$ ，
> >
> > 当选 0 个 $x^{2}$ ，4 个 x，1 个 2 时，系数为 $C_{5}^{0}C_{5}^{1}2^{1}=10$ ，
> >
> > 综上，含 $x^4$ 项的系数为 $10 + 120 + 80 = 210$ .
> >
> > 法二：将 $\left(x^{2}+x+2\right)^{5}$ 看成二项式展开，
> >
> > 由二项式定理得 $\left[x^{2} + (x + 2)\right]^{5}$ 的通项为 $T_{k + 1} = \mathrm{C}_5^k (x + 2)^{5 - k}(x^2)^k = \mathrm{C}_5^k x^{2k}(x + 2)^{5 - k}$
> >
> > 由二项式定理得 $(x+2)^{5-k}$ 的通项为 $t_{r+1}=C_{5-k}^{r}x^{5-k-r}2^{r}$
> >
> > 则 $\left[x^{2} + (x + 2)\right]^{5}$ 的通项为 $T_{k + 1} = \mathrm{C}_5^k x^{2k}\mathrm{C}_{5 - k}^r x^{5 - k - r}2^r = \mathrm{C}_5^k\mathrm{C}_{5 - k}^r 2^r x^{5 + k - r}$
> >
> > 令 $5 + k - r = 4$ ，解得 $r = k + 1$ ，而 $k + 1 \leq 5 - k$ ，解得 $k \in [0,2]$
> >
> > 此时 $\left[x^{2} + (x + 2)\right]^{5}$ 中含 $x^4$ 的项为 $\mathrm{C}_5^k\mathrm{C}_{5 - k}^{k + 1}2^{k + 1}x^4$
> >
> > 当 $k = 0$ 时，系数为 $\mathrm{C}_5^0\mathrm{C}_5^1 2^1 = 10$ ，当 $k = 1$ 时，系数为 $\mathrm{C}_5^1\mathrm{C}_4^2 2^2 = 120$
> >
> > 当 $k = 2$ 时，系数为 $\mathrm{C}_5^2\mathrm{C}_3^3 2^3 = 80$
> >
> > 综上，含 $x^{4}$ 项的系数为 $10+120+80=210$ .
> >
> > 故答案为：5；210
