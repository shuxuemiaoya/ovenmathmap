> [!faq]- 《专题04_组合六大常考题型_高效培优专项训练_》官方解析
>
> > [!success]- **【答案】** 证明见解析
>
> > [!note]- **【分析】**
> > 证法一：根据 $\sum_{k = 0}^{2n - 1}\left(-1\right)^{k - 1}(k + 1)\left(\mathrm{C}_{2n}^k\right)^{-1} = 0$ 并记 $a_{n} = \sum_{k = 1}^{2n - 1}\left(-1\right)^{k - 1}\left(\mathrm{C}_{2n}^{k}\right)^{-1}, b_{n} = \sum_{k = 1}^{2n - 1}\left(-1\right)^{k - 1}k\left(\mathrm{C}_{2n}^{k}\right)^{-1}$ ，构造
> >
> > 方程组即可得结论
> >
> > 证法二：由组合数的计算公式直接可得 $\frac{2n + 2}{2n + 1}\frac{1}{C_{2n}^k} = \frac{1}{C_{2n + 1}^k} +\frac{1}{C_{2n + 1}^{k + 1}}$ ，再结合二项式系数性质计算化简可得结论·
>
> > [!note]- **【解析】**
> > 证法一：
> >
> > 若记 $a_{n} = \sum_{k = 1}^{2n - 1}\left(-1\right)^{k - 1}\left(\mathrm{C}_{2n}^{k}\right)^{-1}, b_{n} = \sum_{k = 1}^{2n - 1}\left(-1\right)^{k - 1}k\left(\mathrm{C}_{2n}^{k}\right)^{-1}$
> >
> > 则由典例 11 知道 $\sum_{k=0}^{2n-1}\left(-1\right)^{k-1}(k+1)\left(C_{2n}^{k}\right)^{-1}=0$
> >
> > 所以 $a_{n} + b_{n} = \sum_{k = 1}^{2n - 1}\left(-1\right)^{k - 1}\left(\mathrm{C}_{2n}^{k}\right)^{-1} + \sum_{k = 1}^{2n - 1}\left(-1\right)^{k - 1}k\left(\mathrm{C}_{2n}^{k}\right)^{-1} = \sum_{k = 1}^{2n - 1}\left(-1\right)^{k - 1}\left(k + 1\right)\left(\mathrm{C}_{2n}^{k}\right)^{-1}$
> >
> > $$
> > = \sum_ {k = 0} ^ {2 n - 1} (- 1) ^ {k - 1} (k + 1) \left(\mathrm{C} _ {2 n} ^ {k}\right) ^ {- 1} + 1 = 1 \tag {6}
> > $$
> >
> > 又有 $na_{n}-b_{n}=\sum_{k=1}^{2n-1}\left(-1\right)^{k-1}(n-k)\left(\mathrm{C}_{2n}^{k}\right)^{-1}=0$ ⑦
> > - **⑥**：和⑦相加，即得 $a_{n}=\frac{1}{n+1}$ ，这就是要证明的恒等式。
> >
> > 证法二：
> >
> > 根据组合数的计算公式直接可得 $\frac{2n+2}{2n+1}\frac{1}{C_{2n}^{k}}=\frac{1}{C_{2n+1}^{k}}+\frac{1}{C_{2n+1}^{k+1}}$
> >
> > $$
> > \text {是} \frac {2 n + 2}{2 n + 1} \sum_ {k = 1} ^ {2 n} \frac {(- 1) ^ {k - 1}}{\mathrm{C} _ {2 n} ^ {k}} = \sum_ {k = 1} ^ {2 n} (- 1) ^ {k - 1} \left(\frac {1}{\mathrm{C} _ {2 n + 1} ^ {k}} + \frac {1}{\mathrm{C} _ {2 n + 1} ^ {k + 1}}\right) = \left(\frac {1}{\mathrm{C} _ {2 n + 1} ^ {1}} + \frac {1}{\mathrm{C} _ {2 n + 1} ^ {2}}\right) - \left(\frac {1}{\mathrm{C} _ {2 n + 1} ^ {2}} + \frac {1}{\mathrm{C} _ {2 n + 1} ^ {3}}\right)
> > $$
> >
> > $$
> > + \dots + (- 1) ^ {2 n - 1} \left(\frac {1}{C _ {2 n + 1} ^ {2 n}} + \frac {1}{C _ {2 n + 1} ^ {2 n + 1}}\right) = \frac {1}{C _ {2 n + 1} ^ {1}} - 1 = \frac {1}{2 n + 1} - 1 = \frac {- 2 n}{2 n + 1};
> > $$
> >
> > 由此即得
> >
> > $$
> > \sum_ {k = 1} ^ {2 n - 1} (- 1) ^ {k} \left(\mathrm{C} _ {2 n} ^ {k}\right) ^ {- 1} = \sum_ {k = 1} ^ {2 n} (- 1) ^ {k - 1} \left(\mathrm{C} _ {2 n} ^ {k}\right) ^ {- 1} + 1 = - \frac {n}{n + 1} + 1 = \frac {1}{n + 1}
> > $$
> >
> > 14. 利用二项式定理证明： $C_{m}^{0}C_{n}^{k} + C_{m}^{1}C_{n}^{k-1} + \ldots + C_{m}^{n}C_{n}^{n-k} = C_{m+n}^{k}$
> >
> > 【答案】证明见解析
> >
> > 【分析】由多项式恒等，即对应项系数相等即可证.
> >
> > 【详解】由于 $\left(1+x\right)^{m}\left(1+x\right)^{n}=\left(\mathrm{C}_{m}^{0}+\mathrm{C}_{m}^{1}x+\cdots+\mathrm{C}_{m}^{m}x^{m}\right)\left(\mathrm{C}_{n}^{0}+\mathrm{C}_{n}^{1}x+\cdots+\mathrm{C}_{n}^{n}x^{n}\right)$
> >
> > 其中含有 $x^{k}$ 项的系数为 $\mathrm{C}_m^0\mathrm{C}_n^k +\mathrm{C}_m^1\cdot \mathrm{C}_n^{k - 1} + \ldots +\mathrm{C}_m^n\mathrm{C}_n^{n - k}$
> >
> > 而 $\left(1+x\right)^{m+n}=C_{m+n}^{0}+C_{m+n}^{1}x+\cdots+C_{m+n}^{m+n}\cdot x^{m+n}$ ，其中含有 $x^{k}$ 项的系数为 $C_{m+n}^{k}$
> >
> > 同时 $\left(1 + x\right)^{m}\left(1 + x\right)^{n} = \left(1 + x\right)^{m + n}$ 故 $\mathrm{C}_m^0\mathrm{C}_n^k +\mathrm{C}_m^1\cdot \mathrm{C}_n^{k - 1} + \dots +\mathrm{C}_m^n\mathrm{C}_n^{n - k} = \mathrm{C}_{m + n}^k$
