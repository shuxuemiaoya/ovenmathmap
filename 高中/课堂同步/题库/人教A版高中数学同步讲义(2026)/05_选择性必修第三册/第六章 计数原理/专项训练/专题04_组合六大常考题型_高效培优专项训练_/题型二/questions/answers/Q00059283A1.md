> [!faq]- 《专题04_组合六大常考题型_高效培优专项训练_》官方解析
>
> > [!success]- **【答案】** 证明见解析
>
> > [!note]- **【分析】**
> > 因为 $\left(1 + x\right)^n\cdot \left(1 + x\right)^m = \left(1 + x\right)^{m + n}$ ，分别求出左右边展开式中 $x^{k}$ 的系数，即可证明
>
> > [!note]- **【解析】**
> > 证明：∵ $(1+x)^{n}\cdot(1+x)^{m}=(1+x)^{m+n}$
> >
> > 比较 $x^{k}$ 项的系数，右边展开式中的 $x^{k}$ 的系数显然是 $\mathrm{C}_{n + m}^{k}$ ，
> >
> > 左边 $= (1 + x)^{n}\cdot (1 + x)^{m} = \left(\mathrm{C}_{n}^{0} + \mathrm{C}_{n}^{1}x + \mathrm{C}_{n}^{2}x^{2} + \dots +\mathrm{C}_{n}^{n}x^{n}\right)\left(\mathrm{C}_{m}^{0} + \mathrm{C}_{m}^{1}x + \mathrm{C}_{m}^{2}x^{2} + \dots +\mathrm{C}_{m}^{m}x^{m}\right)$
> >
> > 由多项式的乘法知 $x^{k}$ 的系数是： $C_{n}^{k} + C_{n}^{k-1}C_{m}^{1} + \cdots + C_{m}^{k}$
> >
> > 由两边 $x^{k}$ 的系数相等，可得： $C_{n}^{k} + C_{n}^{k-1}C_{m}^{1} + \cdots + C_{m}^{k} = C_{n+m}^{k}$
