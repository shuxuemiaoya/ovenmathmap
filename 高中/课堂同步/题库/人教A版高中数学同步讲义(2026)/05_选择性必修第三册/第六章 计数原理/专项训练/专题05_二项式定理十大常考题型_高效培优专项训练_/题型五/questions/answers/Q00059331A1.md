> [!faq]- 《专题05_二项式定理十大常考题型_高效培优专项训练_》官方解析
>
> > [!success]- **【答案】** $2^{18}$
>
> > [!note]- **【分析】**
> > 由二项式展开式的通项公式可得： $a_{1}+2a_{2}+\cdots+8a_{8}=C_{16}^{1}+2C_{16}^{2}+\cdots+8C_{16}^{8}$ ，结合 $kC_{n}^{k}=nC_{n-1}^{k-1}$ 和 $C_{n}^{k}=C_{n}^{n-k}$ ，化简可得 $a_{1}+2a_{2}+\cdots+8a_{8}=16\left(C_{15}^{0}+C_{15}^{1}+\cdots+C_{15}^{7}\right)$ 即可求解.
>
> > [!note]- **【解析】**
> > 由题可得： $a_{1}+2a_{2}+\cdots+8a_{8}=C_{16}^{1}+2C_{16}^{2}+\cdots+8C_{16}^{8}$
> >
> > 因为 $kC_{n}^{k}=nC_{n-1}^{k-1}$
> >
> > 所以 $kC_{16}^{k}=16C_{15}^{k-1}$
> >
> > 所以 $C_{16}^{1} + 2C_{16}^{2} + \cdots + 8C_{16}^{8} = 16C_{15}^{0} + 16C_{15}^{1} + \cdots + 16C_{15}^{7} = 16\left(C_{15}^{0} + C_{15}^{1} + \cdots + C_{15}^{7}\right)$
> >
> > 又因为 $C_{n}^{k}=C_{n}^{n-k}$
> >
> > 所以 $C_{15}^{0} + C_{15}^{1} + \cdots + C_{15}^{7} = \frac{1}{2}\left(C_{15}^{0} + C_{15}^{1} + \cdots + C_{15}^{7} + C_{15}^{8} + \cdots + C_{15}^{15}\right) = \frac{1}{2} \times 2^{15} = 2^{14}$
> >
> > 则 $a_{1}+2a_{2}+\cdots+8a_{8}=C_{16}^{1}+2C_{16}^{2}+\cdots+8C_{16}^{8}=16\left(C_{15}^{0}+C_{15}^{1}+\cdots+C_{15}^{7}\right)=16\times2^{14}=2^{18}$
> >
> > 故选答案为： $2^{18}$
