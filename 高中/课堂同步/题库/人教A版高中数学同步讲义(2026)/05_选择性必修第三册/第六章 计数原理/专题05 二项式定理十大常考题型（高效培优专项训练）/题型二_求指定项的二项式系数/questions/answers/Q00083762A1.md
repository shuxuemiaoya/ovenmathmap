> [!faq]- 《专题05 二项式定理十大常考题型（高效培优专项训练）》官方解析
>
> > [!success]- **【答案】** (2) $(mx + y)^6$ 展开式中 $x^{3}y^{3}$ 的系数为-160，则 $m =$ (3) 已知在 $\left(\sqrt[3]{x} - \frac{3}{\sqrt[3]{x}}\right)^n$ 的展开式中，第6项为常数项。求展开式中所有的有理项。
>
> > [!note]- **【分析】**
> > （1）利用二项式定理求出通项，再得到二项式系数即可·
> >
> > (2) 利用二项式定理结合题意建立方程，求解参数即可·
> >
> > (3) 先结合题意求出 $n = 10$ ，再利用二项式定理求解有理项即可
>
> > [!note]- **【解析】**
> > （1）由二项式定理得 $\left(3x - 1\right)^{11}$ 展开式的通项为 $T_{k + 1} = C_{11}^{k}(3x)^{11 - k}(-1)^{k}$
> >
> > 令 $k + 1 = 3$ ，解得 $k = 2$ ，则第 $^{3}$ 项的二项式系数为 $\mathrm{C}_{11}^{2} = 55$
> >
> > (2) 由二项式定理得 $\left(mx + y\right)^6$ 展开式的通项为 $T_{k+1} = C_6^k (mx)^{6-k}y^k$
> >
> > 令 $k = 3$ ，可得含 $x^{3}y^{3}$ 的项为第4项，即 $T_{4} = C_{6}^{3}(mx)^{3}y^{3}$
> >
> > 而 $x^{3}y^{3}$ 的系数为 -160 ，得到 $C_{6}^{3}m^{3}=-160$ ，解得 m=-2 。
> >
> > (3) 由二项式定理得展开式的第6项为 $T_6 = T_{5+1} = C_n^5\left(\sqrt[3]{x}\right)^{n-5}\left(-\frac{3}{\sqrt[3]{x}}\right)^5 = C_n^5 \times (-3)^5 \times x^{\frac{n-10}{3}}$ ，因为第6项为常数项，所以 $\frac{n-10}{3} = 0$ ，解得 $n = 10$ ，由二项式定理得 $\left(\sqrt[3]{x} - \frac{3}{\sqrt[3]{x}}\right)^n$ 展开式的通项为 $T_{k+1} = C_{10}^k\left(\sqrt[3]{x}\right)^{10-k}\left(-\frac{3}{\sqrt[3]{x}}\right)^k = C_{10}^k\left(-3\right)^k x^{\frac{10-2k}{3}}$ ，而展开式中的有理项需要满足 $\frac{10-2k}{3} \in Z$ ，且 $k = 0, 1, 2, \cdots, 10$ ，解得 $k = 2, 5, 8$ 。故展开式中的有理项为 $T_3 = 405x^2$ ， $T_6 = -61236$ ， $T_9 = 295245x^{-2}$ 。
