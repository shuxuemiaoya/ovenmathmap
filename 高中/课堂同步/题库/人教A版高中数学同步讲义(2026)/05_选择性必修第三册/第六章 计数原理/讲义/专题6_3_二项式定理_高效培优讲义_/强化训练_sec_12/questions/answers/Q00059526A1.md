> [!faq]- 《人教A版高中数学同步讲义(2026)》官方解析
>
> > [!success]- **【答案】** (1) $n = 9$ (2) $-\frac{513}{512}$ (3) $\left|a_{0}\right|,\left|a_{1}\right|,\left|a_{2}\right|,\ldots,\left|a_{9}\right|$ 中 $\left|a_{5}\right|$ 和 $\left|a_{6}\right|$ 均为最大，理由见解析
>
> > [!note]- **【分析】**
> > （1）利用二项式系数的中间项最大的性质，结合第5、6项的二项式系数最大，得 $C_{n}^{4}=C_{n}^{5}$ ，求出正
> >
> > 整数n·
> >
> > (2) 通过赋值法（令 $x = 0$ 、 $x = 1$ ）求出 $a_0$ 与 $a_0 + a_1 + \ldots + a_n$ ，进而得 $a_1 + \ldots + a_n$ ，结合二项式系数和为 $2^n$ 计
> >
> > 算比值·
> >
> > (3) 将系数绝对值转化为 $(2+3x)^{9}$ 的系数，通过列不等式组求解最大项对应的 r 值，确定 $\left|a_{5}\right|$ 和 $\left|a_{6}\right|$ 最大.
>
> > [!note]- **【解析】**
> > （1）因为 $\left(2 - 3x\right)^n$ 的展开式中，第5项和第6项的二项式系数最大，
> >
> > 所以 n 为奇数，且 $C_{n}^{4} = C_{n}^{5}$ ，所以 n = 9。
> >
> > (2) 因为 n=9，所以二项式系数和为 $2^{9}=512$ ，
> >
> > 令 x=0 ，得 $a_{0}=2^{9}=512$
> >
> > 令 $x = 1$ ，得 $a_0 + a_1 + a_2 + \ldots + a_9 = (2 - 3)^9 = -1$
> >
> > 所以 $a_1 + a_2 + a_3 + \ldots + a_9 = -513$
> >
> > 因此 $a_{1}+a_{2}+a_{3}+\ldots+a_{9}$ 与二项式系数和的比值为 $-\frac{513}{512}$
> >
> > (3) $\left|a_{0}\right|\left|a_{1}\right|\left|a_{2}\right|,\ldots\left|a_{9}\right|$ 中 $\left|a_{5}\right|$ 和 $\left|a_{6}\right|$ 均为最大.
> >
> > 因为 $\left(2 - 3x\right)^{9} = a_{0} + a_{1}x + a_{2}x^{2} + \dots +a_{9}x^{9}$
> >
> > $\left(2 - 3x\right)^9_{\text{展开式的通项}}T_{r + 1} = \mathrm{C}_9^r 2^{9 - r}\left(-3x\right)^r = \mathrm{C}_9^r 2^{9 - r}\left(-3\right)^r x^r, r = 0,1,2,\dots,9$
> >
> > 所以 $a_{0}>0, a_{1}<0, a_{2}>0, a_{3}<0, \ldots, a_{9}<0$
> >
> > 即 $\left|a_{0}\right|=a_{0}>0,\left|a_{1}\right|=-a_{1}>0,\left|a_{2}\right|=a_{2}>0,\ldots\left|a_{9}\right|=-a_{9}>0$
> >
> > 故判断 $\left|a_{0}\right|,\left|a_{1}\right|,\left|a_{2}\right|,\ldots,\left|a_{9}\right|$ 系数中谁最大即判断 $(2+3x)^{9}$ 展开式的系数谁最大.
> >
> > $\left(2 + 3x\right)^{9}$ 展开式的通项 $T_{r + 1} = \mathrm{C}_9^r 2^{9 - r}\left(3x\right)^r,r = 0,1,2,\dots ,9$
> >
> > 由 $\left\{ \begin{array}{ll}\mathrm{C}_{9}^{r}\cdot 2^{9 - r}\cdot 3^{r} & \mathrm{C}_{9}^{r - 1}\cdot 2^{10 - r}\cdot 3^{r - 1}\\ \mathrm{C}_{9}^{r}\cdot 2^{9 - r}\cdot 3^{r} & \mathrm{C}_{9}^{r + 1}\cdot 2^{8 - r}\cdot 3^{r + 1} \end{array} \right.$
> >
> > 得 $5 \leq r \leq 6$ ，因为 $r \in N$ ，所以 r = 5 或 6。
> >
> > 故 $\left|a_{0}\right|,\left|a_{1}\right|,\left|a_{2}\right|,\ldots,\left|a_{9}\right|$ 中 $\left|a_{5}\right|$ 和 $\left|a_{6}\right|$ 均为最大.
