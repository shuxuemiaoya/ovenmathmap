## 知识点 03 二项式系数及其性质

1、 $(a + b)^n$ 的展开式中各项的二项式系数 $C_n^0$ 、 $C_n^1$ 、 $C_n^2$ ... $C_n^n$ 具有如下性质：

(1)对称性：二项展开式中，与首末两端“等距离”的两项的二项式系数相等，即 $C_{n}^{r}=C_{n}^{n-r}$ ；

(2)增减性与最大值：二项式系数在前半部分逐渐增大，在后半部分逐渐减小，在中间取得最大值.其中，当 $\mathbf{n}$

为偶数时，二项展开式中间一项的二项式系数 $C_n^{\frac{n}{2}}$ 最大；当 $\mathbf{n}$ 为奇数时，二项展开式中间两项的二项式系数

$C_{n}^{\frac{n-1}{2}}$ ， $C_{n}^{\frac{n+1}{2}}$ 相等，且最大.

(3)各二项式系数之和为 $2^{n}$ ，即 $C_{n}^{0} + C_{n}^{1} + C_{n}^{2} + C_{n}^{3} + C_{n}^{4} + \dots + C_{n}^{n} = 2^{n}$ ；

(4)二项展开式中各奇数项的二项式系数之和等于各偶数项的二项式系数之和，

$$
\text { 即 } C _ {n} ^ {0} + C _ {n} ^ {2} + C _ {n} ^ {4} + \dots = C _ {n} ^ {1} + C _ {n} ^ {3} + C _ {n} ^ {5} + \dots = 2 ^ {n - 1} 。
$$

注意：二项式系数与展开式的系数的区别

二项展开式中，第 $\mathbf{r} + 1$ 项 $C_n^r a^{n - r}b^r$ 的二项式系数是组合数 $\mathrm{C}_{\mathrm{n}}^{\mathrm{r}}$ ，展开式的系数是单项式 $C_n^r a^{n - r}b^r$ 的系数，二

者不一定相等。

2、 $(a + b + c)^n$ 展开式中 $a^p b^q c^r$ 的系数求法（ $p, q, r = 0$ 的整数且 $p + q + r = n$ ）

$$
(a + b + c) ^ {n} = [ (a + b) + c ] ^ {n} = C _ {n} ^ {r} (a + b) ^ {n - r} c ^ {r} = C _ {n} ^ {r} C _ {n - r} ^ {q} a ^ {n - r - q} b ^ {q} c ^ {r}
$$

注意：三项或三项以上的展开式问题，把某两项结合为一项，利用二项式定理解决。

【即学即练】

1. 若 $2x^{4} + (x + 1)^{3} = a_{4}(x - 1)^{4} + a_{3}(x - 1)^{3} + a_{2}(x - 1)^{2} + a_{1}(x - 1) + a_{0}$ ，则 $a_{1} + a_{2} + a_{3} + a_{4} =$ \_\_\_\_.

【答案】49

【分析】令 x=1 得 $a_{0}=10$ ，令 x=2 得 $a_{4}+a_{3}+a_{2}+a_{1}+10=59$ ，从而求出答案.

【详解】 $2x^{4}+(x+1)^{3}=a_{4}(x-1)^{4}+a_{3}(x-1)^{3}+a_{2}(x-1)^{2}+a_{1}(x-1)+a_{0}$ 中，

令 x=1 得 $a_{0}=2+2^{3}=10$

$$
2 x ^ {4} + (x + 1) ^ {3} = a _ {4} (x - 1) ^ {4} + a _ {3} (x - 1) ^ {3} + a _ {2} (x - 1) ^ {2} + a _ {1} (x - 1) + a _ {0} \text {中，}
$$

令 $x = 2$ 得 $2\times 2^{4} + 3^{3} = a_{4} + a_{3} + a_{2} + a_{1} + a_{0}$ ，即 $a_4 + a_3 + a_2 + a_1 + 10 = 59$

解得 $a_4 + a_3 + a_2 + a_1 = 49$

故答案为：49

2. 已知 $\left(x^{2} - \frac{3}{x}\right)^{n}$ 展开式中各项的二项式系数之和为 $64$ ，则（ ）A. $n = 6$ B. $\left(x^{2} - \frac{3}{x}\right)^{n}$ 展开式中所有项的系数之和为 $64$ C. $\left(x^{2} - \frac{3}{x}\right)^{n}$ 展开式中的常数项是 $-1215$ D. $\left(x^{2} - \frac{3}{x}\right)^{n}$ 展开式中含 $x^{3}$ 的项是 $-540x^{3}$

【答案】ABD

【分析】由 $2^{n} = 64$ ，求得 $n$ ，再由二项式定理通项公式，和赋值法逐项判断即可·

【详解】由题意可得 $2^{n} = 64$ ，解得 $n = 6$ ，A正确·

令 $x = 1$ ，得 $(1 - 3)^{6} = 64$ ，B正确.

$\left(x^{2} - \frac{3}{x}\right)^{6}$ 展开式的通项 $T_{r + 1} = \mathrm{C}_{6}^{r}\left(x^{2}\right)^{6 - r}\left(-\frac{3}{x}\right)^{r} = (-3)^{r}\mathrm{C}_{6}^{r}x^{12 - 3r}$

令 $12 - 3r = 0$ ，得 $r = 4$ ，则 $T_{5} = (-3)^{4}\mathrm{C}_{6}^{4} = 81\times 15 = 1215$ ，C错误.

令 $12 - 3r = 3$ ，得 $r = 3$ ，则 $T_{4} = (-3)^{3}\mathrm{C}_{6}^{3}x^{3} = -540x^{3}$ ，D正确·

故选：ABD

3. 已知 $\left(1+x+x^{2}\right)(1-x)^{4}=a_{0}+a_{1}(1+x)+a_{2}(1+x)^{2}+\cdots+a_{n}(1+x)^{n}$ ，则（）

A $n = 6$ B $a_{5} = -9$

C $a_1 + a_3 + a_5 = 121$ D $a_0 + a_1 + a_2 + \dots + a_n = 1$

【答案】ABD

【分析】根据乘法的运算法则，结合赋值法、二项式系数公式逐一判断即可·

【详解】A：二项式 $(1-x)^{4}$ 展开式中最高次项的指数为4，

所以 $\left(1+x+x^{2}\right)(1-x)^{4}$ 展开式中最高次项的指数为 6

所以 n=6 ，因此本选项说法正确；

B： $\left(1+x+x^{2}\right)\left(1-x\right)^{4}$ 展开式中最高次项的指数为6，系数为1，

所以 $a_{6}=1$

含 $x^{5}$ 项的系数为 $1\times C_{4}^{4}\times(-1)^{4}+1\times C_{4}^{3}(-1)^{3}=-3$

$a_{0}+a_{1}(1+x)+a_{2}(1+x)^{2}+\cdots+a_{6}(1+x)^{6}$ 中，含 $x^{5}$ 项的系数 $a_{5}C_{5}^{5}+a_{6}C_{6}^{5}=a_{5}+6$

所以 $a_{5}+6=-3\Rightarrow a_{5}=-9$ ，因此本选项说法正确；

C : 在 $\left(1+x+x^{2}\right)(1-x)^{4}=a_{0}+a_{1}(1+x)+a_{2}(1+x)^{2}+\cdots+a_{n}(1+x)^{n}$ 中，

令 x=0 ，得 $1\times1=a_{0}+a_{1}+a_{2}+a_{3}+a_{4}+a_{5}+a_{6}=1$

令 $x = -2$ ，得 $(1 - 2 + 4)\times 3^{4} = a_{0} - a_{1} + a_{2} - a_{3} + a_{4} - a_{5} + a_{6} = 3^{5}$

两式相减，得 $1 - 3^{5} = 2a_{1} + 2a_{3} + 2a_{5}\Rightarrow a_{1} + a_{3} + a_{5} = \frac{1 - 3^{5}}{2} = -121$

所以本选项说法不正确；

D：由上可知 $a_0 + a_1 + a_2 + \dots + a_n = 1$ ，所以本选项说法正确·

故选：ABD
