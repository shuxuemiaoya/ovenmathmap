> [!faq]- 《人教A版高中数学同步讲义(2026)》官方解析
>
> > [!success]- **【答案】** BCD
>
> > [!note]- **【分析】**
> > 先由二项式系数和为 512 解出 n，再利用二项式定理逐项验证即可求解.
>
> > [!note]- **【解析】**
> > 由题意有： $2^{n}=512$ ，所以 n=9，令 $t=x-1\Rightarrow x=t+1$ ，
> >
> > 所以 $\left(3x - 4\right)^9 = \left(3t - 1\right)^9 = a_0 + a_1t + a_2t^2 +\dots +a_9t^9$
> >
> > 令 $t = 0$ ，所以 $a_0 = (-1)^9 = -1$ ，令 $t = 1$
> >
> > 所以 $a_{0} + a_{1} + a_{2} + \cdots + a_{9} = (3 \times 1 - 1)^{9} = 2^{9} = 512$ ①，
> >
> > 所以 $a_{1} + a_{2} + \cdots + a_{9} = 512 - a_{0} = 512 + 1 = 513$ ，故 A 错误；
> >
> > 由 $T_{k + 1} = \mathrm{C}_9^k (-1)^k (3t)^{9 - k} = \mathrm{C}_9^k (-1)^k 3^{9 - k}t^{9 - k}$ ，令 $k = 7$
> >
> > 所以 $a_{2}=C_{9}^{7}\times(-1)^{7}\times3^{2}=-324$ ，故 B 正确；
> >
> > 令 t = -1 ，所以 $\left(a_{0} + a_{2} + \cdots + a_{8}\right) - \left(a_{1} + a_{3} + \cdots + a_{9}\right) = \left(-4\right)^{9} = -4^{9}$ ②，
> >
> > 由①②解得， $a_{0}+a_{2}+\cdots+a_{8}=\frac{2^{9}-4^{9}}{2},a_{1}+a_{3}+\cdots+a_{9}=\frac{2^{9}+4^{9}}{2}$
> >
> > 所以 $\left|a_{0}\right|+\left|a_{1}\right|+\left|a_{2}\right|+\cdots+\left|a_{n}\right|=\left(a_{1}+a_{3}+\cdots+a_{9}\right)-\left(a_{0}+a_{2}+\cdots+a_{8}\right)=\frac{2^{9}+4^{9}}{2}-\frac{2^{9}-4^{9}}{2}=4^{9}$ ，故 C 正确；
> > 由 $f(3)=(3\times3-4)^{9}=5^{9}=(6-1)^{9}$ $=C_{9}^{0}\times6^{9}+C_{9}^{1}\times6^{8}\times(-1)+\cdots+C_{9}^{8}\times6\times(-1)^{8}+C_{9}^{9}\times(-1)^{9}$ $=6\left[C_{9}^{0}\times6^{8}+\cdots+C_{9}^{8}\right]-1$
> >
> > 所以 $f(3)$ 除以 6 所得的余数为 5，故 D 正确；
> >
> > 故选 **BCD**.
