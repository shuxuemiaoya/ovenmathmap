> [!faq]- 《专题04 组合六大常考题型（高效培优专项训练）》官方解析
>
> > [!success]- **【答案】** (1)165 (2)455
>
> > [!note]- **【分析】**
> > （1）将 $^{12}$ 看作 $^{12}$ 个 $^{1}$ ，再利用隔板法解答；
> >
> > (2) 令 $x_{1} + 1 = y_{1}, x_{2} + 1 = y_{2}, x_{3} + 1 = y_{3}, x_{4} + 1 = y_{4}$ ， $y_{1}, y_{2}, y_{3}, y_{4}$ 均为正整数，则不定方程 $x_{1} + x_{2} + x_{3} + x_{4} = 12$
> >
> > 的自然数解的组数即为不定方程 $y_{1} + y_{2} + y_{3} + y_{4} = 16$ 的正整数解的组数，再利用隔板法解答
>
> > [!note]- **【解析】**
> > （1） $^{12}$ 相当于 $^{12}$ 个 $^{1}$ ，将 $^{12}$ 个 $^{1}$ 用 $^{3}$ 块板子隔开即可
> >
> > 可得不定方程正整数解的组数有 $C_{11}^{3} = 165$ 种；
> >
> > (2) 由 $x_{1} + x_{2} + x_{3} + x_{4} = 12$ 得 $x_{1} + 1 + x_{2} + 1 + x_{3} + 1 + x_{4} + 1 = 16$
> >
> > 令 $x_{1} + 1 = y_{1}, x_{2} + 1 = y_{2}, x_{3} + 1 = y_{3}, x_{4} + 1 = y_{4}$ ， $y_{1}, y_{2}, y_{3}, y_{4}$ 均为正整数，
> >
> > 则 $y_{1} + y_{2} + y_{3} + y_{4} = 16$
> >
> > 则不定方程 $x_{1} + x_{2} + x_{3} + x_{4} = 12$ 的自然数解的组数即为不定方程 $y_{1} + y_{2} + y_{3} + y_{4} = 16$ 的正整数解的组数
> >
> > $^{16}$ 相当于 $^{16}$ 个 $^{1}$ ，将 $^{16}$ 个 $^{1}$ 用 $^{3}$ 块板子隔开即可
> >
> > 可得不定方程 $y_{1} + y_{2} + y_{3} + y_{4} = 16$ 正整数解的组数有 $C_{15}^{3} = 455$ 种；
> >
> > 即不定方程 $x_{1} + x_{2} + x_{3} + x_{4} = 16$ 的自然数解的组数为455.
