> [!faq]- 《第六章_计数原理_高效培优单元自测_提升卷_》官方解析
>
> > [!success]- **【答案】** （1） $\frac{3^{n}}{2}$ ；（2）n=12或13
>
> > [!note]- **【分析】**
> > （ $^{1}$ ）逆用二项式定理展开式化简即可；
> >
> > (2) 先利用二项式展开式通项公式求得 $a_{r} = C_{n}^{r} 2^{n-r}, r = 0, 1, 2, \cdots, n$ ，然后判断其单调性，根据题意列不等
> >
> > 式求解即可·
>
> > [!note]- **【解析】**
> > （1）原式 $=\frac{1}{2}\left(C_{n}^{0}2^{n}+C_{n}^{1}2^{n-1}+C_{n}^{2}2^{n-2}+\cdots+C_{n}^{n}2^{0}\right)=\frac{1}{2}(1+2)^{n}=\frac{3^{n}}{2}$
> >
> > (2) 因为二项式 $(2+x)^{n}$ 展开式的通项为 $T_{r+1}=C_{n}^{r}2^{n-r}x^{r}, r=0,1,2,\cdots,n$
> >
> > $$
> > a _ {r} = \mathrm{C} _ {n} ^ {r} 2 ^ {n - r}, r = 0, 1, 2, \dots , n
> > $$
> >
> > 若 $a_{r}<a_{r+1},r=0,1,2,\cdots,n-1$ ，则 $\frac{n!}{r!(n-r)!}2^{n-r}<\frac{n!}{(r+1)!(n-r-1)!}2^{n-r-1}$ ，得 $r<\frac{n-2}{3}$
> >
> > 当 $r < \frac{n - 2}{3}$ 时， $a_{r} < a_{r + 1}$ ；当 $r = \frac{n - 2}{3}$ 时， $a_{r} = a_{r + 1}$ ；当 $r > \frac{n - 2}{3}$ 时， $a_{r} > a_{r + 1}$ ，
> >
> > 因为在 $a_{0}, a_{1}, a_{2}, \cdots, a_{n}$ 中，唯一的最大的数是 $a_{4}$ ， $a_{3} < a_{4}$ 且 $a_{4} > a_{5}$ ，
> >
> > 所以 $3 < \frac{n-2}{3} < 4$ ，即 11 < n < 14，又 n 为正整数，所以 n = 12 或 13.
