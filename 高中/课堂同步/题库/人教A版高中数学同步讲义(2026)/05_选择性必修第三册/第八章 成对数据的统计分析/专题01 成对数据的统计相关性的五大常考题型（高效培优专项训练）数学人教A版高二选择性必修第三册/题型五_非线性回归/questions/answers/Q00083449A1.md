> [!faq]- 《专题01 成对数据的统计相关性的五大常考题型（高效培优专项训练）数学人教A版高二选择性必修第三册》官方解析
>
> > [!success]- **【答案】** A．若样本数据 $x_{1},x_{2},\cdots,x_{6}$ 的方差为2，则数据 $2x_{1}-1,2x_{2}-1,\cdots,2x_{6}-1$ 的方差为7 B．若 $P(A)=0.6, P(B)=0.8, P(A \mid B)=0.5$ ，则 $P(B \mid A)=\frac{2}{3}$ C．在一组样本数据 $(x_{1},y_{1}),(x_{2},y_{2}),\cdots,(x_{n},y_{n})$ ， $(n=2,x_{1},x_{2},\cdots,x_{n}$ ，不全相等）的散点图中，若所有样本点 $(x_{i},y_{i})(i=1,2,\cdots,n)$ 都在直线 $y=-\frac{1}{2}x+1$ 上，则这组样本数据的线性相关系数为 $-\frac{1}{2}$ D．以模型 $y = c e^{k x}$ 去拟合一组数据时，为了求出经验回归方程，设 $z = \ln y$ ，求得线性回归方程为 $\hat{z} = 4x + 0.3$ ，则 c, k 的值分别是 $e^{0.3}$ 和 4
>
> > [!note]- **【分析】**
> > 利用方差的概念，条件概率公式，线性回归分析等知识分别对每个选项逐一判断即可·
>
> > [!note]- **【解析】**
> > 对于选项 A：若样本数据 $x_{1}, x_{2}, \cdots, x_{6}$ 的方差为 2，则数据 $2x_{1}-1, 2x_{2}-1, \cdots, 2x_{6}-1$ 的方差为 $2^{2} \times 2 = 8 \neq 7$ ，故 A 不正确；
> >
> > 对于选项 B：若 $P(A)=0.6, P(B)=0.8, P(A \mid B)=0.5$ ，则
> >
> > $P(B \mid A) = \frac{P(AB)}{P(A)} = \frac{P(B)P(A \mid B)}{P(A)} = \frac{0.8 \times 0.5}{0.6} = \frac{2}{3}$ ，故 $^{B}$ 正确；
> >
> > 对于选项 C：在一组样本数据 $(x_{1},y_{1}),(x_{2},y_{2}),\cdots,(x_{n},y_{n})$ ，(n=2, $x_{1},x_{2},\cdots,x_{n}$ ，不全相等）的散点图中，若所有样本点 $(x_{i},y_{i})(i=1,2,\cdots,n)$ 都在直线 $y=-\frac{1}{2}x+1$ 上，其中 $-\frac{1}{2}$ 是线性回归方程的一次项系数，不是相关系数，相关系数是刻画一组数据线性相关程度一个量，范围是 $[-1,1]$ ，当相关系数为正时呈正相关关系为负时呈负相关关系，故 C 不正确；
> >
> > 对于选项 D：以模型 $y = ce^{lx}$ 去拟合一组数据时，为了求出经验回归方程，设 $z = \ln y$ ，
> >
> > 则 $z = \ln y = \ln c + \ln e^{kx} = \ln c + kx$ ，由题线性回归方程为 $\hat{z} = 4x + 0.3$ ，则 $\ln c = 0.3, k = 4$ ，故 c, k 的值分别是 $e^{0.3}$ 和 4，故 D 正确。
> >
> > 故选 **BD**.
