> > 3. 近年来，我国电动汽车产业发展迅猛，某品牌汽车市场也异常火爆，销售量逐年上升。现统计某汽车
> >
> > 专卖店 $^{5}$ 月份前 $^{5}$ 天每天电动汽车的实际销量，结果如下表所示。
> >
> > <table><tr><td>日期编号x</td><td>1</td><td>2</td><td>3</td><td>4</td><td>5</td></tr><tr><td>销量y/部</td><td>8</td><td>a</td><td>12</td><td>b</td><td>23</td></tr></table>
> >
> > $y$ 与 $x$ 有较强的线性相关关系，且线性回归方程为 $\hat{y} = 3.5x + 4.7$ ，则 $a + b$ 等于（）A.28 B.30 C.33 D.35
> >
> > 【答案】C
> >
> > 【分析】求出 $\overline{x}$ 、 $\overline{y}$ ，根据回归直线方程必过样本中心点 $(\overline{x},\overline{y})$ ，代入计算可得
> > 【详解】依题意 $\overline{x}=\frac{1}{5}(1+2+3+4+5)=3,\quad\overline{y}=\frac{1}{5}(8+a+12+b+23)=\frac{43+a+b}{5}$ 又回归直线方程 $\hat{y} = 3.5x + 4.7$ 过点 $(\overline{x},\overline{y})$ ，所以 $\frac{43 + a + b}{5} = 3.5\times 3 + 4.7$
> >
> > 解得 $a + b = 33$
> >
> > 故选：C.

> > 4. 相关变量的样本数据如下表：
> >
> > <table><tr><td>x</td><td>1</td><td>2</td><td>3</td><td>4</td></tr><tr><td>y</td><td>2</td><td>3</td><td>a</td><td>5</td></tr></table>
> >
> > 经回归分析可得 $y$ 与 $x$ 线性相关，并由最小二乘法求得回归直线方程为 $\hat{y} = 1.5x + 1$ ，下列说法正确的是（）A.当 $x$ 每增加1时， $y$ 一定增加1.5 B.当 $y$ 每增加13时， $x$ 一定增加8C. $y$ 与 $x$ 呈负相关 D. $a = 9$
> >
> > 【答案】D
> >
> > 【分析】根据回归方程的意义可判断 $^{AB}$ 的正误，根据回归系数的正负可判断 $^{C}$ 的正误，根据回归方程过
> >
> > 样本中心可求 $a$ ，从而可判断 $\mathsf{D}$ 的正误
> >
> > 【详解】对于 A，因为回归直线方程为 $\hat{y}=1.5x+1$ ，故当 x 每增加 1 时，y 增加约为 1.5，
> >
> > 故 $^{A}$ 错误；
> >
> > 对于 B，因为回归直线方程为 $\hat{y}=1.5x+1$ ，故当 y 每增加 13 时，x 增加约为 8，
> >
> > 故 $^{B}$ 错误；
> >
> > 对于 C，因为 1.5 > 0，故 y 与 x 呈正相关，故 C 错误；
> >
> > 对于 D， $\overline{x}=2.5$ ，故 $\overline{y}=1.5\times2.5+1=4.75$ ，故 $\frac{2+3+a+5}{4}=4.75$ ，故 a=9
> >
> > 故 $^{D}$ 正确；
> >
> > 故选 **D**.
