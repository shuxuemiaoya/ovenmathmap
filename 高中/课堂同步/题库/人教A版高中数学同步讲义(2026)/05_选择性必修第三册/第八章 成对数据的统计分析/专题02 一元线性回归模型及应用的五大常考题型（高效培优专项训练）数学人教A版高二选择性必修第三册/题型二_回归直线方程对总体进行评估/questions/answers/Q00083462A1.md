>
> > [!note]- **【分析】**
> > 由已知数据计算 $x, y$ ，根据回归方程的性质求 $\hat{a}$ ，再利用回归方程预测当平均气温为 $35^{\circ}C$ 时，该社区患肠道感染类疾病的人数·
>
> > [!note]- **【解析】**
> > 由表格数据可得， $\overline{x}=\frac{1}{4}\times(22+26+29+32)=27.25,\quad\overline{y}=\frac{1}{4}\times(12+25+27+56)=30$
> >
> > 因为点 $\left( \overline{x}, \overline{y} \right)$ 在直线 $\hat{y} = \hat{b} x + \hat{a}$ 上， $\hat{b} = 4$
> >
> > 所以 $\hat{a}=30-4\times27.25=-79$
> >
> > 所以 $\hat{y} = 4x - 79$
> >
> > 故当 $x = 35$ 时， $\hat{y} = 4\times 35 - 79 = 61$
> >
> > 即预测当平均气温为 $35^{\circ} \mathrm{C}$ 时，该社区患肠道感染类疾病的人数为61
> >
> > 故选：C.
> >
> > 20. 蟋蟀鸣叫的频率 $x$ （次/分）与气温 $y$ （°C）存在着较强的线性相关关系。某地观测人员根据如表所示的观测数据，建立了 $y$ 关于 $x$ 的线性回归方程 $\hat{y} = 0.25x + \hat{b}$ ，则当蟋蟀每分钟鸣叫56次时，该地当时的气温预报值为\_\_\_\_。
> >
> > 【答案】
> >
> > <table><tr><td>x(次/分)</td><td>20</td><td>30</td><td>40</td><td>50</td><td>60</td></tr><tr><td>y(°C)</td><td>25</td><td>27.5</td><td>29</td><td>32.5</td><td>36</td></tr></table>
> >
> > 【答案】 $34^{\circ} \mathrm{C}$
> >
> > 【分析】计算 $\overline{x}=40$ ， $\overline{y}=30$ ，代入回归方程得到 $\hat{b}=20$ ，再代入数据计算得到答案.
> >
> > 【详解】 $\overline{x} = \frac{20 + 30 + 40 + 50 + 60}{5} = 40$ ， $\overline{y} = \frac{25 + 27.5 + 29 + 32.5 + 36}{5} = 30$
> >
> > 故 $30 = 0.25 \times 40 + \hat{b}$ ，解得 $\hat{b} = 20$ ，故 $\hat{y} = 0.25x + 20$ ，当 $x = 56$ 时， $\hat{y} = 34$ 。
> >
> > 故答案为： $34^{\circ} \mathrm{C}$
