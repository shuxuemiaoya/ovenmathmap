> [!faq]- 《专题8_3_列联表与独立性检验_高效培优讲义_数学人教A版高二选择性必》官方解析
>
> > [!success]- **【答案】** BD
>
> > [!note]- **【分析】**
> > 根据独立性检验的原理可判断 A；对 $y = c e^{kx}$ 两边取对数，对照 $z = 3x + 1$ 求解可判断 B；由回归方程
> >
> > 不一定过样本点可判断 $^{C}$ ，根据决定系数公式可判断 $^{D}$ .
>
> > [!note]- **【解析】**
> > 对 $^{A}$ ，由独立性检验的原理可知， $x^{2}$ 的值越小，判定“两变量有关系”犯错误的概率越大，错误；
> >
> > 对 B，对 $y = ce^{kx}$ 两边取对数得 $\ln y = \ln c + kx$ ，即 $z = \ln c + kx$ ，
> >
> > 又 $z = 3x + 1$ ，所以 $k = 3, \ln c = 1$ ，即 $k = 3, c = e$ ，正确；
> >
> > 对 $C$ ，回归方程 $\hat{y} = 0.4x + a$ 不一定过样本点 $(-a,5.4)$ ，所以无法确定 $a$ 的值，错误；
> >
> > 对 $^{D}$ ，由决定系数公式 $R^{2}=1-\frac{\sum_{i=1}^{n}\left(y_{i}-\bar{y}_{i}\right)^{2}}{\sum_{i=1}^{n}\left(y_{i}-\bar{y}\right)^{2}}$ 可知，
> >
> > 当 $y_{i}$ 代换成 $y_{i} + 3$ 时， $y_{i} - \overline{y}_{i}$ 和 $y_{i} - \overline{y}$ 的值都没有发生变化，故决定系数 $R^2$ 不变，正确
> >
> > 故选 **BD**
