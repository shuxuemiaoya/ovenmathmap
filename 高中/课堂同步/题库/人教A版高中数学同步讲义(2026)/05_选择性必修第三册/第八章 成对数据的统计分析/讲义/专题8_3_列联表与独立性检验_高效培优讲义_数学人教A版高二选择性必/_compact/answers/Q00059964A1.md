> [!faq]- 《专题8_3_列联表与独立性检验_高效培优讲义_数学人教A版高二选择性必》官方解析
>
> > [!success]- **【答案】** $^{35}$ （或 $^{36}$ 或 $^{44}$ 或 $^{45}$ ，答案不唯一）
>
> > [!note]- **【分析】**
> > 由独立性检验公式可得 $3.841 < \frac{(a - 40)^{2}}{4} \leq 6.635$ ，据此可得答案
>
> > [!note]- **【解析】**
> > 易知 $\chi^2 = \frac{100[a(a - 30) - (50 - a)(80 - a)]^2}{50\times 50\times 80\times 20} = \frac{(a - 40)^2}{4}$ ，依题意可知 $3.841 <   \frac{(a - 40)^2}{4}\leq 6.635$
> >
> > 解得 $40 - \sqrt{26.54} \leq a < 40 - \sqrt{15.364}$ 或 $40 + \sqrt{15.364} < a \leq 40 + \sqrt{26.54}$ ，
> >
> > 又 $5.2^{2} = 27.04$ ， $5.1^{2} = 26.01$ ， $3.9^{2} = 15.21$
> >
> > 则 $3.9 < \sqrt{15.364} < 4$ ， $5.1 < \sqrt{26.54} < 5.2$
> >
> > 得 $34.8 < a < 36.1$ 或 $43.9 < a \leq 45.2$ ，故 $a$ 的可能取值为 $35, 36, 44, 45$ .
> >
> > 故答案为： $^{35}$ （或 $^{36}$ 或 $^{44}$ 或 $^{45}$ ，答案不唯一）
