> [!faq]- 《第八章_成对数据的统计分析_高效培优讲义_数学人教A版高二选择性必修第》官方解析
>
> > [!success]- **【答案】** D
>
> > [!note]- **【分析】**
> > 根据给定条件，利用决定系数大小关系排除 $AB$ ；再利用数表中数据求出斜率判断 $CD$ .
>
> > [!note]- **【解析】**
> > 由用线性回归和指数型回归模型拟合 $y$ 与 $x$ 关系的决定系数分别为 $R_{1}^{2} = 0.8913$ 和 $R_{2}^{2} = 0.9940$
> >
> > 得 $R_{1}^{2} < R_{2}^{2}$ ，则指数型回归模型最适宜拟合 y 与 x 关系，排除 AB；
> >
> > 设 $y$ 与 $x$ 之间关系的函数为 $\hat{y} = \mathrm{e}^{\hat{b} x + \hat{a}}$ ，两边取对数得 $\ln \hat{y} = \hat{b} x + \hat{a}$ ，设 $\hat{\omega} = \ln \hat{y}$ ，则 $\hat{\omega} = \hat{b} x + \hat{a}$
> >
> > 因此 $\hat{b} = \frac{\sum_{i=1}^{6}(x_i - \overline{x})(\omega_i - \overline{\omega})}{\sum_{i=1}^{6}(x_i - \overline{x})^2} = \frac{6}{10} = 0.6$ ， $\hat{a} = \overline{\omega} - \hat{b}\overline{x} = 0.5 - 0.6\times 3 = -1.3$
> >
> > 即 $\ln\hat{y}=0.6x-1.3,\quad\hat{y}=e^{0.6x-1.3}$ ，C 错误，D 正确.
> >
> > 故选 **D**
