> [!faq]- 《专题8_2_一元线性回归模型及其应用_高效培优讲义_数学人教A版高二选》官方解析
>
> > [!success]- **【答案】** (1) $\hat{y}=-0.32x+14.4$ ; (2)1.6 kg.
>
> > [!note]- **【分析】**
> > （ $^{1}$ ）直接根据最小二乘法估计求回归方程；
> >
> > (2) 直接根据回归方程计算预测值·
>
> > [!note]- **【解析】**
> > （1）由题知
> >
> > $$
> > \overline {{x}} = \frac {1 0 + 1 5 + 2 0 + 2 5 + 3 0}{5} = \frac {1 0 0}{5} = 2 0 \quad \overline {{y}} = \frac {1 1 + 1 0 + 8 + 6 + 5}{5} = \frac {4 0}{5} = 8
> > $$
> >
> > $$
> > \sum_ {i = 1} ^ {5} x _ {i} y _ {i} = 1 0 \times 1 1 + 1 5 \times 1 0 + 2 0 \times 8 + 2 5 \times 6 + 3 0 \times 5 = 1 1 0 + 1 5 0 + 1 6 0 + 1 5 0 + 1 5 0 = 7 2 0,
> > $$
> >
> > $$
> > \sum_ {i = 1} ^ {5} x _ {i} ^ {2} = 1 0 ^ {2} + 1 5 ^ {2} + 2 0 ^ {2} + 2 5 ^ {2} + 3 0 ^ {2} = 1 0 0 + 2 2 5 + 4 0 0 + 6 2 5 + 9 0 0 = 2 2 5 0 \cdot
> > $$
> >
> > $$
> > \hat {b} = \frac {\sum_ {i = 1} ^ {n} x _ {i} y _ {i} - n \cdot \bar {x} \cdot \bar {y}}{\sum_ {i = 1} ^ {n} x _ {i} ^ {2} - n \cdot \bar {x} ^ {2}} = \frac {7 2 0 - 5 \times 2 0 \times 8}{2 2 5 0 - 5 \times 2 0 ^ {2}} = - \frac {8 0}{2 5 0} = - 0. 3 2, \quad \hat {a} = \bar {y} - \hat {b} \bar {x} = 8 - (- 0. 3 2) \times 2 0 = 1 4. 4
> > $$
> >
> > 综上， $y$ 关于 $x$ 的线性回归方程为： $\hat{y} = -0.32x + 14.4$ 。
> >
> > (2) 由 (1) 知回归方程为 $\hat{y} = -0.32x + 14.4$ .
> >
> > 所以当 $x = 40$ 时， $\hat{y} = -0.32 \times 40 + 14.4 = -12.8 + 14.4 = 1.6$ .
> >
> > 故当价格 x = 40 元/kg 时，日需求量 y 的预测值为 1.6 kg.
