> [!faq]- 《专题8_2_一元线性回归模型及其应用_高效培优讲义_数学人教A版高二选》官方解析
>
> > [!success]- **【答案】** BC
>
> > [!note]- **【分析】**
> > 根据中位数概念判断 $^{A}$ ，根据条件概率公式及相互独立事件判断 $^{B}$ ，根据正态分布的对称性判断 $^{C}$ ，
> >
> > 根据残差概念判断 D.
>
> > [!note]- **【解析】**
> > 对 A，数据由小到大排列为 1,2,4,5,7,11,16,21，其中位数为 $\frac{5+7}{2}=6$ ，故 A 错误；
> >
> > 对 $^{B}$ ，当 $P(A) > 0$ 时， $P(B|A) = \frac{P(AB)}{P(A)} = P(B)$ ，即 $P(AB) = P(A)P(B)$ ，所以事件 $A$ 与 $B$ 相互独立，故 $^{B}$ 正
> >
> > 确；
> >
> > 对 $C$ ，随机变量 $X$ 服从正态分布 $N(6,\sigma^2)$ ，且 $P(X < 10) = 0.8$ ，所以 $P(6 < X < 10) = 0.8 - 0.5 = 0.3$ ，由正态分
> >
> > 布的对称性知， $P(2 < X < 6) = 0.3$ ，故 C 正确；
> >
> > 对 $\mathsf{D}$ ，由 $\widehat{y} = 3x + \widehat{a}$ 可知， $(s,3)$ 与 $(3,t)$ 的残差分别为 $3 - (3s + \hat{a})$ ， $t - (3\times 3 + \hat{a})$
> >
> > 所以由 $3 - (3s + \hat{a}) = t - (3 \times 3 + \hat{a})$ 可得 $3s + t = 12$ ，故D错误
> >
> > 故选 **BC**
