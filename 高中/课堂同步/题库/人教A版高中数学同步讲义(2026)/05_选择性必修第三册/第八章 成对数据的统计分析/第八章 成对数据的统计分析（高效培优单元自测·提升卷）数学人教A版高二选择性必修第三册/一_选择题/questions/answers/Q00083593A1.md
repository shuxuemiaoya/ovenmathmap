> [!faq]- 《第八章 成对数据的统计分析（高效培优单元自测·提升卷）数学人教A版高二选择性必修第三册》官方解析
>
> > [!success]- **【答案】** A．已知随机变量 X 服从二项分布 $B(n,p)$ ，若 $E(X)=15$ ， $D(X)=10$ ，则 $p=\frac{1}{3}$ B．已知随机变量 X 服从正态分布 $N(1, \sigma^{2})$ ，若 $P(X < 3) = 0.6$ ，则 $P(-1 < X < 1) = 0.2$ C．已知 $A$ ， $B$ 为随机事件， $P(A) = 0.5$ ， $P(B) = 0.6$ ，若 $A$ ， $B$ 相互独立，则 $P(A \cup B) = 0.8$ D．样本点 $(x_{i},y_{i})(i=1,2,3,\cdots)$ 的经验回归方程为 $\hat{y}=3x+\hat{a}$ ，若样本点 $(m,3)$ 与 $(2,n)$ 的残差相等，则 $$ 3 m + n = 9 $$
>
> > [!note]- **【分析】**
> > 由二项分布的期望和方差公式可得 $^{A}$ ；利用正态分布的对称性可判断 $^{B}$ ；由独立事件的乘法公式
> >
> > 可得 C；利用残差的计算可得 D.
>
> > [!note]- **【解析】**
> > 对于 A，已知随机变量 X 服从二项分布 $B(n,p)$ ，若 $E(X)=15$ ， $D(X)=10$
> >
> > 则 $np = 15, np(1 - p) = 10$ ，解得 $p = \frac{1}{3}$ ，故 $\mathsf{A}$ 正确；
> >
> > 对于 $\mathsf{B}$ ，随机变量 $X$ 服从正态分布 $N(1,\sigma^2)$ ，所以对称轴为 $x = 1$ ，则 $P(X < 1) = 0.5$
> >
> > 因为 $P(X < 3) = 0.6$ ，所以 $P(1 < X < 3) = 0.1$
> >
> > 所以 $P(-1 < X < 1) = P(1 < X < 3) = 0.1$ ，故 B 错误；
> >
> > 对于 $\mathbb{C}$ ，若 $A$ ， $B$ 相互独立，则 $P(AB) = P(A)\cdot P(B) = 0.3$
> >
> > 所以 $P(A \cup B) = P(A) + P(B) - P(AB) = 0.5 + 0.6 - 0.3 = 0.8$ ，故 C 正确；
> >
> > 对于 $^{D}$ ，由题意可得样本点 $(m,3)$ 与 $(2,n)$ 的残差分别为 $3-\left(3m+\hat{a}\right)$ 和 $n-\left(6+\hat{a}\right)$ ，
> >
> > 所以 $3-(3m+\hat{a})=n-(6+\hat{a})$ ，则 $3m+n=9$ ，故 D 正确.
> >
> > 故选 **ACD**.
