> [!faq]- 《第八章 成对数据的统计分析（高效培优讲义）数学人教A版高二选择性必修第三册》官方解析
>
> > [!success]- **【答案】** A．对于独立性检验， $X^{2}$ 的值越大，说明两事件的相关程度越大 B．以模型 $y = ce^{kx}$ 去拟合一组数据时，为了求出回归方程，设 $z = \ln y$ ，将其变换后得到线性方程 $z = 0.3x + 4$ ，则 $c,k$ 的值分别是 $\mathrm{e}^4$ 和0.3 C．在具有线性相关关系的两个变量的统计数据所得的回归直线方程 $\hat{y} = \hat{a} +\hat{b} x$ 中， $\hat{b} = 2,\overline{x} = 1,\overline{y} = 3$ ，则 $$ \hat {a} = 1 $$ D．通过回归直线 $\hat{y} = \hat{b}x + \hat{a}$ 及回归系数 $\hat{b}$ ，可以精确反映变量的取值和变化趋势
>
> > [!note]- **【解析】**
> > 根据独立性检验、非线性回归方程以及回归直线方程相关知识进行判断·
> >
> > 【详解】对于 A ，根据独立性检验的性质知， $X^{2}$ 的值越大，说明两个事件的相关程度越大，故 A 正确；
> >
> > 对于 B ，由 $y = c e^{kx}$ ，两边取自然对数，可得 $\ln y = \ln c + kx$ ，
> >
> > $z = \ln y$ ，则 $z = kx + \ln c$ ，因为 $z = 0.3x + 4$ ，所以 $\left\{ \begin{array}{l} \ln c = 4, \\ k = 0.3, \end{array} \right.$ 则 $\left\{ \begin{array}{l} c = \mathrm{e}^4, \\ k = 0.3, \end{array} \right.$ 故 $^B$ 正确；
> >
> > 对于 $C$ ，由于回归直线过点 $(\overline{x},\overline{y}),\hat{a} = \overline{y} -\hat{b}\overline{x} = 3 - 2\times 1 = 1$ ，故 $^C$ 正确；
> >
> > 对于 D，通过回归直线 $\hat{y} = \hat{b}x + \hat{a}$ 及回归系数 $\hat{b}$ ，可预测变量的取值和变化趋势，故 D 错误
> >
> > 故选 **ABC**.
