> [!faq]- 《专题02_一元线性回归模型及应用的五大常考题型_高效培优专项训练_数学》官方解析
>
> > [!success]- **【答案】** D
>
> > [!note]- **【分析】**
> > 表达式 $\sum_{k=1}^{6}\left(y_{k}-bk-a\right)^{2}$ 表示的是样本点 $(x_{i},y_{i}),(i=1,2,\cdots,n)$ 与回归直线方程的整体接近程度，故可根据此意义逆向分析 $\sum_{k=1}^{6}\left(y_{k}-bk-a\right)^{2}$ 的意义，结合条件即可解决之.
>
> > [!note]- **【解析】**
> > 由题意得 $\overline{x} = \frac{1}{6}\left(2017 + 2018 + 2019 + 2020 + 2021 + 2022\right) = \frac{4039}{2}$ ， $\overline{y} = 4\overline{x} + 9 = 8087$ ，
> >
> > $\sum_{k=1}^{6}\left(y_k - bk - a\right)^2$ 表示样本点 $(k, y_k), (k = 1, 2, \cdots, 6)$ 与回归直线 $\hat{y} = bk + a$ 的整体接近程度，
> >
> > 且由样本点 $(k,y_{k}),(k=1,2,\cdots,6)$ 构成的表为
> >
> > <table><tr><td>k</td><td>1</td><td>2</td><td>3</td><td>4</td><td>5</td><td>6</td></tr><tr><td>y</td><td> $y_1$ </td><td> $y_2$ </td><td> $y_3$ </td><td> $y_4$ </td><td> $y_5$ </td><td> $y_6$ </td></tr></table>
> >
> > 对应的回归直线方程为： $\hat{y} = bk + a$
> >
> > 由表知 $\overline{k} = \frac{1}{6}\big(1 + 2 + 3 + 4 + 5 + 6\big) = \frac{7}{2}$ ，所以 $\overline{y} = b\overline{k} +a = \frac{7}{2} b + a = 8087$
> >
> > 由题意可知：在散点图中，样本点 $(k,y_{k}),(k=1,2,\cdots,6)$ 是将样本点 $(x_{i},y_{i}),(i=1,2,\cdots,6)$ 整体向左平移了2016个单位，
> >
> > 故 $\sum_{k=1}^{6}\left(y_k - bk - a\right)^2$ 取到最小值时，回归直线 $\hat{y} = bk + a$ 与 $\hat{y} = 4x + 9$ 必平行，则有 $b = 4$ ，
> >
> > 所以 $a = 8087 - \frac{7}{2} b = 8073$ ，所以 $a + b = 8077\cdot$
> >
> > 故选 **D**.
