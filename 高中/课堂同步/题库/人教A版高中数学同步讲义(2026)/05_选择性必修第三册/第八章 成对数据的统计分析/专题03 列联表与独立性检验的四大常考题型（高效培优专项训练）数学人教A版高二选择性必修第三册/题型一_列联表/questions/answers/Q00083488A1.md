> [!faq]- 《专题03 列联表与独立性检验的四大常考题型（高效培优专项训练）数学人教A版高二选择性必修第三册》官方解析
>
> > [!success]- **【答案】** $a = 22, b = 24, c = 40, d = 38, e = 82$
>
> > [!note]- **【分析】**
> > 根据已知条件补全联表即可·
>
> > [!note]- **【解析】**
> > 根据已知条件得出 $20 + a = 42, a = 22$
> >
> > 又因为 $20 + b = 44$ ，所以 $b = 24$ ，所以 $c = 24 + 16 = 40$
> >
> > 所以 $d = a + 16 = 38, e = 42 + 40 = 82$ .
> >
> > 所以 $a = 22, b = 24, c = 40, d = 38, e = 82$ .
