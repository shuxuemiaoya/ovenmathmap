> [!faq]- 《专题03 列联表与独立性检验的四大常考题型（高效培优专项训练）数学人教A版高二选择性必修第三册》官方解析
>
> > [!success]- **【答案】** <table><tr><td></td><td> $B_1$ </td><td> $B_2$ </td><td>合计</td></tr><tr><td> $A_1$ </td><td>a</td><td>b</td><td>a+b</td></tr><tr><td> $A_2$ </td><td>c</td><td>d</td><td>c+d</td></tr><tr><td>合计</td><td>a+c</td><td>b+d</td><td>n=a+b+c+d</td></tr></table> A. 若 $\frac{a}{n} = \frac{(a + b)(a + c)}{n^2}$ ，则可以认为 $A_{1}$ 与 $B_{1}$ 独立 B. 若变量 $A$ 与 $B$ 独立，则 $\frac{a}{n} = \frac{(a + b)(a + c)}{n^2}$ C. 若 $\left|\frac{an - (a + b)(a + c)}{n^2}\right|$ 很大，则变量 $A$ 与 $B$ 不独立 D. 若变量 $A$ 与 $B$ 不独立，则 $\left|\frac{an - (a + b)(a + c)}{n^2}\right|$ 很大
>
> > [!note]- **【分析】**
> > 运用独立性检验的步骤原理推理判断即可·
>
> > [!note]- **【解析】**
> > 用频率 $\frac{a}{n}$ 可以估计 $P(A_{1}B_{1})$ ，用频率 $\frac{a+b}{n}$ 可以估计 $P(A_{1})$ ，用频率 $\frac{a+c}{n}$ 可以估计 $P(B_{1})$ ，若 $\frac{a}{n}=\frac{(a+b)(a+c)}{n^{2}}$ ，则 $P(A_{1}B_{1})=P(A_{1})P(B_{1})$ ，可以认为 $A_{1}$ 与 $B_{1}$ 独立，故A正确；
> > 由于 $\frac{a}{n}$ ， $\frac{a+b}{n}$ ， $\frac{a+c}{n}$ 表示的是频率，n是抽取的样本数据，故即使变量A与B独立， $\frac{a}{n}=\frac{(a+b)(a+c)}{n^{2}}$ 也不一定成立，故B错误；
> > 若 $\left|\frac{an-(a+b)(a+c)}{n^{2}}\right|$ 很大，可以说明与不独立，故正确；
> > 若变量与不独立， $\left|\frac{an-(a+b)(a+c)}{n^{2}}\right|\neq0$ ，但并不一定很大，故D错误。
> > 故选：AC.

> > 6. 地铁的开通，在一定程度上缓解了市内交通的拥堵状况·某条地铁线路开通后，某调查机构抽取了部分乘坐该线路地铁的市民作为样本，分析其年龄和性别结构，得到如下信息： $^{35}$ 岁及以下的市民中，男性约占 $52\%$ ； $^{35}$ 岁以上的市民中，男性约占 $56\%$ ；男性市民中， $^{35}$ 岁及以下的约占 $43\%$ ；女性市民中， $^{35}$ 岁及以下的约占 $47\%$ ·根据以上信息，下列结论不一定正确的是（）
> >
> > 【答案】
> >
> > A. 样本中男性比女性多
> >
> > B. 样本中多数女性是 $^{35}$ 岁以上
> >
> > C. 样本中 $^{35}$ 岁及以下的男性人数比 $^{35}$ 岁以上的女性人数多
> >
> > D. 样本中 $^{35}$ 岁以上的市民比 $^{35}$ 岁及以下的多
> >
> > 【答案】C
> >
> > 【分析】根据题意，得到如下两个 $2\times2$ 列联表，再一一分析即可·
> >
> > 【详解】根据题意，得到如下两个 $2 \times 2$ 列联表·
> >
> > <table><tr><td></td><td>35岁以上</td><td>35岁及以下</td><td>总计</td></tr><tr><td>男性</td><td>0.56x</td><td>0.52y</td><td>0.56x+0.52y</td></tr><tr><td>女性</td><td>0.44x</td><td>0.48y</td><td>0.44x+0.48y</td></tr><tr><td>总计</td><td>x</td><td>y</td><td>x+y</td></tr><tr><td></td><td>35岁以上</td><td>35岁及以下</td><td>总计</td></tr><tr><td>男性</td><td>0.57a</td><td>0.43a</td><td>a</td></tr><tr><td>女性</td><td>0.53b</td><td>0.47b</td><td>b</td></tr><tr><td>总计</td><td>0.57a+0.53b</td><td>0.43a+0.47b</td><td>a+b</td></tr></table>
> >
> > 根据第 $^{1}$ 个列联表可知，样本中男性市民人数为 $0.56x + 0.52y$
> >
> > 女性市民人数为 $0.44x + 0.48y$ ，又 $0.56x + 0.52y > 0.44x + 0.48y$ ，即样本中男性比女性多，故 $^{A}$ 正确；根据第 $^{2}$ 个列联表可知，样本中 $^{35}$ 岁以上女性市民人数为 0.53b，
> >
> > $^{35}$ 岁及以下女性市民人数为 0.47b，又 0.53b > 0.47b，即样本中多数女性是 $^{35}$ 岁以上，故 $^{B}$ 正确；由题意， $\frac{0.52y}{0.56x + 0.52y} = 0.43 \Rightarrow x \approx 1.231y$ ，所以 0.52y < 0.44x，故 $^{C}$ 不正确；
> >
> > 根据第 $^{2}$ 个列联表可知，样本中 $^{35}$ 岁以上市民人数为 $0.57a + 0.53b$
> >
> > 35 岁及以下市民人数为 $0.43a + 0.47b$ ，又 $0.57a + 0.53b > 0.43a + 0.47b$
> >
> > 即样本中 $^{35}$ 岁以上的市民比 $^{35}$ 岁及以下的多，故 $^{D}$ 正确·
> >
> > 故选 **C**.
