> [!faq]- 《专题01 条件概率的四大常考题型（高效培优专项训练）数学人教A版高二选择性必修第三册》官方解析
>
> > [!success]- **【答案】** $\frac{1}{4} / 0.25$
>
> > [!note]- **【分析】**
> > 根据条件概率计算公式 $P(B|A) = \frac{n(AB)}{n(A)}$ 求解即可.
>
> > [!note]- **【解析】**
> > 事件 $A$ ：“取到的2个数之和为偶数”，则事件 $A$ 包含的基本事件个数为 $n(A) = C_3^2 + 1 = 4$ 又事件 B：“取到的 2 个数均为偶数”，则事件 A 与事件 B 同时发生包含的基本事件个数为 $n(AB)=1$ ，
> > 所以 $P(B|A)=\frac{n(AB)}{n(A)}=\frac{1}{4}$ .
> > 故答案为： $\frac{1}{4}$

> > 4．抛掷一枚质地均匀的骰子，观察它落地时朝上的面的点数，设事件 $M =$ “点数为1或2”，事件 $N =$ “点数为2或3或4”，则（ ）A． $M$ 与 $N$ 是互斥事件 B． $M$ 与 $N$ 是相互独立事件C． $P(M|N) = P(N|M)$ D． $P(\overline{MN}) + P(M\overline{N}) = \frac{1}{2}$
> >
> > 【答案】BD
> >
> > 【分析】根据互斥事件与独立事件定义可判断 A, B，由条件概率公式计算 $P(M|N), P(N|M)$ 可判断 C，再由对立事件与独立事件的关系计算 $P(\bar{M}N), P(M\bar{N})$ 可判断 D．
> >
> > 【详解】根据题意，依次分析选项：
> >
> > 对于 A，事件 M = “点数为 1 或 2”，事件 N = “点数为 2 或 3 或 4”，则 MN = “点数为 2”，事件 M，N 可以同时发生，不是互斥事件，故 A 错误；
> >
> > 对于 B，由于 $P(MN)=\frac{1}{6}, P(M)=\frac{1}{3}, P(N)=\frac{1}{2}$ ，满足 $P(MN)=P(M)P(N)$ ，故 M 与 N 是相互独立事件，故 B 正确；
> >
> > 对于 C，由 B 可知 $P(M \mid N) = P(M) = \frac{1}{3}$ ， $P(N \mid M) = P(N) = \frac{1}{2}$ ，故 C 错误；
> >
> > 对于 D，由于 M 与 N 是相互独立事件，所以 $\overline{M}$ 与 N，M 与 $\overline{N}$ 是相互独立事件，
> >
> > 所以 $P(\overline{M}N)=P(\overline{M})P(N)=\frac{2}{3}\times\frac{1}{2}=\frac{1}{3}$ ， $P(M\overline{N})=P(M)P(\overline{N})=\frac{1}{3}\times\frac{1}{2}=\frac{1}{6}$ ，则 $P(\overline{M}N)+P(M\overline{N})=\frac{1}{2}$ ，故 D 正确。
> >
> > 故选：BD.

> > 5. 树人中学举办校运动会，甲、乙、丙、丁、戊五名志愿者被随机地分配到篮球、羽毛球、乒乓球三个不同的体有场馆服务，每个场馆至少有一名志愿者。已知有三位志愿者被分配到篮球馆服务，则甲没有被分配到篮球馆的概率为\_\_\_\_。
> >
> > 【答案】 $\frac{2}{5} / 0.4$
> >
> > 【分析】根据题意，由排列组合数公式计算 $n(A), n(AB)$ ，再利用古典概型公式计算即可.
> >
> > 【详解】设“有三位志愿者被分配到篮球馆服务”为事件 A，“甲没有被分配到篮球馆”为事件 B，
> > 则 $n(A)=C_{5}^{3}A_{2}^{2}=20, n(AB)=C_{4}^{3}A_{2}^{2}=8, P(B,A)=\frac{n(AB)}{n(A)}=\frac{8}{20}=\frac{2}{5}$
> >
> > 故答案为： $\frac{2}{5}$
