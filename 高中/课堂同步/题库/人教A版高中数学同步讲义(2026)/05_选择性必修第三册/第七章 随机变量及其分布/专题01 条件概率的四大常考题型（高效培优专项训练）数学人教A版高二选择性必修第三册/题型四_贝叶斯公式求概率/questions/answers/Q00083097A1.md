> [!faq]- 《专题01 条件概率的四大常考题型（高效培优专项训练）数学人教A版高二选择性必修第三册》官方解析
>
> > [!success]- **【答案】** A. 这件生活用品合格的概率为 0.982 B. 这件生活用品不合格的概率为 0.015 C. 若这件生活用品不合格，则它来自 $A$ 机器生产的概率为 $\frac{5}{6}$ D. 若这件生活用品不合格，则它来自 $B$ 机器生产的概率为 $\frac{1}{4}$
>
> > [!note]- **【分析】**
> > 设该生活用品由 A 机器生产为事件 A，该生活用品由 B 机器生产为事件 B，该生活用品为合格品为事件 C，得到 $P(A)=0.75, P(B)=0.25, P(C \mid A)=0.98, P(C \mid B)=0.988$ ，且 $P(\overline{C} \mid A)=0.02, P(\overline{C} \mid B)=0.012$ ，结合全概率公式阿赫条件概率的计算公式，逐项求解，即可得到答案。
>
> > [!note]- **【解析】**
> > 设该生活用品由 A 机器生产为事件 A，该生活用品由 B 机器生产为事件 B，
> > 该生活用品为合格品为事件 C，
> > 可得 $P(A)=0.75, P(B)=0.25, P(C \mid A)=0.98, P(C \mid B)=0.988$ 则 $P(\overline{C} \mid A)=0.02, P(\overline{C} \mid B)=0.012$ 对于 A 中，由 $P(C)=P(A)P(C \mid A)+P(B)P(C \mid B=0.75\times0.98+0.25\times0.988=0.982$ ，所以 A 正确；
> > 对于 B 中，由 $P(\overline{C})=1-P(C)=1-0.982=0.018$ ，所以 B 错误；
> > 对于 C 中， $P(A|\overline{C})=\frac{P(A\overline{C})}{P(\overline{C})}=\frac{0.75\times0.02}{0.018}=\frac{5}{6}$ ，所以 C 正确；
> > 对于 D 中， $P(B|\overline{C})=1-P(A|\overline{C})=\frac{1}{6}$ ，所以 D 错误。
> >
> > 故选：AC.

> > 34. 两批同种规格的产品，第一批占 $40\%$ ，次品率为 $3\%$ ；第二批占 $60\%$ ，次品率为 $2\%$ ，则（）A．从两批产品中各取1件，都取到次品的概率为 $0.06\%$ B．从两批产品中各取1件，都取到次品的概率为 $2.4\%$ C．两批产品混合后任取1件，该产品是次品的概率为 $2.4\%$ D．两批产品混合后任取1件，若取到的是次品，则它取自第一批产品的概率为 $0.3\%$
> >
> > 【答案】AC
> >
> > 【分析】对于 A, B，运用独立事件的概率乘法公式计算即可判断；对于 C，设出相关事件，运用全概率公式计算即得；对于 D，利用贝叶斯公式计算即得.
> >
> > 【详解】依题意，从两批产品中各取1件，都取到次品的概率为 $3\% \times 2\% = 0.06\%$ ，故A正确，B错误；设事件 $B =$ “次品来自第一批产品”， $C =$ “次品来自第二批产品”，而 $A =$ “从混合后的产品中取出一件是次品”，
> >
> > 则 $P(B)=40\%, P(C)=60\%, P(A \mid B)=3\%, P(A \mid C)=2\%$ ,
> >
> > 因 $P(A) = P(B)P(A|B) + P(C)P(A|C = 40\% \times 3\% +60\% \times 2\% = 2.4\%$ ，故C正确；
> >
> > 因 $P(B \mid A) = \frac{P(AB)}{P(A)} = \frac{P(B)P(A \mid B)}{P(A)} = \frac{40\% \times 3\%}{2.4\%} = 50\%$ ，故D错误.
> >
> > 故选：AC.

> > 35. 假设小红口袋中有 3 个白球和 3 个红球，小兰口袋中有 2 个白球和 2 个红球，现小红从自己口袋中任取 2 个球放入小兰口袋中，小兰再从自己口袋中任取 2 个球，已知小兰取出的是 2 个红球，则小红从口袋中取出的也是 2 个红球的概率为 \_\_\_\_.
> >
> > 【答案】 $\frac{3}{8}/0.375$
> >
> > 【分析】根据全概率公式求解小兰取出的是2个红球的概率
> >
> > $P(A_{0})P(B|A_{0})+P(A_{1})P(B|A_{1})+P(A_{2})P(B|A_{2})$ ；进而求解小红从口袋中取出的也是2个红球的概率 $P(A_{2})P(B|A_{2})$ ，即可利用贝叶斯公式求解即可.
> >
> > 【详解】设小红取出2个球，其中红球的个数为 $i = 0,1,2$ 个的事件为 $A_{i}$ ，从小兰取出2个球，其中红球的个数为2个的事件为 $B$ ，
> >
> > 由题意可得： $P(A_0) = \frac{C_3^2C_3^0}{C_6^2} = \frac{1}{5}, P(B|A_0) = \frac{C_4^0C_2^2}{C_6^2} = \frac{1}{15}$ ； $P(A_1) = \frac{C_3^1C_3^1}{C_6^2} = \frac{3}{5}, P(B|A_1) = \frac{C_3^0C_3^2}{C_6^2} = \frac{1}{5}$ ； $P(A_2) = \frac{C_3^0C_3^2}{C_6^2} = \frac{1}{5}, P(B|A_2) = \frac{C_2^0C_4^2}{C_6^2} = \frac{2}{5}$ ；
> > 则 $P(A_2|B) = \frac{P(A_2)P(B|A_2)}{P(A_0)P(B|A_0) + P(A_1)P(B|A_1) + P(A_2)P(B|A_2)} = \frac{\frac{1}{5} \times \frac{2}{5}}{\frac{1}{5} \times \frac{1}{15} + \frac{3}{5} \times \frac{1}{5} + \frac{1}{5} \times \frac{2}{5}} = \frac{3}{8}$ ，所以小兰取出的是2个红球，则小红取出的也是2个红球的概率为 $\frac{3}{8}$ .
> >
> > 故答案为： $\frac{3}{8}$
