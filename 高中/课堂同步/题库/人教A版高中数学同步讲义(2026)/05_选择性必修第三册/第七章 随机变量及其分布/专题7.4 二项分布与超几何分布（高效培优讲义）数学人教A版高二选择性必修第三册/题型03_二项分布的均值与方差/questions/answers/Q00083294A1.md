> [!faq]- 《专题7.4 二项分布与超几何分布（高效培优讲义）数学人教A版高二选择性必修第三册》官方解析
>
> > [!success]- **【答案】** ACD
>
> > [!note]- **【分析】**
> > 对于 $^{A}$ ，由独立事件的乘法公式即可判断；对于 $^{B}$ ，先计算一轮中甲获胜的概率，再由
> >
> > $X \sim B(8, a(1 - b))$ 即可得到；对于 C，由题可得一轮中平局的概率即可判断；对于 D，当 a = b 时，一轮中甲
> >
> > 获胜的概率 $p = a(1 - a)$ ，则 4 轮比赛中，甲获胜 2 次的概率为 $C_{4}^{2}p^{2}(1 - p)^{2} = \frac{392}{2187}$ 即可求解.
>
> > [!note]- **【解析】**
> > 一轮比赛中乙获胜，即乙投中甲未投中，其概率为 $b(1-a)$ ，故 $^{A}$ 正确；
> >
> > 一轮比赛中甲获胜的概率为 $a(1 - b)$ ，由 $X \sim B(8, a(1 - b))$ ，知 $8a(1 - b) = 2$ ，故 $a = \frac{1}{4(1 - b)}$
> >
> > 所以 $a-b=\frac{1}{4(1-b)}+(1-b)-1$ $2\sqrt{\frac{1}{4(1-b)}\times(1-b)}-1=0$ （当且仅当 $b=\frac{1}{2}$ 时取等号），
> >
> > 可得 a-b 的最小值为 0，故 B 错误；
> >
> > 一轮比赛中平局的概率为 $ab + (1 - a)(1 - b) = 2ab - a - b + 1 = \frac{1}{2} + 2\left(\frac{1}{2} - a\right)\left(\frac{1}{2} - b\right) > \frac{1}{2}$ ，故 C 正确；
> >
> > 若 $a = b$ ，一轮比赛中甲获胜的概率 $p = a(1 - a)$ 则4轮比赛中，甲获胜2次的概率为 $\mathrm{C}_4^2 p^2 (1 - p)^2 = \frac{392}{2187}$ 解得 $p = \frac{2}{9}$ 或 $\frac{7}{9}$ ，当 $a(1 - a) = \frac{2}{9}$ 时，解得 $a = \frac{1}{3}$ 或 $\frac{2}{3}$ ，当 $a(1 - a) = \frac{7}{9}$ 时，方程无解，综上， $a = \frac{1}{3}$ 或 $\frac{2}{3}$ ，故D正确·
> >
> > 故选 **ACD**.
