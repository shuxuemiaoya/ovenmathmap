> [!faq]- 《专题7.4 二项分布与超几何分布（高效培优讲义）数学人教A版高二选择性必修第三册》官方解析
>
> > [!success]- **【答案】** B
>
> > [!note]- **【分析】**
> > 将乙盒中原有的 $^{1}$ 个黑球与从甲盒抽取的黑球数结合，利用超几何分布的期望公式计算可判断数列
> >
> > $\left\{E\left[X_n\right]\right\}$ 的单调性；结合乙盒总球数的变化，分析概率随抽取球数的变化趋势可判断 $\left\{p_n\right\}$ 的单调性·
>
> > [!note]- **【解析】**
> > 从甲盒中随机抽取 n 个球，这 n 个球中黑球的个数设为 Y，
> >
> > $P(Y = k) = \frac{C_a^k C_b^{n - k}}{C_{a + b}^n}\left(k = 0,1,2,\dots\right)$ $Y$ 服从超几何分布，且
> >
> > 乙盒中有 $^{1}$ 个球且为黑球，放入n个球后， $X_{n}=1+Y$ ，
> >
> > 因为 $E(Y) = n \cdot \frac{a}{a + b}$ ，所以 $E[X_n] = E(1 + Y) = 1 + E(Y) = 1 + n \cdot \frac{a}{a + b}$ ，
> >
> > 因为 $a > 0, a + b > 0$ ，所以当 $n$ 从1增加到 $a + b$ 时，
> >
> > $n \cdot \frac{a}{a+b}$ 随 n 的增大而增大，所以数列 $\left\{E\left[X_{n}\right]\right\}$ 严格增；
> >
> > 从乙盒中随机抽取 $^{1}$ 球为黑球的概率是 $p_{n}$ ，乙盒中此时有 $n+1$ 个球，黑球有 $X_{n}$ 个，
> >
> > 所以 $p_{n}=\frac{E\left[X_{n}\right]}{n+1}=\frac{1+n\cdot\frac{a}{a+b}}{n+1}=\frac{\frac{a}{a+b}\left(\frac{a+b}{a}+n\right)}{n+1}$
> >
> > $$
> > = \frac {a}{a + b} \frac {\left(n + 1 + \frac {b}{a}\right)}{n + 1} = \frac {a}{a + b} \left(1 + \frac {\frac {b}{a}}{n + 1}\right)
> > $$
> >
> > 因为 $a > 0, a + b > 0$ ，所以当 $n$ 从1增加到 $a + b$ 时，
> >
> > $\frac{\frac{b}{a}}{n+1}$ 单调递减，所以 $\left\{p_{n}\right\}$ 严格减·
> >
> > 故选：B.
> >
> > 8. 端午将至，超市特推出“粽情一夏，情浓端午”为主题的甲乙两款端午粽子礼盒，但是由于工作人员分装时的疏忽，礼盒内的粽子发生了错乱，此时甲款礼盒内已有一个肉粽，乙款礼盒内有三个肉粽和三个甜粽，现
> > 从乙款礼盒内随机取出 $\beta$ 个粽子，其中含 $\gamma$ 个肉粽，放入甲款礼盒后，再从甲款礼盒内随机取出一个粽子，
> > 记取到肉粽的个数为 $\alpha$ ，其中 $\alpha, \beta \in N^{*}$ ，下列说法正确的是（）
> > A. 当 $\beta = 2$ 时，随机变量 $\gamma$ 服从两点分布 B. 随着 $\beta$ 的增大， $E(\alpha)$ 减少， $D(\alpha)$ 增加
> > C. 当 $\beta = 2$ 时，随机变量 $\gamma$ 服从二项分布 D. 随着 $\beta$ 的增大， $E(\alpha)$ 增加， $D(\alpha)$ 减小
> >
> > 【答案】B
> >
> > 【分析】由题意可知，从乙礼盒里随机取出 $\beta$ 个粽子，含有肉粽个数 $\gamma$ 服从超几何分布，即 $\gamma \sim H(6,3,\beta)$
> >
> > 可得出 $E(\gamma) = \frac{\beta}{2}$ ，再从甲礼盒里随机取一粽子，则 $\alpha$ 服从两点分布，所以 $E(\alpha) = P(\alpha = 1) = \frac{1}{2} +\frac{1}{2\beta + 2}$
> >
> > $D(\alpha) = 1 - P(\alpha = 1) = \frac{1}{2} -\frac{1}{2\beta + 2}$ ，从而可判断出 $E(\alpha)$ 和 $D(\alpha)$ 的增减性·
> >
> > 【详解】由题意可知，从乙礼盒里随机取出 $\beta$ 个粽子，含有肉粽个数 $\gamma$ 服从超几何分布，即 $\gamma \sim H(6,3,\beta)$ .
> > 故 A, C 错误
> >
> > 其中 $P(\gamma=k)=\frac{C_{3}^{k}C_{3}^{\beta-k}}{C_{6}^{\beta}}$ ，其中 $k\in N,\quad k\leq3$ 且 $k\leq\beta$ ， $E(\gamma)=\frac{3\beta}{6}=\frac{\beta}{2}$ .
> >
> > 故从甲礼盒取粽子，相当于从含有 $\frac{\beta}{2} + 1$ 个肉粽的 $\beta + 1$ 个粽子中取 $^{1}$ 粽子，取到肉粽个数为 $\alpha$
> >
> > 故 $P(\alpha = 1) = \frac{\frac{\beta}{2} + 1}{\beta + 1} = \frac{1}{2} + \frac{1}{2\beta + 2}$
> >
> > 随机变量 服从两点分布，所以 $E(\alpha)=P\left(\alpha=1\right)=\frac{\frac{\beta}{2}+1}{\beta+1}=\frac{1}{2}+\frac{1}{2\beta+2}$
> >
> > 随着 $\beta$ 的增大， $E(\alpha)$ 减小；
> >
> > $D(\alpha)=\left[1-P(\alpha=1)\right]P(\alpha=1)=\frac{1}{4}-\frac{1}{(2\beta+2)^{2}}$ ，随着 $\beta$ 的增大， $D(\alpha)$ 增大。
> >
> > 故 $^{B}$ 正确， $^{D}$ 错误·
> >
> > 故选 **B**.
