## 三、填空题：本题共3小题，每小题5分，共15分。

12. 随机变量 $\xi$ 服从正态分布 $N(\mu, \sigma^2)$ ，若函数 $f(x) = P(x \leq \xi \leq x + 2)$ 为偶函数，则 $\mu =$ \_\_\_\_.

【答案】1

【分析】利用偶函数的定义，并结合正态曲线的对称性即可求解·

【详解】因为函数 $f(x)=P(x\leq\xi\leq x+2)$ 为偶函数，

所以 $f(-x) = f(x)$

即 $P\left(-x \leq \xi \leq -x + 2\right) = P\left(x \leq \xi \leq x + 2\right)$

所以 $\mu = \frac{-x + 2 + x}{2} = 1$

故答案为：1·
