> [!faq]- 《第七章_随机变量及其分布_高效培优单元自测_强化卷_数学人教A版高二选》官方解析
>
> > [!success]- **【答案】** A
>
> > [!note]- **【分析】**
> > 利用正态密度曲线的对称性可求得 $P(0 \leq X \leq 2)$ 的值.
>
> > [!note]- **【解析】**
> > 利用正态密度曲线的对称性可求得 $P(0 \leq X \leq 2)$ 的值
> >
> > 因为随机变量 $X \sim N(2, \sigma^{2})$ ，且 $P(X \leq 4) = 0.64$
> >
> > 则 $P(X < 0) = P(X > 4) = 1 - P(X \leq 4) = 1 - 0.64 = 0.36$
> >
> > 所以 $P(0 \leq X \leq 2) = P(X \leq 2) - P(X < 0) = 0.5 - 0.36 = 0.14$ .
> >
> > 故选：A.

> > 4. 语文老师想了解全班同学课外阅读中国古典四大名著的情况，经调查，全班同学中阅读过《红楼梦》的占 $80\%$ ，阅读过《三国演义》的占 $60\%$ ，阅读过《红楼梦》或《三国演义》的占 $95\%$ ，现从阅读过《三国演义》的同学中随机抽取一位同学，该同学阅读过《红楼梦》的概率为（）A.0.8 B.0.6 C.0.45 D.0.75
> >
> > 【答案】D
> >
> > 【分析】设出相关事件，根据和事件的概率公式求出 $P(A \cap B) = 0.45$ ，再根据条件概率公式，即可求得答案：
> >
> > 【详解】设事件 A：阅读过《红楼梦》；事件 B：阅读过《三国演义》，则 $P(A)=0.8, P(B)=0.6$ ，则 $P(A\cup B)=0.95$ ，
> > 而 $P(A\cup B)=P(A)+P(B)-P(A\cap B)$ ，即 $0.95=0.8+0.6-P(A\cap B)$ ，故 $P(A\cap B)=0.45$ ，
> > 故 $P(A|B)=\frac{P(A\cap B)}{P(B)}=\frac{0.45}{0.6}=0.75$
> >
> > 即现从阅读过《三国演义》的同学中随机抽取一位同学，该同学阅读过《红楼梦》的概率为 0.75
> >
> > 故选：D
> >
> > 5. 第七届数字中国建设峰会数字福建建设成果摄影展向社会进行作品征集，该摄影展从全新的视角呈现
> > 了数字福建近年来的建设成果，展现了数字福建蓬勃发展的朝气．某企业计划从信息基础设施领域的a幅作品和文化领域的 $^{7}$ 幅作品中随机选取若干幅作品参赛，若选取 $^{2}$ 幅作品，全是文化领域的概率为 $^{\frac{7}{15}}$ 。若
> > 选取 $^{3}$ 幅作品，假设选取的文化领域的作品个数为X，则 $E(X)=$ （）A. $\frac{21}{10}$ B. $\frac{11}{5}$ C.2 D.3
> >
> > 【答案】A
> >
> > 【分析】解法 $^{1}$ ：利用超几何分布求得分布列，得到数学期望；解法 $^{2}$ ：利用超几何分布的数学期望公式求
> >
> > 解即可·
> >
> > 【详解】解法 $^{1}$ ：由题意，共有 $a+7$ 幅作品，选取 $^{2}$ 幅作品有 $C_{a+7}^{2}$ 种方法，
> >
> > 其中全是文化领域的有 $C_{7}^{2}$ 种方法，因此全是文化领域的概率为 $\frac{C_{7}^{2}}{C_{a+7}^{2}}=\frac{7}{15}$ ，从而解得a=3。
> >
> > $X$ 的可能取值为 $0, 1, 2, 3$ ，则 $P(X = 0) = \frac{C_7^0 C_3^3}{C_{10}^3} = \frac{1}{120}$ ， $P(X = 1) = \frac{C_7^1 C_3^2}{C_{10}^3} = \frac{21}{120} = \frac{7}{40}$ ， $P(X = 2) = \frac{C_7^2 C_3^1}{C_{10}^3} = \frac{63}{120} = \frac{21}{40}$ ， $P(X = 3) = \frac{C_7^3 C_3^0}{C_{10}^3} = \frac{35}{120} = \frac{7}{24}$ ，
> >
> > 则随机变量 $X$ 的分布列为：
> >
> > <table><tr><td>X</td><td>0</td><td>1</td><td>2</td><td>3</td></tr><tr><td>P</td><td> $\frac{1}{120}$ </td><td> $\frac{7}{40}$ </td><td> $\frac{21}{40}$ </td><td> $\frac{7}{24}$ </td></tr></table>
> >
> > 则 $E(X) = 0 \times \frac{1}{120} + 1 \times \frac{7}{40} + 2 \times \frac{21}{40} + 3 \times \frac{7}{24} = \frac{21}{10}$
> >
> > 解法 $^{2}$ ：同法 $^{1}$ ，求得a=3后可用下列方法求解。
> >
> > 由题意可知 $X$ 服从参数为 $N = 10$ ， $M = 7$ ， $n = 3$ 的超几何分布，则 $E(X) = \frac{3\times 7}{10} = \frac{21}{10}$
> >
> > 故选：A.

> > 6. 盒中有 $^{10}$ 个玩具，其中有 $^{3}$ 个是坏的，先从盒中随机地抽取 $^{4}$ 个，则下列事件概率是 $^{6}$ 的是（）
> > A．恰有 $^{1}$ 个是坏的
> > B． $^{4}$ 个全是好的
> > C．恰有 $^{2}$ 个是坏的
> > D．至多有 $^{2}$ 个是坏的
> >
> > 【答案】B
> >
> > 【分析】应用超几何分布的概率公式计算各个选项即可·
> >
> > 【详解】盒中有 $^{10}$ 个玩具，其中 $^{3}$ 个坏的， $^{7}$ 个好的·抽取 $^{4}$ 个玩具，计算各选项概率如下：
> >
> > 选项 A（恰有 1 个坏的）： $P(A)=\frac{C_{3}^{1}\cdot C_{7}^{3}}{C_{10}^{4}}=\frac{3\times35}{210}=\frac{105}{210}=\frac{1}{2}$
> >
> > 选项 B（4个全是好的）： $P(B)=\frac{C_{3}^{0}\cdot C_{7}^{4}}{C_{10}^{4}}=\frac{1\times35}{210}=\frac{35}{210}=\frac{1}{6}$
> >
> > 选项 C（恰有 $^{2}$ 个坏的）： $P(C)=\frac{C_{3}^{2}\cdot C_{7}^{2}}{C_{10}^{4}}=\frac{3\times21}{210}=\frac{63}{210}=\frac{3}{10}$
> >
> > 选项D（至多2个坏的）： $P(D)=1-\frac{C_{3}^{3}\cdot C_{7}^{1}}{C_{10}^{4}}=1-\frac{1\times7}{210}=1-\frac{1}{30}=\frac{29}{30}$
> >
> > 综上，只有选项 $^{B}$ 的概率为 $\frac{1}{6}$ ，
> >
> > 故选 **B**.
