> [!faq]- 《专题7.2 离散型随机变量及其分布（高效培优讲义）数学人教A版高二选择性必修第三册》官方解析
>
> > [!success]- **【答案】** B
>
> > [!note]- **【分析】**
> > 根据分布列概率和为 1 求得 a, 再根据互斥事件的概率和公式计算即可.
>
> > [!note]- **【解析】**
> > 根据分布列概率和为1，可得 $0.2 + 0.1 + a + 0.3 + 0.2 + 0.1 = 1, a = 0.1$ ， $P(1 \leq X \leq 3) = P(X = 1) + P(X = 2) + P(X = 3) = 0.1 + 0.1 + 0.3 = 0.5$
> >
> > 故选 **B**.
