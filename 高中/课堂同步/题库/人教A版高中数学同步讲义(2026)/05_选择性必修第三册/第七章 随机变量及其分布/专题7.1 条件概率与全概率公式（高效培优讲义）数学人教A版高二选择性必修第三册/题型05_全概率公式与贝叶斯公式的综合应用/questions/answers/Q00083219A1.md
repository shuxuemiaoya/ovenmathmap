> [!faq]- 《专题7.1 条件概率与全概率公式（高效培优讲义）数学人教A版高二选择性必修第三册》官方解析
>
> > [!success]- **【答案】** AC
>
> > [!note]- **【分析】**
> > 设该生活用品由 A 机器生产为事件 A，该生活用品由 B 机器生产为事件 B，该生活用品为合格品为
> >
> > 事件 $C$ ，得到 $P(A) = 0.75, P(B) = 0.25, P(C \mid A) = 0.98, P(C \mid B) = 0.988$ ，且 $P(\overline{C} \mid A) = 0.02, P(\overline{C} \mid B) = 0.012$ ，结
> >
> > 合全概率公式阿赫条件概率的计算公式，逐项求解，即可得到答案.
>
> > [!note]- **【解析】**
> > 设该生活用品由 A 机器生产为事件 A，该生活用品由 B 机器生产为事件 B，
> >
> > 该生活用品为合格品为事件 C，
> >
> > $$
> > \text { 可得 } P (A) = 0. 7 5, P (B) = 0. 2 5, P (C \mid A) = 0. 9 8, P (C \mid B) = 0. 9 8 8
> > $$
> >
> > 则 $P(\overline{C} \mid A) = 0.02, P(\overline{C} \mid B) = 0.012$
> >
> > 对于 A 中，由 $P(C)=P(A)P(C|A)+P(B)P(C|B=0.75\times0.98+0.25\times0.988=0.982$ ，所以 A 正确；
> >
> > 对于 B 中，由 $P(\overline{C})=1-P(C)=1-0.982=0.018$ ，所以 B 错误；
> >
> > 对于 C 中， $P(A \mid \overline{C}) = \frac{P(A\overline{C})}{P(\overline{C})} = \frac{0.75 \times 0.02}{0.018} = \frac{5}{6}$ ，所以 C 正确；
> >
> > 对于 D 中， $P(B \mid \overline{C}) = 1 - P(A \mid \overline{C}) = \frac{1}{6}$ ，所以 D 错误.
> >
> > 故选 **AC**.
