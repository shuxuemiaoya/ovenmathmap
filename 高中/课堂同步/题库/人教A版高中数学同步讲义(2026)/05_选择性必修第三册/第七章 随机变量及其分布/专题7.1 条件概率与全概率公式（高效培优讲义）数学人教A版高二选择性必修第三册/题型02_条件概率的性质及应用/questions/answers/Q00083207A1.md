> [!faq]- 《专题7.1 条件概率与全概率公式（高效培优讲义）数学人教A版高二选择性必修第三册》官方解析
>
> > [!success]- **【答案】** C
>
> > [!note]- **【分析】**
> > 本题可根据条件概率公式 $P\left(\overline{B} \mid A\right) = \frac{P(A\overline{B})}{P(A)}$ 以及 $P(AB) = P(A) - P(A\overline{B})$ ，再结合独立事件的判定条
> >
> > 件来逐一分析选项.
>
> > [!note]- **【解析】**
> > 对于选项 A，因为 $P(B)=\frac{1}{2}$ ，所以根据对立事件概率公式可得 $P(\overline{B})=1-P(B)=\frac{1}{2}$ 。又 $P(\overline{B}|A)=\frac{1}{3}$ ，
> > 所以 $P(\overline{B}|A) \neq P(\overline{B})$ . 因此事件 A 与事件 $\overline{B}$ 不独立，选项 A 错误.
> >
> > 对于选项B，根据条件概率公式 $P\left(\overline{B}\mid A\right) = \frac{P(A\overline{B})}{P(A)}$ ，已知 $P(A) = \frac{1}{3}$ ， $P\left(\overline{B}\mid A\right) = \frac{1}{3}$ ，将其代入公式可得，
> >
> > $P(A\overline{B})=P(\overline{B}|A)\times P(A)=\frac{1}{3}\times\frac{1}{3}=\frac{1}{9}$ ，选项 B 错误.
> >
> > 对于选项C，因为 $A = AB\cup A\overline{B}$ ，且 $AB$ 与 $A\overline{B}$ 互斥，所以 $P(A) = P(AB) + P(A\overline{B})$ .由选项B可知 $P(A\overline{B}) = \frac{1}{9}$
> >
> > 又 $P(A)=\frac{1}{3}$ ，则 $P(AB)=P(A)-P(A\overline{B})=\frac{1}{3}-\frac{1}{9}=\frac{2}{9}$ ，选项 C 正确.
> >
> > 对于选项D，已知 $P(A) = \frac{1}{3}$ ，根据对立事件概率公式可得 $P(\overline{A}) = 1 - P(A) = 1 - \frac{1}{3} = \frac{2}{3}$ .由选项B可知
> >
> > $P(A\overline{B})=\frac{1}{9}$ ，所以 $P(A\overline{B})\neq P(\overline{A})$ ，选项D错误.
> >
> > 故选：C.
> >
> > ## 方法技巧
> >
> > 当所求事件的概率相对较复杂时，往往把该事件分成两个(或多个)互不相容的较简单的事件之和，求出这些
> >
> > 简单事件的概率，再利用 $P((B_{\cup}C)|A) = P(B|A) + P(C|A)$ 便可求得较复杂事件的概率。
