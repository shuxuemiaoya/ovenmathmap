> [!faq]- 《专题03_离散型随机变量数字特征五大常考题型_高效培优专项训练_数学人》官方解析
>
> > [!success]- **【答案】** 8
>
> > [!note]- **【分析】**
> > 根据题意可得 $\left\{ \begin{array}{l}0.1 + m + 0.2 + n = 1\\ n - m = 0.2 \end{array} \right.$ ，即可求得 $m,n$ 的值，进而结合期望公式可求得 $E(X)$ ，进而得到 $E(3X + 2)$
>
> > [!note]- **【解析】**
> > 由题意，得 $\left\{ \begin{array}{l}0.1 + m + 0.2 + n = 1\\ n - m = 0.2 \end{array} \right.$ ，解得 $m = 0.25,n = 0.45$
> >
> > 所以 $E(X)=0\times0.1+1\times0.25+2\times0.2+3\times0.45=2$
> >
> > 所以 $E(3X+2)=3E(X)+2=3\times2+2=8$ .
> >
> > 故答案为：8.

> > 13. 端午节是中国四大传统节日之一，风俗习惯形式多样，内容丰富多彩。某居民小区为了让业主度过愉快的端午节，业委会组织举办了一场现场抽奖游戏，规则如下：袋中共有 $^{10}$ 张质地均匀的卡片，其中5张卡片图案是粽子，另外5张卡片图案是龙舟，业主从该袋子中不放回地随机抽取5张卡片，如果5张卡片图案相同，则获得100元的购物卡；如果5张卡片中有4张图案相同，则获得50元购物卡；其他情况，则不获得任何奖励。设 $X$ 是业主在一次抽奖活动中获得的购物卡金额，则 $E\left(\frac{1}{3}X+2\right)=$ \_\_\_\_。
> >
> > 【答案】 $\frac{39}{7}$
> >
> > 【分析】由条件确定 X 的可能取值，再求其取各值的概率，由期望公式求 $E(X)$ ，再根据期望性质求结论
> > 【详解】依题意，X 的可能取值是 0,50,100
> >
> > 则 $P(X = 0) = \frac{2C_5^3C_5^2}{C_{10}^5} = \frac{50}{63}$ ， $P(X = 50) = \frac{2C_5^4C_5^1}{C_{10}^5} = \frac{25}{126}$ ， $P(X = 100) = \frac{2C_5^5C_5^0}{C_{10}^5} = \frac{1}{126}$ 故 $E(X) = 0 \times \frac{50}{63} + 50 \times \frac{25}{126} + 100 \times \frac{1}{126} = \frac{75}{7}$ 故 $E\left(\frac{1}{3}X + 2\right) = \frac{1}{3}E(X) + 2 = \frac{39}{7}$ .
> >
> > 故答案为： $\frac{39}{7}$
