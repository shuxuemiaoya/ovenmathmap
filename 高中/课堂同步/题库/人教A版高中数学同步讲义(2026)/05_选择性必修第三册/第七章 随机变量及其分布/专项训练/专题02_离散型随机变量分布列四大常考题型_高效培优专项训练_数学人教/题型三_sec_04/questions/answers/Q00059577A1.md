> > 26. 公园的某个位置摆放了 $^{10}$ 盆牡丹花，编号分别为 0, 1, 2, 3, …, 9，若从中任取 $^{1}$ 盆，则编号“大于5”的概率是（）
> >
> > A. $\frac{1}{2}$ B. $\frac{2}{5}$ C. $\frac{3}{5}$ D. $\frac{1}{10}$
> >
> > 【答案】B
> >
> > 【分析】设编号为随机变量 X，结合题设可得其各可能值的对应概率，再应用互斥事件概率的加法公式求 $P(X > 5)$ 即可.
> >
> > 【详解】设任取 $^{1}$ 盆的编号为随机变量X
> >
> > 则 X 的可能取值为 $0, 1, 2, \ldots, 9$ ,
> >
> > $$
> > P (X = 0) = P (X = 1) = P (X = 2) = \dots = P (X = 9) = \frac {1}{1 0}
> > $$
> >
> > $$
> > \therefore P (X > 5) = P (X = 6) + P (X = 7) + P (X = 8) + P (X = 9) = \frac {4}{1 0} = \frac {2}{5}
> > $$
> >
> > 故选 **B**.
