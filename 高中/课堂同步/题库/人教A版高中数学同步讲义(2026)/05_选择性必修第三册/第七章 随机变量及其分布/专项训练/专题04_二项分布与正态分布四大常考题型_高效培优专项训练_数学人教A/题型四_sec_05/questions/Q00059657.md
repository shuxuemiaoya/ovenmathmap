39. 某数学研究小组对一家商铺进行了研究分析，发现每日客流量 $X$ 服从正态分布，其密度函数峰值为 $\frac{1}{15\sqrt{2\pi}}$ ，均值为 $100$ ，且商铺规定消费一次可以获得不同数量的积分：获得 $^{1}$ 分的概率为 $\frac{1}{2}$ ，获得 $^{2}$ 分的概率为 $\frac{3}{10}$ ，获得 $^{3}$ 分的概率为 $\frac{1}{5}$ ·每次消费获取积分相互独立·

(1)求 $P(55<X<70)$ ;

(2)记某顾客消费两次累计获得的积分为 $Z$ ，求 $Z$ 的分布列与期望

附：正态密度函数 $f(x) = \frac{1}{\sigma\sqrt{2\pi}}\mathrm{e}^{-\frac{(x - \mu)^2}{2\sigma^2}}$ ，其中 $\mu$ 为均值， $\sigma$ 为标准差· $P(\mu -\sigma < X <   \mu +\sigma) = 0.6827$ ， $P(\mu -2\sigma < X <   \mu +2\sigma) = 0.9545$ ， $P(\mu -3\sigma < X <   \mu +3\sigma) = 0.9973.$
