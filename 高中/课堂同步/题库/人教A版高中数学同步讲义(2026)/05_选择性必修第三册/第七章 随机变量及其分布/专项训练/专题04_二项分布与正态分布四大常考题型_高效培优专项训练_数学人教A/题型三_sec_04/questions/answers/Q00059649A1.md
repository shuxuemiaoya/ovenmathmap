> > [!success]- **【答案】** A
>
> > [!note]- **【分析】**
> > 利用正态分布的性质，结合区间概率，即可求解
>
> > [!note]- **【解析】**
> > 学生的抽测成绩 X 服从正态分布 $N(90,10^{2})$ ，
> > 则 $P(100 \leq X \leq 110) = \frac{1}{2} [P(70 \leq X \leq 110) - P(80 \leq X \leq 100)]$ $=\frac{1}{2}\times(0.9545-0.6827)=0.1359$ 由于总人数为 $^{30000}$ ，则抽测成绩在 $[100,110]$ 内的学生人数大约为 $30000\times0.1359=4077$ ，故选：A.

> > 25. 近年来，巫溪县大力发展生态农业，蒲莲蜜柚因其形大、汁多、味甜深受消费者追捧．已知某批次蜜柚的重量（单位：克） $X \sim N(1500, 200^{2})$ ， $P(|X - 1500| \leq 200) = m$ ，规定重量不小于1300克的蜜柚为合格品，重量在1500克到1700克之间的蜜柚为优等品．现从该批次蜜柚中随机抽取一个，下列说法正确的有（）
> >
> > A．该蜜柚是优等品的概率为 $\frac{m}{2}$ B．该蜜柚是合格品的概率为 $\frac{m + 1}{2}$ C．若该蜜柚重量大于1500克，则其为优等品的概率为m
> >
> > D．若该蜜柚是合格品，则其重量不小于1500克的概率为 $\frac{1}{2m + 1}$
> >
> > 【答案】ABC
> > 【分析】根据正态分布的概念，判断分布曲线的对称轴和方差，根据正态分布的对称性，以及条件概率公
> >
> > 式，逐一判断各选项正误·
> >
> > 【详解】由题意 $X \sim N(1500, 200^2)$ ，则随机变量 $X$ 服从正态分布，对称轴为 $X = 1500$ ， $\sigma^2 = 200^2$
> >
> > 因为 $P\left(\left|X - 1500\right|\leq 200\right) = m$ ，即 $P\left(1300\leq X\leq 1700\right) = m$
> >
> > 所以 $P(1300 \leq X \leq 1500) = P(1500 \leq X \leq 1700) = \frac{m}{2}$ ，A 正确；
> >
> > 由 $P(1300 \leq X \leq 1700) = m$ ，可知 $P(X < 1300) = P(X > 1700) = \frac{1 - m}{2}$ ，
> >
> > 所以 $P(X \quad 1300) = 1 - \frac{1 - m}{2} = \frac{1 + m}{2}$ ，B 正确；
> >
> > 由正态分布曲线的对称轴为 X=1500，所以 $P(X>1500)=\frac{1}{2}$ ， $P(1500\leq X\leq1700)=\frac{m}{2}$ ，
> >
> > 设事件 $A$ 为蜜柚重量大于 $1500$ 克，则 $P(A) = \frac{1}{2}$ ，事件 $B$ 为蜜柚为优等品，则 $P(AB) = \frac{m}{2}$
> >
> > 由条件概率可知蜜柚重量大于 $1500$ 克，则其为优等品的概率为 $P(B|A) = \frac{P(AB)}{P(A)} = \frac{\frac{m}{2}}{\frac{1}{2}} = m$ ，C正确；
> >
> > 蜜柚是合格品的概率为 $P(X - 1300) = \frac{1 + m}{2}$ ，重量不小于 $^{1500}$ 克的概率为 $P(X - 1500) = \frac{1}{2}$
> >
> > 设事件 $C$ 为蜜柚是合格品，则 $P(C) = \frac{1 + m}{2}$ ，设事件 $D$ 为蜜柚重量不小于 $^{1500}$ 克，则 $P(CD) = \frac{1}{2}$
> >
> > 由条件概率可知蜜柚是合格品，则其重量不小于 $1500$ 克的概率为 $P(D|C) = \frac{P(CD)}{P(C)} = \frac{\frac{1}{2}}{\frac{1 + m}{2}} = \frac{1}{1 + m}$ ，D错
> >
> > 误；
> >
> > 故选 **ABC**
