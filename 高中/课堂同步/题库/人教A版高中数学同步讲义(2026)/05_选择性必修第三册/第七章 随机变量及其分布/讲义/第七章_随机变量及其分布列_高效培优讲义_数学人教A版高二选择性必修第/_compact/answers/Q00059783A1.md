> [!faq]- 《第七章_随机变量及其分布列_高效培优讲义_数学人教A版高二选择性必修第》官方解析
>
> > [!success]- **【答案】** C
>
> > [!note]- **【分析】**
> > 根据两点分布的性质可得 $P(X = 0) + P(X = 1) = 1$ ，结合题意求得 $P(X = 1)$ ，再根据两点分布的期望公式即可得解·
>
> > [!note]- **【解析】**
> > 解：因为随机变量 $X$ 的分布列服从两点分布，所以 $P(X = 0) + P(X = 1) = 1$ ，则 $P(X = 1) + \frac{2}{9P(X = 1)} = 1$ ，解得 $P(X = 1) = \frac{1}{3}$ 或 $\frac{2}{3}$ 又因 $P(X = 0) < P(X = 1)$ 所以 $P(X = 1) = \frac{2}{3}$ ，则 $P(X = 0) = \frac{1}{3}$ 所以 $E(X) = \frac{2}{3}$
> >
> > 故选 **C**.
