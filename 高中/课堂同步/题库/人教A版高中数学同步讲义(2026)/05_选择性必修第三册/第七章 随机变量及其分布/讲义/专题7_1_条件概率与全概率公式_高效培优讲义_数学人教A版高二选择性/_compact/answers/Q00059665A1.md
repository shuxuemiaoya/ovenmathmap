> [!faq]- 《专题7_1_条件概率与全概率公式_高效培优讲义_数学人教A版高二选择性》官方解析
>
> > [!success]- **【答案】** BC
>
> > [!note]- **【分析】**
> > 根据独立事件的定义及条件概率的性质可判断各选项正误.
>
> > [!note]- **【解析】**
> > 对于 A，考虑投掷两个骰子，记事件 A：第一个骰子的点数为奇数，
> >
> > 事件 B ：第二个骰子点数为奇数，事件 C ：两个骰子的点数之和为奇数，
> >
> > 于是有 $P(A) = P(B) = P(C) = \frac{1}{2}$ ， $P(AB) = P(BC) = P(AC) = \frac{1}{4}$ ，
> >
> > $P(ABC)=0$ ，可以看出事件 A, B, C 两两独立，但 A, B, C 不互相独立，
> >
> > 所以 $P(ABC) \neq P(A)P(B)P(C)$ ，A 错误；
> >
> > 对于 B， $P(D)=1-P(\bar{D}|C)=P(D|C)=\frac{P(CD)}{P(C)}$ ，即 $P(CD)=P(C)P(D)$ ，所以 C, D 相互独立，B 正确；
> >
> > 对于 C，由 $P(A)=0.5$ ， $P(B)=0.6$ ，则 $P(\bar{A})=1-0.5=0.5$ ， $P(\bar{B})=1-0.6=0.4$ ，
> >
> > $P(A \cup \overline{B}) = P(A) + P(\overline{B}) - P(A\overline{B}) = 0.5$ ，则 $P(A\overline{B}) = 0.4$
> >
> > 又 $P(A) = P(AB) + P(A\overline{B}) = 0.5$ ，则 $P(AB) = 0.1$
> >
> > $P(\overline{A} B) = P(B) - P(AB) = 0.6 - 0.1 = 0.5$ ，则 $P(A\overline{B}\cup \overline{A} B) = P(A\overline{B}) + P(\overline{A} B) = 0.4 + 0.5 = 0.9$ ，C正确；
> >
> > 对于 D，当 A, B 互斥时， $P(A \cup B|C) = P(A|C) + P(B|C)$ ;
> >
> > 当 A、B 不互斥时， $P(A \cup B|C) < P(A|C) + P(B|C)$ ，D 错误.
> >
> > 故选 **BC**.
