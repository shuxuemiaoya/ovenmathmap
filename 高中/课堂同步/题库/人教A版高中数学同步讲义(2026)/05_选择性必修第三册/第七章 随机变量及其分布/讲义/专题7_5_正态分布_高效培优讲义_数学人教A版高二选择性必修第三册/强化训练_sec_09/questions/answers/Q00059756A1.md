> [!faq]- 《专题7_5_正态分布_高效培优讲义_数学人教A版高二选择性必修第三册》官方解析
>
> > [!success]- **【答案】** AB
>
> > [!note]- **【分析】**
> > 利用插空法和乘法计数原理即可判断 $^{A}$ ；先根据 $\xi\sim N(29,4)$ 得到 $\mu=29,\sigma=2$ ，进而结合正态密度
> >
> > 曲线的对称性即可判断 $^{B}$ ；结合均匀分组问题的处理方法即可判断 $^{C}$ ；利用赋值法求 $\left(\sqrt{x}-\frac{2\sqrt{y}}{x}\right)^{5}$ 展开式中的
> >
> > 各项系数之和，判断 D.
>
> > [!note]- **【解析】**
> > 对于 $^{A}$ ，利用插空法，将5名男生排成一列，其排列方式有 $A_{5}^{5}$ 种，
> >
> > 将3名女生插入男生排列的两端或男生与男生之间的位置，则有 $\mathrm{A}_6^3$ 种排列方式，
> >
> > 则由乘法计数原理可知一共有 $\mathrm{A}_5^5\cdot \mathrm{A}_6^3$ 种排法，故 $\mathsf{A}$ 正确；
> >
> > 对于 $^{B}$ ，由 $\xi\sim N(29,4)$ 得 $\mu=29,\sigma=2$
> >
> > 则 $P(24 \leq \xi \leq 29) = P(29 \leq \xi \leq 34)$ ，又 $P(\xi - 29) = \frac{1}{2}$ ，
> >
> > 所以 $P(24 \leq \xi \leq 29) + P(\xi - 34) = P(\xi - 29) = \frac{1}{2}$ ，故 B 正确；
> >
> > 对于 C，6 名学生平均分成 3 组，不同的分法有 $\frac{C_{6}^{2}C_{4}^{2}C_{2}^{2}}{A_{3}^{3}}$ ，故 C 错误；
> >
> > 对于 D，将 $\left(\sqrt{x}-\frac{2\sqrt{y}}{x}\right)^{5}$ 中的 x 取 1，y 取 1 可得其展开式中的各项系数之和，
> >
> > 所以 $\left(\sqrt{x} -\frac{2\sqrt{y}}{x}\right)^{5}$ 展开式中的各项系数之和 $\left(\sqrt{1} -\frac{2\sqrt{1}}{1}\right)^{5} = -1$ ，故D错误·
> >
> > 故选 **AB**.
