> [!faq]- 《专题03 离散型随机变量数字特征五大常考题型（高效培优专项训练）数学人教A版高二选择性必修第三册》官方解析
>
> > [!success]- **【答案】** $\frac{1}{10}$
>
> > [!note]- **【分析】**
> > 根据概率和为 $^{1}$ 和均值的定义列出关于a,b的方程组，解出即可·
>
> > [!note]- **【解析】**
> > 因为 $P(X=k)=ak+b(k=1,2,3,4)$
> >
> > 所以 $a + b + 2a + b + 3a + b + 4a + b = 10a + 4b = 1$
> >
> > 又因为 $E(X) = 3$
> >
> > 所以 $(a + b) + 2(2a + b) + 3(3a + b) + 4(4a + b) = 30a + 10b = 3$
> >
> > 解得 $a=\frac{1}{10}$ ，b=0，所以 $a+b=\frac{1}{10}$ ，
> >
> > 故答案为： $\frac{1}{10}$
