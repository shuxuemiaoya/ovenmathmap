> [!faq]- 《专题03 离散型随机变量数字特征五大常考题型（高效培优专项训练）数学人教A版高二选择性必修第三册》官方解析
>
> > [!success]- **【答案】** $\frac{1}{6}$ $\frac{1}{3}$
>
> > [!note]- **【分析】**
> > 根据分布列的性质以及期望公式即可求出 $a, b$ 的值·
>
> > [!note]- **【解析】**
> > 由 $P(\xi = x) = ax + b(x = -1, 0, 1)$ ，可得 $P(\xi = -1) = b - a$ ， $P(\xi = 0) = b$ ， $P(\xi = 1) = b + a$ ，所以 $b - a + b + a + b = 3b = 1$ ，则 $b = \frac{1}{3}$ ，又 $E(\xi) = -1 \times (b - a) + 0 \times b + 1 \times (a + b) = 2a = \frac{1}{3}$ ，则 $a = \frac{1}{6}$ 。故答案为： $\frac{1}{6}$ ； $\frac{1}{3}$ 。
