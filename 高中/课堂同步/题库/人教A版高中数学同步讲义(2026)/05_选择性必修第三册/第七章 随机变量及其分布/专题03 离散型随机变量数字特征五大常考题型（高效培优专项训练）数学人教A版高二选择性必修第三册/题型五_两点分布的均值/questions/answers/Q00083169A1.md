> [!faq]- 《专题03 离散型随机变量数字特征五大常考题型（高效培优专项训练）数学人教A版高二选择性必修第三册》官方解析
>
> > [!success]- **【答案】** $\frac{9}{10} / 0.9$
>
> > [!note]- **【分析】**
> > 根据题意，利用分布列的性质，求得 $P(X = 1) = \frac{9}{10}, P(X = 0) = \frac{1}{10}$ ，结合期望的计算公式，即可求解·
>
> > [!note]- **【解析】**
> > 设模拟手术失败的概率为 $x$ ，即 $P(X = 0) = x$ ，则成功的概率为 $P(X = 1) = 9x$
> >
> > 因为 $P(X = 1) + P(X = 0) = 1$ ，解得 $P(X = 1) = \frac{9}{10}, P(X = 0) = \frac{1}{10}$
> >
> > 则 $E(X) = 1 \times \frac{9}{10} + 0 \times \frac{1}{10} = \frac{9}{10}$
> >
> > 故答案为： $\frac{9}{10}$
