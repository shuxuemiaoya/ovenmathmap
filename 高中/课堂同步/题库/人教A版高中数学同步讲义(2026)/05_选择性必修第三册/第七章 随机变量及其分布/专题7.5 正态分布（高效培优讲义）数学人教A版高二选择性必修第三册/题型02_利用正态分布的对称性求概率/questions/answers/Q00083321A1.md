> [!faq]- 《专题7.5 正态分布（高效培优讲义）数学人教A版高二选择性必修第三册》官方解析
>
> > [!success]- **【答案】** B
>
> > [!note]- **【分析】**
> > 先根据正态分布的性质确定a的值，再利用基本不等式求最小值·
>
> > [!note]- **【解析】**
> > 因为 $\xi\sim N(1,\sigma^{2})$ ，且 $P(\xi\leq-1)=P(\xi\quad a)$
> >
> > 因为 $P(\xi \leq 1 - 2) = P(\xi \quad 1 + 2)$ ，所以 a = 3。
> >
> > 所以 $\frac{1}{x} +\frac{9}{3 - x} = \frac{1}{3}\left[x + (3 - x)\right]\left(\frac{1}{x} +\frac{9}{3 - x}\right) = \frac{1}{3}\left[10 + \frac{9x}{3 - x} +\frac{3 - x}{x}\right]$
> >
> > 因为 0 < x < 3，所以 $\frac{1}{3}\left[10 + \frac{9x}{3 - x} + \frac{3 - x}{x}\right]$ $\frac{1}{3}\left[10 + 2\sqrt{\frac{9x}{3 - x} \cdot \frac{3 - x}{x}}\right] = \frac{16}{3}$ ，当且仅当 $\frac{9x}{3 - x} = \frac{3 - x}{x}$ ，即 $x = \frac{3}{4}$ 时取等号·故选： $^{B}$ .
