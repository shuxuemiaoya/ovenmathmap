> [!faq]- 《专题7.5 正态分布（高效培优讲义）数学人教A版高二选择性必修第三册》官方解析
>
> > [!success]- **【答案】** BC
>
> > [!note]- **【分析】**
> > 根据给定条件，利用正态分布的性质逐项分析计算判断·
>
> > [!note]- **【解析】**
> > 对于 A，由 $X \sim N(70,100)$ ，得 $E(X) = 70$ ，则 $E(2X - 10) = 2E(X) - 10 = 130$ ，A 错误；
> >
> > 对于 B，由 $Y \sim N(74,64)$ ，得 $\sigma = \sqrt{64} = 8$ ，B 正确；
> >
> > 对于 C，由 $X \sim N(70,100)$ ，则 $P(60 < X \leq 80) = P(\mu - \sigma < X \leq \mu + \sigma) = 0.6827$
> >
> > $300 \times 0.6827 = 204.81 \approx 205$ ，C 正确；
> >
> > 对于D， $P(X\quad 90) = P(X\quad 70 + 2\times 10) = P(Y\quad 74 + 2\times 8) = P(Y\quad 90)$
> >
> > 但男生和女生总数不一样，因此及格人数也不一样， $^{D}$ 错误·
> >
> > 故选 **BC**
