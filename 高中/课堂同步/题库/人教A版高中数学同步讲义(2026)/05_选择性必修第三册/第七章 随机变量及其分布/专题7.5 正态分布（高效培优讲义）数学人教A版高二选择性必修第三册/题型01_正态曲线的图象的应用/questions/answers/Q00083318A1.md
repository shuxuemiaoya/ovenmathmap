> [!faq]- 《专题7.5 正态分布（高效培优讲义）数学人教A版高二选择性必修第三册》官方解析
>
> > [!success]- **【答案】** A
>
> > [!note]- **【分析】**
> > 利用正态分布的曲线及性质求解·由 $x$ 服从正态分布 $N(4, \sigma^2)$ 得到 $x = 4$ 为正态曲线的对称轴且 $P(x \leq 4) = 0.5$ ，由 $P(x \leq 6)$ 的值求出 $P(4 < x \leq 6)$ 的值，利用对称性得到 $P(4 < x \leq 6) = P(2 < x \leq 4)$ ，从而得到 $P(2 < x \leq 6) = P(4 < x \leq 6) + P(2 < x \leq 4) = 2P(4 < x \leq 6)$ .
>
> > [!note]- **【解析】**
> > ∵ x 服从正态分布 $N(4, \sigma^{2})$ ，∴ x = 4 为正态曲线的对称轴，∴ $P(x \leq 4) = 0.5$ ，
> > ∵ $P(x \leq 6) = 0.86$ ，∴ $P(4 < x \leq 6) = 0.86 - 0.5 = 0.36$
> >
> > ∵ x = 4
> > 为正态曲线的对称轴，
> > ∴ $P(4 < x \leq 6) = P(2 < x \leq 4)$ ， $P(2 < x \leq 6) = P(4 < x \leq 6) + P(2 < x \leq 4) = 2P(4 < x \leq 6) = 2 \times 0.36 = 0.72$
> >
> > 故选 **A**.
