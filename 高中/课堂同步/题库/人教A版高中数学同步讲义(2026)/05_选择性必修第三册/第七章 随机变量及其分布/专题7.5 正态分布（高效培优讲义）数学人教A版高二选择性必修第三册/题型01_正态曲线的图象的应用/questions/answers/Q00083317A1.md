> [!faq]- 《专题7.5 正态分布（高效培优讲义）数学人教A版高二选择性必修第三册》官方解析
>
> > [!success]- **【答案】** AB
>
> > [!note]- **【分析】**
> > 应用正态分布的对称性及数学期望计算分别判断各个选项·
>
> > [!note]- **【解析】**
> > 由正态分布的定义知 $E(X) = 3$ ，A正确；
> >
> > 由 $P(X \leq 3) = P(X - 3) = 1 - P(X \leq 3)$ ，得 $P(X \leq 3) = 0.5$ ，B 正确；
> >
> > $P(2 \leq X \leq 4) = 2P(3 \leq X \leq 4) = 2 \times (0.5 - 0.2) = 0.6$ ，C 错误；
> >
> > $P(X \quad 2) = 0.5 + P(2 \leq X \leq 3) = 0.5 + P(3 \leq X \leq 4) = 0.5 + (0.5 - 0.2) = 0.8$ ，D 错误
> >
> > 故选 **AB**.
