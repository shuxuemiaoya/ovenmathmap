> [!faq]- 《专题7.5 正态分布（高效培优讲义）数学人教A版高二选择性必修第三册》官方解析
>
> > [!success]- **【答案】** (1)100 (2) (i) 477 ; (ii) 答案见解析
>
> > [!note]- **【分析】**
> > （1）利用频率分布直方图的平均数计算公式计算即可；
> >
> > (2) (i) 由题意 $Z \sim N(100, 12.61^2)$ ，由 $P(\mu - 2\sigma \leq Z \leq \mu + 2\sigma) \approx 0.9544$ 可求得 $P(74.78 \leq Z \leq 100)$ ，进而可
> >
> > 得这批产品质量指标值在 $\left[74.78,100\right]$ 的数量；
> >
> > (ii) 根据正态分布的性质及 $3\sigma$ 原则分析即可.
>
> > [!note]- **【解析】**
> > （1）由题意可知， $\overline{x}=(70\times0.0025+80\times0.009+90\times0.022+100\times0.032+110\times0.024$
> >
> > $$
> > + 1 2 0 \times 0. 0 0 8 + 1 3 0 \times 0. 0 0 2 5) \times 1 0 = 1 0 0
> > $$
> >
> > (2) (i) 由题意， $Z \sim N(100, 12.61^{2})$
> >
> > 则 $P(\mu - 2\sigma \leq Z \leq \mu + 2\sigma) = P(100 - 2 \times 12.61 \leq Z \leq 100 + 2 \times 12.61) \approx 0.9544$ ， $2P(74.78 \leq Z \leq 100) \approx 0.9544$ ，即 $P(74.78 \leq Z \leq 100) \approx 0.4772$ 。
> >
> > 则这批产品质量指标值在 $[74.78,100]$ 的数量约为 $1000 \times 0.4772 \approx 477$ 。
> >
> > （ii）如果生产状态正常，此时一件产品的质量指标值在 $(\mu -3\sigma ,\mu +3\sigma)$ 之外的概率只有 $1 - 0.9974 = 0.0026$
> >
> > 一天内抽取 $^{10}$ 件产品中，发现产品质量指标值在 $(\mu -3\sigma ,\mu +3\sigma)$ 之外的概率只有 $1 - (1 - 0.0026)^{10}\approx 0.0257$
> >
> > 发生的概率很小，
> >
> > 因此一旦发生这种情况，就有理由认为生产线在这一天的生产过程中可能出现异常，需要对当天的生产过程
> >
> > 进行检查，可见这种监控生产过程的方法合理。
