> [!faq]- 《第七章 随机变量及其分布列（高效培优讲义）数学人教A版高二选择性必修第三册》官方解析
>
> > [!success]- **【答案】** (1)0.0525 (2)第 1，2 台车床操作员应分别承担 $\frac{2}{7}$ 的份额，第 3 台车床操作员应承担 $\frac{3}{7}$ 的份额.
>
> > [!note]- **【分析】**
> > 的份额·（1）设 $B =$ “任取一零件为次品”， $A_{i} =$ “零件为第 $i$ 台车床加工” $(i = 1,2,3)$ ，则
> >
> > $\Omega = A_{1} \cup A_{2} \cup A_{3}$ ，且 $A_{1}, A_{2}, A_{3}$ 两两互斥，求出 $P(A_{1})$ 、 $P(A_{2})$ 、 $P(A_{3})$ ，以及 $P(B \mid A_{1})$ 、 $P(B \mid A_{2})$ 、

> > $P(B \mid A_{3})$ ，由全概率公式得 $P(B)$ ；
> >
> > (2) 求“次品为第 $i$ 台车床所加工的概率”，就是计算在 $B$ 发生的条件下，事件 $A_{i}$ 发生的概率由条件概率公式
> >
> > 计算可得答案·
>
> > [!note]- **【解析】**
> > （1）设 $B =$ “任取一零件为次品”， $A_{i} =$ “零件为第 $i$ 台车床加工” $(i = 1,2,3)$
> >
> > 则 $\Omega = A_{1} \cup A_{2} \cup A_{3}$ ，且 $A_{1}, A_{2}, A_{3}$ 两两互斥，根据题意得， $P(A_{1}) = 0.25, P(A_{2}) = 0.3, P(A_{3}) = 0.45$ ， $P(B|A_{1}) = 0.06, P(B|A_{2}) = 0.05, P(B|A_{3}) = 0.05$
> >
> > 由全概率公式得 $P(B)=P(A_{1})P(B|A_{1})+P(A_{2})P(B|A_{2})+P(A_{3})P(B|A_{3})$ $=0.25\times0.06+0.3\times0.05+0.45\times0.05$ =0.0525
> > ;
> >
> > (2) “次品为第 $i(i = 1,2,3)$ 台车床所加工的概率”，就是计算在 $B$ 发生的条件下，事件 $A_{i}$ 发生的概率， $P(A_{1} \mid B) = \frac{P(A_{1}B)}{P(B)} = \frac{P(A_{1})P(B \mid A_{1})}{P(B)} = \frac{0.25 \times 0.06}{0.0525} = \frac{2}{7}$ ， $P(A_{2} \mid B) = \frac{P(A_{2}B)}{P(B)} = \frac{P(A_{2})P(B \mid A_{2})}{P(B)} = \frac{0.3 \times 0.05}{0.0525} = \frac{2}{7}$ ， $P(A_{3} \mid B) = \frac{P(A_{3}B)}{P(B)} = \frac{P(A_{3})P(B \mid A_{3})}{P(B)} = \frac{0.45 \times 0.05}{0.0525} = \frac{3}{7}$ ，故第1，2台车床操作员应承担 $\frac{2}{7}$ 的份额，第3台车床操作员应承担 $\frac{3}{7}$ 的份额。
