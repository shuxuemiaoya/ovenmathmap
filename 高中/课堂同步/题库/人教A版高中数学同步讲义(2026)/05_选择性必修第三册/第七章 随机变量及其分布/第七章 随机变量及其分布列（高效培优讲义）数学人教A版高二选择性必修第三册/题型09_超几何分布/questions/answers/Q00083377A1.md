> [!faq]- 《第七章 随机变量及其分布列（高效培优讲义）数学人教A版高二选择性必修第三册》官方解析
>
> > [!success]- **【答案】** $^{18}$
>
> > [!note]- **【分析】**
> > 根据题意可知百元代金券 X 的所有可能取值为 a, b, ab，根据超几何分布可得随机变量取各个值的概率，即可得 X 的分布列，再求期望可知 $\frac{3}{5}a + \frac{3}{10}b + \frac{1}{10}ab = 5.4$ ，最后结合基本不等式求 ab 的最大值，即可得解。
>
> > [!note]- **【解析】**
> > 设抽奖一次可获得 $X$ 百元代金券，则 $X$ 的所有可能取值为 $a, b, ab$
> >
> > 摸到一红球一白球的概率 $P_{1} = P(X = a) = \frac{\mathrm{C}_{2}^{1}\mathrm{C}_{3}^{1}}{\mathrm{C}_{5}^{2}} = \frac{3}{5}$
> >
> > 摸到两白球的概率 $P_{2}=P(X=b)=\frac{C_{3}^{2}}{C_{5}^{2}}=\frac{3}{10}$
> >
> > 摸到两红球的概率 $P_{3}=P(X=ab)=\frac{C_{2}^{2}}{C_{5}^{2}}=\frac{1}{10}$
> >
> > 则 $X$ 的分布列如下：
> >
> > <table><tr><td>X</td><td>a</td><td>b</td><td>ab</td></tr><tr><td>P</td><td>3/5</td><td>3/10</td><td>1/10</td></tr></table>
> >
> > $E(X)=a\times\frac{3}{5}+b\times\frac{3}{10}+ab\times\frac{1}{10}=5.4,a,b\in\mathbf{N}$ ，即 $6a+3b+ab=54$ ， $b=\frac{54-6a}{a+3}$
> >
> > 由题意知，运气最好者获得 $ab$ 百元代金券，
> >
> > 则 $ab = \frac{54a - 6a^2}{a + 3} = -6\left(a + 3 + \frac{36}{a + 3}\right) + 90 \leq -12 \cdot \sqrt{(a + 3) \times \frac{36}{a + 3}} + 90 = 18$
> >
> > 当且仅当 $a + 3 = \frac{36}{a + 3}$ ，即 $a = 3$ ， $b = 6$ 时等号成立，
> >
> > 即 ab 的最大值为 18.
> >
> > 故答案为：18.
