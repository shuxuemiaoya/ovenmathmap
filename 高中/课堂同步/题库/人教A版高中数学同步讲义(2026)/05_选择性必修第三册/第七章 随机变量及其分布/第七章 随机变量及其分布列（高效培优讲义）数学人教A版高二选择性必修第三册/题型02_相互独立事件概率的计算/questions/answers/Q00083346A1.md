> [!faq]- 《第七章 随机变量及其分布列（高效培优讲义）数学人教A版高二选择性必修第三册》官方解析
>
> > [!success]- **【答案】** BCD
>
> > [!note]- **【分析】**
> > 依次写出 n=2 和 n=3 时样本总空间、事件 M,N,MN 的样本空间，以及利用古典概型求出相应的概
> >
> > 率 $P(M), P(N), P(MN)$ ，再结合互斥事件和独立事件定义分析即可得解
>
> > [!note]- **【解析】**
> > 记抛掷一枚硬币正面向上为 $^{1}$ ，反面向上为 $^{0}$ ，
> >
> > 则连续抛掷一枚硬币两次的样本空间为 $\Omega_{1} = \{11,10,01,00\}$
> >
> > 此时事件 $M$ 的样本空间为 $\{10,01\}$ ，事件 $N$ 的样本空间为 $\{10,01,00\}$
> >
> > 积事件MN的样本空间为 $\{10,01\}$
> >
> > 所以事件 $M, N$ 交集不空，不互斥，且 $P(M) = \frac{1}{2}, P(N) = \frac{3}{4}, P(MN) = \frac{1}{2}$ ，
> >
> > 所以 $P(MN) \neq P(M)P(N)$ ，故 M 与 N 不相互独立，故 A 错误，B 正确；
> >
> > 连续抛掷一枚硬币 $^{3}$ 次的样本空间为 $\Omega_{2}=\left\{111,110,101,011,100,010,001,000\right\}$ 共8个样本点，
> >
> > 此时事件 $M$ 的样本空间为 $\{110, 101, 011, 100, 010, 001\}$ 共6个样本点，
> >
> > 事件 N 的样本空间为 $\left\{100,010,001,000\right\}$ 共 4 个样本点，
> >
> > 积事件 $MN$ 的样本空间为 $\{100,010,001\}$
> >
> > 所以事件 M, N 的交集不空，不互斥，且 $P(M) = \frac{3}{4}, P(N) = \frac{1}{2}, P(MN) = \frac{3}{8}$
> >
> > 所以 $P(MN) = P(M)P(N)$ ，故 $M$ 与 $N$ 相互独立，故 $\mathsf{CD}$ 正确；
> >
> > 故选：BCD
> >
> > 变式3】下列对各事件发生的概率判断正确的是（）
> >
> > A．某学生在上学的路上要经过 $^{4}$ 个路口，假设在各路口是否遇到红灯是相互独立的，遇到红灯的概率都
> >
> > 是 $\frac{1}{3}$ ，那么该生在上学路上到第 $^{3}$ 个路口首次遇到红灯的概率为 $\frac{4}{27}$
> >
> > B．小王逛书店，他买甲书和买乙书相互独立，若小王买甲书不买乙书的概率为 $\frac{1}{6}$ ，甲和乙两本书都买的概率为 $\frac{1}{2}$ ，则小王买乙书的概率为 $\frac{3}{4}$
> >
> > C．三人独立地破译一份密码，他们能单独译出的概率分别为 $\frac{1}{5}$ ， $\frac{1}{3}$ ， $\frac{1}{4}$ ，假设他们破译密码是彼此独立的，则此密码被破译的概率为 $\frac{2}{5}$
> >
> > D．甲袋中有 $^{8}$ 个白球， $^{4}$ 个红球，乙袋中有 $^{6}$ 个白球， $^{6}$ 个红球，从每袋中各任取一个球，则取到同色球的概率为 $\frac{1}{2}$
> >
> > 【答案】ABD
> >
> > 【分析】根据独立事件的乘法公式对每个选项由题意进行计算，从而进行判断即可·
> >
> > 【详解】对于 $^{A}$ ：该生在第 $^{3}$ 个路口首次遇到红灯的情况为前 $^{2}$ 个路口不是红灯，第 $^{3}$ 个路口是红灯，
> >
> > 所以概率为 $\left(1 - \frac{1}{3}\right)^2 \times \frac{1}{3} = \frac{4}{27}$ ，故 $A$ 正确；
> >
> > 对于 B：设购买甲书的概率为 x，购买乙书的概率为 y，
> >
> > 则由题意可得 $\left\{\begin{aligned}x(1-y)&=\frac{1}{6},\\ xy&=\frac{1}{2},\end{aligned}\right.$ 解得 $x=\frac{2}{3},y=\frac{3}{4}$ 故 B 正确；
> >
> > 对于 C：用 A、B、C 分别表示甲、乙、丙三人能破译出密码，
> >
> > 则 $P(A) = \frac{1}{5}$ ， $P(B) = \frac{1}{3}$ ， $P(C) = \frac{1}{4}$
> >
> > “三个人都不能破译出密码”发生的概率为 $\frac{4}{5} \times \frac{2}{3} \times \frac{3}{4} = \frac{2}{5}$
> >
> > 所以此密码被破译的概率为 $1 - \frac{2}{5} = \frac{3}{5}$ ，故C不正确；
> >
> > 对于 $D$ ：设“从甲袋中取到白球”为事件 $\mathsf{A}$ ，则 $P(A) = \frac{8}{12} = \frac{2}{3}$
> >
> > 设“从乙袋中取到白球”为事件 $^{B}$ ，则 $P(B)=\frac{6}{12}=\frac{1}{2}$
> >
> > 故取到同色球的概率为 $\frac{2}{3} \times \frac{1}{2} + \frac{1}{3} \times \frac{1}{2} = \frac{1}{2}$ ，故D正确·
> >
> > 故选 **ABD**
