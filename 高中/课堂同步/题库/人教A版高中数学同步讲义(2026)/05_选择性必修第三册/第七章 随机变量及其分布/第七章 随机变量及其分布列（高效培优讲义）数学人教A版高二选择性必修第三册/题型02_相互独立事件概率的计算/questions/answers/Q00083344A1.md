> [!faq]- 《第七章 随机变量及其分布列（高效培优讲义）数学人教A版高二选择性必修第三册》官方解析
>
> > [!success]- **【答案】** AB
>
> > [!note]- **【分析】**
> > 根据相互独立事件，对立事件和概率加法公式逐一计算判断即可·
>
> > [!note]- **【解析】**
> > 对于 $^{A}$ ，因为事件A与B相互独立，所以 $P(AB)=P(A)P(B)=0.7\times0.8=0.56$ ，故 $^{A}$ 正确；
> >
> > 对于 B， $P(A \cup B) = P(A) + P(B) - P(AB) = 0.7 + 0.8 - 0.56 = 0.94$ ，故 B 正确.
> >
> > 对于 $C$ ，因为 $P(A) = 0.7$ ， $P(B) = 0.8$
> >
> > 所以 $P(\overline{A}) = 1 - P(A) = 0.3$ ， $P(\overline{B}) = 1 - P(B) = 0.2$
> >
> > 因为事件 A 与 B 相互独立，所以因为事件 $\overline{A}$ 与 $\overline{B}$ 相互独立，
> >
> > 所以 $P\left(\overline{A}\overline{B}\right)=P\left(\overline{A}\right)P\left(\overline{B}\right)=0.3\times0.2=0.06$ ，故 C 错误；
> >
> > 对于 D， $P\left(\overline{A} \cup \overline{B}\right) = P\left(\overline{A}\right) + P\left(\overline{B}\right) - P\left(\overline{A}\overline{B}\right) = 0.3 + 0.2 - 0.06 = 0.44$ ，故 D 错误。
> >
> > 故选：AB.
> >
> > ## 方法技巧
> >
> > (1) 求相互独立事件同时发生的概率的步骤
> > - **①**：首先确定各事件之间是相互独立的。
> > - **②**：求出每个事件的概率，再求积。
> >
> > (2) 使用相互独立事件同时发生的概率计算公式时，要掌握公式的适用条件，即各个事件是相互独立的．
