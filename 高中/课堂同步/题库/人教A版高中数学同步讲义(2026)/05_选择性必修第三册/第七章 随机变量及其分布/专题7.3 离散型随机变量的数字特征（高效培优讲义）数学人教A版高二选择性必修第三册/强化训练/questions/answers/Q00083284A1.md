> > 10. 学校成立了生物科技小组，在同一块试验田内交替种植 $A$ 、 $B$ 、 $C$ 三种农作物（该试验田每次只能种植
> >
> > 一种农作物），为了保持土壤肥度，每种农作物都不连续种植，共种植三次．在每次种植 $A$ 后，会有 $\frac{1}{3}$ 的可能性种植 $_{B}$ ， $\frac{2}{3}$ 的可能性种植C；在每次种植 $_{B}$ 的后再种植A的概率为 $\frac{1}{4}$ ，种植C的概率为 $\frac{3}{4}$ ，在每次种植C后再种植A的概率为 $\frac{2}{5}$ ，种植B的概率为 $\frac{3}{5}$ 。
> >
> > (1)在第一次种植 $B$ 的前提下，求第三次种植 $A$ 的概率；
> >
> > (2)在第一次种植 $A$ 的前提下，求种植 $B$ 作物次数 $X$ 的分布列及期望.
> >
> > 【答案】(1) $\frac{3}{10}$
> >
> > $$
> > E (X) = \frac {1 1}{1 5}
> > $$
> >
> > 【分析】（ $^{1}$ ）根据条件概率的概念，写出每次种植各种作物的概率，求出事件概率即可·
> >
> > (2) 根据条件概率的概念，判断分布列可以取到的值，进而求出各自的概率，写出分布列，进而求出期望·
> >
> > 【详解】（1）设事件 $A_{i}, B_{i}, C_{i} (i = 1,2,3)$ 代表第 $i$ 次种植 $A, B, C$ 三种作物的概率，
> >
> > 若第一次种植 B，第三次种植 A，则第二次只能种植 C
> >
> > 则 $P(A_{3}) = P(C_{2}|B_{1})P(A_{3}|C_{2}) = \frac{3}{4}\times \frac{2}{5} = \frac{3}{10}.$
> >
> > (2) 第一次种植 A 的前提下，种植 B 作物次数可以是 0 或 1，即随机变量 X 可能的取值为 0 或 1；
> >
> > 当 X = 0 时，即第一次种植 A ，第二次种植 C ，第三次再种植 A ，
> >
> > 则 $P(X=0)=P\left(C_{2}\mid A_{1}\right)P\left(A_{3}\mid C_{2}\right)=\frac{2}{3}\times\frac{2}{5}=\frac{4}{15}$ ;
> >
> > 当 X=1 时，即第一次种植 A ，第二次种植 B ，第三次再种植 A 或 C
> >
> > 或第一次种植 A，第二次种植 C，第三次再种植 B，则 $P(X = 1) = P(B_2|A_1) + P(C_2|A_1)P(B_3|C_2) = \frac{1}{3} +\frac{2}{3}\times \frac{3}{5} = \frac{11}{15}$
> >
> > 可得 $X$ 的分布列为：
> >
> > <table><tr><td>X</td><td>0</td><td>1</td></tr><tr><td>P</td><td>4/15</td><td>11/15</td></tr></table>
> >
> > $E(X)=0\times\frac{4}{15}+1\times\frac{11}{15}=\frac{11}{15}$
