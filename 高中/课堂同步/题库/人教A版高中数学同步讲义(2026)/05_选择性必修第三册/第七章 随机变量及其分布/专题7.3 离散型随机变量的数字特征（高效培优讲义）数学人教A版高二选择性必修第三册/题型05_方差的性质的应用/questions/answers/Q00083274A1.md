> [!faq]- 《专题7.3 离散型随机变量的数字特征（高效培优讲义）数学人教A版高二选择性必修第三册》官方解析
>
> > [!success]- **【答案】** (1)分布列见解析， $E(X)=100$ (2)应选择方案一，理由见解析
>
> > [!note]- **【分析】**
> > （1）分析可知 $X$ 的值可能为0、100、200，计算出随机变量 $X$ 在不同取值下的概率，可得出随机
> >
> > 变量 X 的分布列，进而可求得 $E(X)$ 的值；
> >
> > (2) 法一：用随机变量 $\xi$ 表示某员工按方案二摸到的红球的个数，则 $\xi \sim B\left(3, \frac{1}{3}\right)$ ，利用二项分布的期望、方差公式结合期望、方差的性质求出 $E(Y)$ 、 $D(Y)$ 的值，可知 $E(X) = E(Y)$ ，再比较 $D(X)$ 、 $D(Y)$ 的大小关
> >
> > 系，可得出结论；
> >
> > 法二：分析可知， $Y$ 的值可能为 0、100、200、300，计算出随机变量 $Y$ 在不同取值下的概率，进而可求得
> >
> > $E(Y)$ 、 $D(Y)$ 的值，可知 $E(X)=E(Y)$ ，再比较 $D(X)$ 、 $D(Y)$ 的大小关系，可得出结论：
>
> > [!note]- **【解析】**
> > （1）解：由题意可知，X 的值可能为 0、100、200，
> >
> > $$
> > P (X = 0) = \frac {\mathrm{C} _ {4} ^ {3}}{\mathrm{C} _ {6} ^ {3}} = \frac {1}{5}, P (X = 1 0 0) = \frac {\mathrm{C} _ {2} ^ {1} \mathrm{C} _ {4} ^ {2}}{\mathrm{C} _ {6} ^ {3}} = \frac {3}{5}, P (X = 2 0 0) = \frac {\mathrm{C} _ {2} ^ {2} \mathrm{C} _ {4} ^ {1}}{\mathrm{C} _ {6} ^ {3}} = \frac {1}{5}.
> > $$
> >
> > <table><tr><td>X</td><td>0</td><td>100</td><td>200</td></tr><tr><td>P</td><td> $\frac{1}{5}$ </td><td> $\frac{3}{5}$ </td><td> $\frac{1}{5}$ </td></tr></table>
> >
> > $$
> > E (X) = 0 \times \frac {1}{5} + 1 0 0 \times \frac {3}{5} + 2 0 0 \times \frac {1}{5} = 1 0 0
> > $$
> >
> > (2) 解：法一：用随机变量 $\xi$ 表示某员工按方案二摸到的红球的个数，则 $\xi \sim B\left(3, \frac{1}{3}\right)$ .
> >
> > $$
> > E (\xi) = 3 \times \frac {1}{3} = 1, D (\xi) = 3 \times \frac {1}{3} \times \frac {2}{3} = \frac {2}{3}
> > $$
> >
> > $$
> > Y = 1 0 0 \zeta \quad E (Y) = 1 0 0 E (\zeta) = 1 0 0 \times 1 = 1 0 0 \quad D (Y) = 1 0 0 0 0 D (\zeta) = 1 0 0 0 0 \times \frac {2}{3} = \frac {2 0 0 0 0}{3}.
> > $$
> >
> > $$
> > D (X) = (0 - 1 0 0) ^ {2} \times \frac {1}{5} + (1 0 0 - 1 0 0) ^ {2} \times \frac {3}{5} + (2 0 0 - 1 0 0) ^ {2} \times \frac {1}{5} = 4 0 0 0
> > $$
> >
> > 因为 $D(X) < D(Y)$ ，按方案一员工抽奖的获奖金额相对均衡，应选择方案一；

> > $$
> >
> > $$

> > $$
> >
