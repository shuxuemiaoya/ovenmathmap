> [!faq]- 《专题02 离散型随机变量分布列四大常考题型（高效培优专项训练）数学人教A版高二选择性必修第三册》官方解析
>
> > [!success]- **【答案】** $0.9/\frac{9}{10}$
>
> > [!note]- **【分析】**
> > 由题意可知： $P(Y \leq 23) = P(X \leq 5)$ ，结合对立事件概率求法即可得到结果。
>
> > [!note]- **【解析】**
> > 令 $Y = 4X + 3 \leq 23$ ，解得 $X \leq 5$ ，且 $P(X = 6) = 0.1$ ，
> > 所以 $P(Y \leq 23) = P(X \leq 5) = 1 - P(X = 6) = 1 - 0.1 = 0.9$
> >
> > 故答案为：0.9
