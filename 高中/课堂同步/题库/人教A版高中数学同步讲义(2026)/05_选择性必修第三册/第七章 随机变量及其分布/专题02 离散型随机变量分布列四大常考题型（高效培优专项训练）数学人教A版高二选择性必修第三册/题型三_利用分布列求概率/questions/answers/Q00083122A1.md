> [!faq]- 《专题02 离散型随机变量分布列四大常考题型（高效培优专项训练）数学人教A版高二选择性必修第三册》官方解析
>
> > [!success]- **【答案】** A
>
> > [!note]- **【分析】**
> > 运用概率分布列的性质求出 $a = 10$ ，再求 $P(2 \leq X < 4)$ 即可·
>
> > [!note]- **【解析】**
> > 依题意，分布列概率之和为 $^{1}$ ，则 $\frac{1}{a} + \frac{2}{a} + \frac{3}{a} + \frac{4}{a} = 1$ ，解得 $a = 10$ 即 $P(X = i) = \frac{i}{10} (i = 1,2,3,4)$ ，所以 $P(2\leq X <   4) = P(X = 2) + P(X = 3) = \frac{2}{10} +\frac{3}{10} = \frac{1}{2}.$
> >
> > 故选：A.

> > ## 28. 已知随机变量 $X$ 的分布列为
> >
> > <table><tr><td>X</td><td>5</td><td>10</td><td>15</td></tr><tr><td>P</td><td> $\frac{1}{6}$ </td><td> $\frac{1}{3}$ </td><td>p</td></tr></table>
> >
> > 则 $p = (\quad)$ A. $\frac{1}{12}$ B. $\frac{1}{6}$ C. $\frac{1}{3}$ D. $\frac{1}{2}$
> >
> > 【答案】D
> >
> > 【分析】由分布列性质计算即可·
> >
> > 【详解】由分布列的性质，得 $\frac{1}{6} +\frac{1}{3} +p = 1$ ，解得 $p = \frac{1}{2}$
> >
> > 故选:D.

> > 29. 课桌上有 $^{12}$ 本书，其中理科书籍有 $^{4}$ 本，现从中任意拿走 $^{6}$ 本书，用随机变量 $\xi$ 表示这 $^{6}$ 本书中理科书籍的本数，则概率为 $\frac{C_{8}^{6}C_{4}^{0}}{C_{12}^{6}}+\frac{C_{8}^{5}C_{4}^{1}}{C_{12}^{6}}$ 的是（）A. $P(\xi\leq1)$ B. $P(\xi=1)$ C. $P(\xi>1)$ D. $P(\xi>2)$
> >
> > 【答案】A
> >
> > 【分析】计算出 $P(\xi = 0) = \frac{\mathrm{C}_8^6\mathrm{C}_4^0}{\mathrm{C}_{12}^6}, P(\xi = 1) = \frac{\mathrm{C}_8^5\mathrm{C}_4^1}{\mathrm{C}_{12}^6}$ ，从而得到答案·
> >
> > 【详解】 $P(\xi = 0) = \frac{\mathrm{C}_8^6\mathrm{C}_4^0}{\mathrm{C}_{12}^6}$ ， $P(\xi = 1) = \frac{\mathrm{C}_8^5\mathrm{C}_4^1}{\mathrm{C}_{12}^6}$
> >
> > 故 $P(\xi \leq 1) = \frac{C_8^6 C_4^0}{C_{12}^6} + \frac{C_8^5 C_4^1}{C_{12}^6}$ ，A 正确，
> >
> > 其他选项，均不合要求·
> >
> > 故选 **A**
