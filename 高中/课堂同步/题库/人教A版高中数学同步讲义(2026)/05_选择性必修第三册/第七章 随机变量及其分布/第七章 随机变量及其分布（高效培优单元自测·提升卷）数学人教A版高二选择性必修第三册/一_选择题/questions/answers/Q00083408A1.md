> [!faq]- 《第七章 随机变量及其分布（高效培优单元自测·提升卷）数学人教A版高二选择性必修第三册》官方解析
>
> > [!success]- **【答案】** A
>
> > [!note]- **【分析】**
> > 应用正态分布的对称性有 $P(X \leq 9) = P(X - 15)$ ， $P(X \leq 9) + P(9 < X < 12) = 0.5$ ，即可求概率。
>
> > [!note]- **【解析】**
> > 由对称性质知 $P(X \leq 9) = P(X - 15)$ ，且 $P(X \leq 9) + P(9 < X < 12) = 0.5$
> >
> > 又 $P(X - 15) - P(9 < X < 12) = P(X \leq 9) - P(9 < X < 12) = 0.1$
> >
> > 所以 $P(X \leq 9) = 0.3$ .
> >
> > 故选 **A**
