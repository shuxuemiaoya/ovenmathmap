> [!faq]- 《高一数学上学期第一次月考__高效培优_提升卷_》官方解析
>
> > [!success]- **【答案】** （1）证明见解析；（2） $1<5a+b<8$
>
> > [!note]- **【解析】**
> > （1） $\frac{a + b}{b} -\frac{c + d}{d} = \frac{(a + b)d - b(c + d)}{bd} = \frac{ad - bc}{bd}$
> >
> > 因为 $bc - ad = 0$ ，所以 $ad - bc \leq 0$
> >
> > 又 $bd > 0$ ，所以 $\frac{ad - bc}{bd} \leq 0$
> >
> > 即 $\frac{a + b}{b} \leq \frac{c + d}{d}$ .
> >
> > (2) 令 $5a + b = \lambda(2a + b) + \mu(a - b) = (2\lambda + \mu)a + (\lambda - \mu)b$
> >
> > 所以 $\left\{ \begin{array}{l}2\lambda +\mu = 5\\ \lambda -\mu = 1 \end{array} \right.$ ，解得 $\left\{ \begin{array}{l}\lambda = 2\\ \mu = 1 \end{array} \right.$
> >
> > 所以 $5a + b = 2(2a + b) + (a - b)$
> >
> > 因为 $-1 < 2a + b < 2$ ，所以 $-2 < 2(2a + b) < 4$
> >
> > 又 3 < a - b < 4 ，所以 $1 < 2(2a + b) + (a - b) < 8$
> >
> > 故 $5a+b$ 的取值范围为 $1<5a+b<8$ .
