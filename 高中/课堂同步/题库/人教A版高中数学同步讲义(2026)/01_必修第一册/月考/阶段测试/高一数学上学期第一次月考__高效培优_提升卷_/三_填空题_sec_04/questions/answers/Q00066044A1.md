> [!faq]- 《高一数学上学期第一次月考__高效培优_提升卷_》官方解析
>
> > [!success]- **【答案】** 8
>
> > [!note]- **【解析】**
> > 从4个数中选3个数求和共有4种取法，
> >
> > 即 $x_{1} + x_{2} + x_{3}, x_{1} + x_{2} + x_{4}, x_{1} + x_{3} + x_{4}, x_{2} + x_{3} + x_{4}$ ，①
> >
> > 将①中4个式子相加得 $3(x_{1}+x_{2}+x_{3}+x_{4})$
> >
> > 因为 $x_{1}, x_{2}, x_{3}, x_{4}$ 是 4 个正整数，所以 $3(x_{1} + x_{2} + x_{3} + x_{4})$ 一定是 3 的倍数，
> >
> > 所得的结果的集合为 $\{25, 26, 27\}$ ，由集合元素的互异性，这四个结果中 $25, 26, 27$ 中必有一个数重复，
> >
> > 注意到 $25 + 26 + 27 = 78$ 是3的倍数，而四个数的和也是3的倍数，
> >
> > 所以①中的4个和为25,26,27,27
> >
> > 则 $3\left(x_{1} + x_{2} + x_{3} + x_{4}\right) = 25 + 26 + 27 + 27 = 105$ ，则 $x_{1} + x_{2} + x_{3} + x_{4} = 35$
> >
> > 又因为 $35 - 25 = 10, 35 - 26 = 9, 35 - 27 = 8$ ，所以这4个数分别为 $8, 8, 9, 10$
> >
> > 故这 4 个数中最小的数为 8.
> >
> > 故答案为：8.
