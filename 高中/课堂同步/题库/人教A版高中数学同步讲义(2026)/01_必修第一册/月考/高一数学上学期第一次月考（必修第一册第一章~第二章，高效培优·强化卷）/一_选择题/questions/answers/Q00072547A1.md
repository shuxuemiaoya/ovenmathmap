> [!faq]- 《高一数学上学期第一次月考（必修第一册第一章~第二章，高效培优·强化卷）》官方解析
>
> > [!success]- **【答案】** A. $a > 0$ B. $a + b + c > 0$ C. 不等式 $bx + c > 0$ 的解集为 $\{x | x < 12\}$ D．不等式 $cx^{2}-bx+a<0$ 的解集为 $\left\{x\left|-\frac{1}{3}<x<\frac{1}{4}\right.\right\}$
>
> > [!note]- **【解析】**
> > A：因为关于 x 的不等式 $ax^{2} + bx + c \leq 0$ 的解集为 $\{x \mid x \leq -4 \text{ 或 } x = 3\}$
> >
> > 所以 -4 和 3 是方程 $ax^{2} + bx + c = 0$ 的两个实根，且对应的二次函数图象开口向下，则 a < 0，错；
> >
> > B：由A得 $-4+3=-\frac{b}{a}$ ， $-4\times3=\frac{c}{a}$ ，所以b=a，c=-12a，
> >
> > 因为 $a + b + c = a + a - 12a = -10a$ ，a < 0，所以 $a + b + c > 0$ ，对；
> >
> > C：不等式 $bx + c > 0$ 可化为 $ax - 12a > 0$ ，因为 $a < 0$ ，所以 $x < 12$ ，对；
> >
> > D：不等式 $cx^{2} - bx + a < 0$ 可化为 $-12ax^{2} - ax + a < 0$ ，又 $a < 0$ ，
> >
> > 所以 $12x^{2} + x - 1 < 0$ ，即 $(4x - 1)(3x + 1) < 0$ ，解得 $-\frac{1}{3} < x < \frac{1}{4}$ ，对
> >
> > 故选 **BCD**
