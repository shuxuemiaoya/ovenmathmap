> [!faq]- 《高一数学上学期第一次月考（必修第一册第一章~第二章，高效培优·强化卷）》官方解析
>
> > [!success]- **【答案】** (1) $\left\{x\mid -1 < x\leq 4\right\}$ ， $\left\{x\mid x\leq -1\right.$ 或 $x > 4\}$ (2) $a \leq -4$ 或 $a \frac{3}{2}$
>
> > [!note]- **【解析】**
> > （1） $A = \{x|x\leq -1$ 或 $x\quad 3\}$ ，则 $\tilde{\mathbf{Q}}_{\mathbf{R}}A = \{x| - 1 <   x <   3\}$
> >
> > $B = \{x\mid 2a\leq x\leq a + 3\}$ ，当 $a = 1$ 时， $B = \{x\mid 2\leq x\leq 4\}$
> >
> > 所以 $\left(\check{\mathbf{Q}}_{\mathbf{R}}A\right)\cup B=\left\{x\mid-1<x\leq4\right\}$
> >
> > 又 $\tilde{\mathbf{Q}}_{\mathbf{R}}B=\left\{x\mid x<2\text{ 或 }x>4\right\}$ ，所以 $A\cap\left(\tilde{\mathbf{Q}}_{\mathbf{R}}B\right)=\left\{x\mid x\leq-1\text{ 或 }x>4\right\}$ .
> >
> > (2) 若 $A \cap B = B$ ，则 $B \subseteq A$ .
> >
> > 当 $B = \emptyset$ 时， $2a > a + 3$ ，即 $a > 3$ ；
> >
> > 当 $B \neq \emptyset$ 时，则 $\left\{ \begin{array}{l} a \leq 3 \\ a + 3 \leq -1 \end{array} \right.$ 或 $\left\{ \begin{array}{l} a \leq 3 \\ 2a - 3 \end{array} \right.$ ，解得 $a \leq -4$ 或 $\frac{3}{2} \leq a \leq 3$ 。
> >
> > 综上， $a$ 的取值范围为 $a \leq -4$ 或 $a = \frac{3}{2}$ .
