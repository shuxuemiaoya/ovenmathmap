> [!faq]- 《高一数学上学期第一次月考（必修第一册第一章~第二章，高效培优·提升卷）》官方解析
>
> > [!success]- **【答案】** C
>
> > [!note]- **【解析】**
> > $\frac{8ab^2 + a}{bc} = \frac{a(8b^2 + 1)}{bc} = a\left(\frac{8b}{c} +\frac{1}{bc}\right) = a\left[\frac{8b}{c} +\frac{(b + c)^2}{bc}\right]$
> >
> > $$
> > = a \left(\frac {8 b}{c} + \frac {b ^ {2} + c ^ {2} + 2 b c}{b c}\right) = a \left(\frac {9 b}{c} + \frac {c}{b} + 2\right) \quad a \left(2 \sqrt {\frac {9 b}{c} \cdot \frac {c}{b}} + 2\right) = 8 a
> > $$
> >
> > 当且仅当 $\frac{9b}{c} = \frac{c}{b}$ ，即 $c = 3b$ ，所以 $b = \frac{1}{4}$ ， $c = \frac{3}{4}$ 时等号成立， $\frac{8ab^2 + a}{bc} + \frac{16}{a + 1}$ $8a + \frac{16}{a + 1} = 8(a + 1) + \frac{16}{a + 1} - 8\sqrt{28(a + 1)\times\frac{16}{a + 1}} - 8$ 当且仅当 $8(a + 1) = \frac{16}{a + 1}$ ，即 $a = \sqrt{2} -1$ 时等号成立，
> >
> > 所以 $\frac{8ab^{2}+a}{bc}+\frac{16}{a+1}$ 的最小值为 $16\sqrt{2}-8$ .
> >
> > 故选 **C**.
