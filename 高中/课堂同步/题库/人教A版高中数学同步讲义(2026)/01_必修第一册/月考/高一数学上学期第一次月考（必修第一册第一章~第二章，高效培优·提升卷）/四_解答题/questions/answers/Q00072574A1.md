> [!faq]- 《高一数学上学期第一次月考（必修第一册第一章~第二章，高效培优·提升卷）》官方解析
>
> > [!success]- **【答案】** (1) $S=5x+\frac{900}{5x+5}+30$ (2)隔热层修建5厘米厚时，总费用达到最小值，最小值为85万元
>
> > [!note]- **【解析】**
> > （1）依题意，当无隔热层时（x=0），每年能消耗费用C=6万元，即 $6=\frac{k}{5\times0+5}$ ，可得k=30
> >
> > 故 $C = \frac{30}{5x + 5}$
> >
> > 所以 $S = 5x + \frac{30}{5x + 5} \cdot 30 + 30 = 5x + \frac{900}{5x + 5} + 30$ ，
> >
> > 即 $S$ 的表达式为 $S = 5x + \frac{900}{5x + 5} +30$
> >
> > (2) $\because 0 \leq x \leq 10$
> >
> > $$
> > S = 5 x + \frac {9 0 0}{5 x + 5} + 3 0 = 5 x + 5 + \frac {9 0 0}{5 x + 5} + 2 5
> > $$
> >
> > $$
> > 2 \sqrt {(5 x + 5) \cdot \frac {9 0 0}{5 x + 5}} + 2 5 = 8 5
> > $$
> >
> > 当且仅当 $5x + 5 = \frac{900}{5x + 5}$ ，即当 $x = 5$ 时取得最小值，
> >
> > 所以隔热层修建 5 厘米厚时，总费用达到最小值，最小值为 85 万元。
