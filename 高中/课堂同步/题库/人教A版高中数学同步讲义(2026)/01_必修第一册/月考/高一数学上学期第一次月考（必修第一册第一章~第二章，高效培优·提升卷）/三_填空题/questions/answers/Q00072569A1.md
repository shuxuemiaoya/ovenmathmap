> [!faq]- 《高一数学上学期第一次月考（必修第一册第一章~第二章，高效培优·提升卷）》官方解析
>
> > [!success]- **【答案】** ②③④
>
> > [!note]- **【解析】**
> > - **对于①**：，若 $ax^2 + x + 1$ 0的解集为 $\varnothing$ ，则 $\left\{ \begin{array}{l}a <   0\\ \Delta = 1 - 4a <   0 \end{array} \right.$ ，得 $a$ 无解，故①正确，
> > - **对于②**：，若 $ax^2 + bx + c \leq 0$ 在 $\mathbf{R}$ 上恒成立，则 $\left\{ \begin{array}{l} a < 0 \\ \Delta = b^2 - 4ac \leq 0 \text{或} a = b = 0, c \leq 0 \end{array} \right.$
> >
> > 故“ $a < 0$ 且 $\Delta = b^{2} - 4ac \leq 0$ ”是“ $ax^{2} + bx + c \leq 0$ 在 $\mathbf{R}$ 上恒成立”的充分不必要条件，故②错误，
> > - **对于③**：，当 $a < 0$ 时，若 $y = ax^2 + bx + c (a \neq 0)$ 对应的方程没有实根，则不等式 $ax^2 + bx + c > 0$ 的解集为 $\varnothing$
> >
> > 故③错误，
> > - **对于④**：，不等式 $\frac{1}{x} > 1$ 的解为 $0 < x < 1$ ，故④错误，
> >
> > 故答案为：②③④
