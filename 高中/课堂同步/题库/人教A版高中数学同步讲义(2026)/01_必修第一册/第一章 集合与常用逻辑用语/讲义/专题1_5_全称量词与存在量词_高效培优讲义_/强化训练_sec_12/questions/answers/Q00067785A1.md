> [!faq]- 《专题1_5_全称量词与存在量词_高效培优讲义_》官方解析
>
> > [!success]- **【答案】** (1) $A \cap B = \{x \mid 5 < x \leq 7\}$ $A \cup B = \{x \mid x < -1$ 或 $x = 4\}$ $$ (- \infty , - 4) \cup (5, + \infty) \tag {2} $$
>
> > [!note]- **【分析】**
> > （ $^{1}$ ）由集合的交集和并集的定义运算即可；
> >
> > (2) 由已知可得 $A \subseteq B$ ，进而得到 $a + 3 < -1$ 或 $a > 5$ ，求解即可·
>
> > [!note]- **【解析】**
> > （1）当 $a = 4$ 时， $A = \{x \mid 4 \leq x \leq 7\}$
> >
> > 因为 $B = \{x\mid x <   - 1$ 或 $x > 5\}$
> >
> > 所以 $A \cap B = \left\{ x \mid 5 < x \leq 7 \right\}$ ， $A \cup B = \left\{ x \mid x < -1 \text{ 或 } x \quad 4 \right\}$ ;
> >
> > (2) 因为“ $\forall x\in A$ ，都有 $x\in B$ ”是真命题，所以 $A\subseteq B$
> >
> > 因为集合 $A = \{x\mid a\leq x\leq a + 3\}$ ，集合 $B = \{x\mid x <   - 1$ 或 $x > 5\}$
> >
> > 所以 $a + 3 < -1$ 或 a > 5 ，
> >
> > 即 $a < -4$ 或 $a > 5$ ，所以实数 $a$ 的取值范围 $(- \infty, -4) \cup (5, +\infty)$ .
