> [!faq]- 《专题1_3_集合的基本运算_高效培优讲义_》官方解析
>
> > [!success]- **【答案】** (1) p = 8, a = 5, b = -6; (2) $m = 0$ 或 $m = -1$ 或 $m = -\frac{2}{3}$ .
>
> > [!note]- **【分析】**
> > （1）根据交集结果有 $3^{2}-3p+15=0$ 求 p，再由并集结果有 $B=\{2,3\}$ ，结合根与系数关系求参数值；
> >
> > (2) 由包含关系并讨论 $C = \varnothing$ 、 $C \neq \varnothing$ 求对应参数值，即可得
>
> > [!note]- **【解析】**
> > （1）由 $A \cap B = \{3\}$ ，故 $3^2 - 3p + 15 = 0$ ，可得 $p = 8$ ，则 $A = \{x \mid x^2 - 8x + 15 = 0\} = \{3, 5\}$
> >
> > 又 $A \cup B = \{2, 3, 5\}$ ，则 $B = \{x \mid x^2 - ax - b = 0\} = \{2, 3\}$ ，故 $a = 5, b = -6$ ；
> >
> > 所以 p = 8 ， a = 5, b = -6 ；
> >
> > (2) 由 $C \subseteq B$
> >
> > 若 $C = \varnothing$ ，即 m = 0，满足题设，
> >
> > 若 $C \neq \emptyset$ ，即 $m \neq 0$ ，则 $2m + 2 = 0 \Rightarrow m = -1$ ，或 $3m + 2 = 0 \Rightarrow m = -\frac{2}{3}$ ，
> >
> > 综上，m=0 或 m=-1 或 $m=-\frac{2}{3}$
