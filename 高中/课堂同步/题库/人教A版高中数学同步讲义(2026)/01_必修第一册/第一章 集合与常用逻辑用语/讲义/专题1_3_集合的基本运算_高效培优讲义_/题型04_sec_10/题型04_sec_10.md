## 题型04：集合的交集、并集与补集的混合运算

【典例1】设集合 $A = \{x\mid 0\leq x <   1\}$ ， $B = \left\{x\middle |x - \frac{1}{2}\right\}$ ，则 $A\cap \tilde{\mathfrak{O}}_{\mathrm{R}}B = (\quad)$ A. $\{x\mid 0 <   x <   1\}$ B. $\left\{x\middle |\frac{1}{2} <  x <   1\right\}$ C. $\left\{x\middle |\frac{1}{2}\leq x <   1\right\}$ D. $\left\{x\middle |0\leq x <   \frac{1}{2}\right\}$

【答案】D

【分析】根据给定条件，利用补集、交集的定义求解·

【详解】依题意， $\check{Q}_{R}B=\left\{x\mid x<\frac{1}{2}\right\}$ ，而 $A=\left\{x\mid0\leq x<1\right\}$

所以 $A I \breve{Q}_{R} B = \{x \mid 0 \leq x < \frac{1}{2}\}$

故选：D
