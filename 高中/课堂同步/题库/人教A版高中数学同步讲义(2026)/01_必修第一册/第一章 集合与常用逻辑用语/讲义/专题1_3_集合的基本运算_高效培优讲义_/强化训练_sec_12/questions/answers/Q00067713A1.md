> [!faq]- 《专题1_3_集合的基本运算_高效培优讲义_》官方解析
>
> > [!success]- **【答案】** A
>
> > [!note]- **【分析】**
> > 根据题设新定义的概念以及集合的基本运算法则计算即可得结果·
>
> > [!note]- **【解析】**
> > 对于 $\mathbb{A}$ ，由 $A = \{1,2,3\}, B = \{2,3,4\}, C = \{4,5\}$ ，则 $A \cup B = \{1,2,3,4\}, A \cap B = \{2,3\}$
> >
> > 所以 $A\triangle B=\{1,4\}$ ，故 A 正确；
> >
> > 对于 B，由 $A \cup \varnothing = A, A \cap \varnothing = \varnothing$ ，所以 $A \triangle \varnothing = A$ ，故 B 错误；
> >
> > 对于 $C$ ，由 $(A\triangle B) \cup C = \{1, 4, 5\}, (A\triangle B) \cap C = \{4\}$ ，则 $(A\triangle B)\triangle C = \{1, 5\}$
> >
> > 由 $B \cup C = \{2, 3, 4, 5\}$ ， $B \cap C = \{4\}$ ，则 $B \triangle C = \{2, 3, 5\}$ ，
> >
> > 所以 $A \cup (B \triangle C) = \{1, 2, 3, 5\}$ ， $A \cap (B \triangle C) = \{2, 3\}$ ，则 $A \triangle (B \triangle C) = \{1, 5\}$
> >
> > 所以 $(A\triangle B)\triangle C = A\triangle (B\triangle C)$ ，故 $C$ 错误；
> >
> > 对于 D，当 $B = \varnothing$ 时，结合选项 B 知， $A \triangle B = A$ ，故 D 错误。
> >
> > 故选：A.
> >
> > 6. [多选题]对于数集 $A, B$ ，它们的 Descartes 积 $A \times B = \{(x, y) | x \in A, y \in B\}$ ，则（）
> >
> > 【答案】
> > A. $A \times B = B \times A$ B. 若 $A \subseteq C$ ，则 $(A \times B) \subseteq (C \times B)$ C. $A \times (B \cap C) = (A \times B) \cap (A \times C)$ D. 集合 $\{0\} \times \mathbf{R}$ 表示 $y$ 轴所在直线
> >
> > 【答案】BCD
> >
> > 【详解】由题知， $A \times B = \{(x, y) | x \in A, y \in B\}$ 表示数集 A 中的数表示横坐标，数集 B 中的数表示纵坐标所组
> >
> > 成的点的全体，故 $A \times B \neq B \times A$ ， $^{\mathsf{A}}$ 错误；若 $A \subseteq C$ ，则 $(A \times B) \subseteq (C \times B)$ ， $^{\mathsf{B}}$ 正确；
> >
> > $A \times (B \cap C) = \{(x, y) | x \in A, y \in (B \cap C)\}, (A \times B) \cap (A \times C) = \{(x, y) | x \in A, y \in B\} \cap \{(x, y) | x \in A, y \in C\}$ ，则 $A \times (B \cap C) = (A \times B) \cap (A \times C)$ $^{C}$ 正确；集合 $^{0} \times R$ 表示 y 轴所在直线， $^{D}$ 正确。
