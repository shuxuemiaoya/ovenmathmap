> [!faq]- 《专题1_3_集合的基本运算_高效培优讲义_》官方解析
>
> > [!success]- **【答案】** $\{x \mid x < 2 \text{ 或 } x \quad 3\} \quad \{a \mid 2 \leq a \leq 3\}$
>
> > [!note]- **【解析】**
> > （1）当 $a = 3$ 时， $B = \{x \mid 3 \leq x \leq 6\}$ ，则 $A \cup B = \{x \mid x < 2 \text{ 或 } x \quad 3\}$
> >
> > (2) 因为 $A \cap B = \emptyset$ ，又 $B \neq \emptyset$ ，所以 $\left\{ \begin{array}{ll} a & 2, \\ a + 3 \leq 6, & \text{解得 } 2 \leq a \leq 3 \end{array} \right.$ . 故实数 $a$ 的取值范围是 $\{a \mid 2 \leq a \leq 3\}$
