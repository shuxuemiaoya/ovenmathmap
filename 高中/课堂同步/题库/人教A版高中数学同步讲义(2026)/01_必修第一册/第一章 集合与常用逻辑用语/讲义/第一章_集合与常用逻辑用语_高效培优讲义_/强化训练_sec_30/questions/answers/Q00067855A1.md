> [!faq]- 《第一章_集合与常用逻辑用语_高效培优讲义_》官方解析
>
> > [!success]- **【答案】** (1) $A \cup B = \{x \mid 0 < x < 7\}$ ， $\left(\tilde{\mathfrak{Q}}_U A\right) \cup \left(\tilde{\mathfrak{Q}}_U B\right) = \{x \mid x \leq 1, x \geq 2\}$ (2) $\left\{a \mid -\frac{1}{2} \leq a \leq 1\right\}$ (3) $\left\{a \mid a \leq -4\right\}$ .
>
> > [!note]- **【解析】**
> > （1）因为 $a = 2$ ，所以 $B = \{x\mid 1 <   x <   7\}$ ，又 $A = \{x\mid 0 <   x <   2\}$
> >
> > 所以 $A \cup B = \{x \mid 0 < x < 7\}$
> >
> > 方法一 因为 $\breve{\mathfrak{Q}}_{U}A=\left\{x\mid x\leq0\text{ 或 }x\quad2\right\}$ ， $\breve{\mathfrak{Q}}_{U}B=\left\{x\mid x\leq1\text{ 或 }x\quad7\right\}$
> >
> > 所以 $\left(\check{\mathfrak{Q}}_{U}A\right)\cup\left(\check{\mathfrak{Q}}_{U}B\right)=\left\{x\mid x\leq1\quad x\quad2\right\}$
> >
> > 方法二 $A \cap B = \{x \mid 1 < x < 2\}, (\tilde{\mathbf{Q}}_U A) \cup (\tilde{\mathbf{Q}}_U B) = \tilde{\mathbf{Q}}_U (A \cap B) = \{x \mid x \leq 1 \text{或} x = 2\}$
> >
> > (2) 因为 $A \cup B = B$ ，所以 $A \subseteq B$ ，
> >
> > 又 $A = \{x\mid 0 <   x <   2\} ,B = \{x\mid a - 1 <   x <   2a + 3\}$ ，所以 $\left\{ \begin{array}{ll}2a + 3 & 2,\\ a - 1\leq 0, & \text{解得} \end{array} \right. - \frac{1}{2}\leq a\leq 1$
> >
> > 所以 $a$ 的取值范围是 $\left\{a\left| -\frac{1}{2} \leq a \leq 1 \right. \right\}$
> >
> > (3) 因为 $A \cap B = B$ ，所以 $B \subseteq A$ （ $B \subseteq A$ ），分为 $B = \emptyset$ 与 $B \neq \emptyset$ 两种情况讨论）.
> >
> > 若 $B = \varnothing$ ，则 $2a + 3 \leq a - 1$ ，可得 $a \leq -4$ ，满足 $B \subseteq A$ ；
> >
> > 若 $B \neq \emptyset$ ，要使 $B \subseteq A$ ，则 $\left\{ \begin{array}{l} 2a + 3 > a - 1, \\ 2a + 3 \leq 2, \\ a - 1 \quad 0, \end{array} \right.$ 不等式组无解。
> >
> > 综上， $a$ 的取值范围是 $\{a|a\leq -4\}$
