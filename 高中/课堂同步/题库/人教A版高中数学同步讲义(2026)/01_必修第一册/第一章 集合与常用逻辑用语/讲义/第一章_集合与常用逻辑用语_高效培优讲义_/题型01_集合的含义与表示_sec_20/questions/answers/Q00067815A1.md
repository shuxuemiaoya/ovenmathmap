> [!faq]- 《第一章_集合与常用逻辑用语_高效培优讲义_》官方解析
>
> > [!success]- **【答案】** B
>
> > [!note]- **【解析】**
> > 根据定义可知 $C(A) = 2$ ，又 $A*B = 1$ ，所以可得 $C(B) = 1$ 或 $C(B) = 3$ ；由方程 $\left(x^{2} + ax\right)\left(x^{2} + ax + 2\right) = 0$ 可得 $x^{2} + ax = 0$ 或 $x^{2} + ax + 2 = 0$ ；当 $C(B) = 1$ 时，方程 $\left(x^{2} + ax\right)\left(x^{2} + ax + 2\right) = 0$ 只有一个实数根，此时 $a = 0$ ，符合题意；当 $C(B) = 3$ 时，必有 $a \neq 0$ ，此时方程 $x^{2} + ax = 0$ 有两个不相等的实数根 $x_{1} = 0, x_{2} = -a$ 显然 $x_{1}=0, x_{2}=-a$ 都不是方程 $x^{2}+ax+2=0$ 的根，
> >
> > 则方程 $x^{2} + ax + 2 = 0$ 有两个相等的实数根，且异于 $x_{1} = 0, x_{2} = -a$
> >
> > 此时 $\Delta = a^{2} - 8 = 0$ ，可得 $a = 2\sqrt{2}$ 或 $a = -2\sqrt{2}$ ，经检验均满足题意；
> >
> > 故可知 $S = \{0,2\sqrt{2}, - 2\sqrt{2}\}$ ，可得 $C(S) = 3$
> >
> > 故选 **B**
