> [!faq]- 《专题1.1 集合的概念（高效培优讲义）》官方解析
>
> > [!success]- **【答案】** B
>
> > [!note]- **【分析】**
> > 利用集合中元素的互异性，对 $a, b$ 的取值进行分类讨论即可·
>
> > [!note]- **【解析】**
> > 由题意， $x = 2a - b$ ，
> > 当 $a = 1, b = 3$ 时， $x = 2a - b = -1$ ，
> > 当 $a = 1, b = 5$ 时， $x = 2a - b = -3$ ，
> > 当 $a = 2, b = 3$ 时， $x = 2a - b = 1$ ，
> > 当 $a = 2, b = 5$ 时， $x = 2a - b = -1$ ，
> > 当 $a = 3, b = 3$ 时， $x = 2a - b = 3$ ，
> > 当 $a = 3, b = 5$ 时， $x = 2a - b = 1$ ，
> > 由集合中元素满足互异性，所以 $C = \{-3, -1, 1, 3\}$ 。
> >
> > 故选：B.

> > 14. 给出下列关系：① $|-2|\notin N^{*}$ ；
> > - **②**：$0\notin Z$ ；
> > - **③**：$\sqrt{2}\in Q$ ；
> > - **④**：$-\frac{3}{2}\in R$ ；
> > - **⑤**：$1.21\in Q$ .其中错误的个数是（）
> >
> > 【答案】
> > A. 1 B. 2 C. 3 D. 4
> >
> > 【答案】C
> >
> > 【分析】依次判断出各数所属于的数域范围，再利用元素与集合的关系判定即可·
> >
> > 【详解】对于命题①， $\left|-2\right|=2\in N^{*}$ ，所以命题①错误，
> >
> > 对于命题②， $0 \in \mathbb{Z}$ ，所以命题②错误，
> >
> > 对于命题③，因为 $\sqrt{2}$ 是无理数， $\sqrt{2} \notin Q$ ，所以命题③错误，
> >
> > 对于命题④，因为 $-\frac{3}{2} \in \mathbb{R}$ ，所以命题④正确，
> >
> > 对于命题⑤，因为1.21是无限循环小数，是有理数，即 $1.21\in Q$ ，所以命题⑤正确，
> >
> > 故选：C.

> > 15. 不等式 $\frac{|x|+1}{x-2}$ 0 的解集是（）
> >
> > 【答案】
> >
> > A. $(2,+\infty)$ B. $[-1,2)$ C. $[2,+\infty)$ D. $(-\infty,-1)\cup(2,+\infty)$
> >
> > 【答案】A
> >
> > 【分析】根据绝对值性质分析可得 $x - 2 > 0$ ，运算求解即可·
> >
> > 【详解】对于不等式 $\frac{|x| + 1}{x - 2}$ 0
> >
> > 因为 $\left|x\right|+1$ 1>0 ，可得 x-2>0 ，解得 x>2 ，
> >
> > 所以不等式 $\frac{|x|+1}{x-2}$ 0 的解集是 $(2,+\infty)$ .
> >
> > 故选 **A**.
