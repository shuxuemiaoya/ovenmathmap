> [!faq]- 《第一章 集合与常用逻辑用语（高效培优单元测试·提升卷）》官方解析
>
> > [!success]- **【答案】** (1) $A \cup (\tilde{\mathfrak{Q}}_U B) = \left\{ x \mid x \leq 3 \text{ 或 } x \quad 6 \right\}$ (2) $(-∞,-1]∪[0,1]$
>
> > [!note]- **【分析】**
> > （1）根据并集与补集的运算求解即可；
> >
> > (2) 分 $B = \emptyset$ 与 $B \neq \emptyset$ 由条件列不等式求范围即可.
>
> > [!note]- **【解析】**
> > （1）当 $a = 2$ 时， $B = \{x \mid 0 < x < 6\}$
> >
> > 所以 $\breve{\mathbf{Q}}_{U}B=\left\{x\mid x\leq0\quad x\quad6\right\}$ ，又 $A=\left\{x\mid-2\leq x\leq3\right\}$
> >
> > 所以 $A \cup (\tilde{\mathfrak{Q}}_{U} B) = \left\{ x \mid x \leq 3 \text{ 或 } x \quad 6 \right\}$ ;
> >
> > (2) 当 $B = \varnothing$ 时，有 a - 2、3a，解得 $a \leq -1$ ；
> >
> > 当 $B \neq \varnothing$ 时，有 $\left\{\begin{aligned}a-2&<3a\\ a-2&-2\\ 3a&\leq3\end{aligned}\right.$ ，解得 $0\leq a\leq1$ ，综上所述 a 的取值范围为 $(-∞,-1]∪[0,1]$ .
