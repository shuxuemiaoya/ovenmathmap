> [!faq]- 《第一章 集合与常用逻辑用语（高效培优单元测试·提升卷）》官方解析
>
> > [!success]- **【答案】** (1) $\tilde{Q}_{R}A=\left\{\left|x<x<-2\right.x>3\right\},\quad\left(\tilde{Q}_{R}B\right)\cap A=\left\{\left|x-2\leq x<1\right\}\right.$ (2) $\{m\mid m\leq-3\quad m\quad1\}$ 或
>
> > [!note]- **【分析】**
> > （1）求出集合A然后求其补集即可，求出集合B的补集，再求与集合A的交集即可·
> >
> > (2) 由题意可得 $A \cap C = \emptyset$ ，讨论集合 $C$ 是否为空集即可.
>
> > [!note]- **【解析】**
> > （1）集合 $A = \{\not k - 2\leq x\leq 3\}$ ， $B = \{\not k x <   - 3$ 或 $x = 1\}$
> >
> > 则 $\check{\mathbf{Q}}_{\mathrm{R}}A = \{\nmid x < -2 \text{ 或 } x > 3\}$ ， $\check{\mathbf{Q}}_{\mathrm{R}}B = \{\nmid -3 \leq x < 1\}$ ，则 $(\check{\mathbf{Q}}_{\mathrm{R}}B)\cap A = \{\nmid -2 \leq x < 1\}$
> >
> > (2) $\forall x \in C, x \notin A$ 为真命题，即 $A \cap C = \varnothing$
> >
> > 又 $C = \{x2m < x < m + 1\} A = \{x - 2 \leq x \leq 3\}$
> >
> > 当 $C = \varnothing$ 时，2m m + 1，即 m 1，此时 $A \cap C = \varnothing$ ，符合题意；
> >
> > 当 $C \neq \emptyset$ 时，由 $A \cap C = \emptyset$ 可得 $\left\{ \begin{array}{l} 2m < m + 1 \\ m + 1 \leq -2 \end{array} \right.$ 或 $\left\{ \begin{array}{c} 2m < m + 1 \\ 2m - 3 \end{array} \right.$ ，解得 $m \leq -3$ ，
> >
> > 综上， $m$ 的取值范围为： $\{m \mid m \leq -3 \text{ 或 } m = 1\}$ 。
