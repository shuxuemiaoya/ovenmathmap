> [!faq]- 《专题04 充分条件与必要条件五大常考题型（高效培优专项训练）》官方解析
>
> > [!success]- **【答案】** $$ b ^ {2} + c ^ {2} - 2 (b + c) = b c - 4 $$
>
> > [!note]- **【分析】**
> > 根据题意，结合充分性和必要性的证明方法，结合多项式的化简、运算，即可求解·
>
> > [!note]- **【解析】**
> > 证明：充分性：
> >
> > 当 $a = 2$ 时，多项式 $b^{2} + c^{2} - 2(b + c) = bc - 4$ 可化为 $b^{2} + c^{2} - a(b + c) = bc - a^{2}$
> >
> > 即 $a^2 + b^2 + c^2 = ab + ac + bc$ ，所以 $2a^2 + 2b^2 + 2c^2 = 2ab + 2ac + 2bc$
> >
> > 则 $\left(a - b\right)^2 +\left(b - c\right)^2 +\left(a - c\right)^2 = 0$ ，所以 $a - b = b - c = a - c = 0$
> >
> > 即 $a = b = c$ ，VABC为等边三角形，即充分性成立；
> >
> > 必要性：由VABC为等边三角形，且a=2，所以a=b=c=2
> >
> > 则 $b^{2} + c^{2} - 2(b + c) = 0$ ， $bc - 4 = 0$ ，所以 $b^{2} + c^{2} - 2(b + c) = bc - 4$ ，即必要性成立.
> >
> > 故VABC为等边三角形的充要条件是 $b^{2}+c^{2}-2(b+c)=bc-4$
