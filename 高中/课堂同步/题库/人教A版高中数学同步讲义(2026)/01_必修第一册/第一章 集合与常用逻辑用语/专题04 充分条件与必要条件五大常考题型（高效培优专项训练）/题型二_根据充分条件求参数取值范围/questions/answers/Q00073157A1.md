> [!faq]- 《专题04 充分条件与必要条件五大常考题型（高效培优专项训练）》官方解析
>
> > [!success]- **【答案】** B
>
> > [!note]- **【分析】**
> > 解不等式得到 $p: x < -3$ 或 $x > 1$ ，根据题意得到 $q$ 是 $p$ 的充分不必要条件，从而得到两不等式的包含关系，求出答案：
>
> > [!note]- **【解析】**
> > 由条件 $p: |x+1| > 2$ ，解得 x < -3 或 x > 1；
> >
> > 因为 $\neg p$ 是 $\neg q$ 的充分不必要条件，所以 q 是 p 的充分不必要条件，
> > 故 $A = \left\{ x \mid x > a \right\}$ 是 $B = \left\{ x \mid x < -3 \text{ 或 } x > 1 \right\}$ 的真子集，
> >
> > 则 $a$ 的取值范围是 $a = 1$ ，
> >
> > 故选 **B**.
