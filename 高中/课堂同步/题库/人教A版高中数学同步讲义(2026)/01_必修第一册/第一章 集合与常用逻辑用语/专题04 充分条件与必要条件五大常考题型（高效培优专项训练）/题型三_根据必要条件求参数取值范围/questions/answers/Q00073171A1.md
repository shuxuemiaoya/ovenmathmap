> [!faq]- 《专题04 充分条件与必要条件五大常考题型（高效培优专项训练）》官方解析
>
> > [!success]- **【答案】** (1) $A \cap B = \{x \mid -1 < x < 0\}$ (2) $a \in \left[-\frac{1}{2}, 0\right]$
>
> > [!note]- **【分析】**
> > （1）由 a = -1 ，可得集合 B ，进而可得 $A \cap B$ ；
> >
> > (2) 由必要不充分条件可知 A B，进而可得不等式，解不等式即可.
>
> > [!note]- **【解析】**
> > （1）当 $a = -1$ 时， $B = \{x \mid -3 < x < 0\}$
> >
> > 又 $A = \left\{x\mid -1 <   x <   \frac{1}{2}\right\}$
> >
> > 则 $A \cap B = \{x \mid -1 < x < 0\}$ ；
> >
> > (2) 由“ $x \in B$ ”是“ $x \in A$ ”的必要不充分条件，
> >
> > 可知 $\mathrm{A}^{\square}\mathrm{B}$
> >
> > 所以 $\left\{\begin{aligned}&2a-1\leq-1\\ &a+1>\frac{1}{2}\end{aligned}\right.$ 或 $\left\{\begin{aligned}&2a-1<-1\\ &a+1\quad\frac{1}{2}\end{aligned}\right.$
> >
> > 解得 $-\frac{1}{2} < a \leq 0$ 或 $-\frac{1}{2} \leq a < 0$
> >
> > 综上所述 $-\frac{1}{2} \leq a \leq 0$
> >
> > 即 $a \in \left[-\frac{1}{2}, 0\right]$ .
