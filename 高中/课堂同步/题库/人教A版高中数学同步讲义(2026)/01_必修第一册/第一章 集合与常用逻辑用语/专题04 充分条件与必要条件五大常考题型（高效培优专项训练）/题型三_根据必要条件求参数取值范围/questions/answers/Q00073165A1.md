> [!faq]- 《专题04 充分条件与必要条件五大常考题型（高效培优专项训练）》官方解析
>
> > [!success]- **【答案】** (1) $A \cap B = \{x \mid 1 \leq x < 3\}$ (2) $m \leq -2$ 或 $m = 4$
>
> > [!note]- **【分析】**
> > （1）分别求出A，B，再根据集合的交集运算即可；
> >
> > (2) 由于 $q$ 是 $p$ 的必要不充分条件，可知A是B的真子集，再根据集合关系求出 $m$ 的范围即可.
>
> > [!note]- **【解析】**
> > （1）∵ $A = \{x \mid -1 < x < 3\}$ ，
> >
> > 当 $m = 0$ 时， $B = \{x \mid x \quad 1 \text{ 或 } x \leq -1\}$
> >
> > $$
> > \therefore A \cap B = \{x \mid 1 \leq x <   3 \}
> > $$
> >
> > (2) 因为 $p: -1 < x < 3$ ， $q: x \leq m - 1$ 或 $x: m + 1$ 。
> >
> > q 是 p 的必要不充分条件，所以 m-1 3 或 $m+1 \leq -1$ ，
> >
> > 所以 $m \leq -2$ 或 $m = 4$
