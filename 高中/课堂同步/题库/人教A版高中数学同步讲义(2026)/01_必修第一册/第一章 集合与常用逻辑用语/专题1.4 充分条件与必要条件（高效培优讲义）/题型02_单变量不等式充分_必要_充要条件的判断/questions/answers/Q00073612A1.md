> [!faq]- 《专题1.4 充分条件与必要条件（高效培优讲义）》官方解析
>
> > [!success]- **【答案】** B
>
> > [!note]- **【解析】**
> > 对于选项 A， $\frac{1}{2}<x\leq3$ 是 $-\frac{1}{2}<x<3$ 成立的一个既不充分也不必要条件，故 A 错误；对于选项 B， $-\frac{1}{2}<x<0$ 是 $-\frac{1}{2}<x<3$ 成立的一个充分条件，故 B 正确；对于选项 C， $-1<x<6$ 是 $-\frac{1}{2}<x<3$ 成立的一个必要条件，故 C 错误；对于选项 D， $-3<x<\frac{1}{2}$ 是 $-\frac{1}{2}<x<3$ 成立的一个既不充分也不必要条件，故 D 错误。
> >
> > ## 方法技巧
> >
> > 结论：小范围可以推出大范围，大范围不能推出小范围
> >
> > 范围求解的类型（单变量）
> >
> > 类型1：绝对值不等式的求解
> >
> > 形如： $\left|ax+b\right|$ $c(a>0)$ 根据大于去两边原则
> >
> > $ax + b$ $c$ 或 $ax + b\leq -c\Rightarrow x$ $\frac{c - b}{a}$ 或 $x\leq \frac{-c - b}{a}$
> >
> > 形如： $\left|ax+b\right|\leq c(a>0)$ 根据小于取中间原则
> >
> > $$
> > - c \leq a x + b \leq c \Rightarrow \frac {- c - b}{a} \leq x \leq \frac {c - b}{a}
> > $$
> >
> > 形如： $\left|ax+b\right|$ $c(a<0)$ 根据大于去两边原则
> >
> > 变形 $\left|ax+b\right|\quad c(a<0)\Rightarrow\left|-ax-b\right|\quad c(a<0)$
> >
> > $-ax - b$ $c$ 或 $-ax - b \leq -c \Rightarrow x$ $\frac{c + b}{-a}$ 或 $x \leq \frac{-c + b}{-a}$
> >
> > 形如： $\left|ax+b\right|\leq c(a<0)$ 根据小于取中间原则
> >
> > 变形 $\left|ax+b\right|\leq c(a<0)\Rightarrow\left|-ax-b\right|\leq c(a<0)$
> >
> > $$
> > - c \leq - a x - b \leq c \Rightarrow \frac {- c + b}{- a} \leq x \leq \frac {c + b}{- a}
> > $$
> >
> > 类型2：一元二次不等式求解（十字相乘）
> >
> > 形如： $x^{2} + (p + q)x + pq$ $0(p > q)\Rightarrow (x + p)(x + q)\quad 0\Rightarrow x\quad -q$ 或 $x\leq -p$
> >
> > $$
> > x ^ {2} + (p + q) x + p q \leq 0 (p > q) \Rightarrow (x + p) (x + q) \leq 0 \Rightarrow - p \leq x \leq - q
> > $$
> >
> > 形如： $x^{2} - (p + q)x + pq$ $0(p > q)\Rightarrow (x - p)(x - q)$ $0\Rightarrow x$ $p$ 或 $x\leq q$ $x^{2} - (p + q)x + pq\leq 0(p > q)\Rightarrow (x - p)(x - q)\leq 0\Rightarrow q\leq x\leq p$
> >
> > 类型 3：分式方程不等式求解（分式整数化）
> >
> > 形如： $\frac{x-b}{x-a}\quad0(a>b)\Rightarrow(x-b)\cdot(x-a)\quad0\Rightarrow$ 大于取两边 $\left\{\begin{aligned}x&a,x\leq b\\ &x\neq a\end{aligned}\right.$
> >
> > 故解集为 $x > a, x \leq b$
> >
> > 形如： $\frac{x - b}{x - a}\leq 0(a > b)\Rightarrow (x - b)\cdot (x - a)\leq 0\Rightarrow$ 大于取两边 $\left\{ \begin{array}{l}b\leq x\leq a\\ x\neq a \end{array} \right.$
> >
> > 故解集为 $b \leq x < a$
