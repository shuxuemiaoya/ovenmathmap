> [!faq]- 《专题1.4 充分条件与必要条件（高效培优讲义）》官方解析
>
> > [!success]- **【答案】** D
>
> > [!note]- **【解析】**
> > 解法 $^{1}$ $\left\{\left|x^{2}+x-6=0\right|\right\}=\{2,-3\}$ ．因为p是q的必要条件，所以 $\left\{\left|x^{2}+mx+1=0\right|\right\}\left\{2,-3\right\}$ ．当
> >
> > $\{x mx + 1 = 0\} = \emptyset$ ，即 $m = 0$ 时，符合题意；当 $\{x mx + 1 = 0\} \neq \emptyset$ 时，由 $\{x mx + 1 = 0\} \square \{2, -3\}$ ，得 $-\frac{1}{m} = 2$ 或 $-\frac{1}{m} = -3$ ，解得 $m = -\frac{1}{2}$ 或 $m = \frac{1}{3}$ 。综上所述， $m$ 的值为 $0$ 或 $-\frac{1}{2}$ 或 $\frac{1}{3}$ 。
> >
> > 解法 $^{2}$ （代入法） $\left\{\begin{matrix}x^{2}+x-6=0\end{matrix}\right\}=\{2,-3\}$ ，当m=0时， $\left\{\begin{matrix}mx+1=0\end{matrix}\right\}=\varnothing$ ，符合题意；当 $m=-\frac{1}{2}$ 时，
> >
> > $\{x mx + 1 = 0\} = \{2\}$ ；当 $m = \frac{1}{3}$ 时， $\{x mx + 1 = 0\} = \{-3\}$ ，均满足题意。
