> [!faq]- 《专题04_充分条件与必要条件五大常考题型_高效培优专项训练_》官方解析
>
> > [!success]- **【答案】** (1) $A \cup B = \{\mid x < -3 \text{ 或 } x > -2\}$ ， $A \cap B = \{\mid x < 1 < x < 3\}$ (2) $\left[\frac{5}{2}, 3\right] \cup [4, +\infty)$
>
> > [!note]- **【分析】**
> > （ $^{1}$ ）解一元二次不等式、分式不等式求集合，再应用集合的交运算求集合；
> >
> > (2) 由必要不充分条件有 $C^{\square}(A \cap B)$ ，进而分情况求解参数范围·
>
> > [!note]- **【解析】**
> > （1）由题意知：集合 $A = \{x - 2 < x < 3\}$
> >
> > 集合 $B = \{\mid x > 1\text{或} x < -3\}$
> >
> > 所以 $A \cup B = \{\left\{ x < -3 \text{ 或 } x > -2 \right\}$ ， $A \cap B = \{\left\{ x1 < x < 3 \right\}$ ;
> >
> > (2) 由“ $x \in A \cap B$ 是 $x \in C$ 的必要不充分条件”知： $C^{\square}(A \cap B)$
> >
> > 当 $C = \varnothing$ 时，2a - 4 a ，即 a 4 ，符合题意，
> >
> > 当时， $\left\{ \begin{array}{ll}2a - 4 <   a\\ 2a - 4 & 1\\ a\leqslant 3 \end{array} \right.$ ，即 $\frac{5}{2}\leqslant a\leqslant 3$
> >
> > 综上所述，实数 $m$ 的取值范围是 $\left[\frac{5}{2},3\right]\cup \left[4, + \infty\right)$
