> [!faq]- 《专题03集合的基本运算五大常考题型_高效培优专项训练_》官方解析
>
> > [!success]- **【答案】** (1) $A \cup B = \{x \mid -9 \leq x \leq 5\}$ , $A \cap (\check{\mathfrak{Q}}_U B) = \{x \mid 2 < x \leq 5\}$ ; (2) $\left\{a\mid a<\frac{1}{3}\right\}$ .
>
> > [!note]- **【分析】**
> > （ $^{1}$ ）根据并集与交集，补集的概念直接计算·
> >
> > (2) 根据集合间的包含关系，列不等式，解不等式即可·
>
> > [!note]- **【解析】**
> > （1）因为 a = 4，所以 $B = \left\{ x \mid -9 \leq x \leq 2 \right\}$ .
> >
> > 因为 $A = \{x\mid 1\leq x\leq 5\}$ ，所以 $A\cup B = \{x\mid -9\leq x\leq 5\}$
> >
> > 因为 U = R ，所以 $\tilde{Q}_{U}B = \left\{ x \mid x < -9 \text{ 或 } x > 2 \right\}$ ，所以 $A \cap (\tilde{Q}_{U}B) = \left\{ x \mid 2 < x \leq 5 \right\}$ .
> >
> > (2) 因为 $B \subseteq A$ .
> > - **①**：当 $B = \varnothing$ 时，满足 $B \subseteq A$ ，此时 $-1 - 2a > a - 2$ ，解得 $a < \frac{1}{3}$ ;
> > - **②**：当时，要满足，则 $\left\{ \begin{array}{ll} -1 - 2a & 1,\\ a - 2\leq 5, & \\ -1 - 2a\leq a - 2, & a\in \emptyset \end{array} \right.$ 解得
> >
> > 综上所述，实数 $a$ 的取值范围是 $\left\{a \mid a < \frac{1}{3}\right\}$ .
