> [!faq]- 《专题03集合的基本运算五大常考题型_高效培优专项训练_》官方解析
>
> > [!success]- **【答案】** (1) $A \cup B = \{x \mid 2 \leq x < 10\}$ ， $\tilde{\mathbf{Q}}_{\mathbb{R}} A = \{x \mid x < 2 \text{ 或 } x \quad 7\}$ . (2) $a > 2$
>
> > [!note]- **【分析】**
> > （ $^{1}$ ）根据并集和补集的概念计算；
> >
> > (2) 根据 $A \cap C \neq \varnothing$ ，可以知道两个集合数轴上表示，要有公共部分，比较端点即可·
>
> > [!note]- **【解析】**
> > （1）因为 $A = \{x\mid 2\leq x <   7\} ,B = \{x\mid 3 <   x <   10\} ,$
> >
> > 所以 $A \cup B = \{x \mid 2 \leq x < 10\}$ ，所以 $\tilde{\mathbf{Q}}_{\mathbb{R}} A = \{x \mid x < 2$ 或 $x = 7\}$ .
> >
> > (2) 因为 $A = \{x \mid 2 \leq x < 7\}, C = \{x \mid x < a\}$ ，且 $A \cap C \neq \emptyset$ ，即集合数轴表示要有公共部分，
> >
> > 所以 a > 2 ，即 a 的取值范围是 a > 2 .
