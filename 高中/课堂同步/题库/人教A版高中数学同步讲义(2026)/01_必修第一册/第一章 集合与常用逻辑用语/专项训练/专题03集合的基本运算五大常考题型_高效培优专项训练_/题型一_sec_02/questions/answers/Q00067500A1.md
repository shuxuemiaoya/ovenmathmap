> [!faq]- 《专题03集合的基本运算五大常考题型_高效培优专项训练_》官方解析
>
> > [!success]- **【答案】** (1) $\tilde{\mathbf{Q}}_{\mathbb{R}}(A\cup B)=\left\{\begin{matrix}x&x<-1\\ x&7\end{matrix}\right.$ 或 $x=7\}$ (2) $a \leq \frac{8}{3}$
>
> > [!note]- **【分析】**
> > （ $^{1}$ ）利用集合的运算求解即可；
> >
> > (2) 分类讨论集合 A 是否为空集即可·
>
> > [!note]- **【解析】**
> > （1）当 $a = 3$ 时， $A = \{\vert x4 < x < 7\}, B = \{\vert x - 1 \leq x \leq 6\}$ ，
> >
> > 因此 $A \cup B = \{x - 1 \leq x < 7\}$
> >
> > 所以 $\tilde{\mathbf{Q}}_{\mathbf{R}}(A\cup B)=\{\nmid x<-1$ 或 x 7}.
> >
> > (2) 由 $A \cap B = A$ ，得 $A \subseteq B$ ，
> >
> > 当 $A = \emptyset$ 时，则 $a + 1 \quad 3a - 2$ ，解得 $a \leq \frac{3}{2}$ ，满足 $A \subseteq B$ ，因此 $a \leq \frac{3}{2}$ ；
> >
> > 当 $A \neq \emptyset$ 时，由 $A \subseteq B$ ，得 $-1 \leq a + 1 < 3a - 2 \leq 6$ ，解得 $\frac{3}{2} < a \leq \frac{8}{3}$
> >
> > 所以实数 a 的取值范围是 $a \leq \frac{8}{3}$ .
