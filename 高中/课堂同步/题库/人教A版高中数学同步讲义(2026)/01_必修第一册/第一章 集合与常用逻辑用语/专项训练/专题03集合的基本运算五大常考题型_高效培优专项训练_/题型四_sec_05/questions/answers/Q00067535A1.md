> [!faq]- 《专题03集合的基本运算五大常考题型_高效培优专项训练_》官方解析
>
> > [!success]- **【答案】** (1) $A \cap B = \{x \mid 1 \leq x < 2\}$ ， $A \cup B = \{x \mid -2 < x \leq 2\}$ (2) $\left\{a\mid a-1\right\}$
>
> > [!note]- **【分析】**
> > （1）计算集合 $B$ ，根据集合交集并集定义计算即可；
> >
> > (2) 由 $\left(\check{\mathbf{Q}}_{\mathbf{R}}A\right) \cap B = B$ 可得 $B \subseteq \check{\mathbf{Q}}_{\mathbf{R}}A$ ，分 $a = 0$ 和 $a < 0$ 两种情况讨论即可.
>
> > [!note]- **【解析】**
> > （1）当 $a = -2$ 时， $B = \{x \mid |x| - 2 < 0\} = \{x \mid -2 < x < 2\}$
> >
> > 所以 $A \cap B = \{x \mid 1 \leq x < 2\}$ ， $A \cup B = \{x \mid -2 < x \leq 2\}$
> >
> > (2) 由题意，得 $\check{\mathbf{Q}}_{\mathrm{R}} A = \{x \mid x < 1 \text{ 或 } x > 2\}$ ，
> >
> > 因为 $\left( \tilde{\mathfrak{d}}_{\mathbf{R}} A \right) \cap B = B$ ，所以 $B \subseteq \tilde{\mathfrak{d}}_{\mathbf{R}} A$
> > - **①**：当 a 0 时， $B = \varnothing$ ，满足 $B \subseteq \breve{\partial}_{R} A$ ；
> > - **②**：当 a < 0 时， $B = \left\{ x \mid |x| + a < 0 \right\} = \left\{ x \mid a < x < -a \right\}$
> >
> > 所以 $\left\{x \mid a < x < -a\right\} \subseteq \left\{x \mid x < 1 \text{ 或 } x > 2\right\}$
> >
> > 所以 $\left\{ \begin{array}{l}a <   0\\ -a\leq 1 \end{array} \right.$ ，解得 $-1\leq a <   0$
> >
> > 综上所述，实数 $a$ 的取值范围是 $\{a \mid a - 1\}$ .
