> [!faq]- 《专题01集合概念的两大常考题型_高效培优专项训练_》官方解析
>
> > [!success]- **【答案】** (1) $A \cup B = \{-1, 0, 1, 2\}$ . (2)不存在,证明见解析; (3) $a = 0, a = 3$ .
>
> > [!note]- **【分析】**
> > 解:(1)将 $a = -1$ 代入集合中,再求出 $A \cup B$ 即可.(2)不存在·证明:若 $A \cap B = \{0\}$ ,则 $0 \in A = \{1,2,a\}$ 且 $0 \in B = \left\{a^2, a + 1\right\}$ ,将 $a = 0$ 代入集合 A 和 B 中,再求交集,得出 $A \cap B = \{0,1\}$ ,与 $A \cap B = \{0\}$ 矛盾,故不存在·
> >
> > (3)根据 $A = \{1,2,a\}$ 得出 $C = \{1,4,a^2\}$ ，再根据 $B \cup C$ 中恰好有 3 个元素·即可得出满足条件的实数 $a$ 的值·
>
> > [!note]- **【解析】**
> > 解:(1)当a=-1时,
> >
> > $$
> > A = \{1, 2, - 1 \}, B = \{1, 0 \}
> > $$
> >
> > 所以 $A \cup B = \left\{-1, 0, 1, 2\right\}$ .
> >
> > (2)不存在实数 $a$ ，使得 $A\cap B = \{0\}$
> >
> > 证明: 若 $A \cap B = \{0\}$ ，则 $0 \in A = \{1, 2, a\}$ ，且 $0 \in B = \left\{a^{2}, a + 1\right\}$ ，
> >
> > 所以 $a = 0$ ，则 $A = \{1,2,0\} ,B = \{0,1\}$
> >
> > 则 $A \cap B = \{0,1\}$ , 与 $A \cap B = \{0\}$ 矛盾,
> >
> > 故不存在实数 $a$ ，使得 $A \cap B = \{0\}$
> >
> > (3) 因为 $C = \left\{ y \mid y = x^{2}, x \in A \right\}$ , $A = \{1, 2, a\}$
> >
> > 所以 C 含有 $1,4,a^{2}$
> >
> > $B=\left\{a^{2},a+1\right\},B\cup C$ 含有 $1,4,a^{2},a+1$
> >
> > 又因为 $B \cup C$ 中恰好有 3 个元素，
> >
> > 所以当 $a + 1 = 1$ 时， $a = 0$ ， $B \cup C = \{1, 4, 0\}$ ，
> >
> > 当 $a+1=4$ , a=3, $B \cup C = \{1,4,9\}$ ,
> >
> > 所以满足条件的实数 a 的值有 a = 0, a = 3.
>
> > [!tip]- **【名师点睛】**
> > 本题考查集合的基本性质和集合的基本运算·注意集合的互异性是解题中容易出错的地方·38．已知集合 $A=\left\{0,m,m+1\right\}$ ，且 $2\in A$ ，则实数m的值为\_\_\_\_.
> >
> > 【答案】 $^{1}$ 或 $^{2}$
> >
> > 【分析】分别讨论 m=2 或 m=1，并根据元素的互异性检验即可
> >
> > 【详解】因为集合 $A=\left\{0,m,m+1\right\}$ ，且 $2\in A$ ，
> >
> > 所以 $m = 2$ 或 $m + 1 = 2$ ，解得 $m = 2$ 或 $m = 1$ ，
> >
> > 当 $m = 2$ ，集合 $A = \{0,2,3\}$ ，满足题意；
> >
> > 当 $m = 1$ ，集合 $A = \{0,1,2\}$ ，满足题意；
> >
> > 故答案为： $^{1}$ 或 $^{2}$
