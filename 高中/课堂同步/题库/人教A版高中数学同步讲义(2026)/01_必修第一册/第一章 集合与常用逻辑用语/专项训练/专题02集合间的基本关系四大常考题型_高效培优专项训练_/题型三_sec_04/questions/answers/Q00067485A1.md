> [!faq]- 《专题02集合间的基本关系四大常考题型_高效培优专项训练_》官方解析
>
> > [!success]- **【答案】** (1) $a < -8$ 或 $a = 2$ (2) $a = 2$
>
> > [!note]- **【分析】**
> > （1）分 $a = 0$ ， $a <   0$ ， $a > 0$ 得到集合 $A$ ，再利用 $A\subseteq B$ 求解；
> >
> > (2) 分 a = 0, a < 0, a > 0 得到集合 A，再利用 A = B 求解；
>
> > [!note]- **【解析】**
> > （1）当 $a = 0$ 时， $A = \mathrm{R}$ ， $A \subseteq B$ 不成立；
> >
> > 当时， $A = \left\{x\mid \frac{4}{a}\leq x <   - \frac{1}{a}\right\}$ ，因为所以 $\left\{ \begin{array}{ll} \frac{4}{a} > - \frac{1}{2}\\ -\frac{1}{a}\leq 2 \end{array} \right.$ ，解得；
> >
> > 当时， $A = \left\{x\mid -\frac{1}{a} <  x\leq \frac{4}{a}\right\}$ ，因为所以 $\left\{ \begin{array}{ll} \frac{4}{a}\leq 2\\ -\frac{1}{a} & -\frac{1}{2} \end{array} \right.$ ，解得
> >
> > 综上：实数 $a$ 的取值范围是 $a < -8$ 或 $a = 2$ ；
> >
> > (2) 当 a = 0 时，A = R ， A = B 不成立；
> >
> > 当 $a < 0$ 时， $A = \left\{x \mid \frac{4}{a} \leq x < -\frac{1}{a}\right\}$ ， $A = B$ ，不成立；
> >
> > 当时， $A = \left\{x\mid -\frac{1}{a} <  x\leq \frac{4}{a}\right\}$ ，因为所以 $\left\{ \begin{array}{ll}\frac{4}{a} = 2\\ -\frac{1}{a} = -\frac{1}{2} \end{array} \right.$ ，解得；
> >
> > 综上：实数 $a$ 的值是 $2$ ；
