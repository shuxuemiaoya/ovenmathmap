> [!faq]- 《专题02集合间的基本关系四大常考题型_高效培优专项训练_》官方解析
>
> > [!success]- **【答案】** $^{0}$ 或 $\frac{1}{4}$
>
> > [!note]- **【分析】**
> > 根据集合相等可得出关于实数 a、b 的方程组，利用集合元素满足互异性可求得实数 a 的值·
>
> > [!note]- **【解析】**
> > 因为集合 $A = \{a,b,2\}, B = \{2,b^2,2a\}$ ，且 $A = B$ ，分以下两种情况讨论：
> >
> > 当 $\left\{ \begin{array}{l}a = 2a\\ b = b^2 \end{array} \right.$ 时，解得 $\left\{ \begin{array}{ll}a = 0\\ b = 0 \end{array} \right.$ 或 $\left\{ \begin{array}{ll}a = 0\\ b = 1 \end{array} \right.$
> >
> > 若 $\left\{ \begin{array}{l}a = 0\\ b = 0 \end{array} \right.$ ，集合 $A$ 、 $B$ 中的元素均不满足互异性；
> >
> > 若 $\left\{ \begin{array}{l}a = 0\\ b = 1 \end{array} \right.$ ，则 $A = B = \{0,1,2\}$ ，符合题意；
> >
> > 当 $\left\{ \begin{array}{l} b = 2a \text{时，解得} \\ a = b^2 \end{array} \right.$ $\left\{ \begin{array}{l} a = 0 \text{或} \\ b = 0 \end{array} \right.$ $\left\{ \begin{array}{l} a = \frac{1}{4} \\ b = \frac{1}{2} \end{array} \right.$ ，
> >
> > 若 $\left\{ \begin{array}{l}a = 0\\ b = 0 \end{array} \right.$ ，集合 $A$ 、 $B$ 中的元素均不满足互异性；
> >
> > 若 $\left\{ \begin{array}{l}a = \frac{1}{4}\\ b = \frac{1}{2} \end{array} \right.$ ，则 $A = B = \left\{\frac{1}{4},\frac{1}{2},2\right\}$ ，符合题意；
> >
> > 综上所述， $a = 0$ 或 $a = \frac{1}{4}$
> >
> > 故答案为： $^{0}$ 或 $\frac{1}{4}$
