> [!faq]- 《专题02集合间的基本关系四大常考题型_高效培优专项训练_》官方解析
>
> > [!success]- **【答案】** B
>
> > [!note]- **【分析】**
> > 先根据题意求出集合 C，然后利用公式可求出其子集的个数·
>
> > [!note]- **【解析】**
> > 因为 $A = \{1,2,3\}, B = \{3,5\}$ ， $x = 2a + b, a \in A, b \in B$
> >
> > 所以当 $a = 1, b = 3$ 时， $x = 2 \times 1 + 3 = 5$ 当 $a = 1, b = 5$ 时， $x = 2 \times 1 + 5 = 7$ 当 $a = 2, b = 3$ 时， $x = 2 \times 2 + 3 = 7$ 当 $a = 2, b = 5$ 时， $x = 2 \times 2 + 5 = 9$ 当 $a = 3, b = 3$ 时， $x = 2 \times 3 + 3 = 9$ 当 $a = 3, b = 5$ 时， $x = 2 \times 3 + 5 = 11$ 所以 $C = \{5, 7, 9, 11\}$ ，所以集合 $C$ 的子集个数为 $2^4 = 16$ .
> >
> > 故选 **B**
