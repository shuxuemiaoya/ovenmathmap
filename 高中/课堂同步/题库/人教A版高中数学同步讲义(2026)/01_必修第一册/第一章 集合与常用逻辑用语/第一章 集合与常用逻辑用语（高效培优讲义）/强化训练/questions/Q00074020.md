15. 设全集 $U = \mathbf{R}$ ，集合 $A = \{x \mid 0 < x < 2\}, B = \{x \mid a - 1 < x < 2a + 3\}$

(1)若 $a = 2$ 时，求 $A\cup B,\left(\check{\mathfrak{Q}}_U A\right)\cup \left(\check{\mathfrak{Q}}_U B\right)$

(2)若 $A \cup B = B$ ，求实数 $a$ 的取值范围；

(3)若 $A \cap B = B$ ，求实数 $a$ 的取值范围.
