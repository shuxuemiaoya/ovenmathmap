> [!faq]- 《第一章 集合与常用逻辑用语（高效培优单元测试·强化卷）》官方解析
>
> > [!success]- **【答案】** (1) $a = -3$ 或 $a = -1$ (2) $a > -3$ $\left|x_{1} - x_{2}\right| = \sqrt{8a + 24}$ (3) $\left\{a\mid a\leq-3\right\}$
>
> > [!note]- **【分析】**
> > （1）由已知 $2 \in B$ ，代入后解方程并检验是否满足题意；
> >
> > (2) 根据根与系数关系和完全差的平方公式化简求值即可；
> >
> > (3) 由条件可得 $B \subseteq A$ ，结合集合A确定集合 $B$ ，再根据集合 $B$ 情况分类求解即可.
>
> > [!note]- **【解析】**
> > （1）由题意得 $A = \{x\mid x^2 -3x + 2 = 0\} = \{1,2\}$ ，因为 $A\cap B = \{2\}$ ，所以 $2\in B$ ， $1\notin B$
> >
> > 所以 $2^{2}+4(a+1)+a^{2}-5=0$ 即 $4+4a+4+a^{2}-5=0$
> >
> > 化简得 $a^2 + 4a + 3 = 0$ ，即 $(a + 3)(a + 1) = 0$ ，解得 $a = -3$ 或 $a = -1$ ，
> >
> > 检验：当 $a = -3$ 时， $B = \{x \mid x^2 - 4x + 4 = 0\} = \{2\}$ ，满足 $A \cap B = \{2\}$
> >
> > 当 $a = -1$ 时， $B = \{x \mid x^2 - 4 = 0\} = \{-2, 2\}$ ，满足 $A \cap B = \{2\}$
> >
> > 所以 a = -3 或 a = -1
> >
> > (2) 因为 B 集合中有两个元素 $x_{1}, x_{2}$ ，所以方程 $x^{2} + 2(a + 1)x + (a^{2} - 5) = 0$ 有两个根，
> >
> > 所以 $\Delta = 4(a + 1)^2 - 4(a^2 - 5) = 8a + 24 > 0$ 且 $x_{1} + x_{2} = -2(a + 1)$ ， $x_{1}x_{2} = a^{2} - 5$
> >
> > 所以 $a > -3$ ， $\left|x_{1} - x_{2}\right| = \sqrt{\left(x_{1} + x_{2}\right)^{2} - 4x_{1}x_{2}} = \sqrt{4(a + 1)^{2} - 4(a^{2} - 5)} = \sqrt{8a + 24}$
> >
> > (3) 因为 $A \cap B = B$ ，所以 $B \subseteq A$ ，又 $A = \{1, 2\}$ ，
> >
> > 所以 $B = \emptyset$ 或 $B = \{1\}$ 或 $B = \{2\}$ 或 $B = \{1,2\}$
> >
> > 当 $B = \varnothing$ 时， $\Delta = 4(a + 1)^2 - 4(a^2 - 5) = 8a + 24 < 0$ ，解得 $a < -3$ ，符合题意；
> >
> > 当 $B = \{1\}$ 时，则 $\left\{ \begin{array}{l} \Delta = 4(a + 1)^2 - 4(a^2 - 5) = 8a + 24 = 0 \\ 1^2 + 2(a + 1) + (a^2 - 5) = 0 \end{array} \right.$ ，无解；
> >
> > 当 $B = \{2\}$ 时，则 $\left\{ \begin{array}{l} \Delta = 4(a + 1)^2 - 4(a^2 - 5) = 8a + 24 = 0 \\ 2^2 + 4(a + 1) + a^2 - 5 = 0 \end{array} \right.$ ，所以 $a = -3$ ；
> >
> > 当 $B = \{1,2\}$ 时，则 $\left\{ \begin{array}{l} \Delta = 4(a + 1)^2 - 4(a^2 - 5) = 8a + 24 > 0 \\ 1 + 2 = -2(a + 1) \\ 2 = a^2 - 5 \end{array} \right.$ ，无解，
> >
> > 综上， $a$ 的范围为 $\{a|a\leq -3\}$
