> [!faq]- 《第一章 集合与常用逻辑用语（高效培优单元测试·强化卷）》官方解析
>
> > [!success]- **【答案】** C
>
> > [!note]- **【分析】**
> > 根据题设定义求出 A-B 和 B-A，再求出 $A \oplus B$ 即可．
>
> > [!note]- **【解析】**
> > 对于集合 $M$ ， $N$ ，定义 $M - N = \{x\mid x\in M$ 且 $x\notin N\}$ ， $M\oplus N = (M - N)\cup (N - M)$
> >
> > 设 $A = \left\{x\mid x - \frac{9}{4},x\in \mathbb{R}\right\}$ ， $B = \{x\mid x <   0,x\in \mathbb{R}\}$
> >
> > 则 $A - B = \{x\mid x\quad 0\}$ ， $B - A = \left\{x\bigg|x <   - \frac{9}{4}\right\}$
> >
> > 所以 $A \oplus B = \left\{ x \mid x \quad 0 \right\} \cup \left\{ x \mid x < -\frac{9}{4} \right\} = \left( -\infty, -\frac{9}{4} \right) \cup [0, +\infty)$ .
> >
> > 故选 **C**.
