> [!faq]- 《专题02 集合间的基本关系四大常考题型（高效培优专项训练）》官方解析
>
> > [!success]- **【答案】** (1) $a+b=3,ab=2$ ; (2)答案见解析.
>
> > [!note]- **【分析】**
> > （1）求出方程 $x^{2} - (a + b)x + ab = 0$ ，进而求出 $a + b, ab$ .
> >
> > (2) 利用集合的包含关系求出 a, b，进而求出集合 B·
>
> > [!note]- **【解析】**
> > （1）由 $x^{2} - (a + b)x + ab = 0$ ，得 $x = a$ 或 $\mathrm{x} = \mathrm{b}$
> >
> > 而 $A = \{1,2\}$ ，则1,2是方程 $x^{2} - (a + b)x + ab = 0$ 的二根，
> >
> > 所以 $a + b = 3, ab = 2$ .
> >
> > (2) 由 (1) 知， $A \neq \varnothing$ ，由 $A \subseteq \{1, 2\}$ ，得 $A = \{1\}$ 或 $A = \{2\}$ 或 $A = \{1, 2\}$ ，
> >
> > 当 $A = \{1\}$ 时， $a = b = 1$ ，则 $B = \{2\}$ ；
> >
> > 当 $A=\{2\}$ 时，a=b=2，则 $B=\{4\}$ ；
> >
> > 当 $A = \{1,2\}$ 时， $a + b = 3$ ，则 $B = \{3\}$ .
