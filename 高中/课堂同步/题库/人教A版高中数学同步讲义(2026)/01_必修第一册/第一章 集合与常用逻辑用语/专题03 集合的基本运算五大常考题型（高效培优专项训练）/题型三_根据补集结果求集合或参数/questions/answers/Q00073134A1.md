> [!faq]- 《专题03 集合的基本运算五大常考题型（高效培优专项训练）》官方解析
>
> > [!success]- **【答案】** A. 3, 2 B. 4, 3 C. 3, 2 或 5, 3 D. 5, 2 或 5, 3
>
> > [!note]- **【分析】**
> > 根据集合关系得到 $A \cup B = U$ ，且 $A \cap B = \varnothing$ ，再得到 $a > b$ ，且 $a \neq 1$ ， $a \neq 4$ ， $b \neq 1$ ， $b \neq 4$ ，分类讨论得到 $a, b$ 的值。
>
> > [!note]- **【解析】**
> > 因为 $\check{Q}_{U}A=B$ ，所以 $A\cup B=U$ ，且 $A\cap B=\varnothing$ 。
> >
> > 由题意得， $a > b$ ，且 $a \neq 1$ ， $a \neq 4$ ， $b \neq 1$ ， $b \neq 4$
> >
> > 若 $a = 3, b = 2$ ，则 $a - b = 1$ ，不满足 $\tilde{\mathfrak{Q}}_U A = B$ ，不符合题意；
> >
> > 若 $a = 5, b = 2$ ，则 $a - b = 3$ ，此时 $A = \{1, 2, 5\}, B = \{4, 3\}, \check{\mathbf{Q}}_U A = \{3, 4\} = B$ ，符合题意；
> >
> > 若 $a = 5, b = 3$ ，则 $a - b = 2$ ，此时 $A = \{1, 3, 5\}$ ， $B = \{2, 4\}, \tilde{\mathfrak{Q}}_U A = \{2, 4\} = B$ ，符合题意。
> >
> > 故选 **D**
