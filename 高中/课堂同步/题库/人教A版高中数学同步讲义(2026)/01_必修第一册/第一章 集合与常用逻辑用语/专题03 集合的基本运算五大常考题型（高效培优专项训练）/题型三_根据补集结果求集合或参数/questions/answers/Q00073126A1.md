> [!faq]- 《专题03 集合的基本运算五大常考题型（高效培优专项训练）》官方解析
>
> > [!success]- **【答案】** (1) $A \cap B = \{x \mid x > 3\}$ (2) $a = 3$
>
> > [!note]- **【分析】**
> > （1）根据交集概念求出答案；
> >
> > (2) 根据补集的概念求出 $\breve{\partial}_{A}M = \left\{ x \mid x > 4 \right\}$ ，结合 $\breve{\partial}_{A}M = B$ ，从而得到 $a + 1 = 4$ ，得到答案.
>
> > [!note]- **【解析】**
> > （1）当 $a = 1$ 时， $B = \{x | x > a + 1\} = \{x | x > 2\}$ ，所以 $A \cap B = \{x | x > 3\} \cap \{x | x > 2\} = \{x | x > 3\}$
> >
> > (2) 因为集合 $A = \{x \mid x > 3\}, M = \{x \mid 3 < x \leq 4\}$ ，所以 $\tilde{\mathfrak{O}}_A M = \{x \mid x > 4\}$
> >
> > 又 $\tilde{\mathfrak{O}}_A M = B$ ，所以 $a + 1 = 4$ ，解得 $a = 3$
