> [!faq]- 《专题03 集合的基本运算五大常考题型（高效培优专项训练）》官方解析
>
> > [!success]- **【答案】** (1) $A \cup B = \{x \mid 2 < x < 7\}$ ， $A \cap \tilde{\mathbf{Q}}_{\mathbf{R}} B = \{x \mid 2 < x \leq 3\}$ (2) $(- \infty, 1] \cup \left[2, \frac{8}{3}\right]$
>
> > [!note]- **【分析】**
> > （ $^{1}$ ）根据题意求集合 B，再结合集合间的运算求解；
> >
> > (2) 由题意可得 $B \subseteq A$ ，分类讨论 $B = \varnothing$ 和 $B \neq \varnothing$ ，结合包含关系分析求解
>
> > [!note]- **【解析】**
> > （1）因为 $A = \{x\mid 2 <   x <   6\}$
> >
> > 若 $a = 3$ ，则 $B = \{x\mid 3 <   x <   7\}$ ，则 $\tilde{\mathbf{Q}}_{\mathbf{R}}B = \{x\mid x\leq 3$ 或 $x\quad 7\}$
> >
> > 所以 $A \cup B = \{x \mid 2 < x < 7\}$ ， $A \cap \tilde{\mathbf{Q}}_{\mathbf{R}} B = \{x \mid 2 < x \leq 3\}$ .
> >
> > (2) 若 $A \cap B = B$ ，可知 $B \subseteq A$ ，
> >
> > 当 $B = \varnothing$ 时，则 a = 3a - 2 ，解得 $a \leq 1$ ；
> >
> > 当时，则 $\left\{ \begin{array}{ll}a <   3a - 2\\ a & 2\\ 3a - 2\leq 6 \end{array} \right.$ ，解得 $2\leq a\leq \frac{8}{3}$
> >
> > 所以 $a$ 的取值范围为 $(- \infty, 1] \cup \left[2, \frac{8}{3}\right]$ .
