> [!faq]- 《专题03 集合的基本运算五大常考题型（高效培优专项训练）》官方解析
>
> > [!success]- **【答案】** (1) $A \cup B = \{0, 1, 4\}$ (2) $\{a \mid a \leq 0 \text{ 或 } a = 2\}$
>
> > [!note]- **【分析】**
> > （1）确定集合A、B，根据并集的概念求解·
> >
> > (2) 确定集合 A、B 的关系，根据集合的包含关系求参数 a 的取值范围.
>
> > [!note]- **【解析】**
> > （1）由 $x^{2} - 4x = 0\Rightarrow x = 0$ 或 $x = 4$ ，所以 $A = \{0,4\}$
> >
> > 当 a=1 时，由 $\sqrt{x}-1=0\Rightarrow x=1$ ，所以 $B=\{1\}$ .
> >
> > 所以 $A \cup B = \{0,1,4\}$
> >
> > (2) 由 $A \cap B = B$ ，所以 $B \subseteq A$ .
> >
> > 若 $B = \varnothing$ ，则方程 $\sqrt{x} - a = 0$ 无解，所以 a < 0；
> >
> > 若 $B = \{0\}$ ，则 $\sqrt{0} - a = 0 \Rightarrow a = 0$
> >
> > 若 $B = \{4\}$ ，则 $\sqrt{4} - a = 0 \Rightarrow a = 2$
> >
> > 综上可得： $a$ 的取值范围为 $\{a\mid a\leq 0$ 或 $a = 2\}$
