> > 6．集合 $A=\{3,1\}$ ， $B=\{0,b\}$ ，若 $A\cap B=\{1\}$ ，则 $A\cup B=$ \_\_\_\_.
> >
> > 【答案】 $\{3,1,0\}$
> >
> > 【分析】根据集合的交集以及并集的定义即可求解·
> >
> > 【详解】由 $A \cap B = \{1\}$ 知 b = 1，∴ $A \cup B = \{3, 1, 0\}$ .
> >
> > 故答案为： $\{3,1,0\}$

> > 7. 集合 $A = \{x < 2 < x < 7\}$ , $B = \{x \mid x < a\}$ .
> >
> > (1)若 $A \cap B$ 只有一个整数，求实数 $a$ 的取值范围；
> >
> > (2) 若 $C = \{x1 - m < x < 2m\}$ ，且 $A \cup C = A$ ，求实数 $m$ 的取值范围。
> >
> > 【答案】(1)(3,4]
> >
> > (2) $\left(-\infty,\frac{1}{3}\right]$
> >
> > 【分析】（1）根据题意可知满足 $3\in A\cap B$ 即可，因此 $3<a\leq4$ ；
> >
> > (2) 利用并集的结果可得 $C \subseteq A$ ，对 C 是否为空集进行分类讨论，即可解得实数 m 的取值范围.
> >
> > 【详解】（1）∵ $A \cap B$ 只有一个整数，又 $A = \{\frac{1}{2} < x < 7\}$ 包含不止一个整数，
> >
> > $\therefore A \cap B = \{\not x 2 < x < a\}$ ，且 $3 \in A \cap B$
> >
> > $\therefore 3 < a \leq 4$
> >
> > 可得实数 a 的取值范围是 $(3,4]$ .
> >
> > (2) 由 $A \cup C = A$ ，可得 $C \subseteq A$ .
> > - **①**：若 $C = \emptyset$ ，此时 $1 - m \quad 2m$ ，解得 $m \leq \frac{1}{3}$
> > - **②**：若 $C \neq \emptyset$ ，此时需满足 $\left\{ \begin{array}{l} 1 - m < 2m \\ 1 - m = 2 \\ 2m \leq 7 \end{array} \right.$ ，此时不等式无解。
> >
> > 综上可知 $m \in \left(-\infty, \frac{1}{3}\right]$ .
