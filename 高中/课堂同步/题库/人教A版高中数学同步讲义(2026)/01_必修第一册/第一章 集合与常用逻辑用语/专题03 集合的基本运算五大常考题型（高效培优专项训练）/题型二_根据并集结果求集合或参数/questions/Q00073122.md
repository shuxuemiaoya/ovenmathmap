17. 已知集合 $A = \{x \mid 2 < x < 4\}$ ， $B = \{x \mid a < x < 3a$ ，且 $a > 0\}$

(1)若 $A \cup B = B$ ，求实数 $a$ 的取值范围；

(2)若 $A\cap B = \{x\mid 3 <   x <   4\}$ ，求实数 $a$ 的值；

(3)若 $A \cap B = \varnothing$ ，求实数 $a$ 的取值范围；

(4)若将题干中集合A，B变为集合 $A=\left\{x\mid2a\leq x\leq a+3\right\}$ ， $B=\left\{x\mid x<-1\text{或}x>5\right\}$ 。若 $A\cap B=\varnothing$ ，求实数

$a$ 的取值范围.
