> > 25. 含有三个实数的集合可表示为 $\left\{a, \frac{b}{a}, 1\right\}$ ，也可表示为 $\left\{a^2, a + b, 0\right\}$ ，求 $a^{2025} + b^{2026}$ 的值。
> >
> > 【答案】-1
> >
> > 【分析】本题根据集合相等以及集合元素的互异性列出等式得出 a, b 的值，再计算 $a^{2025} + b^{2026}$ 即可.
> >
> > 【详解】由 $\left\{a, \frac{b}{a}, 1\right\}$ 可得 $a \neq 0$ 且 $a \neq 1$ （否则不满足集合中元素的互异性）.
> >
> > 所以 $\left\{ \begin{array}{l}a = a + b\\ 1 = a^2\\ \frac{b}{a} = 0 \end{array} \right.$ ，或 $\left\{ \begin{array}{l}a = a^2\\ 1 = a + b\\ \frac{b}{a} = 0 \end{array} \right.$
> >
> > 解得 $\left\{ \begin{array}{l}a = -1\\ b = 0 \end{array} \right.$ ，或 $\left\{ \begin{array}{l}a = 1\\ b = 0 \end{array} \right.$
> >
> > 经检验 a = -1 ， b = 0 满足题意 .
> >
> > 所以 $a^{2025} + b^{2026} = (-1)^{2025} = -1$

> > 26. 举例说明：设集合 $M$ 中含有三个元素 $^3$ , $x$ , $x^2$ :
> >
> > (1)求实数 $x$ ，应满足的条件；
> >
> > (2)若 $4\hat{1} M$ ，求实数 $x$ 的值.
> >
> > 【答案】(1) $x \neq 0$ 且 $x \neq 3$ 且 $x \neq 1$ 且 $x \neq \sqrt{3}$ 且 $x \neq -\sqrt{3}$ ;
> >
> > (2) $x = 4$ 或 $x = 2$ 或 $x = -2$ .
> >
> > 【分析】（ $^{1}$ ）根据集合元素的互异性列出不等式组，解不等式组即可；
> >
> > (2) 若 $4 \hat{1} M$ ，则 $x = 4$ 或 $x^2 = 4$ ，进而求解即可得答案.
> >
> > 【详解】（1）据集合中元素的互异性，可知 $\left\{ \begin{array}{l}x\neq 3\\ x\neq x^2\\ x^2\neq 3 \end{array} \right.$
> >
> > 即 $x \neq 0$ 且 $x \neq 3$ 且 $x \neq 1$ 且 $x \neq \sqrt{3}$ 且 $x \neq -\sqrt{3}$ ；
> >
> > (2) 若 $4 \hat{1} M$ ，则 $x = 4$ 或 $x^2 = 4$ ，解得： $x = 4$ 或 $x = 2$ 或 $x = -2$
> >
> > 若 $x = 4$ ，则 $M = \{3,4,16\}$ ，满足题意；
> >
> > 若 $x = 2$ ，则 $M = \{3,2,4\}$ ，满足题意；
> >
> > 若 $x = -2$ ，则 $M = \{3, - 2,4\}$ ，满足题意；
> >
> > 故 $x = 4$ 或 $x = 2$ 或 $x = -2$ .
