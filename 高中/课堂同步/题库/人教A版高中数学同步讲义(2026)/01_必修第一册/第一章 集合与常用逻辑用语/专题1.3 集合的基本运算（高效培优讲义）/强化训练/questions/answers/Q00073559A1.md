> [!faq]- 《专题1.3 集合的基本运算（高效培优讲义）》官方解析
>
> > [!success]- **【答案】** (1) $\check{\mathbf{Q}}_{\mathrm{R}}(A\cap B)=\{x\mid x\leq3$ 或 $x\quad6\}$ ，且 $(\check{\mathbf{Q}}_{\mathrm{R}}B)\cup B=\mathrm{R}$ (2) $3 \leq a \leq 8$ .
>
> > [!note]- **【分析】**
> > （1）应用集合的交运算求得 $A \cap B = \{x \mid 3 < x < 6\}$ ，再由补运算求 $\tilde{\mathfrak{Q}}_R(A \cap B)$ ，根据 $\tilde{\mathfrak{Q}}_R B, B$ 的关系求 $(\tilde{\mathfrak{Q}}_R B) \cup B$
> >
> > (2) 根据集合的包含关系有 $\left\{\begin{aligned}a & 3 \\ a+1 & \leq 9\end{aligned}\right.$ ，即可得参数范围.
>
> > [!note]- **【解析】**
> > （1）由 $A \cap B = \{x \mid 2 \leq x < 6\} \cap \{x \mid 3 < x < 9\} = \{x \mid 3 < x < 6\}$
> >
> > 所以 $\tilde{\mathbf{Q}}_{\mathrm{R}}(A\cap B)=\{x\mid x\leq3$ 或 $x\quad6\}$ ，且 $(\tilde{\mathbf{Q}}_{\mathrm{R}}B)\cup B=\mathrm{R}$ ；
> >
> > (2) 由 $C = \{x \mid a < x < a + 1\}$ ，显然不是空集，且 $C \subseteq B$
> >
> > 所以 $\left\{\begin{aligned}a&3\\ a+1&\leq9\end{aligned}\right.$ ，可得 $3\leq a\leq8\cdot$
