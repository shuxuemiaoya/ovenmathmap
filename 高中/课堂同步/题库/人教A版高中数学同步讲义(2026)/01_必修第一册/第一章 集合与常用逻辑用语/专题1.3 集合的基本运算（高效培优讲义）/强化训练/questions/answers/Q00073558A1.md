> [!faq]- 《专题1.3 集合的基本运算（高效培优讲义）》官方解析
>
> > [!success]- **【答案】** $A \cap B = \{x \mid -2 < x \leq 2\}$ ， $(\tilde{\mathbf{Q}}_U A) \cup B = \{x \mid x \leq 2$ 或 $3 \leq x \leq 4\}$
>
> > [!note]- **【分析】**
> > 直接利用集合交集的运算、集合补集与并集的运算求解即可·
>
> > [!note]- **【解析】**
> > 因为集 $U = \{x \mid x \leq 4\}$ ，集合 $A = \{x \mid -2 < x < 3\}$ ， $B = \{x \mid -3 \leq x \leq 2\}$ ，
> >
> > 所以 $A \cap B = \{x \mid -2 < x \leq 2\}$
> >
> > $$
> > \mathfrak {Q} _ {U} A = \{x \mid x \leq - 2 \text {或} 3 \leq x \leq 4 \}
> > $$
> >
> > $$
> > \therefore (\tilde {\mathfrak {Q}} _ {U} A) \cup B = \{x \mid x \leq 2 \quad 3 \leq x \leq 4 \}
> > $$
