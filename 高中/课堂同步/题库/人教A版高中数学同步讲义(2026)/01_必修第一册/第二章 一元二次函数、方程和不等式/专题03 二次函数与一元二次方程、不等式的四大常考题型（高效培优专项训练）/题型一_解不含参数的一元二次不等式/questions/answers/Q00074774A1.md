> [!faq]- 《专题03 二次函数与一元二次方程、不等式的四大常考题型（高效培优专项训练）》官方解析
>
> > [!success]- **【答案】** C
>
> > [!note]- **【解析】**
> > 因为 $f(x)=ax^{2}+bx+c$ ，且关于 x 的不等式 $f(x)>0$ 的解集为 $(-1,2)$ ，
> > 所以，且的根为和 $^{2}$ ，所以 $\left\{\begin{aligned}-1+2&=-\frac{b}{a}\\ -1\times2&=\frac{c}{a}\end{aligned}\right.$ ，得，，，
> >
> > 对于 A，因为 a < 0 ，所以 b = -a > 0 ，故 A 错误；
> >
> > 对于 B， $f(x)=ax^{2}-ax-2a=a(x+1)(x-2)$ ，所以 $f(-99)=98\times101a$ ， $f(101)=99\times102a$
> >
> > 因为 $98 \times 101 < 99 \times 102$ ，a < 0，所以 $f(-99) > f(101)$ ，故 B 错误；
> >
> > 对于 C， $bx^{2}+cx-a<0$ 即为 $-ax^{2}-2ax-a<0$ ，即 $x^{2}+2x+1<0$ ，无解，
> >
> > 故命题“ $\exists x\in R$ ， $bx^{2}+cx-a<0$ ”为假命题，故C正确；
> >
> > 对于 D，因为 $y = ax^{2} + bx + c + 1$ 是由 $y = ax^{2} + bx + c$ 向上平移一个单位，所以 $(-1, 2) \square M$ ，故 D 错误。
> > 故选：C.
> >
> > 4. 不等 $x^{2} - 2x - 3 < 0$ 的解集为（）A. $\{x|x < -3$ 或 $x > 1\}$ B. $\{x| - 3 < x < 1\}$ C. $\{x|x < -1$ 或 $x > 3\}$ D. $\{x| - 1 < x < 3\}$
> >
> > 【答案】D
> >
> > 【详解】原不等式 $x^{2}-2x-3<0$ 就转化为 $(x-3)(x+1)<0$ .
> >
> > 解得 -1 < x < 3，即不等式 $x^{2} - 2x - 3 < 0$ 的解集为 $\left\{k - 1 < x < 3\right\}$ .
> >
> > 故选 **D**
