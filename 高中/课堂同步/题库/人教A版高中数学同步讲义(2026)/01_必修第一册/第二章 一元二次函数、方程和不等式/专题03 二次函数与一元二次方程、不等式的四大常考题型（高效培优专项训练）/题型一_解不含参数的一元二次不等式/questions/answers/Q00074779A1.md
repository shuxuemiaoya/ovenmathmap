> [!faq]- 《专题03 二次函数与一元二次方程、不等式的四大常考题型（高效培优专项训练）》官方解析
>
> > [!success]- **【答案】** (1) $(-∞,-\frac{15}{7}]$ (2) 2
>
> > [!note]- **【解析】**
> > （1）由 $1 \leq \frac{8}{1 + x} \leq 8$ 解得： $0 \leq x \leq 7$ ，
> >
> > 不等式组 $\left\{ \begin{array}{l} 1 \leq \frac{8}{1 + x} \leq 8 \\ x^2 + 3tx - 4 < 0 \end{array} \right.$ 解集构成的各区间的长度和等于，
> >
> > ∴不等式 $x^{2} + 3tx - 4 < 0$ 对任意 $x\in [0,7]$ 恒成立，
> >
> > 令 $g(x)=x^{2}+3tx-4,\quad x\in[0,7]$
> >
> > 则 $\left\{ \begin{array}{c} g(0) = -4 \leq 0 \\ g(7) = 49 + 21t - 4 \leq 0 \end{array} \right.$
> >
> > 解得： $t\leq -\frac{15}{7}$
> >
> > ∴ 实数 t 的范围为 $(-∞, -\frac{15}{7}]$
> >
> > (2) ① 当 $x > a$ 或 $x < b$ 时，原不等式等价于 $x - b + x - a \quad (x - a)(x - b)$
> >
> > 整理得： $x^{2} - (a + b + 2)x + (a + b + ab)\leq 0$
> >
> > 令 $f(x)=x^{2}-(a+b+2)x+(a+b+ab)$
> >
> > $\because f(a) = b - a < 0, f(b) = a - b > 0$ 设 $f(x) = 0$ 的两根为 $X_{1}, x_{2}(x_{1} < x_{2})$
> >
> > 此时原不等式的解集为 $(a, x_2]$ ，解集的区间长度为 $x_2 - a$ ；
> > - **②**：当 b < x < a 时，
> >
> > 同理可得原不等式的解集为 $(b, x_1]$ ，此时解集的区间长度为 $x_1 - b$
> >
> > 综合①②知：原不等式的解集的区间长度之和为 $x_{2} + x_{1} - a - b$
> >
> > 又由韦达定理可知： $x_{1}+x_{2}=a+b+2$
> >
> > ∴ 原不等式的解集的区间长度之和为 2.

> > 10．高斯，著名的数学家、物理学家、天文学家、是近代数学奠基者之一，享有“数学王子”之称．函数
> >
> > $y = [x]$ 成为高斯函数，其中 $[x]$ 表示不超过实数 $x$ 的最大整数，如 $[1.2] = 1, [-1.2] = -2$
> >
> > (1)求 $-\frac{5}{2} \leq [x] \leq \frac{5}{2}$ 的解集和 $2[x]^2 - 11[x] + 15 \leq 0$ 的解集.
> >
> > (2)若 $\forall 1\leq x\leq \frac{7}{2},\left[x\right]^2 -m\left[x\right] + 4 > 0$ 恒成立，求 $m$ 取值范围.
> >
> > (3)若 $\left[x\right]^2 - 2\left[x\right] - a^2 + 1 \leq 0$ 的解集为 $\{x \mid 0 \leq x < 3\}$ ，求 $a$ 的范围。
> >
> > 【答案】(1) $\left\{x\mid-2\leq x<3\right\}$ ， $\left\{x\mid3\leq x<4\right\}$
> >
> > (2) $(-∞,4)$
> >
> > (3) $(-2,-1]\cup[1,2)$
> >
> > 【详解】（1）由题意得 $[x] \leq x < [x] + 1$ ，且 $[x] \in \mathbf{Z}$
> >
> > 由 $-\frac{5}{2} \leq [x] \leq \frac{5}{2}$ ，即 $-2 \leq [x] \leq 2$ ，所以 $-2 \leq x < 3$ ，
> >
> > 故 $-\frac{5}{2} \leq [x] \leq \frac{5}{2}$ 的解集为 $\{x | -2 \leq x < 3\}$ ;
> >
> > 由 $2[x]^2 - 11[x] + 15 \leq 0$ ，即 $\left([x] - 3\right)(2[x] - 5) \leq 0$
> >
> > $\therefore \frac{5}{2} \leq [x] \leq 3$ ，则 $[x] = 3$ ，所以 $3 \leq x < 4$ 。
> >
> > 所以 $2[x]^2 - 11[x] + 15 \leq 0$ 的解集为 $\{x | 3 \leq x < 4\}$ .
> >
> > (2) $\forall 1 \leq x \leq \frac{7}{2}, [x]^2 - m[x] + 4 > 0$ 恒成立，此时 $1 \leq [x] \leq 3$
> >
> > 即 $\forall 1\leq x\leq \frac{7}{2}$ ， $m <   [x] + \frac{4}{[x]}$ 恒成立，
> >
> > 又 $\left[x\right] + \frac{4}{\left[x\right]} 4$ ，当且仅当 $\left[x\right] = 2$ 时，即 $2 \leq x < 3$ 时等号成立。
> >
> > 故 $[x] + \frac{4}{[x]}$ 的最小值为 $^4$
> >
> > 所以要使 $\left[x\right]+\frac{4}{\left[x\right]}>m$ 恒成立，则m<4。
> >
> > 故 $m$ 的取值范围为 $(- \infty, 4)$
> >
> > (3) 不等式 $\left[x\right]^2 - 2\left[x\right] - a^2 + 1 \leq 0$ ，即 $\left(\left[x\right] + a - 1\right)\left(\left[x\right] - a - 1\right) \leq 0$
> >
> > 由方程 $\left([x] + a - 1\right)\left([x] - a - 1\right) = 0$ 可得 $[x] = 1 - a$ 或 $1 + a$
> > - **①**：若 $a = 0$ ，不等式为 $[x]^2 - 2[x] + 1 \leq 0$
> >
> > 即 $[x] = 1$ ，所以 $0 \leq x < 1$ ，显然不符合题意；
> > - **②**：若 a > 0, 1 - a < 1 + a
> >
> > 由 $\left([x] + a - 1\right)\left([x] - a - 1\right) \leq 0$ ，解得 $1 - a \leq [x] \leq 1 + a$
> >
> > 因为不等式的解集为 $\left\{x\mid1-a\leq[x]\leq1+a\right\}=\left\{x\mid0\leq x<3\right\}=\left\{x\mid-1<[x]<3\right\}$
> >
> > 所以 $\left\{ \begin{array}{l} -1 < 1 - a \leq 0 \\ 2 \leq 1 + a < 3 \end{array} \right.$ ，解得 $1 \leq a < 2$
> > - **③**：若 $a < 0, 1 + a < 1 - a$
> >
> > 由 $\left([x] + a - 1\right)\left([x] - a - 1\right) \leq 0$ ，解得 $1 + a \leq [x] \leq 1 - a$
> >
> > 因为不等式解集为 $\left\{x\mid1+a\leq[x]\leq1-a\right\}=\left\{x\mid0\leq x<3\right\}=\left\{x\mid-1<[x]<3\right\}$
> >
> > 所以 $\left\{ \begin{array}{l} -1 < 1 + a \leq 0 \\ 2 \leq 1 - a < 3 \end{array} \right.$ ，解得 $-2 < a \leq -1$ 。
> >
> > 综上所述， $-2 < a \leq -1$ 或 $1 \leq a < 2$
> >
> > 故 $a$ 的范围为 $\left(-2, -1\right] \cup [1, 2)$
