> [!faq]- 《专题03 二次函数与一元二次方程、不等式的四大常考题型（高效培优专项训练）》官方解析
>
> > [!success]- **【答案】** A
>
> > [!note]- **【解析】**
> > 因为 a > 2 ，
> >
> > 由 $x^{2} + ax$ 0 解得 $x \leq -a$ 或 x 0 ，
> >
> > $$
> > A = \left\{x \mid x ^ {2} + a x \quad 0 \right\} = \left\{x \mid x \leq - a \text {或} x \quad 0 \right\}
> > $$
> >
> > 由 $x^{2} + ax + 1$ 0解得 $x\leq \frac{-a - \sqrt{a^2 - 4}}{2}$ 或 $x = \frac{-a + \sqrt{a^2 - 4}}{2}$
> >
> > 即 $B = \left\{x \mid x^2 + ax + 1, 0\right\} = \left\{x \mid x \leq \frac{-a - \sqrt{a^2 - 4}}{2}\text{或} x, \frac{-a + \sqrt{a^2 - 4}}{2}\right\}$
> >
> > 因为 a > 2 ，所以 $0 < \sqrt{a^{2} - 4} < a$
> >
> > 所以 $-a < \frac{-a - \sqrt{a^2 - 4}}{2} < \frac{-a + \sqrt{a^2 - 4}}{2} < 0$
> >
> > 所以 A 是 B 的真子集，
> >
> > 所以 p 是 q 的充分不必要条件.
> >
> > 故选 **A**
