> [!faq]- 《专题03 二次函数与一元二次方程、不等式的四大常考题型（高效培优专项训练）》官方解析
>
> > [!success]- **【答案】** B
>
> > [!note]- **【解析】**
> > 当 $f(a) \leq 2$ 时，由 $f(x) = \begin{cases} 2 - |x|, (x \leq 2) \\ x^2 - 6x + 8, (x > 2) \end{cases}$ ， $f(f(a)) = 0$ ，
> >
> > 则 $2 - \left|f(a)\right| = 0$ ，解得 $-2\leq f(a)\leq 2$
> >
> > 当 $a \leq 2$ 时，可得 $-2 \leq 2 - |a| \leq 2$
> >
> > 解得 $-4 \leq a \leq 4$
> >
> > 此时可得 $-4 \leq a \leq 2$ ;
> >
> > 当 $a > 2$ 时，可得 $-2 \leq a^2 - 6a + 8 \leq 2$
> >
> > 即 $\left\{ \begin{array}{ll}a^2 -6a + 6\leq 0\\ a^2 -6a + 10 & 0 \end{array} \right.$ ，解得 $3 - \sqrt{3}\leq a\leq 3 + \sqrt{3}$
> >
> > 此时可得 $2 < a \leq 3 + \sqrt{3}$ ;
> >
> > 当 $f(a) > 2$ 时，可得 $f^2 (a) - 6f(a) + 8\quad 0$
> >
> > 解得 $f(a)$ 4 或 $f(a) \leq 2$ ，所以 $f(a)$ 4，
> >
> > 当 $a \leq 2$ 时，可得 $2 - |a| = 4$ ，此时无解；
> >
> > 当 $a > 2$ 时，可得 $a^2 - 6a + 8 \quad 4$
> >
> > 解得 $a \quad 3 + \sqrt{5}$ 或 $a \leq 3 - \sqrt{5}$
> >
> > 此时可得 $a = 3 + \sqrt{5}$
> >
> > 综上所述，实数 $a$ 的取值范围是 $\left[-4,3 + \sqrt{3}\right]\cup \left[3 + \sqrt{5}, + \infty\right)$
> >
> > 故选 **B**
