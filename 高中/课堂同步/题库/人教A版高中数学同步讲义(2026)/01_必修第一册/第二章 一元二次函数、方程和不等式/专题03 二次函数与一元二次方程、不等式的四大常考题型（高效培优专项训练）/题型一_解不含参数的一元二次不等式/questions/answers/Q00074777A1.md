> [!faq]- 《专题03 二次函数与一元二次方程、不等式的四大常考题型（高效培优专项训练）》官方解析
>
> > [!success]- **【答案】** A. 19 B. 20 C. 21 D. 22
>
> > [!note]- **【解析】**
> > 因为当 $i < j$ （ $i, j \in \mathbb{N}^*$ ）时， $x_i < x_j$ ，故 $2 \leq x_1 + 1 \leq x_2, x_2 + 1 \leq x_3, \dots, x_{j-1} + 1 \leq x_j$ ，诸不等式相加可得 $x_1 + j - 1 \leq x_j$ 即 $j \leq x_j$ .
> >
> > 故 $1^2 + 2^2 + \dots + 8^2 + x_9^2 + (x_9 + 1)^2 \leq x_1^2 + x_2^2 + \dots + x_{10}^2$ ，
> >
> > 所以 $1^2 + 2^2 + \dots + 8^2 + x_9^2 + (x_9 + 1)^2 \leq 2020$ ， $2x_9^2 + 2x_9 - 1815 \leq 0$ ，故 $x_9 \leq 29$ .
> >
> > 又 $x_1 = 1, x_2 = 2, x_3 = 3, x_4 = 4$ ，故 $x_9 - (x_1 + x_2 + x_3 + x_4) \leq 29 - (1 + 2 + 3 + 4) = 19$ .
> >
> > 当 $x_i = i, (1 \leq i \leq 8), x_9 = 29, x_{10} = 30$ 等号成立.
> >
> > 故选 **A**.
