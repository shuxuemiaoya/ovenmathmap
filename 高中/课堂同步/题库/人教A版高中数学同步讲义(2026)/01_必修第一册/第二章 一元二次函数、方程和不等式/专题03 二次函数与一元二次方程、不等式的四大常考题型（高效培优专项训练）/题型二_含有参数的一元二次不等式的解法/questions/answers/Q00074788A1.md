> [!faq]- 《专题03 二次函数与一元二次方程、不等式的四大常考题型（高效培优专项训练）》官方解析
>
> > [!success]- **【答案】** (1) $(-∞,1)$ (2) 答案见解析 (3) $h(m)=\left\{\begin{aligned}&-m^{2}+\frac{5}{2}m-1,\frac{1}{2}<m\leq\frac{5}{4}\\&\frac{9}{16},\frac{5}{4}<m\leq\frac{5+3\sqrt{2}}{4}\\&m^{2}-\frac{5}{2}m+1,m>\frac{5+3\sqrt{2}}{4}\end{aligned}\right.$
>
> > [!note]- **【解析】**
> > （1） $f(x)=0$ 在 $(0,+\infty)$ 上有解，
> >
> > 即 $x + \frac{1}{x} = \frac{a^2 - 2a + 2}{1 - a}$ 在 $(0, +\infty)$ 上有解，
> >
> > 因为 $x > 0, x + \frac{1}{x}$ 2，所以 $\frac{a^2 - 2a + 2}{1 - a}$ 2
> >
> > 因为 $a^2 - 2a + 2 = (a - 1)^2 + 1 > 0$
> >
> > 所以 $\left\{ \begin{array}{ll}1 - a > 0\\ a^2 -2a + 2 & 2(1 - a) \end{array} \right.$ ，解得 $a <   1$
> >
> > 所以 $a$ 的取值范围是 $(- \infty, 1)$
> >
> > (2) 因为 $\frac{a^{2}-2a+2}{a-1}=a-1+\frac{1}{a-1}$ ,
> >
> > 所以 $f(x)$ 0 即 $x^{2}+\left(a-1+\frac{1}{a-1}\right)x+1$ 0，即 $\left(x + a - 1\right)\left(x + \frac{1}{a - 1}\right) = 0$
> > - **①**：当 $1 - a = \frac{1}{1 - a}$ ，即 a = 0 或 a = 2 时， $f(x)$ 0 的解集为 R；
> > - **②**：当 $1 - a > \frac{1}{1 - a}$ ，即 $1 < a < 2$ 或 $a < 0$ 时， $f(x)$ 0的解集为 $\left(-\infty, \frac{1}{1 - a}\right] \cup [1 - a, +\infty)$ ；
> > - **③**：当 $1 - a < \frac{1}{1 - a}$ ，即 $a > 2$ 或 $0 < a < 1$ 时， $f(x)$ 0 的解集为 $\left(-\infty, 1 - a\right] \cup \left[\frac{1}{1 - a}, +\infty\right)$
> >
> > 综上可得， $a = 0$ 或 $a = 2$ 时原不等式的解集为 $\mathbf{R}$
> >
> > $a < 0$ 或 $1 < a < 2$ 时原不等式的解集为 $\left(-\infty, \frac{1}{1 - a}\right] \cup [1 - a, +\infty)$ ,
> >
> > $0 < a < 1$ 或 $a > 2$ 时原不等式的解集为 $\left(-\infty, 1 - a\right] \cup \left[\frac{1}{1 - a}, +\infty\right)$
> >
> > (3) 由题意知 $m > \frac{1}{2}$ , 当 $a = -1$ 时, $f(x) = \left(x - \frac{1}{2}\right)(x - 2), g(x) = \left|\left(x - \frac{1}{2}\right)(x - 2)\right|$ ,
> >
> > $g(x)$ 在 $\left[\frac{1}{2},\frac{5}{4}\right]$ 上单调递增，
> >
> > 当 $\frac{1}{2} < m \leq \frac{5}{4}$ 时， $h(m) = g(m) = -m^2 + \frac{5}{2} m - 1,$
> >
> > $g(x)$ 在 $\left[\frac{5}{4},2\right]$ 上单调递减，在 $[2, + \infty)$ 上单调递增，
> >
> > 且 $g\left(\frac{5}{4}\right) = \frac{9}{16}$ ，令 $g(x) = \frac{9}{16}$ ，解得 $x = \frac{5\pm 3\sqrt{2}}{4}$ 或 $x = \frac{5}{4}$
> >
> > 所以当 $\frac{5}{4} < m \leq \frac{5 + 3\sqrt{2}}{4}$ 时， $h(m) = g\left(\frac{5}{4}\right) = \frac{9}{16}$ ，
> >
> > 当 $m > \frac{5 + 3\sqrt{2}}{4}$ 时， $h(m) = g(m) = m^2 - \frac{5}{2} m + 1$
> >
> > 综上: $h(m)=\left\{\begin{aligned}-m^{2}+\frac{5}{2}m-1,\frac{1}{2}<m\leq\frac{5}{4}\\ \frac{9}{16},\frac{5}{4}<m\leq\frac{5+3\sqrt{2}}{4}\end{aligned}\right.$ $m^{2}-\frac{5}{2}m+1,m>\frac{5+3\sqrt{2}}{4}$
