> [!faq]- 《专题03 二次函数与一元二次方程、不等式的四大常考题型（高效培优专项训练）》官方解析
>
> > [!success]- **【答案】** $\frac{3}{m}$
>
> > [!note]- **【解析】**
> > 当 $m > 0$ 时， $\frac{1}{x - 1} +\frac{2}{x - 2}$ $m\Leftrightarrow \frac{mx^2 - (3 + 3m)x + 2m + 4}{(x - 1)(x - 2)}\leq 0$
> >
> > 令 $y = mx^{2} - (3 + 3m)x + 2m + 4$ ，则 $\Delta = 9(m + 1)^{2} - 8m(m + 2) = m^{2} + 2m + 9 > 0$
> >
> > 令 y=0 的两根为 $x_{1}, x_{2}$ ，且 $x_{1}<x_{2}$ ， $x_{1}+x_{2}=\frac{3+3m}{m}=3+\frac{3}{m}$ ，
> >
> > 则 $\frac{m(x - x_1)(x - x_2)}{(x - 1)(x - 2)}\leq 0$ ，因此 $\left\{ \begin{array}{ll}(x - x_1)(x - x_2)\leq 0\\ (x - 1)(x - 2) > 0 \end{array} \right.$ 或 $\left\{ \begin{array}{ll}(x - x_1)(x - x_2) & 0\\ (x - 1)(x - 2) <   0 \end{array} \right.,$
> >
> > 而当 $x = 1$ 时， $y = m - 3 - 3m + 2m + 4 = 1 > 0$
> >
> > 当 $x = 2$ 时， $y = 4m - 6 - 6m + 2m + 4 = -2 < 0$ ，于是 $1 < x_{1} < 2 < x_{2}$
> >
> > 解 $\left\{ \begin{array}{l}(x - x_1)(x - x_2) \leq 0 \\ (x - 1)(x - 2) > 0 \end{array} \right.$ 得 $2 < x \leq x_2$ ，解 $\left\{ \begin{array}{ll} (x - x_1)(x - x_2) & 0 \\ (x - 1)(x - 2) < 0 \end{array} \right.$ 得 $1 < x \leq x_1$ ，
> >
> > 则不等式 $\frac{1}{x - 1} +\frac{2}{x - 2}$ $m(m > 0)$ 的解集为 $(1,x_1]\cup (2,x_2]$
> >
> > 所以 $l = x_{1} - 1 + x_{2} - 2 = x_{1} + x_{2} - 3 = 3 + \frac{3}{m} - 3 = \frac{3}{m}$ .
> >
> > 故答案为： $\frac{3}{m}$
