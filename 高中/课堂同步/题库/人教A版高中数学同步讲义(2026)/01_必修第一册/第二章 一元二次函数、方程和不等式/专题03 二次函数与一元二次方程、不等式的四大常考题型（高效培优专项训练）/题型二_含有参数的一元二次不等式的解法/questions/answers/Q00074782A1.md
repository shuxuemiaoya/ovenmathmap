> [!faq]- 《专题03 二次函数与一元二次方程、不等式的四大常考题型（高效培优专项训练）》官方解析
>
> > [!success]- **【答案】** (1,2)
>
> > [!note]- **【解析】**
> > 当 $a = 1$ 时，不等式 $\left(a^2 - 1\right)x^2 + 2bx - b^2 < 0$ 化为 $2bx - b^2 < 0$
> >
> > 因为 $0 < b < a + 1$ ，所以该不等式解集为 $\left\{x \mid x < \frac{b}{2}\right\}$ ，不满足解集中的整数恰有4个；
> >
> > 当 $a < 1$ 时， $a^2 - 1 < 0$ ，显然 $\left(a^2 - 1\right)x^2 + 2bx - b^2 < 0$ 不满足解集中的整数恰有4个；
> >
> > 所以 $a > 1$ ， $a^2 - 1 > 0$ ，不等式 $\left(a^2 - 1\right)x^2 + 2bx - b^2 < 0$ 化为 $\left[(a + 1)x - b\right]\left[(a - 1)x + b\right] < 0$
> >
> > 解方程 $\left[(a + 1)x - b\right]\left[(a - 1)x + b\right] = 0\Rightarrow x_1 = \frac{b}{a + 1} < 1,x_2 = -\frac{b}{a - 1} < 0$
> >
> > 所以不等式的解集为 $-\frac{b}{a - 1} < x < \frac{b}{a + 1} < 1$ ，又 $\frac{b}{a + 1} > 0$
> >
> > 所以不等式解集中的整数是-3,-2,-1,0
> >
> > 所以 $-4 \leq -\frac{b}{a-1} < -3$ ，所以 $3(a-1) < b \leq 4(a-1)$ ，
> >
> > 又因为 $0 < b < a + 1$ ，所以 $3(a - 1) < 1 + a$ ，即 $a < 2$ ，所以 $1 < a < 2$ ，
> >
> > 综上，满足题意的实数 $a$ 的取值范围为 $(1,2)$
> >
> > 故答案为： $(1,2)$ .
