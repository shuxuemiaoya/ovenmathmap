> [!faq]- 《专题2.1 等式性质与不等式性质（高效培优讲义）》官方解析
>
> > [!success]- **【答案】** (1) $8 < m + 2n < 14(2) - 3 < m - n < 1(3)6 < mn < 20(4)\frac{2}{5} < \frac{m}{n} < \frac{4}{3}$
>
> > [!note]- **【解析】**
> > （1）∵3<n<5，∴6<2n<10。又∵2<m<4，∴8<m+2n<14。
> >
> > $$
> > (2) \because 3 <   n <   5, \therefore - 5 <   - n <   - 3. \text {又} \because 2 <   m <   4, \therefore - 3 <   m - n <   1.
> > $$
> >
> > (3) $\because 2 < m < 4, 3 < n < 5, \therefore 6 < mn < 20.$
> >
> > (4) $\because 3 < n < 5$ ， $\therefore \frac{1}{5} < \frac{1}{n} < \frac{1}{3}$ . 由 $2 < m < 4$ ，可得 $\frac{2}{5} < \frac{m}{n} < \frac{4}{3}$ .
