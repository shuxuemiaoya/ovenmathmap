> [!faq]- 《专题2.1 等式性质与不等式性质（高效培优讲义）》官方解析
>
> > [!success]- **【答案】** $$ \left(- \frac {3}{2}, \frac {2 3}{2}\right) $$
>
> > [!note]- **【解析】**
> > 若 $x, y$ 满足 $1 < x < 6, 2 < y < 3$ ，则 $\frac{1}{3} < \frac{1}{y} < \frac{1}{2}$ ，从而 $\frac{1}{3} < \frac{x}{y} < 3$ 。若 $-1 < x + y < 4, 2 < x - y < 3$ ，设
> >
> > $3x + 2y = m(x + y) + n(x - y) = (m + n)x + (m - n)y$ ，所以 $\left\{\begin{aligned}m+n&=3,\\ m-n&=2,\end{aligned}\right.$ 解得 $m=\frac{5}{2},n=\frac{1}{2}$ ，则有
> >
> > $-\frac{5}{2} < \frac{5}{2}(x + y) < 10, 1 < \frac{1}{2}(x - y) < \frac{3}{2}$ ，所以 $-\frac{3}{2} < 3x + 2y < \frac{23}{2}$
