> [!faq]- 《专题2.1 等式性质与不等式性质（高效培优讲义）》官方解析
>
> > [!success]- **【答案】** A. a > b > c B. c > a > b C. a > c > b D. b > c > a
>
> > [!note]- **【分析】**
> > 将 $b, c$ 化简，使分子相同，即可根据分母大小关系进行比较；利用作差比较 $a, c$ 大小关系即可·
>
> > [!note]- **【解析】**
> > $b = \sqrt{7} - \sqrt{5} = \frac{2}{\sqrt{7} + \sqrt{5}}, c = \sqrt{6} - 2 = \frac{2}{\sqrt{6} + 2}$ ， $\because \sqrt{7} + \sqrt{5} > \sqrt{6} + 2, \therefore \frac{2}{\sqrt{7} + \sqrt{5}} < \frac{2}{\sqrt{6} + 2}$
> >
> > $\therefore b < c$
> >
> > 又 $a - c = \frac{5}{2} -\sqrt{6} = \sqrt{\frac{25}{4}} -\sqrt{6} >0$ ，故 $a > c$
> >
> > 则 a > c > b.
> >
> > 故选：C.

> > 19. 如果 $a < 0$ ， $-1 < b < 0$ ，那么下列不等式成立的是（ ）A. $a > ab > ab^2$ B. $ab^2 > ab > a$ C. $ab > a > ab^2$ D. $ab > ab^2 > a$
> >
> > 【答案】D
> >
> > 【分析】通过观察三个数的特征可知ab最大，再利用作差法判断即可得出结果·
> >
> > 【详解】由选项可知，仅需要比较 $a, ab, ab^2$ 三个数的大小，
> >
> > 显然， $a <   0,ab > 0,ab^{2} <   0$ ，所以 $ab$ 最大，
> >
> > 由 -1 < b < 0 可得， $0 < b^{2} < 1$
> >
> > 所以 $ab^{2} - a = a(b^{2} - 1) > 0$ ，即 $ab^2 >a$
> >
> > 可得 $ab > ab^2 > a$
> >
> > 故选 **D**
