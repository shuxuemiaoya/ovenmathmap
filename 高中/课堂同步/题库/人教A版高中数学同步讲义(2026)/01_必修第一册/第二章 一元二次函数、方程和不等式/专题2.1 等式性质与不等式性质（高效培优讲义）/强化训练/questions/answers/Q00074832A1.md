> [!faq]- 《专题2.1 等式性质与不等式性质（高效培优讲义）》官方解析
>
> > [!success]- **【答案】** A. 若 $a > b$ ，则 $ac > bc$ B．若a>b>0，c<0，则 $\frac{c}{a}>\frac{c}{b}$ C．若 a > b > c， $a + b + c = 0$ ，则 $\frac{c}{a - c} < \frac{c}{b - c}$ D．若 a > b > 0，c < 0，则 $\frac{b - c}{a - c} < \frac{b}{a}$
>
> > [!note]- **【分析】**
> > 根据不等式的性质，结合特例法进行判断即可·
>
> > [!note]- **【解析】**
> > 因为 a > b, c = 0 ，则 ac = bc, A 选项错误；
> >
> > 若 $a > b > 0, ab > 0, \frac{1}{ab} > 0, \therefore \frac{1}{a} < \frac{1}{b}, \because c < 0, \therefore \frac{c}{a} > \frac{c}{b}, B$ 选项正确；
> >
> > 若 $a > b > c$ ， $a + b + c = 0$ 取 $a = 1, b = 0, c = -1, \therefore \frac{c}{a - c} = \frac{-1}{1 + 1} = -\frac{1}{2}, \frac{c}{b - c} = \frac{-1}{0 + 1} = -1$
> >
> > $\therefore \frac{c}{a-c} > \frac{c}{b-c}, C$ 选项错误；
> >
> > 若 $a > b > 0$ ， $c < 0$ ，取 $a = 3, b = 2, c = -1, \frac{b - c}{a - c} = \frac{2 + 1}{3 + 1} = \frac{3}{4}, \frac{b}{a} = \frac{2}{3}$ 则 $\frac{b - c}{a - c} > \frac{b}{a}$ , D选项错误.
> >
> > 故选 **B**.
