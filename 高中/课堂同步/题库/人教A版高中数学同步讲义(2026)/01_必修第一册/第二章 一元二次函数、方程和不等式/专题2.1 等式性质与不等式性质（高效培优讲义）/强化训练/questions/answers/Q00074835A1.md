> [!faq]- 《专题2.1 等式性质与不等式性质（高效培优讲义）》官方解析
>
> > [!success]- **【答案】** A. $a - b < 0$ $\mathsf{B}_{\cdot}a - b < 1$ $\mathsf{C}_{\cdot}a^{4} - b^{4} < 1$ $\mathsf{D}_{\cdot}\sqrt{a} -\sqrt{b} >1$
>
> > [!note]- **【分析】**
> > 对于选项 $^{A}$ ：结合已知条件，利用不等式性质即可求解；对于选项 $^{BC}$ ：首先根据已知条件可得到
> >
> > $a - b = \frac{1}{a + b} < a + b$ ，然后利用不等式性质即可求解；对于选项D：首先对 $\sqrt{a}$ 和 $\sqrt{b} + 1$ 平方，然后利用作差法
> >
> > 即可求解·
>
> > [!note]- **【解析】**
> > 对于 A：因为 $a^{2}-b^{2}=1>0$ ，故 $a^{2}>b^{2}$
> >
> > 又因为 a > 0，b > 0，所以 a > b，从而 a - b > 0，故 A 错误；
> >
> > 对于 B：由题意可知， $a^{2}-b^{2}=(a-b)(a+b)=1$ ，
> >
> > 因为 $a > b > 0$ ，所以 $a - b = \frac{1}{a + b} < a + b$
> >
> > 故 $(a + b)^2 > 1$ ，即 $a + b > 1$ ，从而 $a - b = \frac{1}{a + b} < 1$ ，故 B 正确，
> >
> > 对于 C：因为 $a^{2}-b^{2}=1$ ，所以 $a^{2}=1+b^{2}$ ，
> >
> > 所以 $a^{4}-b^{4}=\left(a^{2}-b^{2}\right)\left(a^{2}+b^{2}\right)=a^{2}+b^{2}=1+b^{2}+b^{2}=1+2b^{2}>1$ ，故 C 错误；
> >
> > 对于选项D：因为 $(\sqrt{a})^2 - (\sqrt{b} + 1)^2 = a - b - 1 - 2\sqrt{b} < 0$
> >
> > 所以 $\sqrt{a} < \sqrt{b} + 1$ ，即 $\sqrt{a} - \sqrt{b} < 1$ ，故 $^D$ 错误·
> >
> > 故选 **B**.
