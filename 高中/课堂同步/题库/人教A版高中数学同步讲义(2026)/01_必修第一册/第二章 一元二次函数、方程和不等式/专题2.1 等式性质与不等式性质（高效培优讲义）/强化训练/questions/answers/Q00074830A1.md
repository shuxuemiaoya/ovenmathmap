> [!faq]- 《专题2.1 等式性质与不等式性质（高效培优讲义）》官方解析
>
> > [!success]- **【答案】** A
>
> > [!note]- **【分析】**
> > 用已知式子 $a + b, a - b$ 表示 $ab$ ，并利用不等式的性质求 $ab$ 的范围，验证最大值取到即可·
>
> > [!note]- **【解析】**
> > $4ab = (a + b)^2 - (a - b)^2$
> >
> > 由不等式的性质 $9 \leq (a + b)^2 \leq 16$ ， $1 \leq (a - b)^2 \leq 4$ ，所以 $-4 \leq -(a - b)^2 \leq -1$
> >
> > 所以 $5 \leq (a + b)^2 - (a - b)^2 \leq 15$ ，所以 $\frac{5}{4} \leq ab \leq \frac{15}{4}$
> >
> > 当且仅当 $\left\{ \begin{array}{l} (a + b)^2 = 16 \\ (a - b)^2 = 1 \end{array} \right.$ 时，且已知，解得 $\left\{ \begin{array}{l} a = \frac{5}{2} \\ b = \frac{3}{2} \end{array} \right.$ ，且已知 $a + b > 0, a - b > 0$
> >
> > 即 $ab$ 的最大值为 $\frac{15}{4}$
> >
> > 故选 **A**.
