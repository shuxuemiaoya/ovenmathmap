> [!faq]- 《专题2.1 等式性质与不等式性质（高效培优讲义）》官方解析
>
> > [!success]- **【答案】** 详见解析·
>
> > [!note]- **【分析】**
> > 根据不等式的基本性质和反比例函数特点即可求解·
>
> > [!note]- **【解析】**
> > 因为 2 < a < 3 ， -2 < b < -1 ，
> >
> > 所以 $2 + (-2) < a + b < 3 + (-1)$
> >
> > 即 $a + b$ 的取值范围是 $(0,2)$
> >
> > 由 $4 < 2a < 6$ ， $1 < -b < 2$
> >
> > 得 5 < 2a - b < 8
> >
> > 所以 $2a - b$ 的取值范围是 $(5,8)$
> >
> > 由 2 < a < 3 ，1 < -b < 2 ，
> >
> > 得 $2 < -ab < 6$
> >
> > 所以 $ab$ 的取值范围是 $(-6, -2)$
> >
> > 易知 $\frac{1}{2}<-\frac{1}{b}<1$ ，
> >
> > 而 $2 < a < 3$
> >
> > 则 $1 < -\frac{a}{b} < 3$
> >
> > 所以 $\frac{a}{b}$ 的取值范围是 $(-3, -1)$ .
