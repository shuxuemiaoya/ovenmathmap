> [!faq]- 《专题2.1 等式性质与不等式性质（高效培优讲义）》官方解析
>
> > [!success]- **【答案】** A．若 a > b, c > d，则 $a + c > b + d$ B．若 a < b < 0, c < 0，则 $\frac{c}{a} < \frac{c}{b}$ C．若 a > b，则 $ac^{2} > bc^{2}$ D．若 a > b, c > d，则 ac > bd
>
> > [!note]- **【分析】**
> > 利用不等式的基本性质可判断 $^{A}$ ；利用作差法比较出大小可判断 $^{B}$ ；举出反例可判断CD.
>
> > [!note]- **【解析】**
> > 对于 $^{A}$ ，由不等式的性质可知同向不等式相加，不等式方向不变，故 $^{A}$ 正确；
> >
> > 对于 B， $\frac{c}{a}-\frac{c}{b}=\frac{c(b-a)}{ab}$ ，因为 b-a>0, c<0, ab>0，所以 $\frac{c}{a}-\frac{c}{b}<0$ ，故 B 正确；
> >
> > 对于 C，当 c=0 时， $ac^{2}=bc^{2}$ 故 C 错误；
> >
> > 对于 D，当 a = -1, b = -2. c = 2, d = 1 时，ac = bd，故 D 错误；
> >
> > 故选 **AB**.
