> [!faq]- 《专题2.1 等式性质与不等式性质（高效培优讲义）》官方解析
>
> > [!success]- **【答案】** $\left\{t\mid -\frac{9}{2} < t < \frac{13}{2}\right\}$
>
> > [!note]- **【分析】**
> > 利用不等式的性质运算即可得解·
>
> > [!note]- **【解析】**
> > 解：设 $t = 2a + 3b = x(a + b) + y(a - b)$ ，则 $\left\{ \begin{array}{l}x + y = 2\\ x - y = 3 \end{array} \right.$
> >
> > $$
> > x = \frac {5}{2} \quad y = - \frac {1}{2} \quad t = 2 a + 3 b = \frac {5}{2} (a + b) - \frac {1}{2} (a - b)
> > $$
> >
> > 而由 $-1 < a + b < 3$ ，可得 $-\frac{5}{2} < \frac{5}{2}(a + b) < \frac{15}{2}$
> >
> > 再由 $2 < a - b < 4$ ，可得 $-2 < -\frac{1}{2} (a - b) < -1$
> >
> > 所以 $-\frac{5}{2} - 2 < \frac{5}{2}(a + b) - \frac{1}{2}(a - b) < \frac{15}{2} - 1$
> >
> > 即 $-\frac{9}{2}<2a+3b<\frac{13}{2}$ ，可得 $-\frac{9}{2}<t<\frac{13}{2}$
> >
> > 故答案为： $\left\{t\mid -\frac{9}{2} <  t <   \frac{13}{2}\right\} .$
