> [!faq]- 《专题2.1 等式性质与不等式性质（高效培优讲义）》官方解析
>
> > [!success]- **【答案】** AC
>
> > [!note]- **【分析】**
> > 由不等式的性质可判断 A, C；由特值法可判断 B, D.
>
> > [!note]- **【解析】**
> > 由 $\frac{1}{b} < \frac{1}{a} < 0 < \frac{1}{d} < \frac{1}{c}$ ，得 $a < b < 0 < c < d$
> >
> > 对于 A，由 d > c，b > a，得 $d + b > a + c$ 成立，该选项正确；
> >
> > 对于 B，取 a = -2 ， b = -1 ， c = 1 ， d = 2 得 d - b = 3 ， c - a = 3 ，
> >
> > 此时 $d - b = c - a$ ，该选项错误；
> >
> > 对于 C，由 d > c > 0，-a > -b > 0，得 -ad > -bc，所以 ad < bc 成立，该选项正确；
> >
> > 对于 D，取 a = -2 ， b = -1 ， c = 1 ， d = 2 得 bd = -2 ， ac = -2 ，此时 bd = ac ，该选项错误
> >
> > 故选 **AC**.
