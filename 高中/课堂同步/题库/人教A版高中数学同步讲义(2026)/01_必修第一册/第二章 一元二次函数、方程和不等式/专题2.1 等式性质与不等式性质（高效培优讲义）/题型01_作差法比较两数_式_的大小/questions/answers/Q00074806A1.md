> [!faq]- 《专题2.1 等式性质与不等式性质（高效培优讲义）》官方解析
>
> > [!success]- **【答案】** (1)证明见解析 (2)证明见解析
>
> > [!note]- **【解析】**
> > （1）解法 $^{1}$ 因为 a > b > c 且 $a + b + c = 0$ ，所以 c < 0，且 a - c > b - c > 0，两边取倒数得 $\frac{1}{a - c} < \frac{1}{b - c}$ ，又 c < 0，则 $\frac{c}{a - c} > \frac{c}{b - c}$ ，从而得证．
> >
> > 解法 $^{2}$ 因为 a > b > c 且 $a + b + c = 0$ ，所以 c < 0，且 a - c > b - c > 0，所以
> >
> > $\frac{c}{a - c} - \frac{c}{b - c} = \frac{c(b - c) - c(a - c)}{(a - c)(b - c)} = \frac{c(b - a)}{(a - c)(b - c)} > 0$ 即 $\frac{c}{a - c} > \frac{c}{b - c}$
> >
> > (2) 因为 $a > b > c$ 且 $a + b + c = 0$ ，所以 $a > 0$ ， $c < 0$ ，则 $\frac{c}{a} < 0$ ， $\frac{b}{a} < 1$ ，由 $a + b + c = 0$ ，可得 $1 + \frac{b}{a} + \frac{c}{a} = 0$ ，即 $\frac{b}{a} = -\frac{c}{a} - 1$ ，所以 $-\frac{c}{a} - 1 < 1$ ，即 $\frac{c}{a} > -2$ 。综上， $-2 < \frac{c}{a} < 0$ 。
