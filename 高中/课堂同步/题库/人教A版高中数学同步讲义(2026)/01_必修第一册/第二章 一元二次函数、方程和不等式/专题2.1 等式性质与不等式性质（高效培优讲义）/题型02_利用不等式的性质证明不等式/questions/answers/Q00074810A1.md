> [!faq]- 《专题2.1 等式性质与不等式性质（高效培优讲义）》官方解析
>
> > [!success]- **【答案】** （1）证明见解析；（2）-7<a-b<2；（3） $\frac{1}{8}<\frac{a}{b}<2$
>
> > [!note]- **【解析】**
> > （1）证明：因为 $c < d < 0$ ，所以 $-c > -d > 0$ 。又 $a > b > 0$ ，所以 $a - c > b - d > 0$ ，所以
> >
> > $(a - c)^2 > (b - d)^2 > 0$ ，所以 $\frac{1}{(a - c)^2} < \frac{1}{(b - d)^2}$ 。又 $e < 0$ ，所以 $\frac{e}{(a - c)^2} > \frac{e}{(b - d)^2}$
> >
> > (2) 解：因为 $1 < a < 4$ ， $2 < b < 8$ ，所以 $2 < 2a < 8$ ，且 $6 < 3b < 24$ ，所以 $8 < 2a + 3b < 32$ 。因为 $2 < b < 8$
> >
> > 所以 $-8 < -b < -2$ 。又因为 $1 < a < 4$ ，所以 $-7 < a - b < 2$ 。故 $2a + 3b$ 的取值范围是 $8 < 2a + 3b < 32$ ， $a - b$ 的
> >
> > 取值范围是 $-7 < a - b < 2$
> >
> > (3) 解：由 $2 < b < 8$ ，得 $\frac{1}{8} < \frac{1}{b} < \frac{1}{2}$ 。又 $1 < a < 4$ ，所以 $1 \times \frac{1}{8} < a \cdot \frac{1}{b} < 4 \times \frac{1}{2}$ ，即 $\frac{1}{8} < \frac{a}{b} < 2$ 。故 $\frac{a}{b}$ 的取值范围是
> >
> > $$
> > \frac {1}{8} <   \frac {a}{b} <   2
> > $$
