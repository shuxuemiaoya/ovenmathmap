> [!faq]- 《专题2.1 等式性质与不等式性质（高效培优讲义）》官方解析
>
> > [!success]- **【答案】** 证明见解析
>
> > [!note]- **【分析】**
> > 由 $x + y + z > x + y$ ， $x + y + z > x + z$ ， $x + y + z > y + z$ 和 $\frac{x}{x + y} > \frac{x}{x + y + z}$ ， $\frac{y}{y + z} > \frac{y}{x + y + z}$
> >
> > $\frac{z}{z + x} > \frac{z}{x + y + z}$ 证明即可.
>
> > [!note]- **【解析】**
> > 由题意知x>0，y>0，z>0，
> >
> > 则有 $x + y + z > x + y$ ， $x + y + z > x + z$ ， $x + y + z > y + z$ ，①
> >
> > $$
> > {\frac {x}{x + y}} > {\frac {x}{x + y + z}} \quad {\frac {y}{y + z}} > {\frac {y}{x + y + z}} \quad {\frac {z}{z + x}} > {\frac {z}{x + y + z}}
> > $$
> >
> > 所以 $\frac{x}{x+y}+\frac{y}{y+z}+\frac{z}{z+x}>\frac{x}{x+y+z}+\frac{y}{x+y+z}+\frac{z}{x+y+z}=1$
> >
> > 又根据①的结论可知 $\frac{x}{x + y} < \frac{x + z}{x + y + z}$ ， $\frac{y}{y + z} < \frac{x + y}{x + y + z}$ ， $\frac{z}{z + x} < \frac{y + z}{x + y + z}$
> >
> > 所以 $\frac{x}{x + y} +\frac{y}{y + z} +\frac{z}{z + x} <  \frac{x + z}{x + y + z} +\frac{x + y}{x + y + z} +\frac{y + z}{x + y + z} = 2$
> >
> > 综上所述， $1<\frac{x}{x+y}+\frac{y}{y+z}+\frac{z}{z+x}<2$
