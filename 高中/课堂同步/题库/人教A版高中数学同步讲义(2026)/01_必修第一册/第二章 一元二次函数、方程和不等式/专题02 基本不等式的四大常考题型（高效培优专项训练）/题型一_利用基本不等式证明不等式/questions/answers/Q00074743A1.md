> [!faq]- 《专题02 基本不等式的四大常考题型（高效培优专项训练）》官方解析
>
> > [!success]- **【答案】** A. $ac > bc$ B. $\frac{c}{a} < \frac{c}{b}$ C. $\frac{b}{a} + \frac{a}{b} > 2$ D. $a|c| < b|c|$
>
> > [!note]- **【解析】**
> > 因为 a > b > c 且 abc < 0
> >
> > 所以 $ab > 0$ ， $c <   0$
> >
> > 对于 A ，因为 a > b ， c < 0 ，所以 ac < bc ，故 A 错误；
> >
> > 对于 B， $\frac{c}{a}-\frac{c}{b}=\frac{bc-ac}{ab}=\frac{c(b-a)}{ab}$
> >
> > 因为 $a > b$ ， $c < 0$
> >
> > 所以 $c(b-a)>0$ ，
> >
> > 又因为 ab > 0，
> >
> > 所以 $\frac{c}{a} -\frac{c}{b} >0$
> >
> > 即 $\frac{c}{a} >\frac{c}{b}$ ，故B错误；
> >
> > 对于 C，因为 ab > 0
> >
> > 所以 $\frac{b}{a},\frac{a}{b} >0$
> >
> > 所以 $\frac{b}{a} +\frac{a}{b}$ $2\sqrt{\frac{b}{a}\times\frac{a}{b}} = 2$ ，当且仅当 $a = b$ 时等号成立，
> >
> > 所以 $\frac{b}{a} +\frac{a}{b} >2$ ，故C正确；
> >
> > 对于 D，因为 c < 0 ，
> >
> > 所以 $|c|>0$ ，
> >
> > 又因为 a > b
> >
> > 所以 $a \mid c \mid > b \mid c \mid$ ，故 D 错误.
> >
> > 故选：C.
> >
> > 4. “0 < a + b ≤ 6”是“ab ≤ 9”的（）
> >
> > 【答案】
> > A．充分不必要条件
> > B．必要不充分条件
> > C．充分必要条件
> > D．既不充分也不必要条件
> >
> > 【答案】A
> >
> > 【详解】当 $a + b > 0, ab \leq 0$ 时，显然 $ab \leq 9$ 成立，反之不成立；
> >
> > 当 $a > 0, b > 0$ 时，则 $6 \geq a + b \geq 2\sqrt{ab}$ ，故 $\sqrt{ab} \leq 3, ab \leq 9$ ，充分性成立；
> >
> > 令 $a = 9, b = \frac{1}{9}$ ，由 $ab \leq 9$ 推不出 $a + b \leq 6$ ，故“ $0 < a + b \leq 6$ ”是“ $ab \leq 9$ ”的充分不必要条件，
> >
> > 故选 **A**.
