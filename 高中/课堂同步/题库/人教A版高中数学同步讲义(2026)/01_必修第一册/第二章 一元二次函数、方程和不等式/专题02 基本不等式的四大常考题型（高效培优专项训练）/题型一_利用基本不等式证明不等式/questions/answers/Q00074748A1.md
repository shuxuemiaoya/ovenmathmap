> [!faq]- 《专题02 基本不等式的四大常考题型（高效培优专项训练）》官方解析
>
> > [!success]- **【答案】** （1）① 证明见解析；②证明见解析；（2）8.
>
> > [!note]- **【解析】**
> > （1）①a，b，c均为正实数，
> >
> > 则 $a + \frac{b^2}{a}$ 2b（当且仅当 $a = b$ 时取“=”），
> >
> > 同理可得： $b+\frac{c^{2}}{b}$ 2c， $c+\frac{a^{2}}{c}$ 2a（当且仅当b=c，c=a时等号成立），
> >
> > 故 $a + \frac{b^2}{a} + b + \frac{c^2}{b} + c + \frac{a^2}{c}$ $2a + 2b + 2c$ （当且仅当 $a = b = c$ 时取“=”），
> >
> > 又 $a+b+c=3$ ，故 $\frac{b^{2}}{a}+\frac{c^{2}}{b}+\frac{a^{2}}{c}$ 3；
> > - **②**：$\sqrt{a^{2}b+b^{2}a}=\sqrt{ab(a+b)}=\sqrt{2}\times\sqrt{ab}\times\sqrt{\frac{a+b}{2}}$
> >
> > $$
> > \leq \sqrt {2} \times \frac {a b + \frac {a + b}{2}}{2} = \frac {\sqrt {2}}{2} a b + \frac {\sqrt {2}}{4} (a + b)
> > $$
> >
> > (当且仅当 $ab=\frac{a+b}{2}$ 时取“=”)，
> >
> > 同理 $\sqrt{b^2c + c^2b} \leq \frac{\sqrt{2}}{2} bc + \frac{\sqrt{2}}{4}(b + c)$ （当且仅当 $bc = \frac{b + c}{2}$ 时取“=”），
> >
> > $\sqrt{c^{2}a+a^{2}c}\leq\frac{\sqrt{2}}{2}ac+\frac{\sqrt{2}}{4}(a+c)$ （当且仅当 $ac=\frac{a+c}{2}$ 时取“=”）.
> >
> > 又由 $a + b + c = 3$ ， $2a^{2} + 2b^{2} + 2c^{2} = (a^{2} + b^{2}) + (b^{2} + c^{2}) + (a^{2} + c^{2})$ $2ab + 2bc + 2ac$
> >
> > 所以 $9 = (a + b + c)^2 = a^2 + b^2 + c^2 + 2ab + 2ac + 2bc$ ， $3(ab + bc + ac)$ ，（当且仅当 $a = b = c$ 时取“=”），
> >
> > 所以 $ab + bc + ac \leq 3$
> >
> > 故 $\sqrt{a^2b + b^2a} +\sqrt{b^2c + c^2b} +\sqrt{c^2a + a^2c}$
> >
> > $$
> > \leq \frac {\sqrt {2}}{2} (a b + b c + c a) + \frac {\sqrt {2}}{2} (a + b + c) \leq 3 \sqrt {2}
> > $$
> >
> > (当且仅当 a=b=c=1 时取“=”).
> >
> > (2) 因为对任意 $x \in R$ ，不等式 $ax^{2} + 2x + c = 0$ 恒成立，
> >
> > 所以 0 < a < 2, 4 - 4ac ≤ 0，则 $\frac{a + 4c + 4}{2 - a} = \frac{\frac{4}{a} + \frac{4c}{a} + 1}{\frac{2}{a} - 1}$ $\frac{\frac{4}{a^{2}} + \frac{4}{a} + 1}{\frac{2}{a} - 1}$ ，
> >
> > 令 $t = \frac{2}{a} - 1$ ，则 $t > 0$ ， $\frac{2}{a} = t + 1$
> >
> > 所以 $\frac{a + 4c + 4}{2 - a}$ $\frac{(t + 1)^2 + 2(t + 1) + 1}{t} = t + 4 + \frac{4}{t}$ 8，
> >
> > 当且仅当 $t=\frac{4}{t}$ 即 $\frac{2}{a}=3,ac=1$ 时等号成立，
> >
> > 即当且仅当 $a = \frac{2}{3}, c = \frac{3}{2}$ 时等号成立，
> >
> > 所以 $\frac{a + 4c + 4}{2 - a}$ 的最小值为8·
