> [!faq]- 《专题02 基本不等式的四大常考题型（高效培优专项训练）》官方解析
>
> > [!success]- **【答案】** (1)证明见解析 (2)证明见解析，最小值为7 (3)证明见解析
>
> > [!note]- **【解析】**
> > （1）证明：由基本不等式得 $a + \frac{b}{2}\sqrt{2ab},\frac{b}{2} +c\sqrt{2bc}$
> >
> > 左右相加得 $a + b + c \sqrt{2ab} + \sqrt{2bc}$
> >
> > 当且仅当 $a = \frac{b}{2} = c$ 时“=”成立，问题得证·
> >
> > (2) 证明： $a^{3}+b^{3}+c^{3}-3abc=(a+b)^{3}-3a^{2}b-3ab^{2}+c^{3}-3abc$ $=(a+b)^{3}+c^{3}-3a^{2}b-3ab^{2}-3abc$ $=(a+b+c)\left[(a+b)^{2}-(a+b)c+c^{2}\right]-3ab(a+b+c)$ $=(a+b+c)\left[a^{2}+2ab+b^{2}-ac-bc+c^{2}-3ab\right]$ $=(a+b+c)\left(a^{2}+b^{2}+c^{2}-ab-bc-ca\right)$ $=\frac{1}{2}(a+b+c)\left[(a-b)^{2}+(b-c)^{2}+(c-a)^{2}\right]\quad0$
> >
> > 当且仅当 $a = b = c$ 时等号成立，
> >
> > 所以不等式 $a^3 + b^3 + c^3$ 3abc 成立；
> >
> > 所以 $a + b + c = \left(\sqrt[3]{a}\right)^{3} + \left(\sqrt[3]{b}\right)^{3} + \left(\sqrt[3]{c}\right)^{3}$ $3 \times \sqrt[3]{a} \times \sqrt[3]{b} \times \sqrt[3]{c} = 3\sqrt[3]{abc}$
> >
> > 所以 $\frac{a + b + c}{3} 3\sqrt[3]{abc}$ ，当且仅当 $a = b = c$ 时取等号，
> >
> > 故不等式 $\frac{a + b + c}{3} 3\sqrt[3]{abc}$ 成立；
> >
> > $$
> > \because x > 2, \therefore x - 2 > 0, y = 2 x + \frac {1}{(x - 2) ^ {2}} = (x - 2) + (x - 2) + \frac {1}{(x - 2) ^ {2}} + 4
> > $$
> >
> > $$
> > 3 \sqrt [ 3 ]{(x - 2) \cdot (x - 2) \cdot \frac {1}{(x - 2) ^ {2}}} + 4 = 7
> > $$
> >
> > 当且仅当 $x - 2 = \frac{1}{(x - 2)^2}$ ，即 $x = 3$ 时，等号成立， $\therefore y_{\mathrm{min}} = 7$ (3) 证明：令 $a = \left|\frac{y}{x}\right|, b = \left|\frac{x}{z}\right|, c = \left|\frac{z}{y}\right|$ ，则 $\frac{1}{a\sqrt{c^2 + 1}} = \frac{1}{\left|\frac{y}{x}\right|\sqrt{\frac{z^2}{y^2} + 1}} = \frac{|x|}{\sqrt{z^2 + y^2}} = \frac{x^2}{|x|\sqrt{z^2 + y^2}}$ 由基本不等式得 $|x|\sqrt{z^2 + y^2} \leq \frac{z^2 + y^2 + x^2}{2}$ ， $\therefore \frac{1}{a\sqrt{c^2 + 1}} = \frac{x^2}{|x|\sqrt{z^2 + y^2}} = \frac{2x^2}{z^2 + y^2 + x^2}$ ，同理可得 $\frac{1}{b\sqrt{a^2 + 1}} = \frac{2z^2}{z^2 + y^2 + x^2}, \frac{1}{c\sqrt{b^2 + 1}} = \frac{2y^2}{z^2 + y^2 + x^2}$ ，左右相加得 $\frac{1}{a\sqrt{c^2 + 1}} + \frac{1}{b\sqrt{a^2 + 1}} + \frac{1}{c\sqrt{b^2 + 1}} = \frac{2(z^2 + y^2 + x^2)}{z^2 + y^2 + x^2} = 2$ ，当且仅当 $\begin{cases} x^2 = y^2 + z^2 \\ y^2 = x^2 + z^2 \\ z^2 = y^2 + x^2 \end{cases}$ 时取“=”，显然不存在这种情况， $\therefore \frac{1}{a\sqrt{c^2 + 1}} + \frac{1}{b\sqrt{a^2 + 1}} + \frac{1}{c\sqrt{b^2 + 1}} > 2.$
