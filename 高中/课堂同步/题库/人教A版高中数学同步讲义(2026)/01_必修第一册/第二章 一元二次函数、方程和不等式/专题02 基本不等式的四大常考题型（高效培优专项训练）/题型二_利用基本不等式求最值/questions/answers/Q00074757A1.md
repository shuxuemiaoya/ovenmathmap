> [!faq]- 《专题02 基本不等式的四大常考题型（高效培优专项训练）》官方解析
>
> > [!success]- **【答案】** C
>
> > [!note]- **【解析】**
> > 解：∵ a、b、c 均大于 0，
> > ∴ $a(a+b+c)+bc=a^{2}+ab+ac+bc$ $=\left(a^{2}+ac\right)+\left(ab+bc\right)=a\left(a+c\right)+b\left(a+c\right)$ $=\left(a+b\right)\left(a+c\right)\leq\left[\frac{\left(a+b\right)+\left(a+c\right)}{2}\right]^{2}$ $=\left(\frac{2a+b+c}{2}\right)^{2}=\left(\frac{\sqrt{6}}{2}\right)^{2}=\frac{3}{2}$ 当且仅当 $a + b = a + c = \frac{\sqrt{6}}{2}$ 时取“=”，
> > ∴ $a(a+b+c)+bc$ 的最大值为 $\frac{3}{2}$ .
> > 故选:C

> > ## 19. 回答下列问题
> >
> > (1)已知 $0 < x < \frac{1}{3}$ ，求 $x(1 - 3x)$ 的最大值
> >
> > (2)已知正数 $a$ ， $b$ ， $x$ ， $y$ 满足 $a + b = 10$ ， $\frac{a}{x} +\frac{b}{y} = 1$ ， $x + y$ 的最小值为16，求 $a$ ， $b$ 的值
> >
> > (3)已知 $x > 0$ ， $y > 0$ 且 $x + y = 1$ ，求 $\frac{3x}{y} +\frac{1}{xy}$ 的最小值
> >
> > 【答案】(1) $\frac{1}{12}$
> >
> > (2) $\left\{\begin{aligned}a=1\\ b=9\end{aligned}\right.$ 或 $\left\{\begin{aligned}a=9\\ b=1\end{aligned}\right.$
> >
> > (3)6
> >
> > 【详解】（1）因为 $0 < x < \frac{1}{3}$ ，所以 1 - 3x > 0，
> >
> > 所以 $x(1-3x)=\frac{1}{3}\cdot3x\cdot(1-3x)\leq\frac{1}{3}\left[\frac{3x+(1-3x)}{2}\right]^{2}=\frac{1}{12}$
> >
> > 当且仅当 $3x = 1 - 3x$ ，即 $x = \frac{1}{6}$ 时，等号成立，
> >
> > 所以当 $x = \frac{1}{6}$ 时， $x(1 - 3x)$ 的最大值为 $\frac{1}{12}$ ；
> >
> > $$
> > x + y = (x + y) \left(\frac {a}{x} + \frac {b}{y}\right) = a + b + \frac {a y}{x} + \frac {b x}{y} \quad 1 0 + 2 \sqrt {\frac {a y}{x} \cdot \frac {b x}{y}} = 1 0 + 2 \sqrt {a b}, \tag {2}
> > $$
> >
> > 当且仅当 $\frac{ay}{x} = \frac{bx}{y}$ 时等号成立，
> >
> > 因为 $x + y$ 的最小值为16，所以 $10 + 2\sqrt{ab} = 16$ ，所以 $\sqrt{ab} = 3$ ，即 $ab = 9$
> >
> > 又因为 $a + b = 10$ ，解得 $\left\{ \begin{array}{l}a = 1\\ b = 9 \end{array} \right.$ 或 $\left\{ \begin{array}{l}a = 9\\ b = 1 \end{array} \right.$
> >
> > (3) 因为 $x > 0$ ， $y > 0$ ， $x + y = 1$
> >
> > 所以 $0 < x < 1$
> >
> > 所以 $\frac{3x}{y} +\frac{1}{xy} = \frac{3x}{y} +\frac{(x + y)^2}{xy} = \frac{3x}{y} +\frac{x^2 + 2xy + y^2}{xy} = \frac{4x}{y} +\frac{y}{x} +2\quad 2\sqrt{\frac{4x}{y}\times\frac{y}{x}} +2 = 6$
> >
> > 当且仅当 $\frac{4x}{y} = \frac{y}{x}$ ，且 $x + y = 1$ ，即 $x = \frac{1}{3}$ ， $y = \frac{2}{3}$ 时等号成立，
> >
> > 所以 $\frac{3x}{y} +\frac{1}{xy}$ 的最小值为6.
