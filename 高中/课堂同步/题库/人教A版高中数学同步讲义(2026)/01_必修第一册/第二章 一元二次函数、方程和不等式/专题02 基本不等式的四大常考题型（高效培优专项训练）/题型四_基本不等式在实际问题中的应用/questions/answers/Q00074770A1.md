> [!faq]- 《专题02 基本不等式的四大常考题型（高效培优专项训练）》官方解析
>
> > [!success]- **【答案】** (1) $W(x)=\left\{\begin{aligned}-x^{2}+152x-400, & 0<x\leq80\\ -x-\frac{52900}{x+80}+5800, & 80<x\leq200\end{aligned}\right.$ (2)150 台，5420 万元
>
> > [!note]- **【解析】**
> > （1）当 $0 < x \leq 80$ 时， $W(x) = 150x - (x^2 - 2x) - 400 = -x^2 + 152x - 400$ ；
> >
> > 当 $80 < x \leq 200$ 时， $W(x) = 150x - \left(151x + \frac{52900}{x + 80} - 6200\right) - 400$
> >
> > $$
> > = - x - \frac {5 2 9 0 0}{x + 8 0} + 5 8 0 0
> > $$
> >
> > $$
> > W (x) = \left\{ \begin{array}{l} - x ^ {2} + 1 5 2 x - 4 0 0, 0 <   x \leq 8 0 \\ - x - \frac {5 2 9 0 0}{x + 8 0} + 5 8 0 0, 8 0 <   x \leq 2 0 0 \end{array} . \right.
> > $$
> >
> > (2) 当 $0 < x \leq 80$ 时， $W(x) = -x^2 + 152x - 400 = -(x - 76)^2 + 5376$
> >
> > 当 x = 76 时， $W(x)_{\max} = 5376$ 万元.
> >
> > 当 $80 < x \leq 200$ 时， $W(x) = -\left(x + 80 + \frac{52900}{x + 80}\right) + 5880$
> >
> > $$
> > \leq - 2 \sqrt {(x + 8 0) \cdot \frac {5 2 9 0 0}{x + 8 0}} + 5 8 8 0 = 5 4 2 0 \text {万元}.
> > $$
> >
> > 当且仅当 $x + 80 = \frac{52900}{x + 80}$ ，即 $x = 150$ 时，上式等号成立
> >
> > 又 $5420 > 5376$ ，则当该产品的年产量为 $150$ 台时，
> >
> > 该公司所获年利润最大，最大年利润是5420万元·
