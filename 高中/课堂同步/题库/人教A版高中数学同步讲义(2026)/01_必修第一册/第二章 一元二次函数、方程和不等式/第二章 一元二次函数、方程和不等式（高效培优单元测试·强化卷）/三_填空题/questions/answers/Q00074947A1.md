> [!faq]- 《第二章 一元二次函数、方程和不等式（高效培优单元测试·强化卷）》官方解析
>
> > [!success]- **【答案】** 34
>
> > [!note]- **【解析】**
> > 法 $^{1}$ ：由 $a + b = \frac{ab}{4} - 1$ ， $a = \frac{4(b + 1)}{b - 4}$ ，所以 b > 4。
> >
> > 又因为 $a > b$ ，即 $\frac{4(b + 1)}{b - 4} > b$ ， $b^2 - 8b < 4, (b - 4)^2 < 20$ ，从而 $4 < b \leq 8, a, b \in \mathbf{N}^*$
> >
> > 所以 $a = 24, b = 5; a = 14, b = 6; a = 9, b = 8$ ，从而该长方形的周长最小值为 $2a + 2b = 34$
> >
> > 法2： $a + b = \frac{ab}{4} -1$ 得， $ab - 4a - 4b - 4 = 0,(a - 4)(b - 4) = 20$ ，因为 $a,b\in \mathbf{N}^*,a > b$ ，所以
> >
> > $a - 4 = 5, b - 4 = 4; a - 4 = 10, b - 4 = 2; a - 4 = 20, b - 4 = 1$ ，后面方法同上.
> >
> > 法3： $a + b = \frac{ab}{4} -1,a + b = \frac{4(b - 4) + 20}{b - 4} +b(b > 4),a + b = 8 + \frac{20}{b - 4} +b - 4\quad 8 + 4\sqrt{5}$
> >
> > 当且仅当 $b - 4 = 4$ 取得“=”号，此时 $b = 8, a = 9$ ，故该长方形周长 $2a + 2b$ 的最小值为34.
> >
> > 故答案为：34.
