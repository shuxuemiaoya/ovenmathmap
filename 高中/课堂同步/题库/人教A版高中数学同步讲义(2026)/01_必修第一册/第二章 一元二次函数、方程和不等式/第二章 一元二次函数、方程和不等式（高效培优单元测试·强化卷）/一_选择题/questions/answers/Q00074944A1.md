> [!faq]- 《第二章 一元二次函数、方程和不等式（高效培优单元测试·强化卷）》官方解析
>
> > [!success]- **【答案】** BCD
>
> > [!note]- **【解析】**
> > A：由题意得 $1=a+b$ $2\sqrt{ab}$ ，则 $ab\leq\frac{1}{4}$ ，当且仅当 $a=b=\frac{1}{2}$ 时取等号，故A项错误；
> >
> > B：由 $\left(\sqrt{a}+\sqrt{b}\right)^{2}=a+b+2\sqrt{ab}=1+2\sqrt{ab}\leq2$ ，则 $\sqrt{a}+\sqrt{b}\leq\sqrt{2}$ ，当且仅当 $a=b=\frac{1}{2}$ 时取等号，故 B 项正
> >
> > 确；
> >
> > C：由 $\left(\frac{1}{a} +\frac{2}{b}\right)(a + b) = 1 + 2 + \frac{b}{a} +\frac{2a}{b}$ $3 + 2\sqrt{\frac{b}{a}\times\frac{2a}{b}} = 3 + 2\sqrt{2}$ ，当且仅当 $\frac{b}{a} = \frac{2a}{b}$ ，即 $b = \sqrt{2} a = 2 - \sqrt{2}$ 时取等
> >
> > 号，故 $^{C}$ 项正确；
> >
> > D：由 $a + b = 1$ ，则 $\frac{a^2}{a + 2} +\frac{b^2}{b + 1} = \frac{a^2}{a + 2} +\frac{(1 - a)^2}{2 - a} = \frac{a^2}{a + 2} +\frac{a^2 + 1 - 2a}{2 - a} = a - 2 + \frac{4}{a + 2} -a + \frac{1}{2 - a} = \frac{4}{a + 2} +\frac{1}{2 - a} -2$
> >
> > 则
> >
> > $$
> > \frac {4}{a + 2} + \frac {1}{2 - a} = \frac {1}{4} \left(\frac {4}{a + 2} + \frac {1}{2 - a}\right) [ (a + 2) + (2 - a) ] = \frac {1}{4} \left[ 4 + 1 + \frac {4 (2 - a)}{a + 2} + \frac {(a + 2)}{2 - a} \right] \quad \frac {1}{4} \left[ 5 + 2 \sqrt {\frac {4 (2 - a)}{a + 2} \times \frac {(a + 2)}{2 - a}} \right] = \frac {9}{4}
> > $$
> >
> > 当且仅当 $\frac{4(2-a)}{a+2}=\frac{(a+2)}{2-a}$ 时，即 $a=\frac{2}{3}, b=\frac{1}{3}$ 时取等号，此时 $\frac{4}{a+2}+\frac{1}{2-a}-2$ $\frac{9}{4}-2=\frac{1}{4}$ ，故 D 项正确.
> >
> > 故选 **BCD**.
