> [!faq]- 《第二章 一元二次函数、方程和不等式（高效培优单元测试·强化卷）》官方解析
>
> > [!success]- **【答案】** A．已知 $a, b \in \mathbb{R}$ ，则“ $a - 3b = 0$ ”是“ $\frac{a}{b} = 3$ ”的必要不充分条件 B．若 $x \in \mathbb{R}$ ，则 $\sqrt{x^2 + 2} + \frac{1}{\sqrt{x^2 + 2}}$ 的最小值为 $2$ C．若正实数 $x, y$ ，满足 $x + y + xy = 3$ ，则 $x + 2y$ 的最小值为 $4\sqrt{2} - 3$ D．若 $x > \frac{1}{2}, y > \frac{1}{3}$ ，且 $\frac{3}{2x-1} + \frac{1}{3y-1} = 20$ ，则 $\frac{1}{x} + \frac{2}{y}$ 的最大值为 7
>
> > [!note]- **【解析】**
> > 对于 A 选项， $\frac{a}{b}=3$ 中， $b\neq0$ ， $a-3b=0$ 中 $b\in R$ ，所以 $\frac{a}{b}=3$ 可以推出 a-3b=0
> >
> > 但 $a - 3b = 0$ 不能推出 $\frac{a}{b} = 3$ ，所以“ $a - 3b = 0$ ”是“ $\frac{a}{b} = 3$ ”的必要不充分条件，故A正确；
> >
> > 对于 $^{B}$ 选项， $\sqrt{x^{2}+2}+\frac{1}{\sqrt{x^{2}+2}}$ 、当且仅当 $\sqrt{x^{2}+2}=\frac{1}{\sqrt{x^{2}+2}}$ 时取“=”，但此时x无解，故 $^{B}$ 错误；
> >
> > 对于 $C$ 选项，因为 $x + y + xy = 3$ ，所以 $(x + 1)(y + 1) = 4$
> >
> > 则 $x + 2y = (x + 1) + 2(y + 1) - 3 \quad 2\sqrt{2(x + 1)(y + 1)} - 3 = 4\sqrt{2} - 3$
> >
> > 当且仅当 $x + 1 = 2(y + 1)$ 时，即 $x = 2\sqrt{2} - 1, y = \sqrt{2} - 1$ 时，取“=”，故C正确；
> >
> > 对于 D 选项，设 $\frac{3}{2x-1}=s>0,\quad\frac{1}{3y-1}=t>0$ ，则 $\frac{1}{x}=\frac{2s}{3+s},\frac{1}{y}=\frac{3t}{t+1}$ ，且 $s+t=20$ ，
> >
> > 则 $\frac{1}{x} +\frac{2}{y} = \frac{2s}{3 + s} +\frac{6t}{t + 1} = 8 - 6\left(\frac{1}{3 + s} +\frac{1}{t + 1}\right)$
> >
> > 其中 $\frac{1}{3 + s} +\frac{1}{t + 1} = \frac{1}{24}\left(\frac{1}{3 + s} +\frac{1}{t + 1}\right)\left[\left(3 + s\right) + \left(t + 1\right)\right] = \frac{1}{12} +\frac{1}{24}\left(\frac{t + 1}{3 + s} +\frac{3 + s}{t + 1}\right)\quad \frac{1}{12} +\frac{2}{24}\sqrt{\frac{t + 1}{3 + s}\times\frac{3 + s}{t + 1}} = \frac{1}{6}$
> >
> > 当且仅当 s=9, t=11 时，等号成立，故 $\frac{1}{x}+\frac{2}{y}\leq8-6\times\frac{1}{6}=7$ ，故 D 正确.
> >
> > 故选 **ACD**.
