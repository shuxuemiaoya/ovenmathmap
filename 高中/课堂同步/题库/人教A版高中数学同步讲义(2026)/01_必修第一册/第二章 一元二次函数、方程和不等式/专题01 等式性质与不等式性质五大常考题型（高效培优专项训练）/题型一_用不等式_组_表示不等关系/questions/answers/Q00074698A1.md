> [!faq]- 《专题01 等式性质与不等式性质五大常考题型（高效培优专项训练）》官方解析
>
> > [!success]- **【答案】** $^{(1)}\left\{\begin{aligned}&0<x\leq20\\&x\left(20-\frac{x}{2}\right)\quad150\end{aligned}\right.$ (2) $12 \leq x \leq 14$
>
> > [!note]- **【分析】**
> > （ $^{1}$ ）直接根据题意列出不等式组即可求解；
> >
> > (2) 根据题意列出不等式组，解不等式组即可求解·
>
> > [!note]- **【解析】**
> > （1）由题可得 $0 < x \leq 20$
> >
> > 则矩形仓库的另一条边长为 $\frac{40 - x}{2} = \left(20 - \frac{x}{2}\right)$
> >
> > 所以仓库的面积 $S = x\left(20 - \frac{x}{2}\right)$ 150
> >
> > 故该题中的不等关系可表示为 $\left\{\begin{aligned}0&<x\leq20\\ x\left(20-\frac{x}{2}\right)&150\end{aligned}\right.$
> >
> > (2) 因为矩形的长、宽都不能超过 $14 \mathrm{~m}$
> >
> > 所以 $0 < x \leq 14, 0 < 20 - \frac{x}{2} \leq 14$ ，解得 $12 \leq x \leq 14$ .
