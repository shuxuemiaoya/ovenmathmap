> [!faq]- 《专题01 等式性质与不等式性质五大常考题型（高效培优专项训练）》官方解析
>
> > [!success]- **【答案】** 证明见解析
>
> > [!note]- **【分析】**
> > 直接将每个分式缩小，即可证明 $S > 1$ ；通过 $\frac{a}{a + b + d} < 1$ 可得 $\frac{a}{a + b + d} < \frac{a + c}{a + b + c + d}$ ，且类似可以得到其它三个不等式，然后相加即可证明 $S < 2$ 。
>
> > [!note]- **【解析】**
> > 因为 $a, b, c, d > 0$ ，故 $a + b + d < a + b + c + d$ ， $b + c + a < a + b + c + d$ ， $c + d + b < a + b + c + d$ ， $d + a + c < a + b + c + d$ .
> >
> > 故有
> >
> > $$
> > S = \frac {a}{a + b + d} + \frac {b}{b + c + a} + \frac {c}{c + d + b} + \frac {d}{d + a + c}
> > $$
> >
> > $$
> > > \frac {a}{a + b + c + d} + \frac {b}{a + b + c + d} + \frac {c}{a + b + c + d} + \frac {d}{a + b + c + d}
> > $$
> >
> > $$
> > = \frac {a + b + c + d}{a + b + c + d} = 1
> > $$
> >
> > 由于 $\frac{a + c}{a + b + c + d} -\frac{a}{a + b + d}$
> >
> > $$
> > = \frac {(a + c) (a + b + d) - a (a + b + c + d)}{(a + b + c + d) (a + b + d)}
> > $$
> >
> > $$
> > = \frac {a (a + b + d) + c (a + b + d) - a c - a (a + b + d)}{(a + b + c + d) (a + b + d)}
> > $$
> >
> > $$
> > = \frac {c (b + d)}{(a + b + c + d) (a + b + d)} > 0
> > $$
> >
> > 故 $\frac{a}{a + b + d} < \frac{a + c}{a + b + c + d}$ ，同理还有
> >
> > $$
> > \frac {b}{b + c + a} <   \frac {b + d}{a + b + c + d}
> > $$
> >
> > $$
> > \frac {c}{c + d + b} <   \frac {c + a}{a + b + c + d}
> > $$
> >
> > $$
> > \frac {d}{d + a + c} <   \frac {b + d}{a + b + c + d},
> > $$
> >
> > 所以
> >
> > $$
> > S <   \frac {a + c}{a + b + c + d} + \frac {b + d}{a + b + c + d} + \frac {c + a}{a + b + c + d} + \frac {b + d}{a + b + c + d} = \frac {a + c + b + d + c + a + b + d}{a + b + c + d} = \frac {2 a + 2 b + 2 c + 2 d}{a + b + c + d} = 2.
> > $$
> >
> > 这就证明了 $1 < S < 2$ .
