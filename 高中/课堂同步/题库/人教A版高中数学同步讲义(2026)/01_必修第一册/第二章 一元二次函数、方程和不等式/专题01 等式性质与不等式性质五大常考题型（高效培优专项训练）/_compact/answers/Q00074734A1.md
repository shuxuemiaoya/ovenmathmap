> [!faq]- 《专题01 等式性质与不等式性质五大常考题型（高效培优专项训练）》官方解析
>
> > [!success]- **【答案】** $-35 < c < -21$
>
> > [!note]- **【分析】**
> > 根据不等式的性质求解即可·
>
> > [!note]- **【解析】**
> > 因为 -3 < b < 2，所以 $0 \leq b^{2} < 9$ ，因为 6 < a < 7，所以 -35 < -5a < -30
> >
> > 故 $0 - 35 < b^{2} - 5a < 9 - 30$ ，即 $c$ 的取值范围是 $-35 < c < -21$
> >
> > 故答案为： $-35 < c < -21$
