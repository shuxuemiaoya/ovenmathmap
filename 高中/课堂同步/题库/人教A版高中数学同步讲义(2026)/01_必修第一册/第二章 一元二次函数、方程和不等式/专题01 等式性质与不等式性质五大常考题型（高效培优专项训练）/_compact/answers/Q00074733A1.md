> [!faq]- 《专题01 等式性质与不等式性质五大常考题型（高效培优专项训练）》官方解析
>
> > [!success]- **【答案】** (1) $-4 < x - y < 2$ (2) $1 < 3x + 2y < 18$
>
> > [!note]- **【分析】**
> > （ $^{1}$ ）由不等式的性质求解即可；
> >
> > (2) 由不等式的性质求解即可；
>
> > [!note]- **【解析】**
> > （1）因为-1<x<4，2<y<3，
> >
> > 所以 $-3 < -y < -2$ ，所以 $-4 < x - y < 2$
> >
> > (2) 由 -1 < x < 4，2 < y < 3，得 -3 < 3x < 12，4 < 2y < 6，
> >
> > 所以 $1 < 3x + 2y < 18$
