> [!faq]- 《专题01 等式性质与不等式性质五大常考题型（高效培优专项训练）》官方解析
>
> > [!success]- **【答案】** C
>
> > [!note]- **【分析】**
> > 利用赋值法可判断 ABD；利用不等式性质可判断 C.
>
> > [!note]- **【解析】**
> > 对于 A，若 x=1, y=-2, x>y, $x^{2}<y^{2}$ ，故 A 错误；
> >
> > 对于 B，若 x = -1, y = 2, $x < y, x^{2} < y^{2}$ ，故 B 错误；
> >
> > 对于 C，若 $\left|x\right| > \left|y\right|$ ，则 $x^{2} > y^{2}$ 成立，若 $x^{2} > y^{2}$ ，则 $\left|x\right| > \left|y\right|$ 成立，故 C 正确；
> >
> > 对于 D，当 x = -2 ，y = 1 时， $x^{2} > y^{2}, x < 0 < y$ ，故 D 错误。
> >
> > 故选 **C**.
