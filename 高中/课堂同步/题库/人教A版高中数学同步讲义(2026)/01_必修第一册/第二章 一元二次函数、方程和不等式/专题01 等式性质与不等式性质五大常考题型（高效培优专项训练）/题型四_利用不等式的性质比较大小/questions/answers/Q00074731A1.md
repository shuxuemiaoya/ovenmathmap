> [!faq]- 《专题01 等式性质与不等式性质五大常考题型（高效培优专项训练）》官方解析
>
> > [!success]- **【答案】** A. $\frac{2}{3} < \frac{a^2}{b} < \frac{3}{4}$ B. $\frac{4}{3} < \frac{a^2}{b} < \frac{9}{4}$ C. $1 < \frac{a^2}{b} < 3$ D. $\frac{1}{2} < \frac{a^2}{b} < 1$
>
> > [!note]- **【分析】**
> > 由 $a, b$ 的取值范围可分别求得 $a^2, \frac{1}{b}$ 的范围，再利用不等式性质可得结论
>
> > [!note]- **【解析】**
> > 因为 $-3 < a < -2, 3 < b < 4$ ，所以 $4 < a^2 < 9, \frac{1}{4} < \frac{1}{b} < \frac{1}{3}$
> >
> > 由不等式性质可得 $4 \times \frac{1}{4} < \frac{a^{2}}{b} < 9 \times \frac{1}{3}$ ，
> >
> > 即 $1 < \frac{a^2}{b} < 3$
> >
> > 故选 **C**
