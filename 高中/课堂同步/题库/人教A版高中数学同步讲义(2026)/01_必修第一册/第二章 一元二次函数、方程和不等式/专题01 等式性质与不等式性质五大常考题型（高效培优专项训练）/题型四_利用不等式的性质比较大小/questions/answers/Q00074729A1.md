> [!faq]- 《专题01 等式性质与不等式性质五大常考题型（高效培优专项训练）》官方解析
>
> > [!success]- **【答案】** A．“同位角相等”是“两条直线平行”的充要条件 B．“a > b 且 c > 0”是“ac > bc”的必要不充分条件 C．“ $b^{2} = 4ac$ ”是“方程 $ax^{2} + bx + c = 0 (a \neq 0)$ 有一个实数根”的充要条件 D．“ $A \cap B = \varnothing$ ”是“集合A或B为空集”的充要条件
>
> > [!note]- **【分析】**
> > 根据同位角相等的判定定理及两直线平行的性质即可判断 $^{A}$ ；根据ac>bc不一定推出a>b且c>0成立即可判断 $^{B}$ ；根据一元二次方程有一个实数根，即 $\Delta=0$ 即可判断 $^{C}$ ；根据 $A\cap B=\varnothing$ 不一定推出集合A或B为空集，可以通过举反例来说明即可判断。
>
> > [!note]- **【解析】**
> > 由两直线平行的判定及性质定理得，“同位角相等”是“两条直线平行”的充要条件， $^{A}$ 正确；
> >
> > 充分性：当 a > b 且 c > 0 时，必有 ac > bc ，充分性成立；
> >
> > 必要性：当 $ac > bc$ 时，有 $c(a - b) > 0$ ，即 $a > b$ 且 $c > 0$ 或 $a < b$ 且 $c < 0$ ，故不一定有 $a > b$ 且 $c > 0$ ，必要性不成立，
> >
> > 故“a > b 且 c > 0”是“ac > bc”的充分不必要条件，B 错误；
> >
> > 充分性：当 $b^{2}=4ac$ 时，方程 $ax^{2}+bx+c=0(a\neq0)$ 的 $\Delta=0$ ，有一个实数根，充分性成立；
> >
> > 必要性：当方程 $ax^2 + bx + c = 0 (a \neq 0)$ 有一个实数根时， $b^2 - 4ac = 0$ ，即 $b^2 = 4ac$ ，必要性成立，
> >
> > 所以“ $b^{2}=4ac$ ”是“方程 $ax^{2}+bx+c=0(a\neq0)$ 有一个实数根”的充要条件，C正确；
> >
> > 充分性：当 $A \cap B = \emptyset$ 时，取 $A = \{1, 2\}, B = \{3\}, A, B$ 均不为空集，充分性不成立；
> >
> > 必要性：当 A 或 B 为空集时，一定有 $A \cap B = \varnothing$ ，必要性成立，故“ $A \cap B = \varnothing$ ”是“集合A或B为空集”的必要不充分条件，D错误，
> >
> > 故选 **AC**.
