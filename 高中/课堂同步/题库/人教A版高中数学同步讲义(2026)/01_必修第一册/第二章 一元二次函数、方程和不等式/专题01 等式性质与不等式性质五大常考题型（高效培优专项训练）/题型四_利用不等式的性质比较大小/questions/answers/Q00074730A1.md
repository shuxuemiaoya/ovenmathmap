> [!faq]- 《专题01 等式性质与不等式性质五大常考题型（高效培优专项训练）》官方解析
>
> > [!success]- **【答案】** B
>
> > [!note]- **【分析】**
> > 由 $x + y + z = 0$ ，且 x > y > z，可得 x > 0, z < 0，y 正负不确定·取特值可得 AD 错误；根据不等式的基本性质可判定 BC 项·
>
> > [!note]- **【解析】**
> > 因为 x > y > z ， $x + y + z = 0$
> >
> > 则 $3x > x + y + z = 0 > 3z$ ，所以 $x > 0$ ， $z < 0$
> >
> > AD 选项，令 $x = 2, y = 0, z = -2$ ，满足条件 $x > y > z$ ， $x + y + z = 0$
> >
> > 但 $xy = yz = 0$ ，则 $x|y| = z|y| = 0$ ，故AD错误；
> >
> > B 选项，由 y > z, x > 0，则 xy > xz，故 B 正确；
> >
> > C 选项，由 $x > y, z < 0$ ，则 $xz < yz$ ，故 C 错误.
> >
> > 故选：B.

> > 37. 如果 $a < b < 0$ ，那么下列不等式中成立的是（ ）A. $\frac{a}{b} < 1$ ; B. $a^2 > ab$ ; C. $\frac{1}{b^2} < \frac{1}{a^2}$ ; D. $\frac{1}{a} < \frac{1}{b}$ .
> >
> > 【答案】B
> >
> > 【分析】利用不等式的性质比较大小逐一判断即可·
> >
> > 【详解】对于 $^{A}$ ：由a<b<0得 $\frac{a}{b}>\frac{b}{b}=1$ ，错误；
> >
> > 对于 B：由 a < b < 0，则有 $a \cdot a > a \cdot b$ ，即 $a^{2} > ab$ ，正确；
> >
> > 对于 $\mathbb{C}$ ：由 $a < b < 0$ 得 $-a > -b > 0$ ，则根据不等式的性质有 $(-a)^2 > (-b)^2 > 0$ ，即 $a^2 > b^2$
> >
> > 由 $a^2 > b^2$ 可得 $\frac{1}{a^2} < \frac{1}{b^2}$ ，错误；
> >
> > 对于 $^{D}$ ：由 a < b < 0 得 ab > 0 ，则 $\frac{a}{ab} < \frac{b}{ab}$ ，即 $\frac{1}{a} > \frac{1}{b}$ ，错误。
> > 故选： $^{B}$

> > 38. 给出下列命题，其中正确的命题是（）
> >
> > 【答案】
> > A．若 $ac^{4} > bc^{4}$ ，则 a > b
> > B．若 $a > |b|$ ，则 $a^{2} > b^{2}$ C．若 a > b，则 $a^{3} > b^{3}$ D．若 $|a| > b$ ，则 $a^{2} > b^{2}$
> >
> > 【答案】ABC
> >
> > 【分析】由不等式的性质直接判断 $^{A}$ ，由作差法判断 $^{BC}$ ，举反例判断 $^{D}$ .
> >
> > 【详解】对于 A，若 $ac^{4} > bc^{4}$ ，则 $c \neq 0$ ，否则 $ac^{4} = bc^{4} = 0$ ，矛盾，所以 $c^{4} > 0$ ，所以 a > b，故 A 正确；对于 B，若 $a > |b| = 0$ ，则 $a^{2} - b^{2} = (a - |b|)(a + |b|) > 0$ ，即 $a^{2} > b^{2}$ ，故 B 正确；对于 C，若 a > b，则 $a^{3} - b^{3} = (a - b)(a^{2} + ab + b^{2}) = (a - b)\left[\left(a + \frac{1}{2}b\right)^{2} + \frac{3}{4}b^{2}\right]$ ，因为 $\left(a + \frac{1}{2}b\right)^{2} + \frac{3}{4}b^{2} = 0$ 当且仅当 a = b = 0，所以 $\left(a + \frac{1}{2}b\right)^{2} + \frac{3}{4}b^{2} = 0$ 显然不可能（因为 a > b），所以 $\left(a + \frac{1}{2}b\right)^{2} + \frac{3}{4}b^{2} > 0$ ，所以 $a^{3} - b^{3} = (a - b)\left[\left(a + \frac{1}{2}b\right)^{2} + \frac{3}{4}b^{2}\right] > 0$ ，即 $a^{3} > b^{3}$ ，故 C 正确；对于 D，若 $|a| = 0 > b = -1$ ，则 $a^{2} = 0 < 1 = b^{2}$ ，故 D 错误。
> >
> > 故选 **ABC**.
