> [!faq]- 《专题2.3 二次函数与一元二次方程、不等式（高效培优讲义）》官方解析
>
> > [!success]- **【答案】** (1)①3；②p=0. (2) $a = -1$ 时， $k = -\frac{5}{2}$ 或 2；当 $a = 1$ 时， $k = 12$ 。
>
> > [!note]- **【解析】**
> > （1）①若 $a = 2$ ，则 $y = x^{2} - 4x + 3 = (x - 2)^{2} - 1$
> >
> > 当 $1 \leq x \leq 2$ 时， $y$ 随着 $x$ 的增大而减小；当 $2 < x \leq 3$ 时， $y$ 随着 $x$ 的增大而增大。
> >
> > 当 $x = 1$ 时， $y = 0$ ；当 $x = 4$ 时， $y = (4 - 2)^2 - 1 = 3$ ，故 $M[1,4] = 3$ ；
> > - **②**：若 $2 \leq p < \frac{5}{2}$ ，且当 $p \leq x \leq \frac{5}{2}$ 时， $y$ 随着 $x$ 的增大而减大，
> >
> > 此时 $M\left[p,\frac{5}{2}\right]=\left(\frac{5}{2}-2\right)^{2}-1=-\frac{3}{4}$ ，不合乎题意；
> >
> > 若 $p < 2$ ，且 $p \leq x \leq 2$ 时， $y$ 随着 $x$ 的增大而减小；当 $2 \leq x \leq \frac{5}{2}$ 时， $y$ 随着 $x$ 的增大而增大。
> >
> > 若 $\frac{3}{2} \leq p < 2$ ，则 $M\left[p, \frac{5}{2}\right] = \left(\frac{5}{2} - 2\right)^2 - 1 = -\frac{3}{4}$ ，不合乎题意，
> >
> > 若 $p < \frac{3}{2}$ ，则 $M\left[p, \frac{5}{2}\right] = p^2 - 4p + 3 = 3$ ，因为 $p < \frac{3}{2}$ ，解得 $p = 0$ ，合乎题意；
> >
> > 综上所述，p = 0.
> >
> > (2) 因为函数 $y = (a - 1)x^{2} - 4x + a^{2} - 1$ （a 为常数），则 $a^{2} - 1 = 0$ ，解得 $a = \pm 1$ .
> >
> > 若 $a = 1$ ，则 $y = -4x$ ，当 $-3\leq x\leq k$ 时， $-4k\leq -4x\leq 12$ ，则 $M[-3,k] = 12 = k$ ，合乎题意；
> >
> > 若 $a = -1$ ，则 $y = -2x^{2} - 4x = -2(x + 1)^{2} + 2$
> >
> > 若 $-3 < k \leq -1$ ，且当 $-3 \leq x \leq k$ 时， $y$ 随着 $x$ 的增大而增大，
> >
> > 此时 $M\left[-3,k\right]=-2k^{2}-4k=k$ ，即 $2k^{2}+5k=0$ ，因为 $-3<k\leq-1$ ，解得 $k=-\frac{5}{2}$ ；
> >
> > 若 $k > -1$ ，且当 $-3 \leq x \leq -1$ 时， $y$ 随着 $x$ 的增大而增大，
> >
> > 当 $-1 < x \leq k$ 时， $y$ 随着 $x$ 的增大而减小，此时 $M[-3, k] = k = 2$ ，合乎题意；
> >
> > 综上所述，当 $a = -1$ 时， $k = -\frac{5}{2}$ 或2；当 $a = 1$ 时， $k = 12$ 。

> > 18. 美国国家海洋和大气管理局 $(\mathrm{NOAA})$ 最近发布的一则预测引发全球关注：预计在2024年6月，拉尼娜现

> >
> > 温套装，其每月的成本(单位：万元)由两部分构成：
> > - **①**：固定成本(与生产产品的数量无关): 20 万元;
> > - **②**：生产所需材料成本： $\left(10x+\frac{x^{2}}{20}\right)$ 万元， $x^{(单位：万套)}$ 为每月生产产品的套数。
> >
> > (1)该企业每月产量 $x$ 为何值时，平均每万套的成本最低？每万套的最低成本为多少？
> >
> > (2)若每月生产 $x$ 万套产品，每万套售价为： $\left(30 + \frac{x}{10}\right)$ 万元，假设每套产品都能够售出，则该企业应如何制定
> >
> > 计划，才能确保该套装每月的利润不低于625万元。
> >
> > 【答案】(1) $x = 20$ 万套时，每万套的最低成本为 $^{12}$ 万元；
> >
> > (2)该企业至少要生产30万套，才能确保该套装每月的利润不低于625万元。
> >
> > 【详解】（1）由题设，平均每万套的成本 $y = 10 + \frac{x}{20} + \frac{20}{x} \quad 10 + 2\sqrt{\frac{x}{20} \cdot \frac{20}{x}} = 12$
> >
> > 当且仅当 $x = 20$ 万套时取等号，平均每万套的成本最低为 $^{12}$ 万元/万套；
> >
> > (2) 由题设，该套装每月的利润为 $f(x) = x \left(30 + \frac{x}{10}\right) - \left(10x + \frac{x^2}{20}\right) - 20 = 20x + \frac{x^2}{20} - 20$
> >
> > 所以 $f(x)=\frac{x^{2}}{20}+20x-20$ 625，可得 $x^{2}+400x-12900=(x-30)(x+430)$ 0
> >
> > 所以 x 30，即该企业至少要生产 30 万套，才能确保该套装每月的利润不低于 625 万元。
