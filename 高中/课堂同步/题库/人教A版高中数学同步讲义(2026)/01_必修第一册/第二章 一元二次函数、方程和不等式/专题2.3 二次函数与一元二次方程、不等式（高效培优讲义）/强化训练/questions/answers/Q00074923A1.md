> [!faq]- 《专题2.3 二次函数与一元二次方程、不等式（高效培优讲义）》官方解析
>
> > [!success]- **【答案】** C
>
> > [!note]- **【解析】**
> > 由题意可知： $\frac{3}{m}$ ， $m$ 是方程 $ax^2 -bx + 1 = 0$ 的两根，且 $a > 0$
> >
> > 则 $\left\{ \begin{array}{l} \frac{3}{m} + m = \frac{b}{a} \\ \frac{3}{m} \cdot m = \frac{1}{a} \end{array} \right.$ ，可得 $a = \frac{1}{3}$ ， $b = \frac{m}{3} + \frac{1}{m}$
> >
> > 则 $b + \frac{2}{m} = \frac{m}{3} +\frac{3}{m}$ 2，当且仅当 $m = 3$ 时取等号，
> >
> > 所以 $b+\frac{2}{m}$ 的最小值为 2.
> >
> > 故选：C.

> > 4. 实数 $x, y, z$ 满足 $x + y + z = 5, xy + yz + zx = 3$ ，则 $z$ 的最大值是 \_\_\_\_.
> >
> > 【答案】 $\frac{13}{3}$
> >
> > 【详解】因为 $x + y + z = 5$ ，所以 $\left(x + y + z\right)^2 = 25$
> >
> > 即 $x^{2} + y^{2} + z^{2} + 2xy + 2yz + 2xz = 25$
> >
> > 又 $xy + yz + zx = 3$ ，所以 $x^{2} + y^{2} + z^{2} = 19 \Rightarrow x^{2} + y^{2} = 19 - z^{2}$
> >
> > 又 $x + y = 5 - z$
> >
> > 因为 $x^{2} + y^{2}$ $2xy\Rightarrow 2(x^{2} + y^{2})$ $x^{2} + 2xy + y^{2} = (x + y)^{2}.$
> >
> > 所以 $2(19 - z^2)(5 - z)^2$
> >
> > 整理得： $3z^{2} - 10z - 13\leq 0\Rightarrow (z + 1)(3z - 13)\leq 0\Rightarrow -1\leq z\leq \frac{13}{3}$
> >
> > 所以 z 的最大值为： $\frac{13}{3}$
> >
> > 故答案为： $\frac{13}{3}$
