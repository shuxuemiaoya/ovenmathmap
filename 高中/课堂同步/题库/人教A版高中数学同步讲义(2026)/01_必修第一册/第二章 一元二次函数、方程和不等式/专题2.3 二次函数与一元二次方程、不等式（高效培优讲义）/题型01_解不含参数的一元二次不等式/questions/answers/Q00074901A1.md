> [!faq]- 《专题2.3 二次函数与一元二次方程、不等式（高效培优讲义）》官方解析
>
> > [!success]- **【答案】** (1) $\left(\check{\mathfrak{Q}}_{\mathrm{R}}A\right)\cap B=\left\{x\mid1<x\leq\frac{5}{4}\text{或}\frac{7}{2}\leq x<4\right\}$ (2) $\left[1,\frac{3}{2}\right]$ .
>
> > [!note]- **【解析】**
> > （1）因为 $a = \frac{5}{4}$ ，所以 $A = \left\{x\left|\frac{5}{4} < x < \frac{7}{2}\right.\right\}$ 故 $\tilde{\mathbf{Q}}_{\mathrm{R}}A = \left\{x\left|x\leq \frac{5}{4}\right.\right.$ 或 $x = \frac{7}{2}$
> >
> > 又因为 $B = \{x\mid x^2 -5x + 4 <   0\} = \{x\mid 1 <   x <   4\}$
> >
> > 所以 $\left(\tilde{\mathbf{Q}}_{\mathrm{R}}A\right)\cap B = \left\{x\mid 1 <   x\leq \frac{5}{4}\text{或}\frac{7}{2}\leq x <   4\right\} .$
> >
> > (2) 因为 p 是 q 的充分不必要条件，故 A 是 B 的真子集，
> >
> > 又 $B = \{x\mid x^2 -5x + 4 <   0\} = \{x\mid 1 <   x <   4\}$ 且 $A\neq \emptyset$
> >
> > 所以 $\left\{\begin{aligned}a&<2a+1\\ a&1\\ 2a+1&\leq4\end{aligned}\right.$ （等号不同时成立），解得 $1\leq a\leq\frac{3}{2}$
> >
> > 综上，实数 $a$ 的取值范围是 $\left[1, \frac{3}{2}\right]$ .
