> [!faq]- 《专题2.3 二次函数与一元二次方程、不等式（高效培优讲义）》官方解析
>
> > [!success]- **【答案】** (1) $A \cap B = \{x \mid -3 < x < -2\}$ ; $A \cup B = \{x \mid -4 < x \leq 1\}$ (2) $[0,2]$
>
> > [!note]- **【解析】**
> > （1）已知 $A=\{x\mid\frac{2x+2}{x+3}\leq1\}$ ，解不等式 $\frac{2x+2}{x+3}\leq1$
> >
> > 移项可得 $\frac{2x + 2}{x + 3} -1\leq 0$ ，通分得到 $\frac{2x + 2 - (x + 3)}{x + 3}\leq 0$ ，即 $\frac{x - 1}{x + 3}\leq 0$
> >
> > 此不等式等价于 $\left\{\begin{aligned}(x-1)(x+3) &\leq 0\\ x+3 &\neq 0\end{aligned}\right.$
> >
> > 解 $(x-1)(x+3)\leq0$ ，可得 $-3<x\leq1$ ，所以 $A=\{x\mid-3<x\leq1\}$ .
> >
> > 已知 $B = \{x\| x + a| <   1\}$ ，当 $a = 3$ 时， $B = \{x\| x + 3| <   1\}$
> >
> > 解不等式 $|x + 3| < 1$ ，可得 $-1 < x + 3 < 1$ ，即 $-4 < x < -2$ ，所以 $B = \{x \mid -4 < x < -2\}$ .
> >
> > 所以 $A \cap B = \{x \mid -3 < x < -2\}$ . $A \cup B = \{x \mid -4 < x \leq 1\}$ .
> >
> > (2) 已知 $B = \{x \parallel x + a \mid < 1\}$ ，解不等式 $|x + a| < 1$ ，可得 $-1 < x + a < 1$ ，即 $-a - 1 < x < -a + 1$ ，所以
> >
> > $$
> > B = \{x \mid - a - 1 <   x <   - a + 1 \}
> > $$
> >
> > 因为 p 是 q 成立的必要不充分条件，所以 $B \ddot{U} A$ .
> >
> > 则有 $\left\{\begin{aligned}-a-1&-3\\ -a+1&\leq1\end{aligned}\right.$ （不能同时取等号），解 -a -2 得 $0 \leq a \leq 2$
> >
> > 所以实数 $a$ 的取值范围是 $[0,2]$
