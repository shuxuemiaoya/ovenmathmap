> [!faq]- 《专题2.3 二次函数与一元二次方程、不等式（高效培优讲义）》官方解析
>
> > [!success]- **【答案】** (1) $[- \sqrt{2}, \sqrt{2}]$ (2)答案见解析
>
> > [!note]- **【解析】**
> > （1）由函数 $g(x) = \sqrt{x^2 + 2ax + 2}$ 的定义域为R，得 $x^2 + 2ax + 2 = 0$ 在R上恒成立，
> >
> > 则 $\Delta = (2a)^2 - 4 \times 2 \leq 0$ ，解得 $-\sqrt{2} \leq a \leq \sqrt{2}$
> >
> > 所以实数 k 的取值范围为 $\left[-\sqrt{2},\sqrt{2}\right]$ ;
> >
> > (2) 不等式 $(a+1)x^{2}+x>x^{2}+2ax+2$ 化为 $ax^{2}+(1-2a)x-2>0$
> >
> > 即 $(ax + 1)(x - 2) > 0$
> >
> > 当 a=0 时，不等式化为 x-2>0 ，解得 x>2 ；
> >
> > 当 $a > 0$ 时，不等式化为 $(x + \frac{1}{a})(x - 2) > 0$ ，解得 $x < -\frac{1}{a}$ 或 $x > 2$
> >
> > 当 $a < 0$ 时，不等式化为 $(x + \frac{1}{a})(x - 2) < 0$
> >
> > 若 $a = -\frac{1}{2}$ ，不等式 $(x - 2)^{2} < 0$ 无解，
> >
> > 若 $-\frac{1}{2} < a < 0$ ，则 $-\frac{1}{a} > 2$ ，解得 $2 < x < -\frac{1}{a}$ ，
> >
> > 若 $a < -\frac{1}{2}$ ，则 $-\frac{1}{a} < 2$ ，解得 $-\frac{1}{a} < x < 2$ ，
> >
> > 所以当 a = 0 时，原不等式的解集为 $\left\{x \mid x > 2\right\}$ ;
> >
> > 当 $a > 0$ 时，原不等式的解集为 $\left\{x\mid x < -\frac{1}{a}\right.$ 或 $x > 2\}$
> >
> > 当 $-\frac{1}{2}<a<0$ 时，原不等式的解集为 $\left\{x\mid2<x<-\frac{1}{a}\right\}$ ;
> >
> > 当 $a = -\frac{1}{2}$ 时，原不等式的解集为 $\varnothing$ ；
> >
> > 当 $a < -\frac{1}{2}$ 时，原不等式的解集为 $\left\{x \mid -\frac{1}{a} < x < 2\right\}$ .
