> [!faq]- 《专题2.2 基本不等式（高效培优讲义）》官方解析
>
> > [!success]- **【答案】** C
>
> > [!note]- **【解析】**
> > 由于 $a^2 + b^2 - 2ab = (a - b)^2 - 0$ ，可得 $a^2 + b^2 - 2ab$ ，当且仅当 $a = b$ 时，等号成立，可知选项A错误；若 $a = -1, b = -2$ 可得 $a + b = -3, -2\sqrt{|ab|} = -2\sqrt{2}$ ，则 $a + b < -2\sqrt{|ab|}$ ，可知选项B错误；
> >
> > 由于 $a^{2}+b^{2}+2ab=(a+b)^{2}\quad0$ ，可得 $a^{2}+b^{2}\quad-2ab$ ，可知选项 C 正确；
> >
> > 若 $a = 1, b = 2$ 可得 $a + b = 3, 2\sqrt{|ab|} = 2\sqrt{2}$ , 则 $a + b > 2\sqrt{|ab|}$ , 可知选项 D 错误；
> >
> > 故选：C.
> >
> > ## 方法技巧
> >
> > 利用基本不等式比较大小
> >
> > 在利用基本不等式比较大小时，应创设应用基本不等式的使用条件，合理地拆项、配凑或变形。在拆项、配凑或变形的过程中，首先要考虑基本不等式使用的条件，其次要明确基本不等式具有将“和式”转化为“积式”或者将“积式”转化为“和式”的放缩功能。
