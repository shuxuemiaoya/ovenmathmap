> [!faq]- 《专题2.2 基本不等式（高效培优讲义）》官方解析
>
> > [!success]- **【答案】** (1)12 (2)-3 (3) 25
>
> > [!note]- **【解析】**
> > （1）因为 $x > 0, y > 0$ ，且 $xy = 4$ ，所以 $9x + y = 2\sqrt{9x \cdot y} = 6\sqrt{xy} = 12$
> >
> > 当且仅当 $9x = y$ ，即 $x = \frac{2}{3}, y = 6$ 时取等号，
> >
> > 所以当 $x = \frac{2}{3}, y = 6$ 时， $9x + y$ 有最小值，最小值为12；
> >
> > (2) 因为 $x < 1$ ，则 $1 - x > 0$ ，所以 $1 - x + \frac{4}{1 - x} = 2\sqrt{(1 - x) \cdot \left(\frac{4}{1 - x}\right)} = 4$
> >
> > <!-- source-part:2 pages:51-52 -->
> >
> > 当且仅当 $1 - x = \frac{4}{1 - x}$ ，即 $x = -1$ 时取等号，
> >
> > 所以 $y = x + \frac{4}{x - 1} = x - 1 + \frac{4}{x - 1} + 1 = -\left[1 - x + \frac{4}{1 - x}\right] + 1 \leq -4 + 1 = -3$
> >
> > 所以当 $x = -1$ 时， $y = x + \frac{4}{x - 1}$ 有最大值，最大值为 $-3$ ；
> >
> > (3) 因为 $2x + y = xy$ ，所以 $\frac{2}{y} + \frac{1}{x} = 1$
> >
> > 因为 $x > 0, y > 0$ ，所以 $x + 8y = (x + 8y)\left(\frac{2}{y} + \frac{1}{x}\right) = 17 + \frac{2x}{y} + \frac{8y}{x} - 17 + 2\sqrt{\frac{2x}{y} \cdot \frac{8y}{x}} = 25$
> >
> > 当且仅当 $\frac{2x}{y} = \frac{8y}{x}$ ，即 x = 2y，即 $x = 5, y = \frac{5}{2}$ 时取等号，
> >
> > 故当 $x=5, y=\frac{5}{2}$ 时， $x+8y$ 有最小值，最小值为 25.
