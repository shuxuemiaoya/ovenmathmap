> [!faq]- 《专题2.2 基本不等式（高效培优讲义）》官方解析
>
> > [!success]- **【答案】** $^{(1)}$ 当左右两面墙的长度为4m时，甲工程队报价最低 (2) $0 < a < 12$
>
> > [!note]- **【解析】**
> > 解：（1）因为屋子的左右两侧墙的长度均为 $x\mathrm{m}(2 \leq x \leq 6)$ ，底面积为 $12\mathrm{m}^2$ ，所以屋子的前面墙的
> >
> > 长度为 $\frac{12}{x}\mathrm{m}(2\leq x\leq 6)$
> >
> > 设甲工程队报价为 $y$ 元，所以 $y = 3 \times \frac{12}{x} \times 400 + 2 \times 150 \times 3x + 7200 = 900\left(\frac{16}{x} + x\right) + 7200, 2 \leq x \leq 6$
> >
> > 因为 $900\left(\frac{16}{x}+x\right)+7200$ $900\times2\sqrt{\frac{16}{x}\cdot x}+7200=14400$ ，当且仅当 $\frac{16}{x}=x$ ，即 x=4 时，等号成立，
> >
> > 所以当左右两面墙的长度为 4m 时，甲工程队报价最低，为 14400 元。
> >
> > (2) 根据题意可知 $900\left(\frac{16}{x}+x\right)+7200>\frac{900a(1+x)}{x}$ 对任意的 $x\in[2,6]$ 恒成立，即 $\frac{(x+4)^{2}}{x}>\frac{a(1+x)}{x}$ 对任意的
> >
> > $x\in [2,6]$ 恒成立，所以 $a < \frac{(x + 4)^2}{1 + x}$ 对任意的 $x\in [2,6]$ 恒成立.
> >
> > 因为 $a > 0, \frac{(x+4)^{2}}{1+x} = \frac{(x+1)^{2} + 6(x+1) + 9}{1+x} = (x+1) + \frac{9}{x+1} + 6 \quad 2\sqrt{(x+1) \cdot \frac{9}{x+1}} + 6 = 12$ ，当且仅当 $x + 1 = \frac{9}{x+1}$ ，即
> >
> > x=2 0<a<12 时，等号成立，所以
> >
> > 故当 $0 < a < 12$ 时，无论左右两面墙的长度为多少米，乙工程队都能竞标成功。
