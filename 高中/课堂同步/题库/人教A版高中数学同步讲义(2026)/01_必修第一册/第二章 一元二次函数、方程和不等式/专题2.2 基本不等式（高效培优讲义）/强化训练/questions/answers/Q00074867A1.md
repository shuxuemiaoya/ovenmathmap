> [!faq]- 《专题2.2 基本不等式（高效培优讲义）》官方解析
>
> > [!success]- **【答案】** A. $\frac{a}{\sqrt{b}} + \frac{b}{\sqrt{a}} \sqrt{a} + \sqrt{b}$ B. 若 $\frac{1}{a} + \frac{1}{b} + \frac{1}{c} = 1$ ，则 $a + 4b + 9c \geq 38$ C. $a^3 + b^3 + c^3 = 3abc$ D. 若 $a + b + c = 2$ ，则 $ab + ac + bc \geq \frac{9}{2} abc$
>
> > [!note]- **【解析】**
> > $a, b, c \in (0, +\infty)$
> >
> > 对 A，因为 $\frac{a}{\sqrt{b}} + \sqrt{b}$ $2\sqrt{a}, \frac{b}{\sqrt{a}} + \sqrt{a}$ $2\sqrt{b}$ ，当且仅当 a = b 时等号成立，
> >
> > 所以 $\frac{a}{\sqrt{b}} +\sqrt{b} +\frac{b}{\sqrt{a}} +\sqrt{a}$ $2\sqrt{a} +2\sqrt{b}$
> >
> > 即 $\frac{a}{\sqrt{b}}+\frac{b}{\sqrt{a}}\quad\sqrt{a}+\sqrt{b}$ ，A 正确；
> >
> > 对 B， $a + 4b + 9c = (a + 4b + 9c)\left(\frac{1}{a} + \frac{1}{b} + \frac{1}{c}\right) = 14 + \frac{a}{b} + \frac{4b}{a} + \frac{a}{c} + \frac{9c}{a} + \frac{4b}{c} + \frac{9c}{b}$
> >
> > $14 + 2\sqrt{\frac{a}{b} \cdot \frac{4b}{a}} + 2\sqrt{\frac{a}{c} \cdot \frac{9c}{a}} + 2\sqrt{\frac{4b}{c} \cdot \frac{9c}{b}} = 36$ ，当且仅当 $a = 2b = 3c$ 时取等号，因此最小值是 $^{36}$ ，B 错；
> >
> > 对 $C$ ，由三元均值不等式知 $C$ 正确；
> >
> > 对 D， $\frac{1}{a}+\frac{1}{b}+\frac{1}{c}=\frac{1}{2}(a+b+c)(\frac{1}{a}+\frac{1}{b}+\frac{1}{c})=\frac{1}{2}(3+\frac{a}{b}+\frac{b}{a}+\frac{a}{c}+\frac{c}{a}+\frac{b}{c}+\frac{c}{b})\quad\frac{1}{2}(3+2+2+2)=\frac{9}{2}$ ，当且仅当
> > a=b=c 时取等号，
> >
> > 所以 $ab + bc + ca \quad \frac{9}{2}abc$ ，D 正确，
> >
> > 故选：ACD.
> >
