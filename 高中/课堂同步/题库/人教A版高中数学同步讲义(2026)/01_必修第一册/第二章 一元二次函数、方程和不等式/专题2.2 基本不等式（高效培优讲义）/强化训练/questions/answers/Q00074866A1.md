> [!faq]- 《专题2.2 基本不等式（高效培优讲义）》官方解析
>
> > [!success]- **【答案】** ACD
>
> > [!note]- **【解析】**
> > 对于 A，由 a > b > c， $3a + 2b + c = 0$ ，得 $3a + 3c < 3a + 2b + c = 0$ ，则 $a + c < 0$ ，A 正确；
> > 对于 B，由 a > b > c， $3a + 2b + c = 0$ ，得 $6a > 3a + 2b + c = 0$ ，则 a > 0，c < -a < 0，
> >
> > 若存在 $a$ ， $c$ 使得 $c^2 -36a^2 = 0$ ，则 $c = -6a$ ， $b = \frac{3}{2} a > a$ 与已知相矛盾，B错误；
> >
> > 对于 $C$ ，由 $a + c < 0$ ，得 $\frac{c}{a} < -1$ ， $\frac{a}{c} +\frac{c}{a} = -[(-\frac{a}{c}) + (-\frac{c}{a})] <   -2\sqrt{(-\frac{a}{c})(-\frac{c}{a})} = -2$ ， $C$ 正确；
> >
> > 对于 D， $a + c = -2(a + b) < 0$ ， $\frac{2a + b}{a + c} = \frac{a + b + a}{-2(a + b)} = -\frac{1}{2} + \frac{a}{-2(a + b)} < -\frac{1}{2}$ ，D 正确.
> >
> > 故选 **ACD**.
