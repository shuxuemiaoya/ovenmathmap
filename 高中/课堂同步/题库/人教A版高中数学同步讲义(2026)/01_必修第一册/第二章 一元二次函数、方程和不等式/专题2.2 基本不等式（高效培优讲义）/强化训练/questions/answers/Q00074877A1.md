> > [!note]- **【解析】**
> > （1）因为 $a^2 + b^2 - 2(a + b - 1) = (a - 1)^2 + (b - 1)^2 \quad 0$
> >
> > 所以 $a^{2}+b^{2}\quad2(a+b-1)$ ;
> >
> > (2) 因为 a > 0, b > 0, $a + b = 1$ ,
> >
> > 所以 $\frac{1}{a} +\frac{4}{b} = (a + b)\left(\frac{1}{a} +\frac{4}{b}\right) = 5 + \frac{b}{a} +\frac{4a}{b}$ （ $5 + 2\sqrt{\frac{b}{a}\cdot\frac{4a}{b}}$ ） $= 9$
> >
> > 当且仅当 $\frac{b + 1}{a} = \frac{4a}{b + 1}$ ，即 $a = \frac{1}{3}$ ， $b = \frac{2}{3}$ 时等号成立.

> > 16. 发展新能源汽车是我国从汽车大国迈向汽车强国的必由之路，是推动绿色发展的战略措施，某汽车工业
> >
> > 园区正在不断建设，计划在园区建造一个高为 $3$ 米，宽度为 $x \in [6,10]$ （单位：米），地面面积为 $81$ 平方米的
> >
> > 长方体形状的储物室，经过谈判，工程施工单位给出两种报价方案：
> >
> > 方案一：储物室的墙面报价为每平方米 $200$ 元，屋顶和地面报价共计 $7200$ 元，总计报价记为 $P(x)$ ；
> >
> > 方案二：其给出的整体报价为 $f(x) = 1200m\left(\frac{3}{x} +1\right)$ 元， $(m > 0)$
> >
> > (1)当宽度为 $8$ 米时，方案二的报价为 $29700$ 元，求 $m$ 的值；
> >
> > (2)求 $P(x)$ 的函数解析式，并求报价的最小值；
> >
> > (3)若对任意的 $x \in [6,10]$ 时，方案二都比方案一省钱，求 $m$ 的取值范围
> >
> > 【答案】(1)18
> >
> > $$
> > P (x) = 1 2 0 0 \left(x + \frac {8 1}{x}\right) + 7 2 0 0, x \in [ 6, 1 0 ] \tag {2}
> > $$
> >
> > (3) $(017)$
> >
> > 【详解】（1）宽度为8米时，方案二的报价为29700元，
> >
> > $$
> > \therefore f (8) = 1 2 0 0 m \left(\frac {3}{8} + 1\right) = 2 9 7 0 0 \Rightarrow m = 1 8
> > $$
> >
> > 所以 m 的值为 18.
> >
> > (2) 设底面长为 y， $S = xy = 81 \Rightarrow y = \frac{81}{x}$
> >
> > 所以墙面面积为 $2(x+y)\times3=6\left(x+\frac{81}{x}\right)$
> >
> > $$
> > P (x) = 1 2 0 0 \left(x + \frac {8 1}{x}\right) + 7 2 0 0, x \in [ 6, 1 0 ] \quad P (x) = 1 2 0 0 \left(x + \frac {8 1}{x}\right) + 7 2 0 0 \quad 2 8 8 0 0 \quad , \text {当} x = \frac {8 1}{x} = 9
> > $$
> >
> > 所以 $P(x)=1200\left(x+\frac{81}{x}\right)+7200,x\in[6,10]$ ，最小值为28800.
> >
> > (3) 对任意的 $x \in [6, 10]$ 时，方案二都比方案一省钱，
> >
> > 即 $x \in [6,10]$ 时， $1200m\left(\frac{3}{x} + 1\right) < 1200\left(x + \frac{81}{x}\right) + 7200$ 恒成立，
> >
> > 整理得 $m < \left[\frac{x^{2} + 6x + 81}{x + 3}\right]_{\min}$ ，
> >
> > 因为 $y=\frac{x^{2}+6x+27}{x+3}=x+3+\frac{72}{x+3}$ ， $x\in[6,10]$ ，
> >
> > 设 $t = x + 3$ ，则 $y = t + \frac{72}{t}$ ， $t \in [9,13]$
> >
> > 又由对勾函数性质可得 $y = t + \frac{72}{t}$ 在在[9,13]上单调递增，
> >
> > $$
> > m <   \left[ \frac {x ^ {2} + 6 x + 8 1}{x + 3} \right] _ {\min} = 9 + \frac {7 2}{9} = 1 7
> > $$
> >
> > 又 $m > 0$ ，所以 $m \in (0,17)$
> >
> > 所以方案二都比方案一省钱，m 的取值范围为 $(0,17)$ .
