> [!faq]- 《专题2.2 基本不等式（高效培优讲义）》官方解析
>
> > [!success]- **【答案】** B
>
> > [!note]- **【解析】**
> > 不等式 $x^{2} + 5y - m^{2}xy + 6mxy$ 恒成立，等价于 $-m^2 + 6m \leq \frac{x^2 + 5y}{xy} = \frac{x}{y} + \frac{5}{x}$
> >
> > 又 x > 0, y > 0, $x + 4y = 5$ ，故 $-m^{2} + 6m \leq \frac{x}{y} + \frac{5}{x} = \frac{x}{y} + \frac{x + 4y}{x} = \frac{x}{y} + \frac{4y}{x} + 1$ 恒成立，
> >
> > 所以 $-m^{2}+6m\leq\left(\frac{x}{y}+\frac{4y}{x}+1\right)_{\min}$
> >
> > 又 $\frac{x}{y} +\frac{4y}{x} +1\quad 2\sqrt{4} +1 = 5$ ，故 $-m^2 +6m\leq 5$
> >
> > 即 $-m^2 + 6m - 5 \leq 0$ ，解得 $m \leq 1$ 或 $m = 5$
> >
> > 故选 **B**
