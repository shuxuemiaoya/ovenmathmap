> [!faq]- 《专题2.2 基本不等式（高效培优讲义）》官方解析
>
> > [!success]- **【答案】** A. $a + b > 2$ B. $\frac{1}{a} + \frac{1}{b} + \frac{8}{a + b} = 4\sqrt{2}$ C. $\frac{b}{a} + \frac{16}{b} = 16$ D. $\frac{8a^2 + b^2}{a^2 + 1} = 4$
>
> > [!note]- **【解析】**
> > 由 $a + \frac{1}{a} = b + \frac{1}{b}\Rightarrow a - b + \frac{1}{a} -\frac{1}{b} = 0\Rightarrow a - b + \frac{b - a}{ab} = 0\Rightarrow (a - b)\cdot \left(1 - \frac{1}{ab}\right) = 0$
> >
> > 因为 a, b 为不相等的正实数，所以 ab = 1 ，
> >
> > 对于 $\mathsf{A}$ ， $a + b > 2\sqrt{ab} = 2$ ，故 $\mathsf{A}$ 正确；
> >
> > 对于 $\mathsf{B}$ ， $\frac{1}{a} +\frac{1}{b} +\frac{8}{a + b} = a + b + \frac{8}{a + b}$ $4\sqrt{2}$ ，当且仅当 $a + b = \frac{8}{a + b}$ ，即 $\left\{ \begin{array}{ll}a = \sqrt{2} +1\\ b = \sqrt{2} -1 \end{array} \right.$ 或 $\left\{ \begin{array}{ll}b = \sqrt{2} +1\\ a = \sqrt{2} -1 \end{array} \right.$ 时等号成立，
> >
> > 故 $^{B}$ 正确；
> >
> > 对于 C， $\frac{b}{a}+\frac{16}{b}=\frac{b^{2}}{ab}+\frac{16}{b}=b^{2}+\frac{8}{b}+\frac{8}{b}\quad3\sqrt[3]{b^{2}\cdot\frac{8}{b}\cdot\frac{8}{b}}=12$ ，当且仅当 $b^{2}=\frac{8}{b}$ ，即 b=2 时等号成立，故 C 错误；
> >
> > 对于 $^{D}$ ， $\frac{8a^{2}+b^{2}}{a^{2}+1}$ 4等价于 $8a^{2}+b^{2}$ $4a^{2}$ ，即 $4a^{2}+b^{2}$ $4ab=4$ ，当且仅当 $2a=b$ ，即 $\left\{\begin{aligned}a&=\frac{\sqrt{2}}{2}\\ b&=\sqrt{2}\end{aligned}\right.$ 时等号成立，
> >
> > 故 $^{D}$ 正确.
> >
> > 故选 **C**.
