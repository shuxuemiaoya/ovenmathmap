题型05：利用基本不等式求解恒成立问题【典例1】设 $x > 0, y > 0$ ，不等式 $\sqrt{x} + \sqrt{y} \leq a\sqrt{x + y}$ 恒成立，则 $a$ 的最小值是（）A. $\frac{\sqrt{2}}{2}$ B. 1 C. 2 D. $\sqrt{2}$

【答案】D

【详解】因为 $\sqrt{x} +\sqrt{y}\leq a\sqrt{x + y}$ 恒成立，所以 $a^{\frac{\sqrt{x} + \sqrt{y}}{\sqrt{x + y}}}$ 恒成立，即 $a^2\frac{x + y + 2\sqrt{xy}}{x + y}$ 恒成立．又 $\frac{x + y + 2\sqrt{xy}}{x + y}\leq \frac{x + y + x + y}{x + y} = 2$ ，当且仅当 $x = y$ 时，等号成立，所以 $a^2$ 2，即 $a\sqrt{2}$ ：
