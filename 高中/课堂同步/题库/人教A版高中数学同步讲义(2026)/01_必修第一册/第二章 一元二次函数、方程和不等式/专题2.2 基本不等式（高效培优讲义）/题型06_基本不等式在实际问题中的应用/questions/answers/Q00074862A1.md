> [!faq]- 《专题2.2 基本不等式（高效培优讲义）》官方解析
>
> > [!success]- **【答案】** (1) $W(x) = \begin{cases} -10x^{2} + 600x - 1000, & 0 < x < 40, \\ -\left(x + \frac{10000}{x}\right) + 8450, & x = 40. \end{cases}$ (2)当 2023 年年产量为 100 千部时，企业所获利润最大，最大利润是 8250 万元
>
> > [!note]- **【解析】**
> > （1）当 $0 < x < 40$ 时， $W(x) = 700x - (10x^2 + 100x + 750) - 250 = -10x^2 + 600x - 1000$ ；
> >
> > 当 $x$ 40时， $W(x) = 700x - \left(701x + \frac{10000}{x} - 8700\right) - 250 = -\left(x + \frac{10000}{x}\right) + 8450$
> >
> > 所以 $W(x)=\left\{\begin{aligned}-10x^{2}+600x-1000, &0<x<40,\\ -\left(x+\frac{10000}{x}\right)+8450,x&40.\end{aligned}\right.$
> >
> > (2) 当 0 < x < 40 时， $W(x) = -10(x - 30)^{2} + 8000$ ，当 x = 30 时， $W(x)_{\max} = 8000$ 万元；
> >
> > 当 $x$ 40时， $W(x) = -\left(x + \frac{10000}{x}\right) + 8450 \leq 8450 - 2\sqrt{x \cdot \frac{10000}{x}} = 8250$
> >
> > 当且仅当 $x=\frac{10000}{x}$ ，即 x=100 时等号成立， $W(x)_{\max}=8250$ 万元·
> >
> > 因为 8250 > 8000，故最大利润是 8250 万元。
> >
> > 答：当 $^{2023}$ 年年产量为 $^{100}$ 千部时，企业所获利润最大，最大利润是 $^{8250}$ 万元·
