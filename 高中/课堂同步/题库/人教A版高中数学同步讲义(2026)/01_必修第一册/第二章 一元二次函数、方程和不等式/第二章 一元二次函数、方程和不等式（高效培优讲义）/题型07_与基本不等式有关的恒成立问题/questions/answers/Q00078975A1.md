> [!faq]- 《第二章 一元二次函数、方程和不等式（高效培优讲义）》官方解析
>
> > [!success]- **【答案】** C
>
> > [!note]- **【解析】**
> > 因为 $\frac{m(x+1)y}{m-1} \leq y^{2} + x + 1$ 对任意的 x > 0, y > 0 恒成立，
> >
> > 可得 $\frac{m}{m-1} \leq \frac{y^{2} + x + 1}{(x + 1)y} = \frac{y}{x + 1} + \frac{1}{y}$ 对任意的 x > 0, y > 0 恒成立，
> >
> > 又因为 $x + y = 3$ ，可得 $(x + 1) + y = 4$ ，
> >
> > $$
> > \frac {y}{x + 1} + \frac {1}{y} = \frac {y}{x + 1} + \frac {(x + 1) + y}{4 y} = \frac {y}{x + 1} + \frac {x + 1}{4 y} + \frac {1}{4} \quad 2 \sqrt {\frac {y}{x + 1} \cdot \frac {x + 1}{4 y}} + \frac {1}{4} = \frac {5}{4}
> > $$
> >
> > 当且仅当 $\frac{y}{x+1}=\frac{x+1}{4y}$ 即 $x=\frac{5}{3}, y=\frac{4}{3}$ 时等号成立，
> >
> > 所以 $\frac{y}{x + 1} +\frac{1}{y}$ 最小值为 $\frac{5}{4}$ ，所以 $\frac{m}{m - 1}\leq \frac{5}{4}$ ，可得 $\frac{5 - m}{4(m - 1)}\leq 0$ ，即 $\frac{m - 5}{4(m - 1)}$ 0
> >
> > 所以 $\left\{\begin{aligned}(m-5)(m-1)&0\\ m-1\neq0\end{aligned}\right.$ ，解得 m 5 或 m<1，
> >
> > 所以实数 $m$ 的取值范围为 $(- \infty, 1) \cup [5, +\infty)$ .
> >
> > 故选 **C**.
