> [!faq]- 《第二章 一元二次函数、方程和不等式（高效培优讲义）》官方解析
>
> > [!success]- **【答案】** -1<x<0 或 x>2
>
> > [!note]- **【解析】**
> > 由关于 $x$ 的不等式 $ax^2 + bx + c > 0$ 的解是 $-1 < x < 2$
> >
> > 则 $x_{1} = -1$ 和 $x_{1} = 2$ 是方程 $ax^2 + bx + c = 0$ 的两个实根，
> >
> > 由根与系数的关系得 $\left\{ \begin{array}{l}a <   0\\ -1 + 2 = -\frac{b}{a}\\ (-1)\times 2 = \frac{c}{a} \end{array} \right.$ ，整理得 $\left\{ \begin{array}{ll}a <   0\\ b = -a\\ c = -2a \end{array} \right.$
> >
> > 则当 $x > 0$ 时，关于 $x$ 的不等式 $ax + \frac{c}{x} + b < 0$ 转化为 $x^2 - x - 2 = (x + 1)(x - 2) > 0$ ，解得 $x > 2$
> >
> > 当 $x < 0$ 时，关于 $x$ 的不等式 $ax + \frac{c}{x} + b < 0$ 转化为 $x^2 - x - 2 = (x + 1)(x - 2) < 0$ ，解得 $-1 < x < 0$ ：
> >
> > 综上关于 $x$ 的不等式 $ax + \frac{c}{x} + b < 0$ 的解为 $-1 < x < 0$ 或 $x > 2$
> >
> > 故答案为：-1 < x < 0 或 x > 2
