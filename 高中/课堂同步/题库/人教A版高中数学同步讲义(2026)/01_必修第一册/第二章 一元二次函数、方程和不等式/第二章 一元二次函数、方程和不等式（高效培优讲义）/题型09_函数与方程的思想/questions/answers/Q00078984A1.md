> [!faq]- 《第二章 一元二次函数、方程和不等式（高效培优讲义）》官方解析
>
> > [!success]- **【答案】** A
>
> > [!note]- **【解析】**
> > 因为不等式 $ax^2 + bx + c > 0$ 的解集是 $(- \infty, -2) \cup (3, +\infty)$
> >
> > 所以 $-2,3$ 是方程 $ax^2 + bx + c = 0$ 的两根，且 $a > 0$
> >
> > 由韦达定理可得 $\left\{ \begin{array}{l} -\frac{b}{a} = -2 + 3 = 1 \\ \frac{c}{a} = -2 \times 3 = -6 \\ b = -a, c = -6a \end{array} \right.$ ，即
> >
> > 则不等式 $bx + c > 0 \Leftrightarrow -ax - 6a > 0 \Leftrightarrow x + 6 < 0$ ，解得 x < -6。
> >
> > 故选 **A**
