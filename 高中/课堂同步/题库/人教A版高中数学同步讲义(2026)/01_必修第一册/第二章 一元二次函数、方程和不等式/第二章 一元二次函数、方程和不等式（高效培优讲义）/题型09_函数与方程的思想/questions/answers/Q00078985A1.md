> [!faq]- 《第二章 一元二次函数、方程和不等式（高效培优讲义）》官方解析
>
> > [!success]- **【答案】** C
>
> > [!note]- **【解析】**
> > 由题意知，-1和3是方程 $ax^{2} + bx + c = 0$ 的两根，且 $a < 0$
> >
> > 则有 $-1 + 3 = -\frac{b}{a}, (-1) \times 3 = \frac{c}{a}$ ，故得 $b = -2a, c = -3a$
> >
> > 对于 AB，由 a < 0 和 b = -2a, c = -3a，可推得 b > 0, c > 0，故 AB 均错误；
> >
> > 对于 C，因 $1 \notin \{x < -1 \text{ 或 } x > 3\}$ ，故 $a + b + c > 0$ ，故 C 正确；
> >
> > 对于D，由上分析，不等式 $cx^{2} - bx + a < 0$ 可化为 $a(3x + 1)(x - 1) > 0$
> >
> > 因 $a < 0$ ，故可解得 $-\frac{1}{3} < x < 1$ ，即 $cx^2 - bx + a < 0$ 的解集为 $\left\{x\mid -\frac{1}{3} < x < 1\right\}$ ，故D错误
> >
> > 故选 **C**.
