> [!faq]- 《第二章 一元二次函数、方程和不等式（高效培优讲义）》官方解析
>
> > [!success]- **【答案】** (1) $\left\{\begin{aligned}a&=-4\\ b&=-16\end{aligned}\right.$ (2)答案见解析
>
> > [!note]- **【解析】**
> > （1）由题意可知 $ax^{2} + bx - 12 = 0$ 的两根为 -3 和 -1，
> >
> > 所以由根与系数的关系得 $\left\{ \begin{array}{l} -\frac{b}{a} = -3 + (-1) = -4 \\ -\frac{12}{a} = -3 \times (-1) = 3 \end{array} \right.$
> >
> > $\left\{ \begin{array}{l}a = -4\\ b = -16. \end{array} \right.$ 解得
> >
> > (2) 当 a = 0 时，则 $x + 3 \leq 0$ ，解得 $x \leq -3$ ；
> >
> > 当 $a \neq 0$ 时， $f(x) = ax^2 + bx - 12 = ax^2 + (3a - 4)x - 12 = (x + 3)(ax - 4) = a(x + 3)\left(x - \frac{4}{a}\right)$
> >
> > 当 $a > 0$ 时，则 $\left(x + 3\right)\left(x - \frac{4}{a}\right) = 0$ ，解得 $x \leq -3$ 或 $x = \frac{4}{a}$
> >
> > 当 $a < 0$ 时，则 $\left(x + 3\right)\left(x - \frac{4}{a}\right) \leq 0$
> >
> > 当 $\frac{4}{a} > -3$ 时，即 $a < -\frac{4}{3}$ ，解 $(x + 3)\left(x - \frac{4}{a}\right) \leq 0$ ，得 $-3 \leq x \leq \frac{4}{a}$ ；
> >
> > 当 $\frac{4}{a} = -3$ 时，即 $a = -\frac{4}{3}$ ，解 $(x + 3)\left(x - \frac{4}{a}\right) \leq 0$ ，得 $x = -3$ ；
> >
> > 当 $\frac{4}{a} < -3$ 时，即 $-\frac{4}{3} < a < 0$ ，解 $(x + 3)\left(x - \frac{4}{a}\right) \leq 0$ ，得 $\frac{4}{a} \leq x \leq -3$
> >
> > 综上所述，当 $a < -\frac{4}{3}$ 时，不等式 $f(x)$ 0的解集为 $\left[-3, \frac{4}{a}\right]$ ；
> >
> > 当 $a = -\frac{4}{3}$ 时，不等式 $f(x)$ 0 的解集为 $\{-3\}$ ;
> >
> > 当 $-\frac{4}{3}<a<0$ 时，不等式 $f(x)$ 0 的解集为 $\left[\frac{4}{a},-3\right]$ ;
> >
> > 当 a=0 时，不等式 $f(x)$ 0 的解集为 $(-∞,-3]$ ;
> >
> > 当 $a > 0$ 时，不等式 $f(x)$ 0的解集为 $\left(-\infty , - 3\right]\cup \left[\frac{4}{a}, + \infty\right)$
