> [!faq]- 《第二章 一元二次函数、方程和不等式（高效培优讲义）》官方解析
>
> > [!success]- **【答案】** (1)8 (2)答案见解析
>
> > [!note]- **【解析】**
> > （1）因为函数 $f(x)=ax^{2}+(b-2)x+3$ 的图象过点 $(2,1)$
> >
> > 所以 $1=4a+2(b-2)+3$ ，即 $2a+b=1$ ，由 a>0，b>0
> >
> > 所以 $\frac{1}{a} +\frac{2}{b} = (2a + b)\left(\frac{1}{a} +\frac{2}{b}\right) = 2 + 2 + \frac{b}{a} +\frac{4a}{b}$ $4 + 2\sqrt{\frac{b}{a}\cdot\frac{4a}{b}} = 8$
> >
> > 当且仅当 $\frac{b}{a} = \frac{4a}{b}$ 时取等号，即 $a = \frac{1}{4}, b = \frac{1}{2}$ 时取得最小值为8.
> >
> > (2) 因为 $2a + b = 1$ ，所以 $f(x) > 1 \Leftrightarrow ax^2 - (2a + 1)x + 2 = (ax - 1)(x - 2) > 0$
> >
> > 当 $a = 0$ 时，不等式的解为 $x < 2$ ；
> >
> > 当 $a < 0$ 时，得 $\frac{1}{a} < 2$ ，则不等式的解为 $\frac{1}{a} < x < 2$
> >
> > 当 $0 < a < \frac{1}{2}$ 时，得 $\frac{1}{a} > 2$ ，则不等式的解为 $x > \frac{1}{a}$ 或 x < 2；
> >
> > 当 $a = \frac{1}{2}$ 时，得 $\frac{1}{a} = 2$ ，则不等式的解为 $x \neq 2$ ；
> >
> > 当 $a > \frac{1}{2}$ 时，得 $\frac{1}{a} < 2$ ，则不等式的解为 $x < \frac{1}{a}$ 或 $x > 2$
> >
> > 综上所述，当 $a = 0$ 时，不等式的解集为 $\{x|x < 2\}$
> >
> > 当 a<0 时，不等式的解集为 $\left\{x\mid\frac{1}{a}<x<2\right\}$ ;
> >
> > 当 $0 < a \leq \frac{1}{2}$ 时，不等式的解集为 $\left\{x \mid x > \frac{1}{a} \text{ 或 } x < 2\right\}$ ;
> >
> > 当 $a > \frac{1}{2}$ 时，不等式的解集为 $\left\{x \mid x > 2 \text{或} x < \frac{1}{a}\right\}$ .
