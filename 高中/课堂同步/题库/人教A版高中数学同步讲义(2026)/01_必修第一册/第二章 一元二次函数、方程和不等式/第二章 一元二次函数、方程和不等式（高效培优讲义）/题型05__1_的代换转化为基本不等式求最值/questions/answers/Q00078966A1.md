> [!faq]- 《第二章 一元二次函数、方程和不等式（高效培优讲义）》官方解析
>
> > [!success]- **【答案】** A
>
> > [!note]- **【解析】**
> > $\because x + y = 3, \therefore x + y + 1 = 4, \frac{1}{4} [x + (y + 1)] = 1$
> >
> > $$
> > \frac {1}{x} + \frac {1}{y + 1} = \frac {1}{4} [ x + (y + 1) ] \left(\frac {1}{x} + \frac {1}{y + 1}\right) = \frac {1}{4} \left(2 + \frac {y + 1}{x} + \frac {x}{y + 1}\right) \quad \frac {1}{4} \left(2 + 2 \sqrt {\frac {y + 1}{x} \cdot \frac {x}{y + 1}}\right) = 1
> > $$
> >
> > 当且仅当 $\left\{ \begin{array}{l} x + y = 3 \\ \frac{y + 1}{x} = \frac{x}{y + 1} \end{array} \right.$ ，即 $\left\{ \begin{array}{l} x = 2 \\ y = 1 \end{array} \right.$ 时取等号.
> >
> > 故选：A.
> >
> > ## 方法技巧
> >
> > （1）若已知条件中的“1”（常量可化为“1”）与目标函数之间具有某种关系（尤其是整式与分式相乘模型），则实施“1”代换，配凑和或积为常数.
> >
> > 模型1 已知正数 $x, y$ 满足 $ax + by = 1$ ，求 $\frac{m}{x} + \frac{n}{y}$ 的最小值。 $(a > 0, b > 0, m > 0, n > 0)$
> >
> > 模型2 已知正数 $x, y$ 满足 $\frac{a}{x} + \frac{b}{y} = 1$ 求 $mx + ny$ 的最小值。 $(a > 0, b > 0, m > 0, n > 0)$
> >
> > (2) 常数代换法适用于求解条件最值问题．应用此种方法求解最值的基本步骤为：
> > - **①**：根据已知条件或其变形确定定值(常数)；
> > - **②**：把确定的定值(常数)变形为1；
> > - **③**：把“1”的表达式与所求最值的表达式相乘或相除，进而构造和或积的形式；
> > - **④**：利用基本不等式求解最值。
> >
> > (3) 有些问题从形式上看，似乎具备和与倒数和的一些特征，但细究起来，又存在明确的区别，求解此类问
> >
> > 题时，需要对条件和结论中的表达式进行合理、巧妙的配凑与构造；从而变形、构造出和与倒数和的关系.
