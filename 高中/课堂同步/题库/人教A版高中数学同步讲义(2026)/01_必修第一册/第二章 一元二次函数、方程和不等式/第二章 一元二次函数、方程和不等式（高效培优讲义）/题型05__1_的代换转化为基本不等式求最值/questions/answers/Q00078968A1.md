> [!faq]- 《第二章 一元二次函数、方程和不等式（高效培优讲义）》官方解析
>
> > [!success]- **【答案】** $\frac{1}{4}$
>
> > [!note]- **【解析】**
> > 解法1：设 $x+2=s$ ， $y+1=t$ ，
> >
> > 则 $s + t = x + y + 3 = 4$ ，所以 $\frac{x^{2}}{x + 2} + \frac{y^{2}}{y + 1} = \frac{(s - 2)^{2}}{s} + \frac{(t - 1)^{2}}{t}$
> >
> > $$
> > = \left(s - 4 + \frac {4}{s}\right) + \left(t - 2 + \frac {1}{t}\right) = (s + t) + \left(\frac {4}{s} + \frac {1}{t}\right) - 6 = \left(\frac {4}{s} + \frac {1}{t}\right) - 2
> > $$
> >
> > 因为 $\frac{4}{s} +\frac{1}{t} = \frac{1}{4}\left(\frac{4}{s} +\frac{1}{t}\right)(s + t) = \frac{1}{4}\left(\frac{4t}{s} +\frac{s}{t} +5\right)\quad \frac{9}{4},$
> >
> > 当且仅当 $s = 2t$ 时，即 $s = \frac{8}{3}, t = \frac{4}{3}$ 时，等号成立，
> >
> > 所以 $\frac{x^{2}}{x+2}+\frac{y^{2}}{y+1}\quad\frac{1}{4}$
> >
> > 当且仅当 $x=\frac{2}{3}$ ， $y=\frac{1}{3}$ 时取等号。
> >
> > 所以 $\frac{x^2}{x + 2} +\frac{y^2}{y + 1}$ 的最小值为 $\frac{1}{4}$
> >
> > 解法2：因为 $x + y = 1$ ，则 $(x + 2) + (y + 1) = 4$
> >
> > 所以 $\frac{x^2}{x + 2} +\frac{y^2}{y + 1} = \frac{1}{4}\left(\frac{x^2}{x + 2} +\frac{y^2}{y + 1}\right)\left[(x + 2) + (y + 1)\right]$
> >
> > $$
> > = \frac {1}{4} \left[ x ^ {2} + \frac {x ^ {2} (y + 1)}{x + 2} + \frac {y ^ {2} (x + 2)}{y + 1} + y ^ {2} \right] \quad \frac {1}{4} \left[ x ^ {2} + 2 \sqrt {\frac {x ^ {2} (y + 1)}{x + 2} \times \frac {y ^ {2} (x + 2)}{y + 1}} + y ^ {2} \right]
> > $$
> >
> > $$
> > = \frac {1}{4} (x ^ {2} + y ^ {2} + 2 x y) = \frac {1}{4} (x + y) ^ {2} = \frac {1}{4}
> > $$
> >
> > 当且仅当 $\frac{x^{2}(y+1)}{x+2}=\frac{y^{2}(x+2)}{y+1}$ ，即 $x=\frac{2}{3}$ ， $y=\frac{1}{3}$ 时取等号。
> >
> > 所以 $\frac{x^2}{x + 2} +\frac{y^2}{y + 1}$ 的最小值为 $\frac{1}{4}$
> >
> > 解法 3： $\frac{x^{2}}{x+2}+\frac{y^{2}}{y+1}\quad\frac{(x+y)^{2}}{x+2+y+1}=\frac{1}{4}$
> >
> > 当且仅当 $\frac{x}{x + 2} = \frac{y}{y + 1}$ ，即 $xy + x = xy + 2y$ ， $x = 2y$ ，即 $x = \frac{2}{3}$ ， $y = \frac{1}{3}$ 时取等号.
> >
> > 所以 $\frac{x^2}{x + 2} +\frac{y^2}{y + 1}$ 的最小值为 $\frac{1}{4}$
