> [!faq]- 《第二章 一元二次函数、方程和不等式（高效培优讲义）》官方解析
>
> > [!success]- **【答案】** （1） $a$ $\frac{1}{3}$ (2) 答案见解析
>
> > [!note]- **【解析】**
> > （1）根据题意， $ax^{2}+(1-a)x+a$ 0 恒成立，
> >
> > 显然当 $a = 0$ 时，不成立，
> >
> > 则 $\left\{\begin{aligned}a&>0\\\Delta&=(1-a)^{2}-4a^{2}\leq0\end{aligned}\right.$ ，解得 $a=\frac{1}{3}$ ;
> >
> > (2) $f(x) = ax^{2} - (a + 1)x + 1 = (ax - 1)(x - 1)$
> >
> > 当 $a = 0$ 时， $-x + 1 <   0$ ，则 $x > 1$
> >
> > 当 $a < 0$ 时，令 $f(x) = 0$ ，则 $x = \frac{1}{a}$ ，或 $x = 1$ ，此时 $\frac{1}{a} < 1$ ， $\therefore x < \frac{1}{a}$ 或 $x > 1$
> >
> > 当 $\left\{ \begin{array}{l}a > 0\\ \frac{1}{a} < 1\text{时，即}_{a > 1}\text{时，}\frac{1}{a} < x <   1 \end{array} \right.$
> >
> > 当 $\left\{ \begin{array}{l}a > 0\\ \frac{1}{a} = 1 \end{array} \right.$ ，即 $a = 1$ 时， $x\in \emptyset$
> >
> > 当 $\left\{\begin{aligned}a&>0\\\frac{1}{a}&>1\end{aligned}\right.$ 时，即 $0<a<1$ 时， $1<x<\frac{1}{a}$
> >
> > 综上所述：当 $a < 0$ 时，解集为 $\left\{x \mid x < \frac{1}{a} \text{或} x > 1\right\}$ ；
> >
> > 当 a = 0 时，解集为 $\left\{x \mid x > 1\right\}$ ;
> >
> > 当 $0 < a < 1$ 时，解集为 $\left\{x\mid 1 < x < \frac{1}{a}\right\}$ ；当 $a = 1$ 时， $x \in \emptyset$ ；
> >
> > 当 a > 1 时，解集为 $\left\{x \mid \frac{1}{a} < x < 1\right\}$ .
