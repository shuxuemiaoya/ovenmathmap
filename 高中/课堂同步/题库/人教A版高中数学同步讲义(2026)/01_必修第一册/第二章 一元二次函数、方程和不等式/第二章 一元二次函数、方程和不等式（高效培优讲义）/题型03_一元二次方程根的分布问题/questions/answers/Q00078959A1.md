> [!faq]- 《第二章 一元二次函数、方程和不等式（高效培优讲义）》官方解析
>
> > [!success]- **【答案】** (1) $(-∞,0)∪\left(0,\frac{3}{16}\right)$ (2) $(-2,2)$ (3) $x_{1} = 1, x_{2} = 2$ 或 $x_{1} = 0, x_{2} = 3$
>
> > [!note]- **【解析】**
> > （1）当 $p = q = 1$ 时，由题意，若 $m = 0$ 时，方程不是一元二次方程，没有两个实数根，
> >
> > 若方程 $3mx^{2} + 3x + 4 = 0$ 有两个不等的实数解，
> >
> > 则 $\left\{ \begin{array}{l} m \neq 0 \\ \Delta = 9 - 4 \times 3m \times 4 > 0 \end{array} \right.$ ，解得 $m < \frac{3}{16}$ 且 $m \neq 0$
> >
> > 所以 $m$ 的范围是 $\left(-\infty,0\right)\cup \left(0,\frac{3}{16}\right)$
> >
> > (2) $m = 1$ ，方程为 $3x^{2} + 3px + 4q = 0$ ， $\Delta = 9p^2 -48q > 0$
> >
> > 则 $\left\{ \begin{array}{l}x_{1} + x_{2} = -p\\ x_{1}x_{2} = \frac{4q}{3} \end{array} \right.$ ，又 $x_{1}^{2} + x_{2}^{2} = x_{1}x_{2} + 1$ ，即 $\left(x_{1} + x_{2}\right)^{2} - 2x_{1}x_{2} = x_{1}x_{2} + 1$
> >
> > $\therefore (-p)^{2}-2\times\frac{4q}{3}=\frac{4q}{3}+1$ ，即 $4q=p^{2}-1$ ，
> >
> > 所以 $\Delta = 9p^2 -48q = 9p^2 -12(p^2 -1) > 0$ ，解得 $-2 <   p <   2$
> >
> > 所以 $p$ 的取值范围为 $(-2,2)$
> >
> > (3) 依题意： $m \neq 0$ ，且 $\left\{\begin{aligned}x_{1}+x_{2}&=-\frac{p}{m}\\ x_{1}x_{2}&=\frac{4q}{3m}\end{aligned}\right.$
> >
> > $$
> > m = - \frac {p}{3} \Rightarrow x _ {1} + x _ {2} = 3, q = \frac {1 - p}{4} \Rightarrow x _ {1} x _ {2} = \frac {p - 1}{p} = 1 - \frac {1}{p}
> > $$
> >
> > 因为 $x_{1}, x_{2}, p$ 均为整数，
> >
> > 所以 $x_{1}x_{2}=1-\frac{1}{p}$ 也是整数，
> >
> > $$
> > \therefore p = - 1 \text {或} p = 1
> > $$
> >
> > $$
> > p = - 1 \text {时,} x _ {1} x _ {2} = 2 \text {, 又} x _ {1} + x _ {2} = 3 \text {且} x _ {1} <   x _ {2} \quad x _ {1} = 1, x _ {2} = 2
> > $$
> >
> > $$
> > p = 1 \text {时,} x _ {1} x _ {2} = 0 \text {, 又} x _ {1} + x _ {2} = 3 \text {且} x _ {1} <   x _ {2} \text {, } x _ {1} = 0, x _ {2} = 3
> > $$
> >
> > 综上， $x_{1} = 1, x_{2} = 2$ 或 $x_{1} = 0, x_{2} = 3$
