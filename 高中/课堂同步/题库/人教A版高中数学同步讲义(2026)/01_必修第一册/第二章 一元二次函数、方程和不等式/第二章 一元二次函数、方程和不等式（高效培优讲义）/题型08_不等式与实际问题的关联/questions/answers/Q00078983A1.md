> [!faq]- 《第二章 一元二次函数、方程和不等式（高效培优讲义）》官方解析
>
> > [!success]- **【答案】** (1)证明见解析 (2)证明见解析 (3) $\frac{1}{12}$ 米
>
> > [!note]- **【解析】**
> > （1）证明：因为 $\frac{a+b}{2}$ $\sqrt{ab}$ $\frac{c+d}{2}$ $\sqrt{cd}$ ，当且仅当 a=b，c=d 时等号成立，
> >
> > 所以 $\frac{a+b+c+d}{2}$ $\sqrt{ab}+\sqrt{cd}$ 当且仅当 a=b，c=d 时等号成立.
> >
> > 所以 $\frac{\sqrt{ab}+\sqrt{cd}}{2}\quad\sqrt{\sqrt{ab}\cdot\sqrt{cd}}=\sqrt[4]{abcd}$ ，当且仅当 $\sqrt{ab}=\sqrt{cd}$ 时等号成立，
> >
> > 所以 $\frac{a + b + c + d}{4}$ $\frac{\sqrt{ab} + \sqrt{cd}}{2}$ $\sqrt[4]{abcd}$ ，当且仅当 $a = b = c = d$ 时等号成立.
> >
> > (2) 解：由于 $\frac{a+b+c+d}{4}$ $\frac{\sqrt{ab}+\sqrt{cd}}{2}$ $\sqrt[4]{abcd}$ ，当且仅当 a=b=c=d 时等号成立，
> >
> > 令 $d = \sqrt[3]{abc}$ ，得 $\frac{a + b + c + \sqrt[3]{abc}}{4} \sqrt[4]{abc \cdot \sqrt[3]{abc}} = \sqrt[4]{(abc)^{1 + \frac{1}{3}}} = (abc)^{\frac{1}{3}} = \sqrt[3]{abc}$
> >
> > 即 $a + b + c + \sqrt[3]{abc}$ $4\sqrt[3]{abc}$ ，故 $a + b + c = 3\sqrt[3]{abc}$ .
> >
> > 所以 $\frac{a+b+c}{3}$ $\sqrt[3]{abc}$ ，当且仅当 a=b=c=d 时等号成立.
> >
> > (3) 解：做成的长方体的底面是一个边长为 $\frac{1}{2} - 2x$ 的正方形，高为 $x$ .
> >
> > 所以 $V=\left(\frac{1}{2}-2x\right)\left(\frac{1}{2}-2x\right)x$
> >
> > 由（2）中已证的不等式，可知 $\sqrt[3]{\left(\frac{1}{2} - 2x\right)\left(\frac{1}{2} - 2x\right) \cdot 4x} \leq \frac{\left(\frac{1}{2} - 2x\right) + \left(\frac{1}{2} - 2x\right) + 4x}{3} = \frac{1}{3}$ ，
> >
> > 当且仅当 $\frac{1}{2}-2x=4x$ 时等号成立，当且仅当 $x=\frac{1}{12}$ 时等号成立.
> >
> > 所以 $\left(\frac{1}{2} - 2x\right)\left(\frac{1}{2} - 2x\right) \cdot 4x \leq \left(\frac{1}{3}\right)^3$ ，因此 $V = \left(\frac{1}{2} - 2x\right)\left(\frac{1}{2} - 2x\right)x \leq \frac{1}{108}$
> >
> > 综上所述，当 $x = \frac{1}{12}$ 米，长方体盒子的容积 $V$ 取到最大值 $\frac{1}{108}$ 立方米
