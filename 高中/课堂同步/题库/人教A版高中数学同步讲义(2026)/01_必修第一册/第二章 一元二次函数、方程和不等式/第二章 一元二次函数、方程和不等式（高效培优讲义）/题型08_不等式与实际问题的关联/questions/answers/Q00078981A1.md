> [!faq]- 《第二章 一元二次函数、方程和不等式（高效培优讲义）》官方解析
>
> > [!success]- **【答案】** 当水池设计成底面边长为 40m 的正方形时，总造价最低，为 198400 元.
>
> > [!note]- **【解析】**
> > 解：设池底的一边长为 $x\mathrm{m}(x > 0)$ ，则另一边长为 $\frac{4800}{3x}\mathrm{m} = \frac{1600}{x}\mathrm{m}$ ，总造价为 $y$ 元，
> >
> > $$
> > y = 1 6 0 0 \times 1 0 0 + \left(x + \frac {1 6 0 0}{x}\right) \times 3 \times 2 \times 8 0 = 1 6 0 0 0 0 + 4 8 0 \times \left(x + \frac {1 6 0 0}{x}\right)
> > $$
> >
> > $$
> > 1 6 0 0 0 0 + 4 8 0 \times 2 \sqrt {x \cdot \frac {1 6 0 0}{x}} = 1 9 8 4 0 0
> > $$
> >
> > 当且仅当 $x = \frac{1600}{x}$ ，即 $x = 40$ 时，等号成立，
> >
> > 所以当水池设计成底面边长为 40m 的正方形时，总造价最低，最低为 198400 元。
