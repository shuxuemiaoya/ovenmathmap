> [!faq]- 《第二章 一元二次函数、方程和不等式（高效培优讲义）》官方解析
>
> > [!success]- **【答案】** 长为 $9\sqrt{3}$ m，宽为 $\frac{50\sqrt{3}}{9}$ m时总造价最低。
>
> > [!note]- **【解析】**
> > 设处理池的长和宽分别为 $x$ ， $y$ ，高为 $h$ ，总造价为 $z$ ，则 $xy = 150$ ， $(0 < x \leq 16, 0 < y \leq 16)$
> >
> > $$
> > z = (2 x + 2 y) h \times 4 0 0 + 2 y h \times 2 4 8 + 1 5 0 \times 8 0 = (8 0 0 x + 1 2 9 6 y) h + 1 2 0 0 0 \quad 2 \sqrt {8 0 0 x \times 1 2 9 6 y} h + 1 2 0 0 0 = 1 4 4 0 \sqrt {3} h + 1 2 0 0 0
> > $$
> >
> > 当且仅当 $800x = 1296y$ ，又 $xy = 150$ ，即 $x = 9\sqrt{3} < 16$ ， $y = \frac{50\sqrt{3}}{9} < 16$ 时取到等号，
> >
> > 故长为 $9\sqrt{3}\mathrm{m}$ ，宽为 $\frac{50\sqrt{3}}{9}\mathrm{m}$ 时总造价最低.
