> [!faq]- 《第二章 一元二次函数、方程和不等式（高效培优讲义）》官方解析
>
> > [!success]- **【答案】** B
>
> > [!note]- **【解析】**
> > 由 $\frac{12ab}{2a + 3b - 1} = \frac{(2a + 3b)^2 - (4a^2 + 9b^2)}{2a + 3b - 1} = \frac{(2a + 3b)^2 - 1}{2a + 3b - 1} = 2a + 3b + 1$
> >
> > 又因为 $2 \times 2a \times 3b \leq 4a^2 + 9b^2$ ，所以 $2 \times 2a \times 3b + 4a^2 + 9b^2 \leq 2(4a^2 + 9b^2)$
> >
> > 即得 $\left(2a + 3b\right)^2 \leq 2\left(4a^2 + 9b^2\right)$
> >
> > 所以 $\frac{2a + 3b}{2} \leq \sqrt{\frac{(2a)^2 + (3b)^2}{2}} = \frac{\sqrt{2}}{2}$ 当且仅当 $2a = 3b = \frac{\sqrt{2}}{2}$ 时取等号，
> >
> > 所以 $2a + 3b + 1 \leq \sqrt{2} + 1$ ，所以 $\frac{12ab}{2a + 3b - 1}$ 的最大值是 $\sqrt{2} + 1$
> >
> > 故选 **B**.
