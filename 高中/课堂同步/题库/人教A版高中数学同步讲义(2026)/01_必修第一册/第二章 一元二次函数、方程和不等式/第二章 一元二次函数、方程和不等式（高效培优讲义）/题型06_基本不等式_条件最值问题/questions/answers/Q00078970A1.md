> [!faq]- 《第二章 一元二次函数、方程和不等式（高效培优讲义）》官方解析
>
> > [!success]- **【答案】** B
>
> > [!note]- **【解析】**
> > 由 $ab + a + b = 8$ ，得 $b = \frac{8 - a}{a + 1} = -\frac{a + 1 - 9}{a + 1} = -1 + \frac{9}{a + 1}$ 则 $b + 1 = \frac{9}{a + 1}$ ， $\left(a + 1\right)^2 +\left(b + 1\right)^2 = \left(a + 1\right)^2 +\left(\frac{9}{a + 1}\right)^2\quad 2(a + 1)\cdot \left(\frac{9}{a + 1}\right) = 18$
> >
> > 当且仅当 $a + 1 = \frac{9}{a + 1}$ ，即 $a = b = 2$ 时等号成立. $\therefore (a + 1)^2 +(b + 1)^2$ 的最小值是18.
> >
> > 故选 **B**
