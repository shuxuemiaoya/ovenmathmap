> [!faq]- 《第二章 一元二次函数、方程和不等式（高效培优讲义）》官方解析
>
> > [!success]- **【答案】** A
>
> > [!note]- **【解析】**
> > ∵不等式 $ax^{2} + bx + c < 0$ 的解集为 $\{x, x < 1 \text{ 或 } x > 3\}$
> >
> > 可得 $a < 0, x = 1, x = 3$ 是方程 $ax^2 + bx + c = 0$ 的两根，
> >
> > 由韦达定理可得： $b = -4a$ ， $c = 3a$ ，且 $a < 0$
> >
> > 所以 $cx + a < 0$ 的解集，即 $3ax + a < 0$ ，
> >
> > 所以解集为 $\left\{x\mid x > - \frac{1}{3}\right\}$
> >
> > 故选 **A**.
