> [!faq]- 《第二章 一元二次函数、方程和不等式（高效培优讲义）》官方解析
>
> > [!success]- **【答案】** (1)证明见解析； (2) $a = 0$ 或 $a = 1$ 或 $a = 2$ .
>
> > [!note]- **【解析】**
> > （1）不等式 $x*2 + x*3$ 1可化为 $\left|x - 2\right| + \left|x - 3\right|$ 1
> >
> > 当 $x > 3$ 时，不等式可化为 $(x - 2) + (x - 3) = 2x - 5\quad 1$ ，解得 $x = 3$ ，所以 $x > 3$
> >
> > 当 $2 \leq x \leq 3$ 时，不等式可化为 $(x - 2) + (3 - x) = 1 - 1$ ，恒成立，所以 $2 \leq x \leq 3$
> >
> > 当 $x < 2$ 时，不等式可化为 $-(x - 2) - (x - 3) = -2x + 5\quad 1$ ，解得 $x \leq 2$ ，所以 $x < 2$
> >
> > 综上所述，关于 $x$ 的不等式 $x * 2 + x * 3 = 1$ 的解集为 $\mathbf{R}$
> >
> > (2) 不等式 $x * a < \frac{-ax^2 + 20}{2}$ ，即 $\left|x - a\right| < \frac{-ax^2 + 20}{2}$ ，也即 $ax^2 + 2|x - a| - 20 < 0$
> >
> > 当 $a = 0$ 时， $2|x| < 20$ ，解得 $-10 < x < 10$ ， $A = (-10, 10)$ ，满足 $(-2, 3) \subseteq A$
> >
> > 当 $a \neq 0$ 时，因为 $a > 0$ ， $a \in \mathbb{N}$ ， $(-2,3) \subseteq A$
> >
> > 所以 $\left\{\begin{aligned}4a+2|a+2|-20\leq0\\ 9a+2|3-a|-20\leq0\end{aligned}\right.$ ，即 $\left\{\begin{aligned}6a\leq16\\ 2|3-a|\leq20-9a\end{aligned}\right.$ ，解得 a=1 或 a=2。
> >
> > 当 $a = 1$ 时， $ax^2 + 2|x - a| - 20 < 0$ 即 $x^2 + 2|x - 1| - 20 < 0$
> >
> > 当 x 1 时， $x^{2} + 2(x - 1) - 20 = x^{2} + 2x - 22 = (x + 1)^{2} - 23 < 0$ ，所以 $1 \leq x < \sqrt{23} - 1$ ；
> >
> > 当 $x < 1$ 时， $x^{2} + 2(1 - x) - 20 = x^{2} - 2x - 18 = (x - 1)^{2} - 19 < 0$ ，所以 $-\sqrt{19} + 1 < x < 1$
> >
> > 所以 $A = \left(-\sqrt{19} + 1, \sqrt{23} - 1\right)$ ，满足 $(-2, 3) \subseteq A$
> >
> > 当 $a = 2$ 时， $ax^2 + 2|x - a| - 20 < 0$ 即 $2x^2 + 2|x - 2| - 20 < 0$
> >
> > 当 $x$ 2时， $2x^{2} + 2(x - 2) - 20 = 2x^{2} + 2x - 24 = 2\left(x + \frac{1}{2}\right)^{2} - \frac{1}{2} - 24 < 0$ ，所以 $2 \leq x < 3$ ；
> >
> > 当 $x < 2$ 时， $2x^{2} + 2(2 - x) - 20 = 2x^{2} - 2x - 16 = 2\left(x - \frac{1}{2}\right)^{2} - \frac{1}{2} - 16 < 0$ ，所以 $\frac{1 - \sqrt{33}}{2} < x < 2$
> >
> > 所以 $A = \left(\frac{1 - \sqrt{33}}{2}, 3\right)$ ，满足 $(-2, 3) \subseteq A$ 。
> >
> > 综上， $a = 0$ 或 $a = 1$ 或 $a = 2$
