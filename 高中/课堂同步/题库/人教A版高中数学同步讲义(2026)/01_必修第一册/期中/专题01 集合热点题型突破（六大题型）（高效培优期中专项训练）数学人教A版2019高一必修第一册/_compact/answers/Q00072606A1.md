> [!faq]- 《专题01 集合热点题型突破（六大题型）（高效培优期中专项训练）数学人教A版2019高一必修第一册》官方解析
>
> > [!success]- **【答案】** (1) $A \cap B = \{x \mid 1 < x \leq 2\}$ ， $A \cup B = \{x \mid x - 0\}$ ， $\left(\check{\mathbf{Q}}_{\mathbf{R}} A\right) \cap B = \{x \mid 0 \leq x \leq 1\}$ (2) $C = \{x\mid 0\leq x\leq 1$ 或 $x > 2\}$
>
> > [!note]- **【分析】**
> > （ $^{1}$ ）根据交、并、补集的运算计算即可；
> >
> > (2) 结合 (1)，根据题意计算即可·
>
> > [!note]- **【解析】**
> > （1）因为 $A=\left\{x \mid x>1\right\}$ ， $B=\left\{x \mid 0 \leq x \leq 2\right\}$ ，
> >
> > 所以 $A \cap B = \{x \mid 1 < x \leq 2\}$ ， $A \cup B = \{x \mid x - 0\}$ ， $\left(\check{\mathbf{Q}}_{\mathrm{R}} A\right) \cap B = \{x \mid 0 \leq x \leq 1\}$ ；
> >
> > (2) 因为 $A \cap B = \left\{ x \mid 1 < x \leq 2 \right\}$ ， $A \cup B = \left\{ x \mid x \quad 0 \right\}$ ，
> >
> > 所以 $C = \{x \mid 0 \leq x \leq 1 \text{ 或 } x > 2\}$ .
