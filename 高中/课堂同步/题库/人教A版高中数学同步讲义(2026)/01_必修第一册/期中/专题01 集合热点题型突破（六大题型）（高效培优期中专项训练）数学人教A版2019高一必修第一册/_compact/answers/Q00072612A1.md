> [!faq]- 《专题01 集合热点题型突破（六大题型）（高效培优期中专项训练）数学人教A版2019高一必修第一册》官方解析
>
> > [!success]- **【答案】** (1) $A \cap B = \{x < 1 < x < 4\}$ ， $A \cup B = \{x - 3 < x < 5\}$ . (2) $\left(-\infty,\frac{1}{2}\right]$
>
> > [!note]- **【分析】**
> > （ $^{1}$ ）根据交集并集概念计算；在求取值范围时，
> >
> > (2) 根据集合间的包含关系构造不等式组，来确定参数的取值范围·
>
> > [!note]- **【解析】**
> > （1）若 a=1，则 $B=\{x1<x<5\}$ ，
> >
> > 所以 $A \cap B = \{\mid x < 1 < x < 4\}$ ， $A \cup B = \{\mid x - 3 < x < 5\}$ .
> >
> > (2) 因为 $A \cup B = A$ ，所以 $B \subseteq A$
> >
> > 当 $B = \emptyset$ 时，满足 $B \subseteq A$ ，此时 $3 + 2a \leq 2 - a \Rightarrow a \leq -\frac{1}{3}$
> >
> > 当时，要使，则 $\left\{ \begin{array}{ll}a > -\frac{1}{3}\\ 2 - a & -3\\ 3 + 2a\leq 4 & -\frac{1}{3} < a\leq \frac{1}{2}. \end{array} \right.$ $B\neq \emptyset$ $B\subseteq A$
> >
> > 综上，实数 $a$ 的取值范围为 $\left(-\infty, \frac{1}{2}\right]$
