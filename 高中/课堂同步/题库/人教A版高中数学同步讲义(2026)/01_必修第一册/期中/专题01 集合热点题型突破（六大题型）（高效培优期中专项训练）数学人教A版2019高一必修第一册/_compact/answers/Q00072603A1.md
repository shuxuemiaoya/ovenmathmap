> [!faq]- 《专题01 集合热点题型突破（六大题型）（高效培优期中专项训练）数学人教A版2019高一必修第一册》官方解析
>
> > [!success]- **【答案】** (1) $A \cap B = \{x \mid -2 \leq x \leq 1\}$ ， $\tilde{Q}_{R} B = \{x \mid 1 < x \leq 6\}$ (2) $a < 1$ .
>
> > [!note]- **【分析】**
> > （ $^{1}$ ）应用集合的交补运算求集合；
> >
> > (2) 根据题设有 $A \subseteq \breve{\mathfrak{Q}}_{\mathrm{R}} B$ ，讨论 $A = \emptyset$ 、 $A \neq \emptyset$ 列不等式求参数范围·
>
> > [!note]- **【解析】**
> > （1）由题设 $A=\left\{x\mid-2\leq x\leq6\right\}$ ， $B=\{x\mid x\leq1$ 或 $x>6\}$ ，
> >
> > 则 $A \cap B = \{x \mid -2 \leq x \leq 1\}$ ， $\tilde{\mathfrak{Q}}_R B = \{x \mid 1 < x \leq 6\}$ ；
> >
> > (2) 由 $\check{\mathfrak{Q}}_{\mathrm{R}} B = \{x \mid 1 < x \leq 6\}$ ，且 $A \cap \check{\mathfrak{Q}}_{\mathrm{R}} B = A$ ，则 $A \subseteq \check{\mathfrak{Q}}_{\mathrm{R}} B$
> >
> > 当 $A = \emptyset$ 时， $2 - a > 2 + a$ ，即 $a < 0$ ；
> >
> > 当时， $\left\{ \begin{array}{ll}2 - a\leq 2 + a\\ 2 - a > 1\\ 2 + a\leq 6 \end{array} \right.$ ，即；
> >
> > 所以 a < 1.
> >
> > ## 考点04 根据交并补混合运算确定集合或参数
