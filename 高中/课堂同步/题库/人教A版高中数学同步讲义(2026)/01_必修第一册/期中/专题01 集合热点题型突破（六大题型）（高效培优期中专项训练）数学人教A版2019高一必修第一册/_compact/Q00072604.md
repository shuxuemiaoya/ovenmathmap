31. 已知集合 $A = \{x \mid -1 \leq x \leq 3\}$ ，集合 $B = \{x \mid m - 3 \leq x \leq m + 2, x \in \mathbf{R}\}$ .

(1) 若 $A \cap B = \{x \mid 0 \leq x \leq 3\}$ ，求实数 $m$ 的值；

(2) 若 $A \cap (\check{\mathfrak{Q}}_{\mathrm{R}} B) = A$ ，求实数 $m$ 的取值范围.
