> [!faq]- 《专题07+函数单调性与奇偶性考点总结（八大题型）（高效培优期中专项训练）数学人教A版2019高一必修第一册》官方解析
>
> > [!success]- **【答案】** AC
>
> > [!note]- **【分析】**
> > 方法一：对于 A，由条件③令 x=0，y=1，结合条件②可得 $f(0)=1$ ；对于 B，结合条件与单调性定义求解；对于 C，不等式 $f(x)<\frac{f(4)}{f(2)}$ 等价于 $f(x)<f(2)$ ，结合 $f(x)$ 的单调性及奇偶性求解；对于 D，令 x=y=0 判断即可.
> >
> > 方法二：构造函数 $f(x)=\mathrm{e}^{|x|}=\left\{\begin{aligned}\mathrm{e}^{-x},&x<0\\ \mathrm{e}^{x},&x=0\end{aligned}\right.$ 判断即可．
>
> > [!note]- **【解析】**
> > 方法一：对于 A，由条件③当 x 0，y 0 时， $f(x+y)=f(x)f(y)$ ，
> >
> > 令 $x = 0$ ， $y = 1$ ，得： $f(1) = f(0)f(1)$
> >
> > 又由条件②得 $f(1)>1$ ，∴ $f(0)=1$ ，A正确；
> >
> > 对于 B，取 $\forall x_{1}$ ， $x_{2}\in\left[0,+\infty\right)$ ，且 $x_{1}<x_{2}$ ，则
> >
> > $$
> > f (x _ {1}) - f (x _ {2}) = f (x _ {1}) - f (x _ {1} + x _ {2} - x _ {1}) = f (x _ {1}) - f (x _ {1}) f (x _ {2} - x _ {1}) = f (x _ {1}) [ 1 - f (x _ {2} - x _ {1}) ]
> > $$
> >
> > $$
> > \therefore 0 \leq x _ {1} <   x _ {2}, \therefore f (x _ {1}) \quad 1, x _ {2} - x _ {1} > 0, \therefore f (x _ {2} - x _ {1}) > 1
> > $$
> >
> > ∴ $f(x_{1}) - f(x_{2}) < 0$ ，即 $f(x_{1}) < f(x_{2})$ ，∴ $f(x)$ 在 $[0, +\infty)$ 上单调递增，B 不正确；
> >
> > 对于 C，∵ $f(4)=f(2+2)=f(2)f(2)$ ， $f(2)>1$ ，
> >
> > ∴不等式 $f(x) < \frac{f(4)}{f(2)}$ 等价于 $f(x) < f(2)$ ,
> >
> > 又 $f(x)$ 在 $[0, +\infty)$ 上单调递增，且由条件①得 $y = f(x)$ 是偶函数，
> >
> > $\therefore |x| < 2$ ， $\therefore$ 解集为 $(-2, 2)$ ，C 正确；
> >
> > 对于 D，令 x = y = 0，则 $f(x + y) = f(0) = 1$ ， $f(x) + f(y) = f(0) + f(0) = 2$ ，
> >
> > 此时 $f(x+y)=f(x)+f(y)$ 不成立，D 错误。
> >
> > 方法二：构造函数 $f(x) = \mathrm{e}^{|x|} = \begin{cases} \mathrm{e}^{-x}, & x < 0 \\ \mathrm{e}^{x}, & x = 0 \end{cases}$ ，符合条件①②。
> >
> > $f(0)=\mathrm{e}^{0}=1$ ，故 A 正确；
> >
> > x 0 时， $f(x)=\mathrm{e}^{x}$ ，在 $\left[0,+\infty\right)$ 上单调递增，故B不正确；
> >
> > $f(x) = \mathrm{e}^{|x|}$ ，则 $f(x) <   \frac{f(4)}{f(2)}$ 即为 $\mathrm{e}^{|x|} <   \mathrm{e}^2$ ，则 $\left|x\right| <   2$ ，解集为 $(-2,2)$ ，故C正确；
> >
> > 令 $x = y = 0$ ，则 $f(x + y) = f(0) = \mathrm{e}^0 = 1$ ， $f(x) + f(y) = f(0) + f(0) = \mathrm{e}^0 + \mathrm{e}^0 = 2$
> >
> > 此时 $f(x + y) = f(x) + f(y)$ 不成立，D错误.
> >
> > 故选 **AC**.
