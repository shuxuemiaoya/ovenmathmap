> [!faq]- 《专题07+函数单调性与奇偶性考点总结（八大题型）（高效培优期中专项训练）数学人教A版2019高一必修第一册》官方解析
>
> > [!success]- **【答案】** A. $\left\{x \mid x < \frac{6 - 2\sqrt{7}}{5} \text{或 } x > \frac{6 + 2\sqrt{7}}{5}\right\}$ B. $\left\{x \mid \frac{6 - 2\sqrt{7}}{5} < x < \frac{6 + 2\sqrt{7}}{5}\right\}$ C. $\{x \mid x < \frac{2}{5} \text{或 } x > 2\}$ D. $\left\{x \mid \frac{2}{5} < x < 2\right\}$
>
> > [!note]- **【分析】**
> > 先由题设结合赋值法求出 $f(-4) = 16$ 和 $f(0) = 1$ ，接着求出函数 $f(x)$ 是单调递减函数，再利用函数单调性解不等式得 $5x^{2} - 12x < -4$ ，解该不等式即可得解。
>
> > [!note]- **【解析】**
> > 因为对任意的 $a, b \in \mathbb{R}$ ，都有 $f(a + b) = f(a)f(b)$ ， $f(-2) = 4$ ，且 $f(0) \neq 0$ ，所以 $f(-4) = f^2(-2) = 4^2 = 16$ ，且 $f(0) = f(0)f(0) \Rightarrow f(0) = 1$ ，设任意 $x_1 < x_2$ ，则 $x_1 - x_2 < 0$ ，则 $f(x_1 - x_2) = f(x_1)f(-x_2) > 1$ ，又 $f(-x_2) = \frac{f(0)}{f(x_2)} = \frac{1}{f(x_2)}$ ，所以 $f(x_1 - x_2) = f(x_1)f(-x_2) = f(x_1)\frac{1}{f(x_2)} > 1$ ，若 $f(x_2) < 0$ ，则当 $x_1 < 0$ 时， $f(x_1) > 1$ ，则 $f(x_1)\frac{1}{f(x_2)} < 0$ ，矛盾，所以 $f(x_2) > 0$ ，所以 $f(x_1) > f(x_2)$ ，所以函数 $f(x)$ 是单调递减函数，
> >
> > 所以不等式 $f(5x^{2} - 12x) > 16$ 等价于 $f(5x^{2} - 12x) > f(-4)$ ，所以 $5x^{2} - 12x < -4$ ，
> >
> > 故 $5x^{2} - 12x + 4 < 0$ 即 $(5x - 2)(x - 2) < 0$ ，解得 $\frac{2}{5} < x < 2$
> >
> > 所以不等式 $f\left(5x^{2} - 12x\right) > 16$ 的解集是 $\left\{x\mid \frac{2}{5} < x < 2\right\}$
> >
> > 故选 **D**
>
> > [!tip]- **【名师点睛】**
> > 关键点睛：解决本题的关键 $^{1}$ 是巧妙赋值求出求出 $f(-4)=16$ 和 $f(0)=1$ ，关键 $^{2}$ 是由所给条件结合单调性定义求出函数 $f(x)$ 是单调递减函数·
