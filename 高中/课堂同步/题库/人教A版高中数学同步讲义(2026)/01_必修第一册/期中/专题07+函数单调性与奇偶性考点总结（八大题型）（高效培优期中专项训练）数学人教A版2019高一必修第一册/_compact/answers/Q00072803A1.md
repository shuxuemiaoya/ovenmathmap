> [!faq]- 《专题07+函数单调性与奇偶性考点总结（八大题型）（高效培优期中专项训练）数学人教A版2019高一必修第一册》官方解析
>
> > [!success]- **【答案】** (1) $a = 2, b = 0$ (2)奇函数，证明见解析 (3) 减函数，证明见解析
>
> > [!note]- **【分析】**
> > （1）根据给定条件，列出方程求出 $a, b$ 值
> >
> > (2) 由 (1) 求出 $f(x)$ ，再利用奇函数的定义推理判断
> >
> > (3) 利用单调函数的定义证明函数的单调性·
>
> > [!note]- **【解析】**
> > （1）由 $f(x)$ 的图象过点 $(1,1)$ ，得 $f(1) = \frac{a \times 1 + b}{1 + 1^2} = \frac{a + b}{2} = 1$ ，又 $f(3) = \frac{3a + b}{1 + 3^2} = \frac{3a + b}{10} = \frac{3}{5}$ ，联立解得： $a = 2, b = 0$ 。
> >
> > (2) 由 (1) 知函数 $f(x) = \frac{2x}{1 + x^2}$ ，因此 $f(x)$ 是奇函数·证明如下：
> >
> > $f(x)$ 的定义域为 R，对于 $\forall x \in R, -x \in R$ ， $f(-x) = \frac{2 \times (-x)}{1 + (-x)^2} = \frac{-2x}{1 + x^2} = -f(x)$
> >
> > 所以 $f(x)$ 是奇函数·
> >
> > (3) 函数 $f(x)$ 在 $(2, +\infty)$ 上是减函数·证明如下：
> >
> > 设 $2 < x_{1} < x_{2}$ ，则 $f(x_{1}) - f(x_{2}) = \frac{2x_{1}}{1 + x_{1}^{2}} -\frac{2x_{2}}{1 + x_{2}^{2}} = \frac{2x_{1}(1 + x_{2}^{2}) - 2x_{2}(1 + x_{1}^{2})}{(1 + x_{1}^{2})(1 + x_{2}^{2})}$
> >
> > $= \frac{2(x_1 - x_2) + 2x_1x_2(x_2 - x_1)}{(1 + x_1^2)(1 + x_2^2)} = 2\cdot \frac{(x_1 - x_2)(1 - x_1x_2)}{(1 + x_1^2)(1 + x_2^2)}$
> >
> > 由 $2 < x_{1} < x_{2}$ ，得 $x_{1} - x_{2} < 0,1 + x_{1}^{2} > 0,1 + x_{2}^{2} > 0,1 - x_{1}x_{2} < 0,$
> >
> > 因此 $f(x_{1})-f(x_{2})>0$ ，即 $f(x_{1})>f(x_{2})$ ，
> >
> > 所以函数 $f(x)$ 在 $(2, +\infty)$ 上是减函数·
