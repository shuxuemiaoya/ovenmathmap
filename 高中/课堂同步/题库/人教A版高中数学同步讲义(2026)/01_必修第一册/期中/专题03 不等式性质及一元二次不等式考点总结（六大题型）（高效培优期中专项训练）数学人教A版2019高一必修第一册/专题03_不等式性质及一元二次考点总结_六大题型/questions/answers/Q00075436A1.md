> [!faq]- 《专题03 不等式性质及一元二次不等式考点总结（六大题型）（高效培优期中专项训练）数学人教A版2019高一必修第一册》官方解析
>
> > [!success]- **【答案】** D
>
> > [!note]- **【分析】**
> > 根据不等式与方程的关系，结合韦达定理，求得 $a, b, c$ 的关系，再分析选项即可求解。【详解】对于 $\mathsf{A}$ ，由已知可得 $y = ax^2 + bx + c$ 开口向下，即 $a < 0$ ，故 $\mathsf{A}$ 错误；对于 $\mathsf{BCD}$ ， $x = -1, x = 3$ 是方程 $ax^2 + bx + c = 0$ 的两个根，
>
> > [!note]- **【解析】**
> > 所以 $\left\{ \begin{array}{l} -\frac{b}{a} = -1 + 3 = 2 \\ \frac{c}{a} = -1 \times 3 = -3 \end{array} \right. \Rightarrow b = -2a, c = -3a$
> > 所以 $c > 0, a + b + c = a - 2a - 3a = -4a > 0$
> > $\Rightarrow cx^{2}-bx+a=-3ax^{2}+2ax+a<0\Rightarrow3x^{2}-2x-1<0\Rightarrow-\frac{1}{3}<x<1$ ，故BC错误，D正确；
> > 故选：D.
