> [!faq]- 《专题03 不等式性质及一元二次不等式考点总结（六大题型）（高效培优期中专项训练）数学人教A版2019高一必修第一册》官方解析
>
> > [!success]- **【答案】** (1)2 (2) $\{1\}$ : (3)答案见解析
>
> > [!note]- **【分析】**
> > （1）由二次不等式与二次方程的关系，得到方程的解，即可求出实数 $a$ 的值；
> >
> > (2) 整理不等式，将不等式左边看成关于 $a$ 的一次函数，代入两端点不等式成立即可解出 $x$ 的解集；
> >
> > (3) 整理不等式，讨论参数 $a$ 的取值，得到相应不等式的解集即可.
>
> > [!note]- **【解析】**
> > （1）由题意知， $0, \frac{1}{2}$ 是方程 $ax^2 + (1 - a)x + a - 2 = 0$ 的两个根，
> >
> > 则 $\left\{ \begin{array}{ll}0 + \frac{1}{2} = -\frac{1 - a}{a}\\ 0\times \frac{1}{2} = \frac{a - 2}{a} \end{array} \right.$ ，则 $a = 2$ (2) $ax^2 + (1 - a)x + a - 2 - 2$
> >
> > 则 $a(x^{2}-x+1)+x$ 0 对于实数 $a\in[-1,1]$ 时恒成立，
> >
> > 则 $\left\{ \begin{array}{ll} - (x^2 - x + 1) + x & 0 \\ (x^2 - x + 1) + x & 0 \end{array} \right.$ ，即 $\left\{ \begin{array}{ll} -x^2 + 2x - 1 & 0 \\ x^2 + 1 & 0 \end{array} \right.$ ， $\left\{ \begin{array}{ll} -(x - 1)^2 & 0 \\ x^2 + 1 & 0 \end{array} \right.$
> >
> > 解得 $\left\{ \begin{array}{l} x = 1 \\ x \in \mathbb{R} \end{array} \right., \therefore x = 1$
> >
> > 则 x 的取值范围为 $\{1\}$ .
> >
> > (3) 依题意， $f(x) < a - 1$ 等价丁 $ax^{2} + (1 - a)x - 1 < 0$ ，
> >
> > 当 $a = 0$ 时，不等式可化为 $x < 1$ ，解集为 $\{x < x < 1\}$
> >
> > 当 $a > 0$ 时，不等式可化为 $(ax + 1)(x - 1) < 0$ ，此时 $-\frac{1}{a} < 1$
> >
> > 所以不等式的解集为 $\left\{x\mid-\frac{1}{a}<x<1\right\}$ .
> >
> > 当 $a < 0$ 时，不等式化为 $(ax + 1)(x - 1) < 0$
> > - **①**：当 $a = -1$ 时， $-\frac{1}{a} = 1$ ，不等式的解集为 $\{x | x \neq 1\}$ ；
> > - **②**：当 $-1 < a < 0$ 时， $-\frac{1}{a} > 1$ ，不等式的解集为 $\left\{x \mid x < 1 \text{ 或 } x > -\frac{1}{a}\right\}$ ；
> > - **③**：当 $a < -1$ 时， $-\frac{1}{a} < 1$ ，不等式的解集为 $\left\{x \mid x < -\frac{1}{a}\right.$ 或 $x > 1\}$ ；
> >
> > 综上，当 $a < -1$ 时，解集为 $\left\{x\mid x < -\frac{1}{a}\text{或} x > 1\right\}$
> >
> > 当 a = -1 时，解集为 $\left\{x \mid x \neq 1\right\}$ ;
> >
> > 当 $-1 < a < 0$ 时，解集为 $\left\{x \mid x < 1 \text{ 或 } x > -\frac{1}{a} \right\}$ ；
> >
> > 当 a = 0 时，解集为 $\{x, x < 1\}$ ;
> >
> > 当 $a > 0$ 时，解集为 $\left\{x\mid -\frac{1}{a} < x < 1\right\}$
