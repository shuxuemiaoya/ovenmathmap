> [!faq]- 《专题03 不等式性质及一元二次不等式考点总结（六大题型）（高效培优期中专项训练）数学人教A版2019高一必修第一册》官方解析
>
> > [!success]- **【答案】** (1)答案见解析； (2) $a \leq 2$ .
>
> > [!note]- **【分析】**
> > （ $^{1}$ ）分类讨论解含参数的一元二次不等式·
> >
> > (2) 等价变形给定不等式并分离参数，利用基本不等式求出最小值即可得解.
>
> > [!note]- **【解析】**
> > （1）不等式 $f(x) < g(x) \Leftrightarrow x^2 + 2x < (a + 1)x + a \Leftrightarrow x^2 - (a - 1)x - a < 0 \Leftrightarrow (x - a)(x + 1) < 0$ ，
> >
> > 当 $a < -1$ 时，解得 $a < x < -1$ ；当 $a = -1$ 时，不等式无解；当 $a > -1$ 时，解得 $-1 < x < a$
> >
> > 所以当 a < -1 时，原不等式的解集为 $(a, -1)$ ；
> >
> > 当 a = -1 时，原不等式的解集为 ∅；
> >
> > 当 $a > -1$ 时，原不等式的解集为 $(-1, a)$ .
> >
> > (2) $\forall x\in (0, + \infty)$ ，不等式 $f(x)$ $g(x) + x - (a + 1)\Leftrightarrow x^2 +2x$ $(a + 1)x + a + x - (a + 1)$
> >
> > $\Leftrightarrow ax \leq x^2 + 1 \Leftrightarrow a \leq x + \frac{1}{x}$ ，而当 $x > 0$ 时， $x + \frac{1}{x} = 2\sqrt{x \cdot \frac{1}{x}} = 2$ ，当且仅当 $x = 1$ 时取等号，则 $a \leq 2$ ，
> >
> > 所以 a 的取值范围是 $a \leq 2$ .
