> [!faq]- 《专题03 不等式性质及一元二次不等式考点总结（六大题型）（高效培优期中专项训练）数学人教A版2019高一必修第一册》官方解析
>
> > [!success]- **【答案】** D
>
> > [!note]- **【分析】**
> > 应用基本不等式求出 $(x + \frac{y}{4})_{\min}$ ，不等式 $x + \frac{y}{4} < m^2 - m$ 有解，只需 $(x + \frac{y}{4})_{\min} < m^2 - m$ 即可。【详解】因为正实数 $x$ ， $y$ 满足 $4x + y = 2xy$ ，所以 $\frac{4}{y} + \frac{1}{x} = 2$ ，所以 $x + \frac{y}{4} = \frac{1}{2} (\frac{4}{y} + \frac{1}{x})(x + \frac{y}{4}) = \frac{1}{2}(2 + \frac{4x}{y} + \frac{y}{4x})$ $\frac{1}{2}(2 + 2\sqrt{\frac{4x}{y} \times \frac{y}{4x}}) = 2$ ，当且仅当 $\frac{4x}{y} = \frac{y}{4x}$ 且 $\frac{4}{y} + \frac{1}{x} = 2$ ，即 $\left\{ \begin{array}{l} x = \frac{3}{2} \\ y = 3 \end{array} \right.$ 时等号成立。因为不等式 $x + \frac{y}{4} < m^2 - m$ 有解，所以只需 $(x + \frac{y}{4})_{\min} < m^2 - m$ ，即 $m^2 - m > 2$ 即可，所以 $m < -1$ 或 $m > 2$ 。
>
> > [!note]- **【解析】**
> >
> > 故选 **D**
