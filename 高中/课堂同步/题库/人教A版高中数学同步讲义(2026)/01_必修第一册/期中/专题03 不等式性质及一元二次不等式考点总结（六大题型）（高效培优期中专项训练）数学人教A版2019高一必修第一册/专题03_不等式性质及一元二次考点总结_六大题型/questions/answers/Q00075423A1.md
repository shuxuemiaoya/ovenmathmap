> [!faq]- 《专题03 不等式性质及一元二次不等式考点总结（六大题型）（高效培优期中专项训练）数学人教A版2019高一必修第一册》官方解析
>
> > [!success]- **【答案】** $[-1,4]$
>
> > [!note]- **【分析】**
> > 根据不等式的性质结合已知条件求解即可.
>
> > [!note]- **【解析】**
> > 因为 $-1 \leq x + 2y \leq 5, -1 \leq x - 2y > 3$
> >
> > 所以 $-1 + (-1) \leq x + 2y + x - 2y \leq 5 + 3$ ，即 $-2 \leq 2x \leq 8$ ，得 $-1 \leq x \leq 4$
> >
> > 故答案为： $[-1,4]$
