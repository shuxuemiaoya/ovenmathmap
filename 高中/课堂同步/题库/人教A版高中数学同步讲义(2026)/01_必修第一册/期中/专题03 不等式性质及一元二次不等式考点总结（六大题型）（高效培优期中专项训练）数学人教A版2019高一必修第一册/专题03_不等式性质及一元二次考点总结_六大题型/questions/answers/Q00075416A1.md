> [!faq]- 《专题03 不等式性质及一元二次不等式考点总结（六大题型）（高效培优期中专项训练）数学人教A版2019高一必修第一册》官方解析
>
> > [!success]- **【答案】** D
>
> > [!note]- **【分析】**
> > 应用不等式的性质及作差法判断 A，B，C，再应用特殊值法判断 D.
>
> > [!note]- **【解析】**
> > 因为 -1 < b < a < 0，则 1 > -b > -a > 0，则 $b^{2} > a^{2}$ ，A 选项正确；
> > 因为 -1 < b < a < 0，则 $b - a \langle 0, ab \rangle 0$ ，则 $\frac{1}{a} - \frac{1}{b} = \frac{b - a}{ab} < 0$ ，B 选项正确；
> > 因为 -1 < b < a < 0，则 a - b > 0, b < 0，则 $ab - b^{2} = b(a - b) < 0$ ，C 选项正确；
> > 取 b = -0.75, a = -0.5, $a + b = -1.25$ ，所以 $a + b < -1$ ，D 选项错误；
> >
> > 故选 **D**.
