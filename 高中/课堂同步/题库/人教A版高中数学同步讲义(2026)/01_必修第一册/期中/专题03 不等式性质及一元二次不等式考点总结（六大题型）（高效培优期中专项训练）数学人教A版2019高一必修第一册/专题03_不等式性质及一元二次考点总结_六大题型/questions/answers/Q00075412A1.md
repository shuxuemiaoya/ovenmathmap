> [!faq]- 《专题03 不等式性质及一元二次不等式考点总结（六大题型）（高效培优期中专项训练）数学人教A版2019高一必修第一册》官方解析
>
> > [!success]- **【答案】** AB
>
> > [!note]- **【分析】**
> > 作差，由不等式的性质判断 ABD 选项，举反例排除 C 选项.
>
> > [!note]- **【解析】**
> > A选项， $(a-c)-(d-b)=(a-d)+(b-c)$
> >
> > 因为 $a > b > c > d$ ，所以 $a - d > 0, b - c > 0$ ，所以 $(a - c) - (d - b) > 0$ ， $a - c > d - b$ ，A正确；
> >
> > B 选项， $(a+c)-(b+d)=(a-b)+(c-d)$
> >
> > 因为 $a > b > c > d$ ，所以 $a - b > 0, c - d > 0$ ，所以 $(a + c) - (b + d) > 0$ ， $a + c > b + d$ ，B正确；
> >
> > C 选项，当 a=3, b=0, c=-2, d=-3 时，ac=-6, bd=0, ac<bd，C 错误；
> >
> > D 选项， $\frac{b}{a-b}-\frac{c}{a-c}=\frac{b(a-c)-c(a-b)}{(a-b)(a-c)}=\frac{a(b-c)}{(a-b)(a-c)}$
> >
> > 因为 $a > b > c > d$ ，所以 $a - b > 0, a - c > 0, b - c > 0$
> >
> > 当 $a > 0$ 时， $\frac{a(b - c)}{(a - b)(a - c)} >0$ ， $\frac{b}{a - b} >\frac{c}{a - c}$
> >
> > 当 $a < 0$ 时， $\frac{a(b - c)}{(a - b)(a - c)} < 0$ ， $\frac{b}{a - b} < \frac{c}{a - c}$ ，D错误；
> >
> > 故选 **AB**.
