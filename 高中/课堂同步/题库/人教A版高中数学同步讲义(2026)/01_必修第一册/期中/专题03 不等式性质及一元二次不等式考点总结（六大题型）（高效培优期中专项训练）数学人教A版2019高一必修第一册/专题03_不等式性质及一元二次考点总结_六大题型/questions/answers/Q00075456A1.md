> [!faq]- 《专题03 不等式性质及一元二次不等式考点总结（六大题型）（高效培优期中专项训练）数学人教A版2019高一必修第一册》官方解析
>
> > [!success]- **【答案】** C
>
> > [!note]- **【分析】**
> > 分离参数变为 $a \leq \frac{x^2 + 4x + 7}{x + 2}$ 在 $(-2, +\infty)$ 上恒成立，利用基本不等式求解最值得 $a \leq 2\sqrt{3}$ ，即可得解：
>
> > [!note]- **【解析】**
> > $\forall x\in (-2, + \infty)$ ， $x^{2} + (4 - a)x + 7 - 2a$ 0恒成立，
> >
> > 即 $x^{2} + 4x + 7$ $a(x + 2)$ 在 $(-2, + \infty)$ 上恒成立，
> >
> > 所以 $a \leq \frac{x^2 + 4x + 7}{x + 2} = \frac{(x + 2)^2 + 3}{x + 2} = (x + 2) + \frac{3}{x + 2}$ 在 $(-2, +\infty)$ 上恒成立，
> >
> > 又 $(x+2)+\frac{3}{x+2}\quad2\sqrt{(x+2)\cdot\frac{3}{x+2}}=2\sqrt{3}$ ，当且仅当 $x+2=\frac{3}{x+2}$ ，即 $x=\sqrt{3}-2$ 时取等号，
> >
> > 所以 $a \leq 2\sqrt{3}$ ，则实数 $a$ 的最大值为 $2\sqrt{3}$
> >
> > 故选 **C**
