> [!faq]- 《专题06+函数解析式考点总结（六大题型）（高效培优期中专项训练）数学人教A版2019高一必修第一册》官方解析
>
> > [!success]- **【答案】** （1） $f(x) = -x - \frac{2}{x} - 2(x \neq 0)$ （2） $f(x) = \begin{cases} x^2 + x + 1, & x > 0 \\ 0, & x = 0 \\ -x^2 + x - 1, & x < 0 \end{cases}$
>
> > [!note]- **【分析】**
> > （1）在原式中用 $\frac{1}{x}$ 替换 $x$ ，得 $f\left(\frac{1}{x}\right) - 2f(x) = \frac{3}{x} +2$ ，与原式联立方程组，求解即可.
> >
> > (2) 设 $x < 0$ ，可得出 $-x > 0$ ，求出 $f(-x)$ 的表达式，利用奇函数的性质可得出函数 $f(x)$ 在 $x < 0$ 时的解析式。
>
> > [!note]- **【解析】**
> > 在 $f(x) - 2f\left(\frac{1}{x}\right) = 3x + 2$ 中用 $\frac{1}{x}$ 替换 $x$ ，得 $f\left(\frac{1}{x}\right) - 2f(x) = \frac{3}{x} + 2$ ，
> >
> > 于是有 $\left\{ \begin{array}{l} f\left(\frac{1}{x}\right) - 2f(x) = \frac{3}{x} + 2 \\ f(x) - 2f\left(\frac{1}{x}\right) = 3x + 2 \end{array} \right.$
> >
> > 消去 $f\left(\frac{1}{x}\right)$ ，得 $f(x) = -x - \frac{2}{x} - 2(x \neq 0)$
> >
> > ∴ 所求函数的表达式为 $f(x) = -x - \frac{2}{x} - 2 (x \neq 0)$
> >
> > (2) $\because$ 奇函数 $f(x)$ 的定义域为 $\mathbf{R},\therefore f(0) = 0$ 当 $x <   0$ 时， $-x > 0$ ，又当 $x > 0$ 时， $f(x) = x^{2} + x + 1$ $\therefore f(-x) = (-x)^{2} - x + 1 = x^{2} - x + 1$ $\therefore f(x) = -f(-x) = -x^2 +x - 1$ 故 $f(x) = \left\{ \begin{array}{l}x^{2} + x + 1,x > 0\\ 0,x = 0\\ -x^{2} + x - 1,x <   0 \end{array} \right.$
> >
> > 46. 函数 $f(x)$ 是 $\mathbf{R}$ 上的奇函数，且当 $x > 0$ 时，函数的解析式为 $f(x) = \frac{2x + 3}{x + 1}$ .
> >
> > (1)求 $f(2)$ ， $f(-2)$ 的值；
> >
> > (2)用定义证明 $f(x)$ 在 $(0, +\infty)$ 上是减函数；
> >
> > (3)求函数 $f(x)$ 的解析式.
> >
> > 【答案】(1) $f(2)=\frac{7}{3}$ ， $f(-2)=-\frac{7}{3}$
> >
> > (2)证明见解析
> >
> > (3) $f(x)=\left\{\begin{aligned}&\frac{2x+3}{x+1},&x>0\\ &0,x=0\\ &\frac{2x-3}{1-x},&x<0\end{aligned}\right.$
> >
> > 【分析】（1）先求 $f(2)$ ，然后结合奇函数定义可求 $f(-2)$ ；
> >
> > (2) 设 $0 < x_{1} < x_{2}$ ，然后利用作差法比较 $f(x_{1})$ 与 $f(x_{2})$ 的大小即可判断；
> >
> > (3) 由奇函数定义可知 $f(0) = 0$ . 设 $x < 0$ 时， $-x > 0$ ，根据已知函数式及奇函数定义即可求解
> >
> > 【详解】（1）因为 $x > 0$ 时， $f(x) = \frac{2x + 3}{x + 1}$ ，所以 $f(2) = \frac{2 \times 2 + 3}{2 + 1} = \frac{7}{3}$ .
> >
> > 因为 $f(x)$ 为 R 上的奇函数，所以 $f(-2) = -f(2) = -\frac{7}{3}$ .
> >
> > (2) 证明：因为 x > 0 时， $f(x) = \frac{2x + 3}{x + 1} = 2 + \frac{1}{x + 1}$
> >
> > $\forall x_{1}, x_{2} \in (0, +\infty)$ ，且 $x_{1} < x_{2}$
> >
> > $\therefore f(x_{1}) - f(x_{2}) = \frac{1}{1 + x_{1}} -\frac{1}{1 + x_{2}} = \frac{x_{2} - x_{1}}{(1 + x_{1})(1 + x_{2})}$
> >
> > 因为 $x_{1}$ ， $x_{2}\in (0, + \infty)$ ， $x_{1} <   x_{2}$ ，所以 $1 <   1 + x_1 <   1 + x_2$ ， $x_{2} - x_{1} > 0$
> >
> > 所以 $f(x_{1}) - f(x_{2}) > 0$ ，即 $f(x_{1}) > f(x_{2})$
> >
> > 所以 $f(x)$ 在 $(0, +\infty)$ 上是减函数.
> >
> > (3) 当 x = 0 时， $f(0) = 0$ ;
> >
> > 当 x < 0 时，-x > 0，则 $f(-x) = \frac{-2x + 3}{-x + 1} = -f(x)$ ，所以 $f(x) = \frac{2x - 3}{1 - x}$ .
> >
> > 综上， $f(x)=\left\{\begin{aligned}&\frac{2x+3}{x+1},&x>0\\ &0,x=0\\ &\frac{2x-3}{1-x},&x<0\end{aligned}\right.$
