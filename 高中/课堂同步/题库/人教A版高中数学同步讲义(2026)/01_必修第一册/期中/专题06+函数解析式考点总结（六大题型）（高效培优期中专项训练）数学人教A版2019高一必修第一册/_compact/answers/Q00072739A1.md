> [!faq]- 《专题06+函数解析式考点总结（六大题型）（高效培优期中专项训练）数学人教A版2019高一必修第一册》官方解析
>
> > [!success]- **【答案】** （1） $f(x)=x^{2}-1(x-1)$ ；（2） $f(x)=x^{2}-2x-1$
>
> > [!note]- **【分析】**
> > （1）法一，令 $\sqrt{x} + 1 = t, t - 1$ ，得到 $x = (t - 1)^2$ ，代入即可求解；法二，根据条件，通过配凑 $f(\sqrt{x} + 1) = (\sqrt{x} + 1)^2 -1$ ，即可求解；
> >
> > (2) 设 $f(x) = ax^2 + bx + c (a \neq 0)$ ，根据条件，建立方程 $\left\{ \begin{array}{l} 2a = 2 \\ 2b = -4 \\ 2a + 2c = 0 \end{array} \right.$ ，即可求解。
>
> > [!note]- **【解析】**
> > （1）法一，设 $\sqrt{x} + 1 = t, t - 1$ ，则 $\sqrt{x} = t - 1$ ，得到 $x = (t - 1)^2$
> >
> > 所以 $f(t) = (t - 1)^2 + 2(t - 1) = t^2 - 1$ ，故 $f(x) = x^2 - 1(x - 1)$ .
> >
> > 解法二：因为 $f(\sqrt{x} + 1) = x + 2\sqrt{x} = (\sqrt{x})^2 + 2\sqrt{x} + 1 - 1 = (\sqrt{x} + 1)^2 - 1$ ，
> >
> > 所以 $f(x)=x^{2}-1(x\quad1)$ .
> >
> > (2) 设 $f(x)=ax^{2}+bx+c(a\neq0)$
> >
> > 则 $f(x + 1) + f(x - 1) = a(x + 1)^2 +b(x + 1) + c + \left[a(x - 1)^2 +b(x - 1) + c\right] = 2ax^2 +2bx + (2a + 2c)$
> >
> > 又因为 $\forall x\in \mathbb{R},2ax^2 +2bx + (2a + 2c) = 2x^2 -4x$ 所以 $\left\{\begin{aligned}2a&=2\\ 2b&=-4\\ 2a+2c&=0\end{aligned}\right.$ ，解得 $\left\{\begin{aligned}a&=1\\ b&=-2\\ c&=-1\end{aligned}\right.$ 所以 $f(x)=x^{2}-2x-1$
