> [!faq]- 《专题11 对数函数考点大汇总（八大题型）（高效培优期中专项训练）数学人教A版2019高一必修第一册》官方解析
>
> > [!success]- **【答案】** (1) $a = 2$ ; $(-1,3)$ (2)2
>
> > [!note]- **【分析】**
> > （1）根据 $f(1) = 2$ 结合对数运算，即可求得 $a$ 的值；根据函数解析式列不等式组，即可求得函数定义域；
> >
> > (2) 判断函数在给定区间上的单调性，即可求得答案
>
> > [!note]- **【解析】**
> > （1）由题意知 $f(x) = \log_a(1 + x) + \log_a(3 - x)(a > 0, a \neq 1)$ ，且 $f(1) = 2$
> >
> > 故 $\log_a 2 + \log_a 2 = 2, \therefore \log_a 4 = 2$ ，则 $a^2 = 4$
> >
> > 而 a > 0 ，故 a = 2 ，
> >
> > 由 $\left\{ \begin{array}{l} 1 + x > 0 \\ 3 - x > 0 \end{array} \right.$ ，可得 $-1 < x < 3$ ，
> >
> > 故 $f(x)$ 的定义域为 $(-1,3)$ ;
> >
> > (2) 由 (1) 可得 $f(x) = \log_2(1 + x)(3 - x) = \log_2(-x^2 + 2x + 3)$
> >
> > 而 $y = -x^{2} + 2x + 3 = -(x - 1)^{2} + 4, x \in \left[0, \frac{3}{2}\right]$
> >
> > $y = -x^{2} + 2x + 3$ 在 $[0,1]$ 上单调递增，在 $\left(1,\frac{3}{2}\right]$ 上单调递减，
> >
> > 故当 x=1 时， $y=-\left(x-1\right)^{2}+4$ 取到最大值 $^{4}$ ，
> >
> > 函数 $y = \log_{2} x$ 为其定义域上的增函数，
> >
> > 故 $f(x) = \log_2\left(-x^2 + 2x + 3\right)$ 在 $[0,1]$ 上单调递增，在 $\left(1, \frac{3}{2}\right]$ 上单调递减，
> >
> > 故 $f(x) = \log_2\left(-x^2 + 2x + 3\right)$ 在区间 $\left[0, \frac{3}{2}\right]$ 上的最大值为 $f(1) = \log_24 = 2\cdot$
