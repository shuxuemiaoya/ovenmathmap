> [!faq]- 《专题11 对数函数考点大汇总（八大题型）（高效培优期中专项训练）数学人教A版2019高一必修第一册》官方解析
>
> > [!success]- **【答案】** C
>
> > [!note]- **【分析】**
> > 根据对数函数的性质判断 a 的范围，根据指数函数的性质判断 b 的范围，再化简 c 分析判断
>
> > [!note]- **【解析】**
> > 因为 $y = \log_{2} x$ 在 $(0, +\infty)$ 上递增，且 2 < 3 < 4
> >
> > 所以 $\log_{2}2<\log_{2}3<\log_{2}4$ ，即 1<a<2，
> >
> > 因为 $y = 2.7^{x}$ 在 R 上递增，且 -1.3 < 0，
> >
> > 所以 $0 < 2.7^{-1.3} < 2.7^0 = 1$ ，即 $0 < b < 1$
> >
> > 因为 $c = e^{0.5\ln9} = 3 > 2$ ，所以 c > 2，
> >
> > 所以 c > a > b
> >
> > 故选：C.
> >
