> [!faq]- 《专题11 对数函数考点大汇总（八大题型）（高效培优期中专项训练）数学人教A版2019高一必修第一册》官方解析
>
> > [!success]- **【答案】** (1)6 (2) $\left[-2,2\right]$ (3) $y = t^{2} + 3t + 2$ ; $f(x)_{\min} = -\frac{1}{4}$ , 此时 $x = \frac{\sqrt{3}}{9}$ ; $f(x)_{\max} = 12$ , 此时 $x = 9$ .
>
> > [!note]- **【分析】**
> > （ $^{1}$ ）根据函数解析式代入计算可得；
> >
> > (2) 因为 $t = \log_3 x$ ，利用对数函数的单调性求出实数 $t$ 的取值范围；
> >
> > （3）根据换元法将函数转化为二次函数，借助二次函数的单调性求出函数取得最大值、最小值，再得出对应的 $x$ 的值·
>
> > [!note]- **【解析】**
> > （1）由 $f(x) = \log_3(9x) \cdot \log_3(3x)$ 可得 $f(3) = \log_3 27 \cdot \log_3 9 = 3 \times 2 = 6$ ；
> >
> > (2) 因为 $t = \log_{3} x$ 在定义域内为单调递增函数，
> >
> > 又 $\frac{1}{9} \leq x \leq 9$ ，所以 $\log_3 \frac{1}{9} \leq t = \log_3 x \leq \log_3 9$ ，解得 $-2 \leq t \leq 2$ ；
> >
> > 所以实数 t 的取值范围为 $[-2,2]$ .
> >
> > (3) 由 $f(x) = \log_3(9x) \cdot \log_3(3x) = (\log_3 x + 2)(\log_3 x + 1)$
> >
> > $$
> > = \left(\log_ {3} x\right) ^ {2} + 3 \log_ {3} x + 2 = t ^ {2} + 3 t + 2
> > $$
> >
> > 令 $g(t) = t^2 + 3t + 2 = \left(t + \frac{3}{2}\right)^2 - \frac{1}{4}, t \in [-2, 2]$ ，
> >
> > 当 $t = -\frac{3}{2}$ 时， $g(t)_{\min} = -\frac{1}{4}$ ，此时 $\log_3 x = -\frac{3}{2}$ ，解得 $x = 3^{-\frac{3}{2}} = \frac{\sqrt{3}}{9}$ ；
> >
> > 所以 $f(x)_{\min} = -\frac{1}{4}$ ，此时 $x = \frac{\sqrt{3}}{9}$ ;
> >
> > 当 $t = 2$ 时， $g(t)_{\max} = 12$ ，此时 $\log_3 x = 2$ ，解得 $x = 3^2 = 9$ ；
> >
> > 所以 $f(x)_{\max}=12$ ，此时 x=9。
