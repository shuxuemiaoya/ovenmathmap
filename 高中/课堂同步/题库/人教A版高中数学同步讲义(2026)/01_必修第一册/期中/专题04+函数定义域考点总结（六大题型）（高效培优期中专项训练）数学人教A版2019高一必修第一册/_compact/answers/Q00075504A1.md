> [!faq]- 《专题04+函数定义域考点总结（六大题型）（高效培优期中专项训练）数学人教A版2019高一必修第一册》官方解析
>
> > [!success]- **【答案】** A．函数 $f(x) = x + 1$ 与 $g(x) = (\sqrt{x + 1})^2$ 是同一个函数 B．若函数 $f(x)$ 的定义域为 $(0,1]$ ，则函数 $f(x^2) - f(1 - x)$ 的定义域为 $(0,1)$ C．若函数 $f(x) = \sqrt{kx^2 + kx + 1}$ 的值域为 $[0, +\infty)$ ，则实数 $k$ 的取值范围是 $[4, +\infty)$ D．若函数 $f(x) = \frac{1}{\sqrt{kx^2 + kx + 1}}$ 的定义域为 $\mathbf{R}$ ，则实数 $k$ 的取值范围是 $[0,4]$
>
> > [!note]- **【分析】**
> > 对 A：求出两函数定义域即可得；对 B：由题意可得 $\left\{\begin{aligned}0&<x^{2}\leq1\\ 0&<1-x\leq1\end{aligned}\right.$ ，解出即可得；对 C：分 k=0 与 $k\neq0$ ，结合所给值域进行讨论即可得；对 D：分 k=0 与 $k\neq0$ ，结合所给定义域进行讨论即可得。
>
> > [!note]- **【解析】**
> > 对 $\mathsf{A}$ ： $f(x)$ 定义域为 $\mathbf{R}$ ， $g(x)$ 定义域为 $[-1, + \infty)$
> >
> > 故函数 $f(x) = x + 1$ 与 $g(x) = (\sqrt{x + 1})^2$ 不是同一个函数，故A错误；
> >
> > 对 $^{B}$ ：由 $f(x)$ 的定义域为 $(0,1]$ ，则对 $f(x^{2})-f(1-x)$ 有 $\left\{\begin{aligned}0&<x^{2}\leq1\\ 0&<1-x\leq1\end{aligned}\right.$
> >
> > 解得 $(0,1)$ ，故函数 $f(x^{2}) - f(1 - x)$ 的定义域为 $(0,1)$ ，故 $\mathsf{B}$ 正确；
> >
> > 对 C：当 k=0 时， $f(x)=\sqrt{kx^{2}+kx+1}=1$ ，不符；
> >
> > 当 $k \neq 0$ 时，则有 $\left\{ \begin{array}{ll} k > 0 \\ \Delta = k^2 - 4k & 0 \end{array} \right.$ ，解得 $k = 4$ ；
> >
> > 故实数 $k$ 的取值范围是 $\left[4, +\infty\right)$ ，故 $C$ 正确；
> >
> > 对D：当 $k = 0$ 时， $f(x) = \frac{1}{\sqrt{kx^2 + kx + 1}} = 1$ ，其定义域为 $\mathbf{R}$ ，符合要求；
> >
> > 当 $k \neq 0$ 时，则有 $\left\{ \begin{array}{l} k > 0 \\ \Delta = k^2 - 4k < 0 \end{array} \right.$ ，解得 $0 < k < 4$ ；
> >
> > 故实数 k 的取值范围是 $[0,4)$ ，故 D 错误.
> >
> > 故选 **BC**.
