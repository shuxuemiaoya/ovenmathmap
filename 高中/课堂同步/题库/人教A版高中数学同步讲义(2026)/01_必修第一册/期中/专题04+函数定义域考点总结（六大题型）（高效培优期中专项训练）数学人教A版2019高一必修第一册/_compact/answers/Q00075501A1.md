> [!faq]- 《专题04+函数定义域考点总结（六大题型）（高效培优期中专项训练）数学人教A版2019高一必修第一册》官方解析
>
> > [!success]- **【答案】** A．若函数 $y = f(x + 1)$ 的定义域是 $[-2, 3]$ ，则 $y = f(2x - 1)$ 的定义域是 $\left[-\frac{1}{2}, 2\right]$ B．已知 2 < a < 3, -2 < b < -1，则 $\frac{a}{b}$ 的取值范围是 $(-3, -1)$ C． $f(x)=x+1$ 与 $g(x)=x+x^{0}$ 不是同一个函数 D．已知 x>0,y>0，且 $x-y+xy=3$ ，则 $x+y$ 的最小值为 $2\sqrt{2}$
>
> > [!note]- **【分析】**
> > 根据抽象函数定义域求法判断 $^{A}$ ，根据不等式的性质判断 $^{B}$ ，根据函数定义域以及对应关系判断 $^{C}$ ，利用基本不等式判断 $^{D}$ .
>
> > [!note]- **【解析】**
> > 对于 A，因为函数 $y = f(x + 1)$ 的定义域是 $[-2, 3]$ ，则 $-1 \leq x + 1 \leq 4$ 。
> >
> > 令 $-1 \leq 2x - 1 \leq 4$ ，解得 $0 \leq x \leq \frac{5}{2}$ ，即 $y = f(2x - 1)$ 的定义域是 $\left[0, \frac{5}{2}\right]$ ，故 $\mathsf{A}$ 错误；
> >
> > 对于 $^{B}$ ，因为 2 < a < 3，-2 < b < -1，所以 $-1 < \frac{1}{b} < -\frac{1}{2}$ ，则 $\frac{1}{2} < -\frac{1}{b} < 1$ ，
> >
> > 所以 $1 < -\frac{a}{b} < 3$ ，所以 $-3 < \frac{a}{b} < -1$ ，所以 $\frac{a}{b}$ 的取值范围是 $(-3, -1)$ ，故 ${}^{\mathrm{B}}$ 正确；
> >
> > 对于 C， $f(x)=x+1$ 的定义域为 R， $g(x)=x+x^{0}$ 的定义域为 $(-∞,0)∪(0,+∞)$ ，故 C 正确；
> >
> > 对于 D，因为 $x - y + xy = 3$ ，所以 $x(1 + y) = 3 + y$ ，则 $x = \frac{3 + y}{1 + y}$ ，所以 $x + y = \frac{3 + y}{1 + y} + y = \frac{2}{1 + y} + 1 + y \quad 2\sqrt{\frac{2}{1 + y} \cdot (1 + y)} = 2\sqrt{2}$ 当且仅当 $\frac{2}{1+y}=1+y,y=\sqrt{2}-1,x=\sqrt{2}+1$ 时取等号，故D正确，
> >
> > 故选 **BCD**.
