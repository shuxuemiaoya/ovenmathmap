>
> > [!success]- **【答案】** B
>
> > [!note]- **【分析】**
> > 根据函数的定义域以及对应关系是否相等，即可结合选项逐一求解·
>
> > [!note]- **【解析】**
> > 对于 $\mathsf{A}$ ， $f(x) = \sqrt{x^2}$ 的定义域为 $\mathbb{R}$ ， $g(x) = (\sqrt{x})^2$ 的定义域为 $[0, +\infty)$ ，两个函数的定义域不相同，故不是同一个函数， $^{\mathsf{A}}$ 错误，
> >
> > 对于 B， $f(t)=t$ ， $g(x)=\sqrt[3]{x^{3}}=x$ ，两个函数相同，故 B 正确，
> >
> > 对于 C, $f(n)=2n-1(n\in\mathbb{N})$ 与 $g(n)=2n+1(n\in\mathbb{N})$ 的对应关系不相等，故不是同一个函数，C 错误，
> > 对于 D, $f(x)=\frac{x^{2}-1}{x+1}$ 的定义域为 $\left\{x\mid x\neq-1\right\}$ ， $g(x)=x-1$ 的定义域为 R，两个函数的定义域不相等，
> > 故不是同一个函数，D 错误，
> >
> > 故选：B

> > 4. 函数 $f(x) = \sqrt{\frac{4 - x}{2x + 3}}$ 的定义域为（）
> >
> > 【答案】
> >
> > A. $\{x \leq -\frac{3}{2} \text{或 } x, 4\}$ B. $\{x < -\frac{3}{2} \text{或 } x, 4\}$ C. $\left\{x \mid -\frac{3}{2} < x \leq 4\right\}$ D. $\left\{x \mid -\frac{3}{2} \leq x \leq 4\right\}$
> >
> > 【答案】C
> >
> > 【分析】根据二次根号下非负结合分式不等式的解法可求函数的定义域·
> >
> > 【详解】由 $\frac{4-x}{2x+3}$ 0，可得 $(4-x)(2x+3)$ $0(2x+3\neq0)$
> >
> > 即 $(x - 4)(2x + 3) \leq 0(2x + 3 \neq 0)$ ，解得 $-\frac{3}{2} < x \leq 4$
> >
> > 即函数 $f(x)$ 的定义域为 $\left\{x\mid -\frac{3}{2} < x\leq 4\right\}$
> >
> > 故选：C.
> >
> > 5. 函数 $f(x) = \frac{\sqrt{x - 1}}{x - 2}$ 的定义域为（）
> >
> > 【答案】
> > A. [1,2)∪(2,+∞) B. (1,+∞) C. [1,2) D. [1,+∞)
> >
> > 【答案】A
> >
> > 【分析】根据分式和根式求 $x$ 的范围即可·
> >
> > 【详解】因为函数 $f(x) = \frac{\sqrt{x - 1}}{x - 2}$ ，要使得函数有意义，
> >
> > 则 $x - 1$ 0且 $x - 2\neq 0$
> >
> > 解得 $x$ 1且 $x \neq 2$ .
> >
> > 所以该函数的定义域为 $[1,2)\cup (2, + \infty)$
> >
> > 故选 **A**.
