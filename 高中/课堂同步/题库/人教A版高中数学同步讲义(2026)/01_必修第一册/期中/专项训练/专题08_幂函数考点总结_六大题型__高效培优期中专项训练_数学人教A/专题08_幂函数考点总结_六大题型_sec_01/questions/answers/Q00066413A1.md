> >
> > 所以 $4^{\frac{1}{m^{2}+m}}=2=4^{\frac{1}{2}}$ ，所以 $(m^{2}+m)^{-1}=\frac{1}{2}$ ，
> >
> > 所以 $m^2 + m = 2$ ，解得 $m = 1$ 或 $m = -2$ ，又 $m \in \mathbf{N}^*$ ，所以 $m = 1$

> > ## 考点03 求与幂函数综合值域
> >
> > 21. 函数 $f(x) = \frac{2x - 1}{x + 1}$ 图象的对称中心坐标是 \_\_\_\_；函数 $f(x) = \frac{2x^2 - 1}{x^2 + 1}$ 的值域是 \_\_\_\_.
> > 【答案】 $(-1, 2)$ $[-1, 2)$
> >
> > 【分析】将函数解析式变形为 $f(x) = 2 + \frac{-3}{x + 1}$ ，结合图象的平移得到其对称中心；又
> >
> > $f(x)=\frac{2x^{2}-1}{x^{2}+1}=2+\frac{-3}{x^{2}+1}$ ，结合不等式的性质求出函数的值域.
> >
> > 【详解】因为 $f(x)=\frac{2x-1}{x+1}=\frac{2(x+1)-3}{x+1}=2+\frac{-3}{x+1}$
> >
> > 将奇函数 $y = \frac{-3}{x}$ 图象向左平移1个单位，再向上平移2个单位得到 $f(x)$ 图象，
> >
> > 所以 $f(x)$ 图象的对称中心为 $(-1,2)$ ;
> >
> > $f(x) = \frac{2x^2 - 1}{x^2 + 1} = \frac{2(x^2 + 1) - 3}{x^2 + 1} = 2 + \frac{-3}{x^2 + 1}$ ，因为 $x^2 + 1 \leq 1$ ，所以 $0 < \frac{1}{x^2 + 1} \leq 1$ ，
> >
> > 则 $-3 \leq \frac{-3}{x^2 + 1} < 0$ ，所以 $f(x) \in [-1, 2)$ .
> >
> > 故答案为： $(-1,2)$ ; $[-1,2)$
