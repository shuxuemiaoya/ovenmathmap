## 九．集合交并补混合关系的应用（共2小题）

17．已知全集 $U = \{0,1,2,4\}$ ，集合 $M = \{0,4\}$ ， $\breve{\partial}_{U} N = \{0,2\}$ ，则 $M \cap N = (\quad)$ A. $\{1,4\}$ B. $\{0,4\}$ C. $\{0,1,4\}$ D. $\{4\}$

【答案】D

【分析】根据集合交集、补集的概念求解即可.

【详解】因为全集 $U=\left\{0,1,2,4\right\}$ ， $\tilde{\Omega}_{U}N=\left\{0,2\right\}$ ，所以 $N=\left\{1,4\right\}$

又 $M = \{0,4\}$ ，所以 $M\cap N = \{4\}$

故选：D

18. 已知 $A = \{x | x \rangle 1\}$ , $B = \{x | 0 \leq x \leq 2\}$

(1)求 $A \cap B$ 、 $A \cup B$ 、 $\left(\check{\mathfrak{Q}}_{\mathbf{R}} A\right) \cap B$

(2)设 $C = \{x\mid x\in (A\cup B)$ 且 $x\notin (A\cap B)\}$ ，求集合 $C$

【答案】(1) $A \cap B = \{x \mid 1 < x \leq 2\}$ ， $A \cup B = \{x \mid x - 0\}$ ， $\left(\tilde{\mathfrak{Q}}_{\mathbf{R}} A\right) \cap B = \{x \mid 0 \leq x \leq 1\}$

$C = \{x\mid 0\leq x\leq 1\quad x > 2\}$ (2) 或

【分析】（1）根据交、并、补集的运算计算即可；

(2) 结合 (1)，根据题意计算即可.

【详解】（1）因为 $A=\left\{x \mid x>1\right\}$ ， $B=\left\{x \mid 0 \leq x \leq 2\right\}$ ，

所以 $A \cap B = \{x \mid 1 < x \leq 2\}$ ， $A \cup B = \{x \mid x, 0\}$ ， $(\tilde{\mathbf{Q}}_{\mathbf{R}} A) \cap B = \{x \mid 0 \leq x \leq 1\}$ (2) 因为 $A \cap B = \{x \mid 1 < x \leq 2\}$ ， $A \cup B = \{x \mid x, 0\}$ ，
所以 $C = \{x \mid 0 \leq x \leq 1 \text{ 或 } x > 2\}$ .
