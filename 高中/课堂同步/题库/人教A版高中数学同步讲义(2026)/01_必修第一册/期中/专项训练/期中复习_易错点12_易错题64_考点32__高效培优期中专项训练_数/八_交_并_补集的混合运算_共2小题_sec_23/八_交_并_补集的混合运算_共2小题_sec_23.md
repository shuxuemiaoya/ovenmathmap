15. 已知全集 $U = \{2,3,4,5,6,7,8\}, A,B$ 是 $U$ 的两个子集，且 $A \cap B = \{5\}, A \cap (\mathfrak{Q}_U B) = \{2,3,6\}$ ，则 $(\mathfrak{Q}_U A) \cup B =$ ( )

【答案】
A. $\{4,7,8\}$ B. $\{4,5,7,8\}$ C. $\{2,3,5,6\}$ D. $\{3,5,6\}$

【答案】B

【分析】根据题意分析可知 $A=\{2,3,5,6\}$ ，再结合补集和并集运算求解.

【详解】因为 $A \cap B = \{5\}, A \cap (\tilde{\mathfrak{Q}}_U B) = \{2, 3, 6\}$ ，可知 $A = \{2, 3, 5, 6\}, \tilde{\mathfrak{Q}}_U A = \{4, 7, 8\}$

且 $5 \in B, 2 \notin B, 3 \notin B, 6 \notin B$ ，所以 $\left(\check{\mathfrak{Q}}_U A\right) \cup B = \{4, 5, 7, 8\}$ .

故选：B.

围.

【答案】(1) $A \cup B = \{x \mid x < -1 \text{ 或 } x > 7\}$ ; $A \cap \tilde{\mathbf{Q}}_{\mathrm{R}} B = \{x \mid x < -1 \text{ 或 } x \quad 9\}$ .

$$

【分析】（1）首先解二次不等式求得集合A，然后将 $a$ 代入确定集合 $B$ ，最后根据集合的交、并、补运算

(2) 首先根据集合间运算的结果可得 $B \subseteq A$ ，然后分 $B = \emptyset$ 和 $B \neq \emptyset$ 两种情况分类讨论求解参数取值范围
