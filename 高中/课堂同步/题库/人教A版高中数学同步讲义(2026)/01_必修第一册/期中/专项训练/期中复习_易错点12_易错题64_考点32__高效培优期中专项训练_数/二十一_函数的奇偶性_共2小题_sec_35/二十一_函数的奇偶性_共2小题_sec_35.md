## 二十一．函数的奇偶性（共2小题）

41. 设函数 $f(x) = \frac{2x + 1}{x - 1}$ ，则下列函数中为奇函数的是（）

【答案】
A. $f(x + 1) + 2$ B. $f(x - 1) + 2$ C. $f(x + 1) - 2$ D. $f(x - 1) - 2$

【答案】C

【分析】由 $f(x) = 2 + \frac{3}{x - 1}$ ，写出各项对应函数的解析式，利用函数奇偶性的定义依次判断各项对应函数

的奇偶性.

【详解】因为 $f(x)=\frac{2x+1}{x-1}=\frac{2x-2+3}{x-1}=2+\frac{3}{x-1}$ ，

A: $f(x + 1) + 2 = 4 + \frac{3}{x}$ ，而 $4 + \frac{3}{-x} = 4 - \frac{3}{x} \neq -4 - \frac{3}{x}$ ，显然不是奇函数，不符；

B： $f(x - 1) + 2 = 4 + \frac{3}{x - 2}$ ，定义域为 $\{x\mid x\neq 2\}$ ，显然不关于原点对称，不符；

C: $f(x + 1) - 2 = \frac{3}{x}$ ，其中 $\frac{3}{-x} = -\frac{3}{x}$ 且定义域为 $\{x \mid x \neq 0\}$ ，易知 $f(x + 1) - 2$ 为奇函数；

D： $f(x - 1) - 2 = \frac{3}{x - 2}$ ，定义域为 $\{x\mid x\neq 2\}$ ，显然不关于原点对称，不符；

故选：C

42. 已知函数 $f(x) = x|x| - 2x$ ，那么不等式 $2f(x) + f(-x) < 0$ 的解集为（）

【答案】
A. $(-2,2)$ B. $(-∞,-1)∪(0,1)$ C. $(-∞,-2)∪(0,2)$ D. $(-2,0)∪(0,2)$

【答案】C

【分析】先分析出 $f(x)$ 的奇偶性，然后化简不等式并通过分类讨论求解出不等式解集.

【详解】因为 $f(x)$ 的定义域为 R 关于原点对称，

$$
f (- x) = - x | - x | - 2 (- x) = - x | x | + 2 x = - f (x)
$$

所以 $f(x)$ 为奇函数，

所以 $2f(x) + f(-x) < 0 \Leftrightarrow 2f(x) - f(x) < 0 \Leftrightarrow f(x) < 0$

当 x > 0 时， $x^{2} - 2x < 0$ ，解得 0 < x < 2，

当 $x = 0$ 时， $0 < 0$ ，无解，

当 $x < 0$ 时， $-x^{2} - 2x < 0$ ，解得 $x < -2$ 或 $x > 0$ （舍），

综上所述，不等式解集为 $(-∞,-2)∪(0,2)$ ，

故选：C

二十二．奇函数偶函数的判断（共2小题）

43. 已知函数 $f(x) = \frac{2^x + a \cdot 2^{-x}}{x^2}$ ，且 $f(1) = \frac{3}{2}$ .

(1)求 $a$ 的值；

(2) 判断函数 $f(x)$ 的奇偶性.

【答案】(1) $a = -1$

(2) $f(x)$ 为奇函数.

【分析】（1）将 $f(1) = \frac{3}{2}$ 代入 $f(x) = \frac{2^x + a \cdot 2^{-x}}{x^2}$ ，解出 $a$ 的值.

(2) 按照定义法证明奇偶性的步骤，先判断定义域是否关于原点对称，再判断 $f(-x)$ 与 $f(x)$ 的关系即可.

【详解】（1）由已知可得， $f(1)=2+\frac{1}{2}a=\frac{3}{2}$ ，解得：a=-1

(2) 由 (1) 知， $f(x)=\frac{2^{x}-2^{-x}}{x^{2}}$ ，定义域为 $\{x \mid x \neq 0\}$ 关于原点对称，
又 $f(-x)=\frac{2^{-x}-2^{x}}{x^{2}}=-f(x)$ ，所以 $f(x)$ 为奇函数.

44. 已知函数 $f(x)$ 的定义域为 $\mathbf{R}$ ，满足 $f(x + y) - [f(x) + f(y)] = 2023$ ，则下列说法正确的是（）A. $f(x)$ 是偶函数 B. $f(x)$ 是奇函数 C. $f(x) + 2023$ 是偶函数 D. $f(x) + 2023$ 是奇函数

【答案】D

【分析】通过对 $x, y$ 的赋值，结合奇函数、偶函数的定义逐项判断.

【详解】在函数 $f(x)$ 中， $f(x+y)-[f(x)+f(y)]=2023$ ，

当 $x = y = 0$ 时， $f(0) - [f(0) + f(0)] = 2023$ ，解得 $f(0) = -2023$

若函数 $f(x)$ 是 R 上的奇函数，则该函数的图象必过原点，即有 $f(0)=0$ ，B 错误；

当 $y = -x$ 时， $f(0) - [f(x) + f(-x)] = 2023$ ，解得 $f(x) + f(-x) = -4046$

无法得到 $f(x)=f(-x)$ ，A 错误；

在函数 $f(x) + 2023$ 中，由上可知， $f(x) + 2023 + f(-x) + 2023 = 0$ ，且 $f(x) + 2023$ 不一定恒为零，

因此 $f(x)+2023$ 是奇函数，C 错误，D 正确.

故选：D
