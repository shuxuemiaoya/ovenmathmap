## 二十．函数的最值（共2小题）

39. 已知函数 $f(x) = \begin{cases} -\frac{1}{x} + 2, & x < c \\ x^2 - 2x + 3, & c \leq x \leq 3 \end{cases}$ ，若 $f(x)$ 的值域为[2,6]，则实数 $c$ 的取值范围（）A. $[-1, -\frac{1}{4}]$ B. $[- \frac{1}{4}, 0)$ C. $[-1, 0)$ D. $[-1, -\frac{1}{2}]$

【答案】A

【分析】首先分析函数 $y = x^{2} - 2x + 3$ 的取值情况，从而判断 $c \leq 1$ ，再结合 $c^2 - 2c + 3 \leq 6$ 得到 $-1 \leq c \leq 1$ ，再分 $0 \leq c \leq 1$ 和 $-1 \leq c < 0$ 两种情况讨论，当 $-1 \leq c < 0$ 时结合函数 $y = -\frac{1}{x} + 2$ 在 $(-\infty, c)$ 上的单调性，得到 $-\frac{1}{c} + 2 \leq 6$ ，从而求出 $c$ 的取值范围.

【详解】对于函数 $y = x^{2} - 2x + 3 = (x - 1)^{2} + 2$ ，当 x = 3 时，y = 6，当 x = 1 时，y = 2，
而 $-\frac{1}{x} \neq 0$ ，即有 $-\frac{1}{x} + 2 \neq 2$ ，依题意， $c \leq 1$ ，又 $c^{2} - 2c + 3 \leq 6$ ，解得 $-1 \leq c \leq 3$ ，则 $-1 \leq c \leq 1$ ；
当 $0 \leq c \leq 1$ 时，函数 $f(x)$ 在 $(-∞,0)$ 上的取值集合为 $(2,+∞)$ ，不符合题意，
当 $-1 \leq c < 0$ ，函数 $y = -\frac{1}{x} + 2$ 在 $(-∞,c)$ 上单调递增，
则 $2 < -\frac{1}{x} + 2 < -\frac{1}{c} + 2$ ，所以 $\left\{\begin{aligned}-\frac{1}{c}+2&\leq6\\-1&\leq c<0\end{aligned}\right.$ ，解得 $-1 \leq c \leq -\frac{1}{4}$ ，
所以实数 c 的取值范围是 $[-1, -\frac{1}{4}]$ .

故选：A

40. 设函数 $f(x) = \begin{cases} -x + a, & x \leq 1 \\ -a(x - 2)^2 + 1, & x > 1 \end{cases}$ ，若 $a = 2$ ，则 $f(x)$ 的单调递增区间是 \_\_\_\_，若 $f(x)$ 的值域为 $(-\infty, +\infty)$ ，则 $a$ 的取值范围是 \_\_\_\_。

【答案】 $(1,2)$ $0 <   a\leq 2$

【分析】将 $a = 2$ 代入 $f(x)$ 解析式，分析各段单调性，即可得出单调区间；先求出 $(- \infty, 1]$ 上的值域，由 $f(x)$ 的值域为 $(- \infty, +\infty)$ ，只需 $y = -a(x - 2)^2 + 1$ 在 $(1, +\infty)$ 上的值域包含 $(- \infty, a - 1)$ ，分析二次函数的开口方

向，对称轴及值域即可求出 $a$ 的取值范围.

【详解】由题知当 $a = 2$ 时， $f(x) = \begin{cases} -x + 2, & x \leq 1 \\ -2(x - 2)^2 + 1, & x > 1 \end{cases}$ ，

故 $f(x)$ 在 $(- \infty, 1]$ 上单调递减，在 $(1,2)$ 上单调递增，在 $[2, +\infty)$ 上单调递减，

故 $f(x)$ 的单调递增区间是 $(1,2)$ ;

由于 $y = -x + a$ 在 $\left(-\infty, 1\right]$ 上的值域为 $[a - 1, +\infty)$

若 $f(x)$ 的值域为 $(-\infty, +\infty)$

只需 $y = -a(x - 2)^{2} + 1$ 在 $(1, +\infty)$ 上的值域包含 $(-∞, a - 1)$ 即可，

故需 -a < 0 ，即 a > 0 ，

此时 $y = -a(x - 2)^{2} + 1$ 在 $(1, +\infty)$ 上的值域为 $(- \infty, 1]$

故需 $a-1 \leq 1$ ，即 $0 < a \leq 2$ ，

综上： $0 < a \leq 2$

故答案为： $(1,2)$ ； $0 < a \leq 2$
