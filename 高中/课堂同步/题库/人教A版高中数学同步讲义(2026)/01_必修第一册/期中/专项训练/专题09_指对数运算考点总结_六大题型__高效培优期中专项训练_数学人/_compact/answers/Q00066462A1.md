> [!faq]- 《专题09_指对数运算考点总结_六大题型__高效培优期中专项训练_数学人》官方解析
>
> > [!success]- **【答案】** $(1)$ $^{1}$ ; $(2)$ 65
>
> > [!note]- **【分析】**
> > 根据指数幂的运算法则，进行化简计算即可；
>
> > [!note]- **【解析】**
> > （1） $\left(2\frac{1}{4}\right)^{0.5} - 0.75^2 +6^{-2}\times \left(\frac{8}{27}\right)^{-\frac{2}{3}}$ $= \left(\frac{9}{4}\right)^{\frac{1}{2}} - \left(\frac{3}{4}\right)^{2} + \frac{1}{36}\times \left(\frac{2}{3}\right)^{3\times \left(-\frac{2}{3}\right)}$ $= \frac{3}{2} -\frac{9}{16} +\frac{1}{36}\times \frac{9}{4}$ $= 1.$
> >
> > (2) 因为 $a^{\frac{1}{2}} + a^{-\frac{1}{2}} = 3$ ,
> >
> > 所以 $a + a^{-1} = \left(a^{\frac{1}{2}} + a^{-\frac{1}{2}}\right)^2 - 2 = 7$
> >
> > 所以 $a^2 + a^{-2} = (a + a^{-1})^2 - 2 = 47$
> >
> > 所以 $\frac{a^3 + a^{-3} + 3}{a + a^{-1} - 2} = \frac{(a + a^{-1})(a^2 + a^{-2} - 1) + 3}{a + a^{-1} - 2} = \frac{7\times 46 + 3}{7 - 2} = 65$
