> [!faq]- 《专题09_指对数运算考点总结_六大题型__高效培优期中专项训练_数学人》官方解析
>
> > [!success]- **【答案】** $(1)\frac{22}{9}$ ; $(2)^{6}$
>
> > [!note]- **【分析】**
> > （1）利用根式与分数指数幂的转化和分数指数幂的运算公式化简计算即得；
> >
> > (2) 由条件等式求得 $a + a^{-1}$ 和 $a^2 + a^{-2}$ ，再代入计算即得
>
> > [!note]- **【解析】**
> > （1） $(2\frac{7}{9})^{0.5} + (\frac{27}{64})^{-\frac{2}{3}} - (\sqrt{8})^{\frac{2}{3}} + (\frac{2}{3})^{0}$ $= \left(\frac{5}{3}\right)^{2\times 0.5} + \left(\frac{3}{4}\right)^{3\times (-\frac{2}{3})} - \left(2^{\frac{3}{2}}\right)^{\frac{2}{3}} + 1$ $= \frac{5}{3} +\left(\frac{4}{3}\right)^{2} - 2 + 1 = \frac{22}{9};$
> >
> > (2) 由 $a^{\frac{1}{2}} + a^{-\frac{1}{2}} = 3$ 两边取平方， $a + 2 + a^{-1} = 9$ ，即得 $a + a^{-1} = 7$ ，再两边取平方，可得 $a^2 + 2 + a^{-2} = 49$ ，即得 $a^2 + a^{-2} = 47$ 。故 $\frac{a^2 + a^{-2} + 1}{a + a^{-1} + 1} = \frac{47 + 1}{7 + 1} = 6$ .
