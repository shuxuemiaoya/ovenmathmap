> [!faq]- 《专题09_指对数运算考点总结_六大题型__高效培优期中专项训练_数学人》官方解析
>
> > [!success]- **【答案】** A．若函数 $f(\sqrt{x}+1)=x+2\sqrt{x}$ ，则 $f(1)=0$ B．若函数 $f(x+1)$ 的定义域为 $[-1,1]$ ，则函数 $f(x)$ 的定义域为 $[-2,0]$ C． $2^{m}=9^{n}=6$ ，则 $\frac{1}{m}+\frac{1}{2n}=1$ D．已知 $a > 0, b > 0, a + b = 1$ ，则 $\frac{a}{b} + \frac{1}{a}$ 的最小值为3
>
> > [!note]- **【分析】**
> > 令 x=0 ，计算可判断 $^{A}$ ；求得函数 $f(x)$ 的定义域判断 $^{B}$ ；求得 $m=\log_{2}6, n=\log_{9}6$ ，代入 $\frac{1}{m}+\frac{1}{2n}$ 计算可判断 $^{C}$ ；利用 $^{1}$ 的代换可求最小值判断 $^{D}$ .
>
> > [!note]- **【解析】**
> > 对于 A，令 x=0 ，可得 $f(\sqrt{0}+1)=0+2\sqrt{0}$ ，解得 $f(1)=0$ ，故 A 正确；
> >
> > 对于 B，因为函数 $f(x+1)$ 的定义域为 $[-1,1]$ ，
> >
> > 则 $-1 \leq x \leq 1$ ，所以 $0 \leq x + 1 \leq 2$
> >
> > 所以函数 $f(x)$ 的定义域为 $[0,2]$ ，故 $\mathsf{B}$ 错误；
> >
> > 对于 C，因为 $2^{m}=9^{n}=6$ ，所以 $m=\log_{2}6, n=\log_{9}6$
> >
> > 所以 $\frac{1}{m} +\frac{1}{2n} = \frac{1}{\log_26} +\frac{1}{2\log_96} = \log_62 + \frac{1}{2}\log_69 = \log_62 + \frac{1}{2}\log_63^2$
> >
> > $=\log_{6}2+\log_{6}3=\log_{6}(2\times3)=1$ ，故 C 正确；
> >
> > 对于 D， $\frac{a}{b}+\frac{1}{a}=\frac{a}{b}+\frac{a+b}{a}=\frac{a}{b}+\frac{b}{a}+1$ $2\sqrt{\frac{a}{b}\times\frac{b}{a}}+1=3$
> >
> > 当且仅当 $\frac{a}{b} = \frac{b}{a}$ ，即 $a = b = \frac{1}{2}$ 时取等号，
> >
> > 所以 $\frac{a}{b} +\frac{1}{a}$ 的最小值为3，故D正确·
> >
> > 故选 **ACD**.
