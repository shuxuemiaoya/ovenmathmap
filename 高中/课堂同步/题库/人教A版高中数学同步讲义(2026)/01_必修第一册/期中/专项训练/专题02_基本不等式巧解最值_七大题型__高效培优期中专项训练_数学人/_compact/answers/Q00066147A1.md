> [!faq]- 《专题02_基本不等式巧解最值_七大题型__高效培优期中专项训练_数学人》官方解析
>
> > [!success]- **【答案】** AC
>
> > [!note]- **【分析】**
> > 对于选项 $^{A}$ ，直接根据基本不等式可求得结果；
> > 对于选项 $^{B}$ ，化为积为定值的形式后，根据基本不等式求出最小值可得答案；
> > 对于选项 $^{C}$ ，变形后利用二次函数求出最小值可得答案；
> > 对于选项 $^{D}$ ，变形后利用基本不等式求出最小值可得答案·
>
> > [!note]- **【解析】**
> > 对于选项 A， $ab \leq \left(\frac{a+b}{2}\right)^{2} = \frac{1}{4}$ ，当且仅当 $a = b = \frac{1}{2}$ 时取“=”，故 A 正确；
> > 对于选项 B， $\frac{b}{a}+\frac{2}{b}=\frac{b}{a}+\frac{2a+2b}{b}=\frac{b}{a}+\frac{2a}{b}+2\quad2\sqrt{2}+2$ 当且仅当 $b = \sqrt{2}a = 2 - \sqrt{2}$ 时取“=”，故 B 错误；
> > 对于选项 C， $\left(a^{2}+\frac{1}{5}\right)\left(b^{2}+\frac{1}{5}\right)=\left(ab\right)^{2}+\frac{a^{2}+b^{2}}{5}+\frac{1}{25}$ $=(ab)^{2}+\frac{1}{5}(a+b)^{2}-\frac{2}{5}ab+\frac{1}{25}=\left(ab-\frac{1}{5}\right)^{2}+\frac{1}{5}\quad\frac{1}{5}$
> >
> > 当且仅当 $ab = \frac{1}{5}$ 时取“=”，故C正确；
> >
> > 对于选项D， $\frac{a^2}{a + 2} +\frac{b^2}{b + 1} = \frac{(a + 2 - 2)^2}{a + 2} +\frac{(b + 1 - 1)^2}{b + 1}$
> >
> > $$
> > = a + 2 - 4 + \frac {4}{a + 2} + b + 1 - 2 + \frac {1}{b + 1}
> > $$
> >
> > $$
> > = \frac {4}{a + 2} + \frac {1}{b + 1} - 2
> > $$
> >
> > 令 $s = a + 2$ ， $t = b + 1$
> >
> > 则 $s + t = 4$ ，所以 $\frac{4}{a + 2} +\frac{1}{b + 1} = \frac{1}{4}\left(\frac{4}{s} +\frac{1}{t}\right)(s + t) = \frac{1}{4}\left(4 + \frac{4t}{s} +\frac{s}{t} +1\right)$
> >
> > $\frac{1}{4}\left(5 + 2\sqrt{\frac{4t}{s} \cdot \frac{s}{t}}\right) = \frac{9}{4}$ ，
> >
> > 当且仅当 $s = 2t$ ，即 $t = \frac{4}{3}$ ， $s = \frac{8}{3}$ 时取“=”，
> >
> > 所以 $\frac{4}{a + 2} +\frac{1}{b + 1} -2\quad \frac{9}{4} -2 = \frac{1}{4}$
> >
> > 所以 $\frac{a^2}{a + 2} +\frac{b^2}{b + 1}$ $\frac{1}{4}$ ，当且仅当 $a = \frac{2}{3}$ ， $b = \frac{1}{3}$ 时取“=”
> >
> > 故选项 D 错误·
> >
> > 故选 **AC**.
