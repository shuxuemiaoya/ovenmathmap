> [!faq]- 《专题02_基本不等式巧解最值_七大题型__高效培优期中专项训练_数学人》官方解析
>
> > [!success]- **【答案】** AD
>
> > [!note]- **【分析】**
> > 对条件进行变形，利用不等式的基本性质对选项一一分析即可
>
> > [!note]- **【解析】**
> > 对于选项A，由 $16=ab+2a+b$ ，得 $b=\frac{16-2a}{a+1}=\frac{18}{a+1}-2$
> >
> > 所以 $2a + b = 2a + \frac{18}{a + 1} -2 = 2(a + 1) + \frac{18}{a + 1} -4\quad 2\sqrt{2(a + 1)\cdot\frac{18}{a + 1}} -4 = 8$
> >
> > 当且仅当 $2(a + 1) = \frac{18}{a + 1}$ ，即 $a = 2, b = 4$ 时取等号，所以选项 $\mathsf{A}$ 正确，
> >
> > 对于选项 $^{B}$ ，因为 $ab + 2a + b = 16$ ，所以 $\frac{1}{a + 1} + \frac{1}{b + 2}$ ， $2\sqrt{\frac{1}{a + 1} \cdot \frac{1}{b + 2}} = 2\sqrt{\frac{1}{ab + 2a + b + 2}} = \frac{\sqrt{2}}{3}$ ，
> >
> > 当且仅当 $a + 1 = b + 2$ ，即 $a = 3\sqrt{2} - 1, b = 3\sqrt{2} - 2$ 时取等号，
> >
> > 此时 $\frac{1}{a + 1} +\frac{1}{b + 2}$ 取得最小值 $\frac{\sqrt{2}}{3}$ ，所以选项B错误，
> >
> > 对于选项 C，因为 $16 = ab + 2a + b \quad ab + 2\sqrt{2ab}$
> >
> > 当且仅当 $2a = b$ ，即 $a = 2, b = 4$ 时取等号，
> >
> > 又 $\sqrt{ab} > 0$ ，解不等式得 $0 < \sqrt{ab} \leq 2\sqrt{2}$ ，即 $0 < ab \leq 8$ ，得到 $ab$ 的最大值为 $8$ ，所以选项 $C$ 错误，
> >
> > 对于选项D，由选项A知 $b=\frac{18}{a+1}-2$ ，由a>0,b>0，得0<a<8，
> >
> > 所以 $b + \frac{1}{9 - a} = \frac{18}{a + 1} +\frac{1}{9 - a} -2 = \left(\frac{18}{a + 1} +\frac{1}{9 - a}\right)\left(\frac{a + 1}{10} +\frac{9 - a}{10}\right) - 2$
> >
> > $$
> > = \frac {1 8 (9 - a)}{1 0 (a + 1)} + \frac {a + 1}{1 0 (9 - a)} - \frac {1}{1 0} \quad 2 \sqrt {\frac {1 8}{1 0 0}} - \frac {1}{1 0} = \frac {6 \sqrt {2} - 1}{1 0}
> > $$
> >
> > 当且仅当 $\frac{18(9 - a)}{10(a + 1)} = \frac{a + 1}{10(9 - a)}$ ，即 $a = \frac{163 - 30\sqrt{2}}{17}$ 时取等号，
> >
> > 此时 $b+\frac{1}{9-a}$ 取得最小值 $\frac{6\sqrt{2}-1}{10}$ ，所以选项D正确·
> >
> > 故选 **AD**.
