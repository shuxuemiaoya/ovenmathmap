> [!faq]- 《专题02_基本不等式巧解最值_七大题型__高效培优期中专项训练_数学人》官方解析
>
> > [!success]- **【答案】** (1) $\frac{1}{16}$ (2)7
>
> > [!note]- **【分析】**
> > （1）利用基本不等式可求得 $y = \frac{1}{2} x(1 - 2x)$ 的最大值；
> >
> > (2) 将函数解析式变形为 $y = (x + 2) + \frac{4}{x + 2} + 3$ ，利用基本不等式可求得该函数的最小值.
>
> > [!note]- **【解析】**
> > （1）因为 $0 < x < \frac{1}{2}$ ，所以 $1 - 2x > 0$ ，
> >
> > 所以 $\frac{1}{2} x(1 - 2x) = \frac{1}{4}\times 2x(1 - 2x)\leq \frac{1}{4}\times \left(\frac{2x + 1 - 2x}{2}\right)^2 = \frac{1}{16}$
> >
> > 当且仅当 $2x = 1 - 2x\left(0 < x < \frac{1}{2}\right)$
> >
> > 即 $x = \frac{1}{4}$ 时，等号成立，故 $y = \frac{1}{2} x(1 - 2x)$ 的最大值为 $\frac{1}{16}$
> >
> > (2) 因为 $x > -2$ ，所以 $x + 2 > 0$
> >
> > 所以 $y=\frac{x^{2}+7x+14}{x+2}=\frac{(x+2)^{2}+3(x+2)+4}{x+2}$
> >
> > $$
> > = (x + 2) + \frac {4}{x + 2} + 3 2 \sqrt {(x + 2) \cdot \frac {4}{x + 2}} + 3 = 7
> > $$
> >
> > 当且仅当 $x + 2 = \frac{4}{x + 2} (x > -2)$ ，即 $x = 0$ 时，等号成立，
> >
> > 所以当 x=0 时，函数 $y=\frac{x^{2}+7x+14}{x+2}(x>-2)$ 取得最小值 7
> >
> > 53. 解决下列问题：
> >
> > (1)求函数 $y = \frac{x^2 + x + 1}{x} (x > 0)$ 的最小值；
> >
> > (2)若 $x, y \in (0, +\infty)$ ，且 $x + 4y = 1$ ，求 $\frac{1}{x} + \frac{1}{y}$ 的最小值.
> >
> > (3) 求函数 $y = \frac{x^2 + 2x + 6}{x - 1} (x > 1)$ 的最小值；
> >
> > 【答案】(1)3；
> >
> > (2)9 ;
> >
> > (3)10.
> >
> > 【分析】（ $^{1}$ ）由基本不等式可得答案；
> >
> > (2) 注意到 $\frac{1}{x} + \frac{1}{y} = (x + 4y)\left(\frac{1}{x} + \frac{1}{y}\right)$ ，后由基本不等式可得答案；
> >
> > (3) 令 $t = x - 1 (t > 0)$ ，则 $y = \frac{t^2 + 4t + 9}{t}$ ，后由基本不等式可得答案.
> >
> > 【详解】（1） $y=\frac{x^{2}+x+1}{x}=x+\frac{1}{x}+1$
> >
> > ∴ $x + \frac{1}{x}$ $2\sqrt{x \cdot \frac{1}{x}} = 2$ （当且仅当 $x = \frac{1}{x}$ ，即 x = 1 时取等号）
> >
> > $\therefore y=\frac{x^{2}+x+1}{x}(x>0)$ 的最小值为 $^{3}$ ;
> >
> > (2) 因为 $x, y \in (0, +\infty)$ ，且 $x + 4y = 1$ ，
> >
> > 所以 $\frac{1}{x} +\frac{1}{y} = \frac{x + 4y}{x} +\frac{x + 4y}{y} = 5 + \frac{4y}{x} +\frac{x}{y}$ $5 + 2\sqrt{\frac{4y\cdot x}{x\cdot y}} = 9$
> >
> > 当且仅当 $\frac{4y}{x} = \frac{x}{y}$ ，即 $x^{2} = 4y^{2}$ 时取等号，此时 $x = \frac{1}{3}$ ， $y = \frac{1}{6}$
> >
> > 所以 $\frac{1}{x} +\frac{1}{y}$ 的最小值为9.
> >
> > (3) 令 $t = x - 1 (t > 0)$ ，则 $x = t + 1$ ，
> >
> > $$
> > \therefore y = \frac {x ^ {2} + 2 x + 6}{x - 1} = \frac {(t + 1) ^ {2} + 2 (t + 1) + 6}{t} = \frac {t ^ {2} + 4 t + 9}{t} = t + \frac {9}{t} + 4 \quad 2 \sqrt {t \cdot \frac {9}{t}} + 4 = 1 0
> > $$
> >
> > 当且仅当 $t = \frac{9}{t}$ 即 $t = 3$ 时取等号
> >
> > $\therefore y$ 的最小值为 10.
