> [!faq]- 《专题02_基本不等式巧解最值_七大题型__高效培优期中专项训练_数学人》官方解析
>
> > [!success]- **【答案】** BCD
>
> > [!note]- **【分析】**
> > 根据不等式的基本性质，可得判定 A 错误，B 正确；利用基本不等式，可得判定 C 正确；利用作差比较法，可判定 D 正确。
>
> > [!note]- **【解析】**
> > 因为实数 $a, b, c$ 满足 $a > b > 0 > c$
> >
> > 对于 $\mathsf{A}$ ，因为 $a > b > 0, c < 0$ ，所以 $ac < bc$ ，所以 $\mathsf{A}$ 错误；
> >
> > 对于 B，由不等式的性质，可得 $a + c > b + c$ ，所以 B 正确；
> >
> > 对于 C，由 b-c > 0 ，可得 $\frac{4}{b-c} > 0$ ，所以 $b-c + \frac{4}{b-c}$ $2\sqrt{(b-c)\cdot\frac{4}{b-c}} = 4$
> >
> > 当且仅当 $b - c = \frac{4}{b - c}$ 时，即 $b - c = 2$ 时，等号成立，所以 $\mathbb{C}$ 正确；
> >
> > 对于 D，由 $\frac{b}{a}-\frac{b-c}{a-c}=\frac{ab-bc-ab+ac}{a(a-c)}=\frac{(a-b)c}{a(a-c)}<0$ ，所以 $\frac{b}{a}<\frac{b-c}{a-c}$ ，所以 D 正确.
> >
> > 故选 **BCD**.
