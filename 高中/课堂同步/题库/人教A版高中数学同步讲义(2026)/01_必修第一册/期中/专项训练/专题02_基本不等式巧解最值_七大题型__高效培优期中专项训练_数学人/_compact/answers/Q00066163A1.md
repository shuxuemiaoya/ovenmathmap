> [!faq]- 《专题02_基本不等式巧解最值_七大题型__高效培优期中专项训练_数学人》官方解析
>
> > [!success]- **【答案】** AC
>
> > [!note]- **【分析】**
> > 利用基本不等式求解 $^{A}$ ，利用基本不等式的取等条件判断 $^{B}$ ，利用基本不等式结合“1”的代换判断
> >
> > C，先分离参数，再对 $\frac{\sqrt{a} + \sqrt{5b}}{\sqrt{a + b}}$ 平方后利用换元法和判别式法求解最值，得到 $k$ 的最小值判断D即可
>
> > [!note]- **【解析】**
> > 对于 A， $ab = a + b + 3 \quad 2\sqrt{ab} + 3$ ，当且仅当 a = b = 3 时取等号，
> >
> > 即 $\left(\sqrt{ab} - 3\right)\left(\sqrt{ab} + 1\right) = 0$ ，得到 $\sqrt{ab} - 3 = 0$ ，解得 $ab = 9$ 。故 $\mathbb{A}$ 正确；
> >
> > 对于 B， $a^{2}+\frac{4}{a^{2}+3}=\left(a^{2}+3\right)+\frac{4}{a^{2}+3}-3$ $2\sqrt{\left(a^{2}+3\right)\frac{4}{a^{2}+3}}-3=4-3=1$
> >
> > 当且仅当 $a^2 + 3 = \frac{4}{a^2 + 3}$ ，即 $a^2 + 3 = 2$ 时取等号，显然 $a$ 的值不存在，故 $\mathbf{B}$ 错误；
> >
> > 对于 C，因为 $a + b = 9$ ，所以 $\frac{4(a + b)}{a} + \frac{a}{b} = 4 + \frac{4b}{a} + \frac{a}{b}$ ，
> >
> > 由基本不等式得 $4 + \frac{4b}{a} +\frac{a}{b}$ $4 + 2\sqrt{\frac{4b}{a}\times\frac{a}{b}} = 8$
> >
> > 当且仅当 $\frac{4b}{a} = \frac{a}{b}$ 时取等，此时解得 $a = 6, b = 3$
> >
> > 则 $\frac{36}{a} +\frac{a}{b}$ 的最小值为 $^8$ ，故C正确，
> >
> > 对于 D，因为 $\sqrt{a} + \sqrt{5b} \leq k\sqrt{a + b}$ 恒成立，且 a > 0，b > 0
> >
> > 所以 $k = \frac{\sqrt{a} + \sqrt{5b}}{\sqrt{a + b}}$ 恒成立，而 $\left(\frac{\sqrt{a} + \sqrt{5b}}{\sqrt{a + b}}\right)^2 = \frac{a + 5b + 2\sqrt{5ab}}{a + b}$
> >
> > $$
> > = \frac {a + b + 4 b + 2 \sqrt {5 a b}}{a + b} = 1 + \frac {4 \times \frac {b}{a} + 2 \sqrt {5 \times \frac {b}{a}}}{1 + \frac {b}{a}}
> > $$
> >
> > 令 $t = \sqrt{\frac{b}{a}} >0$ ，则 $1 + \frac{4\times\frac{b}{a} + 2\sqrt{5\times\frac{b}{a}}}{1 + \frac{b}{a}}$ 可化为 $1 + \frac{4t^2 + 2\sqrt{5}t}{1 + t^2}$
> >
> > 令 $m = \frac{4t^2 + 2\sqrt{5}t}{1 + t^2}$ ，则 $m(1 + t^2) = 4t^2 + 2\sqrt{5}t$
> >
> > 化简得 $(m - 4)t^{2} - 2\sqrt{5} t + m = 0$
> >
> > 而该一元二次方程一定有实数根，得到 $(-2\sqrt{5})^2 - 4m(m - 4) = 0$
> >
> > 解得 $m \in [-1, 5]$ ，当 m = 5 时， $t = \sqrt{5} > 0$ ，故 $m + 1 \leq 6$ ，故 $1 + \frac{4 \times \frac{b}{a} + 2\sqrt{5 \times \frac{b}{a}}}{1 + \frac{b}{a}} \leq 6$ 即 $\frac{\sqrt{a} + \sqrt{5b}}{\sqrt{a + b}} \leq \sqrt{6}$ ，
> >
> > 得到 $k\sqrt{6}$ ，则 $k$ 的最小值为 $\sqrt{6}$ ，故D错误
> >
> > 故选 **AC**
