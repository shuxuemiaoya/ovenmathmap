> [!faq]- 《专题02_基本不等式巧解最值_七大题型__高效培优期中专项训练_数学人》官方解析
>
> > [!success]- **【答案】** A. $xy$ 的最大值为 2 B. $x + y$ 的最小值为 4 C. $x + 2y$ 的最小值为 $6\sqrt{2} - 3$ D. $\frac{1}{x} + \frac{1}{y}$ 的最大值为 1
>
> > [!note]- **【分析】**
> > 对于 A、B，利用基本不等式，结合题目中的等式与一元二次不等式，可得答案；对于 C、D，整理等式，可得所求代数式的函数解析式，利用基本不等式与不等式性质，可得答案。
>
> > [!note]- **【解析】**
> > 对于 A，由 $xy + x + y = 8$ ，则 $x + y = 8 - xy$ ，
> >
> > 由 $x > 0, y > 0$ ，则 $x + y = 8 - xy > 0$ ，解得 $xy < 8$ ，
> >
> > $xy \leq \left( \frac{x + y}{2} \right)^{2} = \left( \frac{8 - xy}{2} \right)^{2}$ ，可得 $(xy)^{2} - 20xy + 64 = 0$ ， $(xy - 16)(xy - 4) = 0$ ，
> >
> > 解得 $xy \leq 4$ 或 $xy = 16$ ，综上可得 $xy \leq 4$ ，当且仅当 $x = y = 4$ ，等号成立，
> >
> > 所以 $xy$ 的最大值为4，故 $\mathsf{A}$ 错误；
> >
> > 对于 $\mathsf{B}$ ，由 $xy + x + y = 8$ ，则 $xy = 8 - (x + y)$
> >
> > 由 $x > 0, y > 0$ ，则 $xy = 8 - (x + y) > 0$ ，解得 $(x + y) < 8$
> >
> > $(x+y)^{2}$ 4xy=4 $\left[8-(x+y)\right]$ ，可得 $(x+y)^{2}+4(x+y)-32\quad0$
> >
> > $(x+y-4)(x+y+8)$ 0，解得 $x+y\leq-8$ 或 $x+y$ 4，
> >
> > 综上可得 $8 > x + y = 4$ ，当且仅当 $x = y = 2$ 时，等号成立，
> >
> > 所以 $x + y$ 的最小值为4，故 $\mathbf{B}$ 正确；
> >
> > 对于 $C$ ，由 $xy + x + y = 8$ ，则 $y = \frac{8 - x}{x + 1}$ ，由 $y > 0$ ，则 $\frac{8 - x}{x + 1} >0$ ，解得 $-1 <   x <   8$
> >
> > 由题意可得 0 < x < 8， $x + 2y = x + 2\frac{8 - x}{x + 1} = x - 2 + \frac{18}{x + 1} = x + 1 + \frac{18}{x + 1} - 3 \quad 6\sqrt{2} - 3$
> >
> > 当且仅当 $x + 1 = \frac{18}{x + 1}$ ，即 $x = 3\sqrt{2} - 1$ 时，等号成立，所以 $x + 2y$ 的最小值为 $6\sqrt{2} - 3$ ，故C正确；对于D，由A可知 $0 < xy \leq 4$ ，当且仅当 $x = y = 2$ 时，等号成立，且 $x + y = 8 - xy$ ，
> >
> > $\frac{1}{x}+\frac{1}{y}=\frac{x+y}{xy}=\frac{8-xy}{xy}=\frac{8}{xy}-1$ ，由 $0<xy\leq4$ ，则 $\frac{8}{xy}-1=1$ ，所以 $\frac{1}{x}+\frac{1}{y}$ 的最小值为 $_{1}$ ，故 $^{D}$ 错误.
> >
> > 故选 **BC**.
