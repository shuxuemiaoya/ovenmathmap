> [!faq]- 《专题02_基本不等式巧解最值_七大题型__高效培优期中专项训练_数学人》官方解析
>
> > [!success]- **【答案】** A. $ab$ 的最大值为 1 B. $a^2 + b^2$ 的最大值为 2 C. $\frac{a^2}{a + 1} + \frac{b^2}{b + 2}$ 的最小值为 $\frac{4}{5}$ D. $\frac{b}{a} + \frac{2}{b}$ 的最小值 3
>
> > [!note]- **【分析】**
> > 根据已知等式，结合基本不等式的“1”的巧用，分式分离，平方转化等方法逐项判断即可得结论。
>
> > [!note]- **【解析】**
> > 对于 $A$ ，a，b 为正实数， $a + b = 2$ ，所以 $ab \leq \left( \frac{a + b}{2} \right)^{2} = 1$ ，
> >
> > 当且仅当 $a = b = 1$ 时， $ab$ 的最大值为 $1$ ，故 $\mathsf{A}$ 正确；
> >
> > 对于 B，由于 $a^{2}+b^{2}=(a+b)^{2}-2ab=4-2ab$ ，由 A 选项可知 $0<ab\leq1$
> >
> > 所以 $a^2 + b^2 = 4 - 2ab \in [2, 4)$ ，所以 $a^2 + b^2$ 的最小值为 $2$ ，故 $\mathbb{B}$ 不正确；
> >
> > 对于 $\mathbb{C}$ ， $\frac{a^2}{a + 1} +\frac{b^2}{b + 2} = \frac{(a^2 - 1) + 1}{a + 1} +\frac{(b^2 - 4) + 4}{b + 2} = a - 1 + \frac{1}{a + 1} +b - 2 + \frac{4}{b + 2}$ $= a + b - 3 + \frac{1}{a + 1} +\frac{4}{b + 2} = \frac{1}{a + 1} +\frac{4}{b + 2} -1$
> >
> > 因为 $a$ ， $b$ 为正实数， $a + b = 2$ ，所以 $(a + 1) + (b + 2) = 5$ 则 $\left(\frac{1}{a + 1} +\frac{4}{b + 2}\right)\left[\left(a + 1\right) + \left(b + 2\right)\right]\times \frac{1}{5} = \left[1 + \frac{b + 2}{a + 1} +\frac{4(a + 1)}{b + 2} +4\right]\times \frac{1}{5} = 1 + \frac{b + 2}{5(a + 1)} +\frac{4(a + 1)}{5(b + 2)}$ $1 + 2\times \frac{2}{5} = \frac{9}{5}$ 当且仅当 $\frac{b + 2}{5(a + 1)} = \frac{4(a + 1)}{5(b + 2)}$ ，即 $a = \frac{2}{3},b = \frac{4}{3}$ 时， $\frac{a^2}{a + 1} +\frac{b^2}{b + 2}$ 的最小值为 $\frac{4}{5}$ ，故C正确；对于D， $\frac{b}{a} +\frac{2}{b} = \frac{b}{a} +\frac{a + b}{b} = \frac{b}{a} +\frac{a}{b} +1$ $2 + 1 = 3$ ，当且仅当 $a = b = 1$ 时， $\frac{b}{a} +\frac{2}{b}$ 的最小值3，故D正确
> >
> > 故选 **ACD**.
