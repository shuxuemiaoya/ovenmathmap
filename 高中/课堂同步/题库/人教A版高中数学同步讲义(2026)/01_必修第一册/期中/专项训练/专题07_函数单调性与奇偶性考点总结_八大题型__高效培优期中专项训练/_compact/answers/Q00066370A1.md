> [!faq]- 《专题07_函数单调性与奇偶性考点总结_八大题型__高效培优期中专项训练》官方解析
>
> > [!success]- **【答案】** B
>
> > [!note]- **【分析】**
> > 由 $x_{2} = (x_{2} - x_{1}) + x_{1}$ 结合题意，利用单调性的定义法判断 $f(x)$ 在 $\mathbf{R}$ 上是增函数，利用赋值法得 $f(3) = 10$ ，从而原不等式等价 $f(x^{2} - x + 1) > f(3)$ ，利用单调递增化为 $x^{2} - x + 1 > 3$ ，解一元二次不等式即可得解·
>
> > [!note]- **【解析】**
> > 任取 $x_{1}, x_{2} \in \mathbf{R}$ ，且 $x_{1} < x_{2}$ ，因为 $f(x + y) = f(x) + f(y) + 2$
> >
> > 所以 $f(x_{2}) = f((x_{2} - x_{1}) + x_{1}) = f(x_{2} - x_{1}) + f(x_{1}) + 2$
> >
> > 因为 x > 0 时， $f(x) > -2$ ，所以 $f(x_{2} - x_{1}) + 2 > 0$ ，
> >
> > 所以 $f(x_{1})-f(x_{2})=-\left(f(x_{2}-x_{1})+2\right)<0$ ，即 $f(x_{1})<f(x_{2})$
> >
> > 所以 $f(x)$ 在 R 上是增函数.
> >
> > 令 $x = y = 1$ ，所以 $f(2) = f(1) + f(1) + 2 = 6$ ，令 $x = 2, y = 1$ ，所以 $f(3) = f(2) + f(1) + 2 = 10$
> >
> > 不等式 $f\left(x^{2} + x\right) + f(1 - 2x) > 8$ 等价于 $f\left(x^{2} + x\right) + f(1 - 2x) + 2 > 10 = f(3)$
> >
> > 所以 $f\left(x^{2} + x + 1 - 2x\right) > f(3)$ 即 $f\left(x^{2} - x + 1\right) > f(3)$ ，因为 $f(x)$ 在 $\mathbf{R}$ 上是增函数，
> >
> > 所以 $x^{2} - x + 1 > 3 \Leftrightarrow x^{2} - x - 2 > 0$ ，解得 $x < -1$ 或 $x > 2$ .
> >
> > 故选：B
