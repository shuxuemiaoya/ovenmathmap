> [!faq]- 《专题05_函数值域考点总结_六大题型__高效培优期中专项训练_数学人教》官方解析
>
> > [!success]- **【答案】** A. $y = \sqrt{x + 3} \cdot \sqrt{x - 3}$ 与 $y = \sqrt{x^{2} - 9}$ 表示同一个函数 B. 函数 $f(x)$ 的定义域为 $(-3, 3)$ ，则函数 $f(2x - 1)$ 的定义域为 $(-1, 2)$ C. 函数 $f(x) = x^{2} + ax + 2$ 的单调减区间为 $(-∞, -3)$ ，则实数 a 的值为 -6 D. 函数 $f(x) = 2x + 4\sqrt{x - 1}$ 的值域为 $[2, +∞)$
>
> > [!note]- **【分析】**
> > 由两个函数的定义域不同可判断 A；由抽象函数的定义域求法可判断 B；根据二次函数的单调性可判断 C；由换元法求值域可判断 D.
>
> > [!note]- **【解析】**
> > 对于A，函数 $y = \sqrt{x + 3} \cdot \sqrt{x - 3}$ 的定义域为 $[3, +\infty)$
> >
> > 函数 $y = \sqrt{x^2 - 9}$ 的定义域为 $(- \infty, -3] \cup [3, +\infty)$ ，定义域不同，所以不是同一函数，
> >
> > 故A不正确；
> >
> > 对于B，因为函数 $f(x)$ 的定义域为 $(-3,3)$ ，所以 $-3 < x < 3$
> >
> > 所以 $-3 < 2x - 1 < 3$ ，即 $-1 < x < 2$ ，所以函数 $f(2x - 1)$ 的定义域为 $(-1,2)$
> >
> > 故B正确；
> >
> > 对于 C，因为函数 $f(x)=x^{2}+ax+2$ 的单调减区间为 $(-∞,-3)$ ，
> >
> > 所以 $-\frac{a}{2} = -3$ ，所以 $a = 6$ ，故C不正确；
> >
> > 对于 D，设 $t = \sqrt{x - 1}$ ，t = 0，所以 $x = t^{2} + 1$ ，
> >
> > 所以 $f(t)=2t^{2}+4t+2=2(t+1)^{2}$ ，t 0，
> >
> > 当 $t = 0$ 时， $f(t)$ 取得最小值，最小值为 $f(0) = 2$
> >
> > 所以函数 $f(x) = 2x + 4\sqrt{x - 1}$ 的值域为 $[2, +\infty)$ ，故D正确·
> >
> > 故选：BD·

> > 20. 函数 $f(x) = \begin{cases} x + \sqrt{9 - x}, & x \leq 9 \\ x + \frac{100}{x}, & x > 9 \end{cases}$ 的值域为（）
> >
> > 【答案】
> > A. $\left(-\infty, \frac{37}{4}\right] \cup [20, +\infty)$ B. $\left(-\infty, \frac{35}{8}\right] \cup [10, +\infty)$ C. $\left(-\infty, \frac{37}{4}\right] \cup [10, +\infty)$ D. $\left(-\infty, \frac{35}{8}\right] \cup [20, +\infty)$
> >
> > 【答案】A
> >
> > 【分析】当 $x \leq 9$ 时，由换元法结合二次函数的值域即可得到结果，当 $x > 9$ 时，由基本不等式即可得到其值域：
> >
> > 【详解】根据题意，当 $x \leq 9$ 时， $f(x) = x + \sqrt{9 - x}$ ，令 $\sqrt{9 - x} = t$ ，可得 $t \in [0, +\infty)$
> >
> > 所以 $x = 9 - t^2$ ，因此可得 $f(t) = -t^2 + t + 9 = -\left(t - \frac{1}{2}\right)^2 + \frac{37}{4}$
> >
> > 由二次函数性质可得，当 $t = \frac{1}{2}$ 时， $f(x) = x + \sqrt{9 - x}$ 取得最大值 $\frac{37}{4}$
> >
> > 此时 $f(x)=x+\sqrt{9-x}\in\left(-\infty,\frac{37}{4}\right]$ ;
> >
> > 当 $x > 9$ 时， $f(x) = x + \frac{100}{x} - 2\sqrt{x \cdot \frac{100}{x}} = 20$ ，当且仅当 $x = \frac{100}{x}$ ，即 $x = 10$ 时，等号成立；
> >
> > 所以 $f(x) = x + \frac{100}{x}, x > 9$ 的最小值为20，因此 $f(x) = x + \frac{100}{x} \in [20, +\infty)$ ；
> >
> > 综上可得，函数 $f(x)$ 的值域为 $\left(-\infty, \frac{37}{4}\right] \cup [20, +\infty)$ .
> >
> > 故选：A.
