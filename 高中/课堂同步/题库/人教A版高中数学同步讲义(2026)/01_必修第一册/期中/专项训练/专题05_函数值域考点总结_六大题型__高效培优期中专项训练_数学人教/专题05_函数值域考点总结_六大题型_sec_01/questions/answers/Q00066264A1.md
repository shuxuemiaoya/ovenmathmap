> [!faq]- 《专题05_函数值域考点总结_六大题型__高效培优期中专项训练_数学人教》官方解析
>
> > [!success]- **【答案】** D
>
> > [!note]- **【分析】**
> > 因为函数是一对一函数，所以根据值域解定义域，只需解不等式 $\frac{1}{x + 1} < -1$ 或 $\frac{1}{x + 1} > 1$ .
>
> > [!note]- **【解析】**
> > 因为函数是一对一函数，所以可以根据值域解定义域，
> >
> > 由 $\frac{1}{x + 1} > 1$
> >
> > ∴ 0 < x + 1 < 1 ，解得 -1 < x < 0 ，
> >
> > $\frac{1}{x + 1} < -1$ ， $\therefore -1 <   x + 1 <   0$
> >
> > $\therefore -2 < x < -1$
> >
> > ∴定义域是： $(-2,-1)\cup(-1,0)$ .
> >
> > 故选 **D**
