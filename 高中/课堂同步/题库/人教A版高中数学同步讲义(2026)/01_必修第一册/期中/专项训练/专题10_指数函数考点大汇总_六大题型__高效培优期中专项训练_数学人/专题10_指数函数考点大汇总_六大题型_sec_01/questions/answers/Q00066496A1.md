> [!faq]- 《专题10_指数函数考点大汇总_六大题型__高效培优期中专项训练_数学人》官方解析
>
> > [!success]- **【答案】** $f(x) = \begin{cases} -2^{-x} + x + 2, & x < 0 \\ 0, & x = 0 \\ 2^x + x - 2, & x > 0 \end{cases}$
>
> > [!note]- **【分析】**
> > 利用奇函数的性质求出函数 $f(x)$ 在 $x < 0$ 时的解析式，由奇函数的性质得出 $f(0) = 0$ ，综合可得
> >
> > 出函数 $f(x)$ 的解析式·
>
> > [!note]- **【解析】**
> > 因为函数 $f(x)$ 为定义在 $\mathbf{R}$ 上的奇函数，且当 $x > 0$ 时， $f(x) = 2^x + x - 2$
> >
> > 则当 $x < 0$ 时， $-x > 0$ ，则 $f(x) = -f(-x) = -(2^{-x} - x - 2) = -2^{-x} + x + 2$
> >
> > 由奇函数的性质可得 $f(0)=0$ ，
> >
> > 因此， $f(x) = \left\{ \begin{array}{ll} - 2^{-x} + x + 2, & x < 0\\ 0,x = 0\\ 2^{x} + x - 2,x > 0 \end{array} \right.$
> >
> > 故答案为： $f(x)=\left\{\begin{aligned}-2^{-x}+x+2,x&<0\\ 0,x&=0\\ 2^{x}+x-2,x&>0\end{aligned}\right.$
