> [!faq]- 《专题10_指数函数考点大汇总_六大题型__高效培优期中专项训练_数学人》官方解析
>
> > [!success]- **【答案】** $c < a < b$
>
> > [!note]- **【分析】**
> > 根据指数函数与幂函数的单调性比较大小.
>
> > [!note]- **【解析】**
> > 由题知， $a = \left(\frac{3}{2}\right)^{-\frac{1}{3}} = \left(\frac{2}{3}\right)^{\frac{1}{3}}$ ，已 $y = \left(\frac{2}{3}\right)^x$ 在定义域 $(-\infty, + \infty)$ 内单调递减，所以 $c = \left(\frac{2}{3}\right)^{\frac{2}{3}} < a = \left(\frac{2}{3}\right)^{\frac{1}{3}}$ 因为 $y = x^{\frac{1}{3}}$ 在定义域 $\left(-\infty, +\infty\right)$ 内单调递增，所以 $a = \left(\frac{2}{3}\right)^{\frac{1}{3}} < b = \left(\frac{3}{4}\right)^{\frac{1}{3}}$ ，所以 $c = \left(\frac{2}{3}\right)^{\frac{2}{3}} < a = \left(\frac{2}{3}\right)^{\frac{1}{3}} < b = \left(\frac{3}{4}\right)^{\frac{1}{3}}$ 所以 $c < a < b$ ，故答案为： $c < a < b$
