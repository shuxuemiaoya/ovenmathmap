> [!faq]- 《专题01_集合热点题型突破_六大题型__高效培优期中专项训练_数学人教》官方解析
>
> > [!success]- **【答案】** (1) $A \cap (\tilde{\mathbf{Q}}_R B) = \left\{ x \mid -2 \leq x < 0 \text{ 或 } 2 < x \leq 3 \right\}$ . (2)a 3.
>
> > [!note]- **【分析】**
> > （1）先求出 $\check{Q}_{R}B$ ，再利用交集的定义可求出 $A\cap(\check{Q}_{R}B)$ ;
> >
> > (2) 由题意得 $A \subseteq B$ ，然后列不等式组可求得答案.
>
> > [!note]- **【解析】**
> > （1）当 $a = 1$ 时， $B = \{x \mid 0 \leq x \leq 2\}$
> >
> > 所以 $\tilde{\mathbf{Q}}_{\mathrm{R}}B = \left\{x\mid x <   0\right.$ 或 $x > 2\}$
> >
> > 因为 $A = \{x\mid -2\leq x\leq 3\}$
> >
> > 故 $A \cap (\tilde{\mathfrak{Q}}_{\mathrm{R}} B) = \{x | -2 \leq x < 0 \text{ 或 } 2 < x \leq 3\}$ .
> >
> > (2) 因为 $x \in A$ 是 $x \in B$ 的充分条件，所以 $A \subseteq B$
> >
> > 所以 $\left\{ \begin{array}{ll}1 - a\leq -2\\ 1 + a\quad 3 \end{array} \right.$
> >
> > 解得 a 3，
> >
> > 所以 $a$ 的取值范围为 $a = 3$ .
