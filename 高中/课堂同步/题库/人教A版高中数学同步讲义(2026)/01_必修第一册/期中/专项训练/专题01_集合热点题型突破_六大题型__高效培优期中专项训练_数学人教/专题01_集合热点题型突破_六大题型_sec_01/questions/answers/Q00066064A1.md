> [!faq]- 《专题01_集合热点题型突破_六大题型__高效培优期中专项训练_数学人教》官方解析
>
> > [!success]- **【答案】** BCD
>
> > [!note]- **【分析】**
> > 根据题意，分 $A = \{-1\}$ 或 $A = \{2\}$ 或 $A = \{-1, 2\}$ ，三种情况讨论，结合一元二次方程的性质，即可求解：
>
> > [!note]- **【解析】**
> > 因为 $\varnothing \subseteq A\subseteq \{-1,2\}$ ，则 $A = \{-1\}$ 或 $A = \{2\}$ 或 $A = \{-1,2\}$
> >
> > 当 $A = \{-1\}$ 时，可得 $(-1)^2 - a + b = 0$ 且 $\Delta = a^2 - 4b = 0$ ，解得 $a = 2, b = 1$ ，则 $a + b = 3$ ；
> >
> > 当 $A = \{2\}$ 时，可得 $2^{2} + 2a + b = 0$ 且 $\Delta = a^2 -4b = 0$ ，解得 $a = -4,b = 4$ ，则 $a + b = 0$
> >
> > 当 $A = \{-1,2\}$ 时，可得 $\left\{ \begin{array}{l} (-1)^2 - a + b = 0 \\ 2^2 + 2a + b = 0 \end{array} \right.$ ，解得 $a = -1, b = -2$ ，则 $a + b = -3$ ，
> >
> > 综上可得， $a+b$ 的值可以是 3 或 -3 或 0。
> >
> > 故选 **BCD**.
