> [!faq]- 《专题01_集合热点题型突破_六大题型__高效培优期中专项训练_数学人教》官方解析
>
> > [!success]- **【答案】** (1) $\{4,5\}$ ; (2) $\{1,2,6,7,8\}$ ; (3) $\{1,3,4,5,6,7,8\}$
>
> > [!note]- **【分析】**
> > （ $^{1}$ ）根据题意，利用集合交集的概念与运算，即可求解；
> >
> > (2) 根据题意，利用集合补集的概念与运算，即可求解；
> >
> > (3) 根据题意，利用集合补集与并集的概念与运算，即可求解·
>
> > [!note]- **【解析】**
> > （1）解：由集合 $A = \{2,4,5\}$ ， $B = \{3,4,5\}$ ，根据集合交集的运算，可得 $A \cap B = \{4,5\}$ ；
> >
> > (2) 解：由集合 $U = \{1, 2, 3, 4, 5, 6, 7, 8\}$ ， $B = \{3, 4, 5\}$ ，可得 $\tilde{\partial}_{U} B = \{1, 2, 6, 7, 8\}$ ;
> >
> > (3) 解：由集合 $U = \{1, 2, 3, 4, 5, 6, 7, 8\}$ ，且 $A = \{2, 4, 5\}$ ，可得 $\tilde{\mathbf{Q}}_U A = \{1, 3, 6, 7, 8\}$
> >
> > 所以 $B \cup (\tilde{\mathfrak{Q}}_U A) = \{1, 3, 4, 5, 6, 7, 8\}$ .

> > 22. 集合 $A = \{x \mid -1 \leq x < 2\}$ , $B = \{x \mid 1 \leq x \leq 2\}$ , 则 $A \cap B = (\quad)$ A. $\{x \mid -1 \leq x < 2\}$ B. $\{x \mid -1 \leq x \leq 2\}$ C. $\{x \mid 1 \leq x < 2\}$ D. $\{x \mid 1 \leq x \leq 2\}$
> >
> > 【答案】C
> >
> > 【分析】根据交集的定义求解·
> >
> > 【详解】因为 $A=\left\{x\mid-1\leq x<2\right\}$ ， $B=\left\{x\mid1\leq x\leq2\right\}$ ，
> >
> > 所以 $A \cap B = \{x \mid 1 \leq x < 2\}$
> >
> > 故选 **C**
