> [!faq]- 《专题01_集合热点题型突破_六大题型__高效培优期中专项训练_数学人教》官方解析
>
> > [!success]- **【答案】** B
>
> > [!note]- **【分析】**
> > 根据集合的并集运算求出即可·
>
> > [!note]- **【解析】**
> > ∵ $A = \{x \mid -1 < x < 1\}$ ， $B = \{x \mid 0 \leq x \leq 2\}$
> >
> > $\therefore A \cup B = \{x \mid -1 < x < 1\} \cup \{x \mid 0 \leq x \leq 2\} = \{x \mid -1 < x \leq 2\}$
> >
> > 故选 **B**
