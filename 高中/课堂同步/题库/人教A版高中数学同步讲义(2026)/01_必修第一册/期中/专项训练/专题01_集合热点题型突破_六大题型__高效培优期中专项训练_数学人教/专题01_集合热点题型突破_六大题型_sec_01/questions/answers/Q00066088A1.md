> [!faq]- 《专题01_集合热点题型突破_六大题型__高效培优期中专项训练_数学人教》官方解析
>
> > [!success]- **【答案】** $A \cap B = \{x \mid -2 < x < 3\}$ ， $(\tilde{\mathfrak{Q}}_U A) \cup B = \mathbf{R}$ .
>
> > [!note]- **【分析】**
> > 根据给定条件，利用交集、补集、并集的定义求解·
>
> > [!note]- **【解析】**
> > 由 $A = \{x - 2 < x < 3\}, B = \{x - 3 < x \leq 3\}$ ，得 $A \cap B = \{x \mid -2 < x < 3\}$
> >
> > 而全集 $U = \mathbf{R}$ ，则 $\tilde{\mathbf{Q}}_U A = \{x \mid x \leq -2$ 或 $x \quad 3\}$ ，所以 $(\tilde{\mathbf{Q}}_U A) \cup B = \mathbf{R}$ .
