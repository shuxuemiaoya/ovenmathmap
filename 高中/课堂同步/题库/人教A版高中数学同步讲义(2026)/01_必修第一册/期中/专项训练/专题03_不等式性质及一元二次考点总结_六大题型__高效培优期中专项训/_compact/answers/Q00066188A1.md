> [!faq]- 《专题03_不等式性质及一元二次考点总结_六大题型__高效培优期中专项训》官方解析
>
> > [!success]- **【答案】** BD
>
> > [!note]- **【分析】**
> > 利用三个二次关系，待定系数可确定参数之间的关系及符号一一判定选项即可·
>
> > [!note]- **【解析】**
> > ∵关于x的不等式 $ax^{2}+bx+c>0$ 的解集为 $\{x\mid x<-2$ 或 $x>3\}$
> >
> > $\therefore a > 0$ ，故 A 错误；
> >
> > 对于 B、C 选项，已知 -2 和 3 是关于 x 的方程 $ax^{2} + bx + c = 0$ 的两根，
> >
> > 由根与系数的关系得 $\left\{ \begin{array}{l} -2 + 3 = -\frac{b}{a}\\ -2\times 3 = \frac{c}{a} \end{array} \right.$
> >
> > 则 b = -a ， c = -6a
> >
> > 不等式 $bx + c > 0$ ，即 -ax - 6a > 0，又 a > 0，解得 x < -6， $^{B}$ 正确；
> >
> > 且 $a + b + c = -6a < 0$ ，C错误；
> >
> > 对于 D 选项，不等式 $cx^{2}-bx+a<0$ ，即 $-6ax^{2}+ax+a<0$ ，即 $6x^{2}-x-1>0$
> >
> > 解得 $x < -\frac{1}{3}$ 或 $x > \frac{1}{2}$
> >
> > 故不等式 $cx^2 - bx + a < 0$ 的解集为 $\{x \mid x < -\frac{1}{3} \text{或} x > \frac{1}{2}\}$ ，D 正确.
> >
> > 故选 **BD**.
