> [!faq]- 《专题03_不等式性质及一元二次考点总结_六大题型__高效培优期中专项训》官方解析
>
> > [!success]- **【答案】** ACD
>
> > [!note]- **【分析】**
> > 根据一元二次不等式的解集，确定 $a, b, c$ 的关系及符号，可判断 $\mathrm{AC}$ 的真假；解不等式可判断 $\mathrm{BD}$ 的真假·
>
> > [!note]- **【解析】**
> > 因为不等式 $ax^2 + bx + c \leq 0$ 的解集为 $\{x \mid x \leq -2$ 或 $x = 1\}$
> >
> > 所以 -2 和 1 是一元二次方程 $ax^{2} + bx + c = 0$ 的两个实数根，且该一元二次函数的开口向下.
> >
> > 所以且 \(\left\{ \begin{array}{l} -2 + 1 = -\frac{b}{a}\\ -2\times 1 = \frac{c}{a} \end{array} \right.\) ，解得 \(\left\{ \begin{array}{ll}b = a & .^{\mathrm{A}}\) 正确；\\ c = -2a \end{array} \right.\)
> >
> > $ax + c = ax - 2a = a(x - 2) > 0 \Rightarrow x - 2 < 0$ ，解得 $x < 2$ ，故 $ax + c > 0$ 的解集为 $\{x \mid x < 2\}$ ，B错误；
> >
> > $5a + 4b + 3c = 5a + 4a + 3(-2a) = 3a < 0$ ，C 正确；
> >
> > $$
> > c x ^ {2} + b x + a = - 2 a x ^ {2} + a x + a = - a (2 x ^ {2} - x - 1) = - a (2 x + 1) (x - 1) <   0 \Rightarrow (2 x + 1) (x - 1) <   0
> > $$
> >
> > 解得 $-\frac{1}{2} < x < 1$ 。所以 $cx^2 + bx + a < 0$ 的解集为 $\left\{x \mid -\frac{1}{2} < x < 1\right\}$ ，D 正确。
> >
> > 故选 **ACD**
