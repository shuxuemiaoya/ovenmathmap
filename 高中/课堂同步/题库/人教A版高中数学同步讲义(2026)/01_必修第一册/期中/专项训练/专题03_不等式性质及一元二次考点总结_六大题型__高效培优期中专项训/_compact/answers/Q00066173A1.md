> [!faq]- 《专题03_不等式性质及一元二次考点总结_六大题型__高效培优期中专项训》官方解析
>
> > [!success]- **【答案】** AB
>
> > [!note]- **【分析】**
> > 利用不等式的性质可得 $^{AB}$ 正确；举反例或者作差分析可得 $^{C}$ 错误；举例可得 $^{D}$ 错误。
>
> > [!note]- **【解析】**
> > 对于 A：因为 a > 0, b > 0，
> >
> > 因为 a > b ，两边同乘以 a ，不等号的方向不变，得 $a^{2} > ab$ ，
> >
> > 所以 $ab < a^2$ ，故 $\mathsf{A}$ 正确；
> >
> > 对于 $^{B}$ ：因为 a > 0，b > 0，所以 ab > 0，所以 $\frac{1}{ab} > 0$
> >
> > $a > b$ ，两边同乘以 $\frac{1}{ab}$ 并化简得 $\frac{1}{b} >\frac{1}{a}$
> >
> > 所以 $\frac{1}{a} < \frac{1}{b}$ ，故 B 正确；
> >
> > 对于 C :
> >
> > 方法一：若 a=1, c=-1 ，此时分母无意义，不能比较，故 C 错误.
> >
> > 方法二： $a+c=0$ 时不等式左边无意义，不能比较·
> >
> > 当 $a + c \neq 0$ 时做如下
> > 分析：
> >
> > $$
> > \frac {b + c}{a + c} - \frac {b}{a} = \frac {(b + c) a - (a + c) b}{(a + c) a} = \frac {c (a - b)}{a + c}
> > $$
> >
> > c < 0, a - b, $a + c$ 符号不确定，故结论不确定，故 C 错误；
> >
> > 对于 D :
> >
> > 若 $a = 3, b = 2, c = -1$ ，则 $3^{-1} = \frac{1}{3} < 2^{-1} = \frac{1}{2}$ ，故D错误·
> >
> > 故选：AB
> >
> > 7. 给出下列命题，其中正确的命题是（ ）A. $a > b \Rightarrow a^2 > b^2$ B. $a > b \Rightarrow a^3 > b^3$ C. $|a| > b \Rightarrow a^2 > b^2$ D. $a > b \Rightarrow ac^2 > bc^2$
> >
> > 【答案】B
> >
> > 【分析】通过举反例可判断 A、C、D 是假命题；利用作差法比较大小可判断 B 正确。
> > 【详解】对于 A，当 a = -1 > b = -2 时， $a^{2} = 1 < b^{2} = 4$ ，故 A 是假命题；
> > 对于 B，若 $a > b$ ，则 $a^{3} - b^{3} = (a - b)(a^{2} + ab + b^{2}) = (a - b)\left[\left(a + \frac{b}{2}\right)^{2} + \frac{3}{4}b^{2}\right]$ ，
> > 由于 a, b 不同时为 0，所以 $a^{3} > b^{3}$ ，故 B 是真命题；
> > 对于 C，当 $\left|a\right|=\left|1\right|=1>b=-2$ 时， $a^{2}=1<b^{2}=4$ ，故 C 是假命题；
> > 对于 D，当 c=0 时， $ac^{2}>bc^{2}$ 不成立，故 D 是假命题；
> >
> > 故选 **B**
