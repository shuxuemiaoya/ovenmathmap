> [!faq]- 《专题03_不等式性质及一元二次考点总结_六大题型__高效培优期中专项训》官方解析
>
> > [!success]- **【答案】** C
>
> > [!note]- **【分析】**
> > 由不等式恒成立，确定 $a > 0$ ，且 $ab = 2$ ，再由基本不等式即可求解.
>
> > [!note]- **【解析】**
> > 不等式 $(ax-2)(x-b)$ 0 可化为 $ax^{2}-(ab+2)x+2b$ 0
> >
> > 当 a=0 时，不等式为 $x \leq b$ ，不满足对任意的 $x \in R$ 恒成立；
> >
> > 当 $a < 0$ 时， $y = ax^2 - (ab + 2)x + 2b$ ，图象开口向下，不满足题意，
> >
> > 所以 $a > 0$ ，且 $\Delta = (ab + 2)^2 -4a\times 2b\leq 0$ ，所以 $(ab - 2)^{2}\leq 0$
> >
> > 所以 ab = 2 ，且 a > 0 ，b > 0
> >
> > 所以 $a + 2b$ $2\sqrt{a\cdot 2b} = 4$ ，当且仅当 $a = 2b$ ，即 $a = 2,b = 1$ 时等号成立，
> >
> > 所以 $a + 2b$ 的最小值为 4.
> >
> > 故选 **C**
