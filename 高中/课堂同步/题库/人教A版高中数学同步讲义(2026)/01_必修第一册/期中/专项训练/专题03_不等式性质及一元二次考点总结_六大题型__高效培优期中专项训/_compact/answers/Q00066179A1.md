> [!faq]- 《专题03_不等式性质及一元二次考点总结_六大题型__高效培优期中专项训》官方解析
>
> > [!success]- **【答案】** $-1 < a - 2b < 7$
>
> > [!note]- **【分析】**
> > 根据不等式的性质得到 $-2 < -2b < 4$ ， $-2 + 1 < a - 2b < 4 + 3$ ，得到答案·
>
> > [!note]- **【解析】**
> > 因为 -2 < b < 1，所以 -2 < -2b < 4
> >
> > 又 $1 < a < 3$ ，故 $-2 + 1 < a - 2b < 4 + 3$ ，即 $-1 < a - 2b < 7$
> >
> > 故答案为： $-1 < a - 2b < 7$
