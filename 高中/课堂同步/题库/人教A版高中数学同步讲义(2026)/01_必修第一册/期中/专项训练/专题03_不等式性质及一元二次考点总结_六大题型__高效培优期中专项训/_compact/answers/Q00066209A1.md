> [!faq]- 《专题03_不等式性质及一元二次考点总结_六大题型__高效培优期中专项训》官方解析
>
> > [!success]- **【答案】** $(-∞,3)$
>
> > [!note]- **【分析】**
> > 分离参数，然后将不等式有解转化为最值问题即可·
>
> > [!note]- **【解析】**
> > 法一：原不等式可化为 $k < \frac{x^2 + 3}{x + 1}$ ，因为不等式在 $[0, 2]$ 有解，所以 $k < \left(\frac{x^2 + 3}{x + 1}\right)_{\max}$ ；
> >
> > 令 $t = x + 1 \in [1,3]$ ，则 $k < \frac{x^2 + 3}{x + 1} = \frac{(t - 1)^2 + 3}{t} = t + \frac{4}{t} - 2$ ；
> >
> > 令 $f(t) = t + \frac{4}{t} - 2$ ，易知 $f(t)$ 在 $[1,2]$ 单调递减，在 $[2,3]$ 单调递增， $f(t)_{\max} = \max \left\{f(1), f(3)\right\} = 3$ ，所以 $k < 3$ .
> >
> > 法二：令 $f(x) = x^{2} - kx - k + 3$ ，则 $f(x)_{\max} > 0$ 即可；
> >
> > 由二次函数在闭区间上的最值可知， $f(x)_{\max} = \max \left\{f(0), f(2)\right\}$
> >
> > 所以 $f(0) > 0$ 或 $f(2) > 0$ ，解得 $k < 3$ 或 $k < \frac{7}{3}$ ，所以 $k < 3$ .
> >
> > 故答案为： $(-\infty ,3)$

> > 48. 命题“ $\forall x \in [-1, 4]$ ， $x^2 - 2x - a > 0$ ”为假命题，则实数 $a$ 的取值范围是（）A. $a = -1$ B. $a \leq 3$ C. $a \leq 8$ D. $a = 8$
> >
> > 【答案】A
> >
> > 【分析】先写出原命题的否定，然后根据存在量词命题的真假性列不等式，由此求得 $a$ 的取值范围·
> >
> > 【详解】依题意，命题“ $\exists x \in [-1, 4]$ ， $x^2 - 2x - a \leq 0$ ”为真命题，
> >
> > 所以 $a(x^{2} - 2x)_{\min}$ ，由于 $x^{2} - 2x = (x - 1)^{2} - 1$
> >
> > 所以当 $x = 1$ 时， $x^{2} - 2x$ 取得最小值为 $-1$
> >
> > 所以 a -1.
> >
> > 故选 **A**
