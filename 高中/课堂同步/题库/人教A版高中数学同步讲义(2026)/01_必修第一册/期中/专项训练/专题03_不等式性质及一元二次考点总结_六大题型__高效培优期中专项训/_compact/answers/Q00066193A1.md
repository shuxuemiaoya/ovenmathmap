> [!faq]- 《专题03_不等式性质及一元二次考点总结_六大题型__高效培优期中专项训》官方解析
>
> > [!success]- **【答案】** D
>
> > [!note]- **【分析】**
> > 首先求出两个不等式的解集，然后根据充分不必要条件的定义求出实数 $a$ 的取值范围
>
> > [!note]- **【解析】**
> > 由题意可得 $1 + \frac{1}{2 - x} \leq 0 \Rightarrow (x - a)^2 < 4$ ，且 $(x - a)^2 < 4$ , $1 + \frac{1}{2 - x} \leq 0$
> >
> > 又 $1 + \frac{1}{2 - x} \leq 0 \Leftrightarrow \frac{3 - x}{2 - x} \leq 0$
> >
> > $\Leftrightarrow \left\{ \begin{array}{l}(x - 2)(x - 3) \leq 0, \\ x - 2 \neq 0 \end{array} \right. \Leftrightarrow 2 < x \leq 3$
> >
> > $$
> > (x - a) ^ {2} <   4 \Leftrightarrow - 2 <   x - a <   2 \Leftrightarrow a - 2 <   x <   a + 2
> > $$
> >
> > 则 $\left\{\begin{aligned}a-2&\leq2\\ 3<a+2\end{aligned}\right.$ 解得 $1<a\leq4$
> >
> > 故选：D.

> > 29. 不等式 $ax^2 + bx + c > 0$ 的解集为 $\left\{x\mid -\frac{1}{2} < x < 3\right\}$ ，则不等式 $cx^2 + bx + a > 0$ 的解集为（）.
> >
> > 【答案】
> >
> > A. $\left\{x \mid x < -2 \text{或} x > \frac{1}{3}\right\}$ B. $\left\{x \mid -2 < x < \frac{1}{3}\right\}$ C. $\left\{x \mid -\frac{1}{3} < x < 2\right\}$ D. $\left\{x \mid x < -\frac{1}{3} \text{或} x > 2\right\}$
> >
> > 【答案】A
> >
> > 【分析】根据一元二次不等式解法以及根与系数的关系即可求得结果
> > 【详解】依题意可知 $-\frac{1}{2}$ 和 $^{3}$ 是方程 $ax^{2} + bx + c = 0$ 的两个实数根，且 a < 0；
> > 因此 $\left\{\begin{aligned}-\frac{1}{2}+3&=-\frac{b}{a}\\-\frac{1}{2}\times3&=\frac{c}{a}\end{aligned}\right.$ ，解得 $\left\{\begin{aligned}b&=-\frac{5}{2}a\\c&=-\frac{3}{2}a\end{aligned}\right.$ 所以不等式 $cx^{2}+bx+a>0$ 可化为 $-\frac{3}{2}ax^{2}-\frac{5}{2}ax+a>0$ ，即 $3x^{2}+5x-2>0$ ，解得 x<-2 或 $x>\frac{1}{3}$ ，即不等式 $cx^{2}+bx+a>0$ 的解集为 $\left\{x\mid x<-2或x>\frac{1}{3}\right\}$
> >
> > 故选 **A**
