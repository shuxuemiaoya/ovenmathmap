> [!faq]- 《专题03_不等式性质及一元二次考点总结_六大题型__高效培优期中专项训》官方解析
>
> > [!success]- **【答案】** BD
>
> > [!note]- **【分析】**
> > 对于 A，根据不等式的解集得到 a > 0 判断 A；对于 B，结合题意得到 -2 和 3 是关于 x 的方程 $ax^{2} + bx + c = 0$ 的两根，再结合韦达定理得到 b = -a, c = -6a，将目标不等式化为 -ax - 6a > 0，求出解集判断 B，对于 C，结合 b = -a, c = -6a 得到 $a + b + c = -6a < 0$ 判断 C，对于 D，将 $cx^{2} - bx + a < 0$ 合理变形后求出解集判断 D 即可.
>
> > [!note]- **【解析】**
> > 对于 A，因为关于 x 的不等式 $ax^{2} + bx + c > 0$ 的解集为 $(-∞, -2) ∪ (3, +∞)$ ，
> > 所以 -2 和 $^{3}$ 是关于 x 的方程 $ax^{2} + bx + c = 0$ 的两根，且 a > 0，故 A 错误；
> > 对于 B，由已知得 -2 和 $^{3}$ 是关于 x 的方程 $ax^{2} + bx + c = 0$ 的两根，
> >
> > 由韦达定理得 $\left\{ \begin{array}{l} -2 + 3 = -\frac{b}{a}\\ -2\times 3 = \frac{c}{a} \end{array} \right.$ ，解得 $b = -a,c = -6a$
> >
> > 对于不等式 $bx + c > 0$ ，即化为 -ax - 6a > 0，解得 x < -6，故 B 正确；
> >
> > $$
> > \mathrm{C}
> > $$
> >
> > $$
> > a + b + c = - 6 a <   0
> > $$
> >
> > 对于 $\mathsf{D}$ ，对于不等式 $cx^{2} - bx + a < 0$ ，可化为 $-6ax^{2} + ax + a < 0$
> >
> > 而 $a > 0$ ，则化为 $6x^{2} - x - 1 > 0$ ，解得 $x\in (-\infty , - \frac{1}{3})\cup (\frac{1}{2}, + \infty)$ ，故D正确.
> >
> > 故选 **BD**
