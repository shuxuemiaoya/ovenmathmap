> [!faq]- 《专题10 指数函数考点大汇总（六大题型）（高效培优期中专项训练）数学人教A版2019高一必修第一册》官方解析
>
> > [!success]- **【答案】** (1) $\left[\frac{3}{4},\frac{37}{16}\right]$ (2) $\sqrt{2}$
>
> > [!note]- **【分析】**
> > （1）化简 $f(x) = \frac{1}{4^x} -\frac{\lambda}{2^{x - 1}} +3 = \left(\frac{1}{2}\right)^{2x} - 2\lambda \cdot \left(\frac{1}{2}\right)^x +3(-1\leq x\leq 2)$ ，再利用换元法得
> >
> > $g(t) = t^2 - 2\lambda t + 3$ （ $\frac{1}{4} \leq t \leq 2$ ），从而代入 $\lambda = \frac{3}{2}$ 求函数的值域；
> >
> > (2) $g(t)=t^{2}-2\lambda t+3=(t-\lambda)^{2}+3-\lambda^{2}\left(\frac{1}{4}\leq t\leq2\right)$ ，讨论 $\lambda$ 以确定函数的最小值及最小值点，从而求 $\lambda$
>
> > [!note]- **【解析】**
> > （1） $f(x)=\frac{1}{4^{x}}-\frac{\lambda}{2^{x-1}}+3=\left(\frac{1}{2}\right)^{2x}-2\lambda\cdot\left(\frac{1}{2}\right)^{x}+3(-1\leq x\leq2)$ ，
> >
> > 设 $t = \left(\frac{1}{2}\right)^x$ ，得 $g(t) = t^2 - 2\lambda t + 3$ （ $\frac{1}{4} \leq t \leq 2$ ）.
> >
> > 当 $\lambda=\frac{3}{2}$ 时， $g(t)=t^{2}-3t+3=\left(t-\frac{3}{2}\right)^{2}+\frac{3}{4}\left(\frac{1}{4}\leq t\leq2\right)$
> >
> > 所以 $g(t)_{\mathrm{max}} = g\left(\frac{1}{4}\right) = \frac{37}{16}$ ， $g(t)_{\mathrm{min}} = g\left(\frac{3}{2}\right) = \frac{3}{4}$ .
> >
> > 所以 $f(x)_{\max} = \frac{37}{16}$ ， $f(x)_{\min} = \frac{3}{4}$ ，
> >
> > 故函数 $f(x)$ 的值域为 $\left[\frac{3}{4},\frac{37}{16}\right]$ .
> >
> > (2) 由 (1) $g(t) = t^2 - 2\lambda t + 3 = (t - \lambda)^2 + 3 - \lambda^2$ ( $\frac{1}{4} \leq t \leq 2$ )
> > - **①**：当 $\lambda \leq \frac{1}{4}$ 时， $g(t)_{\min} = g\left(\frac{1}{4}\right) = -\frac{\lambda}{2} + \frac{49}{16}$ ，
> >
> > 令 $-\frac{\lambda}{2} + \frac{49}{16} = 1$ ，得 $\lambda = \frac{33}{8} > \frac{1}{4}$ ，不符合舍去；
> > - **②**：当 $\frac{1}{4} < \lambda \leq 2$ 时， $g(t)_{\min} = g(\lambda) = -\lambda^2 + 3$
> >
> > 令 $-\lambda^2 + 3 = 1$ ，得 $\lambda = \sqrt{2}$ ，或 $\lambda = -\sqrt{2} < \frac{1}{4}$ ，不符合舍去；
> > - **③**：当 $\lambda > 2$ 时， $g(t)_{\min} = g(2) = -4\lambda + 7$
> >
> > 令 $-4\lambda + 7 = 1$ ，得 $\lambda = \frac{3}{2} < 2$ ，不符合舍去。
> >
> > 综上所述，实数 $\lambda$ 的值为 $\sqrt{2}$
