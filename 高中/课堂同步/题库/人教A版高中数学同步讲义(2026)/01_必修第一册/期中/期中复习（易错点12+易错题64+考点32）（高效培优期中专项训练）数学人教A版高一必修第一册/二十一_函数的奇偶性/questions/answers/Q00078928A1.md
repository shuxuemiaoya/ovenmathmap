> [!faq]- 《期中复习（易错点12+易错题64+考点32）（高效培优期中专项训练）数学人教A版高一必修第一册》官方解析
>
> > [!success]- **【答案】** A. $(-2,2)$ B. $(-∞,-1)∪(0,1)$ C. $(-∞,-2)∪(0,2)$ D. $(-2,0)∪(0,2)$
>
> > [!note]- **【分析】**
> > 先分析出 $f(x)$ 的奇偶性，然后化简不等式并通过分类讨论求解出不等式解集.
>
> > [!note]- **【解析】**
> > 因为 $f(x)$ 的定义域为 R 关于原点对称，
> >
> > $$
> > f (- x) = - x | - x | - 2 (- x) = - x | x | + 2 x = - f (x)
> > $$
> >
> > 所以 $f(x)$ 为奇函数，
> >
> > 所以 $2f(x) + f(-x) < 0 \Leftrightarrow 2f(x) - f(x) < 0 \Leftrightarrow f(x) < 0$
> >
> > 当 x > 0 时， $x^{2} - 2x < 0$ ，解得 0 < x < 2，
> >
> > 当 $x = 0$ 时， $0 < 0$ ，无解，
> >
> > 当 $x < 0$ 时， $-x^{2} - 2x < 0$ ，解得 $x < -2$ 或 $x > 0$ （舍），
> >
> > 综上所述，不等式解集为 $(-∞,-2)∪(0,2)$ ，
> >
> > 故选：C
