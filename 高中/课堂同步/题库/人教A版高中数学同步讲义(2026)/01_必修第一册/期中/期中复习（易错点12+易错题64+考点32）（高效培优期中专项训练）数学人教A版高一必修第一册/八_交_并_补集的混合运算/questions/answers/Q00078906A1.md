> [!faq]- 《期中复习（易错点12+易错题64+考点32）（高效培优期中专项训练）数学人教A版高一必修第一册》官方解析
>
> > [!success]- **【答案】** (1) $A \cup B = \{x \mid x < -1 \text{ 或 } x > 7\}$ ; $A \cap \tilde{\mathbf{Q}}_{\mathrm{R}} B = \{x \mid x < -1 \text{ 或 } x \quad 9\}$ . $$ (- \infty , 4 ] \cup [ 7, + \infty) \tag {2} $$
>
> > [!note]- **【分析】**
> > （1）首先解二次不等式求得集合A，然后将 $a$ 代入确定集合 $B$ ，最后根据集合的交、并、补运算
> >
> > 法则进行求解即可；
> >
> > (2) 首先根据集合间运算的结果可得 $B \subseteq A$ ，然后分 $B = \emptyset$ 和 $B \neq \emptyset$ 两种情况分类讨论求解参数取值范围
> >
> > 即可
>
> > [!note]- **【解析】**
> > （1）由不等式 $x^{2} - 7x - 8 > 0$ ，解得： $x <   - 1$ 或 $x > 8$ ，因此可得： $A = \{x\mid x <   - 1$ 或 $x > 8\}$
> >
> > 将 $a = 6$ 代入集合 $B$ 中可得： $B = \{x \mid 7 < x < 9\}$
> >
> > 因此 $A \cup B = \left\{ x \mid x < -1 \text{ 或 } x > 7 \right\}$ ;
> >
> > 又 $\breve{\partial}_{R}B=\left\{x\mid x\leq7\text{ 或 }x\quad9\right\}$ ，得： $A\cap\breve{\partial}_{R}B=\left\{x\mid x<-1\text{ 或 }x\quad9\right\}$ .
> >
> > (2) 选①由 $B \mathrm{I} \tilde{\mathfrak{Q}}_{\mathrm{R}} A = \varnothing$ ，可知 $B \subseteq A$ ，
> >
> > 当 $B = \emptyset$ 时， $a + 1, 2a - 3$ ，解得： $a \leq 4$ ；
> >
> > 当 $B \neq \emptyset$ 时，可得： $\left\{ \begin{array}{l} a + 1 < 2a - 3 \\ 2a - 3 \leq -1 \end{array} \right.$ ，无解，或 $\left\{ \begin{array}{l} a + 1 < 2a - 3 \\ a + 1 = 8 \end{array} \right.$ ，解得： $a = 7$ ；
> >
> > 综上所述 $a \in (-\infty, 4] \cup [7, +\infty)$ ；
> >
> > 选②由 $A \cap B = B$ ，可知 $B \subseteq A$ ，
> >
> > 当 $B = \emptyset$ 时， $a + 1, 2a - 3$ ，解得： $a \leq 4$ ；
> >
> > 当 $B \neq \emptyset$ 时，可得： $\left\{ \begin{array}{l} a + 1 < 2a - 3 \\ 2a - 3 \leq -1 \end{array} \right.$ ，无解，或 $\left\{ \begin{array}{l} a + 1 < 2a - 3 \\ a + 1 = 8 \end{array} \right.$ ，解得： $a = 7$ ；
> >
> > 综上所述 $a \in (-\infty, 4] \cup [7, +\infty)$ ；
> >
> > 选③由 $A \cup B = A$ ，可知 $B \subseteq A$ ，
> >
> > 当 $B = \emptyset$ 时， $a + 1, 2a - 3$ ，解得： $a \leq 4$ ；
> >
> > 当 $B \neq \emptyset$ 时，可得： $\left\{ \begin{array}{l} a + 1 < 2a - 3 \\ 2a - 3 \leq -1 \end{array} \right.$ ，无解，或 $\left\{ \begin{array}{l} a + 1 < 2a - 3 \\ a + 1 = 8 \end{array} \right.$ ，解得： $a = 7$ ；
> >
> > 综上所述 $a \in (-\infty, 4] \cup [7, +\infty)$ ；
