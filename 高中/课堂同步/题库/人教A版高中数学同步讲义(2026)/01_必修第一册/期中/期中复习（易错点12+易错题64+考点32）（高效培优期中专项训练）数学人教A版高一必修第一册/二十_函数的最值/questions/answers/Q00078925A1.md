> [!faq]- 《期中复习（易错点12+易错题64+考点32）（高效培优期中专项训练）数学人教A版高一必修第一册》官方解析
>
> > [!success]- **【答案】** A
>
> > [!note]- **【分析】**
> > 首先分析函数 $y = x^{2} - 2x + 3$ 的取值情况，从而判断 $c \leq 1$ ，再结合 $c^2 - 2c + 3 \leq 6$ 得到 $-1 \leq c \leq 1$ ，再分 $0 \leq c \leq 1$ 和 $-1 \leq c < 0$ 两种情况讨论，当 $-1 \leq c < 0$ 时结合函数 $y = -\frac{1}{x} + 2$ 在 $(-\infty, c)$ 上的单调性，得到 $-\frac{1}{c} + 2 \leq 6$ ，从而求出 $c$ 的取值范围.
>
> > [!note]- **【解析】**
> > 对于函数 $y = x^{2} - 2x + 3 = (x - 1)^{2} + 2$ ，当 x = 3 时，y = 6，当 x = 1 时，y = 2，
> > 而 $-\frac{1}{x} \neq 0$ ，即有 $-\frac{1}{x} + 2 \neq 2$ ，依题意， $c \leq 1$ ，又 $c^{2} - 2c + 3 \leq 6$ ，解得 $-1 \leq c \leq 3$ ，则 $-1 \leq c \leq 1$ ；
> > 当 $0 \leq c \leq 1$ 时，函数 $f(x)$ 在 $(-∞,0)$ 上的取值集合为 $(2,+∞)$ ，不符合题意，
> > 当 $-1 \leq c < 0$ ，函数 $y = -\frac{1}{x} + 2$ 在 $(-∞,c)$ 上单调递增，
> > 则 $2 < -\frac{1}{x} + 2 < -\frac{1}{c} + 2$ ，所以 $\left\{\begin{aligned}-\frac{1}{c}+2&\leq6\\-1&\leq c<0\end{aligned}\right.$ ，解得 $-1 \leq c \leq -\frac{1}{4}$ ，
> > 所以实数 c 的取值范围是 $[-1, -\frac{1}{4}]$ .
> >
> > 故选 **A**
