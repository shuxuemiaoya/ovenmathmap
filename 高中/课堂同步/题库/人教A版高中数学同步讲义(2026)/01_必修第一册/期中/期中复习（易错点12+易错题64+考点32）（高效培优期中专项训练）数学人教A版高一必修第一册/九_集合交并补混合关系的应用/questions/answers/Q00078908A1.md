> [!faq]- 《期中复习（易错点12+易错题64+考点32）（高效培优期中专项训练）数学人教A版高一必修第一册》官方解析
>
> > [!success]- **【答案】** (1) $A \cap B = \{x \mid 1 < x \leq 2\}$ ， $A \cup B = \{x \mid x - 0\}$ ， $\left(\tilde{\mathfrak{Q}}_{\mathbf{R}} A\right) \cap B = \{x \mid 0 \leq x \leq 1\}$ $C = \{x\mid 0\leq x\leq 1\quad x > 2\}$ (2) 或
>
> > [!note]- **【分析】**
> > （1）根据交、并、补集的运算计算即可；
> >
> > (2) 结合 (1)，根据题意计算即可.
>
> > [!note]- **【解析】**
> > （1）因为 $A=\left\{x \mid x>1\right\}$ ， $B=\left\{x \mid 0 \leq x \leq 2\right\}$ ，
> >
> > 所以 $A \cap B = \{x \mid 1 < x \leq 2\}$ ， $A \cup B = \{x \mid x, 0\}$ ， $(\tilde{\mathbf{Q}}_{\mathbf{R}} A) \cap B = \{x \mid 0 \leq x \leq 1\}$ (2) 因为 $A \cap B = \{x \mid 1 < x \leq 2\}$ ， $A \cup B = \{x \mid x, 0\}$ ，
> > 所以 $C = \{x \mid 0 \leq x \leq 1 \text{ 或 } x > 2\}$ .
