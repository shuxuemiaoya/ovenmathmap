> [!faq]- 《期中复习（易错点12+易错题64+考点32）（高效培优期中专项训练）数学人教A版高一必修第一册》官方解析
>
> > [!success]- **【答案】** (1) $f(x)=\left\{\begin{aligned}&20x^{2}-20x+330,0\leq x\leq2\\ &490-\frac{80}{x-1}-20x,2<x\leq5\end{aligned}\right.$ (2)施用肥料为 3 千克时，该果树的单株利润最大，最大利润是 390 元
>
> > [!note]- **【分析】**
> > （1）根据 $f(x)=10W(x)-(20x+10)$ 可得 $f(x)$ 的解析式.
> >
> > (2) 利用二次函数的性质及基本不等式可求 $f(x)$ 的最大值.
>
> > [!note]- **【解析】**
> > （1）由已知得， $f(x)=10W(x)-(20x+10)$
> >
> > $$
> > W (x) = \left\{ \begin{array}{l} 2 (x ^ {2} + 1 7), 0 \leq x \leq 2 \\ 5 0 - \frac {8}{x - 1}, 2 <   x \leq 5 \end{array} , \right.
> > $$
> >
> > $$
> > \therefore f (x) = \left\{ \begin{array}{l} 2 0 (x ^ {2} + 1 7) - (2 0 x + 1 0), 0 \leq x \leq 2 \\ 5 0 0 - \frac {8 0}{x - 1} - (2 0 x + 1 0), 2 <   x \leq 5 \end{array} , \right.
> > $$
> >
> > 整理得， $f(x)=\left\{\begin{aligned}&20x^{2}-20x+330,0\leq x\leq2\\ &490-\frac{80}{x-1}-20x,2<x\leq5.\end{aligned}\right.$
> >
> > (2) 当 $0 \leq x \leq 2$ 时， $f(x) = 20x^2 - 20x + 330 = 20\left(x - \frac{1}{2}\right)^2 + 325$ ，对称轴为直线 $x = \frac{1}{2}$
> >
> > $$
> > f (x) _ {\max} = f (2) = 3 7 0
> > $$
> >
> > 当 $2 < x \leq 5$ 时， $f(x) = 490 - \frac{80}{x - 1} - 20x = 490 - \left[\frac{80}{x - 1} + 20(x - 1) + 20\right]$
> >
> > $$
> > = 4 7 0 - \left[ \frac {8 0}{x - 1} + 2 0 (x - 1) \right] \leq 4 7 0 - 2 \sqrt {\frac {8 0}{x - 1} \cdot 2 0 (x - 1)} = 3 9 0
> > $$
> >
> > 当且仅当 $\frac{80}{x - 1} = 20(x - 1)$ ，即 $x = 3$ 时等号成立，故 $f(x)_{\mathrm{max}} = 390$
> >
> > ∵370<390，∴ $f(x)$ 的最大值为390，
> >
> > :当施用肥料为 3 千克时，该果树的单株利润最大，最大利润是 390 元。
