> [!faq]- 《专题05+函数值域考点总结（六大题型）（高效培优期中专项训练）数学人教A版2019高一必修第一册》官方解析
>
> > [!success]- **【答案】** A. $A \cup B = \mathbf{R}$ B. $A \cap B = [1, 2)$ C. $A \cap B = \varnothing$ D. $(\tilde{\mathbf{Q}}_R B) \cup A = (-\infty, 2)$
>
> > [!note]- **【分析】**
> > 先求出集合 A 和 B，再根据集合的交集、并集和补集的定义即可直接计算判断各选项·
>
> > [!note]- **【解析】**
> > 要使函数 $y = \frac{1}{\sqrt{2 - x}}$ 有意义，则 $2 - x > 0 \Rightarrow x < 2$ ，
> >
> > 所以 $A = \{x\mid x <   2\}$ ，即 $A = (-\infty ,2)$
> >
> > 因为 $y = x^2 + 1 \quad 1$ ，所以 $B = \{y \mid y = x^2 + 1\} = \{y \mid y - 1\}$ ，即 $B = [1, +\infty)$
> >
> > 所以 $A \cup B = (-\infty, 2) \cup [1, +\infty) = R$ ， $A \cap B = (-\infty, 2) \cap [1, +\infty) = [1, 2)$ ， $\left(\check{\mathbf{Q}}_{\mathrm{R}} B\right) \cup A = (-\infty, 1) \cup (-\infty, 2) = (-\infty, 2)$ ，故ABD正确，C错误.
> >
> > 故选 **ABD**
