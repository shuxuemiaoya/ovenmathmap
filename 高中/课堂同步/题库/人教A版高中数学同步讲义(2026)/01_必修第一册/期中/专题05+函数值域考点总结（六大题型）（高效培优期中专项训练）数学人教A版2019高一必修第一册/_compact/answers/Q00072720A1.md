> [!faq]- 《专题05+函数值域考点总结（六大题型）（高效培优期中专项训练）数学人教A版2019高一必修第一册》官方解析
>
> > [!success]- **【答案】** (1) $(-2\sqrt{3},2\sqrt{3})$ (2) $\left[-7,+\infty\right)$ (3) $a = -1$
>
> > [!note]- **【分析】**
> > （1）由题意可得：对任意的 $x \in \mathbf{R}$ ， $x^2 + ax + 3 \neq 0$ ，结合二次函数分析求解；
> >
> > (2) 由题意可知，不等式 $x^{2} + ax + 3$ a 对任意的 $x \in (1,2]$ ，令 $m = x - 1 \in (0,1]$ ，由参变量分离法可得 $-a \leq m + \frac{4}{m} + 2$ ，利用对勾函数的单调性求出函数 $p(m) = m + \frac{4}{m} + 2$ 在 $(0,1]$ 上的最小值，可得出关于实数 $a$
> >
> > 的不等式，即可得出实数 $a$ 的取值范围；
> >
> > (3) 令 $t = g(x) \quad a + 2$ ，可得 $g(t) = (t + 1)^2 + a + 2(t - a + 2)$ 的最小值是5，分 $a + 2 < -1$ 和 $a + 2 - 1$ 两种情况，结合二次函数最值分析求解.
>
> > [!note]- **【解析】**
> > （1）若函数 $y = \frac{1}{f(x)}$ 的定义域为 $\mathbf{R}$ ，则对任意的 $x \in \mathbb{R}$ ， $x^2 + ax + 3 \neq 0$ ，
> >
> > 由于函数 $f(x)=x^{2}+ax+3$ 为开口向上的二次函数，
> >
> > 故只需要 $\Delta = a^{2} - 12 < 0$ ，解得 $-2\sqrt{3} < a < 2\sqrt{3}$ ，
> >
> > 所以实数 a 的取值范围是 $\left(-2\sqrt{3}, 2\sqrt{3}\right)$ .
> >
> > (2) 任意 $x \in (1,2]$ , $f(x) = x^2 + ax + 3$ a 恒成立, 则 $0 < x - 1 \leq 1$ ,
> >
> > 可得 $-a(x - 1) \leq x^2 + 3$
> >
> > 令 $m = x - 1 \in (0,1]$ ，则 $x = m + 1$ ，所以， $-am \leq (m + 1)^2 + 3 = m^2 + 4 + 2m$
> >
> > 可得 $-a \leq m + \frac{4}{m} + 2$
> >
> > 令 $p(m) = m + \frac{4}{m} + 2$ ，其中 $m \in (0,1]$ ，则函数 $p(m)$ 在 $(0,1]$ 上为减函数，
> >
> > 所以， $p(m)_{\min}=p(1)=7$ ，所以， $-a\leq7$ ，解得a-7.
> >
> > 因此，实数 a 的取值范围是 $\left[-7, +\infty\right)$ .
> >
> > (3) 因为 $g(x)=f(x)-(a-2)x+a=(x+1)^{2}+a+2$ $a+2$
> >
> > 令 $t = g(x)$ $a + 2$ ，则 $y = g[g(x)] = g(t) = (t + 1)^2 + a + 2, t$ $a + 2$
> >
> > 则 $g(t)$ 为开口向上，对称轴为 $t = -1$ 的二次函数，
> >
> > 当 $a + 2 < -1$ ，即 $a < -3$ 时，则 $g(t)$ 在 $[a + 2, - 1)$ 上单调递减，在 $(-1, + \infty)$ 上单调递增，
> >
> > 此时 $g(t)$ $g(-1)=a+2=5$ ，解得 a=3，不符合要求，舍去；
> >
> > 当 $a + 2 - 1$ ，即 $a - 3$ 时，则 $g(t)$ 在 $[a + 2, + \infty)$ 上单调递增，
> >
> > 此时 $g(t)$ $g(a+2)=a^{2}+7a+11=5$ ，解得 a=-1 或 a=-6（舍去）；
> >
> > 综上所述：a = -1。

> >

> > 42. 函数 $f(x) = \sqrt{-x^2 + 5x + 6}$ 在区间 $[1, 5]$ 的最大值为 \_\_\_\_.
> >
> > 【答案】 $\frac{7}{2} / 3.5$
> >
> > 【分析】先求复合函数的单调性，再根据函数单调性求最值即可
> >
> > 【详解】（1）由 $-x^{2} + 5x + 6$ $0\Rightarrow x^2 -5x - 6\leq 0\Rightarrow -1\leq x\leq 6$
> >
> > 所以 $f(x)$ 的定义域 $[-1,6]$
> >
> > 令 $u(x) = -x^2 + 5x + 6 = -\left(x - \frac{5}{2}\right)^2 + \frac{49}{4}$ ，开口向下，对称轴 $x = \frac{5}{2}$
> >
> > 根据复合函数的单调性可知，
> >
> > $f(x)$ 的单调递增区间是 $\left[-1, \frac{5}{2}\right]$ ; 单调递减区间是 $\left[\frac{5}{2}, 6\right]$
> >
> > $f(x)$ 在区间 $[1,5]$ 的最大值为 $f\left(\frac{5}{2}\right) = \frac{7}{2}$
> >
> > 故答案为： $\frac{7}{2}$
