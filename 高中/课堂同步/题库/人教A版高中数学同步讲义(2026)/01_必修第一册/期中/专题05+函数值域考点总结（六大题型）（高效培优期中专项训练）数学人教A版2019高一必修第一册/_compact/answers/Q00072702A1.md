> [!faq]- 《专题05+函数值域考点总结（六大题型）（高效培优期中专项训练）数学人教A版2019高一必修第一册》官方解析
>
> > [!success]- **【答案】** A
>
> > [!note]- **【分析】**
> > 运用二次函数的性质求得 $-2 < x < 0$ 的最小值，再结合幂函数的单调性，由题意列出不等式，求解即可.
>
> > [!note]- **【解析】**
> > 当 $-2 < x < 0$ 时， $f(x) = x^2 + x = \left(x + \frac{1}{2}\right)^2 - \frac{1}{4}$ ，
> >
> > 故当 $x = -\frac{1}{2}$ 时， $f(x)$ 有最小值为 $-\frac{1}{4}$ ；
> >
> > 当 $0 \leq x < c$ 时， $f(x) = -\sqrt{x}$ 单调递减，所以 $-\sqrt{c} < f(x) \leq 0$ ，由题意 $f(x)$ 存在最小值，则 $-\sqrt{c} - \frac{1}{4}$ ，解得 $0 < c \leq \frac{1}{16}$ ，即 $c$ 的最大值为 $\frac{1}{16}$ .
> >
> > 故选 **A**.
