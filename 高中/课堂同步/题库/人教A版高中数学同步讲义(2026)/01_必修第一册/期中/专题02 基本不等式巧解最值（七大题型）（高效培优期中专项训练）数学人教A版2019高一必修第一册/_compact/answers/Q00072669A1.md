> [!faq]- 《专题02 基本不等式巧解最值（七大题型）（高效培优期中专项训练）数学人教A版2019高一必修第一册》官方解析
>
> > [!success]- **【答案】** $2+2\sqrt{2}/2\sqrt{2}+2$
>
> > [!note]- **【分析】**
> > 令 $2 - c = m, c = n, (m > 0, n > 0)$ ，则 $m + n = 2$ ，由此可将 $\frac{4}{a + b} + \frac{a + b}{c}$ 变形为 $\frac{4}{m} + \frac{2}{n} - 1$ ，结合基本不等式，即可求得答案。
>
> > [!note]- **【解析】**
> > 由题意， $a > 0$ ， $b > 0$ ， $c > 0$ ， $a + b + c = 2$ 得： $a + b = 2 - c$
> >
> > 设 $2 - c = m, c = n, (m > 0, n > 0)$ ，则 $m + n = 2$
> >
> > 故 $\frac{4}{a + b} +\frac{a + b}{c} = \frac{4}{2 - c} +\frac{2 - c}{c} = \frac{4}{2 - c} +\frac{2}{c} -1 = \frac{4}{m} +\frac{2}{n} -1$
> >
> > $$
> > = \frac {m + n}{2} \times \left(\frac {4}{m} + \frac {2}{n}\right) - 1 = 3 + \frac {2 n}{m} + \frac {m}{n} - 1 \quad 2 + 2 \sqrt {\frac {2 n}{m} \cdot \frac {m}{n}} = 2 + 2 \sqrt {2}
> > $$
> >
> > 当且仅当 $m^2 = 2n^2$ ，即 $m = 4 - 2\sqrt{2}, n = c = 2\sqrt{2} - 2$ 时取得等号，故 $\frac{4}{a + b} + \frac{a + b}{c}$ 的最小值为 $2 + 2\sqrt{2}$ 故答案为： $2 + 2\sqrt{2}$
