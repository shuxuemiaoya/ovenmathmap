> [!faq]- 《专题02 基本不等式巧解最值（七大题型）（高效培优期中专项训练）数学人教A版2019高一必修第一册》官方解析
>
> > [!success]- **【答案】** A. $a + b < 21$ B. $\frac{a - 6}{b + 1}$ 的最小值为 $-1$ C. $a + 4b$ 的最小值为 12 D. $\frac{1}{a + 2} + \frac{1}{b + 1}$ 的最小值为 $\frac{1}{2}$
>
> > [!note]- **【分析】**
> > 根据题意，化简得到 $(a+2)(b+1)=16$ ，令 $x=a+2, y=b+1$ ，得到 $a+b=x+\frac{16}{x}-3$ ，结合函数 $f(x)=x+\frac{16}{x}$ 单调性，可判定 $^{A}$ 正确；由 $b+1=\frac{16}{a+2}$ ，得到 $\frac{a-6}{b+1}=\frac{a^{2}-4a-12}{16}$ ，结合二次函数的性质，可得判定 $^{B}$ 正确；化简 $a+4b=x+4y-6$ ，利用基本不等式，可得判定 $^{C}$ 不正确；由 $(a+2)(b+1)=16$ ，得到 $\frac{1}{a+2}+\frac{1}{b+1}\sqrt{\frac{1}{a+2}\cdot\frac{1}{b+1}}$ ，可判定 $^{D}$ 正确。
>
> > [!note]- **【解析】**
> > 由 $ab + a + 2b = 14$ ，可得 $(a + 2)(b + 1) = 16$
> >
> > 对于 A 中，令 $x = a + 2, y = b + 1$ ，则 a = x - 2, b = y - 1 且 xy = 16，
> >
> > 可得 $2 < x < 16$ ，则 $a + b = x + y - 3 = x + \frac{16}{x} - 3$
> >
> > 因为函数 $f(x) = x + \frac{16}{x}$ 在(2,4]上单调递减，在[4,16)上单调递增，
> >
> > 可得 $f(x) < f(16) = 17$ ，所以 $a + b = x + y - 3 < 14$ ，所以 A 正确；
> >
> > 对于 $^{B}$ 中，由 $(a+2)(b+1)=16$ ，可得 $b+1=\frac{16}{a+2}$ ，
> >
> > 则 $\frac{a - 6}{b + 1} = (a - 6) \times \frac{a + 2}{16} = \frac{a^2 - 4a - 12}{16} = \frac{(a - 2)^2 - 16}{16}$ ，
> >
> > 当且仅当 $a = 2$ 时， $\frac{a - 6}{b + 1}$ 取得最小值 $-1$ ，所以 ${}^{\mathrm{B}}$ 正确；
> >
> > 对于 C 中，由 $a + 4b = (x - 2) + 4(y - 1) = x + 4y - 6$ $2\sqrt{x \cdot 4y} - 6 = 10$
> >
> > 当且仅当 x=4y 时，即 x=8,y=2 时，即 a=6,b=1 时，等号成立，所以 C 不正确；
> >
> > 对于 D 中，由 $(a+2)(b+1)=16$ ，
> >
> > 可得 $\frac{1}{a + 2} +\frac{1}{b + 1}$ $2\sqrt{\frac{1}{a + 2}\cdot\frac{1}{b + 1}} = 2\sqrt{\frac{1}{16}} = \frac{1}{2}$
> >
> > 当且仅当 $\frac{1}{a + 2} = \frac{1}{b + 1}$ 时，即 $a = 2, b = 3$ 时，等号成立，
> >
> > 所以 $\frac{1}{a + 2} +\frac{1}{b + 1}$ 的最小值为 $\frac{1}{2}$ ，所以D正确
> >
> > 故选 **ABD**.
