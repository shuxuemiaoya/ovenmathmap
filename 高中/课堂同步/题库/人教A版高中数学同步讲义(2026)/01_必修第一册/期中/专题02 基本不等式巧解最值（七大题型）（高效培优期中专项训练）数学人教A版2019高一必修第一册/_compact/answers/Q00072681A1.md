> [!faq]- 《专题02 基本不等式巧解最值（七大题型）（高效培优期中专项训练）数学人教A版2019高一必修第一册》官方解析
>
> > [!success]- **【答案】** $(1)^{3}$ ; $(2)^{9}$ .
>
> > [!note]- **【分析】**
> > （1）依题意可得 $(x + 1)(1 + y) = 4$ ，则 $\frac{1}{x} +\frac{4}{1 + y} = \frac{1}{x} +x + 1$ ，利用基本不等式计算可得；
> >
> > (2) 令 $t = x + 1$ ，则 $\frac{(t - 1)^2 + 7(t - 1) + 10}{t} = t + \frac{4}{t} + 5$ ，利用基本不等式计算可得；
>
> > [!note]- **【解析】**
> > （1）∵x>0，y>0，且 $xy+x+y=3$ ，所以 $(x+1)(1+y)=4$ ，
> >
> > 则 $\frac{1}{x} +\frac{4}{1 + y} = \frac{1}{x} +x + 1$ $2\sqrt{\frac{1}{x}\cdot x} +1 = 3$
> >
> > 当且仅当 $\left\{ \begin{array}{l} x = 1 \\ y = 1 \end{array} \right.$ 时等号成立，因此 $\frac{1}{x} + \frac{4}{1 + y}$ 的最小值为3.
> >
> > (2) 因为 $x > -1$ ，所以 $x + 1 > 0$ ，令 $t = x + 1$ ，所以 $t > 0$ ，
> >
> > 所以 $y=\frac{(t-1)^{2}+7(t-1)+10}{t}=\frac{t^{2}+5t+4}{t}=t+\frac{4}{t}+5$ $2\sqrt{t\cdot\frac{4}{t}}+5=9$
> >
> > 当且仅当 $t = 2$ ，即 $x = 1$ 时等号成立；
> >
> > 所以函数 $y = \frac{x^2 + 7x + 10}{x + 1} (x > -1)$ 的最小值为9.
> >
> > 60. 函数 $f(x) = \frac{2x^2 + x + 3}{x} (x < 0)$ 的最大值为 \_\_\_\_.
> >
> > 【答案】 $1 - 2\sqrt{6} / - 2\sqrt{6} + 1$
> >
> > 【分析】首先化简可得 $f(x) = \frac{2x^2 + x + 3}{x} = 2x + \frac{3}{x} + 1 = -\left(-2x + \frac{3}{-x}\right) + 1$ ，由 $-x > 0$ 则可以利用基本不等式求最值即可·
> >
> > 【详解】因为 x < 0，则 -x > 0，
> > 所以 $f(x)=\frac{2x^{2}+x+3}{x}=2x+\frac{3}{x}+1=-(2x+\frac{3}{-x})+1$ $\leq-2\sqrt{-2x\cdot\frac{3}{-x}}+1=1-2\sqrt{6}$ 当且仅当 $-2x=\frac{3}{-x}$ ，即 $x=-\frac{\sqrt{6}}{2}$ 时等号成立，
> > 所以 $f(x)$ 的最大值为 $1-2\sqrt{6}$ .
> > 故答案为： $1-2\sqrt{6}$
