> [!faq]- 《专题02 基本不等式巧解最值（七大题型）（高效培优期中专项训练）数学人教A版2019高一必修第一册》官方解析
>
> > [!success]- **【答案】** A. $2a + b$ 的最小值为8 B. $\frac{1}{a + 1} + \frac{1}{b + 2}$ 的最小值为 $\frac{\sqrt{2}}{2}$ C. $ab$ 的最大值为8 D. $b + \frac{1}{9 - a}$ 的最小值为 $\frac{6\sqrt{2} - 1}{10}$
>
> > [!note]- **【分析】**
> > A，利用 $b=\frac{18}{a+1}-2$ 变形 $2a+b$ ，利用基本不等式求解即可；B，由 $ab+2a+b=16$ 可得$ab + 2a + b + 2 = 18$ ，利用基本不等式求解即可； $^{C}$ ，利用 $6 = ab + 2a + b \quad ab + 2\sqrt{2ab}$ ，解一元二次不等式即可； $^{D}$ ，原式变形为 $\left(\frac{18}{a+1} + \frac{1}{9-a}\right)\left(\frac{a+1}{10} + \frac{9-a}{10}\right) - 2$ ，利用基本不等式求解即可。
>
> > [!note]- **【解析】**
> > 由 $16 = ab + 2a + b$ 得 $b = \frac{16 - 2a}{a + 1} = \frac{18}{a + 1} -2$
> >
> > 所以 $2a + b = 2a + \frac{16 - 2a}{a + 1} = 2(a + 1) + \frac{18}{a + 1} -4$
> >
> > $$
> > 2 \sqrt {2 (a + 1) \cdot \frac {1 8}{a + 1}} - 4 = 8
> > $$
> >
> > 当且仅当 $2(a + 1) = \frac{18}{a + 1}$ ，即 $a = 2$ 时取等号，
> >
> > 此时 $2a + b$ 取得最小值8，A对；
> >
> > $$
> > a b + 2 a + b = 1 6 \Rightarrow a b + 2 a + b + 2 = 1 8,
> > $$
> >
> > $$
> > \frac {1}{a + 1} + \frac {1}{b + 2} \quad 2 \sqrt {\frac {1}{a + 1} \cdot \frac {1}{b + 2}} = 2 \sqrt {\frac {1}{a b + 2 a + b + 2}} = 2 \sqrt {\frac {1}{1 8}} = \frac {\sqrt {2}}{3}
> > $$
> >
> > 当且仅当 $a + 1 = b + 2$ 时取等号，此时 $\frac{1}{a + 1} +\frac{1}{b + 2}$ 取得最小值 $\frac{\sqrt{2}}{3}$ ，B错；
> >
> > 因为 $16 = ab + 2a + b$ $ab + 2\sqrt{2ab}$ ，当且仅当 $2a = b$ 时取等号，
> >
> > 解不等式得 $-4\sqrt{2} \leq \sqrt{ab} \leq 2\sqrt{2} \Rightarrow ab \leq 8$ ，故 $ab$ 的最大值为 $8$ ， $C$ 对；
> >
> > $$
> > b + \frac {1}{9 - a} = \frac {1 8}{a + 1} + \frac {1}{9 - a} - 2
> > $$
> >
> > $$
> > = \left(\frac {1 8}{a + 1} + \frac {1}{9 - a}\right) \left(\frac {a + 1}{1 0} + \frac {9 - a}{1 0}\right) - 2
> > $$
> >
> > $$
> > = \frac {1 8 (9 - a)}{1 0 (a + 1)} + \frac {a + 1}{1 0 (9 - a)} - \frac {1}{1 0}
> > $$
> >
> > $$
> > 2 \sqrt {\frac {1 8}{1 0 0}} - \frac {1}{1 0} = \frac {6 \sqrt {2} - 1}{1 0}
> > $$
> >
> > 当且仅当 $\frac{18(9 - a)}{10(a + 1)} = \frac{a + 1}{10(9 - a)}$ 即 $a = \frac{163\pm 30\sqrt{2}}{17}$ 时取等号，
> >
> > 此时 $b+\frac{1}{9-a}$ 取得最小值 $\frac{6\sqrt{2}-1}{10}$ ，D正确；
> >
> > 故选 **ACD**.
