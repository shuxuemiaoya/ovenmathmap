> [!faq]- 《专题02 基本不等式巧解最值（七大题型）（高效培优期中专项训练）数学人教A版2019高一必修第一册》官方解析
>
> > [!success]- **【答案】** $\frac{13}{5}$
>
> > [!note]- **【分析】**
> > 利用代换 $^{1}$ 法来，结合基本不等式，即可求解·
>
> > [!note]- **【解析】**
> > 设 $m + n + k = \lambda (3m + 2n) + \mu (1 + 3n)$ ，由对应系数相等得 $\left\{ \begin{array}{l}1 = 3\lambda \\ 1 = 2\lambda +3\mu \\ k = \mu \end{array} \right.$
> >
> > 解得 $\left\{ \begin{array}{l} \lambda = \frac{1}{3} \\ k = \mu = \frac{1}{9} \end{array} \right.$
> >
> > 所以 $m + n + \frac{1}{9} = \frac{1}{3}(3m + 2n) + \frac{1}{9}(1 + 3n)$ ，整理得 $1 = \frac{3}{10}(3m + 2n) + \frac{1}{10}(1 + 3n)$ ，
> >
> > 即 $1 = \frac{1}{10}\left[\left(9m + 6n\right) + (1 + 3n)\right]$
> >
> > 所以 $\frac{3}{3m + 2n} +\frac{2 + 3n}{1 + 3n} = \frac{3}{3m + 2n} +\frac{1}{1 + 3n} +1$
> >
> > $$
> > = \frac {1}{1 0} \left[ (9 m + 6 n) + (1 + 3 n) \right] \left(\frac {3}{3 m + 2 n} + \frac {1}{1 + 3 n}\right) + 1
> > $$
> >
> > $$
> > = 2 + \frac {1}{1 0} \left[ \frac {3 (1 + 3 n)}{3 m + 2 n} + \frac {9 m + 6 n}{1 + 3 n} \right] \quad 2 + \frac {1}{1 0} \cdot 2 \sqrt {\frac {3 (1 + 3 n)}{3 m + 2 n} \cdot \frac {9 m + 6 n}{1 + 3 n}} = \frac {1 3}{5}
> > $$
> >
> > 当且仅当 $\frac{3(1 + 3n)}{3m + 2n} = \frac{9m + 6n}{1 + 3n}$ ，即 $m = n = \frac{1}{2}$ 时等号成立，
> >
> > 所以 $\frac{3}{3m + 2n} +\frac{2 + 3n}{1 + 3n}$ 的最小值是 $\frac{13}{5}$
> >
> > 故答案为： $\frac{13}{5}$
