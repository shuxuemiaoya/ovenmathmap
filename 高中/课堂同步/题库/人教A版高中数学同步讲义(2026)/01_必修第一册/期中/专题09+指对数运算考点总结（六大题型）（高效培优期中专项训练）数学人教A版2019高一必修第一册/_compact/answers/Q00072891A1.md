> [!faq]- 《专题09+指对数运算考点总结（六大题型）（高效培优期中专项训练）数学人教A版2019高一必修第一册》官方解析
>
> > [!success]- **【答案】** $(1)\frac{21}{4}$ ; $(2)0$ ; $(3)\frac{1}{4}$
>
> > [!note]- **【分析】**
> > 运用指数对数运算性质逐个化简计算即可·
>
> > [!note]- **【解析】**
> > （1）计算 $\left(\frac{8}{27}\right)^{-\frac{1}{3}}$ ：根据指数运算法则，可得 $\left(\frac{8}{27}\right)^{-\frac{1}{3}} = \left(\frac{27}{8}\right)^{\frac{1}{3}}$ ，即 $\left(\frac{27}{8}\right)^{\frac{1}{3}} = \left[\left(\frac{3}{2}\right)^3\right]^{\frac{1}{3}} = \frac{3}{2}.$
> >
> > $$
> > 1 0 ^ {\lg 2}: \text { 可得 } 1 0 ^ {\lg 2} = 2
> > $$
> >
> > 计算 $\log_{\frac{1}{9}}\sqrt{3}$ ：设 $\log_{\frac{1}{9}}\sqrt{3} = x$ ，根据对数的定义可得 $(\frac{1}{9})^x = \sqrt{3}$ ，即 $(3^{-2})^x = 3^{\frac{1}{2}}$ ，则 $-2x = \frac{1}{2}$ ，解得 $x = -\frac{1}{4}$
> >
> > 计算 $\log_516\cdot \log_2\sqrt{5}:\log_516\cdot \log_2\sqrt{5} = \frac{\lg 16}{\lg 5}\cdot \frac{\lg\sqrt{5}}{\lg 2} = \frac{\lg 2^4}{\lg 5}\cdot \frac{\lg 5^{\frac{1}{2}}}{\lg 2} = \frac{4\lg 2}{\lg 5}\cdot \frac{\frac{1}{2}\lg 5}{\lg 2} = 2\cdot$
> >
> > 将以上结果相加： $\frac{3}{2}+2-\frac{1}{4}+2=\frac{6+8-1+8}{4}=\frac{21}{4}$
> >
> > (2) 计算 $(\lg2)^{2} + \lg2 \cdot \lg50$ :
> >
> > $$
> > \lg 5 0 = \lg (5 \times 1 0) = \lg 5 + \lg 1 0 = \lg 5 + 1 \text {, 则} (\lg 2) ^ {2} + \lg 2 \cdot \lg 5 0 = (\lg 2) ^ {2} + \lg 2 \cdot (\lg 5 + 1) = \lg 2 (\lg 2 + \lg 5) + \lg 2.
> > $$
> >
> > 又 $\lg 2 + \lg 5 = \lg (2\times 5) = \lg 10 = 1$ ，所以 $\lg 2(\lg 2 + \lg 5) + \lg 2 = \lg 2\times 1 + \lg 2 = 2\lg 2.$
> >
> > 计算 $\lg 25 + \lg 0.01$ ： $\lg 25 = \lg 5^2 = 2\lg 5$ ， $\lg 0.01 = \lg 10^{-2} = -2$ ，则 $\lg 25 + \lg 0.01 = 2\lg 5 - 2$
> >
> > 将两部分结果相加： $2\lg2+2\lg5-2=2(\lg2+\lg5)-2=2\times1-2=0$
> >
> > (3) 对 $a^{\frac{1}{2}} - a^{-\frac{1}{2}} = 1$ 两边平方，可得 $(a^{\frac{1}{2}} - a^{-\frac{1}{2}})^2 = 1^2$ ，即 $a - 2 + a^{-1} = 1$ ，所以 $a + a^{-1} = 3\cdot$
> >
> > 对 $a + a^{-1} = 3$ 两边平方，可得 $(a + a^{-1})^2 = 3^2$ ，即 $a^2 + 2 + a^{-2} = 9$ ，所以 $a^2 + a^{-2} = 7\cdot$
> >
> > 将 $a + a^{-1} = 3$ ， $a^2 +a^{-2} = 7$ 代入 $\frac{a + a^{-1} - 1}{a^2 + a^{-2} + 1}$ ，可得 $\frac{3 - 1}{7 + 1} = \frac{2}{8} = \frac{1}{4}$
