> [!faq]- 《高一数学上学期期中模拟卷_人教A版2019_高效培优_提升卷_》官方解析
>
> > [!success]- **【答案】** (1)答案、证明见解析；(2) $\left[-\frac{3}{2},0\right)$ .
>
> > [!note]- **【解析】**
> > （1）由函数 $f(x) = \frac{x^2 + 1}{ax + b}$ 为奇函数，且 $f(-1) = -2$ ，可得 $f(1) = 2$
> >
> > 则 $\left\{ \begin{array}{l} \frac{2}{-a + b} = -2 \\ \frac{2}{a + b} = 2 \end{array} \right.$ ，解得 $a = 1, b = 0$ ，可得 $f(x) = x + \frac{1}{x}$ ，定义域 $\{x \mid x \neq 0\}$
> >
> > 且 $f(x) + f(-x) = x + \frac{1}{x} + (-x) + \frac{1}{-x} = 0$ ，所以 $f(x)$ 是奇函数，满足题意。
> >
> > 函数 $f(x)$ 在 $(-1,0)$ 、 $(0,1)$ 上单调递减，在 $(-\infty,-1)$ 、 $(1,+\infty)$ 上单调递增，
> >
> > 证明如下：任取 $x_{1}, x_{2} \in (0,1)$ ，且 $x_{1} < x_{2}$
> >
> > $$
> > f \left(x _ {1}\right) - f \left(x _ {2}\right) = \left(x _ {1} + \frac {1}{x _ {1}}\right) - \left(x _ {2} + \frac {1}{x _ {2}}\right) = \left(x _ {1} - x _ {2}\right) \left(\frac {x _ {1} x _ {2} - 1}{x _ {1} x _ {2}}\right)
> > $$
> >
> > 因为 $x_{1}, x_{2} \in (0,1)$ ，且 $x_{1} < x_{2}$ ，所以 $x_{1} - x_{2} < 0 < x_{1}x_{2} < 1$
> >
> > 所以 $x_{1}x_{2}-1<0$ ，所以 $f(x_{1})-f(x_{2})>0$ ，即 $f(x_{1})>f(x_{2})$ ，
> >
> > 所以函数 $f(x)$ 在 $(0,1)$ 上单调递减；
> >
> > 任取 $1 < x_{1} < x_{2}$ ，
> >
> > 则 $f\left(x_{1}\right) - f\left(x_{2}\right) = \left(x_{1} + \frac{1}{x_{1}}\right) - \left(x_{2} + \frac{1}{x_{2}}\right) = \left(x_{1} - x_{2}\right)\left(\frac{x_{1}x_{2} - 1}{x_{1}x_{2}}\right),$
> >
> > 因为 $1 < x_{1} < x_{2}$ ，所以 $x_{1} - x_{2} < 0$ ， $x_{1}x_{2} > 1$ ，所以 $f(x_{1}) - f(x_{2}) < 0$ ，即 $f(x_{1}) < f(x_{2})$
> >
> > 所以函数 $f(x)$ 在 $(1, +\infty)$ 上单调递增；
> >
> > 由对称性， $f(x)$ 在 $(-∞,-1)$ 上单调递增，在 $(-1,0)$ 上单调递减.
> >
> > (2) 由题意，函数 $h(x) = x^2 + \frac{1}{x^2} - 2t\left(x + \frac{1}{x}\right)$ ，令 $z = x + \frac{1}{x}$ ，可得 $y = z^2 - 2tz - 2$
> >
> > 由（1）知函数 $z = x + \frac{1}{x}$ 在 $\left[\frac{1}{2}, 1\right]$ 上单调递减，在 $[1, 2]$ 上单调递增，所以 $z \in \left[2, \frac{5}{2}\right]$
> >
> > 因为函数 $y = z^{2} - 2tz - 2$ 的对称轴方程为 z = t < 0 ，
> >
> > 所以函数 $y = z^{2} - 2tz - 2$ 在 $\left[2, \frac{5}{2}\right]$ 上单调递增，
> >
> > 当 z = 2 时， $y = z^{2} - 2tz - 2$ 取得最小值， $y_{\min} = -4t + 2$ ；
> >
> > 当 $z = \frac{5}{2}$ 时， $y = z^2 - 2tz - 2$ 取得最大值， $y_{\max} = -5t + \frac{17}{4}$ .
> >
> > 所以 $h(x)_{\min} = -4t + 2, h(x)_{\max} = -5t + \frac{17}{4}$
> >
> > 对任意的 $\forall x_{1}, x_{2} \in \left[\frac{1}{2}, 2\right]$ 都有 $\left|h(x_{1}) - h(x_{2})\right| \leq \frac{15}{4}$ 恒成立，
> >
> > 所以 $h(x)_{\mathrm{max}} - h(x)_{\mathrm{min}} \leq \frac{15}{4}$ ，即 $-5t + \frac{17}{4} - (-4t + 2) \leq \frac{15}{4}$ ，解得 $t - \frac{3}{2}$ ，
> >
> > 又因为 $t < 0$ ，所以 $-\frac{3}{2} \leq t < 0$ ，所以实数 $t$ 的取值范围是 $\left[-\frac{3}{2}, 0\right)$
