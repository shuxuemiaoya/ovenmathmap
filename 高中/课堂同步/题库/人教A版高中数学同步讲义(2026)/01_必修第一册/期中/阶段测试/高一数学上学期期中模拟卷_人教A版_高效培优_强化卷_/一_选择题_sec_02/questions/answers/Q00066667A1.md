> [!faq]- 《高一数学上学期期中模拟卷_人教A版_高效培优_强化卷_》官方解析
>
> > [!success]- **【答案】** A. $f(a^{2}) < f(b^{2}) < f(\frac{1}{a^{2}}) < f(\frac{1}{b^{2}})$ B. $f(\frac{1}{a^{2}}) < f(\frac{1}{b^{2}}) < f(b^{2}) < f(a^{2})$ C. $f(a^{2}) < f(b^{2}) < f(\frac{1}{b^{2}}) < f(\frac{1}{a^{2}})$ D. $f(\frac{1}{a^{2}}) < f(a^{2}) < f(\frac{1}{b^{2}}) < f(b^{2})$
>
> > [!note]- **【解析】**
> > 因 $f(x)=x^{\frac{1}{2}}$ 在 $(0,+\infty)$ 上单调递增，
> >
> > 由 $0 < a < b < 1$ ，可得 $0 < a^2 < b^2 < 1 < \frac{1}{b^2} < \frac{1}{a^2}$
> >
> > 故 $f(a^{2}) < f(b^{2}) < f\left(\frac{1}{b^{2}}\right) < f\left(\frac{1}{a^{2}}\right)$ .
> >
> > 故选：C.
