> > 4. 不等式 $\left(\frac{1}{2} - x\right)\left(\frac{1}{3} - x\right) > 0$ 的解集是（ ）A. $\left\{x \mid \frac{1}{3} < x < \frac{1}{2}\right\}$ B. $\left\{x \mid x > \frac{1}{2}\right\}$ C. $\left\{x \mid x < \frac{1}{3}\right\}$ D. $\left\{x \mid x < \frac{1}{3} \text{或} x > \frac{1}{2}\right\}$
> >
> > 【答案】D
> >
> > 【详解】由 $\left(\frac{1}{2} - x\right)\left(\frac{1}{3} - x\right) > 0$ ，可得： $\left(x - \frac{1}{2}\right)\left(x - \frac{1}{3}\right) > 0$
> >
> > 解得： $x > \frac{1}{2}$ 或 $x < \frac{1}{3}$ ，即 $\left\{x\mid x <   \frac{1}{3}\text{或} x > \frac{1}{2}\right\}$
> >
> > 故选 **D**
