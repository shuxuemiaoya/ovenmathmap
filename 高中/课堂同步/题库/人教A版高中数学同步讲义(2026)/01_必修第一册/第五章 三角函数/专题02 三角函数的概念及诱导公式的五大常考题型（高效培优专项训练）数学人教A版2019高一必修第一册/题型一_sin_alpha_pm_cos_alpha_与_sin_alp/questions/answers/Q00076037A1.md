> [!faq]- 《专题02 三角函数的概念及诱导公式的五大常考题型（高效培优专项训练）数学人教A版2019高一必修第一册》官方解析
>
> > [!success]- **【答案】** $\frac{23}{32}$
>
> > [!note]- **【解析】**
> > $\sin^4 x + \cos^4 x = (\sin^2 x + \cos^2 x)^2 - 2\sin^2 x\cos^2 x = 1 - 2(\sin x\cos x)^2$
> >
> > $\left(\sin x + \cos x\right)^2 = \sin^2 x + \cos^2 x + 2\sin x\cos x = 1 + 2\sin x\cos x = \frac{1}{4}$
> >
> > 所以 $\sin x \cos x = \frac{3}{8}$ ，所以 $1 - 2(\sin x \cos x)^{2} = \frac{23}{32}$ ，
> >
> > 故答案为： $\frac{23}{32}$
