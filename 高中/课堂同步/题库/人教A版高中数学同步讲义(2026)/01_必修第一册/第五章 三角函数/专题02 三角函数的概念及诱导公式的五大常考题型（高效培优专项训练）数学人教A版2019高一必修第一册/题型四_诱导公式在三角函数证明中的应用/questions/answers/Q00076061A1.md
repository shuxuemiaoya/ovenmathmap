> [!faq]- 《专题02 三角函数的概念及诱导公式的五大常考题型（高效培优专项训练）数学人教A版2019高一必修第一册》官方解析
>
> > [!success]- **【答案】** C
>
> > [!note]- **【解析】**
> > 由角 $\alpha$ 和 $\beta$ 的终边关于 x 轴对称，可得 $\alpha = -\beta + 2k\pi, k \in Z$ ，对于 A，由 $\sin \alpha = \sin (-\beta + 2k\pi) = -\sin \beta$ ，故 A 错误；
> >
> > 对于 B，由 $\tan \alpha = \tan (-\beta + 2k\pi) = \tan (-\beta) = -\tan \beta$ ，故 B 错误；
> >
> > 对于 C，由 $\sin \left( \frac{\pi}{2} + \alpha \right) = \cos \alpha = \cos (-\beta + 2k\pi) = \cos (-\beta) = \cos \beta$ ，故 C 正确，
> >
> > 对于 D，由 $\cos (\pi - \alpha) = -\cos \alpha = -\cos (-\beta + 2k\pi) = -\cos \beta$ ，故 D 错误，
> >
> > 故选 **C**.
