> [!faq]- 《专题02 三角函数的概念及诱导公式的五大常考题型（高效培优专项训练）数学人教A版2019高一必修第一册》官方解析
>
> > [!success]- **【答案】** C
>
> > [!note]- **【解析】**
> > 解：由 $\frac{\cos(-\theta)}{\sqrt{1 + \tan^2(\pi + \theta)}} + \frac{\sin(\pi - \theta)}{\sqrt{1 + \cot^2(2\pi - \theta)}} = -1$ ，得 $\frac{\cos\theta}{\sqrt{1 + \tan^2\theta}} + \frac{\sin\theta}{\sqrt{1 + \cot^2\theta}} = -1$ $\frac{\cos\theta}{\sqrt{1 + \frac{\sin^2\theta}{\cos^2\theta}}} + \frac{\sin\theta}{\sqrt{1 + \frac{\cos^2\theta}{\sin^2\theta}}} = -1$ ， $\frac{\cos\theta}{\sqrt{\frac{1}{\cos^2\theta}}} + \frac{\sin\theta}{\sqrt{\frac{1}{\sin^2\theta}}} = -1$ ，
> > 所以 $\cos\theta|\cos\theta| + \sin\theta|\sin\theta| = -1$
> >
> > 所以 $\left\{\begin{aligned}\sin\theta<0\\ \cos\theta<0\end{aligned}\right.$ ，所以 $\theta$ 属于第三象限的角，
> >
> > 故选 **C**
