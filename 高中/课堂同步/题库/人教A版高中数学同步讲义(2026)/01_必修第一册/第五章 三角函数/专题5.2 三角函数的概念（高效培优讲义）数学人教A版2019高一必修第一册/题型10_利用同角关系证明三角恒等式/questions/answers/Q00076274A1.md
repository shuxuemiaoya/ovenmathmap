> [!faq]- 《专题5.2 三角函数的概念（高效培优讲义）数学人教A版2019高一必修第一册》官方解析
>
> > [!success]- **【答案】** 证明见解析· $$ \text {
>
> > [!note]- **【解析】**
> > 左边} = \frac {\cos^ {2} \alpha + \sin^ {2} \alpha - 2 \sin \alpha \cos \alpha}{(\cos \alpha - \sin \alpha) (\cos \alpha + \sin \alpha)} = \frac {(\cos \alpha - \sin \alpha) ^ {2}}{(\cos \alpha - \sin \alpha) (\cos \alpha + \sin \alpha)} = \frac {\cos \alpha - \sin \alpha}{\cos \alpha + \sin \alpha} = \frac {1 - \tan \alpha}{1 + \tan \alpha} = \text {右边}
> > $$
> >
> > 所以 $\frac{1-2\sin\alpha\cos\alpha}{\cos^{2}\alpha-\sin^{2}\alpha}=\frac{1-\tan\alpha}{1+\tan\alpha}$
> >
> > $$
> > \text {【变式3】求证:} \frac {\sin x}{1 + \cos x} - \frac {\cos x}{1 + \sin x} = \frac {2 (\sin x - \cos x)}{1 + \sin x + \cos x}.
> > $$
> >
> > 【答案】证明见解析
> >
> > $$
> > \text {
> > 【详解】方法一：左边} = \frac {\sin x + \sin^ {2} x - \cos x - \cos^ {2} x}{(1 + \cos x) (1 + \sin x)}
> > $$
> >
> > $$
> > \begin{array}{r l} & = \frac {(\sin x - \cos x) (1 + \sin x + \cos x)}{1 + \sin x + \cos x + \cos x \sin x} \\ & = \frac {2 (\sin x - \cos x) (1 + \sin x + \cos x)}{1 + \sin^ {2} x + \cos^ {2} x + 2 \sin x + 2 \cos x + 2 \cos x \sin x} \\ & = \frac {2 (\sin x - \cos x) (1 + \sin x + \cos x)}{(1 + \sin x + \cos x) ^ {2}} \\ & = \frac {2 (\sin x - \cos x)}{1 + \sin x + \cos x} \end{array}
> > $$
> >
> > =右边.
> >
> > 方法二:左边
> >
> > $$
> > = \frac {1 + \sin x + \cos x}{1 + \sin x + \cos x} \left(\frac {\sin x}{1 + \cos x} - \frac {\cos x}{1 + \sin x}\right)
> > $$
> >
> > $$
> > = \frac {1}{1 + \sin x + \cos x} \left[ \frac {\sin x (1 + \sin x + \cos x)}{1 + \cos x} - \frac {\cos x (1 + \sin x + \cos x)}{1 + \sin x} \right]
> > $$
> >
> > $$
> > = \frac {1}{1 + \sin x + \cos x} \left(\sin x + \frac {\sin^ {2} x}{1 + \cos x} - \cos x - \frac {\cos^ {2} x}{1 + \sin x}\right)
> > $$
> >
> > $$
> > = \frac {1}{1 + \sin x + \cos x} (\sin x + 1 - \cos x - \cos x - 1 + \sin x)
> > $$
> >
> > $$
> > = \frac {2 (\sin x - \cos x)}{1 + \sin x + \cos x}
> > $$
> >
> > =右边.
