> [!faq]- 《专题5.2 三角函数的概念（高效培优讲义）数学人教A版2019高一必修第一册》官方解析
>
> > [!success]- **【答案】** $^{(1)}$ 定义域为 $(-17,17)$ ，奇函数，证明见解析； (2) $(0,1)\cup(15,17)$
>
> > [!note]- **【解析】**
> > （1）要使 $f(x)$ 有意义，需满足 $\frac{17 + x}{17 - x} > 0$ ，解得-17 < x < 17
> >
> > 故 $f(x)$ 定义域为 $(-17,17)$ .
> >
> > 判断 $f(x)$ 是奇函数·
> >
> > 证明： $f(x)$ 定义域为 $(-17,17)$ ，关于原点对称；
> >
> > $$
> > f (- x) = \log_ {a} \frac {1 7 + (- x)}{1 7 - (- x)} = \log_ {a} \frac {1 7 - x}{1 7 + x} = \log_ {a} \left(\frac {1 7 + x}{1 7 - x}\right) ^ {- 1}
> > $$
> >
> > $= -\log_{a}\frac{17 + x}{17 - x} = -f(x)$
> >
> > 所以 $f(x)$ 为奇函数；
> >
> > (2) 由 $f(a + \cos^2 x - 1) + f(2\sin x - 3\sqrt{a + 1}) > 0$ ，得 $f(a + \cos^2 x - 1) > -f(2\sin x - 3\sqrt{a + 1})$
> >
> > 由（1）知 $f(x)$ 为奇函数，则 $-f(2\sin x - 3\sqrt{a + 1}) = f(-2\sin x + 3\sqrt{a + 1})$
> >
> > 所以 $f\left(a + \cos^2 x - 1\right) > f\left(-2\sin x + 3\sqrt{a + 1}\right)$
> >
> > 因为 $f(x) = \log_a\frac{17 + x}{17 - x} = \log_a\left(\frac{34}{17 - x} -1\right)$
> >
> > 令 $u = \frac{34}{17 - x} - 1$ ，则 $u = \frac{34}{17 - x} - 1$ 在 $(-17, 17)$ 上单调递增，
> >
> > 当 $0 < a < 1$ 时， $y = \log_a x$ 单调递减，
> >
> > 由复合函数单调性可知， $f(x)$ 在 $(-17,17)$ 上单调递减，
> >
> > 则要使 $-17 < a + \cos^{2}x - 1 < -2\sin x + 3\sqrt{a + 1} < 17$ 恒成立，
> >
> > 即 $\left\{ \begin{array}{l}a + \cos^2 x - 1 > -17\\ -2\sin x + 3\sqrt{a + 1} < 17\\ a + \cos^2 x - 1 <   - 2\sin x + 3\sqrt{a + 1} \end{array} \right.$ 恒成立，
> >
> > 即要使 $a > -17 + \sin^2 x$ ①， $3\sqrt{a + 1} < 17 + 2\sin x$ ②， $a - 3\sqrt{a + 1} < \sin^2 x - 2\sin x$ ③均恒成立.
> >
> > 由 0 < a < 1 ，不等式①②显然恒成立，
> >
> > $$
> > \text {由} \left(\sin^ {2} x - 2 \sin x\right) _ {\min} = \left[ (\sin x - 1) ^ {2} - 1 \right] _ {\min} = - 1,
> > $$
> >
> > 且当 $0 < a < 1$ 时， $a - 3\sqrt{a + 1} < 1 - 3 = -2 < -1$
> >
> > 故不等式③也恒成立，
> >
> > 故当 $0 < a < 1$ 时，即对于任意的 $x \in \mathbf{R}$ ， $f(a + \cos^2 x - 1) + f(2\sin x - 3\sqrt{a + 1}) > 0$ 恒成立。
> >
> > 当 $a > 1$ 时， $y = \log_a x$ 单调递增，则 $f(x)$ 在 $(-17, 17)$ 上单调递增，
> >
> > 则 $-17 < -2\sin x + 3\sqrt{a + 1} < a + \cos^2 x - 1 < 17$ 恒成立，
> >
> > 由 $\left\{ \begin{array}{l}a + \cos^2 x - 1 <   17\\ -2\sin x + 3\sqrt{a + 1} > - 17\\ a + \cos^2 x - 1 > - 2\sin x + 3\sqrt{a + 1} \end{array} \right.$
> >
> > 即 $a < 17 + \sin^{2} x$ ①， $3\sqrt{a+1} > -17 + 2\sin x$ ②， $a - 3\sqrt{a+1} > \sin^{2} x - 2\sin x$ ③ 均恒成立
> >
> > 当 $a > 1$ 时，
> >
> > 要使 $a < 17 + \sin^2 x$ ①恒成立，则 $a < (17 + \sin^2 x)_{\min} = 17$ ，则 $1 < a < 17$
> >
> > 不等式②显然恒成立；
> >
> > 要使不等式③恒成立得， $a - 3\sqrt{a + 1} >\left(\sin^2 x - 2\sin x\right)_{\max} = \left[\left(\sin x - 1\right)^2 -1\right]_{\max} = 3$
> >
> > 由 $a - 3\sqrt{a + 1} >3$ 解得 $a > 15$
> >
> > 故当 $a > 1$ 时，要使①②③均恒成立，则 $15 < a < 17$
> >
> > 综上所述，实数 a 的取值范围为 $(0,1)\cup(15,17)$ .
