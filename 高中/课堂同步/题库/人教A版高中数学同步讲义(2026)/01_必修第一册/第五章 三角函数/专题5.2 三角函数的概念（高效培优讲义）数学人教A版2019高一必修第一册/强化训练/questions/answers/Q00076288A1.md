> [!faq]- 《专题5.2 三角函数的概念（高效培优讲义）数学人教A版2019高一必修第一册》官方解析
>
> > [!success]- **【答案】** $(1)\left[0,2\right]$ ; $(2)$ $\sin x - \cos x = -\frac{7}{5}$
>
> > [!note]- **【解析】**
> > （1）集合 $B = \{x\mid -2\leq x\leq 5\}$ ，而 $A = \{x\mid a + 1\leq x\leq 2a + 1\}$ 必为非空集合，
> >
> > 因为 $x \in A$ 是 $x \in B$ 的充分不必要条件，则集合 A 是集合 B 的真子集，
> >
> > 所以 $\left\{\begin{aligned}a+1&\leq2a+1\\ -2&\leq a+1\\ 2a+1&\leq5\end{aligned}\right.$ （等号不同时成立），解得 $0\leq a\leq2$ ，所以实数 a 的取值范围为 $[0,2]$ .
> >
> > (2) 因为 $\sin x + \cos x = \frac{1}{5}$ ，两边平方得 $1 + 2\sin x\cos x = \frac{1}{25}$
> >
> > 有 $2\sin x\cos x = -\frac{24}{25}$ ，所以 $(\sin x - \cos x)^2 = 1 - 2\sin x\cos x = \frac{49}{25}$
> >
> > 又因为 $-\frac{\pi}{2} < x < 0$ ，所以 $\sin x < 0, \cos x > 0$ ，则 $\sin x - \cos x < 0$ ，
> >
> > 所以 $\sin x - \cos x = -\frac{7}{5}$
