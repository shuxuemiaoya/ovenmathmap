> [!faq]- 《专题5.3 诱导公式（高效培优讲义）数学人教A版2019高一必修第一册》官方解析
>
> > [!success]- **【答案】** A. $\sin C = \frac{\sqrt{2}}{2}$ B. $\sin A = \cos B$ C. $\cos C = \frac{\sqrt{2}}{2}$ D. $\sin 2A = \sin 2B$
>
> > [!note]- **【解析】**
> > 在非等腰中， $A \neq B$ ， $\left\{\begin{aligned}0 &< A < \pi \\ 0 &< B < \pi \\ 0 &< A + B < \pi\end{aligned}\right.$ ，由 $\sin4A = \sin4B$
> >
> > 得 $4A + 4B = \pi$ 或 $4A + 4B = 3\pi$ 或 $4A = 4B + 2\pi (0 < B < \frac{\pi}{4})$ 或 $4B = 4A + 2\pi (0 < A < \frac{\pi}{4})$
> >
> > 即 $A + B = \frac{\pi}{4}$ 或 $A + B = \frac{3\pi}{4}$ 或 $A = B + \frac{\pi}{2} (0 < B < \frac{\pi}{4})$ 或 $B = A + \frac{\pi}{2} (0 < A < \frac{\pi}{4})$
> >
> > 当 $A + B = \frac{3\pi}{4}$ 时， $C = \frac{\pi}{4}$ ，则 $\sin C = \frac{\sqrt{2}}{2}$ ， $\cos C = \frac{\sqrt{2}}{2}$ ，即 AC 可能正确；
> >
> > 当 $A = B + \frac{\pi}{2}(0 < B < \frac{\pi}{4})$ 时， $\sin A = \sin(B + \frac{\pi}{2}) = \cos B$ ，B 可能正确；
> >
> > 对于 D，要 $\sin2A=\sin2B$ ，而 $A\neq B$ ，则必有 $2A+2B=\pi$ ，即 $A+B=\frac{\pi}{2}$ ，不成立，D 错误。
> >
> > 故选 **D**
