> [!faq]- 《专题03正弦函数、余弦函数的图像与性质的五大常考题型（高效培优专项训练）数学人教A版2019高一必修第一册》官方解析
>
> > [!success]- **【答案】** (1)-3 (2) $a=1-\sqrt{7}$ 或 5 ;
>
> > [!note]- **【解析】**
> > （1）当 $a = 1$ 时， $f(x) = \sin^2 x + \cos x - 2 = -\cos^2 x + \cos x - 1 = -\frac{\pi}{6}\cos x - \frac{1}{2}\frac{\ddot{o}^2}{\dot{\varphi}} - \frac{3}{4}$ ，
> >
> > 因为 $-1 \leq \cos x \leq 1$ ，
> >
> > 所以当 $\cos x = -1$ 时，函数有最小值，最小值为 $f(-1) = -\frac{\mathrm{ae}}{\mathrm{e}} - 1 - \frac{1}{2} \frac{\ddot{\mathrm{o}}^{2}}{\dot{\varphi}} - \frac{3}{4} = -3$
> >
> > (2) 因为 $f(x)=\sin^{2}x+a\cos x-\frac{1}{2}a-\frac{3}{2}=-\cos^{2}x+a\cos x-\frac{a+1}{2}=-\frac{\pi}{6}\cos x-\frac{1}{2}a\frac{\ddot{o}^{2}}{\dot{\varphi}}+\frac{a^{2}-2a-2}{4}$
> >
> > 当 $-1 \leq \frac{a}{2} \leq 1$ ，即 $-2 \leq a \leq 2$ 时，
> >
> > 则当 $\cos x = \frac{a}{2}$ 时，函数的最大值为 $\frac{a^2 - 2a - 2}{4} = 1$
> >
> > 解得 $a = 1 + \sqrt{7} > 2$ （舍去），或 $a = 1 - \sqrt{7}$
> >
> > 当 $\frac{a}{2} > 1$ 即 $a > 2$ 时，则当 $\cos x = 1$ 时，函数有最大值，即 $1 = -1 + a - \frac{a + 1}{2}$ ，解得 $a = 5$ ；
> >
> > 当 $\frac{a}{2} < -1$ 时，即 $a < -2$ 时，则当 $\cos x = -1$ 时，函数有最大值，
> >
> > 即 $1=-1-a-\frac{a+1}{2}$ ，解得 $a=-\frac{5}{3}$ （舍去）.
> >
> > 综上， $a=1-\sqrt{7}$ 或 5.
