> [!faq]- 《专题03正弦函数、余弦函数的图像与性质的五大常考题型（高效培优专项训练）数学人教A版2019高一必修第一册》官方解析
>
> > [!success]- **【答案】** $\frac{5}{4}$ $\frac{350}{9} / 38\frac{1}{9}$
>
> > [!note]- **【解析】**
> > 函数 $f(x) = 3^{[\sin x]} + 4^{[\cos x]}$ ，则 $f\left(\frac{5\pi}{6}\right) = 3^{\left[\sin \frac{5\pi}{6}\right]} + 4^{\left[\cos \frac{5\pi}{6}\right]} = 3^{\left[\frac{1}{2}\right]} + 4^{\left[-\frac{\sqrt{3}}{2}\right]} = 3^0 + 4^{-1} = \frac{5}{4}$ ；
> >
> > $f(x + 2\pi) = 3^{[\sin (x + 2\pi)]} + 4^{[\cos (x + 2\pi)]} = 3^{[\sin x]} + 4^{[\cos x]} = f(x)$ ，因此函数 $f(x)$ 的周期为 $2\pi$
> >
> > 则 $\{y \mid y = f(x), x \in \mathbb{R}\} = \{y \mid y = f(x), x \in [0, 2\pi)\}$
> >
> > 当 $x = 0$ 时， $f(0) = 3^0 + 4^1 = 5$ ；当 $0 < x < \frac{\pi}{2}$ 时， $0 < \sin x < 1, 0 < \cos x < 1$ ， $f(x) = 3^0 + 4^0 = 2$ ；
> >
> > 当 $x = \frac{\pi}{2}$ 时， $f(\frac{\pi}{2}) = 3^1 + 4^0 = 4$ ；当 $\frac{\pi}{2} < x \leq \pi$ 时， $0 \leq \sin x < 1, -1 \leq \cos x < 0$ ， $f(x) = 3^0 + 4^{-1} = \frac{5}{4}$ ；
> >
> > 当 $\pi < x < \frac{3\pi}{2}$ 时， $-1 < \sin x < 0, -1 < \cos x < 0$ ， $f(x) = 3^{-1} + 4^{-1} = \frac{7}{12}$ ；
> >
> > 当 $\frac{3\pi}{2} \leq x < 2\pi$ 时， $-1 \leq \sin x < 0, 0 \leq \cos x < 1$ ， $f(x) = 3^{-1} + 4^0 = \frac{4}{3}$ ，
> >
> > 因此 $B=\left\{\frac{7}{12},\frac{5}{4},\frac{4}{3},2,4,5\right\}$ ， $\frac{7}{12}\times\frac{5}{4}\times\frac{4}{3}\times2\times4\times5=\frac{350}{9}$
> >
> > 所以集合 $_{B}$ 中所有元素之积为 $\frac{350}{9}$ .
> >
> > 故答案为： $\frac{5}{4}$ ； $\frac{350}{9}$
