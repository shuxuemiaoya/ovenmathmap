> [!faq]- 《专题03正弦函数、余弦函数的图像与性质的五大常考题型（高效培优专项训练）数学人教A版2019高一必修第一册》官方解析
>
> > [!success]- **【答案】** $\frac{3}{2}$ $\left\{1, \frac{3}{2}, 2, 3\right\}$
>
> > [!note]- **【解析】**
> > 因为 $f(x)=2^{\left[\sin x\right]}+2^{\left[\cos x\right]}$
> >
> > 所以 $f\left(\frac{5\pi}{6}\right) = 2^{\left[\sin \frac{5\pi}{6}\right]} + 2^{\left[\cos \frac{5\pi}{6}\right]} = 2^{\left[\frac{1}{2}\right]} + 2^{\left[-\frac{\sqrt{3}}{2}\right]} = 1 + \frac{1}{2} = \frac{3}{2}$
> >
> > $\sin x = 1$ ， $\cos x = 0$ 或 $\sin x = 0$ ， $\cos x = 1$ 时， $f(x) = 2^{[\sin x]} + 2^{[\cos x]} = 3$
> >
> > $\sin x = -1$ ， $\cos x = 0$ 或 $\sin x = 0$ ， $\cos x = -1$ 时， $f(x) = 2^{[\sin x]} + 2^{[\cos x]} = \frac{3}{2}$ ；
> >
> > $0 < \sin x < 1$ ， $0 < \cos x < 1$ 时， $f(x) = 2^{[\sin x]} + 2^{[\cos x]} = 2;$
> >
> > $0 < \sin x < 1$ ， $-1 < \cos x < 0$ 或 $-1 < \sin x < 0$ ， $0 < \cos x < 1$ 时， $f(x) = 2^{[\sin x]} + 2^{[\cos x]} = \frac{3}{2}$
> >
> > $-1 < \sin x < 0$ ， $-1 < \cos x < 0$ 时， $f(x) = 2^{[\sin x]} + 2^{[\cos x]} = 1$
> >
> > 所以 $f(x)$ 的值域为 $\left\{1,\frac{3}{2},2,3\right\}$ .
> >
> > 故答案为： $\frac{3}{2}$ ， $\left\{1,\frac{3}{2},2,3\right\}$ .
> >
> > 46. 函数 $y = \cos \left( x + \frac{\pi}{6} \right), x \in \left[ 0, \frac{\pi}{2} \right]$ 的值域是 \_\_\_\_.
> >
> > 【答案】 $\left[-\frac{1}{2},\frac{\sqrt{3}}{2}\right]$
> >
> > 【详解】 $\because 0\leq x\leq \frac{\pi}{2}$ ， $\therefore \frac{\pi}{6}\leq x + \frac{\pi}{6}\leq \frac{2\pi}{3}$
> >
> > $$
> > \therefore \cos \frac {2 \pi}{3} \leq \cos \left(x + \frac {\pi}{6}\right) \leq \cos \frac {\pi}{6}
> > $$
> >
> > $\therefore -\frac{1}{2} \leq y \leq \frac{\sqrt{3}}{2}$ ，即值域为 $\left[-\frac{1}{2}, \frac{\sqrt{3}}{2}\right]$
> >
> > 故答案为： $\left[-\frac{1}{2},\frac{\sqrt{3}}{2}\right]$
