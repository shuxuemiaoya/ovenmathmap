> [!faq]- 《专题03正弦函数、余弦函数的图像与性质的五大常考题型（高效培优专项训练）数学人教A版2019高一必修第一册》官方解析
>
> > [!success]- **【答案】** 2024
>
> > [!note]- **【解析】**
> > 设 $g(x) = 2025\sin x + 2025\ln \left(x + \sqrt{x^2 + 1}\right)$ ，则 $g(-x) = 2025\sin (-x) + 2025\ln \left(-x + \sqrt{x^2 + 1}\right)$ ， $g(-x) + g(x) = 2025\sin (-x) + 2025\ln \left(-x + \sqrt{x^2 + 1}\right) + 2025\sin x + 2025\ln (x + \sqrt{x^2 + 1})$ $= 2025[\sin (-x) + \sin x] + 2025\ln \left[(-x + \sqrt{x^2 + 1})(x + \sqrt{x^2 + 1})\right] = 0$ ，
> >
> > 所以 $g(x)$ 是奇函数， $f(-2025) = g(-2025) + 2025 = 2026$ ，则 $g(-2025) = 1$
> >
> > 所以 $g(2025) = -1$ ， $f(2025) = g(2025) + 2025 = 2024$
> >
> > 故答案为：2024

> > 14. 函数 $f(x) = \cos \left( \frac{3\pi}{2} + 2x \right) + x^2 \sin x$ 的奇偶性是 \_\_\_\_.
> >
> > 【答案】奇函数
> >
> > 【详解】解析 $f(x)=\sin2x+x^{2}\sin x$
> >
> > $$
> > \because x \in \mathbf {R}, f (- x) = \sin (- 2 x) + (- x) ^ {2} \sin (- x) = - \sin 2 x - x ^ {2} \sin x = - f (x),
> > $$
> >
> > $\therefore f(x)$ 是奇函数.
> >
> > 故答案为：奇函数
