> [!faq]- 《第五章 三角函数（高效培优单元测试·强化卷）数学人教A版2019高一必修第一册》官方解析
>
> > [!success]- **【答案】** ①③④
>
> > [!note]- **【解析】**
> > 函数 $f(x)=\sin x+\frac{1}{2}\sin 2x+\frac{1}{3}\sin 3x$ ， $x\in R$ ，
> > - **对于①**：， $f(-x)=\sin(-x)+\frac{1}{2}\sin(-2x)+\frac{1}{3}\sin(-3x)=-f(x)$ ，函数 $f(x)$ 是奇函数，①正确；
> > - **对于②**：， $f(\frac{\pi}{3})=\frac{\sqrt{3}}{2}+\frac{\sqrt{3}}{4}=\frac{3\sqrt{3}}{4}$ ， $f(\frac{\pi}{4})=\frac{\sqrt{2}}{2}+\frac{1}{2}+\frac{\sqrt{2}}{6}=\frac{2\sqrt{2}}{3}+\frac{1}{2}$
> >
> > 而 $\frac{3\sqrt{3}}{4} < \frac{3}{4} \cdot \frac{9}{5} = \frac{27}{20} < \frac{28}{20} = \frac{9}{10} + \frac{1}{2} < \frac{2\sqrt{2}}{3} + \frac{1}{2}$ ，即 $f(\frac{\pi}{4}) > f(\frac{\pi}{3})$ ，②错误；
> > - **对于③**：， $\sin 3x = \sin 2x\cos x + \cos 2x\sin x = \sin x(4\cos^2 x - 1)$
> >
> > $$
> > f (x) = \sin x + \sin x \cos x + \frac {1}{3} \sin x \left(4 \cos^ {2} x - 1\right) = \frac {1}{3} \sin x \left(4 \cos^ {2} x + 3 \cos + 2\right),
> > $$
> >
> > 而 $4\cos^2 x + 3\cos + 2 = (2\cos x + \frac{3}{4})^2 + \frac{23}{16} > 0$ ，由 $f(x) = 0$ ，得 $\sin x = 0$ ，
> >
> > 当 $x \in [-4, 4]$ ，解得 $x \in \{-\pi, 0, \pi\}$ ， $f(x)$ 在 $[-4, 4]$ 内恰有3个不同的零点，③正确；
> > - **对于④**：，当 $\sin x \neq 0$ ，即 $-1 < \cos x < 1$ 时， $g(x) = \frac{f(x)}{\sin x} = \frac{1}{3}(4\cos^2 x + 3\cos + 2)$
> >
> > $= \frac{1}{3} (2\cos x + \frac{3}{4})^2 + \frac{23}{48}$ 当 $\cos x = -\frac{3}{8}$ 时， $g(x)_{\min} = \frac{23}{48}$ ， $g(x) < 3$ ，即函数 $g(x)$ 的值域为 $[\frac{23}{48}, 3)$ ，④正确·
