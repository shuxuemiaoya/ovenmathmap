> [!faq]- 《第五章 三角函数（高效培优单元测试·强化卷）数学人教A版2019高一必修第一册》官方解析
>
> > [!success]- **【答案】** A. 若 $x_{1}+x_{2}=\frac{\pi}{2}$ ，则 $\left|f(x_{1})+f(x_{2})\right|\leq3\sqrt{2}$ B. 若 $x_{1}-x_{2}=\frac{\pi}{2}$ ，则 $\left|f(x_{1})f(x_{2})\right|\leq\frac{5}{2}$ C. 若 $f(x_{1}) + f(x_{2}) = 0, \quad x_{1} \neq x_{2},$ 则 $\left|x_{1}-x_{2}\right|=\pi$ D. 若 $f(x_{1})=f(x_{2})=\frac{\sqrt{15}}{2},\quad x_{1}\neq x_{2}$ ，则 $\left|x_{1}-x_{2}\right|=\frac{\pi}{3}$
>
> > [!note]- **【解析】**
> > 对于 A 选项，因为 $x_{1} + x_{2} = \frac{\pi}{2}$ ，则 $f(x_{1}) + f(x_{2}) = f(x_{1}) + f\left(\frac{\pi}{2} - x_{1}\right)$
> >
> > $$
> > = 2 \sin x _ {1} + \cos x _ {1} + 2 \sin \left(\frac {\pi}{2} - x _ {1}\right) + \cos \left(\frac {\pi}{2} - x _ {1}\right) = 3 \sin x _ {1} + 3 \cos x _ {1} = 3 \sqrt {2} \sin \left(x _ {1} + \frac {\pi}{4}\right)
> > $$
> >
> > 所以， $\left|f\left(x_{1}\right)+f\left(x_{2}\right)\right|=3\sqrt{2}\left|\sin\left(x_{1}+\frac{\pi}{4}\right)\right|\leq3\sqrt{2}$ ，A对；
> >
> > 对于 B 选项，因为 $x_{1}-x_{2}=\frac{\pi}{2}$ ，则 $x_{2}=x_{1}-\frac{\pi}{2}$
> >
> > 所以 $f(x_{2})=f\left(x_{1}-\frac{\pi}{2}\right)=2\sin\left(x_{1}-\frac{\pi}{2}\right)+\cos\left(x_{1}-\frac{\pi}{2}\right)=\sin x_{1}-2\cos x_{1}$
> >
> > 所以 $f(x_{1})f(x_{2}) = (2\sin x_{1} + \cos x_{1})\cdot (\sin x_{1} - 2\cos x_{1})$
> >
> > $$
> > = 2 \sin^ {2} x _ {1} - 3 \sin x _ {1} \cos x _ {1} - 2 \cos^ {2} x _ {1} = - \frac {3}{2} \sin 2 x _ {1} - 2 \cos 2 x _ {1} = - \frac {5}{2} \sin (2 x _ {1} + \varphi),
> > $$
> >
> > $\varphi_{为锐角，且} \tan\varphi=\frac{4}{3}$ ，所以 $\left|f(x_{1})f(x_{2})\right|=\frac{5}{2}\left|\sin(2x_{1}+\varphi)\right|\leq\frac{5}{2}$ ，B 对；
> >
> > 对于 C 选项，因为 $f(x)=\sqrt{5}\sin(x+\alpha)$ ， $\alpha$ 为锐角，且 $\tan\alpha=\frac{1}{2}$
> >
> > 不妨取 $x_{1}=0$ ， $x_{2}=2\pi-2\alpha\in[0,2\pi]$ ，
> >
> > 则 $f(x_{1}) = \sqrt{5}\sin \alpha$ ， $f(x_{2}) = f(2\pi - 2\alpha) = \sqrt{5}\sin (2\pi - 2\alpha + \alpha) = \sqrt{5}\sin (2\pi - \alpha) = -\sqrt{5}\sin \alpha$
> >
> > 此时 $f(x_{1}) + f(x_{2}) = 0$ ，但 $\left|x_{1} - x_{2}\right| \neq \pi$ ，C 错；
> >
> > 对于 D 选项，因为 $f(x_{1}) = f(x_{2}) = \frac{\sqrt{15}}{2}$ ，即 $\sqrt{5} \sin(x_{1} + \alpha) = \sqrt{5} \sin(x_{2} + \alpha) = \frac{\sqrt{15}}{2}$ ，
> >
> > 所以， $\sin (x_{1} + \alpha) = \sin (x_{2} + \alpha) = \frac{\sqrt{3}}{2}$
> >
> > 因为 $\tan \alpha = \frac{1}{2} < \frac{\sqrt{3}}{3} = \tan \frac{\pi}{6}$ ， $\alpha$ 为锐角，则 $0 < \alpha < \frac{\pi}{6}$
> >
> > 不妨设，则，所以 $\left\{ \begin{array}{l}x_{1} + \alpha = \frac{\pi}{3}\\ x_{2} + \alpha = \frac{2\pi}{3} \end{array} \right.$
> >
> > 所以 $x_{2}-x_{1}=\frac{\pi}{3}$ ，故 $\left|x_{1}-x_{2}\right|=\frac{\pi}{3}$ ，D 对.
> >
> > 故选 **ABD**.
