> [!faq]- 《专题5.4.2正弦函数、余弦函数的性质（高效培优讲义）数学人教A版2019高一必修第一册》官方解析
>
> > [!success]- **【答案】** A
>
> > [!note]- **【解析】**
> > 对于A：函数 $y = a^{x}(a > 1)$ 为R上的增函数，且当 $x > 0$ 时， $y > 1$
> >
> > 因为 0 < a < b < 3 ，所以 $a + 1 > 1$ ，且 $(a + 1)^{b} > 1$ ，故 A 正确；
> >
> > 对于 B：因为 0 < a < b < 3，所以 $b + 1 > a$ ，
> >
> > 当 $a > 1$ 时，函数 $y = \log_a x$ 为 $(0, +\infty)$ 上的增函数，所以 $\log_a (b + 1) > \log_a a = 1$
> >
> > 当 $0 < a < 1$ 时，函数 $y = \log_a x$ 为 $(0, +\infty)$ 上的减函数，所以 $\log_a (b + 1) < \log_a a = 1$ ，故B错误；
> >
> > 对于 C : $y = \cos x$ 在 $(\pi, 2\pi)$ 上单调递增，又 0 < a < b < 3
> >
> > 所以 $\pi < \pi + a < \pi + b < 2\pi$ ，所以 $\cos(\pi + a) < \cos(\pi + b)$ ，故 C 错误；
> >
> > 对于D： $\cos \left(\frac{\pi}{2} -a\right) = \sin a,\cos \left(\frac{\pi}{2} -b\right) = \sin b$
> >
> > $y=\sin x$ 在 $\left(\frac{\pi}{2},\pi\right)$ 上单调递减， $\frac{\pi}{2}<a<b<3$ 时，
> >
> > $\sin a > \sin b$ ，即 $\cos\left(\frac{\pi}{2}-a\right) > \cos\left(\frac{\pi}{2}-b\right)$ ，故 D 错误.
> >
> > 故选 **A**·
