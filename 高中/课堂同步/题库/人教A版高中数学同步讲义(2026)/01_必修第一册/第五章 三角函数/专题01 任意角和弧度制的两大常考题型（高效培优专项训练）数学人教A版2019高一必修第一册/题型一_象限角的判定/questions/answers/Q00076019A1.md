> [!faq]- 《专题01 任意角和弧度制的两大常考题型（高效培优专项训练）数学人教A版2019高一必修第一册》官方解析
>
> > [!success]- **【答案】** 三
>
> > [!note]- **【解析】**
> > 解：∵ $\theta$ 是第一象限角，∴ $2k\pi < \theta < 2k\pi + \frac{\pi}{2}, k \in Z$
> >
> > $\therefore k\pi < \frac{\theta}{2} < k\pi + \frac{\pi}{4}, k \in Z$ ，故 $\frac{\theta}{2}$ 有可能是第一象限角或第三象限角
> >
> > ∵ $y = \tan x$ 在 $\left(k\pi, k\pi + \frac{\pi}{4}\right), k \in Z$ 上单调递增，
> >
> > $\tan k\pi = \tan 0 = 0, \tan \left(k\pi + \frac{\pi}{4}\right) = \tan \frac{\pi}{4} = 1,$
> >
> > $\therefore 0 < \tan \frac{\theta}{2} < 1$ ，若 $\frac{\theta}{2}$ 是第一象限角，则 $\sin \frac{\theta}{2} > 0, \cos \frac{\theta}{2} > 0$
> >
> > 则 $\sin \frac{\theta}{2} >\cos \frac{\theta}{2}\Rightarrow \tan \frac{\theta}{2} >1$ ，与 $\therefore 0 <   \tan \frac{\theta}{2} <  1$ 矛盾
> >
> > 当 $\frac{\theta}{2}$ 是第三象限角，则 $\sin \frac{\theta}{2} < 0, \cos \frac{\theta}{2} < 0$
> >
> > 则 $\sin \frac{\theta}{2} >\cos \frac{\theta}{2}\Rightarrow 0 <   \tan \frac{\theta}{2} <  1$
> >
> > 综上， $\frac{\theta}{2}$ 是第三象限角
> >
> > 故答案为：三
