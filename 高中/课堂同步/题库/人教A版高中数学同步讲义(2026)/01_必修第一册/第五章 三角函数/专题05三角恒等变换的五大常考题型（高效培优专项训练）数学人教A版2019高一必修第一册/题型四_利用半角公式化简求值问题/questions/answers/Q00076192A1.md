> [!faq]- 《专题05三角恒等变换的五大常考题型（高效培优专项训练）数学人教A版2019高一必修第一册》官方解析
>
> > [!success]- **【答案】** $\frac{\sqrt{5}}{5}$
>
> > [!note]- **【解析】**
> > 解：由 $\sin \alpha +\cos \alpha = \frac{1}{5}$ ，两边平方得： $1 + 2\sin \alpha \cos \alpha = \frac{1}{25}$
> >
> > 即 $2\sin \alpha \cos \alpha = -\frac{24}{25} < 0$
> >
> > 因为 $\frac{\pi}{2} < \alpha < \pi$
> >
> > 所以 $\sin \alpha > 0, \cos \alpha < 0$
> >
> > 所以 $\sin\alpha-\cos\alpha=\sqrt{\left(\sin\alpha-\cos\alpha\right)^{2}}=\sqrt{1-2\sin\alpha\cos\alpha}=\frac{7}{5}$
> >
> > 两式联立得 $\sin \alpha = \frac{4}{5},\cos \alpha = -\frac{3}{5}$
> >
> > 所以 $\cos\frac{\alpha}{2}=\sqrt{\frac{1+\cos\alpha}{2}}=\frac{\sqrt{5}}{5}$
> >
> > 故答案为： $\frac{\sqrt{5}}{5}$

> > 34. 化简： $\frac{\cos\left(\frac{3}{2}\pi - \alpha\right) - \tan\frac{\alpha}{2}(1 + \cos\alpha)}{\sqrt{1 - \cos\alpha}} (0 < \alpha < \pi) =$
> >
> > 【答案】 $-2\sqrt{2}\cos \frac{\alpha}{2}$
> >
> > 【详解】 $\because 0 <   \alpha <  \pi$
> >
> > $\therefore \tan \frac{\alpha}{2} = \sqrt{\frac{1 - \cos\alpha}{1 + \cos\alpha}} = \frac{\sqrt{1 - \cos^2\alpha}}{1 + \cos\alpha} = \frac{\sin\alpha}{1 + \cos\alpha}$
> >
> > $$
> > \therefore (1 + \cos \alpha) \tan \frac {\alpha}{2} = \sin \alpha .
> > $$
> >
> > 又 $\cos \left(\frac{3\pi}{2} -\alpha\right) = -\sin \alpha$ ，且 $1 - \cos \alpha = 2\sin^2{\frac{\alpha}{2}}$
> >
> > $$
> > \therefore \frac {\cos \left(\frac {3}{2} \pi - \alpha\right) - \tan \frac {\alpha}{2} (1 + \cos \alpha)}{\sqrt {1 - \cos \alpha}}
> > $$
> >
> > $$
> > = \frac {- \sin \alpha - \sin \alpha}{\sqrt {2 \sin^ {2} \frac {\alpha}{2}}} = \frac {- 2 \sin \alpha}{\sqrt {2} \left| \sin \frac {\alpha}{2} \right|} = - \frac {2 \sqrt {2} \sin \frac {\alpha}{2} \cos \frac {\alpha}{2}}{\left| \sin \frac {\alpha}{2} \right|}.
> > $$
> >
> > $0 < \alpha < \pi$
> >
> > $0 < \frac{\alpha}{2} < \frac{\pi}{2}$
> >
> > $$
> > \therefore \frac {\cos \left(\frac {3}{2} \pi - \alpha\right) - \tan \frac {\alpha}{2} (1 + \cos \alpha)}{\sqrt {1 - \cos \alpha}} = - 2 \sqrt {2} \cos \frac {\alpha}{2}.
> > $$
> >
> > 故答案为： $-2\sqrt{2}\cos\frac{\alpha}{2}$
