> [!faq]- 《专题05三角恒等变换的五大常考题型（高效培优专项训练）数学人教A版2019高一必修第一册》官方解析
>
> > [!success]- **【答案】** (1) $\pi$ ， $\left[\frac{\pi}{12} + k\pi, \frac{7\pi}{12} + k\pi\right], k \in \mathbb{Z}$ (2) $OP_{1} + OP_{2} + L + OP_{n} = \left(\frac{13\pi}{3}, 0\right)$
>
> > [!note]- **【解析】**
> > （1）由题意 $f(x) = 2\sin x\cos \left(x + \frac{\pi}{3}\right) + \frac{\sqrt{3}}{2} = 2\sin x\left(\frac{1}{2}\cos x - \frac{\sqrt{3}}{2}\sin x\right) + \frac{\sqrt{3}}{2}$
> >
> > $$
> > = \sin x \cos x - \sqrt {3} \sin^ {2} x + \frac {\sqrt {3}}{2} = \frac {1}{2} \sin 2 x + \frac {\sqrt {3}}{2} \cos 2 x = \sin \left(2 x + \frac {\pi}{3}\right)
> > $$
> >
> > 所以 $f(x)$ 的最小正周期为 $T = \frac{2\pi}{2} = \pi$
> >
> > 令 $z = 2x + \frac{\pi}{3}$ ，因为 $y = \sin z$ 得单调递减区间为 $\left[\frac{\pi}{2} + 2k\pi, \frac{3\pi}{2} + 2k\pi\right], k \in \mathbb{Z}$
> >
> > 由 $\frac{\pi}{2} + 2k\pi \leq 2x + \frac{\pi}{3} \leq \frac{3\pi}{2} + 2k\pi$ ，得 $\frac{\pi}{12} + k\pi \leq 2x \leq \frac{7\pi}{12} + k\pi$
> >
> > 所以 $f(x)$ 的单调为 $\left[\frac{\pi}{12} + k\pi, \frac{7\pi}{12} + k\pi\right], k \in \mathbb{Z}$ .
> >
> > (2) 将 $y = f(x)$ 与 $y = \sin\left(x + \frac{\pi}{6}\right)$ 联立，得 $\sin\left(2x + \frac{\pi}{3}\right) = \sin\left(x + \frac{\pi}{6}\right)$
> >
> > 即 $2\sin \left(x + \frac{\pi}{6}\right)\cos \left(x + \frac{\pi}{6}\right) = \sin \left(x + \frac{\pi}{6}\right)$ ，解得 $\sin \left(x + \frac{\pi}{6}\right) = 0$ 或 $\cos \left(x + \frac{\pi}{6}\right) = \frac{1}{2}$ ，
> >
> > 又 $x \in [0, 2\pi]$ ，所以 $x + \frac{\pi}{6} = \frac{\pi}{3}$ ， $\pi$ ， $\frac{5\pi}{3}$ ， $2\pi$ ，解得 $x = \frac{\pi}{6}, \frac{5\pi}{6}, \frac{3\pi}{2}, \frac{11\pi}{6}$ ，
> >
> > 因此，得交点坐标为 $P_{1}\left(\frac{\pi}{6},\frac{\sqrt{3}}{2}\right),P_{2}\left(\frac{5\pi}{6},0\right),P_{3}\left(\frac{3\pi}{2}, - \frac{\sqrt{3}}{2}\right),P_{4}\left(\frac{11\pi}{6},0\right)$
> >
> > 所以 $OP_{1} + OP_{2} + L + OP_{n} = \left( \frac{13\pi}{3}, 0 \right)$ .
