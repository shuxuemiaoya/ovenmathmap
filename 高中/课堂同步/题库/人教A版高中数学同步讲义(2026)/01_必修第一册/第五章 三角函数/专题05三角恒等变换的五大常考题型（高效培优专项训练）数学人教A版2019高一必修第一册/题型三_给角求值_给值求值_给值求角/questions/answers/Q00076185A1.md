> [!faq]- 《专题05三角恒等变换的五大常考题型（高效培优专项训练）数学人教A版2019高一必修第一册》官方解析
>
> > [!success]- **【答案】** $\frac{\pi}{3} / 60^{\circ}$
>
> > [!note]- **【解析】**
> > 因为 $\sin\left(\alpha+\frac{\pi}{3}\right)=\sin\alpha\cos\frac{\pi}{3}+\cos\alpha\sin\frac{\pi}{3}=\frac{1}{2}\sin\alpha+\frac{\sqrt{3}}{2}\cos\alpha$
> >
> > $$
> > \sin \left(\alpha + \frac {2 \pi}{3}\right) = \sin \alpha \cos \frac {2 \pi}{3} + \cos \alpha \sin \frac {2 \pi}{3} = - \frac {1}{2} \sin \alpha + \frac {\sqrt {3}}{2} \cos \alpha
> > $$
> >
> > 又 $\sin \alpha +\sin \left(\alpha +\frac{\pi}{3}\right) + \sin \left(\alpha +\frac{2\pi}{3}\right) = \sqrt{3}$
> >
> > 所以 $\sin \alpha +\sqrt{3}\cos \alpha = \sqrt{3}$ ，所以 $\frac{1}{2}\sin \alpha +\frac{\sqrt{3}}{2}\cos \alpha = \frac{\sqrt{3}}{2}$ ，即 $\sin \left(\alpha +\frac{\pi}{3}\right) = \frac{\sqrt{3}}{2}$
> >
> > 因为 $0 < \alpha < \frac{\pi}{2}$ ，所以 $\frac{\pi}{3} < \alpha + \frac{\pi}{3} < \frac{5\pi}{6}$ ，所以 $\alpha + \frac{\pi}{3} = \frac{2\pi}{3}$ ，所以 $\alpha = \frac{\pi}{3}$ 。
> >
> > 故答案为： $\frac{\pi}{3}$
