> [!faq]- 《专题05三角恒等变换的五大常考题型（高效培优专项训练）数学人教A版2019高一必修第一册》官方解析
>
> > [!success]- **【答案】** 5或-9.
>
> > [!note]- **【解析】**
> > $f(x) = a\cos 2x + \sqrt{3} a\sin 2x - 2a + b = 2a\sin \left(2x + \frac{\pi}{6}\right) - 2a + b$
> >
> > 因为 $x \in \left[0, \frac{\pi}{2}\right]$ ，所以 $2x + \frac{\pi}{6} \in \left[\frac{\pi}{6}, \frac{7\pi}{6}\right]$ ， $\sin \left(2x + \frac{\pi}{6}\right) \in \left[-\frac{1}{2}, 1\right]$ ，
> >
> > 当 $a > 0$ 时， $2a\sin \left(2x + \frac{\pi}{6}\right) - 2a + b \in [-3a + b, b]$ ，所以 $-3a + b = -5, b = 1$
> >
> > 所以 $a = 2, b = 1$ ，所以 $2a + b = 5$ ；
> >
> > 当 $a < 0$ 时， $2a\sin \left(2x + \frac{\pi}{6}\right) - 2a + b \in [b, -3a + b]$ ，所以 $-3a + b = 1, b = -5$
> >
> > 所以 $a = -2, b = -5$ ，所以 $2a + b = -9$ ；
> >
> > 故答案为：5或-9.
