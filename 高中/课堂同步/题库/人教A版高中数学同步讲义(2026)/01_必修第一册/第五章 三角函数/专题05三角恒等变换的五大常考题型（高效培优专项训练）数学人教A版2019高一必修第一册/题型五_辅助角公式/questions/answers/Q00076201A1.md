> [!faq]- 《专题05三角恒等变换的五大常考题型（高效培优专项训练）数学人教A版2019高一必修第一册》官方解析
>
> > [!success]- **【答案】** $\frac{24}{25}$
>
> > [!note]- **【解析】**
> > 已知 $f(x) = 4\sin x + 3\cos x = 5(\frac{4}{5}\sin x + \frac{3}{5}\cos x) = 5\sin (x + \varphi)$ ，其中 $\tan \varphi = \frac{3}{4}$
> >
> > 当 $\sin (x_0 + \varphi) = 1$ 时，取得最大值，且 $\sin \varphi = \frac{3}{5},\cos \varphi = \frac{4}{5}$
> >
> > 可知 $\cos (x_0 + \varphi) = \pm \sqrt{1 - \sin^2(x_0 + \varphi)} = 0$
> >
> > $$
> > \sin x _ {0} = \sin [ (x _ {0} + \varphi) - \varphi ] = \sin (x _ {0} + \varphi) \cos \varphi - \cos (x _ {0} + \varphi) \sin \varphi = 1 \times \frac {4}{5} - 0 \times \frac {3}{5} = \frac {4}{5}
> > $$
> >
> > 同理可得 $\cos x_0 = \cos [(x_0 + \varphi) - \varphi] = \cos (x_0 + \varphi)\cos \varphi +\sin (x_0 + \varphi)\sin \varphi = 0\times \frac{4}{5} +1\times \frac{3}{5} = \frac{3}{5}$
> >
> > 则 $\sin 2x_0 = 2\sin x_0\cos x_0 = 2\times \frac{3}{5}\times \frac{4}{5} = \frac{24}{25}.$
> >
> > 故答案为： $\frac{24}{25}$
