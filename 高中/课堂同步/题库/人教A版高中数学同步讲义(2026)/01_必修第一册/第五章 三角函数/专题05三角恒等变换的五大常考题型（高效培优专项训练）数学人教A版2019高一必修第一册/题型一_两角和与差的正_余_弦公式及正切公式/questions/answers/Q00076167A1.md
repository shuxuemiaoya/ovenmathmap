> [!faq]- 《专题05三角恒等变换的五大常考题型（高效培优专项训练）数学人教A版2019高一必修第一册》官方解析
>
> > [!success]- **【答案】** ①③④
>
> > [!note]- **【解析】**
> > 函数 $f(x) = \sin x + \frac{1}{2}\sin 2x + \frac{1}{3}\sin 3x$ ， $x \in \mathbb{R}$ ，
> > - **对于①**：， $f(-x)=\sin(-x)+\frac{1}{2}\sin(-2x)+\frac{1}{3}\sin(-3x)=-f(x)$ ，函数 $f(x)$ 是奇函数，①正确；
> > - **对于②**：， $f(\frac{\pi}{3})=\frac{\sqrt{3}}{2}+\frac{\sqrt{3}}{4}=\frac{3\sqrt{3}}{4}$ ， $f(\frac{\pi}{4})=\frac{\sqrt{2}}{2}+\frac{1}{2}+\frac{\sqrt{2}}{6}=\frac{2\sqrt{2}}{3}+\frac{1}{2}$
> >
> > 而 $\frac{3\sqrt{3}}{4} < \frac{3}{4} \cdot \frac{9}{5} = \frac{27}{20} < \frac{28}{20} = \frac{9}{10} + \frac{1}{2} < \frac{2\sqrt{2}}{3} + \frac{1}{2}$ ，即 $f(\frac{\pi}{4}) > f(\frac{\pi}{3})$ ，②错误；
> > - **对于③**：， $\sin3x=\sin2x\cos x+\cos2x\sin x=\sin x(4\cos^{2}x-1)$
> >
> > $$
> > f (x) = \sin x + \sin x \cos x + \frac {1}{3} \sin x \left(4 \cos^ {2} x - 1\right) = \frac {1}{3} \sin x \left(4 \cos^ {2} x + 3 \cos + 2\right),
> > $$
> >
> > 而 $4\cos^2 x + 3\cos + 2 = (2\cos x + \frac{3}{4})^2 + \frac{23}{16} > 0$ ，由 $f(x) = 0$ ，得 $\sin x = 0$ ，
> >
> > 当 $x \in [-4, 4]$ ，解得 $x \in \{-\pi, 0, \pi\}$ ， $f(x)$ 在 $[-4, 4]$ 内恰有3个不同的零点，③正确；
> > - **对于④**：，当 $\sin x \neq 0$ ，即 $-1 < \cos x < 1$ 时， $g(x) = \frac{f(x)}{\sin x} = \frac{1}{3}(4\cos^2 x + 3\cos + 2)$
> >
> > $= \frac{1}{3} (2\cos x + \frac{3}{4})^2 +\frac{23}{48}$ 当 $\cos x = -\frac{3}{8}$ 时， $g(x)_{\mathrm{min}} = \frac{23}{48}$ ， $g(x) <   3$ ，即函数 $g(x)$ 的值域为 $[\frac{23}{48},3)$ ，④正确
> >
> > 故答案为：①③④
> >
> > 8. 函数 $g(x) = 3\sin x + \cos x$ ，若 $g(x) = 1$ 在 $[0,2\pi)$ 有两个零点 $x_1, x_2$ ，则 $\cos (x_1 - x_2) =$ \_\_\_\_.
> >
> > 【答案】 $-\frac{4}{5}/-0.8$
> >
> > 【详解】 $g(x)=3\sin x+\cos x=\sqrt{10}\sin(x+\varphi)$
> >
> > 因为 $g(x)=1$ 在 $[0,2\pi)$ 上有两个零点 $x_{1},x_{2}$
> >
> > 所以 $g(x_{1})=g(x_{2})=1$ ，即 $\left\{\begin{aligned}3\sin x_{1}+\cos x_{1}&=1\\ 3\sin x_{2}+\cos x_{2}&=1\end{aligned}\right.$
> >
> > 令 $g(x)=1$ ，则 $\sin(x+\varphi)=\frac{\sqrt{10}}{10}$ ，
> >
> > 根据正弦函数的性质可知， $x_{1}+\varphi,x_{2}+\varphi$ 关于 $x=\frac{\pi}{2}$ 对称，
> >
> > 所以 $x_{1} + x_{2} + 2\varphi = \pi$ ，即 $x_{1} + x_{2} = \pi -2\varphi .$
> >
> > 所以 $x_{1} - x_{2} = \pi -2\varphi -2x_{2}$
> >
> > 所以 $\cos\left(x_{1}-x_{2}\right)=\cos\left(\pi-2\varphi-2x_{2}\right)=-\cos\left(2\varphi+2x_{2}\right)=-\left[2\cos^{2}\left(\varphi+x_{2}\right)-1\right]$
> >
> > 因为 $\sin(x_{2}+\varphi)=\frac{\sqrt{10}}{10}$ ，所以 $\cos^{2}(x_{2}+\varphi)=1-\left(\frac{\sqrt{10}}{10}\right)^{2}=\frac{9}{10}$ ，
> >
> > 所以 $\cos (x_1 - x_2) = -\left[2\cos^2 (\varphi +x_2) - 1\right] = -\left(2\times \frac{9}{10} -1\right) = -\frac{4}{5}.$
> >
> > 故答案为： $-\frac{4}{5}$
