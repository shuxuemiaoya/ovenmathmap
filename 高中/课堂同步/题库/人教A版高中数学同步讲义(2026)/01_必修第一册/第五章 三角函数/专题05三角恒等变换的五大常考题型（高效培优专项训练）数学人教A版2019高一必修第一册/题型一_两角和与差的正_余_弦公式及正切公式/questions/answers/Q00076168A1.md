> [!faq]- 《专题05三角恒等变换的五大常考题型（高效培优专项训练）数学人教A版2019高一必修第一册》官方解析
>
> > [!success]- **【答案】** (1) $\frac{\pi}{6}$ (2) $B=\frac{\pi}{6}$
>
> > [!note]- **【解析】**
> > （1）因为 $\tan A = -\tan(B + C) = \frac{\tan B + \tan C}{1 - \tan B \tan C} = \frac{2 \tan B}{1 + 3 \tan^{2} B}$
> >
> > 所以 $\tan A, \tan B$ 同号，故 $\tan A > 0, \tan B > 0$
> >
> > 因此 $\tan A = \frac{2}{\frac{1}{\tan B} + 3\tan B}\leq \frac{2}{2\sqrt{\frac{1}{\tan B}\cdot 3\tan B}} = \frac{\sqrt{3}}{3}$
> >
> > 等号成立当且仅当 $\frac{1}{\tan B} = 3\tan B$ ，即 $\tan B = \frac{\sqrt{3}}{3}$ 时， $(\tan A)_{\max} = \frac{\sqrt{3}}{3}$ 最大，
> >
> > 因此 $\mathrm{A}$ 的最大值为 $\frac{\pi}{6}$
> >
> > (2) 由题意得 $\sin C = \sqrt{3} \sin A$ ，故 $\sin C = \sqrt{3} \sin (B + C) = \sqrt{3} [\sin B \cos C + \cos B \sin C]$
> >
> > 所以 $\frac{\sin C}{\cos B\cos C} = \sqrt{3}\left[\tan B + \tan C\right] = \left[-\frac{\tan C}{3} +\tan C\right] = \frac{2\sqrt{3}}{3}\tan C.$
> >
> > 即 $\frac{1}{\cos B} \cdot \tan C = \frac{2\sqrt{3}}{3} \tan C$
> >
> > 解得 $\cos B = \frac{\sqrt{3}}{2}$ ，又 $B$ 为三角形内角，故 $B = \frac{\pi}{6}$
