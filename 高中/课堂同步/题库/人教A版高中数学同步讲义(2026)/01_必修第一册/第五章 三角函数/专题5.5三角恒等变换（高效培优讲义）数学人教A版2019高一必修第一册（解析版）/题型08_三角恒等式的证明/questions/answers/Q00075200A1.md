> [!faq]- 《专题5.5三角恒等变换（高效培优讲义）数学人教A版2019高一必修第一册（解析版）》官方解析
>
> > [!success]- **【答案】** (1)函数 $y = f(x)$ 的最小正周期为 $\pi$ ，最大值为 $\frac{\sqrt{3} + 1}{2}$ (2) $\frac{2\sqrt{2}+\sqrt{3}}{6}$ <!-- source-part:2 pages:51-86 -->
>
> > [!note]- **【解析】**
> > $f(x)=\cos\left(2x+\frac{\pi}{3}\right)+\sin^{2}x=\cos2x\cos\frac{\pi}{3}-\sin2x\sin\frac{\pi}{3}+\frac{1-\cos2x}{2}=-\frac{\sqrt{3}}{2}\sin2x+\frac{1}{2}$
> >
> > 故函数 $y = f(x)$ 的最小正周期为 $\pi$ ，最大值为 $\frac{\sqrt{3} + 1}{2}$
> >
> > (2) 由 $f\left(\frac{C}{2}\right)=-\frac{\sqrt{3}}{2}\sin C+\frac{1}{2}=-\frac{1}{4}$ ，解得 $\sin C=\frac{\sqrt{3}}{2}$ .
> >
> > 又 $\cos B = \frac{1}{3}$ ，从而 $\sin B = \frac{2\sqrt{2}}{3}$
> >
> > 因为 $\frac{2\sqrt{2}}{3} > \frac{\sqrt{3}}{2}$ ，所以 C 为锐角， $C = \frac{\pi}{3}$
> >
> > $$
> > \sin A = \sin (B + C) = \sin B \cos C + \sin C \cos B = \frac {2 \sqrt {2} + \sqrt {3}}{6}.
> > $$
