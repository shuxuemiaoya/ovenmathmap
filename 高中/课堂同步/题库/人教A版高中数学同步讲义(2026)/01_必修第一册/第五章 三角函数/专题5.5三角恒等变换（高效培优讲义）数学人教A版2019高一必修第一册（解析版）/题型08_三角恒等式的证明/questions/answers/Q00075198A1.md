> [!faq]- 《专题5.5三角恒等变换（高效培优讲义）数学人教A版2019高一必修第一册（解析版）》官方解析
>
> > [!success]- **【答案】** A
>
> > [!note]- **【解析】**
> > 因为 $b^{2}=a(a+c)$ ，所以 $b^{2}=a^{2}+ac$ ，
> >
> > 由余弦定理得： $b^{2}=a^{2}+c^{2}-2ac\cos B$
> >
> > 所以 $a^2 + c^2 - 2ac\cos B = a^2 + ac$ ，所以 $a + 2a\cos B = c$
> >
> > 由正弦定理得 $\sin A + 2\sin A\cos B = \sin C$ ，因为 $C = \pi -(A + B)$
> >
> > 所以 $\sin A + 2\sin A\cos B = \sin (A + B) = \sin A\cos B + \cos A\sin B$
> >
> > 即 $\sin A = \sin (B - A)$
> >
> > 因为 $\triangle ABC$ 是锐角三角形，所以 $A, B \in (0, \frac{\pi}{2})$
> >
> > 所以 $A = B - A$ ，即 $B = 2A$
> >
> > 所以 $\left\{ \begin{array}{ll}0 < A <   \frac{\pi}{2}\\ 0 <   B = 2A <   \frac{\pi}{2}\\ 0 <   C = \pi -3A <   \frac{\pi}{2} \end{array} \right.$ ，解得
> >
> > 则 $\sqrt{3}\sin(B-A)+\cos A=\sqrt{3}\sin A+\cos A=2\sin(A+\frac{\pi}{6})$
> >
> > 因为 $\frac{\pi}{3} < A + \frac{\pi}{6} < \frac{5\pi}{12}$ ，所以 $2\sin (A + \frac{\pi}{6})\in (\sqrt{3},\frac{\sqrt{6} + \sqrt{2}}{2})$
> >
> > 故选：A.
> >
> > ## 方法技巧
> >
> > (1) 执因素果法：证明的形式一般化繁为简；
> >
> > (2) 左右归一法：证明左右两边都等于同一个式子；
> >
> > （3）拼凑法：针对题设和结论之间的差异，有针对性地变形，以消除它们之间的差异，简言之，即化异求同；
> >
> > (4) 比较法：设法证明“左边 - 右边 = 0”或“左边/右边 = 1”；
> >
> > （5）分析法：从被证明的等式出发，逐步地探求使等式成立的条件，直到已知条件或明显的事实为止，就可以断定原等式成立。
