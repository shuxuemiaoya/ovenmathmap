> [!faq]- 《专题06函数函数y＝Asin(ωx＋φ)及函数的应用的四大常考题型（高效培优专项训练）数学人教A版2019高一必修第一册》官方解析
>
> > [!success]- **【答案】** $4 \frac{3\pi}{4}/135^{\circ}$
>
> > [!note]- **【解析】**
> > 由题意得 $f(x)$ 的最小正周期 $T = 2 \times \frac{\pi}{4} = \frac{2\pi}{\omega}$ ，得 $\omega = 4, f(x) = \sin(4x + \varphi)$ ，
> >
> > 则 $g(x) = \sin \left[4\left(x - \frac{\pi}{16}\right) + \varphi \right] = \sin \left(4x - \frac{\pi}{4} +\varphi\right)$
> >
> > 因为函数 $g(x)$ 的图象关于 $y$ 轴对称，
> >
> > 所以 $-\frac{\pi}{4} + \varphi = \frac{\pi}{2} + k\pi (k \in \mathbf{Z})$ ，得 $\varphi = \frac{3\pi}{4} + k\pi (k \in \mathbf{Z}), \varphi$ 的最小正值为 $\frac{3\pi}{4}$ .
> >
> > 故答案为：① $^{4}$ ；
> > - **②**：$\frac{3\pi}{4}$ ·
> >
> > 4. 将函数 $f(x) = \cos \left( \omega x + \frac{\pi}{6} \right) (\omega > 0)$ 的图象向左平移 $\frac{\pi}{3}$ 个单位长度后与函数 $g(x) = \sin (\omega x)$ 的图象重合，则 $\omega$ 的最小值为\_\_\_\_。
> >
> > 【答案】4
> >
> > 【详解】将函数 $f(x) = \cos \left( \omega x + \frac{\pi}{6} \right) (\omega > 0)$ 的图象向左平移 $\frac{\pi}{3}$ 个单位长度后，
> >
> > 得到函数 $y = \cos \left[\omega \left(x + \frac{\pi}{3}\right) + \frac{\pi}{6}\right] = \cos \left(\omega x + \frac{\pi\omega}{3} + \frac{\pi}{6}\right)$ 的图象，
> >
> > 因为 $g(x)=\sin(\omega x)=\cos\left(\omega x-\frac{\pi}{2}\right)$
> >
> > 由题意可知，函数 $y = \cos \left( \omega x + \frac{\pi \omega}{3} + \frac{\pi}{6} \right)$ 的图象与函数 $g(x)$ 的图象重合，
> >
> > 所以 $\frac{\pi\omega}{3} +\frac{\pi}{6} = 2k\pi -\frac{\pi}{2}\big(k\in \mathbf{Z}\big)$ ，可得 $\omega = 6k - 2\big(k\in \mathbf{Z}\big)$
> >
> > 因为 $\omega > 0$ ，故当 $k = 1$ 时， $\omega$ 取最小值4.
> >
> > 故答案为：4·
> >
> > 5. 将函数 $f(x) = \cos \left( x - \frac{5\pi}{2} \right)$ 的图象上所有点的横坐标变为原来的 $\frac{1}{\omega} (\omega > 0)$ 倍，纵坐标不变，得到函数 $g(x)$ 的图象，若 $g(x)$ 在区间 $(\pi, 2\pi)$ 内恰有3个最值点，则 $\omega$ 的最大值为\_\_\_\_。
> >
> > 【答案】 $\frac{15}{4}$
> >
> > 【详解】 $f(x) = \cos \left(x - \frac{5\pi}{2}\right) = \cos \left(x - \frac{\pi}{2}\right) = \sin x$ ，则 $g(x) = \sin \omega x$
> >
> > 因为 $g(x)$ 在区间 $(\pi, 2\pi)$ 内恰有3个最值点，根据正弦曲线的伸缩变化的特点，
> >
> > 当 $\omega$ 满足条件且取最大值时， $x = 2\pi$ 一定是 $g(x)$ 的一个最值点，
> >
> > 令 $2\omega \pi = k\pi + \frac{\pi}{2} (k \in \mathbf{Z})$ ，得 $\omega = \frac{k}{2} + \frac{1}{4} (k \in \mathbf{Z})$ .
> >
> > 从 $2\pi$ 往左数 $^4$ 个最值点依次为 $2\pi - \frac{\pi}{\omega}$ , $2\pi - \frac{2\pi}{\omega}$ , $2\pi - \frac{3\pi}{\omega}$ , $2\pi - \frac{4\pi}{\omega}$ ,
> >
> > 则 $2\pi - \frac{4\pi}{\omega} \leq \pi < 2\pi - \frac{3\pi}{\omega}$ ，解得 $3 < \omega \leq 4$ ，所以当 $k = 7$ 时， $\omega$ 取得最大值 $\frac{15}{4}$ 。
> >
> > 故答案为： $\frac{15}{4}$
