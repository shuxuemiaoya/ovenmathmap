> [!faq]- 《专题5.4.3正切函数的性质与图像（高效培优讲义）数学人教A版2019高一必修第一册》官方解析
>
> > [!success]- **【答案】** A. 函数 $f(x) = \sin x - |\sin x|$ 是奇函数 B. 函数 $g(x) = \cos x - |\cos x|$ 的图象关于直线 $x = k\pi$ ， $k \in \mathbb{Z}$ 对称 C. 函数 $h(x) = |\tan x - \sin x| + \tan x + \sin x$ 的一个周期为 $2\pi$ D. 函数 $h(x) = |\tan x - \sin x| + \tan x + \sin x$ 在 $\left(-\frac{\pi}{2} + 2k\pi, \frac{\pi}{2} + 2k\pi\right)$ ， $k \in \mathbb{Z}$ 上单调递增
>
> > [!note]- **【解析】**
> > 对于A，因为 $f\left(\frac{\pi}{4}\right) = \sin \frac{\pi}{4} -\left|\sin \frac{\pi}{4}\right| = 0,\quad f\left(-\frac{\pi}{4}\right) = -\sin \frac{\pi}{4} -\left|\sin \frac{\pi}{4}\right| = -\sqrt{2}$
> >
> > 因 $f\left(\frac{\pi}{4}\right) \neq -f\left(-\frac{\pi}{4}\right)$ ，所以 $f(x)$ 不是奇函数，A 错误；
> >
> > 对于 B，因为 $g(2k\pi - x) = \cos(2k\pi - x) - |\cos(2k\pi - x)| = \cos x - |\cos x| = g(x)$
> >
> > 所以 $g(x)$ 的图象关于直线 $x = k\pi$ ， $k \in \mathbb{Z}$ 对称， ${}^{\mathrm{B}}$ 正确；
> >
> > 对于 C，因为 $h(x+2\pi)=\left|\tan(x+2\pi)-\sin(x+2\pi)\right|+\tan(x+2\pi)+\sin(x+2\pi)=h(x)$ ，所以 $h(x)$ 的一个周期为
> >
> > $2\pi$ , C 正确；
> >
> > 对于 D，由 $\tan x - \sin x = \tan x - \tan x \cdot \cos x = \tan x (1 - \cos x) \leq 0$
> >
> > 得 $\tan x\leq 0$ ，得 $-\frac{\pi}{2} +k\pi <  x\leq k\pi (k\in \mathbb{Z})$
> >
> > 此时 $h(x) = |\tan x - \sin x| + \tan x + \sin x = 2\sin x$ ，在 $\left(-\frac{\pi}{2} + 2k\pi, 2k\pi\right](k \in Z)$ 上单调递增；
> >
> > 由 $\tan x - \sin x = \tan x(1 - \cos x)$ 0，得 $\tan x = 0$ ，得 $k\pi \leq x < \frac{\pi}{2} + k\pi (k \in Z)$ ，
> >
> > 此时 $h(x) = |\tan x - \sin x| + \tan x + \sin x = 2\tan x$ ，在 $\left[2k\pi ,\frac{\pi}{2} +2k\pi\right)(k\in Z)$ 上单调递增，
> >
> > 又 $2\sin(2k\pi)=0=2\tan(2k\pi)$ ， $k\in Z$ ，
> >
> > 故 $h(x)$ 在 $\left(-\frac{\pi}{2} + 2k\pi, \frac{\pi}{2} + 2k\pi\right)$ ， $k \in \mathbb{Z}$ 上单调递增，D 正确。
> >
> > 故选 **BCD**
