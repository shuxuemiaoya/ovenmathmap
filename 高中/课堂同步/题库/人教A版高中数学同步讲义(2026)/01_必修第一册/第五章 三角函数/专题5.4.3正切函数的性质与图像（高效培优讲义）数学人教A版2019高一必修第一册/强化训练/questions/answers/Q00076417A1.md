> [!faq]- 《专题5.4.3正切函数的性质与图像（高效培优讲义）数学人教A版2019高一必修第一册》官方解析
>
> > [!success]- **【答案】** ( ) A. 函数 $y = f(x)$ 的最小正周期为 $\frac{\pi}{2}$ B. 点 $\left(\frac{\pi}{3}, 0\right)$ 是函数 $f(x)$ 图象的一个对称中心 C. $f\left(-\frac{\pi}{12}\right) > f\left(\frac{2\pi}{5}\right)$ D. $f(x) < 1$ 的解集为 $\left\{x \mid \frac{k\pi}{2} < x < \frac{k\pi}{2} + \frac{5\pi}{24}, k \in Z\right\}$
>
> > [!note]- **【解析】**
> > 由题意有 $f(x)$ 的最小正周期为 $\frac{\pi}{2}$ ，故 $^{A}$ 正确；所以 $\omega = \frac{\pi}{T} = 2$ ，所以 $f(x) = \tan\left(2x - \frac{\pi}{6}\right)$
> >
> > 由 $2 \times \frac{\pi}{3} - \frac{\pi}{6} = \frac{\pi}{2}$ ，所以 $\left(\frac{\pi}{3}, 0\right)$ 是函数 $f(x)$ 图象的一个对称中心，故 ${}^{\mathrm{B}}$ 正确；
> >
> > $f\left(-\frac{\pi}{12}\right) = f\left(-\frac{\pi}{12} + \frac{\pi}{2}\right) = f\left(\frac{5\pi}{12}\right) = \tan \frac{2\pi}{3}, f\left(\frac{2\pi}{5}\right) = \tan \frac{19\pi}{30}, \text{又} \frac{\pi}{2} < \frac{19\pi}{30} < \frac{2\pi}{3} < \pi, y = \tan x \text{在} \left(\frac{\pi}{2}, \pi\right)$ 上单调
> >
> > 递增，所以 $\tan\frac{19\pi}{30}<\tan\frac{2\pi}{3}$ ，即 $f\left(-\frac{\pi}{12}\right)>f\left(\frac{2\pi}{5}\right)$ ，故 C 正确；
> >
> > 由 $f(x) = \tan \left(2x - \frac{\pi}{6}\right) < 1$ ，所以 $-\frac{\pi}{2} + k\pi < 2x - \frac{\pi}{6} < \frac{\pi}{4} + k\pi, k \in \mathbb{Z}$
> >
> > 即 $-\frac{\pi}{6}+\frac{k\pi}{2}<x<\frac{5\pi}{24}+\frac{k\pi}{2},k\in Z$ ，故 D 错误.
> >
> > 故选 **ABC**.
