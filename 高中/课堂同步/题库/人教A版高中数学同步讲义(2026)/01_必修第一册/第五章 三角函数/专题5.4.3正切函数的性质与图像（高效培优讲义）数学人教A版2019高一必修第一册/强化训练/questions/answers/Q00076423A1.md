> [!faq]- 《专题5.4.3正切函数的性质与图像（高效培优讲义）数学人教A版2019高一必修第一册》官方解析
>
> > [!success]- **【答案】** $^{(1)}$ 最大值为 1 (2) $\left(\frac{2}{3},1\right]$
>
> > [!note]- **【解析】**
> > （1）当 $x \in \left(-\frac{\pi}{3}, \frac{\pi}{6}\right)$ 时，可得 $\omega x + \frac{\pi}{3} \in \left(-\frac{\omega\pi}{3} + \frac{\pi}{3}, \frac{\omega\pi}{6} + \frac{\pi}{3}\right)$
> >
> > 因为函数 $f(x)=\tan\left(\omega x+\frac{\pi}{3}\right)(\omega>0)$ 在区间 $\left(-\frac{\pi}{3},\frac{\pi}{6}\right)$ 上单调，
> >
> > 则满足 $\left\{ \begin{array}{ll} - \frac{\omega\pi}{3} +\frac{\pi}{3} & -\frac{\pi}{2}\\  \frac{\omega\pi}{6} +\frac{\pi}{3}\leq \frac{\pi}{2} & \text{，解得} \\ 0 <   \omega \leq 1 & \omega \end{array} \right.$ ，故的最大值为 $^{1}$
> >
> > (2) 由函数 $f(x)=\tan\left(\omega x+\frac{\pi}{3}\right)(\omega>0)$
> >
> > 可得图象的对称中心满足 $\omega x + \frac{\pi}{3} = \frac{k\pi}{2}, k \in Z$ ，整理得 $x = \frac{(3k - 2)\pi}{6\omega}, k \in Z$
> >
> > 其图象在区间 $\left(0,\pi\right)$ 上至少有两个对称中心，则 $x = \frac{(3k - 2)\pi}{6\omega}, k \in \mathbb{Z}$
> >
> > 因为在区间 $(0, \pi)$ 上至少有两个不同的解，所以至少存在两个 $k$ 值使 $0 < 3k - 2 < 6\omega$
> >
> > 所以至少有 k=1,2 两个取值，所以 $\omega>\frac{2}{3}$
> >
> > 综上可得， $\omega$ 的取值范围为 $\left(\frac{2}{3}, 1\right]$
> >
> > 18. 函数 $f(x) = 3 \tan (\omega x + \varphi)$ 中， $\omega > 0, \varphi \in \left(0, \frac{\pi}{2}\right)$ ，最小正周期为 $\frac{\pi}{2}$ ， $f(0) = 3\sqrt{3}$
> >
> > (1)求 $\omega, \varphi$ ;
> >
> > (2)求函数 $f(x)$ 在 $\left(\frac{\pi}{6},\frac{5\pi}{12}\right]$ 上的值域；
> >
> > (3)求不等式组 $-\sqrt{3} < f(x) < 3$ 的解集.
> >
> > 【答案】(1) $\omega = 2$ ， $\varphi = \frac{\pi}{3}$ (2） $\left(-3\sqrt{3},\sqrt{3}\right]$ (3） $\left\{x\left|\frac{k}{2}\pi -\frac{\pi}{4} < x <   \frac{k}{2}\pi -\frac{\pi}{24},k\in \mathbf{Z}\right.\right\}$
> >
> > 【详解】（1）∵最小正周期为 $\frac{\pi}{\omega}=\frac{\pi}{2}$ ，∴ $\omega=2$ ，又∵ $f(0)=3\tan\varphi=3\sqrt{3}$ ，∴ $\tan\varphi=\sqrt{3}$
> >
> > 又∵ $\varphi\in\left(0,\frac{\pi}{2}\right)$ ，∴ $\varphi=\frac{\pi}{3}$
> >
> > (2) $\because f(x) = 3\tan \left(2x + \frac{\pi}{3}\right)$ ，∴当 $x\in \left(\frac{\pi}{6},\frac{5\pi}{12}\right]$ 时， $2x + \frac{\pi}{3}\in \left(\frac{2\pi}{3},\frac{7\pi}{6}\right]$
> >
> > ∴函数 $f(x)$ 在 $\left(\frac{\pi}{6},\frac{5\pi}{12}\right]$ 上的值域为 $\left(-3\sqrt{3},\sqrt{3}\right]$ .
> >
> > $$
> > \left(3\right) \because - \sqrt {3} <   3 \tan \left(2 x + \frac {\pi}{3}\right) <   3, \therefore - \frac {\sqrt {3}}{3} <   \tan \left(2 x + \frac {\pi}{3}\right) <   1
> > $$
> >
> > ∴ $k\pi - \frac{\pi}{6} < 2x + \frac{\pi}{3} < k\pi + \frac{\pi}{4}$ ，其中 $k \in Z$ ，∴ $\frac{k}{2}\pi - \frac{\pi}{4} < x < \frac{k}{2}\pi - \frac{\pi}{24}$ ，
> >
> > 即不等式的解集为 $\left\{x\left|\frac{k}{2}\pi -\frac{\pi}{4} < x < \frac{k}{2}\pi -\frac{\pi}{24},k\in \mathbf{Z}\right.\right\}$
