> [!faq]- 《专题5.4.3正切函数的性质与图像（高效培优讲义）数学人教A版2019高一必修第一册》官方解析
>
> > [!success]- **【答案】** D
>
> > [!note]- **【解析】**
> > 对于 $^{A}$ ，当x>0时， $y=x+\frac{1}{x}\quad2\sqrt{x\cdot\frac{1}{x}}=2$ ，当且仅当 $x=\frac{1}{x}$ 即x=1时等号成立，
> >
> > 当 $x < 0$ 时， $y = x + \frac{1}{x} = -\left[(-x) + \left(-\frac{1}{x}\right)\right] \leq -2\sqrt{(-x)\left(-\frac{1}{x}\right)} = -2$
> >
> > 当且仅当 $-x = -\frac{1}{x}$ 即 x = -1 时等号成立·故 A 不符合；
> >
> > 对于 B，因为 $0 < x < \frac{\pi}{2}$ ，所以 $0 < \sin x < 1$ ，
> >
> > 所以 $y = \sin x + \frac{1}{\sin x}$ $2\sqrt{\sin x \cdot \frac{1}{\sin x}} = 2$ ，当且仅当 $\sin x = \frac{1}{\sin x}$ 即 $\sin x = 1$ 时等号成立，
> >
> > 但 $\sin x \neq 1$ ，所以 $y = \sin x + \frac{1}{\sin x} > 2$ ，故 B 不符合；
> >
> > 对于 C，因为 $t = \sqrt{x^{2} + 2}$ $\sqrt{2}$ ，函数 $y = t + \frac{1}{t}$ 在 $t \in [1, +\infty)$ 上单调递增，
> >
> > 所以 $y=\sqrt{x^{2}+2}+\frac{1}{\sqrt{x^{2}+2}}=t+\frac{1}{t}\quad\sqrt{2}+\frac{1}{\sqrt{2}}=\frac{3\sqrt{2}}{2}>2$ ，故 C 不符合；
> >
> > 对于 D，因为 $0 < x < \frac{\pi}{2}$ ，所以 $\tan x > 0$ ，
> >
> > 所以 $y = \tan x + \frac{1}{\tan x}$ $2\sqrt{\tan x \cdot \frac{1}{\tan x}} = 2$ ，当且仅当 $\tan x = 1$ ，即 $x = \frac{\pi}{4}$ 时等号成立，故 D 符合.
> >
> > 故选：D.
> >
> > ## 方法技巧
> >
> > 一般函数的值域求法有：观察法、配方法、判别式法、反比例函数法等，而三角函数是函数的特殊形式，其
> >
> > 一般方法也适用，只不过要结合三角函数本身的性质。
