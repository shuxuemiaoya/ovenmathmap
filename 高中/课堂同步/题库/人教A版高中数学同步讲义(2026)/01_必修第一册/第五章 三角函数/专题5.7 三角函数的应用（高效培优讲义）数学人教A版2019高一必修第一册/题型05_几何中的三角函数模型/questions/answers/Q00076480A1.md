> [!faq]- 《专题5.7 三角函数的应用（高效培优讲义）数学人教A版2019高一必修第一册》官方解析
>
> > [!success]- **【答案】** (1) $l=\frac{25(\sin\alpha+\cos\alpha+1)}{\sin\alpha\cos\alpha}$ ; $\left[\frac{\pi}{6},\frac{\pi}{3}\right]$ (2) 详见解析； $200000(\sqrt{2}+1)$ 元.
>
> > [!note]- **【解析】**
> > （1）在 Rt $\triangle BOE$ 中，OB = 25， $\angle B = 90^{\circ}$ ， $\angle BOE = \alpha$ ，所以 $OE = \frac{25}{\cos\alpha}$
> >
> > 在 Rt $\triangle AOF$ 中， $\angle AFO = \alpha$ ，即 $OF = \frac{25}{\sin\alpha}$ ，又 $\angle EOF = 90^{\circ}$
> >
> > 所以 $EF = \sqrt{OE^{2} + OF^{2}} = \frac{25}{\sin\alpha\cos\alpha}$
> >
> > 所以 $\triangle OEF$ 的周长 $l = OE + OF + EF = \frac{25}{\cos\alpha} + \frac{25}{\sin\alpha} + \frac{25}{\sin\alpha\cos\alpha}$
> >
> > $$
> > l = \frac {2 5 (\sin \alpha + \cos \alpha + 1)}{\sin \alpha \cos \alpha}
> > $$
> >
> > 当点 $F$ 在点 $D$ 时，角 $\alpha$ 最小，此时 $\alpha = \frac{\pi}{6}$
> >
> > 当点 E 在点 C 时，角 $\alpha$ 最大，此时 $\alpha = \frac{\pi}{3}$ ;
> >
> > 故此函数的定义域是 $\left[\frac{\pi}{6},\frac{\pi}{3}\right]$
> >
> > (2) 由题意可知，只需求出 $\triangle OEF$ 的周长 $l$ 的最小值即可
> >
> > 设 $\sin\alpha+\cos\alpha=t$ ，则 $\sin\alpha\cos\alpha=\frac{t^{2}-1}{2}$
> >
> > 则原函数可化简为 $l = \frac{25(t + 1)}{\frac{t^2 - 1}{2}} = \frac{50}{t - 1}$
> >
> > 因为 $\alpha \in \left[\frac{\pi}{6},\frac{\pi}{3}\right]$ ，所以 $\alpha +\frac{\pi}{4}\in \left[\frac{5\pi}{12},\frac{7\pi}{12}\right], t = \sqrt{2}\sin \left(\alpha +\frac{\pi}{4}\right)$
> >
> > 则 $\frac{\sqrt{3} + 1}{2} \leq t \leq \sqrt{2}$
> >
> > 则 $\frac{\sqrt{3} - 1}{2} \leq t - 1 \leq \sqrt{2} - 1$
> >
> > 从而 $\sqrt{2} + 1 \leq \frac{1}{t - 1} \leq \sqrt{3} + 1$
> >
> > 则当 $t = \sqrt{2}$ 时，即 $\alpha = \frac{\pi}{4}$ 时， $l_{\min} = 50(\sqrt{2} + 1)$ ；
> >
> > 即当 BE = AF = 25 米时，铺路总费用最低，最低总费用为 $200000(\sqrt{2} + 1)$ 元·
