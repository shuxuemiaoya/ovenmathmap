> [!faq]- 《第五章 三角函数（高效培优讲义）数学人教A版2019高一必修第一册》官方解析
>
> > [!success]- **【答案】** (1) $(-∞,2+√3)$ (2) $\left(-\frac{3}{2},\frac{3}{2}\right)$
>
> > [!note]- **【解析】**
> > （1）因为 $f(x) = \sin (2x + \varphi)(0 < \varphi < \pi)$ 为偶函数，
> >
> > 所以 $\varphi = \frac{\pi}{2}$ ， $f(x) = \cos 2x$
> >
> > $$
> > g (x) = f (x) + f \left(x + \frac {\pi}{6}\right) = \cos 2 x + \cos \left(2 x + \frac {\pi}{3}\right) = \cos 2 x + \frac {1}{2} \cos 2 x - \frac {\sqrt {3}}{2} \sin 2 x
> > $$
> >
> > $$
> > = \frac {3}{2} \cos 2 x - \frac {\sqrt {3}}{2} \sin 2 x = \sqrt {3} \cos \left(2 x + \frac {\pi}{6}\right)
> > $$
> >
> > 当 $x\in \left[0,\frac{\pi}{2}\right]$ 时， $2x + \frac{\pi}{6}\in \left[\frac{\pi}{6},\frac{7\pi}{6}\right]$
> >
> > 所以 $\cos\left(2x+\frac{\pi}{6}\right)\in\left[-1,\frac{\sqrt{3}}{2}\right]$
> >
> > 所以 $g(x)=\sqrt{3}\cos\left(2x+\frac{\pi}{6}\right)\in\left[-\sqrt{3},\frac{3}{2}\right]$
> >
> > 又因为存在 $x \in \left[0, \frac{\pi}{2}\right]$ ，使不等式 $g(x) + m < 2$ 成立，
> >
> > 即 $m < 2 - g(x)$ 成立，
> >
> > 因为 $2 - g(x)\in \left[\frac{1}{2},2 + \sqrt{3}\right]$ ，所以 $m <   2 + \sqrt{3}$
> >
> > 即实数 m 的取值范围为 $\left(-\infty,2+\sqrt{3}\right)$ .
> >
> > (2) 因为函数 $f(x)$ 的图象过点 $\left(\frac{\pi}{3}, \frac{1}{2}\right)$ ，且 $0 < \varphi < \pi$
> >
> > 所以 $\sin\left(\frac{2\pi}{3}+\varphi\right)=\frac{1}{2}$ ，解得 $\varphi=\frac{\pi}{6}$
> >
> > 所以 $f(x) = \sin \left(2x + \frac{\pi}{6}\right)$
> >
> > 所以当 $x_{2} \in \left[0, \frac{\pi}{2}\right]$ 时， $2x_{2} + \frac{\pi}{6} \in \left[\frac{\pi}{6}, \frac{7\pi}{6}\right]$
> >
> > 所以 $f(x_{2})=\sin\left(2x_{2}+\frac{\pi}{6}\right)\in\left[-\frac{1}{2},1\right]$
> >
> > 又 $h(x)=\cos^{2}x+2a\sin x=-\sin^{2}x+2a\sin x+1$
> >
> > 当 $x_{1}\in \left[-\frac{\pi}{2},\frac{\pi}{2}\right]$ 时， $\sin x_1\in [-1,1]$
> >
> > 令 $t = \sin x_{1}\in [-1,1]$ ，则 $h(x)$ 即为 $\varphi (t) = -t^2 +2at + 1$
> >
> > 因为 $\varphi(t)$ 的开口向下，对称轴为 t=a ，
> >
> > 当 $a = 1$ ， $\varphi (t)_{\mathrm{max}} = \varphi (1) = 2a$
> >
> > 由 $2a < 1 + 2$ ，解得 $a < \frac{3}{2}$ ，所以 $1 \leq a < \frac{3}{2}$ ；
> >
> > 当 $-1 < a < 1$ 时， $\varphi(t)_{\max} = \varphi(a) = a^2 + 1$
> >
> > 由 $a^2 + 1 < 1 + 2$ ，解得 $-\sqrt{2} < a < \sqrt{2}$ ，所以 $-1 < a < 1$ ；
> >
> > 当 $a \leq -1$ 时， $\varphi(t)_{\max} = \varphi(-1) = -2a$
> >
> > 由 $-2a < 1 + 2$ ，解得 $a > -\frac{3}{2}$ ，所以 $-\frac{3}{2} < a \leq -1$
> >
> > 综上， $-\frac{3}{2}<a<\frac{3}{2}$ ，
> >
> > 即实数 $a$ 的取值范围为 $\left(-\frac{3}{2}, \frac{3}{2}\right)$
