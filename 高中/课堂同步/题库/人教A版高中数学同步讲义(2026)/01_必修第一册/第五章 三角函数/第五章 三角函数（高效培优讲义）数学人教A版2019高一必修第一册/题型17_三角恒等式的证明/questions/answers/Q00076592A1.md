> [!faq]- 《第五章 三角函数（高效培优讲义）数学人教A版2019高一必修第一册》官方解析
>
> > [!success]- **【答案】** $(1)^{\frac{3}{4}}$ ； $(2)^{2}$ ； $(3)^{3}$ 证明见解析.
>
> > [!note]- **【解析】**
> > （1）由 $4\sin \alpha + 3\cos \alpha = 0$ ，则 $\tan \alpha = -\frac{3}{4}$
> >
> > $$
> > \frac {\cos \left(\frac {\pi}{2} + \alpha\right) \sin (- \pi - \alpha)}{\cos \left(\frac {5 \pi}{2} - \alpha\right) \sin \left(\frac {9 \pi}{2} + \alpha\right)} = \frac {- \sin \alpha [ - \sin (\pi + \alpha) ]}{\cos \left(\frac {\pi}{2} - \alpha\right) \sin \left(\frac {\pi}{2} + \alpha\right)} = \frac {- \sin \alpha \cdot \sin \alpha}{\sin \alpha \cdot \cos \alpha} = - \tan \alpha = \frac {3}{4}.
> > $$
> >
> > $$
> > \left(^ {2}\right) \text {原式} = \frac {2 \sin 5 0 ^ {\circ} + \cos 1 0 ^ {\circ} \left(1 + \sqrt {3} \frac {\sin 1 0 ^ {\circ}}{\cos 1 0 ^ {\circ}}\right)}{\sqrt {1 + \cos 1 0 ^ {\circ}}} = \frac {2 \sin 5 0 ^ {\circ} + \cos 1 0 ^ {\circ} \left(\frac {\cos 1 0 ^ {\circ} + \sqrt {3} \sin 1 0 ^ {\circ}}{\cos 1 0 ^ {\circ}}\right)}{\sqrt {1 + \cos 1 0 ^ {\circ}}}
> > $$
> >
> > $$
> > = \frac {2 \sin 5 0 ^ {\circ} + \cos 1 0 ^ {\circ} + \sqrt {3} \sin 1 0 ^ {\circ}}{\sqrt {1 + \cos 1 0 ^ {\circ}}} = \frac {2 \sin 5 0 ^ {\circ} + 2 \left(\frac {1}{2} \cos 1 0 ^ {\circ} + \frac {\sqrt {3}}{2} \sin 1 0 ^ {\circ}\right)}{\sqrt {1 + \cos 1 0 ^ {\circ}}}
> > $$
> >
> > $$
> > = \frac {2 \sin 5 0 ^ {\circ} + 2 \sin (3 0 ^ {\circ} + 1 0 ^ {\circ})}{\sqrt {1 + \cos 1 0 ^ {\circ}}} = \frac {2 \sin 5 0 ^ {\circ} + 2 \cos 5 0 ^ {\circ}}{\sqrt {1 + \cos 1 0 ^ {\circ}}} = \frac {2 \sqrt {2} \left(\frac {\sqrt {2}}{2} \sin 5 0 ^ {\circ} + \frac {\sqrt {2}}{2} \cos 5 0 ^ {\circ}\right)}{\sqrt {1 + \cos 1 0 ^ {\circ}}} = \frac {2 \sqrt {2} \sin (5 0 ^ {\circ} + 4 5 ^ {\circ})}{\sqrt {2} \cos 5 ^ {\circ}}
> > $$
> >
> > $$
> > = \frac {2 \sqrt {2} \sin 9 5 ^ {\circ}}{\sqrt {2} \cos 5 ^ {\circ}} = \frac {2 \cos 5 ^ {\circ}}{\cos 5 ^ {\circ}} = 2.
> > $$
> >
> > $$
> > \text {(3)} \text {左边} = \lg \left(\cos x \times \frac {\sin x}{\cos x} + 1 - 2 \sin^ {2} \frac {x}{2}\right) + \lg \left(\sqrt {2} \cos \left(x - \frac {\pi}{4}\right)\right)
> > $$
> >
> > $$
> > = \lg (\sin x + \cos x) + \lg \left(\sqrt {2} \cos x \cos \frac {\pi}{4} + \sqrt {2} \sin x \sin \frac {\pi}{4}\right) = \lg (\sin x + \cos x) ^ {2} = \lg (1 + \sin 2 x), \text {得证.}
> > $$
