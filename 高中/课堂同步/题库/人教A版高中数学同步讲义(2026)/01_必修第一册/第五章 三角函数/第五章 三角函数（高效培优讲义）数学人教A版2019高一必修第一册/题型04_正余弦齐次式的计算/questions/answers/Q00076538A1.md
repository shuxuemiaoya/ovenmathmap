> [!faq]- 《第五章 三角函数（高效培优讲义）数学人教A版2019高一必修第一册》官方解析
>
> > [!success]- **【答案】** D
>
> > [!note]- **【解析】**
> > 由 $\sin \theta +\cos \theta = \frac{1}{5}$ 可得 $\left(\sin \theta +\cos \theta\right)^2 = \frac{1}{25}$ ，即 $\sin^2\theta +2\sin \theta \cos \theta +\cos^2\theta = \frac{1}{25}$
> >
> > 所以 $2\sin\theta\cos\theta=-\frac{24}{25}$ ，即 $\sin\theta\cos\theta=-\frac{12}{25}$ ，即 A 错误；
> >
> > 又 $\theta \in (0, \pi)$ ，所以 $\sin \theta > 0, \cos \theta < 0$ ，因此 $\sin \theta - \cos \theta > 0$
> >
> > 所以 $\sin\theta-\cos\theta=\sqrt{\left(\sin\theta-\cos\theta\right)^{2}}=\sqrt{\sin^{2}\theta-2\sin\theta\cos\theta+\cos^{2}\theta}=\sqrt{\frac{49}{25}}=\frac{7}{5}$ ，即 B 错误；
> >
> > 联立 $\left\{ \begin{array}{l} \sin \theta + \cos \theta = \frac{1}{5} \\ \sin \theta - \cos \theta = \frac{7}{5} \end{array} \right.$ ，可得 $\sin \theta = \frac{4}{5}, \cos \theta = -\frac{3}{5}$
> >
> > 所以 $\tan\theta=\frac{\sin\theta}{\cos\theta}=\frac{\frac{4}{5}}{-\frac{3}{5}}=-\frac{4}{3}$ ，即 C 错误；
> >
> > 代入计算可得 $\sin\theta\cos\theta-\cos^{2}\theta=\frac{4}{5}\times\left(-\frac{3}{5}\right)-\left(-\frac{3}{5}\right)^{2}=-\frac{12}{25}-\frac{9}{25}=-\frac{21}{25}$ ，即 D 正确.
> >
> > 故选：D
> >
> > ## 方法技巧
> >
> > 已知 $\tan \alpha = m$
> >
> > (1) 分式齐 1 次式
> >
> > $$
> > \frac {a \sin \alpha + b \cos \alpha}{c \sin \alpha + d \cos \alpha} = \frac {(a \sin \alpha + b \cos \alpha) / \cos \alpha}{(c \sin \alpha + d \cos \alpha) / \cos \alpha} = \frac {a \tan \alpha + b}{c \tan \alpha + d}
> > $$
> >
> > ## (2) 分式齐 2 次式
> >
> > $$
> > \frac {a \sin^ {2} \alpha + b \sin \alpha \cos \alpha + c \cos^ {2} \alpha}{d \sin^ {2} \alpha + e \sin \alpha \cos \alpha + f \cos^ {2} \alpha} = \frac {a \tan^ {2} \alpha + b \tan \alpha + c}{a \tan^ {2} \alpha + e \tan \alpha + f}
> > $$
> >
> > (3) 齐2次整式
> >
> > $$
> > a \sin^ {2} \alpha + b \sin \alpha \cos \alpha + c \cos^ {2} \alpha = \frac {a \sin^ {2} \alpha + b \sin \alpha \cos \alpha + c \cos^ {2} \alpha}{1}
> > $$
> >
> > $$
> > = \frac {a \sin^ {2} \alpha + b \sin \alpha \cos \alpha + c \cos^ {2} \alpha}{\sin^ {2} \alpha + \cos^ {2} \alpha} = \frac {a \tan^ {2} \alpha + b \tan \alpha + c}{\tan^ {2} \alpha + 1}
> > $$
