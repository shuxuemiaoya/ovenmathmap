> [!faq]- 《第五章 三角函数（高效培优讲义）数学人教A版2019高一必修第一册》官方解析
>
> > [!success]- **【答案】** （1）（Ⅰ） $^{10}$ ；（Ⅱ） $\frac{3}{2}$ ；（2） $\tan\alpha=-\frac{1}{2}\quad\tan\alpha=-\frac{1}{3}$ 或
>
> > [!note]- **【解析】**
> > （1）因为 $\tan\alpha=3$
> >
> > 所以（1） $\frac{3\sin\alpha + \cos\alpha}{2\sin\alpha - 5\cos\alpha} = \frac{3\tan\alpha + 1}{2\tan\alpha - 5} = \frac{3\times 3 + 1}{2\times 3 - 5} = 10$
> >
> > $$
> > \sin^ {2} \alpha + 2 \sin \alpha \cdot \cos \alpha = \frac {\sin^ {2} \alpha + 2 \sin \alpha \cdot \cos \alpha}{\sin^ {2} \alpha + \cos^ {2} \alpha} = \frac {\tan^ {2} \alpha + 2 \tan \alpha}{\tan^ {2} \alpha + 1} = \frac {3 ^ {2} + 2 \times 3}{3 ^ {2} + 1} = \frac {3}{2}. \tag {II}
> > $$
> >
> > $$
> > (2) \text {由} 5 \sin^ {2} \alpha + 5 \sin \alpha \cos \alpha + 1 = 0 \text {得} \frac {5 \sin^ {2} \alpha + 5 \sin \alpha \cos \alpha + \sin^ {2} \alpha + \cos^ {2} \alpha}{\sin^ {2} \alpha + \cos^ {2} \alpha} = 0
> > $$
> >
> > $$
> > \frac {6 \sin^ {2} \alpha + 5 \sin \alpha \cos \alpha + \cos^ {2} \alpha}{\sin^ {2} \alpha + \cos^ {2} \alpha} = \frac {6 \tan^ {2} \alpha + 5 \tan \alpha + 1}{\tan^ {2} \alpha + 1} = 0
> > $$
> >
> > $6\tan^{2}\alpha+5\tan\alpha+1=0$ ，解得 $\tan\alpha=-\frac{1}{2}$ 或 $\tan\alpha=-\frac{1}{3}$
> >
> > $\alpha$ 是第四象限角， $\tan\alpha<0$ ，均符合题意，
> >
> > 所以 $\tan\alpha=-\frac{1}{2}$ 或 $\tan\alpha=-\frac{1}{3}$
