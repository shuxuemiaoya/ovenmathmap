> [!faq]- 《第五章 三角函数（高效培优讲义）数学人教A版2019高一必修第一册》官方解析
>
> > [!success]- **【答案】** (1) $f(x)=\cos x(x\neq\frac{k\pi}{2},k\in\mathbb{Z})$ (2) $\tan x = 2$ (3) $[k\pi - \frac{5\pi}{12}, k\pi + \frac{\pi}{12}](k \in \mathbb{Z})$
>
> > [!note]- **【解析】**
> > （1）依题意， $f(x)=\frac{\sin x(-\cos x)(-\cos x)\sin x}{\cos x(-\sin x)(-\sin x)}=\cos x$
> >
> > 由 $\sin x \cos x \neq 0$ 得 $x \neq \frac{k\pi}{2}, k \in Z$
> >
> > 所以 $f(x)$ 的解析式为 $f(x)=\cos x(x\neq\frac{k\pi}{2},k\in\mathbb{Z})$
> >
> > (2) 由 (1) 及 $f(x) + 2f\left(x - \frac{\pi}{2}\right) = \sqrt{5}$ ，得 $\cos x + 2\cos \left(x - \frac{\pi}{2}\right) = \sqrt{5}$ ，则 $2\sin x + \cos x = \sqrt{5}$
> >
> > 两边平方得 $4\sin^{2}x + 4\sin x \cos x + \cos^{2}x = 5 = 5\sin^{2}x + 5\cos^{2}x$
> >
> > 整理得 $(\sin x - 2\cos x)^{2} = 0$ ，因此 $\sin x = 2\cos x$ ，所以 $\tan x = 2 \cdot$
> >
> > (3) 由 $\cos (\omega x + \frac{5\pi}{6}) = \frac{\sqrt{3}}{2}$ ，得 $\omega x_{1} + \frac{5\pi}{6} = -\frac{\pi}{6} + 2k_{1}\pi, \omega x_{2} + \frac{5\pi}{6} = \frac{\pi}{6} + 2k_{2}\pi, k_{1}, k_{2} \in \mathbb{Z}$ 由 $|AB| = \frac{\pi}{6}$ ，得 $|x_{1} - x_{2}|_{\min} = \frac{\pi}{6}$ ，因此 $\omega |x_1 - x_2|_{\min} = \frac{\pi}{3}$ ，解得 $\omega = 2$ ， $g(x) = \cos (2x + \frac{5\pi}{6})$ 由 $2k\pi \leq 2x + \frac{5\pi}{6} \leq 2k\pi + \pi, k \in \mathbb{Z}$ ，解得 $k\pi - \frac{5\pi}{12} \leq x \leq k\pi + \frac{\pi}{12}, k \in \mathbb{Z}$ 所以 $g(x)$ 的单调递减区间为 $[k\pi - \frac{5\pi}{12}, k\pi + \frac{\pi}{12}](k \in \mathbb{Z})$
