> [!faq]- 《第五章 三角函数（高效培优讲义）数学人教A版2019高一必修第一册》官方解析
>
> > [!success]- **【答案】** A. 2022 B. 2023 C. 2024 D. 2025
>
> > [!note]- **【解析】**
> > 由题意，函数 $f(x) = \frac{4}{2^x + 2} + \sin \pi x$ ，
> >
> > 可得 $f(x) + f(2 - x) = \frac{4}{2^x + 2} + \sin \pi x + \frac{4}{2^{2 - x} + 2} + \sin [\pi (2 - x)] = \frac{4}{2^x + 2} + \frac{4 \cdot 2^x}{4 + 2 \cdot 2^x} = \frac{4}{2^x + 2} + \frac{2 \cdot 2^x}{2 + 2^x} = 2$
> >
> > 所以 $f\left(\frac{1}{1013}\right)+f\left(\frac{2}{1013}\right)+\cdots+f\left(\frac{2025}{1013}\right)$
> >
> > $$
> > = f \left(\frac {1}{1 0 1 3}\right) + f \left(\frac {2 0 2 5}{1 0 1 3}\right) + f \left(\frac {2}{1 0 1 3}\right) + f \left(\frac {2 0 2 4}{1 0 1 3}\right) + \dots + f \left(\frac {1 0 1 2}{1 0 1 3}\right) + f \left(\frac {1 0 1 4}{1 0 1 3}\right) + f \left(\frac {1 0 1 3}{1 0 1 3}\right)
> > $$
> >
> > $$
> > = 2 \times 1 0 1 2 + \frac {4}{2 ^ {1} + 2} + \sin \pi = 2 0 2 4 + 1 + 0 = 2 0 2 5
> > $$
> >
> > 故选 **D**.
