> [!faq]- 《第五章 三角函数（高效培优讲义）数学人教A版2019高一必修第一册》官方解析
>
> > [!success]- **【答案】** A
>
> > [!note]- **【解析】**
> > 由 $\sin B = 4\sin A\cos C$ ，得 $\sin (A + C) = 4\sin A\cos C$
> >
> > 即 $\sin A\cos C + \cos A\sin C = 4\sin A\cos C$ ，所以 $\cos A\sin C = 3\sin A\cos C$
> >
> > 易知 $\cos A\cos C\neq 0$ ，则 $\tan C = 3\tan A$ ，显然 $\tan A > 0$
> >
> > 所以 $\tan(C-A)=\frac{\tan C-\tan A}{1+\tan C\tan A}=\frac{2\tan A}{1+3\tan^{2}A}=\frac{2}{\frac{1}{\tan A}+3\tan A}$
> >
> > 法一： $\tan (C - A) = \frac{2}{\frac{1}{\tan A} + 3\tan A} \leq \frac{2}{2\sqrt{\frac{1}{\tan A} \cdot 3\tan A}} = \frac{\sqrt{3}}{3}$
> >
> > 当且仅当 $\tan A = \frac{\sqrt{3}}{3}$ 时， $\tan (C - A)$ 取得最大值 $\frac{\sqrt{3}}{3}$ ，此时 $\tan C = 3\tan A = \sqrt{3}$
> >
> > 由三角形内角范围，知 $C=\frac{\pi}{3}$ ；
> >
> > 法二：令 $t = \tan A > 0, f(t) = 3t + \frac{1}{t}$ ，
> >
> > 由对勾函数的性质， $f(t)$ 的最小值为 $2\sqrt{3}$ ，当且仅当 $t = \frac{\sqrt{3}}{3}$ 时取最小值，
> >
> > 所以 $\tan (C - A) \leq \frac{\sqrt{3}}{3}$ ，此时 $\tan C = 3\tan A = \sqrt{3}$
> >
> > 由三角形内角范围，知 $C=\frac{\pi}{3}$
> >
> > 故选 **A**
