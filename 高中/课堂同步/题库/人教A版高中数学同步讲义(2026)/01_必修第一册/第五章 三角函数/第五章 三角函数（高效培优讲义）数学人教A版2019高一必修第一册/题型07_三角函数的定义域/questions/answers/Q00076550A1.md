> [!faq]- 《第五章 三角函数（高效培优讲义）数学人教A版2019高一必修第一册》官方解析
>
> > [!success]- **【答案】** A．函数 $y = \sqrt{2\cos2x + 1}$ 的定义域是 $\left\{\left| x - k\pi - \frac{\pi}{3} \leq x \leq k\pi + \frac{\pi}{3}, k \in Z \right|\right\}$ B．函数 $f(x)=2\sin\left(\frac{\pi}{6}+2x\right)$ 在 $x\in\left[0,\frac{\pi}{2}\right]$ 时的值域为 $[-1,2]$ C．若 $f(x)=\sin\frac{\pi x}{6}$ ，则 $f(1)+f(2)+\cdots+f(2015)$ 的值为 0 D．函数 $y=2\sin\left(\frac{\pi}{6}-2x\right)\left(x\in(0,\pi)\right)$ 的单调递增区间是 $\left(0,\frac{5\pi}{6}\right)$
>
> > [!note]- **【解析】**
> > 对于选项A：令 $2\cos2x+1$ 0，则 $\cos2x - \frac{1}{2}$
> >
> > 可得 $2k\pi - \frac{2\pi}{3} \leq 2x \leq 2k\pi + \frac{2\pi}{3}, k \in \mathbf{Z}$ ，解得 $k\pi - \frac{\pi}{3} \leq x \leq k\pi + \frac{\pi}{3}, k \in \mathbf{Z}$
> >
> > 所以函数 $y = \sqrt{2\cos2x + 1}$ 的定义域是 $\left\{\frac{x}{k}\pi - \frac{\pi}{3} \leq x \leq k\pi + \frac{\pi}{3}, k \in Z\right\}$ ，故 A 正确；
> >
> > 对于选项B：因为 $x\in \left[0,\frac{\pi}{2}\right]$ ，则 $\frac{\pi}{6} +2x\in \left[\frac{\pi}{6},\frac{7\pi}{6}\right]$
> >
> > 可知 $\sin\left(\frac{\pi}{6}+2x\right)\in\left[-\frac{1}{2},1\right]$ ，则 $f(x)\in[-1,2]$ ，故 B 正确；
> >
> > 对于选项 $^{C}$ ：因为 $f(x)$ 的最小正周期 $T=\frac{2\pi}{\frac{\pi}{6}}=12$ ，
> >
> > 又因为 $f(6) = \sin \pi = 0, f(12) = \sin 2\pi = 0$ ，可知 $(6,0)$ 为 $f(x)$ 的对称中心，
> >
> > $$
> > \text {则} f (1) + f (1 1) = f (2) + f (1 0) = f (3) + f (9) = f (4) + f (8) = f (5) + f (7) = 0
> > $$
> >
> > 即 $f(1)+f(2)+\cdots+f(12)=0$ ，且 $2015=167\times12+11$ ，
> >
> > 所以 $f(1)+f(2)+\cdots+f(2015)=f(1)+f(2)+\cdots+f(11)=0$ ，故 C 正确；
> >
> > 对于选项 D：当 $x=\frac{\pi}{12}$ 时， $y=\sin0=0$ ；当 $x=\frac{7\pi}{12}$ 时， $y=\sin(-\pi)=0$ ；
> >
> > 可知函数 $y = 2\sin\left(\frac{\pi}{6} - 2x\right)$ 在 $\left(0, \frac{5\pi}{6}\right)$ 不单调，故 D 错误；
> >
> > 故选 **D**.
