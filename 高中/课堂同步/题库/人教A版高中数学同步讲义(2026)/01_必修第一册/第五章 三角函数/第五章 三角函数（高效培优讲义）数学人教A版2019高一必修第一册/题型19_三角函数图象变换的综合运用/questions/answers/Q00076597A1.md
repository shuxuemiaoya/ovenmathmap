> [!faq]- 《第五章 三角函数（高效培优讲义）数学人教A版2019高一必修第一册》官方解析
>
> > [!success]- **【答案】** (1) $\left(-\frac{\pi}{6}+\frac{k\pi}{2},1\right),k\in\mathbf{Z}$ (2)① $\left\{x\left|-\frac{\pi}{3}\leq x\leq-\frac{\pi}{6}\right.$ 或 $0\leq x\leq\frac{5\pi}{6}\right\}$ ; ② $-\frac{4\sqrt{2}}{9}$
>
> > [!note]- **【解析】**
> > （1）因为 $f(x) = \sin \left(2x - \frac{\pi}{3}\right) + \sqrt{3}\cos 2x + a = \sin 2x\cos \frac{\pi}{3} -\cos 2x\sin \frac{\pi}{3} +\sqrt{3}\cos 2x + a$
> >
> > $$
> > = \frac {1}{2} \sin 2 x + \frac {\sqrt {3}}{2} \cos 2 x + a = \sin \left(2 x + \frac {\pi}{3}\right) + a
> > $$
> >
> > 所以 $f(x)_{\max} = 1 + a = 2$ ，解得 $a = 1$ ，所以 $f(x) = \sin \left(2x + \frac{\pi}{3}\right) + 1$
> >
> > 令 $2x + \frac{\pi}{3} = k\pi, k \in \mathbf{Z}$ ，得 $x = -\frac{\pi}{6} + \frac{k\pi}{2}, k \in \mathbf{Z}$
> >
> > 即 $f(x)$ 图象的对称中心为 $\left(-\frac{\pi}{6} +\frac{k\pi}{2},1\right),k\in \mathbf{Z}$
> >
> > (2) 由题意可得 $g(x) = f\left(x - \frac{\pi}{3}\right) - 1 = \sin \left[2\left(x - \frac{\pi}{3}\right) + \frac{\pi}{3}\right] = \sin \left(2x - \frac{\pi}{3}\right)$
> > - **①**：由 $g(x) - \frac{\sqrt{3}}{2}$ 可得 $\sin\left(2x-\frac{\pi}{3}\right) - \frac{\sqrt{3}}{2}$
> >
> > 解得 $-\frac{\pi}{3} + 2k\pi \leq 2x - \frac{\pi}{3} \leq \frac{4\pi}{3} + 2k\pi, k \in \mathbf{Z}$ ，即 $k\pi \leq x \leq \frac{5\pi}{6} + k\pi, k \in \mathbf{Z}$
> >
> > 又因为 $x \in \left[-\frac{\pi}{3}, \pi\right]$ ，所以 $-\frac{\pi}{3} \leq x \leq -\frac{\pi}{6}$ 或 $0 \leq x \leq \frac{5\pi}{6}$ ，
> >
> > 故不等式的解集为 $\left\{x\left|-\frac{\pi}{3}\leq x\leq-\frac{\pi}{6}\right.0\leq x\leq\frac{5\pi}{6}\right\}$
> > - **②**：因为 $0 < x < \pi$ ，所以 $0 < 2x < 2\pi, -\frac{\pi}{3} < 2x - \frac{\pi}{3} < \frac{5\pi}{3}$ ，
> >
> > 由 $g(x) = \frac{1}{3}$ ，可得 $\sin \left(2x - \frac{\pi}{3}\right) = \frac{1}{3} >0$ ，所以 $0 <   2x - \frac{\pi}{3} <  \pi$
> >
> > 由正弦函数图象的对称性可知 $\frac{2x_1 - \frac{\pi}{3} + 2x_2 - \frac{\pi}{3}}{2} = x_1 + x_2 - \frac{\pi}{3} = \frac{\pi}{2}$
> >
> > 所以 $x_{1} + x_{2} = \frac{5\pi}{6}$ ，且 $0 < 2x_{1} - \frac{\pi}{3} < \frac{\pi}{2}, \frac{\pi}{2} < 2x_{2} - \frac{\pi}{3} < \pi$
> >
> > $$
> > \cos \left(2 x _ {1} - \frac {\pi}{3}\right) = \sqrt {1 - \frac {1}{9}} = \frac {2 \sqrt {2}}{3}
> > $$
> >
> > $$
> > \sin \left(2 x _ {1} - 2 x _ {2}\right) = 2 \sin \left(x _ {1} - x _ {2}\right) \cos \left(x _ {1} - x _ {2}\right) = 2 \sin \left[ x _ {1} - \left(\frac {5 \pi}{6} - x _ {1}\right) \right] \cos \left[ x _ {1} - \left(\frac {5 \pi}{6} - x _ {1}\right) \right]
> > $$
> >
> > $$
> > = 2 \sin \left(2 x _ {1} - \frac {5 \pi}{6}\right) \cos \left(2 x _ {1} - \frac {5 \pi}{6}\right) = 2 \sin \left(2 x _ {1} - \frac {\pi}{3} - \frac {\pi}{2}\right) \cos \left(2 x _ {1} - \frac {\pi}{3} - \frac {\pi}{2}\right)
> > $$
> >
> > $$
> > = - 2 \cos \left(2 x _ {1} - \frac {\pi}{3}\right) \sin \left(2 x _ {1} - \frac {\pi}{3}\right) = - 2 \times \frac {2 \sqrt {2}}{3} \times \frac {1}{3} = - \frac {4 \sqrt {2}}{9}
> > $$

> > ## 方法技巧
> >
> > ## 1、正弦、余弦型函数奇偶性的判断方法
> >
> > 正弦型函数 $y = A\sin (\omega x + \varphi)$ 和余弦型函数 $y = A\cos (\omega x + \varphi)$ 不一定具备奇偶性。对于函数 $y = A\sin (\omega x + \varphi)$ ，当 $\varphi = k\pi (k\in \mathbb{Z})$ 时为奇函数，当 $\varphi = k\pi +(k\in \mathbb{Z})$ 时为偶函数；对于函数 $y = A\cos (\omega x + \varphi)$ ，当 $\varphi = k\pi (k\in \mathbb{Z})$ 时为偶函数，当 $\varphi = k\pi +(k\in \mathbb{Z})$ 时为奇函数。
> >
> > ## 2、与正弦、余弦型函数有关的单调区间的求解技巧
> > - **①**：结合正弦、余弦函数的图象，熟记它们的单调区间。
> > - **②**：确定函数 $y = A \sin (\omega x + \varphi) (A > 0, \omega > 0)$ 单调区间的方法：采用“换元”法整体代换，将 $\omega x + \varphi$ 看作一个整体，可令“ $z = \omega x + \varphi$ ”即通过求 $y = A \sin z$ 的单调区间而求出函数的单调区间。若 $\omega < 0$ ，则可利用诱导公式先将 $x$ 的系数转变为正数，再求单调区间。
