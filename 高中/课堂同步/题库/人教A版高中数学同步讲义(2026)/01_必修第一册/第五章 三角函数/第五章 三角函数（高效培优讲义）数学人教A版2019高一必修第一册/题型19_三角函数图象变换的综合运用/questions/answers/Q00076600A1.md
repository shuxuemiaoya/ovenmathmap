> [!faq]- 《第五章 三角函数（高效培优讲义）数学人教A版2019高一必修第一册》官方解析
>
> > [!success]- **【答案】** (1) $f(x)=\frac{1}{2}\sin\left(2x+\frac{\pi}{3}\right)+1$ ; $\left(-\frac{\pi}{6}+\frac{k\pi}{2},1\right),k\in Z$ (2)① $\left[\frac{3}{4},\frac{3}{2}\right]$ ；② $\sqrt{3}$
>
> > [!note]- **【解析】**
> > （1）由图象可得 $\left\{ \begin{array}{l} A + B = \frac{3}{2} \\ -A + B = \frac{1}{2} \end{array} \right.$ ，解得 $\left\{ \begin{array}{l} A = \frac{1}{2} \\ B = 1 \end{array} \right.$
> >
> > 又 $\frac{T}{2} = \frac{7\pi}{12} -\frac{\pi}{12} = \frac{\pi}{2}$ ，所以 $T = \pi$ ，所以 $\omega = \frac{2\pi}{T} = 2$ ，故 $f(x) = \frac{1}{2}\sin (2x + \varphi) + 1$
> >
> > 又因为 $f(x)$ 过点 $\left(\frac{\pi}{12},\frac{3}{2}\right)$
> >
> > 所以 $\frac{3}{2} = \frac{1}{2}\sin \left(2\times \frac{\pi}{12} +\varphi\right) + 1\Rightarrow \sin \left(\frac{\pi}{6} +\varphi\right) = 1\Rightarrow \frac{\pi}{6} +\varphi = 2k\pi +\frac{\pi}{2},k\in Z$
> >
> > 又 $|\varphi| < \frac{\pi}{2}$ ，所以 $\varphi = \frac{\pi}{3}$ ，故 $f(x) = \frac{1}{2} \sin \left(2x + \frac{\pi}{3}\right) + 1$
> >
> > 令 $2x + \frac{\pi}{3} = k\pi$ ，解得 $x = -\frac{\pi}{6} +\frac{k\pi}{2},k\in Z$
> >
> > 所以 $f(x)$ 的对称中心为 $\left(-\frac{\pi}{6}+\frac{k\pi}{2},1\right), k\in Z$
> >
> > (2) ① 将函数 $y = f(x)$ 的图象上所有的点向左平移 $\frac{\pi}{12}$ 个单位得到
> >
> > $y = \frac{1}{2}\sin \left[2\left(x + \frac{\pi}{12}\right) + \frac{\pi}{3}\right] + 1 = \frac{1}{2}\cos 2x + 1$
> >
> > 再将所得图象上每一个点的横坐标变为原来的 $^{2}$ 倍（纵坐标不变），得到 $y=\frac{1}{2}\cos x+1$
> >
> > 最后将所得图象上所有的点向下平移 $^{1}$ 个单位（横坐标不变），得到函数 $y = g(x)$ 的图象，
> >
> > 则 $g(x)=\frac{1}{2}\cos x$
> >
> > $$
> > h (x) = \frac {1}{2} \sin \left(2 x + \frac {\pi}{3}\right) + 1 - 4 \sqrt {3} \times \left(\frac {1}{4} \cos^ {2} x\right) + \frac {\sqrt {3}}{2}
> > $$
> >
> > $$
> > = \frac {1}{2} \sin 2 x \cdot \frac {1}{2} + \frac {1}{2} \cos 2 x \cdot \frac {\sqrt {3}}{2} + 1 - \sqrt {3} \times \frac {1 + \cos 2 x}{2} + \frac {\sqrt {3}}{2}
> > $$
> >
> > $$
> > = \frac {1}{4} \sin 2 x - \frac {\sqrt {3}}{4} \cos 2 x + 1 = \frac {1}{2} \sin \left(2 x - \frac {\pi}{3}\right) + 1
> > $$
> >
> > 当 $x \in \left[\frac{\pi}{12}, \frac{\pi}{2}\right]$ 时， $2x - \frac{\pi}{3} \in \left[-\frac{\pi}{6}, \frac{2\pi}{3}\right], \sin \left(2x - \frac{\pi}{3}\right) \in \left[-\frac{1}{2}, 1\right], \frac{1}{2} \sin \left(2x - \frac{\pi}{3}\right) + 1 \in \left[\frac{3}{4}, \frac{3}{2}\right]$
> >
> > 即函数 $h(x)$ 在 $\left[\frac{\pi}{12},\frac{\pi}{2}\right]$ 上的值域是 $\left[\frac{3}{4},\frac{3}{2}\right]$
> > - **②**：$g\left(x+\frac{2\pi}{3}\right)-m=0$ ， $\cos\left(x+\frac{2\pi}{3}\right)=2m$
> >
> > 令 $x + \frac{2\pi}{3} = t \in \left[-\frac{5\pi}{12}, 2\pi\right]$ ，则 $\cos t = 2m$ 有三个不同的实数根 $t_1, t_2, t_3 (t_1 < t_2 < t_3)$
> >
> > 由余弦函数的图象的对称性可知， $t_{1} + t_{2} = 2 \times 0 = 0, t_{2} + t_{3} = 2 \times \pi = 2\pi$
> >
> > 所以 $t_1 + 2t_2 + t_3 = 2\pi$ ，即 $\left(x_{1} + \frac{2\pi}{3}\right) + 2\left(x_{2} + \frac{2\pi}{3}\right) + \left(x_{3} + \frac{2\pi}{3}\right) = 2\pi$
> >
> > 所以 $x_{1} + x_{2} + x_{3} = -\frac{2\pi}{3}$ ，所以 $\tan (x_1 + 2x_2 + x_3) = \tan \frac{-2\pi}{3} = \sqrt{3}$
