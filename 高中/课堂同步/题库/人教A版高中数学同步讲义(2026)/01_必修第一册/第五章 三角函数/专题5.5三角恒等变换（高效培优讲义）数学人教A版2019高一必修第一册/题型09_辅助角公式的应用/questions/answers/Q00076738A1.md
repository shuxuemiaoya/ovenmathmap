> [!faq]- 《专题5.5三角恒等变换（高效培优讲义）数学人教A版2019高一必修第一册》官方解析
>
> > [!success]- **【答案】** (1) $f(x)=\sin(2x+\frac{\pi}{6})$ (2) $\frac{-2\sqrt{2}+\sqrt{3}}{6}$ (3) $\left(\frac{\sqrt{3}}{2},\sqrt{3}\right]$
>
> > [!note]- **【解析】**
> > （1） $f(x) = \sin (\frac{\pi}{4} + x)\sin (\frac{\pi}{4} -x) + \sqrt{3}\sin x\cos x = \sin (\frac{\pi}{4} +x)\cos (\frac{\pi}{4} +x) + \sqrt{3}\sin x\cos x$
> >
> > $$
> > = \frac {1}{2} \sin \left(\frac {\pi}{2} + 2 x\right) + \frac {\sqrt {3}}{2} \sin 2 x = \frac {\sqrt {3}}{2} \sin 2 x + \frac {1}{2} \cos 2 x = \sin \left(2 x + \frac {\pi}{6}\right).
> > $$
> >
> > $$
> > \left(^ {2}\right) \text {由} \left(^ {1}\right) \text {知} f (x) = \sin \left(2 x + \frac {\pi}{6}\right), \text {则} f \left(\frac {\pi}{1 2} + \frac {\alpha}{2}\right) = \sin \left[ 2 \left(\frac {\pi}{1 2} + \frac {\alpha}{2}\right) + \frac {\pi}{6} \right] = \sin \left(\alpha + \frac {\pi}{3}\right) = - \frac {2 \sqrt {2}}{3},
> > $$
> >
> > 由 $\pi < \alpha < \frac{7\pi}{6}$ ，得 $\frac{4\pi}{3} < \alpha + \frac{\pi}{3} < \frac{3\pi}{2}$ ，则 $\cos(\alpha + \frac{\pi}{3}) = -\sqrt{1 - \sin^{2}(\alpha + \frac{\pi}{3})} = -\frac{1}{3}$ ，
> >
> > $$
> > \sin \alpha = \sin \left(\alpha + \frac {\pi}{3} - \frac {\pi}{3}\right) = \frac {1}{2} \sin \left(\alpha + \frac {\pi}{3}\right) - \frac {\sqrt {3}}{2} \cos \left(\alpha + \frac {\pi}{3}\right)
> > $$
> >
> > $$
> > = \frac {1}{2} \times \left(- \frac {2 \sqrt {2}}{3}\right) - \frac {\sqrt {3}}{2} \times \left(- \frac {1}{3}\right) = \frac {\sqrt {3} - 2 \sqrt {2}}{6}.
> > $$
> >
> > $$
> > (3) \text {在} V A B C \text {中，} f (\frac {A}{2}) = \sin (A + \frac {\pi}{6}) = 1, \text {由} 0 <   A <   \pi , \text {得} \frac {\pi}{6} <   A + \frac {\pi}{6} <   \frac {7 \pi}{6}
> > $$
> >
> > 则 $A + \frac{\pi}{6} = \frac{\pi}{2}$ ，解得 $A = \frac{\pi}{3}$ ，则 $C = \pi -(A + B) = \frac{2\pi}{3} -B$
> >
> > $$
> > \text {于是} \sin B + \sin C = \sin B + \sin \left(\frac {2 \pi}{3} - B\right) = \frac {3}{2} \sin B + \frac {\sqrt {3}}{2} \cos B = \sqrt {3} \sin \left(B + \frac {\pi}{6}\right),
> > $$
> >
> > 由 $0 < B < \frac{2\pi}{3}$ ，得 $\frac{\pi}{6} < B + \frac{\pi}{6} < \frac{5\pi}{6}$ ，则 $\frac{1}{2} < \sin(B + \frac{\pi}{6}) \leq 1$ ，即 $\frac{\sqrt{3}}{2} < \sin B + \sin C \leq \sqrt{3}$
> >
> > 所以 $\sin B + \sin C$ 的取值范围为 $\left(\frac{\sqrt{3}}{2}, \sqrt{3}\right]$ .
