> [!faq]- 《专题05 函数的定义域及值域高频题型精准突破（八大题型）（高效培优期末专项训练）》官方解析
>
> > [!success]- **【答案】** A. $f(x) = -3x + 2$ B. $f(x) = 3x + 1$ C. $g(x) = x^2 - 4x + 4$ D. $g(x) = x^2 - 2x + 1$
>
> > [!note]- **【分析】**
> > 利用待定系数法设 $f(x) = kx + b$ 解方程组可得 $f(x) = -3x + 2$ ，再由换元法代入计算可得 $g(x) = x^2 - 4x + 4$ ，可得出结论：
>
> > [!note]- **【解析】**
> > 依题意可设 $f(x) = kx + b$
> >
> > 由 $f(f(x)) = 9x - 4$ 可得 $k(kx + b) + b = k^2 x + kb + b = 9x - 4$
> >
> > 因此可得 $\left\{ \begin{array}{l} k^2 = 9 \\ kb + b = -4 \end{array} \right.$ ，解得 $\left\{ \begin{array}{l} k = 3 \\ b = -1 \end{array} \right.$ 或 $\left\{ \begin{array}{l} k = -3 \\ b = 2 \end{array} \right.$ ；
> >
> > 又因为 $f(0) = b > 0$ ，所以 $\left\{ \begin{array}{l}k = -3\\ b = 2 \end{array} \right.$ ，即 $f(x) = -3x + 2$ ，即A正确，B错误；
> >
> > 又 $g(f(x)) = 9x^{2}$ 可得 $g(-3x + 2) = 9x^{2}$
> >
> > 令 $-3x + 2 = t$ ，所以 $x = \frac{2 - t}{3}$ ，因此 $g(t) = 9 \times \left(\frac{2 - t}{3}\right)^{2} = t^{2} - 4t + 4$ ，
> >
> > 所以 $g(x)=x^{2}-4x+4$ ，可得 C 正确，D 错误.
> >
> > 故选 **AC**
