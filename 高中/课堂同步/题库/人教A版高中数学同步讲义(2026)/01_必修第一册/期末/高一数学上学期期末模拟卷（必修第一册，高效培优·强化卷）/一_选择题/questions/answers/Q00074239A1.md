> [!faq]- 《高一数学上学期期末模拟卷（必修第一册，高效培优·强化卷）》官方解析
>
> > [!success]- **【答案】** A. $mn$ 的最大值为 $\frac{1}{2}$ B. $\sqrt{2m} + \sqrt{n}$ 的最大值为 1 C. $\frac{2}{m} + \frac{m}{n}$ 的最小值为 4 D. $\frac{1}{m} + \frac{8}{n}$ 的最小值为 9
>
> > [!note]- **【解析】**
> > 对于 A， $2m + n = 2 \quad 2\sqrt{2mn} \Rightarrow mn \leq \frac{1}{2}$
> >
> > 当且仅当 $\left\{ \begin{array}{l} 2m + n = 2 \\ 2m = n \end{array} \right. \Rightarrow \left\{ \begin{array}{l} m = \frac{1}{2} \\ n = 1 \end{array} \right.$ 时取等号，故A正确；
> >
> > 对于B，当 $m = \frac{1}{2}, n = 1$ 时， $\sqrt{2m} + \sqrt{n} = 2$ ，故B错误；
> >
> > 对于 C， $\frac{2}{m}+\frac{m}{n}=\frac{2m+n}{m}+\frac{m}{n}=2+\frac{n}{m}+\frac{m}{n}\quad2+2\sqrt{\frac{n}{m}\cdot\frac{m}{n}}=4$
> >
> > 当且仅当 $\frac{n}{m} = \frac{m}{n} \Rightarrow m = n = \frac{2}{3}$ 时取等号，故C正确；
> >
> > 对于D， $\frac{1}{2}\left(\frac{1}{m} +\frac{8}{n}\right)(2m + n) = \frac{1}{2}\left(2 + \frac{n}{m} +\frac{16m}{n} +8\right)\quad \frac{1}{2}\left(10 + 2\sqrt{\frac{n}{m}\cdot\frac{16m}{n}}\right) = 9$
> >
> > 当且仅当 $\frac{n}{m} = \frac{16m}{n}\Rightarrow m = \frac{1}{3},n = \frac{4}{3}$ 时取等号，故D正确；
> >
> > 故选 **ACD**.
