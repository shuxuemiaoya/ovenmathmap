> [!faq]- 《专题03 利用基本不等式巧解最值（八大题型）（高效培优期末专项训练）》官方解析
>
> > [!success]- **【答案】** (1) $\frac{1}{16}$ (2)7
>
> > [!note]- **【分析】**
> > （1）利用基本不等式可求得 $y = \frac{1}{2} x(1 - 2x)$ 的最大值；
> >
> > (2) 将函数解析式变形为 $y = (x + 2) + \frac{4}{x + 2} + 3$ ，利用基本不等式可求得该函数的最小值.
>
> > [!note]- **【解析】**
> > （1）因为 $0 < x < \frac{1}{2}$ ，所以 $1 - 2x > 0$ ，
> >
> > 所以 $\frac{1}{2} x(1 - 2x) = \frac{1}{4}\times 2x(1 - 2x)\leq \frac{1}{4}\times \left(\frac{2x + 1 - 2x}{2}\right)^2 = \frac{1}{16}$
> >
> > 当且仅当 $2x = 1 - 2x\left(0 < x < \frac{1}{2}\right)$
> >
> > 即 $x = \frac{1}{4}$ 时，等号成立，故 $y = \frac{1}{2} x(1 - 2x)$ 的最大值为 $\frac{1}{16}$
> >
> > (2) 因为 $x > -2$ ，所以 $x + 2 > 0$
> >
> > 所以 $y=\frac{x^{2}+7x+14}{x+2}=\frac{(x+2)^{2}+3(x+2)+4}{x+2}$
> >
> > $$
> > = (x + 2) + \frac {4}{x + 2} + 3 2 \sqrt {(x + 2) \cdot \frac {4}{x + 2}} + 3 = 7
> > $$
> >
> > 当且仅当 $x + 2 = \frac{4}{x + 2} (x > -2)$ ，即 $x = 0$ 时，等号成立，
> >
> > 所以当 $x = 0$ 时，函数 $y = \frac{x^2 + 7x + 14}{x + 2} (x > -2)$ 取得最小值7.
> >
> > 62. 利用基本不等式求以下最值：
> >
> > (1)若 $0 < x < 4$ ，求 $y = x(12 - 3x)$ 的最大值；
> >
> > (2)已知 $x > 0, y > 0$ ，且 $x + y + 3 = xy$ ，求 $x + y$ 的最小值；
> >
> > (3)求 $y=\frac{x^{2}+6x+12}{x+3}$ 在 $x>-3$ 时的最小值.
> >
> > 【答案】(1)12；
> >
> > (2)6 ;
> >
> > (3) $2\sqrt{3}$
> >
> > 【分析】（1）（2）（3）根据题设前提条件，应用基本不等式求积、和及分式型目标式的最值·
> >
> > 【详解】（1）∵ 0 < x < 4 ⇒ 12 - 3x > 0
> >
> > $$
> > \therefore y = x (1 2 - 3 x) = \frac {1}{3} \times 3 x \times (1 2 - 3 x) \leq \frac {1}{3} \times \left[ \frac {3 x + (1 2 - 3 x)}{2} \right] ^ {2} = 1 2,
> > $$
> >
> > 当且仅当 $3x = 12 - 3x$ ，即 $x = 2$ 时等号成立，
> >
> > $\therefore y = x(12 - 3x)$ 的最大值为12.
> >
> > (2) $\because x > 0, y > 0$ ，则 $(x + y) + 3 = xy \leq \left(\frac{x + y}{2}\right)^2,$
> >
> > 即 $(x+y)^{2}-4(x+y)-12\quad0$ ，解得 $x+y$ 6或 $x+y\leq-2$ （舍），
> >
> > 当且仅当 $x = y$ 且 $x + y + 3 = xy$ ，即 $x = y = 3$ 时等号成立，
> >
> > $\therefore x + y$ 的最小值为6
> >
> > $$
> > (3) \because x > - 3 \Rightarrow x + 3 > 0
> > $$
> >
> > 令 $t = x + 3$ ，则 $t > 0, x = t - 3$
> >
> > 所以 $y=\frac{x^{2}+6x+12}{x+3}$ ，化为 $y=\frac{t^{2}+3}{t}=t+\frac{3}{t}$ ，
> >
> > 而 $y = t + \frac{3}{t}$ $2\sqrt{t\cdot\frac{3}{t}} = 2\sqrt{3}$ ，当且仅当 $t = \frac{3}{t}$ ，即 $t = \sqrt{3}\Rightarrow x = \sqrt{3} -3$ 时等号成立，
> >
> > $\therefore y = \frac{x^2 + 6x + 12}{x + 3}$ 的最小值为 $2\sqrt{3}$ .
