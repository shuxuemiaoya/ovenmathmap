> [!faq]- 《专题03 利用基本不等式巧解最值（八大题型）（高效培优期末专项训练）》官方解析
>
> > [!success]- **【答案】** 31
>
> > [!note]- **【分析】**
> > 由“1”的代换结合基本不等式求解·
>
> > [!note]- **【解析】**
> > 因为 $\frac{1}{x + 1} +\frac{3}{x + y} = \frac{1}{2}$ 得 $\frac{2}{x + 1} +\frac{6}{x + y} = 1$
> >
> > 所以 $4x + 3y = (x + 1) + 3(x + y) - 1 = \left[(x + 1) + 3(x + y)\right]\left(\frac{2}{x + 1} + \frac{6}{x + y}\right) - 1$ $= 2 + 18 + \frac{6(x + y)}{x + 1} + \frac{6(x + 1)}{x + y} - 1 \quad 20 + 2\sqrt{\frac{6(x + y)}{x + 1} \times \frac{6(x + 1)}{x + y}} - 1$ $= 20 + 12 - 1 = 31$ 当且仅当 $\frac{6(x + y)}{x + 1} = \frac{6(x + 1)}{x + y}$ 且 $\frac{2}{x + 1} + \frac{6}{x + y} = 1$ ，即 x = 7, y = 1 时取等号，
> >
> > 所以 $4x + 3y$ 的最小值为 31，
> >
> > 故答案为：31·
