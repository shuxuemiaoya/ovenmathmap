> [!faq]- 《专题03 利用基本不等式巧解最值（八大题型）（高效培优期末专项训练）》官方解析
>
> > [!success]- **【答案】** A．ab 的最大值为 $\frac{1}{4}$ B． $a^2 + 2b^2$ 的最小值 $\frac{3}{4}$ C. $\frac{2}{a} +\frac{1}{ab}$ 的最小值为 $\frac{9}{2}$ D. $\sqrt{a} +\sqrt{b}$ 的最大值为 $\sqrt{2}$
>
> > [!note]- **【分析】**
> > 对 $^{A}$ ，由 $ab \leq \left(\frac{a+b}{2}\right)^{2}$ 求解；对 $^{B}$ ，由消元法化为二次函数求解；对 $^{C}$ ，由“1”的代换求解；对 $^{D}$ ，由 $\sqrt{a} + \sqrt{b} \leq \sqrt{2(a+b)}$ 求解.
>
> > [!note]- **【解析】**
> > 对于 A： $ab \leq \left(\frac{a + b}{2}\right)^{2} = \left(\frac{1}{2}\right)^{2} = \frac{1}{4}$ ，当且仅当 $a = b = \frac{1}{2}$ 时取等号，
> >
> > 即 $ab$ 的最大值是 $\frac{1}{4}$ ，A正确；
> >
> > 对于 B : $a^{2} + 2b^{2} = a^{2} + 2(1 - a)^{2} = 3a^{2} - 4a + 2 = 3\left(a - \frac{2}{3}\right)^{2} + \frac{2}{3}$ ， $a \in (0,1)$ ，
> >
> > 当 $a = \frac{2}{3}$ 时，取得最小值 $\frac{2}{3}$ ， $B$ 错误；
> >
> > 对于 $\mathsf{C}:\frac{2}{a} +\frac{1}{ab} = \frac{2}{a} +\frac{a + b}{ab} = \frac{3}{a} +\frac{1}{b} = (a + b)\left(\frac{3}{a} +\frac{1}{b}\right) = 3 + 1 + \frac{3b}{a} +\frac{a}{b}$ $4 + 2\sqrt{3}$
> >
> > 当且仅当 $\frac{3b}{a} = \frac{a}{b}$ 时取等号，又 $a + b = 1$ ，所以 $a = \frac{3 - \sqrt{3}}{2}, b = \frac{\sqrt{3} - 1}{2}$
> >
> > 所以 $\frac{2}{a} +\frac{1}{ab}$ 的最小值为 $4 + 2\sqrt{3}$ ，C错误；
> >
> > 对于 D： $\sqrt{a}+\sqrt{b}\leq\sqrt{2(a+b)}=\sqrt{2}$ ，当且仅当 $a=b=\frac{1}{2}$ 时取等号，
> >
> > $$
> > \sqrt {a} + \sqrt {b}
> > $$
> >
> > $$
> > \sqrt {2}
> > $$
> >
> > 故选 **AD**.
