> [!faq]- 《专题03 利用基本不等式巧解最值（八大题型）（高效培优期末专项训练）》官方解析
>
> > [!success]- **【答案】** ACD
>
> > [!note]- **【分析】**
> > 根据基本不等式的性质，以及题干所给条件，逐一判断各选项正误，判断结果即可·
>
> > [!note]- **【解析】**
> > 对 A， $ab \leq \left(\frac{a + b}{2}\right)^{2} = \frac{1}{4}$ ，当且仅当 $a = b = \frac{1}{2}$ 时取等号，A 正确；
> >
> > 对 B，结合 A，有 $\frac{1}{a} + \frac{1}{b} = \frac{a + b}{ab} = \frac{1}{ab}$ 4， $a = b = \frac{1}{2}$ 时取等号，B 错；
> >
> > 对 C， $\frac{a}{b}+\frac{1}{a}=\frac{a}{b}+\frac{a+b}{a}=\frac{a}{b}+\frac{b}{a}+1$ $2\sqrt{\frac{a}{b}\cdot\frac{b}{a}}+1=3$ ，当且仅当 $\frac{a}{b}=\frac{b}{a}$ 即 a=b= $\frac{1}{2}$ 时取等号，C 正确；
> >
> > 对 D，因为 a > 0，b > 0， $a + b = 1$ ，所以 0 < b < 1，a = 1 - b，
> >
> > 所以 $a^{2}+2b^{2}=(1-b)^{2}+2b^{2}=3b^{2}-2b+1=3\left(b-\frac{1}{3}\right)^{2}+\frac{2}{3}$ ，当 $b=\frac{1}{3}$ ， $a^{2}+2b^{2}$ 取得最小值为 $\frac{2}{3}$ ，D 正确。
> >
> > 故选 **ACD**.
