> [!faq]- 《专题03 利用基本不等式巧解最值（八大题型）（高效培优期末专项训练）》官方解析
>
> > [!success]- **【答案】** ACD
>
> > [!note]- **【分析】**
> > 利用基本不等式可判断 A 选项；求得 $0 < ab \leq \frac{1}{4}$ ，设 u = ab，则 $0 < u \leq \frac{1}{4}$ ，利用对勾函数单调性求出 $y = u + \frac{1}{u}$ 的最小值，可判断 B 选项；利用重要不等式可判断 C 选项；由 $\frac{1}{a + 2b} + \frac{1}{2a + b} = \frac{1}{3} \left[ (a + 2b) + (2a + b) \right] \left( \frac{1}{a + 2b} + \frac{1}{2a + b} \right)$ 结合基本不等式可判断 D 选项·
>
> > [!note]- **【解析】**
> > 因为 a > 0, b > 0, $a + b = 1$ ，
> >
> > 对于 A 选项，由基本不等式可得 $a + b = 1 \quad 2\sqrt{ab}$ ，可得 $ab \leq \frac{1}{4}$ ，
> >
> > 当且仅当 $\begin{cases} a + b = 1 \\ a = b \end{cases}$ 时，即当 $a = b = \frac{1}{2}$ 时，等号成立，故 ab 的最大值为 $\frac{1}{4}$ ，A 对；
> >
> > 对于 B 选项，设 u = ab，则 $0 < u \leq \frac{1}{4}$ ，
> >
> > 因为对勾函数 $y = u + \frac{1}{u}$ 在 $\left(0, \frac{1}{4}\right]$ 上单调递减，故当 $u = \frac{1}{4}$ 时，y 取最小值，即 $y_{\min} = \frac{1}{4} + 4 = \frac{17}{4}$ ，
> >
> > 故 $\frac{1}{ab} + ab$ 的最小值为 $\frac{17}{4}$ ，B 错；
> >
> > 对于 C 选项， $a^{2} + b^{2} = \frac{1}{2} \left( a^{2} + b^{2} + a^{2} + b^{2} \right) - \frac{1}{2} \left( a^{2} + b^{2} + 2ab \right) = \frac{\left( a + b \right)^{2}}{2} = \frac{1}{2}$ ，
> >
> > 当且仅当 $\left\{ \begin{array}{l} a + b = 1 \\ a = b \end{array} \right.$ 时，即当 $a = b = \frac{1}{2}$ 时，等号成立，故 $a^2 + b^2$ 的最小值为 $\frac{1}{2}$ ， $^\mathrm{C}$ 对；对于 $\mathbb{D}$ 选项， $\frac{1}{a + 2b} + \frac{1}{2a + b} = \frac{1}{3}(3a + 3b)\left(\frac{1}{a + 2b} + \frac{1}{2a + b}\right) = \frac{1}{3}\left[(a + 2b) + (2a + b)\right]\left(\frac{1}{a + 2b} + \frac{1}{2a + b}\right)$ $= \frac{1}{3}\left(2 + \frac{2a + b}{a + 2b} + \frac{a + 2b}{2a + b}\right)$ $\frac{1}{3}\left(2 + 2\sqrt{\frac{2a + b}{a + 2b} \cdot \frac{a + 2b}{2a + b}}\right) = \frac{4}{3}$ ，当且仅当 $\left\{ \begin{array}{l} \frac{2a + b}{a + 2b} = \frac{a + 2b}{2a + b} \\ a + b = 1 \\ a > 0, b > 0 \end{array} \right.$ 时，即当时，等号成立，故 $\frac{1}{a + 2b} + \frac{1}{2a + b}$ 的最小值为 $\frac{4}{3}$ ， $^{\mathrm{D}}$ 对。
> >
> > 故选 **ACD**.
