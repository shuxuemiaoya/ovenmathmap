> [!faq]- 《专题03 利用基本不等式巧解最值（八大题型）（高效培优期末专项训练）》官方解析
>
> > [!success]- **【答案】** $[-2,+\infty)$
>
> > [!note]- **【分析】**
> > 方法一：将题设条件化成关于 $2x + y$ 和 $xy$ 的方程，利用基本不等式将 $xy$ 放大得到关于 $2x + y$ 的一元二次不等式，求解即得；方法二：先将所求式 $2x + y$ 整理成 $2(x + 1) + (y + 2) - 4$ ，利用“乘 $1$ ”法和基本不等式即可求得 $2x + y$ 的取值范围.
>
> > [!note]- **【解析】**
> > 方法一：由 $\frac{1}{x + 1} +\frac{2}{y + 2} = 4$ 去分母，可得 $2(x + 1) + y + 2 = 4(x + 1)(y + 2)$ ，整理得 $4xy + 3(2x + y) + 4 = 0$ （\*），
> >
> > 因 $x > -1, y > -2$ ， $(2x + y)^2 = 4x^2 + y^2 + 4xy$ ， $8xy$ ，即 $xy \leq \frac{(2x + y)^2}{8}$ ，当且仅当 $2x = y$ 时等号成立，由（ $^{*}$ ）可得 $-3(2x+y)-4=4xy\leq\frac{(2x+y)^{2}}{2}$ ，即 $(2x+y)^{2}+6(2x+y)+8$ 0，解得 $2x+y-2$ 或 $2x+y\leq-4$ （不合题意舍去），
> >
> > 故 $2x + y$ 的取值范围为 $[-2, +\infty)$ ;
> >
> > 方法二：因为 $x > -1, y > -2$ ，所以 $2x + y = 2(x + 1) + (y + 2) - 4$
> >
> > $$
> > 2 (x + 1) + (y + 2) = \frac {1}{4} [ 2 (x + 1) + (y + 2) ] \left(\frac {1}{x + 1} + \frac {2}{y + 2}\right) = \frac {1}{4} \left[ 4 + \frac {4 (x + 1)}{y + 2} + \frac {y + 2}{x + 1} \right] \quad \frac {1}{4} (4 + 2 \sqrt {4}) = 2
> > $$
> >
> > 当且仅当 $\frac{4(x + 1)}{y + 2} = \frac{y + 2}{x + 1}$ 时等号成立，由 $\left\{ \begin{array}{l} \frac{4(x + 1)}{y + 2} = \frac{y + 2}{x + 1} \\ \frac{1}{x + 1} + \frac{2}{y + 2} = 4 \end{array} \right.$ ，解得 $\left\{ \begin{array}{l} x = -\frac{1}{2} \\ y = -1 \end{array} \right.$ ，
> >
> > 当 $x = -\frac{1}{2}, y = -1$ 时， $2(x + 1) + (y + 2)$ 取得最小值为 2
> >
> > $$
> > 2 x + y = 2 (x + 1) + (y + 2) - 4
> > $$
> >
> > $$
> > 2 x + y
> > $$
> >
> > $$
> > [ - 2, + \infty)
> > $$
> >
> > 故答案为： $[-2,+\infty)$ .
