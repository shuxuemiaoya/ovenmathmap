> [!faq]- 《专题03 利用基本不等式巧解最值（八大题型）（高效培优期末专项训练）》官方解析
>
> > [!success]- **【答案】** A．对任意实数 $a, b$ ，都有 $a + b = 2ab$ B．若 $a > 0$ ，则 $a + \frac{1}{a} \geq 2$ C．当 $a, b > 0$ 且 $a + b = 1$ 时， $ab$ 的最大值为 $\frac{1}{2}$ D．若 $a, b$ 为任意实数，则 $(a + b)^2 - 4ab$
>
> > [!note]- **【分析】**
> > 选项 A，当 a < 0, b < 0 时，即可判断 A 错误；选项 B，根据基本不等式即可判断 B 正确；选项 C
> >
> > 根据基本不等式即可判断 C 错误；选项 D，移项化简得 $\left(a+b\right)^{2}-4ab=\left(a-b\right)^{2}\quad0$ ，可判断 D 正确。
>
> > [!note]- **【解析】**
> > 对于选项 $^{A}$ ，当a<0，b<0时，则 $a+b<0$ ，2ab>0，所以 $a+b<2ab$ ，故 $^{A}$ 错误；
> >
> > 对于选项B，当 $a > 0$ 时， $\frac{1}{a} >0$ ，根据基本不等式，可得 $a + \frac{1}{a}$ $2\sqrt{a\cdot\frac{1}{a}} = 2$
> >
> > 当且仅当 $a = \frac{1}{a}$ ，即 $a = 1$ 时，等号成立，故 $\mathbf{B}$ 正确；
> >
> > 对于选项 $^{C}$ ，因为 a, b > 0 且 $a + b = 1$ ，则 $a + b = 2\sqrt{ab}$ ，即 $1 = 2\sqrt{ab}$ ，解得 $\frac{1}{4} = ab$ 当且仅当 $a = b$ ，即 $a = b = \frac{1}{2}$ 时，等号成立，即 $ab$ 的最大值为 $\frac{1}{4}$ ，故C错误；
> > 对于选项D，因为 $(a + b)^2 - 4ab = a^2 + b^2 - 2ab = (a - b)^2 - 0$ ，所以 $(a + b)^2 - 4ab$ ，故D正确·故选：BD
> >
