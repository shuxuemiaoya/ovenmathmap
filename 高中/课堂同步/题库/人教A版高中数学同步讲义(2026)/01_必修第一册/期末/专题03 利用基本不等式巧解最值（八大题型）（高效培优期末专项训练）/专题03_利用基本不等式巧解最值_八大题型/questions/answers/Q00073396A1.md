> [!faq]- 《专题03 利用基本不等式巧解最值（八大题型）（高效培优期末专项训练）》官方解析
>
> > [!success]- **【答案】** A. 当 x < 0 时，函数 $y = x + \frac{1}{x}$ 的最小值为 2 B. 若 x, y 均为正数，且 $x + y = 1$ ，则 $\frac{1}{x} + \frac{1}{y}$ 的最小值为 4 C. 若 x, y 均为正数，且 $x + 9y = 6xy$ ，则 xy 的最小值为 1 D. 若 x, y 均为正数，且 $x + y = 2$ ，则 $x^{2} + y^{2}$ 的最小值为 2
>
> > [!note]- **【分析】**
> > 应用基本不等式求 A、C、D 中目标式的最值，由“1”的代换及基本不等式求 C 中目标式的最值，注意取值条件即可·
>
> > [!note]- **【解析】**
> > 对于 A，当 x < 0 时，则 $y = x + \frac{1}{x} \leq -2\sqrt{x \cdot \frac{1}{x}} = -2$ ，
> >
> > 当且仅当 $x = \frac{1}{x} (x < 0)$ ，即 $x = -1$ 时等号成立，
> >
> > 故当 $x < 0$ 时，函数 $\mathrm{y} = \mathrm{x} + \frac{1}{\mathrm{x}}$ 的最大值为-2，错误
> >
> > 对于 B，因为 x, y 均为正数，且 $x + y = 1$ ，
> >
> > 所以 $\frac{1}{x} +\frac{1}{y} = (x + y)\left(\frac{1}{x} +\frac{1}{y}\right) = 2 + \left(\frac{x}{y} +\frac{y}{x}\right)\quad 2 + 2\sqrt{\frac{x}{y}\cdot\frac{y}{x}} = 4$
> >
> > 当且仅当 $\left\{\begin{aligned}\frac{x}{y}&=\frac{y}{x}\\ x+y&=1\end{aligned}\right.$ ，即 $x=y=\frac{1}{2}$ 时等号成立，则 $\frac{1}{x}+\frac{1}{y}$ 的最小值为 4，正确.
> >
> > 对于 C，若 x, y 均为正数，且 $x + 9y = 6xy$
> >
> > 由基本不等式得 $6xy = x + 9y$ $2\sqrt{x \cdot 9y} = 6\sqrt{xy}$ ，得 $xy$ $\sqrt{xy}$ ，即 $\sqrt{xy}$ 1，得 $xy$ 1，
> >
> > 当且仅当 $\left\{ \begin{array}{l} x = 9y \\ x + 9y = 6xy \\ x > 0, y > 0 \end{array} \right.$ ，即 $\left\{ \begin{array}{l} x = 3 \\ y = \frac{1}{3} \text{时等号成立，则的最小值为 } 1 \\ xy \end{array} \right.$ ，正确·
> >
> > 对于 $\mathsf{D}$ ，若 $x,y$ 均为正数，且 $x + y = 2$ ，则 $4 = x^{2} + y^{2} + 2xy\leq 2(x^{2} + y^{2})$ ，得 $x^{2} + y^{2}$ 2
> >
> > 当且仅当 $\left\{\begin{array}{l}x=y\\x+y=2\\x>0,y>0\end{array}\right.$ ，即时，等号成立，故的最小值为 $^{2}$ ，正确.
> >
> > 故选：BCD
> >
