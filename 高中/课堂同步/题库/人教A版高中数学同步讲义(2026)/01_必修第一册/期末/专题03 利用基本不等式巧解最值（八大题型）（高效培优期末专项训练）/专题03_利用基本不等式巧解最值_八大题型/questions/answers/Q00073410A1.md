> [!faq]- 《专题03 利用基本不等式巧解最值（八大题型）（高效培优期末专项训练）》官方解析
>
> > [!success]- **【答案】** A. $ab \leq \frac{1}{2}$ B. $a > \frac{1}{4}$ C. $a + 2b = \frac{9}{4}$ D. $a + b = \frac{2\sqrt{2} + 3}{4}$
>
> > [!note]- **【分析】**
> > 根据已知条件有 $b = \frac{2a}{4a - 1}$ 且 $a > \frac{1}{4}$ 、 $\frac{1}{2}\left(\frac{1}{2a} +\frac{1}{b}\right) = 1$ ，再应用不等式的性质或基本不等式“1”的代换判断各项的正误.
>
> > [!note]- **【解析】**
> > 由 $a, b > 0$ ，则 $2a = (4a - 1)b > 0$ ，可得 $a > \frac{1}{4}$ ，B对，
> >
> > 所以 $b = \frac{2a}{4a - 1}$ ，则 $ab = \frac{2a^2}{4a - 1} = \frac{2}{\frac{4}{a} - \frac{1}{a^2}} = \frac{2}{-(\frac{1}{a} - 2)^2 + 4}$ ， $0 <   \frac{1}{a} <  4$
> >
> > 所以 $ab \frac{1}{2}$ ，当且仅当 $a = \frac{1}{2}, b = 1$ 时取等号，A 错，
> >
> > 由 $2a + b = 4ab$ ，则 $\frac{1}{2}\left(\frac{1}{2a} +\frac{1}{b}\right) = 1$
> >
> > 所以 $a + 2b = \frac{1}{2}(a + 2b)(\frac{1}{2a} + \frac{1}{b}) = \frac{1}{2}(\frac{5}{2} + \frac{b}{a} + \frac{a}{b})$ $\frac{1}{2}(\frac{5}{2} + 2\sqrt{\frac{b}{a} \cdot \frac{a}{b}}) = \frac{9}{4}$
> >
> > 当且仅当 $\frac{b}{a}=\frac{a}{b}$ ，即 $a=b=\frac{3}{4}$ 时取等号，即 $a+2b=\frac{9}{4}$ ，C对，
> >
> > $$
> > a + b = \frac {1}{2} (a + b) \left(\frac {1}{2 a} + \frac {1}{b}\right) = \frac {1}{2} \left(\frac {3}{2} + \frac {b}{2 a} + \frac {a}{b}\right) \quad \frac {1}{2} \left(\frac {3}{2} + 2 \sqrt {\frac {b}{2 a} \cdot \frac {a}{b}}\right) = \frac {2 \sqrt {2} + 3}{4}
> > $$
> >
> > 当且仅当 $\frac{b}{2a} = \frac{a}{b}$ ，即 $a = \frac{\sqrt{2} + 1}{4}, b = \frac{2 + \sqrt{2}}{4}$ 时取等号，即 $a + b = \frac{2\sqrt{2} + 3}{4}$ ，D对
> >
> > 故选 **BCD**
