> [!faq]- 《高一数学上学期期末模拟卷_人教A版2019_高效培优_强化卷_》官方解析
>
> > [!success]- **【答案】** (1) $M(x)=\left\{\begin{aligned}-x^{2}+80x-400, &0 \leq x < 50 \\ -\frac{3}{2}x - \frac{5400}{x} + 1283, &50 \leq x \leq 100\end{aligned}\right.$ ， $x \in N$ (2)年产量 40 百台，最大利润为 1200 万元
>
> > [!note]- **【解析】**
> > （1）每百台高级设备售价为90万元，年产量x（百辆）时销售收入为90x万元，
> >
> > 总成本为 $400 + y = \begin{cases} x^{2} + 10x + 400, & 0 \leq x < 50 \\ \frac{183}{2}x + \frac{5400}{x} - 1283, & 50 \leq x \leq 100 \end{cases}$
> >
> > 所以 $M(x)=\left\{\begin{aligned}&90x-\left(x^{2}+10x+400\right),0\leq x<50\\ &90x-\left(\frac{183}{2}x+\frac{5400}{x}-1283\right),50\leq x\leq100\end{aligned}\right.$
> >
> > $$
> > = \left\{ \begin{array}{l} - x ^ {2} + 8 0 x - 4 0 0, 0 \leq x <   5 0 \\ - \frac {3}{2} x - \frac {5 4 0 0}{x} + 1 2 8 3, 5 0 \leq x \leq 1 0 0, x \in \mathbf {N}. \end{array} \right.
> > $$
> >
> > 所以年利润 $M(x)=\left\{\begin{aligned}-x^{2}+80x-400, &0 \leq x < 50 \\ -\frac{3}{2}x - \frac{5400}{x} + 1283, &50 \leq x \leq 100\end{aligned}\right.$ ， $x \in N$ .
> >
> > (2) 由 (1) 当 $0 \leq x < 50$ 时， $M(x) = -x^2 + 80x - 400 = -(x - 40)^2 + 1200$
> >
> > 故当 $x = 40 \in [0, 50)$ （百台）时， $M(x)_{\max} = 1200$ （万元），
> >
> > 当 $50 \leq x \leq 100$ 时， $M(x) = -\left(\frac{3}{2} x + \frac{5400}{x}\right) + 1283 \leq -2\sqrt{\frac{3}{2} x \cdot \frac{5400}{x}} + 1283 = 1103$
> >
> > 当且仅当 $\frac{3}{2} x = \frac{5400}{x}$ 即 $x = 60$ （百台）时，等号成立，此时 $M(x)_{\max} = 1103$ （万元），
> >
> > 因为 1200 万元 > 1103 万元，
> >
> > 所以年产量 40 百台时利润最大，最大利润为 1200 万元.
