> [!faq]- 《高一数学上学期期末模拟卷_人教A版2019_高效培优_强化卷_》官方解析
>
> > [!success]- **【答案】** ACD
>
> > [!note]- **【解析】**
> > 因为对任意 $x, y \in \mathbf{R}$ ，满足 $f(x) + f(y) = f(x + y) + 2$
> >
> > 对于选项 A：令 x = y = 0 ，可得 $f(0) + f(0) = f(0) + 2$ ，即 $f(0) = 2$ ，故 A 正确；
> >
> > 对于选项 B：因为 $f(0)+f(2)=6$ ，且 $f(0)=2$ ，
> >
> > 可得 $f(2)=4$ ，即 $f(0)<f(2)$ ，
> >
> > 又因为函数 $f(x)$ 在 $\mathbf{R}$ 上单调，所以函数 $f(x)$ 在 $\mathbf{R}$ 上单调递增，故B错误；
> >
> > 对于选项C：设 $g(x) = f(x) - 2$
> >
> > 令 $y = -x$ ，可得 $f(x) + f(-x) = f(0) + 2 = 4$
> >
> > 即 $f(x) - 2 = -\left[f(-x) - 2\right]$ ，可得 $g(x) = -g(-x)$
> >
> > 所以函数 $g(x)=f(x)-2$ 是奇函数，故 C 正确；
> >
> > 对于选项D：因为 $f\left(x^{2} + kx\right) + f(x + 1) < 4$ ，即 $f\left(x^{2} + kx\right) - 2 < -\left[f(x + 1) - 2\right]$
> >
> > 可得 $g\left(x^{2} + kx\right) < -g(x + 1) = g(-x - 1)$
> >
> > 又因为函数 $f(x)$ 在 R 上单调递增，则函数 $g(x)$ 在 R 上单调递增，
> >
> > 可得 $x^{2} + kx < -x - 1$ ，且 $x\in (1,2)$ ，整理可得 $k < -\left(x + \frac{1}{x}\right) - 1$
> >
> > 因为 $y = x + \frac{1}{x}$ 在 $(1,2)$ 内单调递增，则 $h(x) = -\left(x + \frac{1}{x}\right) - 1$ 在 $(1,2)$ 内单调递减，
> >
> > 可得 $h(x) > h(2) = -\frac{7}{2}$ ，则 $k \leq -\frac{7}{2}$ ，
> >
> > 所以实数 $k$ 的取值范围是 $\left(-\infty, -\frac{7}{2}\right]$ ，故D正确；
> >
> > 故选 **ACD**.
