> [!faq]- 《高一数学上学期期末模拟卷_人教A版2019_高效培优_提升卷_》官方解析
>
> > [!success]- **【答案】** (1) $A \cap B = \{x < 1 < x < 4\}$ ， $A \cup B = \{x - 3 < x < 5\}$ . (2) $\left(-\infty,\frac{1}{2}\right]$
>
> > [!note]- **【解析】**
> > （1）若 $a = 1$ ，则 $B = \{x1 < x < 5\}$
> >
> > 所以 $A \cap B = \{x < 1 < x < 4\}$ ， $A \cup B = \{x - 3 < x < 5\}$ .
> >
> > (2) 因为 $A \cup B = A$ ，所以 $B \subseteq A$ ，
> >
> > 当 $B = \emptyset$ 时，满足 $B \subseteq A$ ，此时 $3 + 2a \leq 2 - a \Rightarrow a \leq -\frac{1}{3}$
> >
> > 当时，要使，则 $\left\{ \begin{array}{ll}a > -\frac{1}{3}\\ 2 - a & -3\\ 3 + 2a\leq 4 & -\frac{1}{3} < a\leq \frac{1}{2}. \end{array} \right.$
> >
> > 综上，实数 $a$ 的取值范围为 $\left(-\infty, \frac{1}{2}\right]$
