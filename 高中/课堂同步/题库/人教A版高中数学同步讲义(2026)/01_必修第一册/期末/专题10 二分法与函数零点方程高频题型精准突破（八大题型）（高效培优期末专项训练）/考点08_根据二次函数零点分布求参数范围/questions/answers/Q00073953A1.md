> [!faq]- 《专题10 二分法与函数零点方程高频题型精准突破（八大题型）（高效培优期末专项训练）》官方解析
>
> > [!success]- **【答案】** $(12]\cup\left\{\frac{5}{2},3\right\}$
>
> > [!note]- **【分析】**
> > 首先求出 $f(x)$ 进而得到 $f\left(\frac{x}{2}\right)$ ，原方程转化为 $(a - 3)x^2 + (2a - 7)x - 2 = 0$ ，分 $a = 3$ 和 $a \neq 3$ ，当 $a \neq 3$ 时，需要分 $\frac{1}{a - 3} = -2$ 和 $\frac{1}{a - 3} \neq -2$ 进行讨论·
>
> > [!note]- **【解析】**
> > 由题意可得 $f(x) = \log_2\frac{ax + 1}{x}$ ，所以 $f\left(\frac{x}{2}\right) = \log_2\frac{ax + 2}{x}$ ，所以原方程即
> >
> > $\log_2\frac{ax + 2}{x} = \log_2[(a - 3)x + 3a - 7] \Rightarrow \frac{ax + 2}{x} = (a - 3)x + 3a - 7 \Rightarrow (a - 3)x^2 + (2a - 7)x - 2 = 0$ ，且满足 $\frac{ax + 2}{x} > 0$
> >
> > 当 $a = 3$ 时， $x = -2$ ，此时 $\frac{3 \times (-2) + 2}{-2} = 2 > 0$ 符合题意；
> >
> > 当 $a \neq 3$ 时， $\Rightarrow (x + 2) \cdot [(a - 3)x - 1] = 0 \Rightarrow x = -2$ 或 $x = \frac{1}{a - 3}$ ，
> >
> > 若 $\frac{1}{a - 3} = -2 \Rightarrow a = \frac{5}{2}$ ，此时 $\frac{\frac{5}{2} \times (-2) + 2}{-2} = \frac{3}{2} > 0$ 符合题意；
> >
> > 若 $\frac{1}{a - 3} \neq -2$ ，则 $\left\{ \begin{array}{l} \frac{a \times (-2) + 2}{-2} > 0 \\ \frac{a \times \frac{1}{a - 3} + 2}{\frac{1}{a - 3}} \leq 0 \end{array} \right.$ 或 $\left\{ \begin{array}{l} \frac{a \times (-2) + 2}{-2} \leq 0 \\ \frac{a \times \frac{1}{a - 3} + 2}{\frac{1}{a - 3}} > 0 \end{array} \right. \Rightarrow 1 < a \leq 2$
> >
> > 综上所述： $a\in (1,2]\cup \left\{\frac{5}{2},3\right\}$
> >
> > 故答案为： $(1,2]\cup\left\{\frac{5}{2},3\right\}$
