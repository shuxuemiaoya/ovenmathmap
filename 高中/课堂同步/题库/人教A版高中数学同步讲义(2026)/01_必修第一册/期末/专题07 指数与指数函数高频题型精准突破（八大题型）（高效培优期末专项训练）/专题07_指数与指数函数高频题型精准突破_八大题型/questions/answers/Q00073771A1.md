> [!faq]- 《专题07 指数与指数函数高频题型精准突破（八大题型）（高效培优期末专项训练）》官方解析
>
> > [!success]- **【答案】** AD
>
> > [!note]- **【分析】**
> > 由已知结合不等式及函数单调性可得 $0 < x < y$ ，检验各选项即可判断.
>
> > [!note]- **【解析】**
> > 因为正实数 $x, y$ 满足 $x^{2} - y^{2} < \frac{1}{x^{2}} - \frac{1}{y^{2}}$ ，即 $x^{2} - \frac{1}{x^{2}} < y^{2} - \frac{1}{y^{2}}$
> >
> > 因为 $y = x^2$ 在 $(0, +\infty)$ 上单调递增， $y = -\frac{1}{x^2}$ 在 $(0, +\infty)$ 上单调递增，
> >
> > 所以函数 $y = x^{2} - \frac{1}{x^{2}}$ 在 $(0, +\infty)$ 上单调递增，则 $0 < x < y$ ，
> >
> > 对于 $\mathsf{A}$ ，因为 $0 < x < y$ ，所以 $\sqrt{x} < \sqrt{y}$ ，故 $\mathsf{A}$ 正确；
> >
> > 对于 $\mathsf{B}$ ，因为 $0 < x < y$ ，所以 $\left(\frac{1}{2}\right)^x >\left(\frac{1}{2}\right)^y$ ，故 $\mathsf{B}$ 错误；
> >
> > 对于 $C$ ，因为 $0 < x < y$ ，所以 $\frac{1}{x} -\frac{1}{y} = \frac{y - x}{xy} >0$ ，即 $\frac{1}{x} >\frac{1}{y}$ ，故 $C$ 错误；
> >
> > 对于 D，因为 0 < x < y，所以 $x^{3} < y^{3}$ ，故 D 正确。
> >
> > 故选 **AD**.
