> [!faq]- 《专题07 指数与指数函数高频题型精准突破（八大题型）（高效培优期末专项训练）》官方解析
>
> > [!success]- **【答案】** ACD
>
> > [!note]- **【分析】**
> > 化去绝对值再利用指数函数的单调性解不等式可判断 $^{A}$ ；判断函数 $f(x)$ 的奇偶性可判断 $^{B}$ ；根据复合函数单调性判断 $^{C}$ ；通过求含指数函数的复合函数的值域判断 $^{D}$ .
>
> > [!note]- **【解析】**
> > $f(x)=\frac{2^{x}-1}{2^{x}+1}=1-\frac{2}{2^{x}+1}$
> >
> > 对于 A，由 $\left|f(x)\right|<\frac{1}{3}$ 得 $-\frac{1}{3}<1-\frac{2}{2^{x}+1}<\frac{1}{3}$ ，即 $\frac{1}{2}<2^{x}<2$ ，解得 $-1<x<1$ 故 A 正确；
> >
> > 对于 B，因为 $f(-x)=\frac{2^{-x}-1}{2^{-x}+1}=\frac{1-2^{x}}{1+2^{x}}=-f(x)$ ，所以函数 $f(x)$ 是奇函数，其图像关于原点对称，不关于 y 轴对称，故 B 不正确；
> >
> > 对于 C，因为函数 $y = 2^{x} + 1$ 是增函数，因为 $y = 2^{x} + 1 > 1$ ，所以函数 $y = \frac{2}{2^{x} + 1}$ 是减函数，
> >
> > 因此函数 $f(x) = 1 - \frac{2}{2^x + 1}$ 是增函数，故 $^C$ 正确；
> >
> > 对于 D，由 $2^{x} > 0 \Rightarrow 2^{x} + 1 > 1 \Rightarrow 0 < \frac{1}{2^{x} + 1} < 1 \Rightarrow -2 < -\frac{2}{2^{x} + 1} < 0 \Rightarrow -1 < 1 - \frac{2}{2^{x} + 1} < 1$ ，所以函数 $f(x)$ 的值域为 $(-1,1)$ ，故 D 正确.
> >
> > 故选 **ACD**.
