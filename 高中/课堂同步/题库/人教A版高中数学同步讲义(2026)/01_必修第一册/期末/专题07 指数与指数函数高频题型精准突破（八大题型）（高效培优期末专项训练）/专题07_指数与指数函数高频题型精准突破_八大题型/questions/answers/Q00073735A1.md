> [!faq]- 《专题07 指数与指数函数高频题型精准突破（八大题型）（高效培优期末专项训练）》官方解析
>
> > [!success]- **【答案】** $\left[\sqrt[3]{3},\sqrt[4]{5}\right)$
>
> > [!note]- **【分析】**
> > 根据给定定义，利用根式的性质求解即得·
>
> > [!note]- **【解析】**
> > 由 $[t] = 1$ ，得 $1 \leq t < 2$ ；由 $[t^2] = 2$ ，得 $2 \leq t^2 < 3$ ，则 $\sqrt{2} \leq t < \sqrt{3}$ ；
> >
> > 由 $[t^3] = 3$ ，得 $3\leq t^3 < 4$ ，则 $\sqrt[3]{3}\leq t < \sqrt[3]{4}$ ；由 $[t^4 ] = 4$ ，得 $4\leq t^4 < 5$ ，则 $\sqrt{2}\leq t < \sqrt[4]{5}$
> >
> > 而 $1 < \sqrt{2} = \sqrt[6]{8} < \sqrt[6]{9} = \sqrt[3]{3}$ ， $\sqrt[4]{5} = \sqrt[12]{125} < \sqrt[12]{256} = \sqrt[3]{4} = \sqrt[6]{16} < \sqrt[6]{27} = \sqrt{3} < 2$
> >
> > 所以 t 的取值范围是 $\left[\sqrt[3]{3},\sqrt[4]{5}\right)$ .
> >
> > 故答案为： $\left[\sqrt[3]{3},\sqrt[4]{5}\right)$
