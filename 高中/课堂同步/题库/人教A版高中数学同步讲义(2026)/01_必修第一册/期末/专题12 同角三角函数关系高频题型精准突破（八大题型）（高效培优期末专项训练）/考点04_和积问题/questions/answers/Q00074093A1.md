> [!faq]- 《专题12 同角三角函数关系高频题型精准突破（八大题型）（高效培优期末专项训练）》官方解析
>
> > [!success]- **【答案】** $-\frac{1}{5} / -0.2$
>
> > [!note]- **【分析】**
> > 首先利用平方关系求 $2\sin x\cos x$ 的值，再利用平方关系求 $\sin x-\cos x$ 的值.
>
> > [!note]- **【解析】**
> > $\left(\sin x + \cos x\right)^2 = 1 + 2\sin x\cos x = \frac{49}{25}$ ，得 $2\sin x\cos x = \frac{24}{25}$
> >
> > 则 $\left(\sin x - \cos x\right)^2 = 1 - 2\sin x\cos x = \frac{1}{25}$
> >
> > 且 $0 < x < \frac{\pi}{4}$ ，则 $\sin x - \cos x < 0$ ，所以 $\sin x - \cos x = -\frac{1}{5}$ .
> >
> > 故答案为： $-\frac{1}{5}$
