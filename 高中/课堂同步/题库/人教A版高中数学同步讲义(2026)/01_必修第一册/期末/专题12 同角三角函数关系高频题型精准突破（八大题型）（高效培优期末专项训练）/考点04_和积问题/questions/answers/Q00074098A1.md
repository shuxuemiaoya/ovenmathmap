> [!faq]- 《专题12 同角三角函数关系高频题型精准突破（八大题型）（高效培优期末专项训练）》官方解析
>
> > [!success]- **【答案】** D
>
> > [!note]- **【分析】**
> > 利用 $\sin\theta\pm\cos\theta$ 与 $\sin\theta\cos\theta$ 之间的关系式，再由平方关系计算可得 A 错误，B 错误，联立方程组并由商数关系可得 C 错误，代入计算可得 D 正确.
>
> > [!note]- **【解析】**
> > 由 $\sin\theta + \cos\theta = \frac{1}{5}$ 可得 $\left(\sin\theta + \cos\theta\right)^{2} = \frac{1}{25}$ ，即 $\sin^{2}\theta + 2\sin\theta\cos\theta + \cos^{2}\theta = \frac{1}{25}$ ;
> >
> > 所以 $2\sin \theta \cos \theta = -\frac{24}{25}$ ，即 $\sin \theta \cos \theta = -\frac{12}{25}$ ，即A错误；
> >
> > 又 $\theta \in (0, \pi)$ ，所以 $\sin \theta > 0, \cos \theta < 0$ ，因此 $\sin \theta - \cos \theta > 0$
> >
> > 所以 $\sin \theta -\cos \theta = \sqrt{(\sin\theta - \cos\theta)^2} = \sqrt{\sin^2\theta - 2\sin\theta\cos\theta + \cos^2\theta} = \sqrt{\frac{49}{25}} = \frac{7}{5}$ ，即B错误；
> >
> > 联立 $\left\{ \begin{array}{ll}\sin \theta +\cos \theta = \frac{1}{5}\\ \sin \theta -\cos \theta = \frac{7}{5} \end{array} \right.$ ，可得 $\sin \theta = \frac{4}{5},\cos \theta = -\frac{3}{5}$
> >
> > 所以 $\tan\theta=\frac{\sin\theta}{\cos\theta}=\frac{\frac{4}{5}}{-\frac{3}{5}}=-\frac{4}{3}$ ，即 C 错误；
> >
> > 代入计算可得 $\sin\theta\cos\theta-\cos^{2}\theta=\frac{4}{5}\times\left(-\frac{3}{5}\right)-\left(-\frac{3}{5}\right)^{2}=-\frac{12}{25}-\frac{9}{25}=-\frac{21}{25}$ ，即 D 正确.
> >
> > 故选 **D**
