> [!faq]- 《专题12 同角三角函数关系高频题型精准突破（八大题型）（高效培优期末专项训练）》官方解析
>
> > [!success]- **【答案】** (1) $\frac{\sqrt{3}}{3}$ (2)2
>
> > [!note]- **【分析】**
> > （1）解法 $^{1}$ 由平方关系得到 $\sin\alpha-\cos\alpha=\frac{\sqrt{6}}{2}$ ，从而解出即可；解法 $^{2}$ 由同角的三角函数关系解出 $\sin\alpha,\cos\alpha$ ，从而求出结果；
> >
> > (2) 解法 $^{1}$ 由同角的三角函数关系和商数关系计算即可；解法 $^{2}$ 由已知得到 $\sin\alpha=-2\cos\alpha$ ，再由同角的三角函数关系化简得到；
>
> > [!note]- **【解析】**
> > （1）解法 $^{1}$ ： $f(\alpha)=\frac{\sin\alpha+\cos\alpha}{\sin\alpha-\cos\alpha}$ ，
> >
> > 因为 $\sin\alpha+\cos\alpha=\frac{\sqrt{2}}{2}$ ，
> >
> > 所以 $\left(\sin \alpha +\cos \alpha\right)^2 = \frac{1}{2}$ ，即 $2\sin \alpha \cos \alpha = -\frac{1}{2}$
> >
> > 从而 $\left(\sin\alpha-\cos\alpha\right)^{2}=1-2\sin\alpha\cos\alpha=\frac{3}{2}$ ，
> >
> > 因为 $0 < \alpha < \pi$ ， $\sin \alpha > 0$
> >
> > 又因为 $\sin\alpha\cos\alpha<0$ ，所以 $\cos\alpha<0$ ，因此 $\sin\alpha-\cos\alpha>0$
> >
> > 从而 $\sin \alpha -\cos \alpha = \frac{\sqrt{6}}{2}$
> >
> > 故 $f(\alpha) = \frac{\sin\alpha + \cos\alpha}{\sin\alpha - \cos\alpha} = \frac{\sqrt{3}}{3}$
> >
> > 解法 $^{2}$ ：由 $\sin\alpha+\cos\alpha=\frac{\sqrt{2}}{2}$ 及 $\sin^{2}\alpha+\cos^{2}\alpha=1$
> >
> > 解得 $\sin \alpha = \frac{\sqrt{6} + \sqrt{2}}{4}$ ， $\cos \alpha = \frac{\sqrt{2} - \sqrt{6}}{4}$
> >
> > 或 $\sin \alpha = \frac{\sqrt{2} - \sqrt{6}}{4}$ ， $\cos \alpha = \frac{\sqrt{6} + \sqrt{2}}{4}$
> >
> > 因为 $0 < \alpha < \pi$ ，所以 $\sin \alpha = \frac{\sqrt{6} + \sqrt{2}}{4}$ ， $\cos \alpha = \frac{\sqrt{2} - \sqrt{6}}{4}$ ，
> >
> > 所以 $\sin \alpha -\cos \alpha = \frac{\sqrt{6}}{2}$ ，因此 $f(\alpha) = \frac{\sin\alpha + \cos\alpha}{\sin\alpha - \cos\alpha} = \frac{\sqrt{3}}{3}$
> >
> > (2)
> > 解法 1: $f(\alpha)=\frac{\sin\alpha+\cos\alpha}{\sin\alpha-\cos\alpha}=\frac{1}{3}$
> >
> > 所以 $2\sin \alpha = -4\cos \alpha$
> >
> > 假设 $\cos\alpha=0$ ，则由上式知 $\sin\alpha=0$ ，与 $\sin^{2}\alpha+\cos^{2}\alpha=1$ 矛盾，
> >
> > 所以 $\cos\alpha\neq0$
> >
> > 从而 $\tan \alpha = -2$
> >
> > $$
> > \sin^ {2} \alpha - 3 \sin \alpha \cos \alpha = \frac {\sin^ {2} \alpha - 3 \sin \alpha \cos \alpha}{\sin^ {2} \alpha + \cos^ {2} \alpha} = \frac {\tan^ {2} \alpha - 3 \tan \alpha}{\tan^ {2} \alpha + 1} = 2
> > $$
> >
> > 解法2： $f(\alpha) = \frac{\sin\alpha + \cos\alpha}{\sin\alpha - \cos\alpha} = \frac{1}{3}$ ，所以 $\sin \alpha = -2\cos \alpha$
> >
> > 又 $\sin^2\alpha +\cos^2\alpha = 1$ ，所以 $5\cos^2\alpha = 1$ ，即 $\cos^2\alpha = \frac{1}{5}$
> >
> > 因此 $\sin^2\alpha - 3\sin \alpha \cos \alpha = 4\cos^2\alpha + 6\cos^2\alpha = 10\cos^2\alpha = 2$
