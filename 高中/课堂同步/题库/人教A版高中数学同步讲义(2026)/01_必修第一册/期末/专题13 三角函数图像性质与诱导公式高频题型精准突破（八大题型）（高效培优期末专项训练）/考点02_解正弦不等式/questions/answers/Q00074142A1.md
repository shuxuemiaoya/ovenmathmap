> [!faq]- 《专题13 三角函数图像性质与诱导公式高频题型精准突破（八大题型）（高效培优期末专项训练）》官方解析
>
> > [!success]- **【答案】** A．若 $a, b \in \mathbb{R}$ ，则“ $2^a > 2^b$ ”是“ $\ln a > \ln b$ ”的必要不充分条件 B．设 $x, y \in R$ ，则“ $x + y > 4$ ”是“x 2 且 y 2”的充分不必要条件 C. “ $ac < 0$ ”是“一元二次方程 $ax^2 + bx + c = 0$ 有一正一负两个实数根”的充要条件 D. “ $0 < \theta < \frac{\pi}{3}$ ”是“ $0 < \sin \theta < \frac{\sqrt{3}}{2}$ ”的充分不必要条件
>
> > [!note]- **【分析】**
> > 利用充分条件，必要条件的定义逐项判断求解即可·
>
> > [!note]- **【解析】**
> > 对于 A， $2^{a}>2^{b}\Leftrightarrow a>b$ ， $\ln a>\ln b\Leftrightarrow a>b>0$ ，显然由 a>b 推不出 a>b>0，
> > 比如 a = -1 > b = -2 ，但是 a > b > 0 必推出 a > b ，
> >
> > “ $a > b$ ”是“ $a > b > 0$ ”的必要不充分条件，即“ $2^{a} > 2^{b}$ ”是“ $\ln a > \ln b$ ”的必要不充分条件，正确；对于B， $x,y\in \mathbf{R}$ ，若 $x + y > 4$ ，取 $x = 1,y = 4$ ，显然“ $x - 2$ 且 $y - 2$ ”不成立，
> >
> > 而 $x = 2$ 且 $y = 2$ ，必有 $x + y > 4$ ，则“ $x + y > 4$ ”是“ $x = 2$ 且 $y = 2$ ”的必要不充分条件，错误；对于 $C$ ，若 $ac < 0$ ，一元二次方程 $ax^2 + bx + c = 0$ 判别式 $\Delta = b^2 - 4ac > 0$ ，
> >
> > 方程有二根 $x_{1}, x_{2}$ ， $x_{1}x_{2} = \frac{c}{a} < 0$ ，即 $x_{1}, x_{2}$ 一正一负，
> >
> > 反之，一元二次方程 $ax^2 + bx + c = 0$ 有一正一负两个实根 $x_1, x_2$ ，则 $x_1x_2 = \frac{c}{a} < 0$ ，有 $ac < 0$ ，所以“ $ac < 0$ ”是“一元二次方程 $ax^2 + bx + c = 0$ 有一正一负两个实根”的充要条件，正确；对于 D， $0 < \theta < \frac{\pi}{3}$ 时，因为 $y = \sin x$ 在 $\left(0, \frac{\pi}{3}\right)$ 上单调递增，故 $0 < \sin \theta < \frac{\sqrt{3}}{2}$ ，充分性成立，当 $\frac{2\pi}{3} < \theta < \pi$ 时，也满足 $0 < \sin \theta < \frac{\sqrt{3}}{2}$ ，故必要性不成立，所以“ $0 < \theta < \frac{\pi}{3}$ ”是“ $0 < \sin \theta < \frac{\sqrt{3}}{2}$ ”的充分不必要条件，正确。
> >
> > 故选：ACD

> > 16. 函数 $f(x) = \ln (2\sin^2 x - 5\sin x + 2)$ 的定义域是（）
> >
> > 【答案】
> > A. $\left(2k\pi + \frac{\pi}{3}, 2k\pi + \frac{5\pi}{3}\right)(k \in \mathbb{Z})$ B. $\left(2k\pi + \frac{\pi}{6}, 2k\pi + \frac{5\pi}{6}\right)(k \in \mathbb{Z})$ C. $\left(2k\pi - \frac{7\pi}{6}, 2k\pi + \frac{\pi}{6}\right)(k \in \mathbb{Z})$ D. $\left(2k\pi - \frac{4\pi}{3}, 2k\pi + \frac{\pi}{3}\right)(k \in \mathbb{Z})$
> >
> > 【答案】C
> >
> > 【分析】根据对数的性质可将问题转化为 $2\sin^2 x - 5\sin x + 2 > 0$ ，利用三角函数的性质求解即可·
> > 【详解】 $f(x) = \ln (2\sin^2 x - 5\sin x + 2)$ 的定义域满足 $2\sin^2 x - 5\sin x + 2 > 0$ ，
> > 故 $(\sin x - 2)(2\sin x - 1) > 0$ ，由于 $\sin x \in [-1, 1]$ ，所以 $\sin x - 2 < 0$
> >
> > 故 $2\sin x - 1 < 0 \Rightarrow \sin x < \frac{1}{2}$ ，解得 $2k\pi - \frac{7\pi}{6} < x < 2k\pi + \frac{\pi}{6}, (k \in \mathbb{Z})$
> >
> > 故函数的定义域为 $\left(2k\pi -\frac{7\pi}{6},2k\pi +\frac{\pi}{6}\right)(k\in \mathbb{Z})$
> >
> > 故选 **C**
