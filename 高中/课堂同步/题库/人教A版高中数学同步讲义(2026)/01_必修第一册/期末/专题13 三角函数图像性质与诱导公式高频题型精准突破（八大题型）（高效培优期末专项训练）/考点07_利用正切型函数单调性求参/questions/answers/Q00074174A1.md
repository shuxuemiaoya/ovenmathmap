> [!faq]- 《专题13 三角函数图像性质与诱导公式高频题型精准突破（八大题型）（高效培优期末专项训练）》官方解析
>
> > [!success]- **【答案】** B
>
> > [!note]- **【分析】**
> > 根据复合函数的单调性，先确定 $f(x)$ 在 $(\ln 2, +\infty)$ 上单调递增，因 $\ln 2 < b < c < a$ ，故可得。
>
> > [!note]- **【解析】**
> > 设 $t = e^{x} - 1$ ，则 $t = e^{x} - 1$ 在 R 上单调递增，
> >
> > $f(x) = \frac{\mathrm{e}^{2x}}{\mathrm{e}^x - 1}$ 可化为 $y = \frac{(t + 1)^2}{t} = t + \frac{1}{t} + 2$
> >
> > 由对勾函数的性质可知：
> >
> > 当 $t \in (0,1)$ 时， $y = t + \frac{1}{t} + 2$ 单调递减，当 $t \in (1, +\infty)$ 时， $y = t + \frac{1}{t} + 2$ 单调递增，
> >
> > 由 $t = \mathrm{e}^{x} - 1 = 1$ 得 $x = \ln 2$
> >
> > 故 $f(x)$ 在区间 $(0, \ln 2)$ 上单调递减，在 $(\ln 2, +\infty)$ 上单调递增，
> >
> > 又 $b = -\tan 136^{\circ} = \tan 44^{\circ}$ ， $c = \tan 241^{\circ} = \tan 61^{\circ}$
> >
> > 因为 $y = \tan x$ 在 $\left(0, \frac{\pi}{2}\right)$ 上单调递增，故 $a > c > b$
> >
> > 因 $\tan 44^{\circ} = \tan \frac{44\pi}{180} >\frac{44\pi}{180} >\frac{44\times 3.1}{180} >\frac{3\times 45}{180} = \frac{3}{4}$ ，（因为 $\tan x > x,x\in \left(0,\frac{\pi}{2}\right)$ ），
> >
> > 又 $e^{3}>16$ ，则 $e^{\frac{3}{4}}>16^{\frac{1}{4}}=2$ ，即 $\frac{3}{4}>\ln2$ ，
> >
> > 故 $\ln 2 < b < c < a$ ，故 $f(b) < f(c) < f(a)$
> >
> > 故选 **B**.
