> [!faq]- 《专题13 三角函数图像性质与诱导公式高频题型精准突破（八大题型）（高效培优期末专项训练）》官方解析
>
> > [!success]- **【答案】** (1)关于原点对称，理由见解析； (2)① ; ② $\left\{ \begin{array}{l}a = \frac{\sqrt{2}}{2}\\ b = \frac{1}{2} \end{array} \right.$ 或 $\left\{b = -\frac{1}{2}\right.$
>
> > [!note]- **【分析】**
> > （ $^{1}$ ）利用函数的定义域和奇函数恒等式来证明，即可得到函数图象关于原点对称；
> >
> > (2) ①利用平移变换求得解析式 $y = g(x)$ ，再用代入法证明恒等式成立；
> >
> > ②利用恒等式成立来转化求解的不等式，最后利用函数的单调性来进行推理，结合基本不等式来求最大值，利用取等号关系可求得取最大值时的 $a$ 、 $b$ 的值·
>
> > [!note]- **【解析】**
> > （1）由 $\frac{1 + x}{1 - x} > 0 \Rightarrow -1 < x < 1$ 可知函数 $f(x) = \sin x + \ln \frac{1 + x}{1 - x}$ 的定义域为 $(-1, 1)$ ，
> >
> > 再由 $f(-x) + f(x) = \sin (-x) + \ln \frac{1 - x}{1 + x} +\sin x + \ln \frac{1 + x}{1 - x} = 0$
> >
> > 所以 $f(-x) = -f(x)$ ，故 $f(x) = \sin x + \ln \frac{1 + x}{1 - x}$ 是奇函数，它的图象关于原点对称
> >
> > (2) 由函数 $y = f(x)$ 的图象向右平移1个单位长度，再向上平移3个单位长度得到函数为：
> >
> > $y = g(x) = f(x - 1) + 3 = \sin (x - 1) + \ln \frac{x}{2 - x} + 3$ ，此时定义域为 $(0,2)$
> >
> > 再由 $g(x) + g(2 - x) = \sin (x - 1) + \ln \frac{x}{2 - x} +3 + \sin (1 - x) + \ln \frac{2 - x}{x} +3 = 6$
> >
> > 所以 $g(x)+g(2-x)=6$ ;
> >
> > 由于 $6 - g(x) = g(2 - x)$ ，所以不等式 $g(a^2) + g(2b^2 + 1) \leq 6$ 可变形为：
> >
> > $$
> > g (a ^ {2}) \leq 6 - g (2 b ^ {2} + 1) = g (2 - 2 b ^ {2} - 1) = g (1 - 2 b ^ {2})
> > $$
> >
> > 因为当 $x \in (0,2)$ 时， $x - 1 \in (-1,1) \subseteq \left[-\frac{\pi}{2}, \frac{\pi}{2}\right]$ ，所以 $y = \sin (x - 1)$ 是在 $x \in (0,2)$ 上的增函数，
> >
> > 又因为当 $x \in (0,2)$ 时， $y = \frac{x}{2 - x} = \frac{x - 2 + 2}{2 - x} = -1 - \frac{2}{x - 2}$ 是在 $x \in (0,2)$ 上的增函数，
> >
> > 所以 $y = \ln \frac{x}{2 - x}$ 也是在 $x\in (0,2)$ 上的增函数，
> >
> > 即 $y = g(x) = \sin (x - 1) + \ln \frac{x}{2 - x} +3$ 是在 $x\in (0,2)$ 上的增函数，
> >
> > 因为 $g(a^{2})\leq g(1 - 2b^{2})$ ，所以 $0 < a^2\leq 1 - 2b^2 < 2$
> >
> > 即 $a^2 + 2b^2 \leq 1$ ，又因为 $a^2 + 2b^2 = 2\sqrt{2}ab$ ，所以 $2\sqrt{2}ab \leq 1 \Rightarrow ab \leq \frac{\sqrt{2}}{4}$ ，
> >
> > 它们取等的条件为 $a^2 = 2b^2 = \frac{1}{2}$ ，此时满足 $0 < a^2 \leq 1 - 2b^2 < 2$ ，
> >
> > 所以 $\left\{\begin{aligned}a&=\frac{\sqrt{2}}{2}\\ b&=\frac{1}{2}\end{aligned}\right.$ 或 $\left\{\begin{aligned}a&=-\frac{\sqrt{2}}{2}\\ b&=-\frac{1}{2}\end{aligned}\right.$
