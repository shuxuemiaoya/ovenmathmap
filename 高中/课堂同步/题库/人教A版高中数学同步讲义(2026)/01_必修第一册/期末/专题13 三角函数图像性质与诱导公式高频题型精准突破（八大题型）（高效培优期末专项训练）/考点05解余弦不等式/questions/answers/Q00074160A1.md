> [!faq]- 《专题13 三角函数图像性质与诱导公式高频题型精准突破（八大题型）（高效培优期末专项训练）》官方解析
>
> > [!success]- **【答案】** (1) $a = 1$ (2)单调递增， $\left(\frac{\pi}{2} + 2k\pi, \frac{3\pi}{2} + 2k\pi\right) k \in \mathbb{Z}$
>
> > [!note]- **【分析】**
> > （1）根据 $f(0) = 0$ 求出 $a = 1$ ，再代入验证即可；
> >
> > (2) 利用定义判断函数 $f(x)$ 的单调性，结合奇偶性可得到 $\sin^2 x < 1 - \cos x$ ，再利用余弦函数的性质求解即可·
>
> > [!note]- **【解析】**
> > （1）因为 $f(x)$ 是定义域为 $R$ 的奇函数，所以 $f(0) = \frac{1}{1 + a} - \frac{1}{2} = 0$ ，解得 $a = 1$ ，
> >
> > 当 $a = 1$ 时， $f(x) = \frac{2^x}{2^x + 1} - \frac{1}{2} = \frac{2 \cdot 2^x - 2^x - 1}{2(2^x + 1)} = \frac{2^x - 1}{2(2^x + 1)}$
> >
> > 所以 $f(-x) = \frac{2^{-x} - 1}{2(2^{-x} + 1)} = \frac{1 - 2^x}{2(1 + 2^x)} = -f(x)$ ，满足 $f(x)$ 是奇函数，
> >
> > 所以 $a = 1$
> >
> > (2) 设 $x_{1}, x_{2} \in R, x_{1} < x_{2}$ ,
> >
> > 则 $f(x_{1}) - f(x_{2}) = \frac{1}{2}\left(\frac{2^{x_{1}} - 1}{2^{x_{1}} + 1} -\frac{2^{x_{2}} - 1}{2^{x_{2}} + 1}\right) = \frac{2^{x_{1}} - 2^{x_{2}}}{(2^{x_{1}} + 1)(2^{x_{2}} + 1)}$
> >
> > 因为 $x_{1} < x_{2}$ ，所以 $2^{x_1} - 2^{x_2} < 0$ ， $2^{x_1} + 1 > 0, 2^{x_2} + 1 > 0$
> >
> > 所以 $f(x_{1}) - f(x_{2}) = \frac{2^{x_{1}} - 2^{x_{2}}}{(2^{x_{1}} + 1)(2^{x_{2}} + 1)} < 0$ ，即 $f(x_{1}) < f(x_{2})$
> >
> > 所以 $f(x)$ 在 R 上单调递增，
> >
> > 因为 $f(\sin^2 x) + f(\cos x - 1) < 0$ ，所以 $f(\sin^2 x) < -f(\cos x - 1)$
> >
> > 又 $f(x)$ 为奇函数，所以 $-f(\cos x-1)=f(1-\cos x)$ ，
> >
> > 所以 $f\left(\sin^{2}x\right)<f(1-\cos x)$ ，得 $\sin^{2}x<1-\cos x$ ，
> >
> > 所以 $1 - \cos^2 x < 1 - \cos x$ ，化简得 $\cos x (\cos x - 1) > 0$ ，解得 $\cos x < 0$ 或 $\cos x > 1$
> >
> > 因为 $\cos x\in [-1,1]$ ，所以 $\cos x < 0$ ，解得 $\frac{\pi}{2} +2k\pi <  x <   \frac{3\pi}{2} +2k\pi ,k\in \mathbb{Z}$
> >
> > 所以关于 x 的不等式 $f(\sin^{2}x) + f(\cos x - 1) < 0$ 的解集为 $\left(\frac{\pi}{2} + 2k\pi, \frac{3\pi}{2} + 2k\pi\right) k \in \mathbb{Z}$ .
