> [!faq]- 《专题01 集合高频题型精准突破（八大题型）（高效培优期末专项训练）》官方解析
>
> > [!success]- **【答案】** A. $A \cdot B = \{x \mid x \leq -1$ 或 $x = 7\}$ B. $A \circ B = \{x \mid x < 0$ 或 $x > 4\}$ C. $A \cdot (\check{\mathbf{Q}}_{\mathbf{R}} B) = \{x \mid 4 \leq x \leq 7\}$ D. $(\check{\mathbf{Q}}_{\mathbf{R}} A) \circ B = \{x \mid x \leq 4$ 或 $x = 7\}$
>
> > [!note]- **【分析】**
> > 由题意可知 $A \cdot B = \tilde{\mathbf{Q}}_{\mathbf{R}}(A \cup B)$ ， $A \circ B = \tilde{\mathbf{Q}}_{\mathbf{R}}(A \cap B)$ ，结合集合的交集、并集和补集运算逐项分析判断即可·
>
> > [!note]- **【解析】**
> > 由题意可知： $A\cdot B = \check{\mathfrak{Q}}_{\mathbf{R}}(A\cup B)$ ， $A\circ B = \check{\mathfrak{Q}}_{\mathbf{R}}(A\cap B)$
> >
> > 因为集合 $A = \{x\mid -1 <   x\leq 4\} ,B = \{x\mid 0\leq x <   7\}$
> >
> > 对于选项 A：因为 $A \cup B = \{x \mid -1 < x < 7\}$
> >
> > 所以 $A \cdot B = \tilde{\partial}_{\mathbf{R}}(A \cup B) = \left\{ x \mid x \leq -1 \text{ 或 } x \quad 7 \right\}$ ，故 A 正确；
> >
> > 对于选项 B：因为 $A \cap B = \{x \mid 0 \leq x \leq 4\}$
> >
> > 所以 $A \circ B = \breve{\partial}_{\mathbf{R}}(A \cap B) = \left\{ x \mid x < 0 \text{ 或 } x > 4 \right\}$ ，故 B 正确；
> >
> > 对于选项 C：因为 $\tilde{\partial}_{R}B=\left\{x\mid x<0\text{ 或 }x\quad7\right\}$ ，则 $A\cup\left(\tilde{\partial}_{R}B\right)=\left\{x\mid x\leq4\text{ 或 }x\quad7\right\}$
> >
> > 所以 $A \cdot (\tilde{\mathfrak{Q}}_{\mathbf{R}} B) = \tilde{\mathfrak{Q}}_{\mathbf{R}}[A \cup (\tilde{\mathfrak{Q}}_{\mathbf{R}} B)] = \{x \mid 4 < x < 7\}$ ，故 $C$ 错误；
> >
> > 对于选项D：因为 $\check{\mathbf{Q}}_{\mathbf{R}}A = \{x\mid x\leq -1$ 或 $x > 4\}$ ，则 $(\check{\mathbf{Q}}_{\mathbf{R}}A)\cap B = \{x\mid 4 <   x <   7\}$
> >
> > 所以 $\left(\tilde{\mathbf{Q}}_{\mathbf{R}}A\right)\circ B = \tilde{\mathbf{Q}}_{\mathbf{R}}\left[\left(\tilde{\mathbf{Q}}_{\mathbf{R}}A\right)\cap B\right] = \left\{x\mid x\leq 4\text{或} x\quad 7\right\}$ ，故D正确；
> >
> > 故选 **ABD**.
