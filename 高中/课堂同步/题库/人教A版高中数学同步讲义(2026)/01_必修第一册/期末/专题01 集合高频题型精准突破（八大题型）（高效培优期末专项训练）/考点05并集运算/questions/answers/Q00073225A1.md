> [!faq]- 《专题01 集合高频题型精准突破（八大题型）（高效培优期末专项训练）》官方解析
>
> > [!success]- **【答案】** D
>
> > [!note]- **【分析】**
> > 先求出集合 $A$ 与 $B$ 的并集，然后根据并集的定义分类求出 $a$ 的值即可.
>
> > [!note]- **【解析】**
> > 因为 $A \cup B = \{x \in \mathbb{N}^* \mid x < 7\} = \{1, 2, 3, 4, 5, 6\}$
> >
> > 又因为 $A = \{2,3,4,5,6\}$ ， $B = \{1,2a + 3\}$
> >
> > 所以当 $2a + 3 = 1$ 时，解得 $a = -1$ ，不满足互异性，不符合题意，
> > 当 $2a + 3 = 2$ 时，解得 $a = -\frac{1}{2}$ ，符合题意，
> > 当 $2a + 3 = 3$ 时，解得 $a = 0$ ，符合题意，
> > 当 $2a + 3 = 4$ 时，解得 $a = \frac{1}{2}$ ，符合题意，
> >
> > 当 $2a + 3 = 5$ 时，解得 $a = 1$ ，符合题意，当 $2a + 3 = 6$ 时，解得 $a = \frac{3}{2}$ ，符合题意，综上可得， $a$ 的可能值为 $1$ ，故D正确·
> >
> > 故选 **D**
