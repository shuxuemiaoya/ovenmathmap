>
> > [!success]- **【答案】** ABD

> > [!note]- **【分析】**
> > 根据幂函数的概念可求 a 的值，再结合幂函数的性质对各选项进行判断.
>
> > [!note]- **【解析】**
> > 对于 $^{A}$ ，根据幂函数的定义可得 $a^{2}-4a+4=1\Rightarrow a=1$ 或3，故 $^{A}$ 正确；
> >
> > 对于 B，当 a=1 或 3 时， $f(x)=x^{-1}$ 或 $f(x)=x$ 都为奇函数，故 B 正确；
> >
> > 对于 C，当 a=1 时， $f(x)=x^{-1}$ 不是减函数，当 a=3 时， $f(x)=x$ 是增函数，故 C 错误；
> >
> > 对于 $^{D}$ ，因为对任意 $\alpha\in R$ 都有 $1^{\alpha}=1$ ，所以幂函数均经过点 $(1,1)$ ，故 $^{D}$ 正确·
> >
> > 故选：ABD
> >
> > 19. 函数 $f(x) = (3x - 2)^a + 2$ 的图象恒过点 \_\_\_\_.
> >
> > 【答案】(1,3)
> >
> > 【分析】根据幂函数的图象过定点求解·【详解】令 $3x - 2 = 1 \Rightarrow x = 1$ ，此时，无论 $a$ 取何值，都有 $f(1) = 1^a + 2 = 3$ 所以函数图象恒过点 $(1,3)$ 故答案为： $(1,3)$
