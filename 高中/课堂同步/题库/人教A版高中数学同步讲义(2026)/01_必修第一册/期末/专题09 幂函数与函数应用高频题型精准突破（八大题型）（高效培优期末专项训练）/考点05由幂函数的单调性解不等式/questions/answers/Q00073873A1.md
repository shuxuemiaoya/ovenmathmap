> [!faq]- 《专题09 幂函数与函数应用高频题型精准突破（八大题型）（高效培优期末专项训练）》官方解析
>
> > [!success]- **【答案】** D
>
> > [!note]- **【分析】**
> > 利用函数的奇偶性和单调性即可求解不等式·
>
> > [!note]- **【解析】**
> > 由于函数 $f(x) = \frac{x^2 + 1}{x^4}$ 的定义域为 $\{x | x \neq 0\}$ ，
> >
> > 且 $f(-x) = \frac{(-x)^2 + 1}{(-x)^4} = \frac{x^2 + 1}{x^4} = f(x)$ ，所以 $f(x) = \frac{x^2 + 1}{x^4}$ 是偶函数，
> >
> > 又因为 $f(x) = \frac{x^2 + 1}{x^4} = x^{-2} + x^{-4}$ ，由当 $k < 0$ 时， $y = x^k$ 在 $(0, +\infty)$ 上是减函数，
> >
> > 所以 $f(x)=x^{-2}+x^{-4}$ 在 $(0,+\infty)$ 上是减函数，
> >
> > 则由 $f(2a + 1) > f(3 - a)$ ，可得 $0 < |2a + 1| < |3 - a|$
> >
> > 平方得： $0 < (2a + 1)^{2} < (3 - a)^{2}$ ，解得 $x \in \left(-4, -\frac{1}{2}\right) \cup \left(-\frac{1}{2}, \frac{2}{3}\right)$
> >
> > 故选 **D**.
