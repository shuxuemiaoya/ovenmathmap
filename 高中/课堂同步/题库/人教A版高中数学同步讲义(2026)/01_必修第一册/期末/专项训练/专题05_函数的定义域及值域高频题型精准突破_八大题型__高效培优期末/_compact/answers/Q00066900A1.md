>
> > [!note]- **【分析】**
> > 利用待定系数法，由题意建立方程组，可得答案·
>
> > [!note]- **【解析】**
> > 设 $f(x)=ax^{2}+bx+c$ （ $a\neq0$ ），由 $f(0)=2$ ，则 c=2，
> >
> > 由 $f(x + 2) - f(x) = 4x$ ，则 $a(x + 2)^2 +b(x + 2) + 2 - (ax^2 +bx + 2) = 4x$
> >
> > 整理可得 $4ax + 4a + 2b = 4x$ ，则 $\left\{ \begin{array}{l}4a = 4\\ 4a + 2b = 0 \end{array} \right.$ ，解得 $\left\{ \begin{array}{l}a = 1\\ b = -2 \end{array} \right.$
> >
> > 所以 $f(x)=x^{2}-2x+2$
> >
> > 故选：B.
> >
> > 22. 根据下列条件，求 $f(x)$ 的解析式
> >
> > (1)已知 $f(\sqrt{x}-1)=x+4\sqrt{x}+3$ ；
> >
> > (2)已知 $f(x)$ 是二次函数，且满足 $f(0)=2, f(x)-f(x-1)=2x+3$ .
> >
> > 【答案】(1) $f(x)=x^{2}+6x+8(x-1)$
> >
> > (2) $f(x)=x^{2}+4x+2$
> >
> > 【分析】（1）利用换元法，可求得函数解析式；
> >
> > (2) 利用待定系数法，即可求得答案·
> >
> > 【详解】（1）令 $t = \sqrt{x} - 1(t - 1)$ ，则 $\sqrt{x} = t + 1, x = (t + 1)^2$
> >
> > 所以由 $f\left(\sqrt{x}-1\right)=x+4\sqrt{x}+3$
> >
> > 得 $f(t)=(t+1)^{2}+4(t+1)+3=t^{2}+6t+8$
> >
> > 所以 $f(x)=x^{2}+6x+8(x-1)$ ;
> >
> > (2) 由题意设 $f(x)=ax^{2}+bx+c(a\neq0)$ ,
> >
> > 因为 $f(0)=2$ ，所以 c=2，
> >
> > 因为 $f(x) - f(x - 1) = 2x + 3$
> >
> > 所以 $ax^{2} + bx + c - \left[a(x-1)^{2} + b(x-1) + c\right] = 2x + 3$
> >
> > 所以 $2ax - a + b = 2x + 3$
> >
> > 所以 $\left\{ \begin{array}{l} 2a = 2 \\ -a + b = 3 \end{array} \right.$ ，得 $a = 1, b = 4$ ，
> >
> > 所以 $f(x)=x^{2}+4x+2$ .
