> [!faq]- 《专题05_函数的定义域及值域高频题型精准突破_八大题型__高效培优期末》官方解析
>
> > [!success]- **【答案】** $\left[0, \frac{1}{2}\right]$
>
> > [!note]- **【分析】**
> > 根据二次函数以及根式可得 $0 \leq -x^{2} + x \leq \frac{1}{4}$ ，进而可得结果
>
> > [!note]- **【解析】**
> > 令 $-x^{2} + x = 0$ ，可得 $0\leq x\leq 1$
> >
> > 所以函数 $f(x)=\sqrt{-x^{2}+x}$ 的定义域为 $[0,1]$ ，
> >
> > 因为 $-x^{2} + x = -\left(x - \frac{1}{2}\right)^{2} + \frac{1}{4} \leq \frac{1}{4}$ ，当且仅当 $x = \frac{1}{2}$ 时，等号成立，
> >
> > $0 \leq -x^{2} + x \leq \frac{1}{4}$ ，则 $0 \leq \sqrt{-x^{2} + x} \leq \frac{1}{2}$ ，
> >
> > 所以函数 $y = f(x)$ 的值域为 $\left[0, \frac{1}{2}\right]$ .
> >
> > 故答案为： $\left[0, \frac{1}{2}\right]$
> >
> > 14. 函数 $f(x) = \frac{1 - 2x}{x^2 + 2}$ 在 $(- \infty, \frac{1}{2}]$ 上的值域为 \_\_\_\_.
> >
> > 【答案】[0,1]
> >
> > 【分析】根据给定条件，按 $x = \frac{1}{2}, x < \frac{1}{2}$ 分类，结合基本不等式求出值域
> >
> > 【详解】当 $x = \frac{1}{2}$ 时， $f(x) = 0$ ；
> >
> > 当 $x < \frac{1}{2}$ 时，令 $t = 1 - 2x > 0$ ， $x = \frac{1 - t}{2}$ ，则 $y = \frac{t}{\left(\frac{1 - t}{2}\right)^2 + 2} = \frac{4t}{t^2 - 2t + 9} = \frac{4}{t + \frac{9}{t} - 2}$ ，
> >
> > $t + \frac{9}{t} - 2\quad 2\sqrt{t \cdot \frac{9}{t}} - 2 = 4$ ，当且仅当 $t = \frac{9}{t}$ ，即 $t = 3, x = -1$ 时取等号，此时 $0 < y \leq 1$
> >
> > 所以所求值域为[0,1].
> >
> > 故答案为：[0,1]
> >
> > 15. 函数 $f(x) = [x]$ 的函数值表示不超过 $x$ 的最大整数，例如， $[-3.5] = -4, [2.1] = 2$ ，则函数 $g(x) = x - [x]$ 的值域为（）A.[0,1) B.(0,1] C.(-1,0) D.(-1,1]
> >
> > 【答案】A
> >
> > 【分析】根据取整函数的定义求函数的值域·
> >
> > 【详解】设 $x = a + b$ ，其中 $a = [x]$ ， $b$ 为 $x$ 的小数部分，则 $0 \leq b < 1$
> >
> > 则 $g(x) = x - [x] = b\in [0,1)$
> >
> > 所以函数 $g(x)$ 的值域为： $[0,1)$ .
> >
> > 故选 **A**
