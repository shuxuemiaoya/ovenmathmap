> [!faq]- 《专题05_函数的定义域及值域高频题型精准突破_八大题型__高效培优期末》官方解析
>
> > [!success]- **【答案】** A. $f(1) = 3$ B. $f(0) = 2$ C. 若 $f(x) = -1$ ，则 $x = 2$ D. $f(x) < 2$ 的解集为 $(-\infty, 0) \cup (1, +\infty)$
>
> > [!note]- **【分析】**
> > 根据分段函数的解析式直接计算求解可判断答案·
>
> > [!note]- **【解析】**
> > $f(1) = -1 + 3 = 2$ ，故 A 选项错误； $f(0) = 0 + 2 = 2$ ，故 B 选项正确；
> >
> > 当 $x < 1$ 时， $f(x) = x + 2 = -1$ ，解得 $x = -3$ ，当 $x = 1$ 时， $f(x) = -x^2 + 3 = -1$ ，解得 $x = 2$ ，即 $f(x) = -1$ 的解集为 $\{-3, 2\}$ ，故 C 选项错误；
> >
> > 当 $x < 1$ 时， $f(x) = x + 2 < 2$ ，解得 $x < 0$ ，当 $x - 1$ 时， $f(x) = -x^2 + 3 < 2$ ，解得 $x > 1$ ，综上， $f(x) < 2$ 的解集为 $(- \infty, 0) \cup (1, +\infty)$ ，故 D 选项正确；
> >
> > 故选 **BD**.
