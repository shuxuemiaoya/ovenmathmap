> [!faq]- 《专题09_幂函数与函数应用高频题型精准突破_八大题型__高效培优期末专》官方解析
>
> > [!success]- **【答案】** C
>
> > [!note]- **【分析】**
> > 根据幂函数的图象性质分别判断每个选项即可·
>
> > [!note]- **【解析】**
> > 对于 $^{A}$ ，当 $\alpha < 0$ 时，幂函数 $f(x) = x^{\alpha}$ 在 x = 0 处无定义，故图象不会经过点 $(0,0)$ ，选项 A 错误；对于 B，当 x > 0 时，幂函数 $f(x) = x^{\alpha}$ 都有意义，且 $x^{\alpha} > 0$ ，故幂函数的图象不经过第四象限，选项 B 错误；对于 C，当 $\alpha = 1$ 时， $f(x) = x$ ，在 R 上单调递增；当 $\alpha = 3$ 时， $f(x) = x^{3}$ ，在 R 上单调递增；当 $\alpha = \frac{1}{2}$ 时， $f(x) = x^{\frac{1}{2}} = \sqrt{x}$ ，定义域为 $[0, +\infty)$ ，且在 $[0, +\infty)$ 上单调递增，选项 C 正确；对于 D，幂函数的图象过点 $\left(\frac{1}{4}, 8\right)$ ，即 $f\left(\frac{1}{4}\right) = \left(\frac{1}{4}\right)^{\alpha} = 8$ ，所以 $\alpha = -\frac{3}{2}$ ，即 $f(x) = x^{-\frac{3}{2}}$ ，所以 $f(9) = 9^{-\frac{3}{2}} = 3^{-3} = \frac{1}{27}$ ，选项 D 错误；
> >
> > 故选 **C**.
