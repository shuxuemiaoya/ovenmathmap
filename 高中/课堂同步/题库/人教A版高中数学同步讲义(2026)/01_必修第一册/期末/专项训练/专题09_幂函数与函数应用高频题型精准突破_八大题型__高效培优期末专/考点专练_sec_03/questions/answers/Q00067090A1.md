> [!faq]- 《专题09_幂函数与函数应用高频题型精准突破_八大题型__高效培优期末专》官方解析
>
> > [!success]- **【答案】** BC
>
> > [!note]- **【分析】**
> > 首先求出函数的解析式，根据解析式即可判断 A，根据函数的奇偶性可判断 B，根据函数的单调性可判断 C，证明 $f(x)+x+2 \leq 0$ 即可判断 D.
>
> > [!note]- **【解析】**
> > 因为函数 $f(x) = x^a$ 经过 $\left(\frac{1}{3}, 3\right)$ ，即 $\left(\frac{1}{3}\right)^a = 3 \Rightarrow a = -1$ ，所以函数解析式为 $f(x) = \frac{1}{x}$ ，当 $x = 2$ 时， $f(2) = \frac{1}{2}$ ，所以函数 $f(x)$ 经过 $\left(2, \frac{1}{2}\right)$ ，故 ${}^{\mathrm{A}}$ 正确； $f(x)$ 为奇函数不为偶函数，图像关于原点对称，故 ${}^{\mathrm{B}}$ 错误； $f(x)$ 在 $(- \infty, 0)$ 和 $(0, +\infty)$ 单调递减，故 ${}^{\mathrm{C}}$ 错误；
> > 当 $x < 0$ 时， $f(x) + x + 2 = \frac{1}{x} + x + 2 = \frac{x^2 + 2x + 1}{x} = \frac{(x + 1)^2}{x} \leq 0$ ，故 $f(x) \leq -x - 2$ 恒成立，故 ${}^{\mathrm{D}}$ 正确。
> >
> > 故选 **BC**
