> [!faq]- 《专题09_幂函数与函数应用高频题型精准突破_八大题型__高效培优期末专》官方解析
>
> > [!success]- **【答案】** (1) $P(x)=\left\{\begin{aligned}&-2x^{2}+94x-2002<x\leq5,\\&-\frac{-10x^{2}+370x-720}{x-1}\end{aligned}\right.$ $5<x\leq10$ (2)当笔记本的售价定为每本 $^{7}$ 元时，该文具店的日均利润最大，为 $^{230}$ 元。
>
> > [!note]- **【分析】**
> > （1）依题意，当 $2 < x \leq 5$ 时，当 $5 < x \leq 10$ 时，根据利润与售价的关系即可求得解析式；
> >
> > (2) 根据相应解析式利用二次函数与基本不等式得最值，比较可得结论.
>
> > [!note]- **【解析】**
> > （1）当 $2 < x \leq 5$ 时，
> >
> > $$
> > P (x) = (x - 2) y - 2 0 = (x - 2) (9 0 - 2 x) - 2 0 = - 2 x ^ {2} + 9 4 x - 2 0 0
> > $$
> >
> > 当 $5 < x \leq 10$ 时，
> >
> > $$
> > P (x) = (x - 2) y - 2 0 = \frac {(x - 2) (3 7 0 - 1 0 x)}{x - 1} - 2 0 = \frac {- 1 0 x ^ {2} + 3 7 0 x - 7 2 0}{x - 1}
> > $$
> >
> > 综上， $P(x) = \left\{ \begin{array}{ll} - 2x^{2} + 94x - 2002 <   x\leq 5,\\ \frac{-10x^{2} + 370x - 720}{x - 1} 5 <   x\leq 10. \end{array} \right.$
> >
> > (2) 当 $2 < x \leq 5$ 时， $P(x) = -2x^{2} + 94x - 200 = -2\left(x - \frac{47}{2}\right)^{2} + \frac{1809}{2}$
> >
> > $P(x)$ 图象的对称轴为 $x=\frac{47}{2}>5$
> >
> > 所以 $P(x)$ 在 $(2,5]$ 上单调递增，最大值在 x=5 处取到，为 220；
> >
> > 当 $5 < x \leq 10$ 时， $P(x) = \frac{-10x^2 + 370x - 720}{x - 1} = \frac{-10(x - 1)^2 + 350(x - 1) - 360}{x - 1}$
> >
> > $$
> > = 3 5 0 - \left[ 1 0 (x - 1) + \frac {3 6 0}{x - 1} \right] \leq 3 5 0 - 2 \sqrt {3 6 0 0} = 2 3 0
> > $$
> >
> > 当且仅当 $10(x - 1) = \frac{360}{x - 1}$ ，即 $x = 7$ 时，等号成立，且 $5 < 7 \leq 10$ ；
> >
> > 因为 $220 < 230$ ，所以当笔记本的售价定为每本 ${ }^{7}$ 元时，该文具店的日均利润最大，为 ${ }^{230}$ 元。

> > 43. 为推动县域经济发展，某县计划建一农产品加工厂·经市场调研，生产需投入年固定成本为 $30$ 万元，每生产 $x$ 万件产品，需另投入的流动成本为 $W(x)$ 万元，在年产量不足 $10$ 万件时， $W(x) = \frac{1}{4} x^2 + 3x - 60$ （万元），在年产量不小于10万件时， $W(x)=10x+\frac{450}{x}-150$ （万元），每件产品的售价为8元，且该厂生产的产品当年能全部售完·
> >
> > (1)写出年利润 $L(x)$ （万元）关于年产量x（万件）的函数解析式；
> >
> > (注：年利润 = 年销售收入 - 固定成本 - 流动成本)
> >
> > (2)当年产量为多少万件时，该厂所获利润最大？最大利润是多少？
> >
> > 【答案】(1) $L(x)=\left\{\begin{aligned}-\frac{1}{4}x^{2}+5x+30,x&\in[0,10)\\-2x-\frac{450}{x}+120,x&\in[10,+\infty)\end{aligned}\right.$
> >
> > (2)年产量15万件时，该厂所获利润最大，最大利润为60万元
> >
> > 【分析】（1）根据年利润的定义，分别考虑 $x \in [0,10), x \in [10, +\infty)$ 时年利润的表达式，由此可知结果；（2）当 $x \in [0,10)$ 时，利用二次函数性质分析 $L(x)$ 的最大值；当 $x \in [10, +\infty)$ 时，利用基本不等式求出 $L(x)$ 的最大值，由此可知结果。
> >
> > 【详解】（1）当 $x \in [0, 10)$ 时， $L(x) = 8x - \left(\frac{1}{4} x^2 + 3x - 60\right) - 30 = -\frac{1}{4} x^2 + 5x + 30$
> >
> > 当 $x \in [10, +\infty)$ 时， $L(x) = 8x - \left(10x + \frac{450}{x} - 150\right) - 30 = -2x - \frac{450}{x} + 120$
> >
> > 所以 $L(x)=\left\{\begin{aligned}-\frac{1}{4}x^{2}+5x+30,x&\in[0,10)\\-2x-\frac{450}{x}+120,x&\in[10,+\infty)\end{aligned}\right.$
> >
> > (2) 当 $x \in [0,10)$ 时， $L(x) = -\frac{1}{4}(x - 10)^{2} + 55$
> >
> > 因为 $0 \leq x < 10$ ，所以 $L(x) < 55$ ；
> >
> > 当 $x\in [10, + \infty)$ 时， $L(x) = -2\left(x + \frac{225}{x}\right) + 120\leq -4\sqrt{x\cdot\frac{225}{x}} +120 = 60$
> >
> > 当且仅当 $x = \frac{225}{x}$ ，即 $x = 15$ 时取等号，所以 $L(x)_{\mathrm{max}} = 60$
> >
> > 综上所述，当年产量15万件时，该厂所获利润最大，最大利润为60万元·
