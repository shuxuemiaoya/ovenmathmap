> [!faq]- 《专题09_幂函数与函数应用高频题型精准突破_八大题型__高效培优期末专》官方解析
>
> > [!success]- **【答案】** (1)4米 (2) $0 < a < 12$
>
> > [!note]- **【分析】**
> > （1）由题意可得 $y$ 与 $x$ 的关系，结合基本不等式计算即可得；
> >
> > (2) 由题意可将问题转化为 $\frac{(x + 4)^2}{x + 1} > a$ 在 $x \in [2,6]$ 恒成立，结合基本不等式计算即可得.
>
> > [!note]- **【解析】**
> > （1）设甲工程队的总造价为 $y$ 元，
> >
> > 则 $y=3\left(150\times2x+400\times\frac{12}{x}\right)+7200=900\left(x+\frac{16}{x}\right)+7200,(2\leq x\leq6)$
> >
> > $$
> > \because 9 0 0 \left(x + \frac {1 6}{x}\right) + 7 2 0 0 \quad 9 0 0 \times 2 \times \sqrt {x \cdot \frac {1 6}{x}} + 7 2 0 0 = 1 4 4 0 0
> > $$
> >
> > 当且仅当 $x = \frac{16}{x}$ ，即 $x = 4$ 时等号成立，
> >
> > ∴当左右两面墙的长度为4米时，甲工程队的报价最低为14400元；
> >
> > (2) 由题意可得， $900\left(x+\frac{16}{x}\right)+7200>\frac{900a(1+x)}{x}$ 对任意的 $x\in[2,6]$ 恒成立，
> >
> > 则 $\frac{(x + 4)^2}{x} >\frac{a(1 + x)}{x}$ ，即 $\frac{(x + 4)^2}{x + 1} >a$ 在 $x\in [2,6]$ 恒成立，
> >
> > 又 $\frac{(x + 4)^2}{x + 1} = x + 1 + \frac{9}{x + 1} +6\quad 2\sqrt{(x + 1)\frac{9}{x + 1}} +6 = 12$
> >
> > 当且仅当 $x + 1 = \frac{9}{x + 1}$ 即 $x = 2$ 时等号成立，
> >
> > $\therefore a < 12$ ，又 $a > 0$ ，故 $0 < a < 12$ .

> > 48. 随着我国经济发展，医疗消费需求增长，人们健康观念转变以及人口老龄化进程加快等影响，医疗器械市场近年来一直保持了持续增长的趋势。某医疗器械公司为了进一步增加市场力，计划改进技术生产某产品。已知生产该产品的年固定成本为 $300$ 万元，最大产能为 $100$ 台，每生产 $x$ 台，需另投入成本 $G(x)$ 万元，且 $G(x) = \begin{cases} 2x^2 + 80x, & 0 < x \leq 40 \\ 201x + \frac{3600}{x} - 2100, & 40 < x \leq 100 \end{cases}$ ，由市场调研知，该产品每台的售价为 $200$ 万元，且全年内
> >
> > 生产的该产品当年能全部销售完。
> >
> > (1)写出年利润 $W(x)$ 万元关于年产量x台的函数解析式（利润=销售收入-成本）；
> >
> > (2)当该产品的年产量为多少时，公司所获利润最大？最大利润是多少？
> >
> > 【答案】(1) $W(x)=\left\{\begin{aligned}-2x^{2}+120x-300, & 0<x\leq40\\ -\left(x+\frac{3600}{x}\right)+1800, & 40<x\leq100\end{aligned}\right.$
> >
> > (2)年产量为 60 台时，公司所获利润最大，最大利润是 1680 万元
> >
> > 【分析】（1）分 $0 < x \leq 40$ 和 $40 < x \leq 100$ 两种情况，进行求解利润；
> >
> > (2) $0 < x \leq 40$ 时，可利用二次函数的特点求最大利润值， $40 < x \leq 100$ 时，利用基本不等式求最值，最后要对两个最值比较，得出最大利润。
> >
> > 【详解】（1）当 $0 < x \leq 40$ 时， $W(x) = 200x - (2x^2 + 80x) - 300 = -2x^2 + 120x - 300$ ；
> >
> > 当 $40 < x \leq 100$ 时， $W(x) = 200x - \left(201x + \frac{3600}{x} - 2100\right) - 300 = -\left(x + \frac{3600}{x}\right) + 1800$
> >
> > $$
> > W (x) = \left\{ \begin{array}{l} - 2 x ^ {2} + 1 2 0 x - 3 0 0, 0 <   x \leq 4 0 \\ - \left(x + \frac {3 6 0 0}{x}\right) + 1 8 0 0, 4 0 <   x \leq 1 0 0 \end{array} \cdot \right.
> > $$
> >
> > (2) 若 $0 < x \leq 40, W(x) = -2(x - 30)^{2} + 1500$ ，当 x = 30 时， $W(x)_{\max} = 1500$ 万元；
> >
> > 若 $40 < x \leq 100$
> >
> > $$
> > W (x) = - \left(x + \frac {3 6 0 0}{x}\right) + 1 8 0 0 \leq - 2 \sqrt {x \cdot \frac {3 6 0 0}{x}} + 1 8 0 0 = - 1 2 0 + 1 8 0 0 = 1 6 8 0,
> > $$
> >
> > 当且仅当 $x = \frac{3600}{x}$ 时，即 $x = 60$ 时， $W(x)_{\max} = 1680$ 万元，
> >
> > 由于 $1680 > 1500$ ，故该产品的年产量为 $^{60}$ 台时，公司所获利润最大，
> >
> > 最大利润是 1680 万元 .
