> [!faq]- 《专题09_幂函数与函数应用高频题型精准突破_八大题型__高效培优期末专》官方解析
>
> > [!success]- **【答案】** (1) $g(x)=\left\{\begin{aligned}&-\frac{2}{3}x^{2}+12x-30,0\leq x\leq14,\\ &50-x-\frac{400}{x},14<x\leq35.\end{aligned}\right.$ (2)9 万件
>
> > [!note]- **【分析】**
> > （1）分 $0 \leq x \leq 14$ 和 $14 < x \leq 35$ 两种情况，分别求出函数解析式；
> >
> > (2) 结合二次函数及基本不等式求出函数的最大值，即可得解
>
> > [!note]- **【解析】**
> > （1）根据题意得，当 $0 \leq x \leq 14$ 时， $g(x) = 16x - f(x) - 30 = -\frac{2}{3} x^2 + 12x - 30$
> >
> > 当 $14 < x \leq 35$ 时， $g(x) = 16x - f(x) - 30 = 50 - x - \frac{400}{x}$ ，
> >
> > $$
> > g (x) = \left\{ \begin{array}{l} - \frac {2}{3} x ^ {2} + 1 2 x - 3 0, 0 \leq x \leq 1 4, \\ 5 0 - x - \frac {4 0 0}{x}, 1 4 <   x \leq 3 5. \end{array} \right.
> > $$
> >
> > (2) 当 $0 \leq x \leq 14$ 时， $g(x) = -\frac{2}{3}x^{2} + 12x - 30$
> >
> > 且当 $0 \leq x \leq 9$ 时， $g(x)$ 单调递增，当 $9 < x \leq 14$ 时， $g(x)$ 单调递减，
> >
> > 此时 $g(x)_{\max}=g(9)=-\frac{2}{3}\times81+12\times9-30=24$ .
> >
> > 当 $14 < x \leq 35$ 时， $g(x) = 50 - x - \frac{400}{x} \leq 50 - 2\sqrt{x \cdot \frac{400}{x}} = 10$ ，当且仅当 $x = 20$ 时，等号成立·
> >
> > 因为 $24 > 10$ ，故当 $x = 9$ 时， $g(x)$ 取得最大值24，
> >
> > 即为使公司获得的年利润最大，每年应生产9万件该芯片·
