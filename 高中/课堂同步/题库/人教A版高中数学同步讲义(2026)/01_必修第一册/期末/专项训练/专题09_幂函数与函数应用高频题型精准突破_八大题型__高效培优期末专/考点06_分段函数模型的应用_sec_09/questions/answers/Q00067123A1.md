> >
> > (2) 结合二次函数的性质以及基本不等式求得正确答案.

> > [!note]- **【解析】**
> > （1） $g(x)=10x-10-f(x)=\left\{\begin{aligned}-\frac{1}{5}x^{2}+4x-10, & 0<x\leq4\\45-\left(3x+\frac{123}{x}\right), & x>4\end{aligned}\right.$ ， $x\in N^{*}$
> >
> > (2) 当 $0 < x \leq 4$ 时， $g(x) = -\frac{1}{5}x^{2} + 4x - 10$
> >
> > 由对称轴 $x = 10$ 知 $g(x)$ 在 $x \in (0,4]$ 递增， $g(x) \leq g(4) = 2.8$ .
> >
> > 当 $x > 4$ 时， $g(x) = 45 - \left(3x + \frac{123}{x}\right) \leq 45 - 2\sqrt{3x \cdot \frac{123}{x}} = 45 - 6\sqrt{41}$ .
> >
> > 当且仅当 $x = \sqrt{41}$ 时等号成立，
> >
> > 而 $\sqrt{41} \notin N^{*}$ ，由 $\sqrt{41} \in (6,7)$
> >
> > $$
> > g (6) = \frac {1 3}{2}, g (7) = \frac {4 5}{7}, \frac {1 3}{2} > \frac {4 5}{7} > 2. 8
> > $$
> >
> > 所以当 x=6 时， $g(x)_{\max}=\frac{13}{2}$ .
> >
> > 即当年销量为 $^{6}$ 千册时，该纪念册的年利润最大，最大年利润为 $\frac{13}{2}$ 万元。

> > 46. 经过调研发现，某机器工厂每月生产的机器数量 $W$ （单位：台）和成本 $x$ （单位：万元）满足如下关
> >
> > 系： $W(x) = \left\{ \begin{array}{ll}19 - \frac{4}{x + 1},0 <   x\leq 3\\ -x^{2} + 9x - 5,3 <   x\leq 6 \end{array} \right.$ .已知该机器的市场售价为1万元/台，且供不应求，记工厂每月的利润
> >
> > 为 $f(x)$ （单位：万元）
> >
> > (1)求 $f(x)$ 的函数解析式；
> >
> > (2)当成本 $x$ 为多少万元时，该工厂每月的利润最大？最大利润是多少万元？
> >
> > 【答案】(1) $f(x)=\left\{\begin{aligned}&19-\frac{4}{x+1}-x,0<x\leq3\\&-x^{2}+8x-5,3<x\leq6\end{aligned}\right.$
> >
> > (2)当成本为 $^{1}$ 万元时，该工厂每月的利润最大，最大利润是 $^{16}$ 万元。
> >
> > 【分析】（ $^{1}$ ）由利润=销售额-成本，得函数关系式；
> >
> > (2) 结合二次函数的性质及基本不等式求出各段的最大值，比较大小，即可求出分段函数的最值.
> >
> > 【详解】（1）由题意可得 $f(x) = W(x) - x = \begin{cases} 19 - \frac{4}{x + 1} - x, & 0 < x \leq 3 \\ -x^2 + 8x - 5, & 3 < x \leq 6 \end{cases}$ ;
> >
> > 所以 $f(x) = \begin{cases} 19 - \frac{4}{x + 1} - x, & 0 < x \leq 3 \\ -x^2 + 8x - 5, & 3 < x \leq 6 \end{cases}$
> >
> > (2) 当 $0 < x \leq 3$ 时， $x + 1 \in (1, 4]$
> >
> > $$
> > f (x) = 1 9 - \frac {4}{x + 1} - x = 2 0 - \left(\frac {4}{x + 1} + x + 1\right) \leq 2 0 - 2 \sqrt {\frac {4}{x + 1} \times (x + 1)} = 1 6,
> > $$
> >
> > 当且仅当 $\frac{4}{x + 1} = x + 1$ 即 $x = 1$ 时等号成立，此时 $f(x)_{\max} = 16$
> >
> > 当 $3 < x \leq 6$ 时， $f(x) = -x^2 + 8x - 5$ 为开口向下的抛物线，其对称轴为 $x = 4$
> >
> > 所以当 x=4 时， $f(x)_{\max}=f(4)=11$
> >
> > 综上所述：当成本为 $^{1}$ 万元时，该工厂每月的利润最大，最大利润是 $^{16}$ 万元。
