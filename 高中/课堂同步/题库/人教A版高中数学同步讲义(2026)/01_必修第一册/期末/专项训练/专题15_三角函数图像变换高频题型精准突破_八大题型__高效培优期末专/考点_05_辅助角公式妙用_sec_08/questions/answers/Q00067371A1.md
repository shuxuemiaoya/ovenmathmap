> [!faq]- 《专题15_三角函数图像变换高频题型精准突破_八大题型__高效培优期末专》官方解析
>
> > [!success]- **【答案】** A. $\left(\frac{1}{\tan5^{\circ}}-\tan5^{\circ}\right)\tan10^{\circ}=2$ B. $\frac{\tan\frac{5\pi}{4}+\tan\frac{5\pi}{12}}{1-\tan\frac{5\pi}{12}}=-\frac{\sqrt{3}}{3}$ C. $\frac{\sqrt{1 - \sin 10^{\circ}}\cos 40^{\circ}}{\cos 10^{\circ}} = \frac{\sqrt{2}}{2}$ D. $2\cos10^{\circ}-\frac{1}{2\tan10^{\circ}}=-\frac{\sqrt{3}}{2}$
>
> > [!note]- **【分析】**
> > 对 A，利用正切的二倍角公式化简；对 B，利用两角和的正切公式化简；对 C 和 D，利用二倍角公式和辅助角公式化简·
>
> > [!note]- **【解析】**
> > 对于 A， $\left(\frac{1}{\tan5^{\circ}}-\tan5^{\circ}\right)\tan10^{\circ}=\frac{1-\tan^{2}5^{\circ}}{\tan5^{\circ}}\times\tan10^{\circ}=2\frac{1}{\tan10^{\circ}}\times\tan10^{\circ}=2$ ，A 正确；
> >
> > 对于 B， $\frac{\tan\frac{5\pi}{4}+\tan\frac{5\pi}{12}}{1-\tan\frac{5\pi}{12}}=\frac{\tan\frac{\pi}{4}+\tan\frac{5\pi}{12}}{1-\tan\frac{\pi}{4}\cdot\tan\frac{5\pi}{12}}=\tan\left(\frac{\pi}{4}+\frac{5\pi}{12}\right)=\tan\frac{2\pi}{3}=-\sqrt{3}$ ，B 错误；
> >
> > 对于 C， $\frac{\sqrt{1-\sin10^{\circ}}\cos40^{\circ}}{\cos10^{\circ}}=\frac{(\cos5^{\circ}-\sin5^{\circ})\cos40^{\circ}}{\cos^{2}5^{\circ}-\sin^{2}5^{\circ}}=\frac{\cos40^{\circ}}{\cos5^{\circ}+\sin5^{\circ}}=\frac{\cos40^{\circ}}{\sqrt{2}\cos40^{\circ}}=\frac{\sqrt{2}}{2}$ ，C 正确；
> >
> > 对于 D
> >
> > $$
> > 2 \cos 1 0 ^ {\circ} - \frac {1}{2 \tan 1 0 ^ {\circ}} = 2 \cos 1 0 ^ {\circ} - \frac {\cos 1 0 ^ {\circ}}{2 \sin 1 0 ^ {\circ}} = \frac {2 \sin 2 0 ^ {\circ} - \cos 1 0 ^ {\circ}}{2 \sin 1 0 ^ {\circ}} = \frac {2 \sin (3 0 ^ {\circ} - 1 0 ^ {\circ}) - \cos 1 0 ^ {\circ}}{2 \sin 1 0 ^ {\circ}} = \frac {- \sqrt {3} \sin 1 0 ^ {\circ}}{2 \sin 1 0 ^ {\circ}} = - \frac {\sqrt {3}}{2}, D
> > $$
> >
> > 确·
> >
> > 故选 **ACD**.
