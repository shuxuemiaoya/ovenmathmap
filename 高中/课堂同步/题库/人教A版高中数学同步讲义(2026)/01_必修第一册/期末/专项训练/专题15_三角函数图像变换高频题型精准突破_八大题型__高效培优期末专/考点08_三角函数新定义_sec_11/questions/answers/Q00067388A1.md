> [!faq]- 《专题15_三角函数图像变换高频题型精准突破_八大题型__高效培优期末专》官方解析
>
> > [!success]- **【答案】** -4
>
> > [!note]- **【分析】**
> > 根据题意化简得到 $2(m+n\cos p)\sin\left(x+\frac{\pi}{6}\right)-2n\sin p\cos\left(x+\frac{\pi}{6}\right)+(m+n-1)=0$ ，结合对任意实数x
> >
> > 恒成立，得到 $\left\{ \begin{array}{l} m + n\cos p = 0 \\ n\sin p = 0 \\ m + n - 1 = 0 \end{array} \right.$ ，分类讨论，取得 $\cos p = -1$ ，且 $m = n = \frac{1}{2}$ ，即可求解。
>
> > [!note]- **【解析】**
> > 由题意可得 $h(x)=f(x)+1=\sqrt{3}\sin x+\cos x+1=2\sin\left(x+\frac{\pi}{6}\right)+1$
> >
> > 所以 $2m\sin \left(x + \frac{\pi}{6}\right) + 2n\sin \left(x + \frac{\pi}{6}\right)\cos p - 2\cos \left(x + \frac{\pi}{6}\right)\sin p + (m + n - 1) = 0$
> >
> > 所以 $2(m + n\cos p)\sin \left(x + \frac{\pi}{6}\right) - 2n\sin p\cos \left(x + \frac{\pi}{6}\right) + (m + n - 1) = 0$
> >
> > 又因为上式对任意实数 恒成立，所以 $\left\{ \begin{array}{l}m + n\cos p = 0\\ n\sin p = 0\\ m + n - 1 = 0 \end{array} \right.$
> >
> > 若 n=0 ，由 $m+n\cos p=0$ ，可得 m=0 ，不满足 $m+n-1=0$ ；
> >
> > 由 $\sin p = 0$ ，可得 $p = 2k\pi$ 或 $p = 2k\pi +\pi (k\in Z)$
> >
> > 当 $p = 2k\pi (k\in \mathbb{Z})$ 时， $\cos p = 1$ ，由 $m + n\cos p = 0$ 与 $m + n - 1 = 0$ 矛盾；
> >
> > 故 $p = 2k\pi + \pi (k \in \mathbb{Z})$ ，则 $\cos p = -1$
> >
> > 由 $m + n\cos p = 0$ 与 $m + n - 1 = 0$ ，可得 $m = n = \frac{1}{2}$
> >
> > 综上可得，原式 $\frac{\cos p}{mn} = -4$
> >
> > 故答案为：-4。
