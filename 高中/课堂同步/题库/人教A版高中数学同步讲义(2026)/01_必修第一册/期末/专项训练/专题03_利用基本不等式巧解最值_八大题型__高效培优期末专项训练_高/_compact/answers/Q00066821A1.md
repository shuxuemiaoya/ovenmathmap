> [!faq]- 《专题03_利用基本不等式巧解最值_八大题型__高效培优期末专项训练_高》官方解析
>
> > [!success]- **【答案】** A
>
> > [!note]- **【分析】**
> > 利用基本不等式逐项判断即可·
>
> > [!note]- **【解析】**
> > 由重要不等式可得 $a^2 + b^2 = 2ab$ ，当且仅当 $a = b$ 时等号成立，即 $\sqrt{\frac{a^2 + b^2}{2}} = \sqrt{ab}$ ，但 $a \neq b$ ，则 $\sqrt{\frac{a^2 + b^2}{2}} > \sqrt{ab}$ ，
> >
> > 因为 $a^{2}+b^{2}\quad2ab$ ，则 $2\left(a^{2}+b^{2}\right)\quad a^{2}+b^{2}+2ab=\left(a+b\right)^{2}$ ，即 $\frac{a^{2}+b^{2}}{2}\quad\left(\frac{a+b}{2}\right)^{2}$ ，
> >
> > 故 $\sqrt{\frac{a^2 + b^2}{2}}$ $\frac{a + b}{2}$ ，当且仅当 $a = b$ 时等号成立，
> >
> > 但 $a \neq b$ ，则 $\sqrt{\frac{a^2 + b^2}{2}} > \frac{a + b}{2}$
> >
> > 由基本不等式可得 $\frac{2ab}{a + b} \leq \frac{2 \times \left(\frac{a + b}{2}\right)^2}{a + b} = \frac{a + b}{2}$ ，当且仅当 $a = b$ 时等号成立，但 $a \neq b$ ，则 $\frac{2ab}{a + b} < \frac{2 \times \left(\frac{a + b}{2}\right)^2}{a + b} = \frac{a + b}{2}$ ，
> >
> > 故这四个数中，最大的为 $\sqrt{\frac{a^2 + b^2}{2}}$
> >
> > 故选 **A**.
