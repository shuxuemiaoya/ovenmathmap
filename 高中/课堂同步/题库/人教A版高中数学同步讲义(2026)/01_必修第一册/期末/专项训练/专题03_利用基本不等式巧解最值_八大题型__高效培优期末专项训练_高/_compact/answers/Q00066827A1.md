> [!faq]- 《专题03_利用基本不等式巧解最值_八大题型__高效培优期末专项训练_高》官方解析
>
> > [!success]- **【答案】** (1) $\frac{9}{2}$ (2)5 (3)7
>
> > [!note]- **【分析】**
> > （1）根据基本不等式“1”的代换，计算即可得答案
> >
> > (2) 对所求进行配凑变形可得 $4x - 2 + \frac{1}{4x - 5} = 4x - 5 + \frac{1}{4x - 5} + 3$ ，利用基本不等式，即可得答案.
> >
> > (3) 对所求进行变形可得 $\frac{x^{2}+3x+4}{x}=x+\frac{4}{x}+3$ ，利用基本不等式，即可得答案.
>
> > [!note]- **【解析】**
> > （1）由 $x + y = 2$ ，得 $\frac{1}{2} (x + y) = 1$
> >
> > 所以 $\frac{4}{x} +\frac{1}{y} = \left(\frac{4}{x} +\frac{1}{y}\right)\times \frac{1}{2}\big(x + y\big) = \frac{1}{2}\left(4 + \frac{4y}{x} +\frac{x}{y} +1\right)\quad \frac{1}{2}\left(5 + 2\sqrt{\frac{4y}{x}\cdot\frac{x}{y}}\right) = \frac{9}{2},$
> >
> > 当且仅当 $\frac{4y}{x} = \frac{x}{y}$ ，即 $x = \frac{4}{3}, y = \frac{2}{3}$ 时取等号，
> >
> > 所以 $\frac{4}{x} +\frac{1}{y}$ 的最小值为 $\frac{9}{2}$
> >
> > (2) 由 $x > \frac{5}{4}$ 得 4x - 5 > 0，
> >
> > 则 $4x - 2 + \frac{1}{4x - 5} = 4x - 5 + \frac{1}{4x - 5} + 3$ $2\sqrt{(4x - 5)\times\frac{1}{4x - 5}} +3 = 5$
> >
> > 当且仅当 $4x - 5 = \frac{1}{4x - 5}$ ，即 $x = \frac{3}{2}$ 时取等号，
> >
> > 所以 $4x - 2 + \frac{1}{4x - 5}$ 的最小值为5
> >
> > (3) 当 x > 0 时， $\frac{x^{2} + 3x + 4}{x} = x + \frac{4}{x} + 3 \quad 2\sqrt{x \cdot \frac{4}{x}} + 3 = 7$
> >
> > 当且仅当 $x=\frac{4}{x}$ ，即 x=2 时取等号，
> >
> > 所以 $\frac{x^2 + 3x + 4}{x}$ 的最小值为7
