> [!faq]- 《专题03_利用基本不等式巧解最值_八大题型__高效培优期末专项训练_高》官方解析
>
> > [!success]- **【答案】** A. $a - 2 - 2\sqrt{3}$ B. $-2 - 2\sqrt{3} \leq a \leq -2 + 2\sqrt{3}$ C. $a \leq \frac{3}{2}$ D. $a \leq 2\sqrt{3} - 2$
>
> > [!note]- **【分析】**
> > 先把问题转化成 $a \leq \frac{x^2 + 2}{x + 1}$ ，再利用换元法，结合基本不等式求 $\frac{x^2 + 2}{x + 1}$ 的最小值即可。【详解】由 $x^2 - ax - a + 2 = 0 \Rightarrow a(x + 1) \leq x^2 + 2$ ，因为 $0 \leq x \leq 1$ ，所以 $1 \leq x + 1 \leq 2$ ，所以 $a \leq \frac{x^2 + 2}{x + 1}$ 。设 $t = x + 1$ ，则 $x = t - 1, 1 \leq t \leq 2$ ，所以 $\frac{x^2 + 2}{x + 1} = \frac{(t - 1)^2 + 2}{t} = t + \frac{3}{t} - 2 = 2\sqrt{t \cdot \frac{3}{t}} - 2 = 2\sqrt{3} - 2$ （当且仅当 $t = \frac{3}{t}$ 即 $t = \sqrt{3} \in [1, 2]$ 时取等号）。所以 $a \leq 2\sqrt{3} - 2$ 。故选：D
>
