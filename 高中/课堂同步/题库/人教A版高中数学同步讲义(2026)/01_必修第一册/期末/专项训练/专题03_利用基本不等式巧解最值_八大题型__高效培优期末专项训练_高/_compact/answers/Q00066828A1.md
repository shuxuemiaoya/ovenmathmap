> [!faq]- 《专题03_利用基本不等式巧解最值_八大题型__高效培优期末专项训练_高》官方解析
>
> > [!success]- **【答案】** $(-∞,2)$
>
> > [!note]- **【分析】**
> > 问题化为 $3 - \frac{x + 1}{(x + 1)^2 - (x + 1) + 1} > n$ 恒成立，讨论 $t = x + 1$ 的符号确定代数式的范围，即可得参数范
> >
> > 围·
>
> > [!note]- **【解析】**
> > 由 $\frac{3x^2 + 2x + 2}{x^2 + x + 1} = \frac{3(x^2 + x + 1) - x - 1}{x^2 + x + 1} = 3 - \frac{x + 1}{(x + 1)^2 - (x + 1) + 1}$
> >
> > 令 $t = x + 1$ ，则 $3 - \frac{x + 1}{(x + 1)^2 - (x + 1) + 1} = 3 - \frac{t}{t^2 - t + 1}$
> >
> > 当 时， $3-\frac{t}{t^{2}-t+1}=3+\frac{1}{(-t)+\left(-\frac{1}{t}\right)+1}\leq3+\frac{1}{2\sqrt{(-t)\cdot\left(-\frac{1}{t}\right)}+1}=\frac{10}{3}$ ，当且仅当 $-t=-\frac{1}{t}$ ，即 t=-1 时取等号，
> >
> > 若 $t \to -\infty$ 时， $\frac{1}{(-t)+\left(-\frac{1}{t}\right)+1} \to 0$ ，则 $3 + \frac{1}{(-t)+\left(-\frac{1}{t}\right)+1} \to 3$ ，此时代数式的范围为 $\left(3, \frac{10}{3}\right]$ ，
> >
> > 当 $t = 0$ 时， $3 - \frac{t}{t^2 - t + 1} = 3$
> >
> > 当 时， $3-\frac{t}{t^{2}-t+1}=3-\frac{1}{t+\frac{1}{t}-1}$ $3-\frac{1}{2\sqrt{t\cdot\frac{1}{t}}-1}=2$ ，当且仅当 $t=\frac{1}{t}$ ，即 时取等号，
> >
> > 若 $t \to +\infty$ 时， $\frac{1}{t+\frac{1}{t}-1} \to 0$ ，则 $3-\frac{1}{t+\frac{1}{t}-1} \to 3$ ，此时代数式的范围为 $[2,3)$ ，
> >
> > 综上， $2 \leq \frac{3x^{2} + 2x + 2}{x^{2} + x + 1} \leq \frac{10}{3}$
> >
> > 所以对 $x \in \mathbb{R}$ 恒有 $\frac{3x^2 + 2x + 2}{x^2 + x + 1} > n$ ，只需 $_{n < 2}$ ，即 $n \in (-\infty, 2)$ .
> >
> > 故答案为： $(-\infty ,2)$
