> [!faq]- 《专题03_利用基本不等式巧解最值_八大题型__高效培优期末专项训练_高》官方解析
>
> > [!success]- **【答案】** A. $ab$ 的最大值为 $\frac{1}{4}$ B. $a^2 + 2b^2$ 的最小值为 $\frac{3}{4}$ C. $\frac{2}{a} + \frac{1}{ab}$ 的最小值为 $\frac{9}{2}$ D. $\sqrt{a} + 2\sqrt{b}$ 的最大值为 $\sqrt{5}$
>
> > [!note]- **【分析】**
> > 利用基本不等式及“1”的妙用求出最小值判断 $^{AC}$ ；利用二次函数求出最小值判断 $^{B}$ ；利用一元二次方程判别式求出最大值判断 $^{D}$ .
>
> > [!note]- **【解析】**
> > 对于 $^{A}$ ，由a>0,b>0, $a+b=1$ ，得 $ab\leq(\frac{a+b}{2})^{2}=\frac{1}{4}$ ，当且仅当 $a=b=\frac{1}{2}$ 时取等号， $^{A}$ 正确；
> > 对于 $^{B}$ ，由a>0,b>0,a+b=1，得a=1-b,0<b<1
> >
> > 则 $a^2 + 2b^2 = (1 - b)^2 + 2b^2 = 3b^2 - 2b + 1 = 3(b - \frac{1}{3})^2 + \frac{2}{3}$ ，当且仅当 $b = \frac{1}{3}$ 时取等号，B 错误；
> >
> > 对于 C，因为 a > 0, b > 0, $a + b = 1$
> >
> > $$
> > \frac {2}{a} + \frac {1}{a b} = \frac {2}{a} + \frac {a + b}{a b} = \frac {3}{a} + \frac {1}{b} = (a + b) (\frac {3}{a} + \frac {1}{b}) = 4 + \frac {3 b}{a} + \frac {a}{b} \quad 4 + 2 \sqrt {\frac {3 b}{a} \cdot \frac {a}{b}} = 4 + 2 \sqrt {3}
> > $$
> >
> > 当且仅当 $\frac{3b}{a} = \frac{a}{b}$ ，即 $a = \sqrt{3} b = \frac{3 - \sqrt{3}}{2}$ 时取等号，C错误；
> >
> > 对于D，令 $\sqrt{a} + 2\sqrt{b} = t$ ，则 $\sqrt{a} = t - 2\sqrt{b}$ ，而 $a + b = 1$ ，于是 $(t - 2\sqrt{b})^2 + b = 1$
> >
> > 由关于 $\sqrt{b}$ 的一元二次方程 $5(\sqrt{b})^2 - 4t\sqrt{b} + t^2 - 1 = 0$ 有解，得 $\Delta = 16t^2 - 20(t^2 - 1) - 0$
> >
> > 解得 $t^2 \leq 5$ ，则 $-\sqrt{5} \leq t \leq \sqrt{5}$
> >
> > 即 $\sqrt{a} + 2\sqrt{b}$ 取得最大值 $\sqrt{5}$ ，此时 $a = \frac{1}{5}, b = \frac{4}{5}$ ，D 正确。
> >
> > 故选 **AD**
