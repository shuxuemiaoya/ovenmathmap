> [!faq]- 《专题03_利用基本不等式巧解最值_八大题型__高效培优期末专项训练_高》官方解析
>
> > [!success]- **【答案】** ACD
>
> > [!note]- **【分析】**
> > 利用基本不等式可判断 A；令 a-b=m，可得关于 b 的方程 $b^{2}+mb+m^{2}-3=0$ 有实根，结合判别式 $\Delta=m^{2}-4(m^{2}-3)\quad0$ ，求出 m 的范围，可判断 B；根据关于 a 的方程 $a^{2}-\sqrt{2}ab+b^{2}-3=0$ 有实数根，结合判别式可判断 C；将 $a^{2}-tab+b^{2}=3$ 变形为 $(a+b)^{2}-(t+2)ab=3$ ，讨论 $t+2$ 的符号，结合基本不等式可判断 D.
>
> > [!note]- **【解析】**
> > 若 t = -1 ，则 $a^{2} + ab + b^{2} = 3$ 3ab ，所以 $ab \leq 1$
> >
> > 当且仅当 $a = b = 1$ 或 $a = b = -1$ 时，等号成立，A正确；
> >
> > 若 $t = 1$ ，则 $a^2 - ab + b^2 = 3$ ，令 $a - b = m$ ，所以 $(b + m)^2 - (b + m)b + b^2 = 3$
> >
> > 所以关于 $b$ 的方程 $b^{2} + mb + m^{2} - 3 = 0$ 有实根，
> >
> > 所以 $\Delta = m^2 - 4(m^2 - 3) = 0$ ，解得 $m^2 \leq 4$ ，所以 $|a - b| \leq 2$ ，B 错误；
> >
> > 若 $t = \sqrt{2}$ ，则关于 $a$ 的方程 $a^2 -\sqrt{2} ab + b^2 -3 = 0$ 有实数根，
> >
> > 所以 $\Delta^{\prime}=(-\sqrt{2}b)^{2}-4(b^{2}-3)$ 0 ，解得 $-\sqrt{6}\leq b\leq\sqrt{6}$ ，C 正确；
> >
> > $a^2 - tab + b^2 = (a + b)^2 - (t + 2)ab = 3$ ，当 $t + 2 = 0$ ，即 $t = -2$ 时，则 $\left|a + b\right|$ 存在最大值且最大值为 $\sqrt{3}$ ；
> >
> > 当 $t + 2 > 0$ ，即 $t > -2$ 时， $(a + b)^{2} = (t + 2)ab + 3\leq \frac{(t + 2)(a + b)^{2}}{4} +3$
> >
> > 所以 $\left(2 - t\right)(a + b)^{2} \leq 12$ ，当且仅当 $a = b$ 时，等号成立，
> >
> > 当 $2 - t > 0$ 时， $\left|a + b\right| \leq \sqrt{\frac{12}{2 - t}}$ ，所以当 $-2 < t < 2$ 时， $\left|a + b\right|$ 存在最大值，最大值为 $\sqrt{\frac{12}{2 - t}}$
> >
> > 当 $2 - t \leq 0$ 时， $\left(2 - t\right)(a + b)^2 \leq 0 \leq 12, \left|a + b\right|$ 不存在最大值；
> >
> > 当 $t + 2 < 0$ ，即 $t < -2$ 时， $(a + b)^{2} = (t + 2)ab + 3\frac{(t + 2)(a + b)^{2}}{4} +3$
> >
> > 所以 $(2 - t)(a + b)^{2}$ 12，当且仅当 $a = b$ 时，等号成立，此时 $\left|a + b\right|\sqrt{\frac{12}{2 - t}}$ ，此时 $\left|a + b\right|$ 不存在最大值
> >
> > 综上，若 $\left|a+b\right|$ 存在最大值，则 $-2\leq t<2$ ，D正确·
> >
> > 故选 **ACD**.
