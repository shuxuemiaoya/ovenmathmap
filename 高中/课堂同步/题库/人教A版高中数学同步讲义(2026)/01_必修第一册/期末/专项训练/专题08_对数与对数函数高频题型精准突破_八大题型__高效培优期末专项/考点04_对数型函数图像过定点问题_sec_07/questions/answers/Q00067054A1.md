> [!faq]- 《专题08_对数与对数函数高频题型精准突破_八大题型__高效培优期末专项》官方解析
>
> > [!success]- **【答案】** A. $f(x)$ 的图象过定点(1,1) B. $f(mn) = f(m) + f(n)$ C. $f(\frac{m}{n}) > f(m) - f(n)$ D. $f(\frac{m+n}{2}) \leq \frac{f(m) + f(n)}{2}$
>
> > [!note]- **【分析】**
> > 令 $x = 1$ 时，得到 $f(1) = 1$ ，可判定 $\mathsf{A}$ 正确；令 $a = 2, m = 2, n = 4$ ，求得 $f(m) = 2$ ， $f(n) = 3$ 和 $f(mn) = 4$ ，可判定 $\mathsf{B}$ 错误；根据对数的运算性质，可判定 $\mathsf{C}$ 正确；令 $a = \mathrm{e}, m = \mathrm{e}^2, n = \mathrm{e}^4$ ，求得 $\frac{f(m) + f(n)}{2} = 4$ ，由 $\mathrm{e}^2 + 1 > 2\mathrm{e}$ ，得到 $\ln (\frac{\mathrm{e}^2 + 1}{2}) > \ln \mathrm{e} = 1$ ，求得 $f(\frac{m + n}{2}) > 4$ ，可判定 $\mathsf{D}$ 错误。【详解】对于 $\mathsf{A}$ ，由函数 $f(x) = \log_a(ax)$ ，当 $x = 1$ 时， $f(1) = \log_a a = 1$ 所以 $f(x)$ 的图象过定点 $(1,1)$ ，所以 $\mathsf{A}$ 正确；
> > 对于 $\mathsf{B}$ ，令 $a = 2, m = 2, n = 4$ ，此时 $f(x) = \log_2(2x)$ ，
> > 可得 $f(m) = f(2) = \log_2(2\times 2) = \log_24 = 2$ ， $f(n) = f(4) = \log_2(2\times 4) = \log_28 = 3$ ， $f(mn) = f(2\times 4) = \log_2(2\times 8) = \log_216 = 4$ 此时不满足 $f(mn) = f(m) + f(n)$ ，所以 $\mathsf{B}$ 错误；
> > 对于 $\mathsf{C}$ ，由 $f(\frac{m}{n}) = \log_a(a\times \frac{m}{n}) = \log_a a + \log_a(\frac{m}{n}) = 1 + \log_a(\frac{m}{n})$ 又由 $f(m) - f(n) = \log_a(am) - \log_a(an) = \log_a(\frac{am}{an}) = \log_a(\frac{m}{n})$ 因为 $1 + \log_a(\frac{m}{n}) > \log_a(\frac{m}{n})$ ，所以 $f(\frac{m}{n}) > f(m) - f(n)$ ，所以 $\mathsf{C}$ 正确；
> > 对于 $\mathsf{D}$ ，令 $a = \mathrm{e}, m = \mathrm{e}^2, n = \mathrm{e}^4$ ，可得 $f(x) = \ln (\mathrm{e}x) = \ln \mathrm{e} + \ln x = 1 + \ln x$ 此时 $f(m) = f(\mathrm{e}^2) = 1 + \ln \mathrm{e}^2 = 1 + 2 = 3$ ， $f(n) = f(\mathrm{e}^4) = 1 + \ln \mathrm{e}^4 = 1 + 4 = 5$ 所以 $\frac{f(m) + f(n)}{2} = \frac{5 + 3}{2} = 4$ ，而 $(\mathrm{e} - 1)^2 >0$ ，故 $\mathrm{e}^2 - 2\mathrm{e} + 1 >0$
> >
> > A
> >
> > 得到 $\mathrm{e}^2 + 1 > 2\mathrm{e}$ ，即 $\frac{\mathrm{e}^2 + 1}{2} > \mathrm{e}$ ，可得 $\ln \left(\frac{\mathrm{e}^2 + 1}{2}\right) > \ln \mathrm{e} = 1$
> >
> > 又由 $f\left(\frac{m + n}{2}\right) = f\left(\frac{\mathrm{e}^2 + \mathrm{e}^4}{2}\right) = 1 + \ln \left(\frac{\mathrm{e}^2 + \mathrm{e}^4}{2}\right) = 1 + \ln \left[\mathrm{e}^2\left(\frac{\mathrm{e}^2 + 1}{2}\right)\right] = 1 + \ln \mathrm{e}^2 + \ln \left(\frac{\mathrm{e}^2 + 1}{2}\right)$
> >
> > $$
> > = 1 + 2 + \ln (\frac {\mathrm{e} ^ {2} + 1}{2}) = 3 + \ln (\frac {\mathrm{e} ^ {2} + 1}{2}) > 3 + 1 = 4
> > $$
> >
> > 此时不满足 $f\left(\frac{m + n}{2}\right) \leq \frac{f(m) + f(n)}{2}$ ，所以D错误
> >
> > 故选：AC.

> > 26. 函数 $f(x) = \log_a (2^x - m) + n (a > 0$ ，且 $a \neq 1$ 恒过点(1,2)，则 $2m - n = (\quad)$ A. 0 B. 1 C. 2 D. 4
> >
> > 【答案】A
> >
> > 【分析】根据给定条件，结合对数函数图象恒过的点列式求解·
>
> > [!note]- **【解析】**
> > 由函数 $f(x)=\log_{a}(2^{x}-m)+n$ 的图象恒过点 (1,2)，得 $\left\{\begin{aligned}2-m=1\\ n=2\end{aligned}\right.$ ，解得 m=1, n=2，所以 2m-n=0。
> >
> > 故选 **A**
