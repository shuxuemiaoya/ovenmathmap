> [!faq]- 《专题08_对数与对数函数高频题型精准突破_八大题型__高效培优期末专项》官方解析
>
> > [!success]- **【答案】** (1)证明见解析； (2) $(-∞,-\frac{1}{2})$ ; (3) $\left[1,\frac{31}{8}\right]$ .
>
> > [!note]- **【分析】**
> > （1）把 $m = 1$ 代入，求出 $g(x)$ ，再利用偶函数定义推理得证
> >
> > (2) 根据对数函数的单调性结合定义域列出不等式组即可求解.
> >
> > (3) 分离常数后利用复合函数的单调性求得函数的最值即可求解.
>
> > [!note]- **【解析】**
> > （1）当 $m = 1$ 时，函数 $f(x) = \log_2(x + 1)$ ，则 $g(x) = f(2^x) - \frac{1}{2} x = \log_2(2^x + 1) - \frac{1}{2} x$
> >
> > 函数 $g(x)$ 定义域为 $\mathbb{R}$ ， $g(-x) - g(x) = \log_2(2^{-x} + 1) + \frac{1}{2} x - \log_2(2^x + 1) + \frac{1}{2} x$
> >
> > $$
> > = \log_ {2} \frac {2 ^ {- x} + 1}{2 ^ {x} + 1} + x = \log_ {2} 2 ^ {- x} + x = - x + x = 0
> > $$
> >
> > 所以函数 $g(x)$ 是偶函数·
> >
> > (2) 当 $m = 2$ 时， $f(x) = \log_2(x + 2)$ ，不等式 $f\left(\frac{1}{x}\right) < 1 \Leftrightarrow \log_2\left(\frac{1}{x} + 2\right) < 1$
> >
> > 则 $\left\{ \begin{array}{l} \frac{1}{x} + 2 > 0 \\ \frac{1}{x} + 2 < 2 \end{array} \right.$ ，由 $\frac{1}{x} + 2 > 0$ 或 $x > 0$ ，由 $\frac{1}{x} + 2 < 2$ ，因此 $x < -\frac{1}{2}$ ，
> >
> > 所以原不等式的解集为 $(-∞,-\frac{1}{2})$ .
> >
> > (3) 当 $m = 10$ 时， $f(x) = \log_2(x + 10)$ ，方程 $f(x) = (\frac{1}{\sqrt{2}})^x + \lambda \Leftrightarrow \log_2(x + 10) = (\frac{1}{\sqrt{2}})^x + \lambda$
> >
> > $$
> > \lambda = \log_ {2} (x + 1 0) - (\frac {1}{\sqrt {2}}) ^ {x}
> > $$
> >
> > $$
> > y = \log_ {2} (x + 1 0)
> > $$
> >
> > $$
> > y = - \left(\frac {1}{\sqrt {2}}\right) ^ {x}
> > $$
> >
> > $$
> > [ - 2, 6 ]
> > $$
> >
> > 因此函数 $\lambda = \log_2(x + 10) - (\frac{1}{\sqrt{2}})^x$ 在[-2,6]上单调递增，
> >
> > 则当 $x = -2$ 时， $\lambda_{\mathrm{min}} = 1$ ；当 $x = 6$ 时， $\lambda_{\mathrm{max}} = \frac{31}{8}$
> >
> > 所以实数 $\lambda$ 的取值范围是 $[1, \frac{31}{8}]$
