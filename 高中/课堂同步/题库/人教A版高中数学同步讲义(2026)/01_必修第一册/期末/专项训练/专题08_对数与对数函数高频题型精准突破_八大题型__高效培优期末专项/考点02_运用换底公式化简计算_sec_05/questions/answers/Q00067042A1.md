> [!faq]- 《专题08_对数与对数函数高频题型精准突破_八大题型__高效培优期末专项》官方解析
>
> > [!success]- **【答案】** 15
>
> > [!note]- **【分析】**
> > 利用指数式与对数式的互化关系，结合指数运算计算得解·
>
> > [!note]- **【解析】**
> > 由 $\log_25 = n$ ，得 $2^{n} = 5$ ，而 $2^{m} = 3$
> >
> > 所以 $2^{m+n}=2^{m}\cdot2^{n}=3\times5=15$ .
> >
> > 故答案为：15
> >
> > 9. 计算： $\left(\frac{81}{16}\right)^{-\frac{1}{4}} + \log_{2}3 \times \log_{3}4 + 7^{\log_{7}\frac{1}{3}} =$ \_\_\_\_.
> >
> > 【答案】3
> >
> > 【分析】利用指数、对数的运算性质及换底公式化简计算即可.
> >
> > 【详解】原式 $= \left[\left(\frac{3}{2}\right)^4\right]^{-\frac{1}{4}} + \frac{\lg 3}{\lg 2} \times \frac{2\lg 2}{\lg 3} + \frac{1}{3} = \left(\frac{3}{2}\right)^{4 \times \left(-\frac{1}{4}\right)} + 2 + \frac{1}{3} = \frac{2}{3} + 2 + \frac{1}{3} = 3$
> >
> > 故答案为：3.
> >
> > 10. 计算
> >
> > (1)求 $27^{\frac{2}{3}}+\sqrt{(\pi-4)^{2}}+\log_{2}(4^{7}\cdot2^{\pi})$ 的值；
> >
> > (2)已知 $a^{\frac{1}{2}} + a^{-\frac{1}{2}} = 3$ ，求 $\frac{a^2 + a^{-2} - 7}{a + a^{-1} + 3}$ 的值；
> >
> > (3)已知 $b\log_34 = 1,2^c = 6$ ，求 $2b - c$ 的值.
> >
> > 【答案】(1)27
> >
> > (2)4
> >
> > (3)-1
> >
> > 【分析】（ $^{1}$ ）根据指数与对数的运算法则进行求解即可；
> >
> > (2) 由 $a^{\frac{1}{2}} + a^{-\frac{1}{2}} = 3$ 通过两边同时平方可得 $a + a^{-1} = 7$ ，同理可以求解 $a^2 + a^{-2} = 47$ ；
> >
> > (3) 根据指数与对数的相互转化再结合对数的运算法则进行求解即可.
> >
> > 【详解】（1） $27^{\frac{2}{3}}+\sqrt{(\pi-4)^{2}}+\log_{2}(4^{7}\cdot2^{\pi})$ $=9+4-\pi+\log_{2}(4^{7})+\log_{2}(2^{\pi})$ $=13-\pi+14+\pi$ =27
> >
> > (2) 因为 $a^{\frac{1}{2}} + a^{-\frac{1}{2}} = 3$ ,
> >
> > 所以 $\left(a^{\frac{1}{2}} + a^{-\frac{1}{2}}\right)^2 = a + a^{-1} + 2 = 9$ ，即 $a + a^{-1} = 7$
> >
> > 所以 $\left(a+a^{-1}\right)^{2}=a^{2}+a^{-2}+2=49$ ，即 $a^{2}+a^{-2}=47$ ，
> >
> > 故 $\frac{a^2 + a^{-2} - 7}{a + a^{-1} + 3} = \frac{47 - 7}{7 + 3} = 4$
> >
> > (3) 已知 $b \log_{3} 4 = 1, 2^{c} = 6$
> >
> > 依题意得 $b=\frac{1}{\log_{3}4}=\log_{4}3$ ， $c=\log_{2}6$
> >
> > 所以 $2b - c = 2 \log_{4} 3 - \log_{2} 6 = \log_{2} 3 - \log_{2} 6 = \log_{2} \frac{1}{2} = -1$ .
