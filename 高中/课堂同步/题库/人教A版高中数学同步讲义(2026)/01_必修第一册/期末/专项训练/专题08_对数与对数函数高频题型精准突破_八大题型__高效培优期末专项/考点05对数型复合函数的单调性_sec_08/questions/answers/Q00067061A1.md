> [!faq]- 《专题08_对数与对数函数高频题型精准突破_八大题型__高效培优期末专项》官方解析
>
> > [!success]- **【答案】** (1) $\left(\frac{1}{2},2\right)$ (2) $(0, \frac{\sqrt{11}}{4}] \cup [\frac{3}{2}, +\infty)$
>
> > [!note]- **【分析】**
> > （ $^{1}$ ）求出函数定义域，再利用对数函数、二次函数单调性求出递减区间·
> >
> > (2) 按 $a > 1, 0 < a < 1$ 分类求出函数 $f(x)$ 在指定区间上的最大值，再建立不等式求解即得
>
> > [!note]- **【解析】**
> > （1）函数 $f(x) = \log_a(2 - x) + \log_a(x + 1)$ 有意义，则 $\left\{ \begin{array}{l} 2 - x > 0 \\ x + 1 > 0 \end{array} \right.$ ，解得 $-1 < x < 2$ ，
> >
> > 此时 $f(x) = \log_a[(2 - x)(x + 1)] = \log_a(-x^2 + x + 2)$ ，令 $t = -x^2 + x + 2$
> >
> > 函数 $t = -x^{2} + x + 2$ 在 $(-1, \frac{1}{2})$ 上单调递增，在 $(\frac{1}{2}, 2)$ 上单调递减，
> >
> > 而当 $a > 1$ 时，函数 $y = \log_a t$ 在 $(0, +\infty)$ 上单调递增，
> >
> > 所以函数 $f(x)$ 的单调递减区间是 $\left(\frac{1}{2},2\right)$ .
> >
> > (2) 由 (1) 得，当 $a > 1$ 时，函数 $f(x)$ 在 $\left[\frac{1}{2}, \frac{7}{4}\right]$ 上单调递减， $f(x)_{\max} = f\left(\frac{1}{2}\right) = \log_a \frac{9}{4}$ 依题意， $\log_a \frac{9}{4} \leq 2 \Leftrightarrow \log_a \frac{9}{4} \leq \log_a a^2 \Leftrightarrow a^2 - \frac{9}{4}$ ，解得 $a = \frac{3}{2}$ ；当 $0 < a < 1$ 时，函数 $f(x)$ 在 $[\frac{1}{2}, \frac{7}{4}]$ 上单调递增， $f(x)_{\max} = f(\frac{7}{4}) = \log_a \frac{11}{16}$ ，依题意， $\log_a \frac{11}{16} \leq 2 \Leftrightarrow \log_a \frac{11}{16} \leq \log_a a^2 \Leftrightarrow 0 < a^2 \leq \frac{11}{16}$ ，解得 $0 < a \leq \frac{\sqrt{11}}{4}$ ，所以 $a$ 的取值范围是 $(0, \frac{\sqrt{11}}{4}] \cup [\frac{3}{2}, +\infty)$ .
