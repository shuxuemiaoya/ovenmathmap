> [!faq]- 《专题08_对数与对数函数高频题型精准突破_八大题型__高效培优期末专项》官方解析
>
> > [!success]- **【答案】** ABD
>
> > [!note]- **【分析】**
> > $^{A}$ 利用偶函数的定义； $^{B}$ 利用复合函数的单调性求出 $f(x)$ 在 $(0,+\infty)$ 上的单调性，再利用对称性即可； $^{C}$ 先求出当 x>0 时， $0<1-\frac{2}{2^{x}+1}<1$ 即可得出 $f(x)$ 的范围，再结合对称性即可； $^{D}$ 利用 $f(1)=\log_{2}\frac{1}{3}$ 以及对称性和单调性即可。
>
> > [!note]- **【解析】**
> > 对于 A 选项，函数 $f(x)$ 的定义域为 $(-∞,0)∪(0,+∞)$
> >
> > 由 $f(x) = \log_2\frac{|2^x - 1|}{2^x + 1}$ ，有 $f(-x) = \log_2\frac{|2^{-x} - 1|}{2^{-x} + 1} = \log_2\frac{|2^x - 1|}{2^x + 1} = f(x)$ ，
> >
> > 可得函数 $f(x)$ 为偶函数，故 A 选项正确；
> >
> > 对于 B 选项，当 x > 0 时， $f(x) = \log_{2} \frac{2^{x} - 1}{2^{x} + 1} = \log_{2} \frac{2^{x} + 1 - 2}{2^{x} + 1} = \log_{2} \left(1 - \frac{2}{2^{x} + 1}\right)$
> >
> > 由函数 $y = 1 - \frac{2}{2^x + 1}$ 在 $(0, +\infty)$ 上单调递增， $y = \log_2 x$ 在 $(0, +\infty)$ 上单调递增，可得函数 $f(x)$ 在 $(0, +\infty)$ 上单调递增（复合函数的单调性），
> >
> > 又由函数 $f(x)$ 为偶函数，可得函数 $f(x)$ 的增区间为 $(0, +\infty)$ ，减区间为 $(- \infty, 0)$ ，故 ${}^{\mathsf{B}}$ 选项正确；
> >
> > 对于 $^{C}$ 选项，当x>0时，由 $2^{x}+1>2$ ，得 $0<\frac{2}{2^{x}+1}<1$ ，有 $0<1-\frac{2}{2^{x}+1}<1$ ，
> >
> > 可得 $\log_2\left(1 - \frac{2}{2^x + 1}\right)\in (-\infty ,0)$
> >
> > 又由函数 $f(x)$ 为偶函数，可得函数 $f(x)$ 的值域为 $(-\infty,0)$ ，故 C 选项错误；
> >
> > 对于 $\mathbf{D}$ 选项，由 $f(1) = \log_2\frac{1}{3}$ 及函数 $f(x)$ 是偶函数，
> >
> > 且函数 $f(x)$ 的增区间为 $(0, +\infty)$ ，减区间为 $(- \infty, 0)$
> >
> > $f(a) > \log_{2}\frac{1}{3}$ ，可得 $a\in (-\infty , - 1)\cup (1, + \infty)$ ，故D选项正确.
> >
> > 故选：ABD.

> > 23. 函数 $f(x) = \log_{\frac{1}{3}} (x^2 - 6x + 18)$ 的值域为（）
> >
> > 【答案】
> > A. $(- \infty, -2)$ B. $(-2, +\infty)$ C. $(- \infty, -2]$ D. $[-2, +\infty)$
> >
> > 【答案】C
> >
> > 【分析】利用二次函数性质以及复合函数单调性判断出 $f(x)$ 的单调区间，代入计算即可求得结果。
> > 【详解】依题意可知 $x^{2}-6x+18>0$ ，解得 $x\in R$ ；
> >
> > 易知函数 $f(x)$ 的定义域为R；
> >
> > 又 $f(x) = \log_{\frac{1}{3}}(x^2 - 6x + 18)$ 是由函数 $y = \log_{\frac{1}{3}}u$ 和 $u = x^2 - 6x + 18$ 复合而成的，
> >
> > 由对数函数单调性可知 $y = \log_{\frac{1}{3}}u$ 在定义域内单调递减，
> >
> > 而二次函数 $u = x^{2} - 6x + 18$ 开口向上，关于 $x = 3$ 对称，
> >
> > 因此 $u = x^{2} - 6x + 18$ 在 $(3, +\infty)$ 上单调递增，在 $(- \infty, 3)$ 上单调递减；
> >
> > 由复合函数单调性可知 $f(x)$ 在 $(3, +\infty)$ 上单调递减，在 $(- \infty, 3)$ 上单调递增；
> >
> > 因此 $f(x)$ 在 $x = 3$ 处取得最大值，即 $f(3) = \log_{\frac{1}{3}}(3^2 - 6 \times 3 + 18) = -2$
> >
> > 可得 $f(x)$ 的值域为 $(-∞,-2]$ .
> >
> > 故选 **C**
