> [!faq]- 《专题08_对数与对数函数高频题型精准突破_八大题型__高效培优期末专项》官方解析
>
> > [!success]- **【答案】** (1)奇函数，证明见解析 (2) $f(x)$ 在 $(-1, 1)$ 上单调递减，证明见解析 (3) $m = 1$ 或 $m = 2$
>
> > [!note]- **【分析】**
> > （1）利用奇偶性的定义结合对数的运算证明即可；
> >
> > (2) 利用单调性的定义任取 $x_{1}, x_{2}$ 满足 $-1 < x_{1} < x_{2} < 1$ ，结合对数的运算判断 $f(x_{1}) - f(x_{2})$ 的符号证明即可；
> >
> > (3) 由 $f(x)$ 在 $x \in \left[-\frac{2}{5}, \frac{3}{5}\right]$ 上的单调性求出 $|f(x)|$ 的最值，解不等式即可.
>
> > [!note]- **【解析】**
> > （1）函数 $f(x)$ 是奇函数，证明如下：
> >
> > $f(x) = \log_2(1 - x) - \log_2(1 + x)$ ，所以 $\left\{ \begin{array}{l} 1 - x > 0 \\ 1 + x > 0 \end{array} \right.$ ，解得函数定义域 $D = \{x \mid -1 < x < 1\}$ ，
> >
> > 因为任意 $x \in D$ ，都有 $-x \in D$ ，
> >
> > 又 $f(-x) = \log_2(1 + x) - \log_2(1 - x) = -f(x)$ ，所以函数 $f(x)$ 是奇函数。
> >
> > (2) $f(x)$ 在 $(-1, 1)$ 上单调递减，证明如下：
> >
> > 法一：任取 $x_{1}, x_{2}$ 满足 $-1 < x_{1} < x_{2} < 1$
> >
> > 因为 $f(x_{1}) - f(x_{2}) = \log_{2}(1 - x_{1}) - \log_{2}(1 + x_{1}) - [\log_{2}(1 - x_{2}) - \log_{2}(1 + x_{2})]$
> >
> > $$
> > = \left[ \log_ {2} \left(1 - x _ {1}\right) - \log_ {2} \left(1 - x _ {2}\right) \right] + \left[ \log_ {2} \left(1 + x _ {2}\right) - \log_ {2} \left(1 + x _ {1}\right) \right]
> > $$
> >
> > 因为 $1 - x_{1} > 1 - x_{2} > 0$ ， $1 + x_{2} > 1 + x_{1} > 0$ ，且 $y = \log_2x$ 单调递增，
> >
> > 所以 $\log_{2}(1-x_{1})>\log_{2}(1-x_{2})$ ， $\log_{2}(1+x_{2})>\log_{2}(1+x_{1})$
> >
> > 依据同向不等式的可加性，
> >
> > 所以 $\left[\log_2\left(1 - x_1\right) - \log_2\left(1 - x_2\right)\right] + \left[\log_2\left(1 + x_2\right) - \log_2\left(1 + x_1\right)\right] > 0$
> >
> > 即 $f(x_{1}) > f(x_{2})$ ，所以 $f(x)$ 在 $(-1, 1)$ 上单调递减。
> >
> > 法二：任取 $x_{1}$ ， $x_{2}$ 满足 $-1 < x_{1} < x_{2} < 1$ ，因为 $f(x) = \log_{2} \frac{1 - x}{1 + x}$ ，
> >
> > 所以 $f(x_{1}) - f(x_{2}) = \log_{2}\frac{(1 - x_{1})}{(1 + x_{1})} -\log_{2}\frac{(1 - x_{2})}{(1 + x_{2})} = \log_{2}\frac{(1 - x_{1})(1 + x_{2})}{(1 + x_{1})(1 - x_{2})},$
> >
> > 因为 $\left(1 - x_{1}\right)\left(1 + x_{2}\right) = 1 + x_{2} - x_{1} - x_{1}x_{2}$ ， $\left(1 + x_{1}\right)\left(1 - x_{2}\right) = 1 + x_{1} - x_{2} - x_{1}x_{2}$
> >
> > 所以 $\left(1 - x_{1}\right)\left(1 + x_{2}\right) > \left(1 + x_{1}\right)\left(1 - x_{2}\right) > 0$ ，即 $\frac{\left(1 - x_1\right)\left(1 + x_2\right)}{\left(1 + x_1\right)\left(1 - x_2\right)} > 1$
> >
> > 所以 $f(x_{1}) - f(x_{2}) > 0$ ，即 $f(x_{1}) > f(x_{2})$ ，所以 $f(x)$ 在 $(-1,1)$ 上单调递减.
> >
> > (3) 由第 (2) 问知 $f(x)$ 在 $\left[-\frac{2}{5}, \frac{3}{5}\right]$ 上单调递减，
> >
> > 所以 $\log_2\frac{7}{3} = f\left(-\frac{2}{5}\right)\quad f(x)\quad f\left(\frac{3}{5}\right) = \log_2\frac{1}{4} = -2$
> >
> > 因为 $\log_{2}\frac{7}{3}<\log_{2}4=2$
> >
> > 所以 $\left|f(x)\right|_{\max} = \max \left\{\left|f\left(\frac{3}{5}\right)\right|\left|f\left(-\frac{2}{5}\right)\right|\right\} = 2$
> >
> > 所以 $2 \leq 3m - m^2$ ，即得 $m^2 - 3m + 2 = (m - 2)(m - 1) \leq 0$ ，解得 $1 \leq m \leq 2$ ，因为 $m \in \mathbf{Z}$ ，所以 $m = 1$ 或 $m = 2$ 。
