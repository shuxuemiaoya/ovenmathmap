> [!faq]- 《专题04_一元二次不等式高频题型精准突破_八大题型__高效培优期末专项》官方解析
>
> > [!success]- **【答案】** $(-∞,-2]$
>
> > [!note]- **【分析】**
> > 首先求出命题 p 、 q 为真时参数的取值范围，依题意可知 p 、 q 真假性相反，再分类讨论，分别计算可得·
>
> > [!note]- **【解析】**
> > 若命题 $p: x^{2} - 2x + a = 0$ 在 R 上恒成立，为真命题，
> >
> > 则 $\Delta = (-2)^{2} - 4a\leq 0$ ，解得 $a = 1$
> >
> > 若命题 $q: \exists x_{0} \in R$ ， $x_{0}^{2} + 2ax_{0} + 2 - a = 0$ ，为真命题，
> >
> > 则 $\Delta=(2a)^{2}-4(2-a)$ 0，解得 a 1 或 $a \leq -2$ ；
> >
> > 因为 p 或 q 为真，p 且 q 为假，
> >
> > 所以 $p$ 与 $q$ 一个为真一个为假，
> >
> > 若 p 为真命题，即 a 1，此时 q 也为真命题，故舍去，
> >
> > 若 q 为真命题、p 为假命题，则 $a \leq -2$ ，
> >
> > 综上可得实数 a 的取值范围为 $(-∞, -2]$ .
> >
> > 考点 06 一元二次不等式在实数上恒成立问题
> >
> > 41. “ $0 < m < \frac{12}{5}$ ”是“不等式 $mx^{2} + 3mx + m + 3 > 0$ 对一切实数 x 恒成立”的（）
> >
> > 【答案】
> > A．充分非必要条件
> > B．必要非充分条件
> > C．充要条件
> > D．既非充分又非必要条件
> >
> > 【答案】A
> >
> > 【分析】根据一元二次不等式的恒成立问题求实数 m 的取值范围，结合集合的包含关系分析充分、必要条件.
> >
> > 【详解】若不等式 $mx^{2} + 3mx + m + 3 > 0$ 对一切实数 x 恒成立，
> >
> > 当 m = 0 时，可得 3 > 0，符合题意；
> >
> > 当 $m \neq 0$ 时，可得 $\left\{\begin{aligned}m &>0\\ 9m^{2} &-4m(m+3)<0\end{aligned}\right.$ ，解得 $0 < m < \frac{12}{5}$ ；
> >
> > 综上所述：实数 m 的取值范围为 $\left\{m \mid 0 \leq m < \frac{12}{5}\right\}$ ，
> >
> > 因为集合 $\left\{m \mid 0 < m < \frac{12}{5}\right\}$ 是集合 $\left\{m \mid 0 \leq m < \frac{12}{5}\right\}$ 的真子集，
> >
> > 所以 “ $0 < m < \frac{12}{5}$ ” 是“不等式 $mx^{2} + 3mx + m + 3 > 0$ 对一切实数 x 恒成立”的充分非必要条件，故 A 正确。
> >
> > 故选 **A**.
