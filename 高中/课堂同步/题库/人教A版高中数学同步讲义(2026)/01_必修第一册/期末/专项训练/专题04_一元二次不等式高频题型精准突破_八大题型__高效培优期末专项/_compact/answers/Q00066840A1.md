> [!faq]- 《专题04_一元二次不等式高频题型精准突破_八大题型__高效培优期末专项》官方解析
>
> > [!success]- **【答案】** D
>
> > [!note]- **【分析】**
> > 由题意得 $(x - 2)(x - 2m) \leq 0$ ，根据 $m$ 的范围，分类讨论，求出不等式的解集，再结合已知列出不等式求解得答案：
>
> > [!note]- **【解析】**
> > 不等式 $x^{2} - 2(m + 1)x + 4m\leq 0\Leftrightarrow (x - 2)(x - 2m)\leq 0$
> >
> > 当 $m < 1$ 时，原不等式的解集为 $\{x \mid 2m \leq x \leq 2\}$
> >
> > 由解集中恰有 $^{4}$ 个整数，得 $-2 < 2m \leq -1$ ，解得 $-1 < m \leq -\frac{1}{2}$ ；
> >
> > 当 $m \quad 1$ 时，原不等式的解集为 $\{x \mid 2 \leq x \leq 2m\}$ ，由解集中恰有 $^{4}$ 个整数，得 $5 \leq 2m < 6$ ，解得 $\frac{5}{2} \leq m < 3$ ，所以实数 $m$ 的取值范围是 $-1 < m \leq -\frac{1}{2}$ 或 $\frac{5}{2} \leq m < 3$ 。
> >
> > 故选 **D**
