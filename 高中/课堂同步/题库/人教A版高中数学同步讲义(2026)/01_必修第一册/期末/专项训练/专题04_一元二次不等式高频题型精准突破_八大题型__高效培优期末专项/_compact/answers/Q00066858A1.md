> [!faq]- 《专题04_一元二次不等式高频题型精准突破_八大题型__高效培优期末专项》官方解析
>
> > [!success]- **【答案】** C
>
> > [!note]- **【分析】**
> > 由题意可得 $B \subseteq A$ ，进而转化问题为 $f(x) = x^2 + mx + n \leq 0$ 在 $x \in [1,2]$ 时恒成立，进而得到 $\left\{ \begin{array}{l} m + n \leq -1 \\ 2m + n \leq -4 \end{array} \right.$ ，进而根据不等式的基本性质求解即可。
>
> > [!note]- **【解析】**
> > 因为 $x \in A$ 是 $x \in B$ 的必要条件，所以 $B \subseteq A$ ，
> > 所以 $\forall x \in [1,2], x^2 + mx + n \leq 0$ 成立。
> > 令 $f(x) = x^2 + mx + n$ ，得 $f(x) = x^2 + mx + n \leq 0$ 在 $x \in [1,2]$ 时恒成立，
> > 所以 $\left\{ \begin{array}{l} f(1) \leq 0 \\ f(2) \leq 0 \end{array} \right.$ ，所以 $\left\{ \begin{array}{l} 1 + m + n \leq 0 \\ 4 + 2m + n \leq 0 \end{array} \right.$ ，则 $\left\{ \begin{array}{l} m + n \leq -1 \\ 2m + n \leq -4 \end{array} \right.$ ，又 $3m + 2n = (m + n) + (2m + n)$ ，所以 $3m + 2n \leq -5$ ，当且仅当 $m = -3, n = 2$ 时取等号，
> >
> > 所以 $3m + 2n$ 的最大值为 $-5$ .
> >
> > 故选 **C**.
