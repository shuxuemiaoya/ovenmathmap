> [!faq]- 《专题04_一元二次不等式高频题型精准突破_八大题型__高效培优期末专项》官方解析
>
> > [!success]- **【答案】** A．若 $a^2 > b^2, ab > 0$ ，则 $\frac{1}{a} < \frac{1}{b}$ B．若 $a > b, c < d$ ，则 $a - c > b - d$ C．若 $1 \leq a \leq 2, 2 \leq b \leq 3$ ，则 $\frac{a}{b}$ 的取值范围是 $\left[\frac{1}{3}, 1\right]$ D．已知关于 $x$ 的不等式 $ax + b > 0$ 的解集为 $(-3, +\infty)$ ，则关于 $x$ 的不等式 $ax^2 + bx < 0$ 的解集为 $(-3, 0)$
>
> > [!note]- **【分析】**
> > 利用作差法分析不等式判断 $^{A}$ ；利用同向不等式可加性判断 $^{B}$ ；利用同向正数不等式可乘性判断 $^{C}$ ；利用一元一次不等式的解集得到系数关系，再解一元二次不等式即可。
>
> > [!note]- **【解析】**
> > 由 $a^2 > b^2, ab > 0$ ，可得 $a > b > 0$ 或 $a < b < 0$ ，而 $\frac{1}{a} - \frac{1}{b} = \frac{b - a}{ab}$ 无法确定恒正或恒负，故 A 错误；由 $a > b, c < d$ 可得 $a > b, -c > -d$ ，根据同向不等式可加性有 $a - c > b - d$ ，故 B 正确；由 $1 \leq a \leq 2, 2 \leq b \leq 3$ 可得 $1 \leq a \leq 2, \frac{1}{3} \leq \frac{1}{b} \leq \frac{1}{2}$ ，根据同向正数不等式可乘性有 $\frac{1}{3} \leq \frac{a}{b} \leq 1$ ，故 C 正确；已知关于 $x$ 的不等式 $ax + b > 0$ 的解集为 $(-3, +\infty)$ ，可得 $a > 0, \frac{-b}{a} = -3$ ，即 $b = 3a$ ，则关于 $x$ 的不等式 $ax^2 + bx < 0$ 可化简为 $ax^2 + 3ax < 0 \Leftrightarrow x^2 + 3x < 0$ ，解得 $x \in (-3, 0)$ ，故 D 正确。
> >
> > 故选 **BCD**。
