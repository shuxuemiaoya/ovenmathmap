> [!faq]- 《专题04_一元二次不等式高频题型精准突破_八大题型__高效培优期末专项》官方解析
>
> > [!success]- **【答案】** B
>
> > [!note]- **【分析】**
> > 应用绝对值不等式及一元二次不等式化简，再结合充要条件定义判断求解
>
> > [!note]- **【解析】**
> > 不等式 $|x - 1| < 1$ 的解集为 $\{x \mid 0 < x < 2\}$ ，不等式 $x^2 - x = x(x - 1) < 0$ 的解集为 $\{x \mid 0 < x < 1\}$ ，而 $\{x \mid 0 < x < 1\}$ 是 $\{x \mid 0 < x < 2\}$ 的真子集，
> > 则 $\alpha$ 是 $\beta$ 的必要非充分条件·
> > 故选：B.
> >
> > 3. 不等式 $\left(\frac{1}{2} - x\right)\left(\frac{1}{3} - x\right) > 0$ 的解集是（ ）A. $\left\{x \mid \frac{1}{3} < x < \frac{1}{2}\right\}$ B. $\left\{x \mid x < \frac{1}{3} \text{或} x > \frac{1}{2}\right\}$ C. $\left\{x \mid x < \frac{1}{3}\right\}$ D. $\left\{x \mid x > \frac{1}{2}\right\}$
> >
> > 【答案】B
> >
> > 【分析】先将不等式 $\left(\frac{1}{2}-x\right)\left(\frac{1}{3}-x\right)>0$ 变形为 $\left(x-\frac{1}{2}\right)\left(x-\frac{1}{3}\right)>0$ ，再求出变形后的一元二次不等式的解，
> > 即可得解
> > 【详解】原不等式 $\left(\frac{1}{2}-x\right)\left(\frac{1}{3}-x\right)>0$ 可化为 $\left(x-\frac{1}{2}\right)\left(x-\frac{1}{3}\right)>0$ 解得 $x < \frac{1}{3}$ 或 $x > \frac{1}{2}$ ，
> > 所以不等式 $\left(\frac{1}{2}-x\right)\left(\frac{1}{3}-x\right)>0$ 的解集为 $\left\{x\mid x<\frac{1}{3}\text{或}x>\frac{1}{2}\right\}$ .
> >
> > 故选：B
> >
> > 4. 不等式 $\frac{3x - 1}{x - 2} \leq 0$ 的解集为（）
> >
> > 【答案】
> > A. $\left\{x \mid \frac{1}{3} \leq x \leq 2\right\}$ B. $\left\{x \mid \frac{1}{3} \leq x < 2\right\}$ C. $\{x \mid x < 2\}$ D. $\{x \mid x \leq \frac{1}{3}\text{或} x > 2\}$
> >
> > 【答案】B
> >
> > 【分析】根据分式不等式的解法，求出结果即可·
> >
> > 【详解】有题意可得 $\left\{ \begin{array}{l} x - 2 \neq 0 \\ (3x - 1)(x - 2) \leq 0 \end{array} \right.$ ，解得 $\frac{1}{3} \leq x < 2$ ，即解集为 $\left\{ x \mid \frac{1}{3} \leq x < 2 \right\}$
> >
> > 故选 **B**.
