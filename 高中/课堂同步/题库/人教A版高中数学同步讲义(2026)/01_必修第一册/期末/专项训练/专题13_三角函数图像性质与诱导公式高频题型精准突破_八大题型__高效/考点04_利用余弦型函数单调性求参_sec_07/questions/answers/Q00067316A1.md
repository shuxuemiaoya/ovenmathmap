> [!faq]- 《专题13_三角函数图像性质与诱导公式高频题型精准突破_八大题型__高效》官方解析
>
> > [!success]- **【答案】** (1)答案见解析 (2)证明见解析
>
> > [!note]- **【分析】**
> > （1）化简函数由 $f(x) = \cos^2 x + \cos x + \frac{1}{2} - a$ ，令 $t = \cos x$ ，得到 $f(t) = t^2 + t + \frac{1}{2} - a$ ，结合 $f(x) = 0$ ，得到 $t^2 + t = a - \frac{1}{2}$ ，分类讨论，结合余弦函数的性质，即可求解；
> >
> > (2) 设 $f(x)$ 两个零点 $x_{1}, x_{2}$ ，转化为 $\cos^{2}x_{1} + 2\cos x_{1}\cos x_{2} + \cos^{2}x_{2} = 1$ ，分 $x_{1}, x_{2} \in \left(\frac{\pi}{2}, \pi\right)$ 和 $x_{2} \in \left(\frac{\pi}{2}, \pi\right)$ ，两种情况讨论，结合正弦函数的性质，即可求解.
>
> > [!note]- **【解析】**
> > （1）解：由 $f(x) = \frac{1}{2}\cos 2x + \cos x + 1 - a = \frac{1}{2}(2\cos^2 x - 1) + \cos x + 1 - a = \cos^2 x + \cos x + \frac{1}{2} - a$ ，
> >
> > 令 $t = \cos x$ ，因为 $x\in \left(\frac{\pi}{2},\pi\right)$ ，可得 $t\in (-1,0)$ ，且 $f(t) = t^2 +t + \frac{1}{2} -a$
> >
> > 令 $f(x) = 0$ ，即 $t^2 + t = a - \frac{1}{2}$ ，又因为 $y = t^2 + t = (t + \frac{1}{2})^2 - \frac{1}{4} \in \left[-\frac{1}{4}, 0\right)$
> >
> > 当 $a - \frac{1}{2}$ 0或 $a - \frac{1}{2} < -\frac{1}{4}$ ，即 $a\in \left(-\infty ,\frac{1}{4}\right)\cup \left[\frac{1}{2}, + \infty\right)$ 时，此时 $t^2 +t = a - \frac{1}{2}$ 无解；
> >
> > 当 $a - \frac{1}{2} = -\frac{1}{4}$ ，即 $a = \frac{1}{4}$ 时， $t^2 + t = a - \frac{1}{2}$ 仅有一解 $t = -\frac{1}{2}$ ，此时 $x$ 仅有一解 $\frac{2\pi}{3}$ ；
> >
> > 当 $-\frac{1}{4} < a - \frac{1}{2} < 0$ ，即 $\frac{1}{4} < a < \frac{1}{2}$ 时， $t^2 + t = a - \frac{1}{2}$ 有两解 $t = -\frac{1}{2} \pm \sqrt{a - \frac{1}{4}}$
> >
> > 因为 $\cos x = -\frac{1}{2} \pm \sqrt{a - \frac{1}{4}}$ 各有一解，此时 $f(x)$ 恰有两个零点，
> >
> > 综上可得，当 $a \in \left(-\infty, \frac{1}{4}\right) \cup \left[\frac{1}{2}, +\infty\right)$ 时， $f(x)$ 无零点；当 $a = \frac{1}{4}$ 时， $f(x)$ 恰有一个零点；当 $a \in \left(\frac{1}{4}, \frac{1}{2}\right)$ 时， $f(x)$ 恰有两个零点。
> >
> > (2) 解：若 $f(x)$ 恰有两个零点 $x_{1}, x_{2}$ 时，
> >
> > 令 $t_1 = \cos x_1, t_2 = \cos x_2$ ，所以 $t_1, t_2$ 为 $t^2 + t = a - \frac{1}{2}$ 的两解，
> >
> > 所以 $t_1 + t_2 = -1$ ，所以 $\cos x_{1} + \cos x_{2} = -1$ ，所以 $\cos^2 x_1 + 2\cos x_1\cos x_2 + \cos^2 x_2 = 1$
> >
> > 由 $x_{1}, x_{2} \in \left(\frac{\pi}{2}, \pi\right)$ ，可得 $\cos x_{1} < 0, \cos x_{2} < 0$ ，所以 $2\cos x_{1}\cos x_{2} > 0$ ，则 $\cos^2 x_1 + \cos^2 x_2 < 1$ ，
> >
> > 所以 $\cos^{2}x_{1}<\sin^{2}x_{2}=\cos^{2}\left(\frac{3\pi}{2}-x_{2}\right)$ ;
> >
> > 由 $x_{2} \in \left(\frac{\pi}{2}, \pi\right)$ ，可得 $\frac{3\pi}{2} - x_{2} \in \left(\frac{\pi}{2}, \pi\right), \cos \left(\frac{3\pi}{2} - x_{2}\right) < 0$ ，所以 $\cos x_{1} > \cos \left(\frac{3\pi}{2} - x_{2}\right)$ ，因为 $y = \cos x$ 在 $\left(\frac{\pi}{2}, \pi\right)$ 上单调递减，可得 $x_{1} < \frac{3\pi}{2} - x_{2}$ ，所以 $x_{1} + x_{2} < \frac{3\pi}{2}$ 。
