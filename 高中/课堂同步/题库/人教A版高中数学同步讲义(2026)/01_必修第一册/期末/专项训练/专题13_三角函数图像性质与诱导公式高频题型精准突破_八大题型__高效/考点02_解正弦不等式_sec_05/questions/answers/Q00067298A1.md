> [!faq]- 《专题13_三角函数图像性质与诱导公式高频题型精准突破_八大题型__高效》官方解析
>
> > [!success]- **【答案】** (1) $2 - \sqrt{3}$ (2) $f(x)_{\max} = \frac{33}{8}$ , $f(x)_{\min} = 3$ (3) $\left(-\frac{\pi}{6},\frac{7\pi}{6}\right]$
>
> > [!note]- **【分析】**
> > （1）由 $\sin \alpha +\cos \alpha = \frac{\sqrt{6}}{2}$ 平方求得 $\sin \alpha \cos \alpha$ ，进而求得 $\cos \alpha -\sin \alpha = \frac{\sqrt{2}}{2}$ ，即可求解；
> >
> > (2) 由 (1) 得 $f(x) = -2\sin^2 x + \sin x + 4$ ，通过换元，由二次函数即可求解；
> >
> > (3) 求解 $-2\sin^{2}x + \sin x + 4$ 3 得到 $x \in \left[-\frac{\pi}{6} + 2k\pi, \frac{7\pi}{6} + 2k\pi\right]$ ，进而可判断 m 范围.
>
> > [!note]- **【解析】**
> > （1）因为 $\sin \alpha +\cos \alpha = \frac{\sqrt{6}}{2}$ ①， $\therefore (\sin \alpha +\cos \alpha)^2 = 1 + 2\sin \alpha \cos \alpha = \frac{3}{2}$ $\therefore 2\sin \alpha \cos \alpha = \frac{1}{2}, \therefore (\cos \alpha - \sin \alpha)^2 = 1 - 2\sin \alpha \cos \alpha = \frac{1}{2}$ ，又 $\cos \alpha > \sin \alpha$ $\cos \alpha - \sin \alpha = \frac{\sqrt{2}}{2}$ ②，由①②得 $\sin \alpha = \frac{\sqrt{6} - \sqrt{2}}{4}$ ， $\cos \alpha = \frac{\sqrt{6} + \sqrt{2}}{4}$ ， $\tan \alpha = \frac{\sin \alpha}{\cos \alpha} = 2 - \sqrt{3}$ ；(2) $\because f(x) = \sin x + 2\sin^2 (x + \frac{\pi}{2}) + 2 = -2\sin^2 x + \sin x + 4$ 令 $t = \sin x \in [-\frac{1}{2}, 1]$ ，则 $y = -2t^2 + t + 4 = -2(t - \frac{1}{4})^2 + \frac{33}{8}$ ， $(- \frac{1}{2} \leq t \leq 1)$ 当 $\sin x = t = \frac{1}{4}$ 时， $f(x)_{\max} = \frac{33}{8}$ ，
> > 当 $t = -\frac{1}{2}$ 或 $t = 1$ 即 $x = -\frac{\pi}{6}$ 或 $x = \frac{\pi}{2}$ 时， $f(x)_{\min} = 3$ ；
> > （3）要使 $f(x) = -2\sin^2 x + \sin x + 4 - 3$ ，即 $2\sin^2 x - \sin x - 1 \leq 0$ 所以 $-\frac{1}{2} \leq \sin x \leq 1$ ，即 $x \in \left[-\frac{\pi}{6} + 2k\pi, \frac{7\pi}{6} + 2k\pi\right]$ ， $k \in Z$ 依题意得 $-\frac{\pi}{6} < m \leq \frac{7\pi}{6}$ ，所以数 $m$ 的取值范围是 $\left(-\frac{\pi}{6}, \frac{7\pi}{6}\right]$ .
