> [!faq]- 《专题13_三角函数图像性质与诱导公式高频题型精准突破_八大题型__高效》官方解析
>
> > [!success]- **【答案】** $\left[\frac{3}{4},\frac{4}{5}\right]$
>
> > [!note]- **【分析】**
> > 当 $0 < x < \frac{5\pi}{2}$ 时，求出 $4\omega x$ 的取值范围，根据函数 $f(x)$ 在区间 $\left(0, \frac{5\pi}{2}\right)$ 内的零点个数可得出关于 $\omega$
> >
> > 的不等式；当 $\frac{\pi}{3} < x < \frac{\pi}{2}$ 时，求出 $4\omega x$ 的取值范围，根据函数 $f(x)$ 在区间 $\left(\frac{\pi}{3}, \frac{\pi}{2}\right)$ 上的单调性，可得出关于
> >
> > $\omega$ 的不等式组，综合可得出 $\omega$ 的取值范围·
>
> > [!note]- **【解析】**
> > 因为函数 $f(x) = 1 - \cos 4\omega x (\omega > 0)$ 在区间 $\left(0, \frac{5\pi}{2}\right)$ 上恰有3个零点，
> >
> > 令 $f(x) = 0$ ，可得 $\cos 4\omega x = 1$ ，当 $0 < x < \frac{5\pi}{2}$ 时， $0 < 4\omega x < 10\pi \omega$
> >
> > 所以， $6\pi < 10\pi\omega \leq 8\pi$ ，解得 $\frac{3}{5} < \omega \leq \frac{4}{5}$ ，
> >
> > 又因为函数 $f(x) = 1 - \cos 4\omega x(\omega >0)$ 在区间 $\left(\frac{\pi}{3},\frac{\pi}{2}\right)$ 上单调递减，
> >
> > 当 $\frac{\pi}{3} < x < \frac{\pi}{2}$ 时， $\frac{4\pi\omega}{3} < 4\omega x < 2\pi\omega$
> >
> > 则 $\left(\frac{4\pi\omega}{3},2\pi\omega\right)\subseteq(2k\pi+\pi,2k\pi+2\pi)$ ，其中 $k\in\mathbf{N}$ ，
> >
> > 所以， $\left\{\begin{aligned}\frac{4\pi\omega}{3}&(2k+1)\pi(k\in\mathbf{N})\\ 2\pi\omega&\leq(2k+2)\pi\end{aligned}\right.$ ，解得 $\frac{6k+3}{4}\leq\omega\leq k+1,\quad k\in\mathbf{N}$
> >
> > 由 $k + 1$ $\frac{6k + 3}{4}$ 解得 $k\leq \frac{1}{2}$ ，故 $k = 0$ ，则 $\frac{3}{4}\leq \omega \leq 1$
> >
> > 综上所述，正实数 $\omega$ 的取值范围是 $\left[\frac{3}{4},\frac{4}{5}\right]$
> >
> > 故答案为： $\left[\frac{3}{4},\frac{4}{5}\right]$
>
> > [!tip]- **【名师点睛】**
> > 思路点睛：三角函数图象与性质问题的求解
> > 思路：
> >
> > (1) 将函数解析式变形为 $y = A \sin (\omega x + \varphi) + B (\omega > 0)$ 或 $y = A \cos (\omega x + \varphi) + B (\omega > 0)$ 的形式；
> >
> > (2) 将 $\omega x + \varphi$ 看成一个整体；
> >
> > (3) 借助正弦函数 $y = \sin x$ 或余弦函数 $y = \cos x$ 的图象和性质（如定义域、值域、最值、周期性、对称性、单调性等）解决相关问题.
