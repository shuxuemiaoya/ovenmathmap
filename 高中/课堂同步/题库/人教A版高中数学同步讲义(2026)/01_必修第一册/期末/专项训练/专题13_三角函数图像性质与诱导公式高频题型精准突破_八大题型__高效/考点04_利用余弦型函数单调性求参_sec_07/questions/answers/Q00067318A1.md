> [!faq]- 《专题13_三角函数图像性质与诱导公式高频题型精准突破_八大题型__高效》官方解析
>
> > [!success]- **【答案】** AB
>
> > [!note]- **【分析】**
> > 根据三角函数的周期性、含 $\cos x$ 的二次项函数的值域、三角函数的零点、单调性等知识对选项进行分析，从而确定正确答案：
>
> > [!note]- **【解析】**
> > 当 $a = 0$ 时， $f(x) = \cos 2x + 2$ ，所以 $f(x)$ 的最小正周期为 $\pi$ ， $^{\mathrm{A}}$ 选项正确；
> >
> > 当 $a = 1$ 时， $f(x) = \cos 2x + \cos x + 2 = 2\cos^2 x + \cos x + 1 = 2\left(\cos x + \frac{1}{4}\right)^2 + \frac{7}{8} \frac{7}{8}$ ，
> >
> > 所以 $f(x)$ 的最小值为 $\frac{7}{8}$ ，B选项正确；
> >
> > 当 $a = 3$ 时， $f(x) = \cos 2x + 3\cos x + 2 = 2\cos^2 x + 3\cos x + 1 = (2\cos x + 1)(\cos x + 1)$ ，
> >
> > 令 $f(x) = 0$ ，解得 $\cos x = -\frac{1}{2}$ 或 $\cos x = -1$ ，此时 $x = \frac{2\pi}{3}$ 或 $x = \frac{4\pi}{3}$ 或 $x = \pi$ ，
> >
> > $f(x)$ 在区间 $[0,2\pi ]$ 上有3个零点，C选项错误；
> >
> > $f(x) = \cos 2x + a\cos x + 2 = 2\cos^2 x + a\cos x + 1$ ，设 $t = \cos x$
> >
> > $\cos x$ 在 $\left(0, \frac{\pi}{3}\right)$ 上单调递减，则 $t \in \left(\frac{1}{2}, 1\right)$ ，根据复合函数的单调性， $g(t) = 2t^2 + at + 1$ 在 $\left(\frac{1}{2}, 1\right)$ 上单调递增，所以 $-\frac{a}{4} \leq \frac{1}{2}$ ，解得 $a - 2$ ， $D$ 选项错误。
> >
> > 故选 **AB**
