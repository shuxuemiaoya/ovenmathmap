> [!faq]- 《专题13_三角函数图像性质与诱导公式高频题型精准突破_八大题型__高效》官方解析
>
> > [!success]- **【答案】** BC
>
> > [!note]- **【分析】**
> > 首先化简函数 $f(x) = \sqrt{3}\sin \left(2\omega x + \frac{\pi}{3}\right)$ ，利用函数单调性得出 $0 < \omega \leq 1$ ，应用周期公式，对称性及最值，再根据函数的性质逐项判断即可。
>
> > [!note]- **【解析】**
> > $f(x) = \sin \left(2\omega x + \frac{\pi}{6}\right) + 2\cos^2\omega x - 1 = \frac{\sqrt{3}}{2}\sin 2\omega x + \frac{1}{2}\cos 2\omega x + \cos 2\omega x$ $= \frac{\sqrt{3}}{2}\sin 2\omega x + \frac{3}{2}\cos 2\omega x$ $= \sqrt{3}\sin \left(2\omega x + \frac{\pi}{3}\right)$ 当 $x \in \left[-\frac{5\pi}{12}, \frac{\pi}{12}\right]$ 时单调递增，则 $t = 2\omega x + \frac{\pi}{3} \in \left[-\frac{5\pi}{6}\omega + \frac{\pi}{3}, \frac{\pi}{6}\omega + \frac{\pi}{3}\right]$ 时，函数 $y = \sin t$ 单调递增，
> >
> > 所以 $-\frac{5\pi}{6}\omega + \frac{\pi}{3} - \frac{\pi}{2}, \frac{\pi}{6}\omega + \frac{\pi}{3} \leq \frac{\pi}{2}$ ，所以 $0 < \omega \leq 1$ ； $\because T = \frac{2\pi}{2\omega}$ 不确定，A选项错误；
> >
> > 令 $2\omega x + \frac{\pi}{3} = k\pi, k \in Z, 2\omega x = -\frac{\pi}{3} + k\pi, k \in Z$ 所以当 $\omega = 1$ 时， $x = -\frac{\pi}{6} + \frac{k\pi}{2}, k \in Z$ 时， $k = 1$ 时，函数 $f(x)$ 图象的一个对称中心是 $\left(\frac{\pi}{3}, 0\right)$ ，B选项正确；
> >
> > 设 $t = 2\omega x + \frac{\pi}{3}$ ，因为函数 $y = \sin t$ 的最大值为 $^1$ ，
> >
> > 所以函数 $f(x) = \sqrt{3}\sin \left(2\omega x + \frac{\pi}{3}\right) = \sqrt{3}\sin t$ 的最大值是 $\sqrt{3}$ ，故C选项正确；
> >
> > 已知 $f(x)$ 在区间 $\left[-\frac{5\pi}{12}, \frac{\pi}{12}\right]$ 上单调递增，若函数 $f(x)$ 在区间 $\left[\frac{\pi}{12}, \frac{7\pi}{12}\right]$ 上单调递减，
> >
> > 则 $f\left(\frac{\pi}{12}\right) = \sqrt{3}$ ，但是 $0 < \omega \leq 1, f\left(\frac{\pi}{12}\right) = \sqrt{3}\sin \left(\omega\frac{\pi}{6} + \frac{\pi}{3}\right) = \sqrt{3}$ 不能恒成立，故D不正确。
> >
> > 故选 **BC**.
