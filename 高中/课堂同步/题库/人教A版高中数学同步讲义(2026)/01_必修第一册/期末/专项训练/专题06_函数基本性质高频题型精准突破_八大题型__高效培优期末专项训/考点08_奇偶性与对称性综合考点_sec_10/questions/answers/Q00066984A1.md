> [!faq]- 《专题06_函数基本性质高频题型精准突破_八大题型__高效培优期末专项训》官方解析
>
> > [!success]- **【答案】** AC
>
> > [!note]- **【分析】**
> > 令 $x = y = 0$ ，可判断A；令 $x_{1} = x + y, x_{2} = y$ ，可得 $f(x_{1}) - f(x_{2}) > 0$ ，可判断B；令 $y = -x$ ，可得 $f(x) + f(-x) = 2$ ，可判断C；举反例 $f(x) = x^{2} + x + 1$ ，可判断D.
>
> > [!note]- **【解析】**
> > 解：令 $x = y = 0$ ，得 $f(0) = 2f(0) - 1$
> >
> > 所以 $f(0)=1$ ，故 A 正确；
> >
> > 当 a=0 时， $f(x+y)=f(x)+f(y)-1$
> >
> > 当 x > 0 时，恒有 $f(x + y) - f(y) = f(x) - 1 > 0$ ，
> >
> > 令 $x_{1} = x + y, x_{2} = y$
> >
> > 即对任意 $x_{1}, x_{2} \in R$ ， $x_{1} > x_{2}$ 时，
> >
> > $$
> > f (x _ {1}) - f (x _ {2}) > 0
> > $$
> >
> > 即函数 $f(x)$ 为增函数，故 $\mathsf{B}$ 错误.
> >
> > 令 $y = -x$ ，则 $f(0) = f(x) + f(-x) - 1$
> >
> > 又 $f(0) = 1$
> >
> > 所以 $f(x) + f(-x) = 2$
> >
> > 即 $f(x)$ 的图象关于点 $(0,1)$ 对称，故 C 正确；
> >
> > 当 a=2 时，若取 $f(x)=x^{2}+x+1$
> >
> > 则 $f(x + y) = (x + y)^2 +(x + y) + 1 = x^2 +y^2 +(x + y) + 1 + 2xy$
> >
> > $$
> > f (x) + f (y) + 2 x y - 1 = x ^ {2} + y ^ {2} + (x + y) + 1 + 2 x y
> > $$
> >
> > 即 $f(x + y) = f(x) + f(y) + 2xy - 1$
> >
> > 且当 $x > 0$ 时， $f(x)$ 单调递增，恒有 $f(x) > 1$
> >
> > 显然， $f(x)$ 不为偶函数，故 D 错误。
> >
> > 故选 **AC**.
