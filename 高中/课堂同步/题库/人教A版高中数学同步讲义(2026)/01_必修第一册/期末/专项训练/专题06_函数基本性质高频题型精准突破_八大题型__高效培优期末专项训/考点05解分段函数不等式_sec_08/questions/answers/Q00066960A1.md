> [!faq]- 《专题06_函数基本性质高频题型精准突破_八大题型__高效培优期末专项训》官方解析
>
> > [!success]- **【答案】** B
>
> > [!note]- **【分析】**
> > 根据绝对值的情况，对参数进行分类讨论，写出分段函数解析式，根据不等式求出参数范围；
>
> > [!note]- **【解析】**
> > 令 $2x - a = 0$ ，解得 $x = \frac{a}{2}$
> >
> > 当 $a \leq 2$ 时， $\forall x > 1, 2x - a > 0$
> >
> > 令 $f(x) = 2x^{2} - ax - a^{2}$ ，可知 $f(x)$ 在 $\left(\frac{a}{4}, +\infty\right)$ 上单调递增，由 $\frac{a}{4} \leq \frac{1}{2}$ 可知， $f(x)$ 在 $(1, +\infty)$ 上单调递增，所以 $f(x) > f(1)$ ，得 $f(1) = 2 - a - a^2 - 0$ ，解得 $-2 \leq a \leq 1$ ；
> >
> > 当时，令 $f(x) = \left\{ \begin{array}{ll}2x^{2} - ax - a^{2},x & \frac{a}{2}\\ ax - 2x^{2} - a^{2},1 <   x <   \frac{a}{2} \end{array} \right.$
> >
> > 当 $1 < x < \frac{a}{2}$ 时， $f(x) = ax - 2x^2 - a^2$ ，可知 $\Delta = a^2 - 8a^2 = -7a^2 < 0$ ，所以在 $1 < x < \frac{a}{2}$ 上 $f(x) < 0$ ，不符合条件；
> >
> > 综上：实数 a 的取值范围是 $\left[-2,1\right]$ ;
> >
> > 故选 **B**.
