> [!faq]- 《专题06_函数基本性质高频题型精准突破_八大题型__高效培优期末专项训》官方解析
>
> > [!success]- **【答案】** ACD
>
> > [!note]- **【分析】**
> > 令 x = y = 0 ，求出 $f(0)$ 的值，可判断 A 正确；令 x = 1, y = -1 ，求得 $f(-1)$ 的值，再令 x = y = -1 ，求得 $f(-2)$ 的值，可判断 B 错误；根据题意，得到 x > 0 时， $f(x) > -2025$ ，结合函数单调性的定义，可判断 C 正确；令 $g(x) = f(x) + 2025$ ，由 $g(0) = 0$ ，令 y = -x ，结合函数奇偶性的定义，可判断 D 选项。
>
> > [!note]- **【解析】**
> > 对于 A，对任意的实数 x, y 满足 $f(x + y) = f(x) + f(y) + 2025$
> >
> > 令 $x = y = 0$ 可得 $f(0) = 2f(0) + 2025$ ，解得 $f(0) = -2025$ ，所以A正确；
> >
> > 对于 B，令 x=1, y=-1 可得 $f(0)=f(1)+f(-1)+2025$
> >
> > 即 $-2025 = 0 + f(-1) + 2025$ ，解得 $f(-1) = -4050$ ，
> >
> > 再令 $x = y = -1$ ，可得 $f(-2) = 2f(-1) + 2025 = 2 \times (-4050) + 2025 = -6075$ ，所以B错误；
> >
> > 对于 C，由题意知：当 x > 1 时， $f(x) > 0$
> >
> > 当 $x > 1$ 时，则 $x - 1 > 0$ 时， $f(x - 1) = f(x) + f(-1) + 2025 = f(x) - 2025 > -2025$
> >
> > 故当 x > 0 时， $f(x) > -2025$ ，
> >
> > 任取 $x_{1}, x_{2} \in R$ 且 $x_{1} < x_{2}$
> >
> > 则 $f(x_{2}) = f(x_{2} - x_{1}) + f(x_{1}) + 2025 > -2025 + f(x_{1}) + 2025 = f(x_{1})$
> >
> > 所以函数 $f(x)$ 在R上为增函数，所以C正确；
> >
> > 对于 D，令 $g(x)=f(x)+2025$ ，因为 $f(x+y)=f(x)+f(y)+2025$ ，
> >
> > 可得 $f(x+y)+2025=f(x)+2025+f(y)+2025$
> >
> > 即 $g(x + y) = g(x) + g(y)$ ，且 $g(0) = f(0) + 2025 = 0$
> >
> > 令 $y = -x$ ，则 $g(x) + g(-x) = g(0) = 0$ ，即 $g(-x) = -g(x)$ ，
> >
> > 所以，函数 $g(x) = f(x) + 2025$ 为奇函数，D对；
> >
> > 故选 **ACD**.
