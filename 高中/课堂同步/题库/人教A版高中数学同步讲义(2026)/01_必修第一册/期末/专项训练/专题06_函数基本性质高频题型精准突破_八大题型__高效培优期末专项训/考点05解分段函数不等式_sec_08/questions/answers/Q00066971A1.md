> [!faq]- 《专题06_函数基本性质高频题型精准突破_八大题型__高效培优期末专项训》官方解析
>
> > [!success]- **【答案】** AD
>
> > [!note]- **【分析】**
> > AB选项，由奇函数得到 $f(0) = 0$ ， $f(-x) = -f(x)$ ，进而得到 $g(-x) = g(x)$ ，得到 $g(x)$ 为偶函数，
> >
> > B 错误；C 选项， $f(-1) = -f(1) = -7$ ；D 选项，由函数的奇偶性结合 x > 0 时的解析式，求出答案
>
> > [!note]- **【解析】**
> > AB选项，因为 $f(x)$ 是定义在R上的奇函数，
> >
> > 根据奇函数性质可知， $f(0)=0$ ，A 正确；
> >
> > $g(x) = xf(x)$ 的定义域为 $\mathsf{R}$ ，由于 $f(-x) = -f(x)$
> >
> > 则 $g(-x) = -xf(-x) = xf(x) = g(x)$
> >
> > 即 $g(x)$ 为偶函数，B 错误；
> >
> > C 选项，当 x > 0 时， $f(x) = x^{2} + x + 5$ ，则 $f(1) = 7$ ，
> >
> > 故 $f(-1) = -f(1) = -7$ ，C 错误；
> >
> > D 选项，当 x < 0 时，-x > 0，则 $f(-x) = x^{2} - x + 5 = -f(x)$ ，
> >
> > 所以 $f(x) = -x^{2} + x - 5$ ，D 正确。
> >
> > 故选 **AD**.
