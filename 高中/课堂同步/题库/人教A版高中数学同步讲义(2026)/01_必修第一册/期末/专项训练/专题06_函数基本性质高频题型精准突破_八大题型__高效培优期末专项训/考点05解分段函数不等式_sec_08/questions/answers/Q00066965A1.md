> [!faq]- 《专题06_函数基本性质高频题型精准突破_八大题型__高效培优期末专项训》官方解析
>
> > [!success]- **【答案】** A. $f\left[f\left(\sqrt{3}\right)\right] = 2$ B. 若 $f(x) = -1$ ，则 $x = 2$ 或 $x = -3$ C. $f(x) < 2$ 的解集为 $(-\infty, 0) \cup [1, +\infty)$ D. $\forall x \in \mathbb{R}, a > f(x)$ ，则 $a = 3$
>
> > [!note]- **【分析】**
> > 对于 $^{A}$ ，根据解析式先求 $f(\sqrt{3})$ ，再求 $f[f(\sqrt{3})]$ ，对于 $^{B}$ ，分x<1和x-1两种情况求解，对于C，分x<1和x-1两种情况解不等式，对于 $^{D}$ ，求出函数的值域进而即得.
>
> > [!note]- **【解析】**
> > 对于 A，因为 $f(\sqrt{3}) = -\left(\sqrt{3}\right)^{2} + 3 = 0$ ，所以 $f\left[f(\sqrt{3})\right] = f(0) = 2$ ，所以 A 正确；
> >
> > 对于 B，当 x < 1 时，由 $f(x) = -1$ ，得 $x + 2 = -1$ ，得 x = -3；
> >
> > 当 $x$ 1时，由 $f(x) = -1$ ，得 $-x^{2} + 3 = -1$ ， $x^{2} = 4$ ，得 $x = 2$ 或 $x = -2$ （舍去）；
> >
> > 综上， $x = 2$ 或 $x = -3$ ，所以 $\mathsf{B}$ 正确；
> >
> > 对于 C，当 x<1 时，由 $f(x)<2$ ，得 $x+2<2$ ，解得 x<0；
> >
> > 当 x 1 时，由 $f(x) < 2$ ，得 $-x^{2} + 3 < 2$ ，解得 x > 1 或 $x < -1$ （舍去）；
> >
> > 综上， $f(x) < 2$ 的解集为 $(-∞,0)∪(1,+∞)$ ，所以 C 错误；
> >
> > 对于 D，当 x<1 时， $x+2<3$ ，当 x=1 时， $-x^{2}+3\leq2$ ，所以 $f(x)$ 的值域为 $(-∞,3)$ ，
> >
> > 因为 $\forall x\in R,\quad a>f(x)$ ，所以 a 3，所以 D 正确，
> >
> > 故选 **ABD**.
