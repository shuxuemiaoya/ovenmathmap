> [!faq]- 《专题07_指数与指数函数高频题型精准突破_八大题型__高效培优期末专项》官方解析
>
> > [!success]- **【答案】** $^{(1)}$ m=1 ， $f(-1)=2+\frac{1}{e}$ (2)证明见详解 (3) $(-∞, \frac{7}{2}]$
>
> > [!note]- **【分析】**
> > （1）函数 $f(x)$ 的图象过点 $\left(\frac{1}{2},\frac{17}{4}\right)$ ，可求得 $m = 1$ ；再将 $x = -1$ 带入分段函数对应解析式即可求解；
> >
> > (2) 根据不等式的性质，结合 x 的取值范围即可证明；
> >
> > (3) 由题知 $g(x) = |f(x) - (x + n)| = \begin{cases} \left|\mathrm{e}^x + 3 - n\right|, & x \leq 0, \\ \left|-x^2 + 4 - n\right|, & 0 < x < 1 \end{cases}$ ，对的取值范围进行分类讨论，去绝对值后研究分段函数的单调性即可求解。
>
> > [!note]- **【解析】**
> > （1）∵函数 $f(x)=\left\{\begin{aligned}&\mathrm{e}^{x}+x+3,x\leq0,\\&-x^{2}+mx+4,0<x<1\end{aligned}\right.$ 的图象过点 $\left(\frac{1}{2},\frac{17}{4}\right)$
> >
> > $\therefore f(\frac{1}{2}) = -\left(\frac{1}{2}\right)^2 + \frac{m}{2} + 4 = \frac{15 + 2m}{4} = \frac{17}{4}$ ，解得 $m = 1$
> >
> > $$
> > \therefore f (x) = \left\{ \begin{array}{l} \mathrm{e} ^ {x} + x + 3, x \leq 0, \\ - x ^ {2} + x + 4, 0 <   x <   1 \end{array} \right..
> > $$
> >
> > 故 $f(-1)=\mathrm{e}^{-1}-1+3=2+\frac{1}{\mathrm{e}}$ .
> >
> > (2) 证明：由 (1) 知 $f(x) = \begin{cases} \mathrm{e}^x + x + 3, & x \leq 0, \\ -x^2 + x + 4, & 0 < x < 1 \end{cases}$ ，
> >
> > 当 $x \leq 0$ 时，∵ $0 < e^{x} \leq 1$
> >
> > $\therefore x + 3 < \mathrm{e}^{x} + x + 3 \leq x + 4$
> >
> > 当 $0 < x < 1$ 时， $\because 0 < x^2 < 1$
> >
> > $$
> > \therefore - 1 <   - x ^ {2} <   0 \quad \therefore x + 3 <   - x ^ {2} + x + 4 <   x + 4.
> > $$
> >
> > 综上， $\forall x \in (-\infty, 1)$ ，都有 $x + 3 < f(x) \leq x + 4$ 。
> >
> > (3) 由 (1) 知 $g(x) = |f(x) - (x + n)| = \begin{cases} \left|\mathrm{e}^x + 3 - n\right|, & x \leq 0, \\ \left|-x^2 + 4 - n\right|, & 0 < x < 1. \end{cases}$
> >
> > 当 $x \leq 0$ 时，∵ $0 < e^{x} \leq 1$ ，∴ $3 < e^{x} + 3 \leq 4$ ；
> >
> > 当 $0 < x < 1$ 时， $\because 0 < x^2 < 1, \therefore 3 < -x^2 + 4 < 4.$
> >
> > 当 $n$ 4时， $g(x) = |f(x) - (x + n)| = \begin{cases} -\mathrm{e}^x - 3 + n, & x \leq 0, \\ x^2 - 4 + n, & 0 < x < 1 \end{cases}$ ，
> >
> > 由于函数 $y = -\mathrm{e}^{x} - 3 + n$ 在 $(- \infty, 0]$ 上单调递减，函数 $y = x^{2} - 4 + n$ 在 $(0, 1)$ 上单调递增，
> >
> > 故函数 $g(x) = \left|f(x) - (x + n)\right| = \begin{cases} -\mathrm{e}^x -3 + n,x\leq 0,\\ x^2 -4 + n,0 <   x <   1 \end{cases}$ 在 $(-\infty ,1)$ 上无最大值；
> >
> > 当 $n \leq 3$ 时， $g(x) = |f(x) - (x + n)| = \begin{cases} e^x + 3 - n, & x \leq 0, \\ -x^2 + 4 - n, & 0 < x < 1 \end{cases}$ ，
> >
> > 由于函数 $y = \mathrm{e}^{x} + 3 - n$ 在 $(- \infty, 0]$ 上单调递增，函数 $y = -x^{2} + 4 - n$ 在 $(0, 1)$ 上单调递减，
> >
> > 故当 $x = 0$ 时，函数 $g(x) = |f(x) - (x + n)| = \begin{cases} \mathrm{e}^x + 3 - n, & x \leq 0, \\ -x^2 + 4 - n, & 0 < x < 1 \end{cases}$ 取得最大值，最大值为 $g(0) = 4 - n$ ；
> >
> > 当 $3 < n < 4$ 时，不妨设方程 $g(x) = 0$ 的两根分别为 $x_{1}(x_{1} < 0)$ 和 $x_{2}(0 < x_{2} < 1)$ ，
> >
> > $$
> > g (x) = \left| f (x) - (x + n) \right| = \left\{ \begin{array}{l} - \mathrm{e} ^ {x} - 3 + n, x \leq x _ {1}, \\ \mathrm{e} ^ {x} + 3 - n, x _ {1} <   x \leq 0, \\ - x ^ {2} + 4 - n, 0 <   x \leq x _ {2}, \\ x ^ {2} - 4 + n, x _ {2} <   x <   1 \end{array} \right.
> > $$
> >
> > 易知函数 $g(x)$ 在 $(- \infty, x_1)$ 和 $(0, x_2]$ 上单调递减，在 $(x_1, 0]$ 和 $(x_2, 1)$ 上单调递增，
> >
> > 要使函数 $g(x) = |f(x) - (x + n)|$ 在 $(- \infty, 1)$ 上存在最大值，需使 $\left\{ \begin{array}{ll} g(0) & n - 3 \\ 3 < n < 4 \end{array} \right.$ ，即 $\left\{ \begin{array}{ll} 4 - n & n - 3 \\ 3 < n < 4 \end{array} \right.$ ，解得 $3 < n \leqslant \frac{7}{2}$ .
> >
> > 综上，若函数 $g(x) = |f(x) - (x + n)|(n \in \mathbf{R})$ 在 $(- \infty, 1)$ 上存在最大值， $n$ 的取值范围为 $(- \infty, \frac{7}{2}]$ .
