> [!faq]- 《专题07_指数与指数函数高频题型精准突破_八大题型__高效培优期末专项》官方解析
>
> > [!success]- **【答案】** (1)7 (2) $\frac{1}{3}$
>
> > [!note]- **【分析】**
> > （ $^{1}$ ）由完全平方公式以及分数指数幂的运算即可得解·
> >
> > (2) 由完全平方公式、立方和公式以及分数指数幂的运算即可得解.
>
> > [!note]- **【解析】**
> > （1）由题意 $a^{\frac{1}{2}} + a^{-\frac{1}{2}} = 3$ ，所以 $a + a^{-1} = \left(a^{\frac{1}{2}} + a^{-\frac{1}{2}}\right)^2 - 2 = 3^2 - 2 = 7$
> >
> > (2) 由题意 $a^{\frac{1}{2}} + a^{-\frac{1}{2}} = 3$
> >
> > 所以 $\frac{a^{\frac{3}{2}} + a^{-\frac{3}{2}} - 3}{a^2 + a^{-2} - 2} = \frac{\left(a^{\frac{1}{2}} + a^{-\frac{1}{2}}\right)\left(a - a^{\frac{1}{2}} \cdot a^{-\frac{1}{2}} + a^{-1}\right) - 3}{(a + a^{-1})^2 - 4} = \frac{3 \times (7 - 1) - 3}{7^2 - 4} = \frac{15}{45} = \frac{1}{3}$ .
> >
> > 15. 计算.
> >
> > (1) $(0.0081)^{-\frac{1}{4}} - \left[3 \times \left(\frac{7}{8}\right)^0\right]^{-1} \times \left[81^{-0.25} + \left(3\frac{3}{8}\right)^{-\frac{1}{3}}\right]^{\frac{1}{2}};$
> >
> > (2) $\sqrt[3]{-125} + \sqrt[4]{(-36)^2} + \sqrt[6]{(\pi - 4)^6} - \sqrt[3]{(3 - \pi)^3}$
> >
> > 【答案】(1)3
> >
> > (2)2
> >
> > 【分析】（1）利用分数指数幂的运算法则计算即可；
> >
> > (2) 先将根式转化为指数幂，利用指数的运算法则计算即可·
> >
> > 【详解】（1） $(0.0081)^{-\frac{1}{4}} - \left[3\times (\frac{7}{8})^0\right]^{-1}\times \left[81^{-0.25} + \left(3\frac{3}{8}\right)^{-\frac{1}{3}}\right]^{-\frac{1}{2}}$ $= (0.3)^{4\times (-\frac{1}{4})} - 3^{-1}\times \left[3^{4\times (-0.25)} + \left(\frac{3}{2}\right)^{3\times \left(-\frac{1}{3}\right)}\right]^{-\frac{1}{2}}$ $= (0.3)^{-1} - \frac{1}{3}\times \left(\frac{1}{3} +\frac{2}{3}\right)^{-\frac{1}{2}} = \frac{10}{3} -\frac{1}{3} = 3$ ：
> > （2） $\sqrt[3]{-125} +\sqrt[4]{(-36)^2} +\sqrt[6]{(\pi -4)^6} -\sqrt[3]{(3 - \pi)^3}$ $= [(-5)^3]^{\frac{1}{3}} + (6^4)^{\frac{1}{4}} + |\pi -4| - (3 - \pi)$ $= -5 + 6 + 4 - \pi -3 + \pi = 2.$
