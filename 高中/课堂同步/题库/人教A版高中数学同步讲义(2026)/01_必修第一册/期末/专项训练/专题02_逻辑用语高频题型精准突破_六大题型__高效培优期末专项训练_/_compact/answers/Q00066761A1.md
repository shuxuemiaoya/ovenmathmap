> [!faq]- 《专题02_逻辑用语高频题型精准突破_六大题型__高效培优期末专项训练_》官方解析
>
> > [!success]- **【答案】** (1) $A \cap B = \{x \mid 5 < x \leq 7\}$ ， $A \cup B = \{x \mid x < -1 \text{或} x \quad 4\}$ (2) $\left\{a\mid a<-4\text{或}a>5\right\}$
>
> > [!note]- **【分析】**
> > （1）先求出集合 A，再根据交集和并集的定义运算即可；
> >
> > (2) 由已知可得 $A \subseteq B$ ，进而根据包含关系求解
>
> > [!note]- **【解析】**
> > （1）当 $a = 4$ 时， $A = \{x | 4 \leq x \leq 7\}$ ，而 $B = \{x | x < -1$ 或 $x > 5\}$
> >
> > 则 $A \cap B = \{x \mid 5 < x \leq 7\}$ ， $A \cup B = \{x \mid x < -1 \text{或} x \quad 4\}$ .
> >
> > (2) 若命题“ $\forall x \in A$ ，都有 $x \in B$ ”是真命题，则 $A \subseteq B$
> >
> > 由 $A \neq \emptyset$ ，所以 $a + 3 < -1$ 或 $a > 5$ ，即 $a < -4$ 或 $a > 5$
> >
> > 故 a 的取值范围为 $\left\{a \mid a < -4 \text{ 或 } a > 5\right\}$ .
