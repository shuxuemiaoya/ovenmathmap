> [!faq]- 《专题02_逻辑用语高频题型精准突破_六大题型__高效培优期末专项训练_》官方解析
>
> > [!success]- **【答案】** C
>
> > [!note]- **【分析】**
> > 利用全称量词命题的否定是存在量词命题，再由它们必有一真一假，即可根据真命题，结合判别式大于或等于零求解参数范围·
>
> > [!note]- **【解析】**
> > 由 $p:\forall x\in R,x^{2}+4x+a\neq0$ 是假命题，
> >
> > 则 $\neg p:\exists x\in R,x^{2}+4x+a=0$ 是真命题，
> >
> > 即 $\Delta = 16 - 4a$ $0\Rightarrow a\leq 4$
> >
> > 所以实数 $a$ 的取值范围是 $(- \infty, 4]$
> >
> > 故选：C
> >
> > $$
> > A = \left\{x \mid - 3 \leq x \leq 7 \right\}
> > $$
> >
> > $$
> > B = \left\{x \mid 3 - 2 a \leq x \leq 2 a - 5 \right\}
> > $$
> >
> > $$
> > a \in \mathrm{R}
> > $$
> >
> > (1) 当 $a = 4$ 时，求 $\tilde{\mathfrak{Q}}_U(A \cup B)$
> >
> > (2)若命题“ $\forall x \in A \cup B$ ，都有 $x \in A$ ”是真命题，求实数 $a$ 的取值范围。
> >
> > 【答案】(1) $\{x\mid x<-5$ 或 $x>7\}$
> >
> > (2) $2 \leq a \leq 3$ .
> >
> > 【分析】（ $^{1}$ ）根据给定条件，利用集合的并集和补集运算定义求解·
> >
> > (2) 由已知可得 $B \subseteq A$ ，再结合 $B$ 非空列出不等式组求解.
> >
> > 【详解】（1）当 $a = 4$ 时， $B = \{x \mid -5 \leq x \leq 3\}$ ，而 $A = \{x \mid -3 \leq x \leq 7\}$ ，则 $A \cup B = \{x \mid -5 \leq x \leq 7\}$ ，所以 $\tilde{\mathfrak{Q}}_U(A \cup B) = \{x \mid x < -5$ 或 $x > 7\}$ .
> >
> > (2) 由命题“ $\forall x \in A \cup B$ ，都有 $x \in A$ ”是真命题，得 $B \subseteq A$ ，而 $B$ 为非空集合，
> >
> > 因此 $-3 \leq 3 - 2a \leq 2a - 5 \leq 7$ ，解得 $2 \leq a \leq 3$
> >
> > 所以实数 a 的取值范围是 $2 \leq a \leq 3$ .
