> [!faq]- 《专题01_集合高频题型精准突破_八大题型__高效培优期末专项训练_高一》官方解析
>
> > [!success]- **【答案】** ABC
>
> > [!note]- **【分析】**
> > 根据集合元素个数求子集个数判断 $^{A}$ ，根据交集运算结果求出参数范围判断 $^{BC}$ ，分类讨论判断 $^{D}$ .
>
> > [!note]- **【解析】**
> > 因为 $A = \left\{ x^2 - x - 2 = 0 \right\} = \{-1, 2\}$ ，所以集合 $A$ 的子集个数为 $2^2 = 4$ ，故 $\mathsf{A}$ 正确；
> >
> > 当 $A \cap B = \{2\}$ 时， $\left\{ \begin{array}{l} 2a - 2 > 0 \\ -a - 2 \leq 0 \end{array} \right.$ ，即 $a > 1$ ，故 ${}^{\mathrm{B}}$ 正确；
> >
> > 当 $A \cap B = \{-1\}$ 时， $\left\{ \begin{array}{l} -a - 2 > 0 \\ 2a - 2 \leq 0 \end{array} \right.$ ，即 $a < -2$ ，此时必有 $a \leq -2$ 成立，故 $C$ 正确；
> >
> > 对 D，当 a=0 时， $B=\varnothing$ ，满足 $A\cap B=\varnothing$ ，
> >
> > 当 $a > 0$ 时， $B = \left\{x \mid x > \frac{2}{a}\right\}$ ，当 $A \cap B = \varnothing$ 时， $\frac{2}{a} - 2$ ，即 $a \leq 1$ ，此时 $0 < a \leq 1$ ，
> >
> > 当 $a < 0$ 时， $B = \left\{x \mid x < \frac{2}{a}\right\}$ ，当 $A \cap B = \varnothing$ 时， $\frac{2}{a} \leq -1$ ，即 $a - 2$ ，此时 $-2 \leq a < 0$ ，
> >
> > 综上， $-2 \leq a \leq 1$ ，故 D 不正确。
> >
> > 故选 **ABC**
