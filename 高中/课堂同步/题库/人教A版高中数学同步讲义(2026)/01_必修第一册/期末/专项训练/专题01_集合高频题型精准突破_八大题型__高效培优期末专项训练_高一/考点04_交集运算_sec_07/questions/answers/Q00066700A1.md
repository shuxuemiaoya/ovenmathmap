> [!faq]- 《专题01_集合高频题型精准突破_八大题型__高效培优期末专项训练_高一》官方解析
>
> > [!success]- **【答案】** C
>
> > [!note]- **【分析】**
> > 根据题意得到 $B \subseteq A$ ，讨论 $a + 2 = 3$ 和 $a + 2 = a^2$ ，解方程并验证得到答案。
>
> > [!note]- **【解析】**
> > 若 $A \cap B = B$ ，则 $B \subseteq A$ ，故 $a + 2 = 3$ 或 $a + 2 = a^{2}$ .
> >
> > 当 $a + 2 = 3$ 时， $a = 1$ ，此时 $a^2 = 1$ ，集合 $A$ 不满足元素的互异性，舍去；
> >
> > 当 $a + 2 = a^2$ 时， $a = -1$ 或 $a = 2$
> >
> > a = -1 时， $a^{2} = 1$ ，集合 A 不满足元素的互异性，舍去；
> >
> > a=2 时， $A=\{1,3,4\},B=\{1,4\}$ ，满足条件。
> >
> > 综上所述： $a = 2$
> >
> > 故选 **C**.
