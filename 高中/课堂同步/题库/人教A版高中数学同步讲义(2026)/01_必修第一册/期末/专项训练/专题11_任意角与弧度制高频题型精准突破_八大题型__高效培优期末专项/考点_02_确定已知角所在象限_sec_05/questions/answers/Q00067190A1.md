> [!faq]- 《专题11_任意角与弧度制高频题型精准突破_八大题型__高效培优期末专项》官方解析
>
> > [!success]- **【答案】** C
>
> > [!note]- **【分析】**
> > 根据 $240^{\circ}$ 所在区域及象限角的定义判断得解·
>
> > [!note]- **【解析】**
> > 显然 $180^{\circ} < 240^{\circ} < 270^{\circ}$ ，所以 $240^{\circ}$ 是第三象限角·
> >
> > 故选：C
> >
> > 16. 命题“ $\exists \alpha < 0, \alpha$ 是第一象限角”的否定是（）
> >
> > 【答案】
> > A. $\exists \alpha = 0, \alpha$ 是第一象限角
> > B. $\exists \alpha < 0, \alpha$ 不是第一象限角
> > C. $\forall \alpha < 0, \alpha$ 是第一象限角
> > D. $\forall \alpha < 0, \alpha$ 不是第一象限角
> >
> > 【答案】D
> >
> > 【分析】存在量词命题的否定为全称量词命题·
> >
> > 【详解】存在量词命题的否定为全称量词命题，则命题“ $\exists \alpha < 0, \alpha$ 是第一象限角”的否定是 $\forall \alpha < 0, \alpha$ 不是第一象限角·
> >
> > 故选：D
> >
> > 考点03 确定 $\mathbf{n}$ 分角所在象限
