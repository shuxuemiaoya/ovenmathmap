> [!faq]- 《高一数学上学期期末模拟卷（必修第一册，高效培优·提升卷）》官方解析
>
> > [!success]- **【答案】** (1) $f(x) = \begin{cases} 45x^2 - 30x + 90, & 0 \leq x \leq 2 \\ \frac{540x}{x + 2} - 30x, & 2 < x \leq 5 \end{cases}$ (2)当施用肥料为 4 千克时，该水果单株利润最大，最大利润是 240 元
>
> > [!note]- **【解析】**
> > （1）由题意可得 $f(x) = 15W(x) - (10x + 20x) = 15W(x) - 30x$
> >
> > 即 $f(x) = \begin{cases} 45(x^2 + 2) - 30x, & 0 \leq x \leq 2 \\ \frac{540x}{x + 2} - 30x, & 2 < x \leq 5 \end{cases}$ ，整理得 $f(x) = f(x) = \begin{cases} 45x^2 - 30x + 90, & 0 \leq x \leq 2 \\ \frac{540x}{x + 2} - 30x, & 2 < x \leq 5 \end{cases}$ .
> >
> > (2) 当 $0 \leq x \leq 2$ 时， $f(x) = 45x^2 - 30x + 90$ 为对称轴 $x = \frac{1}{3}$ 开口向上的抛物线，
> >
> > 所以当 $0 \leq x \leq 2$ 时， $f(x)_{\max} = f(2) = 210$
> >
> > 当 $2 < x \leq 5$ 时， $f(x) = \frac{540x}{x + 2} - 30x = -30 \times \left(\frac{36}{x + 2} + x + 2\right) + 600$
> >
> > 因为 $\frac{36}{x+2} + x + 2$ $2\sqrt{\frac{36}{x+2} \times (x+2)} = 12$ ，当且仅当 $\frac{36}{x+2} = (x+2)$ 即 x = 4 取等号，
> >
> > 所以 $f(x) \leq -30 \times 12 + 600 = 240$ ，即 $f(x)_{\max} = 240$ ，
> >
> > 综上所述，当 $x = 4$ 时，该水果单株利润最大，最大利润是240元.
