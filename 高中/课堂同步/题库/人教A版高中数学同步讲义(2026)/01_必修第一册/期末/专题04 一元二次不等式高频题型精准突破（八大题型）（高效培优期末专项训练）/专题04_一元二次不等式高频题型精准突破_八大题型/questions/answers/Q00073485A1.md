> [!faq]- 《专题04 一元二次不等式高频题型精准突破（八大题型）（高效培优期末专项训练）》官方解析
>
> > [!success]- **【答案】** B
>
> > [!note]- **【分析】**
> > 由题意，命题的否定为真命题，根据 $x$ 的范围，整理可得 $a \leq \frac{x^2 + 2}{x + 1} = x + 1 + \frac{3}{x + 1} - 2$ ，根据基本不等式，化简计算，即可得答案：
>
> > [!note]- **【解析】**
> > 因为命题“ $\exists x \in [0,5], x^2 - ax + 2 - a < 0$ ”为假命题，
> >
> > 所以命题的否定 $\forall x\in[0,5],x^{2}-ax+2-a$ 0 为真命题，
> >
> > 则 $a + ax \leq x^2 + 2$ ，整理得 $a \leq \frac{x^2 + 2}{x + 1} = \frac{(x + 1)^2 - 2(x + 1) + 3}{x + 1} = x + 1 + \frac{3}{x + 1} - 2$ ，
> >
> > 因为 $x + 1 + \frac{3}{x + 1} -2\quad 2\sqrt{(x + 1)\cdot\left(\frac{3}{x + 1}\right)} -2 = 2\sqrt{3} -2$
> >
> > 当且仅当 $x + 1 = \frac{3}{x + 1}$ ，即 $x = \sqrt{3} - 1$ 时取等号，符合题意，
> >
> > 所以 $a \leq 2\sqrt{3} - 2$ ，则实数 $a$ 的取值范围是 $\left(-\infty, 2\sqrt{3} - 2\right]$ .
> >
> > 故选 **B**
