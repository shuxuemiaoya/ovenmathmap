> [!faq]- 《专题04 一元二次不等式高频题型精准突破（八大题型）（高效培优期末专项训练）》官方解析
>
> > [!success]- **【答案】** (1) $\left\{\begin{aligned}a&=8\\ b&=4\end{aligned}\right.$ ; (2) $-1 \leq a \leq 7$ ; (3)答案见详解·
>
> > [!note]- **【分析】**
> > （ $^{1}$ ）利用三个二次关系结合韦达定理计算参数即可；
> >
> > (2) 利用二次函数的性质计算即可;
> >
> > (3) 含着参数分类讨论计算即可·
>
> > [!note]- **【解析】**
> > （1）由题意可知 $x^{2} - (a - 3)x + 4 = 0$ 的两个解为 $1, b$
> >
> > 所以 $\left\{ \begin{array}{l} 1 + b = a - 3 \\ b = 4 \end{array} \right.$ ，所以 $\left\{ \begin{array}{l} a = 8 \\ b = 4 \end{array} \right.$ ；
> >
> > (2) 因为 $x^{2}-(a-3)x+4$ 0 恒成立，则 $\Delta=(a-3)^{2}-4\times4\leq0$
> >
> > 即 $(a - 3)^{2} \leq 4^{2}$ ，解之得 $-1 \leq a \leq 7$ ；
> >
> > (3) 原不等式等价于 $ax^{2} + (a - 3)x - 3 = (ax - 3)(x + 1) < 0$
> >
> > 若 $a = 0$ ，则 $x > -1$ ；
> >
> > 若 $a = -3$ ，则 $x \neq -1$ ；
> >
> > 若 a > 0 ，则 $\frac{3}{a} > x > -1$ ；
> >
> > 若 $-3 < a < 0$ ，则 $x < \frac{3}{a}$ 或 $x > -1$ ；
> >
> > 若 $-3 > a$ ，则 $x > \frac{3}{a}$ 或 $x < -1$ ；
> >
> > 综上所述： $a = 0$ 时，不等式的解集为 $\{x|x > - 1\}$ ； $a = -3$ 时，不等式的解集为 $\{x|x\neq -1\}$
> >
> > $a > 0$ 时，不等式的解集为 $\left\{x\mid -1 <   x <   \frac{3}{a}\right\}$ ； $a <   - 3$ 时，不等式的解集为 $\{x\mid x > \frac{3}{a}$ 或 $x <   - 1$
> >
> > -3 < a < 0 时，不等式的解集为 $\{x \mid x < \frac{3}{a}$ 或 $x > -1\}$ .
