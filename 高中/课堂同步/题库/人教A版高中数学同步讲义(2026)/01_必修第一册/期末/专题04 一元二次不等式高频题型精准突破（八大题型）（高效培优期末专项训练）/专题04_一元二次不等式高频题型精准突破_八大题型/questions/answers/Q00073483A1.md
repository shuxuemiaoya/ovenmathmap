> [!faq]- 《专题04 一元二次不等式高频题型精准突破（八大题型）（高效培优期末专项训练）》官方解析
>
> > [!success]- **【答案】** A．若关于 x 的方程 $x^{2} + (a^{2} - 1)x + a - 2 = 0$ 的一根比 1 大且另一根比 1 小，则 a 的取值范围是 -2 < a < 1 B．若关于 x 的不等式 $x^{2} - kx + k - 1 < 0$ 在 $(1,2)$ 上恒成立，则实数 k 的取值范围是 k < 3 C．若关于 x 的不等式 $ax - b > 0$ 的解集是 $(1, +\infty)$ ，则关于 x 的不等式 $\frac{ax + b}{x - 2} > 0$ 的解集是 $\left\{x \mid x > 2 \text{ 或 } x < -1\right\}$ D．若 $\frac{1}{a} +\frac{2}{b} = 1(a > 0,b > 0)$ ，则 $\frac{1}{a^2} +\frac{4}{b^2}$ 的最小值为 $\frac{1}{2}$
>
> > [!note]- **【分析】**
> > 对于 A，原问题等价于 $f(1)=1+(a^{2}-1)+a-2=a^{2}+a-2<0$ ，解一元二次不等式即可验证；对于 B，原问题等价于 $k>x+1$ 在 $(1,2)$ 上恒成立，由此即可验证；对于 C，首先得 a>0, a=b，然后解分式不等式即可验证；对于 D，首先由基本不等式得 $\frac{4}{ab}\leq\frac{1}{2}$ ，然后由 $\frac{1}{a^{2}}+\frac{4}{b^{2}}=\left(\frac{1}{a}+\frac{2}{b}\right)^{2}-\frac{4}{ab}=1-\frac{4}{ab}\quad1-\frac{1}{2}=\frac{1}{2}$ 即可验证，注意取等条件是否成立。
>
> > [!note]- **【解析】**
> > 对于 A，二次函数 $f(x)=x^{2}+(a^{2}-1)x+a-2$ ，开口向上，
> >
> > 若关于 $x$ 的方程 $x^{2} + (a^{2} - 1)x + a - 2 = 0$ 的一根比1大且另一根比1小，
> >
> > 则 $f(1) = 1 + (a^2 - 1) + a - 2 = a^2 + a - 2 < 0$ ，解得 $-2 < a < 1$ ，故 $\mathsf{A}$ 正确；
> >
> > 对于 $^{B}$ ，若关于 x 的不等式 $x^{2}-kx+k-1<0$ 在 $(1,2)$ 上恒成立，
> >
> > 则只需 $k(x - 1) > x^2 - 1$ ，即 $k > x + 1$ 在 $(1,2)$ 上恒成立即可，
> >
> > 则实数 $k$ 的取值范围是 $k = 3$ ，故 $\mathbf{B}$ 错误；
> >
> > 对于 $C$ ，若关于 $x$ 的不等式 $ax - b > 0$ 的解集是 $(1, +\infty)$ ，则 $a > 0, a = b$
> >
> > 所以关于 $x$ 的不等式 $\frac{ax + b}{x - 2} > 0 \Leftrightarrow \frac{x + 1}{x - 2} > 0 \Leftrightarrow x < -1$ 或 $x > 2$ ，故 $C$ 正确；
> >
> > 对于 D，若 $\frac{1}{a} + \frac{2}{b} = 1 (a > 0, b > 0)$ ，则 $\frac{1}{a} + \frac{2}{b} = 1 \quad 2\sqrt{\frac{2}{ab}}$ ，解得 $\frac{4}{ab} \leq \frac{1}{2}$ ，等号成立当且仅当 a = 2, b = 4，
> >
> > 所以 $\frac{1}{a^2} +\frac{4}{b^2} = \left(\frac{1}{a} +\frac{2}{b}\right)^2 -\frac{4}{ab} = 1 - \frac{4}{ab}$ $1 - \frac{1}{2} = \frac{1}{2}$ ，等号成立当且仅当 $a = 2,b = 4$ ，故D正确·
> >
> > 故选：ACD.
