> [!faq]- 《专题04 一元二次不等式高频题型精准突破（八大题型）（高效培优期末专项训练）》官方解析
>
> > [!success]- **【答案】** D
>
> > [!note]- **【分析】**
> > 由一元二次不等式的解集得到 $a < 0$ ， $\left\{ \begin{array}{l}b = -2a > 0\\ c = -3a > 0 \end{array} \right.$ ，再依次判断A、B、C，再由一元二次不等式的解法求解集判断D.
>
> > [!note]- **【解析】**
> > 由题设-1,3是 $ax^{2}+bx+c=0$ 的两个根，且a<0，A错，
> >
> > 所以 $\left\{ \begin{array}{l} -\frac{b}{a} = 2 \\ \frac{c}{a} = -3 \end{array} \right. \Rightarrow \left\{ \begin{array}{l} b = -2a > 0 \\ c = -3a > 0 \end{array} \right.$ ，故 $a + b + c = -4a > 0$ ，B、C错，
> >
> > 由 $-3ax^{2} + 2ax + a < 0 \Leftrightarrow 3x^{2} - 2x - 1 < 0 \Leftrightarrow (3x + 1)(x - 1) < 0 \Leftrightarrow -\frac{1}{3} < x < 1$ ，D对.
> >
> > 故选 **D**
