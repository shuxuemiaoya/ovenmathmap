> [!faq]- 《专题04 一元二次不等式高频题型精准突破（八大题型）（高效培优期末专项训练）》官方解析
>
> > [!success]- **【答案】** B
>
> > [!note]- **【分析】**
> > 按照 $a = 0$ 、 $a > 0$ 和 $a < 0$ 分类讨论，按照二次方程根的分布列不等式组求解即可。
>
> > [!note]- **【解析】**
> > 当 $a = 0$ 时，方程 $-x + 3 = 0$ 只有一个根，显然不符合题意；
> >
> > 当时，则 $\left\{ \begin{array}{l} -2 < \frac{a + 1}{2a} < 3 \\ \Delta = (a + 1)^2 - 4a(3 - 2a) > 0 \\ a(-2)^2 - (a + 1)(-2) - 2a + 3 > 0 \\ a \cdot 3^2 - 3(a + 1) - 2a + 3 > 0, \end{array} \right.$ ，解得； $a > 0$
> >
> > 当时，则 $\left\{ \begin{array}{l} -2 < \frac{a + 1}{2a} < 3 \\ \Delta = (a + 1)^2 - 4a(3 - 2a) > 0 \\ a(-2)^2 - (a + 1)(-2) - 2a + 3 < 0 \\ a \cdot 3^2 - 3(a + 1) - 2a + 3 < 0, \end{array} \right.$ ，解得 $a < -\frac{5}{4}$
> >
> > 故 $a \in \{\phi, a > 1$ 或 $a < -\frac{5}{4}\}$
> >
> > 故选 **B**
