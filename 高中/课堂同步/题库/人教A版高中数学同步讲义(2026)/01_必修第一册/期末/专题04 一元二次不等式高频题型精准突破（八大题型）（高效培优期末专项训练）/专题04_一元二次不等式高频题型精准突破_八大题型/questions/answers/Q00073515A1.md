> [!faq]- 《专题04 一元二次不等式高频题型精准突破（八大题型）（高效培优期末专项训练）》官方解析
>
> > [!success]- **【答案】** A．已知a>b>0，则 $a^{2}>ab>b^{2}$ B．已知a>b>0,c<0，则 $a(c-1)>b(c-1)$ C．若a>b>0>c>d，则ab>cd D．若a<b<0，则 $\frac{1}{a}>\frac{1}{b}$
>
> > [!note]- **【分析】**
> > 利用不等式性质可判断 ABD；利用赋值法可判断 C.
>
> > [!note]- **【解析】**
> > A选项：∵ a > b > 0, $a > 0 \Rightarrow a^{2} > ab$ ，又∵ a > b > 0, $b > 0 \Rightarrow ab > b^{2}$ ，则 $a^{2} > ab > b^{2}$ ，故 A 正确；
> >
> > B 选项：∵ $c < 0 \Rightarrow c + (-1) < -1 < 0$ ，则 $a(c - 1) < b(c - 1)$ ，故 B 错误；
> >
> > 对于 $C$ ，若 $a > b > 0 > c > d$ ，当 $a = 2, b = 1, c = -2, d = -3$ ，则 $ab = 2 < cd = 6$ ，故 $C$ 不正确；
> >
> > 对于 D，若 a < b < 0，则 $\frac{1}{ab} > 0$ ，则 $a \cdot \frac{1}{ab} < b \cdot \frac{1}{ab} < 0$ ，即 $\frac{1}{b} < \frac{1}{a}$ ，故 D 正确。
> >
> > 故选 **AD**.
