> [!faq]- 《专题04 一元二次不等式高频题型精准突破（八大题型）（高效培优期末专项训练）》官方解析
>
> > [!success]- **【答案】** (1)答案见解析； (2) $(- \frac{3}{7}, 0)$ .
>
> > [!note]- **【分析】**
> > （ $^{1}$ ）根据题意，利用含参数的一元二次不等式的解法，分类讨论，即可求解；
> >
> > (2) 根据题意，转化为不等式 $ax^2 - (a + 1)x + 1 + a > 0$ 在 $[-2, -1]$ 上恒成立，结合二次函数的图象与性质，列出不等式组，即可求解.
>
> > [!note]- **【解析】**
> > （1）解：由不等式 $ax^2 -(a + 1)x + 1\quad 0$
> >
> > 若 $a = 0$ ，不等式即为 $-x + 1\quad 0$ ，解得 $x\leq 1$ ，即不等式的解集为 $\{x\mid x\leq 1\}$
> >
> > 若 $a \neq 0$ ，不等式可化为 $(ax - 1)(x - 1) = 0$ ，即 $a(x - \frac{1}{a})(x - 1) = 0$
> >
> > 此时方程 $a(x - \frac{1}{a})(x - 1) = 0$ 的两根分别为 $x_{1} = 1, x_{2} = \frac{1}{a}$ ，
> >
> > 当 $a < 0$ 时，不等式即为 $(x - \frac{1}{a})(x - 1) \leq 0$ ，解得 $\frac{1}{a} \leq x \leq 1$ ，解集为 $\{x \mid \frac{1}{a} \leq x \leq 1\}$
> >
> > 当 $a > 0$ 时，不等式即为 $(x - \frac{1}{a})(x - 1) = 0$
> >
> > 若 $0 < a < 1$ ，可得 $\frac{1}{a} > 1$ ，解得 $x \leq 1$ 或 $x = \frac{1}{a}$ ，不等式的解集为 $\{x \mid x \leq 1$ 或 $x = \frac{1}{a}\}$
> >
> > 若 $a = 1$ ，可得 $\frac{1}{a} = 1$ ，不等式即为 $(x - 1)^2$ 0，此时不等式的解集为 $\mathbb{R}$
> >
> > 若 $a > 1$ ，可得 $\frac{1}{a} < 1$ ，解得 $x - 1$ 或 $x \leq \frac{1}{a}$ ，不等式的解集为 $\{x \mid x \leq \frac{1}{a} \text{或} x - 1\}$ ，
> >
> > 综上可得：
> >
> > 当 $a < 0$ 时，不等式的解集为 $\{x\mid \frac{1}{a}\leq x\leq 1\}$
> >
> > 当 a = 0 时不等式的解集为 $\{x \mid x \leq 1\}$ ;
> >
> > 当 $0 < a < 1$ 时，不等式的解集为 $\{x \mid x \leq 1 \text{ 或 } x \frac{1}{a}\}$ ；
> >
> > 当 a=1 时，不等式的解集为 R；
> >
> > 当 $a > 1$ 时，不等式的解集为 $\{x\mid x\leq \frac{1}{a}$ 或 $x - 1\}$
> >
> > (2) 解：由不等式 $y > -a$ ，可得 $ax^2 - (a + 1)x + 1 > -a$ ，即 $ax^2 - (a + 1)x + 1 + a > 0$
> >
> > 因为 $a < 0$ 时，集合 $A = \{x \mid -2 \leq x \leq -1\}, B = \{x \mid y > -a\}$ ，且 $A \subseteq B$
> >
> > 所以不等式 $ax^2 - (a + 1)x + 1 + a > 0$ 在 $[-2, -1]$ 上恒成立，
> >
> > 设 $f(x) = ax^{2} - (a + 1)x + 1 + a, a < 0$
> >
> > 则满足 $\left\{\begin{aligned}f(-2)&=4a+2(a+1)+1+a>0\\ f(-1)&=a+(a+1)+1+a>0\\ a&<0\end{aligned}\right.$ ，解得 $-\frac{3}{7}<a<0$ ，
> >
> > 即实数 a 的取值范围为 $(- \frac{3}{7}, 0)$ .
