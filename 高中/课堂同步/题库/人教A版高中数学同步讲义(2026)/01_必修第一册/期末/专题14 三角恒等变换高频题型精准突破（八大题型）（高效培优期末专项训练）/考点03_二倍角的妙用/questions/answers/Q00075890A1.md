> [!faq]- 《专题14 三角恒等变换高频题型精准突破（八大题型）（高效培优期末专项训练）》官方解析
>
> > [!success]- **【答案】** $\frac{1}{2}/0.5$
>
> > [!note]- **【分析】**
> > 方法一：先利用二倍角公式，结合同角三角函数的基本关系，求出 $\tan x$ ，再利用二倍角公式结合弦化切进行求值·
> >
> > 方法二：分子分母同乘以 $1+\sin2x$ ，利用平方关系求值·
>
> > [!note]- **【解析】**
> > 法 $1: \frac{1}{2} = \frac{\cos 2x}{1 - \sin 2x} = \frac{\cos^2 x - \sin^2 x}{\sin^2 x + \cos^2 x - 2\sin x\cos x} = \frac{(\sin x + \cos x)(\cos x - \sin x)}{(\cos x - \sin x)^2}$
> >
> > $= \frac{\cos x + \sin x}{\cos x - \sin x} = \frac{\tan x + 1}{1 - \tan x}$ ，解得： $\tan x = -\frac{1}{3}$
> >
> > $$
> > \frac {1 + \sin 2 x}{\cos 2 x} = \frac {\sin^ {2} x + \cos^ {2} x + 2 \sin x \cos x}{\cos^ {2} x - \sin^ {2} x} = \frac {(\sin x + \cos x) ^ {2}}{(\sin x + \cos x) (\cos x - \sin x)} = \frac {\cos x + \sin x}{\cos x - \sin x} = \frac {\tan x + 1}{1 - \tan x} = \frac {1}{2}.
> > $$
> >
> > 法 $^{2}$ : $\sin^{2}2x + \cos^{2}2x = 1$
> >
> > $$
> > \therefore \cos^ {2} 2 x = 1 - \sin^ {2} 2 x = (1 + \sin 2 x) (1 - \sin 2 x)
> > $$
> >
> > 又 $1-\sin2x\neq0,\cos2x\neq0,\therefore\frac{1+\sin2x}{\cos2x}=\frac{\cos2x}{1-\sin2x}=\frac{1}{2}.$
> >
> > 故答案为： $\frac{1}{2}$
