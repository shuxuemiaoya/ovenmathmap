> [!faq]- 《专题14 三角恒等变换高频题型精准突破（八大题型）（高效培优期末专项训练）》官方解析
>
> > [!success]- **【答案】** A $\sin^{2}A + \sin^{2}C > \sin^{2}B$ B $AB \cdot BC < 0$ C. $\frac{c}{b} < \cos A$ D. $0 < \tan A\tan C < 1$
>
> > [!note]- **【分析】**
> > 结合正弦定理、余弦定理、向量运算、三角恒等变换确定正确选项·
>
> > [!note]- **【解析】**
> > A选项，由正弦定理得 $a^2 + c^2 > b^2, \cos B = \frac{a^2 + c^2 - b^2}{2ac} > 0 \Rightarrow B$ 为锐角.
> >
> > B 选项， $AB \cdot BC = |AB| \cdot |BC| \cdot \cos(\pi - B) = -|AB| \cdot |BC| \cdot \cos B < 0, \cos B > 0 \Rightarrow B$ 为锐角.
> >
> > C 选项，由余弦定理得 $\frac{c}{b} < \frac{b^2 + c^2 - a^2}{2bc}$ ， $c^2 + a^2 < b^2$ ， $\cos B = \frac{a^2 + c^2 - b^2}{2ac} < 0 \Rightarrow B$ 为钝角。
> >
> > D 选项， $0 < \tan A \tan C < 1, 0 < \frac{\sin A \sin C}{\cos A \cos C} < 1$ ，由于三角形中，最多只有一个钝角，所以 $\cos A > 0, \cos C > 0$ ，
> > 则 $\sin A \sin C < \cos A \cos C, \cos(A + C) > 0$ ，即 $-\cos B > 0, \cos B < 0$ ，B 为钝角.
> >
> > 故选 **CD**
