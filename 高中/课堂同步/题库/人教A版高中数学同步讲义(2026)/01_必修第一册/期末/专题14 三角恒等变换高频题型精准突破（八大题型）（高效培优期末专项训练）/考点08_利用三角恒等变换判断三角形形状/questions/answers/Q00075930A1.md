> [!faq]- 《专题14 三角恒等变换高频题型精准突破（八大题型）（高效培优期末专项训练）》官方解析
>
> > [!success]- **【答案】** A
>
> > [!note]- **【分析】**
> > 由二倍角公式可得， $\cos^2 \frac{A}{2} = \frac{1}{2}(1 + \cos A)$ ，再根据诱导公式可得 $\cos A = -\cos (B + C)$ ，然后利用两角和与差的余弦公式，即可将 $\sin B \sin C = \cos^2 \frac{A}{2}$ 化简成 $\cos (B - C) = 1$ ，所以 $B = C$ ，即可求得答案．
>
> > [!note]- **【解析】**
> > 因为 $\sin B \sin C = \cos^2 \frac{A}{2} = \frac{1}{2}(1 + \cos A) = \frac{1}{2}[1 - \cos (B + C)]$ ， $\cos (B + C) = \cos B \cos C - \sin B \sin C$ ，
> >
> > 所以， $\cos B \cos C + \sin B \sin C = 1$ ，即 $\cos (B - C) = 1$ ，
> >
> > 因为 $B, C \in (0, \pi)$ ，所以 $B - C \in (-\pi, \pi)$ 所以 $B = C$ ，即 VABC 为等腰三角形·
> >
> > 故选 **A**.
