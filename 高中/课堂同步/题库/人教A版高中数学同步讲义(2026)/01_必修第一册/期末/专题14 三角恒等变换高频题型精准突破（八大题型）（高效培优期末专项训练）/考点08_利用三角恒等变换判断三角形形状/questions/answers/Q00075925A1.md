> [!faq]- 《专题14 三角恒等变换高频题型精准突破（八大题型）（高效培优期末专项训练）》官方解析
>
> > [!success]- **【答案】** C
>
> > [!note]- **【分析】**
> > 根据两角和与差的余弦公式可得 $\sin A\sin B = -\frac{1}{2}\left[\cos (A + B) - \cos (A - B)\right]$ ，再结合诱导公式化简计算得出结果。
>
> > [!note]- **【解析】**
> > 因为 $\cos(A+B)=\cos A\cos B-\sin A\sin B$ $\cos (A - B) = \cos A\cos B + \sin A\sin B$ 所以 $\sin A\sin B = -\frac{1}{2}\big[\cos (A + B) - \cos (A - B)\big]$ ，
> > 因为 $\sin A\sin B = \frac{1}{2}\big(1 + \cos C\big)$ 则 $-\frac{1}{2}\big[\cos (A + B) - \cos (A - B)\big] = \frac{1}{2}\big(1 + \cos C\big)$ 又 $A + B = \pi -C$ ，
> > 所以 $\cos C = -\cos (A + B)$ 所以 $-\frac{1}{2}\big[\cos (A + B) - \cos (A - B)\big] = \frac{1}{2}\big[1 - \cos (A + B)\big]$ 所以 $\cos (A - B) = 1$ 又 $A,B$ 为△ABC的内角，所以 $A - B = 0$ 所以 $A = B$ ，故△ABC为等腰三角形.
> >
> > 故选 **C**.
