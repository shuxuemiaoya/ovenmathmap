> [!faq]- 《专题14 三角恒等变换高频题型精准突破（八大题型）（高效培优期末专项训练）》官方解析
>
> > [!success]- **【答案】** (1) $y_{0}=3\sqrt{3}$ (2)增区间为 $\left[-\frac{5\pi}{12} + k\pi, \frac{\pi}{12} + k\pi\right](k \in \mathbf{Z})$ ，值域为 $[3 - 2\sqrt{3}, 3 + 2\sqrt{3}]$
>
> > [!note]- **【分析】**
> > （1）利用诱导公式得出 $\sin \theta = \frac{\sqrt{3}}{2}$ ，再利用三角函数的定义可得出关于 $y_0$ 的等式，解出 $y_0$ 即可；（2）由（1）得出 $\tan \theta = \sqrt{3}$ ，利用三角恒等变换化简函数解析式为 $f(x) = 2\sqrt{3} \sin \left(2x + \frac{\pi}{3}\right) + 3$ ，利用正弦型函数的单调性可得出函数 $f(x)$ 的增区间，利用正弦型函数的值域可得出函数 $f(x)$ 的值域。
>
> > [!note]- **【解析】**
> > （1）因为 $\sin (\pi -\theta) = \frac{\sqrt{3}}{2}$ ，且 $\sin (\pi -\theta) = \sin \theta$ ，所以 $\sin \theta = \frac{\sqrt{3}}{2}$
> >
> > 因为角 $\theta$ 的终边经过点 $P(3, y_0)$ ，所以 $\sin \theta = \frac{y_0}{\sqrt{9 + y_0^2}} = \frac{\sqrt{3}}{2}$ ，解得 $y_0 = 3\sqrt{3}$ 。
> >
> > (2) 由 (1) 得 $\tan \theta = \frac{y_0}{3} = \sqrt{3}$
> >
> > 所以 $f(x) = \sqrt{3}\sin 2x + 6\cos^2 x = \sqrt{3}\sin 2x + 3\cos 2x + 3 = 2\sqrt{3}\sin \left(2x + \frac{\pi}{3}\right) + 3.$
> >
> > 令 $-\frac{\pi}{2} + 2k\pi \leq 2x + \frac{\pi}{3} \leq \frac{\pi}{2} + 2k\pi$ ， $k \in \mathbf{Z}$ ，得 $-\frac{5\pi}{12} + k\pi \leq x \leq \frac{\pi}{12} + k\pi$ ， $k \in \mathbf{Z}$ ，
> >
> > 所以 $f(x)$ 的单调递增区间为 $\left[-\frac{5\pi}{12} + k\pi, \frac{\pi}{12} + k\pi\right]$ ， $k \in \mathbf{Z}$ 。
> >
> > 因为 $-1 \leq \sin \left(2x + \frac{\pi}{3}\right) \leq 1$ ，所以 $3 - 2\sqrt{3} \leq 2\sqrt{3} \sin \left(2x + \frac{\pi}{3}\right) + 3 \leq 3 + 2\sqrt{3}$
> >
> > 即 $f(x)$ 的值域为 $\left[3 - 2\sqrt{3}, 3 + 2\sqrt{3}\right]$
