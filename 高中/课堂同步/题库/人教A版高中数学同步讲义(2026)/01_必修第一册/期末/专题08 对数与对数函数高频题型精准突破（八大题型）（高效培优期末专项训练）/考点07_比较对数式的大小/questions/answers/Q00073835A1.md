> [!faq]- 《专题08 对数与对数函数高频题型精准突破（八大题型）（高效培优期末专项训练）》官方解析
>
> > [!success]- **【答案】** D
>
> > [!note]- **【分析】**
> > 根据对数函数的性质进行比较即可·
>
> > [!note]- **【解析】**
> > $a = \log_{0.2}0.3 < \log_{0.2}0.2 = 1$ ， $b = \log_23 > \log_22\sqrt{2} = \log_22^{\frac{3}{2}} = \frac{3}{2}$
> >
> > $$
> > 1 = \log_ {3} 3 <   c = \log_ {3} 4 <   \log_ {3} 3 \sqrt {3} = \log_ {3} 3 ^ {\frac {3}{2}} = \frac {3}{2}, \therefore b > c > a.
> > $$
> >
> > 故选：D.
> >
> > 54. 函数 $f(x) = |\lg x|$ ，若 $a = f(0.1), b = f(1), c = f(2)$ ，则（）A. $a < b < c$ B. $c < b < a$ C. $b < a < c$ D. $b < c < a$
> >
> > 【答案】D
> >
> > 【分析】结合对数运算得 $a = f(0.1) = f(10)$ ，再利用对数函数单调性比较大小即可。【详解】因为 $f(x) = |\lg x|$ ，所以 $a = f(0.1) = |\lg 0.1| = |- \lg 10| = |\lg 10| = f(10)$ ，
> >
> > 又当 $x$ 1时， $f(x) = |\lg x| = \lg x$ 在 $[1, +\infty)$ 上单调递增，所以 $f(10) > f(2) > f(1)$ ，即 $b < c < a$
> >
> > 故选 **D**
