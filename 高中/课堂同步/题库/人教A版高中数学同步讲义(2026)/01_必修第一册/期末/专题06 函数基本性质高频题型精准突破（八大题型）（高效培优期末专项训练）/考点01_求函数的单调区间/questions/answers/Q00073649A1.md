> [!faq]- 《专题06 函数基本性质高频题型精准突破（八大题型）（高效培优期末专项训练）》官方解析
>
> > [!success]- **【答案】** (1) $(-1,0)$ ， $(0,+\infty)$ (2) $g(a) = \left\{ \begin{array}{ll}a - 2,a & \frac{7}{4}\\ \frac{3}{2} -a,a < \frac{7}{4} \end{array} \right.$
>
> > [!note]- **【分析】**
> > （1）当 $a = 1$ 时，将函数 $f(x)$ 写为分段函数的形式，结合 $y = x - \frac{1}{x}, y = x + \frac{1}{x}$ 的单调性，写出函数的单调递增区间·
> >
> > (2) 对 $a$ 分成 $a = 2, a \leq 0, 0 < a < 2$ 三种情况，结合函数 $f(x)$ 的解析式，讨论函数的最大值，由此求得 $g(a)$ 的解析式.
>
> > [!note]- **【解析】**
> > （1）当时， $f(x)=|x-1|-\frac{1}{x}=\left\{\begin{aligned}&x-\frac{1}{x}-1,x>1\\&1-\left(x+\frac{1}{x}\right),x\leq1\text{且}x\neq0\end{aligned}\right.$
> >
> > 当 $x > 1$ 时，易得 $f(x) = x - \frac{1}{x} - 1$ 单调递增；
> >
> > 当 $x \leq 1$ 时， $f(x) = 1 - \left(x + \frac{1}{x}\right)$ ，
> >
> > 因为对勾函数 $y = x + \frac{1}{x}$ 在 $(- \infty, -1), (1, +\infty)$ 上单调递增，在 $(-1, 0), (0, 1)$ 上单调递减，
> >
> > 所以 $f(x)$ 在 $(-1,0),(0,1)$ 上单调递增，
> >
> > 又当 $x = 1$ 时， $1 - \frac{1}{1} - 1 = 1 - \left(1 + \frac{1}{1}\right)$ ，所以 $f(x)$ 在 $(0, +\infty)$ 上单调递增，
> >
> > 综上， $f(x)$ 的单调递增区间为 $(-1,0)$ ， $(0,+\infty)$ .
> >
> > (2) 因为 $x \in (0, 2]$ ,
> >
> > 当 $a$ 2时， $x \leq a$ ，则 $f(x) = -x - \frac{1}{x} + a = a - \left(x + \frac{1}{x}\right)$ ，
> >
> > 根据对勾函数的单调性可知 $f(x)$ 在 $(0,1)$ 上单调递增，在 $(1,2]$ 上单调递减，
> >
> > 所以 $g(a)=f(x)_{\max}=f(1)=a-2$ ;
> >
> > 当 $a \leq 0$ 时， $x - a$ ，则 $f(x) = x - \frac{1}{x} - a$ ，显然 $f(x)$ 在 $(0,2]$ 上单调递增，
> >
> > 所以 $g(a) = f(x)_{\max} = f(2) = \frac{3}{2} - a$
> >
> > 当时， $f(x) = \left\{ \begin{array}{l}x - \frac{1}{x} -a,a <   x\leq 2\\ a - \left(x + \frac{1}{x}\right),0 <   x\leq a \end{array} \right.$
> >
> > 当 $a < x \leq 2$ 时， $f(x) = x - \frac{1}{x} - a$ 单调递增，故 $f(x)_{\max} = f(2) > f(a)$ ，当 $0 < x \leq a$ 时， $f(x) = a - \left(x + \frac{1}{x}\right)$ ，
> >
> > 若 $a \leq 1$ 时，则 $f(x)_{\max} = f(a)$ ；若 $a > 1$ 时，则 $f(x)_{\max} = f(1) = a - 2$ ；
> >
> > 所以当 $a \leq 1$ 时， $g(a) = f(2) = \frac{3}{2} - a$ ；
> >
> > 若 $1 < a < 2$ 时， $g(a) = \max \left\{f(1), f(2)\right\}$ ，又 $f(1) = a - 2$ ， $f(2) = \frac{3}{2} - a$ ，
> >
> > 当 $a - 2\frac{3}{2} -a$ ，即 $\frac{7}{4}\leq a <   2$ 时， $g(a) = f(1)$
> >
> > 当 $a - 2 < \frac{3}{2} - a$ ，即 $1 < a < \frac{7}{4}$ 时， $g(a) = f(2)$ ；
> >
> > 综上， $g(a)=\left\{\begin{aligned}&a-2,a&\frac{7}{4}\\ &\frac{3}{2}-a,a<\frac{7}{4}\end{aligned}\right.$
