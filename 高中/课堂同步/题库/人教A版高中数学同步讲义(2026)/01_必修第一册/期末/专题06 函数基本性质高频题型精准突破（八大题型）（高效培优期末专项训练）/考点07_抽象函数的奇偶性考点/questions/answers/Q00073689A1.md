> [!faq]- 《专题06 函数基本性质高频题型精准突破（八大题型）（高效培优期末专项训练）》官方解析
>
> > [!success]- **【答案】** BCD
>
> > [!note]- **【分析】**
> > 对于 A，通过 x = y = 0 即可求解，对于 B，先令 x = 1，y = -1 得到 $f(-1) = -4050$ ，再令 x = y = -1 即可求解；对于 C，先确定当 x > 0 时， $f(x) > -2025$ ，再通过函数单调性定义即可判断，对于 D，令 $g(x) = f(x) + 2025$ ，先确定 $g(x + y) = g(x) + g(y)$ ，再令 y = -x，即可判断。
>
> > [!note]- **【解析】**
> > 对于 A 选项，对任意的实数 x、y 满足 $f(x + y) = f(x) + f(y) + 2025$ ，
> > 令 x = y = 0 可得 $f(0) = 2f(0) + 2025$ ，解得 $f(0) = -2025$ ，A 错；
> >
> > 对于 B 选项，令 x=1 ，y=-1 可得 $f(0)=f(1)+f(-1)+2025$
> >
> > 即 $-2025 = 0 + f(-1) + 2025$
> >
> > 解得 $f(-1) = -4050$
> >
> > 再令 $x = y = -1$ 可得 $f(-2) = 2f(-1) + 2005 = 2 \times (-4050) + 2025 = -6075$ ，B对；
> >
> > 对于 $C$ 选项，由题意可知，当 $x > 1$ 时， $f(x) > 0$
> >
> > $x - 1 > 0$ 时， $f(x - 1) = f(x) + f(-1) + 2025 = f(x) - 2025 > -2025$
> >
> > 故当 x > 0 时， $f(x) > -2025$ ，
> >
> > 任取 $x_{1}, x_{2} \in R$ 且 $x_{1} < x_{2}$
> >
> > 则 $f(x_{2}) = f(x_{2} - x_{1}) + f(x_{1}) + 2025 > -2025 + f(x_{1}) + 2025 > f(x_{1})$
> >
> > 即函数 $f(x)$ 在 $\mathbf{R}$ 上为增函数， $C$ 对.
> >
> > 对于 D 选项，令 $g(x)=f(x)+2025$
> >
> > 由 $f(x+y)=f(x)+f(y)+2025$
> >
> > 可得 $f(x+y)+2025=f(x)+2025+f(y)+2025$
> >
> > 即 $g(x + y) = g(x) + g(y)$
> >
> > 且 $g(0) = f(0) + 2025 = 0$
> >
> > 令 $y = -x$ ，则 $g(x) + g(-x) = g(0) = 0$ ，即 $g(-x) = -g(x)$ ，
> >
> > 所以，函数 $g(x)=f(x)+2025$ 为奇函数，D 对；
> >
> > 故选 **BCD**
