> [!faq]- 《专题01 函数的概念及其表示的四大常考题型（高效培优专项训练）》官方解析
>
> > [!success]- **【答案】** D
>
> > [!note]- **【解析】**
> > 对于选项 A， $x\left|\operatorname{sgn}x\right|=\begin{cases}x,x\neq0\\0,x=0\end{cases}$ ， $\left|x\right|=\begin{cases}x,x&0\\-x,x<0\end{cases}$ ，故 $\left|x\right|\neq x\left|\operatorname{sgn}x\right|$ ，故 A 不正确；
> >
> > 对于选项 B， $x \operatorname{sgn} |x| = \begin{cases} x, & x \neq 0 \\ 0, & x = 0 \end{cases}$ ， $|x| = \begin{cases} x, & x = 0 \\ -x, & x < 0 \end{cases}$ ，故 $|x| \neq x \operatorname{sgn} |x|$ ，故 B 不正确；
> >
> > 对于选项C， $|x|\mathrm{sgn}x = \left\{ \begin{array}{ll}x,x\neq 0\\ 0,x = 0 \end{array} \right.$ ， $|x| = \left\{ \begin{array}{ll}x,x & 0\\ -x,x <   0 \end{array} \right.$ ，故 $|x|\neq |x|\mathrm{sgn}x$ ，故C不正确；
> >
> > 对于选项D， $x\mathrm{sgn}x = \left\{ \begin{array}{ll}x,x > 0\\ 0,x = 0\\ -x,x <   0 \end{array} \right.$ $= \left\{ \begin{array}{ll}x,x & 0\\ -x,x <   0 \end{array} \right.,|x|\equiv \left\{ \begin{array}{ll}x,x & 0\\ -x,x <   0 \end{array} \right.$ ，故，故D正确.
> >
> > 故选 **D**.
