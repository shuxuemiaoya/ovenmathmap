> [!faq]- 《专题01 函数的概念及其表示的四大常考题型（高效培优专项训练）》官方解析
>
> > [!success]- **【答案】** A. $f(f(-1)) = 1$ B. 若 $f(x) = 3$ ，则 $x$ 的值是 $\sqrt{3}$ C. $f(x) < 1$ 的解集为 $(-\infty, 1)$ D. $f(x)$ 的值域为 $(-\infty, 4)$
>
> > [!note]- **【解析】**
> > 对于 $\mathsf{A}$ ，因为 $f(x) = \begin{cases} x + 2, & x \leq -1 \\ x^2, & -1 < x < 2 \end{cases}$ ，则 $f(-1) = -1 + 2 = 1$ ，所以 $f(f(-1)) = f(1) = 1^2 = 1$ ，故 $\mathsf{A}$ 正确；
> >
> > 对于 B，当 $x \leq -1$ 时， $f(x) = x + 2 = 3$ ，解得：x = 1（舍）；
> > 当 -1 < x < 2 时， $f(x) = x^{2} = 3$ ，解得： $x = -\sqrt{3}$ （舍）或 $x = \sqrt{3}$ ；
> > ∴ $f(x)=3$ 的解为 $x=\sqrt{3}$ ，故 B 正确；
> > 对于 C，当 $x \leq -1$ 时， $f(x)=x+2<1$ ，解得：x<-1；
> > 当 -1 < x < 2 时， $f(x)=x^{2}<1$ ，解得：-1 < x < 1；
> > ∴ $f(x) < 1$ 的解集为 $(-∞, -1) ∪ (-1, 1)$ ，故 C 错误；
> > 对于 D，当 $x \leq -1$ 时， $f(x)=x+2 \leq -1+2=1$ ；
> > 当 -1 < x < 2 时， $f(x)=x^{2} \in [0,4)$ ；
> > ∴ $f(x)$ 的值域为 $(-∞,4)$ ，故 D 正确。
> >
> > 故选 **ABD**.
