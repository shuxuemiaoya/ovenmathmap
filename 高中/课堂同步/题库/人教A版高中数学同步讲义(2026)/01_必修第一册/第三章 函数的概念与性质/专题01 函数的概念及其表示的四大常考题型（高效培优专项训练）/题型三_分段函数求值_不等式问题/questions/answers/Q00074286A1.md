> [!faq]- 《专题01 函数的概念及其表示的四大常考题型（高效培优专项训练）》官方解析
>
> > [!success]- **【答案】** ACD
>
> > [!note]- **【解析】**
> > 注意到 $x + 1 \leq x^2 - 2x - 3 \Rightarrow x \leq -1$ 或 $x - 4, x + 1 > x^2 - 2x - 3 \Rightarrow -1 < x < 4$ .
> >
> > 则 $M(x) = \begin{cases} x + 1, & x \in (-\infty, -1] \cup [4, +\infty) \\ x^2 - 2x - 3, & x \in (-1, 4) \end{cases}$ .
> >
> > A 选项， $M(2)=2^{2}-2\times2-3=-3$ ，故 A 正确.
> >
> > B 选项，由 $M(x) = \begin{cases} x + 1, & x \in (-\infty, -1] \cup [4, +\infty) \\ x^2 - 2x - 3, & x \in (-1, 4) \end{cases}$ 可知 $M(x)$ 无最小值，无最大值，故 B 错误；
> >
> > C 选项，当 $x \in (-\infty, -1] \cup [4, +\infty)$ 时， $M(x) < -4 \Rightarrow x + 1 < -4 \Rightarrow x < -5$ ；
> >
> > 当 $x \in (-1, 4)$ 时， $M(x) < -4 \Rightarrow x^2 - 2x - 3 < -4 \Rightarrow x$ 不存在.
> >
> > 综上，不等式 $M(x) < -4$ 的解集是 $(- \infty, -5)$ ，故 $C$ 正确；
> >
> > D 选项，当 $x \in (-\infty, -1] \cup [4, +\infty)$ 时， $M(x) + 1 = 0 \Rightarrow x + 1 + 1 = 0 \Rightarrow x = -2$ ；
> >
> > 当 $x \in (-1, 4)$ 时， $M(x) + 1 = 0 \Rightarrow x^2 - 2x - 3 + 1 = x^2 - 2x - 2 = 0 \Rightarrow x = \frac{2 \pm 2\sqrt{3}}{2} = 1 \pm \sqrt{3}$ ，
> >
> > 则 $a + b + c = -2 + 1 + \sqrt{3} + 1 - \sqrt{3} = 0$ ，故 $\mathbb{D}$ 正确.
> >
> > 故选 **ACD**
