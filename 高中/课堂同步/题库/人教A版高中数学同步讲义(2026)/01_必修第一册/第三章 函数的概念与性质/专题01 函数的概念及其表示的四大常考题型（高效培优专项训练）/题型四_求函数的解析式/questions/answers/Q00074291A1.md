> [!faq]- 《专题01 函数的概念及其表示的四大常考题型（高效培优专项训练）》官方解析
>
> > [!success]- **【答案】** B
>
> > [!note]- **【解析】**
> > 设一次函数 $f(x) = ax + b (a \neq 0)$
> >
> > 则 $f[f(x)] = a(ax + b) + b = a^2 x + ab + b$ ， $\because f[f(x)] = 4x - 3$ $\therefore \left\{ \begin{array}{l}a^{2} = 4\\ ab + b = -3 \end{array} \right.$ 解得 $\left\{ \begin{array}{l}a = 2\\ b = -1 \end{array} \right.$ 或 $\left\{ \begin{array}{l}a = -2\\ b = 3 \end{array} \right.$
> >
> > $\therefore f(x) = 2x - 1$ 或 $f(x) = -2x + 3$ ， $\therefore f(1) = 2 \times 1 - 1 = 1$ 或 $f(1) = -2 \times 1 + 3 = 1$
> >
> > 故选 **B**.
