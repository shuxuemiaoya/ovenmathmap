> [!faq]- 《专题03 幂函数及函数的应用（一）的六大常考题型（高效培优专项训练）》官方解析
>
> > [!success]- **【答案】** (1) $45 < x < 100$ (2) 当 $x = 32.5$ 时， $g(x)$ 有最小值 36.875 分钟
>
> > [!note]- **【解析】**
> > （1）由已知可得 $f(x) > 40$
> >
> > 当 $0 < x \leq 30$ 时，不符合题意；
> >
> > 当时，由不等式组 $\left\{ \begin{array}{l}30 <   x <   100\\ 2x + \frac{1800}{x} -90 > 40 \end{array} \right.$ ，解得 $45 <   x <   100$
> >
> > 所以当 $45 < x < 100$ 时，公交群体的人均通勤时间少于自驾群体的人均通勤时间·
> >
> > (2) 当 $0 < x \leq 30$ 时， $g(x) = 30 \times x\% + 40(1 - x\%) = -0.1x + 40$ ；
> >
> > 当 $30 < x < 100$ 时， $g(x) = \left(2x + \frac{1800}{x} - 90\right)x\% + 40(1 - x\%) = 0.02x^2 - 1.3x + 58$
> >
> > 所以 $g(x)=\left\{\begin{aligned}-0.1x+40, &0<x\leq30\\0.02x^{2}-1.3x+58, &30<x<100\end{aligned}\right.$
> >
> > 当 $0 < x \leq 30$ 时，函数 $g(x)$ 单调递减，此时 $g(x)_{\min} = g(30) = 37$ ；
> >
> > 当 $30 < x < 100$ ，函数 $g(x)$ 在 $(30,32.5)$ 上单调递减、在 $(32.5,100)$ 上单调递增，
> >
> > 此时 $g(x)_{\min}=g(32.5)=36.875$ ;
> >
> > 且 $37 > 36.875$ ，可知当 $x = 32.5$ 时， $g(x)$ 有最小值36.875分钟·
