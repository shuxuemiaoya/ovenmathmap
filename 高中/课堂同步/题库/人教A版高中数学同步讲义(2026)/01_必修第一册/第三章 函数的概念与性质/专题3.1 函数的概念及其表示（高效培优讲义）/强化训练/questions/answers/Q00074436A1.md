> [!faq]- 《专题3.1 函数的概念及其表示（高效培优讲义）》官方解析
>
> > [!success]- **【答案】** $(1)(0,2)$ ; $(2)(-\infty,2)\cup(2,+\infty)$ .
>
> > [!note]- **【解析】**
> > （1）由题意得 $\left\{ \begin{array}{l} -1 < \frac{x}{2} < 1, \\ -1 < x - 1 < 1, \end{array} \right.\therefore \left\{ \begin{array}{ll} -2 < x < 2, \\ 0 < x < 2, \end{array} \right.\therefore 0 < x < 2$
> >
> > 所以函数 $g(x)=f\frac{\partial x}{\partial2}\frac{\partial}{\partial}+f(x-1)$ 的定义域为 $(0,2)$ .
> >
> > (2) $y = \frac{2x + 1}{x - 3} = \frac{2(x - 3) + 7}{x - 3} = 2 + \frac{7}{x - 3}, \text{显然} \frac{7}{x - 3} \neq 0, \therefore y \neq 2$
> >
> > 故函数的值域为 $(-∞,2)∪(2,+∞)$ .
