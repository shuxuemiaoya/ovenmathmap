> [!faq]- 《专题3.1 函数的概念及其表示（高效培优讲义）》官方解析
>
> > [!success]- **【答案】** $\{x\mid -3 < x\leq -1$ 或 $3\leq x\leq 4\}$ $\{a\mid a\leq 3\}$
>
> > [!note]- **【解析】**
> > 要使函数 $f(x) = \sqrt{4 - x} +\frac{1}{\sqrt{x + 3}}$ 有意义，则 $\left\{ \begin{array}{ll}4 - x & 0,\\ x + 3 > 0, \text{解得} - 3 <   x£4 \end{array} \right.$ ，所以集合 $A = \{x\mid -3 <   x\leq 4\}$
> >
> > 因为 $a = 2$ ，所以 $B = \{x\mid 1 - a <   x <   1 + a\} = \{x\mid -1 <   x <   3\}$ ，所以 $\tilde{\mathbf{Q}}_{\mathbb{R}}B = \{x\mid x\leq -1$ 或 $x = 3\}$ ，所以
> >
> > $A \cap (\tilde{\mathbf{Q}}_{\mathbb{R}} B) = \{x \mid -3 < x \leq -1 \text{ 或 } 3 \leq x \leq 4\}$ . 因为 $B \subseteq A$ ，所以①当 $B = \varnothing$ 时， $1 - a \quad 1 + a$ ，即 $a \leq 0$ ，满足题意；
> > - **②**：当 时， $\left\{\begin{aligned}1-a&<1+a,\\ 1-a&-3,\\ 1+a&\leq4,\end{aligned}\right.$ 解得 0<a≤3 .综上所述，实数 的取值范围是 $a\left\{a\mid a\leq3\right\}$
