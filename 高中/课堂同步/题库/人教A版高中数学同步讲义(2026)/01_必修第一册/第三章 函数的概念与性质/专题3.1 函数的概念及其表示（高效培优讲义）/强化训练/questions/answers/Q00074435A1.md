> [!faq]- 《专题3.1 函数的概念及其表示（高效培优讲义）》官方解析
>
> > [!success]- **【答案】** (1) $f(x)=x^{2}-2x+3$ (2)实数 $m$ 的取值集合为 $\left[-1 - \sqrt{3}, - 1 + \sqrt{3}\right]$
>
> > [!note]- **【解析】**
> > （1）设 $f(x) = ax^{2} + bx + c$ ，又 $f(0) = 3$ ，所以 $c = 3$ ，所以 $f(x) = ax^{2} + bx + 3$
> >
> > 又 $f(x + 1) - f(x) = 2x - 1$ ，所以 $a(x + 1)^2 +b(x + 1) + 3 - (ax^2 +bx + 3) = 2x - 1$
> >
> > 即 $2ax + a + b = 2x - 1$ ，所以 $\left\{ \begin{array}{l}2a = 2\\ a + b = -1 \end{array} \right.$ ，解得 $a = 1,b = -2$
> >
> > 所以 $f(x)=x^{2}-2x+3$ ;
> >
> > (2) 若 $x \in R$ 时， $f(x) = 2mx$ 恒成立，则 $x^{2} - 2x + 3 = 2mx$ 的解集为 R，
> >
> > 即 $x^{2} - (2 + 2m)x + 3$ 0 的解集为 $\mathbb{R}$ ，所以 $\Delta = (2 + 2m)^2 -4\times 1\times 3\leq 0$
> >
> > 所以 $4m^{2} + 8m + 4 - 12\leq 0$ ，即 $m^2 +2m - 2\leq 0$ ，解得 $-1 - \sqrt{3}\leq m\leq -1 + \sqrt{3}$
> >
> > 所以实数 $m$ 的取值集合为 $\left[-1 - \sqrt{3}, - 1 + \sqrt{3}\right]$
