> [!faq]- 《专题3.1 函数的概念及其表示（高效培优讲义）》官方解析
>
> > [!success]- **【答案】** （1） $\left[-\frac{1}{3},0\right]$ ；(2)① $\left[\frac{23}{12},+\infty\right)$ ；② $(-∞,5]$
>
> > [!note]- **【解析】**
> > 解：（1）在函数 $f(x - 1)$ 中， $2 \leq x \leq 3$ ，则 $1 \leq x - 1 \leq 2$ 。因此在函数 $f(3x + 2)$ 中， $1 \leq 3x + 2 \leq 2$ ，解
> >
> > 得 $-\frac{1}{3} \leq x \leq 0$ ，所以函数 $f(3x + 2)$ 的定义域为 $\left[-\frac{1}{3}, 0\right]$
> >
> > (2) ①函数 $y = 3x^{2} - x + 2$ 的定义域为 $\mathbf{R}$ ， $y = 3\left(x - \frac{1}{6}\right)^{2} + \frac{23}{12} \quad \frac{23}{12}$ ，当且仅当 $x = \frac{1}{6}$ 时，等号成立，所以函数
> >
> > $y = 3x^{2} - x + 2$ 的值域为 $\left[\frac{23}{12}, + \infty\right)$
> > - **②**：函数 $y = x + 4\sqrt{1 - x}$ 的定义域为 $(- \infty, 1]$ ， $y = -(\sqrt{1 - x})^2 + 4\sqrt{1 - x} + 1 = -(\sqrt{1 - x} - 2)^2 + 5 \leq 5$ ，当且仅当 $x = -3$
> >
> > 时，等号成立，所以函数 $y = x + 4\sqrt{1 - x}$ 的值域为 $(- \infty, 5]$

> > 19. 根据下列条件，求函数 $f(x)$ 的解析式
> >
> > (1)已知函数 $f(x)$ 是一次函数，若 $f(f(x)) = 4x + 8$ ，求 $f(x)$ 的解析式
> >
> > (2)已知 $f(\sqrt{x} + 1) = x - 2\sqrt{x}$ ，求 $f(x)$ 的解析式.
> >
> > 【答案】(1) $f(x)=2x+\frac{8}{3}$ 或 $f(x)=-2x-8$ (2) $f(x)=x^{2}-4x+3,(x=1)$
> >
> > 【详解】（1）∵ $f(x)$ 是一次函数，∴设 $f(x)=kx+b.$ （ $k\neq0$ ）
> >
> > $$
> > \because f (f (x)) = 4 x + 8, \therefore f (k x + b) = 4 x + 8, \therefore k (k x + b) + b = 4 x + 8, \therefore \left\{ \begin{array}{l} k ^ {2} = 4 \\ k b + b = 8 \end{array} \right.
> > $$
> >
> > $$
> > \therefore \left\{ \begin{array}{l l} k = 2 \\ b = \frac {8}{3} \text {或} \left\{ \begin{array}{l l} k = - 2 \\ b = - 8 \end{array} , \therefore f (x) = 2 x + \frac {8}{3} \text {或} f (x) = - 2 x - 8 \right. \end{array} \right.
> > $$
> >
> > (2) 令 $t = \sqrt{x} + 1, (t - 1)$ 则 $\sqrt{x} = t - 1$ ， $\therefore x = (t - 1)^2$
> >
> > $$
> > \therefore f (t) = (t - 1) ^ {2} - 2 (t - 1) = t ^ {2} - 4 t + 3, \therefore f (x) = x ^ {2} - 4 x + 3, (x - 1)
> > $$
