> [!faq]- 《专题3.1 函数的概念及其表示（高效培优讲义）》官方解析
>
> > [!success]- **【答案】** ACD
>
> > [!note]- **【解析】**
> > 由题意得 $BC = 2 - x, PC = x - y$ 。因为 $x > 2 - x$ ，所以 $1 < x < 2$ 。因为
> >
> > $AD = B'C, \angle D = \angle B', \angle APD = \angle CPB'$ ，所以 $\triangle ADP \subseteq \triangle CB'P$ ，所以 $PA = PC = x - y$ 。由 $PA^2 = AD^2 + DP^2$ ，得$(x - y)^2 = (2 - x)^2 + y^2$ ，所以 $y = 2\left(1 - \frac{1}{x}\right), 1 < x < 2$ 。记 $\triangle ADP$ 的面积为 $S$ ，则
> >
> > $S = \left(1 - \frac{1}{x}\right)(2 - x) = 3 - \left(x + \frac{2}{x}\right) \leq 3 - 2\sqrt{2}$ ，当且仅当 $x = \sqrt{2}$ 时等号成立， $S$ 取得最大值，此时长方形ABCD的
> >
> > 面积为 $x(2 - x) = \sqrt{2} (2 - \sqrt{2}) = 2\sqrt{2} - 2$ 。综上所述，A，C，D均正确。
