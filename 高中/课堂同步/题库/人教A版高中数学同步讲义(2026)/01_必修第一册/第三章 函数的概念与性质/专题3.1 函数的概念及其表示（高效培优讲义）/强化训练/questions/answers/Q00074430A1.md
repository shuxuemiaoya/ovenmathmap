> [!faq]- 《专题3.1 函数的概念及其表示（高效培优讲义）》官方解析
>
> > [!success]- **【答案】** A. 函数 $f(x + 1)$ 的定义域为 $[-2, 2]$ ，则函数 $f(x)$ 的定义域为 $[-1, 3]$ B. $f(x) = \frac{x^2}{x}$ 和 $g(x) = x$ 表示同一个函数 C. 函数 $y = \frac{1}{x^{2} + 3}$ 的值域为 $\left(0, \frac{1}{3}\right]$ D．定义在R上的函数 $f(x)$ 满足 $2f(x)-f(-x)=x+1$ ，则 $f(x)=\frac{x}{3}+1$
>
> > [!note]- **【解析】**
> > 对于 A：由 $f(x+1)$ 的定义域为 $[-2,2]$ ，则 $-2 \leq x \leq 2 \Rightarrow -1 \leq x + 1 \leq 3$ ，所以函数 $f(x)$ 的定义域为
> >
> > $[-1,3]$ ，故 $\mathsf{A}$ 正确；
> >
> > 对于 B：函数 $f(x)=\frac{x^{2}}{x}$ 的定义域为 $\left\{x\mid x\neq0\right\}$ ，函数 $g(x)=x$ 的定义域为 R，故 B 错误；
> >
> > 对于 C：由 $x^{2}$ $0 \Rightarrow x^{2} + 3$ 3，所以 $0 < \frac{1}{x^{2} + 3} \leq \frac{1}{3}$ ，函数 $y = \frac{1}{x^{2} + 3}$ 的值域为 $\left(0, \frac{1}{3}\right]$ ，故 C 正确；
> >
> > 对于 D：由 $2f(x)-f(-x)=x+1$ ，所以 $2f(-x)-f(x)=-x+1$ ，所以 $f(x)=\frac{x}{3}+1$ ，故 D 正确·
> >
> > 故选 **ACD**.
