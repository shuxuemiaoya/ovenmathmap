> [!faq]- 《专题3.1 函数的概念及其表示（高效培优讲义）》官方解析
>
> > [!success]- **【答案】** C
>
> > [!note]- **【解析】**
> > 由 $f(1)=1\Rightarrow\frac{2}{a+b}=1\Rightarrow a+b=2$ ；
> >
> > 又 $\frac{2x}{ax + b} = 2x\Rightarrow x = 0$ 或 $ax + b = 1$
> >
> > 因为关于 x 的方程 $f(x)=2x$ 只有一解，
> >
> > 当 $x = 0$ 为方程的唯一解时， $b = 1, a = 1$ ，或方程 $ax + b = 1$ 无解，得 $a = 0, b = 2$ ；
> >
> > 当 $x = 0$ 不为方程的解时， $a \times 0 + b = 0 \Rightarrow b = 0, a = 2$
> >
> > 此时 $f(x) = \frac{2x}{2x} = 1 (x \neq 0)$ ，满足题意；
> >
> > 所以 a-b=0 或 a-b=-2 或 a-b=2.
> >
> > ## 方法技巧
> >
> > 1. 解析式类型已知的，如本例（1），一般用待定系数法，对于二次函数问题要注意对一般式 $y = ax^2 + bx + c$ ，
> >
> > 顶点式 $y = a(x - h)^2 + k$ 和两点式 $y = a(x - x_1)(x - x_2)$ 的选择.
> >
> > 2. 已知 $f[g(x)]$ 求 $f(x)$ 的问题，方法一是用配凑法；方法二是用换元法。
> >
> > 3.函数方程问题，需建立关于 $f(x)$ 的方程组，如本例（3），若函数方程中同时出现 $f(x)$ 、 $f(\frac{1}{x})$ ，则一般 $x$
> >
> > 用 $\frac{1}{x}$ 代之，构造另一个方程.
