> [!faq]- 《专题3.1 函数的概念及其表示（高效培优讲义）》官方解析
>
> > [!success]- **【答案】** B
>
> > [!note]- **【解析】**
> > 由 $f(x) + |g(x)| - |h(x)| = \begin{cases} 2x - 1, & x < -\frac{1}{2} \\ 6x + 1, & -\frac{1}{2} \leq x < \frac{2}{3} \\ 5, & \frac{2}{3} \end{cases}$ 可知函数的分段点为 \_\_\_\_ 和 \_\_\_\_，
> >
> > 而函数 $f(x)$ ， $g(x)$ ， $h(x)$ 为一次函数，所以可得函数 $g(x)=0$ 和 $h(x)=0$ 的根为 $x=-\frac{1}{2}$ 和 $x=\frac{2}{3}$ ，假设 $g(x)=0$ 的根为 $x=-\frac{1}{2}$ ， $h(x)=0$ 的根为 $x=\frac{2}{3}$ ，
> >
> > 分 $^{4}$ 种情况讨论：
> >
> > (1) $x < -\frac{1}{2}$ 时， $g(x) < 0$ ， $x < \frac{2}{3}$ 时， $h(x) < 0$
> >
> > 当 $x < -\frac{1}{2}$ 时， $f(x) + |g(x)| - |h(x)| = f(x) - g(x) + h(x) = 2x - 1$
> >
> > 当 $x$ $\frac{2}{3}$ 时， $f(x) + |g(x)| - |h(x)| = f(x) + g(x) - h(x) = 5$
> >
> > 两式相加可得 $f(x)=x+2$
> >
> > (2) $x < -\frac{1}{2}$ 时， $g(x) > 0$ ， $x < \frac{2}{3}$ 时， $h(x) > 0$
> >
> > 当 $x < -\frac{1}{2}$ 时， $f(x) + |g(x)| - |h(x)| = f(x) + g(x) - h(x) = 2x - 1$
> >
> > 当 $x$ $\frac{2}{3}$ 时， $f(x) + |g(x)| - |h(x)| = f(x) - g(x) + h(x) = 5$
> >
> > 两式相加可得 $f(x) = x + 2$
> >
> > (3) $x < -\frac{1}{2}$ 时， $g(x) > 0$ ， $x < \frac{2}{3}$ 时， $h(x) < 0$
> >
> > 当 $x < -\frac{1}{2}$ 时， $f(x) + |g(x)| - |h(x)| = f(x) + g(x) + h(x) = 2x - 1$
> >
> > 当 $x$ $\frac{2}{3}$ 时， $f(x) + |g(x)| - |h(x)| = f(x) - g(x) - h(x) = 5$
> >
> > 两式相加可得 $f(x)=x+2$
> >
> > (4) $x < -\frac{1}{2}$ 时， $g(x) < 0$ ， $x < \frac{2}{3}$ 时， $h(x) > 0$
> >
> > 当 $x < -\frac{1}{2}$ 时， $f(x) + |g(x)| - |h(x)| = f(x) - g(x) - h(x) = 2x - 1$
> >
> > 当 $x$ $\frac{2}{3}$ 时， $f(x) + |g(x)| - |h(x)| = f(x) + g(x) + h(x) = 5$
> >
> > 两式相加可得 $f(x) = x + 2$
> >
> > 综上可得 $f(x) = x + 2$
> >
> > 故选 **B**
