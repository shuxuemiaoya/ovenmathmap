> [!faq]- 《专题3.1 函数的概念及其表示（高效培优讲义）》官方解析
>
> > [!success]- **【答案】** B
>
> > [!note]- **【解析】**
> > 令 $x = 1, y = 0$ ，则有 $f(1 + 0) = f(1) + f(0) + 1 \times 0 = f(1) + f(0)$ ，由于 $f(1) = 1$ ，则 $1 = 1 + f(0)$ ，故 $f(0) = 0$ ；
> >
> > 令 $x = 1, y = -1$ ，则有 $f(0) = f(1) + f(-1) + 1 \times (-1)$ ，将已知条件代入，得到 $0 = 1 + f(-1) - 1$ ，因此 $f(-1) = 0$ ；
> > 令 $x = -1, y = -1$ ，则有 $f(-2) = f(-1) + f(-1) + (-1) \times (-1) = 0 + 0 + 1 = 1$ ；
> > 令 $x = -2, y = -2$ ，则有 $f(-4) = f(-2) + f(-2) + (-2) \times (-2) = 1 + 1 + 4 = 6$ ；
> >
> > 令 $x = -4, y = -1$ ，则有 $f(-5) = f(-4) + f(-1) + (-4) \times (-1) = 6 + 0 + 4 = 10$ .
> >
> > 因此， $f(-5)=10$ .
> >
> > 故选 **B**.
