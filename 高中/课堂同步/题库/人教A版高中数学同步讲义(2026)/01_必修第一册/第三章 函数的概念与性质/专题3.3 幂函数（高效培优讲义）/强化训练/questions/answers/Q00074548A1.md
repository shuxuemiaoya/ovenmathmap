> [!faq]- 《专题3.3 幂函数（高效培优讲义）》官方解析
>
> > [!success]- **【答案】** (1) $f(x)=x$ (2)8
>
> > [!note]- **【解析】**
> > （1）因为幂函数 $f(x) = (m^2 - 5m + 7)x^{m-1}$ ，所以 $m^2 - 5m + 7 = 1$ ，解得 $m = 2$ 或 $m = 3$
> >
> > 当 m=2 时， $f(x)=x$ ，满足 $f(x)+f(-x)=0$ ，
> >
> > 当 $m = 3$ 时， $f(x) = x^2$ ，不满足 $f(x) + f(-x) = 0$ ，所以 $f(x) = x$
> >
> > (2) 由 (1) 得 $g(x) = \frac{1}{x + 2}$ . 由 $g(a) + g(b) = \frac{1}{2}$ , 得 $\frac{1}{a + 2} + \frac{1}{b + 2} = \frac{1}{2}$
> >
> > 因为 $f(a)+f(b)+4=a+b+4=a+2+b+2$
> >
> > 所以 $a + 2 + b + 2 = 2(a + 2 + b + 2)\left(\frac{1}{a + 2} +\frac{1}{b + 2}\right) = 2\left(2 + \frac{b + 2}{a + 2} +\frac{a + 2}{b + 2}\right)$
> >
> > 又 $a, b$ 均为正数，所以 $\frac{b + 2}{a + 2} + \frac{a + 2}{b + 2}$ $2\sqrt{\frac{b + 2}{a + 2} \cdot \frac{a + 2}{b + 2}} = 2$
> >
> > 当且仅当 a=b=2 时，等号成立，
> >
> > 所以 $f(a) + f(b) + 4$ $2(2 + 2) = 8$ ，即 $f(a) + f(b) + 4$ 的最小值为8.
