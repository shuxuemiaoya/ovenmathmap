> [!faq]- 《专题3.3 幂函数（高效培优讲义）》官方解析
>
> > [!success]- **【答案】** (1) $m = 3$ ， $f(x) = x^{-1}$ (2) $n = \frac{53}{8}$ 或 $n \leq -\frac{53}{4}$ .
>
> > [!note]- **【解析】**
> > （1）因为幂函数 $f(x) = (m^2 - 2m - 2)x^{m^2 - 4m + 2}$ 在 $(0, +\infty)$ 上单调递减，
> >
> > 所以 $\left\{\begin{aligned}m^{2}-2m-2&=1,\\ m^{2}-4m+2&<0,\end{aligned}\right.$
> >
> > 解得： $m = 3$
> >
> > 所以 $f(x)=x^{-1}$ .
> >
> > (2) $h(x) = f(x)(x^3 - 7x^2 + 6x) = x^2 - 7x + 6$
> >
> > 当 $x \in [1,4]$ 时， $h(x) = \left(x - \frac{7}{2}\right)^{2} - \frac{25}{4}$
> >
> > 易得 $h(x)$ 的值域为 $\left[-\frac{25}{4},0\right]$ .
> >
> > $\because x_{1}\in[1,4]$ ，总存在 $x_{2}\in[1,4]$ ，使 $h(x_{1})=g(x_{2})$
> >
> > $h(x)$ 的值域为 $g(x)$ 值域的子集.
> >
> > $$
> > \because g (x) = n x + 7 - 3 n
> > $$
> >
> > ∴ ① 当 n > 0 时， $g(x) \in [7 - 2n, n + 7]$
> >
> > 则 $\left\{ \begin{array}{l} n > 0, \\ 7 - 2n \leq -\frac{25}{4}, \Rightarrow n = \frac{53}{8} \\ n + 7 = 0 \end{array} \right.$
> > - **②**：当 $n < 0$ 时， $g(x) \in [n + 7, 7 - 2n]$
> >
> > 则 $\left\{ \begin{array}{l} n < 0, \\ n + 7 \leq -\frac{25}{4}, \Rightarrow n \leq -\frac{53}{4} \\ 7 - 2n = 0 \end{array} \right.$
> > - **③**：当 n=0 时， $g(x)=7$ ，不符合题意。
> >
> > 综上， $n \frac{53}{8}$ 或 $n \leq -\frac{53}{4}$ .
