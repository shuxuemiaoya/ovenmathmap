> [!faq]- 《专题3.3 幂函数（高效培优讲义）》官方解析
>
> > [!success]- **【答案】** 2 $a > 3$ 或 $a < - \frac{1}{3}$
>
> > [!note]- **【解析】**
> > 由题意知函数 $f(x) = x^{4m - m^2} (m \in \mathbf{Z})$ 在区间 $(0, +\infty)$ 上单调递增，所以 $m^2 - 4m < 0$ ，解得 $0 < m < 4$ ，由 $m \in \mathbf{Z}$ 得 $m = 1, 2, 3$ 。又 $f(x) = x^{4m - m^2}$ 的图象关于 $y$ 轴对称，所以 $4m - m^2$ 为偶数，所以 $m = 2$ ，所以 $f(x) = x^4$ 不等式 $f(a + 2) < f(1 - 2a)$ 等价于 $|a + 2| < |1 - 2a|$ ，解得 $a > 3$ 或 $a < -\frac{1}{3}$ 。
