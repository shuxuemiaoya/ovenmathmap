> [!faq]- 《专题3.3 幂函数（高效培优讲义）》官方解析
>
> > [!success]- **【答案】** (1) $f(x)=\frac{1}{\sqrt[3]{x}}$ (2) $(-∞,-1)∪\left(\frac{2}{3},\frac{3}{2}\right)$
>
> > [!note]- **【解析】**
> > （1）由幂函数的定义可得 $3m^{2} - 2m = 1$ ，解得 $m = 1$ 或 $m = -\frac{1}{3}$
> >
> > 若 $m = 1$ ，则 $f(x) = x$ 的定义域为 $\mathbf{R}$ ，不符合题意，
> >
> > <!-- source-part:2 pages:51-56 -->
> >
> > 若 $m = -\frac{1}{3}$ ，则 $f(x) = x^{-\frac{1}{3}} = \frac{1}{\sqrt[3]{x}}$ 的定义域为 $(-\infty,0)\cup (0, + \infty)$ ，符合题意，
> >
> > 所以 $f(x)$ 的解析式为 $f(x)=\frac{1}{\sqrt[3]{x}}$ .
> >
> > (2) 由 (1) 得， $f(x)$ 的定义域 $(- \infty, 0) \cup (0, +\infty)$ 关于原点对称，且 $f(-x) = \frac{1}{\sqrt[3]{-x}} = -\frac{1}{\sqrt[3]{x}} = -f(x)$
> >
> > 所以 $f(x)$ 为奇函数，
> >
> > 由 $f(a + 1) + f(2a - 3) < 0$ 可得 $f(a + 1) < -f(2a - 3) = f(3 - 2a)$
> >
> > 因为 $f(x)$ 在 $(-\infty, 0)$ 上递减且恒负，在 $(0, +\infty)$ 上递减且恒正，
> >
> > 所以 $\left\{\begin{aligned}a+1&>0\\ 3-2a&>0\\ a+1&>3-2a\end{aligned}\right.$ 或 $\left\{\begin{aligned}a+1&<0\\ 3-2a&<0\\ a+1&>3-2a\end{aligned}\right.$ 或 $\left\{\begin{aligned}a+1&<0\\ 3-2a&>0\end{aligned}\right.$
> >
> > 解得 $a < -1$ 或 $\frac{2}{3} < a < \frac{3}{2}$
> >
> > 所以 $a$ 的取值范围为 $(- \infty, -1) \cup \left(\frac{2}{3}, \frac{3}{2}\right)$
