> [!faq]- 《专题3.3 幂函数（高效培优讲义）》官方解析
>
> > [!success]- **【答案】** C
>
> > [!note]- **【解析】**
> > 令 $f(x) = x^{\alpha}$ ，由 $f(4) = 2$ ，得 $4^{\alpha} = 2$ ，解得 $\alpha = \frac{1}{2}$ ，则 $f(x) = x^{\frac{1}{2}}$
> >
> > 所以 $f(x) = x^{\frac{1}{2}}$ 的定义域为 $[0, +\infty)$ ，则 $f(x)$ 为非奇非偶函数，故 $^A$ 错误；
> >
> > 因为 $f(x) = x^{\frac{1}{2}}$ ，所以 $f(x) = x^{\frac{1}{2}}$ 在 $[0, +\infty)$ 上单调递增，
> >
> > 则当 $0 < x_{1} < x_{2}$ 时， $f(x_{1}) < f(x_{2})$ ，故B错误；
> >
> > 当 $x_{1}, x_{2} \in [0, +\infty)$ 且 $x_{1} \neq x_{2}$ 时，
> >
> > $$
> > f \left(\frac {x _ {1} + x _ {2}}{2}\right) = \sqrt {\frac {x _ {1} + x _ {2}}{2}} > 0, \frac {f (x _ {1}) + f (x _ {2})}{2} = \frac {\sqrt {x _ {1}} + \sqrt {x _ {2}}}{2} > 0
> > $$
> >
> > $$
> > \text {则} \left(\sqrt {\frac {x _ {1} + x _ {2}}{2}}\right) ^ {2} = \frac {x _ {1} + x _ {2}}{2} = \frac {x _ {1} + x _ {2} + \left(x _ {1} + x _ {2}\right)}{4}, \left(\frac {\sqrt {x _ {1}} + \sqrt {x _ {2}}}{2}\right) ^ {2} = \frac {x _ {1} + x _ {2} + 2 \sqrt {x _ {1} x _ {2}}}{4}
> > $$
> >
> > 又 $x_{1} + x_{2} > 2\sqrt{x_{1}x_{2}}$ ，所以 $\left(\sqrt{\frac{x_1 + x_2}{2}}\right)^2 >\left(\frac{\sqrt{x_1} + \sqrt{x_2}}{2}\right)^2$ ，则 $\sqrt{\frac{x_1 + x_2}{2}} >\frac{\sqrt{x_1} + \sqrt{x_2}}{2}$
> >
> > 所以 $f\left(\frac{x_{1}+x_{2}}{2}\right)>\frac{f(x_{1})+f(x_{2})}{2}$ ，故 C 正确；
> >
> > 当 $x > 0$ 时 $f(x) = x^{\frac{1}{2}} > 0$ ，即 $\forall x > 0, f(x) > 0$ ，故D错误·
> >
> > 故选：C
> >
> > ## 方法技巧
> >
> > 利用单调性求解.
