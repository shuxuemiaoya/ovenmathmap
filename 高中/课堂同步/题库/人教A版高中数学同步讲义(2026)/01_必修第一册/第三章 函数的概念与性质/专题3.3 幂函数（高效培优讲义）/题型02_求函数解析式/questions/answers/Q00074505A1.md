> [!faq]- 《专题3.3 幂函数（高效培优讲义）》官方解析
>
> > [!success]- **【答案】** (1) $f(x)=x^{-\frac{1}{2}}$ (2) $[1,3]$
>
> > [!note]- **【解析】**
> > （1）因为 $f(x)$ 是幂函数，所以 $m^2 - m - 5 = 1$ ，解得 $m = -2$ 或 $m = 3$
> >
> > 当 $m = -2$ 时， $f(x) = x^{-\frac{1}{2}}$ ，此时 $f(4) = \frac{1}{2}$ ，则 $m = -2$ 符合题意；
> >
> > 当 $m = 3$ 时， $f(x) = x^{\frac{1}{3}}$ ，此时 $f(4) = 4^{\frac{1}{3}} \neq \frac{1}{2}$ ，则 $m = 3$ 不符合题意。
> >
> > 故 $f(x)=x^{-\frac{1}{2}}$
> >
> > (2) 由 (1) 可知 $f(x) = x^{-\frac{1}{2}}$ ，则 $g(x) = \sqrt{x} - x + 3 = -\left(\sqrt{x} - \frac{1}{2}\right)^2 + \frac{13}{4}$ .
> >
> > 因为 $1 \leq x \leq 4$ ，所以 $1 \leq \sqrt{x} \leq 2$ ，所以 $\frac{1}{2} \leq \sqrt{x} - \frac{1}{2} \leq \frac{3}{2}$
> >
> > 所以 $\frac{1}{4} \leq \left( \sqrt{x} - \frac{1}{2} \right)^2 \leq \frac{9}{4}$ ，所以 $-\frac{9}{4} \leq -\left( \sqrt{x} - \frac{1}{2} \right)^2 \leq -\frac{1}{4}$
> >
> > 所以 $1 \leq -\left(\sqrt{x} - \frac{1}{2}\right)^{2} + \frac{13}{4} \leq 3$ ，即 $g(x)$ 在 $[1,4]$ 上的值域为 $[1,3]$ .
