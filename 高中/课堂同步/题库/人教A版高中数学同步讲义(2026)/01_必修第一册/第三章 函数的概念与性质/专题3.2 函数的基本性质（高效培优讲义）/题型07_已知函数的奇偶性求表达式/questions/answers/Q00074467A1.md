> [!faq]- 《专题3.2 函数的基本性质（高效培优讲义）》官方解析
>
> > [!success]- **【答案】** (1) $f(x)=\frac{1}{1+x^{2}}$ (2) $t \in \left( \frac{1}{2}, \frac{3}{4} \right)$
>
> > [!note]- **【解析】**
> > （1）由题意 $f(1) = f(-1) = \frac{1}{2}$ ，即 $\frac{a + b}{2} = \frac{-a + b}{2} = \frac{1}{2}$ ，解得 $a = 0, b = 1$
> >
> > 当 $a = 0, b = 1$ 时， $f(x) = \frac{1}{1 + x^2}$ ，此时 $f(x)$ 定义域为 $\mathbb{R}$ 关于原点对称，
> >
> > 且 $f(-x) = f(x)$ ，即 $f(x) = \frac{1}{1 + x^2}$ 是偶函数，
> >
> > 故 $f(x)=\frac{1}{1+x^{2}}$ 满足题意；
> >
> > (2) 由题意 $g(x)=|x|-\frac{1}{1+x^{2}}$ ，显然 $y=|x|$ , $y=\frac{1}{1+x^{2}}$ 是偶函数，
> >
> > 所以 $g(x) = |x| - \frac{1}{1 + x^2}$ 也是偶函数，
> >
> > 当 $x$ 0时， $g(x) = |x| - \frac{1}{1 + x^2} = x - \frac{1}{1 + x^2}$ ，
> >
> > 显然当 $x = 0$ 时， $y = |x| = x, y = -\frac{1}{1 + x^2}$ 都是增函数，
> >
> > 即 $g(x) = |x| - \frac{1}{1 + x^2}$ 在 $(0, +\infty)$ 上单调递增，所以函数 $g(x) = |x| - \frac{1}{1 + x^2}$ 在 $(- \infty, 0)$ 上单调递减，
> >
> > 而 $g(3t-2)<g(t-1)\Leftrightarrow\left|3t-2\right|<\left|t-1\right|$
> >
> > 所以 $\left(3t-2\right)^{2}-\left(t-1\right)^{2}=\left(4t-3\right)\left(2t-1\right)<0$ ，解得 $\frac{1}{2}<t<\frac{3}{4}$
