> [!faq]- 《专题3.2 函数的基本性质（高效培优讲义）》官方解析
>
> > [!success]- **【答案】** (1)4 (2) $(0,1)$
>
> > [!note]- **【解析】**
> > （1）当 $x = 2$ 时， $a = x^2 = 4$ ， $b = -x^2 + 2x = 0$
> >
> > $$
> > \therefore a > b \quad a + b = 4 > 0
> > $$
> >
> > $$
> > \therefore f (a, b) = \max \{a, b \} = 4
> > $$
> >
> > 即 $g(2)=4$ .
> >
> > (2) $a + b = x^{2} - x^{2} + 2x = 2x$
> >
> > 当 $x < 0$ 时， $a + b < 0$ ，当 $x = 0$ 时， $a + b = 0$ .
> >
> > 若 $a > b$ ，则 $x^{2} > -x^{2} + 2x$ ，解得 $x > 1$ 或 $x < 0$ ；
> >
> > 若 $a \leq b$ ，则 $x^{2} \leq -x^{2} + 2x$ ，解得 $0 \leq x \leq 1$ .
> >
> > 当 x < 0 时， $f(a, b) = a + b - a = b = -x^{2} + 2x$
> >
> > 当 $0 \leq x \leq 1$ 时， $f(a, b) = \max \{a, b\} = b = -x^2 + 2x$
> >
> > 当 $x > 1$ 时， $f(a, b) = \max \{a, b\} = a = x^2$
> >
> > 所以 $g(x)=\left\{\begin{aligned}-x^{2}+2x,x&\leq1,\\ x^{2},x&>1,\end{aligned}\right.$ 故 $g(x)$ 在 R 上单调递增.
> >
> > 所以 $g(x) > g(x^{2})$ ，则 $x > x^{2}$ ，解得 0 < x < 1，
> >
> > $\therefore x_{\text{的取值范围为}}(0,1)$
