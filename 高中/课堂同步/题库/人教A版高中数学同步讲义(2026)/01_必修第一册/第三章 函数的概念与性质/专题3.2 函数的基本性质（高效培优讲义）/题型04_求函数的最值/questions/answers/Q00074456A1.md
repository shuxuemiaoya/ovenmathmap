> [!faq]- 《专题3.2 函数的基本性质（高效培优讲义）》官方解析
>
> > [!success]- **【答案】** (1) $f(x)=x-\frac{4}{x}$ ，证明见解析 (2) $g(a) = \begin{cases} 6a + 17, & a < -3 \\ -a^2 + 8, & -3 \leq a \leq 0 \\ 8, & a > 0 \end{cases}$
>
> > [!note]- **【解析】**
> > （1）设 $h(x)=ax^{2}+bx+c(a\neq0)$
> >
> > $$
> > \because h (0) = - 4 \quad h (x + 1) - h (x) = 2 x + 1
> > $$
> >
> > $$
> > \therefore \left\{ \begin{array}{l} c = - 4, \\ a (x + 1) ^ {2} + b (x + 1) + c - (a x ^ {2} + b x + c) = 2 x + 1 \end{array} \right.
> > $$
> >
> > 即 $\left\{ \begin{array}{l} c = -4, \\ 2ax + a + b = 2x + 1 \end{array} \right.$
> >
> > $\therefore \left\{ \begin{array}{l} c = -4 \\ 2a = 2 \\ a + b = 1 \end{array} \right.$ ，解得 $\left\{ \begin{array}{l} c = -4 \\ a = 1 \\ b = 0 \end{array} \right.$
> >
> > ∴ $h(x)=x^{2}-4$ ，则 $f(x)=x-\frac{4}{x}$
> >
> > 证明：任取 $x_{1}$ ， $x_{2}\in [1,2]$ ，且 $x_{1} <   x_{2}$
> >
> > $$
> > f \left(x _ {1}\right) - f \left(x _ {2}\right) = x _ {1} - \frac {4}{x _ {1}} - \left(x _ {2} - \frac {4}{x _ {2}}\right) = \left(x _ {1} - x _ {2}\right) + \left(\frac {4}{x _ {2}} - \frac {4}{x _ {1}}\right) = \left(x _ {1} - x _ {2}\right) \cdot \left(1 + \frac {4}{x _ {1} x _ {2}}\right)
> > $$
> >
> > 因为 $1 \leq x_{1} < x_{2} \leq 2$ ，则 $\left(x_{1} - x_{2}\right) \cdot \left(1 + \frac{4}{x_{1}x_{2}}\right) < 0$
> >
> > 所以 $f(x_{1})-f(x_{2})<0\Rightarrow f(x_{1})<f(x_{2})$
> >
> > $\therefore f(x)$ 在 $[1,2]$ 上单调递增.
> >
> > (2) 令 $x - \frac{4}{x} = t$ ，则由 (1) 知 $t \hat{l} [-3, 0]$
> >
> > 则 $F(x) = x^{2} + \frac{16}{x^{2}} - 2a\left(x - \frac{4}{x}\right) = t^{2} - 2at + 8$ ，记 $\varphi(t) = t^2 - 2at + 8$ ， $t \uparrow [-3,0]$
> >
> > 当 a < -3 时， $\varphi(t)_{\min} = \varphi(-3) = 6a + 17$
> >
> > 当 $-3 \leq a \leq 0$ 时， $\varphi(t)_{\min} = \varphi(a) = -a^{2} + 8$ ；
> >
> > 当 $a > 0$ 时， $\varphi (t)_{\mathrm{min}} = \varphi (0) = 8$
> >
> > 故 $g(a) = \begin{cases} 6a + 17, & a < -3 \\ -a^2 + 8, & -3 \leq a \leq 0 \\ 8, & a > 0 \end{cases}$
