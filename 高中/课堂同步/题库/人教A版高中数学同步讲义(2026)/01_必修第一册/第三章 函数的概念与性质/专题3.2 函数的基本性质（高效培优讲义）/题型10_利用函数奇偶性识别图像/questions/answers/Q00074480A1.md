> [!faq]- 《专题3.2 函数的基本性质（高效培优讲义）》官方解析
>
> > [!success]- **【答案】** $(-2,0)\cup(2,4)$
>
> > [!note]- **【解析】**
> > 由偶函数的性质可知， $f(x)>0\Leftrightarrow-2<x<2$
> >
> > $f(x) < 0 \Leftrightarrow -4 \leq x < -2$ 或 $2 < x \leq 4$
> >
> > 由奇函数的性质可知， $g(x)>0\Leftrightarrow0<x<4$ ， $g(x)<0\Leftrightarrow-4<x<0$
> >
> > 当 $\left\{\begin{aligned}f(x)>0\\ g(x)<0\end{aligned}\right.\Leftrightarrow\left\{\begin{aligned}-2<x<2\\ -4<x<0\end{aligned}\right.$ ，得 $-2<x<0$ ，
> >
> > 当 $\left\{ \begin{array}{l} f(x) < 0 \\ g(x) > 0 \end{array} \right. \Leftrightarrow \left\{ \begin{array}{l} -4 \leq x < -2 \text{或} 2 < x \leq 4 \\ 0 < x < 4 \end{array} \right.$ ，得 $2 < x < 4$ ，
> >
> > 所以不等式 $f(x)g(x)<0$ 的解集为 $(-2,0)\cup(2,4)$ .
> >
> > 故答案为： $(-2,0)\cup(2,4)$
