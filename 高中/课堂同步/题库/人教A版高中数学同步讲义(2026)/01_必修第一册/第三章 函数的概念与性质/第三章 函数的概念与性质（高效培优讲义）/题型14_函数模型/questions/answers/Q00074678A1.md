> [!faq]- 《第三章 函数的概念与性质（高效培优讲义）》官方解析
>
> > [!success]- **【答案】** (1)1 $$ W (x) = \left\{ \begin{array}{l} - x ^ {2} + 6 0 x - 2 0 0 (0 \leq x \leq 1 5) \\ - x - \frac {9 0 0}{x + 8} + 5 5 2 (x > 1 5) \end{array} \right. \tag {2} $$ (3)年产量为 22 台时，该企业所获利润最大，最大利润是 500 万元
>
> > [!note]- **【解析】**
> > （1）将 $x = 5$ ， $f(x) = 75$ 代入 $f(x) = ax^2 + 10x$
> >
> > 得 $25a + 50 = 75$ ，解得 a = 1。
> >
> > (2) 由题意得， $W(x)=70x-200-f(x)$ ，x=0.
> >
> > 当 $0 \leq x \leq 15$ 时，由（1）知， $f(x) = x^2 + 10x$
> >
> > 则 $W(x)=70x-x^{2}-10x-200=-x^{2}+60x-200$ ;
> >
> > 当 $x > 15$ 时， $f(x) = 71x + \frac{900}{x + 8} - 752$ .
> >
> > 则 $W(x)=70x-71x-\frac{900}{x+8}+752-200=-x-\frac{900}{x+8}+552$
> >
> > 所以年利润 $W(x)$ （万元）关于年产量 $x$ （台）的函数关系式为：
> >
> > $$
> > W (x) = \left\{ \begin{array}{l} - x ^ {2} + 6 0 x - 2 0 0 (0 \leq x \leq 1 5) \\ - x - \frac {9 0 0}{x + 8} + 5 5 2 (x > 1 5) \end{array} \right.
> > $$
> >
> > (3) 由 (2) 得当 $0 \leq x \leq 15$ 时，
> >
> > $$
> > W (x) = - x ^ {2} + 6 0 x - 2 0 0 = - (x - 3 0) ^ {2} + 7 0 0
> > $$
> >
> > 所以当 x=15 时， $W(x)_{\max}=475$ ；
> >
> > 当 $x > 15$ 时， $W(x) = -x - \frac{900}{x + 8} + 552 = -\left(x + 8 + \frac{900}{x + 8}\right) + 560$ ， $\leq -2\sqrt{(x + 8)\left(\frac{900}{x + 8}\right)} + 560 = 500$
> >
> > 当且仅当 $x + 8 = \frac{900}{x + 8}$ ，即 $x = 22$ 时等号成立，
> >
> > 所以当 x = 22 时， $W(x)_{\max} = 500$
> >
> > 又 500 > 475，故 x = 22 时，利润最大，最大利润是 500 万元.
> >
> > 综上所述，年产量为 22 台时，该企业所获利润最大，最大利润是 500 万元.
