> [!faq]- 《第三章 函数的概念与性质（高效培优讲义）》官方解析
>
> > [!success]- **【答案】** (1) $W(x) = \begin{cases} -2x^2 + 120x - 300, & 0 < x \leq 40, \\ -x - \frac{25600}{x + 100} + 1800, & 40 < x \leq 100, \\ x \in \mathbb{N}^*\end{cases}$ . (2)当年产量为60台时，公司所获利润最大，最大利润是1580万元.
>
> > [!note]- **【解析】**
> > （1）当 $0 < x \leq 40$ 时， $W(x) = 180x - (2x^2 + 60x) - 300 = -2x^2 + 120x - 300$
> >
> > 当 $40 < x \leq 100$ 时， $W(x) = 180x - \left(181x + \frac{25600}{x + 100} - 2100\right) - 300 = -x - \frac{25600}{x + 100} + 1800$
> >
> > 所以 $W(x)=\left\{\begin{aligned}-2x^{2}+120x-300,0<x\leq40,x\in\mathbb{N}^{*}\\ -x-\frac{25600}{x+100}+1800,40<x\leq100,x\in\mathbb{N}^{*}\end{aligned}\right.$
> >
> > (2) 当 $0 < x \leq 40$ 时， $W(x) = -2(x - 30)^{2} + 1500$ ，当 x = 30 时， $W(x)_{\max} = 1500$ 万元.
> >
> > 当 $40 < x \leq 100$ 时， $W(x) = -\left(x + 100 + \frac{25600}{x + 100}\right) + 1900 \leq -2\sqrt{(x + 100)\left(\frac{25600}{x + 100}\right)} + 1900 = 1580$ 万元.
> >
> > 当且仅当 $x + 100 = \frac{25600}{x + 100}$ ，即 $x = 60$ 时，上式等号成立.
> >
> > 又 $1580 > 1500$ ，所以当年产量为60台时，公司所获利润最大，最大利润是1580万元.
