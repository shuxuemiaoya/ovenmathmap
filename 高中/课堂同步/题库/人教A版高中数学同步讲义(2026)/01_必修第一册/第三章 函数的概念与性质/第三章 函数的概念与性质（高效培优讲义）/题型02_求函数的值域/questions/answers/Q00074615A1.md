> [!faq]- 《第三章 函数的概念与性质（高效培优讲义）》官方解析
>
> > [!success]- **【答案】** C
>
> > [!note]- **【解析】**
> > 显然， $f(0)=\frac{1}{2}$
> >
> > 当 $x \neq 0$ 时， $f(x) = \frac{(x + 1)^2}{x^2 + 1} - \frac{1}{2} = \frac{2(x + 1)^2 - (x^2 + 1)}{2(x^2 + 1)} = \frac{x^2 + 4x + 1}{2(x^2 + 1)} = \frac{1}{2} + \frac{2}{x + \frac{1}{x}}$ .
> >
> > 令 $t = x + \frac{1}{x}$ ，当 x > 0 时， $t = x + \frac{1}{x}$ $2\sqrt{x \cdot \frac{1}{x}} = 2$ ，当且仅当 x = 1 时等号成立，
> >
> > 则 $0 < \frac{1}{t} \leq \frac{1}{2}, \frac{1}{2} < f(x) \leq \frac{1}{2} + 2 \times \frac{1}{2} = \frac{3}{2}$ ;
> >
> > 当 x<0 时， $t=x+\frac{1}{x}\leq-2\cdot\sqrt{(-x)\cdot\left(-\frac{1}{x}\right)}=-2$ ，当且仅当 x=-1 时等号成立，
> >
> > 则 $-\frac{1}{2} \leq \frac{1}{t} < 0, \frac{1}{2} - 2 \times \frac{1}{2} = -\frac{1}{2} \leq f(x) < \frac{1}{2}$
> >
> > 综上所述， $f(x)$ 的值域为 $\left[-\frac{1}{2},\frac{3}{2}\right]$
> >
> > 所以根据高斯函数的定义，函数 $y = \left[f(x)\right]$ 的值域是 $\{-1,0,1\}$
> >
> > 故选：C.
> >
> > ## 方法技巧
> >
> > (1)观察法：对于一些比较简单的函数，其值域可通过观察得到；
> >
> > (2)配方法：此法是求“二次函数类”值域的基本方法，即把函数通过配方转化为能直接看出其值域的方法；(3)分离常数法：此方法主要是针对有理分式，即将有理分式转化为“反比例函数类”的形式，便于求值域；(4)换元法：即运用新元代换，将所给函数化成值域易确定的函数，从而求得原函数的值域。
