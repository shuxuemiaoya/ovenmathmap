> [!faq]- 《第三章 函数的概念与性质（高效培优讲义）》官方解析
>
> > [!success]- **【答案】** C
>
> > [!note]- **【解析】**
> > 对于 A，因为定义在 R 上的函数 $f(x)$ 满足 $f(f(x)) = x$ ，设 $f(x) = kx + b$
> >
> > 所以 $f(f(x)) = f(kx + b) = k(kx + b) + b = k^{2}x + kb + b = x$
> >
> > 所以 $\left\{\begin{aligned}k^{2}&=1\\ kb+b&=0\end{aligned}\right.$ ，所以 $\left\{\begin{aligned}k&=1\\ b&=0\end{aligned}\right.$ 或 $\left\{\begin{aligned}k&=-1\\ b&\in\mathbb{R}\end{aligned}\right.$ ，所以 $f(x)=x$ 或 $f(x)=-x+b, b\in\mathbb{R}$ ，但 $f(x)$ 不恒等于 x，
> >
> > 所以 $f(x) = -x + b, b \in \mathbb{R}$ ，不是 R 上的增函数，故 A 错误，
> >
> > 对于B，因为 $f\big(f(-x)\big) = -x,f\big(f(x)\big) = x$ ，所以 $f\big(f(-x)\big) = -f\big(f(x)\big)$ ，所以 $f(x)$ 不可以是偶函数，故B错
> >
> > 误，
> >
> > 对于 C，当 $f(x) = -x$ 时，满足 $f(f(x)) = f(-x) = x = -f(x)$ ，故 $f(x)$ 是奇函数，故 C 正确，
> >
> > 对于D，若存在非零实数 $k$ ，使得 $f(x + k) = f(x)$ ，则 $f(f(x + k)) = x + k = f(f(x)) = x$
> >
> > 故 $k = 0$ 与 $k$ 为非零实数矛盾，故D错误，
> >
> > 故选 **C**
