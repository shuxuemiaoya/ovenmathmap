> [!faq]- 《第三章 函数的概念与性质（高效培优讲义）》官方解析
>
> > [!success]- **【答案】** (1) $f(x)=\left\{\begin{aligned}&2x^{2}-4x+3,x>0\\&0,\\&-2x^{2}-4x-3,x<0\end{aligned}\right.$ (2)① $(-∞,0]∪\left[\frac{1}{2},\frac{3}{2}\right]$ ; ② $|M|=\frac{\sqrt{2}}{2}$
>
> > [!note]- **【解析】**
> > （1）∵ $f(x)$ 是定义在 R 上的奇函数，
> >
> > $\therefore f(-x) = -f(x)$ ，且 $f(0) = 0$
> >
> > 当 $x > 0$ 时， $-x <   0$
> >
> > $$
> > \therefore f (x) = - f (- x) = - \left[ - 2 (- x) ^ {2} - 4 (- x) - 3 \right] = 2 x ^ {2} - 4 x + 3
> > $$
> >
> > 综上， $f(x)$ 的解析式为： $f(x)=\left\{\begin{aligned}&2x^{2}-4x+3,x>0\\ &0,x=0\\ &-2x^{2}-4x-3,x<0\end{aligned}\right.$
> >
> > (2) ① $g(x) + \frac{1}{2} = \frac{\left(\mathrm{e}^{x} - \mathrm{e}^{-x}\right)^{2} + \mathrm{e}^{x} + \mathrm{e}^{-x}}{2} + \frac{1}{2} = \frac{\left(\mathrm{e}^{x} + \mathrm{e}^{-x}\right)^{2} + \mathrm{e}^{x} + \mathrm{e}^{-x} - 3}{2}$ ，
> >
> > 令 $t = \mathrm{e}^{x} + \mathrm{e}^{-x}\in [2, + \infty)$ ， $y = g(x) + \frac{1}{2} = \frac{t^2 + t - 3}{2} = \frac{1}{2}\left(t + \frac{1}{2}\right)^2 -\frac{13}{8}$
> >
> > $\therefore y=\frac{t^{2}+t-3}{2}$ 在 $[2,+\infty)$ 上单调递增，
> >
> > ∴当t=2时， $y_{\min}=\left(g(x)+\frac{1}{2}\right)_{\min}=\frac{3}{2}$
> >
> > ∴不等式 $f(m) \leq g(x) + \frac{1}{2}$ 恒成立，转化为： $f(m) \leq \frac{3}{2}$
> >
> > i 当 m < 0 时， $f(m) = -2m^{2} - 4m - 3 = -2(m + 1)^{2} - 1 < 0 \leq \frac{3}{2}$ 恒成立，
> >
> > ii 当 $m = 0$ 时， $f(m) = 0 \leq \frac{3}{2}$ 恒成立，
> >
> > iii 当 $m > 0$ 时， $f(m) = 2m^2 - 4m + 3 \leq \frac{3}{2}$ ，则 $\frac{1}{2} \leq m \leq \frac{3}{2}$ ，
> >
> > 由 i, ii, iii 知：
> >
> > $\forall x \in \mathbf{R}$ 不等式 $f(m) \leq g(x) + \frac{1}{2}$ 恒成立的 $m$ 的取值范围是 $(- \infty, 0] \cup \left[\frac{1}{2}, \frac{3}{2}\right]$
> > - **②**：不妨设 $f\left[g\left(x_{1}\right)\right] \leq f\left[g\left(x_{2}\right)\right] \leq f\left[g\left(x_{3}\right)\right]$
> >
> > 依题意中的“ $\forall x_{1},x_{2},x_{3}\in D$ ，都存在以 $f[g(x_1)],f[g(x_2)],f[g(x_3)]$ 为三角形的三条边长”，
> >
> > 等价于 $f\left[g\left(x_{1}\right)\right] + f\left[g\left(x_{2}\right)\right] > f\left[g\left(x_{3}\right)\right]$
> >
> > 等价于 $2f[g(x)]_{\min} > f[g(x)]_{\max}$ 所包含的任意子区间.
> >
> > 由（2）知， $g(x)$ 1，令 $k = g(x)$ ，则 $k$ $1, f[g(x)] = f(k) = 2k^{2} - 4k + 3 = 2(k - 1)^{2} + 1$ 1。
> >
> > 又 $0 \in D$ ，当 $k = 1$ 时，有 $f[g(x)]_{\min} = 1$
> >
> > ∴所有符合条件的区间 D 上，满足 $2f[g(x)]_{\min} > f[g(x)]_{\max}$
> >
> > 即为： $2 > 2k^{2} - 4k + 3$ ，等价于 $2k^{2} - 4k + 1 < 0$ ，等价于 $1 - \frac{\sqrt{2}}{2} < k < 1 + \frac{\sqrt{2}}{2}$
> >
> > 综上， $M = \left[1,1 + \frac{\sqrt{2}}{2}\right)$ ，有 $|M| = \frac{\sqrt{2}}{2}$
