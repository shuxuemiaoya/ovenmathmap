> [!faq]- 《第三章 函数的概念与性质（高效培优讲义）》官方解析
>
> > [!success]- **【答案】** C
>
> > [!note]- **【解析】**
> > 当 $0 < x \leq \frac{l}{4}$ 时， $f(x) = x$ 为正比例函数，
> >
> > 当 $\frac{l}{4} < x \leq \frac{l}{2}$ 时， $f(x) = \sqrt{\frac{l^2}{16} + \left(x - \frac{l}{4}\right)^2}$ 不是正比例函数，
> >
> > 且 $f(x)$ 图象关于 $x = \frac{l}{2}$ 对称，
> >
> > 由题可知当 $0 \leq x \leq \frac{l}{2}$ 时，只有C项符合要求。
> >
> > 故选 **C**.
