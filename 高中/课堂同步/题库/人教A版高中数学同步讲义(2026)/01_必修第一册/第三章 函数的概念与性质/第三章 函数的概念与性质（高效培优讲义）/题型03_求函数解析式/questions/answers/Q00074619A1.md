> [!faq]- 《第三章 函数的概念与性质（高效培优讲义）》官方解析
>
> > [!success]- **【答案】** （1） $f(x)=3x+1$ 或 $f(x)=-3x-2$ ；（2） $f(x)=x^{2}-4(x-2)$ ；（3） $f(x)=\frac{1}{3}\left(x+\frac{2}{x-2}-2\right)$ $x \neq 2$
>
> > [!note]- **【解析】**
> > （1）因为 $f(x)$ 为一次函数，可设 $f(x) = kx + b$
> >
> > 所以 $f(f(x)) = f(kx + b) = k(kx + b) + b = k^{2}x + bk + b = 9x + 4$
> >
> > 所以 $\left\{\begin{aligned}k^{2}&=9\\ bk+b&=4\end{aligned}\right.$ ，解得 $\left\{\begin{aligned}k&=3\\ b&=1\end{aligned}\right.$ 或 $\left\{\begin{aligned}k&=-3\\ b&=-2\end{aligned}\right.$
> >
> > 所以 $f(x)=3x+1$ 或 $f(x)=-3x-2$
> >
> > (2) 设 $t = \sqrt{x} + 2$ ，则 t = 2， $\sqrt{x} = t - 2$ ，即 $x = (t - 2)^{2}$
> >
> > 所以 $f(t)=(t-2)^{2}+4(t-2)=t^{2}-4$
> >
> > 所以 $f(x) = x^{2} - 4(x - 2)$
> >
> > (3) 由 $f(2-x)+2f\left(2+\frac{1}{x}\right)=x$ ①，
> >
> > 用 $-\frac{1}{x}$ 代替 $x$ ，得 $f\left(2 + \frac{1}{x}\right) + 2f(2 - x) = -\frac{1}{x}$ ②，
> > - **①**：-②×2得： $-3f(2-x)=x+\frac{2}{x}$ ，
> >
> > 即 $f(2-x)=-\frac{1}{3}\left(x+\frac{2}{x}\right)$ ， $x\neq0$
> >
> > 令 $2 - x = t$ ，则 $2 - t = x$ ， $t \neq 2$
> >
> > 则： $f(t) = -\frac{1}{3}\left(2 - t + \frac{2}{2 - t}\right) = \frac{1}{3}\left(t + \frac{2}{t - 2} -2\right)$ ， $t\neq 2$
> >
> > 所以 $f(x)=\frac{1}{3}\left(x+\frac{2}{x-2}-2\right)$ ， $x\neq2$ .
