> [!faq]- 《第三章 函数的概念与性质（高效培优讲义）》官方解析
>
> > [!success]- **【答案】** (1)答案见解析 (2) $M(a) = \begin{cases} 24 - 8a, & 0 < a < 4\sqrt{3} - 5 \\ (a + 1)^2, & 4\sqrt{3} - 5 \leq a < 3 \\ 8a - 8, & a = 3 \end{cases}$
>
> > [!note]- **【解析】**
> > （1）①当 $a = 0$ 时， $f(x) = x|x| + bx$
> >
> > 由 $f(-x) = -x|x| - bx = -f(x)$ 知 $f(x)$ 为奇函数.
> > - **②**：当 $a \neq 0$ 时， $f(-x) = -x |-x - 2a| - bx = -x |x + 2a| - bx$ ，而 $f(x) = x |x - 2a| + bx$ ，故 $f(x)$ 为非奇非偶函数；
> >
> > (2) $f(x) = \begin{cases} x^2 + (2 - 2a)x, & x < 2a \\ -x^2 + (2a + 2)x, & x < 2a \end{cases}$ ,
> > - **①**：当 $0 < a \leq 1$ 时，有 $a - 1 < 2a \leq a + 1, y = f(x)$ 在 $[0,4]$ 上单调递增，
> >
> > $$
> > M (a) = f (4) = 2 4 - 8 a
> > $$
> > - **②**：当 $1 < a < 2$ 时，有 $0 < a - 1 < a + 1 < 2a < 4, y = f(x)$ 在 $[0, a + 1]$ 上单调递增，
> >
> > 在 $[a + 1,2a]$ 上单调递减，在 $[2a,4]$ 上单调递增，所以 $M(a) = \max \left\{f(a + 1),f(4)\right\}$
> >
> > $$
> > f (a + 1) - f (4) = - (a + 1) ^ {2} + (2 a + 2) (a + 1) - (2 4 - 8 a) = (a + 1) ^ {2} - (2 4 - 8 a) = a ^ {2} + 1 0 a - 2 3
> > $$
> >
> > 当 $1 < a < 4\sqrt{3} - 5$ 时， $f(a + 1) - f(4) = a^2 + 10a - 23 < 0$ ，所以 $M(a) = f(4) = 24 - 8a$ ；
> >
> > 当 $4\sqrt{3} - 5 \leq a < 2$ 时， $f(a + 1) - f(4) = a^2 + 10a - 23 > 0$ ，所以 $M(a) = f(a + 1) = (a + 1)^2$
> > - **③**：当 $2 \leq a < 3$ 时，有 $a - 1 < a + 1 < 4 \leq 2a$ ， $y = f(x)$ 在 $[0, a + 1]$ 上单调递增，
> >
> > 在 $[a + 1,4]$ 上单调递减，此时 $M(a) = f(a + 1) = (a + 1)^2$
> > - **④**：当 a = 3 时，有 $a + 1 = 4$ ， $y = f(x)$ 在 $[0, 4]$ 上单调递增，
> >
> > 此时 $M(a) = f(4) = -4^2 + 4(2a + 2) = 8a - 8$
> >
> > 综上所述，当 时， $M(a)=\left\{\begin{aligned}&24-8a,0<a<4\sqrt{3}-5\\&(a+1)^{2},4\sqrt{3}-5\leq a<3\\&8a-8,a\quad3\end{aligned}\right.$
