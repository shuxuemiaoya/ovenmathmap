> [!faq]- 《第三章 函数的概念与性质（高效培优单元测试·提升卷）》官方解析
>
> > [!success]- **【答案】** $^{(1)}$ 是，理由见解析 (2)3 (3) $(-1012,+\infty)$
>
> > [!note]- **【解析】**
> > （1）函数 $f(x)$ 是“2步长”增函数．理由如下：
> >
> > 因为 $f(x) = \log_3 x - \frac{1}{3^x}$ 的定义域为 $(0, +\infty), y = \log_3 x, y = -\frac{1}{3^x}$ 在 $(0, +\infty)$ 上都是单调递增，
> >
> > 所以 $f(x)$ 在 $(0, +\infty)$ 上单调递增，所以 $f(x + 2) - f(x) > 0$
> >
> > 所以 $f(x)$ 是“2步长”增函数.
> >
> > (2) 因为 $h(x)=x^{2}+x^{2}-x$ 是“ $\lambda$ 步长”增函数，
> >
> > 所以 $h(x+\lambda)-h(x)>0$ 恒成立，
> >
> > 所以 $h(x+\lambda)-h(x)=(x+\lambda)^{3}+(x+\lambda)^{2}-(x+\lambda)-x^{3}-x^{2}+x$
> >
> > $$
> > = x ^ {3} + 3 x ^ {2} \lambda + 3 x \lambda^ {2} + \lambda^ {3} + x ^ {2} + 2 x \lambda + \lambda^ {2} - x - \lambda - x ^ {3} - x ^ {2} + x
> > $$
> >
> > $= 3x^{2}\lambda + 3x\lambda^{2} + \lambda^{3} + 2x\lambda + \lambda^{2} - \lambda > 0$ 恒成立，
> >
> > 即 $3x^{2}+(3\lambda+2)x+\lambda^{2}+\lambda-1>0$ 恒成立，
> >
> > 由 $\Delta = (3\lambda + 2)^2 - 12(\lambda^2 + \lambda - 1) < 0$ ，解得 $\lambda < -\frac{4\sqrt{3}}{3}$ 或 $\lambda > \frac{4\sqrt{3}}{3}$
> >
> > 因为 $\lambda \in \mathbf{N}^{*}$ ，所以 $\lambda_{\mathrm{min}} = 3$
> >
> > (3) 若 $b \quad 0, f(x)$ 在 R 上单调递增，则 $f(x + 2024) - f(x) > 0$ 恒成立，符合题意；
> >
> > 若 $b < 0$ ，分以下情况：
> > - **①**：当 x > 0 时， $f(x)$ 单调递增，则 $f(x + 2024) - f(x) > 0$ 恒成立；
> > - **②**：当 $x < -2024$ 时， $x < x + 2024 < 0$ ， $f(x)$ 单调递增，则 $f(x + 2024) - f(x) > 0$ 恒成立；
> > - **③**：当 -2024 < x < 0 时，若 $f(x + 2024) - f(x) > 0$ ，则 $2x + b + 4048 - (2x - 3b) > 0$ ，解得 b > -1012；
> > - **④**：当 $x = 0$ 或 $x = -2024$ 时，若 $b > -1012$ ，则 $f(x + 2024) - f(x) > 0$
> >
> > 综上， $b$ 的取值范围是 $(-1012, +\infty)$

> > 18. 通过研究学生的学习行为，专家发现，学生的注意力随着老师讲课时间的变化而变化，讲课开始时，
> >
> > 学生的兴趣激增，中间有一段时间，学生的兴趣保持较理想的状态，随后学生的注意力开始分散，设 $f$
> >
> > $(t)$ 表示学生注意力随时间 t（分钟）的变化规律 $(f(t)$ 越大，表明学生注意力越集中）经过实验分析得
> >
> > 知： $f(t) = \left\{ \begin{array}{ll} - t^2 +24t + 100,(0 <   t,,10)\\ 240,(10 <   t,,20)\\ -7t + 380,(20 <   t,,40) \end{array} \right.$
> >
> > (1)讲课开始后第 $^{5}$ 分钟与讲课开始后第 $^{25}$ 分钟比较，何时学生的注意力更集中？
> >
> > (2)讲课开始后多少分钟，学生的注意力最集中？能持续多少分钟？
> >
> > (3)一道比较难的数学题，需要讲解 $^{25}$ 分钟，并且要求学生的注意力至少达到 $^{180}$ ，那么经过适当安排，老
> >
> > 师能否在学生达到所需的状态下讲授完这道题目？
> >
> > 【答案】 $^{(1)}$ 讲课开始 $^{25}$ 分钟时，学生的注意力比讲课开始后 $^{5}$ 分钟更集中
> >
> > (2)讲课开始 10 分钟，学生的注意力最集中，能持续 10 分钟
> >
> > (3)不能
> >
> > 【详解】（1）因为 $f(5) = -5^2 + 24 \times 5 + 100 = 195, f(25) = (-7) \times 25 + 380 = 205$
> >
> > 所以讲课开始 $^{25}$ 分钟时，学生的注意力比讲课开始后 $^{5}$ 分钟更集中。
> >
> > (2) 当 $0 < t, 10$ 时， $f(t) = -t^2 + 24t + 100 = -(t - 12)^2 + 244$ 是增函数，且 $f(10) = 240$
> >
> > 当 $20 < t$ ，40时， $f(t) = -7t + 380$ 是减函数，且 $f(20) = 240$
> >
> > 所以讲课开始 $^{10}$ 分钟，学生的注意力最集中，能持续 $^{10}$ 分钟
> >
> > (3) 当 $0 < t, 10$ 时，令 $f(t) = -t^2 + 24t + 100 = 180$ ，则 $t = 4$ 。
> >
> > 当 $20 < t, 40$ 时，令 $f(t) = -7t + 380 = 180$ ，则 $t \approx 28.57$
> >
> > 则学生注意力在 $180$ 以上所持续的时间为 $28.57 - 4 = 24.57 < 25$
> >
> > 所以老师不能在学生达到所需要的状态下讲授完这道题.

> > 19. 参加劳动是学生成长的必要途径，每个孩子都要抓住日常生活中的劳动实践机会，自觉参与、自己动
> >
> > 手，坚持不懈进行劳动，掌握必要的劳动技能。在劳动中接受锻炼、磨炼意志，培养正确的劳动价值观和
> >
> > 良好的劳动品质．大家知道，用清水洗衣服，其上残留的污渍用水越多，洗掉的污渍量也越多，但是还有
> >
> > 污渍残留在衣服上，在实验基础上现作如下假定：用 $x$ 单位的水清洗 $^{1}$ 次后，衣服上残留的污渍与本次清
> >
> > 洗前残留的污渍之比为函数 $f(x) = \frac{2}{2 + x^2}$
> >
> > (1)① 试解释 $f(0)$ 与 $f(1)$ 的实际意义；
> > - **②**：写出函数 $f(x)$ 应该满足的条件或具有的性质（写出至少 $^{2}$ 条，不需要证明）；
> >
> > (2)现有 $a(a > 0)$ 单位量的水，可以清洗一次，也可以把水平均分成2份后清洗两次．哪种方案清洗后衣服
> >
> > 上残留的污渍比较少？请说明理由。
> >
> > 【答案】 $^{(1)}$ 表示没有用水清洗时，衣服上的污渍不变；表示用 $^{1}$ 个单位的水清洗时，可清除衣服上残留的
> >
> > 污渍的 $\frac{1}{3}$ ；定义域为 $[0,+\infty)$ ，值域为 $(0,1]$ ，在区间 $[0,+\infty)$ 内单调递减。
> >
> > (2) 当 a = 4 时， $W_{1} = W_{2}$ ，此时两种清洗方法效果相同；
> >
> > 当 $a > 4$ 时， $W_{1} > W_{2}$ ，此时把 $a$ 单位的水平均分成2份后，清洗两次，残留的污渍较少；
> >
> > 当 $0 < a < 4$ 时， $W_{1} < W_{2}$ ，此时用 $a$ 单位的水清洗一次后残留的污渍较少。
> >
> > 【详解】（1）① $f(0)=1$ 表示没有用水清洗时，衣服上的污渍不变；
> >
> > $f(1)=\frac{2}{3}$ 表示用 1 个单位的水清洗时，可清除衣服上污渍的 $\frac{1}{3}$
> > - **②**：函数 $f(x)=\frac{2}{2+x^{2}}$ 的定义域为 $\left[0,+\infty\right)$ ，值域为 $(0,1]$ ，在区间 $\left[0,+\infty\right)$ 内单调递减
> >
> > (2) 设清洗前衣服上的污渍为 1，用 $a(a > 0)$ 单位的水，清洗一次后残留的污渍为 $W_{1}$
> >
> > 则 $W_{1} = 1 \times f(a) = \frac{2}{2 + a^{2}}$
> >
> > 用 $\frac{a}{2}$ 单位的水清洗 $^1$ 次，则残留的污渍为 $1 \times f\left(\frac{a}{2}\right) = \frac{8}{8 + a^2}$
> >
> > 然后再用 $\frac{a}{2}$ 单位的水清洗 $^{1}$ 次，则残留的污渍为 $W_{2} = \frac{8}{8 + a^{2}}\times f\left(\frac{a}{2}\right) = \frac{64}{\left(8 + a^{2}\right)^{2}}$
> >
> > 因为 $W_{1}-W_{2}=\frac{2}{2+a^{2}}-\frac{64}{\left(8+a^{2}\right)^{2}}=\frac{2a^{2}\left(a^{2}-16\right)}{\left(2+a^{2}\right)\left(8+a^{2}\right)^{2}}$
> >
> > 所以当 $a = 4$ 时， $W_{1} = W_{2}$ ，此时两种清洗方法效果相同；
> >
> > 当 $a > 4$ 时， $W_{1} > W_{2}$ ，此时把 $a$ 单位的水平均分成2份后，清洗两次，残留的污渍较少；
> >
> > 当 0 < a < 4 时， $W_{1} < W_{2}$ ，此时用 a 单位的水清洗一次后残留的污渍较少。
