> [!faq]- 《第三章 函数的概念与性质（高效培优单元测试·提升卷）》官方解析
>
> > [!success]- **【答案】** $[0,2]$
>
> > [!note]- **【解析】**
> > - **①**：当 a < 0 时，-a > 0，
> >
> > 当 x < a 时， $f(x)$ 单调递增，且 $f(x) < f(a) = -a^{2} + 4$ ，
> >
> > 当 x a 时， $f(x)=(x-2)^{2}$ $f(2)=0$
> >
> > 因此 $f(x)$ 不存在最小值；
> > - **②**：当 a=0 时， $f(x)=\left\{\begin{aligned}&4,x<0\\&(x-2)^{2},x&0\end{aligned}\right.$
> >
> > 当 x 0 时， $f(x)=(x-2)^{2}$ $f(2)=0$ ，故函数 $f(x)$ 存在最小值；
> > - **③**：当 $0 < a \leq 2$ 时， $-2 \leq -a < 0$
> >
> > 当 x < a 时， $f(x)$ 单调递减， $f(x) > f(a) = -a^{2} + 4$
> >
> > 当 x a 时， $f(x)=(x-2)^{2}$ $f(2)=0$
> >
> > 而 $-a^2 + 4 \geq 0$ ，故函数 $f(x)$ 存在最小值；
> > - **④**：当 a > 2 时，-a < -2
> >
> > 当 x < a 时， $f(x)$ 单调递减， $f(x) > f(a) = -a^{2} + 4$
> >
> > 当 x a 时， $f(x)=(x-2)^{2}$ $f(a)=(a-2)^{2}$
> >
> > 因为 $(a - 2)^{2} - (-a^{2} + 4) = 2a^{2} - 4a = 2a(a - 2) > 0$
> >
> > 所以 $(a-2)^{2}>-a^{2}+4$ ，因此 $f(x)$ 不存在最小值。
> >
> > 综上， $a$ 的取值范围是 $[0,2]$
> >
> > 故答案为： $[0,2]$
