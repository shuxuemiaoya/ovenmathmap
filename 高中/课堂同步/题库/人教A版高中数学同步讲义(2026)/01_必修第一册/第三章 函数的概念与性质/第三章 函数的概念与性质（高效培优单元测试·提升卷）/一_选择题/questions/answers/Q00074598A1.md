> [!faq]- 《第三章 函数的概念与性质（高效培优单元测试·提升卷）》官方解析
>
> > [!success]- **【答案】** C
>
> > [!note]- **【解析】**
> > 对于 A，因为当 x=0.5 时， $y=[0.5]=0$ ，当 x=-0.5 时， $y=[-0.5]=-1$
> >
> > 即 $[-0.5] \neq -[0.5]$ ，即函数 $y = [x]$ 不是奇函数，故A错误；
> >
> > 对于 B，由取整函数的定义可知， $[x] \leq x < [x] + 1$ ，则 $0 \leq x - [x] < 1$ ，
> >
> > 即函数 $y = x - [x]$ 的值域为 $[0,1)$ ，故B错误；
> >
> > 对于 C，不妨设函数 $f(x)=x-[x]$ 最小正周期为 T，则 T>0，且 $f(x+T)=f(x)$ ，
> >
> > 取 $x = 0$ ，即得 $f(T) = f(0)$ ，即 $T - [T] = 0$ ，则 $T$ 为整数，
> >
> > 又因 $[x + 1] = [x] + 1$ ， $f(x + 1) = x + 1 - [x + 1] = x + 1 - ([x] + 1) = x - [x] = f(x)$
> >
> > 故函数 $f(x)=x-[x]$ 的最小正周期为 1，故 C 正确；
> >
> > 对于 D，由 $2[x]^{2} + [x] - 1 < 0$ 可得： $(2[x] - 1)([x] + 1) < 0$ ，解得 $0 \leq [x] < \frac{1}{2}$
> >
> > 而 $[x]$ 是整数，则得 $[x] = 0$ ，故 $0 \leq x < 1$ ，即不等式的解集为 $\{x | 0 \leq x < 1\}$ ，故 D 错误
> >
> > 故选 **C**.
