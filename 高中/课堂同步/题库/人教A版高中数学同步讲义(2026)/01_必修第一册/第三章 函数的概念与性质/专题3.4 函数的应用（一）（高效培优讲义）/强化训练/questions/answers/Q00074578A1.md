> [!faq]- 《专题3.4 函数的应用（一）（高效培优讲义）》官方解析
>
> > [!success]- **【答案】** (1) $f(x)=\left\{\begin{aligned}-x^{2}+60x-400, & 0<x\leq40,\\ -4x-\frac{14400}{x}+1300, & 40<x\leq70.\end{aligned}\right.$ ，400万元. (2)生产60台该设备时，该企业所获利润最大，最大利润为820万元.
>
> > [!note]- **【解析】**
> > （1）当 $0 < x \leq 40(x \in \mathbb{N}^*)$ 时， $f(x) = 80x - (x^2 + 20x + 400) = -x^2 + 60x - 400$ ；
> >
> > $$
> > \text {当} 4 0 <   x \leq 7 0 (x \in \mathbf {N} ^ {*}) \text {时,} f (x) = 8 0 x - \left(8 4 x + \frac {1 4 4 0 0}{x} - 1 3 0 0\right) = - 4 x - \frac {1 4 4 0 0}{x} + 1 3 0 0
> > $$
> >
> > 综上， $f(x) = \left\{ \begin{array}{l} -x^{2} + 60x - 400,0 <   x\leq 40,\\ -4x - \frac{14400}{x} +1300,40 <   x\leq 70. \end{array} \right.$
> >
> > 当 $x = 20$ 台时， $f(20) = -20^2 + 60 \times 20 - 400 = 400$ 万元，
> >
> > 所以该企业生产 $^{20}$ 台该设备时，所获利润为 $^{400}$ 万元。
> >
> > (2) 当 $0 < x \leq 40(x \in \mathbf{N}^{*})$ 时， $f(x) = -x^{2} + 60x - 400 = -(x - 30)^{2} + 500$
> >
> > 故当 $x = 30$ 台时， $f(x)$ 取得最大值，最大值为500万元；
> >
> > 当 $40 < x \leq 70(x \in \mathbf{N}^{*})$ 时，
> >
> > $$
> > f (x) = - \left(4 x + \frac {1 4 4 0 0}{x}\right) + 1 3 0 0 \leq - 2 \sqrt {4 x \cdot \frac {1 4 4 0 0}{x}} + 1 3 0 0 = 8 2 0
> > $$
> >
> > 当且仅当 $4x=\frac{14400}{x}$ ，即 x=60 时，等号成立，
> >
> > 故当 $x = 60$ 台时， $f(x)$ 取得最大值，最大值为820万元；
> >
> > 因为 $820 > 500$ ，所以当生产60台该设备时，该企业所获利润最大，最大利润为820万元.
