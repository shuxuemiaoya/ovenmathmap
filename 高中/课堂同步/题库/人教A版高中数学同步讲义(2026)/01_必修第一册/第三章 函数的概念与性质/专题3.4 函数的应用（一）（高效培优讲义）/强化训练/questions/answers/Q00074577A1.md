> [!faq]- 《专题3.4 函数的应用（一）（高效培优讲义）》官方解析
>
> > [!success]- **【答案】** (1) $L(x) = \left\{ \begin{array}{l}72 - \frac{36}{x + 1} -4x,(0\leq x\leq 6)\\ -x^{2} + 14x + \frac{1}{2},(6 < x\leq 10) \end{array} \right.$ (2)当投入的肥料费用为 $^{2}$ 百元时，该梨树获得的利润最大，最大利润是 $^{52}$ 百元
>
> > [!note]- **【解析】**
> > （1）由题意， $L(x)=18y-x-3x=\left\{\begin{aligned}&18\left(4-\frac{2}{x+1}\right)-4x,(0\leq x\leq6)\\&18\left(-\frac{1}{18}x^{2}+x+\frac{1}{36}\right)-4x,(6<x\leq10)\end{aligned}\right.$
> >
> > 即 $L(x) = \left\{ \begin{array}{l} 72 - \frac{36}{x + 1} - 4x, (0 \leq x \leq 6) \\ -x^2 + 14x + \frac{1}{2}, (6 < x \leq 10) \end{array} \right.$ ;
> >
> > (2) 当 $0 \leq x \leq 6$ 时， $1 \leq x + 1 \leq 7$
> >
> > $$
> > L (x) = 7 2 - \frac {3 6}{x + 1} - 4 x = 7 6 - \left[ \frac {3 6}{x + 1} + 4 (x + 1) \right] \leq 7 6 - 2 \sqrt {\frac {3 6}{x + 1} \cdot 4 (x + 1)} = 5 2
> > $$
> >
> > 当且仅当 $\frac{36}{x+1}=4(x+1)$ ，即x=2时，等号成立，
> >
> > 所以当 x=2 时， $L(x)$ 取得最大值 52；
> >
> > 当 $6 < x \leq 10$ 时， $L(x) = -x^2 + 14x + \frac{1}{2} = -(x - 7)^2 + 49.5$
> >
> > 所以当 $x = 7$ 时， $L(x)$ 取得最大值，最大值为 $L(7) = 49.5$
> >
> > 所以当投入的肥料费用为 $^{2}$ 百元时，该梨树获得的利润最大，最大利润是 $^{52}$ 百元。
