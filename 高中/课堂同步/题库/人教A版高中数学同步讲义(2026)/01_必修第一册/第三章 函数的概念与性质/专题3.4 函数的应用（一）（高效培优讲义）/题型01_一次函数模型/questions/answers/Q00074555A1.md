> [!faq]- 《专题3.4 函数的应用（一）（高效培优讲义）》官方解析
>
> > [!success]- **【答案】** (1) $P = \begin{cases} t + 20, & 0 < t < 25, \\ -t + 100, & 25 \leq t \leq 30, \\ t \in \mathbf{N} \end{cases}$ ; (2) $Q = -t + 50 (0 < t \leq 30, t \in \mathbf{N})$ ; (3)详见解析.
>
> > [!note]- **【解析】**
> > （1）根据图象知，当 $0 < t < 25$ 时， $P = t + 20$ ，当 $25 \leq t \leq 30$ 时， $P = -t + 100$
> >
> > 所以每件商品的销售价格 P 与时间 t 的函数关系式为：
> >
> > $$
> > P = \left\{ \begin{array}{l} t + 2 0, 0 <   t <   2 5 \\ - t + 1 0 0, 2 5 \leq t \leq 3 0 (t \in \mathbf {N}) \end{array} \right.
> > $$
> >
> > (2) 可设日销售量 $Q$ 与时间 $t$ 的一次函数关系式为： $Q = kt + b$
> >
> > 将表格中的数据 $(20,30)$ ， $(10,40)$ 代入， $\left\{ \begin{array}{l}30 = 20k + b\\ 40 = 10k + b \end{array} \right.$ ，解得
> >
> > $k = -1 \quad b = 50$ ，所以日销售量 $Q$ 与时间的一次函数关系式为：
> >
> > $$
> > Q = - t + 5 0 \quad (0 <   t \leq 3 0, t \in \mathbf {N})
> > $$
> >
> > (3) 设该商品的日销售金额为 $y$ ，当 $0 < t < 25$ ， $t \in \mathbb{N}_{+}$ 时，由 (1)，(2) 有：
> >
> > $$
> > y = (t + 2 0) (- t + 5 0) = - t ^ {2} + 3 0 t + 1 0 0 0 = - (t - 1 5) ^ {2} + 1 2 2 5
> > $$
> >
> > 所以 t=15 （天）时， $y_{\max}=1225$ （元），
> >
> > 同理可得，当 $25 \leq t \leq 30$ ， $t \in \mathbb{N}_{+}$ 时， $y = (-t + 100)(-t + 50) = t^2 - 150t + 5000 = (t - 75)^2 - 625$
> >
> > 所以在 $t \in [25, 30]$ 时，函数单调递减，所以当 $t = 25$ （天）时， $y_{\max} = 1875$ （元）.
> >
> > 因为 $1875 > 1225$ ， $y_{\mathrm{max}} = 1875$ （元）.
> >
> > 故所求日销售金额的最大值为 1875 元，且在 30 天中的第 25 天日销售金额最大。
