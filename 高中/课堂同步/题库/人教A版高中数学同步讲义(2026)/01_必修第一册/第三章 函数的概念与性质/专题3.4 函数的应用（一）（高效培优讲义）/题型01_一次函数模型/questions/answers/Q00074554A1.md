> [!faq]- 《专题3.4 函数的应用（一）（高效培优讲义）》官方解析
>
> > [!success]- **【答案】** （1） $v(x)=\left\{\begin{aligned}&50,0\leq x<30,\\&\frac{1}{3}(180-x),30\leq x\leq180.\end{aligned}\right.$ (2) 当车流密度为 $90$ 辆/千米时，车流量可以达到最大，最大值 $2700$ 辆/小时·
>
> > [!note]- **【解析】**
> > （1）由题意：当 $0 \leq x \leq 30$ 时， $v(x) = 50$ ；当 $30 \leq x \leq 180$ 时，设 $v(x) = ax + b$
> >
> > 再由已知得 $\left\{ \begin{array}{l} 180a + b = 0 \\ 30a + b = 50 \end{array} \right.$ ，解得 $\left\{ \begin{array}{l} a = -\frac{1}{3} \\ b = 60 \end{array} \right.$
> >
> > 故函数 $v(x)$ 的表达式为 $v(x)=\left\{\begin{aligned}&50,0\leq x<30,\\ &\frac{1}{3}(180-x),30\leq x\leq180.\end{aligned}\right.$
> >
> > (2) 依题意并由 (1) 可得 $f(x) = \begin{cases} 50x, & 0 \leq x < 30 \\ \frac{1}{3}(180 - x)x, & 30 \leq x \leq 180 \end{cases}$
> >
> > 当 $0 \leq x \leq 30$ 时， $f(x)$ 为增函数，故当 $x = 30$ 时，其最大值为 $50 \times 30 = 1500$ ；
> >
> > 当 $30 \leq x \leq 180$ 时， $f(x) = \frac{1}{3} x (180 - x) = -\frac{1}{3} (x - 90)^2 + 2700,$
> >
> > 所以，当 x=90 时， $f(x)$ 在区间 $[20,200]$ 上取得最大值 2700；
> >
> > 综上，当 $x = 90$ 时， $f(x)$ 在区间[0,200]上取得最大值 $f(x)_{\max} = 2700$
> >
> > 即当车流密度为 $^{90}$ 辆/千米时，车流量可以达到最大，最大值 2700 辆/小时·
