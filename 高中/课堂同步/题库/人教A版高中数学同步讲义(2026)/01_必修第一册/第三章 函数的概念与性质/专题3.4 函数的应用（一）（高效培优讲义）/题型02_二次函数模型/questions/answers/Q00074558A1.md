> [!faq]- 《专题3.4 函数的应用（一）（高效培优讲义）》官方解析
>
> > [!success]- **【答案】** A
>
> > [!note]- **【解析】**
> > 设生产 $x$ 吨产品全部卖出，获利润为 $y$ 元，
> >
> > $$
> > \text {且} y = x Q - P = x \left(a + \frac {x}{b}\right) - \left(1 0 0 0 + 5 x + \frac {1}{1 0} x ^ {2}\right) = \left(\frac {1}{b} - \frac {1}{1 0}\right) \cdot x ^ {2} + (a - 5) x - 1 0 0 0 (x > 0)
> > $$
> >
> > 由题意知，当 $x = 150$ 时， $y$ 取最大值，此时 $Q = 40$ .
> >
> > 所以 $\left\{\begin{aligned}-\frac{a-5}{2\left(\frac{1}{b}-\frac{1}{10}\right)}&=150\\ a+\frac{150}{b}&=40\end{aligned}\right.$ 解得 $\left\{\begin{aligned}a&=45\\ b&=-30\end{aligned}\right.$
> >
> > 答案：A
