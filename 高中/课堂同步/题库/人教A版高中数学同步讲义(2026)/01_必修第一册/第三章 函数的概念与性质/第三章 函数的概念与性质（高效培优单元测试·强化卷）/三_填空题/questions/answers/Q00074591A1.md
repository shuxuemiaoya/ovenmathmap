> [!faq]- 《第三章 函数的概念与性质（高效培优单元测试·强化卷）》官方解析
>
> > [!success]- **【答案】** $1 \leq a \leq \frac{7}{4}$
>
> > [!note]- **【解析】**
> > 由题意知对任意的 $x_{1}, x_{2}, x_{3} \in \mathbb{R}$ ， $f(x_{1}) + f(x_{2}) > f(x_{3})$ 恒成立，
> >
> > 则 $2f(x)_{\min} > f(x)_{\max}$
> >
> > 因为 $f(x) = \frac{x^2 + x + a}{x^2 + x + 1} = \frac{x^2 + x + 1 + a - 1}{x^2 + x + 1} = 1 + \frac{a - 1}{x^2 + x + 1}$
> >
> > 当 a=1 时， $f(x)=1$ ，显然满足 $2f(x)_{\min}>f(x)_{\max}$ ；
> >
> > 当 $a > 1$ 时， $x^{2} + x + 1 = \left(x + \frac{1}{2}\right)^{2} + \frac{3}{4} \quad \frac{3}{4}$ ， $a > 1$ ，则 $a - 1 > 0$ ，
> >
> > 所以 $0 < \frac{1}{x^2 + x + 1} \leq \frac{4}{3}$ ， $0 < \frac{a - 1}{x^2 + x + 1} \leq \frac{4}{3}(a - 1) = \frac{4}{3} a - \frac{4}{3}$ ，
> >
> > 所以 $1 < 1 + \frac{a - 1}{x^2 + x + 1} \leq \frac{4}{3} a - \frac{1}{3}$ ，即 $1 < f(x) \leq \frac{4}{3} a - \frac{1}{3}$ ，
> >
> > 此时 $f(x)$ 没有最小值，所以 $2 \times 1$ $\frac{4}{3} a - \frac{1}{3}$ ，解得 $a \leq \frac{7}{4}$ ，故 $1 < a \leq \frac{7}{4}$ ；
> >
> > 综上， $1 \leq a \leq \frac{7}{4}$ .
> >
> > 故答案为： $1 \leq a \leq \frac{7}{4}$
