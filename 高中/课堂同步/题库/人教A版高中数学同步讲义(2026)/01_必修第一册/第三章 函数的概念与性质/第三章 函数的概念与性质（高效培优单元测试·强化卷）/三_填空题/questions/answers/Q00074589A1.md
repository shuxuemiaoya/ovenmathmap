> [!faq]- 《第三章 函数的概念与性质（高效培优单元测试·强化卷）》官方解析
>
> > [!success]- **【答案】** $(- \infty, -2) \cup (-1, 0) \cup (0, +\infty)$
>
> > [!note]- **【解析】**
> > 因对任意的 $x_{1}, x_{2} \in (0, +\infty)$ ，且 $x_{1} \neq x_{2}$ ，都有 $\frac{x_{1} f(x_{1}) - x_{2} f(x_{2})}{x_{1} - x_{2}} < 0$
> >
> > 则 $g(x) = xf(x)$ 在 $(0, +\infty)$ 上单调递减，
> >
> > 又 $f(x)$ 为奇函数及 $f(1) = 0$ ，所以 $g(-x) = -xf(-x) = xf(x) = g(x)$
> >
> > 则 $g(x)$ 为偶函数，且 $g(1) = g(-1) = 0$ ，故 $g(x)$ 在 $(- \infty, 0)$ 上单调递增，
> >
> > 所以 $g(x+1)$ 在 $(-∞,-1)$ 上单调递增，在 $(-1,+∞)$ 上单调递减.
> >
> > 又 $x \in (-\infty, 0) \cup (0, +\infty)$ ，则 $xf(x + 1) < 0 \Leftrightarrow \left\{ \begin{array}{l} f(x + 1) \langle 0, x \rangle 0 \\ f(x + 1) > 0, x < 0 \end{array} \right.$ ，
> >
> > 当 $x > 0$ 时， $f(x + 1) < 0 \Rightarrow \frac{g(x + 1)}{x + 1} < 0$ ，得 $g(x + 1) < 0$ ，解得 $x < -2$ 或 $x > 0$ ，
> >
> > 故 $x > 0$
> >
> > 当 $x < 0$ 时， $f(x + 1) > 0 \Rightarrow \frac{g(x + 1)}{x + 1} > 0$ ，即 $(x + 1)g(x + 1) > 0$ ，
> >
> > 得 $\left\{\begin{aligned}x+1&<0\\ g(x+1)&<0\end{aligned}\right.$ 或 $\left\{\begin{aligned}x+1&>0\\ g(x+1)&>0\end{aligned}\right.$ ，解得 x<-2 或 -1<x<0，
> >
> > 综上，不等式 $xf(x + 1) < 0$ 的解集为 $(- \infty, -2) \cup (-1, 0)$ .
> >
> > 故答案为： $(-∞,-2)∪(-1,0)∪(0,+∞)$
