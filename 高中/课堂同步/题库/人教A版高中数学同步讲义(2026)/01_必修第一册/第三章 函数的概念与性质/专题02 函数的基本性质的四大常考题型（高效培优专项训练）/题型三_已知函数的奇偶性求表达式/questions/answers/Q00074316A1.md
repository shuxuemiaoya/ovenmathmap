> [!faq]- 《专题02 函数的基本性质的四大常考题型（高效培优专项训练）》官方解析
>
> > [!success]- **【答案】** B
>
> > [!note]- **【解析】**
> > 因为 $f(x)$ 是 R 的奇函数 $f(x)$
> >
> > 且当 $x < 0$ 时， $f(x) = -x - 2$
> >
> > 则 $x > 0$ 时， $-x <   0$
> >
> > 所以 $f(x) = -f(-x) = -(x-2) = -x + 2$
> >
> > 对于不等式 $\frac{f(x)}{x} > 0$
> >
> > 则当 $x > 0$ 时，则 $f(x) = -x + 2 > 0$
> >
> > 故 0 < x < 2
> >
> > 当 $x < 0$ 时，则 $f(x) = -x - 2 < 0$
> >
> > 故 $-2 < x < 0$
> >
> > 综上知，x 的取值范围是 $(-2,0)\cup(0,2)$ .
> >
> > 故选 **B**.
