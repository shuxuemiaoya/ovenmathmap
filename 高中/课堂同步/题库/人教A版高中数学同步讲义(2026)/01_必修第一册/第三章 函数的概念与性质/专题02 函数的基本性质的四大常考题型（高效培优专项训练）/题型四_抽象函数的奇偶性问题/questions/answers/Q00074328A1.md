> [!faq]- 《专题02 函数的基本性质的四大常考题型（高效培优专项训练）》官方解析
>
> > [!success]- **【答案】** A. $[-1,1] \cup [3,+\infty)$ B. $[-3,-1] \cup [0,1]$ C. $[-1,0] \cup [1,+\infty)$ D. $[-1,0] \cup [1,3]$
>
> > [!note]- **【解析】**
> > 因为在R上的奇函数 $f(x)$ 在 $(0,+\infty)$ 上单调递减，且 $f(-2)=0$ 所以 $f(x)$ 在 $(-∞,0)$ 上也是单调递减，且 $f(0)=0,f(2)=-f(-2)=0$ ，所以当 $x∈(-∞,-2)∪(0,2)$ 时， $f(x)>0$ ，
> >
> > 当 $x \in (-2, 0) \cup (2, +\infty)$ 时， $f(x) < 0$ 。
> >
> > 所以由 $xf(x - 1)$ 0可得： $\left\{ \begin{array}{ll}x <   0\\ -2\leq x - 1\leq 0 \end{array} \right.$ 或 $\left\{ \begin{array}{ll}x > 0\\ 0\leq x - 1\leq 2 \end{array} \right.$ 或 $x = 0$
> >
> > 解得 $-1 \leq x < 0$ 或 $1 \leq x \leq 3$ 或 x = 0 ，即 $-1 \leq x \leq 0$ 或 $1 \leq x \leq 3$ 。
> >
> > 所以满足 $xf(x-1)$ 0 的 x 的取值范围是 $[-1,0]\cup[1,3]$ .
> >
> > 故选 **D**.
