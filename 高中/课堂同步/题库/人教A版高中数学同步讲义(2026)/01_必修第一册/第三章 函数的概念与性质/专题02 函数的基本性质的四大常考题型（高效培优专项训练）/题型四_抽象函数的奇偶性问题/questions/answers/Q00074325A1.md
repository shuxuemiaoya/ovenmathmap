> [!faq]- 《专题02 函数的基本性质的四大常考题型（高效培优专项训练）》官方解析
>
> > [!success]- **【答案】** D
>
> > [!note]- **【解析】**
> > 对任意 $x_{1}, x_{2} \in [-2023, 2023]$ 有 $f(x_{1} + x_{2}) = f(x_{1}) + f(x_{2}) - 2022$ ，则令 $x_{1} = x_{2} = 0, f(0) = f(0) + f(0) - 2022 \Rightarrow f(0) = 2022$
> >
> > 令 $x_{1} = x, x_{2} = -x, f(0) = f(x) + f(-x) - 2022 \Rightarrow f(x) + f(-x) = 4044 \Rightarrow -[f(x) - 2022] = f(-x) - 2022$ ，令 $g(x) = f(x) - 2022$ ，则 $g(x) = -g(-x)$ ，故 $g(x)$ 为 $[-2023, 2023]$ 上的奇函数，故 $g(x)_{\min} + g(x)_{\max} = 0 \text{ P } f(x)_{\min} - 2022 + f(x)_{\max} - 2022 = 0 \text{ P } M + N = f(x)_{\min} + f(x)_{\max} = 4044$ 。
> >
> > 故选 **D**.
