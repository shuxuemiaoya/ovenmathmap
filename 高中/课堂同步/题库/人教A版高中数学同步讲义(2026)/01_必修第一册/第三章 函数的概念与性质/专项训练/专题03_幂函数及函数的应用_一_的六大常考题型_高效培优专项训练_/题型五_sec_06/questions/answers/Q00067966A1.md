> [!faq]- 《专题03_幂函数及函数的应用_一_的六大常考题型_高效培优专项训练_》官方解析
>
> > [!success]- **【答案】** (1) $L(x)=\left\{\begin{aligned}&\frac{1}{6}x^{2}+20x-300(0<x\leq30,x\in\mathbf{N}),\\&1200-\left(4x+\frac{19600}{x}\right)(x>30,x\in\mathbf{N}).\end{aligned}\right.$ (2)70 个，640 万元
>
> > [!note]- **【解析】**
> > （ $^{1}$ ）根据题意得
> >
> > 当 $0 < x \leq 30$ 时， $L(x) = 30x + \frac{1}{6}x^2 - 10x - 300 = \frac{1}{6}x^2 + 20x - 300$
> >
> > 当 $x > 30$ 时， $L(x) = 30x - 34x - \frac{19600}{x} + 1500 - 300 = -4x - \frac{19600}{x} + 1200$
> >
> > 所以 $L(x)=\left\{\begin{aligned}&\frac{1}{6}x^{2}+20x-300(0<x\leq30,x\in\mathbf{N}),\\&1200-\left(4x+\frac{19600}{x}\right)(x>30,x\in\mathbf{N}).\end{aligned}\right.$
> >
> > (2) 当 $0 < x \leq 30$ 时， $L(x) = \frac{1}{6}x^{2} + 20x - 300 = \frac{1}{6}(x + 60)^{2} - 900$
> >
> > $L(x)$ 在 $(0,30]$ 内单调递增，所以当 x=30 时， $L(x)$ 的最大值为 450，
> >
> > 当 $x > 30$ 时， $L(x) = 1200 - \left(4x + \frac{19600}{x}\right)$ ，
> >
> > 因为 $4x + \frac{19600}{x}$ $2\sqrt{4 \times 19600} = 560$ ，当且仅当 $4x = \frac{19600}{x}$ ，
> >
> > 即 $x = 70$ 时，等号成立，
> >
> > 所以 $L(x)\leq 1200 - 560 = 640$
> >
> > 因为 640 > 450，所以当 x = 70 时， $L(x)$ 的最大值为 640，
> >
> > 所以建造 $^{70}$ 个生态农场获得的利润最大，最大利润为640万元。
> >
> > 54．2024年9月29日，渝昆高铁正式开通运行，重庆到泸州最快30分钟，完成了川渝两地旅客高铁出行的最后一块拼图·现在已知列车的发车时间间隔 $t$ （单位：分钟）满足 $2 \leq t \leq 20$ ·经市场调研测算，列车载客量与发车时间间隔 $t$ 相关，当 $10 \leq t \leq 20$ 时列车为满载状态，载客量为720人；当 $2 \leq t < 10$ 时，载客量会减少，减少的人数 $s(t) = k(12 - t)^{2}$ ，（ $k$ 为常数），且发车时间间隔为3分钟时的载客减少量为324人·记列车载客量为 $p(t)$ .
> >
> > (1)求 $p(t)$ 的表达式；
> >
> > (2)为响应低碳出行，若载客量至少达到 $524$ 人时，列车才发车，问列车发车间隔时间至少多少分钟？
> >
> > (3)若该线路每分钟的净收益为 $Q(t) = \frac{2p(t) - 360}{t} - 60$ （元），问当发车时间间隔为多少时，该线路每分钟的净收益最大，并求出最大值.
> >
> > 【答案】(1) $p(t)=\left\{\begin{aligned}-4t^{2}+96t+144,2\leq t<10\\720,10\leq t\leq20\end{aligned}\right.$
> >
> > (2)至少 $^{5}$ 分钟；
> >
> > (3)时间间隔为 $^{3}$ 分钟时，每分钟的净收益最大为 84 元.
> >
> > 【详解】（1）由题知，当 $10 \leq t \leq 20$ 时， $p(t) = 720$ ；
> >
> > 当 $2 \leq t < 10$ 时, $p(t) = 720 - k(12 - t)^{2}$ ,
> >
> > 因为发车时间间隔为 $^{3}$ 分钟时的载客减少量为 324 人，
> >
> > 此时发车时间间隔为 $^{3}$ 分钟时的载客量为 720 - 324 = 396 人，
> >
> > $\therefore p(3) = 720 - k(12 - 3)^{2} = 396$ ，解得 $k = 4$
> >
> > 此时 $p(t)=720-4\times(12-t)^{2}=-4t^{2}+96t+144$
> >
> > 所以 $p(t)=\left\{\begin{aligned}-4t^{2}+96t+144,2\leq t<10\\720,10\leq t\leq20\end{aligned}\right.$
> >
> > (2) 依题意 $p(t)$ 524
> >
> > 当 $10 \leq t \leq 20$ 时， $p(t) = 720 > 524$ ，满足题意；
> >
> > 当 $2 \leq t < 10$ 时， $p(t) = -4t^2 + 96t + 144\quad 524$ ，即 $t^2 - 24t + 95 \leq 0$ ，
> >
> > 解得 $5 \leq t \leq 9$ ，所以列车发车间隔时间至少 $5$ 分钟，列车载客量至少达到 $524$ 人·
> >
> > (3) 由 (1) 知 $Q(t) = \begin{cases} 132 - 8t - \frac{72}{t}, & 2 \leq t < 10 \\ \frac{1080}{t} - 60, & 10 \leq t \leq 20 \end{cases}$
> >
> > $\because 2 \leq t < 10$ 时， $Q(t) \leq 132 - 2\sqrt{8t \cdot \frac{72}{t}} = 84$ ，当且仅当 t = 3 等号成立，
> >
> > ∴ $2 \leq t < 10$ 时， $Q(t)_{\max} = Q(3) = 84,$
> >
> > 当 $10 \leq t \leq 20$ 上， $Q(t)$ 单调递减，则 $Q(t)_{\max} = Q(10) = 48$
> >
> > 综上，时间间隔为 $^{3}$ 分钟时，每分钟的净收益最大为 $^{84}$ 元·
