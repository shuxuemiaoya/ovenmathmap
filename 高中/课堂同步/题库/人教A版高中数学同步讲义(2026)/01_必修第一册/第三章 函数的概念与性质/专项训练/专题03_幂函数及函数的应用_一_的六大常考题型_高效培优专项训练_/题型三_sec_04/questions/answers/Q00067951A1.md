> [!faq]- 《专题03_幂函数及函数的应用_一_的六大常考题型_高效培优专项训练_》官方解析
>
> > [!success]- **【答案】** (1) $m = -3$ (2) $a < 2$ (3)2
>
> > [!note]- **【解析】**
> > （1）由 $f(x) = (m^2 + 4m + 4)x^{m+2}$ 是幂函数，得 $m^2 + 4m + 4 = 1$ ，解得 $m = -1$ 或 $m = -3$
> >
> > 当 $m = -1$ 时， $f(x) = x$ ，在 $(0, +\infty)$ 上单调递增，不合题意；
> >
> > 当时， $f(x)=x^{-1}$ ，在 $(0,+\infty)$ 上单调递减，符合题意，
> >
> > 所以 $m = -3$
> >
> > (2) 若 $(2a+1)^{-m} < (a+3)^{-m}$ ，即 $(2a+1)^{3} < (a+3)^{3}$ ，
> >
> > ∵函数 $y = x^{3}$ 在 R 上单调递增，
> >
> > ∴ $2a + 1 < a + 3$ ，解得 a < 2
> >
> > (3) $h(x) = x^{\frac{1}{2}} = \sqrt{x}$ ，则 $h(x - 3) + h(5 - x) = \sqrt{x - 3} + \sqrt{5 - x}$ ， $3 \leq x \leq 5$ ，
> >
> > $$
> > \therefore \frac {\sqrt {x - 3} + \sqrt {5 - x}}{2} \leq \sqrt {\frac {(\sqrt {x - 3}) ^ {2} + (\sqrt {5 - x}) ^ {2}}{2}} = 1
> > $$
> >
> > $\therefore \sqrt{x - 3} + \sqrt{5 - x} \leq 2$ ，当且仅当 $x = 4$ 取等号，
> >
> > ∴ $h(x-3)+h(5-x)$ 的最大值为 2.
