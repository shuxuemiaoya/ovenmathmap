> [!faq]- 《专题03_幂函数及函数的应用_一_的六大常考题型_高效培优专项训练_》官方解析
>
> > [!success]- **【答案】** A. $2a < b + c$ B. $a(b - c) < b(a - c)$ C. $\frac{1}{a - c} >\frac{1}{b - c}$ D. $(a - c)^3 >(b - c)^3$
>
> > [!note]- **【解析】**
> > 对于 A，因为 a > b > c > 0，所以 a > b, a > c，所以 $2a > b + c$ ，故 A 错误；
> >
> > 对于 B， $a(b-c)-b(a-c)=c(b-a)$ ，因为 a>b>c>0，所以 $c(b-a)<0$ ，
> >
> > 即 $a(b - c) < b(a - c)$ ，故 $\mathsf{B}$ 正确；
> >
> > 对于 $^{C}$ ，因为 a > b > c > 0，a - c > b - c > 0，所以 $\frac{1}{a - c} < \frac{1}{b - c}$ ，故 $^{C}$ 错误；
> >
> > 对于 $^{D}$ ，因为a>b>c>0，a-c>b-c>0，根据幂函数 $y=x^{3}$ 在R上单调递增，
> >
> > 所以 $\left(a - c\right)^3 >\left(b - c\right)^3$ ，故D正确，
> >
> > 故选 **BD**.
