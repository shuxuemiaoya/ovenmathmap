> [!faq]- 《专题03_幂函数及函数的应用_一_的六大常考题型_高效培优专项训练_》官方解析
>
> > [!success]- **【答案】** ABC
>
> > [!note]- **【解析】**
> > A选项：函数 $f(x) = \sqrt{(a + 1)x^2 + x - a} (a \in \mathbb{R})$ ，当 $\begin{cases} a + 1 > 0 \\ 1^2 - 4(a + 1) \cdot (-a) \leq 0 \end{cases}$ 时，即 $a = -\frac{1}{2}$ 时，其定义域为 $\mathbb{R}$ ，故A选项正确；
> >
> > B选项：当 $a + 1 < 0$ ，即 $a < -1$ 时，函数 $y = (a + 1)x^{2} + x - a$ 在 $\left(-\infty, -\frac{1}{2a + 2}\right)$ 上单调递增，在 $\left(-\frac{1}{2a + 2}, +\infty\right)$ 上单调递减，不成立；
> >
> > 当 $a + 1 = 0$ ，即 $a = -1$ 时， $f(x) = \sqrt{x + 1}$ ，在 $(-1, +\infty)$ 上单调递增，满足在区间 $[0, +\infty)$ 上递增，成立；当 $a + 1 > 0$ ，即 $a > -1$ 时，函数 $y = (a + 1)x^2 + x - a$ 在 $\left(-\infty, -\frac{1}{2a + 2}\right)$ 上单调递减，在 $\left(-\frac{1}{2a + 2}, +\infty\right)$ 上单调递增，故 $-\frac{1}{2a + 2} \leq 0$ ，且 $f(0) = \sqrt{-a} - 0$ ，即 $-1 < a \leq 0$ ；综上所述，若函数 $f(x)$ 在区间 $[0, +\infty)$ 上递增， $a \in [-1, 0]$ ，故 B 选项正确；
> >
> > C 选项：由 $1^{2} - 4(a + 1)(-a) = 4a^{2} + 4a + 1$ 0 恒成立， $f(x) = \sqrt{(a + 1)x^2 + x - a} = \sqrt{[(a + 1)x - a] \cdot (x + 1)}$ 当 $a = -\frac{1}{2}$ 时， $f(x) = \sqrt{\frac{1}{2}x^2 + x + \frac{1}{2}} = \sqrt{\frac{1}{2}(x + 1)^2}$ ， $x = -1$ 时取最小值为 0；
> >
> > 当 $a < -1$ 且 $a \neq -\frac{1}{2}$ 时， $f(x)$ 在 $x = -1$ 或 $x = \frac{a}{a + 1}$ 时取最小值为 0；当 $a = -1$ 时， $f(x) = \sqrt{x + 1}$ ， $x = -1$ 时取最小值为 0；
> >
> > 当 $a > -1$ 时， $f(x)$ 在 $x = -1$ 或 $x = \frac{a}{a + 1}$ 时取最小值为0；故C选项正确；
> >
> > D 选项：当 $a = -\frac{1}{2}$ 时， $f(x) = \sqrt{\frac{1}{2}x^2 + x + \frac{1}{2}} = \sqrt{\frac{1}{2}(x + 1)^2}$ ，其值域为 $[0, +\infty)$ ，
> >
> > 当 $a < -1$ 且 $a \neq -\frac{1}{2}$ 时， $f(x)$ 在 $x = -\frac{1}{2a + 2}$ 时取最大值为 $f\left(-\frac{1}{2a + 2}\right) = \sqrt{\frac{-4a^2 - 4a - 1}{4(a + 1)}}$ ，其值域为
> >
> > $\left[0, \sqrt{\frac{-4a^2 - 4a - 1}{4(a + 1)}}\right]$ ，故D选项错误；
> >
> > 故选 **ABC**.
