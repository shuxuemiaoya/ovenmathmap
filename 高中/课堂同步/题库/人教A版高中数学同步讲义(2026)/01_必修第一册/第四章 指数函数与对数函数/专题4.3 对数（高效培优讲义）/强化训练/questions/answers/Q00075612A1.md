> [!faq]- 《专题4.3 对数（高效培优讲义）》官方解析
>
> > [!success]- **【答案】** （1）1；（2） $x=1+\log_{2}15,y=1+\log_{3}10,z=1+\log_{5}6$ ；（3）3
>
> > [!note]- **【解析】**
> > 解：（1）解法1由 $3^{a} = 4^{b} = 36$ ，得 $a = \log_336, b = \log_436$ ，由换底公式得 $\frac{1}{a} = \log_{36}3, \frac{1}{b} = \log_{36}4$ ，所
> >
> > 以 $\frac{2}{a} +\frac{1}{b} = 2\log_{36}3 + \log_{36}4 = \log_{36}36 = 1$
> >
> > 解法2 由 $3^{a} = 4^{b} = 36$ ，两边同时取以6为底数的对数，得 $a\log_63 = b\log_64 = \log_636 = 2$ ，所以
> >
> > $\frac{2}{a} = \log_63, \frac{1}{b} = \frac{1}{2}\log_64 = \log_62$ ，所以 $\frac{2}{a} + \frac{1}{b} = \log_63 + \log_62 = \log_66 = 1$
> >
> > (2) 令 $2^{x} = 3^{y} = 5^{z} = k (k > 0)$ ，所以 $x = \log_{2} k, y = \log_{3} k, z = \log_{5} k$ ，所以 $\frac{1}{x} = \log_{k} 2, \frac{1}{y} = \log_{k} 3, \frac{1}{z} = \log_{k} 5$ ，由
> >
> > $\frac{1}{x}+\frac{1}{y}+\frac{1}{z}=1$ ，得 $\log_{k}2+\log_{k}3+\log_{k}5=\log_{k}30=1$ ，所以 k=30，所以
> >
> > $$
> > x = \log_ {2} 3 0 = 1 + \log_ {2} 1 5, y = \log_ {3} 3 0 = 1 + \log_ {3} 1 0, z = \log_ {5} 3 0 = 1 + \log_ {5} 6
> > $$
> >
> > $$
> > \text {(3)} \text {原式} = 2 \lg 5 + 2 \lg 2 + \lg 5 (\lg 4 + \lg 5) + (\lg 2) ^ {2} = 2 + 2 \lg 5 \lg 2 + (\lg 5) ^ {2} + (\lg 2) ^ {2} = 2 + (\lg 2 + \lg 5) ^ {2} = 2 + 1 = 3
> > $$
