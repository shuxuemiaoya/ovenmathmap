> [!faq]- 《专题4.3 对数（高效培优讲义）》官方解析
>
> > [!success]- **【答案】** ACD
>
> > [!note]- **【解析】**
> > 对于 $\mathsf{A}$ ，因为正实数 $a,b$ 满足 $\ln (a + b) = \ln a + \ln b = \ln ab$ ，所以 $ab = a + b, a > 0, b > 0$ 所以 $ab = a + b, 2\sqrt{ab}$ ，解得 $ab = 4$ ，当且仅当 $\left\{ \begin{array}{l} a = b \\ ab = a + b \end{array} \right.$
> >
> > 即 $a = b = 2$ 时， $ab$ 取到最小值4，故 $\mathsf{A}$ 正确；
> >
> > 对于 B，由 $ab = a + b$ 得 $\frac{1}{b} + \frac{1}{a} = 1$
> >
> > 所以 $a + 4b = (a + 4b)\left(\frac{1}{b} +\frac{1}{a}\right) = \frac{a}{b} +\frac{4b}{a} +5\quad 2\sqrt{\frac{a}{b}\cdot\frac{4b}{a}} +5 = 9$
> >
> > 当且仅当 $\left\{ \begin{array}{l} \frac{a}{b} = \frac{4b}{a} \\ \frac{1}{b} + \frac{1}{a} = 1 \end{array} \right.$ 即 $\left\{ \begin{array}{ll} a = 3 \\ b = \frac{3}{2} \text{时, 取到最小值} \\ a + 4b & 9 \end{array} \right.$ , 故 $^{\mathrm{B}}$ 错误;
> >
> > 对于 C，因为 $ab = a + b, a > 0, b > 0$ ，所以 $(a - 1)(b - 1) = ab - a - b + 1 = 1$ ，
> >
> > 所以 $\frac{1}{a - 1} >0,\frac{1}{b - 1} >0$ ，所以 $\frac{1}{a - 1} +\frac{1}{b - 1}$ $2\sqrt{\frac{1}{a - 1}\cdot\frac{1}{b - 1}} = 2$
> >
> > 当且仅当 $\left\{ \begin{array}{l} \frac{1}{a - 1} = \frac{1}{b - 1} \\ \frac{1}{b} + \frac{1}{a} = 1 \\ a = b = 2 \end{array} \right.$ 即 $a = b = 2$ 时， $\frac{1}{a - 1} + \frac{1}{b - 1}$ 取到最小值，故 $^{\mathbb{C}}$ 正确；
> >
> > 对于 D， $\frac{1}{a+1}+\frac{1}{b+1}=\frac{a+b+2}{(a+1)(b+1)}=\frac{a+b+2}{ab+a+b+1}=\frac{ab+2}{2ab+1}=\frac{1}{2}+\frac{\frac{3}{2}}{2ab+1}$ ，由 A 选项可知 ab 4由函数 $y = \frac{1}{2} + \frac{\frac{3}{2}}{2x + 1}$ 在 $[4, +\infty)$ 上单调递减可知， $\frac{1}{2} + \frac{\frac{3}{2}}{2ab + 1} \leq \frac{1}{2} + \frac{\frac{3}{2}}{2 \times 4 + 1} = \frac{2}{3}$ ，
> >
> > 所以 $\frac{1}{a + 1} +\frac{1}{b + 1}\leq \frac{2}{3}$ ，故D正确·
> >
> > 故选 **ACD**
