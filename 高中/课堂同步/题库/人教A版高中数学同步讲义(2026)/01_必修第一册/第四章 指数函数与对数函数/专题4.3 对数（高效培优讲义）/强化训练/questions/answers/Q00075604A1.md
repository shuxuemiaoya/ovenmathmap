> [!faq]- 《专题4.3 对数（高效培优讲义）》官方解析
>
> > [!success]- **【答案】** C
>
> > [!note]- **【解析】**
> > 因为 $\frac{\ln^2a + \ln^2b}{\ln^2(ab^2)} = \frac{\ln^2a + \ln^2b}{(\ln a + \ln b^2)^2} = \frac{\ln^2a + \ln^2b}{(\ln a + 2\ln b)^2}$
> >
> > 令 $\left\{ \begin{array}{l}x = \ln a\\ y = \ln b \end{array} \right.$ ，则 $\frac{\ln^2a + \ln^2b}{(\ln a + 2\ln b)^2} = \frac{x^2 + y^2}{(x + 2y)^2} = \frac{x^2 + y^2}{x^2 + 4y^2 + 4xy}$
> >
> > 又 $4xy \leq (2x)^{2} + y^{2} = 4x^{2} + y^{2}$ ，当且仅当 $2x = y$ 时取等号，
> >
> > 所以 $\frac{x^2 + y^2}{(x + 2y)^2} = \frac{x^2 + y^2}{x^2 + 4y^2 + 4xy}$ $\frac{x^2 + y^2}{5x^2 + 5y^2} = \frac{1}{5}$ ，当且仅当 $2x = y \neq 0$ 时取等号，
> >
> > 即 $\frac{\ln^2a + \ln^2b}{\ln^2(ab^2)}$ 的最小值为 $\frac{1}{5}$ ，当且仅当 $b = a^2 \neq 1$ 时取等号，
> >
> > 所以 $\frac{\ln^2a + \ln^2b}{\ln^2(ab^2)}$ 的取值范围是 $\left[\frac{1}{5}, + \infty\right)$
> >
> > 故选 **C**
