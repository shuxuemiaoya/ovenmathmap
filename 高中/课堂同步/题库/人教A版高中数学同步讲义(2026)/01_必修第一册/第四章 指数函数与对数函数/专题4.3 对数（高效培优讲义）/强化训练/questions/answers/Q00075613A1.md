> [!faq]- 《专题4.3 对数（高效培优讲义）》官方解析
>
> > [!success]- **【答案】** $(1)$ 12； $(2)$ $\frac{b}{a}=\frac{\sqrt{5}+1}{2}$
>
> > [!note]- **【解析】**
> > 解：（1）由 $\log_a 3 = m, \log_a 2 = n$ 得 $a^m = 3, a^n = 2$ ，因此 $a^{m+2n} = a^m \cdot a^{2n} = 3 \times 2^2 = 12$
> >
> > (2) 设 $\log_4 a = \log_6 b = \log_9 (a + b) = m, a > 0, b > 0$ ，则 $a = 4^m, b = 6^m, a + b = 9^m$ ，所以
> >
> > $a+b=9^{m}=\frac{36^{m}}{4^{m}}=\frac{6^{2m}}{4^{m}}=\frac{b^{2}}{a}$ ，整理得 $\left(\frac{b}{a}\right)^{2}-\frac{b}{a}-1=0$ ．又a>0,b>0，所以 $\frac{b}{a}=\frac{\sqrt{5}+1}{2}$
