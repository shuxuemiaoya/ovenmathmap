> [!faq]- 《专题4.3 对数（高效培优讲义）》官方解析
>
> > [!success]- **【答案】** (1)① $\frac{1}{a} = \log_{k} 2$ ; ② m = 1 (2) $5 + 4\log_{2}3 + \log_{3}2$
>
> > [!note]- **【解析】**
> > 解：（1）①因为 $2^{a} = 3^{b} = 6^{c} = k$ ，所以 $a = \log_2k = \frac{1}{\log_k2}$ ，所以 $\frac{1}{a} = \log_k2$
> > - **②**：因为 $\frac{1}{a} +\frac{1}{b} = \log_k2 + \log_k3 = \log_k6,\frac{1}{c} = \log_k6$ ，且 $\frac{1}{a} +\frac{1}{b} = \frac{m}{c}$ ，所以 $\log_k6 = m\log_k6$ ，解得 $m = 1$ ：
> >
> > (2) 由不等式 $4a + b$ tc，得 $t \leq \frac{4a}{c} + \frac{b}{c} = \frac{4\log_2k}{\log_6k} + \frac{\log_3k}{\log_6k} = \frac{4\lg 6}{\lg 2} + \frac{\lg 6}{\lg 3} = 4\log_26 + \log_36 = 4(1 + \log_23) +$
> >
> > $\left(1 + \log_32\right) = 5 + 4\log_23 + \log_32$ 所以 $t$ 的最大值 $5 + 4\log_23 + \log_32$
