> [!faq]- 《专题4.3 对数（高效培优讲义）》官方解析
>
> > [!success]- **【答案】** (1) x=1 或 x=2 或 x=3 或 x=4 或 x=5 或 x=6 (2) $x = 4$
>
> > [!note]- **【解析】**
> > （1）因为 $\left(x^{2}-5x+5\right)^{x^{2}-11x+30}=1$ ，所以
> >
> > $\left\{\begin{aligned}x^{2}-5x+5&\neq0\\ x^{2}-11x+30&=0\end{aligned}\right.$ ，解得x=5或x=6；
> > - **②**：$x^{2}-5x+5=1$ ，解得 x=4 或 x=1；
> > - **③**：$x^{2}-5x+5=-1$ ，解得 x=2 或 x=3，
> >
> > 当 x=2 时， $x^{2}-11x+30=12$ ，符合题意；
> >
> > 当 x=3 时， $x^{2}-11x+30=6$ ，符合题意；
> >
> > 综上，方程的解为 x=1 或 x=2 或 x=3 或 x=4 或 x=5 或 x=6；
> >
> > (2) 由 $\log_4(2^x + 48) = x - 1$ 得 $2^x + 48 = 4^{x-1} = \frac{1}{4} \times 2^{2x}$
> >
> > 所以 $\left(2^{x}\right)^{2} - 4 \times 2^{x} - 48 \times 4 = 0 \Rightarrow \left(2^{x} - 16\right)\left(2^{x} + 12\right) = 0$
> >
> > 由于 $2^{x} + 12 \neq 0$ ，所以 $2^{x} - 16 = 0$ ，故 x = 4，
> >
> > 故方程的解为 $x = 4$
