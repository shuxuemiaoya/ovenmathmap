> [!faq]- 《专题4.3 对数（高效培优讲义）》官方解析
>
> > [!success]- **【答案】** A. ab 4 B. $a + 9b$ 16 C. $\lg a + \lg 4b$ 的最小值为 $2\lg 2$ D. $\sqrt{\frac{1}{a}} + \sqrt{\frac{1}{b}}$ 的最大值为 $2\sqrt{2}$
>
> > [!note]- **【解析】**
> > 对于 $^{A}$ ：因为 a > 0，b > 0， $a + b = ab$ ，所以 $a + b = 2\sqrt{ab}$ ，即 $ab = 2\sqrt{ab}$
> >
> > 解得 $ab$ 4（当 $a = b = 2$ 时取等号），故 $\mathsf{A}$ 正确；
> >
> > 对于 B：由 $a + b = ab$ ，得 $\frac{1}{a} + \frac{1}{b} = 1$
> >
> > 所以 $a+9b=\left(a+9b\right)\left(\frac{1}{a}+\frac{1}{b}\right)=10+\frac{9b}{a}+\frac{a}{b}$
> >
> > $10+2\sqrt{\frac{9b}{a}\cdot\frac{a}{b}}=16$ （当 a=4， $b=\frac{4}{3}$ 时取等号），故 B 正确；
> >
> > 对于 C： $\lg a + \lg(4b) = \lg(4ab)$ $\lg 16 = 4\lg 2$ （当 a = b = 2 时取等号），故 C 错误；
> >
> > 因为 $\left(\sqrt{\frac{1}{a}} +\sqrt{\frac{1}{b}}\right)^2 = \frac{1}{a} +\frac{1}{b} +2\sqrt{\frac{1}{ab}} = 1 + 2\sqrt{\frac{1}{ab}}$ ，又 $0 <   \frac{1}{ab}\leq \frac{1}{4}$
> >
> > 所以 $\left(\sqrt{\frac{1}{a}} +\sqrt{\frac{1}{b}}\right)^2\leq 1 + 2\sqrt{\frac{1}{4}} = 2$ ，所以 $\sqrt{\frac{1}{a}} +\sqrt{\frac{1}{b}}\leq \sqrt{2}$ （当 $a = b = 2$ 时取等号），故D错误.
> >
> > 故选 **AB**
