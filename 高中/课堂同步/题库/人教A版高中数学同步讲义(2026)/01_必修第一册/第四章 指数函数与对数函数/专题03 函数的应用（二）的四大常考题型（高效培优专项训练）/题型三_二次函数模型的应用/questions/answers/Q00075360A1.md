> [!faq]- 《专题03 函数的应用（二）的四大常考题型（高效培优专项训练）》官方解析
>
> > [!success]- **【答案】** A. 2千克/小时 B. 3千克/小时 C. 4千克/小时 D. 6千克/小时
>
> > [!note]- **【解析】**
> > 由题意得，生产 $^{100}$ 千克该产品获得的利润为 $f(x)=\frac{100}{x}\cdot100\left(3x+1-\frac{2}{x}\right)=10000\left(3+\frac{1}{x}-\frac{2}{x^{2}}\right)=10000\left[-2\left(\frac{1}{x}\right)^{2}+\frac{1}{x}+3\right]$ ， $1\leq x\leq10$ 令 $t=\frac{1}{x}$ ， $\frac{1}{10}\leq t\leq1$ ，则 $f(t)=10000(-2t^{2}+t+3)=-20000\left[\left(t-\frac{1}{4}\right)^{2}-\frac{25}{16}\right]$ ，故当 $t=\frac{1}{4}$ 时， $f(t)$ 最大，此时
> > x=4.
> > 故选：C

> > 23. 一家报刊推销员从报社买进报纸的价格是每份 $^{2}$ 元，卖出的价格是每份 $^{3}$ 元，卖不完的还可以以每份0.8元的价格退回报社。在一个月（以 $^{30}$ 天计算）内有 $^{20}$ 天每天可卖出 $^{400}$ 份，其余 $^{10}$ 天每天只能卖出 $^{250}$ 份，且每天从报社买进报纸的份数都相同，要使推销员每月所获得的利润最大，则应该每天从报社买进报纸
> > A. 215 份 B. 350 份
> > C. 400 份 D. 250 份
> >
> > 【答案】C
> >
> > 【详解】设每天从报社买进 $x$ （ $250 \leq x \leq 400$ ， $x \in \mathbb{N}$ ）份报纸时，每月所获利润为 $y$ 元，具体情况如下表。
> >
> > <table><tr><td></td><td>数量/份</td><td>单价/元</td><td>金额/元</td></tr><tr><td>买进</td><td>30x</td><td>2</td><td>60x</td></tr><tr><td>卖出</td><td>20x+10×250</td><td>3</td><td>60x+7500</td></tr><tr><td>退回</td><td>10(x-250)</td><td>0.8</td><td>8x-2000</td></tr></table>
> >
> > 则推销员每月所获得的利润
> >
> > $$
> > y = \left[ (6 0 x + 7 5 0 0) + (8 x - 2 0 0 0) \right] - 6 0 x = 8 x + 5 5 0 0 (2 5 0 \leq x \leq 4 0 0, x \in \mathrm{N})
> > $$
> >
> > 又由 $y = 8x + 5500$ 在 $[250, 400]$ 上单调递增，
> >
> > 所以当 x = 400 时，y 取得最大值 8700。
> >
> > 故选C.
> >
> > 即每天从报社买进 $^{400}$ 份报纸时，每月获得的利润最大，最大利润为 $^{8700}$ 元．故选C.

> > 24. 国家购买某种农产品的价格为 $120$ 元/担，某征税标准为 $100$ 元征 $8$ 元，计划可购 $m$ 万担·为了减轻农民负担，决定税率降低 $x$ 个百分点，预计收购量可增加 $2x$ 个百分点则税收 $f(x)$ （万元）与 $x$ 的函数关系式为
> >
> > 【答案】
> > A. $f(x) = 120m(1 + 2x\%)[(8 - x)\%](0 < x \leq 8)$ B. $f(x) = 120m[(1 + 2x)\%][(8 - x)\%](0 < x \leq 8)$ C. $f(x) = 120m[(1 + 2x)\%](8 - x\%) (0 < x \leq 8)$ D. $f(x) = 120m(1 + 2x\%) (8 - x\%) (0 < x \leq 8)$
> >
> > 【答案】A
> >
> > 【详解】由题意，可得调节税率后税率为 $(8 - x)\%$ ，预计调节税率后可收购 $m(1 + 2x\%)$ 万担，总费用 $120m(1 + 2x\%)$ 万元，
> >
> > 所以税收 $f(x)$ 与 $x$ 的函数关系式为 $f(x) = 120m(1 + 2x\%) \cdot [(8 - x)\%] (0 < x \leq 8)$ .
> >
> > 故选 **A**.
