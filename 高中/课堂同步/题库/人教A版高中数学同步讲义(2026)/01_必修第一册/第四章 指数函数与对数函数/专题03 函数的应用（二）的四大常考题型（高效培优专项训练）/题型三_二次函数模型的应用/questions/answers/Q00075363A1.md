> [!faq]- 《专题03 函数的应用（二）的四大常考题型（高效培优专项训练）》官方解析
>
> > [!success]- **【答案】** (1) $W(x)=\left\{\begin{aligned}-10x^{2}+600x-280,0<x<50,x&\in\mathbb{N}\\ -\left(x+\frac{10000}{x}\right)+9170,x&50,x&\in\mathbb{N}\end{aligned}\right.$ (2)全年产量为 100 千个时，该企业所获利润最大，最大利润是 8970 万元
>
> > [!note]- **【解析】**
> > （1）当 $0 < x < 50$ 时，
> >
> > $$
> > W (x) = 8 0 0 x - \left(1 0 x ^ {2} + 2 0 0 x\right) - 2 8 0 = - 1 0 x ^ {2} + 6 0 0 x - 2 8 0
> > $$
> >
> > 当 x 50 时，
> >
> > $$
> > W (x) = 8 0 0 x - \left(8 0 1 x + \frac {1 0 0 0 0}{x} - 9 4 5 0\right) - 2 8 0 = - \left(x + \frac {1 0 0 0 0}{x}\right) + 9 1 7 0,
> > $$
> >
> > 所以 $W(x) = \left\{ \begin{array}{ll} - 10x^{2} + 600x - 280, & 0 < x < 50, \\ -\left(x + \frac{10000}{x}\right) + 9170, & 50, \\ x \in \mathbb{N} \end{array} \right.$
> >
> > (2) 若 0 < x < 50，则 $W(x) = -10(x - 30)^{2} + 8720$ ，
> >
> > 当 x=30 时， $W(x)_{\max}=8720$ ；
> >
> > 若 $x = 50$ ，则 $W(x) = -\left(x + \frac{10000}{x}\right) + 9170 \leq -2\sqrt{x \cdot \frac{10000}{x}} + 9170 = 8970$
> >
> > 当且仅当 $x = \frac{10000}{x}$ ，即 $x = 100$ 时，等号成立，此时 $W(x)_{\mathrm{max}} = 8970$
> >
> > 因为 8970 > 8720，
> >
> > 所以当全年产量为 100 千个时，该企业所获利润最大，最大利润是 8970 万元。

> > 29. 六盘水市乌蒙大草原旅游景点某年国庆期间，团队收费方案如下：不超过 $30$ 人时，人均收费 $80$ 元；超过30人且不超过 $n(30 < n \leq 100)$ 人时，每增加1人，人均收费降低1元；超过 $n$ 人时，人均收费都按照 $n$ 人时的标准·设该景点接待有 $x$ 名游客的某团队，收取总费用为 $y$ 元·
> >
> > (1)求 $y$ 关于 $x$ 的函数解析式；
> >
> > (2)景点工作人员发现：当接待某团队人数超过一定数量时，会出现随着人数的增加收取的总费用反而减少这一现象·为了让收取的总费用随着团队中人数增加而增加，求 $n$ 的取值范围·
> >
> > 【答案】(1) \( y=\begin{cases}80x,0\leq x\leq30\\x(110-x),30<x\leq n\\(110-n)x,x>n\end{cases} \) ，且 \( x\in N^{\*}\quad30<n\leq100 \)
> >
> > (2) $30 < n \leq 55$ .
> >
> > 【详解】（1）由题意， $0 \leq x \leq 30$ 时，y = 80x；
> >
> > $30 < x \leq n$ 且 $30 < n \leq 100$ 时， $y = (80 - x + 30)x = (110 - x)x$ ；
> >
> > $x > n$ 且 $30 < n \leq 100$ 时， $y = (110 - n)x$ ；
> >
> > 综上， \( y=\begin{cases}80x,0\leq x\leq30\\x(110-x),30<x\leq n\\(110-n)x,x>n\end{cases} \) ，且 \( x\in N^{\*}\quad30<n\leq100 \)
> >
> > (2) 由 (1) 知：总费用在 $[0,30]$ 和 $[n,+\infty)$ 上都是递增，
> >
> > 所以，只需在 $(30,n]$ 上总费用不出现递减即可，
> >
> > 对于 $y=110x-x^{2}$ ，开口向下且对称轴为 x=55，
> >
> > 所以，只需 $30 < n \leq 55$ ，总费用随着团队中人数增加而增加·

> > 30. 近年来，国家发展改革委、国务院、工信部、生态环境部等有关部门纷纷出台污水处理领域指导、支持及规范类政策，该相关政策的落实不仅促进了环境保护，同时也带动了一批企业的发展·已知某企业每年生产某种智能污水处理设备的最大产能为 $100$ 台，其年度总利润 $W(x)$ （单位：万元）与产能 $x$ （单位：
> >
> > 台）的函数关系为 $W(x)=\left\{\begin{aligned}-2x^{2}+140x-400, &0<x\leq40,\\ -x-\frac{3600}{x}+1700, &40<x\leq100,\end{aligned}\right.$ $x\in N^{*}$ (1)当产能不超过 $40$ 台时，求每年生产多少台时，平均每台设备的年利润最大？
> >
> > (2)当产能为多少台时，该企业所获年度总利润最大？最大利润是多少？
> >
> > 【答案】(1)14 台
> >
> > (2)35 台，最大利润为 2050 万元
> >
> > 【详解】（1）因为当 $0 < x \leq 40$ 时， $W(x) = -2x^2 + 140x - 400$ .
> >
> > 则平均每台设备的年利润为 $f(x)=\frac{W(x)}{x}=140-2\left(x+\frac{200}{x}\right)$ ,
> >
> > $x + \frac{200}{x}$ $2\sqrt{200} = 20\sqrt{2}$ ，当且仅当 $x = 10\sqrt{2}$ 时取等号，
> >
> > 由于 $x \in N^{*}$ ， $14 < 10\sqrt{2} < 15$ ，且 $f(14) = 83\frac{3}{7} > f(15) = 83\frac{1}{3}$ ，
> >
> > 故当生产 $^{14}$ 台时，平均每台设备的年利润最大·
> >
> > (2) 当 $0 < x \leq 40$ 时， $W(x) = -2x^{2} + 140x - 400$
> >
> > 对称轴为 $x = -\frac{140}{-4} = 35 \in (0, 40]$
> >
> > 所以当 x=35 时， $W(x)$ 取最大值， $W(35)=2050$ （万元）；
> >
> > 当 $40 < x \leq 100$ 时，
> >
> > $$
> > W (x) = - x - \frac {3 6 0 0}{x} + 1 7 0 0 = - \left(x + \frac {3 6 0 0}{x}\right) + 1 7 0 0 \leq - 2 \sqrt {x \cdot \frac {3 6 0 0}{x}} + 1 7 0 0 = 1 5 8 0 (\text {万元}),
> > $$
> >
> > 当且仅当 x = 60 时等号成立.
> >
> > 因为 2050 > 1580，
> >
> > 故当产能为 35 台时，所获年度总利润最大，最大利润为 2050 万元
