> [!faq]- 《专题02 对数及对数函数的六大常考题型（高效培优专项训练）》官方解析
>
> > [!success]- **【答案】** C
>
> > [!note]- **【解析】**
> > 因为 $a$ 是方程 $x + \lg x = 3$ 的解，所以 $a + \lg a = 3$
> >
> > 令 $t = \lg a$ ，则有 $a = 10^{t}$
> >
> > 所以 $10^{t} + t = 3$ ，①
> >
> > 因为 b 是方程 $2x + 100^{x} = 3$ 的解，所以 $2b + 100^{b} = 3$ ，即 $2b + 10^{2b} = 3$ ，②
> >
> > 设 $f(x) = 10^{x} + x$ ，易知 $f(x)$ 在 $\mathbb{R}$ 是单调递增，
> >
> > 由①②得， $t = 2b$ ，所以 $\lg a = 2b$
> >
> > 代入 $a + \lg a = 3$ 得， $a + 2b = 3$
> >
> > 故选 **C**
