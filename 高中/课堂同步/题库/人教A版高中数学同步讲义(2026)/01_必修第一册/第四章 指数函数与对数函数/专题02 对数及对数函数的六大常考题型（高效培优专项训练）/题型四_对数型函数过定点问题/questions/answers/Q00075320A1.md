> [!faq]- 《专题02 对数及对数函数的六大常考题型（高效培优专项训练）》官方解析
>
> > [!success]- **【答案】** (1) $m = 2$ ，函数 $y = f(x + 1)$ 为奇函数； (2) $1 \leq k < 2$ 或 $-1 \left\langle k \leq 0 \right.$ .
>
> > [!note]- **【解析】**
> > （1）因为函数 $f(x) = \log_a\left(\frac{m}{x} - 1\right)$ 的图象恒过定点(1,0)，
> >
> > 所以 $\log_{a}(m-1)=0$ ，则 m-1=1 ，得 m=2 ，
> >
> > 所以 $f(x)=\log_{a}\left(\frac{2}{x}-1\right)$ ,
> >
> > 所以 $y = f(x + 1) = \log_a\left(\frac{2}{x + 1} -1\right) = \log_a\frac{1 - x}{x + 1}$
> >
> > 由 $\frac{1 - x}{x + 1} >0$ ，得 $-1 <   x <   1$ ，即 $y = f(x + 1)$ 的定义域为 $(-1,1)$ ，关于原点对称，
> >
> > $$
> > \text {令} h (x) = f (x + 1) = \log_ {a} {\frac {1 - x}{x + 1}}
> > $$
> >
> > 因为 $h(-x) = \log_a\frac{1 + x}{-x + 1} = \log_a\left(\frac{1 - x}{x + 1}\right)^{-1} = -\log_a\frac{1 - x}{x + 1} = -h(x)$
> >
> > 所以 $h(x)$ 为奇函数，即函数 $y = f(x + 1)$ 为奇函数；
> >
> > (2) 由 $f(x) = g(x)$ ，得 $\log_a\left(\frac{2}{x} - 1\right) = \log_a\left[x + \frac{k^2 + k + 2}{x} - 2(k + 1)\right]$ ，
> >
> > 所以 $\left\{ \begin{array}{l} x + \frac{k^2 + k + 2}{x} - 2(k + 1) = \frac{2}{x} - 1 \\ \frac{2}{x} - 1 > 0 \\ x + \frac{k^2 + k + 2}{x} - 2(k + 1) > 0 \end{array} \right.$
> >
> > 由 $\frac{2}{x} - 1 > 0$ ，得 $\frac{2 - x}{x} > 0$ ，解得 $0 < x < 2$ ，
> >
> > 由 $x + \frac{k^2 + k + 2}{x} - 2(k + 1) = \frac{2}{x} - 1$ ，得 $x^2 + k^2 + k + 2 - 2(k + 1)x = 2 - x$ ，
> >
> > 整理得 $x^{2} - (2k + 1)x + k^{2} + k = 0$
> >
> > 得 $(x-k)[x-(k+1]=0$ ，解得x=k或 $x=k+1$
> >
> > 因为关于 $x$ 的方程 $f(x) = g(x)$ 恰有唯一解，
> >
> > 所以 $\left\{\begin{aligned}0&<k<2\\ k&+1\notin(0,2)\end{aligned}\right.$ 或 $\left\{\begin{aligned}k\notin(0,2)\\ 0&<k+1<2\end{aligned}\right.$
> >
> > 解得 $1 \leq k < 2$ 或 $-1 < k \leq 0$
> >
> > 综上， $1 \leq k < 2$ 或 $-1 \left\langle k \leq 0 \right.$ .
