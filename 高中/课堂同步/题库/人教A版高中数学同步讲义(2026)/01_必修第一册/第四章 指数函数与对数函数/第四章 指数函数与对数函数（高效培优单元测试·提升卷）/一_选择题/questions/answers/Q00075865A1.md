> [!faq]- 《第四章 指数函数与对数函数（高效培优单元测试·提升卷）》官方解析
>
> > [!success]- **【答案】** ABC
>
> > [!note]- **【解析】**
> > 当 $a = 0$ 时， $f(x) = x^2 - |x|$ ，定义域为 $\mathbf{R}$ ，且 $f(-x) = (-x)^2 - |-x| = x^2 - |x| = f(x)$ ，此时 $f(x) = x^2 - |x|$
> >
> > 为偶函数，故 $\mathsf{A}$ 正确．当 $x - a$ 时， $f(x) = x^2 - x - a$ ，开口向上，对称轴为 $x = \frac{1}{2}$ ；当 $x < -a$ 时，
> >
> > $f(x) = x^{2} + x + a$ 开口向上，对称轴为 $x = -\frac{1}{2}$ 所以 $f(x) = x^2 - |x + a| = \begin{cases} x^2 - x - a, & x - a, \\ x^2 + x + a, & x < -a, \end{cases}$ 且
> >
> > $(-a)^2 - (-a) - a = a^2$ ， $(-a)^2 + (-a) + a = a^2$ ，即在分段处函数值相等，由于 $f(x) = x^2 + x + a$ 的对称轴在
> >
> > $f(x) = x^{2} - x - a$ 的对称轴的左侧，故 $\forall a\in \mathbf{R},f(x)$ 都不是 $\mathbf{R}$ 上的单调函数，故B正确．当 $a < 0$ 时，
> >
> > $f(x) = x^{2} - |x + a| = \left\{ \begin{array}{ll}x^{2} - x - a, & x - a,\\ x^{2} + x + a, & x <   - a, \end{array} \right.$ 若 $1 + 4a = 0$ ，则 $a = -\frac{1}{4}$ ，当 $x = \frac{1}{4}$ 时，令 $x^{2} - x + \frac{1}{4} = 0$ ，解得
> >
> > $x = \frac{1}{2}$ $\frac{1}{4}$ 当 $x <   \frac{1}{4}$ 时，令 $x^{2} + x - \frac{1}{4} = 0$ ，解得 $x = \frac{-1\pm\sqrt{2}}{2} <  \frac{1}{4}$ ，均符合要求，所以 $\exists a <   0$ ，使得函数 $f(x)$
> >
> > 有 $^{3}$ 个零点，故 $^{C}$ 正确．由 $^{B}$ 可知 $f(x)$ 的最小值在 $x=\frac{1}{2}$ 或 $x=-\frac{1}{2}$ 处取到，
> >
> > $f(x) = x^{2} - |x + a| = \left\{ \begin{array}{ll}x^{2} - x - a,x & -a,\\ x^{2} + x + a,x <   - a. \end{array} \right.$ 当 $a > \frac{1}{2}$ 时，函数最小值在 $x = \frac{1}{2}$ 处取到，由 $f\left(\frac{1}{2}\right) = \frac{1}{4} -\frac{1}{2} -a = -\frac{5}{4}$ 解得 $a = 1$ ，满足题意；当 $a < -\frac{1}{2}$ 时，函数最小值在 $x = -\frac{1}{2}$ 处取到，由 $f\left(-\frac{1}{2}\right) = \frac{1}{4} - \frac{1}{2} + a = -\frac{5}{4}$ ，解得 $a = -1$ ，满足题意，当 $-\frac{1}{2} \leq a \leq \frac{1}{2}$ 时，函数最小值在 $x = \frac{1}{2}$ 或 $x = -\frac{1}{2}$ 处取到，此时 $f\left(\frac{1}{2}\right) = -\frac{1}{4} - a > -\frac{5}{4}$ 恒成立， $f\left(-\frac{1}{2}\right) = -\frac{1}{4} + a > -\frac{5}{4}$ 恒成立，都不满足题意，舍去．综上，若 $f(x)$ 的最小值是 $-\frac{5}{4}$ ，则 $a = \pm 1$ ，故D错误．
