> [!faq]- 《第四章 指数函数与对数函数（高效培优单元测试·提升卷）》官方解析
>
> > [!success]- **【答案】** A. $x < y$ B. $\lg (y - x) > 0$ C. $\frac{1}{x} > \frac{1}{y} > 0$ D. $\mathrm{e}^x < \mathrm{e}^y$
>
> > [!note]- **【解析】**
> > 对于A， $x^{3}<y^{3}\Leftrightarrow x<y$ ，所以x<y是 $x^{3}<y^{3}$ 的充要条件，故A错误；
> >
> > 对于B，由 $\lg (y - x) > 0$ 可得 $y - x > 1$ ，即 $y > x + 1 > x$ ，充分性成立，
> >
> > 反之， $y > x$ 不一定推出 $y > x + 1$ ，必要性不成立，
> >
> > 所以 $\lg(y-x)>0$ 是 $x^{3}<y^{3}$ 的充分不必要条件，故 B 正确；
> >
> > 对于 C，由 $\frac{1}{x} > \frac{1}{y} > 0$ 可得 0 < x < y，所以 $x^{3} < y^{3}$ ，反之不成立，
> >
> > 所以 $\frac{1}{x} > \frac{1}{y} > 0$ 是 $x^{3} < y^{3}$ 的充分不必要条件，故 C 正确；
> >
> > 对于 D，因为 $e^{x} < e^{y} \Leftrightarrow x < y$ ，所以 $e^{x} < e^{y}$ 是 $x^{3} < y^{3}$ 的充要条件，故 D 错误。
> >
> > 故选 **BC**·
