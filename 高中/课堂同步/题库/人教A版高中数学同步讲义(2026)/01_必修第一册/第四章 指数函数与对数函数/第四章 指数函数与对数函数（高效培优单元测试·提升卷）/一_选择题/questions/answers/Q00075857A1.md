> [!faq]- 《第四章 指数函数与对数函数（高效培优单元测试·提升卷）》官方解析
>
> > [!success]- **【答案】** D
>
> > [!note]- **【解析】**
> > 由 $1 \leq \log_{2}(x^{2} - 2) \leq \log_{2}14$ 得 $2 \leq x^{2} - 2 \leq 14$ ，得 $4 \leq x^{2} \leq 16$ ，得 $-4 \leq x \leq -2$ 或 $2 \leq x \leq 4$ 。由 $x^{2} - 2 > 0$ 得 $x < -\sqrt{2}$ 或 $x > \sqrt{2}$ ，故 $b < -\sqrt{2}$ 或 $a > \sqrt{2}$ 。当 $a > \sqrt{2}$ 时，由函数 $y = \log_{2}(x^{2} - 2)(a \leq x \leq b)$ 单调递增得
> >
> > $2 \leq x \leq 4$ ，故 $a = 2, b = 4$ ；当 $b < -\sqrt{2}$ 时，由函数 $y = \log_2(x^2 - 2)(a \leq x \leq b)$ 单调递减得 $-4 \leq x \leq -2$ ，故 $a = -4, b = -2$ 。
> >
> > 故选 **D**.
