> [!faq]- 《第四章 指数函数与对数函数（高效培优单元测试·提升卷）》官方解析
>
> > [!success]- **【答案】** C
>
> > [!note]- **【解析】**
> > 函数 $f(x) = \mathrm{e}^{x} + \ln x$ 的定义域为 $\{x, x > 0\}$ ，且 $y = \mathrm{e}^{x}, y = \ln x$ 均为增函数，故函数 $f(x) = \mathrm{e}^{x} + \ln x$ 是增函数。由于 $0 < a < b < c$ ，故 $f(a) < f(b) < f(c)$ ，满足 $f(a) \cdot f(b)f(c) < 0 (0 < a < b < c)$ ，则 $f(a) < 0 < f(b) < f(c)$ 或 $f(a) < f(b) < f(c) < 0$ 。若 $f(a) < 0 < f(b) < f(c)$ ，则由 $f(x)$ 存在零点知， $x_{0} \in (a, b)$ ， $A, B$ 正确；若 $f(a) < f(b) < f(c) < 0$ ，则由 $f(x)$ 存在零点知， $x_{0} > c$ ， $D$ 正确。
