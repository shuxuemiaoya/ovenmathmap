> [!faq]- 《第四章 指数函数与对数函数（高效培优单元测试·提升卷）》官方解析
>
> > [!success]- **【答案】** C
>
> > [!note]- **【解析】**
> > 由题意，得 $\left\{ \begin{array}{l} 1 + x > 0, \\ 1 - x > 0, \end{array} \right.$ 解得 $-1 < x < 1$ ，函数 $f(x)$ 的定义域为 $(-1,1)$ 。又
> >
> > $f(-x) = \ln (1 - x) + \ln (1 + x) = f(x)$ ，所以函数 $f(x)$ 是定义在 $(-1,1)$ 上的偶函数.
> >
> > $f(x) = \ln (1 + x) + \ln (1 - x) = \ln \left(1 - x^2\right)$ ，所以 $f(x)$ 在 $[0,1)$ 上单调递减．又 $f(2a - 1) < f(-a)$ ，所以
> >
> > $\left\{ \begin{array}{l} \left| -a \right| < \left| 2a - 1 \right|, \\ \left| 2a - 1 \right| < 1, \quad \text{解得} 0 < a < \frac{1}{3} \end{array} \right.$
