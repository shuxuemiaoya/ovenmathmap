> [!faq]- 《专题4.2 指数函数（高效培优讲义）》官方解析
>
> > [!success]- **【答案】** C
>
> > [!note]- **【解析】**
> > 因为 $g(x)$ 为偶函数， $h(x)$ 为奇函数，且 $g(x)-h(x)=2^{x}$ ①，
> >
> > 所以， $g(-x)-h(-x)=g(x)+h(x)=2^{-x}$ ②，
> > - **①**：②两式联立可得 $g(x)=\frac{2^{x}+2^{-x}}{2}$ ， $h(x)=\frac{2^{-x}-2^{x}}{2}$
> >
> > 由 $mg(x) + 2[h(x)]^2 \leq 0$ 可得 $\frac{m(2^x + 2^{-x})}{2} + \frac{4^x + 4^{-x} - 2}{2} \leq 0$
> >
> > 可得 $-m$ $\frac{4^x + 4^{-x} - 2}{2^x + 2^{-x}} = \frac{\left(2^x + 2^{-x}\right)^2 - 4}{2^x + 2^{-x}} = 2^x + 2^{-x} - \frac{4}{2^x + 2^{-x}}$
> >
> > 令 $f(x) = 2^{x} + 2^{-x}$ ，其中 $x\in \left[-1,\frac{1}{2}\right]$
> >
> > 任取 $x_{1}$ 、 $x_{2}\in\left[-1,\frac{1}{2}\right]$ 且 $x_{1}>x_{2}$ ，则 $2^{x_{1}}>2^{x_{2}}>0$ ，
> >
> > 所以， $f(x_{1}) - f(x_{2}) = (2^{x_{1}} + 2^{-x_{1}}) - (2^{x_{2}} + 2^{-x_{2}}) = (2^{x_{1}} - 2^{x_{2}}) + \left(\frac{1}{2^{x_{1}}} -\frac{1}{2^{x_{2}}}\right) = (2^{x_{1}} - 2^{x_{2}}) - \frac{2^{x_{1}} - 2^{x_{2}}}{2^{x_{1} + x_{2}}}$
> >
> > $= \frac{\left(2^{x_1} - 2^{x_2}\right)\left(2^{x_1 + x_2} - 1\right)}{2^{x_1 + x_2}}$
> >
> > 当 $-1 < x_{2} < x_{1} \leq 0$ 时，则 $x_{1} + x_{2} < 0$ ，则 $0 < 2^{x_{1} + x_{2}} < 1$ ，则 $f(x_{1}) < f(x_{2})$ ，
> >
> > 当 $0 \leq x_{2} < x_{1} \leq 1$ 时，则 $x_{1} + x_{2} > 0$ ，则 $2^{x_{1} + x_{2}} > 1$ ，则 $f(x_{1}) > f(x_{2})$ ，
> >
> > 所以，函数 $f(x)$ 在 $[-1,0)$ 上单调递减，在 $\left(0,\frac{1}{2}\right]$ 上单调递增，
> >
> > 所以， $f(x)_{\min}=f(0)=2$
> >
> > 又因为 $f(-1) = \frac{5}{2}$ ， $f\left(\frac{1}{2}\right) = \sqrt{2} + \frac{\sqrt{2}}{2} = \frac{3\sqrt{2}}{2}$ ，则 $f(x)_{\max} = \frac{5}{2}$ ，
> >
> > 令 $t = 2^{x} + 2^{-x}$ ，则 $t\in \left[2,\frac{5}{2}\right]$ ，则 $2^{x} + 2^{-x} - \frac{4}{2^{x} + 2^{-x}} = t - \frac{4}{t}$
> >
> > 因为函数 $y = t$ 、 $y = -\frac{4}{t}$ 在 $\left[2, \frac{5}{2}\right]$ 上均为增函数，则 $y_{\max} = \frac{5}{2} - 4 \times \frac{2}{5} = \frac{9}{10}$
> >
> > 故 $-m \frac{9}{10}$ ，即 $m \leq -\frac{9}{10}$ ，故 m 的最大值为 $-\frac{9}{10}$
> >
> > 故选：C.
> >
> > ## 方法技巧
> >
> > 利用指数函数的单调性求解.
