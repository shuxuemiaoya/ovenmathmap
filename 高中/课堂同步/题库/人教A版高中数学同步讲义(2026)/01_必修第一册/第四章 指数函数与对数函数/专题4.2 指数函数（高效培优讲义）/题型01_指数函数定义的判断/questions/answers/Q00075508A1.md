> [!faq]- 《专题4.2 指数函数（高效培优讲义）》官方解析
>
> > [!success]- **【答案】** B
>
> > [!note]- **【解析】**
> > 令 $h(x)=f(x)+2^{x+1}$ ， $g(x)=f(x)-2^{x+2}$
> >
> > 依题意可得 $h(x) = f(x) + 2^{x + 1}$ 是奇函数， $g(x) = f(x) - 2^{x + 2}$ 是偶函数，则 $h(-x) = f(-x) + 2^{-x + 1} = -f(x) - 2^{x + 1}$ ， $g(-x) = f(-x) - 2^{-x + 2} = f(x) - 2^{x + 2}$ 即 $\left\{ \begin{array}{l} f(-x) + f(x) = -2^{-x + 1} - 2^{x + 1} \\ f(-x) - f(x) = 2^{-x + 2} - 2^{x + 2} \end{array} \right.$ ，解得 $f(x) = \frac{-2^{-x + 1} - 2^{x + 1} - 2^{-x + 2} + 2^{x + 2}}{2}$ ，则 $f(1) = \frac{-2^{-1 + 1} - 2^{1 + 1} - 2^{-1 + 2} + 2^{1 + 2}}{2} = \frac{1}{2}$ .
> >
> > 故选 **B**
