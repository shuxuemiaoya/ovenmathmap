> [!faq]- 《专题4.5 函数的应用（二）（高效培优讲义）》官方解析
>
> > [!success]- **【答案】** (1) $v(x)=\left\{\begin{aligned}&50,0\leq x<50\\&-\frac{1}{2}x+75,50\leq x\leq150\end{aligned}\right.$ (2)75 辆/千米，2812 辆/小时。
>
> > [!note]- **【解析】**
> > （1）由题意：当 $0 \leq x \leq 50$ 时， $v(x) = 50$ ；当 $50 \leq x \leq 150$ 时，设 $v(x) = ax + b$
> >
> > 再由已知得 $\left\{ \begin{array}{l} 150a + b = 0 \\ 50a + b = 50 \end{array} \right.$ ，解得 $\left\{ \begin{array}{l} a = -\frac{1}{2} \\ b = 75 \end{array} \right.$
> >
> > 故函数 $v(x)$ 的表达式为 $v(x)=\left\{\begin{aligned}&50,0\leq x<50\\&-\frac{1}{2}x+75,50\leq x\leq150\end{aligned}\right.$
> >
> > (2) 依题并由 (1) 可得 $f(x) = \begin{cases} 50x, & 0 \leq x < 50 \\ -\frac{1}{2}x^2 + 75x, & 50 \leq x \leq 150 \end{cases}$
> >
> > 当 $0 \leq x < 50$ 时， $f(x)$ 为增函数， $\therefore f(x) < f(50) < 2500$
> >
> > 当 $50 \leq x \leq 150$ 时， $f(x)_{\max} = f(75) = \frac{75^2}{2} = \frac{5625}{2} \approx 2812$
> >
> > 即当 $x = 75$ 时， $f(x)$ 在区间 $[0,150]$ 上取得最大值约为2812，
> >
> > 即当车流密度为 $75$ 辆/千米时，车流量可以达到最大值，最大值约为 $2812$ 辆/小时。
