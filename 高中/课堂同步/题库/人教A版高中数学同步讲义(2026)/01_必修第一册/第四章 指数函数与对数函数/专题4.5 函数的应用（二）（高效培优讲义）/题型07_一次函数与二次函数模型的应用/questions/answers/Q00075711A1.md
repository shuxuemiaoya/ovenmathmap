> [!faq]- 《专题4.5 函数的应用（二）（高效培优讲义）》官方解析
>
> > [!success]- **【答案】** A
>
> > [!note]- **【解析】**
> > $v(x)=\left\{\begin{aligned}0,x&200\\ kx+m,20&\leq x\leq200\\ 90,0&<x\leq20\end{aligned}\right.$
> >
> > 则当 $x = 200$ 时， $v(200) = 0$ ，
> >
> > 当 x=20 时， $v(20)=90$ ，即 $\left\{\begin{aligned}&200k+m=0\\ &20k+m=90\end{aligned}\right.$ ，解得 $k=-\frac{1}{2}$ ，m=100，
> >
> > 故 $f(x) = x \cdot v(x) = \begin{cases} 0, & x = 200 \\ \left(-\frac{1}{2}x + 100\right)x, & 20 \leq x \leq 200 \\ 90x, & 0 < x \leq 20 \end{cases}$
> >
> > 当 $0 < x \leq 20$ 时， $f(x)$ 的最大值为 x = 20 时， $f(20) = 1800$ ;
> >
> > 当 $20 \leq x \leq 200$ 时， $f(x) = \left(-\frac{1}{2} x + 100\right)x = -\frac{1}{2} x^2 + 100x$
> >
> > 根据二次函数的对称轴方程为 $x = 100$ ，得 $f(x)$ 的最大值为 $x_0 = 100$ 时， $f(100) = 5000$
> >
> > 故选 **A**.
