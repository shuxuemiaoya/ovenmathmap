> [!faq]- 《专题4.5 函数的应用（二）（高效培优讲义）》官方解析
>
> > [!success]- **【答案】** B
>
> > [!note]- **【解析】**
> > 解：当 $20 \leq x \leq 200$ 时，设 $v = kx + b$ ，则 $\left\{ \begin{array}{l} 60 = 20k + b \\ 0 = 200k + b \end{array} \right.$ ，解得 $k = -\frac{1}{3}, b = \frac{200}{3}$ .
> >
> > 于是 $v=\left\{\begin{aligned}&60,0\leq x<20,\\&-\frac{1}{3}x+\frac{200}{3},20\leq x\leq200.\end{aligned}\right.$
> >
> > 设车流量为 $q$ ，则 $q = v \cdot x = \left\{ \begin{array}{c} 60x0 \leq x < 20, \\ -\frac{1}{3} x^2 + \frac{200}{3} x \geq 0 \leq x \leq 200, \end{array} \right.$
> >
> > 当 $0 \leq x < 20$ 时， $q = 60x$ ，此时，函数在区间 $[0, 20)$ 上是增函数，恒有 $q < 1200$ ；
> >
> > 当 $20 \leq x \leq 200$ 时， $q = -\frac{1}{3} x^2 + \frac{200}{3} x$ ，此时函数在区间[20,100]上是增函数，在区间[100,200]是减函数，
> >
> > 因此恒有 $q \leq \frac{10000}{3}$ ，等号成立当且仅当 $x = 100$ ；
> >
> > 综上所述，当 $x = 100$ 时，函数取得最大值，即车流量最大，最大值约为3333辆.
> >
> > 故选 **B**.
