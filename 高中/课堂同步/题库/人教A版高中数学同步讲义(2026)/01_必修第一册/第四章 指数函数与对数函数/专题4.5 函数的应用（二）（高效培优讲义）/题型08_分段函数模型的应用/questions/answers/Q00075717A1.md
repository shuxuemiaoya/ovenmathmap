> [!faq]- 《专题4.5 函数的应用（二）（高效培优讲义）》官方解析
>
> > [!success]- **【答案】** (1) $v(x)=-\frac{1}{2}x+110$ (2)当车流密度为 110 辆/千米时，车流量最大，最大车流量为 6050 辆
>
> > [!note]- **【解析】**
> > （1）由题意，当 $20 \leq x \leq 220$ 时，若 $v(x) = ax + b (a \neq 0)$ ，则 $\left\{ \begin{array}{l} v(20) = 20a + b = 100 \\ v(220) = 220a + b = 0 \end{array} \right.$ ，解得 $\left\{ \begin{array}{l} a = -\frac{1}{2}. \\ b = 110. \end{array} \right.$
> >
> > $$
> > v (x) = - \frac {1}{2} x + 1 1 0
> > $$
> >
> > (2) 当 $0 \leq x \leq 20$ 时， $v(x) = 100$ ，由 (1) 得： $v(x) = \begin{cases} 100, & 0 \leq x \leq 20 \\ -\frac{1}{2}x + 110, & 20 < x \leq 220 \end{cases}$
> >
> > $$
> > f (x) = x \cdot v (x) = \left\{ \begin{array}{l} 1 0 0 x, 0 \leq x \leq 2 0, \\ - \frac {1}{2} x ^ {2} + 1 1 0 x, 2 0 <   x \leq 2 2 0 \end{array} , \right.
> > $$
> >
> > 当 $0 \leq x \leq 20$ 时， $f(x) = 100x$ 为增函数，所以 $f(x)$ 的最大值为 $f(20) = 2000$ ；
> >
> > 当 $20 < x \leq 220$ 时， $f(x) = -\frac{1}{2} x^2 + 110x = -\frac{1}{2}(x - 110)^2 + 6050$
> >
> > 当 $x = 110$ 时， $f(x)$ 取得最大值，且 $f(x)$ 的最大值为 $f(110) = 6050$
> >
> > 综上，当车流密度为 110 辆/千米时，车流量最大，最大车流量为 6050 辆.
