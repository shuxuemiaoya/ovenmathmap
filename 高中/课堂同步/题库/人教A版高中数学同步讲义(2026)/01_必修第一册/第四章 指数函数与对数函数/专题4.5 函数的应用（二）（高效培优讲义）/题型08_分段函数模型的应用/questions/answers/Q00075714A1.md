> [!faq]- 《专题4.5 函数的应用（二）（高效培优讲义）》官方解析
>
> > [!success]- **【答案】** B
>
> > [!note]- **【解析】**
> > 当 $20 \leq x \leq 200$ 时，设 $v = kx + b$ ，则 $\left\{ \begin{array}{l}60 = 20k + b\\ 0 = 200k + b \end{array} \right.$ ，解得 $k = -\frac{1}{3},b = \frac{200}{3}$
> >
> > 于是 $v=\left\{\begin{aligned}&60,0\leq x<20\\&-\frac{1}{3}x+\frac{200}{3},20\leq x\leq200\end{aligned}\right.$
> >
> > 设车流量为 q，则车流量 $q = vx = \begin{cases} 60x, & 0 \leq x < 20 \\ -\frac{1}{3}x^{2} + \frac{200}{3}x, & 20 \leq x \leq 200 \end{cases}$
> >
> > 当 $0 \leq x < 20$ 时， $q = 60x \in [0,1200)$ ；
> >
> > 当 $20 \leq x \leq 200$ 时， $q = -\frac{1}{3} x^2 + \frac{200}{3} x = -\frac{1}{3} (x - 100)^2 + \frac{10000}{3} \leq \frac{10000}{3}$ ，当且仅当 $x = 100$ 取等号，所以当 $x = 100$ 时，车流量最大，最大值约为 $^{3333}$ 辆。
> >
> > 故选：B
> >
> > ## 方法技巧
> >
> > 1、分段函数的“段”一定要分得合理，不重不漏。
> >
> > 2、分段函数的定义域为对应每一段自变量取值范围的并集.
> >
> > 3、分段函数的值域求法：逐段求函数值的范围，最后比较再下结论.
