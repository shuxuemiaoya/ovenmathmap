> [!faq]- 《专题4.5 函数的应用（二）（高效培优讲义）》官方解析
>
> > [!success]- **【答案】** C
>
> > [!note]- **【解析】**
> > 函数 $f(x) = \ln |x| + |x| - 2$ 的定义域为 $(- \infty, 0) \cup (0, +\infty)$
> >
> > $f(-x)=\ln|-x|+|-x|-2=f(x)$ ，即函数 为偶函数，
> >
> > 当 $x > 0$ 时， $f(x) = \ln x + x - 2$ 在 $(0, +\infty)$ 上单调递增， $f(1) = -1 < 0, f(2) = \ln 2 > 0$
> >
> > 则存在 $x_0 \in (1,2)$ ，使得 $f(x_0) = 0$ ，因此函数 $f(x)$ 在 $(0, +\infty)$ 的唯一零点 $x_0 \in (0,b]$ ，
> >
> > 则 b 2，由偶函数的性质得 $a \leq -2$ ，于是 b - a 4，
> >
> > 所以 b-a 的最小值为 4.
> >
> > 故选：C
> >
> > 9. 一种细胞的分裂速度 $v$ (单位：个/秒) 与其年龄 $t$ (单位：岁) 的关系可以用下面的分段函数来表示：
> >
> > $v(t)=\left\{\begin{aligned}&0.5t,\quad0\leq t\leq10,\\&\frac{2a}{b+\log_{2}\frac{t}{a}},t>10,\end{aligned}\right.$ 其中 $a,b\in\mathbf{R}$ 而且这种细胞从诞生到死亡，它的分裂速度变化是连续的·若这种细胞 $^{5}$
> >
> > 岁和 $^{60}$ 岁的分裂速度相等，则 $a\approx(\quad)$
> >
> > (参考数据： $\log_{2}3\approx1.585$ )
> > A. 6.402 B. 6.463 C. 6.502 D. 6.522
> >
> > 【答案】B
> >
> > 【详解】由题意知细胞 $^{5}$ 岁和 $^{60}$ 岁的分裂速度相等，即 $v(5)=v(60)$ ，所以 $0.5\times5=\frac{2a}{b+\log_{2}\frac{60}{a}}$ ，整理得 $b=\frac{4a}{5}-\log_{2}\frac{60}{a}$ ·又分裂速度变化是连续的，所以 $0.5\times10=\frac{2a}{b+\log_{2}\frac{10}{a}}$ ，整理得 $b=\frac{2a}{5}-\log_{2}\frac{10}{a}$ ，所以 $\frac{4a}{5}-\log_{2}\frac{60}{a}=\frac{2a}{5}-\log_{2}\frac{10}{a}$ ，得 $\frac{2a}{5}=\log_{2}\frac{60}{a}-\log_{2}\frac{10}{a}=\log_{2}6=1+\log_{2}3$ ，解得 $a\approx6.463$ 。
