> [!faq]- 《专题4.5 函数的应用（二）（高效培优讲义）》官方解析
>
> > [!success]- **【答案】** (1)-1 (2) $0 < a < 1$ (3) $0 < b \leq \frac{\sqrt{2}}{4}$
>
> > [!note]- **【解析】**
> > （1）因为 $a = 1, b = 2$ ，所以 $f(x) = x^2 + 3x + 1$ .
> >
> > 设函数 $f(x)$ 的不动点为 $x_{0}$ ，则 $f(x_{0}) = x_{0}^{2} + 3x_{0} + 1 = x_{0}$ .
> >
> > 化简得 $\left(x_0 + 1\right)^2 = 0$ ，解得 $x_0 = -1$ ，所以 $f(x)$ 的不动点为-1.
> >
> > (2) 令 $f(x) = x$ ，则 $ax^2 + bx + b - 1 = 0$ 有两个相异的解.
> >
> > 所以 $\Delta=b^{2}-4a(b-1)>0$ ，即： $b^{2}-4ab+4a>0$ 对于任意 b 恒成立.
> >
> > 令 $g(b)=b^{2}-4ab+4a$ ，则 $g(b)_{\min}=g(2a)=(2a)^{2}-4a\times2a+4a>0$
> >
> > 解得 0 < a < 1.
> >
> > (3) 因为 $x_{1}, x_{2}$ 为 $f(x)$ 的两个不动点，且 $f(x_{1}) + x_{2} = \frac{-1}{2a^{2} + 1}$
> >
> > 所以 $x_{1} + x_{2} = \frac{-1}{2a^{2} + 1}$ .
> >
> > 因为由（2）知， $x_{1} + x_{2} = -\frac{b}{a}$ ，所以 $\frac{-1}{2a^2 + 1} = -\frac{b}{a}$
> >
> > 所以 $b=\frac{a}{2a^{2}+1}=\frac{1}{2a+\frac{1}{a}}$
> >
> > 由（2）得到 $0 < a < 1$ ，根据基本不等式的性质可得 $2a + \frac{1}{a} 2\sqrt{2}$
> >
> > 当且仅当 $2a=\frac{1}{a}$ 时，即 $a=\frac{\sqrt{2}}{2}$ 时等号成立，
> >
> > 所以 $b \leq \frac{1}{2\sqrt{2}} = \frac{\sqrt{2}}{4}$ .
> >
> > 又 a > 0 ，所以 $b = \frac{a}{2a^{2} + 1} > \frac{0}{1} = 0$
> >
> > 所以实数 b 的取值范围为 $0 < b \leq \frac{\sqrt{2}}{4}$ .
