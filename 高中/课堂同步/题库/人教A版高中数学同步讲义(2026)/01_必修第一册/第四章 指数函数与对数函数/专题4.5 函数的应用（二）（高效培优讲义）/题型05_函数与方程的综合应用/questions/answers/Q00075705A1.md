> [!faq]- 《专题4.5 函数的应用（二）（高效培优讲义）》官方解析
>
> > [!success]- **【答案】** (1) $a = 2$ (2)奇函数，理由见解析； (3) $(-2,0]\cup[2,4)$
>
> > [!note]- **【解析】**
> > （1）因为函数 $f(x) = \log_a\frac{b - x}{x}$ 的图象恒过点 $(2,0)$
> >
> > 所以 $\log_a\frac{b - 2}{2} = 0$ ，即 $\frac{b - 2}{2} = 1$ ，解得 $b = 4$ ，
> >
> > 所以 $f(x) = \log_a\frac{4 - x}{x}$ ，即 $f(x) = \log_a\left(\frac{4}{x} -1\right)$
> >
> > 由 $f\left(\frac{4}{9}\right) = \log_a\left(4\times \frac{9}{4} -1\right) = 3$ ，解得 $a = 2$ ：
> >
> > (2) $g(x)=f(x+2)$ 为奇函数，理由如下：
> >
> > 由（1）知 $f(x) = \log_a\frac{4 - x}{x}$
> >
> > 所以 $g(x)=f(x+2)=\log_{a}\frac{4-x-2}{x+2}=\log_{a}\frac{2-x}{2+x}$
> >
> > 所以 $g(-x)=\log_{a}\frac{2+x}{2-x}=-\log_{a}\frac{2-x}{2+x}=-g(x)$
> >
> > 又 $g(x) = \log_a\frac{2 - x}{2 + x}$ 的定义域为 $(-2,2)$ ，关于原点对称，
> >
> > 所以 $g(x)$ 是奇函数.
> >
> > (3) 由 $f(x) = h(x)$ ，得 $\log_a\left(\frac{4}{x} - 1\right) = \log_a\left(\frac{x^2 + t^2 + 2t + 4}{x} - 2t - 3\right)$
> >
> > 所以 $\left\{\begin{aligned}&\frac{4}{x}-1=\frac{x^{2}+t^{2}+2t+4}{x}-2t-3,\\&\frac{4}{x}-1>0,\\&\frac{x^{2}+t^{2}+2t+4}{x}-2t-3>0,\end{aligned}\right.$
> >
> > 由 $\frac{4}{x} - 1 > 0$ ，得 $\frac{x - 4}{x} < 0$ ，解得 $0 < x < 4$
> >
> > 由 $\frac{4}{x} - 1 = \frac{x^2 + t^2 + 2t + 4}{x} - 2t - 3$ ，整理得 $x^{2} - (2t + 2)x + t(t + 2) = 0$
> >
> > 解得 $x = t$ 或 $x = t + 2$
> >
> > 因为关于 x 的方程 $f(x)=h(x)$ 恰有唯一解，
> >
> > 所以 $\left\{\begin{aligned}0<t<4,\\ t+2\quad4,\\ \frac{2t^{2}+2t+4}{t}-2t-3>0\end{aligned}\right.$ 或 $\left\{\begin{aligned}0<t+2<4,\\ t\leq0,\\ \frac{(t+2)^{2}+t^{2}+2t+4}{t+2}-2t-3>0,\end{aligned}\right.$
> >
> > 解得 $2 \leq t < 4$ 或 $-2 < t \leq 0$ ，即实数 $t$ 的取值范围为 $(-2,0] \cup [2,4)$ 。
