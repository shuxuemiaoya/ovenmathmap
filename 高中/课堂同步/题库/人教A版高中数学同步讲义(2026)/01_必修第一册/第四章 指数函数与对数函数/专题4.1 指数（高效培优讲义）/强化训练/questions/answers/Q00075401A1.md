> [!faq]- 《专题4.1 指数（高效培优讲义）》官方解析
>
> > [!success]- **【答案】** A. $mn \leq \frac{9}{8}$ B. $mn - 1$ C. $3^n + 9^m - 12$ D. $\frac{2}{m} + \frac{1}{n} - 3$
>
> > [!note]- **【解析】**
> > 因为 $m > 0, n > 0, 2m + n = 3$ 所以 $3 = 2m + n \sqrt{2mn}, \sqrt{2mn} \leq \frac{3}{2}$
> >
> > 即 $2mn \leq \frac{9}{4}$ ，得 $mn \leq \frac{9}{8}$ （当且仅当 $m = \frac{3}{4}, n = \frac{3}{2}$ 时，等号成立），故 A 正确；
> >
> > 当 $m=\frac{1}{4}, n=\frac{5}{2}$ 时，满足 $2m+n=3$ ，此时 $mn=\frac{5}{8}<1$ ，故 B 错误；
> >
> > $3^{n}+9^{m}=3^{n}+3^{2m}\quad2\sqrt{3^{n}\times3^{2m}}=2\sqrt{3^{n+2m}}=2\sqrt{3^{3}}=6\sqrt{3}$ （当且仅当 $m=\frac{3}{4},n=\frac{3}{2}$ 时，等号成立），故C错误；
> >
> > 由 $2m + n = 3$ 得 $\frac{2m + n}{3} = 1$ ，所以 $\frac{2}{m} +\frac{1}{n} = \left(\frac{2}{m} +\frac{1}{n}\right)\frac{2m + n}{3} = \frac{1}{3}\left(4 + \frac{2n}{m} +\frac{2m}{n} +1\right)$ $\frac{1}{3}\left(5 + 2\sqrt{\frac{2n}{m}\cdot\frac{2m}{n}}\right) = 3$
> >
> > (当且仅当 m=1, n=1 时，等号成立)，故 D 正确.
> >
> > 故选 **AD**
