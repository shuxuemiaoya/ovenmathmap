> [!faq]- 《专题4.1 指数（高效培优讲义）》官方解析
>
> > [!success]- **【答案】** （1） $6-\sqrt{2}$ ；（2）答案见解析
>
> > [!note]- **【解析】**
> > （1） $\sqrt{\frac{3}{2}-\sqrt{2}}+2^{1+\sqrt{2}}\times\left(\frac{1}{8}\right)^{\frac{\sqrt{2}}{3}}+2^{2\log_{4}(1-\sqrt{2})^{2}}+\log_{4}9\times\log_{3^{\sqrt{2}}}8$
> >
> > $$
> > = \sqrt {\frac {3 - 2 \sqrt {2}}{2}} + 2 ^ {1 + \sqrt {2}} \times 2 ^ {- \sqrt {2}} + 2 ^ {\log_ {2} (3 - 2 \sqrt {2})} + \log_ {2} 3 \times \frac {1}{\sqrt {2}} \log_ {3} 2 ^ {3}
> > $$
> >
> > $$
> > = \frac {\sqrt {2} - 1}{\sqrt {2}} + 2 + 3 - 2 \sqrt {2} + \frac {3}{\sqrt {2}}
> > $$
> >
> > $= 6 - \sqrt{2}$
> >
> > (2) 因为点 $(-1,0)$ 在函数 $y=ax^{2}-(b-2)x-3$ 的图象上，
> >
> > 所以 $a + b - 2 - 3 = 0$ ，即 $a + b = 5$
> >
> > 则 $y = ax^{2} - (3 - a)x - 3$ 0 可化为 $(ax - 3)(x + 1)$ 0
> >
> > 当 a=0 时，解得 $x \leq -1$ ，
> >
> > 当 $a \neq 0$ 时， $a(x - \frac{3}{a})(x + 1) = 0$
> >
> > 当 a > 0 时，解得 $\frac{3}{a}$ 或 $x \leq -1$ ，
> >
> > 当 $a < 0$ 时，可化为 $\left(x - \frac{3}{a}\right)(x + 1) \leq 0$
> >
> > 当 $a < -3$ 时，解得 $-1 \leq x \leq \frac{3}{a}$ ，
> >
> > 当 a = -3 时，解得 x = -1 ，
> >
> > 当 $-3 < a < 0$ 时，解得 $\frac{3}{a} \leq x \leq -1$
> >
> > 故 a = 0 时，解集为 $\{x \mid x \leq -1\}$ ，
> >
> > 当 $a > 0$ 时，解集为 $\{x\mid x = \frac{3}{a}$ 或 $x\leq -1\}$ ，
> >
> > 当 $a < -3$ 时，解集为 $\{x\mid -1\leq x\leq \frac{3}{a}\}$
> >
> > 当 a = -3 时，解集为 $\left\{-1\right\}$ ，
> >
> > 当 $-3 < a < 0$ 时，解集为 $\{x \mid \frac{3}{a} \leq x \leq -1\}$ .
