> [!faq]- 《专题01 指数及指数函数的五大常考题型（高效培优专项训练）》官方解析
>
> > [!success]- **【答案】** A. 16 的 4 次方根是 ±2 B. $\sqrt[3]{-27} = 3$ C. $\sqrt[4]{81} = \pm 3$ D. $\sqrt{(x+y)^{2}} = |x+y|$
>
> > [!note]- **【解析】**
> > 对于 A， $^{16}$ 的 4 次方根有两个，为 $\pm2$ ，故 A 正确；
> > 对于 B，负数的 3 次方根是一个负数， $\sqrt[3]{-}27=\sqrt[3]{(-3)^{3}}=-3$ ，故 B 错误；
> >
> > 对于 C， $\sqrt[4]{81}=\sqrt[4]{3^{4}}=|3|=3$ ，故 C 错误；
> >
> > 对于 $D$ ， $\sqrt{(x + y)^2}$ 是非负数，所以 $\sqrt{(x + y)^2} = |x + y|$ ，故 $D$ 正确.
> >
> > 故选：AD.
> >
> > 6. 给出下列结论：
> > - **①**：$\sqrt[4]{(-2)^{4}}=\pm2$ ;
> > - **②**：$f(x)=x^{2}+1,\quad x\in[-1,2]$ ， $f(x)$ 的值域是 $[2,5]$ ；
> > - **③**：幂函数图象一定不过第四象限；
> > - **④**：若 $\ln a < 1$ 成立，则 a 的取值范围是 $(0, e)$ . 其中正确的序号是 \_\_\_\_.
> >
> > 【答案】③④
> >
> > 【详解】① $\sqrt[4]{(-2)^{4}}=|2|=2$ ，①不正确；
> > - **②**：$y=x^{2}+1$ ， $x\in[1,2]$ ，y的值域是 $[1,5]$ ，②不正确；
> > - **③**：由幂函数的图像及性质知：幂函数图象一定不过第四象限，③正确；
> > - **④**：由 $lna < 1$ 得 0 < a < e，即 a 的取值范围是 $(0, e)$ ，④正确，
> >
> > 正确的是③④，
> >
> > 故答案为：③④。

> > 7. 以下命题，正确的是
> >
> > 【答案】
> > - **①**：函数 $f(x)=x$ 和 $f(x)=10^{\lg x}$ 为同一函数
> > - **②**：如果函数 $y = f(x)$ 在区间 $[a, b]$ 内满足 $f(a) \mathbb{I} f(b) < 0$ ，那么函数 $y = f(x)$ 在区间 $(a, b)$ 内有零点
> > - **③**：由实数 $x, -x, |x|, \sqrt{x^2}, -\sqrt[3]{x^3}$ 组成的集合，至多有 2 个元素
> > - **④**：函数 $f(x) = \log_2\left(-x^2 - 2x + 3\right)$ 的减区间为 $(-1, +\infty)$
> >
> > 【答案】③
> >
> > 【详解】①函数 $f(x) = x$ 和 $f(x) = 10^{\lg x}$ 不是同一函数，因为两个函数的定义域不同，前者的定义域是 $R$ ，后者的定义域是 $\{x \mid x > 0\}$ ，所以该命题是错误的；
> > - **②**：如果函数 $y = f(x)$ 在区间 $[a, b]$ 内满足 $f(a) \boxplus f(b) < 0$ ，那么函数 $y = f(x)$ 在区间 $(a, b)$ 内不一定有零点，因为函数可能不连续，所以该命题是错误的；
> > - **③**：由实数 $x, -x, |x|, \sqrt{x^2} = |x|, -\sqrt[3]{x^3} = -x$ 组成的集合，至多有 2 个元素，是正确的，所以该命题是正确的；
> > - **④**：函数 $f(x) = \log_2(-x^2 - 2x + 3)$ 是一个复合函数，函数的定义域为 $\{x \mid -3 < x < 1\}$
> >
> > 函数 $y = -x^{2} - 2x + 3 (-3 < x < 1)$ 的减区间为 $(-1, 1)$ ，函数 $y = \log_{2} x$ 是增函数，所以函数
> >
> > $f(x)=\log_{2}\left(-x^{2}-2x+3\right)$ 减区间为 $(-1,1)$ ，所以该命题是错误的。
> >
> > 故答案为③
