> [!faq]- 《专题01 指数及指数函数的五大常考题型（高效培优专项训练）》官方解析
>
> > [!success]- **【答案】** (1)-6 $$ \sqrt {(x - 1) ^ {2}} - \sqrt {(x + 3) ^ {2}} = \left\{ \begin{array}{l l} - 2 x - 2, & - 3 < x < 1 \\ - 4, & 1 \leq x < 3 \end{array} \right. $$
>
> > [!note]- **【解析】**
> > （1） $\sqrt[3]{(-6)^3} +\sqrt[4]{(\sqrt{5} - 4)^4} +\sqrt[3]{(\sqrt{5} - 4)^3} = -6 + (4 - \sqrt{5}) + \sqrt{5} -4 = -6$
> >
> > (2) 原式= $\sqrt{(x-1)^{2}}-\sqrt{(x+3)^{2}}=|x-1|+|x+3|(-3<x<3)$
> >
> > 因为 $-3 < x < 3$ ，所以 $-4 < x - 1 < 2$ ， $0 < x + 3 < 6$
> >
> > 当 $-4 < x - 1 < 0$ ，即 $-3 < x < 1$ 时， $|x - 1| + |x + 3| = 1 - x - (x + 3) = -2x - 2;$
> >
> > 当 $0 \leq x - 1 < 2$ ，即 $1 \leq x < 3$ 时， $|x - 1| + |x + 3| = x - 1 - (x + 3) = -4$ ，
> >
> > 所以 $\sqrt{(x-1)^{2}}-\sqrt{(x+3)^{2}}=\left\{\begin{aligned}-2x-2,-3&<x<1\\ -4,&1\leq x<3\end{aligned}\right.$
