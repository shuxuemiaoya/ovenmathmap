> [!faq]- 《专题01 指数及指数函数的五大常考题型（高效培优专项训练）》官方解析
>
> > [!success]- **【答案】** $^{(1)}$ 定义域为 R，值域为 $(-1,1)$ (2) $f(x)$ 为奇函数，证明见解析
>
> > [!note]- **【解析】**
> > （1）函数 $f(x)$ 的定义域为 R. $f(x)=\frac{4^{x}-1}{4^{x}+1}=1-\frac{2}{4^{x}+1}$
> >
> > $\because 4^{x} + 1 > 1, \therefore 0 < \frac{1}{4^{x} + 1} < 1, 0 < \frac{2}{4^{x} + 1} < 2,$
> >
> > 函数 $f(x)$ 的值域为 $(-1,1)$ ;
> >
> > (2) $f(x)$ 定义域为 R，关于原点对称，
> >
> > $\because f(-x) = \frac{4^{-x} - 1}{4^{-x} + 1} = \frac{1 - 4^x}{1 + 4^x} = -f(x)$
> >
> > 所以函数 $f(x)$ 为奇函数·
