> [!faq]- 《第四章 指数函数与对数函数（高效培优讲义）》官方解析
>
> > [!success]- **【答案】** (1) $f(x)$ 在 $(-1,1)$ 上单调递增，证明见解析 (2) $\left(2,\frac{7}{2}\right)$
>
> > [!note]- **【解析】**
> > （1） $f(x)$ 在 $(-1,1)$ 上单调递增.
> >
> > 证明如下：令 $\frac{x + 1}{1 - x} >0$ ，解得 $-1 <   x <   1$ ，所以 $f(x)$ 的定义域为 $(-1,1)$ .设 $-1 <   x_{1} <   x_{2} <   1$
> >
> > 得 $f(x_{2}) - f(x_{1}) = \ln \frac{1 + x_{2}}{1 - x_{2}} -\ln \frac{1 + x_{1}}{1 - x_{1}} = \ln \left(\frac{1 + x_{2}}{1 - x_{2}}\times \frac{1 - x_{1}}{1 + x_{1}}\right) = \ln \frac{1 + x_{2} - x_{1} - x_{1}x_{2}}{1 - x_{2} + x_{1} - x_{1}x_{2}}.$
> >
> > 因为 $-1 < x_{1} < x_{2} < 1$ ，所以 $1 + x_{2} - x_{1} - x_{1}x_{2} > 1 - x_{2} + x_{1} - x_{1}x_{2} = (1 - x_{2})(1 + x_{1}) > 0$
> >
> > 得 $f(x_{2}) - f(x_{1}) = \ln \frac{1 + x_{2} - x_{1} - x_{1}x_{2}}{1 - x_{2} + x_{1} - x_{1}x_{2}} >\ln 1 = 0$ ，所以 $f(x)$ 在 $(-1,1)$ 上单调递增.
> >
> > (2) $f(x)=\ln\frac{x+1}{1-x}$ ，定义域为 $(-1,1)$ ， $f(-x)=\ln\frac{-x+1}{1+x}=-\ln\frac{x+1}{1-x}=-f(x)$ ，所以 $f(x)$ 是奇函数.
> >
> > 所以 $f(x - 3) < -f\left(-\frac{1}{2}\right)$ ，即 $f(x - 3) < f\left(\frac{1}{2}\right)$
> >
> > 又 $f(x)$ 在 $(-1, 1)$ 上单调递增，所以 $-1 < x - 3 < \frac{1}{2}$ ，解得 $2 < x < \frac{7}{2}$ ，
> >
> > 所以 $x$ 的取值范围为 $\left(2, \frac{7}{2}\right)$
