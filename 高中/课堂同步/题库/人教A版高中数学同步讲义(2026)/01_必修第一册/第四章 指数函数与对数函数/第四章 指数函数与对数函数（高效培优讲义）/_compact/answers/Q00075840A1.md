> [!faq]- 《第四章 指数函数与对数函数（高效培优讲义）》官方解析
>
> > [!success]- **【答案】** (1) $4 < k < 5$ (2) $x_{1}^{2} + x_{2}^{2} + x_{3}^{2}\in \left(18,\frac{726}{25}\right)$
>
> > [!note]- **【解析】**
> > （1）因为 $f(1)=4\neq0$
> >
> > 所以由 $f(x) = \left\{ \begin{array}{l} kx - k + 4, x \leq 1, \\ x^2 - (k + 2)x + k + 5, x > 1, \text{在}(-1,5) \text{上有三个零点}X_1, x_2, x_3 \text{得} \end{array} \right.$
> >
> > $y = f(x)$ 在 $x \in (-1,1)$ 内有 1 个零点，且在 $(1,5)$ 内有两个不同的零点，
> >
> > 若 $y = f(x)$ 在 $x \in (-1, 1)$ 内有 1 个零点，则 $\left\{ \begin{array}{l} k > 0 \\ -1 < \frac{k - 4}{k} \leq 1 \end{array} \right.$ ，得 $k > 2$ ，
> >
> > 若 在 内有两个不同的零点，则 $\left\{\begin{aligned}\Delta&=(k+2)^{2}-4(k+5)>0\\ 1&<\frac{k+2}{2}<5\\ 1^{2}&-(k+2)\times1+k+5>0\\ f(5)&>0\end{aligned}\right.$
> >
> > 即 $\left\{ \begin{array}{l} \Delta = k^2 - 16 > 0 \\ 0 < k < 8 \\ 25 - 5(k + 2) + k + 5 > 0 \end{array} \right.$ ，得 $4 < k < 5$
> >
> > 综上所述，4<k<5。
> >
> > (2) 不妨设 $x_{1}=\frac{k-4}{k}$ ， $x_{2}+x_{3}=k+2$ ， $x_{2}x_{3}=k+5$ ，
> >
> > 则 $x_{1}^{2} + x_{2}^{2} + x_{3}^{2} = x_{1}^{2} + (x_{2} + x_{3})^{2} - 2x_{2}x_{3} = \left(\frac{k - 4}{k}\right)^{2} + (k + 2)^{2} - 2(k + 5) = \left(k - \frac{4}{k}\right)^{2} + 2\left(k - \frac{4}{k}\right) + 3$
> >
> > 令 $t = k - \frac{4}{k}$ 则 $x_{1}^{2} + x_{2}^{2} + x_{3}^{2} = t^{2} + 2t + 3 = (t + 1)^{2} + 2.$
> >
> > 由（1）知 $k\in (4,5)$ ， $\quad t = k - \frac{4}{k}\in \left(3,\frac{21}{5}\right)$
> >
> > 所以 $x_{1}^{2} + x_{2}^{2} + x_{3}^{2} \in \left(18, \frac{726}{25}\right)$
