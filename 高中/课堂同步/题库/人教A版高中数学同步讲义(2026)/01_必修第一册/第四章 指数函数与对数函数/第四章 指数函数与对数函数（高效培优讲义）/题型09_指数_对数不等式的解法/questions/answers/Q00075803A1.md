> [!faq]- 《第四章 指数函数与对数函数（高效培优讲义）》官方解析
>
> > [!success]- **【答案】** (1)奇函数，证明见解析 (2)是定值，关于 x 的不等式 $2[f(x)]^{2} < f(1 - x)$ 的解集为 $(-∞, 0)$
>
> > [!note]- **【解析】**
> > （1） $g(x)=f\left(x+\frac{1}{2}\right)-\frac{1}{2}=\frac{4^{x+\frac{1}{2}}}{4^{x+\frac{1}{2}}+2}-\frac{1}{2}=\frac{4^{x+\frac{1}{2}}-\frac{1}{2}\times4^{x+\frac{1}{2}}-1}{4^{x+\frac{1}{2}}+2}=\frac{\frac{1}{2}\times4^{x+\frac{1}{2}}-1}{4^{x+\frac{1}{2}}+2}$
> >
> > $= \frac{1}{2}\times \frac{4^{x + \frac{1}{2}} - 2}{4^{x + \frac{1}{2}} + 2}$
> >
> > $g(x)$ 是奇函数，证明如下：
> >
> > $g(x)$ 的定义域是 R， $g(-x)=\frac{1}{2}\times\frac{4^{-x+\frac{1}{2}}-2}{4^{-x+\frac{1}{2}}+2}=\frac{1}{2}\times\frac{4^{\frac{1}{2}}-2\times4^{x}}{4^{\frac{1}{2}}+2\times4^{x}}=\frac{1}{2}\times\frac{2-4^{x+\frac{1}{2}}}{2+4^{x+\frac{1}{2}}}=-\frac{1}{2}\times\frac{4^{x+\frac{1}{2}}-2}{4^{x+\frac{1}{2}}+2}=-g(x)$
> >
> > 所以 $g(x)$ 是奇函数.
> >
> > (2) $f(x) + f(1 - x) = \frac{4^x}{4^x + 2} +\frac{4^{1 - x}}{4^{1 - x} + 2} = \frac{2\times 4^x}{2\times 4^x + 4} +\frac{4}{4 + 2\times 4^x} = 1$ 为定值.
> >
> > 所以 $2[f(x)]^{2} < f(1 - x) = 1 - f(x)$
> >
> > 即 $2\left[f(x)\right]^2 + f(x) - 1 = (f(x) + 1)(2f(x) - 1) < 0$
> >
> > 即 $-1 < f(x) < \frac{1}{2}$ ①
> >
> > $f(x) = \frac{4^x}{4^x + 2} = \frac{4^x + 2 - 2}{4^x + 2} = 1 - \frac{2}{4^x + 2}$ 在R上单调递增，
> >
> > $$
> > 4 ^ {x} > 0, 4 ^ {x} + 2 > 2, 0 <   \frac {1}{4 ^ {x} + 2} <   \frac {1}{2}, 0 <   \frac {2}{4 ^ {x} + 2} <   1
> > $$
> >
> > $-1<-\frac{2}{4^{x}+2}<0,0<1-\frac{2}{4^{x}+2}<1$ ，即 $0<f(x)<1$ ②，
> >
> > 由①②得 $0 < f(x) < \frac{1}{2}$ ，而 $f(0) = \frac{1}{2}$
> >
> > 所以关于 x 的不等式 $2[f(x)]^{2} < f(1 - x)$ 的解集为 $(-∞, 0)$ .
