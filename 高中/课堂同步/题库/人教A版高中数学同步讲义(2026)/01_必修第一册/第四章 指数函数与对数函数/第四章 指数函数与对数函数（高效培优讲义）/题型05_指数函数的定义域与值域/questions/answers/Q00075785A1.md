> [!faq]- 《第四章 指数函数与对数函数（高效培优讲义）》官方解析
>
> > [!success]- **【答案】** A.2 B.4 C.6 D.8
>
> > [!note]- **【解析】**
> > 正数 $x, y$ 满足 $\frac{1}{x} + \frac{1}{2y} = 2$ ，则 $x + 2y = \frac{1}{2}(x + 2y)(\frac{1}{x} + \frac{1}{2y}) = \frac{1}{2}(2 + \frac{2y}{x} + \frac{x}{2y})$
> >
> > $\frac{1}{2} (2 + 2) = 2$ ，当且仅当 $\frac{2y}{x} = \frac{x}{2y}$ ，即 $x = 2y = 1$ 时取等号，
> >
> > 所以 $x^{2}+4y^{2}+e^{x-1}+e^{2y-1}=\frac{(x+2y)^{2}+(x-2y)^{2}}{2}+e^{x-1}+e^{2y-1}$
> >
> > $\frac{1}{2} (x + 2y)^2 + 2\sqrt{\mathrm{e}^{x - 1} \cdot \mathrm{e}^{2y - 1}} = \frac{1}{2} (x + 2y)^2 + 2\sqrt{\mathrm{e}^{x + 2y - 2}} \quad 2 + 2 = 4$ ，当且仅当 $x = 2y = 1$ 时取等号，
> >
> > 所以 $x^{2} + 4y^{2} + \mathrm{e}^{x - 1} + \mathrm{e}^{2y - 1}$ 的最小值为4.
> >
> > 故选 **B**
