> [!faq]- 《第四章 指数函数与对数函数（高效培优讲义）》官方解析
>
> > [!success]- **【答案】** (1) $y_{1}=\frac{12000}{x}$ ( $2\leq x\leq6$ ，且x取整数)， $y_{2}=x^{2}+10000$ ( $7\leq x\leq12$ ，且x取整数) (2)去年5月用于所需工料的总费用最多，最多费用是22000元
>
> > [!note]- **【解析】**
> > （1）根据表格中数据可以得出 $xy_{1}=$ 定值，则 $y_{1}$ 与x之间的函数关系为反比例函数关系
> >
> > 设 $y_{1}=\frac{k}{x}$ ，将 $(2,6000)$ 代入得： $k=2\times6000=12000$ ，
> >
> > 故 $y_{1}=\frac{12000}{x}$ （ $2\leq x\leq6$ ，且x取整数）
> >
> > 根据图象可以看出： $y_{2}=ax^{2}+c(a\neq0)$ 的图象过(7,10049)，(12,10144)两个点，
> >
> > 代入 $y_{2}=ax^{2}+c(a\neq0)$ 得：
> >
> > $\left\{ \begin{array}{l}10049 = 49a + c\\ 10144 = 144a + c \text{解得：} \end{array} \right.$ $\left\{ \begin{array}{l}a = 1\\ c = 10000 \end{array} \right.$
> >
> > 故 $y_{2}=x^{2}+10000$ （ $7\leq x\leq12$ ，且 x 取整数）
> >
> > (2) 当 $2 \leq x \leq 6$ ，且 $x$ 取整数时：
> >
> > $$
> > W = y _ {1} \cdot z _ {1} + (1 2 0 0 0 - y _ {1}) \cdot z _ {2} = \frac {1 2 0 0 0}{x} \cdot \frac {1}{2} x + (1 2 0 0 0 - \frac {1 2 0 0 0}{x}) \cdot \left(\frac {3}{4} x - \frac {1}{1 2} x ^ {2}\right)
> > $$
> >
> > $$
> > = - 1 0 0 0 x ^ {2} + 1 0 0 0 0 x - 3 0 0 0
> > $$
> >
> > $$
> > x = 5, 2 \leq x \leq 6
> > $$
> >
> > ,则开口向下，且对称轴为
> >
> > 当 x=5 时， $W_{最大}=22000$ （元）
> >
> > 当 $7 \leq x \leq 12$ 时，且 $x$ 取整数时，
> >
> > $$
> > W = 3 \times \left(1 2 0 0 0 - y _ {2}\right) + 1. 5 \cdot y _ {2} = 3 \times \left(1 2 0 0 0 - x ^ {2} - 1 0 0 0 0\right) + 1. 5 \left(x ^ {2} + 1 0 0 0 0\right)
> > $$
> >
> > $= -\frac{3}{2} x^{2} + 21000$ 为开口向下，对称轴为 $y$ 轴，
> >
> > 当 $7 \leq x \leq 12$ 时， $W$ 随 $x$ 的增大而减小，
> >
> > ∴当 x=7 时， $W_{最大}=21000-\frac{3}{2}\times49<22000$ （元）
> >
> > 去年5月用于所需工料的总费用最多，最多费用是22000元.
