> [!faq]- 《专题4.4 对数函数（高效培优讲义）》官方解析
>
> > [!success]- **【答案】** A．函数 $f(x)=\sqrt{x+1}\cdot\sqrt{x-1}$ 与 $g(x)=\sqrt{x^{2}-1}$ 是同一个函数 B．函数 $f(x)=\ln\left(x^{2}-2x\right)$ 的单调递增区间是 $(1,+\infty)$ C．若函数 $f(x)$ 的最大值为 3，最小值为 1，则 $f(x)$ 的值域是 [1,3] D．若 $f(x+1)$ 是偶函数，则函数 $y=f(x)$ 的图象关于直线 x=1 对称
>
> > [!note]- **【解析】**
> > 对于选项 $^{A}$ ：令 $\left\{\begin{aligned}x-1&0\\ x+1&0\end{aligned}\right.$ ，解得x 1，
> >
> > 可知函数 $f(x)=\sqrt{x+1}\cdot\sqrt{x-1}$ 的定义域为 $\left[1,+\infty\right)$ ,
> >
> > 令 $x^{2}-1$ 0 ，解得 x 1 或 $x \leq -1$
> >
> > 可知函数 $g(x) = \sqrt{x^2 - 1}$ 的定义域为 $(- \infty, -1] \cup [1, +\infty)$
> >
> > 两者定义域不同，所以函数 $f(x)$ 与 $g(x)$ 不是同一个函数，故 $^{A}$ 错误；
> >
> > 对于 B：令 $x^{2}-2x>0$ ，解得 x>2 或 x<0
> >
> > 可知函数 $f(x)=\ln\left(x^{2}-2x\right)$ 的定义域为 $(-∞,0)∪(2,+∞)$
> >
> > 又因为 $y = \ln u$ 在定义域内单调递增，且 $u = x^{2} - 2x$ 在 $(- \infty, 0)$ 内单调递减，在 $(2, +\infty)$ 内单调递增，
> >
> > 可知 $f(x)$ 在 $(- \infty, 0)$ 内单调递减，在 $(2, +\infty)$ 内单调递增，
> >
> > 所以函数 $f(x)=\ln\left(x^{2}-2x\right)$ 的单调递增区间是 $(2,+\infty)$ ，故 B 错误；
> >
> > 对于选项 C：例如 $f(x)=\left\{\begin{aligned}&1,x&0\\ &3,x<0\end{aligned}\right.$ ，可知函数 $f(x)$ 的最大值为 3，最小值为 1，
> >
> > 但 $f(x)$ 的值域是 $\{1,3\}$ ，故 $C$ 错误；
> >
> > 对于选项 D：若 $f(x+1)$ 是偶函数，则 $f(x+1)=f(-x+1)$ ，
> >
> > 所以函数 $y = f(x)$ 的图象关于直线 $x = 1$ 对称，故 $^{D}$ 正确；
> >
> > 故选：D.
> >
> > 5. 函数 $f(x) = |\lg x|$ ，若 $a = f(0.1), b = f(1), c = f(2)$ ，则（ ）A. $a < b < c$ B. $c < b < a$ C. $b < a < c$ D. $b < c < a$
> >
> > 【答案】D
> >
> > 【详解】因为 $f(x)=\left|\lg x\right|$ ，所以 $a=f(0.1)=\left|\lg0.1\right|=\left|-\lg10\right|=\left|\lg10\right|=f(10)$ ，
> >
> > 又当 $x = 1$ 时， $f(x) = |\lg x| = \lg x$ 在 $[1, +\infty)$ 上单调递增，所以 $f(10) > f(2) > f(1)$ 所以 $b < c < a$ 。
> >
> > 故选 **D**
