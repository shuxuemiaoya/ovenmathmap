> [!faq]- 《专题4.4 对数函数（高效培优讲义）》官方解析
>
> > [!success]- **【答案】** B
>
> > [!note]- **【解析】**
> > 令 $\frac{2 + x}{2 - x} > 0$ ，解得 $-2 < x < 2$ ，可知函数 $f(x)$ 的定义域为 $(-2, 2)$ ，若函数 $f(x)$ 为奇函数，则 $f(1) + f(-1) = 0$ ，可得 $(1 + a)\lg 3 + (1 - a)\lg \frac{1}{3} = 2a \cdot \lg 3 = 0$ ，即 $a = 0$ ，则 $f(x) = x^2\lg \frac{2 + x}{2 - x}$ ，可得 $f(x) + f(-x) = x^2\lg \frac{2 + x}{2 - x} + (-x)^2\lg \frac{2 - x}{2 + -x} = x^2\left(\lg \frac{2 + x}{2 - x} + \lg \frac{2 - x}{2 + -x}\right) = 0$ ，即 $f(x) = -f(-x)$ ，可知函数 $f(x)$ 为奇函数，所以 $a = 0$ 。
> >
> > 故选 **B**.
