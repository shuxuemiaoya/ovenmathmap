> [!faq]- 《专题4.4 对数函数（高效培优讲义）》官方解析
>
> > [!success]- **【答案】** (1)(-1,1)，奇函数； (2) $1 < m \leq 2$ .
>
> > [!note]- **【解析】**
> > （1）当 $m = 1$ 时，函数 $g(x) = \ln (1 - x) - \ln (1 + x)$ ，则 $\left\{ \begin{array}{l} 1 - x > 0 \\ 1 + x > 0 \end{array} \right.$ ，解得 $-1 < x < 1$ ，
> >
> > 所以函数 $g(x)$ 的定义域为 $(-1,1)$ ，
> >
> > $$
> > g (- x) = \ln (1 + x) - \ln (1 - x) = - [ \ln (1 - x) - \ln (1 + x) ] = - g (x)
> > $$
> >
> > 所以 $g(x)$ 是奇函数·
> >
> > (2) 依题意， $g(0)=0$ ，不等式 $g(0)-\ln(f(x))$ $0 \Leftrightarrow \ln(f(x)) \leq 0 \Leftrightarrow 0 < f(x) \leq 1$
> >
> > 由不等式 $g(0) - \ln (f(x))$ 0 恒成立，得 $0 < f(x) \leq 1 \Leftrightarrow 0 < \frac{m^2 - m}{\mathrm{e}^x + \mathrm{e}^{-x}} \leq 1$ 恒成立，
> >
> > 即 $0 < m^2 - m \leq e^x + e^{-x}$ 恒成立，而 $e^x + e^{-x} = 2\sqrt{e^x \cdot e^{-x}} = 2$ ，当且仅当 $x = 0$ 时取等号，
> >
> > 因此 $0 < m^2 - m \leq 2$ ，因为 $m > 0$ ，解得 $1 < m \leq 2$
> >
> > 所以 $m$ 的取值范围是 $1 < m \leq 2$ .
