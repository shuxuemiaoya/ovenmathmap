> [!faq]- 《专题4.4 对数函数（高效培优讲义）》官方解析
>
> > [!success]- **【答案】** C
>
> > [!note]- **【解析】**
> > 因为函数 $f(x) = x\ln \left(1 + \frac{1}{x - b}\right)$ 为偶函数，所以 $f(-x) = f(x)$ ，即 $-x\ln \left(1 + \frac{1}{-x - b}\right) = x\ln \left(1 + \frac{1}{x - b}\right)$
> >
> > $$
> > x \left[ \ln (1 - \frac {1}{x + b}) + \ln (1 + \frac {1}{x - b}) \right] = 0, \text {即} x \left[ \ln (\frac {x + b - 1}{x + b}) (\frac {x - b + 1}{x - b}) \right] = 0
> > $$
> >
> > 即 $x\ln \frac{x^2 - (b - 1)^2}{x^2 - b^2} = 0$ ，即 $\frac{x^2 - (b - 1)^2}{x^2 - b^2} = 1$
> >
> > 化简得 $(b-1)^{2}=b^{2}$ ，解得 $b=\frac{1}{2}$
> >
> > 故选：C.
> >
> > ## 方法技巧
> >
> > $y = \log_a x(a > 0, a \neq 1)$ 的系数为 1
