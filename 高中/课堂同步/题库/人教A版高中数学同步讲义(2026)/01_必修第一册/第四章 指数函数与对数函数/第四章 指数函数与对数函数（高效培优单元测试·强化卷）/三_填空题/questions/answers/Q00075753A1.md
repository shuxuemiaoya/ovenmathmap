> [!faq]- 《第四章 指数函数与对数函数（高效培优单元测试·强化卷）》官方解析
>
> > [!success]- **【答案】** (1) $m = 1$ ， $f(2) = 4$ ； (2)证明见解析 (3) $a = 1$ .
>
> > [!note]- **【解析】**
> > （1）由图象过点 $\left(\frac{1}{2},\frac{3}{4}\right)$ ，
> >
> > 可得： $\frac{1}{4}+\frac{m}{2}=\frac{3}{4}$ ，解得：m=1，
> >
> > $$
> > f (2) = \log_ {2} 2 + 2 + 1 = 4
> > $$
> >
> > (2) 由 (1) $f(x) = \left\{ \begin{array}{c} x^2 + x, 0 < x \leq 1 \\ \log_2 x + x + 1, 1 < x \leq 2 \end{array} \right.$ ,
> >
> > 当 $0 < x \leq 1$ 时， $0 < x^2 \leq 1$ ， $\therefore x < x^2 + x \leq x + 1 \leq x + 2$
> >
> > 当 $1 < x \leq 2$ 时， $0 < \log_2 x \leq 1$ ， $\therefore x < x + 1 < \log_2 x + x + 1 \leq x + 2$
> >
> > 综上， $\forall x\in(0,2]$ ，都有 $x<f(x)\leq x+2$
> >
> > (3) 设 $h(x)=f(x)-x=\left\{\begin{aligned}&x^{2},0<x\leq1\\&\log_{2}x+1,1<x\leq2\end{aligned}\right.$ ，则 $g(x)=\left|f(x)-(x+a)\right|=\left|h(x)-a\right|$
> >
> > $\because x^{2}$ 在 $(0,1]$ 单调递增，且在 $x = 1$ 处取最大值1，
> >
> > $\log_2 x + 1$ 在 $(1,2]$ 单调递增，且在 $x = 1$ 处取最小值1，
> >
> > $h(x)$ 在 $(0,2]$ 单调递增，值域为 $(0,2]$ ，故 $-a < g(x) \leq 2 - a$
> >
> > ∴当 $a \leq 1$ 时，此时 $\left|a\right| \leq \left|2 - a\right| = 2 - a$ ，故 $M(a) = 2 - a$ ，
> >
> > 当 $a > 1$ 时，此时 $a > |2 - a|M(a)$ 不存在，
> >
> > ∴当 $M(a)$ 最小时，a=1.
