> [!faq]- 《第四章 指数函数与对数函数（高效培优单元测试·强化卷）》官方解析
>
> > [!success]- **【答案】** (1) $f(x)=\left\{\begin{aligned}3^{-x}-3^{x},&x\leq0\\ 3^{x}-3^{-x},&x>0\end{aligned}\right.$ (2) 存在 $m = \log_3 2, n = 1$ 满足题意
>
> > [!note]- **【解析】**
> > （1）因为 $f(x)$ 是偶函数，所以 $f(1) = f(-1) = \frac{a}{3^{-1}} - 3^{-1} = 3a - \frac{1}{3} = \frac{8}{3}$
> >
> > 解得 a = 1 ，
> >
> > 所以当 $x \leq 0$ 时， $f(x) = \frac{1}{3^x} - 3^x$
> >
> > 当 $x > 0$ 时，可得 $-x < 0$ ，则 $f(-x) = \frac{1}{3^{-x}} - 3^{-x} = 3^x - 3^{-x} = f(x)$
> >
> > 所以函数 $f(x)$ 的解析式为 $f(x) = \begin{cases} 3^{-x} - 3^{x}, & x \leq 0 \\ 3^{x} - 3^{-x}, & x > 0 \end{cases}$ ;
> >
> > (2) 存在.
> >
> > 假设存在正实数 $m, n$ ，使得当 $x \in [m, n]$ 时，函数 $f(x)$ 的值域为 $\left[5 - \frac{7}{3^m}, 5 - \frac{7}{3^n}\right]$
> >
> > 因为当 x > 0 时， $f(x) = 3^{x} - 3^{-x}$ ，所以 $f(x)$ 在 $x \in [m, n]$ 上单调递增，
> >
> > 所以 $\left\{\begin{aligned}f(m)&=5-\frac{7}{3^{m}}\\ f(n)&=5-\frac{7}{3^{n}}\end{aligned}\right.$
> >
> > 所以 $m, n$ 为方程 $f(x) = 5 - \frac{7}{3^x}$ 的两个根，即 $3^x - 3^{-x} = 5 - \frac{7}{3^x}$ 的两个根，
> >
> > 即 $\left(3^{x}\right)^{2}-5\cdot3^{x}+6=0$ 的两根，整理得 $3^{x}=2$ 或 $3^{x}=3$ ，
> >
> > 解得 $x = \log_{3} 2$ 或 x = 1 ，
> >
> > 又 0 < m < n ，所以 $m = \log_{3} 2, n = 1$
> >
> > 所以存在 $m = \log_32, n = 1$ ，使得当 $x \in [m, n]$ 时，函数 $f(x)$ 的值域为 $\left[5 - \frac{7}{3^m}, 5 - \frac{7}{3^n}\right]$
