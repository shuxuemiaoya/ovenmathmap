> [!faq]- 全练一本通解析
> **【答案】** （1） $1 + \mathrm{i}$ ；（2）-1-8i；（3）1；（4） $\frac{7}{25} -\frac{49}{25}\mathrm{i}$ ；（5） $\frac{1}{2}$
>
> **【解析】**
> （1） $(3 + \mathrm{i})\div (2 - \mathrm{i}) = \frac{3 + \mathrm{i}}{2 - \mathrm{i}} = \frac{(3 + \mathrm{i})(2 + \mathrm{i})}{(2 - \mathrm{i})(2 + \mathrm{i})} = \frac{5 + 5\mathrm{i}}{5} = 1 + \mathrm{i}$ （2） $\frac{7 - 9\mathrm{i}}{1 + \mathrm{i}} = \frac{(7 - 9\mathrm{i})(1 - \mathrm{i})}{(1 + \mathrm{i})(1 - \mathrm{i})} = \frac{-2 - 16\mathrm{i}}{1 - \mathrm{i}^2} = \frac{-2 - 16\mathrm{i}}{2} = -1 - 8\mathrm{i}$ （3） $\frac{(1 + \mathrm{i})^3 - (1 - \mathrm{i})^3}{(1 + \mathrm{i})^2 - (1 - \mathrm{i})^2} = \frac{2\mathrm{i} - 2 + 2 + 2\mathrm{i}}{2\mathrm{i} + 2\mathrm{i}} = \frac{4\mathrm{i}}{4\mathrm{i}} = 1$ （4） $\frac{(1 - 2\mathrm{i})^2}{3 - 4\mathrm{i}} -\frac{(2 + \mathrm{i})^2}{4 - 3\mathrm{i}} = -\frac{3 + 4\mathrm{i}}{3 - 4\mathrm{i}} -\frac{3 + 4\mathrm{i}}{4 - 3\mathrm{i}} = -\frac{(3 + 4\mathrm{i})^2}{25} -\frac{(3 + 4\mathrm{i})(4 + 3\mathrm{i})}{25}$ $= \frac{7 - 24\mathrm{i}}{25} -\frac{25\mathrm{i}}{25} = \frac{7}{25} -\frac{49}{25}\mathrm{i}$ （5） $\frac{\sqrt{5} + \sqrt{3}\mathrm{i}}{\sqrt{5} - \sqrt{3}\mathrm{i}} -\frac{\sqrt{3} + \sqrt{5}\mathrm{i}}{\sqrt{3} - \sqrt{5}\mathrm{i}} = \frac{(\sqrt{5} + \sqrt{3}\mathrm{i})^2}{(\sqrt{5} - \sqrt{3}\mathrm{i})(\sqrt{5} + \sqrt{3}\mathrm{i})} -\frac{(\sqrt{5} + \sqrt{5}\mathrm{i})^2}{(\sqrt{5} - \sqrt{5}\mathrm{i})(\sqrt{5} + \sqrt{5}\mathrm{i})}$ $= \frac{5 - 3 + 2\sqrt{15}\mathrm{i}}{(\sqrt{5})^2 - (\sqrt{3}\mathrm{i})^2} -\frac{3 - 5 + 2\sqrt{15}\mathrm{i}}{(\sqrt{3})^2 - (\sqrt{5}\mathrm{i})^2} = \frac{2 + 2\sqrt{15}\mathrm{i}}{8} -\frac{-2 + 2\sqrt{15}\mathrm{i}}{8}$ $= \frac{1}{4} +\frac{\sqrt{15}}{4}\mathrm{i} + \frac{1}{4} -\frac{\sqrt{15}}{4}\mathrm{i} = \frac{1}{2}$
