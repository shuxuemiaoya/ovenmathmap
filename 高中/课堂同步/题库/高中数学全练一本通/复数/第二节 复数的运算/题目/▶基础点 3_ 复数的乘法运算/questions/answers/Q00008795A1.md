> [!faq]- 全练一本通解析
> **【答案】** 3-i
>
> **【解析】**
> 设 $z = a + bi(a,b\in R)$ ，则 $\overline{z} = a - bi$ ，
> 所以 $z + \overline{z} = 2a,z - \overline{z} = 2bi$ ，
> 因为 $z + \overline{z} = (z - \overline{z})\mathrm{i} = 2$ 所以 $2a = 2bi^{2} = 2$ ，所以 $a = 1,b = -1$ 所以 $z = 1 - \mathrm{i}$ ，则 $z(2 + \mathrm{i}) = (1 - \mathrm{i})(2 + \mathrm{i}) = 3 - \mathrm{i}$ .故答案为：3-i.
