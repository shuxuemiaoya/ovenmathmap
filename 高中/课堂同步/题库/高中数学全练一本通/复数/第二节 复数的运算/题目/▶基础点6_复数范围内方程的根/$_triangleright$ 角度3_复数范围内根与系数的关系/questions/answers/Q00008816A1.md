> [!faq]- 全练一本通解析
> **【答案】** C
>
> **【解析】**
> 解析：因为 $1 + \mathrm{i}$ 是关于 $x$ 的方程 $x^2 + ax + b = 0 (a, b \in \mathbf{R})$ 的一个根，
> 则 $1 - \mathrm{i}$ 也是关于 $x$ 的方程 $x^2 + ax + b = 0 (a, b \in \mathbf{R})$ 的一个根。
> 可得 $\begin{cases} (1 + \mathrm{i}) + (1 - \mathrm{i}) = -a \\ (1 + \mathrm{i}) \times (1 - \mathrm{i}) = b \end{cases}$ ，解得 $a = -2, b = 2$ ，所以 $a + b = 0$ 。
>
> 故选 **C**。
