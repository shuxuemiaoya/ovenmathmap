> [!faq]- 全练一本通解析
> **【答案】** $$ z = - 1 5 + 8 \mathrm{i} $$ $$ \left(- 1, \frac {1}{2} \right] \tag {2} $$
>
> **【解析】**
> （1）解法1：设 $z = a + bi(a,b\in \mathbf{R})$ ，则 $|z| = \sqrt{a^2 + b^2}$ 代入方程得 $a + bi + \sqrt{a^2 + b^2} = 2 + 8\mathrm{i}$ 所以 $\left\{ \begin{array}{l}a + \sqrt{a^2 + b^2} = 2\\ b = 8 \end{array} \right.$ ，解得 $\left\{ \begin{array}{l}a = -15\\ b = 8 \end{array} \right.$ 所以 $z = -15 + 8\mathrm{i}$ 解法2：原式可化为 $z = 2 - |z| + 8\mathrm{i}$ ，于是 $|z| = \sqrt{(2 - |z|)^2 + 8^2}$ 即 $|z|^2 = 68 - 4|z| + |z|^2$ ，所以 $|z| = 17$ 代入 $z = 2 - |z| + 8\mathrm{i}$ ，得 $z = -15 + 8\mathrm{i}$ （2）因为 $\left|z_1\right| = \sqrt{x^4 + x^2 + 1},\left|z_2\right| = \left|x^2 +a\right|$ ，且 $\left|z_1\right| > \left|z_2\right|$ 所以 $x^{4} + x^{2} + 1 > \left(x^{2} + a\right)^{2}$ ，即 $(1 - 2a)x^{2} + (1 - a^{2}) > 0$ 恒成立当 $1 - 2a = 0$ ，即 $a = \frac{1}{2}$ 时， $1 - \frac{1}{4} >0$ 恒成立；当 $1 - 2a\neq 0$ 时， $\left\{ \begin{array}{ll}1 - 2a > 0\\ \Delta = -4(1 - 2a)(1 - a^2) <   0 \end{array} \right.$ 解得 $-1 <   a <   \frac{1}{2}$ 综上，实数 $a$ 的取值范围是 $\left(-1,\frac{1}{2}\right]$
