> **【答案】** A

> **【解析】**
> A解析：设 $z = a + bi(a,b\in \mathbb{R})$ ，则 $\overline{z} = a - bi,\left|\overline{z}\right| = \sqrt{a^2 + b^2}$ 因为 $z + \left|\overline{z}\right| = 2 + 4\mathrm{i}$ ，即 $a + \sqrt{a^2 + b^2} +bi = 2 + 4\mathrm{i}$ 所以 $\left\{ \begin{array}{l}a + \sqrt{a^2 + b^2} = 2\\ b = 4 \end{array} \right.$ ，解得 $\left\{ \begin{array}{l}a = -3\\ b = 4 \end{array} \right.$ ，所以 $z = -3 + 4\mathrm{i}$ .故选：A
