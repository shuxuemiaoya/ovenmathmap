> [!faq]- 全练一本通解析
> **【解析】**
> （1）证明见解析；（2） $\frac{PF}{PB} = \frac{1}{2}$ 解析：（1）取 $DC$ 的中点 $M$ ，连接ME,MB，如图（1）.
![](../../../../../images/answers/ed3806f405f213b9e621f5d08f1ae056ce1f4bcd11569bf65524dca83d976591.jpg)
图(1)
因为点 E, M 分别为 PC, DC 的中点, 所以 PD//ME.
因为 $\frac{AB}{BC} = \frac{BC}{CM} = \sqrt{2}$ ， $\angle ABC = \angle BCM = 90^{\circ}$ ，
所以 $\triangle ABC \sim \triangle BCM$ ，得 $\angle CAB = \angle MBC$ ，
所以 $\angle CAB + \angle MBA = \angle MBC + \angle MBA = 90^{\circ}$ ，所以 $MB \perp AC$ 。
又 $BE \perp AC, MB \cap BE = B, MB, BE \subset$ 平面 MBE，所以 $AC \perp$ 平面 MBE。
因为 $ME \subset$ 平面 MBE，所以 $AC \perp ME$ 。
又 $ME //PD$ ，所以 $PD \perp AC$ 。
（2）因为 $PD \perp DC, PD \perp AC, DC \cap AC = C, DC, AC \subset$ 平面 ABCD，
所以 $PD \perp$ 平面 ABCD．因为 $DA \subset$ 平面 ABCD，所以 $PD \perp DA$ 。
如图（2），以点 D 为原点，分别以 DA, DC, DP 所在直线为 x 轴、y 轴、z 轴，建立空间直角坐标系。
![](../../../../../images/answers/332e9181585fdf2c25dbefbb14d37a9aa521258f8afaebbf03454b5b58b1a49c.jpg)
图(2)
令 $AD = 2$ ，则 $D(0,0,0), A(2,0,0), B(2,2\sqrt{2},0), P(0,0,2), E(0,\sqrt{2},1)$ ，所以 $\overrightarrow{DA} = (2,0,0), \overrightarrow{DB} = (2,2\sqrt{2},0), \overrightarrow{DE} = (0,\sqrt{2},1), \overrightarrow{PB} = (2,2\sqrt{2},-2), \overrightarrow{DP} = (0,0,2)$ 设 $\frac{PF}{PB} = t$ ，则 $\overrightarrow{PF} = t\overrightarrow{PB} = (2t,2\sqrt{2}t,-2t)$ ，所以 $\overrightarrow{DF} = \overrightarrow{DP} + \overrightarrow{PF} = (2t,2\sqrt{2}t,2-2t)$ . 设平面 $BDE$ 的一个法向量为 $\vec{m} = (x,y,z)$ ，则有 $\left\{\begin{array}{l}\overrightarrow{DE} \cdot \vec{m} = \sqrt{2}y + z = 0, \\ \overrightarrow{DB} \cdot \vec{m} = 2x + 2\sqrt{2}y = 0,\end{array}\right.$ 令 $y = -1$ ，得 $x = \sqrt{2}, z = \sqrt{2}$ ，则 $\vec{m} = (\sqrt{2}, -1, \sqrt{2})$ 。设平面 $ADF$ 的一个法向量为 $\vec{n} = (a,b,c)$ ，则有 $\left\{\begin{array}{l}\overrightarrow{DA} \cdot \vec{n} = 2a = 0, \\ \overrightarrow{DF} \cdot \vec{n} = 2ta + 2\sqrt{2}tb + (2 - 2t)c = 0,\end{array}\right.$ 令 $b = t - 1$ ，得 $a = 0, c = \sqrt{2}t$ ，则 $\vec{n} = (0,t - 1,\sqrt{2}t)$ 。因为平面 $ADF$ 与平面 $BDE$ 所成锐二面角的余弦值为 $\frac{\sqrt{15}}{5}$ ，所以 $\left|\cos\left\langle\vec{m},\vec{n}\right\rangle\right| = \frac{\left|\vec{m} \cdot \vec{n}\right|}{\left|\vec{m}\right|\left|\vec{n}\right|} = \frac{\left|1 - t + 2t\right|}{\sqrt{\left(\sqrt{2}\right)^2 + (-1)^2 + \left(\sqrt{2}\right)^2} \cdot \sqrt{(t - 1)^2 + (\sqrt{2}t)^2}} = \frac{\sqrt{15}}{5}$ ，解得 $t = \frac{1}{2}$ 。故 $\frac{PF}{PB} = \frac{1}{2}$ 。
