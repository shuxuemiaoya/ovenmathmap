## 3. 空间向量的平行或垂直的坐标表示

（1）空间向量平行（共线）的充要条件

设 $\vec{a} = (a_{1}, a_{2}, a_{3}), \vec{b} = (b_{1}, b_{2}, b_{3})(\vec{b} \neq 0)$ ，则 $\vec{a} // \vec{b} \Leftrightarrow a_{1} = \lambda b_{1}, a_{2} = \lambda b_{2}, a_{3} = \lambda b_{3} (\lambda \in \mathbf{R})$ 。

(2) 空间向量垂直的充要条件

设非零向量 $\vec{a} = (a_{1}, a_{2}, a_{3}), \vec{b} = (b_{1}, b_{2}, b_{3})$ ，则 $\vec{a} \perp \vec{b} \Leftrightarrow \vec{a} \cdot \vec{b} = 0 \Leftrightarrow a_{1}b_{1} + a_{2}b_{2} + a_{3}b_{3} = 0$ .
