> [!faq]- 全练一本通解析
> **【答案】** $(-1, \frac{1}{2}) \cup (\frac{1}{2}, +\infty)$
>
> **【解析】**
> 由向量 $\vec{a} = (1, 1, 0)$ ， $\vec{b} = (m, 0, 2)$ ，可得 $\vec{a} \cdot \vec{b} = m, |\vec{a}| = \sqrt{2}, |\vec{b}| = \sqrt{m^2 + 4}$ ，因为 $\cos \left\langle \vec{a}, \vec{b} \right\rangle = -\frac{\sqrt{10}}{10}$ ，可得 $\frac{\vec{a} \cdot \vec{b}}{|\vec{a}||\vec{b}|} = \frac{m}{\sqrt{2} \cdot \sqrt{m^2 + 4}} = -\frac{\sqrt{10}}{10}$ ，解得 $m = -1$ ，所以 $\vec{b} = (-1, 0, 2)$ ，所以 $\vec{a} + k\vec{b} = (1 - k, 1, 2k)$ 与 $2\vec{a} + \vec{b} = (1, 2, 2)$ ，又因为向量 $\vec{a} + k\vec{b}$ 与 $2\vec{a} + \vec{b}$ 所成角为锐角，
> 所以 $(\vec{a} + k\vec{b}) \cdot (2\vec{a} + \vec{b}) = 1 - k + 2 + 4k > 0$ ，解得 $k > -1$ ，
> 若向量 $\vec{a} + k\vec{b}$ 与 $2\vec{a} + \vec{b}$ 共线，则 $\frac{1 - k}{1} = \frac{1}{2} = \frac{2k}{2}$ ，解得 $k = \frac{1}{2}$ ，所以实数 $k$ 的范围是 $(-1, \frac{1}{2}) \cup (\frac{1}{2}, +\infty)$ 。
> 故答案为： $(-1, \frac{1}{2}) \cup (\frac{1}{2}, +\infty)$ 。
