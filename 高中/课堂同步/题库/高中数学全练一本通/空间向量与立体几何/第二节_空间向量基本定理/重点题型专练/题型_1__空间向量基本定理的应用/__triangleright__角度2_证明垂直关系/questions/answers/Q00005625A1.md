> [!faq]- 全练一本通解析
> **【答案】** 详见解析
>
> **【解析】**
> （1） $\overrightarrow{OG} = \overrightarrow{OM} +\overrightarrow{MG} = \frac{1}{2}\overrightarrow{OA} +\frac{2}{3}\left(\overrightarrow{MA} +\overrightarrow{AB} +\overrightarrow{BN}\right)$
> \(= \frac{1}{2}\overrightarrow{OA} +\frac{2}{3}\left(\frac{1}{2}\overrightarrow{OA} +\overrightarrow{OB} -\overrightarrow{OA} +\frac{1}{2}\overrightarrow{BC}\right) = \frac{1}{2}\overrightarrow{OA} +\frac{2}{3}\left[\overrightarrow{OB} -\frac{1}{2}\overrightarrow{OA} +\frac{1}{2}\left(\overrightarrow{OC} -\overrightarrow{OB}\right)\right]\)
> \(= \frac{1}{2}\overline{OA} +\frac{2}{3}\left(\frac{1}{2}\overline{OB} -\frac{1}{2}\overline{OA} +\frac{1}{2}\overline{OC}\right) = \frac{1}{2}\overline{OA} +\frac{1}{3}\overline{OB} -\frac{1}{3}\overline{OA} +\frac{1}{3}\overline{OC}\)
> \(= \frac{1}{6}\overline{OA} +\frac{1}{3}\overline{OB} +\frac{1}{3}\overline{OC} = \frac{1}{6}\vec{a} +\frac{1}{3}\vec{b} +\frac{1}{3}\vec{c}\)
> （2）由题意知， \(\left|\vec{a}\right| = \left|\vec{b}\right| = \left|\vec{c}\right| = 1\) ， \(\vec{a}\cdot \vec{b} = \vec{a}\cdot \vec{c} = \vec{b}\cdot \vec{c} = \frac{1}{2},\) ， \(\overline{BA} = \vec{a} -\vec{b}\)
> 则 \(\left|\overline{BA}\right| = \sqrt{\left(\vec{a} - \vec{b}\right)^2} = \sqrt{\left|\vec{a}\right|^2 - 2\vec{a}\cdot \vec{b} +\left|\vec{b}\right|^2} = 1\)
> \(\left|\overline{OG}\right| = \sqrt{\left(\frac{1}{6}\vec{a} + \frac{1}{3}\vec{b} + \frac{1}{3}\vec{c}\right)^2} = \sqrt{\frac{1}{36}\left|\vec{a}\right|^2 + \frac{1}{9}\left|\vec{b}\right|^2 + \frac{1}{9}\left|\vec{c}\right|^2 + \frac{1}{9}\vec{a}\cdot \vec{b} +\frac{1}{9}\vec{a}\cdot \vec{c} +\frac{2}{9}\vec{b}\cdot \vec{c}}\)
> \(= \frac{\sqrt{17}}{6},\)
> \(\overline{OG}\cdot \overline{BA} = (\vec{a} -\vec{b})\cdot \left(\frac{1}{6}\vec{a} +\frac{1}{3}\vec{b} +\frac{1}{3}\vec{c}\right)\)
> \(= \frac{1}{6}\vec{a}^2 +\frac{1}{3}\vec{a}\cdot \vec{b} +\frac{1}{3}\vec{a}\cdot \vec{c} -\frac{1}{6}\vec{a}\cdot \vec{b} -\frac{1}{3}\vec{b}^2 -\frac{1}{3}\vec{b}\cdot \vec{c} = -\frac{1}{12}\)
> 所以cos \(<  \overline{\mathrm{{OG}},\overline{\mathrm{{BA}}} > } = \frac{\overline{\mathrm{{OG}}}\cdot\overline{\mathrm{{BA}}}}{\left|\overline{\mathrm{{OG}}}\right|\left|\overline{\mathrm{{BA}}}\right|} = -\frac{\sqrt{17}}{34}\)
