> [!faq]- 全练一本通解析
> **【解析】**
> $\vec{n} = (0, - 3,1)$
![](../../../../../images/answers/d78e6cc30a08ce3f335efdd0a484d05d87b5c284a7b85912446fdad1858590a6.jpg)
因为四边形ABCD是平行四边形，所以 $CD = AB = 1,OD = \frac{1}{2} AD = \frac{1}{2} BC = 2,\angle CDA = \angle ABC = \frac{\pi}{3}$ 故在△OCD中，由余弦定理可得： $OC^2 = CD^2 +OD^2 -2\cdot CD\cdot OD\cdot \cos \angle CDA = 1 + 4 - 2\times 1\times 2\times \cos \frac{\pi}{3} = 3,$ $OC = \sqrt{3}$ ， $\because OC^2 +CD^2 = OD^2,\therefore CD\bot OC$ ，又 $\because P$ 在平面ABCD的投影为 $O$ $\therefore PO\bot$ 平面ABCD， $CD\subset$ 平面ABCD， $\therefore PO\bot CD$ ， $PO\bot OC$ 取BC的中点 $F$ ，连接OF，因为OF，OP，OC两两垂直，故分别以OC的反向延长线、OF，OP为 $x$ 轴、y轴、z轴建立如图的空间直角坐标系，则 $B(\sqrt{3},2,0),P(0,0,3),C(-\sqrt{3},0,0),\overline{OB} = (\sqrt{3},2,0),\overline{OC} = (-\sqrt{3},0,0),$ $\overline{OP} = (0,0,3),\overline{BP} = \overline{OP} -\overline{OB} = (-\sqrt{3}, - 2,3)$ 设 $\overline{BE} = \frac{2}{3}\overline{BP} = \left(\frac{-2\sqrt{3}}{3}, - \frac{4}{3},2\right),\overline{OE} = \overline{OB} +\overline{BE} = \left(\frac{\sqrt{3}}{3},\frac{2}{3},2\right),$ 易知平面POC的一个法向量为 $\vec{m} = (0,1,0)$ 设平面EOC的法向量为 $\vec{n} = (x,y,z)$ 则 $\left\{ \begin{array}{c}\overrightarrow{OC}\cdot \vec{n} = -\sqrt{3} x = 0\\ \overrightarrow{OE}\cdot \vec{n} = \frac{\sqrt{3}}{3} x + \frac{2}{3} y + 2z = 0, \end{array} \right.$ 令 $z = 1$ 得 $\vec{n} = (0, - 3,1)$
