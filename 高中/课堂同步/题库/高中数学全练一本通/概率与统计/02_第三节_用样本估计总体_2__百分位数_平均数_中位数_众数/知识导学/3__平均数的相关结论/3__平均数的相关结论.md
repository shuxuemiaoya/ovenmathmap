## 3. 平均数的相关结论

（1）如果两组数 $x_{1}, x_{2}, \cdots, x_{n}$ 和 $y_{1}, y_{2}, \cdots, y_{n}$ 的平均数分别是 $\bar{x}$ 和 $\bar{y}$ ，则一组数 $x_{1} + y_{1}, x_{2} + y_{2}, \cdots, x_{n} + y_{n}$ 的平均数是 $\bar{x} + \bar{y}$ ；

（2）如果一组数 $x_{1}, x_{2}, \cdots, x_{n}$ 的平均数为 $\overline{x}$ ，则一组数 $ax_{1}, ax_{2}, \cdots, ax_{n}$ 的平均数为 $a\overline{x}$ .

（3）如果一组数 $x_{1}, x_{2}, \cdots, x_{n}$ 的平均数为 $\overline{x}$ ，则一组数 $x_{1} + b, x_{2} + b, \cdots, x_{n} + b$ 的平均数为 $\overline{x} + b$

（4）如果一组数 $x_{1}, x_{2}, \cdots, x_{n}$ 的平均数为 $\overline{x}$ ，则一组数 $ax_{1} + b, ax_{2} + b, \cdots, ax_{n} + b$ 的平均数为 $a\overline{x} + b$
