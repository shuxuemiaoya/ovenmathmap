## 1. 事件的相互独立性的概念

（1）定义:对任意两个事件 A 与 B, 如果 $P(AB)=P(A)P(B)$ 成立, 则称事件 A 与事件 B 相互独立, 简称为独立.

(2) 直观理解: 事件 A 与 B 相互独立的直观理解是, 事件 A 是否发生不会影响事件 B 发生的概率, 事件 B 是否发生也不会影响事件 A 发生的概率.

2. 性质: 如果事件 A 与事件 B 相互独立, 则 A 与 $\overline{B}$ , $\overline{A}$ 与 B, $\overline{A}$ 与 $\overline{B}$ 也都相互独立.

3. 两个相互独立事件同时发生的概率乘法: 事件 A 与事件 B 相互独立, 则 $P(AB) = P(A)P(B)$

4. 推广: 两个事件的相互独立可以推广到 $n(n > 2, n \in N^{*})$ 个事件的相互独立性, 即若事件 $A_{1}, A_{2}, \cdots, A_{n}$ 相互独立, 则这 n 个事件同时发生的概率 $P(A_{1}A_{2} \cdots A_{n}) = P(A_{1})P(A_{2}) \cdots P(A_{n})$

注意:两两独立和相互独立不是一个概念, 当 $A_{1}, A_{2}, A_{3}$ 两两独立, $P(A_{1}A_{2}A_{3}) = P(A_{1})P(A_{2})P(A_{3})$ 一般不成立.
