> [!faq]- 全练一本通解析
> **【答案】** $[\frac{5}{3}, \frac{11}{5}]$
>
> **【解析】**
> 函数 $f(x) = \frac{2x^2 + 3x + 8}{x^2 + x + 4} = \frac{2(x^2 + x + 4) + x}{x^2 + x + 4} = 2 + \frac{x}{x^2 + x + 4}$ ，当 $x = 0$ 时， $f(x) = 2$ ；当 $x \neq 0$ 时， $f(x) = 2 + \frac{1}{x + \frac{4}{x} + 1}$ ，根据对勾函数的性质可知：当 $x > 0$ 时， $x + \frac{4}{x} \geq 4$ ，则 $0 < \frac{1}{x + \frac{4}{x} + 1} \leq \frac{1}{5}$ ，所以 $2 < f(x) \leq \frac{11}{5}$ ，当 $x < 0$ 时， $x + \frac{4}{x} \leq -4$ ，则 $-\frac{1}{3} \leq \frac{1}{x + \frac{4}{x} + 1} < 0$ ，所以 $\frac{5}{3} \leq f(x) < 2$ ，综上所述，函数 $f(x) = \frac{2x^2 + 3x + 8}{x^2 + x + 4}$ 在 $x \in \mathbb{R}$ 上的值域是 $[\frac{5}{3}, \frac{11}{5}]$ 。故答案为： $[\frac{5}{3}, \frac{11}{5}]$
