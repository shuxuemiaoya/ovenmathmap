> [!faq]- 全练一本通解析
> **【解析】**
> 答案见解析
> 解析： $\because$ 函数 $f(x) = \frac{ax + 1}{x + 2} = \frac{a(x + 2) - 2a + 1}{x + 2} = a + \frac{1 - 2a}{x + 2}$ ∴任取 $x_{1},x_{2}\in (-2, + \infty)$ ，且 $x_{1} <   x_{2}$ 则 $f(x_{1}) - f(x_{2}) = (a + \frac{1 - 2a}{x_1 + 2}) - \left(a + \frac{1 - 2a}{x_2 + 2}\right) = \frac{1 - 2a}{x_1 + 2} -\frac{1 - 2a}{x_2 + 2} =$ $\frac{(1 - 2a)(x_2 - x_1)}{(x_1 + 2)(x_2 + 2)}$ $\because -2 <   x_1 <   x_2,\therefore x_2 - x_1 > 0,(x_1 + 2)(x_2 + 2) > 0$ ∴当 $1 - 2a > 0$ ，即 $a <   \frac{1}{2}$ 时， $f(x_{1}) - f(x_{2}) > 0$ ，即 $f(x_{1}) > f(x_{2})$ ，是减函数；
> 当 $1 - 2a <   0$ ，即 $a > \frac{1}{2}$ 时， $f(x_{1}) - f(x_{2}) <   0$ ，即 $f(x_{1}) <   f(x_{2})$ ，是增函数.
