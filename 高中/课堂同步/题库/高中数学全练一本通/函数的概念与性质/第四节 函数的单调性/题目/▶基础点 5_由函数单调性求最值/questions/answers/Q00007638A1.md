> [!faq]- 全练一本通解析
> **【答案】** （1） $f(x)=x^{2}+2x+2$ ；（2）最小值为1，最大值为26； （3）当 $m > -1$ 时， $f(x)_{\min} = m^2 + 2m + 2$ ，当 $m < -3$ 时， $f(x)_{\min} = m^2 + 6m + 10$ ，当 $-3 \leq m \leq -1$ 时， $f(x)_{\min} = 1$ 。
>
> **【解析】**
> （1）设二次函数解析式为 $f(x) = ax^2 + bx + c$ ，因为 $f(0) = 2$ ，所以 $c = 2$ ，因为 $f(x + 1) - f(x) = 2x + 3$ ，所以 $a(x + 1)^2 + b(x + 1) + c - ax^2 - bx - c = 2x + 3$ ，整理得 $2ax + a + b = 2x + 3$ ，所以 $\begin{cases} 2a = 2 \\ a + b = 3 \end{cases}$ ，解得 $\begin{cases} a = 1 \\ b = 2 \end{cases}$ ，所以 $f(x) = x^2 + 2x + 2$ 。（2）由（1）得 $f(x)$ 的对称轴为 $x = -1$ ，所以 $f(x)$ 在 $(-3, -1)$ 上单调递减， $(-1, 4)$ 上单调递增，所以 $f(x)_{\min} = f(-1) = 1$ 又 $f(-3) = 5$ ， $f(4) = 26$ ，所以 $f(x)_{\max} = f(4) = 26$ ，所以 $f(x)$ 在 $[-3, 4]$ 上的最小值为 1，最大值为 26。（3）当 $m > -1$ 时， $f(x)$ 在 $[m, m + 2]$ 上单调递增，所以 $f(x)_{\min} = f(m) = m^2 + 2m + 2$ ；当 $m + 2 < -1$ ，即 $m < -3$ 时， $f(x)$ 在 $[m, m + 2]$ 上单调递减，所以 $f(x)_{\min} = f(m + 2) = m^2 + 6m + 10$ ；当 $m \leq -1 \leq m + 2$ ，即 $-3 \leq m \leq -1$ 时， $f(x)$ 在 $(m, -1)$ 上单调递减， $(-1, m + 2)$ 上单调递增，所以 $f(x)_{\min} = f(-1) = 1$ 综上所述，当 $m > -1$ 时， $f(x)_{\min} = m^2 + 2m + 2$ ，当 $m < -3$ 时， $f(x)_{\min} = m^2 + 6m + 10$ ，当 $-3 \leq m \leq -1$ 时， $f(x)_{\min} = 1$ 。
