## 3. 函数的增减性的等价形式

设 $x_{1}, x_{2} \in [a, b]$ ，且 $x_{1} \neq x_{2}$ ，那么

① $\frac{f(x_1) - f(x_2)}{x_1 - x_2} > 0 \Leftrightarrow (x_1 - x_2)[f(x_1) - f(x_2)] > 0 \Leftrightarrow f(x)$ 在 $[a, b]$ 是增函数.

② $\frac{f(x_1) - f(x_2)}{x_1 - x_2} < 0 \Leftrightarrow (x_1 - x_2)[f(x_1) - f(x_2)] < 0 \Leftrightarrow f(x)$ 在 $[a, b]$ 是减函数.
