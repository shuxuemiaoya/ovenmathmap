> [!faq]- 全练一本通解析
> **【解析】**
> $f(x) = x^{2} - 2$ （ $x\leq -2$ 或 $x\geq 2$ ）
> 解析: 令 $t = x + \frac{1}{x}$ ，当 x > 0 时，则 $t = x + \frac{1}{x} \geq 2\sqrt{x \cdot \frac{1}{x}} = 2$ ，当且仅当 x = 1 时取等号，
> 当 x<0 时， $t=x+\frac{1}{x}=-\left[\left(-x\right)+\frac{1}{-x}\right]\leq-2\sqrt{\left(-x\right)\cdot\frac{1}{-x}}=-2$ ，当且仅当 x=-1 时取等号，所以， $t\leq-2$ 或 $t\geq2$ ，
> 且 $x^{2} + \frac{1}{x^{2}} = \left(x + \frac{1}{x}\right)^{2} - 2 = t^{2} - 2$ ，所以， $f(t) = t^2 -2$ ，其中 $t\leq -2$ 或 $t\geq 2$ 因此， $f(x) = x^{2} - 2$ （ $x\leq -2$ 或 $x\geq 2$ ）.
