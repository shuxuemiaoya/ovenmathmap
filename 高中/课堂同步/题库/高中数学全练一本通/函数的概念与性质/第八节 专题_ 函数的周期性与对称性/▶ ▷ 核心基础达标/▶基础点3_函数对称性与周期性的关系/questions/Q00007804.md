【4】判断下列函数的周期并画出满足题意的简图：

(1) $f(x)$ 为奇函数且满足 $f(4+x)+f(-x)=0$ ;

(2) $f(x)$ 为偶函数且满足 $f(4 + x) = f(2 - x)$ ;

(3) $f(x+1)$ 为奇函数且满足 $f(6+x)=f(-x)$ ;

(4) $f(x-1)$ 为偶函数且满足 $f(x)+f(2-x)=0$ ;

(5) $f(x+1)$ 为偶函数且满足 $f(2+x)-f(4-x)=0$ ;

(6) $f(x+5)$ 为奇函数且满足 $f(2+x)=-f(2-x)$ ;

(7) $f(x)$ 为偶函数且满足 $f(-2+x)+f(6-x)=2$ ;

(8) $f(x+2)$ 为偶函数且满足 $f(x)+f(8-x)=-2$ ;

(9) $f(2x + 1)$ 为奇函数且满足 $f(8 + x) = f(-2 - x)$ ;

(10) $f(4x - 2)$ 为偶函数且 $f(4 + x) + f(-2 - x) = 0$
