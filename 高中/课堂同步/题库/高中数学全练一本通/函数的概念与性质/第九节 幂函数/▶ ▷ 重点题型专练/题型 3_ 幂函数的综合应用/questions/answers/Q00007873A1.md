> [!faq]- 全练一本通解析
> **【答案】** （1） $f(x) = x^2$ ；（2）答案见解析；（3）(4,6)。
>
> **【解析】**
> （1）由 $f(x)$ 为幂函数，得 $m^2 - 5m + 7 = 1$ ，解得 $m = 2$ 或 $m = 3$ ， $m = 2$ 时， $f(x) = x$ 为奇函数，舍去； $m = 3$ 时， $f(x) = x^2$ 为偶函数，符合题意，所以 $m = 3, f(x) = x^2$ 。（2）由（1）知，原不等式化为 $ax^2 - (2a + 1)x + 2 < 0$ ，即 $(ax - 1)(x - 2) < 0$ ，
> 当 a=0 时, 解得 x>2 ;
> 当 $a < 0$ 时，不等式为 $(x - \frac{1}{a})(x - 2) > 0$ ，解得 $x < \frac{1}{a}$ 或 $x > 2$
> 当 a>0 时, 不等式化为 $(x-\frac{1}{a})(x-2)<0$ ,
> 当 $0 < a < \frac{1}{2}$ 时, 解得 $2 < x < \frac{1}{a}$ ;
> 当 $a = \frac{1}{2}$ 时，不等式无解；
> 当 $a > \frac{1}{2}$ 时, 解得 $\frac{1}{a} < x < 2$ ,
> 所以当 a=0 时, 原不等式的解集为 $\{x|x>2\}$ ;
> 当 $a < 0$ 时, 原不等式的解集为 $\{x \mid x < \frac{1}{a} \text{或} x > 2\}$ ;
> 当 $0 < a < \frac{1}{2}$ 时, 原不等式的解集为 $\left\{x \mid 2 < x < \frac{1}{a}\right\}$ ;
> 当 $a = \frac{1}{2}$ 时，原不等式的解集为 $\varnothing$ ；
> 当 $a > \frac{1}{2}$ 时，原不等式的解集为 $\left\{x \mid \frac{1}{a} < x < 2\right\}$ .
> （3）函数 $g(x) = x^2 - ax - 3$ 在 $[2,3]$ 上不单调，则有 $2 < \frac{a}{2} < 3$ ，解得 $4 < a < 6$
> 所以实数 a 的取值范围是 $(4,6)$ .
