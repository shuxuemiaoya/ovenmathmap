> [!faq]- 全练一本通解析
> **【解析】**
> $[-4,5]$
> 解析: 因为 $y = x^{2} - 2x - 3 = (x - 1)^{2} - 4$ ，且 $-2 \leq x \leq 2$ ，则当 x = 1 时， $y_{\min} = -4$ ，当 x = -2 时， $y_{\max} = 5$ ，则函数值域为 $[-4, 5]$ 。故答案为： $[-4, 5]$
