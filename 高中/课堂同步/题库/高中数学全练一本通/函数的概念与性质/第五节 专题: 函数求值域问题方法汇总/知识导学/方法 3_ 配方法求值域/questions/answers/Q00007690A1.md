> [!faq]- 全练一本通解析
> **【解析】**
> $\left[0, \sqrt{3}\right]$ 解析: 令 $\mu(x) = -x^{2} + 2x + 2$ ，则 $0 \leq \mu(x) = -x^{2} + 2x + 2 = -(x - 1)^{2} + 3 \leq 3$ ，所以 $0 \leq f(x) \leq \sqrt{3}$ 。故答案为： $\left[0, \sqrt{3}\right]$ 。
