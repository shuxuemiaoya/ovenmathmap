> [!faq]- 全练一本通解析
> **【解析】**
> $[2, 4]$ 解析: 由题意得: $3 + 2x - x^{2} \geq 0 \Rightarrow -1 \leq x \leq 3$ 。因 $3 + 2x - x^{2} = -(x - 1)^{2} + 4$ 。函数 $g(x) = -(x - 1)^{2} + 4$ 在 $[-1, 1]$ 上单调递增，在 $(1, 3]$ 上单调递减，则 $g(x)$ 在 $[-1, 3]$ 上的最大值为 $g(1) = 4$ ，最小值为 $g(-1) = g(3) = 0$ 。即 $3 + 2x - x^{2} \in [0, 4] \Rightarrow \sqrt{3 + 2x - x^{2}} \in [0, 2]$ 。则 $f(x) = 4 - \sqrt{3 + 2x - x^{2}} \in [2, 4]$ 。故答案为： $[2, 4]$ 。
