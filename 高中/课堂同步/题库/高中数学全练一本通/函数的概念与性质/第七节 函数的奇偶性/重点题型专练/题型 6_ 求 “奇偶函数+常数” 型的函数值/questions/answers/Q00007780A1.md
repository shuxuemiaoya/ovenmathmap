> [!faq]- 全练一本通解析
> **【答案】** 2
>
> **【解析】**
> $f(x) = \frac{x^2 + x + 1}{x^2 + 1} = \frac{x^2 + 1}{x^2 + 1} + \frac{x}{x^2 + 1} = 1 + \frac{x}{x^2 + 1}$ 令 $g(x) = \frac{x}{x^2 + 1}$ ，则其定义域为 R，又 $g(-x) = \frac{-x}{(-x)^2 + 1} = -\frac{x}{x^2 + 1} = -g(x)$ ，所以 $g(x) = \frac{x}{x^2 + 1}$ 为奇函数，则 $g(x)_{\max} + g(x)_{\min} = 0$ ，
> 所以 $f(x)_{\max} + f(x)_{\min} = g(x)_{\max} + 1 + g(x)_{\min} + 1 = 2$ ，则 $M + N = 2$ 。
