> [!faq]- 全练一本通解析
> **【解析】**
> -26
> 解析：令 $g(x) = x^5 + ax^3 + bx$ ， $x \in \mathbb{R}$ ，则 $g(-x) = (-x)^5 + a(-x)^3 - bx = -(x^5 + ax^3 + bx) = -g(x)$ ，所以 $g(x) = x^5 + ax^3 + bx$ 为奇函数，则 $f(x) = g(x) - 8$ ，又 $f(-2) = 10$ ，所以 $f(-2) = g(-2) - 8 = 10$ ，即 $g(-2) = 18$ ，所以 $g(2) = -g(-2) = -18$ ，所以 $f(2) = g(2) - 8 = -26$ 。
