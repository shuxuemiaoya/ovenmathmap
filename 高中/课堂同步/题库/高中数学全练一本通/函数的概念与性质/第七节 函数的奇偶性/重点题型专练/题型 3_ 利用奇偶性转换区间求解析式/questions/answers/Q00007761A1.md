> [!faq]- 全练一本通解析
> **【答案】** $f(x) = \begin{cases} x + \frac{3}{x} - 4, & x > 0 \\ 0, & x = 0 \\ x + \frac{3}{x} + 4, & x < 0 \end{cases}$
>
> **【解析】**
> 由 $x > 0$ 时， $f(x) = x + \frac{3}{x} - 4$ 可知， $f(-x) = -x - \frac{3}{x} - 4$ 又 $f(x)$ 为奇函数，故 $f(x) = -f(-x) = x + \frac{3}{x} + 4 (x < 0)$ ，并且 $f(0) = 0$ ∴函数 $f(x)$ 在R上的解析式为 $f(x) = \begin{cases} x + \frac{3}{x} - 4, & x > 0 \\ 0, & x = 0 \\ x + \frac{3}{x} + 4, & x < 0 \end{cases}$
