【2】(2024·全国高一专题练习) 判断下列函数是否具有奇偶性:

(1) $f(x) = x + x^{3} + x^{5}$ ;

(2) $f(x) = x^{2}, x \in [-1,3]$ ;

(3) $f(x) = x^{2} + |x|$ ;

(4) $f(x)=x+\frac{k}{x}$ ;

(5) $f(x) = x^{3} - 2x$

(6) $f(x) = \sqrt{x - 2} + \sqrt{2 - x}$ ;

(7) $f(x) = \sqrt{1 - x^2} +\sqrt{x^2 - 1};$

(8) $f(x) = |2x - 1| - |2x + 1|$ ;

(9) $f(x) = \frac{\sqrt{1 + x^2} + x - 1}{\sqrt{1 + x^2} + x + 1}.$
