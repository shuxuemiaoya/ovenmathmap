【9】利用奇偶性的性质判断函数的奇偶性：
(1) $f(x)=\frac{2x^{3}+x}{\sqrt{1+x^{2}}}$ ;

(2) $f(x) = \frac{2x^5}{1 + 3x^6} + \frac{1}{4} x$ ;

(3) $f(x) = \frac{3x^2}{\sqrt{3 + x^4}}$ ;

(4) $f(x) = \frac{3x^2}{\sqrt{3 + x^4}} + \frac{2|x|}{x^2 + 1}.$
