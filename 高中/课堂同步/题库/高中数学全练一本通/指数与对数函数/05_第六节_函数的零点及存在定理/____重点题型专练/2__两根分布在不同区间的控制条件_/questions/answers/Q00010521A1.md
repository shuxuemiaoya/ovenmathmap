> [!faq]- 全练一本通解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > （1） $0 < m \leq 1$ ；（2） $m < 1$ ；（3） $-\frac{4}{5} < m < 0$ ；（4） $m < -\frac{4}{5}$ ；（5） $\frac{2}{3} < m \leq 1$ .
> > 详解：（1）令 $f(x)=x^{2}+(m-3)x+m$ ，设 $f(x)$ 的两个零点为 $x_{1},x_{2}$ . 由题得 $\left\{\begin{aligned}&x_{1}+x_{2}=3-m>0\\ &x_{1}x_{2}=m>0\end{aligned}\right.$ ，解得 $0<m\leq1$ . $\Delta=\left(3-m\right)^{2}-4m\geq0$
> > （2）若 $f(x) = x^{2} + (m - 3)x + m$ 的一个零点大于1，一个零点小于1，则 $f(1) = 2m - 2 <   0$ ，解得 $m <   1$
> > (3) 若 $f(x)=x^{2}+(m-3)x+m$ 一个零点在 $(-2,0)$ 内，另一个零点在 $(0,4)$ 内，则 $\left\{\begin{aligned}f(-2)&=10-m>0\\ f(0)&=m<0\\ f(4)&=5m+4>0\end{aligned}\right.$ ，解得 $-\frac{4}{5}<m<0$
> > （4）若 $f(x) = x^{2} + (m - 3)x + m$ 的一个零点小于2，一个零点大于4，则 $\left\{ \begin{array}{l}f(2) = 3m - 2 <   0\\ f(4) = 5m + 4 <   0 \end{array} \right.$ ，解得 $m <   - \frac{4}{5}$
> > （5）若 $f(x)=x^{2}+(m-3)x+m$ 的两个零点都在 $(0,2)$ 内，则
> > $\left\{ \begin{array}{l} f(2) = 3m - 2 > 0 \\ f(0) = m > 0 \\ 0 < -\frac{m - 3}{2} < 2 \\ \Delta = (3 - m)^2 - 4m \geq 0 \end{array} \right.$ ，解得 $\frac{2}{3} < m \leq 1$
