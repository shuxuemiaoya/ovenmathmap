> [!faq]- 全练一本通解析
>
> > [!success]- **【答案】** BCD
>
> > [!note]- **【分析】**
> > 令 $f(x) = 0$ 转化为方程 $|x^2 - 9| = a + 2$ 的根的个数问题，利用函数图象的交点分析.
>
> > [!note]- **【解析】**
> > 方程 $|x^2 - 9| = a + 2$ 的解的个数即为曲线 $y = |x^2 - 9|$ 与水平直线 $y = a + 2$ 的交点个数.
> > 画出 $y = |x^2 - 9|$ 的图象：
> > 当 $a + 2 < 0$ 时，0 个交点；
> > 当 $a + 2 = 0$ 时，2 个交点（$x = \pm 3$）；
> > 当 $0 < a + 2 < 9$ 时，4 个交点；
> > 当 $a + 2 = 9$ 时，3 个交点；
> > 当 $a + 2 > 9$ 时，2 个交点.
> > 因此零点个数可能为 0, 2, 3, 4. 故选 BCD.
