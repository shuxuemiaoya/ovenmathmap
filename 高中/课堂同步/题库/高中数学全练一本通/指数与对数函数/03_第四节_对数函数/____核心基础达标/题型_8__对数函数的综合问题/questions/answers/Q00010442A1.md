> [!faq]- 全练一本通解析
>
> > [!success]- **【答案】** （1）(-1,1)；（2）当 a > 1 时，解集为 (0,1)；当 0 < a < 1 时，解集为 (-1,0)；
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > （1）因为函数 $f(x)$ 为奇函数，所以 $f(-x) = -f(x)$ ，即 $\log_a(1 - bx) - \log_a(1 + x) = -\log_a(1 + bx) + \log_a(1 - x)$ ，所以 $1 - b^2 x^2 = 1 - x^2$ ，得 $b^2 = 1$ ，又因为 b > 0，所以 b = 1
> > 根据解析式可得， $\begin{cases} 1 + x > 0 \\ 1 - x > 0 \end{cases}$ ，故 -1 < x < 1。所以 $f(x)$ 的定义域为 (-1,1)，（2）解不等式 $f(x) = \log_a(1 + x) - \log_a(1 - x) > 0$ ，即解 $\log_a \frac{1 + x}{1 - x} > 0$ 当 a > 1 时， $\log_a \frac{1 + x}{1 - x} > 0$ 等价于 $\frac{1 + x}{1 - x} > 1$ ，即 $\frac{2x}{1 - x} > 0$ ，解得 0 < x < 1；
> > 当 0 < a < 1 时， $\log_a \frac{1 + x}{1 - x} > 0$ 等价于 $\frac{1 + x}{1 - x} < 1$ ，即 $\frac{2x}{1 - x} < 0$ ，解得 x < 0 或 x > 1，又因为 -1 < x < 1，所以解集为 -1 < x < 0。
> > 综上，当 a > 1 时，解集为 (0,1)；当 0 < a < 1 时，解集为 (-1,0)；
