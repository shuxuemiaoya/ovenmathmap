> [!faq]- 全练一本通解析
>
> > [!success]- **【答案】** $a < c < b$
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > 根据对数函数单调性可知 $a = \log_20.3 < \log_21 = 0$ ，即可得 $a < 0$ 而 $b = \log_{\frac{1}{2}}0.4 > \log_{\frac{1}{2}}\frac{1}{2} = 1$ ，即 $b > 1$ ；由指数函数单调性及值域可得 $0 < c = 0.4^{0.3} < 0.4^0 = 1$ ，即可得 $0 < c < 1$ ；所以可得 $a < c < b$ 故答案为： $a < c < b$
