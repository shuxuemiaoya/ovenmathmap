> [!faq]- 全练一本通解析
>
> > [!success]- **【答案】** B
>
> > [!note]- **【解析】**
> > 因为 $\log_{2}2 < a = \log_{2}3 < \log_{2}4 = 2$ ，所以 1 < a < 2 $c = \left(\frac{1}{2}\right)^{\log_{3}2}, 0 < \log_{3}2 < 1 = \log_{3}3, c = \left(\frac{1}{2}\right)^{\log_{3}2} > \frac{1}{2}$ , $b = 2^{\ln 3}, \ln 3 > 1 = \ln e, b = 2^{\ln 3} > 2^{1} = 2$ ,
> >
> > 所以 c < a < b. 故选：B.
