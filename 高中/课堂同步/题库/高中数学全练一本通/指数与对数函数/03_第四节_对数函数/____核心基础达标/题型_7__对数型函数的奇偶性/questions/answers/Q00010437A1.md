> [!faq]- 全练一本通解析
>
> > [!success]- **【答案】** 2
>
> > [!note]- **【解析】**
> > 由已知得 $f(x) = 1 + \frac{2x + \ln\left(\sqrt{x^2 + 1} + x\right)}{x^2 + 1}$ 因为 $\ln \left(\sqrt{x^2 + 1} + x\right) + \ln \left[\sqrt{\left(-x\right)^2 + 1} + (-x)\right] = \ln 1 = 0$ 所以 $\ln \left[\sqrt{\left(-x\right)^2 + 1} + (-x)\right] = -\ln \left(\sqrt{x^2 + 1} + x\right)$ 易知函数 $y = \ln \left(\sqrt{x^2 + 1} + x\right)$ 的定义域为R，因此函数 $y = \ln \left(\sqrt{x^2 + 1} + x\right)$ 是奇函数.  
> > 令 $g(x) = \frac{2x + \ln\left(\sqrt{x^2 + 1} + x\right)}{x^2 + 1}$ 则 $g(-x) = \frac{-2x - \ln(\sqrt{x^2 + 1} + x)}{x^2 + 1} = -g(x), g(x)$ 为奇函数，  
> > 则 $g(x)$ 的最大值 $M_{1}$ 和最小值 $N_{1}$ 满足 $M_{1} + N_{1} = 0$ 因为 $M = M_{1} + 1, N = N_{1} + 1$ ，所以 $M + N = 2$ .故答案为：2.
