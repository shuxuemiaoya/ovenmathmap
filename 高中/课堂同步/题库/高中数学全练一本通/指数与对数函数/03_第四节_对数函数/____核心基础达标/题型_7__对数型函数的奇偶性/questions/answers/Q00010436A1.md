> [!faq]- 全练一本通解析
>
> > [!success]- **【答案】** -5
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > 由 $f(x) = x^{2}\ln \left(\sqrt{x^{2} + 1} + x\right) + 2$ ，
> > 令 $h(x) = x^{2}\ln \left(\sqrt{x^{2} + 1} + x\right), x\in \mathbf{R}$ 则 $h(-x) = x^{2}\ln \left(\sqrt{x^{2} + 1} - x\right) = x^{2}\ln \left(\frac{1}{\sqrt{x^{2} + 1} + x}\right)$ $= -x^{2}\ln \left(\sqrt{x^{2} + 1} + x\right) = -h(x)$ 所以函数 $h(x)$ 为奇函数，则 $f(a) = h(a) + 2 = 9$ ，解得 $h(a) = 7$ 所以 $f(-a) = h(-a) + 2 = -h(a) + 2 = -7 + 2 = -5$ .故答案为：-5
