> [!faq]- 全练一本通解析
>
> > [!success]- **【答案】** C
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > 解析：因为 $f(x) = \log_2(4^x + 1) - x + \sqrt{x^2 - 1}$ $= \log_2(4^x + 1) - \log_22^x + \sqrt{x^2 - 1} = \log_2\frac{4^x + 1}{2^x} + \sqrt{x^2 - 1}$ $= \log_2(2^x + 2^{-x}) + \sqrt{x^2 - 1}$ 由 $x^{2} - 1\geq 0$ 可得 $x\leq -1$ 或 $x\geq 1$ ，即函数 $f(x)$ 的定义域为 $(-\infty , - 1]\cup [1, + \infty)$ 因为 $f(-x) = \log_2(2^{-x} + 2^x) + \sqrt{(-x)^2 - 1} = \log_2(2^{-x} + 2^x) + \sqrt{x^2 - 1} = f(x)$ 所以，函数 $f(x)$ 为偶函数，
> > 同时可证函数 $f(x)$ 在 $[1, + \infty)$ 上为增函数，
> > 由 $f(x + 2) > f(2x)$ 可得 $f(|x + 2|) > f(|2x|)$ ，可得 $|x + 2| > |2x|\geq 1$ 解得 $-\frac{2}{3} < x\leq -\frac{1}{2}$ 或 $\frac{1}{2}\leq x < 2$ 因此，原不等式的解集为 $\left(-\frac{2}{3}, - \frac{1}{2}\right]\cup \left[\frac{1}{2},2\right)$ .
> >
> > 故选 **C**.
