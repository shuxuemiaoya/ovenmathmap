> [!faq]- 全练一本通解析
>
> > [!success]- **【答案】** $a = 1$
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > 因为 $f(x) = \log_2\frac{1 - x}{a + x}$ 是奇函数，所以 $f(-x) = -f(x)$ 所以 $f(-x) + f(x) = \log_2\frac{1 + x}{a - x} +\log_2\frac{1 - x}{a + x}$ 所以 $\frac{1 - x^2}{a^2 - x^2} = 1,a^2 = 1$ 所以 $a = 1$ 或 $a = -1$ 当 $a = -1$ 时， $f(x) = \log_2\frac{1 - x}{-1 + x}$ 无意义不成立；当 $a = 1$ 时， $f(x) = \log_2\frac{1 - x}{1 + x},f(-x) = -f(x)$ $= \log_2\left(\frac{1 + x}{a - x}\right)\times \left(\frac{1 - x}{a + x}\right) = \log_2\left(\frac{1 - x^2}{a^2 - x^2}\right) = 0,$ ， $f(x) = \log_2\frac{1 - x}{a + x}$ 是奇函数.
