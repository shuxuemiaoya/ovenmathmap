> [!faq]- 全练一本通解析
>
> > [!success]- **【答案】** B
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > B解析：函数 $f(x) = \ln \left(\frac{1 + x}{1 - x}\right)$ ，则 $\frac{1 + x}{1 - x} >0$ ，即 $(x + 1)(x - 1) <   0$ ，解得 $-1 <   x <   1$ 所以函数的定义域为（-1,1），故A正确；又 $f(-x) = \ln \left(\frac{1 - x}{1 + x}\right) = \ln \left(\frac{1 + x}{1 - x}\right)^{-1} = -\ln \left(\frac{1 + x}{1 - x}\right) = -f(x)$ 所以 $f(x)$ 的奇函数，则函数图象关于原点对称，故B错误，C正确；因为 $f(x) = \ln \left(\frac{1 + x}{1 - x}\right) = \ln \left(-1 + \frac{-2}{x - 1}\right)$ 又 $y = \frac{-2}{x - 1}$ 在(0,1）上单调递增， $y = \ln x$ 在定义域 $(0, + \infty)$ 上单调递增，所以 $f(x)$ 在(0,1）上单调递增，故D正确.
> >
> > 故选 **B**
