> [!faq]- 全练一本通解析
>
> > [!success]- **【答案】** （1） $\frac{1}{2}$ ；（2）2；（3）13；（4）-7；（5）5；（6）-1；（7）7； (8) $\frac{14}{3}$ ;
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > （1） $\lg \sqrt{2} +\lg \sqrt{5} = \lg (\sqrt{2}\times \sqrt{5}) = \lg \sqrt{10} = \frac{1}{2}.$
> > (2) $\log_345 - \log_35 = \log_3\frac{45}{5} = \log_39 = 2$
> > (3) $\log_2\left(2^3\times 4^5\right) = \log_22^3 +\log_24^5 = 3 + 5\log_24 = 3 + 5\log_22^2 = 3 + 5\times 2 = 13$
> > (4) $\log_2\left(\frac{2^3}{4^5}\right) = \log_22^3 -\log_24^5 = \log_22^3 -\log_22^{10} = 3 - 10 = -7.$
> > (5) $\log_3(9\times 27) = \log_3\left(3^2\times 3^3\right) = \log_33^5 = 5$
> > (6) $\log_7\frac{5}{9} +\log_7\frac{9}{35} = \log_7\left(\frac{5}{9}\times \frac{9}{35}\right) = \log_7\frac{1}{7} = -1$
> > （7）由 $\log_3(27\times 9^2) = \log_3(3^3\times 3^4) = \log_33^7 = 7$
> > (8) $\log_2\left(2^4\times \sqrt[3]{4}\right) = \log_22^4 +\log_2\sqrt[3]{4} = 4 + \log_22^{\frac{2}{3}} = 4 + \frac{2}{3} = \frac{14}{3}.$
