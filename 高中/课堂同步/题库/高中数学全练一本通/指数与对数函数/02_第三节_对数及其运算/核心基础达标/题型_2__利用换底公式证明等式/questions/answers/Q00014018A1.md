> [!faq]- 全练一本通解析
>
> > [!success]- **【答案】** （1）证明见解析；（2）3x<4y<6z
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > （1）证明：令 $3^{x} = 4^{y} = 6^{z} = m$ ，利用指数式和对数式的互化知 $x = \log_3m$ ， $y = \log_4m$ ， $z = \log_6m$ 则 $\frac{1}{x} = \log_m3$ ， $\frac{1}{y} = \log_m4$ ， $\frac{1}{z} = \log_m6$ ∴ $\frac{1}{z} -\frac{1}{x} = \log_{m}6 - \log_{m}3 = \log_{m}2 = \frac{1}{2y}$ （2） $3x < 4y < 6z$ 证明：因为正实数 $x,y,z,\therefore 3x > 0,4y > 0,6z > 0$ ， $\therefore \frac{3x}{4y} = \frac{3\log_3m}{4\log_4m} = \frac{3\frac{\lg m}{\lg 3}}{4\frac{\lg m}{\lg 4}} = \frac{3}{4}\times \frac{\lg 4}{\lg 3} = \frac{3}{4}\log_34 = \log_3\sqrt[4]{64}$ 又 $\sqrt[4]{64} < 3$ ，∴ $\log_3\sqrt[4]{64} < 1$ ，∴ $3x < 4y$ ∴ $\frac{4y}{6z} = \frac{4\log_4m}{6\log_6m} = \frac{4\frac{\lg m}{\lg 4}}{6\frac{\lg m}{\lg 6}} = \frac{2}{3}\times \frac{\lg 6}{\lg 4} = \frac{2}{3}\log_46 = \log_2\sqrt[3]{6}$ 又 $\sqrt[3]{6} < 2$ ，∴ $\log_2\sqrt[3]{6} < 1$ ，∴ $4y < 6z$ ∴ $3x < 4y < 6z$ ：
