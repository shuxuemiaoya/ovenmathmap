【56】（多选）已知函数 $f(x) = \begin{cases} |x^2 + 2x|, & x \leq 1 \\ \frac{4}{x} - 1, & x > 1 \end{cases}$ . 若 $m, n, k, t, c (m < n < k < t < c)$ 满足 $f(m) = f(n) = f(k) = f(t) = f(c) = a$ ，则下列结论正确的是（）
A. $a \in (0,1)$ B. $m + n + k + t = -4$ C. 若 $b = mf(m) + nf(n) + kf(k) + tf(t) + cf(c)$ ，则 $b \in (-2,0)$ D. 若 $s = mf(m) + tf(t) + cf(c)$ ，则 $s \in (0,6 - \sqrt{33})$
