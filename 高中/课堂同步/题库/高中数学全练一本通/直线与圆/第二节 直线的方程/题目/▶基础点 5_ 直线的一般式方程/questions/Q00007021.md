A. 当 C = 0 时，l 过坐标原点

B. 当 AB > 0 时，l 的倾斜角为锐角

C. 当 $B = 0, C \neq 0$ 时，l 和 x 轴平行

D. 若直线 l 过点 $P(x_{0}, y_{0})$ ，直线 l 的方程可化为 $A(x - x_{0}) + B(y - y_{0}) = 0$
