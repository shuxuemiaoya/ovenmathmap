> [!faq]- 全练一本通解析
> **【解析】**
> $\frac{2\sqrt{109}}{5}$ 解析：设 $P(x,0)$ ，则 $\left|PA\right| = \sqrt{\left[x - (-3)\right]^2 + (0 - 4)^2} = \sqrt{x^2 + 6x + 25}$ ， $\left|PB\right| = \sqrt{(x - 2)^2 + (0 - \sqrt{3})^2} = \sqrt{x^2 - 4x + 7}$ ，由 $\left|PA\right| = \left|PB\right|$ ，得 $\sqrt{x^2 + 6x + 25} = \sqrt{x^2 - 4x + 7}$ 。解得 $x = -\frac{9}{5}$ ，所以 $P\left(-\frac{9}{5},0\right)$ ，且 $|PA| = \frac{2\sqrt{109}}{5}$ 。
