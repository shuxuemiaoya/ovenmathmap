> [!faq]- 全练一本通解析
> **【答案】** $x^{2} + y^{2} - 4x - 2y + 3 = 0$
>
> **【解析】**
> 依题意，设 △ABC 的外接圆的一般方程为 $x^{2} + y^{2} + Dx + Ey + F = 0 (D^{2} + E^{2} - 4F > 0)$ ，
> 则 $\left\{\begin{aligned}&1 + 4 + D + 2E + F = 0\\ &9 + 4 + 3D + 2E + F = 0\\ &9 + 0 + 3D + 0 + F = 0\end{aligned}\right.$ ，解得 $\left\{\begin{aligned}&D=-4\\ &E=-2\\ &F=3\end{aligned}\right.$ ，
> 所以所求圆的一般方程为 $x^{2} + y^{2} - 4x - 2y + 3 = 0$ ，
> 则其标准方程为 $(x-2)^{2}+(y-1)^{2}=2$ 。
