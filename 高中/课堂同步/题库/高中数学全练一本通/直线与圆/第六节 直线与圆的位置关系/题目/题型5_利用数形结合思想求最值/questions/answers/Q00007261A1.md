> [!faq]- 全练一本通解析
> **【答案】** 详见解析
>
> **【解析】**
> $x^{2} + y^{2} - 6x - 6y + 14 = 0$ 即 $(x - 3)^{2} + (y - 3)^{2} = 4$ .圆心为 $C(3,3)$ ，半径 $r = 2$ （1） $\frac{y}{x}$ 表示圆上的点 $P$ 与原点连线的斜率，显然 $PO$ 与圆相切时，斜率最大或最小.设切线方程为 $y = kx$ ，即 $kx - y = 0$ ，由圆心 $C(3,3)$ 到切线的距离等于半径2，可得 $\frac{|3k - 3|}{\sqrt{k^2 + 1}} = 2$ ，解得 $k = \frac{9\pm 2\sqrt{14}}{5}$ 所以 $\frac{y}{x}$ 的最大值为 $\frac{9 + 2\sqrt{14}}{5}$ 最小值为 $\frac{9 - 2\sqrt{14}}{5}$ （2） $x^{2} + y^{2} + 2x + 3 = (x + 1)^{2} + y^{2} + 2$ ，它表示圆 $C$ 上的点 $M$ 到 $E(-1,0)$ 的距离的平方再加2，所以，当点 $M$ 与点 $E$ 的距离最大或最小时，所求式子取最大值或最小值.显然，点 $M$ 与点 $E$ 的距离的最大值为 $|CE| + 2$ ，点 $M$ 与点 $E$ 的距离的最小值为 $|CE| - 2$ .又 $|CE| = \sqrt{(3 + 1)^2 + 3^2} = 5$ 所以 $x^{2} + y^{2} + 2x + 3$ 的最大值为 $(5 + 2)^{2} + 2 = 51$ ，最小值为 $(5 - 2)^{2} + 2 = 11.$ （3）设 $x + y = b$ ，则 $b$ 表示动直线 $y = -x + b$ 的纵截距，显然当动直线 $y = -x + b$ 与圆 $(x - 3)^2 +(y - 3)^2 = 4$ 相切时， $b$ 取最大值或最小值.由圆心 $C(3,3)$ 到切线 $x + y - b = 0$ 的距离等于圆的半径2，得 $\frac{|3 + 3 - b|}{\sqrt{l^2 + 1^2}} = 2$ ，即 $|b - 6| = 2\sqrt{2}$ ，解得 $b = 6\pm 2\sqrt{2}$ ，所以 $x + y$ 的最大值为 $6 + 2\sqrt{2}$ ，最小值为 $6 - 2\sqrt{2}$
> （4）点到直线的距离公式为 $d = \frac{|Ax_0 + By_0 + C|}{\sqrt{A^2 + B^2}}$ ， $|4x + 3y + 9|$ 可变形为 $5 \times \frac{|4x + 3y + 9|}{5}$ 。其中 $\frac{|4x + 3y + 9|}{5}$ 可表示为圆上的点到直线 $4x + 3y + 9 = 0$ 的距离。所以 $|4x + 3y + 9|$ 的最小值可转化为求圆上的点到直线 $4x + 3y + 9 = 0$ 的距离的5倍。通过计算圆心到直线的距离减半径得 $|4x + 3y + 9|$ 的最小值为20。
