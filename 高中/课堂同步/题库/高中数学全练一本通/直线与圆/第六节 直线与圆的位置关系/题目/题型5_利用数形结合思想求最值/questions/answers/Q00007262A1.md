> [!faq]- 全练一本通解析
> **【答案】** （1） $16 + 2\sqrt{10}$ （2）最大值为 $2 + \sqrt{3}$ ，最小值为 $2 - \sqrt{3}$ 。 （3） $61 + 4\sqrt{106}$ ， $61 - 4\sqrt{106}$ （4） $104 - 26\sqrt{2}$
>
> **【解析】**
> （1）解：由圆 $C: x^2 + y^2 - 4x - 14y + 45 = 0$ ，可得圆心为 $C(2,7)$ ，半径 $r = 2\sqrt{2}$ ，设 $m + 2n = t$ ，将 $m + 2n = t$ 看成直线方程，因为该直线与圆 $C$ 有公共点，所以圆心 $C$ 到直线的距离 $d = \frac{|1 \times 2 + 2 \times 7 - t|}{\sqrt{1^2 + 2^2}} \leq 2\sqrt{2}$ ，解得 $16 - 2\sqrt{10} \leq t \leq 16 + 2\sqrt{10}$ ，所以 $m + 2n$ 的最大值为 $16 + 2\sqrt{10}$ 。
> （2）解：记点 $Q(-2,3)$ ，则 $\frac{n-3}{m+2}$ 表示直线 $MQ$ 的斜率，设直线 $MQ$ 的方程为 $y - 3 = k(x + 2)$ ，即 $kx - y + 2k + 3 = 0$ ，因为直线 $MQ$ 与圆 $C$ 有公共点，可得 $d = \frac{|2k - 7 + 2k + 3|}{\sqrt{k^2 + 1}} \leq 2\sqrt{2}$ ，解得 $2 - \sqrt{3} \leq k \leq 2 + \sqrt{3}$ ，所以 $\frac{n-3}{m+2}$ 的最大值为 $2 + \sqrt{3}$ ，最小值为 $2 - \sqrt{3}$ 。
> （3）解：设 $u = m^2 + n^2 = (m - 0)^2 + (n - 0)^2$ ，则 $u$ 等价于圆 $C$ 的圆心 $C(2,7)$ 到原点的距离的平方，根据圆的性质，可得 $u_{\max} = [\sqrt{(2 - 0)^2 + (7 - 0)^2} + r]^2 = (\sqrt{53} + 2\sqrt{2})^2 = 61 + 4\sqrt{106}$ ， $u_{\min} = [\sqrt{(2 - 0)^2 + (7 - 0)^2} - r]^2 = (\sqrt{53} - 2\sqrt{2})^2 = 61 - 4\sqrt{106}$ 。
> （4）点到直线的距离公式为 $d = \frac{|Ax_0 + By_0 + C|}{\sqrt{A^2 + B^2}}$ ， $|5m + 12n + 10|$ 可变形为 $13 \times \frac{|5m + 12n + 10|}{13}$ 。其中 $\frac{|5m + 12n + 10|}{13}$ 可表示为圆上的点 $M(m,n)$ 到直线 $5x + 12y + 10 = 0$ 的距离。通过计算圆心到直线的距离减半径得 $\frac{|5m + 12n + 10|}{13}$ 的最小值为 $8 - 2\sqrt{2}$ ，故 $|5m + 12n + 10|$ 的最小值为 $104 - 26\sqrt{2}$ 。
