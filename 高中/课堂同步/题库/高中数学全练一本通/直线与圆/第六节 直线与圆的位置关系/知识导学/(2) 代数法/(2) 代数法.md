## (2) 代数法

直线 $Ax + By + C = 0$ 和圆 $x^{2} + y^{2} + Dx + Ey + F = 0$ 的位置关系, 可由 $\left\{\begin{aligned}&Ax + By + C = 0,\\ &x^{2} + y^{2} + Dx + Ey + F = 0\end{aligned}\right.$ 推出关于 x 的一元二次方程 $mx^{2} + nx + p = 0 (m \neq 0)$ , 利用判别式 $\Delta$ 进行判断
① $\Delta < 0 \Leftrightarrow$ 直线 l 和圆 C 相离 $\Leftrightarrow$ 直线 l 和圆 C 没有公共点;
② $\Delta = 0 \Leftrightarrow$ 直线 l 和圆 C 相切 $\Leftrightarrow$ 直线 l 和圆 C 有一个公共点;
③ $\Delta > 0 \Leftrightarrow$ 直线 l 和圆 C 相交 $\Leftrightarrow$ 直线 l 和圆 C 有两个公共点.
