> **【解析】**
> $x+2y+3=0$
> 解析:由题意得 $l' // l$ ，故设 $l': x + 2y + c = 0 (c \neq -1)$ ，在 l 上取点 $A(1,0)$ ，则点 $A(1,0)$ 关于点 $(1,-1)$ 的对称点是 $A'(1,-2)$ ，所以 $1 + 2 \times (-2) + c = 0$ ，即 c = 3，故直线 $l'$ 的方程为 $x + 2y + 3 = 0$ 。
>
> 故选 **C**
