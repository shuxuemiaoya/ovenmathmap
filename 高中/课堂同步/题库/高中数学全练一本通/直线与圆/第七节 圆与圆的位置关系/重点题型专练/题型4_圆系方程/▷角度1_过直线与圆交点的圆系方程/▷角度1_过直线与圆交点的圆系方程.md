▷角度1:过直线与圆交点的圆系方程
经过圆 $C: x^{2} + y^{2} + Dx + Ey + F = 0$ 与直线 $l: ax + by + c = 0$ 的两个交点的圆的方程可设为: $x^{2} + y^{2} + Dx + Ey + F + \lambda(ax + by + c) = 0$ .整理得 $x^{2} + y^{2} + (D + \lambda a)x + (E + \lambda b)y + F + \lambda c = 0$ .
