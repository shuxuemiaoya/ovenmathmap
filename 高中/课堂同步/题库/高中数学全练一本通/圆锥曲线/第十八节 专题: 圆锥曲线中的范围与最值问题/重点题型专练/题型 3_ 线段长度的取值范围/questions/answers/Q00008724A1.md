> [!faq]- 全练一本通解析
> **【解析】**
> （1） \( \frac{x^2}{2} + y^2 = 1 \) （2） \( \frac{4\sqrt{2}}{3} \)
> 解析：（1）由题意可得  \( \left\{\begin{aligned}&2a = 2\sqrt{2}\\&b = c\\&a^2 = b^2 + c^2\end{aligned}\right. \) ，解得  \( \left\{\begin{aligned}&a = \sqrt{2}\\&b = 1\\&c = 1\end{aligned}\right. \) ，所以椭圆 E 的方程为
> \( \frac{x^2}{2} + y^2 = 1 \) ;
> （2）椭圆 E 左焦点为  \( (-1,0) \) ，
> 设过椭圆 E 左焦点的直线为 x = my - 1 （m 存在且不为 0），
> \( \left\{\begin{aligned}\frac{x^2}{2} + y^2 &= 1, \\x &= my - 1\end{aligned}\right. \) ，则  \( (m^2 + 2)y^2 - 2my - 1 = 0 \) ，设  \( M(x\_1, y\_1), N(x\_2, y\_2) \) ，
> 则  \( \Delta = 4m^2 + 4(m^2 + 2) = 8m^2 + 8 > 0 \) ，且  \( y\_1 + y\_2 = \frac{2m}{m^2 + 2}, y\_1 y\_2 = \frac{-1}{m^2 + 2} \) ，
> 所以 MN 的中点为  \( (\frac{-2}{m^2 + 2}, \frac{m}{m^2 + 2}) \) ，
> 因此线段 MN 的垂直平分线为  \( y - \frac{m}{m^2 + 2} = -m(x - \frac{-2}{m^2 + 2}) \) ，令 x = 0，则 Q 的纵坐标为  \( \frac{-m}{m^2 + 2} \) ，因为与 y 轴交于负半轴，所以 m > 0，又因为点 Q 的纵坐标的最大值是  \( -\frac{1}{3} \) ，所以  \( \frac{-m}{m^2 + 2} \leq -\frac{1}{3} \) ，即  \( 1 \leq m \leq 2 \) ，
> 而  \( |MN| = \sqrt{1 + m^2} \sqrt{(y\_1 + y\_2)^2 - 4y\_1 y\_2} = \sqrt{1 + m^2} \sqrt{\left(\frac{2m}{m^2 + 2}\right)^2 - 4 \times \frac{-1}{m^2 + 2}} = \sqrt{1 + m^2} \sqrt{\left(\frac{8m^2 + 8}{(m^2 + 2)^2}\right)} = \frac{2\sqrt{2}(m^2 + 1)}{m^2 + 2} = 2\sqrt{2}\left(1 - \frac{1}{m^2 + 2}\right) = m^{-3}/3^{3/5} < m^{-3}/3^{3/5} < m^{-3}/3^{3/5} < m^{-3}/3^{3/5} < m^{-3}/3^{3/5} < m^{-3}/3^{3/5} < m^{-3}/3^{3/5} < m^{-3}/3^{3/5} < m^{-3}/3^{3/5} < m^{-3}/3^{3/5} < n^{-3}/3^{3/5} < n^{-3}/3^{3/5} < n^{-3}/3^{3/5} < n^{-3}/3^{3/5} < n^{-3}/3^{3/5} < n^{-3}/3^{3/5} < n^{-3}/3^{3/5} < n^{-3}/3^{3/5} < n^{-3}/3^{3/5} < n^-3/n^{-3}/3^{3/5} < n^-3/n^{-3}/3^{3/5} < n^-3/n^{-3}/3^{3/5} < n^-3/n^{-3}/3^{3/5} < n^-3/n^{-3}/3^{3/5} < n^-3/n^{-3}/3^{3/5} < n^-3/n^{-3}/3^{3/5} < n^-3/n^{-6/7}<sup>0</sup>
