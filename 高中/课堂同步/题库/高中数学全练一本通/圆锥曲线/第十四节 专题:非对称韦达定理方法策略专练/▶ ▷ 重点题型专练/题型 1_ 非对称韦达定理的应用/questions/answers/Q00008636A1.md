> [!faq]- 全练一本通解析
> **【解析】**
> 详见解析
> 解析：（1）由 $\angle OHF_2 = 30^\circ$ ，得 $b = \sqrt{3}c$ （ $c$ 为半焦距）， $\because$ 点 $\left(1, \frac{3}{2}\right)$ 在椭圆 $E$ 上，则 $\frac{1}{a^2} + \frac{9}{4b^2} = 1$ 。又 $a^2 = b^2 + c^2$ ，
> 解得 $a = 2, b = \sqrt{3}, c = 1$ 。∴ 椭圆 $E$ 的方程为 $\frac{x^2}{4} + \frac{y^2}{3} = 1$ 。
> （2）因为 $F_2(1,0)$ 。设直线 $l: x = my + 1, A(x_1, y_1), B(x_2, y_2)$ 。由 $\left\{\begin{aligned}&x = my + 1 \\&\frac{x^2}{4} + \frac{y^2}{3}\\&-\end{aligned}\right.$ 消去 $x$ ，得 $(3m^2 + 4)y^2 + 6my - 9 = 0$ 。显然 $\Delta = 144(m^2 + 1) > 0$ 。
> 则 $y_1 + y_2 = \frac{-6m}{3m^2 + 4}, y_1y_2 = \frac{-9}{3m^2 + 4}$ 。 $\therefore my_1y_2 = \frac{3}{2}(y_1 + y_2)$ 。由 $P(-2,0), Q(2,0)$ ，得直线 $AP$ 的斜率 $k_1 = \frac{y_1}{x_1 + 2}$ ，直线 $BQ$ 的斜率 $k_2 = \frac{y_2}{x_2 - 2}$ 。
> 又 $\left|k_1\right| = \frac{|OM|}{|OP|}, \left|k_2\right| = \frac{|ON|}{|OQ|}, |OP| = |OQ| = 2$ ， $\therefore \frac{|OM|}{|ON|} = \frac{|k_1|}{|k_2|}$ 。 $\therefore \frac{S_{\triangle MPQ}}{S_{\triangle NPQ}} = \frac{\frac{1}{2}|PQ|\cdot|OM|}{\frac{1}{2}|PQ|\cdot|ON|} = \frac{|OM|}{|ON|} = \frac{|k_1|}{|k_2|}$ 。 $\because \frac{k_1}{k_2} = \frac{y_1(x_2 - 2)}{(x_1 + 2)y_2} = \frac{y_1(my_2 - 1)}{(my_1 + 3)y_2} = \frac{my_1y_2 - y_1}{my_1y_2 + 3y_2} = \frac{\frac{3}{2}(y_1 + y_2) - y_1}{\frac{3}{2}(y_1 + y_2) + 3y_2}$ $= \frac{\frac{1}{2}y_1 + \frac{3}{2}y_2}{\frac{3}{2}y_1 + \frac{9}{2}y_2} = \frac{1}{3}$ $\therefore \frac{S_{\triangle MPQ}}{S_{\triangle NPQ}} = \frac{1}{3}$ 。
