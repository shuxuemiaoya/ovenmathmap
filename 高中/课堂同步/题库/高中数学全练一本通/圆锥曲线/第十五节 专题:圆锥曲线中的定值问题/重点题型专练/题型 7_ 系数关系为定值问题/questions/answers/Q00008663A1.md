> [!faq]- 全练一本通解析
> **【答案】** （1） $\frac{x^{2}}{2}+y^{2}=1$ ；（2）存在，定值为 -4.
>
> **【解析】**
> （1）由题可得 $a=\sqrt{b^{2}+c^{2}}=\sqrt{2}$ 又 $e=\frac{c}{a}=\frac{\sqrt{2}}{2}$ ，所以 c=1 $b=\sqrt{a^{2}-c^{2}}=1$ 因此椭圆方程为 $\frac{x^{2}}{2}+y^{2}=1$ （2）由题可得直线斜率存在，设直线 l 的方程为 $y=k(x-1)$ ，
> 由 $\left\{\begin{aligned}y=k(x-1)\\ \frac{x^{2}}{2}+y^{2}=1\end{aligned}\right.$ 消去 y，整理得： $(1+2k^{2})x^{2}-4k^{2}x+2k^{2}-2=0$ 设 $A(x_{1},y_{1}),B(x_{2},y_{2})$ ，则 $\left\{ \begin{array}{l}x_{1} + x_{2} = \frac{4k^{2}}{1 + 2k^{2}}\\ x_{1}x_{2} = \frac{2k^{2} - 2}{1 + 2k^{2}} \end{array} \right.$ 又 $F(1,0),P(0, - k)$ ，则 $\overline{PA} = (x_1,y_1 + k),\overline{AF} = (1 - x_1, - y_1)$ 由 $\overline{PA} = \lambda_1\overline{AF}$ 可得 $x_{1} = \lambda_{1}(1 - x_{1})$ ，所以 $\lambda_1 = \frac{x_1}{1 - x_1}$ 同理可得 $\lambda_{2} = \frac{x_{2}}{1 - x_{2}}$ 所以 $\lambda_1 + \lambda_2 = \frac{x_1}{1 - x_1} +\frac{x_2}{1 - x_2} = \frac{x_1 + x_2 - 2x_1x_2}{(1 - x_1)(1 - x_2)} = \frac{x_1 + x_2 - 2x_1x_2}{1 - (x_1 + x_2) + x_1x_2}$ $= \frac{\frac{4k^2}{1 + 2k^2} - 2\times\frac{2k^2 - 2}{1 + 2k^2}}{1 - \frac{4k^2}{1 + 2k^2} + \frac{2k^2 - 2}{1 + 2k^2}} = -4$ 所以， $\lambda_{1} + \lambda_{2}$ 为定值-4.
