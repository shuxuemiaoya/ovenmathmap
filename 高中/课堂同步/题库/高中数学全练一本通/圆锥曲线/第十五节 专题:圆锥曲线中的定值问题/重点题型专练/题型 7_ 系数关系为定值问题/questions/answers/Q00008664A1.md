> [!faq]- 全练一本通解析
> **【答案】** （1） $C:\frac{x^2}{9} +\frac{y^2}{5} = 1$ ；（2）是定值，为 $-\frac{18}{5}$ ，理由详见解析.
>
> **【解析】**
> 是定值，为 $-\frac{18}{5}$ ，理由如下：（1）设 $E$ 、 $O$ 、 $F$ 三点到直线 $l_{1}$ 的距离分别为 $d_{1}$ 、 $d$ 、 $d_{2}$ ， $O$ 为 $EF$ 的中点，∵直线 $l_{1}$ 与圆 $O:x^{2} + y^{2} = 9$ 相切，∴ $d = 3$ ∴ $\left|ME\right| + \left|MF\right| = d_1 + d_2 = 2d = 6 > 4$ ∴动点 $M$ 的轨迹是以 $E$ 、 $F$ 为焦点，长轴长为6的椭圆∴ $2a = b,a = 3,c = 2,b^{2} = a^{2} - c^{2} = 5$ 所以动点 $M$ 的轨迹 $C:\frac{x^2}{9} +\frac{y^2}{5} = 1.$ （2）①当 $l_{2}$ 斜率为0时， $N(0,0),F(2,0)$ ，不妨取 $A(-3,0),B(3,0)$ ∴ $\overline{NA} = (-3,0),\overline{AF} = (5,0)$ ，则 $\lambda_1 = -\frac{3}{5}$ ∴ $\overline{NB} = (3,0),\overline{BF} = (-1,0)$ ，则 $\lambda_{2} = -3,\therefore \lambda_{1} + \lambda_{2} = -\frac{18}{5}$ .②当 $l_{2}$ 斜率不为0时，设 $l_{2}:ty = x - 2(t\neq 0),A(x_{1},y_{1})$ 、 $B(x_{2},y_{2})$ ，则 $N\left(0, - \frac{2}{t}\right)$ 则 $\overline{NA} = \lambda_1\overline{ABF}\Rightarrow \left(x_1,y_1 + \frac{2}{t}\right) = \lambda_1(2 - x_1, - y_1)\Rightarrow \lambda_1 = -1 - \frac{2}{ty_1}$ 由 $\overline{NB} = \lambda_{2}\overline{BF}$ ，同理可得 $\lambda_{2} = -1 - \frac{2}{ty_{2}}$ 由 $\left\{ \begin{array}{l}x = ty + 2\\ \frac{x^2}{9} +\frac{y^2}{5} = 1 \end{array} \right.$ 得 $(5t^{2} + 9)y^{2} + 20ty - 25 = 0,\right.$ ∴ $y_{1} + y_{2} = -\frac{20t}{5t^{2} + 9},y_{1}y_{2} = -\frac{25}{5t^{2} + 9},$ ∴ $\lambda_1 + \lambda_2 = -2 - \left(\frac{2}{ty_1} +\frac{2}{ty_2}\right) = -2 - \frac{2}{t}\cdot \frac{y_1 + y_2}{y_1y_2} = -2 - \frac{2}{t}\cdot \frac{20t}{25} = -\frac{18}{5},$ 综上， $\lambda_1 + \lambda_2 = -\frac{18}{5}$ 为定值.
