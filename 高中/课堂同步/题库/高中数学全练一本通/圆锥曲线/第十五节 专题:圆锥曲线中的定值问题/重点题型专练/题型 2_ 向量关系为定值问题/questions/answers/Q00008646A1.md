> [!faq]- 全练一本通解析
> **【解析】**
> （1）\(\frac{x^2}{9} + y^2 = 1\)；（2）证明见解析。
> 解析：（1）因为椭圆 \(C: \frac{x^2}{a^2} + \frac{y^2}{b^2} = 1\)（\(a > b > c\)）上的点 \(M\) 到 \(C\) 的两焦点的距离之和为 6，所以 \(2a = 6\)，解得 \(a = 3\)，
> 又 \(C\) 的离心率为 \(\frac{2\sqrt{2}}{3}\)，所以 \(\frac{c}{a} = \frac{2\sqrt{2}}{3}\)，\(c = 2\sqrt{2}\)，
> 又 \(c^2 = a^2 - b^2\)，所以 \(b = 1\)，所以 \(C\) 的标准方程为 \(\frac{x^2}{9} + y^2 = 1\)；
> （2）法一：设 \(M(x\_1, y\_1)\)，当直线 \(MN\) 的斜率不存在时，\(N(x\_1, -y\_1)\)，
> 因为直线 \(OM\)，\(ON\) 的斜率之积为 \(-\frac{1}{9}\)，所以 \(\frac{y\_1}{x\_1} \cdot \frac{-y\_1}{x\_1} = -\frac{1}{9}\)，即 \(x\_1^2 = 9y\_1^2\)，
> 又 \(M\)，\(N\) 在椭圆 \(\frac{x^2}{9} + y^2 = 1\) 上，所以 \(x\_1^2 = \frac{9}{2}\)，\(y\_1^2 = \frac{1}{2}\)。
> 因为 \(\overrightarrow{OP} = \overrightarrow{OM} + \overrightarrow{ON}\)，所以 \(\overrightarrow{MN}^2 + \overrightarrow{OP}^2 = (\overrightarrow{ON} - \overrightarrow{OM})^2 + (\overrightarrow{ON} + \overrightarrow{OM})^2 = \overrightarrow{ON}^2 + \overrightarrow{OM}^2 - 2\overrightarrow{ON} \cdot \overrightarrow{OM} + \overrightarrow{ON}^2 + \overrightarrow{OM}^2 + 2\overrightarrow{ON} \cdot \overrightarrow{OM} = 2\left(\left|\overrightarrow{OM}\right|^2 + \left|\overrightarrow{ON}\right|^2\right) = 4(x\_1^2 + y\_1^2) = 4 \times \left(\frac{9}{2} + \frac{1}{2}\right) = 20\)；
> 当直线 \(MN\) 的斜率存在时，设直线 \(MN\) 的方程为 \(y = kx + m\)（\(m \neq 0\)），
> 联立方程得 \(\begin{cases} y = kx + m, \\ \frac{x^2}{9} + y^2 = 1, \end{cases}\) 消去 \(y\)，得 \((1 + 9k^2)x^2 + 18kxm + 9m^2 - 9 = 0\)，
> \(\Delta = (18km)^2 - 4(1 + 9k^2)(9m^2 - 9) = 36(9k^2 - m^2 + 1) > 0\)，
> 设 \(N(x\_2, y\_2)\)，则 \(x\_1 + x\_2 = \frac{-18km}{1 + 9k^2}\)，\(x\_1x\_2 = \frac{9m^2 - 9}{1 + 9k^2}\)。
> 因为直线 \(OM\)，\(ON\) 的斜率之积为 \(-\frac{1}{9}\)，
> 所以 \(\frac{y\_1}{x\_1} \cdot \frac{y\_2}{x\_2} = \frac{(kx\_1 + m)(kx\_2 + m)}{x\_1x\_2} = k\_2 + \frac{km(x\_1 + x\_2) + m^2}{x\_1x\_2} = -\frac{1}{9}\)，
> 即 \(k^2 + \frac{\frac{-18k^2m^2}{1 + 9k^2} + m^2}{\frac{9m^2 - 9}{1 + 9k^2}} = -\frac{1}{9}\)，得 \(2m^2 - 9k^2 = 1\)，满足 \(\Delta > 0\)。
> 因为 \(\overrightarrow{OP} = \overrightarrow{OM} + \overrightarrow{ON}\)，
> 所以 \(\overrightarrow{MN}^2 + \overrightarrow{OP}^2 = (\overrightarrow{ON} - \overrightarrow{OM})^2 + (\overrightarrow{ON} + \overrightarrow{OM})^2 = \overrightarrow{ON}^2 + \overrightarrow{OM}^2 - 2\overrightarrow{ON} \cdot \overrightarrow{OM} + \overrightarrow{ON}^2 + \overrightarrow{\textbf{\textit{\textit{\textit{\textit{\textit{\textit{\textit{\textit{\textit{\textit{\textit{\textit{\textit{\textit{\textit{\textit{\textit{\textit{\textit{\textit{\textit{\textit{\textit{\textit{\textit{\textit{\textit{\textit{\textit{\textit{\textit{\textit{\textit{\textit {\textit{\textit{\textit{\textit{\textit{\textit{\textit{\textit{\textit{\textit{\textit{\textit{\textit{\textit{\textit{\textit{\textit{\textit{\textit{\textit{\textit{\textit{\textit{\textit{\textit{\textit{\textit{\textit{\textit{\textit{\textit{\textit{\textit{\times}}}}}}}}}}}}}}}}}}\\
> 即 \(k^2 + \frac{-18k^2m^2}{1 + 9k^2} + m^2}{\frac{9m^2 - 9}{1 + 9k^2}} = -\frac{1}{9}\)，得 \(2m^2 - 9k^2 = 1\)，满足 \(\Delta > 0\)。
> 因为 \(\overrightarrow{OP} = \overrightarrow{OM} + \overrightarrow{OR}\)，
> 所以 \(\overrightarrow{MN}^2 + \overrightarrow{OP}^2 = (\overrightarrow{ON} - \overrightarrow{OM})^2 + (\overrightarrow{ON} + \overrightarrow{OM})^2 = 0\)
> \(= \overrightarrow{ON}^2 + \overrightarrow{OM}^2 - 2\overrightarrow{ON} \cdot \overrightarrow{OM} + \overrightarrow{ON}^2 + \overrightarrow{OM}^2 + 2\overrightarrow{ON} \cdot \overrightarrow{OM}\)
> \(= 4+\frac{16}{9}\left[(x\_1+x\_2)^- - 2x\_1x\_2\right]\)
> \(= 4+\frac{16}{9}\left[\left(\frac{-18km}{1+9k^2}\right)^- -\frac{2(9m^2 - 9)}{1+9k^2}\right] = 4+\frac{16}{9}\left[\left(\frac{-18km}{2m^2}\right)^- -\frac{2(9m^2 - 9)}{2m^2}\right]\)
> \(= 4+\frac{16}{9}×9=20\)。综上，\(\overrightarrow{MN}^2 + \overrightarrow{OP}^2\)为定值。
> 法二：设 \(M(x\_1, y\_1)\)，\(N(x\_2, y\_2)\)，因为直线 \(OM\)，\(ON\) 的斜率之积为 \(-\frac{1}{9}\)，
> 所以 \(\frac{y\_1}{x\_1} · \frac{y\_2}{x\_2} = -\frac{1}{9}\)，即 \(x\_1x\_2 = -9y\_1y\_2\)。
> 因为 \(M M(x\_1, y\_1)\)，\(N(x\_2, y\_2)\) 在椭圆 \(C: \frac{x^2}{9} + y^2 = 1\) 上，
> 所以 \(x\_1^2 + 9y\_1^2 = 9\)，\(x\_2^2 + 9y\_2^2 = 9\)，
> 可得 \(x\_1^2 - 9 = -9y\_1^2\)①，
> \(x\_2^2 - 9 = -9y\_2^2\)②，
> 由① × ②得 \((x\_1^2 - 9)(x\_2^2 - 9) = 81y\_1^2y\_2^2\)，所以 \((x\_1^2 - 9)(x\_2^2 - 9) = x\_1^2x\_2^2\)，即
> $x_{1}^{2}+x_{2}^{2}=9$ .
> 由① + ②得 $x_{1}^{2}-9+x_{2}^{2}-9=-9\left(y_{1}^{2}+y_{2}^{2}\right)$ ，得 $y_{1}^{2}+y_{2}^{2}=1$ .
> 因为 $\overrightarrow{OP}=\overrightarrow{OM}+\overrightarrow{ON}$ 所以 $\overrightarrow{MN}^{2}+\overrightarrow{OP}^{2}=\left(\overrightarrow{ON}-\overrightarrow{OM}\right)^{2}+\left(\overrightarrow{ON}+\overrightarrow{OM}\right)^{2}$ $=\overrightarrow{ON}^{2}+\overrightarrow{OM}^{2}-2\overrightarrow{ON}\cdot\overrightarrow{OM}+\overrightarrow{ON}^{2}+\overrightarrow{OM}^{2}+2\overrightarrow{ON}\cdot\overrightarrow{OM}$ $=2\left(\left|\overrightarrow{OM}\right|^{2}+\left|\overrightarrow{ON}\right|^{2}\right)$ $=2\left(x_{1}^{2}+y_{1}^{2}+x_{2}^{2}+y_{2}^{2}\right)$ $=2\times(9+1)=20$ ，因此 $\overrightarrow{MN}^{2}+\overrightarrow{OP}^{2}$ 为定值.
