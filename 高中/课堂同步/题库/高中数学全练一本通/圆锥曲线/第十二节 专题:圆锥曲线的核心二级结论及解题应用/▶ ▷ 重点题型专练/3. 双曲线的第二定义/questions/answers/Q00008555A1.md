> [!faq]- 全练一本通解析
> **【答案】** $|AF| = 8 + 4\sqrt{6}, |BF| = 4\sqrt{6} - 8, |AB| = 16$
>
> **【解析】**
> 双曲线 $\frac{x^2}{4} - \frac{y^2}{8} = 1$ 中， $a = 2, b = 2\sqrt{2}$ ，所以 $c = \sqrt{a^2 + b^2} = 2\sqrt{3}$ ，利用公式 $|AF| = \frac{b^2}{|a - c\cos\theta|} = \frac{8}{|2 - \sqrt{6}|} = 8 + 4\sqrt{6}$ , $|BF| = \frac{b^2}{|a + c\cos\theta|} = \frac{8}{|2 + \sqrt{6}|} = 4\sqrt{6} - 8$ $|AB| = \frac{2ab^2}{|a^2 - c^2\cos^2\theta|}$ ，代入得 $\left|AB\right| = \frac{2ab^2}{\left|a^2 - c^2\cos^2\theta\right|} = \frac{2\times 2\times 8}{\left|4 - 12\times \frac{1}{2}\right|} = 16$ 。
