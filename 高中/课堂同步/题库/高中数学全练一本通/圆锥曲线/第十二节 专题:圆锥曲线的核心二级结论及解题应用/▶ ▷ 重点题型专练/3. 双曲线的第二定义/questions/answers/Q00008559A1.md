> [!faq]- 全练一本通解析
> **【解析】**
> $\frac{9 + 4\sqrt{2}}{7}$ 或 $\frac{9 - 4\sqrt{2}}{7}$ 解析： $|MF| = \frac{b^2}{a - c\cos\alpha}, |NF_1| = \frac{b^2}{a + c\cos\alpha}$ ，因为 $\frac{c}{a} = \frac{\sqrt{2}}{2}, c = \frac{\sqrt{2}}{2}a, b = \frac{\sqrt{2}}{2}a$ 且 $\cos\alpha = \frac{1}{2}$ 所以代入化简得 $\frac{|MF|}{|NF|} = \frac{9 + 4\sqrt{2}}{7}$ 或 $\frac{9 - 4\sqrt{2}}{7}$
