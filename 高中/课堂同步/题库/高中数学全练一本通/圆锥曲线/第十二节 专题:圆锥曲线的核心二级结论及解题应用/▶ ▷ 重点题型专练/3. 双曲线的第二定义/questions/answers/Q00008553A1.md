> [!faq]- 全练一本通解析
> **【答案】** $\frac{x^{2}}{4}-\frac{y^{2}}{5}=1$
>
> **【解析】**
> 由双曲线的第二定义可知 $d=\frac{2}{3}PF_{1}$ 又因为 $PF_{1}=-(ex_{0}+a)=14-a$ $PF_{2}=-(ex_{0}-a)=14+a$ 由已知得 $d+\left|PF_{2}\right|=2\left|PF_{1}\right|$ ，即 $\frac{2}{3}(14-a)+(14+a)=28-2a$
> 得 $a = 2, c = 3, b = \sqrt{5}$ ，所以双曲线方程为 $\frac{x^2}{4} - \frac{y^2}{5} = 1$ 。
