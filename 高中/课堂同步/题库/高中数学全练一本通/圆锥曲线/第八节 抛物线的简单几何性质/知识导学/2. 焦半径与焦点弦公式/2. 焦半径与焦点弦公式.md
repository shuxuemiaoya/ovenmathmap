## 2. 焦半径与焦点弦公式

设抛物线上一点 P 的坐标为 $(x_{0}, y_{0})$ ，焦点弦端点 $A(x_{1}, y_{1})$ ， $B(x_{2}, y_{2})$ ，焦点为 F.

<table><tr><td>标准方程</td><td> $y^{2} = 2px (p >0)$ </td><td> $y^{2} = -2px (p >0)$ </td><td> $x^{2} = 2py (p >0)$ </td><td> $x^{2} = -2py (p >0)$ </td></tr><tr><td>焦半径</td><td> $|PF| = x_{0} + \frac{p}{2}$ </td><td> $|PF| = -x_{0} + \frac{p}{2}$ </td><td> $|PF| = y_{0} + \frac{p}{2}$ </td><td> $|PF| = -y_{0} + \frac{p}{2}$ </td></tr><tr><td>焦点弦</td><td> $|AB| = x_{1} + x_{2} + P$ </td><td> $|AB| = P - x_{1} - x_{2}$ </td><td> $|AB| = y_{1} + y_{2} + P$ </td><td> $|AB| = P - y_{1} - y_{2}$ </td></tr></table>

注意: 在使用焦半径公式时, 先要明确抛物线的标准方程的形式, 不同的标准方程对应于不同的焦半径公式.
