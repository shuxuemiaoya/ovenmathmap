> [!faq]- 全练一本通解析
> **【解析】**
> （1） $\frac{x^2}{8} + \frac{y^2}{2} = 1$ ；（2）存在，点 $G(-4,0)$ 。解析：（1）设点 $P(x,y)$ ，则 $\frac{\sqrt{(x + \sqrt{6})^2 + y^2}}{|x + \frac{4\sqrt{6}}{3}|} = \frac{\sqrt{3}}{2}$ ，化简得 $\frac{x^2}{8} + \frac{y^2}{2} = 1$ 故动点 $P$ 的轨迹 $C$ 的标准方程为 $\frac{x^2}{8} + \frac{y^2}{2} = 1$ （2）设直线 $l$ 的方程为 $x = ty - 4$
> 联立方程组 $\left\{ \begin{array}{l} x = ty - 4 \\ \frac{x^2}{8} + \frac{y^2}{2} = 1 \end{array} \right.$ ，得 $(t^2 + 4)y^2 - 8ty + 8 = 0$ ， $\Delta = 64t^2 - 32(t^2 + 4) = 32t^2 - 128 = 32(t^2 - 4) > 0$ ，得： $t > 2$ 或 $t < -2$ $y_1 + y_2 = \frac{8t}{t^2 + 4}, y_1y_2 = \frac{8}{t^2 + 4}$ .
> 设 $E(x_3,0), F(x_4,0)$ ，定点 $G$ 存在，其坐标为 $(x_0,0)$ $\because B(-2,-1), \therefore k_{BM} = \frac{y_1 + 1}{ty_1 - 2}, k_{BN} = \frac{y_2 + 1}{ty_2 - 2}$ 则 $BM: y = \frac{y_1 + 1}{ty_1 - 2}(x + 2) - 1, BN: y = \frac{y_2 + 1}{ty_2 - 1}(x + 2) - 1$ 令 $y = 0$ ，求出与 $x$ 轴的交点 $E, F$ $\frac{y_1 + 1}{ty_1 - 2}(x_3 + 2) - 1 = 0, x_3 + 2 = \frac{ty_1 - 2}{y_1 + 1}, \frac{y_2 + 1}{ty_2 - 2}(x_4 + 2) - 1 = 0, x_4 + 2 = \frac{ty_2 - 2}{y_2 + 1}$ $\overrightarrow{BE} = (x_3 + 2, 1), \overrightarrow{BF} = (x_4 + 2, 1), \overrightarrow{GF} = (x_4 - x_0, 0), \overrightarrow{GE} = (x_3 - x_0, 0)$ $\overrightarrow{BE} \cdot \overrightarrow{GF} + \overrightarrow{GE} \cdot \overrightarrow{BF} = 0$ 即有： $(x_3 + 2)(x_4 - x_0) + (x_4 + 2)(x_3 - x_0) = 0,$ 即 $2x_3x_4 + 2(x_3 + x_4) - (x_3 + x_4 + 4)x_0 = 0$ $x_0 = \frac{2x_3x_4 + 2(x_3 + x_4)}{x_3 + x_4 + 4}$ $\therefore x_0 = \frac{2x_3x_4 + 2(x_3 + x_4 + 4) - 8}{x_3 + x_4 + 4} = \frac{2x_3x_4 - 8}{x_3 + x_4 + 4} + 2$ $= \frac{2(x_3x_4 + 2x_3 + 2x_4 + 4) - 4x_3 - 4x_4 - 16}{x_3 + x_4 + 4} + 2$ $= \frac{2(x_3 + 2)(x_4 + 2) - 4(x_3 + x_4 + 4)}{x_3 + x_4 + 4} + 2$ $= \frac{2(x_3 + 2)(x_4 + 2)}{(x_3 + 2) + (x_4 + 2)} - 2$ $= \frac{2 \cdot \frac{ty_1 - 2}{y_1 + 1} \cdot \frac{ty_2 - 2}{y_2 + 1}}{\frac{ty_1 - 2}{y_1 + 1} + \frac{ty_2 - 2}{y_2 + 1}} - 2 = \frac{2(ty_1 - 2)(ty_2 - 2)}{(ty_1 - 2)(y_2 + 1) + (ty_2 - 2)(y_1 + 1)} - 2$ $= \frac{2[t^2y_1y_2 - 2t(y_1 + y_2) + 4]}{2ty_1y_2 + (t - 2)(y_1 + y_2) - 4} - 2$ $= \frac{2t^2 \cdot \frac{8}{t^2 + 4} - 4t \cdot \frac{8t}{t^2 + 4} + 8}{2t \cdot \frac{8}{t^2 + 4} + \frac{8t(t - 2)}{t^2 + 4} - 4} - 2 = \frac{-16t^2}{t^2 + 4} + 8$ $= \frac{-16t^2 + 8(t^2 + 4)}{8t^2 - 4(t^2 + 4)} - 2 = \frac{-8t^2 + 32}{4t^2 - 16} - 2 = -4$
> $$
> x _ {0} = - 4
> $$
> 当直线 l 与 x 轴重合
> 时， $\overrightarrow{BE}\cdot\overrightarrow{GF}+\overrightarrow{GE}\cdot\overrightarrow{BF}=(-2\sqrt{2}+2)(2\sqrt{2}-x_{0})+(-2\sqrt{2}-x_{0})(2\sqrt{2}+2)=0,$ 解得 $x_{0}=-4.$ 所以存在定点 G, G 的坐标为 $(-4,0)$ .
