> [!faq]- 全练一本通解析
> **【答案】** $x^2 + y^2 - x = 0(x \neq 0)$
>
> **【解析】**
> 联立 $l: x = my + 1$ 与 $C: x^2 + y^2 = 4$ 得： $(m^2 + 1)y^2 + 2my - 3 = 0$ ，设 $A(x_1, y_1), B(x_2, y_2), M(x_0, y_0)$ ，则 $y_1 + y_2 = -\frac{2m}{m^2 + 1}, y_1y_2 = -\frac{3}{m^2 + 1}, x_1 + x_2 = m(y_1 + y_2) + 2 = -\frac{2m^2}{m^2 + 1} + 2 = \frac{2}{m^2 + 1}$ ，故 $y_0 = \frac{y_1 + y_2}{2} = -\frac{m}{m^2 + 1}, x_0 = \frac{x_1 + x_2}{2} = \frac{1}{m^2 + 1}$ ，所以点 $M$ 的坐标为 $\left(\frac{1}{m^2 + 1}, -\frac{m}{m^2 + 1}\right)$ ，令 $x = \frac{1}{m^2 + 1} \neq 0, y = -\frac{m}{m^2 + 1}$ ，两式相除可得： $m = -\frac{y}{x}$ ，代入 $x = \frac{1}{m^2 + 1}$ 中，消去 $m$ 可得， $x^2 + y^2 - x = 0$ ，由于 $x \neq 0$ ，故 $y \neq 0$ ，即去除原点，则点 $M$ 的轨迹方程为： $x^2 + y^2 - x = 0(x \neq 0)$ 。
