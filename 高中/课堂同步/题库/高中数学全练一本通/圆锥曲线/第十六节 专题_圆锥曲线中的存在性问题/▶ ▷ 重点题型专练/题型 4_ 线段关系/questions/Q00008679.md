【13】已知椭圆 $C: \frac{x^{2}}{a^{2}} + \frac{y^{2}}{b^{2}} = 1 (a > b > 0)$ 的左、右焦点分别为 $F_{1}, F_{2}$ ，离心率为 $\frac{1}{2}$ ，P 为椭圆 C 上的一个动点。当 P 是 C 的上顶点时， $\triangle F_{1}PF_{2}$ 的面积为 $\sqrt{3}$ 。（1）求椭圆 C 的标准方程；

(2)设斜率存在的直线 $PF_{2}$ 与 C 的另一个交点为 Q，是否存在点 $T(t,0)$ ，使得 $\left|TP\right|=\left|TQ\right|$ ？若存在，求出 t 的取值范围；若不存在，请说明理由.
