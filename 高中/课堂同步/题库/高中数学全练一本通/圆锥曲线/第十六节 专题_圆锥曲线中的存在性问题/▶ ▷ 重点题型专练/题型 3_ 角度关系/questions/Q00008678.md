【12】已知双曲线 $C:\frac{x^{2}}{a^{2}}-\frac{y^{2}}{b^{2}}=1(a>0,b>0)$ 的离心率为 2，点 A 为 C 上位于第二象限的动点，

(1) 若点 A 的坐标为 $A(-2,3)$ ，求双曲线 C 的方程；

（2）设 B, F 分别为双曲线 C 的右顶点、左焦点，是否存在常数 $\lambda$ ，使得 $\angle AFB = \lambda \angle ABF$ 。如果存在，请求出 $\lambda$ 的值；如果不存在，请说明理由。
