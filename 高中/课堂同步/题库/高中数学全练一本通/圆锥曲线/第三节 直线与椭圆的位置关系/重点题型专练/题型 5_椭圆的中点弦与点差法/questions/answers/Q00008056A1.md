> [!faq]- 全练一本通解析
> **【答案】** 详见解析
>
> **【解析】**
> （1）设 $A(x_1, y_1), B(x_2, y_2)$ ，则 $M\left(\frac{x_1 + x_2}{2}, \frac{y_1 + y_2}{2}\right)$ ，即 $k_{OM} = \frac{y_1 + y_2}{x_1 + x_2} = -\frac{1}{2}$ . 因为 $A, B$ 在椭圆 $C$ 上，所以 $\frac{x_1^2}{a^2} + \frac{y_1^2}{b^2} = 1, \frac{x_2^2}{a^2} + \frac{y_2^2}{b^2} = 1$ ，两式相减得 $\frac{(x_1 + x_2)(x_1 - x_2)}{a^2} + \frac{(y_1 + y_2)(y_1 - y_2)}{b^2} = 0$ ，即 $\frac{1}{a^2} + \frac{(y_1 + y_2)(y_1 - y_2)}{b^2(x_1 + x_2)(x_1 - x_2)} = 0$ 又 $k_{AB} = \frac{y_1 - y_2}{x_1 - x_2} = 1$ ，所以 $\frac{1}{a^2} - \frac{1}{2b^2} = 0$ ，即 $a^2 = 2b^2$ . 又因为椭圆 $C$ 过点 $\left(1, \frac{\sqrt{6}}{2}\right)$ ，所以 $\frac{1}{a^2} + \frac{3}{2b^2} = 1$ ，解得 $a^2 = 4, b^2 = 2$ ，所以椭圆 $C$ 的标准方程为 $\frac{x^2}{4} + \frac{y^2}{2} = 1$ ；（2）设 $P(x_3, y_3), Q(x_4, y_4), PQ$ 的中点为 $N(x_0, y_0)$ ，所以 $x_3 + x_4 = 2x_0, y_3 + y_4 = 2y_0$ ，因为 $P, Q$ 关于直线 $l$ 对称，所以 $k_{PQ} = -1$ 且点 $N$ 在直线 $l$ 上，即 $y_0 = x_0 + m$ 又因为 $P, Q$ 在椭圆 $C$ 上，所以 $\frac{x_3^2}{4} + \frac{y_3^2}{2} = 1, \frac{x_4^2}{4} + \frac{y_4^2}{2} = 1$ 。两式相减得 $\frac{(x_3 + x_4)(x_3 - x_4)}{4} + \frac{(y_3 + y_4)(y_3 - y_4)}{2} = 0$ 即 $\frac{x_3 + x_4}{4} + \frac{(y_3 + y_4)(y_3 - y_4)}{2(x_3 - x_4)} = 0$ ，所以 $\frac{x_3 + x_4}{4} = \frac{y_3 + y_4}{2}$ ，即 $x_0 = 2y_0$ 。联立 $\left\{ \begin{array}{l} x_0 = 2y_0 \\ y_0 = x_0 + m \end{array} \right.$ ，解得 $\left\{ \begin{array}{l} x_0 = -2m \\ y_0 = -m \end{array} \right.$ ，即 $N(-2m, -m)$ 。又因为点 $N$ 在椭圆 $C$ 内，所以 $\frac{(-2m)^2}{4} + \frac{(-m)^2}{2} < 1$ ，所以 $-\frac{\sqrt{6}}{3} < m < \frac{\sqrt{6}}{3}$ 所以实数 $m$ 的范围为 $-\frac{\sqrt{6}}{3} < m < \frac{\sqrt{6}}{3}$ 。
