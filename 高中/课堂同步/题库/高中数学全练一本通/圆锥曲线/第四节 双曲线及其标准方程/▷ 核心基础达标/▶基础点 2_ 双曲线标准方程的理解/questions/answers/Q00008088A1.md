> [!faq]- 全练一本通解析
> **【答案】** C
>
> **【解析】**
> 解析: $ax^{2} + by^{2} = 1$ 可整理成 $\left(\frac{1}{a}\right) + \left(\frac{1}{b}\right) = 1$ ,
> 当 ab < 0, 则 a > 0 且 b < 0 或 a < 0 且 b > 0, 此时方程 $\frac{x^{2}}{\left(\frac{1}{a}\right)} + \frac{y^{2}}{\left(\frac{1}{b}\right)} = 1$ 即 $ax^{2} + by^{2} = 1$ 表示的曲线为双曲线, 则充分性成立;
> 若方程 $\frac{x^{2}}{\left(\frac{1}{a}\right)} + \frac{y^{2}}{\left(\frac{1}{b}\right)} = 1$ 表示的曲线为双曲线, 则 $\frac{1}{a} \cdot \frac{1}{b} < 0$ 即 ab < 0, 则必要性成立,
>
> 故选 **C**
