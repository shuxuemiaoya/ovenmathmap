> [!faq]- 全练一本通解析
> **【解析】**
> （1） $y^{2}=4x$ （2）过定点， $\left(\frac{9}{4},1\right)$
> 解析：（1）由已知 $F\left(\frac{P}{2},0\right)$ ，直线 $AB$ 的方程为 $y = x - \frac{p}{2}$ 联立直线与抛物线 $\left\{ \begin{array}{l}y^{2} = 2px\\ y = x - \frac{p}{2} \end{array} \right.$ ，消 $y$ 可得， $x^{2} - 3px + \frac{p^{2}}{4} = 0$ ，所以 $x_{A} + x_{B} = 3p$ ，因为 $|AB| = x_A + x_B + p = 4p = 8$ ，所以 $2p = 4$ 即抛物线的方程为 $y^{2} = 4x$ （2）将 $P(x_0, - 1)$ 代入 $y^{2} = 4x$ 可得 $P\left(\frac{1}{4}, - 1\right)$ 不妨设直线MN的方程为 $x = my + t(m\neq 0),M(x_1,y_1),N(x_2,y_2)$ 联立 $\left\{ \begin{array}{l}y^2 = 4x\\ x = my + t \end{array} \right.$ ，消 $x$ 得 $y^{2} - 4my - 4t = 0$ 则有 $y_{1} + y_{2} = 4m,y_{1}y_{2} = -4t,\Delta = 16m^{2} + 16t$ 由题意 $k_{PM}\cdot k_{PN} = \frac{y_1 + 1}{x_1 - \frac{1}{4}}\times \frac{y_2 + 1}{x_2 - \frac{1}{4}} = \frac{4}{y_1 - 1}\times \frac{4}{y_2 - 1} = \frac{16}{y_1y_2 - (y_1 + y_2) + 1} = -2,$ 化简可得， $t = \frac{9}{4} -m$ 代入 $\Delta = 16m^2 +16t = 16\left(m^2 +\frac{9}{4} -m\right) = 16\left(m - \frac{1}{2}\right)^2 +32 > 0$ 此时直线MN的方程为 $x = m(y - 1) + \frac{9}{4}$ ，所以直线MN过定点 $\left(\frac{9}{4},1\right)$
