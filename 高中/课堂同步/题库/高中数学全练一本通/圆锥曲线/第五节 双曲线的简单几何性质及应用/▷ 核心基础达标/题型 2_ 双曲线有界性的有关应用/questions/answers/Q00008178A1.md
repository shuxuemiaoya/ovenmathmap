> [!faq]- 全练一本通解析
> **【解析】**
> 8
> 解析: $a = 2, b = \sqrt{21}, c = 5, \left|PF_2\right| \geq c - a = 3, \left|PF_1\right| = \left|PF_2\right| + 2a = \left|PF_2\right| + 4, \left|PF_1\right| + \frac{3}{\left|PF_2\right|} = \left|PF_2\right| + \frac{3}{\left|PF_2\right|} + 4, \left|PF_2\right| \geq 3$ , 而函数 $y = x + \frac{3}{x} + 4, (x > 0)$ 在 $[3, +\infty)$ 上单调递增, 所以当且仅当 $x = 3$ 时, $y_{\min} = 8$ . 故答案为: 8.
