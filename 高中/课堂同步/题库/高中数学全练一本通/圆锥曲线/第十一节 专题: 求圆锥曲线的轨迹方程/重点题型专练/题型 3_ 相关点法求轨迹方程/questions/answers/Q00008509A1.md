> [!faq]- 全练一本通解析
> **【解析】**
> $y = -\frac{x}{2} (-\sqrt{2} < x < \sqrt{2})$ 解析：设斜率为 $\frac{1}{2}$ 的直线方程为 $y = \frac{1}{2} x + b$ ，与椭圆的交点为 $A(x_{1}, y_{1}), B(x_{2}, y_{2})$ ，设中点坐标为 $(x, y)$ ，则 $\frac{y_{2} - y_{1}}{x_{1} - x_{2}} = -\frac{1}{2}, \frac{x_{1} + x_{2}}{2} = x, \frac{y_{2} + y_{1}}{2} = y$ ，所以 $\left\{\begin{array}{l}\frac{x_{1}^{2}}{4} + y_{1}^{2} = 1 \\ \frac{x_{2}^{2}}{4} + y_{2}^{2} = 1\end{array}\right.$ ，两式相减可得 $\frac{(x_{1} - x_{2})(x + x_{2})}{4} = (y_{2} - y_{1})(y_{2} + y_{1})$ ， $\frac{(x + x_{2})}{4} = \frac{y_{2} - y_{1}}{x_{1} - x_{2}} (y_{2} + y_{1})$ ，即 $y = -\frac{x}{2}$ ，由于在椭圆内部，由 $\left\{\begin{array}{l}\frac{x^{2}}{4} + y^{2} = 1 \\ y = \frac{1}{2} x + b\end{array}\right.$ 得 $\frac{x^{2}}{2} + bx + b^{2} - 1 = 0$ ，所以 $\Delta = b^{2} - 2(b^{2} - 1) = 0$ 时，即 $b = \pm \sqrt{2}$ 直线与椭圆相切，此时由 $\frac{x^{2}}{2} \pm \sqrt{2} x + 1 = 0$ 解得 $x = \sqrt{2}$ 或 $x = -\sqrt{2}$ ，所以 $-\sqrt{2} < x < \sqrt{2}$ ，所求得轨迹方程为 $y = -\frac{x}{2} (-\sqrt{2} < x < \sqrt{2})$ 。故答案为： $y = -\frac{x}{2} (-\sqrt{2} < x < \sqrt{2})$ 。
