> [!faq]- 全练一本通解析
> **【答案】** $x + 4y = 0(-\frac{4}{3}\leq x\leq \frac{4}{3})$
>
> **【解析】**
> 设弦的两个端点分别为 $P(x_{1},y_{1}),Q(x_{2},y_{2})$ ， $PQ$ 的中点为 $M(x,y)$ 则 $\frac{x_1^2}{2} +y_1^2 = 1①,\frac{x_2^2}{2} +y_2^2 = 1②$ ①-②得： $\frac{x_1^2 - x_2^2}{2} +\left(y_1^2 -y_2^2\right) = 0,$ ∴ $\frac{x_1 + x_2}{2} +\frac{y_1 - y_2}{x_1 - x_2}\left(y_1 + y_2\right) = 0.$ 又 $x_{1} + x_{2} = 2x,y_{1} + y_{2} = 2y,\frac{y_{1} - y_{2}}{x_{1} - x_{2}} = 2,\therefore x + 4y = 0.$ 由于弦中点轨迹在已知椭圆内，联立 $\left\{ \begin{array}{l}\frac{x^2}{2} +y^2 = 1\\ x + 4y = 0 \end{array} \right.\therefore x = \pm \frac{4}{3}$ 故斜率为2的平行弦中点的轨迹方程： $x + 4y = 0(-\frac{4}{3}\leq x\leq \frac{4}{3})$
