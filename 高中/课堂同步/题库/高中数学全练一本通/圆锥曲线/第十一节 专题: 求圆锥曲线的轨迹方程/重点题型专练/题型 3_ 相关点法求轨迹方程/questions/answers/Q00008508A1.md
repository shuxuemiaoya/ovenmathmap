> [!faq]- 全练一本通解析
> **【解析】**
> $3x^{2} + 4y^{2} - 3x - 4y = 0$ 解析：设 $A(x_{1},y_{1}),B(x_{2},y_{2})$ ，弦 $AB$ 的中点 $F(x,y)$ ，则 $\left\{ \begin{array}{l}x_{1} + x_{2} = 2x\\ y_{1} + y_{2} = 2y \end{array} \right.$ 将 $A,B$ 代入椭圆方程得 $\left\{ \begin{array}{l}\frac{x_1^2}{4} +\frac{y_1^2}{3} = 1\\ \frac{x_2^2}{4} +\frac{y_2^2}{3} = 1 \end{array} \right.$ 两式相减得 $\frac{(x_1 + x_2)(x_1 - x_2)}{4} +\frac{(y_1 + y_2)(y_1 - y_2)}{3} = 0,$ 所以 $\frac{x(x_1 - x_2)}{2} +\frac{2y(y_1 - y_2)}{3} = 0,$ 当 $x_{1}\neq x_{2}$ 时， $\frac{x}{2}-\frac{2y(y_1-y_2)}{3(x_1-x_2)} = 0\Rightarrow \frac{x}{2}-\frac{2y}{3}\times\frac{y_{1}-y_{2}}{x_{1}-x_{2}} = 0,$ 因为 $k_{EF} = k_{AB}$ ，所以 $\frac{y_1 - y_2}{x_1 - x_2} = \frac{y - 1}{x - 1}$ ，则 $\frac{x}{2}-\frac{2y}{3}\times\frac{y - 1}{x - 1} = 0,$
> 整理得 $3x^{2} + 4y^{2} - 3x - 4y = 0(x \neq 1)$ ；当 $x_{1} = x_{2}$ 时，则直线 $AB$ 方程为 $x = 1$ ，代入椭圆方程解得 $A\left(1, \frac{3}{2}\right), B\left(1, -\frac{3}{2}\right)$ 所以 $F(1,0)$ 满足上述方程，故点 $F$ 的轨迹方程 $3x^{2} + 4y^{2} - 3x - 4y = 0$ 。
