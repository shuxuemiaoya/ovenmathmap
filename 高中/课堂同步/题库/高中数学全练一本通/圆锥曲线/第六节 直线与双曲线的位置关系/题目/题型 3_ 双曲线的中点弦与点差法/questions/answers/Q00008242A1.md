> [!faq]- 全练一本通解析
> **【答案】** （1） $\frac{x^2}{4} -\frac{y^2}{16} = 1$ （2） $\frac{4\sqrt{42}}{3}$
>
> **【解析】**
> （1）由焦点可知 $c = 2\sqrt{5}$ 又一条渐近线方程为 $2x - y = 0$ ，所以 $\frac{b}{a} = 2$ 由 $c^2 = a^2 +b^2$ 可得 $20 = a^2 +4a^2$ ，解得 $a^2 = 4,b^2 = 16$ 故双曲线 $C$ 的标准方程为 $\frac{x^2}{4} -\frac{y^2}{16} = 1.$ （2）设 $A(x_{1},y_{1}),B(x_{2},y_{2}),AB$ 中点的坐标为 $(x_0,4)$ 则 $\left\{\frac{x_1^2}{4} -\frac{y_1^2}{16} = 1\right.$ $\frac{x_2^2}{4} -\frac{y_2^2}{16} = 1$ 两式子相减得： $16(x_{2}^{2} - x_{1}^{2}) = 4(y_{2}^{2} - y_{1}^{2})$ 化简得 $16(x_{2} - x_{1})(x_{2} + x_{1}) = 4(y_{2} - y_{1})(y_{2} + y_{1})$ 即 $k = \frac{y_2 - y_1}{x_2 - x_1} = \frac{4(x_2 + x_1)}{y_2 + y_1} = \frac{4x_0}{4} = x_0$ ，又 $k = \tan \frac{3\pi}{4} = -1$ ，所以 $x_0 = -1$ 所以 $AB$ 中点的坐标为 $(-1,4)$ 所以直线 $l$ 的方程为 $y - 4 = -(x + 1)$ ，即 $x + y - 3 = 0$ 将 $x + y - 3 = 0$ 代入 $\frac{x^2}{4} -\frac{y^2}{16} = 1$ 得， $3x^{2} + 6x - 25 = 0$ 则 $x_{1} + x_{2} = -2,x_{1}x_{2} = -\frac{25}{3},$ $|AB| = \sqrt{2}|x_{1} - x_{2}| = \sqrt{2}\sqrt{(x_{1} + x_{2})^{2} - 4x_{1}x_{2}} = \sqrt{2}\sqrt{4 + 4\times\frac{25}{3}} = \frac{4\sqrt{42}}{3},$
