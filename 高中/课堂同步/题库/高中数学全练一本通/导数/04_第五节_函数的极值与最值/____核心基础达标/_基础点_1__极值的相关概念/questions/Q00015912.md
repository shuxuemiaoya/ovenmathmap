【1】判断正误, 正确的写“正确”, 错误的写“错误”.

（1）函数的极大值一定大于其极小值。（）

(2) 导数为 0 的点一定是极值点. ( )

(3)函数 $y = f(x)$ 一定有极大值和极小值.()

（4）函数的极值点是自变量的值, 极值是函数值.
()

(5) 函数的最大值不一定是函数的极大值. ( )

(6)函数 $f(x)$ 在区间 $[a,b]$ 上的最大值与最小值一定在区间端点处取得.（）

(7)函数 $f(x)$ 在区间 $[a,b]$ 上连续,则 $f(x)$ 在区间 $[a,b]$ 上一定有最值,但不一定有极值.()

（8）“ $f(x)$ 在 R 上单调递增”是“ $f'(x)>0$ 在 R 上恒成立”的必要不充分条件（）

（9）函数 $f(x)$ 在给定的区间 $[a,b]$ 上必存在最值（ ）

(10) 若 $f(x)$ 在 R 上存在极值, 则它在 R 一定不单调 ( )

（11）有极值的函数一定有最值,有最值的函数不一定有极值.（）
