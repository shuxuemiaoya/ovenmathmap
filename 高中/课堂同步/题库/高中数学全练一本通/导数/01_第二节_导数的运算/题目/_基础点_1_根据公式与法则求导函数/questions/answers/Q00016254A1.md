> [!faq]- 全练一本通解析
>
> > [!success]- **【答案】** （1） $y' = 3x^{2} - 1$ ；（2） $y' = 2^{x}\ln 2 - \sin x$
>
> > [!note]- **【解析】**
> > (3) $y' = \mathrm{e}^{x} + \frac{1}{x} + \cos x$ ; (4) $y' = -\frac{\sin x + \cos x}{\mathrm{e}^x}$ .
> >
> > (5) $y' = \frac{(2 + \ln x)\sqrt{x}}{2x}$ ; (6) $y' = \frac{-2\mathrm{e}^x}{(\mathrm{e}^x - 1)^2}$
> >
> > (7) $y' = \frac{\cos x - \sin x}{e^x} + \ln x + 1$ ; (8) $y' = 2x + \frac{1}{\cos^2 x}$ ;
> >
> > (9) $y' = \frac{xe^x}{(x + 1)^2}$ ; (10) $y' = 9x^2 + \frac{1}{4x^2}$
> >
> > (11) $y' = \frac{1}{x \ln 2} + \frac{1}{\cos^2 x}$ ; (12) $y' = 4x^3 + 5^x \ln 5$
> >
> > (13) $y' = 2x\sin x + x^2\cos x - \frac{2x\sin x + \cos x}{2x\sqrt{x}}$
> >
> > [!note]- **【解析】**
> > （1） $y' = (x^3 - x + 3)' = (x^3)' - (x)' + (3)' = 3x^2 - 1$ .
> >
> > (2) $y' = \left(2^x + \cos x\right)' = \left(2^x\right)' + (\cos x)' = 2^x \ln 2 - \sin x$ .
> >
> > (3) $y' = \mathrm{e}^{x} + \frac{1}{x} + \cos x$ .
> >
> > (4) $y' = \left(\frac{\cos x}{\mathrm{e}^x}\right)' = \frac{(\cos x)'\mathrm{e}^x - \cos x\left(\mathrm{e}^x\right)'}{\left(\mathrm{e}^x\right)^2} = -\frac{\sin x + \cos x}{\mathrm{e}^x}.$
> >
> > (5) $y' = \left(\sqrt{x}\right)' \ln x + \sqrt{x} (\ln x)' = \frac{\ln x}{2\sqrt{x}} + \frac{\sqrt{x}}{x} = \frac{(2 + \ln x)\sqrt{x}}{2x}$ .
> >
> > (6) $y' = \frac{\mathrm{e}^x(\mathrm{e}^x - 1) - (\mathrm{e}^x + 1)\mathrm{e}^x}{(\mathrm{e}^x - 1)^2} = \frac{-2\mathrm{e}^x}{(\mathrm{e}^x - 1)^2}$
> >
> > (7) $y' = \frac{\cos x \cdot e^x - \sin xe^x}{\left(e^x\right)^2} + \ln x + x \cdot \frac{1}{x} = \frac{\cos x - \sin x}{e^x} + \ln x + 1$
> >
> > (8) $y = x^{2} + \frac{\sin x}{\cos x}, y' = 2x + \frac{\cos^{2}x + \sin^{2}x}{\cos^{2}x} = 2x + \frac{1}{\cos^{2}x}.$
> >
> > (9) $y' = \frac{e^x(x + 1) - e^x}{(x + 1)^2} = \frac{xe^x}{(x + 1)^2}$ .
> >
> > (10) $y' = \left(3x^3 - \frac{1}{4} x^{-1}\right)' = 9x^2 + \frac{1}{4} x^{-2} = 9x^2 + \frac{1}{4x^2}$ .
> >
> > (11) $y' = \left(\log_2 x + \frac{\sin x}{\cos x}\right)' = \frac{1}{x \ln 2} + \frac{\cos^2 x + \sin^2 x}{\cos^2 x} = \frac{1}{x \ln 2} + \frac{1}{\cos^2 x}$ .
> >
> > (12) $y' = \left(x^4 + 5^x - e^5\right)' = 4x^3 + 5^x \ln 5 \cdot$
> >
> > (13)
> >
> > $$
> > y ^ {\prime} = 2 x \sin x + x ^ {2} \cos x + \frac {- \sqrt {x} \cdot \sin x - \frac {\cos x}{2 \sqrt {x}}}{x} = 2 x \sin x + x ^ {2} \cos x - \frac {2 x \sin x + \cos x}{2 x \sqrt {x}}
