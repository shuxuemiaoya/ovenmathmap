> [!faq]- 全练一本通解析
>
> > [!success]- **【答案】** (1) $\frac{1}{x}$ (2) $y' = 12x^{11}$ ; (3) $y' = -\frac{4}{x^5}$ ; (4) $y' = 3^x\ln 3$ ; (5) $y' = \frac{1}{x\ln 5}$
>
> > [!note]- **【解析】**
> > (6) $y' = \frac{3}{5} x^{-\frac{2}{5}}$
> >
> > [!note]- **【解析】**
> > （1）根据求导公式可得 $\left(\ln x\right)' = \frac{1}{x}$
> >
> > (2) $y = x^{12}$ ，则 $y' = 12x^{11}$
> >
> > (3) $y = \frac{1}{x^4} = x^{-4}$ ，则 $y' = -4x^{-4-1} = -\frac{4}{x^5}$
> >
> > (4) $y = 3^{x}$ ，则 $y' = 3^{x} \ln 3$
> >
> > (5) $y = \log_5 x$ ，则 $y' = \frac{1}{x \ln 5}$
> >
> > (6) $y = \sqrt[5]{x^3} = x^{\frac{3}{5}}\therefore y' = \frac{3}{5} x^{-\frac{2}{5}}$
