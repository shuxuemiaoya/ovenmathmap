> [!faq]- 全练一本通解析
>
> > [!success]- **【答案】** （1）\(y = -x + 3\)（2）答案见解析（3）证明见解析
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > （1）\(f(0) = 4 - 2 \times 0 - \frac{1}{e^0} = 3\)，
> > \(f'(x) = -2 + \frac{1}{e^x}, \therefore f'(0) = -2 + 1 = -1\)。
> > ∴ 切线方程为：\(y - 3 = -x\)，即 \(y = -x + 3\)。
> > （2）由题意得函数 \(g(x)\) 的定义域为 \((0, +\infty)\)，
> > \(g'(x) = a^2 - a - \frac{1}{x^2} - \frac{1}{x} = \frac{(a^2 - a)x^2 - x - 1}{x^2} = \frac{(ax + 1)[(a - 1)x - 1]}{x^2}\)，
> > - **①**：当 \(0 < a \leq 1\) 时，\(g'(x) < 0, \therefore g(x)\) 在 \((0, +\infty)\) 上单调递减；
> > - **②**：当 \(a > 1\) 时，\(x \in \left(0, \frac{1}{a - 1}\right)\) 时，\(g'(x) < 0, \therefore g(x)\) 在 \(\left(0, \frac{1}{a - 1}\right)\) 上单调递减。
> > \(x \in \left(\frac{1}{a - 1}, +\infty\right)\) 时，\(g'(x) > 0, \therefore g(x)\) 在 \(\left(\frac{1}{a - 1}, +\infty\right)\) 上单调递增。
> > 综上，当 \(0 < a \leq 1\) 时，\(g(x)\) 在 \((0, +\infty)\) 上单调递减。
> > 当 \(a > 1\) 时，\(g(x)\) 在 \(\left(0, \frac{1}{a - 1}\right)\) 上单调递减，在 \(\left(\frac{1}{a - 1}, +\infty\right)\) 上单调递增。
> > （3）当 \(a = 1\) 时，\(h(x) = 4 - 2x - \frac{1}{e^x} - x\left(\frac{1}{x} - \ln x\right) = x\ln x - \frac{1}{e^x} - 2x + 3\)，
> > \$\therefore h'(x) = \ln x + \frac{1}{e^x} - 1\$。
> > 令 \(c(x) = h'(x)\)，则 \(c'(x) = \frac{1}{x} - \frac{1}{e^x} = \frac{e^x - x}{xe^x}\$。
> > 构建函数 \(p(x) = e^x - x, \therefore p'(x) = e^x - 1\)。
> > ∴ 当 \(x > 0\) 时，\(p'(x) = e^x - 1 > 0, \therefore\) 函数 \(p(x)\) 单调递增。
> > ∴ 当 \(x > 0\) 时，\(p(x) = e^x - x > p(0) = 1 > 0, \therefore c'(x) > 0, \therefore\) 函数 \(h'(x)\) 单调增。
> > \$\because h'(1) = \frac{1}{e} - 1\left\langle 0, h'(e) = \frac{1}{e^e} \right\rangle 0, \therefore h'(x)\) 在 \((1, e)\) 内有唯一零点 \(x\_0\)。
> > ∴ 当 \(x \in (0, x\_0), h'(x) < h'(x\_0) = 0, \therefore\) 函数 \(h(x)\) 单调递减。
> > 当 \(x \in (x\_0, +\infty), h'(x) > h'(x\_0) = 0, \therefore\) 函数 \(h(x)\) 单调递增。
> > ∴ 当 \(x = x\_0\) 时，函数 \(h(x)\) 取最小值 \(h(x\_0) = x\_0\ln x\_0 - \frac{1}{e^{x\_0}} - 2x\_0 + 3\)。
> > \$\because h'(x\_0) = \ln x\_0 + \frac{1}{e^{x\_0}} - 1 = 0, \therefore -\frac{1}{e^{x\_0}} = \ln x\_0 - 1.\$。
> > \$\therefore h(x\_0) = (x\_0 + 1)\ln x\_0 - 2x\_0 + 2, x\_0 \in (1, e)\$。
> > 构造函数 \(q(x) = (x + 1)\ln x - 2x + 2, \therefore q'(x) = \frac{1}{x} + \ln x - 1.\$。
> > 令 \(d(x) = q'(x), \therefore d'(x) = \frac{x - 1}{x^2}\).
> > ∴ 当 \(x > 1\) 时，\(d'(x) > 0, \therefore\) 函数 \(q'(x)\) 单调递增.
> > ∴ 当 \(x > 1\) 时，\(q'(x) > q'(1) = 0, \therefore\) 函数 \(q(x)\) 单调递增.
> > \$\therefore h(x\_0) > q(1) = 0, \therefore h(x) \geq h(x\_0) > 0\$。
