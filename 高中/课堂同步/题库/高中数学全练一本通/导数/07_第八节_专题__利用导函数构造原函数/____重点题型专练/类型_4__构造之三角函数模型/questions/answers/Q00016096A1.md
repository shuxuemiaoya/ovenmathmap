> [!faq]- 全练一本通解析
>
> > [!success]- **【答案】** （-1,0）
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > 由 $x \in (0, + \infty)$ 时，函数 $f(x)$ 满足 $2f(x) + xf'(x) > 0$ ，可得 $2xf(x) + x^2 f'(x) > 0$ ，设 $h(x) = x^2 f(x), x > 0$ ，则 $h'(x) = 2xf(x) + x^2 f'(x) > 0$ ，故 $h(x)$ 在 $(0, + \infty)$ 上单调递增，由 $f(x + 1) <   \frac{f(1)}{(x + 1)^2}$ ，即 $(x + 1)^2 f(x + 1) <   f(1)$ ，即 $h(x + 1) <   h(1)$ 所以 $0 <   x + 1 <   1$ ，解得 $-1 <   x <   0$ ，所以 $f(x + 1) <   \frac{f(1)}{(x + 1)^2}$ 的解集为 $(-1,0)$
