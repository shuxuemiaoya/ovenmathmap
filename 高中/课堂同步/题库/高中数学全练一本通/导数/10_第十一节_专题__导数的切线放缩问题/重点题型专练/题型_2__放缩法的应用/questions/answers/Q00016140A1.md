> [!faq]- 全练一本通解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > 方法1:单独放缩 $\ln x$ 证明：当 x > 0 时， $\ln x \leq x - 1$ （放缩）， $\therefore e^{x} - \ln x \geq e^{x} - (x - 1)$ ,
> > 只需证 x > 0 时， $e^{x} - (x - 1) > 2$ ，
> > 即证 x > 0 时， $e^{x} - x - 1 > 0$ ，
> > 令 $t(x) = e^{x} - x - 1, \therefore t'(x) = e^{x} - 1$ , $\therefore x > 0$ 时， $t'(x) > 0, t(x)$ 在 $(0, +\infty)$ 上递增， $\therefore t(x) > t(0) = 0$ ，故得证.
> > 方法2:单独放缩 $e^{x}$ 证明：当 x > 0 时， $e^{x} > x + 1$ （放缩）， $\because e^{x} \geq x + 1 \therefore e^{x} - \ln x > x + 1 - \ln x,$ 故只需证 x > 0 时， $x + 1 - \ln x \geq 2$ 即证 x > 0 时， $x - \ln x - 1 \geq 0$ 令 $t(x) = x - \ln x - 1$ $\therefore t'(x) = 1 - \frac{1}{x} = \frac{x - 1}{x}, x > 0.$ $\therefore t(x)$ 在 $(0,1)$ 递减，在 $(1,+\infty)$ 递增， $\therefore t(x) \geq t(1) = 0$ ，故得证.
> > 方法3:同时放缩 $e^{x}$ 与 $\ln x$ 证明：当 x > 0 时， $e^{x} > x + 1$ ， $\ln x \leq x - 1$ ， $\therefore e^{x} - \ln x \geq e^{x} - (x - 1) > (x + 1) - (x - 1) = 2$
