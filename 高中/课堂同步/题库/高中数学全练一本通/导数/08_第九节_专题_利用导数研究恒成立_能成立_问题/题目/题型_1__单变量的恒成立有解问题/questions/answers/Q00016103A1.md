> [!faq]- 全练一本通解析
>
> > [!success]- **【答案】** （1）极小值为 $-\frac{1}{\mathrm{e}}$ ，无极大值（2）4
>
> > [!note]- **【解析】**
> > （1）由 $f(x) = x\ln x\Rightarrow f'(x) = \ln x + 1$ 令 $f^{\prime}(x) > 0\Rightarrow x > \frac{1}{\mathrm{e}}$ ；令 $f^{\prime}(x) <   0\Rightarrow \frac{1}{\mathrm{e}} >x > 0$ $\therefore f(x)$ 在 $\left(0,\frac{1}{\mathrm{e}}\right)$ 上单调递减，在 $\left(\frac{1}{\mathrm{e}}, + \infty\right)$ 上单调递增， $\therefore f(x)$ 在 $x = \frac{1}{\mathrm{e}}$ 处取得极小值，且为 $f\left(\frac{1}{\mathrm{e}}\right) = -\frac{1}{\mathrm{e}}$ ，无极大值；  
> > （2）由 $f(x)\leq \frac{-x^2 + mx - 3}{2}\Rightarrow m\geq \frac{2x\ln x + x^2 + 3}{x} (x > 0)$ 能成立，  
> > 问题转化为 $m\geq \left(2\ln x + x + \frac{3}{x}\right)_{\min}$ 令 $g(x) = 2\ln x + x + \frac{3}{x}\Rightarrow g'(x) = \frac{2}{x} +1 - \frac{3}{x^2} = \frac{(x + 3)(x - 1)}{x^2},$ 由 $x > 1\Rightarrow g'(x) > 0$ ；由 $0 <   x <   1\Rightarrow g'(x) <   0$ $\therefore g(x)$ 在(0,1)上单调递减，在 $(1, + \infty)$ 上单调递增， $\therefore g(x)_{\min} = g(1) = 4$ ，则 $m\geq 4$ ，故 $m$ 的最小值为4.
