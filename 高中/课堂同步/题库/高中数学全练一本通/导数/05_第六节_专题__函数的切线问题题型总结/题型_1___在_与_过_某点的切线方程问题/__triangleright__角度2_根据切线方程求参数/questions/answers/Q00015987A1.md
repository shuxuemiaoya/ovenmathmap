> [!faq]- 全练一本通解析
>
> > [!success]- **【答案】** 3
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > 由题意可得 $f^{\prime}(x) = e^{x - 1}$ ，设直线 $y = kx - 2k$ 与曲线 $f(x) = e^{x - 1}$ 的切点为 $(x_{1},y_{1})$ 则 $\mathrm{e}^{\mathrm{x}_i - 1} = k$ ，即 $x_{1} = \ln k + 1$ 又切点在曲线上，所以 $y_{1} = e^{x_{1} - 1} = e^{\ln k + 1 - 1} = k$ ，代入直线方程可得 $k = k(\ln k + 1) - 2k$ ，即 $k(2 - \ln k) = 0$ ，解 $k = 0$ 或 $\mathbf{e}^2$ 又 $\mathbf{e}^{\mathbf{x}_i - 1} = k$ ，所以 $k = 0$ 舍去， $g'(x) = \frac{1}{x - 2}$ ，设直线 $y = kx - 2k$ 与曲线 $g(x) = \ln (x - 2) + m$ 的切点为 $(x_{2},y_{2})$ 所以 $k = \frac{1}{x_2 - 2}$ ，由 $k = e^2$ 代入可得 $x_{2} = 2 + \frac{1}{e^2}$ 又 $\left\{ \begin{array}{l} y_2 = \ln (x_2 - 2) + m \\ y_2 = kx_2 - 2k \end{array} \right.$ ，所以 $y_{2} = e^{2}\left(2 + \frac{1}{e^{2}}\right) - 2e^{2} = 1,$ 所以将 $\left(2 + \frac{1}{e^2},1\right)$ 代入曲线 $g(x) = \ln (x - 2) + m$ 可得 $1 = \ln \frac{1}{e^2} +m$ 解得 $m = 3$ .故答案为：3.
