> [!faq]- 全练一本通解析
>
> > [!success]- **【答案】** C
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > C解析：由 $\ln x + \ln y = \frac{1}{y} -x$ 得： $\ln x + x = -\ln y + \frac{1}{y} = \ln \frac{1}{y} +\frac{1}{y},$ 构造函数 $f(x) = \ln x + x$ ，则 $f^{\prime}(x) = \frac{1}{x} +1 > 0,$ 可知 $f(x) = \ln x + x$ 在 $(0, + \infty)$ 上递增，结合 $\ln x + x = \ln \frac{1}{y} +\frac{1}{y}$ ，得 $x = \frac{1}{y}$ ，即 $xy = 1$ 由基本不等式可知： $x + y\geq 2\sqrt{xy} = 2$ 当且仅当 $x = y = 1$ 时等号成立，所以 $x + y > 1$ .
> >
> > 故选 **C**.
