> [!faq]- 全练一本通解析
>
> > [!success]- **【答案】** 0
>
> > [!note]- **【解析】**
> > 令 $f(x) = \mathrm{e}^{x} + x$ ，则 $f(x)$ 在 $(0, +\infty)$ 上单调递增， $\mathrm{e}^{x} + x = ax + \ln ax$ ，即 $\mathrm{e}^{x} + x = \mathrm{e}^{\ln ax} + \ln ax$ ，故 $f(x) = f(\ln ax)$ ， $\because$ 正实数 $x_0$ 是方程 $\mathrm{e}^{x} + x = ax + \ln ax$ 的根， $\therefore f(x_0) = f(\ln ax_0)$ ，则 $x_0 = \ln ax_0$ ，得 $\mathrm{e}^{x_0} = ax_0$ ，即 $\mathrm{e}^{x_0} - ax_0 = 0$ 。故答案为：0
