> > [!note]- **【解析】**
> > 构造函数 $f(x) = x + e^{x}$ ， $g(x) = x + 3^{x}$ 所以 $f(m) = m + e^{m} = e$ ， $g(n) = n + 3^n = e$ 因为 $y = x,y = e^{x},y = 3^{x}$ 均为R上增函数，则函数 $f(x),g(x)$ 为增函数.函数 $f(x),g(x)$ 与函数 $y = e$ 的图象，如下图所示：
> >
> > ![](images/answers/964d9d6643fb6046e7111aaa2556d5cfad6619e25284c4e26dd9cb8d72fa8009.jpg)
> >
> > 由图可知，0 < n < m。
> >
> > $$
> > f (1) = 1 + \mathrm{e} > f (m), g (1) = 1 + 3 > g (n)
> > $$
> >
> > 所以 $m < 1, n < 1$ 。综上， $0 < n < m < 1$ 。故选：C所以 m<1, n<1. 综上，0<n<m<1. 故选：C
