> [!faq]- 全练一本通解析
> **【答案】** A
>
> **【解析】**
> 解析: 设 $\overrightarrow{MG} = \lambda \overrightarrow{MN}$ ，则
> $\overrightarrow{AG} = \overrightarrow{AM} + \overrightarrow{MG} = \overrightarrow{AM} + \lambda \overrightarrow{MN} = \overrightarrow{AM} + \lambda (\overrightarrow{AN} - \overrightarrow{AM})$ $= (1 - \lambda)\overrightarrow{AM} + \lambda \overrightarrow{AN} = x(1 - \lambda)\overrightarrow{AB} + y\lambda \overrightarrow{AC}$ 又因为 $G$ 是 $\triangle ABC$ 的重心，故 $\overrightarrow{AG} = \frac{1}{3}\overrightarrow{AB} +\frac{1}{3}\overrightarrow{AC}$ 所以有 $\left\{ \begin{array}{l}x(1 - \lambda) = \frac{1}{3}\\ y\lambda = \frac{1}{3} \end{array} \right.\Rightarrow \frac{1}{x} +\frac{1}{y} = 3(1 - \lambda) + 3\lambda = 3.$
>
> 故选 **A**.
