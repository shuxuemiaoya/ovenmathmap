> [!faq]- 全练一本通解析
> **【答案】** C
>
> **【解析】**
> 解析:对于 A 项:零向量的方向是任意的并不是没有方向,故 A 项错误;对于 B 项:因为向量的模相等,但向量不一定相等,故 B 项错误;
> 对于 C 项: 因为 $\vec{a}=\vec{b}$ ， $\vec{b}=\vec{c}$ ，所以可得： $\vec{a}=\vec{c}$ ，故 C 项正确；
> 对于 D 项: 若 $\vec{b} = \vec{0}$ ，则不共线的 $\vec{a}, \vec{c}$ 也有 $\vec{a} // \vec{0}, \vec{0} // \vec{c}$ ，故 D 项错误.
>
> 故选 **C**.
