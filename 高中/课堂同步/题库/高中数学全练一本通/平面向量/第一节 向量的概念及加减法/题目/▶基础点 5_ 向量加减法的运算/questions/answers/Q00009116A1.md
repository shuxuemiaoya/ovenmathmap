> [!faq]- 全练一本通解析
> **【答案】** （1） $\overrightarrow{BC}+\overrightarrow{CE}+\overrightarrow{EA}=\overrightarrow{BA}$ ; （2） $\overrightarrow{OE}+\overrightarrow{AB}+\overrightarrow{EA}=\overrightarrow{OB}$ ; （3） $\overrightarrow{AB}+\overrightarrow{FE}+\overrightarrow{DC}=\overrightarrow{AC}$
>
> **【解析】**
> （1） $\overrightarrow{BC}+\overrightarrow{CE}+\overrightarrow{EA}=\overrightarrow{BE}+\overrightarrow{EA}=\overrightarrow{BA}$ （2） $\overrightarrow{OE}+\overrightarrow{AB}+\overrightarrow{EA}=(\overrightarrow{OE}+\overrightarrow{EA})+\overrightarrow{AB}=\overrightarrow{OA}+\overrightarrow{AB}=\overrightarrow{OB}$ （3）易知 FE 为三角形 ABC 的一条中位线， $\therefore FE // BC, FE = \frac{1}{2} BC$ 又∵点 D 是 BC 的中点， $\therefore BD=\frac{1}{2}BC$ $\therefore \overline{FE}=\overline{BD}$ $\therefore \overrightarrow{AB} + \overrightarrow{FE} + \overrightarrow{DC} = \overrightarrow{AB} + \overrightarrow{BD} + \overrightarrow{DC} = \overrightarrow{AD} + \overrightarrow{DC} = \overrightarrow{AC}$
