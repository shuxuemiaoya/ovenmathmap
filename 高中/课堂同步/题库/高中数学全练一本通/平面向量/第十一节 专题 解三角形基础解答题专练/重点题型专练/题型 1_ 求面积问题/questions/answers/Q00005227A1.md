> [!faq]- 全练一本通解析
> **【解析】**
> （1） $C=\frac{\pi}{2}$ 或 $\frac{\pi}{3}$ 或 $\frac{2\pi}{3}$ ; （2） $S_{\triangle ABC}=\sqrt{3}$ 或 $3\sqrt{3}$
$$
A + B + C = \pi
$$
$$
\sin 2 C + \sqrt {3} \cos (A + B) = 0
$$
$\sin 2C + \sqrt{3}\cos(A + B) = \sin 2C + \sqrt{3}\cos(\pi - C) = 2\sin C\cos C - \sqrt{3}\cos C = 0$ 即 $2\sin C\cos C=\sqrt{3}\cos C$ 所以 $\cos C=0$ 或 $\sin C=\frac{\sqrt{3}}{2}$ ,
解得 $C=\frac{\pi}{2}$ 或 $\frac{\pi}{3}$ 或 $\frac{2\pi}{3}$ .
（2）因为 $a = 4$ ， $c = \sqrt{13}$ ，所以 $C = \frac{\pi}{3}$ 根据余弦定理得 $\cos C = \frac{a^2 + b^2 - c^2}{2ab}$ 所以 $\frac{1}{2} = \frac{16 + b^2 - 13}{8b}$ ，即 $b^{2} - 4b + 3 = 0$ 解得 $b = 1$ 或 $b = 3$ 当 $b = 1$ 时， $S_{\triangle ABC} = \frac{1}{2} ab\sin C = \frac{1}{2}\times 4\times 1\times \frac{\sqrt{3}}{2} = \sqrt{3}$ 当 $b = 3$ 时， $S_{\triangle ABC} = \frac{1}{2} ab\sin C = \frac{1}{2}\times 4\times 3\times \frac{\sqrt{3}}{2} = 3\sqrt{3}$ 所以 $\triangle ABC$ 的面积的面积为 $\sqrt{3}$ 或 $3\sqrt{3}$
