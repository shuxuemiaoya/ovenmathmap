> [!faq]- 全练一本通解析
> **【答案】** （1） $A=\frac{\pi}{3}$ $$ (\sqrt {3}, 2 \sqrt {3}) $$
>
> **【解析】**
> （1）由 $\frac{2\cos A}{bc} = \frac{\cos B}{ab} +\frac{\cos C}{ac}$ 得： $2a\cos A = c\cos B + b\cos C$ 由正弦定理 $\frac{a}{\sin A} = \frac{b}{\sin B} = \frac{c}{\sin C}$ 得： $2\sin A\cos A = \sin C\cos B + \sin B\cos C = \sin (B + C) = \sin A$ 又 $A\in (0,\pi)$ ，所以 $\sin A\neq 0$ 故 $2\cos A = 1$ ，即 $\cos A = \frac{1}{2}$ ，则 $A = \frac{\pi}{3}$ （2）由正弦定理 $\frac{a}{\sin A} = \frac{b}{\sin B} = \frac{c}{\sin C} = \frac{\sqrt{3}}{\sin\frac{\pi}{3}} = 2$ 得： $b = 2\sin B,c = 2\sin C$ 所以 $b + c = 2(\sin B + \sin C) = 2[\sin (\pi -A - C) + \sin C]$ $= 2\left[\sin \left(\frac{2\pi}{3} -C\right) + \sin C\right] = 2\left(\frac{\sqrt{3}}{2}\cos C + \frac{1}{2}\sin C + \sin C\right) = 2\sqrt{3}\sin \left(C + \frac{\pi}{6}\right)$ 又因为 $c > a$ ，所以 $C > A$ ，又 $A = \frac{\pi}{3}$ ，故 $C <   \frac{2\pi}{3}$ 故 $C\in \left(\frac{\pi}{3},\frac{2\pi}{3}\right)$ ，则 $C + \frac{\pi}{6}\in \left(\frac{\pi}{2},\frac{5\pi}{6}\right)$ ，所以 $\sin \left(C + \frac{\pi}{6}\right)\in \left(\frac{1}{2},1\right)$ 故 $b + c$ 的取值范围为 $(\sqrt{3},2\sqrt{3})$
