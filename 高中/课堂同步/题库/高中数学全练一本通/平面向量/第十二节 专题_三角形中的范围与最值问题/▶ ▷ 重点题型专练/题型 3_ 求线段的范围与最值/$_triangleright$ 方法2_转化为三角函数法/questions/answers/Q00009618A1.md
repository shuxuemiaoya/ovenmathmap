> [!faq]- 全练一本通解析
> **【答案】** $$ (1) \frac {\pi}{3}; (2) \left(\frac {1}{2}, 2\right) $$ $$ a \sin A - c \sin C = (b - c) \sin B $$
>
> **【解析】**
> （1）由 $a\sin A - c\sin C = (b - c)\sin B$ ，则根据正弦定理有 $a^2 - c^2 = (b - c)b$ ，即 $a^2 = b^2 + c^2 - bc$ ，又由余弦定理有 $a^2 = b^2 + c^2 - 2bc\cos A$ ，得 $2\cos A = 1$ 所以在 $\triangle ABC$ 中，得 $A = \frac{\pi}{3}$ （2）由 $\triangle ABC$ 为锐角三角形，且 $A = \frac{\pi}{3}$ 则有 $\left\{ \begin{array}{l}0 < C < \frac{\pi}{2}\\ 0 < \frac{2\pi}{3} -C < \frac{\pi}{2} \end{array} \right.$ 得 $C\in \left(\frac{\pi}{6},\frac{\pi}{2}\right)$ ，即 $\tan C\in \left(\frac{\sqrt{3}}{3}, + \infty\right)$ ，即 $\frac{1}{\tan C}\in \left(0,\sqrt{3}\right),$ 所以根据正弦定理有 $\frac{b}{c} = \frac{\sin B}{\sin C} = \frac{\sin\left(\frac{\pi}{3} + C\right)}{\sin C} = \frac{\frac{\sqrt{3}}{2}\cos C + \frac{1}{2}\sin C}{\sin C} = \frac{\sqrt{3}}{2}\cdot \frac{1}{\tan C} +\frac{1}{2}\in \left(\frac{1}{2},2\right).$
