> [!faq]- 全练一本通解析
> **【答案】** （1） $A = \frac{\pi}{4}$ ；（2）4
>
> **【解析】**
> （1）由正弦定理 $\frac{a}{\sin A} = \frac{b}{\sin B} = \frac{c}{\sin C}$ 和 $a\cos B + b\sin A = c$ ，得 $\sin A\cos B + \sin A\sin B = \sin C$ 又 $\because \sin C = \sin (A + B) = \sin A\cos B + \cos A\sin B$ ， $\therefore \sin A\sin B = \cos A\sin B$ 因为 $B\in (0,\pi)$ ，所以 $\sin B\neq 0$ ，则 $\sin A = \cos A$ ，即 $\tan A = 1$ 又 $\because A\in \left(0,\frac{\pi}{2}\right)$ ，则 $A = \frac{\pi}{4}$
> （2）∵ $a^{2}=4\sqrt{3}S=4\sqrt{3}\times\frac{1}{2}bc\sin A=2\sqrt{3}bc\sin A$ 由余弦定理得 $a^{2}=b^{2}+c^{2}-2bc\cos A$ 所以 $b^{2}+c^{2}-2bc\cos A=2\sqrt{3}bc\sin A$ ，则 $\frac{b}{c}+\frac{c}{b}=2\cos A+2\sqrt{3}\sin A=4\sin\left(A+\frac{\pi}{6}\right)$ 又∵ $A \in \left(0, \frac{\pi}{2}\right)$ ，则 $\frac{\pi}{6} < A + \frac{\pi}{6} < \frac{2\pi}{3}$ 当 $A + \frac{\pi}{6} = \frac{\pi}{2}$ ，即 $A = \frac{\pi}{3}$ 时， $\frac{b}{c} + \frac{c}{b}$ 取最大值，最大值为 4.
