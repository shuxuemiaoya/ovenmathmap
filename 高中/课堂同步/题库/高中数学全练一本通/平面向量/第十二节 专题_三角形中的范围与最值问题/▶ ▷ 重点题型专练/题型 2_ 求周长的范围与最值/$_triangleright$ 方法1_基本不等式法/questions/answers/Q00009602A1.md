> [!faq]- 全练一本通解析
> **【答案】** （1） $120^{\circ}$ ；（2） $10 + 5\sqrt{3}$
>
> **【解析】**
> （1）∵ $a^2 +b^2 +ab = c^2$ ，即 $a^2 +b^2 -c^2 = -ab$ 由余弦定理得： $\cos C = \frac{a^2 + b^2 - c^2}{2ab} = -\frac{1}{2},$ ∴ $C = 120^{\circ}$ （2）∵ $a + b = 10$ ∴由余弦定理得： $c^{2} = a^{2} + b^{2} - 2ab\cos C = c^{2} = a^{2} + b^{2} + ab = (a + b)^{2} - ab = 100 - ab$ ，由基本不等式得 $a + b\geq 2\sqrt{ab}$ ，所以 $\sqrt{ab}\leq \frac{a + b}{2} = 5$ ，即 $ab\leq 25$ ∴ $c^2 = 100 - ab\geq 75.$ 当 $a = b = 5$ 时取等号，则△ABC周长的最小值为 $a + b + c = 10 + 5\sqrt{3}$
