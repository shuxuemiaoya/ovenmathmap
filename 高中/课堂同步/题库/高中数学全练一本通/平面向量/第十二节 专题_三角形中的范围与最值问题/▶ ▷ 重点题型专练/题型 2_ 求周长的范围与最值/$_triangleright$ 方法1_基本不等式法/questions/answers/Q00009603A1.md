> [!faq]- 全练一本通解析
> **【答案】** （1） $B = \frac{2\pi}{3}$ （2） $4 + 2\sqrt{3}$
>
> **【解析】**
> （1）因为 $\sqrt{3} b\sin A = a(2 + \cos B)$ 所以 $\sqrt{3}\sin B\sin A = \sin A(2 + \cos B)$ 因为 $\sin A > 0$ 所以 $\sqrt{3}\sin B - \cos B = 2$ 所以 $2\sin \left(B - \frac{\pi}{6}\right) = 2,$ ∴ $B\in (0,\pi)$ ，所以 $B - \frac{\pi}{6}\in \left(-\frac{\pi}{6},\frac{5\pi}{6}\right)$ 所以 $B - \frac{\pi}{6} = \frac{\pi}{2},\therefore B = \frac{2\pi}{3};$ （2）依题意 $\frac{\sqrt{3}ac}{4} = \sqrt{3},\therefore ac = 4,$ 所以 $a + c\geq 2\sqrt{ac} = 4$ ，当且仅当 $a = c = 2$ 时取等号，又由余弦定理得 $b^{2} = a^{2} + c^{2} - 2accos\cdot B = a^{2} + c^{2} + ac\geq 3ac = 12,$ ∴ $b\geq 2\sqrt{3}$ ，当且仅当 $a = c = 2$ 时取等号，所以△ABC的周长最小值为 $4 + 2\sqrt{3}$
