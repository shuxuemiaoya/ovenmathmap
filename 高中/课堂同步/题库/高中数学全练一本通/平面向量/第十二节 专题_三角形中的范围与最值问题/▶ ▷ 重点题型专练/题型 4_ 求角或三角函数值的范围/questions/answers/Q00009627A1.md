> [!faq]- 全练一本通解析
> **【答案】** (1)} \frac {3}{4}; (2) 9. $$ $$ \frac {\pi}{3} $$
>
> **【解析】**
> （1）在 $\Delta ABC$ 中， $5\left(\sin^2 B + \sin^2 C\right) = 8\sin B\sin C + 5\sin^2 A$ 由正弦定理 $\frac{a}{\sin A} = \frac{b}{\sin B} = \frac{c}{\sin C}$ ，得 $b^2 + c^2 - a^2 = \frac{8}{5} bc$ 故 $\cos A = \frac{b^2 + c^2 - a^2}{2bc} = \frac{4}{5}$ ， $\therefore 0 < A < \frac{\pi}{2}$ ，故 $\sin A = \sqrt{1 - \cos^2 A} = \sqrt{1 - \frac{16}{25}} = \frac{3}{5}$ ，则 $\tan A = \frac{\sin A}{\cos A} = \frac{3}{4}$ ；（2）由 $\tan(B + C) = \frac{\tan B + \tan C}{1 - \tan B\tan C} = -\tan A = -\frac{3}{4}$ 得， $4\tan B + 4\tan C - 3\tan B\tan C + 3 = 0$ ∴ $\tan B > 0$ ， $\tan C > 0$ 由均值不等式得， $4\tan B + 4\tan C = 3\tan B\tan C - 3 \geq 2\sqrt{4\tan B \times 4\tan C}$ ，当且仅当 $\tan B = \tan C = 3$ 时，等号成立。解得 $\sqrt{\tan B\tan C} \geq 3$ ∴ $\tan B\tan C$ 的最小值为9。
