> [!faq]- 全练一本通解析
> **【答案】** （1）证明见解析；（2） $(1,\sqrt{2} ]$
>
> **【解析】**
> （1）由余弦定理可
> 得： $a - b = a\cos B - b\cos A = a\cdot \frac{a^2 + c^2 - b^2 - b\cdot b^2 + c^2 - a^2}{2ac} = \frac{a^2 - b^2}{c},$ 有 $a^2 -b^2 = c(a - b)$ ，即 $(a + b - c)(a - b) = 0$ 由 $a + b - c > 0$ ，得 $a - b = 0$ ，即 $a = b$ （2）由 $a = b$ ，有 $A = B$ ∴ $A + B + C = 2A + C = \pi$ ，得 $C = \pi -2A$ ， $0 <   A <   \frac{\pi}{2}$ $\sin A + \sin \frac{C}{2} = \sin A + \sin \frac{\pi - 2A}{2} = \sin A + \sin \left(\frac{\pi}{2} -A\right)$ $= \sin A + \cos A = \sqrt{2}\sin \left(A + \frac{\pi}{4}\right),$
> 由 $0 < A < \frac{\pi}{2}$ , 有 $\frac{\pi}{4} < A + \frac{\pi}{4} < \frac{3\pi}{4}$ , 则有 $\frac{\sqrt{2}}{2} < \sin \left(A + \frac{\pi}{4}\right) \leq 1$ , 可得 $1 < \sqrt{2} \sin \left(A + \frac{\pi}{4}\right) \leq \sqrt{2}$ . 所以 $\sin A + \sin \frac{C}{2}$ 的取值范围为 $(1, \sqrt{2}]$ .
