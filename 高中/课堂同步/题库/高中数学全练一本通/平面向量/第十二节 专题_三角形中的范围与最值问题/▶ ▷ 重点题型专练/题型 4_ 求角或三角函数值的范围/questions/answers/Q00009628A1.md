> [!faq]- 全练一本通解析
> **【答案】** （1） $\frac{\pi}{3}$ ；（2） $\frac{2\sqrt{3}}{3}$ 。
>
> **【解析】**
> （1）由 $\frac{(b - c)\sin C}{b + a} = \sin B - \sin A$ ，可得 $(b - c)\sin C = (\sin B - \sin A)(b + a)$ ，由正弦定理得 $(b - c)c = (b - a)(b + a)$ ，即 $b^2 + c^2 - a^2 = bc$ ，由余弦定理，得 $\cos A = \frac{b^2 + c^2 - a^2}{2bc} = \frac{1}{2}$ ，因为 $0 < A < \pi$ ，可得 $A = \frac{\pi}{3}$ 。
> （2）由（1）知 $A=\frac{\pi}{3}$ ，设三角形的外接圆的半径为 R，可得 $2R=\frac{a}{\sin A}=\frac{4\sqrt{3}}{3}$ ,
> $$
> a ^ {2} = b ^ {2} + c ^ {2} - 2 b c \cos A = b ^ {2} + c ^ {2} - b c \geq b c
> $$
> 即 $bc \leq a^2 = 4$ ，当且仅当 $b = c = 2$ 时取等号，
> 又由 $\frac{1}{\tan B} +\frac{1}{\tan C} = \frac{\cos B}{\sin B} +\frac{\cos C}{\sin C} = \frac{\cos B\sin C + \sin B\cos C}{\sin B\sin C}$
> $$
> = \frac {\sin (B + C)}{\sin B \sin C} = \frac {\sin A}{\sin B \sin C} = \frac {2 R \cdot 2 R \sin A}{2 R \sin B \cdot 2 R \sin C}
> $$
> $$
> = \frac {2 R \cdot a}{b c} = \frac {8 \sqrt {3}}{3 b c} \geq \frac {8 \sqrt {3}}{3 \times 4} = \frac {2 \sqrt {3}}{3}
> $$
> 其中 R 是 $\triangle ABC$ 外接圆的半径,
> 所以 $\frac{1}{\tan B} +\frac{1}{\tan C}$ 的最小值为 $\frac{2\sqrt{3}}{3}$
