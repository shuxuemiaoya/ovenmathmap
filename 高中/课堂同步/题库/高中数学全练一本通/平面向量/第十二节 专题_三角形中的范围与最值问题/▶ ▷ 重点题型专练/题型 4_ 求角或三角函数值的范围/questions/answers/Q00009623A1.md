> [!faq]- 全练一本通解析
> **【答案】** 详见解析
>
> **【解析】**
> （1） $\frac{\pi}{3}$ ; （2） $\left(\frac{\sqrt{3}}{2}, \sqrt{3}\right]$ .
> $$
> 2 \cos C (a \cos B + b \cos A) = c
> $$
> 结合正弦定理得 $2\cos C(\sin A\cos B + \sin B\cos A) = \sin C$ 故 $2\cos C\sin (A + B) = \sin C$ ，即 $2\cos C\sin C = \sin C$ 因为 $C\in (0,\pi)$ ，则 $\sin C > 0$ ，所以 $2\cos C = 1$ ，则 $\cos C = \frac{1}{2}$ ，所以 $C = \frac{\pi}{3}$ （2） $\sin A + \sin B = \sin A + \sin (A + C)$ $= \sin A + \sin \left(A + \frac{\pi}{3}\right)$ $= \sin A + \sin A\cos \frac{\pi}{3} +\cos A\sin \frac{\pi}{3}$ $= \sin A + \frac{1}{2}\sin A + \frac{\sqrt{3}}{2}\cos A$ $= \frac{3}{2}\sin A + \frac{\sqrt{3}}{2}\cos A$ $= \sqrt{3}\sin \left(A + \frac{\pi}{6}\right)$ 因为 $0 <   A <   \frac{2\pi}{3}$ ，则 $\frac{\pi}{6} <  A + \frac{\pi}{6} <   \frac{5\pi}{6}$ 故 $\frac{1}{2} <  \sin \left(A + \frac{\pi}{6}\right)\leq 1$ ，因此 $\frac{\sqrt{3}}{2} <  \sqrt{3}\sin \left(A + \frac{\pi}{6}\right)\leq \sqrt{3}$ 所以 $\sin A + \sin B$ 的取值范围为 $\left(\frac{\sqrt{3}}{2},\sqrt{3}\right].$
