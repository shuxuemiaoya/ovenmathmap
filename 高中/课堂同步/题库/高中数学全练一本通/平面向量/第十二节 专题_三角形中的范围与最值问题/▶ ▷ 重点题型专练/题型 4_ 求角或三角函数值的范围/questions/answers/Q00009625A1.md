> [!faq]- 全练一本通解析
> **【答案】** （1） $C = \frac{\pi}{3}$ ；（2） $0 < \sin A\sin B\leq \frac{3}{4}$
>
> **【解析】**
> （1）中正弦定理得： $(a - c)(a + c) = cb - b^2$
> 解析：（1）由正弦定理得： $(a - c)(a + c) = ab - b^{2}$ $\therefore a^2 +b^2 -c^2 = ab$ 由余弦定理 $\cos C = \frac{a^2 + b^2 - c^2}{2ab} = \frac{1}{2}$ $\because C$ 为三角形的内角
> ∴ $C=\frac{\pi}{3}$
> （2）由（1）得 $A + B = \frac{2\pi}{3}$ ，即 $B = \frac{2\pi}{3} - A$ 则 $\sin A\sin B = \sin A\sin \left(\frac{2\pi}{3} - A\right)$ $= \sin A\left(\frac{\sqrt{3}}{2}\cos A + \frac{1}{2}\sin A\right)$ $= \frac{\sqrt{3}}{2}\sin A\cos A + \frac{1}{2}\sin^2 A$ $= \frac{\sqrt{3}}{4}\sin 2A + \frac{1 - \cos 2A}{4}$ $= \frac{1}{2}\sin \left(2A - \frac{\pi}{6}\right) + \frac{1}{4}$ $\because A\in \left(0,\frac{2\pi}{3}\right),\therefore 2A - \frac{\pi}{6}\in \left(-\frac{\pi}{6},\frac{7\pi}{6}\right),$ $\therefore 0 <   \sin A\sin B\leq \frac{3}{4}$
