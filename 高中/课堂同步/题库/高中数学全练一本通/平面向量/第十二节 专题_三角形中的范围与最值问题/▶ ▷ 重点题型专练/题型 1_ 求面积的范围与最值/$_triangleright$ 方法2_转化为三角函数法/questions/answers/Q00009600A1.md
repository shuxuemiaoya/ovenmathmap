> [!faq]- 全练一本通解析
> **【答案】** （1） $\frac{\pi}{3}$ ;（2） $\left(\frac{\sqrt{3}}{2},2\sqrt{3}\right)$
>
> **【解析】**
> （1）由 $b\cos C + c\cos B = 2$ 根据余弦定理可得 $b \cdot \frac{a^{2} + b^{2} - c^{2}}{2ab} + c \cdot \frac{a^{2} + c^{2} - b^{2}}{2ac} = 2$ ，化简得 a = 2，
> 由正弦定理 $\frac{a}{\sin A} = \frac{b}{\sin B}$ ，可知 $\sin B = \frac{b\sin A}{a} = \frac{\sqrt{3}}{2}$ 因为△ABC为锐角三角形，所以 $B=\frac{\pi}{3}$ .
> （2）由 $S_{\triangle ABC}=\frac{1}{2}a c s i n B=\frac{\sqrt{3}}{2}c$ 由正弦定理得 $c=\frac{a s i n C}{s i n A}=\frac {2 s i n(A+B)}{s i n A}=\frac {2(s i n A c o s B+c o s A s i n B)}{s i n A}=1+\frac {\sqrt {3}}{\tan A}$ 因为△ABC为锐角三角形，
> 所以 $\left\{\begin{aligned}&0<A<\frac{\pi}{2}\\&0<C=\frac {2\pi}{3}-A<\frac {\pi}{2}\end{aligned}\right.$ ，解得 $\frac{\pi}{6}<A<\frac{\pi}{2}$
> 则 $\tan A\in \left(\frac{\sqrt{3}}{3}, + \infty\right),c = \frac{\sqrt{3}}{\tan A} +1\in (1,4)$ ，故 $\frac{\sqrt{3}}{2} < S_{\triangle ABC} < 2\sqrt{3}$ 即 $\triangle ABC$ 面积的取值范围为 $\left(\frac{\sqrt{3}}{2},2\sqrt{3}\right)$
