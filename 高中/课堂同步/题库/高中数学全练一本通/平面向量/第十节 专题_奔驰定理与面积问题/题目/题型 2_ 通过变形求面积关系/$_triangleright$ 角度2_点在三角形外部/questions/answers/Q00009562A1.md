> [!faq]- 全练一本通解析
> **【答案】** 3
>
> **【解析】**
> 方法一：因为 $\overline{PA} + 2\overline{PC} = m\overline{AB}$ ，所以 $\overline{PA} + 2\overline{PC} = m(\overline{PB} - \overline{PA})$ ，整理得 $(m + 1)\overline{PA} - m\overline{PB} + 2\overline{PC} = \vec{0}$ ，根据奔驰定理的推论 $(m + 1)\overline{PA} - m\overline{PB} + 2\overline{PC} = \vec{0}$ ，则 $S_{\triangle PBC}: S_{\triangle PCA}: S_{\triangle PAB} = |m + 1|: |-m|: |2|$ . 又因为 $\Delta ABP$ 的面积为2，所以 $S_{\triangle ABC} = S_{\triangle PAB} + S_{\triangle PBC} - S_{\triangle PAC} = (m + 1) + 2 - m = 3$ 。方法二：因为 $\overline{PA} + 2\overline{PC} = m\overline{AB}(m > 0)$ ，所以 $\frac{1}{3}\overline{PA} + \frac{2}{3}\overline{PC} = \frac{m}{3}\overline{AB}(m > 0)$ ，令 $\overline{PD} = \frac{1}{3}\overline{PA} + \frac{2}{3}\overline{PC}$ ，则 $\frac{1}{3}\overline{PD} - \frac{1}{3}\overline{PA} = \frac{2}{3}\overline{PC} - \frac{2}{3}\overline{PD}$ ，所以 $\frac{1}{3}\overline{AD} = \frac{2}{3}\overline{DC}$ ，所以 $D$ 为 $AC$ 上靠近 $C$ 的三等分点，因为 $\overline{PD} = \frac{m}{3}\overline{AB}$ ，所以 $\overline{PD} // \overline{AB}$ ，所以 $S_{\triangle ABP} = S_{\triangle ABD} = \frac{2}{3} S_{\triangle ABC} = 2$ ，所以 $S_{\triangle ABC} = 3$ ，故答案为：3
