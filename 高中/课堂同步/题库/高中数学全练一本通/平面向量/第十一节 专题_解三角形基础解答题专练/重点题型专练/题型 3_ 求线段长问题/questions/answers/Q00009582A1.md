> [!faq]- 全练一本通解析
> **【答案】** （1） $C=\frac{3}{4}\pi$ ；（2） $AD=\sqrt{13}$
>
> **【解析】**
> （1）因为 $b=c(\cos A-\sin A)$ ，所以 $\sin B=\sin C(\cos A-\sin A)$ ，
> 又 $\sin B = \sin(A + C) = \sin A \cos C + \cos A \sin C$ ，所以 $\sin A \cos C \equiv -\sin C \sin A$ 因为 $A \in (0, \pi)$ ，所以 $\sin A \neq 0$ ，所以 $\cos C = -\sin C$ 即 $\tan C = -1$ ，又 $C \in (0, \pi)$ ，所以 $C = \frac{3}{4}\pi$ ;
> （2）由△ADC面积 S=1 可得 $S_{\triangle ABC}=2$ 则 $\frac{1}{2}ab\sin C=2$ ，即 $\frac{1}{2}ab\times\frac{\sqrt{2}}{2}=2$ ，得 $ab=4\sqrt{2}$ ①，
> 又 $c^{2}=a^{2}+b^{2}-2ab\cos C$ ，所以 $a^{2}+b^{2}+\sqrt{2}ab=20$ ②，
> 联立①②得 $\left\{\begin{aligned}a&=2\sqrt{2}\\ b&=2\end{aligned}\right.$ 或 $\left\{\begin{aligned}a&=2\\ b&=2\sqrt{2}\end{aligned}\right.$ ，又 B > A，所以 $a=2, b=2\sqrt{2}$ 在△ACD中，由余弦定理可得 $AD^{2}=AC^{2}+CD^{2}-2AC\cdot CD\cdot\cos C=8+1-2\times2\sqrt{2}\times1\times\left(-\frac{\sqrt{2}}{2}\right)=13$ 所以 $AD=\sqrt{13}$
