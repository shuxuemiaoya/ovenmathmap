> [!faq]- 全练一本通解析
> **【答案】** （1）等腰直角三角形（2） $\frac{3\sqrt{10}}{10}$
>
> **【解析】**
> （1）因为 $\sin C + \cos C = \sqrt{2}$
> 所以 $\sqrt{2}\sin\left(C+\frac{\pi}{4}\right)=\sqrt{2}$
> 所以 $\sin\left(C+\frac{\pi}{4}\right)=1$
> 又因为 $0 < C < \pi$ ，所以 $C = \frac{\pi}{4}$ .
> 在 $\triangle ABC$ 中, 由正弦定理 $\frac{a}{\sin A} = \frac{b}{\sin B}$ 得, $\frac{a}{b} = \frac{\sin A}{\sin B}$ ,
> 又因为 $(1 - \cos A)b = a\cos B$ ，所以 $(1 - \cos A)\sin B = \sin A\cos B$
> 所以 $\sin B = \sin A \cos B + \cos A \sin B = \sin(A + B)$
> 又因为 $A + B + C = \pi$ ，所以 $\sin (A + B) = \sin (\pi -C) = \sin C$
> 所以 $\sin B = \sin C.$
> 因为 $C = \frac{\pi}{4}$ ，所以 $B = \frac{\pi}{4}, A = \frac{\pi}{2}$
> 所以 $\triangle ABC$ 的形状是等腰直角三角形.
> (2) 因为 $\triangle ABC$ 的形状是等腰直角三角形,
> 所以不妨设 $AC = AB = 2\sqrt{2}k$ ，BC = 4k。
> 因为 $BD = 3CD$ ， $BC = 2PD$ ，所以 $CD = k$ ， $PD = 2k$
> 在直角 $\triangle CPD$ 中， $\tan\angle PCD=\frac{PD}{CD}=2$ ，
> 所以 $\tan \angle PCA = \tan (\angle PCD - \angle ACB) = \frac{\tan\angle PCD - \tan\angle ACB}{1 + \tan\angle PCD\tan\angle ACB} = \frac{2 - 1}{1 + 2} = \frac{1}{3}$
> 因为 $\tan \angle PCA = \frac{\sin\angle PCA}{\cos\angle PCA} = \frac{1}{3}$ ， $\sin^2\angle PCA + \cos^2\angle PCA = 1$
> 所以 $\cos\angle ACP=\frac{3\sqrt{10}}{10}$ .
