> [!faq]- 全练一本通解析
> **【答案】** （1） $B=\frac{\pi}{3}$ ;（2）6
>
> **【解析】**
> （1）解：由 $\left(b + c\right)\left(\sin B - \sin C\right) = (\sin A - \sin C)a$ ，根据正弦定理可得 $\left(b + c\right)\left(b - c\right) = (a - c)a$ ，所以， $a^2 +c^2 -b^2 = ac$ 由余弦定理可得 $\cos B = \frac{a^2 + c^2 - b^2}{2ac} = \frac{1}{2}$ ∴ $B\in (0,\pi)$ ，因此， $B = \frac{\pi}{3}$ （2）解：因为 $S_{\triangle ABC} = \frac{1}{2} ac\sin B = \frac{\sqrt{3}}{4} ac = \sqrt{3}$ ，∴ $ac = 4$ 由余弦定理可得 $b^{2} = a^{2} + c^{2} - 2ac\cos B = a^{2} + c^{2} - ac = (a + c)^{2} - 3ac = (a + c)^{2} - 12 = 4$ ， $\therefore a + c = 4$ ，因此，△ABC的周长为 $a + b + c = 6$
