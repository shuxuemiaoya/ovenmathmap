> [!faq]- 全练一本通解析
> **【答案】** A
>
> **【解析】**
> 解析:由 $\overrightarrow{AM} = \lambda \overrightarrow{MB}$ ，得 $\overrightarrow{AB} = \overrightarrow{AM} + \overrightarrow{MB} = (\lambda + 1) \overrightarrow{MB}$ ，所以 $\overrightarrow{MB} = \frac{1}{\lambda + 1} \overrightarrow{AB}$ 。
> 由 $\overrightarrow{DN} = \mu \overrightarrow{NC}$ ，得 $\overrightarrow{DC} = \overrightarrow{DN} + \overrightarrow{NC} = (\mu + 1) \overrightarrow{NC}$ ，所以 $\overrightarrow{NC} = \frac{1}{\mu + 1} \overrightarrow{DC}$ 。
> 因为 $\overrightarrow{DC} = \overrightarrow{AB}$ ，所以 $\overrightarrow{NC} = \frac{1}{\mu + 1} \overrightarrow{AB}$ 。
> 所以
> $\overrightarrow{MN} = \overrightarrow{MB} + \overrightarrow{BC} + \overrightarrow{CN} = \frac{1}{\lambda + 1}\overrightarrow{AB} + \overrightarrow{AD} - \frac{1}{\mu + 1}\overrightarrow{AB} = \left(\frac{1}{\lambda + 1} - \frac{1}{\mu + 1}\right)\overrightarrow{AB} + \overrightarrow{AD}$ 所以 $\frac{1}{\lambda + 1} - \frac{1}{\mu + 1} = -\frac{1}{3}$ ，即 $\frac{1}{\mu + 1} - \frac{1}{\lambda + 1} = \frac{1}{3}$ .
>
> 故选 **A**.
