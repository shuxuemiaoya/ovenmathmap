> [!faq]- 全练一本通解析
> **【答案】** （1） $B = \frac{\pi}{3}$ ；（2） $[\frac{3\sqrt{3}}{2},3)$
>
> **【解析】**
> （1）在 $\triangle ABC$ 中，依题意有 $2b\sin A - \sqrt{3}a\cos B = a\sin B$
> 由正弦定理得： $2\sin B\sin A - \sqrt{3}\sin A\cos B = \sin A\sin B$ 而 $0 < A < \pi$ ，即 $\sin A > 0$ ，则有 $\sin B = \sqrt{3}\cos B$ ，即 $\tan B = \sqrt{3}$ ，而 $0 < B < \pi$ ，所以 $B = \frac{\pi}{3}$ .
> （2）在 $\triangle ABC$ 中，由（1）知， $B = \frac{\pi}{3}$ ，又 $a + c = 6$ ，点 $D$ 是边 $AC$ 的中点，则 $\overrightarrow{BD} = \frac{1}{2} (\overrightarrow{BA} +\overrightarrow{BC})$ ，于是得 $|\overrightarrow{BD}| = \frac{1}{2}\sqrt{(\overrightarrow{BA} + \overrightarrow{BC})^2} = \frac{1}{2}\sqrt{\overrightarrow{BA}^2 + \overrightarrow{BC}^2 + 2\overrightarrow{BA}\cdot\overrightarrow{BC}} = \frac{1}{2}\sqrt{a^2 + c^2 + 2ac\cos\frac{\pi}{3}}$ $= \frac{1}{2}\sqrt{(a + c)^2 - ac} = \frac{1}{2}\sqrt{36 - ac}$ ，显然 $0 < ac\leq (\frac{a + c}{2})^2 = 9$ ，当且仅当 $a = c = 3$ 时取等号，因此 $27\leq 36 - ac < 36$ ， $\frac{3\sqrt{3}}{2}\leq \frac{1}{2}\sqrt{36 - ac} < 3$ ，即 $\frac{3\sqrt{3}}{2}\leq |\overrightarrow{BD}| < 3$ 所以 $BD$ 的取值范围是 $[\frac{3\sqrt{3}}{2},3)$
