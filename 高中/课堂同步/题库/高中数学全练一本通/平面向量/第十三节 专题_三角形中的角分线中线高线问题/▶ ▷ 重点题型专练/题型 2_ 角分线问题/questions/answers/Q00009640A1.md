> [!faq]- 全练一本通解析
> **【答案】** （1） $A = \frac{\pi}{3}$ ；（2）3
>
> **【解析】**
> （1）因为 $\frac{(c \cos B + b \cos C)^2 + bc}{b^2 + c^2} = 1$ ，即 $\left(c\frac{a^2 + c^2 - b^2}{2ac} + b\frac{a^2 + b^2 - c^2}{2ab}\right)^2 + bc = b^2 + c^2$ 化简可得 $a^2 = b^2 + c^2 - bc$ ，由余弦定理可得 $a^2 = b^2 + c^2 - 2bc \cos A$ ，所以 $2\cos A = 1 \Rightarrow \cos A = \frac{1}{2}$ ，且 $A \in (0, \pi)$ ，则 $A = \frac{\pi}{3}$ （2）由（1）知 $A = \frac{\pi}{3}$ ，由余弦定理可得 $\cos A = \frac{b^2 + c^2 - a^2}{2bc}$ ，将 $b = 2c$ 代入，化简可得 $a = \sqrt{3}c$ ，又因为 $AD$ 平分 $\angle BAC$ ，由角平分线定理可得 $\frac{AB}{AC} = \frac{BD}{CD}$ ，即 $\frac{c}{b} = \frac{BD}{CD} \Rightarrow \frac{1}{2} = \frac{BD}{CD} \Rightarrow CD = 2BD$ ，且 $a = \sqrt{3}c$ ，所以 $CD = \frac{2\sqrt{3}}{3}c, BD = \frac{\sqrt{3}}{3}c$ ，又因为 $\angle ADB + \angle ADC = \pi$ ，则 $\cos \angle ADB = -\cos \angle ADC$ ，结合余弦定理可得 $\frac{4 + \frac{1}{3}c^2 - c^2}{2 \times 2 \times \frac{\sqrt{3}}{3}c} = -\frac{4 + \frac{4}{3}c^2 - 4c^2}{2 \times 2 \times \frac{2\sqrt{3}}{3}c}$ ，解得 $c^2 = 3$ ，所以 $c = \sqrt{3}$ 则 $a = \sqrt{3}c = 3$
