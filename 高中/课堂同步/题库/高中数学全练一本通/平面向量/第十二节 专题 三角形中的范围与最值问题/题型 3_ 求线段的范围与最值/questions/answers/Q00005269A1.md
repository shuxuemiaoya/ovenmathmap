> **【解析】**
> （1） $\frac{2\pi}{3};$ （2）1.解析：（1） $\sqrt{3}(b\cos C - a) = c\sin B$ ，由正弦定理，得 $\sqrt{3} (\sin B\cos C - \sin A) = \sin C\sin B,$ 由 $\sin A = \sin (B + C) = \sin B\cos C + \sin C\cos B,$ 得一√3 sinC cosB= sinC sinB，又 $0 <   C <   \pi$ 所以 $\sin C\neq 0$ ，有一√3 cosB= sinB，即tanB=-√3，又 $0 <   B <   \pi$ ，所以 $B = \frac{2\pi}{3};$ （2）由 $S_{ ABC} = \frac{1}{2} ac\sin B = \frac{1}{2} b\cdot BD$ ，得 $BD = \frac{ac\sin B}{b} = \frac{1}{4} ac,$ 由余弦定理及 $b = 2\sqrt{3}$ 得 $12 = a^{2} + c^{2} - 2ac\cos \frac{2\pi}{3} = a^{2} + c^{2} + ac\geq 2ac + ac = 3ac,$ 当且仅当 $a = c = 2$ 时取到等号.所以ac≤4，故 $BD = \frac{1}{4} ac\leq 1$ ，即BD的最大值为1.
