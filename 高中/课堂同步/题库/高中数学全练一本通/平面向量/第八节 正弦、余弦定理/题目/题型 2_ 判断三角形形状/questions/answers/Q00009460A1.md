> [!faq]- 全练一本通解析
> **【答案】** B
>
> **【解析】**
> 解析:根据余弦定理知, $b\cos C + c\cos B = b \times \frac{a^{2} + b^{2} - c^{2}}{2ab} + c \times \frac{a^{2} + c^{2} - b^{2}}{2ac}$ $= \frac{a^{2} + b^{2} - c^{2}}{2a} + \frac{a^{2} + c^{2} - b^{2}}{2a}$ $= a = \frac{b^{2} + c^{2}}{a}$ ，所以 $a^{2} = b^{2} + c^{2}$ ，则 $\angle A = \frac{\pi}{2}$ ，故三角形为直角三角形，
>
> 故选 **B**.
