> [!faq]- 全练一本通解析
> **【答案】** （1）一解；（2）一解；（3）一解；（4）两解；（5）无解；（6）两解；（7）无解；（8）一解；（9）两解；（10）一解.
>
> **【解析】**
> （1）因为 $a = 5$ , $b = 4$ , $A = 120^\circ$
> $$
> \sin B = \frac {b \sin A}{a} = \frac {4 \times \frac {\sqrt {3}}{2}}{5} = \frac {2 \sqrt {3}}{5} <   1
> $$
> 则由正弦定理可得 $\sin B=\frac{b\sin A}{a}=\frac{4\times\frac{1}{2}}{5}=\frac{2\sqrt{3}}{5}<1$ 又 a>b，则 A>B，即 B 只能是锐角，
> 则 $\sin B=\frac{2\sqrt{3}}{5}$ 只有一解，故 $\triangle ABC$ 有一解；
> （2）因为 a=5, b=4, $A=90^{\circ}$ ,
> 则由正弦定理可得 $\sin B = \frac{b \sin A}{a} = \frac{4 \times 1}{5} = \frac{4}{5} < 1$ 又 a > b，则 A > B，即 B 只能是锐角，
> 则 $\sin B = \frac{4}{5}$ 只有一解，故 $\triangle ABC$ 有一解；
> （3）因为 $a=10\sqrt{6}, b=20\sqrt{3}, A=45^{\circ}$ 则由正弦定理可得 $\sin B = \frac{b \sin A}{a} = \frac{20\sqrt{3} \times \frac{\sqrt{2}}{2}}{10\sqrt{6}} = 1$ 由于 $0^{\circ} < B < 180^{\circ}$ ，故 $B = 90^{\circ}$ ，故 $\triangle ABC$ 有一解；
> （4）因为 $a = 20\sqrt{2}, b = 20\sqrt{3}, A = 45^{\circ}$ 则由正弦定理可得 $\sin B = \frac{b \sin A}{a} = \frac{20\sqrt{3} \times \frac{\sqrt{2}}{2}}{20\sqrt{2}} = \frac{\sqrt{3}}{2}$ 因为 a < b，故 B > A，而 $0^{\circ} < B < 180^{\circ}$ ，则 $B = 60^{\circ}$ 或 $120^{\circ}$ ，
> 故 $\triangle ABC$ 有两解；
> （5） $a=4,b=\frac{10\sqrt{3}}{3},A=60^{\circ}$ 则由正弦定理可得 $\sin B = \frac{b \sin A}{a} = \frac{\frac{10\sqrt{3}}{3} \times \frac{\sqrt{3}}{2}}{4} = \frac{5}{4} > 1$ 故 $\triangle ABC$ 无解.
> （6）a=14, b=16, $A=45^{\circ}$ ∴由正弦定理得： $\sin B = \frac{b \sin A}{a} = \frac{16 \times \frac{\sqrt{2}}{2}}{14} = \frac{4\sqrt{2}}{7} > \frac{\sqrt{2}}{2}$ ∵ a < b, ∴ $A = 45^{\circ} < B$ 故 B 有锐角和钝角两个解，故答案为：两解.
> （7）由 a=12, c=15, 得到 a<c，
> 有 A<C，而 A=120°，得到 C 也为钝角，
> 故此三角形无解，故答案为：无解.
> （8）∵ a=8, b=16, A=30°
> ∴ $\sin B = \frac{b \sin A}{a} = \frac{16 \times \frac{1}{2}}{8} = 1$ ∴ $B = \frac{\pi}{2}$ 故三角形只有一个解，故答案为：一解.
> （9）∵ b=18, c=20, B=60°,
> ∴ $\sin C = \frac{c \sin B}{b} = \frac{20 \times \frac{\sqrt{3}}{2}}{18} = \frac{5\sqrt{3}}{9} > \frac{\sqrt{3}}{2}$ ∵ 0 < C < π，故 C 有锐角和钝角两个解.
> （10）正弦定理可得 $\frac{b}{\sin B} = \frac{c}{\sin C}$ 所以 $\sin B = \frac{b \sin C}{c} = \frac{2 \times \frac{\sqrt{3}}{2}}{\sqrt{5}} = \frac{\sqrt{15}}{5}$ .
> 因为 b < c，所以 B 只有一个解，所以此三角形解的情况是一个解.
