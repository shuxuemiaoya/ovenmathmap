## 题型 1:三角形中的边角转化

三角形的要素无非就是三个角和三条边, 而解三角形便是紧紧围绕着边与角进行的, 边与角的关系密不可分, 所以 “边角的转换” 可谓是解三角形的核心. 参考公式:

(1) a:b:c = sin A : sin B : sin C ;

(2) $a = 2R\sin A, b = 2R\sin B, c = 2R\sin C$ (R为 $\triangle ABC$ 的外接圆半径）；
(3) $\sin A = \frac{a}{2R}, \sin B = \frac{b}{2R}, \sin C = \frac{c}{2R}$ （R为 $\triangle ABC$ 的外接圆半径）.

【注】从公式可以看出,边的比等于所对角正弦之比,这一点是正弦定理最广泛的应用.但务必注意,边与正弦的相互转换必须在“齐次”的前提下才可以进行,如下面的(1),如果不是齐次式,则只能在齐次的条件下进行相应的转换,如下面的(2).

(1) $a + 2b = 2c$ 等价于 $\sin A + 2\sin B = 2\sin C$ ;

(2) $a + 2b^{2} = 2c$ 等价于 $\sin A + 2b\sin B = 2\sin C$ ;

(3) $a + 2b = 3$ 无法进行转换.
