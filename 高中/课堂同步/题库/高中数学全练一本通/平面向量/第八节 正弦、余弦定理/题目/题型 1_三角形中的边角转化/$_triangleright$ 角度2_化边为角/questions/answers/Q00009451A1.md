> [!faq]- 全练一本通解析
> **【答案】** 直角
>
> **【解析】**
> 由正弦定理和降幂公式可得 $\sin A\sin C + \sin A(1 + \cos C) = \sin A + \sin B + \sin C$ 即 $\sin A\sin C + \sin A\cos C = \sin B + \sin C$ 又 $\sin B = \sin(A + C) = \sin A\cos C + \cos A\sin C$ 所以 $\sin A \sin C + \sin A \cos C = \sin A \cos C + \cos A \sin C + \sin C$ 即 $\sin A \sin C = (\cos A + 1) \sin C$ 因为 $C \in (0, \pi), \sin C > 0$ 所以 $\sin A = \cos A + 1, \therefore (\sin A - \cos A)^{2} = 1$ 即 $1 - 2\sin A\cos A = 1, \sin 2A = 0$ 因为 $0 < 2a < 2\pi$ ，所以 $2A = \pi$ ，得 $A = \frac{\pi}{2}$ ，故为直角三角形.
> 故答案为: 直角
