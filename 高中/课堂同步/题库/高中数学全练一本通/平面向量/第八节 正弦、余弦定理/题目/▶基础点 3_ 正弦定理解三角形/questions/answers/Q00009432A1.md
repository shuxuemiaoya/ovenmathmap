> [!faq]- 全练一本通解析
> **【答案】** D
>
> **【解析】**
> 解析: 因为 $A + B = 5C$ ，且 $A + B + C = \pi$ ，则 $5C + C = 6C = \pi$ ，可得 $C = \frac{\pi}{6}$ ，
> 由正弦定理 $\frac{b}{\sin B}=\frac{c}{\sin C}$ ，可得 $\sin B=\frac{b\sin C}{c}=\frac{1\times\frac{1}{2}}{2}=\frac{1}{4}$ 。
>
> 故选 **D**.
