# 第八节 正弦、余弦定理

## 知识导学

## 1. 余弦定理

三角形中任何一边的平方等于其他两边平方的和减去这两边与它们的夹角的余弦的积的两倍, 即 $\triangle ABC$ 中

$$
\left\{ \begin{array}{l} a ^ {2} = b ^ {2} + c ^ {2} - 2 b c \cos A \\ b ^ {2} = a ^ {2} + c ^ {2} - 2 a c \cos B \\ c ^ {2} = a ^ {2} + b ^ {2} - 2 a b \cos C \end{array} \right. \quad \text {推论} \left\{ \begin{array}{l} \cos A = \frac {b ^ {2} + c ^ {2} - a ^ {2}}{2 b c} \\ \cos B = \frac {a ^ {2} + c ^ {2} - b ^ {2}}{2 a c} \\ \cos C = \frac {a ^ {2} + b ^ {2} - c ^ {2}}{2 a b} \end{array} \right.
$$

适用范围:三边;两边及其夹角;两边及其一边的对角.

揭示规律:余弦定理指的是三角形中三条边与其中一个角的余弦之间的关系,它含有4个不同的量,知道其中三个量,就可求出第四个量.

## 2. 正弦定理

在一个三角形中, 各边和它所对角的正弦的比相等, 即在 $\triangle ABC$ 中, $\frac{a}{\sin A} = \frac{b}{\sin B} = \frac{c}{\sin C}$ .

适用范围:两角及一边;两边及一边的对角.

揭示规律:正弦定理刻画了三角形中边与角的一种数量关系,实现三角形中的边角关系的互化.

## 3. 正弦定理的变形

（1） $\frac{a}{\sin A}=\frac{b}{\sin B}=\frac{c}{\sin C}=2R.$ （R为△ABC外接圆半径）；

(2) a:b:c = sin A : sin B : sin C ;

(3) $a = 2R \sin A, b = 2R \sin B, c = 2R \sin C$ (R 为 $\triangle ABC$ 的外接圆半径);

（4） $\sin A = \frac{a}{2R},\sin B = \frac{b}{2R},\sin C = \frac{c}{2R}$ （ $R$ 为 $\triangle ABC$ 的外接圆半径）；

(5) $\frac{a + b + c}{\sin A + \sin B + \sin C} = \frac{a + b}{\sin A + \sin B} = \frac{a + c}{\sin A + \sin C} = \frac{b + c}{\sin B + \sin C} = 2R$ （ $R$ 为 $\triangle ABC$ 的外接圆半径）.

## 4. 三角形面积公式

公式 1: $S_{\triangle ABC} = \frac{1}{2} ab \sin C = \frac{1}{2} bc \sin A = \frac{1}{2} ac \sin B.$

公式 2: $S_{\triangle ABC} = \frac{1}{2} r(a + b + c)$ （ $r$ 为 $\triangle ABC$ 的内切圆半径）.

公式 3: $S_{\triangle ABC} = \frac{abc}{4R}$ （R 为 $\triangle ABC$ 的外接圆半径）.

## 5. 三角形中的边角关系

$a > b > c \Leftrightarrow \sin A > \sin B > \sin C \Leftrightarrow \angle A > \angle B > \angle C$ （大边对大角，大角对大边）.

## 6. 常用结论

在 $\triangle ABC$ 中， $\angle A + \angle B + \angle C = \pi$ ，则

(1) $\sin A = \sin (B + C),\cos A = -\cos (B + C),\tan A = -\tan (B + C).$

(2) $\sin \frac{A}{2} = \cos \frac{B + C}{2}, \cos \frac{A}{2} = \sin \frac{B + C}{2}$

(3) $\sin 2A = -\sin (2B + 2C), \cos 2A = \cos (2B + 2C) \tan 2A = -\tan (2B + 2C)$

(4) $\tan A + \tan B + \tan C = \tan A \tan B \tan C$
