>
> > [!success]- **【答案】** 8
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > 由权方和不等式可得: $1 = \frac{1}{a^2} + \frac{2^3}{b^2} + \frac{1}{c^2} \geqslant \frac{(1 + 2 + 1)^3}{(a + b + c)^2} \Rightarrow (a + b + c) \geqslant 8$ 当 $\frac{1}{a} = \frac{2}{b} = \frac{1}{c}$ 时, 即 $a = 2, b = 4, c = 2$ 时, 等号成立.
