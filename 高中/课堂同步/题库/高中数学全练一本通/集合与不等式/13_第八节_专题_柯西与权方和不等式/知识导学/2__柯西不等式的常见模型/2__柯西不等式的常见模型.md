## 2. 柯西不等式的常见模型

模型一： $(a + b)\left(\frac{m}{a} +\frac{n}{b}\right)\geqslant (\sqrt{m} +\sqrt{n})^2$ 其中 $a,b,m,n\in \mathbf{R}^{+}$ ，如 $(a + b)\left(\frac{1}{a} +\frac{1}{b}\right)\geqslant \left(\sqrt{a\cdot\frac{1}{a}} +\sqrt{b\cdot\frac{1}{b}}\right)^2 = 4$

模型二： $\frac{a}{x} +\frac{b}{1 - x} = [(x) + (1 - x)]\left(\frac{a}{x} +\frac{b}{1 - x}\right)\geqslant (\sqrt{a} +\sqrt{b})^2$

模型三:一高一低和式配凑类型

已知 $x^{2} + y^{2}$ 的值，求 $x + y$ 的取值范围，或者已知 $x + y$ 的值，求 $2x^{2} + 3y^{2}$ 的最值或者求 $\sqrt{x} +\sqrt{y}$ 的最值，即 $\left(x^{2} + y^{2}\right)\left(m^{2} + n^{2}\right)\geqslant (mx + ny)^{2}$ ，例如 $\left(a^2 +b^2\right)\cdot (1 + 1)\geqslant (a + b)^2$ 或者写成 $\sqrt{\frac{a^2 + b^2}{2}}\geqslant \frac{a + b}{2}$

## 模型四: 同次积式配凑类型

已知 $xy$ 值， $(x + m)(y + n)(m, n \in \mathbf{R}^{+})$ 的最值，利用 $(x + m)(y + n) \geqslant (\sqrt{xy} + \sqrt{mn})^{2}$ 求最值.

注意:用柯西不等式求最值的核心在于凑出柯西不等式的形式和凑出定值.常用于一些带有平方和的结构或者二次根式和的结构求最值.
