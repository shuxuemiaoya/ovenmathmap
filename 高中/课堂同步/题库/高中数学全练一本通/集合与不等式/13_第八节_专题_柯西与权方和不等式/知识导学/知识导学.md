## 知识导学

## 1. 柯西不等式

柯西不等式是法国著名的数学家、物理学家、天文学家柯西发现的, 故命名为柯西不等式. 柯西不等式是数学中一个非常重要的不等式, 除了用柯西不等式来证明一些不等式成立外, 柯西不等式还常用于选择、填空求最值的问题中, 借助柯西不等式的技巧可以达到事半功倍的效果.

（1）二维形式的柯西不等式： $\left(a_1^2 +a_2^2\right)\left(b_1^2 +b_2^2\right)\geq \left(a_1b_1 + a_2b_2\right)^2$ ，当且仅当 $\frac{a_1}{b_1} = \frac{a_2}{b_2}$ 时等号成立.

（2）三维形式的柯西不等式： $\left(a_{1}^{2} + a_{2}^{2} + a_{3}^{2}\right)\left(b_{1}^{2} + b_{2}^{2} + b_{3}^{2}\right)\geq \left(a_{1}b_{1} + a_{2}b_{2} + a_{3}b_{3}\right)^{2}$ ，当且仅当 $\frac{a_1}{b_1} = \frac{a_2}{b_2} = \frac{a_3}{b_3}$ 等号成立.

## 2. 柯西不等式的常见模型

模型一： $(a + b)\left(\frac{m}{a} +\frac{n}{b}\right)\geqslant (\sqrt{m} +\sqrt{n})^2$ 其中 $a,b,m,n\in \mathbf{R}^{+}$ ，如 $(a + b)\left(\frac{1}{a} +\frac{1}{b}\right)\geqslant \left(\sqrt{a\cdot\frac{1}{a}} +\sqrt{b\cdot\frac{1}{b}}\right)^2 = 4$

模型二： $\frac{a}{x} +\frac{b}{1 - x} = [(x) + (1 - x)]\left(\frac{a}{x} +\frac{b}{1 - x}\right)\geqslant (\sqrt{a} +\sqrt{b})^2$

模型三:一高一低和式配凑类型

已知 $x^{2} + y^{2}$ 的值，求 $x + y$ 的取值范围，或者已知 $x + y$ 的值，求 $2x^{2} + 3y^{2}$ 的最值或者求 $\sqrt{x} +\sqrt{y}$ 的最值，即 $\left(x^{2} + y^{2}\right)\left(m^{2} + n^{2}\right)\geqslant (mx + ny)^{2}$ ，例如 $\left(a^2 +b^2\right)\cdot (1 + 1)\geqslant (a + b)^2$ 或者写成 $\sqrt{\frac{a^2 + b^2}{2}}\geqslant \frac{a + b}{2}$

## 模型四: 同次积式配凑类型

已知 $xy$ 值， $(x + m)(y + n)(m, n \in \mathbf{R}^{+})$ 的最值，利用 $(x + m)(y + n) \geqslant (\sqrt{xy} + \sqrt{mn})^{2}$ 求最值.

注意:用柯西不等式求最值的核心在于凑出柯西不等式的形式和凑出定值.常用于一些带有平方和的结构或者二次根式和的结构求最值.

## 3. 权方和不等式

对柯西不等式变形，易得 $\left(\frac{a^{2}}{x}+\frac{b^{2}}{y}\right)(x+y)\geqslant(a+b)^{2}$ ，在a,b,x,y>0时，易得 $\frac{a^{2}}{x}+\frac{b^{2}}{y}\geqslant\frac{(a+b)^{2}}{x+y}$ ，当 $\frac{a}{x}=\frac{b}{y}$ 时，等号成立.

## （1）权方和不等式最简形式：

当 $a, b, x, y > 0$ 时， $\frac{a^2}{x} + \frac{b^2}{y} \geqslant \frac{(a + b)^2}{x + y}$ ，当 $\frac{a}{x} = \frac{b}{y}$ 时，等号成立。（权方和不等式的最简二元形式）

同理: $\frac{a^2}{x} + \frac{b^2}{y} + \frac{c^2}{z} \geqslant \frac{(a + b + c)^2}{x + y + z}$ , 当 $\frac{a}{x} = \frac{b}{y} = \frac{c}{z}$ 时, 等号成立. (权方和不等式的最简三元形式)

## （2）权方和不等式的一般形式：

$\frac{x_{1}^{m+1}}{y_{1}^{m}}+\frac{x_{2}^{m+1}}{y_{2}^{m}}+\cdots+\frac{x_{n}^{n+1}}{y_{n}^{m}}\geqslant\frac{\left(x_{1}+x_{2}+\cdots+x_{n}\right)^{m+1}}{\left(y_{1}+y_{2}+\cdots+y_{n}\right)^{m}}$ ，当且仅当 $\frac{x_{1}}{y_{1}}=\frac{x_{2}}{y_{2}}=\cdots=\frac{x_{n}}{y_{n}}$ 时，取等号，其中 $m,x_{i},y_{i}\in\mathrm{R}^{+}(i=1,2,\cdots,n)$ .

权方和不等式的特征是分子的幂指数比分母的幂指数高1次. 高考阶段只需要掌握二元和三元形式, 二元变量的权方和不等式, 用于“知和求和型”求最值, 有时候比“1”代换简便一些.
