## 知识导学

## 1. 分式不等式解法

方法一:移项通分,化分式为整式

解分式不等式的基本思想是化分式不等式为整式不等式或整式不等式组.注意转化时的等价性.

$$
\frac {A}{B} > 0 \Leftrightarrow A \cdot B > 0; \frac {A}{B} <   0 \Leftrightarrow A \cdot B <   0; \frac {A}{B} \geq 0 \Leftrightarrow \left\{ \begin{array}{l} B \neq 0 \\ A \cdot B \geq 0 \end{array} ; \frac {A}{B} \leq 0 \Leftrightarrow \left\{ \begin{array}{l} B \neq 0 \\ A \cdot B \leq 0 \end{array} \right. \right.
$$

注意当分式右侧不为 0 时, 可通过移项、通分合并的手段将右侧变为 0; 当分母符号确定时, 可利用不等式的形式直接去分母

方法二:根据分式的性质,讨论分子分母的符号

（1）分式值为正或大于0：分子分母同号： $\left\{\begin{aligned}A&>0\\ B&>0\end{aligned}\right.$ 或 $\left\{\begin{aligned}A&<0\\ B&<0\end{aligned}\right.$

（2）分式值为负或小于0：分子分母异号： $\left\{\begin{aligned}A<0\\ B>0\end{aligned}\right.$ 或 $\left\{\begin{aligned}A>0\\ B<0\end{aligned}\right.$

## 2. 绝对值不等式的解法

(1) $|x| > m$ 和 $|x| \leqslant m$ 型不等式的解法

①当 $m \geqslant 0$ 时, 不等式 $|x| > m$ 等价于 x > m 或 x < -m; 不等式 $|x| \leqslant m$ 等价于 $-m \leqslant x \leqslant m$ .

②当 m<0 时， $|x|>m$ 的解集为 R, $|x|\leqslant m$ 的解集为 $\varnothing$ .

(2) $|ax + b| \leqslant c$ 和 $|ax + b| \geqslant c$ 型不等式的解法

①当 $c \geqslant 0$ ，不等式 $|ax + b| \leqslant c$ 等价于 $-c \leqslant ax + b \leqslant c, |ax + b| \geqslant c$ 等价于 $ax + b \geqslant c$ 或 $ax + b \leqslant -c$

②当 c<0 ，不等式 $\left|ax+b\right|\leqslant c$ 的解集为 $\varnothing,\left|ax+b\right|\geqslant c$ 的解集为 R .

(3) $|x - a| + |x - b| \geqslant c (c > 0), |x - a| + |x - b| \leqslant c (c > 0)$ 型不等式的解法

零点分段法：

①令每个绝对值号内的代数式为零,并求出相应的根;

②将这些根按从小到大的顺序排列, 把实数集分为若干个区间;

③在所分区间内去掉绝对值号得若干个不等式, 解这些不等式, 求出解集;

④取各个不等式解集的并集就是原不等式的解集.

## 3. 高次不等式的解法

解高次不等式的步骤：

（1）标准化：通过移项、通分等方法将不等式左侧化为未知数的整式, 右侧化为 0 的形式;

（2）分解因式: 将不等式左侧化为若干个因式 （一次因式或高次因式不可约因式）的乘积, 如

$(x-x_{1})(x-x_{2})\cdots(x-x_{n})\geq0$ 的形式, 其中各因式中未知数的系数为正;

（3）求根：求如 $(x - x_{1})(x - x_{2})\dots (x - x_{n}) = 0$ 的根，并在数轴上表示出来（按照从小到大的顺序标注）

（4）穿线:从右上方穿线,经过数轴上表示各根的点，（奇穿偶不穿：经过偶次根时应从数轴的一侧仍回到这一侧,经过奇数次根时应从数轴的一侧穿过到达数轴的另一侧）

（5）得解集：若不等式 “>0”，则找 “线” 在数轴上方的区间若不等式 “<0”，则找 “线” 在数轴下方的区间
