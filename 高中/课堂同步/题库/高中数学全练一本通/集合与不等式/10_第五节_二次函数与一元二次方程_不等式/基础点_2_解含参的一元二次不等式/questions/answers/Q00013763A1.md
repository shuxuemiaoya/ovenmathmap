> > [!note]- **【解析】**
> > 解析：当 a=0 时, 原不等式为 -2>0 , 该不等式的解集为 $\varnothing$ .
> > 当 $a \neq 0$ 时， $2a^{2} > 0$ ，原不等式可化为 $(2ax + 1)(ax - 2) > 0$ .
> > 对应方程两根为 $x_{1}=-\frac{1}{2a}$ ， $x_{2}=\frac{2}{a}$ （或通过判别式公式法解出对应方程两根）
> > - **①**：若 a<0，则 $-\frac{1}{2a}>\frac{2}{a}$ ，原不等式的解集为 $\left\{x\mid x<\frac{2}{a}\text{ 或 }x>-\frac{1}{2a}\right\}$ ;
> > - **②**：若 a > 0，则 $-\frac{1}{2a} < \frac{2}{a}$ ，原不等式的解集为 $\left\{x \mid x < -\frac{1}{2a} \text{ 或 } x > \frac{2}{a}\right\}$ .
> > 综上, 当 a = 0 时, 原不等式的解集为 $\varnothing$ ;
> > 当 a < 0 时, 原不等式的解集为 $\left\{x \mid x < \frac{2}{a} \text{ 或 } x > -\frac{1}{2a}\right\}$ ;
> > 当 a > 0 时, 原不等式的解集为 $\left\{x \mid x < -\frac{1}{2a} \text{ 或 } x > \frac{2}{a}\right\}$ .
