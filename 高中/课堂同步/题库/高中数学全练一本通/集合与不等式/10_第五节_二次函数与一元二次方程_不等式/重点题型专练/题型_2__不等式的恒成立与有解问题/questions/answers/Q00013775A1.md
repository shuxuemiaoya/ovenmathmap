> [!faq]- 全练一本通解析
>
> > [!success]- **【答案】** $x < -1 - \sqrt{3}$ 或 $-1 + \sqrt{3} < x < 2$ 或 $x > 2$
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > 不等式 $x^{2} + px > 4x + p - 4$
> > 等价于 $p(x-1)+(x^{2}-4x+4)>0$ ，
> > 设关于 p 的一次函数 $y=(x-1)p+(x^{2}-4x+4)$ ,
> > 因为 $0 \leq p \leq 6$ 时不等式 $(x - 1)p + (x^2 - 4x + 4) > 0$ 恒成立，
> > 即 $\left\{\begin{aligned}x^{2}-4x+4&>0\\ 6(x-1)+(x^{2}-4x+4)&>0\end{aligned}\right.$
> > 解得 $x < -1 - \sqrt{3}$ 或 $-1 + \sqrt{3} < x < 2$ 或 x > 2 ;
> > 所以实数 $x$ 的取值范围是 $x < -1 - \sqrt{3}$ 或 $-1 + \sqrt{3} < x < 2$ 或 $x > 2$ ：
> > $$
> > - 3 <   x <   - \frac {3}{2} \text {或} - \frac {1}{2} <   x <   1
> > $$
> > 解析: 因为不等式 $(a-3)x^{2}+2(a-3)x-6<0$ 对一切 $-5\leq a\leq5$ 恒成立
> > 所以 $(x^{2} + 2x)a - 3x^{2} - 6x - 6 < 0$ 对一切 $-5\leq a\leq 5$ 恒成立
> > 设关于 $a$ 的一次函数 $y = (x^{2} + 2x)a - 3x^{2} - 6x - 6$ ，则
> > $$
> > \left\{ \begin{array}{l} (x ^ {2} + 2 x) (- 5) - 3 x ^ {2} - 6 x - 6 <   0 \\ (x ^ {2} + 2 x) \cdot 5 - 3 x ^ {2} - 6 x - 6 <   0 \end{array} \right.
> > $$
> > 所以 $-3 < x < -\frac{3}{2}$ 或 $-\frac{1}{2} < x < 1$
> > 所以 x 的取值范围为 $-3 < x < -\frac{3}{2}$ 或 $-\frac{1}{2} < x < 1$ .
