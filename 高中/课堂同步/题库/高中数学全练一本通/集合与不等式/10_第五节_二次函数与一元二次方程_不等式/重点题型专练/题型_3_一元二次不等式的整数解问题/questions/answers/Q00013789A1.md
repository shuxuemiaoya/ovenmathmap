> > [!note]- **【解析】**
> > 解析：由 $(ax - 1)^2 < 4x^2$ 恰有3个整数解，即 $\left[(a + 2)x - 1\right]\left[(a - 2)x - 1\right] < 0$ 恰有3个整数解，所以 $(a + 2)(a - 2) > 0$ ，解得 $a > 2$ 或 $a < -2$ 。当 $a > 2$ 时，不等式解集为 $\left\{x \mid \frac{1}{a + 2} < x < \frac{1}{a - 2}\right\}$ ，因为 $0 < \frac{1}{a + 2} < \frac{1}{4}$ ，故3个整数解为1,2和3。则 $3 < \frac{1}{a - 2} \leq 4$ ，即 $3a - 6 < 1 \leq 4a - 8$ ，解得是 $\frac{9}{4} \leq a < \frac{7}{3}$ ；当 $a < -2$ 时，不等式解集为 $\left\{x \mid \frac{1}{a + 2} < x < \frac{1}{a - 2}\right\}$ ，因为 $-\frac{1}{4} < \frac{1}{a - 2} < 0$ ，故3个整数解为-1，-2，-3，则 $-4 \leq \frac{1}{a + 2} < -3$ ，即 $-3(a + 2) < 1 \leq -4(a + 2)$ ，解得 $-\frac{7}{3} < a \leq -\frac{9}{4}$ 。综上所述，实数 $a$ 的取值范围为 $-\frac{7}{3} < a \leq -\frac{9}{4}$ 或 $\frac{9}{4} \leq a < \frac{7}{3}$ 。
> >
> > 故选 **C**
