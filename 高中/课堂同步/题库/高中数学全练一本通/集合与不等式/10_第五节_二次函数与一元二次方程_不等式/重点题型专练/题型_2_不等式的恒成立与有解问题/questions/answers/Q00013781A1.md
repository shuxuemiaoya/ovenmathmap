> > [!success] **【答案】** $a \geq \frac{5}{2}$
>
> > [!note]- **【解析】**
> > 解析：当 $1 \leq x \leq 2$ 时，不等式 $x^2 - ax + 1 \leq 0$ 恒成立，所以当 $1 \leq x \leq 2$ 时，$a \geq \frac{x^2 + 1}{x} = x + \frac{1}{x}$ 恒成立，则 $a \geq \left(x + \frac{1}{x}\right)_{\max}$，令 $y = x + \frac{1}{x}$，则 $y = x + \frac{1}{x}$ 在 $1 \leq x \leq 2$ 上，根据对勾函数的图像与性质，所以 $y_{\max} = 2 + \frac{1}{2} = \frac{5}{2}$，所以 $a \geq \frac{5}{2}$。故答案为：$a \geq \frac{5}{2}$.
