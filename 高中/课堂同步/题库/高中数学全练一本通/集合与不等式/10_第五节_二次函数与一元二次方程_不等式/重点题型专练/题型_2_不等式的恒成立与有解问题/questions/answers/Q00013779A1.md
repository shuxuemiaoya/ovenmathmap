> [!success]- 全练一本通
>
> > [!success] **【答案】** $a \leq 0$
>
> > [!note]- **【解析】**
> > 解析：命题“任意 $-2 \leq x \leq 1$，$x^2 + 2a > 0$”为假命题，等价于命题“存在 $-2 \leq x \leq 1$，$x_0^2 + 2a \leq 0$”为真命题，所以存在 $-2 \leq x \leq 1$，$x_0^2 \leq -2a$，所以 $(x_0^2)_{\min} \leq -2a$，则 $0 \leq -2a$，所以 $a \leq 0$。故答案为：$a \leq 0$.
