## ▶基础点 2: 解含参的一元二次不等式

含参数的一元二次不等式讨论依据：
1. 对二次项系数进行大于 0, 小于 0, 等于 0 分类讨论；
2. 当二次项系数不等于 0 时, 再对判别式进行大于 0, 小于 0, 等于 0 的分类讨论；
3. 当判别式大于 0 时, 再对两根的大小进行讨论, 最后确定出解集.
