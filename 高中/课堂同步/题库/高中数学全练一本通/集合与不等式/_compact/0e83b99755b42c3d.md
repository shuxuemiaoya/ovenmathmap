题型4:主参换位问题观察上文例题,我们发现都是给出x的取值范围,求解参数m的取值范围.但对于给出参数m的取值范围,反向求解x的取值范围,我们又将如何应对?对于这类问题我们的方法是用主参换位法,即把x看作参数,m看作主元,把变元与参数交换位置,构造以参数为变量的函数,根据原变量的取值范围列式求解,常见的是转化为关于m的一次函数 $y = xm + n$  在 $a \leq m \leq b$ 恒成立问题,若y&gt;0恒成立 $\Leftrightarrow \begin{cases} ax + n > 0 \\ bx + n > 0 \end{cases}$ ,若y&lt;0恒成立 $\Leftrightarrow \begin{cases} ax + n < 0 \\ bx + n < 0 \end{cases}$
