> > [!success] **【答案】** （1） \( \{x | -5 < x < 8\} \)；（2）-2 或 1
>
> > [!note]- **【解析】**
> > 解析：（1）当 \( m = -2 \) 时，\( B = \{x | -5 < x < 1\} \)，则 \( A \cup B = \{x | -2 < x < 8\} \cup \{x | -5 < x < 1\} = \{x | -5 < x < 8\} \)；（2）因为 \( A = \{x | -2 < x < 8\} \)，\( 8 - (-2) = 10 \)，\( A \cap B = \{x | a < x < b\} \)，且 \( b - a = 3 \)，①当 \( A \cap B = B \) 时，则 \( m + 3 - (2m - 1) = 3 \)，解得 \( m = 1 \)，此时 \( B = \{x | 1 < x < 4\} \)，此时 \( A \cap B = \{x | 1 < x < 4\} \)，满足题意；
> > - **②**：当 \( A \cap B = \{x | 2m - 1 < x < 8\} \) 时，有 \( 8 - (2m - 1) = 3 \)，解得 \( m = 3 \)，则 \( B = \{x | 5 < x < 6\} \)，此时 \( A \cap B = \{x | 5 < x < 6\} \)，不满足题意，舍去；
> > - **③**：当 \( A \cap B = \{x | -2 < x < m + 3\} \) 时，有 \( m + 3 - (-2) = 3 \)，解得 \( m = -2 \)，此时 \( B = \{x | -5 < x < 1\} \)，\( A \cap B = \{x | -2 < x < 1\} \)，满足题意. 综上，实数 \( m \) 的值为 -2 或 1.
