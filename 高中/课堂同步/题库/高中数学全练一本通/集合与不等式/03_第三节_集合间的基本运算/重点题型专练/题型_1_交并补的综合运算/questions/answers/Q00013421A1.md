> > [!note]- **【解析】**
> > 解析：$U = R, A = \left\{ x \mid x \geq 0 \right\}, B = \left\{ x \mid -1 < x < 1 \right\}$ , $C_{U}A=\left\{x|x<0,\left(C_{U}A\right)\cap B=\left\{x|-1<x<0\right.\right.$ ，B选项正确；
> >
> > $A \cup B = \left\{ x \mid x > -1 \right\}$ ， $A \cap (\complement_{\mathrm{U}} B) = \left\{ x \mid x \geq 1 \right\}$ ， $\complement_{\mathrm{U}}(A \cap B) = \left\{ x \mid x < 0 \text{ 或 } x \geq 1 \right\}$ ，ACD选项都不符合。
> >
> > 故选 **B**
