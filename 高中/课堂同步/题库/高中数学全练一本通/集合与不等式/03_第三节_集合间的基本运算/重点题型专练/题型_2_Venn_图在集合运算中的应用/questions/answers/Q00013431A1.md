> > [!success] **【答案】** $\{-3, -1, 0, 1, 2\}$
>
> > [!note]- **【解析】**
> > 解析：全集 $U = \{x \in \mathbf{Z} | -5 < x \leq 4\} = \{-4, -3, -2, -1, 0, 1, 2, 3, 4\}$ ， $A \cap B = \emptyset$ ，则 $(\complement_U A) \cap B = B = \{-2, 3\}$ ， $(\complement_U B) \cap A = A = \{-4, 4\}$ ，所以 $(\complement_U A) \cap (\complement_U B) = \{-3, -1, 0, 1, 2\}$ . 故答案为： $\{-3, -1, 0, 1, 2\}$ .
