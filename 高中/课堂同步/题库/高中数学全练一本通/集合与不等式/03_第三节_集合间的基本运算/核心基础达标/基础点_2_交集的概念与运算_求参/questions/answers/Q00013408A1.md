> > [!success] **【答案】** $1 \leq a < 2$
>
> > [!note]- **【解析】**
> > 因为 $M = \{-2, -1, 0, 1\}$ ， $N = \{x \mid a - 3 < x < 1\}$ ，若 $M \cap N$ 中有 2 个元素，所以 $M \cap N = \{-1, 0\}$ ，所以 $-2 \leq a - 3 < -1$ ，解得 $1 \leq a < 2$ ，则实数 a 的取值范围是 $1 \leq a < 2$ 。
