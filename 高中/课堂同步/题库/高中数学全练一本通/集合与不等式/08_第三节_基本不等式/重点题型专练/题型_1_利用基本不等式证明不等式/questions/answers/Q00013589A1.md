> > [!note]- **【解析】**
> > 解析：因为 $a, b, c$ 都为正实数，且 $a + b + c = 1$ ，
> >
> > 所以 $(a + \frac{1}{a}) + (b + \frac{1}{b}) + (c + \frac{1}{c}) = (a + \frac{a + b + c}{a}) + (b + \frac{a + b + c}{b}) + (c + \frac{a + b + c}{c}) = 4 + (\frac{b}{a} + \frac{a}{b}) + (\frac{c}{a} + \frac{a}{c}) + (\frac{c}{b} + \frac{b}{c}) \geqslant 4 + 2\sqrt{\frac{b}{a} \cdot \frac{a}{b}} + 2\sqrt{\frac{c}{a} \cdot \frac{a}{c}} + 2\sqrt{\frac{c}{b} \cdot \frac{b}{c}} = 4 + 2 + 2 + 2 = 10$ ，当且仅当 $a = b = c = \frac{1}{3}$ 时取等号，所以 $\left(a + \frac{1}{a}\right) + \left(b + \frac{1}{b}\right) + \left(c + \frac{1}{c}\right) \geqslant 10$ 。
