> > [!success] **【答案】** （1）证明见解析；（2）证明见解析.
>
> > [!note]- **【解析】**
> > 解析：（1） $\frac{a^2}{b} + \frac{b^2}{c} + \frac{c^2}{a} + (a + b + c) = \left(\frac{a^2}{b} + b\right) + \left(\frac{b^2}{c} + c\right) + \left(\frac{c^2}{a} + a\right) \geqslant 2\sqrt{\frac{a^2}{b} \cdot b} + 2\sqrt{\frac{b^2}{c} \cdot c} + 2\sqrt{\frac{c^2}{a} \cdot a} = 2(a + b + c)$ ，当且仅当 $a = b = c$ 时等号成立，所以 $\frac{a^2}{b} + \frac{b^2}{c} + \frac{c^2}{a} \geqslant a + b + c$ 。
> >
> > （2） $a + b + c = \frac{1}{2}(a + b) + \frac{1}{2}(b + c) + \frac{1}{2}(a + c) \geqslant \sqrt{ab} + \sqrt{bc} + \sqrt{ca}$ ，当且仅当 $a = b = c$ 时等号成立，因为 $a, b, c$ 为不全相等的正实数，所以 $a + b + c > \sqrt{ab} + \sqrt{bc} + \sqrt{ca}$ .
