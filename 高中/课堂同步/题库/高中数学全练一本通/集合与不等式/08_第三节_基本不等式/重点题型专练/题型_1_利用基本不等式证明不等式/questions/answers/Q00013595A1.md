> > [!success] **【答案】** （1）证明见解析 （2）证明见解析
>
> > [!note]- **【解析】**
> > 解析：(1) $\frac{b + c}{a} + \frac{a + c}{b} + \frac{a + b}{c}$ $=\frac{b}{a} + \frac{c}{a} + \frac{a}{b} + \frac{c}{b} + \frac{a}{c} + \frac{b}{c}$ $=\frac{b}{a} + \frac{a}{b} + \frac{c}{a} + \frac{a}{c} + \frac{c}{b} + \frac{b}{c}$ ∵ a > 0, b > 0, c > 0, $\frac{b}{a} + \frac{a}{b} \geq 2\sqrt{\frac{b}{a} \cdot \frac{a}{b}} = 2$ , $\frac{c}{a} + \frac{a}{c} \geq 2\sqrt{\frac{c}{a} \cdot \frac{a}{c}} = 2$ , $\frac{c}{b} + \frac{b}{c} \geq 2\sqrt{\frac{c}{b} \cdot \frac{b}{c}} = 2$ 当且仅当 a = b = c 时, 等号成立.
> >
> > ∴ $\frac{b + c}{a} + \frac{a + c}{b} + \frac{a + b}{c} \geq 6$ ;
> >
> > （2）∵ $b^{2} + c^{2} \geq 2bc$ , a > 0, ∴ $a(b^{2} + c^{2}) \geq 2abc$ , 当且仅当 b = c 时, 等号成立;
> >
> > ∵ $a^{2} + c^{2} \geq 2ac$ , b > 0, ∴ $b(a^{2} + c^{2}) \geq 2abc$ , 当且仅当 a = c 时, 等号成立;
> >
> > ∵ $a^{2} + b^{2} \geq 2ab$ , a > 0, ∴ $c(a^{2} + b^{2}) \geq 2abc$ , 当且仅当 a = b 时, 等号成立;
> >
> > 累加, 得 $a(b^{2} + c^{2}) + b(a^{2} + c^{2}) + c(a^{2} + b^{2}) \geq 6abc$ , 证毕.
