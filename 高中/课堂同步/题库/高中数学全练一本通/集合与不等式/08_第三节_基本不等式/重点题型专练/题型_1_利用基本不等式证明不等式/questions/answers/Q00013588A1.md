>
> > [!note]- **【解析】**
> > 解析：因为 $a^2 + b^2 \geqslant 2ab, b^2 + c^2 \geqslant 2bc, c^2 + a^2 \geqslant 2ac$ ，当且仅当 $a = b = c$ 时，取等号，
> >
> > 又 $abc = 1$ ，
> >
> > 故有 $a^2 + b^2 + c^2 \geqslant ab + bc + ca = \frac{ab + bc + ca}{abc} = \frac{1}{a} + \frac{1}{b} + \frac{1}{c}$ .
> >
> > 所以 $\frac{1}{a} + \frac{1}{b} + \frac{1}{c} \leqslant a^2 + b^2 + c^2$ ，当且仅当 $a = b = c = 1$ 时取等号.
