>
> > [!note]- **【解析】**
> > 解析：由题设 $2a + 2b + 2c = (a + b) + (a + c) + (b + c) = 2$ ,
> >
> > 又 $(a + b) + (a + c) + (b + c) = 2 \geq 2\sqrt{ab} + 2\sqrt{ac} + 2\sqrt{bc}$ ,
> >
> > 当且仅当 $a = b = c = \frac{1}{3}$ 时等号成立,
> >
> > 所以 $\sqrt{ab} + \sqrt{bc} + \sqrt{ac} \leq 1$ , 得证.
