> > [!success] **【答案】** 3
>
> > [!note]- **【解析】**
> > 解析：由 $a + b = 2$ 得， $a + (b + 1) = 3$ ，
> >
> > 所以 $\frac{1}{a} + \frac{4}{b + 1} = \frac{1}{3}[a + (b + 1)]\left(\frac{1}{a} + \frac{4}{b + 1}\right) = \frac{1}{3}\left(5 + \frac{b + 1}{a} + \frac{4a}{b + 1}\right) \geq$ $\frac{1}{3}\left(5 + 2\sqrt{\frac{b+1}{a} \times \frac{4a}{b+1}}\right) = 3$ ，（当且仅当 $\frac{b+1}{a} = \frac{4a}{b+1}$ ，即 a = 1，b = 1 时取得等号）。故答案为：3
