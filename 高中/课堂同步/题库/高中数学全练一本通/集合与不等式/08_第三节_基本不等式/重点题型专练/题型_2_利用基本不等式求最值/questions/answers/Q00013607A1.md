> > [!success] **【答案】** B
>
> > [!note]- **【解析】**
> > 解析：因为 m > 0, n > 0, m + n = 1，
> >
> > 则 $\frac{1}{m} + \frac{2}{n} = (\frac{1}{m} + \frac{2}{n})(m + n) = 3 + \frac{n}{m} + \frac{2m}{n} \geq 3 + 2\sqrt{\frac{n}{m} \cdot \frac{2m}{n}} = 3 + 2\sqrt{2}$ ，当且仅当 $\frac{n}{m} = \frac{2m}{n}$ ，即 $n = 2 - \sqrt{2}, m = \sqrt{2} - 1$ 时，等号成立，所以 $\frac{1}{m} + \frac{2}{n}$ 的最小值为 $3 + 2\sqrt{2}$ 。
> >
> > 故选 **B**。
