>
> > [!success] **【答案】** 4
>
> > [!note]- **【解析】**
> > 解析：因为 $x > 0,y > 0,x + 2y + 2xy = 8$ $x + 2y + 2xy\leq (x + 2y) + \left(\frac{x + 2y}{2}\right)^2$ ，当且仅当 $x = 2y$ 时取等号，因此 $(x + 2y) + \left(\frac{x + 2y}{2}\right)^2\geq 8$ ，即 $(x + 2y)^2 +4(x + 2y) - 32\geq 0$ 化为 $(x + 2y + 8)(x + 2y - 4)\geq 0$ ，解得 $x + 2y\geq 4$ 或 $x + 2y\leq -8$ （舍去），由 $\left\{\begin{array}{l}x + 2y + 2xy = 8\\ x = 2y > 0\end{array}\right.$ 解得 $x = 2,y = 1$ ，所以当 $x = 2,y = 1$ 时， $x + 2y$ 取得最小值4.
