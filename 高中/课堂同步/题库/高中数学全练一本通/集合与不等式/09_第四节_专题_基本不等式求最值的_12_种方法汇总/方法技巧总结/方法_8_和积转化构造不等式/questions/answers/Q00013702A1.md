> > [!success] **【答案】** $\frac{2\sqrt{3}}{3}$
>
> > [!note]- **【解析】**
> > 解析：$1 = x^{2} + y^{2} + xy = (x + y)^{2} - xy\geq (x + y)^{2} - \left(\frac{x + y}{2}\right)^{2}$ 所以 $(x + y)^{2}\leq \frac{4}{3}$ ，即 $x + y\leq \frac{2\sqrt{3}}{3}$ ，当且仅当 $x = y$ ，且 $x^{2} + y^{2} + xy = 1$ ，即 $x = y = \frac{\sqrt{3}}{3}$ 时，等号成立，所以 $x + y$ 的最大值为 $\frac{2\sqrt{3}}{3}$
