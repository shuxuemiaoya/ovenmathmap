> [!success]- 全练一本通
>
> > [!success] **【答案】** $\frac{1}{6}$
>
> > [!note]- **【解析】**
> > 解析：由 $0 < x < \frac{1}{3}$ 得 0 < 3x < 1, -1 < -3x < 0, 0 < 1 - 3x < 1, 因为
> > 0 < 3x < 1, 0 < 1 - 3x < 1, 所以由基本不等式得 $\frac{3x+(1-3x)}{2}\geq\sqrt{3x(1-3x)}$ 整理得 $3x(1-3x)\leq\frac{1}{4}$ ，即 $3x(1-3x)\leq\frac{1}{4}$ ，即 $x(1-3x)\leq\frac{1}{12}$ ，当且仅当
> > 3x=1-3x 即 x= $\frac{1}{6}$ 时，等号成立，所以 $2x(1-3x)\leq2\times\frac{1}{12}=\frac{1}{6}$ . 故当 $x=\frac{1}{6}$ 时， $y=2x(1-3x)$ 的最大值为 $\frac{1}{6}$ . 故答案为 $\frac{1}{6}$ .
