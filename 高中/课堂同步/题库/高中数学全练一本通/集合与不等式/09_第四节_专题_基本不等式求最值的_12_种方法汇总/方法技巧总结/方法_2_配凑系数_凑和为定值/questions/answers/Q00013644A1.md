> > [!success] **【答案】** 16

> > [!note]- **【解析】**
> > 解析：因为实数 a > 0, b > 0，且 $4a + b = 12$ ，所以 $4(a + 1) + b = 16$ ，则 $16 = 4(a + 1) + b \geq 2\sqrt{4(a + 1)b} = 4\sqrt{(a + 1)b}$ ，所以 $\sqrt{(a + 1)b} \leq 4$ ，所以 $(a + 1)b \leq 16$ ，当且仅当 $4(a + 1) = b$ 即 a = 1, b = 8 时，等号成立，所以 $(a + 1)b$ 的最大值为 16。故答案为：16
