> > [!success] **【答案】** （1） $\frac{3+2\sqrt{2}}{5}$ （2）1
>
> > [!note]- **【解析】**
> > 解析：（1）由 $x+y=1$ 知 $2x+y+y+3=5$ ，
> >
> > 所以 $\frac{1}{2x+y}+\frac{2}{y+3}=\frac{1}{5}(2x+y+y+3)\left(\frac{1}{2x+y}+\frac{2}{y+3}\right)$ $=\frac{1}{5}\left[1+2+\frac{y+3}{2x+y}+\frac{2(2x+y)}{y+3}\right]\geq\frac{3}{5}+\frac{2\sqrt{2}}{5}$ 。仅当 $\frac{y+3}{2x+y}=\frac{2(2x+y)}{y+3}$ 时取等号。所以 $\frac{1}{2x+y}+\frac{2}{y+3}$ 的最小值为 $\frac{3+2\sqrt{2}}{5}$ 。
> >
> > （2）假设分式变形为 $\frac{\lambda}{\lambda(x+y)}+\frac{2\mu}{\mu(y+3)}$ 的形式，保证 x 的系数与 y 的系数之比等于整式中的系数之比，即 $\frac{\lambda}{\lambda + \mu} = \frac{2}{3}, \lambda = 2\mu$ 所以 $\mu = 1, \lambda = 2$ 分式变形为 $\frac{1}{x + y} + \frac{2}{y + 3} = \frac{2}{2x + 2y} + \frac{2}{y + 3}$ 具体解法如下：由 $2x + 3y = 5$ 知 $2x + 2y + y + 3 = 8$ 所以 $\frac{1}{x + y} + \frac{2}{y + 3} = \frac{2}{2x + 2y} + \frac{2}{y + 3} = \frac{1}{8}(2x + 2y + y + 3)$ $\left(\frac{2}{2x + 2y} + \frac{2}{y + 3}\right) = \frac{1}{8}\left[2 + 2 + \frac{2(y + 3)}{2x + 2y} + \frac{2(2x + 2y)}{y + 3}\right] \geqslant 1$ 当且仅当 $\frac{2(y + 3)}{2x + 2y} = \frac{2(2x + 2y)}{y + 3}$ 时取等号. 所以 $\frac{1}{x + y} + \frac{2}{y + 3}$ 的最小值是1.
