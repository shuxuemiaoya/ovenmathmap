> > [!success] **【答案】** $\frac{3 + 2\sqrt{3}}{3}$
>
> > [!note]- **【解析】**
> > 解析：由题可得 $b = 1 - a$ ： $\therefore \frac{2a}{a^2 + b} +\frac{b}{a + b^2} = \frac{2a}{a^2 + 1 - a} +\frac{1 - a}{a + (1 - a)^2} = \frac{a + 1}{a^2 - a + 1},$ 而 $\frac{a^2 - a + 1}{a + 1} = (a + 1) + \frac{3}{a + 1} -3\geqslant 2\sqrt{3} -3$ ，当且仅当 $a + 1 = \frac{3}{a + 1}$ ，即 $a = \sqrt{3} -1$ 时取等号，∴ $\frac{2a}{a^2 + b} +\frac{b}{a + b^2} = \frac{a + 1}{a^2 - a + 1}\leqslant \frac{1}{2\sqrt{3} -3} = \frac{2\sqrt{3} +3}{3}$ 即 $\frac{2a}{a^2 + b} +\frac{b}{a + b^2}$ 的最大值是 $\frac{3 + 2\sqrt{3}}{3}$ ，故答案为 $\frac{3 + 2\sqrt{3}}{3}$
