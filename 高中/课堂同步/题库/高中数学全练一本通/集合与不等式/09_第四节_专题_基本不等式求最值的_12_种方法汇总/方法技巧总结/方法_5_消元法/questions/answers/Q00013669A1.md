> > [!note]- **【解析】**
> > 解析：a, b 为正实数，且 $ab + 2a + b = 6$ ，故 $b = \frac{6 - 2a}{a + 1} = \frac{8}{a + 1} - 2$ ，
> > 故 $a + b = a + \frac{8}{a + 1} - 2 = a + 1 + \frac{8}{a + 1} - 3 \geq 4\sqrt{2} - 3$ ，当且仅当 $a + 1 = \frac{8}{a + 1}$ ，即 $a = 2\sqrt{2} - 1, b = 2\sqrt{2} - 2$ 时取等号，故 $a + b$ 的最小值为 $4\sqrt{2} - 3$ .
