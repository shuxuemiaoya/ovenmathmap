## 知识导学

1. 在用基本不等式求函数的最值时, 要满足三个条件: 一正二定三取等.

（1）一正:各项均为正数;

（2）二定:含变数的各项的和或积必须有一个为定值；

(3) 三取等: 含变数的各项均相等, 取得最值.

## 2. 积定和最小, 和定积最大

（1）设 x, y 为正实数, 若 $x + y = s$ （和 s 为定值）, 则当 x = y 时, 积 xy 有最大值, 且这个值为 $\frac{s^{2}}{4}$ .

（2）设 $x, y$ 为正实数，若 $xy = p$ （积 $p$ 为定值），则当 $x = y$ 时，和 $x + y$ 有最小值，且这个值为 $2\sqrt{p}$

## 3. 由基本不等式变形得到的常用结论

结论 1: $ab \leq \left( \frac{a + b}{2} \right)^{2} \leq \frac{a^{2} + b^{2}}{2} \quad (a, b \in R)$

结论 2: $\sqrt{ab} \leq \frac{a + b}{2} \leq \sqrt{\frac{a^2 + b^2}{2}} (a, b \in R^+)$

结论 3: $\frac{b}{a}+\frac{a}{b}\geq2$ （a,b 同号）

结论 $4:\frac{b}{a}+\frac{a}{b}\leq-2$ （a,b 同负）

结论 5: $a^{2} + b^{2} + c^{2} \geq ab + bc + ca$ ( $a, b, c \in R$ )

## 4. 重要的均值不等式链

若 $a > 0, b > 0$ ，则 $\frac{2}{\frac{1}{a} + \frac{1}{b}} \leq \sqrt{ab} \leq \frac{a + b}{2} \leq \sqrt{\frac{a^2 + b^2}{2}}$ 。（当且仅当 $a = b$ 时取“=”）
