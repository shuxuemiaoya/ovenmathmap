【18】比较下列两个代数式的大小.

(1) $x^{2} + 5x + 6$ 与 $2x^{2} + 5x + 9$ ;

(2) $3x^{2}+4x-3$ 与 $4x^{2}+5x+5$ ;

(3) $(x + 1)(x^{2} + \frac{x}{2} + 1)$ 与 $(x + \frac{1}{2})(x^{2} + x + 1)$ ;

(4) $\left(x^{2} - y^{2}\right)^{2}$ 与 $xy(x - y)^{2}$ ;

(5) $x^{6}+1$ 与 $x^{4}+x^{2}$ ;

(6) $x^{2} + y^{2}$ 与 $\frac{1}{2} -\frac{1}{x^2} +2y$

(7) $5x^{2}+y^{2}+z^{2}$ 与 $2xy+4x+2z-2$ .
