> > [!note]- **【解析】**
> > 解析：对于A，取 $a = 2,b = 1,m = 1$ ，满足 $a > b > 0$ ，且 $m > 0$ 此时 $\frac{a + m}{b + m} = \frac{3}{2},\frac{a}{b} = 2,\frac{a + m}{b + m} < \frac{a}{b}$ ，故A错误；对于B，取 $a = 2,b = 1,m = -3$ ，满足 $a > b > 0,m < 0$ 此时 $\frac{b + m}{a + m} = 2,\frac{b}{a} = \frac{1}{2}$ ，则 $\frac{b + m}{a + m} >\frac{b}{a}$ ，故B错误；对于C，因为 $\forall a > b > 0$ ，当 $m > 0$ 时， $a - b > 0,a + m > 0$ 所以 $\frac{b + m}{a + m} -\frac{b}{a} = \frac{(a - b)m}{a(a + m)} >0$ ，则 $\frac{b + m}{a + m} >\frac{b}{a}$ ，故C正确；对于D，存在 $a = 3,b = 1,m = 1,\frac{b - m}{a - m} = 0,\frac{b}{a} = \frac{1}{3}$ ，满足 $\frac{b - m}{a - m} < \frac{b}{a}$ ，故D正确.
> >
> > 故选 **CD**.
