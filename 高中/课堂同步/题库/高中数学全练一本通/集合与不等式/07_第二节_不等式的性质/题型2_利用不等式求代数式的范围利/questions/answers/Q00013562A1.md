> > [!success] **【答案】** （1） $0 \leq a \leq 3$ ， $1 \leq c \leq 7$ ；（2） $-1 \leq 9a - c \leq 20$ ：
>
> > [!note]- **【解析】**
> > 解析：（1）设 $a = m(a - c) + n(4a - c) = (m + 4n)a - (m + n)c$ 解析：（1）设 $a = m(a - c) + n(4a - c) = (m + 4n)a - (m + n)c$ ，则 $\left\{ \begin{array}{l}m + n = 0\\ m + 4n = 1 \end{array} \right.$ ，解得 $\left\{ \begin{array}{l}m = -\frac{1}{3}\\ n = \frac{1}{3} \end{array} \right.$ $\therefore a = -\frac{1}{3} (a - c) + \frac{1}{3} (4a - c),$ $\because -4\leq a - c\leq -1, - 1\leq 4a - c\leq 5.$ $\therefore \frac{1}{3}\leq -\frac{1}{3} (a - c)\leq \frac{4}{3}, - \frac{1}{3}\leq \frac{1}{3} (4a - c)\leq \frac{5}{3},$ $\therefore 0\leq -\frac{1}{3} (a - c) + \frac{1}{3} (4a - c)\leq 3$ $\therefore 0\leq a\leq 3$ 设 $c = m(a - c) + n(4a - c) = (m + 4n)a - (m + n)c$ 则 $\left\{ \begin{array}{l}m + n = -1\\ m + 4n = 0 \end{array} \right.$ ，解得 $\left\{ \begin{array}{l}m = -\frac{4}{3}\\ n = \frac{1}{3} \end{array} \right.$ $\therefore c = -\frac{4}{3} (a - c) + \frac{1}{3} (4a - c),$ $\therefore -4\leq a - c\leq -1, - 1\leq 4a - c\leq 5.$ $\therefore \frac{4}{3}\leq -\frac{4}{3} (a - c)\leq \frac{16}{3}, - \frac{1}{3}\leq \frac{1}{3} (4a - c)\leq \frac{5}{3},$ $\therefore 1\leq -\frac{4}{3} (a - c) + \frac{1}{3} (4a - c)\leq 7$
> >
> > （2）设 $9a - c = m(a - c) + n(4a - c) = (m + 4n)a - (m + n)c$ ，则 $\left\{ \begin{array}{l}m + n = 1\\ m + 4n = 9 \end{array} \right.$ ，解得 $\left\{ \begin{array}{l}m = -\frac{5}{3}\\ n = \frac{8}{3} \end{array} \right.$ $\therefore 9a - c = -\frac{5}{3} (a - c) + \frac{8}{3} (4a - c)$ $\because -4\leq a - c\leq -1, - 1\leq 4a - c\leq 5$ $\therefore \frac{5}{3}\leq -\frac{5}{3} (a - c)\leq \frac{20}{3}, - \frac{8}{3}\leq \frac{8}{3} (4a - c)\leq \frac{40}{3},$ $\therefore -1\leq -\frac{5}{3} (a - c) + \frac{8}{3} (4a - c)\leq 20$ $\therefore -1\leq 9a - c\leq 20$
