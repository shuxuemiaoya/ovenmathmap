>
> > [!success] **【答案】** （1） $-2 \leq a \leq 3$ ， $-\frac{7}{2} \leq b \leq \frac{3}{2}$ ；（2） $-4 \leq 3a - 2b \leq 11$
>
> > [!note]- **【解析】**
> > 解析：（1）由 $-3 \leq a + b \leq 2$ ， $-1 \leq a - b \leq 4$ ，
> >
> > 则 $a = \frac{1}{2}\Big[(a + b) + (a - b)\Big]$ ，所以 $-4\leq (a + b) + (a - b)\leq 6$
> >
> > 所以 $-2\leq \frac{1}{2}\Bigl [\bigl (a + b\bigr) + \bigl (a - b\bigr)\Bigr ]\leq 3$ ，即 $-2\leq a\leq 3$
> >
> > 即实数 $a$ 的取值范围为 $-2 \leq a \leq 3$
> >
> > 因为 $b=\frac{1}{2}\left[\left(a+b\right)-\left(a-b\right)\right]$ ,
> >
> > 由 $-1 \leq a - b \leq 4$
> >
> > 所以 $-4 \leq b - a \leq 1$ ，所以 $-7 \leq (a + b) - (a - b) \leq 3$ ，
> >
> > 所以 $-\frac{7}{2} \leq \frac{1}{2}\left[\left(a + b\right) - (a - b)\right] \leq \frac{3}{2}$
> >
> > $\therefore -\frac{7}{2} \leq b \leq \frac{3}{2}$ , 即实数 $b$ 的取值范围为 $-\frac{7}{2} \leq b \leq \frac{3}{2}$ .
> >
> > $$
> > 3 a - 2 b = m (a + b) + n (a - b) = (m + n) a + (m - n) b
> > $$
> >
> > 则 $\left\{\begin{aligned}m+n=3\\ m-n=-2\end{aligned}\right.$ ，解得 $\left\{\begin{aligned}m=\frac{1}{2}\\ n=\frac{5}{2}\end{aligned}\right.$
> >
> > ∴ $3a - 2b = \frac{1}{2}(a + b) + \frac{5}{2}(a - b)$ ,
> >
> > $$
> > \because - 3 \leq a + b \leq 2, - 1 \leq a - b \leq 4
> > $$
> >
> > $$
> > \therefore - \frac {3}{2} \leq \frac {1}{2} (a + b) \leq 1, - \frac {5}{2} \leq \frac {5}{2} (a - b) \leq 1 0
> > $$
> >
> > ∴ $-4 \leq 3a - 2b \leq 11$ ，即 3a - 2b 的取值范围为 $-4 \leq 3a - 2b \leq 11$ 。
