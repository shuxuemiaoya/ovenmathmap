> > 解析：因为 $3 <   a <   7,1 <   b <   10$ ，所以 $4 <   a + b <   17$ ，即 $a + b$ 的取值范围为 $4 <   a + b <   17$ 由 $9 <   3a <   21,2 <   2b <   20$ ，则- $20 <   - 2b <   - 2$ 所以- $11 <   3a - 2b <   19$ ，即 $3a - 2b$ 的取值范围为- $11 <   3a - 2b <   19$ 又由 $\frac{1}{7} <   \frac{1}{a} <   \frac{1}{3}$ 且 $1 <   b <   10$ ，可得 $\frac{1}{7} <   \frac{b}{a} <   \frac{10}{3}$ ，即 $\frac{b}{a}$ 的取值范围为 $\frac{1}{7} <   \frac{b}{a} <   \frac{10}{3}$
