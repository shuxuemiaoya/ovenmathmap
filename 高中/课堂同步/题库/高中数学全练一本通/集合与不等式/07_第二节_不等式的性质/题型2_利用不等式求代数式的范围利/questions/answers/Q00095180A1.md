>
> > [!success] **【答案】** $-\frac{3}{2} < 2a - b < \frac{5}{2}$
>
> > [!note]- **【解析】**
> > 解析：令 $2a - b = m(a + b) + n(b - a), m, n \in \mathbf{R}$ ,
> >
> > $$
> > (m - n) a + (m + n) b = 2 a - b
> > $$
> >
> > 则有 $\left\{\begin{aligned}m-n=2\\ m+n=-1\end{aligned}\right.$ ，解得 $\left\{\begin{aligned}m=\frac{1}{2}\\ n=-\frac{3}{2}\end{aligned}\right.$
> >
> > 而 $0 < a + b < 2, -1 < b - a < 1$
> >
> > 于是 $0 < \frac{a + b}{2} < 1, -\frac{3}{2} < -\frac{3}{2}(b - a) < \frac{3}{2}$ ,
> >
> > 所以 $-\frac{3}{2} < \frac{a + b}{2} - \frac{3}{2}(b - a) < 1 + \frac{3}{2}$ , 即 $-\frac{3}{2} < 2a - b < \frac{5}{2}$ ,
> >
> > 所以 $-\frac{3}{2} < 2a - b < \frac{5}{2}$
