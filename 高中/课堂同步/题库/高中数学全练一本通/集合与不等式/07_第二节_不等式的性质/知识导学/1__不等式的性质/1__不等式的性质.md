## 1. 不等式的性质

<table><tr><td></td><td>名称</td><td>性质内容</td><td>注意</td></tr><tr><td>性质1</td><td>对称性</td><td> $a > b \Leftrightarrow b < a$ </td><td>可逆</td></tr><tr><td>性质2</td><td>传递性</td><td> $a > b, b > c \Rightarrow a > c$ </td><td>同向</td></tr><tr><td>性质3</td><td>可加性</td><td> $a > b \Leftrightarrow a + c > b + c$ </td><td>可逆</td></tr><tr><td>性质4</td><td>移项法则</td><td> $a + b > c \Leftrightarrow a > c - b$ </td><td>可逆</td></tr><tr><td>性质5</td><td>同向可加性</td><td> $a > b, c > d \Rightarrow a + c > b + d$ </td><td>同向</td></tr><tr><td>性质6</td><td>可倒数性</td><td> $a > b > 0 \Rightarrow \frac{1}{a} < \frac{1}{b}$ </td><td>同向同正</td></tr><tr><td rowspan="2">性质7</td><td rowspan="2">可乘性</td><td> $a > b, c > 0 \Rightarrow ac > bc$ </td><td rowspan="2">c的正负</td></tr><tr><td> $a > b, c < 0 \Rightarrow ac < bc$ </td></tr><tr><td>性质8</td><td>同向同正可乘性</td><td> $a > b > 0, c > d > 0 \Rightarrow ac > bd$ </td><td>同向同正</td></tr><tr><td>性质9</td><td>可乘方性</td><td> $a > b > 0 \Rightarrow a^{n} > b^{n} (n \in \mathrm{N}, n > 1)$ </td><td>同正</td></tr><tr><td>性质10</td><td>可开方性</td><td> $a > b > 0 \Rightarrow \sqrt[n]{a} > \sqrt[n]{b} (n \in \mathrm{N}, n > 1)$ </td><td>同正</td></tr></table>
