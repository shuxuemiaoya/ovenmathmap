> > [!note]- **【解析】**
> > 解析：（1）由 $x - 3 = 0 \Rightarrow (x - 2)(x - 3) = 0$ ，但 $x - 3 = 0 \Rightarrow (x - 2)(x - 3) = 0$ ，故 $p$ 是 $q$ 的充分不必要条件。
> > （2）“两个三角形相似”不能推出“两个三角形全等”，但“两个三角形全等”能推出“两个三角形相似”，故 $p$ 是 $q$ 的必要不充分条件。
> > （3）由不等式的性质，可知： $a > b$ 不能推出 $ac > bc$ ，且 $ac > bc$ 不能推出 $a > b$ ，故 $p$ 是 $q$ 的既不充分也不必要条件。
> > （4）若 $A \cup B = B$ ，则 $A \subseteq B$ ；因为空集是任意集合的子集，所以由 $A = \emptyset$ 能推出 $A \subseteq B$ ；反之，不一定成立；所以 $p$ 是 $q$ 的充分不必要条件；
> > （5）根据交集的概念， $A \cap B = \{x | x \in A \text{且 } x \in B\}$ ，所以由 $p: x \in A$ 不能推出 $q: x \in A \cap B$ ；由 $q: x \in A \cap B$ 能推出 $p: x \in A$ ；因此 $p$ 是 $q$ 的必要不充分条件。
> > （6）因为 $a, b$ 都是奇数能推出 $a + b$ 为偶数，而 $a + b$ 为偶数不能推出 $a, b$ 都是奇数，所以 $p$ 是 $q$ 的充分不必要条件。
> > （7）因为当 $-2 < x < 1$ 时，不能得到 $x > 1$ 或 $x < -1$ ，而 $x > 1$ 或 $x < -1$ 时，不能得到 $-2 < x < 1$ ，所以“ $-2 < x < 1$ ”是“ $x > 1$ 或 $x < -1$ ”的既不充分条件，也不必要条件。故 $p$ 是 $q$ 的既不充分条件，也不必要条件。
> > （8）因为 $A \cup B = A \Leftrightarrow A \cap B = B$ ，所以 $p$ 是 $q$ 的充要条件。
> > （9）因为等腰梯形的对角线相等，故 $p \neq q$ ，又因为矩形的对角线相等，故 $q \Rightarrow p$ ，所以 $p$ 是 $q$ 的必要不充分条件。
> > （10）因为 $p: x > 2$ 且 $y > 3, q: x + y > 5$ ; 所以 $p$ 可以推出 $q$ ，但 $p$ 不可以被 $q$ 推出，故 $p$ 是 $q$ 的充分不必要条件。
> > （11）因为 $-4 \leq x + 1 \leq 4 \Leftrightarrow -5 \leq x \leq 3$ ，而 $-5 \leq x \leq 3 \Rightarrow -6 \leq x \leq 3$ （小范围推大范围），所以 $p$ 是 $q$ 的充分不必要条件。
> > （12）由 $|x| < 2$ ，则 $-2 < x < 2$ ，因为 $-2 < x < 2 \Rightarrow -2 < x < 6$ ，所以 $p$ 是 $q$ 的必要不充分条件。
> > （13）由 $\frac{1}{a} < \frac{1}{9}$ ，解得 $a > 9$ 或 $a < 0$ ，所以 $p$ 是小范围，即 $p \Rightarrow q, q$ 推不出 $p$ ，所以 $p$ 是 $q$ 的充分不必要条件。
