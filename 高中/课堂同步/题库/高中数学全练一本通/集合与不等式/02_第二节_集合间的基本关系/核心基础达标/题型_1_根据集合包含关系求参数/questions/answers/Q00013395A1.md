> > [!success] **【答案】** $$ a \geq 2; (2) a = 2 $$
>
> > [!note]- **【解析】**
> > 解析：（1）当 $a = 0$ 时， $A = \mathbb{R}$ ， $A \subseteq B$ 不成立；
> > 当 $a < 0$ 时， $A = \left\{x \mid \frac{4}{a} \leq x < -\frac{1}{a}\right\}$ ，因为 $A \subseteq B$ ，所以 $\left\{ \begin{array}{l} \frac{4}{a} > -\frac{1}{2} \\ -\frac{1}{a} \leq 2 \end{array} \right.$ ，得 $a < -8$ ；
> > 当 $a > 0$ 时， $A = \left\{x \mid -\frac{1}{a} < x \leq \frac{4}{a}\right\}$ ，因为 $A \subseteq B$ ，所以 $\left\{ \begin{array}{l} \frac{4}{a} \leq 2 \\ -\frac{1}{a} \geq -\frac{1}{2} \end{array} \right.$ ，解得 $a \geq 2$ ，综上：实数 $a$ 的取值范围是 $a < -8$ 或 $a \geq 2$ ；（2）当 $a = 0$ 时， $A = \mathbb{R}$ ， $A = B$ 不成立；
> > 当 $a < 0$ 时， $A = \left\{x \mid \frac{4}{a} \leq x < -\frac{1}{a}\right\}$ ， $A = B$ ，不成立；
> > 当 $a > 0$ 时， $A = \left\{x \mid -\frac{1}{a} < x \leq \frac{4}{a}\right\}$ ，因为 $A = B$ ，所以 $\left\{ \begin{array}{l} \frac{4}{a} = 2 \\ -\frac{1}{a} = -\frac{1}{2} \end{array} \right.$ ，解得 $a = 2$ ；综上：实数 $a$ 的值是2.
