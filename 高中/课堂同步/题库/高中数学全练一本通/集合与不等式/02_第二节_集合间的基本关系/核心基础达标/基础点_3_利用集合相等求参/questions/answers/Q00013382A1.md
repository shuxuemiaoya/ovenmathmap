> > [!note]- **【解析】**
> > 当 $a = 0$ 时， $ax^2 + x + b = 0$ 化为 $x = -b$ ，所以 $b = -1$ ；当 $a \neq 0$ 时， $\Delta = 1 - 4ab = 0$ ，则 $ab = \frac{1}{4}$ ，又 $x = 1$ 是方程 $ax^2 + x + b = 0$ 的解，所以 $a + b = -1$ ，得 $a = b = -\frac{1}{2}$ 。故答案为：AB
