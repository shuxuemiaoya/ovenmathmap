> > 解析：因为等式 $ax^3 + bx + c = x^3 + 2x - 2$ 恒成立, 所以 $a = 1, b = 2, c = -2$ , 所以 $a + b + c = 1 + 2 + (-2) = 1$ . 故答案为: 1
