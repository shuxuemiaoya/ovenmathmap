> > 解析：（1）原式 $= ab - a + b - 1$ $= a(b - 1) + b - 1$ $= (a + 1)(b - 1)$ （2）原式 $= (b^{2} - a^{2}) + (b - a)$ $= (b - a)(b + a) + (b - a)$ $= (b - a)(b + a + 1)$ （3）原式 $= a^2 -\bigl (b^2 -2b + 1\bigr)$ $= a^2 -(b - 1)^2$ $= (a + b - 1)(a - b + 1)$ （4）原式 $= (a^4 -c^4) + (a^2 b^2 -b^2 c^2)$ $= (a^2 +c^2)(a^2 -c^2) + b^2(a^2 -c^2)$ $= (a^2 +c^2)(a + c)(a - c) + b^2(a + c)(a - c)$ $= (a + c)(a - c)(a^2 +b^2 +c^2)$ （5）原式 $= 1 - \left(4a^{2} - 4ab + b^{2}\right)$ $= 1 - (2a - b)^{2}$ $= (1 + 2a - b)(1 - 2a + b)$ .
> > （6）原式 $= (a^3 -b^3) + (a^2 -b^2)$ $= (a - b)(a^2 +ab + b^2) + (a - b)(a + b)$ $= (a - b)(a^2 +ab + b^2 +a + b)$ （7）原式 $= (a^3 +2a^2) + (5a + 10)$ $= a^2 (a + 2) + 5(a + 2)$ $= (a + 2)(a^2 +5)$ （8）原式 $= (a^3 +b^3) + (a^2 c + b^2 c - abc)$ $= (a + b)(a^2 -ab + b^2) + c(a^2 +b^2 -ab)$ $= (a + b + c)(a^2 -ab + b^2)$
