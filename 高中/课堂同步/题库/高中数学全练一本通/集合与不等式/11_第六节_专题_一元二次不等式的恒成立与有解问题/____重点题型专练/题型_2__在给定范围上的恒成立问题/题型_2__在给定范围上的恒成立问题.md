## 题型 2: 在给定范围上的恒成立问题

形如 $ax^{2} + bx + c \geq 0 (a \neq 0)$ 或 $ax^{2} + bx + c \leq 0 (a \neq 0)$ 在 $a \leq x \leq b$ 上的恒成立与有解, 确定参数的范围, 常用分类讨论法或者分离参数法求解.

（1）分类讨论法, 利用二次函数分类讨论求最值.

（2）分离参数法：（分离参数法的前提是分离后系数可以与0比较大小）
通过分离参数，把参数的范围问题转化为区间上函数的最值问题.
对 $\forall x\in \{x|m\leq x\leq n\}$ ， $a > y$ 恒成立 $\Leftrightarrow a > y_{\mathrm{max}}$ ；
对 $\forall x\in \{x|m\leq x\leq n\}$ ， $a <   y$ 恒成立 $\Leftrightarrow a <   y_{\mathrm{min}}$ ；

注意: 若二次项前有参数, 也需要对参数是否为 0 进行分类
