## 1. 分式不等式解法

方法一:移项通分,化分式为整式

解分式不等式的基本思想是化分式不等式为整式不等式或整式不等式组.注意转化时的等价性.

$$
\frac {A}{B} > 0 \Leftrightarrow A \cdot B > 0; \frac {A}{B} <   0 \Leftrightarrow A \cdot B <   0; \frac {A}{B} \geq 0 \Leftrightarrow \left\{ \begin{array}{l} B \neq 0 \\ A \cdot B \geq 0 \end{array} ; \frac {A}{B} \leq 0 \Leftrightarrow \left\{ \begin{array}{l} B \neq 0 \\ A \cdot B \leq 0 \end{array} \right. \right.
$$

注意当分式右侧不为 0 时, 可通过移项、通分合并的手段将右侧变为 0; 当分母符号确定时, 可利用不等式的形式直接去分母

方法二:根据分式的性质,讨论分子分母的符号

（1）分式值为正或大于0：分子分母同号： $\left\{\begin{aligned}A&>0\\ B&>0\end{aligned}\right.$ 或 $\left\{\begin{aligned}A&<0\\ B&<0\end{aligned}\right.$

（2）分式值为负或小于0：分子分母异号： $\left\{\begin{aligned}A<0\\ B>0\end{aligned}\right.$ 或 $\left\{\begin{aligned}A>0\\ B<0\end{aligned}\right.$
