> [!faq]- 全练一本通解析
>
> > [!success]- **【答案】** （1） $\{x\mid\frac{8}{5}<x<2\}$ ; (2) $\left\{x\left|\frac{1}{3} < x < 1\right.\text{或}1 < x < 3\right\}$ ; (3) $\left\{x\mid x<-2\text{或}x>4\right\}$ ; (4) $\left\{-1 \leq x \leq 3\right\}$ ; (5) $\left\{1 \leq x \leq 3\right\}$ ; (6) $\{x \mid 2 < x \leq 3 \text{或} - 1 \leq x < 0\}$ .
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > （1） $\left|5x-9\right|<1\Leftrightarrow-1<5x-9<1\Leftrightarrow\frac{8}{5}<x<2$
> > 故不等式的解集为 $\{x\mid\frac{8}{5}<x<2\}$ ;
> > （2）由 $\left|\frac{x + 1}{x - 1}\right| > 2$ ，可得 $\frac{x + 1}{x - 1} > 2$ ，或 $\frac{x + 1}{x - 1} < -2$
> > 所以 $\frac{x - 3}{x - 1} < 0$ ，或 $\frac{3x - 1}{x - 1} < 0$
> > 解得 1 < x < 3，或 $\frac{1}{3} < x < 1$ ，
> > 所以不等式 $\left|\frac{x + 1}{x - 1}\right| > 2$ 的解集为 $\left\{x\left|\frac{1}{3} < x < 1\right.\right.$ 或 $1 < x < 3\}$
> > （3）因为 $|x-1|>3$ ，所以 $(x-1)^{2}>3^{2}$ ，
> > 即 $(x - 1)^2 -3^2 >0\Rightarrow (x - 4)(x + 2) > 0$ ，所以 $x <   - 2$ 或 $x > 4$
> > （4）由条件得 $|x - 1|\leq 2$ 可得 $-2\leq x - 1\leq 2$ ，解得 $-1\leq x\leq 3$
> > 所以解集为 $\left\{-1\leq x\leq3\right\}$ .
> > （5）因为 $\left|x-2\right|\leq1$ ，故 $-1\leq x-2\leq1$ 故 $1\leq x\leq3$
> > 故不等式的解集为 $\{1\leq x\leq 3\}$
> > (6) 由 $1 < |x - 1| \leq 2$ 可得 $1 < x - 1 \leq 2$ 或 $-2 \leq x - 1 < -1$ ,
> > 解得 $2 < x \leq 3$ 或 $-1 \leq x < 0$
> > 即解集为： $\{x\mid 2 <   x\leq 3$ 或 $-1\leq x <   0\}$
