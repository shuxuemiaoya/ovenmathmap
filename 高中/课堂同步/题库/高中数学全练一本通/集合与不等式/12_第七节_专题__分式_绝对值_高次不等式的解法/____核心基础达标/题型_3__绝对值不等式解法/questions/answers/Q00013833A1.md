> [!faq]- 全练一本通解析
>
> > [!success]- **【答案】** （1） $\{x\mid x\leq 0$ 或 $x\geq 3\}$ $$ \{x \mid - 4 < x < 3 \} $$ (3) $\left\{x \mid x \leq 0 \text{ 或 } x \geq 4\right\}$ ; (4) $\{x\mid -1 < x < 4\}$ (5) $\left\{x \mid x \leq -2 \text{或} x \geq 2\right\}$ ; (6) $\left\{x \mid x < -4 \text{或} x > 4\right\}$ ; (7) $\left\{x \mid x \leq -2 \text{或} x \geq 1\right\}$ ; (8) $\left\{x\mid0<x<2\right\}$ .
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > （1） $\left|x-1\right|+\left|x-2\right|\geq3$
> > - **①**：当 x<1 时, 原不等式可化为 $1-x+2-x\geq3$ ,
> > 即 $-2x \geq 0$ ，解得 $x \leq 0$ ，满足 x < 1，
> > $$
> > x \leq 0
> > $$
> > - **②**：当 $1 \leq x \leq 2$ 时, 原不等式可化为 $x - 1 + 2 - x \geq 3$ ,
> > 即 $1 \geq 3$ ，无解.
> > - **③**：当 x>2 时, 原不等式可化为 $x-1+x-2\geq3$ ,
> > 即 $2x \geq 6$ ，解得 $x \geq 3$ ，满足 x > 2，
> > $$
> > x \geq 3
> > $$
> > 综上所述, 原不等式的解集是 $\left\{x \mid x \leq 0 \text{ 或 } x \geq 3\right\}$ .
> > （2）不等式 $\left|x+3\right|+\left|x-2\right|<7$ 等价于
> > $\left\{ \begin{array}{l} - (x + 3) - (x - 2) < 7 \\ x \leq -3 \end{array} \right.$ 或 $\left\{ \begin{array}{l} (x + 3) - (x - 2) < 7 \\ -3 < x \leq 2 \end{array} \right.$ 或 $\left\{ \begin{array}{l} (x + 3) + (x - 2) < 7 \\ x > 2 \end{array} \right.$
> > 即 $-4 < x \leq -3$ 或 $-3 < x \leq 2$ 或 $2 < x < 3$ ，即 $-4 < x < 3$ .
> > 故原不等式的解集为 $\left\{x\mid-4<x<3\right\}$ .
> > （3）当 x<1 时, 不等式可化为 $-x+1-x+3\geq4$ ,
> > 此时不等式解为 $x \leq 0$ ；
> > 当 $1 \leq x \leq 3$ 时, 不等式可化为 $x - 1 - x + 3 \geq 4$ ,
> > 此时不等式无解；
> > 当 x>3 时, 不等式可化为 $x-1+x-3\geq4$ ,
> > $$
> > x \geq 4
> > $$
> > 综上:原不等式的解集为 $\left\{x \mid x \leq 0 \text{ 或 } x \geq 4\right\}$ .
> > （4）当 $x < 1$ 时，不等式为 $1 - x + 2 - x < 5, \therefore x > -1, \therefore -1 < x < 1$ ；
> > 当 $1 \leq x \leq 2$ 时, 不等式为 $1 < 5, \therefore 1 \leq x \leq 2$ ;
> > 当 $x > 2$ 时, 不等式为 $x - 1 + x - 2 < 5, \therefore x < 4, \therefore 2 < x < 4$ .
> > 所以不等式的解集为 $\left\{x\mid-1<x<4\right\}$ .
> > $$
> > \left| 2 x + 1 \right| + \left| x - 1 \right| \geq 6
> > $$
> > 当 $x < -\frac{1}{2}$ 时，有 $-2x - 1 + 1 - x \geq 6$ ，解得 $x \leq -2$ ，所以 $x \leq -2$
> > $$
> > - \frac {1}{2} \leq x <   1
> > $$
> > $$
> > 2 x + 1 + 1 - x \geq 6
> > $$
> > $$
> > x \geq 4
> > $$
> > 当 $x \geq 1$ 时，有 $2x + 1 + x - 1 \geq 6$ ，解得 $x \geq 2$ ，所以 $x \geq 2$
> > $$
> > x \in \emptyset
> > $$
> > 综上所述:不等式 $\left|2x+1\right|+\left|x-1\right|\geq6$ 的解集为 $\left\{x\mid x\leq-2或x\geq2\right\}$ ;
> > （6）所以解不等式 $\left|x+3\right|+\left|x-3\right|>8$ ，
> > 而 $\left|x+3\right|+\left|x-3\right|=\begin{cases}-2x,x\leq-3\\6,-3<x<3\\2x,x\geq3\end{cases}$
> > 当 $x \leq -3$ 时, 不等式为 $-2x > 8$ , 解得 $x < -4$ ;
> > $$
> > - 3 <   x <   3
> > $$
> > 当 $x \geq 3$ 时, 不等式为 $2x > 8$ , 解得 $x > 4$ .
> > 综上所述, 不等式 $\left|x+3\right|+\left|x-3\right|>8$ 的解集为 $\left\{x\mid x<-4\text{或}x>4\right\}$ 1.
> > （7）依题意，
> > 当 $x \geq 0$ 时, 不等式可化为 $x + x + 1 \geq 3$ , $x \geq 1$ , 所以 $x \geq 1$ ;
> > 当 $-1 \leq x < 0$ ，不等式可化为 $-x + x + 1 \geq 3, 1 \geq 3$ ，不等式不成立；当 x < -1 时，不等式可化为 $-x - x - 1 \geq 3, x \leq -2$ ，所以 $x \leq -2$ ；
> > 因此不等式 $|x| + |x + 1| \geq 3$ 的解集为 $\{x \mid x \leq -2 \text{或} x \geq 1\}$ .
> > （8）当 $x < 0$ 时，原不等式可化为 $-2x + 1 < -x + 1$ ，解得 $x > 0$ 又因为 $x < 0$ ，所以这样的 $x$ 不存在.
> > 当 $0 \leq x < \frac{1}{2}$ 时, 原不等式可化为 $-2x + 1 < x + 1$ , 解得 $x > 0$ ,
> > 又因为 $0 \leq x < \frac{1}{2}$ , 所以 $0 < x < \frac{1}{2}$ .
> > 当 $x \geq \frac{1}{2}$ 时, 原不等式可化为 $2x - 1 < x + 1$ , 解得 $x < 2$ ,
> > 又因为 $x \geq \frac{1}{2}$ , 所以 $\frac{1}{2} \leq x < 2$ .
> > 综上所述, 原不等式的解集为 $\{x \mid 0 < x < 2\}$
