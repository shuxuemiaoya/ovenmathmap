> [!faq]- 全练一本通解析
>
> > [!success]- **【答案】** （1） $x\geq 2$ 或 $x < 0$ ；（2） $1 < x < 6$ ；（3） $\frac{7}{15}\leq x < \frac{3}{5}$ (4) $x \leq -3$ 或 $x \geq 1$ ; (5) $-1 < x < 2$ ; (6) $-2 < x < -1$ .
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > （1）由题设 $\frac{2}{x} - 1 = \frac{2 - x}{x} \leq 0$ ，则 $\left\{ \begin{array}{l} x(2 - x) \leq 0 \\ x \neq 0 \end{array} \right.$ ，可得 $x \geq 2$ 或 $x < 0$ ，
> > $$
> > x \geq 2
> > $$
> > $$
> > x <   0
> > $$
> > $$
> > \frac {2 x - 7}{x - 1} <   1 \Leftrightarrow \frac {2 x - 7}{x - 1} - 1 <   0 \Leftrightarrow \frac {x - 6}{x - 1} <   0
> > $$
> > 即 $(x - 1)(x - 6) < 0$ ，解得： $1 < x < 6$ ，所以不等式的解是 $1 < x < 6$
> > $$
> > \Leftrightarrow \frac {2}{3 - 5 x} - 3 \geq 0 \Leftrightarrow \frac {1 5 x - 7}{3 - 5 x} \geq 0 \Leftrightarrow \frac {1 5 x - 7}{5 x - 3} \leq 0
> > $$
> > $\Leftrightarrow \left\{ \begin{array}{l} (15x - 7)(5x - 3) \leq 0 \\ 5x - 3 \neq 0 \end{array} \right. \Leftrightarrow \left\{ \begin{array}{l} \frac{7}{15} \leq x \leq \frac{3}{5} \\ x \neq \frac{3}{5} \end{array} \right.$ , 解得 $\frac{7}{15} \leq x < \frac{3}{5}$ ,
> > 所以原不等式的解为 $\frac{7}{15} \leq x < \frac{3}{5}$ .
> > （4）因为 $x^{2}+x+1=\left(x+\frac{1}{2}\right)^{2}+\frac{3}{4}>0$
> > 由 $\frac{4 - x}{x^2 + x + 1} \leq 1$ 可得 $x^2 + x + 1 \geq 4 - x$
> > $$
> > x ^ {2} + 2 x - 3 \geq 0
> > $$
> > $$
> > x \geq 1
> > $$
> > 故原不等式的解为 $x \leq -3$ 或 $x \geq 1$ .
> > （5）由 $\frac{(x+1)(x-5)^{2}}{(x-2)}<0$ 可得 $\left\{\begin{aligned}\frac{x+1}{x-2}<0\\ x-5\neq0\end{aligned}\right.$
> > 等价于 $\left\{ \begin{array}{l} (x + 1)(x - 2) < 0 \\ x - 5 \neq 0 \end{array} \right.$ ，解得 $-1 < x < 2$ ，
> > $$
> > - 1 <   x <   2
> > $$
> > (6) $\frac{x^2 + 4x + 2}{x + 2} < x \Leftrightarrow \frac{x^2 + 4x + 2}{x + 2} - x < 0 \Leftrightarrow \frac{2x + 2}{x + 2} < 0$
> > 原不等式化为： $2(x+1)(x+2)<0$ ，
> > 解得：-2<x<-1，
> > 所以原不等式的解集是 -2 < x < -1
