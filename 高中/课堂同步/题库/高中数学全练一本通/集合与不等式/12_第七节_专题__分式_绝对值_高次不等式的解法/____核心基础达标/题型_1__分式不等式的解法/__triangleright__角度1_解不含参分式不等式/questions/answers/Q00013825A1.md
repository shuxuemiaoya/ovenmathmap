> [!faq]- 全练一本通解析
>
> > [!success]- **【答案】** (1) $\frac{1}{2} < x < 4$ ; (2) $x < 2$ 或 $x \geq 5$ ; (3) $-13 \leq x < 3$ ; (4) $-\frac{3}{2} < x \leq \frac{1}{3}$
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > （1）由 $\frac{x + 3}{4 - x} > 1$ ，则 $4 - x \neq 0$ ，即 $x \neq 4$ ；
> > $$
> > 4 - x > 0
> > $$
> > $$
> > x <   4
> > $$
> > $$
> > x > \frac {1}{2}
> > $$
> > $$
> > x + 3 > 4 - x
> > $$
> > $$
> > \frac {1}{2} <   x <   4
> > $$
> > - **②**：当 4-x<0，即 x>4 时，两边同乘以 $(4-x)$ ，不等号方向改变，
> > $$
> > x <   \frac {1}{2}
> > $$
> > $$
> > x + 3 <   4 - x
> > $$
> > 所以, 原不等式的解为 $\frac{1}{2}<x<4$ .
> > $$
> > \frac {x + 1}{x - 2} - 2 \leq 0
> > $$
> > $$
> > \frac {- x + 5}{x - 2} \leq 0
> > $$
> > 得 $\left\{ \begin{array}{l} -x + 5 \geq 0 \\ x - 2 < 0 \end{array} \right.$ 或 $\left\{ \begin{array}{l} -x + 5 \leq 0 \\ x - 2 > 0 \end{array} \right.$ ，解得 $x < 2$ 或 $x \geq 5$
> > 所以原不等式的解为 x<2 或 $x\geq5$
> > $$
> > \frac {x + 5}{x - 3} \leq \frac {1}{2}
> > $$
> > $$
> > \left\{ \begin{array}{l} x + 5 \leq \frac {1}{2} (x - 3) \\ x - 3 > 0 \end{array} \right.
> > $$
> > $$
> > \left\{ \begin{array}{l} x + 5 \geq \frac {1}{2} (x - 3) \\ x - 3 <   0 \end{array} \right.
> > $$
> > $$
> > - 1 3 \leq x <   3
> > $$
> > 即不等式的解为 $-13 \leq x < 3$ .
> > （4）由 $\frac{4 - x}{2x + 3} \geq 1$ 可得 $1 - \frac{4 - x}{2x + 3} = \frac{2x + 3 - (4 - x)}{2x + 3} = \frac{3x - 1}{2x + 3} \leq 0$
> > $$
> > \left\{ \begin{array}{l} 3 x - 1 \geq 0 \\ 2 x + 3 <   0 \end{array} \right.
> > $$
> > $$
> > \left\{ \begin{array}{l} 3 x - 1 \leq 0 \\ 2 x + 3 > 0 \end{array} \right.
> > $$
> > $$
> > - \frac {3}{2} <   x \leq \frac {1}{3}
> > $$
> > 故原不等式的解为 $-\frac{3}{2} < x \leq \frac{1}{3}$ .
