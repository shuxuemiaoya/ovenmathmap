> > [!success] **【答案】** （1） $A = \{-2, - 1,0,1,2\}$ （2） $B = \{(3,2)\}$
>
> > [!note]- **【解析】**
> > 解析：（1） $\because -2 \leq x \leq 2, x \in \mathbf{Z}$ ， $\therefore x = -2, -1, 0, 1, 2$ ， $A = \{-2, -1, 0, 1, 2\}$ ；
> >
> > （2）解方程组 $\left\{\begin{aligned}&2x+y=8\\ &x-y=1\end{aligned}\right.$ 得 $\left\{\begin{aligned}&x=3\\ &y=2\end{aligned}\right.$ $\therefore B=\left\{(3,2)\right\}$ ;
