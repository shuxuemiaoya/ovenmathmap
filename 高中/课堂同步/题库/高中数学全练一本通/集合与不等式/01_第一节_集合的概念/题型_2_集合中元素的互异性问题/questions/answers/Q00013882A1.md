> > [!note]- **【解析】**
> > 解析：$\because -3 \in A, \therefore -3 = a^2 + 4a$ 或 $-3 = a - 2$ 。若 $-3 = a^2 + 4a$ ，解得 $a = -1$ 或 $a = -3$ 。当 $a = -1$ 时， $a^2 + 4a = a - 2 = -3$ ，不满足集合中元素的互异性，故舍去；当 $a = -3$ 时，集合 $A = \{12, -3, -5\}$ ，满足题意，故 $a = -3$ 成立。若 $-3 = a - 2$ ，解得 $a = -1$ ，由上述讨论可知，不满足题意，故舍去。综上所述， $a = -3$ 。
> >
> > 故选 **D**.
