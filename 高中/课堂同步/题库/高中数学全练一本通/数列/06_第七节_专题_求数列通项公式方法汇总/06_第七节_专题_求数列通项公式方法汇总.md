## 方法 1: 叠加法求数列通项

![](../images/questions/bb18622c705704cfb3b9d9e47f5057692a3f0fb54266b726959a4152a1505845.jpg)

若数列 $\left\{a_{n}\right\}$ 满足 $a_{n+1}-a_{n}=f(n)$ ，则称数列 $\left\{a_{n}\right\}$ 为 “变差数列”，求变差数列 $\left\{a_{n}\right\}$ 的通项时，利用恒等式 $a_{n}=a_{1}+(a_{2}-a_{1})+(a_{3}-a_{2})+\cdots+(a_{n}-a_{n-1})=a_{1}+f(1)+f(2)+f(3)+\cdots+f(n-1)(n\geq2)$ 求通项公式的方法称为叠加法。具体步骤： $a_{2}-a_{1}=f(1)$ ; $a_{3}-a_{2}=f(2)$ ; $a_{4}-a_{3}=f(3)$ ..... $a_{n}-a_{n-1}=f(n-1)$ 将上述 n-1 个式子相加（左边加左边，右边加右边）得： $(a_{2}-a_{1})+(a_{3}-a_{2})+(a_{4}-a_{3})+\cdots+(a_{n}-a_{n-1})=f(1)+f(2)+f(3)+\cdots+f(n-1)$ 整理得： $a_{n}-a_{1}=f(1)+f(2)+f(3)+\cdots+f(n-1)$ 即 $a_{n}=f(1)+f(2)+f(3)+\cdots+f(n-1)+a_{1}(n\geq2)$ ，最后检验 $a_{1}$ 是否满足 $a_{n}$ 的通项公式。

## 方法 2: 叠乘法求数列通项

若数列 $\left\{a_{n}\right\}$ 满足 $\frac{a_{n+1}}{a_{n}}=f(n)$ ，则称数列 $\left\{a_{n}\right\}$ 为 “变比数列”，求变比数列 $\left\{a_{n}\right\}$ 的通项时，可利用恒等式 $a_{n}=a_{1}\cdot\frac{a_{2}}{a_{1}}\cdot\frac{a_{3}}{a_{2}}\cdot\frac{a_{4}}{a_{3}}\cdots\frac{a_{n}}{a_{n-1}}=a_{1}\cdot f(1)\cdot f(2)\cdot f(3)\cdots f(n-1)(n\geq2)$ 求通项公式的方法称为累乘法.

具体步骤： $\frac{a_{2}}{a_{1}}=f(1)$ ; $\frac{a_{3}}{a_{2}}=f(2)$ ; $\frac{a_{4}}{a_{3}}=f(3)\ldots\frac{a_{n}}{a_{n-1}}=f(n-1)$ 将上述 n-1 个式子相乘（左边乘左边，右边乘右边）得： $\frac{a_{2}}{a_{1}}\cdot\frac{a_{3}}{a_{2}}\cdot\frac{a_{4}}{a_{3}}\cdots\frac{a_{n}}{a_{n-1}}=f(1)\cdot f(2)f(3)\cdots f(n-1)$ 整理得： $\frac{a_{n}}{a_{1}}=f(1)\cdot f(2)f(3)\cdots f(n-1)$ 即 $a_{n}=a_{1}\cdot\frac{a_{2}}{a_{1}}\cdot\frac{a_{3}}{a_{2}}\cdot\frac{a_{4}}{a_{3}}\cdots\frac{a_{n}}{a_{n-1}}=a_{1}\cdot f(1)\cdot f(2)\cdot f(3)\cdots f(n-1)(n\geq2)^{-1}$ 最后检验 $a_{1}$ 是否满足 $a_{n}$ 的通项公式.

## 方法4:待定系数之 $a_{n+1} = A a_n + B n + C$ 型构造等比数列

求关于 $a_{n+1} = A a_n + B n + C (A \neq 1, C \neq 0, B \neq 0)$ 类型的通项公式时，与上面讲述的构造一的方法很相似，只不过等式中多了一项 $B n$ ，在构造时我们也保持跟题干一样的结构，加一项 $p n$ 再构造等比数列就可以，即令 $a_{n+1} + p(n+1) + q = A(a_n + p n + q)$ ，然后与已知递推式各项的系数对应相等，解 $p, q$ ，从而得到 $\{a_n + p n + q\}$ 是公比为 $A$ 的等比数列.

## 方法 5: 待定系数之 $a_{n+1} = pa_{n} + q^{n}$ 型构造数列

求关于 $a_{n + 1} = pa_n + q^n$ (其中 $p,q$ 均为常数， $pq(p - 1)\neq 0$ )类型的通项公式时，共有3种方法.

方法一: 先用待定系数法把原递推公式转化为 $a_{n+1} + \lambda q^{n+1} = p\left(a_n + \lambda q^n\right)$ ，根据对应项系数相等求出 $\lambda$ 的值，再利用换元法转化为等比数列求解.

方法二: 先在递推公式两边同除以 $q^{n+1}$ ，得 $\frac{a_{n+1}}{q^{n+1}} = \frac{p}{q} \cdot \frac{a_n}{q^n} + \frac{1}{q}$ ，引入辅助数列 $\left\{b_n\right\}$ （其中 $b_n = \frac{a_n}{q^n}$ ），得 $b_{n+1} = \frac{p}{q} \cdot b_n + \frac{1}{q}$ ，再利用待定系数法解决.

方法三:也可以在原递推公式两边同除以 $p^{n+1}$ ，得 $\frac{a_{n+1}}{p^{n+1}}=\frac{a_{n}}{p^{n}}+\frac{1}{p}\cdot\left(\frac{q}{p}\right)^{n}$ ，引入辅助数列 $\left\{b_{n}\right\}$ （其中 $b_{n}=\frac{a_{n}}{p^{n}}$ ），得 $b_{n+1}-b_{n}=\frac{1}{p}\cdot\left(\frac{q}{p}\right)^{n}$ ，再利用叠加法(逐差相加法)求解.

## 方法 6: 取倒数构造数列

类型一: 数列 $\{a_{n}\}$ 满足: $a_{n+1}=\frac{ba_{n}}{ka_{n}+b}$ ，则有 $\frac{1}{a_{n+1}}=\frac{b+ka_{n}}{ba_{n}}=\frac{1}{a_{n}}+\frac{k}{b}$ .
所以 $\left\{\frac{1}{a_{n}}\right\}$ 是以 $\frac{1}{a_{1}}$ 为首项, $\frac{k}{b}$ 为公差的等差数列, 即 $\frac{1}{a_{n}}=\frac{1}{a_{1}}+(n-1)\frac{k}{b}$ . (当分母出现加减时, 我们很难将它进行化简运算, 所以往往取倒数再运算才能找到突破点).
类型二: 若数列 $\{a_{n}\}$ 的前 n 项和为 $S_{n}$ ，且满足 $a_{n} + kS_{n}S_{n-1} = 0$ ，则有 $S_{n} - S_{n-1} + kS_{n}S_{n-1} = 0$ ，两边同除以 $S_{n}S_{n-1}$ 得: $\frac{1}{S_{n}} - \frac{1}{S_{n-1}} = k$ ，故 $\left\{\frac{1}{S_{n}}\right\}$ 是以 $\frac{1}{a_{1}}$ 为首项, k 为公差的等差数列, 即 $\frac{1}{S_{n}} = \frac{1}{a_{1}} + (n-1)k$ , 再用 $a_{n} = S_{n} - S_{n-1}$ , 求 $\{a_{n}\}$ .

# 方法 7: 同型构造

所谓同型构造法, 就是将找因式中的因子和数列项数相同或者相近的部分通过同除或同乘化归成结构相同的形式, 形成新的数列, 如常数列, 等差数列或等比数列.

模型一： $a_{n + 1} = \frac{n}{n + 1}\cdot a_n\xrightarrow{\text{左右同乘}n + 1}$ $(n + 1)a_{n + 1} = n\cdot a_n$ ，构造 $b_{n} = n\cdot a_{n}$ ，则 $b_{n + 1} = b_n$ ， $\{b_n\}$ 为常数数列.
模型二： $a_{n + 1} = \frac{n + 1}{n}\cdot a_n\xrightarrow{\text{左右同除}n + 1}\frac{a_{n + 1}}{n + 1} = \frac{a_n}{n}$ ，构造 $b_{n} = \frac{a_{n}}{n}$ ，则 $b_{n + 1} = b_n$ ， $\{b_n\}$ 为常数数列.
模型三： $a_{n + 1} = \frac{n + 2}{n}\cdot a_n\xrightarrow{\text{左右同除}(n + 2)(n + 1)}\frac{a_{n + 1}}{(n + 1)(n + 2)} = \frac{a_n}{n(n + 1)}$ ，构造 $b_{n} = \frac{a_{n}}{n(n + 1)}$ ，则 $b_{n + 1} = b_n$ ， $\{b_n\}$ 为常数数列.
模型四： $na_{n + 1} = 2(n + 1)a_n\xrightarrow{\text{左右同除}n(n + 1)}\frac{a_{n + 1}}{n + 1} = 2\frac{a_n}{n}$ ，构造 $b_{n} = \frac{a_{n}}{n}$ ，则 $b_{n + 1} = 2b_{n}$ ， $\{b_n\}$ 为等比数列.
模型五： $a_{n + 1} = \frac{n + 2}{n}\cdot S_n\Rightarrow S_{n + 1} - S_n = \frac{n + 2}{n}\cdot S_n\Rightarrow S_{n + 1} = \frac{2n + 2}{n}\cdot S_n\xrightarrow{\text{左右同除}n + 1}\frac{S_{n + 1}}{n + 1} = 2\frac{S_n}{n}$ ，构造 $b_{n} = \frac{S_{n}}{n}$ ，则 $b_{n + 1} = 2b_n$ ， $\{b_n\}$ 为等比数列.
模型六： $a_{n + 1} = \frac{n + 1}{n}\cdot a_n + n + 1\xrightarrow{\text{左右同除}n + 1}\frac{a_{n + 1}}{n + 1} = \frac{a_n}{n} +1$ ，构造 $b_{n} = \frac{a_{n}}{n}$ ，则 $b_{n + 1} = b_n + 1$ ， $\{b_n\}$ 为等差数列.
模型七： $a_{n + 1} = 2a_{n} + 2^{n + 1}\xrightarrow{\text{左右同除}2^{n + 1}}\frac{a_{n + 1}}{2^{n + 1}} = \frac{a_n}{2^n} +1$ ，构造 $b_{n} = \frac{a_{n}}{2^{n}}$ ，则 $b_{n + 1} = b_n + 1$ ， $\{b_n\}$ 为等差数列.
模型八： $a_{n} - a_{n + 1} = a_{n}a_{n + 1}\xrightarrow{\text{左右同除}a_a a_{n + 1}}\frac{1}{a^{n + 1}} -\frac{1}{a^n} = 1$ ，构造 $b_{n} = \frac{1}{a^{n}}$ ，则 $b_{n + 1} - b_n = 1$ ， $\{b_n\}$ 为等差数列.
当看到这类式子，尽量将 $n + 1$ 和 $a_{n + 1}$ ， $n$ 和 $a_{n}$ 等因子和数列项数相同的部分划归成结构相同的形式，构造成新数列.

## 方法 8:二阶整体构造等比

简单的二阶整体等比:关于 $a_{n+1} = Aa_n + Ba_{n-1}$ 的模型,可通过构造二阶等比数列求解,大部分题型可转化为 $a_{n+1} - a_n = (A-1)(a_n - a_{n-1})$ ,利用 $\{a_{n+1} - a_n\}$ 成等比数列,以及叠加法求出 $a_n$ .针对个别试题,我们需要用待定系数法解决,通过构造 $\{a_{n+1} - pa_n\}$ 成等比来解决.设原等式 $a_{n+2} - pa_{n+1} = q(a_{n+1} - pa_n)$ ,打开得到 $a_{n+2} = (p + q)a_{n+1} - pqa_n$ ,通过对应项系数相等解参数.

## 方法 9: 取对数构造数列

$$
a _ {n + 1} = c a _ {n} ^ {k}, a _ {n} = c a _ {n - 1} ^ {k}
$$

$$
a _ {n} + b = c \left(a _ {n - 1} + b\right) ^ {k}, b
$$
