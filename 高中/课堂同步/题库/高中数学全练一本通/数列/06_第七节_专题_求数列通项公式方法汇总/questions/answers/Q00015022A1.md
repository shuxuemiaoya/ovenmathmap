> [!faq]- 全练一本通解析
>
> > [!success]- **【答案】** $a_{n} = 3^{2^{n - 1}} - 2$
>
> > [!note]- **【解析】**
> > 由 $a_{n + 1} = a_n^2 +4a_n + 2$ ，得 $a_{n + 1} + 2 = a_n^2 +4a_n + 4$ ，即 $a_{n + 1} + 2 = (a_n + 2)^2$ 两边同取以3为底的对数，得 $\log_3^{a_{n + 1} + 2} = \log_3^{(a_n + 2)^2}$ ，即 $\log_3^{a_{n + 1} + 2} = 2\log_3^{(a_n + 2)}$ ，所以数列 $\{\log_3^{(a_n + 2)}\}$ 是以1为首项，2为公比的等比数列， $\log_3^{(a_n + 2)} = 2^{n - 1},a_n + 2 = 3^{2^{n - 1}}$ ，即 $a_{n} = 3^{2^{n - 1}} - 2$
