> [!faq]- 全练一本通解析
>
> > [!success]- **【答案】** $a_{n} = (3n - 1)\times 2^{n - 2}$
>
> > [!note]- **【解析】**
> > $\because a_1 = 1$ ， $S_{n + 1} = 4a_n + 2$ ， $\therefore S_2 = a_1 + a_2 = 4a_1 + 2$ ，解得 $a_2 = 5$ ： $\because S_{n + 1} = 4a_n + 2$ ， $\therefore S_{n + 2} = 4a_{n + 1} + 2$ ，两式相减得， $a_{n + 2} = 4a_{n + 1} - 4a_n$ ， $\therefore a_{n + 2} - 2a_{n + 1} = 2(a_{n + 1} - 2a_n)$ ， $\therefore \{a_{n + 1} - 2a_n\}$ 是以 $a_2 - 2a_1 = 3$ 为首项，2为公比的等比数列， $\therefore a_{n + 1} - 2a_n = 3\times 2^{n - 1}$ ，两边同除以 $2^{n + 1}$ ，则 $\frac{a_{n + 1}}{2^{n + 1}} -\frac{a_n}{2^n} = \frac{3}{4}$ ， $\therefore \left\{\frac{a_n}{2^n}\right\}$ 是以 $\frac{3}{4}$ 为公差， $\frac{a_1}{2^1} = \frac{1}{2}$ 为首项的等差数列， $\therefore \frac{a_n}{2^n} = \frac{1}{2} +(n - 1)\times \frac{3}{4} = \frac{3n - 1}{4},$ $\therefore a_n = \frac{3n - 1}{4}\times 2^n = (3n - 1)\times 2^{n - 2},$
