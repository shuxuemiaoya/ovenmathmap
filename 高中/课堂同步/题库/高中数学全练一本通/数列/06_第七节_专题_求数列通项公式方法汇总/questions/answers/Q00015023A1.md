> [!faq]- 全练一本通解析
>
> > [!success]- **【答案】** $a_{n} = 2^{n}$
>
> > [!note]- **【解析】**
> > 因为 $a_{n + 1}^n = a_n^{n + 1}(a_n >0)$ ，且 $a_1 = 2$ ，所以 $a_{n} > 1$ 所以 $\lg a_{n + 1}^n = \lg a_{n + 1}^{\mathrm{n}}$ ，即 $n\lg a_{n + 1} = (n + 1)\lg a_n$ ，所以 $\frac{\lg a_{n + 1}}{\lg a_n} = \frac{n+1}{n}$ 当 $n\geqslant 2$ 时，所以 $\frac{\lg a_n}{\lg a_{n-1}}\cdot \frac{\lg a_{n-1}}{\lg a_{n-2}}\dots \frac{\lg a_3}{\lg a_2}\cdot \frac{\lg a_2}{\lg a_1} = \frac{n}{n - 1}\cdot \frac{n - 1}{n - 2}\cdot \frac{n - 2}{n - 3}\dots \frac{3}{2}\cdot \frac{2}{1},$
> >
> > 所以 $\frac{\lg a_n}{\lg a_1} = n$ 因为 $a_1 = 2$ ，所以 $\log_2a_n = n$ ，所以 $a_{n} = 2^{n}$ $a_1 = 2$ 也符合上式，所以 $a_{n} = 2^{n}$
