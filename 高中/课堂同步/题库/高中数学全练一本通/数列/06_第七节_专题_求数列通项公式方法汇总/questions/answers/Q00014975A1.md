> [!faq]- 全练一本通解析
>
> > [!success]- **【答案】** $a_{n}=3^{n}-2.$
>
> > [!note]- **【解析】**
> > 设 $a_{n+1} + t = 3(a_n + t)$ ，即 $a_{n+1} = 3a_n + 2t$ ，题干中 $a_{n+1} = 3a_n + 4$ ，根据对应项系数相等，解得 t=2，故 $a_{n+1} + 2 = 3(a_n + 2)$ 。令 $b_n = a_n + 3$ ，则 $b_1 = a_1 + 3 = 4, \text {且 } \frac{b_{n+1}}{b_n} = \frac{a_{n+1} + 3}{a_n + 3} = 3.$ . 所以 $\left\{b_n\right\}$ 是 3 为首项，3 为公比的等比数列. 所以 $b_n=3\times3^{n-1}=3^n,$ 即 $a_n=3^n-2.$
