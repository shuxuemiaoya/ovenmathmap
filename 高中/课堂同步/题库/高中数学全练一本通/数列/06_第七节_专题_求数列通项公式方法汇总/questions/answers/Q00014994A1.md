> [!faq]- 全练一本通解析
>
> > [!success]- **【答案】** $a_{n}=(-n+3)\frac{1}{2^{n}}$
>
> > [!note]- **【解析】**
> > 当 $n\geq2$ 时， $2a_{n}+S_{n-1}=1+\frac{1}{2^{n-1}}$ ，
> > 相减可得 $2a_{n+1}-a_{n}=-\frac{1}{2^{n}}$ ，所以 $\frac{a_{n+1}}{\frac{1}{2^{n+1}}} - \frac{a_{n}}{\frac{1}{2^{n}}} = -1$ ，
> > 又 $\frac{a_{1}}{\frac{1}{2^{1}}} = 2, \quad \frac{a_{2}}{\frac{1}{2^{2}}} = 4a_{2} = 4 \times \frac{1}{4} = 1$ ，所以 $\frac{a_{2}}{\frac{1}{2^{2}}} - \frac{a_{1}}{\frac{1}{2^{1}}} = -1$ 故 $\left\{\begin{aligned}&\frac{a_{n}}{\frac{1}{2^n}}\\&\frac{\textbf{\textit{\textit{\textit{\textit{\textit{\textit{\textit{\textit{\textit{\textit{\textit{\textit{\textit{\textit{\textit{\textit{\textit{\textit{\textit{\textit{\textit{\textit{\textit{\textit{\textit{\textit{\textit{\textit{\textit{\textit{\textit{\textit{\textit{\textit{{\begin}}}^{\circ}}}^{\circ}}}^{\circ}}}^{\circ}}} } } } } \\ &\frac{\circ}{\circ}\\ &\end{array}\right.$ 为等差数列，且公差为 -1，首项为 2，
> >
> > 故 $\left.\frac{a_{n}}{\frac{1}{2^n}}=2+(n-1)\times(-1)=-n+3,\quad a_{n}=(-n+3)\frac {1}{2^{n}},\right.$ 故答案为： $a_{n}=(-n+3)\frac {1}{2^{n}}$
