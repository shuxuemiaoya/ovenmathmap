> [!faq]- 全练一本通解析
>
> > [!success]- **【答案】** $a_{n}=\frac {1}{2 n-1}$
>
> > [!note]- **【解析】**
> > 取倒数得： $\frac {1}{a _ { n + 1 }}=\frac { 1 } { a _ { n } } + 2$ ，即 $\frac { 1 } { a _ { n } } - \frac { 1 } { a _ { n - 1 }} = 2 ( n > 1 )$ 所以数列 $\left\{\frac { 1 } { a _ { n } }\right\}$ 是首项为 1，公差为 2 的等差数列 $\frac { 1 } { a _ { n }}=1+2(n-1)=2 n-1$ ，所以 $a_{n}=\frac { 1 } { 2 n-1 }$ .
