> [!faq]- 全练一本通解析
>
> > [!success]- **【答案】** $a_{n} = \frac{2}{5}\cdot \left(\frac{1}{3}\right)^{n - 1} + \frac{3}{5}\cdot 2^{n - 1}$
>
> > [!note]- **【解析】**
> > 通过构造 $\{a_{n + 1} - pa_n\}$ 成等比来解决.设原等式 $a_{n + 2} - pa_{n + 1} = q(a_{n + 1} - pa_n)$ ，打开得到 $a_{n + 2} = (p + q)a_{n + 1} - pqa_n$ ，对应项系数相等， $\left\{ \begin{array}{l}p + q = \frac{7}{3}\\ -pq = -\frac{2}{3} \end{array} \right.$ 解得 $\left\{ \begin{array}{l}p = 2\\ q = \frac{1}{3} \end{array} \right.$ 或 $\left\{ \begin{array}{l}p = \frac{1}{3}\\ q = 2 \end{array} \right.$ ，我们发现解出两组结果，没关系，都是成立的，可以构造 $\{a_{n + 1} - 2a_n\}$ 首项为 $-\frac{2}{3}$ ，公比为 $\frac{1}{3}$ 的等比数列或构造 $\{a_{n + 1} - \frac{1}{3} a_n\}$ 为首项为1，公比为2的等比数列.我们都来尝试下.构造一： $a_{n + 1} - 2a_{n} = -\frac{2}{3}\left(\frac{1}{3}\right)^{n - 1}$ ，即 $a_{n + 1} = 2a_{n} - \frac{2}{3}\left(\frac{1}{3}\right)^{n - 1}$ ，这就回到了熟悉的 $a_{n + 1} = pa_n + q^n$ 型，设 $a_{n + 1} + \lambda \cdot \left(\frac{1}{3}\right)^n = 2\left[a_n + \lambda \cdot \left(\frac{1}{3}\right)^{n - 1}\right]$ ，待定系数法得 $\lambda = -\frac{2}{5}$ ，则数列 $\left\{a_n - \frac{2}{5}\cdot \left(\frac{1}{3}\right)^{n - 1}\right\}$ 是首项为 $a_1 - \frac{2}{5}\cdot \left(\frac{1}{3}\right)^{1 - 1} = \frac{3}{5}$ ，公比为2的等比数列，所以 $a_{n} - \frac{2}{5}\cdot \left(\frac{1}{3}\right)^{n - 1} = \left(\frac{3}{5}\right)\cdot 2^{n - 1}$ ，即 $a_{n} = \frac{2}{5}\cdot \left(\frac{1}{3}\right)^{n - 1} + \frac{3}{5}\cdot 2^{n - 1}$ .构造二： $a_{n + 1} - \frac{1}{3} a_n = 2^{n - 1}$ ，即 $a_{n + 1} = \frac{1}{3} a_n + 2^{n - 1}$ ，设 $a_{n + 1} + \lambda \cdot 2^n = \frac{1}{3}\left(a_n + \lambda \cdot 2^{n - 1}\right)$ ，待定系数法得 $\lambda = -\frac{3}{5}$ ，则数列 $\left\{a_n - \frac{3}{5}\cdot 2^{n - 1}\right\}$ 是首项为 $a_1 - \frac{3}{5}\cdot 2^{1 - 1} = \frac{2}{5}$ ，公比为 $\frac{1}{3}$ 的等比数列，所以 $a_{n} - \frac{3}{5}\cdot 2^{n - 1} = \frac{2}{5}\cdot \left(\frac{1}{3}\right)^{n - 1}$ ，即 $a_{n} = \frac{2}{5}\cdot \left(\frac{1}{3}\right)^{n - 1} + \frac{3}{5}\cdot 2^{n - 1}$
