> [!faq]- 全练一本通解析
>
> > [!success]- **【答案】** $a_{n} = 3^{n}$
>
> > [!note]- **【解析】**
> > 由 $T_{n}$ 为正项数列 $\{a_n\}$ 的前 $n$ 项的乘积，得 $\frac{T_{n + 1}}{T_n} = a_{n + 1}$ ，由 $T_{n}^{2} = a_{n}^{n + 1}$ 得 $T_{n + 1}^2 = a_{n + 1}^{n + 2}$ 于是 $\frac{T_{n + 1}^2}{T_n^2} = a_{n + 1}^2 = \frac{a_{n + 1}^{n + 2}}{a_n^{n + 1}}$ ，即 $a_{n + 1}^n = a_n^{n + 1}$ ，两边取对数得 $\lg a_{n + 1}^n = \lg a_n^{n + 1}$ 即 $n\lg a_{n + 1} = (n + 1)\lg a_n$ ，整理得 $\frac{\lg a_{n + 1}}{n + 1} = \frac{\lg a_n}{n}$ 因此数列 $\{\frac{\lg a_n}{n}\}$ 是常数列，即 $\frac{\lg a_n}{n} = \frac{\lg a_1}{1} = \lg 3$ ，于是 $\lg a_n = n\lg 3 = \lg 3^n$ 所以 $a_{n} = 3^{n}$
