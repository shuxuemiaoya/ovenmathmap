> [!faq]- 全练一本通解析
>
> > [!success]- **【答案】** $a_{n}=2^{n+1}-3.$
>
> > [!note]- **【解析】**
> > 设 $a_{n+1} + t = 2(a_n + t)$ ，整理得 $a_{n+1} = 2a_n + t$ ，题干中 $a_{n+1} = 2a_n + 3$ ，根据对应项系数相等，解得 t=3，故 $a_{n+1} + 3 = 2(a_n + 3)$ 。令 $b_n = a_n + 3$ ，则 $b_1 = a_1 + 3 = 4, \text {且 } \frac{b_{n+1}}{b_n} = \frac{a_{n+1} + 3}{a_n + 3} = 2.$ 所以 $\left\{b_n\right\}$ 是 4 为首项，2 为公比的等比数列. 所以 $b_n=4\times2^{n-1}=2^{n+1}$ ，即 $a_n=2^{n+1}-3.$
