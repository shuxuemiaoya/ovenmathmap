> [!faq]- 全练一本通解析
>
> > [!success]- **【答案】** 585
>
> > [!note]- **【解析】**
> > 设等比数列 $\{a_n\}$ 的公比为 $q$ ，设等比数列 $\{a_n\}$ 的前 10 项中，设所有奇数项的和为 $S_\text{奇}$ ，所有偶数项的和为 $S_\text{偶}$ ，则 $S_\text{偶} = a_2 + a_4 + a_6 + a_8 + a_{10} = q(a_1 + a_3 + a_5 + a_7 + a_9) = qS_\text{奇}$ ，所以， $q = \frac{S_\text{偶}}{S_\text{奇}} = \frac{170 + \frac{1}{2}}{85 + \frac{1}{4}} = 2$ ，又 $S_\text{奇} = \frac{a_1[1 - (q^2)^5]}{1 - q^2} = \frac{1023a_1}{3} = 34la_1 = \frac{341}{4}$ ，则 $a_1 = \frac{1}{4}$ ，因此， $S = a_3 + a_6 + a_9 + a_{12} = a_3(1 + q^3 + q^6 + q^9) = a_1q^2 \cdot \frac{1 - q^{12}}{1 - q^3} = 585$ 。故答案为：585
