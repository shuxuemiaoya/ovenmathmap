> [!faq]- 全练一本通解析
>
> > [!success]- **【答案】** （1） $a_n = 2^{n-1}, n \in \mathbb{N}^*$ （2） $\frac{2^{2n+1} - 3n - 2}{3}$ .
>
> > [!note]- **【解析】**
> > （1）由题意，设等比数列 $\{a_n\}$ 的公比为 $q(q > 1)$ ，则 $a_2 = \frac{a_3}{q} = \frac{4}{q}, a_4 = a_3 q = 4q$ ， $\because a_2, a_3, a_4 - 2$ 成等差数列， $\therefore 2a_3 = a_2 + a_4 - 2$ ，即 $\frac{4}{q} + 4q - 2 = 8$ ，  
> > 化简整理，得 $2q^2 - 5q + 2 = 0$ ，  
> > 解得 $q = \frac{1}{2}$ （舍去），或 $q = 2$ ， $\therefore$ 首项 $a_1 = \frac{a_3}{q^2} = \frac{4}{2^2} = 1$ ， $\therefore a_n = 1 \cdot 2^{n-1} = 2^{n-1}, n \in \mathbb{N}^*$ .  
> > （2）由（1）可得 $b_n = \begin{cases} a_n - 1(n \text{为奇数}) \\ \frac{1}{2} a_n(n \text{为偶数}) \end{cases} = \begin{cases} 2^{n-1} - 1(n \text{为奇数}), \\ 2^{n-2}(n \text{为偶数}), \end{cases}$ 则数列 $\{b_n\}$ 的前 $2n$ 项和为 $b_1 + b_2 + b_3 + b_4 + \cdots + b_{2n-1} + b_{2n}$ $= a_1 + a_3 + a_5 + \cdots + a_{2n-1} - n + \frac{1}{2}(a_2 + a_4 + a_6 + \cdots + a_{2n})$ $= (2^0 + 2^2 + 2^4 + \cdots + 2^{2n-2} - n) + (2^0 + 2^2 + 2^4 + \cdots + 2^{2n-2})$ $= (2^0 + 2^2 + 2^4 + \cdots + 2^{2n-2}) \times 2 - n$ $= \frac{1 - 4^n}{1 - 4} \times 2 - n = \frac{2^{2n+1} - 3n - 2}{3}$ .
