> [!faq]- 全练一本通解析
>
> > [!success]- **【答案】** $\frac{1}{2}$
>
> > [!note]- **【解析】**
> > 设数列 $\{a_n\}$ 共有 $2m + 1$ 项，由题意得 $S_\text{奇} = a_1 + a_3 + \cdots + a_{2m+1} = \frac{85}{32}$ ， $S_\text{偶} = a_2 + a_4 + \cdots + a_{2m} = \frac{21}{16}$ ，则 $S_\text{奇} = a_1 + a_2q + \cdots + a_{2m}q = 2 + q(a_2 + a_4 + \cdots + a_{2m}) = 2 + \frac{21}{16}q = \frac{85}{32}$ ，解得 $q = \frac{1}{2}$ ，故答案为： $\frac{1}{2}$
