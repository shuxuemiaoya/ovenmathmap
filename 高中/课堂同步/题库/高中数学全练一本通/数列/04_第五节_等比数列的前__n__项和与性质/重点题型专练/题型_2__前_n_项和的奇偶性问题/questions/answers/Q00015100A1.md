>
> > [!success]- **【答案】** C
>
> > [!note]- **【解析】**
> > 当 $n = 1$ 时， $S_1 + 1 = 2$ ，解得 $a_1 = S_1 = 2 - 1 = 1$ ， $S_n + 1 = 2^n$ ，当 $n \geq 2$ 时， $S_{n-1} + 1 = 2^{n-1}$ ，两式相减得 $S_n - S_{n-1} = 2^n - 2^{n-1}$ ，即 $a_n = 2^{n-1}$ ，且 $a_1 = 1$ 满足上式，故 $\frac{a_{n+1}}{a_n} = 2$ ，所以等比数列 $\{a_n\}$ 的首项为 1，公比为 2，又 $\frac{a_{2n-1}^2}{a_{2n-3}^2} = \left(\frac{a_{2n-1}}{a_{2n-3}}\right)^2 = 16$ ，则 $a_1^2$ 、 $a_3^2$ 、 $a_5^2$ 、...、 $a_{2n-1}^2$ 构成首项为 1，公比为 16 的等比数列，故 $a_1^2 + a_3^2 + a_5^2 + \cdots + a_{2n-1}^2 = \frac{1 - 16^n}{1 - 16} = \frac{16^n - 1}{15}$ 。故选：C
