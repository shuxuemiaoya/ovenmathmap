> [!faq]- 全练一本通解析
>
> > [!success]- **【答案】** 120
>
> > [!note]- **【解析】**
> > 因为在等比数列中，若项数为 $2n$ ，则 $\frac{S_\text{偶}}{S_\text{奇}} = q$ ，所以 $a_1 + a_2 + a_3 + \cdots + a_{100} = (a_1 + a_3 + a_5 + \cdots + a_{99}) + (a_2 + a_4 + a_6 + \cdots + a_{100}) = (a_1 + a_3 + a_5 + \cdots + a_{99}) + \frac{1}{3}(a_1 + a_3 + a_5 + \cdots + a_{99}) = 90 + \frac{1}{3} \times 90 = 120$ 。故答案为：120
