> [!faq]- 全练一本通解析
>
> > [!success]- **【答案】** B
>
> > [!note]- **【解析】**
> > 因为等比数列有 $2n+1$ 项，则奇数项有 $n+1$ 项，偶数项有 n 项，设公比为 q，
> >
> > 得到奇数项为 $1 + q^2 + q^4 + \ldots + q^{2n} = 1 + q\left(q + q^3 + q^5 + \ldots + q^{2n-1}\right) = 85$ ，偶数项为 $q + q^3 + q^5 + \ldots + q^{2n-1} = 42$ ，整体代入得 $q = 2$ ，所以前 $2n+1$ 项的和为 $\frac{1 - 2^{2n+1}}{1 - 2} = 85 + 42 = 127$ ，解得 $n = 3$ 。故选：B
