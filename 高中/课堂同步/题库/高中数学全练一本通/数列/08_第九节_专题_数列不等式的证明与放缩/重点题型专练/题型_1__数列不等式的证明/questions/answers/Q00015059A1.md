> [!faq]- 全练一本通解析
>
> > [!success]- **【答案】** （1）证明见解析， $a_{n} = 2 + 2^{n-1}$ （2）证明见解析
>
> > [!note]- **【解析】**
> > （1）解：当 $n \geqslant 2$ 时，由 $S_{n+1} + 2S_{n-1} = 3S_n - 2$ 可变形为 $S_{n+1} - S_n = 2(S_n - S_{n-1}) - 2$ ，
> >
> > 即 $a_{n+1} = 2a_n - 2$ ，即 $a_{n+1} - 2 = 2(a_n - 2)$ ，所以 $\frac{a_{n+1} - 2}{a_n - 2} = 2(n \geqslant 2)$ ，
> >
> > 又因为 $a_1 = 3$ ， $a_2 = 4$ ，可得 $a_1 - 2 = 1, a_2 - 2 = 2$ ，所以 $\frac{a_2 - 2}{a_1 - 2} = 2$ ，
> >
> > 所以数列 $\{a_n - 2\}$ 是以 1 为首项，2 为公比的等比数列，
> >
> > 所以 $a_n - 2 = 2^{n-1}$ ，所以数列 $\{a_n\}$ 的通项公式为 $a_n = 2 + 2^{n-1}$ 。
> >
> > （2）解：由 $a_n = 2 + 2^{n-1}$ ，可得 $b_n = \frac{2^{n-1}}{a_na_{n+1}} = \frac{2^{n-1}}{(2 + 2^{n-1})(2 + 2^n)} = \frac{1}{2 + 2^{n-1}} - \frac{1}{2 + 2^n}$ ，
> >
> > 所以 $T_n = b_1 + b_2 + b_3 + \cdots + b_n$ ， $= \frac{1}{3} - \frac{1}{4} + \frac{1}{4} - \frac{1}{6} + \frac{1}{6} - \frac{1}{6} - \frac{1}{10} + \cdots + \frac{1}{2 + 2^{n-1}} - \frac{1}{2 + 2^n} = \frac{1}{3} - \frac{1}{2 + 2^n}$ ，
> >
> > 因为 $\frac{1}{2 + 2^n} > 0$ ，所以 $\frac{1}{3} - \frac{1}{2 + 2^n} < \frac{1}{3}$ ，即 $T_n < \frac{1}{3}$ ，
> >
> > 又因为 $f(n) = \frac{1}{3} - \frac{1}{2 + 2^n}$ ， $n \in \mathbf{N}^*$ 单调递增，
> >
> > 所以 $T_n ≥ b_1 = \frac{1}{(2 + 1)(2 + 2)} = \frac{1}{12}$ ，所以 $\frac{1}{12} ≤ T_n < \frac{1}{3}$ 。
