> [!faq]- 全练一本通解析
>
> > [!success]- **【答案】** （1）证明见解析； $b_{n} = 6^{n - 1}$ （2） $S_{2n} = \frac{3}{5}\times 6^n -n - \frac{3}{5}$ ；证明见解析.
>
> > [!note]- **【解析】**
> > （1）证明：由题意可知， $\frac{b_{n + 1}}{b_n} = \frac{a_{2n + 1}}{a_{2n - 1}} = \frac{3a_{2n} + 3}{a_{2n - 1}} = \frac{3a_{(2n - 1) + 1} + 3}{a_{2n - 1}} = \frac{3(2a_{2n - 1} - 1) + 3}{a_{2n - 1}} = 6,$ 所以数列 $\{b_n\}$ 是首项 $b_{1} = a_{1} = 1$ ，公比为6的等比数列.于是 $b_{n} = 6^{n - 1}$ （2）由题意可知， $a_{2n} = 2a_{2n - 1} - 1$ ，所以 $S_{2n} = a_1 + a_2 + a_3 + \dots +a_{2n} = (a_1 + a_3 + \dots +a_{2n - 1}) + (a_2 + a_4 + \dots +a_{2n})$ $= (a_{1} + a_{3} + \dots +a_{2n - 1}) + (2a_{1} - 1 + 2a_{3} - 1 + \dots +a_{2n - 1} - 1)$ $= 3(a_{1} + a_{3} + \dots +a_{2n - 1}) - n = 3(b_{1} + b_{2} + b_{3} + \dots +b_{n}) - n$ $= 3\times \frac{1 - 6^n}{1 - 6} -n = \frac{3}{5}\times 6^n -n - \frac{3}{5}$ 又 $b_{n + 1} = a_{2n + 1} = 6^n$ ，令 $c_{n} = 2S_{2n} - a_{2n + 1} + 2 = \frac{6}{5}\times 6^{n} - 2n - \frac{6}{5} -6^{n} + 2 = \frac{1}{5}\times 6^{n} - 2n + \frac{4}{5},$ $c_{n + 1} - c_n = \frac{1}{5}\times 6^{n + 1} - 2(n + 1) + \frac{4}{5} -\left(\frac{1}{5}\times 6^n -2n + \frac{4}{5}\right) = 6^n -2 > 0,$ 所以数列 $\{c_n\}$ 单调递增，故 $c_{n}\geq c_{1} = 0$ ，即 $2S_{2n}\geq a_{2n + 1} - 2.$
