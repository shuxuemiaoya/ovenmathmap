> > [!note]- **【解析】**
> > 已知 $a_{n} = \frac{n}{2},b_{n} = n^{2}$ ，因为 $c_n = \frac{2}{2n^2 + n} = \frac{2}{n(2n + 1)} = \frac{4}{2n(2n + 1)} <   \frac{4}{(2n - 1)(2n + 1)}$ $= 2\left(\frac{1}{2n - 1}-\frac{1}{2n + 1}\right)$ 所以 $c_{1}+c_{2}+ \cdots+c_{n}<\frac {2}{3}+2\left(\frac {1 } {3}-\frac {1 } {5}+\frac {1 } {5}-\frac {7 } {7}+\cdots+\frac {1 } {2 n- 1}-\frac {1 } {2 n+ 1}\right)$ $=\frac {2}{3}+\frac {2}{3}-\frac {2}{2 n+ 1}< \frac {4}{3},$ 故不等式得证.
