> [!faq]- 全练一本通解析
>
> > [!success]- **【答案】** $\frac{21}{2}$
>
> > [!note]- **【解析】**
> > 因为 $a_4a_9 = a_5a_8 = -18$ ，又 $a_5 + a_8 = -3,$ 解得 $\left\{ \begin{array}{l}a_{5} = -6\\ a_{8} = 3 \end{array} \right.$ 或 $\left\{ \begin{array}{l}a_5 = 3\\ a_8 = -6 \end{array} \right.$ 设等比数列 $\{a_n\}$ 的公比为 $q$ ，当 $a_5 = -6,a_8 = 3$ 时， $q^{3} = \frac{a_{8}}{a_{5}} = -\frac{1}{2}$ 所以 $a_2 + a_{11} = \frac{a_5}{q^3} +a_8q^3 = 12 + 3\times \left(-\frac{1}{2}\right) = \frac{21}{2};$ 当 $a_5 = 3,a_8 = -6$ 时， $q^3 = \frac{a_8}{a_5} = -2$ ，所以 $a_2 + a_{11} = \frac{a_5}{q^3} +a_8q^3 = -\frac{3}{2} +(-6)\times (-2) = \frac{21}{2},$ 故答案为： $\frac{21}{2}$
