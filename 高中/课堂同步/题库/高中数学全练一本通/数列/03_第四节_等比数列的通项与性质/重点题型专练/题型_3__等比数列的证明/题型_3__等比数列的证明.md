## 题型 3: 等比数列的证明

1. 定义法: $\frac{a_{n+1}}{a_{n}} = q$ （常数） $\Rightarrow \left\{a_{n}\right\}$ 为等比数列；
2. 中项法: $a_{n+1}^{2}=a_{n}\cdot a_{n+2}\quad(a_{n}\neq0)\Rightarrow\left\{a_{n}\right\}$ 为等比数列；
3. 通项公式法: $a_{n}=kq^{n}$ (k, q 为常数) $\Rightarrow\left\{a_{n}\right\}$ 为等比数列.
4. 构造法: 在条件中出现 $a_{n+1}=ka_{n}+b$ 关系时, 往往构造数列, 方法是把 $a_{n+1}+x=k(a_{n}+x)$ 与 $a_{n+1}=ka_{n}+b$ 对照, 求出 x 即可.
