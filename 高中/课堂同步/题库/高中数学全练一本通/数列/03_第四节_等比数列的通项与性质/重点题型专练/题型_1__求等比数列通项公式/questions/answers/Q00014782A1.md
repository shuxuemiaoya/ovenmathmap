> [!faq]- 全练一本通解析
>
> > [!success]- **【答案】** $a_{n} = 3^{n - 1}$ 或 $a_{n} = (-1)^{n}\cdot 3^{n - 1}$
>
> > [!note]- **【解析】**
> > 设等比数列 $\{a_n\}$ 的公比为 $q$ 则 $\left\{ \begin{array}{l}a_2 = a_1q = 3\\ a_6 = a_1q^5 = 243 \end{array} \right.$ ，解得 $\left\{ \begin{array}{l}a_1 = 1\\ q = 3 \end{array} \right.$ 或 $\left\{ \begin{array}{l}a_1 = -1\\ q = -3 \end{array} \right.$ 所以 $a_{n} = 3^{n - 1}$ 或 $a_{n} = -1\times (-3)^{n - 1} = (-1)^{n}\cdot 3^{n - 1}$ 故答案为： $a_{n} = 3^{n - 1}$ 或 $a_{n} = (-1)^{n}\cdot 3^{n - 1}$
