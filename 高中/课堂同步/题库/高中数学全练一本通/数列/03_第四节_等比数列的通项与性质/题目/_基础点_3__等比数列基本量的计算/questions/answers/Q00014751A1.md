> > [!note]- **【解析】**
> > （1）∵ $a_{n} = a_{1}q^{n - 1} = 128$ ， $a_1 = 4$ ， $q = 2$ $\therefore 4\cdot 2^{n - 1} = 128$ $\therefore 2^{n - 1} = 32$ $\therefore n - 1 = 5$ ， $n = 6$ (2） $\because a_{n} = a_{1}q^{n - 1} = 625$ ， $n = 4$ ， $q = 5$ $\therefore a_{1} = \frac{a_{n}}{q^{n - 1}} = \frac{625}{5^{4 - 1}} = 5$ (3） $a_{8} = a_{1}q^{7} = 3\cdot (-\sqrt{3})^{7} = -81\sqrt{3}$ (4） $a_1 = 4^{1 - 3} = (4)^{-2} = \frac{1}{16}$ ， $q = \frac{a^{n + 1}}{a^n} = \frac{4^{(n + 1) - 3}}{4^{n - 3}} = 4$ ，所以 $a_1 = \frac{1}{16},q = 4$ (5） $a_1 = 2^{2 - 3} = \frac{1}{2}$ ， $q = \frac{a^{n + 1}}{a^n} = \frac{2^{2(n + 1) - 3}}{2^{2n - 3}} = 4$ ，所以 $a_1 = \frac{1}{2},q = 4$ (6） $a_3 = a_1\cdot q^2$ ，即 $8 = 2q^2$ $\therefore q^2 = 4$ ， $\therefore q = \pm 2$ 当 $q = 2$ 时， $a_{n} = a_{1}q^{n - 1} = 2\cdot 2^{n - 1} = 2^{n}$ 当 $q = -2$ 时， $a_{n} = a_{1}q^{n - 1} = 2\cdot (-2)^{n - 1} = (-1)^{n - 1}\cdot 2^n$
