## 1. 等差数列的性质

设 $\{a_{n}\}$ 为等差数列, 公差为 $d$ , 则

（1）若 $m + n = p + q(m,n,p,q\in \mathbf{N}^{*})$ ，则 $a_{m} + a_{n} = a_{p} + a_{q}$

特别地, 若 $m + n = 2p$ , 则 $a_{m} + a_{n} = 2a_{p}(m, n, p \in \mathbf{N}^{*})$ ;

（2）若 $m + n + t = p + q + r$ ，则 $a_{m} + a_{n} + a_{t} = a_{p} + a_{q} + a_{r}\left(m,n,t,p,q,r\in \mathbf{N}^{*}\right)$

（3）若 $\left\{a_{n}\right\}$ 是有穷等差数列，则与首、末两项等距离的两项之和都相等，且等于首、末两项之和，即 $a_{1} + a_{n} = a_{2} + a_{n-1} = a_{3} + a_{n-2} = \cdots$ .

（4）数列 $\{\lambda a_{n} + b\} (\lambda ,b$ 是常数）是公差为 $\lambda d$ 的等差数列.

（5）若 $\{b_n\}$ 是公差为 $d'$ 的等差数列， $\{a_n\}$ 与 $\{b_n\}$ 的项数一致，则数列 $\{\lambda_1 a_n + \lambda_2 b_n\} (\lambda_1, \lambda_2$ 为常数）是公差为 $\lambda_1 d + \lambda_2 d'$ 的等差数列.
