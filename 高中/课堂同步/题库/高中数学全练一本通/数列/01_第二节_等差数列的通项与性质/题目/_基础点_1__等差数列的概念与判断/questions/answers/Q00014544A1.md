> [!faq]- 全练一本通解析
>
> > [!success]- **【答案】** C
>
> > [!note]- **【解析】**
> > 若“a, b, c 成等差数列”, 则“b-a=c-b”, 即“a, b, c 成等差数列”是“b-a=c-b”的充分条件;
> > 若“b-a=c-b”，则“a,b,c成等差数列”，即“a,b,c成等差数列”是“b-a=c-b”的必要条件，
> >
> > 综上可得:“a, b, c 成等差数列”是“b - a = c - b”的充要条件, 故选:C.
