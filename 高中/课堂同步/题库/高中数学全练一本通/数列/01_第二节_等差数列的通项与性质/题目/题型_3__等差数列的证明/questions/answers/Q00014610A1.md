> [!faq]- 全练一本通解析
>
> > [!success]- **【答案】** 证明见解析； $a_{n} = 2^{n} + 2(n - 1)$
>
> > [!note]- **【解析】**
> > 证明：因为 $a_{n + 1} = a_n + 2^n +2$ 所以 $(a_{n + 1} - 2^{n + 1}) - (a_n - 2^n) = (a_n + 2^n +2 - 2^{n + 1}) - (a_n - 2^n) = 2$ 因为 $a_1 - 2^1 = 0$ 所以数列 $\{a_n - 2^n\}$ 为首项为0，公差为2的等差数列.所以 $a_{n} - 2^{n} = 0 + 2(n - 1)$ ，即 $a_{n} = 2^{n} + 2(n - 1)$
