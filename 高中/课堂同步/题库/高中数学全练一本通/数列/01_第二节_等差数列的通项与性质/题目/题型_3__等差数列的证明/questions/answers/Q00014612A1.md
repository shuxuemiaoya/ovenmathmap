> [!faq]- 全练一本通解析
>
> > [!success]- **【答案】** 证明见解析， $a_{n} = (3n - 1)\cdot 2^{n}$
>
> > [!note]- **【解析】**
> > 因为 $a_{n + 1} = 2a_{n} + 6\cdot 2^{n}$ ，所以 $\frac{a_{n + 1}}{2^{n + 1}} = \frac{a_n}{2^n} +3$ 所以 $\frac{a_{n + 1}}{2^{n + 1}} -\frac{a_n}{2^n} = 3$ 为定值，所以 $\left\{\frac{a_n}{2^n}\right\}$ 是首项为 $\frac{a_1}{2} = 2$ ，公差为3的等差数列，所以 $\frac{a_n}{2^n} = 2 + 3(n - 1) = 3n - 1$ ，所以 $a_{n} = (3n - 1)\cdot 2^{n}$
