> [!faq]- 全练一本通解析
>
> > [!success]- **【答案】** 8
>
> > [!note]- **【解析】**
> > 设等差的数列 $\{a_{n}\}$ 的公差为 d，
> > 因为 $a_{2} + a_{9} = a_{5} + 4$ ，所以 $a_{1} + d + a_{1} + 8d = a_{1} + 4d + 4$ ，
> > 所以 $a_{1} + 5d = 4$ ，
> > 所以 $a_{3} + a_{9} = a_{1} + 2d + a_{1} + 8d = 2a_{1} + 10d = 2(a_{1} + 5d) = 8$
