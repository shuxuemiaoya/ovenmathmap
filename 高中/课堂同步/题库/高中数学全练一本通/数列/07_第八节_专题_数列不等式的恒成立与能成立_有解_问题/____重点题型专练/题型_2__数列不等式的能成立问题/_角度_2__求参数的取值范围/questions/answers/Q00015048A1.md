> [!faq]- 全练一本通解析
>
> > [!success]- **【答案】** （1） $\frac{n}{n + 1}$ （2） $\lambda \geq \frac{1}{3}$
>
> > [!note]- **【解析】**
> > （1）令 $n = 1$ ，得 $3S_{1} = (1 + m)a_{1}$ ，故 $m = 2$ 当 $n \geq 2$ 时，由 $3S_{n} = (n + m)a_{n}$ ，得 $3S_{n-1} = (n - 1 + m)a_{n-1}$ 两式相减并整理得 $\frac{a_{n}}{a_{n-1}} = \frac{n + 1}{n - 1}$ ，累乘得 $\frac{a_{n}}{a_{n-1}} \cdot \frac{a_{n-1}}{a_{n-2}} \cdot \cdots \cdot \frac{a_{2}}{a_{1}} = \frac{n + 1}{n - 1} \cdot \frac{n}{n - 2} \cdot \frac{n - 1}{n - 3} \cdot \cdots \cdot \frac{4}{2} \cdot \frac{3}{1}$ ，故 $a_{n} = n(n + 1)(n \geq 2)$ ， $a_{1} = 2$ 也满足该式，故 $\frac{1}{a_n} = \frac{1}{n(n + 1)} = \frac{1}{n} - \frac{1}{n + 1}$ .所以 $R_{n} = 1 - \frac{1}{2} + \frac{1}{2} - \frac{1}{3} + \dots + \frac{1}{n} - \frac{1}{n + 1} = 1 - \frac{1}{n + 1} = \frac{n}{n + 1}$ .（2）由题知， $b_{n} = \frac{1}{n + 1}$ ，根据题意得 $\lambda \geq (T_{2n} - T_n)_{\min}$ ，令 $c_{n} = T_{2n} - T_{n} = \frac{1}{n + 2} + \frac{1}{n + 3} + \dots + \frac{1}{2n + 1}$ ，则 $c_{n+1} - c_{n} = \frac{1}{2n + 2} + \frac{1}{2n + 3} - \frac{1}{n + 2} >0.$ 故 $(T_{2n} - T_n)_{\min} = c_1 = \frac{1}{3}$ ，所以 $\lambda \geq \frac{1}{3}$ .
