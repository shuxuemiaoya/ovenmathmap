> [!faq]- 全练一本通解析
>
> > [!success]- **【答案】** （1）证明见详解； $a_{n}=\frac{1}{2n-1}, n\in N^{+}$ （2） $(-∞,\frac{1}{49}]$
>
> > [!note]- **【解析】**
> > （1）解：由题意，∵ $2a_{n+1}a_{n}+a_{n+1}-a_{n}=0$ ，
> >
> > ∴ $\frac{a_{n}-a_{n+1}}{a_{n+1}a_{n}}=2$ ，又由 $b_{n}=\frac{1}{a_{n}}$ ，
> >
> > ∴ $b_{n+1}-b_{n}=\frac{1}{a_{n+1}}-\frac{1}{a_{n}}=\frac{a_{n}-a_{n+1}}{a_{n+1}a_{n}}=2$ ，
> >
> > 数列 $\left\{b_{n}\right\}$ 为等差数列， $b_{1}=1, d=2\cdot$ ∴ $b_{n}=b_{1}+(n-1)d=1+(n-1)\times2=2n-1$ ，
> >
> > ∴ $a_{n}=\frac{1}{2n-1}, n\in N^{+}\cdot$ （2）解：由（1）知 $a_{n}=\frac{1}{2n-1}$ ，
> >
> > 所以有 $a_{1}a_{2}+a_{2}a_{3}+\cdots+a_{n}a_{n+1}=\frac{1}{1\times3}+\frac{1}{3\times5}+\cdots+\frac{1}{(2n-1)(2n+1)}$
> >
> > $= \frac{1}{2}\left(1 - \frac{1}{3} +\frac{1}{3} -\frac{1}{5} +\dots +\frac{1}{2n - 1} -\frac{1}{2n + 1}\right) = \frac{1}{2}\left(1 - \frac{1}{2n + 1}\right) = \frac{n}{2n + 1},$ 所以存在 $n\in \mathbf{N}^{+}$ ，使不等式 $a_1a_2 + a_2a_3 + \dots +a_na_{n + 1}\geq (n + 18)\lambda$ 成立，即存在 $n\in \mathbf{N}^+$ ，使不等式 $\frac{n}{2n + 1}\geq (n + 18)\lambda$ 成立，即存在 $n\in \mathbf{N}^+$ ，使不等式 $\frac{n}{(2n + 1)(n + 18)}\geq \lambda$ 成立， $\therefore \lambda \leq \left[\frac{n}{(2n + 1)(n + 18)}\right]_{\max}.$ $\because \frac{n}{(2n + 1)(n + 18)} = \frac{n}{2n^2 + 37n + 18} = \frac{1}{2\left(n + \frac{9}{n}\right) + 37}\leq \frac{1}{4\sqrt{n\cdot\frac{9}{n}} + 37} = \frac{1}{49},$ 当且仅当 $n = \frac{9}{n}$ ，即 $n = 3$ 时等号成立；所以有， $\lambda \leq \frac{1}{49}.$ ∴实数 $\lambda$ 的取值范围是 $\left(-\infty ,\frac{1}{49}\right].$
