> [!faq]- 全练一本通解析
>
> > [!success]- **【答案】** C
>
> > [!note]- **【解析】**
> > 设等差数列的公差为 d，由 $S_{8}=3S_{4}$ 得， $8a_{1}+28d=3(4a_{1}+6d)$ ，即 $a_{1}=\frac{5}{2}d$ 由 $S_{12} = \lambda S_8$ 得， $12a_1 + 66d = \lambda (8a_1 + 28d)$ 即 $12\times\frac{5}{2}d + 66d = \lambda (8\times\frac{5}{2}d + 28d)$ ，解得 $\lambda=2$ ，故选: C.
