# 第六节 专题:数列求和题型方法汇总

## 方法 1: 错位相减求和

错位相减法是求解由等差数列 $\{a_{n}\}$ 和等比数列 $\{b_n\}$ 对应项之积组成的数列 $\{c_n\}$ （即 $c_{n} = a_{n}b_{n}$ ）的前 $n$ 项和的方法.在使用错位相减法求和时，应注意将“ $S_{n}$ 与“ $qS_{n}$ ”的表达式“错项对齐”，以便下一步准确写出“ $S_{n} - qS_{n}$ ”的表达式，要确定项数与公比正确求出 $S_{n}$ ；若公比是个参数（字母），则应先对参数加以讨论，一般情况下分等于1和不等于1两种情况求和.

公式秒杀：

$S_{n} = (A\cdot n + B)q^{n} - B$ （错位相减都可化简为这种形式，对于求解参数 $A$ 与 $B$ ，可以采用将前1项和与前2项和代入式中，建立二元一次方程求解.此方法可以快速求解出结果或者作为检验对错的依据.）

## 方法 2: 裂项相消求和

对于裂项后明显有能够相消的项的一类数列, 在求和时常用 “裂项法”, 分式的求和多利用此法. 可用待定系数法对通项公式进行拆项. 在消项时要注意前面保留第几项, 最后也要保留相对应的倒数几项. 例如消项时保留第一项和第 3 项, 相应的也要保留最后一项和倒数第三项.

常见的裂项形式:

(1) $\frac{1}{n(n + k)} = \frac{1}{k}\left(\frac{1}{n} -\frac{1}{n + k}\right);$

(2) $\frac{1}{(2n - 1)(2n + 1)} = \frac{1}{2}\left(\frac{1}{2n - 1} -\frac{1}{2n + 1}\right);$

(3) $\frac{1}{\sqrt{n + k} + \sqrt{n}} = \frac{1}{k} (\sqrt{n + k} - \sqrt{n})$ ;

(4) $\frac{2n + 1}{n^2(n + 1)^2} = \frac{1}{n^2} -\frac{1}{(n + 1)^2};$

(5) $\frac{2^n}{(2^n - 1)(2^{n + 1} - 1)} = \frac{1}{2^n - 1} -\frac{1}{2^{n + 1} - 1};$

(6) $\frac{1}{n(n + 1)(n + 2)} = \frac{1}{2}\left[\frac{1}{n(n + 1)} -\frac{1}{(n + 1)(n + 2)}\right];$

(7) $\frac{(n - 1)2^n}{n(n + 1)} = \frac{2^{n + 1}}{n + 1} -\frac{2^n}{n}$

(8) $\frac{n + 1}{(2n - 1)(2n + 1)2^n} = \frac{1}{(2n - 1)2^{n + 1}} -\frac{1}{(2n + 1)2^{n + 2}};$

(9) $\frac{(-1)^n(n + 1)}{(2n + 1)(2n + 3)} = \frac{1}{4}\left(\frac{(-1)^n}{2n + 1} -\frac{(-1)^{n + 1}}{2n + 3}\right);$

(10) $\ln \left(1 + \frac{1}{n}\right) = \ln (n + 1) - \ln n.$

## 方法 4: 分组求和法求和

当一个数列本身不是等差数列也不是等比数列,但它的通项公式可以拆分为几项的和,而且这些项又构成等差数列或等比数列时,那么就可以用分组求和法,即原数列的前n项和等于拆分成的每个数列前n项和的和.
