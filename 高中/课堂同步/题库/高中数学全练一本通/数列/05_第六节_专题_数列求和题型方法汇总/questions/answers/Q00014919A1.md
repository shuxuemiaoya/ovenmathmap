> [!faq]- 全练一本通解析
>
> > [!success]- **【答案】** （1） $a_{n}=2n-1$ （2） $T_{n}=n+\frac{n}{2n+1}$
>
> > [!note]- **【解析】**
> > （1）解：对任意的 $n\in \mathbb{N}^*$ ， $a_{n} > 0$ ，由题意可得 $4S_{n} = (a_{n} + 1)^{2} = a_{n}^{2} + 2a_{n} + 1$ 当 $n = 1$ 时，则 $4a_{1} = 4S_{1} = a_{1}^{2} + 2a_{1} + 1$ ，解得 $a_1 = 1$ 当 $n\geq 2$ 时，由 $4S_{n} = a_{n}^{2} + 2a_{n} + 1$ 可得 $4S_{n - 1} = a_{n - 1}^{2} + 2a_{n - 1} + 1$ 上述两个等式作差得 $4a_{n} = a_{n}^{2} - a_{n - 1}^{2} + 2a_{n} - 2a_{n - 1}$ ，即 $\left(a_n + a_{n - 1}\right)\left(a_n - a_{n - 1} - 2\right) = 0$ 因为 $a_{n} + a_{n - 1} > 0$ ，所以， $a_{n} - a_{n - 1} = 2$ 所以，数列 $\{a_n\}$ 为等差数列，且首项为1，公差为2，则 $a_{n} = 1 + 2(n - 1) = 2n - 1.$ （2）解： $S_{n} = \frac{n(1 + 2n - 1)}{2} = n^{2}$ 则 $b_{n} = \frac{4S_{n}}{a_{n}a_{n + 1}} = \frac{4n^{2}}{(2n - 1)(2n + 1)} = \frac{4n^{2} - 1 + 1}{(2n - 1)(2n + 1)} = 1 + \frac{1}{(2n - 1)(2n + 1)}$ $= 1 + \frac{1}{2}\left(\frac{1}{2n - 1} -\frac{1}{2n + 1}\right)$ 因此， $T_{n} = n + \frac{1}{2}\left(1 - \frac{1}{3} +\frac{1}{3} -\frac{1}{5} +\dots +\frac{1}{2n - 1} -\frac{1}{2n + 1}\right) = n + \frac{n}{2n + 1}$
