> [!faq]- 全练一本通解析
>
> > [!success]- **【答案】** $\frac{91}{2}$
>
> > [!note]- **【解析】**
> > $S = \sin^20^{\circ} + \sin^21^{\circ} + \sin^22^{\circ} + \ldots +\sin^290^{\circ}$ 倒序得 $S = \sin^290^\circ +\sin^289^\circ +\sin^288^\circ +\ldots +\sin^20^\circ$ ∴ $2S = (\sin^290^\circ +\sin^20^\circ) + (\sin^289^\circ +\sin^21^\circ) + \ldots +( \sin^20^\circ +\sin^289^\circ )$ ∵ $\sin \alpha = \cos \left(\frac{\pi}{2}-\alpha\right)$ 且 $\sin^2\alpha +\cos^2\alpha = 1$ ∴ $\sin^290^\circ +\sin^20^\circ = \sin^289^\circ +\sin^21^\circ = 1$ ∴ $2S = (\sin^290^\circ +\sin^20^\circ) + (\sin^289^\circ +\sin^21^\circ) + \ldots +( \sin^20^\circ +\sin^289^\circ ) = 91$ ∴ $S = \frac{91}{2}$
