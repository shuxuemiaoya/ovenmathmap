> [!faq]- 全练一本通解析
>
> > [!success]- **【答案】** （1） $a_{n} = n$ （2） $T_{n} = \left\{ \begin{array}{l} \frac{n(n + 1)}{2} -\frac{3 + (-3)^{n + 1}}{4},\\ -\frac{n(n + 1)}{2} -\frac{3 + (-3)^{n + 1}}{4}, \end{array} \right.$ 为偶数，
>
> > [!note]- **【解析】**
> > （1）根据题意， $(n + 1)S_n = nS_{n + 1} - \frac{1}{2} n(n + 1)$ ，所以 $\frac{S_{n + 1}}{n + 1} -\frac{S_n}{n} = \frac{1}{2}$ 由于 $\frac{S_1}{1} = a_1 = 1$ ，则 $\left\{\frac{S_n}{n}\right\}$ 是以首项为1，公差为 $\frac{1}{2}$ 的等差数列，  
> > 所以 $\frac{S_n}{n} = 1 + (n - 1)\times \frac{1}{2} = \frac{n + 1}{2}$ ，所以 $S_{n} = \frac{n(n + 1)}{2}$ 当 $n\geq 2$ 时， $a_{n} = S_{n} - S_{n - 1} = \frac{n(n + 1)}{2} -\frac{(n - 1)n}{2} = n$ 验证 $n = 1$ 时 $a_1 = 1$ 满足通项公式，故数列 $\{a_n\}$ 的通项公式为 $a_{n} = n$ （2）由（1）知 $b_{n} = (a_{n}^{2} + 3^{a_{n}})\cdot \cos n\pi = (-1)^{n}n^{2} + (-3)^{n}$ 设 $(-1)^{n}n^{2}$ 的前 $n$ 项和为 $A_{n}$ ，则当 $n$ 为偶数时， $A_{n} = -1^{2} + 2^{2} - 3^{2} + 4^{2} - \dots -\left(n - 1\right)^{2} + n^{2}$ $= (2 - 1)(2 + 1) + (4 - 3)(4 + 3) + \dots +(n - (n - 1))[n + (n - 1)]$ $= 1 + 2 + 3 + 4 + \dots +(n - 1) + n = \frac{n(n + 1)}{2}$ 当 $n$ 为奇数时， $A_{n} = A_{n - 1} - n^{2} = \frac{(n - 1)n}{2} -n^{2} = -\frac{n(n + 1)}{2}$ 设 $(-3)^{n}$ 的前 $n$ 项和为 $B_{n}$ ，则 $B_{n} = \frac{(-3)\cdot[1 - (-3)^{n}]}{1 + 3} = \frac{-3 - (-3)^{n + 1}}{4}$ 因为 $T_{n} = A_{n} + B_{n}$ ，所以 $T_{n} = \left\{ \begin{array}{l}\frac{n(n + 1)}{2} -\frac{3 + (-3)^{n + 1}}{4},\\ -\frac{n(n + 1)}{2} -\frac{3 + (-3)^{n + 1}}{4}, \end{array} \right.$ n为偶数，
