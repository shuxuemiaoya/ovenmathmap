> [!faq]- 全练一本通解析
>
> > [!success]- **【答案】** （1）因为 $S_{n} = (n - 1)\cdot 2^{n + 1} + 2$ ，当 $n\geq 2$ 时， $S_{n - 1} = (n - 2)\cdot 2^n +2$ ，两式相减得 $a_{n} = n\cdot 2^{n}(n\geq 2)$ 又因为 $a_1 = S_1 = 2$ ，所以 $a_{n} = n\cdot 2^{n}\left(n\in \mathbf{N}^{*}\right)$ （2）由（1）知 $a_{n} = n\cdot 2^{n}$ ，因为 $b_{n} = \frac{\left(n^{2} + n\right)\cdot 2^{n}}{\left(a_{n} - n\right)\cdot\left[a_{n + 1} - (n + 1)\right]}$ 所以 $b_{n} = \frac{\left(n^{2} + n\right)\cdot 2^{n}}{\left(n\cdot 2^{n} - n\right)\cdot\left[\left(n + 1\right)\cdot 2^{n + 1} - (n + 1)\right]} = \frac{2^n}{\left(2^n - 1\right)\cdot\left(2^{n + 1} - 1\right)} = \frac{1}{2^n - 1}\cdot \frac{1}{2^{n + 1} - 1}$ 所以 $T_{n} = \frac{1}{2 - 1} -\frac{1}{2^{2} - 1} +\frac{1}{2^{2} - 1} -\frac{1}{2^{3} - 1} +\dots +\frac{1}{2^{n} - 1} -\frac{1}{2^{n + 1} - 1} = 1 - \frac{1}{2^{n + 1} - 1},$ 因为 $n\geq 1$ 时， $2^{n + 1} - 1 > 0$ ，所以 $1 - \frac{1}{2^{n + 1} - 1} <   1$ ，即 $T_{n} <   1.$ 因为 $n = 1$ 时， $T_{1} = 1 - \frac{1}{2^{2} - 1} = \frac{2}{3}$ ，而函数 $y = 1 - \frac{1}{2^x - 1}$ 在 $(0, + \infty)$ 上是增函数，所以 $\frac{2}{3}\leq T_n <   1.$
