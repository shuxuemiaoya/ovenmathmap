> [!faq]- 全练一本通解析
>
> > [!success]- **【答案】** （1） $a_{n}=3n-1$ （2） $T_{n}=\frac{6n+7}{4\times3^{n-1}}-\frac{21}{4}$
>
> > [!note]- **【解析】**
> > （1）设数列 $\{a_{n}\}$ 的公差为 $d$ ， $\because a_{2} = 5, a_{3} + a_{5} = 22$ ， $\therefore a_{1} + d = 5, 2a_{1} + 6d = 22$ ， $\therefore a_{1} = 2, d = 3$ ， $\therefore a_{n} = a_{1} + (n - 1)d = 3n - 1$ （2）当 $n = 1, b_{1} = S_{1} = \frac{1}{2}(1 - 3) = -1$ 当 $n \geq 2$ 时， $b_{n} = S_{n} - S_{n - 1}$ ， $= \frac{1}{2}\left(3^{n - 1} - 3^{n}\right) = -3^{n - 1}$ ， $\therefore \frac{a_{n}}{b_{n}} = -\frac{3n - 1}{3^{n - 1}}$ ， $T_{n} = -\left[\frac{2}{3^{0}} + \frac{5}{3^{1}} + \frac{8}{3^{2}} + \dots + \frac{3n - 4}{3^{n - 2}} + \frac{3n - 1}{3^{n - 1}}\right]$ ①， $\frac{1}{3} T_{n} = -\left[\frac{2}{3} + \frac{5}{3^{2}} + \frac{8}{3^{3}} \dots + \frac{3n - 4}{3^{n - 1}} + \frac{3n - 1}{3^{n}}\right]$ ②，  
> > 由①-②得， $\frac{2}{3} T_{n} = -\left\{2 + 3\left[\frac{1}{3} + \frac{1}{3^{2}} + \dots + \frac{1}{3^{n - 1}}\right] - \frac{3n - 1}{3^{n}}\right\}$ ， $= -2 - \frac{3 \cdot \frac{1}{3}\left(1 - \frac{1}{3^{n - 1}}\right)}{1 - \frac{1}{3}} + \frac{3n - 1}{3^n}$ ， $\therefore T_{n} = \frac{6n + 7}{4 \times 3^{n - 1}} - \frac{21}{4}$ .
