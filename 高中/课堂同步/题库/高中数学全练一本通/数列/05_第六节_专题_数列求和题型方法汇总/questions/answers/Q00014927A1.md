> [!faq]- 全练一本通解析
>
> > [!success]- **【答案】** $a_{n} = \frac{n + 1}{2}$
>
> > [!note]- **【解析】**
> > 因为 $f(x) + f(1 - x) = 1$ 故 $a_{n} = f(0) + f\left(\frac{1}{n}\right) + f\left(\frac{n - 1}{n}\right) = 1.$ 故 $a_{n} = f(0) + f\left(\frac{1}{n}\right) + f\left(\frac{2}{n}\right) + \ldots +f\left(\frac{n - 1}{n}\right) + f(1).①$ $\therefore a_{n} = f(1) + f\left(\frac{n - 1}{n}\right) + f\left(\frac{n - 2}{n}\right) + \ldots +f\left(\frac{1}{n}\right) + f(0).②$ ∴ $① +②$ ，得 $2a_{n} = n + 1$ ，∴ $a_{n} = \frac{n + 1}{2}$ 所以数列 $\{a_n\}$ 的通项公式为 $a_{n} = \frac{n + 1}{2}$
