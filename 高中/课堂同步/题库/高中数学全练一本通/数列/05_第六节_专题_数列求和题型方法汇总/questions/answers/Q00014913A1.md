> [!faq]- 全练一本通解析
>
> > [!success]- **【答案】** （1） $b_{n} = 2n - 1$ ；（2） $S_{n} = 1 - \frac{1}{n + 1}$
>
> > [!note]- **【解析】**
> > （1）由条件 $a_{n+1} - 2a_n = 0(n\in N^*)$ 知， $\frac{a_{n+1}}{a_n} = 2$ ， $(n\in N^*)$ ，所以数列 $\{a_n\}$ 是公比为2的等比数列，又 $a_2 = 2\therefore a_n = 2^{n - 1}, n\in N^*$ 由 $b_{3} = a_{3} + 1$ 得 $b_{1} + 2d = 5$ ，由 $T_{4} = a_{5}$ 得 $4b_{1} + \frac{4\times3}{2} d = 16$ ，联立以上两个方程解得 $b_{1} = 1,d = 2$ ∴ $b_{n} = 2n - 1,n\in N^{*}$ ．（2）由（1）知 $c_{n} = \log_{2}a_{n+1} = \log_{2}2^{n} = n$ ，则 $\frac{1}{c_n c_{n+1}} = \frac{1}{n(n+1)} = \frac{1}{n} -\frac{1}{n+1}$ ，
> >
> > $\therefore S_{n}=1-\frac{1}{2}+\frac{1}{2}-\frac{1}{3}+\cdots+\frac{1}{n}-\frac{1}{n+1}=1-\frac{1}{n+1}$
