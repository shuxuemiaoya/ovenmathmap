> [!faq]- 全练一本通解析
>
> > [!success]- **【答案】** （1） $a_{n}=2n+1$ ， $b_{n}=\frac{1}{4n(n+1)}$ （2） $S_{n}=\frac{n}{4(n+1)}$
>
> > [!note]- **【解析】**
> > （1）由题意，可设等差数列 $\{a_{n}\}$ 的公差为 $d$ ，则 $\left\{ \begin{array}{l}a_1 + 2d = 7\\ 2a_1 + 10d = 26 \end{array} \right.$ ，解得 $a_1 = 3,d = 2,$ ∴ $a_{n} = 3 + 2(n - 1) = 2n + 1$ ∴ $b_{n} = \frac{1}{a_{n}^{2} - 1} = \frac{1}{(2n + 1)^{2} - 1} = \frac{1}{4n^{2} + 4n} = \frac{1}{4n(n + 1)}$ （2）∵ $b_{n} = \frac{1}{4n(n + 1)} = \frac{1}{4}\left(\frac{1}{n} -\frac{1}{n + 1}\right),$ $S_{n} = \frac{1}{4}\left(1 - \frac{1}{2} +\frac{1}{2} -\frac{1}{3} +\dots +\frac{1}{n} -\frac{1}{n + 1}\right) = \frac{1}{4}\left(1 - \frac{1}{n + 1}\right) = \frac{n}{4(n + 1)}.$
