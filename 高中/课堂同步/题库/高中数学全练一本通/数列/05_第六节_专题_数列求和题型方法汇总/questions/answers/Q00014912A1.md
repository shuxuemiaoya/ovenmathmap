> [!faq]- 全练一本通解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【解析】**
> > （1）设等差数列 $\{a_n\}$ 的公差为 $d$ 则 $\left\{ \begin{array}{l} a_3 = a_1 + 2d = 5 \\ S_9 = 9a_1 + 36d = 81 \end{array} \right.$ ，解得 $\left\{ \begin{array}{l} a_1 = 1 \\ d = 2 \end{array} \right.$ ∴ $a_{n} = 2n - 1$ ∴ $T_{n} = b_{n + 1} - 2$ ∴ $T_{n - 1} = b_{n} - 2, n \geq 2$ ，两式相减可得 $b_{n} = b_{n + 1} - b_{n}$ ，即 $\frac{b_{n + 1}}{b_n} = 2$ 又∵ $T_{1} = b_{1} = b_{2} - 2$ ，得 $b_{2} = 4$ ，∴ $\frac{b_2}{b_1} = 2$ ∴数列 $\{b_n\}$ 是以2为首项，2为公比的等比数列 ∴ $b_{n} = 2^{n}$ ；（2）由（1）得 $c_{n} = \frac{2n - 1}{2^{n}}$ ∴ $P_{n} = \frac{1}{2} + \frac{3}{2^{2}} + \frac{5}{2^{3}} + \dots + \frac{2n - 1}{2^n}$ ∴ $\frac{1}{2} P_{n} = \frac{1}{2^{2}} + \frac{3}{2^{3}} + \frac{5}{2^{4}} + \dots + \frac{2n - 1}{2^{n + 1}}$ ，两式相减得 $\frac{1}{2} P_{n} = \frac{1}{2} + \frac{2}{2^{2}} + \frac{2}{2^{3}} + \dots + \frac{2}{2^{n}} - \frac{2n - 1}{2^{n + 1}} = \frac{1}{2} + \frac{\frac{1}{2}\left(1 - \frac{1}{2^{n - 1}}\right)}{1 - \frac{1}{2}} - \frac{2n - 1}{2^{n + 1}} = \frac{3}{2} - \frac{2n + 3}{2^{n + 1}}$ ∴ $P_{n} = 3 - \frac{2n + 3}{2^{n}}$ ∴ $P_{n} = 3 - \frac{2n + 3}{2^{n}}$ ∴ $P_{n} = 0$ ∴ $P_{n} <  3$
