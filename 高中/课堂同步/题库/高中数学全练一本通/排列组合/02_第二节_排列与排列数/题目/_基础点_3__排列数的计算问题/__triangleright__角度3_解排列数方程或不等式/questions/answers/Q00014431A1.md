> [!faq]- 全练一本通解析
>
> > [!success]- **【答案】** $n = 6$ 或 $n = 7$ 因为 $A_{7}^{n}< 12A_{7}^{n-2}(n \geq 3)$ ，所以 $\frac{7!}{(7-n)!} < 12 \times \frac{7!}{(9-n)(8-n)(7-n)!}$ . 因为 $3 \leq n \leq 7$ ，所以 $(9-n)(8-n) < 12$ 即 $n^2 - 17n + 60 < 0$ ，解得 $5 < n < 12$ 所以 $5 < n \leq 7$ ，又 $n \in N^{*}$ ，所以 $n = 6$ 或 $n = 7$ .
