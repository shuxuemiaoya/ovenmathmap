> > [!note]- **【解析】**
> > $\because (x + y + z)^{4} = \left[(x + y) + z\right]^{4}$ $= C_{4}^{0}(x + y)^{4} + C_{4}^{1}(x + y)^{3}z + C_{4}^{2}(x + y)^{2}z^{2} + C_{4}^{3}(x + y)z^{3} + C_{4}^{4}z^{4}$ 由二项式定理可知， $(x + y)^{n}$ 展示式中共有 n + 1 项， $\therefore (x + y + z)^{4}$ 的展开式共有 $5 + 4 + 3 + 2 + 1 = 15$ 项. 故选：B.
