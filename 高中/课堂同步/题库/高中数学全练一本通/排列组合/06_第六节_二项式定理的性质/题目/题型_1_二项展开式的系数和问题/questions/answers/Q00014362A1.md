> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > （1） $2^{100}$ （2） $(2 - \sqrt{3})^{100} - 2^{100}$ （3） $\frac{(2 - \sqrt{3})^{100} - (2 + \sqrt{3})^{100}}{2}$ （4）1（5） $(2 + \sqrt{3})^{100}$ 【详解】（1）在 $(2 - \sqrt{3}x)^{100} = a_{0} + a_{1}x + a_{2}x^{2} + \cdots + a_{100}x^{100}$ 中，令 x = 0，得 $a_{0} = 2^{100}$ .
> > （2）令 x = 1，得 $a_{0} + a_{1} + a_{2} + \cdots + a_{100} = (2 - \sqrt{3})^{100}$ ①，
> > 则 $a_{1} + a_{2} + \cdots + a_{100} = (2 - \sqrt{3})^{100} - 2^{100}$ .
> > （3）令 x = -1，得 $a_{0} - a_{1} + a_{2} - a_{3} + \cdots - a_{99} + a_{100} = (2 + \sqrt{3})^{100}$ ②，
> > 联立①②，得 $a_{1} + a_{3} + a_{5} + \cdots + a_{99} = \frac{(2 - \sqrt{3})^{100} - (2 + \sqrt{3})^{100}}{2}$ .
> > （4） $(a_{0} + a_{2} + a_{4} + \cdots + a_{100})^{2} - (a_{1} + a_{3} + a_{5} + \cdots + a_{99})^{2} = (a_{0} + a_{1} + a_{2} + \cdots + a_{100})(a_{0} - a_{1} + a_{2} - a_{3} + \cdots - a_{99} + a_{100}) = (2 - \sqrt{3})^{100}\cdot(2 + \sqrt{3})^{100}=[(2 - \sqrt{3})(2 + \sqrt{3})]^{100}=1.$ （5）方法 1：因为 $(2 - \sqrt{3}x)^{100}$ 的展开式的通项为 $T_{k+1}=C_{100}^{k}\cdot2^{100-k}\cdot(-\sqrt{3}x)^{k}=(-1)^{k}\cdot C_{100}^{k}\cdot2^{100-k}\cdot(\sqrt{3}x)^{k},$ 所以 $a_{0}>0, a_{1}<0, a_{2}>0, a_{3}<0, \cdots, a_{99}<0, a_{100}>0,$ 所以 $|a_{0}|+|a_{1}|+|a_{2}|+\cdots+|a_{100}|=a_{0}-a_{1}+a_{2}-a_{3}+a_{4}-\cdots+a_{100}=2+\sqrt{3})^{100}.$ 方法 2：将二项式 $(2-\sqrt{3}x)^{100}$ 变为 $(2+\sqrt{3}x)^{100}$ 即可消除负号，令 x=1 可得到 $|a_{0}|+|a_{1}|+|a_{2}|+\cdots+|a_{100}|=(2+\sqrt{3})^{100}.$
