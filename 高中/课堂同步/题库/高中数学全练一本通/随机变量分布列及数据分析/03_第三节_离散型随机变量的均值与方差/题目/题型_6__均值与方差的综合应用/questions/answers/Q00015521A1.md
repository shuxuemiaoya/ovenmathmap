> [!faq]- 全练一本通解析
>
> > [!success]- **【答案】** （1）① $\frac{1}{2}$ ;②分布列答案见解析,数学期望:700元
>
> > [!note]- **【解析】**
> > (2) 答案见解析
> >
> > [!note]- **【解析】**
> > （1）设员工所获得的奖励额为 X,
> >
> > ① $P(X=1000)=\frac{C_{3}^{1}}{C_{4}^{2}}=\frac{1}{2}$ ,
> >
> > ∴员工所获得的奖励额为1000元的概率为 $\frac{1}{2}$ ;
> >
> > ②X 所有可能的取值为 400, 1000,
> >
> > $P(X = 400) = \frac{C_3^2}{C_4^2} = \frac{1}{2}, P(X = 1000) = 1 - P(X = 400) = \frac{1}{2},$
> >
> > $\therefore X$ 的分布列为
> >
> > <table><tr><td>X</td><td>400</td><td>1000</td></tr><tr><td>P</td><td> $\frac{1}{2}$ </td><td> $\frac{1}{2}$ </td></tr></table>
> >
> > ∴员工所获得的奖励额的期望为 $E(X)=400\times\frac{1}{2}+1000\times\frac{1}{2}=700$ 元；
> >
> > （2）根据公司预算,每个员工的平均奖励额为1000元,
> >
> > 所以先寻找期望为 1000 元的可能方案,
> >
> > 对于面值由 800 元和 200 元组成的情况,
> >
> > 如果选择（200, 200, 200, 800）的方案, 因为 1000 元是面值之和的最大值,
> >
> > 所以期望不可能为 1000 元,
> >
> > 如果选择（800, 800, 800, 200）的方案，
> >
> > 因为 1000 元是面值之和的最小值, 所以期望不可能为 1000 元,
> >
> > 因此可能的方案是（800, 800, 200, 200）记为方案1，
> >
> > 对于面值 600 元和 400 元的情况,
> >
> > 同理排除（600, 600, 600, 400）和（400, 400, 400, 600）的方案，
> >
> > 所以可能的方案是（400, 400, 600, 600）记为方案2，
> >
> > 对于方案1,设员工所获得的奖励额为 $X_{1}$ ， $X_{1}$ 可取400,1000,1600，
> >
> > $$
> > P (X = 4 0 0) = \frac {\mathrm{C} _ {2} ^ {2}}{\mathrm{C} _ {4} ^ {2}} = \frac {1}{6}, P (X = 1 0 0 0) = \frac {\mathrm{C} _ {2} ^ {1} \mathrm{C} _ {2} ^ {1}}{\mathrm{C} _ {4} ^ {2}} = \frac {2}{3}, P (X = 1 6 0 0) = \frac {\mathrm{C} _ {2} ^ {2}}{\mathrm{C} _ {4} ^ {2}} = \frac {1}{6},
> > $$
> >
> > ∴ $X_{1}$ 的期望为 $E(X_{1})=400\times\frac{1}{6}+1000\times\frac{2}{3}+1600\times\frac{1}{6}=1000$
> >
> > 方差
> >
> > $$
> > D \left(X _ {1}\right) = (4 0 0 - 1 0 0 0) ^ {2} \times \frac {1}{6} + (1 0 0 0 - 1 0 0 0) ^ {2} \times \frac {2}{3} + (1 6 0 0 - 1 0 0 0) ^ {2} \times \frac {1}{6} = 1 2 0 0 0 0
> > $$
> >
> > 对于方案2,设员工所获得的奖励额为 $X_{2}$ ， $X_{1}$ 可取800,1000,1200，
> >
> > $$
> > P (X = 8 0 0) = \frac {\mathrm{C} _ {2} ^ {2}}{\mathrm{C} _ {4} ^ {2}} = \frac {1}{6}, P (X = 1 0 0) = \frac {\mathrm{C} _ {2} ^ {1} \mathrm{C} _ {2} ^ {1}}{\mathrm{C} _ {4} ^ {2}} = \frac {2}{3}, P (X = 1 2 0 0) = \frac {\mathrm{C} _ {2} ^ {2}}{\mathrm{C} _ {4} ^ {2}} = \frac {1}{6},
> > $$
> >
> > ∴ $X_{2}$ 的期望为 $E(X_{2})=800\times\frac{1}{6}+1000\times\frac{2}{3}+1200\times\frac{1}{6}=1000$
> >
> > 方差
> >
> > $$
> > D \left(X _ {2}\right) = \frac {1}{6} \times (8 0 0 - 1 0 0 0) ^ {2} + \frac {2}{3} \times (1 0 0 0 - 1 0 0 0) ^ {2} + \frac {1}{6} \times (1 2 0 0 - 1 0 0 0) ^ {2} = \frac {4 0 0 0 0}{3}
> > $$
> >
> > 由于两种方案的奖励额都符合预算要求,但方案2的方差比方案1小,所以应选择方案2.
