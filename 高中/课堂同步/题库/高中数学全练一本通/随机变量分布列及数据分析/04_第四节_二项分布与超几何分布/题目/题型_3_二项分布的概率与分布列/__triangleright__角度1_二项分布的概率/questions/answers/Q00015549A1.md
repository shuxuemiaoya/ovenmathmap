> [!faq]- 全练一本通解析
>
> > [!success]- **【答案】** D
>
> > [!note]- **【解析】**
> > 由二项分布的知识得 $P(X \leq 3) = 1 - P(X = 4) = 1 - p^{4} = \frac{15}{16}$ ，得 $p^{4} = \frac{1}{16}$ ，又 0 < p < 1，所以 $p = \frac{1}{2}$ ，
> >
> > 所以 $P(X = 3) = \mathrm{C}_4^3\times \left(\frac{1}{2}\right)^3\times \left(1 - \frac{1}{2}\right) = \frac{1}{4}.$ 故选：D.
