## 3. 超几何分布

(1) 定义: 一般地, 假设一批产品共有 N 件, 其中有 M 件次品. 从 N 件产品中随机抽取 n 件 (不放回), 用 X 表示抽取的 n 件产品中的次品数, 则 X 的分布列为 $P(X=k)=\frac{\mathrm{C}_{M}^{k}\mathrm{C}_{N-M}^{n-k}}{\mathrm{C}_{N}^{n}}, k=m,m+1,m+2,\cdots,r$ . 其中 $n,N,M\in\mathbf{N}^{*}, M\leqslant N, n\leqslant N, m=\max\{0,n-N+M\}, r=\min\{n,M\}$ . 如果随机变量 X 的分布列具有上式的形式, 称这里的 X 服从参数为 N, n, M 的超几何分布, 记作 $X\sim H(N,n,M)$
