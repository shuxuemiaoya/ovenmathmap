> [!faq]- 全练一本通解析
>
> > [!success]- **【答案】** B
>
> > [!note]- **【解析】**
> > $\because y = ce^{kx}(c > 0),$ ∴两边取对数，可得 $\ln y = \ln (ce^{kx}) = \ln c + \ln e^{kx} = \ln c + kx$ ，令 $z = \ln y$ ，可得 $z = \ln c + kx$ ，∵线性回归方程 $z = 2x - 1,$ ∴ $\ln c = -1,k = 2$ ，解得 $c = \frac{1}{\mathrm{e}},k = 2$ .故选：B.
