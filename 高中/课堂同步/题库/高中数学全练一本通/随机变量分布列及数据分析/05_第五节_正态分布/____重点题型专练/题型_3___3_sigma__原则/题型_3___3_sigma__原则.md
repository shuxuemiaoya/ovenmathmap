## 题型 3: $3\sigma$ 原则

若 $X \sim N\left(\mu, \sigma^2\right)$ , 则

① $P(\mu - \sigma < X \leq \mu + \sigma) = 0.6827$ ;

② $P(\mu - 2\sigma < X \leq \mu + 2\sigma) = 0.9545$

③ $P(\mu - 3\sigma < X \leq \mu + 3\sigma) = 0.9973$ .
