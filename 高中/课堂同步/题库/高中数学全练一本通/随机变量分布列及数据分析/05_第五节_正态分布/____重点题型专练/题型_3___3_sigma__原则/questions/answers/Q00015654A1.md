> > 所以 $P(96 \leq X \leq 108) = P(\mu - \sigma \leq X \leq \mu + 2\sigma)$ $= \frac{1}{2}\left[P(\mu - \sigma \leq X \leq \mu + \sigma) + P(\mu - 2\sigma \leq X \leq \mu + 2\sigma)\right]$ $= \frac{1}{2} \times (0.6827 + 0.9545) = 0.8186$ .故选:B
