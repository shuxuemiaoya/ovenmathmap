> [!faq]- 全练一本通解析
>
> > [!success]- **【答案】** C
>
> > [!note]- **【解析】**
> > 因为 $\frac{P(X < 3)}{P(X < 1)} = 4,$ 所以 $P(X < 3) = 4P(X < 1), P(X < 3) + P(X \geq 3) = 1,$ 又因为正态分布的对称轴为 2，所以 $P(X \geq 3) = P(X < 1),$ 所以 $4P(X < 1) + P(X < 1) = 1, P(X < 1) = \frac{1}{5},$ 所以 $P(2 < X < 3) = P(1 < X < 2) = \frac{1}{2} - P(X < 1) = \frac{1}{2} - \frac{1}{5} = \frac{3}{10} .$ 故选：C。
