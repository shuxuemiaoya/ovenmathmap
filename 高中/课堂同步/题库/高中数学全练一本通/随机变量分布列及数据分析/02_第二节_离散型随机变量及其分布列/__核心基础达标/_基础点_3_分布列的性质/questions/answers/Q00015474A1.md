> [!faq]- 全练一本通解析
>
> > [!success]- **【答案】** （1） $a=\frac{1}{15}$ （2） $\frac{4}{5}$ （3） $\frac{1}{5}$
>
> > [!note]- **【解析】**
> > （1）解:由题意得随机变量 X 的分布列如下表所示.
> >
> > <table><tr><td>X</td><td>1/5</td><td>2/5</td><td>3/5</td><td>4/5</td><td>1</td></tr><tr><td>P</td><td>a</td><td>2a</td><td>3a</td><td>4a</td><td>5a</td></tr></table>
> >
> > 由分布列的性质得， $a+2a+3a+4a+5a=1$ ，解得 $a=\frac{1}{15}$ .
> >
> > (2) 解: $P\left(X \geq \frac{3}{5}\right) = P\left(X = \frac{3}{5}\right) + P\left(X = \frac{4}{5}\right) + P(X = 1) = \frac{3}{15} + \frac{4}{15} + \frac{5}{15} = \frac{4}{5}$ .
> > (3) 解: $\because \frac{1}{10} < X < \frac{3}{5}, \therefore X = \frac{1}{5}$ 或 $X = \frac{2}{5}$ , $\therefore P\left(\frac{1}{10}<X<\frac{3}{5}\right)=P\left(X=\frac{1}{5}\right)+P\left(X=\frac{2}{5}\right)=\frac{1}{15}+\frac{2}{15}=\frac{1}{5}$
