> [!faq]- 全练一本通解析
> **【答案】** D
>
> **【解析】**
> 解析: 若 $a \parallel b$ 且 $b \subset \alpha$ ，则 $a \parallel \alpha$ 或 $a \subset \alpha$ ，故命题错误；
若 $a \parallel \alpha$ 且 $b \subset \alpha$ ，则 $a \parallel b$ 或 a, b 为异面直线，故命题错误；
若 $a \parallel b$ 且 $a \parallel \alpha$ ，则 $b \parallel \alpha$ 或 $b \subset \alpha$ ，故命题错误；
若 $a / / \alpha$ 且 $b / / \alpha$ ，则 $a / / b$ 或 a, b 相交或异面，故命题错误.
故选:D.
