> [!faq]- 全练一本通解析
> **【答案】** D
>
> **【解析】**
> 解析:A. 如图所示:
![](../../../../../images/answers/53f699a95ec22afc32a5805835c47a94a57baadd9a757c9249c852977111c6bb.jpg)
存在一条直线 $a, a // \alpha, a // \beta$ ，但平面 $\alpha$ 与平面 $\beta$ 相交，故错误；B. 如图所示：
![](../../../../../images/answers/bd5210bb4bb3b9f4cde50549f3440b2bb61754b5a41b96af9159ba0d99039205.jpg)
存在一条直线 $a, a \subset \alpha, a // \beta$ ，但平面 $\alpha$ 与平面 $\beta$ 相交，故错误；C. 如图所示：
![](../../../../../images/answers/b5038eb5ab10f097096d1dbd8812f0483d2863b7496ab65a7437ab145dead82f.jpg)
存在两条平行直线 $a, b, a \subset \alpha, b \subset \beta, a // \beta, b // \alpha$ ，但平面 $\alpha$ 与平面 $\beta$ 相交，故错误；
D. 如图所示:
![](../../../../../images/answers/f290802d481cda43acf77e40b65d1d43af28ddf14b02bc273a25034f19e89eb8.jpg)
在平面 $\beta$ 内过 $b$ 上一点 $P$ 作 $c // a$ , 则 $c // \alpha$ , 又 $b // \alpha$ , 且 $b \cap c = P$ , 所以 $\alpha // \beta$ , 故正确; 故选: D
