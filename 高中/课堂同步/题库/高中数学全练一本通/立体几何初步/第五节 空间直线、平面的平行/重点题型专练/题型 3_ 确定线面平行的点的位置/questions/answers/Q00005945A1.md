> [!faq]- 全练一本通解析
> **【解析】**
> 当 L 是 DF 上靠近点 D 的三等分点时，CL // 平面 AEF
解析: 当 L 是 DF 上靠近点 D 的三等分点时，CL // 平面 AEF. 理由如下：
延长 AE，DC 交于点 M，连接 FM，
易知 $\triangle ABE \sim \triangle MCE$ ， $\therefore \frac{CM}{AB} = \frac{CE}{BE} = 2$ ∵ AB = CD, ∴ $\frac{CM}{CD} = 2$ .
当 L 是 DF 上靠近点 D 的三等分点时， $\frac{FL}{DL}=2,\therefore\frac{CM}{CD}=\frac{FL}{DL},\therefore LC//FM$ ∵ FM ⊂ 平面 AEF, LC ≠ 平面 AEF, ∴ LC // 平面 AEF.
