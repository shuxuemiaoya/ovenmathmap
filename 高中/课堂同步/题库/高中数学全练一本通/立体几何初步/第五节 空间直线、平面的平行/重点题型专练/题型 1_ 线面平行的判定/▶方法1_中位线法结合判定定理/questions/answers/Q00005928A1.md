解析:证明:延长 AD,BC 交于点 M, 因为 CD // AB, AB=2CD,
![](../../../../../../images/answers/afc5df7c4ca8a861c126e1756157c27c6d8a8ac523c8810684e0ef0027944911.jpg)
所以 D 为 AM 的中点, 因为 PA 的中点为 E, 所以 DE // PM,
因为 DE ⊂ 平面 DEF, PM ∉ 平面 DEF, 所以 PM // 平面 DEF,
又 P, M ∈ 平面 PAD, P, M ∈ 平面 PBC,
所以平面 PAD ∩ 平面 PBC = PM, 即直线 l 为直线 PM.
所以 l // 平面 DEF.
