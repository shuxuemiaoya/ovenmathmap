> [!faq]- 全练一本通解析
> **【答案】** 详见解析
>
> **【解析】**
> 解析: 因为 D, C, E, F 分别是 AQ, BQ, AP, BP 的中点, 所以 EF // AB, DC // AB, 所以 EF // DC.
> 又 $EF \not\subset$ 平面 PCD, $DC \subset$ 平面 PCD, 所以 EF // 平面 PCD.
> 因为 $EF \subset$ 平面 EFQ，平面 $EFQ \cap$ 平面 $PCD = GH$ ，所以 $EF // GH$ .
> 又 EF // AB，所以 AB // GH.
