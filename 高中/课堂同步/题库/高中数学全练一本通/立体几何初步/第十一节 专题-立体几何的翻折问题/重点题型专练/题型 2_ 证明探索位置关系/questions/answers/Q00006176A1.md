> [!faq]- 全练一本通解析
> **【答案】** B
>
> **【解析】**
> 解析：
![](../../../../../images/answers/e1a99cd93faf89c9888f6b3fde46a92dcccaf3b81c44bb08fcd8175297325d20.jpg)
取 $A_{1}D$ 的中点 $N$ ，连接 $MN, NE$ ，则有 $MN // CD, MN = \frac{1}{2} CD,$ 又 $EB // CD, EB = \frac{1}{2} AB = \frac{1}{2} CD,$ $\therefore MN // EB, MN = EB,$ 四边形MNEB是平行四边形，故 $BM // NE$ 又 $BM\not\subset$ 平面 $A_{1}DE, NE\subset$ 平面 $A_{1}DE,$ $\therefore BM //$ 平面 $A_{1}DE,$ 故①正确；设 $AB = 2AD = 2,$ 则 $DE = CE = \sqrt{2}, CD = 2,$ $\therefore DE^{2} + CE^{2} = CD^{2}$ ，故 $DE\perp CE,$ 若 $DE\perp A_{1}C,$ 成立，则 $DE\perp$ 平面 $A_{1}CE,$ $\therefore DE\perp AE,$ 与 $\angle DEA_{1} = \angle AED = 45^{\circ}$ 矛盾， $DE$ 不可能垂直 $A_{1}C,$ 故②错误；由（1）可知 $BM = NE,$ 故 $BM$ 长为定值，故③正确；过 $M$ 作 $CD$ 的垂线，垂足为 $F$ ，连接 $MF, BF,$ 若 $BM\perp$ 平面 $A_{1}CD,$ 则 $BM\perp CD,$ 又 $CD\perp MF,$ $\therefore CD\perp$ 平面 $BMF,$ $\therefore CD\perp BF,$ 这与 $BC\perp CD$ 矛盾，故④错误.故选：B
