> [!faq]- 全练一本通解析
> **【答案】** （1） $\left[-4, \frac{2}{3}\right]$ ；（2） $\left[-2, \frac{4}{3}\right]$ ；（3） $\left[\frac{1}{3}, 3\right]$ ；（4） $\left[-\frac{1}{3}, \frac{1}{3}\right]$
>
> **【解析】**
> （1） $\because y = \frac{3\sin x + 1}{\sin x - 2} = \frac{3(\sin x - 2) + 7}{\sin x - 2} = 3 + \frac{7}{\sin x - 2}$ ， $\because -1 \leq \sin x \leq 1, \therefore -3 \leq \sin x - 2 \leq -1,$ $\therefore -1 \leq \frac{1}{\sin x - 2} \leq -\frac{1}{3},$ $\therefore -7 \leq \frac{7}{\sin x - 2} \leq -\frac{7}{3},$ $\therefore -4 \leq 3 + \frac{7}{\sin x - 2} \leq \frac{2}{3},$ $\therefore y = \frac{3\sin x + 1}{\sin x - 2} \in [-4, \frac{2}{3}]$ ，
> 故 $y = \frac{3\sin x + 1}{\sin x - 2}$ 的值域为 $\left[-4, \frac{2}{3}\right]$ .
> （2） $y = \frac{3\sin x + 1}{\sin x + 2} = \frac{3(\sin x + 2) - 5}{\sin x + 2} = 3 - \frac{5}{\sin x + 2}$ . $\because -1 \leq \sin x \leq 1, \therefore 1 \leq \sin x + 2 \leq 3,$ $\therefore \frac{1}{3} \leq \frac{1}{\sin x + 2} \leq 1, \therefore -2 \leq 3 - \frac{5}{\sin x + 2} \leq \frac{4}{3}$ ，即 $-2 \leq y \leq \frac{4}{3}$ ， $\therefore$ 函数的值域为 $\left[-2, \frac{4}{3}\right]$ .
> 故答案为： $\left[-2, \frac{4}{3}\right]$ .
> （3） $y = \frac{4 - (2 + \cos x)}{2 + \cos x} = \frac{4}{2 + \cos x} - 1,$ 因为 $-1 \leq \cos x \leq 1$
> 所以 $1 \leq 2 + \cos x \leq 3$ ,
> 所以 $\frac{1}{3} \leq \frac{1}{2 + \cos x} \leq 1$ ,
> 所以 $\frac{4}{3} \leq \frac{4}{2 + \cos x} \leq 4$ ,
> 所以 $\frac{1}{3} \leq \frac{4}{2 + \cos x} - 1 \leq 3$ ,
> 所以 $\frac{1}{3} \leq y \leq 3$ 所以函数 $y = \frac{2 - \cos x}{2 + \cos x}$ 的值域为 $\left[\frac{1}{3}, 3\right]$ .
> （4）函数 $f(x)=\frac{2^{\cos x}-1}{2^{\cos x}+1}=\frac{2^{\cos x}+1-2}{2^{\cos x}+1}=1-\frac{2}{2^{\cos x}+1}$ ，
> 因为 $-1 \leq \cos x \leq 1$ 所以 $\frac{1}{2} \leq 2^{\cos x} \leq 2, \frac{2}{3} \leq \frac{2}{2^{\cos x} + 1} \leq \frac{4}{3}$ 所以 $-\frac{1}{3} \leq 1 - \frac{2}{2^{\cos x} + 1} \leq \frac{1}{3}, f(x) \in \left[-\frac{1}{3}, \frac{1}{3}\right]$ ,
> 故答案为： $\left[-\frac{1}{3},\frac{1}{3}\right]$ .
