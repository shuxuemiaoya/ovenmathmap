## 3. 万能公式（用正切来表示正余弦的倍角）

$\sin 2\alpha = 2\sin \alpha \cos \alpha = \frac{2\sin \alpha \cos \alpha}{\sin^2\alpha + \cos^2\alpha} = \frac{2\tan\alpha}{1 + \tan^2\alpha}$ 即 $\sin 2\alpha = \frac{2\tan\alpha}{1 + \tan^2\alpha}$ .

$$
\cos 2 \alpha = \cos^ {2} \alpha - \sin^ {2} \alpha = \frac {\cos^ {2} \alpha - \sin^ {2} \alpha}{\sin^ {2} \alpha + \cos^ {2} \alpha} = \frac {1 - \tan^ {2} \alpha}{1 + \tan^ {2} \alpha} \text {即} \cos 2 \alpha = \frac {1 - \tan^ {2} \alpha}{1 + \tan^ {2} \alpha}.
$$
