> **【解析】**
> （1） $\frac{1}{4}$ ；（2） $\frac{\sqrt{3}}{2}$ ；（3） $\frac{\sqrt{2}}{2}$ ；（4）1；（5）-2；（6） $\frac{1}{2}\sin 2\alpha$
(7) $\left|\tan\alpha\right|$ ; (8) 2; (9) -4; (10) $\frac{1}{4}\sin2\alpha$ ;
解析：（1） $\sin 75^{\circ}\cos 75^{\circ} = \frac{1}{2}\times 2\sin 75^{\circ}\cos 75^{\circ} = \frac{1}{2}\sin 150^{\circ} = \frac{1}{2}\sin 30^{\circ} = \frac{1}{4}$
(2) $\cos^2 15^\circ - \sin^2 15^\circ = \cos 2 \times 15^\circ = \cos 30^\circ = \frac{\sqrt{3}}{2}$ ;
(3) $1 - 2\sin^2 22.5^\circ = \cos 45^\circ = \frac{\sqrt{2}}{2}$ ;
(4) $\frac{2\tan 22.5^{\circ}}{1 - \tan^{2}22.5^{\circ}} = \tan (2\times 22.5^{\circ}) = \tan 45^{\circ} = 1;$
$$
\frac {\sin^ {2} 5 ^ {\circ} - \cos^ {2} 5 ^ {\circ}}{\sin 4 0 ^ {\circ} \cos 4 0 ^ {\circ}} = \frac {- \cos 1 0 ^ {\circ}}{\frac {1}{2} \sin 8 0 ^ {\circ}} = \frac {- \sin 8 0 ^ {\circ}}{\frac {1}{2} \sin 8 0 ^ {\circ}} = - 2
$$
(6) 原式 $=\frac{\cos2\alpha}{\frac{\cos\alpha}{\sin\alpha}-\frac{\sin\alpha}{\cos\alpha}}=\frac{\cos2\alpha}{\frac{\cos^{2}\alpha-\sin^{2}\alpha}{\sin\alpha\cdot\cos\alpha}}=\frac{\cos2\alpha}{\frac{\cos2\alpha}{\frac{1}{2}\sin2\alpha}}=\frac{1}{2}\sin2\alpha$ ;
(7) $\sqrt{\frac{1 - \cos 2\alpha}{1 + \cos 2\alpha}} = \sqrt{\frac{1 - (1 - 2\sin^2\alpha)}{1 + (2\cos^2\alpha - 1)}} = \sqrt{\frac{2\sin^2\alpha}{2\cos^2\alpha}} = \sqrt{\tan^2\alpha} = |\tan \alpha|;$
(8) $\frac{3 - \sin 70^{\circ}}{2 - \cos^{2}10^{\circ}} = \frac{3 - \cos 20^{\circ}}{2 - \cos^{2}10^{\circ}} = \frac{3 - (2\cos^{2}10^{\circ} - 1)}{2 - \cos^{2}10^{\circ}} = \frac{2(2 - \cos^{2}10^{\circ})}{2 - \cos^{2}10^{\circ}} = 2;$
（9）原式 $= \frac{\sqrt{3} - \frac{\sin 80^{\circ}}{\cos 80^{\circ}}}{\cos 10^{\circ}} = \frac{\sqrt{3}\cos 80^{\circ} - \sin 80^{\circ}}{\cos 10^{\circ}\cos 80^{\circ}}$ $= \frac{2(\sin 60^{\circ}\cos 80^{\circ} - \cos 60^{\circ}\sin 80^{\circ})}{\cos 10^{\circ}\cos 80^{\circ}}$ $= \frac{2\sin(-20^{\circ})}{\cos 10^{\circ}\sin 10^{\circ}}$ $= \frac{-4\sin 20^{\circ}}{\sin 20^{\circ}} = -4;$ (10） $\frac{\cos^2\alpha}{\frac{1}{\tan\frac{\alpha}{2}} - \tan\frac{\alpha}{2}} = \frac{\cos^2\alpha}{\frac{\cos\frac{\alpha}{2}}{\sin\frac{\alpha}{2}} - \frac{\sin\frac{\alpha}{2}}{\cos\frac{\alpha}{2}}}$ $= \frac{\cos^2\alpha}{\frac{\cos^2\frac{\alpha}{2} - \sin^2\frac{\alpha}{2}}{\sin\frac{\alpha}{2}\cos\frac{\alpha}{2}}} = \frac{\cos^2\alpha\sin\frac{\alpha}{2}\cos\frac{\alpha}{2}}{\cos^2\frac{\alpha}{2} - \sin^2\frac{\alpha}{2}}$ $= \frac{\cos^2\alpha\sin\frac{\alpha}{2}\cos\frac{\alpha}{2}}{\cos\alpha} = \cos \alpha \sin \frac{\alpha}{2}\cos \frac{\alpha}{2}$ $= \frac{1}{2}\sin \alpha \cos \alpha = \frac{1}{4}\sin 2\alpha ;$
