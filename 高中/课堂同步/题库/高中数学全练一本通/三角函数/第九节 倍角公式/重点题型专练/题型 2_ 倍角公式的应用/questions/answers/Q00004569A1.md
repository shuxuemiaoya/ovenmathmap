> **【答案】** A

> **【解析】**
> 解析: 所以 $\tan A\tan B = \tan 2B\tan B = \frac{2\tan^2B}{1 - \tan^2B} = -2 + \frac{2}{1 - \tan^2B}$ , 因为锐角三角形,
所以 $\left\{ \begin{array}{l} 0 < A < \frac{\pi}{2} \\ 0 < B < \frac{\pi}{2} \\ 0 < C < \frac{\pi}{2} \end{array} \right. \Rightarrow \left\{ \begin{array}{l} 0 < 2B < \frac{\pi}{2} \\ 0 < B < \frac{\pi}{2} \\ 0 < C < \frac{\pi}{2} \end{array} \right. \Rightarrow \frac{\pi}{6} < B < \frac{\pi}{4}$ , 所以 $\frac{1}{3} < \tan^2B < 1$ ,
所以 $\tan A\tan B = -2 + \frac{2}{1 - \tan^2B} > 1$ .
所以 $\tan A\tan B$ 的取值范围是: (1, +∞), 故选: A.
