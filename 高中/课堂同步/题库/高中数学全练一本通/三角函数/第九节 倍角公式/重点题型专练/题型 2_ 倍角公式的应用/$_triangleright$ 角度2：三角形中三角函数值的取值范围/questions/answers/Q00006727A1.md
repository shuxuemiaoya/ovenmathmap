> [!faq]- 全练一本通解析
> **【解析】**
> (-1,3]
> 解析: 因为 $A = \frac{\pi}{4}$ , 故 $B + C = \frac{3\pi}{4}$ , 即 $B = \frac{3\pi}{4} - C$ .
> 故 $\sin 2B + 2\sin C = \sin 2\left(\frac{3\pi}{4} - C\right) + 2\sin C = \sin\left(\frac{3\pi}{2} - 2C\right) + 2\sin C$ $= -\cos 2C + 2\sin C = 2\sin^2C - 1 + 2\sin C = 2\left(\sin C + \frac{1}{2}\right)^2 - \frac{3}{2}$ .
> 因为 $A = \frac{\pi}{4}$ , 则 $C \in (0, \frac{3\pi}{4})$ , 故 $0 < \sin C \leq 1$ , 故 $\frac{1}{2} < \sin C + \frac{1}{2} \leq \frac{3}{2}$ ,
> 则 $-1 < 2\left(\sin C + \frac{1}{2}\right)^2 - \frac{3}{2} \leq 3$ , 即 $\sin 2B + 2\sin C$ 的取值范围为 (-1,3].
