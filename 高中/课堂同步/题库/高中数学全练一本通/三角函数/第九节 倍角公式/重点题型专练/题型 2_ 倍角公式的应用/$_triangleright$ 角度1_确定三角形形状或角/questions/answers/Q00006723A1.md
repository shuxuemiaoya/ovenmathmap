> [!faq]- 全练一本通解析
> **【答案】** $C = \frac{2\pi}{3}$
>
> **【解析】**
> 在 $\triangle ABC$ 中, $A + B + C = \pi$ ,
> 由 $8\sin A \cdot \cos A \cdot \sin B \cdot \cos B + 2\cos 2A \cdot \sin^{2}B = 2\cos 2A \cdot \cos^{2}B + 4\cos C + 3$ 得:
> \[ 2\sin 2A \cdot \sin 2B + 2\cos 2A \cdot \frac{1 - \cos 2B}{2} = 2\cos 2A \cdot \frac{1 + \cos 2B}{2} + 4\cos C + 3 \\
> \[ 2\sin 2A \cdot \sin 2B - 2\cos 2A \cdot \cos 2B = 4\cos C + 3 \\
> 即 -2\cos(2A + 2B) = 4\cos C + 3 \\
> 也即 -2\cos 2C = 4\cos C + 3 \\
> -2(2\cos^{2}C - 1) = 4\cos C + 3
> 即 $4\cos^{2}C + 4\cos C + 1 = 0$ , 解得 $\cos C = -\frac{1}{2}$ ,
> 又 $0 < C < \pi, ∴ C = \frac{2\pi}{3}$ ;
