> **【解析】**
> $\sqrt{2}$ 或 $-\sqrt{2}$ 。
解析：由题意可设角 $\alpha$ 的终边上任意一点 $A(x, x)$ ，则由三角函数的定义有 $\sin \alpha = \frac{x}{\sqrt{x^2 + x^2}} = \frac{x}{\sqrt{2} \cdot |x|} = \cos \alpha$ ，当 $x > 0$ 时， $\sin \alpha + \cos \alpha = \frac{1}{\sqrt{2}} + \frac{1}{\sqrt{2}} = \sqrt{2}$ ，当 $x < 0$ 时， $\sin \alpha + \cos \alpha = -\frac{1}{\sqrt{2}} + (-\frac{1}{\sqrt{2}}) = -\sqrt{2}$ 。故 $\sin \alpha + \cos \alpha = \sqrt{2}$ 或 $-\sqrt{2}$ 。
