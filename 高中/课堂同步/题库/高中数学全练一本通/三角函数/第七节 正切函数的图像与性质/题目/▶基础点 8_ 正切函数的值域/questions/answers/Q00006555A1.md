> [!faq]- 全练一本通解析
> **【解析】**
> $m = 3, n = 4$ 或 $m = -3, n = 4$ .
> 解析：当 $m = 0$ 时， $y = n$ ，不符合题意，舍去.
> 当 $m > 0$ 时， $y = m\tan x + n$ 在区间 $\left[-\frac{\pi}{4}, \frac{\pi}{4}\right]$ 上为增函数， $\begin{cases} y_{\min} = m\tan\left(-\frac{\pi}{4}\right) + n = -m + n = 1 \\ y_{\max} = m\tan\frac{\pi}{4} + n = m + n = 7 \end{cases}$ ，解得 $m = 3, n = 4$ .
> 当 $m < 0$ 时， $y = m\tan x + n$ 在区间 $\left[-\frac{\pi}{4}, \frac{\pi}{4}\right]$ 上为减函数， $\begin{cases} y_{\min} = m\tan\frac{\pi}{4} + n = m + n = 1 \\ y_{\max} = m\tan\left(-\frac{\pi}{4}\right) + n = -m + n = 7 \end{cases}$ ，解得 $m = -3, n = 4$ .
