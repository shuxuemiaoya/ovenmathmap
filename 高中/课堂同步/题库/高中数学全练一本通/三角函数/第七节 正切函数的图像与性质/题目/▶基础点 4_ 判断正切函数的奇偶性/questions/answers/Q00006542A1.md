> [!faq]- 全练一本通解析
> **【答案】** （1）偶函数；（2）奇函数；（3）既不是偶函数，也不是奇函数；（4）奇函数.
>
> **【解析】**
> （1）因为 $y=3x\tan2x-2x^{4}$ 的定义域为 $\left\{x\mid x\neq k\pi+\frac{\pi}{2},k\in\mathbf{Z}\right\}$ ，关于原点对称，且 $3(-x)\tan2(-x)-2(-x)^{4}=3x\tan2x-2x^{4}$ ，
> 所以 $y=3x\tan2x-2x^{4}$ 为偶函数.
> （2）由 $\frac{\tan x + 1}{\tan x - 1} >0$ ，得 $\tan x > 1$ 或 $\tan x < -1$ ，则 $\frac{\pi}{4} + k\pi < x < \frac{\pi}{2} + k\pi$ 或 $-\frac{\pi}{2} + k\pi < x < -\frac{\pi}{4} + k\pi$ ， $k\in Z$ ；
> ∴函数 $f(x)$ 的定义域为 $\left(k\pi -\frac{\pi}{2},k\pi -\frac{\pi}{4}\right)\cup \left(k\pi +\frac{\pi}{4},k\pi +\frac{\pi}{2}\right)(k\in \mathbf{Z})$ ，关于原点对称.
> 又 $f(-x) + f(x) = \lg \left(\frac{\tan(-x) + 1}{\tan(-x) - 1}\right) + \lg \left(\frac{\tan x + 1}{\tan x - 1}\right)$ $= \lg \left(\frac{-\tan x + 1}{-\tan x - 1}\cdot \frac{\tan x + 1}{\tan x - 1}\right) = \lg 1 = 0$ ，
> ∴ $f(-x) = f(x)$ ，∴ $f(x)$ 是奇函数.
> （3）由题知函数的定义域为 $\left\{x\mid x\neq k\pi -\frac{\pi}{4}\text{且}x\neq k\pi +\frac{\pi}{4},k\in Z\right\}$ ，定义域关于原点对称，
> 又 $f(-x) = \tan (-x - \frac{\pi}{4}) + \tan (-x + \frac{\pi}{4}) = -\tan (x + \frac{\pi}{4}) - \tan (x - \frac{\pi}{4}) = -f(x)$ 所以函数 $f(x) = \tan \left(x - \frac{\pi}{4}\right) + \tan \left(x + \frac{\pi}{4}\right)$ 是奇函数.
