> [!faq]- 全练一本通解析
> **【解析】**
> 详见解析
> 解析：（1）由 $k\pi -\frac{\pi}{2} < x + \frac{\pi}{5} < k\pi +\frac{\pi}{2},k\in Z$ 解得 $k\pi -\frac{7\pi}{10} < x < k\pi +\frac{3\pi}{10},k\in Z$ 所以函数 $y = \tan (x + \frac{\pi}{5})$ 的单调递增区间是 $(k\pi -\frac{7\pi}{10},k\pi +\frac{3\pi}{10})(k\in Z)$ ，无递减区间.
> （2）由 $-\frac{\pi}{2} + k\pi < \frac{\pi}{2} x + \frac{\pi}{3} < \frac{\pi}{2} + k\pi ,k\in Z$ 得 $-\frac{5}{3} + 2k < x < \frac{1}{3} + 2k,k\in Z$ 即函数 $y = \tan (\frac{\pi}{2} x + \frac{\pi}{3})$ 的单调递增区间为 $\left(-\frac{5}{3} + 2k,\frac{1}{3} + 2k\right),k\in Z.$ 无减区间.
> （3） $y = \tan \left(-\frac{1}{4} x + \frac{\pi}{4}\right) = -\tan \left(\frac{1}{4} x - \frac{\pi}{4}\right)$ 由 $-\frac{\pi}{2} + k\pi < \frac{1}{4} x - \frac{\pi}{4} < \frac{\pi}{2} + k\pi ,k\in Z$ 得 $-\pi +4k\pi < x < 3\pi +4k\pi ,k\in Z$ 所以，函数 $y = \tan \left(-\frac{1}{4} x + \frac{\pi}{4}\right)$ 的递减区间为 $\left(-\pi +4k\pi ,3\pi +4k\pi \right)(k\in Z)$ 无增区间.
