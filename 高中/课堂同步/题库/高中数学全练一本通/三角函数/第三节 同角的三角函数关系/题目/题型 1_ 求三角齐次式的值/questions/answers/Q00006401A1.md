> [!faq]- 全练一本通解析
> **【解析】**
> （1）\(-\frac{9}{5}\)；（2）\(\frac{2}{5}\).
> 解析：（1）\(\frac{\cos\alpha - 5\sin\alpha}{3\cos\alpha + sin\alpha} = \frac{1 - 5\tan\alpha}{3 + tan\alpha} = \frac{1 - 10}{3 + 2} = -\frac{9}{5}\);
> （2）由\(\frac{3\cos\alpha - sin\alpha}{\cos\alpha + 2sin\alpha} = \frac{1}{5}\)得：
> \(15\cos\alpha - 5\sin\alpha = cos\alpha + 2sin\alpha, ∴ 2cos\alpha = sin\alpha;\)
> 方法一：\(sin\alpha cos\alpha = \frac{\sin\alpha cos\alpha}{sin^2\alpha + cos^2\alpha} = \frac{2cos^2\alpha}{4cos^2\alpha + cos^2\alpha} = \frac{2}{5};\)
> 方法二：由\(2cos\alpha = sin\alpha\)得：\(tan\alpha = 2\)，
> \$\therefore sin\alpha cos\alpha = \frac{\sin\alpha cos\alpha}{sin^2\alpha + cos^2\alpha} = \frac{\tan\alpha}{tan^2\alpha + 1} = \frac{2}{2^2 + 1} = \frac{2}{5}.\)
