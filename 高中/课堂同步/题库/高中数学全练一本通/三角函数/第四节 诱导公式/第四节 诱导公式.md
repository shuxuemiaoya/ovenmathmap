## 1. 诱导公式

## 2. 诱导公式的进一步理解

诱导公式不仅为上述8组公式, 对于 $\sin\left(\frac{k\pi}{2}\pm\alpha\right)$ 的变换口诀可总结为 “奇变偶不变, 符号看象限” 理解如下:

“奇变偶不变”是指“当k为奇数时,正弦变余弦（余弦变正弦）;当k为偶数时,函数名不变”,

“符号看象限”是指“在将 $\alpha$ 默认为第一象限后, 确定 $\frac{k\pi}{2} \pm \alpha$ 所在的象限, 根据原函数所在象限的正负确定变换后三角函数值的正负”.

注意: 当使用诱导公式时, 要将 $\alpha$ 默认为第一象限角, 再进行变换.

例如： $\sin (3\pi +\alpha) = -\sin \alpha ;\cos (5\pi -\alpha) = -\cos \alpha ;\sin \left(\frac{5\pi}{2} +\alpha\right) = \cos \alpha ;\cos \left(\frac{7\pi}{2} -\alpha\right) = -\sin \alpha$

## 3. 利用诱导公式求任意角三角函数值的步骤

用诱导公式可将任意角的三角函数化为锐角的三角函数, 其一般方向是:

①化负角的三角函数为正角的三角函数；

②化为 $[0,2\pi]$ 内的三角函数；

③化为锐角的三角函数.

可概括为：“负化正, 大化小, 化到锐角为终了”（有时也直接化到锐角求值）.

## 4. 互余角与互补角的三角函数关系

（1）若 $\angle A + \angle B = \frac{\pi}{2}$ ，即 $\angle B$ 与 $\angle A$ 互余，根据诱导公式可得 $\sin B = \sin \left(\frac{\pi}{2} - A\right) = \cos A$ ，即 $\sin B = \cos A$ ，同理可得 $\cos B = \sin A$ 。

(2) 若 $\angle A + \angle B = \pi$ ，即 $\angle B$ 与 $\angle A$ 互补，根据诱导公式可得 $\sin B = \sin (\pi - A) = \sin A$ ，即 $\sin B = \sin A$ ，同理可得 $\cos B = \cos (\pi - A) = -\cos A$ ，即 $\cos B = -\cos A$ ，

注意: 此结论可用于利用诱导公式求值问题, 对于给值求值问题, 需要观察两角之间的关系, 观察是否存在互余或者互补关系, 若存在此关系, 可利用诱导公式关系进行凑角化简.

## 5. 诱导公式在三角形中的几个结论

设 A, B, C 是 $\triangle ABC$ 的三个内角, 则

(1) $\sin(A+B)=\sin(\pi-C)=\sin C$ ;

(2) $\cos(A+B)=\cos(\pi-C)=-\cos C;$

(3) $\tan(A+B)=\tan(\pi-C)=-\tan C$ ;

(4) $\sin \left(\frac{A}{2} +\frac{B}{2}\right) = \sin \left(\frac{\pi}{2} -\frac{C}{2}\right) = \cos \frac{C}{2};$

(5) $\cos \left(\frac{A}{2} +\frac{B}{2}\right) = \cos \left(\frac{\pi}{2} -\frac{C}{2}\right) = \sin \frac{C}{2}$
