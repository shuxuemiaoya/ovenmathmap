# 第十一节 正弦型三角函数的图像与性质

## 知识导学

## 1. 正弦型函数

一般地, 形如 $y = A \sin (\omega x + \varphi)$ 的函数称为正弦型函数, 其中 A, $\omega, \varphi$ 都是常数, 且 $A \neq 0, \omega \neq 0$ .

## 2. 五点法作正弦型函数图像

画 $y = A \sin(\omega x + \varphi)$ 的图象时, 将 $\omega x + \varphi$ 看成整体, 令 $\omega x + \varphi = 0, \frac{\pi}{2}, \pi, \frac{3\pi}{2}, 2\pi$ , 计算出对应 x 的值, 即为五个点的横坐标, 相应的函数值即为五个点的纵坐标.

## 4. 正弦型三角函数的处理策略：

正弦型函数 $y = A \sin (\omega x + \varphi)$ 是通过正弦函数 $y = \sin x$ 通过平移与伸缩得到, 所以在探究函数 $y = A \sin (\omega x + \varphi)$ 的性质 (定义域、值域、奇偶性、单调性, 则对称性等) 时, 可利用换元思想 (令 $t = \omega x + \varphi$ ), 将 $\omega x + \varphi$ 看作一个整体, 结合 $y = \sin x, x \in R$ 的性质探究.

注： $y = A \cos (\omega x + \varphi)$ 的处理策略与 $y = A \sin (\omega x + \varphi)$ 相同.

5. 由 $y = \sin x$ 的图像得到 $y = A\sin (\omega x + \varphi)$ 的图像的过程：

## 途径 1: 先平移后伸缩

$$
\begin{array}{l} y = \sin x \xrightarrow [ | \varphi | \text {个单位长度} ]{\text {向左或向右平移}} y = \sin (x + \varphi) \xrightarrow [ \text {到原来的} \frac {1}{\omega} , \text {纵坐标不变} ]{\text {横坐标伸长或缩短}} y = \sin (\omega x + \varphi) \xrightarrow [ \text {到原来的A倍，横坐标不变} ]{\text {纵坐标伸长或缩短}} \\ y = A \sin (\omega x + \varphi) \end{array}
$$

## 途径 2: 先伸缩再平移

$$
\begin{array}{l} y = \sin x \xrightarrow [ \text {到原来的} \frac {1}{\omega} , \text {纵坐标不变} ]{\text {横坐标伸长或缩短}} y = \sin \omega x \xrightarrow [ \left| \frac {\varphi}{\omega} \right| \text {个单位长度} ]{\text {向左或向右平移}} y = \sin (\omega x + \varphi) \xrightarrow [ \text {到原来的A倍，横坐标不变} ]{\text {纵坐标伸长或缩短}} \\ y = A \sin (\omega x + \varphi) \end{array}
$$
