> **【解析】**
> （1） $f(x) = 2\sin \left(2x + \frac{\pi}{3}\right)$ ；（2）[√3,2）解析：（1）由图可知 $A = 2$ ，最小正周期 $T = 4\left(\frac{7\pi}{12} -\frac{\pi}{3}\right) = \pi$ ，即 $\frac{2\pi}{\omega} = \pi$ 则 $\omega = 2$ 则 $f(x) = 2\sin (2x + \varphi)$ ，又图象过 $\left(\frac{7\pi}{12}, - 2\right)$
$\therefore 2\sin \left(2\times \frac{7\pi}{12} +\varphi\right) = -2,\therefore \frac{7\pi}{6} +\varphi = \frac{3\pi}{2} +2k\pi ,k\in Z$ $\therefore \varphi = \frac{\pi}{3} +2k\pi ,k\in Z$ ，又 $\left|\varphi \right| <   \frac{\pi}{2},\therefore \varphi = \frac{\pi}{3},$ $\therefore$ 所求的函数解析式为 $f(x) = 2\sin \left(2x + \frac{\pi}{3}\right).$ （2） $f(x) = 2\sin \left(2x + \frac{\pi}{3}\right),x\in \left[0,\frac{7\pi}{12}\right],$ $\because x\in \left[0,\frac{7\pi}{12}\right],\therefore 2x + \frac{\pi}{3}\in \left[\frac{\pi}{3},\frac{3\pi}{2}\right],\therefore -2\leq f(x)\leq 2$ $f(0) = 2\sin \frac{\pi}{3} = \sqrt{3},f\left(\frac{7\pi}{12}\right) = -2,f\left(\frac{\pi}{12}\right) = 2,$ 作出直线 $y = m$ 与 $f(x) = 2\sin \left(2x + \frac{\pi}{3}\right),x\in \left[0,\frac{7\pi}{12}\right]$ 的图象，如图，
