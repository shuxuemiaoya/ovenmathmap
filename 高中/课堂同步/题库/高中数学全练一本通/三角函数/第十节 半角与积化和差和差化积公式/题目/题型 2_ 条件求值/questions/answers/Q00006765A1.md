> [!faq]- 全练一本通解析
> **【答案】** C
>
> **【解析】**
> 解析：因为 $\cos \left( \alpha + \frac{\pi}{4} \right) \cos \left( \alpha - \frac{3\pi}{4} \right) = \frac{1}{2} \times \left[ \cos \left( \alpha + \frac{\pi}{4} + \alpha - \frac{3\pi}{4} \right) + \cos \left( \alpha + \frac{\pi}{4} - \alpha + \frac{3\pi}{4} \right) \right]$ $= \frac{1}{2} \times \left[ \cos \left( 2\alpha - \frac{\pi}{2} \right) + cos\pi \right] = \frac{1}{2} (\sin 2\alpha - 1) = -\frac{1}{3}$ ，所以 $sin 2\alpha = \frac{1}{3}$ .
>
> 故选 **C**.
