## 3.两角和与差的正切

$$
\tan (\alpha + \beta) = \frac {\tan \alpha + \tan \beta}{1 - \tan \alpha \tan \beta}; \quad \tan (\alpha - \beta) = \frac {\tan \alpha - \tan \beta}{1 + \tan \alpha \tan \beta}
$$

注意: 公式中的 $\alpha, \beta$ 都是任意角, 既可以是一个角, 也可以是几个角的组合. 要掌握公式的正用, 如

$$
\cos \alpha = \cos [ (\alpha + \beta) - \beta ] = \cos (\alpha + \beta) \cos \beta + \sin (\alpha + \beta) \cdot \sin \beta
$$

同样也要掌握公式的逆用, 如

$$
\cos (\alpha + \beta) \cos (\alpha - \beta) + \sin (\alpha + \beta) \sin (\alpha - \beta) = \cos [ (\alpha + \beta) - (\alpha - \beta) ] = \cos 2 \beta
$$
