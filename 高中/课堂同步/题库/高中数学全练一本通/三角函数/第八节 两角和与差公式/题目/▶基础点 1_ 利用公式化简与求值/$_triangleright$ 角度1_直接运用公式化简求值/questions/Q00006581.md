【1】利用两角和（差）的余弦公式化简求值：

(1) $\cos57^{\circ}\cos3^{\circ}-\sin57^{\circ}\sin3^{\circ}$ ;

(2) $\sin 12^{\circ} \sin 18^{\circ} - \cos 12^{\circ} \cos 18^{\circ}$ ;

(3) $\sin 20^{\circ}\cos 40^{\circ} + \cos 20^{\circ}\sin 40^{\circ}$ ;

(4) $\frac{\sin (\alpha - 150^\circ) + \cos (\alpha - 120^\circ)}{\cos \alpha}$ ;

(5) $\frac{\tan 74^{\circ} + \tan 76^{\circ}}{1 - \tan 74^{\circ} \tan 76^{\circ}}$ ;

(6) $\frac{\sin\left(\frac{\pi}{6} + \alpha\right) - \sin\left(\frac{\pi}{6} - \alpha\right)}{\sin\alpha}$ ;

(7) $\frac{1 + \tan 15^{\circ}}{1 - \tan 15^{\circ}};$

(8) $\frac{\sqrt{3} - \tan 15^{\circ}}{1 + \sqrt{3} \tan 15^{\circ}}$ ;

(9) $\frac{\cos 75^{\circ} - \sin 75^{\circ}}{\cos 75^{\circ} + \sin 75^{\circ}};$

(10) $\tan 25^{\circ} + \tan 35^{\circ} + \sqrt{3}\tan 25^{\circ}\tan 35^{\circ}.$
