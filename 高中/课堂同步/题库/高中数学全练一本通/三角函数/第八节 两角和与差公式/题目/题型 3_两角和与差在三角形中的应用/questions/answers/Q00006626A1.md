> [!faq]- 全练一本通解析
> **【答案】** $\frac{\pi}{2}$
>
> **【解析】**
> 在 $\triangle ABC$ 中, $\sin A=\sin\left[\pi-(B+C)\right]=\sin(B+C)=\sin B\cos C+\cos B\sin C,$ $\sin B=\sin\left[\pi-(A+C)\right]=\sin A\cos C+\cos A\sin C,$ $\because \sin A + \sin B = \sin C (\cos A + \cos B),$ $\therefore \sin B \cos C + \cos B \sin C + \sin A \cos C + \cos A \sin C = \sin C \cos A + \sin C \cos B,$ 化简得: $\sin B \cos C + \sin A \cos C = 0, \therefore (\sin A + \sin B) \cos C = 0,$ $\because\left\{\begin{aligned}&0<A<\pi\\ &0<B<\pi\\ &0<C<\pi\end{aligned}\right.,\therefore\left\{\begin{aligned}\sin A>0\\ \sin B>0\end{aligned}\right.$ ，故 $\sin A + \sin B > 0,$ 从而 $\cos C = 0, \therefore C = \frac{\pi}{2}.$ 故答案为: $\frac{\pi}{2}$ .
