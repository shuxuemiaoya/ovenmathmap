> [!faq]- 全练一本通解析
> **【答案】** B
>
> **【解析】**
> 解析：∵ 在△ABC 中， $A + B + C = \pi$ ，
> ∴ $C = \pi - (A + B)$ ，又 $\cos A = \frac{3}{5}$ ， $\cos B = \frac{5}{13}$ ，
> ∴ $\sin A = \frac{4}{5}$ ， $\sin B = \frac{12}{13}$ ，
> ∴ $\cos C = \cos[\pi - (A + B)] = -\cos(A + B) = -\cos A\cos B + \sin A\sin B = (-\frac{3}{5})\cdot\frac{5}{13} + \frac{4}{5}\cdot\frac{12}{13} = \frac{33}{65}$ 。故选：B。
> 解析: 因为 $\sin(2B+C)+2\sin B\cos A$ $=\sin B\cos(B+C)+\cos B\sin(B+C)+2\sin B\cos A$ $=-\sin B\cos A+\cos B\sin A+2\sin B\cos A$ $=\sin B\cos A+\cos B\sin A=\sin(B+A)=1$ 所以在 $\triangle ABC$ 中， $B+A=\frac{\pi}{2}$ ，即 $\triangle ABC$ 一定是直角三角形。
>
> 故选 **B**
