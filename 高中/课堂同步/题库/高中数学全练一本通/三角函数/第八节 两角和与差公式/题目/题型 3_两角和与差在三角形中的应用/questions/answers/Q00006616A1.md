> [!faq]- 全练一本通解析
> **【答案】** B
>
> **【解析】**
> 解析：∵ 在△ABC 中， $A + B + C = \pi$ ，
> ∴ $C = \pi - (A + B)$ ，又 $\cos A = \frac{3}{5}$ ， $\cos B = \frac{5}{13}$ ，
> ∴ $\sin A = \frac{4}{5}$ ， $\sin B = \frac{12}{13}$ ，
> ∴ $\cos C = \cos[\pi - (A + B)] = -\cos(A + B) = -\cos A\cos B + \sin A\sin B = (-\frac{3}{5})\cdot\frac{5}{13} + \frac{4}{5}\cdot\frac{12}{13} = \frac{33}{65}$ 。
>
> 故选 **B**。
