## 第十三节 专题: 求 $\omega$ 的取值范围问题

## 知识导学

1. 思想方法:

卡根法:根据题中条件,将含 $\omega$ 的式子卡在某个形式或者范围,继而求解答案.

2. 常用结论：

（1）任意两条对称轴之间的距离为半周期的整数倍, 即: $\frac{T}{2}k$

(2) 任意两个对称中心之间的距离为半周期的整数倍, 即: $\frac{T}{2} k$

（3）任意对称轴与对称中心之间的距离为 $\frac{1}{4}$ 个周期的奇数倍，即： $\frac{T}{4} (2k + 1)$

（4）函数 $f(x) = A\sin (\omega x + \varphi) + B$ 在 $(a,b)$ 内单调，可知； $\left\{ \begin{array}{l}b - a\leq \frac{T}{2}\\ k\pi -\frac{\pi}{2}\leq a\omega +\varphi \leq b\omega +\varphi \leq k\pi +\frac{\pi}{2} \end{array} \right.$

（5）函数 $f(x) = A\sin (\omega x + \varphi) + B$ 在 $(a,b)$ 内不单调，可知： $\left\{ \begin{array}{l}b - a\geq \frac{T}{2}\\ a\omega +\varphi \leq k\pi +\frac{\pi}{2}\leq b\omega +\varphi \end{array} \right.$

（6）函数 $f(x) = A\sin (\omega x + \varphi) + B$ 在 $(a,b)$ 内无零点，可知： $\left\{ \begin{array}{l}b - a\leq \frac{T}{2}\\ k\pi \leq a\omega +\varphi \leq b\omega +\varphi \leq (k + 1)\pi \end{array} \right.$

（7）函数 $f(x) = A\sin (\omega x + \varphi) + B$ 在 $(a,b)$ 内有 $n$ 个零点，可知： $\left\{ \begin{array}{l}(k - 1)\pi \leq a\omega +\varphi < k\pi \\ (k + n - 1)\pi < b\omega +\varphi \leq (k + n)\pi \end{array} \right.$
