> [!faq]- 全练一本通解析
> **【答案】** C
>
> **【解析】**
> 解析：因为函数 $f(x) = \cos (\omega x + \varphi)$ ( $\omega > 0, 0 < \varphi < \pi$ ) 为奇函数，所以 $\varphi = \frac{\pi}{2}$ 故 $f(x) = \cos (\omega x + \frac{\pi}{2}) = -\sin \omega x$ ，要使得 $f(x)$ 在 $\left[-\frac{\pi}{6}, \frac{3\pi}{4}\right]$ 上单调递减，只需 $y = \sin \omega x$ 在 $\left[-\frac{\pi}{6}, \frac{3\pi}{4}\right]$ 上单调递增，因为 $x \in \left[-\frac{\pi}{6}, \frac{3\pi}{4}\right]$ ，所以 $\omega x \in \left[-\frac{\omega\pi}{6}, \frac{3\omega\pi}{4}\right]$ ，其中 $-\frac{\omega\pi}{6} < 0, \frac{3\omega\pi}{4} > 0$ ，结合正弦函数图象可知： $-\frac{\omega\pi}{6} \geq -\frac{\pi}{2}, \frac{3\omega\pi}{4} \leq \frac{\pi}{2}$ ，解得： $\omega \leq \frac{2}{3}$ ，综上： $\omega \in \left(0, \frac{2}{3}\right]$ 。故选：C
