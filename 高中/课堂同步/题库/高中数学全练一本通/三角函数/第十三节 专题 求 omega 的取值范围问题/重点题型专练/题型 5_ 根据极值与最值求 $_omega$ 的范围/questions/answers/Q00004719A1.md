> **【解析】**
> 解析：因为 $\omega > 0$ ，所以当 $0 < x < \frac{\pi}{2}$ 时，则有 $\frac{\pi}{6} < \omega x + \frac{\pi}{6} < \frac{\pi}{2}\omega + \frac{\pi}{6}$ ，因为 $f(x)$ 在区间 $\left(0, \frac{\pi}{2}\right)$ 内有最大值，但无最小值，结合函数图象，得 $\frac{\pi}{2} < \frac{\pi}{2}\omega + \frac{\pi}{6} \leq \frac{3\pi}{2}$ ，解得 $\frac{2}{3} < \omega \leq \frac{8}{3}$ ，故选：A
