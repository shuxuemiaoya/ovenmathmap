例 2 设集合 $A=\{x \mid -1 < x < 2\}$ ，集合 $B=\{x \mid 1 < x < 3\}$ ，求 $A \cup B$ .

解： $A\cup B = \{x\mid -1 <   x <   2\} \cup \{x\mid 1 <   x <   3\}$ $= \{x\mid -1 <   x <   3\} .$
