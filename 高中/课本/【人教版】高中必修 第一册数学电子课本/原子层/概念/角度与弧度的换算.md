一般地，只需根据

$$
180 ^ {\circ} = \pi \text { rad } \quad \begin{array}{l} 1 ^ {\circ} = \frac {\pi}{180} \text { rad } \approx 0.01745 \text { rad } \\ 1 \text { rad } = \left(\frac {180}{\pi}\right) ^ {\circ} \approx 57.30 ^ {\circ} \end{array}
$$
