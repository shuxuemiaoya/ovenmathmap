我们知道：
如果 $x^{2}=a$ ，那么 x 叫做 a 的[平方根](高中/课本/【人教版】高中必修%20第一册数学电子课本/概念/平方根.md)。例如， $\pm2$ 就是 4 的平方根。
如果 $x^{3}=a$ ，那么 x 叫做 a 的[立方根](高中/课本/【人教版】高中必修%20第一册数学电子课本/概念/立方根.md)。例如，2 就是 8 的立方根。
类似地，由于 $(\pm 2)^{4} = 16$ ，我们把 $\pm 2$ 叫做16的[4次方根](高中/课本/【人教版】高中必修%20第一册数学电子课本/概念/4次方根.md)；由于 $2^{5} = 32$ ，2叫做32的5次方根.

一般地，如果 $x^{n}=a$ ，那么 x 叫做 a 的 [n 次方根](概念/n 次方根.md)，其中 n>1，且 $n\in N^{*}$ .

当 $n$ 是奇数时，正数的 $n$ 次方根是一个正数，负数的 $n$ 次方根是一个负数。这时， $a$ 的 $n$ 次方根用符号 $\sqrt[n]{a}$ 表示。例如，$\sqrt [ 5 ]{3 2} = 2, \sqrt [ 5 ]{- 3 2} = - 2, \sqrt [ 3 ]{a ^ {6}} = a ^ {2}.$

当 $n$ 是偶数时，正数的 $n$ 次方根有两个，这两个数互为相反数。这时，正数 $a$ 的正的 $n$ 次方根用符号 $\sqrt[n]{a}$ 表示，负的 $n$ 次方根用符号 $-\sqrt[n]{a}$ 表示。
正的 $n$ 次方根与负的 $n$ 次方根可以合并写成 $\pm \sqrt[n]{a} (a > 0)$ 。例如，$\sqrt [ 4 ]{1 6} = 2, - \sqrt [ 4 ]{1 6} = - 2, \pm \sqrt [ 4 ]{1 6} = \pm 2.$

负数没有偶次方根.

0 的任何次方根都是 0，记作 $\sqrt[n]{0}=0$ .

式子 $\sqrt[n]{a}$ 叫做[根式](高中/课本/【人教版】高中必修%20第一册数学电子课本/概念/根式.md)（radical），这里 n 叫做根指数，a 叫做被开方数.

根据 $n$ 次方根的意义，可得
$$\left(\sqrt [ n ]{a}\right) ^ {n} = a.$$

例如， $(\sqrt{5})^2 = 5$ ， $(\sqrt[5]{-3})^5 = -3.$

>[!quote] 为什么负数没有偶次方根？

> [!question] 探究
$\sqrt[n]{a^n}$ 表示 $a^n$ 的 $n$ 次方根， $\sqrt[n]{a^n} = a$ 一定成立吗？如果不一定成立，那么 $\sqrt[n]{a^n}$ 等于什么？

可以得到：
当 n 为奇数时， $\sqrt[n]{a^{n}}=a$ ;
当 n 为偶数时， $\sqrt[n]{a^{n}}=|a|=\begin{cases}a,&a\geqslant0,\\-a,&a<0.\end{cases}$
