一般地，n 元有序实数组 $(a_{1}, a_{2}, \cdots, a_{n})$ 称为 n 维向量，它是几何向量的推广。n 维向量的全体构成的集合，赋予相应的结构后，叫做 n 维向量空间。它的每一个元素可看成 n 维向量空间的一点。特别地，对 n 维向量空间赋予数量积运算，可以得到 n 维欧氏空间。
