由上可知，关于 $x, y$ 的二元一次方程都表示一条直线。

我们把关于 $x, y$ 的二元一次方程
$$Ax + By + C = 0 \quad (A, B \text{ 不同时为 } 0)$$
叫做[直线的一般式方程](高中/课本/【人教版】高中选择性必修%20第一册数学电子课本/概念/直线的一般式方程.md)，简称一般式（general form）。
