> [!faq]- 巩固练习答案
> **【答案】** 详见解析
>
> **【解析】**
> 令 $a + b = p, a - b = q$ 则原题目变成：已知 $|p| = 1, |2p + q| = 2,$ $\langle p, q \rangle = 60^{\circ}$ 求 $\frac{p + q}{2}, \frac{p - q}{2}$ 的夹角 $\theta$ 的余弦值.由 $4|p|^2 + 4p \cdot q + |q|^2 = 4$ 得 $|q| = 2$ ，则 $\left|\frac{p + q}{2}\right| = \frac{\sqrt{7}}{2}, \left|\frac{p - q}{2}\right| = \frac{\sqrt{3}}{2},$ $\cos \theta = \frac{\frac{p + q}{2} \cdot \frac{p - q}{2}}{\left|\frac{p + q}{2}\right| \left|\frac{p - q}{2}\right|} = \frac{\frac{-3}{4}}{\frac{\sqrt{7}}{2} \times \frac{\sqrt{3}}{2}} = \frac{-3\sqrt{91}}{91}.$
