> [!faq]- 巩固练习答案
> **【答案】** 2
>
> **【解析】**
> 注意到 $a + b$ 中 $a, b$ 系数相同，不妨令 $\cos x = \cos 2x = 2\cos^2 x - 1$ ，于是 $x = \frac{2}{3}\pi$ ，则有 $(a + b)\left(-\frac{1}{2}\right) + 1 \geqslant 0$ ，即 $a + b \leqslant 2$ 下面检验 $a + b = 2$ 是否能取到.当 $a + b = 2$ 时， $a\cos x + b\cos 2x + 1 = 2b\cos^2 x + (2 - b)\cos x + 1 - b \geqslant 0$ 恒成立，即 $b(2\cos^2 x - \cos x - 1) + 2\cos x + 1 = (2\cos x + 1)[b(\cos x - 1) + 1] \geqslant 0$ 恒成立，故 $\cos x = \frac{b - 1}{b} = -\frac{1}{2}$ ，解得 $b = \frac{2}{3}, a = \frac{4}{3}$ ，此时对任意实数 $x, a\cos x + b\cos 2x + 1 \geqslant 0$ 恒成立.所以 $(a + b)_{\max} = 2.$
