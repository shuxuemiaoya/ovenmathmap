> [!faq]- 巩固练习答案
> **【答案】** 详见解析
>
> **【解析】**
> 设 $f(x) = kx + b (k \neq 0)$ ，由 $f(f(x)) = x + 2$ ，得 $k(kx + b) + b = x + 2$ ，即 $k^2x + kb + b = x + 2$ ，所以 $k^2 = 1$ ，且 $kb + b = 2$ ，解得 $k = b = 1$ ，所以 $f(x) = x + 1$ .
