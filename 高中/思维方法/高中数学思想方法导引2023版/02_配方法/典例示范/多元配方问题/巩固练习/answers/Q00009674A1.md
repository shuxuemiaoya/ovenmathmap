> [!faq]- 巩固练习答案
> **【答案】** 1
>
> **【解析】**
> 对原式配方，得 $S = x^{2} + 2xy + y^{2} + 2x + 2y + 2y^{2} + 4y + 4$ $= (x + y)^{2} + 2(x + y) + 1 + 2(y + 1)^{2} + 1$ $= (x + y + 1)^{2} + 2(y + 1)^{2} + 1\geqslant 1,$ 当且仅当 $x = 0,y = -1$ 时取等号.
