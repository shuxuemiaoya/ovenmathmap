> [!faq]- 巩固练习答案
> **【答案】** 详见解析
>
> **【解析】**
> 由正弦定理及余弦定理可得 $A = \frac{2\pi}{3}$ 则 $B + C = \frac{\pi}{3}$ ，可设 $B = \frac{\pi}{6} - d, C = \frac{\pi}{6} + d, -\frac{\pi}{6} < d < \frac{\pi}{6}$ . 由正弦定理知 $\frac{3}{\sin \frac{2\pi}{3}} = \frac{b}{\sin B} = \frac{c}{\sin C} = 2\sqrt{3}$ ，得 $b = 2\sqrt{3}\sin \left(\frac{\pi}{6} - d\right), c = 2\sqrt{3}\sin \left(\frac{\pi}{6} + d\right)$ ，则 $\triangle ABC$ 的周长为 $a + b + c = 3 + 2\sqrt{3}\sin \left(\frac{\pi}{6} - d\right) + 2\sqrt{3}\sin \left(\frac{\pi}{6} + d\right) = 3 + 2\sqrt{3}\left(\frac{1}{2}\cos d - \frac{\sqrt{3}}{2}\sin d + \frac{1}{2}\cos d + \frac{\sqrt{3}}{2}\sin d\right)$
> $= 3 + 2\sqrt{3}\cos d$ 当 $d = 0$ ，即 $B = C = \frac{\pi}{6}$ 时， $\triangle ABC$ 的周长取得最大值 $3 + 2\sqrt{3}$
