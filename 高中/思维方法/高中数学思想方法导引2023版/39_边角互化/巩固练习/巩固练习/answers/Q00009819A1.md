> [!faq]- 巩固练习答案
> **【答案】** C
>
> **【解析】**
> 由余弦定理得 $c\cos A + a\cos C = c \cdot \frac{b^{2} + c^{2} - a^{2}}{2bc} + a \cdot \frac{a^{2} + b^{2} - c^{2}}{2ab} = b,$ 则 $3b\cos A = c\cos A + a\cos C = b,$ 两边约去 b，得 $3\cos A = 1, \cos A = \frac{1}{3} > 0,$ 所以 A 为锐角，且 $\sin A = \sqrt{1 - \cos^{2} A} = \frac{2\sqrt{2}}{3}$ 因此， $\tan A=\frac{\sin A}{\cos A}=2\sqrt{2}$ .
>
> 故选 **C**.
