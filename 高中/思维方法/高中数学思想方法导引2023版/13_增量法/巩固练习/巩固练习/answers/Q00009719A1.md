> [!faq]- 巩固练习答案
> **【答案】** B
>
> **【解析】**
> 由已知得 $\lambda + |a| = \lambda +$ $\sqrt{\lambda^2 + 2\lambda + 4} (\lambda < 0)$ 令 $x = \lambda + 1$ 则 $\lambda + |\pmb{a}| = x - 1 + \sqrt{x^2 + 3} (x < 1)$ 令 $y_1 = \sqrt{x^2 + 3}, y_2 = -x$ 转化为双曲线 $y_1 = \sqrt{x^2 + 3}$ 上横坐标小于1且在上支的一点到一条渐近线 $y_2 = -x$ 上一点的纵向距离问题，
> 如图， $0 < y_1 - y_2 < 3$ 所以 $-1 < x - 1 + \sqrt{x^2 + 3} < 2$ ，故选B.
