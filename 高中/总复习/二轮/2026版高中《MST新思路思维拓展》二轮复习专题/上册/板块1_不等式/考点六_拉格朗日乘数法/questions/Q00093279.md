$\begin{cases} L_{x}(x,y,\lambda) = f_{x}(x,y) + \lambda g_{x}(x,y) = 0 \\ L_{y}(x,y,\lambda) = f_{y}(x,y) + \lambda g_{y}(x,y) = 0, \text{解此方程组,得出解} (x,y), \text{就是二元函数} z = f(x,y) \text{在约束} \\ L_{z}(x,y,\lambda) = g(x,y) = 0 \end{cases}$
