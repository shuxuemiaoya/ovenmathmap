## 考点六_拉格朗日乘数法

给定二元函数 $z = f(x, y)$ 和限制性条件 $t(x, y) = 0$ ，为寻找二元函数 $x = f(x, y)$ 在附加条件 $t(x, y) = 0$ 下的极值点，对三变量函数 $F(x, y, \lambda) = f(x, y) + \lambda t(x, y)$ 分别求导：

即 $F^{\prime}_{\circ} = f^{\prime}_{x} + \lambda t^{\prime}_{z} = 0, F^{\prime}_{y} = f^{\prime}_{y} + \lambda t^{\prime}_{y} = 0, F^{\prime}_{\lambda} = t(x,y) = 0$ ，即可求出 $x, y$ ，那么二元函数的最值即在此处取到。

例如 $x > 0, y > 0, xy + x + y = 17$ ，求 $x + 2y + 3$ 的最小值.

第一步:构造函数 $F(x,y,\lambda)=x+2y+3-\lambda(xy+x+y-17)$ .

第二步:求导, $F'_{y}=1-\lambda y-\lambda=0$ , $F'_{y}=2-\lambda x-\lambda=0$ , $F'_{\lambda}=-(xy+x+y)+17=0$

第三步:联立代人,联立解得 x=5,y=2, $\lambda=\frac{1}{3}$ ,故 $x+2y+3$ 最小为 12.

例 (2026 届江苏南通·开学考试) 已知正数 $a, b, c$ 满足 $4a + b^2 + c^2 = 4$ , 则 $ac\left(b + \frac{1}{2}\right)$ 的最大值是 \_\_\_\_.

一，因为 $4 - b^{2} = 4a^{2} + c^{2}\geqslant 2\sqrt{4a^{2}\cdot c^{2}} = 4ac$ （当且仅当 $4a^{2} = c^{2}$ 时取等号）.

所以 $ac\left(b + \frac{1}{2}\right) \leqslant \frac{(4 - b^2)(b + \frac{1}{2})}{4}, 0 < b < 2.$ 设 $f(x) = (4 - x^2)(x + \frac{1}{2}) = -x^3 - \frac{1}{2}x^2 + 4x + 2, 0 < x < 2,$

则 $f'(x) = -3x^2 - x + 4 = -(3x + 4)(x - 1), 0 < x < 2$ . 由 $f'(x) > 0$ 得 $0 < x < 1$ ; 由 $f'(x) < 0$ 得 $1 < x < 2$ .

所以 $f(x)$ 在 $(0,1)$ 上单调递增，在 $(1,2)$ 上单调递减. 所以 $f(x)_{\max} = f(1) = -1 - \frac{1}{2} + 4 + 2 = \frac{9}{2}$ .

所以 $ac\left(b + \frac{1}{2}\right) \leqslant \frac{1}{4} f(1) = \frac{9}{8}$ , 当且仅当 $\begin{cases} 4a^2 = c^2 = \frac{3}{2} \\ b = 1 \end{cases}$ 时取等号.

构造Lagrange函数：

$$
L (a, b, c, \lambda) = a c \left(b + \frac {1}{2}\right) + \lambda (4 a ^ {2} + b ^ {2} + c ^ {2} - 4)
$$

$$
L _ {a} = c \left(b + \frac {1}{2}\right) + 8 \lambda a = 0 \dots ①
$$

$$
L _ {b} = a c + 2 \lambda b = 0 \dots ②
$$

$$
\text { 法二 }: L _ {c} = a \left(b + \frac {1}{2}\right) + 2 \lambda c = 0 \dots ③
$$

故答案为: $\frac{9}{8}$

$$
L _ {\lambda} = 4 a ^ {2} + b ^ {2} + c ^ {2} - 4 = 0 \dots ④
$$

①得： $\frac{c}{a}=\frac{4a}{c},c=2a$ ，代入②，④消去 $\lambda$ ，得：

$3b^{2}+b-4=0$ , 解得, b=1

代入,得, $ac\left(b+\frac{1}{2}\right)=\frac{9}{8}$

## 例2 (2026 届安徽合肥一中十月质检 T14) 若 $a, b > 0$ , 则 $ab = a^{2} + b^{2} - 4a - 4b + 6$ , 则 $ab$ 的取值范围为 \_\_\_\_.

解析 去一(换元构造函数):由题意得 $3ab=(a+b)^{2}-4(a+b)+6$ , 令 $m=\sqrt{ab}, n=a+b$ ,

则 $n \geqslant 2m$ ，当且仅当 $a = b$ 时等号成立，且 $3m^2 = n^2 - 4n + 6$ ，设 $f(n) = n^2 - 4n + 6 = (n - 2)^2 + 2, n \in [2m, +\infty)$ ，

当 $m \in (0,1)$ 时， $f(n) \in [2, +\infty)$ ，所以 $3m^2 \geqslant 2$ ，则 $ab = m^2 \in \left[\frac{2}{3}, 1\right)$ ；当 $m \in [1, +\infty)$ 时， $f(n) \in [4m^2 - 8m + 6, +\infty)$ ，

所以 $3m^{2} \geqslant 4m^{2} - 8m + 6$ ，解得 $m \in [4 - \sqrt{10}, 4 + \sqrt{10}]$ ，即 $m \in [1, 4 + \sqrt{10}]$ ，所以 $ab = m^{2} \in [1, 26 + 8\sqrt{10}]$ .

综上所述， $ab$ 的取值范围为 $\left[\frac{2}{3}, 26 + 8\sqrt{10}\right]$ .


设 $a + b = a, ab = v$ ，则等式化为：

$$
a ^ {2} - 4 u + 6 - 3 v = 0
$$

$$
\Delta = 1 6 - 4 (6 - 3 \circ) \geqslant 0, \nu \geqslant \frac {2}{3}
$$

构造Lagrange函数：

$$
L (a, b, \lambda) = a b + \lambda \left(a ^ {2} + b ^ {2} - a b - 4 (a + b) + 6\right)
$$

$$
L _ {a} = b + \lambda (2 a - b - 4) = 0 \dots ①
$$

$$
\mathrm{法二}) L _ {a} = a + \lambda (2 b - a - 4) = 0 \dots ②
$$

故答案为： $\left[\frac{2}{3}, 26 + 8\sqrt{10}\right]$ .

①消去λ，得：

$\frac{b}{a} = \frac{2a - b - 4}{2b - a - 4}$ , 化简得: $b^2 - 2b = a^2 - 2a$

则 $a = b$ 或 $a + b = 1$ （代入方程无解）

$a = b$ ，带入方程解得：

$a=4+\sqrt{10}$ ，最大值为： $a^{2}=26+8\sqrt{10}$
