> [!faq]- 例题解析
>
> > [!success]- **【答案】** B
>
> > [!note]- **【解析】**
> > 解析 因为 $\frac{3}{(x + 2y)y} + \frac{8}{(3x + 2y)x} = 2$ ，所以 $xy = \frac{xy}{2} \cdot \left[\frac{3}{(x + 2y)y} + \frac{8}{(3x + 2y)x}\right] = \frac{1}{2}\left(\frac{3x}{x + 2y} + \frac{8y}{3x + 2y}\right)$ ，
> >
> > 令 $x + 2y = m, m > 0, 3x + 2y = n, n > 0, x = \frac{n - m}{2}, y = \frac{3m - n}{4}$ ,
> >
> > $xy = \frac{1}{2}\left(\frac{3x}{x + 2y} +\frac{8y}{3x + 2y}\right) = \frac{1}{2}\left[\frac{3(n - m)}{2m} +\frac{8(3m - n)}{4n}\right] = \frac{1}{2}\left(\frac{3n}{2m} +\frac{6m}{n} -\frac{7}{2}\right)\geqslant \frac{1}{2}\left(2\sqrt{\frac{3n}{2m}\cdot\frac{6m}{n}} -\frac{7}{2}\right) =$ $\frac{1}{2}\left(6 - \frac{7}{2}\right) = \frac{5}{4},$
> >
> > 当且仅当 $\frac{3n}{2m} = \frac{6m}{n}$ 即 $n = 2m$ ，即 $x = \frac{\sqrt{10}}{2}, y = \frac{\sqrt{10}}{4}$ 时等号成立，
> >
> > 所以 $xy$ 的最小值是 $\frac{5}{4}$ .
> >
> > 故选 **B**.
