> [!faq]- 例题解析
>
> > [!success]- **【答案】** $\frac{4}{5}$
>
> > [!note]- **【解析】**
> > 法二：（三角代换）令 $x = r\cos \alpha, 3y = r\sin \alpha$ ，则原式可化为 $\frac{r\cos \alpha + r}{2r\cos \alpha + r\sin \alpha} = \frac{\cos \alpha + 1}{2\cos \alpha + \sin \alpha} = \frac{2\cos^2\frac{\alpha}{2}}{2\cos^4\frac{\alpha}{2} - 2\sin^2\frac{\alpha}{2} + 2\sin\frac{\alpha}{2}\cos\frac{\alpha}{2}} = \frac{1}{1 - t^2 + t}, t = \tan \frac{\alpha}{2}$ ，由二次函数性质： $t = \frac{1}{2}, \frac{x + \sqrt{x^2 + 9y^2}}{2x + 3y}$ 的最小值为 $\frac{4}{5}$ ，故答案为： $\frac{4}{5}$ .
> >
> > 例(2025 读华强基)已知 a>0, b>0, 求 $\frac{ab+2b}{a^{2}+b^{2}+1}$ 的最大值.
> >
> > 解析 $\frac{ab + 2b}{a^2 + b^2 + 1} = \frac{ab + 2b}{a^2 + \lambda b^2 + (1 - \lambda)b^2 + 1} \leqslant \frac{ab + 2b}{2\sqrt{\lambda}ab + 2\sqrt{(1 - \lambda)}b}$ , 则 $\frac{1}{2\sqrt{\lambda}} = \frac{2}{2\sqrt{1 - \lambda}}$ , 解得 $\lambda = \frac{1}{5}$ , 则 $\frac{ab + 2b}{a^2 + b^2 + 1}$ 的最大值为 $\frac{1}{2\sqrt{\lambda}} = \frac{\sqrt{5}}{2}$ . 故答案为: $\frac{\sqrt{5}}{2}$ .
