> [!faq]- 例题解析
>
> > [!success]- **【答案】** C
>
> > [!note]- **【解析】**
> > 解析 图为 $a > |b| > 0$ ，所以 $a - b > 0, 2a + b > 0$ ，构造 $5a + b = m(a - b) + n(2a + b)$ ，整理可得 $5a + b = (m + 2n)a + (n - m)b$ ，则 $\left\{ \begin{array}{l} m + 2n = 5 \\ n - m = 1 \end{array} \right.$ ，解得 $m = 1, n = 2$ ，故 $5a + b = (a - b) + 2(2a + b)$ ，得到 $[(a - b) + 2(2a + b)]\left(\frac{1}{a - b} + \frac{2}{2a + b}\right) = 1 + \frac{2(2a + b)}{a - b} + \frac{2(a - b)}{2a + b} + 4 = 5 + \frac{2(2a + b)}{a - b} + \frac{2(a - b)}{2a + b} \geqslant 5 + 2\sqrt{\frac{2(2a + b)}{a - b} \times \frac{2(a - b)}{2a + b}} = 9,$ 当且仅当 $\frac{2(2a + b)}{a - b} = \frac{2(a - b)}{2a + b}$ 时取等，此时解得 $a = 2, b = -1$ ，则 $5a + b$ 的最小值是9，故C正确.
> >
> > 故选 **C**.
