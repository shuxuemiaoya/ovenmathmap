> [!faq]- 例题解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【解析】**
> > 解析：因为 $f(x) = \frac{x}{\sqrt{1 + x^2}} +\frac{1 - x^2}{1 + x^2},x = \tan \alpha$ ，则 $\frac{x}{\sqrt{1 + x^2}} +\frac{1 - x^2}{1 + x^2} = \frac{\tan\alpha}{\frac{1}{\cos\alpha}} +\frac{1 - \tan^2\alpha}{1 + \tan^2\alpha} = \sin \alpha +\cos^2\alpha -\sin^2\alpha =$
> >
> > $\sin a + 1 - 2\sin^2 a$ ，令 $g(x) = 1 + x - 2x^{2},x\in (-1,1),g(x) > g(-1) = -2,g(x)_{\max} = g\left(\frac{1}{4}\right) = \frac{9}{8}$ 故值域为 $\left(-2,\frac{9}{8}\right]$
> >
> >
> > 法二：注意到 $2\left(\frac{x}{\sqrt{1 + x^3}}\right)^2 + \frac{1 - x^2}{1 + x^3} = 1$ ，设 $\frac{1}{\sqrt{1 + x^3}} = t, \frac{1 - x^2}{1 + x^3} = 1 - 2t^2$ ，光分析 $t$ 的范围。-1 < $\frac{1}{\sqrt{1 + x^3}} < 1, x \to \pm$ ∞时的极限，则 $f(x) = -\frac{x}{\sqrt{1 + x^3}} + \frac{1 - x^2}{1 + x^3} = t + 1 - 2t^2$ ，下同法一。
