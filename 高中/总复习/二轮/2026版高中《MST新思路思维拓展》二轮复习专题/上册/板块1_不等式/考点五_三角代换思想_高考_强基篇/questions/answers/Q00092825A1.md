> [!faq]- 例题解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【解析】**
> > 解析 $a + b = r^2$ ，可令 $a = r\cos \alpha, b = r\sin \alpha$ ，则 $\frac{\sin \alpha}{\cos \alpha} + \frac{\cos \alpha}{\sin \alpha} + 2r^2\sin \alpha \cos \alpha = r^2 (\sin^2 \alpha - \cos^2 \alpha), r^2 = \frac{\frac{\sin \alpha}{\cos \alpha} + \frac{\cos \alpha}{\sin \alpha}}{(\sin^2 a - \cos^2 a - 2\sin \alpha \cos \alpha)} = -\frac{2}{\sin 2\alpha (\sin 2a + \cos 2\alpha)} = -\frac{2}{\frac{1 - \cos 4\alpha}{2} + \frac{\sin 4\alpha}{2}}.$ $\frac{2}{\frac{1 - \cos 4a}{2} + \frac{\sin 4a}{2}} = \frac{4}{\cos 4a - \sin 4a - 1} = \frac{4}{\sqrt{2}\cos(4a + \frac{\pi}{4}) - 1}$ ，由 $a^2 + b^2 > 0$ ，可知 $\sqrt{2}\cos (4a + \frac{\pi}{4}) > 1$ ，故 $\cos (4a + \frac{\pi}{4}) = 1, \frac{4}{\sqrt{2}\cos(4a + \frac{\pi}{4}) - 1}$ 取最小值，最小值为： $4\sqrt{2} + 4.$
