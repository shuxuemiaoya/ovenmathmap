## 考点三_不等式转化为函数思想

## 一、利用等式将双变量转化为单变量

例(25-26高三上·江苏南通·开学考试)已知 $a, b > 0$ ，且 $ab = a + b + 3$ ，则 $a + 4b$ 的最小值是（A.6 B.9 C.13 D. $7 + 4\sqrt{3}$

解析 $a, b = a + b + 3 \Rightarrow a(b - 1) = b + 3$ ，因 $a, b > 0$ ，则 $b + 3 > 0 \Rightarrow a(b - 1) > 0 \Rightarrow b > 1$ ，同理易得 $a > 1$ .

则 $ab = a + b + 3 \Rightarrow ab - a - b + 1 = (a - 1)(b - 1) = 4.$ 从而 $a + 4b = a - 1 + 4(b - 1) + 5 \geqslant 2\sqrt{4(a - 1)(b - 1)} + 5 = 13,$

当且仅当 $a-1=4(b-1)$ ，即 b=2, a=5 时取等号.

法二(转化为函数): $ab=a+b+3,a=\frac{b+3}{b-1}=1+\frac{4}{b-1},a+4b=5+\frac{4}{b-1}+4(b-1)\geqslant5+2\sqrt{16}=13$ ,当且仅当b=2,a=5时等号成立,故选:C

例 (2026 四川汶川部盐道街中学九月月考 T10) 已知正实数 $x$ 、 $y$ 满足 $xy = x + 2y + 6$ , 则下列说法正确的有
A. $xy$ 的最大值为 18
B. $x + 2y$ 的最小值为 1
C. $2x + y$ 的最小值为 13
D. $\frac{1}{x - 2} + \frac{4}{(y + 1)^2}$ 的最小值为 $\frac{1}{2}$

A、法一： $xy = x + 2y + 6\geqslant 2\sqrt{2xy} +6$ ，所以 $(\sqrt{xy})^2 -2\sqrt{2xy} -6\geqslant 0$ 所以 $(\sqrt{xy} -3\sqrt{2})(\sqrt{xy} +\sqrt{2})\geqslant 0$ ，又 $\sqrt{xy} +\sqrt{2} >0$ ，则 $xy\geqslant 18$ ，当且仅当 $x = 6,y = 3$ 时取等号，即 $xy$ 的最小值为18，法二： $xy = x + 2y + 6\Rightarrow (x - 2)(y - 1) = 8,xy = (x - 2 + 2)(y - 1 + 1)\geqslant [\sqrt{(x - 2)(y - 1)} +\sqrt{2}]^2 = 18$ ，故A错误；对于B，由选项A知 $xy\geqslant 18$ ，所以 $x + 2y = xy - 6\geqslant 12$ ，故 $x + 2y$ 的最小值为12，则B错误；
对于C， $xy = x + 2y + 6\Rightarrow x(y - 1) = 2y + 6\Rightarrow (x - 2)(y - 1) = 8,$

法一:由 $x(y-1)=2y+6, x>0, y>0$ 得 y-1>0，故 x-2>0，令 $\left\{\begin{aligned}a&=x-2>0\\ b&=y-1>0\end{aligned}\right.$ ，则 a>0, b>0, ab=8，所以 $\left\{\begin{aligned}x=a+2\\ y=b+1\end{aligned}\right.$ ，则 $2x+y=2a+b+5\geqslant2\sqrt{2ab}+5=13$ ，当且仅当 a=2, b=4，即 x=4, y=5 时取等号，

即 $2x+y$ 的最小值为 13，

法二： $2x+y=2(x-2)+(y-1)+5\geqslant2\sqrt{2(x-2)(y-1)}+5=13$ ，故C正确；

对于 D, 法一: 由选项 C, 得

$$
\frac {1}{x - 2} + \frac {4}{(y + 1) ^ {2}} = \frac {1}{a} + \frac {4}{(b + 2) ^ {2}} = \frac {b + 2}{8} + \frac {4}{(b + 2) ^ {2}} - \frac {1}{4} = \frac {b + 2}{1 6} + \frac {b + 2}{1 6} + \frac {4}{(b + 2) ^ {2}} - \frac {1}{4} \geqslant 3 \sqrt [ 3 ]{\frac {1}{6 4}} - \frac {1}{4} = \frac {1}{2},
$$

当且仅当 $a = 4, b = 2$ ，即 $x = 6, y = 3$ 时取等号，即 $\frac{1}{x - 2} + \frac{4}{(y + 1)^2}$ 的最小值为 $\frac{1}{2}$ ，

法二： $(x - 2)(y - 1) = 8\Rightarrow y + 1 = \frac{8}{x - 2} +2 = \frac{2x + 4}{x - 2},\frac{1}{x - 2} +\frac{4}{(y + 1)^2} = \frac{1}{x - 2} +\frac{(x - 2)^2}{(x + 2)^2} = \frac{1}{4}\left(\frac{x + 2}{x - 2} -1\right) + \frac{(x - 2)^2}{(x + 2)^2}$ $= \frac{1}{8}\cdot \frac{x + 2}{x - 2} +\frac{1}{8}\cdot \frac{x + 2}{x - 2} +\frac{(x - 2)^2}{(x + 2)^2} -\frac{1}{4}\geqslant 3\sqrt[3]{\frac{1}{64}} -\frac{1}{4} = \frac{1}{2}$ ，故D正确.故选：CD.

## 四、对偶式换元

利用根式的对偶式,通常是有理化的反比例对偶关系换元.

例(2026届江苏审通·开学考试)若实数 $x, y$ 满足 $(\sqrt{x^2 + 1} - x)(\sqrt{y^2 + 4} - y) = 2$ ，则 $4^2 + 2^{x - 1}$ 的最小值为 \_\_\_\_.

解近 $m = \sqrt{x^2 + 1} - x, m > 0, n = \sqrt{y^2 + 4} - y$ ，则 $\frac{1}{m} = \sqrt{x^2 + 1} + x, \frac{4}{n} = \sqrt{y^2 + 4} + y,$


由题知 $m \cdot n = 2$ ，则 $n = \frac{2}{m}$ ，所以 $\left\{ \begin{array}{l} m = \sqrt{x^2 + 1} - x \\ \frac{1}{m} = \sqrt{x^2 + 1} + x \end{array} \right. \Rightarrow \frac{1}{m} - m = 2x \Rightarrow x = \frac{1}{2}\left(\frac{1}{m} - m\right), \left\{ \begin{array}{l} n = \sqrt{y^3 + 4} - y = \frac{2}{m} \\ \frac{4}{n} = \sqrt{y^2 + 4} + y = 2m \end{array} \right. \Rightarrow y = m - \frac{1}{m}$ ，所以 $4^a + 2^{a-1} = 2^{4a} + 2^{a-1} = 2^{4a - a} + 6^{a - a - 1} = 2^{4a - a} + \frac{6^{a - a - 1}}{2}$ 。令 $t = 2^{a - a}$ ，则 $t > 0, 2^{a - a} = \frac{1}{t}$ ，则 $4^a + 2^{a-1} = 2^{4a - a} + \frac{2^{a-4}}{2} = \frac{1}{t} + \frac{t}{2} \geqslant 2\sqrt{\frac{1}{t} \cdot \frac{t}{2}} = 2 \cdot \frac{\sqrt{2}}{2} = \sqrt{2}$ ，当且仅当 $\frac{1}{t} = \frac{t}{2}$ ，即 $t = \sqrt{2}$ 时取等号：故答案为： $\sqrt{2}$ .
