> [!faq]- 例题解析
>
> > [!success]- **【答案】** AC
>
> > [!note]- **【解析】**
> > 解析 对于 A, 正实数 a, b 满足 $\frac{8}{a} + \frac{1}{b} = 1$ , 得 $1 = \frac{8}{a} + \frac{1}{b} \geqslant 2\sqrt{\frac{8}{a} \times \frac{1}{b}} = \frac{4\sqrt{2}}{\sqrt{ab}}$ ,
> >
> >
> > 即 $\sqrt{ab} \geqslant 4\sqrt{2}$ ，所以 $ab \geqslant 32$ ，当且仅当 $\frac{8}{a} = \frac{1}{b}$ ，即 $a = 16, b = 2$ 时，等号成立，故 A 正确；
> >
> > 对于 B, 由 $\frac{8}{a} + \frac{1}{b} = 1$ , 得 $\frac{1}{b} = 1 - \frac{8}{a} = \frac{a - 8}{a} > 0$ , 因 a > 0, b > 0, 所以 a > 8, 且 $\frac{1}{a - 8} = \frac{b}{a}$ . 同理可得 b > 1, 且 $\frac{1}{b - 1} = \frac{a}{8b}$ .
> > 所以 $\frac{1}{a-8}+\frac{2}{b-1}=\frac{b}{a}+\frac{a}{4b}\geqslant2\sqrt{\frac{b}{a}\times\frac{a}{4b}}=1$ ，所以B错误；
> >
> > 对于 $C: 2a + b = (2a + b)\left(\frac{8}{a} + \frac{1}{b}\right) = 17 + \frac{8b}{a} + \frac{2a}{b} \geqslant 17 + 2\sqrt{\frac{8b}{a} \times \frac{2a}{b}} = 25$ ，当且仅当 $\frac{8b}{a} = \frac{2a}{b}$ ，即 $a = 10, b = 5$ 时等号成立，所以 $C$ 正确；
> >
> > 对于 $\mathrm{D}; a^2 + b^2 = \frac{1}{5} (a^2 + b^2)(2^2 + 1^2) \geqslant \frac{1}{5} (2a + b)^2$ ，由 C 可知 $2a + b \geqslant 25$ ，所以 $a^2 + b^2 \geqslant \frac{1}{5} \times 25^2 = 125$ ，所以存在 $a = 10, b = 5$ ，使得 $a^2 + b^2 = 125 < 126$ ，所以 D 错误。
> >
> > 故选 **AC**。
