> [!faq]- 例题解析
>
> > [!success]- **【答案】** B
>
> > [!note]- **【解析】**
> > 因为 x, y 为非负实数，且 $x + 2y = 2$ ，即 $x + 2(y + 1) = 4$ ，
> >
> > $$
> > \frac {x ^ {2} + 1}{x} + \frac {2 y ^ {2}}{y + 1} = x + \frac {1}{x} + \frac {2 (y + 1) ^ {2} - 4 (y + 1) + 2}{y + 1} = x + \frac {1}{x} + 2 y + 2 + \frac {2}{y + 1} - 4 = \frac {1}{x} + \frac {2}{y + 1}
> > $$
> >
> > $= \left(\frac{1}{x} +\frac{2}{y + 1}\right)[x + 2(y + 1)]\times \frac{1}{4} = \frac{1}{4}\left(5 + \frac{2y + 2}{x} +\frac{2x}{y + 1}\right)\geqslant \frac{1}{4}\left(5 + 2\sqrt{\frac{2y + 2}{x}\cdot\frac{2x}{y + 1}}\right) = \frac{9}{4},$ 当且仅当 $x = y + 1$ ，即 $x = \frac{4}{3},y = \frac{1}{3}$ 时取等号.故选：B.
> >
> > 法二:权方和不等式 $\frac{x^{1}+1}{x}+\frac{2y^{2}}{y+1}=\frac{x^{2}+2x+1}{x}+\frac{4y^{2}}{2(y+1)}-2\geqslant\frac{(x+1+2y)^{2}}{x+2(y+1)}-2=\frac{1}{4}$ ，发现无取等条件，故考虑 $\frac{x^{2}+1}{x}+\frac{2y^{2}}{y+1}=\frac{x^{2}-2x+1}{x}+\frac{4y^{2}}{2(y+1)}+2\geqslant\frac{(x-1+2y)^{2}}{x+2(y+1)}+2=\frac{9}{4}$ ，当且仅当 $\frac{x-1}{x}=\frac{2y}{2(y+1)}$ 时等号成立，此时 $x=\frac{4}{3},y=\frac{1}{3}$ ；
> >
> > 故选 **B**.
