> [!faq]- 例题解析
>
> > [!success]- **【答案】** C
>
> > [!note]- **【解析】**
> > 对于 $C_{1}$ 因为 $ab + 2a + b = 6$ ，所以 $ab + 2a + b + 2 = (a + 1)(b + 2) = 8$ ，即 $a + b = a + 1 + b + 2 - 3 \geqslant 2\sqrt{(a + 1)(b + 2)} - 3 = 4\sqrt{2} - 3, a = 2\sqrt{2} - 1$ 时取等号，故选项 $C$ 错误；
> >
> > 对于 $\mathrm{D}_1\frac{1}{a + 1} +\frac{1}{b + 2}\geqslant \frac{2}{\sqrt{(a + 1)(b + 2)}} = \frac{\sqrt{2}}{2}$ ，即 $a = 2\sqrt{2} -1$ 时取等号，
> >
> > 所以 $\frac{1}{a + 1} +\frac{1}{b + 2}$ 的最小值是 $\frac{\sqrt{2}}{2}$ ，故选项D正确.故选：C.
> >
> > 不等式代数转换的核心就是求什么留什么,也需要掌握不等式中的因式分解技巧.
