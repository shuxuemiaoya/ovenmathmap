> [!faq]- 例题解析
>
> > [!success]- **【答案】** A
>
> > [!note]- **【解析】**
> > 解析 $x - 0 < x < 1$ ，则 $\frac{x^2}{x + 1} - \frac{(1 - x)^2}{x - 3} = \frac{(x + 1 - 1)^2}{x + 1} + \frac{(3 - x - 2)^2}{3 - x}$
> >
> > $$
> > = \frac {(x + 1) ^ {2} - 2 (x + 1) + 1}{x + 1} + \frac {(3 - x) ^ {2} - 4 (3 - x) + 4}{3 - x} = (x + 1) - 2 + \frac {1}{x + 1} + (3 - x) - 4 + \frac {4}{3 - x}
> > $$
> >
> > $$
> > = - 2 + \frac {1}{x + 1} + \frac {4}{3 - x} = - 2 + \frac {1}{4} \left(\frac {1}{x + 1} + \frac {4}{3 - x}\right) (x + 1 + 3 - x)
> > $$
> >
> > $= -2 + \frac{1}{4}\left[1 + 4 + \frac{4(x + 1)}{3 - x} +\frac{3 - x}{x + 1}\right]\geqslant -2 + \frac{1}{4}\left[5 + 2\sqrt{\frac{4(x + 1)}{3 - x}\cdot\frac{3 - x}{x + 1}}\right] = -2 + \frac{9}{4} = \frac{1}{4}.$ 当且仅当 $x = \frac{1}{3}$ 时取等
> >
> > 号、故选：A.
> >
> > 法二： $\frac{x^2}{x + 1} -\frac{(1 - x)^2}{x - 3} = \frac{x^2}{x + 1} +\frac{(1 - x)^2}{3 - x}\geqslant \frac{(x + 1 - x)^2}{x + 1 + 3 - x} = \frac{1}{4}$ 当且仅当 $\frac{x}{x + 1} = \frac{1 - x}{3 - x}$ 即 $x = \frac{1}{3}$ 时取等号，故选：A.
> >
> > 广义的权方和不等式,分子次数比分母高一次.
