> [!faq]- 例题解析
>
> > [!success]- **【答案】** 4
>
> > [!note]- **【解析】**
> > 解析 正解 $a, b, c$ 满足 $c < 1, a + b = 2$ ，由 $c(1 - c) \leqslant \left(\frac{c + 1 - c}{2}\right)^2 = \frac{1}{4}$ ，当且仅当 $c = 1 - c$ ，即 $c = \frac{1}{2}$ 时取等号， $\frac{c + a}{abc} + \frac{a + b}{2b(1 - c)} = \frac{c}{abc} + \frac{a}{abc} + \frac{2}{2b(1 - c)} = \frac{1}{ab} + \frac{1}{bc} + \frac{1}{b(1 - c)}$
> >
> > $$
> > = \frac {1}{a b} + \frac {1}{b} \left(\frac {1}{c} + \frac {1}{1 - c}\right) = \frac {1}{a b} + \frac {1}{b} \cdot \frac {1}{c (1 - c)} \geqslant \frac {1}{a b} + \frac {4}{b} = \frac {1}{2} \cdot \frac {a + b}{a b} + \frac {4}{b} = \frac {1}{2} \left(\frac {1}{a} + \frac {9}{b}\right) = \frac {1}{4} \left(\frac {1}{a} + \frac {9}{b}\right) (a + b)
> > $$
> >
> > $= \frac{1}{4}\left(10 + \frac{b}{a} +\frac{9a}{b}\right)\geqslant \frac{1}{4}\left(10 + 2\sqrt{\frac{b}{a}\cdot\frac{9a}{b}}\right) = 4$ ，当且仅当 $b = 3a$ 时取等号，
> >
> > 即 $a = \frac{1}{2}, b = \frac{3}{2}, c = \frac{1}{2}$ 时，等号成立，所以 $\frac{c + a}{abc} + \frac{a + b}{2b(1 - c)}$ 的最小值为4、故答案为：4.
