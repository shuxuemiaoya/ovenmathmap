> [!faq]- 例题解析
>
> > [!success]- **【答案】** BCD
>
> > [!note]- **【解析】**
> > 解析 对于 A, 因为 a, b 都是正数 $a + b = 1$ , 所以 $1 = a + b \geqslant 2\sqrt{ab}$ , 即 $0 < ab \leqslant \frac{1}{4}$ .
> >
> > $$
> > \left(a + \frac {1}{a}\right) \left(b + \frac {1}{b}\right) = a b + \frac {a}{b} + \frac {b}{a} + \frac {1}{a b} = a b + \frac {a ^ {2} + b ^ {2}}{a b} + \frac {1}{a b} = a b + \frac {(a + b) ^ {2} - 2 a b}{a b} + \frac {1}{a b} = a b + \frac {2}{a b} - 2.
> > $$
> >
> > 因为函数 $y = x + \frac{2}{x}$ 在 $(0, \sqrt{2})$ 递减，所以当 $ab = \frac{1}{4}$ 时， $ab + \frac{2}{ab} - 2$ 取得最小值 $\frac{1}{4} + \frac{2}{\frac{1}{4}} - 2 = \frac{25}{4}$ ，所以 A 错误，
> >
> > B: $[(1 + a) + (1 + b)](1 + 1) \geqslant (\sqrt{1 + a} + \sqrt{1 + b})^2$ ，当且仅当 $a = b = \frac{1}{2}$ 时取等号，所以 $\sqrt{1 + a} + \sqrt{1 + b}$ 的最大值为
> >
> > $\sqrt{6}$ ，所以B正确。
> >
> > $C_{1}\frac{1}{a}+\frac{2}{b}=\left(\frac{1}{a}+\frac{2}{b}\right)(a+b)\geqslant(\sqrt{1}+\sqrt{2})^{2}=2\sqrt{2}+3$ ，当且仅当 $a=\sqrt{2}+1,b=2-\sqrt{2}$ 时取等号，所以 $\frac{1}{a}+\frac{2}{b}$ 的最小值为 $2\sqrt{2}+3$ ，所以C正确，
> >
> > $$
> > \frac {2 a}{a ^ {2} + b} + \frac {b}{a + b ^ {2}} = \frac {2 a}{a ^ {2} - a + 1} + \frac {1 - a}{a + (1 - a) ^ {2}} = \frac {a + 1}{a ^ {2} - a + 1}
> > $$
> >
> > 因为 $\frac{a^2 - a + 1}{a + 1} = a + 1 + \frac{3}{a + 1} - 3 \geqslant 2\sqrt{3} - 3$ ，当且仅当 $a = \sqrt{3} - 1, b = 2 - \sqrt{3}$ 时取等号，
> >
> > 所以 $\frac{2a}{a^2 + b} +\frac{b}{a + b^2}\leqslant \frac{1}{2\sqrt{3} - 3} = \frac{2\sqrt{3} + 3}{3}$ 所以 $\frac{2a}{a^2 + b} +\frac{b}{a + b^2}$ 的最大值为 $\frac{2\sqrt{3} + 3}{3}$ 所以D正确，
> >
> > 故选 **BCD**.
