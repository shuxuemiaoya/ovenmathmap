> >
> > 故曲线 $y = e^{x} - a (a > 0)$ 在 $x = 0$ 处的切线方程为 $y = x - 0 + e^{0} - a = x + 1 - a$ ，设该直线与曲线 $y = \ln (x + b) (b > 0)$ 的切点坐标为 $(m, \ln (m + b))$ ，则 $\frac{1}{m + b} = 1$ ，故 $m = 1 - b$ ，故切点坐标为 $(1 - b, 0)$ ，
> >
> > 该切点在直线 $y = x + 1 - a$ 上，故 $0 = 1 - b + 1 - a$ 即 $a + b = 2$ ，故 $\frac{1}{a} +\frac{1}{b} = \frac{1}{2}(a + b)\left(\frac{1}{a} +\frac{1}{b}\right) = \frac{1}{2}$ $(2 + \frac{b}{a} +\frac{a}{b})\geqslant 2,$
> >
> > 当且仅当 $a = b = 1$ 时等号成立，故 $\frac{1}{a} +\frac{1}{b}$ 的最小值为2，故答案为：2.
