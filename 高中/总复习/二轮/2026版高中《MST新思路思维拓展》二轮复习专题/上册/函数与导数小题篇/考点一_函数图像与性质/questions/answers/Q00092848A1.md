> [!faq]- 例题解析
>
> > [!success]- **【答案】** AC
>
> > [!note]- **【解析】**
> > 题13 选项A,因为 $f(4 - x) = \frac{(4 - x - 2)^2}{e^{|4 - x - 3|}} = \frac{(2 - x)^2}{e^{|2 - x|}} = f(x)$ ，即 $f(4 - x) = f(x)$ ，故A正确；
> >
> > 选项 $\mathrm{B}_1$ 因为函数 $f(x) = \frac{(x - 2)^2}{e^{|x - 2|}}$ 的定义域为 $R$ ，当 $x > 2$ 时，由同构函数： $f(x) = \frac{(x - 2)^2}{e^{x - 2}} = 4\left(\frac{\frac{x - 2}{2}}{e^{\frac{x}{2}}}\right)^2 \leqslant \frac{4}{e^2}$ ，故B错误；
> >
> > 选项 $C_1g(x)$ 有两个不同零点，即方程 $\frac{(x - 2)^{2}}{e^{|x - 2|}} = k(x - 2)$ 有两个不同的解，显然 $x = 2$ 是一个解，则 $\frac{x - 2}{e^{|x - 2|}} = k$ 有①
> >
> > 一个非2的解，或者有②两个不同的解，其中一个为2，令 $h(x) = \frac{x - 2}{e^{|x - 2|}}$ ，当 $x > 2$ 时， $h(x) = \frac{x - 2}{e^{r - 1}}$ ，求导得 $h^\prime (x) = \frac{3 - x}{e^{x - 2}}$ ，当 $2 < x < 3$ 时， $h^\prime (x) > 0, h(x)$ 单调递增，当 $x > 3$ 时， $h^\prime (x) < 0, h(x)$ 单调递减，又因为 $h(x) + h(4 - x) = \frac{x - 2}{e^{|x - 2|}} + \frac{2 - x}{e^{|x - 2|}} = 0$ ，且 $h(2) = 0$ ，所以函数 $h(x)$ 关于(2,0)中心对称，
> >
> > 所以函数 $h(x)$ 的增区间为 $(1,3)$ ，减区间为 $(- \infty, 1)$ ， $(3, +\infty)$ ，所以当 $x > 2$ 时， $h(x)_{\min} = h(3) = \frac{1}{e}$ ，当 $x < 2$ 时， $h(x)_{\min} = h(1) = -\frac{1}{e}$ ，且 $x \to +\infty$ 时， $h(x) \to 0^{+}$ ， $x \to -\infty$ 时， $h(x) \to 0^{-}$ ，所以①若 $\frac{x - 2}{e^{|x - 2|}} = k$ 有一个非2的解，则 $k = \pm \frac{1}{e}$ ；
> > - **②**：若 $\frac{x - 2}{e^{|x - 2|}} = k$ 有两个不同的解，其中一个是2，则 $k = 0$ ，而 $\frac{x - 2}{e^{|x - 2|}} = 0$ 仅有唯一解 $x = 2$ ，矛盾，故C正确；
> >
> > 选项D:由选项A、B知, $f(x)$ 的图像关于x=2对称, $f(x)$ 在 $(-∞,0)$ , $(2,4)$ 上单调递增,
> >
> > 在 $(0,2),(4, + \infty)$ 上单调递减， $f(x)_{\max} = f(0) = f(4) = \frac{4}{e^2} < 1$ ，令 $t = f(x)$ ，则 $t\in \left[0,\frac{4}{e^2}\right]$ ，由 $f(f(x)) = \frac{1}{e}$ 得 $f(t) = \frac{1}{e} = f(1),t\in \left[0,\frac{4}{e^2}\right]$ 因为 $f(x)$ 在 $(0,2)$ 上单调递减， $\frac{4}{e^2} < 1$ ，所以 $f(t)$ 在 $t\in \left[0,\frac{4}{e^2}\right]$ 的值域为 $\left[f\left(\frac{4}{e^2}\right),\frac{4}{e^2}\right]$ ，所以 $f(1) = \frac{1}{e} <  f\left(\frac{4}{e^2}\right)$ 不在值域 $\left[f\left(\frac{4}{e^2}\right),\frac{4}{e^2}\right]$ 内，故方程 $f(t) = \frac{1}{e}$ 无解，故D错误.
> >
> > 故选 **AC**.
