> [!faq]- 例题解析
>
> > [!success]- **【答案】** $\left(2,\frac{7}{3}\right]\cup\left(\frac{5}{2},3\right]$
>
> > [!note]- **【解析】**
> > 解析 因为 $f(x)$ 在区间 $(0, +\infty)$ 内恰有6个零点，当 $a < 0$ 时，区间 $(0, +\infty)$ 上 $f(x) = |x - a - 1| - 3a + 6$ ，最多有2个零点，不符合题意；
> >
> > 当 $a > 0$ 时，易知函数 $f(x) = |x - a - 1| - 3a + 6(x \geqslant a)$ 最多有2个零点，所以当 $0 < x < a$ 时， $f(x) = 0$ 至少有4个根。由 $\sin (2\pi x - 2\pi a) = \sin [2\pi (x - a)] = 0$ ，得 $2\pi (x - a) = k\pi, k \in Z$ ，所以 $x = \frac{k}{2} + a, k \in Z$
> >
> > 又 $0 < x < a$ ，所以 $0 < \frac{k}{2} + a < a, k \in \mathbb{Z}$ ，解得 $-2a < k < 0, k \in \mathbb{Z}$ ，所以当 $x < a$ 时，函数 $f(x)$ 的零点由右至左依次为 $x_1 = -\frac{1}{2} + a, x_2 = -1 + a, x_3 = -\frac{3}{2} + a, x_4 = -2 + a, x_5 = -\frac{5}{2} + a, x_6 = -3 + a, x_7 = -\frac{7}{2} + a, \cdots$ ，令 $|x - a - 1| - 3a + 6 = 0$ ①，得 $|x - a - 1| = 3a - 6$ ，
> >
> > (1)当 $3a - 6 < 0$ ，即 $a < 2$ 时，方程①无解，即 $f(x)$ 在 $x \geqslant a$ 时无零点，所以， $f(x)$ 在 $0 < x < a$ 时有6个零点，则 $\left\{ \begin{array}{l} x_{0} = -3 + a > 0 \\ x_{1} = -\frac{7}{2} + a \leqslant 0, \\ a < 2 \end{array} \right.$ 此不等式组无解，舍去；
> >
> > (2)当 $a = 2$ 时, 方程①有唯一解 $x = 3$ , 即 $f(x)$ 在 $x \geqslant a$ 时有一个零点 3 , 所以, $f(x)$ 在 $0 < x < a$ 时有 5 个零点, 由 $a = 2$ , 所以 $-4 < k < 0, k \in \mathbb{Z}$ 所以, $f(x)$ 在 $0 < x < a$ 时只有 3 个零点, 显然矛盾, 舍去;
> >
> > (3) 当 $a > 2$ 时, 方程①的解为 $x = 4a - 5$ 或 $x = 7 - 2a$ , 且 $7 - 2a < 4a - 5$ , 若 $7 - 2a \geqslant a$ , 则 $2 < a \leqslant \frac{7}{3}$ 时, 此时 $f(x)$ 在 $x$
> >
> > $a$ 时有2个零点，所以，在 $0 < x < a$ 时，函数 $f(x)$ 有4个零点，所以 $\left\{ \begin{array}{l}x_{4} = -2 + a > 0\\ x_{5} = -\frac{5}{2} +a\leqslant 0,\\ 2 <   a\leqslant \frac{7}{3} \end{array} \right.$ 若 $7 - 2a <$
> >
> > a, 则 $a > \frac{7}{3}$ ，此时 $f(x)$ 在 $x \geqslant a$ 时有 1 个零点，所以，在 0 < x < a 时，函数 $f(x)$ 有 5 个零点，所以 $\left\{\begin{aligned}x_{3}&=-\frac{5}{2}+a>0\\ x_{4}&=-3+a<0\\ a&>\frac{7}{3}\end{aligned}\right.$ 解得 $\frac{5}{2}<a\leqslant3$ ;综上所述,a的取值范围为 $\left(2,\frac{7}{3}\right]\cup\left(\frac{5}{2},3\right]$ .故答案为： $\left(2,\frac{7}{3}\right]\cup\left(\frac{5}{2},3\right]$
