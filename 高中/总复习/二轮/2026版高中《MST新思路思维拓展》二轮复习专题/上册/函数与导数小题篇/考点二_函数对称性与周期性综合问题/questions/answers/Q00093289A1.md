> > 注意, 因为 $g(x)$ 的图象关于直线 x = -3 对称, 则有 $g(-x - 3) = g(-x + 3)$ , 又由 $f(x) + g(-x - 3) = 2$ , 所以 $f(-x) + g(x - 3) = f(-x) + g(-x - 3) = 2$ , 变形可得 $f(x) = f(-x)$ , $f(x)$ 为偶函数, 故 C 不正确; 当 x = 0时， $f(0)+g(-3)=2$ ，又 $g(-3)=1$ ，所以 $f(0)=1$ ，故 A 正确；
> >
> > 【解析】
> > 因为 $f(x + 3) = -f(x)$ ，又 $f(x) = f(-x)$ ，所以 $f(-x) = -f(x + 3)$ ，即 $f(-x) + f(x + 3) = 0$ ，所以 $f(x)$ 的图象关于点 $\left(\frac{3}{2}, 0\right)$ 中心对称，故 B 正确；
> >
> > $T=4\left(\frac{3}{2}-0\right)=6$ , 所以 $f(x)$ 是以 6 为周期的周期函数, 综合可得: $f(0)+f(3)=f(1)+f(2)=0$ ,
> >
> > $f(0)+f(1)+f(2)+\cdots+f(2025)=f(0)+337\times[f(1)+f(2)+f(3)+f(4)+f(5)+f(6)]+f(2023)+f(2024)+f(2025)=f(0)+337\times[f(1)+f(2)+f(3)-f(1)-f(2)-f(3)]+f(2023)+f(2024)+f(2025)=f(0)+f(1)+f(2)+f(3)=0,D$ 不正确.故选：AB.

> > 例 (2026 届临渭区校级月考·多选)已知函数 $f(x), g(x)$ 的定义域均为 $R, f(x+1)+f(x-1)=f(x)$ ， $g(x-3)$ 是偶函数， $f(x)+g(x-3)=2$ ，若 $g(-3)=1$ ，则( )
> > A. $f(1)=\frac{1}{2}$ B. $f(x)$ 的图象关于点 $\left(\frac{3}{2},0\right)$ 对称
> > C. $f(x)=f(x+6)$ D. $f(x)$ 为奇函数
> >
> > 解析 因为 $f(x + 1) + f(x - 1) = f(x)$ ，所以 $f(x + 2) + f(x) = f(x + 1)$ ，
> >
> > 所以 $f(x+2)+f(x-1)=0$ ，所以 $f(x+3)+f(x)=0$ ，所以 $f(x+6)+f(x+3)=0$ ，
> >
> > 所以 $f(x + 6) = f(x)$ ，所以C选项正确；又 $f(x) + g(x - 3) = 2$ ，若 $g(-3) = 1$
> >
> > 所以 $f(0)+g(-3)=2$ ，所以 $f(0)=1$ ，又 $g(x-3)$ 是偶函数，所以 $g(-x-3)=g(x-3)$ ，
> >
> > 又 $f(x)+g(x-3)=2$ ，所以 $f(-x)+g(-x-3)=2$ ，所以 $f(x)=f(-x)$ ，所以 $f(x)$ 为偶函数，所以D选项错误；
> >
> > 又 $f(x + 1) + f(x - 1) = f(x)$ ，所以 $f(1) + f(-1) = f(0) = 1$ ，所以 $f(1) + f(1) = f(0) = 1$
> >
> > 所以 $f(1) = \frac{1}{2}$ ，所以A选项正确；又 $f(x + 3) + f(x) = 0, f(-x) = f(x)$ ，
> >
> > 所以 $f(x+3)+f(-x)=0$ ，所以 $f(x)$ 的图象关于点 $\left(\frac{3}{2},0\right)$ 对称，所以 B 选项正确。
> >
