> > [!note]- **【解析】**
> > 解析 对于 A, 因为 $f_{h}(x+\pi)=\cos^{2h}(x+\pi)-\sin^{2h}(x+\pi)=\cos^{2h}x-\sin^{2h}x=f(x)$ ，所以函数 $f_{h}(x)$ 的一个周期为 $\pi$ ，故 A 正确；
> > 对于 B, $f_{2}(x)=\cos^{4}x-\sin^{4}x=(\cos^{2}x-\sin^{2}x)(\cos^{2}x+\sin^{2}x)=(\cos^{2}x-\sin^{2}x)=\cos2x$ ，当 $x\in\left[0,\frac{\pi}{2}\right]$ 时， $2x\in[0,\pi]$ ，又因为 $y=\cos x$ 在 $[0,\pi]$ 上单调递减，由复合函数的单调性可得 $f_{2}(x)=\cos2x$ 在 $\left[0,\frac{\pi}{2}\right]$ 上单调递减，故 B 正确；
> > 对于 C, $f_{k}\left(\frac{\pi}{2}-x\right)=\cos^{2k}\left(\frac{\pi}{2}-x\right)-\sin^{2k}\left(\frac{\pi}{2}-x\right)=\sin^{2k}x-\cos^{2k}x=-f_{k}(x)$ ，所以曲线 $y=f_{k}(x)$ 关于 $\left(\frac{\pi}{4},0\right)$ 对称，故 C 错误；
> > 对于 D, $0 \leqslant \cos^{2} x \leqslant 1, 0 \leqslant \sin^{2} x \leqslant 1$ ，所以 $0 \leqslant \cos^{2k} x \leqslant 1, 0 \leqslant \sin^{2k} x \leqslant 1$ ，当 $\cos^{2k}x=1$ 时， $\sin^{2k}x=0$ ，所以函数 $f_{k}(x)$ 的最大值为 1，又 $0 \leqslant \cos^{2} x \leqslant 1, 0 \leqslant \sin^{2} x \leqslant 1$ ，又因为 $\cos^{2}x \geqslant (\cos^{2}x)^{k}, \sin^{2}x \geqslant (\sin^{2}x)^{k}$ ，所以 $g_{k}(x)=\cos^{2k}x+\sin^{2k}x \leqslant \cos^{2}x + \sin^{2}x = 1$ ，当且仅当 $\cos^{2}x = (\cos^{2}x)^{k}, \sin^{2}x = (\sin^{2}x)^{k}$ 时取等号，所以 $g_{k}(x)$ 的最大值为 1，所以函数 $f_{k}(x)$ 与函数 $g_{k}(x)$ 的最大值相等，故 D 正确.
> >
> > 故选 **ABD**.
