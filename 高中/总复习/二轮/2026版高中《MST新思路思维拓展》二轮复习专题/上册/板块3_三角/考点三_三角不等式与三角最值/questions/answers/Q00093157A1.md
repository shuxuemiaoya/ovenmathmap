> [!faq]- 例题解析
>
> > [!success]- **【答案】** BCD
>
> > [!note]- **【解析】**
> > 解析 $\varphi=0$ 时，由题意有对任意的 $x\in R$ ，不等式 $\sin x\geqslant\cos(\omega x)$ 恒成立，
> >
> > 但当 x=0 时， $\sin0=0<\cos0=1$ ，故不 $\exists\omega\in R$ ，使得命题成立，A 错误；
> >
> > 当 $\varphi = \pi$ 时，由题意有对任意的 $x \in \mathbb{R}$ ，不等式 $\sin x \geqslant -\cos (\omega x)$ 即 $\sin x + \cos (\omega x) \geqslant 0$ 恒成立，当 $\omega = 0$ 时， $\sin x + \cos 0 = \sin x + 1 \geqslant 0$ 恒成立，故当 $\varphi = \pi$ 时， $\exists \omega \in \mathbb{R}$ ，使得命题成立，B 正确；
> >
> > 对任意的 $x \in \mathbb{R}$ , 不等式 $\sin x \geqslant \cos (\omega x + \varphi)$ 恒成立, 则 $\cos \left(-\frac{\omega \pi}{2} + \varphi\right) \leqslant \sin \left(-\frac{\pi}{2}\right) = -1$ , 则 $\cos \left(\frac{\omega \pi}{2} - \varphi\right) = \cos$ $\left(-\frac{\omega \pi}{2} + \varphi\right) = -1, C$ 正确;
> >
> > 由正余弦函数图象和性质可知若对任意的 $x \in \mathbb{R}$ 不等式 $\sin x \geqslant \cos (\omega x + \varphi)$ 恒成立, 则 $y = \sin x$ 图象恒在 $y = \cos (\omega x + \varphi)$ 图象上方, 或两图象重合, 故要使命题成立则 $\cos (\omega x + \varphi) = -1$ 或 $\sin x = \cos (\omega x + \varphi)$ , 又 $\varphi \in [0, 2\pi]$ , 所以 $\omega = 0, \varphi = \pi$ 或 $\omega = 1, \varphi = \frac{3\pi}{2}$ 或 $\omega = -1, \varphi = \frac{\pi}{2}$ , 共三组解, 所以使得命题成立的有序实数对 $(\omega, \varphi)$ 恰有 3 组, D 正确. 故选: BCD.
> >
> >
> > > 本题 两个无常数项三角函数比大小, 当其中一个大于等于另一个恒成立时, 则函数相等, $\sin x \geqslant \cos (\alpha x + \varphi)$ , 只需要利用诱导公式分析 $\sin x = \cos (\alpha x + \varphi)$ .
