> > [!note]- **【解析】**
> > 解析 (1) 法一: 因为 $\sqrt{3} b \sin C + b \cos C = a + 2c$ , 由正弦定理得 $\sqrt{3} \sin B \sin C + \sin B \cos C = \sin A + 2 \sin C$ , 因为 $\sin A = \sin (B + C) = \sin B \cos C + \cos B \sin C$ , 可得 $\sqrt{3} \sin B \sin C + \sin B \cos C = \sin B \cos C + \cos B \sin C + 2 \sin C$ , 即 $\sqrt{3} \sin B \sin C - \cos B \sin C = 2 \sin C$ , 又因为 $C \in (0, \pi)$ , 则 $\sin C > 0$ , 所以可得 $\sqrt{3} \sin B - \cos B = 2$ , 即 $\sin \left(B - \frac{\pi}{6}\right) = 1$ , 因为 $B \in (0, \pi)$ , 则 $B - \frac{\pi}{6} \in \left(-\frac{\pi}{6}, \frac{5\pi}{6}\right)$ , 可得 $B - \frac{\pi}{6} = \frac{\pi}{2}$ , 解得 $B = \frac{2\pi}{3}$ .
> >
> >
> > 法二： $\sqrt{3} b\sin C + b\cos C = a + 2c = b\cos C + c\cos B + 2c\Rightarrow \sqrt{3} b\sin C = \sqrt{3} c\sin B = c\cos B + 2c\Rightarrow 2\sin \left(B - \frac{\pi}{6}\right) = 2,B - \frac{\pi}{6} = \frac{\pi}{2},$ 解得 $B = \frac{2\pi}{3}$
> >
> > (2)由余弦定理得 $b^{2}=a^{2}+c^{2}-2ac\cos B$ ，即 $3=a^{2}+c^{2}+2ac\times\frac{1}{2}$ ，即 $a^{2}+c^{2}+ac=3$ ，所以 $(a+c)^{2}-3=ac$ ，因为 BD 是 $\angle ABC$ 的平分线，所以 $\angle ABD=\angle CBD=\frac{\pi}{3}$ ，又因为 $S_{\triangle CBD}+S_{\triangle ABD}=S_{\triangle ABC}$ ，可得 $\frac{1}{2}\cdot a\cdot BD\cdot\sin\frac{\pi}{3}+\frac{1}{2}\cdot c\cdot BD$ 和 $\frac{\pi}{3}=\frac{1}{2}ac\cdot\sin\frac{2\pi}{3}$ ，即 $(a+c)\cdot BD=ac$ （推导角平分线张角定理），所以 $BD=\frac{ac}{a+c}=\frac{(a+c)^{2}-3}{a+c}=(a+c)-\frac{3}{a+c}$ ，因为 $(a+c)^{2}-3=ac\leqslant\left(\frac{a+c}{2}\right)^{2}$ ，当且仅当 a=c 时等号成立，所以 $\sqrt{3}<a+c\leqslant2$ 。令 $a+c=t$ ，则 $BD=t-\frac{3}{t}$ ，令 $g(t)=t-\frac{3}{t}$ ，因为 $g(t)$ 在 $(\sqrt{3},2]$ 上单调递增，所以当 t=2 时，BD 最大，最大值为 $\frac{1}{2}$ 。
> >
> > (3)由正弦定理得 $\frac{ac - ab + bc}{b^2} = \frac{\sin A\sin C - \sin A\sin B + \sin B\sin C}{\sin^2B} = \frac{4}{3}\left[\sin A\sin \left(\frac{\pi}{3} -A\right) - \frac{\sqrt{3}}{2}\sin A + \frac{\sqrt{3}}{2}\sin \left(\frac{\pi}{3} -A\right)\right]$ $= \frac{4}{3}\left[\sin A\left(\frac{\sqrt{3}}{2}\cos A - \frac{1}{2}\sin A\right) - \frac{\sqrt{3}}{2}\sin A + \frac{\sqrt{3}}{2}\left(\frac{\sqrt{3}}{2}\cos A - \frac{1}{2}\sin A\right)\right]$ $= \frac{4}{3}\left[\sin A\left(\frac{\sqrt{3}}{2}\cos A - \frac{1}{2}\sin^2A - \frac{3\sqrt{3}}{4}\sin A + \frac{3}{4}\cos A\right) = \frac{4}{3}\left[\frac{\sqrt{3}}{4}\sin 2A + \frac{1}{4}\cos 2A - \frac{1}{4} -\frac{3}{2}\sin \left(A - \frac{\pi}{6}\right)\right]$ $= \frac{4}{3}\left[\frac{1}{2}\sin \left(2A + \frac{\pi}{6}\right) - \frac{3}{2}\sin \left(A - \frac{\pi}{6}\right) - \frac{1}{4}\right] = \frac{2}{3}\sin \left(2A + \frac{\pi}{6}\right) - 2\sin \left(A - \frac{\pi}{6}\right) - \frac{1}{3},$
> >
> > 令 $x = A - \frac{\pi}{6}$ ，则 $2A + \frac{\pi}{6} = 2x + \frac{\pi}{2}$ 所以 $\sin \left(2A + \frac{\pi}{6}\right) = \sin \left(2x + \frac{\pi}{2}\right) = \cos 2x = 1 - 2\sin^2 x,$
> >
> > 即 $\frac{ac - ab + bc}{b^2} = -\frac{4}{3}\sin^2 x - 2\sin x + \frac{1}{3}$ , 因为 $B = \frac{2\pi}{3}$ , 可得 $A \in \left(0, \frac{\pi}{3}\right)$ , 则 $x = A - \frac{\pi}{6} \in \left(-\frac{\pi}{6}, \frac{\pi}{6}\right)$ , 可得 $\sin x \in \left(-\frac{1}{2}, \frac{1}{2}\right)$ , 由二次函数的性质得 $-\frac{4}{3}\sin^2 x - 2\sin x + \frac{1}{3}$ 在 $\sin x \in \left(-\frac{1}{2}, \frac{1}{2}\right)$ 时单调递减, 所以当 $\sin x = -\frac{1}{2}$ 时, $-\frac{4}{3}\sin^2 x - 2\sin x + \frac{1}{3}$ 取得最大值为 1; 当 $\sin x = \frac{1}{2}$ 时; $-\frac{4}{3}\sin^2 x - 2\sin x + \frac{1}{3}$ 取得最小值为 -1,
> >
