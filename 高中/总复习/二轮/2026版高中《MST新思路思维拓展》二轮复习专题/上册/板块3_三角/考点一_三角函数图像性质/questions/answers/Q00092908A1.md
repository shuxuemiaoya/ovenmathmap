> [!faq]- 例题解析
>
> > [!success]- **【答案】** AC
>
> > [!note]- **【解析】**
> > 解析 因为 $f(x)$ 的导函数 $f'(x)=2\sqrt{2}\sin 2x$ ，所以 $f(x)=-\sqrt{2}\cos 2x+C$ ，
> >
> > 因为只有左右水平平移，故 C=0 ，所以 $f(x)=-\sqrt{2}\cos2x$
> >
> > 因为 $y = \sin 2x + \cos 2x = \sqrt{2}\left(\frac{\sqrt{2}}{2}\sin 2x + \frac{\sqrt{2}}{2}\cos 2x\right) = \sqrt{2}\sin \left(2x + \frac{\pi}{4}\right)$ 或 $y = \sin 2x + \cos 2x = \sqrt{2}\left(\frac{\sqrt{2}}{2}\cos 2x + \frac{\sqrt{2}}{2}\sin 2x\right) = \sqrt{2}\cos \left(2x - \frac{\pi}{4}\right),$ $f(x) = -\sqrt{2}\cos 2x = \sqrt{2}\sin \left(2x + \frac{3\pi}{2}\right) = \sqrt{2}\cos (\pi -2x) = \sqrt{2}\cos (2x - \pi),$
> >
> > 对于 A, 将函数 $y = \sin 2x + \cos 2x$ 的图象向左平移 $\frac{5\pi}{8}$ 个单位长度,
> >
> > 得 $y = \sqrt{2}\sin \left[2\left(x + \frac{5\pi}{8}\right) + \frac{\pi}{4}\right] = \sqrt{2}\sin \left(2x + \frac{3\pi}{2}\right)$ ，满足题意，故A正确；
> >
> > 对于B，将函数 $y = \sin 2x + \cos 2x$ 的图象向左平移 $\frac{5\pi}{4}$ 个单位长度，
> >
> > 得 $y = \sqrt{2}\sin \left[2\left(x + \frac{5\pi}{4}\right) + \frac{\pi}{4}\right] = \sqrt{2}\sin \left(2x + \frac{3\pi}{4}\right) = \sqrt{2}\cos \left(2x + \frac{\pi}{4}\right)$ ，不满足题意，故B错误；
> >
> > 对于 C, 将函数 $y = \sin 2x + \cos 2x$ 的图象向右平移 $\frac{3\pi}{8}$ 个单位长度, 得 $y = \sqrt{2} \cos \left[ 2 \left( x - \frac{3\pi}{8} \right) - \frac{\pi}{4} \right] = \sqrt{2} \cos (2x - \pi)$ , 满足题意, 故 C 正确;
> >
> > 对于 D, 将函数 $y = \sin 2x + \cos 2x$ 的图象向右平移 $\frac{3\pi}{4}$ 个单位长度, 得 $y = \sqrt{2} \cos \left[ 2 \left( x - \frac{3\pi}{4} \right) - \frac{\pi}{4} \right] = \sqrt{2} \cos \left( 2x - \frac{3\pi}{2} - \frac{\pi}{4} \right) = -\sqrt{2} \sin \left( 2x - \frac{\pi}{4} \right)$ , 不满足题意, 故 D 错误.
> >
> > 故选 **AC**.
