> [!faq]- 例题解析
>
> > [!success]- **【答案】** $\left(\frac{23}{5}, \frac{26}{5}\right] \cup \left(\frac{36}{5}, \frac{38}{5}\right]$
>
> > [!note]- **【解析】**
> > 解析 议 $T$ 为 $f(x)$ 的最小正周期，由题意可知， $\frac{T}{2} < \frac{\pi}{4} < T$ ，即 $\frac{\pi}{\omega} < \frac{\pi}{4} < \frac{2\pi}{\omega}$ ，解得 $4 < \omega < 8$ ，
> >
> > 由 $f(x) = 0$ 得， $\omega x + \frac{\pi}{5} = k\pi +\frac{\pi}{2},k\in Z,$ 由 $x\in \left[\frac{\pi}{4},\frac{\pi}{2}\right)$ 得， $\omega x + \frac{\pi}{5}\in \left[\frac{\omega\pi}{4} +\frac{\pi}{5},\frac{\omega\pi}{2} +\frac{\pi}{5}\right),$
> >
> > 又 $4 < \omega < 8$ ，所以 $\frac{6\pi}{5} \leqslant \frac{\omega\pi}{4} + \frac{\pi}{5} < \frac{11\pi}{5}, \frac{11\pi}{5} \leqslant \frac{\omega\pi}{2} + \frac{\pi}{5} < \frac{21\pi}{5}$ ，由余弦函数的图象可知，两个相邻零点之间必有一条对称轴，即存在一个极值点。由题意 $\left\{ \begin{array}{l} \frac{\omega\pi}{4} + \frac{\pi}{5} \leqslant \frac{3\pi}{2} \\ \frac{5\pi}{2} < \frac{\omega\pi}{2} + \frac{\pi}{5} \leqslant 3\pi \end{array} \right.$ 或 $\left\{ \begin{array}{l} \frac{\omega\pi}{4} + \frac{\pi}{5} > 2\pi \\ \frac{7\pi}{2} < \frac{\omega\pi}{2} + \frac{\pi}{5} \leqslant 4\pi \end{array} \right.$ ，解得 $\frac{23}{5} < \omega \leqslant \frac{26}{5}$ 或 $\frac{36}{5} < \omega \leqslant \frac{38}{5}$ ，故实数 $\omega$ 的取值范围为 $\left(\frac{23}{5}, \frac{26}{5}\right] \cup \left(\frac{36}{5}, \frac{38}{5}\right]$ 。故答案为： $\left(\frac{23}{5}, \frac{26}{5}\right] \cup \left(\frac{36}{5}, \frac{38}{5}\right]$
