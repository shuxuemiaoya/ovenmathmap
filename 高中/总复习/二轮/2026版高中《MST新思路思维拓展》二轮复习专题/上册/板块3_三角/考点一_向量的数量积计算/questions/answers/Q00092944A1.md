> [!faq]- 例题解析
>
> > [!success]- **【答案】** BCD
>
> > [!note]- **【解析】**
> > 解析 依题意， $\overrightarrow{OP} = (x_0, y_0), i = (1, 0), j = (0, 1)$ ，由 $|\overrightarrow{OP}|^2 = |\overrightarrow{OP} \cdot i| + |\overrightarrow{OP} \cdot j|$ ，得 $x_0^2 + y_0^2 = |x_0| + |y_0|$ ，则曲线 $C: \left(|x_0| - \frac{1}{2}\right)^2 + \left(|y_0| - \frac{1}{2}\right)^2 = \frac{1}{2}$ ，对于 A，当 $x_0 = 1, y_0 = \frac{1}{2}$ 时， $x_0^2 + y_0^2 = \frac{5}{4} \neq \frac{3}{2} = |x_0| + |y_0|$ ，点 $\left(1, \frac{1}{2}\right)$ 不在曲线 C 上，A 错误；
> >
> > 对于 B, $\left(|y_{0}|-\frac{1}{2}\right)^{2}\leqslant\frac{1}{2}$ ，当且仅当 $x_{0}=\pm\frac{1}{2}$ 取等号，则 $|y_{0}|\leqslant\frac{1+\sqrt{2}}{2}$ ，B 正确；
> >
> > 对于 $\mathrm{C}, x_0^2 + y_0^2 \geqslant \frac{(|x_0| + |y_0|)^2}{2} = \frac{1}{2} (x_0^2 + y_0^2)^2$ ，当且仅当 $|x_0| = |y_0|$ 时取等号，则有 $x_0^2 + y_0^2 \leqslant 2, C$ 正确；
> >
> > 对于 D，当 $x_{0}y_{0}\geqslant0$ 时， $\left|x_{0}+y_{0}\right|=\left|x_{0}\right|+\left|y_{0}\right|=x_{0}^{2}+y_{0}^{2}\leqslant2$ ，则 $-2\leqslant x_{0}+y_{0}\leqslant2$ ，即 $-4\leqslant x_{0}+y_{0}-2\leqslant0$ ，因此 $\left(x_{0}+y_{0}-2\right|\leqslant4$ ；当 $x_{0}y_{0}\leqslant0$ 时，若 $\left(x_{0}+\frac{1}{2}\right)^{2}+\left(y_{0}-\frac{1}{2}\right)^{2}=\frac{1}{2}$ ，则 $\frac{(x_{0}+y_{0})^{2}}{2}=\frac{\left[\left(x_{0}+\frac{1}{2}\right)+\left(y_{0}-\frac{1}{2}\right)\right]^{2}}{2}\leqslant\left(x_{0}+\frac{1}{2}\right)^{2}+\left(y_{0}-\frac{1}{2}\right)^{2}=\frac{1}{2}$ ，若 $\left(x_{0}-\frac{1}{2}\right)^{2}+\left(y_{0}+\frac{1}{2}\right)^{2}=\frac{1}{2}$ ，则 $\frac{(x_{0}+y_{0})^{2}}{2}=\frac{\left[\left(x_{0}-\frac{1}{2}\right)+\left(y_{0}+\frac{1}{2}\right)\right]^{2}}{2}\leqslant\left(x_{0}-\frac{1}{2}\right)^{2}+\left(y_{0}+\frac{1}{2}\right)^{2}=\frac{1}{2}$ ，解得 $-1\leqslant x_{0}+y_{0}\leqslant1$ ，即 $-3\leqslant x_{0}+y_{0}-2\leqslant-1$ ，于是 $1\leqslant\left|x_{0}+y_{0}-2\right|\leqslant3$ ，因此 $\left|x_{0}-y_{0}-2\right|\leqslant4$ 成立，D 正确。
> >
> > 故选 **BCD**.
