> [!faq]- 例题解析
>
> > [!success]- **【答案】** BCD
>
> > [!note]- **【解析】**
> > 解析 $b-3a+6a\sin^{2}\frac{A+B}{2}=0$ ，所以 $b-3a+6a\cos^{2}\frac{C}{2}=0$ ，即 $b-3a+3a(\cos C+1)=0$ ，
> >
> > 所以 $\cos C = -\frac{b}{3a} < 0$ ，又 $C \in (0, \pi)$ ，所以 C 一定为钝角，A 错误；
> >
> >
> > 由余弦定理知， $\cos C = \frac{a^2 + b^2 - c^2}{2ab} = -\frac{b}{3a}$ ，化简得， $3a^{2} + 5b^{2} - 3c^{2} = 0,3a^{2} + 5b^{2} = 3c^{2},$ B正确；
> >
> > 因为 $\frac{\tan A}{\tan C} = \frac{\sin A\cos C}{\cos A\sin C} = \frac{a}{c}\cdot \frac{(a^3 + b^2 - c^2)\cdot 2bc}{2ab\cdot (b^2 + c^3 - a^2)} = \frac{-\frac{2}{3}b^0}{\frac{8}{3}b^2} = -\frac{1}{4}$ 所以 $4\tan A + \tan C = 0,C$ 正确；
> >
> > 因为 $A + B + C = \pi$ ，所以 $\tan B = -\tan (A + C) = -\frac{\tan A + \tan C}{1 - \tan A\tan C} = -\frac{\tan A - 4\tan A}{1 + \tan A\cdot 4\tan A} = \frac{3}{\frac{1}{\tan A} + 4\tan A},$
> >
> > 因为 C 为钝角, 所以 $A \in \left(0, \frac{\pi}{2}\right)$ , $\tan A > 0$ , 所以 $\frac{1}{\tan A} + 4\tan A \geqslant 2\sqrt{\frac{1}{\tan A} \cdot 4\tan A} = 4$ , 当且仅当 $\frac{1}{\tan A} = 4\tan A$ , 即 $\tan A = \frac{1}{2}$ 时, 等号成立, 此时 $\tan B$ 取得最大值 $\frac{3}{4}$ , D 正确.
> >
> > 故选 **BCD**.
