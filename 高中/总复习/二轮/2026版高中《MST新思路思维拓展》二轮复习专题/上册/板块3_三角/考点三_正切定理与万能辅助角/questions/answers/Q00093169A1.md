> [!faq]- 例题解析
>
> > [!success]- **【答案】** B
>
> > [!note]- **【解析】**
> > 解析 法一：由 $\left\{\begin{aligned}&2\sin C-\sin A=\sqrt{2}\sin B\\ &2\cos C+\cos A=\sqrt{6}\cos B\end{aligned}\right.$ ，得 $\left\{\begin{aligned}&4\sin^{2}C-4\sin C\sin A+\sin^{2}A=2\sin^{2}B\\ &4\cos^{2}C+4\cos C\cos A+\cos^{2}A=6\cos^{2}B\end{aligned}\right.$
> >
> > 两式相加得, $4+4\cos(C+A)+1=2+4\cos^{2}B$ ,得 $4\cos^{2}B+4\cos B-3=0$ ,
> >
> > 得 $(2\cos B - 1)(2\cos B + 3) = 0$ ，得 $\cos B = \frac{1}{2}$ 或 $\cos B = -\frac{3}{2}$ （舍去），因为 $0 < B < \frac{\pi}{2}$ 所以 $B = \frac{\pi}{3}$
> >
> > 法二(万能辅助角): $2\sin C - \sin A = 2\sin C - \sin B\cos C - \cos B\sin C = \sqrt{5 - 4\cos B}\sin(C - \varphi)$ , $\tan\varphi = \frac{\sin B}{2 - \cos B}$
> >
> > 同理， $2\cos C + \cos A = \sqrt{5 - 4\cos B}\cos (C - \varphi),\tan \varphi = \frac{\sin B}{2 - \cos B},$ 再利用 $\sin^2 (C - \varphi) + \cos^2 (C - \varphi) = \frac{2\sin^2B + 6\cos^2B}{5 - 4\cos B} =$
> >
> > 1, 得 $4 \cos^{2} B + 4 \cos B - 3 = 0$ , 所以 $B = \frac{\pi}{3}$ ,
> >
> > 则 $\left\{ \begin{array}{l} 2\sin C - \sin A = \frac{\sqrt{6}}{2} \\ 2\cos C + \cos A = \frac{\sqrt{6}}{2} \end{array} \right.$ 得 $\left\{ \begin{array}{l} 2\sin C = \frac{\sqrt{6}}{2} + \sin A \\ 2\cos C = \frac{\sqrt{6}}{2} - \cos A \end{array} \right.$ ，得 $4\sin^2 C + 4\cos^2 C = \left(\frac{\sqrt{6}}{2} + \sin A\right)^2 + \left(\frac{\sqrt{6}}{2} - \cos A\right)^2$
> >
> > 得 $4 = \frac{6}{4} +\sqrt{6}\sin A + \sin^2 A + \frac{6}{4} -\sqrt{6}\cos A + \cos^2 A$ ，得 $\sin A = \cos A$ ，即 $\tan A = 1$
> >
> > 因为 $0 < A < \frac{\pi}{2}$ , 所以 $A = \frac{\pi}{4}$ , 得 $C = \pi - \frac{\pi}{3} - \frac{\pi}{4} = \frac{5\pi}{12}$ , 则 $\sin C + \cos C = \sqrt{2} \sin \left(C + \frac{\pi}{4}\right) = \sqrt{2} \sin \left(\frac{5\pi}{12} + \frac{\pi}{4}\right) = \sqrt{2} \sin \frac{2\pi}{3} = \frac{\sqrt{6}}{2} \neq \cos A = \frac{\sqrt{2}}{2}$ , 故 $A$ 项错误,
> >
> > 则 $\sin C - \cos C = \sqrt{2}\sin \left(C - \frac{\pi}{4}\right) = \sqrt{2}\sin \left(\frac{5\pi}{12} -\frac{\pi}{4}\right) = \sqrt{2}\sin \frac{\pi}{6} = \frac{\sqrt{2}}{2} = \sin A = \frac{\sqrt{2}}{2}$ 。故 $B$ 项正确；
> >
> >
> > 由锐角 $\triangle ABC$ 的面积为 $3 + \sqrt{3}$ ，得 $\frac{1}{2} ac\sin B = 3 + \sqrt{3}$ ，得 $ac = 4(\sqrt{3} + 1)$ ，设 $\triangle ABC$ 的外接圆半径为： $R$ 。
> >
> > 则 $2R\sin A \cdot 2R\sin C = 4(\sqrt{3} + 1)$ ，而 $\sin A = \frac{\sqrt{2}}{2}, \sin C = \sin \frac{5\pi}{12} = \sin \frac{7\pi}{12} = \sin \left(\frac{\pi}{3} + \frac{\pi}{4}\right) = \frac{\sqrt{6} + \sqrt{2}}{4}$ ，
> >
> > 则 $4R^{2} \cdot \frac{\sqrt{2}}{2} \times \frac{\sqrt{6} + \sqrt{2}}{4} = 4(\sqrt{3} + 1)$ ，得 $R = 2$ ，得 $a = 2R\sin A = 2 \times 2 \times \frac{\sqrt{2}}{2} = 2\sqrt{2}$ ，
> >
> > $$
> > b = 2 R \sin B = 2 \times 2 \times \frac {\sqrt {3}}{2} = 2 \sqrt {3}, c = 2 R \sin C = 2 \times 2 \times \frac {\sqrt {6} + \sqrt {2}}{4} = \sqrt {6} + \sqrt {2},
> > $$
> >
> > 得 $AC^2 - BC^2 = b^2 - a^2 = (2\sqrt{3})^2 - (2\sqrt{2})^2 = 4$ ，故 $C$ 项正确，
> >
> > 由锐角 $\triangle ABC$ 的面积为 $3 + \sqrt{3}$ , 得 $\frac{1}{2} ch = 3 + \sqrt{3}$ , 得 $\frac{1}{2} (\sqrt{6} + \sqrt{2})h = 3 + \sqrt{3}$ , 得 $h = \sqrt{6}$ , 故 D 正确.
> >
> > 故选 **BCD**.
