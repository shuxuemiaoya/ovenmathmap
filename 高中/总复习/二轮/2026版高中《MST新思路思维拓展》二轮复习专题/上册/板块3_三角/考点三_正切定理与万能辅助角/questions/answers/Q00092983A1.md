> [!faq]- 例题解析
>
> > [!success]- **【答案】** 4
>
> > [!note]- **【解析】**
> > 解析 因为 $a = 2b\sin C$ ，由正弦定理得 $\sin A = 2\sin B\sin C$ ，即 $\sin B\cos C + \cos B\sin C = 2\sin B\sin C$
> >
> > 等式两边同时除以 $\sin B\sin C$ ，得到 $\frac{\cos C}{\sin C} +\frac{\cos B}{\sin B} = 2$ ，即 $\frac{1}{\tan C} +\frac{1}{\tan B} = 2,$
> >
> > $$
> > \tan B + \tan C + \tan A = 2 \tan B \tan C + \tan A = \tan A \tan B \tan C \Rightarrow \tan B \tan C = \frac {\tan A}{\tan A - 2} (\tan A > 2),
> > $$
> >
> > 那么 $\frac{4}{\tan A} -\frac{1}{2}\tan B\tan C = \frac{4}{\tan A} +\frac{1}{2}\cdot \frac{\tan A}{2 - \tan A} = \frac{4}{\tan A} +\frac{1}{2}\cdot \frac{-2 + \tan A + 2}{2 - \tan A} = \frac{4}{\tan A} +\frac{1}{2 - \tan A} -\frac{1}{2},$
> >
> > 由反向柯西不等式得 $[\tan A + (2 - \tan A)]\left(\frac{4}{\tan A} +\frac{1}{2 - \tan A}\right)\leqslant 1$ ，当且仅当 $\frac{\tan^2A}{4} = (2 - \tan A)^2$ ，所以 $\tan A = 4.$ 故答案为：4
