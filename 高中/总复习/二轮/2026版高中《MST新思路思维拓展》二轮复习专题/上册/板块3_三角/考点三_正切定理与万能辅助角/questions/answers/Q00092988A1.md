> [!faq]- 例题解析
>
> > [!success]- **【答案】** $\frac{1}{3}$
>
> > [!note]- **【解析】**
> > 解析 $\frac{1}{\tan A} + \frac{1}{\tan C} = \frac{\lambda}{\tan B} \Leftrightarrow \lambda = \frac{2b^2}{a^2 + c^2 - b^2}$ ①, $\frac{1}{\tan B} + \frac{1}{\tan C} = \frac{\mu}{\tan A} \Leftrightarrow \mu = \frac{2a^2}{b^2 + c^2 - a^2}$ ②,
> >
> > 又由题设可知 $\frac{1}{\tan A} + \frac{2}{\tan B} = \frac{3}{\tan C}$ ，故两式相加： $\frac{2}{\tan C} = \frac{\lambda - 1}{\tan B} + \frac{\mu - 1}{\tan A}$ ，所以 $\frac{2}{3} = \frac{\lambda - 1}{2} = \frac{\mu - 1}{1}, \begin{cases} \lambda = \frac{7}{3} \\ \mu = \frac{5}{5} \end{cases}$ ， $6a^2 = 5(b^2 + c^2 - a^2)$ (3), $4a^2 + 8b^2 = 12c^2$ ，故 $\frac{c^2}{a^2 + 2b^2} = \frac{1}{3}$ ，故答案为 $\frac{1}{3}$ . $6b^2 = 7(a^2 + c^2 - b^2)$ (4)
