> [!faq]- 例题解析
>
> > [!success]- **【答案】** C
>
> > [!note]- **【解析】**
> > 解析 (1)由余弦定理得 $c^2 = a^2 + b^2 - 2ab\cos C$ ，又 $a^2 + b^2 = 2c^2$ ，所以 $c^2 = 2c^2 - 2ab\cos C$ ，即 $c^2 = 2ab\cos C$ 由正弦定理得 $\sin^2 C = 2\sin A\sin B\cos C$ ，因为 $A + B + C = \pi$ ，所以 $\sin C = \sin (A + B) = \sin A\cos B + \cos A\sin B$
> >
> > 由 $\triangle ABC$ 为锐角三角形, 得 $\tan C = \frac{2\sin A\sin B}{\sin C} = \frac{2\sin A\sin B}{\sin A\cos B + \cos A\sin B} = \frac{2\tan A\tan B}{\tan A + \tan B}$ , 两边取倒数得 $\frac{2}{\tan C} = \frac{1}{\tan A} + \frac{1}{\tan B}$ .
> >
> > (2)(1)因为 c=2，所以 $a^{2}+b^{2}=8\geqslant2ab$ ，即 $ab\leqslant4$ ，当且仅当 a=b=2 时等号成立，
> >
> > 所以 $(a + b)^2 = a^2 + b^2 + 2ab = 8 + 2ab \leqslant 16$ ，即 $a + b \leqslant 4$ ，所以 $a + b + c \leqslant 6$ ，当且仅当 $a = b = c = 2$ 时等号成立，满足 $\triangle ABC$ 为锐角三角形，所以 $\triangle ABC$ 周长的最大值为 6.
> >
> > (Ⅱ) $\cos C=\frac{a^{2}+b^{2}-c^{2}}{2ab}=\frac{c^{2}}{2ab}>0$ 成立，即C为锐角，且 $ab=\frac{c^{2}}{2\cos C}$ ，由A,B为锐角得 $\cos A=\frac{b^{2}+c^{2}-a^{2}}{2bc}=\frac{3c^{2}-2a^{2}}{2bc}>0$ 及 $\cos B=\frac{a^{2}+c^{2}-b^{2}}{2ac}=\frac{2a^{2}-c^{2}}{2ac}>0$ ，解得 $c^{2}<2a^{2}<3c^{2}$ ，即 $a^{2}\in(2,6)$
> >
> > $\triangle ABC$ 的面积为 $S_{\triangle ABC} = \frac{1}{2} ab\sin C = \frac{1}{2}\cdot \frac{c^2}{2\cos C}\cdot \sin C = \tan C$ ，因为 $\cos^2 C = \left(\frac{c^2}{2ab}\right)^2 = \frac{c^4}{4a^3(2c^2 - a^2)} = \frac{4}{a^2(8 - a^2)}$ 令 $f(x) = x(8 - x) = -x^{2} + 8x,x\in (2,6)$ ，则二次函数 $f(x)$ 开口向下，对称轴为 $x = 4,f(x)$ 在(2,4)上单调递增，在(4,6)上单调递减，又 $f(2) = f(6) = 12,f(4) = 16$ ，所以 $f(x)\in (12,16]$ ，即 $\cos^2 C\in \left[\frac{1}{4},\frac{1}{3}\right)$ ，所以 $\tan^2 C + 1 =$ $\frac{\sin^2C + \cos^2C}{\cos^2C} = \frac{1}{\cos^2C}\in (3,4]$ ，即 $\tan^2 C\in (2,3]$ ，所以 $S_{\triangle ABC} = \tan C\in (\sqrt{2},\sqrt{3} ]$ ，即△ABC面积的取值范围为 $(\sqrt{2},\sqrt{3} ]$
> >
> > 本质就是 $\frac{1}{\tan A} +\frac{1}{\tan B} = \frac{|AD|}{h} +\frac{|BD|}{h} = \frac{c}{h} = \frac{2}{\tan C}$ 且 $S = \frac{ch}{2} = \frac{c^2\tan C}{4} = \tan C = \frac{1}{4}(a^2 +b^2 -c^2)\tan C$ 来回变形。
