> [!faq]- 例题解析
>
> > [!success]- **【答案】** 8
>
> > [!note]- **【解析】**
> > 解析 $\sin A = \sin (\pi - A) = \sin (B + C) = \sin B \cos C + \cos B \sin C, \sin A = 2 \sin B \sin C,$
> >
> > 可得 $\sin B\cos C + \cos B\sin C = 2\sin B\sin C,$ ①由三角形 ABC 为锐角三角形，则 $\cos B > 0, \cos C > 0,$
> >
> > 在①式两侧同时除以 $\cos B\cos C$ 可得 $\tan B + \tan C = 2\tan B\tan C$ ，又 $\tan A\tan B\tan C = \tan A + \tan B + \tan C②$
> >
> >
> > $+\tan C$ 时取等号，此时 $\tan A\tan B\tan C=8$ ，所以 $\tan B+\tan C=4,\tan B\tan C=2$ ，
> >
> > 解得 $\tan B = 2 + \sqrt{2},\tan C = 2 - \sqrt{2},\tan A = 4$ ，（或 $\tan B,\tan C$ 互换），此时 $A,B,C$ 均为锐角.故答案为：8
