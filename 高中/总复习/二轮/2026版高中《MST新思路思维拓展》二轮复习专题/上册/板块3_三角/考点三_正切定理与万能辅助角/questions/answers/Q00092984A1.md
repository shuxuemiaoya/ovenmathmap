> [!faq]- 例题解析
>
> > [!success]- **【答案】** BD
>
> > [!note]- **【解析】**
> > 解析 A 选项, 若 $\sin A = \sin B - \sin C$ , 由正弦定理可得 $a = b - c$ , 由三角形三边关系可知等式 $a = b - c$ 不成立, A 错;
> >
> > 对于 B 选项, 若 $\tan A = \tan B + \tan C \Leftrightarrow 2\tan A = \tan A + \tan B + \tan C = \tan A\tan B\tan C$ , 故只需 $\tan B\tan C = 2$ 即可, 合乎题意;
> >
> > C 选项, 若 $\sin A = \cos B - \cos C = \cos B + \cos (A + B) = \cos B(1 + \cos A) - \sin A\sin B = 2\cos \frac{A}{2}\cos \left(B + \frac{A}{2}\right)$ , 则 $\sin \frac{A}{2} = \cos \left(B + \frac{A}{2}\right)$ , 则 $A + B = \frac{\pi}{2}$ , 这与题意斜三角形矛盾, C 错;
> >
> > 对于 D 选项, $\cos A = \sin B + \sin C = \sin B + \sin(A + B) = \cos \frac{A}{2} \sin \left( B + \frac{A}{2} \right)$ , 所以 $2 \cos^{2} \frac{A}{2} - \sin \left( B + \frac{A}{2} \right) \cos \frac{A}{2} - 1 = 0$ 一个位于 $\cos \frac{A}{2} \in \left( \frac{\sqrt{2}}{2}, 1 \right)$ 的根, $f(x) = 2x^{2} - \sin \left( B + \frac{A}{2} \right)x - 1 = 0$ , $f\left( \frac{\sqrt{2}}{2} \right) = -\sin \left( B + \frac{A}{2} \right) < 0$ , $f(1) = 1 - \sin \left( B + \frac{A}{2} \right) > 0$ , 故锐角 A 存在, D 对.
> >
> > 故选 **BD**.
