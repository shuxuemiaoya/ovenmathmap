> [!faq]- 例题解析
>
> > [!success]- **【答案】** BCD
>
> > [!note]- **【解析】**
> > 解析 对于 A、因为 $\frac{\sin A}{\sin B} + \frac{\sin B}{\sin A} = 4 \cos C = 4 \times \frac{a^{2} + b^{2} - c^{2}}{2ab} = \frac{2(a^{2} + b^{2} - c^{2})}{ab}$ ，即 $\frac{a}{b} + \frac{b}{a} = \frac{2(a^{2} + b^{2} - c^{2})}{ab}$ ，整理得： $a^{2} + b^{2} = 2c^{2}$ ，即 $\sin^{2}A + \sin^{2}B = 2\sin^{2}C$ ，故 A 错误；
> >
> > 对于 B, 因为 $\sin A > 0, \sin B > 0$ , 所以 $4\cos C = \frac{\sin A}{\sin B} + \frac{\sin B}{\sin A} \geqslant 2\sqrt{\frac{\sin A}{\sin B} \times \frac{\sin B}{\sin A}} = 2$ , 当且仅当 $\frac{\sin A}{\sin B} = \frac{\sin B}{\sin A}$ , 即 A = B 时, 等号成立, 所以 $\cos C \geqslant \frac{1}{2}$ , 又因为 $C \in (0, \pi)$ , 所以 $C \in \left(0, \frac{\pi}{3}\right]$ , 所以 C 的最大值为 $\frac{\pi}{3}$ , 故 B 正确;
> >
> > 对于 C, 由 A 可知 $\sin^{2}A + \sin^{2}B = 2\sin^{2}C$ , 即 $\sin^{2}A - \sin^{2}C = \sin^{2}C - \sin^{2}B$ , 证明正弦平方差, 即可得 C 正确, 证明过程如下: $\sin(A+C)\sin(A-C) = (\sin A\cos C + \cos A\sin C)(\sin A\cos C - \cos A\sin C)$ $=\sin^{2}A\cos^{2}C-\cos^{2}A\sin^{2}C=\sin^{2}A(1-\sin^{2}C)-(1-\sin^{2}A)\sin^{2}C=\sin^{2}A-\sin^{2}C,$
> >
> > $$
> > \sin^ {2} A - \sin^ {2} C = \sin (A + C) \sin (A - C)
> > $$
> >
> > $$
> > \sin^ {2} C - \sin^ {2} B = \sin (C + B) \sin (C - B)
> > $$
> >
> > $$
> > \sin (A + C) \sin (A - C) = \sin (C + B) \sin (C - B)
> > $$
> >
> > $$
> > \sin (\pi - B) \sin (A - C) = \sin (\pi - A) \sin (C - B)
> > $$
> >
> > $$
> > \sin B \sin (A - C) = \sin A \sin (C - B)
> > $$
> >
> > 对于D，因为 $\frac{1}{\tan A} +\frac{1}{\tan B} = \frac{\cos A}{\sin A} +\frac{\cos B}{\sin B} = \frac{\sin A\cos B + \cos A\sin B}{\sin A\sin B} = \frac{\sin(A + B)}{\sin A\sin B} = \frac{\sin C}{\sin A\sin B},$
> >
> > 又因为 $a^2 + b^2 = 2c^2$ ，所以 $\cos C = \frac{a^2 + b^2 - c^2}{2ab} = \frac{c^2}{2ab} = \frac{\sin^2 C}{2\sin A\sin B}$ ，
> >
> > $\frac{2}{\tan C} = \frac{2\cos C}{\sin C} = \frac{2\times\frac{\sin^2C}{2\sin A\sin B}}{\sin C} = \frac{\sin C}{\sin A\sin B}$ 所以 $\frac{1}{\tan A} +\frac{1}{\tan B} = \frac{2}{\tan C}$ ，也可以根据结论 $\left\{ \begin{array}{l}a^{2} + b^{2} = 2c^{2}\\ \frac{1}{\tan A} +\frac{1}{\tan B} = \frac{\lambda}{\tan C} \end{array} \right.\Leftrightarrow \lambda =$ $\frac{2c^2}{a^2 + b^2 - c^2} = 2$ ，故D正确.
> >
> > 故选 **BCD**.
