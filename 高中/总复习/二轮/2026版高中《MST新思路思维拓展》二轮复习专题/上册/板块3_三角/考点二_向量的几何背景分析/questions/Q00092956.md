A. $a \otimes (b + c) = a \otimes b + a \otimes c$ B. 若 $a = (1, 2), b = (-2, -1)$ , 则 $a \otimes b = 2$ C. $a \otimes b = |x_1y_2 - x_2y_1|$ D. 若 $a \otimes b = 2\sqrt{2}, a \cdot b = 1$ , 则 $|a + 2b|$ 的最小值为 4
