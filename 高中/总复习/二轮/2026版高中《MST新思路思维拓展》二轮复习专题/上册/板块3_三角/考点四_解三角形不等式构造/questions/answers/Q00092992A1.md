> [!faq]- 例题解析
>
> > [!success]- **【答案】** A
>
> > [!note]- **【解析】**
> > 解析 因为 $\cos A = -\sin B, A \in (0, \pi), B \in (0, \pi)$ ，故 $B + \frac{\pi}{2} = A$ ，所以 $C = \pi - A - B = \pi - B - B - \frac{\pi}{2} = \frac{\pi}{2} - 2B$
> >
> > 所以 $\sin C = \sin \left(\frac{\pi}{2} - 2B\right) = \cos 2B = 2\cos^2 B - 1$ ，故 $\frac{b^2 + c^2}{a^2} = \frac{\sin^2 B + \sin^2 C}{\sin^2 A} = \frac{1 - \cos^2 B + (2\cos^2 B - 1)^2}{\cos^2 B} = 4\cos^2 B + \frac{2}{\cos^2 B} - 5 \geqslant 2\sqrt{4\cos^2 B \cdot \frac{2}{\cos^2 B}} - 5 = 4\sqrt{2} - 5(*)$ ，当且仅当 $4\cos^2 B = \frac{2}{\cos^2 B}$ ，即 $\cos^2 B = \frac{\sqrt{2}}{2}$ 时，等号成立，又 $A + B < \pi$ ，故 $2B + \frac{\pi}{2} < \pi$ ，解得 $0 < B < \frac{\pi}{4}$ ，
> >
> > 所以 $\frac{1}{2} < \cos^2 B < 1$ ，所以（ $*$ ）式可取等号，所以 $\frac{b^2 + c^2}{a^2} = 4\sin^2 A + \frac{2}{\sin^2 A} - 5$ 的最小值为 $4\sqrt{2} - 5$ .
> >
> > 故选 **A**.
