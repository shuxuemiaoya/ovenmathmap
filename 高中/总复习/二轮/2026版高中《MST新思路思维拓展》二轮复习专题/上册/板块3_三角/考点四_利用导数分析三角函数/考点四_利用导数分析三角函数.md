## 例9 (2026·安徽合肥·开学考试 T19) 已知函数 $f(x) = 3\sin x + \sin 3x$ .

(1)求曲线 $y = f(x)$ 在点 $\left(\frac{\pi}{6}, f\left(\frac{\pi}{6}\right)\right)$ 处的切线方程；

(2)求 $f(x)$ 的值域；

(3)若关于 $x$ 的方程 $f(x) = a(a \in \mathbb{R})$ 在 $\left(0, \frac{\pi}{2}\right)$ 内有两个根 $x_{1}, x_{2} (x_{1} < x_{2})$ , 证明: $x_{1} + x_{2} > \frac{\pi}{2}$ .

解析 $f(x) = 3\cos x + 3\cos 3x$ ，所以 $f^{\prime}\left(\frac{\pi}{6}\right) = 3\cos \frac{\pi}{6} +3\cos \frac{\pi}{2} = \frac{3\sqrt{3}}{2}$ 又 $f\left(\frac{\pi}{6}\right) = 3\sin \frac{\pi}{6} +\sin \frac{\pi}{2} = \frac{5}{2},$

故所求切线方程为 $y - \frac{5}{2} = \frac{3\sqrt{3}}{2}\left(x - \frac{\pi}{6}\right)$ ，即 $6\sqrt{3} x - 4y + 10 - \sqrt{3}\pi = 0$ ；

(2)法1: $f(x)$ 为以 $2\pi$ 为周期的函数,所以 $f(x)$ 在 $\left[-\frac{\pi}{4},\frac{7\pi}{4}\right]$ 上的值域即为 $f(x)$ 在定义域R上的值域.

$$
f ^ {\prime} (x) = 3 \cos x + 3 \cos 3 x
$$

$$
\cos 3 x = \cos (2 x + x) = \cos 2 x \cos x - \sin 2 x \sin x = (2 \cos^ {2} x - 1) \cos x - 2 \cos x (1 - \cos^ {2} x) = 4 \cos^ {3} x - 3 \cos x,
$$

$$
f ^ {\prime} (x) = 3 \cos x + 3 (4 \cos^ {3} x - 3 \cos x) = 6 \cos x (2 \cos^ {2} x - 1) = 1 2 \cos x \left(\cos x - \frac {\sqrt {2}}{2}\right) \left(\cos x + \frac {\sqrt {2}}{2}\right).
$$

①当 $x \in \left(-\frac{\pi}{4}, \frac{\pi}{4}\right)$ 时， $\cos x > 0, \cos x - \frac{\sqrt{2}}{2} > 0, \cos x + \frac{\sqrt{2}}{2} > 0$ ，所以 $f'(x) > 0$ ；

②当 $x \in \left(\frac{\pi}{4}, \frac{\pi}{2}\right)$ 时， $\cos x > 0, \cos x - \frac{\sqrt{2}}{2} < 0, \cos x + \frac{\sqrt{2}}{2} > 0$ ，所以 $f'(x) < 0$ ；

③当 $x \in \left(\frac{\pi}{2}, \frac{3\pi}{4}\right)$ 时， $\cos x < 0, \cos x - \frac{\sqrt{2}}{2} < 0, \cos x + \frac{\sqrt{2}}{2} > 0$ ，所以 $f'(x) > 0$

所以 $f(x)$ 在 $\left(-\frac{\pi}{4},\frac{\pi}{4}\right),\left(\frac{\pi}{2},\frac{3\pi}{4}\right)$ 上单调递增，在 $\left(\frac{\pi}{4},\frac{\pi}{2}\right)$ 上单调递减，又 $f\left(\frac{\pi}{4}\right) = f\left(\frac{3\pi}{4}\right) = 2\sqrt{2},f\left(-\frac{\pi}{4}\right) =$

$-2\sqrt{2}, f\left(\frac{\pi}{2}\right) = 2$ ，所以 $f(x)$ 在 $\left[-\frac{\pi}{4}, \frac{3\pi}{4}\right]$ 上的值域为 $\left[-2\sqrt{2}, 2\sqrt{2}\right]$ .

因为 $f(\pi + x) = 3\sin (\pi + x) + \sin (3\pi + 3x) = -3\sin x - \sin 3x = -f(x)$ ，所以 $f(x) = -f(x - \pi)$ 。当 $x \in \left[\frac{3\pi}{4}, \frac{7\pi}{4}\right]$ 时， $x - \pi \in \left[-\frac{\pi}{4}, \frac{3\pi}{4}\right]$ ，所以 $f(x)$ 在 $\left[\frac{3\pi}{4}, \frac{7\pi}{4}\right]$ 上的值域也为 $[-2\sqrt{2}, 2\sqrt{2}]$ ，

$$
[ - 2 \sqrt {2}, 2 \sqrt {2} ]
$$

法 2: $f(x)$ 为以 $2\pi$ 为周期的函数, 所以 $f(x)$ 在 $[-\pi, \pi]$ 上的值域即为 $f(x)$ 在定义域 $R$ 上的值域。由 (1) 知 $f'(x) = 3\cos x + 3\cos 3x$ , 因为 $\cos x = \cos(2x - x) = \cos 2x\cos x + \sin 2x\sin x$ , $\cos 3x = \cos(2x + x) = \cos 2x\cos x - \sin 2x\sin x$ , 所以 $f'(x) = 6\cos 2x\cos x$ .

当 $x \in \left(0, \frac{\pi}{4}\right)$ 时， $\cos 2x > 0, \cos x > 0$ ，所以 $f'(x) > 0$ ；当 $x \in \left(\frac{\pi}{4}, \frac{\pi}{2}\right)$ 时， $\cos 2x < 0, \cos x > 0$ ，所以 $f'(x) < 0$ ；当 $x \in \left(\frac{\pi}{2}, \frac{3\pi}{4}\right)$ 时， $\cos 2x < 0, \cos x < 0$ ，所以 $f'(x) > 0$ ；当 $x \in \left(\frac{3\pi}{4}, \pi\right)$ 时， $\cos 2x > 0, \cos x < 0$ ，所以 $f'(x) < 0$ ，所以 $f(x)$ 在 $\left(0, \frac{\pi}{4}\right)$ 和 $\left(\frac{\pi}{2}, \frac{3\pi}{4}\right)$ 上单调递增，在 $\left(\frac{\pi}{4}, \frac{\pi}{2}\right)$ 和 $\left(\frac{3\pi}{4}, \pi\right)$ 上单调递减，又 $f\left(\frac{\pi}{4}\right) = f\left(\frac{3\pi}{4}\right) = 2\sqrt{2}, f(0) = f(\pi) = 0, f\left(\frac{\pi}{2}\right) = 2$ ，所以 $f(x)$ 在 $[0, \pi]$ 上的值域为 $[0, 2\sqrt{2}]$ ，因为 $f(x)$ 为奇函数，所以 $f(x)$ 在 $[- \pi, 0]$ 上的值域为 $[-2\sqrt{2}, 0]$ . 所以 $f(x)$ 在 $[- \pi, \pi]$ 上的值域为 $[-2\sqrt{2}, 2\sqrt{2}]$ ，又 $2\pi$ 是 $f(x)$ 的一个周期，所以 $f(x)$ 的值域为 $[-2\sqrt{2}, 2\sqrt{2}]$ .

(3)由(2)知 $f(x)$ 在 $\left(0, \frac{\pi}{4}\right)$ 上单调递增，在 $\left(\frac{\pi}{4}, \frac{\pi}{2}\right)$ 上单调递减，所以 $0 < x_1 < \frac{\pi}{4} < x_2 < \frac{\pi}{2}$ ，要证 $x_1 + x_2 > \frac{\pi}{2}$ ，只需证 $x_2 > \frac{\pi}{2} - x_1$ ，因为 $0 < x_1 < \frac{\pi}{4}$ ，所以 $\frac{\pi}{2} - x_1 \in \left(\frac{\pi}{4}, \frac{\pi}{2}\right)$ ，所以只需证 $f(x_2) < f\left(\frac{\pi}{2} - x_1\right)$ ，因为 $f(x_1) = f(x_2)$ ，所以只需证 $f(x_1) < f\left(\frac{\pi}{2} - x_1\right)$ . 令 $g(x) = f(x) - f\left(\frac{\pi}{2} - x\right)\left(0 < x < \frac{\pi}{4}\right)$ ，则

$$
g ^ {\prime} (x) = f ^ {\prime} (x) + f ^ {\prime} \left(\frac {\pi}{2} - x\right) = 6 \cos x (2 \cos^ {2} x - 1) + 6 \cos \left(\frac {\pi}{2} - x\right) \cdot \left[ 2 \cos^ {2} \left(\frac {\pi}{2} - x\right) - 1 \right]
$$

$= 6\cos x\cos 2x + 6\sin x(2\sin^2 x - 1) = 6\cos 2x(\cos x - \sin x)$ . 因为 $0 < x < \frac{\pi}{4}$ , 所以 $0 < 2x < \frac{\pi}{2}, \frac{\pi}{4} < x + \frac{\pi}{4} < \frac{\pi}{2}$ ,

所以 $\cos2x>0,\cos x-\sin x=\sqrt{2}\cos\left(x+\frac{\pi}{4}\right)>0$ ，所以 $g'(x)>0$ ，所以 $g(x)$ 在 $\left(0,\frac{\pi}{4}\right)$ 上单调递增，所以 $g(x)<g\left(\frac{\pi}{4}\right)=0$ 。又 $0<x_{1}<\frac{\pi}{4}$ ，所以 $g(x_{1})<0$ ，所以 $f(x_{1})<f\left(\frac{\pi}{2}-x_{1}\right)$ ，问题得证。
