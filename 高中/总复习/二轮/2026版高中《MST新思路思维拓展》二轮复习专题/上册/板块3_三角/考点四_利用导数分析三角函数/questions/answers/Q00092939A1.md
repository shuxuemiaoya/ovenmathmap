> [!faq]- 例题解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【解析】**
> > 解析 由题可得 $f'(x) = \cos x + \cos 2x + \cos 3x$ ，所以 $f'\left(\frac{\pi}{4}\right) = \frac{\sqrt{2}}{2} + 0 - \frac{\sqrt{2}}{2} = 0$ ，所以切线的斜率为 0，由于 $f\left(\frac{\pi}{4}\right) = \frac{\sqrt{2}}{2} + \frac{1}{2} + \frac{1}{3} \times \frac{\sqrt{2}}{2} = \frac{4\sqrt{2} + 3}{6}$ ，则函数 $f(x)$ 在 $\left(\frac{\pi}{4}, f\left(\frac{\pi}{4}\right)\right)$ 处的切线方程为： $y = \frac{4\sqrt{2} + 3}{6}$ .
> >
> > (2) 由于 $\cos a + \cos b = \cos \left(\frac{a + b}{2} + \frac{a - b}{2}\right) + \cos \left(\frac{a + b}{2} - \frac{a - b}{2}\right) = 2\cos \frac{a + b}{2}\cos \frac{a - b}{2},$
> >
> > 所以 $f^{\prime}(x) = \cos x + \cos 2x + \cos 3x = 2\cos x\cos 2x + \cos 2x = \cos 2x(2\cos x + 1),$
> >
> > 当 $x \in (0, \pi)$ , 令 $f'(x) = 0$ , 解得 $x_{1} = \frac{\pi}{4}, x_{2} = \frac{3\pi}{4}, x_{3} = \frac{2\pi}{3}$ ,
> >
> > 则令 $f^{\prime}(x) > 0$ ，解得： $0 <   x <   \frac{\pi}{4}$ 或 $\frac{2\pi}{3} <  x <   \frac{3\pi}{4}$ ，令 $f^{\prime}(x) <   0$ ，解得： $\frac{\pi}{4} <  x <   \frac{2\pi}{3}$ 或 $\frac{3\pi}{4} <   x <   \pi$
> >
> > 所以 $f(x)$ 的增区间为： $\left(0,\frac{\pi}{4}\right)$ 和 $\left(\frac{2\pi}{3},\frac{3\pi}{4}\right)$ ，减区间为： $\left(\frac{\pi}{4},\frac{2\pi}{3}\right)$ 和 $\left(\frac{3\pi}{4},\pi\right)$ ;
> >
> > (3)证明：由于 $g(x) = f(x) + 2\sin x - mx = 3\sin x + \frac{1}{2}\sin 2x + \frac{1}{3}\sin 3x - mx,$
> >
> > 所以 $g^{\prime}(x) = 3\cos x + \cos 2x + \cos 3x - m$ ，由于 $\cos 3x = \cos 2x\cos x - \sin 2x\sin x = (2\cos^2 x - 1)\cos x - 2\sin^2 x\cos x = \cos x$ $(2\cos^2 x - 1 - 2\sin^2 x) = \cos x(4\cos^2 x - 3),$
> >
> > 所以 $g^{\prime}(x) = 3\cos x + \cos 2x + \cos 3x - m = 4\cos^{3}x + \cos 2x - m = 4\cos^{3}x + 2\cos^{2}x - (m + 1),$
> >
> > 因为 $g(x)$ 在 $(0, \pi)$ 上有三个不同的极值点 $x_{1}, x_{2}, x_{3} (x_{i} \neq \frac{\pi}{2}, i = 1, 2, 3)$ ,
> >
> > 所以 $g^{\prime}(x) = 0$ 在 $(0,\pi)$ 上有三个不同的根，即 $4\cos^3 x + 2\cos^2 x - (m + 1) = 0$ 在 $(0,\pi)$ 上有三个不同的根，
> >
> > 令 $t = \cos x\left(x\in (0,\pi)\right.$ 时， $t\in (-1,1)$ 且 $t\neq 0$ ，因为 $x_{i}\neq \frac{\pi}{2}$ ，方程转化为 $4t^{3} + 2t^{2} - (m + 1) = 0$ ，设方程的根为 $t_1 = \cos x_1,t_2 = \cos x_2,t_3 = \cos x_3$ ，则 $4(t - t_1)(t - t_2)(t - t_3) = 0$ ，化简可得： $4t^9 -4(t_1 + t_2 + t_3)t^2 +4(t_1t_2 + t_2t_3 + t_1t_3)t-$ $4t_{1}t_{2}t_{3} = 0$ ，则 $-4(t_{1} + t_{2} + t_{3}) = 2$ ，即 $t_1 + t_2 + t_3 = -\frac{1}{2},$
> >
> > $4(t_{1}t_{2} + t_{2}t_{3} + t_{1}t_{3}) = 0$ ，即 $t_1t_2 + t_2t_3 + t_1t_3 = 0, - 4t_1t_2t_3 = -(m + 1)$ ，即 $t_1t_2t_3 = \frac{m + 1}{4},$
> >
> > 所以 $\frac{1}{\cos x_1} + \frac{1}{\cos x_2} + \frac{1}{\cos x_3} = \frac{1}{t_1} + \frac{1}{t_2} + \frac{1}{t_3} = \frac{t_2t_3 + t_1t_3 + t_1t_2}{t_1t_2t_3} = 0.$ 所以 $\frac{1}{\cos x_1} + \frac{1}{\cos x_2} + \frac{1}{\cos x_3}$ 为定值.
