> [!faq]- 例题解析
>
> > [!success]- **【答案】** ABC
>
> > [!note]- **【解析】**
> > 解析 由于 $\cos 2A + \cos 2B + 2\sin C = 1 - 2\sin^2 A + 1 - 2\sin^2 B + 2\sin C = 2$ ，故 $\sin C = \sin^2 A + \sin^2 B$ ，故 A 正确；所以 $c = a\sin A + b\sin B$ ，结合射影定理， $c = a\cos B + b\cos A$ ，
> >
> > 故 $a(\sin A - \cos B) + b(\sin B - \cos A) = 0$ ，显然 $\left\{ \begin{array}{l} \sin A = \cos B \\ \sin B = \cos A \end{array} \right.$ 时成立，此时 $C = \frac{\pi}{2}$ ；当 $C > \frac{\pi}{2}$ 时， $A + B < \frac{\pi}{2}$ ， $\left\{ \begin{array}{l} \sin A < \sin \left(\frac{\pi}{2} - B\right) = \cos B \\ a(\sin A - \cos B) + b(\sin B - \cos A) < 0, \\ \sin B < \sin \left(\frac{\pi}{2} - A\right) = \cos A \end{array} \right.$
> >
> > 当 $C < \frac{\pi}{2}$ 时， $A + B > \frac{\pi}{2}$ ， $\left\{ \begin{array}{l} \sin A > \sin \left(\frac{\pi}{2} - B\right) = \cos B \\ \sin B > \sin \left(\frac{\pi}{2} - A\right) = \cos A \end{array} , a (\sin A - \cos B) + b (\sin B - \cos A) > 0, \text{与题意不符；又} \right.$
> >
> > $\cos A \cos B \sin C = \frac{1}{4} > 0$ ，故 $\cos A \cos B \sin C = \cos A \sin A = \frac{1}{4}$ ，故 $\sin 2A = \frac{1}{2}$ ，故 $A = \frac{\pi}{12}$ 或 $\frac{5\pi}{12}$ ，当 $A = \frac{\pi}{12}$ 时， $B = \frac{5\pi}{12}$ ；当 $A = \frac{5\pi}{12}$ 时， $B = \frac{\pi}{12}$ ；无论那种 $S = \frac{1}{2} \times \sin \frac{\pi}{12} c \times \sin \frac{5\pi}{12} c = \frac{c^2}{8} = \frac{1}{4}$ ，故 $c^2 = 2$ ，故 D 错误；故 C 正确；且 $\sin A + \sin B = \frac{\sqrt{6} - \sqrt{2}}{4}$
> >
> > $+\frac{\sqrt{6}+\sqrt{2}}{4}=\frac{\sqrt{6}}{2}$ ，故B正确，
> >
> > 故选 **ABC**.
