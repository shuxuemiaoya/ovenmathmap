> [!faq]- 例题解析
>
> > [!success]- **【答案】** $\frac{\pi}{2}$
>
> > [!note]- **【解析】**
> > $$
> > \text {   解析   } - \text {   由   } \cos A + \cos^ {2} B + \cos^ {2} C = 1, \cos^ {2} A + \cos^ {2} B + \cos^ {2} C = 3 - \sin^ {2} A - \sin B - \sin C
> > $$
> >
> > $= 3 - (2 + 2\cos A\cos B\cos C) = 1 - 2\cos A \cdot \cos B\cos C = 1$ ，又 $\cos A\cos B\sin C = \frac{\sqrt{3}}{4}$ ，则 $\cos C = 0$
> >
> > 所以 $C=\frac{\pi}{2}$ . 故答案为: $\frac{\pi}{2}$
