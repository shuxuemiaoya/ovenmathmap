> [!faq]- 例题解析
>
> > [!success]- **【答案】** BCD
>
> > [!note]- **【解析】**
> > 因为 $a = c\cos B = c\cos B + b\cos C$ ，所以 $C = \frac{\pi}{2}$ ，因为 $c = \sqrt{3}$ ，所以 $a^2 + b^2 = 3$ ，因为 $\triangle ABC$ 的面积为 $\frac{\sqrt{2}}{2}$ ，所以 $\frac{1}{2} ab = \frac{\sqrt{2}}{2}$ ，化简得 $ab = \sqrt{2}$ ，联立方程组 $\left\{ \begin{array}{l} a^2 + b^2 = 3 \\ ab = \sqrt{2} \end{array} \right.$ ，解得 $\left\{ \begin{array}{l} a = 1 \\ b = \sqrt{2} \end{array} \right.$ 或 $\left\{ \begin{array}{l} a = \sqrt{2} \\ b = 1 \end{array} \right.$ 对于 A，因为 $a \neq b$ ，所以 $A \neq B$ ，A 错误；对于 B，由上分析可知 $a^2 + b^2 = 3$ ，B 正确；对于 C，由上分析可知 $a + b = \sqrt{2} + 1$ ，C 正确；对于 D，因为正弦定理 $\frac{a}{\sin A} = \frac{c}{\sin C}$ ，所以 $\sin A = \frac{a\sin C}{c} = \frac{a}{c}$ ，则 $\sin A + \cos A = \frac{a}{c} + \frac{b}{c}$ ，当 $a = 1, b = \sqrt{2}, c = \sqrt{3}$ 时， $\sin A + \cos A = \frac{\sqrt{3} + \sqrt{6}}{3}$ ，同理当 $a = \sqrt{2}, b = 1, c = \sqrt{3}$ 时， $\sin A + \cos A = \frac{\sqrt{6} + \sqrt{3}}{3}$ ，D 正确；
> >
> > 故选 **BCD**.
