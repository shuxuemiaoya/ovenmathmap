> [!faq]- 例题解析
>
> > [!success]- **【答案】** ACD
>
> > [!note]- **【解析】**
> > 解析 对于 A, 因为 $\sin B + \sin C = 2\sin A\cos B$ , 由正弦定理可得 $b + c = 2a\cos B$ ,
> >
> > 再由余弦定理得 $b + c = 2a\cdot \frac{a^2 + c^2 - b^2}{2ac}$ 整理得 $a^2 -b^2 = bc$ ，故A正确；
> >
> > 对于 B, 若 $2c = a + b$ , 则 $a^{2} - b^{2} = (a - b)(a + b) = 2c(a - b) = bc$ , 则 $a = \frac{3}{2}b, c = \frac{5}{4}b$ , 由余弦定理可得 $\cos\angle ABC = \frac{a^{2} + c^{2} - b^{2}}{2ac} = \frac{\left(\frac{3}{2}b\right)^{2} + \left(\frac{5}{4}b\right)^{2} - b^{2}}{2 \times \frac{3}{2}b \times \frac{5}{4}b} = \frac{3}{4}$ , 故 B 错误;
> >
> > 对于 C, 由 $a^{2}-b^{2}=bc$ 可知: A=2B, 故 C 正确;
> >
> > 对于 D，因为 $\angle ABC, \angle CBD$ 互补，所以 $\cos\angle ABC + \cos\angle CBD = 0$ ，结合余弦定理可得 $\frac{a^{2} + c^{2} - b^{2}}{2ac} + \frac{a^{2} + |BD|^{2} - |CD|^{2}}{2a \cdot |BD|} = 0$ ，因为 $c = |AB| = 3, |BD| = 1$ ，则 $\frac{a^{2} + 9 - b^{2}}{3} + \frac{a^{2} + 1 - |CD|^{2}}{1} = 0$ ，整理得 $4a^{2} - b^{2} + 12 - 3 |CD|^{2} = 0$ ，又 $a^{2} = b^{2} + bc = b^{2} + 3b$ ，则 $|CD|^{2} = \frac{4}{3}a^{2} - \frac{1}{3}b^{2} + 4 = \frac{4}{3}(b^{2} + 3b) - \frac{1}{3}b^{2} + 4 = (b + 2)^{2}$ ，从而 $|CD| = b +$
> >
> >
> > 2, 故 $\left|CD\right| - \left|CA\right| = 2$ 为定值, 故 D 正确.
> >
> > 故选 **ACD**.
