> [!faq]- 例题解析
>
> > [!success]- **【答案】** BCD
>
> > [!note]- **【解析】**
> > 对于 $A, C > B > A, \sin^2 A + \sin^2 B + \sin^2 C = 2 = 2 + 2\cos A\cos B\cos C$ ，所以 $\cos C = 0$ ，故 $\triangle ABC$ 为直角三角形，故 A 错误；
> >
> > 对于 B, 由 $A + B = \frac{\pi}{2}$ ，则 $\sin B = \cos A$ ，所以 $\sin^{2}A + \sin B = 1 - \cos^{2}A + \cos A$ ，由于 $\cos A \in \left(\frac{\sqrt{2}}{2}, 1\right)$ ，故 $1 - \cos^{2}A + \cos A = -\left(\cos A - \frac{1}{2}\right)^{2} + \frac{5}{4} < \frac{\sqrt{2} + 1}{2}$ ，故 B 正确；
> >
> > 对于 C，由 $C=\frac{\pi}{2}$ ，则 $AC^{2}+BC^{2}=AB^{2}=16$ ，所以 $2AC+BC=8\sin B+4\sin A=8\cos A+4\sin A=4\sqrt{5}\sin(A+\alpha)$ ，
> >
> > 其中 $\sin \alpha = \frac{2\sqrt{5}}{5}, \cos \alpha = \frac{\sqrt{5}}{5}, A + \alpha \in (\alpha, \frac{\pi}{4} + \alpha)$ ，又 $\alpha > \frac{\pi}{4}, \sin \left(\frac{\pi}{4} + \alpha\right) = \frac{3\sqrt{10}}{10} > \frac{2\sqrt{5}}{5} = \sin \alpha$ ，故 $2AC + BC \in (8, 4\sqrt{5}]$ ，故 C 正确；
> >
> > 对于 D, $\angle B = \angle BCD > \frac{\pi}{4}$ , $\angle BDC < \frac{\pi}{2}$ , 所以 $\triangle BCD$ 必是锐角三角形, 即证 $\tan \angle BDC > \frac{1}{\tan B} = \tan \left( \frac{\pi}{2} - B \right)$ ,
> > 又 $\frac{\pi}{2}-B\in\left(0,\frac{\pi}{2}\right)$ ，即证 $\angle BDC>\frac{\pi}{2}-B$ ，即 $\angle BDC+B>\frac{\pi}{2}$ ，成立，故D正确.
> >
> > 故选 **BCD**.
