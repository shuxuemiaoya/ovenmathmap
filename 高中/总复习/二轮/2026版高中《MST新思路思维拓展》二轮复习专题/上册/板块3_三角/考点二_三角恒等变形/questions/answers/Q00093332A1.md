> [!faq]- 例题解析
>
> > [!success]- **【答案】** A
>
> > [!note]- **【解析】**
> > $$
> > \text {解析} \quad \text {因为} \sin^ {2} \alpha \cos^ {2} \beta - \cos^ {2} \alpha \sin^ {2} \beta = (\sin \alpha \cos \beta + \cos \alpha \sin \beta) (\sin \alpha \cos \beta - \cos \alpha \sin \beta) = \frac {1}{1 2},
> > $$
> >
> > 【解析】
> > 即 $\sin (\alpha +\beta)\sin (\alpha -\beta) = \frac{1}{12}$ ，因为 $\sin (\alpha -\beta) = \frac{1}{3}$ ，所以 $\sin (\alpha +\beta) = \frac{1}{4}$ 因为 $0 <   \alpha -\beta <  \frac{\pi}{2}$ ，且 $\sin (\alpha -\beta) = \frac{1}{3}$ 所以 $\cos (\alpha -\beta) = \frac{2\sqrt{2}}{3}$ ；因为 $\beta >0$ ，所以 $\alpha -\beta <  \alpha +\beta$ ，若 $0 <   \alpha +\beta <  \frac{\pi}{2}$ 时，由 $0 <   \alpha -\beta <   \alpha +\beta <  \frac{\pi}{2}$ 则有 $\sin (\alpha -\beta)<$ $\sin (\alpha +\beta)$ ，这与 $\sin (\alpha -\beta) = \frac{1}{3},\sin (\alpha +\beta) = \frac{1}{4}$ 矛盾，所以 $\frac{\pi}{2} <  \alpha +\beta <  \pi$ ，又因为 $\sin (\alpha +\beta) = \frac{1}{4}$ ，所以 $\cos (\alpha +\beta) =$ $-\frac{\sqrt{15}}{4}$ .则 $\cos 2\alpha = \cos [(a + \beta) + (a - \beta)] = \cos (a + \beta)\cos (a - \beta) - \sin (a + \beta)\sin (a - \beta) = -\frac{\sqrt{15}}{4}\times \frac{2\sqrt{2}}{3} -\frac{1}{4}\times \frac{1}{3}$ $= -\frac{2\sqrt{30} + 1}{12}$
> >
> > 故选 **A**.
