> [!faq]- 例题解析
>
> > [!success]- **【答案】** AB
>
> > [!note]- **【解析】**
> > 解析 $S_{11} = 4a_{n} + 2, a_{1} = 1$ ，可得 $n = 1$ 时， $S_{2} = a_{1} + a_{2} = 4a_{1} + 2$ ，即 $a_{2} = 3a_{1} + 2 = 3 + 2 = 5$ ； $n = 2$ 时， $S_{3} = a_{1} + a_{2} + a_{3} = 4a_{2} + 2$ ，即 $a_{3} = 3a_{2} + 2 - a_{1} = 15 + 2 - 1 = 16$ .
> >
> > 当 $n \geqslant 2$ 时，由 $S_{n+1} = 4a_n + 2$ ，可得 $S_n = 4a_{n-1} + 2$ ，相减可得 $a_{n+1} = S_{n+1} - S_n = 4a_n + 2 - 4a_{n-1} - 2,$
> >
> > 化简可得 $a_{n+1} = 4a_n - 4a_{n-1}$ ，即有 $a_{n+1} - 2a_n = 2(a_n - 2a_{n-1})$ ，而 $a_3 - 2a_2 = 6 = 2(a_2 - 2a_1)$ ，则 $\{a_{n+1} - 2a_n\}$ 首项为3，公比为2的等比数列，故A正确；
> >
> > 由等比数列的通项公式可得 $a_{n+1} - 2a_n = 3 \times 2^{n-1}$ , 即有 $\frac{a_{n+1}}{2^{n+1}} - \frac{a_n}{2^n} = \frac{3}{4}$ , 即 $\left\{\frac{a_n}{2^n}\right\}$ 是首项为 $\frac{1}{2}$ , 公差为 $\frac{3}{4}$ 的等差数列, 故 B 正确;
> >
> > 由等差数列的通项公式可得 $\frac{a_n}{2^n} = \frac{1}{2} +\frac{3}{4} (n - 1) = \frac{3n - 1}{4}$ 即 $a_{n} = (3n - 1)\cdot 2^{n - 2}$ ，则 $S_{n + 1} = 4a_{n} + 2 = (3n - 1)\cdot 2^{n} + 2$ $S_{n + 1} - 2S_n + 2 = (3n - 1)\cdot 2^n +2 - (3n - 4)\cdot 2^n -4 + 2 = 3\cdot 2^n$ ，对 $n = 1$ 也成立，即 $\{S_{n + 1} - 2S_n + 2\}$ 为等比数列，故D错误； $\frac{S_n - 2}{2^n} = \frac{(3n - 4)\cdot 2^{n - 1} + 2 - 2}{2^n} = \frac{3n - 4}{2}$ ，则 $\left\{\frac{S_n - 2}{2^n}\right\}$ 是等差数列，故C错误.
> >
