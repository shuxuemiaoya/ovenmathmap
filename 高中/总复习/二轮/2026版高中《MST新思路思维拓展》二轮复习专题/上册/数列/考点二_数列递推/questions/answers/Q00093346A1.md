> [!faq]- 例题解析
>
> > [!success]- **【答案】** 4
>
> > [!note]- **【解析】**
> > $$
> > a _ {1} = 2, a _ {n + 1} = 3 a _ {n} + 2 ^ {n - 1}, n \in \mathbf {N} ^ {\mathrm{a}}
> > $$
> >
> > $$
> > a _ {n + 1} + 2 ^ {n} = 3 \left(a _ {n} + 2 ^ {n - 1}\right)
> > $$
> >
> > $$
> > a _ {1} + 2 ^ {0} = 3
> > $$
> >
> > 所以，数列 $\{a_{n} + 2^{n - 1}\}$ 是首项为3，公比为3的等比数列，所以 $a_{n} + 2^{n - 1} = 3\cdot 3^{n - 1} = 3^{n}$ ，故 $b_{n} = \log \sqrt{3}(a_{n} + 2^{n - 1}) + 1 =$ $\log \sqrt{3} 3^n +1 = 2n + 1$ ，由 $15\left(1 + \frac{1}{b_1}\right)\left(1 + \frac{1}{b_2}\right)\dots \left(1 + \frac{1}{b_n}\right)\geqslant k\sqrt{10n + 15},$
> >
> > 可得 $k \leqslant \frac{15}{\sqrt{10n + 15}}\left(1 + \frac{1}{b_1}\right)\left(1 + \frac{1}{b_2}\right) \cdots \left(1 + \frac{1}{b_n}\right)$ ，令 $x_n = \frac{15}{\sqrt{10n + 15}}\left(1 + \frac{1}{b_1}\right)\left(1 + \frac{1}{b_2}\right) \cdots \left(1 + \frac{1}{b_n}\right)$ ，
> >
> > $$
> > \frac {x _ {n + 1}}{x _ {n}} = \frac {\frac {1 5}{\sqrt {1 0 (n + 1) + 1 5}} \left(1 + \frac {1}{b _ {1}}\right) \left(1 + \frac {1}{b _ {2}}\right) \cdots \left(1 + \frac {1}{b _ {n}}\right) \left(1 + \frac {1}{b _ {n + 1}}\right)}{\frac {1 5}{\sqrt {1 0 n + 1 5}} \left(1 + \frac {1}{b _ {1}}\right) \left(1 + \frac {1}{b _ {2}}\right) \cdots \left(1 + \frac {1}{b _ {n}}\right)} = \sqrt {\frac {2 n + 3}{2 n + 5}} \left(1 + \frac {1}{b _ {n + 1}}\right)
> > $$
> >
> > $= \sqrt{\frac{2n + 3}{2n + 5}}\cdot \left(1 + \frac{1}{2n + 3}\right) = \sqrt{\frac{2n + 3}{2n + 5}}\cdot \frac{2n + 5}{2n + 3} = \sqrt{\frac{2n + 5}{2n + 3}} >1$ ，对任意的 $n\in \mathbf{N}^{\circ},x_{n} > 0$ ，故 $\frac{x_{n + 1}}{x_n} >1$ ，则 $x_{n + 1} > x_n$ ，故数列 $\langle x_n\rangle$ 为递增数列，所以， $k\leqslant (x_n)_{\min} = x_1 = \frac{15}{5}\left(1 + \frac{1}{3}\right) = 4,$ 因此，实数 $k$ 的最大值为4.故答案为：4.
