> [!faq]- 例题解析
>
> > [!success]- **【答案】** C
>
> > [!note]- **【解析】**
> > 解析 $S_{n} = -n^{2} + 8n$ ，当 $n = 1$ 时， $a_1 = S_1 = -1^2 +8\times 1 = 7$ ，当 $n\geqslant 2$ 时， $a_{n} = S_{n} - S_{n - 1} = (-n^{2} + 8n) -$ $[-(n - 1)^{2} + 8(n - 1)] = -2n + 9$ ，经检验， $a_1 = 7$ 满足上式，
> >
> > 所以 $a_{n} = -2n + 9(n\in \mathbf{N}^{\circ})$ ，令 $a_{n} = -2n + 9\geqslant 0\Rightarrow n\leqslant 4,a_{n} = -2n + 9\leqslant 0\Rightarrow n\geqslant 5,$
> >
> > 设数列 $\{|a_n|\}$ 的前 $n$ 项和为 $T_{n}$ ，则数列 $\{|a_n|\}$ 的前4项和为 $T_{4} = S_{4} = -4^{2} + 8\times 4 = 16$
> >
> > 数列 $\left(\left|a_{n}\right|\right)$ 的前12项和为 $T_{12}=\left|a_{1}\right|+\left|a_{2}\right|+\cdots+\left|a_{12}\right|=a_{1}+a_{2}+a_{3}+a_{4}-a_{5}-a_{6}-\cdots-a_{12}=2S_{4}-S_{12}=2\times16-(-12^{2}+8\times12)=80.$
> >
> > 故选 **C**.
