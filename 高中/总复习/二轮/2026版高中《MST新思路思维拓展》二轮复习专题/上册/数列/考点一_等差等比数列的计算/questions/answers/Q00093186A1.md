> [!faq]- 例题解析
>
> > [!success]- **【答案】** C
>
> > [!note]- **【解析】**
> > 解析 等 $(a_{n})$ 是等差数列，设数列 $(a_{n})$ 的首项为 $a_{1}$ ，公差为 $d$ ，则 $S_{n} = na_{1} + \frac{n(n - 1)}{2} d$
> >
> > 即 $\frac{S_n}{n} = a_1 + \frac{n - 1}{2} d = \frac{d}{2} n + a_1 - \frac{d}{2}$ ，故 $\left\{\frac{S_n}{n}\right\}$ 为等差数列，即甲是乙的充分条件.
> >
> > 反之，若 $\left\{\frac{S_n}{n}\right\}$ 为等差数列，则可设 $\frac{S_{n + 1}}{n + 1} -\frac{S_n}{n} = D$ ，则 $\frac{S_n}{n} = S_1 + (n - 1)D,$
> >
> > 即 $S_{n} = nS_{1} + n(n - 1)D = na_{1} + \frac{n(n - 1)}{2} d$ ，故满足 $D = \frac{d}{2}$ ，所以数列 $\{a_{n}\}$ 为等差数列.即甲是乙的必要条件.综上所述，甲是乙的充要条件.
> >
> > 故本题选:C.
