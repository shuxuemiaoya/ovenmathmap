> [!faq]- 例题解析
>
> > [!success]- **【答案】** C
>
> > [!note]- **【解析】**
> > 解析 法一: 设等差数列 $\{a_{n}\}$ 的前 n 项和为 $S_{n}, a_{2} = -3, S_{5} = -10$ ，所以 $\left\{\begin{aligned}a_{1} + d &= -3 \\ 5a_{1} + \frac{5 \times 4}{2}d &= -10\end{aligned}\right.$
> >
> > 解得 $a_1 = -4, d = 1$ ，所以 $a_5 = a_1 + 4d = -4 + 4 \times 1 = 0, S_n = na_1 + \frac{n(n-1)}{2}d = -4n + \frac{n(n-1)}{2} = \frac{1}{2}\left(n - \frac{9}{2}\right)^2 - \frac{81}{8}$ ，所以 $n = 4$ 或 $n = 5$ 时， $S_n$ 取最小值为 $S_4 = S_5 = -10$ .
> >
> > 法二:由于 $a_{2}=-3=\frac{S_{3}}{3},\frac{S_{5}}{5}=-2$ ，且 $\left\{\frac{S_{n}}{n}\right\}$ 也为等差数列，且公差 $d'$ 为 $\frac{1}{2},a_{6}=\frac{S_{9}}{9}=\frac{S_{5}}{5}+4d'= -2+2=0$ ，当 $S_{n}$ 的最小值时，一定有 $\left\{\begin{aligned}a_{n}&\leqslant0\\ a_{n+1}&>0\end{aligned}\right.$ ，由于 $a_{5}=0$ ，且 $a_{6}>0$ ，故 $S_{n}$ 的最小值为 $S_{5}=S_{4}=-10$ 故答案为：0，-10.
> >
> > 例 (2019·新课标Ⅲ)记 $S_{n}$ 为等差数列 $\{a_{n}\}$ 的前 $n$ 项和. 若 $a_{1} \neq 0, a_{2} = 3a_{1}$ , 则 $\frac{S_{10}}{S_{5}} =$ \_\_\_\_.
> >
> > 解析 设等差数列 $\langle a_{n}\rangle$ 的公差为 $d$ ，则由 $a_{1} \neq 0, a_{2} = 3a_{1}$ 可得， $\frac{S_{2}}{2} = \frac{4a_{1}}{2} = 2a_{1}, \left\{\frac{S_{n}}{n}\right\}$ 为公差是 $a_{1}$ 的等差数列，所以 $\frac{\frac{S_{10}}{10}}{\frac{S_{5}}{5}} = \frac{S_{1} + 9a_{1}}{S_{1} + 4a_{1}} = \frac{10a_{1}}{5a_{1}} = 2$ ，故 $\frac{S_{10}}{S_{5}} == 4$ ，故答案为：4.
> >
> > 例 S (2013·新课标 I) 设等差数列 $\{a_{n}\}$ 的前 n 项和为 $S_{n}$ ，若 $S_{m-1} = -2, S_{m} = 0, S_{m+1} = 3$ ，则 m = （）
> > A. 3
> > B. 4
> > C. 5
> > D. 6
> >
> > 易知 $\left\{\frac{S_n}{n}\right\}$ 为等差数列，则 $\frac{2S_m}{m} = \frac{S_{m - 1}}{m - 1} +\frac{S_{m + 1}}{m + 1}\Rightarrow 0 = \frac{-2}{m - 1} +\frac{3}{m + 1},m = 5$ ，
> >
> > 故选 **C**.
