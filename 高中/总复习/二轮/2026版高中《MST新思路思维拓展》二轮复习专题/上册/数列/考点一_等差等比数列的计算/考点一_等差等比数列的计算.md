## 考点一_等差等比数列的计算

## 一、等差数列性质

1. $a_{n} = a_{1} + (n - 1)d$ 中的知三求一.

(1)关于等差中项:如果 a, A, b 成等差数列,则 $A=\frac{a+b}{2}$ .

(2) $S_{n}=\frac{n(a_{1}+a_{n})}{2}$ ，用此公式要求 $S_{n}$ 必须具备三个条件： $n,a_{1},a_{n}$

(3) $S_{n}=na_{1}+\frac{n(n-1)d}{2}$ ，此公式要求 $S_{n}$ 必须具备三个条件： $n,a_{1},d$ （有时比较有用）.

总之:两个公式都表明要求 $S_{n}$ 必须已知 $n, a_{1}, d, a_{n}$ 中三个.

2. $a_{n}$ 与 $S_{n}$ 之间一步转换

$$
a _ {m _ {1}} + a _ {m _ {2}} + a _ {m _ {3}} + \dots + a _ {m _ {n}} = n a \frac {m _ {1} + m _ {2} + m _ {3} + \cdots + m _ {n}}{n}
$$

例： $a_2 + a_6 + a_7 = 3a_5;3a_8 - a_{12} = 2a_6.$

公式一： $S_{n}=a_{1}+a_{2}+a_{3}+\cdots\cdots+a_{n}\Rightarrow S_{n}=n\cdot a_{\frac{n+1}{2}}$ （其中 n 为奇数）例： $S_{5}=5a_{3}$

公式二： $a_{n} = \frac{S_{2n - 1}}{2n - 1}$ 例： $a_5 = \frac{S_9}{9};a_8 = \frac{S_{15}}{15}.$

当 $m_{1}$ 、 $m_{2}$ 、 $m_{3}$ 、 $\cdots$ 、 $m_{n}$ 也成等差数列时，均有 $a_{m_{1}} + a_{m_{2}} + a_{m_{3}} + \cdots + a_{m_{n}} = na^{\frac{m_{1} + m_{n}}{2}}$

3. 只有 $S$ 的模型与最值问题

性质1. 等差数列中： $\frac{S_{m+n}}{m+n} = \frac{S_m - S_n}{m-n}$ ，则有 $\frac{S_{2m+m}}{2m+m} = \frac{S_{2m} - S_m}{2m-m}$ 可以求出 $S_{3m}$ ，甚至 $S_{4m}$ .

①若 $S_{m} = S_{n}$ ，则一定有： $S_{m + n} = 0;a\frac{m + n + 1}{2} = 0.$

② $S_{n},S_{2n}-S_{n},S_{3n}-S_{2n}$ 成等差数列，公差为 $n^{2}d$

性质2.等差数列 $\{a_{n}\}$ 中： $\left\{\frac{S_n}{n}\right\}$ 为首项是 $a_1$ ，公差是 $\frac{d}{2}$ 的等差数列，若 $m + n = p + q$ ，则 $\frac{S_m}{m} +\frac{S_n}{n} = \frac{S_p}{p} +\frac{S_q}{q}$ 特别的，若 $m + n = 2p$ ，则有 $\frac{S_m}{m} +\frac{S_n}{n} = \frac{2S_p}{p}$

性质 3. 关于等差数列最值和零点区间问题

$S_{n}$ 有最大值 $\Leftrightarrow \left\{ \begin{array}{l}a_{n} > 0\\ a_{n + 1} <   0 \end{array} \right.;S_{n}$ 有最小值 $\Leftrightarrow \left\{ \begin{array}{l}a_n <   0\\ a_{n + 1} > 0 \end{array} \right.$ ，若 $a_{n} = 0$ ，则有 $S_{n} = S_{n - 1}$ 同时取得最值

$S_{n}>0,n$ 的最大值 $\Leftrightarrow\left\{\begin{aligned}S_{n}>0\\ S_{n+1}<0\end{aligned}\right.$ ; $S_{n}<0,n$ 的最大值 $\Leftrightarrow\left\{\begin{aligned}S_{n}<0\\ S_{n+1}>0\end{aligned}\right.$ .

例 i (2025·新课标Ⅱ总) 记 $S_{n}$ 为等差数列 $\left\{a_{n}\right\}$ 的前 n 项和，若 $S_{2}=6, S_{1}=-5$ ，则 $S_{0}=$ A. -20
B. -15
C. -10
D. -

解析 一；设等差数列 $(a_{0})$ 的公差为 $d$ ，则由题可得 $\left\{ \begin{array}{l} 3a_{1} + 3d = 6 \\ 5a_{1} + 10d = -5 \end{array} \right. \Rightarrow \left\{ \begin{array}{l} d = -3 \\ a_{1} = 5 \end{array} \right.$ ，

所以 $S_{\mathrm{c}} = 6a_{1} + 15d = 6\times 5 + 15\times (-3) = -15.$

解法二：利用 $\left\{\frac{S_n}{n}\right\}$ 为等差数列，则 $\frac{S_0}{6} -\frac{S_5}{5} = \frac{1}{2}\left(\frac{S_6}{5} -\frac{S_9}{3}\right)$ ，所以 $S_{0} = -15.$ 故选：B.

## 二、等比数列性质

1. 关于等比中项：

如果在 a, b 中插入一个数 G，使 a, G, b 成等比数列，则 G 是 a, b 的等比中项.

$\frac{G}{a} = \frac{b}{G}\Rightarrow G^2 = ab\Rightarrow G = \pm \sqrt{ab}$ （注意两解且同号两项才有等比中项）

例:2与8的等比中项为G,则 $G^{2}=16,G=\pm4$

2. 等比数列的有关性质：

①. 与首末两项等距离的两项积等于首末两项的积。与某一项距离相等的两项之积等于这一项的平方.

②. 若 $m+n=p+q$ ，则 $a_{m}a_{n}=a_{p}a_{q}$ .

3. $S_{n}$ 一般公式推导: 设 $S_{n} = a_{1} + a_{2} + a_{3} + \dots + a_{n-1} + a_{n}$ ①

乘以公比 $q, qS_{n} = a_{2} + a_{3} + \dots + a_{n-1} + a_{n} + qa_{n}$ ②

①-②： $(1 - q)S_{n} = a_{1} - qa_{n},q\neq 1$ 时： $S_{n} = \frac{a_{1} - qa_{n}}{1 - q} = \frac{a_{1} - aq^{n}}{1 - q} = \frac{a_{1}(1 - q^{n})}{1 - q}$

$q = 1$ 时： $S_{n} = na_{1}$

注意 (1) $a_1, q, n, S_n$ 和 $a_1, a_n, q, S_n$ 各已知三个可求第四个。

(2)注意求和公式中是 $q^n$ ，通项公式中是 $q^{n-1}$ 不要混淆。

(3)应用求和公式时 $q \neq 1$ ，必要时应讨论 q = 1 的情况.

## 4. 等间隔的等比数列比值

公式 1: $\frac{a_{m_1+k} + a_{m_2+k} + \cdots a_{m_n+k}}{a_{m_1} + a_{m_2} + \cdots a_{m_n}} = q^k$ .

例如：① $\frac{a_{3}+a_{6}+\cdots a_{99}}{a_{2}+a_{5}+\cdots a_{98}}=q$ ② $\frac{a_{3}+a_{6}+\cdots a_{99}}{a_{1}+a_{4}+\cdots a_{97}}=q^{2}$ ③ $\frac{a_{7}+a_{8}+a_{9}}{a_{4}+a_{5}+a_{6}}=q^{3}$ ④ $\frac{a_{7}+a_{8}+a_{9}}{a_{1}+a_{2}+a_{3}}=q^{6}$

强调:一定要项数相等,才能用此定理。

推论:在等比数列 $\{a_{n}\}$ 中,当项数n=2k时, $S_{偶}=qS_{奇}$ .

公式 2: $S_{m+n}=S_m+q^mS_n=S_n+q^nS_m$ .

例如：① $S_{10}=S_{5}+q^{5}S_{5}$ ；② $S_{16}=S_{5}+q^{5}S_{10}=S_{5}(1+q^{5}+q^{10})$ ；③ $S_{2m}=S_{m}+q^{m}S_{m}$ ；④ $S_{3m}=S_{m}+q^{m}S_{2m}=S_{m}(1+q^{m}+q^{2m})$ （重点）.
