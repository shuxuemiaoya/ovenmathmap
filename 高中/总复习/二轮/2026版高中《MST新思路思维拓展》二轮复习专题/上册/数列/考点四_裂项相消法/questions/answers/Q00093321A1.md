> [!faq]- 例题解析
>
> > [!success]- **【答案】** D
>
> > [!note]- **【解析】**
> > 解析 由 $a_{1} = 3, a_{n+1} - a_{n} = 2$ ，得数列 $\{a_{n}\}$ 是首项为 3，公差为 2 的等差数列，则 $a_{n} = 2n + 1$ ，
> >
> > 于是 $b_{n} = \frac{1}{4}\times (-1)^{n + 1}\times \left(\frac{1}{2n + 1} +\frac{1}{2n + 3}\right)$ ，当 $n$ 为偶数时， $T_{n} = \frac{1}{4}\left[\left(\frac{1}{3} +\frac{1}{5}\right) - \left(\frac{1}{5} +\frac{1}{7}\right) + \left(\frac{1}{7} +\frac{1}{9}\right) - \right.$ $\left(\frac{1}{9} +\frac{1}{11}\right) + \dots +\left(\frac{1}{2n - 1} +\frac{1}{2n + 1}\right) - \left(\frac{1}{2n + 1} +\frac{1}{2n + 3}\right)\Big] = \frac{1}{4}\left(\frac{1}{3} -\frac{1}{2n + 3}\right),$
> >
> > 当 $n$ 为奇数时， $T_{n} = T_{n + 1} - b_{n + 1} = \frac{1}{4}\left(\frac{1}{3} -\frac{1}{2n + 5}\right) + \frac{1}{4}\left(\frac{1}{2n + 3} +\frac{1}{2n + 5}\right) = \frac{1}{4}\left(\frac{1}{3} +\frac{1}{2n + 3}\right),$
> >
> > 当 $n$ 为偶数时， $T_{n} = \frac{1}{4}\left(\frac{1}{3} - \frac{1}{2n + 3}\right) < \frac{1}{12}$ ；当 $n$ 为奇数时， $T_{n} = \frac{1}{4}\left(\frac{1}{3} + \frac{1}{2n + 3}\right) \leqslant T_{1} = \frac{2}{15}$ ，因此 $(T_{n})_{\max} = \frac{2}{15}$ ，由不等式 $3T_{n} < \lambda (3 - 5\lambda)(n \in \mathbb{N}^{*})$ 恒成立，得 $\frac{5}{3}\lambda^{2}$ ，即 $\lambda^{2} - \frac{3}{5}\lambda + \frac{2}{25} < 0$ ，解得 $\frac{1}{5} < \lambda < \frac{2}{5}$ ，
> >
> > 所以 $\lambda$ 的取值范围为 $\left(\frac{1}{5},\frac{2}{5}\right)$ . 故选: D.

> > 3. 带有等比数列的裂项相消：
> >
> > $$
> > a _ {n} = \frac {q ^ {n}}{(q ^ {n} + m) (q ^ {n + 1} + m)} = \frac {1}{q - 1} \left(\frac {1}{q ^ {n} + m} - \frac {1}{q ^ {n + 1} + m}\right) (\text {其中} m \in \mathbf {R}, q \neq 1)
> > $$
> >
> > $$
> > S _ {n} = \frac {1}{q - 1} \left(\frac {1}{q + m} - \frac {1}{q ^ {2} + m} + \frac {1}{q ^ {2} + m} - \frac {1}{q ^ {3} + m} + \dots + \frac {1}{q ^ {n} + m} - \frac {1}{q ^ {n + 1} + m}\right) = \frac {1}{q - 1} \left(\frac {1}{q + m} - \frac {1}{q ^ {n + 1} + m}\right).
> > $$
> >
> >
> > $\left\{\frac{1}{a_n}\right\}$ 与数列 $(4^{n}a_{n}a_{n + 1})$ 的前 $n$ 项和分别为 $R_{n},T_{n}$ ，则A. $\frac{a_{n + 1}}{a_n} >\frac{1}{4}$ B. $T_{n} <   \frac{1}{3}$ C. $S_{n} <   \frac{43}{39}$ D. $R_{n}\geqslant 6n^{2} - 5n$
> >
> > 解析 图 $9a_{n}a_{n+1}=a_{n}-4a_{n+1}$ 两边同时除以 $a_{n}a_{n+1}$ , 可得 $9=\frac{1}{a_{n+1}}-\frac{4}{a_{n}}$ , 所以 $\frac{1}{a_{n+1}}+3=4\left(\frac{1}{a_{n}}+3\right), \frac{1}{a_{1}}+3=4 \neq 0$ , 故数列 $(\frac{1}{a_{n}}+3)$ 是以 4 为首项, 公比为 4 的等比数列, 所以 $\frac{1}{a_{n}}+3=4^{n}$ , 即 $a_{n}=\frac{1}{4^{n}-3}$ ,
> >
> > 对于 A 中，因为 $a_{n}=\frac{1}{4^{n}-3}>0$ ，可得 $9a_{n}a_{n+1}=a_{n}-4a_{n+1}>0$ ，所以 $4a_{n+1}<a_{n}$ ，即 $\frac{a_{n+1}}{a_{n}}<\frac{1}{4}$ ，所以 A 错误；
> >
> > 对于B中，由 $4^{n}a_{n}a_{n + 1} = \frac{4^{n}}{(4^{n} - 3)(4^{n + 1} - 3)} = \frac{1}{3}\left(\frac{1}{4^n - 3} -\frac{1}{4^{n + 1} - 3}\right)$ ，所以 $T_{n} = \frac{1}{3}\left[\left(1 - \frac{1}{4^{2} - 3}\right) + \left(\frac{1}{4^{2} - 3} -\frac{1}{4^{1} - 3}\right) + \right.$ $\cdots +\left(\frac{1}{4^n - 3} -\frac{1}{4^{n + 1} - 3}\right)] = \frac{1}{3}\left(1 - \frac{1}{4^{n + 1} - 3}\right) <   \frac{1}{3},$ 所以B正确；
> >
> > 对于 C 中，由 $a_{n}=\frac{1}{4^{n}-3}=\frac{1}{4^{n}\left(1-\frac{3}{4^{n}}\right)}\leqslant\frac{1}{4^{n}\left(1-\frac{3}{4^{2}}\right)}=\frac{1}{13\times4^{n-2}}(n\leqslant2)$ ,
> >
> > 可得 $S_{n} \leqslant 1 + \frac{1}{13 \times 4^{0}} + \frac{1}{13 \times 4^{1}} + \cdots + \frac{1}{13 \times 4^{n - 2}} = 1 + \frac{1}{13} \times \frac{1 - \frac{1}{4^{n - 1}}}{1 - \frac{1}{4}} = 1 + \frac{4}{39}\left(1 - \frac{1}{4^{n - 1}}\right) < 1 + \frac{4}{39} = \frac{43}{39}$ , 所以 C 正确;
> >
> > 对于D中，由 $R_{n} = (4^{1} - 3) + (4^{2} - 3) + \dots +(4^{n} - 3) = \frac{4}{3} (4^{n} - 1) - 3n$ ，当 $n = 1$ 时， $R_{n}\geqslant 6n^{2} - 5n$ 显然成立；
> >
> > 当 $n \geqslant 2$ 时， $4^n = (1 + 3)^n \geqslant C_n^0 + 3C_n^1 + 9C_n^2 = \frac{9n^2 - 3n + 2}{2}$ ，所以 $R_n = \frac{4}{3}(4^n - 1) - 3n \geqslant \frac{4}{3} \times \frac{9n^2 - 3n}{2} - 3n = 6n^2 - 5n$ ，所以 D 正确。
> >
> > 故选 **BCD**。
