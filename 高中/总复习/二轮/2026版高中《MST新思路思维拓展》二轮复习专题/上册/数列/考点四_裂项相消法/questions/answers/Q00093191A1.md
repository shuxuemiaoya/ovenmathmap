> [!faq]- 例题解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【解析】**
> > 解析 (1) 已知 $a_1 = 1, \left\{\frac{S_n}{a_n}\right\}$ 是公差为 $\frac{1}{3}$ 的等差数列，所以 $\frac{S_n}{a_n} = 1 + \frac{1}{3} (n - 1) = \frac{1}{3} n + \frac{2}{3}$ ，
> >
> > 即 $S_{n} = \frac{1}{3} na_{n} + \frac{2}{3} a_{n}$ ，①，故当 $n\geqslant 2$ 时， $S_{n - 1} = \frac{1}{3} (n - 1)a_{n - 1} + \frac{2}{3} a_{n - 1},$ ②，
> > - **①**：一②得： $\frac{1}{3} a_{n} = \frac{1}{3} na_{n} - \frac{1}{3} na_{n - 1} - \frac{1}{3} a_{n - 1}$ ，故 $(n - 1)a_{n} = (n + 1)a_{n - 1}$
> >
> > 化简得： $\frac{a_n}{a_{n - 1}} = \frac{n + 1}{n - 1} = \frac{(n + 1)n}{n(n - 1)}$ ，即 $\frac{a_n}{n(n + 1)} = \frac{a_{n - 1}}{n(n - 1)}$ ，故 $\{\frac{a_n}{n(n + 1)}\}$ 为常数数列， $\frac{a_n}{(n + 1)n} = \frac{a_1}{2\times 1},$
> >
> > 所以 $\frac{a_n}{a_1} = \frac{n(n + 1)}{2}$ 故 $a_{n} = \frac{n(n + 1)}{2}$
> >
> > 证明：(2)由于 $a_{n} = \frac{n(n + 1)}{2}$ 所以 $\frac{1}{a_n} = \frac{2}{n(n + 1)} = 2\left(\frac{1}{n} -\frac{1}{n + 1}\right)$
> >
> > $$
> > \left. \frac {1}{a _ {1}} + \frac {1}{a _ {2}} + \dots + \frac {1}{a _ {n}} = 2 \left(1 - \frac {1}{2} + \frac {1}{2} - \frac {1}{3} + \dots + \frac {1}{n} - \frac {1}{n + 1}\right) = 2 \times \left(1 - \frac {1}{n + 1}\right) <   2. \right.
> > $$
> >
> > 2. 特殊等差数列与裂项相消：
> >
> > 若等差数列 $\{a_{n}\}$ 满足： $b_{n} = (-1)^{n - 1}\frac{a_{n} + a_{n + 1}}{a_{n}a_{n + 1}}$ ，则 $b_{n} = (-1)^{n - 1}\left(\frac{1}{a_n} +\frac{1}{a_{n + 1}}\right)$ ，则数列 $\{b_n\}$ 前 $n$ 项和
> >
> > $$
> > S _ {n} = \left(\frac {1}{a _ {1}} + \frac {1}{a _ {2}}\right) - \left(\frac {1}{a _ {2}} + \frac {1}{a _ {3}}\right) + \dots + (- 1) ^ {n - 1} \left(\frac {1}{a _ {n}} + \frac {1}{a _ {n + 1}}\right) = \frac {1}{a _ {1}} + \frac {(- 1) ^ {n - 1}}{a _ {n + 1}}
> > $$
