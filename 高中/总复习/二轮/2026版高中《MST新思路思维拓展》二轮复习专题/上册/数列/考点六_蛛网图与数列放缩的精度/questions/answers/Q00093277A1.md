> [!faq]- 例题解析
>
> > [!success]- **【答案】** A
>
> > [!note]- **【解析】**
> > 由 $a_{n+1} = \frac{a_n}{1 + \sqrt{a_n}}$ ，于是 $a_n - a_{n+1} = a_{n+1} \cdot \sqrt{a_n}, a_{n+1} = \frac{a_n - a_{n+1}}{\sqrt{a_n}} < \frac{a_n - a_{n+1}}{\frac{\sqrt{a_{n+1}} + \sqrt{a_n}}{2}} = 2(\sqrt{a_n} - \sqrt{a_{n+1}})$ $a_{n+1} = \frac{a_n - a_{n+1}}{\sqrt{a_n}} > \frac{a_n - a_{n+1}}{(2 - \sqrt{2})(\sqrt{a_{n+1}} + \sqrt{a_n})} = \frac{2 + \sqrt{2}}{2} (\sqrt{a_n} - \sqrt{a_{n+1}})$ 所以 $S_{100} < 1 + 2(\sqrt{a_1} - \sqrt{a_2} + \sqrt{a_2} - \sqrt{a_3} + \dots +\sqrt{a_{99}} -\sqrt{a_{100}}) = 1 + 2(\sqrt{a_1} -\sqrt{a_{100}}) = 3 - 2\sqrt{\frac{1}{2^{99}}} < 3,$ $S_{100} > 1 + \frac{2 + \sqrt{2}}{2} (\sqrt{a_1} -\sqrt{a_2} +\sqrt{a_2} -\sqrt{a_3} +\dots +\sqrt{a_{99}} -\sqrt{a_{100}}) = 1 + \frac{2 + \sqrt{2}}{2} (\sqrt{a_1} -\sqrt{a_{100}}) = 2 + \frac{\sqrt{2}}{2} -\frac{2 + \sqrt{2}}{2}\sqrt{\frac{1}{2^{99}}}>\frac{5}{2}$ 故选：A.
> >
> > 注意 本题需判断出 $S_{100} < 3 - 2\sqrt{\frac{1}{2^{69}}} < 3$ 即可得出答案, 之所以放缩到 $\frac{5}{2}$ , 甚至到 2.7 都可以, 放缩到二级精度, 通常都是一个比较狭窄的范围.
