> > [!note]- **【解析】**
> > 解析 不动点 $x = x^{2} - 5x + 9$ ，所以有唯一不动点 $x = 3$ ，所以 $\frac{1}{a_{n+1}-3} = \frac{1}{a_n^2 - 5a_n + 6} = \frac{1}{(a_n - 2)(a_n - 3)} = \frac{1}{a_n - 3} - \frac{1}{a_n - 2}$ 即 $\frac{1}{a_n - 2} = \frac{1}{a_n - 3} - \frac{1}{a_{n+1} - 3}$
> >
> > 对于 A, 由蛛网图可知, $a_{n+1}>a_{n}>\cdots>a_{1}=5$ 故 A 正确;
> >
> > 对于 B, $\frac{1}{a_{n+1}} < \frac{1}{a_{n+1}-3} = \frac{1}{(a_n-2)(a_n-3)}$ ，因为 $a_1 = 5, a_2 = 9, a_3 = 45, a_4 = 45^2 - 45 \times 5 + 9 = 1809$ ，所以 $\frac{1}{a_3} < \frac{1}{1806 \cdot 1807}$ ，故 B 正确；
> >
> > 对于C，法一： $a_{n + 1} - \frac{5}{2} = \left(a_n - \frac{5}{2}\right)^2 +\frac{1}{4} >\left(a_n - \frac{5}{2}\right)^2,\ln \left(a_{n + 1} - \frac{5}{2}\right) > \ln \left(a_n - \frac{5}{2}\right)^2 = 2\ln \left(a_n - \frac{5}{2}\right),$
> >
> > 所以 $\frac{\ln\left(a_{n+1}-\frac{2}{2}\right)}{\ln\left(a_{n-1}\right)}>2$ ，累乘可得： $\frac{\ln\left(a_{2025}-\frac{5}{2}\right)}{\ln\left(a_{2024}-\frac{5}{2}\right)}\cdot\frac{\ln\left(a_{2024}-\frac{5}{2}\right)}{\ln\left(a_{2023}-\frac{5}{2}\right)}\cdot\cdots\cdot\frac{\ln\left(a_{2}-\frac{5}{2}\right)}{\ln\left(a_{1}-\frac{5}{2}\right)}=\frac{\ln\left(a_{2025}-\frac{5}{2}\right)}{\ln\left(a_{1}-\frac{5}{2}\right)}=\frac{\ln\left(a_{2025}-\frac{5}{2}\right)}{\ln\frac{5}{2}}>2^{2024},$ 所以 $\ln\left(a_{2025}-\frac{5}{2}\right)>2^{2024}\cdot\ln\frac{5}{2}=\ln\left(\frac{5}{2}\right)^{2^{n_0n_1}}$ ，所以 $a_{2025}>\left(\frac{5}{2}\right)^{2^{n_0n_1}}+\frac{5}{2}>\left(\frac{5}{2}\right)^{2025}+\frac{5}{2},$
> >
> > 法二： $\frac{a_{n+1}-3}{a_{n}-3}>\cdots\frac{a_{3}-3}{a_{2}-3}>\frac{a_{2}-3}{a_{1}-3}=3,a_{2025}-3>(a_{1}-3)\cdot3^{2024}=2\cdot3^{2024},a_{2025}>3+2\cdot3^{2024}$ ，故C错误；
> > 对于 D, $S_{n}=\frac{1}{a_{1}-2}+\frac{1}{a_{2}-2}+\frac{1}{a_{3}-2}+\cdots+\frac{1}{a_{n}-2}$ $=\frac{1}{a_{1}-3}-\frac{1}{a_{2}-3}+\frac{1}{a_{2}-3}-\frac{1}{a_{3}-3}+\frac{1}{a_{3}-3}-\frac{1}{a_{4}-3}+\cdots+\frac{1}{a_{n}-3}-\frac{1}{a_{n+1}-3}$ $=\frac{1}{a_{1}-3}-\frac{1}{a_{n+1}-3}=\frac{1}{2}-\frac{1}{a_{n+1}-3}<\frac{1}{2}$ ，故D正确.
> >
> > 故选 **ABD**.
