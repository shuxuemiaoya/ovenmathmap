> [!faq]- 例题解析
>
> > [!success]- **【答案】** BCD
>
> > [!note]- **【解析】**
> > $$
> > \text {解机} \quad \text {对于} A, \frac {b _ {n + 1} ^ {3}}{b _ {n}} = \frac {2 ^ {2 n + 2} \tan^ {2} \theta_ {n + 1}}{2 ^ {n} \tan \theta_ {n}} = \frac {2 ^ {2 n + 2} \tan^ {2} \theta_ {n + 1}}{\frac {2 ^ {n + 1} \tan \theta_ {n + 1}}{1 - \tan^ {2} \theta_ {n + 1}}} = 2 ^ {n + 1} \tan \theta_ {n + 1} (1 - \tan^ {2} \theta_ {n + 1}) \neq a _ {n + 1}, A \text {错误};
> > $$
> >
> > 【解析】
> > 对于 $B, \frac{1}{a_n} + \frac{1}{b_n} = \frac{1 + \cos\theta_n}{2^n\sin\theta_n} = \frac{2\cos^2\theta_{n+1}}{2^{n+1}\sin\theta_{n+1}\cos\theta_{n+1}} = \frac{2}{2^{n+1}\tan\theta_{n+1}} = \frac{2}{b_{n+1}}, B$ 正确；
> >
> > $$
> > \mathrm{对于} C, \frac {a _ {n + 1} - b _ {n + 1}}{a _ {n} - b _ {n}} = \frac {2 ^ {n + 1} \tan \theta_ {n + 1} - 2 ^ {n + 1} \sin \theta_ {n + 1}}{2 ^ {n} \tan 2 \theta_ {n + 1} - 2 ^ {n} \sin 2 \theta_ {n + 1}} = \frac {\frac {2 \sin \theta_ {n + 1} (1 - \cos \theta_ {n + 1})}{\cos \theta_ {n + 1}}}{\frac {2 \sin \theta_ {n + 1} \cos \theta_ {n + 1} (1 - \cos 2 \theta_ {n + 1})}{\cos 2 \theta_ {n + 1}}}
> > $$
> >
> > $$
> > = \frac {(1 - \cos \theta_ {n + 1}) \cos 2 \theta_ {n + 1}}{\cos^ {2} \theta_ {n + 1} \cdot 2 \sin^ {2} \theta_ {n + 1}} = \frac {2 \cos^ {2} \theta_ {n + 1} - 1}{2 \cos^ {2} \theta_ {n + 1} (\cos \theta_ {n + 1} + 1)}, \frac {1}{4} - \frac {2 \cos^ {2} \theta_ {n + 1} - 1}{2 \cos^ {2} \theta_ {n + 1} (\cos \theta_ {n + 1} + 1)} = \frac {\cos^ {3} \theta_ {n + 1} - 3 \cos^ {2} \theta_ {n + 1} + 2}{4 \cos^ {2} \theta_ {n + 1} (\cos \theta_ {n + 1} + 1)},
> > $$
> >
> > 令 $f(x) = x^{3} - 3x^{2} + 2,0 <   x <   1$ ，求导得 $f^{\prime}(x) = 3x(x - 2) <   0$ ，函数 $f(x)$ 在(0，1)上单调递减，
> >
> > 而 $0 < \cos \theta_{n+1} < 1$ ，则 $f(\cos \theta_{n+1}) > f(1) = 0$ ，因此 $\frac{a_{n+1} - b_{n+1}}{a_n - b_n} < \frac{1}{4}$ ，C 正确；
> >
> > 对于 $D, \theta_{n} = \frac{\theta_{1}}{2^{n-1}}, \frac{b_{n}}{a_{n}} = \frac{2^{n} \tan \theta_{n}}{2^{n} \sin \theta_{n}} = \frac{1}{\cos \theta_{n}}$ ，则 $\frac{b_{1} b_{2} \cdots b_{n}}{a_{1} a_{2} \cdots a_{n}} = \frac{1}{\cos \theta_{1} \cos \theta_{2} \cdots \cos \theta_{n}}$
> >
> > $= \frac{2^{n}\sin\theta_{n}}{2^{n}\cos\theta_{1}\cos\theta_{2}\cdots\cos\theta_{n}\sin\theta_{n}} = \frac{2^{n}\sin\theta_{n}}{\sin 2\theta_{1}} = 2^{n}\sin \frac{\theta_{1}}{2^{n - 1}}$ ，当 $x\in (0,1)$ ， $\sin x <   x$ ，因此 $2^{n}\sin \frac{\theta_{1}}{2^{n - 1}} <  2^{n}\cdot \frac{\theta_1}{2^{n - 1}} = 2\theta_1 = \frac{\pi}{2},$ $\frac{b_1b_2\dots b_n}{a_1a_2\dots a_n} <  \frac{\pi}{2},\mathrm{D}$ 正确.
> >
> > 故选 **BCD**.
