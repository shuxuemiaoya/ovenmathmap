> [!faq]- 例题解析
>
> > [!success]- **【答案】** C
>
> > [!note]- **【解析】**
> > 解析 对于(1)，由题意知： $a_{n}^{2} = b_{n}^{2} + c_{n}^{2}$ ，故 $a_{n + 1}^2 = b_{n + 1}^2 +c_{n + 1}^2 = \frac{2a_{n + 1}^2 + c_n^2 +b_n^2}{3} = \frac{2a_{n + 1}^2 + a_n^2}{3}$ 即 $a_{n + 1}^2 = a_n^2$ ，即 $a_{n + 1} = a_n$ ，所以 $a_{n + 1} = a_n = a_{n - 1} = \dots = a_2 = a_1 = 5$ ，则 $a_{n}^{2} = b_{n}^{2} + c_{n}^{2} = 25$ ，故 $b_{n + 1}^{2} = \frac{a_{n + 1}^{2} + c_{n}^{2}}{3} = \frac{25 + c_{n}^{2}}{3},c_{n + 1}^{2} = \frac{a_{n + 1}^{2} + b_{n}^{2}}{3} = \frac{25 + b_{n}^{2}}{3}$ 由 $S_{n + 1}$ $= \frac{1}{2} b_{n + 1}c_{n + 1}$ 得： $(2S_{n + 1})^2 = \frac{25 + c_n^2}{3}\cdot \frac{25 + b_n^2}{3} = \frac{25^2 + 25(c_n^2 +b_n^2) + c_n^2b_n^2}{9},$ 即 $(2S_{n + 1})^2 = \frac{25^2 + 25^2 + (2S_n)^2}{9}$ ，所以 $S_{n + 1}^{2} = \frac{25^{2}}{18} +\frac{S_{n}^{2}}{9}$ ，则 $S_{n + 1}^{2} - \frac{25^{2}}{16} = \frac{1}{9}\left(S_{n}^{2} - \frac{25^{2}}{16}\right)$ 而 $S_{1}^{2} - \frac{25^{2}}{16} = \frac{1}{4}\times 4^{2}\times 3^{2} - \frac{25^{2}}{16}$ $= -\frac{49}{16}$ ，故 $S_{n}^{2} - \frac{25^{2}}{16} = -\frac{49}{16}\left(\frac{1}{9}\right)^{n - 1}$ 则 $S_{n}^{2} = \frac{25^{2}}{16} -\frac{49}{16}\left(\frac{1}{9}\right)^{n - 1},$ 因为 $S_{n} > 0$ ，故 $S_{n} = \sqrt{\frac{25^{2}}{16} - \frac{49}{16}\left(\frac{1}{9}\right)^{n - 1}}$ ，由于 $\left(\frac{1}{9}\right)^{n - 1}$ 随 $n$ 的增大而减小，故 $S_{n} = \sqrt{\frac{25^{2}}{16} - \frac{49}{16}\left(\frac{1}{9}\right)^{n - 1}}$ 随 $n$ 的增大而增大，即数列 $\langle S_n\rangle$ 是递增数列，故 $\langle S_n\rangle$ 的最小项为 $S_{1}$ ，无最大项，①为假命题；
> > - **对于②**：，又 $b_{n + 1}^2 -c_{n + 1}^2 = \frac{c_n^2 - b_n^2}{3} = -\frac{1}{3}(b_n^2 -c_n^2)$ ，由于 $b_{n + 1}^2 +c_{n + 1}^2 = 25,b_n^2 +c_n^2 = 25$ ，且 $b_1^2 -c_1^2 = 7,$ 所以 $\langle b_n^2 -c_n^2\rangle$ 是首项为7，公比为一 $\frac{1}{3}$ 的等比数列，故 $b_{n}^{2} - c_{n}^{2} = 7\cdot \left(-\frac{1}{3}\right)^{n - 1}$ 所以， $\left\{ \begin{array}{l}b_n^2 -c_n^2 = 7\cdot \left(-\frac{1}{3}\right)^{n - 1}\\ b_n^2 +c_n^2 = 25 \end{array} \right.$ 因为 $b_{n} > 0,c_{n} > 0$ ，故 $b_{n} = \sqrt{\frac{25}{2} + \frac{7}{2}\cdot\left(-\frac{1}{3}\right)^{n - 1}},c_n = \sqrt{\frac{25}{2} - \frac{7}{2}\cdot\left(-\frac{1}{3}\right)^{n - 1}}$ ，所以 $b_{n} - c_{n} = \sqrt{\frac{25}{2} + \frac{7}{2}\left(-\frac{1}{3}\right)^{n - 1}}-$ $\sqrt{\frac{25}{2}-\frac{7}{2}\left(-\frac{1}{3}\right)^{n - 1}}$ ，所以， $b_{2k - 1} - c_{2k - 1} = \sqrt{\frac{25}{2} + \frac{7}{2}\cdot\left(\frac{1}{9}\right)^{h - 1}} -\sqrt{\frac{25}{2} - \frac{7}{2}\cdot\left(\frac{1}{9}\right)^{k - 1}} >0$ ，其中 $k\in N^\circ ,b_{2k} - c_{2k} =$ $\sqrt{\frac{25}{2}-\frac{7}{2}\cdot\left(\frac{1}{3}\right)^{2k - 1}} -\sqrt{\frac{25}{2} + \frac{7}{2}\cdot\left(\frac{1}{3}\right)^{2k - 1}} <   0$ ，其中 $k\in N^\circ$ ，因为数列 $\left\{\frac{25}{2} +\frac{7}{2}\cdot \left(\frac{1}{9}\right)^{k - 1}\right\}(k\in N^\circ)$ 随着 $k$ 的增大而减小，数列 $\left\{\frac{25}{2}-\frac{7}{2}\cdot \left(\frac{1}{9}\right)^{k - 1}\right\}(k\in N^\circ)$ 随着 $k$ 的增大而减小, 故 $b_{1} - c_{1}$ 为数列 $\{b_{n} - c_{n}\}$ 中所有正项中最大的, 同理可知数列 $(b_{2h} - c_{2h})(k \in \mathbf{N}^{\circ})$ 随着 $k$ 的增大而增大, 故 $b_{2} - c_{2}$ 为数列 $\{b_{n} - c_{n}\}$ 中所有负项中最小的, 综上所述, 数列 $\{b_{n} - c_{n}\}$ 的最大项为 $b_{1} - c_{1}$ , 最小项为 $b_{2} - c_{2}$ , ②为真命题.
> >
> > 故选 **C**.
