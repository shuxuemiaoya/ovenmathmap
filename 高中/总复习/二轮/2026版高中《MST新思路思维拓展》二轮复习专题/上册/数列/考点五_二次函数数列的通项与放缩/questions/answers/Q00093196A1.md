> [!faq]- 例题解析
>
> > [!success]- **【答案】** D
>
> > [!note]- **【解析】**
> > 解析 函数 $f(x) = ax^2 + bx + c (a > 0)$ 有两个零点 1, 2，所以 $\begin{cases} a + b + c = 0 \\ 4a + 2b + c = 0 \end{cases}$ ，解得 $\begin{cases} c = 2a \\ b = -3a \end{cases}$ ，所以 $f(x) = ax^2 - 3ax + 2a$ ，则 $f(x) = 2ax - 3a$ . 则 $x_{n+1} = x_n - \frac{a(x_n^2 - 3x_n + 2)}{a(2x_n - 3)}$
> >
> >
> > $$
> > = \frac {x _ {n} (2 x _ {n} - 3) - (x _ {n} ^ {2} - 3 x _ {n} + 2)}{2 x _ {n} - 3} = \frac {2 x _ {n} ^ {2} - 3 x _ {n} - x _ {n} ^ {3} + 3 x _ {n} - 2}{2 x _ {n} - 3} = \frac {x _ {n} ^ {2} - 2}{2 x _ {n} - 3}, a _ {n + 1} = \ln \frac {x _ {n + 1} - 2}{x _ {n + 1} - 1} = \ln \frac {\frac {x _ {n} ^ {2} - 2}{2 x _ {n} - 3} - 2}{\frac {x _ {n} ^ {2} - 2}{2 x _ {n} - 3} - 1}
> > $$
> >
> > $= \ln \frac{x_n^2 - 2 - 2(2x_n - 3)}{x_n^2 - 2 - (2x_n - 3)} = \ln \frac{x_n^2 - 4x_n + 4}{x_n^2 - 2x_n + 1} = \ln \frac{(x_n - 2)^2}{(x_n - 1)^2} = 2\ln \frac{x_n - 2}{x_n - 1} = 2a_n$ ，且 $a_1 = 2$ ，所以数列 $(a_{n})$ 是以2为首项，以2为公比的等比数列，则 $a_{n} = 2\cdot 2^{n - 1} = 2^{n}$ ，所以 $S_{n} = 2^{n + 1} - 2,S_{2025} + 2 = 2^{2020}$ .
> >
> > 故选 **D**.
