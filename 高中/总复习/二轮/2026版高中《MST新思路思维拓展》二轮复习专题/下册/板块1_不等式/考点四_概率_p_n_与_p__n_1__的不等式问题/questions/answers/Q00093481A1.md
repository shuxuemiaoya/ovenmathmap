> > [!note]- **【解析】**
> > 解析 (1)3球后甲比乙至少多两分,只能是甲3分乙0分,因此 $p_{3}=p^{3}$ ;
> >
> > 4球后甲比乙至少多两分，可能是甲4分乙0分，或者甲3分乙1分，因此 $p_4 = C_4^3 p^3 q + p^4 = 4p^3 q + p^4 = 4p^3$ $(1 - p) + p^4 = 4p^3 -3p^4;$
> >
> > (2)根据对称性,以及(1)的结果,可得 $q_{3}=q^{3}$ , $q_{4}=4p^{3}-3p^{4}$ .因此 $\frac{p_{3}-p_{4}}{q_{4}-q_{3}}=\frac{4}{4}p^{3}-3\frac{p^{4}-p^{3}}{q^{4}-q^{3}}=\frac{3p^{3}(1-p)}{3q^{3}(1-q)}=\frac{p^{3}q}{q^{3}p}=\frac{p^{2}}{q^{2}}=4$ ,因此 $\frac{p}{q}=2$ ,又 $p+q=1$ ,故 $p=\frac{2}{3},q=\frac{1}{3}$ ;
> >
> > 本题我们通过枚举:分析 $p_{2} \rightarrow p_{4}$ ，在满足甲前2局获胜基础上，必须要获得3分才能获胜，所以后2局至少要胜1局，即 $p_{2}[C_{2}^{1}p(1-p)+C_{2}^{2}p^{2}]$ ，如果前2局有1局甲输，则会有 $C_{2}^{1}p^{3}(1-p)$ ，加起来就是 $p_{4}=p_{2}(2p-p^{2})+C_{2}^{1}p_{2}(p-p^{2})=4p^{3}-3p^{4}$ ；通过计算验证，是正确的，这种增量和存量的理解就可以继续分析，关于第三问的 $p_{2m} \rightarrow p_{2m+1}$ ，以及 $p_{2m} \rightarrow p_{2m+2}$ ，显然 $p_{2}, p_{3}, p_{4}$ 太小，不足以支撑本题的存量和增量体系的思考方向。
> >
> > 接下来分析 $p_4 \to p_5$ ，易得甲必须得到 4 分才能赢，所以 $p_5 = C_5^1 p^4 (1 - p) + p^5 = 5p^4 - 4p^5$
> >
> > 那么甲前4局得到3分的前提下,最后1局必须赢,共有 $p(p_{4}-p^{4})$ ,甲得到4分的前提下,最后1局则无论输赢,共有 $p^{4}$ ,所以 $p_{5}=p\cdot p_{4}+p^{4}(1-p)=5p^{4}-4p^{5}$ ,推理正确,也可以理解为前4局得4分,则最后1局无论输赢,有 $p_{4}-C_{4}^{3}p^{3}(1-p)$ ,当前4局得了3分,则最后1局必须赢,有 $C_{4}^{3}p^{4}(1-p)$ ,共有 $p_{5}=p_{4}-C_{4}^{3}p^{3}(1-p)^{2}=5p^{4}-4p^{5}$ ,显然后者更适合作为一般化增量推理:
> >
> > $p_{2m}$ 表示赢得 $m + 1$ 局以上， $p_{2m + 1}$ 表示赢得 $m + 2$ 局以上，当 $p_{2m}$ 赢得 $m + 2$ 局以上，则最后1局无论输赢，共有 $p_{2m} - C_{2m}^{m + 1} p^{m + 1}(1 - p)^{m - 1}$ ，当最后1局赢，前 $2m$ 局赢了 $m + 1$ 局，共有 $C_{2m}^{m + 1} p^{m + 2}(1 - p)^{m - 1}$ ，
> >
