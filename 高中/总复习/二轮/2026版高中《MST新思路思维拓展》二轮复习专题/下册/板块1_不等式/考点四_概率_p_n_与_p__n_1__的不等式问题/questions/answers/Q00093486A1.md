> [!faq]- 例题解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【解析】**
> > 解析 (1) 李老师通知 40 人, 甲同学家长未收到李老师通知的概率为 $\frac{20}{60} = \frac{1}{3}$ , 王老师通知 40 人, 甲同学家长未收到王老师通知的概率也为 $\frac{20}{60} = \frac{1}{3}$ , 因为非老师和王老师发通知是独立事件, 所以甲同学家长未收到李老师和王老师通知的概率为 $\frac{1}{3} \times \frac{1}{3} = \frac{1}{9}$ , 所以甲同学家长收到李老师或王老师通知的概率为 $1 - \frac{1}{9} = \frac{8}{9}$ ;
> >
> > (2) $X$ 表示乙同学家长收到通知的次数, $X$ 的可能取值为 $0,1,2,P(X = 0) = \frac{1}{3}\times \frac{1}{3} = \frac{1}{9},$
> >
> > $P(X = 1) = 2 \times \frac{1}{3} \times \frac{2}{3} = \frac{4}{9}, P(X = 2) = \frac{2}{3} \times \frac{2}{3} = \frac{4}{9}$ , 所以分布列为:
> >
> > <table><tr><td>X</td><td>0</td><td>1</td><td>2</td></tr><tr><td>P</td><td> $\frac{1}{9}$ </td><td> $\frac{4}{9}$ </td><td> $\frac{4}{9}$ </td></tr></table>
> >
> > 期望 $E(X)=0\times\frac{1}{9}+1\times\frac{4}{9}+2\times\frac{4}{9}=\frac{4}{3}$ ;
> >
> > (3)Y 表示两次都收到通知的人数，Y 的可能取值为 20, 21, 22, …, 40，设 Y = k，则 $P(Y = k) = \frac{C_{40}^{h} C_{20}^{40 - \delta}}{C_{60}^{40}}$ ,
> >
> > 所以 $\frac{P(Y = k + 1)}{P(Y = k)} = \frac{\frac{C_{40}^{k + 1}C_{20}^{0 - h}}{C_{00}^{10}}}{\frac{C_{40}^{k - 1}C_{20}^{40 - h}}{C_{60}^{10}}} = \frac{(40 - k)(40 - k)}{(k + 1)(k - 19)}$ ，令 $\frac{P(Y = k + 1)}{P(Y = k)} >1$ ，解得 $k <   \frac{1619}{62}\approx 26.11,$
> >
> > 所以 $k \leqslant 26$ 时， $P(Y = k) = \frac{C_{40}^{h} C_{20}^{10 - k}}{C_{60}^{10}}$ 单调递增， $k \geqslant 27$ 时， $P(Y = k) = \frac{C_{40}^{h} C_{20}^{10 - k}}{C_{60}^{10}}$ 单调递减，
> >
> > 又 $\frac{P(Y = 27)}{P(Y = 26)} = \frac{(40 - 26)^2}{(26 + 1)(26 - 19)} = \frac{196}{189} > 1$ ，则 $P(Y = 27) > P(Y = 26)$ ，所以 $k = 27$ 时概率最大，
> >
> > 则 $Y$ 取到27的可能性最大。
