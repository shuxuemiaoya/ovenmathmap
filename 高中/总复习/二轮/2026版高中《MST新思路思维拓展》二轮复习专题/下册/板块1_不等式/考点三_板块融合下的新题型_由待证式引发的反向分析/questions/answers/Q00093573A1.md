> [!faq]- 例题解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【解析】**
> > 解析 (1)(方法一)因为 $\cos 3x = \cos 2x\cos x - \sin 2x\sin x = 2\cos^3 x - \cos x - 2\sin^2 x\cos x = 4\cos^3 x - 3\cos x,$
> >
> > 所以 $f(x)=4x^{3}-3x$ ，则 $f(1)=4-3=1$ 。
> >
> > (方法二)由题意得 $f(x)=a_{3}x^{3}+a_{2}x^{2}+a_{1}x+a_{0}$ ,
> >
> > 令 $x = 0$ ，得 $\cos 0 = a_{n}\cdot \cos^{n}0 + a_{n - 1}\cdot \cos^{n - 1}0 + + a_1\cdot \cos 0 + a_0 = 1,$
> >
> > 即 $a_{n} + a_{n - 1} + + a_{0} = 1$ ，则 $f(1) = a_3 + a_2 + a_1 + a_0 = 1.$
> >
> > (2)证明:①由题可知 $f(x)=a_{2n}x^{2n}+a_{2n-1}x^{2n-1}+\cdots+a_{1}x+a_{0}$
> >
> > $$
> > f \left(\cos x _ {k}\right) = a _ {2 n} \cos^ {2 n} x _ {k} + a _ {2 n - 1} \cos^ {2 n - 1} x _ {k} + \dots + a _ {1} \cos x _ {k} + a _ {0} = \cos (2 n x _ {k}).
> > $$
> >
> > 因为 $x_{k} = \frac{(2k - 1)\pi}{4n}$ 所以 $f(\cos x_k) = \cos (2nx_k) = \cos \left(2n\cdot \frac{2k - 1}{4n}\pi\right) = \cos \left(k\pi -\frac{\pi}{2}\right) = 0,$
> >
> > 所以数列 $\{\cos x_{k}\}$ 中的每一项均为 $f(x)$ 的零点.
> > - **②**：法一：令 $g(x) = \cos x + x - \frac{\pi}{2}\left(0 < x < \frac{\pi}{2}\right)$ ，则 $g'(x) = 1 - \sin x > 0, g(x)$ 在 $\left(0, \frac{\pi}{2}\right)$ 上单调递增，
> >
> > 则 $g(x) < g\left(\frac{\pi}{2}\right) = 0$ ，即 $\cos x < \frac{\pi}{2} - x.$ 因为 $0 < x_{n-1} = \frac{(2n-3)\pi}{4n} < \frac{(2n-1)\pi}{4n} = x_n < \frac{\pi}{2}$ ，
> >
> > 所以 $\left\{ \begin{array}{l} \cos x_{n - 1} <   \frac{\pi}{2} -x_{n - 1},\\ \cos x_n <   \frac{\pi}{2} -x_n, \end{array} \right.$ 则 $\cos x_{n - 1} + \cos x_n <   \pi -(x_{n - 1} + x_n)$ ，则 $\cos \frac{x_{n - 1} + x_n}{2}\cos \frac{x_{n - 1} - x_n}{2} <  \frac{\pi - (x_{n - 1} + x_n)}{2}.$
> >
> > $$
> > x _ {n - 1} - x _ {n} = \frac {(2 n - 3) \pi}{4 n} - \frac {(2 n - 1) \pi}{4 n} = - \frac {\pi}{2 n}, x _ {n - 1} + x _ {n} = \frac {(2 n - 3) \pi}{4 n} + \frac {(2 n - 1) \pi}{4 n} = \frac {(n - 1) \pi}{n},
> > $$
> >
> > 所以 $\cos \frac{x_{n - 1} - x_n}{2} = \cos \left(-\frac{\pi}{4n}\right) = \cos \frac{\pi}{4n} >0$ ，从而 $\cos \frac{x_{n - 1} + x_n}{2} < \frac{\pi - (x_{n - 1} + x_n)}{2\cos\frac{x_{n - 1} - x_n}{2}} = \frac{\pi}{2n\cos\frac{\pi}{4n}}.$
> > - **②**：法二：当 $n \geqslant 2$ 时，要证 $\cos \frac{x_{n-1} + x_n}{2} < \frac{\pi}{2n\cos \frac{\pi}{4n}}$
> >
> > 因为 $x_{k} = \frac{(2k - 1)\pi}{4n}$ 所以 $x_{n} = \frac{(2n - 1)\pi}{4n}, x_{n - 1} = \frac{(2n - 3)\pi}{4n}$ 所以 $x_{n} + x_{n - 1} = \pi -\frac{\pi}{n}, x_{n} - x_{n - 1} = \frac{\pi}{2n},$
> >
> > 所以即证 $\cos \frac{\pi - \frac{\pi}{n}}{2} < \frac{\pi}{2n} \cdot \frac{1}{\cos \frac{\pi}{4n}}$ ，即证 $\sin \frac{\pi}{2n} < \frac{\pi}{2n} \cdot \frac{1}{\cos \frac{\pi}{4n}}$ ；
> >
> > 由 $\left\{\begin{aligned}\sin\frac{\pi}{2n}<\frac{\pi}{2n}\\1&\leqslant\frac{1}{\cos\frac{\pi}{4^{n}}}\end{aligned}\right.$ ，命题得证. $(x>0,\sin x<x$ 自证 $)$
> >
> > 法三：即证： $\cos \frac{x_n + x_{n - 1}}{2} < \frac{\pi}{2n\cos\frac{x_n - x_{n - 1}}{2}}$ ，即 $\cos \frac{x_n + x_{n - 1}}{2}\cdot \cos \frac{x_n - x_{n - 1}}{2} <   \frac{\pi}{2n},$ 由 $\frac{\cos x_n + \cos x_{n - 1}}{2} = \cos \frac{x_n + x_{n - 1}}{2}$ 。 $\cos \frac{x_{\mathrm{a}} - x_{n - 1}}{2}$ ，即证 $\frac{\cos x_n + \cos x_{n - 1}}{2} <  x_n - x_{n - 1} = \frac{\pi}{2} -\frac{x_n + x_{n - 1}}{2}.$
> >
> > 可证 $\cos x < \pi - x$ ，由题 $x \in \left(0, \frac{\pi}{2}\right)$ ，令 $h(x) = x + \cos x - \pi, h'(x) = 1 - \sin x > 0, h(x)$ 单调递增， $h\left(\frac{\pi}{2}\right) = \frac{\pi}{2} - \pi < 0$ ，所以 $h(x) < 0$ ，综上，即 $\cos x < \pi - x$ ，故 $n \geqslant 2, \cos \frac{x_{n-1} + x_n}{2} < \frac{\pi}{2n \cos \frac{\pi}{4n}}$ 得证！
> >
> > 相较于法一, 法二和法三的分析法显得思路更平滑, 此类题常规的证明只能走一步看一步, 考场上几乎不可能完成。
