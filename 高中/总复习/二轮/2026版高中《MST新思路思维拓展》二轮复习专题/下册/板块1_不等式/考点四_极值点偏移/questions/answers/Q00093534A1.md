>
> > [!success]- **【答案】** A
>
> > [!note]- **【解析】**
> > 解析 (1) 因为 $f'(x) = \frac{a}{x} - \frac{1}{x^2} = \frac{ax - 1}{x^2}$ ，因为 $f'\left(\frac{1}{e}\right) = 0$ ，所以 $\frac{a}{e} - 1 = 0$ ，即 $a = e$ .
> >
> > 当 $a = e$ 时， $f'(x) = \frac{ex - 1}{x^2}$ ，所以 $x \in \left(0, \frac{1}{e}\right), f'(x) < 0, x \in \left(\frac{1}{e}, +\infty\right), f'(x) > 0,$
> >
> > 所以满足 $f(x)$ 在 $x=\frac{1}{e}$ 处取得极值。
> >
> > (2) 因为 $e^x \leqslant 1$ , 所以 $e^x - 1 \leqslant 0$ , 所以当 $b \leqslant 2$ 时, $b(e^x - 1) \geqslant 2(e^x - 1)$ 恒成立
> >
> >
> > 要证任意 $x \leqslant 0, b(e^x - 1) \geqslant x(e^x + 1)$ , 即证: $2(e^x - 1) - x(e^x + 1) \geqslant 0$ . 设 $g(x) = 2(e^x - 1) - x(e^x + 1)$ , 因为 $g'(x) = e^x - xe^x - 1$ , 令 $r(x) = e^x - xe^x - 1$ , 则 $x \leqslant 0$ 时, $r'(x) = -xe^x \geqslant 0$ , 所以 $r(x)$ 在 $(- \infty, 0]$ 上单调递增, 即 $r(x) = g'(x) \leqslant g'(0) = 0$ , 所以 $g(x)$ 在 $(- \infty, 0]$ 上单调递减, 所以 $g(x) \geqslant g(0) = 0$ , 即证.
> >
> > (3)法1:由题意 $\ln x_{1}+\frac{c}{x_{1}}=\ln x_{2}+\frac{c}{x_{2}}=0$ ，设 $h(x)=\ln x+\frac{c}{x}$ ，所以 $h'(x)=\frac{x-c}{x^{2}}$ ，
> >
> > 当 $c \leqslant 0$ 时, $h'(x) > 0$ 恒成立, 此时 $h(x)$ 单调递增, 不会存在两个零点, 故 $c > 0$ ,
> >
> > 则当 $x \in (0, c)$ 时， $h'(x) < 0$ ，当 $x \in (c, +\infty)$ 时， $h'(x) > 0$ ，所以 $h(x)$ 在 $(0, c)$ 上单调递减，在 $(c, +\infty)$ 上单调递增，所以 $h(c) = \ln c + 1 < 0$ ，即 $0 < c < \frac{1}{e}$ . 不妨设 $0 < x_1 < c < x_2$ ，则 $0 < \frac{x_1}{c} < 1 < \frac{x_2}{c}$
> >
> > 由(2)得，令 $t = e^{x}, t \in (0,1], 2(t - 1) \geqslant \ln t(t + 1)$ ，所以 $0 < t < 1, \ln t < \frac{2(t - 1)}{t + 1}$ ，
> >
> > 所以 $-\frac{c}{x_1} = \ln x_1 = \ln \frac{x_1}{c} + \ln c < \frac{2\left(\frac{x_1}{c} - 1\right)}{\frac{x_1}{c} + 1} + \ln c$ ，化简得， $(\ln c + 2)x_1 + \frac{c^2}{x_1} + c\ln c - c > 0$ ①：
> >
> > 同理， $(\ln c + 2)x_{2} + \frac{c^{2}}{x_{2}} + c\ln c - c <   0②$ ； $① - ②$ 得 $(\ln c + 2)(x_1 - x_2) > \frac{c^2}{x_2} -\frac{c^2}{x_1} = \frac{c^2(x_1 - x_2)}{x_1x_2},$
> >
> > 因为 $x_{1} - x_{2} < 0$ ，所以 $\ln c + 2 < \frac{c^2}{x_1x_2}$ 所以 $(- \ln x_1)(- \ln x_2) > \ln c + 2$ ，即证 $\ln x_{1} \ln x_{2} - \ln c > 2 > \frac{3}{2}$ .
> >
> > 法2: 同法1得到 $0 < c < \frac{1}{e}$ ，令 $\ln x_{1} = t_{1}, \ln x_{2} = t_{2}$ ，则 $\left\{\begin{aligned} t_{1} e^{t_{1}} + c &= 0 \\ t_{2} e^{t_{2}} + c &= 0 \end{aligned}\right.$ (\*），设 $k(t) = te' + c$ ，则 $k'(t) = (t+1)e^{t}$ ，
> >
> > 当 $t \in (-\infty, -1)$ 时， $k'(t) < 0$ ，当 $t \in (-1, +\infty)$ 时， $k'(t) > 0$ ，所以 $k(t)$ 在 $(- \infty, -1)$ 上单调递减，在 $(-1, +\infty)$ 上单调递增，且 $k(0) = c > 0$ 。不妨设 $t_1 < -1 < t_2 < 0$ 。
> >
> > $(*)$ 式可以化为 $\left\{ \begin{array}{l} e^{t_1} = -\frac{c}{t_1} \\ e^{t_2} = -\frac{c}{t_2} \end{array} \right.$ ，取对数得， $\left\{ \begin{array}{l} t_1 = \ln c - \ln (-t_1) \\ t_2 = \ln c - \ln (-t_2) \end{array} \right.$ ，所以 $\frac{(-t_2) - (-t_1)}{\ln (-t_2) - \ln (-t_1)} = 1.$
> >
> > 由(2)得 $0 < \frac{t_2}{t_1} < 1$ ，则 $\ln \frac{t_2}{t_1} < \frac{2\left(\frac{t_2}{t_1} - 1\right)}{\frac{t_2}{t_1} + 1}$ ，所以 $\ln (-t_2) - \ln (-t_1) < \frac{2(t_2 - t_1)}{t_2 + t_1} = \frac{2[(-t_2) - (-t_1)]}{-t_2 - t_1}$ ，
> >
> > 即 $\frac{(-t_2) - (-t_1)}{\ln(-t_2) - \ln(-t_1)} < \frac{-t_1 - t_2}{2}$ , 所以 $t_1 + t_2 < -2$ , 即 $\ln x_1 + \ln x_2 < -2$ , 所以 $\frac{1}{x_1x_2} > e^2$ .
> >
> > 要证： $\ln x_{1}\ln x_{2} > \ln c + \frac{3}{2}$ 即证： $\frac{c^2}{x_1x_2} >\ln c + \frac{3}{2}.$
> >
> > 因为 $\frac{c^2}{x_1x_2} > e^2 c^2$ ，所以只要证 $e^2 c^2 - \ln c - \frac{3}{2} > 0$ . 设 $I(c) = e^2 c^2 - \ln c - \frac{3}{2}, 0 < c < \frac{1}{e}$ .
> >
> > 因为 $I^{\prime}(c) = 2e^{2}c - \frac{1}{c} = \frac{2e^{2}c^{2} - 1}{c}$ ，令 $I^{\prime}(c) < 0$ ，解得 $0 < c < \frac{1}{\sqrt{2}e}$ ，令 $I^{\prime}(c) > 0$ ，解得 $\frac{1}{\sqrt{2}e} < c < \frac{1}{e}$
> >
> > 所以 $I(c)$ 在 $\left(0, \frac{1}{\sqrt{2}e}\right)$ 上单调递增，在 $\left(\frac{1}{\sqrt{2}e}, \frac{1}{e}\right)$ 上单调递减，所以 $I(c) \geqslant I\left(\frac{1}{\sqrt{2}e}\right) = \frac{1}{2} + \ln \sqrt{2} + 1 - \frac{3}{2} = \ln \sqrt{2} > 0$ ，即
> >
> > 证 $\ln x_{1}\ln x_{2} > \ln c + \frac{3}{2}$
> >
> > 法3: 令 $h(x) = x \ln x + c$ , 因为 $h'(x) = \ln x + 1$ , 当 $x \in \left(0, \frac{1}{e}\right)$ 时, $h'(x) < 0$ , 当 $x \in \left(\frac{1}{e}, +\infty\right)$ 时, $h'(x) > 0$ , 所以 $h(x)$ 在 $\left(0, \frac{1}{e}\right)$ 上单调递减, 在 $\left(\frac{1}{e}, +\infty\right)$ 上单调递增。因为 $h(x)$ 在定义域内有2个零点,
> >
> > 所以 $h\left(\frac{1}{e}\right) = c - \frac{1}{e} < 0$ ，且 $x \to 0, h(x) \to c$ ，所以 $0 < c < \frac{1}{e}$ . 因为 $h(x_1) = h(x_2) = 0$ ，不妨设 $0 < x_1 < \frac{1}{e} < x_2$ .
> >
> > 令 $\varphi(x) = h(x) - h\left(\frac{1}{e^2x}\right), 0 < x < \frac{1}{e},$
> >
> > $$
> > \varphi^ {\prime} (x) = h ^ {\prime} (x) + h ^ {\prime} \left(\frac {1}{e ^ {2} x}\right) \frac {1}{e ^ {2} x ^ {2}} = \ln x + 1 + \left(\ln \frac {1}{e ^ {2} x} + 1\right) \frac {1}{e ^ {2} x ^ {2}} = (\ln x + 1) \left[ 1 - \frac {1}{e ^ {2} x ^ {2}} \right] > 0,
> > $$
> >
> > 所以 $\varphi(x)$ 在 $\left(0, \frac{1}{e}\right)$ 上单调递增. 因为 $0 < x_1 < \frac{1}{e}$ , 所以 $\varphi(x_1) < \varphi\left(\frac{1}{e}\right) = 0$ ,
> >
> > 所以 $h(x_{1}) < h\left(\frac{1}{e^{2}x_{1}}\right)$ ，即 $h(x_{2}) < h\left(\frac{1}{e^{2}x_{1}}\right)$ ，因为 $x_{2} > \frac{1}{e}, \frac{1}{e^{2}x_{1}} > \frac{1}{e}, h(x)$ 在 $\left(\frac{1}{e}, +\infty\right)$ 上单调递增，
> >
> > 所以 $x_{2} < \frac{1}{e^{2}x_{1}}$ ，即 $\frac{1}{x_1x_2} > c^2$ 。因为 $\ln x_{1}\ln x_{2} = \frac{c^{2}}{x_{1}x_{2}} > e^{2}c^{2}$ ，设 $F(c) = e^{2}c^{2} - \ln c, c \in \left(0, \frac{1}{e}\right)$ ，
> >
> > 因为 $F^{\prime}(c) = 2e^{2}c - \frac{1}{c} = \frac{2e^{2}c^{2} - 1}{c} = \frac{(\sqrt{2}ec + 1)(\sqrt{2}ec - 1)}{c}$ ，当 $c \in \left(0, \frac{1}{\sqrt{2}e}\right)$ 时， $F^{\prime}(c) < 0$ ，此时 $F(c)$ 单调递减，当 $c \in \left(\frac{1}{\sqrt{2}e}, \frac{1}{e}\right)$ 时， $F^{\prime}(c) > 0$ ， $F(c)$ 单调递增，所以 $F(c) \geqslant F\left(\frac{1}{\sqrt{2}e}\right) = \frac{1}{2} - \ln \frac{1}{\sqrt{2}e} = \frac{1}{2} + \ln \frac{\sqrt{2}}{2} + 1 > \frac{3}{2}$ ，
> >
> > 所以 $\ln x_{1}\ln x_{2} - \ln c > \frac{3}{2}$
> >
> > 法四：由同构函数， $-c\in \left(-\frac{1}{e},0\right)$ （请自证），故 $x_{1}\ln x_{1} = x_{2}\ln x_{2} = -c,\left\{ \begin{array}{l}\ln x_1 = \frac{-c}{x_1}\\ \ln x_2 = \frac{-c}{x_2} \end{array} \right.\Rightarrow \ln x_1\ln x_2 = \frac{c^2}{x_1x_2}$ ，由对数均值不
> >
> > 等式: $x_{1}x_{2}<\frac{1}{e^{2}}$ , 故 $\ln x_{1}\ln x_{2}>e^{2}c^{2}, \frac{\frac{1}{x_{1}}+\frac{1}{x_{2}}}{2}>\frac{\frac{1}{x_{1}}-\frac{1}{x_{2}}}{\ln\frac{1}{x_{1}}-\ln\frac{1}{x_{2}}}=\frac{1}{c}>\sqrt{\frac{1}{x_{1}x_{2}}}=\frac{\frac{1}{x_{1}}+\frac{1}{x_{2}}}{\ln\frac{1}{x_{1}}+\ln\frac{1}{x_{2}}}, \ln\frac{1}{x_{1}}+\ln\frac{1}{x_{2}}>2, \frac{1}{x_{1}x_{2}}>e^{2}.$
> >
> > 故 $\ln x_{1}x_{2} - \ln c > e^{2}c^{2} - \ln c = t(c),t^{\prime}(c) = 2e^{2}c - \frac{1}{c}$ 单调递增， $c\in \left(0,\frac{1}{e}\right)$ ，令 $t^\prime (c) = 0\Rightarrow c = \frac{\sqrt{2}}{2e}$ 所以 $t(c)_{\min} = t$ $\left(\frac{\sqrt{2}}{2e}\right) = e^2\cdot \frac{2}{e^2\cdot t} -\ln \frac{\sqrt{2}}{2e} = \frac{1}{2} +\ln \sqrt{2} +1 > \frac{3}{2}$ 成立，得证！
