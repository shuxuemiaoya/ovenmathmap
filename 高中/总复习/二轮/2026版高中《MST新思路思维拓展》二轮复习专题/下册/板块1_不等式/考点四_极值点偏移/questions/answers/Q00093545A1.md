> [!faq]- 例题解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【解析】**
> > 解析 (1) 根据题意可得 $f'(x) = \frac{1 - x}{e^x}$ ，令 $f'(x) = 0$ ，得 $x = 1$ ，所以在 $(- \infty, 1)$ 上单调递增，在 $(1, +\infty)$ 上单调递减，所以 $f(x)$ 有极大值 $f(1) = \frac{1}{e}$ ，无极小值.
> >
> > (2)由题意, $k(2x+1)\geqslant f(x)$ 对 $x\in R$ 恒成立,当 $x=-\frac{1}{2}$ 时, $k(2x+1)\geqslant f(x)$ 成立,当 $x<-\frac{1}{2}$ 时,由 $k(2x+1)\geqslant f(x)$ ,得 $k\leqslant\frac{x}{(2x+1)e^{x}}$ ,当 $x>-\frac{1}{2}$ 时,由 $k(2x+1)\geqslant f(x)$ ,得 $k\geqslant\frac{x}{(2x+1)e^{x}}$ ,
> >
> > 设函数 $h(x) = \frac{x}{(2x + 1)e^x}$ ，则 $h'(x) = \frac{(2x + 1) - x(2x + 3)}{(2x + 1)^2e^x} = \frac{(x + 1)(1 - 2x)}{(2x + 1)^2e^x}$ ，当 $x < -1$ 或 $x > \frac{1}{2}$ 时， $h'(x) < 0$ ，当 $-1 < x < \frac{1}{2}$ 且 $x \neq -\frac{1}{2}$ 时， $h'(x) > 0$ ，所以 $h(x)$ 在 $(- \infty, -1)$ ， $\left(\frac{1}{2}, +\infty\right)$ 上单调递减，在 $(-1, -\frac{1}{2})$
> >
> > $\left(-\frac{1}{2}, \frac{1}{2}\right)$ 上单调递增，所以当 $x < -\frac{1}{2}$ 时， $h(x)_{\min} = g(-1) = e$ ，当 $x > \frac{1}{2}$ 时， $h(x)_{\max} = h\left(\frac{1}{2}\right) = \frac{1}{4\sqrt{e}} = \frac{\sqrt{e}}{4e}$ ，所以 $k$ 的取值范围是 $\left[\frac{\sqrt{e}}{4e}, e\right]$ .
> >
> > (3) 法一: 证明: 由(2)知, $e(2x + 1) \geqslant f(x)$ , 故 $(2x + 1)e^{x + 1} \geqslant x (x \in \mathbb{R})$ ,
> >
> > 令 $x = \ln \frac{j + 2}{j + 1} - 1 (j \in \mathbb{N}^*)$ ，得 $\left(2\ln \frac{j + 2}{j + 1} - 1\right)\frac{j + 2}{j + 1} \geqslant \ln \frac{j + 2}{j + 1} - 1$ ，化简整理，得 $\frac{j + 3}{j + 1}\ln \frac{j + 2}{j + 1} \geqslant \frac{1}{j + 1}$ ，故 $(j + 3)\ln \frac{j + 2}{j + 1} \geqslant 1$ ，所以 $(j + 3)\ln (j + 2) - (j + 2)\ln (j + 1) \geqslant 1 + \ln (j + 1)$ ，累加得 $\frac{(i + 1)^{i + 2}}{8} \geqslant i! \cdot e^{i - 1}$ ，所以 $\frac{i!}{(i + 1)^{i + 2}} \leqslant \frac{1}{8e^{i - 1}}$ （当 $i = 1$ 时成立），所以 $\sum_{i=1}^{n} \frac{i!}{(i + 1)^{i + 2}} \leqslant \frac{1}{8}\sum_{i=1}^{n} \frac{1}{e^{i - 1}} = \frac{1}{8} \times \frac{1}{1 - \frac{1}{e}} \left(1 - \frac{1}{e^n}\right) < \frac{1}{8} \times \frac{1}{1 - \frac{1}{e}} = \frac{e}{8(e - 1)} (n \in \mathbb{N}^*)$ 。
> >
> > 法二:和式代换: $\frac{e}{8(e-1)}=\frac{1}{8\left(1-\frac{1}{e}\right)}>\frac{\left(1-\frac{1}{e^{n}}\right)}{8\left(1-\frac{1}{e}\right)}=\sum_{i=1}^{n}\frac{1}{8e^{i-1}}$ ,
> >
> > 可证： $\frac{i!}{(i + 1)^{i + 2}} < \frac{1}{8e^{i - 1}} (n\in \mathbf{N}^{\circ})$ ，即证： $\ln \frac{i!}{(i + 1)^{i + 2}} < \ln \frac{1}{8e^{i - 1}}$ ，即证： $\ln i! - (i + 2)\ln (i + 1) < -3\ln 2 - i + 1$ ，即 $\ln (i+$ $1)! - (i + 3)\ln (i + 2) < -3\ln 2 - i,$ 可证 $\ln (i + 1) <   (i + 3)\ln (i + 2) - (i + 2)\ln (i + 1) - 1,$
> >
> > 即 $(i + 3)\ln \frac{i + 2}{i + 1} >1$ ，由 $\ln \left(1 + \frac{1}{i + 1}\right) = -\ln \left(1 - \frac{1}{i + 2}\right) >\frac{1}{i + 2} >\frac{1}{(i + 3)}$ ，故命题成立，得证！
> >
> > 总结: 常见的类似于法二最后一步的调整, 如调和级数中 $\frac{1}{i} > \ln\left(1 + \frac{1}{i}\right) > \frac{1}{i+1}$ , 类似的调整法在 23 天津卷泰勒展开加强也有出现, 同学们可以多注意!
> >
> > 法三：积式代换 $\frac{i!}{(i + 1)^{i + 2}} < \frac{1}{8e^{i - 1}}$ ，可证明 $\frac{(i + 1)!}{(i + 2)^{i + 3}} < \frac{1}{8e^i}$ ，可证明： $\frac{\frac{(i + 1)!}{(i + 2)^{i + 3}}}{\frac{i!}{(i + 1)^{i + 2}}} < \frac{1}{e}$ 即 $\frac{(i + 2)^{i + 3}}{(i + 1)^{i + 3}} < \frac{1}{e},$
> >
> > 取对即 $\ln \left(1 - \frac{1}{(i + 2)}\right) < \frac{-1}{(i + 3)}$ ，可证 $\ln \left(1 - \frac{1}{(i + 2)}\right) < \frac{-1}{(i + 2)} < \frac{-1}{(i + 3)}$ ，由切线放缩，显然成立，得证！
