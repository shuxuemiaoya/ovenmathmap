> [!faq]- 例题解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【解析】**
> > 解析 证明:(1)函数的定义域为 $(0,+\infty)$ ，要证 $f(x)<0$ ，即证 $x^{2}+x\ln x-ax^{2}e^{x}+ae^{-x}<0$ ，即证 $x+\ln x-axe^{x}+\frac{a}{xe^{x}}<0$ ，即证 $\ln(xe^{x})-axe^{x}+\frac{a}{xe^{x}}<0$ ，令 $t=xe^{x}$ ，由于 $x+\ln x=\ln(xe^{x})>0$ ，则 $t=xe^{x}>1$ ，
> >
> > 即证当 $t > 1$ 时， $\ln t - at + \frac{a}{t} < 0$ ，设 $h(t) = \ln t - at + \frac{a}{t}, t > 1$ ，则 $h'(t) = \frac{1}{t} - a - \frac{a}{t^2} = \frac{-at^2 + t - a}{t^2}$ 又 $a \geqslant \frac{1}{2}$ 则方程一 $at^2 + t - a = 0$ 中 $\triangle = 1 - 4a^2 \leqslant 0$ ，则 $h'(t) \leqslant 0$ 在 $[1, +\infty)$ 上恒成立，所以 $h(t)$ 在 $[1, +\infty)$ 上单调递减，则 $h(t) < \ln 1 - a + \frac{a}{1} = 0$ 即 $\ln (xe^x) - axe^x + \frac{a}{xe^x} < 0$ 即得证；
> >
> > (2)由(1)可知,当 $t > 1, a = \frac{1}{2}$ 时, $\ln t < \frac{1}{2}\left(t - \frac{1}{t}\right), \frac{1}{n + 1} + \frac{1}{n} = \frac{1}{n + 1} - 1 + \frac{n + 1}{n} = \frac{n + 1}{n} - \frac{n}{n + 1} > 2\ln \frac{n + 1}{n}$ ,
> >
> > 所以 $\ln (n + 1) - \ln n < \frac{1}{2}\left(\frac{1}{n} +\frac{1}{n + 1}\right)$ ，则 $\ln (n + 2) - \ln (n + 1) <   \frac{1}{2}\left(\frac{1}{n + 1} +\frac{1}{n + 2}\right),$
> >
> > $$
> > \ln (n + 3) - \ln (n + 2) <   \frac {1}{2} \left(\frac {1}{n + 2} + \frac {1}{n + 3}\right), \dots \dots \ln (2 n) - \ln (2 n - 1) <   \frac {1}{2} \left(\frac {1}{2 n - 1} + \frac {1}{2 n}\right),
> > $$
> >
> > 以上各式相加可得， $\ln (2n) - \ln n < \frac{1}{2}\left(\frac{1}{n} + \frac{2}{n+1} + \frac{2}{n+2} + \cdots + \frac{2}{2n-1} + \frac{1}{2n}\right)$ ，所以 $\frac{1}{n+1} + \frac{1}{n+2} + \cdots + \frac{1}{2n-1} + \frac{1}{2n} + \frac{1}{4n} > \ln 2 > \ln \frac{e}{2}$ ，则 $\frac{1}{n+1} + \frac{1}{n+2} + \cdots + \frac{1}{2n-1} + \frac{3}{4n} > \ln \frac{e}{2}$ 得证。
