> > 例 (2025·辽宁模拟 T19)已知函数 $f(x) = x\ln x - kx + 1 (k \in \mathbb{R})$ .
> >
> > (1) 当 k=1 时, 求 $f(x)$ 的零点;
> >
> > (2) 若 $f(x) \geqslant 0$ 恒成立, 求实数 k 的取值范围;
> >
> > (3) 证明: $\ln \frac{2n+1}{n+1} < \sum_{i=n+1}^{2n} \frac{1}{i} < \ln 2 (n \in \mathbb{N}^*)$ .
> >
> > 解析 (1) 解: 当 $k=1$ 时, $f(x)=x\ln x-x+1$ , 定义域为 $(0,+\infty)$ , $f'(x)=\ln x$ ,
> >
> > 当 $x \in (0,1)$ 时， $f'(x) < 0$ ，当 $x \in (1, +\infty)$ 时， $f'(x) > 0$ ，则 $f(x)$ 在 $(0,1)$ 上单调递减，在 $(1, +\infty)$ 上单调递增，所以 $f(x)_{\min} = f(1) = 0$ ，则 $f(x)$ 的零点为 1.
> >
> > (2) 解: $f(x) \geqslant 0$ 恒成立, 即 $x \ln x - kx + 1 \geqslant 0$ 恒成立, 即 $k \leqslant \ln x + \frac{1}{x}$ 恒成立, 所以 $k \leqslant \left( \ln x + \frac{1}{x} \right)_{\min}$ ,
> >
> > 设 $g(x) = \ln x + \frac{1}{x} (x > 0)$ ，即 $k \leqslant g(x)_{\min}, g'(x) = \frac{1}{x} - \frac{1}{x^2} = \frac{x - 1}{x^2}$ ，
> >
> > 当 0 < x < 1 时， $g'(x) < 0$ ， $g(x)$ 单调递减，当 x > 1 时， $g'(x) > 0$ ， $g(x)$ 单调递增，
> >
> > 所以 $g(x)_{\min}=g(1)=1$ ，即 $k\leqslant1$ ，所以 k 的取值范围是 $(-∞,1]$ .
> >
> > (3)法一:证明:由(2)可知,当k=1时,有 $\ln x\geqslant1-\frac{1}{x}$ 成立,当且仅当x=1时等号成立,
> >
> > 取 $x=\frac{n+1}{n},\frac{n+2}{n+1},\cdots,\frac{2n}{2n-1}$ ，则 $\frac{1}{n+1}<\ln\frac{n+1}{n},\frac{1}{n+2}<\ln\frac{n+2}{n+1},\cdots,\frac{1}{n+n}<\ln\frac{2n}{2n-1}$
> >
> > $$
> > \left. \frac {1}{n + 1} + \frac {1}{n + 2} + \dots + \frac {1}{n + n} <   \ln \frac {n + 1}{n} + \ln \frac {n + 2}{n + 1} + \dots + \ln \frac {n + n}{2 n - 1} = \ln \left(\frac {n + 1}{n} \cdot \frac {n + 2}{n + 1} \cdot \dots \cdot \frac {n + n}{2 n - 1}\right) = \ln \frac {2 n}{n} = \ln 2, \right.
> > $$
> >
> > 即 $\sum_{i=n+1}^{2a}\frac{1}{i}<\ln 2.$ 由 $\ln x\geqslant 1 - \frac{1}{x}\Rightarrow -\ln x\leqslant \frac{1}{x} -1\Rightarrow \ln \frac{1}{x}\leqslant \frac{1}{x} -1$ ，即 $\ln (1 + x)\leqslant x$ ，当且仅当 $x = 0$ 时等号成立，取 $x =$
> >
> > $\frac{1}{n+1},\frac{1}{n+2},\frac{1}{n+3},\cdots,\frac{1}{n+n}$ ，得 $\ln\left(1+\frac{1}{n+1}\right)<\frac{1}{n+1},\ln\left(1+\frac{1}{n+2}\right)<\frac{1}{n+2},\cdots,\ln\left(1+\frac{1}{n+n}\right)<\frac{1}{n+n}$
> >
> > 所以 $\ln \left(1 + \frac{1}{n + 1}\right) + \ln \left(1 + \frac{1}{n + 2}\right) + \dots +\ln \left(1 + \frac{1}{n + n}\right) <   \frac{1}{n + 1} +\frac{1}{n + 2} +\dots +\frac{1}{n + n},$ 即 $\ln \frac{2n + 1}{n + 1} <  \sum_{i = n + 1}^{2n}\frac{1}{i}.$
> >
> > 综上， $\ln \frac{2n + 1}{n + 1} <  \sum_{(= n + )}^{2n}\frac{1}{i} <  \ln 2.$
> >
> > 法二：要证： $\ln \frac{2n + 1}{n + 1} < \sum_{i = n + 1}^{2n}\frac{1}{i}$ 即证 $\sum_{i = n + 1}^{2n}\ln \frac{i + 1}{i} = \ln \frac{n + 2}{n + 1} +\ln \frac{n + 3}{n + 2} +\dots +\ln \frac{2n + 1}{2n} <  \sum_{i = n + 1}^{2n}\frac{1}{i}$ ，可证明 $\ln \frac{i + 1}{i} <  \frac{1}{i},$
> >
> > 由切线放缩,显然成立,得证!
