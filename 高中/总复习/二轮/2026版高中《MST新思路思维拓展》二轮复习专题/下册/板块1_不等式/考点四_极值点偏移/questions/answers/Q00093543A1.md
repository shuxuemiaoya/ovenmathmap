> [!faq]- 例题解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【解析】**
> > 解析 (1) 证明: 要证 $f_{1}(x) \geqslant 2 - \frac{2}{x}$ , 即证 $\ln x + \frac{1}{x} - 1 \geqslant 0$ . 设 $g(x) = \ln x + \frac{1}{x} - 1$ ,
> >
> > 对 $g(x)$ 求导得 $g'(x) = \frac{x - 1}{x^2}$ ，当 $0 < x < 1, g'(x) < 0, g(x)$ 递减；当 $x > 1, g'(x) > 0, g(x)$ 递增.
> >
> > 所以 $g(x)$ 在 $x = 1$ 取最小值， $g(1) = \ln 1 + \frac{1}{1} - 1 = 0$ ，即 $g(x) \geqslant 0$ ，原不等式得证.
> >
> > (2) 证明: 要证 $\sum_{i=1}^{n} \frac{1}{a_i} \leqslant 2\sqrt{n}-1$ , 由 (1) 知 $a_1 = 1$ , 可证明 $\sum_{i=2}^{n} \frac{1}{a_i} \leqslant 2\sqrt{n}-2 = \sum_{i=2}^{n} 2(\sqrt{n}-\sqrt{n-1})$ ,
> >
> > 当 $n \geqslant 2$ ，可证明： $\frac{1}{a_n} < \frac{1}{\sqrt{n}} < \frac{2}{\sqrt{n} + \sqrt{n-1}} = 2(\sqrt{n} - \sqrt{n-1})$ 。即证 $a_n > \sqrt{n}$ ， $f_n(x) = \ln x - \frac{n}{x} + 1$ 单调递增，即证： $f_n(\sqrt{n}) = \ln \sqrt{n} - \sqrt{n} + 1 < 0$ ，由切线放缩显然成立，得证！
> >
> > 再证 $\sum_{i=1}^{n} \frac{1}{a_i} > 2\ln \frac{n+2}{2}$ , 可证: $\sum_{i=1}^{n} \frac{1}{a_i} > \sum_{i=1}^{n} 2\ln \frac{n+2}{n+1}$ , 可证明: $\frac{1}{a_n} > 2\ln \frac{n+2}{n+1}$ , 即可证 $a_n < \frac{n+1}{2} < \frac{1}{2\ln \frac{n+2}{n+1}}$ ,
> >
> > 即 $f_{n}\left(\frac{n + 1}{2}\right) = \ln \frac{n + 1}{2} -\frac{n}{\frac{n + 1}{2}} +1 = \frac{2}{n + 1} -1 - \ln \frac{2}{n + 1} >0$ ，由切线放缩显然成立，得证！
> >
> > 综上， $2\ln \frac{n + 2}{2} < \sum_{i = 1}^{n}\frac{1}{a_i}\leqslant 2\sqrt{n} -1.$
> >
> > (3) $f_{n}^{\prime}(x)=\frac{1}{x}+\frac{n}{x^{2}}$ ，在x>0时大于0，函数递增. $f_{n}(1)=1-n\leqslant0$
> >
> > 因为 $a_{n}\ln a_{n} + a_{n} < a_{n + 1}\ln a_{n + 1} + a_{n + 1}$ ，即 $h(a_{n}) < h(a_{n + 1})$ ，所以 $a_{n} < a_{n + 1}$ ，设公比 $q$
> >
> > $q = \frac{a_{n + 1}}{a_n} = \frac{\ln a_n + 1}{(\ln a_{n + 1} + 1)}\cdot \frac{n + 1}{n} < \frac{n + 1}{n}$ 所以 $a_{n} < a_{n + 1} < a_{n + 2}$ .假设 $a_{n},a_{n + 1},a_{n + 2}$ 成等比，公比 $q > 1$ 且 $a_{n}a_{n + 2} = a_{n + 1}^{2}$ 所以 $\ln a_n + \ln a_{n + 2} = 2\ln a_{n + 1}$ ，可得 $\ln (a_na_{n + 2}) = \ln (a_{n + 1}^2)$ ，那么 $a_{n}a_{n + 2} = a_{n + 1}^{2}$
> >
> > 又因为 $\ln a_{n} = \frac{n}{a_{n}} - 1, \ln a_{n + 1} = \frac{n + 1}{a_{n + 1}} - 1, \ln a_{n + 2} = \frac{n + 2}{a_{n + 2}} - 1$ ，所以 $\frac{n}{a_n} - 1 + \frac{n + 2}{a_{n + 2}} - 1 = 2\left(\frac{n + 1}{a_{n + 1}} - 1\right)$ ，
> >
> > 即 $\frac{n}{a_n} + \frac{n+2}{a_{n+2}} = \frac{2(n+1)}{a_{n+1}}$ ，即 $n \cdot a_n q^2 + (n+2) a_n = 2(n+1) a_n q$ ，故 $n q^2 - 2(n+1) q + n + 2 = 0$ ，解得 $q = \frac{n+2}{n}$ ，与 $q < \frac{n+1}{n}$ 矛盾。故数列 $\{a_n\}$ 中不存在连续三项按某顺序构成等比数列。
