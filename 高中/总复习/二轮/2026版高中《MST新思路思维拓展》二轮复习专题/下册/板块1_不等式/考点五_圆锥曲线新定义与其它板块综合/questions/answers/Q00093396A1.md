> [!faq]- 例题解析
>
> > [!success]- **【答案】** BC
>
> > [!note]- **【解析】**
> > 解析 由进口曲线知, 当 $\beta < \alpha$ 时, 平面截这个圆锥所得截面为双曲线, A 错.
> >
> > 对于 B, 过 N 作 $NG \perp PC_{1}$ 于点 G, 而 $\angle C_{1}A_{1}N = \alpha + \beta, |NA_{1}| = a$ , 所以 $|NG| = a\sin(\alpha + \beta)$ , 而 $\angle C_{1}NG = \alpha$ , 所以 $|C_{1}N| = \frac{a\sin(\alpha + \beta)}{\cos\alpha}$ , 同理过 N 向 $PC_{2}$ 作垂线, 可得 $|C_{2}N| = \frac{a\sin(\beta - \alpha)}{\cos\alpha}$ ,
> >
> > 所以 $|NC_{1}| \cdot |NC_{2}| = \frac{a^{2}\sin(\beta + \alpha)\sin(\beta - \alpha)}{\cos^{2}\alpha}$ , B 正确;
> >
> > 对于 C, D，设圆锥上部球 $O_{1}$ 与椭圆截面圆锥侧面均相切，轴截面的内切圆 $O_{1}$ ，半径为 r，球 $O_{1}$ 与 $A_{1}A_{2}$ 的切点为椭圆左焦点 F，设 $\angle O_{1}A_{2}F = \theta, \angle O_{1}A_{1}F = \varphi$ ，所以 $\theta = \frac{\beta - \alpha}{2}①$ ，
> >
> > $\varphi = \frac{\pi - (\alpha + \beta)}{2}, |A_1F| = a - c = \frac{r}{\tan \varphi}, |A_2F| = a + c = \frac{r}{\tan \theta}$ , 所以 $\frac{a + c}{a - c} = \frac{\tan \varphi}{\tan \theta} = \frac{1 + e}{1 - e}$ ,
> >
> > 解得 $e = \frac{\tan\varphi - \tan\theta}{\tan\varphi + \tan\theta} = \frac{\sin(\varphi - \theta)}{\sin(\varphi + \theta)}$ ，而 $\left\{ \begin{array}{l} \varphi - \theta = \frac{\pi}{2} - \beta \\ \varphi + \theta = \frac{\pi}{2} - a \end{array} \right.$ ，故 $e = \frac{\sin\left(\frac{\pi}{2} - \beta\right)}{\sin\left(\frac{\pi}{2} - \alpha\right)} = \frac{\cos\beta}{\cos\alpha}$ ，故 C 正确，D 错误，
> >
> > 故选 **BC**.
