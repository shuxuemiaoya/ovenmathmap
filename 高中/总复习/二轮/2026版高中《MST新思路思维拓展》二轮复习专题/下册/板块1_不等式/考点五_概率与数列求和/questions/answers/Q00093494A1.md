> [!faq]- 例题解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【分析】**
> > $a_3 = -2$ 概率为 $C_2^0\left(\frac{1}{2}\right)^2, a_3 = 2$ 概率为 $C_2^2\left(\frac{1}{2}\right)^2$ ，所以 $X = 2m (m = \pm 1,0)$ 概率为 $\left(\frac{1}{2}\right)^2 C_2^{1 + m}$
>
> > [!note]- **【解析】**
> > $a_{5} = -4$ 概率为 $C_4^0\left(\frac{1}{2}\right)^4, a_5 = -2$ 概率为 $C_4^1\left(\frac{1}{2}\right)^4, a_5 = 0$ 概率为 $C_4^2\left(\frac{1}{2}\right)^4, a_5 = 2$ 概率为 $C_4^3\left(\frac{1}{2}\right)^4, a_5 = 4$ 概率为 $C_4^4\left(\frac{1}{2}\right)^4$ , 所以 $X = 2m (m = \pm 1, 0, \pm 2)$ 概率为 $\left(\frac{1}{2}\right)^4 C_4^{2+m}$ ;
> > (2)(1)对任意正整数 n，取 1 或 -1 的概率均为 $\frac{1}{2}$ ， $a_{2n+1}=X$ ，故 $X=2m(m=0,\pm1,\pm2,\cdots\pm n)$ ，当 m=0 时，则出现 n 个 -1 和 n 个 1， $P=\left(\frac{1}{2}\right)^{2n}C_{2n}^{n}$ ，当 m=-1 时，则出现 $n+1$ 个 -1 和 n-1 个 1， $P=\left(\frac{1}{2}\right)^{2n}C_{2n}^{n-1}$ ，当 m=-2 时，则出现 $n+2$ 个 -1 和 n-2 个 1， $P=\left(\frac{1}{2}\right)^{2n}C_{2n}^{n-2}$ ，所以 $X=2m(m=0,\pm1,\pm2,\cdots\pm n)$ 时，X 的概率分布可表示为 $P(X=2m)=\frac{C_{2n}^{n+m}}{2^{2n}}(m=0,\pm1,\cdots,\pm n)$ .
> > (Ⅱ)对任意 $1 \leqslant i \leqslant n$ ，利用对称性，易知 $P(X = -2m) = P(X = 2m)$ . 从而 $P(|X| = 2m) = \frac{C_{2n}^{n+m}}{2^{2n-1}} (m = 1, 2, \cdots, n)$ .
> > $$
> > E (| X |) = \sum_ {m = 1} ^ {n} 2 m \frac {C _ {2 n} ^ {n + m}}{2 ^ {2 n - 1}} = \frac {1}{2 ^ {2 n - 2}} \sum_ {m = 1} ^ {n} m C _ {2 n} ^ {n + m} = \frac {1}{2 ^ {2 n - 2}} \sum_ {m = 1} ^ {n} [ (n + m) C _ {2 n} ^ {n + m} - n C _ {2 n} ^ {n + m} ] = \frac {1}{2 ^ {2 n - 2}} \sum_ {m = 1} ^ {n} (2 n C _ {2 n - 1} ^ {n + m - 1} - n C _ {2 n} ^ {n + m})
> > $$
> > 涉及组合恒等式,第一个就是小丑鱼恒等式: $(n+m)C_{2n}^{n+m}=2nC_{2n-1}^{m+n-1}$ ，所以
> > 原式 $\frac{1}{2^{2n - 2}} (2n\sum_{m = 1}^{n}C_{2n - 1}^{n + m - 1} - n\sum_{m = 1}^{n}C_{2n}^{n + m}) = \frac{1}{2^{2n - 2}} [2n(C_{2n - 1}^{n} + \dots +C_{2n - 1}^{2n - 1}) - n(C_{2n}^{n + 1} + C_{2n}^{n + 2} + \dots +C_{2n}^{2n})]$
> > $$
> > = \frac {1}{2 ^ {2 n - 2}} \left[ 2 n \times \frac {1}{2} \times 2 ^ {2 n - 1} - \frac {1}{2} (2 ^ {2 n} - C _ {2 n} ^ {n}) n \right] = \frac {n C _ {2 n} ^ {n}}{2 ^ {2 n - 1}}.
> > $$
> > $$
> > \begin{array}{r l} & {\text {注意}} \\ & {\text {由于} C _ {2 n - 1} ^ {0} + \dots + C _ {2 n - 1} ^ {n - 1} + C _ {2 n - 1} ^ {n} + \dots + C _ {2 n - 1} ^ {2 n - 1} = 2 ^ {2 n - 1}, \text {且} C _ {2 n - 1} ^ {0} + \dots + C _ {2 n - 1} ^ {n - 1} = C _ {2 n - 1} ^ {n} + \dots + C _ {2 n - 1} ^ {2 n - 1},} \\ & {\text {所以} C _ {2 n - 1} ^ {n} + \dots + C _ {2 n - 1} ^ {2 n - 1} = 2 ^ {2 n - 2};} \\ & {C _ {2 n} ^ {0} + \dots + \frac {1}{2} C _ {2 n} ^ {n} + \frac {1}{2} C _ {2 n} ^ {n} + C _ {2 n} ^ {n + 1} + \dots + C _ {2 n} ^ {2 n} = 2 ^ {2 n}, \text {且} C _ {2 n} ^ {0} + \dots + \frac {1}{2} C _ {2 n} ^ {n} = \frac {1}{2} C _ {2 n} ^ {n} + C _ {2 n} ^ {n + 1} + \dots + C _ {2 n} ^ {2 n},} \\ & {\text {所以} C _ {2 n} ^ {n + 1} + \dots + C _ {2 n} ^ {2 n} = 2 ^ {2 n - 1} - \frac {1}{2} C _ {2 n} ^ {n}.} \end{array}
> > $$
