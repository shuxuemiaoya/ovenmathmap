> [!faq]- 例题解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【解析】**
> > 解析 (1) $f'(x)=\frac{1}{x}-m=\frac{1-mx}{x}, x>0$ ，当 $0<x<\frac{1}{m}$ 时， $f'(x)>0, f(x)$ 单调递增，当 $x>\frac{1}{m}$ 时， $f'(x)<0, f(x)$ 单调递减，所以 $f(x)$ 的单调递增区间为 $\left(0,\frac{1}{m}\right)$ ，单调递减区间减区间为 $\left(\frac{1}{m},+\infty\right)$
> >
> > (2) $g(x)=2f(x)+x^{2}=2\ln x-2mx+x^{2}$ ，则 $g'(x)=\frac{2(x^{2}-mx+1)}{x}$
> >
> > 所以 $g'(x)$ 的两根 $x_{1}, x_{2}$ 即为方程 $x^{2}-mx+1=0$ 的两根.
> >
> > 因为 $m \geqslant \frac{3\sqrt{2}}{2}$ , 所以 $\triangle = m^2 - 4 > 0, x_1 + x_2 = m, x_1 x_2 = 1$ ,
> >
> > 又因为 $x_{1}, x_{2}$ 为 $h(x) = \ln x - cx^{2} - bx$ 的零点，所以 $\ln x_{1} - cx_{1}^{2} - bx_{1} = 0, \ln x_{2} - cx_{2}^{2} - bx_{2} = 0,$
> >
> > 两式相减得 $\ln \frac{x_1}{x_2} - c(x_1 - x_2)(x_1 + x_2) - b(x_1 - x_2) = 0$ ，得 $b = \frac{\ln\frac{x_1}{x_2}}{x_1 - x_2} -c(x_1 + x_2),$
> >
> > 而 $h^{\prime}(x) = \frac{1}{x} -2cx - b,y = (x_{1} - x_{2})\left[\frac{2}{x_{1} + x_{2}} -c(x_{1} + x_{2}) - b\right]$
> >
> > $$
> > = (x _ {1} - x _ {2}) \left[ \frac {2}{x _ {1} + x _ {2}} - c (x _ {1} + x _ {2}) - \frac {\ln \frac {x _ {1}}{x _ {2}}}{x _ {1} - x _ {2}} + c (x _ {1} + x _ {2}) \right] = \frac {2 (x _ {1} - x _ {2})}{x _ {1} + x _ {2}} - \ln \frac {x _ {1}}{x _ {2}} = 2 \frac {\frac {x _ {1}}{x _ {2}} - 1}{\frac {x _ {1}}{x _ {2}} + 1} - \ln \frac {x _ {1}}{x _ {2}},
> > $$
> >
> > 令 $\frac{x_1}{x_1} = t(0 < t < 1), y = 2\frac{t - 1}{t + 1} - \ln t$ ，由 $(x_1 + x_2)^2 = m^2$ 得 $x_1^2 + x_2^2 + 2x_1x_2 = m^2$
> >
> > 因为 $x_{1}x_{2} = 1$ ，两边同时除以 $x_{1} + x_{2}$ ，得 $t + \frac{1}{t} +2 = m^2$ ，因为 $m\geqslant \frac{3\sqrt{2}}{2}$ ，故 $t + \frac{1}{t}\geqslant \frac{5}{2}$ 解得 $t\leqslant \frac{1}{2}$ 或 $t\geqslant 2$ ，所以 $0 < t\leqslant$ $\frac{1}{2}$ ，设 $G(x) = 2\frac{t - 1}{t + 1} -\ln t$ ，所以 $G^{\prime}(x) = 2\frac{-(t - 1)^{2}}{t(t + 1)} < 0$ ，则 $y = G(t)$ 在 $\left(0,\frac{1}{2}\right]$ 上是减函数，所以 $G(t)_{\min} = G\left(\frac{1}{2}\right) =$ $-\frac{2}{3} +\ln 2$ ，即 $y = (x_{1} - x_{2})h^{\prime}\left(\frac{x_ {1} + x_ {2}}{2}\right)$ 的最小值为 $-\frac{2}{3} +\ln 2.$
