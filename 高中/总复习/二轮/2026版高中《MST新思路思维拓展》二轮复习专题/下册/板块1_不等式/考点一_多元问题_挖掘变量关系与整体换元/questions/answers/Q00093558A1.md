> [!faq]- 例题解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【解析】**
> > 解析 (1) 当 $a = b = 1, c = -2$ 时， $f(x) = x + \frac{2}{x} - \ln x$ 且 $x > 0$ ，
> >
> > 则 $f^{\prime}(x) = 1 - \frac{2}{x^{2}} -\frac{1}{x} = \frac{x^{2} - x - 2}{x^{2}} = \frac{(x + 1)(x - 2)}{x^{2}}$ ，当 $0 <   x <   2$ 时 $f^{\prime}(x) <   0$ ，当 $x > 2$ 时 $f^{\prime}(x) > 0$
> >
> > 所以 $f(x)$ 在 $(0,2)$ 上单调递减，在 $(2,+\infty)$ 上单调递增，所以 $f(x)_{\min}=f(2)=3-\ln2$ ;
> >
> > (2) $a = c = 1, f'(x) = 1 + \frac{1}{x^2} - \frac{b}{x} = \frac{x^2 - bx + 1}{x^2}$ , 则 $\left\{ \begin{array}{l} \Delta = b^2 - 4 > 0 \\ x_1 + x_2 = b > 0 \Rightarrow b > 2, \\ f(e^{x_1}) + f(e^{x_2}) + \frac{b^2}{2} = e^{x_1} - \frac{1}{e^{x_1}} - bx_1 + e^{x_2} - \\ x_1x_2 = 1 \end{array} \right.$ $\frac{1}{e^{x_1}} - x_2 + \frac{b^2}{2} = e^{x_1} + e^{x_2} - \frac{e^{x_1} + e^{x_2}}{e^{x_1 + x_1}} + \frac{b_0^2}{2} - b(x_1 + x_2)$ $= e^{x_1} + e^{x_2} - \frac{e^{x_1} + e^{x_2}}{e^b} + \frac{b^2}{2} - b^2 = \left(1 - \frac{1}{e^b}\right)(e^{x_1} + e^{x_2}) - \frac{b^2}{2} > \left(1 - \frac{1}{e^b}\right) \cdot 2\sqrt{e^{x_1 + x_2}} - \frac{b^2}{2}$ $= 2\left(1 - \frac{1}{e^b}\right) \cdot e^+ - \frac{b^2}{2} = 2(e^+ - e^{-+}) - 2\left(\frac{b}{2}\right)^2,$
> >
> > 【解析】
> > 令 $\frac{b}{2} = t > 1$ ，即证： $(e^t - e^{-t} - t^2) > 0, h(t) = e^t - e^{-t} - t^2, h'(t) = e^t + e^{-t} - 2t, h''(t) = e^t - e^{-t} - 2$ 单调递增， $h''(1) = e - \frac{1}{e} - 2 > 0, h'(t) > h'(1) > 0, h(t)$ 单调递增， $h(t) > h(1) = e - \frac{1}{e} - 1 > 0$ （成立），综上： $f(e^{\pi}) + f(e^{\pi}) + \frac{b^2}{2} > 0$ $f'(x) = \frac{ax^2 - bx + c}{x^2}, x > 0$ ，因为 $a, b$ 为极值点，所以 $ax^2 - bx + c = 0 \Rightarrow \begin{cases} x_1 + x_2 = \frac{b}{a} = a + b \\ x_1x_2 = \frac{c}{a} = ab \\ \Delta = b^2 - 4ac > 0 \\ a < b \end{cases}$ ，所以 $\begin{cases} b = \frac{a^2}{1 - a} \\ c = \frac{a^4}{1 - a} \end{cases}$ . 因为 $0 < a < b \Rightarrow \frac{1}{2} < a < 1$ ，故 $c < b$ ，因为 $a, b, c$ 为三边长，所以 $a + c > b$ ，故 $a + \frac{a^4}{1 - a} > \frac{a^2}{1 - a}$ ，所以 $a^3 - 2a + 1 > 0, \frac{1}{2} < a < 1, \varphi'$ ( $\alpha$ ) = $3a^2 - 2$ ，所以 $\begin{cases} \frac{1}{2} < a < \frac{\sqrt{6}}{3}, \varphi'(a) < 0, \varphi(a)\text{单调递减} \\ \frac{\sqrt{6}}{3} < a < 1, \varphi'(a) > 0, \varphi(a)\text{单调递增} \end{cases}$ ，且 $\varphi(1) = 0, \varphi(a) = (a - 1)(a^2 + a - 1), a = \frac{\sqrt{5} - 1}{2}$ ，故 $\frac{1}{2} < a < \frac{\sqrt{5} - 1}{2}$ 时， $\varphi(a) > 0$ ，综上， $a \in \left(\frac{1}{2}, \frac{\sqrt{5} - 1}{2}\right)$ ，此时 $a + b - c = a + \frac{a^2}{1 - a} - \frac{a_4}{1 - a} = a^3 + a^2 + a = h(a)$ 单调递增，故 $a + b - c \in \left(h\left(\frac{1}{2}\right), h\left(\frac{\sqrt{5} - 1}{2}\right)\right) = \left(\frac{7}{8}, \sqrt{5} - 1\right)$ .
