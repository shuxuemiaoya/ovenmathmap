> > [!note]- **【解析】**
> > BCD
> > 解析：A 项，复数的平方可能是虚数，而复数的模是实数，平方后仍为实数，故 $z^{2}$ 与 $\left|z\right|^{2}$ 不一定相等，下面举个反例，
> > 设 $z=1+i$ ，则 $z^{2}=(1+\mathrm{i})^{2}=1^{2}+2\mathrm{i}+\mathrm{i}^{2}=2\mathrm{i}$ 而 $\left|z\right|=\sqrt{1^{2}+1^{2}}=\sqrt{2}$ ，所以 $\left|z\right|^{2}=(\sqrt{2})^{2}=2$ 从而 $z^{2}\neq\left|z\right|^{2}$ ，故 A 项错误；
> >
> > B项，直接观察不易判断结论的正误，但我们发现两端可约去 $z$ ，于是先约分，再进行判断，由题意， $z\neq 0$ ，所以 $\frac{z}{\overline{z}} = \frac{z^2}{|z|^2}\Leftrightarrow \frac{1}{\overline{z}} = \frac{z}{|z|^2}\Leftrightarrow z\cdot \overline{z} = |z|^2$ ①，设 $z = a + bi(a,b\in \mathbf{R}$ ，且 $a,b$ 不同时为0），则 $z\cdot \overline{z} = (a + bi)(a - bi) = a^2 -b^2\mathrm{i}^2 = a^2 +b^2 = |z|^2$ 所以式①成立，从而 $\frac{z}{\overline{z}} = \frac{z^2}{|z|^2}$ 成立，故B项正确；
> >
> > C 项，直接分析不易，考虑设复数 z，w 的代数形式来验证，
> > 设 $z = a + bi$ ， $w = c + di$ ，其中 $a, b, c, d \in R$ ，且 a, b 不同时为 0，c, d 不同时为 0，
> > 则 $z - w = a + bi - (c + di) = (a - c) + (b - d)i$ 所以 $\overline{z-w}=(a-c)-(b-d)\mathrm{i}$ ，而 $\overline{z}=a-bi,\quad\overline{w}=c-d\overline{i}$ 所以 $\overline{z}-\overline{w}=a-bi-(c-d\overline{i})=(a-c)-(b-d)\mathrm{i}$ 从而 $\overline{z-w}=\overline{z}-\overline{w}$ ，故 C 项正确；
> > D 项，因为 $w \neq 0$ ，所以 $\left|\frac{z}{w}\right|=\frac{|z|}{|w|}$ ，故 D 项正确.
