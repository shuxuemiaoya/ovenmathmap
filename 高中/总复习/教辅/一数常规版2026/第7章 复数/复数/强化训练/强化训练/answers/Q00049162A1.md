> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > (2024·浙江模拟·★★☆)
> >
> > 若复数 $z$ 的实部大于0，且 $\overline{z} (z + 1) = \frac{20}{3 + \mathrm{i}}$ ，则 $z = (\quad)$ A. $1 - 2\mathrm{i}$ B. $-1 - 2\mathrm{i}$ C. $-1 + 2\mathrm{i}$ D. $1 + 2\mathrm{i}$
> >
> > 解析：由所给等式不方便直接分离出 $z$ ，故考虑设 $z$ 的代数形式，代入所给等式，设 $z = a + bi (a > 0, b \in \mathbf{R})$ ，则 $\overline{z} = a - bi$ ，所以 $\overline{z}(z + 1) =$
> >
> > $z\cdot \overline{z} +\overline{z} = (a + bi)(a - bi) + (a - bi) = a^2 +b^2 +a - bi,$ $\frac{20}{3 + i} = \frac{20(3 - i)}{(3 + i)(3 - i)} = \frac{60 - 20i}{9 - i^2} = \frac{60 - 20i}{10} = 6 - 2i,$
> >
> > 由题意， $\overline{z}(z+1)=\frac{20}{3+i}$ ，所以 $a^{2}+b^{2}+a-bi=6-2i$ ，
> > 故 $\left\{\begin{aligned}a^{2}+b^{2}+a&=6\\ -b&=-2\end{aligned}\right.$ ，解得： $\left\{\begin{aligned}a&=1\\ b&=2\end{aligned}\right.$ 或 $\left\{\begin{aligned}a&=-2\\ b&=2\end{aligned}\right.$ 又因为 a > 0 ，所以 a = 1 ， b = 2 ，故 $z = 1 + 2i$ 。
