> [!faq]- 《第1节 不等式与二次函数》参考答案
>
> > [!success]- **【答案】** $\pm 2$
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > 解析：观察发现解集的端点都含参，但差值不变，故可由韦达定理求出 $|x_{1} - x_{2}|$ ，从而建立方程求 $a$
> >
> > 因为 $x^{2} - ax - 3 < 0$ 的解集为 $(x_0, x_0 + 4)$ ，所以 $x_0$ 和 $x_0 + 4$ 是方程 $x^{2} - ax - 3 = 0$ 的两根，
> >
> > 记 $x_{1} = x_{0}$ ， $x_{2} = x_{0} + 4$ ，则由韦达定理， $\left\{ \begin{array}{l}x_1 + x_2 = a\\ x_1x_2 = -3 \end{array} \right.$
> >
> > 故 $\left|x_{1} - x_{2}\right| = \sqrt{(x_1 + x_2)^2 - 4x_1x_2} = \sqrt{a^2 - 4\times(-3)}$
> >
> > $= \sqrt{a^2 + 12}$ ，又 $\left|x_{1} - x_{2}\right| = \left|x_{0} - (x_{0} + 4)\right| = 4$
> >
> > 所以 $\sqrt{a^{2}+12}=4$ ，解得： $a=\pm2$
>
> > [!tip]- **【反思】**
> > 对于一元二次方程 $ax^2 + bx + c = 0$ ，除两根之和、两根之积的韦达定理外，两根之差的绝对值 $\left|x_1 - x_2\right| = \sqrt{(x_1 + x_2)^2 - 4x_1x_2} = \frac{\sqrt{\Delta}}{|a|}$ 也需要掌握，它在解析几何中有广泛的应用.
