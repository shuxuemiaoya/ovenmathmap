> [!faq]- 《第3节 不等式的进阶方法》参考答案
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > 解析：求两个分式和的最值，考虑权方和不等式，为了凑出分母和为定值，将 $\frac{2}{b + 1}$ 变成 $\frac{4}{2b + 2}$ 由权方和不等式， $\frac{1}{2a} + \frac{2}{b + 1} = \frac{1^2}{2a} + \frac{2^2}{2b + 2}$ $\geq \frac{(1 + 2)^2}{2a + 2b + 2} = \frac{9}{4}$ ，取等条件是 $\frac{1}{2a} = \frac{2}{2b + 2}$ ，结合 $a + b = 1$ 得 $a = \frac{2}{3}$ ， $b = \frac{1}{3}$ ，故 $\left(\frac{1}{2a} + \frac{2}{b + 1}\right)_{\min} = \frac{9}{4}$ .
