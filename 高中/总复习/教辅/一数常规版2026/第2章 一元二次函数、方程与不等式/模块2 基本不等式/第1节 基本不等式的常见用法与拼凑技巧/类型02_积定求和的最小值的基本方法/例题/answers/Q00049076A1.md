> [!faq]- 《第1节 基本不等式的常见用法与拼凑技巧》例题解析
>
> > [!success]- **【答案】** 4
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > 解析：条件与所求看着似乎不好联系，咋办？一般这时候条件会有“猫腻”，观察发现条件可分解因式， $4x^{4} + 9x^{2}y^{2} + 2y^{4} = (4x^{2} + y^{2})(x^{2} + 2y^{2}) = 4$ ，可发现 $(4x^{2} + y^{2}) + (x^{2} + 2y^{2})$ 即为目标式，想到基本不等式， $5x^{2} + 3y^{2} = (4x^{2} + y^{2}) + (x^{2} + 2y^{2}) \geq 2\sqrt{(4x^{2} + y^{2})(x^{2} + 2y^{2})} = 4$ ，取等条件是 $4x^{2} + y^{2} = x^{2} + 2y^{2}$ ，结合 $4x^{4} + 9x^{2}y^{2} + 2y^{4} = 4$ 可得此时 $x^{2} = \frac{2}{7}$ ， $y^{2} = \frac{6}{7}$ ，满足题意，所以 $5x^{2} + 3y^{2}$ 的最小值为 4.
>
> > [!tip]- **【反思】**
> > 有的题目积定隐藏在条件中，需要变形才能发现，上面的变式1、2就是如此.
