> [!faq]- 《第2节 基本不等式的核心运用思想》例题解析
>

> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > 解析：目标式变量多，不易分析取值，注意到所给等式可方便地提 $a$ 反解出 $b + c$ ，故可代入目标式消元，由 $ab + ac = 2$ 可得 $b + c = \frac{2}{a}$ ，代入 $\frac{1}{a} +\frac{1}{b + c} +\frac{8}{a + b + c}$ 可得 $\frac{1}{a} +\frac{1}{b + c} +\frac{8}{a + b + c} = \frac{1}{a} +\frac{a}{2} +\frac{8}{a + \frac{2}{a}}$ 上式看似复杂，但若提个 $\frac{1}{2}$ ，就出现“积定”了， $\frac{1}{a} +\frac{a}{2} +\frac{8}{a + \frac{2}{a}} = \frac{1}{2}\left(\frac{2}{a} +a + \frac{16}{a + \frac{2}{a}}\right)\geq \sqrt{\left(\frac{2}{a} + a\right)\cdot\frac{16}{a + \frac{2}{a}}} = 4,$ 取等条件是 $\frac{2}{a} +a = \frac{16}{a + \frac{2}{a}}$ ，结合 $a > 0$ 可解得： $a = 2\pm \sqrt{2}$ ，所以 $\left|\frac{1}{a} +\frac{1}{b + c} +\frac{8}{a + b + c}\right|_{\min} = 4$ ，
> >
> > 故选 **ABC**.
