> [!faq]- 《第2节 基本不等式的核心运用思想》例题解析
>
> > [!success]- **【答案】** 4
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > 解法1: 将目标直接凑“积定”不易, 注意到 $a, b$ 的关系较简单, 不妨解出 $b$ , 代入目标式消元再看,
> >
> > 由 $ab = 1$ 可得 $b = \frac{1}{a}$ ，所以 $\frac{1}{a} + \frac{1}{b} + \frac{4}{a + b} = \frac{1}{a} + a + \frac{4}{a + \frac{1}{a}} \geq 2\sqrt{\left(a + \frac{1}{a}\right) \cdot \frac{4}{a + \frac{1}{a}}} = 4$
> >
> > 当且仅当 $a + \frac{1}{a} = \frac{4}{a + \frac{1}{a}}$ 时取等号，结合 $a > 0$ 可解得： $a = 1$ ，此时 $b = 1$ ，满足题意，故 $\left(\frac{1}{a} +\frac{1}{b} +\frac{4}{a + b}\right)_{\min} = 4.$
> >
> > 解法2：求和的最小值应凑“积定”，注意到分母为 $a + b$ ，所以分子也应有 $a + b$ ，故将前两项通分，
> >
> > 由题意， $\frac{1}{a} +\frac{1}{b} +\frac{4}{a + b} = \frac{b + a}{ab} +\frac{4}{a + b} = a + b + \frac{4}{a + b}\geq 2\sqrt{(a + b)\cdot\frac{4}{a + b}} = 4,$
> >
> > 当且仅当 $a + b = \frac{4}{a + b}$ 时取等号，结合 $ab = 1$ 及 $a$ ， $b$ 均为正数可得 $a = b = 1$ ，所以 $\left(\frac{1}{a} + \frac{1}{b} + \frac{4}{a + b}\right)_{\min} = 4$
>
> > [!tip]- **【反思】**
> > 如果条件等式中的两个变量方便用其中一个表示另外一个，可以尝试消元，将目标式化为单变量形式再看。有时消元不一定是两个变量间的转换，多个变量也可以整体进行消元，如下面变式。
