> [!faq]- 《第2节 基本不等式的核心运用思想》参考答案
>
> > [!success]- **【答案】** C
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > C
> >
> > 解析：要求和的最小值，应凑“积定”，直接凑不易，可考虑先由所给等式反解出 $x$ ，代入消元再看， $xy + x - 2y = 4 \Rightarrow x(y + 1) = 2y + 4 \Rightarrow x = \frac{2y + 4}{y + 1}$ ①，代入 $2x + y$ 可得 $2x + y = 2 \cdot \frac{2y + 4}{y + 1} + y = 2 \cdot \frac{2(y + 1) + 2}{y + 1} + y = 2\left(2 + \frac{2}{y + 1}\right) + y = \frac{4}{y + 1} + y + 4 = \frac{4}{y + 1} + (y + 1) + 3$
> >
> > $\geq 2\sqrt{\frac{4}{y + 1}\cdot(y + 1)} +3 = 7$ ，取等条件是 $\frac{4}{y + 1} = y + 1$
> >
> > 结合 $y > 0$ 得 $y = 1$ ，代入①得 $x = 3$ ，所以 $(2x + y)_{\min} = 7$
