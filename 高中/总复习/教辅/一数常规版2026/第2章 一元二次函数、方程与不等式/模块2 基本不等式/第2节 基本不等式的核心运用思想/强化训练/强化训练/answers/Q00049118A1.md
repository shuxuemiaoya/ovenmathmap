> [!faq]- 《第2节 基本不等式的核心运用思想》参考答案
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > 8
> >
> > 解法1：涉及变量较多，不好处理. 观察发现由所给等式容易反解出 $c$ ，可尝试将其反解出来，代入 $a + b + c$ 中消去 $c$ 因为 $abc = 4(a + b)$ ，所以 $c = \frac{4(a + b)}{ab}$ 故 $a + b + c = a + b + \frac{4(a + b)}{ab}$ ①，
> >
> > 求和的最小值的关键是凑积为定值，观察发现只要把分式拆开，就能凑出积定，
> >
> > 由①可得 $a + b + c = a + \frac{4}{a} +b + \frac{4}{b}\geq 2\sqrt{a\cdot\frac{4}{a}} +2\sqrt{b\cdot\frac{4}{b}} = 8$
> >
> > 取等条件是 $a = \frac{4}{a}$ 且 $b = \frac{4}{b}$ ，即 $a = b = 2$ ，
> >
> > 故 $a + b + c$ 的最小值为8.
> >
> > 解法2：得到上述式①的过程同解法1，式①中有 $a + b$ 和 $ab$ ，也可考虑先用 $a + b \geq 2\sqrt{ab}$ 把结构统一为 $ab$ 再来看， $a + b + c = a + b + \frac{4(a + b)}{ab} \geq 2\sqrt{ab} + \frac{4 \times 2\sqrt{ab}}{ab}$ $= 2\sqrt{ab} + \frac{8}{\sqrt{ab}} \geq 2\sqrt{2\sqrt{ab} \cdot \frac{8}{\sqrt{ab}}} = 8$ 上述两个不等号的取等条件分别是 $a = b$ 和 $2\sqrt{ab} = \frac{8}{\sqrt{ab}}$ 解得： $a = b = 2$ ，所以 $a + b + c$ 的最小值为8.
