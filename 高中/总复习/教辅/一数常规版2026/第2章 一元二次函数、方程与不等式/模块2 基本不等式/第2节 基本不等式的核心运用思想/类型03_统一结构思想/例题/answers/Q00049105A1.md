> [!faq]- 《第2节 基本不等式的核心运用思想》例题解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > 解析：消元或齐次化都不好处理，仔细观察会发现，若将分子展开，会出现 $a + 3b$ ，与已知联系起来，由题意， $\frac{(a + 1)(3b + 1)}{\sqrt{ab}} = \frac{3ab + a + 3b + 1}{\sqrt{ab}} = \frac{3ab + 6}{\sqrt{ab}} = 3\sqrt{ab} +\frac{6}{\sqrt{ab}}\geq 2\sqrt{3\sqrt{ab}\cdot\frac{6}{\sqrt{ab}}} = 6\sqrt{2}$
> >
> > 取等条件是 $3\sqrt{ab} = \frac{6}{\sqrt{ab}}$ ，结合 $a + 3b = 5$ 可得此时 $\left\{ \begin{array}{l}a = 2\\ b = 1 \end{array} \right.$ 或 $\left\{ \begin{array}{l}a = 3\\ b = \frac{2}{3} \end{array} \right.$ ，所以 $\frac{(a + 1)(3b + 1)}{\sqrt{ab}}$ 的最小值为 $6\sqrt{2}$ 答案： $6\sqrt{2}$
