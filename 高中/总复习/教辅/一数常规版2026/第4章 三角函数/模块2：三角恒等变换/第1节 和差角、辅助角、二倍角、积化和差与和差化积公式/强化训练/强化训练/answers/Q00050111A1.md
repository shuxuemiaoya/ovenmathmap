> [!faq]- 《第1节 和差角、辅助角、二倍角、积化和差与和差化积公式》参考答案
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > 解法 1: (求 $f(x)$ 在 $\left[0, \frac{\pi}{4}\right]$ 上的最大值, 最容易想到的是直接对 $f(x)$ 求导, 分析单调性, 我们来试试)由题意, $f'(x) = -5\sin x + 5\sin 5x = 5(\sin 5x - \sin x)$ ,
> >
> > （怎样判断 $f'(x)$ 在 $\left[0, \frac{\pi}{4}\right]$ 上的正负？直接判断不易，考虑进一步变形，怎样变形？涉及正弦减正弦，可考虑用和差化积公式 $\sin \alpha - \sin \beta = 2\cos \frac{\alpha + \beta}{2}\sin \frac{\alpha - \beta}{2}$ 处理）由和差化积公式， $f'(x) = 5 \times 2\cos \frac{5x + x}{2}\sin \frac{5x - x}{2} = 10\cos 3x\sin 2x$ ，因为 $x \in \left[0, \frac{\pi}{4}\right]$ ，所以 $3x \in \left[0, \frac{3\pi}{4}\right]$ ， $2x \in \left[0, \frac{\pi}{2}\right]$ ，从而 $\sin 2x \geq 0$ ，故 $f'(x) \geq 0 \Leftrightarrow \cos 3x \geq 0 \Leftrightarrow 0 \leq 3x \leq \frac{\pi}{2} \Leftrightarrow 0 \leq x \leq \frac{\pi}{6}$ ， $f'(x) \leq 0 \Leftrightarrow \frac{\pi}{6} \leq x \leq \frac{\pi}{4}$ ，所以 $f(x)$ 在 $\left[0, \frac{\pi}{6}\right]$ 上单调递增，在 $\left[\frac{\pi}{6}, \frac{\pi}{4}\right]$ 上单调递减，故 $f(x)$ 在 $\left[0, \frac{\pi}{4}\right]$ 上的最大值为 $f\left(\frac{\pi}{6}\right) = 5\cos \frac{\pi}{6} - \cos \frac{5\pi}{6} = 3\sqrt{3}$ .
> >
> > 解法2：（若没想到和差化积公式，有其它方法吗？注意到 $5x$ 与 $x$ 的倍数相差不大，可尝试统一角度，如何统一？不妨先按 $\cos 5x = \cos (4x + x)$ 展开，再逐步用二倍角公式，直到把角全部化为 $x$ ，同时为了统一函数名，我们尽可能都化成 $\cos x$ ）
> >
> > $\cos 5x = \cos (4x + x) = \cos 4x\cos x - \sin 4x\sin x$ $= (2\cos^2 2x - 1)\cos x - 2\sin 2x\cos 2x\sin x$ $= [2(2\cos^2 x - 1)^2 -1]\cos x - 4\sin x\cos x(2\cos^2 x - 1)\sin x$ $= (8\cos^4 x - 8\cos^2 x + 1)\cos x - 4\cos x(2\cos^2 x - 1)\sin^2 x$ $= (8\cos^4 x - 8\cos^2 x + 1)\cos x - 4\cos x(2\cos^2 x - 1)(1 - \cos^2 x)$ $= \cos x[8\cos^4 x - 8\cos^2 x + 1 - 4(2\cos^2 x - 1)(1 - \cos^2 x)]$ $= \cos x[8\cos^4 x - 8\cos^2 x + 1 - 4(2\cos^2 x - 2\cos^4 x - 1+$ $\cos^2 x)] = \cos x(16\cos^4 x - 20\cos^2 x + 5)$ ，  
> > 所以 $f(x) = 5\cos x - \cos 5x = 5\cos x - \cos x(16\cos^4 x-$
> >
> > $$
> > 2 0 \cos^ {2} x + 5) = - 1 6 \cos^ {5} x + 2 0 \cos x ^ {3}
> > $$
> >
> > (含 x 的部分以 $\cos x$ 整体出现，可将其换元成 t，化简上述解析式，再求导分析)
> >
> > 令 $t = \cos x$ ，则当 $x\in \left[0,\frac{\pi}{4}\right]$ 时， $t\in \left[\frac{\sqrt{2}}{2},1\right]$
> >
> > 且 $f(x) = -16t^{5} + 20t^{3}$
> >
> > 设 $g(t) = -16t^{5} + 20t^{3}$ ， $t\in \left[\frac{\sqrt{2}}{2},1\right]$
> >
> > 则 $g^{\prime}(t) = -80t^{4} + 60t^{2} = -20t^{2}(4t^{2} - 3)$
> >
> > 所以 $g^{\prime}(t) > 0 \Leftrightarrow 4t^{2} - 3 < 0 \Leftrightarrow \frac{\sqrt{2}}{2} \leq t < \frac{\sqrt{3}}{2}$ ,
> >
> > $$
> > g ^ {\prime} (t) <   0 \Leftrightarrow \frac {\sqrt {3}}{2} <   t \leq 1,
> > $$
> >
> > 故 $g(t)$ 在 $\left[\frac{\sqrt{2}}{2},\frac{\sqrt{3}}{2}\right)$ 上单调递增，在 $\left(\frac{\sqrt{3}}{2},1\right]$ 上单调递减，所以 $g(t)_{\max} = g\left(\frac{\sqrt{3}}{2}\right) = -16\times \left(\frac{\sqrt{3}}{2}\right)^5 +20\times \left(\frac{\sqrt{3}}{2}\right)^3 = 3\sqrt{3}$ 故 $f(x)$ 在 $\left[0,\frac{\pi}{4}\right]$ 上的最大值为 $3\sqrt{3}$ ：
