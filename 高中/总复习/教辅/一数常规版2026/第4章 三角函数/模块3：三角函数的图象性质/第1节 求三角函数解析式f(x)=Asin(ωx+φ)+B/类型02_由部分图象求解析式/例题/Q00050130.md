【变式1】已知函数 $f(x) = A \sin (\omega x + \varphi) + B \left( \omega > 0, \left| \varphi \right| < \frac{\pi}{2} \right)$ 的部分图象如图所示，则（）A. $f(x) = -4 \sin \left( \frac{\pi}{8} x + \frac{\pi}{4} \right) + 2$ B. $f(x) = 4 \sin \left( \frac{\pi}{8} x - \frac{\pi}{4} \right) + 2$ C. $f(x) = -4 \sin \left( \frac{\pi}{8} x - \frac{\pi}{4} \right) + 2$ D. $f(x) = 4 \sin \left( \frac{\pi}{8} x + \frac{\pi}{4} \right) + 2$

![](../../images/questions/d5a08ea410a5117df09878eda80b1c56bd6729e1b0e973f4cbea44e4d239b611.jpg)

(2) = 4\sin \left(\frac{\pi}{8} \times 2 + \varphi\right) + 2 = -2$ ，所以 $\sin \left(\frac{\pi}{4} + \varphi\right) = -1$ ，因为 $|\varphi| < \frac{\pi}{2}$ ，所以 $-\frac{\pi}{2} < \varphi < \frac{\pi}{2}$ ，从而 $-\frac{\pi}{4} < \frac{\pi}{4} + \varphi < \frac{3\pi}{4}$ ，故 $\sin \left(\frac{\pi}{4} + \varphi\right) = -1$ 无解；②当 $A < 0$ 时，由图可知， $\begin{cases} -A + B = 6 \\ A + B = -2 \end{cases}$ ，解得： $A = -4, B = 2$ ，所以 $f(x) = -4\sin \left(\frac{\pi}{8} x + \varphi\right) + 2$ ，接下来再求 $\varphi$ ，还是代最小值点 $x = 2$ ， $f (2) = -4\sin \left(\frac{\pi}{4} + \varphi\right) + 2 = -2 \Rightarrow \sin \left(\frac{\pi}{4} + \varphi\right) = 1$ ，结合 $-\frac{\pi}{4} < \frac{\pi}{4} + \varphi < \frac{3\pi}{4}$ 可得 $\frac{\pi}{4} + \varphi = \frac{\pi}{2}$ ，所以 $\varphi = \frac{\pi}{4}$ ，故 $f(x) = -4\sin \left(\frac{\pi}{8} x + \frac{\pi}{4}\right) + 2$ 。解法2：这种给出部分图象，选解析式的题，有时也可结合图象的一些特征，用排除法来选答案，由图可知， $f\left(-\frac{2}{3}\right) = 0$ ，经检验，选项B、C、D均不满足，故选A。
