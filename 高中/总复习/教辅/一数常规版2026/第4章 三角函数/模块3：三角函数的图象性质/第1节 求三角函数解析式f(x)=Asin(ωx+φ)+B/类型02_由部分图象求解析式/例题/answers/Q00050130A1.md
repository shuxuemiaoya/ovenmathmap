> [!faq]- 《第1节 求三角函数解析式f(x)=Asin(ωx+φ)+B》例题解析
>
> > [!success]- **【答案】** A
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > 解法1：图上只有一个最大值点，求周期还不够，观察发现可由 $x$ 轴上的两个点推断出最小值点，由所给图象可知， $x = -\frac{2}{3}$ 和 $x = \frac{14}{3}$ 的中间 $x = 2$ 必为最小值点，所以 $\frac{T}{2} = 10 - 2 = 8$ ，从而 $T = 16$ ，故 $\omega = \frac{2\pi}{T} = \frac{\pi}{8}$ ，所以 $f(x) = A\sin \left(\frac{\pi}{8} x + \varphi\right) + B$ ，从图象可以看出最大、最小值分别为6和-2，可由此求 $A$ 和 $B$ ，但由于没给 $A$ 的正负，故需讨论，①当 $A > 0$ 时，由图可知， $\begin{cases} A + B = 6 \\ -A + B = -2 \end{cases}$ ，解得： $A = 4, B = 2$ ，所以 $f(x) = 4\sin \left(\frac{\pi}{8} x + \varphi\right) + 2$ ，最后求 $\varphi$ ，首选最值点，代最小值点 $x = 2$ 或最大值点 $x = 10$ 均可，不妨代 $x = 2$ ，故 $f
> > (2) = 4\sin \left(\frac{\pi}{8} \times 2 + \varphi\right) + 2 = -2$ ，所以 $\sin \left(\frac{\pi}{4} + \varphi\right) = -1$ ，因为 $|\varphi| < \frac{\pi}{2}$ ，所以 $-\frac{\pi}{2} < \varphi < \frac{\pi}{2}$ ，从而 $-\frac{\pi}{4} < \frac{\pi}{4} + \varphi < \frac{3\pi}{4}$ ，故 $\sin \left(\frac{\pi}{4} + \varphi\right) = -1$ 无解；
> > - **②**：当 $A < 0$ 时，由图可知， $\begin{cases} -A + B = 6 \\ A + B = -2 \end{cases}$ ，解得： $A = -4, B = 2$ ，所以 $f(x) = -4\sin \left(\frac{\pi}{8} x + \varphi\right) + 2$ ，接下来再求 $\varphi$ ，还是代最小值点 $x = 2$ ， $f (2) = -4\sin \left(\frac{\pi}{4} + \varphi\right) + 2 = -2 \Rightarrow \sin \left(\frac{\pi}{4} + \varphi\right) = 1$ ，结合 $-\frac{\pi}{4} < \frac{\pi}{4} + \varphi < \frac{3\pi}{4}$ 可得 $\frac{\pi}{4} + \varphi = \frac{\pi}{2}$ ，所以 $\varphi = \frac{\pi}{4}$ ，故 $f(x) = -4\sin \left(\frac{\pi}{8} x + \frac{\pi}{4}\right) + 2$ 。
> > 解法2：这种给出部分图象，选解析式的题，有时也可结合图象的一些特征，用排除法来选答案，由图可知， $f\left(-\frac{2}{3}\right) = 0$ ，经检验，选项B、C、D均不满足，
> >
> > 故选 **A**。
>
> > [!tip]- **【反思】**
> > - **①**：不确定 A 的正负时，可讨论；
> > - **②**：选择题抓住图中关键信息，用排除法选答案也是好方法.
