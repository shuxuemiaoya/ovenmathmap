>
> > [!note]- **【解析】**
> > ## 5. (★★★)
> >
> > 已知锐角 $\triangle ABC$ 的三个内角 $A, B, C$ 的对边分别是 $a, b, c$ , 且 $\frac{a + b}{\cos A + \cos B} = \frac{c}{\cos C}$ , 求角 $C$ .
> >
> > 解：（已知的等式左右都有齐次的边，可边化角分析）
> > 因为 $\frac{a+b}{\cos A+\cos B}=\frac{c}{\cos C}$ ，所以 $\frac{\sin A+\sin B}{\cos A+\cos B}=\frac{\sin C}{\cos C}$ ，
> > 故 $\sin A \cos C + \sin B \cos C = \sin C \cos A + \sin C \cos B$ （观察发现若将相同角的项组合，则能用差角公式合并）
> > 所以 $\sin A \cos C - \sin C \cos A = \sin C \cos B - \sin B \cos C$ 故 $\sin(A-C)=\sin(C-B)$ ①，
> > （要由式①研究角的关系，得分析角的范围）
> >
> > 因为 $\triangle ABC$ 是锐角三角形，所以 $A, B, C \in \left(0, \frac{\pi}{2}\right)$ ，
> >
> > 从而 $A - C\in \left(-\frac{\pi}{2},\frac{\pi}{2}\right),\quad C - B\in \left(-\frac{\pi}{2},\frac{\pi}{2}\right),$
> >
> > 结合 $y = \sin x$ 在 $\left(-\frac{\pi}{2},\frac{\pi}{2}\right)$ 上单调递增知式①等价于 $A - C =$
> >
> > $C - B$ ，所以 $A + B = 2C$
> >
> > 又 $A + B = \pi -C$ ，所以 $\pi -C = 2C$ ，故 $C = \frac{\pi}{3}$
> >
