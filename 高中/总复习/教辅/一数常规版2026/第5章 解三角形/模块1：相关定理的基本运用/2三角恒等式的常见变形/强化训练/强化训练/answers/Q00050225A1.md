> [!faq]- 《2三角恒等式的常见变形》参考答案
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > 因为 $c\sin (A - B) = b\sin (C - A)$ ，所以 $c(\sin A\cos B -$
> >
> > $$
> > \cos A \sin B) = b (\sin C \cos A - \cos C \sin A) \quad ①,
> > $$
> >
> > (观察发现有齐次的内角正弦值, 结合另一条件 $a^2 = bc$ 涉及的是边, 可考虑用正弦定理将式①角化边)
> >
> > 由①可得 $c(a\cos B - b\cos A) = b(c\cos A - a\cos C)$
> >
> > 化简得： $ac\cos B+ab\cos C=2bc\cos A$ ②，
> >
> > (看到 $ac \cos B$ ， $ab \cos C$ ， $bc \cos A$ ，想到余弦定理)
> >
> > 由余弦定理， $b^{2} = a^{2} + c^{2} - 2ac\cos B$
> >
> > 所以 $ac\cos B = \frac{a^2 + c^2 - b^2}{2}$
> >
> > 同理， $ab\cos C = \frac{a^2 + b^2 - c^2}{2}$ ， $bc\cos A = \frac{b^2 + c^2 - a^2}{2}$
> >
> > 代入②得 $\frac{a^2 + c^2 - b^2}{2} +\frac{a^2 + b^2 - c^2}{2} = 2\times \frac{b^2 + c^2 - a^2}{2},$
> >
> > 整理得： $2a^{2} = b^{2} + c^{2}$ ，又由题意， $a^2 = bc$
> >
> > 所以 $2bc = b^{2} + c^{2}$ ，从而 $(b - c)^{2} = 0$ ，故 $b = c$
> >
> > 结合 $a^2 = bc$ 可得 $a = b = c$
> >
> > 所以 $\triangle ABC$ 为正三角形，故 $A = \frac{\pi}{3}$
> >
> > （2）（给了 $a$ ，第（1）问又得到了 $2a^{2} = b^{2} + c^{2}$ ，故只需对已知的 $A$ 用余弦定理，即可再得到一个边的方程，求出 $b$ 和 $c$ ）由余弦定理， $a^{2} = b^{2} + c^{2} - 2bc\cos A$ ，
> >
> > 将 $a = 2$ ， $\cos A = \frac{4}{5}$ 代入化简得： $b^{2} + c^{2} - \frac{8}{5} bc = 4$ ③，
> >
> > 由（1）可得 $b^{2} + c^{2} = 2a^{2} = 8$ ，代入③得 $8 - \frac{8}{5} bc = 4$
> >
> > 所以 $bc = \frac{5}{2}$ ，又 $8 = b^{2} + c^{2} = (b + c)^{2} - 2bc$
> >
> > 所以 $(b + c)^2 = 8 + 2bc = 13$ ，故 $b + c = \sqrt{13}$
> >
> > 所以 $\triangle ABC$ 的周长为 $a + b + c = 2 + \sqrt{13}$ .
