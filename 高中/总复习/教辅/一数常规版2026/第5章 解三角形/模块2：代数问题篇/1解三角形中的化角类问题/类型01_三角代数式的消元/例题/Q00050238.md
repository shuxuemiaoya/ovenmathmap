【变式2】(2020·新课标Ⅱ卷) $\triangle ABC$ 的内角 $A, B, C$ 的对边分别为 $a, b, c$ , 已知 $\cos^2\left(\frac{\pi}{2} + A\right)$ $+\cos A = \frac{5}{4}$ .

（1）求 $A$ ；
（2）若 $b - c = \frac{\sqrt{3}}{3} a$ ，证明： $\triangle ABC$ 是直角三角形.

（1）由题意， $\cos^2\left(\frac{\pi}{2} +A\right) + \cos A = \sin^2 A + \cos A = 1 - \cos^2 A + \cos A = \frac{5}{4}$

(2) (证明直角三角形可看成求角, 故将所给条件边化角分析) 由 $b - c = \frac{\sqrt{3}}{3} a$ 可得 $\sin B - \sin C = \frac{\sqrt{3}}{3}\sin A$ , 将 $A = \frac{\pi}{3}$ 代入可得 $\sin B - \sin C = \frac{1}{2}$ ①, (此式有两个变量, 但已知 $A$ , 可找到 $B$ 和 $C$ 的关系, 并用来消元) 又 $B + C = \pi - A = \frac{2\pi}{3}$ , 所以 $C = \frac{2\pi}{3} - B$ , 故 $\sin C = \sin \left(\frac{2\pi}{3} - B\right) = \frac{\sqrt{3}}{2}\cos B + \frac{1}{2}\sin B$ ,

代入式①得 $\sin B - \left(\frac{\sqrt{3}}{2}\cos B + \frac{1}{2}\sin B\right) = \frac{1}{2}$ ，整理得： $\frac{1}{2}\sin B - \frac{\sqrt{3}}{2}\cos B = \frac{1}{2}$ ，所以 $\sin \left(B - \frac{\pi}{3}\right) = \frac{1}{2}$ ②，

由 $B + C = \frac{2\pi}{3}$ 可得 $0 < B < \frac{2\pi}{3}$ ，所以 $-\frac{\pi}{3} < B - \frac{\pi}{3} < \frac{\pi}{3}$ ，

结合式②可得 $B - \frac{\pi}{3} = \frac{\pi}{6}$ ，故 $B = \frac{\pi}{2}$ ，所以 $\triangle ABC$ 是直角三角形.
