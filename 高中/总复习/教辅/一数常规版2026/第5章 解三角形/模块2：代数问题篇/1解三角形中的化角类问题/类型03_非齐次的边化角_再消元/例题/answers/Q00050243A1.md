> [!faq]- 《1解三角形中的化角类问题》例题解析
>
> > [!success]- **【答案】** C
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > 解析：所给等式中有 $a^2 + b^2 - c^2$ ，这是用余弦定理的标志，由余弦定理， $c^2 = a^2 +b^2 -2ab\cos C$ ，所以 $a^2 +b^2 -c^2 = 2ab\cos C$ 代入题干等式整理得： $b\cos C = 2a\cos A - c\cos B$ ，所以 $\sin B\cos C = 2\sin A\cos A - \sin C\cos B$ 从而 $\sin B\cos C + \sin C\cos B = 2\sin A\cos A$ ，故 $\sin (B + C) = 2\sin A\cos A$ ，又 $\sin (B + C) = \sin (\pi -A) = \sin A$ 所以 $\sin A = 2\sin A\cos A$ ，由 $0 <   A <   \pi$ 可得 $\sin A > 0$ ，所以 $\cos A = \frac{1}{2}$ ，故 $A = \frac{\pi}{3}$ 已知外接圆半径，非齐次分式 $\frac{ac}{b}$ 也可边化角，  
> > 由正弦定理， $\frac{a}{\sin A} = \frac{b}{\sin B} = \frac{c}{\sin C} = 2R = 2$ ，所以 $a = 2\sin A$ ， $b = 2\sin B$ ， $c = 2\sin C$ 故 $\frac{ac}{b} = \frac{2\sin A\cdot 2\sin C}{2\sin B} = \frac{\sqrt{3}\sin C}{\sin B} = \frac{\sqrt{3}\sin(\pi -A - B)}{\sin B} = \frac{\sqrt{3}\sin\left(\frac{2\pi}{3} -B\right)}{\sin B} = \frac{\sqrt{3}\left(\frac{\sqrt{3}}{2}\cos B + \frac{1}{2}\sin B\right)}{\sin B} = \frac{3}{2\tan B} +\frac{\sqrt{3}}{2},$ 因为△ABC是锐角三角形，所以 $\left\{ \begin{array}{ll}0 <   B <   \frac{\pi}{2}\\ 0 <   C = \frac{2\pi}{3} -B <   \frac{\pi}{2} \end{array} \right.$ ，从而 $\frac{\pi}{6} <  B <   \frac{\pi}{2}$ 故tan $B > \frac{\sqrt{3}}{3}$ 所以 $0 <   \frac{1}{\tan B} <  \sqrt{3}$ ，从而 $\frac{\sqrt{3}}{2} <  \frac{3}{2\tan B} +\frac{\sqrt{3}}{2} <  2\sqrt{3}$ ，故 $\frac{ac}{b}$ 的取值范围是 $\left(\frac{\sqrt{3}}{2},2\sqrt{3}\right)$
