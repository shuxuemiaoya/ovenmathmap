> [!faq]- 《1解三角形中的化角类问题》例题解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > 解析：由 $a = 3\sin A$ 可求出外接圆直径，故可用它来边角互化，因为 $a = 3\sin A$ ，所以 $\frac{a}{\sin A} = 3$ ，故 $\triangle ABC$ 的外接圆直径 $2R = 3$
> >
> > 有了外接圆直径，可将条件 $b = 3\sqrt{3}\cos B$ 边化角，建立关于 $B$ 的方程并求解，所以 $\frac{b}{\sin B} = 3$ ，故 $b = 3\sin B$ ，由题意， $b = 3\sqrt{3}\cos B$ ，所以 $3\sin B = 3\sqrt{3}\cos B$ ，故 $\tan B = \sqrt{3}$ 结合 $0 < B < \pi$ 可得 $B = \frac{\pi}{3}$ ；由 $\frac{c}{\sin C} = 2R = 3$ 可得 $c = 3\sin C$ 因为 $B = \frac{\pi}{3}$ ，所以 $A + C = \pi -B = \frac{2\pi}{3}$ ，从而 $C\in \left(0,\frac{2\pi}{3}\right)$ ，故 $c = 3\sin C\in (0,3]$ 答案： $\frac{\pi}{3}$ ；(0,3]
>
> > [!tip]- **【反思】**
> > 本题相比于例2，边长不再是齐次分式，但当知道 $2R$ 的值时，依旧可以使用正弦定理边化角.
