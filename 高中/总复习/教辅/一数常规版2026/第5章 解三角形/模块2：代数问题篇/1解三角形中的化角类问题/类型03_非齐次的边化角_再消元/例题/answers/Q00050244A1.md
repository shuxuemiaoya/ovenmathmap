> [!faq]- 《1解三角形中的化角类问题》例题解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > 解法1: 已知 $B$ 和 $c$ , 于是求面积把它们都用起来, 看还差什么, 由题意, $S_{\triangle A B C} = \frac{1}{2} a c \sin B = \frac{\sqrt{3}}{4} a$ , 所以只需求 $a$ 的范围, 可将 $a$ 边化角, 借助角来分析, 因为 $\frac { a } { \sin A } = \frac { c } { \sin C }$ , 所以 $a = \frac { c \sin A } { \sin C } = \frac { \sin A } { \sin C }$ , 有 $A, C$ 两个变量, 但已知 $B$ , 可找到 $A, C$ 的关系, 并用来消元,
> >
> > $$
> > S _ {\triangle A B C} = \frac {\sqrt {3} \sin A}{4 \sin C} = \frac {\sqrt {3} \sin (\pi - B - C)}{4 \sin C} = \frac {\sqrt {3} \sin \left(\frac {2 \pi}{3} - C\right)}{4 \sin C} = \frac {\sqrt {3} \left(\frac {\sqrt {3}}{2} \cos C + \frac {1}{2} \sin C\right)}{4 \sin C} = \frac {3}{8 \tan C} + \frac {\sqrt {3}}{8},
> > $$
> >
> > 因为 $\triangle ABC$ 为锐角三角形，所以 $\left\{ \begin{array}{l}0 < C < \frac{\pi}{2}\\ 0 < A = \frac{2\pi}{3} -C < \frac{\pi}{2} \end{array} \right.$ ，解得： $\frac{\pi}{6} < C < \frac{\pi}{2}$ ，故 $\tan C > \frac{\sqrt{3}}{3}$
> >
> > 所以 $0 < \frac{1}{\tan C} < \sqrt{3}$ ，从而 $\frac{\sqrt{3}}{8} < \frac{3}{8\tan C} + \frac{\sqrt{3}}{8} < \frac{\sqrt{3}}{2}$ ，故 $\triangle ABC$ 的面积的取值范围为 $\left(\frac{\sqrt{3}}{8}, \frac{\sqrt{3}}{2}\right)$ .
> >
> > 解法2：按解法1得到 $S_{\triangle ABC} = \frac{\sqrt{3}}{4} a$ 后，也可考虑直接从边入手，分析 $a$ 的范围，先把 $b$ 也用 $a$ 表示，
> >
> > 由余弦定理， $b^{2} = a^{2} + c^{2} - 2ac\cos B$ ，将 $B = \frac{\pi}{3}$ ， $c = 1$ 代入得 $b^{2} = a^{2} - a + 1$
> >
> > 因为 $\triangle ABC$ 为锐角三角形，所以 $\left\{ \begin{array}{l}a^2 +b^2 -c^2 >0\\ a^2 +c^2 -b^2 >0\\ b^2 +c^2 -a^2 >0 \end{array} \right.$ 故 $\left\{ \begin{array}{l}a^{2} + a^{2} - a + 1 - 1 > 0\\ a^{2} + 1 - (a^{2} - a + 1) > 0\\ a^{2} - a + 1 + 1 - a^{2} > 0 \end{array} \right.$ 解得： $\frac{1}{2} < a < 2$
> >
> > 所以 $\frac{\sqrt{3}}{8} < S_{\triangle ABC} = \frac{\sqrt{3}}{4} a < \frac{\sqrt{3}}{2}$ ，故 $\triangle ABC$ 的面积的取值范围为 $\left(\frac{\sqrt{3}}{8}, \frac{\sqrt{3}}{2}\right)$ .
>
> > [!tip]- **【反思】**
> > - **①**：解法1将求 $S$ 的范围转化为求 $a$ 的范围, 此时虽不知道 $2 R$ , 但由于知道一边一角, 仍可用正弦定理边化角, 转化为例2类型的角度相关范围问题;
> > - **②**：$A$ 为锐角 $\Leftrightarrow \cos A > 0 \Leftrightarrow b^{2} + c^{2} - a^{2} > 0$ .
