> [!faq]- 《1解三角形中的化角类问题》例题解析
>
> > [!success]- **【答案】** $\left(\frac{3}{10},\frac{5}{6}\right)$
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > 解析：$\frac{b}{2 c}$ 这个式子可边化角, 知道 $\sin A$ , 等同于知道 $A$ , 可得出 $B$ 和 $C$ 的关系, 用于消元,
> >
> > 由正弦定理， $\frac{b}{2c} = \frac{\sin B}{2\sin C} = \frac{\sin(\pi - A - C)}{2\sin C} = \frac{\sin(A + C)}{2\sin C} = \frac{\sin A\cos C + \cos A\sin C}{2\sin C}$ ①，
> >
> > 因为 $\sin A = \frac{4}{5}$ ，且 $\triangle ABC$ 是锐角三角形，所以 $\cos A = \sqrt{1 - \sin^2 A} = \frac{3}{5}$ ，
> >
> > 代入式①整理得： $\frac{b}{2c} = \frac{4\cos C + 3\sin C}{10\sin C} = \frac{2}{5\tan C} +\frac{3}{10},$
> >
> > 下面由 $\triangle ABC$ 是锐角三角形分析 $C$ 的范围, $A$ 是已知的非特殊锐角, 故只需再考虑 $B$ 和 $C$ ,
> >
> > $\triangle ABC$ 是锐角三角形 $\Rightarrow \left\{ \begin{array}{l}0 < B = \pi -A - C <   \frac{\pi}{2}\\ 0 <   C <   \frac{\pi}{2} \end{array} \right.$ ，解得： $\frac{\pi}{2} -A <   C <   \frac{\pi}{2}$
> >
> > 所以 $\tan C > \tan \left(\frac{\pi}{2} - A\right) = \frac{\sin \left(\frac{\pi}{2} - A\right)}{\cos \left(\frac{\pi}{2} - A\right)} = \frac{\cos A}{\sin A} = \frac{3}{4}$ ，另一方面，因为 $C$ 可无限接近 $\frac{\pi}{2}$ ，所以 $\tan C$ 能趋于 $+\infty$ ，故 $0 < \frac{1}{\tan C} < \frac{4}{3}$ ，所以 $\frac{3}{10} < \frac{2}{5\tan C} + \frac{3}{10} < \frac{5}{6}$ ，即 $\frac{3}{10} < \frac{b}{2c} < \frac{5}{6}$ .
>
> > [!tip]- **【反思】**
> > - **①**：虽然 A 不是特殊角，但知道了 $\sin A$ 和 $\cos A$ ，依然可以消元；
> > - **②**：对 C 的范围限定有难度，由于 A 不是特殊角，所以 C 的范围无法给出具体度数，故用 A 来表示，也能求出 $\tan C$ 的范围.
