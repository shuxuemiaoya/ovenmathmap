> [!faq]- 《1解三角形中的化角类问题》参考答案
>
> > [!success]- **【答案】** ${15}^{ \circ }$
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > 解析：已知 $B$ ，可求出 $A$ 和 $C$ 的关系，用来将所给的关于 $A$ 和 $C$ 的方程消元， $B = 150^{\circ}\Rightarrow A + C = 180^{\circ} - B = 30^{\circ}$ 所以 $0^{\circ} <   C <   30^{\circ}$ ，且 $A = 30^{\circ} - C$ ，故 $\sin A + \sqrt{3}\sin C =$
> >
> > $$
> > \sin (3 0 ^ {\circ} - C) + \sqrt {3} \sin C = \frac {1}{2} \cos C - \frac {\sqrt {3}}{2} \sin C + \sqrt {3} \sin C
> > $$
> >
> > $$
> > = \frac {1}{2} \cos C + \frac {\sqrt {3}}{2} \sin C = \sin (C + 3 0 ^ {\circ}) = \frac {\sqrt {2}}{2},
> > $$
> >
> > 因为 $0^{\circ} < C < 30^{\circ}$ ，所以 $30^{\circ} < C + 30^{\circ} < 60^{\circ}$
> >
> > 结合 $\sin (C + 30^{\circ}) = \frac{\sqrt{2}}{2}$ 可得 $C + 30^{\circ} = 45^{\circ}$ ，故 $C = 15^{\circ}$ .
