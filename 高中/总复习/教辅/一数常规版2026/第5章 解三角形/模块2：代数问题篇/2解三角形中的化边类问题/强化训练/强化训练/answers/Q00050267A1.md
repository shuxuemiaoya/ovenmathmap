> [!faq]- 《2解三角形中的化边类问题》参考答案
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > ## 8. (2023·广东模拟·★★★☆)
> >
> > 已知锐角 $\triangle ABC$ 的内角 $A, B, C$ 的对边分别为 $a, b, c, \frac{\sqrt{3}c}{b\cos A} = \tan A + \tan B$ .
> >
> > (1) 求 B;
> >
> > （2）若 $c = 4$ ，求 $\triangle ABC$ 面积的取值范围.
> >
> > 解：（1）（条件等式显然不方便全部角化边，但有边的齐次分式，故考虑用正弦定理边化角分析）
> > 由 $\frac{\sqrt{3}c}{b\cos A} = \tan A + \tan B$ 得 $\frac{\sqrt{3}\sin C}{\sin B\cos A} = \tan A + \tan B$ ①，
> > （接下来弦化切较难，考虑将右侧切化弦）
> > 又 $\tan A + \tan B = \frac{\sin A}{\cos A} + \frac{\sin B}{\cos B} = \frac{\sin A \cos B + \sin B \cos A}{\cos A \cos B}$ $=\frac{\sin(A+B)}{\cos A\cos B}=\frac{\sin(\pi-C)}{\cos A\cos B}=\frac{\sin C}{\cos A\cos B}$ 代入①得 $\frac{\sqrt{3}\sin C}{\sin B\cos A}=\frac{\sin C}{\cos A\cos B}$ ②，
> > 由△ABC为锐角三角形可得0<C< $\frac{\pi}{2}$ ，所以sinC>0，
> > 故在②两端约去 $\frac{\sin C}{\cos A}$ 可得 $\frac{\sqrt{3}}{\sin B}=\frac{1}{\cos B}$ 所以 $\tan B = \sqrt{3}$ ，结合 $0 < B < \frac{\pi}{2}$ 可得 $B = \frac{\pi}{3}$ .
> >
> > (2) 解法 1: (已知 B 和 c, 求面积把它们都用起来)
> >
> > 由题意， $S_{\triangle ABC} = \frac{1}{2} ac\sin B = \sqrt{3} a$ ③，
> >
> > （故核心是求 $a$ 的范围，怎样用边来翻译 $\triangle ABC$ 为锐角三角形这一条件？事实上，该条件等价于 $\cos A > 0, \cos B > 0$ 且 $\cos C > 0$ 再结合余弦定理推论即可翻译成边）
> >
> > 因为 $\triangle ABC$ 为锐角三角形，所以 $\left\{ \begin{array}{l} \cos A = \frac{b^2 + c^2 - a^2}{2bc} > 0 \\ \cos B = \frac{a^2 + c^2 - b^2}{2ac} > 0 \\ \cos C = \frac{a^2 + b^2 - c^2}{2ab} > 0 \end{array} \right.$
> >
> > 故 $\left\{ \begin{array}{l} b^{2} + c^{2} - a^{2} > 0 \\ a^{2} + c^{2} - b^{2} > 0 \\ a^{2} + b^{2} - c^{2} > 0 \end{array} \right.$ (已知 $c$ ，且要求的是 $a$ 的范围，故考虑将 $b$ 用 $a$ 表示，可由余弦定理建立二者关系)由余弦定理， $b^{2} = a^{2} + c^{2} - 2ac\cos B$ ，
> > 将 $B = \frac{\pi}{3}$ ， $c = 4$ 代入得 $b^{2} = a^{2} - 4a + 16$ ，代入④⑤⑥得 $\left\{ \begin{array}{l} a^{2} - 4a + 16 + 16 - a^{2} > 0 \\ a^{2} + 16 - (a^{2} - 4a + 16) > 0, \\ a^{2} + a^{2} - 4a + 16 - 16 > 0 \end{array} \right.$ 解法2：（按解法1得到式③后，也可考虑将 $a$ 边化角，借助角来分析）因为 $\frac{a}{\sin A} = \frac{c}{\sin C}$ ，所以 $a = \frac{c\sin A}{\sin C} = \frac{4\sin A}{\sin C}$ ，代入③得 $S_{\triangle ABC} = \frac{4\sqrt{3}\sin A}{\sin C}$ ⑦，
> > （式⑦中有 $A$ ， $C$ 两个变量，可用它们的关系消元）
> > 因为 $B = \frac{\pi}{3}$ ，所以 $A + C = \pi - B = \frac{2\pi}{3}$ ，故 $A = \frac{2\pi}{3} - C$ ，
> > 代入④得 $S_{\triangle ABC} = \frac{4\sqrt{3}\sin\left(\frac{2\pi}{3} - C\right)}{\sin C}$ $= \frac{4\sqrt{3}\left(\frac{\sqrt{3}}{2}\cos C + \frac{1}{2}\sin C\right)}{\sin C} = \frac{6}{\tan C} + 2\sqrt{3}$ ⑧，
> > 因为△ABC是锐角三角形，所以 $\left\{ \begin{array}{l} 0 < A = \frac{2\pi}{3} - C < \frac{\pi}{2}\\ 0 < C < \frac{\pi}{2} \end{array} \right.$ ，从而 $\frac{\pi}{6} < C < \frac{\pi}{2}$ ，故 $\tan C > \frac{\sqrt{3}}{3}$ ，所以 $0 < \frac{1}{\tan C} < \sqrt{3}$ ，代入⑧得 $2\sqrt{3} < S_{\triangle ABC} < 8\sqrt{3}$ ，所以△ABC面积的取值范围是 $(2\sqrt{3},8\sqrt{3})$ 。
