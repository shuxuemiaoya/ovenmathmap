> [!faq]- 《2解三角形中的化边类问题》例题解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > (2) 若 $\frac{1}{2}bc\sin A = 4\sqrt{3}$ ，求 $a$ 的取值范围.
> >
> > $$
> > B = \sin [ \pi - (A + C) ] = \sin (A + C) = \sin A \cos C + \cos A \sin C
> > $$
> >
> > $$
> > 2 \sin B - \sin C = 2 \sin A \cos C
> > $$
> >
> > $$
> > 2 (\sin A \cos C + \cos A \sin C) - \sin C = 2 \sin A \cos C
> > $$
> >
> > $$
> > \sin C (2 \cos A - 1) = 0 \quad ①
> > $$
> >
> > $$
> > 0 <   C <   \pi
> > $$
> >
> > $$
> > \sin C > 0
> > $$
> >
> > $$
> > 2 \cos A - 1 = 0
> > $$
> >
> > $$
> > \cos A = \frac {1}{2}
> > $$
> >
> > $$
> > 0 <   A <   \pi
> > $$
> >
> > $$
> > A = \frac {\pi}{3}
> > $$
> >
> > $$
> > A = \frac {\pi}{3}
> > $$
> >
> > $$
> > \frac {1}{2} b c \sin A = 4 \sqrt {3}
> > $$
> >
> > $$
> > \frac {\sqrt {3}}{4} b c = 4 \sqrt {3}
> > $$
> >
> > $$
> > b c = 1 6
> > $$
> >
> > $$
> > a ^ {2} = b ^ {2} + c ^ {2} - 2 b c \cos A = b ^ {2} + c ^ {2} - b c \geq 2 b c - b c = b c = 1 6
> > $$
> >
> > $$
> > a \geq 4
> > $$
> >
> > $$
> > b = c = 4
> > $$
> >
> > $$
> > [ 4, + \infty)
> > $$
>
> > [!tip]- **【反思】**
> > 余弦定理是沟通 $a^2$ ， $b + c$ 和 $bc$ 的桥梁，所以涉及相关最值，可考虑运用余弦定理.
