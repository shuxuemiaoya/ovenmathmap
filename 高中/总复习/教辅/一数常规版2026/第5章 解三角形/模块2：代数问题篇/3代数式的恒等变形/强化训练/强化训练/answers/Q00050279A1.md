> > [!note]- **【解析】**
> > ## 6. (2024·全国甲卷·★★★☆)
> >
> > 记△ABC 的内角 A, B, C 的对边分别为 a, b, c，已知 $B = \frac{\pi}{3}$ ， $b^{2} = \frac{9}{4} ac$ ，则 $\sin A + \sin C = (\quad)$ A. $\frac{3}{2}$ B. $\sqrt{2}$ C. $\frac{\sqrt{7}}{2}$ D. $\frac{\sqrt{3}}{2}$
> >
> > $$
> > b ^ {2} = \frac {9}{4} a c
> > $$
> >
> > $$
> > b ^ {2} = \frac {9}{4} a c
> > $$
> >
> > $$
> > \sin^ {2} B = \frac {9}{4} \sin A \sin C
> > $$
> >
> > $$
> > B = \frac {\pi}{3}
> > $$
> >
> > $$
> > \sin A \sin C = \frac {1}{3}
> > $$
> >
> > 到此容易想到利用 $A + C = \frac{2\pi}{3}$ 将上式消元，求出 $A$ ，再得到 $C$ 但经尝试， $A,C$ 不是特殊角，怎么办呢？看到已知的 $\sin A\sin C$ 和所求的 $\sin A + \sin C$ ，想到配方，需要 $\sin^2 A + \sin^2 C$ ，有平方，于是又想到对 $B$ 用余弦定理，由余弦定理， $b^{2} = a^{2} + c^{2} - 2ac\cos B$ ，结合 $B = \frac{\pi}{3}$ 可得 $b^{2} = a^{2} + c^{2} - ac$ ，所以 $\sin^2 B = \sin^2 A + \sin^2 C - \sin A\sin C$ ，从而 $(\sin A + \sin C)^2 -3\sin A\sin C = \sin^2 B = \frac{3}{4}$ 故 $(\sin A + \sin C)^2 = \frac{3}{4} +3\sin A\sin C = \frac{7}{4}$ ，又 $A,C\in (0,\pi)$ 所以 $\sin A + \sin C > 0$ ，故 $\sin A + \sin C = \frac{\sqrt{7}}{2}$
