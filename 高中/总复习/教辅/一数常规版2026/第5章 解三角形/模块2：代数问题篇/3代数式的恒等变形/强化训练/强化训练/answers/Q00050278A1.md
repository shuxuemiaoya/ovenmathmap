> [!faq]- 《3代数式的恒等变形》参考答案
>
> > [!success]- **【答案】** B
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > B
> > 解析：因为 $\sin(C-B)=2\sin B\cos C$ 所以 $\sin C \cos B - \cos C \sin B = 2 \sin B \cos C$ 故 $\sin C \cos B = 3 \sin B \cos C$ ①,
> >
> > $2\sin A + b\sin B = c\sin C$ 的边不齐次，不能边化角，故只能角化边，于是把式①也角化边，联合分析，因为 $2\sin A + b\sin B = c\sin C$ ，所以 $2a + b^{2} = c^{2}$ ，故 $c^{2} - b^{2} = 2a$ ②，由式①可得： $c \cdot \frac{a^{2} + c^{2} - b^{2}}{2ac} = 3b \cdot \frac{a^{2} + b^{2} - c^{2}}{2ab}$ ，整理得： $a^{2} = 2(c^{2} - b^{2})$ ③，将式②代入式③消去 $c^{2} - b^{2}$ 可得： $a^{2} = 4a$ ，所以 $a = 4$ 或0（舍去）.
