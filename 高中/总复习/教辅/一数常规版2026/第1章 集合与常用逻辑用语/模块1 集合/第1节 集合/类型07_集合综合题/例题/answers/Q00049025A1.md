> [!faq]- 《第1节 集合》例题解析
>
> > [!success]- **【答案】** D
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > 解析：已知 B，求 $A \cap B$ 只差 A，而求 A 需从题干的信息弄懂什么是一位正整数自恋数，一位正整数有 1, 2, 3, …, 9，它们都满足所有数位上数字的 1 次方和等于这个数本身，所以它们都是自恋数，故 $A = \{1, 2, 3, 4, 5, 6, 7, 8, 9\}$ ，又 $B = \{x \mid -3 < x < 4, x \in Z\} = \{-2, -1, 0, 1, 2, 3\}$ ，所以 $A \cap B = \{1, 2, 3\}$ ，故 $A \cap B$ 的子集个数为 $2^{3} = 8$ 。
