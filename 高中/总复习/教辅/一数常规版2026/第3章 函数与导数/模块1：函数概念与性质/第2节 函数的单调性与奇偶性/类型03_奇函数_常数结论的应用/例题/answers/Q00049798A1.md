> [!faq]- 《第2节 函数的单调性与奇偶性》例题解析
>
> > [!success]- **【答案】** -2
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > 解析：涉及 $f(a)$ 和 $f(-a)$ ，想到奇偶性。观察发现 $y = \ln (\sqrt{1 + x^2} - x)$ 是奇函数，故可按例4的方法处理，
> >
> > 设 $g(x) = \ln (\sqrt{1 + x^2} -x)(x\in \mathbf{R})$ ，则 $g(-x) + g(x) = \ln (\sqrt{1 + (-x)^2} +x) + \ln (\sqrt{1 + x^2} -x)$
> >
> > $= \ln [(\sqrt{1 + x^2} +x)(\sqrt{1 + x^2} -x)] = \ln (1 + x^2 -x^2) = \ln 1 = 0$ ，所以 $g(x)$ 为奇函数，
> >
> > 而 $f(x) = g(x) + 1$ ，所以 $f(a) + f(-a) = g(a) + 1 + g(-a) + 1 = 2$ ，故 $f(-a) = 2 - f(a) = -2$
>
> > [!tip]- **【反思】**
> > - **①**：本题的“奇函数+常数”结构隐含在解析式中；
> > - **②**：$y=\log_{a}(\sqrt{m^{2}x^{2}}+1\pm mx)$ 是较常见的奇函数.
