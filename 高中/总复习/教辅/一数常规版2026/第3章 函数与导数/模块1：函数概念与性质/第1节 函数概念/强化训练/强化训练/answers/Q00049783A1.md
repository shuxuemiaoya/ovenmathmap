> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > 解析：$f(x+1)$ 定义域为 $[-1,0] \Rightarrow -1 \leq x \leq 0 \Rightarrow 0 \leq x + 1 \leq 1$ ,
> > 因为括号范围恒不变，所以 $0 \leq \lg x \leq 1$ ，从而 $1 \leq x \leq 10$ ，
> > 故 $f(\lg x)$ 的定义域是 [1,10].
