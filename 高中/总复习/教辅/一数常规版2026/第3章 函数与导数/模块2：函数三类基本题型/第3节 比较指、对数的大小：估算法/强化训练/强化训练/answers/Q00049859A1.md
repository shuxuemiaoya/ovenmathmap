> [!faq]- 《第3节 比较指、对数的大小：估算法》参考答案
>
> > [!success]- **【答案】** A
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > 解析：要比较 $a, b, c$ ，考虑先解出它们，并粗略估算范围，
> >
> > 由题意， $1 < a = \sqrt[3]{2} < 2$ ， $b = \log_26 > 2$ ， $1 < c = \log_38 < 2$ ，所以 $b$ 最大，因为 $a, c$ 都在1和2之间，所以要比较 $a$ 和 $c$ 的大小，可以试试以 $\frac{3}{2}$ 作为中间量。考虑到 $a = \sqrt[3]{2} = 2^{\frac{1}{3}}$ ，为了将指数整数化，将其立方并与 $\left(\frac{3}{2}\right)^3$ 比较，因为 $\left(\frac{3}{2}\right)^3 = \frac{27}{8} > a^3 = 2$ ，所以 $a < \frac{3}{2}$ 又 $c = \log_38 > \log_3(3\sqrt{3}) = \frac{3}{2}$ ，所以 $a < c$ ，故 $a < c < b$ 。
