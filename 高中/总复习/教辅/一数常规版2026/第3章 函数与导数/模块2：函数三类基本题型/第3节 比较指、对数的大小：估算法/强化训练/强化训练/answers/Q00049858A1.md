> [!faq]- 《第3节 比较指、对数的大小：估算法》参考答案
>
> > [!success]- **【答案】** D
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > 解析：题干专门给了个 $c=\frac{4}{3}$ ，可能是中间量的提示，于是我们就把 a 和 b 跟 c 比较一下，看能不能选出答案，
> > 因为 $c=\frac{4}{3}=\log_{3}3^{\frac{4}{3}}$ ，所以要比较 a 和 c 的大小，
> > 只需比较 4 和 $3^{\frac{4}{3}}$ 的大小，可将它们同时立方，
> > 因为 $4^{3}=64<\left(3^{\frac{4}{3}}\right)^{3}=3^{4}=81$ ，所以 $4<3^{\frac{4}{3}}$ 从而 $\log_{3}4 < \log_{3}3^{\frac{4}{3}} = \frac{4}{3}$ ，故 a < c；
> > 又 $\frac{4}{3}=\log_{5}5^{\frac{4}{3}}$ ，所以要比较 b 和 c 的大小，只需比较 9 和 $5^{\frac{4}{3}}$ 的大小，因为 $9^{3}=729>\left(5^{\frac{4}{3}}\right)^{3}=5^{4}=625$ ，所以 $9>5^{\frac{4}{3}}$ 从而 $\log_{5}9 > \log_{5}5^{\frac{4}{3}} = \frac{4}{3}$ ，故 b > c，所以 a < c < b。
