> > 解析：观察发现 a, b 底数相同，可用指数函数的单调性来比较大小，因为 4.2 > 1，所以 $f(x) = 4.2^{x}$ 在 R 上 $\nearrow$ ，又 -0.3 < 0.3，所以 $0 < f(-0.3) < f(0.3)$ ，
> > 从而 $0 < 4.2^{-0.3} < 4.2^{0.3}$ ，故 0 < a < b，
> > 又因为 $c = \log_{4.2} 0.2 < 0$ ，所以 c < a < b，故 b > a > c。
