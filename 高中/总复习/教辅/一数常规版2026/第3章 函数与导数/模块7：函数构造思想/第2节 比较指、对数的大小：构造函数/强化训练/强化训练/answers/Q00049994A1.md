> [!faq]- 《第2节 比较指、对数的大小：构造函数》参考答案
>
> > [!success]- **【答案】** （2022·浙江月考·★★☆）已知 $a = 2^{\frac{4}{5}}$ ， $b = 4^{\frac{2}{7}}$ ， $c = 25^{\frac{1}{5}}$ ，则（）A. $b < a < c$ B. $a < b < c$ C. $b < c < a$ D. $c < a < b$
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > 解析：观察三个数的结构可发现 $a$ ， $b$ 底数有猫腻，考虑化同底； $a$ ， $c$ 指数有猫腻，考虑化同指，故先把它们化同底、同指，再构造指数函数和幂函数来比较， $b = 4^{\frac{2}{7}} = (2^{2})^{\frac{2}{7}} = 2^{\frac{4}{7}}$ ，函数 $f(x) = 2^{x}$ 在 $\mathbf{R}$ 上 $\nearrow$ ，所以 $f\left(\frac{4}{7}\right) < f\left(\frac{4}{5}\right)$ ，从而 $2^{\frac{4}{7}} < 2^{\frac{4}{5}}$ ，故 $b < a$ ； $a = 2^{\frac{4}{5}} = (2^{2})^{\frac{2}{5}} = 4^{\frac{2}{5}}$ ， $c = 25^{\frac{1}{5}} = (5^{2})^{\frac{1}{5}} = 5^{\frac{2}{5}}$ ，函数 $g(x) = x^{\frac{2}{5}}$ 在 $(0, + \infty)$ 上 $\nearrow$ ，所以 $a < c$ ，故 $4^{\frac{2}{5}} < 5^{\frac{2}{5}}$ ；所以 $b < a < c$ ：
