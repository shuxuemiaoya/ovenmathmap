> [!faq]- 《第2节 比较指、对数的大小：构造函数》例题解析
>
> > [!success]- **【答案】** >
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > 解析：b，c 的结构不同，故考虑从数字入手分析，不妨试试先将 c 也调整为含 $\frac{1}{9}$ 的结构，由题意， $c = -\ln 0.9 = -\ln \frac{9}{10} = \ln \frac{10}{9} = \ln \left(1 + \frac{1}{9}\right)$ ,
> >
> > 数字 $\frac{1}{9}$ 在 $b, c$ 中都有出现，将其看成 $x$ ，则 $b = x$ ， $c = \ln(1 + x)$ ，由此联想到经典切线放缩不等式，我们知道， $\ln x \leq x - 1$ ，取等条件是 $x = 1$ ，将 $x$ 换成 $1 + x$ 可得 $\ln(1 + x) \leq x$ ，当且仅当 $x = 0$ 时等号成立，令 $x = \frac{1}{9}$ 可得 $\ln\left(1 + \frac{1}{9}\right) < \frac{1}{9}$ ，所以 $c < b$ ，故 $b > c$ 。
>
> > [!tip]- **【反思】**
> > 有的比大小问题，命制的思路就是在诸如 $\ln x \leq x - 1$ ， $\mathrm{e}^x \geq x + 1$ 等经典切线放缩不等式中将 $x$ 换成一些切点附近的数字。例如，在 $\mathrm{e}^x \geq x + 1$ 中取 $x = 0.1$ ，又可以命制出比较 $\mathrm{e}^{0.1}$ 与 1.1 大小的题目。
