# 模块七 函数构造思想

## 第1节 原函数构造（★★★☆）

## 内容提要

若题干给出一个含 $f'(x)$ 的不等式，让我们求解另外的与 $f(x)$ 有关的不等式，这类题往往需要从所给不等式出发，构造一个原函数（若 $F'(x) = f(x)$ ，则称 $F(x)$ 为 $f(x)$ 的原函数），并判断其单调性，用单调性来分析与 $f(x)$ 有关的不等式。下面归纳一些常见的构造。

<table><tr><td>已知的不等式中所含结构</td><td>构造原函数的方法</td></tr><tr><td> $xf'(x) + f(x)$ </td><td> $F(x) = xf(x),\quad F'(x) = f(x) + xf'(x)$ </td></tr><tr><td> $xf'(x) - f(x)$ </td><td> $F(x) = \frac{f(x)}{x},\quad F'(x) = \frac{xf'(x) - f(x)}{x^2}$ </td></tr><tr><td> $xf'(x) + 2f(x)$ </td><td> $F(x) = x^2f(x),\quad F'(x) = x[xf'(x) + 2f(x)]$ </td></tr><tr><td> $xf'(x) - 2f(x)$ </td><td> $F(x) = \frac{f(x)}{x^2},\quad F'(x) = \frac{xf'(x) - 2f(x)}{x^3}$ </td></tr><tr><td> $f(x) + f'(x)$ </td><td> $F(x) = e^x f(x),\quad F'(x) = e^x [f(x) + f'(x)]$ </td></tr><tr><td> $f(x) - f'(x)$ </td><td> $F(x) = \frac{f(x)}{e^x},\quad F'(x) = \frac{f'(x) - f(x)}{e^x}$ </td></tr><tr><td> $f'(x)\sin x + f(x)\cos x$ </td><td> $F(x) = f(x)\sin x,\quad F'(x) = f'(x)\sin x + f(x)\cos x$ </td></tr><tr><td> $f'(x)\cos x - f(x)\sin x$ </td><td> $F(x) = f(x)\cos x,\quad F'(x) = f'(x)\cos x - f(x)\sin x$ </td></tr><tr><td> $f'(x)\sin x - f(x)\cos x$ </td><td> $F(x) = \frac{f(x)}{\sin x},\quad F'(x) = \frac{f'(x)\sin x - f(x)\cos x}{\sin^2 x}$ </td></tr><tr><td> $f'(x)\cos x + f(x)\sin x$ </td><td> $F(x) = \frac{f(x)}{\cos x},\quad F'(x) = \frac{f'(x)\cos x + f(x)\sin x}{\cos^2 x}$ </td></tr></table>

提醒：高中数学并没有系统性地学习不定积分，高考对求导逆运算（构造原函数）的要求并不高，不需要钻研一些特别复杂的构造，掌握常见的几种构造形式即可.
