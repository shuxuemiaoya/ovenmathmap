> > [!note]- **【解析】**
> > 解：由题意， $f'(x) = -\frac{(x + 1)(x - 2)}{\mathrm{e}^x}$ ，所以 $f'(x) > 0 \Leftrightarrow -1 < x < 2$ ， $f'(x) < 0 \Leftrightarrow x < -1$ 或 $x > 2$ ，从而 $f(x)$ 的单调递增区间为 $(-1, 2)$ ，单调减区间为 $(- \infty, -1)$ ， $(2, +\infty)$ ，故 $f(x)$ 有极小值 $f(-1) = -\mathrm{e}$ ，极大值 $f
> > (2) = \frac{5}{\mathrm{e}^2}$ .
>
> > [!tip]- **【反思】**
> > 当函数有多个单调递增区间（或递减区间）时，不要用并集符号连接，用逗号隔开即可.
