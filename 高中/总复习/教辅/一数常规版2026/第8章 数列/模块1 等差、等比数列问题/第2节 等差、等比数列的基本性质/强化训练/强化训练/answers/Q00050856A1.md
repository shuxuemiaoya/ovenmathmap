> [!faq]- 《第2节 等差、等比数列的基本性质》参考答案
>
> > [!success]- **【答案】** C
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > （2024·九省联考·★★）记等差数列 $\{a_{n}\}$ 的前 $n$ 项和为 $S_{n}$ ， $a_{3} + a_{7} = 6$ ， $a_{12} = 17$ ，则 $S_{16} = (\quad)$ A. 120 B. 140 C. 160 D. 180
> >
> > 解法1：已知条件容易代公式，故可直接用公式翻译，建立关于 $a_1$ 和 $d$ 的方程组，求出 $a_1$ 和 $d$ ，那么 $S_{16}$ 也就有了，设等差数列 $\{a_n\}$ 的公差为 $d$ ，则由题意， $\left\{ \begin{array}{l} a_3 + a_7 = a_1 + 2d + a_1 + 6d = 2a_1 + 8d = 6 \\ a_{12} = a_1 + 11d = 17 \end{array} \right.$ ，解得： $a_1 = -5$ ， $d = 2$ ，所以 $S_{16} = 16a_1 + \frac{16 \times 15}{2} d = 16a_1 + 120d = 16 \times (-5) + 120 \times 2 = 160$ 。解法2：已知 $a_{12}$ ，则按 $S_{16} = \frac{16(a_1 + a_{16})}{2} = \frac{16(a_5 + a_{12})}{2} = 8(a_5 + a_{12})$ 求 $S_{16}$ 只差 $a_5$ ，观察发现由已知的 $a_3 + a_7 = 6$ 可用下标和性质快速求出 $a_5$ ，于是可按此速算答案，由题意， $a_3 + a_7 = 2a_5 = 6$ ，所以 $a_5 = 3$ ，又 $a_{12} = 17$ ，所以 $S_{16} = \frac{16(a_1 + a_{16})}{2} = \frac{16(a_5 + a_{12})}{2} = 8(a_5 + a_{12}) = 8 \times (3 + 17) = 160$ 。
