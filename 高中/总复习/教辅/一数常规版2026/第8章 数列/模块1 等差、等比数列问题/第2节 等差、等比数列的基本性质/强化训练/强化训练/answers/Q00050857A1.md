> [!faq]- 《第2节 等差、等比数列的基本性质》参考答案
>
> > [!success]- **【答案】** B
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > B解法1：已知和所求都容易用公式翻译，故直接代公式，再观察二者的联系，设 $\{a_{n}\}$ 的公差为 $d$ ，则 $\frac{S_{13}}{S_9} = \frac{13a_1 + \frac{13 \times 12}{2} d}{9a_1 + \frac{9 \times 8}{2} d}$ $= \frac{13a_1 + 78d}{9a_1 + 36d} = \frac{26}{9}$ ，化简得： $a_1 = -2d$ ，
> >
> > 所以 $\frac{a_7}{a_5} = \frac{a_1 + 6d}{a_1 + 4d} = \frac{-2d + 6d}{-2d + 4d} = \frac{4d}{2d} = 2$ 。
> >
> > 解法2：观察已知和所求可发现 $S_{13}$ 与 $a_7$ ， $S_9$ 与 $a_5$ 都可用 $S_{2n-1} = (2n - 1)a_n$ 来沟通彼此，故也可按此翻译已知，得到所求，因为 $\{a_n\}$ 是等差数列，所以 $S_{13} = \frac{13(a_1 + a_{13})}{2}$ $= \frac{13 \times 2a_7}{2} = 13a_7$ ，同理， $S_9 = 9a_5$ ，所以 $\frac{S_{13}}{S_9} = \frac{13a_7}{9a_5}$ ,
> >
> > 由题意， $\frac{S_{13}}{S_9} = \frac{26}{9}$ ，所以 $\frac{13a_7}{9a_5} = \frac{26}{9}$ ，故 $\frac{a_7}{a_5} = 2$ 。
