> [!faq]- 《第1节 等差、等比数列的基本公式》例题解析
>
> > [!success]- **【答案】** C
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > 解析：条件与所求都容易代公式，故直接用公式处理，由题意， $\left\{ \begin{array}{l}a_{1} + a_{3} = a_{1} + a_{1}q^{2} = a_{1}(1 + q^{2}) = 1\\ a_{6} + a_{8} = a_{1}q^{5} + a_{1}q^{7} = a_{1}q^{5}(1 + q^{2}) = -32 \end{array} \right.$ 两式相除可得 $\frac{1}{q^5} = -\frac{1}{32}$ ，所以 $q^5 = -32$ ，故 $\frac{a_{10} + a_{12}}{a_5 + a_7} = \frac{a_1q^9 + a_1q^{11}}{a_1q^4 + a_1q^6} = \frac{a_1q^9(1 + q^2)}{a_1q^4(1 + q^2)} = q^5 = -32.$
