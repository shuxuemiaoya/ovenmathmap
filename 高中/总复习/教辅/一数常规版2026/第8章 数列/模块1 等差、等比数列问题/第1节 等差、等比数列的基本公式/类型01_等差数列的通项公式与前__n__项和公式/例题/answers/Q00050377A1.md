> [!faq]- 《第1节 等差、等比数列的基本公式》例题解析
>
> > [!success]- **【答案】** A
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > 解析：给的两个条件都容易用公式表示，故直接套用公式，即可求出 $a_{1}$ 和 $d$
> >
> > 因为 $\left\{ \begin{array}{l}a_{1} + a_{3} = 6\\ S_{5} = S_{3} + 11 \end{array} \right.$ ，所以 $\left\{ \begin{array}{l}2a_1 + 2d = 6\\ 5a_1 + 10d = 3a_1 + 3d + 11 \end{array} \right.$ ，解得： $\left\{ \begin{array}{l}a_1 = 2\\ d = 1 \end{array} \right.$
> >
> > 有了 $a_{1}$ 和 $d$ ，就能求出 $a_{n}$ 和 $S_{n}$ ，进而可将 $\frac{S_{n} + 8}{a_{n} - 1}$ 表示为关于 $n$ 的单变量函数，研究最值，所以 $a_{n} = a_{1} + (n - 1)d = n + 1$ ， $S_{n} = \frac{n(a_{1} + a_{n})}{2} = \frac{n(2 + n + 1)}{2} = \frac{n^{2}}{2} +\frac{3n}{2},$ 故 $\frac{S_n + 8}{a_n - 1} = \frac{\frac{n^2}{2} + \frac{3n}{2} + 8}{n + 1 - 1} = \frac{n}{2} +\frac{8}{n} +\frac{3}{2}\geq 2\sqrt{\frac{n}{2}\cdot\frac{8}{n}} +\frac{3}{2} = \frac{11}{2}$ ，取等条件是 $\frac{n}{2} = \frac{8}{n}$ ，即 $n = 4$ ，所以 $\left(\frac{S_n + 8}{a_n - 1}\right)_{\min} = \frac{11}{2}.$ 答案：A
