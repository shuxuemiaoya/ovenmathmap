> [!faq]- 《第1节 等差、等比数列的基本公式》例题解析
>
> > [!success]- **【答案】** B
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > 解析：已知条件和要求的量都容易用公式表示，直接套用公式翻译它们，
> >
> > 由题意， $a_2 + a_6 + a_7 = a_1 + d + a_1 + 5d + a_1 + 6d = 3a_1 + 12d = 18$ ，所以 $a_1 + 4d = 6$ ①，故 $\frac{1}{2} a_9 - a_7 = \frac{1}{2} (a_1 + 8d) - (a_1 + 6d) = -\frac{1}{2} a_1 - 2d = -\frac{1}{2} (a_1 + 4d)$ ，结合式①可得 $\frac{1}{2} a_9 - a_7 = -3.$
