> [!faq]- 《第1节 数列通项的核心求法》参考答案
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > 因为 $a_{n + 1} = 2a_{n} + n$ ，所以 $a_{n + 1} + (n + 1) + 1 = 2(a_n + n + 1)$ ①，
> > 又 $a_1 = 0$ ，所以 $a_1 + 1 + 1 = 2\neq 0$ 结合式①知数列 $\{a_n + n + 1\}$ 所有项均不为0，故 $\{a_{n} + n + 1\}$ 是首项和公比均为2的等比数列，所以 $a_{n} + n + 1 = 2^{n}$ 从而 $a_{n} = 2^{n} - n - 1$ ，故 $b_{n} = 2^{n} - a_{n} = n + 1$ 所以 $\frac{b_n - 1}{(b_n + 1)^2} = \frac{n + 1 - 1}{(n + 1 + 1)^2} = \frac{n}{n^2 + 4n + 4}$ $= \frac{1}{n + \frac{4}{n} + 4}\leq \frac{1}{2\sqrt{n\cdot\frac{4}{n}} + 4} = \frac{1}{8},$ 取等条件是 $n = \frac{4}{n}$ ，即 $n = 2$ ，所以 $\frac{b_n - 1}{(b_n + 1)^2}$ 的最大值为 $\frac{1}{8}$
