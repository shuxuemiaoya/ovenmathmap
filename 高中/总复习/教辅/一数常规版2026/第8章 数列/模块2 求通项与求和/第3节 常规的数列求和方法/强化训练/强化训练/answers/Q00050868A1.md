> [!faq]- 《第3节 常规的数列求和方法》参考答案
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > 解：（1）（要证 $\left\{\frac{1}{a_n}\right\}$ 是等差数列，只需证 $\frac{1}{a_{n+1}} - \frac{1}{a_n}$ 为常数，
> >
> > 可将条件中的递推公式代入，消去 $a_{n + 1}$ 并化简）
> >
> > 因为 $a_{n + 1} = \frac{a_n}{2a_n + 1}$ ，所以 $\frac{1}{a_{n + 1}} -\frac{1}{a_n} = \frac{2a_n + 1}{a_n} -\frac{1}{a_n} = \frac{2a_n}{a_n} = 2$
> >
> > 从而 $\left\{\frac{1}{a_n}\right\}$ 是首项 $\frac{1}{a_1} = 1$ ，公差为2的等差数列，
> >
> > 故 $\frac{1}{a_n} = 1 + (n - 1) \times 2 = 2n - 1$ ，所以 $a_n = \frac{1}{2n - 1}$ .
> >
> > （2）由（1）得 $b_{n} = \frac{4}{(2n - 1)[2(n + 2) - 1]} = \frac{4}{(2n - 1)(2n + 3)}$ ，
> >
> > (注意到分母是数列 $\{2n-1\}$ 的间隔项，故考虑裂项求和)
> >
> > 所以 $b_{n} = \frac{4}{(2n - 1)(2n + 3)} = \frac{1}{2n - 1} -\frac{1}{2n + 3}$ ，从而 $S_{n} =$
> >
> > $$
> > 1 - \frac {1}{5} + \frac {1}{3} - \frac {1}{7} + \frac {1}{5} - \frac {1}{9} + \dots + \frac {1}{2 n - 3} - \frac {1}{2 n + 1} + \frac {1}{2 n - 1} - \frac {1}{2 n + 3},
> > $$
> >
> > （为了看出抵消后剩哪些，可先将整个式子调整顺序，按符号进行分组）故 $S_{n}=\left(1+\frac{1}{3}+\frac{1}{5}+\cdots+\frac{1}{2n-3}+\frac{1}{2n-1}\right)-$ $\left(\frac{1}{5}+\frac{1}{7}+\frac{1}{9}+\cdots+\frac{1}{2n-1}+\frac{1}{2n+1}+\frac{1}{2n+3}\right)$ $=1+\frac{1}{3}-\frac{1}{2n+1}-\frac{1}{2n+3}=\frac{4}{3}-\frac{1}{2n+1}-\frac{1}{2n+3}$
