> [!faq]- 《第3节 常规的数列求和方法》参考答案
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > 解：（1）（已有 $b_{n+1} = 2b_n$ ，只需再求出 $\{b_n\}$ 中的任何一项，
> > 都可得到 $b_n$ 。已知 $a_2$ ，故在 $a_n + n^4 = b_n + (n+1)^4$ 中取 $n = 2$ 求 $b_2$ ）因为 $a_n + n^4 = b_n + (n+1)^4$ ，所以取 $n = 2$ 得 $a_2 + 16 = b_2 + 81$ ，结合 $a_2 = 66$ 可得 $b_2 = a_2 + 16 - 81 = 1$ ，
> > 又 $b_{n+1} = 2b_n$ ，所以 $\{b_n\}$ 是公比 $q = 2$ 的等比数列，
> > 从而 $b_1 = \frac{b_2}{q} = \frac{1}{2}$ ，故 $b_n = b_1q^{n-1} = \frac{1}{2} \times 2^{n-1} = 2^{n-2}$ 。
> > （2）将 $b_n = 2^{n-2}$ 代入 $a_n + n^4 = b_n + (n+1)^4$ 可得 $a_n + n^4 = 2^{n-2} + (n+1)^4$ ，所以 $a_n = 2^{n-2} + (n+1)^4 - n^4$ ，
> > （观察发现 $2^{n-2}$ 和 $(n+1)^4 - n^4$ 这两部分都能直接求和，故可将 $a_n$ 的和拆分成这两部分分别求和，再相加） $S_n = 2^{-1} + 2^4 - 1^4 + 2^0 + 3^4 - 2^4 + 2^1 + 4^4 - 3^4 + \cdots + 2^{n-2} + (n+1)^4 - n^4 = (2^-1 + 2^0 + 2^1 + \cdots + 2^{n-2}) + [2^4 - 1^4 + 3^4 - 2^4 + 4^4 - 3^4 + \cdots + (n+1)^4 - n^4] = \frac{2^{-1}(1 - 2^n)}{1 - 2} + [-1^4 + 2^4 - 2^4 + 3^4 - 3^4 + 4^4 - \cdots - n^4 + (n+1)^4] = 2^{n-1} - 2^{-1} + (n+1)^4 - 1 = 2^{n-1} + (n+1)^4 - \frac{3}{2}$ 。
