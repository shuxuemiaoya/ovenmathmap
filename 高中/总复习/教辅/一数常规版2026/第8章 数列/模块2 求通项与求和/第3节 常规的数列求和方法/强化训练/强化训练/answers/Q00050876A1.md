> [!faq]- 《第3节 常规的数列求和方法》参考答案
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > 解：（1）（把 $na_{n}$ 看作 $c_{n}$ ，则所给递推公式属于 $c_{n+1}-c_{n}=f(n)$ 这种结构，可先用累加法求出 $c_{n}$ ）
> >
> > 设 $c_{n}=na_{n}$ ，则 $c_{1}=a_{1}=1$ ，且 $(n+1)a_{n+1}-na_{n}=2n+1$ 即为 $c_{n+1}-c_{n}=2n+1$ ，所以当 $n\geq2$ 时， $\left\{\begin{aligned}c_{2}-c_{1}&=3\\ c_{3}-c_{2}&=5\\ &\cdots\\ &c_{n}-c_{n-1}&=2n-1\end{aligned}\right.$ 以上各式相加得 $c_{n}-c_{1}=3+5+7+\cdots+(2n-3)+(2n-1)$ ，
> >
> > 所以 $c_{n}=c_{1}+3+5+7+\cdots+(2n-3)+(2n-1)=1+3+5+7+\cdots+(2n-3)+(2n-1)=\frac{n(1+2n-1)}{2}=n^{2}$ ，
> >
> > 从而 $na_{n}=n^{2}$ ，故 $a_{n}=n$ ，
> >
> > 又 $a_{1}=1$ 也满足上式，所以 $\forall n\in N^{*}$ ，都有 $a_{n}=n$ 。
> >
> > （2）由（1）可得 $b_{n}=\left[\lg a_{n}\right]=\left[\lg n\right]$ ，
> >
> > （要求 $T_{2022}$ ，可先分析 $b_{n}$ 的取值情况，寻找规律）
> >
> > 当 $1\leq n\leq9$ 时， $0\leq\lg n<1$ ，所以 $b_{n}=\left[\lg n\right]=0$ ；
> >
> > 当 $10\leq n\leq99$ 时， $1\leq\lg n<2$ ，所以 $b_{n}=\left[\lg n\right]=1$ ；
> >
> > 当 $100 \leq n \leq 999$ 时， $2 \leq \lg n < 3$ ，所以 $b_{n} = [\lg n] = 2$ ；
> >
> > 当 $1000 \leq n \leq 2022$ 时， $3 \leq \lg n < 4$ ，所以 $b_{n} = [\lg n] = 3$ ；
> >
> > 故 $T_{2022} = 1 \times 90 + 2 \times 900 + 3 \times 1023 = 4959$ .
