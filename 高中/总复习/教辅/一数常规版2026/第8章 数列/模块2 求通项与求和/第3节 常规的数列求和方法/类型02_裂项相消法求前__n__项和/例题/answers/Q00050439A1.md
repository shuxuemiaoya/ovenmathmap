> [!faq]- 《第3节 常规的数列求和方法》例题解析
>
> > [!success]- **【答案】** $\frac{2n}{2n + 1}$
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > 解析：$a_{n} = a_{n-1} + 2 \Rightarrow$ 数列 $\{a_{n}\}$ 是公差 $d = 2$ 的等差数列，结合 $a_{1} = 1$ 可得 $a_{n} = a_{1} + (n-1)d = 2n-1$ ，注意到 $\frac{2}{a_{n} a_{n+1}}$ 中的 $a_{n}$ 和 $a_{n+1}$ 是 $\{a_{n}\}$ 的相邻项，这种情况常用裂项求和，故将其拆成两项之差，所以 $\frac{2}{a_{n} a_{n+1}} = \frac{2}{(2n-1)(2n+1)} = \frac{1}{2n-1} - \frac{1}{2n+1}$ ，故 $S_{n} = \left(1 - \frac{1}{3}\right) + \left(\frac{1}{3} - \frac{1}{5}\right) + \left(\frac{1}{5} - \frac{1}{7}\right) + \cdots + \left(\frac{1}{2n-3} - \frac{1}{2n-1}\right) + \left(\frac{1}{2n-1} - \frac{1}{2n+1}\right) = 1 - \frac{1}{2n+1} = \frac{2n}{2n+1}$ .
