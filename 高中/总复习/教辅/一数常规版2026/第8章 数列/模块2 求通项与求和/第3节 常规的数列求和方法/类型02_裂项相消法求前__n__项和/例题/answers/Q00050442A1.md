> [!faq]- 《第3节 常规的数列求和方法》例题解析
>
> > [!success]- **【答案】** $\sqrt{n + 1} -1$
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > 解析：分母的 $\sqrt{n}$ 和 $\sqrt{n + 1}$ 是 $\{\sqrt{n}\}$ 的第 $n$ 项和第 $n + 1$ 项，故考虑裂项，分母有理化即可裂项，
> >
> > 由题意， $a_{n} = \frac{1}{\sqrt{n} + \sqrt{n + 1}} = \frac{\sqrt{n + 1} - \sqrt{n}}{(\sqrt{n} + \sqrt{n + 1})(\sqrt{n + 1} - \sqrt{n})} = \sqrt{n + 1} -\sqrt{n} = -\sqrt{n} +\sqrt{n + 1},$
> >
> > 所以 $S_{n}=-\sqrt{1}+\sqrt{2}-\sqrt{2}+\sqrt{3}-\sqrt{3}+\sqrt{4}-\cdots-\sqrt{n-1}+\sqrt{n}-\sqrt{n}+\sqrt{n+1}=-\sqrt{1}+\sqrt{n+1}=\sqrt{n+1}-1$
