> [!faq]- 《第4节 数列拔高小题专项》参考答案
>
> > [!success]- **【答案】** C
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > C
> >
> > 解析：观察发现选项均与 $\{b_n\}$ 有关，故考虑由所给的两个关系式消去与 $\{a_n\}$ 有关的项再看，因为 $\{a_n\}$ 各项都为正数，且 $a_{n}^{2} = b_{n}b_{n + 1}$ 所以 $a_{n} = \sqrt{b_{n}b_{n + 1}}$ ，故 $a_{n + 1} = \sqrt{b_{n + 1}b_{n + 2}}$ ，代入 $a_{n} + a_{n + 1} = 2b_{n + 1}$ 可得 $\sqrt{b_nb_{n + 1}} +\sqrt{b_{n + 1}b_{n + 2}} = 2b_{n + 1}$ 所以 $\sqrt{b_n} +\sqrt{b_{n + 2}} = 2\sqrt{b_{n + 1}}$ ，故 $\{\sqrt{b_n}\}$ 是等差数列.
