> [!faq]- 《第4节 数列拔高小题专项》参考答案
>
> > [!success]- **【答案】** 16
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > 解析：给出 $a_n$ 与 $S_n$ 混搭的关系式，要分析的是 $\left\{\frac{1}{S_n}\right\}$ 的前80项和，故考虑将 $a_n$ 换成 $S_n - S_{n-1}$ ，消去 $a_n$ ，因为 $a_n + 2S_{n-1} = \frac{1}{a_n}$ ，所以 $S_n - S_{n-1} + 2S_{n-1} = \frac{1}{S_n - S_{n-1}}$ ，从而 $S_n^2 - S_{n-1}^2 = 1 (n \geq 2)$ ，故 $\{S_n^2\}$ 是公差为1的等差数列，又 $a_1 = 1$ ，所以 $S_1^2 = a_1^2 = 1$ ，故 $S_n^2 = 1 + (n - 1) \times 1 = n$ ，因为 $\{a_n\}$ 是正项数列，所以 $S_n > 0$ ，从而 $S_n = \sqrt{n}$ ，故 $\frac{1}{S_n} = \frac{1}{\sqrt{n}}$ ；观察发现 $\left\{\frac{1}{S_n}\right\}$ 无法求和，故考虑放缩，由 $\frac{1}{\sqrt{n}}$ 联想到可裂项的结构 $\frac{1}{\sqrt{n} + \sqrt{n+1}}$ 和 $\frac{1}{\sqrt{n} + \sqrt{n-1}}$ ，一方面， $\frac{1}{S_n} = \frac{1}{\sqrt{n}} = \frac{2}{\sqrt{n} + \sqrt{n}} > \frac{2}{\sqrt{n} + \sqrt{n+1}} = \frac{2(\sqrt{n+1} - \sqrt{n})}{(\sqrt{n} + \sqrt{n+1})(\sqrt{n+1} - \sqrt{n})} = 2(-\sqrt{n} + \sqrt{n+1})$ ，所以 $\frac{1}{S_1} + \frac{1}{S_2} + \cdots + \frac{1}{S_{80}} > 2(-\sqrt{1} + \sqrt{2} - \sqrt{2} + \sqrt{3} - \sqrt{3} + \sqrt{4} - \cdots - \sqrt{80} + \sqrt{81}) = 2(-1 + \sqrt{81}) = 16$ ；另一方面， $\frac{1}{S_n} = \frac{1}{\sqrt{n}} = \frac{2}{\sqrt{n} + \sqrt{n}} < \frac{2}{\sqrt{n} + \sqrt{n-1}} = \frac{2(\sqrt{n} - \sqrt{n-1})}{(\sqrt{n} + \sqrt{n-1})(\sqrt{n} - \sqrt{n-1})} = 2(-\sqrt{n-1} + \sqrt{n})$ ，所以 $\frac{1}{S_1} + \frac{1}{S_2} + \cdots + \frac{1}{S_{80}} < 2(-\sqrt{0} + \sqrt{1} - \sqrt{1} + \sqrt{2} - \sqrt{2} + \sqrt{3} - \cdots - \sqrt{79} + \sqrt{80}) = 2\sqrt{80} = 8\sqrt{5}$ ；由于 $17 < 8\sqrt{5} < 18$ ，所以 $8\sqrt{5}$ 这部分可能放缩过度了，为了提高精度，可尝试从第二项起开始放缩， $\frac{1}{S_1} + \frac{1}{S_2} + \cdots + \frac{1}{S_{80}} = 1 + \frac{1}{S_2} + \cdots + \frac{1}{S_{80}} < 1 + 2(-\sqrt{1} + \sqrt{2} - \sqrt{2} + \sqrt{3} - \cdots - \sqrt{79} + \sqrt{80}) = 1 + 2(-1 + 4\sqrt{5}) = 8\sqrt{5} - 1$ ，所以 $16 < \frac{1}{S_1} + \frac{1}{S_2} + \cdots + \frac{1}{S_{80}} < 8\sqrt{5} - 1 < 17$ ，故 $\left[\frac{1}{S_1} + \frac{1}{S_2} + \cdots + \frac{1}{S_{80}}\right] = 16.$
>
> > [!tip]- **【反思】**
> > 在对通项进行放缩后，若发现求和的精度不够，可尝试少放缩几项，例如从第二项或从第三项开始放缩，以提高精度.
