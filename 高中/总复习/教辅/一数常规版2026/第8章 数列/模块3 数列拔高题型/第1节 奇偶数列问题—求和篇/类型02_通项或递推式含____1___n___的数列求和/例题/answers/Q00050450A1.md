> [!faq]- 《第1节 奇偶数列问题—求和篇》例题解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > 解：（递推式中有 $(-1)^n$ 这一结构，考虑分奇偶讨论）当 $n$ 为奇数时， $a_{n + 2} - a_n = (-1)^n +3$ 即为 $a_{n + 2} - a_n = 2$ （若不懂上式的含义，可代一些值去看，将 $n = 1$ ，3，5分别代入可得 $a_3 - a_1 = 2$ ， $a_5 - a_3 = 2$ ， $a_7 - a_5 = 2$ 我们发现 $\{a_n\}$ 的奇数项构成公差 $d = 2$ 的等差数列）
> >
> > 所以 $a_1 + a_3 + \dots + a_{19} = 10a_1 + \frac{10 \times (10 - 1)}{2} d = 20 + 45 \times 2 = 110$ ；
> >
> > 当 $n$ 为偶数时， $a_{n+2} - a_n = (-1)^n + 3$ 即为 $a_{n+2} - a_n = 4$ ，所以 $\{a_n\}$ 的偶数项构成公差 $d' = 4$ 的等差数列，
> >
> > $$
> > a _ {2} + a _ {4} + \dots + a _ {2 0} = 1 0 a _ {2} + \frac {1 0 \times (1 0 - 1)}{2} d ^ {\prime} = 4 0 + 4 5 \times 4 = 2 2 0
> > $$
> >
> > 所以 $a_1 + a_2 + \dots + a_{20} = (a_1 + a_3 + \dots + a_{19}) + (a_2 + a_4 + \dots + a_{20}) = 110 + 220 = 330$ .
>
> > [!tip]- **【反思】**
> > 当递推公式中含有 $(-1)^n$ 这种结构时，往往需要通过分奇偶讨论，化简递推式，再进行分析.
