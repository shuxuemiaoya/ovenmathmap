>
> > [!success]- **【答案】** C

> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > 答案 C 解析 $y' = 3x^2 + 3x = 3x(x + 1)$ ，易知当 $-1 < x < 0$ 时， $y' < 0$ ，当 $-2 < x < -1$ 或 $0 < x < 1$ 时， $y' > 0$ ，所以函数 $y = x^3 + \frac{3}{2}x^2 + m$ 在 $(-2, -1)$ ， $(0, 1)$ 上单调递增，在 $(-1, 0)$ 上单调递减，又当 $x = -1$ 时， $y = m + \frac{1}{2}$ ，当 $x = 1$ 时， $y = m + \frac{5}{2}$ ，所以最大值为 $m + \frac{5}{2} = \frac{9}{2}$ ，解得 $m = 2$ 。
