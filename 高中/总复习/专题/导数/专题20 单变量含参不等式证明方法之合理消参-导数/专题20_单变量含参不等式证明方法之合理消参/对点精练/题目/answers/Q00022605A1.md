> [!faq]- 教师版对点精练解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > 解析 (1) $\because a = 0$ 时， $\therefore f(x) = \mathrm{e}^x - \ln x, f'(x) = \mathrm{e}^x - \frac{1}{x} (x > 0), \therefore f(1) = \mathrm{e}, f'(1) = \mathrm{e} - 1,$ $\therefore$ 函数 $f(x)$ 的图象在 $(1, f(1))$ 处的切线方程为： $y - \mathrm{e} = (\mathrm{e} - 1)(x - 1)$ ，即 $(\mathrm{e} - 1)x - y + 1 = 0.$ (2) $\because f'(x) = \mathrm{e}^{x + a} - \frac{1}{x} (x > 0)$ ，设 $g(x) = f'(x)$ ，则 $g'(x) = \mathrm{e}^{x + a} + \frac{1}{x^2} > 0, \therefore g(x)$ 是增函数， $\because \mathrm{e}^{x + a} > \mathrm{e}^a, \therefore$ 由 $\mathrm{e}^a > \frac{1}{x} x > \mathrm{e}^{-a}, \therefore$ 当 $x > \mathrm{e}^{-a}$ 时， $f'(x) > 0;$ 若 $0 < x < 1 \Rightarrow \mathrm{e}^{x + a} < \mathrm{e}^{a + 1}$ ，由 $\mathrm{e}^{a + 1} < \frac{1}{x} \Rightarrow x < \mathrm{e}^{-a - 1}, \therefore$ 当 $0 < x < \min \{1, \mathrm{e}^{-a - 1}\}$ 时， $f'(x) < 0$ 故 $f(x) = 0$ 仅有一解，记为 $x_0$ ，则当 $0 < x < x_0$ 时， $f'(x) < 0, f(x)$ 递减；当 $x > x_0$ 时， $f(x) > 0, f(x)$ 递增； $\therefore f(x)_{\min} = f(x_0) = \mathrm{e}^{x_0 + a} - \ln x_0$ ，而 $f'(x_0) = \mathrm{e}^{x_0 + a} - \frac{1}{x_0} = 0 \Rightarrow \mathrm{e}^{x_0 + a} = \frac{1}{x_0} \Rightarrow a = -\ln x_0 - x_0,$ 记 $h(x) = \ln x + x$ ，则 $f(x_0) = \frac{1}{x_0} - \ln x_0 = h\left(\frac{1}{x_0}\right), a > 1 - \frac{1}{\mathrm{e}} \Leftrightarrow -a < \frac{1}{\mathrm{e}} - 1 \Leftrightarrow h(x_0) < h\left(\frac{1}{\mathrm{e}}\right)$ ，而 $h(x)$ 显然是增函数， $\therefore 0 < x_0 < \frac{1}{\mathrm{e}} \Leftrightarrow \frac{1}{x_0} > \mathrm{e}, \therefore h\left(\frac{1}{x_0}\right) > h(\mathrm{e}) = \mathrm{e} + 1.$ 综上，当 $a > 1 - \frac{1}{\mathrm{e}}$ 时， $f(x) > \mathrm{e} + 1.$
