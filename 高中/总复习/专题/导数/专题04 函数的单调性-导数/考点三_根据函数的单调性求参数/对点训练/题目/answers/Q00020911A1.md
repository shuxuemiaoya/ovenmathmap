> [!faq]- 教师版对点训练解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > 答案 $(0, 1) \cup (2, 3)$ 解析 由题意知 $f'(x) = -x + 4 - \frac{3}{x} = \frac{-x^2 + 4x - 3}{x} = -\frac{(x - 1)(x - 3)}{x}$ ，由 $f'(x) = 0$ 得函数 $f(x)$ 的两个极值点为 1，3，则只要这两个极值点有一个在区间 $(t, t + 1)$ 内，函数 $f(x)$ 在区间 $[t, t + 1]$ 上就不单调，由 $t < 1 < t + 1$ 或 $t < 3 < t + 1$ ，得 $0 < t < 1$ 或 $2 < t < 3$ 。
