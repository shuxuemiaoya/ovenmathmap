> [!faq]- 教师版对点训练解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > 答案 $\left[0, \frac{1}{2}\right] \cup [2, +\infty)$ 解析 由 $f(x)$ 图象特征可得，在 $\left[-\infty, \frac{1}{2}\right]$ 和 $[2, +\infty)$ 上 $f'(x) \geq 0$ ，在 $\left[\frac{1}{2}, 2\right]$ 上 $f'(x) < 0$ ，所以 $xf'(x) \geq 0 \Leftrightarrow \begin{cases} x \geq 0, \\ f'(x) \geq 0 \end{cases}$ 或 $\left\{ \begin{array}{l} x \leq 0, \\ f'(x) \leq 0 \end{array} \right.$ $\Leftrightarrow 0 \leq x \leq \frac{1}{2}$ 或 $x \geq 2$ ，所以 $xf'(x) \geq 0$ 的解集为 $\left[0, \frac{1}{2}\right] \cup [2, +\infty)$ .
