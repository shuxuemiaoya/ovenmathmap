> [!faq]- 《专题04 函数的单调性-导数》例题解析
>
> > [!success]- **【答案】** D
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > (2)$ ， $c = f(\log_27)$ ，则 $a, b, c$ 的大小关系是（）A. $a < b < c$ B. $c < a < b$ C. $b < a < c$ D. $b < c < a$
> > 2. 答案 D 解析 根据题意，函数 $f(x) = 3x + 2\cos x$ ， $f'(x) = 3 - 2\sin x$ ，因为 $f'(x) = 3 - 2\sin x > 0$ 在 $\mathbf{R}$ 上恒成立，所以 $f(x)$ 在 $\mathbf{R}$ 上为增函数。又由 $2 = \log_24 < \log_27 < 3 < 3\sqrt{2}$ ，则 $b < c < a$ 。
> >
> > 故选 **D**.
