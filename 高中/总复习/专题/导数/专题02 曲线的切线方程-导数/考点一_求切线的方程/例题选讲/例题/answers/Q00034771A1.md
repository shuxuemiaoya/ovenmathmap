>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > 答案 $5x - y + 2 = 0$ 解析 $y' = \left(\frac{2x - 1}{x + 2}\right)' = \frac{2(x + 2) - (2x - 1)}{(x + 2)^2} = \frac{5}{(x + 2)^2}$ ，所以 $y'|_{x=-1} = \frac{5}{(-1 + 2)^2} = 5$ ，所以切线方程为 $y + 3 = 5(x + 1)$ ，即 $5x - y + 2 = 0$ 。
