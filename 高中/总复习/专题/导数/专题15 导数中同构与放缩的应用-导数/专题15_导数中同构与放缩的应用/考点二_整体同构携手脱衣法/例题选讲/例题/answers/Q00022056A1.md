> [!faq]- 教师版例题解析
>
> > [!success]- **【答案】** (1) $a > \mathrm{e}^{\frac{1}{\mathrm{e}}}$
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > 答案 $a > \mathrm{e}^{\frac{1}{\mathrm{e}}}$ 解析 $a^x >\log_a x\Leftrightarrow \mathrm{e}^{x\ln a} > \frac{\ln x}{\ln a}\Leftrightarrow (x\ln a)\mathrm{e}^{x\ln a} > x\ln x\Leftrightarrow$ $\left\{ \begin{array}{ll}(x\ln a)\mathrm{e}^{x\ln a} > (\ln x)\mathrm{e}^{\ln x}\rightarrow f(x) = xe^{x}\\ \mathrm{e}^{x\ln a}\ln \mathrm{e}^{x\ln a} > x\ln x\to f(x) = x\ln x\\ x\ln a + \ln (x\ln a) > \ln x + \ln (\ln x)\to f(x) = x + \ln x \end{array} \right.$ (1)(2）（三种模式，只要写一种），由(3)得， $x\ln a > \ln x$ ，
> > 即 $\ln a > \frac{\ln x}{x}$ ，由导数法可得 $\ln a > \frac{1}{\mathrm{e}}$ ，从而所以 $a > \mathrm{e}^{\frac{1}{\mathrm{e}}}$ 。
> > 解析 $m\ln (x + 1) - 3(x + 1) > mx - 3\mathrm{e}^{x} = m\ln \mathrm{e}^{x} - 3\mathrm{e}^{x}$ (同构)，令 $g(x) = m\ln x - 3x$ ，由 $g(x + 1) > g(\mathrm{e}^x)$ ，且 $1 <   x + 1 <   \mathrm{e}^x$ ，知 $g(x)$ 在 $(1, + \infty)$ 为减函数，所以 $g^{\prime}(x) = \frac{m}{x} -3\leq 0\Rightarrow m\leq 3x\Rightarrow m\leq 3$ ：故选C.
> > 解析 $2a\mathrm{e}^{2x} - \ln x + \ln a\geq 0\Leftrightarrow 2a\mathrm{e}^{2x}\geq \ln \frac{x}{a}\Leftrightarrow 2x\mathrm{e}^{2x}\geq \frac{x}{a}\ln \frac{x}{a}\Leftrightarrow 2x + \ln 2x\geq \ln \frac{x}{a} +\ln (\ln \frac{x}{a})$ （积型同构取对数），令 $f(x) = x + \ln x$ ，则 $f(x)$ 为增函数，由 $f(2x)\geq f(\ln \frac{x}{a})$ ，得 $2x\geq \ln \frac{x}{a}$ ，即 $a\geq \frac{x}{\mathrm{e}^{2x}}$ 恒成立，令 $g(x) = \frac{x}{\mathrm{e}^{2x}}$ 则 $g^{\prime}(x) = \frac{1 - 2x}{\mathrm{e}^{2x}}$ ，易得 $g(x)_{\max} = g(\frac{1}{2}) = \frac{1}{2\mathrm{e}}$ ，所以实数 $a$ 的最小值为 $\frac{1}{2\mathrm{e}}$
> > 解析 $f(x) = \mathrm{e}^{x} - a\ln (ax - a) - a > 0\Leftrightarrow \frac{1}{a}\mathrm{e}^{x} > \ln a(x - 1) - 1\Leftrightarrow \mathrm{e}^{x - \ln a} - \ln a > \ln (x - 1) - 1\Leftrightarrow \mathrm{e}^{x - \ln a} + x-$ $\ln a > \mathrm{e}^{\ln (x - 1)} + \ln (x - 1)$ （和差型同构），令 $g(x) = \mathrm{e}^x +x$ ，显然 $g(x)$ 为增函数，则原命题等价于 $g(x - \ln a)>$ $g(\ln (x - 1))\Leftrightarrow x - \ln a > \ln (x - 1)\Leftrightarrow \ln a <   x - \ln (x - 1)$ ，由于 $x - \ln (x - 1)\geq x - (x - 2)$ ，所以 $\ln a <   2$ ，即得 $0 <   a <   \mathrm{e}^2$
> > 解析 $a(\mathrm{e}^{ax}+1)\geq2(x+\frac{1}{x})\ln x\Leftrightarrow ax(\mathrm{e}^{ax}+1)\geq(x^{2}+1)\ln x^{2}\Leftrightarrow(\mathrm{e}^{ax}+1)\ln\mathrm{e}^{ax}\geq(x^{2}+1)\ln x^{2}$ (积型同构)，令 $f(x)=(x+1)\ln x$ ，则 $f'(x)=\ln x+\frac{x+1}{x}$ ， $f''(x)=\frac{1}{x}-\frac{1}{x^{2}}=\frac{x-1}{x^{2}}$ ，易知 $f'(x)$ 在 $(0,1)$ 上递减，在 $(1,+\infty)$ 上递增，所以 $f'(x)>f'(1)=2>0$ ，所以 $f(x)$ 在 $(0,+\infty)$ 上单调递增，则 $(\mathrm{e}^{ax}+1)\ln\mathrm{e}^{ax}\geq(x^{2}+1)\ln x^{2}\Leftrightarrow f(\mathrm{e}^{ax})\geq f(x^{2})\Leftrightarrow\mathrm{e}^{ax}\geq x^{2}\Leftrightarrow ax\geq2\ln x\Leftrightarrow a\geq\frac{2\ln x}{x}$ ，由导数法易证 $\frac{2\ln x}{x}\leq\frac{2}{e}$ ，所以 $a\geq\frac{2}{e}$ .
> > 解析 $x + a\ln x + \frac{1}{\mathrm{e}^x}\geq x^a\Leftrightarrow x + \frac{1}{\mathrm{e}^x}\geq x^a -a\ln x = x^a -\ln x^a\Leftrightarrow \mathrm{e}^{-x} - \ln \mathrm{e}^{-x}\geq x^{a} - \ln x^{a}$ ，令 $f(x) = x - \ln x$ 则 $f^{\prime}(x) = \frac{x - 1}{x}$ ，易知 $f(x)$ 在(0,1)上递减，在 $(1, + \infty)$ 上递增，所以 $f(\mathrm{e}^{-x})\geq f(x^{a})$ ， $\because x\in (1, + \infty)$ ， $\mathrm{e}^{-x}\in (0,\frac{1}{\mathrm{e}})$ .根据选项只讨论 $a <   0$ 的情况，当 $a <   0$ 时， $x^{a}\in (0,1)$ ， $\therefore \mathrm{e}^{-x}\leq x^{a}$ ， $\therefore a\geq \frac{-x}{\ln x}$ .令 $h(x) = \frac{-x}{\ln x}$ 则 $h^\prime (x) = \frac{1 - \ln x}{(\ln x)^2}$ ，所以 $h(x)$ 在(1,e)上递增，在(e, $+\infty)$ 上递减，则 $h(x)_{\max} = h(\mathrm{e}) = -\mathrm{e}$ ，即 $a\geq -\mathrm{e}$ ，
> >
> > 故选 **C**.
