> [!faq]- 教师版例题解析
>
> > [!success]- **【答案】** (1) 1；(2) $0 < a \leq 1$；(3) $0 \leq a \leq e$；(4) $a \leq b$；(5) $a \geq \frac{1}{\mathrm{e}}$；(6) $k \leq e - 1$；(7) $(- \infty, \frac{1}{\mathrm{e}}]$；(8) (e, +∞)
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > 答案 1 解析 $x\mathrm{e}^{x} - ax - \ln x - 1 \geq 0$ 恒成立 $\Leftrightarrow a \leq \left(\frac{x\mathrm{e}^{x} - \ln x - 1}{x}\right)_{\min} \Leftrightarrow \frac{x\mathrm{e}^{x} - \ln x - 1}{x} = \frac{\mathrm{e}^{x + \ln x} - \ln x - 1}{x}$ $\geq \frac{x + \ln x + 1 - \ln x - 1}{x} = 1$ ，当且仅当 $x + \ln x = 0$ 等号成立.
> > 答案 $0 < a \leq 1$ 解析 $x\mathrm{e}^{x} - a(x + \ln x + 1) \geq 0 \Leftrightarrow x\mathrm{e}^{x} - a(x + \ln x + 1) \geq 0 \Leftrightarrow \mathrm{e}^{x + \ln x} \geq a(x + \ln x + 1)$ ，当 $x + \ln x + 1 \leq 0$ 时，原不等式恒成立，当 $x + \ln x + 1 > 0$ 时， $a \leq \frac{\mathrm{e}^{x + \ln x}}{x + \ln x + 1}$ ，由于 $\frac{\mathrm{e}^{x + \ln x}}{x + \ln x + 1} \geq \frac{x + \ln x + 1}{x + \ln x + 1} = 1$ ，当且仅当 $x + \ln x = 1$ 等号成立，所以 $a \leq 1$ ，故 $0 < a \leq 1$ 。
> > 答案 $0 \leq a \leq e$ 解析 $xe^{x} - a(x + \ln x) \geq 0 \Leftrightarrow xe^{x} - a(x + \ln x) \geq 0 \Leftrightarrow e^{x + \ln x} \geq a(x + \ln x) \Leftrightarrow e^{t} \geq at$ (令
> > $$
> > t = x + \ln x) \Leftrightarrow \left\{ \begin{array}{l} a \geq \frac {\mathrm{e} ^ {t}}{t} (t <   0) \\ a \leq \frac {\mathrm{e} ^ {t}}{t} (t > 0) \end{array} \right. \Leftrightarrow \left\{ \begin{array}{l} a \geq 0 \\ a \leq \mathrm{e} \end{array} \right. \Leftrightarrow 0 \leq a \leq \mathrm{e}.
> > $$
> > 答案 $a \leq b$ 解析 $f(x) \geq 0 \Leftrightarrow x^b \mathrm{e}^x \geq a \ln x + x + 1 \Leftrightarrow \mathrm{e}^{x + b \ln x} - x - 1 \geq a \ln x \Leftrightarrow a \leq \frac{\mathrm{e}^{x + b \ln x} - x - 1}{\ln x}$ ，由于 $\frac{\mathrm{e}^{x + b \ln x} - x - 1}{\ln x} \geq \frac{x + b \ln x + 1 - x - 1}{\ln x} = b$ ，当且仅当 $x + b \ln x = 0$ 等号成立，所以 $a \leq b$ 。
> > 答案 $a \geq \frac{1}{\mathrm{e}}$ 解析 $a\mathrm{e}^{x} - \ln x - 1 \geq 0 \Leftrightarrow a \geq \frac{\ln x + 1}{\mathrm{e}^{x}}$ ，由于 $\ln x + 1 \leq x, \mathrm{e}^{x} \geq \mathrm{e}x$ ，两者都是当且仅当 $x = 1$ 等号成立，则 $\frac{\ln x + 1}{\mathrm{e}^{x}} \geq \frac{x}{\mathrm{e}x} = \frac{1}{\mathrm{e}}$ ，所以 $a \geq \frac{1}{\mathrm{e}}$ 。
> > 答案 $k \leq e - 1$ 解析 $\mathrm{e}^{x} - 1 \geq kx + \ln x \Leftrightarrow k \leq \frac{\mathrm{e}^{x}}{x} - \frac{\ln x}{x}$ ，由于 $\mathrm{e}^{x} \geq \mathrm{e}x$ ， $\ln x \leq x$ ，两者都是当且仅当 $x = 1$ 等号成立，所以 $\frac{\mathrm{e}^{x}}{x} \geq \mathrm{e}$ ， $\frac{\ln x}{x} \leq 1$ 则 $\frac{\mathrm{e}^{x}}{x} - \frac{\ln x}{x} \geq \mathrm{e} - 1$ ，所以 $k \leq \mathrm{e} - 1$ 。
> > 答案 $(- \infty, \frac{1}{\mathrm{e}}]$ 解析 $x \mathrm{e}^{-ax} + ax - \ln x - 1 = \mathrm{e}^{-ax + \ln x} + ax - \ln x - 1 \geq -ax + \ln x + 1 + ax - \ln x - 1 = 0$ ，当且仅当 $-ax + \ln x = 0$ ，即 $a = \frac{\ln x}{x}$ 时等号成立，由 $a = \frac{\ln x}{x}$ 有解，易得 $a \leq \frac{1}{\mathrm{e}}$ 。
> > 答案 (e, +∞) 解析 $f(x)=xe^{x}-a(x+\ln x)=\mathrm{e}^{x+\ln x}-a(x+\ln x)$ ，令 $t=x+\ln x, t\in R$ ，显然该函数单调递增，即 $e^{t}-at=0$ 有两个根，即 $a=\frac{e^{t}}{t}$ 有两个根，令 $g(t)=\frac{e^{t}}{t}$ ， $g(t)$ 在 $(-∞,1)$ 单调递减，在 $(1,+∞)$ 单调递增。∴ $g(t)_{\min}=g(1)=e$ ，a>e.
