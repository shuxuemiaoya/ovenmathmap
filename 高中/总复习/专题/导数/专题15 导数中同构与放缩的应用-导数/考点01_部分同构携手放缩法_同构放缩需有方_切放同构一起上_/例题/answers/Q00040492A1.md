> [!faq]- 《专题15 导数中同构与放缩的应用-导数》例题解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > 答案 -2 解析 $f(x) = \ln x + x - x\mathrm{e}^{x + 1} = x + \ln x - \mathrm{e}^{x + \ln x + 1} \leq x + \ln x - (x + \ln x + 2) = -2$ . (当且仅当 $x + \ln x + 1 = 0$ 取等号).
> > (2)函数 $f(x)=\mathrm{e}^{x}-\frac{\ln x+1}{x}$ 的最小值是 \_\_\_\_.
> > 答案 1 解析 $f(x) = \mathrm{e}^{x} - \frac{\ln x + 1}{x} = \frac{x\mathrm{e}^{x} - \ln x - 1}{x} = \frac{\mathrm{e}^{x + \ln x} - \ln x - 1}{x} \geq \frac{\ln x + x + 1 - \ln x - 1}{x} = 1$ (当且仅当 $x + \ln x = 0$ 取等号).
> > (3)函数 $f(x)=\frac{x^{2}e^{x}-2\ln x}{x+1}$ 的最小值是 \_\_\_\_.
> > 答案 1 解析 $f(x) = \frac{x^2\mathrm{e}^x - 2\ln x}{x + 1} = \frac{\mathrm{e}^{x + 2\ln x} - 2\ln x}{x + 1} \geq \frac{x + 2\ln x + 1 - 2\ln x}{x + 1} = 1$ (当且仅当 $x + 2\ln x = 0$ 取等号).
