A

![](../../images/questions/7f2fe0f78458f3c5775cfecd87c239e773737ece78a622dd9b1eea0e0c0becc1.jpg)

B

![](../../images/questions/0685c615214e507588f2b471d801d9fc41adf50fe722ba58b30a8c2ab5cd1c01.jpg)

C

![](../../images/questions/828b2d7482c679fda21ddeaec7e16856f25ad12c2ee6ff451724670f3055056b.jpg)

D

(1)答案 B 解析 因为 $f(x)$ 的定义域为 $\{x|x>-1, \text{且 } x\neq0\}$ ，所以排除选项 D．当 x>0 时，由经典不等式 $x>1+\ln x(x>0)$ ，以 $x+1$ 代替 x，得 $x>\ln(x+1)(x>-1, \text{且 } x\neq0)$ ，所以 $\ln(x+1)-x<0(x>-1, \text{且 } x\neq0)$ ，即 x>0 或 -1<x<0 时均有 $f(x)<0$ ，排除 A、C，易知 B 正确.
