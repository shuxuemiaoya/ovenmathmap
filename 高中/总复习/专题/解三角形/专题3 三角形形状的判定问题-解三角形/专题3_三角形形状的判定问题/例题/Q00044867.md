(10)已知 a, b, c 分别是 $\triangle ABC$ 三个内角 A, B, C 的对边．下列四个命题：

①若 $\tan A + \tan B + \tan C > 0$ ，则 $\triangle ABC$ 是锐角三角形；

②若 $a \cos A = b \cos B$ ，则 $\triangle ABC$ 是等腰三角形；

③若 $b \cos C + c \cos B = b$ ，则 $\triangle ABC$ 是等腰三角形；

④若 $\frac{a}{\cos A} = \frac{b}{\cos B} = \frac{c}{\cos C}$ ，则 $\triangle ABC$ 是等边三角形.
