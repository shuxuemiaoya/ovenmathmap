> [!faq]- 《专题3 三角形形状的判定问题-解三角形》例题解析
>
> > [!success]- **【答案】** D
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > 答案 D 解析 法一：由余弦定理及已知得 $a \times \frac{a^{2} + c^{2} - b^{2}}{2ac} + a \times \frac{a^{2} + b^{2} - c^{2}}{2ab} = b + c$ ，所以 $a^{2}b + c^{2}b - b^{3} + a^{2}c + b^{2}c - c^{3} = 2b^{2}c + 2bc^{2}$ ，得 $b^{2} + c^{2} = a^{2}$ ，故 $A = 90^{\circ}$ ，所以 $\triangle ABC$ 为直角三角形.
> > 法二:由正弦定理得 $a\cos B + a\cos C = b + c$ ，即 $\sin A\cos B + \sin A\cos C = \sin B + \sin C$ ，即 $\sin A\cos B + \sin A\cos C = \sin(A + C) + \sin(A + B)$ ，化简得 $\cos A(\sin B + \sin C) = 0$ ，在 $\triangle ABC$ 中， $\sin B + \sin C \neq 0$ ，则 $\cos A = 0$ ，所以 $\triangle ABC$ 为直角三角形.
