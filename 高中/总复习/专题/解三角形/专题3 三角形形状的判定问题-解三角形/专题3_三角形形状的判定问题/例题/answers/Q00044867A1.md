> [!faq]- 《专题3 三角形形状的判定问题-解三角形》例题解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > 答案 ①③④ 解析 命题①：∵ $\tan A + \tan B + \tan C = \tan A\tan B\tan C > 0$ ，∴A，B，C均为锐角，∴①正确；命题②：由 $a\cos A = b\cos B$ ，可得 $\sin 2A = \sin 2B$ ，∴A = B或 $A + B = \frac{\pi}{2}$ ，∴②错；命题③：可知 $\sin B\cos C + \sin C\cos B = \sin B$ ，∴ $\sin A = \sin B$ ，∴A = B，∴③正确；命题④：由已知和正弦定理，易知 $\tan A = \tan B = \tan C$ ，∴④正确.
