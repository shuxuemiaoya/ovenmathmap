> [!faq]- 《专题3 三角形形状的判定问题-解三角形》例题解析
>
> > [!success]- **【答案】** B
>
> > [!note]- **【解析】**
> > 答案 B 解析 由 $2a\cos B = c \Rightarrow 2a \cdot \frac{a^2 + c^2 - b^2}{2ac} = c \Rightarrow a^2 = b^2$ ，所以 $a = b$ 。因为 $\sin A \sin B(2 - \cos C) = \sin^2 \frac{C}{2} + \frac{1}{2}$ ，所以 $2\sin A \sin B(2 - \cos C) - 2 + 1 - 2\sin^2 \frac{C}{2} = 0$ ，所以 $2\sin A \sin B(2 - \cos C) - 2 + \cos C = 0$ ，所以 $(2 - \cos C)(2\sin A \sin B - 1) = 0$ ，因为 $\cos C \neq 2$ ，所以 $\sin A \sin B = \frac{1}{2}$ ，因为 $a = b$ ，所以 $\sin^2 A = \frac{1}{2}$ ，所以 $A = B = \frac{\pi}{4}$ ，所以 $\triangle ABC$ 是等腰直角三角形，
> >
> > 故选 **B**.
