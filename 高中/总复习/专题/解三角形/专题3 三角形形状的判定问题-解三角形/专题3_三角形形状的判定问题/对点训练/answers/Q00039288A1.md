> [!faq]- 《专题3 三角形形状的判定问题-解三角形》例题解析
>
> > [!success]- **【答案】** A
>
> > [!note]- **【解析】**
> > 答案 A 解析 $\because a^{2} + b^{2} - c^{2} = ab, \therefore \cos C = \frac{a^{2} + b^{2} - c^{2}}{2ab} = \frac{1}{2}$ , 又 $0 < C < \pi, \therefore C = \frac{\pi}{3}$ , 又由 $2\cos A\sin B = \sin C$ 得 $\sin (B - A) = 0, \therefore A = B$ , 故 $\triangle ABC$ 为等边三角形.
