> [!faq]- 《专题3 三角形形状的判定问题-解三角形》例题解析
>
> > [!success]- **【答案】** B
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > 答案 B 解析 由 $b \cos C + c \cos B = a \sin A$ ，得 $\sin B \cos C + \sin C \cos B = \sin^2 A$ ，即 $\sin (B + C) = \sin^2 A$ ，所以 $\sin A = 1$ ，由 $0 < A < \pi$ ，得 $A = \frac{\pi}{2}$ ，所以 $\triangle ABC$ 为直角三角形.
