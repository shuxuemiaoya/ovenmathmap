> [!faq]- 《专题3 三角形形状的判定问题-解三角形》例题解析
>
> > [!success]- **【答案】** B
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > 答案 B 解析 $\because 2\sin A\cos B = \sin C = \sin (A + B), \therefore 2\sin A\cos B = \sin A\cos B + \cos A\sin B, \therefore \sin (A - B) = 0.$ 又 $A, B$ 为 $\triangle ABC$ 的内角. $\therefore A = B, \therefore \triangle ABC$ 为等腰三角形.
