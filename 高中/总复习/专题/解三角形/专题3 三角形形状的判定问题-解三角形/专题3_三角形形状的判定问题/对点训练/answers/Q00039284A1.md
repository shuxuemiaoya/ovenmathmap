> [!faq]- 《专题3 三角形形状的判定问题-解三角形》例题解析
>
> > [!success]- **【答案】** C
>
> > [!note]- **【解析】**
> > ．答案 C 解析 $\because\frac{\sin A}{a}=\frac{\cos B}{b},\quad\therefore a\cos B=b\sin A,\quad\therefore2R\sin A\cos B=2R\sin B\sin A.$ 又 $2R\sin A\neq0,$ $\therefore \cos B = \sin B, \therefore B = 45^{\circ}.$ 同理 $C = 45^{\circ}$ ，故 $A = 90^{\circ}$ .
> >
> > 故选 **C**.
