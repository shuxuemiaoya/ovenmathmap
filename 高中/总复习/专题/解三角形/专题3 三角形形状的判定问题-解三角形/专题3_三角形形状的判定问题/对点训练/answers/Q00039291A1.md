> [!faq]- 《专题3 三角形形状的判定问题-解三角形》例题解析
>
> > [!success]- **【答案】** D
>
> > [!note]- **【解析】**
> > 答案 D 解析 由正弦定理，得 $\sin A = \frac{a}{2R}$ ， $\sin B = \frac{b}{2R}$ ， $\sin C = \frac{c}{2R}$ ， $\because \sin^2 A = \sin^2 B + \sin^2 C$ ， $\therefore \left(\frac{a}{2R}\right)^2$
> >
> > $= \left(\frac{b}{2R}\right)^2 +\left(\frac{c}{2R}\right)^2$ ，即 $a^2 = b^2 +c^2$ ，故 $A = 90^{\circ}$ ， $\therefore C = 90^{\circ} - B$ ，cos $C = \sin B$ . $\therefore 2\sin B\cdot \cos C = 2\sin^2 B = \sin$ $A = 1$ . $\therefore \sin B = \frac{\sqrt{2}}{2}$ . $\therefore B = 45^{\circ}$ 或 $B = 135^{\circ}(A + B = 225^{\circ} > 180^{\circ}$ ，故舍去)，∴△ABC是等腰直角三角形.16.在△ABC中，若 $\frac{bcosC}{ccosB} = \frac{1 + \cos 2C}{1 + \cos 2B}$ 则△ABC为（ A）A.锐角三角形 B.等腰三角形 C.直角三角形 D.等腰或者直角三角形
> >
> > 16. 答案 D 解析 由已知 $\frac{1 + \cos 2C}{1 + \cos 2B} = \frac{2\cos^2 C}{2\cos^2 B} = \frac{\cos^2 C}{\cos^2 B} = \frac{b\cos C}{c\cos B}$ 得 $\frac{\cos C}{\cos B} = \frac{b}{c}$ ，以下可有两种解法：法一：(利用正弦定理边化角)由正弦定理得 $\frac{b}{c} = \frac{\sin B}{\sin C}, \therefore \frac{\cos C}{\cos B} = \frac{\sin B}{\sin C}$ ，即 $\sin C\cos C = \sin B\cos B$ ，即 $\sin 2C = \sin 2B, \because B, C$ 均为 $\triangle ABC$ 的内角， $\therefore 2C = 2B$ 或 $2C + 2B = 180^\circ$ . $\therefore B = C$ 或 $B + C = 90^\circ, \therefore \triangle ABC$ 为等腰三角形或直角三角形。法二：(利用余弦定理角化边)由余弦定理得 $\frac{(a^2 + b^2 - c^2) \cdot 2ac}{(a^2 + c^2 - b^2) \cdot 2ab} = \frac{b}{c}$ ，即 $a^2(b^2 - c^2) = (b^2 + c^2)(b^2 - c^2)$ ，解得 $a^2 = b^2 + c^2$ 或 $b^2 = c^2$ (即 $b = c$ )
