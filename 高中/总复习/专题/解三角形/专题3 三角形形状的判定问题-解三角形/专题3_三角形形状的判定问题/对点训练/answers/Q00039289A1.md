> [!faq]- 《专题3 三角形形状的判定问题-解三角形》例题解析
>
> > [!success]- **【答案】** C
>
> > [!note]- **【解析】**
> > 答案 C 解析 由两直线平行可得 $b \cos B - a \cos A = 0$ ，由正弦定理可知 $\sin B \cos B - \sin A \cos A = 0$ ，即 $\frac{1}{2} \sin 2A = \frac{1}{2} \sin 2B$ ，又 $A, B \in (0, \pi)$ ，且 $A + B \in (0, \pi)$ ，所以 $2A = 2B$ 或 $2A + 2B = \pi$ ，即 $A = B$ 或 $A + B = \frac{\pi}{2}$ 。若 $A = B$ ，则 $a = b$ ， $\cos A = \cos B$ ，此时两直线重合，不符合题意，舍去，故 $A + B = \frac{\pi}{2}$ ，则 $\triangle ABC$ 是直角三角形。
> >
> > 故选 **C**.
