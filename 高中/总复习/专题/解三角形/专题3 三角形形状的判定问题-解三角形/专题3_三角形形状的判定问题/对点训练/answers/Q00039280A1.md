> [!faq]- 《专题3 三角形形状的判定问题-解三角形》例题解析
>
> > [!success]- **【答案】** C
>
> > [!note]- **【解析】**
> > 答案 等腰三角形或直角三角形 解析 由正弦定理，得 $\sin A\cos A = \sin B\cos B$ ，即 $\sin 2A = \sin 2B$ 所以 $2A = 2B$ 或 $2A = \pi - 2B$ ，即 $A = B$ 或 $A + B = \frac{\pi}{2}$ ，所以这个三角形为等腰三角形或直角三角形.
