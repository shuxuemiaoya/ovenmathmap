> [!faq]- 《专题3 三角形形状的判定问题-解三角形》例题解析
>
> > [!success]- **【答案】** D
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > 答案 C 解析 $\because c - a\cos B = (2a - b)\cos A, C = \pi - (A + B), \therefore$ 由正弦定理得 $\sin C - \sin A\cos B = 2\sin A\cos A - \sin B\cos A, \therefore \sin A\cos B + \cos A\sin B - \sin A\cos B = 2\sin A\cos A - \sin B\cos A, \therefore \cos A(\sin B - \sin A) = 0, \therefore \cos A = 0$ 或 $\sin B = \sin A, \therefore A = \frac{\pi}{2}$ 或 $B = A$ 或 $B = \pi - A$ (舍去), $\therefore \triangle ABC$ 为等腰或直角三角形.
