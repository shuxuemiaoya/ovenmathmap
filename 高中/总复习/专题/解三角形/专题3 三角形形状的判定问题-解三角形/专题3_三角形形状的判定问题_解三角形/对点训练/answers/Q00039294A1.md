> [!faq]- 《专题3 三角形形状的判定问题-解三角形》例题解析
>
> > [!success]- **【答案】** B
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > 答案 B 解析 ∵ 内角 A、B、C 成等差数列，∴ $A + C = 2B$ 。又 $A + B + C = \pi$ 。∴ $B = \frac{\pi}{3}$ ，由余弦定理得 $b^{2} = a^{2} + c^{2} - 2ac \cdot \cos B = a^{2} + c^{2} - ac$ 。又 $b^{2} = ac$ ，∴ $a^{2} + c^{2} - ac = ac$ ，即 $(a - c)^{2} = 0$ ，∴ a = c，又 $B = \frac{\pi}{3}$ ，∴ $\triangle ABC$ 为等边三角形；选 B。
