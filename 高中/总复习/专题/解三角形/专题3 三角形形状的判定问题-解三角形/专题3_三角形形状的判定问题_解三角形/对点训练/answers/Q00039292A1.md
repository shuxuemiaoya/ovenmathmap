> [!faq]- 《专题3 三角形形状的判定问题-解三角形》例题解析
>
> > [!success]- **【答案】** D
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > 答案 D 解析 在 $\triangle ABC$ 中，由 $a^2 = b^2 + c^2 - bc$ ，得 $\cos A = \frac{b^2 + c^2 - a^2}{2bc} = \frac{1}{2}$ ， $\therefore A = 60^\circ$ 。\$\because \sin B = \sqrt{3}\cos C, \therefore \sin (120^\circ - C) = \sqrt{3}\cos C\$，可得 $\frac{\sqrt{3}}{2}\cos C + \frac{1}{2}\sin C = \sqrt{3}\cos C$ ，即 $\tan C = \sqrt{3}$ 。 $\therefore C = 60^\circ$ 。 $\therefore \triangle ABC$ 是等边三角形。
