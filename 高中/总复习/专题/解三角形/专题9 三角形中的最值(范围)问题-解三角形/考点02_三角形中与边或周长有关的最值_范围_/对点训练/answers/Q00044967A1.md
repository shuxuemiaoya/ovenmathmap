> [!faq]- 《专题9 三角形中的最值(范围)问题-解三角形》例题解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【解析】**
> > 解析
> > (1)由正弦定理知， $\sin B\cos C+\sqrt{3}\sin B\sin C-\sin A-\sin C=0,$ $\because \sin A=\sin(B+C)=\sin B\cos C+\cos B\sin C$ ，代入上式得， $\sqrt{3}\sin B\sin C-\cos B\sin C-\sin C=0,$ $\because \sin C\neq0,\quad\therefore\sqrt{3}\sin B-\cos B-1=0$ ，即 $\sin(B-\frac{\pi}{6})=\frac{1}{2}$ ，因为 $0<B<\pi$ ，所以 $B=\frac{\pi}{3}.$
> >
> > (2)由
> > (1)得， $2R=\frac{b}{\sin B}=2,\quad2a+c=2R\sin A+2R\sin C=5\sin A+\sqrt{3}\cos A=2\sqrt{7}\sin(A+\Phi)$ ，其中，
> >
> > $\sin \phi = \frac{\sqrt{3}}{2\sqrt{7}}, \cos \phi = \frac{5}{2\sqrt{7}}$ ，因为 $0 < A < \frac{2\pi}{3}$ ，所以 $\sqrt{3} < 2\sqrt{7}\sin (A + \phi) < 2\sqrt{7}$ 。所以 $\sqrt{3} < 2a + c < 2\sqrt{7}$ 。
