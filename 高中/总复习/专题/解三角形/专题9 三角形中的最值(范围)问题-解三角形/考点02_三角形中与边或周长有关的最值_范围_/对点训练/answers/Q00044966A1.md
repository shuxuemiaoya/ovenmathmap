> [!faq]- 《专题9 三角形中的最值(范围)问题-解三角形》例题解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > (1)求角 $C$ 的大小；
> > (2)求 $a+b$ 的最大值.
> > 2. 解析
> > (1)由题意可知 $\frac{1}{2} ab\sin C = \frac{\sqrt{3}}{4}\times 2ab\cos C$ ，所以 $\tan C = \sqrt{3}$ ，因为 $0 < C < \pi$ ，所以 $C = \frac{\pi}{3}$ .
> > (2)由
> > (1)知 $2R = \frac{c}{\sin C} = \frac{\sqrt{3}}{\sin \frac{\pi}{3}} = 2$ .
> > 所以 $a + b = 2R\sin A + 2R\sin B = 2(\sin A + \sin B) = 2\left[\sin A + \sin \left(\pi - A - \frac{\pi}{3}\right)\right]$ $= 2\left[\sin A + \sin \left(\frac{2\pi}{3} - A\right)\right] = 2\left(\sin A + \frac{\sqrt{3}}{2}\cos A + \frac{1}{2}\sin A\right) = 2\sqrt{3}\sin \left(A + \frac{\pi}{6}\right) \leqslant 2\sqrt{3}\left(0 < A < \frac{2\pi}{3}\right)$ , 当 $A = \frac{\pi}{3}$ ，即 $\triangle ABC$ 为等边三角形时取等号。所以 $a + b$ 的最大值为 $2\sqrt{3}$ .
