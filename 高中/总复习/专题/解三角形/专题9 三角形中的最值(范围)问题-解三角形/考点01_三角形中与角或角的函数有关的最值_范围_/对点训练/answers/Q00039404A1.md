> [!faq]- 《专题9 三角形中的最值(范围)问题-解三角形》例题解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > (1)求角 $A$ 的大小；
> > (2)求 $\sqrt{3}\cos C - \sin B$ 的取值范围.
> > 2. 解析 (1)由正弦定理得 $b^{2} - a^{2} = (b - c)\cdot c$ . 即 $b^{2} + c^{2} - a^{2} = bc$ .
> > $\therefore \cos A = \frac{b^2 + c^2 - a^2}{2bc} = \frac{bc}{2bc} = \frac{1}{2}$ . 又 $\because A$ 为三角形内角， $\therefore A = \frac{\pi}{3}$ .
> > (2) $\because B + C = \frac{2}{3}\pi, \therefore C = \frac{2}{3}\pi - B.$ $\because \triangle ABC$ 为锐角三角形， $\therefore \begin{cases} 0 < B < \frac{\pi}{2}, \\ 0 < \frac{2}{3}\pi - B < \frac{\pi}{2}. \end{cases} \quad \therefore \frac{\pi}{6} < B < \frac{\pi}{2}$ .
> > 又 $\because \sqrt{3}\cos C - \sin B = \sqrt{3}\cos \left(\frac{2}{3}\pi - B\right) - \sin B = -\frac{\sqrt{3}}{2}\cos B + \frac{1}{2}\sin B = \sin \left(B - \frac{\pi}{3}\right)$ , $\because \frac{\pi}{6} < B < \frac{\pi}{2}, \therefore -\frac{\pi}{6} < B - \frac{\pi}{3} < \frac{\pi}{6}.$ $\therefore -\frac{1}{2} < \sin \left(B - \frac{\pi}{3}\right) < \frac{1}{2}$ . 即 $\sqrt{3}\cos C - \sin B$ 的取值范围为 $\left(-\frac{1}{2}, \frac{1}{2}\right)$ .
