> [!faq]- 《专题9 三角形中的最值(范围)问题-解三角形》例题解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > (1) 证明: $a + b = 2c$ ;
> >
> > (2) 求 $\cos C$ 的最小值.
> >
> > 3. 解析 由题意知， $2(\frac{\sin A}{\cos A}+\frac{\sin B}{\cos B})=\frac{\sin A}{\cos A\cos B}+\frac{\sin B}{\cos A\cos B}$
> >
> > $$
> > 2 (\sin A \cos B + \sin B \cos A) = \sin A + \sin B, \text {即} 2 \sin (A + B) = \sin A + \sin B
> > $$
> >
> > $$
> > A + B + C = \pi
> > $$
> >
> > $$
> > \sin (A + B) = \sin (\pi - C) = \sin C
> > $$
> >
> > $$
> > \sin A + \sin B = 2 \sin C
> > $$
> >
> > $$
> > a + b = 2 c
> > $$
> >
> > (2)由
> > (1)知 $c = \frac{a + b}{2}$ ，所以 $\cos C = \frac{a^2 + b^2 - c^2}{2ab} = \frac{a^2 + b^2 - \left(\frac{a + b}{2}\right)^2}{2ab} = \frac{3}{8}\left(\frac{b}{a} + \frac{a}{b}\right) - \frac{1}{4} \geq \frac{1}{2}$ ，当且仅当 $a = b$ 时，等号成立。故 $\cos C$ 的最小值为 $\frac{1}{2}$ 。
