> [!faq]- 《专题4 三角形中的最值(范围)问题-解三角形》例题解析
>
> > [!success]- **【答案】** A
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > 答案 A 解析 因为 $c = AB = 1, a = BC = 2, b = AC$ 。根据两边之和大于第三边，两边之差小于第三边可知 $1 < b < 3$ ，根据余弦定理 $\cos C = \frac{1}{2ab} (a^2 + b^2 - c^2) = \frac{1}{4b} (4 + b^2 - 1) = \frac{1}{4b} (3 + b^2) = \frac{3}{4b} + \frac{b}{4} = \frac{1}{4}\left(\frac{\sqrt{3}}{\sqrt{b}} - \sqrt{b}\right)^2 + \frac{\sqrt{3}}{2} \geq \frac{\sqrt{3}}{2}$ 。所以 $0 < C \leq \frac{\pi}{6}$ ，
> >
> > 故选 **A**.
