> [!faq]- 《专题4 三角形中的最值(范围)问题-解三角形》例题解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > 答案 $\frac{\pi}{3}$ 解析 由正弦定理，得 $bccosA + accosB = 2ab\cos C$ ，由余弦定理，得 $bc\cdot \frac{b^2 + c^2 - a^2}{2bc} + ac\cdot \frac{c^2 + a^2 - b^2}{2ac} = 2ab\cdot \frac{a^2 + b^2 - c^2}{2ab}, \therefore a^2 + b^2 = 2c^2, \therefore \cos C = \frac{a^2 + b^2 - c^2}{2ab} = \frac{a^2 + b^2 - \frac{1}{2}(a^2 + b^2)}{2ab} = \frac{a^2 + b^2}{4ab} \geqslant \frac{2ab}{4ab} = \frac{1}{2}$ ，当且仅当 $a = b$ 时，取等号． $\because 0 < C < \pi, \therefore 0 < C \leqslant \frac{\pi}{3}, \therefore C$ 的最大值为 $\frac{\pi}{3}$ .
