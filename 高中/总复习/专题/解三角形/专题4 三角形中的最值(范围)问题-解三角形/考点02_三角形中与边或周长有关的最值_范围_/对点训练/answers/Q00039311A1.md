> [!faq]- 《专题4 三角形中的最值(范围)问题-解三角形》例题解析
>
> > [!success]- **【答案】** A
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > 答案 A 解析 由 $a = b\cos C + c\sin B$ 及正弦定理，得 $\sin A = \sin B\cos C + \sin C\sin B$ ，即 $\sin (B + C) = \sin B\cos C + \sin C\sin B$ ，得 $\sin C\cos B = \sin C\sin B$ ，又 $\sin C \neq 0$ ，所以 $\tan B = 1$ 。因为 $B \in (0, \pi)$ ，所以 $B = \frac{\pi}{4}$ 。由 $S_{\triangle ABC} = \frac{1}{2} ac\sin B = 1 + \sqrt{2}$ ，得 $ac = 2\sqrt{2} + 4$ 。又 $b^2 = a^2 + c^2 - 2ac\cos B \geqslant 2ac - \sqrt{2}ac = (2 - \sqrt{2})(4 + 2\sqrt{2}) = 4$ ，当且仅当 $a = c$ 时等号成立，所以 $b \geqslant 2$ ， $b$ 的最小值为 2，
> >
> > 故选 **A**。
