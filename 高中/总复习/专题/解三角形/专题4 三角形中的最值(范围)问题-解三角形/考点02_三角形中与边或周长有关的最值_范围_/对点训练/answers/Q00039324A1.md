> [!faq]- 《专题4 三角形中的最值(范围)问题-解三角形》例题解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > 答案 $3\sqrt{3} R$ 解析 由凸函数的性质可得 $\sin \frac{A + B + C}{3} = \sin \frac{\pi}{3} \geq \frac{\sin A + \sin B + \sin C}{3}$ ，化简得 $\sin A + \sin B + \sin C \leq 3\sin \frac{\pi}{3} = \frac{3\sqrt{3}}{2}$ 。设 $a, b, c$ 分别为内角 $A, B, C$ 所对的边，利用正弦定理可得三角形的周长 $l = a + b + c = 2R (\sin A + \sin B + \sin C) \leq 2R \times \frac{3\sqrt{3}}{2} = 3\sqrt{3} R$ ，即周长的最大值为 $3\sqrt{3} R$ 。
