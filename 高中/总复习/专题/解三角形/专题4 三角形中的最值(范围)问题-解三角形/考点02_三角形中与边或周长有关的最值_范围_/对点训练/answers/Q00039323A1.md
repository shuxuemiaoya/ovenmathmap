> [!faq]- 《专题4 三角形中的最值(范围)问题-解三角形》例题解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【解析】**
> > 答案 $3\sqrt{3}$ 解析 由正弦定理得 $\frac{BC}{\sin A} = \frac{AB}{\sin C} = \frac{AC}{\sin B} = \frac{\sqrt{3}}{\sin 60^\circ}$ ，即 $\frac{BC}{\sin A} = \frac{AB}{\sin C} = 2$ ，则 $BC = 2\sin A$ ， $AB = 2\sin C$ ，又 $\triangle ABC$ 的周长 $l = BC + AB + AC = 2\sin A + 2\sin C + \sqrt{3} = 2\sin (120^\circ - C) + 2\sin C + \sqrt{3} = 2\sin 120^\circ \cos C - 2\cos 120^\circ \sin C + 2\sin C + \sqrt{3} = \sqrt{3} \cos C + 3\sin C + \sqrt{3} = 2\sqrt{3}\left(\frac{\sqrt{3}}{2}\sin C + \frac{1}{2}\cos C\right) + \sqrt{3} = 2\sqrt{3}\sin \left(C + \frac{\pi}{6}\right) + \sqrt{3}$ ，故 $\triangle ABC$ 的周长的最大值为 $3\sqrt{3}$ .
