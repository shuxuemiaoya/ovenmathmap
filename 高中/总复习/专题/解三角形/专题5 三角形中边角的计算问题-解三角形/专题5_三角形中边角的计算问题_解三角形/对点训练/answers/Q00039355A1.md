> [!faq]- 《专题5 三角形中边角的计算问题-解三角形》例题解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > (2)若 $AC = 7$ ， $AD = 5$ ， $DC = 3$ ，求 $AB$ 的长.
> > 13. 解析 (1)由 $b\cos A + \frac{\sqrt{2}}{2} a = c$ ，得 $\sin B\cos A + \frac{\sqrt{2}}{2}\sin A = \sin C, \sin B\cos A + \frac{\sqrt{2}}{2}\sin A = \sin (A + B), \sin B\cos A + \frac{\sqrt{2}}{2}\sin A = \sin A\cos B + \cos A\sin B, \frac{\sqrt{2}}{2}\sin A = \sin A\cos B,$ $\because \sin A \neq 0, \therefore \cos B = \frac{\sqrt{2}}{2}, \therefore B = \frac{\pi}{4}.$ (2)在 $\triangle ADC$ 中， $AC = 7, AD = 5, DC = 3, \therefore \cos \angle ADC = \frac{AD^2 + DC^2 - AC^2}{2AD \cdot DC} = \frac{5^2 + 3^2 - 7^2}{2 \times 5 \times 3} = -\frac{1}{2},$ $\therefore \angle ADC = \frac{2\pi}{3}, \text{在} \triangle ABD \text{中，} AD = 5, B = \frac{\pi}{4}, \angle ADB = \frac{\pi}{3},$ 由 $\frac{AB}{\sin \angle ADB} = \frac{AD}{\sin B}, \text{得 } AB = \frac{AD \cdot \sin \angle ADB}{\sin B} = \frac{5 \times \sin \frac{\pi}{3}}{\sin \frac{\pi}{4}} = \frac{5 \times \frac{\sqrt{3}}{2}}{\frac{\sqrt{2}}{2}} = \frac{5\sqrt{6}}{2}.$
