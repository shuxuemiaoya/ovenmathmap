> [!faq]- 《专题5 三角形中边角的计算问题-解三角形》例题解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > (1)证明： $\sin B = \cos A$
> > (2)若 $\sin C - \sin A\cos B = \frac{3}{4}$ ，且 $B$ 为钝角，求 $A, B, C$ .
> > 1. 解析
> > (1)证明 由正弦定理知 $\frac{a}{\sin A} = \frac{b}{\sin B} = \frac{c}{\sin C} = 2R, \therefore a = 2R\sin A, b = 2R\sin B$ ，代入 $a = b\tan A$ 得 $\sin A = \sin B \cdot \frac{\sin A}{\cos A}$ ，又 $\because A \in (0, \pi), \therefore \sin A > 0, \therefore 1 = \frac{\sin B}{\cos A}$ ，即 $\sin B = \cos A$ .
> > (2)解 由 $\sin C - \sin A\cos B = \frac{3}{4}$ 知， $\sin (A + B) - \sin A\cos B = \frac{3}{4}$ ， $\therefore \cos A\sin B = \frac{3}{4}$ .
> > 由
> > (1)知， $\sin B=\cos A,\quad\therefore\cos^{2}A=\frac{3}{4}$ ，由于B是钝角，故 $A\in\left(0,\frac{\pi}{2}\right)$ ， $\therefore\cos A=\frac{\sqrt{3}}{2},\quad A=\frac{\pi}{6}.$
> > $\sin B = \frac{\sqrt{3}}{2}, B = \frac{2\pi}{3}, \therefore C = \pi - (A + B) = \frac{\pi}{6}.$
