> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > (1)求角 A 的大小;
> >
> > (2)若 $b + c = 10$ ， $\triangle ABC$ 的面积 $S_{\triangle ABC} = 4\sqrt{3}$ ，求 $a$ 的值.
> >
> > 17. 解析
> > (1)由正弦定理及 $\frac{a\sin C}{1 - \cos A} = \sqrt{3} c$ ，得 $\frac{\sin A\sin C}{1 - \cos A} = \sqrt{3}\sin C,$
> >
> > $$
> > \because \sin C \neq 0, \therefore \sin A = \sqrt {3} (1 - \cos A), \therefore \sin A + \sqrt {3} \cos A = 2 \sin \left(A + \frac {\pi}{3}\right) = \sqrt {3},
> > $$
> >
> > $\therefore \sin \left( A + \frac{\pi}{3} \right) = \frac{\sqrt{3}}{2}$ , 又 $0 < A < \pi$ , $\therefore \frac{\pi}{3} < A + \frac{\pi}{3} < \frac{4\pi}{3}$ , $\therefore A + \frac{\pi}{3} = \frac{2\pi}{3}$ , $\therefore A = \frac{\pi}{3}$ .
> >
> > $$
> > \because S _ {\triangle A B C} = \frac {1}{2} b c \sin A = \frac {\sqrt {3}}{4} b c = 4 \sqrt {3}, \therefore b c = 1 6.
> > $$
> >
> > 由余弦定理，得 $a^{2}=b^{2}+c^{2}-2bc\cos\frac{\pi}{3}=(b+c)^{2}-2bc-bc=(b+c)^{2}-3bc,$
> >
> > 又 $b + c = 10$ ， $\therefore a^2 = 10^2 -3\times 16 = 52$ ， $\therefore a = 2\sqrt{13}.$
