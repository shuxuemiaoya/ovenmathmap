> [!faq]- 《专题5 三角形中边角的计算问题-解三角形》例题解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > (1)求 $\cos B$ ;
> >
> > (2)若 $a + c = 6$ ， $\triangle ABC$ 的面积为2，求 $b$
> >
> > 15. 解析
> > (1)由题设及 $A + B + C = \pi$ 得 $\sin B = 8\sin^2\frac{B}{2}$ , 即 $\sin B = 4(1 - \cos B)$ ,
> >
> > 故 $17\cos^2 B - 32\cos B + 15 = 0$ ，解得 $\cos B = \frac{15}{17}$ ， $\cos B = 1$ （舍去）.
> >
> > (2)由 $\cos B = \frac{15}{17}$ ，得 $\sin B = \frac{8}{17}$ ，故 $S_{\triangle ABC} = \frac{1}{2} ac\sin B = \frac{4}{17} ac.$
> >
> > 又 $S_{\triangle ABC} = 2$ ，则 $ac = \frac{17}{2}$ 由余弦定理及 $a + c = 6$ 得
> >
> > $b^{2}=a^{2}+c^{2}-2ac\cos B=(a+c)^{2}-2ac(1+\cos B)=36-2\times\frac{17}{2}\times\left(1+\frac{15}{17}\right)=4.$ 所以 b=2.
