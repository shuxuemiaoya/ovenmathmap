> [!faq]- 《专题5 三角形中边角的计算问题-解三角形》例题解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【解析】**
> > 解析 由余弦定理得： $\cos B = \frac{a^2 + c^2 - b^2}{2ac} = \frac{a^2 + c^2 - 4}{2ac} = \frac{7}{9}$ ，即 $a^2 + c^2 - 4 = \frac{14}{9} ac$ .
> >
> > $\therefore (a + c)^{2} - 2ac - 4 = \frac{14}{9} ac, \therefore ac = 9.$ 由 $\left\{ \begin{array}{l} a + c = 6, \\ ac = 9, \end{array} \right.$ 得 $a = c = 3$
> >
> > (2)在 $\triangle ABC$ 中， $\cos B=\frac{7}{9}$ ， $\therefore \sin B=\sqrt{1-\cos^{2}B}=\sqrt{1-\left(\frac{7}{9}\right)^{2}}=\frac{4\sqrt{2}}{9}$ . 由正弦定理得： $\frac{a}{\sin A}=\frac{b}{\sin B}$ ,
> >
> > $\therefore \sin A = \frac{a\sin B}{b} = \frac{3\times\frac{4\sqrt{2}}{9}}{2} = \frac{2\sqrt{2}}{3}.$ 又 $A = C$ ， $\therefore 0 <   A <   \frac{\pi}{2},\quad \therefore \cos A = \sqrt{1 - \sin^2A} = \frac{1}{3},$
> >
> > $$
> > \therefore \sin (A - B) = \sin A \cos B - \cos A \sin B = \frac {2 \sqrt {2}}{3} \times \frac {7}{9} - \frac {1}{3} \times \frac {4 \sqrt {2}}{9} = \frac {1 0 \sqrt {2}}{2 7}.
> > $$
