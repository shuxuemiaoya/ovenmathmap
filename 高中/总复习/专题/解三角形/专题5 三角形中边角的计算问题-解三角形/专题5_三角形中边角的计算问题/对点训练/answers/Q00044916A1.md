> [!faq]- 《专题5 三角形中边角的计算问题-解三角形》例题解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > (1)求 $\tan C$ 的值；
> >
> > (2)若 $\triangle ABC$ 的面积为3，求 $b$ 的值.
> >
> > 18. 解析
> > (1)由 $b^{2} - a^{2} = \frac{1}{2} c^{2}$ 及正弦定理得 $\sin^2 B - \frac{1}{2} = \frac{1}{2}\sin^2 C$ ，所以 $-\cos 2B = \sin^2 C$ . ①
> >
> > 又由 $A = \frac{\pi}{4}$ ，即 $B + C = \frac{3\pi}{4}$ 得 $-\cos 2B = -\cos 2\left(\frac{3}{4}\pi -C\right) = -\cos \left(\frac{3}{2}\pi -2C\right) =$
> >
> > $\sin 2C=2\sin C\cos C,$ ②，由①②解得 $\tan C=2.$
> >
> > (2)由 $\tan C = 2$ ， $C\in (0,\pi)$ ，得 $\sin C = \frac{2\sqrt{5}}{5}$ ， $\cos C = \frac{\sqrt{5}}{5}$
> >
> > 因为 $\sin B = \sin (A + C) = \sin \left(\frac{\pi}{4} + C\right) = \sin \frac{\pi}{4}\cos C + \cos \frac{\pi}{4}\sin C$ ，所以 $\sin B = \frac{3\sqrt{10}}{10}$ .
> >
> > 由正弦定理得 $c = \frac{2\sqrt{2}b}{3}$ ，又因为 $A = \frac{\pi}{4}$ ，由 $S_{\triangle ABC} = \frac{1}{2} bc\sin A = 3$ ，所以 $bc = 6\sqrt{2}$ ，故 $b = 3$ 。
