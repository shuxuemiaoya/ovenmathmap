> [!faq]- 《专题5 三角形中边角的计算问题-解三角形》例题解析
>
> > [!success]- **【答案】** B
>
> > [!note]- **【解析】**
> > 解析
> > (1)由题设得 $\frac{1}{2} ac\sin B = \frac{a^2}{3\sin A}$ , 即 $\frac{1}{2} c\sin B = \frac{a}{3\sin A}$ .
> >
> > 由正弦定理得 $\frac{1}{2}\sin C\sin B = \frac{\sin A}{3\sin A}$ ，故 $\sin B\sin C = \frac{2}{3}$ .
> >
> > (2)由题设及
> > (1)得 $\cos B\cos C - \sin B\sin C = -\frac{1}{2}$ ，即 $\cos (B + C) = -\frac{1}{2}$ 。所以 $B + C = \frac{2\pi}{3}$ ，故 $A = \frac{\pi}{3}$ 。
> >
> > 由题设得 $\frac{1}{2} bc\sin A = \frac{a^2}{3\sin A}$ ，即 $bc = 8$ 。由余弦定理得 $b^2 + c^2 - bc = 9$ ，即 $(b + c)^2 - 3bc = 9$
> >
> > 得 $b+c=\sqrt{33}$ . 故 $\triangle ABC$ 的周长为 $3+\sqrt{33}$ .
