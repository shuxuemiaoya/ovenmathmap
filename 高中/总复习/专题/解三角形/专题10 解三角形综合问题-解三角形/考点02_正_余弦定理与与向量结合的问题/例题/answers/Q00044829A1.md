> [!faq]- 《专题10 解三角形综合问题-解三角形》例题解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【解析】**
> > 解析
> > (1)由 $2b\cos C = 2a - \sqrt{3} c$ 及正弦定理，得 $2\sin B\cos C = 2\sin A - \sqrt{3}\sin C,$
> >
> > $$
> > 2 \sin B \cos C = 2 \sin (B + C) - \sqrt {3} \sin C, \therefore 2 \sin C \cos B = \sqrt {3} \sin C,
> > $$
> >
> > $\because C \in (0, \pi), \therefore \sin C \neq 0, \therefore \cos B = \frac{\sqrt{3}}{2}, \text{又} B \in (0, \pi), \therefore B = \frac{\pi}{6}.$
> >
> > (2)由条件知， $M$ 为 $AB$ 的中点， $\therefore$ 在 $\triangle BCM$ 中，由余弦定理可得 $\cos B = \frac{BM^2 + BC^2 - 1}{2BM\cdot BC} = \frac{\sqrt{3}}{2},$ $\therefore BM^{2} + BC^{2} = 1 + \sqrt{3} BM\cdot BC\geqslant 2BM\cdot BC,\therefore BM\cdot BC\leqslant 2 + \sqrt{3}$ ，当且仅当 $BM = BC$ 时等号成立.又 $S_{\triangle ABC} = \frac{1}{2} BC\cdot BA\sin \frac{\pi}{6} = \frac{1}{2} BC\cdot BM\leqslant 1 + \frac{\sqrt{3}}{2},\therefore \triangle ABC$ 面积的最大值是 $1 + \frac{\sqrt{3}}{2}.$
