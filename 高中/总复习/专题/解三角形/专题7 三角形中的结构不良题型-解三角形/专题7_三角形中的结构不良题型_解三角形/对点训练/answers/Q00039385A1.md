> [!faq]- 《专题7 三角形中的结构不良题型-解三角形》例题解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > 解析 解 选①. $\because \cos A = \frac{3}{5}, \cos C = \frac{2\sqrt{5}}{5}, \therefore \sin A = \frac{4}{5}, \sin C = \frac{\sqrt{5}}{5}$ ,
> > $$
> > \therefore \sin B = \sin (A + C) = \sin A \cos C + \cos A \sin C = \frac {4}{5} \times \frac {2 \sqrt {5}}{5} + \frac {3}{5} \times \frac {\sqrt {5}}{5} = \frac {1 1 \sqrt {5}}{2 5}.
> > $$
> > 由正弦定理，得 $b=\frac{a\sin B}{\sin A}=\frac{3\times\frac{11\sqrt{5}}{25}}{\frac{4}{5}}=\frac{33\sqrt{5}}{20}$ ，∴ $S=\frac{1}{2}ab\sin C=\frac{1}{2}\times3\times\frac{33\sqrt{5}}{20}\times\frac{\sqrt{5}}{5}=\frac{99}{40}$ .
> > 选②．∵ $c\sin C=\sin A+b\sin B$ ，∴结合正弦定理，得 $c^{2}=a+b^{2}$ ．∵a=3，∴ $b^{2}=c^{2}-3$
> > $$
> > \because B = 6 0 ^ {\circ}, \therefore b ^ {2} = c ^ {2} + 9 - 2 \times 3 \times c \times \frac {1}{2} = c ^ {2} - 3, \therefore c = 4, \therefore S = \frac {1}{2} a c \sin B = 3 \sqrt {3}.
> > $$
> > 选③. $\because c = 2, \cos A = \frac{1}{8}, \therefore$ 结合余弦定理，得
> > $\frac{1}{8}=\frac{b^{2}+2^{2}-3^{2}}{2\times b\times2}$ ，即 $b^{2}-\frac{b}{2}-5=0$ ，解得 $b=\frac{5}{2}$ 或b=-2(舍去).
> > $$
> > \because \sin A = \sqrt {1 - \cos^ {2} A} = \frac {3 \sqrt {7}}{8}, \therefore S = \frac {1}{2} b c \sin A = \frac {1}{2} \times \frac {5}{2} \times 2 \times \frac {3 \sqrt {7}}{8} = \frac {1 5 \sqrt {7}}{1 6}.
> > $$
