> [!faq]- 《专题7 三角形中的结构不良题型-解三角形》例题解析
>
> > [!success]- **【答案】** A
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > 解析 若选①，由正弦定理得 $(a + b)(a - b) = (c - b)c$ ，即 $b^{2} + c^{2} - a^{2} = bc$ 所以 $\cos A = \frac{b^2 + c^2 - a^2}{2bc} = \frac{bc}{2bc} = \frac{1}{2}$ . 因为 $A \in (0, \pi)$ ，所以 $A = \frac{\pi}{3}$ . 又 $a^2 = b^2 + c^2 - bc = (b + c)^2 - 3bc$ $a = 2\sqrt{6}, b + c = 6$ ，所以 $bc = 4$ ，所以 $S_{\triangle ABC} = \frac{1}{2} bc\sin A = \frac{1}{2} \times 4 \times \sin \frac{\pi}{3} = \sqrt{3}$ .
> >
> > 若选②，由正弦定理得 $\sin A\sin B=\sin B\cos\left(\frac{A+\pi}{6}\right)$ . 因为 $0<B<\pi$ ，所以 $\sin B\neq0$ ，所以 $\sin A=\cos\left(\frac{A+\pi}{6}\right)$ ，化简得 $\sin A=\frac{\sqrt{3}}{2}\cos A-\frac{1}{2}\sin A$ ，即 $\tan A=\frac{\sqrt{3}}{3}$ .
> >
> > 因为 $0 < A < \pi$ ，所以 $A = \frac{\pi}{6}$ 。又因为 $a^2 = b^2 + c^2 - 2bc\cos \frac{\pi}{6}$ ，
> >
> > 所以 $bc = \frac{(b + c)^2 - a^2}{2 + \sqrt{3}} = \frac{6^2 - (2\sqrt{6})^2}{2 + \sqrt{3}} = 24 - 12\sqrt{3}$ ，所以 $S_{\triangle ABC} = \frac{1}{2} bc\sin A = \frac{1}{2}\times (24 - 12\sqrt{3})\times \frac{1}{2} = 6 - 3\sqrt{3}$ .
> >
> > 若选③，由正弦定理得 $\sin B\sin \frac{B + C}{2} = \sin A\sin B$ ，因为 $0 < B < \pi$ ，所以 $\sin B \neq 0$ ，所以 $\sin \frac{B + C}{2} = \sin A.$ 又因为 $B + C = \pi - A$ ，所以 $\sin \frac{\pi - A}{2} = \sin A$ ，即 $\cos \frac{A}{2} = 2\sin \frac{A}{2}\cos \frac{A}{2}$
> >
> > 因为 $0<A<\pi$ ，所以 $0<\frac{A}{2}<\frac{\pi}{2}$ ，所以 $\cos\frac{A}{2}\neq0$ ，所以 $\sin\frac{A}{2}=\frac{1}{2}$ ，所以 $A=\frac{\pi}{3}$ .
> >
> > 又 $a^2 = b^2 + c^2 - 2bc\cos A = b^2 + c^2 - bc = (b + c)^2 - 3bc, a = 2\sqrt{6}, b + c = 6$ ，所以 $bc = 4$
> >
> > 所以 $S_{\triangle ABC}=\frac{1}{2}bc\sin A=\frac{1}{2}\times4\times\sin\frac{\pi}{3}=\sqrt{3}.$
