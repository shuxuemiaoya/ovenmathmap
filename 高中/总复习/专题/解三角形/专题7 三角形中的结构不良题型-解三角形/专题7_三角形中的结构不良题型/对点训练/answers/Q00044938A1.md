> [!faq]- 《专题7 三角形中的结构不良题型-解三角形》例题解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【解析】**
> > 解析 选择条件①:
> > (1)由题意得 $8ac\sin B = 3(a^2 + c^2 - b^2)$ ,
> >
> > 即 $4\sin B = 3 \cdot \frac{a^2 + c^2 - b^2}{2ac}$ ，整理可得 $3\cos B - 4\sin B = 0$ 。
> >
> > 又 $\sin B > 0$ ，所以 $\cos B > 0$ ，所以 $\tan B = \frac{\sin B}{\cos B} = \frac{3}{4}$ .
> >
> > (2)由 $\tan B=\frac{3}{4}$ ，得 $\sin B=\frac{3}{5}$ 。又 S=42，a=10，所以 $S=\frac{1}{2}ac\sin B=\frac{1}{2}\times10c\times\frac{3}{5}=42$ ，解得 c=14。
> >
> > 将 $S = 42$ ， $a = 10$ ， $c = 14$ 代入 $3c^{2} = 16S + 3(b^{2} - a^{2})$ ，得 $3\times 14^{2} = 16\times 42 + 3(b^{2} - 10^{2})$ ，解得 $b = 6\sqrt{2}$
> >
> > 选择条件②：
> > (1)已知 $5b\cos C + 4c = 5a$ ，由正弦定理，得 $5\sin B\cos C + 4\sin C = 5\sin A$ ，
> >
> > 即 $5\sin B\cos C + 4\sin C = 5\sin(B + C)$ ，即 $\sin C(4 - 5\cos B) = 0$ .
> >
> > 在 $\triangle ABC$ 中，因为 $\sin C\neq0$ ，所以 $\cos B=\frac{4}{5}$ 。所以 $\sin B=\sqrt{1-\cos^{2}B}=\frac{3}{5}$ ，所以 $\tan B=\frac{3}{4}$ 。
> >
> > (2)由 $S = \frac{1}{2} ac\sin B = \frac{1}{2}\times 10c\times \frac{3}{5} = 42$ ，解得 $c = 14$ ，又 $a = 10$
> >
> > 所以 $b^{2}=100+196-2\times140\times\frac{4}{5}=72$ ，所以 $b=6\sqrt{2}$ .
