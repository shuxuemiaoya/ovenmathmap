> [!faq]- 《专题2 三角形的3线两圆及面积问题-解三角形》例题解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【解析】**
> > 答案 $2 \sqrt{2}$ 解析 因为 $b \cos C = 3a \cos B - c \cos B$ ，由正弦定理得 $\sin B \cos C = 3 \sin A \cos B - \sin C \cos B$ ，即$\sin B\cos C + \sin C\cos B = 3\sin A\cos B$ ，所以 $\sin (B + C) = 3\sin A\cos B$ 。又 $\sin (B + C) = \sin (\pi - A) = \sin A$ ，所以 $\sin A = 3\sin A\cos B$ ，又 $\sin A \neq 0$ ，解得 $\cos B = \frac{1}{3}$ ，所以 $\sin B = \sqrt{1 - \cos^2 B} = \sqrt{1 - \frac{1}{9}} = \frac{2\sqrt{2}}{3}$ 。由 $\vec{BA} \cdot \vec{BC} = 2$ ，可得 $c a\cos B = 2$ ，解得 $ac = 6$ 。所以 $S_{\triangle ABC} = \frac{1}{2} ac \cdot \sin B = \frac{1}{2} \cdot 6 \cdot \frac{2\sqrt{2}}{3} = 2\sqrt{2}$ 。
