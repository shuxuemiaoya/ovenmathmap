> [!faq]- 《专题2 三角形的3线两圆及面积问题-解三角形》例题解析
>
> > [!success]- **【答案】** C
>
> > [!note]- **【解析】**
> > 答案 C 解析 因为 $2b - \sqrt{3}c = 2a\cos C$ ，所以由正弦定理可得 $2\sin B - \sqrt{3}\sin C = 2\sin A\cos C$ ，所以 $2\sin(A + C) - \sqrt{3}\sin C = 2\sin A\cos C$ 。所以 $2\cos A\sin C = \sqrt{3}\sin C$ ，又 $\sin C \neq 0$ ，所以 $\cos A = \frac{\sqrt{3}}{2}$ ，因为 $A \in (0^\circ, 180^\circ)$ ，所以 $A = 30^\circ$ ，因为 $\sin C = \frac{\sqrt{3}}{2}$ ，所以 $C = 60^\circ$ 或 $120^\circ$ 。当 $C = 60^\circ$ 时， $A = 30^\circ$ ，所以 $B = 90^\circ$ ，又 a = 1，所以 $\triangle ABC$ 的面积为 $\frac{1}{2} \times 1 \times 2 \times \frac{\sqrt{3}}{2} = \frac{\sqrt{3}}{2}$ ；当 $C = 120^\circ$ 时， $A = 30^\circ$ ，所以 $B = 30^\circ$ ，又 a = 1，所以 $\triangle ABC$ 的面积为 $\frac{1}{2} \times 1 \times 1 \times \frac{\sqrt{3}}{2} = \frac{\sqrt{3}}{4}$ ，
> >
> > 故选 **C**。
