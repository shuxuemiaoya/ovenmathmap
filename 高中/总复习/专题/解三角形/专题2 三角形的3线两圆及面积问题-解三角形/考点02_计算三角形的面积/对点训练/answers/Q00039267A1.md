> [!faq]- 《专题2 三角形的3线两圆及面积问题-解三角形》例题解析
>
> > [!success]- **【答案】** B
>
> > [!note]- **【解析】**
> > 答案 D 解析 因为 $(2b - a)\cos C = c\cos A$ ，由正弦定理得， $(2\sin B - \sin A)\cos C = \sin C\cos A$ ，化简得 $2\sin B\cos C = \sin B$ ，又 $\sin B \neq 0$ ，因为 $C \in (0, \pi)$ ，所以 $\cos C = \frac{1}{2}$ ，所以 $C = \frac{\pi}{3}$ 。又由 $\sin A + \sin B = 2\sqrt{6}\sin A\sin B$ 可得 $(\sin A + \sin B) \cdot \sin C = 3\sqrt{2}\sin A\sin B$ ，由正弦定理可得 $(a + b)c = 3\sqrt{2}ab$ ，所以 $a + b = \sqrt{2}ab$ 。因为 $c^2 = a^2 + b^2 - 2ab\cos C$ ，所以 $2(ab)^2 - 3ab - 9 = 0$ ，所以 $ab = 3$ （负值舍去），所以 $S_{\triangle ABC} = \frac{1}{2}ab\sin C = \frac{3\sqrt{3}}{4}$ 。
