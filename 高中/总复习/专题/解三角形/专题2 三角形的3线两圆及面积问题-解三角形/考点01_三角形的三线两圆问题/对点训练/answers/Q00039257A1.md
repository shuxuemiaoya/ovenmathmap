> [!faq]- 《专题2 三角形的3线两圆及面积问题-解三角形》例题解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【解析】**
> > 答案 $\sqrt{2}$ 解析 $\because \frac{a}{\sin A} = \frac{b}{\sin B} = \frac{c}{\sin C} = 2R = 8, \therefore \sin C = \frac{c}{8}, \therefore S_{\triangle ABC} = \frac{1}{2} ab\sin C = \frac{abc}{16} = \frac{16\sqrt{2}}{16} = \sqrt{2}$
