>
> > [!success]- **【答案】** 详见解析

> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > 答案 7:5:3 解析 $\because (b + c):(c + a):(a + b) = 4:5:6, \therefore \frac{b + c}{4} = \frac{c + a}{5} = \frac{a + b}{6}$ . 令 $\frac{b + c}{4} = \frac{c + a}{5} = \frac{a + b}{6}$ $\frac{a + b}{6} = k(k > 0)$ , 则 $\left\{ \begin{array}{l} b + c = 4k \\ c + a = 5k \\ a + b = 6k \end{array} \right.$ , 解得 $\left\{ \begin{array}{l} a = \frac{7}{2}k, \\ b = \frac{5}{2}k, \\ c = \frac{3}{2}k, \end{array} \right.$ $\therefore \sin A: \sin B: \sin C = a:b:c = 7:5:3.$
