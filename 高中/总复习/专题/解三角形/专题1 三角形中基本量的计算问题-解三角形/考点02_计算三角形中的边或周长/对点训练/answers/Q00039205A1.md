> [!faq]- 《专题1 三角形中基本量的计算问题-解三角形》例题解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > 答案 $1 + \sqrt{3}$ 解析 由已知可得 $\frac{1}{2} ac\sin 30^{\circ} = \frac{3}{2}$ ，解得 $ac = 6$ 。因为 $\sin A + \sin C = 2\sin B$ ，所以由正弦定理可得 $a + c = 2b$ 。由余弦定理知 $b^{2} = a^{2} + c^{2} - 2ac\cos B = (a + c)^{2} - 2ac - \sqrt{3}ac = 4b^{2} - 12 - 6\sqrt{3}$ ，解得 $b^{2} = 4 + 2\sqrt{3}$ ， $\therefore b = 1 + \sqrt{3}$ 或 $b = -1 - \sqrt{3}$ (舍去).
