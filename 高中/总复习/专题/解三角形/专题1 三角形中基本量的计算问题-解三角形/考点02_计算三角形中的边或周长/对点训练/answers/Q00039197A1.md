> [!faq]- 《专题1 三角形中基本量的计算问题-解三角形》例题解析
>
> > [!success]- **【答案】** A
>
> > [!note]- **【解析】**
> > 答案 C 解析 由 $2\cos^2\frac{A + B}{2} - \cos 2C = 1$ ，可得 $2\cos^2\frac{A + B}{2} - 1 - \cos 2C = 0$ ，则有 $\cos 2C + \cos C = 0$ ，即 $2\cos^2 C + \cos C - 1 = 0$ ，解得 $\cos C = \frac{1}{2}$ 或 $\cos C = -1$ （舍），由 $4\sin B = 3\sin A$ ，得 $4b = 3a$ ，①，又 $a - b = 1$ ，②，联立①，②得 $a = 4$ ， $b = 3$ ，所以 $c^2 = a^2 + b^2 - 2ab\cos C = 16 + 9 - 12 = 13$ ，则 $c = \sqrt{13}$ .
