> [!faq]- 《专题1 三角形中基本量的计算问题-解三角形》例题解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【解析】**
> > 答案 $\frac{14}{5}$ 解析 在 $\triangle ABC$ 中， $\because \cos A = \frac{3}{5} > 0, \therefore \sin A = \frac{4}{5}.$ $\because \cos B = \frac{5}{13} > 0, \therefore \sin B = \frac{12}{13}.$ $\therefore \sin C = \sin [\pi - (A + B)] = \sin (A + B) = \sin A \cos B + \cos A \sin B = \frac{4}{5} \times \frac{5}{13} + \frac{3}{5} \times \frac{12}{13} = \frac{56}{65}$ . 由正弦定理知 $\frac{b}{\sin B} = \frac{c}{\sin C}, \therefore c = \frac{b \sin C}{\sin B} = \frac{3 \times \frac{56}{65}}{\frac{12}{13}} = \frac{14}{5}$ .
