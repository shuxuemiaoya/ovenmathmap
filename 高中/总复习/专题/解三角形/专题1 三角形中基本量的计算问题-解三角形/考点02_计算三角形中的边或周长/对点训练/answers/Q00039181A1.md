> [!faq]- 《专题1 三角形中基本量的计算问题-解三角形》例题解析
>
> > [!success]- **【答案】** A
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > 答案 A 解析 因为 $A, C$ 为 $\triangle ABC$ 的内角，且 $\cos A = \frac{4}{5}, \cos C = \frac{5}{13}$ ，所以 $\sin A = \frac{3}{5}, \sin C = \frac{12}{13}$ ，所以 $\sin B = \sin (\pi - A - C) = \sin (A + C) = \sin A \cos C + \cos A \sin C = \frac{3}{5} \times \frac{5}{13} + \frac{4}{5} \times \frac{12}{13} = \frac{63}{65}$ . 又 $a = 1$ ，所以由正弦定理得 $b = \frac{a \sin B}{\sin A} = \frac{63}{65} \times \frac{5}{3} = \frac{21}{13}$ .
