> [!faq]- 《专题1 三角形中基本量的计算问题-解三角形》例题解析
>
> > [!success]- **【答案】** A
>
> > [!note]- **【解析】**
> > 答案 A 解析 $\because$ 等式右边 $= \sin A\cos C + (\sin A\cos C + \cos A\sin C) = \sin A\cos C + \sin (A + C) = \sin A\cos C + \sin B$ ，等式左边 $= \sin B + 2\sin B\cos C$ ， $\therefore \sin B + 2\sin B\cos C = \sin A\cos C + \sin B$ 。由 $\cos C > 0$ ，得 $\sin A = 2\sin B$ 。根据正弦定理，得 $a = 2b$ 。
