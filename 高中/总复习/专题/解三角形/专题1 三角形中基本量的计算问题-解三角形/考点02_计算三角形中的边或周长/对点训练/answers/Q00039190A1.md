> [!faq]- 《专题1 三角形中基本量的计算问题-解三角形》例题解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > 答案 $\frac{\pi}{3} 2$ 解析 $\because 2\cos^2 A + \sqrt{3}\sin 2A = 2, \therefore \cos 2A + \sqrt{3}\sin 2A = 1, \therefore \sin \left(2A + \frac{\pi}{6}\right) = \frac{1}{2}, \because 0 < A < \pi,$ $\therefore 2A + \frac{\pi}{6} \in \left(\frac{\pi}{6}, \frac{13\pi}{6}\right), \therefore 2A + \frac{\pi}{6} = \frac{5\pi}{6}, \therefore A = \frac{\pi}{3}.$ $\because b = 1, S_{\triangle ABC} = \frac{\sqrt{3}}{2} = \frac{1}{2} bc\sin A = \frac{1}{2} \times 1 \times c \times \frac{\sqrt{3}}{2}, \therefore c = 2, \therefore$ 由余弦定理可得， $a = \sqrt{b^2 + c^2 - 2bc\cos A} = \sqrt{1^2 + 2^2 - 2 \times 1 \times 2 \times \frac{1}{2}} = \sqrt{3}, \therefore \frac{b + c}{\sin B + \sin C} = \frac{a}{\sin A} = \frac{\sqrt{3}}{\frac{\sqrt{3}}{2}} = 2.$
