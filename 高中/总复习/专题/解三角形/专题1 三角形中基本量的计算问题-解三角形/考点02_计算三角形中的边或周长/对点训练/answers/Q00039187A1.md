> [!faq]- 《专题1 三角形中基本量的计算问题-解三角形》例题解析
>
> > [!success]- **【答案】** C
>
> > [!note]- **【解析】**
> > 答案 2 解析 方法一 因为 $b \cos C + c \cos B = 2b$ ，所以 $b \cdot \frac{a^2 + b^2 - c^2}{2ab} + c \cdot \frac{a^2 + c^2 - b^2}{2ac} = 2b$ ，化简可得 $\frac{a}{b} = 2$ 。方法二 因为 $b \cos C + c \cos B = 2b$ ，所以 $\sin B \cos C + \sin C \cos B = 2 \sin B$ ，故 $\sin (B + C) = 2 \sin B$ ，故 $\sin A = 2 \sin B$ ，则 $a = 2b$ ，即 $\frac{a}{b} = 2$ 。
