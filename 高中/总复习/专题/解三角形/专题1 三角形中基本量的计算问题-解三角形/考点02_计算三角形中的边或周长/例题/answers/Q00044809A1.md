> [!faq]- 《专题1 三角形中基本量的计算问题-解三角形》例题解析
>
> > [!success]- **【答案】** C
>
> > [!note]- **【解析】**
> > 答案 C 解析 $\because \frac{a\cos B + b\cos A}{c} = 2\cos C$ ，由正弦定理，得 $\sin A\cos B + \cos A\sin B = 2\sin C\cos C, \therefore \sin(A + B) = \sin C = 2\sin C\cos C$ ，由于 $0 < C < \pi, \sin C \neq 0, \therefore \cos C = \frac{1}{2}, \therefore C = \frac{\pi}{3}, \because S_{\triangle ABC} = 2\sqrt{3} = \frac{1}{2}ab\sin C = \frac{\sqrt{3}}{4}ab, \therefore ab = 8$ ，又 $a + b = 6$ ，解得 $\left\{\begin{aligned}a &= 2, \\ b &= 4\end{aligned}\right.$ 或 $\left\{\begin{aligned}a &= 4, \\ b &= 2,\end{aligned}\right.$ $c^{2} = a^{2} + b^{2} - 2ab\cos C = 4 + 16 - 8 = 12, \therefore c = 2\sqrt{3}$ ，
> >
> > 故选 **C**.
