> [!faq]- 《导数专题(上册)》例题解析
>
> > [!success]- **【答案】** B
>
> > [!note]- **【解析】**
> > 解析 法一(切线找点): $e^{x} \geqslant (a + 1)x + b \Leftrightarrow e^{x - \ln (a + 1)} \geqslant x - \ln (a + 1) + 1 = x + \frac{b}{a + 1} \Leftrightarrow (a + 1)b = -(a + 1)^{2}\ln \frac{a + 1}{e} = -(a + 1)^{2}\ln \frac{a + 1}{e} = -\frac{e^{2}}{2}\frac{(a + 1)^{2}}{e^{2}}\ln \frac{(a + 1)^{2}}{e^{2}} \leqslant \frac{e}{2}$ ; 法二(基本不等式): $e^{x} \geqslant (a + 1)x + b \geqslant 2\sqrt{(a + 1)bx} \Rightarrow \frac{e^{x}}{2\sqrt{x}} \geqslant \sqrt{(a + 1)b} \Rightarrow \frac{e^{2x}}{4x} \geqslant \frac{e}{2} \geqslant (a + 1)b$ , 当且仅当 $(a + 1)x = b$ 时取等, 此时, 所以当且仅当 $x = \frac{1}{2}$ , $a + 1 = \sqrt{e}$ , $b = \frac{\sqrt{e}}{2}$ 时取等,
> >
> > 故选 **B**.
