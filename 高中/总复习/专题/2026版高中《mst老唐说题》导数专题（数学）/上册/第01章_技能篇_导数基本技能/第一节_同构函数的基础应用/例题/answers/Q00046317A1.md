> [!faq]- 《导数专题(上)》例题解析
>
> > [!success]- **【答案】** D
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > 解析 因为 $3y + \log_3y = 2$ ，所以 $3y + \log_3y + 1 = 3$ ，即 $3y + \log_3(3y) = 3$ ， $\log_3(3y) + 3^{\log_3(3y)} = 3$ ，令 $f(x) = x + 3^x \uparrow$ ，则 $f(\log_3(3y)) = 3$ ，又 $x + 3^x = 3$ ，即 $f(x) = 3$ ，所以 $f(x) = f(\log_3(3y)) = 3$ ；所以 $x = \log_3(3y)$ ，所以 $3^x = 3y$ ，所以 $x + 3y = x + 3^x = 3$ 。
> >
> > 故选 **D**.
