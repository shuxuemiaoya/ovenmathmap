> [!faq]- 《导数专题(上)》例题解析
>
> > [!success]- **【答案】** D
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > 解析 由题可知 $f'(x) = 2x \ln x + x + a$ ，因为函数 $f(x) = x^2 \ln x + ax$ 存在减区间，则 $f'(x) < 0$ 有解，即 $a < -2x \ln x - x = -2x \left( \ln x + \frac{1}{2} \right) = -2x \ln \sqrt{\mathrm{e}}x = \frac{-2}{\sqrt{\mathrm{e}}} \sqrt{\mathrm{e}}x \ln \sqrt{\mathrm{e}}x_{\max} = \frac{-2}{\sqrt{\mathrm{e}}} \cdot \left( -\frac{1}{\mathrm{e}} \right) = 2\mathrm{e}^{-\frac{3}{2}}$ ，当且仅当 $\sqrt{\mathrm{e}}x = \frac{1}{\mathrm{e}}$ 时取得最值，
> >
> > 故选 **D**.
