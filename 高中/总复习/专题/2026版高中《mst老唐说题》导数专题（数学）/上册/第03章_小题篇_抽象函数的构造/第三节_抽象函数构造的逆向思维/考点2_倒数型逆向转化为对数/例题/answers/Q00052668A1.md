> [!faq]- 《导数专题(上册)》例题解析
>
> > [!success]- **【答案】** C
>
> > [!note]- **【解析】**
> > 解析 因为 $xf'(x) - f(x) = x^2 + x$ ，所以 $\frac{xf'(x) - f(x)}{x^2} = 1 + \frac{1}{x}$ ，所以 $\left[\frac{f(x)}{x}\right]' = 1 + \frac{1}{x}$ ，所以 $\frac{f(x)}{x} = \int \left(1 + \frac{1}{x}\right) dx = x + \ln x + C$ ，所以 $f(x) = x^2 + x \ln x + Cx$ ，所以 $f(1) = 1 + 1 \ln 1 + C = 1 + C$ ，因为 $f(1) \geqslant 1$ ，所以 $1 + C \geqslant 1$ ，所以 $C \geqslant 0$ ，所以 $f(x)$ 的解析式可能是 $x^2 + x \ln x + x$ ，
> >
> > 故选 **C**.
