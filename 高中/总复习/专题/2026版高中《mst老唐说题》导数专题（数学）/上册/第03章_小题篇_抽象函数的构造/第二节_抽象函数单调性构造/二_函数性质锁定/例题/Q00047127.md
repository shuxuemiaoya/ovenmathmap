例23 (2024·湖北月考)已知定义在 $\mathbf{R}$ 上的函数 $f(x)$ 的导函数为 $f'(x)$ , 满足 $f(1 + x) = f(1 - x)$ , $(x - 1)f'(x) > 0$ , $f
(3) = 2$ , 则不等式 $[f(x) - 2] \ln x < 0$ 的解集为 \_\_\_\_.

(3) = 2$ ，所以 $f (3) = f(-1) = 2$ ， $(x - 1)f'(x) > 0 \Rightarrow \begin{cases} x > 1 \\ f'(x) > 0 \end{cases}$ ，或 $\left\{ \begin{array}{l} x < 1 \\ f'(x) < 0 \end{array} \right.$ ，所以函数 $f(x)$ 在 $(-\infty, 1)$ 上递减， $(1, +\infty)$ 上递增，当 $x < 1$ 时，

$[f(x) - 2]\ln x < 0 \Rightarrow \begin{cases} 0 < x < 1 \\ [f(x) - 2]\ln x < 0 \end{cases} \Rightarrow f(x) - 2 > 0 \Rightarrow f(x) > 2 = f(-1) \Rightarrow x < -1$ ，不满足，当 $x > 1$ 时， $[f(x) - 2]\ln x < 0 \Rightarrow f(x) - 2 < 0 \Rightarrow f(x) < 2 = f
(3) \Rightarrow x < 3 \Rightarrow 1 < x < 3$ ：故答案为：(1, 3).
