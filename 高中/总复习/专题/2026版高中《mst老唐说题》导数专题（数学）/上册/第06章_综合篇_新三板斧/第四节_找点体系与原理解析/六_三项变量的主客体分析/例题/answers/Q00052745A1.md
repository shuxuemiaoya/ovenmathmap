> [!faq]- 《导数专题(上册)》例题解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【解析】**
> > 解析 $f(x) = \ln \frac{x}{2 - x} + ax + b(x - 1)^3, f(1) = a < -2$ ，当 $1 < x < 2, f(x) > \ln \frac{x}{2 - x} + 2a - |b| = -2 \Rightarrow x = \frac{2}{e^{2a - |b| + 2} + 1}$ ；即存在 $1 < x < \frac{2}{e^{2a - |b| + 2} + 1}$ 使得 $f(x) = 0$ .
> >
> > 类似的找点方法其实比较多，在此再分享一种取点方法，由于同类题出现的太少，同学们可以仅理解.
