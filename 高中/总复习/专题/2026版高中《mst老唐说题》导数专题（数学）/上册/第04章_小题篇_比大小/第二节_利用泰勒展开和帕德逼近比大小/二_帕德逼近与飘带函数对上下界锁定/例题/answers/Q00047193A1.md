> [!faq]- 《导数专题(上册)》例题解析
>
> > [!success]- **【答案】** C
>
> > [!note]- **【解析】**
> > 解析 $\sin x < x$ 对任意的 $x \in \left(0, \frac{\pi}{2}\right)$ 恒成立，即 $\sin \frac{2}{21} < \frac{2}{21}$ ，即 $b < a; a = \frac{2}{21}, c = \ln \frac{11}{10}, \frac{2\left(\frac{11}{10} - 1\right)}{\frac{11}{10} + 1} = \frac{2}{21} = a$ ，根据帕德逼近， $\ln x > \frac{2(x - 1)}{x + 1}, x > 1$ ，即 $c > a$ ，综上所述， $c > a > b$ 。
> >
> > 故选 **C**.
