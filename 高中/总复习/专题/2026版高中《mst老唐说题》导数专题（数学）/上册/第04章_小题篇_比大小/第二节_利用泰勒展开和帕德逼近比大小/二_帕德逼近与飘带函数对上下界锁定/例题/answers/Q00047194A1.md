> [!faq]- 《导数专题(上册)》例题解析
>
> > [!success]- **【答案】** C
>
> > [!note]- **【解析】**
> > 解析 ① 先比较 b 与 a 的大小， $\frac{1}{2}\left(x-\frac{1}{x}\right)>\ln x>\frac{2(x-1)}{x+1}(x>1)$ ，所以 $\frac{1}{2}\left(2-\frac{1}{2}\right)>\ln2>\frac{2(2-1)}{2+1}$ ，所以 b>a;
> > - **②**：再比较 b 与 c 的大小： $\sin x > \ln(1 + x) (0 < x < 1)$ ，所以 $\sin 1 - \ln 2 > 0$ ，所以 c > b，所以 c > b > a。
> >
> > 故选 **C**.
