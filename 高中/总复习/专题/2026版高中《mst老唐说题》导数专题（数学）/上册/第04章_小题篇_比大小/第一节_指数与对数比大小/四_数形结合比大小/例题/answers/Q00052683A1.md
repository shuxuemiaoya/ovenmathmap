> [!faq]- 《导数专题(上册)》例题解析
>
> > [!success]- **【答案】** A
>
> > [!note]- **【解析】**
> > 解析 由题意可得 $a - \ln a = e^{-1} + 1, b - \ln b = e^{-2} + 2, c - \ln c = e^{-4} + 4$ ，令 $f(x) = e^{-x} + x$ ，则 $f'(x) = -e^{-x} + 1$ ，因为当 $x > 0$ 时， $f'(x) > 0$ ， $f(x)$ 单调递增，所以 $f(1) < f(2) < f(4)$ ，即 $a - \ln a < b - \ln b < c - \ln c$ ，令 $g(x) = x - \ln x$ ，由同构函数因为当 $x > 1$ 时，所以 $g(x)$ 单调递增，又因为 $a, b, c \in (1, +\infty)$ 且 $g(a) < g(b) < g(c)$ ，所以 $a < b < c$ 。
> >
> > 故选 **A**.
