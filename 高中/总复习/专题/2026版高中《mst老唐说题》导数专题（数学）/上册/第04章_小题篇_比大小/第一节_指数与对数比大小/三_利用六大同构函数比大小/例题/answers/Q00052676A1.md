> [!faq]- 《导数专题(上册)》例题解析
>
> > [!success]- **【答案】** D
>
> > [!note]- **【解析】**
> > 解析 解：因为 $a = \frac{\ln\sqrt{2}}{2} = \frac{\frac{1}{2}\ln 2}{2} = \frac{\ln 2}{4}, c = \frac{1}{2e} = \frac{\ln e}{2e}$ ，设 $f(x) = \frac{\ln x}{2x}, x > 0$ ，则 $f'(x) = \frac{\frac{1}{x} \cdot (2x) - 2\ln x}{(2x)^2} = \frac{1 - \ln x}{2x^2}$ ，所以当 $x \in (0, e)$ 时， $f'(x) > 0, f(x)$ 单调递增；当 $x \in (e, +\infty)$ 时， $f'(x) < 0, f(x)$ 单调递减；所以 $a = f(2) < f(e) = c, b = f(3) < f(e) = c$ ，又因为 $a = \frac{\ln 2}{4} = \frac{3\ln 2}{12} = \frac{\ln 8}{12} < \frac{\ln 9}{12} = \frac{2\ln 3}{12} = \frac{\ln 3}{6} = b$ ，所以 $c > b > a$ 。
> >
> > 故选 **D**。法二： $\frac{m_2}{4} = \frac{m_4}{8} = f(4) < f(3) < f(e)$ ，所以 $a < b < c$ ，选 D。
