A. $a < c < b$ B. $c < a < b$ C. $a < b < c$ D. $b < a < c$

(4) = f
(2)$ ， $f(x)$ 在 $(0,e)$ 上递增，在 $(e, + \infty)$ 上递减．则有 $b = f(e)$ 最大， $e > 2 > \frac{e^2}{4}$ ， $f\left(\frac{e^2}{4}\right) <   f (2) <   f(e)$ ，即 $a <   c <   b$ ；故选A
