例10 (24高三上·天津宁河·期末)已知函数 $f(x) = \ln x + \frac{a}{2} x^2, a \in \mathbb{R}$ .

(1) 当 a=1 时，求曲线 $y=f(x)$ 在 $(1, f (1))$ 处的切线方程；

(2)求 $f(x)$ 的单调区间；

(3)设 $x_{1}$ ， $x_{2}(0<x_{1}<x_{2})$ 是函数 $g(x)=f(x)-ax$ 的两个极值点，证明： $g(x_{1})-g(x_{2})<\frac{a}{2}-\ln a.$

(1)当 $a = 1$ 时， $f(x) = \ln x + \frac{1}{2} x^2$ ，得 $f'(x) = \frac{1}{x} + x$ ，则 $f' (1) = 2, f (1) = \frac{1}{2}$ ，所以切线方程为 $y = 2(x - 1) + \frac{1}{2}$ ，即 $4x - 2y - 3 = 0$ ；

(2) $f'(x) = \frac{1}{x} + ax = \frac{1 + ax^2}{x}$ ，当 $a \geqslant 0$ 时， $f'(x) > 0$ 恒成立， $f(x)$ 在 $(0, +\infty)$ 上单调递增，当 $a \leqslant 0$ 时，令 $f'(x) > 0$ ，得 $0 < x < -\frac{\sqrt{-a}}{a}$ ， $f(x)$ 单调递增，令 $f'(x) < 0$ ，得 $x > -\frac{\sqrt{-a}}{a}$ ， $f(x)$ 单调递减，综合得：当 $a \geqslant 0$ 时， $f(x)$ 的单调递增区间为 $(0, +\infty)$ ，无减区间；当 $a < 0$ 时， $f(x)$ 的单调递增区间为 $\left(0, -\frac{\sqrt{-a}}{a}\right)$ ， $f(x)$ 的单调递减区间为 $\left(-\frac{\sqrt{-a}}{a}, +\infty\right)$ ；

(3) $g(x) = f(x) - ax = \ln x + \frac{a}{2} x^2 - ax$ ，则 $g'(x) = \frac{1}{x} + ax - a = \frac{ax^2 - ax + 1}{x}$ ，因为 $x_1, x_2 (0 < x_1 < x_2)$ 是函数 $g(x) = f(x) - ax$ 的两个极值点，即 $x_1, x_2 (0 < x_1 < x_2)$ 是方程 $ax^2 - ax + 1 = 0$ 的两不等正根，所以 $\begin{cases} a^2 - 4a > 0 \\ x_1 + x_2 = 1 > 0 \\ x_1x_2 = \frac{1}{a} > 0 \end{cases}$ ，得 $a > 4$ ，令 $\frac{x_2}{x_1} = t, t > 1$ ，则 $a = \frac{(x_1 + x_2)^2}{x_1x_2} = t + \frac{1}{t} + 2$ ，即 $g(x_1) - g(x_2) = \ln x_1 + \frac{a}{2} x_1^2 - ax_1 - (\ln x_2 + \frac{a}{2} x_2^2 - ax_2) = \ln \frac{x_1}{x_2} + \frac{a}{2} (x_1^2 - x_2^2) - a(x_1 - x_2) = \ln \frac{x_1}{x_2} + \frac{a}{2} (x_1 - x_2)(x_1 + x_2) - a(x_1 - x_2) = \ln \frac{x_1}{x_2} - \frac{1}{2} \frac{(x_1 - x_2)(x_1 + x_2)}{x_1x_2} = \ln \frac{x_1}{x_2} +$ $\frac{1}{2}\left(\frac{x_{2}}{x_{1}}-\frac{x_{1}}{x_{2}}\right)=\frac{1}{2}\left(t-\frac{1}{t}\right)-\ln t$ ，则 $g(x_{1})-g(x_{2})-\frac{a}{2}+\ln a=-\frac{1}{t}-1+2\ln\left(1+\frac{1}{t}\right)$ ，令 $\frac{1}{t}=m$ ，
