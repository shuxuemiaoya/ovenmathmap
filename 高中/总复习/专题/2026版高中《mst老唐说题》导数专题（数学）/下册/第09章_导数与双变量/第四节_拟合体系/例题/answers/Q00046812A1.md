> [!faq]- 《导数专题(下)》例题解析
>
> > [!success]- **【答案】** 解析
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > 左边由于 $\ln x \leqslant x - 1$ ，故 $\left\{\begin{aligned} f(x) & > a (x - 1)^{2} - (a - 1), \\ f(x) & < a (x - 1)^{2} - (a - 1), \end{aligned}\right.$ （当 0 < x < 1），故取 $\left\{\begin{aligned} x_{3} & = 1 - \sqrt{\frac{a - 1}{a}} \\ x_{4} & = 1 + \sqrt{\frac{a - 1}{a}} \end{aligned}\right.$
> > 右边由于 $\ln x \geqslant 1 - \frac{1}{x}$ ，且 $\left\{ \begin{array}{l} x^2 - 2x < x + \frac{1}{x} - 3, \quad (\text{当 } 0 < x < 1) \\ x^2 - 2x > x + \frac{1}{x} - 3, \quad (\text{当 } x > 1) \end{array} \right.$ ，所以 $\left\{ \begin{array}{l} f(x) < (x - 1)\left(1 - \frac{1}{x}\right) + (a - 1)\left(x + \frac{1}{x} - 3\right), \quad (\text{当 } 0 < x < 1) \\ f(x) > (x - 1)\left(1 - \frac{1}{x}\right) + (a - 1)\left(x + \frac{1}{x}\right), \quad (\text{当 } x > 1) \end{array} \right.$ ，故取 $\left\{ \begin{array}{l} x_5 = \frac{3a - 1 - \sqrt{5a^2 - 6a + 1}}{2a} \\ x_6 = \frac{3a - 1 + \sqrt{5a^2 - 6a + 1}}{2a} \end{array} \right.$ ，所以 $\exists x_1 \in (x_3, x_5)$ ，使 $f(x_1) = 0$ ， $\exists x_2 \in (x_4, x_6)$ ，使 $f(x_2) = 0$ ，且 $x_3 + x_4 = 2$ ， $x_5 + x_6 = \frac{3a - 1}{a}$ ，所以 $2 < x_1 + x_2 < 3 - \frac{1}{a}$ 。当然：这一类采用找点思路的都可以采用做差的思想。
