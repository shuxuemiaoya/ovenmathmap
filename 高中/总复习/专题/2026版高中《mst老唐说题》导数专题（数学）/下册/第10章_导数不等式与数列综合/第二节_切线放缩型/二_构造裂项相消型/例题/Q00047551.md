例23 (23届绵阳一诊理科导数)已知函数 $f(x)=2e^{x}-x^{2}-ax-2$ ，当 $x\geqslant0,\ f(x)\geqslant0.$

(1) 求 a 的取值范围；

(2)求证： $\left(1 + \frac{2}{2e - 1}\right)\left(1 + \frac{2}{2e^2 - 1}\right)\left(1 + \frac{2}{2e^3 - 1}\right)\dots \left(1 + \frac{2}{2e^n - 1}\right) <   5,\quad n\in \mathbf{N}^{*}.$

(1) $f(0)=0$ ， $f'(x)=2e^{x}-2x-a$ ， $f'(0)=2-a$ ，当 $a\leqslant2$ 时， $f'(0)\geqslant0$ ， $f''(x)=2e^{x}-2\geqslant0$ 恒成立，故 $f'(x)$ 单调递增， $f'(x)\geqslant f'(0)\geqslant0$ 恒成立，故 $f(x)$ 单调递增， $f(x)\geqslant f(0)$ 恒成立；当 $a>2$ 时， $f'(0)<0$ ， $f'(a)=2e^{a}-3a>0$ ，故存在 $x_{0}\in(0,a)$ ，使得 $f'(x_{0})=0$ ，此时 $f(x)$ 在 $(0,x_{0})$ 单调递减， $f(x)<f(0)=0$ 恒成立，矛盾；综上 $a\leqslant2$ （端点效应）；

(2) 由
(1) 知 $2e^{x} - 1 \geqslant x^{2} + 2x + 1 > x^{2} + 2x$ ，故 $\frac{2}{2e^{n} - 1} < \frac{2}{n^{2} + 2n} = \frac{1}{n} - \frac{1}{n + 2}$ ，得 $\left(1 + \frac{2}{2e - 1}\right)\left(1 + \frac{2}{2e^2 - 1}\right)\left(1 + \frac{2}{2e^3 - 1}\right) \cdots \left(1 + \frac{2}{2e^n - 1}\right) < \left(1 + 1 - \frac{1}{3}\right)\left(1 + \frac{1}{2} - \frac{1}{4}\right) \cdots \left(1 + \frac{1}{n} - \frac{1}{n + 2}\right)$ ，转化为证 $\ln \left[\left(1 + 1 - \frac{1}{3}\right)\left(1 + \frac{1}{2} - \frac{1}{4}\right) \cdots \left(1 + \frac{1}{n} - \frac{1}{n + 2}\right)\right] < \ln 5$ ，即 $\ln \left(1 + 1 - \frac{1}{3}\right) + \ln \left(1 + \frac{1}{2} - \frac{1}{4}\right) + \cdots + \ln \left(1 + \frac{1}{n} - \frac{1}{n + 2}\right) < \ln 5$ ，再由 $\ln (n + 1) < n, n \in \mathbb{N}^*$ ，

$$
1 - \frac {1}{3} + \frac {1}{2} - \frac {1}{4} + \frac {1}{3} - \frac {1}{5} + \dots + \frac {1}{n - 1} - \frac {1}{n + 1} + \frac {1}{n} - \frac {1}{n + 2} = \frac {3}{2} - \frac {1}{n + 1} - \frac {1}{n + 2} <   \frac {3}{2} <   \ln 5.
$$
