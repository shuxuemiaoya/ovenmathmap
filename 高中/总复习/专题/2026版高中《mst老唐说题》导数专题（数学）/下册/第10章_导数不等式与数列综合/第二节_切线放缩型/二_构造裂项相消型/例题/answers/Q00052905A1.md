> [!faq]- 《导数专题(下册)》例题解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【解析】**
> > 解析 (1) $f(0)=0$ ， $f'(x)=2e^{x}-2x-a$ ， $f'(0)=2-a$ ，当 $a\leqslant2$ 时， $f'(0)\geqslant0$ ， $f''(x)=2e^{x}-2\geqslant0$ 恒成立，故 $f'(x)$ 单调递增， $f'(x)\geqslant f'(0)\geqslant0$ 恒成立，故 $f(x)$ 单调递增， $f(x)\geqslant f(0)$ 恒成立；当 $a>2$ 时， $f'(0)<0$ ， $f'(a)=2e^{a}-3a>0$ ，故存在 $x_{0}\in(0,a)$ ，使得 $f'(x_{0})=0$ ，此时 $f(x)$ 在 $(0,x_{0})$ 单调递减， $f(x)<f(0)=0$ 恒成立，矛盾；综上 $a\leqslant2$ （端点效应）；
> >
> > (2) 由 (1) 知 $2e^{x} - 1 \geqslant x^{2} + 2x + 1 > x^{2} + 2x$ ，故 $\frac{2}{2e^{n} - 1} < \frac{2}{n^{2} + 2n} = \frac{1}{n} - \frac{1}{n + 2}$ ，得 $\left(1 + \frac{2}{2e - 1}\right)\left(1 + \frac{2}{2e^2 - 1}\right)\left(1 + \frac{2}{2e^3 - 1}\right) \cdots \left(1 + \frac{2}{2e^n - 1}\right) < \left(1 + 1 - \frac{1}{3}\right)\left(1 + \frac{1}{2} - \frac{1}{4}\right) \cdots \left(1 + \frac{1}{n} - \frac{1}{n + 2}\right)$ ，转化为证 $\ln \left[\left(1 + 1 - \frac{1}{3}\right)\left(1 + \frac{1}{2} - \frac{1}{4}\right) \cdots \left(1 + \frac{1}{n} - \frac{1}{n + 2}\right)\right] < \ln 5$ ，即 $\ln \left(1 + 1 - \frac{1}{3}\right) + \ln \left(1 + \frac{1}{2} - \frac{1}{4}\right) + \cdots + \ln \left(1 + \frac{1}{n} - \frac{1}{n + 2}\right) < \ln 5$ ，再由 $\ln (n + 1) < n, n \in \mathbb{N}^*$ ，
> >
> > $$
> > 1 - \frac {1}{3} + \frac {1}{2} - \frac {1}{4} + \frac {1}{3} - \frac {1}{5} + \dots + \frac {1}{n - 1} - \frac {1}{n + 1} + \frac {1}{n} - \frac {1}{n + 2} = \frac {3}{2} - \frac {1}{n + 1} - \frac {1}{n + 2} <   \frac {3}{2} <   \ln 5.
> > $$

> >
> > 已知函数 $f(x)=e^{x}+2mx^{2}-x.$
> >
> > (1) 若 $x = 0$ 是 $f(x)$ 的极小值点, 求 $m$ 的取值范围;
> >
> > (2) 当 $x > 0$ 时, $f(x) > 1$ 恒成立, 求 $m$ 的取值范围;
> >
> > (3)当 $n\in \mathbf{N}^*$ 时，求证： $n + \frac{1}{2}\leqslant \sum_{i = 1}^{n}e_{1 + i^2}^{\frac{1}{2}}\leqslant n + \frac{7}{4}.$
> >
> > 解析 左边： $\sum_{i = 1}^{n}e^{\frac{1}{1 + i^2}}\geqslant \sum_{i = 1}^{n}\left(1 + \frac{1}{1 + i^2}\right) = n + \sum_{i = 1}^{n}\frac{1}{1 + i^2}\geqslant n + \frac{1}{2}$
> >
> > 右边： $\sum_{i = 1}^{n}e^{\frac{1}{1 + i^2}}\leqslant \sum_{i = 1}^{n}\frac{1}{1 - \frac{1}{1 + i^2}} = \sum_{i = 1}^{n}\left(\frac{1}{i^2} +1\right) = n + \sum_{i = 2}^{n}\frac{1}{i^2} +1 <   n + 1 + \sum_{i = 2}^{n}\frac{1}{(i^2 - 1)} = n + 1 + \frac{1}{3}\left(\frac{1}{3} -\frac{1}{n + 1}\right) = n$ $+ \frac{7}{6} -\frac{1}{2(n + 1)} <  n + \frac{7}{4}.$
> >
> > 注：常见将 $e^x$ 放大 $\left\{ \begin{array}{ll} e^{x} \leqslant \frac{1}{1 - x} & x \in (0, 1) \\ e^{x} \leqslant \frac{2 + x}{2 - x} & x \in (0, 2) \end{array} \right.$
> >
> > 左边法二： $\sum_{i = 1}^{n}e^{1 + i^2} <   n + 1 + \sum_{i = 2}^{n}\frac{1}{i^2} <  n + 1 + \sum_{i = 1}^{n}\frac{1}{\left(i^2 - \frac{1}{4}\right)} = n + 1 + 2\sum_{i = 2}^{n}\frac{2}{(2i - 1)(2i + 1)} = n + 1+$ $2\left(\frac{1}{3} -\frac{1}{5} +\dots +\frac{1}{2n - 1} +\frac{1}{2n + 1}\right) = n + \frac{5}{3} -\frac{2}{2n + 1} <  n + \frac{7}{4}.$
