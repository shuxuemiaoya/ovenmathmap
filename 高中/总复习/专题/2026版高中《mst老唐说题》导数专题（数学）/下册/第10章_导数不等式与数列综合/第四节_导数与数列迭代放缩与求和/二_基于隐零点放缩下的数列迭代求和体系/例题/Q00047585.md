例5 (25 安徽模拟)定义数列 $\{a_{n}\}$ 为“阶梯数列”： $a_{1} = \frac{1}{1}, a_{2} = \frac{1}{1 + \frac{1}{1}}, a_{3} = \frac{1}{1 + \frac{1}{1 + \frac{1}{1}}} \cdots a_{n}$

$$
= \frac {1}{1 + \frac {1}{1 + \frac {1}{\frac {\cdots}{1 + \frac {1}{1}}}}}.
$$

(1)求“阶梯数列”中， $a_{n+1}$ 与 $a_{n}$ 的递推关系；

(2)证明：对 $k \in \mathbf{N}^*$ ，数列 $\{a_{2k-1}\}$ 为递减数列；

(3) 证明： $\left|a_{k+1}-a_{k}\right|\leqslant\frac{1}{2}\cdot\left(\frac{4}{9}\right)^{k-1}$

(1) $a_{n+1}=\frac{1}{1+a_{n}}$ ;

背景分析：显然 $a_{n + 1} = \frac{1}{1 + a_n}$ 的特征函数单调递减，令 $x = \frac{1}{1 + x}$ 可得不动点为 $x = \frac{\sqrt{5} - 1}{2}$

本题作为螺旋形不动点，必有奇偶项位于不动点两侧，由蛛网图可知奇数项大于不动点，偶数项小于不动点.

$a_{2n + 1} - a_{2n - 1} = \frac{1}{1 + a_{2n}} -\frac{1}{a_{2n}} +1 = \frac{a_{2n}^2 + a_{2n} - 1}{a_{2n}(1 + a_{2n})},\frac{a_{n + 1} - \frac{\sqrt{5} - 1}{2}}{a_n - \frac{\sqrt{5} - 1}{2}} = \frac{\frac{1}{1 + a_n} - \frac{\sqrt{5} - 1}{2}}{a_n - \frac{\sqrt{5} - 1}{2}},$ 当 $a_{n} > \frac{\sqrt{5} - 1}{2},a_{n + 1}<$ $\frac{\sqrt{5} - 1}{2}$ ，易得 $0 <   a_{2n} <   \frac{\sqrt{5} - 1}{2}$ ，即 $a_{2n + 1} - a_{2n - 1} = \frac{a_2^2 + a_2n - 1}{a_2n(1 + a_2n)} < 0$ ，所以 $\{a_{2k - 1}\}$ 单调递减
