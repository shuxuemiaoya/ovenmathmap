> > [!note]- **【解析】**
> > 答案 7 解析 $\because a_{1} + a_{2} + a_{3} + \dots + a_{12} = 21, \therefore a_{1} + a_{12} = a_{2} + a_{11} = a_{3} + a_{10} = a_{4} + a_{9} = a_{5} + a_{8} = a_{6} + a_{7} = \frac{21}{6} = \frac{7}{2}, \therefore a_{2} + a_{5} + a_{8} + a_{11} = 7.$
