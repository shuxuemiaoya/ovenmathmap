> [!faq]- 《专题07 等差数列的性质及应用-数列》例题解析
>
> > [!success]- **【答案】** C
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > 答案 A 解析 由 $a_3 + a_4 + a_5 = 3$ 及等差数列的性质， $\therefore 3a_4 = 3$ ，则 $a_4 = 1$ 。又 $a_4 + a_{12} = 2a_8$ ，得 $1 + a_{12} = 2 \times 8$ 。 $\therefore a_{12} = 16 - 1 = 15$ 。
> > (2)在等差数列 $\{a_{n}\}$ 中，若 $a_{3}+a_{4}+a_{5}+a_{6}+a_{7}=450$ ，则 $a_{2}+a_{8}=$ \_\_\_\_.
> > 答案 180 解析 由等差数列的性质，得 $a_{3} + a_{4} + a_{5} + a_{6} + a_{7} = 5a_{5} = 450$ ， $\therefore a_5 = 90$ ， $\therefore a_2 + a_8 = 2a_5 = 180.$
> > (3)等差数列 $a_{n}$ 中，若 $a_2$ ， $a_{2020}$ 为方程 $x^{2} - 10x + 16 = 0$ 的两根，则 $a_1 + a_{1011} + a_{2021}$ 等于（）A.10 B.15 C.20 D.40
> > 答案 B 解析 $\because a_{2}, a_{2020}$ 为方程 $x^{2}-10x+16=0$ 的两根， $\therefore a_{2}+a_{2020}=10$ ，由等差数列的性质得 $2a_{1011}=10$ ，即 $a_{1011}=5,\therefore a_{1}+a_{1011}+a_{2021}=3a_{1011}=15.$
> > (4)数列 $\{a_{n}\}$ 满足 $3 + a_{n} = a_{n + 1}$ 且 $a_2 + a_4 + a_6 = 9$ ，则 $\log_6(a_5 + a_7 + a_9)$ 的值是（）A. -2 B. $-\frac{1}{2}$ C. 2 D. $\frac{1}{2}$
> > 答案 B 解析 答案 C 解析 由 $3 + a_{n} = a_{n + 1}$ ，得 $a_{n + 1} - a_n = 3$ .所以 $\{a_{n}\}$ 是公差为3的等差数列.又 $a_2 + a_4 + a_6 = 9$ ，且 $a_2 + a_6 = 2a_4$ ，所以 $3a_{4} = 9$ ，则 $a_4 = 3$ ，所以 $a_7 = a_4 + 3d = 3 + 3\times 3 = 12$ ，故 $\log_6(a_5 + a_7$ $+a_{9}) = \log_{6}(3a_{7}) = \log_{6}36 = 2.$
> > (5)在等差数列 $\{a_{n}\}$ 中，若 $a_{2}^{2}+2a_{2}a_{8}+a_{6}a_{10}=16$ ，则 $a_{4}a_{6}=$ \_\_\_\_.
> > 答案 4 解析 ∵ 在等差数列 $\{a_{n}\}$ 中， $a_{2}^{2}+2a_{2}a_{8}+a_{6}a_{10}=16,\quad\therefore a_{2}^{2}+a_{2}(a_{6}+a_{10})+a_{6}a_{10}=16,\quad\therefore(a_{2}+a_{6})(a_{2}+a_{10})=16,\quad\therefore2a_{4}\cdot2a_{6}=16,\quad\therefore a_{4}a_{6}=4.$
> > (6)等差数列 $\{a_{n}\}$ ， $\{b_{n}\}$ 满足对任意 $n \in \mathbb{N}^{*}$ 都有 $\frac{a_{n}}{b_{n}} = \frac{2n + 3}{4n - 9}$ ，则 $\frac{a_{7}}{b_{3} + b_{9}} + \frac{a_{5}}{b_{4} + b_{8}} =$ \_\_\_\_.
> > 答案 1 解析 由等差数列的性质可得 $b_{3} + b_{9} = b_{4} + b_{8} = 2b_{6}, a_{7} + a_{5} = 2a_{6}$ ，所以 $\frac{a_7}{b_3 + b_9} + \frac{a_5}{b_4 + b_8} = \frac{2a_6}{2b_6} = \frac{a_6}{b_6} = \frac{2\times 6 + 3}{4\times 6 - 9} = 1$ .
