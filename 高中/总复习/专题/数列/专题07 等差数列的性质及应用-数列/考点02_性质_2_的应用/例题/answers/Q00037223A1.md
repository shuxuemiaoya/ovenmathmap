> > 答案 D 解析 $\because a_{4}, a_{10}$ 是方程 $x^{2} - 8x + 1 = 0$ 的两根， $\therefore a_{4} + a_{10} = 8, \therefore a_{1} + a_{13} = 8, \therefore S_{13} = \frac{13 \times (a_{1} + a_{13})}{2} = \frac{13 \times 8}{2} = 52.$
> > (2)等差数列 $\{a_{n}\}$ 中， $a_1 + a_4 + a_7 = 39$ ， $a_3 + a_6 + a_9 = 27$ ，则数列 $\{a_{n}\}$ 的前9项和 $S_{9}$ 等于（ ）A.99 B.66 C.144 D.297
> > 答案 A 解析 由等差数列的性质可得 $a_1 + a_7 = 2a_4$ ， $a_3 + a_9 = 2a_6$ ，又 $\because a_1 + a_4 + a_7 = 39$ ， $a_3 + a_6 + a_9 = 27$ ， $\therefore 3a_4 = 39, 3a_6 = 27$ ，解得 $a_4 = 13, a_6 = 9$ ， $\therefore a_4 + a_6 = 22$ ， $\therefore$ 数列 $\{a_n\}$ 的前 9 项和 $S_9 = \frac{9(a_1 + a_9)}{2} = \frac{9(a_4 + a_6)}{2} = \frac{9 \times 22}{2} = 99$ .
> > (3)设等差数列 $\{a_{n}\}$ 的前 $n$ 项和为 $S_{n}$ , 已知前 6 项和为 36, 最后 6 项的和为 180, $S_{n} = 324 (n > 6)$ , 则数列 $\{a_{n}\}$ 的项数为 \_\_\_\_.
> > 答案 18 解析 由题意知 $a_1 + a_2 + \ldots + a_6 = 36$ ，①， $a_n + a_{n-1} + a_{n-2} + \ldots + a_{n-5} = 180$ ，②，①+②得 $(a_1 + a_n) + (a_2 + a_{n-1}) + \ldots + (a_6 + a_{n-5}) = 6(a_1 + a_n) = 216$ ， $\therefore a_1 + a_n = 36$ ，又 $S_n = \frac{n(a_1 + a_n)}{2} = 324$ ， $\therefore 18n = 324$ ， $\therefore n = 18$ 。
> > (4)在等差数列 $\{a_{n}\}$ 中， $S_{10}=100,\quad S_{100}=10$ ，则 $S_{110}=$ \_\_\_\_.
> > 答案 解析 方法一 设数列 $\{a_{n}\}$ 的公差为 $d$ ，首项为 $a_{1}$ ，则 $\left\{\begin{aligned} & 10a_{1} + \frac{10 \times 9}{2} d = 100, \\ & 100a_{1} + \frac{100 \times 99}{2} d = 10, \end{aligned}\right.$ 解得 $\left\{\begin{aligned} & a_{1} = \frac{1099}{100}, \\ & d = -\frac{11}{50}. \end{aligned}\right.$ 所以 $S_{110} = 110a_{1} + \frac{110 \times 109}{2} d = -110.$
> > 方法二 因为 $S_{100} - S_{10} = \frac{(a_{11} + a_{100})\times 90}{2} = -90$ ，所以 $a_{11} + a_{100} = -2$ ，所以 $S_{110} = \frac{(a_1 + a_{110})\times 110}{2} = \frac{(a_{11} + a_{100})\times 110}{2} = -110.$
> > (5)已知函数 $y = f(x + 1)$ 的图象关于 $y$ 轴对称，且函数 $f(x)$ 在 $(1, +\infty)$ 上单调，若数列 $\{a_{n}\}$ 是公差不为0的等差数列，且 $f(a_{4}) = f(a_{18})$ ，则 $\{a_{n}\}$ 的前21项和为（）
> > A. 0 B. $\frac{25}{2}$ C. 21 D. 42
> > 答案 C 解析 函数 $y=f(x+1)$ 的图象关于 y 轴对称，平移可得 $y=f(x)$ 的图象关于直线 x=1 对称，且函数 $f(x)$ 在 $(1,+\infty)$ 上单调，由数列 $\{a_{n}\}$ 是公差不为 0 的等差数列，且 $f(a_{4})=f(a_{18})$ ，可得 $a_{4}+a_{18}=2$ ，所以 $a_{1}+a_{21}=a_{4}+a_{18}=2$ ，可得数列 $\{a_{n}\}$ 的前 21 项和 $S_{21}=\frac{21(a_{1}+a_{21})}{2}=21$ 。故选 C.
> > (6)等差数列 $\{a_{n}\}$ 的各项均不为零，其前n项和为 $S_{n}$ 。若 $a_{n+1}^{2}=a_{n+2}+a_{n}$ ，则 $S_{2n+1}=$ \_\_\_\_。
> > 答案 $4n + 2$ 解析 因为 $\{a_{n}\}$ 为等差数列，所以 $a_{n + 2} + a_n = 2a_{n + 1}$ ，又 $a_{n + 1}^2 = a_{n + 2} + a_n$ ，所以 $a_{n + 1}^2 = 2a_{n + 1}$ 。因为数列 $\{a_{n}\}$ 的各项均不为零，所以 $a_{n + 1} = 2$ ，所以 $S_{2n + 1} = \frac{(a_1 + a_{2n + 1})(2n + 1)}{2} = \frac{2\times a_{n + 1}\times(2n + 1)}{2} = 4n + 2$ 。
> > (7)在数列 $\{a_{n}\}$ 中， $2a_{n + 1} = a_n + a_{n + 2}$ ，且 $a_n\neq 0$ 。若 $a_{n - 1} - a_n^2 +a_{n + 1} = 0(n\geqslant 2)$ ，且 $S_{2n - 1} = 38$ ，则 $n = (\quad)$ A. 38 B. 20 C. 10 D. 9
> > 答案 C 解析 在数列 $\{a_{n}\}$ 中，因为 $2a_{n+1}=a_{n}+a_{n+2}$ ，所以 $a_{n+2}-a_{n+1}=a_{n+1}-a_{n}$ ，所以数列 $\{a_{n}\}$ 为等差数列。由 $a_{n-1}-a_{n}^{2}+a_{n+1}=0(n\geqslant2)$ ，得 $2a_{n}-a_{n}^{2}=0$ ，又 $a_{n}\neq0$ ，解得 a\_{n}=2。又 $S_{2n-1}=38$ ，即 $\frac{(2n-1)(a_{1}+a_{2n-1})}{2}=(2n-1)a_{n}=38$ ，即 $(2n-1)\times2=38$ ，解得 n=10。
> > (8)设正项数列 $\{a_{n}\}$ 的前 $n$ 项和为 $S_{n}$ ，且 $4S_{n} = (1 + a_{n})^{2}(n\in \mathbf{N}^{*})$ ，则 $a_5 + a_6 + a_7 + a_8 = (\quad)$ A.24 B.48 C.64 D.72
> > 答案 B 解析 当 n=1 时，由 $S_{1}=a_{1}=\frac{(1+a_{1})^{2}}{4}$ ，得 $a_{1}=1$ ，当 $n\geq2$ 时， $\left\{\begin{aligned}&4S_{n}=(1+a_{n})^{2},\\ &4S_{n-1}=(1+a_{n-1})^{2},\end{aligned}\right.$ 得 $4a_{n}=(1+a_{n})^{2}-(1+a_{n-1})^{2},\quad\therefore a_{n}^{2}-a_{n-1}^{2}-2a_{n}-2a_{n-1}=0,\quad(a_{n}+a_{n-1})(a_{n}-a_{n-1}-2)=0.\quad\because a_{n}>0,\quad\therefore a_{n}-a_{n-1}=2,$ $\therefore\{a_{n}\}$ 是等差数列， $\therefore a_{n}=2n-1,\quad\therefore a_{5}+a_{6}+a_{7}+a_{8}=2(a_{6}+a_{7})=48.$
