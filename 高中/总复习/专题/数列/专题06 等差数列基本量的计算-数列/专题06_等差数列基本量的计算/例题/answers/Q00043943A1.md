> [!faq]- 《专题06 等差数列基本量的计算-数列》例题解析
>
> > [!success]- **【答案】** B
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > 答案 1425 解析 因为 $a_1a_2 + a_2a_3 + \cdots + a_na_{n+1} = na_1a_{n+1}$ ，所以当 $n \geqslant 2$ 时， $a_1a_2 + a_2a_3 + \cdots + a_{n-1}a_n = (n-1)a_1a_n$ ，两式相减可得 $a_na_{n+1} = na_1a_{n+1} - (n-1)a_1a_n$ ，即 $\frac{1}{a_1} = \frac{n}{a_n} - \frac{n-1}{a_{n+1}}$ ，则 $\frac{1}{a_1} = \frac{n+1}{a_{n+1}} - \frac{n}{a_{n+2}}$ ，则 $\frac{n}{a_n} - \frac{n-1}{a_{n+1}} = \frac{n+1}{a_{n+1}} - \frac{n}{a_{n+2}}$ ，即 $\frac{1}{a_n} + \frac{1}{a_{n+2}} = \frac{2}{a_{n+1}}$ ，即数列 $\left\{\frac{1}{a_n}\right\}$ 是等差数列，又由 $a_1 = \frac{1}{4}$ ， $a_5 = \frac{1}{8}$ 可得数列 $\{\frac{1}{a_n}\}$ 的公差 $d = 1$ ，则 $\frac{1}{a_{50}} = 53$ ，则 $\frac{1}{a_1} + \frac{1}{a_2} + \cdots + \frac{1}{a_{50}} = \frac{50 \times (4 + 53)}{2} = 1425.$
