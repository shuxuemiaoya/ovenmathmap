> > [!note]- **【解析】**
> > 答案 C 解析 $\because a_{1} + 5a_{3} = S_{8}, \therefore a_{1} + 5a_{1} + 10d = 8a_{1} + 28d, \therefore a_{1} = -9d, \therefore a_{n} = a_{1} + (n - 1)d = (n - 10)d, \therefore a_{10} = 0$ ，故①一定正确。 $S_{n} = na_{1} + \frac{n(n - 1)d}{2} = -9nd + \frac{n(n - 1)d}{2} = \frac{d}{2}(n^{2} - 19n), \therefore S_{7} = S_{12}$ ，故③一定正确。显然②④不一定正确，
