> [!faq]- 《专题06 等差数列基本量的计算-数列》例题解析
>
> > [!success]- **【答案】** D
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > 答案 D 解析 由题意得 $S_{11} = \frac{11(a_1 + a_{11})}{2} = \frac{11(2a_1 + 10d)}{2} = 22$ ，即 $a_1 + 5d = 2$ ，所以 $a_3 + a_7 + a_8 = a_1 + 2d + a_1 + 6d + a_1 + 7d = 3(a_1 + 5d) = 6$ ，
> >
> > 故选 **D**.
