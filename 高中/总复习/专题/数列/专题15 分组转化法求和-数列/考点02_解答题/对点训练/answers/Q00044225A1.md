> [!faq]- 《专题15 分组转化法求和-数列》例题解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > (1)求数列 $\{b_{n}\}$ 的通项公式;
> >
> > (2)若数列 $\{c_n\}$ 满足 $c_{n} = a_{n + 1} + \frac{1}{b_{2n - 1}\cdot b_{2n + 1}}$ ，求数列 $\{c_n\}$ 的前 $n$ 项和 $S_{n}$
> >
> > 18. 解析
> > (1)设等比数列 $\{a_{n}\}$ 的公比为 $q$ ，且 $q > 0$ ，由 $a_{n} > 0$ ， $a_{1}a_{3} = 4$ ，得 $a_{2} = 2$ ，又 $a_{3}$ 是 $a_{2} - 2$ 与 $a_{4}$ 的等差中项，故 $2a_{3} = a_{2} - 2 + a_{4}$ ， $\therefore 2 \cdot 2q = 2 - 2 + 2q^{2}$ ， $\therefore q = 2$ 或 $q = 0$ （舍）。 $\therefore a_{n} = a_{2}q^{n - 2} = 2^{n - 1}$ ， $\therefore a_{n + 1} = 2^{n} = 2^{b_{n}}$ ， $\therefore b_{n} = n(n \in \mathbb{N}^{*})$ 。
> >
> > (2)由
> > (1)得， $c_{n} = a_{n + 1} + \frac{1}{b_{2n - 1} \cdot b_{2n + 1}} = 2^{n} + \frac{1}{(2n - 1)(2n + 1)} = 2^{n} + \frac{1}{2}\left[\frac{1}{2n - 1} - \frac{1}{2n + 1}\right]$ ， $\therefore$ 数列 $\{c_{n}\}$ 的前 $n$ 项和 $S_{n} = 2 + 2^{2} + \dots + 2^{n} + \frac{1}{2}\left[\left(1 - \frac{1}{3}\right) + \left(\frac{1}{3} - \frac{1}{5}\right) + \dots + \left(\frac{1}{2n - 1} - \frac{1}{2n + 1}\right)\right]$ $= \frac{2(1 - 2^{n})}{1 - 2} + \frac{1}{2}\left[1 - \frac{1}{2n + 1}\right] = 2^{n + 1} - 2 + \frac{n}{2n + 1}(n \in \mathbb{N}^{*})$ 。
