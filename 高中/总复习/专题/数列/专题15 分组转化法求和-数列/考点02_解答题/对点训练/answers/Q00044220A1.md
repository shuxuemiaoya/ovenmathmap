> [!faq]- 《专题15 分组转化法求和-数列》例题解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > (1)求数列 $\{a_{n}\}$ 的通项公式;
> >
> > $$
> > \{b _ {n} \}
> > $$
> >
> > $$
> > \{a _ {n} \}
> > $$
> >
> > $$
> > c _ {1} + c _ {2} + \dots + c _ {1 0 0}
> > $$
> >
> > 16. 解析
> > (1) 因为 $n, a_n, S_n$ 成等差数列，所以 $S_n + n = 2a_n$ ，①
> > 所以 $S_{n-1} + n - 1 = 2a_{n-1}(n \geqslant 2)$ ，②
> > - **①**：-②，得 $a_n + 1 = 2a_n - 2a_{n-1}$ ，所以 $a_n + 1 = 2(a_{n-1} + 1)(n \geqslant 2)$ ，又当 $n = 1$ 时， $S_1 + 1 = 2a_1$ ，所以 $a_1 = 1$ ，所以 $a_1 + 1 = 2$ ，故数列 $\{a_n + 1\}$ 是首项为 2，公比为 2 的等比数列，所以 $a_n + 1 = 2 \cdot 2^{n-1} = 2^n$ ，即 $a_n = 2^n - 1$ 。
> > （2）据
> > (1)求解知， $b_n = 2\log_2(1 + 2^n - 1) - 1 = 2n - 1, b_1 = 1$ ，所以 $b_{n+1} - b_n = 2$ ，所以数列 $\{b_n\}$ 是以 1 为首项，2 为公差的等差数列，又因为 $a_1 = 1, a_2 = 3, a_3 = 7, a_4 = 15, a_5 = 31, a_6 = 63, a_7 = 127, a_8 = 255, b_{64} = 127, b_{106} = 211, b_{107} = 213,$ 所以 $c_1 + c_2 + \cdots + c_{100} = (b_1 + b_2 + \cdots + b_{107}) - (a_1 + a_2 + \cdots + a_7)$ $= \frac{107 \times (1 + 213)}{2} - [(2^1 + 2^2 + \cdots + 2^7) - 7] = \frac{107 \times 214}{2} - \frac{2(1 - 2^7)}{1 - 2} + 7 = 107^2 - 2^8 + 9 = 11202.$
