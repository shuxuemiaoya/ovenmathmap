> [!faq]- 《专题15 分组转化法求和-数列》例题解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > (1)求数列 $\{a_{n}\}$ 的通项公式;
> > (2)若 $b_{n} = 2^{an} + a_{n}$ ，求数列 $\{b_n\}$ 的前 $n$ 项和 $T_{n}$
> > 8. 解析
> > (1) $\because \{a_{n}\}$ 为等差数列， $\therefore \left\{ \begin{array}{l} S_{4} = 4a_{1} + \frac{4 \times 3}{2} d = 24, \\ S_{7} = 7a_{1} + \frac{7 \times 6}{2} d = 63, \end{array} \right.$ 解得 $\left\{ \begin{array}{l} a_{1} = 3, \\ d = 2, \end{array} \right.$ $\therefore a_{n} = 2n + 1.$
> > (2) $\because b_{n} = 2^{an} + a_{n} = 2^{2n + 1} + (2n + 1) = 2 \times 4^{n} + (2n + 1),$ $\therefore T_{n} = 2 \times (4 + 4^{2} + \ldots + 4^{n}) + (3 + 5 + \ldots + 2n + 1) = 2 \times \frac{4(1 - 4^{n})}{1 - 4} + \frac{n(3 + 2n + 1)}{2} = \frac{8}{3}(4^{n} - 1) + n^{2} + 2n.$
