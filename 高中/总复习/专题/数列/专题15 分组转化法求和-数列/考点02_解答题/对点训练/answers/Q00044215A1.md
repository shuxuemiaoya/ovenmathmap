> [!faq]- 《专题15 分组转化法求和-数列》例题解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【解析】**
> > 解析
> > (1)设等比数列 $\{a_{n}\}$ 的公比为q，∵ $a_{1}$ ， $a_{2}$ ， $a_{3}-1$ 成等差数列，
> >
> > $\therefore 2a_{2} = a_{1} + (a_{3} - 1) = a_{3}, \therefore q = \frac{a_{3}}{a_{2}} = 2, \therefore a_{n} = a_{1}q^{n - 1} = 2^{n - 1}(n \in \mathbf{N}^{*}).$
> > (2)由
> > (1)知 $b_{n} = 2n - 1 + a_{n} = 2n - 1 + 2^{n - 1}$ , $\therefore S_{n} = (1 + 1) + (3 + 2) + (5 + 2^{2}) + \dots + (2n - 1 + 2^{n - 1})$ $= [1 + 3 + 5 + \dots + (2n - 1)] + (1 + 2 + 2^{2} + \dots + 2^{n - 1})$ $= \frac{1 + (2n - 1)}{2} \cdot n + \frac{1 - 2^{n}}{1 - 2} = n^{2} + 2^{n} - 1.$ $\because S_{n} - (n^{2} + 2^{n}) = -1 < 0, \therefore S_{n} < n^{2} + 2^{n}.$
