>
> > [!success]- **【答案】** B
>
> > [!note]- **【解析】**
> > 答案 B 解析 由题意，得 $a_1 + a_2 + a_3 + \cdots + a_{100} = 1^2 - 2^2 - 2^2 + 3^2 + 3^2 - 4^2 - 4^2 + 5^2 + \cdots + 99^2 - 100^2 - 100^2 + 101^2 = (1^2 - 2^2) + (3^2 - 2^2) + (3^2 - 4^2) + \cdots + (99^2 - 100^2) + (101^2 - 100^2) = -(1 + 2) + (3 + 2) - (4 + 3) + \cdots - (99 + 100) + (101 + 100) = -(1 + 2 + \cdots + 99 + 100) + (2 + 3 + \cdots + 100 + 101) = -50 \times 101 + 50 \times 103 = 100$ 。
> >
> > 故选 **B**.
