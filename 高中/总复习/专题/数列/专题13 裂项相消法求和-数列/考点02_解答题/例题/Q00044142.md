[例9] 已知在数列 $\{a_{n}\}$ 中， $a_1 = 1$ ， $a_2 = 2$ ， $a_{n + 1} = 3a_n - 2a_{n - 1}(n\geqslant 2$ ， $n\in \mathbf{N}^*)$ .设 $b_{n} = a_{n + 1} - a_{n}$

(1)证明：数列 $\{b_{n}\}$ 是等比数列；

(2)设 $c_{n} = \frac{b_{n}}{(4n^{2} - 1)2^{n}}$ ，求数列 $\{c_n\}$ 的前 $n$ 项和 $S_{n}$

(1) 因为 $a_{n+1} = 3a_n - 2a_{n-1} (n \geqslant 2, n \in \mathbb{N}^*)$ , $b_n = a_{n+1} - a_n$ ,

所以 $\frac{b_{n + 1}}{b_n} = \frac{a_{n + 2} - a_{n + 1}}{a_{n + 1} - a_n} = \frac{3a_{n + 1} - 2a_n - a_{n + 1}}{a_{n + 1} - a_n} = \frac{2(a_{n + 1} - a_n)}{a_{n + 1} - a_n} = 2,$

又 $b_{1} = a_{2} - a_{1} = 2 - 1 = 1$ ，所以数列 $\{b_n\}$ 是以1为首项，2为公比的等比数列.

(2)由
(1)知 $b_{n} = 1\times 2^{n - 1} = 2^{n - 1}$ ，因为 $c_{n} = \frac{b_{n}}{(4n^{2} - 1)2^{n}},$

所以 $c_{n}=\frac{1}{2(2n+1)(2n-1)}=\frac{1}{4}\left(\frac{1}{2n-1}-\frac{1}{2n+1}\right)$ ,

$$
S _ {n} = c _ {1} + c _ {2} + \dots + c _ {n} = \frac {1}{4} \left(1 - \frac {1}{3} + \frac {1}{3} - \frac {1}{5} + \dots + \frac {1}{2 n - 1} - \frac {1}{2 n + 1}\right) = \frac {1}{4} \left(1 - \frac {1}{2 n + 1}\right) = \frac {n}{4 n + 2}.
$$
