> [!faq]- 《专题13 裂项相消法求和-数列》例题解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > (1)求数列 $\{a_{n}\}$ 的通项公式;
> > (2)若 $b_{n} = (-1)^{n + 1}\frac{2a_{n} + 1}{a_{n}a_{n + 1}}$ ，数列 $\{b_n\}$ 的前 $n$ 项和为 $T_{n}$ ，求 $T_{2021}$
> > 31. 解析 (1)由题设， $S_{n}=\frac{(n+1)a_{n}}{2}$ ①，当 $n\geqslant2$ 时， $S_{n-1}=\frac{na_{n-1}}{2}$ ②
> > - **①**：-②，得 $a_{n} = \frac{(n + 1)a_{n}}{2} -\frac{na_{n - 1}}{2} (n\geqslant 2)$ ，则 $(n - 1)a_{n} = na_{n - 1}$
> > $\therefore\frac{a_{n}}{n}=\frac{a_{n-1}}{n-1}=\cdots=\frac{a_{1}}{1}=1.$ 所以 $a_{n}=n.$
> > 又 $a_{1}$ 适合上式，故 $a_{n}=n$ .
> > $$
> > (2) b _ {n} = (- 1) ^ {n + 1} \frac {2 n + 1}{n (n + 1)} = (- 1) ^ {n + 1} \left(\frac {1}{n} + \frac {1}{n + 1}\right).
> > $$
> > $$
> > T _ {2 0 2 1} = \left(1 + \frac {1}{2}\right) - \left(\frac {1}{2} + \frac {1}{3}\right) + \left(\frac {1}{3} + \frac {1}{4}\right) - \dots - \left(\frac {1}{2 0 2 0} + \frac {1}{2 0 2 1}\right) + \left(\frac {1}{2 0 2 1} + \frac {1}{2 0 2 2}\right) = 1 + \frac {1}{2 0 2 2} = \frac {2 0 2 3}{2 0 2 2}.
> > $$
