> [!faq]- 《专题13 裂项相消法求和-数列》例题解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【解析】**
> > 解析
> > (1) $\because a_{2} = 8, S_{n} = \frac{a_{n + 1}}{2} - n - 1, \therefore a_{1} = S_{1} = \frac{a_{2}}{2} - 2 = 2,$ 当 $n\geq 2$ 时， $a_{n} = S_{n} - S_{n - 1} = \frac{a_{n + 1}}{2} -n - 1 - \left(\frac{a_n}{2} -n\right)$ 即 $a_{n + 1} = 3a_{n} + 2$ ，又 $a_2 = 8 = 3a_1 + 2$ $\therefore a_{n + 1} = 3a_{n} + 2,n\in \mathbf{N}^{*},\therefore a_{n + 1} + 1 = 3(a_{n} + 1),$ $\therefore$ 数列 $\{a_n + 1\}$ 是等比数列，且首项为 $a_1 + 1 = 3$ ，公比为3， $\therefore a_n + 1 = 3\times 3^{n - 1} = 3^n$ ， $\therefore a_n = 3^n -1.$
> > (2) $\because \frac{2\times 3^n}{a_na_{n + 1}} = \frac{2\times 3^n}{(3^n - 1)(3^{n + 1} - 1)} = \frac{1}{3^n - 1} -\frac{1}{3^{n + 1} - 1}.$ $\therefore$ 数列 $\left\{\frac{2\times 3^n}{a_na_{n + 1}}\right\}$ 的前 $n$ 项和 $T_{n} = \left(\frac{1}{3 - 1} -\frac{1}{3^{2} - 1}\right) + \left(\frac{1}{3^{2} - 1} -\frac{1}{3^{3} - 1}\right) + \dots +\left(\frac{1}{3^n - 1} -\frac{1}{3^{n + 1} - 1}\right) = \frac{1}{2} -\frac{1}{3^{n + 1} - 1}.$
