> > (2)(2017·全国Ⅱ)等差数列 $\{a_{n}\}$ 的前n项和为 $S_{n}$ ， $a_{3}=3$ ， $S_{4}=10$ ，则错误! $\frac{1}{S_{k}}=$ \_\_\_\_.
> > 答案 $\frac{2n}{n+1}$ 解析 设公差为 d，则 $\left\{\begin{aligned}a_{1}+2d=3,\\ 4a_{1}+6d=10,\end{aligned}\right.$ $\therefore\left\{\begin{aligned}a_{1}=1,\\ d=1,\end{aligned}\right.$ $\therefore a_{n}=n.\therefore$ 前 n 项和 $S_{n}=1+2+\cdots$ $+n=\frac{n(n+1)}{2},\quad\therefore\frac{1}{S_{n}}=\frac{2}{n(n+1)}=2\left(\frac{1}{n}-\frac{1}{n+1}\right),\quad\therefore$ 错误! $\frac{1}{S_{k}}=2\left(1-\frac{1}{2}+\frac{1}{2}-\frac{1}{3}+\cdots+\frac{1}{n}-\frac{1}{n+1}\right)=2\left(1-\frac{1}{n+1}\right)=2\cdot\frac{n}{n+1}=\frac{2n}{n+1}.$
> > (3)设等差数列 $\{a_{n}\}$ 的前 $n$ 项和为 $S_{n}$ ，已知 $a_1 = 9$ ， $a_2$ 为整数，且 $S_{n} \leqslant S_{5}$ ，则数列 $\left\{\frac{1}{a_n a_{n+1}}\right\}$ 的前9项和为 \_\_\_\_. 答案 $-\frac{1}{9}$ 解析 由 $S_{n} \leqslant S_{5}$ 得 $\left\{\begin{array}{l} a_5 \geqslant 0, \\ a_6 \leqslant 0, \end{array}\right.$ 即 $\left\{\begin{array}{l} a_1 + 4d \geqslant 0, \\ a_1 + 5d \leqslant 0, \end{array}\right.$ 得 $-\frac{9}{4} \leqslant d \leqslant -\frac{9}{5}$ ，又 $a_2$ 为整数，所以 $d = -2$ ， $a_n = a_1 + (n-1) \times d = 11 - 2n$ ， $\frac{1}{a_na_{n+1}} = \frac{1}{d} \left[\frac{1}{a_n} - \frac{1}{a_{n+1}}\right]$ ，所以数列 $\left\{\frac{1}{a_na_{n+1}}\right\}$ 的前 $n$ 项和 $T_n = \frac{1}{d} \left[\frac{1}{a_1} - \frac{1}{a_2} + \frac{1}{a_2} - \frac{1}{a_3} + \cdots + \frac{1}{a_n} - \frac{1}{a_{n+1}}\right] = \frac{1}{d} \left[\frac{1}{a_1} - \frac{1}{a_{n+1}}\right]$ ，所以 $T_9 = -\frac{1}{2} \times \left[\frac{1}{9} - \left(-\frac{1}{9}\right)\right] = -\frac{1}{9}$ .
> > (4)定义各项为正数的数列 $\{p_n\}$ 的“美数”为 $\frac{n}{p_1 + p_2 + \ldots + p_n} (n \in \mathbb{N}^*)$ 。若各项为正数的数列 $\{a_n\}$ 的“美数” $\frac{1}{2n + 1}$ ，且 $b_n = \frac{a_n + 1}{4}$ ，则 $\frac{1}{b_1 b_2} + \frac{1}{b_2 b_3} + \ldots + \frac{1}{b_{2021} b_{2022}} =$ \_\_\_\_.
> > 答案 $\frac{2021}{2022}$ 解析 因为各项为正数的数列 $\{a_n\}$ 的“美数”为 $\frac{1}{2n + 1}$ ，所以 $\frac{n}{a_1 + a_2 + \ldots + a_n} = \frac{1}{2n + 1}$ ，即 $S_{n} = n(2n + 1)$ ，则 $S_{n - 1} = (n - 1)[2(n - 1) + 1] = 2n^2 -3n + 1(n\geq 2)$ ，所以 $a_{n} = S_{n} - S_{n - 1} = 4n - 1(n\geq 2)$ ，又 $\frac{1}{a_1} = \frac{1}{3}$ ，所以 $a_1 = 3$ ，满足式子 $a_{n} = 4n - 1$ ，所以 $a_{n} = 4n - 1(n\in \mathbf{N}^{*})$ 。又 $b_{n} = \frac{a_{n} + 1}{4}$ ，所以 $b_{n} = n$ ，所以 $\frac{1}{b_1b_2} +\frac{1}{b_2b_3} +\ldots$ $+ \frac{1}{b_{2021}b_{2022}} = \frac{1}{1\times 2} +\frac{1}{2\times 3} +\ldots +\frac{1}{2021\times 2022} = \left(1 - \frac{1}{2}\right) + \left(\frac{1}{2} -\frac{1}{3}\right) + \ldots +\left(\frac{1}{2021} -\frac{1}{2022}\right) = 1 - \frac{1}{2022} = \frac{2021}{2022}$ 。
> > (5)若数列 $\{a_{n}\}$ 满足 $a_{1}=1$ ，且对于任意的 $n\in N^{*}$ 都有 $a_{n+1}=a_{n}+n+1$ ，则 $\frac{1}{a_{1}}+\frac{1}{a_{2}}+\cdots+\frac{1}{a_{2021}}+\frac{1}{a_{2022}}$ 等于（）
> > A. $\frac{4035}{2021}$ B. $\frac{2016}{2022}$ C. $\frac{4044}{2023}$ D. $\frac{4035}{2024}$
> > 答案 C 解析 由 $a_{n+1} = a_n + n + 1$ ，得 $a_{n+1} - a_n = n + 1$ ，则 $a_2 - a_1 = 1 + 1, a_3 - a_2 = 2 + 1, a_4 - a_3 = 3$ +1, $\cdots$ , $a_{n}-a_{n-1}=(n-1)+1$ ，以上等式相加，得 $a_{n}-a_{1}=1+2+3+\cdots+(n-1)+n-1$ ，把 $a_{1}=1$ 代入上式得， $a_{n}=1+2+3+\cdots+(n-1)+n=\frac{n(n+1)}{2}$ ， $\frac{1}{a_{n}}=\frac{2}{n(n+1)}=2\left(\frac{1}{n}-\frac{1}{n+1}\right)$ ，则 $\frac{1}{a_{1}}+\frac{1}{a_{2}}+\cdots+\frac{1}{a_{2021}}+\frac{1}{a_{2022}}=$ $2\left[\left(1-\frac{1}{2}\right)+\left(\frac{1}{2}-\frac{1}{3}\right)+\cdots+\left(\frac{1}{2021}-\frac{1}{2022}\right)+\left(\frac{1}{2022}-\frac{1}{2023}\right)\right]=2\left(1-\frac{1}{2023}\right)=\frac{4044}{2023}.$
> > (6)已知数列 $\{4^n - 2^n\} (n \in \mathbf{N}^*)$ 的前 $n$ 项和为 $S_n, b_n = \frac{2^n}{S_n}$ , 则数列 $\{b_n\}$ 的前 $n$ 项和 $T_n = \_$ .
> > 答案 $\frac{3(2^n - 1)}{2^{n+1} - 1}$ 解析 $S_n = \frac{4}{3} \times (2^{2n} - 1) - 2 \times (2^n - 1) = \frac{2}{3} \times [2(2^n + 1)(2^n - 1) - 3 \times (2^n - 1)] = \frac{2}{3} \times (2^{n+1} - 1)(2^n - 1)$ . 所以 $b_n = \frac{2^n}{S_n} = \frac{3}{2} \times \frac{2^n}{(2^{n+1} - 1)(2^n - 1)} = \frac{3}{2} \left[ \frac{1}{2^n - 1} - \frac{1}{2^{n+1} - 1} \right]$ . 所以 $T_n =$ 错误！ $i = \frac{3}{2} \left[ \left( \frac{1}{2^1 - 1} - \frac{1}{2^2 - 1} \right) + \left( \frac{1}{2^2 - 1} - \frac{1}{2^3 - 1} \right) + \cdots + \left( \frac{1}{2^n - 1} - \frac{1}{2^{n+1} - 1} \right) \right] = \frac{3}{2} \left[ 1 - \frac{1}{2^{n+1} - 1} \right] = \frac{3(2^n - 1)}{2^{n+1} - 1}$ .
> > (7)已知 $S_{n}$ 为数列 $\{a_{n}\}$ 的前 $n$ 项和， $a_{n} = 2 \cdot 3^{n - 1}(n \in \mathbb{N}^{*})$ ，若 $b_{n} = \frac{a_{n + 1}}{S_{n} S_{n + 1}}$ ，则 $b_{1} + b_{2} + \ldots + b_{n} =$ \_\_\_\_。答案 $\frac{1}{2} - \frac{1}{3^{n + 1} - 1}$ 解析由 $a_{n} = 2 \cdot 3^{n - 1}$ 可知数列 $\{a_{n}\}$ 是以2为首项，3为公比的等比数列，所以 $S_{n} = \frac{2(1 - 3^{n})}{1 - 3} = 3^{n} - 1$ ，则 $b_{n} = \frac{a_{n + 1}}{S_{n} S_{n + 1}} = \frac{S_{n + 1} - S_{n}}{S_{n} S_{n + 1}} = \frac{1}{S_{n}} - \frac{1}{S_{n + 1}}$ ，则 $b_{1} + b_{2} + \ldots + b_{n} = \left(\frac{1}{S_{1}} - \frac{1}{S_{2}}\right) + \left(\frac{1}{S_{2}} - \frac{1}{S_{3}}\right) + \ldots + \left(\frac{1}{S_{n}} - \frac{1}{S_{n + 1}}\right) = \frac{1}{S_{1}} - \frac{1}{S_{n + 1}} = \frac{1}{2} - \frac{1}{3^{n + 1} - 1}$ .
