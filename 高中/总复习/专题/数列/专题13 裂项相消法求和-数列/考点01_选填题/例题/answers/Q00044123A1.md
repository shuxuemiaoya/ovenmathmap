> [!faq]- 《专题13 裂项相消法求和-数列》例题解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【解析】**
> > 答案 $\frac{2021}{2022}$ 解析 因为各项为正数的数列 $\{a_n\}$ 的“美数”为 $\frac{1}{2n + 1}$ ，所以 $\frac{n}{a_1 + a_2 + \ldots + a_n} = \frac{1}{2n + 1}$ ，即 $S_{n} = n(2n + 1)$ ，则 $S_{n - 1} = (n - 1)[2(n - 1) + 1] = 2n^2 -3n + 1(n\geq 2)$ ，所以 $a_{n} = S_{n} - S_{n - 1} = 4n - 1(n\geq 2)$ ，又 $\frac{1}{a_1} = \frac{1}{3}$ ，所以 $a_1 = 3$ ，满足式子 $a_{n} = 4n - 1$ ，所以 $a_{n} = 4n - 1(n\in \mathbf{N}^{*})$ 。又 $b_{n} = \frac{a_{n} + 1}{4}$ ，所以 $b_{n} = n$ ，所以 $\frac{1}{b_1b_2} +\frac{1}{b_2b_3} +\ldots$ $+ \frac{1}{b_{2021}b_{2022}} = \frac{1}{1\times 2} +\frac{1}{2\times 3} +\ldots +\frac{1}{2021\times 2022} = \left(1 - \frac{1}{2}\right) + \left(\frac{1}{2} -\frac{1}{3}\right) + \ldots +\left(\frac{1}{2021} -\frac{1}{2022}\right) = 1 - \frac{1}{2022} = \frac{2021}{2022}$ 。
