> [!faq]- 《专题13 裂项相消法求和-数列》例题解析
>
> > [!success]- **【答案】** A
>
> > [!note]- **【解析】**
> > 答案 A 解析 由 $S_{n} = n^{2} + 4n$ ，可得 $a_{n} = 2n + 3$ ，根据 $\frac{1}{b_{n+1}} - \frac{1}{b_n} = a_n = 2n + 3$ ，结合题设条件，应用累加法可求得 $\frac{1}{b_n} = n^2 + 2n$ ，所以 $b_{n} = \frac{1}{n^2 + 2n} = \frac{1}{n(n + 2)} = \frac{1}{2}\left[\frac{1}{n} - \frac{1}{n + 2}\right]$ ，所以数列 $\{b_n\}$ 的前 $n$ 项和为 $T_{n} = \frac{1}{2}\left[1 - \frac{1}{3} + \frac{1}{2} - \frac{1}{4} + \ldots + \frac{1}{n} - \frac{1}{n + 2}\right] = \frac{1}{2}\left[\frac{3}{2} - \frac{1}{n + 1} - \frac{1}{n + 2}\right]$ ，所以 $T_{10} = \frac{1}{2}\left[\frac{3}{2} - \frac{1}{11} - \frac{1}{12}\right] = \frac{175}{264}$ ，
> >
> > 故选 **A**.
