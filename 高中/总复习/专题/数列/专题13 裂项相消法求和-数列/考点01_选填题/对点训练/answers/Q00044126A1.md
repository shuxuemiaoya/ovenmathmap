> > (4) = 2$ 可得 $4^{\alpha} = 2$ ，解得 $\alpha = \frac{1}{2}$ ，则 $f(x) = x^{\frac{1}{2}}$ . $\therefore a_{n} = \frac{1}{f(n + 1) + f(n)} = \frac{1}{\sqrt{n + 1} + \sqrt{n}} = \sqrt{n + 1} - \sqrt{n}, S_{2019} = a_{1} + a_{2} + a_{3} + \ldots + a_{2019} = (\sqrt{2} - \sqrt{1}) + (\sqrt{3} - \sqrt{2}) + (\sqrt{4} - \sqrt{3}) + \ldots + (\sqrt{2019} - \sqrt{2018}) + (\sqrt{2020} - \sqrt{2019}) = \sqrt{2020} - 1.$
