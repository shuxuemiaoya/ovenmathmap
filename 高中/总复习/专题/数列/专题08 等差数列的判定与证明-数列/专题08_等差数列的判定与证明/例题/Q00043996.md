[例 2] 已知等差数列 $\{a_{n}\}$ 的前 n 项和为 $S_{n}$ ，且 $a_{3}=7,\quad a_{5}+a_{7}=26.$

(1)求 $a_{n}$ 及 $S_{n}$ ;

(2)令 $b_{n} = \frac{S_{n}}{n} (n\in \mathbf{N}^{*})$ ，求证：数列 $\{b_n\}$ 为等差数列.

(1)设等差数列 $\{a_{n}\}$ 的首项为 $a_1$ ，公差为 $d$ ，由题意有 $\left\{\begin{aligned} & a_1 + 2d = 7, \\ & 2a_1 + 10d = 26, \end{aligned}\right.$ 解得 $a_1 = 3, d = 2$ ，则 $a_{n} = a_{1} + (n - 1)d = 3 + 2(n - 1) = 2n + 1, S_{n} = \frac{n(a_{1} + a_{n})}{2} = \frac{n[3 + (2n + 1)]}{2} = n(n + 2)$ .

(2)因为 $b_{n} = \frac{S_{n}}{n} = \frac{n(n + 2)}{n} = n + 2$ ，又 $b_{n + 1} - b_{n} = n + 3 - (n + 2) = 1$ ，

所以数列 $\{b_{n}\}$ 是首项为3，公差为1的等差数列.
