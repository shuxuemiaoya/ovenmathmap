> [!faq]- 《专题08 等差数列的判定与证明-数列》例题解析
>
> > [!success]- **【答案】** C
>
> > [!note]- **【解析】**
> > 答案 C 解析 令 $b_{n} = a_{2n - 1} + 2a_{2n}$ ，则 $b_{n + 1} = a_{2n + 1} + 2a_{2n + 2}$ ，故 $b_{n + 1} - b_{n} = a_{2n + 1} + 2a_{2n + 2} - (a_{2n - 1} + 2a_{2n}) = (a_{2n + 1} - a_{2n - 1}) + 2(a_{2n + 2} - a_{2n}) = 2d + 4d = 6d = 6 \times 1 = 6$ 。即 $\{a_{2n - 1} + 2a_{2n}\}$ 是公差为6的等差数列。
