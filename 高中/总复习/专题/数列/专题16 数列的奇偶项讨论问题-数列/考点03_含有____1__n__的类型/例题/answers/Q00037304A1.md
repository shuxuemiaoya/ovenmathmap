> > (2)若数列 $\{a_{n}\}$ 的通项公式 $a_{n} = (-1)^{n}\frac{2n + 1}{n^{2} + n}$ ，则它的前 $n$ 项和 $S_{n} =$ \_\_\_\_.
> > 答案 $-1+\frac{(-1)^{n}}{n+1}$ 或 $\left\{\begin{aligned}-\frac{n+2}{n+1},&n\text{为奇数,}\\-\frac{n}{n+1},&n\text{为偶数}\end{aligned}\right.$ 解析 $a_{n}=(-1)^{n}\frac{n+(n+1)}{n(n+1)}=(-1)^{n}\left(\frac{1}{n+1}+\frac{1}{n}\right),\quad S_{n}=-$ $\left(1+\frac{1}{2}\right)+\left(\frac{1}{2}+\frac{1}{3}\right)-\left(\frac{1}{3}+\frac{1}{4}\right)+\cdots+(-1)^{n}\left(\frac{1}{n}+\frac{1}{n+1}\right),\quad$ 当 n 为偶数时， $S_{n}=-1+\frac{1}{n+1}$ ，当 n 为奇数时， $S_{n}=-1-\frac{1}{n+1}$ ，综上所述 $S_{n}=-1+\frac{(-1)^{n}}{n+1}.$

> > 答案（-1，3）解析 当 $n = 1$ 时， $a_1 = S_1 = -1$ ；当 $n \geqslant 2$ 时， $a_n = S_n - S_{n-1} = (-1)^n n - (-1)^{n-1}(n-1) = (-1)^n (2n-1)$ 。因为对任意的正整数 $n$ ， $(a_{n+1} - p)(a_n - p) < 0$ 恒成立，所以 $[( -1)^{n+1}(2n+1) - p] [( -1)^n (2n-1) - p] < 0$ 。
> > - **①**：当 $n$ 是正奇数时，化为 $[p - (2n+1)][p + (2n-1)] < 0$ ，解得 $1 - 2n < p < 2n + 1$ ，因为对任意的正奇数 $n$ 都成立，取 $n = 1$ 时，可得 $-1 < p < 3$ 。
> > - **②**：当 $n$ 是正偶数时，化为 $[p - (2n-1)][p + (1+2n)] < 0$ ，解得 $-1 - 2n < p < 2n - 1$ ，因为对任意的正偶数 $n$ 都成立，取 $n = 2$ 时，可得 $-5 < p < 3$ 。联立 $\left\{ \begin{array}{l} -1 < p < 3, \\ -5 < p < 3, \end{array} \right.$ 解得 $-1 < p < 3$ 。所以实数 $p$ 的取值范围是 $(-1, 3)$ 。

> > (8)在数列 $\{a_{n}\}$ 中， $a_1 = 1$ ， $a_2 = 3$ ，且 $\frac{a_{n + 2}}{a_n} = 2 + (-1)^n (n\in \mathbf{N}^*)$ ， $S_{n}$ 为数列 $\{a_{n}\}$ 的前 $n$ 项和，则 $S_{100}$ 等于（）A. $\frac{3^{50} - 1}{2} +50$ B. $\frac{3(1 - 3^{50})}{2} +50$ C. $\frac{3(3^{50} - 1)}{2} +50$ D. $\frac{3(3^{100} - 1)}{2} +50$
> > 答案 C 解析 由题意 $\frac{a_{n+2}}{a_n} = 2 + (-1)^n (n \in \mathbf{N}^*)$ ，当 $n$ 为偶数时，可得 $\frac{a_{n+2}}{a_n} = 3$ ；当 $n$ 为奇数时，可得 $\frac{a_{n+2}}{a_n} = 1$ ，即数列的偶数项成公比为 3 的等比数列，奇数项都为 1，由求和公式可得 $S_{100} = \frac{3(3^{50}-1)}{3-1} + 50 = \frac{3(3^{50}-1)}{2} + 50$ .
> > (9)已知数列 $\{a_{n}\}$ 满足 $a_1 = 1, a_2 = \frac{1}{2}$ , 且 $[3 + (-1)^n] a_{n+2} - 2a_n + 2[(-1)^n - 1] = 0, n \in \mathbf{N}^*$ , 记 $T_{2n}$ 为数列 $\{a_{n}\}$ 的前 $2n$ 项和, 数列 $\{b_{n}\}$ 是首项和公比都是 2 的等比数列, 则使不等式 $\left(T_{2n} + \frac{1}{b_n}\right) \cdot \frac{1}{b_n} < 1$ 成立的最小整数 $n$ 的值为 ( ) A. 7 B. 6 C. 5 D. 4
> > 答案 C 解析 因为 $[3+(-1)^{n}]a_{n+2}-2a_{n}+2[(-1)^{n}-1]=0,\quad n\in\mathbf{N}^{*}$ ，所以当 n 为奇数时， $a_{n+2}-a_{n}=2$ ，且 $a_{1}=1$ ，所以数列 $\{a_{n}\}$ 的奇数项构成首项为 1，公差为 2 的等差数列；当 n 为偶数时， $\frac{a_{n+2}}{a_{n}}=\frac{1}{2}$ ，且 $a_{2}=\frac{1}{2}$ ，所以数列 $\{a_{n}\}$ 的偶数项构成首项为 $\frac{1}{2}$ ，公比为 $\frac{1}{2}$ 的等比数列，则 $T_{2n}=(a_{1}+a_{3}+a_{5}+\cdots+a_{2n-1})+(a_{2}+$ $a_{4}+a_{6}+\cdots+a_{2n})=n^{2}+1-\left(\frac{1}{2}\right)^{n}$ . 又因为数列 $\{b_{n}\}$ 是首项和公比都是2的等比数列，所以 $b_{n}=2^{n}$ ，则 $\left(T_{2n}+\frac{1}{b_{n}}\right)\cdot\frac{1}{b_{n}}<1$ 等价于 $\frac{1}{2^{n}}(n^{2}+1)<1$ ，即 $n^{2}+1<2^{n}$ ，当n=1时， $n^{2}+1=2^{n}$ ；当n=2,3,4时， $n^{2}+1>2^{n}$ ；当n=5时， $n^{2}+1<2^{n}$ ；当n>5时， $n^{2}+1<2^{n}$ 。综上所述，使不等式 $\left(T_{2n}+\frac{1}{b_{n}}\right)\cdot\frac{1}{b_{n}}<1$ 成立的最小整数n的值为5，故选C.
