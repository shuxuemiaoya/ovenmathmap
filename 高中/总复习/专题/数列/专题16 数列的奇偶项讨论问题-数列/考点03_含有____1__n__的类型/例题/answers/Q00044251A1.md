> [!faq]- 《专题16 数列的奇偶项讨论问题-数列》例题解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > 解析
> > (1) 因为 $S_{n} - n^{2} = n(a_{n} - 1)$ ，即 $S_{n} = na_{n} + n^{2} - n$ ，①
> >
> > 当 $n \geqslant 2$ 时， $S_{n-1} = (n-1)a_{n-1} + (n-1)^2 - (n-1)$ ，②
> > - **①**：-②，得 $(n-1)a_{n}-(n-1)a_{n-1}+2(n-1)=0.$
> >
> > 因为 $n \geqslant 2$ ，所以 $a_{n} - a_{n-1} = -2$ ，所以数列 $\{a_{n}\}$ 是以 $a_{1} = 5$ 为首项， $d = -2$ 为公差的等差数列，所以 $a_{n} = a_{1} + (n-1)d = -2n + 7$ .
> >
> > (2)由
> > (1)得 $b_{n}=(-1)^{n}n(a_{n}+2n-4)+2n=(-1)^{n}3n+2n,$ 所以 $T_{n}=b_{1}+b_{2}+\cdots+b_{n}$ $=(-3\times1+2\times1)+(3\times2+2\times2)+(-3\times3+2\times3)+(3\times4+2\times4)+\cdots+(-1)^{n}3n+2n$ $=-3[1-2+3-4+5-6+\cdots+(-1)^{n+1}n]+2(1+2+3+4+\cdots+n),$ 于是当 n 为奇数时， $T_{n}=-3\times\frac{n+1}{2}+n(n+1)=\frac{(2n-3)(n+1)}{2};$ 当 n 为偶数时， $T_{n}=\frac{3n}{2}+n(n+1)=\frac{n(2n+5)}{2}.$
> >
> > 所以数列 $\{b_n\}$ 的前 $n$ 项和 $T_{n} = \left\{ \begin{array}{l} \frac{(2n - 3)(n + 1)}{2}, n \text{为奇数,} \\ \frac{n(2n + 5)}{2}, n \text{为偶数.} \end{array} \right.$
