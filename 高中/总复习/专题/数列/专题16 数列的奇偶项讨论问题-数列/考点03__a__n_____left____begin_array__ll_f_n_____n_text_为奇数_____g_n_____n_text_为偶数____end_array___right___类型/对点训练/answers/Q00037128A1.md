> [!faq]- 《专题16 数列的奇偶项讨论问题-数列》例题解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > (1)证明：数列 $\{a_{n}\}$ 为等比数列，并求 $a_{n}$
> > (2)若 $\lambda = 4$ ， $b_{n} = \left\{ \begin{array}{ll}a_{n}, & n\text{是奇数}\\ \log_{2}a_{n}, & n\text{是偶数} \end{array} \right.\quad (n\in \mathbf{N}^{*})$ ，求数列 $\{b_n\}$ 的前 $n$ 项和 $T_{n}$
> > 6. 解析 (1)由题意可知 $S_{1} = 2a_{1} - \lambda$ ，即 $a_{1} = \lambda$ ，
> > 当 $n \geqslant 2$ 时， $a_{n} = S_{n} - S_{n-1} = (2a_{n} - \lambda) - (2a_{n-1} - \lambda) = 2a_{n} - 2a_{n-1}$ ，即 $a_{n} = 2a_{n-1}$ ，所以数列 $\{a_{n}\}$ 是首项为 $\lambda$ ，公比为 2 的等比数列，所以 $a_{n} = \lambda \times 2^{n-1}$ .
> > (2)由(1)可知，当 $\lambda = 4$ 时， $a_{n} = 2^{n + 1}$ ，从而 $b_{n} = \left\{ \begin{array}{ll}2^{n + 1}, & n\text{是奇数，}\\ n + 1, & n\text{是偶数}. \end{array} \right.$
> > n 为偶数时， $T_{n}=\frac{4(1-4\frac{n}{2})}{1-4}+\frac{\frac{n}{2}(3+n+1)}{2}=\frac{4(2^{n}-1)}{3}+\frac{(n+4)n}{4},$
> > n 为奇数时， $T_{n}=T_{n+1}-b_{n+1}=\frac{4(1-4\frac{n+1}{2})}{1-4}+\frac{\frac{n+1}{2}(3+n+1+1)}{2}-(n+2)$
> > $$
> > = \frac {4 (2 ^ {n + 1} - 1)}{3} + \frac {(n + 1) (n + 5)}{4} - n - 2 = \frac {4 (2 ^ {n + 1} - 1)}{3} + \frac {(n - 1) (n + 3)}{4},
> > $$
> > 综上， $T_{n}=\left\{\begin{aligned}&\frac{4(2^{n}-1)}{3}+\frac{(n+4)n}{4},&n 是偶数,\\&\frac{4(2^{n+1}-1)}{3}+\frac{(n-1)(n+3)}{4},&n 是奇数.\end{aligned}\right.$
