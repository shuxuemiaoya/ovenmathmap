> [!faq]- 《专题16 数列的奇偶项讨论问题-数列》例题解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > 解析 $\because b_{n+1} = a_{2(n+1)} = \frac{1}{2} a_{2n+1} + 2n + 1 - 1 = \frac{1}{2} a_{2n+1} + 2n = \frac{1}{2}(a_{2n} - 2 \cdot 2n) + 2n = \frac{1}{2} a_{2n} = \frac{1}{2} b_n,$
> >
> > $\therefore \{b_n\}$ 为等比数列，且公比 $q = \frac{1}{2}$ 又 $b_{1} = \frac{1}{2} a_{1} = \frac{1}{2}$ 可得 $b_{n} = \frac{1}{2}\cdot \left(\frac{1}{2}\right)^{n - 1} = \left(\frac{1}{2}\right)^{n},$
> >
> > 所以，当 $n$ 为偶数时， $a_{n} = b_{2}^{n} = \left(\frac{1}{\sqrt{2}}\right)^{n}$ ;
> >
> > 当 $n$ 为奇数且 $n \geqslant 3$ 时， $a_n = a_{(n-1)+1} = a_{n-1} - 2(n-1) = b\frac{n-1}{2} - 2(n-1) = \left(\frac{1}{\sqrt{2}}\right)^{n-1} - 2(n-1)$ ，
> >
> > 可验证 $a_1 = 1$ 也符合上式，综上所述， $a_n = \begin{cases} \left(\frac{1}{\sqrt{2}}\right)^{n-1} - 2(n-1), & n \text{为奇数,} \\ \left(\frac{1}{\sqrt{2}}\right)^n, & n \text{为偶数.} \end{cases}$
