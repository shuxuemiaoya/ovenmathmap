[例 3] (2021·新高考 I) 已知数列 $\{a_{n}\}$ 满足 $a_{1}=1,\quad a_{n+1}=\left\{\begin{aligned}&a_{n}+1,\quad n\text{为奇数},\\&a_{n}+2,\quad n\text{为偶数}.\end{aligned}\right.$

(1)记 $b_{n} = a_{2n}$ ，写出 $b_{1}, b_{2}$ ，并求数列 $\{b_n\}$ 的通项公式；

(2)求 $\{a_{n}\}$ 的前20项和.

(1) 因为 $b_{n}=a_{2n}$ ，且 $a_{1}=1$ ， $a_{n+1}=\begin{cases}a_{n}+1, & n\text{为奇数}, \\a_{n}+2, & n\text{为偶数},\end{cases}$

所以 $b_{1} = a_{2} = a_{1} + 1 = 2$ ， $b_{2} = a_{4} = a_{3} + 1 = a_{2} + 2 + 1 = 5.$

因为 $b_{n}=a_{2n}$ ，所以 $b_{n+1}=a_{2n+2}=a_{2n+1+1}=a_{2n+1}+1=a_{2n}+2+1=a_{2n}+3$

所以 $b_{n+1}-b_{n}=a_{2n}+3-a_{2n}=3$ ，所以数列 $\{b_{n}\}$ 是以 2 为首项，3 为公差的等差数列，

所以 $b_{n} = 2 + 3(n - 1) = 3n - 1, n\in \mathbf{N}^{*}$

(2)因为 $a_{n+1}=\begin{cases}a_{n}+1,&n\text{为奇数,}\\a_{n}+2,&n\text{为偶数,}\end{cases}$

所以 $k \in N^{*}$ 时， $a_{2k} = a_{2k-1+1} = a_{2k-1} + 1$ ，即 $a_{2k} = a_{2k-1} + 1$ ，①， $a_{2k+1} = a_{2k} + 2$ ，②

$a_{2k+2}=a_{2k+1+1}=a_{2k+1}+1$ ，即 $a_{2k+2}=a_{2k+1}+1$ ，③

所以①+②得 $a_{2k+1}=a_{2k-1}+3$ ，即 $a_{2k+1}-a_{2k-1}=3$ ，

所以数列 $\{a_{n}\}$ 的奇数项是以1为首项，3为公差的等差数列；

②+③得 $a_{2k+2}=a_{2k}+3$ ，即 $a_{2k+2}-a_{2k}=3$ ，

又 $a_2 = 2$ ，所以数列 $\{a_n\}$ 的偶数项是以2为首项，3为公差的等差数列.

所以数列 $\{a_{n}\}$ 的前20项和

$$
S _ {2 0} = \left(a _ {1} + a _ {3} + a _ {5} + \dots + a _ {1 9}\right) + \left(a _ {2} + a _ {4} + a _ {6} + \dots + a _ {2 0}\right) = 1 0 + \frac {1 0 \times 9}{2} \times 3 + 2 0 + \frac {1 0 \times 9}{2} \times 3 = 3 0 0.
$$
