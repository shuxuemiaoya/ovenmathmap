> [!faq]- 《专题04 用累加法与累乘法求通项公式-数列》例题解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > 答案 $a_{n} = \frac{n(n + 1)}{2}$ 解析 由题设知， $a_{1} = 1$ 。当 $n > 1$ 时， $a_{n} = S_{n} - S_{n - 1} = \frac{n + 2}{3} a_{n} - \frac{n + 1}{3} a_{n - 1}$ 。 $\therefore \frac{a_{n}}{a_{n - 1}} = \frac{n + 1}{n - 1}$ 。 $\therefore \frac{a_{n}}{a_{n - 1}} = \frac{n + 1}{n - 1}, \dots, \frac{a_{4}}{a_{3}} = \frac{5}{3}, \frac{a_{3}}{a_{2}} = \frac{4}{2}, \frac{a_{2}}{a_{1}} = 3$ 。以上 $n - 1$ 个式子的等号两端分别相乘，得到 $\frac{a_{n}}{a_{1}} = \frac{n(n + 1)}{2}$ ，又 $\because a_{1} = 1, \therefore a_{n} = \frac{n(n + 1)}{2}$ 。
