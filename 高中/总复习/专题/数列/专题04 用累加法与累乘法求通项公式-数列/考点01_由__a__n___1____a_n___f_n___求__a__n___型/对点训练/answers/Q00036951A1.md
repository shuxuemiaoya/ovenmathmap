> [!faq]- 《专题04 用累加法与累乘法求通项公式-数列》例题解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > 答案 $a_{n} = \frac{2}{n^{2} - n + 2}$ 解析 原数列递推公式可化为 $\frac{1}{a_{n + 1}} -\frac{1}{a_n} = n$ ，令 $b_{n} = \frac{1}{a_{n}}$ ，则 $b_{n + 1} - b_n = n$ ，因此 $b_{n}$ $= (b_{n} - b_{n - 1}) + (b_{n - 1} - b_{n - 2}) + \ldots +(b_{3} - b_{2}) + (b_{2} - b_{1}) + b_{1} = (n - 1) + (n - 2) + \ldots +2 + 1 + 1 = \frac{n^2 - n + 2}{2}$ 所以 $a_{n} = \frac{2}{n^{2} - n + 2}$
