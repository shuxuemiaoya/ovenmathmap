> [!faq]- 《专题12 等差、等比数列的综合应用-数列》例题解析
>
> > [!success]- **【答案】** A
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > 答案 A 解析 由题意 $a_1, a_3, a_{13}$ 成等比数列，得 $(1 + 2d)^2 = 1 + 12d$ ，解得 $d = 2$ 。故 $a_n = 2n - 1$ ， $S_n = n^2$ 。因此 $\frac{2S_n + 16}{a_n + 3} = \frac{2n^2 + 16}{2n + 2} = \frac{n^2 + 8}{n + 1} = \frac{(n + 1)^2 - 2(n + 1) + 9}{n + 1} = (n + 1) + \frac{9}{n + 1} - 2 \geqslant 2\sqrt{(n + 1) \times \frac{9}{n + 1}} - 2 = 4$ 当且仅当 $n = 2$ 时取得最小值4。
