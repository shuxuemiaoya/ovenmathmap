> [!faq]- 《专题12 等差、等比数列的综合应用-数列》例题解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【解析】**
> > 答案 $\frac{20}{3}$ 解析 由于 $a_2, a_5 - 1, a_{10}$ 成等比数列，所以 $(a_5 - 1)^2 = a_2 \cdot a_{10}, (a_1 + 4d - 1)^2 = (a_1 + d) \cdot (a_1 + 9d)$ ，又 $a_1 = 5$ ，所以 $d = 3$ ，所以 $a_n = 5 + 3(n - 1) = 3n + 2, S_n = na_1 + \frac{n(n - 1)}{2} d = 5n + \frac{3}{2} n(n - 1)$ ，所以 $\frac{2S_n + n + 32}{a_n + 1} = \frac{3n^2 + 8n + 32}{3n + 3} = \frac{1}{3}[3(n + 1) + \frac{27}{n + 1} + 2] \geq \frac{20}{3}$ ，当且仅当 $3(n + 1) = \frac{27}{n + 1}$ ，即 $n = 2$ 时等号成立。
