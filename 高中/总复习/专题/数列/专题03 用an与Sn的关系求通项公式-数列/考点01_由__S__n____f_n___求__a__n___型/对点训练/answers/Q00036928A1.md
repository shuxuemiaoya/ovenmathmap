> [!faq]- 《专题03 用an与Sn的关系求通项公式-数列》例题解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【解析】**
> > 答案 $\left\{ \begin{array}{l} 2, n = 1, \\ 6n - 5, n \geqslant 2 \end{array} \right.$ 解析 当 $n = 1$ 时， $a_1 = S_1 = 3 \times 1^2 - 2 \times 1 + 1 = 2$ ；当 $n \geqslant 2$ 时， $a_n = S_n - S_{n-1} = 3n^2 - 2n + 1 - [3(n-1)^2 - 2(n-1) + 1] = 6n - 5$ ，显然当 $n = 1$ 时，不满足上式。故数列的通项公式为 $a_n = \left\{ \begin{array}{l} 2, n = 1, \\ 6n - 5, n \geqslant 2. \end{array} \right.$
