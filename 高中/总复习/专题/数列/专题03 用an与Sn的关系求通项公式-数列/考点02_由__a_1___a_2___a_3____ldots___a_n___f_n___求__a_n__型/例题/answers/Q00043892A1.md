> [!faq]- 《专题03 用an与Sn的关系求通项公式-数列》例题解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > 答案 $\left\{ \begin{array}{l} 2, n = 1, \\ \frac{2^{n - 1}}{n}, n \geq 2. \end{array} \right.$ 解析 当 $n = 1$ 时， $a_1 = 2^1 = 2$ ， $\because a_1 + 2a_2 + 3a_3 + \ldots + na_n = 2^n$ ，①，故 $a_1 + 2a_2 + 3a_3 + \ldots + (n - 1)a_{n - 1} = 2^{n - 1}(n \geq 2)$ ，②，由①-②得 $na_n = 2^n - 2^{n - 1} = 2^{n - 1}$ ， $\therefore a_n = \frac{2^{n - 1}}{n} (n \geq 2)$ . 显然当 $n = 1$ 时不满足上式， $\therefore a_n = \left\{ \begin{array}{l} 2, n = 1, \\ \frac{2^{n - 1}}{n}, n \geq 2. \end{array} \right.$
