> [!faq]- 《专题03 用an与Sn的关系求通项公式-数列》例题解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > 答案 $\left\{ \begin{array}{l}3, n = 1, \\ \frac{18}{(5 - 3n)(8 - 3n)}, n \geqslant 2 \end{array} \right.$ 解析 当 $n \geqslant 2$ 时，由 $2a_{n} = S_{n} \cdot S_{n - 1}$ 可得 $2(S_{n} - S_{n - 1}) = S_{n} \cdot S_{n - 1}, \therefore \frac{1}{S_{n - 1}} - \frac{1}{S_{n}} = \frac{1}{2}$ ，即 $\frac{1}{S_n} - \frac{1}{S_{n - 1}} = -\frac{1}{2}, \therefore$ 数列 $\left\{\frac{1}{S_n}\right\}$ 是首项为 $\frac{1}{3}$ ，公差为 $-\frac{1}{2}$ 的等差数列， $\therefore \frac{1}{S_n} = \frac{1}{3} + \left[\frac{-\frac{1}{2}}{2}\right] (n - 1) = \frac{5 - 3n}{6}, \therefore S_n = \frac{6}{5 - 3n}$ . 当 $n \geqslant 2$ 时， $a_{n} = \frac{1}{2} S_{n} S_{n - 1} = \frac{1}{2} \times \frac{6}{5 - 3n} \times \frac{6}{5 - 3(n - 1)} = \frac{18}{(5 - 3n)(8 - 3n)}$ ，又 $a_1 = 3, \therefore a_n = \left\{\begin{array}{l}3, n = 1, \\ \frac{18}{(5 - 3n)(8 - 3n)}, n \geqslant 2. \end{array}\right.$
