> [!faq]- 《专题09 等比数列基本量的计算-数列》例题解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【解析】**
> > 答案 $\left\{ \begin{array}{l} 12, n = 1, \\ 3^{n+1}, n \geq 2 \end{array} \right.$ $\left\{ \begin{array}{l} 12, n = 1, \\ \frac{3^{n+2} - 3}{2}, n \geq 2 \end{array} \right.$ 解析 由题意可得，当 $n = 1$ 时， $\frac{1}{3} a_1 = 4$ ，解得 $a_1 = 12$ 。当 $n \geq 2$ 时， $\frac{1}{3} a_1 + \frac{1}{3^2} a_2 + \ldots + \frac{1}{3^{n-1}} a_{n-1} = 3n - 2$ ，所以 $\frac{1}{3^n} a_n = 3, n \geq 2$ ，即 $a_n = 3^{n+1}, n \geq 2$ ，又当 $n = 1$ 时， $a_n = 3^{n+1}$ 不成立，所以 $a_n = \left\{ \begin{array}{l} 12, n = 1, \\ 3^{n+1}, n \geq 2. \end{array} \right.$ 当 $n \geq 2$ 时， $a_1 + a_2 + \ldots + a_n = 12 + \frac{3^3 - 3^{n+2}}{1 - 3} = \frac{3^{n+2} - 3}{2}$ .
