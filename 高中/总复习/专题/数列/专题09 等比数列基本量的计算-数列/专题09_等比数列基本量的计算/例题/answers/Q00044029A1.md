> [!faq]- 《专题09 等比数列基本量的计算-数列》例题解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【解析】**
> > 解析
> > (1)设 $\{a_{n}\}$ 的公比为 $q$ ，由题设得 $a_{n} = q^{n - 1}$ 。由已知得 $q^4 = 4q^2$ ，解得 $q = 0$ （舍去）， $q = -2$ 或 $q = 2$ 。故 $a_{n} = (-2)^{n - 1}$ 或 $a_{n} = 2^{n - 1}$ 。
> >
> > (2)若 $a_{n} = (-2)^{n - 1}$ ，则 $S_{n} = \frac{1 - (-2)^{n}}{3}$ 由 $S_{m} = 63$ 得 $(-2)^{m} = -188$ ，此方程没有正整数解.若 $a_{n} = 2^{n - 1}$ ，则 $S_{n} = 2^{n} - 1$ ．由 $S_{m} = 63$ 得 $2^{m} = 64$ ，解得 $m = 6$ ．综上， $m = 6$
