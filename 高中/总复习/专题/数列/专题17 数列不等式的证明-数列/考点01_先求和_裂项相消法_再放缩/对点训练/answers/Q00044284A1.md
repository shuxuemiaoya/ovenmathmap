> [!faq]- 《专题17 数列不等式的证明-数列》例题解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【解析】**
> > 解析
> > (1) 因为 $S_{n} = \frac{n^{2}}{2} + \frac{3n}{2}$ , ①. 所以当 $n \geq 2$ 时, $S_{n-1} = \frac{(n-1)^{2}}{2} + \frac{3(n-1)}{2}$ , ②
> >
> > 所以由①②两式相减得 $a_{n} = S_{n} - S_{n - 1} = \frac{n^{2}}{2} +\frac{3n}{2} -\frac{(n - 1)^{2}}{2} -\frac{3(n - 1)}{2} = n + 1.$
> >
> > 又因为 n=1 时， $a_{1}=S_{1}=2$ 适合 $a_{n}=n+1$ ，所以 $a_{n}=n+1$ 。
> >
> > (2)由
> > (1)知 $b_{n}=n+3-(n+1)+\frac{1}{(n+3)(n+1)}=2+\frac{1}{2}\left(\frac{1}{n+1}-\frac{1}{n+3}\right)$ ,
> >
> > 所以 $T_{n}=b_{1}+b_{2}+b_{3}+\ldots+b_{n}=2n+\frac{1}{2}\left[\frac{1}{2}-\frac{1}{4}+\frac{1}{3}-\frac{1}{5}+\ldots+\frac{1}{n+1}-\frac{1}{n+3}\right]$
> >
> > $$
> > = 2 n + \frac {1}{2} \left(\frac {1}{2} + \frac {1}{3} - \frac {1}{n + 2} - \frac {1}{n + 3}\right) = 2 n + \frac {5}{1 2} - \frac {1}{2} \left(\frac {1}{n + 2} + \frac {1}{n + 3}\right) <   2 n + \frac {5}{1 2}.
> > $$
