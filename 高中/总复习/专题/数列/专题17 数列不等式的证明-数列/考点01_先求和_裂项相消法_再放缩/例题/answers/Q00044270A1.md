> [!faq]- 《专题17 数列不等式的证明-数列》例题解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > 解析
> > (1)设数列 $\{a_{n}\}$ 的公比为 $q$ ，数列 $\{b_{n}\}$ 的公差为 $d$ ，由题意得 $1 + d = 1 + q$ ， $q^{2} = 2(1 + 2d) - 6$ ，解得 $d = q = 2$ ，所以 $a_{n} = 2^{n - 1}$ ， $b_{n} = 2n - 1$ .
> >
> > (2)因为 $c_{n}=\frac{1}{b_{n}b_{n+2}}=\frac{1}{(2n-1)(2n+3)}=\frac{1}{4}\left(\frac{1}{2n-1}-\frac{1}{2n+3}\right)$ ,
> >
> > $$
> > T _ {n} = \frac {1}{4} \left[ \left(1 - \frac {1}{5}\right) + \left(\frac {1}{3} - \frac {1}{7}\right) + \dots + \quad \left(\frac {1}{2 n - 3} - \frac {1}{2 n + 1}\right) + \left(\frac {1}{2 n - 1} - \frac {1}{2 n + 3}\right) \right.
> > $$
> >
> > $$
> > \frac {1}{4} \left(1 + \frac {1}{3} - \frac {1}{2 n + 1} - \frac {1}{2 n + 3}\right) = \frac {1}{3} - \frac {1}{4} \left(\frac {1}{2 n + 1} + \frac {1}{2 n + 3}\right),
> > $$
> >
> > 因为 $\frac{1}{4}\left[\frac{1}{2n + 1} +\frac{1}{2n + 3}\right] > 0$ ，所以 $T_{n} <   \frac{1}{3}$ 又因为 $T_{n}$ 在 $[1, + \infty)$ 上单调递增，
> >
> > 所以当 n=1 时， $T_{n}$ 取最小值 $T_{1}=\frac{1}{5}$ ，所以 $\frac{1}{5}\leq T_{n}<\frac{1}{3}$ .
