> [!faq]- 《专题02 数列中的最值问题-数列》例题解析
>
> > [!success]- **【答案】** A
>
> > [!note]- **【解析】**
> > 答案 A 解析 记等比数列 $\{a_{n}\}$ 的公比为 $q$ ，其中 $q > 0$ ，于是有 $a_{4}q^{2} = a_{4}q + 2a_{4}$ ，即 $q^{2} - q - 2 = 0$ ， $(q + 1)(q - 2) = 0(q > 0)$ ，由此解得 $q = 2$ 。由 $a_{m}a_{n} = 16a_{1}^{2}$ 得 $a_{1}^{2} \times 2^{m + n - 2} = 16a_{1}^{2}$ ，故 $m + n = 6$ ，其中 $m, n \in \mathbb{N}^{*}$ ， $\therefore \frac{1}{m} + \frac{4}{n} = \frac{1}{6}\left(\frac{1}{m} + \frac{4}{n}\right)(m + n) = \frac{5 + \frac{n}{m} + \frac{4m}{n}}{6} \geq \frac{5 + 2\sqrt{\frac{n}{m} \times \frac{4m}{n}}}{6} = \frac{3}{2}$ ，当且仅且 $\frac{n}{m} = \frac{4m}{n}$ ，即 $m = 2, n = 4$ 时等号成立， $\therefore \frac{1}{m} + \frac{4}{n}$ 的最小值为 $\frac{3}{2}$ .
