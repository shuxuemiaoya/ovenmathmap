[例4](1)记 $S_{n}$ 为等差数列 $\{a_{n}\}$ 的前 $n$ 项和，已知 $a_1 = -7, S_3 = -15$ ，求 $S_{n}$ 取得最小值时 $n$ 的值为\_\_\_\_答案4解析解法一：设 $\{a_{n}\}$ 的公差为 $d$ ， $\because a_1 = -7, S_3 = 3a_1 + 3d = -15, \therefore d = 2, \therefore a_n = -7 + (n - 1)\cdot 2 = 2n - 9.$ （ $n \in \mathbf{N}^*$ ）． $\therefore S_{n} = na_{1} + \frac{n(n - 1)}{2} d = n^{2} - 8n = (n - 4)^{2} - 16$ ，∴当 $n = 4$ 时， $S_{n}$ 取得最小值-16.解法二：由解法一知 $a_{n} = 2n - 9$ ， $(n \in \mathbf{N}^*)$ 由 $\left\{ \begin{array}{l} a_{n} \leq 0, \\ a_{n+1} \geq 0, \end{array} \right.$ 即 $\left\{ \begin{array}{l} 2n - 9 \leq 0, \\ 2n - 7 \geq 0, \end{array} \right.$ 解得3． $5 \leq n \leq 4$ ．5，又 $n \in \mathbf{N}^*$ ，故 $n = 4$ 时， $S_{n}$ 取得最小值 $S_{4}$ .
