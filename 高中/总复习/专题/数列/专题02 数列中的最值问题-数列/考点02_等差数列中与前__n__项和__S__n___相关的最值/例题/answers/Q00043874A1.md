> [!faq]- 《专题02 数列中的最值问题-数列》例题解析
>
> > [!success]- **【答案】** B
>
> > [!note]- **【解析】**
> > 答案 B 解析 设等差数列 $\{a_{n}\}$ 的公差为 $d$ ， $\because a_{1} = -9, a_{5} = -1, \therefore a_{5} = -9 + 4d = -1, \therefore d = 2, \therefore a_{n} = -9 + (n - 1) \times 2 = 2n - 11$ 。令 $a_{n} = 2n - 11 \leq 0$ ，则 $n \leq 5.5, \therefore n \leq 5$ 时， $a_{n} < 0; n \geq 6$ 时， $a_{n} > 0$ 。 $\therefore T_{1} = -9 < 0, T_{2} = (-9) \times (-7) = 63 > 0, T_{3} = (-9) \times (-7) \times (-5) = -315 < 0, T_{4} = (-9) \times (-7) \times (-5) \times (-3) = 945 > 0, T_{5} = (-9) \times (-7) \times (-5) \times (-3) \times (-1) = -945 < 0$ ，当 $n \geq 6$ 时， $a_{n} > 0$ ，且 $a_{n} \geq 1, \therefore T_{n+1} < T_{n} < 0, \therefore T_{n} = a_{1}a_{2} \ldots a_{n}(n=1,2,\ldots)$ 有最大项 $T_{4}$ ，无最小项，
> >
> > 故选 **B**.
