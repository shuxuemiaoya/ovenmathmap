> [!faq]- 《专题02 数列中的最值问题-数列》例题解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【解析】**
> > 答案 8 或 9 解析 设等差数列 $\{a_{n}\}$ 的公差为 $d$ ，由 $S_{5} = S_{12}$ 得 $5a_{1} + 10d = 12a_{1} + 66d$ ，所以 $d = -\frac{1}{8}$ $a_{1} < 0$ . 设此数列的前 $n$ 项和最大，则 $\left\{ \begin{array}{l} a_{n} \geqslant 0, \\ a_{n+1} \leqslant 0, \end{array} \right.$ 即 $\left\{ \begin{array}{l} a_{n} = a_{1} + (n-1) \cdot \left(-\frac{1}{8}\right) a_{1} \geqslant 0, \\ a_{n+1} = a_{1} + n \cdot \left(-\frac{1}{8}\right) a_{1} \leqslant 0, \end{array} \right.$ 解得 $\left\{ \begin{array}{l} n \leqslant 9, \\ n \geqslant 8, \end{array} \right.$ 即 $8 \leqslant n \leqslant 9$ ，又 $n \in \mathbf{N}^{*}$ ，所以当 $n = 8$ 或 $n = 9$ 时， $S_{n}$ 有最大值.
