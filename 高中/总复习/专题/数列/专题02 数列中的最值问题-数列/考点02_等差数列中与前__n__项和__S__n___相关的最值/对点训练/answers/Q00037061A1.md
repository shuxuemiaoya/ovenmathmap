>
> > [!success]- **【答案】** B
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > 答案 B 解析 由题意知 $\left\{ \begin{array}{l} (a_1 + 2d)(a_1 + 14d) = 25, \\ a_1 + 4d = 5, \end{array} \right.$ 由 $d \neq 0$ ，解得 $a_1 = -3, d = 2, \therefore \frac{S_n}{n} =$
> > $\frac{na_{1}+\frac{n(n-1)}{2}d}{n}=-3+n-1=n-4,$ 则 $n-4\geqslant0,$ 得 $n\geqslant4,$ ∴数列 $\left\{\begin{aligned}&S_{n}\\ &n\end{aligned}\right\}$ 的前 n 项和取最小值时的 n 为 3 或 4.
