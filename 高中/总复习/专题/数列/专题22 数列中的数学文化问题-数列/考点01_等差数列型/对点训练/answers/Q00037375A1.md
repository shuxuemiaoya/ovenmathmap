> > [!note]- **【解析】**
> > 答案 135 解析 法一：由题设 $a = 3m + 2 = 5n + 3$ ， $m, n \in \mathbb{N}$ ，则 $3m = 5n + 1$ ， $m, n \in \mathbb{N}$ ，当 $m = 5k$ 时， $n$ 不存在；当 $m = 5k + 1$ 时， $n$ 不存在；当 $m = 5k + 2$ 时， $n = 3k + 1$ ，满足题意；当 $m = 5k + 3$ 时， $n$ 不存在；当 $m = 5k + 4$ 时， $n$ 不存在，其中 $k \in \mathbb{N}$ 。故 $2 \leq a = 15k + 8 \leq 2019$ ，解得 $-\frac{6}{15} \leq k \leq \frac{2011}{15}$ ，则 $k = 0, 1, 2, \ldots, 134$ ，共 135 个。即符合条件的 $a$ 共有 135 个，故答案为 135。

> > 5. 我国古代数学名著《算法统宗》中说：“九百九十六斤棉，赠分八子做盘缠。次第每人多十七，要将第八数来言。务要分明依次第，孝和休惹外人传。”意为：“996斤棉花，分别赠送给8个子女做旅费，从第1个孩子开始，以后每人依次多17斤，直到第8个孩子为止。分配时一定要按照次序分，要顺从父母，兄弟间和气，不要引得外人说闲话。”在这个问题中，第8个孩子分到的棉花为( )
> >
> > A. 184斤
> >
> > B. 176斤
> >
> > C. 65斤
> >
> > D. 60斤
> >
> > 5. 答案 A 解析 依题意得，八个子女所得棉花斤数依次构成等差数列，设该等差数列为 $\{a_{n}\}$ ，公差为 $d$ ，前 $n$ 项和为 $S_{n}$ ，第一个孩子所得棉花斤数为 $a_{1}$ ，则由题意得， $d = 17$ ， $S_{8} = 8a_{1} + \frac{8 \times 7}{2} \times 17 = 996$ ，解得 $a_{1} = 65$ ， $\therefore a_{8} = a_{1} + (8 - 1)d = 184$ .
