> [!faq]- 《专题05 用构造辅助数列通项公式-数列》例题解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > 答案 $a_{n} = \frac{1}{n + 2}$ 解析 因为 $\frac{a_{n + 1}(a_n + a_{n + 2})}{2} = a_{n + 2}a_n$ ，所以 $a_{n + 1}a_{n} + a_{n + 1}a_{n + 2} = 2a_{n + 2}a_{n}$ 。因为 $a_{n}a_{n + 1}a_{n + 2} \neq 0$ ，所以 $\frac{1}{a_{n + 2}} + \frac{1}{a_n} = \frac{2}{a_{n + 1}}$ ，所以数列 $\left\{\frac{1}{a_n}\right\}$ 为等差数列。设数列 $\left\{\frac{1}{a_n}\right\}$ 的公差为 $d$ ，则 $\frac{1}{a_8} = \frac{1}{a_3} + (8 - 3)d$ 。因为 $a_3 = 2a_8 = \frac{1}{5}$ ，所以 $d = 1$ ，又 $\frac{1}{a_1} = \frac{1}{a_3} - 2d = 3$ ，所以数列 $\left\{\frac{1}{a_n}\right\}$ 是以3为首项，1为公差的等差数列。 $\therefore \frac{1}{a_n} = 3 + (n - 1) \times 1 = n + 2$ ， $\therefore a_n = \frac{1}{n + 2}$ 。
