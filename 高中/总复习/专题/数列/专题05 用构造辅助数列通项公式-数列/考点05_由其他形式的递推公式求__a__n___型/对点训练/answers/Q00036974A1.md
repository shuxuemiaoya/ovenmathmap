> [!faq]- 《专题05 用构造辅助数列通项公式-数列》例题解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【解析】**
> > 答案 $a_{n} = \sqrt{3n - 2}$ 解析 由已知 $S$ 梯形 $A_{n}B_{n}B_{n + 1}A_{n + 1} = S_{\text{梯形} A_{n + 1}B_{n + 1}B_{n + 2}A_{n + 2}} = S_{\triangle OB_{n + 1}A_{n + 1}} - S_{\triangle OB_nA_n}$ $= S_{\triangle OB_{n + 2}A_{n + 2}} - S_{\triangle OB_{n + 1}A_{n + 1}}$ ，即 $S_{\triangle OB_nA_n} + S_{\triangle OB_{n + 2}A_{n + 2}} = 2S_{\triangle OB_{n + 1}A_{n + 1}}$ ，由相似三角形面积比是相似比的平方知 $OA_n^2 + OA_{n + 2}^2 = 2OA_{n + 1}^2$ ，即 $a_{n}^{2} + a_{n + 2}^{2} = 2a_{n + 1}^{2}$ ，因此 $\{a_n^2\}$ 为等差数列且 $a_{n}^{2} = a_{1}^{2} + 3(n - 1) = 3n - 2$ ，故 $a_{n} = \sqrt{3n - 2}$ .
