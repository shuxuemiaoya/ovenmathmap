> [!faq]- 《专题05 用构造辅助数列通项公式-数列》例题解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【解析】**
> > 答案 $(3n - 1)2^{n - 2}$ 解析 当 $n\geqslant 2$ 时， $S_{n + 1} = 4a_{n} + 2$ ， $S_{n} = 4a_{n - 1} + 2$ 。两式相减，得 $a_{n + 1} = 4a_n - 4a_{n - 1}$ 将之变形为 $a_{n + 1} - 2a_{n} = 2(a_{n} - 2a_{n - 1})$ 。所以 $\{a_{n + 1} - 2a_n\}$ 是公比为2的等比数列。又 $a_1 + a_2 = S_2 = 4a_1 + 2$ ， $a_1 = 1$ ，得 $a_2 = 5$ ，则 $a_2 - 2a_1 = 3$ 。所以 $a_{n + 1} - 2a_n = 3\cdot 2^{n - 1}$ 。两边同除以 $2^{n + 1}$ ，得 $\frac{a_{n + 1}}{2^{n + 1}} -\frac{a_n}{2^n} = \frac{3}{4}$ ，所以 $\left\{\frac{a_n}{2^n}\right\}$ 是首项为 $\frac{a_1}{2} = \frac{1}{2}$ ，公差为 $\frac{3}{4}$ 的等差数列。所以 $\frac{a_n}{2^n} = \frac{1}{2} +\frac{3}{4} (n - 1) = \frac{3}{4} n - \frac{1}{4}$ ，所以 $a_{n} = (3n - 1)2^{n - 2}$
