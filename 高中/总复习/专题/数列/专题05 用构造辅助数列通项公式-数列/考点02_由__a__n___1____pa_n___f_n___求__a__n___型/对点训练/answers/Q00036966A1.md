> [!faq]- 《专题05 用构造辅助数列通项公式-数列》例题解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > 答案 $\frac{2 - n}{2^{n - 1}}$ 解析 由 $a_{n + 1} = \frac{1}{2} a_n - \frac{1}{2^n}$ 得 $2^{n}a_{n + 1} = 2^{n - 1}a_{n} - 1$ ，令 $b_{n} = 2^{n - 1}a_{n}$ ，则 $b_{n + 1} - b_{n} = -1$ ，又 $a_1 = 1$ $\therefore b_{1} = 1, \therefore b_{n} = 1 + (n - 1)\times (-1) = -n + 2.$ 即 $2^{n - 1}a_{n} = -n + 2,\therefore a_{n} = \frac{2 - n}{2^{n - 1}}.$
