## 考点二 由 $a_{n + 1} = pa_n + f(n)$ 求 $a_{n}$ 型

【基本方法】

$$
\text { 已知 } a _ {n + 1} = p a _ {n} + f (n) \text { 求 } a _ {n} \text { 的方法 }
$$

递推关系形如 $a_{n + 1} = pa_n + f(n)(p$ 是非零常数)的数列 $\{a_{n}\}$ 的通项公式，可先在两边同除以 $f(n)$ 后再用累加法求得.
