> [!faq]- 《专题05 用构造辅助数列通项公式-数列》例题解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > 答案 $\frac{4\cdot 6^{n - 1} - 5^{n - 1}}{2\cdot 6^{n - 1} - 5^{n - 1}}$ 解析 由方程 $x = \frac{7x - 2}{x + 4}$ ，得数列 $\{a_{n}\}$ 的不动点为1和2， $\frac{a_{n + 1} - 1}{a_{n + 1} - 2} = \frac{\frac{7a_n - 2}{a_n + 4} - 1}{\frac{7a_n - 2}{a_n + 4} - 2} =$ $\frac{7a_n - 2 - (a_n + 4)}{7a_n - 2 - 2(a_n + 4)} = \frac{6}{5}\cdot \frac{a_n - 1}{a_n - 2}$ 所以 $\left\{\frac{a_n - 1}{a_n - 2}\right\}$ 是首项为 $\frac{a_1 - 1}{a_1 - 2} = 2$ ，公比为 $\frac{6}{5}$ 的等比数列，所以 $\frac{a_n - 1}{a_n - 2} = 2\cdot \left(\frac{6}{5}\right)^{n - 1},$ 解得 $a_{n} = \frac{1}{2\cdot\left(\frac{6}{5}\right)_{n - 1} - 1} +2 = \frac{4\cdot 6^{n - 1} - 5^{n - 1}}{2\cdot 6^{n - 1} - 5^{n - 1}}, n\in \mathbf{N}^*$
