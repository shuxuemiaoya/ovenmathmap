考点三 由 $a_{n + 2} = pa_{n + 1} + qa_n$ 求 $a_{n}$ 型

## 【基本方法】

已知 $a_{n + 2} = pa_{n + 1} + qa_n$ 求 $a_{n}$ 的方法

递推关系形如 $a_{n + 2} = pa_{n + 1} + qa_n$ 型，可化为 $a_{n + 2} + xa_{n + 1} = (p + x)\left(a_{n + 1} + \frac{q}{p + x} a_n\right)$ ，令 $x = \frac{q}{p + x}$ ，求得 $x$ 来解决.
