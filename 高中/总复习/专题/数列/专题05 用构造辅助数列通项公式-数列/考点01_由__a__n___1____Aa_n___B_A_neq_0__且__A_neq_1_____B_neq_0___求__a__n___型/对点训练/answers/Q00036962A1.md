> [!faq]- 《专题05 用构造辅助数列通项公式-数列》例题解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > 答案 $2^{n+1} - 3$ 解析 设递推公式 $a_{n+1} = 2a_n + 3$ 可以转化为 $a_{n+1} + t = 2(a_n + t)$ ，即 $a_{n+1} = 2a_n + t$ ，解得 $t = 3$ 。故 $a_{n+1} + 3 = 2(a_n + 3)$ 。令 $b_n = a_n + 3$ ，则 $b_1 = a_1 + 3 = 4$ ，且 $\frac{b_{n+1}}{b_n} = \frac{a_{n+1} + 3}{a_n + 3} = 2$ 。所以 $\{b_n\}$ 是以 4 为首项，2 为公比的等比数列。 $\therefore b_n = 4 \cdot 2^{n-1} = 2^{n+1}$ ， $\therefore a_n = 2^{n+1} - 3$ 。
