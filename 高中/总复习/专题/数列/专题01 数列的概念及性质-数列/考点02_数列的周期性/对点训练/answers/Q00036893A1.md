> > [!note]- **【解析】**
> > 答案 0 解析 $\because a_{1} = 1, a_{n + 1} = a_{n}^{2} - 2a_{n} + 1 = (a_{n} - 1)^{2}, \therefore a_{2} = (a_{1} - 1)^{2} = 0, a_{3} = (a_{2} - 1)^{2} = 1, a_{4} = (a_{3} - 1)^{2} = 0, \cdots,$ 可知数列 $\{a_{n}\}$ 是以2为周期的数列， $\therefore a_{2022} = a_2 = 0.$
