> > [!note]- **【解析】**
> > 答案 0 解析 $\because a_{1} = 0, a_{n + 1} = \frac{\sqrt{3} + a_{n}}{1 - \sqrt{3}a_{n}}, \therefore a_{2} = \frac{\sqrt{3}}{1} = \sqrt{3}, a_{3} = \frac{\sqrt{3} + \sqrt{3}}{1 - \sqrt{3} \times \sqrt{3}} = \frac{2\sqrt{3}}{-2} = -\sqrt{3}, a_{4} = \frac{\sqrt{3} - \sqrt{3}}{1 + \sqrt{3} \times \sqrt{3}}$ $= 0$ ，即数列 $\{a_{n}\}$ 的取值具有周期性，周期为3，且 $a_{1} + a_{2} + a_{3} = 0$ ，则 $S_{2022} = S_{3\times 674} = 0.$
