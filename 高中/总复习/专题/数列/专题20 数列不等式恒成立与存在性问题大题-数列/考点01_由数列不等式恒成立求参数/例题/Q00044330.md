[例 2] 已知各项均不相等的等差数列 $\{a_{n}\}$ 的前 4 项和为 14，且 $a_{1}, a_{3}, a_{7}$ 恰为等比数列 $\{b_{n}\}$ 的前 3 项.
(1)分别求数列 $\{a_{n}\}$ ， $\{b_{n}\}$ 的前n项和 $S_{n}$ ， $T_{n}$ ;

(2)设 $K_{n}$ 为数列 $\{a_{n}b_{n}\}$ 的前 $n$ 项和，若不等式 $\lambda S_nT_n\geqslant K_n + n$ 对一切 $n\in \mathbf{N}^*$ 恒成立，求实数 $\lambda$ 的最小值.

(1)设数列 $\{a_{n}\}$ 的公差为 $d$ ，则 $\left\{ \begin{array}{l} 4a_{1} + 6d = 14, \\ (a_{1} + 2d)^{2} = a_{1}(a_{1} + 6d), \end{array} \right.$ 解得 $d = 1$ 或 $d = 0$ （舍去）， $a_{1} = 2$ ，

所以 $a_{n} = n + 1$ ， $S_{n} = \frac{n(n + 3)}{2}$ ： $b_{n} = 2^{n}$ ， $T_{n} = 2^{n + 1} - 2$

(2)由题意得 $K_{n}=2\times2^{1}+3\times2^{2}+\cdots+(n+1)\times2^{n}$ ，①

则 $2K_{n}=2\times2^{2}+3\times2^{3}+\cdots+n\times2^{n}+(n+1)\times2^{n+1}$ ，②

①-②得 $-K_{n}=2\times2^{1}+2^{2}+2^{3}+\cdots+2^{n}-(n+1)\times2^{n+1},\quad\therefore K_{n}=n\times2^{n+1}.$

要使 $\lambda S_{n}T_{n}\geqslant K_{n} + n$ 对一切 $n\in \mathbf{N}^{*}$ 恒成立，即 $\lambda \geqslant \frac{K_n + n}{S_nT_n} = \frac{2^{n + 1} + 1}{(n + 3)(2^n - 1)}$ 恒成立，设 $g(n) = \frac{2^{n + 1} + 1}{(n + 3)(2^n - 1)}$

因为 $\frac{g(n + 1)}{g(n)} = \frac{(n + 3)(2^n - 1)(2^{n + 2} + 1)}{(n + 4)(2^{n + 1} - 1)(2^{n + 1} + 1)} = \frac{(n + 3)(2^{2n + 2} - 1 - 3 \cdot 2^n)}{(n + 4)(2^{2n + 2} - 1)} < \frac{(n + 3)(2^{2n + 2} - 1)}{(n + 4)(2^{2n + 2} - 1)} < 1,$

所以 $g(n)$ 随 n 的增加而减小，所以 $g(n)_{\max}=g
(1)=\frac{5}{4}$ ，所以当 $\lambda\geqslant\frac{5}{4}$ 时不等式恒成立，

因此 $\lambda$ 的最小值为 $\frac{5}{4}$ .
