> [!faq]- 《专题20 数列不等式恒成立与存在性问题大题-数列》例题解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > (1)记 $b_{n} = \frac{S_{n + 2}}{S_{n + 1}} +\frac{S_{n + 1}}{S_{n + 2}}$ ，求数列 $\{b_n\}$ 的前 $n$ 项和 $T_{n}$
> > (2)记 $c_{n} = T_{n} - 2n$ ，是否存在正整数 $N$ ，使得当 $n > N$ 时，恒有 $c_{n}\in \left(\frac{5}{2},3\right)$ ，若存在，证明你的结论，并给出一个具体的 $N$ 值，若不存在，请说明理由.
> > 解析 (1)由 $S_{2} = \frac{2(a_{2} - a_{1})}{2}$ 得 $a_1 + a_2 = a_2 - a_1$ ， $\therefore a_{1} = 0$ ， $\therefore d = a_{2} - a_{1} = p - 0 = p,$
> > $$
> > \therefore S _ {n} = \frac {n \left(a _ {n} - a _ {1}\right)}{2} = \frac {n (n - 1) p}{2}, b _ {n} = \frac {S _ {n + 2}}{S _ {n + 1}} + \frac {S _ {n + 1}}{S _ {n + 2}} = \frac {n + 2}{n} + \frac {n}{n + 2} = 2 + 2 \left(\frac {1}{n} - \frac {1}{n + 2}\right),
> > $$
> > 所以 $T_{n} = 2n + 2\left(1 - \frac{1}{3}\right) + \left(\frac{1}{2} -\frac{1}{4}\right) + \left(\frac{1}{3} -\frac{1}{5}\right) + \left(\frac{1}{4} -\frac{1}{6}\right) + \dots +\left(\frac{1}{n - 1} -\frac{1}{n + 1}\right) + \left(\frac{1}{n} -\frac{1}{n + 2}\right)$
> > $$
> > = 2 n + 2 \left(1 + \frac {1}{2} - \frac {1}{n + 1} - \frac {1}{n + 2}\right) = 2 n + 3 - 2 \left(\frac {1}{n + 1} + \frac {1}{n + 2}\right).
> > $$
> > (2) $c_{n}=T_{n}-2n=3-2\left(\frac{1}{n+1}+\frac{1}{n+2}\right)<3$ 对所有正整数 n 都成立；
> > 若 $c_{n} > \frac{5}{2}$ ，即 $3 - 2\left(\frac{1}{n + 1} +\frac{1}{n + 2}\right) > \frac{5}{2}\Leftrightarrow \frac{1}{n + 1} +\frac{1}{n + 2} <  \frac{1}{4}$ 记 $f(n) = \frac{1}{n + 1} +\frac{1}{n + 2}$ 则 $f(n)$ 单调递减，又 $f(6) = \frac{1}{7} +\frac{1}{8} >\frac{1}{8} +\frac{1}{8} = \frac{1}{4},f(7) = \frac{1}{8} +\frac{1}{9} <  \frac{1}{8} +\frac{1}{8} = \frac{1}{4}$ 故可取 $N = 6$ ，则当 $n > 6$ 时， $f(n) <   \frac{1}{4}$ 故存在正整数 $N$ ，使得当 $n > N$ 时，恒有 $c_{n}\in \left(\frac{5}{2},3\right),N$ 可以取所有不小于6的正整数.
