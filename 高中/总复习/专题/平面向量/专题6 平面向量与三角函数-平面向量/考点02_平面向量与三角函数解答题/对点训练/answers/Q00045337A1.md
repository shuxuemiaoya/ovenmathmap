> [!faq]- 《专题6 平面向量与三角函数-平面向量》例题解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > (1)若 $\alpha=\frac{\pi}{4}$ ，求函数 $f(x)=\boldsymbol{b}\cdot\boldsymbol{c}$ 的最小值及相应x的值；
> > (2)若 $\pmb{a}$ 与 $\pmb{b}$ 的夹角为 $\frac{\pi}{3}$ ，且 $\pmb{a} \perp \pmb{c}$ ，求 $\tan 2\alpha$ 的值.
> > 12. 解析
> > (1) $\because b = (\cos x, \sin x)$ , $c = (\sin x + 2\sin \alpha, \cos x + 2\cos \alpha)$ , $\alpha = \frac{\pi}{4}$ , $\therefore f(x) = b \cdot c = \cos x \sin x + 2\cos x \sin \alpha + \sin x \cos x + 2\sin x \cos \alpha = 2\sin x \cos x + \sqrt{2} (\sin x + \cos x)$ . 令 $t = \sin x + \cos x \left( \frac{\pi}{4} < x < \pi \right)$ , 则 $2\sin x \cos x = t^2 - 1$ , 且 $-1 < t < \sqrt{2}$ . 则 $y = t^2 + \sqrt{2} t - 1 = \left( t + \frac{\sqrt{2}}{2} \right)^2 - \frac{3}{2}$ , $-1 < t < \sqrt{2}$ , $\therefore t = -\frac{\sqrt{2}}{2}$ 时, $y_{\min} = -\frac{3}{2}$ , 此时 $\sin x + \cos x = -\frac{\sqrt{2}}{2}$ , 即 $\sqrt{2} \sin \left( x + \frac{\pi}{4} \right) = -\frac{\sqrt{2}}{2}$ , $\because \frac{\pi}{4} < x < \pi$ , $\therefore \frac{\pi}{2} < x + \frac{\pi}{4} < \frac{5}{4}\pi$ , $\therefore x + \frac{\pi}{4} = \frac{7}{6}\pi$ , $\therefore x = \frac{11\pi}{12}$ . $\therefore$ 函数 $f(x)$ 的最小值为 $-\frac{3}{2}$ , 相应 $x$ 的值为 $\frac{11\pi}{12}$ .
> > (2) $\because a$ 与 $b$ 的夹角为 $\frac{\pi}{3}$ , $\therefore \cos \frac{\pi}{3} = \frac{a \cdot b}{|a| \cdot |b|} = \cos \alpha \cos x + \sin \alpha \sin x = \cos (x - a)$ . $\because 0 < a < x < \pi$ , $\therefore 0 < x - a < \pi$ , $\therefore x - a = \frac{\pi}{3}$ . $\because a \perp c$ , $\therefore \cos \alpha (\sin x + 2\sin \alpha) + \sin \alpha (\cos x + 2\cos \alpha) = 0$ , $\therefore \sin (x + a) + 2\sin 2a = 0$ , 即 $\sin \left( 2a + \frac{\pi}{3} \right) + 2\sin 2a = 0$ . $\therefore \frac{5}{2} \sin 2a + \frac{\sqrt{3}}{2} \cos 2a = 0$ , $\therefore \tan 2a = -\frac{\sqrt{3}}{5}$ .
