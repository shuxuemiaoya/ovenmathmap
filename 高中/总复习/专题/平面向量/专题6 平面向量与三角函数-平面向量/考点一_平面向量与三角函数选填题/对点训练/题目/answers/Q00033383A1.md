> [!faq]- 教师版对点训练解析
>
> > [!success]- **【答案】** C
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > 答案 C 解析 $\because 20a\overrightarrow{BC} + 15b\overrightarrow{CA} + 12c\overrightarrow{AB} = \mathbf{0}, \therefore 20a(\overrightarrow{AC} - \overrightarrow{AB}) + 15b\overrightarrow{CA} + 12c\overrightarrow{AB} = \mathbf{0}, \therefore (20a - 15b)\overrightarrow{AC}$ $+(12c - 20a)\overrightarrow{AB} = \mathbf{0}, \because \overrightarrow{AC}$ 与 $\overrightarrow{AB}$ 不共线， $\therefore \left\{ \begin{array}{l} 20a - 15b = 0, \\ 12c - 20a = 0, \end{array} \right.$ 解得 $\left\{ \begin{array}{l} b = \frac{4}{3} a, \\ c = \frac{5}{3} a, \end{array} \right.$ $\therefore \triangle ABC$ 最小角为角 $A, \therefore \cos A = \frac{b^2 + c^2 - a^2}{2bc} = \frac{\frac{16}{9}a^2 + \frac{25}{9}a^2 - a^2}{2\times\frac{4}{3}a\times\frac{5}{3}a} = \frac{4}{5}, \therefore \sin A = \frac{3}{5}$ ，
> >
> > 故选 **C**.
