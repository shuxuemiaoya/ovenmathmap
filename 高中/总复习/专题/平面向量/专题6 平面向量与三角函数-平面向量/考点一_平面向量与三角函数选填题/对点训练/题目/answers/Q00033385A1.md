>
> > [!note]- **【解析】**
> > 答案 $\frac{5\pi}{6}$ 解析 $\because m // n, \therefore (a + b)(\sin B - \sin A) - \sin C(\sqrt{3} a + c) = 0$ ，又 $\because \frac{a}{\sin A} = \frac{b}{\sin B} = \frac{c}{\sin C}$ ，则化简得 $a^2 + c^2 - b^2 = -\sqrt{3} ac, \therefore \cos B = \frac{a^2 + c^2 - b^2}{2ac} = -\frac{\sqrt{3}}{2}, \because 0 < B < \pi, \therefore B = \frac{5\pi}{6}$ .
