> > [!note]- **【分析】**

> > [!note]- **【解析】**
> > 答案 D 解析 由题意可知 $\lambda_1 + \lambda_2 + \lambda_3 = 1$ 。因为 $P$ 是 $\triangle ABC$ 的中位线 $EF$ 上任意一点，且 $EF // BC$ ，所以 $\lambda_1 = \frac{1}{2}$ ，所以 $\lambda_2 + \lambda_3 = \frac{1}{2}$ ，所以 $\lambda_2\lambda_3 \leq \left(\frac{\lambda_2 + \lambda_3}{2}\right)^2 = \frac{1}{16}$ ，当且仅当 $\lambda_2 = \lambda_3 = \frac{1}{4}$ 时，等号成立，所以 $\lambda_2\lambda_3$ 取最大值时， $P$ 为 $EF$ 的中点。延长 $AP$ 交 $BC$ 于 $M$ ，则 $M$ 为 $BC$ 的中点，所以 $PA = PM$ ，所以 $\overrightarrow{PA} = -\overrightarrow{PM} = -\frac{1}{2} (\overrightarrow{PB} + \overrightarrow{PC})$ ，又因为 $\overrightarrow{PA} + x\overrightarrow{PB} + y\overrightarrow{PC} = 0$ ，所以 $x = y = \frac{1}{2}$ ，所以 $3x + y = 2$ 。故选 D。
