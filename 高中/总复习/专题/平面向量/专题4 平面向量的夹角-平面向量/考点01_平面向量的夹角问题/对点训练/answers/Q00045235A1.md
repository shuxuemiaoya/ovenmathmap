> [!faq]- 《专题4 平面向量的夹角-平面向量》例题解析
>
> > [!success]- **【答案】** C
>
> > [!note]- **【解析】**
> > 答案 C 解析 设向量 a 与 b 的夹角为 $\theta$ ， $\because c = a + b, c \perp a, \therefore c \cdot a = (a + b) \cdot a = a^2 + a \cdot b = 0, \therefore |a|^2 = -|a||b| \cdot \cos\theta, \therefore \cos\theta = -\frac{|a|^2}{|a||b|} = -\frac{|a|}{|b|} = -\frac{1}{2}, \therefore \theta = 120^\circ.$
