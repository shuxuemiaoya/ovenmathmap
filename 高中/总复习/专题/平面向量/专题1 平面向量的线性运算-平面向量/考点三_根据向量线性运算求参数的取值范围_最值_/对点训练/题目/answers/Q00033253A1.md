> [!faq]- 教师版对点训练解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > 答案 $\frac{1}{2}$ 解析 因为 $\overrightarrow{BD} = \overrightarrow{DC}$ ，所以 $\overrightarrow{AD} = \frac{1}{2}\overrightarrow{AB} + \frac{1}{2}\overrightarrow{AC}$ 。又 $\overrightarrow{AE} = \lambda \overrightarrow{AB} + \mu \overrightarrow{AC}$ ，点 $E$ 在线段 $AD$ 上移动，所以 $\overrightarrow{AE} // \overrightarrow{AD}$ ，则 $\frac{1}{\lambda} = \frac{1}{2}$ ，即 $\lambda = \mu \left(0 \leq \lambda \leq \frac{1}{2}\right)$ 。所以 $t = (\lambda - 1)^2 + \lambda^2 = 2\lambda^2 - 2\lambda + 1 = 2\left(\frac{\lambda - 1}{2}\right)^2 + \frac{1}{2}$ 。当 $\lambda = \frac{1}{2}$ 时， $t$ 的最小值是 $\frac{1}{2}$ 。
