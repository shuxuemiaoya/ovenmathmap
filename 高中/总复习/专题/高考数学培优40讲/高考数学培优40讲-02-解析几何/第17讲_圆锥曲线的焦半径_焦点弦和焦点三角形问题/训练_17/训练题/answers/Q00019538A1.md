> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > 设 $\angle AF_{2}x = \alpha$ ，则根据椭圆的焦半径公式可得 $|AF_{2}| = \frac{b^{2}}{a + c\cos\alpha}$ ， $|CF_{2}| = \frac{b^{2}}{a - c\cos\alpha}$ 。因为 $\overrightarrow{AF_2} = m_2\overrightarrow{F_2C}$ ，所以 $m_{2} = \frac{|AF_{2}|}{|F_{2}C|} = \frac{a - c\cos\alpha}{a + c\cos\alpha}$ ，解得 $c\cos\alpha = \frac{a(1 - m_{2})}{1 + m_{2}}$ 。同理设 $\angle AF_{1}x = \beta$ ，则由 $m_{1} = \frac{|AF_{1}|}{|F_{1}B|} = \frac{a + c\cos\beta}{a - c\cos\beta}$ ，可解得 $c\cos\beta = \frac{a(m_1 - 1)}{m_1 + 1}$ 。又 $|AF_{1}| + |AF_{2}| = 2a$ ，所以 $\frac{b^{2}}{a - c\cos\beta} + \frac{b^{2}}{a + c\cos\alpha} = 2a$ ，即 $\frac{b^{2}}{a - \frac{a(m_1 - 1)}{m_1 + 1}} + \frac{b^{2}}{a + \frac{a(1 - m_2)}{1 + m_2}} = 2a$ ，整理得 $m_{1} + m_{2} = \frac{4a^{2}}{b^{2}} - 2$ 。
