> [!faq]- 《高考数学培优40讲》例题解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > 解析 由 $\left\{ \begin{array}{l} (x - 1)^{2023} + (x - 1)^{2021} + 2022x = 4044 \\ (y - 1)^{2023} + (y - 1)^{2021} + 2022y = 0 \end{array} \right.$ 可得 $\left\{ \begin{array}{l} (x - 1)^{2023} + (x - 1)^{2021} + 2022(x - 1) = 2022 \\ (y - 1)^{2023} + (y - 1)^{2021} + 2022(y - 1) = -2022 \end{array} \right.,$
> > $$
> > (x - 1) ^ {2 0 2 3} + (x - 1) ^ {2 0 2 1} + 2 0 2 2 (x - 1) = - [ (y - 1) ^ {2 0 2 3} + (y - 1) ^ {2 0 2 1} + 2 0 2 2 (y - 1) ]
> > $$
> > 令 $f(t) = t^{2023} + t^{2021} + 2022t$ ，易知 $f(t)$ 为 $\mathbb{R}$ 上单调递增的奇函数，因为 $f(x - 1) = -f(y - 1)$ ，所以 $x - 1 + y - 1 = 0, x + y = 2$ . 故填 2.
