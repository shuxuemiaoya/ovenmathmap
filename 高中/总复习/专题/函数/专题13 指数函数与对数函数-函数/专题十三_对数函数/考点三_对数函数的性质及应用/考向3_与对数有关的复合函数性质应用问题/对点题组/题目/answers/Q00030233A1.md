> > [!note]- **【解析】**
> > 答案 A 解析 因为 $y = \log_5 x$ 是增函数，所以 $a = \log_5 2 < \log_5 \sqrt{5} = 0.5$ 。因为 $y = \log_{0.5} x$ 是减函数，所以 $b = \log_{0.5} 0.2 > \log_{0.5} 0.5 = 1$ 。因为 $y = 0.5^x$ 是减函数，所以 $0.5 = 0.5^1 < c = 0.5^{0.2} < 0.5^0 = 1$ ，即 $0.5 < c < 1$ 。所以 $a < c < b$ 。
> >
