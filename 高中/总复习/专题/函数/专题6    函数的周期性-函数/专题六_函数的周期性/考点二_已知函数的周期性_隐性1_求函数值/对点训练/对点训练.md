### 对点训练

答案 1348 解析 $\because f(x + 2) = -\frac{1}{f(x)}, \therefore f(x + 4) = -\frac{1}{f(x + 2)} = f(x), \therefore$ 函数 $y = f(x)$ 的周期 $T = 4$ 。又 $x \in (0, 2]$ 时， $f(x) = 2x - 1, \therefore f(1) = 1, f(2) = 3, f(3) = -\frac{1}{f(1)} = -1, f(4) = -\frac{1}{f(2)} = -\frac{1}{3}, \therefore f(1) + f(2) + f(3) + \ldots + f(2018) = 504[f(1) + f(2) + f(3) + f(4)] + f(504 \times 4 + 1) + f(504 \times 4 + 2) = 504\left(1 + 3 - 1 - \frac{1}{3}\right) + 1 + 3 = 1348.$ 【对点训练】
