> [!faq]- 教师版对点训练解析
>
> > [!success]- **【答案】** C
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > 答案 C 解析 $f(x) = \sin x - \sin 3x = \sin (2x - x) - \sin (2x + x) = -2\cos 2x\sin x$ ，令 $f(x) = 0$ ，可得 $\cos 2x = 0$ 或 $\sin x = 0$ ，因为 $x \in [0, 2\pi]$ ，所以 $2x \in [0, 4\pi]$ ，由 $\cos 2x = 0$ 可得 $2x = \frac{\pi}{2}$ 或 $2x = \frac{3\pi}{2}$ 或 $2x = \frac{5\pi}{2}$ 或 $2x = \frac{7\pi}{2}$ ，所以 $x = \frac{\pi}{4}$ 或 $x = \frac{3\pi}{4}$ 或 $x = \frac{5\pi}{4}$ 或 $x = \frac{7\pi}{4}$ ，由 $\sin x = 0$ 可得 $x = 0$ 或 $x = \pi$ 或 $x = 2\pi$ ，因为 $\frac{\pi}{4} + \frac{3\pi}{4} + \frac{5\pi}{4} + \frac{7\pi}{4} + 0 + \pi + 2\pi = 7\pi$ ，所以 $f(x)$ 的所有零点之和等于 $7\pi$ ，
> >
> > 故选 **C**.
