> [!faq]- 教师版对点训练解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > 答案 $\left(0, \frac{1}{3}\right) \cup (1, 3)$ 解析 由题意， $y = f(x)$ 为奇函数且 $f\left(\frac{1}{2}\right) = 0$ ，所以 $f\left(-\frac{1}{2}\right) = -f\left(\frac{1}{2}\right) = 0$ ，又 $y = f(x)$ 在 $(0, +\infty)$ 上单调递增，则 $y = f(x)$ 在 $(- \infty, 0)$ 上单调递增，于是 $\left\{ \begin{array}{l} \log x > 0, \\ f \log x > f\left(\frac{1}{2}\right) \end{array} \right.$ 或 $\left\{ \begin{array}{l} \log x < 0, \\ f \log x > f\left(-\frac{1}{2}\right), \end{array} \right.$ 即 $\left\{ \begin{array}{l} \log x > 0, \\ \log x > \frac{1}{2} \end{array} \right.$ 或 $\left\{ \begin{array}{l} \log x < 0, \\ \log x > -\frac{1}{2}, \end{array} \right.$ 解得 $0 < x < \frac{1}{3}$ 或 $1 < x < 3$ .
