> [!faq]- 《专题2　函数的解析式与分段函数-函数》例题解析
>
> > [!success]- **【答案】** A
>
> > [!note]- **【解析】**
> > 答案 A 解析 由题意可知 $f(x) = 2$ ，即 $\left\{ \begin{array}{l} 2^x = 2, \\ x \leq 0 \end{array} \right.$ 或 $\left\{ \begin{array}{l} |\log_2 x| = 2, \\ x > 0, \end{array} \right.$ 解得 $x = \frac{1}{4}$ 或 4.
> >
> > 故选 **A**.
