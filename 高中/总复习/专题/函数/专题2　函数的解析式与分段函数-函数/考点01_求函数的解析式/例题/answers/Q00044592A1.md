> [!faq]- 《专题2　函数的解析式与分段函数-函数》例题解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【解析】**
> > 答案 $\frac{2^{x + 1} - 2^{-x}}{3}$ 解析 (解方程组法)由 $f(-x) + 2f(x) = 2^x$ ，①．得 $f(x) + 2f(-x) = 2^{-x}$ ，②．①×2-②，得 $3f(x) = 2^{x + 1} - 2^{-x}$ .即 $f(x) = \frac{2^{x + 1} - 2^{-x}}{3}$ 故 $f(x)$ 的解析式是 $f(x) = \frac{2^{x + 1} - 2^{-x}}{3} (x\in \mathbf{R})$
