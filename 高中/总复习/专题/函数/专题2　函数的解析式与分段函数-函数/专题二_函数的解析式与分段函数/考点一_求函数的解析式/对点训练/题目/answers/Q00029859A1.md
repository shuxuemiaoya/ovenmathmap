> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > 答案 $-\frac{1}{2}x(x+1)$ 解析 $\because -1 \leq x \leq 0, \therefore 0 \leq x + 1 \leq 1, \therefore f(x) = \frac{1}{2}f(x+1) = \frac{1}{2}(x+1)[1-(x+1)] = -\frac{1}{2}x(x+1).$ 故当 $-1\leq x\leq0$ 时， $f(x)=-\frac{1}{2}x(x+1)$ .
