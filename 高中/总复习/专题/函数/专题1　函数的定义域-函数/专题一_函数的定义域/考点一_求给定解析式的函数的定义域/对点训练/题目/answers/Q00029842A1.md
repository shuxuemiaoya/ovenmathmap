>
> > [!note]- **【解析】**
> > 答案 (0, 1] 解析 由 $\left\{ \begin{array}{l} 1 + \frac{1}{x} > 0, \\ x \\ 1 - x^2 \geq 0 \end{array} \right.$ $\Rightarrow \left\{ \begin{array}{l} x < -1 \text{ 或 } x > 0, \\ -1 \leq x \leq 1 \end{array} \right.$ $\Rightarrow 0 < x \leq 1$ 。所以该函数的定义域为(0, 1].
