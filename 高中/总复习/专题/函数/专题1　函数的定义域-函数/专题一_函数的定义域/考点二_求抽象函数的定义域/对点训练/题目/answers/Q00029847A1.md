> > 答案 B 解析 $\because f(x + 1)$ 的定义域为 $[0, 1]$ ，即 $0 \leq x \leq 1$ ， $\therefore 1 \leq x + 1 \leq 2$ 。 $\because f(x + 1)$ 与 $f(2^x - 2)$ 是同一个对应关系 $f$ ， $\therefore 2^x - 2$ 与 $x + 1$ 的取值范围相同，即 $1 \leq 2^x - 2 \leq 2$ ，也就是 $3 \leq 2^x \leq 4$ ，解得 $\log_2 3 \leq x \leq 2$ 。 $\therefore$ 函数 $f(2^x - 2)$ 的定义域为 $[\log_2 3, 2]$ .
