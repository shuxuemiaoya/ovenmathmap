> > [!note]- **【解析】**
> > 答案 -3 解析 当 $x > 0, -x < 0, f(-x) = -\mathrm{e}^{-ax}$ . 因为 $f(x)$ 是奇函数，所以当 $x > 0$ 时， $f(x) = -f(-x) = \mathrm{e}^{-ax}$ ，所以 $f(\ln 2) = \mathrm{e}^{-a\ln 2} = (\mathrm{e}^{\ln 2})^{-a} = 2^{-a} = 8$ 。解得 $a = -3$ 。

> > 7. 若 $f(x)=\ln(e^{3x}+1)+ax$ 是偶函数，则 a= \_\_\_\_.
> >
> > 7. 答案 $-\frac{3}{2}$ 解析 函数 $f(x) = \ln (\mathrm{e}^{3x} + 1) + ax$ 是偶函数，故 $f(-x) = f(x)$ ，即 $\ln (\mathrm{e}^{-3x} + 1) - ax = \ln (\mathrm{e}^{3x} + 1) + ax$ ，化简得 $\ln (1 + \mathrm{e}^{3x}) - \ln \mathrm{e}^{3x} - ax = \ln (\mathrm{e}^{3x} + 1) + ax$ ，即 $-3x - ax = ax$ ，所以 $2ax + 3x = 0$ 恒成立，所以 $a = -\frac{3}{2}$
