> [!faq]- 《专题5    函数的奇偶性-函数》例题解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > 答案 $-\frac{3}{2}$ 解析 函数 $f(x) = \ln (\mathrm{e}^{3x} + 1) + ax$ 是偶函数，故 $f(-x) = f(x)$ ，即 $\ln (\mathrm{e}^{-3x} + 1) - ax = \ln (\mathrm{e}^{3x} + 1) + ax$ ，化简得 $\ln (1 + \mathrm{e}^{3x}) - \ln \mathrm{e}^{3x} - ax = \ln (\mathrm{e}^{3x} + 1) + ax$ ，即 $-3x - ax = ax$ ，所以 $2ax + 3x = 0$ 恒成立，所以 $a = -\frac{3}{2}$
