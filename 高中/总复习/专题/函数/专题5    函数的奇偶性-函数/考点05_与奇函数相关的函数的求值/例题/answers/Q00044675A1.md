> [!faq]- 《专题5    函数的奇偶性-函数》例题解析
>
> > [!success]- **【答案】** D
>
> > [!note]- **【解析】**
> > 答案 D 解析 令 $g(x) = a\sin x + b\ln \frac{1 - x}{1 + x}$ ，则易知 $g(x)$ 为奇函数，所以 $g(\frac{1}{2}) + g(-\frac{1}{2}) = 0$ ，则由 $f(x) = g(x) + t$ ，得 $f(\frac{1}{2}) + f(-\frac{1}{2}) = g(\frac{1}{2}) + g(-\frac{1}{2}) + 2t = 2t = 6$ ，解得 $t = 3$ 。
> >
> > 故选 **D**.
