> [!faq]- 教师版例题解析
>
> > [!success]- **【答案】** (1) D；(2) $\left\{ \begin{array}{l} \mathrm{e}^{-x - 1} - x, x \leqslant 0 \\ \mathrm{e}^{x - 1} + x, x > 0 \end{array} \right.$；(3) D
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > 答案 D 解析 通解：依题意得，当 x<0 时， $f(x)=-f(-x)=-\left(\mathrm{e}^{-x}-1\right)=-\mathrm{e}^{-x}+1$ ，选 D.
> > 优解：依题意得， $f(-1)=-f(1)=-(e^{1}-1)=1-e$ ，结合选项知，选 D.
> > 答案 $\left\{ \begin{array}{l} \mathrm{e}^{-x - 1} - x, x \leqslant 0 \\ \mathrm{e}^{x - 1} + x, x > 0 \end{array} \right.$ 解析 当 $x > 0$ 时， $-x < 0$ ，则 $f(-x) = \mathrm{e}^{x - 1} + x$ ，又 $f(-x) = f(x)$ ，因此 $f(x) = \mathrm{e}^{x - 1} + x$ 。所以 $f(x) = \left\{ \begin{array}{l} \mathrm{e}^{-x - 1} - x, x \leqslant 0 \\ \mathrm{e}^{x - 1} + x, x > 0 \end{array} \right.$ 。
> > 答案 D 解析 因为 $f(x)+g(x)=\mathrm{e}^{x}$ ，所以 $f(-x)+g(-x)=f(x)-g(x)=\mathrm{e}^{-x}$ ，所以 $g(x)=\frac{1}{2}(\mathrm{e}^{x}-\mathrm{e}^{-x})$ .
