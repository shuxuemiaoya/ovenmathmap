> [!faq]- 《专题8　函数奇偶性与单调性的综合问题-函数》例题解析
>
> > [!success]- **【答案】** C
>
> > [!note]- **【解析】**
> > 答案 C 解析 因为函数 $f(x)$ 是定义在 R 上的奇函数，所以 $f(\ln x) - f(\ln \frac{1}{x}) = f(\ln x) - f(-\ln x) = f(\ln x) + f(\ln x) = 2f(\ln x)$ ，所以 $\frac{|f(\ln x) - f(\ln \frac{1}{x})|}{2} < f
> > (1)$ 等价于 $|f(\ln x)| < f (1)$ ，又 $f(x)$ 在区间 $[0, +\infty)$ 上单调递增，所以 $-1 < \ln x < 1$ ，解得 $\frac{1}{e} < x < e$ .
