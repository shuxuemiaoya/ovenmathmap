>
> > [!success]- **【答案】** C
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > 答案 C 解析 秒杀 双曲线渐近线方程为 $y = \pm \frac{b}{a} x$ ，与直线 $y = -(x - a)$ 联立。由 $-\frac{b}{a} x = -x + a$ ，得 $x = \frac{a^2}{a - b}$ ，由 $\frac{b}{a} x = -x + a$ ，得 $x = \frac{a^2}{a + b}$ 。根据题意，若 $\frac{a^2}{a - b} \cdot a = \left(\frac{a^2}{a + b}\right)^2$ ，得 $a(a - b) = (a + b)^2$ ，此式不可能，若 $\frac{a^2}{a + b} \cdot a = \left(\frac{a^2}{a - b}\right)^2$ ，则 $a(a + b) = (a - b)^2$ ，解得 $b = 3a$ 。双曲线的离心率 $e = \sqrt{1 + \left(\frac{b}{a}\right)^2} = \sqrt{10}$ 。
> >
> > 故选 **C**.
