> > [!note]- **【分析】**

> > [!note]- **【解析】**
> > [规范解答] (1)解法一(点差法): 由题意可知直线 $AB$ 的斜率存在.
> > 设 $A(x_{1},y_{1}),B(x_{2},y_{2})$ ，则 $\left\{ \begin{array}{l}\frac{x_1^2 + y_1^2}{4} = 1,\\ \frac{x_2^2 + y_2^2}{4} = 1, \end{array} \right.$ 两式作差得 $\frac{y_1 - y_2}{x_1 - x_2} = -\frac{2}{4}\frac{x_1 + x_2}{y_1 + y_2} = -\frac{2}{4}\frac{2\times 1}{2\times 1} = -\frac{1}{2},$ ∴直线 $AB$ 的方程为 $y - 1 = -\frac{1}{2} (x - 1)$ ，即 $x + 2y - 3 = 0$ 解法二：由题意可知直线 $AB$ 的斜率存在．设直线 $AB$ 的斜率为 $k$ 则其方程为 $y - 1 = k(x - 1)$ ，代入 $x^{2} + 2y^{2} = 4$ 中，得 $x^{2} + 2[kx - (k - 1)]^{2} - 4 = 0$ $\therefore (1 + 2k^2)x^2 -4k(k - 1)x + 2(k - 1)^2 -4 = 0.$ $A = [-4(k - 1)k]^2 -4(2k^2 +1)[2(k - 1)^2 -4] = 8(3k^2 +2k + 1) > 0.$ 设 $A(x_{1},y_{1}),B(x_{2},y_{2})$ ，则 $\left\{ \begin{array}{ll}x_{1} + x_{2} = \frac{4k-k - 1}{2k^{2} + 1},\\ x_{1}x_{2} = \frac{2-k - 1^2 - 4}{2k^{2} + 1}. \end{array} \right.$ $\because AB$ 中点为(1，1)， $\therefore \frac{1}{2} (x_1 + x_2) = \frac{2k-k - 1}{2k^2 + 1} = 1$ ，则 $k = -\frac{1}{2}$ ∴直线 $AB$ 的方程为 $y - 1 = -\frac{1}{2} (x - 1)$ ，即 $x + 2y - 3 = 0.$
