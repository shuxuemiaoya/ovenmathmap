> [!faq]- 教师版对点训练解析
>
> > [!success]- **【答案】** C
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > 答案 C 解析 设直线 $l: x = ty + 2, A(x_1, y_1), B(x_2, y_2)$ ，则由 $\left\{ \begin{array}{l} y^2 = 8x \\ x = ty + 2 \end{array} \right.$ 可以得到 $y^2 - 8ty - 16 = 0$ 。
> > 所以 $AB$ 的中点 $M(4t^2 + 2,4t)$ ，线段 $AB$ 的垂直平分线与 $x$ 轴交于点 $P(10,0)$ ，故 $t \neq 0$ 。所以 $AB$ 的中垂线的方程为 $y = -\frac{1}{t} (x - 4t^2 - 2) + 4t = -\frac{1}{t} x + 8t + \frac{2}{t}$ ，令 $y = 0$ 可得 $x = 8t^2 + 2$ ，解方程 $10 = 8t^2 + 2$ 得 $t = \pm 1$ 。此时 $AB = \sqrt{1 + t^2} |y_1 - y_2| = 8\sqrt{1 + t^2}\sqrt{t^2 + 1} = 16, O$ 到 $AB$ 的距离为 $d = \frac{2}{\sqrt{1 + t^2}} = \sqrt{2}$ , 所以 $S_{\Delta OAB} = \frac{1}{2} \times 16 \times \sqrt{2} = 8\sqrt{2}$ .
> >
> > 故选 **C**.
