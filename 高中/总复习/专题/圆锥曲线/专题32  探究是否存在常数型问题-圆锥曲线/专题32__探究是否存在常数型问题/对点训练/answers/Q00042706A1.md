> [!faq]- 《专题32  探究是否存在常数型问题-圆锥曲线》例题解析
>
> > [!success]- **【答案】** C
>
> > [!note]- **【解析】**
> > 解析
> > (1)∵抛物线 $x^{2}=4y$ 在点 $P(2,1)$ 处的切线方程为 y=x-1，它过 x 轴上的点 $(1,0)$ ,
> >
> > ∴椭圆 C 的一个焦点为 $(1, 0)$ ，即 c=1，又∵ $e=\frac{c}{a}=\frac{\sqrt{2}}{2}$ ，∴ $a=\sqrt{2}$ ，b=1，
> >
> > ∴椭圆 C 的方程为 $\frac{x^{2}}{2} + y^{2} = 1$ .
> >
> > (2)设 $A(x_{1}, y_{1})$ , $B(x_{2}, y_{2})$ , l 的方程为 $y=k(x+4)$ ，联立 $\left\{\begin{aligned}y &= k(x+4), \\ x^{2} &= 2y^{2} = 2\end{aligned}\right.$ $\Rightarrow (1 + 2k^{2})x^{2} + 16k^{2}x + 32k^{2} - 2 = 0, \quad \therefore \left\{\begin{aligned} &\Delta > 0, \\ &x_{1} + x_{2} = -\frac{16k^{2}}{1 + 2k^{2}}, \\ &x_{1}x_{2} = \frac{32k^{2} - 2}{1 + 2k^{2}}.\end{aligned}\right.$ $\because F_{1}(-1, 0), k_{1} = \frac{y_{1}}{x_{1} + 1}, k_{2} = \frac{y_{2}}{x_{2} + 1}, \quad \therefore \frac{1}{k_{1}} + \frac{1}{k_{2}} = \frac{x_{1} + 1}{y_{1}} + \frac{x_{2} + 1}{y_{2}} = \frac{1}{k} \left(\frac{x_{1} + 1}{x_{1} + 4} + \frac{x_{2} + 1}{x_{2} + 4}\right),$ $\therefore \frac{k}{k_{1}} + \frac{k}{k_{2}} = \frac{2x_{1}x_{2} + 5(x_{1} + x_{2}) + 8}{x_{1}x_{2} + 4(x_{1} + x_{2}) + 16} = \frac{2}{7}, \quad \therefore k_{1}k + k_{2}k = \frac{2}{7}k_{1}k_{2}, \quad \therefore \text { 存在常数 } \lambda = \frac{2}{7}.$
