> [!faq]- 教师版对点训练解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > 答案 $(2, +\infty)$ 解析 设直线 $l: x = 2y + t$ ，联立抛物线方程消去 $x$ 得 $y^{2} = 2p(2y + t) \Rightarrow y^{2} - 4py - 2pt = 0$ ，设 $A(x_{1}, y_{1}), B(x_{2}, y_{2}), \Delta = 16p^{2} + 8pt > 0 \Rightarrow t > -2p, y_{1} + y_{2} = 4p, y_{1}y_{2} = -2pt > 0 \Rightarrow t < 0$ ，即 $-2p < t < 0.x_{1}x_{2} = (2y_{1} + t)(2y_{2} + t) = 4y_{1}y_{2} + 2t(y_{1} + y_{2}) + t^{2} = 4(-2pt) + 2t \cdot 4p + t^{2} = t^{2}, k_{1} + k_{2} = \frac{y_{1}}{x_{1}} + \frac{y^{2}}{x_{2}} = \frac{(2y_{2} + t)y_{1} + (2y_{1} + t)y_{2}}{x_{1}x_{2}} = \frac{t(y_{1} + y_{2}) + 4y_{1}y_{2}}{x_{1}x_{2}} = \frac{4pt - 8pt}{t^{2}} = -\frac{4p}{t}. - 2p < t < 0, -\frac{4p}{t} > 2$ ，即 $k_{1} + k_{2}$ 的取值范围是 $(2, +\infty)$ .
