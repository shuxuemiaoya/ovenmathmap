>
> > [!success]- **【答案】** A
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > 答案 A 解析 $PF_{2} \perp PQ$ 且 $|PF_{2}| = |PQ|$ ，可得 $\triangle PQF_{2}$ 为等腰直角三角形，设 $|PF_{2}| = t$ ，则 $|QF_{2}| = \sqrt{2}t$ ，由椭圆的定义可得 $|PF_{1}| = 2a - t, 2t + \sqrt{2}t = 4a$ ，则 $t = 2(2 - \sqrt{2})a$ ，在直角三角形 $PF_{1}F_{2}$ 中，可得 $t^{2} + (2a - t)^{2} = 4c^{2} \cdot 4(6 - 4\sqrt{2})a^{2} + (12 - 8\sqrt{2})a^{2} = 4c^{2}$ ，化为 $c^{2} = (9 - 6\sqrt{2})a^{2}$ ，可得 $e = \frac{c}{a} = \sqrt{6} - \sqrt{3}$ 。
> >
> > 故选 **A**.
