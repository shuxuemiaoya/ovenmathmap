> > [!note]- **【解析】**
> > 答案 D 解析 设 $|F_{1}B|=k(k>0)$ ，依题意可得 $|AF_{1}|=3k,\quad|AB|=4k,\quad\therefore|AF_{2}|=2a-3k,\quad|BF_{2}|=2a-k.\quad\because\cos\angle AF_{2}B=\frac{3}{5}$ ，在 $\triangle ABF_{2}$ 中，由余弦定理可得 $|AB|^{2}=|AF_{2}|^{2}+|BF_{2}|^{2}-2|AF_{2}||BF_{2}|\cos\angle AF_{2}B,\quad\therefore(4k)^{2}=(2a-3k)^{2}+(2a-k)^{2}-\frac{6}{5}(2a-3k)(2a-k)$ ，化简可得 $(a+k)(a-3k)=0$ ，而 $a+k>0$ ，故a-3k=0，a=3k， $\therefore|AF_{2}|=|AF_{1}|=3k,\quad|BF_{2}|=5k,\quad\therefore|BF_{2}|^{2}=|AF_{2}|^{2}+|AB|^{2},\quad\therefore AF_{1}\perp AF_{2},\quad\therefore\triangle AF_{1}F_{2}$ 是等腰直角三角形。 $\therefore c=\frac{\sqrt{2}}{2}a$ ，椭圆的离心率 $e=\frac{c}{a}=\frac{\sqrt{2}}{2}$ .
