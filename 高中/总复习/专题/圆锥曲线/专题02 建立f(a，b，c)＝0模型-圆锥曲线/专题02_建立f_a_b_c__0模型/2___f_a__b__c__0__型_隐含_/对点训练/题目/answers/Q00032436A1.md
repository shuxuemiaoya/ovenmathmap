> > [!note]- **【解析】**
> > 答案 C 解析 不妨设椭圆的标准方程为 $\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1 (a > b > 0)$ ，则 $2b = 8$ ，即 $b = 4$ ，设 $\triangle PF_1F_2$ 内切圆的半径为 $r$ ，则有 $S_{\triangle PF1F2} = \frac{1}{2}(2a + 2c)r = \frac{1}{2} \times 2c|y_P|$ ，即 $r = \frac{c|y_P|}{a + c}$ ，当点 $P$ 运动到椭圆短轴的端点时， $r$ 有最大值 $\frac{3}{2}$ ，此时 $|y_P| = b$ ，于是有 $\frac{4c}{a + c} = \frac{3}{2}$ ，即 $3a = 5c$ ，故椭圆的离心率 $e = \frac{c}{a} = \frac{3}{5}$ .
