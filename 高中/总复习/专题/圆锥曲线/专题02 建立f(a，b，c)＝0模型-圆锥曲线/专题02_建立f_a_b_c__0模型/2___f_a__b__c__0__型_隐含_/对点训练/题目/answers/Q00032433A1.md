> [!faq]- 教师版对点训练解析
>
> > [!success]- **【答案】** C
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > 答案 C 解析 设 $F'$ 为双曲线的左焦点， $|F'F|=2c$ ，依题意可得 $|PO|=|PF|=c$ ，连接 $PF'$ ，由双曲线的定义可得 $|PF'|-|PF|=2a$ ，故 $|PF'|=2a+c$ ，在 $\triangle PF'O$ 中， $\angle POF'=120^{\circ}$ ，由余弦定理可得 $\cos120^{\circ}=\frac{c^{2}+c^{2}-(2a+c)^{2}}{2c^{2}}$ ，化简可得 $c^{2}-2ac-2a^{2}=0$ ，即 $(\frac{c}{a})^{2}-2\times\frac{c}{a}-2=0$ ，解得 $\frac{c}{a}=1+\sqrt{3}$ 或 $\frac{c}{a}=1-\sqrt{3}$ （不合题意，舍去），故双曲线的离心率 $e=1+\sqrt{3}$ ，
> >
> > 故选 **C**.
