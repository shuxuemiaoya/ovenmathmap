> > [!note]- **【分析】**

> > [!note]- **【解析】**
> > 答案 D 解析 设 $P(x_{0}, y_{0})$ ，又 $F_{1}(-c, 0)$ ， $F_{2}(c, 0)$ ，则 $\triangle PF_{1}F_{2}$ 的重心 $G\left(\frac{x_{0}}{3}, \frac{y_{0}}{3}\right)$ 。因为 $IG \parallel F_{1}F_{2}$ ，所以 $\triangle PF_{1}F_{2}$ 的内心 I 的纵坐标为 $\frac{y_{0}}{3}$ 。即 $\triangle PF_{1}F_{2}$ 的内切圆半径为 $\frac{|y_{0}|}{3}$ 。由 $\triangle PF_{1}F_{2}$ 的面积 $S = \frac{1}{2}(|PF_{1}| + |PF_{2}| + |F_{1}F_{2}|)r$ ， $S = \frac{1}{2}|F_{1}F_{2}||y_{0}|$ 及椭圆定义 $|PF_{1}| + |PF_{2}| = 2a$ ，得 $\frac{1}{2}(2a + 2c)\frac{|y_{0}|}{3} = \frac{1}{2} \times 2c|y_{0}|$ ，解得 $e = \frac{1}{2}$ 。
> >
> > 故选 **D**。
