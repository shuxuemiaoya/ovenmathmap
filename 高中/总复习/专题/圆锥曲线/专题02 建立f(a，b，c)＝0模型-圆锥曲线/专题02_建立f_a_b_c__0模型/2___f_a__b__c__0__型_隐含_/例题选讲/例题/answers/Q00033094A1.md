> > [!note]- **【解析】**
> > 答案 A 解析 由 $F_{2}(c,0)$ 到渐近线 $y = \frac{b}{a} x$ 的距离为 $d = \frac{bc}{\sqrt{a^2 + b^2}} = b$ ，即有 $|\overrightarrow{AF_2}| = b$ ，则 $|\overrightarrow{BF_2}| = 3b$ ，在 $\triangle AF_2O$ 中， $|\overrightarrow{OA}| = a, |\overrightarrow{OF_2}| = c, \tan \angle F_2OA = \frac{b}{a}$ ，又有 $\angle AOB = 2\angle F_2OA$ ，则 $\tan \angle AOB = \frac{4b}{a} = \frac{2\times\frac{b}{a}}{1 - \left(\frac{b}{a}\right)^2}$ ，化简可得 $a^2 = 2b^2$ ，即有 $c^2 = a^2 + b^2 = \frac{3}{2} a^2$ ，即有 $e = \frac{c}{a} = \frac{\sqrt{6}}{2}$ 。
> >
> > 故选 **A**.
