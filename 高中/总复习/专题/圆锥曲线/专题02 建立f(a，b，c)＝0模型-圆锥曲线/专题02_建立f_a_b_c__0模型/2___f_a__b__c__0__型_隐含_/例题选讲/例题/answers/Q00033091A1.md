> > 答案 B 解析 设双曲线的右焦点为 $F'$ ，取 $MN$ 的中点 $P$ ，连接 $F'P, F'M, F'N$ ，如图所示，由 $\overrightarrow{FN} = 3\overrightarrow{FM}$ ，可知 $|MF| = |MP| = |NP|$ 。又 $O$ 为 $FF'$ 的中点，可知 $OM // PF'$ 。 $\because OM \perp FN, \therefore PF' \perp FN.$ $\therefore PF'$ 为线段 $MN$ 的垂直平分线。 $\therefore |NF'| = |MF'|$ 。设 $|MF| = t$ ，由双曲线定义可知 $|NF'| = 3t - 2a, |MF'| = 2a + t$ ，则 $3t - 2a = 2a + t$ ，解得 $t = 2a$ 。在 Rt△MF'P 中， $|PF'| = \sqrt{|MF'|^2 - |MP|^2} = \sqrt{16a^2 - 4a^2} = 2\sqrt{3}a, \therefore |OM| = \frac{1}{2} |PF'| = \sqrt{3}a$ 。在 Rt△MFO 中， $|MF|^2 + |OM|^2 = |OF|^2, \therefore 4a^2 + 3a^2 = c^2 \Rightarrow e = \sqrt{7}$ 。
