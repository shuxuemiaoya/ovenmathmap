> [!faq]- 教师版对点训练解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > 答案 $\frac{2\sqrt{3}}{3}$ 解析 设右焦点 $F(c,0)$ ，渐近线 $OM$ ， $ON$ 的方程分别为 $y = \frac{b}{a} x$ ， $y = -\frac{b}{a} x$ 。不失一般性，设过 $F$ 的垂线为 $x = -\frac{b}{a} y + c$ 。由 $\left\{ \begin{array}{l} y = -\frac{b}{a} x, \\ x = -\frac{b}{a} y + c \end{array} \right.$ 得 $y_{N} = \frac{-\frac{bc}{a}}{1 - \frac{b^{2}}{a^{2}}}$ 。由 $\left\{ \begin{array}{l} y = \frac{b}{a} x, \\ x = -\frac{b}{a} y + c \end{array} \right.$ 得 $y_{M} = \frac{\frac{bc}{a}}{1 + \frac{b^{2}}{a^{2}}}$ 。因为 $2\overrightarrow{MF} = \overrightarrow{FN}$ ，所以 $-2y_{M} = y_{N}$ ，即 $\frac{-2\frac{bc}{a}}{1 + \frac{b^{2}}{a^{2}}} = \frac{-\frac{bc}{a}}{1 - \frac{b^{2}}{a^{2}}}$ ，易解得 $\frac{b^2}{a^2} = \frac{1}{3}$ ，所以 $e = \sqrt{1 + \frac{b^2}{a^2}} = \sqrt{1 + \frac{1}{3}} = \frac{2\sqrt{3}}{3}$ 。
