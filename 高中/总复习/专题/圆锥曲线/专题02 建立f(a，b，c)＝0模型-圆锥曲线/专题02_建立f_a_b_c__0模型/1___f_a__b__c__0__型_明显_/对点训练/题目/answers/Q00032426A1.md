> [!faq]- 教师版对点训练解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > 答案 $\sqrt{3}-1$ 解析 设椭圆的焦距为 $2c, A(x_1, y_1), B(x_2, y_2)$ ，由题意得直线 $AB$ 的方程为 $y=x-1$ ，与椭圆方程联立，消去 $x$ 化简得 $(a^2+b^2)y^2+2b^2y+b^2-a^2b^2=0$ ，由根与系数的关系得， $y_1+y_2=\frac{-2b^2}{a^2+b^2}$ ， $y_1\cdot y_2=\frac{b^2-a^2b^2}{a^2+b^2}$ ，则 $\triangle F_1AB$ 的面积为 $\frac{1}{2}\times 2c|y_1-y_2|=\sqrt{\left(\frac{-2b^2}{a^2+b^2}\right)^2-\frac{4(b^2-a^2b^2)}{a^2+b^2}}=\sqrt{2}b^2$ ，化简得 $-2a^2+2a^4+2a^2b^2=b^2(a^2+b^2)^2$ ，又因为 $b^2=a^2-1$ ，所以 $4a^4-8a^2+1=0$ ，解得 $a=\frac{1+\sqrt{3}}{2}$ ，则椭圆的离心率 $e=\frac{c}{a}=\sqrt{3}-1$ .
