> [!faq]- 教师版对点训练解析
>
> > [!success]- **【答案】** D
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > 答案 D 解析 不妨设点 $P$ 在第一象限，因为 $PF \perp x$ 轴，所以 $x_{P} = c$ ，将 $x_{P} = c$ 代入椭圆方程得 $y_{P} = \frac{b^{2}}{a}$ ，即 $|PF| = \frac{b^{2}}{a}$ ，则 $\tan \angle PAF = \frac{|PF|}{|AF|} = \frac{\frac{b^2}{a}}{a + c} = \frac{1}{2}$ ，结合 $b^{2} = a^{2} - c^{2}$ ，整理得 $2c^{2} + ac - a^{2} = 0$ ，两边同时除以 $a^{2}$ 得 $2e^{2} + e - 1 = 0$ ，解得 $e = \frac{1}{2}$ 或 $e = -1$ （舍去）。
> >
> > 故选 **D**.
