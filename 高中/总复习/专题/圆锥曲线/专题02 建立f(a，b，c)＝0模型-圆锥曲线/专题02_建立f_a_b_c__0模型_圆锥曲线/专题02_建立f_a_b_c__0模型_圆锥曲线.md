# 专题02 建立 $f(a, b, c) = 0$ 模型

## 1. $f(a, b, c)=0$ 型(明显)

所谓明显型就是题目中有明显的等量关系，在计算离心率的大小时，根据题目中的条件，建立 a, b, c 之间的齐次等量关系 $f(a, b, c)=0$ ，再化归为关于离心率 e 的方程求解.
