2. $f(a, b, c)=0$ 型(隐含)

所谓隐含型就是题目中没有明显的等量关系，在计算离心率的大小时，根据题目中的条件，利用图形中存在的几何特征掘几何关系，运用点在曲线上或垂直关系或用余弦定理等，建立 $a, b, c$ 之间的齐次等量关系 $f(a, b, c) = 0$ ，再化归为关于离心率 $e$ 的方程求解.
