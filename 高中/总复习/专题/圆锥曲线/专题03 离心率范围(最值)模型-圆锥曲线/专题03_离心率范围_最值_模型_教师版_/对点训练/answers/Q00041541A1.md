> [!faq]- 《专题03 离心率范围(最值)模型(教师版)》例题解析
>
> > [!success]- **【答案】** C
>
> > [!note]- **【解析】**
> > 答案 C 解析 双曲线 $C: \frac{x^2}{a^2 + 1} - y^2 = 1 (a > 0)$ 中，右顶点为 $A(\sqrt{a^2 + 1}, 0), \therefore |OA| = \sqrt{a^2 + 1} < 2, \therefore 1 < a^2 + 1 < 4, \therefore 1 > \frac{1}{a^2 + 1} > \frac{1}{4}, \because c^2 = a^2 + 1 + 1 = a^2 + 2, \therefore c = \sqrt{a^2 + 2}, \therefore e = \frac{\sqrt{a^2 + 2}}{\sqrt{a^2 + 1}} = \sqrt{\frac{a^2 + 2}{a^2 + 1}} = \sqrt{1 + \frac{1}{a^2 + 1}}, \therefore \sqrt{1 + \frac{1}{4}} < e < \sqrt{1 + 1}$ ，即 $\frac{\sqrt{5}}{2} < e < \sqrt{2}$ .
> >
> > 故选 **C**.
