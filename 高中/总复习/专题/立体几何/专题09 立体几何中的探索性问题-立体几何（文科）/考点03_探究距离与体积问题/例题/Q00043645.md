[例 1]如图所示，圆柱的高为2，点A，B，C，D分别是圆柱下底面圆周上的点，ABCD为矩形，PA是圆柱的母线，AB=2，BC=4，E，F，G分别是线段PA，PD，CD的中点.

(1)求证：平面 $PDC \perp$ 平面 PAD;

(2)求证： $PB / /$ 平面EFG;

(3)在线段 $BC$ 上是否存在一点 $M$ ，使得 $D$ 到平面 $PAM$ 的距离为 2？若存在，求出 $BM$ ；若不存在，请说明理由.

![](../../images/questions/cee399c4eeed12360836f913eefdf59bd4c078acd433a4d908bcf49e6f67a40b.jpg)

(1)∵ PA 是圆柱的母线，∴ $PA \perp$ 圆柱的底面.

∵ $CD \subset$ 圆柱的底面， $PA \perp CD$ ，又∵ ABCD 为矩形，∴ $CD \perp AD$ ，

而 $PA \perp AD = A$ ，∴ $CD \perp$ 平面 PAD．又 $CD \subset$ 平面 PDC，∴ 平面 $PDC \perp$ 平面 PAD．

![](../../images/questions/e0ee25ca3156c87fab16a33e699e9059471df5fa96b7574371984c56a88340c3.jpg)

(2)取 AB 中点 H，连接 GH, HE，∵ E、F、G 分别是线段 PA、PD、CD 的中点，∴ GH // AD // EF，∴ E、F、G、H 四点共面．又 H 为 AB 中点，∴ EH // PB．又 $EH \subset$ 平面 EFG， $PB \not\subset$ 平面 EFG，∴ PB // 平面 EFG．
