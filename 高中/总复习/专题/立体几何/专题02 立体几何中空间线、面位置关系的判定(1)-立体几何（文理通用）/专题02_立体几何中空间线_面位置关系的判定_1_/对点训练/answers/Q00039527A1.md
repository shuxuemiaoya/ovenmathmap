> [!faq]- 《专题02 立体几何中空间线、面位置关系的判定(1)-立体几何（文理通用）》例题解析
>
> > [!success]- **【答案】** C
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > 答案 C 解析 若直线 a, b 异面, b, c 异面, 则 a, c 相交、平行或异面; 若 a, b 相交, b, c 相交, 则 a, c 相交、平行或异面; 若 $a \perp b$ , $b \perp c$ , 则 a, c 相交、平行或异面; 由异面直线所成的角的定义知 C 正确.
> >
> > 故选 **C**.
