## 3.3 借用运算

利用向量的运算来处理立体几何问题是高中数学中一道亮丽的风景线,这样往往能较好地避免添加辅助线的无端烦恼,同时也在无形之中降低了对空间想象能力高要求的依赖,这体现了向量运算解决几何问题的巨大威力.常见的向量运算有:向量三项和的平方公式,向量的对角线定理等.
