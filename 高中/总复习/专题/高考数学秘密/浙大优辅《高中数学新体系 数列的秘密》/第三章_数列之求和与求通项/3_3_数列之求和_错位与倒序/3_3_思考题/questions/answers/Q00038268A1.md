> [!faq]- 《高中数学新体系·数列的秘密》参考答案
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > 解答 公共项构成的新数列 $\{c_{n}\}$ 是以 $c_{1} = 22$ 为首项， $d = 20$ 为公差的等差数列，所以 $c_{n} = 20n + 2$ 。因为 $a_{n} = 4n + 2, b_{n} = 5n - 3$ ，所以 $a_{100} = 402, b_{100} = 497$ 。
> > 故 $20n + 2 \leqslant 402, n \leqslant 20$ . 公共项有20项，它们的和 $S_{20} = 20 \times 22 + \frac{20 \times 19}{2} \times 20 = 4240.$
