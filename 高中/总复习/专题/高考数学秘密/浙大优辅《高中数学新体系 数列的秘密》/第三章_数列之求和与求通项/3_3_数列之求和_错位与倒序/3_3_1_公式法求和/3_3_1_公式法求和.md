## 3.3.1 公式法求和

(1)等差数列的前 $n$ 项和: $S_{n} = \frac{n(a_{1} + a_{n})}{2} = na_{1} + \frac{n(n - 1)}{2} d$ ;

(2)等比数列的前 $n$ 项和： $S_{n} = \begin{cases} na_{1}, q = 1, \\ \frac{a_{1}(1 - q^{n})}{1 - q} = \frac{a_{1} - a_{n}q}{1 - q}, q \neq 0 \text{且} q \neq 1. \end{cases}$

其中,等比数列求和公式的适用范围需要予以特别注意.
