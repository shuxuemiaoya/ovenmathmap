> [!faq]- 《高中数学新体系·数列的秘密》例题解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > 解答 结合等比数列与等差数列的求和公式,可得
> > $$
> > S _ {n} = \frac {2 (1 - 2 ^ {n})}{1 - 2} + \frac {(1 + 2 n - 1) n}{2} = 2 ^ {n + 1} + n ^ {2} - 2.
> > $$
