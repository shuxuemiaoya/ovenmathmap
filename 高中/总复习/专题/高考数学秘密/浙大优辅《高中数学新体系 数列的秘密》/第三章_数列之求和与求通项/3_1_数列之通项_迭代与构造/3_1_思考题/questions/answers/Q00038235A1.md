> [!faq]- 《高中数学新体系·数列的秘密》参考答案
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > 解答 令 $x = \frac{7x - 8}{2x - 3}$ , 解得 $x_{1} = 1, x_{2} = 4$ .
> > 于是 $a_{n + 1} - 1 = \frac{5(a_n - 1)}{2a_n - 3}, a_{n + 1} - 4 = -\frac{a_n - 4}{2a_n - 3}$
> > 所以 $\frac{a_{n + 1} - 1}{a_{n + 1} - 4} = \frac{-5(a_n - 1)}{a_n - 4} = (-5)^n\times \frac{a_1 - 1}{a_1 - 4} =$ $\frac{-1}{2}\times (-5)^n,$
> > 即 $2 - 2a_{n} = (-5)^{n - 1}\times (a_{n} - 4),$
> > 所以 $a_{n} = \frac{2 + 4\times(-5)^{n - 1}}{2 + (-5)^{n - 1}}.$
> > 化简可得 $na_{n + 1} = (n + 1)a_n$ ，即 $\frac{a_{n + 1}}{n + 1} = \frac{a_n}{n}$
> > 故 $a_{n} = n$
> > $b_{n} = a_{n} + 2^{n + 1} - \frac{1}{2}$ $= (3a_{n - 1} + 2^n -1) + \left(2^{n + 1} - \frac{1}{2}\right)$ $= 3a_{n - 1} + 3\times 2^n -\frac{3}{2} = 3b_{n - 1}(n\geqslant 2),$
> > 所以 $\{b_n\}$ 为等比数列.
> > 其首项 $b_{1} = a_{1} + 2^{2} - \frac{1}{2} = \frac{9}{2}, q = 3.$
> > (2)由(1)可知 $b_{n}=a_{n}+2^{n+1}-\frac{1}{2}=\frac{3^{n+1}}{2}$ ,
> > 所以 $a_{n} = \frac{3^{n + 1}}{2} -2^{n + 1} + \frac{1}{2}.$
