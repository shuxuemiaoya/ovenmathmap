> [!faq]- 《高中数学新体系·数列的秘密》参考答案
>
> > [!success]- **【答案】** C
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > 解答 依题意, $a_{n+1}=2+\sqrt{4a_{n}-a_{n}^{2}}$ 可化为 $(a_{n+1}-2)^{2}+(a_{n}-2)^{2}=4$ .
> > 令 $b_{n}=(a_{n}-2)^{2}$ ，则 $b_{n+1}+b_{n}=4$ ，
> > 所以 $b_{n+2}+b_{n+1}=4$ ，于是 $b_{n+2}=b_{n}$ .
> > 所以 $b_{1} = (a_{1} - 2)^{2}, b_{2020} = b_{2} = (a_{2} - 2)^{2}$ ， $b_{1} + b_{2020} = b_{1} + b_{2} = 4$ 即 $(a_{1} - 2)^{2} + (a_{2020} - 2)^{2} = 4.$ 解法一： $\left\{ \begin{array}{l}a_1 = 2 + 2\cos \theta ,\\ a_{2020} = 2 + 2\sin \theta \end{array} \right.\Rightarrow a_1 + a_{2020} = 4+$ $2\sqrt{2}\sin \left(\theta +\frac{\pi}{4}\right)\leqslant 4 + 2\sqrt{2}$ （当且仅当 $\theta = \frac{\pi}{4}$ 时，等号成立）.故选C.解法二：因为 $\frac{x + y}{2}\leqslant \sqrt{\frac{x^2 + y^2}{2}}$ 所以 $a_1 + a_{2020} = (a_1 - 2) + (a_{2020} - 2) + 4\leqslant 2\times$ $\sqrt{\frac{(a_1 - 2)^2 + (a_{2020} - 2)^2}{2}} +4 = 4 + 2\sqrt{2}$ （当且仅当 $a_1 = a_{2020} = 2 + \sqrt{2}$ 时，等号成立）故选C.解法三： $(a_{1} - 2)^{2} + (a_{2020} - 2)^{2} = 4$ 即点 $(a_{1},a_{2020})$ 在圆 $(x - 2)^{2} + (y - 2)^{2} = 4$ 上.令 $z = x + y$ ，即 $x + y - z = 0$ ，所以 $d = \frac{|z - 4|}{\sqrt{2}}\leqslant 2,$ 即 $|z - 4|\leqslant 2\sqrt{2}$ ，从而 $4 - 2\sqrt{2}\leqslant z\leqslant 4 + 2\sqrt{2}$ 即 $z_{\max} = 4 + 2\sqrt{2}$ 故选C.6.解答因为 $x_{n + 1} = \frac{ax_n}{x_n + 1}$ 所以 $x_{n + 3} = \frac{ax_{n + 2}}{x_{n + 2} + 1} = \frac{a^2x_{n + 1}}{(a + 1)x_{n + 1} + 1} =$ $\frac{a^3x_n}{(a^2 + a + 1)x_n + 1} = x_n,$ 即 $(a^{2} + a + 1)(x_{n} + 1 - a) = 0$ 恒成立.因为 $x_{n}\neq a - 1$ 且 $x_{n}\neq 0$ ，所以 $a^2 +a + 1 = 0$ 所以 $a = -\frac{1}{2}\pm \frac{\sqrt{3}}{2}\mathrm{i}$ 7.解答由 $a_{n} = \frac{aa_{n - 1} - b}{ca_{n - 1} - d}$ 得 $a_{n}a_{n - 1} - \frac{a}{c} a_{n} - \frac{a}{c} a_{n - 1} + \frac{b}{c} = 0,$
> > 所以 $\left(a_{n}-\frac{a}{c}\right)\left(a_{n-1}-\frac{a}{c}\right)=\frac{a^{2}}{c^{2}}-\frac{b}{c}$ .
> > 由 $\left(a_{n+1}-\frac{a}{c}\right)\left(a_{n}-\frac{a}{c}\right)=\frac{a^{2}}{c^{2}}-\frac{b}{c}$ 知 $a_{n+1}=a_{n-1}$ ，
> > 故数列 $\{a_{n}\}$ 是周期数列且其周期T=2.
