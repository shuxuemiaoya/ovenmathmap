> > 解答 把 $a^2 - bc, b^2 - ac, c^2 - ab$ 中的 $b$ 用 $\frac{a + c}{2}$ 替换，可推导出 $2(b^2 - ac) - [(a^2 - bc) + (b^2 - ac)] = 0.$ 所以 $a^2 - bc, b^2 - ac, c^2 - ab$ 是等差数列。16. 解答（1）因为 $a_1 = 5$ ，所以 $a_2 = 2a_1 + 2^2 - 1 = 13, a_3 = 2a_2 + 2^3 - 1 = 33.$ （2）假设存在实数 $\lambda$ ，使得数列 $\left\{\frac{a_n + \lambda}{2^n}\right\}$ 为等差数列。设 $b_n = \frac{a_n + \lambda}{2^n}$ ，由于 $\{b_n\}$ 为等差数列，则有 $2b_2 = b_1 + b_3$ ，所以 $2 \times \frac{a_2 + \lambda}{2^2} = \frac{a_1 + \lambda}{2} + \frac{a_3 + \lambda}{2^3}$ ，所以 $\frac{13 + \lambda}{2} = \frac{5 + \lambda}{2} + \frac{33 + \lambda}{8}$ ，解得 $\lambda = -1$ 。事实上， $b_{n+1} - b_n = \frac{a_{n+1} - 1}{2^{n+1}} - \frac{a_n - 1}{2^n} = \frac{1}{2^{n+1}}[(a_{n+1} - 2a_n) + 1] = \frac{1}{2^{n+1}}[(2^{n+1} - 1) + 1] = 1.$ 综上可知，存在实数 $\lambda = -1$ ，使得数列 $\left\{\frac{a_n + \lambda}{2^n}\right\}$ 是首项为 2，公差为 1 的等差数列。17. 解答（1） $a_n = S_n - S_{n-1} = (100n - n^2) - [100(n-1) - (n-1)^2] = 101 - 2n (n \geqslant 2)$ 因为 $a_1 = S_1 = 100 \times 1 - 1^2 = 99 = 101 - 2 \times 1$ ，所以数列 $\{a_n\}$ 的通项为 $a_n = 101 - 2n (n \in \mathbb{N}^*)$ 又 $a_{n+1} - a_n = -2$ 为常数，所以数列 $\{a_n\}$ 是首项为 $a_1 = 99$ ，公差 $d = -2$ 的等差数列。（2）令 $a_n = 101 - 2n \geqslant 0$ ，得 $n \leqslant 50.5$ 因为 $n \in \mathbb{N}^*$ ，所以 $n \leqslant 50 (n \in \mathbb{N}^*)$ 。
> > - **①**：当 $1 \leqslant n \leqslant 50$ 时， $a_n > 0$ ，此时 $b_n = |a_n| = a_n$ ，所以 $\{b_n\}$ 的前 $n$ 项和 $S_n' = 100n - n^2$ 。
> > - **②**：当 $n \geqslant 51$ 时， $a_n < 0$ ，此时 $b_n = |a_n| = -a_n$ 。由于 $b_{51} + b_{52} + \dots + b_n = -(a_{51} + a_{52} + \dots + a_n) = -(S_n - S_{50}) = S_{50} - S_n$ ，所以数列 $\{b_n\}$ 的前 $n$ 项和 $S_n' = S_{50} + (S_{50} - S_n) = 2S_{50} - S_n$
> > $= 2\times 2500 - (100n - n^2) = 5000 - 100n + n^2.$ 由①②得数列 $\{b_n\}$ 的前 $n$ 项和 $S_{n}^{\prime} = \left\{ \begin{array}{l}100n - n^{2},\qquad 1\leqslant n\leqslant 50,\\ 5000 - 100n + n^{2},n\geqslant 51. \end{array} \right.$ 18.解答（1）由于 $2S_{n} - na_{n} = 3n$ ①，当 $n\geqslant 2$ 时， $2S_{n - 1} - (n - 1)a_{n - 1} = 3(n - 1)$ ②，①一②得 $(n - 1)a_{n - 1} - (n - 2)a_n = 3.$ 当 $n\geqslant 3$ 时， $(n - 2)a_{n - 2} - (n - 3)a_{n - 1} = 3,$ 所以 $(n - 1)a_{n - 1} - (n - 2)a_n = (n - 2)a_{n - 2} -$ $(n - 3)a_{n - 1}$ 整理得 $2a_{n - 1} = a_n + a_{n - 2}(n\geqslant 3)$ 所以 $\{a_{n}\}$ 为等差数列.因为 $2S_{1} - a_{1} = 3$ ，所以 $a_1 = 3.$ 又 $a_2 = 5$ ，所以 $a_2 - a_1 = 2$ 所以 $a_{n} = 2n + 1(n\in \mathbb{N}^{*})$ （2）由(1)可得 $b_{n} = \frac{1}{a_{n}\sqrt{a_{n + 1}} + a_{n + 1}\sqrt{a_{n}}}\\ = \frac{1}{\sqrt{a_n}\sqrt{a_{n + 1}}(\sqrt{a_n} +\sqrt{a_{n + 1}})}\\ = \frac{1}{\sqrt{2n + 1}\sqrt{2n + 3}(\sqrt{2n + 1} +\sqrt{2n + 3})}\\ = \frac{\sqrt{2n + 3} - \sqrt{2n + 1}}{2\sqrt{2n + 1}\sqrt{2n + 3}}\\ = \frac{1}{2}\Big(\frac{1}{\sqrt{2n + 1}} -\frac{1}{\sqrt{2n + 3}}\Big),$ 所以 $T_{n} = \frac{1}{2}\Big(\frac{1}{\sqrt{3}} -\frac{1}{\sqrt{5}} +\frac{1}{\sqrt{5}} -\frac{1}{\sqrt{7}} +\dots +\frac{1}{\sqrt{2n + 1}}-$ $\frac{1}{\sqrt{2n + 3}}\Big) = \frac{1}{2}\Big(\frac{1}{\sqrt{3}} -\frac{1}{\sqrt{2n + 3}}\Big).$ 要使 $T_{n} > \frac{\sqrt{3}}{10}$ ，只需 $\frac{1}{2}\Big(\frac{1}{\sqrt{3}} -\frac{1}{\sqrt{2n + 3}}\Big) > \frac{\sqrt{3}}{10},$ 解得 $n > \frac{63}{8}$ 又 $n\in \mathbb{N}^*$ ，所以 $n$ 的最小值为8.
