> [!faq]- 《高中数学新体系·数列的秘密》参考答案
>
> > [!success]- **【答案】** C
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > 解答 由 $a_{i+m} = a_i$ 知，序列 $a_i$ 的周期为 $m$ ，由已知， $m = 5, C(k) = \frac{1}{5} \sum_{i=1}^{5} a_i a_{i+k}, k = 1, 2, 3, 4.$ 对于选项 A， $C(1) = \frac{1}{5} \sum_{i=1}^{5} a_i a_{i+1} = \frac{1}{5} (a_1 a_2 + a_2 a_3 + a_3 a_4 + a_4 a_5 + a_5 a_6) = \frac{1}{5} (1 + 0 + 0 + 0 + 0) = \frac{1}{5} \leqslant \frac{1}{5},$ $C(2) = \frac{1}{5} \sum_{i=1}^{5} a_i a_{i+2} = \frac{1}{5} (a_1 a_3 + a_2 a_4 + a_3 a_5 + a_4 a_6 + a_5 a_7) = \frac{1}{5} (0 + 1 + 0 + 1 + 0) = \frac{2}{5}$ ，不满足.
> > 对于选项 B， $C(1) = \frac{1}{5} \sum_{i=1}^{5} a_i a_{i+1} = \frac{1}{5} (a_1 a_2 + a_2 a_3 + a_3 a_4 + a_4 a_5 + a_5 a_6) = \frac{1}{5} (1 + 0 + 0 + 1 + 1) = \frac{3}{5}$ ，不满足.
> > 对于选项 D， $C(1) = \frac{1}{5} \sum_{i=1}^{5} a_i a_{i+1} = \frac{1}{5} (a_1 a_2 + a_2 a_3 + a_3 a_4 + a_4 a_5 + a_5 a_6) = \frac{1}{5} (1 + 0 + 0 + 0 + 1) = \frac{2}{5}$ ，不满足.
> >
> > 故选 **C**.
