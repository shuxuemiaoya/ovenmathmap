【思考题55】已知 $f(x) = \frac{x^2 + 2x}{2} + \ln (x + 1)$ ，设 $g(x) = bx + \frac{c}{x}$ ，其中 $b \leqslant 2, c > 0, f(x) = g(x)$ 的两个根为 $x_1, x_2 (x_1 < x_2)$ ，证明： $x_2 f(x_1) < x_1 f(x_2) < 0$ 。
