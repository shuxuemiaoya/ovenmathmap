> > [!note]- **【解析】**
> > 【思考题76】解答 当 $0 < x < \frac{\pi}{6}$ 时， $\frac{3}{\pi} x < \sin x < x.$ 当 $n = 1$ 时，不符合题意；当 $2 \leqslant n \leqslant 9$ 时， $\sin \frac{\pi}{n} \geqslant \sin \frac{\pi}{9} > \frac{3}{\pi} \cdot \frac{\pi}{9} = \frac{1}{3}$ ，不符合题意；当 $n \geqslant 13$ 时， $\sin \frac{\pi}{n} < \sin \frac{\pi}{13} < \frac{\pi}{13} < \frac{1}{4}$ ，不符合题意。又 $\frac{1}{4} < \sin \frac{\pi}{12} < \sin \frac{\pi}{11} < \sin \frac{\pi}{10} < \frac{\pi}{10} < \frac{1}{3}$ ，因此正整数 $n = 10, 11, 12$ ，和为33.
> > 注 本题为2012年全国高中数学联赛题(7).
