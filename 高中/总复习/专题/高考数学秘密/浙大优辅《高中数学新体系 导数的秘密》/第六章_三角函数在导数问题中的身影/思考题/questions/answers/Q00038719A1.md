> > 【思考题60】解答 构造函数 $f(x) = \sin x + \tan x - 2x$ ，其中 $0 < x < \frac{\pi}{2}$ ，则 $f'(x) = \cos x + \frac{1}{\cos^2 x} - 2 > \cos^2 x + \frac{1}{\cos^2 x} - 2 > 2\sqrt{\cos^2 x \cdot \frac{1}{\cos^2 x}} - 2 = 0$ ，所以 $f(x)$ 单调递增，从而 $f(x) > f(0) = 0$ 。sin $A + \sin B + \sin C + \tan A + \tan B + \tan C > 2(A + B + C) = 2\pi$ 。
