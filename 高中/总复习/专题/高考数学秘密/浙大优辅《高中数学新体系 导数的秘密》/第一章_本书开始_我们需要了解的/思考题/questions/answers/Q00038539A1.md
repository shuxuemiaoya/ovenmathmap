> > [!note]- **【解析】**
> > 【思考题11】解答 $\frac{x}{a^3x^2 + a^2} +\frac{a}{a^2x^3 + x^2} +$ $\frac{a^3x^3}{a + x} = \frac{x^2}{a^3x^3 + a^2x} +\frac{a^2}{a^3x^3 + ax^2} +\frac{a^4x^4}{ax(a + x)}$ $\geqslant \frac{(x + a + a^2x^2)^2}{a^3x^3 + a^2x + a^3x^3 + ax^2 + ax(a + x)}$ $= \frac{(x + a + a^2x^2)^2}{2ax(x + a + a^2x^2)} = \frac{x + a + a^2x^2}{2ax}$ $= \frac{1}{2}\left(\frac{1}{x} +\frac{1}{a} +ax\right)$ $\geqslant \frac{1}{2}\times 3\sqrt[3]{\frac{1}{x}\times\frac{1}{a}\times ax} = \frac{3}{2}.$
