> > 【思考题3】解答当 $x = 1$ 时，原不等式成立.当 $0 <   x <   1$ 时，由于 $\mathrm{e}^x <   \frac{1}{1 - x},\ln x <   x - 1,$ 则有 $x\ln x <   x(x - 1),$ 即 $x^{x} <   \mathrm{e}^{x(x - 1)} <   \frac{1}{1 - x(x - 1)},$ 所以 $x^{x} - 1 - x\mathrm{e}^{x - 1}(x - 1) <   \frac{1}{1 - x(x - 1)} -1-$ $\frac{x(x - 1)}{2 - x} = \frac{x(x - 1)^3}{(2 - x)(1 + x - x^2)} < 0.$
