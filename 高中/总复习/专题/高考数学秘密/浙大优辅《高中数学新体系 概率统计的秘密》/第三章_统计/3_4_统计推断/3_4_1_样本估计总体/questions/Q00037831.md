例题1（多选题）有一组样本数据 $x_{1}, x_{2}, \cdots, x_{n}$ ，由这组数据得到新样本数据 $y_{1}, y_{2}, \cdots, y_{n}$ ，其中 $y_{i} = x_{i} + c (i = 1, 2, \cdots, n), c$ 为非零常数，则（ ）.

A. 两组样本数据的样本平均数相同 B. 两组样本数据的样本中位数相同 C. 两组样本数据的样本标准差相同 D. 两组样本数据的样本极差相同
【分析】本题主要研究数据的影响因素,其中样本平均数和中位数,它们是描述中心位置的量,显然平移 c 后发生变化了,而标准差和极差是描述离散程度的量,这个是没有变化的.
【解析】由平均数、中位数、标准差、极差的计算公式,容易得出新样本数据的平均数和中位数均改变了 c,而标准差和极差保持不变.
综上,答案选 CD.
【探求】不仅要会运用数字特征的计算公式计算其值,更重要的是对其含义或者说实际意义要真正理解.
