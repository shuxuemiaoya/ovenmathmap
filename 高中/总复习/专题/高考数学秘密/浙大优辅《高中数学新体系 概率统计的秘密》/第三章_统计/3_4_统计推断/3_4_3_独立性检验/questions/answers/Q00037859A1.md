> [!faq]- 《高中数学新体系·概率统计的秘密》例题解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > (I)设求职者在甲、乙公司的聘用月薪分别为 $X, Y$ , 则
> > $$
> > E (X) = 6 0 0 0 \times 0. 4 + 7 0 0 0 \times 0. 3 + 8 0 0 0 \times 0. 2 + 9 0 0 0 \times 0. 1 = 7 0 0 0,
> > $$
> > $$
> > E (Y) = 5 0 0 0 \times 0. 4 + 7 0 0 0 \times 0. 3 + 9 0 0 0 \times 0. 2 + 1 1 0 0 0 \times 0. 1 = 7 0 0 0.
> > $$
> > $$
> > \begin{array}{r l} D (X) & = (6 0 0 0 - 7 0 0 0) ^ {2} \times 0. 4 + (7 0 0 0 - 7 0 0 0) ^ {2} \times 0. 3 + (8 0 0 0 - 7 0 0 0) ^ {2} \times 0. 2 + \\ & (9 0 0 0 - 7 0 0 0) ^ {2} \times 0. 1 = 1 0 ^ {6}, \end{array}
> > $$
> > $$
> > \begin{array}{r l} D (Y) & = (5 0 0 0 - 7 0 0 0) ^ {2} \times 0. 4 + (7 0 0 0 - 7 0 0 0) ^ {2} \times 0. 3 + (9 0 0 0 - 7 0 0 0) ^ {2} \times 0. 2 + \\ & (1 1 0 0 0 - 7 0 0 0) ^ {2} \times 0. 1 = 4 \times 1 0 ^ {6}. \end{array}
> > $$
> > 因为 $E(X) = E(Y), D(X) < D(Y)$ , 所以甲、乙两公司的平均待遇相同, 但受聘于甲公司后待遇会比较稳定, 如果我是求职者的话, 会选择甲公司.
> > (Ⅱ)列出关于选择意愿与性别变量的 $2 \times 2$ 列联表如下.
> > <table><tr><td>选择的公司</td><td>男</td><td>女</td><td>总计</td></tr><tr><td>甲公司</td><td>250</td><td>200</td><td>450</td></tr><tr><td>乙公司</td><td>350</td><td>200</td><td>550</td></tr><tr><td>总计</td><td>600</td><td>400</td><td>1000</td></tr></table>
> > 所以 $K^{2}=\frac{1000(250\times200-200\times350)^{2}}{450\times550\times600\times400}\approx6.7$ ，即选择意愿与性别变量的 $K^{2}$ 的观测值为 $k_{1}\approx5.5513,k_{2}\approx6.7$ 。它们相应的犯错率 0.01<0.025，故选择意愿与年龄变量相比，选择意愿与性别变量的关联性更大。（或由于 $k_{1}<k_{2}$ ，故选择意愿与年龄变量相比，选择意愿与性别变量的关联性更大）。
> > 【探讨】本题的背景是求职意愿的选择及意愿关联变量的关系分析. 第(Ⅰ)问设计了面对月薪平均水平相同, 方差不同的两家公司, 求职者的抉择问题, 并尝试设置了开放性的答案, 即不同的人可有不同的选择, 但要说明选择的理由, 知识上考查了概率分布列的期望与方差的计算. 第(Ⅱ)问设计的问题是量化分析选择意愿与年龄变量或性别变量的关联性, 尝试分析做出不同选择的可能原因, 考查独立性检验. 为了减少计算量, 给出了选择意愿与年龄变量的卡方观测值, 只需建立选择意愿与性别变量的 $2 \times 2$ 列联表与卡方观测值, 再做比较. 本题涉及的重要概念有概率分布列的期望与方差、 $2 \times 2$ 列联表、独立性检验、比较决策.
