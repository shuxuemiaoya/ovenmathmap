> [!faq]- 《高中数学新体系·概率统计的秘密》参考答案
>
> > [!success]- **【答案】** 题1-3
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > 设事件 $A =$ “机器可运行时间不少于3个月”，从6个部件 $S$ 中任取2个，设事件 $B_{1} =$ “取到2个一等品”， $B_{2} =$ “取到1个一等品和1个二等品”， $B_{3} =$ “取到2个二等品”， $P(A) = P(B_1A + B_2A + B_3A) = P(B_1A) + P(B_2A) + P(B_3A) = P(A|B_1)P(B_1) + P(A|B_2)\cdot P(B_2) + P(A|B_3)P(B_3).\\ \text{其中} P(B_{1}) = \frac{\mathrm{C}_{4}^{2}}{\mathrm{C}_{6}^{2}} = \frac{2}{5},P(B_{2}) = \frac{\mathrm{C}_{4}^{1}\mathrm{C}_{2}^{1}}{\mathrm{C}_{6}^{2}} = \frac{8}{15},\\ P(B_{3}) = \frac{\mathrm{C}_{2}^{2}}{\mathrm{C}_{6}^{2}} = \frac{1}{15},P(A|B_{1}) = 1,P(A|B_{2}) = \frac{1}{2},\\ P(A|B_{3}) = \frac{1}{2}\times \frac{1}{2} = \frac{1}{4},\\ \text{则} P(A) = \frac{2}{5} +\frac{8}{15}\times \frac{1}{2} +\frac{1}{15}\times \frac{1}{4} = \frac{41}{60}.$
> > 【探讨】整个试验可分为两个环节,首先是从6个部件中选取2个,会有三种情况,“取到2个一等品”“取到1个一等品和1个二等品”“取到2个二等品”;其次是求不同的随机事件下部件的使用寿命了,全概率公式的运用顺理成章.
