> > 题 1-3 【解析】根据字母 C 的位置分成六类, 又根据对称性, 最终可以分成三大类.
> > 第一大类, 字母 C 排在左边第一个位置, 有 $A_{5}^{5}$ 种;
> > 第二大类, 字母 C 排在左边第二个位置, 有 $A_{4}^{2}A_{3}^{3}$ 种;
> > 第三大类, 字母 C 排在左边第三个位置, 有 $A_{2}^{2}A_{3}^{3} + A_{3}^{2}A_{3}^{3}$ 种.
> > 由对称性可知, 共有 $2 \times (A_{5}^{5} + A_{4}^{2}A_{3}^{3} + A_{2}^{2}A_{3}^{3} + A_{3}^{2}A_{3}^{3}) = 480$ 种.
> > 故答案选A.
