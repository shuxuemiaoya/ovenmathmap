> [!faq]- 《高中数学新体系·概率统计的秘密》参考答案
>
> > [!success]- **【答案】** 题 3-1
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > 由 $6^{2021} + n = (5 + 1)^{2021} + n = 5^{2021} + C_{2021}^{1} 5^{2020} + \cdots + C_{2021}^{2020} 5 + 1 + n$ ,
> > 其中 $C_{2021}^{0}5^{2021} + C_{2021}^{1}5^{2020} + \cdots + C_{2021}^{2020}5$ 能被 5 整除，
> > 要满足 $6^{2021} + n$ 能被 5 整除, 只需 $1 + n$ 能被 5 整除, 所以 n = 4.
> > 故答案为 4.
