题 1-1 【解析】每月的 AQI 指数平均值都不超过 100, 故全年的平均 AQI 指数也不超过 100, 对应的空气质量为优或良, 选项 A 正确;

每月的 AQI 指数最小值均不超过 50, 故每月都至少有一天空气质量为优, 选项 B 正确;

2月、8月、9月和12月的AQI指数最大值均大于100，故至少有一天出现了污染天气，选项C正确；

2月、8月、9月、12月中空气质量为污染的天数不确定，选项D不一定正确.

综上,答案选 ABC.

【探讨】2月份的空气质量指数最大值在一年中最大,并不意味着污染的天数最多,可见依然是属于不考虑数据的定义和单位,单纯的比较数据值的大小的命题方法.

题 2-2 【解析】因为 2019 年居民人均消费总支出比 2018 年居民人均消费总支出提高 8.5%，所以 2019 年居民人均消费总支出为 $(7000 + 4600 + 2300 + 1700 + 4400) \times 1.085 = 20000 \times 1.085 = 21700$ 元，2019 年的人均衣食支出金额为 $21700 \times 34.5\% = 7486.5$ 元，所以 2019 年的人均衣食支出金额比 2018 年的人均衣食支出金额高，选项 A 正确；

2019年除医疗以外的人均消费支出金额为 $21700 \times (1 - 8.5\%) = 19855.5$ 元, 2018年的人均消费总支出金额为20000元, 2019年除医疗以外的人均消费支出金额不等于2018年的人均消费总支出金额, 选项B错误;

2019 年的人均文教支出比例为 12.0%, 2018 年的人均文教支出比例为 $\frac{2300}{20000} \times 100\% = 11.5\%$ , 2019 年的人均文教支出比例比 2018 年的人均文教支出比例有所提高, 选项 C 正确;

2018 其他支出 4400 元, 2019 年其他支出 $21700 \times 21.0\% = 4557$ 元, “其他”消费支出的年增长率为 $\frac{4557 - 4400}{4400} \times 100\% \approx 3.6\%$ ，衣食支出的年增长率为 $\frac{21700 \times 34.5\% - 7000}{7000} \times 100\% = 6.95\%$ ，“住”支出的年增长率为 $\frac{21700 \times 24.0\% - 4600}{4600} \times 100\% \approx 13.22\%$ ，文教支出的年增长率为 $\frac{21700 \times 12.0\% - 2300}{2300} \times 100\% \approx 13.22\%$ ，医疗支出的年增长率为 $\frac{21700 \times 8.5\% - 1700}{1700} \times 100\% = 8.5\%$ ，则“其他”消费支出的年增长率最低，选项D正确。

综上,答案选 ACD.

【探讨】本题主要围绕着计算展开,比较的式子较多,需要考生耐心准确计算.考查的是运算求解能力和批判性思维.

题 2-3 【解析】由不同群体中倾向选择生育二胎与倾向选择不生育二胎的人数比例图知,城镇户籍倾向选择生育二胎的比例为 40%,农村户籍倾向选择生育二胎的比例为 80%,所以是否倾向选择生育二胎与户籍有关,选项 A 正确;

男性倾向选择生育二胎的比例为 60%, 女性倾向选择生育二胎的比例为 60%, 所以是否倾向选择生育二胎与性别无关, 选项 B 正确;

男性倾向选择生育二胎的比例为 60%, 人数为 $60 \times 60\% = 36$ 人, 女性倾向选择生育二胎的比例为 60%, 人数为 $40 \times 60\% = 24$ 人, 所以倾向选择生育二胎的人员中, 男性人数比女性人数多, 选项 C 错误;

倾向选择不生育二胎的人员中,农村户籍人数为 $50 \times (1 - 80\%) = 10$ 人,城镇户籍人数为 $50 \times (1 - 40\%) = 30$ 人,所以倾向选择不生育二胎的人员中,农村户籍人数少于城镇户籍人数,选项 D 正确.

综上,答案选 C.

【探讨】本题中男女倾向选择生育二胎的比例相同,但由于男女样本人数不同,因此倾向选择生育二胎的人数自然也不同。
