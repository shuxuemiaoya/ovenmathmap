4. 解答 根据平面向量基本定理, 将 $\overrightarrow{AP}$ 分解为 $\overrightarrow{AB}, \overrightarrow{AD}$ 分量.

$\overrightarrow{AP} = \lambda \overrightarrow{AB} + (1 - \lambda)\overrightarrow{AC}$ $= \lambda \overrightarrow{AB} + (1 - \lambda)\left(\overrightarrow{AD} + \frac{\overrightarrow{AB}}{4}\right)$ $= \left(\frac{1 + 3\lambda}{4}\right)\overrightarrow{AB} + (1 - \lambda)\overrightarrow{AD}.$ 故 $m = \frac{1 + 3\lambda}{4}, n = 1 - \lambda$ ，即 $m + \frac{3n}{4} = 1$ 故 $\frac{1}{m} + \frac{1}{n} = \left(\frac{1}{m} + \frac{1}{n}\right)\left(m + \frac{3n}{4}\right) \geqslant \frac{7}{4} + \sqrt{3}.$ 当且仅当 $3n^2 = 4m^2$ 时，等号成立. $\frac{1}{m} + \frac{1}{n}$ 的最小值为 $\frac{7}{4} + \sqrt{3}$ .
