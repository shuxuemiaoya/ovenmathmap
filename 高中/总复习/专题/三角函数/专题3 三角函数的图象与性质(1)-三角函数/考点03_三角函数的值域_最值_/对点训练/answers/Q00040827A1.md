> [!faq]- 《专题3 三角函数的图象与性质(1)-三角函数》例题解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【解析】**
> > 答案 $[0, +\infty)$ 解析 $f(x) = \cos (2x + \theta)\left[0 \leq \theta \leq \frac{\pi}{2}\right]$ ，当 $x \in \left[-\frac{3\pi}{8}, -\frac{\pi}{6}\right]$ 时， $-\frac{3\pi}{4} + \theta \leq 2x + \theta \leq -\frac{\pi}{3} + \theta$ ，由函数 $f(x)$ 在 $\left[-\frac{3\pi}{8}, -\frac{\pi}{6}\right]$ 上是增函数得 $\left\{ \begin{array}{l} -\pi + 2k\pi \leq -\frac{3\pi}{4} + \theta, \\ -\frac{\pi}{3} + \theta \leq 2k\pi, \end{array} \right.$ $k \in \mathbf{Z}$ ，则 $2k\pi - \frac{\pi}{4} \leq \theta \leq 2k\pi + \frac{\pi}{3}(k \in \mathbf{Z})$ 。又 $0 \leq \theta \leq \frac{\pi}{2}, \therefore 0 \leq \theta \leq \frac{\pi}{3}, \because f\left(\frac{\pi}{4}\right) = \cos\left(\frac{\pi}{2} + \theta\right)$ ，又 $\frac{\pi}{2} \leq \theta + \frac{\pi}{2} \leq \frac{5\pi}{6}, \therefore f\left(\frac{\pi}{4}\right)_{\max} = 0, \therefore m \geq 0.$
