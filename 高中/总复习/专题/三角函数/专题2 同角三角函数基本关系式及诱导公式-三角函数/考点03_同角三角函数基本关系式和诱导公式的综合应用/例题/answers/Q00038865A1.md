> > (2) 已知 $x \in \left(\frac{\pi}{2}, \pi\right)$ , $\tan x = -\frac{4}{3}$ , 则 $\cos \left(-x - \frac{\pi}{2}\right)$ 等于 ( ) A. $\frac{3}{5}$ B. $-\frac{3}{5}$ C. $-\frac{4}{5}$ D. $\frac{4}{5}$
> > 答案 C 解析 $\because \tan x=\frac{\sin x}{\cos x}=-\frac{4}{3},\therefore \cos x=-\frac{3}{4}\sin x,\therefore \sin^{2}x+\cos^{2}x=\sin^{2}x+\frac{9}{16}\sin^{2}x=\frac{25}{16}\sin^{2}x=1,$
> > $\therefore \sin^2 x = \frac{16}{25}$ . 又 $x \in \left[\frac{\pi}{2}, \pi\right]$ , $\therefore \sin x = \frac{4}{5}$ , $\therefore \cos \left[-x - \frac{\pi}{2}\right] = \cos \left(\frac{\pi}{2} + x\right) = -\sin x = -\frac{4}{5}$ .
> > (3) (2016·全国I)已知 $\theta$ 是第四象限角，且 $\sin \left(\theta + \frac{\pi}{4}\right) = \frac{3}{5}$ ，则 $\tan \left(\theta - \frac{\pi}{4}\right) = \underline{\quad}$ .
> > 答案 $-\frac{4}{3}$ 解析 由题意知 $\sin \left(\theta +\frac{\pi}{4}\right) = \frac{3}{5},$ $\theta$ 是第四象限角，所以 $\cos \left(\theta +\frac{\pi}{4}\right) > 0$ ，所以 $\cos \left(\theta +\frac{\pi}{4}\right) =$ $\sqrt{1 - \sin^2\left(\theta + \frac{\pi}{4}\right)} = \frac{4}{5}.$ 则 $\tan \left(\theta -\frac{\pi}{4}\right) = \tan \left(\theta +\frac{\pi}{4} -\frac{\pi}{2}\right) = -\frac{\sin\left[\frac{\pi}{2} -\left(\theta + \frac{\pi}{4}\right)\right]}{\cos\left[\frac{\pi}{2} -\left(\theta + \frac{\pi}{4}\right)\right]} = -\frac{\cos\left(\theta + \frac{\pi}{4}\right)}{\sin\left(\theta + \frac{\pi}{4}\right)} = -\frac{4}{5}\times \frac{5}{3} = -\frac{4}{3}.$
> > (4) 已知 $\sin \alpha + \cos \alpha = -\frac{1}{5}$ , 且 $\frac{\pi}{2} < \alpha < \pi$ , 则 $\frac{1}{\sin (\pi - \alpha)} + \frac{1}{\cos (\pi - \alpha)}$ 的值为 \_\_\_\_.
> > 答案 $\frac{35}{12}$ 解析 由 $\sin \alpha + \cos \alpha = -\frac{1}{5}$ 平方得 $\sin \alpha \cos \alpha = -\frac{12}{25}$ , $\because \frac{\pi}{2} < \alpha < \pi$ , $\therefore \sin \alpha - \cos \alpha =$
> > $\sqrt{(\sin \alpha + \cos \alpha)^2 - 4\sin \alpha \cos \alpha} = \frac{7}{5}, \therefore \frac{1}{\sin (\pi - \alpha)} + \frac{1}{\cos (\pi - \alpha)} = \frac{1}{\sin \alpha} - \frac{1}{\cos \alpha} = \frac{\cos \alpha - \sin \alpha}{\sin \alpha \cos \alpha} = \frac{-\frac{7}{5}}{-\frac{12}{25}} = \frac{35}{12}.$
> > (5) 已知 $\tan(\pi-\alpha)=-\frac{2}{3}$ ，且 $\alpha\in\left(-\pi,-\frac{\pi}{2}\right)$ ，则 $\frac{\cos(-\alpha)+3\sin(\pi+\alpha)}{\cos(\pi-\alpha)+9\sin\alpha}=()$ A. $-\frac{1}{5}$ B. $-\frac{3}{7}$ C. $\frac{1}{5}$ D. $\frac{3}{7}$
> > 答案 解析 由 $\tan (\pi -\alpha) = -\frac{2}{3}$ ，得 $\tan \alpha = \frac{2}{3}.\frac{\cos(-\alpha) + 3\sin(\pi + \alpha)}{\cos(\pi - \alpha) + 9\sin\alpha} = \frac{\cos\alpha - 3\sin\alpha}{-\cos\alpha + 9\sin\alpha} = \frac{1 - 3\tan\alpha}{-1 + 9\tan\alpha} =$ $\frac{1 - 2}{-1 + 6} = -\frac{1}{5}$ 故选A.
> > (6)已知角 $\theta$ 的终边在第三象限， $\tan 2\theta = -2\sqrt{2}$ ，则 $\sin^2\theta + \sin (3\pi - \theta)\cos (2\pi + \theta) - \sqrt{2}\cos^2\theta$ 等于（ A. $-\frac{\sqrt{2}}{6}$ B. $\frac{\sqrt{2}}{6}$ C. $-\frac{2}{3}$ D. $\frac{2}{3}$
> > 答案 D 解析 由 $\tan 2\theta = -2\sqrt{2}$ 可得 $\tan 2\theta = \frac{2\tan\theta}{1 - \tan^2\theta} = -2\sqrt{2}$ ，即 $\sqrt{2}\tan^2\theta - \tan \theta - \sqrt{2} = 0$ ，解得 $\tan \theta = \sqrt{2}$ 或 $\tan \theta = -\frac{\sqrt{2}}{2}$ 。又角 $\theta$ 的终边在第三象限，故 $\tan \theta = \sqrt{2}$ ，故 $\sin^2\theta + \sin (3\pi - \theta)\cos (2\pi + \theta) - \sqrt{2}\cos^2\theta = \sin^2\theta + \sin \theta\cos \theta - \sqrt{2}\cos^2\theta = \frac{\sin^2\theta + \sin \theta\cos \theta - \sqrt{2}\cos^2\theta}{\sin^2\theta + \cos^2\theta} = \frac{\tan^2\theta + \tan \theta - \sqrt{2}}{\tan^2\theta + 1} = \frac{(\sqrt{2})^2 + \sqrt{2} - \sqrt{2}}{(\sqrt{2})^2 + 1} = \frac{2}{3}$ .
