> [!faq]- 《专题2 同角三角函数基本关系式及诱导公式-三角函数》例题解析
>
> > [!success]- **【答案】** D
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > 答案 D 解析 由 $\tan 2\theta = -2\sqrt{2}$ 可得 $\tan 2\theta = \frac{2\tan\theta}{1 - \tan^2\theta} = -2\sqrt{2}$ ，即 $\sqrt{2}\tan^2\theta - \tan \theta - \sqrt{2} = 0$ ，解得 $\tan \theta = \sqrt{2}$ 或 $\tan \theta = -\frac{\sqrt{2}}{2}$ 。又角 $\theta$ 的终边在第三象限，故 $\tan \theta = \sqrt{2}$ ，故 $\sin^2\theta + \sin (3\pi - \theta)\cos (2\pi + \theta) - \sqrt{2}\cos^2\theta = \sin^2\theta + \sin \theta\cos \theta - \sqrt{2}\cos^2\theta = \frac{\sin^2\theta + \sin \theta\cos \theta - \sqrt{2}\cos^2\theta}{\sin^2\theta + \cos^2\theta} = \frac{\tan^2\theta + \tan \theta - \sqrt{2}}{\tan^2\theta + 1} = \frac{(\sqrt{2})^2 + \sqrt{2} - \sqrt{2}}{(\sqrt{2})^2 + 1} = \frac{2}{3}$ .
