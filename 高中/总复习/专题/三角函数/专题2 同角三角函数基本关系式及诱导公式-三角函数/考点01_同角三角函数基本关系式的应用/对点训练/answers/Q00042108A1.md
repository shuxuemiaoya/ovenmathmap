> [!faq]- 《专题2 同角三角函数基本关系式及诱导公式-三角函数》例题解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > 解
> > (1)由 $\sin x + \cos x = \frac{1}{5}$ , 平方得 $\sin^2 x + 2\sin x\cos x + \cos^2 x = \frac{1}{25}$ , 整理得 $2\sin x\cos x = -\frac{24}{25}$ . $\therefore (\sin x - \cos x)^2 = 1 - 2\sin x\cos x = \frac{49}{25}$ . 由 $x \in (-\pi, 0)$ , 知 $\sin x < 0$ , 又 $\sin x + \cos x > 0$ ,
> > $\therefore \cos x > 0$ ，则 $\sin x - \cos x <   0$ ，故 $\sin x - \cos x = -\frac{7}{5}.$
> > $$
> > \frac {\sin 2 x + 2 \sin^ {2} x}{1 - \tan x} = \frac {2 \sin x (\cos x + \sin x)}{1 - \frac {\sin x}{\cos x}} = \frac {2 \sin x \cos x (\cos x + \sin x)}{\cos x - \sin x} = \frac {- \frac {2 4}{2 5} \times \frac {1}{5}}{\frac {7}{5}} = - \frac {2 4}{1 7 5}. \tag {2}
> > $$
