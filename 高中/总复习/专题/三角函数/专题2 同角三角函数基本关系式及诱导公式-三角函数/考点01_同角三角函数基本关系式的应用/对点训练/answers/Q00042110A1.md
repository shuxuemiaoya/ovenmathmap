> [!faq]- 《专题2 同角三角函数基本关系式及诱导公式-三角函数》例题解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > 解
> > (1) $\frac{\sin \alpha - 4\cos \alpha}{5\sin \alpha + 2\cos \alpha} = \frac{\tan \alpha - 4}{5\tan \alpha + 2} = \frac{-\frac{4}{3} - 4}{5 \times \left(-\frac{4}{3}\right) + 2} = \frac{8}{7}$ .
> >
> > $$
> > (2) \frac {1}{\cos^ {2} \alpha - \sin^ {2} \alpha} = \frac {\sin^ {2} \alpha + \cos^ {2} \alpha}{\cos^ {2} \alpha - \sin^ {2} \alpha} = \frac {\frac {\sin^ {2} \alpha + \cos^ {2} \alpha}{\cos^ {2} \alpha}}{\frac {\cos^ {2} \alpha - \sin^ {2} \alpha}{\cos^ {2} \alpha}} = \frac {\tan^ {2} \alpha + 1}{1 - \tan^ {2} \alpha} = \frac {\left(- \frac {4}{3}\right) ^ {2} + 1}{1 - \left(- \frac {4}{3}\right) ^ {2}} = - \frac {2 5}{7}.
> > $$
> >
> > $$
> > (3) \sin^ {2} \alpha + 2 \sin \alpha \cos \alpha = \frac {\sin^ {2} \alpha + 2 \sin \alpha \cos \alpha}{\sin^ {2} \alpha + \cos^ {2} \alpha} = \frac {\tan^ {2} \alpha + 2 \tan \alpha}{\tan^ {2} \alpha + 1} = \frac {\frac {1 6}{9} - \frac {8}{3}}{\frac {1 6}{9} + 1} = - \frac {8}{2 5}.
> > $$
