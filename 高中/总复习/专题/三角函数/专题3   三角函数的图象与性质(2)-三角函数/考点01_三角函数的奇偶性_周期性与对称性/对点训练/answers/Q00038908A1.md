> [!faq]- 《专题3   三角函数的图象与性质(2)-三角函数》例题解析
>
> > [!success]- **【答案】** D
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > 答案 D 解析 根据函数解析式可知函数 $f(x)$ 的最小正周期为 $2\pi$ ，所以函数的一个周期为 $-2\pi$ ，A 正确；当 $x = \frac{8\pi}{3}$ 时， $x + \frac{\pi}{3} = 3\pi$ ，所以 $\cos \left( x + \frac{\pi}{3} \right) = -1$ ，所以 B 正确； $f(x + \pi) = \cos \left( x + \pi + \frac{\pi}{3} \right) = \cos \left( x + \frac{4\pi}{3} \right)$ ，当 $x = \frac{\pi}{6}$ 时， $x + \frac{4\pi}{3} = \frac{3\pi}{2}$ ，所以 $f(x + \pi) = 0$ ，所以 C 正确；函数 $f(x) = \cos \left( x + \frac{\pi}{3} \right)$ 在 $\left( \frac{\pi}{2}, \frac{2\pi}{3} \right)$ 上单调递减，
> > 在 $\left(\frac{2\pi}{3},\pi\right)$ 上单调递增，故D不正确.
