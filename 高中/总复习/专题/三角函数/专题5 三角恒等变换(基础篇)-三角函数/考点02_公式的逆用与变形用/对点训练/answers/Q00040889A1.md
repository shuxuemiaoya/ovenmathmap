> [!faq]- 《专题5 三角恒等变换(基础篇)-三角函数》例题解析
>
> > [!success]- **【答案】** C
>
> > [!note]- **【解析】**
> > 答案 C 解析 原式 $= -\sin (180^{\circ} - 13^{\circ})\sin (180^{\circ} + 43^{\circ}) + \sin (180^{\circ} + 77^{\circ})\cdot \sin (360^{\circ} - 47^{\circ}) = \sin 13^{\circ}\sin 43^{\circ}$ $+\sin 77^{\circ}\sin 47^{\circ} = \sin 13^{\circ}\sin 43^{\circ} + \cos 13^{\circ}\cos 43^{\circ} = \cos (13^{\circ} - 43^{\circ}) = \cos (-30^{\circ}) = \frac{\sqrt{3}}{2}.$
