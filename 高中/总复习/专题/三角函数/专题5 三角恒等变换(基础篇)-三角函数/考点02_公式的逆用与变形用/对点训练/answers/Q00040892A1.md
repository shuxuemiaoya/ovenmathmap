> [!faq]- 《专题5 三角恒等变换(基础篇)-三角函数》例题解析
>
> > [!success]- **【答案】** C
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > 答案 C 解析 $\because A + B + C = \pi, \therefore A = \pi - (B + C)$ , 由已知可得 $\sin(B + C) = 2\sin C\cos B \Rightarrow \sin B\cos C + \cos B\sin C = 2\sin C\cos B \Rightarrow \sin B\cos C - \cos B\sin C = 0 \Rightarrow \sin(B - C) = 0.$ $\because 0 < B < \pi, 0 < C < \pi, \therefore -\pi < B - C < \pi.$ $\therefore B = C$ 故 $\triangle ABC$ 为等腰三角形.
