> [!faq]- 《专题6 三角恒等变换题型篇-三角函数》例题解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【解析】**
> > 答案 $\frac{3\pi}{4}$ 解析 因为 $0 < \alpha < \frac{\pi}{2}, 0 < \beta < \frac{\pi}{2}, \alpha < \beta$ 。所以 $-\frac{\pi}{2} < \alpha - \beta < 0$ 。又 $\cos(\alpha - \beta) = \frac{\sqrt{5}}{5}$ ，所以 $\sin(\alpha - \beta) = -\sqrt{1 - \cos^2(\alpha - \beta)} = -\frac{2\sqrt{5}}{5}$ 。又因为 $0 < 2\alpha < \pi, \cos 2\alpha = \frac{\sqrt{10}}{10}$ ，所以 $\sin 2\alpha = \sqrt{1 - \cos^2 2\alpha} = \frac{3\sqrt{10}}{10}$ ，所以 $\cos (\alpha + \beta) = \cos [2\alpha - (\alpha - \beta)] = \cos 2\alpha \cos (\alpha - \beta) + \sin 2\alpha \sin (\alpha - \beta) = \frac{\sqrt{10}}{10} \times \frac{\sqrt{5}}{5} + \frac{3\sqrt{10}}{10} \times \left[ -\frac{2\sqrt{5}}{5} \right] = -\frac{\sqrt{2}}{2}$ 。又 $0 < \alpha + \beta < \pi$ ，故 $\alpha + \beta = \frac{3\pi}{4}$ 。
