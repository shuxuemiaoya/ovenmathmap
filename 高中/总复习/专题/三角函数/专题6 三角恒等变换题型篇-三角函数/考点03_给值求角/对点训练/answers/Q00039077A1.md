> [!faq]- 《专题6 三角恒等变换题型篇-三角函数》例题解析
>
> > [!success]- **【答案】** A
>
> > [!note]- **【解析】**
> > 答案 A 解析 由题意知 $\left\{ \begin{array}{l} 3\sin A + 4\cos B = 6, \\ 3\cos A + 4\sin B = 1, \end{array} \right.$ ① ① $^{2}$ +② $^{2}$ 得 $9 + 16 + 24\sin (A + B) = 37$ 。则 $\sin (A + B) = \frac{1}{2}$ 。∴在△ABC中， $\sin C = \frac{1}{2}$ ， $\therefore C = \frac{\pi}{6}$ 或 $C = \frac{5\pi}{6}$ 。若 $C = \frac{5\pi}{6}$ ，则 $A + B = \frac{\pi}{6}$ ， $\therefore 1 - 3\cos A = 4\sin B > 0$ 。 $\therefore \cos A < \frac{1}{3}$ 。又 $\frac{1}{3} < \frac{1}{2}$ ， $\therefore A > \frac{\pi}{3}$ 。此时 $A + C > \pi$ ，不符合题意， $\therefore C \neq \frac{5\pi}{6}$ ， $\therefore C = \frac{\pi}{6}$ 。
