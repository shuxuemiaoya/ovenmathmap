> [!faq]- 《专题6 三角恒等变换题型篇-三角函数》例题解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【解析】**
> > 答案 $-\frac{\pi}{4}$ 解析 $\because \alpha, \beta$ 均为锐角， $\therefore \sin \alpha = \frac{\sqrt{5}}{5}, \sin \beta = \frac{3\sqrt{10}}{10}.$ $\therefore \cos (\alpha - \beta) = \cos \alpha \cos \beta + \sin \alpha \sin \beta = \frac{2\sqrt{5}}{5} \times \frac{\sqrt{10}}{10} + \frac{\sqrt{5}}{5} \times \frac{3\sqrt{10}}{10} = \frac{\sqrt{2}}{2}.$ 又 $\sin \alpha < \sin \beta, \therefore 0 < \alpha < \beta < \frac{\pi}{2}, \therefore -\frac{\pi}{2} < \alpha - \beta < 0.$ 故 $\alpha - \beta = -\frac{\pi}{4}.$
