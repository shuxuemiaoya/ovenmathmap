> [!faq]- 《专题5 三角恒等变换(方法篇)-三角函数》例题解析
>
> > [!success]- **【答案】** C
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > 答案 $-\frac{33}{65}$ 解析 $\because \frac{\pi}{2} < \beta < \alpha < \frac{3}{4}\pi, \therefore -\frac{3}{4}\pi < -\beta < -\frac{\pi}{2}.\therefore 0 < \alpha -\beta < \frac{\pi}{4},\pi < \alpha +\beta < \frac{3}{2}\pi .\therefore \sin (\alpha -\beta) =$ $\sqrt{1 - \cos^2(\alpha - \beta)} = \sqrt{1 - \left(\frac{12}{13}\right)^2} = \frac{5}{13},\cos (\alpha +\beta) = -\sqrt{1 - \sin^2(\alpha + \beta)} = -\sqrt{1 - \left(-\frac{3}{5}\right)^2} = -\frac{4}{5}.\therefore \cos 2\alpha = \cos [(a-$ $-\beta +(a + \beta)] = \cos (a - \beta)\cos (a + \beta) - \sin (a - \beta)\sin (a + \beta) = \frac{12}{13}\times \left(-\frac{4}{5}\right) - \frac{5}{13}\times \left(-\frac{3}{5}\right) = -\frac{33}{65},$ 即 $\cos 2\alpha = -\frac{33}{65}.$ (5）已知 $\sin \left[\alpha +\frac{\pi}{4}\right] = \frac{1}{3}$ ，则 $\sin 2\alpha$ 的值为（ ）A. $-\frac{8}{9}$ B. $\frac{8}{9}$ C. $-\frac{7}{9}$ D. $\frac{7}{9}$
> > 答案 C 解析 $\because2\alpha=2\left(\alpha+\frac{\pi}{4}\right)-\frac{\pi}{2},\quad\therefore\sin2\alpha=\sin\left[2\left(\alpha+\frac{\pi}{4}\right)-\frac{\pi}{2}\right]=-\sin\left[\frac{\pi}{2}-2\left(\alpha+\frac{\pi}{4}\right)\right]=-\cos2\left(\alpha+\frac{\pi}{4}\right)$ $=-\left[1-2\sin^{2}\left(\alpha+\frac{\pi}{4}\right)\right]=-\left(1-2\times\frac{1}{9}\right)=-\frac{7}{9}.$
