> > $$
> > \text { 答案 } \quad \frac {1}{2} \quad
> > \text { 解析 } \quad \frac {\sin 4 7 ^ {\circ} - \sin 1 7 ^ {\circ} \cos 3 0 ^ {\circ}}{\cos 1 7 ^ {\circ}} = \frac {\sin (1 7 ^ {\circ} + 3 0 ^ {\circ}) - \sin 1 7 ^ {\circ} \cos 3 0 ^ {\circ}}{\cos 1 7 ^ {\circ}}
> > $$
> > $$
> > = \frac {\sin 1 7 ^ {\circ} \cos 3 0 ^ {\circ} + \cos 1 7 ^ {\circ} \sin 3 0 ^ {\circ} - \sin 1 7 ^ {\circ} \cos 3 0 ^ {\circ}}{\cos 1 7 ^ {\circ}} = \frac {\cos 1 7 ^ {\circ} \sin 3 0 ^ {\circ}}{\cos 1 7 ^ {\circ}} = \sin 3 0 ^ {\circ} = \frac {1}{2}.
> > $$
> > (2) 已知 $\sin\left(\alpha+\frac{\pi}{4}\right)=-\frac{1}{3},\quad\alpha\in\left(\frac{5\pi}{4},\quad\frac{7\pi}{4}\right)$ ，则 $\cos\alpha=$ \_\_\_\_.
> > 答案 $\frac{4 - \sqrt{2}}{6}$ 解析 $\because \alpha \in \left(\frac{5\pi}{4}, \frac{7\pi}{4}\right), \therefore \alpha + \frac{\pi}{4} \in \left(\frac{3\pi}{2}, 2\pi\right), \therefore \cos \left(\alpha + \frac{\pi}{4}\right) = \sqrt{1 - \sin^2 \left(\alpha + \frac{\pi}{4}\right)} = \sqrt{1 - \left(-\frac{1}{3}\right)^2} = \frac{2\sqrt{2}}{3}, \therefore \cos \alpha = \cos \left[\left(\alpha + \frac{\pi}{4}\right) - \frac{\pi}{4}\right] = \cos \left(\alpha + \frac{\pi}{4}\right) \cos \frac{\pi}{4} + \sin \left(\alpha + \frac{\pi}{4}\right) \sin \frac{\pi}{4} = \frac{2\sqrt{2}}{3} \times \frac{\sqrt{2}}{2} + \left(-\frac{1}{3}\right) \times \frac{\sqrt{2}}{2} = \frac{4 - \sqrt{2}}{6}.$
> > (3) 已知 $\alpha, \beta \in \left(0, \frac{\pi}{2}\right)$ , 且 $\sin \alpha = \frac{4}{5}, \cos (\alpha + \beta) = -\frac{16}{65}$ , 则 $\cos \beta =$ \_\_\_\_.
> > 答案 $\frac{204}{325}$ 解析 因为 $\alpha, \beta \in \left(0, \frac{\pi}{2}\right)$ ，所以 $0 < \alpha + \beta < \pi$ ，由 $\cos (\alpha + \beta) = -\frac{16}{65}$ ，得 $\sin (\alpha + \beta) = \frac{63}{65}$ ，又 $\sin \alpha = \frac{4}{5}$ ，所以 $\cos \alpha = \frac{3}{5}$ ，所以 $\cos \beta = \cos [(\alpha + \beta) - \alpha] = \cos (\alpha + \beta)\cos \alpha + \sin (\alpha + \beta)\sin \alpha = \left(-\frac{16}{65}\right) \times \frac{3}{5} + \frac{63}{65} \times \frac{4}{5} = \frac{204}{325}$ .
> > (4) 已知 $\frac{\pi}{2} < \beta < \alpha < \frac{3}{4}\pi$ ， $\cos (\alpha - \beta) = \frac{12}{13}$ ， $\sin (\alpha + \beta) = -\frac{3}{5}$ ，则 $\cos 2\alpha =$ \_\_\_\_.
> > 答案 $-\frac{33}{65}$ 解析 $\because \frac{\pi}{2} < \beta < \alpha < \frac{3}{4}\pi, \therefore -\frac{3}{4}\pi < -\beta < -\frac{\pi}{2}.\therefore 0 < \alpha -\beta < \frac{\pi}{4},\pi < \alpha +\beta < \frac{3}{2}\pi .\therefore \sin (\alpha -\beta) =$ $\sqrt{1 - \cos^2(\alpha - \beta)} = \sqrt{1 - \left(\frac{12}{13}\right)^2} = \frac{5}{13},\cos (\alpha +\beta) = -\sqrt{1 - \sin^2(\alpha + \beta)} = -\sqrt{1 - \left(-\frac{3}{5}\right)^2} = -\frac{4}{5}.\therefore \cos 2\alpha = \cos [(a-$ $-\beta +(a + \beta)] = \cos (a - \beta)\cos (a + \beta) - \sin (a - \beta)\sin (a + \beta) = \frac{12}{13}\times \left(-\frac{4}{5}\right) - \frac{5}{13}\times \left(-\frac{3}{5}\right) = -\frac{33}{65},$ 即 $\cos 2\alpha = -\frac{33}{65}.$ (5）已知 $\sin \left[\alpha +\frac{\pi}{4}\right] = \frac{1}{3}$ ，则 $\sin 2\alpha$ 的值为（ ）A. $-\frac{8}{9}$ B. $\frac{8}{9}$ C. $-\frac{7}{9}$ D. $\frac{7}{9}$
> > 答案 C 解析 $\because2\alpha=2\left(\alpha+\frac{\pi}{4}\right)-\frac{\pi}{2},\quad\therefore\sin2\alpha=\sin\left[2\left(\alpha+\frac{\pi}{4}\right)-\frac{\pi}{2}\right]=-\sin\left[\frac{\pi}{2}-2\left(\alpha+\frac{\pi}{4}\right)\right]=-\cos2\left(\alpha+\frac{\pi}{4}\right)$ $=-\left[1-2\sin^{2}\left(\alpha+\frac{\pi}{4}\right)\right]=-\left(1-2\times\frac{1}{9}\right)=-\frac{7}{9}.$ (6)已知 $\sin\left(\frac{\pi}{3}-\alpha\right)=\frac{\sqrt{2}}{3}$ ，那么 $\cos\left(\frac{\pi}{3}+2\alpha\right)$ 等于（）
> > A. $-\frac{5}{9}$ B. $-\frac{\sqrt{2}}{3}$ C. $\frac{\sqrt{2}}{3}$ D. $\frac{5}{9}$
> > 答案 A 解析 $\because \frac{\pi}{3} + 2\alpha = \pi - 2\left(\frac{\pi}{3} - \alpha\right), \therefore \cos \left(\frac{\pi}{3} + 2\alpha\right) = \cos \left[\pi - 2\left(\frac{\pi}{3} - \alpha\right)\right] = -\cos 2\left(\frac{\pi}{3} - \alpha\right) = -\left[1 - 2\sin^2\left(\frac{\pi}{3} - \alpha\right)\right] = -\left(1 - 2 \times \frac{2}{9}\right) = -\frac{5}{9}.$
