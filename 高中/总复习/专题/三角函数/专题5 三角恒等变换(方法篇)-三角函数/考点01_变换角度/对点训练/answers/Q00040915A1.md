> [!faq]- 《专题5 三角恒等变换(方法篇)-三角函数》例题解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【解析】**
> > 答案 $\frac{2}{3} - \frac{1}{9}$ 解析 $\because \alpha + \frac{\pi}{4} = \alpha - \frac{\pi}{4} + \frac{\pi}{2}, \therefore \sin \left( \alpha + \frac{\pi}{4} \right) = \sin \left[ \left( \alpha - \frac{\pi}{4} \right) + \frac{\pi}{2} \right] = \cos \left( \alpha - \frac{\pi}{4} \right) = \frac{2}{3}, 2\alpha = 2\left( \alpha - \frac{\pi}{4} \right) + \frac{\pi}{2}.$ $\therefore \sin 2\alpha = \sin \left[ 2\left( \alpha - \frac{\pi}{4} \right) + \frac{\pi}{2} \right] = \cos 2\left( \alpha - \frac{\pi}{4} \right) = 2\cos^2\left( \alpha - \frac{\pi}{4} \right) - 1 = 2\times \left( \frac{2}{3} \right)^2 - 1 = -\frac{1}{9}.$
