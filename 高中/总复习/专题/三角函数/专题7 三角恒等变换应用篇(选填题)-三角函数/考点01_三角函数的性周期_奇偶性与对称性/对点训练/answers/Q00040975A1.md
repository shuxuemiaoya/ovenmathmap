> [!faq]- 《专题7 三角恒等变换应用篇(选填题)-三角函数》例题解析
>
> > [!success]- **【答案】** B
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > 答案 B 解析 法一： $\because f(x) = (\sqrt{3}\sin x + \cos x)(\sqrt{3}\cos x - \sin x) = 4\left[\frac{\sqrt{3}}{2}\sin x + \frac{1}{2}\cos x\right]\left[\frac{\sqrt{3}}{2}\cos x - \frac{1}{2}\sin x\right] = 4\sin \left(x + \frac{\pi}{6}\right)\cos \left(x + \frac{\pi}{6}\right) = 2\sin \left(2x + \frac{\pi}{3}\right), \therefore T = \frac{2\pi}{2} = \pi.$ 法二： $\because f(x) = (\sqrt{3}\sin x + \cos x)(\sqrt{3}\cos x - \sin x) = 3\sin x\cos x + \sqrt{3}\cos^2 x - \sqrt{3}\sin^2 x - \sin x\cos x = \sin 2x + \sqrt{3}\cos 2x = 2\sin \left(2x + \frac{\pi}{3}\right), \therefore T = \frac{2\pi}{2} = \pi.$
> >
> > 故选 **B**.
