> [!faq]- 《专题7 三角恒等变换应用篇(选填题)-三角函数》例题解析
>
> > [!success]- **【答案】** B
>
> > [!note]- **【解析】**
> > 答案 B 解析 $\because x = \frac{\pi}{12}$ 是 $f(x) = 2\sin \left(2x + \frac{\pi}{6} + \varphi\right)$ 图象的一条对称轴， $\therefore \frac{\pi}{3} + \varphi = k\pi + \frac{\pi}{2} (k \in \mathbb{Z})$ ，即 $\varphi = \frac{\pi}{6} + k\pi (k \in \mathbb{Z})$ 。 $\because 0 < \varphi < \pi, \therefore \varphi = \frac{\pi}{6}$ ，则 $f(x) = 2\sin \left(2x + \frac{\pi}{3}\right), \therefore g(x) = 2\sin \left(2x - \frac{7\pi}{6}\right) = 2\sin \left(2x + \frac{5\pi}{6}\right)$ . 又 $\because -$ $\frac{\pi}{4} \leq x \leq \frac{\pi}{6}, \therefore \frac{\pi}{3} \leq 2x + \frac{5\pi}{6} \leq \frac{7\pi}{6}, \therefore -1 \leq 2\sin \left(2x + \frac{5\pi}{6}\right) \leq 2.$ $\therefore g(x)$ 在 $\left[-\frac{\pi}{4}, \frac{\pi}{6}\right]$ 上的最小值为 $-1$
