> [!faq]- 《专题3   三角函数的图象与性质(1)-三角函数》例题解析
>
> > [!success]- **【答案】** C
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > 答案 C 解析 因为 $0 < \omega < 1, 0 \leq x \leq \frac{\pi}{3}$ ，所以 $0 \leq \omega x < \frac{\pi}{3}$ ，所以 $f(x)$ 在区间 $\left[0, \frac{\pi}{3}\right]$ 上单调递增，则 $f(x)_{\max} = f\left(\frac{\pi}{3}\right) = 2\sin\frac{\omega\pi}{3} = 1$ ，即 $\sin\frac{\omega\pi}{3} = \frac{1}{2}$ 。又因为 $0 \leq \omega x < \frac{\pi}{3}$ ，所以 $\frac{\omega\pi}{3} = \frac{\pi}{6}$ ，解得 $\omega = \frac{1}{2}$ 。
