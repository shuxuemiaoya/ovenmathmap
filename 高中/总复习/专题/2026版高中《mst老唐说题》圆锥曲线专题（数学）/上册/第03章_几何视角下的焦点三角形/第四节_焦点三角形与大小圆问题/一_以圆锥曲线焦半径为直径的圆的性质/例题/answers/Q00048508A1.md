> [!faq]- 《圆锥曲线专题(上册)》例题解析
>
> > [!success]- **【答案】** D
>
> > [!note]- **【解析】**
> > 解析 双曲线的 $a = 2, b = \sqrt{5}, c = 3$ ，设 $|PF_2| = 2t$ ，由双曲线的定义可得 $|PF_1| = 2a + 2t$
> >
> > 由 $N$ 为 $PF_{1}$ 的中点， $O$ 为 $F_{1}F_{2}$ 的中点，可得 $|ON| = \frac{1}{2} |PF_{2}| = t$ ，由 $Q$ 在圆 $N$ 上，可得 $|NQ| = \frac{1}{2} |PF_{1}| = a + t$ ，即有 $|OQ| = a + t - t = a$ ，所以圆 $N$ 与圆 $O$ 内切， $|QO|^2 - |OF_1|^2 = a^2 - c^2 = -5$ ，
> >
> > 故选 **D**.
