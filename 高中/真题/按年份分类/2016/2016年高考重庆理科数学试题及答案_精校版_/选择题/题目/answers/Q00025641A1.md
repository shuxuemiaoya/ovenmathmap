> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > C
> >
> > $$
> > B = \left\{x \mid (x + 1) (x - 2) <   0, x \in \mathbf {Z} \right\} = \left\{x \mid - 1 <   x <   2, x \in \mathbf {Z} \right\},
> > $$
> >
> > $\therefore B = \{0,1\}$ ， $\therefore A\cup B = \{0,1,2,3\}$
> >
