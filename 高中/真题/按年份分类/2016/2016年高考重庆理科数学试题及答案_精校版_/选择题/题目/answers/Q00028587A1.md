> [!faq]- 2016年高考重庆理科数学试题及答案(精校版)解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > $\frac{21}{13}$
> >
> > $\therefore \cos A = \frac{4}{5}, \cos C = \frac{5}{13}$
> >
> > $\sin B = \sin (A + C) = \sin A\cos C + \cos A\sin C = \frac{63}{65}$
> >
> > 由正弦定理得： $\frac{b}{\sin B} = \frac{a}{\sin A}$ 解得 $b = \frac{21}{13}$
