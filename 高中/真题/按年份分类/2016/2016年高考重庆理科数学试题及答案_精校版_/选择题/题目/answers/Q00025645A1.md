> > [!note]- **【分析】**
> > 本题解析推导如下：
>
> > [!note]- **【解析】**
> > C
> >
> > 几何体是圆锥与圆柱的组合体，
> >
> > 设圆柱底面圆半径为 r，周长为 c，圆锥母线长为 l，圆柱高为 h。
> >
> > 由图得 $r = 2$ ， $c = 2\pi r = 4\pi$ ，由勾股定理得： $l = \sqrt{2^2 + (2\sqrt{3})^2} = 4$
> >
> > $S_{\text{表}} = \pi r^{2} + ch + \frac{1}{2} cl = 4\pi + 16\pi + 8\pi = 28\pi$
> >
> > 故选C.
