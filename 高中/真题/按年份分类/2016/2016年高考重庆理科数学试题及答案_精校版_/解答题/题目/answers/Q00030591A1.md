> [!faq]- 2016年高考重庆理科数学试题及答案(精校版)解析
>
> > [!success]- **【答案】** (B)
>
> > [!note]- **【分析】**
> > 本题解析推导如下：
>
> > [!note]- **【解析】**
> > 解：
> > (1)当 $x < -\frac{1}{2}$ 时， $f(x) = \frac{1}{2} - x - x - \frac{1}{2} = -2x$ ，若 $-1 < x < -\frac{1}{2}$ ;
> >
> > 当 $-\frac{1}{2} \leq x \leq \frac{1}{2}$ 时， $f(x) = \frac{1}{2} - x + x + \frac{1}{2} = 1 < 2$ 恒成立；
> >
> > 当 $x > \frac{1}{2}$ 时， $f(x) = 2x$ ，若 $f(x) < 2$ ， $\frac{1}{2} < x < 1$ 。
> >
> > 综上可得， $M = \{x\mid -1 <   x <   1\}$
> > (2) 当 $a, b \in (-1, 1)$ 时，有 $(a^2 - 1)(b^2 - 1) > 0$
> >
> > 即 $a^2 b^2 + 1 > a^2 + b^2$
> >
> > 则 $a^2 b^2 + + 2ab + 1 > a^2 +2ab + b^2$
> >
> > 则 $(ab + 1)^2 > (a + b)^2$
> >
> > 即 $\left|a+b\right|<\left|ab+1\right|$ ,
> >
> > 证毕.
