> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > (1)设 $\left\{a_{n}\right\}$ 的公差为d， $S_{7}=7a_{4}=28$ ，
> >
> > $$
> > \therefore a _ {4} = 4, \quad \therefore d = \frac {a _ {4} - a _ {1}}{3} = 1, \quad \therefore a _ {n} = a _ {1} + (n - 1) d = n.
> > $$
> >
> > $$
> > \therefore b _ {1} = \left[ \lg a _ {1} \right] = \left[ \lg 1 \right] = 0, \quad b _ {1 1} = \left[ \lg a _ {1 1} \right] = \left[ \lg 1 1 \right] = 1, \quad b _ {1 0 1} = \left[ \lg a _ {1 0 1} \right] = \left[ \lg_ {1 0 1} \right] = 2.
> > $$
> >
> > (2) 记 $\left\{b_{n}\right\}$ 的前 n 项和为 $T_{n}$ ，则 $T_{1000}=b_{1}+b_{2}+\cdots+b_{1000}$
> >
> > $$
> > = \left[ \lg a _ {1} \right] + \left[ \lg a _ {2} \right] + \dots + \left[ \lg a _ {1 0 0 0} \right].
> > $$
> >
> > 当 $0 \leq \lg a_{n} < 1$ 时， $n = 1, 2, \ldots, 9$ ;
> >
> > 当 $1 \leq \lg a_{n} < 2$ 时， $n = 10, 11, \cdots, 99$ ;
> >
> > 当 $2 \leq \lg a_{n} < 3$ 时， $n = 100, 101, \cdots, 999$ ;
> >
> > 当 $\lg a_{n} = 3$ 时， $n = 1000$
> >
> > $$
> > \therefore T _ {1 0 0 0} = 0 \times 9 + 1 \times 9 0 + 2 \times 9 0 0 + 3 \times 1 = 1 8 9 3.
> > $$
