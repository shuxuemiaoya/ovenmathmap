> [!faq]- 2016年全国统一高考数学试卷（理科）（新课标ⅲ）（含解析版）解析
>
> > [!success]- **【答案】** . 【
>
> > [!note]- **【分析】**
> > 令 $f(x) = \sin x + \sqrt{3}\cos x = 2\sin \left(x + \frac{\pi}{3}\right)$ ，则 $f(x - \varphi) = 2\sin \left(x + \frac{\pi}{3} - \varphi\right)$ ，依题意可得 $2\sin \left(x + \frac{\pi}{3} - \varphi\right) = 2\sin \left(x - \frac{\pi}{3}\right)$ ，由 $\frac{\pi}{3} - \varphi = 2k\pi - \frac{\pi}{3} (k \in \mathbb{Z})$ ，可得
>
> > [!note]- **【解析】**
> > 分析】令 $f(x) = \sin x + \sqrt{3}\cos x = 2\sin \left(x + \frac{\pi}{3}\right)$ ，则 $f(x - \varphi) = 2\sin \left(x + \frac{\pi}{3} - \varphi\right)$ ，依题意可得 $2\sin \left(x + \frac{\pi}{3} - \varphi\right) = 2\sin \left(x - \frac{\pi}{3}\right)$ ，由 $\frac{\pi}{3} - \varphi = 2k\pi - \frac{\pi}{3} (k \in \mathbb{Z})$ ，可得
> > 答案.
> > 【
> > 解答】解： $\because y = f(x) = \sin x + \sqrt{3}\cos x = 2\sin \left(x + \frac{\pi}{3}\right), y = \sin x - \sqrt{3}\cos x = 2\sin \left(x - \frac{\pi}{3}\right)$ ，$\therefore f(x - \varphi) = 2\sin (x + \frac{\pi}{3} -\varphi)\quad (\varphi >0)$
> >
> > 令 $2\sin \left(x + \frac{\pi}{3} -\varphi\right) = 2\sin \left(x - \frac{\pi}{3}\right)$
> >
> > 则 $\frac{\pi}{3} -\varphi = 2k\pi -\frac{\pi}{3}$ （ $k\in Z$ ），
> >
> > 即 $\varphi = \frac{2\pi}{3} - 2k\pi (k \in \mathbb{Z})$
> >
> > 当 k=0 时，正数 $\varphi_{\min}=\frac{2\pi}{3}$ ,
> >
> > 故
> > 答案为： $\frac{2\pi}{3}$ .
> >
> > 【点评】本题考查函数 $y=\sin x$ 的图象变换得到 $y=Asin(\omega x+\varphi)(A>0,\omega>0)$ 的图象，
> >
> > 得到 $\frac{\pi}{3} -\varphi = 2k\pi -\frac{\pi}{3}$ （ $k\in Z$ ）是关键，也是难点，属于中档题.
