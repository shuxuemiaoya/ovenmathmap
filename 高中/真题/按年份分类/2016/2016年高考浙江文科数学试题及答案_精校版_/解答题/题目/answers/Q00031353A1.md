> [!faq]- 2016年高考浙江文科数学试题及答案(精校版)解析
>
> > [!success]- **【答案】** ,$
>
> > [!note]- **【分析】**
> > （1）由 $b + c = 2acosB$ ，利用正弦定理可得： $\sin B + \sin C = 2\sin A\cos B$ ，而
>
> > [!note]- **【解析】**
> > （1）证明：∵b+c=2acosB，
> >
> > $$
> > \therefore \sin B + \sin C = 2 \sin A \cos B,
> > $$
> >
> > $$
> > \because \sin C = \sin (A + B) = \sin A \cos B + \cos A \sin B,
> > $$
> >
> > $\therefore \sin B = \sin A \cos B - \cos A \sin B = \sin (A - B)$ ，由 $A, B \in (0, \pi)$ ，
> >
> > $\therefore 0 < A - B < \pi, \therefore B = A - B$ ，或 $B = \pi - (A - B)$ ，化为 $A = 2B$ ，或 $A = \pi$ （舍去）.
> >
> > $$
> > \therefore A = 2 B
> > $$
> >
> > (II) 解: $\cos B = \frac{2}{3}$ , $\therefore \sin B = \sqrt{1 - \cos^2 B} = \frac{\sqrt{5}}{3}$ .
> >
> > $$
> > \cos A = \cos 2 B = 2 \cos^ {2} B - 1 = - \frac {1}{9}, \sin A = \sqrt {1 - \cos^ {2} A} = \frac {4 \sqrt {5}}{9}.
> > $$
> >
> > $$
> > \therefore \cos C = - \cos (A + B) = - \cos A \cos B + \sin A \sin B = - \frac {2}{3} \times (- \frac {1}{9}) + \frac {\sqrt {5}}{3} \times \frac {4 \sqrt {5}}{9} = \frac {2 2}{2 7}.
> > $$
