> [!faq]- 2016年北京高考理科数学试题及答案解析
>
> > [!success]- **【答案】** C
>
> > [!note]- **【分析】**
> > x, $y \in R$ ，且 x > y > 0，可得： $\frac{1}{x} < \frac{1}{y}$ ，sinx 与 siny 的大小关系不确定， $\left(\frac{1}{2}\right)^{x} < \left(\frac{1}{2}\right)^{y}$ ，lnx + lny 与 0 的大小关系不确定，即可判断出结论.
> > 【
>
> > [!note]- **【解析】**
> > 分析】x, $y \in R$ ，且 x > y > 0，可得： $\frac{1}{x} < \frac{1}{y}$ ，sinx 与 siny 的大小关系不确定， $\left(\frac{1}{2}\right)^{x} < \left(\frac{1}{2}\right)^{y}$ ，lnx + lny 与 0 的大小关系不确定，即可判断出结论.
> > 【
> > 解答】解：∵x， $y\in R$ ，且x>y>0，则 $\frac{1}{x}<\frac{1}{y}$ ，sinx与siny的大小关系不确定， $\left(\frac{1}{2}\right)^{x}<\left(\frac{1}{2}\right)^{y}$ ，即 $\left(\frac{1}{2}\right)^{x}-\left(\frac{1}{2}\right)^{y}<0$ ，lnx+lny与0的大小关系不确定.
> >
> > 故选：C.
> >
> > 【点评】本题考查了不等式的性质、函数的单调性，考查了推理能力与计算能力，属于中档题.
