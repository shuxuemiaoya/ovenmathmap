16. (13 分) (2016·北京) A, B, C 三个班共有 100 名学生, 为调查他们的体育锻炼情况, 通过分层抽样获得了部分学生一周的锻炼时间, 数据如表 (单位: 小时):

（Ⅰ）试估计 C 班的学生人数；

（II）从 A 班和 C 班抽出的学生中，各随机选取一个人，A 班选出的人记为甲，C 班选出的人记为乙．假设所有学生的锻炼时间相对独立，求该周甲的锻炼时间比乙的锻炼时间长的概率；

（III）再从 A, B, C 三班中各随机抽取一名学生，他们该周锻炼时间分别是 7, 9, 8.25（单位：小时），这 3 个新数据与表格中的数据构成的新样本的平均数记为 $\mu_{1}$ ，表格中数据的平均数记为 $\mu_{0}$ ，试判断 $\mu_{0}$ 和 $\mu_{1}$ 的大小。（结论不要求证明）
