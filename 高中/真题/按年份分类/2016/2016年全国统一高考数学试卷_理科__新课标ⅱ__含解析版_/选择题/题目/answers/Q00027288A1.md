> [!faq]- 2016年全国统一高考数学试卷（理科）（新课标ⅱ）（含解析版）解析
>
> > [!success]- **【答案】** C
>
> > [!note]- **【分析】**
> > 先求出集合 A，B，由此利用并集的定义能求出 AUB 的值.
>
> > [!note]- **【解析】**
> > 解：∵集合 A={1, 2, 3},
> >
> > $$
> > B = \{x \mid (x + 1) (x - 2) <   0, x \in Z \} = \{0, 1 \},
> > $$
> >
> > $\therefore A \cup B = \{0, 1, 2, 3\}.$
> >
> > 故选：C.
> >
> > 【点评】本题考查并集的求法, 是基础题, 解题时要认真审题, 注意并集定义的合
> >
> > 理运用.
