> > [!note]- **【解析】**
> > 分析】（1）利用正弦定理将边化角即可得出 $\cos B$ ;
> >
> > (2) 求出 $\sin A$ ，利用两角和的正弦函数公式计算.
> >
> > 【
> > 解答】解：（1）∵asin2B= $\sqrt{3}$ bsinA，
> >
> > $\therefore 2 \sin A \sin B \cos B = \sqrt{3} \sin B \sin A,$
> >
> > $$
> > \therefore \cos B = \frac {\sqrt {3}}{2}, \quad \therefore B = \frac {\pi}{6}.
> > $$
> >
> > (2) $\because \cos A = \frac{1}{3}, \therefore \sin A = \frac{2\sqrt{2}}{3},$
> >
> > $$
> > \therefore \sin C = \sin (A + B) = \sin A \cos B + \cos A \sin B = \frac {2 \sqrt {2}}{3} \times \frac {\sqrt {3}}{2} + \frac {1}{2} \times \frac {1}{3} = \frac {2 \sqrt {6} + 1}{6}.
> > $$
> >
> > 【点评】本题考查了正弦定理解三角形，两角和的正弦函数，属于基础题.
