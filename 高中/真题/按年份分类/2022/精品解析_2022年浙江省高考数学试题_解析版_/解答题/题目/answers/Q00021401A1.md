> [!faq]- 精品解析：2022年浙江省高考数学试题（解析版）解析
>
> > [!success]- **【答案】** (1) $\frac{\sqrt{5}}{5}$ ; (2) 22. 【
>
> > [!note]- **【分析】**
> > （1）先由平方关系求出 $\sin C$ ，再根据正弦定理即可解出；
>
> > [!note]- **【解析】**
> > 由于 $\cos C = \frac{3}{5}$ ， $0 < C < \pi$ ，则 $\sin C = \frac{4}{5}$ .因为 $4a = \sqrt{5} c$
> >
> > 由正弦定理知 $4\sin A = \sqrt{5}\sin C$ ，则 $\sin A = \frac{\sqrt{5}}{4}\sin C = \frac{\sqrt{5}}{5}$
> >
> > 【
> >
> > 小问2
> >
> > 因为 $4a = \sqrt{5} c$ ，由余弦定理，得 $\cos C = \frac{a^2 + b^2 - c^2}{2ab} = \frac{a^2 + 121 - \frac{16}{5} a^2}{22a} = \frac{11 - \frac{a^2}{5}}{2a} = \frac{3}{5}$ 即 $a^2 + 6a - 55 = 0$ ，解得 $a = 5$ ，而 $\sin C = \frac{4}{5}$ ， $b = 11$ 所以 $\triangle ABC$ 的面积 $S = \frac{1}{2} ab\sin C = \frac{1}{2} \times 5 \times 11 \times \frac{4}{5} = 22$ 。
