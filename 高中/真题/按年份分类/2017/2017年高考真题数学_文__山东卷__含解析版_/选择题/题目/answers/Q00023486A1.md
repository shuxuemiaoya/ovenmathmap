> [!faq]- 2017年高考真题数学【文】(山东卷)（含解析版）解析
>
> > [!success]- **【答案】** C
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > ∵ $M=\{x|0<x<2\}$ ， $N=\{x|x<2\}$ ，
> >
> > $$
> > \therefore M \cap N = \{x | 0 <   x <   2 \} \cap \{x | x <   2 \} = \{x | 0 <   x <   2 \}.
> > $$
> >
> > 故选 C.
