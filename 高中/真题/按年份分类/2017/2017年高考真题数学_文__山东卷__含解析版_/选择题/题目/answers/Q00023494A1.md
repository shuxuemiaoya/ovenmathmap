> [!faq]- 2017年高考真题数学【文】(山东卷)（含解析版）解析
>
> > [!success]- **【答案】** C
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > 若 0 < a < 1，由 $f(a) = f(a + 1)$ ，
> >
> > 得=2(a+1-1),
> >
> > 若 $a \geq 1$ ，由 $f(a) = f(a + 1)$ ，
> >
> > 得 $2(a - 1) = 2(a + 1 - 1)$ ，无解。
> >
> > 综上， $f = 6$
> >
> > 故选C.
