19. (16 分) 对于给定的正整数 k，若数列 $\{a_{n}\}$ 满足： $a_{n-k} + a_{n-k+1} + \ldots + a_{n-1} + a_{n+1} + \ldots + a_{n+k}$

$_{-1}+a_{n+k}=2ka_{n}$ 对任意正整数 n (n>k) 总成立，则称数列 $\{a_{n}\}$ 是 “P(k) 数列”.

(1) 证明: 等差数列 $\{a_{n}\}$ 是 “P
(3) 数列”;

(2) 若数列 $\{a_{n}\}$ 既是“P
(2)数列”，又是“P
(3)数列”，证明： $\{a_{n}\}$ 是等差数列.
