> > [!note]- **【分析】**
> > 先分别求出集合 A 和 B，再求出 $A \cap B$ 和 $A \cup B$ ，由此能求出结果.
>
> > [!note]- **【解析】**
> > 解：∵集合 $A=\{x \mid x<1\}$ ,
> >
> > $B=\{x\mid3^{x}<1\}=\{x\mid x<0\},$
> >
> > $\therefore A \cap B = \{x \mid x < 0\}$ ，故 $A$ 正确， $D$ 错误；
> >
> > AUB={x|x<1}, 故 B 和 C 都错误.
> >
> > 故选：A.
