> [!faq]- 2017年全国统一高考数学试卷（理科）（新课标ⅰ）（含解析版）解析
>
> > [!success]- **【答案】** (12 分) $\triangle ABC$ 的内角 $A, B, C$ 的对边分别为 $a, b, c$ , 已知 $\triangle ABC$ 的面积为 $\frac{a^2}{3\sin A}$
>
> > [!note]- **【分析】**
> > （1）根据三角形面积公式和正弦定理可得答案，
> > (2) 根据两角余弦公式可得 $\cos A = \frac{1}{2}$ , 即可求出 $A = \frac{\pi}{3}$ , 再根据正弦定理可得 $bc = 8$ ,
>
> > [!note]- **【解析】**
> > 解：
> > （1）由三角形的面积公式可得 $S_{\triangle ABC}=\frac{1}{2}ac\sin B=\frac{a^{2}}{3\sin A}$ ,
> >
> > ∴3csinBsinA=2a,
> >
> > 由正弦定理可得 $3\sin C\sin B\sin A=2\sin A$ ,
> >
> > $\because \sin A = 0,$
> >
> > $\therefore \sin B \sin C = \frac{2}{3}$ ;
> > (2) $\because 6\cos B\cos C=1,$
> >
> > $\therefore \cos B \cos C = \frac{1}{6}$ ,
> >
> > $$
> > \therefore \cos B \cos C - \sin B \sin C = \frac {1}{6} - \frac {2}{3} = - \frac {1}{2},
> > $$
> >
> > $\therefore \cos (B + C) = -\frac{1}{2},$
> >
> > $\therefore \cos A = \frac{1}{2},$
> >
> > $\because 0 < A < \pi,$
> >
> > $\therefore A = \frac{\pi}{3},$
> >
> > $$
> > \therefore \frac {a}{\sin A} = \frac {b}{\sin B} = \frac {c}{\sin C} = 2 R = \frac {\frac {3}{\sqrt {3}}}{2} = 2 \sqrt {3},
> > $$
> >
> > $$
> > \therefore \sin B \sin C = \frac {b}{2 R} \cdot \frac {c}{2 R} = \frac {b c}{(2 \sqrt {3}) ^ {2}} = \frac {b c}{1 2} = \frac {2}{3},
> > $$
> >
> > $\therefore bc=8,$
> >
> > $\because a^{2}=b^{2}+c^{2}-2bccosA,$
> >
> > $$
> > \therefore b ^ {2} + c ^ {2} - b c = 9,
> > $$
> >
> > $$
> > \therefore (b + c) ^ {2} = 9 + 3 c b = 9 + 2 4 = 3 3,
> > $$
> >
> > $$
> > \therefore b + c = \sqrt {3 3}
> > $$
> >
> > ∴周长 $a+b+c=3+\sqrt{33}$ .
