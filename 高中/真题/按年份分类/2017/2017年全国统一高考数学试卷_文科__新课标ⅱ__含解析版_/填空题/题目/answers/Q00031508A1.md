> [!faq]- 2017年全国统一高考数学试卷（文科）（新课标ⅱ）（含解析版）解析
>
> > [!success]- **【答案】** $\frac{\pi}{3}$
>
> > [!note]- **【分析】**
> > 根据正弦定理和两角和的正弦公式和诱导公式计算即可
>
> > [!note]- **【解析】**
> > 解：∵2bcosB=acosC+ccosA，由正弦定理可得，
> >
> > $$
> > 2 \cos B \sin B = \sin A \cos C + \sin C \cos A = \sin (A + C) = \sin B,
> > $$
> >
> > $\because \sin B = 0,$
> >
> > $$
> > \therefore \cos B = \frac {1}{2},
> > $$
> >
> > $$
> > \because 0 <   B <   \pi ,
> > $$
> >
> > $$
> > \therefore B = \frac {\pi}{3},
> > $$
> >
> > 故答案为： $\frac{\pi}{3}$
