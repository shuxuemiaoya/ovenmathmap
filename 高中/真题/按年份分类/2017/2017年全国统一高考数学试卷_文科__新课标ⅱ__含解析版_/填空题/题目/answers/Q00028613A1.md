>
> > [!success]- **【答案】** 为： $\frac{\pi}{3}$ 【点评】本题考查了正弦定理和两角和的正弦公式和诱导公式，属于基础题
>
> > [!note]- **【分析】**

>
> > [!note]- **【解析】**
> > 分析】根据正弦定理和两角和的正弦公式和诱导公式计算即可
> >
> > 【
> > 解答】解：∵2bcosB=acosC+ccosA，由正弦定理可得，
> >
> > $$
> > 2 \cos B \sin B = \sin A \cos C + \sin C \cos A = \sin (A + C) = \sin B,
> > $$
> >
> > $\because \sin B = 0,$
> >
> > $$
> > \therefore \cos B = \frac {1}{2},
> > $$
> >
> > $$
> > \because 0 <   B <   \pi ,
> > $$
> >
> > $$
> > \therefore B = \frac {\pi}{3},
> > $$
> >
> > 故
> > 答案为： $\frac{\pi}{3}$
> >
> > 【点评】本题考查了正弦定理和两角和的正弦公式和诱导公式，属于基础题
