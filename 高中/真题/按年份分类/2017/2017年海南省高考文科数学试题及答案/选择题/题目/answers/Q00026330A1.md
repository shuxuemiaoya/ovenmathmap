> [!faq]- 2017年海南省高考文科数学试题及答案解析
>
> > [!success]- **【答案】** B
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > 阅读流程图，初始化数值 $a = -1, k = 1, S = 0$
> >
> > 循环结果执行如下：
> >
> > 第一次： $S=0-1=-1, a=1, k=2$
> >
> > 第二次： $S = -1 + 2 = 1, a = -1, k = 3$ ;
> >
> > 第三次： $S=1-3=-2,a=1,k=4$ ；
> >
> > 第四次： $S = -2 + 4 = 2, a = -1, k = 5$
> >
> > 第五次： $S=2-5=-3,a=1,k=6$ ；
> >
> > 第六次： $S = -3 + 6 = 3, a = -1, k = 7$
> >
> > 结束循环，输出 S = 3. 故选 B.
