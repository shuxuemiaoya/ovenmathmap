> [!faq]- 2017年高考真题数学【理】(山东卷)（含解析版）解析
>
> > [!success]- **【答案】** A $$ \because \text {等式右边} = \sin A \cos C + (\sin A \cos C + \cos A \sin C) = \sin A \cos C + \sin (A + C) $$ $$ = \sin A \cos C + \sin B, $$ 等式左边= $\sin B+2\sin B\cos C$ , $$ \therefore \sin B + 2 \sin B \cos C = \sin A \cos C + \sin B. $$ 由 $\cos C > 0$ ，得 $\sin A = 2\sin B$ . 根据正弦定理，得 a=2b. 故选A.
