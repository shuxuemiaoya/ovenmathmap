> [!faq]- 2017年高考真题数学【理】(山东卷)（含解析版）解析
>
> > [!success]- **【答案】** D 【
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > $\because 4-x^{2}\geq0,\therefore-2\leq x\leq2,\therefore A=[-2,2].$
> >
> > $\because 1 - x > 0, \therefore x < 1, \therefore B = (-\infty, 1). \therefore A \cap B = [-2, 1)$ ，故选 D.
