>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > 解答】解：在 ABC 中，角 A，B，C 的对边分别为 a，b，c，满足
> >
> > $$
> > \sin B (1 + 2 \cos C) = 2 \sin A \cos C + \cos A \sin C = \sin A \cos C + \sin (A + C) = \sin A \cos C + \sin B,
> > $$
> >
> > 可得： $2\sin B\cos C=\sin A\cos C$ ，因为 $\triangle ABC$ 为锐角三角形，所以 $2\sin B=\sin A$ ，
> >
> > 由正弦定理可得：2b=a.
> >
> > 故选：A.
