> [!faq]- 2017年全国统一高考数学试卷（理科）（新课标ⅱ）（含解析版）解析
>
> > [!success]- **【答案】** C
>
> > [!note]- **【分析】**
> > 通过圆的圆心与双曲线的渐近线的距离, 列出关系式, 然后求解双曲线的离心率即可.
>
> > [!note]- **【解析】**
> > 解：双曲线 C: $\frac{x^{2}}{a^{2}} - \frac{y^{2}}{b^{2}} = 1 (a > 0, b > 0)$ 的一条渐近线不妨为： $bx + ay = 0$ ，
> > 圆 $(x-2)^{2}+y^{2}=4$ 的圆心 $(2,0)$ ，半径为：2，
> >
> > 双曲线 C: $\frac{x^{2}}{a^{2}} - \frac{y^{2}}{b^{2}} = 1 (a > 0, b > 0)$ 的一条渐近线被圆 $(x - 2)^{2} + y^{2} = 4$ 所截得的弦
> >
> > 长为 2，
> >
> > 可得圆心到直线的距离为： $\sqrt{2^2 - 1^2} = \sqrt{3} = \frac{|2b|}{\sqrt{a^2 + b^2}}$
> >
> > 解得： $\frac{4c^2 - 4a^2}{c^2} = 3$ ，可得 $e^2 = 4$ ，即 $e = 2$
> >
> > 故选：A.
> >
> > 【点评】本题考查双曲线的简单性质的应用，圆的方程的应用，考查计算能力.
