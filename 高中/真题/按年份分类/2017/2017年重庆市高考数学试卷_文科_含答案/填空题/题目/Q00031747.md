16. $\triangle ABC$ 的内角 $A, B, C$ 的对边分别为 $a, b, c$ , 若 $2b\cos B = a\cos C + c\cos A$ , 则 $B =$ \_\_\_\_.

$$
2 \sin B \cos B = \sin A \cos C + \sin C \cos A = \sin (A + C) = \sin B \Rightarrow \cos B = \frac {1}{2} \Rightarrow B = \frac {\pi}{3}.
$$
