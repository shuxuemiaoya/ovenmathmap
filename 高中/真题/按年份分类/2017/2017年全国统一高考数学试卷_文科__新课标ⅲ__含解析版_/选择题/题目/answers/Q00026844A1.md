> [!faq]- 2017年全国统一高考数学试卷（文科）（新课标ⅲ）（含解析版）解析
>
> > [!success]- **【答案】** A
>
> > [!note]- **【分析】**
> > 利用诱导公式化简函数的解析式，通过正弦函数的最值求解即可.
>
> > [!note]- **【解析】**
> > 解：函数 $f(x) = \frac{1}{5}\sin \left(x + \frac{\pi}{3}\right) + \cos \left(x - \frac{\pi}{6}\right) = \frac{1}{5}\sin \left(x + \frac{\pi}{3}\right) + \cos \left(-x + \frac{\pi}{6}\right) = \frac{1}{5}$ $\sin \left(x + \frac{\pi}{3}\right) + \sin \left(x + \frac{\pi}{3}\right)$ $= \frac{6}{5}\sin \left(x + \frac{\pi}{3}\right) \leqslant \frac{6}{5}.$
> >
> > 故选：A.
> >
> > 【点评】本题考查诱导公式的应用，三角函数的最值，正弦函数的有界性，考查计算能力.
