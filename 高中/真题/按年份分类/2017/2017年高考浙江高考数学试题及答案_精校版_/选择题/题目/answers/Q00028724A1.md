> [!faq]- 2017年高考浙江高考数学试题及答案(精校版)解析
>
> > [!success]- **【答案】** 为： $(-∞, \frac{9}{2})$ . 【点评】本题考查函数的最值，考查绝对值函数，考查转化与化归思想，注意解题 方法的积累，属于中档题. ##
>
> > [!note]- **【分析】**
> > 通过转化可知 $|x + \frac{4}{x} - a| + a \leq 5$ 且 $a \leq 5$ ，进而解绝对值不等式可知 $2a - 5 \leq x + \frac{4}{x} \leq 5$ ，进而计算可得结论.
>
> > [!note]- **【解析】**
> > 分析】通过转化可知 $|x + \frac{4}{x} - a| + a \leq 5$ 且 $a \leq 5$ ，进而解绝对值不等式可知 $2a - 5 \leq x + \frac{4}{x} \leq 5$ ，进而计算可得结论.
> >
> > 【
> > 解答】解：由题可知 $|x + \frac{4}{x} - a| + a \leq 5$ ，即 $|x + \frac{4}{x} - a| \leq 5 - a$ ，所以 $a \leq 5$ ，
> >
> > 又因为 $\left|x+\frac{4}{x}-a\right|\leq5-a,$
> >
> > 所以 $a - 5 \leq x + \frac{4}{x} - a \leq 5 - a,$
> >
> > 所以 $2a - 5 \leq x + \frac{4}{x} \leq 5$ ,
> >
> > 又因为 $1 \leq x \leq 4$ ， $4 \leq x + \frac{4}{x} \leq 5$ ，
> >
> > 所以 $2a - 5 \leq 4$ ，解得 $a \leq \frac{9}{2}$ ，
> >
> > 故
> > 答案为： $(-∞, \frac{9}{2})$ .
> >
