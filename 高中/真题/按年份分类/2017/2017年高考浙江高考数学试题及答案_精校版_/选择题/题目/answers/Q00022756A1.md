> [!faq]- 2017年高考浙江高考数学试题及答案(精校版)解析
>
> > [!success]- **【答案】** A
>
> > [!note]- **【分析】**
> > 直接利用并集的运算法则化简求解即可.
>
> > [!note]- **【解析】**
> > 解：集合 $P=\{x \mid -1 < x < 1\}$ ， $Q=\{x \mid 0 < x < 2\}$ ，
> >
> > 那么 $PUQ=\{x \mid -1 < x < 2\} = (-1, 2)$ .
> >
> > 故选：A.
