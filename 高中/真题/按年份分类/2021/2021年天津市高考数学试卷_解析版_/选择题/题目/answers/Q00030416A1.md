> [!faq]- 2021年天津市高考数学试卷（解析版）解析
>
> > [!success]- **【答案】** D
>
> > [!note]- **【分析】**
> > 根据指数函数和对数函数的性质求出 $a, b, c$ 的范围即可求解.
>
> > [!note]- **【解析】**
> > $\because \log_2 0.3 < \log_2 1 = 0, \therefore a < 0,$
> >
> > $\because \log_{\frac{1}{2}} 0.4 = -\log_{2} 0.4 = \log_{2} \frac{5}{2} > \log_{2} 2 = 1, \therefore b > 1,$ $\because 0 < 0.4^{0.3} < 0.4^0 = 1, \therefore 0 < c < 1,$ $\therefore a < c < b.$
> >
> > 故选：D.
