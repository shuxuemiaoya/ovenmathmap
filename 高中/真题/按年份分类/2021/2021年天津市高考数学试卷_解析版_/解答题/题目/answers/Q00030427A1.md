> [!faq]- 2021年天津市高考数学试卷（解析版）解析
>
> > [!success]- **【答案】** (I) $2\sqrt{2}$ ; (II) (III) $\frac{3\sqrt{21} - 1}{16}$
>
> > [!note]- **【分析】**
> > （I）由正弦定理可得 $a:b:c = 2:1:\sqrt{2}$ ，即可求出；
>
> > [!note]- **【解析】**
> > （I）因为 $\sin A:\sin B:\sin C=2:1:\sqrt{2}$ ，由正弦定理可得 $a:b:c=2:1:\sqrt{2}$ ， $\because b=\sqrt{2},\therefore a=2\sqrt{2},c=2;$
> >
> > (II) 由余弦定理可得 $\cos C = \frac{a^{2} + b^{2} - c^{2}}{2ab} = \frac{8 + 2 - 4}{2 \times 2\sqrt{2} \times \sqrt{2}} = \frac{3}{4}$ ;
> >
> > (III) $\because \cos C = \frac{3}{4}, \therefore \sin C = \sqrt{1 - \cos^{2} C} = \frac{\sqrt{7}}{4},$
> >
> > $$
> > \therefore \sin 2 C = 2 \sin C \cos C = 2 \times \frac {\sqrt {7}}{4} \times \frac {3}{4} = \frac {3 \sqrt {7}}{8}, \cos 2 C = 2 \cos^ {2} C - 1 = 2 \times \frac {9}{1 6} - 1 = \frac {1}{8},
> > $$
> >
> > $$
> > \sin \left(2 C - \frac {\pi}{6}\right) = \sin 2 C \cos \frac {\pi}{6} - \cos 2 C \sin \frac {\pi}{6} = \frac {3 \sqrt {7}}{8} \times \frac {\sqrt {3}}{2} - \frac {1}{8} \times \frac {1}{2} = \frac {3 \sqrt {2 1} - 1}{1 6}
> > $$
