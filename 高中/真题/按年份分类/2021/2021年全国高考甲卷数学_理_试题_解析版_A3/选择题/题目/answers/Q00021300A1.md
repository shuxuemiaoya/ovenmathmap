> [!faq]- 2021年全国高考甲卷数学（理）试题（解析版）A3解析
>
> > [!success]- **【答案】** B
>

> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > 因为 $M = \{x \mid 0 < x < 4\}$ ， $N = \{x \mid \frac{1}{3} \leq x \leq 5\}$ ，所以 $M \cap N = \left\{x \mid \frac{1}{3} \leq x < 4\right\}$ ，
> >
