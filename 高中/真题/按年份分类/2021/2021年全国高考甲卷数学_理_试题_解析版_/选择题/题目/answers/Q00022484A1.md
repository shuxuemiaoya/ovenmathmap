> [!faq]- 2021年全国高考甲卷数学（理）试题（解析版）解析
>
> > [!success]- **【答案】** B
>
> > [!note]- **【分析】**
> > 根据交集定义运算即可
>
> > [!note]- **【解析】**
> > 因为 $M = \{x \mid 0 < x < 4\}$ ， $N = \{x \mid \frac{1}{3} \leq x \leq 5\}$ ，所以 $M \cap N = \left\{x \mid \frac{1}{3} \leq x < 4\right\}$
> >
> > 故选：B.
> >
> > 【点睛】本题考查集合的运算，属基础题，在高考中要求不高，掌握集合的交并补的基本概念即可求解.
