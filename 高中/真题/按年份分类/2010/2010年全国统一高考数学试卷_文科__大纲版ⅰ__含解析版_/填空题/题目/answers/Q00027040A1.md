> [!faq]- 2010年全国统一高考数学试卷（文科）（大纲版ⅰ）（含解析版）解析
>
> > [!success]- **【答案】** (12 分) 已知 $\triangle ABC$ 的内角 $A, B$ 及其对边 $a, b$ 满足 $a + b = acotA + bcotB$ , 求内角
>
> > [!note]- **【分析】**
> > 先利用正弦定理题设等式中的边转化角的正弦,化简整理求得 $\sin\left(A-\frac{\pi}{4}\right)=\sin\left(B+\frac{3\pi}{4}\right)$ ，进而根据 A, B 的范围，求得 $A-\frac{\pi}{4}$ 和 $B+\frac{3\pi}{4}$ 的关系，进而求得 $A+B=\frac{\pi}{2}$ ，则 C 的值可求.
>
> > [!note]- **【解析】**
> > 解：由已知及正弦定理，有 $\sin A + \sin B = \sin A \cdot \frac{\cos A}{\sin A} + \sin B \cdot \frac{\cos B}{\sin B} = \cos A + \cos B,$ $\therefore \sin A - \cos A = \cos B - \sin B$ $\therefore \sin \left( A - \frac{\pi}{4} \right) = \sin \left( B + \frac{3\pi}{4} \right),$ $\because 0 < A < \pi, 0 < B < \pi$ $\therefore -\frac{\pi}{4} < A - \frac{\pi}{4} < \frac{3\pi}{4} < B + \frac{3\pi}{4} < \frac{7\pi}{4}$ $\therefore A - \frac{\pi}{4} + B + \frac{3\pi}{4} = \pi,$ $\therefore A + B = \frac{\pi}{2}, C = \pi - (A + B) = \frac{\pi}{2}$
