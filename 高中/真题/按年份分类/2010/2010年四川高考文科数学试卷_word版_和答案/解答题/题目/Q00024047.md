19. (12 分) (2010·四川) (Ⅰ) ①证明两角和的余弦公式 $C_{\alpha + \beta} : \cos (\alpha + \beta) = \cos \alpha \cos \beta - \sin \alpha \sin \beta$ ; ②由 $C_{\alpha + \beta}$ 推导两角和的正弦公式 $S_{\alpha + \beta} : \sin (\alpha + \beta) = \sin \alpha \cos \beta + \cos \alpha \sin \beta$ .

(II) 已知

$\cos \alpha = -\frac{4}{5}, \alpha \in (\pi, \frac{3}{2}\pi), \tan \beta = -\frac{1}{3}, \beta \in (\frac{\pi}{2}, \pi), \cos (\alpha + \beta)$ ，求 $\cos (\alpha + \beta)$ 。
