> [!faq]- 2010年全国统一高考数学试卷（文科）（大纲版ⅱ）（含解析版）解析
>
> > [!success]- **【答案】** A
>
> > [!note]- **【分析】**
> > 本题的方法是: 要使不等式小于 0 即要分子与分母异号, 得到一个一元二
>
> > [!note]- **【解析】**
> > 分析】本题的方法是: 要使不等式小于 0 即要分子与分母异号, 得到一个一元二
> >
> > 次不等式，讨论 x 的值即可得到解集。
> >
> > 【
> > 解答】解： $\because \frac{x - 3}{x + 2} < 0$ ，得到 $(x - 3) (x + 2) < 0$
> >
> > 即 x - 3 > 0 且 $x + 2 < 0$ 解得：x > 3 且 x < -2 所以无解；
> >
> > 或 x - 3 < 0 且 $x + 2 > 0$ ，解得 -2 < x < 3，
> >
> > 所以不等式的解集为 $-2 < x < 3$
> >
> > 故选：A.
> >
> > 【点评】本题主要考查学生求不等式解集的能力，是一道基础题.
