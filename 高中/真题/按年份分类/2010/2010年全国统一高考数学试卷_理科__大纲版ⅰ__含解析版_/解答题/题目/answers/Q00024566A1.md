> [!faq]- 2010年全国统一高考数学试卷（理科）（大纲版ⅰ）（含解析版）解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【分析】**
> > （Ⅰ）先根据导数公式求出导函数 $f'(x)$ ，代入 $xf'(x) \leqslant x^{2} + ax + 1$ ，将 a 分离
>
> > [!note]- **【解析】**
> > 解：（Ⅰ） $f'(x)=\frac{x+1}{x}+\ln x-1=\ln x+\frac{1}{x}$
> >
> > $$
> > x f ^ {\prime} (x) = x \ln x + 1,
> > $$
> >
> > 题设 $xf'(x) \leqslant x^{2} + ax + 1$ 等价于 $\ln x - x \leq a$ .
> >
> > 令 $g(x) = \ln x - x$ ，则 $g'(x) = \frac{1}{x} - 1$
> >
> > 当 0 < x < 1, $g'$ (x) > 0;
> >
> > 当 $x \geq 1$ 时， $g'(x) \leqslant 0$ ，x = 1 是 $g(x)$ 的最大值点，
> >
> > $$
> > \mathrm{g} (x) \leqslant \mathrm{g} (1) = - 1
> > $$
> >
> > 综上，a 的取值范围是 $[-1, +\infty)$ 。
> >
> > （Ⅱ）由（Ⅰ）知， $g(x) \leqslant g(1) = -1$ 即 $\ln x - x + 1 \leq 0$ .
> >
> > 当 0 < x < 1 时， $f(x) = (x + 1) \ln x - x + 1 = x \ln x + (\ln x - x + 1) < 0;$
> >
> > 当 $x \geq 1$ 时， $f(x) = \ln x + (x \ln x - x + 1) = \ln x + x (\ln x + \frac{1}{x} - 1) = \ln x - x (\ln \frac{1}{x} - \frac{1}{x} + 1) \geq 0$
> >
> > 所以 $(x - 1)$ f $(x) \geqslant 0$ .
> >
> > 【点评】本题主要考查了利用导数研究函数的最值，以及利用参数分离法求参数
> >
> > 的取值范围，同时考查了运算求解的能力，属于中档题.
