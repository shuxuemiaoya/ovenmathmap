> [!faq]- 2009年重庆市高考数学试卷(文科)含答案解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【分析】**
> > （1）先将函数化简为 $f(x) = \sqrt{2}\sin \left(2\omega x + \frac{\pi}{4}\right)$ ，再由 $\frac{2\pi}{2\omega} = \frac{2\pi}{3}$ ，可得答案.
> > (2) 根据 $g(x) = f(x - \frac{\pi}{2})$ 先求出解析式，再求单调区间.
>
> > [!note]- **【解析】**
> > 解：
> > （1） $f(x) = (\sin \omega x + \cos \omega x)^{2} + 2\cos^{2}\omega x = \sin^{2}\omega x + \cos^{2}\omega x + \sin 2\omega x + 1 + 2\cos 2\omega x = \sin 2\omega x + \cos 2\omega x + 2 = \sqrt{2}\sin(2\omega x + \frac{\pi}{4}) + 2$
> >
> > 依题意得 $\frac{2\pi}{2\omega} = \frac{2\pi}{3}$ ，故 $\omega$ 的值为 $\frac{3}{2}$ .
> >
> > （II）依题意得： $g(x) = \sqrt{2} \sin [3(x - \frac{\pi}{2}) + \frac{\pi}{4}] + 2 = \sqrt{2} \sin (3x - \frac{5\pi}{4}) + 2$ 由 $2k\pi-\frac{\pi}{2}\leqslant3x-\frac{5\pi}{4}\leqslant2k\pi+\frac{\pi}{2}(k\in Z)$ 解得 $\frac{2}{3}k\pi+\frac{\pi}{4}\leqslant x\leqslant\frac{2}{3}k\pi+\frac{7\pi}{12}(k\in Z)$ 故 y=g (x) 的单调增区间为： $\left[\frac{2}{3}k\pi+\frac{\pi}{4},\frac{2}{3}k\pi+\frac{7\pi}{12}\right](k\in Z)$
> >
> > 【点评】本题主要考查三角函数最小正周期的求法和单调区间的求法。做这种题首先要将原函数化简为 $y=\text{Asin}(\omega x+\varphi)$ 的形式再做题。
