> [!faq]- 2009年重庆市高考数学试卷(文科)含答案解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【分析】**
> > （Ⅰ）由题意可知双曲线的焦点在 x 轴上，双曲线的方程，根据准线方程和离心率求得 a 和 c，进而求得 b.
>
> > [!note]- **【解析】**
> > 分析】（Ⅰ）由题意可知双曲线的焦点在 x 轴上，双曲线的方程，根据准线方程和离心率求得 a 和 c，进而求得 b.
> >
> > （II）设点D的坐标为 $(\sqrt{5}, 0)$ ，则点A、D为双曲线的焦点，根据双曲线的性质可得， $|\mathrm{MA}| - |\mathrm{MD}| = 2a$ ，进而可 $|\mathrm{MA}| + |\mathrm{MB}| = 2 + |\mathrm{MB}| + |\mathrm{MD}| \geqslant 2 + |\mathrm{BD}|$ ，又由B是圆 $x^2 + (y - \sqrt{5})^2 = 1$ 上的点，推断出 $|\mathrm{MA}| + |\mathrm{MB}| \geqslant 2 + |\mathrm{BD}| \geqslant \sqrt{10} + 1$ ，进而通过直线方程与双曲线方程联立求得M的坐标.
> >
> > 【
> > 解答】解：（Ⅰ）由题意可知，双曲线的焦点在 x 轴上，
> >
> > 故可设双曲线的方程为 $\frac{x^2}{a^2} -\frac{y^2}{b^2} = 1(a > 0,b > 0)$
> >
> > 设 $c = \sqrt{a^2 + b^2}$
> >
> > 由准线方程为 $x = \frac{\sqrt{5}}{5}$ 得 $\frac{a^2}{c} = \frac{\sqrt{5}}{5}$ ，由 $e = \sqrt{5}$
> >
> > 得 $\frac{c}{a} = \sqrt{5}$ 解得 $a = 1$ ， $c = \sqrt{5}$
> >
> > 从而 $b = 2$ ，∴该双曲线的方程为 $\mathbf{x}^2 -\frac{\mathbf{y}^2}{4} = 1$
> >
> > （Ⅱ）设点D的坐标为 $(\sqrt{5},0)$ ，
> >
> > 则点 A、D 为双曲线的焦点， $|MA| - |MD| = 2a = 2$
> >
> > 所以 $|\mathrm{MA}| + |\mathrm{MB}| = 2 + |\mathrm{MB}| + |\mathrm{MD}| \geq 2 + |\mathrm{BD}|$ ,
> >
> > $\because \mathrm{B}$ 是圆 $\mathbf{x}^{2 + }(y - \sqrt{5})^2 = 1$ 上的点，
> >
> > 其圆心为 $C(0, \sqrt{5})$ ，半径为1，
> >
> > 故 $|\mathrm{BD}| \geqslant |\mathrm{CD}| - 1 = \sqrt{10} - 1$
> >
> > 从而 $|\mathsf{MA}| + |\mathsf{MB}| \geqslant 2 + |\mathsf{BD}| \geqslant \sqrt{10} + 1$
> >
> > 当 M，B 在线段 CD 上时取等号，
> >
> > 此时 $|\mathrm{MA}| + |\mathrm{MB}|$ 的最小值为 $\sqrt{10} + 1$
> >
> > ∵直线CD的方程为 $y=-x+\sqrt{5}$ ,
> >
> > 因点 M 在双曲线右支上，故 x > 0
> >
> > 由方程组 $\left\{ \begin{array}{l}4x^{2} - y^{2} = 4\\ y = -x + \sqrt{5} \end{array} \right.$
> >
> > 解得 $x = \frac{-\sqrt{5} + 4\sqrt{2}}{3}, y = \frac{4\sqrt{5} - 4\sqrt{2}}{3}$
> >
> > 所以M点的坐标为 $\left(\frac{-\sqrt{5} + 4\sqrt{2}}{3},\frac{4\sqrt{5} - 4\sqrt{2}}{3}\right)$
> >
> > 【点评】本题主要考查了双曲线的标准方程和双曲线与直线的关系。圆锥曲线问题是高考中必考的知识点，故应加强训练。
