> [!faq]- 2009年高考真题数学【文】(山东卷)（含解析版）解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > 设函数 $y = a^{x} (a > 0, \text{且 } a \neq 1)$ 和函数 $y = x + a$ ，则函数 $f(x) = a_{x} - x - a (a > 0 \text{ 且 } a \neq 1)$ 有两个零点，就是函数 $y = a^{x} (a > 0, \text{且 } a \neq 1)$ 与函数 $y = x + a$ 有两个交点，由图象可知当 $_{0 < a < 1}$ 时两函数只有一个交点，不符合，当 $_{a > 1}$ 时，因为函数 $y = a^{x} (a > 1)$ 的图象过点 $(0,1)$ ，而直线 $y = x + a$ 所过的点（0，a）一定在点
> >
> > (0,1)的上方,所以一定有两个交点.所以实数 a 的取值范围是 $\{a \mid a > 1\}$
> >
