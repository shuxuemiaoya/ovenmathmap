> [!faq]- 精品解析：2025年高考北京卷数学真题（解析版）解析
>
> > [!success]- **【答案】** ①.1 ②.15 【
>
> > [!note]- **【分析】**
> > 利用赋值法可求 $a_{0}$ ，利用换元法结合赋值法可求 $a_{1}+a_{2}+a_{3}+a_{4}$ 的值.
>
> > [!note]- **【解析】**
> > 令x=0，则 $a_{0}=1$ ，
> >
> > 又 $(1 - 2x)^{4} = a_{0} - 2a_{1}x + 4a_{2}x^{2} - 8a_{3}x^{3} + 16a_{4}x^{4}$
> >
> > 故 $(1 - 2x)^{4} = a_{0} + a_{1}(-2x) + a_{2}(-2x)^{2} + a_{3}(-2x)^{3} + a_{4}(-2x)^{4}$
> >
> > 令 $t = -2\chi$ ，则 $(1 + t)^{4} = a_{0} + a_{1}t + a_{2}t^{2} + a_{3}t^{3} + a_{4}t^{4}$
> >
> > 令 $t = 1$ ，则 $a_0 + a_1 + a_2 + a_3 + a_4 = 2^4$ ，故 $a_1 + a_2 + a_3 + a_4 = 15$
> >
> > 故
