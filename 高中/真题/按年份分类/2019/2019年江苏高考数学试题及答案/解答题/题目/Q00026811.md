19.设函数 $f(x) = (x - a)(x - b)(x - c),a,b,c\in \mathbb{R}$ ， $f^{\prime}(x)$ 为 $f(x)$ 的导函数.

(1) 若 $a = b = c$ ， $f(4) = 8$ ，求 $a$ 的值；

(2) 若 $a \neq b, b = c$ ，且 $f(x)$ 和 $f'(x)$ 的零点均在集合 $\{-3, 1, 3\}$ 中，求 $f(x)$ 的极小值；

(3) 若 $a = 0, 0 < b_{n}, 1, c = 1$ ，且 $f(x)$ 的极大值为 $M$ ，求证: $M \leq \frac{4}{27}$ .
