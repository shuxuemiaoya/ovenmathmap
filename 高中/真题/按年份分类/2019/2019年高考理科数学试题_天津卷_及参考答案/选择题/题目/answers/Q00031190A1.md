> [!faq]- 2019年高考理科数学试题(天津卷)及参考答案解析
>
> > [!success]- **【答案】** B
>
> > [!note]- **【分析】**
> > 分别求出两不等式的解集，根据两解集的包含关系确定.
>
> > [!note]- **【解析】**
> > $x^{2} - 5x <   0$ ，即 $0 <   x <   5$
> >
> > $\left|x - 1\right| <   1$ 等价于 $0 <   x <   2$ ，故 $0 <   x <   5$ 推不出 $\left|x - 1\right| <   1$
> >
> > 由 $|x-1|<1$ 能推出0<x<5。
> >
> > 故 “ $x^{2}-5x<0$ ” 是 “ $|x-1|<1$ ” 的必要不充分条件。
> >
> > 故选 B。
