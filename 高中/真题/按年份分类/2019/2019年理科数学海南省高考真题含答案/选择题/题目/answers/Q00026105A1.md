> > [!note]- **【解析】**

> > D

> > 解答： $\frac{M_1}{(R + r)^2} + \frac{M_2}{r^2} = (R + r)\frac{M_1}{R^3} \Rightarrow \frac{M_1}{R^2(1 + \alpha)^2} + \frac{M_2}{r^2} = (1 + \alpha)\frac{M_1}{R^2}$ 所以有 $\frac{M_2}{r^2} = \frac{M_1}{R^2}[(1 + \alpha) - \frac{1}{(1 + \alpha)^2}] = \frac{M_1}{R^2} \times \frac{3\alpha + 3\alpha^2 + \alpha^3}{(1 + \alpha)^2}$ 化简可得 $M_2 = \frac{M_1r^2}{R^2} \times \frac{3\alpha + 3\alpha^2 + \alpha^3}{(1 + \alpha)^2} = M_1 \times 3\alpha^3 \Rightarrow \alpha^3 = \frac{M_2}{3M_1}$ ，可得 $\sqrt[3]{\frac{M_2}{3M_1}} R$ 。
