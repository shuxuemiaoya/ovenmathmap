# 2019年普通高等学校招生全国统一考试

# 文科数学

注意事项：

1. 答卷前，考生务必将自己的姓名、考生号等填写在答题卡和试卷指定位置上。

2. 回答选择题时，选出每小题
答案后，用铅笔把答题卡对应题目的
答案标号涂黑。如需改动，用橡皮擦干净后，再选涂其他
答案标号。回答非选择题时，将
答案写在答题卡上。写在本试卷上无效。

3. 考试结束后，将本试卷和答题卡一并交回。
