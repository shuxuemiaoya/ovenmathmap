> [!faq]- 2019年全国统一高考数学试卷（理科）（新课标ⅲ）（含解析版）解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【分析】**
> > (1) $f'(x)=6x^{2}-2ax=6x\left(x-\frac{a}{3}\right)$ . 令 $f'(x)=6x\left(x-\frac{a}{3}\right)=0$ ，解得x=0，或 $\frac{a}{3}$ . 对a分类讨论，即可得出单调性.
> > (2) 对 $a$ 分类讨论, 利用
> > (1) 的结论即可得出.
>
> > [!note]- **【解析】**
> > 解：
> > （1） $f'(x)=6x^{2}-2ax=6x\left(x-\frac{a}{3}\right)$
> >
> > 令 $f'(x) = 6x \left( x - \frac{a}{3} \right) = 0$ ，解得 $x = 0$ ，或 $\frac{a}{3}$ .
> >
> > ①a=0 时， $f'(x)=6x^{2}\geq0$ ，函数 $f(x)$ 在 R 上单调递增.
> >
> > ② $a > 0$ 时，函数 $f(x)$ 在 $(- \infty, 0)$ ， $\left(\frac{a}{3}, +\infty\right)$ 上单调递增，在 $(0, \frac{a}{3})$ 上单调递减.
> >
> > ③ $a < 0$ 时，函数 $f(x)$ 在 $(- \infty, \frac{a}{3})$ ， $(0, +\infty)$ 上单调递增，在 $\left(\frac{a}{3}, 0\right)$ 上单调递减.
> > (2) 由
> > (1) 可得:
> >
> > ① $a \leq 0$ 时，函数 $f(x)$ 在[0,1]上单调递增. 则 $f(0) = b = -1, f(1) = 2 - a + b = 1$ ，解得 $b = -1, a = 0$ ，满足条件.
> >
> > ② $a > 0$ 时，函数 $f(x)$ 在 $[0, \frac{a}{3}]$ 上单调递减.
> >
> > $\frac{a}{3} \geq 1$ ，即 $a \geq 3$ 时，函数 $f(x)$ 在 $[0, 1]$ 上单调递减。则 $f(0) = b = 1, f(1) = 2 - a + b = -1$ ，解得 $b = 1, a = 4$ ，满足条件。
> >
> > ③ $0 < \frac{a}{3} < 1$ ，即 $0 < a < 3$ 时，函数 $f(x)$ 在 $[0, \frac{a}{3})$ 上单调递减，在 $(\frac{a}{3}, 1]$ 上单调递增. 则最小值 $f(\frac{a}{3}) = 2 \times (\frac{a}{3})^3 - a \times (\frac{a}{3})^2 + b = -1$
> >
> > 化为： $-\frac{a^3}{27} + b = -1$ 而 $f(0) = b, f(1) = 2 - a + b$ ，∴最大值为 $b$ 或 $2 - a + b$
> >
> > 若： $-\frac{a^{3}}{27}+b=-1,\quad b=1$ ，解得 $a=3\sqrt[3]{2}>3$ ，矛盾，舍去.
> >
> > 若： $-\frac{a^3}{27} + b = -1, 2 - a + b = 1$ ，解得 $a = \pm 3\sqrt{3}$ ，或0，矛盾，舍去.
> >
> > 综上可得：存在 $a, b$ ，使得 $f(x)$ 在区间 $[0, 1]$ 的最小值为 -1 且最大值为 1.
> >
> > a, b 的所有值为： $\left\{\begin{aligned}a=0\\b=-1\end{aligned}\right.$ ，或 $\left\{\begin{aligned}a=4\\b=1\end{aligned}\right.$
> >
> > 【点评】本题考查了利用导数研究函数的单调性、方程与不等式的解法、分类讨论方法、等价转化方法，考查了推理能力与计算能力，属于难题.
