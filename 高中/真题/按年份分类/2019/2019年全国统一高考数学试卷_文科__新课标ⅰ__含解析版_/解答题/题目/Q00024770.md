23. 已知 $a, b, c$ 为正数，且满足 $abc = 1$ 。证明：

(1) $\frac{1}{a} + \frac{1}{b} + \frac{1}{c} \leq a^2 + b^2 + c^2$ ;

(2) $(a+b)^{3}+(b+c)^{3}+(c+a)^{3}\geq24.$
