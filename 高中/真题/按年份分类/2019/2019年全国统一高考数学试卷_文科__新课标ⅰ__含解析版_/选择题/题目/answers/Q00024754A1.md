> [!faq]- 2019年全国统一高考数学试卷（文科）（新课标ⅰ）（含解析版）解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【分析】**
> > 利用诱导公式变形，再由两角和的正切求解.
>
> > [!note]- **【解析】**
> > 解： $\tan 255^{\circ} = \tan (180^{\circ} + 75^{\circ}) = \tan 75^{\circ} = \tan (45^{\circ} + 30^{\circ})$ $= \frac{\tan 45^{\circ} + \tan 30^{\circ}}{1 - \tan 45^{\circ}\tan 30^{\circ}} = \frac{1 + \frac{\sqrt{3}}{3}}{1 - 1\times\frac{\sqrt{3}}{3}} = \frac{3 + \sqrt{3}}{3 - \sqrt{3}} = \frac{(3 + \sqrt{3})^{2}}{6} = \frac{12 + 6\sqrt{3}}{6} = 2 + \sqrt{3}.$ 故选： $D$
> >
> > 【点评】本题考查三角函数的取值，考查诱导公式与两角和的正切，是基础题.
