> [!faq]- 2019年全国统一高考数学试卷（理科）（新课标ⅰ）（含解析版）解析
>
> > [!success]- **【答案】** C
>
> > [!note]- **【分析】**
> > 利用一元二次不等式的解法和交集的运算即可得出.
>
> > [!note]- **【解析】**
> > 分析】利用一元二次不等式的解法和交集的运算即可得出.
> >
> > $$
> > \because M = \{x \mid - 4 <   x <   2 \}, N = \{x \mid x ^ {2} - x - 6 <   0 \} = \{x \mid - 2 <   x <   3 \}
> > $$
> >
> > $$
> > \therefore M \cap \mathbf {N} = \{x | - 2 <   x <   2 \}
> > $$
> >
> > 故选：C.
> >
> > 【点评】本题考查了一元二次不等式的解法和交集的运算，属基础题.
