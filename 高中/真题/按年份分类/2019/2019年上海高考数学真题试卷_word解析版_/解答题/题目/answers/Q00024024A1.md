> [!faq]- 2019年上海高考数学真题试卷（word解析版）解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【分析】**
> > 根据几何图形作出线面角度求解；建立坐标系计算平面的法向量求解..
>
> > [!note]- **【解析】**
> > （1）依题意： $A_{1}A \perp$ 面ABCD，连接AC，则 $A_{1}C$ 与平面ABCD所成夹角为 $\angle A_{1}CA$ ；
> >
> > $\because A_{1}A = 5, AC = \sqrt{3^{2} + 4^{2}} = 5, \therefore \triangle A_{1}CA$ 为等腰直角， $\angle A_{1}CA = \frac{\pi}{4}$ ;
> >
> > ∴ 直线 $A_{1}C$ 与平面 ABCD 的夹角为 $\frac{\pi}{4}$ .
> > (2) 法一（空间向量）：如图建立坐标系：
> >
> > $$
> > A (0, 0, 0), C (3, 4, 0), A _ {1} (0, 0, 5), M (3, 0, 2)
> > $$
> >
> > $$
> > \overrightarrow {A C} = (3, 4, 0), \quad A _ {1} \bar {C} = (3, 4, - 5), \quad \overrightarrow {M C} = (0, 4, - 2)
> > $$
> >
> > ∴求平面 $A_{1}MC$ 的法向量 $\vec{n}=(x,y,z)$ :
> >
> > $\left\{ \begin{array}{l} \vec{n} \cdot \overrightarrow{A_{1}C} = 3x + 4y - 5z = 0 \\ \vec{n} \cdot \overrightarrow{MC} = 4y - 2z = 0 \end{array} \right.$ ，得： $\vec{n} = (2,1,2)$
> >
> > A 到平面 $A_{1}MC$ 的距离为： $d=\frac{\left|\overrightarrow{AC}\cdot\vec{n}\right|}{\left|\vec{n}\right|}=\frac{3\times2+4\times1}{\sqrt{2^{2}+1^{2}+2^{2}}}=\frac{10}{3}$
> >
> > 法二（等体积法）：利用 $V_{A - A_1MC} = V_{C - A_1AM}$ 求解，求 $S_{\triangle A_1MC}$ 时，需要求出三边长（不是特殊三角形），利用 $S_{\triangle} = \frac{1}{2} ab\sin C$ 求解.
> >
> > 【归纳与总结】本题考查点到平面的距离的求法，考查异面直线所成角的正切值的求法，考查空间中线线、线面、面面间的位置关系等基础知识，考查运算求解能力，考查函数与方程思想，是基础题.
