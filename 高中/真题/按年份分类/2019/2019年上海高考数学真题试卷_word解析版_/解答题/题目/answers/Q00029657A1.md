> [!faq]- 2019年上海高考数学真题试卷（word解析版）解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【分析】**
> > 根据定义式子代入即可求解 $a_4$ ；通过证明逆否命题证明；去掉具有P性质三项，求和
>
> > [!note]- **【解析】**
> > （1） $a_4$ 可能的值为3,5,7；
> > (2) 要证明 $\left\{a_{n}\right\}$ 中存在满足性质 $P$ ，
> >
> > 即证明：若数列 $\left\{a_{n}\right\}$ 中不存在满足性质 $P$ 的项，则 $a_{n}$ 为等差数列（原命题的逆否命题）显然 $a_1 = a, a_2 = a + d, a_3 = a_i + d, (i = 1,2)$
> >
> > i=1 时， $a_{3}=a_{1}+d=a_{2}$ ，满足性质 P，不成立；
> >
> > i=2 时， $a_{3}=a_{2}+d=a+2d$ ， $a_{4}=a_{i}+d,i=1,2,3$
> >
> > 同理 $i = 1$ 时， $a_4 = a_2$ 不成立； $i = 2$ 时， $a_4 = a_3$
> >
> > 所以 $a_4 = a_3 + d = a + 3d$
> >
> > 以此类推 $a_{n} = a_{i} + d, i \in [1, n - 1]$ ，其中 $a_{n} = a_{i} + d, i \in [1, n - 2]$ 时不成立
> >
> > 只有 $i = n - 1$ ，即 $a_{n} = a_{n - 1} + d$ 成立，即 $\{a_n\}$ 为等差数列，
> >
> > 即得证明： $\{a_{n}\}$ 不为等差数列， $\{a_{n}\}$ 中存在满足性质 $P$
> > (3) 将数列中具有性质 P 的三项去掉，形成一个新数列 $\left\{b_{n}\right\}$
> >
> > $b_{1} = a_{1} = a, n \in [2,97]$ 时， $b_{n} = a_{i} + d, i \in [1, n - 1]$ ，且 $\left\{b_{n}\right\}$ 中元素满足性质 P 的项，
> >
> > 根据
> > （2） $\{b_n\}$ 为等差数列，所以
> >
> > $$
> > b _ {1} + b _ {2} + \dots + b _ {9 7} = 9 7 b _ {1} + \frac {9 7 \times 9 6}{2} \times d
> > $$
> >
> > 即 $b_{1} + b_{2} + \dots +b_{97} = 97a + 4656d$
> >
> > 又因为三项去掉和为 c，所以 $a_{1} + a_{2} + \cdots + a_{100} = 97a + 4656d + c$
> >
> > 【归纳与总结】本题考查新定义“性质 P”的理解和运用，考查等差数列和等比数列的定义和通项公式的运用，考查分类讨论思想方法，以及运算能力和推理能力，属于难题.
