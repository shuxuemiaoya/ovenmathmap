> [!faq]- 2019年上海高考数学真题试卷（word解析版）解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【分析】**
> > 将不等式具体化，直接解不等式；分离参数得到新函数，研究新函数的最值与值域.
>
> > [!note]- **【解析】**
> > （1）当a=1时， $f(x)=x+\frac{1}{x+1}$ ;
> >
> > 代入原不等式： $x + \frac{1}{x + 1} + 1 < x + 1 + \frac{1}{x + 2}$ ；即： $\frac{1}{x + 1} < \frac{1}{x + 2}$
> >
> > 移项通分： $\frac{1}{(x + 1)(x + 2)} < 0$ ，得：- $2 < x < -1$
> > (2) 依题意: $f(x) = ax + \frac{1}{x + 1} = 0$ 在 $x \in [1,2]$ 上有解
> >
> > 参编分离： $a = -\frac{1}{x(x + 1)}$ ，即求 $g(x) = -\frac{1}{x(x + 1)}$ 在 $x\in [1,2]$ 值域，
> >
> > $x(x + 1)$ 在 $x\in [1,2]$ 单调递增， $x(x + 1)\in [2,6]$
> >
> > $-\frac{1}{x(x + 1)} \in [-\frac{1}{6}, -\frac{1}{2}]$ ，故： $a \in [-\frac{1}{6}, -\frac{1}{2}]$ .
> >
> > 【归纳与总结】本题考查了分式不等式的解法、分式函数最值与值域的求解，也考查了转化与划归思想的应用.
