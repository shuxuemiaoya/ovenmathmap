> [!faq]- 2019年高考真题数学【理】(山东卷)（含解析版）解析
>
> > [!success]- **【答案】** B
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > 由题意设椭圆的方程为 $\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1 (a > b > 0)$ ，连接 $F_1A$ ，令 $|F_2B| = m$ ，则 $|AF_2| = 2m$ ， $|BF_1| = 3m$ 。由椭圆的定义知， $4m = 2a$ ，得 $m = \frac{\frac{a}{2}}{2}$ ，故 $|F_2A| = a = |F_1A|$ ，则点 $A$ 为椭圆 $C$ 的上顶点或下顶点。令 $\angle OAF_2 = \theta (O$ 为坐标原点)，则 $\sin \theta = \frac{\frac{c}{a}}{a} = \frac{1}{a}$ 。在等腰三角形 $ABF_1$ 中， $\cos 2\theta = \frac{(2m)^2 + (3m)^2 - (3m)^2}{2 \times 2m \cdot 3m} = \frac{1}{3}$ ，因为 $\cos 2\theta = 1 - 2\sin^2\theta$ ，所以 $\frac{1}{3} = 1 - 2\left(\frac{1}{a}\right)^2$ ，得 $a^2 = 3$ 。又 $c^2 = 1$ ，所以 $b^2 = a^2 - c^2 = 2$ ，椭圆 $C$ 的方程为 $\frac{x^2}{3} + \frac{y^2}{2} = 1$ ，故选 B.
