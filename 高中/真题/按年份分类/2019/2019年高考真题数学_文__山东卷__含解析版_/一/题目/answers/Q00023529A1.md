> [!faq]- 2019年高考真题数学【文】(山东卷)（含解析版）解析
>
> > [!success]- **【答案】** (1) 见解析; (2) 见解析
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > （1） $\because a^{2}+b^{2}\geq2ab,\ b^{2}+c^{2}\geq2bc,\ c^{2}+a^{2}\geq2ac$ ，
> >
> > $\therefore 2a^{2} + 2b^{2} + 2c^{2}\geq 2ab + 2bc + 2ac$ ，即 $a^2 +b^2 +c^2\geq ab + bc + ac$ ，当且仅当 $a = b = c$ 时取等
> >
> > 号∵abc=1且a，b，c都为正数，∴ab= $\frac{1}{c}$ ，bc= $\frac{1}{a}$ ，ac= $\frac{1}{b}$ ，故 $\frac{1}{a}+\frac{1}{b}+\frac{1}{c}\leq a^{2}+b^{2}+c^{2}$
> > (2) $\because (a + b)^{3} + (b + c)^{3} + (c + a)^{3} \geq 3\sqrt[3]{(a + b)^{3}(b + c)^{3}(c + a)^{3}}$
> >
> > 当且仅当 $(a+b)^{3}=(b+c)^{3}=(c+a)^{3}$ 时等号成立，即a=b=c时等号成立.又
> >
> > $$
> > 3 \sqrt [ 3 ]{(a + b) ^ {3} (b + c) ^ {3} (c + a) ^ {3}} = 3 (a + b) (b + c) (c + a) \geq 3 \times 2 \sqrt {a b} \cdot 2 \sqrt {b c} \cdot 2 \sqrt {a c} = 2 4 a b c
> > $$
> >
> > 当且仅当 $a = b = c$ 时等号成立， $\because abc = 1$ ，故 $3\sqrt[3]{(a + b)^{3}(b + c)^{3}(c + a)^{3}} \geq 24abc = 24$ ，即得
> >
> > $$
> > (a + b) ^ {3} + (b + c) ^ {3} + (c + a) ^ {3} \geq 2 4
> > $$
