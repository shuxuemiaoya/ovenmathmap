> [!faq]- 2019年高考真题数学【文】(山东卷)（含解析版）解析
>
> > [!success]- **【答案】** 略
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > 答案: 略
> >
> > 解答：
> >
> > (1)曲线 C: 由题意得 $x = \frac{1 - t^{2}}{1 + t^{2}} = -1 + \frac{2}{1 + t^{2}}$ 即 $x + 1 = \frac{2}{1 + t^{2}}$ ，则 $t = \frac{y}{2(x + 1)}$ ，然后代入即可得到 $\frac{y^{2}}{4} + x^{2} = 1$
> >
> > 而直线 $l$ ：将 $x = \rho \cos \theta ,y = \rho \sin \theta$ 代入即可得到 $2x + \sqrt{3} y + 11 = 0$
> >
> > (2) 将曲线化成参数方程形式为 $\left\{\begin{aligned}x&=\cos\theta\\ y&=2\sin\theta\end{aligned}\right.$ ( $\theta$ 为参数)
> >
> > $$
> > d = \frac {\left| 2 \cos \theta + 2 \sqrt {3} \sin \theta + 1 1 \right|}{\sqrt {7}} = \frac {\left| 4 \sin \left(\theta + \frac {\pi}{6}\right) + 1 1 \right|}{\sqrt {7}}
> > $$
> >
> > 所以当 $\theta +\frac{\pi}{6} = \frac{3\pi}{2}$ 时，最小值为 $\sqrt{7}$
