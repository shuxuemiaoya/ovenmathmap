> [!faq]- 2011年浙江高考数学(理科)试卷(含答案)解析
>
> > [!success]- **【答案】** A
>
> > [!note]- **【分析】**
> > 因为 “0<ab<1”⇒“a< $\frac{1}{b}$ ”或 “b> $\frac{1}{a}$ ”．“a< $\frac{1}{b}$ ”或 “b> $\frac{1}{a}$ ”不能推出 “0<ab<1”，所以 “0<ab<1”是 “a< $\frac{1}{b}$ ”
>
> > [!note]- **【解析】**
> > 解：∵a、b为实数，0<ab<1，
> >
> > $$
> > \therefore “ 0 <   a <   ^ {\frac {1}{b}} ” \text {或} “ 0 > b > ^ {\frac {1}{a}},
> > $$
> >
> > $$
> > \therefore \text { “ } 0 <   a b <   1 \text { ” } \Rightarrow \text { “ } a <   ^ {\frac {1}{b}} \text { ” } \text { 或 } \text { “ } b > ^ {\frac {1}{a}} \text { ” }.
> > $$
> >
> > “a< $\frac{1}{b}$ ”或“b> $\frac{1}{a}$ ”不能推出“0<ab<1”，
> >
> > 所以 “0<ab<1” 是 “a< $\frac{1}{b}$ ” 或 “b> $\frac{1}{a}$ ” 的充分而不必要条件.
> >
> > 故选A.
> >
> > 点评：本题考查充分分条件、必要条件和充要条件，解题时要注意基本不等式的合理运用.
