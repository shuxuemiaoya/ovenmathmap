> [!faq]- 2011年重庆市高考数学试卷(文科)含答案解析
>
> > [!success]- **【答案】** 为： $2 - \log_{2}3$ 【点评】本题考查指数的运算法则，基本不等式求最值、不等式的性质等问题，综合性较强. ## 三、解答题（共6小题，满分75分）
>
> > [!note]- **【分析】**
> > 由基本不等式得 $2^{a} + 2^{b}\geq 2\sqrt{2^{a}2^{b}} = 2\times 2^{\frac{a + t}{2}}$ ，可求出 $2^{a + b}$ 的范围，
>
> > [!note]- **【解析】**
> > 解：由基本不等式得 $2^{a + 2^b}\geq 2\sqrt{2^a2^b} = 2\times 2^{\frac{a + b}{2}}$ ，即 $2^{a + b}\geq 2\sqrt{2^a2^b} = 2\times 2^{\frac{a + b}{2}}$ ，所以 $2^{a + b}\geq 4,$
> >
> > 令 $t = 2^{a + b}$ ，由 $2^{a} + 2^{b} + 2^{c} = 2^{a + b + c}$ 可得 $2^{a + b} + 2^{c} = 2^{a + b}2^{c}$ ，所以 $2^{c} = \frac{t}{t - 1} = 1 + \frac{1}{t - 1}$
> >
> > 因为 $t \geq 4$ ，所以 $1 < \frac{t}{t - 1} \leqslant \frac{4}{3}$ ，即 $1 < 2^c \leqslant \frac{4}{3}$ ，所以 $0 < c \leqslant \log_2 \frac{4}{3} - 2 - \log_2 3$
> >
> > 故
