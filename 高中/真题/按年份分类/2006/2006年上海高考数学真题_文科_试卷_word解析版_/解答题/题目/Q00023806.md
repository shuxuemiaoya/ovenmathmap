22. 解(1) 由已知得 $\sqrt{2^b} = 4, \therefore b = 4$ .

(2) $\because c \in [1,4], \therefore \sqrt{c} \in [1,2],$

于是,当 $x=\sqrt{c}$ 时, 函数 $f(x)=x+\frac{c}{x}$ 取得最小值 $2\sqrt{c}$ .

$f(1)-f(2)=\frac{c-2}{2},$

当 $1 \leq c \leq 2$ 时, 函数 $f(x)$ 的最大值是 $f(2)=2+\frac{c}{2}$ ;

当 $2 \leq c \leq 4$ 时, 函数 $f(x)$ 的最大值是 $f(1) = 1 + c$ .

(3)设 $0 < x_{1} < x_{2}, g(x_{2}) - g(x_{1}) = x_{2}^{n} + \frac{c}{x_{2}^{n}} - x_{1}^{n} - \frac{c}{x_{1}^{n}} = (x_{2}^{n} - x_{1}^{n})(1 - \frac{c}{x_{1}^{n}x_{2}^{n}})$ .

当 $\sqrt[2n]{C} < x_1 < x_2$ 时， $g(x_2) > g(x_1)$ ，函数 $g(x)$ 在 $[\sqrt[2n]{C}, +\infty)$ 上是增函数；

当 $0 < \mathrm{x}_1 < \mathrm{x}_2 < \sqrt[2n]{C}$ 时， $\mathrm{g}(\mathrm{x}_2) > \mathrm{g}(\mathrm{x}_1)$ ，函数 $\mathrm{g}(\mathrm{x})$ 在 $(0, \sqrt[2n]{C}]$ 上是减函数.

当 n 是奇数时, $g(x)$ 是奇函数,

函数 $g(x)$ 在 $(-∞, -\sqrt[2n]{a}]$ 上是增函数，在 $[-\sqrt[2n]{a}, 0)$ 上是减函数.

当 n 是偶数时, $g(x)$ 是偶函数,

函数 $g(x)$ 在 $(-∞, -\sqrt[2n]{a})$ 上是减函数，在 $[-\sqrt[2n]{a}, 0]$ 上是增函数.
