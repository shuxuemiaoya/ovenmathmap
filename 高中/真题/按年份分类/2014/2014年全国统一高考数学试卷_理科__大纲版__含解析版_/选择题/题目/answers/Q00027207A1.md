> [!faq]- 2014年全国统一高考数学试卷（理科）（大纲版）（含解析版）解析
>
> > [!success]- **【答案】** B
>
> > [!note]- **【分析】**
> > 求解一元二次不等式化简集合 M，然后直接利用交集运算求解.
>
> > [!note]- **【解析】**
> > 分析】求解一元二次不等式化简集合 M，然后直接利用交集运算求解.
> >
> > 【
> > 解答】解：由 $x^{2}-3x-4<0$ ，得 $-1<x<4$ 。
> >
> > $$
> > \therefore M = \{x \mid x ^ {2} - 3 x - 4 <   0 \} = \{x \mid - 1 <   x <   4 \},
> > $$
> >
> > 又 $N=\{x \mid 0 \leq x \leq 5\}$ ,
> >
> > $$
> > \therefore M \cap N = \{x \mid - 1 <   x <   4 \} \cap \{x \mid 0 \leq x \leq 5 \} = [ 0, 4).
> > $$
> >
> > $$
> > - 1 0 \quad 4 5
> > $$
> >
> > 故选：B.
> >
> > 【点评】本题考查了交集及其运算，考查了一元二次不等式的解法，是基础题.
