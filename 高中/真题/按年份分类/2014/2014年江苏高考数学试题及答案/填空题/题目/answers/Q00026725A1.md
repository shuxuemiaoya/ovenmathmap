> [!faq]- 2014年江苏高考数学试题及答案解析
>
> > [!success]- **【答案】** 为：24. 点评：本题考查了频率分布直方图，在频率分布直方图中频率=小矩形的面积=小矩形的高× $$ \text { 组距 } = \frac {\text { 频数 }}{\text { 样本容量 }}. $$
>
> > [!note]- **【分析】**
> > 根据频率=小矩形的面积=小矩形的高×组距底部求出周长小于 $100 \mathrm{~cm}$ 的频率, 再根据频数=样本容量×频率求出底部周长小于 $100 \mathrm{~cm}$ 的频数.
>
> > [!note]- **【解析】**
> > 分析: 根据频率=小矩形的面积=小矩形的高×组距底部求出周长小于 $100 \mathrm{~cm}$ 的频率, 再根据频数=样本容量×频率求出底部周长小于 $100 \mathrm{~cm}$ 的频数.
> >
> > 解答：解：由频率分布直方图知：底部周长小于 $100\mathrm{cm}$ 的频率为 $(0.015 + 0.025)\times 10 = 0.4$ ， $\therefore$ 底部周长小于 $100\mathrm{cm}$ 的频数为 $60\times 0.4 = 24$ （株）．故
> > 答案为：24.
