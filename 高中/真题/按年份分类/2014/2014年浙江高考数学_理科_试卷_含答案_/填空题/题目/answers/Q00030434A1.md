> [!faq]- 2014年浙江高考数学(理科)试卷(含答案)解析
>
> > [!success]- **【答案】** $\frac{\sqrt{5}}{2}$ 17
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > 2】不妨设 $a = 1$ ，渐近线方程为 $\frac{x^2}{1^2} -\frac{y^2}{b^2} = 0$ 即 $b^{2}x^{2} - y^{2} = 0$ 由 $\left\{ \begin{array}{l}b^{2}x^{2} - y^{2} = 0\\ x - 3y + m = 0 \end{array} \right.$ 消去 $x$ 得 $(9b^{2} - 1)y^{2} - 6b^{2}my + b^{2}m = 0$ 设AB中点为 $Q(x_0,y_0)$ ，由韦达定理得： $y_{0} = \frac{3b^{2}m}{9b^{2} - 1}\dots\dots①$ 又 $x_0 = 3y_0 - m$ ，由 $k_{PQ}\mathbb{I}k_l = -1$ 得 $\frac{y_0}{x_0 - m}\mathbb{I}\frac{1}{3} = -1$ 即得 $\frac{y_0}{3y_0 - 2m}\mathbb{I}\frac{1}{3} = -1$ 得 $y_0 = \frac{3}{5} m$ 代入①得 $\frac{3b^2m}{9b^2 - 1} = \frac{3}{5} m$ 得 $b^{2} = \frac{1}{4}$ ，所以 $c^2 = a^2 +b^2 = 1 + \frac{1}{4} = \frac{5}{4}$ ，所以 $c = \frac{\sqrt{5}}{2}$ ，得 $e = \frac{c}{a} = c = \frac{\sqrt{5}}{2}$
