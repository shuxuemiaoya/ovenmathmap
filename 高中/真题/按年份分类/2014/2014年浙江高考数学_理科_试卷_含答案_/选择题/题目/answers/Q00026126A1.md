> [!faq]- 2014年浙江高考数学(理科)试卷(含答案)解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > 当 $a = b = 1$ 时， $(a + bi)^{2} = (1 + i)^{2} = 2i$ ，反之， $(a + bi)^{2} = 2i$
> >
> > 即 $a^2 - b^2 + 2abi = 2i$ ，则 $\left\{ \begin{array}{l} a^2 - b^2 = 0 \\ 2ab = 2 \end{array} \right.$ 解得 $\left\{ \begin{array}{l} a = 1 \\ b = 1 \end{array} \right.$ 或 $\left\{ \begin{array}{l} a = -1 \\ b = -1 \end{array} \right.$
