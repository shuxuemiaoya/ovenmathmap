> [!faq]- 2014年重庆市高考数学试卷(文科)含答案解析
>
> > [!success]- **【答案】** D
>
> > [!note]- **【分析】**
> > 基本不等式；对数的运算性质.
> > 函数的性质及应用.
>
> > [!note]- **【解析】**
> > 利用对数的运算法则可得 $b = \frac{3a}{a - 4} > 0, a > 4$ ，再利用基本不等式即可得出
> > 解：∵3a+4b>0，ab>0，
> > ∴a>0. b>0
> > ∴log $_{4}$ (3a+4b) = log $_{2}$ √ab，
> >
> > $\therefore \log_4(3a + 4b) = \log_4(ab)$ $\therefore 3a + 4b = ab, a \neq 4, a > 0. b > 0$ $\therefore b = \frac{3a}{a - 4} > 0,$ $\therefore a > 4,$ 则 $a + b = a + \frac{3a}{a - 4} = a + \frac{3(a - 4) + 12}{a - 4} = (a - 4) + \frac{12}{a - 4} +7$ $\geqslant 2\sqrt{(a - 4)\cdot\frac{12}{a - 4}} +7 = 4\sqrt{3} +7$ ，当且仅当 $a = 4 + 2\sqrt{3}$ 取等号.  
> > 故选：D.  
> > 本题考查了对数的运算法则、基本不等式的性质，属于中档题.
