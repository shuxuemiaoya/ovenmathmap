> [!faq]- 2014年重庆市高考数学试卷(文科)含答案解析
>
> > [!success]- **【答案】** $\frac{\sqrt{2}}{2}
>
> > [!note]- **【分析】**
> > $$
> > \mathrm{y} = \text { A   s   i   n } (\omega \mathrm{x} + \varphi)
> > $$
>
> > [!note]- **【解析】**
> > 解：函数 $f(x) = \sin (\omega x + \varphi) (\omega > 0, -\frac{\pi}{2} \leqslant \varphi < \frac{\pi}{2})$ 图象上每一点的横坐标缩短为原来的一半，纵坐标不变，可得函数 $y = \sin (2\omega x + \varphi)$ 的图象。
> > 再把所得图象再向右平移 $\frac{\pi}{6}$ 个单位长度得到函数 $y=\sin[2\omega(x-\frac{\pi}{6})+\varphi)]$ $=\sin(2\omega x+\varphi-\frac{\pi}{3}\omega)=\sin x$ 的图象， $\therefore 2\omega=1$ ，且 $\varphi-\frac{\pi}{3}\omega=2k\pi, k\in z,$ $\therefore \omega=\frac{1}{2}, \varphi=\frac{\pi}{6}, \therefore f(x)=\sin(\frac{1}{2}x+\frac{\pi}{6}),$ $\therefore f(\frac{\pi}{6})=\sin(\frac{\pi}{12}+\frac{\pi}{6})=\sin\frac{\pi}{4}=\frac{\sqrt{2}}{2}.$ 故答案为： $\frac{\sqrt{2}}{2}.$
> >
> > 点评：
> >
> > 本题主要考查函数 $y = A \sin (\omega x + \varphi)$ 的图象变换规律，属于中档题.
