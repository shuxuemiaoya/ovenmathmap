> [!faq]- 2014年高考真题数学【理】(山东卷)（含解析版）解析
>
> > [!success]- **【答案】** 3
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > 根据判断条件 $x^{2} - 4x + 3\leq 0$ ，得 $1\leq x\leq 3$
> >
> > 输入 $x = 1$
> >
> > 第一次判断后循环， $x = x + 1 = 2, n = n + 1 = 1$
> >
> > 第二次判断后循环， $x = x + 1 = 3, n = n + 1 = 2$
> >
> > 第三次判断后循环， $x = x + 1 = 4, n = n + 1 = 3$
> >
> > 第四次判断不满足条件，退出循环，输出 n=3
