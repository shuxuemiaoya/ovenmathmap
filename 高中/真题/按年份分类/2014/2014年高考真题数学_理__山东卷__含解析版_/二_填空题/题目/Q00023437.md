19、解：（Ⅰ） $d = 2, S_{1} = a_{1}, S_{2} = 2a_{1} + d, S_{4} = 4a_{1} + 6d$

$\because S_{1},S_{2},S_{4}$ 成等比数列

$$
\therefore S _ {2} ^ {2} = S _ {1} S _ {4}
$$

解得 $a_{1} = 1, \therefore a_{n} = 2n - 1$

(II) $b_{n}=(-1)^{n-1}\frac{4n}{a_{n}a_{n+1}}=(-1)^{n-1}\left(\frac{1}{2n-1}+\frac{1}{2n+1}\right)$

当 n 为偶数时， $T_{n}=(1+\frac{1}{3})-(\frac{1}{3}+\frac{1}{5})+(\frac{1}{5}+\frac{1}{7})-\cdots+(\frac{1}{2n-3}+\frac{1}{2n-1})-(\frac{1}{2n-1}+\frac{1}{2n+1})$

当 $n$ 为奇数时， $T_{n} = (1 + \frac{1}{3}) - (\frac{1}{3} + \frac{1}{5}) + (\frac{1}{5} + \frac{1}{7}) - \dots - (\frac{1}{2n - 3} + \frac{1}{2n - 1}) + (\frac{1}{2n - 1} + \frac{1}{2n + 1})$

$$
\therefore T _ {n} = 1 + \frac {1}{2 n + 1} = \frac {2 n + 2}{2 n + 1}
$$

$\therefore T_{n} = \left\{ \begin{array}{l} \frac{2n}{2n + 1}, n \text{为偶数} \\ \frac{2n + 2}{2n + 1}, n \text{为奇数} \end{array} \right.$
