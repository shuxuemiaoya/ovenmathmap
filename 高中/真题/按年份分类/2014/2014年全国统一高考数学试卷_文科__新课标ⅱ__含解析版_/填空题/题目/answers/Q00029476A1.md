> [!faq]- 2014年全国统一高考数学试卷（文科）（新课标ⅱ）（含解析版）解析
>
> > [!success]- **【答案】** 为： $\frac{1}{2}$ . 【点评】本题考查了数列递推公式的简单应用，即给 n 具体的值代入后求数列的 项，属于基础题. 三、解答题：
>
> > [!note]- **【分析】**
> > 根据 $a_{8} = 2$ ，令 $n = 7$ 代入递推公式 $a_{n + 1} = \frac{1}{1 - a_n}$ ，求得 $a_7$ ，再依次求出 $a_6, a_5$ 的
>
> > [!note]- **【解析】**
> > 解：由题意得， $a_{n + 1} = \frac{1}{1 - a_n}$ ， $a_8 = 2$
> >
> > 令 $n = 7$ 代入上式得， $a_{8} = \frac{1}{1 - a_{7}}$ ，解得 $a_{7} = \frac{1}{2}$ ；
> >
> > 令 $n = 6$ 代入得， $a_{7} = \frac{1}{1 - a_{6}}$ ，解得 $a_{6} = -1$ ;
> >
> > 令 $n = 5$ 代入得， $a_{6} = \frac{1}{1 - a_{5}}$ ，解得 $a_{5} = 2$ ；
> >
> > 根据以上结果发现，求得结果按 $2, \frac{1}{2}, -1$ 循环，
> >
> > ∵8÷3=2...2，故 $a_{1}=\frac{1}{2}$
> >
> > 故
