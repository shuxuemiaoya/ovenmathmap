> [!faq]- 2014年全国统一高考数学试卷（文科）（新课标ⅱ）（含解析版）解析
>
> > [!success]- **【答案】** B
>
> > [!note]- **【分析】**
> > 分子分母同乘以分母的共轭复数 $1+i$ 化简即可.
>
> > [!note]- **【解析】**
> > 解：化简可得 $\frac{1 + 3\mathrm{i}}{1 - \mathrm{i}} = \frac{(1 + 3\mathrm{i})(1 + \mathrm{i})}{(1 - \mathrm{i})(1 + \mathrm{i})} = \frac{1 - 3 + 4\mathrm{i}}{1 - \mathrm{i}^2} = \frac{-2 + 4\mathrm{i}}{2} = -1 + 2\mathrm{i}$
> >
> > 故选：B.
> >
> > 【点评】本题考查复数代数形式的化简，分子分母同乘以分母的共轭复数是解决
> >
> > 问题的关键，属基础题。
