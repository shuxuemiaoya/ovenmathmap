> [!faq]- 2014年高考浙江文科数学试题及答案(精校版)解析
>
> > [!success]- **【答案】** C
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > 因为 $y = \sin 3x + \cos 3x = \sqrt{2} \sin \left(3x + \frac{\pi}{4}\right)$ ，所以将函数 $y = \sqrt{2} \sin 3x$ 的图象向左平移 $\frac{\pi}{12}$ 个单位长得函数 $y = \sqrt{2} \sin 3(x + \frac{\pi}{12})$ ，即得函数 $y = \sin 3x + \cos 3x$ 的图象，选 C. 点评：本题考查三角函数的图象的平移变换，公式 $\sin x + \cos x = \sqrt{2} \sin \left( x + \frac{\pi}{4} \right)$ 的运用，容易题.
