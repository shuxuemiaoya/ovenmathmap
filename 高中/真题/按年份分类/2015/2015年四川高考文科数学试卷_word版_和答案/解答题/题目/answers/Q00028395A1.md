> > [!note]- **【解析】**
> > 分析：直接利用并集求解法则求解即可.
> >
> > 解答：解：集合 $A = \{x\mid -1 <   x <   2\}$ ，集合 $B = \{x|1 <   x <   3\}$ 则 $\mathrm{AUB} = \{\mathrm{x}\mid -1 <   \mathrm{x} <   3\}$ 故选：A.
