> [!faq]- 2015年浙江高考数学(理科)试卷(含答案)解析
>
> > [!success]- **【答案】** $\pi$ ； $[\mathrm{k}\pi +\frac{3\pi}{8},\mathrm{k}\pi +\frac{7\pi}{8} ]$ （ $\mathbf{k}\in \mathbb{Z})$
>
> > [!note]- **【分析】**
> > 由三角函数公式化简可得 $f(x) = \frac{\sqrt{2}}{2}\sin \left(2x - \frac{\pi}{4}\right) + \frac{3}{2}$ ，易得最小正周期，解不等式 $2k\pi + \frac{\pi}{2} \leq 2x - \frac{\pi}{4} \leq 2k\pi + \frac{3\pi}{2}$ 可得函数的单调递减区间.
>
> > [!note]- **【解析】**
> > 解：化简可得 $f(x) = \sin^2 x + \sin x \cos x + 1$
> >
> > $$
> > = \frac {1}{2} (1 - \cos 2 x) + \frac {1}{2} \sin 2 x + 1
> > $$
> >
> > $$
> > = \frac {\sqrt {2}}{2} \sin (2 x - \frac {\pi}{4}) + \frac {3}{2},
> > $$
> >
> > ∴原函数的最小正周期为 $T=\frac{2\pi}{2}=\pi$ ,
> >
> > 由 $2k\pi + \frac{\pi}{2} \leq 2x - \frac{\pi}{4} \leq 2k\pi + \frac{3\pi}{2}$ 可得 $k\pi + \frac{3\pi}{8} \leq x \leq k\pi + \frac{7\pi}{8}$ ,
> >
> > ∴函数的单调递减区间为 $\left[k\pi+\frac{3\pi}{8},k\pi+\frac{7\pi}{8}\right]$ ( $k\in Z$ )
> >
> > 故答案为： $\pi$ ； $[\mathrm{k}\pi +\frac{3\pi}{8},\mathrm{k}\pi +\frac{7\pi}{8} ]$ （ $\mathbf{k}\in \mathbb{Z})$
> >
> > 点评：本题考查三角函数的化简，涉及三角函数的周期性和单调性，属基础题.
