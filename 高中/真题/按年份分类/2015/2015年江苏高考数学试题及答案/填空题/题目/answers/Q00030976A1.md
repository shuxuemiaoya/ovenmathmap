> [!faq]- 2015年江苏高考数学试题及答案解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【分析】**
> > （1）根据等比数列和等差数列的定义即可证明；
> > (2) 利用反证法, 假设存在 $a_1$ , d 使得 $a_1, a_2^2, a_3^3, a_4^4$ 依次构成等比数列, 推出矛盾, 否定假设, 得到结论;
> > (3) 利用反证法, 假设存在 $a_1$ , d 及正整数 n, k, 使得 $a_1^n$ , $a_2^{n+k}$ , $a_3^{n+2k}$ , $a_4^{n+3k}$ 依次构成等比数列, 得到 $a_1^n (a_1 + 2d)^{n+2k} = (a_1 + 2d)^{2(n+k)}$ , 且 $(a_1 + d)^{n+k}(a_1 + 3d)^{n+3k} = (a_1 + 2d)^{2(n+2k)}$ , 利用等式以及对数的性质化简整理得到 $\ln (1 + 3t)\ln (1 + 2t) + 3\ln (1 + 2t)\ln (1 + t) = 4\ln (1 + 3t)\ln (1 + t)$ , (\*\*), 多次构造函数, 多次求导, 利用零点存在定理, 推出假设不成立.
>
> > [!note]- **【解析】**
> > 解：
> > （1）证明： $\because \frac{2^{a_{n + 1}}}{2^{a_n}} = 2^{a_{n + 1} - a_n = 2^d}$ ，（ $n = 1$ ，2，3，）是同一个常数，
> >
> > $\therefore 2^{a_{1}}, 2^{a_{2}}, 2^{a_{3}}, 2^{a_{4}}$ 依次构成等比数列；
> > (2) 令 $a_1 + d = a$ ，则 $a_1, a_2, a_3, a_4$ 分别为 $a - d, a, a + d, a + 2d (a > d, a > -2d, d \neq 0)$ 假设存在 $a_1, d$ 使得 $a_1, a_2^2, a_3^3, a_4^4$ 依次构成等比数列，
> >
> > 则 $a^4 = (a - d)$ （ $a + d)^3$ ，且 $(a + d)^6 = a^2$ （ $a + 2d)^4$ ，
> >
> > 令 $t=\frac{d}{a}$ ，则 $1=(1-t)\quad(1+t)^{3}$ ，且 $(1+t)^{6}=(1+2t)^{4}$ ， $(- \frac{1}{2}<t<1, t\neq0)$ ，化简得 $t^{3}+2t^{2}-2=0$ （\*），且 $t^{2}=t+1$ ，将 $t^{2}=t+1$ 代入（\*）式，
> >
> > t (t+1) +2 (t+1) - 2=t $^{2}$ +3t=t+1+3t=4t+1=0，则 t=- $\frac{1}{4}$ ，
> >
> > 显然 $t = -\frac{1}{4}$ 不是上面方程的解，矛盾，所以假设不成立，
> >
> > 因此不存在 $a_{1}$ ，d，使得 $a_{1}$ ， $a_{2}^{2}$ ， $a_{3}^{3}$ ， $a_{4}^{4}$ 依次构成等比数列.
> > (3) 假设存在 $a_1, d$ 及正整数 $n, k$ , 使得 $a_1^n, a_2^{n+k}, a_3^{n+2k}, a_4^{n+3k}$ 依次构成等比数列,
> >
> > 则 $a_1^n (a_1 + 2d)^{n + 2k} = (a_1 + 2d)^{2(n + k)}$ ，且 $(a_1 + d)^{n + k}(a_1 + 3d)^{n + 3k} = (a_1 + 2d)^{2(n + 2k)}$
> >
> > 分别在两个等式的两边同除以 $= a_{1}^{2(n + k)}$ ， $a_1^2 (n + 2k)$ ，并令 $t = \frac{d}{a_1}$ ，（ $t > -\frac{1}{3}, t \neq 0$ ），
> >
> > 则 $(1 + 2t)^{n + 2k} = (1 + t)^{2(n + k)}$ ，且 $(1 + t)^{n + k}(1 + 3t)^{n + 3k} = (1 + 2t)^{2(n + 2k)}$
> >
> > 将上述两个等式取对数，得 $(\mathrm{n} + 2\mathrm{k})\ln (1 + 2\mathrm{t}) = 2(\mathrm{n} + \mathrm{k})\ln (1 + \mathrm{t})$ ，
> >
> > $$
> > (n + k) \ln (1 + t) + (n + 3 k) \ln (1 + 3 t) = 2 (n + 2 k) \ln (1 + 2 t)
> > $$
> >
> > 化简得， $2k[\ln(1+2t)-\ln(1+t)]=n[2\ln(1+t)-\ln(1+2t)]$
> >
> > $$
> > 3 k \left[ \ln (1 + 3 t) - \ln (1 + t) \right] = n \left[ 3 \ln (1 + t) - \ln (1 + 3 t) \right],
> > $$
> >
> > $$
> > \ln (1 + 3 t) \ln (1 + 2 t) + 3 \ln (1 + 2 t) \ln (1 + t) = 4 \ln (1 + 3 t) \ln (1 + t), \quad (* *)
> > $$
> >
> > $$
> > \mathrm{g} (t) = 4 \ln (1 + 3 t) \ln (1 + t) - \ln (1 + 3 t) \ln (1 + 2 t) + 3 \ln (1 + 2 t) \ln (1 + t),
> > $$
> >
> > $$
> > \mathrm{g} ^ {\prime} (t) = \frac {2}{(1 + t) (1 + 2 t) (1 + 3 t)} [ (1 + 3 t) ^ {2} \ln (1 + 3 t) - 3 (1 + 2 t) ^ {2} \ln (1 + 2 t)
> > $$
> >
> > $$
> > \varphi (t) = (1 + 3 t) ^ {2} \ln (1 + 3 t) - 3 (1 + 2 t) ^ {2} \ln (1 + 2 t) + 3 (1 + t) ^ {2} \ln (1 + t),
> > $$
> >
> > $$
> > \varphi^ {\prime} (t) = 6 \left[ (1 + 3 t) \ln (1 + 3 t) - 2 (1 + 2 t) \ln (1 + 2 t) + 3 (1 + t) \ln (1 + t) \right],
> > $$
> >
> > $$
> > \varphi_ {1} (t) = \varphi^ {\prime} (t), \text {则} \varphi_ {1} ^ {\prime} (t) = 6 [ 3 \ln (1 + 3 t) - 4 \ln (1 + 2 t) + \ln (1 + t) ],
> > $$
> >
> > 令 $\varphi_{2}(t) = \varphi_{1}'(t)$ ，则 $\varphi_{2}'(t) = \frac{12}{(1 + t)(1 + 2t)(1 + 3t)} >0$
> >
> > 由 g (0) =φ (0) =φ₁ (0) =φ₂ (0) =0, φ₂' (t) >0,
> >
> > 知 $\mathrm{g(t)}$ ， $\varphi (t)$ ， $\varphi_{1}(t)$ ， $\varphi_{2}(t)$ 在 $(- \frac{1}{3},0)$ 和 $(0, + \infty)$ 上均单调，
> >
> > 故 g（t）只有唯一的零点 t=0，即方程（\*\*）只有唯一解 t=0，故假设不成立，
> >
> > $$
> > \mathrm{a} _ {1} ^ {\mathrm{n}}, \mathrm{a} _ {2} ^ {\mathrm{n+k}}, \mathrm{a} _ {3} ^ {\mathrm{n+2k}}, \mathrm{a} _ {4} ^ {\mathrm{n+3k}}
> > $$
