> [!faq]- 2020年全国统一高考数学试卷（理科）（新课标ⅱ）（含解析版）解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【分析】**
> > （1）先求导，根据导数和函数单调性的关系即可求出，
> > (2) 根据导数和函数最值的关系即可证明，
> > (3) 利用
> > (2) 的结论, 根据指数函数的性质即可证明.
>
> > [!note]- **【解析】**
> > 解：
> > （1） $f(x)=\sin^{2}x\sin2x=2\sin^{3}x\cos x$
> >
> > $\therefore f'(x) = 2\sin^{2}x (3\cos^{2}x - \sin^{2}x) = 2\sin^{2}x (3 - 4\sin^{2}x) = 2\sin^{2}x [3 - 2 (1 - \cos 2x)] = 2\sin^{2}x (1 + 2\cos 2x)$ ，
> >
> > 令 $f'(x)=0$ ，解得， $x=\frac{\pi}{3}$ ，或 $x=\frac{2\pi}{3}$ ，
> >
> > 当 $x \in (0, \frac{\pi}{3})$ 或 $(\frac{2\pi}{3}, \pi)$ 时， $f'(x) > 0$ ，当 $x \in (\frac{\pi}{3}, \frac{2\pi}{3})$ 时， $f'(x) < 0$ ， $\therefore f(x)$ 在 $(0, \frac{\pi}{3})$ ， $(\frac{2\pi}{3}, \pi)$ 上单调递增，在 $(\frac{\pi}{3}, \frac{2\pi}{3})$ 上单调递减.
> >
> > 证明：
> > (2) $\because f(0) = f(\pi) = 0$ ，由
> > (1)可知 $f(x)$ 极小值 $= f\left(\frac{2}{3}\pi\right) = -\frac{3\sqrt{3}}{8}, f(x)$ 极大值 $= f\left(\frac{\pi}{3}\right)$ $= \frac{3\sqrt{3}}{8},$
> >
> > $$
> > \therefore f (x) _ {\max} = \frac {3 \sqrt {3}}{8}, f (x) _ {\min} = - \frac {3 \sqrt {3}}{8},
> > $$
> >
> > $\because f(x)$ 为周期函数，
> >
> > $$
> > \therefore | f (x) | \leq \frac {3 \sqrt {3}}{8};
> > $$
> > (3) 由
> > (2) 可知 $\sin^2 x \sin 2x \leq \frac{3\sqrt{3}}{8} = \left(\frac{3}{4}\right) \frac{3}{2}, \sin^2 2x \sin 4x \leq \frac{3\sqrt{3}}{8} = \left(\frac{3}{4}\right) \frac{3}{2}, \sin^2 2^2 x \sin 2^3 x \leq$
> >
> > $$
> > \frac {3 \sqrt {3}}{8} = (\frac {3}{4}) \frac {3}{2}, \dots , \sin^ {2} 2 ^ {n - 1} x \sin 2 ^ {n} x \leq \frac {3 \sqrt {3}}{8} = (\frac {3}{4}) \frac {3}{2},
> > $$
> >
> > $$
> > \therefore \sin^ {3} x \sin^ {3} 2 x \sin^ {3} 4 x \dots \dots \sin^ {3} 2 ^ {n - 1} x \sin^ {3} 2 ^ {n} x = \sin x (\quad \sin^ {2} x \sin^ {3} 2 x \sin^ {3} 4 x \dots \dots \sin^ {3} 2 ^ {n - 1})
> > $$
> >
> > $$
> > { } ^ { 1 } x \sin ^ { 2 } 2 ^ { n } x ) \sin 2 ^ { n } x \leq ( \frac { 3 } { 4 } ) \frac { 3 n } { 2 } ,
> > $$
> >
> > $$
> > \therefore \sin^ {2} x \sin^ {2} 2 x \sin^ {2} 4 x \dots \dots \sin^ {2} 2 ^ {n} x \leq \frac {3 ^ {n}}{4 ^ {n}}.
> > $$
> >
> > 【点评】本题考查了导数和函数的单调性的和极值最值的关系，不等式的证明，考查了运算求解能力，转化与化归能力，属于难题.
