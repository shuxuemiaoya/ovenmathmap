> [!faq]- 2020年高考重庆理科数学试题及答案(精校版)解析
>
> > [!success]- **【答案】** （1） $A=\frac{2\pi}{3}$ ； （2） $3+2\sqrt{3}$ 【
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > （1）在 $\triangle ABC$ 中，设内角 $A, B, C$ 的对边分别为 $a, b, c$
> >
> > 因为 $\sin^2 A - \sin^2 B - \sin^2 C = \sin B\sin C$
> >
> > 由正弦定理得， $a^2 - b^2 - c^2 = bc$ ，即 $b^2 + c^2 - a^2 = -bc$
> >
> > 由余弦定理得， $\cos A = \frac{b^2 + c^2 - a^2}{2bc} = -\frac{1}{2}$
> >
> > 因为 $0 < A < \pi$ ，所以 $A = \frac{2\pi}{3}$
> > （2）由
> > （1）知 $A = \frac{2\pi}{3}$ ，因为 $BC = 3$ ，即 $a = 3$
> >
> > 由余弦定理得， $a^2 = b^2 +c^2 -2bc\cos A$
> >
> > 所以 $9 = b^{2} + c^{2} + bc = (b + c)^{2} - bc$
> >
> > 由基本不等式 $\sqrt{bc} \leq \frac{b + c}{2}$ 知 $bc \leq \frac{(b + c)^2}{4}$ ，结合上式得
> >
> > $9 = (b + c)^{2} - bc \geq \frac{3}{4} (b + c)^{2}, (b + c)^{2} \leq 12$ ，所以 $b + c \leq 2\sqrt{3}$
> >
> > 当且仅当 $b = c = \sqrt{3}$ 时取等号
> >
> > 所以 $\triangle ABC$ 周长的最大值为 $3 + 2\sqrt{3}$
> >
> > 解法2：由正弦定理得 $\frac{b}{\sin B} = \frac{c}{\sin C} = \frac{a}{\sin A} = \frac{3}{\sin\frac{2\pi}{3}} = 2\sqrt{3}$
> >
> > 所以 $b = 2\sqrt{3}\sin B, c = 2\sqrt{3}\sin C$ ，由 $A + B + C = \pi$ 知 $C = \frac{\pi}{3} - B$ ， $0 < B < \frac{\pi}{3}$
> >
> > 所以 $a + b + c = 3 + 2\sqrt{3}\sin B + 2\sqrt{3}\sin \left(\frac{\pi}{3} -B\right)$ $= 3 + 2\sqrt{3}\sin B + 2\sqrt{3} (\frac{\sqrt{3}}{2}\cos B - \frac{1}{3}\sin B)$ $= 3 + \sqrt{3}\sin B + 3\cos B$ $= 3 + 2\sqrt{3}\sin (B + \frac{\pi}{3})$ 因为 $0 <   B <   \frac{\pi}{3}$ ，所以 $\frac{\pi}{3} <  B + \frac{\pi}{3} <   \frac{2\pi}{3}$ ，所以当且仅当 $B + \frac{\pi}{3} = \frac{\pi}{2}$ ，即 $B = \frac{\pi}{6}$ 时，  
> > △ABC的周长的最大值为 $3 + 2\sqrt{3}$
