> [!faq]- 2020年高考重庆理科数学试题及答案(精校版)解析
>
> > [!success]- **【答案】** C
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > 取 $m = 1$ ，则 $a_{n + 1} = a_1a_n$ ，又 $a_1 = 2$ ，所以 $\frac{a_{n + 1}}{a_n} = 2$ ，所以 $\{a_n\}$ 是等比数列，则 $a_{n} = 2^{n}$ ，所以 $a_{k + 1} + a_{k + 2} + \dots +a_{k + 10} = \frac{2^{k + 1}(1 - 2^{10})}{1 - 2} = 2^{k + 11} - 2^{k + 1} = 2^{15} - 2^5$ ，得 $k = 4$
