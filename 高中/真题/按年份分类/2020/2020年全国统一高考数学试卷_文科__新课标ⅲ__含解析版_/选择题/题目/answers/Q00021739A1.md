> [!faq]- 2020年全国统一高考数学试卷（文科）（新课标ⅲ）（含解析版）解析
>
> > [!success]- **【答案】** C
>
> > [!note]- **【分析】**
> > 先根据余弦定理求 $c$ ，再根据余弦定理求 $\cos B$ ，最后根据同角三角函数关系求 $\tan B.$
>
> > [!note]- **【解析】**
> > 设 $AB = c,BC = a,CA = b$ $c^2 = a^2 +b^2 -2ab\cos C = 9 + 16 - 2\times 3\times 4\times \frac{2}{3} = 9.\therefore c = 3$ $\cos B = \frac{a^2 + c^2 - b^2}{2ac} = \frac{1}{9}\therefore \sin B = \sqrt{1 - (\frac{1}{9})^2} = \frac{4\sqrt{5}}{9}\therefore \tan B = 4\sqrt{5}$
> >
> > 故选：C
> >
