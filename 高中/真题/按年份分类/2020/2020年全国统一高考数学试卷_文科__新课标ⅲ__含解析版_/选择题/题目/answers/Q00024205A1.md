> [!faq]- 2020年全国统一高考数学试卷（文科）（新课标ⅲ）（含解析版）解析
>
> > [!success]- **【答案】** B
>
> > [!note]- **【分析】**
> > 直接代入点到直线的距离公式，结合基本不等式即可求解结论.
>
> > [!note]- **【解析】**
> > 分析】直接代入点到直线的距离公式，结合基本不等式即可求解结论.
> >
> > 【
> > 解答】解：因为点（0，-1）到直线 $y = k(x + 1)$ 距离 $d = \frac{|1 + k|}{\sqrt{k^2 + 1}} = \sqrt{\frac{k^2 + 2k + 1}{k^2 + 1}} = \sqrt{1 + \frac{2k}{k^2 + 1}}$ ;
> >
> > ∵要求距离的最大值，故需k>0;
> >
> > 可得 $d \leq \sqrt{1 + \frac{2k}{2k}} = \sqrt{2}$ ; 当 $k = 1$ 时等号成立;
> >
> > 故选：B.
> >
> > 【点评】本题考查的知识点是点到直线的距离公式，属于基础题.
