> [!faq]- 2020年全国统一高考数学试卷（文科）（新课标ⅱ）（含解析版）解析
>
> > [!success]- **【答案】** C
>
> > [!note]- **【分析】**
> > 由原位大三和弦、原位小三和弦的定义，运用列举法，即可得到所求和.
> > 【
>
> > [!note]- **【解析】**
> > 解：若 k-j=3 且 j-i=4，则 $a_{i}$ ， $a_{j}$ ， $a_{k}$ 为原位大三和弦，
> >
> > 即有 $i = 1, j = 5, k = 8; i = 2, j = 6, k = 9; i = 3, j = 7, k = 10; i = 4, j = 8, k = 11; i = 5, j = 9, k = 12$ ，共5个；  
> > 若 $k - j = 4$ 且 $j - i = 3$ ，则 $a_i, a_j, a_k$ 为原位小三和弦，  
> > 可得 $i = 1, j = 4, k = 8; i = 2, j = 5, k = 9; i = 3, j = 6, k = 10; i = 4, j = 7, k = 11; i = 5, j = 8, k = 12$ ，共5个，  
> > 总计10个。  
> > 故选：C.
> >
> > 【点评】本题是数列在实际问题中的运用，运用列举法是解题的关键，属于基础题.
