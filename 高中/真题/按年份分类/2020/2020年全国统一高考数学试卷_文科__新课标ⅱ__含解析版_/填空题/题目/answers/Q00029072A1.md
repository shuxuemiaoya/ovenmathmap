> > [!note]- **【解析】**
> > 解：
> > （1） $f(x) \leqslant 2x + c$ 等价于 $2\ln x - 2x \leqslant c - 1$ .
> >
> > 设 $h(x) = 2\ln x - 2x, h'(x) = \frac{2}{x} - 2 = \frac{2(1 - x)}{x} (x > 0)$ .
> >
> > 当 $x \in (0, 1)$ 时， $h'(x) > 0$ ， $h(x)$ 单调递增，
> >
> > 当 $x \in (1, +\infty)$ 时， $h'(x) < 0$ ， $h(x)$ 单调递减，
> >
> > ∴h (x) 在 x=1 时取得极大值也就是最大值为 h (1) = -2,
> >
> > $\therefore c - 1 \geq -2$ ，即 $c \geq -1$ .
> >
> > 则 c 的取值范围为 $[-1, +\infty)$ ;
> > (2) $g(x) = \frac{f(x) - f(a)}{x - a} = \frac{2(1nx - 1na)}{x - a} (x > 0, x \neq a, a > 0).$
> >
> > $\therefore g^{\prime}(x) = \frac{\frac{2}{x} (x - a) - 21nx + 21na}{(x - a)^{2}} = \frac{-\frac{2a}{x} - 21nx + 21na + 2}{(x - a)^{2}}.$
> >
> > 令 $w(x) = -\frac{2a}{x} - 21nx + 2lna + 2 (x > 0)$ ，
> >
> > 则 $w^{\prime}(x) = \frac{2a}{x^{2}} -\frac{2}{x} = \frac{2(a - x)}{x^{2}},$
> >
> > 令 $w'(x) > 0$ ，解得 0 < x < a，令 $w'(x) < 0$ ，解得 x > a，
> >
> > ∴w (x) 在 $(0, a)$ 上单调递增，在 $(a, +\infty)$ 上单调递减.
> >
> > $\therefore w(x) \leqslant w(a) = 0, \text{即 } g'(x) \leqslant 0,$
> >
> > $\therefore g(x)$ 在 $(0, a)$ 和 $(a, +\infty)$ 上单调递减.
