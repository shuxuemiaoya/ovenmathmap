> [!faq]- 2020年江苏高考数学试题及答案解析
>
> > [!success]- **【答案】** $\left[-2, \frac{2}{3}\right]$ 【
>
> > [!note]- **【分析】**
> > 根据绝对值定义化为三个方程组，解得结果
>
> > [!note]- **【解析】**
> > $\because \left\{ \begin{array}{l} x < -1 \\ -2x - 2 - x \leq 4 \end{array} \right.$ 或 $\left\{ \begin{array}{l} -1 \leq x \leq 0 \\ 2x + 2 - x \leq 4 \end{array} \right.$ 或 $\left\{ \begin{array}{l} x > 0 \\ 2x + 2 + x \leq 4 \end{array} \right.$
> >
> > $\therefore -2 \leq x < -1$ 或 $-1 \leq x \leq 0$ 或 $0 < x \leq \frac{2}{3}$
> >
> > 所以解集为 $\left[-2, \frac{2}{3}\right]$
> >
> > 【点睛】本题考查分类讨论解含绝对值不等式，考查基本
