时间内通过的车辆数除以该路段的长度，现定义交通流量为 $v=\frac{q}{x}$ ，x 为道路密度，q 为车

辆密度.

$$
v = f (x) = \left\{ \begin{array}{l} 1 0 0 - 1 3 5 \text {   (} \frac {1}{3}) ^ {x}, 0 <   x <   4 0 \\ - k (x - 4 0) + 8 5, 4 0 _ {n}, x _ {n} 8 0 \end{array} \right.
$$
