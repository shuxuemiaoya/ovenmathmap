> [!faq]- 2020年全国统一高考数学试卷（理科）（新课标ⅲ）（含解析版）解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【分析】**
> > （1）将 $a+b+c=0$ 平方之后，化简得到 $2ab+2ac+2bc=-\left(a^{2}+b^{2}+c^{2}\right)<0$ ，即可得证；
> > (2) 利用反证法，假设 $a \leq b < 0 < c < \sqrt[3]{4}$ ，结合条件推出矛盾.
>
> > [!note]- **【解析】**
> > 证明：（1）∵ $a+b+c=0$ ，∴ $(a+b+c)^{2}=0$ ，
> >
> > $$
> > \therefore a ^ {2} + b ^ {2} + c ^ {2} + 2 a b + 2 a c + 2 b c = 0,
> > $$
> >
> > $\therefore 2ab + 2ac + 2bc = - (a^2 + b^2 + c^2)$
> >
> > $\because abc=1,\therefore a,b,c$ 均不为0,
> >
> > $$
> > \therefore 2 a b + 2 a c + 2 b c = - \left(a ^ {2} + b ^ {2} + c ^ {2}\right) <   0,
> > $$
> >
> > $$
> > \therefore a b + a c + b c <   0;
> > $$
> > (2) 不妨设 $a \leq b < 0 < c < \sqrt[3]{4}$ , 则 $ab = \frac{1}{c} > \frac{1}{\sqrt[3]{4}}$ ,
> >
> > $$
> > \because a + b + c = 0, \therefore - a - b = c <   \sqrt [ 3 ]{4},
> > $$
> >
> > 而 $-a - b \geq 2\sqrt{ab} > \frac{2}{\sqrt[6]{4}} = \frac{4^{\frac{1}{2}}}{4^{\frac{1}{6}}} = \frac{1}{4^{\frac{3}{3}}} = \sqrt[3]{4}$ ，与假设矛盾，
> >
> > 故 $max\{a, b, c\} \geq \sqrt[3]{4}$ .
> >
> > 【点评】本题考查基本不等式的应用和利用综合法与反正法证明不等式，考查了转化思想，属于中档题.
