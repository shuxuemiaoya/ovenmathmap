> [!faq]- 2020年全国统一高考数学试卷（理科）（新课标ⅲ）（含解析版）解析
>
> > [!success]- **【答案】** $ 题为必考题，每个试题考生都必须作答。第22、23题为选考题，考生根据要求作答。（一）必考题：共60分。
>
> > [!note]- **【分析】**
> > （1）求出原函数的导函数，由题意可得 $f'(\frac{1}{2}) = 3 \times (\frac{1}{2})^2 + b = 0$ ，由此求得 $b$ 值；
> > （2）设 $x_0$ 为 $f(x)$ 的一个零点，根据题意， $f(x_0) = x_0^3 - \frac{3}{4}x_0 + c = 0$ ，且 $|x_0| \leq 1$ ，得到 $c = -x_0^3 + \frac{3}{4}x_0$ ，由 $|x_0| \leq 1$ ，对 $c(x)$ 求导数，可得 $c(x)$ 在[-1, 1]上的单调性，得到 $-\frac{1}{4} \leq c \leq \frac{1}{4}$ . 设 $x_1$ 为 $f(x)$ 的零点，则必有 $f(x_1) = x_1^3 - \frac{3}{4}x_1 + c = 0$ ，可得 $-\frac{1}{4} \leq c = -x_1^3 + \frac{3}{4}x_1 \leq \frac{1}{4}$ ，由此求得 $x_1$ 的范围得答案.
>
> > [!note]- **【解析】**
> > （1）解：由 $f(x) = x^3 + bx + c$ ，得 $f'(x) = 3x^2 + b$ ， $\therefore f'(\frac{1}{2}) = 3 \times (\frac{1}{2})^2 + b = 0$ ，即 $b = -\frac{3}{4}$ ;
> >
> > $$
> > x _ {0}
> > $$
> >
> > $$
> > f \left(x _ {0}\right) = x _ {0} ^ {3} - \frac {3}{4} x _ {0} + c = 0
> > $$
> >
> > $$
> > | x _ {0} | \leq 1
> > $$
> >
> > 则 $c = -x_0^3 + \frac{3}{4} x_0$ ，由 $|x_0| \leq 1$
> >
> > 令 $c(x) = -x^3 +\frac{3}{4} x(-1\leq x\leq 1)$
> >
> > $$
> > \therefore c ^ {\prime} (x) = - 3 x ^ {2} + \frac {3}{4} = - 3 (x + \frac {1}{2}) (x - \frac {1}{2}),
> > $$
> >
> > 当 $x \in (-1, -\frac{1}{2}) \cup (\frac{1}{2}, 1)$ 时， $c'(x) < 0$ ，当 $x \in (-\frac{1}{2}, \frac{1}{2})$ 时， $c'(x) > 0$
> >
> > 可知 $c(x)$ 在 $(-1, -\frac{1}{2})$ ， $(\frac{1}{2}, 1)$ 上单调递减，在 $(- \frac{1}{2}, \frac{1}{2})$ 上单调递增.
> >
> > $$
> > c (- 1) = \frac {1}{4}, c (1) = - \frac {1}{4}, c (- \frac {1}{2}) = - \frac {1}{4}, c (\frac {1}{2}) = \frac {1}{4},
> > $$
> >
> > $$
> > \therefore - \frac {1}{4} \leqslant c \leqslant \frac {1}{4}.
> > $$
> >
> > 设 $x_{1}$ 为 $f(x)$ 的零点，则必有 $\mathbf{f}(\mathbf{x}_1) = \mathbf{x}_1^3 -\frac{3}{4}\mathbf{x}_1 + c = 0$
> >
> > 即 $-\frac{1}{4} \leqslant c = -x_1^3 + \frac{3}{4} x_1 \leqslant \frac{1}{4}$ ,
> >
> > $$
> > \therefore \left\{ \begin{array}{l l} {4   x _ {1} ^ {3} - 3   x _ {1} - 1 = (x _ {1} - 1)   (2   x _ {1} + 1) ^ {2} \leqslant 0} \\ {4   x _ {1} ^ {3} - 3   x _ {1} + 1 = (x _ {1} + 1)   (2   x _ {1} - 1) ^ {2} \geqslant 0} \end{array} , \text {得} - 1 \leqslant x _ {1} \leqslant 1, \right.
> > $$
> >
> > 即 $|x_{1}|\leq1$ .
> >
> > $\therefore f(x)$ 所有零点的绝对值都不大于1.
