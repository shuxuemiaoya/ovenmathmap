23. 设 $a, b, c \in \mathbf{R}, a + b + c = 0, abc = 1$ .

(1) 证明: $ab + bc + ca < 0$ ;

(2) 用 $max\{a, b, c\}$ 表示 $a, b, c$ 的最大值，证明： $max\{a, b, c\} \geq \sqrt[3]{4}$ .
