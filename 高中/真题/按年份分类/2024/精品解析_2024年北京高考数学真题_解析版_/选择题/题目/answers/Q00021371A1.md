> [!faq]- 精品解析：2024年北京高考数学真题（解析版）解析
>
> > [!success]- **【答案】** B
>
> > [!note]- **【分析】**
> > 根据指数函数和对数函数的单调性结合基本不等式
>
> > [!note]- **【解析】**
> > 由题意不妨设 $x_{1} < x_{2}$ ，因为函数 $y = 2^{x}$ 是增函数，所以 $0 < 2^{x_1} < 2^{x_2}$ ，即 $0 < y_{1} < y_{2}$ ，对于选项AB：可得 $\frac{2^{x_1} + 2^{x_2}}{2} >\sqrt{2^{x_1} \cdot 2^{x_2}} = 2^{\frac{x_1 + x_2}{2}}$ ，即 $\frac{y_1 + y_2}{2} > 2^{\frac{x_1 + x_2}{2}} > 0$ ，
> >
> > 根据函数 $y = \log_2 x$ 是增函数，所以 $\log_2 \frac{y_1 + y_2}{2} > \log_2 2^{\frac{x_1 + x_2}{2}} = \frac{x_1 + x_2}{2}$ ，故B正确，A错误；对于选项D：例如 $x_1 = 0, x_2 = 1$ ，则 $y_1 = 1, y_2 = 2$ ，
> >
> > 可得 $\log_2\frac{y_1 + y_2}{2} = \log_2\frac{3}{2}\in (0,1)$ ，即 $\log_2\frac{y_1 + y_2}{2} < 1 = x_1 + x_2$ ，故D错误；
> >
> > 对于选项C：例如 $x_{1} = -1, x_{2} = -2$ ，则 $y_{1} = \frac{1}{2}, y_{2} = \frac{1}{4}$ ，
> >
> > 可得 $\log_2\frac{y_1 + y_2}{2} = \log_2\frac{3}{8} = \log_23 - 3\in (-2, - 1)$ ，即 $\log_2\frac{y_1 + y_2}{2} > - 3 = x_1 + x_2$ ，故C错误，
> >
> > 故选：B.
