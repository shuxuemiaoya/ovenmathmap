> [!faq]- 2026年高考上海卷数学高考真题（解析版）解析
>
> > [!success]- **【答案】** -6
>
> > [!note]- **【分析】**
> > 方法一：由条件可得 $\vec{a} + 3\vec{b} = x(\vec{b} + \vec{c})$ ， $2\vec{a} + k\vec{c} = y(\vec{b} + \vec{c})$ ，消去 $\vec{a}$ ，根据平面向量基本定理列方程求结论；
>
> > [!note]- **【解析】**
> > 方法一：因为 $\vec{a} + 3\vec{b} / /\vec{b} + \vec{c}$ ，所以 $\vec{a} + 3\vec{b} = x(\vec{b} + \vec{c})$ ,
> >
> > 因为 $2\vec{a} + k\vec{c} / / \vec{b} +\vec{c}$ ，所以 $2\vec{a} +k\vec{c} = y(\vec{b} +\vec{c})$
> >
> > 所以 $k\vec{c} - 6\vec{b} = (y - 2x)\vec{b} + (y - 2x)\vec{c}$
> >
> > 因为 $\vec{b},\vec{c}$ 不平行，所以 $\left\{ \begin{array}{l}k = y - 2x\\ -6 = y - 2x \end{array} \right.$
> >
> > 所以 $k = -6$ ，
> >
> > 方法二：因为 $\vec{a} + 3\vec{b} / / \vec{b} +\vec{c}$ ， $2\vec{a} +k\vec{c} / / \vec{b} +\vec{c}$ ， $\vec{a},\vec{b},\vec{c}$ 两两不平行，
> >
> > 所以， $\vec{a} + 3\vec{b} = x(2\vec{a} + k\vec{c})$
> >
> > 若 $\vec{a},\vec{b},\vec{c}$ 不共面，所以 $1 = 2x,3 = 0,0 = xk$ ，矛盾，
> >
> > 所以 $\vec{a},\vec{b},\vec{c}$ 共面，可设 $\vec{c} = \lambda \vec{a} +\mu \vec{b}$
> >
> > 所以 $\vec{a} + 3\vec{b} = x(2\vec{a} + k\lambda \vec{a} + k\mu \vec{b})$
> >
> > 所以 $\left\{\begin{aligned}1&=2x+k\lambda x\\ 3&=k\mu x\end{aligned}\right.$ ,
> >
> > 因为 $\vec{a} + 3\vec{b} / / \vec{b} + \vec{c}$ ，可设 $\vec{a} + 3\vec{b} = y(\vec{b} + \vec{c}) = y\vec{b} + y\lambda \vec{a} + y\mu \vec{b}$ ，
> >
> > 所以 $1=y\lambda$ ， $3=y+y\mu$ ，
> >
> > 所以 $3(2+k\lambda)=k\mu$ ， $3\lambda=1+\mu$ ，
> >
> > 所以 $6 + k(1 + \mu) = k\mu$ ，所以 $k = -6$
