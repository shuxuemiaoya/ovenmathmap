> [!faq]- 2026年高考北京卷数学高考真题（解析版）解析
>
> > [!success]- **【答案】** C
>
> > [!note]- **【分析】**
> > 平移后函数为 $\sin (x - 2\varphi)$ ，与 $\sin (x + \varphi)$ 关于 $x$ 轴对称可知函数值互为相反数，利用正弦相等得方程，排除不恒成立情形，得到 $\varphi$ 的取值个数.
>
> > [!note]- **【解析】**
> > 将 $f(x) = \sin (x + \varphi)$ 向右平移 $3\varphi$ 个单位得 $g(x) = f(x - 3\varphi) = \sin (x - 3\varphi + \varphi) = \sin (x - 2\varphi)$ .
> > 由题意， $g(x)$ 与 $f(x)$ 的图像关于 $x$ 轴对称，即 $g(x) = -f(x)$ 恒成立，  
> > 即 $\sin (x - 2\varphi) = -\sin (x + \varphi) = \sin (-x - \varphi)$ . 分两种情形讨论： $① x - 2\varphi = -x - \varphi + 2k\pi \Rightarrow 2x - \varphi = 2k\pi (k \in \mathbf{Z})$ ，对任意 $x$ 不恒成立，舍去； $② x - 2\varphi = \pi - (-x - \varphi) + 2k\pi = \pi + x + \varphi + 2k\pi (k \in \mathbf{Z})$ ，化简得 $-2\varphi = \pi + \varphi + 2k\pi \Rightarrow 3\varphi = -\pi - 2k\pi$ ，即 $\varphi = -\frac{\pi}{3}(1 + 2k)$ .  
> > 由 $0 < \varphi < 2\pi$ 得 $0 < -\frac{\pi}{3}(1 + 2k) < 2\pi \Rightarrow k = -1, -2, -3$ ，  
> > 对应 $\varphi = \frac{\pi}{3}, \pi, \frac{5\pi}{3}$ ，因此 $\varphi$ 的取值个数为3个.
