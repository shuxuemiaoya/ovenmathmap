> > 7. $\{a_{n}\}$ ， $\{b_{n}\}$ 是无穷数列，则“存在常数 M，使 $a_{n} \leq M \leq b_{n} (n = 1, 2, 3, \cdots)$ ”是“ $a_{n} \leq b_{n} (n = 1, 2, 3, \cdots)$ ”的（）
> > A. 充分不必要条件
> > B. 必要不充分条件
> > C. 充分必要条件
> > D. 既不充分也不必要条件
> >
> > 【
> >
> > 由题意， $\left\{a_{n}\right\},\left\{b_{n}\right\}$ 是无穷数列，
> > 验证充分性：
> > 当存在常数 M，使 $a_{n} \leq M \leq b_{n} (n = 1, 2, 3, \cdots)$ 时， $a_{n} \leq M (n = 1, 2, 3, \cdots)$ ， $M \leq b_{n} (n = 1, 2, 3, \cdots)$ ， $a_{n} \leq b_{n} (n = 1, 2, 3, \cdots)$ 显然成立，
> >
> > 验证必要性:
> >
> > 当 $a_{n}=n,\quad b_{n}=n^{2}$ 时，此时满足 $a_{n}\leq b_{n}$
> >
> > 假设存在常数 M，使 $a_{n} \leq M \leq b_{n} (n = 1, 2, 3, \cdots)$ 成立，
> >
> > $$
> > a _ {n} = n \rightarrow + \infty
> > $$
> >
> > $$
> > b _ {n} = n ^ {2} \rightarrow + \infty
> > $$
> >
> > 此时，M 需同时 “不小于无限增大的 n” 和 “不大于无限增大的 $n^{2}$ ”，
> >
> > ∴当 $a_{n}\leq b_{n}$ 时，无法必然推出“存在常数M”，即必要性不成立，
> >
> > ∴ “存在常数 M，使 $a_{n} \leq M \leq b_{n}(n=1,2,3,\cdots)$ ” 是 “ $a_{n} \leq b_{n}(n=1,2,3,\cdots)$ ” 的充分不必要条件.
> > 8. $f(x)=\sin(x+\varphi)$ ( $0<\varphi<2\pi$ ), 将 $f(x)$ 向 x 轴正方向平移 $3\varphi$ 个单位, 得到的函数图像与 $f(x)$ 图像关于 x 轴对称, 则 $\varphi$ 的取值个数为 ( )
> >
> > A. 1    B. 2    C. 3    D. 4
> >
> > 【
> >
> > 将 $f(x) = \sin (x + \varphi)$ 向右平移 $3\varphi$ 个单位得 $g(x) = f(x - 3\varphi) = \sin (x - 3\varphi + \varphi) = \sin (x - 2\varphi)$ .
> > 由题意， $g(x)$ 与 $f(x)$ 的图像关于 $x$ 轴对称，即 $g(x) = -f(x)$ 恒成立，  
> > 即 $\sin (x - 2\varphi) = -\sin (x + \varphi) = \sin (-x - \varphi)$ . 分两种情形讨论： $① x - 2\varphi = -x - \varphi + 2k\pi \Rightarrow 2x - \varphi = 2k\pi (k \in \mathbf{Z})$ ，对任意 $x$ 不恒成立，舍去； $② x - 2\varphi = \pi - (-x - \varphi) + 2k\pi = \pi + x + \varphi + 2k\pi (k \in \mathbf{Z})$ ，化简得 $-2\varphi = \pi + \varphi + 2k\pi \Rightarrow 3\varphi = -\pi - 2k\pi$ ，即 $\varphi = -\frac{\pi}{3}(1 + 2k)$ .  
> > 由 $0 < \varphi < 2\pi$ 得 $0 < -\frac{\pi}{3}(1 + 2k) < 2\pi \Rightarrow k = -1, -2, -3$ ，  
> > 对应 $\varphi = \frac{\pi}{3}, \pi, \frac{5\pi}{3}$ ，因此 $\varphi$ 的取值个数为3个.
