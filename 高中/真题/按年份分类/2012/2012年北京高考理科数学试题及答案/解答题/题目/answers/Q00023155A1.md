> [!faq]- 2012年北京高考理科数学试题及答案解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【分析】**
> > （1）原曲线方程，化为标准方程，利用曲线 C 是焦点在 x 轴点上的椭圆可得不等式组，即可求得 m 的取值范围；
>
> > [!note]- **【解析】**
> > 分析：（1）原曲线方程，化为标准方程，利用曲线 C 是焦点在 x 轴点上的椭圆可得不等式组，即可求得 m 的取值范围；
> >
> > (2) 由已知直线代入椭圆方程化简得: $(2k^{2} + 1)x^{2} + 16kx + 24 = 0, \triangle = 32(2k^{2} - 3)$ , 解得: $k^{2} > \frac{3}{2}$ , 设 $N(x_{N}, kx_{N} + 4), M(x_{M}, kx_{M} + 4), G(x_{G}, 1), MB$ 方程为: $y = \frac{kx_{M} + 6}{x_{M}}x - 2$ ,则 $G(\frac{3x_{M}}{kx_{M} + 6},1)$ ，从而可得 $\overrightarrow{AG} = (\frac{3x_{M}}{kx_{M} + 6}, - 1)$ ， $\overrightarrow{AN} = (x_N,kx_N + 2)$ ，欲证A，G，N三点共线，只需证 $\overrightarrow{AG}$ ， $\overrightarrow{AN}$ 共线，利用韦达定理，可以证明.
> >
> > (1) 解：原曲线方程可化简得： $\frac{x^{2}}{5-m}+\frac{y^{2}}{m-2}=1$
> >
> > 由题意，曲线C是焦点在x轴点上的椭圆可得： $\left\{\begin{aligned}\frac{8}{5-m}&>\frac{8}{m-2}\\ \frac{8}{5-m}&>0\\ \frac{8}{m-2}&>0\end{aligned}\right.$ ，解得： $\frac{7}{2}<m<5$
> >
> > (2) 证明: 由已知直线代入椭圆方程化简得: $(2k^{2} + 1)x^{2} + 16kx + 24 = 0, \triangle = 32(2k^{2} - 3) > 0$ , 解得: $k^{2} > \frac{3}{2}$
> >
> > 由韦达定理得： $x_{M}+x_{N}=-\frac{16k}{2k^{2}+1}$ ①， $x_{M}x_{N}=\frac{24}{2k^{2}+1}$ ，②
> >
> > 设 N $(x_{N}, kx_{N}+4)$ ，M $(x_{M}, kx_{M}+4)$ ，G $(x_{G}, 1)$ ，MB 方程为： $y=\frac{kx_{M}+6}{x_{M}}x-2$ ，则 $G\left(\frac{3x_{M}}{kx_{M}+6},1\right)$
> >
> > $$
> > \therefore \overrightarrow {A G} = (\frac {3 x _ {M}}{k x _ {M} + 6}, - 1), \overrightarrow {A N} = (x _ {N}, k x _ {N} + 2),
> > $$
> >
> > 欲证A，G，N三点共线，只需证 $\overrightarrow{\mathrm{AG}}$ ， $\overrightarrow{\mathrm{AN}}$ 共线
> >
> > 即 $\frac{3\mathrm{x}_{\mathbb{M}}}{\mathrm{x}_{\mathbb{M}}\mathrm{k} + 6}$ （ $\mathbf{x}_N\mathbf{k} + 2$ ） $= -\mathbf{x}_N$ 成立，化简得：（3k+k） $\mathrm{x_Mx_N = -6(x_M + x_N)}$
> >
> > 将①②代入可得等式成立，则 A，G，N 三点共线得证.
> >
> > 点评：本题考查椭圆的标准方程，考查直线与椭圆的位置关系，考查三点共线，解题的关键是直线与椭圆方程联立，利用韦达定理进行求解.
