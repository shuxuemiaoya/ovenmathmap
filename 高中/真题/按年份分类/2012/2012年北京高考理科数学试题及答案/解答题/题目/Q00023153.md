17.（13分）（2012·北京）近年来，某市为促进生活垃圾的分类处理，将生活垃圾分为厨余垃圾、可回收物和其他垃圾三类，并分别设置了相应的垃圾箱，为调查居民生活垃圾分类投放情况，先随机抽取了该市三类垃圾箱总计1000吨生活垃圾，数据统计如下（单位：吨）；

<table><tr><td></td><td>“厨余垃圾”箱</td><td>“可回收物”箱</td><td>“其他垃圾”箱</td></tr><tr><td>厨余垃圾</td><td>400</td><td>100</td><td>100</td></tr><tr><td>可回收物</td><td>30</td><td>240</td><td>30</td></tr><tr><td>其他垃圾</td><td>20</td><td>20</td><td>60</td></tr></table>

(1) 试估计厨余垃圾投放正确的概率;

(2) 试估计生活垃圾投放错误的概率;

(3) 假设厨余垃圾在“厨余垃圾”箱、“可回收物”箱、“其他垃圾”箱的投放量分别为 $a, b, c$ ，其中 $a > 0, a + b + c = 600$ . 当数据 $a, b, c$ 的方差 $s^2$ 最大时，写出 $a, b, c$ 的值（结论不要求证明），并求此时 $s^2$ 的值.

(求： $S^{2}=\frac{1}{n}\left[\left(x_{1}-\overline{x}\right)^{2}+\left(x_{2}-\overline{x}\right)^{2}+\ldots+\left(x_{n}-\overline{x}\right)^{2}\right]$ ，其中 $\overline{x}$ 为数据 $x_{1},x_{2},\cdots,x_{n}$ 的平均数)

考 模拟方法估计概率；极差、方差与标准差.

点：

专 概率与统计.

题：

分 （1）厨余垃圾 600 吨，投放到 “厨余垃圾” 箱 400 吨，故可求厨余垃圾投放正确的概率；

析：（2）生活垃圾投放错误有 $200 + 60 + 20 + 20 = 300$ ，故可求生活垃圾投放错误的概率；

(3) 计算方差可得 $s^2 = \frac{1}{3} \left[ (a - 200)^2 + (b - 200)^2 + (c - 200)^2 \right] =$

$\frac{1}{3} (a^2 + b^2 + c^2 - 120000)$ ，因此有当 $a = 600$ ， $b = 0$ ， $c = 0$ 时，有 $s^2 = 80000$ 。

解：(1)由题意可知：厨余垃圾600吨，投放到“厨余垃圾”箱400吨，故厨余垃圾投放正确的概答：率为 $\frac{400}{600}=\frac{2}{3}$ ;

(2) 由题意可知: 生活垃圾投放错误有 $200 + 60 + 20 + 20 = 300$ , 故生活垃圾投放错误的概率为 $\frac{300}{1000} = \frac{3}{10}$ ;

(3) 由题意可知: $\because a + b + c = 600, \therefore a, b, c$ 的平均数为 $200$

$$
\therefore s ^ {2} = \frac {1}{3} [ (a - 2 0 0) ^ {2} + (b - 2 0 0) ^ {2} + (c - 2 0 0) ^ {2} ] = \frac {1}{3} (a ^ {2} + b ^ {2} + c ^ {2} - 1 2 0 0 0 0)
$$

$\because (a + b + c)^2 = a^2 + b^2 + c^2 + 2ab + 2bc + 2ac \geq a^2 + b^2 + c^2$ ，因此有当 $a = 600$ ， $b = 0$ ， $c = 0$ 时，有 $s^2 = 80000$ 。点 本题考查概率知识的运用，考查学生的阅读能力，属于中档题。
