> [!faq]- 2012年北京高考理科数学试题及答案解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【分析】**
> > 求出集合 B, 然后直接求解 A∩B.
>
> > [!note]- **【解析】**
> > 分析: 求出集合 B, 然后直接求解 A∩B.
> >
> > 解答：解：因为 $B = \{x\in R|$ （ $x + 1$ ）（ $x - 3$ ） $>0$ } = $\{x|x < -1$ 或 $x > 3\}$ ，又集合 $A = \{x\in R|3x + 2 > 0\} = \{x|x > -\frac{2}{3}\}$ ，所以 $A\cap B = \{x|x > -\frac{2}{3}\} \cap \{x|x < -1$ 或 $x > 3\} = \{x|x > 3\}$ ，故选：D.
> >
> > 点评：本题考查一元二次不等式的解法，交集及其运算，考查计算能力.
