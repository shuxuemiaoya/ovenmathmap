> [!faq]- 2012年全国统一高考数学试卷（理科）（新课标）（含解析版）解析
>
> > [!success]- **【答案】** (12 分) 已知函数 f(x) 满足 f(x) = f'
>
> > [!note]- **【分析】**
> > (1) 对函数 $f(x)$ 求导, 再令自变量为 1, 求出 $f'
> > (1)$ 得到函数的解析式及导
>
> > [!note]- **【解析】**
> > 解：
> > （1） $f(x) = f'(1)e^{x-1} - f(0)x + \frac{1}{2}x^2 \Rightarrow f'(x) = f'(1)e^{x-1} - f(0) + x$
> >
> > 令 $x = 1$ 得：f（0）=1
> >
> > $\therefore f(x) = f'(1)e^{x - 1} - x + \frac{1}{2} x^2$ 令 $x = 0$ ，得 $f(0) = f'(1)e^{-1} = 1$ 解得 $f'(1) = e$
> >
> > 故函数的解析式为 $f(x) = e^x - x + \frac{1}{2} x^2$
> >
> > 令 g (x) = f' (x) = e^x - 1 + x
> >
> > ∴ $g'(x) = e^{x} + 1 > 0$ ，由此知 $y = g(x)$ 在 $x \in R$ 上单调递增
> >
> > 当 x > 0 时， $f'(x) > f'(0) = 0$ ; 当 x < 0 时，有
> >
> > $f'(x) < f'(0) = 0$ 得:
> >
> > 函数 $f(x) = e^{x} - x + \frac{1}{2} x^{2}$ 的单调递增区间为 $(0, +\infty)$ ，单调递减区间为 $(-\infty, 0)$
> >
> > $$
> > (2) f (x) \geqslant \frac {1}{2} x ^ {2} + a x + b \Leftrightarrow h (x) = e ^ {x} - (a + 1) x - b \geq 0 \text {得} h ^ {\prime} (x) = e ^ {x} - (a + 1)
> > $$
> >
> > ① 当 $a+1 \leq 0$ 时， $h'(x) > 0 \Rightarrow y = h(x)$ 在 $x \in R$ 上单调递增， $x \to -\infty$ 时， $h(x) \to -\infty$ 与
> >
> > h (x) ≥0 矛盾
> >
> > ② 当 $a+1>0$ 时， $h'(x)>0\Leftrightarrow x>\ln(a+1)$ ， $h'(x)<0\Leftrightarrow x<\ln(a+1)$
> >
> > 得: 当 $x=\ln(a+1)$ 时, $h(x)_{\min}=(a+1)-(a+1)\ln(a+1)-b\geq0$ , 即 $(a+1)-(a+1)\ln$
> >
> > (a+1) $\geqslant b$
> >
> > $$
> > \therefore (a + 1) b \leq (a + 1) ^ {2} - (a + 1) ^ {2} \ln (a + 1), \quad (a + 1 > 0)
> > $$
> >
> > 令 $F(x) = x^{2} - x^{2} \ln x (x > 0)$ ，则 $F'(x) = x (1 - 2 \ln x)$
> >
> > $$
> > \therefore F ^ {\prime} (x) > 0 \Leftrightarrow 0 <   x <   \sqrt {e}, F ^ {\prime} (x) <   0 \Leftrightarrow x > \sqrt {e}
> > $$
> >
> > 当 $x = \sqrt{e}$ 时， $F(x)_{\max} = \frac{e}{2}$
> >
> > 即当 $a = \sqrt{e} - 1$ ， $b = \frac{\sqrt{e}}{2}$ 时，（ $a + 1$ ）b的最大值为 $\frac{e}{2}$
