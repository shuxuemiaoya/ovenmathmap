> >

> > 【
> > 解答】解：由 A, B, C 成等差数列，及 $A + B + C = \pi$ 得 $B = \frac{\pi}{3}$ ，故有 $A + C = \frac{2\pi}{3}$
> >
> > 由 $2b^{2}=3ac$ 得 $2\sin^{2}B=3\sin A\sin C=\frac{3}{2}$ ,
> >
> > 所以 $\sin A \sin C = \frac{1}{2}$
> >
> > 所以 $\cos(A+C)=\cos A \cos C-\sin A \sin C=\cos A \cos C-\frac{1}{2}$
> >
> > 即 $\cos A\cos C - \frac{1}{2} = -\frac{1}{2}$ ，可得 $\cos A\cos C = 0$
> >
> > 所以 $\cos A=0$ 或 $\cos C=0$ ，即 A 是直角或 C 是直角
> >
> > 所以 A 是直角，或 $A=\frac{\pi}{6}$
> >

> >
> > 公式, 正弦定理的作用边角互化, 解题的关键是熟练掌握等差数列的性质及三
> >
