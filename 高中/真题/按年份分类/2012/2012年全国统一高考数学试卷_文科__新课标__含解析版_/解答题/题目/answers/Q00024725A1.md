> [!faq]- 2012年全国统一高考数学试卷（文科）（新课标）（含解析版）解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【分析】**
> > ①不等式等价于 $\left\{\begin{aligned}&x\leqslant2\\ &3-x+2-x\geqslant3\end{aligned}\right.$ ，或 $\left\{\begin{aligned}&2<x<3\\ &3-x+x-2\geqslant3\end{aligned}\right.$ ，或 $\left\{\begin{aligned}&x\geqslant3\\ &x-3+x-2\geqslant3\end{aligned}\right.$ ，求出
>
> > [!note]- **【解析】**
> > 分析】①不等式等价于 $\left\{\begin{aligned}&x\leqslant2\\ &3-x+2-x\geqslant3\end{aligned}\right.$ ，或 $\left\{\begin{aligned}&2<x<3\\ &3-x+x-2\geqslant3\end{aligned}\right.$ ，或 $\left\{\begin{aligned}&x\geqslant3\\ &x-3+x-2\geqslant3\end{aligned}\right.$ ，求出
> >
> > 每个不等式组的解集，再取并集即得所求.
> >
> > ② 原命题等价于 $-2 - x \leq a \leq 2 - x$ 在 $[1, 2]$ 上恒成立，由此求得求 a 的取值范围.
> >
> > 【
> > 解答】解：（1）当 $a = -3$ 时， $f(x) \geqslant 3$ 即 $|x - 3| + |x - 2| \geqslant 3$ ，即
> >
> > $\left\{ \begin{array}{l} x \leqslant 2 \\ 3 - x + 2 - x \geqslant 3 \end{array} \right.$ ，可得 $x \leq 1$ ；
> >
> > $\left\{ \begin{array}{l} 2 < x < 3 \\ 3 - x + x - 2 \geqslant 3 \end{array} \right.$ ，可得 $x \in \emptyset$ ；
> >
> > $\left\{ \begin{array}{l} x \geqslant 3 \\ x - 3 + x - 2 \geqslant 3 \end{array} \right.$ ，可得 $x \geq 4$ 。
> >
> > 取并集可得不等式的解集为 $\{x \mid x \leq 1 \text{ 或 } x \geq 4\}$ .
> >
> > (2) 原命题即 $f(x) \leqslant |x - 4|$ 在[1, 2]上恒成立，等价于 $|x + a| + 2 - x \leq 4 - x$ 在[1, 2]
> >
> > 上恒成立，
> >
> > 等价于 $|x + a| \leq 2$ ，等价于 $-2 \leq x + a \leq 2$ ， $-2 - x \leq a \leq 2 - x$ 在[1, 2]上恒成立.
> >
> > 故当 $1 \leq x \leq 2$ 时， $-2 - x$ 的最大值为 $-2 - 1 = -3$ ， $2 - x$ 的最小值为 $0$ ，
> >
> > 故 a 的取值范围为 $[-3, 0]$ .
> >
> > 【点评】本题主要考查绝对值不等式的解法,关键是去掉绝对值,化为与之等价的
> >
> > 不等式组来解，体现了分类讨论的数学思想，属于中档题.
