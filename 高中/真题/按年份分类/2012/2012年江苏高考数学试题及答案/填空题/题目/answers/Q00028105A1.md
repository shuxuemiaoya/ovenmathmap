> [!faq]- 2012年江苏高考数学试题及答案解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > 解答：解：（1）∵ $\overrightarrow{AB}\cdot\overrightarrow{AC}=3\overrightarrow{BA}\cdot\overrightarrow{BC}$
> >
> > ∴cbcosA=3cacosB，即 bcosA=3acosB，
> >
> > 由正弦定理 $\frac{b}{\sin B} = \frac{a}{\sin A}$ 得： $\sin B \cos A = 3 \sin A \cos B$
> >
> > 又 $0 < A + B < \pi, \therefore \cos A > 0, \cos B > 0,$
> >
> > 在等式两边同时除以 $\cos A \cos B$ ，可得 $\tan B = 3 \tan A$ ;
> >
> > (2) $\because \cos C = \frac{\sqrt{5}}{5}, 0 < C < \pi,$
> >
> > $$
> > \sin C = \sqrt {1 - \cos C ^ {2}} = \frac {2 \sqrt {5}}{5},
> > $$
> >
> > $\therefore \tan C = 2$
> >
> > 则 $\tan[\pi - (A+B)] = 2$ ，即 $\tan(A+B) = -2$ ，
> >
> > $\therefore \frac{\tan A + \tan B}{1 - \tan A\tan B} = -2,$
> >
> > 将 $\tan B = 3\tan A$ 代入得： $\frac{\tan A + 3\tan A}{1 - 3\tan^2A} = -2,$
> >
> > 整理得： $3\tan^{2}A - 2\tan A - 1 = 0$ ，即 $(\tan A - 1)$ $(3\tan A + 1) = 0$ ，
> >
> > 解得： $\tan A = 1$ 或 $\tan A = -\frac{1}{3}$
> >
> > 又 $\cos A > 0,\quad \therefore \tan A = 1,$
> >
> > 又 A 为三角形的内角，
> >
> > 则 $A=\frac{\pi}{4}$ .
> >
> > 点评：此题属于解三角形的题型，涉及的知识有：平面向量的数量积运算法则，正弦定理，同角三角函数间的基本关系，诱导公式，两角和与差的正切函数公式，以及特殊角的三角函数值，熟练掌握定理及公式是解本题的关键.
