> [!faq]- 2012年全国统一高考数学试卷（理科）（大纲版）（含解析版）解析
>
> > [!success]- **【答案】** 为： $\frac{5\pi}{6}$ 【点评】本题考查三角函数的最值两与角和与差的正弦函数，着重考查辅助角公 式的应用与正弦函数的性质，将 $y=\sin x-\sqrt{3}\cos x\quad(0\leq x<2\pi)$ 化为 $y=2\sin(x-$ $\frac{\pi}{3})$ （ $0 \leq x < 2\pi$ ）是关键，属于中档题.
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > 解答】解： $\because y = \sin x - \sqrt{3} \cos x = 2$ ( $\frac{1}{2} \sin x - \frac{\sqrt{3}}{2} \cos x$ ) $= 2 \sin (x - \frac{\pi}{3})$ .
> >
> > $\because 0 \leq x < 2\pi,$
> >
> > $$
> > \therefore - \frac {\pi}{3} \leq x - \frac {\pi}{3} <   \frac {5 \pi}{3},
> > $$
> >
> > $\therefore y_{\max} = 2$ ，此时 $x - \frac{\pi}{3} = \frac{\pi}{2}$
> >
> > $$
> > \therefore x = \frac {5 \pi}{6}
> > $$
> >
> > 故
> > 答案为： $\frac{5\pi}{6}$
