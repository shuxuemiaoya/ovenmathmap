> > [!success]- **【答案】** 详见解析

> > [!note]- **【分析】**
> > （Ⅰ）用数学归纳法证明：① n=1 时， $x_{1}=2$ ，直线 $PQ_{1}$ 的方程为 $y-5=\frac{f(2)-5}{2-4}(x-4)$ ，当 y=0 时，可得 $x_{2}=\frac{11}{4}$ ；② 假设 n=k 时，结论成立，即 $2\leq x_{k}<x_{k+1}<3$ ，直线 $PQ_{k+1}$ 的方程为 $y-5=\frac{f(x_{k+1})-5}{x_{k+1}-4}(x-4)$ ，当 y=0 时，可得 $x_{k+2}=\frac{3+4x_{k+1}}{2+x_{k+1}}$ ，根据归纳假设 $2\leq x_{k}<x_{k+1}<3$ ，可以证明 $2\leq x_{k+1}<x_{k+2}<3$ ，从而结论成立。
>
> > [!note]- **【解析】**
> > 分析】（Ⅰ）用数学归纳法证明：① n=1 时， $x_{1}=2$ ，直线 $PQ_{1}$ 的方程为 $y-5=\frac{f(2)-5}{2-4}(x-4)$ ，当 y=0 时，可得 $x_{2}=\frac{11}{4}$ ；② 假设 n=k 时，结论成立，即 $2\leq x_{k}<x_{k+1}<3$ ，直线 $PQ_{k+1}$ 的方程为 $y-5=\frac{f(x_{k+1})-5}{x_{k+1}-4}(x-4)$ ，当 y=0 时，可得 $x_{k+2}=\frac{3+4x_{k+1}}{2+x_{k+1}}$ ，根据归纳假设 $2\leq x_{k}<x_{k+1}<3$ ，可以证明 $2\leq x_{k+1}<x_{k+2}<3$ ，从而结论成立。
> >
> > （II）由（I），可得 $x_{n+1}=\frac{3+4x_n}{2+x_n}$ ，构造 $b_n=x_n-3$ ，可得 $\left\{\frac{1}{b_n}+\frac{1}{4}\right\}$ 是以 $-\frac{3}{4}$ 为首项，5
> >
> > 为公比的等比数列，由此可求数列 $\{x_{n}\}$ 的通项公式.
> >
> > 【
> > 解答】（Ⅰ）证明：① n=1 时， $x_{1}=2$ ，直线 $PQ_{1}$ 的方程为 $y-5=\frac{f(2)-5}{2-4}(x-4)$ 当 y=0 时， $\therefore x_{2}=\frac{11}{4}$ ， $\therefore 2 \leq x_{1} < x_{2} < 3;$
> >
> > ② 假设 $n = k$ 时，结论成立，即 $2 \leq x_{k} < x_{k+1} < 3$ ，直线 $\mathrm{PQ}_{k+1}$ 的方程为
> >
> > $$
> > y - 5 = \frac {f (x _ {k + 1}) - 5}{x _ {k + 1} - 4} (x - 4)
> > $$
> >
> > 当 $y = 0$ 时， $\therefore x_{k + 2} = \frac{3 + 4x_{k + 1}}{2 + x_{k + 1}}$
> >
> > $$
> > \because 2 \leq x _ {k} <   x _ {k + 1} <   3, \therefore x _ {k + 2} = 4 - \frac {5}{2 + x _ {k + 1}} <   4 - \frac {5}{2 + 3} = 3
> > $$
> >
> > $$
> > \mathrm{x} _ {\mathrm{k} + 2} - \mathrm{x} _ {\mathrm{k} + 1} = \frac {(3 - \mathrm{x} _ {\mathrm{k} + 1}) (1 + \mathrm{x} _ {\mathrm{k} + 1})}{2 + \mathrm{x} _ {\mathrm{k} + 1}} > 0
> > $$
> >
> > $$
> > \therefore x _ {k + 1} <   x _ {k + 2}
> > $$
> >
> > $$
> > \therefore 2 \leq x _ {k + 1} <   x _ {k + 2} <   3
> > $$
> >
> > 即 $n=k+1$ 时，结论成立
> >
> > 由①②可知： $2 \leq x_{n} < x_{n+1} < 3;$
> >
> > （Ⅱ）由（Ⅰ），可得 $x_{n+1}=\frac{3+4x_{n}}{2+x_{n}}$
> >
> > 设 $b_{n}=x_{n}-3,\therefore\frac{1}{b_{n+1}}=\frac{5}{b_{n}}+1$
> >
> > $$
> > \therefore \frac {1}{b _ {n + 1}} + \frac {1}{4} = 5 \left(\frac {1}{b _ {n}} + \frac {1}{4}\right)
> > $$
> >
> > $\therefore \left\{\frac{1}{b_n} +\frac{1}{4}\right\}$ 是以 $-\frac{3}{4}$ 为首项，5为公比的等比数列
> >
> > $$
> > \therefore \frac {1}{b _ {n}} + \frac {1}{4} = (- \frac {3}{4}) \times 5 ^ {n - 1}
> > $$
> >
> > $$
> > \therefore b _ {n} = - \frac {4}{3 \times 5 ^ {n - 1} + 1}
> > $$
> >
> > $$
> > \therefore x _ {n} = b _ {n} + 3 = 3 - \frac {4}{3 \times 5 ^ {n - 1} + 1}.
> > $$
> >
> > 【点评】本题考查数列的通项公式, 考查数列与函数的综合, 解题的关键是从函数
> >
> > 入手，确定直线方程，求得交点坐标，再利用数列知识解决.
