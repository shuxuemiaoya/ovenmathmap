> [!faq]- 2012年全国统一高考数学试卷（理科）（大纲版）（含解析版）解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【分析】**
> > （Ⅰ）求导函数，可得 $f'(x)=a-\sin x, x\in[0,\pi], \sin x\in[0,1]$ ，对 a 进行分类
>
> > [!note]- **【解析】**
> > 解：（Ⅰ）求导函数，可得 $f'(x) = a - \sin x, x \in [0, \pi], \sin x \in [0, 1]$ ;
> >
> > 当 $a \leq 0$ 时， $f'(x) \leq 0$ 恒成立， $f(x)$ 单调递减；当 $a \geq 1$ 时， $f'(x) \geq 0$ 恒成立， $f(x)$ 单
> >
> > 调递增；
> >
> > 当 0 < a < 1 时，由 $f'(x) = 0$ 得 $x_{1} = arcsina, x_{2} = \pi - arcsina$
> >
> > 当 $x \in [0, x_1]$ 时， $\sin x < a$ ， $f'(x) > 0$ ， $f(x)$ 单调递增
> >
> > 当 $x \in [x_{1}, x_{2}]$ 时， $\sin x > a, f'(x) < 0, f(x)$ 单调递减
> >
> > 当 $x \in [x_{2}, \pi]$ 时， $\sin x < a, f'(x) > 0, f(x)$ 单调递增；
> >
> > （II）由 $f(x) \leqslant 1 + \sin x$ 得 $f(\pi) \leqslant 1, a\pi - 1 \leq 1, \therefore a \leq \frac{2}{\pi}$ .
> >
> > 令 $g(x) = \sin x - \frac{2}{\pi} x (0 \leq x \leqslant \frac{\pi}{2})$ ，则 $g'(x) = \cos x - \frac{2}{\pi}$
> >
> > 当 $x \in (0, \arccos \frac{2}{\pi})$ 时， $g'(x) > 0$ ，当 $x \in (\arccos \frac{2}{\pi}, \frac{\pi}{2})$ 时， $g'(x) < 0$
> >
> > $\because g(0) = g(\frac{\pi}{2}) = 0, \therefore g(x) \geqslant 0,$ 即 $\frac{2}{\pi} x \leqslant \sin x (0 \leqslant x \leqslant \frac{\pi}{2})$
> >
> > 当 $a \leq \frac{2}{\pi}$ 时，有 $f(x) \leqslant \frac{2}{\pi} x + \cos x$
> >
> > ① 当 $0 \leq x \leq \frac{\pi}{2}$ 时， $\frac{2}{\pi} x \leq \sin x$ ， $\cos x \leq 1$ ，所以 $f(x) \leq 1 + \sin x$ ;
> >
> > ② 当 $\frac{\pi}{2} \leqslant x \leqslant \pi$ 时， $f(x) \leqslant \frac{2}{\pi} x + \cos x = 1 + \frac{2}{\pi} (x - \frac{\pi}{2}) - \sin (x - \frac{\pi}{2}) \leq 1 + \sin x$ 综上， $a \leq \frac{2}{\pi}$ .
> >
> > 【点评】本题考查导数知识的运用，考查函数的单调性，考查函数的最值，解题的
> >
> > 关键是正确求导，确定函数的单调性.
