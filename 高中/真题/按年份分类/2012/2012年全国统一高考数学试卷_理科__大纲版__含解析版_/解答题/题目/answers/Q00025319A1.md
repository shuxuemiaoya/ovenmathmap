> [!faq]- 2012年全国统一高考数学试卷（理科）（大纲版）（含解析版）解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【分析】**
> > 由 $\cos(A-C)+\cos B=\cos(A-C)-\cos(A+C)=1$ ，可得 $\sin A\sin C=\frac{1}{2}$ ，由 a=2c
>
> > [!note]- **【解析】**
> > 解：由 $B=\pi-(A+C)$ 可得 $\cos B=-\cos(A+C)$
> >
> > $$
> > \therefore \cos (A - C) + \cos B = \cos (A - C) - \cos (A + C) = 2 \sin A \sin C = 1
> > $$
> >
> > $$
> > \therefore \sin A \sin C = \frac {1}{2} ①
> > $$
> >
> > 由 a=2c 及正弦定理可得 $\sin A=2\sin C②$
> >
> > ①② 联立可得， $\sin^{2}C=\frac{1}{4}$
> >
> > $$
> > \because 0 <   c <   \pi
> > $$
> >
> > $$
> > \therefore \sin C = \frac {1}{2}
> > $$
> >
> > a=2c 即 a>c
> >
> > $$
> > C = \frac {\pi}{6}
> > $$
> >
> > 【点评】本题主要考查了两角和与差的余弦公式及正弦定理的应用，属于基础试题
