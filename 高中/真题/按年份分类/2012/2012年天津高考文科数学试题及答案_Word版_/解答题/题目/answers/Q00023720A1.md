> [!faq]- 2012年天津高考文科数学试题及答案(Word版)解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【分析】**
> > （1）求导函数，令 $f'(x) > 0$ ，可得函数的递增区间；令 $f'(x) < 0$ ，可得单调递减区间；
> > (2) 由
> > (1) 知函数在区间 $(-2, -1)$ 内单调递增，在 $(-1, 0)$ 内单调递减，从而函数在 $(-2, 0)$ 内恰有两个零点，由此可求 $a$ 的取值范围；
>
> > [!note]- **【解析】**
> > 解：
> > （1）求导函数可得 $f'(x) = (x + 1) \quad (x - a)$ ，令 $f'(x) = 0$ ，可得 $x_1 = -1, x_2 = a > 0$
> >
> > 令 $f'(x) > 0$ ，可得 $x < -1$ 或 $x > a$ ；令 $f'(x) < 0$ ，可得 $-1 < x < a$
> >
> > 故函数的递增区间为 $(- \infty, -1)$ ， $(a, +\infty)$ ，单调递减区间为 $(-1, a, \cdot)$
> > (2) 由
> > (1) 知函数在区间 $(-2, -1)$ 内单调递增，在 $(-1, 0)$ 内单调递减，从而函数在 $(-2, 0)$ 内恰有两个零点，
> >
> > $$
> > \therefore \left\{ \begin{array}{l} f (- 2) <   0 \\ f (- 1) > 0, \\ f (0) <   0 \end{array} \right. \therefore \left\{ \begin{array}{l} - \frac {2}{3} - a <   0 \\ \frac {1}{6} - \frac {a}{2} > 0 \\ - a <   0 \end{array} , \therefore 0 <   a <   \frac {1}{3} \right.
> > $$
> >
> > ∴a 的取值范围为 $(0, \frac{1}{3})$ ;
> > (3) $a = 1$ 时， $f(x) = \frac{1}{3} x^3 - x - 1$ ，由
> > (1) 知，函数在 $(-3, -1)$ 上单调递增，在 $(-1, 1)$ 上单调递减，在 $(1, 2)$ 上单调递增
> >
> > ① 当 $t \in [-3, -2]$ 时， $t + 3 \in [0, 1], -1 \in [t, t + 3]$ ， $f(x)$ 在 $[t, -1]$ 上单调递增，在 $[-1, t + 3]$ 上单调递减因此函数在 $[t, t + 3]$ 上的最大值为 $M(t) = f(-1) = -\frac{1}{3}$ ，而最小值 $m(t)$ 为 $f(t)$ 与 $f(t + 3)$ 中的较小者由 $f(t + 3) - f(t) = 3(t + 1)(t + 2)$ 知，当 $t \in [-3, -2]$ 时， $f(t) \leqslant f(t + 3)$ ，故 $m(t) = f(t)$ ，所以 $g(t) = f(-1) - f(t)$ 而 $f(t)$ 在 $[-3, -2]$ 上单调递增，因此 $f(t) \leqslant f(-2) = -\frac{5}{3}$ ，所以 $g(t)$ 在 $[-3, -2]$ 上的最小值为 $g(-2) = -\frac{1}{3} - (-\frac{5}{3}) = \frac{4}{3}$
> >
> > ② 当 $t \in [-2, -1]$ 时， $t + 3 \in [1, 2], -1, 1 \in [t, t + 3]$ ，下面比较 $f(-1), f(1), f(t), f(t + 3)$ 的大小。由 $f(x)$ 在 $[-2, -1]$ ， $[1, 2]$ 上单调递增，有
> >
> > f (-2) $\leqslant$ f (t) $\leqslant$ f (-1), f
> > (1) $\leqslant$ f (t+3) $\leqslant$ f
> > (2) $\because f(1)=f(-2)=-\frac{5}{3},f(-1)=f(2)=-\frac{1}{3}$ $\therefore M(t)=f(-1)=-\frac{1}{3},m(t)=f(1)=-\frac{5}{3}$ $\therefore g(t)=M(t)-m(t)=\frac{4}{3}$
> >
> > 综上，函数 $g(t)$ 在区间[-3，-1]上的最小值为 $\frac{4}{3}$ .
> >
> > 点评：本题考查导数知识的运用，考查函数的单调性，考查函数的最值，考查分类讨论的数学思想，正确求导与分类讨论是解题的关键.
