> [!faq]- 2012年高考浙江文科数学试题及答案(精校版)解析
>
> > [!success]- **【答案】** A
>
> > [!note]- **【分析】**
> > 对于 $e^{a} + 2a = e^{b} + 3b$ ，若 $a \leq b$ 成立，经
>
> > [!note]- **【解析】**
> > 分析：对于 $e^{a} + 2a = e^{b} + 3b$ ，若 $a \leq b$ 成立，经
> > 分析可排除B；对于 $e^{a} - 2a = e^{b} - 3b$ ，若 $a \geq b$ 成立，经
> > 分析可排除C，D，从而可得
> > 答案.
> >
> > 解答: 解: 对于 $e^{a}+2a=e^{b}+3b$ ，若 $a\leq b$ 成立，则必有 $e^{a}\leq e^{b}$ ，故必有 $2a\geq3b$ ，即有 $a\geq\frac{3}{2}b$ 这与 $a\leq b$ 矛盾，故 $a\leq b$ 成立不可能成立，故 B 不对；
> >
> > 对于 $e^{a} - 2a = e^{b} - 3b$ ，若 $a \geq b$ 成立，则必有 $e^{a} \geq e^{b}$ ，故必有 $2a \geq 3b$ ，即有 $a \geq \frac{3}{2}b$ ，故排除 C，D. 故选 A.
> >
> > 点评：本题考查指数函数综合题，对于 $e^{a} + 2a = e^{b} + 3b$ 与 $e^{a} - 2a = e^{b} - 3b$ ，根据选项中的条件逆向
> > 分析而排除不适合的选项是关键，也是难点，属于难题.
