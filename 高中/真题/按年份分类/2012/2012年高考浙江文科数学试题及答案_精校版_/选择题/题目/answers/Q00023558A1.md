> [!faq]- 2012年高考浙江文科数学试题及答案(精校版)解析
>
> > [!success]- **【答案】** C
>
> > [!note]- **【分析】**
> > 将 $x + 3y = 5xy$ 转化成 $\frac{3}{5x} +\frac{1}{5y} = 1$ ，然后根据 $3x + 4y = (\frac{3}{5x} +\frac{1}{5y})(3x + 4y)$ ，展开后利用基本不等式可求出 $3x + 4y$ 的最小值.
>
> > [!note]- **【解析】**
> > 解：∵正数 $x$ ，y满足 $x + 3y = 5xy$ ∴ $\frac{3}{5x} +\frac{1}{5y} = 1$ ∴ $3x + 4y = (\frac{3}{5x} +\frac{1}{5y}) (3x + 4y) = \frac{9}{5} +\frac{4}{5} +\frac{12y}{5x} +\frac{3x}{5y}\geq \frac{13}{5} +2\sqrt{\frac{12y}{5x}\cdot\frac{3x}{5y}} = 5$ 当且仅当 $\frac{12y}{5x} = \frac{3x}{5y}$ 时取等号∴ $3x + 4y\geq 5$ 即 $3x + 4y$ 的最小值是5故选C
> >
