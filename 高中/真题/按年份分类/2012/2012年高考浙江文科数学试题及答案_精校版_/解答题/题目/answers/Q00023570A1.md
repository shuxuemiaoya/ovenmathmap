> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【分析】**
> > (1) 求导函数, 再分类讨论: $a \leq 0$ 时, $f'(x) \geqslant 0$ 恒成立; $a > 0$ 时, $f'(x) = 12x^2 - 2a = 12(x - \sqrt{\frac{a}{6}})(x + \sqrt{\frac{a}{6}})$ , 由此可确定 $f(x)$ 的单调递增区间; 单调递增区间;
>
> > [!note]- **【解析】**
> > 分析:
> >
> > (1) 求导函数, 再分类讨论: $a \leq 0$ 时, $f'(x) \geqslant 0$ 恒成立; $a > 0$ 时, $f'(x) = 12x^2 - 2a = 12(x - \sqrt{\frac{a}{6}})(x + \sqrt{\frac{a}{6}})$ , 由此可确定 $f(x)$ 的单调递增区间; 单调递增区间;
> >
> > (2) 由于 $0 \leq x \leq 1$ ，故当 $a \leq 2$ 时， $f(x) + |2 - a| = 4x^3 - 2ax + 2 \geq 4x^3 - 4x + 2$ ；当 $a > 2$ 时， $f(x) + |2 - a| = 4x^3 + 2a(1 - x) - 2 \geq 4x^3 + 4(1 - x) - 2 = 4x^3 - 4x + 2$ ，构造函数 $g(x) = 2x^3 - 2x + 1, 0 \leq x \leq 1$ ，确定 $g(x)_{\min} = g(\frac{\sqrt{3}}{3}) = 1 - \frac{4\sqrt{3}}{9} > 0$ ，即可证得结论。
> >
> > 解答：（1）解：求导函数可得 $f'(x) = 12x^{2} - 2a$
> >
> > $a \leq 0$ 时， $f'(x) \geqslant 0$ 恒成立，此时 $f(x)$ 的单调递增区间为 $(-∞, +∞)$
> >
> > a>0 时， $f'(x)=12x^{2}-2a=12(x-\sqrt{\frac{a}{6}})(x+\sqrt{\frac{a}{6}})$
> >
> > ∴f（x）的单调递增区间为 $(-∞, -\sqrt{\frac{a}{6}})$ ， $(\sqrt{\frac{a}{6}}, +∞)$ ；单调递增区间为 $(-√\frac{a}{6}, \sqrt{\frac{a}{6}})$ ；
> >
> > (2) 证明: 由于 $0 \leq x \leq 1$ , 故
> >
> > 当 $a \leq 2$ 时， $f(x) + |2 - a| = 4x^3 - 2ax + 2 \geq 4x^3 - 4x + 2$
> >
> > 当 $a > 2$ 时， $f(x) + |2 - a| = 4x^3 + 2a(1 - x) - 2 \geq 4x^3 + 4(1 - x) - 2 = 4x^3 - 4x + 2$ 设 $g(x) = 2x^3 - 2x + 1, 0 \leq x \leq 1, \therefore g'(x) = 6(x - \frac{\sqrt{3}}{3}) (x + \frac{\sqrt{3}}{3})$
> >

> >
> > $\therefore \mathrm{g(x)}_{\min} = \mathrm{g}\left(\frac{\sqrt{3}}{3}\right) = 1 - \frac{4\sqrt{3}}{9} >0$
> >
> > ∴当 $0 \leq x \leq 1$ 时， $2x^{3} - 2x + 1 > 0$
> >
> > ∴当 $0 \leq x \leq 1$ 时，f(x) + |2 - a| > 0.
