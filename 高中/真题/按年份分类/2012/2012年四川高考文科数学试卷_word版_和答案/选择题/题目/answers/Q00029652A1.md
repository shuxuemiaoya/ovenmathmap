> [!faq]- 2012年四川高考文科数学试卷(word版)和答案解析
>
> > [!success]- **【答案】** D
>
> > [!note]- **【分析】**
> > 根据 $f(x)=(x-3)^{3}+x-1$ ，可得 $f(x)-2=(x-3)^{3}+x-3$ ，构造函数 $g(x)=f(x)-2$ ，从而 $g(x)$ 关于 $(3,0)$ 对称，利用 $f(a_{1})+f(a_{2})+\ldots+f(a_{7})=14$ ，可得 $g(a_{1})+g(a_{2})+\ldots+g(a_{7})=0$ ，从而 $g(a_{4})$ 为 $g(x)$ 与 x 轴的交点，由此可求 $a_{1}+a_{2}+\ldots+a_{7}$ 的值.
>
> > [!note]- **【解析】**
> > 解： $\because f(x) = (x - 3)^{3} + x - 1, \therefore f(x) - 2 = (x - 3)^{3} + x - 3,$ 令 $g(x) = f(x) - 2$ $\therefore g(x)$ 关于（3，0）对称 $\because f(a_1) + f(a_2) + \ldots + f(a_7) = 14$ $\therefore f(a_1) - 2 + f(a_2) - 2 + \ldots + f(a_7) - 2 = 0$ $\therefore g(a_1) + g(a_2) + \ldots + g(a_7) = 0$ $\therefore g(a_4)$ 为 $g(x)$ 与 $x$ 轴的交点
> > 因为 $g(x)$ 关于（3，0）对称，所以 $a_4 = 3$ $\therefore a_1 + a_2 + \ldots + a_7 = 7a_4 = 21,$ 故选D.
> >
> > 点评：本题考查数列与函数的综合，考查函数的对称性，考查数列的性质，需要一定的基本功.
