> [!faq]- 2012年北京高考文科数学试题及答案解析
>
> > [!success]- **【答案】** $\frac{\pi}{2}$ 【 试题
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > $\cos A = \frac{b^2 + c^2 - a^2}{2bc} \Rightarrow c = 2\sqrt{3}$ 而 $\frac{c}{\sin C} = \frac{a}{\sin A}$ ，而 $\sin C = 1 \Rightarrow C = \frac{\pi}{2}$
