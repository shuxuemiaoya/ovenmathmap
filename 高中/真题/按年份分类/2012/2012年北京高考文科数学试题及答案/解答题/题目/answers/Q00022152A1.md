> > ## 17. (本小题 13 分)
> >
> > 近年来，某市为了促进生活垃圾的分类处理，将生活垃圾分为厨余垃圾、可回收物和其他垃圾三类，并分别设置了相应的垃圾箱，为调查居民生活垃圾分类投放情况，现随机抽取了该市三类垃圾箱中总计1000吨生活垃圾，数据统计如下（单位：吨）：
> >
> > <table><tr><td></td><td>“厨余垃圾”箱</td><td>“可回收物”箱</td><td>“其他垃圾”箱</td></tr><tr><td>厨余垃圾</td><td>400</td><td>100</td><td>100</td></tr><tr><td>可回收物</td><td>30</td><td>240</td><td>30</td></tr><tr><td>其他垃圾</td><td>20</td><td>20</td><td>60</td></tr></table>
> >
> > (1) 试估计厨余垃圾投放正确的概率；
> >
> > (2) 试估计生活垃圾投放错误的概率;
> >
> > (3) 假设厨余垃圾在 “厨余垃圾” 箱、“可回收物” 箱、“其他垃圾” 箱的投放量分别为 $a, b, c$ 其中 $a > 0, a + b + c = 600$ 当数据 $a, b, c$ 的方差 $S^2$ 最大时，写出 $a, b, c$ 的值（结论不要求证明），并求此时 $S^2$ 的值.
> >
> > (注：方差 $S^{2}=\frac{1}{n}\left[(x_{1}-\bar{x})^{2}+(x_{2}-\bar{x})^{2}+\cdots+(x_{n}-\bar{x})^{2}\right]$ ，其中 $\bar{x}$ 为 $x_{1}, x_{2}, \cdots, x_{n}$ 的平均数)
> >
> > 【测量目标】概率的意义、频率与概率的区别及分布的特点与意义及方差的计算.
> >
> > 【考查方式】给出垃圾数据表，分别求各项概率及方差
