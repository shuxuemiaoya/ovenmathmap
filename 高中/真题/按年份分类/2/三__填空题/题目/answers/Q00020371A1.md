> [!faq]- 2解析
>
> > [!success]- **【答案】** (1).5 (2). $720-\frac{15(3+n)}{2^{n-4}}$
>
> > [!note]- **【分析】**
> > （1）按对折列举即可；（2）根据规律可得 $S_{n}$ ，再根据错位相减法得结果.
>
> > [!note]- **【解析】**
> > （1）对折4次可得到如下规格： $\frac{5}{4}dm\times12dm,\quad\frac{5}{2}dm\times6dm,\quad5dm\times3dm,\quad10dm\times\frac{3}{2}dm,$ $20dm\times\frac{3}{4}dm$ ，共5种；
> >
> > （2）由题意可得 $S_{1} = 2\times 120$ ， $S_{2} = 3\times 60$ ， $S_{3} = 4\times 30$ ， $S_{4} = 5\times 15$ ，…， $S_{n} = \frac{120(n + 1)}{2^{n - 1}}$ 设 $S = \frac{120\times 2}{2^0} +\frac{120\times 3}{2^1} +\frac{120\times 4}{2^2} +\dots +\frac{120(n + 1)}{2^{n - 1}}$ 则 $\frac{1}{2} S = \frac{120\times 2}{2^1} +\frac{120\times 3}{2^2} +\dots +\frac{120n}{2^{n - 1}} +\frac{120(n + 1)}{2^n}$ $\frac{1}{2} S = 240 + 120\left(\frac{1}{2} +\frac{1}{2^2} +\dots +\frac{1}{2^{n - 1}}\right) - \frac{120(n + 1)}{2^n} = 240 + \frac{60\left(1 - \frac{1}{2^{n - 1}}\right)}{1 - \frac{1}{2}} -\frac{120(n + 1)}{2^n}$ 两式作差得 $= 360 - \frac{120}{2^{n - 1}} -\frac{120(n + 1)}{2^n} = 360 - \frac{120(n + 3)}{2^n},$ 因此， $S = 720 - \frac{240(n + 3)}{2^n} = 720 - \frac{15(n + 3)}{2^{n - 4}}.$ 故答案为：5； $720 - \frac{15(n + 3)}{2^{n - 4}}.$
> >
> > 【点睛】方法点睛：数列求和 常用方法：
> >
> > （1）对于等差等比数列，利用公式法可直接求解；
> >
> > （2）对于 $\left\{a_{n}b_{n}\right\}$ 结构，其中 $\left\{a_{n}\right\}$ 是等差数列， $\left\{b_{n}\right\}$ 是等比数列，用错位相减法求和；
> >
> > （3）对于 $\left\{a_{n}+b_{n}\right\}$ 结构，利用分组求和法；
> >
> > （4）对于 $\left\{\frac{1}{a_n a_{n+1}}\right\}$ 结构，其中 $\{a_n\}$ 是等差数列，公差为 $d(d \neq 0)$ ，则 $\frac{1}{a_n a_{n+1}} = \frac{1}{d} \left(\frac{1}{a_n} - \frac{1}{a_{n+1}}\right)$ ，利用裂项相消法求和.
