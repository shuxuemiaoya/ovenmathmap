19.（本题满分14分，第1小题满分6分，第2小题满分8分）

某群体的人均通勤时间，是指单日内该群体中成员从居住地到工作地的平均用时。某地上班

族 S 中的成员仅以自驾或公交方式通勤。分析显示：当 S 中 $x\%$ （0 < x < 100）的成员自驾

时，自驾群体的人均通勤时间为

$$
f (x) = \left\{ \begin{array}{l l} 3 0, & 0 <   x \leq 3 0, \\ 2 x + \frac {1 8 0 0}{x} - 9 0, & 3 0 <   x <   1 0 0 \end{array} \right. (\text {单位：分钟})
$$

而公交群体的人均通勤时间不受 $X$ 影响，恒为40分钟。试根据上述分析结果回答下列问题：

(1) 当 $x$ 在什么范围内时，公交群体的人均通勤时间少于自驾群体的人均通勤时间？

(2) 求该地上班族 $S$ 的人均通勤时间 $g(x)$ 的表达式；讨论 $g(x)$ 的单调性，并说明其实际意义。
