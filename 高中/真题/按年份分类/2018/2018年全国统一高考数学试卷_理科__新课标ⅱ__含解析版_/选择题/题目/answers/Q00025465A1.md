> [!faq]- 2018年全国统一高考数学试卷（理科）（新课标ⅱ）（含解析版）解析
>
> > [!success]- **【答案】** A

> > [!note]- **【分析】**
> > 分别令 x = -1, 0, 1，进行求解即可.
>
> > [!note]- **【解析】**
> > 解：当 $x = -1$ 时， $y^{2} \leq 2$ ，得 $y = -1, 0, 1$
> >
> > 当 x=0 时， $y^{2}\leq3$ ，得 y=-1, 0, 1，
> >
> > 当 x=1 时， $y^{2}\leq2$ ，得 y=-1,0,1，
> >
> > 即集合 A 中元素有 9 个，
> >
> > 故选：A.
> >
