> [!faq]- 2018年全国统一高考数学试卷（文科）（新课标ⅲ）（含解析版）解析
>
> > [!success]- **【答案】** -2
>
> > [!note]- **【分析】**
> > 利用函数的奇偶性的性质以及函数值，转化求解即可.
>
> > [!note]- **【解析】**
> > 解：函数 $g(x) = \ln (\sqrt{1 + x^2} - x)$
> >
> > 满足 $g(-x) = \ln (\sqrt{1 + x^2} + x) = \ln \frac{1}{\sqrt{1 + x^2} - x} = -\ln (\sqrt{1 + x^2} - x) = -g(x)$ ，
> >
> > 所以 $g(x)$ 是奇函数.
> >
> > 函数 $f(x) = \ln (\sqrt{1 + x^2} - x) + 1, f(a) = 4,$
> >
> > 可得 $f(a) = 4 = \ln (\sqrt{1 + a^2} - a) + 1$ ，可得 $\ln (\sqrt{1 + a^2} - a) = 3$ ，
> >
> > 则 $f(-a) = -\ln \left(\sqrt{1 + a^2} - a\right) + 1 = -3 + 1 = -2$ .
> >
> > 故答案为：-2.
