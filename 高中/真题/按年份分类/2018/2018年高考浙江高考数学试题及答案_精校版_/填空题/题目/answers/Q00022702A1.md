> [!faq]- 2018年高考浙江高考数学试题及答案(精校版)解析
>
> > [!success]- **【答案】** $\frac{\sqrt{21}}{7}$ ，3
>
> > [!note]- **【分析】**
> > 本题解析推导如下：
>
> > [!note]- **【解析】**
> > 解：∵在△ABC中，角A，B，C所对的边分别为a，b，c.
> >
> > $a = \sqrt{7}, b = 2, A = 60^{\circ},$
> >
> > ∴由正弦定理得： $\frac{a}{\sin A}=\frac{b}{\sin B}$ ，即 $\frac{\sqrt{7}}{\sin60^{\circ}}=\frac{2}{\sin B}$ ，
> >
> > 解得 $\sin B = \frac{2 \times \frac{\sqrt{3}}{2}}{\sqrt{7}} = \frac{\sqrt{21}}{7}$ .
> >
> > 由余弦定理得：
> >
> > $$
> > \cos 6 0 ^ {\circ} = \frac {4 + c ^ {2} - 7}{2 \times 2 c},
> > $$
> >
> > 解得 c=3 或 c=-1 （舍），
> >
> > $\therefore \sin B = \frac{\sqrt{21}}{7}, c = 3.$
> >
> > 故答案为： $\frac{\sqrt{21}}{7}$ ，3.
