> > [!note]- **【解析】**
> > 解：（1）∵函数 $f(x)=ae^{x}-\ln x-1$ .
> >
> > $\therefore x > 0, f'(x) = ae^x - \frac{1}{x},$
> >
> > ∵x=2 是 f(x) 的极值点，
> >
> > $\therefore f^{\prime}(2)=ae^{2}-\frac{1}{2}=0$ ，解得 $a=\frac{1}{2e^{2}}$
> >
> > $\therefore f(x) = \frac{1}{2e^2} e^x - \ln x - 1, \therefore f'(x) = \frac{1}{2e^2} e^x - \frac{1}{x},$
> >
> > 当 0 < x < 2 时， $f'(x) < 0$ ，当 x > 2 时， $f'(x) > 0$ ，
> >
> > ∴f（x）在（0，2）单调递减，在（2，+∞）单调递增.
> > (2) 证明：当 $a \geq \frac{1}{e}$ 时， $f(x) \geqslant \frac{e^x}{e} - \ln x - 1,$
> >
> > 设 $g(x) = \frac{e^x}{e} - \ln x - 1$ ，则 $g'(x) = \frac{e^x}{e} - \frac{1}{x}$ ，
> >
> > 当 0 < x < 1 时， $g'(x) < 0$ ，
> >
> > 当 x>1 时， $g'(x)>0$ ，
> >
> > ∴x=1 是 g (x) 的最小值点，
> >
> > 故当 x>0 时， $g(x) \geqslant g(1)=0$ ，
> >
> > ∴当 $a \geq \frac{1}{e}$ 时， $f(x) \geqslant 0$ .
