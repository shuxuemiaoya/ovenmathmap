> [!faq]- 2018年全国统一高考数学试卷（理科）（新课标ⅲ）（含解析版）解析
>
> > [!success]- **【答案】** C
>
> > [!note]- **【分析】**
> > 由二项式定理得 $(\mathrm{x}^2 +\frac{2}{\mathrm{x}})^5$ 的展开式的通项为： $T_{r + 1} = C_5^r (x^2)^{5 - r}\left(\frac{2}{x}\right)^r = 2^r C_5^rx^{10 - 3r}$ ，由 $10 - 3r = 4$ ，解得 $r = 2$ ，由此能求出 $(x^{2} + \frac{2}{x})^{5}$ 的展开式中 $x^4$ 的系数.
>
> > [!note]- **【解析】**
> > 分析】由二项式定理得 $(\mathrm{x}^2 +\frac{2}{\mathrm{x}})^5$ 的展开式的通项为： $T_{r + 1} = C_5^r (x^2)^{5 - r}\left(\frac{2}{x}\right)^r = 2^r C_5^rx^{10 - 3r}$ ，由 $10 - 3r = 4$ ，解得 $r = 2$ ，由此能求出 $(x^{2} + \frac{2}{x})^{5}$ 的展开式中 $x^4$ 的系数.
> >
> > 【
> > 解答】解：由二项式定理得 $(\mathrm{x}^2 +\frac{2}{\mathrm{x}})^5$ 的展开式的通项为： $\mathrm{T}_{\mathrm{r} + 1} = \mathrm{C}_{5}^{\mathrm{r}}(\mathrm{x}^{2})^{5 - \mathrm{r}}(\frac{2}{\mathrm{x}})^{\mathrm{r}} = 2^{\mathrm{r}}\mathrm{C}_{5}^{\mathrm{r}}\mathrm{x}^{10 - 3\mathrm{r}},$
> >
> > 由 $10 - 3\mathrm{r} = 4$ ，解得 $\mathbf{r} = 2$
> >
> > ∴ $\left(x^{2}+\frac{2}{x}\right)^{5}$ 的展开式中 $x^{4}$ 的系数为 $2^{2}C_{5}^{2}=40$ .
> >
> > 故选：C.
> >

> >
