> [!faq]- 2018年全国统一高考数学试卷（理科）（新课标ⅰ）（含解析版）解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【分析】**
> > （1）求出函数的定义域和导数，利用函数单调性和导数之间的关系进行
>
> > [!note]- **【解析】**
> > 分析】（1）求出函数的定义域和导数，利用函数单调性和导数之间的关系进行
> >
> > 求解即可.
> >
> > (2) 将不等式进行等价转化, 构造新函数, 研究函数的单调性和最值即可得到结论.
> >
> > 【
> > 解答】解：（1）函数的定义域为 $(0, +\infty)$ ，
> >
> > 函数的导数 $f'(x) = -\frac{1}{x^2} - 1 + \frac{a}{x} = -\frac{x^2 - ax + 1}{x^2}$ ，
> >
> > 设 g (x) = x $^{2}$ - ax+1,
> >
> > 当 $a \leq 0$ 时， $g(x) > 0$ 恒成立，即 $f'(x) < 0$ 恒成立，此时函数 $f(x)$ 在 $(0, +\infty)$ 上是减
> >
> > 函数，
> >
> > 当 a>0 时，判别式 $\triangle=a^{2}-4$ ，
> >
> > ① 当 $0 < a \leq 2$ 时， $\triangle \leq 0$ ，即 $g(x) > 0$ ，即 $f'(x) < 0$ 恒成立，此时函数 $f(x)$ 在 $(0, +\infty)$
> >
> > 上是减函数，
> >
> > ② 当 a > 2 时，x， $f'(x)$ ， $f(x)$ 的变化如下表：
> >
> > <table><tr><td>x</td><td> $(0, \frac{a-\sqrt{a^2-4}}{2})$ </td><td> $\frac{a-\sqrt{a^2-4}}{2}$ </td><td> $(\frac{a-\sqrt{a^2-4}}{2}, \frac{a+\sqrt{a^2-4}}{2})$ </td><td> $\frac{a+\sqrt{a^2-4}}{2}$ </td><td> $(\frac{a+\sqrt{a^2-4}}{2}, +\infty)$ </td></tr><tr><td>f'(x)f(x)</td><td>-递减</td><td>0</td><td>+递增</td><td>0</td><td>-递减</td></tr></table>
> >
> > 综上当 $a \leq 2$ 时， $f(x)$ 在 $(0, +\infty)$ 上是减函数，
> >
> > 当 $a > 2$ 时，在 $(0, \frac{a - \sqrt{a^2 - 4}}{2})$ ，和 $(\frac{a + \sqrt{a^2 - 4}}{2}, +\infty)$ 上是减函数，
> >
> > 则 $\left(\frac{a - \sqrt{a^2 - 4}}{2},\frac{a + \sqrt{a^2 - 4}}{2}\right)$ 上是增函数.
> >
> > (2) 由 (1) 知 $a > 2, 0 < x_1 < 1 < x_2, x_1x_2 = 1$ ,
> >
> > 则 $f(x_1) - f(x_2) = (x_2 - x_1) \left(1 + \frac{1}{x_1 x_2}\right) + a(\ln x_1 - \ln x_2) = 2(x_2 - x_1) + a(\ln x_1 - \ln x_2)$ ，
> >
> > 则 $\frac{f(x_1) - f(x_2)}{x_1 - x_2} = -2 + \frac{a(\ln x_1 - \ln x_2)}{x_1 - x_2},$
> >
> > 则问题转为证明 $\frac{\ln x_1 - \ln x_2}{x_1 - x_2} < 1$ 即可，
> >
> > 即证明 $\ln x_{1}-\ln x_{2}>\mathrm{x}_{1}-\mathrm{x}_{2}$ ,
> >
> > 则 $\ln x_{1} - \ln \frac{1}{x_{1}} >x_{1} - \frac{1}{x_{1}}$
> >
> > 即 $\ln x_{1} + \ln x_{1} > x_{1} - \frac{1}{x_{1}}$
> >
> > 即证 $2\ln x_{1} > x_{1} - \frac{1}{x_{1}}$ 在（0，1）上恒成立，
> >
> > 设 h (x) = 2lnx - x + $\frac{1}{x}$ , (0 < x < 1), 其中 h (1) = 0,
> >
> > 求导得 $\mathrm{h}'(\mathrm{x}) = \frac{2}{\mathrm{x}} - 1 - \frac{1}{\mathrm{x}^2} = -\frac{\mathrm{x}^2 - 2\mathrm{x} + 1}{\mathrm{x}^2} = -\frac{(\mathrm{x} - 1)^2}{\mathrm{x}^2} < 0,$
> >
> > 则 h (x) 在 $(0, 1)$ 上单调递减，
> >
> > ∴h (x) >h (1)，即 $2\ln x - x + \frac{1}{x} > 0$ ,
> >
> > 故 $2\ln x > x - \frac{1}{x}$
> >
> > 则 $\frac{f(x_1) - f(x_2)}{x_1 - x_2} < a - 2$ 成立.
> >
> > (2) 另解：注意到 $f\left(\frac{1}{x}\right)=x-\frac{1}{x}-a \ln x=-f(x)$ ，
> >
> > 即 $f(x) + f\left(\frac{1}{x}\right) = 0,$
> >
> > 由韦达定理得 $\mathrm{x_1x_2 = 1}$ ， $\mathrm{x_1 + x_2 = a > 2}$ ，得 $0 <   \mathrm{x}_1 <   1 <   \mathrm{x}_2$ ， $\mathrm{x_1 = \frac{1}{x_2}}$
> >
> > 可得 $f(x_2) + f(\frac{1}{x_2}) = 0$ ，即 $f(x_1) + f(x_2) = 0$ ，
> >
> > 要证 $\frac{f(x_1) - f(x_2)}{x_1 - x_2} < a - 2$ ，只要证 $\frac{-f(x_2) - f(x_2)}{x_1 - x_2} < a - 2,$
> >
> > 即证 $2\mathrm{a}\ln \mathrm{x}_2 - \mathrm{ax}_2 + \frac{\mathrm{a}}{\mathrm{x}_2} < 0, \quad (\mathrm{x}_2 > 1)$ ，
> >
> > 构造函数 h (x) = 2a1nx - ax + a/x, (x > 1), h' (x) = $\frac{-a(x-1)^{2}}{x^{2}} \leq 0$ ,
> >
> > ∴h (x) 在 $(1, +\infty)$ 上单调递减，
> >
> > ∴h (x) < h (1) = 0,
> >
> > $\therefore 2 \mathrm{a} \ln x - \mathrm{a} x + \frac{\mathrm{a}}{\mathrm{x}} < 0$ 成立，即 $2 \mathrm{a} \ln x_{2} - \mathrm{a} x_{2} + \frac{\mathrm{a}}{\mathrm{x}_{2}} < 0, \quad (\mathrm{x}_{2} > 1)$ 成立.
> >
> > 即 $\frac{f(x_1) - f(x_2)}{x_1 - x_2} < a - 2$ 成立.
> >

> >
> > 导数，利用导数的应用是解决本题的关键．综合性较强，难度较大．
