> [!faq]- 精品解析：2023年新高考天津数学高考真题（解析版）解析
>
> > [!success]- **【答案】** （1） $\frac{\sqrt{13}}{13}$ (2) 5 (3) $-\frac{7\sqrt{3}}{26}$ 【
>
> > [!note]- **【分析】**
> > （1）根据正弦定理即可解出；
>
> > [!note]- **【解析】**
> > 由正弦定理可得， $\frac{a}{\sin A} = \frac{b}{\sin B}$ ，即 $\frac{\sqrt{39}}{\sin 120^{\circ}} = \frac{2}{\sin B}$ ，解得： $\sin B = \frac{\sqrt{13}}{13}$
> >
> > 【
> >
> > 小问 2
> >
> > 由余弦定理可得， $a^2 = b^2 + c^2 - 2bc\cos A$ ，即 $39 = 4 + c^2 - 2 \times 2 \times c \times \left(-\frac{1}{2}\right)$
> >
> > 解得： $c = 5$ 或 $c = -7$ （舍去）.
> >
> > 【
> >
> > 小问 3
> >
> > 由正弦定理可得， $\frac{a}{\sin A}=\frac{c}{\sin C}$ ，即 $\frac{\sqrt{39}}{\sin120^{\circ}}=\frac{5}{\sin C}$ ，解得： $\sin C=\frac{5\sqrt{13}}{26}$ ，而 $A=120^{\circ}$ ，
> >
> > 所以 $B, C$ 都为锐角，因此 $\cos C = \sqrt{1 - \frac{25}{52}} = \frac{3\sqrt{39}}{26}$ ， $\cos B = \sqrt{1 - \frac{1}{13}} = \frac{2\sqrt{39}}{13}$ ，
> >
> > 故 $\sin (B - C) = \sin B\cos C - \cos B\sin C = \frac{\sqrt{13}}{13}\times \frac{3\sqrt{39}}{26} -\frac{2\sqrt{39}}{13}\times \frac{5\sqrt{13}}{26} = -\frac{7\sqrt{3}}{26}.$
