> [!faq]- 精品解析：2023年高考全国乙卷数学(文)真题（解析版）解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > 当 $a = -1$ 时， $f(x) = \left(\frac{1}{x} - 1\right)\ln (x + 1)(x > -1)$ ，
> >
> > 则 $f^{\prime}(x) = -\frac{1}{x^{2}}\times \ln (x + 1) + \left(\frac{1}{x} -1\right)\times \frac{1}{x + 1},$
> >
> > 据此可得 $f(1)=0, f'(1)=-\ln2$
> >
> > 所以函数在 $\left(1, f(1)\right)$ 处的切线方程为 $y - 0 = -\ln 2(x - 1)$ ，即 $(\ln 2)x + y - \ln 2 = 0$
> >
