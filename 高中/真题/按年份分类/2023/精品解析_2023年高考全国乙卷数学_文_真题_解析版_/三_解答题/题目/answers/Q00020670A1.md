> [!faq]- 精品解析：2023年高考全国乙卷数学(文)真题（解析版）解析
>
> > [!success]- **【答案】** (1) $a_{n} = 15 - 2n$ (2) $T_{n} = \left\{ \begin{array}{ll}14n - n^{2},n\leq 7\\ n^{2} - 14n + 98,n\geq 8 \end{array} \right.$
>
> > [!note]- **【分析】**
> > （1）根据题意列式求解 $a_1, d$ ，进而可得结果；
> >
> > (2) 先求 $S_{n}$ , 讨论 $a_{n}$ 的符号去绝对值, 结合 $S_{n}$ 运算求解.
>
> > [!note]- **【解析】**
> > 【小问 1 详解】
> >
> > 设等差数列的公差为 $d$ ，
> >
> > 由题意可得 $\left\{ \begin{array}{l}a_{2} = a_{1} + d = 11\\ S_{10} = 10a_{1} + \frac{10\times 9}{2} d = 40 \end{array} \right.$ 即 $\left\{ \begin{array}{l}a_1 + d = 11\\ 2a_1 + 9d = 8 \end{array} \right.$ ，解得 $\left\{ \begin{array}{l}a_1 = 13,\\ d = -2 \end{array} \right.$
> >
> > 所以 $a_{n}=13-2(n-1)=15-2n$
> >
> > 【小问 2 详解】
> >
> > 因为 $S_{n} = \frac{n(13 + 15 - 2n)}{2} = 14n - n^{2}$
> >
> > 令 $a_{n}=15-2n>0$ ，解得 $n<\frac{15}{2}$ ，且 $n\in N^{*}$ ，
> >
> > 当 $n \leq 7$ 时，则 $a_{n} > 0$ ，可得 $T_{n} = \left|a_{1}\right| + \left|a_{2}\right| + \cdots + \left|a_{n}\right| = a_{1} + a_{2} + \cdots + a_{n} = S_{n} = 14n - n^{2}$ ;
> >
> > 当 $n \geq 8$ 时，则 $a_{n} < 0$ ，可得 $T_{n} = |a_{1}| + |a_{2}| + \cdots + |a_{n}| = (a_{1} + a_{2} + \cdots + a_{7}) - (a_{8} + \cdots + a_{n})$
> >
> > $= S_{7} - (S_{n} - S_{7}) = 2S_{7} - S_{n} = 2(14\times 7 - 7^{2}) - (14n - n^{2}) = n^{2} - 14n + 98;$
> >
> > 综上所述： $T_{n}=\begin{cases}14n-n^{2},n\leq7\\n^{2}-14n+98,n\geq8\end{cases}$
