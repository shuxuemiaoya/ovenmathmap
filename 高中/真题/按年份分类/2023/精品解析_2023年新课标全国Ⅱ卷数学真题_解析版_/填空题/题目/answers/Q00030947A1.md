> [!faq]- 精品解析：2023年新课标全国Ⅱ卷数学真题（解析版）解析
>
> > [!success]- **【答案】** $\sqrt{3}$
>
> > [!note]- **【分析】**
> > 法一：根据题意结合向量数量积的运算律运算求解；法二：换元令 $c = a - b$ ，结合数量积的运算律运算求解.
>
> > [!note]- **【解析】**
> > 法一：因为 $\left|a+b\right|=\left|2a-b\right|$ ，即 $\left(\vec{a}+\vec{b}\right)^{2}=\left(2a-b\right)^{2}$
> >
> > 则 $a^2 + 2a \cdot b + b = 4a - 4a \cdot b + b$ ，整理得 $a^2 - 2a \cdot b = 0$ ，
> >
> > 又因为 $\left|a-b\right|=\sqrt{3}$ ，即 $\left(\vec{a}-b\right)^{2}=3$ ，
> >
> > 则 $\Gamma_{2} - 2a\cdot b + b = b^{2} = 3$ ，所以 $\left|b\right| = \sqrt{3}$
> >
> > 法二：设 $c = a - b$ ，则 $\left|c\right| = \sqrt{3},a + b = c + 2b,2a - b = 2c + b,$
> >
> > 由题意可得： $\left( \begin{array}{cc}\mathsf{r}\\ c + 2b \end{array} \right)^2 = \left( \begin{array}{cc}\mathsf{r}\\ 2c + b \end{array} \right)^2$ ，则 $\mathsf{r}_2 + 4\mathsf{c}\cdot \mathsf{b} + 4\mathsf{b} = 4\mathsf{c} + 4\mathsf{c}\cdot \mathsf{b} + \mathsf{b},$
> >
> > 整理得： $r_{2}=r_{2}$ ，即 $\left|b\right|=\left|c\right|=\sqrt{3}$ .
> >
> > 故答案为： $\sqrt{3}$ .
