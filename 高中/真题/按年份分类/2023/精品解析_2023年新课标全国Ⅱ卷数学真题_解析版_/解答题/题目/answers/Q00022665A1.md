> [!faq]- 精品解析：2023年新课标全国Ⅱ卷数学真题（解析版）解析
>
> > [!success]- **【答案】** (1) c=97.5， $q(c)=3.5\%$ ; (2) $f(c) = \begin{cases} -0.008c + 0.82,95\leq c\leq 100\\ 0.01c - 0.98,100 < c\leq 105 \end{cases}$ ，最小值为 $0.02$ 【
>
> > [!note]- **【分析】**
> > （1）根据题意由第一个图可先求出 $c$ ，再根据第二个图求出 $c \geq 97.5$ 的矩形面积即可解出；
>
> > [!note]- **【解析】**
> > 依题可知，左边图形第一个小矩形的面积为 $5 \times 0.002 > 0.5\%$ ，所以 $95 < c < 100$
> >
> > 所以 $(c - 95) \times 0.002 = 0.5\%$ ，解得： $c = 97.5$ ，
> >
> > $$
> > q (c) = 0. 0 1 \times (97. 5 - 95) + 5 \times 0. 0 0 2 = 0. 0 3 5 = 3. 5 \%.
> > $$
> >
> > 【
> >
> > 小问 2
> >
> > $$
> > \text { 当 } c \in [ 9 5, 1 0 0 ] \text { 时 },
> > $$
> >
> > $$
> > f (c) = p (c) + q (c) = (c - 9 5) \times 0. 0 0 2 + (1 0 0 - c) \times 0. 0 1 + 5 \times 0. 0 0 2 = - 0. 0 0 8 c + 0. 8 2 \geq 0. 0 2;
> > $$
> >
> > 当 $c\in (100,105]$ 时，
> >
> > $$
> > f (c) = p (c) + q (c) = 5 \times 0. 0 0 2 + (c - 1 0 0) \times 0. 0 1 2 + (1 0 5 - c) \times 0. 0 0 2 = 0. 0 1 c - 0. 9 8 > 0. 0 2,
> > $$
> >
> > 故 $f(c) = \left\{ \begin{array}{ll} - 0.008c + 0.82,95\leq c\leq 100\\ 0.01c - 0.98,100 <   c\leq 105 \end{array} \right.$
> >
> > 所以 $f(c)$ 在区间[95,105]的最小值为0.02.
