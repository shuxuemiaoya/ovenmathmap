> [!faq]- 精品解析：2023年北京高考数学真题（解析版）解析
>
> > [!success]- **【答案】** 48；384
>
> > [!note]- **【分析】**
> > 方法一：根据题意结合等差、等比数列的通项公式列式求解 $d, q$ ，进而可求得结果；方法二：根
>
> > [!note]- **【解析】**
> > 方法一：设前3项的公差为d，后7项公比为q>0，
> >
> > 则 $q^4 = \frac{a_9}{a_5} = \frac{192}{12} = 16$ ，且 $q > 0$ ，可得 $q = 2$
> >
> > 则 $a_{3} = 1 + 2d = \frac{a_{5}}{q^{2}}$ ，即 $1 + 2d = 3$ ，可得 $d = 1$
> >
> > 空1：可得 $a_{3} = 3, a_{7} = a_{3}q^{4} = 48$
> >
> > 空2: $a_{1} + a_{2} + L + a_{9} = 1 + 2 + 3 + 3 \times 2 + \cdots + 3 \times 2^{6} = 3 + \frac{3(1 - 2^{7})}{1 - 2} = 384$
> >
> > 方法二：空1：因为 $\left\{a_{n}\right\} ,3\leq n\leq 7$ 为等比数列，则 $a_7^2 = a_5a_9 = 12\times 192 = 48^2$
> >
> > 且 $a_{n} > 0$ ，所以 $a_{7} = 48$
> >
> > 又因为 $a_5^2 = a_3a_7$ ，则 $a_3 = \frac{a_5^2}{a_7} = 3$
> >
> > 空2：设后7项公比为 $q > 0$ ，则 $q^{2} = \frac{a_{5}}{a_{3}} = 4$ ，解得 $q = 2$
> >
> > 可得 $a_{1} + a_{2} + a_{3} = \frac{3(a_{1} + a_{3})}{2} = 6, a_{3} + a_{4} + a_{5} + a_{6} + a_{7} + a_{8} + a_{9} = \frac{a_{3} - a_{9}q}{1 - q} = \frac{3 - 192 \times 2}{1 - 2} = 381$
> >
> > 所以 $a_{1} + a_{2} + \mathsf{L} + a_{9} = 6 + 381 - a_{3} = 384$
> >
> > 故答案为：48；384.
