> [!faq]- 精品解析：2023年北京高考数学真题（解析版）解析
>
> > [!success]- **【答案】** $\frac{x^2}{2} -\frac{y^2}{2} = 1$ 【
>
> > [!note]- **【分析】**
> > 根据给定条件，求出双曲线 C 的实半轴、虚半轴长，再写出 C 的方程作答.
>
> > [!note]- **【解析】**
> > 令双曲线 C 的实半轴、虚半轴长分别为 a, b，显然双曲线 C 的中心为原点，焦点在 x 轴上，其半
> >
> > 焦距 $c = 2$
> >
> > 由双曲线 $C$ 的离心率为 $\sqrt{2}$ ，得 $\frac{c}{a} = \sqrt{2}$ ，解得 $a = \sqrt{2}$ ，则 $b = \sqrt{c^2 - a^2} = \sqrt{2}$ ，
> >
> > 所以双曲线 $C$ 的方程为 $\frac{x^2}{2} -\frac{y^2}{2} = 1.$
> >
> > 故
