>
> > [!note]- **【分析】**
> > （1）a=0 时，求出函数 $f(x)$ 的解析式，根据函数的定义域和奇偶性进行求解判断即可.
> > （2）根据函数过点（1，3），求出 $c$ 的值，然后根据 $f(x)$ 与 $x$ 轴负半轴有两个不同交点，转化为一元二次方程根的分布进行求解即可.
>
> > [!note]- **【解析】**
> > 解：
> > （1）若 $a = 0$ ，则 $f(x) = \frac{x^2 + x + c}{x} = x + \frac{c}{x} + 1,$
> >
> > 要使函数有意义，则 $x=0$ ，即 $f(x)$ 的定义域为 $\{x|x=0\}$ ，
> >
> > $\because y = x + \frac{c}{x}$ 是奇函数， $y = 1$ 是偶函数，
> >
> > ∴函数 $f(x)=x+\frac{c}{x}+1$ 为非奇非偶函数，不可能是奇函数，故不存在实数 c，使得 $f(x)$ 是奇函数.
> > (2) 若函数过点（1，3），则 $f(1) = \frac{1 + 3a + 1 + c}{1 + a} = \frac{3a + 2 + c}{1 + a} = 3$ ，得 $3a + 2 + c = 3 + 3a$ ，得 $c = 3 - 2 = 1$ ，
> >
> > 此时 $f(x) = \frac{x^2 + (3a + 1)x + 1}{x + a}$ ，若数 $f(x)$ 与 $x$ 轴负半轴有两个不同交点，
> >
> > 即 $f(x) = \frac{x^2 + (3a + 1)x + 1}{x + a} = 0$ ，得 $x^{2+}(3a + 1)x + 1 = 0$ ，当 $x < 0$ 时，有两个不同的交点，
> >
> > 设 $g(x) = x^{2} + (3a + 1)x + 1$
> >
> > 则 $\left\{ \begin{array}{l} \triangle = (3a + 1)^2 - 4 > 0 \\ x_1x_2 = 1 > 0 \\ x_1 + x_2 = -(3a + 1) < 0 \\ \frac{3a + 1}{2} < 0 \end{array} \right.$ 得 $\left\{ \begin{array}{l} 3a + 1 > 2 \text{或} 3a + 1 < -2 \\ 3a + 1 > 0 \end{array} \right.$ ，得 $\left\{ \begin{array}{l} a > \frac{1}{3} \text{或} a < -1 \\ a > -\frac{1}{3} \end{array} \right.$ ，即 $a$

> > $$
> >
> > 若 $x + a = 0$ 即 $x = -a$ 是方程 $x^{2+}(3a + 1)x + 1 = 0$ 的根，
> >
> > 则 $a^2 - (3a + 1)a + 1 = 0$ ，即 $2a^2 + a - 1 = 0$ ，得 $a = \frac{1}{2}$ 或 $a = -1$

> > 则实数 $a$ 的取值范围是 $a > \frac{1}{3}$ 且 $a = \frac{1}{2}$ 且 $a = -1$
> >
