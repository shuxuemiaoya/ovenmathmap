> [!faq]- 2013年上海高考数学真题（文科）试卷（word解析版）解析
>
> > [!success]- **【答案】** （1）不是奇函数，也不是偶函数。 (2) 20,21 【
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > （1） $\omega = 1$ 时， $f(x) = 2\sin x, F(x) = f(x) + f(x + \frac{\pi}{2}) = 2\sin x + 2\sin (x + \frac{\pi}{2}) = 2\sin x + 2\cos x = 2\sqrt{2}\sin (x + \frac{\pi}{4}), \because$ 周期 $T = \frac{2\pi}{\omega} = 2\pi, y = 2\sqrt{2}\sin x$ 是奇函数： $\therefore$ 图像左移 $\frac{\pi}{4}$ 后得 $f(x) = 2\sqrt{2}\sin (x + \frac{\pi}{4})$ ，即不是奇函数，也不是偶函数。
> >
> > (2) $\omega = 2$ ，将函数 $y = f(x)$ 的图像向左平移 $\frac{\pi}{6}$ 个单位，再向上平移 1 个单位，得到函数 $y = g(x)$ : $f(x) = 2\sin 2x, g(x) = f(x - \frac{\pi}{6}) + 1 = 2\sin 2(x - \frac{\pi}{6}) + 1,$ 最小正周期 $T = \pi$ 。令 $f(x) = 0 \Rightarrow \sin 2(x - \frac{\pi}{6}) = -\frac{1}{2}$ 在一个周期内最多有 3 个零点，最少 2 个零点。所以 $y = g(x)$ 在区间 $[a, a + 10\pi]$ 、其长度为 10 个周期上，零点个数可以取 20,21 个
