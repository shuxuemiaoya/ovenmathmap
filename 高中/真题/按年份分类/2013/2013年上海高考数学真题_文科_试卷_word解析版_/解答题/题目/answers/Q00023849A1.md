> [!faq]- 2013年上海高考数学真题（文科）试卷（word解析版）解析
>
> > [!success]- **【答案】** (1) 见下 (2) 当生产速度为 6 千克/小时，这时获得最大利润为 457500 元。 【
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > （1）证明：由题知，生产 a 千克该产品所需要的时间 $t = \frac{a}{x}$ 小时，
> >
> > 所获得的利润 $y=\frac{a}{x}\cdot100(5x+1-\frac{3}{x})=100a(5+\frac{1}{x}-\frac{3}{x^{2}})$ (元)，其中 $1\leq x\leq10$ .
> >
> > 所以，生产a千克该产品所获得的利润为 $100\mathrm{a}\left(5 + \frac{1}{x} -\frac{3}{x^2}\right)$ 元；（证毕）
> >
> > (2) 由（1）知，生产900千克该产品即 $a = 900$ 千克时，获得的利润
> >
> > $$
> > y = 1 0 0 \cdot 9 0 0 (5 + \frac {1}{x} - \frac {3}{x ^ {2}}) = 9 0 0 0 0 [ 5 + \frac {1}{x} (1 - 3 \cdot \frac {1}{x}) ]
> > $$
> >
> > 由二次函数的知识可知，当 $\frac{1}{x} = \frac{1}{6}$ ，即 $x = 6$ 时， $y \leq 90000[5 + \frac{1}{6}(1 - 3 \cdot \frac{1}{6})]$
> >
> > $$
> > = 4 5 0 0 0 0 + 7 5 0 0 = 4 5 7 5 0 0 (\text {元})
> > $$
> >
> > 所以，当生产速度为 6 千克/小时，这时获得最大利润为 457500 元。
