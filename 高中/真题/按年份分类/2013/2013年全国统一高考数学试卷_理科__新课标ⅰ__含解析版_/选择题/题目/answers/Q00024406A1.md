> [!faq]- 2013年全国统一高考数学试卷（理科）（新课标ⅰ）（含解析版）解析
>
> > [!success]- **【答案】** B
>
> > [!note]- **【分析】**
> > 根据一元二次不等式的解法，求出集合 A，再根据的定义求出 $A \cap B$ 和
> > AUB.
>
> > [!note]- **【解析】**
> > 解：∵集合 $A=\{x \mid x^{2}-2x>0\}=\{x \mid x>2$ 或 x<0，
> >
> > $\therefore A \cap B = \{x \mid 2 < x < \sqrt{5} \text{或} - \sqrt{5} < x < 0\}, A \cup B = R,$
> >
> > 故选：B.
> >
> > 【点评】本题考查一元二次不等式的解法，以及并集的定义，属于基础题.
