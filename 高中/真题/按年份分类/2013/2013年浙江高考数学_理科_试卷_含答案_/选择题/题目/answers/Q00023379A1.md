> [!faq]- 2013年浙江高考数学(理科)试卷(含答案)解析
>
> > [!success]- **【答案】** B
>
> > [!note]- **【分析】**
> > $\varphi = \frac{\pi}{2} \Rightarrow f(x) = A \cos (\omega x + \frac{\pi}{2}) \Rightarrow f(x) = A \sin (\omega x) \quad (A > 0, \omega > 0, x \in \mathbb{R})$ 是奇函数． $f(x)$ 为奇函数 $\Rightarrow f(0) = 0 \Rightarrow \varphi = k\pi + \frac{\pi}{2}, k \in \mathbb{Z}$ . 所以“ $f(x)$ 是奇函数”是“ $\varphi = \frac{\pi}{2}$ ”必要不充分条件.
>
> > [!note]- **【解析】**
> > 解：若 $\varphi = \frac{\pi}{2}$ 则 $f(x) = A\cos (\omega x + \frac{\pi}{2})$ $\Rightarrow f(x) = A\sin (\omega x)\quad (A > 0,\omega >0,x\in R)$ 是奇函数；若 $f(x)$ 是奇函数， $\Rightarrow f(0) = 0,$ $\therefore f(0) = A\cos (\omega \times 0 + \varphi) = A\cos \varphi = 0.$ $\therefore \varphi = k\pi +\frac{\pi}{2},k\in Z$ ，不一定有 $\varphi = \frac{\pi}{2}$ “ $f(x)$ 是奇函数”是“ $\varphi = \frac{\pi}{2}$ ”必要不充分条件.故选B.
> >
> > 点评：本题考查充分条件、必要条件和充要条件的判断，解题时要认真审题，仔细解答，注意三角函数性质的灵活运用.
