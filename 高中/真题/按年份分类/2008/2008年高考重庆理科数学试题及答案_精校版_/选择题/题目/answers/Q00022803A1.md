> [!faq]- 2008年高考重庆理科数学试题及答案(精校版)解析
>
> > [!success]- **【答案】** C
>
> > [!note]- **【分析】**
> > 对任意 $x_{1}, x_{2} \in R$ 有 $f(x_{1} + x_{2}) = f(x_{1}) + f(x_{2}) + 1$ ，考察四个选项，本题要研究函数的奇偶性，故对所给的 $x_{1}, x_{2} \in R$ 有 $f(x_{1} + x_{2}) = f(x_{1}) + f(x_{2}) + 1$ 进行赋值研究即可
>
> > [!note]- **【解析】**
> > 解：∵对任意 $x_{1}, x_{2} \in R$ 有 $f(x_{1} + x_{2}) = f(x_{1}) + f(x_{2}) + 1,$ ∴令 $x_{1} = x_{2} = 0$ ，得 $f(0) = -1$ ∴令 $x_{1} = x, x_{2} = -x$ ，得 $f(0) = f(x) + f(-x) + 1,$ ∴ $f(x) + 1 = -f(-x) - 1 = -[f(-x) + 1]$ ,
> >
> > ∴ $f(x) + 1$ 为奇函数.
> >
> > 故选 C
> >
> > 点评：本题考查函数的性质和应用，解题时要认真审题，仔细
