> [!faq]- 2008年高考重庆理科数学试题及答案(精校版)解析
>
> > [!success]- **【答案】** B
>
> > [!note]- **【分析】**
> > 根据特殊值代入法进行逐一排除.
>
> > [!note]- **【解析】**
> > 解：特殊值法， $\sin x = 0$ ， $\cos x = 1$ 则f（x） $= \frac{0 - 1}{\sqrt{3 - 2*1 - 2*0}} = -1$ 淘汰A，
> >
> > 令 $\frac{\sin x - 1}{\sqrt{3 - 2\cos x - 2\sin x}} = -\sqrt{2}$ 得 $\cos x = \frac{6 - (\sin x + 1)^2}{4}$ 当时 $\sin x = -1$ 时 $\cos x = \frac{3}{2}$ 所以矛盾 $f(x) \neq -\sqrt{2}$ 淘汰C，
> >
> > 同理，令 $\frac{\sin x - 1}{\sqrt{3 - 2\cos x - 2\sin x}} = -\sqrt{3}$ 得 $\cos x = \frac{8 - (\sin^2 x + 4\sin x)}{6}$ ，当 $\sin x = 1$ 时， $\cos x = \frac{1}{2}$ ，不满足条件，淘汰D，故选B.
> >
> > 点评：主要考查对任意角 x 满足 $\sin^{2}x + \cos^{2}x = 1$ .
> >
