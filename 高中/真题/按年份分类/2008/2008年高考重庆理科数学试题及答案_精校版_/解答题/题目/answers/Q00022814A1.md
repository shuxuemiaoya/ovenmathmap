> [!faq]- 2008年高考重庆理科数学试题及答案(精校版)解析
>
> > [!success]- **【答案】** . （Ⅱ）对原式进行化简整理得 $\cot B + \cot C = \frac{\sin A}{\sin B\sin C}$ 由正弦定理和（Ⅰ）的结论求得结果.
>
> > [!note]- **【分析】**
> > （Ⅰ）先根据余弦定理求得 a，b 和 c 的关系式，再利用 c=3b 消去 b，进而可得
>
> > [!note]- **【解析】**
> > 解：
> > （1）由余弦定理得 $a^2 = b^2 + c^2 - 2bccosA = \left(\frac{1}{3}c\right)^2 + c^2 - 2\cdot \frac{1}{3}c\cdot c\cdot \frac{1}{2} = \frac{7}{9}c^2.$
> >
> > $$
> > \therefore \frac {a}{c} = \frac {\sqrt {7}}{3}.
> > $$
> >
> > $$
> > \cot B + \cot C = \frac {\cos B \sin C + \cos C \sin B}{\sin B \sin C} = \frac {\sin (B + C)}{\sin B \sin C} = \frac {\sin A}{\sin B \sin C},
> > $$
> >
> > 由正弦定理和（I）的结论得 $\frac{\sin A}{\sin B\sin C} = \frac{1}{\sin A}\cdot \frac{a^2}{bc} = \frac{2}{\sqrt{3}}\cdot \frac{\frac{7}{9}c^2}{\frac{1}{3}c\cdot c} = \frac{14}{3\sqrt{3}} = \frac{14\sqrt{3}}{9}.$
> >
> > 故 $\cot B + \cot C = \frac{14\sqrt{3}}{9}$
> >
> > 点评：本题主要考查了正弦定理和余弦定理的应用。正弦定理和余弦定理是解三角形问题中常使用的方法，应熟练掌握。
