> [!faq]- 2008年四川高考理科数学(非延考区)试题及答案详解解析
>
> > [!success]- **【答案】** 4
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > 由题意， $\left\{\begin{aligned}&4a_{1}+\frac{4\times3}{2}d\geq10\\ &5a_{1}+\frac{5\times4}{2}d\leq15\end{aligned}\right.$ ，即 $\left\{\begin{aligned}&4a_{1}+6d\geq10\\ &5a_{1}+10d\leq15\end{aligned}\right.$ ， $\left\{\begin{aligned}&2a_{1}+3d\geq5\\ &a_{1}+2d\leq3\end{aligned}\right.$ ， $a_{4}=a_{1}+3d$
> >
> > 这是加了包装的线性规划，有意思．建立平面直角坐标系 $a_{1}od$ ，画出可行域 $\left\{\begin{aligned}&2a_{1}+3d\geq5\\ &a_{1}+2d\leq3\end{aligned}\right.$ （图略），画出目标函数即直线 $a_{4}=a_{1}+3d$ ，由图知，当直线 $a_{4}=a_{1}+3d$ 过可行域内(1,1)点时截距最大，此时目标函数取最大值 $a_{4}=4$ ．本题明为数列，实为线性规划，着力考查了转化化归和数形结合思想．掌握线性规划问题“画一移一求一答”四步曲，理解线性规划解题程序的实质是根本．这是本题的命题意图．
> >
> > 因约束条件只有两个，本题也可走不等式路线。设
> >
> > $a_{1} + 3d = \lambda_{1}(2a_{1} + 3d) + \lambda_{2}(a_{1} + 2d)$ ，由 $\left\{ \begin{array}{l}2\lambda_1 + \lambda_2 = 1\\ 3\lambda_1 + 2\lambda_2 = 3 \end{array} \right.$ 解得 $\left\{ \begin{array}{l}\lambda_1 = -1\\ \lambda_2 = 3 \end{array} \right.,\therefore$
> >
> > $a_{1} + 3d = -(2a_{1} + 3d) + 3(a_{1} + 2d)$ ，由不等式的性质得： $\left\{ \begin{array}{l}2a_{1} + 3d\geq 5\\ a_{1} + 2d\leq 3 \end{array} \right.$
> >
> > $\Rightarrow \left\{ \begin{array}{l} - (2a_{1} + 3d) \leq -5 \\ 3(a_{1} + 2d) \leq 9 \end{array} \right. \Rightarrow -(2a_{1} + 3d) + 3(a_{1} + 2d) \leq 4$ ，即 $a_{4} = a_{1} + 3d \leq 4$ ， $a_{4}$ 的最大
> >
> > 值是4.
> >
> > 从解题效率来看, 不等式路线为佳, 尽管命题者的意图为线性规划路线. 本题解题策略的选择至关重要.
