> [!faq]- 2008年全国统一高考数学试卷（理科）（全国卷ⅰ）（含解析版）解析
>
> > [!success]- **【答案】** D
>
> > [!note]- **【分析】**
> > 首先利用奇函数定义与 $\frac{f(x) - f(-x)}{x} < 0$ 得出 $x$ 与 $f(x)$ 异号，
>
> > [!note]- **【解析】**
> > 解：由奇函数 $f(x)$ 可知 $\frac{f(x) - f(-x)}{x} = \frac{2f(x)}{x} < 0$ ，即 $x$ 与 $f(x)$ 异号，
> >
> > 而 $f(1) = 0$ ，则 $f(-1) = -f(1) = 0$ ，
> >
> > 又 $f(x)$ 在 $(0, +\infty)$ 上为增函数，则奇函数 $f(x)$ 在 $(-\infty, 0)$ 上也为增函数，
> >
> > 当 $0 < x < 1$ 时， $f(x) < f(1) = 0$ ，得 $\frac{f(x)}{x} < 0$ ，满足；
> >
> > 当 $x > 1$ 时， $f(x) > f(1) = 0$ ，得 $\frac{f(x)}{x} > 0$ ，不满足，舍去；
> >
> > 当 $-1 < x < 0$ 时， $f(x) > f(-1) = 0$ ，得 $\frac{f(x)}{x} < 0$ ，满足；
> >
> > 当 $x < -1$ 时， $f(x) < f(-1) = 0$ ，得 $\frac{f(x)}{x} > 0$ ，不满足，舍去；
> >
> > 所以 x 的取值范围是 -1 < x < 0 或 0 < x < 1.
> >
> > 故选：D.
> >
> > 【点评】本题综合考查奇函数定义与它的单调性.
