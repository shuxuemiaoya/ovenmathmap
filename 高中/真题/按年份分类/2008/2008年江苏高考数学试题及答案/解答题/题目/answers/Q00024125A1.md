> [!faq]- 2008年江苏高考数学试题及答案解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【分析】**
> > （1）对二项式定理的展开式两边求导数，移项得到恒等式.
>
> > [!note]- **【解析】**
> > 证明：
> > （1）在等式 $(1 + x)^{n} = C_{n}^{0} + C_{n}^{1}x + C_{n}^{2}x^{2} + + C_{n}^{n}x^{n}$ 两边对 $x$ 求导得 $n(1 + x)^{n - 1} = C_n^1 +2C_n^2 x++(n - 1)C_n^{n - 1}x^n$
> >
> > 移项得 $n[(1+x)^{n-1}-1]=\sum_{k=2}^{n}kC_{n}^{k}x^{k-1}$ (\*)
> >
> > (2) (i) 在 (\*) 式中，令 x = -1，整理得 $\sum_{k=1}^{n} (-1)^{k-1} k C_{n}^{k} = 0$ 所以 $\sum_{k=1}^{n} (-1)^{k} k C_{n}^{k}=0$
> >
> > (ii) 由
> > （1）知 $n(1 + x)^{n-1} = C_n^1 + 2C_n^2x + \ldots + (n-1)C_n^{n-1}x^{n-2} + nC_n^n x^{n-1}$ ， $n \geq 3$ 两边对 $x$ 求导，得 $n(n-1)(1 + x)^{n-2} = 2C_n^2 + 3 \cdot 2C_n^3x + \ldots + n(n-1)C_n^n x^{n-2}$ 在上式中，令 $x = -1$ ，得 $0 = 2C_n^2 + 3 \cdot 2C_n^3(-1) + \ldots + n(n-1)C_n^2(-1)^{n-2}$
> >
> > 即 $\sum_{k=2}^{n} k(k-1) C_n^k(-1)^{k-2}=0$ ,
> >
> > 亦即 $\sum_{k=2}^{n} (-1)^{k} (k^2 - k) C_n^k = 0$
> > (1)
> >
> > 又由 (i) 知 $\sum_{k=1}^{n} (-1)^{k} k C_{n}^{k}=0$
> > (2)
> >
> > 由（1）+
> > （2）得 $\sum_{k = 1}^{n}(-1)^{k}k^2 C_n^k = 0$
> >
> > (iii) 将等式 $(1+x)^{n}=C_{n}^{0}+C_{n}^{1}x+C_{n}^{2}x^{2}+\ldots+C_{n}^{n}x^{n}$ 两边在 $[0,1]$ 上对 x 积分 $\int\limits_{0}^{1}(1+x)^{n}dx=\int\limits_{0}^{1}\left(C_{n}^{0}+C_{n}^{1}x+C_{n}^{2}x^{2}+\cdots+C_{n}^{n}x^{n}\right)dx$
> >
> > 由微积分基本定理，得 $\frac{1}{n + 1} (1 + x)^{n + 1}\mid \begin{array}{l}1 = (\sum_{k = 0}^{n}\frac{1}{k + 1} C_n^k x^{k + 1})\quad | \quad 1\\ 0 \end{array}$
> >
> > 所以 $\sum_{k=0}^{n}\frac{1}{k+1} C_n^k = \frac{2^{n+1} - 1}{n+1}$
> >
> > 点评：本题考查导数的运算法则、考查通过赋值求系数和问题、考查微积分基本定理.
