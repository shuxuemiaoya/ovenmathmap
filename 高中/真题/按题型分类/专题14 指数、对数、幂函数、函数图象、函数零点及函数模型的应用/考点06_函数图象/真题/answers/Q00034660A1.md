> [!faq]- 《专题14 指数、对数、幂函数、函数图象、函数零点及函数模型的应用》真题解析
>
> > [!success]- **【答案】** C
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > 【答案】C
> > 【详解】试题分析：函数在 $P$ 处无意义，由图像看 $P$ 在 $y$ 轴右侧，所以 $-c > 0, c < 0$ ， $f(0) = \frac{b}{c^2} > 0, \therefore b > 0$ ，由 $f(x) = 0, \therefore ax + b = 0$ ，即 $x = -\frac{b}{a}$ ，即函数的零点 $x = -\frac{b}{a} > 0 \therefore a < 0 \therefore a \langle 0, b \rangle 0, c < 0$ ，故选 C.
> > 考点：函数的图像
