> [!faq]- 《专题14 指数、对数、幂函数、函数图象、函数零点及函数模型的应用》真题解析
>
> > [!success]- **【答案】** (1,4) (1,3] ∪ (4,+∞)
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > 分析·根据分段函数，转化为两个不等式组，分别求解，最后求并集·先讨论一次函数零点的取法再对应确定二次函数零点的取法，即得参数 $\lambda$ 的取值范围·
> > 详解：由题意得 $\left\{ \begin{array}{ll}x & 2\\ x - 4 <   0 \end{array} \right.$ 或 $\left\{ \begin{array}{ll}x <   2\\ x^2 -4x + 3 <   0 \end{array} \right.$ ，所以 $2\leq x <   4$ 或 $1 <   x <   2$ ，即 $1 <   x <   4$ ，不等式 $f(x)^{<  0}$ 的解集是(1,4)，
> > 当 $\lambda > 4$ 时， $f(x) = x - 4 > 0$ ，此时 $f(x) = x^{2} - 4x + 3 = 0, x = 1, 3$ ，即在 $(-∞, λ)$ 上有两个零点；当 $\lambda ≤ 4$ 时， $f(x) = x - 4 = 0, x = 4$ ，由 $f(x) = x^{2} - 4x + 3$ 在 $(-∞, λ)$ 上只能有一个零点得 $1 < \lambda ≤ 3 \cdot$ 综上， $\lambda$ 的取值范围为 $(1, 3] ∪ (4, +∞)$ .
> > 点睛：已知函数有零点求参数取值范围常用的方法和思路：
> > (1)直接法：直接根据题设条件构建关于参数的不等式，再通过解不等式确定参数范围；
> > (2)分离参数法：先将参数分离，转化成求函数值域问题加以解决；
> > (3)数形结合法：先对解析式变形，在同一平面直角坐标系中，画出函数的图象，然后数形结合求解.
