> [!faq]- 《zhenti-专题20 数列的通项公式及数列求和大题综合》例题解析
>
> > [!success]- **【答案】** （1） $a_{n} = (-2)^{n - 1}$ 或 $a_{n} = 2^{n - 1}$
>
> > [!note]- **【解析】**
> > (1) 求 $\left\{a_{n}\right\}$ 的通项公式；
> >
> > (2) 记 $S_{n}$ 为 $\{a_{n}\}$ 的前 $n$ 项和. 若 $S_{m} = 63$ , 求 $m$ .
> >
> >
> > (2) m = 6.
> >
> > 【详解】分析：
> > （1）列出方程，解出 $q$ 可得；
> > （2）求出前 $n$ 项和，解方程可得 $m$
> >
> > 详解：
> > （1）设 $\{a_{n}\}$ 的公比为 $q$ ，由题设得 $a_{n} = q^{n - 1}$
> >
> > 由已知得 $q^4 = 4q^2$ ，解得 $q = 0$ （舍去）， $q = -2$ 或 $q = 2$
> >
> > 故 $a_{n} = (-2)^{n - 1}$ 或 $a_{n} = 2^{n - 1}$
> >
> > (2) 若 $a_{n} = (-2)^{n - 1}$ ，则 $S_{n} = \frac{1 - (-2)^{n}}{3}$ 。由 $S_{m} = 63$ 得 $(-2)^{m} = -188$ ，此方程没有正整数解。
> >
> > 若 $a_{n} = 2^{n - 1}$ ，则 $S_{n} = 2^{n} - 1$ 由 $S_{m} = 63$ 得 $2^{m} = 64$ ，解得 $m = 6$
> >
> > 综上， $m = 6$
> >
> > 点睛：本题主要考查等比数列的通项公式和前 $^{n}$ 项和公式，属于基础题.
