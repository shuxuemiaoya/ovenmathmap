> [!faq]- 《专题08 数列小题综合》真题解析
>
> > [!success]- **【答案】** 7
>
> > [!note]- **【分析】**
> > 对 $n$ 为奇偶数分类讨论，分别得出奇数项、偶数项的递推关系，由奇数项递推公式将奇数项用 $a_{1}$ 表示，由偶数项递推公式得出偶数项的和，建立 $a_{1}$ 方程，求解即可得出结论·
>
> > [!note]- **【解析】**
> > $a_{n + 2} + (-1)^{n}a_{n} = 3n - 1$
> > 当 $n$ 为奇数时， $a_{n+2} = a_n + 3n - 1$ ；当 $n$ 为偶数时， $a_{n+2} + a_n = 3n - 1$ .
> > 设数列 $\left\{a_{n}\right\}$ 的前 n 项和为 $S_{n}$
> > $S_{16} = a_1 + a_2 + a_3 + a_4 + \dots +a_{16}$ $= a_{1} + a_{3} + a_{5}\dots +a_{15} + (a_{2} + a_{4}) + \dots (a_{14} + a_{16})$ $= a_{1} + (a_{1} + 2) + (a_{1} + 10) + (a_{1} + 24) + (a_{1} + 44) + (a_{1} + 70)$ $+(a_1 + 102) + (a_1 + 140) + (5 + 17 + 29 + 41)$ $= 8a_{1} + 392 + 92 = 8a_{1} + 484 = 540$
> > 故答案为：7·
> > 【点睛】本题考查数列的递推公式的应用，以及数列的并项求和，考查分类讨论思想和数学计算能力，属于较难题·
