> [!faq]- 《专题08 数列小题综合》真题解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【分析】**
> > 【分析】利用等差数列通项公式得到方程组，解出 $a_1, d$ ，再利用等差数列的求和公式节即可得到答案
>
> > [!note]- **【解析】**
> > 【详解】因为数列 $a_{n}$ 为等差数列，则由题意得 $\left\{ \begin{array}{l}a_1 + 2d + a_1 + 3d = 7\\ 3(a_1 + d) + a_1 + 4d = 5 \end{array} \right.$ ，解得 $\left\{ \begin{array}{l}a_1 = -4\\ d = 3 \end{array} \right.$
> > 则 $S_{10} = 10a_{1} + \frac{10\times 9}{2} d = 10\times (-4) + 45\times 3 = 95$
> > 故答案为：95·
