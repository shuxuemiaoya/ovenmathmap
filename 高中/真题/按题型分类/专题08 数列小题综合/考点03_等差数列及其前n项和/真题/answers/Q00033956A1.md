> [!faq]- 《专题08 数列小题综合》真题解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > 【答案】 $-\frac{1}{n}$
> > 【详解】原式为 $a_{n + 1} = S_nS_{n + 1}\Leftrightarrow S_{n + 1} - S_n = S_nS_{n + 1}$ ，整理为： $\frac{1}{S_n} -\frac{1}{S_{n + 1}} = 1$ ，即 $\frac{1}{S_{n + 1}} -\frac{1}{S_n} = -1$ ，即数列 $\left\{\frac{1}{S_n}\right\}$ 是以-1为首项，-1为公差的等差的数列，所以 $\frac{1}{S_n} = -1 + (n - 1)(-1) = -n$ ，即 $S_{n} = -\frac{1}{n}$
> > 【点睛】这类型题使用的公式是 $a_{n} = \left\{ \begin{array}{ll}S_{1} & n = 1\\ S_{n} - S_{n - 1} & n - 2 \end{array} \right.$ ，一般条件是 $S_{n} = f(a_{n})$ ，若是消 $S_{n}$ ，就需当 $n - 2$ 时构造 $S_{n - 1} = f(a_{n - 1})$ ，两式相减 $S_{n} - S_{n - 1} = a_{n}$ ，再变形求解；若是消 $a_{n}$ ，就需在原式将 $a_{n}$ 变形为： $a_{n} = S_{n} - S_{n - 1}$ ，再利用递推求解通项公式·
