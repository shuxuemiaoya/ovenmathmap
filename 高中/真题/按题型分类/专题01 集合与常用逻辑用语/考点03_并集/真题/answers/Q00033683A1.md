> [!faq]- 《专题01 集合与常用逻辑用语》真题解析
>
> > [!success]- **【答案】** A
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > 试题分析：集合 $B = \{x\mid -1 <   x <   2,x\in Z\} = \{0,1\}$ ，而 $A = \{1,2,3\}$ ，所以 $A\cup B = \{0,1,2,3\}$ ，故选C.【考点】 集合的运算
> > 【名师点睛】集合的交、并、补运算问题，应先把集合化简再计算，常常借助数轴或韦恩图进行处理·10．（2015·全国·高考真题）已知集合 $A = \{x\mid -1 <   x <   2\} ,B = \{x\mid 0 <   x <   3\}$ ，则 $A\cup B =$ （ ）A.(-1,3) B.(-1,0) C. $(0,2)$ D. $(2,3)$
> > 【答案】A
> > 【详解】因为 $A=\left\{x\mid-1<x<2\right\}$ ， $B=\left\{x\mid0<x<3\right\}$ ，所以 $A\cup B=\left\{x\mid-1<x<3\right\}$ .
> >
> > 故选 **A**.
