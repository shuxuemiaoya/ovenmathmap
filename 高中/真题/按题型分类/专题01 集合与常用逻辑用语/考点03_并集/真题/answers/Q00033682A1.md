> [!faq]- 《专题01 集合与常用逻辑用语》真题解析
>
> > [!success]- **【答案】** C
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > $A=\{y|y=2x,\ x\in R\}=\{y|y>0\}$
> > $B = \{x\mid x^2 -1 <   0\} = \{x\mid -1 <   x <   1\} ,\therefore A\cup B = \{x\mid x > 0\} \cup \{x\mid -1 <   x <   1\} = \{x\mid x > - 1\} ,$
> >
