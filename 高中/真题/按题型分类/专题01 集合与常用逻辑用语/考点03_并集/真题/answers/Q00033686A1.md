> [!faq]- 《专题01 集合与常用逻辑用语》真题解析
>
> > [!success]- **【答案】** A
>
> > [!note]- **【分析】**
> > 【分析】由题意逐一考查所给的选项运算结果是否为 $\left\{x \mid x = 2\right\}$ 即可.
>
> > [!note]- **【解析】**
> > 【详解】由题意可得 $M \cup N = \{x \mid x < 2\}$ ，则 $\tilde{\mathfrak{Q}}_{U}(M \cup N) = \{x \mid x - 2\}$ ，选项 A 正确；
> > $\check{\mathbf{Q}}_U M = \left\{x \mid x - 1\right\}$ ，则 $N \cup \check{\mathbf{Q}}_U M = \left\{x \mid x > -1\right\}$ ，选项B错误；
> > $M\cap N = \{x\mid -1 <   x <   1\}$ ，则 $\tilde{\mathfrak{Q}}_U(M\cap N) = \left\{x\mid x\leq -1\text{或} x\quad 1\right\}$ ，选项C错误；
> > $\tilde{\mathfrak{Q}}_U N = \left\{x \mid x \leq -1 \text{ 或 } x, 2\right\}$ ，则 $M \cup \tilde{\mathfrak{Q}}_U N = \left\{x \mid x < 1 \text{ 或 } x, 2\right\}$ ，选项 D 错误；
> >
> > 故选 **A**.
