> > [!success]- **【答案】** C
>
> > [!note]- **【解析】**
> > 因为 $A = \{x \mid x < -2 \text{ 或 } x > 2\}$ ，所以 $\tilde{Q}_{U} A = \left\{x \mid -2 \leq x \leq 2\right\}$ ，
> >
> > 故选 **C**.
>
> > [!tip]- **【名师点睛】**
> > 集合分为有限集合和无限集合，若集合个数比较少时可以用列举法表示；若集合是无限集合就用描述法表示，并注意代表元素是什么．集合的交、并、补运算问题，应先把集合化简再计算，常常借助数轴或 Venn 图进行处理．
