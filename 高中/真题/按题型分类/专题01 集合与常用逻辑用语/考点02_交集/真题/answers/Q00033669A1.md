> [!faq]- 《专题01 集合与常用逻辑用语》真题解析
>
> > [!success]- **【答案】** A
>
> > [!note]- **【分析】**
> > 根据集合的交集运算即可解出.
>
> > [!note]- **【解析】**
> > 因为 $A = \{-2, -1, 0, 1, 2\}$ ， $B = \left\{x: 0 \leq x < \frac{5}{2}\right\}$ ，所以 $A \cap B = \{0, 1, 2\}$
> >
> > 故选 **A**.
