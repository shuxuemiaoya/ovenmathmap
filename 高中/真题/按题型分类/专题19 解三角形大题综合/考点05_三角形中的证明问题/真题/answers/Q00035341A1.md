> [!faq]- 《专题19 解三角形大题综合》真题解析
>
> > [!success]- **【答案】** （Ⅰ）证明详见解析；（Ⅱ） $\cos C=\frac{22}{27}$
>
> > [!note]- **【分析】**
> > （Ⅰ）用正弦定理将边转化为角，进而用两角和的正弦公式转化为含有A，B的式子，根据角的范围可证 $A=2B$ ；（Ⅱ）先用同角三角函数的基本关系及二倍角公式可得 $\cos2B$ ，进而可得 $\cos A$ 和 $\sin A$ ，再用两角和的余弦公式可得 $\cos C$ 。
>
> > [!note]- **【解析】**
> > （1）由正弦定理得 $\sin B + \sin C = 2\sin A\cos B$
> > 故 $2\sin A\cos B = \sin B + \sin (A + B) = \sin B + \sin A\cos B + \cos A\sin B$
> > 于是 $\sin B = \sin (A - B)$
> > 又 $A, B \in (0, \pi)$ ，故 $0 < A - B < \pi$ ，所以 $B = \pi - (A - B)$ 或 $B = A - B$
> > 因此 $A = \pi$ （舍去）或 A = 2B ，
> > 所以， $A = 2B\cdot$
> > (Ⅱ) 由 $\cos B = \frac{2}{3}$ ，得 $\sin B = \frac{\sqrt{5}}{3}$ ， $\cos 2B = 2\cos^{2}B - 1 = -\frac{1}{9}$ ，
> > 故 $\cos A = -\frac{1}{9}$ ， $\sin A = \frac{4\sqrt{5}}{9}$
> > $$
> > \cos C = - \cos (A + B) = - \cos A \cos B + \sin A \sin B = \frac {2 2}{2 7}.
> > $$
