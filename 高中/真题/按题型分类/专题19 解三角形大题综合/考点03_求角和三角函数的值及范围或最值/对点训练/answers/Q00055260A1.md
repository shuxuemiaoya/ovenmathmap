> [!faq]- 《zhenti-专题19 解三角形大题综合》例题解析
>
> > [!success]- **【答案】** （1） $\frac{\pi}{4}$
>
> > [!note]- **【解析】**
> > (1)$ 求 $B$ 的大小；
> >
> > (2)求 $\sqrt{2}\cos A + \cos C$ 的最大值.
> >
> >
> > （2）1
> >
> > 【详解】试题分析：
> > （1）由余弦定理及题设得 $\cos B = \frac{a^2 + c^2 - b^2}{2ac} = \frac{\sqrt{2}ac}{2ac} = \frac{\sqrt{2}}{2} \Rightarrow \angle B = \frac{\pi}{4}$ ；
> > （2）由
> > （1）知 $\angle A + \angle C = \frac{3\pi}{4} \Rightarrow \sqrt{2} \cos A + \cos C = \sqrt{2} \cos A + \cos (\frac{3\pi}{4} - A) = \cos (A - \frac{\pi}{4}) \Rightarrow$ 当 $\angle A = \frac{\pi}{4}$ 时， $\sqrt{2} \cos A + \cos C$ 取得最大值1.
> >
> > 试题解析：

> >
> > 又∵ $0<\angle B<\pi$ ，∴ $\angle B=\frac{\pi}{4}$ ；

> > （1）知 $\angle A+\angle C=\frac{3\pi}{4}$ ，
> >

> > \sqrt {2} \cos A + \cos C = \sqrt {2} \cos A + \cos (\frac {3 \pi}{4} - A) = \sqrt {2} \cos A - \frac {\sqrt {2}}{2} \cos A + \frac {\sqrt {2}}{2} \sin A
> > $$
> >
> > $= \frac{\sqrt{2}}{2}\cos A + \frac{\sqrt{2}}{2}\sin A = \cos (A - \frac{\pi}{4})$ ，因为 $0 < \angle A < \frac{3\pi}{4}$ ，所以当 $\angle A = \frac{\pi}{4}$ 时， $\sqrt{2}\cos A + \cos C$ 取得最大值
> >
