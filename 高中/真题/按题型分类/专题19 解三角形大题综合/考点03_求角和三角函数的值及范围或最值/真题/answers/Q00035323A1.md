> [!faq]- 《专题19 解三角形大题综合》真题解析
>
> > [!success]- **【答案】** 详见解析

> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > 【答案】（1） $\frac{\pi}{4}$ （2）1
> > 【详解】试题分析：（1）由余弦定理及题设得 $\cos B = \frac{a^2 + c^2 - b^2}{2ac} = \frac{\sqrt{2}ac}{2ac} = \frac{\sqrt{2}}{2} \Rightarrow \angle B = \frac{\pi}{4}$ ；（2）由（1）知 $\angle A + \angle C = \frac{3\pi}{4} \Rightarrow \sqrt{2} \cos A + \cos C = \sqrt{2} \cos A + \cos (\frac{3\pi}{4} - A) = \cos (A - \frac{\pi}{4}) \Rightarrow$ 当 $\angle A = \frac{\pi}{4}$ 时， $\sqrt{2} \cos A + \cos C$ 取得最大值1.
