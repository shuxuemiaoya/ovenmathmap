> [!faq]- 《zhenti-专题14 基本初等函数与图象零点应用》例题解析
>
> > [!success]- **【答案】** C
>
> > [!note]- **【解析】**
> > 试题分析：函数在 $P$ 处无意义，由图像看 $P$ 在 $y$ 轴右侧，所以 $-c > 0, c < 0$ ， $f(0) = \frac{b}{c^2} > 0, \therefore b > 0$ ，由 $f(x) = 0, \therefore ax + b = 0$ ，即 $x = -\frac{b}{a}$ ，即函数的零点 $x = -\frac{b}{a} > 0 \therefore a < 0 \therefore a \langle 0, b \rangle 0, c < 0$ ，故选 C.
> >
> > 考点：函数的图像
