> [!faq]- 《专题16 导数及其应用小题综合》真题解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > 【答案】 $1 - \ln 2$
> > 【详解】试题分析：对函数 $y = \ln x + 2$ 求导得 $y' = \frac{1}{x}$ ，对 $y = \ln(x + 1)$ 求导得 $y' = \frac{1}{x + 1}$ ，设直线 $y = kx + b$ 与曲线 $y = \ln x + 2$ 相切于点 $P_{1}(x_{1}, y_{1})$ ，与曲线 $y = \ln(x + 1)$ 相切于点 $P_{2}(x_{2}, y_{2})$ ，则 $y_{1} = \ln x_{1} + 2, y_{2} = \ln(x_{2} + 1)$ ，由点 $P_{1}(x_{1}, y_{1})$ 在切线上得 $y - (\ln x_{1} + 2) = \frac{1}{x_{1}}(x - x_{1})$ ，由点 $P_{2}(x_{2}, y_{2})$ 在切线上得 $y - \ln(x_{2} + 1) = \frac{1}{x_{2} + 1}(x - x_{2})$ ，这两条直线表示同一条直线，所以 $\left\{\begin{aligned}\frac{1}{x_{1}} &= \frac{1}{x_{2} + 1} \\ \ln(x_{2} + 1) &= \ln x_{1} + \frac{2x_{2} + 1}{x_{2} + 1}\end{aligned}\right.$ ，解得 $x_{1} = \frac{1}{2}, \therefore k = \frac{1}{x_{1}} = 2, b = \ln x_{1} + 2 - 1 = 1 - \ln 2.$
> > 【考点】导数的几何意义
> > 【名师点睛】函数 $f(x)$ 在点 $x_0$ 处的导数 $f'(x_0)$ 的几何意义是曲线 $y = f(x)$ 在点 $P(x_0, y_0)$ 处的切线的斜率．相应地，切线方程为 $y - y_0 = f'(x_0)(x - x_0)$ ．
> > 注意：求曲线切线时，要分清在点 $P$ 处的切线与过点 $P$ 的切线的不同。
