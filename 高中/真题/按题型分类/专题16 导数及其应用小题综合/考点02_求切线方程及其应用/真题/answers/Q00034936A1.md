> [!faq]- 《专题16 导数及其应用小题综合》真题解析
>
> > [!success]- **【答案】** $y = 2x$
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > 试题分析：当 $x > 0$ 时， $-x < 0$ ，则 $f(-x) = \mathrm{e}^{x - 1} + x$ 。又因为 $f(x)$ 为偶函数，所以 $f(x) = f(-x) = \mathrm{e}^{x - 1} + x$ ，所以 $f'(x) = \mathrm{e}^{x - 1} + 1$ ，则 $f'(1) = 2$ ，所以切线方程为 $y - 2 = 2(x - 1)$ ，即 $y = 2x$
> > 【考点】函数的奇偶性、解析式及导数的几何意义
> > 【知识拓展】本题题型可归纳为“已知当 x > 0 时，函数 $y = f(x)$ ，则当 x < 0 时，求函数的解析式”。有如下结论：若函数 $f(x)$ 为偶函数，则当 x < 0 时，函数的解析式为 $y = -f(x)$ ；若 $f(x)$ 为奇函数，则函数的解析式为 $y = -f(-x)$ 。
