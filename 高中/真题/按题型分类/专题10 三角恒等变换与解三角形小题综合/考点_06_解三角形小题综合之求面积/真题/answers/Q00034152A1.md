> [!faq]- 《专题10 三角恒等变换与解三角形小题综合》真题解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【分析】**
> > 【分析】方法一：由正弦定理可得 $\sin B\sin C + \sin C\sin B = 4\sin A\sin B\sin C$ ，化简求得 $\sin A = \frac{1}{2}$ ，利用余弦定理结合题中的条件，可以得到 $2bc\cos A = 8$ ，由 A 为锐角，求得 $\cos A = \frac{\sqrt{3}}{2}$ ， $bc = \frac{8\sqrt{3}}{3}$ ，利用三角形面积公式即可解出.
>
> > [!note]- **【解析】**
> > 【详解】[方法一]：【最优解】边化角
> > 因为 $b\sin C + c\sin B = 4a\sin B\sin C$ ，由正弦定理得 $\sin B\sin C + \sin C\sin B = 4\sin A\sin B\sin C$
> > 因为 $\sin B\sin C\neq 0$ ，所以 $\sin A = \frac{1}{2}$ .又因为 $b^{2} + c^{2} - a^{2} = 8$
> > 由余弦定理 $a^2 = b^2 + c^2 - 2bc\cos A$ ，可得 $2bc\cos A = 8$
> > 所以 $\cos A > 0$ ，即 $\mathrm{A}$ 为锐角，且 $\cos A = \frac{\sqrt{3}}{2}$ ，从而求得 $bc = \frac{8\sqrt{3}}{3}$
> > 所以 $\triangle ABC$ 的面积为 $S = \frac{1}{2} bc\sin A = \frac{1}{2}\cdot \frac{8\sqrt{3}}{3}\cdot \frac{1}{2} = \frac{2\sqrt{3}}{3}$
> > 故答案为： $\frac{2\sqrt{3}}{3}$
> > [方法二]：角化边
> > 因为 $b\sin C + c\sin B = 4a\sin B\sin C$ ，由正弦定理得 $bc + bc = 4ab\sin C$ ，即 $c = 2a\sin C$ ，又 $\frac{c}{\sin C} = \frac{a}{\sin A}$ ，所以， $\sin A = \frac{1}{2}$ 。又因为 $b^2 + c^2 - a^2 = 8$ ，
> > 由余弦定理 $a^2 = b^2 + c^2 - 2bc\cos A$ ，可得 $2bc\cos A = 8$
> > 所以 $\cos A > 0$ ，即 $\mathrm{A}$ 为锐角，且 $\cos A = \frac{\sqrt{3}}{2}$ ，从而求得 $bc = \frac{8\sqrt{3}}{3}$
> > 所以 $\triangle ABC$ 的面积为 $S = \frac{1}{2} bc\sin A = \frac{1}{2}\cdot \frac{8\sqrt{3}}{3}\cdot \frac{1}{2} = \frac{2\sqrt{3}}{3}$
> > 故答案为： $\frac{2\sqrt{3}}{3}$
> > 【整体点评】方法一：利用正弦定理边化角，求出 $\sin A$ ，再结合余弦定理求出 $bc$ ，即可求出面积，该法是本题的最优解；
> > 方法二：利用正弦定理边化角，求出 $\sin A$ ，再结合余弦定理求出 $bc$ ，即可求出面积.
