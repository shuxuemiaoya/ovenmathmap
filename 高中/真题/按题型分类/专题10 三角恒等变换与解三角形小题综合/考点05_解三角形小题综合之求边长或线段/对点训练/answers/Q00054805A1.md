> [!faq]- 《zhenti-专题10 三角恒等变换与解三角形小题综合》例题解析
>
> > [!success]- **【答案】** $\sqrt{6}$
>
> > [!note]- **【解析】**
> > 试题分析：由正弦定理可得 $\frac{AD}{\sin B} = \frac{AB}{\sin\angle ADB}$ ，所以 $\sin \angle ADB = \frac{AB\sin B}{AD} = \frac{\sqrt{2}\times\sin 120^{\circ}}{\sqrt{3}} = \frac{\sqrt{2}}{2}$ 在 $\Delta ADB$ 中 $\angle ADB = 45^{\circ}$ ，所以 $\angle BAD = 180^{\circ} - 120^{\circ} - 45^{\circ} = 15^{\circ}$ ，所以在 $\Delta ABC$ 中 $A = 30^{\circ}$ .又因为 $B = 120^{\circ}$ 所以 $A = C = 30^{\circ}$ .所以 $AB = BC = \sqrt{2}$ ，所以 $AC^{2} = AB^{2} + BC^{2} - 2AC\cdot BC\cdot \cos B =$
> >
> > $2+2-2\times\sqrt{2}\times\sqrt{2}\cdot\left(-\frac{1}{2}\right)=6$ ，所以 $AC=\sqrt{6}$
> >
> > 考点：正余弦定理.
> >
> > 【技巧点睛】
> > （1）在三角形中处理边角关系时，一般全部转化为角的关系，或全部转化为边的关系．题中若出现边的一次式一般采用正弦定理，出现边的二次式一般采用余弦定理，应用正弦、余弦定理时，注意公式变形的应用，解决三角形问题时，注意角的限制范围．
