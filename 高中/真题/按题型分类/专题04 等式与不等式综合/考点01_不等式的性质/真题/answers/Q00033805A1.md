> [!faq]- 《专题04 等式与不等式综合》真题解析
>
> > [!success]- **【答案】** B
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > 【答案】B
> > 【详解】分析：求出 $\frac{1}{a} = \log 0.3^{0.2},\frac{1}{b} = \log 0.3^2$ ，得到 $\frac{1}{a} +\frac{1}{b}$ 的范围，进而可得结果.详解： $\because a = \log 0.2^{0.3},b = \log 2^{0.3}$ $\therefore \frac{1}{a} = \log 0.3^{0.2},\frac{1}{b} = \log 0.3^2$ $\therefore \frac{1}{a} +\frac{1}{b} = \log_{0.3}0.4$ $\therefore 0 <   \frac{1}{a} +\frac{1}{b} <  1,$ 即 $0 <   \frac{a + b}{ab} <  1$ 又∵ $a > 0,b <   0$
> > ∴ ab < 0 即 ab < a + b < 0
> > 故选 B.
> > ## 点睛：本题主要考查对数的运算和不等式，属于中档题。
