> [!faq]- 《专题04 等式与不等式综合》真题解析
>
> > [!success]- **【答案】** A
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > 【答案】A
> > 【详解】不等式 $f(x)$ $\left|\frac{x}{2} +a\right|$ 为 $-f(x)\leq \frac{x}{2} +a\leq f(x)(*)$
> > 当 $x \leq 1$ 时， $(^{*})$ 式即为 $-x^{2} + x - 3 \leq \frac{x}{2} + a \leq x^{2} - x + 3$ ， $-x^{2} + \frac{x}{2} - 3 \leq a \leq x^{2} - \frac{3}{2}x + 3$ ，又 $-x^{2} + \frac{x}{2} - 3 = -(x - \frac{1}{4})^{2} - \frac{47}{16} \leq -\frac{47}{16}$ （ $x = \frac{1}{4}$ 时取等号）， $x^{2} - \frac{3}{2}x + 3 = (x - \frac{3}{4})^{2} + \frac{39}{16}$ 、 $\frac{39}{16}$ （ $x = \frac{3}{4}$ 时取等号），
> > 所以 $-\frac{47}{16} \leq a \leq \frac{39}{16}$ ，
> > 当 $x > 1$ 时， $(^{*})$ 式为 $-x - \frac{2}{x} \leq \frac{x}{2} + a \leq x + \frac{2}{x}$ ， $-\frac{3}{2} x - \frac{2}{x} \leq a \leq \frac{x}{2} + \frac{2}{x}$ ，
> > 又 $-\frac{3}{2}x - \frac{2}{x} = -\left(\frac{3}{2}x + \frac{2}{x}\right) \leq -2\sqrt{3}$ （当 $x = \frac{2\sqrt{3}}{3}$ 时取等号），
> > $\frac{x}{2}+\frac{2}{x}\quad2\sqrt{\frac{x}{2}\times\frac{2}{x}}=2$ （当 $x=2$ 时取等号），
> > 所以 $-2\sqrt{3} \leq a \leq 2$
> > 综上 $-\frac{47}{16} \leq a \leq 2$ 。故选 A.
> > ## 【考点】不等式、恒成立问题
> > 【名师点睛】首先满足 $f(x) \left| \frac{x}{2} + a \right|$ 转化为 $-f(x) - \frac{x}{2} \leq a \leq f(x) - \frac{x}{2}$ 去解决，由于涉及分段函数问题要遵循分段处理原则，分别对 $x$ 的两种不同情况进行讨论，针对每种情况根据 $x$ 的范围，利用极端原理，求出对应的 $a$ 的范围.
