> [!faq]- 《专题09 三角函数的图象与性质小题综合》真题解析
>
> > [!success]- **【答案】** 3
>
> > [!note]- **【分析】**
> > 方法一：求出 $3x + \frac{\pi}{6}$ 的范围，再由函数值为零，得到 $3x + \frac{\pi}{6}$ 的取值即得零点个数.
>
> > [!note]- **【解析】**
> > [方法一]：【最优解】
> > $$
> > \because 0 \leq x \leq \pi \therefore \frac {\pi}{6} \leq 3 x + \frac {\pi}{6} \leq \frac {1 9 \pi}{6}
> > $$
> > 由题可知 $3x + \frac{\pi}{6} = \frac{\pi}{2}, 3x + \frac{\pi}{6} = \frac{3\pi}{2}$ ，或 $3x + \frac{\pi}{6} = \frac{5\pi}{2}$
> > 解得 $x=\frac{\pi}{9},\frac{4\pi}{9}$ ，或 $\frac{7\pi}{9}$ 故有 3 个零点。
> > 故答案为：3.
> > 方法二：
> > 令 $f(x) = \cos \left(3x + \frac{\pi}{6}\right) = 0$ ，即 $3x + \frac{\pi}{6} = k\pi +\frac{\pi}{2},k\in \mathbf{Z}$ ，解得， $x = \frac{k}{3}\pi +\frac{\pi}{9},k\in \mathbf{Z}$ ，分别令 $k = 0,1,2$ ，得 $x = \frac{\pi}{9},x = \frac{4\pi}{9},x = \frac{7\pi}{9}$ ，所以函数 $f(x) = \cos \left(3x + \frac{\pi}{6}\right)$ 在 $[0,\pi ]$ 的零点的个数为3.
> > 故答案为：3
> > 【整体点评】方法一：先求出 $3x + \frac{\pi}{6}$ 的范围，再根据余弦函数在该范围内的零点，从而解出，是该题的最优解；
> > 方法二：先求出函数的所有零点，再根据题中范围限制，找出符合题意的零点。
