> > 【详解】设 $A(x_{1},y_{1}), B(x_{2},y_{2}), D(x_{3},y_{3}), E(x_{4},y_{4})$ ，直线 $l_{1}$ 的方程为 $y = k_{1}(x - 1)$ ，联立方程 $\left\{\begin{aligned} y^{2} &= 4x \\ y &= k_{1}(x - 1) \end{aligned}\right.$ ，得 $k_{1}^{2}x^{2} - 2k_{1}^{2}x - 4x + k_{1}^{2} = 0$ ，∴ $x_{1} + x_{2} = -\frac{-2k_{1}^{2} - 4}{k_{1}^{2}} = \frac{2k_{1}^{2} + 4}{k_{1}^{2}}$ ，同理直线 $l_{2}$ 与抛物线的交点满足 $x_{3} + x_{4} = \frac{2k_{2}^{2} + 4}{k_{2}^{2}}$ ，由抛物线定义可知 $|AB| + |DE| = x_{1} + x_{2} + x_{3} + x_{4} + 2p = \frac{2k_{1}^{2} + 4}{k_{1}^{2}} + \frac{2k_{2}^{2} + 4}{k_{2}^{2}} + 4 = \frac{4}{k_{1}^{2}} + \frac{4}{k_{2}^{2}} + 8 \sqrt{\frac{16}{k_{1}^{2}k_{2}^{2}}} + 8 = 16$ ，当且仅当 $k_{1} = -k_{2} = 1$ （或 -1）时，取等号·
