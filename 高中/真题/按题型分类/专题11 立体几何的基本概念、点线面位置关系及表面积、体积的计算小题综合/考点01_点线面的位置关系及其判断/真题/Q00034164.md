①若 $m // n$ ，则 $n // \alpha$ 或 $n // \beta$ ②若 $m \perp n$ ，则 $n \perp \alpha$ 或 $n \perp \beta$

③若 $n / / \alpha$ 且 $n / / \beta$ ，则 $m / / n$ ④若 $n$ 与 $\alpha, \beta$ 所成的角相等，则 $m \perp n$

其中所有真命题的编号是（）
A. ①③ B. ②④ C. ①②③ D. ①③④
