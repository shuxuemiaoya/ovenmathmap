> [!faq]- 《专题23 导数及其应用大题综合》真题解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【分析】**
> > 【分析】（ $^{1}$ ）直接使用导数的几何意义；
> >
> > (2) 先由题设条件得到 a = 2 ，再证明 a = 2 时条件满足；
> >
> > (3) 先确定 $f(x)$ 的单调性，再对 $x_{1}, x_{2}$ 分类讨论.
>
> > [!note]- **【解析】**
> > 【详解】（1）由于 $f(x) = x \ln x$ ，故 $f'(x) = \ln x + 1$ .
> > 所以 $f(1)=0$ ， $f'(1)=1$ ，所以所求的切线经过 $(1,0)$ ，且斜率为 1，故其方程为 y=x-1。
> > (2) 设 $h(t)=t-1-\ln t$ ，则 $h'(t)=1-\frac{1}{t}=\frac{t-1}{t}$ ，从而当 0<t<1 时 $h'(t)<0$ ，当 $t>1$ 时 $h'(t)>0\cdot$
> > 所以 $h(t)$ 在 $(0,1]$ 上递减，在 $[1, +\infty)$ 上递增，这就说明 $h(t) - h(1)$ ，即 $t - 1 - \ln t$ ，且等号成立当且仅当 $t = 1$
> > 设 $g(t) = a(t - 1) - 2\ln t$ ，则
> > $$
> > f (x) - a (x - \sqrt {x}) = x \ln x - a (x - \sqrt {x}) = x \left(a \left(\frac {1}{\sqrt {x}} - 1\right) - 2 \ln \frac {1}{\sqrt {x}}\right) = x \cdot g \left(\frac {1}{\sqrt {x}}\right).
> > $$
> > 当 $x \in (0, +\infty)$ 时， $\frac{1}{\sqrt{x}}$ 的取值范围是 $(0, +\infty)$ ，所以命题等价于对任意 $t \in (0, +\infty)$ ，都有 $g(t) = 0\cdot$
> > 一方面，若对任意 $t \in (0, +\infty)$ ，都有 $g(t) = 0$ ，则对 $t \in (0, +\infty)$ 有
> > $$
> > 0 \leq g (t) = a (t - 1) - 2 \ln t = a (t - 1) + 2 \ln \frac {1}{t} \leq a (t - 1) + 2 \left(\frac {1}{t} - 1\right) = a t + \frac {2}{t} - a - 2
> > $$
> > 取 t = 2 ，得 $0 \leq a - 1$ ，故 a 1 > 0 .
> > 再取 $t = \sqrt{\frac{2}{a}}$ ，得 $0\leq a\cdot \sqrt{\frac{2}{a}} +2\sqrt{\frac{a}{2}} -a - 2 = 2\sqrt{2a} -a - 2 = -\left(\sqrt{a} -\sqrt{2}\right)^{2}$ ，所以 $a = 2$
> > 另一方面，若 $a = 2$ ，则对任意 $t\in (0, + \infty)$ 都有 $g(t) = 2(t - 1) - 2\ln t = 2h(t)\quad 0$ ，满足条件
> > 综合以上两个方面，知 a 的值是 2.
> > (3) 先证明一个结论：对 $0 < a < b$ ，有 $\ln a + 1 < \frac{f(b) - f(a)}{b - a} < \ln b + 1$ .
> > 证明：前面已经证明不等式 $t - 1\quad \ln t$ ，故 $\frac{b\ln b - a\ln a}{b - a} = \frac{a\ln b - a\ln a}{b - a} +\ln b = \frac{\ln\frac{b}{a}}{\frac{b}{a} - 1} +\ln b <   1 + \ln b,$
> > 且 $\frac{b\ln b - a\ln a}{b - a} = \frac{b\ln b - b\ln a}{b - a} +\ln a = \frac{-\ln\frac{a}{b}}{1 - \frac{a}{b}} +\ln a > \frac{-\left(\frac{a}{b} - 1\right)}{1 - \frac{a}{b}} +\ln a = 1 + \ln a$
> > 所以 $\ln a + 1 < \frac{b\ln b - a\ln a}{b - a} < \ln b + 1$ ，即 $\ln a + 1 < \frac{f(b) - f(a)}{b - a} < \ln b + 1$ .
> > 由 $f'(x)=\ln x+1$ ，可知当 $0<x<\frac{1}{e}$ 时 $f'(x)<0$ ，当 $x>\frac{1}{e}$ 时 $f\Phi(x)>0\cdot$
> > 所以 $f(x)$ 在 $\left(0, \frac{1}{\mathrm{e}}\right]$ 上递减，在 $\left[\frac{1}{\mathrm{e}}, +\infty\right)$ 上递增.
> > 不妨设 $x_{1} \leq x_{2}$ ，下面分三种情况（其中有重合部分）证明本题结论：
> > $$
> > \frac {1}{e} \leq x _ {1} \leq x _ {2} <   1
> > $$
> > $$
> > \left| f \left(x _ {1}\right) - f \left(x _ {2}\right) \right| = f \left(x _ {2}\right) - f \left(x _ {1}\right) <   (\ln x _ {2} + 1) \left(x _ {2} - x _ {1}\right) <   x _ {2} - x _ {1} <   \sqrt {x _ {2} - x _ {1}}
> > $$
> > 成立；
> > 情况二：当 $0 < x_{1} \leq x_{2} \leq \frac{1}{\mathrm{e}}$ 时，有 $\left|f(x_1) - f(x_2)\right| = f(x_1) - f(x_2) = x_1\ln x_1 - x_2\ln x_2.$
> > 对任意的 $c \in \left(0, \frac{1}{\mathbf{e}}\right]$ ，设 $\varphi(x) = x \ln x - c \ln c - \sqrt{c - x}$ ，则 $\varphi'(x) = \ln x + 1 + \frac{1}{2\sqrt{c - x}}$ 。
> > 由于 $\varphi'(x)$ 单调递增，且有
> > $$
> > \varphi^ {\prime} \left(\frac {c}{2 \mathrm{e} ^ {1 + \frac {1}{\sqrt {2 c}}}}\right) = \ln \frac {c}{2 \mathrm{e} ^ {1 + \frac {1}{\sqrt {2 c}}}} + 1 + \frac {1}{2 \sqrt {c - \frac {c}{2 \mathrm{e} ^ {1 + \frac {1}{\sqrt {2 c}}}}}} <   \ln \frac {1}{\mathrm{e} ^ {1 + \frac {1}{\sqrt {2 c}}}} + 1 + \frac {1}{2 \sqrt {c - \frac {c}{2}}} = - 1 - \frac {1}{\sqrt {2 c}} + 1 + \frac {1}{\sqrt {2 c}} = 0
> > $$
> > 且当 $x = c - \frac{1}{4\left(\ln\frac{2}{c} - 1\right)^2}$ ， $x > \frac{c}{2}$ 时，由 $\frac{1}{2\sqrt{c - x}} = \ln \frac{2}{c} - 1$ 可知
> > $$
> > \varphi^ {\prime} (x) = \ln x + 1 + \frac {1}{2 \sqrt {c - x}} > \ln \frac {c}{2} + 1 + \frac {1}{2 \sqrt {c - x}} = \frac {1}{2 \sqrt {c - x}} - \left(\ln \frac {2}{c} - 1\right) 0.
> > $$
> > 所以 $\varphi'(x)$ 在 $(0, c)$ 上存在零点 $x_0$ ，再结合 $\varphi'(x)$ 单调递增，即知 $0 < x < x_0$ 时 $\varphi'(x) < 0$ ， $x_0 < x < c$ 时 $\varphi'(x) > 0$ .
> > 故 $\varphi(x)$ 在 $(0, x_0]$ 上递减，在 $[x_0, c]$ 上递增
> > - **①**：当 $x_{0} \leq x \leq c$ 时，有 $\varphi(x) \leq \varphi(c) = 0$ ；
> > - **②**：当 $0 < x < x_0$ 时，由于 $\sqrt{c} \ln \frac{1}{c} = -2f\left(\sqrt{c}\right) \leq -2f\left(\frac{1}{e}\right) = \frac{2}{e} < 1$ ，故我们可以取 $q \in \left(\sqrt{c} \ln \frac{1}{c}, 1\right)$ .
> > 从而当 $0 < x < \frac{c}{1 - q^2}$ 时，由 $\sqrt{c - x} > q\sqrt{c}$ ，可得
> > $$
> > \varphi (x) = x \ln x - c \ln c - \sqrt {c - x} <   - c \ln c - \sqrt {c - x} <   - c \ln c - q \sqrt {c} = \sqrt {c} (\sqrt {c} \ln \frac {1}{c} - q) <   0.
> > $$
> > 再根据 $\varphi(x)$ 在 $(0, x_{0}]$ 上递减，即知对 $0 < x < x_{0}$ 都有 $\varphi(x) < 0$ ；
> > 综合①②可知对任意 $0 < x \leq c$ ，都有 $\varphi(x) \leq 0$ ，即 $\varphi(x) = x \ln x - c \ln c - \sqrt{c - x} \leq 0$ .
> > 根据 $c \in \left(0, \frac{1}{\mathrm{e}}\right]$ 和 $0 < x \leq c$ 的任意性，取 $c = x_2$ ， $x = x_1$ ，就得到 $x_1 \ln x_1 - x_2 \ln x_2 - \sqrt{x_2 - x_1} \leq 0$
> > 所以 $\left|f(x_1) - f(x_2)\right| = f(x_1) - f(x_2) = x_1\ln x_1 - x_2\ln x_2\leq \sqrt{x_2 - x_1}$
> > 情况三：当 $0 < x_{1} \leq \frac{1}{\mathrm{e}} \leq x_{2} < 1$ 时，根据情况一和情况二的讨论，可得 $\left|f\left(x_{1}\right) - f\left(\frac{1}{\mathrm{e}}\right)\right| \leq \sqrt{\frac{1}{\mathrm{e}} - x_1} \leq \sqrt{x_2 - x_1}$ ， $f\left(\frac{1}{\mathrm{e}}\right) - f\left(x_{2}\right) \leq \sqrt{x_2 - \frac{1}{\mathrm{e}}} \leq \sqrt{x_2 - x_1}$ .
> > 而根据 $f(x)$ 的单调性，知 $\left|f(x_1) - f(x_2)\right| \leq \left|f(x_1) - f\left(\frac{1}{\mathbf{e}}\right)\right|$ 或 $\left|f(x_1) - f(x_2)\right| \leq \left|f\left(\frac{1}{\mathbf{e}}\right) - f(x_2)\right|$ .
> > 故一定有 $\left|f\left(x_{1}\right)-f\left(x_{2}\right)\right|\leq\sqrt{x_{2}-x_{1}}$ 成立.
> > 综上，结论成立·
> > 【点睛】关键点点睛：本题的关键在于第 $^{3}$ 小问中，需要结合 $f(x)$ 的单调性进行分类讨论.
