> [!faq]- 《专题23 导数及其应用大题综合》真题解析
>
> > [!success]- **【答案】** (1) $f(x) = 1 - x + x^2$ (II) $\frac{3}{4} < f(x) \leq \frac{3}{2}$ . 【答案】（Ⅰ）证明详见解析；（Ⅱ）证明详见解析。 【详解】试题分析：本题主要考查函数的单调性与最值、分段函数等基础知识，同时考查推理论证能力、 分析问题和解决问题的能力·第一问，利用放缩法，得到 $\frac{1 - x^4}{1 + x} \leq \frac{1}{1 + x}$ ，从而得到结论；第二问，由 $0 \leq x \leq 1$ 得 $x^{3} \leq x$ ，进行放缩，得到 $f(x) \leq \frac{3}{2}$ ，再结合第一问的结论，得到 $f(x) > \frac{3}{4}$ ，从而得到结论 试题
>
> > [!note]- **【分析】**
> > 本题未单列分析。
>
> > [!note]- **【解析】**
> > （Ⅰ）因为 $1 - x + x^{2} - x^{3} = \frac{1 - (-x)^{4}}{1 - (-x)} = \frac{1 - x^{4}}{1 + x}$
> > 由于 $x \in [0,1]$ ，有 $\frac{1 - x^4}{1 + x} \leq \frac{1}{1 + x}$ ，即 $1 - x + x^2 - x^3 \leq \frac{1}{x + 1}$ ，
> > 所以 $f(x)$ $1 - x + x^{2}$ .
> > (Ⅱ) 由 $0 \leq x \leq 1$ 得 $x^3 \leq x$ ，故
> > $$
> > f (x) = x ^ {3} + \frac {1}{x + 1} \leq x + \frac {1}{x + 1} - \frac {3}{2} + \frac {3}{2} = \frac {(x - 1) (2 x + 1)}{2 (x + 1)} + \frac {3}{2} \leq \frac {3}{2}
> > $$
> > 所以 $f(x) \leq \frac{3}{2}$ .
> > 由（1）得 $f(x) = 1 - x + x^2 = (x - \frac{1}{2})^2 +\frac{3}{4}$ $\frac{3}{4}$
> > 又因为 $f\left(\frac{1}{2}\right) = \frac{19}{24} >\frac{3}{4}$ ，所以 $f(x) > \frac{3}{4}$
> > 综上， $\frac{3}{4}<f(x)\leq\frac{3}{2}.$
> > 【考点】函数的单调性与最值、分段函数·
> > 【思路点睛】（Ⅰ）先用等比数列前 n 项和公式计算 $1 - x + x^{2} - x^{3}$ ，再用放缩法可得 $1 - x + x^{2} - x^{3} \leq \frac{1}{1 + x}$ ，进
> > 而可证 $f(x) = 1 - x + x^2$ ；（Ⅱ）由（Ⅰ）的结论及放缩法可证 $\frac{3}{4} < f(x) \leq \frac{3}{2}$
