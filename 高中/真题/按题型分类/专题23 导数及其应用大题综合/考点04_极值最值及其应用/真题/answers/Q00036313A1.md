> [!faq]- 《专题23 导数及其应用大题综合》真题解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【分析】**
> > （1）由题意得到关于 $a$ 的方程，解方程即可确定 $a$ 的值；
> >
> > (2) 由题意首先确定 $a, b, c$ 的值从而确定函数的解析式，然后求解其导函数，由导函数即可确定函数的极小值.
> >
> > (3) 由题意首先确定函数的极大值 $M$ 的表达式，然后可用如下方法证明题中的不等式：
> >
> > 解法一：由函数的解析式结合不等式的性质进行放缩即可证得题中的不等式；
> >
> > 解法二：由题意构造函数，求得函数在定义域内的最大值，
> >
> > 因为 $0 < b \leq 1$ ，所以 $x_{1} \in (0,1)$
> >
> > 当 $x \in (0,1)$ 时， $f(x) = x(x - b)(x - 1) \leq x(x - 1)^2$
> >
> > 令 $g(x) = x(x - 1)^2, x \in (0,1)$ ，则 $g'(x) = 3\left(x - \frac{1}{3}\right)(x - 1)$
> >
> > 令 $g'(x) = 0$ ，得 $x = \frac{1}{3}$ .列表如下：
> >
> > <table><tr><td>x</td><td> $(0,\frac{1}{3})$ </td><td> $\frac{1}{3}$ </td><td> $(\frac{1}{3},1)$ </td></tr><tr><td>g&#x27;(x)</td><td>+</td><td>0</td><td>-</td></tr><tr><td>g(x)</td><td>↗</td><td>极大值</td><td>↘</td></tr></table>
> >
> > 所以当 $x = \frac{1}{3}$ 时， $g(x)$ 取得极大值，且是最大值，故 $g(x)_{\max} = g\left(\frac{1}{3}\right) = \frac{4}{27}$
> >
> > 所以当 $x \in (0,1)$ 时， $f(x) \leq g(x) \leq \frac{4}{27}$ ，因此 $M \leq \frac{4}{27}$ 。
>
> > [!note]- **【解析】**
> > （1）因为 $a = b = c$ ，所以 $f(x) = (x - a)(x - b)(x - c) = (x - a)^3$
> > 因为 $f(4)=8$ ，所以 $(4-a)^{3}=8$ ，解得 a=2。
> > (2) 因为 b = c，
> > 所以 $f(x)=(x-a)(x-b)^{2}=x^{3}-(a+2b)x^{2}+b(2a+b)x-ab^{2}$
> > 从而 $f^{\prime}(x) = 3(x - b)\left(x - \frac{2a + b}{3}\right)$ .令 $f^{\prime}(x) = 0$ ，得 $\mathrm{x} = \mathrm{b}$ 或 $x = \frac{2a + b}{3}$
> > 因为 $a, b, \frac{2a + b}{3}$ ，都在集合 $\{-3, 1, 3\}$ 中，且 $a^1 - b$ ，
> > 所以 $\frac{2a + b}{3} = 1, a = 3, b = -3$
> > 此时 $f(x)=(x-3)(x+3)^{2}$ ， $f'(x)=3(x+3)(x-1)$
> > 令 $f'(x) = 0$ ，得 $x = -3$ 或 $x = 1$ 。列表如下：
> > <table><tr><td>x</td><td>(-∞,-3)</td><td>-3</td><td>(-3,1)</td><td>1</td><td>(1,+∞)</td></tr><tr><td>f&#x27;(x)</td><td>+</td><td>0</td><td>-</td><td>0</td><td>+</td></tr><tr><td>f(x)</td><td>↗</td><td>极大值</td><td>↘</td><td>极小值</td><td>↗</td></tr></table>
> > 所以 $f(x)$ 的极小值为 $f(1) = (1 - 3)(1 + 3)^2 = -32$
> > (3) 因为 $a = 0, c = 1$ ，所以 $f(x) = x(x - b)(x - 1) = x^3 - (b + 1)x^2 + bx$
> > $$
> > f ^ {\prime} (x) = 3 x ^ {2} - 2 (b + 1) x + b
> > $$
> > 因为 $0 < b \leq 1$ ，所以 $\Delta = 4(b + 1)^2 - 12b = (2b - 1)^2 + 3 > 0$
> > 则 $f^{\prime}(x)$ 有2个不同的零点，设为 $x_{1}, x_{2} (x_{1} < x_{2})$
> > 由 $f^{\prime}(x) = 0$ ，得 $x_{1} = \frac{b + 1 - \sqrt{b^{2} - b + 1}}{3}, x_{2} = \frac{b + 1 + \sqrt{b^{2} - b + 1}}{3}$
> > 列表如下：
> > <table><tr><td> $x$ f'(x)</td><td> $(-\infty, x_1)$ +</td><td> $x_1$ 0</td><td> $(x_1, x_2)$ -</td><td> $x_2$ 0</td><td> $(x_2, +\infty)$ +</td></tr><tr><td>f(x)</td><td> $\nearrow$ </td><td>极大值</td><td> $\searrow$ </td><td>极小值</td><td> $\nearrow$ </td></tr></table>
> > 所以 $f(x)$ 的极大值 $M = f(x_{1})$
> > 解法一：
> > $$
> > M = f \left(x _ {1}\right) = x _ {1} ^ {3} - (b + 1) x _ {1} ^ {2} + b x _ {1}
> > $$
> > $$
> > \begin{array}{r l} & {= \left(3 x _ {1} ^ {2} - 2 (b + 1) x _ {1} + b\right) \left(\frac {x _ {1}}{3} - \frac {b + 1}{9}\right) - \frac {2 \left(b ^ {2} - b + 1\right)}{9} x _ {1} + \frac {b (b + 1)}{9}} \\ & {= \frac {- 2 \left(b ^ {2} - b + 1\right) (b + 1)}{2 7} + \frac {b (b + 1)}{9} + \frac {2}{2 7} \left(\sqrt {b ^ {2} - b + 1}\right) ^ {3}} \\ & {= \frac {b (b + 1)}{2 7} - \frac {2 (b - 1) ^ {2} (b + 1)}{2 7} + \frac {2}{2 7} (\sqrt {b (b - 1) + 1}) ^ {3}} \\ & {\leq \frac {b (b + 1)}{2 7} + \frac {2}{2 7} \leq \frac {4}{2 7}. \text {因此} M \leq \frac {4}{2 7}.} \end{array}
> > $$
> > 解法二：
> > 因为 $0 < b \leq 1$ ，所以 $x_{1} \in (0,1)$
> > 当 $x \in (0,1)$ 时， $f(x) = x(x - b)(x - 1) \leq x(x - 1)^2$
> > 令 $g(x) = x(x - 1)^2, x \in (0,1)$ ，则 $g'(x) = 3\left(x - \frac{1}{3}\right)(x - 1)$
> > 令 $g'(x) = 0$ ，得 $x = \frac{1}{3}$ .列表如下：
> > <table><tr><td>x</td><td>(0,1/3)</td><td>1/3</td><td>(1/3,1)</td></tr><tr><td>g&#x27;(x)</td><td>+</td><td>0</td><td>-</td></tr><tr><td>g(x)</td><td>↗</td><td>极大值</td><td>↘</td></tr></table>
> > 所以当 $x = \frac{1}{3}$ 时， $g(x)$ 取得极大值，且是最大值，故 $g(x)_{\max} = g\left(\frac{1}{3}\right) = \frac{4}{27}$
> > 所以当 $x \in (0,1)$ 时， $f(x) \leq g(x) \leq \frac{4}{27}$ ，因此 $M \leq \frac{4}{27}$
