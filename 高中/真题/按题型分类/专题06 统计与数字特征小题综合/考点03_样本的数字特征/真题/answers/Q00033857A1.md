> [!faq]- 《专题06 统计与数字特征小题综合》真题解析
>
> > [!success]- **【答案】** BD
>
> > [!note]- **【分析】**
> > 【分析】根据题意结合平均数、中位数、标准差以及极差的概念逐项分析判断·
>
> > [!note]- **【解析】**
> > 【详解】对于选项 A：设 $x_{2}, x_{3}, x_{4}, x_{5}$ 的平均数为 m， $x_{1}, x_{2}, \cdots, x_{6}$ 的平均数为 n，
> > $$
> > n - m = \frac {x _ {1} + x _ {2} + x _ {3} + x _ {4} + x _ {5} + x _ {6}}{6} - \frac {x _ {2} + x _ {3} + x _ {4} + x _ {5}}{4} = \frac {2 (x _ {1} + x _ {6}) - (x _ {5} + x _ {2} + x _ {3} + x _ {4})}{1 2}
> > $$
> > 因为没有确定 $2(x_{1} + x_{6}), x_{5} + x_{2} + x_{3} + x_{4}$ 的大小关系，所以无法判断 $m, n$ 的大小，
> > 例如：1,2,3,4,5,6，可得 $m = n = 3.5$
> > 例如 1,1,1,1,1,7 ，可得 m=1,n=2 ；
> > 例如1,2,2,2,2,2，可得 $m=2,n=\frac{11}{6}$ ；故A错误；
> > 对于选项 B：不妨设 $x_{1} \leq x_{2} \leq x_{3} \leq x_{4} \leq x_{5} \leq x_{6}$
> > 可知 $x_{2}, x_{3}, x_{4}, x_{5}$ 的中位数等于 $x_{1}, x_{2}, \cdots, x_{6}$ 的中位数均为 $\frac{x_{3} + x_{4}}{2}$ ，故 B 正确；
> > 对于选项 C：因为 $x_{1}$ 是最小值， $x_{6}$ 是最大值，
> > 则 $x_{2}, x_{3}, x_{4}, x_{5}$ 的波动性不大于 $x_{1}, x_{2}, \cdots, x_{6}$ 的波动性，即 $x_{2}, x_{3}, x_{4}, x_{5}$ 的标准差不大于 $x_{1}, x_{2}, \cdots, x_{6}$ 的标准差，
> > 例如：2,4,6,8,10,12，则平均数 $n=\frac{1}{6}(2+4+6+8+10+12)=7$ ，
> > 标准差 $s_1 = \sqrt{\frac{1}{6}\left[\left(2 - 7\right)^2 + \left(4 - 7\right)^2 + \left(6 - 7\right)^2 + \left(8 - 7\right)^2 + \left(10 - 7\right)^2 + \left(12 - 7\right)^2\right]} = \frac{\sqrt{105}}{3}$
> > 4,6,8,10，则平均数 $m=\frac{1}{4}(4+6+8+10)=7$ ，
> > 标准差 $s_2 = \sqrt{\frac{1}{4}\left[\left(4 - 7\right)^2 + \left(6 - 7\right)^2 + \left(8 - 7\right)^2 + \left(10 - 7\right)^2\right]} = \sqrt{5}$
> > 显然 $\frac{\sqrt{105}}{3} >\sqrt{5}$ ，即 $s_1 > s_2$ ；故C错误；
> > 对于选项 D：不妨设 $x_{1} \leq x_{2} \leq x_{3} \leq x_{4} \leq x_{5} \leq x_{6}$ ，
> > 则 $x_{6} - x_{1}$ $x_{5} - x_{2}$ ，当且仅当 $x_{1} = x_{2},x_{5} = x_{6}$ 时，等号成立，故D正确；
> >
> > 故选 **BD**.
