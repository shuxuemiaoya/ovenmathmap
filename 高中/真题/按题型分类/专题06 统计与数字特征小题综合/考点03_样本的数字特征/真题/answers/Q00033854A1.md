> [!faq]- 《专题06 统计与数字特征小题综合》真题解析
>
> > [!success]- **【答案】** 详见解析
>
> > [!note]- **【分析】**
> > 【分析】可不用动笔，直接得到答案，亦可采用特殊数据，特值法筛选答案．
>
> > [!note]- **【解析】**
> > 【详解】设 $^{9}$ 位评委评分按从小到大排列为 $x_{1} \leq x_{2} \leq x_{3} \leq x_{4} \cdots \leq x_{8} \leq x_{9}$ ．
> > 则①原始中位数为 $x_{5}$ ，去掉最低分 $x_{1}$ ，最高分 $x_{9}$ ，后剩余 $x_{2} \leq x_{3} \leq x_{4} \cdots \leq x_{8}$ ，
> > 中位数仍为 $x_{5}$ ，∴ A 正确．
> > - **②**：原始平均数 $\overline{x} = \frac{1}{9}(x_{1} + x_{2} + x_{3} + x_{4} \cdots + x_{8} + x_{9})$ ，后来平均数 $\overline{x'} = \frac{1}{7}(x_{2} + x_{3} + x_{4} \cdots + x_{8})$ 平均数受极端值影响较大，∴ $\overline{x}$ 与 $\overline{x'}$ 不一定相同， $^{B}$ 不正确
> > - **③**：$S^{2} = \frac{1}{9}\left[(x_{1} - \overline{x})^{2} + (x_{1} - \overline{x})^{2} + \cdots + (x_{9} - \overline{x})^{2}\right]$ $s'^{2} = \frac{1}{7}\left[(x_{2} - \overline{x}')^{2} + (x_{3} - \overline{x}')^{2} + \cdots + (x_{8} - \overline{x}')^{2}\right]$ 由②易知， $^{C}$ 不正确．
> > - **④**：原极差 $= x_{9} - x_{1}$ ，后来极差 $= x_{8} - x_{2}$ 可能相等可能变小，D不正确.
> > 【点睛】本题旨在考查学生对中位数、平均数、方差、极差本质的理解·
