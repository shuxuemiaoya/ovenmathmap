> [!faq]- 《zhenti-专题17 直线与圆小题综合》例题解析
>
> > [!success]- **【答案】** （Ⅰ） $(x-1)^{2}+(y-\sqrt{2})^{2}=2$ ；（Ⅱ） $-1-\sqrt{2}$
>
> > [!note]- **【解析】**
> > (1) 圆 C 的标准方程为 \_\_\_\_ ;
> >
> > (Ⅱ) 圆 C 在点 B 处的切线在 x 轴上的截距为 \_\_\_\_ .
> >
> >
> > 【详解】设点 C 的坐标为 $(x_{0}, y_{0})$ ，则由圆 C 与 x 轴相切于点 $T(1,0)$ 知，点 C 的横坐标为 1，即 $x_{0} = 1$ ，半径 $r = y_{0}$ 。又因为 $\left|AB\right| = 2$ ，所以 $1^{2} + 1^{2} = y_{0}^{2}$ ，即 $y_{0} = \sqrt{2} = r$ ，所以圆 C 的标准方程为 $(x - 1)^{2} + (y - \sqrt{2})^{2} = 2$ 令 $x = 0$ 得： $B(0, \sqrt{2} + 1)$ 。设圆 $C$ 在点 $B$ 处的切线方程为 $y - (\sqrt{2} + 1) = kx$ ，则圆心 $C$ 到其距离为： $d = \frac{|k - \sqrt{2} + \sqrt{2} + 1|}{\sqrt{k^2 + 1}} = \sqrt{2}$ ，解之得 $k = 1$ 。即圆 $C$ 在点 $B$ 处的切线方程为 $y = x + (\sqrt{2} + 1)$ ，于是令 $y = 0$ 可得 $x = -\sqrt{2} - 1$ ，即圆 $C$ 在点 $B$ 处的切线在 $x$ 轴上的截距为 $-1 - \sqrt{2}$ ，故应填 $(x - 1)^2 + (y - \sqrt{2})^2 = 2$ 和 $-1 - \sqrt{2}$ 。考点：本题考查圆的标准方程和圆的切线问题，属中高档题。
