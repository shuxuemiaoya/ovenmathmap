> [!faq]- 必刷题解析
> **【解析】**
> 【解】原不等式即为 $(ax-1)(x+2)<0$ .
> - **①**：当a=0时，-x-2<0，解得x>-2，故不等式的解集为 $\{x\mid x>-2\}$ ;
> - **②**：当a>0时， $\frac{1}{a}>-2$ ，解原不等式可得-2<x< $\frac{1}{a}$ ，此时原不等式的解集为 $\left\{x\right| - 2 < x < \frac{1}{a}\}$ ;
> - **③**：当 $-\frac{1}{2}<a<0$ 时， $\frac{1}{a}<-2$ ，解原不等式可得 $x<\frac{1}{a}$ 或x>-2，此时原不等式的解集为 $\left\{x\mid x<\frac{1}{a}或x>-2\right\}$ ;
> - **④**：当 $a=-\frac{1}{2}$ 时，原不等式即为 $-\frac{1}{2}(x+2)^{2}<0$ ，解得 $x\neq-2$ ，此时原不等式的解集为 $\{x\mid x\neq-2\}$ ;
> - **⑤**：当 $a < -\frac{1}{2}$ 时， $\frac{1}{a} > -2$ ，解原不等式可得 $x < -2$ 或 $x > \frac{1}{a}$ ，此时原不等式的解集为 $\left\{x \mid x < -2 \text{ 或 } x > \frac{1}{a}\right\}$ . 综上所述，当 $a < -\frac{1}{2}$ 时，原不等式的解集为 $\left\{x \mid x < -2 \text{ 或 } x > \frac{1}{a}\right\}$ ; 当 $a = -\frac{1}{2}$ 时，原不等式的解集为 $\{x \mid x \neq -2\}$ ; 当 $-\frac{1}{2} < a < 0$ 时，原不等式的解集为 $\left\{x \mid x < \frac{1}{a} \text{ 或 } x > -2\right\}$ ; 当 $a = 0$ 时，原不等式的解集为 $\{x \mid x > -2\}$ ; 当 $a > 0$ 时，原不等式的解集为 $\left\{x \mid -2 < x < \frac{1}{a}\right\}$ .
>

> **💡 规律方法**
> 对含参数的二次型不等式的讨论顺序:第一步讨论二次项系数是否为0;第二步讨论二次函数图象的开口方向;第三步讨论一元二次方程根的个数;第四步讨论根的大小.
