> [!faq]- 必刷题解析
> **【答案】** C
>
> **【解析】**
> 因为直线 $l_{1}: ax + 8y = 0$ 与 $l_{2}: 3x + 4y + b = 0$ 平行，所以 $4a = 3 \times 8$ ，解得 a = 6，则直线 $l_{1}: 6x + 8y = 0$ ，即为 $3x + 4y = 0$ 。又 $l_{1}$ 与 $l_{2}$ 之间的距离是 1，所以 $d = \frac{|b|}{\sqrt{3^{2} + 4^{2}}} = 1$ ，解得 b = 5 或 b = -5，所以 $a + b = 11$ 或 $a + b = 1$ 。
>
> 故选 **C**.
