> 在 $\triangle ABD$ 中， $\frac{|AB|}{\sin\angle ADB} = \frac{|BD|}{\sin\angle BAD}$ ，在 $\triangle ADC$ 中， $\frac{|AC|}{\sin\angle ADC} = \frac{|DC|}{\sin\angle CAD}$ ，故 $\frac{|AB|}{|BD|} = \frac{\sin\angle ADB}{\sin\angle BAD}$ ， $\frac{|AC|}{|DC|} = \frac{\sin\angle ADC}{\sin\angle CAD}$ 。因为 $\angle ADB = 180^\circ - \angle ADC$ ，所以 $\sin \angle ADB = \sin (180^\circ - \angle ADC) = \sin \angle ADC$ ，又角 $A$ 的平分线交 $BC$ 于点 $D$ ，则 $\angle BAD = \angle CAD$ ，因此 $\frac{|AB|}{|BD|} = \frac{|AC|}{|DC|}$ ，故
$$
\frac {| A B |}{| A C |} = \frac {| B D |}{| D C |} = \frac {1}{2}.
$$
以 $D$ 为坐标原点， $BC$ 所在直线为 $x$ 轴，建立如图所示的平面直角坐标系，因为 $|BC| = 3, \frac{|BD|}{|DC|} = \frac{1}{2}$ ，所以 $B(-1,0), C(2,0)$ ，设 $A(x,y)$ ，则 $\frac{\sqrt{(x + 1)^2 + y^2}}{\sqrt{(x - 2)^2 + y^2}} = \frac{1}{2}$ ，即 $4[(x + 1)^2 + y^2] = (x - 2)^2 + y^2$ 化简可得 $x^2 + 4x + y^2 = 0$ ，即 $(x + 2)^2 + y^2 = 4$ ，故点 $A(x,y)$ 的轨迹是以 $(-2,0)$ 为圆心，2为半径的圆（除去点 $(-4,0),(0,0)$ ）.
