> [!faq]- 必刷题解析
> **【答案】** C
>
> **【解析】**
> 由题可得抛物线的焦点 $F(1,0)$ ，准线方程为 $x = -1$ .由题意可知，直线 $AB$ 的斜率存在且不为0， $\rightarrow$ 避坑：注意直线斜率是否存在或为0
设直线 $AB$ 的方程为 $y = k(x - 1)(k\neq$ 0).
联立方程 $\left\{ \begin{array}{l}y^{2} = 4x,\\ y = k(x - 1), \end{array} \right.$ 消去 $y$ 得 $k^2 x^2 -(2k^2 +4)x + k^2 = 0.$ 设 $A(x_{1},y_{1}),B(x_{2},y_{2})$ ，则 $x_{1}x_{2} = 1$ $\because |FA| = x_1 + 1,|FB| = x_2 + 1,$ $\therefore |FA|\cdot |FB| = (x_1 + 1)(x_2 + 1) = x_1+$ $x_{2} + x_{1}x_{2} + 1 = x_{1} + x_{2} + 2 = 8,$ $\therefore |AB| = |FA| + |FB| = x_1 + x_2 + 2 = 8.$
>
> 故选 **C**.
