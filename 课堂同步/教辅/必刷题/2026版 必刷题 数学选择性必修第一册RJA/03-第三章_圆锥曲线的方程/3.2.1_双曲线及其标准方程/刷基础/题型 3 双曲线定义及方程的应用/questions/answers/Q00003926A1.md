> [!faq]- 必刷题解析
> **【答案】** B
>
> **【解析】**
> 由双曲线方程 $x^{2} - \frac{y^{2}}{8} = 1$ 可知， $a = 1, c = 3$ ，故右焦点 $F(3,0)$ 设左焦点为 $F_{1}$ ，则 $F_{1}(-3,0)$ 当点 $P$ 在双曲线左支上运动时，由双曲线定义知 $|PF| - |PF_{1}| = 2$ 所以 $|PF| = |PF_{1}| + 2$ 从而 $|PA| + |PF| = |PA| + |PF_{1}| + 2 \geqslant |AF_{1}| + 2$ 又 $|AF_{1}| = \sqrt{3^{2} + (\sqrt{7})^{2}} = 4$ 所以 $|PA| + |PF| \geqslant 6$ ，因此 $|PA| + |PF|$ 的最小值为6，此时点 $P$ 在线段 $AF_{1}$ 与双曲线左支的交点处.
>
> 故选 **B**.
