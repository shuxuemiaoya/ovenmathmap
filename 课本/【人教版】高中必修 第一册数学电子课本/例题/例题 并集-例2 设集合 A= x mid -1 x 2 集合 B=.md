> [!example]- 例 2 设集合 $A=\{x \mid -1 < x < 2\}$ ，集合 $B=\{x \mid 1 < x < 3\}$ ，求 $A \cup B$ .
>
> > [!success]- 解：
> > $A \cup B = \{x \mid -1 < x < 2\} \cup \{x \mid 1 < x < 3\}$
> > $= \{x \mid - 1 <   x <   3 \}.$
> >
> > 在求两个集合的并集时，它们的公共元素在并集中只能出现一次。如元素5，8.
