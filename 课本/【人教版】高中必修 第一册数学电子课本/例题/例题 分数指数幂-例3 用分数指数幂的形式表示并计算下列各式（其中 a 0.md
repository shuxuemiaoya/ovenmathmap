> [!example]- 例 3 用分数指数幂的形式表示并计算下列各式（其中 a>0）：
> （1） $a^2 \cdot \sqrt[3]{a^2}$ ;
> （2） $\sqrt{a\sqrt[3]{a}}$
>
> > [!success]- 解：
> > （1） $a^2\cdot \sqrt[3]{a^2} = a^2 a^{\frac{2}{3}} = a^{2 + \frac{2}{3}} = a^{\frac{8}{3}};$
> > （2） $\sqrt{a\sqrt[3]{a}} = (a a^{\frac{1}{3}})^{\frac{1}{2}} = (a^{\frac{4}{3}})^{\frac{1}{2}} = a^{\frac{2}{3}}.$
