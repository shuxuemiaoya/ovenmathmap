# 习题5.1 拓广探索 第10题

（1）假设这把扇子是从一个圆面中剪下的，而剩余部分的面积为 $S_{2}$ ，求 $S_{1}$ 与 $S_{2}$ 的比值；

（2）要使 $S_{1}$ 与 $S_{2}$ 的比值为0.618，则扇子的圆心角应为几度（精确到 $1^{\circ}$ ）？
