2. 解下列不等式，并把它们的解集分别表示在数轴上：

(1) $2x + 3 < -1$ ;

(2) $-2x + 1 < x + 4$ ;

(3) $2(-3 + x) - 3(x + 2) < 0$ ;

(4) $\frac{x}{2} \geqslant 1 + \frac{x - 1}{3}$ ;

(5) $\frac{2x + 1}{3} \leqslant -\frac{x + 5}{2}$ ;

(6) $x+\frac{x}{2}+\frac{x}{3}>11;$

(7) $\frac{7x + 5}{7} - 2 > 2(x + 1)$ ;

$$
\frac {1 + 2 x}{4} - \frac {1 - 3 x}{10} > - \frac {1}{5} 。 \tag {8}
$$
