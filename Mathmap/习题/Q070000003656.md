(1) 求 C 的方程;

(2)作曲线 $y=\ln x$ 在 $x=x_{0}$ 处的切线 l.

(i) 若 $x_{0}=1$ ，l 与 C 相交于 A，B 两点，P 是 C 上任意一点，求 $\triangle ABP$ 面积的最大值；

(ii) 当 $0 < x_{0} < \sqrt{2}$ 时，证明 l 与 C 有两个公共点.
