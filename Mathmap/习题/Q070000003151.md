4. 解方程:

(1) $\frac{1}{x - 1} = \frac{1}{x^2 - 1}$ ;

(2) $\frac{1}{x - 2} + 3 = \frac{x - 1}{x - 2}$ ;

(3) $\frac{2 - x}{3 + x} = \frac{1}{2} + \frac{1}{x + 3}$ 。
