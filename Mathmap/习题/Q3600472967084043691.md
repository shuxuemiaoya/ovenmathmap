# 习题1.2 复习巩固 第2题

2. 指出下列各集合之间的关系，并用 Venn 图表示：

$A = \{x \mid x \text{ 是四边形}\}$，$B = \{x \mid x \text{ 是平行四边形}\}$，$C = \{x \mid x \text{ 是矩形}\}$，$D = \{x \mid x \text{ 是正方形}\}$.

![](attachments/c1/c17a4a856353f076bb20a353a1fd0f537fc61a048be9d83405d46ee7896a0efd.jpg)

> [!success]- 答案与解析
>
> > [!success] **【答案】** $D \subsetneqq C \subsetneqq B \subsetneqq A$
>
> > [!note]- **【解析】**
> > 正方形是特殊的矩形，矩形是特殊的平行四边形，平行四边形是特殊的四边形，因此各集合之间的关系为 $D \subsetneqq C \subsetneqq B \subsetneqq A$. 用 Venn 图表示时，由内到外依次为封闭曲线 $D, C, B, A$ 逐层包含.
