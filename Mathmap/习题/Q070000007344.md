4. 已知实数 $a, b, c$ 满足 $c - b = a + \frac{2}{a} - 2, c + b = 2a^2 + 2a + \frac{2}{a}$ , 且 $a > 0$ , 则 $a, b, c$ 的大小关系是 ( ) A. $b > c > a$ B. $c > b > a$ C. $a > c > b$ D. $c > a > b$
