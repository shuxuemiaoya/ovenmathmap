# 习题5.2 综合运用 第14题

14. 求证：

(1) $\frac{1 - 2\sin x\cos x}{\cos^2x - \sin^2x} = \frac{1 - \tan x}{1 + \tan x};$

(2) $\tan^2\alpha - \sin^2\alpha = \tan^2\alpha \sin^2\alpha$ ;

(3) $(\cos \beta - 1)^2 + \sin^2\beta = 2 - 2\cos \beta;$

(4) $\sin^4 x + \cos^4 x = 1 - 2\sin^2 x\cos^2 x.$
