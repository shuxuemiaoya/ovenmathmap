6. (多选)已知关于 $x$ 的不等式 $a(x - 1)(x + 3) + 2 > 0$ 的解集是 $\{x \mid x_1 < x < x_2\}$ , 其中 $x_1 < x_2$ , 则下列结论中正确的是 ( )
A. $x_1 + x_2 + 2 = 0$ B. $-3 < x_1 < x_2 < 1$ C. $|x_1 - x_2| > 4$ D. $x_1x_2 + 3 < 0$

最慢的脚步不是跬步而是徘徊，最快的脚步不是冲刺而是坚持。
