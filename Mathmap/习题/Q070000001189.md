例 3 已知圆心为 C 的圆经过 A(1, 1)，B(2, -2) 两点，且圆心 C 在直线 l：x - y + 1 = 0 上，求此圆的标准方程.

分析：设圆心 C 的坐标为 $(a, b)$ 。由已知条件可知， $|CA| = |CB|$ ，且 $a - b + 1 = 0$ 。由此可求出圆心坐标和半径。

另外，因为线段 $AB$ 是圆的一条弦，根据平面几何知识， $AB$ 的中点与圆心 $C$ 的连线垂直于 $AB$ ，由此可得到另一种解法。
