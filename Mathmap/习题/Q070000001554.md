例 5 日常生活中的饮用水通常是经过净化的．随着水的纯净度的提高，所需净化费用不断增加．已知将 1 t 水净化到纯净度为 $x\%$ 时所需费用（单位：元）为

$$
c (x) = \frac {5 2 8 4}{1 0 0 - x} (8 0 <   x <   1 0 0).
$$

求净化到下列纯净度时，所需净化费用的瞬时变化率：

(1) 90%; (2) 98%.
