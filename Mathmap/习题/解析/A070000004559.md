# 例 3 用分数指数幂表示并化简根式·解析

对应题目：[例 3 用分数指数幂表示并化简根式](../Q070000008593.md)

解：（1） $a^2\cdot \sqrt[3]{a^2} = a^2 a^{\frac{2}{3}} = a^{2 + \frac{2}{3}} = a^{\frac{8}{3}};$

(2) $\sqrt{a\sqrt[3]{a}} = (a a^{\frac{1}{3}})^{\frac{1}{2}} = (a^{\frac{4}{3}})^{\frac{1}{2}} = a^{\frac{2}{3}}.$
