> [!faq]- 2026版 必刷题 数学选择性必修第一册RJA
> **【答案】** ABD
>
> **【解析】**
> 因为正切函数 $y = \tan x$ 在 $\left(0,\frac{\pi}{2}\right)$ 上单调递增，在 $\left(\frac{\pi}{2},\pi\right)$ 上也单调递增，分以下四种情况讨论：当 $0 < k_{1} < k_{2} < k_{3}$ 时，则 $\alpha ,\beta ,\gamma$ 均为锐角，且 $\alpha < \beta < \gamma$ 当 $k_{1} < 0 < k_{2} < k_{3}$ 时，则 $\alpha$ 为钝角， $\beta ,\gamma$ 均为锐角，且 $\beta < \gamma < \alpha$ 当 $k_{1} < k_{2} < 0 < k_{3}$ 时，则 $\alpha ,\beta$ 均为钝角， $\gamma$ 为锐角，且 $\gamma < \alpha < \beta$ 当 $k_{1} < k_{2} < k_{3} < 0$ 时，则 $\alpha ,\beta ,\gamma$ 均为钝角，且 $\alpha < \beta < \gamma .$ 故选ABD.
