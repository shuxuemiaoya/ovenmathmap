> [!faq]- 2026版 高中必刷题数学必修第一册
> **【解析】**
> 充分不必要 【解析】由 $p: \frac{1}{x} > 1$ ，得 $p: 0 < x < 1$ ，由 $q: |x - 1| < 1$ ，得 $q: 0 < x < 2$ .
> 显然由 p 可以推出 q，由 q 推不出 p，
> 所以 p 是 q 的充分不必要条件.
