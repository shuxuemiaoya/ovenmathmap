> [!faq]- 必刷题解析
> **【答案】** D
>
> **【解析】**
> 由 a, b, c 都不小于 1，得 $a \geqslant 1$ ， $b \geqslant 1, c \geqslant 1$ ，即 a, b, c 都大于或等于 1，所以其否定是 a, b, c 不都大于或等于 1，即 a, b, c 中至少有一个小于 1，故 a < 1 或 b < 1 或 c < 1。
>
> 故选 **D**.
