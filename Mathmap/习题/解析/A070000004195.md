> [!faq]- 2027版 高中必刷题数学必修第一册RJA
>
> > [!success]- **【答案】** C
>
> > [!note]- **【解析】**
> > C【解析】当 $n = 2k(k\in \mathbf{Z})$ 时，原式 $= \frac{\sin(2k\pi + \alpha)}{\cos(2k\pi + \alpha)} = \frac{\sin\alpha}{\cos\alpha} = \tan \alpha .$ 当 $n = 2k + 1 (k\in \mathbf{Z})$ 时，原式 $= \frac{\sin(2k\pi + \pi + \alpha)}{\cos(2k\pi + \pi + \alpha)} = \frac{\sin(\pi + \alpha)}{\cos(\pi + \alpha)} = \frac{-\sin\alpha}{-\cos\alpha} =$ tan $\alpha$
> >
> > 综上, 原式= $\tan\alpha$ . 故选 C.
> >
