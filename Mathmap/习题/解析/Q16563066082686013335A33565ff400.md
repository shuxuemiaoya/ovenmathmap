# 例 3 运动会参赛同学集合的交集与并集应用·解析

对应题目：[例 3 运动会参赛同学集合的交集与并集应用](../Q16563066082686013335.md)

解： $A \cap B$ 就是立德中学高一年级中那些既参加百米赛跑又参加跳高比赛的同学组成的集合．所以，

$A \cap B = \{ x \mid x  是立德中学高一年级既参加百米赛跑又参加跳高比赛的同学 \} .$
