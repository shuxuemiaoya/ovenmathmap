$$
R = \left\{ \begin{array}{l l} 4 0 0 x - \frac {1}{2} x ^ {2}, & 0 \leqslant x \leqslant 4 0 0, \\ 8 0 0 0 0, & x > 4 0 0. \end{array} \right.
$$

(1) 将利润 P (单位：元) 表示为月产量 x 的函数；

（2）当月产量为何值时，公司所获利润最大？最大利润为多少元？（总收入 $=$ 总成本 $+$ 利润）
