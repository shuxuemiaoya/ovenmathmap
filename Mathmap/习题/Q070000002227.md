1. 解方程：

(1) $\frac{3 - x}{2} = \frac{x + 4}{3}$ ;

(2) $\frac{1}{3}(x + 1) = \frac{1}{7}(2x - 3)$ ;

(3) $\frac{x + 2}{5} = \frac{x}{4}$ ;

(4) $\frac{1}{4}(x + 1) = \frac{1}{3}(x - 1)$ ;

(5) $\frac{2x - 1}{3} = \frac{x + 2}{4} - 1$ ;

(6) $\frac{1}{2}(x - 1) = 2 - \frac{1}{5}(x + 2)$ 。
