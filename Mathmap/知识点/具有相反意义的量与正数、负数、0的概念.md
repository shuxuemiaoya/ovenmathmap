# 具有相反意义的量与正数、负数、0的概念

## 北师大版初中数学·七年级上册

“加分与扣分”“零上温度与零下温度”“高于海平面与低于海平面”“上涨量与下跌量”等都是具有相反意义的量。为了表示具有相反意义的量，我们可以把其中一个量规定为正的，把与这个量意义相反的量规定为负的，并分别用“+”“-”来表示。例如，“加3分”记为+3分，“扣2分”就记为-2分。

像 +3, +15, +2.4%, …都是正数，正数前面的“+”可以省略不写。

像 -2, -8, -0.5%, …都是负数。

0 既不是正数，也不是负数。

负数与对应的正数在数量上相等，表示的意义相反。
