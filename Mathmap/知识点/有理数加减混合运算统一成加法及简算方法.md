## 知识讲解

### 北师大版初中数学·七年级上册

有理数的加减混合运算可以统一成加法运算，如算式“4.5 - 3.2 + 1.1 - 1.4”可以看成4.5，-3.2，1.1，-1.4这4个数的和，因此在进行加减混合运算时可运用加法交换律和加法结合律简化运算。例如，

$4.5 - 3.2 + 1.1 - 1.4 = 4.5 + 1.1 - 3.2 - 1.4 = 5.6 - 4.6 = 1$ 。
