# 二次根式与被开方数的概念

## 北师大版初中数学·八年级上册

观察下列代数式:

$$
\sqrt {5}, \sqrt {11}, \sqrt {7.2}, \sqrt {\frac {49}{121}}, \sqrt {(c + b) (c - b)} (\text {其中} b = 24, c = 25) 。
$$

可以发现，这些式子我们在前面都已学习过，它们的共同特征是：都含有开方运算，并且被开方数都是非负数。

一般地，形如 $\sqrt{a} (a \geqslant 0)$ 的式子叫作二次根式，a 叫作被开方数。
