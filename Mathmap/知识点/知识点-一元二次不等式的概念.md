例如，园艺师打算在绿地上用长度为 $24 \mathrm{~m}$ 的栅栏围一个面积大于 $20 \mathrm{~m}^{2}$ 的矩形区域种植花卉。设这个矩形的一条边长为 $x \mathrm{~m}$ ，则另一条边长为 $(12 - x) \mathrm{~m}$ 。由题意，得

![](attachments/c0/c0dc84c636c3fc4e345f46f6d1c4d04b7e05aed45306a22c48a1e2a62d623a7d.jpg)

$$
(1 2 - x) x > 2 0,
$$

其中 $x \in \{x \mid 0 < x < 12\}$ . 整理得

$$
x ^ {2} - 1 2 x + 2 0 <   0, x \in \{x \mid 0 <   x <   1 2 \}.\tag{①}
$$

求得不等式①的解集，就得到了矩形边长的取值范围.

一般地，我们把只含有一个未知数，并且未知数的最高次数是2的不等式，称为[一元二次不等式](%E7%9F%A5%E8%AF%86%E7%82%B9-%E4%B8%80%E5%85%83%E4%BA%8C%E6%AC%A1%E4%B8%8D%E7%AD%89%E5%BC%8F%E7%9A%84%E6%A6%82%E5%BF%B5.md)（quadratic inequality with one unknown）。一元二次不等式的一般形式是

$$
a x ^ {2} + b x + c > 0 \text { 或 } a x ^ {2} + b x + c <   0,
$$

其中 $a, b, c$ 均为常数， $a \neq 0$ .
