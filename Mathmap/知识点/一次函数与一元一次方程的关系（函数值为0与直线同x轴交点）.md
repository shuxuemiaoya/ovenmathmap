learning_objective: "理解当一次函数 y=kx+b 函数值为 0 时自变量即为方程 kx+b=0 的解，在几何上等于直线与 x 轴交点的横坐标。"
---
一般地，当一次函数 $y = kx + b$ 的函数值为 0 时，相应的自变量的值就是方程 $kx + b = 0$ 的解。从图象上看，一次函数 $y = kx + b$ 的图象与 $x$ 轴交点的横坐标就是方程 $kx + b = 0$ 的解。
