# 思考·交流：互为相反数和为0与加正负数的和变化规律

## 北师大版初中数学·七年级上册

> [!question] 思考·交流
> (1) 根据有理数加法法则, 如果两个数互为相反数, 那么它们的和等于 0 。反过来, 如果两个数的和等于 0 , 那么这两个数互为相反数吗?
>
> (2) 根据有理数加法法则进行正数或 0 的运算, 得到的结果与小学数学中的加法运算结果一致吗?
>
> (3) 一个数加一个正数, 所得的和与这个数有怎样的大小关系? 一个数加一个负数呢? 与同伴进行交流。
