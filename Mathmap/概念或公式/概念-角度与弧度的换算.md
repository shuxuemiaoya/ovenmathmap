一般地，只需根据
$$
1 8 0 ^ {\circ} = \pi \text { rad } \quad \begin{array}{l} 1 ^ {\circ} = \frac {\pi}{1 8 0} \text { rad } \approx 0. 0 1 7 4 5 \text { rad } \\ 1 \text { rad } = \left(\frac {1 8 0}{\pi}\right) ^ {\circ} \approx 5 7. 3 0 ^ {\circ} \end{array}
$$
