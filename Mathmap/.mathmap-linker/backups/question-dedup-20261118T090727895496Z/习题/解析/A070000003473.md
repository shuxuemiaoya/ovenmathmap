> > A 【解析】因为 $M = \{x \mid x < 1\}$ , $N = \{x \mid -1 < x < 2\}$ , 所以 $M \cup N = \{x \mid x < 2\}$ , $\complement_U M = \{x \mid x \geqslant 1\}$ , $M \cap N = \{x \mid -1 < x < 1\}$ , $\complement_U N = \{x \mid x \leqslant -1$ 或 $x \geqslant 2\}$ , 所以 $\complement_U (M \cup N) = \{x \mid x \geqslant 2\}$ , $N \cup \complement_U M = \{x \mid x > -1\}$ , $\complement_U (M \cap N) = \{x \mid x \leqslant -1$ 或 $x \geqslant 1\}$ , $M \cup \complement_U N = \{x \mid x < 1$ 或 $x \geqslant 2\}$ ,
> >
