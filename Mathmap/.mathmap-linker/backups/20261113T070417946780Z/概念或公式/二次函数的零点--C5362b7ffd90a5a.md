# 二次函数的零点

一般地，对于二次函数 $y=ax^{2}+bx+c$ ，我们把使 $ax^{2}+bx+c=0$ 的实数 x 叫做二次函数 $y=ax^{2}+bx+c$ 的零点。于是，二次函数 $y=x^{2}-12x+20$ 的两个零点是 $x_{1}=2,\quad x_{2}=10$ 。
