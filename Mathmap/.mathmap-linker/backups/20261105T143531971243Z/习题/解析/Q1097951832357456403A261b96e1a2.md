# 例 1 把下列指数式化为对数式·解析

> 来源：人教A版高中数学·必修第一册

对应题目：[例 1 把下列指数式化为对数式](../Q1097951832357456403.md)

解：（1） $\log_5625 = 4$

(2) $\log_2\frac{1}{64} = -6;$

(3) $\log_{\frac{1}{3}} 5.73 = m$ ;

(4) $\left(\frac{1}{2}\right)^{-4} = 16;$

(5) $10^{-2} = 0.01$ ;

(6) $\mathrm{e}^n = 10$ .
