# 例 2 设集合 $A=\{x \mid·解析

> 来源：人教A版高中数学·必修第一册

对应题目：[例 2 设集合 $A=\{x \mid](../Q13439021260984025191.md)

解： $A\cup B = \{x\mid -1 <   x <   2\} \cup \{x\mid 1 <   x <   3\}$ $= \{x\mid -1 <   x <   3\} .$
