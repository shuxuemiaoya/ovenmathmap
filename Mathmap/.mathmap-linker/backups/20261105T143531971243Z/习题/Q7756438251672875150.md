# 习题1.2 综合运用 第3题

> 来源：人教A版高中数学·必修第一册

3. 举出下列各集合的一个子集：

(1) $A = \{x \mid x \text{ 是立德中学的学生}\}$；

(2) $B = \{x \mid x \text{ 是三角形}\}$；

(3) $C = \{0\}$；

(4) $D = \{x \in \mathbf{Z} \mid 3 < x < 30\}$.

> [!success]- 答案与解析
>
> > [!success] **【答案】** 详见解析（答案不唯一）
>
> > [!note]- **【解析】**
> > (1) $\{x \mid x \text{ 是立德中学高一（1）班的学生}\}$（或 $\varnothing$ 等）；
> > (2) $\{x \mid x \text{ 是等腰三角形}\}$（或 $\{x \mid x \text{ 是直角三角形}\}$ 等）；
> > (3) $\varnothing$（或 $\{0\}$）；
> > (4) $\{4, 5, 6\}$（或 $\{x \in \mathbf{Z} \mid 4 \leqslant x \leqslant 10\}$ 等）.
