# 习题1.2 综合运用 第4题

> 来源：人教A版高中数学·必修第一册

4. 在平面直角坐标系中，集合 $C = \{(x, y) \mid y = x\}$ 表示直线 $y = x$，从这个角度看，集合 $D = \left\{(x, y) \;\middle|\; \begin{cases} 2x - y = 1 \\ x + 4y = 5 \end{cases}\right\}$ 表示什么？集合 $C, D$ 之间有什么关系？

![](attachments/07/079bcea05efcea691a689aa5f3bc66b00b1ec138800c77744dc1ce188a6fb423.jpg)

5. (1) 设 $a, b \in \mathbf{R}$，$P = \{1, a\}$，$Q = \{-1, -b\}$，若 $P = Q$，求 $a - b$ 的值；

(2) 已知集合 $A = \{x \mid 0 < x < a\}$，$B = \{x \mid 1 < x < 2\}$，若 $B \subseteq A$，求实数 $a$ 的取值范围.

> [!success]- 答案与解析
>
> > [!success] **【答案】** 第 4 题：集合 $D$ 表示点 $(1, 1)$ 组成的集合，$D \subsetneqq C$；第 5 题：(1) $0$；(2) $a \geqslant 2$
>
> > [!note]- **【分析】**
> > 第 4 题通过解二元一次方程组求两条直线的交点坐标，再判断该点是否在直线 $y = x$ 上；第 5 题利用集合相等的元素对应关系及数轴端点比较确定参数.
>
> > [!note]- **【解析】**
> > **第 4 题：** 解方程组 $\begin{cases} 2x - y = 1 \\ x + 4y = 5 \end{cases}$ 得 $\begin{cases} x = 1 \\ y = 1 \end{cases}$，因此集合 $D = \{(1, 1)\}$，从几何角度看表示直线 $2x - y = 1$ 与直线 $x + 4y = 5$ 的交点 $(1, 1)$ 组成的单元素点集. 因为点 $(1, 1)$ 在直线 $y = x$ 上，即 $(1, 1) \in C$，所以 $D \subsetneqq C$（或 $D \subseteq C$）.
> > **第 5 题：**
> > (1) 由 $P = Q$，即 $\{1, a\} = \{-1, -b\}$，根据集合相等的定义可得 $\begin{cases} a = -1 \\ -b = 1 \end{cases}$，解得 $a = -1, b = -1$，故 $a - b = (-1) - (-1) = 0$.
> > (2) 因为 $B = \{x \mid 1 < x < 2\} \neq \varnothing$ 且 $B \subseteq A = \{x \mid 0 < x < a\}$，结合数轴可知右端点需满足 $a \geqslant 2$，故实数 $a$ 的取值范围是 $\{a \mid a \geqslant 2\}$（或 $a \geqslant 2$）.
>
> > [!tip]- **【总结】**
> > 利用数轴解决含参数的区间子集问题 $B \subseteq A$ 时，需先画数轴定大致位置，再单独检验端点处取等号时是否仍满足包含关系.
