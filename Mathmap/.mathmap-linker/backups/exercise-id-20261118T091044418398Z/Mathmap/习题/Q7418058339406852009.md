# 习题3.1 拓广探索 第15题

15. 如图所示，一座小岛距离海岸线上最近的点 $P$ 的距离是 $2\mathrm{km}$ ，从点 $P$ 沿海岸正东 $12\mathrm{km}$ 处有一个城镇.

（2）如果将船停在距点 $P4\mathrm{km}$ 处，那么从小岛到城镇要多长时间（精确到0.1h)?
