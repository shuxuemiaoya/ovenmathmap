# 例 1 找出0°~360°内终边相同的角并判定象限·解析

对应题目：[例 1 找出0°~360°内终边相同的角并判定象限](../Q6136159717902038643.md)

解： $-950^{\circ}12' = 129^{\circ}48' - 3 \times 360^{\circ}$ ，所以在 $0^{\circ} \sim 360^{\circ}$ 范围内，与 $-950^{\circ}12'$ 角终边相同的角是 $129^{\circ}48'$ ，它是第二象限角.
