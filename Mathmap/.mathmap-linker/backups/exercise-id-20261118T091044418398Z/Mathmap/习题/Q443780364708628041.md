# 例 2 判断命题中的必要条件

例2 下列“若 $p$ ，则 $q$ ”形式的命题中，哪些命题中的 $q$ 是 $p$ 的必要条件？

（1）若四边形为平行四边形，则这个四边形的两组对角分别相等；

（2）若两个三角形相似，则这两个三角形的三边成比例；

（3）若四边形的对角线互相垂直，则这个四边形是菱形；

(4) 若 x=1，则 $x^{2}=1$ ;

(5) 若 ac=bc，则 a=b；

(6) 若 $xy$ 为无理数，则 $x, y$ 为无理数.
