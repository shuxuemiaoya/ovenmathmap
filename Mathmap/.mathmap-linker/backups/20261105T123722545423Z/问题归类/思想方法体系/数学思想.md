# 数学思想

先识别问题的共同结构，再选择数形结合、化归、分类或建模等方向。

## 从什么思路找问题

- [类比与推广](%E6%95%B0%E5%AD%A6%E6%80%9D%E6%83%B3/%E7%B1%BB%E6%AF%94%E4%B8%8E%E6%8E%A8%E5%B9%BF.md)：借用已熟悉对象的研究路径，提出新对象的定义、性质和问题。（31 个问题）
- [数形结合](%E6%95%B0%E5%AD%A6%E6%80%9D%E6%83%B3/%E6%95%B0%E5%BD%A2%E7%BB%93%E5%90%88.md)：在图形、坐标与代数条件之间来回解释，使关系、变化和取值更清楚。（54 个问题）
- [转化与化归](%E6%95%B0%E5%AD%A6%E6%80%9D%E6%83%B3/%E8%BD%AC%E5%8C%96%E4%B8%8E%E5%8C%96%E5%BD%92.md)：保留目标与约束，把不熟悉的问题改写成已有定义、公式或已会处理的问题。（23 个问题）
- [分类讨论](%E6%95%B0%E5%AD%A6%E6%80%9D%E6%83%B3/%E5%88%86%E7%B1%BB%E8%AE%A8%E8%AE%BA.md)：当同一个结论随条件分支变化时，先分清情况再分别研究。（8 个问题）
- [函数与方程](%E6%95%B0%E5%AD%A6%E6%80%9D%E6%83%B3/%E5%87%BD%E6%95%B0%E4%B8%8E%E6%96%B9%E7%A8%8B.md)：把求解或不等式转成函数的零点、图象位置和取值变化问题。（6 个问题）
- [抽象与建模](%E6%95%B0%E5%AD%A6%E6%80%9D%E6%83%B3/%E6%8A%BD%E8%B1%A1%E4%B8%8E%E5%BB%BA%E6%A8%A1.md)：从具体对象或生活情境中选出必要的量、集合和关系，构建可研究的数学对象。（25 个问题）
