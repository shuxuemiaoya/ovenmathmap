# 思维模型启蒙

用输入与输出、条件网络、增长、对称、周期和逼近等框架理解陌生情境。

## 从什么思路找问题

- [输入—对应—输出](%E6%80%9D%E7%BB%B4%E6%A8%A1%E5%9E%8B%E5%90%AF%E8%92%99/%E8%BE%93%E5%85%A5%E2%80%94%E5%AF%B9%E5%BA%94%E2%80%94%E8%BE%93%E5%87%BA.md)：把函数理解为带有允许输入范围和确定规则的对应系统。（15 个问题）
- [对称、不变与等价](%E6%80%9D%E7%BB%B4%E6%A8%A1%E5%9E%8B%E5%90%AF%E8%92%99/%E5%AF%B9%E7%A7%B0%E3%80%81%E4%B8%8D%E5%8F%98%E4%B8%8E%E7%AD%89%E4%BB%B7.md)：寻找变化前后保持的结构，用已知部分理解另一部分。（23 个问题）
- [迭代逼近与误差控制](%E6%80%9D%E7%BB%B4%E6%A8%A1%E5%9E%8B%E5%90%AF%E8%92%99/%E8%BF%AD%E4%BB%A3%E9%80%BC%E8%BF%91%E4%B8%8E%E8%AF%AF%E5%B7%AE%E6%8E%A7%E5%88%B6.md)：用一连串可执行步骤逐步缩小不确定范围，在规定精度下得到近似。（3 个问题）
- [增长率与累积变化](%E6%80%9D%E7%BB%B4%E6%A8%A1%E5%9E%8B%E5%90%AF%E8%92%99/%E5%A2%9E%E9%95%BF%E7%8E%87%E4%B8%8E%E7%B4%AF%E7%A7%AF%E5%8F%98%E5%8C%96.md)：区分相同时间增加相同数量与按相同比例变化，研究多次变化的累积效果。（9 个问题）
- [周期重复与基本单元](%E6%80%9D%E7%BB%B4%E6%A8%A1%E5%9E%8B%E5%90%AF%E8%92%99/%E5%91%A8%E6%9C%9F%E9%87%8D%E5%A4%8D%E4%B8%8E%E5%9F%BA%E6%9C%AC%E5%8D%95%E5%85%83.md)：把重复现象先压缩到一个基本区间，再利用周期、相位和幅度扩展理解。（20 个问题）
- [条件网络与正反推理](%E6%80%9D%E7%BB%B4%E6%A8%A1%E5%9E%8B%E5%90%AF%E8%92%99/%E6%9D%A1%E4%BB%B6%E7%BD%91%E7%BB%9C%E4%B8%8E%E6%AD%A3%E5%8F%8D%E6%8E%A8%E7%90%86.md)：把定义、判定和性质放进有方向的条件网络，区分能推出、反向能否推出和互相等价。（10 个问题）
