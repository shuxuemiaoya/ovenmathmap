# 像 4 + 3(x - 1), x + x + (x + 1), m - 1, m + 5, {1}{an}, 2a

像 $4 + 3(x - 1), x + x + (x + 1), m - 1, m + 5, \frac{1}{an}, 2a + 10, (a - 1)^{3}, 6(a - 1)^{2}$ 等式子，它们都是用运算符号把数和字母连接而成的，这样的式子叫作[[代数式]]（algebraic expression）。单独一个数或一个字母也是代数式。

用具体数值代替代数式中的字母，就可以求出代数式的值。
