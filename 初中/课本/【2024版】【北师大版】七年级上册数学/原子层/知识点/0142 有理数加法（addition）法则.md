有理数加法（addition）法则

同号两数相加，取相同的符号，并把绝对值相加。

异号两数相加，绝对值相等时和为 0；绝对值不等时，取绝对值较大的数的符号，并用较大的绝对值减较小的绝对值。

一个数同 0 相加，仍得这个数。

计算：

(1) $180 + (-10)$ ;

(3) $5 + (-5)$ ;

(2) $(-10) + (-1)$ ;

解：（1） $180+(-10)$ $=+(180-10)$ =170;

(4) $0 + (-2)$ 。

(3) $5+(-5)=0;$

(2) $(-10) + (-1)$ $= -(10 + 1)$ $\circ$ $= -11;$

(4) $0 + (-2) = -2$ 。
