# 等式 10x + 15(45 - x) = 475, x(x + 25) = 5850, {22}{x} - {22

等式 $10x + 15(45 - x) = 475, x(x + 25) = 5850, \frac{22}{x} - \frac{22}{x + 1} = \frac{12}{60}$ , 都是用不同的代数式表示相等的量, 像这样含有未知数的表示量相等的等式称为[[方程]] (equation)。

在一个方程中，只含有一个未知数，且方程中的代数式都是整式，未知数的次数都是1，这样的方程叫作[[一元一次方程]]（linear equation with one unknown）。

如 $10x + 15(45 - x) = 475$ ， $2x + 3 = 7x + 4$ 都是一元一次方程。
