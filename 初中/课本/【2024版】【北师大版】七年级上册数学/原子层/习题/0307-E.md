5. 解方程：

(1) $\frac{7x - 5}{4} = \frac{3}{8}$ ;

(2) $\frac{2x - 1}{6} = \frac{5x + 1}{8}$ ;

(3) $\frac{1}{2} x - 7 = \frac{9x - 2}{6}$ ;

(4) $\frac{1}{5} x - \frac{1}{2}(3 - 2x) = 1$ ;

(5) $\frac{2x + 1}{3} - \frac{5x - 1}{6} = 1$ ;

(6) $\frac{1}{7}(2x + 14) = 4 - 2x$ 。
