# 相反数

像 3 与 -3, $\frac{3}{2}$ 与 $-\frac{3}{2}$ , 5 与 -5 这样的两个数, 它们的符号不同, 数量相等。我们称其中一个数为另一个数的相反数 (opposite number), 也称这两个数互为相反数。特别地, 0 的相反数是 0。
