# 多项式的次数

在多项式中, 每个单项式叫作多项式的项 (term), 如多项式 $10 x + 5 y$ 是 $10 x$ 与 $5 y$ 两项的和。一个多项式中, 次数最高的项的次数, 叫作这个多项式的次数。如 $10 x + 5 y$ 是 1 次的, $a^2 b + 2 a$ 是 3 次的。
