# 例4 解方程－ {1}{4} x = -{1}{2} x + 3 。

例4 解方程: $\frac{1}{4} x = -\frac{1}{2} x + 3$ 。

解：移项，得

$$
\frac {1}{4} x + \frac {1}{2} x = 3 _ {\circ}
$$

合并同类项，得

$$
\frac {3}{4} x = 3 _ {\circ}
$$

方程的两边都除以 $\frac{3}{4}$ , 得 $x = 4$ 。
