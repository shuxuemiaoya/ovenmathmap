# 例2 求下列各数的相反数和绝对值－

例2 求下列各数的相反数和绝对值:

$$
- 2, \frac {4}{9}, 0, - 3. 8, 3 0 _ {\circ}
$$

解：-2， $\frac{4}{9}$ ，0，-3.8，30的相反数分别是

$$
2, - \frac {4}{9}, 0, 3. 8, - 3 0;
$$

$a$ 的相反数为
\_\_\_\_。

$$
\vert - 2 \vert = 2, \left| \frac {4}{9} \right| = \frac {4}{9}, \vert 0 \vert = 0, \vert - 3. 8 \vert = 3. 8, \vert 3 0 \vert = 3 0 。
$$
