3. 求下列各式的值：

(1) $\sqrt{49}$ ;

(2) $\sqrt{\frac{25}{196}}$ ;

(3) $\sqrt{0.09}$ ;

(4) $-\sqrt{64}$ ;

(5) $\sqrt{4^{2}}$ ;

(6) $\sqrt{(-4)^{2}}$ ;

(7) $(\sqrt{0.8})^{2}$ ;

(8) $(- \sqrt{0.8})^{2}$ ;

(9) $\sqrt[3]{8}$ ;

(10) $\sqrt[3]{(-3)^{3}}$ ;

(11) $(\sqrt[3]{125})^{3}$ ;

(12) $-\sqrt[3]{27}$ 。
