2. 把下列各式因式分解：

(1) $9 - 12t + 4t^{2}$ ;

(2) $y^{2} + y + \frac{1}{4}$ ;

(3) $25m^{2} - 80m + 64$ ;

(4) $(x + y)^{2} + 6(x + y) + 9$ ;

(5) $a^{2} - 2a(b + c) + (b + c)^{2}$ ;

(6) $-a + 2a^{2} - a^{3}$ 。
