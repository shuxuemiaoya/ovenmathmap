2. 计算：

(1) $\frac{m - 1}{x} + \frac{n - m}{x}$ ;

(2) $\frac{3}{mn} - \frac{5}{nm}$ ;

(3) $\frac{a^2}{a + b} + \frac{b^2 + 2ab}{a + b}$ ;

(4) $\frac{x + 2y}{2x - y} - \frac{3y - x}{2x - y}$ ;

(5) $\frac{2n - m}{m - n} + \frac{n}{n - m}$ ;

(6) $\frac{x^2 + 5}{x - 2} - \frac{1 + 4x}{2 - x}$ 。
