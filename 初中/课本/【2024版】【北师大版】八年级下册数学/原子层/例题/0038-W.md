例3 计算：

(1) $\frac{a + b}{ab} + \frac{a - b}{ab}$ ;

(2) $\frac{x^2}{x - 2} - \frac{4}{x - 2}$ 。

> [!success]- 例题解析
>
> > [!success] **【答案】** 详见解析
>
> > [!note]- **【解析】**
> > 解：(1) $\frac{a + b}{ab} +\frac{a - b}{ab} = \frac{a + b + a - b}{ab} = \frac{2a}{ab} = \frac{2}{b};$
> >
> > (2) $\frac{x^2}{x - 2} - \frac{4}{x - 2} = \frac{x^2 - 4}{x - 2} = \frac{(x - 2)(x + 2)}{x - 2} = x + 2$ 。
