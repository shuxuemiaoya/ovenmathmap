例1 利用平方差公式计算：

(1) $(5 + 6x)(5 - 6x)$ ;

(2) $(x - 2y)(x + 2y)$ ;

(3) $(-m + n)(-m - n)$ 。

> [!success]- 例题解析
>
> > [!success] **【答案】** 详见解析
>
> > [!note]- **【解析】**
> > 解：(1) $(5+6x)(5-6x)=5^{2}-(6x)^{2}=25-36x^{2}$ ;
> >
> > (2) $(x - 2y)(x + 2y) = x^{2} - (2y)^{2} = x^{2} - 4y^{2}$ ;
> >
> > (3) $(-m + n)(-m - n) = (-m)^2 - n^2 = m^2 - n^2$ 。
