> > [!success] **【答案】** ①②③
>
> > [!note]- **【解析】**
> > ∵ 四边形 ABCD、四边形 GMNO 是正方形，∴ OA = OB, ∠AOB = ∠GON = 90°, ∠BAO = ∠CBO = 45°, ∴ ∠AOE + ∠BOE = ∠BOF + ∠BOE, ∴ ∠AOE = ∠BOF, ∴ △AOE ≅ △BOF (ASA), ∴ OE = OF, AE = BF, S△AOE = S△BOF, ∴ S△AOE + S△CFO = S△BOF + S△CFO = S△BOC = $\frac{1}{4} a^2$ ，故①②正确。∵ 四边形 EOFB 的周长为 OE + OF + BF + BE = 2OE + AE + BE = 2OE + AB = 2OE + a, ∴ 当 OE ⊥ AB，旋转角 α° = 45° 时，OE 的值最小，即四边形 EOFB 周长最小，此时，OE = $\frac{1}{2} a$ ，∴ 四边形 EOFB 周长的最小值为 $2 \times \frac{1}{2} a + a = 2a$ ，故③正确。故答案为①②③。
