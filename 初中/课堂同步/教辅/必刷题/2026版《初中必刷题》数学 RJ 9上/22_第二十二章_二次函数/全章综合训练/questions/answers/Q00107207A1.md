> [!success]- 必刷题
>
> > [!success] **【答案】** $>, -\frac{1}{2} < m < 1$
>
> > [!note]- **【解析】**
> > ∵ $y=-x^{2}+4x-1=$ $-(x-2)^{2}+3,\therefore$ 二次函数 $y=-x^{2}+4x-1$ 图象的对称轴为直线 x=2，开口向下。∵ $0<x_{1}<1, x_{2}>4, \therefore 2-x_{1}<x_{2}-2$ ，即 $A(x_{1},y_{1})$ 比 $B(x_{2},y_{2})$ 离对称轴的水平距离近，∴ $y_{1}>y_{2}$ 。∵ $m<x_{1}<m+1$ ， $m+1<x_{2}<m+2$ ， $m+2<x_{3}<m+3$ ，∴ $x_{1}<x_{2}<x_{3}$ 。
> >
> > 思路分析
> > 设矩形菜地在射线 OA 上的边长为 x m.
> > 分两种情况进行讨论：当 $x \leqslant 8$ 时和当 x > 8 时，分别求出最大面积，再进行比较即可.
> >
> > 对于 $m < x_{1} < m + 1, m + 1 < x_{2} < m + 2, m + 2 < x_{3} < m + 3$ ，存在 $y_{1} < y_{3} < y_{2}, \therefore x_{1} < 2, x_{3} > 2$ ，且 $A(x_{1}, y_{1})$ 离对称轴最远， $B(x_{2}, y_{2})$ 离对称轴最近， $\therefore 2 - x_{1} > x_{3} - 2 > |x_{2} - 2|$ ， $\therefore x_{1} + x_{3} < 4$ ，且 $x_{2} + x_{3} > 4$ 。 $\because 2m + 2 < x_{1} + x_{3} < 2m + 4, 2m + 3 < x_{2} + x_{3} < 2m + 5, \therefore 2m + 2 < 4$ ，且 $2m + 5 > 4$ ，解得 $-\frac{1}{2} < m < 1$ 。故答案为 $>, -\frac{1}{2} < m < 1$ 。
