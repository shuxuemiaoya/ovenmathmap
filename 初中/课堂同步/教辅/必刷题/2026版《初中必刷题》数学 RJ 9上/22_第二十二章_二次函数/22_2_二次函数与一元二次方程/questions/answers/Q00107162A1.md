> [!success]- 必刷题
>
> > [!success] **【答案】** x = -1 或 3
>
> > [!note]- **【解析】**
> > (1) 由 $ax^{2} + (b - 1)x + c = 0$ ，得 $ax^{2} + bx + c = x$ ，结合表格可知抛物线 $y = ax^{2} + bx + c$ 与直线 y = x 的交点为 $(-1, -1)$ 和 $(3, 3)$ ，且直线 y = x 与抛物线最多有两个交点，∴ 方程 $ax^{2} + bx + c = x$ 的根是 x = -1 或 3。故答案为 x = -1 或 3。
> > (2) 根据表格可知抛物线的对称轴是直线 $x = \frac{0 + 3}{2} = \frac{3}{2}$ ，当 $x < \frac{3}{2}$ 时，函数值 y 随着 x 的增大而增大，∴ 抛物线开口向下。令 $\frac{-1 + x}{2} = \frac{3}{2}$ ，解得 x = 4，可知当 x = -1 和 x = 4 时，y = -1。
> > ∴ 当 -1 < x < 4 时， $ax^{2} + bx + c > -1$ 。故答案为 -1 < x < 4。
