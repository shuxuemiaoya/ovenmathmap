> [!success]- 必刷题
>
> > [!success] **【答案】** C
>
> > [!note]- **【解析】**
> > ∵ PA, PB 分别切 $\odot O$ 于点 A, B, CD 切 $\odot O$ 于点 E, ∴ PA = PB = 8, AC = EC, BD = ED, ∴ PC + CD + PD = PC + CE + DE + PD = PC + AC + PD + BD = PA + PB = 8 + 8 = 16, 即 $\triangle PCD$ 的周长为 16. 故选 C.
> >
> > 关键点按认真阅读材料,类比材料中等积法求内切圆半径公式是解此类题的关键.
