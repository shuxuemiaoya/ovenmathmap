> [!success]- 必刷题
>
> > [!success] **【答案】** $1 \leqslant n < 10$
>
> > [!note]- **【解析】**
> > ∵ $y = x^{2} + 2x + 2 = (x + 1)^{2} + 1$ ，∴ 二次函数 $y = x^{2} + 2x + 2$ 的图象开口向上，顶点坐标为 $(-1, 1)$ ，对称轴是直线 x = -1。∵ 以 P 为圆心，2 为半径的圆与 y 轴相交，∴ $P(m, n)$ 到 y 轴的距离小于 2，∴ -2 < m < 2。当 x = -2 时， $y = (-2 + 1)^{2} + 1 = 2$ ；当 x = 2 时， $y = (2 + 1)^{2} + 1 = 10$ ；当 x = -1 时，y = 1，∴ n 的取值范围是 $1 \leqslant n < 10$ 。故答案为 $1 \leqslant n < 10$ 。
