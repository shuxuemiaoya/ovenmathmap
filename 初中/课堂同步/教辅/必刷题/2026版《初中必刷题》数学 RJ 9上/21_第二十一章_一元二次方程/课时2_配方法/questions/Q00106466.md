6 求最值 [2025 山西吕梁质检, 中] 阅读材料: 配方法不仅能够帮助我们解一元二次方程, 还能用来解决最大值、最小值问题, 例如: 求代数式 $2x^{2} - x + 2 + y^{2}$ 的最小值. 过程如下：原式 $= 2\left(x^{2} - \frac{1}{2} x\right) + 2 + y^{2} = 2\left(x^{2} - \frac{1}{2} x + \frac{1}{16} - \frac{1}{16}\right) + 2 + y^{2} = 2\left(x^{2} - \frac{1}{2} x + \frac{1}{16}\right) - \frac{1}{8} + 2 + y^{2} = 2\left(x - \frac{1}{4}\right)^{2} + y^{2} + \frac{15}{8}.$ $\because 2\left(x - \frac{1}{4}\right)^{2} \geqslant 0, y^{2} \geqslant 0,$ $\therefore 2\left(x - \frac{1}{4}\right)^{2} + y^{2} + \frac{15}{8} \geqslant \frac{15}{8}, \therefore 2x^{2} - x + 2 + y^{2}$ 的最小值是 $\frac{15}{8}$ .

根据材料,解答下列问题.

(1) $-x^{2}+4x-1$ 的最大值为\_\_\_\_；

(2) $m^{2}+n^{2}+6m-4n+15$ 的最小值为 \_\_\_\_.
