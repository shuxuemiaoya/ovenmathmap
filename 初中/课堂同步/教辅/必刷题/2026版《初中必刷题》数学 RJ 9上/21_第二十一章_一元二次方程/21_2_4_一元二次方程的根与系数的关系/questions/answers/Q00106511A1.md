> [!success]- 必刷题
>
> > [!success] **【答案】** 18
>
> > [!note]- **【解析】**
> > ∵ a 与 b 是一元二次方程 $ax^{2} + bx + c = 0$ 的两个根，∴ $a + b = -\frac{b}{a}$ ， $ab = \frac{c}{a}$ ，∴ $a^{2} + ab = -b$ ，∴ $b = -\frac{a^{2}}{a + 1} = \frac{-a^{2} - 1 + 1}{a + 1} = -\frac{(a + 1)(a - 1)}{a + 1} - \frac{1}{a + 1} = -a + 1 - \frac{1}{a + 1}$ 。∵ b 为整数，∴ $a + 1 = 1$ 或 $a + 1 = -1$ ，∴ a = 0（舍去）或 a = -2，∴ b = 4，∴ ab = -8 = $\frac{c}{-2}$ ，∴ c = 16，∴ $a + b + c = 18$ ，故答案为 18。
