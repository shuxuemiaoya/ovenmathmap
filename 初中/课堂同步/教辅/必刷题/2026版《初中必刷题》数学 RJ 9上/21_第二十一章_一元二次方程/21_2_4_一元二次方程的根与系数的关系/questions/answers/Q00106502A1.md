> [!success]- 必刷题
>
> > [!success] **【答案】** 23
>
> > [!note]- **【解析】**
> > ∵ m, n 是不为 0 的实数，∴ 由 $m + \frac{1}{m} = 5, n + \frac{1}{n} = 5$ ，得 $m^{2} - 5m + 1 = 0, n^{2} - 5n + 1 = 0$ 。又∵ $m \neq n$ ，∴ m, n 为一元二次方程 $x^{2} - 5x + 1 = 0$ 的两个不相等的实数根，∴ $m + n = -\frac{-5}{1} =$
> >
> > $5, mn = 1, \therefore \frac{n}{m} + \frac{m}{n} = \frac{n^2 + m^2}{mn} = \frac{(m + n)^2 - 2mn}{mn} = \frac{25 - 2}{1} = 23.$
