> > 【解】不正确. 正确的解题过程如下:
> > - **①**：+②, 得 $2a + 2c = 6$ , 即 $a + c = 3$ . ④
> > - **③**：-①×2, 得 $2a - c = 0$ . ⑤
> > 联立④⑤, 得方程组 $\left\{ \begin{array}{l} a + c = 3, \\ 2a - c = 0. \end{array} \right.$ 解这个二元一次方程组, 得 $\left\{ \begin{array}{l} a = 1, \\ c = 2. \end{array} \right.$ 把 $\left\{ \begin{array}{l} a = 1, \\ c = 2 \end{array} \right.$ 代入①, 得 $b = -2$ . 所以原方程组的解为 $\left\{ \begin{array}{l} a = 1, \\ b = -2, \\ c = 2. \end{array} \right.$
