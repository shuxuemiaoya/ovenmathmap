> > [!note]- **【解析】**
> > 【解】(1) 原式 = $\sqrt{3 + 2\sqrt{6} + 2} = \sqrt{(\sqrt{3})^{2} + 2\sqrt{3} \times \sqrt{2} + (\sqrt{2})^{2}} = \sqrt{(\sqrt{3} + \sqrt{2})^{2}} = \sqrt{3} + \sqrt{2}.$ (2) 原式 = $\sqrt{4 - 4\sqrt{3} + 3} = \sqrt{2^{2} - 2 \times 2\sqrt{3} + (\sqrt{3})^{2}} = \sqrt{(2 - \sqrt{3})^{2}} = 2 - \sqrt{3}.$ (3) 因为 $\sqrt{a^{2} + 4\sqrt{5}} = b + \sqrt{5}$ ，所以 $a^{2} + 4\sqrt{5} = b^{2} + 2\sqrt{5}b + 5.$ 因为 a, b 都是整数，所以 $4\sqrt{5} = 2\sqrt{5}b$ ，解得 b = 2，所以 $a^{2} + 4\sqrt{5} = 2^{2} + 2\sqrt{5} \times 2 + 5$ ，解得 $a = \pm 3.$
