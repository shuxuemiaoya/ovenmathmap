> [!success]- 必刷题
>
> > [!success] **【答案】** 详见解析
>
> > [!note]- **【解析】**
> > 【解】因为 $\frac{2\sqrt{3} - \sqrt{11}}{3\sqrt{2}} = \frac{1}{3\sqrt{2}(2\sqrt{3} + \sqrt{11})} = 1$ $\frac{1}{6\sqrt{6} + 3\sqrt{22}} = \frac{1}{6\sqrt{6} + \sqrt{198}}, \frac{3\sqrt{2} - \sqrt{17}}{2\sqrt{3}} = \frac{1}{2\sqrt{3}(3\sqrt{2} + \sqrt{17})} = \frac{1}{6\sqrt{6} + 2\sqrt{51}} = \frac{1}{6\sqrt{6} + \sqrt{204}}, \frac{1}{6\sqrt{6} + \sqrt{198}} > \frac{1}{6\sqrt{6} + \sqrt{204}}, \text{所以} \frac{2\sqrt{3} - \sqrt{11}}{3\sqrt{2}} > \frac{3\sqrt{2} - \sqrt{17}}{2\sqrt{3}}.$
> >
> > 关键点拨分子、分母同乘一个式子，将分子有理化为1是解题关键.
> >
> > 大招解读 | 取倒数法
> > 设 a, b 为两个大于 0 的实数, 先分别求出 a 与 b 的倒数, 再根据“当 $\frac{1}{a} < \frac{1}{b}$ 时, a > b; 当 $\frac{1}{a} = \frac{1}{b}$ 时, a = b; 当 $\frac{1}{a} > \frac{1}{b}$ 时, a < b”来比较 a 与 b 的大小.
