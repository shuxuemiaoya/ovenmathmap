> > [!note]- **【解析】**
> > 【解】(1)小明测试的平均成绩为 $\frac{1}{5} \times (80 + 85 + 82 + 85 + 83) = 83$ (分), 小红测试的平均成绩为 $\frac{1}{5} \times (88 + 79 + 90 + 81 + 72) = 82$ (分). (2) $s_{\text {小明}}^{2} = \frac{1}{5} \times [(80 - 83)^{2} + 2 \times (85 - 83)^{2} + (82 - 83)^{2} + (83 - 83)^{2}] = \frac{18}{5}, s_{\text {小红}}^{2} = \frac{1}{5} \times [(88 - 82)^{2} + (79 - 82)^{2} + (90 - 82)^{2} + (81 - 82)^{2} + (72 - 82)^{2}] = 42.$
