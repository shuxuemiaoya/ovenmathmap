> [!success]- 必刷题
>
> > [!success] **【答案】** C
>
> > [!note]- **【解析】**
> > 因为一组数据 $a_{1}, a_{2}, \cdots, a_{n}$ 的平均数为 2，所以 $\frac{a_{1} + a_{2} + \cdots + a_{n}}{n} = 2$ ，所以 $3a_{1} + 2, 3a_{2} + 2, \cdots, 3a_{n} + 2$ 的平均数是 $\frac{3a_{1} + 2 + 3a_{2} + 2 + \cdots + 3a_{n} + 2}{n} = 3 \times 2 + 2 = 8$ 。
> >
> > 故选 **C**.
