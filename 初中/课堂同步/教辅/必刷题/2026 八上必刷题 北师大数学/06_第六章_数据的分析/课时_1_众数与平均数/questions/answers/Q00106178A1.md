> > [!note]- **【解析】**
> > 这三个数的平均数为 $\frac{1}{3} [(x_1 + y_1 - z_1) + (x_2 + y_2 - z_2) + (x_3 + y_3 - z_3)] = \frac{1}{3} [(x_1 + x_2 + x_3) + (y_1 + y_2 + y_3) - (z_1 + z_2 + z_3)] = \frac{1}{3} (x_1 + x_2 + x_3) + \frac{1}{3} (y_1 + y_2 + y_3) - \frac{1}{3} (z_1 + z_2 + z_3) = a + b - c.$ 故选C.
