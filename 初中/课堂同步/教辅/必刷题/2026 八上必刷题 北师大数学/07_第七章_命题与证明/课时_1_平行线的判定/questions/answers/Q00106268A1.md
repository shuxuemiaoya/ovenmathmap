> > [!note]- **【解析】**
> > 【解】(1)AB 与 CD 平行. 理由如下: ∵ BE, DE 分别平分 ∠ABD, ∠BDC, ∴ ∠FBD = $\frac{1}{2}$ ∠ABD, ∠BDE = $\frac{1}{2}$ ∠BDC. ∵ ∠BED = 90°, ∴ ∠FBD + ∠BDE = 90°, ∴ ∠ABD + ∠BDC = 180°, ∴ AB // CD.
> >
> > (2) $\angle EFD + \angle BDE = 90^{\circ}$ . 理由如下： $\because DE$ 平分 $\angle BDC, \therefore \angle BDE = \angle FDE.$ $\because \angle BED = 90^{\circ} = \angle DEF,$ $\therefore \angle EFD + \angle FDE = 90^{\circ},$ $\therefore \angle EFD + \angle BDE = 90^{\circ}.$
