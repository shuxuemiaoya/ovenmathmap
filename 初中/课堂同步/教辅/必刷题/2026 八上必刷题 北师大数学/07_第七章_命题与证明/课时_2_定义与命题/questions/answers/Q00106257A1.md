>
> > [!success] **【答案】** (答案不唯一) -1 0
>
> > [!note]- **【解析】**
> > 当 $a = -1, b = 0$ 时, $-1 < 0, ab = 0, b^2 = 0, ab = b^2$ , 所以“若 $a < b$ , 则 $ab < b^2$ ”是假命题。(答案不唯一)
