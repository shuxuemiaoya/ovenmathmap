> > [!success] **【答案】** 详见解析
>
> > [!note]- **【解析】**
> > 【解】(1)∵AM∥BN, ∴∠ABN+∠A=180°,
> > ∴∠ABN = 180° - 60° = 120°, ∴∠ABP + ∠PBN = 120°. ∵BC 平分∠ABP, BD 平分
> > ∠PBN, ∴∠ABP = 2∠CBP, ∠PBN = 2∠DBP,
> > ∴2∠CBP+2∠DBP=120°,
> > ∴∠CBD = ∠CBP + ∠DBP = 60°.
> > (2)不变, ∠APB:∠ADB = 2:1.
> > ∵AM∥BN, ∴∠APB = ∠PBN, ∠ADB = ∠DBN.
> > ∵BD 平分∠PBN, ∴∠PBN = 2∠DBN,
> > ∴∠APB:∠ADB = 2:1.
> > (3)∵AM∥BN, ∴∠ACB = ∠CBN.
> > 当∠ACB = ∠ABD时,有∠CBN = ∠ABD,
> > ∴∠CBD + ∠DBN = ∠ABC + ∠CBD,
> > ∴∠DBN = ∠ABC.
> > 由(1)可知∠ABN = 120°, ∠CBD = 60°,
> > ∴∠ABC + ∠DBN = 60°, ∴∠ABC = 30°.
