>
> > [!note]- **【解析】**
> > 【证明】∵ DE∥BC, ∴ ∠C = ∠AED.
> > ∵ ∠EDF = ∠C, ∴ ∠AED = ∠EDF,
> >
> > $\therefore DF \parallel AC, \therefore \angle BDF = \angle A.$
> >
> > (2)【解】 $\triangle ABC$ 是等腰直角三角形. $\because \angle A = 45^{\circ}, \therefore \angle BDF = 45^{\circ} \because DF$ 平分 $\angle BDE, \therefore \angle BDE = 2\angle BDF = 90^{\circ} \because DE \parallel BC, \therefore \angle B = 90^{\circ}, \therefore \triangle ABC$ 是等腰直角三角形.
