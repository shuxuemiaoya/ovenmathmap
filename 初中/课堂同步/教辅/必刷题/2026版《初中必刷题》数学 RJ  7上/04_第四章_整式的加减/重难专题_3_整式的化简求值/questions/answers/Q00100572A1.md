> > [!note]- **【解析】**
> > 【解】(1)因为 $A = 2a^{2} + 3ab - 2a - 1, B = -a^{2} + ab + 2$ ，所以 $3A - (2A - 2B) = 3A - 2A + 2B = A + 2B = (2a^{2} + 3ab - 2a - 1) + 2(-a^{2} + ab + 2) = 2a^{2} + 3ab - 2a - 1 - 2a^{2} + 2ab + 4 = 5ab - 2a + 3.$ (2)因为 $(a + 5)^{2} + |b - 2| = 0$ ，所以 $a + 5 = 0, b - 2 = 0$ ，所以 $a = -5, b = 2$ ，所以 $3A - (2A - 2B) = 5ab - 2a + 3 = 5 \times (-5) \times 2 - 2 \times (-5) + 3 = -37.$
