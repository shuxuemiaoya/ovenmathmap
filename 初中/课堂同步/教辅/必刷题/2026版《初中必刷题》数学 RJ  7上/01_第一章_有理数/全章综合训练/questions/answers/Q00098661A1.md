> [!success]- 必刷题
>
> > [!success] **【答案】** D
>
> > [!note]- **【解析】**
> > 因为 a, c 异号, a < b < c, 所以 a < 0, c > 0. 又因为 $\vert c \vert < \vert b \vert < \vert a \vert$ , 所以 a < b < -c < 0 < c. 因为 $\vert x - a \vert + \vert x - b \vert + \vert x - (-c) \vert$ 表示在数轴上数 x 对应的点到 a, b, -c 三个数对应的点的距离之和, 而当 x = b 时, 其距离之和最小, 即 $\vert x - a \vert + \vert x - b \vert + \vert x - (-c) \vert$ 最小, 所以最小值是 a 与 -c 在数轴上对应的点之间的距离, 即 -c -a. 故选 D.
> >
> > 思路分析
> > 利用已知条件得到 a<b<-c<0<c，再利用绝对值的几何意义和数形结合的思想解答即可.
