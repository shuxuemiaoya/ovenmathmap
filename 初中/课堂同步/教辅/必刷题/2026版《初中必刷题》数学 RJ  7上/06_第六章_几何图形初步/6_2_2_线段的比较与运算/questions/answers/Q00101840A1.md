> [!success]- 必刷题
>
> > [!success] **【答案】** C
>
> > [!note]- **【解析】**
> > 因为 $AB + BC + CD = AD = a, AC + BD = AB + BC + BC + CD = AD + BC = a + 3$ ，所以所有线段的和为 $AB + BC + CD + AC + BD + AD = a + (a + 3) + a = 3a + 3 = 3(a + 1)$ 。因为 a 为整数，所以 $3(a + 1)$ 是 3 的倍数，所以 32 符合题意，故选 C。
> >
> > 根据题意得出所有线段的和为 $3(a + 1)$ 是解题关键.
