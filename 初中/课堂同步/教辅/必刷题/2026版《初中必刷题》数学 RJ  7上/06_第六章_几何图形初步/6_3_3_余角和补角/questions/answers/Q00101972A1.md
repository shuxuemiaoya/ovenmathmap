> > [!success] **【答案】** ①②③④
>
> > [!note]- **【解析】**
> > 因为 OD 平分 ∠AOC, OE 平分 ∠BOC, 所以 ∠COD = ∠AOD = $\frac{1}{2}$ ∠AOC, ∠COE = ∠BOE = $\frac{1}{2}$ ∠BOC, 所以 ∠DOE = ∠COD + ∠COE = $\frac{1}{2}$ (∠AOC + ∠BOC). 因为 ∠AOC + ∠BOC = 180°, 所以 ∠DOE = 90°, 故①正确. 因为 ∠AOE + ∠BOE = 180°, 所以 ∠AOE + ∠COE = 180°, 即 ∠AOE 与 ∠COE 互补, 故②正确. 因为 OC 平分 ∠BOD, 所以 ∠COD = $\frac{1}{2}$ ∠BOD. 因为 ∠BOD = 180° - ∠AOD, 所以 ∠COD = 90° - $\frac{1}{2}$ ∠AOD, 所以 ∠AOD = 90° - $\frac{1}{2}$ ∠AOD, 所以 ∠AOD = 60°, 所以 ∠AOE = ∠AOD + ∠DOE = 60° + 90° = 150°, 故③正确. 因为 ∠DOE = 90°, 所以 ∠COE = 90° - ∠COD, 所以 ∠BOE = 90° - ∠COD, 所以 ∠BOE + ∠COD = 90°, 所以 ∠COD 是 ∠BOE 的余角. 因为 ∠COD = $\frac{1}{2}$ ∠AOC, ∠AOC = ∠AOE - ∠COE, 所以 ∠COD = $\frac{1}{2}$ (∠AOE - ∠COE) = $\frac{1}{2}$ (∠AOE - ∠BOE), 即 ∠BOE 的余角可表示为 $\frac{1}{2}$ (∠AOE - ∠BOE), 故④正确. 综上所述, 正确的有①②③④. 故答案为①②③④.
