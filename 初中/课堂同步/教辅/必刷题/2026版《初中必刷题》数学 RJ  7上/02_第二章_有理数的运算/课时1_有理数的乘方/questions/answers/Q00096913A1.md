> [!success]- 必刷题
>
> > [!success] **【答案】** -1925
>
> > [!note]- **【解析】**
> > 因为 a, b, c 为整数, c < 0, 且满足 $\left|a\right| + 10b^{2} - 100c^{3} = 2024$ , $a + b + c$ 取最小值, 所以 c = -1, b = 0, 所以 $a = -(2024 + 100c^{3} - 10b^{2}) = -[2024 + 100 \times (-1)^{3} - 10 \times 0] = -1924$ , 所以 $a + b + c$ 的最小值为 $-1924 + 0 + (-1) = -1925$ . 故答案为 -1925.
