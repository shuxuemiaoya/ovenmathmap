> [!success]- 必刷题
>
> > [!success] **【答案】** D
>
> > [!note]- **【解析】**
> > 因为 $abcd < 0, a + b = 0, cd > 0$ ，所以 c, d 同号，a, b 异号，则 a, b 中有 1 个负数。若 c < 0, d < 0，则这四个数中负数的个数是 3；若 c > 0, d > 0，则这四个数中负数的个数是 1，所以这四个数中负数有 1 个或 3 个。
> >
> > 故选 **D**.
