> [!success]- 必刷题
>
> > [!success] **【答案】** D
>
> > [!note]- **【解析】**
> > ∵ 矩形纸片 ABCD 中, BC = 3, AB = 4, ∴ $\angle B = \angle A = \angle C = 90^{\circ}$ , BC = AD = 3, AB = DC = 4. 根据折叠可知 $\triangle DCP \cong \triangle DEP$ , ∴ DC = DE = 4, $\angle E = \angle C = 90^{\circ}$ , CP = EP,$\therefore \angle E = \angle B = 90^{\circ}$ . 在 $\triangle OBP$ 和 $\triangle OEF$ 中， $\left\{ \begin{array}{l} \angle B = \angle E, \\ \angle BOP = \angle EOF, \therefore \triangle OBP \cong \triangle OEF(AAS), \\ OP = OF, \end{array} \right.$ $\therefore EF = BP, OE = OB, \therefore BF = OB + OF = OE + OP = PE, \therefore BF = EP = CP.$ 设 $BF = EP = CP = x$ 则 $AF = 4 - x, BP = 3 - x = EF, \therefore DF = DE - EF = 4 - (3 - x) = x + 1.$ $\because \angle A = 90^{\circ}, \therefore Rt\triangle ADF$ 中， $AF^{2} + AD^{2} = DF^{2}$ ，即 $(4 - x)^{2} + 3^{2} = (1 + x)^{2}$ ，解得 $x = \frac{12}{5}, \therefore BF = \frac{12}{5} = 2.4$ ，
> >
> > 故选 **D**.
