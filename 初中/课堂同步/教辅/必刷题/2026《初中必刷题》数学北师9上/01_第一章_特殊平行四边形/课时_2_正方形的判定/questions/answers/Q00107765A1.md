>
> > [!success] **【答案】** D
>
> > [!note]- **【解析】**
> > 甲: ∵ 四边形 ABCD 是边长为 1 的正方形, ∴ AB = BC = CD = AD = 1, ∠BAD = 90°, ∴ AQ = 4 - 1 = 3, AP = 3 + 1 = 4, ∠PAQ = 90°, ∴ $PQ^{2} = AQ^{2} + AP^{2} = 25$ , ∴ PQ = 5, 同理可得 MN = 5, ∴ 四边形 PQMN 是菱形. 在 △QMD 和 △PQA 中, $\left\{ \begin{array}{l} MQ = QP, \\ MD = QA, \\ DQ = AP, \end{array} \right.$ ∴ △QMD ≅ △PQA (SSS), ∴ ∠MQD = ∠APQ. ∵ ∠AQP + ∠QPA = 90°, ∴ ∠AQP + ∠MQD = 90°, ∴ ∠MQP = 90°, 则四边形 PQMN 必是正方形, ∴ 甲正确. 乙: 若四边形 PQMN 为正方形, 则 PQ = PN = MN = MQ = 5, 且 ∠QMD + ∠MQD = ∠AQP + ∠MQD = ∠AQP + ∠APQ = 90°, ∴ ∠MQD = ∠APQ, ∠QMD = ∠AQP. 在 △QMD 和 △PQA 中, $\left\{ \begin{array}{l} \angle QMD = \angle AQP, \\ MQ = PQ, \\ \angle MQD = \angle QPA, \end{array} \right.$ ∴ △QMD ≅ △PQA (ASA), ∴ QD = AP = 4, MD = AQ = 3, 同理可得 QD = AP = MC = BN = 4. 又∵ BP = MD = AQ = 3, ∴ AB = AD = 1. 又∵ 四边形 ABCD 为矩形, ∴ 四边形 ABCD 必是边长为 1 的正方形, ∴ 乙正确.
> >
> > 故选 **D**.
