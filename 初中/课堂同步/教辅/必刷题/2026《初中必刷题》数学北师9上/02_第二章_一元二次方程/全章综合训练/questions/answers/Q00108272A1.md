> [!success]- 必刷题
>
> > [!success] **【答案】** D
>
> > [!note]- **【解析】**
> > ∵ $a \neq 0, c \neq 0, a + c = 0, \therefore \frac{c}{a} = -1.$ 将已知中的两个方程变形为 $x^{2} + \frac{b}{a}x + \frac{c}{a} = 0,$ $\frac{c}{a}x^{2} + \frac{b}{a}x + 1 = 0, \therefore x^{2} + \frac{b}{a}x - 1 = 0, x^{2} - \frac{b}{a}x - 1 = 0.$ ∵ x = 2023 是方程 $cx^{2} + bx + a = 0$ 的一个根，
> >
> > ∴ x = 2023 是方程 $x^{2} - \frac{b}{a}x - 1 = 0$ 的一个根，
> >
> > ∴ $2023^{2} - \frac{b}{a} \times 2023 - 1 = 0, \therefore (-2023)^{2} + \frac{b}{a} \times (-2023) - 1 = 0, \therefore x = -2023$ 是方程 $x^{2} + \frac{b}{a}x - 1 = 0$ 的一个根. 当 $x = \frac{1}{2023}$ 时， $\left(\frac{1}{2023}\right)^{2} + \frac{b}{a}\left(\frac{1}{2023}\right) - 1 = -\left(\frac{1}{2023}\right)^{2}\left[2023^{2} - \frac{b}{a} \times 2023 - 1\right] = 0,$ 即 $x = \frac{1}{2023}$ 是方程 $ax^{2} + bx + c = 0$ 的一个根.
> >
> > 故选 **D**.
