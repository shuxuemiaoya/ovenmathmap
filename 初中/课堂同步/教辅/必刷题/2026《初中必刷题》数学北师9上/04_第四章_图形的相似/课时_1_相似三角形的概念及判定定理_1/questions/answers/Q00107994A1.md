> [!success]- 必刷题
>
> > [!success] **【答案】** A
>
> > [!note]- **【解析】**
> > 设 BP = x，则 CP = 7 - x。当 $\angle APB = \angle PDC$ 时，∵ $\angle B = \angle C = 90^{\circ}$ ，∴ $\triangle APB \sim \triangle PDC$ ，∴ $\frac{BP}{CD} = \frac{AB}{CP}$ ，∴ $BP \cdot CP = AB \cdot CD = 2 \times 6 = 12$ ，∴ $x(7 - x) = 12$ ，解得 x = 3 或 x = 4，∴ BP = 3 或 4；当 $\angle APB = \angle DPC$ 时，∵ $\angle B = \angle C = 90^{\circ}$ ，∴ $\triangle APB \sim \triangle DPC$ ，∴ $\frac{BP}{CP} = \frac{AB}{CD} = \frac{2}{6} = \frac{1}{3}$ ，∴ 3BP = CP，∴ 3x = 7 - x，解得 $x = \frac{7}{4}$ 。综上所述，BP = 3 或 4 或 $\frac{7}{4}$ ，故选 A。

> > 关键;
