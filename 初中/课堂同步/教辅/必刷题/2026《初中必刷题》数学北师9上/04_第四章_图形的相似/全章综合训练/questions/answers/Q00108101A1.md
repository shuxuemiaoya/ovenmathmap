> [!success]- 必刷题
>
> > [!success] **【答案】** B
>
> > [!note]- **【解析】**
> > 在正方形 ABCD 中, AB = 6, ∴ AB = AD = CD = 6. 在正方形 CEFG 中, CE = 2, ∴ CE = GF = CG = 2, ∴ DG = CD - CG = 4. 由题意得 AD // BE, GF // BE, ∴ AD // GF, ∴ 易得 △ADH ∼ △FGH, ∴ $\frac{AD}{GF} = \frac{DH}{GH}$ , 即 $\frac{6}{2} = \frac{DH}{4 - DH}$ , 解得 DH = 3,
> >
> > 故选 **B**.
