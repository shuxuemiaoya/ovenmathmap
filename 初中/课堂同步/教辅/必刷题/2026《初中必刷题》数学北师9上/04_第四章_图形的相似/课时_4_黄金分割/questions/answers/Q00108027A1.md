> [!success]- 必刷题
>
> > [!success] **【答案】** D
>
> > [!note]- **【解析】**
> > 设正方形 ABCD 的边长为 2a.
> >
> > A 选项, ∵ 点 N 是 BC 的中点, ∴ BN = CN = $\frac{1}{2}BC = a$ , ∴ $\frac{CN}{CD} = \frac{a}{2a} = \frac{1}{2} \neq \frac{\sqrt{5} - 1}{2}$ , ∴ 矩形 MNCD 不是黄金矩形. B 选项, 在 Rt $\triangle DCN$ 中, CN = a, CD = 2a, ∴ $DN = \sqrt{CN^{2} + CD^{2}} = \sqrt{a^{2} + (2a)^{2}} = \sqrt{5}a$ . 由题意得 DN = NE = $\sqrt{5}a$ ,
> >
> > ∴ CE = EN - CN = ( $\sqrt{5} - 1$ ) a, ∴ $\frac{CE}{CD} = \frac{(\sqrt{5} - 1)a}{2a} = \frac{\sqrt{5} - 1}{2}$ ,
> >
> > ∴ 矩形 DCEF 是黄金矩形. C 选项,
> >
> > ∵ 四边形 DCEF 是矩形, ∴ EF = CD = 2a,
> >
> > ∴ $\frac{EF}{NE} = \frac{2a}{\sqrt{5}a} = \frac{2\sqrt{5}}{5} \neq \frac{\sqrt{5} - 1}{2}$ ,
> >
> > ∴ 矩形 MNEF 不是
> >
> > 黄金矩形. D 选项, ∵ BN = a, NE = $\sqrt{5}a$ , ∴ BE = BN + NE = ( $\sqrt{5} + 1$ ) a, ∴ $\frac{AB}{BE} = \frac{2a}{(\sqrt{5} + 1)a} = \frac{2}{\sqrt{5} + 1} = \frac{\sqrt{5} - 1}{2}$ ,
> >
> > ∴ 矩形 ABEF 是黄金矩形, ∴ 矩形 DCEF 和矩形 ABEF 都是黄金矩形.
> >
> > 故选 **D**.
