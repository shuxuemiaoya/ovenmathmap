> > [!note]- **【解析】**
> > 【解】(1) $A-B=(a^{2}+b^{2}-c^{2})-(-4a^{2}+2b^{2}+3c^{2})=a^{2}+b^{2}-c^{2}+4a^{2}-2b^{2}-3c^{2}=5a^{2}-b^{2}-4c^{2}.$ (2) 因为 $A - B + C = 0$ ，所以 $C = -(A - B) = -(5a^{2} - b^{2} - 4c^{2}) = -5a^{2} + b^{2} + 4c^{2}$ ，当 a = 1, b = -1, c = 3 时， $C = -5 \times 1^{2} + (-1)^{2} + 4 \times 3^{2} = -5 + 1 + 36 = 32.$
