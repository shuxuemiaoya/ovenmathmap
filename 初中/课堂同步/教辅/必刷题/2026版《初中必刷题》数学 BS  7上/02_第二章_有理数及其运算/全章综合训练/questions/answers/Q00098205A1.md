> > [!note]- **【解析】**
> > 【解】(1)以 B 为原点, 点 A, C 所对应的数分别是 -8,4, 则 $m = -8 + 0 + 4 = -4$ ;
> > 以 C 为原点, 点 A, B 所对应的数分别为 -12, -4, 则 $m = -12 + (-4) + 0 = -16$ .
> > (2)由题意得点 A 对应的数为 -16, 点 B 对应的数为 -8, 点 C 对应的数为 -4, 则 $n = -16 \times (-8) \times (-4) = -512$ .
