6 核心素养运算能力[2024 湖北武汉调研,较难]请利用绝对值的性质,解决下列问题:

(1) 已知 a, b 是有理数, 当 a > 0 时, $\frac{a}{|a|} =$ \_\_\_\_; 当 b < 0 时, $\frac{b}{|b|} =$ \_\_\_\_.

(2)已知 a, b 是有理数, 且 ab < 0, 求 $\frac{|a|}{a} + \frac{|b|}{b}$ 的值.

(3)已知 a, b, c 是有理数, $a + b + c = 0$ , abc < 0, 求 $\frac{b + c}{|a|} + \frac{a + c}{|b|} + \frac{a + b}{|c|}$ 的值.

(4)已知 $a, b, c$ 是有理数，当 $abc \neq 0$ 时，求 $\frac{a}{|a|} + \frac{|b|}{b} + \frac{c}{|c|}$ 的值.
