> [!success]- 必刷题
>
> > [!success] **【答案】** 同号得正,异号得负,并把绝对值相加;正数与0进行“⊕”运算得它本身,负数与0进行“⊕”运算得它的相反数(或等于这个数的绝对值)
>
> > [!note]- **【解析】**
> > 【解】(1)“⊕”运算的运算法则:不为0的两数进行“⊕”运算时,同号得正,异号得负,并把绝对值相加;一个不为0的数与0进行“⊕”运算时,正数与0进行“⊕”运算得它本身,负数与0进行“⊕”运算得它的相反数(或等于这个数的绝对值).故答案为同号得正,异号得负,并把绝对值相加;正数与0进行“⊕”运算得它本身,负数与0进行“⊕”运算得它的相反数(或等于这个数的绝对值).
> >
> > 思路分析
> > 将实际问题抽象为有理数减法模型, 先计算出四个地区的四季温差, 再分别与10℃进行比较即可.
> >
> > $$
> > (2) (- 3) \oplus [ 2 \oplus (- 4) ] = (- 3) \oplus (- 6) = 9.
> > $$
> >
> > (3) 结合律在有理数的“⊕”运算中不适用. 例如: $\left[(-3) \oplus (-2)\right] \oplus 0 = 5 \oplus 0 = 5$ ; $(-3) \oplus \left[(-2) \oplus 0\right] = (-3) \oplus 2 = -5$ , 这时, $\left[(-3) \oplus (-2)\right] \oplus 0 \neq (-3) \oplus \left[(-2) \oplus 0\right]$ , 所以结合律在有理数的“⊕”运算中不适用.
> >
> > 易错警示
> > 在有理数的减法运算中,添括号时要注意,如果括号前是负号,则括号内要变号.
