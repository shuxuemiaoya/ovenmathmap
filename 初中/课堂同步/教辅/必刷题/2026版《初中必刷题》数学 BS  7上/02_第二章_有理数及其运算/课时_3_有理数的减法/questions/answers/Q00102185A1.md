> [!success]- 必刷题
>
> > [!success] **【答案】** C
>
> > [!note]- **【解析】**
> > 因为 x 为最大负整数, 所以 x = -1, 所以 $\frac{1}{3} - x = \frac{1}{3} - (-1) = \frac{4}{3}$ . 因为 $1 < \frac{4}{3} < 1.6$ , 所以落在段③, 故选 C.
> >
> > 4.3 【解析】因为 $a \oplus b = a - b$ ，所以 $(-2) \oplus (-5) = (-2) - (-5) = (-2) + 5 = 3$ ，故答案为3.
