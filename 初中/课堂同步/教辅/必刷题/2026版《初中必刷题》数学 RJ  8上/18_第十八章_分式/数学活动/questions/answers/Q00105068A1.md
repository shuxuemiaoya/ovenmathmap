> [!success]- 必刷题
>
> > [!success] **【答案】** 2, 5, 4, 10 ( $a, b, c, d$ 的值均不唯一)
>
> > [!note]- **【解析】**
> > (1)【解】当 $a = 2, b = 5, c = 4, d = 10$ 时, $\frac{a}{b} = \frac{c}{d}$ 成立. 故答案为 2, 5, 4, 10 ( $a, b, c, d$ 的值均不唯一).
> >
> > (2)【解】当 $a = 2, b = 5, c = 4, d = 10$ 时， $\frac{a + b}{a - b} =$ $-\frac{7}{3},\frac{c+d}{c-d}=-\frac{7}{3}.$ 故答案为 $-\frac{7}{3},-\frac{7}{3}$ （答案不唯一，与(1)对应即可）.
> >
> > (3)【解】猜想:若 $\frac{a}{b}=\frac{c}{d}$ ，则 $\frac{a+b}{a-b}=\frac{c+d}{c-d}(a\neq b,$ $c \neq d)$ .
> >
> > (4)【证明】∵ $\frac{a}{b} = \frac{c}{d}$ , ∴ ad = bc. ∵ $a \neq b, c \neq d$ ,
> > ∴ $\frac{a+b}{a-b}-\frac{c+d}{c-d}=\frac{(a+b)(c-d)}{(a-b)(c-d)}-\frac{(a-b)(c+d)}{(a-b)(c-d)}=$ $\frac{ac+bc-ad-bd-ac+bc-ad+bd}{(a-b)(c-d)}=\frac{2bc-2ad}{(a-b)(c-d)}=$ 0, ∴ $\frac{a+b}{a-b}=\frac{c+d}{c-d}.$
