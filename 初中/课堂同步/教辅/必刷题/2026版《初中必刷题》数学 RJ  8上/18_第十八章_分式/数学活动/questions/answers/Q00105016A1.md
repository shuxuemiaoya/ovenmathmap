> [!success]- 必刷题
>
> > [!success] **【答案】** 3 或 -3 或 $\frac{1}{3}$ 或 $-\frac{1}{3}$
>
> > [!note]- **【解析】**
> > 根据 $x^{2} = 9$ ，得 $x = 3$ 或 -3，代入 $x^{2} + \frac{1}{x^{2}} = 9\frac{1}{9}$ ，等式成立；同理根据 $x^{2} = \frac{1}{9}$ ，得 $x = \frac{1}{3}$ 或 $-\frac{1}{3}$ ，代入 $x^{2} + \frac{1}{x^{2}} = 9\frac{1}{9}$ ，等式成立。故答案为 3 或 -3 或 $\frac{1}{3}$ 或 $-\frac{1}{3}$ 。
> >
> > 关键点拨6.【解】(1)填表如下：
> >
> > <table><tr><td>x</td><td>...</td><td> $\frac{1}{3}$ </td><td> $\frac{1}{2}$ </td><td>1</td><td>2</td><td>3</td><td>...</td></tr><tr><td> $x^{2}+\frac{1}{x^{2}}$ </td><td>...</td><td> $\frac{82}{9}$ </td><td> $\frac{17}{4}$ </td><td>2</td><td> $\frac{17}{4}$ </td><td> $\frac{82}{9}$ </td><td>...</td></tr></table>
> >
> > (2)根据(1)猜想:当x=1时, $x^{2}+\frac{1}{x^{2}}$ 有最小值,是2.故答案为1,小,2.
> > (3) $x^{2}+\frac{1}{x^{2}}=x^{2}-2+\frac{1}{x^{2}}+2=\left(x-\frac{1}{x}\right)^{2}+2.$ $\because\left(x-\frac{1}{x}\right)^{2}\geqslant0,\therefore$ 当x=1时, $x^{2}+\frac{1}{x^{2}}(x>0)$ 有最小值,是2.
> > (4) $\because x^{2}-6x+\frac{1}{(x-3)^{2}}+10=x^{2}-6x+9+\frac{1}{(x-3)^{2}}+1=(x-3)^{2}+\frac{1}{(x-3)^{2}}+1=(x-3)^{2}-2+\frac{1}{(x-3)^{2}}+1+2=\left[(x-3)-\frac{1}{x-3}\right]^{2}+3.\because\left[(x-3)-\frac{1}{x-3}\right]^{2}\geqslant0,\therefore\left[(x-3)-\frac{1}{x-3}\right]^{2}+3(x>3)$ 有最小值,是3,此时x-3=1,即x=4. $\therefore x^{2}-6x+\frac{1}{(x-3)^{2}}+10(x>3)$ 有最小值,是3,此时x=4.
