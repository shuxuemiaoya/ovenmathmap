> > [!success] **【答案】** $b < a < d < c
>
> > [!note]- **【解析】**
> > $\because a = -0.09, b = -\frac{1}{9}, c = 9,$ $d = 1, -\frac{1}{9} < -0.09 < 1 < 9, \therefore b < a < d < c.$ 故答案为 $b < a < d < c.$
