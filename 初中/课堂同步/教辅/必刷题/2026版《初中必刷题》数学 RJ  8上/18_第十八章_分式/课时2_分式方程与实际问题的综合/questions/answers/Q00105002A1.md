> [!success]- 必刷题
>
> > [!success] **【答案】** A
>
> > [!note]- **【解析】**
> > 设甲、乙、丙单独完成这项工程各需 x 天、y 天、z 天。根据题意得 $x = a \cdot \frac{1}{\frac{1}{y} + \frac{1}{z}} = \frac{ayz}{y + z}, \therefore a = \frac{xy + xz}{yz}, \therefore a + 1 = \frac{xy + yz + xz}{yz}, \therefore \frac{1}{a + 1} = \frac{yz}{xy + yz + xz}$ 。同理可得 $\frac{1}{b + 1} = \frac{xz}{xy + yz + xz}, \frac{1}{c + 1} = \frac{xy}{xy + yz + xz}, \therefore \frac{1}{a + 1} + \frac{1}{b + 1} + \frac{1}{c + 1} = \frac{yz}{xy + yz + xz} + \frac{xz}{xy + yz + xz} + \frac{xy}{xy + yz + xz} = \frac{xy + yz + xz}{xy + yz + xz} = 1$ ，
> >
> > 故选 **A**.
