> [!success]- 必刷题
>
> > [!success] **【答案】** A
>
> > [!note]- **【解析】**
> > ∵ $M = \frac{a + mb}{1 + m} = \frac{1}{1 + m} a + \frac{m}{1 + m} b, N = \frac{a + nb}{1 + n} = \frac{1}{1 + n} a + \frac{n}{1 + n} b, \therefore M - N = \left( \frac{1}{1 + m} - \frac{1}{1 + n} \right) a +$ $\left(\frac{m}{1 + m} - \frac{n}{1 + n}\right)b = \frac{n - m}{(1 + m)(1 + n)} a + \frac{m - n}{(1 + m)(1 + n)} b = \frac{(m - n)(b - a)}{(1 + m)(1 + n)}. \because a < b, -1 < n < m, \therefore m - n > 0, 1 + m > 0, 1 + n > 0, b - a > 0, \therefore \frac{(m - n)(b - a)}{(1 + m)(1 + n)} > 0, \therefore M - N > 0, \therefore M > N.$
> >
> > 故选 **A**.
