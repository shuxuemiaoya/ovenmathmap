6[中]已知：
方程 $x+\frac{1}{x}=2+\frac{1}{2}$ 的解是 $x_{1}=2, x_{2}=\frac{1}{2}$ ;
方程 $x + \frac{1}{x} = 3 + \frac{1}{3}$ 的解是 $x_{1} = 3, x_{2} = \frac{1}{3}$ ;
方程 $x + \frac{1}{x} = 4 + \frac{1}{4}$ 的解是 $x_{1} = 4, x_{2} = \frac{1}{4}$ ;
……

(1)关于 $x$ 的方程 $x + \frac{1}{x} = a + \frac{1}{a}$ 的解是什么？并用方程解的概念验证你的猜想是否正确.

(2)根据结论求出关于 $x$ 的方程 $x + \frac{1}{x - 3} = b + \frac{1}{b - 3}$ 的解.
