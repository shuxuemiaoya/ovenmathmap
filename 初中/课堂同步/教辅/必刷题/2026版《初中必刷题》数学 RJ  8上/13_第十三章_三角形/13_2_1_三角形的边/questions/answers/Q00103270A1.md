> > [!note]- **【解析】**
> > 【解】(1)由题意得 $a - b < c < a + b$ ，且 $a + b = 3c - 4, a - b = 2c - 6, \therefore 2c - 6 < c < 3c - 4, \therefore 2 < c < 6$ . 又 $\because a > b, \therefore a - b = 2c - 6 > 0, \therefore c > 3, \therefore 3 < c < 6.$ (2) $\because \triangle ABC$ 的周长为 $12, \therefore a + b + c = 12$ . 又 $\because a + b = 3c - 4, \therefore 3c - 4 + c = 12, \therefore c = 4.$
