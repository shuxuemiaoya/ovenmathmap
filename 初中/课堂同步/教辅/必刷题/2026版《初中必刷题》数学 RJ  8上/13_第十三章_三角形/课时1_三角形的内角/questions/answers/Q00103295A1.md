> [!success]- 必刷题
>
> > [!success] **【答案】** C
>
> > [!note]- **【解析】**
> > ∵ $\angle A: \angle B: \angle C = 1:2:6$ , ∴ 设 $\angle A = x, \angle B = 2x, \angle C = 6x.$ ∵ $\angle A + \angle B + \angle C = 180^{\circ}$ ，即 $x + 2x + 6x = 180^{\circ}$ ，解得 $x = 20^{\circ}$ ，∴ 最大角为 $\angle C = 120^{\circ}$ ，∴ 此三角形是钝角三角形，
> >
> > 故选 **C**.
