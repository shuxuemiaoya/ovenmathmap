> [!success]- 必刷题
>
> > [!success] **【答案】** A
>
> > [!note]- **【解析】**
> > ∵ $\angle BAC = 90^{\circ}, AD \perp BC, DF \perp AB$ ,
> > ∴ $\angle C + \angle B = 90^{\circ}, \angle BAD + \angle B = 90^{\circ}, \angle BDF + \angle B = 90^{\circ}, \therefore \angle C = \angle BDF = \angle BAD.$ 同理， $\angle DAC + \angle C = 90^{\circ}, \angle DAC + \angle ADE = 90^{\circ},$ ∴ $\angle C = \angle ADE, \therefore$ 题图中与 $\angle C (\angle C \text{ 除外})$ 相等的角的个数是3个，
> >
> > 故选 **A**.
