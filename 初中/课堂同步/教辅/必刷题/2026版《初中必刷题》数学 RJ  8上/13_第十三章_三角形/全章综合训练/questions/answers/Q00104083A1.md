> [!success]- 必刷题
>
> > [!success] **【答案】** $0^{\circ} < \angle ADE < 45^{\circ}$ 或 $90^{\circ} < \angle ADE \leqslant 95^{\circ}$
>
> > [!note]- **【解析】**
> > $\because \angle B = 50^{\circ}, \angle C = 40^{\circ}, \therefore \angle BAC = 180^{\circ} - \angle B - \angle C = 90^{\circ}.$ $\because AD$ 平分 $\angle BAC, \therefore \angle DAE = 45^{\circ}, \therefore \angle ADC = 180^{\circ} - \angle DAE - \angle C = 95^{\circ}.$ 当 $\angle ADE$ 是钝角时， $90^{\circ} < \angle ADE \leqslant 95^{\circ}.$ 当 $\angle AED$ 是钝角时， $\angle AED > 90^{\circ}.$ $\because \angle AED = 180^{\circ} - \angle DAE - \angle ADE = 180^{\circ} - 45^{\circ} - \angle ADE = 135^{\circ} - \angle ADE, \therefore 135^{\circ} - \angle ADE > 90^{\circ}, \therefore 0^{\circ} < \angle ADE < 45^{\circ}.$ 综上， $0^{\circ} < \angle ADE < 45^{\circ}$ 或 $90^{\circ} < \angle ADE \leqslant 95^{\circ}.$
