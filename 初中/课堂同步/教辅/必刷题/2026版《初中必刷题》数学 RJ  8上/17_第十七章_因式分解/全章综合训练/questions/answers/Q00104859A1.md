> [!success]- 必刷题
>
> > [!success] **【答案】** $(n + 1)^{2} - (n - 1)^{2}$ （2） $(2k + 1)^{2} - (2m + 1)^{2} = (2k + 1 + 2m + 1)\cdot$ $(2k + 1 - 2m - 1) = 4(k^{2} - m^{2} + k - m)$ 故答案为 $4(k^{2} - m^{2} + k - m)$
>
> > [!note]- **【解析】**
> > 【解】(1)(i) $4=4\times1=(1+1)^{2}-(1-1)^{2},8=4\times2=(2+1)^{2}-(2-1)^{2},$ $12=4\times3=(3+1)^{2}-(3-1)^{2},16=4\times4=(4+1)^{2}-(4-1)^{2},20=4\times5=(5+1)^{2}-(5-1)^{2},$ $24=4\times6=(6+1)^{2}-(6-1)^{2}=7^{2}-5^{2}.$
> >
> > (ii)由(i)推导的规律可知 $4n = 4\cdot n = (n+$ $1)^{2} - (n - 1)^{2}$ 故答案为 $(n + 1)^{2} - (n - 1)^{2}$ （2） $(2k + 1)^{2} - (2m + 1)^{2} = (2k + 1 + 2m + 1)\cdot$ $(2k + 1 - 2m - 1) = 4(k^{2} - m^{2} + k - m)$ 故答案为 $4(k^{2} - m^{2} + k - m)$
