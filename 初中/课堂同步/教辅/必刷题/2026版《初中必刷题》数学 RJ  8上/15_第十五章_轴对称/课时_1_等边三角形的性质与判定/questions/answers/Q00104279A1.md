> > [!note]- **【解析】**
> > 归纳总结
> > 判定等边三角形的方法：
> > (1) 由定义判定: 三条边都相等的三角形是等边三角形.
> > (2) 判定定理
> > 1: 三个角都相等的三角形是等边三角形.
> > (3) 判定定理
> > 2: 有一个角是60°的等腰三角形是等边三角形.
> >
> > $\because \angle A = \angle B = 60^{\circ}, \therefore \angle C = 60^{\circ}, \therefore \angle A = \angle B = \angle C, \therefore \triangle ABC$ 是等边三角形，故选项A不符合题意 $\because \angle B + \angle C = 120^{\circ}, \therefore \angle A = 60^{\circ}, \therefore \triangle ABC$ 不一定是等边三角形，故选项B符合题意 $\because \angle B = 60^{\circ}, AB = AC, \therefore \triangle ABC$ 是等边三角形，故选项C不符合题意 $\because \angle A = 60^{\circ}, AB = AC, \therefore \triangle ABC$ 是等边三角形，故选项D不符合题意
