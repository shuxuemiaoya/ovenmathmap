> [!success]- 必刷题
>
> > [!success] **【答案】** $-\frac{3}{2}$
>
> > [!note]- **【解析】**
> > 【解】(1)题图(1): $(a+b)^{2}=a^{2}+2ab+b^{2}$ ;题图(2): $(a-b)^{2}=a^{2}-2ab+b^{2}$ ;题图(3): $4ab=(a+b)^{2}-(a-b)^{2}$ .(选一个等式填空即可)
> > (2)①∵m+n=2,∴(m+n)²=m²+2mn+n²=4.
> >
> > $\because m^{2} + n^{2} = 7, \therefore 7 + 2mn = 4, \therefore mn = -\frac{3}{2}$ . 故答案为 $-\frac{3}{2}$ .
> > - **②**：$\because ab = 1, \therefore 8ab = 8. \because (2a - b)^{2} = (2a + b)^{2} - 8ab, 2a + b = 3, 8ab = 8, \therefore (2a - b)^{2} = 3^{2} - 8 = 1.$ ③ $\because (4 - x) - (5 - x) = -1, \therefore [(4 - x) - (5 - x)]^{2} = 1. \because (4 - x)(5 - x) = 6, \therefore (4 - x)^{2} + (5 - x)^{2} = 1 + 2(4 - x)(5 - x) = 1 + 12 = 13.$
> >
> > (3) 数字 1\~9 的和为 $1+2+3+4+5+6+7+8+9=45$ . ∵ 各边上的四个数字的和都等于 21, $21 \times 3 - 45 = 18$ , ∴ $x + y + (x + y) = 18$ , 即 $x + y = 9$ .
> >
> > ∵ 每边四个数字的平方和分别记为 A, B, C, A + B + C = 411, 且 $1^{2} + 2^{2} + 3^{2} + 4^{2} + 5^{2} + 6^{2} + 7^{2} + 8^{2} + 9^{2} = 285$ , ∴ $x^{2} + y^{2} + (x + y)^{2} = 411 - 285 = 126$ ,
> >
> > ∴ $x^{2} + y^{2} + 81 = 126$ , ∴ $x^{2} + y^{2} = 45$ , ∴ $(x + y)^{2} - 2xy = 45$ , ∴ xy = 18.
