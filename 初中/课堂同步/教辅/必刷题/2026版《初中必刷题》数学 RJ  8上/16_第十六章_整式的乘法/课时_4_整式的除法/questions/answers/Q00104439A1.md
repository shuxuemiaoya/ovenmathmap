> > [!note]- **【解析】**
> > (1) ① $x^{2021} + x^{2020} + \cdots + x + 1$ ② $x^{n-1} + x^{n-2} + \cdots + x + 1$ $x+1$ 【解】(2) $\because (x^n - 1) \div (x - 1) = x^{n-1} + x^{n-2} + \cdots + x + 1, \therefore 2^{2022} + 2^{2021} + \cdots + 2 + 1 = (2^{2023} - 1) \div (2 - 1) = 2^{2023} - 1.$ (3) $\because (x^{2022} - 1) \div (x - 1) = x^{2021} + x^{2020} + \cdots + x + 1 = 0, \therefore (x^{2022} - 1) \div (x - 1) = 0, \therefore x^{2022} - 1 = 0,$ $\therefore x^{2022} = 1.$
