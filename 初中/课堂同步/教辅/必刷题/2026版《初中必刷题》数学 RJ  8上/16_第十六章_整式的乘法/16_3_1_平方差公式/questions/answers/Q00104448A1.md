> [!success]- 必刷题
>
> > [!success] **【答案】** $b < a < c$
>
> > [!note]- **【解析】**
> > $a = 1954 \times 1946 = (1950 + 4)(1950 - 4) = 1950^2 - 16, b = 1957 \times 1943 = (1950 + 7)(1950 - 7) = 1950^2 - 49, c = 1949 \times 1951 = (1950 - 1)(1950 + 1) = 1950^2 - 1.$ $\because 1950^2 - 49 < 1950^2 - 16 < 1950^2 - 1, \therefore b < a < c,$ 故答案为 $b < a < c$ .
