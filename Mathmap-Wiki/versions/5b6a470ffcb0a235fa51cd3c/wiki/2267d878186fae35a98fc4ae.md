# 例 3 下列各题中

例3 下列各题中，哪些 $p$ 是 $q$ 的充要条件？

（1）p：四边形是正方形，q：四边形的对角线互相垂直且平分；

(2) p：两个三角形相似，q：两个三角形三边成比例；

(3) p: xy > 0, q: x > 0, y > 0;

(4) p: x=1 是一元二次方程 $ax^{2}+bx+c=0$ 的一个根， $q:a+b+c=0\quad(a\neq0)$ .
