# 一元二次不等式应用：摩托车产值

例 4 一家车辆制造厂引进了一条摩托车整车装配流水线，这条流水线生产的摩托车数量 x （单位：辆）与创造的价值 y （单位：元）之间有如下的关系：

$$
y = - 2 0 x ^ {2} + 2 2 0 0 x.
$$

若这家工厂希望在一个星期内利用这条流水线创收60 000元以上，则在一个星期内大约应该生产多少辆摩托车？
