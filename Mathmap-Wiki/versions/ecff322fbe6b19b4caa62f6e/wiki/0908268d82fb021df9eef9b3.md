# 练习 3

3. 判断下列两个集合之间的关系：

(1) $A = \{x \mid x < 0\}$，$B = \{x \mid x < 1\}$；

(2) $A = \{x \mid x = 3k, k \in \mathbf{N}\}$，$B = \{x \mid x = 6z, z \in \mathbf{N}\}$；

(3) $A = \{x \in \mathbf{N}_{+} \mid x \text{ 是 } 4 \text{ 与 } 10 \text{ 的公倍数}\}$，$B = \{x \mid x = 20m, m \in \mathbf{N}_{+}\}$.

> [!success]- 答案与解析
>
> > [!success] **【答案】** (1) $A \subsetneqq B$；(2) $B \subsetneqq A$；(3) $A = B$
>
> > [!note]- **【分析】**
> > 结合数轴或整数倍数的整除性质，检验一个集合中的任意元素是否必属于另一个集合.
>
> > [!note]- **【解析】**
> > (1) 任意满足 $x < 0$ 的实数都满足 $x < 1$，但 $0 \in B$ 且 $0 \notin A$，所以 $A \subsetneqq B$.
> > (2) 当 $x = 6z = 3 \times (2z)$（$z \in \mathbf{N}$）时，必有 $2z \in \mathbf{N}$，即 $6$ 的自然数倍必是 $3$ 的自然数倍，但 $3 \in A$ 且 $3 \notin B$，所以 $B \subsetneqq A$.
> > (3) $4$ 与 $10$ 的最小公倍数为 $20$，正整数中 $4$ 与 $10$ 的公倍数恰为 $20$ 的正整数倍，故 $A = B$.
