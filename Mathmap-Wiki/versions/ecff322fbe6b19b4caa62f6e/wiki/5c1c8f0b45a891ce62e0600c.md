1. 把下列指数式写成对数式，对数式写成指数式：
(1) $3^{x}=1$ ; (2) $4^{x}=\frac{1}{6}$ ; (3) $10^{x}=6$ ; (4) $e^{x}=25$ ;
(5) $x=\log_{5}27$ ; (6) $x=\log_{7}\frac{1}{3}$ ; (7) $x=\lg0.3$ ; (8) $x=\ln\sqrt{3}$ .

(A) $x > 2$ (B) $x < 2$ (C) $\frac{1}{2} < x < 2$ (D) $\frac{1}{2} < x < 2$ ，且 $x \neq 1$

(2) 若 $\lg a (a > 0)$ 与 $\lg b (b > 0)$ 互为相反数，则（）.
(A) $a + b = 0$ (B) $a - b = 0$ (C) $ab = 1$ (D) $\frac{a}{b} = 1$
