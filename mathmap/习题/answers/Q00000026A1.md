> [!faq]- 必刷题解析
> **【答案】** D
>
> **【解析】**
> 因为 $A = \{x \mid -2 < x < 1\}$ ， $B = \{x \mid x \leqslant 2\}$ ，所以 $A \cup B = \{x \mid x \leqslant 2\}$ ， $A \cap B = \{x \mid -2 < x < 1\}$ ，所以 $\complement_{\mathbb{R}}(A \cup B) = \{x \mid x > 2\}$ ， $\complement_{\mathbb{R}}(A \cap B) = \{x \mid x \leqslant -2 \text{ 或 } x \geqslant 1\}$ 。
>
> 故选 **D**.
