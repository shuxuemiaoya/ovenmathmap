> [!faq]- 全练一本通解析
> **【解析】**
> $$
(2) \frac {\pi}{2}
$$
解析：（1）证明：取 AB 的中点 G，连接 MG 交 EF 于 H，连接 CH，因为 M 分别为棱 $A_{1}B_{1}$ 的中点，所以 $MG \parallel AA_{1} \parallel BB_{1}$ ，
所以 $\frac{EH}{FH}=\frac{AG}{BG}=1$ ，所以 EH=FH，
所以 $HG=\frac{1}{2}(BF+AE)$ ,
因为 $A_{1}E = BF = \frac{1}{3}AA_{1}$ ，所以 $HG = \frac{1}{2}AA_{1}$ ，所以 $MH = \frac{1}{2}AA_{1}$ ，
因为 N 分别为棱 $CC_{1}$ 的中点，所以 $CN = \frac{1}{2}CC_{1}$ ，
因为 $MG \parallel AA_{1} \parallel CC_{1}$ ，所以 $MH = CN, MH \parallel CN$ ，
所以四边形 CHMN 为平行四边形，
所以 MN // CH，
因为 MN ∉ 平面 CEF，CH ⊂ 平面 CEF，
所以直线 MN // 平面 CEF ;
（2）解：连接 $CG$ ，因为三棱柱 $ABC - A_{1}B_{1}C_{1}$ 为正三棱柱，所以 $\triangle ABC$ 为等边三角形，所以 $CG\bot AB$ ，所以以 $C$ 为原点，以 $CG$ 所在的直线为 $x$ 轴，过 $C$ 与 $AB$ 平行的直线为 $y$ 轴， $CC_{1}$ 所在的直线为 $z$ 轴建立空间直角坐标系，设 $AB = a,AA_{1} = b$ ，则 $C(0,0,0),E(\frac{\sqrt{3}}{2} a,\frac{1}{2} a,\frac{2}{3} b),F(\frac{\sqrt{3}}{2} a, - \frac{1}{2} a,\frac{1}{3} b),A(\frac{\sqrt{3}}{2} a,\frac{1}{2} a,0),C(0,0,b)$ ，所以 $\overline{CE} = (\frac{\sqrt{3}}{2} a,\frac{1}{2} a,\frac{2}{3} b),\overline{CF} = (\frac{\sqrt{3}}{2} a, - \frac{1}{2} a,\frac{1}{3} b),\overline{CA} = (\frac{\sqrt{3}}{2} a,\frac{1}{2} a,0),\overline{CC_{1}} = (0,0,b)$ 设平面 $CEF$ 的法向量为 $\vec{m} = (x_1,y_1,z_1)$ ，则 $\left\{ \begin{array}{l}\vec{m}\cdot \overline{CE} = \frac{\sqrt{3}}{2} ax_1 + \frac{1}{2} ay_1 + \frac{2}{3} bz_1 = 0\\ \vec{m}\cdot \overline{CF} = \frac{\sqrt{3}}{2} ax_1 - \frac{1}{2} ay_1 + \frac{1}{3} bz_1 = 0 \end{array} \right.$ ，令 $x_{1} = \sqrt{3}$ ，则 $\vec{m} = (\sqrt{3},1, - \frac{3a}{b})$ 设平面 $ACC_{1}A_{1}$ 的法向量为 $\vec{n} = (x_2,y_2,z_2)$ ，则 $\left\{ \begin{array}{l}\vec{n}\cdot \overrightarrow{CA} = \frac{\sqrt{3}}{2} ax_2 + \frac{1}{2} ay_2 = 0\\ \vec{n}\cdot \overrightarrow{CC_1} = bz_2 = 0 \end{array} \right.$ ，令 $x_{2} = \sqrt{3}$ ，则 $\vec{n} = (\sqrt{3}, - 3,0)$ 所以 $\cos \vec{m},\vec{n} = |\vec{m} ||\vec{n}| = \frac{3 - 3 - 0}{\sqrt{3 + 1 + \frac{9a^2}{b^2}}\times\sqrt{3 + 9}} = 0$ 设平面 $CEF$ 和平面 $ACC_{1}A_{1}$ 的夹角为 $\theta$ ，则 $\theta = 0$ 因为 $\theta \in [0,\frac{\pi}{2} ]$ ，所以 $\theta = \frac{\pi}{2}$
