> [!faq]- 全练一本通解析
> **【解析】**
> $\sqrt{2}$
解析: 把长方体 $DCC_{1}D_{1}$ 展开到长方形 $ACC_{1}A_{1}$ 所在的平面, 易知 $AC = \sqrt{1 + 3} = 2$ ,
![](../../../../../images/answers/5777a5792972100aa6f71b2d5f4ee95ab01bca3ad80a5ddbd167aef8fc3d0d12.jpg)
当 $A, M, D_{1}$ 在同一直线上时， $MD_{1} + MA$ 取得最小值，此时 $\frac{AM}{AD_{1}} = \frac{MC}{DD_{1}} = \frac{AC}{AD} = \frac{2}{3}$ ，设 $MC = x$ ， $DD_{1} = \frac{3x}{2}$ ，原图形中，则有 $AM^{2} = AC^{2} + CM^{2} = 2^{2} + x^{2} = 4 + x^{2}$ ， $MD_{1}^{2} = C_{1}D_{1}^{2} + C_{1}M^{2} = 1 + (CC_{1} - CM)^{2} = 1 + \left(\frac{x}{2}\right)^{2} = 1 + \frac{x^{2}}{4}$ ， $AD_{1}^{2} = AD^{2} + DD_{1}^{2} = 3 + \frac{9}{4}x^{2}$ ，因为 $MD_{1} \perp MA$ ，所以 $AM^{2} + MD_{1}^{2} = AD_{1}^{2}$ ，即 $4 + x^{2} + 1 + \frac{1}{4}x^{2} = 3 + \frac{9}{4}x^{2}$ ，解得： $x = \sqrt{2}$ 。故答案为： $\sqrt{2}$ 。
