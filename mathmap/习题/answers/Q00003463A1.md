> [!faq]- 必刷题解析
> **【解析】**
> $\frac{\sqrt{10}}{5}$ 【解析】因为在正四面体ABCD中，点 $M,N$ 分别为棱 $BC,AD$ 的中点，所以 $AM = CN.$ 因为点 $E,F$ 分别为线段 $AM,CN$ 上的动点，且满足 $AE = CF$ ，令 $\overrightarrow{AE} = \lambda \overrightarrow{AM},\lambda \in [0,1]$ ，则 $\overrightarrow{CF} = \lambda \overrightarrow{CN}$ 所以 $\overrightarrow{EF} = \overrightarrow{AF} -\overrightarrow{AE} = (\overrightarrow{AC} +\overrightarrow{CF}) - \lambda \overrightarrow{AM} =$ $\overrightarrow{AC} +\lambda \overrightarrow{CN} -\lambda \overrightarrow{AM} = \overrightarrow{AC} +\lambda (-\overrightarrow{AC}+$ $\frac{1}{2}\overrightarrow{AD}) - \lambda \cdot \frac{1}{2} (\overrightarrow{AB} +\overrightarrow{AC}) =$ $(1 - \frac{3\lambda}{2})\overrightarrow{AC} -\frac{\lambda}{2}\overrightarrow{AB} +\frac{\lambda}{2}\overrightarrow{AD}.$ 又 $\overrightarrow{AC}\cdot \overrightarrow{AB} = |\overrightarrow{AC}||\overrightarrow{AB}|\cos \angle BAC = 2,$ $\overrightarrow{AC}\cdot \overrightarrow{AD} = |\overrightarrow{AC}||\overrightarrow{AD}|\cos \angle DAC = 2,$ $\overrightarrow{AD}\cdot \overrightarrow{AB} = |\overrightarrow{AD}||\overrightarrow{AB}|\cos \angle BAD = 2,$ $|\overrightarrow{AC}| = |\overrightarrow{AB}| = |\overrightarrow{AD}| = 2,$ 故 $|\overrightarrow{EF}| = \left|\left(1 - \frac{3\lambda}{2}\right)\overrightarrow{AC} -\frac{\lambda}{2}\overrightarrow{AB} +\frac{\lambda}{2}\overrightarrow{AD}\right|$ $= \sqrt{\left[\left(1 - \frac{3\lambda}{2}\right)\overrightarrow{AC} - \frac{\lambda}{2}\overrightarrow{AB} +\frac{\lambda}{2}\overrightarrow{AD}\right]^2}$ $= \sqrt{4\left(1 - \frac{3\lambda}{2}\right)^2 + \frac{\lambda^2}{4}\times 4 + \frac{\lambda^2}{4}\times 4 - \lambda^2}$ $= \sqrt{10\lambda^2 - 12\lambda +4}$ $= \sqrt{10\left(\lambda -\frac{3}{5}\right)^2 + \frac{2}{5}},$ 当 $\lambda = \frac{3}{5}$ 时， $|\overrightarrow{EF}|_{\min} = \frac{\sqrt{10}}{5}.$
