> **【解析】**
> （1） $\frac{\pi}{3}$ ；（2） $\left(\frac{9\sqrt{3}}{8},\frac{9\sqrt{3}}{2}\right)$ 解析：（1）解：由已知可得 $\vec{m}\cdot \vec{n} = 2b\sin A - \sqrt{3} a = 0$ ，由正弦定理可得 $2\sin A\sin B - \sqrt{3}\sin A = 0$ ∵ $A$ 、 $B$ 均为锐角，则 $\sin A > 0$ ，故 $\sin B = \frac{\sqrt{3}}{2}$ 因此， $B = \frac{\pi}{3}$ （2）解：由（1）可知， $B = \frac{\pi}{3}$ ，故 $A + C = \frac{2\pi}{3}$ ，又因为 $\frac{a}{\sin A} = \frac{3}{\sin C}$ 所以 $a = \frac{3\sin A}{\sin C} = \frac{3\sin\left(\pi - \frac{\pi}{3} - C\right)}{\sin C} = \frac{3\sin\left(\frac{\pi}{3} + C\right)}{\sin C} = \frac{\frac{3}{2}\sin C + \frac{3\sqrt{3}}{2}\cos C}{\sin C}\\ = \frac{3}{2} +\frac{3\sqrt{3}}{2}\cdot \frac{1}{\tan C}$ 又因为 $0 <   C <   \frac{\pi}{2},0 <   \pi -\frac{\pi}{3} -C <   \frac{\pi}{2}$ ，所以 $\frac{\pi}{6} <  C <   \frac{\pi}{2}$ 故 $\tan C > \frac{\sqrt{3}}{3}$ 即有 $0 <   \frac{1}{\tan C} <   \sqrt{3}$ ，则 $\frac{3}{2} <  a <   6$ 又由 $S_{\triangle ABC} = \frac{1}{2} ac\sin B = \frac{1}{2}\cdot 3a\cdot \frac{\sqrt{3}}{2} = \frac{3\sqrt{3}}{4} a\in \left(\frac{9\sqrt{3}}{8},\frac{9\sqrt{3}}{2}\right).$ 所以△ABC面积的取值范围是 $\left(\frac{9\sqrt{3}}{8},\frac{9\sqrt{3}}{2}\right)$
