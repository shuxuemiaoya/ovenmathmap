> [!faq]- 必刷题解析
> **【答案】** C
>
> **【解析】**
> ∵ $\overrightarrow{SC} + \overrightarrow{SA} + 2\overrightarrow{BS} = \overrightarrow{SC} + \overrightarrow{SA} - 2\overrightarrow{SB} = (\overrightarrow{SC} - \overrightarrow{SB}) + (\overrightarrow{SA} - \overrightarrow{SB}) = \overrightarrow{BC} + \overrightarrow{BA}, \overrightarrow{SC} - \overrightarrow{SA} = \overrightarrow{AC} = \overrightarrow{BC} - \overrightarrow{BA}, \therefore (\overrightarrow{SC} + \overrightarrow{SA} + 2\overrightarrow{BS}) \cdot (\overrightarrow{SC} - \overrightarrow{SA}) = (\overrightarrow{BC} + \overrightarrow{BA}) \cdot (\overrightarrow{BC} - \overrightarrow{BA}) = \overrightarrow{BC}^{2} - \overrightarrow{BA}^{2} = 0, \therefore |\overrightarrow{BC}| = |\overrightarrow{BA}|$ ，即 BC = BA，∴ $\triangle ABC$ 是等腰三角形。
>
> 故选 **C**.
