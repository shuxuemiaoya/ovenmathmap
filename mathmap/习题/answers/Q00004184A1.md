> **【解析】**
> 详见解析
解析：∵ $\alpha$ 是第一象限角，
∴ $k \cdot 360^{\circ} < \alpha < k \cdot 360^{\circ} + 90^{\circ}(k \in Z)$ （\*）
∴ $k \cdot 720^{\circ} < 2\alpha < k \cdot 720^{\circ} + 180^{\circ}(k \in Z)$ .
故 $2\alpha$ 是第一或第二象限角或是终边重合于 y 轴的非负半轴的角.
由（\*）得 $k\cdot 180^{\circ} < \frac{\alpha}{2} < k\cdot 180^{\circ} + 45^{\circ}(k\in Z)$ ①当 $k$ 为偶数时，令 $k = 2n(n\in Z)$ 得 $n\cdot 360^{\circ} <   \frac{\alpha}{2} <  n\cdot 360^{\circ} + 45^{\circ}(n\in Z)$ ，这表明 $\frac{\alpha}{2}$ 是第一象限角.
> - **②**：当 $k$ 为奇数时，令 $k = 2n + 1(n\in Z)$ 得 $n\cdot 360^{\circ} + 180^{\circ} <   \frac{\alpha}{2} <  n\cdot 360^{\circ} + (180^{\circ} + 45^{\circ})(n\in Z)$ ，这表明 $\frac{\alpha}{2}$ 是第三象限角.
综合①②知， $\frac{\alpha}{2}$ 是第一或第三象限角.
由（\*）得 $k\cdot 120^{\circ} <   \frac{\alpha}{3} <  k\cdot 120^{\circ} + 30^{\circ}(k\in Z)$ .
> - **①**：当 $k = 3n(n\in Z)$ 时， $n\cdot 360^{\circ} <   \frac{\alpha}{3} <  n\cdot 360^{\circ} + 30^{\circ}(n\in Z)$ ，这表明 $\frac{\alpha}{3}$ 是第一象限角.
> - **②**：当 $k = 3n + 1(n\in Z)$ 时， $n\cdot 360^{\circ} + 120^{\circ} <   \frac{\alpha}{3} <  n\cdot 360^{\circ} + 150^{\circ}(n\in Z)$ ，这表明 $\frac{\alpha}{3}$ 是第二象限角.
> - **③**：当 $k = 3n + 2(n\in Z)$ 时， $n\cdot 360^{\circ} + 240^{\circ} <   \frac{\alpha}{3} <  n\cdot 360^{\circ} + 270^{\circ}(n\in Z)$ ，这表明是第三象限角.
综合①②③知，是第一或第二或第三象限角.
解析：
如图, 将每个象限二等分, 再从 x 轴的非负半轴的上方起, 依次将各区域标上 I, II, III, IV, 则标号为 IV 的区域即为 $\frac{\alpha}{2}$ 的终边所在的区域, 可知 $\frac{\alpha}{2}$ 的终边所在的象限为第二或第四象限.
