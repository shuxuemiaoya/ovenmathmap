> **【解析】**
> 证明见解析
解析： $2\sin B = 2\sin (A + C) = 4\sin \frac{A + C}{2}\cos \frac{A + C}{2}$ ①， $\sin A + \sin C = \sin \left(\frac{A + C}{2} + \frac{A - C}{2}\right) + \sin \left(\frac{A + C}{2} - \frac{A - C}{2}\right) = 2\sin \frac{A + C}{2}\cos \frac{A - C}{2}$ ②，
> - **①**：，②两式相等，因此有 $2\cos \frac{A + C}{2} = \cos \frac{A - C}{2}$ 化简得 $\cos \frac{A}{2}\cos \frac{C}{2} = 3\sin \frac{A}{2}\sin \frac{C}{2}$ 即 $\tan \frac{A}{2}\tan \frac{C}{2} = \frac{1}{3}$ . 所以原等式得证.
