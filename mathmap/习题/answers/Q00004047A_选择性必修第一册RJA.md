> **【解析】**
> 【解】(1)将四个点的坐标代入抛物线方程解得 $p$ 的值分别为 $p_1 = -\frac{1}{2}, p_2 = \frac{1}{2}, p_3 = \frac{\sqrt{6}}{12}, p_4 = \frac{1}{2}$ , 巧思: 由于抛物线方程中只有一个参数 $p$ , 四点中两点在抛物线上, 易求出 $p$ , 故从抛物线方程出发解题
注意到 $P_{2}(1, - 1), P_{4}(9,3)$ 对应的 $p$ 一样，所以 $P_{2}(1, - 1), P_{4}(9,3)$ 在抛物线上，故抛物线 $E$ 的方程为 $y^{2} = x$ 故 $P_{1}(-2,\sqrt{2}), P_{3}(\sqrt{6}, - 1)$ 为椭圆上的点，则 $\left\{ \begin{array}{l} \frac{6}{a^2} + \frac{1}{b^2} = 1, \\ \frac{4}{a^2} + \frac{2}{b^2} = 1 \end{array} \right. \Rightarrow \left\{ \begin{array}{l} a^2 = 8, \\ b^2 = 4, \end{array} \right.$ 故椭圆 $C$ 的方程为 $\frac{x^2}{8} + \frac{y^2}{4} = 1.$ (2) $\frac{1}{k_1k_2} + m^2$ 是定值，理由如下：设 $A(x_1,y_1), B(x_2,y_2)$ ，则 $\left\{ \begin{array}{l} x = my + 3, \\ y^2 = x \end{array} \right. \Rightarrow y^2 -my - 3 = 0$ ，由根与系数的关系得 $\left\{ \begin{array}{l} y_1 + y_2 = m, \\ y_1y_2 = -3, \end{array} \right.$ 又因为 $x_{1} = my_{1} + 3$ 所以 $k_{1} = \frac{y_{1} - 0}{x_{1} + 3} = \frac{y_{1}}{my_{1} + 3 + 3} = \frac{y_{1}}{my_{1} + 6}$ 同理 $k_{2} = \frac{y_{2}}{my_{2} + 6}$ 所以 $\frac{1}{k_1k_2} + m^2 = \frac{(my_1 + 6)(my_2 + 6)}{y_1y_2} +m^2 = 2m^2 +\frac{36}{y_1y_2}+$ $\frac{6m(y_1 + y_2)}{y_1y_2} = 2m^2 +\frac{36}{-3} +\frac{6m\cdot m}{-3} =$ -12，所以 $\frac{1}{k_1k_2} +m^2$ 为定值-12.
