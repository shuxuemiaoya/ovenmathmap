> **【解析】**
> 证明见解析
解析: 证明: 由题意得 $A + B + C = \pi$ ，且三角形不是直角三角形，
所以 $\tan A = \tan(\pi - B - C) = -\tan(B + C) = -\frac{\tan B + \tan C}{1 - \tan B \tan C}$ 所以 $-\tan A(1-\tan B\tan C)=\tan B+\tan C$ 所以 $-\tan A + \tan A\tan B\tan C = \tan B + \tan C$ 所以 $\tan A + \tan B + \tan C = \tan A\tan B\tan C$ .
