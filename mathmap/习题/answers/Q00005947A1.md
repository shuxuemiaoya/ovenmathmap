> [!faq]- 全练一本通解析
> **【解析】**
> 证明见解析
解析:如图
![](../../../../../images/answers/42e26a91914c2584015fe73abf4eea071def6a132b4a54d98b8cf0e97c176bcf.jpg)
记 AC, CD, AD 的中点分别为 E, F, H；连接 EF, FH, HE；连接 BE, BF, BH；
因为 M, G 分别为 $\triangle ABC$ 、 $\triangle BCD$ 的重心，
所以 $\frac{BM}{BE} = \frac{BG}{BF} = \frac{2}{3}$ ，所以 MG // EF，
因为 $MG \not\subset$ 平面 ACD， $EF \subset$ 平面 ACD，
所以 MG // 平面 ACD.
同理 GN // 平面 ACD，
又 $MG \cap GN = G, MG, GN \subset$ 平面 MNG，
所以平面 MNG // 平面 ACD.
