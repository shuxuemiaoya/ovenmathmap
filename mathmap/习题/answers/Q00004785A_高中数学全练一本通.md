> **【解析】**
> $\overline{\mathcal {C A}}$ 解析：因为在梯形 $ABCD$ 中， $AD // BC, AC$ 与 $BD$ 交于点 $O$ ，
故 $\overline{\mathcal {B A}} - \overline{\mathcal {B C}} - \overline{\mathcal {O A}} + \overline{\mathcal {O D}} + \overline{\mathcal {D A}}$ $= \overline{\mathcal {C A}} + \overline{\mathcal {A O}} + \overline{\mathcal {O D}} + \overline{\mathcal {D A}} = \overline{\mathcal {C O}} + \overline{\mathcal {O D}} + \overline{\mathcal {D A}} = \overline{\mathcal {C D}} + \overline{\mathcal {D A}} = \overline{\mathcal {C A}}$
即 $\overrightarrow{BA}-\overrightarrow{BC}-\overrightarrow{OA}+\overrightarrow{OD}+\overrightarrow{DA}=\overrightarrow{CA}$
