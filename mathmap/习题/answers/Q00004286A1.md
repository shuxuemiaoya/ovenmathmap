> **【解析】**
> 解析：①因为在 $\triangle ABC$ 中， $A + B + C = \pi$ ，
所以 $\sin (A + B) + \sin C = \sin (\pi - C) + \sin C = \sin C + \sin C = 2\sin C$ ；
> - **②**：因为在 $\triangle ABC$ 中， $A + B + C = \pi$ ， $\cos (A + B) + \cos C = \cos (\pi - C) + \cos C = -\cos C + \cos C = 0$ ；
> - **③**：$\sin (2A + 2B) + \sin 2C = \sin [2(A + B)] + \sin 2C = \sin [2(\pi - C)] + \sin 2C = \sin (2\pi - 2C) + \sin 2C = -\sin 2C + \sin 2C = 0$ ；
> - **④**：$\cos (2A + 2B) + \cos 2C = \cos [2(A + B)] + \cos 2C = \cos [2(\pi - C)] + \cos 2C = \cos (2\pi - 2C) + \cos 2C = \cos 2C + \cos 2C = 2\cos 2C$ ．故选：B.
$$
\because A + B + C = \pi , \therefore A + B - C = \pi - 2 C, A - B + C = \pi - 2 B
$$
解析：∵ $A + B + C = \pi$ ，∴ $A + B - C = \pi - 2C$ 又 $\sin\frac{A+B-C}{2}=\sin\frac{A-B+C}{2}$ ,
∴ $\sin\frac{\pi-2C}{2}=\sin\frac{\pi-2B}{2}$ ,
∴ $\sin\left(\frac{\pi}{2}-C\right)=\sin\left(\frac{\pi}{2}-B\right)$ , ∴ $\cos C = \cos B$ .
又 B, C 为 $\triangle ABC$ 的内角，
∴ C = B，故 $\triangle ABC$ 为等腰三角形.
