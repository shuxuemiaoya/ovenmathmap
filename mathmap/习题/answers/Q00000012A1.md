> [!faq]- 必刷题解析
> **【答案】** C
>
> **【解析】**
> - **对于①**：, $\left\{(x,y)\mid\left\{\begin{aligned}x-y=1,\\ x+y=1\end{aligned}\right.\right\}=$ $\{(1,0)\}=M.$ 对于②, $\{(x,y)\mid y=\sqrt{x-1}+\sqrt{1-x}\}$ 中 $\left\{\begin{aligned}x-1&\geqslant0,\\ 1-x&\geqslant0,\end{aligned}\right.$ 解得 x=1，故 $\{(x,y)\mid y=\sqrt{x-1}+\sqrt{1-x}\}=\{(1,0)\}=M.$
> - **对于③**：, 当 n 为奇数时, x = -1; 当 n 为偶数时, x = 0, 所以 $\left\{x \mid x = \frac{(-1)^{n} - 1}{2}, n \in \mathbf{N}\right\} = \{-1, 0\} \neq M.$ 对于④, $\{x\mid-1<x<2,x\in N\}=\{0,1\}\neq M.$ 所以与 M 相等的集合的个数为 2.
>
> 故选 **C**.
