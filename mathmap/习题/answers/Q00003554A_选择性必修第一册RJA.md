> **【解析】**
> 【解】(1)由 $SC \perp$ 平面 ABC，且 $\angle ACB = 90^{\circ}$ ，可得 AC, BC, SC 两两垂直，
如图，以 C 为坐标原点，AC, BC, SC 所在直线分别为 x, y, z 轴建立空间直角坐标系.
![](../../../../../../images/answers/part-001/4943f0ad07c8be7b5a5b901c4673583e3dc7543ac1da74cdfd5068510a982047.jpg)
设 $SC = 2a(a > 0)$ ，则 $A(1,0,0),B(0,$ $2,0),C(0,0,0),S(0,0,2a),M(0,1,$ $a),P(0,0,a)$ ，
可得 $\overrightarrow{AM} = (-1,1,a),\overrightarrow{CS} = (0,0,2a)$ 所以 $|\cos \langle \overrightarrow{AM},\overrightarrow{CS}\rangle | = \frac{|\overrightarrow{AM}\cdot\overrightarrow{CS}|}{|\overrightarrow{AM}||\overrightarrow{CS}|} =$ $\frac{2a^2}{\sqrt{2 + a^2}\times 2a} = \frac{1}{2}$ 解得 $a = \frac{\sqrt{6}}{3}$ （负值舍去），
所以 $SC = 2a = \frac{2\sqrt{6}}{3}$ （2）由（1）可得 $\overrightarrow{AP} = \left(-1,0,\frac{\sqrt{6}}{3}\right)$ $\overrightarrow{PM} = (0,1,0),\overrightarrow{CM} = \left(0,1,\frac{\sqrt{6}}{3}\right)$ 设平面AMP的法向量为 $\pmb {n} = (x,y,$ $z)$ ，则 $\left\{ \begin{array}{l}\pmb {n}\cdot \overrightarrow{AP} = -x + \frac{\sqrt{6}}{3} z = 0,\\ \pmb {n}\cdot \overrightarrow{PM} = y = 0, \end{array} \right.$ 令 $x = \sqrt{2}$ ，则 $y = 0,z = \sqrt{3}$ 可得 $\pmb {n} = (\sqrt{2},0,\sqrt{3})$ 则 $\cos \langle \pmb {n},\overrightarrow{CM}\rangle = \frac{\pmb{n}\cdot\overrightarrow{CM}}{|n||\overrightarrow{CM}|} = \frac{\sqrt{2}}{\sqrt{5}\times\frac{\sqrt{5}}{\sqrt{3}}} =$ $\frac{\sqrt{6}}{5}$ 所以直线CM与平面AMP所成角的正弦值为 $\frac{\sqrt{6}}{5}$

> **📝 归纳总结**
> 求空间角的常用方法
(1) 定义法: 由异面直线所成角、线面角、二面角的定义, 结合图形, 作出所求空间角, 再结合题中条件, 解对应三角形, 即可求出结果;
(2) 向量法: 建立适当的空间直角坐标系, 通过计算向量夹角 (直线方向向量与直线方向向量、直线方向向量与平面法向量、平面法向量与平面法向量) 的余弦值, 再进行转化求出结果.
