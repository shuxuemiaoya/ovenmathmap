> [!faq]- 全练一本通解析
> **【解析】**
> （1）证明见解析（2） $\frac{4\sqrt{5}}{5}$
解析：（1）连接 DE，
∵ ABCD 是正方形，E，F 分别是棱 BC，AD 的中点，
∴ DF = BE, DF // BE,
∴ 四边形 BEDF 是平行四边形，∴ DE // BF，
∵ G 是 PA 的中点，∴ FG // PD，
∵ PD, DE ∉ 平面 BFG, FG, BF ⊂ 平面 BFG,
∴ PD // 平面 BFG, DE // 平面 BFG,
∵ PD ∩ DE = D，直线 PD, DE 在平面 PDE 内，
∴ 平面 PDE // 平面 BFG, ∵ PE ⊂ 平面 PDE,
∴ PE// 平面 BFG.
(2) $\because PD \perp$ 平面 ABCD, FG//PD,
∴ FG ⊥ 平面 ABCD，
过 $C$ 在平面ABCD内，作 $CM\perp BF$ ，垂足为 $M$ ，则 $FG\perp CM$ ∵ $FG\cap BF = F$ ，又直线FG,BF在平面BFG内，
∴ CM⊥平面 BFG，
∴ CM 的长是点 C 到平面 BFG 的距离,
∵ $\triangle BCF$ 中， $FB = CF = \sqrt{5}$ ，
∴由等面积可得 $CM=\frac{2\times2}{\sqrt{5}}=\frac{4\sqrt{5}}{5}$ ,
∴点 C 到平面 BFG 的距离为 $\frac{4\sqrt{5}}{5}$ .
