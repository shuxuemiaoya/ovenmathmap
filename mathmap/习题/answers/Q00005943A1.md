> [!faq]- 全练一本通解析
> **【解析】**
> 当 M 是 AC 的中点时，MB // 平面 AEF.
解析:证明:过 F, B, M 作平面 FBMN 交 AE 于点 N, 连接 MN, NF,
易知 BF // 平面 $AA_{1}C_{1}C$ , 又 $BF \subset$ 平面 FBMN,
平面 FBMN ∩ 平面 $AA_{1}C_{1}C = MN$ , 所以 BF // MN.
又 MB // 平面 AEF, MB ⊂ 平面 FBMN,
平面 FBMN ∩ 平面 AEF = FN, 所以 MB // FN,
所以四边形 BFNM 是平行四边形,
所以 MN = BF = 1.
而 EC // FB, EC = 2FB = 2,
所以 MN // EC, MN = $\frac{1}{2}EC$ ,
故 MN 是 $\triangle ACE$ 的中位线.
所以当 M 是 AC 的中点时，MB // 平面 AEF.
