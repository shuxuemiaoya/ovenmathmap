> **【解析】**
> （1）\(\frac{8}{9}\)；（2）\(\frac{3}{10}\)
解析：（1）\(\frac{\sin \alpha + \cos \alpha}{\sin\alpha - \cos\alpha} = 2\)的分子和分母同除以\(\cos\alpha\)得\(\frac{\tan\alpha + 1}{\tan\alpha - 1} = 2\)，解得\(\tan\alpha = 3\)，
故\(\frac{3\sin\alpha - cos\alpha}{2\sin\alpha + 3cos\alpha} = \frac{3\tan\alpha - 1}{2\tan\alpha + 3} = \frac{9 - 1}{6 + 3} = \frac{8}{9}\);
（2）\(\sin^2\alpha - 2\sin\alpha · cos\alpha = \frac{\sin^2\alpha - 2\sin\alpha · cos\alpha}{\sin^2\alpha + cos^2\alpha} = \frac{\tan^2\alpha - 2\tan\alpha}{\tan^2\alpha + 1} = \frac{9 - 6}{9 + 1} = \frac{3}{10}\)
