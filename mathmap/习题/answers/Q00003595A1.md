> [!faq]- 必刷题解析
> **【答案】** BD
>
> **【解析】**
> 因为 $\boldsymbol{u}=(1,2,-3)$ ， $\boldsymbol{v}=(-2,-4,6)$ ，所以 $v=-2u$ ，所以 $\alpha\parallel\beta$ ，故 A 错误；
因为 $\overrightarrow{AP} = (2, -4, -5) = 2(3, -1, -2) - (4, 2, 1) = 2\overrightarrow{AB} - \overrightarrow{AC}$ ，且 $\overrightarrow{AB}, \overrightarrow{AC}$ 不共线；
所以 $\overrightarrow{AP},\overrightarrow{AB},\overrightarrow{AC}$ 共面，即点 $P$ 在平面 $ABC$ 内，故B正确；因为 $A(0,1,0),B(1,2,0)$ ，所以 $\overrightarrow{AB} = (1,1,0)$ 所以与 $\overrightarrow{AB}$ 方向相同的单位向量是 $\left(\frac{\sqrt{2}}{2},\frac{\sqrt{2}}{2},0\right)$ ，故C错误；
若 $\pmb {a},\pmb {b},\pmb {c}$ 为共面向量，则存在不全为零的实数 $x,y,z$ 使得 $xa + yb + zc = 0$ 故 $\frac{x + y - z}{2} (a + b) + \frac{z + y - x}{2} (b + c) +$ $\frac{x + z - y}{2} (c + a) = 0,$ 而 $\{\pmb {a} + \pmb {b},\pmb {b} + \pmb {c},\pmb {c} + \pmb {a}\}$ 是空间的一个基底，故 $x = y = z = 0$ ，矛盾，故 $\{\pmb {a},\pmb {b},\pmb {c}\}$ 不共面，故 $\pmb {a},\pmb {b},\pmb {c}$ 是空间的一个基底，故D巧思：对任意向量 $d$ ，存在唯一实数 $x,y,z$ 使得 $d = x(a + b) + y(b + c) + z(c+$ a)，则 $d = (x + z)a + (x + y)b + (y + z)c$ 正确.
>
> 故选 **BD**.
