> [!faq]- 全练一本通解析
> **【解析】**
> （1） $C = \frac{\pi}{3};$ （2） $\frac{2\sqrt{6}}{3}$ 解析：（1）由正弦定理得：√3 sinB-√3 sinC cosA=sinAsinC，∴√3 sin(A+C)-√3 sinC cosA=√3 sinAcosC+√3 cosAsinC-√3 sinC cosA=√3 sinAcosC=sinAsinC，∵A∈(0,π)，∴sinA≠0，∴√3 cosC=sinC，即tanC=√3，又C∈(0,π)，∴C=π/3；（2）∵S△ABC=½ab sinC=√3/4 ab=√3，∴ab=4，∴CA·CB=4cosπ/3=2；
$\because \overline{CD} = \overline{CA} + \overline{AD} = \overline{CA} + \frac{1}{3}\overline{AB} = \overline{CA} + \frac{1}{3}\left(\overline{CB} - \overline{CA}\right) = \frac{2}{3}\overline{CA} + \frac{1}{3}\overline{CB},$ $\therefore \left|\overline{CD}\right|^2 = \left(\frac{2}{3}\overline{CA} + \frac{1}{3}\overline{CB}\right)^2 = \frac{4}{9} b^2 + \frac{1}{9} a^2 + \frac{4}{9}\overline{CA} \cdot \overline{CB} = \frac{4}{9} b^2 + \frac{1}{9} a^2 + \frac{8}{9} \geq \frac{4}{9} ab + \frac{8}{9} = \frac{8}{3}$ （当且仅当 $\frac{4}{9} b^2 = \frac{1}{9} a^2$ ，即 $a = 2b = 2\sqrt{2}$ 时取等号）， $\therefore \left|\overline{CD}\right|_{\min} = \frac{2\sqrt{6}}{3}$ ，即 $CD$ 的最小值为 $\frac{2\sqrt{6}}{3}$ .
