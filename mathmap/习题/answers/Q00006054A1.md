> [!faq]- 全练一本通解析
> **【答案】** D
>
> **【解析】**
> 解析: 在棱长为1的正方体 $ABCD-A_{1}B_{1}C_{1}D_{1}$ 中, 取 $AA_{1}$ 中点 G, 连接 $GD_{1}, GF, BD, EF, AF$ , 如图,
![](../../../../../images/answers/a57bfbfcc8f9357c246574f12aafd82a33cbfe75115f4c4aff4dc98286d5eaf9.jpg)
因为 $F$ 为 $BB_{1}$ 的中点，则 $A_{1}G // B_{1}F, A_{1}G = B_{1}F$ ，即有四边形 $A_{1}GFB_{1}$ 为平行四边形，有 $GF // A_{1}B_{1} // D_{1}C_{1}, GF = A_{1}B_{1} = D_{1}C_{1}$ ，则四边形 $GFC_{1}D_{1}$ 为平行四边形，有 $FC_{1} // GD_{1}$ ，又 $E$ 为 $DD_{1}$ 的中点，则 $AG // ED_{1}, AG = ED_{1}$ ，四边形 $AGD_{1}E$ 为平行四边形，则有 $AE // GD_{1} // FC_{1}$ ，因此直线 $FC_{1}$ 到直线 $AE$ 的距离等于点 $F$ 到直线 $AE$ 的距离 $d$ ，因为
$BF // DE, BF = DE$ 则四边形 BDEF 为平行四边形，有 $EF = BD = \sqrt{2}$ ，在 $\triangle AEF$ 中， $AE = AF = \sqrt{AB^{2} + BF^{2}} = \frac{\sqrt{5}}{2}$ ，
边 EF 上的高 $h=\sqrt{AF^{2}-(\frac{1}{2}EF)^{2}}=\frac{\sqrt{3}}{2}$ ，由三角形面积得： $\frac{1}{2}AE\cdot d=\frac{1}{2}EF\cdot h,\quad d=\frac{EF\cdot h}{AE}=\frac{\sqrt{30}}{5}$ 所以直线 $FC_{1}$ 到直线 AE 的距离为 $\frac{\sqrt{30}}{5}$ . 故选：D
