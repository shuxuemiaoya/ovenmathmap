> [!faq]- 全练一本通解析
> **【解析】**
> 作图见解析
解析:如图, 过点 O 作 $EF \parallel PC$ , 分别交 PB, BC 于点 E, F,
![](../../../../../../images/answers/7b38f21855ade31c6f4463386fcea5ad51be2fbf0fc5671f9b0b3b9fef913cd1.jpg)
过点 E 作 $EH \parallel AB$ ，交 PA 于点 H，过点 F 作 $FG \parallel AB$ ，交 AD 于点 G，连接 GH。∴ 截面为四边形 EHGF。
理由如下：
∵ EH // AB, FG // AB, ∴ EH // FG,
∴ E, F, G, H 四点共面.
∵ AB // EH, EH ⊂ 平面 EFGH, AB ≠ 平面 EFGH,
∴ AB // 平面 EFGH.
∵ PC // EF, EF ⊂ 平面 EFGH, PC ≠ 平面 EFGH,
∴ PC // 平面 EFGH.
