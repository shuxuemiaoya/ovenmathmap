> **【解析】**
> （1） $A = \frac{\pi}{6}$ ；（2） $(\sqrt{3} +3,2 + 2\sqrt{3})$ 解析：（1）在锐角△ABC中，由 $\overline{m}\bot \overline{n}$ ，得 $\sin A(2\sin B - \cos C) + \cos A(-\sin C) = 0$ 整理得到： $2\sin A\sin B - \sin A\cos C - \cos A\sin C = 0$ 则 $2\sin A\sin B = \sin B$ ，而 $B\in (0,\frac{\pi}{2})$ ，即 $\sin B > 0$ ，于是 $\sin A = \frac{1}{2}$ 而 $A\in (0,\frac{\pi}{2})$ ，所以 $A = \frac{\pi}{6}$ （2）在锐角△ABC中，由正弦定理得 $\frac{a}{\sin A} = \frac{c}{\sin C} = \frac{b}{\sin B},$ $a + c = \frac{2}{\sin B} (\sin A + \sin C) = \frac{2}{\sin B} [\frac{1}{2} +\sin (\frac{5\pi}{6} -B)] = \frac{2}{\sin B} (\frac{1}{2} +\frac{1}{2}\cos B + \frac{\sqrt{3}}{2}\sin$ $= \sqrt{3} +\frac{1 + \cos B}{\sin B} = \sqrt{3} +\frac{2\cos^2\frac{B}{2}}{2\sin\frac{B}{2}\cos\frac{B}{2}} = \sqrt{3} +\frac{1}{\tan\frac{B}{2}},$ 由△ABC为锐角三角形，得 $\left\{ \begin{array}{l}0 <   B <   \frac{\pi}{2}\\ 0 <   \frac{5\pi}{6} -B <   \frac{\pi}{2} \end{array} \right.$ ，即 $\frac{\pi}{3} <  B <   \frac{\pi}{2},$ 则 $\frac{\pi}{6} <   \frac{B}{2} <   \frac{\pi}{4}$ ，于是 $\frac{\sqrt{3}}{3} <  \tan \frac{B}{2} <  1$ ，从而 $\sqrt{3} +1 <   a + c <   2\sqrt{3}$ 所以周长的取值范围为 $(\sqrt{3} +3,2 + 2\sqrt{3})$
