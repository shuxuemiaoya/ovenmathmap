17. 已知 $0 < x < 1, 0 < y < 1$ .  
（1）求证： $\sqrt{x^2 + y^2} +\sqrt{x^2 + (1 - y)^2} +\sqrt{(1 - x)^2 + y^2} +\sqrt{(1 - x)^2 + (1 - y)^2}\geqslant 2\sqrt{2}$ ，并求使等式成立的条件.  
（2） 说明上述不等式的几何意义.
