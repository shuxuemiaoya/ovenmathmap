> [!faq]- 全练一本通解析
> **【解析】**
> （1） $\vec{c} = -3\vec{a} + 2\vec{b}$ ；（2） $k = -\frac{2}{3}$ ，反向， $|\vec{a} + k\vec{b}| = \frac{\sqrt{41}}{3}$ 。
解析：（1）设 $\vec{c} = x\vec{a} + y\vec{b}$ ，依题意， $(-5, -4) = x(1, 2) + y(-1, 1) = (x - y, 2x + y)$ ，从而 $\begin{cases} x - y = -5 \\ 2x + y = -4 \end{cases}$ ，解得 $\begin{cases} x = -3 \\ y = 2 \end{cases}$ ，
所以 $\vec{c} = -3\vec{a} + 2\vec{b}$ 。
（2）依题意， $\vec{a} + k\vec{b} = (1 - k, 2 + k)$ ，而 $\vec{c} = (-5, -4)$ ，由 $(\vec{a} + k\vec{b}) // \vec{c}$ ，得 $\frac{1 - k}{-5} = \frac{2 + k}{-4}$ ，解得 $k = -\frac{2}{3}$ ，此时 $\vec{a} + k\vec{b} = (\frac{5}{3}, \frac{4}{3})$ 与 $\vec{c}$ 反向，
所以 $|\vec{a} + k\vec{b}| = \sqrt{\left(\frac{5}{3}\right)^2 + \left(\frac{4}{3}\right)^2} = \frac{\sqrt{41}}{3}$ 。
