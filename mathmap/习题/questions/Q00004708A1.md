> 解析：方法一：原函数卡根 由 $x \in \left(\frac{\pi}{2}, \pi\right)$ 可得 $\pi\omega + \frac{\pi}{3} \leq 2\omega x + \frac{\pi}{3} \leq 2\pi\omega + \frac{\pi}{3}$ ，结合原函数单调区间，得 $\left\{ \begin{array}{l} 2\pi\omega + \frac{\pi}{3} \leq \frac{\pi}{2} + k\pi \\ \pi\omega + \frac{\pi}{3} \geq -\frac{\pi}{2} + k\pi \end{array} \right.$ 解得 $-\frac{5}{6} + k \leq \omega \leq \frac{1}{12} + \frac{k}{2}$ ①，因为 $f(x)$ 在区间 $\left(\frac{\pi}{2}, \pi\right)$ 上单调递增，故 $T = \frac{2\pi}{2\omega} \geq 2\left(\pi - \frac{\pi}{2}\right) = \pi$ ，所以 $0 < \omega \leq 1$ ②

当 $k = 0$ 时，结合①②得 $0 < \omega \leq \frac{1}{12}$ ；
当 $k = 1$ 时，得 $\frac{1}{6} \leq \omega \leq \frac{7}{12}$ ；综上， $\omega$ 的取值范围为 $0 < \omega \leq \frac{1}{12}$ 或 $\frac{1}{6} \leq \omega \leq \frac{7}{12}$ ，故选：C
方法二：现函数卡根
因为 $g(x) = \sin \left(2\omega x + \frac{\pi}{3}\right)(\omega > 0)$ ，
令 $-\frac{\pi}{2} + k\pi \leq 2\omega x + \frac{\pi}{3} \leq \frac{\pi}{2} + k\pi, (k \in \mathbb{Z})$ （没有具体说明增减性，所以以半个周期为单位），可得单调区间 $-\frac{5\pi}{12\omega} + \frac{k\pi}{2\omega} \leq x \leq \frac{\pi}{12\omega} + \frac{k\pi}{2\omega}, (k \in \mathbb{Z})$ ， $\because$ 函数 $g(x) = \sin \left(2\omega x + \frac{\pi}{3}\right)(\omega > 0)$ 在区间 $\left(\frac{\pi}{2}, \pi\right)$ 上是单调的， $\therefore \frac{1}{2} T \geq \frac{\pi}{2}$ ，即 $\frac{1}{2} \cdot \frac{2\pi}{2\omega} \geq \frac{\pi}{2}$ 即 $0 < \omega \leq 1$ ，
函数 $g(x) = \sin \left(2\omega x + \frac{\pi}{3}\right)(\omega > 0)$ 在区间 $\left(\frac{\pi}{2}, \pi\right)$ 上是单调的，
所以 $\left\{ -\frac{5\pi}{12\omega} + \frac{k\pi}{2\omega} \leq \frac{\pi}{2}, \text{解 } \frac{6k - 5}{6} \leq \omega \leq \frac{6k + 1}{12} (k \in \mathbb{Z}), \right.$ 又 $0 < \omega \leq 1$ ，所以当 $k = 0$ 或 $k = 1$ 成立，可得 $0 < \omega \leq \frac{1}{12}$ 或 $\frac{1}{6} \leq \omega \leq \frac{7}{12}$ ，故选：C.
