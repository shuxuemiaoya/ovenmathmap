> [!faq]- 全练一本通解析
> **【解析】**
> （1）第一象限角；（2）第二或第三象限角；（3）第二或第四象限角；（4）第一或第二象限角.解析：(1) $\because \sin \alpha >0$ ， $\tan \alpha = \frac{\sin\alpha}{\cos\alpha} >0$ ，∴cos $\alpha >0$ ，由 $\left\{ \begin{array}{l}\sin \alpha >0\\ \cos \alpha >0 \end{array} \right.$ 知： $\alpha$ 为第一象限角；
(2) $\because \tan \alpha \sin \alpha = \frac{\sin^2\alpha}{\cos\alpha} < 0, \therefore \cos \alpha < 0, \therefore \alpha$ 是第二或第三象限角；
（3）∵ $\sin\alpha$ 与 $\cos\alpha$ 异号，即 $\left\{\begin{aligned}\sin\alpha&>0\\ \cos\alpha&<0\end{aligned}\right.$ 或 $\left\{\begin{aligned}\sin\alpha&<0\\ \cos\alpha&>0\end{aligned}\right.$ ，∴ $\alpha$ 是第二或第四象限角；
(4) $\because \cos \alpha$ 与 $\tan \alpha$ 同号, 即 $\left\{ \begin{array}{l} \tan \alpha > 0 \\ \cos \alpha > 0 \end{array} \right.$ 或 $\left\{ \begin{array}{l} \tan \alpha < 0 \\ \cos \alpha < 0 \end{array} \right., \therefore \alpha$ 是第一或第二象限角.
