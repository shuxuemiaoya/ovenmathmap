> **【解析】**
> 以点 $A$ 为坐标原点， $AB$ ， $AD,AA_{1}$ 所在直线分别为 $x,y,z$ 轴建立如图所示的空间直角坐标系，设 $AB = 2$ ，则 $A(0,0,0),B(2,0,0),C(2,2,0),D(0,2,0),A_{1}(0,0,2),B_{1}(2,0,2),C_{1}(2,2,2),D_{1}(0,2,2),E(2,1,0),F(1,2,0).$ 设平面 $A_{1}EC_{1}$ 的法向量为 $\pmb {m} = (x_1,y_1,z_1),\overrightarrow{A_1C_1} = (2,2,0),\overrightarrow{EC_1} = (0,1,2)$ 则 $\left\{ \begin{array}{l}\pmb {m}\cdot \overrightarrow{A_1C_1} = 2x_1 + 2y_1 = 0,\\ \pmb {m}\cdot \overrightarrow{EC_1} = y_1 + 2z_1 = 0, \end{array} \right.$ 取 $x_{1} = 2,$ 可得 $\pmb {m} = (2, - 2,1)$ 设平面 $AFD_{1}$ 的法向量为 $\pmb {n} = (x_{2},y_{2},z_{2}),\overrightarrow{AF} = (1,2,0),\overrightarrow{AD_1} = (0,2,2)$ 则 $\left\{ \begin{array}{ll}\pmb {n}\cdot \overrightarrow{AF} = x_2 + 2y_2 = 0,\\ \pmb {n}\cdot \overrightarrow{AD_1} = 2y_2 + 2z_2 = 0, \end{array} \right.$ 取 $x_{2} = 2$ ，则 $\pmb {n} = (2, - 1,1).$ 对于A选项， $\overrightarrow{AF}\cdot \pmb {m} = -2\neq 0,\mathrm{A}$ 错误；对于B选项， $\overrightarrow{D_1F} = (1,0, - 2),\overrightarrow{D_1F}\cdot$ $\pmb {m} = 0$ ，且 $D_{1}F\not\subset$ 平面 $A_{1}EC_{1}$ ，则 $D_{1}F / /$ 平面 $A_{1}EC_{1},\mathrm{B}$ 正确；对于C选项， $\overrightarrow{A_1C_1}\cdot \pmb {n} = 2\neq 0,\mathrm{C}$ 错误；对于D选项， $\overrightarrow{A_1E} = (2,1, - 2),\overrightarrow{A_1E}\cdot \pmb {n} =$ $4 - 1 - 2 = 1\neq 0,\mathrm{D}$ 错误故选B.
