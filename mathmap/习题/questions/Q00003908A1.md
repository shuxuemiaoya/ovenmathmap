> [!faq]- 必刷题解析
> **【答案】** BCD
>
> **【解析】**
> 对于 A, ∵ 椭圆 $C: \frac{x^{2}}{25} + \frac{y^{2}}{9} = 1, \therefore a^{2} = 25, b^{2} = 9, c = \sqrt{a^{2} - b^{2}} = 4, |PF_{1}| + |PF_{2}| = 2a = 10, |F_{1}F_{2}| = 8, \therefore \triangle F_{1}PF_{2}$ 的周长为 $|PF_{1}| + |PF_{2}| + |F_{1}F_{2}| = 18$ , 故 A 错误;
对于 B, ∵ $\angle F_{1}PF_{2}=90^{\circ}, \therefore |PF_{1}|^{2}+|PF_{2}|^{2}=|F_{1}F_{2}|^{2}=4c^{2}=64,$ ∵ $|PF_{1}|+|PF_{2}|=2a=10, \therefore |PF_{1}|^{2}+|PF_{2}|^{2}+2|PF_{1}|\cdot|PF_{2}|=100,$ ∴ $|PF_{1}||PF_{2}|=18,$ ∴ $\triangle F_{1}PF_{2}$ 的面积为 $\frac{1}{2}|PF_{1}||PF_{2}|=\frac{1}{2}\times18=9$ ，故 B 正确；
对于 C，由题意知 $F_{1}(-4,0), F_{2}(4,0), A(-5,0), B(5,0)$ ，设 $P(x,y)$ ，
则 $\overrightarrow{PF_{1}}\cdot\overrightarrow{PF_{2}}-\overrightarrow{PA}\cdot\overrightarrow{PB}=(-x-4,-y)\cdot(4-x,-y)-(-x-5,-y)\cdot(5-x,-y)=x^{2}-16+y^{2}-(x^{2}-25+y^{2})=9$ ，为定值，故 C 正确；
对于 D，设 $P(x_{0},y_{0})(x_{0}\neq\pm5)$ ，则 $k_{PA}=\frac{y_{0}}{x_{0}+5}, k_{PB}=\frac{y_{0}}{x_{0}-5}, \therefore k_{PA}\cdot k_{PB}=\frac{y_{0}^{2}}{x_{0}^{2}-25}, \because P(x_{0},y_{0})$ 在椭圆 C 上，
∴ $\frac{x_{0}^{2}}{25}+\frac{y_{0}^{2}}{9}=1$ ，即 $y_{0}^{2}=-\frac{9}{25}(x_{0}^{2}-25)$ ，
代入可得 $k_{PA}\cdot k_{PB}=-\frac{9}{25}$ ，故 D 正确。
>
> 故选 **BCD**.
