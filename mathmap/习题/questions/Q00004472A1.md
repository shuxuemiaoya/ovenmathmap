> **【解析】**
> 等腰三角形
解析: 因为 $1 + \cos C = 1 + \cos (\pi - A - B) = 1 - \cos (A + B)$ $= 1 - \cos A \cos B + \sin A \sin B = 2 \sin A \sin B$ 所以 $\sin A \sin B + \cos A \cos B = 1$ ，即 $\cos(A - B) = 1$ .
又 $0 < A < \pi, 0 < B < \pi$ , 得 $-\pi < A - B < \pi$ ,
所以 A-B=0，即 A=B，所以 $\triangle ABC$ 是等腰三角形.
