> **【解析】**
> 【解】(1)抛物线 $E:y^{2} = 4x$ 的焦点 $F(1,0)$ 当 $k = 1$ 时，直线 $l:y = x - 1$ 联立 $\left\{ \begin{array}{ll}y^{2} = 4x,\\ y = x - 1, \end{array} \right.$ 消去 $y$ 得 $x^{2} - 6x + 1 = 0,$ $\Delta = 32 > 0$ ，所以设点 $A(x_{1},y_{1}),$ $B(x_{2},y_{2}),M(x_{0},y_{0})$ 则 $x_{1} + x_{2} = 6,x_{1}x_{2} = 1,$ 则 $x_0 = \frac{x_1 + x_2}{2} = \frac{6}{2} = 3,y_0 = x_0 - 1 = 3 - 1 =$ 2，所以点 $M$ 的坐标为(3,2).由过焦点的弦长公式得 $|AB| = x_1 + x_2+$ $2 = 8.$ (2)直线 $l:y = k(x - 1)(k\neq 0)$ 联立 $\left\{ \begin{array}{ll}y^2 = 4x,\\ y = k(x - 1), \end{array} \right.$ 消去 $y$ 得 $k^2 x^2-$ $(2k^2 +4)x + k^2 = 0,\Delta = 16(k^2 +1) > 0,$ 设 $A(x_{1},y_{1}),B(x_{2},y_{2})$ 则 $x_{1} + x_{2} = \frac{2k^{2} + 4}{k^{2}},x_{1}x_{2} = 1,$ 因为 $x_{1}y_{2} + x_{2}y_{1} = 2kx_{1}x_{2} - k(x_{1}+$ $x_{2}) = -\frac{4}{k},$ $k_{1} + k_{2} = \frac{y_{1}}{x_{1}} +\frac{y_{2}}{x_{2}} = \frac{x_{1}y_{2} + x_{2}y_{1}}{x_{1}x_{2}} = -\frac{4}{k} = 1,$ 解得 $k = -4$ ，所以 $l$ 的方程为 $y =$ $-4x + 4.$
