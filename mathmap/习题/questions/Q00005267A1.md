> **【解析】**
> （1）A=2B，证明见解析；（2）(2,6)
解析：（1）等量关系为A=2B。
证明如下：
因为 $a^{2}=b(b+c)$ ，由余弦定理得 $\cos A=\frac{b^{2}+c^{2}-a^{2}}{2bc}=\frac{c^{2}-bc}{2bc}=\frac{c-b}{2b}$ ，
即 $2b\cos A=c-b$ ，
又由正弦定理，可得 $2\sin B\cos A=\sin C-\sin B$ ，
因为 $A+B+C=\pi$ ，所以 $2\sin B\cos A=\sin(A+B)-\sin B$ ，
即 $2\sin B\cos A = \sin B\cos A + \cos B\sin A - \sin B$ 整理得 $\sin B = -\sin B\cos A + \cos B\sin A$ ，所以 $\sin B = \sin (A - B)$ 又因为 $A,B\in (0,\pi)$ ，所以 $A - B\in (-\pi ,\pi)$ ，所以 $B = A - B$ ，所以 $A = 2B$ （2）由 $\frac{a}{\sin A} = \frac{b}{\sin B} = \frac{c}{\sin C}$ 及 $b = 1$ 可得 $a + c = \frac{b\sin A}{\sin B} +\frac{b\sin C}{\sin B} = \frac{\sin A + \sin(A + B)}{\sin B} = \frac{\sin 2B + \sin 3B}{\sin B}$ $= \frac{2\sin B\cos B + 4\sin B\cos^2B - \sin B}{\sin B},$ 所以 $a + c = 2\cos B + 4\cos^2 B - 1$ 因为 $A = 2B$ ，所以 $0 <   B <   \frac{\pi}{3}$ ，所以 $\frac{1}{2} <  \cos B <   1$ ，所以 $1 <   a + c <   5$ 所以△ABC周长的取值范围是(2,6).
