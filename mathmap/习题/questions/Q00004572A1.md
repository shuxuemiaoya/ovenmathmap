> **【解析】**
> (√2,3)
解析: $B = A + \frac{\pi}{2}$ , 所以 $C = \pi - A - B = \frac{\pi}{2} - 2A$ ,
又 $\cos A = \sin B$ , 所以 $\cos A + \sin B + \sin C = 2\sin B + \sin C = 2\sin\left(A + \frac{\pi}{2}\right) + \sin\left(\frac{\pi}{2} - 2A\right)$ $= 2\cos A + \cos 2A = 2\cos^2A + 2\cos A - 1 = 2\left(\cos A + \frac{1}{2}\right)^2 - \frac{3}{2}$ ,
因为 $\left\{ \begin{array}{l} 0 < A < \pi \\ 0 < B = A + \frac{\pi}{2} < \pi \\ 0 < C = \frac{\pi}{2} - 2A < \pi \end{array} \right.$ , 所以 $0 < A < \frac{\pi}{4}$ , 所以 $\frac{\sqrt{2}}{2} < \cos A < 1$ , $\left\{ \begin{array}{l} 0 < A < \pi \\ 0 < B = A + \frac{\pi}{2} < \pi \\ 0 < C = \frac{\pi}{2} - 2A < \pi \end{array} \right.$
因为函数  \( y=2\left(\cos A+\frac{1}{2}\right)^{2}-\frac{3}{2} \)  在  \( \cos A\in\left(\frac{\sqrt{2}}{2},1\right) \)  单调递增，
所以  \( 2\left(\frac{\sqrt{2}}{2}+\frac{1}{2}\right)^{2}-\frac{3}{2}=\sqrt{2}<2\left(\cos A+\frac{1}{2}\right)^{2}-\frac{3}{2}<2\left(1+\frac{1}{2}\right)^{2}-\frac{3}{2}=3 \)
所以  \( \cos A + \sin B + \sin C \)  的取值范围为  \( (\sqrt{2},3) \) .
