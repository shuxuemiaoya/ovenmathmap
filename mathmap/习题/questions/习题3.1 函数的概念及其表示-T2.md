2. 下列哪一组中的函数 $f(x)$ 与 $g(x)$ 是同一个函数?  
（1） $f(x) = x - 1, g(x) = \frac{x^2}{x} - 1;$   
（2） $f(x) = x^{2}, g(x) = (\sqrt{x})^{4}$ ;   
（3） $f(x) = x^{2}, g(x) = \sqrt[3]{x^{6}}.$
