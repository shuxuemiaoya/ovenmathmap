## 题型 1: 确定 n 分角和 n 倍角的象限

1. $n\alpha$ 所在象限的判断方法:

确定 $n\alpha$ 终边所在的象限, 先求出 $n\alpha$ 的范围, 再直接转化为终边相同的角即可.

2. $\frac{\alpha}{n}$ 所在象限的判断方法:

已知角 $\alpha$ 所在象限, 要确定角 $\frac{\alpha}{n}$ 所在象限, 有两种方法:

解法 1:用不等式表示出角 $\frac{\alpha}{n}$ 的范围, 然后对 k 的取值分情况讨论: 被 n 整除; 被 n 除余 1; 被 n 除余 2; ...; 被 n 除余 n-1. 从而得出结论;

解法 2:作出各个象限的从原点出发的 n 等分射线, 它们与坐标轴把周角分成 4n 个区域. 从 x 轴非负半轴起, 按逆时针方向把这 4n 个区域依次循环标上 1, 2, 3, 4. $\alpha$ 的终边在第几象限, 则标号为几的区域, 就是 $\frac{\alpha}{n}$ 的终边所落在的区域. 如此, $\frac{\alpha}{n}$ 所在的象限就可以由标号区域所在的象限直观地看出.
