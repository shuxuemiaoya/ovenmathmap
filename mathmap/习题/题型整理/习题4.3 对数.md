#### 2. 选择题  

（1）使式子 $\log_{(2x - 1)}(2 - x)$ 有意义的 $x$ 的取值范围是（ ）.

(A) $x > 2$

(B) $x <   2$

(C) $\frac{1}{2} < x < 2$

(D) $\frac{1}{2} < x < 2$ ，且 $x \neq 1$  
（2） 若 $\lg a (a > 0)$ 与 $\lg b (b > 0)$ 互为相反数，则（ ）.

(A) $a + b = 0$

(B) $a - b = 0$

(C) ab=1

(D) $\frac{a}{b} = 1$

（4） $2\log_{5}25 - 3\log_{2}64;$  
（5） $\log_2(\log_216)$ ;

（3） $\log_a x = \frac{1}{2} \log_a b - \log_a c$ ;
